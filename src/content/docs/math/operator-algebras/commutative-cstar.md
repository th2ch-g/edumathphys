## この章の目標

- 指標に各元を評価し、指標空間の位相を定める。
- 可換 C*-環を関数環として復元し、スペクトルを計算する。
- 単位を保たない準同型と連続写像の対応を説明する。
- 整数群の畳み込みから円周上の関数を得る。

## 指標空間と Gelfand 変換

関数環 $C(X)$ の各点 $x$ では、$f\mapsto f(x)$ が積と和を保つ。この性質を抽象化すると、環だけから点を探せる。指標がほかにないことは、点での評価と位相の両方を復元するために必要である。

:::definition[指標空間と変換]{#def-oa-gelfand-transform}
可換 C*-環 $A$ の非零な複素線形乗法写像 $\chi:A\to\C$ 全体を $\Delta(A)$ と書く。各評価 $\chi\mapsto\chi(a)$ が連続となる最も弱い位相を入れ、:term[指標空間]{en="character space" yomi="しひょうくうかん"} と呼ぶ。$\widehat a(\chi)=\chi(a)$ を :term[Gelfand 変換]{en="Gelfand transform" yomi="げるふぁんとへんかん"} という。点の収束はすべての $a$ に対する評価の収束をいう。
:::

:::proposition[指標の連続性と空間の局所コンパクト性]{#prop-oa-character-topology}
各指標は対合を保ちノルム $1$ をもつ。$\Delta(A)$ は局所コンパクト Hausdorff で、$A$ が単位的ならコンパクトである。$\widehat a$ は無限遠で消える。
:::

:::proof
単位的な場合は :ref[lem-oa-spectrum-characters] より $\abs{\chi(a)}\le\norm a$ で、$1$ の評価からノルムは $1$ である。自己共役元の評価が実数であるため対合を保つ。積空間 $\prod_{a\in A}\{z:\abs z\le\norm a\}$ の中で、線形性・乗法性・$\chi(1)=1$ は閉条件である。:ref[thm-top-tychonoff] でこの閉集合はコンパクト Hausdorff である。

非単位的な場合、$\widetilde\chi(a,\lambda)=\chi(a)+\lambda$ は単位的な指標である。従って $A$ 上でも縮小性と対合保存が成り立つ。$\chi$ は非零だから $\chi(b)\ne0$ となる $b\in A$ を選べる。$h=b^*b$ とすると $t=\chi(h)=|\chi(b)|^2>0$ である。$f(0)=0$、$f(t)=1$、$0\le f\le1$ となる連続関数を選べば、単位化でのカルキュラスの自然性により $f(h)\in A$、$\norm{f(h)}=1$、$\chi(f(h))=1$ である。

$\Delta(A^+)$ のうち $A$ を零に写す指標は $\chi_\infty(a,\lambda)=\lambda$ だけである。他の指標は制限で $\Delta(A)$ と対応し、各座標の式から対応は同相である。$\widehat a$ は外部の点で $0$ となるので、$\abs{\widehat a}\ge\eps>0$ の集合は外部の点を含まないコンパクト集合である。
:::

:::example[二点の指標]
$\C^2$ の座標射影 $e_1,e_2$ は $\chi(e_j)^2=\chi(e_j)$、$\chi(e_1)+\chi(e_2)=1$ を満たす。したがって指標は二つで、$(2,5)$ の Gelfand 変換はその二点でそれぞれ $2,5$ を取る。
:::

:::example[可算離散空間]
$c_0$ で異なる二つの座標射影の積は $0$ である。一つに値 $1$ を取る指標は他の座標射影に $0$ を取り、有限台列の稠密性から座標評価に等しい。すべてを $0$ に写すと指標が零になる。第 $n$ 評価は $c_0$ 上で $0$ に収束し、単位化では $\chi_\infty$ に収束する。
:::

### 指標を生成元の値から復元する

単位的可換環が正規元 $a_1,\ldots,a_d$ で生成されるとする。指標は積と対合を保つので、値の組 $(\chi(a_1),\ldots,\chi(a_d))$ が等しければ、各 $a_j,a_j^*$ の多項式上で一致する。これらの多項式は稠密であり、指標は縮小的であるため環全体でも一致する。従って、指標空間から $\C^d$ へのこの写像は連続単射である。定義域がコンパクトで値域が Hausdorff なので、像への同相写像になる。積関係がある場合は値を独立に選べない。

:::example[二つの射影が作る有限集合]
$p=\diag(1,1,0,0)$、$q=\diag(1,0,1,0)$ とする。$p,q$ は可換なので $pq,p(1-q),(1-p)q,(1-p)(1-q)$ は互いに直交し、和は $1$ である。この例では四つとも非零である。いずれか一つだけを $1$ に送る指標を作れるため、座標の組は $(1,1),(1,0),(0,1),(0,0)$ の四点になる。もし $pq=0$ と置けば $(1,1)$ は消える。指標に $pq$ を入力した値は $\chi(p)\chi(q)$ であり、その値が $1$ では零を保存できないためである。
:::

:::example[極限を課された指標]
収束列の環 $c$ は $c_0$ と定数列で張られる。座標射影 $e_n$ は互いに直交するから、指標が $1$ に送る $e_n$ は高々一つである。そのような $n$ があれば $e_na=a_ne_n$ より $\chi(a)=a_n$ である。全部を零に送る場合は有限台列を消し、ノルム連続性により $c_0$ も消す。そこで $\chi(a)=\lim a_n$ になる。座標を遠くへ送ると各 $a$ の値が極限に収束するので、点評価列が極限評価に収束する。有限個の座標を連続関数 $e_n$ で一つずつ除けることから、極限評価の近傍は有限個を除いた座標評価を含むものになる。
:::

### 有界列の指標をフィルターで読む

$\ell^\infty(\N)$ では、点評価以外の指標もある。部分集合 $E\subset\N$ の指示関数を $p_E$ とし、指標 $\chi$ から $\mathcal U=\{E:\chi(p_E)=1\}$ を作る。$p_Ep_F=p_{E\cap F}$ なので有限交叉を取り、$E\subset F$ なら $p_Ep_F=p_E$ なので上位集合も取り、さらに $p_E+p_{\N\setminus E}=1$ により集合とその補集合のどちらか一方だけを含む。このような真のフィルターを :term[超フィルター]{en="ultrafilter" yomi="ちょうふぃるたー"} という。

逆に超フィルター $\mathcal U$ を取る。有限値列 $f$ の値ごとの分割のうち、ただ一つの部分集合が $\mathcal U$ に入る。二つ入れば交わりが空となり、どれも入らなければ全ての補集合の交叉が空になるためである。そこでその部分集合上の値を $\chi(f)$ と定める。二つの有限値列では両方の分割を細分すれば、同じ部分集合上で足し算と積を検査できる。従って線形、乗法的で共役を保ち、絶対値は上限ノルム以下である。有界列は有限個の小さい長方形に値域を分けて各長方形の代表値を選べば有限値列で一様近似できる。従って $\chi$ は $\ell^\infty$ 全体の指標へ一意に延びる。

例えば偶数集合と奇数集合の補集合のうち、超フィルターは偶数集合または奇数集合のどちらか一方を選ぶ。従って $a_n=(-1)^n$ に対する値は $1$ または $-1$ である。有限集合を含まない超フィルターでは有限台列の値は零である。これは余有限集合のフィルターを Zorn の補題で極大に延長すれば得られる。極大性により、どちらも入らない集合と補集合があるときには、片側を加えても空集合を生成せず拡張できるため、上の二者択一が成立する。この指標は $c_0$ を消し、収束列では極限を取る。従って $c$ 上の一つの極限評価は、$\ell^\infty$ では複数の指標に延び得る。偶数と奇数については、余有限集合のフィルターにそれぞれ選びたい側を加えてから延長すればよい。

:::example[二つの射影が独立な場合]
二つの対角射影 $p,q$ を取り、この場合は どの組合せも存在する。生成される単位的部分環の指標と、元 $2p-3q+pq$ の Gelfand 変換を求める。

\end{aligned}
$$

$p_1=p,\ p_0=1-p,\ q_1=q,\ q_0=1-q$ と置く。$p_kq_l$ を計算すれば各点の指示関数が得られる。

| $(k,l)$ | $p_kq_l$ の対角値 | 指標は存在するか |
| --- | --- | --- |
| $\left( 0, \  0\right)$ | $\left( 1, \  0, \  0, \  0\right)$ | 存在する |
| $\left( 0, \  1\right)$ | $\left( 0, \  1, \  0, \  0\right)$ | 存在する |

## 可換 Gelfand–Naimark の定理

変換が元を失わないためには、すべての指標で消えた元が $0$ である必要がある。C* 条件から可換環の全要素にスペクトルとノルムの一致を適用できる。

:::theorem[可換 Gelfand–Naimark]{#thm-oa-commutative-gn}
可換 C*-環 $A$ に対し $a\mapsto\widehat a$ は $A$ から $C_0(\Delta(A))$ への等長 *-同型である。
:::

:::proof
単位的なら :ref[lem-oa-spectrum-characters] と :ref[thm-oa-normal-radius] から $\norm a=\max_{\chi}\abs{\widehat a(\chi)}$ である。像は完備性から閉じ、定数を含み、指標の定義から積と共役で閉じる。異なる指標はある元で値が違うので像は点を分離する。:ref[lem-oa-stone-weierstrass] を適用して全射性を得る。非単位的なら $A^+$ に適用する。$A$ は $\chi_\infty$ の核であり、連続関数側では $\chi_\infty$ に消える関数である。これは $\Delta(A)$ への制限で $C_0(\Delta(A))$ になる。逆の延長はその点で値を $0$ とし、コンパクトなレベル集合の補集合で連続性を確認すればよい。零環では指標空間は空であり、関数環も零である。
:::

:::example[行列の対角部分環]
$\diag(a,b,c)$ の指標空間は三点である。一方、全行列環の指標 $\chi$ では、任意の $i\ne j$ に対して $\chi(E_{ii})=\chi(E_{ij})\chi(E_{ji})=\chi(E_{jj})$ となる。$E_{ii}E_{jj}=0$ なので共通の値は零である。従って全ての対角値が零で、単位元の値も零になって矛盾する。非可換環全体にはこの再構成を適用できない。
:::

:::example[一つの座標で関数を復元する]
$X=[-1,2]$ で座標関数を $x$ とする。多項式が一様稠密なので $C^*(1,x)=C(X)$ である。例えば $x^2-1$ は $-1$ と $2$ でそれぞれ $0,3$ を取り、最小値 $-1$ を $0$ で取る。ノルムは $3$ であり、値域全体がスペクトルとなる。
:::

### 単位化と一点コンパクト化

非零かつ非単位的な可換 C*-環 $A$ では、$A^+$ の指標のうち $A$ に制限して零になるものは $\chi_\infty(a,\lambda)=\lambda$ の一つだけである。逆に $A$ の任意の指標は $\widetilde\chi(a,\lambda)=\chi(a)+\lambda$ と一意に延長する。この対応は、弱 * 位相が各元の値の収束であることから同相である。$X^+=\Delta(A^+)$ から $\chi_\infty$ を除いた空間を $X=\Delta(A)$ とすると、$\chi_\infty$ の開近傍の補集合は $X$ のコンパクト部分集合であり、逆に $X$ のコンパクト部分集合の補集合は $\chi_\infty$ の開近傍である。$X$ がコンパクトなら $A\cong C(X)$ は単位的になるので、$X$ は非コンパクトで $X^+$ に稠密である。従って $X^+$ が $X$ の :term[一点コンパクト化]{en="one-point compactification" yomi="いってんこんぱくとか"} である。すでに単位的な $A$ の外部単位化では、$\chi_\infty$ は孤立点になる。

:::example[端点を同一視する]
$A=C_0((0,1))$ を、両端で零に延長できる関数として考える。$A^+$ に定数を足すと両端で同じ値を取る $C([0,1])$ の部分環が得られる。逆に両端で値 $\lambda$ を取る関数から定数 $\lambda$ を引くと $A$ に戻る。写像 $t\mapsto e^{2\pi it}$ の各ファイバーは一点、または $\{0,1\}$ であるから、この部分環は円周の連続関数環に一致する。従って両端の評価は単位化で一つの無限遠の指標になる。例えば $f(t)=t(1-t)$ の像のスペクトルは $[0,1/4]$ であり、値 $0$ は円周の $1$ に対応する。
:::

:::example[分離する関数と生成]
$X=[-1,1]$ で $u(t)=t^2$ が生成する単位的環では、すべての関数が $t$ と $-t$ を区別できない。逆に偶関数 $f$ に対し $g(s)=f(\sqrt s)$ と置けば $f=g(u)$ なので、環は偶関数全体である。$v(t)=t^3$ を加えると $v$ が点を分離し、実数値で対合に閉じているため Stone–Weierstrass により全体を生成する。実際、座標そのものが連続関数 $s\mapsto\sqrt[3]{s}$ を $v$ に作用させて得られる。
:::

### 複数の生成元の同時スペクトル

:::proposition[同時スペクトルの座標射影]{#prop-oa-joint-spectrum}
可換な正規元 $a_1,\ldots,a_d$ が単位的可換 C*-環 $A$ を生成する場合、指標の値の組の集合 $K$ に対して $A\cong C(K)$ である。各座標射影 $K\to\C$ の像は $\sigma_A(a_j)$ である。
:::

:::proof
指標空間からの座標写像は最初の節の議論で位相的な埋め込みである。その像を $K$ とすれば可換 Gelfand–Naimark で $A\cong C(K)$ が出る。この同型で $a_j$ に対応するのは $j$ 番目の座標関数なので、そのスペクトルは座標の値域である。逆に $K$ が先に与えられている場合にも、座標関数とその共役は各点を分離するので全環を生成する。
:::

:::example[三角形と正方形を座標スペクトルで区別できない]
$K=\{(s,t)\in[0,1]^2:s+t\le1\}$、$L=[0,1]^2$ とする。どちらの空間でも二つの座標のスペクトルは個別には $[0,1]$ である。一方、和の値域は $K$ で $[0,1]$、$L$ で $[0,2]$ である。積は $K$ では $st\le(s+t)^2/4\le1/4$ で、$(1/2,1/2)$ で上界を達成する。$L$ では $(1,1)$ で $1$ を取る。このため個々のスペクトルだけを知っても、和や積のスペクトルは決まらない。
:::

:::example[一変数の図形から二変数の関係を読む]
$C([-2,2])$ で $a(t)=t^2$、$b(t)=t^3$ とする。$b$ が単射なのでこれらは全環を生成する。値の組は $s\ge0$、$r^2=s^3$、$s\le4$ を満たす。逆にこの条件を満たす組について $t=\sqrt[3]r$ と置くと $t^2=s$ であり、$|t|\le2$ である。従って同時スペクトルはこの半三次曲線の切片になる。$r$ を許される二符号に分けると、$a$ だけが生成する部分環が区別できなくなる二点の対も読み取れる。
:::

:::example[絶対値を生成元にする]
対角行列 $a$ の単位的生成環を考え、$b=a^2$ が生成する部分環を求める。$a$ の値が異なっていても $b$ の値は一致し得る。

固有値を変換し、等しくなる成分を拾い出す。

$$
\begin{aligned}

\end{aligned}
$$

$b$ の相異なる値を $v_j$ とする。各 $v_j$ に対応する射影は $\prod_{i\ne j}(b-v_iI)/(v_j-v_i)$ であり、その対角成分は次の表になる。

| $v_j$ | 射影の対角値 | 階数 |
| --- | --- | --- |
| $0$ | $\left( 0, \  1, \  0\right)$ | $1$ |
| $4$ | $\left( 0, \  0, \  1\right)$ | $1$ |
| $9$ | $\left( 1, \  0, \  0\right)$ | $1$ |

$$
\begin{aligned}
\sigma(a)&=\left\{-3, 0, 2\right\}\\
\sigma(b)&=\left\{0, 4, 9\right\}
\end{aligned}

この結果は Gelfand 双対での連続全射 $\sigma(a)\to\sigma(b)$ を具体化する。異なる点を同じ値に送る場合、引き戻した関数はその二点を分離できない。
:::

## スペクトル写像定理

:::theorem[連続スペクトル写像]{#thm-oa-continuous-spectral-mapping}
$A$ を非零単位的 C*-環、$a$ を正規元とし、$f$ を $\sigma_A(a)$ 上の連続関数とする。このとき
$$
\sigma_A(f(a))=f(\sigma_A(a)),\qquad
\norm{f(a)}=\max_{\lambda\in\sigma_A(a)}\abs{f(\lambda)}.
$$
さらに $g$ が $f(\sigma_A(a))$ 上連続なら $g(f(a))=(g\circ f)(a)$ である。
:::

:::proof
:ref[thm-oa-functional-calculus] によって $C^*(1,a)$ に移ると、$f-\mu$ は零点がないときちょうど可逆で、逆は点ごとの逆数である。:ref[cor-oa-spectral-permanence] で元の環へ戻せる。ノルム式は等長性である。$g$ が座標とその共役の多項式なら合成式は演算の保存から従い、連続 $g$ については Stone–Weierstrass の定理による一様近似で従う。
:::

:::example[逆数の計算]
$h(t)=2+t$ を $[-1,1]$ 上で考えると $\sigma(h)=[1,3]$ である。したがって $\sigma(h^{-1})=[1/3,1]$、$\norm{h^{-1}}=1$ となる。これに対し $h-1$ は $t=-1$ で消えるので逆元をもたない。
:::

:::example[非単位的なスペクトル]
$c_0$ の列 $a_n=(-1)^n/n$ には $\sigma(a)=\{0\}\cup\{(-1)^n/n:n\ge1\}$ が対応する。絶対値を作用させるとスペクトルは $\{0\}\cup\{1/n:n\ge1\}$ になる。元の環に値を取る条件は $f(0)=0$ である。$1+\abs a$ のような元は単位化で計算する。
:::

### 値域、閉包、零の三つの役割

単位的な $C(X)$ で $f-z$ が逆元を持つ条件は $z$ が値域の外にあることである。コンパクト性により $|f-z|$ は正の最小値を持つので、逆数が連続になる。非単位的な $C_0(X)$ では、無限遠を含むスペクトルを使う。この場合 $z\ne0$ で $z\notin f(X)$ なら、逆数と定数 $-1/z$ の差は無限遠で消える。実際、
$$
\frac1{f-z}+\frac1z=\frac{f}{z(f-z)}
$$
であり、分母は無限遠では $-z^2$ へ近づき、残りのコンパクト部分でも零点をもたない。

:::example[値を取らないスペクトル点]
離散空間 $\N$ で $a_n=1/(n+1)$ とする。各座標は正だが、単位化では無限遠の値が零なので $\sigma(a)=\{1/2,1/3,\ldots\}\cup\{0\}$ である。$f(t)=1/(1+t)$ を作用させると、第 $n$ 座標は $(n+1)/(n+2)$、無限遠の値は $1$ になる。従ってノルムは $1$ であるが、どの有限座標でも $1$ は達成されない。一方 $f(a)-1$ は $c_0$ に戻り、そのスペクトルは $\{-1/3,-1/4,\ldots\}\cup\{0\}$ となる。
:::

:::example[逆数から距離を測る]
$f(t)=2+it$、$-1\le t\le1$ とする。$z=2+2i$ は線分 $f([-1,1])$ から距離 $1$ にあり、$|f(t)-z|=|t-2|$ の最小値が $t=1$ で達成される。従って $(f-z)^{-1}$ のノルムは $1$ である。これを $z=3$ に替えると距離は $\min_t\sqrt{1+t^2}=1$ で、ノルムは同じだが最小点は $0$ になる。スペクトルの位置と距離を使えば、最大値をとる場所まで求められる。
:::

:::example[内部に最小がある記号]
$a$ を区間 $\left[0, 4\right]$ 上の座標関数とする。$f(a)$ のスペクトルと、実数 $b$ の中で $\norm{f(a)-b1}$ を最小にする $b$ を求める。

連続スペクトル写像によりスペクトルは $f$ の値域になる。二次式の導関数を使い、区間内に入る臨界点だけを端点に加える。

$$
\begin{aligned}

f'(t)&=2 t - 4
\end{aligned}
$$

候補点の値を比較する。区間は連結なので、最大値と最小値の間の値をすべて取る。

| 候補点 | 値 |
| --- | --- |
| $0$ | $1$ |
| $2$ | $-3$ |
| $4$ | $1$ |

$[l,u]$ を得られた値域とすると、$\norm{f(a)-b1}=\max(|l-b|,|u-b|)$ である。三角不等式よりこの最大値は少なくとも $(u-l)/2$ であり、中点で二つの距離が等しくなる。

$$
\begin{aligned}
\sigma(f(a))&=\left[-3, 1\right]\\
b&=-1\\
\norm{f(a)-b1}&=2
\end{aligned}
$$
:::

## 局所コンパクト空間と可換 C*-環の対応

:::lemma[関数環の指標は点評価]{#lem-oa-evaluation-character}
局所コンパクト Hausdorff 空間 $X$ は、点評価によって $\Delta(C_0(X))$ と同相である。
:::

:::proof
コンパクトな場合、指標の核の関数に共通の零点がないと仮定する。各点で消えない核の元の有限族 $f_1,\dots,f_n$ をコンパクト性で選ぶと $\sum_j\bar f_j f_j$ は核に属し逆元ももつので矛盾する。共通の零点 $x$ では $f-\chi(f)1$ が消え、$\chi(f)=f(x)$ である。連続関数が点を分離するため $x$ は一意である。非コンパクトな場合は一点コンパクト化 $X^+$ に移ると $C(X^+)$ が外部単位化であり、無限遠点の指標だけが $C_0(X)$ を零に写す。これで全単射を得る。評価による連続性と逆の連続性は、任意の点とその開近傍について、その点で $1$ で近傍の外で消えるコンパクト台連続関数を取れば分かる。この存在は一点コンパクト化上で :ref[thm-top-urysohn] を適用すればよい。
:::

:::theorem[準同型の空間表示]{#thm-oa-contravariant}
$\Phi:C_0(X)\to C_0(Y)$ を *-準同型とし、$U=\{y\in Y:\exists f,\ \Phi(f)(y)\ne0\}$ とする。ある一意な固有連続写像 $g:U\to X$ があり、$U$ で $\Phi(f)=f\circ g$、$Y\setminus U$ で $\Phi(f)=0$ となる。逆に開集合 $U\subset Y$ と固有連続写像 $g:U\to X$ はこの式で *-準同型を定める。
:::

:::proof
$U$ は連続関数の非零集合の和集合で開である。$y\in U$ では $f\mapsto\Phi(f)(y)$ が指標なので :ref[lem-oa-evaluation-character] で $g(y)$ が一意に定まる。評価の位相により連続である。コンパクト $K\subset X$ 上で $1$ となるコンパクト台関数 $f$ を取る。$g^{-1}(K)$ は $\{\abs{\Phi(f)}\ge1\}$ の閉部分集合である。この集合は $U$ に入るコンパクト集合なので $g^{-1}(K)$ もコンパクトである。

逆に固有性により $\{y\in U:\abs{f(g(y))}\ge\eps\}$ は $U$ でコンパクトであり、$Y$ でも閉である。したがって零延長は $U$ の境界で連続で、無限遠で消える。演算は点ごとの式に従う。
:::

$U=Y$ となる条件は $\Phi(C_0(X))C_0(Y)$ の線形包が稠密であることである。実際、$y\notin U$ があれば評価 $y$ がこの線形包を零にする。逆に $U=Y$ なら $Y$ のコンパクト集合 $K$ に対して $g(K)$ 上で $1$ の関数を選び、台が $K$ の任意の関数 $h$ を $\Phi(f)h$ と書ける。コンパクト台関数が稠密である。コンパクト空間で単位的なときは全空間上の連続写像だけになり、準同型の向きは空間の写像と逆になる。

ここで用いる切断関数は、$X$ に無限遠点を加えたコンパクト Hausdorff 空間上で作れる。コンパクト集合 $K\subset X$ の近傍を、その閉包が $X$ に入るように選び、$K$ 上で $1$、その近傍の外で $0$ になる $[0,1]$ 値関数を Urysohn の補題で取る。$f\in C_0(X)$ について $K=\{x:|f(x)|\ge\eps\}$ とすれば、この関数を $f$ に掛けた誤差は $\eps$ 以下なので、コンパクト台関数の稠密性も従う。

:::example[開部分集合での零延長]
$X=U=(0,1)$、$Y=[0,1]$、$g=\id$ とする。端点で値 $0$ を入れると $C([0,1])$ の両端点で消えるイデアルになる。$f(t)=t(1-t)$ のノルムは $1/4$ である。
:::

:::proposition[関数環の閉イデアル]{#prop-oa-commutative-ideals}
$I$ を $C_0(X)$ の閉イデアルとし、$U=\bigcup_{g\in I}\{x:g(x)\ne0\}$ とおく。すると $I$ は $C_0(U)$ の零延長の像である。
:::

:::proof
$I$ の各元は $U$ の外で消える。逆に $f$ が $U$ の外で消えるとし、$\eps>0$ に対し $K_\eps=\{x:\abs f(x)\ge\eps\}$ とおく。$K_\eps$ は $U$ に含まれるコンパクト集合である。各点で消えない $I$ の元を有限個選び、その絶対値の二乗の和を $h\in I$ とする。$K_\eps$ が非空なら $m=\min_{K_\eps}h>0$ である。$\delta>0$ に対し $fh/(h+\delta)\in I$ であり、差の絶対値は $K_\eps$ 上で $\norm f_\infty\delta/(m+\delta)$ 以下、その外で $\eps$ 未満である。$\delta$ を十分小さくすれば $\norm{f-fh/(h+\delta)}_\infty\le\eps$ となる。$K_\eps$ が空なら零で同じ誤差を得る。閉性で $f\in I$ である。$C_0(U)$ の零延長と $U$ の外で消える元が一致するのは、正のレベル集合が $U$ 内でコンパクトであることによる。
:::

:::example[一つの関数が生成するイデアル]
$X=[0,1]$、$g(t)=t(1-t)$ なら、$g$ が生成する閉イデアルは両端点で消える関数全体である。例えば $f=\sqrt{g}$ はこのイデアルに入る。$f/g$ は端点で発散するため $f$ は $g$ の連続関数倍にはならないが、上の $fg/(g+\delta)$ によって一様近似できる。
:::

:::example[消える成分]
$X$ を一点、$Y=\{1,2\}$ とし、$\Phi(\lambda)=(\lambda,0)$ とする。$U=\{1\}$ なので $Y$ 上の写像による引き戻しでは単位元の値を再現できない。開集合を入れることにより準同型が表される。
:::

### 閉集合への制限と商ノルム

$F\subset X$ を閉集合とし、$r:C_0(X)\to C_0(F)$ を制限とする。$F$ が空なら標的は零環である。そうでなければ $F$ に無限遠を加えて $X$ の一点コンパクト化の閉集合と考え、$h\in C_0(F)$ を無限遠で零に延長する。コンパクトな $X$ の場合も、別の孤立点を一つ加えれば同じ方法が使える。

:::proposition[閉集合への制限は等長な商を与える]
$r$ は全射であり、$\norm{f+\Ker r}=\norm{f|_F}_\infty$ である。
:::

:::proof
コンパクト Hausdorff 空間は正規なので、:ref[thm-top-tietze]{text="Tietze 拡張定理"}を実部と虚部に適用できる。得られた複素関数を半径 $\norm h_\infty$ の閉円板に放射方向に縮める連続写像に通すと、閉集合上では値が変わらず、全体のノルムが $\norm h_\infty$ 以下になる。無限遠での値は零なので、その制限は $C_0(X)$ に属する。このため任意の $h$ が同じノルムで持ち上がる。逆向きの評価は $\norm{r(g)}\le\norm g$ から直ちに出る。
:::

:::example[三点からの最小ノルム延長]
$X=[0,2]$、$F=\{0,1,2\}$ とし、$h(0)=2$、$h(1)=-1$、$h(2)=i$ とする。二つの単位区間で隣り合う値を線分で補間する。半径 $2$ の閉円板は凸で三つの値を含むため、この補間のノルムは $2$ 以下である。端点 $0$ で値 $2$ を取るのでちょうど $2$ であり、制限写像の核で割った商のノルムも $2$ になる。
:::

:::proposition[引き戻しの単射性と全射性]
:ref[thm-oa-contravariant] の $\Phi$ は、$g(U)=X$ のとき、かつそのときに限り単射である。また $U=Y$ かつ $g$ が単射のとき、かつそのときに限り全射である。
:::

:::proof
固有連続写像 $g:U\to X$ は閉写像である。閉集合 $D\subset U$ と $x\in\overline{g(D)}$ を取る。$x$ のコンパクト近傍 $K$ を選ぶと $x\in\overline{g(D)\cap K}$ であり、$D\cap g^{-1}(K)$ はコンパクトなので、その像 $g(D)\cap K$ は閉である。従って $x\in g(D)$ である。核は $g(U)$ で消える関数全体である。この閉集合が $X$ 全体でなければ補集合で非零のコンパクト台関数が取れるため、単射性に関する主張が従う。

$U\ne Y$ なら像の関数は $Y\setminus U$ で消える。$g$ が異なる二点を同じ点に送る場合も、その二点を分離する $C_0(Y)$ の関数は像にない。逆に $U=Y$ で $g$ が単射なら、閉写像であるため閉集合 $g(Y)$ への同相である。$g(Y)$ への関数の制限は前の命題により全射なので、それを $g$ で引き戻す $\Phi$ も全射である。
:::

:::example[引き戻しが無限遠で消えない場合]
$X=\R$、$Y=\R$ とし $p(y)=0$ と置く。$f(t)=e^{-t^2}$ の引き戻しは定数 $1$ である。従って連続な写像でも $C_0(X)$ 全体を $C_0(Y)$ へ引き戻せるとは限らない。一方 $p(y)=2y$ ならコンパクト集合の逆像がコンパクトであり、$f(2y)$ の $\eps$ 以上の領域は $f$ のそれの逆像になる。従って引き戻しは $C_0(Y)$ に入る。
:::

### 三つの空間を合成するときの定義域

可換 C*-環の準同型に対応する空間の写像を、開部分集合とその上の固有写像の組として扱う。$\varphi:C_0(X)\to C_0(Y)$ が $p:U\to X$（$U\subset Y$ は開集合）、$\psi:C_0(Y)\to C_0(Z)$ が $q:V\to Y$ に対応するとする。合成 $\psi\varphi$ は $W=V\cap q^{-1}(U)$ 上の $p\circ q$ に対応する。実際 $z\notin V$ なら $\psi$ の評価は零であり、$z\in V$ でも $q(z)\notin U$ なら $\varphi$ の結果は零である。$z\in W$ でだけ二つの点評価を続けられる。任意のコンパクト集合 $K\subset X$ について $p^{-1}(K)$ は $U$ 内でコンパクトであり $Y$ 内でもコンパクトである。その $q$ による逆像は $V$ 内でコンパクトで $W$ に含まれる。このため合成も固有になる。

:::example[離散空間で定義域が狭まる合成]
$X=\{x_1,x_2\}$、$Y=\{y_1,y_2,y_3\}$、$Z=\{z_1,z_2,z_3,z_4\}$ とする。$U=\{y_1,y_3\}$ で $p(y_1)=x_2$、$p(y_3)=x_1$ とする。$q$ の定義域は $z_1,z_2,z_3$ で、像を順に $y_3,y_2,y_1$ とする。$f=(2,7)$ なら $\varphi f=(7,0,2)$ であり、$\psi\varphi f=(2,0,7,0)$ になる。途中の $y_2$ を通る $z_2$ では値が消え、$z_4$ では二つ目の写像自体が定義されていない。従って合成の非零評価があり得る定義域は $\{z_1,z_3\}$ である。
:::

:::example[繰り返しと消える座標]
有限離散空間 $X,Y$ で点の写像 $r:Y\to X$ を考える。$X$ の関数 $f$ を値の列、$r^*f=f\circ r$ を行列による変換として書く。

行は $Y$ の一点を表す。一つの行の唯一の $1$ が、その点の像を指定する。

$$
\begin{aligned}
P&=\begin{pmatrix}0 & 0 & 1 & 0\\1 & 0 & 0 & 0\\0 & 0 & 1 & 0\end{pmatrix}\\
f&=\begin{pmatrix}1\\2\\4\\6\end{pmatrix}\\
r^*f=Pf&=\begin{pmatrix}4\\1\\4\end{pmatrix}
\end{aligned}
$$

各行は一つの成分を選ぶので、積の関数も同じ成分で評価される。$f^2$ の引き戻しと、引き戻しの二乗を比較する。

$$
\begin{aligned}
r^*(f^2)&=\begin{pmatrix}16\\1\\16\end{pmatrix}\\
(r^*f)^2&=\begin{pmatrix}16\\1\\16\end{pmatrix}
\end{aligned}
$$

核は $r(Y)$ 上で零になる関数である。$X$ の点を $1$ から番号で表すと、核の中で値を自由に選べる点の集合は $\left\{2, 4\right\}$ である。像の関数は $Y$ の同じファイバー上で一定であり、任意のファイバー定数関数は残りの座標に零を入れれば持ち上がる。

$$
\begin{aligned}
\dim\Ker r^*&=2\\
\dim\Img r^*&=2
\end{aligned}
$$

この場合、単射性は点の写像の全射性、全射性は点の写像の単射性で決まる。
:::

## 例：C*(ℤ) と円周上の連続関数環

整数の有限台列を $\sum_n a_n\delta_n$ と書く。$\delta_m*\delta_n=\delta_{m+n}$、$\delta_n^*=\delta_{-n}$ と定め、線形または共役線形に延長する。表現は $\delta_1$ の像であるユニタリで決まり、任意のユニタリ $U$ が $\sum_n a_nU^n$ によって表現を定める。

:::proposition[整数群の普遍ノルム]{#prop-oa-z-group-cstar}
すべてのユニタリへの代入で得られるノルムの上限は
$$
\sup_U\norm{\sum_n a_nU^n}=\max_{z\in\mathbb T}\abs{\sum_n a_nz^n}
$$
である。そのノルムによる完備化 $C^*(\Z)$ は $C(\mathbb T)$ と等長 *-同型である。両側シフトを用いて完備化しても同じ環を得る。
:::

:::proof
:ref[thm-oa-normal-radius] から $\sigma(U)\subset\mathbb T$ であり、関数カルキュラスが左辺を右辺で抑える。各 $z\in\mathbb T$ を一次元ユニタリとすれば逆向きである。Laurent 多項式の一様稠密性は Stone–Weierstrass の定理による。両側シフト $Se_k=e_{k+1}$ に対して $\eta_N=(2N+1)^{-1/2}\sum_{k=-N}^N z^{-k}e_k$ とおくと $\norm{(S-z)\eta_N}^2=2/(2N+1)$ である。もし $S-z$ が可逆なら左辺の平方根は $\norm{(S-z)^{-1}}^{-1}$ 以上であり、矛盾する。よって $\sigma(S)=\mathbb T$ であり、一つの表現で上限を実現する。
:::

:::example[畳み込みを関数の積に変える]
$\delta_1+\delta_{-1}$ は $z+z^{-1}$ に移るので、$z=e^{i\theta}$ で $2\cos\theta$ となり、スペクトルは $[-2,2]$ である。二乗は $\delta_2+2\delta_0+\delta_{-2}$ であり、第 $0$ 係数 $2$ は $4\cos^2\theta$ の円周平均である。
:::

:::example[円周での零点]
$2\delta_0-\delta_1$ は円周上で決して消えない。逆元は $\sum_{n\ge0}2^{-n-1}\delta_n$ であり、級数を掛けると定数項 $1$ だけが残る。$\delta_0-\delta_1$ は $z=1$ で消えるので逆元をもたない。
:::

### 正則表現と Fourier 変換

$\ell^2(\Z)$ の正規直交基底 $\delta_n$ を $L^2(\mathbb T,m)$ の $z^n$ に送る。$m$ は全質量 $1$ の弧長測度である。指数関数の内積を積分すれば正規直交性が分かり、Stone–Weierstrass と連続関数の $L^2$ 稠密性により全体を張る。従ってこの対応はユニタリ $U$ に延びる。左移動 $\lambda(k)\delta_n=\delta_{n+k}$ は、$U$ の下で $M_{z^k}$ になる。有限台 $a$ の正則表現は $M_{p_a}$ で、作用素ノルムは $p_a$ の上限ノルムに一致する。上界は点ごとの評価、下界は最大値の任意の近傍が正の測度をもつことから得られる。

:::example[有限差分 Laplacian]
$a=2\delta_0-\delta_1-\delta_{-1}$ の記号は $p(z)=2-z-\bar z=|1-z|^2$ である。円周上の値域は $[0,4]$ であり、$\lambda(a)$ は正作用素で $\norm{\lambda(a)}=4$ になる。$1-p$ の値域は $[-3,1]$ なので $1-\lambda(a)$ のノルムは $3$ になる。$(\delta_0-\delta_1)^*\ast(\delta_0-\delta_1)=a$ と計算しても正性を確かめられる。
:::

:::example[Fourier 係数と零点]
$a=\delta_{-1}+2\delta_0+\delta_1$ の記号は $2+2\cos\theta$ である。この関数は $\theta=\pi$ で零になるので可逆でない。一方 $L^2$ での乗算作用素の核は零である。零点が一点で測度零だからである。$\pi$ に近い小区間の規格化指示関数に適用すれば像のノルムは任意に小さくなるので、核が零でも逆作用素は有界にならない。
:::

### 二つ以上の独立な Fourier 変数

:::proposition[整数格子の群 C*-環]{#prop-oa-integer-lattice-cstar}
$d\ge1$ に対し $C^*(\Z^d)\cong C(\mathbb T^d)$ であり、この群の普遍ノルムと被約ノルムは一致する。
:::

:::proof
標準基底の群元は可換なユニタリ $u_1,\ldots,u_d$ に対応する。その有限 Laurent 多項式は普遍群環の稠密な *-部分代数である。各組 $(z_1,\ldots,z_d)\in\mathbb T^d$ は群指標 $n\mapsto z_1^{n_1}\cdots z_d^{n_d}$ を与えるので、普遍ノルムは多項式の上限ノルム以上である。一方任意のユニタリ表現で生成される環は可換である。その指標が各 $u_j$ を絶対値一の数へ送るので、可換 Gelfand–Naimark によりその表現でのノルムは同じ上限ノルム以下である。従って等号である。これらの多項式は定数を含み、各座標で点を分離し、複素共役で閉じるので Stone–Weierstrass により $C(\mathbb T^d)$ に一様稠密である。

$\ell^2(\Z^d)$ の標準基底を $z^n$ に送る写像は、各変数の積分の直交性と Laurent 多項式の稠密性で $L^2(\mathbb T^d)$ へのユニタリになる。各左移動の像は $z_j$ の乗算である。連続関数の上限は弧長測度の積に関する本質的上限に一致する。最大点の任意の開近傍が正測度であるためである。そこで被約ノルムも同じになる。
:::

:::example[格子の二方向の有限差分]
$\Z^2$ で $a=4\delta_0-\delta_{(1,0)}-\delta_{(-1,0)}-\delta_{(0,1)}-\delta_{(0,-1)}$ とする。記号は $|1-z|^2+|1-w|^2$ であり、各項は $[0,4]$ の全域を動く。従ってスペクトルは $[0,8]$ である。零になるのは両座標が $1$ の点だけである。正則表現には零固有ベクトルはないが、そこへの近傍に単位ベクトルを集中させれば近似固有値零を確認できる。二つの方向の差分を足したため、最大値は片方だけを動かすときの二倍になる。
:::

:::example[正の記号を持つ和]
$C^*(\Z)$ の有限台元 $x=\sum c_k\delta_k$ の記号を $p$ とする。$c_{-k}=\overline{c_k}$ なので $x$ は自己共役である。積 $x^*x=x^2$ の全係数と、正則表現で単位ベクトル $\delta_0$ に関する期待値を求める。

まず記号を Laurent 多項式に直す。$\delta_i\delta_j=\delta_{i+j}$ なので、積の添字は和で決まる。

$$
\begin{aligned}
p(z)&=z + 3 + \frac{1}{z}\\
p(z)^2&=z^{2} + 6 z + 11 + \frac{6}{z} + \frac{1}{z^{2}}
\end{aligned}
$$

同じ和になる添字をまとめる。円周上では $p(z)$ は実数だから $p(z)^2=|p(z)|^2$ である。

| 次数 $k$ | 係数 $\sum_i c_i c_{k-i}$ |
| --- | --- |
| $-2$ | $1$ |
| $-1$ | $6$ |
| $0$ | $11$ |
| $1$ | $6$ |
| $2$ | $1$ |

$\lambda(x^2)\delta_0$ の $\delta_0$ 成分には定数項だけが入る。他方 $\lambda(x)\delta_0=\sum_i c_i\delta_i$ だから二乗ノルムは各係数の二乗和になる。

$$
\begin{aligned}
\inner{\lambda(x^*x)\delta_0}{\delta_0}&=11\\
\sum_i|c_i|^2&=11
\end{aligned}
$$

Fourier 変換ではこの期待値は記号の二乗の平均であり、作用素ノルムの二乗はその最大値である。
:::

## 演習問題

::::exercise{level=basic}
$\C^3$ の指標を列挙し、$(3,-1,2i)$ の変換のノルムを求めよ。
:::solution
座標冪等元を評価した値は $0$ か $1$ で、その和は $1$ である。よって三つの座標評価が全指標である。値 $3,-1,2i$ の絶対値の最大は $3$ となる。
:::
::::

::::exercise{level=basic}
$C([-2,1])$ で $h(t)=t^2+t$ のスペクトルを求めよ。
:::solution
$h(t)=(t+1/2)^2-1/4$ だから最小は $-1/4$、端点の値はともに $2$ である。中間値をすべて取るのでスペクトルは $[-1/4,2]$ である。
:::
::::

::::exercise{level=basic}
$z^2+z^{-2}$ に対応する群環の元のノルムと、その二乗の第 $0$ 係数を求めよ。
:::solution
元は $\delta_2+\delta_{-2}$ である。円周での値は $2\cos(2\theta)$ なのでノルムは $2$ である。二乗は $\delta_4+2\delta_0+\delta_{-4}$ で、求める係数は $2$ である。
:::
::::

::::exercise{level=basic}
$g:[0,1]\to[0,1]$、$g(t)=t^2$ の引き戻しは全射か。$t\mapsto t$ の原像を求めよ。
:::solution
$g$ は逆写像 $x\mapsto\sqrt x$ をもつ同相なので、任意の $h$ は $f=h\circ g^{-1}$ で引き戻せる。座標関数の原像は $\sqrt x$ である。
:::
::::

::::exercise{level=advanced}
$X$ が局所コンパクト Hausdorff のとき、$C_0(X)$ に単位元がある条件を示せ。ただし $X\ne\varnothing$ とする。
:::solution
各点 $x$ で値 $1$ になるコンパクト台関数を選び、それに単位元を掛けると単位元の値も $1$ と分かる。定数 $1$ が $C_0(X)$ に属するにはレベル集合 $X$ がコンパクトでなければならない。コンパクトなら定数 $1$ は単位元である。
:::
::::

::::exercise{level=advanced}
非コンパクトな $X$ について、$C_0(X)$ の非零冪等元とコンパクトかつ開な部分集合の対応を示せ。
:::solution
冪等性により値は $0,1$ だけである。値 $1$ の逆像は開で、絶対値が $1/2$ 以上のレベル集合でもあるためコンパクトである。逆に非空なコンパクト開集合は Hausdorff 性によって閉でもあり、その指示関数は連続で無限遠で消える。
:::
::::

::::exercise{level=advanced}
コンパクト空間 $X,Y$ の連続写像 $g:Y\to X$ の引き戻しが単射である条件を求めよ。
:::solution
$g(Y)=X$ なら $f\circ g=0$ は $f=0$ を意味する。像はコンパクトで閉だから、像にない点があればその点で $1$、像で $0$ となる連続関数を選べる。その関数は非零の核の元である。従って条件は $g$ の全射性である。
:::
::::

::::exercise{level=advanced}
$t>1$ に対して $t\delta_0-\delta_{-1}$ の逆元のノルムを求めよ。
:::solution
円周上で $\abs{t-z^{-1}}\ge t-1$ であり、$z=1$ で等号となる。従って逆元のノルムは $(t-1)^{-1}$ である。Neumann 級数でも $\sum_{n\ge0}t^{-n-1}\delta_{-n}$ が逆元を与え、$z=1$ で同じ値に達する。
:::
::::

::::exercise{level=advanced}
$f(t)=t^2$ と $g(t)=t^3$ を $C([-2,2])$ の元とする。$\sigma(f)$ と $\sigma(g)$ を求めよ。また $(1,3)$ は $\chi\mapsto(\chi(f),\chi(g))$ の像に入るか。
:::solution
$t^2$ は $0$ で最小値 $0$ を、端点で最大値 $4$ を取るので $\sigma(f)=[0,4]$ である。$t^3$ は狭義単調で端点の値は $-8,8$ だから $\sigma(g)=[-8,8]$ である。指標が $f$ を $1$ に送ると、点評価の記述により対応する点は $t=1$ または $t=-1$ である。このとき $g$ の値は $1$ または $-1$ になるため $(1,3)$ は得られない。代数的に見ても $g^2=f^3$ から、像の中では第 2 成分の二乗が第 1 成分の三乗に等しい。
:::
::::

::::quiz
可換単位的 C*-環の Gelfand 変換は何を保つか。

- [x] ノルム
- [x] 対合
- [x] 積
- [ ] 異なる指標における評価値の一致

:::explanation
各指標が積を保ち、自己共役元上で実数値なので対合も保つ。すべての指標での絶対値の最大がスペクトル半径であり、可換環の元は正規なのでこれはノルムに等しい。異なる指標は定義により少なくとも一つの元の評価値が異なる。
:::

:::explanation
対応する関数は $1+2\cos\theta$ で値域は $[-1,3]$ である。絶対値の最大は $3$ である。
:::

::::quiz
包含 $(0,1)\subset[0,1]$ に沿う零延長の像はどれか。

- [x] 両端点で消える連続関数
- [ ] 両端点で値が一致する全連続関数
- [ ] 定数関数

:::explanation
無限遠で消える条件により両端点の極限は $0$ である。逆に $[0,1]$ 上で両端点に消える連続関数の正のレベル集合は両端点から離れたコンパクト集合なので、その制限は $C_0((0,1))$ に属する。
:::
