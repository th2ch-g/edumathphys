## この章の目標

- Gauss 過程の有限次元分布を構成し、連続な版を得る。
- Brown 経路が Hölder 連続でも微分できない理由を説明する。
- 停止時刻以後の増分から鏡像原理と逆正弦法則を導く。
- 微分の代わりに二次変分が有限になることを示す。

## Gauss 過程と Kolmogorov の拡張定理

有限個の時刻で望ましい同時分布を書けても、全時刻で定まる過程が得られるとはすぐには言えない。まず有限次元分布の整合性を使って確率測度を作り、その後で連続性を調べる。

:::definition[Gauss 過程]{#def-prob-gaussian-process}
任意の有限個の時刻の値が同時正規分布をもつ過程を :term[Gauss 過程]{en="Gaussian process" yomi="がうすかてい"} という。退化した正規分布も許す。平均 $m(t)$ と共分散 $C(s,t)$ が与えられ、全有限行列 $(C(t_i,t_j))$ が半正定値なら、各有限時刻集合に対応する正規分布を定められる。
:::

有限次元分布は、平均ベクトルと共分散をもつ行列の平方根を独立標準正規に作用させて作る。特性関数は平均と共分散だけに依存し、座標を消すと対応する部分行列を共分散とする分布になる。

:::theorem[実数値過程の Kolmogorov 拡張定理]{#thm-prob-kolmogorov-extension}
任意の添字集合 $T$ について、有限部分集合 $F$ ごとに $\R^F$ 上の確率測度 $\mu_F$ を与え、$F\subset G$ のとき $\mu_G$ の射影が $\mu_F$ になるとする。このとき、$\R^T$ の積 $\sigma$-加法族上に、これらを有限次元分布とする確率測度がただ一つ存在する。
:::

:::proof
有限座標の柱状集合の代数に、対応する有限次元確率を割り当てる。整合性により割当は矛盾なく定まり、有限加法性も共通の有限座標に引き上げれば従う。空集合に減少する柱状集合列があり、それぞれの確率が $\delta>0$ 以上だと仮定する。第 $n$ の集合の有限次元底面の中からコンパクト集合を選び、確率の損失を $\delta 2^{-n-2}$ 未満にする。これは Euclid 空間の有限 Borel 測度の内部正則性による。元の列が減少するので、選んだコンパクト底面を持つ柱状集合の任意の有限共通部分は、その確率が $\delta-\sum_n\delta 2^{-n-2}>0$ 以上である。

列が指定する座標は高々可算である。各座標が初めて指定された底面の射影で、その座標を制限する。この射影はコンパクトである。有限個の底面と先の座標制限を同時に課しても、有限個だけの座標制限ならそれらを生む底面を加えて有限交叉性を使える。有限個の底面が使う座標だけ確認して、残りの座標は各コンパクト集合から補えばよい。従ってコンパクト集合の可算積の中で、底面に対応する閉集合が有限交叉性を持つ。可算積のコンパクト性は対角部分列で示せる。全ての底面を満たす列を得て、元の減少列の共通部分が空であることに反する。従って有限加法的割当は空集合で上から連続であり、前測度になる。:ref[thm-meas-extension]で確率測度に延長でき、生成族での一致により一意である。
:::

:::definition[標準 Brown 運動]{#def-prob-brownian}
$t\ge0$ で定義され、$B_0=0$ を満たし、概確実に連続な経路をもつ過程を考える。互いに素な半開区間の増分が独立で、$0\le s<t$ に対し $B_t-B_s\sim N(0,t-s)$ であるとき、:term[標準 Brown 運動]{en="standard Brownian motion" yomi="ひょうじゅんぶらうんうんどう"} という。
:::

以下で経路を扱うときは、必要に応じて例外の零集合上を零経路に置き換えた連続版を用いる。

$C(s,t)=s\wedge t$ は半正定値である。実際、$s\wedge t=\int_0^\infty\mathbf1_{[0,s]}(u)\mathbf1_{[0,t]}(u)\,\dd u$ は内積である。この共分散と零平均の正規族では、増分の共分散は二区間の共通部分の長さである。区間が互いに素なら零であり、正規ベクトルでは無相関成分が独立である。例えば $B_1$ と $B_3$ の共分散は $1$、$B_3-B_1$ の分散は $2$ である。拡張定理だけからは経路の連続性は出ないため、次節で別途構成する。

### 共分散から独立性と分布を判定する

:::example[増分が重なると相関が残る]
$B_3-B_1$ と $B_4-B_2$ のそれぞれの分散は $2$ である。共通区間 $(2,3]$ が長さ $1$ であるため共分散は $1$ で、相関係数は $1/2$ となる。例えば両増分の差は $(B_2-B_1)-(B_4-B_3)$ であり、独立な二増分の差なので $N(0,2)$ である。元の二増分を独立と誤ると差の分散に $4$ を割り当てることになる。
:::

:::example[同じ各時刻の分布でも運動は異なる]
一つの $Z\sim N(0,1)$ に対し $X_t=\sqrt t Z$ とする。各 $t$ で $X_t\sim N(0,t)$ だが、共分散は $\sqrt{st}$ である。例えば $(X_1,X_4)$ の共分散は $2$、Brown 運動では $1$ である。$X_4-X_1=Z$ の分散は $1$ である一方、$B_4-B_1$ の分散は $3$ である。過程を指定するには各時刻の周辺法則だけでなく有限次元の整合した法則が必要である。
:::

### 増分が独立な正規過程を時刻変更で作る

:::proposition[単調な決定論的時計による Brown 運動の変更]
連続非減少な $a:[0,\infty)\to[0,\infty)$ で $a(0)=0$ とする。$X_t=B_{a(t)}$ は連続な零平均 Gauss 過程で、共分散は $a(s\wedge t)$、独立増分を持ち、$X_t-X_s$ の分散は $a(t)-a(s)$ である。
:::

:::proof
有限個の $a(t)$ における値なので Gauss 性を持つ。共分散は $a(s)\wedge a(t)=a(s\wedge t)$ である。時間区間が重ならなければ、単調性により対応する Brown 時刻の区間は内部で重ならない。縮退して幅零になる区間では増分が定数になる。従って独立性と分散の式が得られる。連続性は経路と $a$ の合成による。
:::

:::example[カレンダーの時間と分散の時計が異なる]
$a(t)=t^2$ とすると、時刻 $1$ から $2$ の増分は分散 $3$、時刻 $2$ から $3$ の増分は分散 $5$ である。実時間の幅はどちらも $1$ だが、分散が等しくないため定常増分を持たない。一方、$X_t$ の最初の時刻から固定正水準 $b$ に達する時刻は、Brown 運動の到達時刻 $\tau_b$ を逆時計で戻した $\sqrt{\tau_b}$ である。時計の変更は連続性も増分の独立性も保つが、所要時間の尺度を変える。
:::

### 有限次元分布から連続経路上の法則を決める

:::proposition[連続経路の法則の一意性]
$C([0,T])$ を一様距離の空間とする。そこに値を取る二過程が、稠密な可算時刻集合 $D$ 上の全有限次元分布で一致するなら、経路の Borel 法則が一致する。さらに、実数値過程の連続な版は $C([0,T])$ 値確率変数として可測に取れる。
:::

:::proof
任意の連続 $f,g$ の一様距離は $\sup_{t\in D}|f(t)-g(t)|$ に等しい。従って既知の連続関数 $g$ のまわりの閉球は、$D$ 上の座標で書いた可算個の条件の共通部分である。開球は半径を右端へ近づける閉球の可算和で作れる。$C([0,T])$ は、有限等間隔格子と有理数値を使う折れ線の可算集合によって可分である。実際、連続関数は格子を細かくすると補間誤差が一様に小さく、各頂点の値も有理数で近似できる。したがって開集合は可算基底の開球の可算和である。以上により Borel $\sigma$-加法族が有理時刻などの $D$ 上の座標で生成される。これらの座標の有限個が作る柱状集合は共通部分に閉じ、法則の一意性が従う。可測性は各座標が可測であることと同じ生成族を使う。連続性が確率 $1$ の可測集合上だけで成り立つときは、外側を零経路に補ってからこの議論を適用する。
:::

:::example[有限の観測で経路上の事象を段階的に近似する]
連続経路の最大値が $1$ を超える事象は $\{B_t>1\}$ を有理時刻上で可算和したものである。例えば $[0,1]$ で二進格子の最大値 $M_n$ を使えば、格子が入れ子なので $M_n$ は増加し、極限は連続性で全時刻の最大値になる。従って $\mathbb P(M>1)=\lim_n\mathbb P(M_n>1)$ である。格子にない時刻で $B_t>1$ となっても、連続性でその近くの格子点にも閾値より上の値がある。右連続性や連続性がない過程で、固定時刻ごとの情報だけを同じ方法で使うことはできない。
:::

## Brown 運動の構成（Lévy–Ciesielski の方法）

:::theorem[二進補間による構成]{#thm-prob-levy-ciesielski}
独立な標準正規列から、$[0,1]$ 上の標準 Brown 運動を一様収束する折れ線の極限として構成できる。
:::

:::proof
$B_0=0$、$B_1=Z_0$ とする。長さ $h=2^{-n}$ の二進区間の両端が既に与えられたとき、中点の値を両端の平均に $\sqrt h\,Z_{n,k}/2$ を足して定める。ここで各 $Z_{n,k}$ は既に使った変数と独立な標準正規である。親区間の増分 $\Delta$ が $N(0,h)$ なら、子二区間の増分は $\Delta/2+\sqrt h\,Z_{n,k}/2$ と $\Delta/2-\sqrt h\,Z_{n,k}/2$ である。それぞれ分散 $h/2$、互いの共分散は零である。異なる親区間での組も独立なので、帰納法により全ての二進格子で所望の独立増分を得る。

格子を線形補間した関数を $B^{(n)}$ とすると、$B^{(n+1)}-B^{(n)}$ は各区間で両端が零、中点の値が $\sqrt h\,Z_{n,k}/2$ の三角形である。従ってその上限ノルムは $2^{-n/2-1}\max_{k<2^n}|Z_{n,k}|$ である。正規の指数型評価と和の上界で、$\mathbb P(\max_k|Z_{n,k}|>n)\le2^{n+1}e^{-n^2/2}$ は総和可能である。Borel–Cantelli により上限ノルムの総和は概確実に有限で、折れ線が一様に連続関数へ収束する。

極限は二進点で既に構成した値と一致する。任意の時刻を二進点から近似すると、連続性と有界収束により有限次元特性関数が二進点での式の極限となる。共分散 $s\wedge t$ が連続なので Gauss 過程になり、増分の性質が従う。単位区間ごとに独立なコピーを取り、前区間の終点を足してつなげば全 $t\ge0$ でも構成できる。
:::

例えば $B_{1/2}=\tfrac12Z_0+\tfrac12Z_{0,0}$ であり、$B_1-B_{1/2}=\tfrac12Z_0-\tfrac12Z_{0,0}$ である。二つの増分は同じ $Z_0$ を含むが、正規ベクトルとして共分散が消えるので独立になる。

### 展開の係数と粗い格子での予測

:::example[四分点の構成で条件付き分散を読む]
$B_1=Z_0$、$B_{1/2}=(Z_0+Z_{0,0})/2$ から、左側の中点 $B_{1/4}$ は $B_{1/2}/2+Z_{1,0}/(2\sqrt2)$ である。従って $B_{1/2}$ と $B_1$ を既知とした条件付き分散は $1/8$ である。共分散を展開しても $\operatorname{Cov}(B_{1/4},B_1)=1/4$ となる。新しい係数は過去に使った係数に独立だが、新しい時刻の値自体は粗い格子の値を含む。
:::

:::example[線形補間より見えない波がある]
レベル $n$ の一つの区間の幅を $h=2^{-n}$ とする。中点の真値と線形補間との差は分散 $h/4$ の正規変数である。例えば $h=1/4$ なら差の標準偏差は $1/4$ なので、絶対差が $1/2$ を超える確率は $2(1-\Phi(2))$ となる。区間の中点まで観測するとこの不確かさは消えるが、さらに狭い区間では次の世代の独立係数が残っている。
:::

### Haar 関数を積分して折れ線を得る

:::proposition[Haar 基底による経路の共分散表示]
$\mathbf1_{(0,1)}$ と、各二進区間 $I_{n,k}$ の左半分に $2^{n/2}$、右半分に $-2^{n/2}$ を取る Haar 関数 $H_{n,k}$ を考える。異なる関数は $L^2(0,1)$ で直交し、各ノルムは $1$ である。$h_{n,k}(t)=\int_0^t H_{n,k}(s)\dd s$ とすれば
$$
s\wedge t=st+\sum_{n,k}h_{n,k}(s)h_{n,k}(t).
$$
:::

:::proof
各 $H_{n,k}$ は積分が零で、長さ $2^{-n}$ の台で絶対値が $2^{n/2}$ なのでノルムは $1$ である。異なる二進区間は内部が互いに素であるか、片方が他方の半分の中にある。後者では広い台の関数は狭い台の上で一定であり、狭い方の積分が零なので直交する。定数関数と深さ $0,\ldots,m-1$ の Haar 関数の個数は $1+\sum_{n=0}^{m-1}2^n=2^m$ である。これらは幅 $2^{-m}$ の格子で区分定数の空間に属し、次元と個数が等しく正規直交なのでその基底である。

$\mathbf1_{[0,t]}$ をこの区分定数空間へ直交射影する。完全な格子セルでは元の指示関数に一致し、端点を含む長さ高々 $2^{-m}$ の一セルだけで違う。従って $L^2$ 誤差は $2^{-m/2}$ 以下である。時刻 $s,t$ の指示関数の内積を有限格子への射影で近似し、その基底係数の積を足す。定数関数の係数が $s,t$、Haar 関数の係数が $h_{n,k}(s),h_{n,k}(t)$ である。$m\to\infty$ で内積は元の $s\wedge t$ に収束する。
:::

:::example[最初の二段の基底で雑音を積む]
$h_{0,0}$ の高さは $1/2$、左半分の $h_{1,0}$ の高さは $1/(2\sqrt2)$ である。$t=1/4$ では定数関数の積分が $1/4$、$h_{0,0}(1/4)=1/4$、$h_{1,0}(1/4)=1/(2\sqrt2)$ で、より細かい全項は二進点で零になる。従って係数の二乗和は $1/16+1/16+1/8=1/4$ であり、$B_{1/4}$ の分散と一致する。折れ線を一段ずつ足す手順は、正規係数とこれらの積分関数を対応させている。
:::

### 区間ごとに独立な Brown 橋を取り出す

:::proposition[線形補間からの残差の独立性]
決定論的な格子 $0=t_0<\cdots<t_m=T$ とし、格子上の $B_{t_j}$ を結ぶ折れ線を $L(t)$ とする。各区間の残差 $R_j(u)=B_{t_{j-1}+u}-L(t_{j-1}+u)$（$0\le u\le h_j=t_j-t_{j-1}$）は互いに独立であり、格子値全体とも独立である。$\beta_v=B_v-vB_1$（$0\le v\le1$）を :term[標準 Brown 橋]{en="standard Brownian bridge" yomi="ひょうじゅんぶらうんきょう"} という。区間 $j$ の残差は $\sqrt{h_j}\,\beta_{u/h_j}$ と同じ経路の法則を持つ。
:::

:::proof
$\Delta_j(u)=B_{t_{j-1}+u}-B_{t_{j-1}}$ と置けば $R_j(u)=\Delta_j(u)-(u/h_j)\Delta_j(h_j)$ である。異なる区間の全増分は独立増分性と有限座標の生成族で独立であり、それらの関数として残差も独立である。同じ区間では $\operatorname{Cov}(\Delta_j(u),\Delta_j(h_j))=u$ なので、残差と $\Delta_j(h_j)$ の共分散は $u-(u/h_j)h_j=0$ である。残差の任意の有限組と全格子増分は同時正規であるため、無相関性が独立性を与える。格子値は格子増分の有限和なので全格子値とも独立であり、有理時刻の生成族により経路へ拡張できる。残差の共分散は $u\wedge v-uv/h_j$ であり、$\sqrt{h_j}\beta_{u/h_j}$ の共分散と一致する。連続な Gauss 過程なので全経路の法則が一致する。
:::

:::example[二つの中点の条件付き誤差を計算する]
格子を $0,1,3$ とする。時刻 $1/2$ の残差の分散は $1/4$、時刻 $2$ の残差の分散は $2/4=1/2$ である。二つの残差は独立なので、その差の分散は $3/4$ である。例えば $B_1=2,B_3=0$ における条件付き平均は、直線補間により時刻 $1/2$ と $2$ でともに $1$ である。従って $B_2-B_{1/2}$ の条件付き分布は $N(0,3/4)$ である。二つの時刻の無条件の差の分散 $3/2$ より小さいのは、格子値のゆらぎを条件で固定したためである。
:::

## Kolmogorov の連続性定理

:::theorem[連続な版と Hölder 指数]{#thm-prob-kolmogorov-continuity}
実数値過程 $X_t$（$t\in[0,1]$）について、ある $p>0,\beta>0,C<\infty$ があり $\mathbb E|X_t-X_s|^p\le C|t-s|^{1+\beta}$ が全 $s,t$ で成り立つとする。このとき連続な版が存在し、各 $0<\alpha<\beta/p$ について、その経路は概確実に $\alpha$-Hölder 連続である。
:::

:::proof
二進格子の隣接差が $2^{-n\alpha}$ を超えるものが一つでもある確率は、和の上界と Markov により $C2^{-n(\beta-p\alpha)}$ 以下である。総和は有限なので、概確実に全二進レベルで隣接差を $K(\omega)2^{-n\alpha}$ で抑えられる。二進点 $s,t$ について $2^{-m-1}<|t-s|\le2^{-m}$ とする。それぞれを下側のレベル $m$ に丸めると、丸めた点の差は格子一つ分以下である。また細かいレベルから粗いレベルへ一段戻るたび、隣接差を高々一回足せばよい。その和は幾何級数で $C_\alpha K(\omega)2^{-m\alpha}$ 以下である。従って二進点上で Hölder 評価が一様に成り立ち、全時刻に一意に連続拡張できる。固定した $t$ で二進点 $t_n\to t$ を選ぶと、元の仮定により $X_{t_n}\to X_t$ は確率収束する。拡張値には概収束するので両者は概確実に等しい。有理な指数から小さい実指数への包含を使えば、許される全指数の主張を一つの確率一の集合上にまとめられる。
:::

例えば Brown 増分は $\mathbb E|B_t-B_s|^{2m}=(2m-1)!!|t-s|^m$ を満たす。この正規積率は部分積分で偶数次を二次ずつ下げれば得られる。$m\ge2$ について $\beta=m-1,p=2m$ なので、任意の $\alpha<1/2$ を選べる。区間を可算個に分ければ任意のコンパクト時間区間で成り立つ。

### 各時刻で一致する版と全時刻で一致する版

:::definition[修正と区別不能性]
二過程 $X,Y$ が各固定 $t$ に対し $\mathbb P(X_t=Y_t)=1$ を満たすとき、一方を他方の修正という。一つの確率 $1$ の事象上で全時刻の値が一致するとき、両過程は区別不能であるという。
:::

:::proposition[連続な修正の一意性]
$[0,1]$ 上で概確実に連続な二過程が互いに修正なら、区別不能である。
:::

:::proof
各有理点での一致事象と両経路の連続性の事象を可算個だけ交わす。得られた確率 $1$ の事象上では、任意の時刻を有理点列で近似して連続性を使うと値が一致する。この確率 $1$ の事象は時刻に依存しない。
:::

:::example[時刻ごとに零でも経路に一つの突起がある]
一様な $U\in(0,1)$ を使い $X_t=\mathbf1_{\{U=t\}}$ とする。固定した全ての $s,t$ で増分は概確実に零であり、連続性定理の積率条件を満たす。零過程は連続な修正であるが、ほぼ全ての元の経路は時刻 $U$ に高さ $1$ の突起を持つため連続でない。従って定理が保証する連続性は構成した修正についてである。
:::

### Hölder 定数の積率を確かめる

:::proposition[増分評価から Hölder 半ノルムの積率を得る]
:ref[thm-prob-kolmogorov-continuity] の仮定で $p\ge1$ とする。任意の $0<\alpha<\beta/p$ について、連続な版 $\tilde X$ の
$$
[\tilde X]_\alpha=\sup_{s\ne t}\frac{|\tilde X_t-\tilde X_s|}{|t-s|^\alpha}
$$
は $L^p$ に属する。
:::

:::proof
二進格子の最大隣接差を $D_n=\max_{j<2^n}|X_{(j+1)2^{-n}}-X_{j2^{-n}}|$ とする。最大の $p$ 乗は各差の $p$ 乗の和以下だから $\mathbb ED_n^p\le C2^{-n\beta}$ である。従って Minkowski により
$$
\left\|\sum_{n=0}^m2^{n\alpha}D_n\right\|_p
\le C^{1/p}\sum_{n\ge0}2^{-n(\beta/p-\alpha)}<\infty.
$$
非負の和に単調収束を使うと、無限和 $K$ も $L^p$ に属する。全レベルで $D_n\le K2^{-n\alpha}$ である。連続性定理の証明の丸めと幾何級数の評価で $[\tilde X]_\alpha\le C_\alpha K$ を得る。半ノルムの上限は連続性により異なる有理時刻の組から取れるので可測である。
:::

:::example[Brown 経路の Hölder 半ノルムの四次積率]
Brown 運動では $\mathbb E|B_t-B_s|^4=3|t-s|^2$ なので $p=4,\beta=1$ である。従って例えば $\alpha=1/8$ の半ノルムは四次可積分である。同じ四次積率の評価だけでは $\alpha=1/3$ を選べない。そこで六次では $15|t-s|^3$ で比は $\beta/p=1/3$ となるが、まだ端点は含まれない。八次では $105|t-s|^4$ となり比は $3/8$、ここで $\alpha=1/3$ の半ノルムが八次可積分であると分かる。一つの積率評価から得られる指数と、全ての正規積率を使って得られる指数を区別する。
:::

:::example[増分評価が時間の一次では連続な版を保証しない]
一様な時刻 $U\in(0,1)$ で一度だけ跳ぶ $X_t=\mathbf1_{\{U\le t\}}$ を考える。$s<t$ で $|X_t-X_s|$ は $s<U\le t$ の指示関数であるため、任意の $p>0$ で $\mathbb E|X_t-X_s|^p=t-s$ である。例えば $s=1/4,t=3/4$ ではこの積率は $1/2$ である。一方、連続な版がもしあれば、可算な全有理時刻で同時に元の過程と一致する確率 $1$ の集合がある。その集合上で $U$ を左から近づける有理時刻では値は零、右から近づける有理時刻では値は一であり、連続性に反する。この例では積率の評価に時間の一次より高い冪がないことが、連続性定理を適用できない箇所である。
:::

## 標本路の Hölder 連続性と非微分可能性

:::proposition[Brown 経路の粗さ]{#prop-prob-brownian-roughness}
概確実に、Brown 運動の経路はどの非自明な時間区間でも $1/2$-Hölder 連続でなく、有限な右微分を持つ時刻は存在しない。
:::

:::proof
固定した有理端点の区間 $I=[a,b]$ を $2^n$ 等分し、区間幅を $h$ とする。$1/2$-Hölder 定数が $K$ 以下なら全ての差を $\sqrt h$ で割った絶対値は $K$ 以下である。これらは独立標準正規の絶対値だから、その確率は $\mathbb P(|Z|\le K)^{2^n}\to0$ である。有理端点と整数 $K$ について可算和を取ると前半が従う。

右微分がある時刻 $t\in[0,T]$ では、ある整数 $M$ があり、十分小さい $u\ge0$ では $|B_{t+u}-B_t|\le Mu$ である。格子幅 $h=2^{-n}$ の $t$ 以後の最初の格子点から始まる三本の連続区間を取る。それらの端点はすべて $t$ から $4h$ 以内なので、各増分は絶対値が $8Mh$ 以下である。固定した開始点での三本は独立であり、正規密度の上界から一つがこの条件を満たす確率は $C_M\sqrt h$ 以下である。候補の開始点は $O_T(1/h)$ 個なので、ある組がこの条件を満たす確率は $O_{M,T}(\sqrt h)$ である。$n$ について総和可能なので Borel–Cantelli により、無限に細かい格子でそのような組があることはない。整数 $M,T$ で可算和を取ると主張を得る。
:::

任意の固定時刻で差分商が正規分布になり、分散が $1/h$ へ増えることからも、微分が難しいと分かる。ただし固定時刻ごとの零確率を非可算個足すことはできない。格子上の三連続増分を同時に抑えたのは、例外になり得る時刻も含めて扱うためである。

### 平滑なドリフトを加えても粗さは残る

:::example[二進格子での Hölder 定数]
区間 $[0,1]$ の $m$ 等分で、$|\Delta B|/\sqrt{1/m}\le1$ が全区間で成り立つ確率は $(2\Phi(1)-1)^m$ である。例えば $m=4$ では $(2\Phi(1)-1)^4$ である。単一の格子の全増分が閾値内にあっても、同じ定数で全ての分割を満たす確率は零である。格子点を増やすと、大きい標準化増分を避ける条件が増えるためである。
:::

:::example[線形ドリフトは差分商の発散を取り除かない]
$X_t=B_t+3t$ では、右差分商は Brown 運動の右差分商に $3$ を足したものである。もし $X$ に有限な右微分があれば $B$ にも有限な右微分が生じるので、そのような時刻は概確実に存在しない。また線形成分 $3t$ は各コンパクト区間で $1/2$-Hölder 連続である。従って $X$ も $1/2$-Hölder 連続なら差の $B$ もそうなり、粗さの命題と矛盾する。
:::

### 対数を許した一様な連続性

:::proposition[二進区間からの Brown 運動の連続度上界]
$[0,1]$ の標準 Brown 運動の経路は、ある有限なランダム定数 $C$ により、$0<h\le1/2$ で
$$
\sup_{|s-t|\le h}|B_t-B_s|
\le C\sqrt{h\log(1/h)}
$$
を概確実に満たす。
:::

:::proof
レベル $n\ge1$ の格子で、いずれかの隣接差が $A\sqrt n\,2^{-n/2}$ を超える確率は、正規尾と和の上界により $2^{n+1}e^{-A^2n/2}$ 以下である。$A^2/2>\log2$ を選べば $n$ で総和可能である。従って Borel–Cantelli により、全レベルの隣接差が $K\sqrt n\,2^{-n/2}$ 以下となる有限の $K$ がほとんどすべての経路にある。$2^{-m-1}<h\le2^{-m}$ とし、時刻を二進格子に丸める。両側で細かい格子からレベル $m$ へ戻る誤差と、レベル $m$ での高々一つの隣接差を足すと、$C'K\sum_{n\ge m}\sqrt n\,2^{-n/2}$ 以下になる。連続性で二進点から全時刻へ延長できる。この級数は $C''K\sqrt m\,2^{-m/2}$ 以下である。実際 $n=m+j$ と置けば $\sqrt{m+j}\le\sqrt m\sqrt{1+j}$ で、$\sum_{j\ge0}\sqrt{1+j}\,2^{-j/2}$ は有限である。最後に $2^{-m}<2h$、$m\le\log(1/h)/\log2$ を用いる。
:::

:::example[格子を細かくしたときに同時に保証できる幅]
レベル $n=16$ の一つの隣接差の標準偏差は $2^{-8}$ である。全 $2^{16}$ 個を $A\sqrt{16}$ 標準偏差以内に収めることを考えると、$A=2$ では閾値は $8\cdot2^{-8}=1/32$ であり、少なくとも一つが超える確率は $2^{17}e^{-32}$ 以下である。単一の増分での標準偏差 $2^{-8}$ にそのまま一つの確率を当てはめるだけでは、格子上の最大の制御にはならない。レベルに応じて $\sqrt n$ を加えたことが、実時間では対数因子に対応する。
:::

:::theorem[Lévy の一様連続度]{#thm-prob-levy-modulus}
$[0,1]$ 上の標準 Brown 運動に対し $\omega_B(h)=\sup_{|s-t|\le h}|B_t-B_s|$ と置くと、概確実に
$$
\lim_{h\downarrow0}\frac{\omega_B(h)}{\sqrt{2h\log(1/h)}}=1
$$
である。
:::

:::proof
$q>1$、$h_n=q^{-n}$ とし、$a(h)=\sqrt{2h\log(1/h)}$ と置く。下界には $[0,1]$ 内にある長さ $h_n$ の連続した $\lfloor1/h_n\rfloor$ 個の互いに素な区間を取る。増分を $\sqrt{h_n}$ で割ると独立標準正規である。$0<\eps<1$ とし、$z_n=(1-\eps)\sqrt{2\log(1/h_n)}$ と置く。標準正規の密度を $[z_n,z_n+1/z_n]$ 上で積分すると、十分大きい $n$ で $\mathbb P(Z>z_n)\ge c z_n^{-1}e^{-z_n^2/2}$ となる。よって全増分が $(1-\eps)a(h_n)$ 以下に収まる確率は
$$
\exp\left(-c'\frac{h_n^{(1-\eps)^2-1}}{\sqrt{\log(1/h_n)}}\right)
$$
以下であり、$n$ で総和可能である。Borel–Cantelli により格子幅 $h_n$ での下極限は $1-\eps$ 以上となる。

上界では $0<\delta<1$ とし、時刻を幅 $\delta h_n$ の格子の下側へ丸める。元の二時刻の距離が $h_n$ 以下であれば、丸めた二点の距離は $(1+\delta)h_n$ 以下である。そのような格子点の組は $O_\delta(1/h_n)$ 個である。正規尾の上界から、丸めた差の絶対値の一つでも $(1+\eps)a(h_n)$ を超える確率は $O_\delta(h_n^{(1+\eps)^2/(1+\delta)-1})$ である。$\delta$ を十分小さく選べば指数は正であり、Borel–Cantelli が使える。二つの丸めの誤差は、直前の連続度上界により $2C\sqrt{\delta h_n\log(1/(\delta h_n))}$ 以下である。従って $a(h_n)$ で割った上極限は $1+\eps+\sqrt{2}C\sqrt\delta$ 以下となる。可算な $\delta\downarrow0$、$\eps\downarrow0$ を用いると、格子幅 $h_n$ での極限が $1$ となる。

一般の $h$ について $h_{n+1}\le h\le h_n$ を選び、$\omega_B(h_{n+1})\le\omega_B(h)\le\omega_B(h_n)$ を使う。$a(h)$ は十分小さい $h$ で増加し、$a(h_n)/a(h_{n+1})\to\sqrt q$ なので、一般の幅での下極限は $q^{-1/2}$ 以上、上極限は $q^{1/2}$ 以下となる。可算な $q\downarrow1$ について同時にこの評価を使えば結論を得る。
:::

## Markov 性と Blumenthal の 0-1 法則

$\mathcal F_t=\sigma(B_s:0\le s\le t)$ を自然な情報とする。有理時刻の値と $B_t$ から連続性で全ての過去の値が分かる。独立増分を有限座標の生成族から拡張すると $(B_{t+s}-B_t)_{s\ge0}$ は $\mathcal F_t$ と独立で標準 Brown 運動である。$\mathcal F_t^+=\bigcap_{u>t}\mathcal F_u$ としても成立する。実際、$A\in\mathcal F_t^+$ に対し $t_k\downarrow t$ から始めた増分と $A$ は独立であり、有界連続試験関数の積分で $t_k\to t$ とすると希望する独立性が得られる。零事象を加えた完備化でも積分等式は変わらない。

:::proposition[Blumenthal の 0-1 法則]{#prop-prob-blumenthal}
Brown 運動の時刻零の芽 $\sigma$-加法族 $\mathcal F_0^+$ の事象の確率は零または一である。
:::

:::proof
時刻 $t=0$ の直後の全増分は上の議論で $\mathcal F_0^+$ と独立である。$B_0=0$ なので全増分が経路全体を生成する。従って $\mathcal F_0^+$ の任意の事象は自分自身と独立であり、確率は零または一である。
:::

例えば $B_t>0$ となる時刻が任意に零に近く存在する事象は芽に属する。各 $n$ で $B_{1/n}>0$ の確率は $1/2$ なので、上極限の事象の確率は少なくとも $1/2$ である。零一法則により確率は $1$ になる。負の値も対称性から同じであり、零の直後に片側だけに留まることはない。

### 拡大と反転による新しい Brown 運動

:::proposition[Brown 運動の拡大・時間反転]{#prop-prob-brownian-scaling-reversal}
$c>0$ に対し $(c^{-1/2}B_{ct})_{t\ge0}$ は標準 Brown 運動である。また $T>0$ で $(B_T-B_{T-t})_{0\le t\le T}$ は $[0,T]$ 上の標準 Brown 運動と同じ法則を持つ。
:::

:::proof
どちらも零から始まる連続な正規過程である。拡大では長さ $c(t-s)$ の増分を $\sqrt c$ で割り、分散は $t-s$ になる。反転の $[s,t]$ の増分は元の $[T-t,T-s]$ の増分で、同じ分散を持つ。いずれの変換も互いに素な区間を互いに素な元の区間へ写すので独立性が保たれる。
:::

:::example[先に観測した時刻からの予測]
$B_2=x$ なら独立な増分により $B_5\mid\mathcal F_2$ の法則は $N(x,3)$ である。従ってたとえば $x=1$ で $B_5>1+\sqrt3$ となる条件付き確率は $1-\Phi(1)$ である。条件を $B_2$ の値で表す式は、実際に $\{B_2=x\}$ に正の確率があることを要求しない。過去全体で条件付けても増分が独立であるため、同じ核を使える。
:::

### Brown 運動の遷移作用素と指数マルチンゲール

:::proposition[熱核と生成作用素]
標準 Brown 運動に対し、$P_tf(x)=\mathbb E f(x+B_t)$ は $P_{s+t}=P_sP_t$ を満たす。$f$ が二回連続微分可能で $f,f',f''$ が有界なら、固定 $x$ で
$$
\lim_{t\downarrow0}\frac{P_tf(x)-f(x)}t=\tfrac12 f''(x)
$$
である。
:::

:::proof
独立増分により $B_{s+t}$ は独立な $B_s,B_t'$ の和と同分布なので、二度の期待値を取ると半群性になる。$B_t$ を $\sqrt t Z$ と書く。Taylor の積分形により
$$
f(x+\sqrt t Z)-f(x)-\sqrt t Z f'(x)
=t Z^2\int_0^1(1-r)f''(x+r\sqrt t Z)\,\dd r.
$$
一次項の期待値は零であり、右辺を $t$ で割ると $\|f''\|_\infty Z^2/2$ で支配できる。連続性で $t\downarrow0$ の極限は $Z^2 f''(x)/2$ であり、その期待値が $f''(x)/2$ となる。
:::

:::proposition[Brown 運動の指数マルチンゲール]
$\theta\in\R$ に対し $M_t=\exp(\theta B_t-\theta^2t/2)$ は Brown 運動の右連続自然フィルトレーションに関して非負マルチンゲールである。
:::

:::proof
各時刻の期待値は $1$ である。$s<t$ で $M_t$ を $M_s$ と $\exp(\theta(B_t-B_s)-\theta^2(t-s)/2)$ の積に分ける。第二の因子は $\mathcal F_s^+$ と独立で平均が $1$ だから条件付き期待値が $M_s$ になる。
:::

:::example[周波数ごとに熱核の減衰を読む]
$f(x)=\cos(2x)$ なら $P_tf(x)=e^{-2t}\cos(2x)$ である。実際、増分の特性関数を周波数 $2$ で評価すれば実部からこの値を得る。従って時刻零での微分は $-2\cos(2x)=f''(x)/2$ である。周波数 $1$ の余弦なら係数は $e^{-t/2}$ となるので、高い周波数の方が早く減衰する。
:::

### Brown 運動の有界停止

:::proposition[連続時間の有界停止]{#prop-prob-brownian-bounded-stopping}
$B_t$、$B_t^2-t$、$\exp(\theta B_t-\theta^2t/2)$ は Brown 運動の右連続自然フィルトレーションに関するマルチンゲールである。これらのいずれかを $M_t$ と書く。有界な停止時刻 $\sigma\le\tau$ について $\mathbb E[M_\tau\mid\mathcal F_\sigma^+]=M_\sigma$ が成り立つ。ここで連続時間の停止時刻は全 $t\ge0$ で $\{\tau\le t\}\in\mathcal F_t^+$ を満たす写像であり、$\mathcal F_\sigma^+$ は全 $t$ で $A\cap\{\sigma\le t\}\in\mathcal F_t^+$ となる事象 $A$ の族である。
:::

:::proof
独立増分の平均は零なので $B_t$ はマルチンゲールである。また $\mathbb E[B_t^2\mid\mathcal F_s^+]=B_s^2+(t-s)$ から $B_t^2-t$ もマルチンゲールとなる。指数の場合は直前の命題で示した。

$\sigma,\tau\le T$ とする。各停止時刻を上側の二進格子点に丸めた $\sigma_m,\tau_m$ は $\sigma_m\le\tau_m\le T+1$ を満たす。例えば $\{\sigma_m\le j2^{-m}\}=\{\sigma<j2^{-m}\}$ だから格子上の停止時刻である。また $A\in\mathcal F_\sigma^+$ なら $A\cap\{\sigma<j2^{-m}\}$ は $A\cap\{\sigma\le s\}$ を $s<j2^{-m}$ の可算列に沿って和にしたものなので、格子上の停止情報にも属する。従って :ref[thm-prob-optional-stopping] で $\int_A M_{\tau_m}=\int_A M_{\sigma_m}$ となる。

有限時間区間の入れ子の格子に :ref[thm-prob-doob-max] を適用する。$|B_t|$ と $e^{|\theta||B_t|}$ は凸関数による非負劣マルチンゲールであり、正規変数の指数積率から両方の終端の二次積率が有限である。格子の最大値を連続経路の最大値に移せば、両方の最大値は $L^2$ に入る。従って三種類とも格子上の停止値は一つの可積分変数で支配できる。経路の連続性と優収束により、積分等式は極限の停止値にも成り立つ。$M_\sigma$ の停止情報に関する可測性は、各 $t$ で $M_{\sigma\wedge t}$ を $[0,t]$ 内の格子上で近似すれば分かる。これで条件付き等式が証明できた。
:::

### 時刻を右から近づけても新しい情報は増えない

:::proposition[完備化された Brown フィルトレーションの右連続性]
$\mathcal F_t=\sigma(B_s:s\le t)$ とし、全経路での零集合を各族に加える完備化を $\overline{\mathcal F_t}$ とする。このとき $\bigcap_{u>t}\overline{\mathcal F_u}=\overline{\mathcal F_t}$ である。
:::

:::proof
包含 $\overline{\mathcal F_t}\subset\bigcap_{u>t}\overline{\mathcal F_u}$ は単調性による。逆に左の交わりの事象 $A$ を取り、$Z=\mathbb E[\mathbf1_A\mid\overline{\mathcal F_t}]$ と置く。未来の増分の族を $\mathcal H=\sigma(B_{t+s}-B_t:s\ge0)$ とする。固定時刻からの独立増分を上から極限に移す証明により、$\mathcal H$ は $\bigcap_{u>t}\overline{\mathcal F_u}$ と独立である。従って $C\in\overline{\mathcal F_t},D\in\mathcal H$ に対し
$$
\mathbb E[\mathbf1_A\mathbf1_C\mathbf1_D]
=\mathbb E[\mathbf1_A\mathbf1_C]\mathbb P(D)
=\mathbb E[Z\mathbf1_C]\mathbb P(D)
=\mathbb E[Z\mathbf1_C\mathbf1_D].
$$
全経路の族は $\overline{\mathcal F_t}$ と $\mathcal H$ の合成で生成される。$t$ 以後の値は $B_t$ と未来の増分から読めるからである。ゆえに $\pi$–$\lambda$ 定理で $\mathbf1_A$ と $Z$ の全経路の事象上の積分が一致する。両方が全経路の完備族で可測なので $\mathbf1_A=Z$ 概確実であり、完備化により $A\in\overline{\mathcal F_t}$ となる。
:::

:::example[一次の未来の符号は時刻 $t$ の情報に含まれない]
固定時刻 $t$ と $\delta>0$ で事象 $D=\{B_{t+\delta}>B_t\}$ を取る。独立増分性により $\mathbb P(D\mid\overline{\mathcal F_t})=1/2$ である。もし $D$ が任意の $u>t$ で観測できるなら、右連続性により $\mathbf1_D$ は時刻 $t$ の情報で可測となり、その条件付き期待値は自分自身になる。すると $0,1$ の値しか取らない指示関数が $1/2$ に等しくなり矛盾する。近い未来を任意に細かい時間で観測できることは、固定された正の $\delta$ での増分を今知ることとは異なる。
:::

## 強 Markov 性と鏡像原理

:::theorem[Brown 運動の強 Markov 性]{#thm-prob-brownian-strong-markov}
自然な右連続フィルトレーションの概確実に有限な停止時刻 $\tau$ に対し、$(B_{\tau+s}-B_\tau)_{s\ge0}$ は $\mathcal F_\tau^+$ と独立な標準 Brown 運動である。$\tau=\infty$ を許す場合も、任意の $A\in\mathcal F_\tau^+$、有限個の $s_j\ge0$、有界 Borel 関数 $g$ について
$$
\int_{A\cap\{\tau<\infty\}}g\bigl((B_{\tau+s_j}-B_\tau)_j\bigr)\,\dd\mathbb P
=\mathbb P(A\cap\{\tau<\infty\})\,\mathbb E g((B_{s_j})_j)
$$
が成立する。
:::

:::proof
$\tau_n=2^{-n}(\lfloor2^n\tau\rfloor+1)$ とし、無限のときは無限のままとする。$\tau_n$ は上から近似する停止時刻である。$A\in\mathcal F_\tau^+$ なら $A\cap\{\tau_n=t\}\in\mathcal F_t^+$ である。そこで $\tau_n=t$ の各格子点上で決定論的時刻の独立増分を使い、$t$ について可算和を取ると、$\{\tau<\infty\}$ 上の有限次元増分に対する積分等式が得られる。連続経路で $B_{\tau_n+s}-B_{\tau_n}\to B_{\tau+s}-B_\tau$ であり、有界連続試験関数には有界収束が使える。各有限次元分布から柱状集合を拡張し、連続経路全体に対する主張を得る。
:::

:::corollary[鏡像原理]{#cor-prob-reflection}
$a,t>0$、$M_t=\sup_{0\le s\le t}B_s$ とする。$b<a$ なら
$$
\mathbb P(M_t\ge a,\,B_t\le b)=\mathbb P(B_t\ge2a-b),
\qquad \mathbb P(M_t\ge a)=2\mathbb P(B_t\ge a).
$$
:::

:::proof
$\tau_a=\inf\{s:B_s=a\}$ は停止時刻であり、$\{M_t\ge a\}=\{\tau_a\le t\}$ である。$\tau_a$ 以後の増分を負に変えても、強 Markov 性と対称性により経路の法則は変わらない。停止時刻と停止前の経路はこの変換で固定され、停止後の独立な Brown 運動だけが反転する。従って $\{\tau_a\le t,B_t\le b\}$ は $\{\tau_a\le t,B_t\ge2a-b\}$ と同確率である。後者の $B_t$ の条件は連続性で自動的に到達を含む。$b\uparrow a$ として $B_t=a$ の確率が零であることを使い、残る $B_t\ge a$ の確率を足せば二つ目の式になる。
:::

例えば $M_1$ の法則は $|Z|$（$Z$ は標準正規）であり、$\mathbb E M_1=\sqrt{2/\pi}$ である。終点 $B_1$ が零付近でも、その前に大きな正の値を取った可能性があるため、最大値と終点は別の分布をもつ。

### 最大値と終点の同時密度

:::proposition[鏡像原理による同時密度]
$t>0$、$p_t(x)=e^{-x^2/(2t)}/\sqrt{2\pi t}$ とする。$(M_t,B_t)$ の同時密度は $m>\max(0,x)$ 上で
$$
\frac{2(2m-x)}{t}p_t(2m-x)
$$
であり、その外で零である。
:::

:::proof
固定 $m>0$ で $x<m$ なら、鏡像原理の終点分布を $x$ で微分して $\mathbb P(M_t\ge m,B_t\in\dd x)=p_t(2m-x)\dd x$ を得る。従って $\mathbb P(M_t<m,B_t\in\dd x)=(p_t(x)-p_t(2m-x))\dd x$ である。$x\ge m$ の部分は零である。$m$ を $\max(0,x)$ から増やすと、式は下端で零であり連続微分可能である。$m$ で微分した式は非負で、$m\to\infty$ まで積分すると周辺密度 $p_t(x)$ になる。従って境界に質量は残らず、長方形での積分を通じて同時密度を得る。
:::

:::example[障壁に届かずに終点が零付近になる確率密度]
$t=1$、障壁 $m=1$ なら、終点 $x=0$ での生存密度は $p_1(0)-p_1(2)=p_1(0)(1-e^{-2})$ である。従って $|B_1|\le\eps$ の下で $M_1<1$ である確率は、$\eps\downarrow0$ で $1-e^{-2}$ へ向かう。終点の密度が正なので、この比は連続な条件付き確率としても読める。
:::

### 最大値と終点を一緒に積分する

:::example[最大値から終点までの落差]
$M_t-B_t$ の法則は $\sup_{0\le u\le t}(B_{t-u}-B_t)$ と等しい。:ref[prop-prob-brownian-scaling-reversal] と符号対称性を使えば、この過程は $[0,t]$ の Brown 運動と同分布であり、最大の法則は $|N(0,t)|$ である。例えば $t=4$ で $M_t-B_t>2$ となる確率は $2(1-\Phi(1))$ である。$M_t$ と $M_t-B_t$ は周辺法則が等しくても、$B_t$ に対する関係が異なる。最大が同じ値でも、終点がその値に近い経路と離れた経路がある。
:::

:::example[終点で条件付けた障壁越え]
$t>0$、$a>\max(0,x)$ とする。鏡像原理の密度から
$$
\mathbb P(M_t\ge a\mid B_t=x)
=\frac{p_t(2a-x)}{p_t(x)}
=\exp(-2a(a-x)/t)
$$
である。$x\ge a$ なら経路の連続性からこの確率は $1$ である。例えば $t=2,a=2$ で $x=1$ なら $e^{-2}$、$x=-1$ なら $e^{-6}$ となる。終点が障壁より低いという情報だけでも、その具体的な距離によって途中で越えた確率は大きく変わる。ここでの条件付き確率は点 $B_t=x$ を正の確率の事象として割り算したものではなく、両密度の連続な比から選んだ核である。
:::

## 到達時刻の分布と逆正弦法則

鏡像原理により $\mathbb P(\tau_a\le t)=2(1-\Phi(a/\sqrt t))$ である。$t\to\infty$ では $1$ に近づくので $\tau_a$ は有限であり、微分すると
$$
f_{\tau_a}(t)=\frac{a}{\sqrt{2\pi}t^{3/2}}\exp(-a^2/(2t)),\qquad t>0.
$$
$t\to\infty$ で $t f_{\tau_a}(t)$ は正の定数倍の $t^{-1/2}$ に漸近するので、$\mathbb E\tau_a$ は無限大である。また式から $\tau_a\stackrel d=a^2\tau_1$ となる。

:::proposition[Brown 運動の零点集合]
概確実に、Brown 運動の零点集合は閉じて非有界であり、孤立点を持たない。また Lebesgue 測度は零である。
:::

:::proof
連続性から零点集合は閉じている。任意の整数時刻 $n$ で $B_n$ を条件とすると、未来の運動は $B_n$ から始まる。片側到達時刻の分布と符号対称性により、そこから零に達する時刻は有限である。全 $n$ に対して同時に成立するので零点集合は非有界である。

Blumenthal の法則の応用で見たように、零から始まる Brown 運動は任意に小さい正時刻で正負両方の値を取る。連続性により、正の零点も任意に時刻零へ近づく。各正の有理数 $r$ に対して $\sigma_r=\inf\{t\ge r:B_t=0\}$ と置く。これは有限な停止時刻であり、強 Markov 性により $\sigma_r$ の直後にも零点が任意に近く存在する。この性質は全有理 $r$ で同時に成り立つ。孤立した正時刻の零点があれば、その少し前の有理 $r$ を選ぶと、その零点は $\sigma_r$ に等しい。すると直後にも零点があることと矛盾する。

最後に決定時刻 $s>0$ では $B_s$ が密度を持ち $\mathbb P(B_s=0)=0$ である。Tonelli により各有限区間内の零点の Lebesgue 測度の期待値は零であり、測度自体も概確実に零になる。区間を整数端点まで広げれば全時間で成立する。
:::

:::theorem[最終零点の逆正弦法則]{#thm-prob-arcsine}
$G=\sup\{s\le1:B_s=0\}$ とすると、$0<t<1$ で $\mathbb P(G\le t)=(2/\pi)\arcsin\sqrt t$ である。密度は $1/(\pi\sqrt{t(1-t)})$ である。
:::

:::proof
$\mathcal F_t$ に関して条件付ける。$B_t=x\ne0$ のとき $G\le t$ であることは、独立な未来の増分が残り時間 $1-t$ までに $-x$ に達しないことと同値である。鏡像原理と対称性によりその確率は $\mathbb P(\sqrt{1-t}|Z|<|x|)$ である。$B_t$ は $\sqrt t Z_1$ と同分布なので、求める値は独立標準正規の $Z_1,Z_2$ に対する $\mathbb P(\sqrt{1-t}|Z_2|<\sqrt t|Z_1|)$ である。同時密度が半径だけに依存するため、極座標の角度は一様である。第一象限に限ると許される角は $0$ から $\arctan\sqrt{t/(1-t)}$ までで、全角の幅は $\pi/2$ である。この角は $\arcsin\sqrt t$ に等しい。微分して密度を得る。
:::

:::corollary[最大時刻の逆正弦法則]{#cor-prob-arcsine-maximum-time}
$[0,1]$ 上で Brown 運動が最大値を取る時刻は概確実にただ一つである。その分布関数は $0<t<1$ で $(2/\pi)\arcsin\sqrt t$ となる。
:::

:::proof
固定した $t$ に対し $M_t-B_t$ は逆向きの増分 $\{B_{t-u}-B_t:0\le u\le t\}$ の最大値である。時間反転と符号対称性、鏡像原理により $\sqrt t|Z|$ と同分布である。時刻 $t$ 以後の最大増分は独立な $\sqrt{1-t}|Z'|$ と同分布である。二つの分布に原子がないので等号は零確率である。最大が時刻 $t$ 以前に取られる確率は前者が後者より大きい確率であり、:ref[thm-prob-arcsine] と同じ角度計算になる。最大時刻が二つ以上あればその間に有理 $t$ を挟めて、過去と未来の最大値が同じになる。どの有理 $t$ でも等号は零確率だから、最大時刻は概確実に一意である。
:::

### 正の半直線の占有時間

最終零点を知っても、それ以前に正の半直線で過ごした時間は分からない。それでも、占有時間を別の方法で計算すると同じ分布が現れる。

:::proposition[占有時間の逆正弦法則]{#prop-prob-arcsine-occupation}
$A_t=\int_0^t\mathbf1_{\{B_s>0\}}\dd s$ とする。$A_1$ の分布関数は $0<u<1$ で $(2/\pi)\arcsin\sqrt u$ である。
:::

:::proof
$\mathbb E_x$ は $B_0=x$ から始めたときの期待値とし、$q,r>0$ について $u(x)=\int_0^\infty e^{-qt}\mathbb E_x e^{-rA_t}\dd t$ と置く。時刻 $t$ を固定し、$s$ から $t$ までの占有時間の指数を $s$ について積分すると
$$
e^{-rA_t}
=1-r\int_0^t\mathbf1_{\{B_s>0\}}\,e^{-r\int_s^t\mathbf1_{\{B_v>0\}}\dd v}\dd s
$$
となる。実際、右辺の積分の被積分関数は、指数を $s$ で微分したものを $r$ で割った値である。Markov 性により未来の指数を $B_s$ で条件付け、非負積分の順番を交換する。すると $u=1/q-rR_q(\mathbf1_{(0,\infty)}u)$ であり、ここで
$$
(R_q f)(x)=\int_0^\infty e^{-qs}\mathbb E_x f(B_s)\,\dd s
$$
である。

$R_q$ は核 $K_q(z)=e^{-\sqrt{2q}|z|}/\sqrt{2q}$ との畳み込みである。これを確認するため、熱核の Fourier 変換 $e^{-st^2/2}$ を $s$ で積分すると $(q+t^2/2)^{-1}$ になる。指数核 $K_q$ も左右の半直線で指数を直接積分すると同じ変換をもち、有限測度の反転の一意性を使える。$K_q$ は絶対連続で導関数が可積分なので、任意の有界 $f$ に対し $K_q*f$ は連続微分可能である。実際、差分商の収束と導関数の連続性は、$K_q'$ の $L^1$ における平行移動の連続性から従う。従って $u$ は $C^1$ である。また $f=\mathbf1_{(0,\infty)}u$ は零以外で連続である。指数核の積分を $y<x$ と $y>x$ に分け、それぞれ二回微分すると、零以外で $(R_q f)''=2qR_q f-2f$ となる。この計算で最初の微分の境界項は打ち消し合い、二回目の微分では合計 $-2f$ を生む。

従って $u''/2=(q+r\mathbf1_{\{x>0\}})u-1$ である。$0\le u\le1/q$ から無限遠で増える指数項は除かれるので、負の側では $u(x)=1/q+A e^{\sqrt{2q}\,x}$、正の側では $u(x)=1/(q+r)+D e^{-\sqrt{2(q+r)}\,x}$ である。$U=u(0)$ とし、値と導関数をつなげると
$$
\sqrt q(U-1/q)=-\sqrt{q+r}\,(U-1/(q+r)),
\qquad U=\frac{1}{\sqrt{q(q+r)}}
$$
を得る。

Brown 運動の時間・空間拡大により $A_t\stackrel d=tA_1$ である。そこで非負積分の順を交換すると $U=\mathbb E[(q+rA_1)^{-1}]$ となる。一方、候補の密度 $1/(\pi\sqrt{a(1-a)})$ で同じ積分を行う。$a=\sin^2\theta$ に続いて $v=\tan\theta$ と置くと
$$
\frac{2}{\pi}\int_0^{\pi/2}\frac{\dd\theta}{q+r\sin^2\theta}
=\frac{2}{\pi}\int_0^\infty \frac{\dd v}{q+(q+r)v^2}
=\frac{1}{\sqrt{q(q+r)}}
$$
になる。$r/q<1$ で $(1+(r/q)A_1)^{-1}$ をべき級数で展開すれば全積率が候補と一致する。$A_1$ は $[0,1]$ に値を取るので指数積率をもち、:ref[thm-prob-moment-method] によって分布も一致する。
:::

例えば正の側にいた時間が $3/4$ 以上となる確率は $1-(2/\pi)(\pi/3)=1/3$ である。逆正弦密度は両端に向かって発散するので、占有時間は平均 $1/2$ のすぐ近くだけに集中しない。

### 達する側を指定した有限区間の退出

:::example[二つの障壁のどちらへ先に届くか]
標準 Brown 運動を $0$ から始め、$(-2,3)$ の初退出時刻を $\tau$ とする。片側の固定水準への到達は概確実に有限なので、$\tau$ も有限である。停止値は $-2$ または $3$ である。$B_{\tau\wedge n}$ は有界なので期待値を極限へ移せる。$3$ に着く確率を $h$ とすると $3h-2(1-h)=0$ から $h=2/5$ となる。また $B_{\tau\wedge n}^2-(\tau\wedge n)$ の期待値が零であることを使うと、優収束と単調収束により $\mathbb E\tau=9(2/5)+4(3/5)=6$ となる。片側の到達時刻の期待値が無限でも、二側で囲った退出時刻には有限平均がある。
:::

:::example[逆正弦分布の中央と両端]
最終零点の分布で中央の区間 $[1/4,3/4]$ に入る確率は $(2/\pi)(\pi/3-\pi/6)=1/3$ である。従って残りの両端の区間は合わせて確率 $2/3$ である。一様分布では中央の区間も両端の合計も $1/2$ である。逆正弦法則では中央より両端に集中することが、この区間確率に表れる。
:::

### 退出時刻の Laplace 変換

:::proposition[対称な区間からの退出時刻]{#prop-prob-brownian-exit-laplace}
$a>0$ に対し $\tau=\inf\{t:|B_t|=a\}$ とすると、$s\ge0$ で
$$
\mathbb E e^{-s\tau}=\frac1{\cosh(a\sqrt{2s})}.
$$
また正の側の単一障壁への到達時刻 $\tau_a$ について $\mathbb E e^{-s\tau_a}=e^{-a\sqrt{2s}}$ である。
:::

:::proof
$s>0$、$\theta=\sqrt{2s}$ とする。指数マルチンゲールを $\tau\wedge n$ で止めると期待値は $1$ である。連続時間の有界停止に対するこの等式は、時刻を上から近似する離散格子上で任意停止を行い、優収束で格子幅を零へ送れば得られる。実際、格子近似の値は $\exp(\theta\sup_{t\le n+1}|B_t|)$ で抑えられ、その期待値は鏡像原理による正規尾から有限である。今度は $n\to\infty$ とする。$B_{\tau\wedge n}$ は $[-a,a]$ にあるので、優収束で $1=\mathbb E e^{\theta B_\tau-s\tau}$ を得る。符号反転により $\mathbb E[e^{-s\tau}\mathbf1_{\{B_\tau=a\}}]$ と負側の対応する値は等しい。従って右辺は $\cosh(a\theta)\mathbb E e^{-s\tau}$ である。

正の障壁だけの場合、止める前に $B_t\le a$ なので $\exp(\theta B_{\tau_a\wedge n}-s(\tau_a\wedge n))\le e^{\theta a}$ である。$\tau_a$ は概確実に有限であり、優収束で $1=e^{\theta a}\mathbb E e^{-s\tau_a}$ を得る。$s=0$ では両方の式が $1$ になる。
:::

:::example[平均の有限性を変換から確認する]
両側の障壁が $-2,2$ なら $\cosh(2\sqrt{2s})=1+4s+O(s^2)$ なので、変換は $1-4s+O(s^2)$ である。$s\downarrow0$ で $(1-e^{-s\tau})/s\uparrow\tau$ だから平均は $4$ である。一方、障壁 $2$ だけでは $1-e^{-2\sqrt{2s}}$ は $2\sqrt{2s}$ に漸近し、$s$ で割ると発散する。変換は原点で連続でも、その傾きが有限とは限らない。
:::

### 一定のドリフトがあると到達確率がどう変わるか

:::proposition[線形ドリフト付き Brown 運動の到達密度]
$X_t=B_t+\mu t$（$\mu\in\R$）とし、$\tau_a=\inf\{t:X_t=a\}$（$a>0$）とする。有限時刻における密度は
$$
\mathbb P(\tau_a\in\dd t)=
\frac{a}{\sqrt{2\pi}t^{3/2}}
  \exp\left(-\frac{(a-\mu t)^2}{2t}\right)\dd t,\qquad t>0
$$
である。有限となる確率は $\exp(a\mu-a|\mu|)$ である。
:::

:::proof
固定した観測時刻 $T$ に対し $L_T=\exp(\mu B_T-\mu^2T/2)$ で測度を変える。$\mathbb EL_T=1$ である。有限時刻を $0=t_0<\dots<t_m=T$ と並べると、
$$
L_T=\prod_{j=1}^m \exp\bigl(\mu(B_{t_j}-B_{t_{j-1}})-\mu^2(t_j-t_{j-1})/2\bigr).
$$
各増分の正規密度に対応する因子を掛けると、平方完成により平均が $\mu(t_j-t_{j-1})$ へ移り、分散は元の時間差である。積の形に分かれるため、新しい測度でも増分は独立である。連続経路の法則の一意性により、新測度の $B$ は元の測度の $X$ と時刻 $T$ まで同分布である。

元の $B$ が $a$ に達する時刻を $\sigma_a$ とする。指数マルチンゲールを $\sigma_a\wedge T$ でサンプルすれば、その時刻までの事象上で $L_T$ の積分は $L_{\sigma_a\wedge T}$ の積分と等しい。この等式は決定論的な格子で上から $\sigma_a\wedge T$ を近似し、必要なら $T$ で切った格子を含めて離散の任意停止を使えば得られる。実際、停止時刻までの事象は近似した停止時刻の情報にも属し、停止値は経路の連続性で収束する。絶対値の最大の指数に対する正規尾の積分が有限なので優収束が使える。

従って $0<t\le T$ の到達密度は元の $f_{\sigma_a}(t)$ に $e^{\mu a-\mu^2t/2}$ を掛けたものである。指数をまとめると記載の式になる。$T$ は任意であり、全質量は $e^{\mu a}\mathbb E e^{-\mu^2\sigma_a/2}=e^{\mu a-a|\mu|}$ である。単一障壁の Laplace 変換を用いた。足りない質量は $\tau_a=\infty$ に対応する。
:::

:::example[障壁から離れる向きでは到達がまれになる]
$a=2,\mu=-1$ なら到達確率は $e^{-4}$ である。有限時刻の密度を到達確率で割ると指数は
$$
-\frac{(2+t)^2}{2t}+4=-\frac{(2-t)^2}{2t}
$$
になり、$\mu=1$ の到達密度に一致する。この例では、負のドリフトにもかかわらず到達した経路の時間の法則は、正のドリフトで出発した到達時間の法則と同じである。到達したかどうかの確率と、到達したという条件での時刻を区別する必要がある。
:::

## 二次変分

:::proposition[Brown 運動の二次変分]{#prop-prob-brownian-quadratic-variation}
$0=t_0<\cdots<t_m=T$ を決定論的分割 $\pi$ とし、$Q_\pi=\sum_{j=1}^m(B_{t_j}-B_{t_{j-1}})^2$ と置く。分割幅 $|\pi|=\max_j(t_j-t_{j-1})\to0$ なら $Q_\pi\to T$ が $L^2$ で成り立つ。分割列の幅の総和が有限なら概確実にも成り立つ。
:::

:::proof
増分の二次積率は $\Delta t_j$、四次積率は $3(\Delta t_j)^2$ である。独立性から $\mathbb E Q_\pi=T$、$\mathbb E(Q_\pi-T)^2=2\sum_j(\Delta t_j)^2\le2T|\pi|$ となる。前半は直接従い、後半は Chebyshev と Borel–Cantelli による。
:::

$T=1$ を $m$ 等分すると $\operatorname{Var}(Q_\pi)=2/m$ である。二進分割では幅の総和が有限なので、$Q_\pi\to1$ は概確実である。一方、連続な有限変動関数 $f$ では $\sum(\Delta f)^2\le\max|\Delta f|\sum|\Delta f|\to0$ である。従って Brown 経路は任意の非自明な区間で全変動が無限大である。非有理端点の区間でも、内部の有理端点区間に二進分割の議論を可算個適用すれば従う。

$B_t^2-t$ がマルチンゲールであることは、:ref[prop-prob-brownian-bounded-stopping] で示した。この補償項 $t$ は、上の二次変分の極限とも一致する。

### 二経路の積とドリフトの寄与

:::proposition[独立な Brown 経路の交差変分]
独立な標準 Brown 運動 $B,W$ について、決定論的分割 $\pi$ で $C_\pi=\sum_j\Delta B_j\Delta W_j$ と置くと
$$
\mathbb EC_\pi=0,\qquad
\mathbb EC_\pi^2=\sum_j(\Delta t_j)^2\le T|\pi|.
$$
従って $C_\pi\to0$ は $L^2$ で成り立ち、分割幅の総和が有限な列では概確実にも成り立つ。
:::

:::proof
各積の平均は独立性と中心化から零である。異なる区間では二つの経路を合わせた増分ベクトルが独立なので、交差項は零である。同じ区間内の積の二乗平均は $\mathbb E(\Delta B_j)^2\mathbb E(\Delta W_j)^2=(\Delta t_j)^2$ である。従って二次積率の上界と Chebyshev、Borel–Cantelli により結論を得る。
:::

:::example[拡散係数と線形ドリフトの二次変分]
$X_t=2B_t+3t$ とする。$\sum_j(\Delta X_j)^2=4Q_\pi+12\sum_j\Delta B_j\Delta t_j+9\sum_j(\Delta t_j)^2$ である。中央の和は平均零で、分散は $\sum_j(\Delta t_j)^3\le T|\pi|^2$ である。末項は $9T|\pi|$ 以下である。従って全体は $L^2$ で $4T$ に収束する。元の Brown 運動に掛けた $2$ は二乗で残り、時間に比例するドリフトは分割幅とともに消える。
:::

### 有界な過去依存の重みを付けた二次変分

:::proposition[予測可能な重みを付けた分割和]
$H_t$ を Brown 運動の右連続自然フィルトレーションに適合する実過程とし、一様に有界で経路は概確実に連続とする。決定論的分割で
$$
Q_\pi(H)=\sum_j H_{t_{j-1}}(B_{t_j}-B_{t_{j-1}})^2
$$
と置くと、分割幅が零へ向かうとき $Q_\pi(H)\to\int_0^T H_s\,\dd s$ が $L^2$ で成り立つ。
:::

:::proof
$D_j=(\Delta B_j)^2-\Delta t_j$ と置く。増分の独立性から直前の情報での条件付き平均は零、条件付き二次積率は $2(\Delta t_j)^2$ である。$H_{t_{j-1}}$ を掛けても条件付き平均が零で、異なる $j$ の項は後の項の直前で条件を取ると直交する。従って
$$
\mathbb E\left(\sum_j H_{t_{j-1}}D_j\right)^2
\le2\|H\|_\infty^2 T|\pi|\longrightarrow0.
$$
残りは $\sum_j H_{t_{j-1}}\Delta t_j$ であり、経路の連続性で Riemann 積分へ収束する。各和と極限の絶対値は $T\|H\|_\infty$ 以下なので、優収束で $L^2$ でも収束する。
:::

:::example[時刻で重みを付けた二次変分の平均]
$T=2$、$H_t=t$ とする。$m$ 等分では重みを付けた二乗和の平均は $\sum_{j=0}^{m-1}(2j/m)(2/m)=2-2/m$ であり、極限は $\int_0^2 t\,\dd t=2$ である。分散は
$$
2\sum_{j=0}^{m-1}(2j/m)^2(2/m)^2
=\frac{16(m-1)(2m-1)}{3m^3}
$$
であり、零へ向かう。重みが過去の観測に依存する場合は、右辺の時間積分自体はランダムになり得る。条件付き平均零の部分を先に取り出すと、何が極限に残るかを判定できる。
:::

### 二次変分を途中の全時刻で同時に近似する

:::proposition[二次変分の時間一様な二乗平均収束]
決定論的分割 $\pi$ に対し、時刻 $t$ までに完了した区間の二乗和を $Q_\pi(t)=\sum_{t_j\le t}(\Delta B_j)^2$ とする。$|\pi|\to0$ なら
$$
\mathbb E\sup_{0\le t\le T}|Q_\pi(t)-t|^2\longrightarrow0.
$$
分割列の幅の総和が有限なら、左辺の上限の中身は概確実にも零へ向かう。
:::

:::proof
$Z_k=\sum_{j=1}^k((\Delta B_j)^2-\Delta t_j)$ は、増分の独立性と中心化により格子上のマルチンゲールである。終端の二乗平均は $2\sum_j(\Delta t_j)^2$ だから、Doob の $p=2$ の最大不等式で $\mathbb E\max_k|Z_k|^2\le8T|\pi|$ である。$t_k\le t<t_{k+1}$ では $Q_\pi(t)-t=Z_k+(t_k-t)$ であり、最後の項の絶対値は $|\pi|$ 以下である。従って上限の二乗平均は $16T|\pi|+2|\pi|^2$ 以下で零へ向かう。幅の総和が有限ならこの上界の和も有限である。各固定閾値に Markov と Borel–Cantelli を適用し、可算な閾値を零へ送ると概確実な一様収束も得られる。
:::

:::example[二つの拡散を組み合わせた交差変分]
$X_t=B_t$、$Y_t=B_t+2W_t$ とし、$B,W$ は独立とする。決定論的分割で
$$
\sum_j\Delta X_j\Delta Y_j
=\sum_j(\Delta B_j)^2+2\sum_j\Delta B_j\Delta W_j
$$
となるので、極限は $T$ である。一方 $Y$ の二次変分は、二乗を展開して $T+4T=5T$ となる。例えば $T=3$ ではそれぞれ $3,15$ である。両経路が共有する $B$ は交差変分にも残り、独立な $W$ は $Y$ の二次変分だけに寄与する。
:::

## 演習問題

::::exercise{level=basic}
$B_2$ と $B_5$ の共分散を求めよ。

:::solution
$B_5=B_2+(B_5-B_2)$ で後者の増分は $B_2$ と独立である。従って共分散は $\operatorname{Var}(B_2)=2$ である。
:::
::::

::::exercise{level=basic}
$B_4-B_1$ の第四積率を求めよ。

:::solution
分散 $3$ の正規増分であり、第四積率は標準正規の第四積率 $3$ に分散の二乗を掛ける。従って $3\cdot3^2=27$ である。
:::
::::

::::exercise{level=basic}
$\mathbb P(\tau_2\le4)$ を $\Phi$ で表せ。

:::solution
鏡像原理の式に $a=2,t=4$ を入れると $2[1-\Phi(2/\sqrt4)]=2[1-\Phi(1)]$ である。
:::
::::

::::exercise{level=basic}
$[0,2]$ を四等分したときの二次変分和の期待値と分散を求めよ。

:::solution
各幅が $1/2$ なので期待値は $4/2=2$、分散は $2\cdot4(1/2)^2=2$ である。
:::
::::

::::exercise{level=advanced}
$B_t$ を $c>0$ で時間拡大し $Y_t=B_{ct}/\sqrt c$ とする。$Y$ の法則を求めよ。

:::solution
連続性と $Y_0=0$ は保存される。各増分は互いに素な時間区間の Brown 増分に対応し独立で、分散は $c(t-s)/c=t-s$ である。従って $Y$ も標準 Brown 運動である。
:::
::::

::::exercise{level=advanced}
$X_t=B_t-tB_1$（$0\le t\le1$）の共分散を求め、$B_1$ との独立性を示せ。

:::solution
展開して $\operatorname{Cov}(X_s,X_t)=s\wedge t-st$ を得る。$\operatorname{Cov}(X_t,B_1)=t-t=0$ であり、有限次元で同時正規だから各有限座標は $B_1$ と独立である。柱状集合の生成性で過程全体の独立性が従う。
:::
::::

::::exercise{level=advanced}
$\tau$ を Brown 運動が $-1$ または $2$ に初めて達する時刻とする。$2$ への到達確率と $\mathbb E\tau$ を求めよ。

:::solution
$\tau\le\tau_2<\infty$ で停止値は区間 $[-1,2]$ 内である。$B$ に有界停止 $\tau\wedge t$ を使い優収束を取ると $2p-(1-p)=0$ から $p=1/3$ である。$B_t^2-t$ では二乗項に優収束、時刻項に単調収束を使い、$\mathbb E\tau=4/3+2/3=2$ を得る。
:::
::::

::::exercise{level=advanced}
最終零点 $G$ が $[1/4,3/4]$ に入る確率を求めよ。

:::solution
逆正弦法則により $F(3/4)=(2/\pi)(\pi/3)=2/3$、$F(1/4)=(2/\pi)(\pi/6)=1/3$ である。端点に原子がないので差は $1/3$ である。
:::
::::

::::exercise{level=advanced}
$B_2=x$ を条件とした $\max_{0\le t\le2}B_t$ が $2$ を超える確率を、$x=0,1,2$ でそれぞれ求めよ。$x=2$ の境界も含めて説明せよ。

:::solution
$x<2$ では鏡像原理による密度の比が $\exp(-2\cdot2(2-x)/2)=e^{-2(2-x)}$ である。従って $x=0$ で $e^{-4}$、$x=1$ で $e^{-2}$ となる。等号を含む最大値の条件付き分布は、終点を固定したときの最大値の密度の式を積分して得られる。$x=2$ では $m>2$ の尾が $e^{-m(m-2)}$ であり、$m\downarrow2$ で $1$ に向かう。従って連続な橋に基づく版では、最大値がちょうど $2$ に留まる確率は零であり、厳密に超える確率も $1$ である。
:::
::::

::::exercise{level=basic}
$X_t=3B_t+t$ とする。時刻 $1$ から $3$ までの増分の平均と分散、および区間 $[1,3]$ での二次変分を求めよ。

:::solution
増分は $3(B_3-B_1)+2$ である。$B_3-B_1$ は平均零、分散 $2$ なので、増分の平均は $2$、分散は $18$ である。決定論的な分割で増分の二乗和を取ると、Brown の部分は係数の二乗 $9$ と区間長 $2$ の積 $18$ に収束する。時間部分の二乗和は $2|\pi|$ 以下、交差項を係数で割った和の分散は $\sum_j(\Delta t_j)^3\le2|\pi|^2$ なので、いずれも極限に残らない。増分の平均には決定論的ドリフトが現れるが、二次変分はそのドリフトから寄与を受けない。
:::

## 確認テスト

::::quiz
Brown 運動の増分について正しいものはどれか。

- [x] 互いに素な区間の増分は独立である。
- [ ] 各時刻での値が互いに独立である。
- [ ] 増分の分散は区間長の二乗である。

:::explanation
独立性が成立するのは互いに素な区間の増分であり、分散は区間長に等しい。値の共分散は $s\wedge t$ なので正の時刻同士では通常独立でない。
:::
::::

::::quiz{answer="0.02" tol="1e-6"}
$[0,1]$ を $100$ 等分したとき、増分二乗和の分散を求めよ。

:::explanation
一つの増分は分散 $1/100$ の正規で、その二乗の分散は $2/100^2$ である。独立な百項を加えると $2/100=0.02$ になる。
:::
::::

::::quiz{answer="0.5" tol="1e-6"}
最終零点 $G$ に対し $\mathbb P(G\le1/2)$ を求めよ。

:::explanation
$(2/\pi)\arcsin(1/\sqrt2)=(2/\pi)(\pi/4)=1/2$ である。
:::
::::

::::quiz
鏡像原理で経路のどの部分を反転するか。

- [x] 初到達時刻後の増分。
- [ ] 時刻零から水準に達するまでの経路だけ。
- [ ] 決定した日時以前に観測される全ての値。

:::explanation
初到達時刻後の増分は強 Markov 性で独立な Brown 運動となり、符号を反転しても法則が同じである。初到達時刻とそれ以前の値を固定したままこの対称性を使う。
:::
::::

::::quiz{answer="6" tol="1e-6"}
標準 Brown 運動を $0$ から始めて、$-2$ または $3$ に初めて届くまでの平均時間を求めよ。

:::explanation
停止した $B$ の期待値は零なので、$3$ に着く確率は $2/5$ である。$B_t^2-t$ に有界停止 $\tau\wedge n$ を適用し、二乗には優収束、時間には単調収束を使う。$\mathbb E\tau=3^2(2/5)+(-2)^2(3/5)=6$ を得る。
:::
::::
