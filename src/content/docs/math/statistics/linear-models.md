## この章の目標

- 計画行列への射影として最小二乗推定を理解する。
- Gauss–Markov の定理と正規モデルの F 検定を証明する。
- 一元・二元配置を直交する効果に分解する。
- 誤差の共分散、回帰診断、モデル選択の基準を区別する。

## 線形回帰モデルと最小二乗推定

観測ベクトルのうち説明変数で表せる部分を当てはめ、表せない部分を残差とする。二乗和を使うと、この分解は直交射影になる。

:::definition[固定計画の線形モデル]{#def-stat-linear-model}
$Y=X\beta+\varepsilon$ で $X\in\R^{n\times p}$ は既知、$\beta\in\R^p$ は未知、$E\varepsilon=0$ とする。$\norm{Y-Xb}^2$ を最小にする $b$ を :term[最小二乗推定量]{en="least squares estimator" yomi="さいしょうにじょうすいていりょう"} という。
:::

:::proposition[正規方程式と射影]{#prop-stat-ols}
$X$ が列フルランクなら $\widehat\beta=(X^{\mathsf T}X)^{-1}X^{\mathsf T}Y$、$H=X(X^{\mathsf T}X)^{-1}X^{\mathsf T}$ であり、当てはめ値は $HY$、残差は $(I-H)Y$ である。
:::

:::proof
:ref[thm-linalg-projection] の直交条件 $X^{\mathsf T}(Y-Xb)=0$ を解く。同じ式は平方和の勾配がゼロという条件でもある。$H=H^{\mathsf T}=H^2$ で、$\operatorname{Im}H=\operatorname{Im}X$ であるから直交射影である。階数が足りない場合も当てはめ値は一意だが、係数は解に $\Ker X$ を足す自由度を持つ。$c^{\mathsf T}\beta$ が識別可能なのは $c$ がこの核に直交する場合である。
:::

:::example[切片と傾き]
$(x_i,y_i)=(0,1),(1,2),(2,5)$ の直線では、中心化した説明変数の二乗和は $2$、積和は $4$ である。傾きは $2$、切片は $\bar y-2\bar x=2/3$、残差は $(1/3,-2/3,1/3)$ であり、残差平方和は $2/3$ である。
:::

:::example[計画の重複]
$X$ の二列がともに $\mathbf1$ なら、平均は $\beta_1+\beta_2$ だけで決まる。解は係数和が $\bar y$ になる全ての組であり、傾向のない切片への当てはめ値 $\bar y\mathbf1$ は一意である。
:::

### 階数が足りない計画と推定可能な対比

計画行列に同じ情報を持つ列があると、データを完全に記録しても係数の一部を分離できない。このときは係数そのものより、観測分布で区別できる係数の組合せを調べる。以下で $x_i^{\mathsf T}$ は $X$ の第 $i$ 行を表す。誤差の法則は係数に依存しないとする。

:::definition[推定可能な対比]{#def-stat-estimable-contrast}
$c^{\mathsf T}\beta$ の :term[線形不偏推定可能性]{en="linear unbiased estimability" yomi="せんけいふへんすいていかのうせい"} とは、ある $a\in\R^n$ がすべての $\beta$ に対して $E_\beta(a^{\mathsf T}Y)=c^{\mathsf T}\beta$ を満たすことである。水準平均の線形結合で係数和が $0$ のものは対比と呼ぶ。回帰では一般の $c^{\mathsf T}\beta$ に対しても線形仮説を立てられる。
:::

:::proposition[特異値分解による最小二乗解]{#prop-stat-ols-svd}
$X=U_r D V_r^{\mathsf T}$ を階数 $r$ の薄い特異値分解とする。すなわち $U_r,V_r$ の列はそれぞれ正規直交系であり、$D$ の対角成分は正である。このとき解全体は
$$
b=X^+Y+v,\qquad X^+=V_r D^{-1}U_r^{\mathsf T},\quad v\in\Ker X
$$
である。その中で $X^+Y$ はノルムが最小で、$H=U_rU_r^{\mathsf T}$ である。$c^{\mathsf T}\beta$ が線形不偏推定可能である条件は $c\in\Img X^{\mathsf T}$ であり、その条件は識別可能性とも同値である。
:::

:::proof
:ref[thm-linalg-svd] の分解を代入すると、残差平方和は
$$
\norm{(I-U_rU_r^{\mathsf T})Y}^2+\norm{U_r^{\mathsf T}Y-DV_r^{\mathsf T}b}^2
$$
となる。二項が分かれるのは対応するベクトルが直交するからである。第 2 項を $0$ にするには $V_r^{\mathsf T}b=D^{-1}U_r^{\mathsf T}Y$ が必要十分である。$V_r$ の列空間は $\Ker X$ に直交するので、核成分を $0$ にした解のノルムが最小になる。$X X^+Y=U_rU_r^{\mathsf T}Y$ である。

線形不偏性は $X^{\mathsf T}a=c$ と同値である。期待値が異なれば分布は異なるため、$P_\beta=P_{\beta'}$ なら $X\beta=X\beta'$ である。逆に同じ平均なら共通の誤差法則を平行移動して得る分布も同じである。従って識別可能性は $c$ が $\Ker X$ に直交することに等しい。特異値分解で見ればその直交補は $\Img X^{\mathsf T}$ であり、主張が従う。
:::

:::example[三水準のうち二水準だけを観測した場合]
切片と三つの水準の指示変数を列に取り、データを水準 A の $(2,4)$ と水準 B の $(5,7)$ とする。水準 C の列は $0$ であり、切片列は A と B の列の和である。平方和を最小にする条件は $b_0+b_A=3$ と $b_0+b_B=6$ の二つだけである。よって B と A の平均差 $b_B-b_A=3$ は推定できる。C と A の差は $b_C$ を任意に動かしても観測法則が同じなので識別できない。最小ノルム解を求めるなら $b_C=0$ とし、$b_0^2+(3-b_0)^2+(6-b_0)^2$ を最小にして $(b_0,b_A,b_B,b_C)=(3,0,3,0)$ を得る。この解が C の平均を $3$ と返すのは、ノルムの最小化という約束からである。
:::

### 調整後の回帰と計算

説明変数の一部を固定して残りの係数を調べるには、固定した部分で説明できる成分を応答と説明変数の両方から除く。この手順は切片を取り除くために中心化する操作を一般化したものである。

:::theorem[Frisch–Waugh–Lovell の定理]{#thm-stat-partial-regression}
$X=(X_1,X_2)$ は列フルランクとする。$H_1$ を $\Img X_1$ への直交射影、$M_1=I-H_1$ とすると、全モデルでの第 2 ブロックの係数は
$$
\widehat\beta_2=(X_2^{\mathsf T}M_1X_2)^{-1}X_2^{\mathsf T}M_1Y.
$$
この係数は $M_1Y$ を $M_1X_2$ で回帰した係数に等しい。
:::

:::proof
$b_2$ を固定して $b_1$ を最適化すると、$Y-X_2b_2$ の $X_1$ による当てはめが $H_1(Y-X_2b_2)$ となる。残った平方和は $\norm{M_1Y-M_1X_2b_2}^2$ である。$M_1X_2v=0$ なら $X_2v\in\Img X_1$ なので、$X$ の列の一次独立性から $v=0$ である。そのため :ref[prop-stat-ols] が使え、$M_1^{\mathsf T}M_1=M_1$ を代入して式が得られる。また $\Img X=\Img X_1\oplus\Img(M_1X_2)$ であるため、追加平方和は $M_1Y$ の後者への射影ノルム二乗である。
:::

:::example[群の違いと連続変数の傾きを分ける]
二群 A, B で $(x,y)$ がそれぞれ $(0,1),(1,3)$ と $(2,10),(3,14)$ であるとする。$X_1$ を各群の指示変数とし、共通傾きを $X_2=x$ に掛ける。群ごとの平均を引くと $M_1x=(-1/2,1/2,-1/2,1/2)^{\mathsf T}$、$M_1y=(-1,1,-2,2)^{\mathsf T}$ である。積和は $3$、$x$ の残差平方和は $1$ なので共通傾きは $3$ となる。A の切片は $2-3/2=1/2$、B の切片は $12-15/2=9/2$ である。切片だけを調整して群を無視すると、中心化した $x$ の平方和は $5$、積和は $23$ なので傾きは $23/5$ になる。群をまたいで平均が動く分が傾きに入るためである。
:::

:::example[直交分解を用いた二次曲線の当てはめ]
$x=(-1,0,1)$、$y=(2,1,4)$ とし、列に $\mathbf1,x,x^2$ を取る。$u=x^2-(2/3)\mathbf1=(1/3,-2/3,1/3)^{\mathsf T}$ は $\mathbf1,x$ と直交する。そこで $y$ の $\mathbf1,x,u$ への射影係数を順に求めると $7/3,(4-2)/2=1,(2-2+4)/(3\cdot(2/3))=2$ である。元の列に戻すと切片は $7/3-4/3=1$ で、曲線は $1+x+2x^2$ となる。説明変数の関数 $x^2$ を使っても、未知係数に関して線形であるため同じ射影計算を使える。
:::

計算機でフルランクの場合に逆行列を明示的に作る必要はない。:ref[thm-linalg-qr] により $X=QR$ と分ければ、$R\widehat\beta=Q^{\mathsf T}Y$ を後退代入で解ける。$X^{\mathsf T}X$ の固有値は $X$ の特異値の二乗なので、正規方程式では最大値と最小値の比が二乗になる。列がほとんど平行なときに係数が不安定になることを、桁落ちと統計的な分散の両面から調べる必要がある。

## Gauss–Markov の定理

最小二乗解を別の線形推定量と比べる。平均を保つ変更は説明変数に直交する方向の雑音を足すことになる。

:::theorem[Gauss–Markov の定理]{#thm-stat-gauss-markov}
:ref[def-stat-linear-model] で $X$ は列フルランク、$\operatorname{Cov}\varepsilon=\sigma^2 I$ とする。任意の線形不偏推定量 $AY$ に対し $\operatorname{Cov}(AY)-\operatorname{Cov}(\widehat\beta)$ は半正定値である。
:::

:::proof
不偏性は $AX=I$ と同値である。$A_0=(X^{\mathsf T}X)^{-1}X^{\mathsf T}$ とし、$D=A-A_0$ とすると $DX=0$ である。$A_0D^{\mathsf T}=0$ なので共分散の差は $\sigma^2 DD^{\mathsf T}$ である。任意の線形対比の分散についても対応する二次形式をとればよい。
:::

:::example[等しい精度の平均]
切片だけの $n=2$ の模型で重み $(3/4,1/4)$ は不偏だが、分散は $5\sigma^2/8$ である。等重みなら $\sigma^2/2$ であり、差 $\sigma^2/8$ は重みの差 $(1/4,-1/4)$ の二乗和に対応する。
:::

:::example[不偏性を外す場合]
切片のみで $\sigma^2=4,n=4$ なら $\bar Y$ の分散は $1$ である。定数規則 $0$ の分散は常に $0$ であるが、$\beta=2$ では二乗誤差が $4$ になる。定理の比較は線形不偏規則の中である。
:::

### 推定可能な線形結合の最小分散性

行列の階数が不足しても、ある対比の推定値は一意になる。推定量を観測の重みとして表すと、平均の制約と分散の最小化を別々に扱える。

:::proposition[階数が不足する場合の最良線形不偏推定]{#prop-stat-blue-contrast}
$E_\beta Y=X\beta$、$\operatorname{Cov}Y=\sigma^2I$、$\sigma^2>0$ とする。$c\in\Img X^{\mathsf T}$ なら、$c^{\mathsf T}X^+Y$ は $c^{\mathsf T}\beta$ の一意な最良線形不偏推定量である。最良とは、この場合すべての線形不偏推定量に対して分散が最小であることをいう。
:::

:::proof
:ref[prop-stat-ols-svd] の分解で $a_0=U_rD^{-1}V_r^{\mathsf T}c$ とおく。$X^{\mathsf T}a_0=V_rV_r^{\mathsf T}c=c$ なので対応する推定量は不偏である。他の不偏な重み $a$ と $a_0$ の差 $v$ は $X^{\mathsf T}v=0$ を満たす。一方 $a_0\in\Img X$ であるから $a_0^{\mathsf T}v=0$ である。従って
$$
\operatorname{Var}(a^{\mathsf T}Y)
=\sigma^2\norm{a_0}^2+\sigma^2\norm v^2.
$$
差が消えるのは $v=0$ の場合だけである。$a_0^{\mathsf T}Y=c^{\mathsf T}X^+Y$ より結論を得る。
:::

:::example[反復数の違う二群の平均差]
群 A に $2$ 個、群 B に $3$ 個の独立観測があり、各観測の分散は $\sigma^2$ とする。A の重みの和は $-1$、B の和は $1$ でなければ平均差の不偏推定にならない。$\bar Y_B-\bar Y_A$ の重みは $(-1/2,-1/2,1/3,1/3,1/3)$ であり、分散は $(1/2+1/3)\sigma^2=5\sigma^2/6$ である。各群の初めの観測だけを使うと重みは $(-1,0,1,0,0)$ になる。重みの差の二乗和は $1/2+2/3=7/6$ であるから、その分散は $2\sigma^2$ になる。切片と両群の指示変数を同時に置いても、この対比の推定精度は変わらない。
:::

### 当てはめた平均の分散と条件の確認

推定対象がベクトルのとき、個々の分散の比較だけでなく、任意の方向の分散を比べると共分散の半正定値順序が現れる。:ref[thm-stat-gauss-markov] の差 $DD^{\mathsf T}$ に左と右から行列 $C,C^{\mathsf T}$ を掛ければ、$C\widehat\beta$ に対する差は $(CD)(CD)^{\mathsf T}$ になる。複数の対比を同時に報告するときにも任意の重み付き和の分散が増えない。

:::example[データ範囲の端での推定]
$x=(-1,0,1)$ とし、切片と傾きを求める。中心化した計画で係数共分散は $\sigma^2\diag(1/3,1/2)$ である。従って点 $x_0$ での平均の分散は $\sigma^2(1/3+x_0^2/2)$ となる。$x_0=0$ では $\sigma^2/3$、$x_0=2$ では $7\sigma^2/3$ である。端から外へ出るほど傾きの推定誤差が大きく効く。なお、この式は平均が直線という仮定のもとでのばらつきであり、真の平均が曲がることによる外挿誤差は別途生じる。
:::

:::example[小さい特異値が係数と当てはめに及ぼす効果]
直交する二列 $u,v$ がともに長さ $1$ とし、計画の列を $u$ と $u+\epsilon v$（$\epsilon>0$）にする。$X^{\mathsf T}X=\begin{pmatrix}1&1\\1&1+\epsilon^2\end{pmatrix}$ の逆は $\epsilon^{-2}\begin{pmatrix}1+\epsilon^2&-1\\-1&1\end{pmatrix}$ である。例えば $\epsilon=1/10$ では第 2 係数の分散が $100\sigma^2$ であるが、$\beta_1+\beta_2$ の推定量は $u^{\mathsf T}Y$ で分散は $\sigma^2$ である。$HY$ は $\spn\{u,v\}$ への射影であり $\epsilon>0$ の範囲で変わらない。報告したい係数の組に応じて不確かさが変わる。
:::

固定計画での不偏性は誤差平均ゼロに基づく。説明変数が確率的な場合には、観測した $X$ ごとに $E(\varepsilon\mid X)=0$、$\operatorname{Cov}(\varepsilon\mid X)=\sigma^2I$ を仮定すれば同じ証明が条件付きで使える。例えば傾きだけの一観測で $X=\pm1$ が等確率、$\varepsilon=X$ とする。$E\varepsilon=0$ だが $\widehat\beta=Y/X=\beta+1$ となる。無条件の平均ゼロだけでは説明変数と誤差の関係を制御できない。

## 正規線形モデルの分布論

正規誤差では計画空間と残差空間の座標が独立になる。そのため係数の正規分布と独立な分散推定量を組み合わせられる。

:::theorem[正規線形モデルの標本分布]{#thm-stat-normal-linear}
$\varepsilon\sim N_n(0,\sigma^2 I)$ とし $X$ は列フルランク、$n>p$ とする。$\widehat\beta\sim N_p(\beta,\sigma^2(X^{\mathsf T}X)^{-1})$ で、$\mathrm{RSS}=\norm{(I-H)Y}^2$ と独立である。$\mathrm{RSS}/\sigma^2\sim\chi_{n-p}^2$ である。
:::

:::proof
$\widehat\beta$ は正規ベクトルの線形変換であり、平均と共分散は行列積で得る。計画空間と直交補空間の基底を並べ、誤差を直交変換すると独立な正規座標になる。係数は前者だけを使い、二乗残差は後者だけを使う。後者の座標数が $n-p$ である。
:::

:::example[係数の t 統計量]
非零の $c$ に対し $S^2=\mathrm{RSS}/(n-p)$ とおく。$\{c^{\mathsf T}(\widehat\beta-\beta)\}/[S\sqrt{c^{\mathsf T}(X^{\mathsf T}X)^{-1}c}]$ は $t_{n-p}$ に従う。前の直線当てはめでは $S^2=2/3$ で、傾きの標準誤差は $1/\sqrt3$ になる。
:::

:::example[平均応答と新観測]
新しい説明変数 $x_0$ に対する平均の推定値の分散は $\sigma^2x_0^{\mathsf T}(X^{\mathsf T}X)^{-1}x_0$ である。独立な新観測に対する予測誤差にはさらに $\sigma^2$ が加わる。切片だけで $n=4$ なら係数は順に $\sigma^2/4,5\sigma^2/4$ である。
:::

### 同時尤度と分散推定の二つの分母

$Y\sim N_n(X\beta,\sigma^2I)$ では、対数尤度が残差平方和で決まる。$X$ が列フルランクで $n>p$ の場合、
$$
\ell(b,v)=-\frac n2\log(2\pi v)-\frac{\norm{Y-Xb}^2}{2v},\qquad v>0.
$$
$v$ を固定すると最大化の解は $\widehat\beta$ である。そこで $v$ で微分すると $-n/(2v)+\mathrm{RSS}/(2v^2)$ の符号は $v=\mathrm{RSS}/n$ で正から負に変わる。このため $\widehat v_{\mathrm{ML}}=\mathrm{RSS}/n$ となる。:ref[thm-stat-normal-linear] から $E\mathrm{RSS}=(n-p)\sigma^2$ なので、$S^2=\mathrm{RSS}/(n-p)$ が不偏である。$\mathrm{RSS}=0$ なら $v\downarrow0$ で尤度が発散するが、仮定した正規モデルでこの事象の確率は $0$ である。

:::proposition[回帰係数と残差平方和の完備十分性]{#prop-stat-linear-complete}
計画 $X$ が列フルランクで $n>p$ の正規線形モデルでは、$(\widehat\beta,\mathrm{RSS})$ は $(\beta,\sigma^2)$ に対する完備十分統計量である。従って $C\widehat\beta$ の各成分と $S^2$ はそれぞれの対象に対する一様最小分散不偏推定量である。
:::

:::proof
密度の指数に $Y$ が現れる項は $(X^{\mathsf T}Y)^{\mathsf T}\beta/v-\norm Y^2/(2v)$ である。自然パラメータの範囲は $\R^p\times(-\infty,0)$ であり、任意の第 2 成分で $v$ を決め、その後に $\beta$ を決められる。そこで $Y$ 全体を一観測とする指数型実験に :ref[thm-stat-full-exponential-complete] を適用すると、$(X^{\mathsf T}Y,\norm Y^2)$ が完備十分である。$X^{\mathsf T}Y=X^{\mathsf T}X\widehat\beta$ と $\norm Y^2=\mathrm{RSS}+\widehat\beta^{\mathsf T}X^{\mathsf T}X\widehat\beta$ により、二組は互いに計算できる。平均と分散を :ref[thm-stat-normal-linear] で求めれば二乗可積分な不偏推定量である。:ref[thm-stat-lehmann-scheffe] を各成分に適用すると結論を得る。
:::

:::example[自由度の補正と二乗誤差]
$n=8,p=3,\sigma^2=4$ とする。$\mathrm{RSS}/4$ は $\chi^2_5$ なので、$E\mathrm{RSS}=20$、$\operatorname{Var}\mathrm{RSS}=160$ である。従って $\widehat v_{\mathrm{ML}}$ の期待値と分散は $5/2,5/2$、二乗誤差リスクは $5/2+(3/2)^2=19/4$ になる。$S^2$ は不偏で分散 $160/25=32/5$ である。不偏推定量の中での最適性から、偏りを許したときの二乗誤差の最適性までは従わない。
:::

### 平均の区間と予測区間

$t_{\nu,1-\alpha/2}$ を自由度 $\nu=n-p$ の t 分布の上側確率 $\alpha/2$ の点とする。$x_0$ を事前に固定し、$v_0=x_0^{\mathsf T}(X^{\mathsf T}X)^{-1}x_0>0$ とする。$x_0^{\mathsf T}\widehat\beta-x_0^{\mathsf T}\beta$ は分散 $\sigma^2v_0$ の正規変数で $S^2$ と独立である。ゆえに平均の $1-\alpha$ 信頼区間は $x_0^{\mathsf T}\widehat\beta\pm t_{\nu,1-\alpha/2} S\sqrt{v_0}$ である。

同じ説明変数 $x_0$ で $Y_0=x_0^{\mathsf T}\beta+\varepsilon_0$ を新たに観測し、$\varepsilon_0$ も訓練標本と独立な $N(0,\sigma^2)$ に従うとする。この場合も、$Y_0-x_0^{\mathsf T}\widehat\beta$ は正規で $S^2$ と独立である。その分散は $\sigma^2(1+v_0)$ であるから、幅の因子を $\sqrt{1+v_0}$ に替えると $Y_0$ を含む予測区間になる。被覆確率を計算するときは訓練標本と将来値の双方を繰り返す。

:::example[二点を結ぶ線への反復観測]
$x=0$ に $(1,3)$、$x=1$ に $(4,6)$ があるとする。推定切片は $2$、傾きは $3$、$\mathrm{RSS}=4$、$S^2=2$ である。点 $x_0=1/2$ の推定は二群平均の等重み平均なので $7/2$、$v_0=(1/2)^2/2+(1/2)^2/2=1/4$ である。よって平均の区間半幅は $t_{2,1-\alpha/2}/\sqrt2$ であり、予測の区間半幅は $t_{2,1-\alpha/2}\sqrt{5/2}$ である。たとえモデルの平均が正確に分かっても、新観測の誤差は残るため後者が幅広い。
:::

:::example[切片を含むモデルの残差と無中心化平方和]
$(Y_1,Y_2,Y_3)=(2,4,6)$ で切片だけを当てはめると、$HY=(4,4,4)^{\mathsf T}$、$\norm{HY}^2=48$ である。残差平方和は $8$ で、無中心化平方和 $56$ はその和になる。$\beta=4,\sigma^2=2$ とすれば $\norm{HY}^2/\sigma^2$ は自由度 $1$、非心度 $24$ の非心カイ二乗分布である。実際 $\sqrt3\bar Y/\sigma$ は平均 $\sqrt{24}$、分散 $1$ の正規変数である。一方 $\mathrm{RSS}/\sigma^2$ は残差方向の平均が $0$ なので中心カイ二乗分布になる。
:::

## 一般線形仮説と F 検定

個別の係数の検定を繰り返す代わりに、同時に課した制約で当てはめがどれだけ悪化したかを測る。

:::theorem[一般線形仮説の F 検定]{#thm-stat-linear-f}
:ref[thm-stat-normal-linear] の条件で、一般線形仮説を $H_0:C\beta=d$ とする。$C$ は行フルランクの $q\times p$ 行列、$d\in\R^q$、$1\le q\le p$ とする。$V=(X^{\mathsf T}X)^{-1}$ のとき
$$
F=\frac{(C\widehat\beta-d)^{\mathsf T}(CVC^{\mathsf T})^{-1}(C\widehat\beta-d)/q}{\mathrm{RSS}/(n-p)}
\sim F_{q,n-p}\quad(H_0).
$$
分子の $q$ で割る前の値は制約付き残差平方和と全残差平方和の差である。
:::

:::proof
帰無で $C\widehat\beta-d$ は共分散 $\sigma^2 CVC^{\mathsf T}$ の中心正規なので、白色化した二乗和は $\chi_q^2$ になる。分母と独立であり、F 分布の定義を使える。平方和の増分は正規方程式により $(b-\widehat\beta)^{\mathsf T}V^{-1}(b-\widehat\beta)$ である。これを $C b=d$ のもとで最小化すると、Lagrange 乗数方程式から $b-\widehat\beta=VC^{\mathsf T}(CVC^{\mathsf T})^{-1}(d-C\widehat\beta)$ となり、代入で主張を得る。
:::

:::example[差の F 検定]
$n=12,p=4,q=2$ で全平方和が $16$、制約付きが $28$ なら $F=((28-16)/2)/(16/8)=3$ である。
:::

:::example[対比一つ]
$q=1$ では分子が $(c^{\mathsf T}\widehat\beta-d)^2/(c^{\mathsf T}Vc)$ である。従って F 統計量は同じ対比の t 統計量の二乗であり、$t_{8}$ の値 $-2$ は $F_{1,8}$ の値 $4$ に対応する。
:::

### 部分空間の差と検出力

制約が単に一部の係数を $0$ にする場合、制約付き計画の空間が全計画の空間に含まれる。$H_0,H_1$ をそれぞれへの射影とする。包含により $H_1H_0=H_0H_1=H_0$ である。よって $D=H_1-H_0$ は対称で $D^2=D$ を満たし、増えた方向だけへの射影になる。補空間 $I-H_1$ と $D$ の積は $0$ である。平方和の増分は
$$
Y^{\mathsf T}(I-H_0)Y-Y^{\mathsf T}(I-H_1)Y=\norm{DY}^2
$$
である。非零の制約 $C\beta=d$ でも、制約を満たす基準点 $b_0$ を引いた応答 $Y-Xb_0$ を使えば同じ形になる。この見方により、入れ子の二つのモデルでは列の本数でなく空間の次元の差を自由度に使う理由が分かる。

:::proposition[F 検定の対立仮説下の分布]{#prop-stat-linear-f-power}
:ref[thm-stat-linear-f] の設定において、真の $C\beta$ が $d$ と異なる場合の $F$ は自由度 $(q,n-p)$、非心度
$$
\lambda=\frac{(C\beta-d)^{\mathsf T}(CVC^{\mathsf T})^{-1}(C\beta-d)}{\sigma^2}
$$
の :term[非心 F 分布]{en="noncentral F distribution" yomi="ひしんえふぶんぷ"} に従う。ここで非心 F 分布は、独立な非心カイ二乗と中心カイ二乗を各自由度で割ってから取った比である。
:::

:::proof
$A=CVC^{\mathsf T}$ とおくと $\sigma^{-1}A^{-1/2}(C\widehat\beta-d)$ は単位共分散の正規ベクトルで、その平均のノルム二乗が $\lambda$ である。これを直交変換すれば、ベクトルのノルムと共分散を保ったまま平均を $(\sqrt\lambda,0,\ldots,0)^{\mathsf T}$ の形にできる。ノルム二乗は非心カイ二乗、残差平方和は係数と独立なので比の定義が使える。対応する中心 F の上側確率 $\alpha$ の点を $f_{q,n-p;1-\alpha}$ とすれば、検出力は非心 F がその点を超える確率である。
:::

:::example[観測点の範囲が傾きの検出力を変える]
切片を含む $n=4$ の回帰で傾き $0$ を検定する。$x=(-1,-1,1,1)$ と $x'=2x$ の中心化平方和は $4,16$ である。同じ物理的な傾き $\beta_1=1$ と誤差分散 $\sigma^2=4$ を仮定するなら、非心度は順に $1,4$ となる。どちらでも帰無の自由度は $(1,2)$ で共通である。ここで実際の計画点を遠ざける場合と、同じ計画点の単位だけを変える場合を区別する。単位だけを変更して傾きの数値も半分にすれば、非心度は $1$ のままである。
:::

:::example[同じ残差を用いた追加平方和の順序]
相互に直交する単位ベクトル $\mathbf1/\sqrt4,u,v,w$ に対して $y=3\mathbf1/\sqrt4+2u+v+w$ とする。切片だけから $u$ を追加すると減る平方和は $4$、さらに $v$ を追加すると $1$ である。両方を追加したモデルの残差平方和は $1$、自由度は $1$ なので、二方向を同時に検定した F 値は $(4+1)/(2\cdot1)=5/2$ である。最初の $u$ だけを追加した時点で検定するなら残差平方和が $2$、自由度も $2$ になる。このデータでは平均平方は偶然どちらも $1$ であるが、参照する F 分布の分母自由度は異なる。
:::

### Scheffé の同時区間

多数の方向をデータを見てから選ぶと、それぞれの t 区間で保証した確率はすべてを含む確率にならない。全方向を一度に含む楕円体を作ると、後から選んだ線形結合についても区間を読める。

:::theorem[Scheffé の同時信頼区間]{#thm-stat-scheffe-intervals}
$V=(X^{\mathsf T}X)^{-1}$、$A=CVC^{\mathsf T}$ とし、$C$ は階数 $q$ の $q\times p$ 行列とする。:ref[thm-stat-normal-linear] の条件で、すべての $a\in\R^q$ に対する
$$
a^{\mathsf T}C\widehat\beta
\ \pm\ S\sqrt{q f_{q,n-p;1-\alpha}}\sqrt{a^{\mathsf T}Aa}
$$
が同時に $a^{\mathsf T}C\beta$ を含む確率は $1-\alpha$ である。
:::

:::proof
$e=C(\widehat\beta-\beta)$ とおく。$a\ne0$ について Cauchy–Schwarz を $A^{1/2}a$ と $A^{-1/2}e$ に適用すると、$(a^{\mathsf T}e)^2/(a^{\mathsf T}Aa)\le e^{\mathsf T}A^{-1}e$ となる。$e\ne0$ なら $a=A^{-1}e$ で等号が成り立つ。$e=0$ でも上限は $0$ である。よって同時に含む事象は $e^{\mathsf T}A^{-1}e/(qS^2)\le f_{q,n-p;1-\alpha}$ に等しい。真の $C\beta$ を $d$ に入れた :ref[thm-stat-linear-f] がこの事象の確率を与える。
:::

:::example[同じ直線の任意の点での平均応答]
$x=(-1,-1,1,1)$、$y=(0,2,4,6)$ の場合、切片は $3$、傾きは $2$、$V=I_2/4$、$S^2=2$ である。$\alpha=1/4$ とする。独立な $U,V_2\sim\chi_2^2$ の比は $P(U/V_2>c)=E(e^{-cV_2/2})=1/(1+c)$ なので、$f_{2,2;3/4}=3$ である。$C=I_2$、$a=(1,x_0)^{\mathsf T}$ とすれば同時区間は $3+2x_0\pm\sqrt{3(1+x_0^2)}$ である。$x_0=0$ で半幅 $\sqrt3$、$x_0=1$ で $\sqrt6$ となる。個別の平均を同じ訓練標本から推定しているため、報告したい点を増やしても区間の同時被覆をこの楕円体から読める。
:::

## 一元配置と二元配置の分散分析

群ごとに平均が異なるなら、全体のばらつきを群内と群間に分ける。因子が二つなら、さらに一方の効果がもう一方の水準で変わるかを分ける。

:::definition[分散分析]{#def-stat-anova}
:term[分散分析]{en="analysis of variance" yomi="ぶんさんぶんせき"} は、要因を表す部分空間の平方和を分離して比較する方法である。一元配置では群平均 $\mu_i$ をモデルとし、独立誤差の共通分散を仮定する。群サイズ $n_i$、総数 $N$、群数 $a$ とすると群内平方和は $\sum_{ij}(Y_{ij}-\bar Y_{i\cdot})^2$、群間平方和は $\sum_i n_i(\bar Y_{i\cdot}-\bar Y_{\cdot\cdot})^2$ である。
:::

群内残差の群ごとの和はゼロなので、全平均との差の二乗展開で交差項が消える。以下、厳密な F 分布を用いる際は誤差が独立な $N(0,\sigma^2)$ に従い、$\sigma^2>0$ とする。一元配置で $a\ge2$、$N>a$ なら、計画の次元が $a$、全群同平均の部分空間の次元が $1$ であるから、:ref[thm-stat-linear-f] の自由度は $(a-1,N-a)$ となる。

二元配置では水準数 $a,b$、各セルの反復数を $m$ とする。平均応答を $\mu+\alpha_i+\beta_j+\gamma_{ij}$ とし、$\sum_i\alpha_i=\sum_j\beta_j=0$、$\gamma$ の各行和と各列和をゼロにする。全平均、行効果、列効果、交互作用、セル内残差の空間は直交する。実際、行効果と列効果の積和はそれぞれの和の積になり、交互作用との積和は行和や列和でゼロになり、セル内残差はセル内和がゼロである。従って各射影は
$$
\bar Y_{\cdots},\quad
\bar Y_{i\cdot\cdot}-\bar Y_{\cdots},\quad
\bar Y_{\cdot j\cdot}-\bar Y_{\cdots},\quad
\bar Y_{ij\cdot}-\bar Y_{i\cdot\cdot}-\bar Y_{\cdot j\cdot}+\bar Y_{\cdots},\quad
Y_{ijk}-\bar Y_{ij\cdot}.
$$
各成分の階数は順に $1,a-1,b-1,(a-1)(b-1),ab(m-1)$ である。交互作用は最後の行と列を和の制約で決めると残りが自由なのでこの階数になる。Cochran の定理を用いて、各効果の平均平方をセル内平均平方で割れば帰無で対応する F 分布を得る。$m=1$ では全セル平均モデルにセル内自由度がない。不均衡計画では上の単純平均による直交性が一般に失われるため、比較する入れ子モデルを明示する。

:::example[二群の一元配置]
群が $(1,3)$ と $(5,7)$ なら群平均は $2,6$、全平均は $4$ である。群間平方和は $2\cdot2^2+2\cdot2^2=16$、群内平方和は $4$、自由度は $1,2$ で $F=8$ となる。
:::

:::example[二元配置の交互作用]
セル平均が $\begin{pmatrix}1&3\\3&1\end{pmatrix}$ なら行平均、列平均、全平均は全て $2$ である。交互作用は $\begin{pmatrix}-1&1\\1&-1\end{pmatrix}$ であり、$m=2$ なら平方和は $8$、自由度は $1$ である。
:::

### 平均平方の期待値と対比

正規性を仮定しなくても、二次形式の期待値からどの効果が平均平方に入るかを計算できる。平均ベクトルを $m$、共分散を $\sigma^2I$ とし、階数 $d>0$ の直交射影を $P$ とする。$\norm{PY}^2=\norm{Pm}^2+2m^{\mathsf T}P(Y-m)+(Y-m)^{\mathsf T}P(Y-m)$ と展開すると、交差項は平均ゼロで最後の項の期待値は $\sigma^2\tr P=\sigma^2d$ になる。従って平均平方の期待値は $\sigma^2+\norm{Pm}^2/d$ である。例えば均衡二元配置の行効果では $\norm{Pm}^2=bm_0\sum_i\alpha_i^2$ となる。ここで $m_0$ はセルごとの反復数である。交互作用では $m_0\sum_{ij}\gamma_{ij}^2$ である。各効果がゼロのとき、対応する平均平方とセル内平均平方が同じ期待値を持つ。

:::proposition[一元配置の直交対比]{#prop-stat-anova-orthogonal-contrasts}
一元配置で群サイズ $n_i>0$、正規誤差、共通分散 $\sigma^2$ とする。対比係数 $c=(c_1,\ldots,c_a)$ の線形結合 $L_c=\sum_i c_i\bar Y_{i\cdot}$ の分散は $\sigma^2\sum_i c_i^2/n_i$ である。二つの対比 $c,d$ の推定量が独立である条件は $\sum_i c_id_i/n_i=0$ である。$a-1$ 個の相互に直交する非零対比があれば、群間平方和は各対比の平方を $\sum_i c_i^2/n_i$ で割った値の和になる。
:::

:::proof
群平均は独立で、分散は $\sigma^2/n_i$ である。よって共分散は $\sigma^2\sum_i c_id_i/n_i$ になり、正規性の下で共分散ゼロと独立が同値になる。観測空間に、群 $i$ の各座標が $c_i/n_i$ のベクトル $v_c$ を作る。$\sum_i c_i=0$ だから全平均方向に直交し、群平均方向の空間に属する。$v_c^{\mathsf T}Y=L_c$ かつ $\norm{v_c}^2=\sum_i c_i^2/n_i$ である。$a-1$ 個の直交ベクトルは群平均方向から全平均を除いた空間の基底なので、各方向への射影ノルム二乗を足すと群間平方和を得る。
:::

:::example[三群の差を二つに分ける]
各群二個の標本 $(1,3),(3,5),(7,9)$ を取る。群平均は $2,4,8$、全平均は $14/3$ なので、群間平方和は $2(64+4+100)/9=112/3$、群内平方和は $6$ である。$c=(-1,1,0)$ と $d=(-1,-1,2)$ は内積 $\sum c_id_i/2=0$ である。対比は $2$ と $10$、規格化する因子は $1,3$ なので、平方和は $4+100/3=112/3$ となる。群間の全体検定に加えて、どの差が平方和に寄与したかを読み取れる。データを見てから対比を選ぶ場合の同時推測には :ref[thm-stat-scheffe-intervals] を使える。
:::

### 群平均のすべての対を同時に比較する

一元配置で $a\ge 2$ 群、各群 $m\ge 2$ 個の正規観測があるとする。群平均の推定誤差は $Z_i=\sqrt m(\bar Y_{i\cdot}-\mu_i)/\sigma$ と標準化すれば独立な標準正規になる。群内平均平方を $S^2$ とすると、$S/\sigma=\sqrt{U/\nu}$、$U\sim\chi_\nu^2$、$\nu=a(m-1)$ であり、$U$ はどの群平均とも独立である。従ってすべての群対での標準化した誤差の最大値は
$$
\max_{i<j}\frac{|(\bar Y_{i\cdot}-\bar Y_{j\cdot})-(\mu_i-\mu_j)|}{S/\sqrt m}
=\frac{\max_i Z_i-\min_i Z_i}{\sqrt{U/\nu}}
$$
となる。右辺の法則を :term[スチューデント化範囲分布]{en="studentized range distribution" yomi="すちゅーでんとかはんいぶんぷ"} という。その $1-\alpha$ 分位点を $q_{a,\nu;1-\alpha}$ とすれば、すべての差に対する $\bar Y_{i\cdot}-\bar Y_{j\cdot}\pm q_{a,\nu;1-\alpha} S/\sqrt m$ が同時に真値を含む確率は $1-\alpha$ である。これが均衡計画での :term[Tukey の同時比較]{en="Tukey's simultaneous comparisons" yomi="てゅーきーのどうじひかく"} である。

分布関数は最小値の添字で事象を分けると計算できる。$U=u$ を固定し、$c=q\sqrt{u/\nu}$ とおく。$Z_1=z$ が最小で範囲が $c$ 以下となるには、残りの $a-1$ 個すべてが $[z,z+c]$ に入ればよい。同点はほぼ確実に起こらないので、$q\ge0$ に対して条件付き分布関数は $a\int\phi(z)\{\Phi(z+c)-\Phi(z)\}^{a-1}\,\dd z$ である。ここで $\phi,\Phi$ は標準正規の密度と分布関数である。これを $U$ について平均すればよい。$a=2$ では範囲は $|Z_1-Z_2|$ なので分位点は $\sqrt2\,t_{\nu,1-\alpha/2}$ になり、二群の通常の t 区間と一致する。

### 二元配置での調整と反復の役割

水準 A と水準 B がともに二つあるとし、セル平均の期待値を $m_{ij}$ とする。交互作用がない条件は $m_{11}-m_{12}-m_{21}+m_{22}=0$ である。セルサイズ $n_{ij}$ が異なる場合にも、この対比はセル平均モデルで推定できる。独立なセル平均の分散は $\sigma^2/n_{ij}$ なので、制約を課すことによる平方和の増分は
$$
\frac{(\bar Y_{11}-\bar Y_{12}-\bar Y_{21}+\bar Y_{22})^2}
{\sum_{i,j}1/n_{ij}}.
$$
実際、全セル平均を係数とする計画では $X^{\mathsf T}X$ は $n_{ij}$ を対角に並べた行列であり、:ref[thm-stat-linear-f] で $C=(1,-1,-1,1)$ と置けばよい。この調整では対比の係数が水準の意味を決め、分散の重みが反復数の違いを織り込む。

:::example[不均衡計画での交互作用検定]
セル $(11),(12),(21),(22)$ にそれぞれ $(0,2),(2,4),(4,5,6),(6,8,10)$ を観測したとする。平均は $1,3,5,8$ なので交互作用の対比は $1$ である。セル内平方和は $2+2+2+8=14$、残差自由度は $10-4=6$ である。対比の平方を $1/2+1/2+1/3+1/3=5/3$ で割ると増分は $3/5$ になり、F 値は $(3/5)/(14/6)=9/35$ である。反復数が共通という仮定を置かず、セル平均の分散差を反映した計算である。
:::

:::example[一セル一観測で残差に混じる効果]
$2\times2$ の一セル一観測で $y=\begin{pmatrix}2&4\\6&12\end{pmatrix}$ とする。加法モデルの当てはめは行平均 $(3,9)$ と列平均 $(4,8)$ を足し全平均 $6$ を引いた $\begin{pmatrix}1&5\\7&11\end{pmatrix}$ である。残差 $\begin{pmatrix}1&-1\\-1&1\end{pmatrix}$ の平方和は $4$ である。加法モデルと正規誤差を仮定するならこの残差で分散を推定できる。一方、交互作用を許すモデルでは同じ方向に効果が入るので、残差の大きさを誤差分散と交互作用に分けられない。セルごとの反復は両者を分けるために必要になる。
:::

## 一般化最小二乗法

観測ごとに精度が違う場合、同じ残差を同じ重みで扱う必要はない。共分散が分かっていれば、誤差を球対称な共分散に変換してから当てはめる。

:::theorem[一般化最小二乗法]{#thm-stat-gls}
正定値 $\Sigma$ に対し $\operatorname{Cov}\varepsilon=\sigma^2\Sigma$、$X$ は列フルランクとする。:term[一般化最小二乗推定量]{en="generalized least squares estimator" yomi="いっぱんかさいしょうにじょうすいていりょう"} は
$$
\widehat\beta_{\mathrm{GLS}}=(X^{\mathsf T}\Sigma^{-1}X)^{-1}X^{\mathsf T}\Sigma^{-1}Y
$$
であり、線形不偏推定量の中で共分散を最小にする。
:::

:::proof
$\Sigma^{-1/2}$ を両辺に掛けると誤差共分散は $\sigma^2 I$ になる。この正則変換は線形推定量の集合を変えないため、:ref[thm-stat-gauss-markov] を変換後の計画に適用する。変換した残差の平方和が元の残差の $\Sigma^{-1}$ による二次形式になる。
:::

:::example[精度の違う平均]
二観測の分散が $1,4$、共分散がゼロなら重みは正規化した精度 $(4/5,1/5)$ である。$Y=(2,7)$ なら推定値は $3$、分散は $4/5$ である。
:::

:::example[共通成分のある誤差]
$\Sigma=\begin{pmatrix}2&1\\1&2\end{pmatrix}$ で切片だけなら $\Sigma^{-1}\mathbf1=\mathbf1/3$ なので重みは等しい。推定値の分散は $\sigma^2(2+2+2)/4=3\sigma^2/2$ になる。共分散を無視すると $\sigma^2$ と過小に見積もる。
:::

### 不均一分散と共分散推定

未知の誤差共分散を扱うとき、係数推定の変更と標準誤差の変更は区別する。固定計画で観測の誤差が無相関、共分散 $\Omega=\diag(\sigma_i^2)$ なら、最小二乗推定量の共分散は $V X^{\mathsf T}\Omega X V$（$V=(X^{\mathsf T}X)^{-1}$）である。これは $\widehat\beta-\beta=VX^{\mathsf T}\varepsilon$ を展開すれば得られる。残差の二乗を $\sigma_i^2$ に代入する形式はこの行列を推定するが、有限標本では残差が射影を受けるので各 $e_i^2$ は $\sigma_i^2$ の不偏推定量ではない。一般に $Ee_i^2=\sum_j(I-H)_{ij}^2\sigma_j^2$ である。既知の $\Omega$ を逆重みとして使う GLS は推定値そのものを変える。

:::example[平均の分散を二通りで計算する]
切片のみで独立な $Y_1,Y_2$ の分散が $1,9$ なら、通常の平均の分散は $(1+9)/4=5/2$ である。推定値を GLS に替えると分散は $9/10$ となる。前者に正しい分散式を使っても、前者の推定値の分散が後者まで下がるわけではない。係数と分散の両方に使った仮定を記録する必要がある。
:::

### 共分散が与えられた推測

$\Sigma=LL^{\mathsf T}$ を Cholesky 分解とし、三角方程式で $Y_*=L^{-1}Y$、$X_*=L^{-1}X$ を計算する。これを :term[白色化]{en="whitening" yomi="はくしょくか"} という。誤差が正規なら $L^{-1}\varepsilon$ の各成分が独立で分散 $\sigma^2$ である。:ref[thm-stat-normal-linear] を $Y_*,X_*$ に適用すると、共分散は $\sigma^2(X^{\mathsf T}\Sigma^{-1}X)^{-1}$、重み付き残差平方和を $\sigma^2$ で割ったものは $\chi^2_{n-p}$ であり、係数と独立になる。ここで GLS の残差は $\Sigma^{-1}$ が定める内積で計画空間と直交する。元の座標における当てはめ行列 $H_\Sigma=X(X^{\mathsf T}\Sigma^{-1}X)^{-1}X^{\mathsf T}\Sigma^{-1}$ は冪等だが、一般の $\Sigma$ では対称とは限らない。

:::example[一次自己相関を差分で取り除く]
$\varepsilon_1$ の分散を $\sigma^2$ とし、$\varepsilon_i=\rho\varepsilon_{i-1}+\xi_i$、$|\rho|<1$、$\xi_i$ は過去と独立で分散 $(1-\rho^2)\sigma^2$ とする。逐次代入で $\operatorname{Cov}(\varepsilon_i,\varepsilon_j)=\rho^{|i-j|}\sigma^2$ になる。第 1 行はそのまま、第 $i\ge2$ 行は $(Y_i-\rho Y_{i-1})/\sqrt{1-\rho^2}$ とし、計画にも同じ操作をすれば誤差共分散は $\sigma^2I$ になる。例えば $\rho=1/2$、切片だけで $y=(1,4,5)$ とすると、変換後の応答は $(1,7/\sqrt3,6/\sqrt3)$、切片列は $(1,1/\sqrt3,1/\sqrt3)$ である。積和は $16/3$、列のノルム二乗は $5/3$ なので推定値は $16/5$、分散は $3\sigma^2/5$ である。元の単純平均 $10/3$ とは端点への重みが異なる。
:::

:::example[相関があると負の重みも現れる]
切片モデルの共分散係数が $\Sigma=\begin{pmatrix}1&3/2\\3/2&4\end{pmatrix}$ の場合、行列式は $7/4>0$ である。$\Sigma^{-1}\mathbf1$ は $(5/2,-1/2)^{\mathsf T}$ に比例するので、GLS 重みは $(5/4,-1/4)$ になる。$y=(3,7)$ なら推定値は $2$、分散は $\sigma^2/(\mathbf1^{\mathsf T}\Sigma^{-1}\mathbf1)=7\sigma^2/8$ である。第 2 観測は第 1 観測と同じ方向の誤差を含むため、その一部を差し引くと分散が減る。
:::

### 重みを誤った場合の共分散

実際の共分散を $\Omega$、当てはめ時の正定値重みを $W$ とする。$A=(X^{\mathsf T}WX)^{-1}X^{\mathsf T}W$ とすると $\widehat\beta_W=AY$ は $AX=I$ により不偏であり、共分散は
$$
\operatorname{Cov}(\widehat\beta_W)
=(X^{\mathsf T}WX)^{-1}X^{\mathsf T}W\Omega WX(X^{\mathsf T}WX)^{-1}
$$
となる。$\Omega=\sigma^2 W^{-1}$ が成り立つと仮定する場合、この式を $\sigma^2(X^{\mathsf T}WX)^{-1}$ に簡約できる。$\Omega$ の推定から重みを作る場合には重みが応答とともに変動するので、有限標本の不偏性を $AX=I$ だけから結論できない。

:::example[二観測の精度を入れ替えた場合]
真の分散が $1,9$ の独立な切片モデルに誤って $1/10,9/10$ の重みを使うと分散は $(1+729)/100=73/10$ になる。真の精度を使う $9/10,1/10$ なら分散は $9/10$ である。誤ったモデルの式でも推定分散を $9/10$ と計算してしまうため、重みに入れた仮定は点推定と推測の両方に効く。
:::

## 回帰診断

残差が小さく見えても、その観測が当てはめを強く引いている場合がある。各観測の幾何学的な位置と、除いたときの変化を別に調べる。

:::proposition[てこ比と削除残差]{#prop-stat-leverage}
$X$ は列フルランク、$\operatorname{Cov}\varepsilon=\sigma^2I$ とし、$V=(X^{\mathsf T}X)^{-1}$、$e=(I-H)Y$ とおく。$h_i=H_{ii}$ を :term[てこ比]{en="leverage" yomi="てこひ"} という。$0\le h_i\le1$、$\sum_i h_i=p$、$\operatorname{Var}(e_i)=\sigma^2(1-h_i)$ である。$h_i<1$ なら $i$ を除いた係数は $\widehat\beta_{(-i)}=\widehat\beta-Vx_i e_i/(1-h_i)$ であり、削除残差は $e_i/(1-h_i)$ となる。
:::

:::proof
射影の対角は標準基底の射影ノルム二乗であり、跡は階数である。残差共分散は $\sigma^2(I-H)^2$ なので対角から分散が出る。削除後の正規方程式は $(X^{\mathsf T}X-x_ix_i^{\mathsf T})b=X^{\mathsf T}Y-x_iY_i$ である。上記の $b$ を代入し $x_i^{\mathsf T}Vx_i=h_i$ を用いれば一致する。$h_i<1$ なら $I-(X^{\mathsf T}X)^{-1/2}x_ix_i^{\mathsf T}(X^{\mathsf T}X)^{-1/2}$ が正定値なので解は一意である。
:::

:::example[切片モデルでの削除]
$(1,2,6)$ の平均は $3$ で、最後の残差は $3$、てこ比は $1/3$ である。削除残差は $9/2$ で、実際に $6-(1+2)/2=9/2$ である。
:::

:::example[Cook の距離]
除去による全当てはめ値の二乗変化を $pS^2$ で割ると、:ref[prop-stat-leverage] から $D_i=e_i^2h_i/[pS^2(1-h_i)^2]$ となる。$p=2,S^2=1,e_i=1,h_i=1/2$ では $D_i=1$ である。残差図の曲がりは平均構造、広がりの変化は分散構造、単一点の大きい $D_i$ は影響度を調べる手掛かりになる。
:::

### 削除した観測を用いない分散で標準化する

$h_i<1$ とする。削除後の平方和の最小値は $\mathrm{RSS}_{(-i)}=\mathrm{RSS}-e_i^2/(1-h_i)$ になる。実際、任意の $b=\widehat\beta+d$ で全平方和は $\mathrm{RSS}+d^{\mathsf T}V^{-1}d$、削除した項は $(e_i-x_i^{\mathsf T}d)^2$ である。:ref[prop-stat-leverage] の $d=-Vx_i e_i/(1-h_i)$ を入れると差が得られる。$n>p+1$ の正規モデルでは $S^2_{(-i)}=\mathrm{RSS}_{(-i)}/(n-p-1)$ とし、
$$
t_i=\frac{e_i}{S_{(-i)}\sqrt{1-h_i}}
$$
は $t_{n-p-1}$ に従う。これを示すには、削除残差 $Y_i-x_i^{\mathsf T}\widehat\beta_{(-i)}$ が削除後の残差平方和と独立であることを使う。削除した $Y_i$ は残りの観測すべてと独立であり、残りの標本の係数と残差は :ref[thm-stat-normal-linear] で独立である。また削除残差は $e_i/(1-h_i)$ なので分散は $\sigma^2/(1-h_i)$ である。標準化して F や t の比の定義を使えば結論が従う。

:::example[内部と外部で異なる標準化]
切片だけの標本 $(1,2,6)$ では $\mathrm{RSS}=14$、最後の $e_i=3$、$h_i=1/3$ である。従って削除後の平方和は $14-9/(2/3)=1/2$ であり、外部標準化残差は $3\sqrt3$ となる。元の標本分散を使う内部標準化の値は $3/\sqrt{14/3}$ である。大きな残差を分母の計算に含めると値が小さくなり得る。
:::

### 内部標準化残差の有限標本分布

残差 $e_i$ を $S\sqrt{1-h_i}$ で割った値は、分子のデータを $S$ の計算にも使う。この依存を残差空間で追うと、分布が有界になることを示せる。$\nu=n-p>1$、$h_i<1$ とし、第 $i$ 標準基底を $b_i$ とする。残差空間内の単位ベクトル $u=(I-H)b_i/\sqrt{1-h_i}$ を最初に取ると、直交座標において
$$
\frac{e_i}{\sigma\sqrt{1-h_i}}=Z_1,\qquad
\frac{\mathrm{RSS}}{\sigma^2}=Z_1^2+\cdots+Z_\nu^2
$$
である。$Z_j$ は独立標準正規なので、内部標準化の二乗を $\nu$ で割った量は $Z_1^2/\sum_j Z_j^2$ である。独立な $\chi^2_1,\chi^2_{\nu-1}$ の和と比に変数変換すれば、これは $\operatorname{Beta}(1/2,(\nu-1)/2)$ になる。比は $1$ 以下であるため、内部標準化残差の絶対値は $\sqrt\nu$ 以下である。一方、削除後の平方和は $\sigma^2\sum_{j=2}^\nu Z_j^2$ であり、外部標準化ではこの有界性がない。

:::example[残差がすべて小さく見える点]
$\nu=3$、$h_i=1/2$、$e_i=2$、$\mathrm{RSS}=9$ とする。内部標準化の二乗は $4/[(9/3)(1/2)]=8/3$ で、上限 $3$ に近い。削除平方和は $9-4/(1/2)=1$、$S_{(-i)}^2=1/2$ なので外部標準化残差は $4$ となる。一つの観測が残差平方和の大半を占めると、内部標準化の分母も大きくなる。
:::

### 留一法の予測誤差と誤差モデルの診断

全ての $h_i<1$ とする。観測 $i$ を使わない予測の二乗誤差を合計した
$$
\mathrm{PRESS}=\sum_i\left(\frac{e_i}{1-h_i}\right)^2
$$
を :term[予測残差平方和]{en="prediction residual sum of squares" yomi="よそくざんさへいほうわ"} という。:ref[prop-stat-leverage] により再当てはめを $n$ 回行わずに計算できる。$h_i=1$ の場合にはその観測を除くと階数が下がるため、この式は使えない。実際 $\norm{(I-H)b_i}^2=1-h_i=0$ であり、$e_i=0$ はその点で予測が正確という情報を与えない。

:::example[三点直線の留一予測]
$x=(0,1,2)$、$y=(1,2,5)$ の当てはめでは残差が $(1/3,-2/3,1/3)$、てこ比が $(5/6,1/3,5/6)$ になる。これは中心化した $x$ で $h_i=1/3+(x_i-1)^2/2$ と書けるためである。削除残差は $(2,-1,2)$、従って $\mathrm{PRESS}=9$ である。訓練時の平方和は $2/3$ と小さいが、端の点を除くと残りの二点からその点へ外挿するため予測が変わりやすい。
:::

:::example[同じ残差成分でも影響が異なる]
$p=2,S^2=1$ とし、二つの点で $e_i=1/2$ が同じ、てこ比が $1/4$ と $3/4$ であるとする。Cook の距離は前者で $(1/4)(1/4)/[2(3/4)^2]=1/18$、後者で $(1/4)(3/4)/[2(1/4)^2]=3/2$ である。分母が $(1-h_i)^2$ なので、てこ比の差が影響の大きな差になる。一点だけの影響度を測るため、似た外れ点が複数ある場合には一緒に除いてみたときの変化も別に調べる必要がある。
:::

残差図で気付いた特徴を仮定のどの部分と照合するかを明確にすると、次の診断を選べる。平均の曲がりを調べるなら、説明変数の順序で残差平均を追う。分散が増える形かを調べるなら、分散が $\sigma^2(1-h_i)$ であることを考えて標準化した残差の広がりを見る。系列の順序がある場合は、残差の隣り合う成分の積も手掛かりになる。例えば Durbin–Watson の統計量 $\sum_{i=2}^n(e_i-e_{i-1})^2/\sum_i e_i^2$ は、展開すると $2-[e_1^2+e_n^2+2\sum_{i=2}^n e_ie_{i-1}]/\sum_i e_i^2$ である。正の隣接積が大きいと値は小さくなる。帰無でも残差の共分散は $\sigma^2(I-H)$ なので、その分布の評価は計画に依存する。

## モデル選択と情報量規準（AIC・BIC）

変数を増やすと訓練標本への当てはめは改善するため、その改善だけでモデルを選ぶと複雑な方に寄る。予測と周辺尤度では、複雑さへの補正の導き方が異なる。

:::definition[情報量規準]{#def-stat-aic-bic}
最大対数尤度 $\ell(\widehat\theta)$、自由パラメータ数 $k$、標本数 $n$ とする。$\mathrm{AIC}=-2\ell(\widehat\theta)+2k$、$\mathrm{BIC}=-2\ell(\widehat\theta)+k\log n$ とし、小さい値を比較する。未知分散を推定する正規回帰では分散も $k$ に含める。
:::

既知分散の正規回帰では $2p$ の補正を厳密に導ける。独立な再観測 $Y'$ が同じ真の平均 $m$ と共分散 $\sigma^2 I$ を持つとする。$E\norm{Y'-HY}^2=\norm{(I-H)m}^2+(n+p)\sigma^2$ である。一方 $E\norm{Y-HY}^2=\norm{(I-H)m}^2+(n-p)\sigma^2$ となる。差は $2p\sigma^2$ なので、正規負対数尤度の二倍の尺度では補正 $2p$ を加える。

BIC は事前密度を掛けた周辺尤度の Laplace 近似から得られる。パラメータの次元を固定し、内点最大値 $\widehat\theta$ が真値 $\theta_0$ に確率収束するとする。さらに正定値行列 $I$ に対して $\ell(\widehat\theta+h/\sqrt n)-\ell(\widehat\theta)\to-h^{\mathsf T}Ih/2$ が $h$ のコンパクト集合上で一様に確率収束し、局所積分を可積分な Gaussian 上界で支配でき、外側の積分が $e^{\ell(\widehat\theta)}n^{-k/2}$ に比べて無視できるとする。$\theta=\widehat\theta+h/\sqrt n$ に変換すると積分は $e^{\ell(\widehat\theta)}n^{-k/2}$ に正の有界な因子を掛けたものになる。実際、事前密度が真値で連続正なら支配収束後の因子は $\pi(\theta_0)(2\pi)^{k/2}|I|^{-1/2}$ である。負対数の二倍を取ると BIC と有界な差になる。境界や識別不能なモデルではこの変数変換の近似が成立するか確認する必要がある。

:::example[追加変数への罰則]
一変数を追加して最大対数尤度が $3/2$ 改善したとする。AIC の差は $-3+2=-1$ なので追加を選ぶ。$n=100$ で BIC の差は $-3+\log100>0$ なので元のモデルを選ぶ。
:::

:::example[同次元なら適合度で比較]
同じデータで二つの正規回帰の自由パラメータ数が等しく、残差平方和が $10,12$ とする。未知分散の最尤値は残差平方和を $n$ で割った値なので、最大化後の二倍の負対数尤度の差は $n\log(10/12)<0$ となる。両規準とも残差平方和 $10$ を選ぶ。
:::

### 予測誤差と共分散による補正

観測 $Y$ から作った任意の二乗可積分な当てはめ $\widehat m(Y)$ に対し、独立な $Y'$ は $Y$ と同じ平均および共分散を持つとする。$E\norm{Y'-\widehat m}^2$ から $E\norm{Y-\widehat m}^2$ を引くと、両辺の $E\norm Y^2$ と $E\norm{\widehat m}^2$ が相殺され、残りは $2\sum_i\operatorname{Cov}(Y_i,\widehat m_i)$ となる。線形な当てはめ $\widehat m=AY$ と共分散 $\sigma^2I$ ではこの差が $2\sigma^2\tr A$ になる。通常の最小二乗では $\tr H=p$ であり、縮小して当てはめると跡も縮む。

:::example[リッジ回帰の予測補正]
$X^{\mathsf T}X=\diag(4,1)$ で、係数に罰則 $\lambda\norm b^2$ を加える。正規方程式から当てはめ行列は $A_\lambda=X(X^{\mathsf T}X+\lambda I)^{-1}X^{\mathsf T}$ である。$\lambda=1$ なら $\tr A_\lambda=4/5+1/2=13/10$ であり、独立な再観測に対する平均二乗誤差の補正は $13\sigma^2/5$ である。説明変数が二本であることだけを使うと $4\sigma^2$ になるが、ここでは推定値がデータに追従する程度を対角成分の和で測っている。
:::

### BIC の選択確率と固定罰則の違い

比較する二つの固定計画は入れ子で、誤差の正規分散 $\sigma^2$ は既知とする。次元差 $q>0$ は標本数を増やしても一定とする。:ref[thm-stat-linear-f] の分子の導出から対数尤度の増加の二倍は
$$
D_n=(\mathrm{RSS}_0-\mathrm{RSS}_1)/\sigma^2
$$
である。小さいモデルが真なら $D_n\sim\chi_q^2$ なので、BIC が大きい方を選ぶ確率 $P(\chi_q^2>q\log n)$ は $0$ に近づく。AIC の対応する確率は $P(\chi_q^2>2q)>0$ であり標本数によらない。この違いは、AIC の予測補正と BIC の周辺尤度の近似から生じる。

大きいモデルが真で、小さいモデルに追加される平均成分のノルム二乗を $\sigma^2\lambda_n$ とする。$\lambda_n/n\to c>0$ なら $D_n/n\to c$ が確率収束する。実際、追加空間の正規座標のノルム二乗を展開すると $ED_n=q+\lambda_n$、$\operatorname{Var}(D_n)=2q+4\lambda_n$ になる。正規の三次積率がゼロなので線形項と中心化した二乗項の共分散はゼロである。よって Chebyshev の不等式を $D_n/n$ に適用でき、$2q/n$ と $q\log n/n$ はどちらもゼロへ行く。両規準が大きい方を選ぶ確率は $1$ に近づく。この結論は固定した次元差と信号強度の仮定を使う。

:::example[二方向を加えたときの過剰選択確率]
$q=2$ なら中心カイ二乗の上側確率は $P(\chi_2^2>t)=e^{-t/2}$ である。小さいモデルが真の場合、BIC が二方向を加える確率は $e^{-(2\log n)/2}=1/n$ となり、$n=50$ なら $1/50$ である。AIC での確率は $e^{-2}$ であり、同じ $n$ でも別の値になる。これらは共通の既知分散を用いる二候補での確率である。
:::

### 有限標本での AIC の補正

同じ $X$ で再観測する場合の予測負対数尤度を考える。未知分散を $\widehat v=\mathrm{RSS}/n$ で推定し、真の平均が $\Img X$ に入るとする。$Y'$ を独立な再観測とすれば、$Y'-HY$ は平均ゼロで $\mathrm{RSS}$ と独立であり、そのノルム二乗の期待値は $(n+p)\sigma^2$ である。$\nu=n-p>2$ なら $\chi_\nu^2$ の密度を積分して $E[(\chi_\nu^2)^{-1}]=1/(\nu-2)$ を得る。従って訓練負対数尤度の二倍に含まれる $\mathrm{RSS}/\widehat v=n$ を、再観測の期待値で置き換えた差は
$$
\frac{n(n+p)}{n-p-2}-n
=2(p+1)+\frac{2(p+1)(p+2)}{n-p-2}.
$$
対数分散の項は訓練と再観測で同じなので消える。$k=p+1$ とすれば、これは AIC の補正 $2k$ に $2k(k+1)/(n-k-1)$ を加える形になり、:term[修正 AIC]{en="corrected Akaike information criterion" yomi="しゅうせいえーあいしー"} と呼ばれる。ここでは固定計画で平均構造が正しく、$n>p+2$ の場合に導いた。

:::example[分散推定に使える自由度と補正量]
$n=10,p=2$ なら $k=3$ なので $2k=6$、追加補正は $24/(10-3-1)=4$ である。$n=10,p=5$ なら $k=6$ で追加補正は $84/3=28$ になる。後者は訓練誤差を小さくできても、分散推定の下振れによって予測負対数尤度が大きくなる可能性を強く反映する。
:::

## 演習問題

::::exercise{#exr-stat-linear-models-1 level=basic}
切片だけの標本 $(2,4,6)$ の最小二乗値と残差平方和を求めよ。

:::solution
平均は $4$ で、残差 $(-2,0,2)$ の二乗和は $8$ である。
:::
::::

::::exercise{#exr-stat-linear-models-2 level=basic}
$n=15,p=4$ で残差平方和が $22$ の場合、分散の不偏推定値を求めよ。

:::solution
残差自由度は $11$ なので $22/11=2$ である。
:::
::::

::::exercise{#exr-stat-linear-models-3 level=basic}
$n=10,p=3,q=1$、全残差平方和 $14$、制約付き $20$ での F 値を求めよ。

:::solution
増分 $6$ を $q=1$ で割り、残差平均平方 $14/7=2$ で割るので $F=3$ である。
:::
::::

::::exercise{#exr-stat-linear-models-4 level=basic}
切片だけで $n=5$ のとき、各観測の $h_i$ を求めよ。

:::solution
$H=\mathbf1\mathbf1^{\mathsf T}/5$ なので対角の値は全て $1/5$ である。
:::
::::

::::exercise{#exr-stat-linear-models-5 level=advanced}
$2\times3$ の均衡配置で各セルに $4$ 回反復がある。交互作用と誤差の自由度を求めよ。

:::solution
各行和と列和がゼロの交互作用の自由度は $(2-1)(3-1)=2$ である。各セルの残差は和ゼロの $3$ 次元なので、誤差は $6\cdot3=18$ 次元である。
:::
::::

::::exercise{#exr-stat-linear-models-6 level=advanced}
独立二観測の分散が $1,9$ の切片モデルで GLS の重みと分散を求めよ。

:::solution
精度 $1,1/9$ を正規化して $9/10,1/10$ となる。分散は $(9/10)^2+9(1/10)^2=9/10$ である。
:::
::::

::::exercise{#exr-stat-linear-models-7 level=advanced}
$r=(I-H)Y$ と当てはめ値 $HY$ が無相関であることを示せ。正規性がなければどこまで言えるか。

:::solution
交差共分散は $\sigma^2(I-H)H=0$ である。これは二次積率の条件だけで成立する。独立性は一般の無相関からは従わず、正規モデルでは直交座標の独立性を別に使う。
:::
::::

::::exercise{#exr-stat-linear-models-8 level=advanced}
自由パラメータが二つ増え、最大対数尤度が $5/2$ 増えた。AIC 差を求めよ。

:::solution
新モデルの値から旧モデルの値を引くと $-2\cdot5/2+2\cdot2=-1$ である。従って新モデルを選ぶ。
:::
::::

::::exercise{#exr-stat-linear-models-9 level=advanced}
計画行列の二列を $u$ と $u+v$ とし、$u,v,w$ は相互に直交する単位ベクトルとする。$y=2u+3v+4w$ で、第 2 係数と、$u$ だけを残したモデルを使う場合の残差平方和の増分を求めよ。第 1 係数も求めよ。

:::solution
$u$ への射影を除くと第 2 列は $v$、応答は $3v+4w$ になる。よって :ref[thm-stat-partial-regression] で第 2 係数は $3$ である。全モデルの当てはめは $2u+3v$ なので第 1 係数は $2-3=-1$ である。全モデルの残差は $4w$ で平方和 $16$、$u$ だけのモデルでは残差 $3v+4w$ で平方和 $25$ になる。差は $9$ であり、追加方向 $v$ への射影の二乗 $3^2$ と一致する。
:::
::::

::::exercise{#exr-stat-linear-models-10 level=advanced}
独立な二群の標本数が $2,4$、平均が $1,4$、群内平方和の合計が $12$ である。共通分散の正規モデルで二群の平均差 $0$ を検定する F 統計量を求め、傾き一つの t 統計量との関係を示せ。

:::solution
群平均差の推定値は $3$ であり、$\sigma^2$ で割った分散は $1/2+1/4=3/4$ である。全モデルの係数は二群平均の二つ、残差自由度は $6-2=4$ なので $S^2=12/4=3$ である。よって t 値は $3/\sqrt{3\cdot3/4}=2$ である。平均差 $0$ を課すと増える平方和は $3^2/(3/4)=12$ なので、F 値は $12/3=4$ になる。自由度は $(1,4)$ であり、同じ制約で計算した t 値の二乗である。
:::

## 確認テスト

::::quiz
Gauss–Markov の比較対象を選べ。

- [x] 線形で不偏な規則
- [ ] 全ての偏りを許す決定規則
- [ ] 観測を用いない定数のみ

:::explanation
不偏性 $AX=I$ から、重みの差が計画空間に直交することを使う。偏りを許すとこの条件は成立しない。
:::

::::quiz{answer="3" tol="1e-6"}
$n=12,p=4,q=2$ で全平方和 $16$、制約付き平方和 $28$ の F 値を答えよ。

:::explanation
分子は $(28-16)/2=6$、分母は $16/(12-4)=2$ なので $3$ である。
:::
::::

::::quiz
予測誤差の分散に、平均応答の標準誤差にはない項が入る理由を選べ。

- [x] 未観測の新しい個体の誤差が加わる。
- [ ] 毎回計画行列の全要素が変わる。
- [ ] 新しい観測には平均が存在しない。

:::explanation
新観測の予測誤差は独立な新誤差と平均推定誤差の差である。独立な二つの分散が加算される。
:::
::::

::::quiz{answer="0.8" tol="1e-6"}
独立な二観測の分散が $1,4$ のとき、同一平均に対する GLS の分散を答えよ。

:::explanation
それぞれの精度に比例する重みは $4/5,1/5$ である。独立性から分散は $16/25+4/25=4/5$ となる。
:::
::::

::::quiz{answer="9" tol="1e-6"}
切片を含む直線回帰で $(x,y)=(0,1),(1,2),(2,5)$ のとき、各点を一つずつ除いた予測の残差平方和 $\mathrm{PRESS}$ を答えよ。

:::explanation
全点で当てはめると残差は $(1/3,-2/3,1/3)$ である。中心化した $x$ は $(-1,0,1)$ なので、てこ比は $h_i=1/3+(x_i-1)^2/2$ から $(5/6,1/3,5/6)$ になる。各残差を $1-h_i$ で割ると $(2,-1,2)$ であり、二乗和は $4+1+4=9$ である。
:::
