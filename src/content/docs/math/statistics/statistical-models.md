## この章の目標

- 観測の分布から識別できる量を見分ける。
- 指数型分布族を自然パラメータで表示し、積率を導く。
- 位置と尺度の変換に従う決定規則を構成する。
- 複数の決定規則をリスクで比較し、縮約で残る情報を説明する。

## 統計的モデルとパラメータの識別可能性

同じセンサーで測定を繰り返すと、測定値は回ごとに変わる。そこで、観測値を直接固定する代わりに、未知の状態に応じて観測値がどのような頻度で現れるかを定める。確率空間と分布の定義には [確率論](/math/probability/probability-spaces/) を用いる。

:::definition[モデルと識別可能性]{#def-stat-model}
可測空間 $(\mathcal X,\mathcal B)$ 上の確率測度の族 $(P_\theta)_{\theta\in\Theta}$ を :term[統計的モデル]{en="statistical model" yomi="とうけいてきもでる"} という。$\mathcal X$ は標本空間、$\Theta$ はパラメータ空間である。写像 $\theta\mapsto P_\theta$ が単射であれば、パラメータは :term[識別可能]{en="identifiable" yomi="しきべつかのう"} である。関数 $\psi:\Theta\to\R^k$ が識別可能であるとは、$P_\theta=P_{\theta'}$ から $\psi(\theta)=\psi(\theta')$ が従うことである。
:::

各 $P_\theta$ が同じ $\sigma$ 有限測度 $\nu$ に関して密度 $p_\theta$ を持つとき、モデルを支配されたモデルという。離散モデルなら数え上げ測度、連続モデルなら Lebesgue 測度が基本である。分布の等しさは密度の $\nu$ ほとんど至る所での等しさと同値である。観測 $x$ を固定した関数 $\theta\mapsto p_\theta(x)$ を :term[尤度]{en="likelihood" yomi="ゆうど"} という。密度の積分変数は $x$ なので、尤度を $\theta$ 上で積分しても一般に $1$ にはならない。

各 $\theta$ で密度を零集合上だけ変更しても $P_\theta$ は同じである。ただし、零集合が $\theta$ ごとに異なると、固定した $x$ での尤度は変わり得る。例えば $\operatorname{Unif}(0,\theta)$ の密度で $x=\theta$ を含める版と除く版は、同じ確率法則を与える。$x>0$ を観測すると、前者では尤度が $\theta=x$ で最大になり、後者では $\theta\downarrow x$ で上限に近づく。尤度を点ごとに比較する際は、各モデルで指定した密度の版を用いる。

:::example[二つのオフセット]
$X$ が平均 $a+b$、分散 $1$ の正規分布に従うとする。$(a,b)=(1,2)$ と $(2,1)$ は同じ観測法則を与える。期待値は $a+b$ なので和は識別可能であるが、$a$ を単独で推測するには、例えば $b$ を既知にするか、$b$ のみに依存する観測を追加する必要がある。
:::

:::example[上限で打ち切られる観測]
潜在変数 $Z$ が区間 $[0,\theta]$ 上の一様分布に従い、記録装置が $X=\min(Z,2)$ を返すとする。$0<\theta\le2$ では分布の右端が $\theta$ であり、$\theta>2$ では $P_\theta(X=2)=1-2/\theta$ から $\theta$ を復元できる。このモデルの共通測度には $[0,2)$ 上の Lebesgue 測度と $2$ の点質量の和を使える。連続部分の密度だけを尤度に使うと、上限に達した記録の情報を落とす。
:::

:::proposition[識別と反復観測]{#prop-stat-identification}
同じ分布の独立な観測を $n\ge1$ 個得るモデルでは、$P_\theta=P_{\theta'}$ と $P_\theta^{\otimes n}=P_{\theta'}^{\otimes n}$ が同値である。したがって、すべての $\theta$ で $\psi(\theta)$ に確率収束する推定量列が存在するなら、$\psi$ は識別可能である。
:::

:::proof
正方向は積測度の同一性による。逆方向は第 $1$ 座標への周辺化で従う。$\psi(\theta)\ne\psi(\theta')$ なら、それぞれを中心とする互いに交わらない開球を選べる。推定量の法則は両パラメータで同じであるため、二つの球に入る確率がともに $1$ に近づくことはない。
:::

未知量のうち調べたい $\psi$ 以外の部分を :term[攪乱パラメータ]{en="nuisance parameter" yomi="かくらんぱらめーた"} という。例えば正規標本で平均を推定するとき、未知の分散は攪乱パラメータである。識別可能であることは分布が異なることを保証するが、手元の標本でどれほど見分けられるかは標本数と分布間の距離にも依存する。

### 固定試行数と可変試行数の標本空間

独立な検査を $n$ 回行い、不良が見つかった回数を記録すると、観測空間は $\{0,\ldots,n\}$ である。不良率を $0<p<1$ とすれば、この確率質量は $\binom ns p^s(1-p)^{n-s}$ になる。別の計画として、最初の不良が見つかるまで検査し、検査回数 $N$ を記録する。この場合の観測空間は $\{1,2,\ldots\}$ であり、質量は $(1-p)^{k-1}p$ になる。$s=1$ と $N=n$ はどちらも「$n$ 回のうち一回が不良」と読めるが、前者には最後の観測が不良である条件がない。この違いが $n$ 倍の質量の差になる。$p=0$ まで許す計画では、停止しない結果 $N=\infty$ も観測空間に加える。

:::example[有限母集団の抽出計画]
$N$ 個中 $K$ 個が不良の集団から同じ確率で $n$ 個を置換なしに選ぶ。不良個数 $S$ の分布は、全 $\binom Nn$ 部分集合のうち、不良から $s$ 個、良品から $n-s$ 個を選ぶ数を数えて
$$
P_K(S=s)=\frac{\binom Ks\binom{N-K}{n-s}}{\binom Nn}
$$
となる。各抽出位置に不良が入る確率は $K/N$ なので $E_K S=nK/N$ である。$n>0$ ならこの期待値から $K$ を識別できる。$N=5,K=2,n=2$ では $s=0,1,2$ の確率は $3/10,6/10,1/10$ であり、独立 Bernoulli 二試行の $(9/25,12/25,4/25)$ とは異なる。抽出方式をモデルの一部として指定する必要がある。
:::

### パラメータ化と同じ分布を表す点

モデルの分布の集合が同じでも、パラメータの選び方は複数ある。例えば二成分混合 $p(x)=w f(x-\mu_1)+(1-w)f(x-\mu_2)$ では $(w,\mu_1,\mu_2)$ と $(1-w,\mu_2,\mu_1)$ が同じ密度を与える。$\mu_1<\mu_2$ と順序を決めれば、この交換による非識別性を除ける。一方、$\mu_1=\mu_2$ を許せば、どの $w$ でも分布が同じという別の非識別性がある。この場合は順序だけでは $w$ を定められない。

:::example[分布の重なりと判別の限界]
二つの候補密度 $f,g$ が等確率で与えられ、誤りの損失を両方向で $1$ とする。$x$ を見て $g$ を選べば誤りの密度は $f(x)/2$、$f$ を選べば $g(x)/2$ なので、最小平均誤りは $\tfrac12\int\min(f,g)$ となる。$\min(f,g)=(f+g-|f-g|)/2$ より、この値は $\tfrac12(1-\tfrac12\int|f-g|)$ である。Bernoulli の $p=2/5$ と $3/5$ なら $\int|f-g|=2/5$ なので最小平均誤りは $2/5$ である。分布が識別できても、有限回の観測で誤りが消えるとは限らない。
:::

### 観測計画と尤度の測度

観測値が上限で止まるとき、上限に達したこと自体が一件の観測になる。一方、上限を超えた個体を調査対象から外すと、得られるのは上限未満を条件とした観測である。この二つの装置を区別するため、潜在的な正の測定値を $Z$、密度と分布関数を $f_\theta,F_\theta$ とし、固定した上限を $c>0$ とする。

:::definition[打ち切りと切断]{#def-stat-censor-truncate}
$Z<c$ なら $Z$ を、$Z\ge c$ なら上限 $c$ に達した印を記録する方式を :term[右打ち切り]{en="right censoring" yomi="みぎうちきり"} という。$Z<c$ を満たす対象だけから標本を取り、除外個数を記録しない方式を :term[右切断]{en="right truncation" yomi="みぎせつだん"} という。本節では $Z$ は連続分布に従うとする。
:::

打ち切りでは $\nu$ を $(0,c)$ 上の Lebesgue 測度と $c$ の点質量の和とする。任意の可測集合 $B$ に対し観測 $X=\min(Z,c)$ の法則は
$$
P_\theta(X\in B)=\int_{B\cap(0,c)}f_\theta(x)\,\dd x
+\mathbf1_{\{c\in B\}}[1-F_\theta(c)]
$$
である。切断時は $P_\theta(Z\in B,Z<c)/P_\theta(Z<c)$ を計算するため、$F_\theta(c)>0$ のとき密度は $f_\theta(x)\mathbf1_{\{0<x<c\}}/F_\theta(c)$ になる。正規化する項そのものが未知量を含む。試行を何回行ってそのうち何回除外したかが分かれば、その件数にも尤度への寄与がある。

:::example[同じ一組の正の測定値が与える情報]
$Z$ は率 $\lambda$ の指数分布に従い、上限を $2$ とする。三件の打ち切り観測 $(1,1/2,2)$ なら、最初の二件は密度、最後の一件は生存確率を寄与させる。全尤度は
$$
\lambda^2 e^{-\lambda(1+1/2+2)}
=\lambda^2 e^{-7\lambda/2}
$$
である。対数微分は $2/\lambda-7/2$、二階微分は $-2/\lambda^2$ なので最大は $4/7$ である。一方、切断された分布から観測数を二件に固定して $(1,1/2)$ を得た場合の尤度は $\lambda^2e^{-3\lambda/2}/(1-e^{-2\lambda})^2$ である。二つの式でどの部分が異なるかを見れば、観測値だけから実験計画を決められないことが分かる。
:::

同じ確率法則を別の測度で表すことと、測定対象を変えることも区別できる。共通測度 $\nu$ に対して $\nu'=w\nu$、$0<w(x)<\infty$ とすると、新しい密度は $p_\theta(x)/w(x)$ である。各観測点で尤度の全体に同じ因子が掛かるため、固定した密度の版の上では尤度比は変わらない。また、観測を微分同相 $y=g(x)$ で変換したときも、新密度に掛かる Jacobian は $\theta$ を含まない。

:::example[測定単位を変更する]
率 $\lambda$ の指数変数について $Y=3X$ とすると、密度は $(\lambda/3)e^{-\lambda y/3}\mathbf1_{\{y>0\}}$ である。$x=2$ と $y=6$ の観測から $\lambda=1$ と $\lambda=2$ の尤度を比べる。密度の比 $p_2(2)/p_1(2)=2e^{-2}$ は、新しい測定単位でも同じ $2e^{-2}$ になる。尺度の変更を通じて $\lambda$ というパラメータの意味を保っているためである。
:::

### 識別集合と局所的な区別

仮に確率法則 $P$ を誤差なく知っても、その法則を与える $\theta$ が一つとは限らない。実現しうるパラメータの集合 $\{\theta:P_\theta=P\}$ を :term[識別集合]{en="identified set" yomi="しきべつしゅうごう"} という。対象量がこの集合上で一定であることが、その量の識別可能性に当たる。

:::example[誤検出率を別に測定する必要がある場合]
本当の陽性率を $p$、陰性を陽性と誤記録する確率を $a$ とし、陽性はすべて正しく記録されるとする。記録の陽性確率は $q=p+(1-p)a$ である。未知の $a$ が $0\le a\le1/5$、観測法則から決まる $q$ が $2/5$ なら、
$$
p=\frac{q-a}{1-a},\qquad
p\in[1/4,2/5]
$$
となる。右辺は $a$ の減少関数であるため、区間の全点が実現できる。既知の陰性について同じ装置を使い、その陽性率を観測する追加実験があれば、二つの法則から順に $a$ と $p$ を識別できる。
:::

有限次元の観測特性がパラメータの近くで一対一に変化することは、:term[局所識別]{en="local identification" yomi="きょくしょしきべつ"} の判定に使える。$\Theta$ の内点 $\theta_0\in\R^d$ で、観測の $d$ 個の期待値 $m(\theta)$ が $C^1$ 級であり、Jacobian $Dm(\theta_0)$ が正則なら、:ref[thm-anl-inverse-function]{text="逆関数定理"} により、ある近傍で $m$ が単射である。その近傍の同じ分布からは同じ期待値が得られるので、パラメータも一致する。ただし Jacobian が特異でも、例えば $X\sim N(\theta^3,1)$ では平均が $\theta$ の狭義単調関数なので $\theta=0$ も識別できる。逆に $N(\theta^2,1)$ では任意の非零点でこの局所判定が使えるが、正負の対称な点が大域的には残る。

:::example[分散も使って混合比を決める]
密度 $w\phi(x-a)+(1-w)\phi(x+a)$ を考える。$\phi$ は標準正規密度、$a>0$、$0<w<1$ とする。潜在符号 $B\in\{-1,1\}$ を用いて $X=aB+Z$ と書くと、$Z$ と $B$ の独立性から $EX=a(2w-1)$、$EX^2=1+a^2$ である。例えば $EX=1,EX^2=5$ なら $a=2,w=3/4$ である。$a=0$ を加えると二成分が重なり、同じ二つの期待値をすべての $w$ が与える。分散も使った理由は、正負の平均を相殺する混合比を平均単独では判定できないからである。
:::

### 分離の強さと誤りの下限

二つの観測法則の差を、事象の確率がどこまで離れるかで測ることができる。密度に違いがあってもその差が非常に小さければ、一回の観測で信頼できる判定を行うのは難しい。

:::definition[全変動距離]{#def-stat-tv}
二つの確率測度 $P,Q$ に対し、$d_{\mathrm{TV}}(P,Q)=\sup_B|P(B)-Q(B)|$ を :term[全変動距離]{en="total variation distance" yomi="ぜんへんどうきょり"} という。
:::

:::proposition[全変動距離と二点判別]{#prop-stat-tv-classification}
$P,Q$ の共通密度を $p,q$ とすると、$d_{\mathrm{TV}}(P,Q)=\frac12\int|p-q|\,\dd\nu$ である。$P,Q$ を等確率で与え、誤判定を損失 $1$ とすると、最小平均損失は $(1-d_{\mathrm{TV}}(P,Q))/2$ である。
:::

:::proof
$\int(p-q)=0$ なので、正の部分と負の部分の積分はともに $\tfrac12\int|p-q|$ である。任意の $B$ でその値を確率差の絶対値が超えることはない。$B=\{p>q\}$ で上限を達成する。$P$ を選ぶ確率を $r(x)\in[0,1]$ とすると、平均誤りは
$$
\frac12\int [(1-r(x))p(x)+r(x)q(x)]\,\dd\nu(x)
$$
である。積分の各点で最小を取ると $p>q$ のとき $r=1$、$p<q$ のとき $r=0$ であり、残る積分は $\frac12\int\min(p,q)$ になる。$\min(p,q)=(p+q-|p-q|)/2$ を代入すればよい。
:::

:::example[観測の回数を増やす効果]
二つの一様分布 $\operatorname{Unif}(0,1)$ と $\operatorname{Unif}(0,2)$ を識別する。独立な $n$ 観測で、全てが $1$ 以下なら前者の積密度 $1$ は後者の $2^{-n}$ より大きい。$1$ を超える観測があれば後者だけが可能である。等確率の誤判定は後者で全観測が $1$ 以下のときに限り、平均誤りは $2^{-n-1}$ となる。$n=3$ では $1/16$ である。共通部分の確率が積で減るため、識別可能性が有限標本の誤りにどう現れるかを計算できる。
:::

### 独立な反復で分布が離れる速さ

二分布の重なりを測る $\rho(P,Q)=\int\sqrt{pq}\,\dd\nu$ を :term[Hellinger 親和度]{en="Hellinger affinity" yomi="へりんがーしんわど"} という。密度の共通因子を打ち消せるので、この値は支配測度の選び方によらない。実際、二つの支配測度で計算した値を比較するには、両者の和を共通の基準とし、そこへの密度変換を使えばよい。両方の分布を支配できる領域では Radon–Nikodym 密度が平方根の積と打ち消し合い、残りの領域では被積分関数が零になる。

$\min(p,q)\le\sqrt{pq}$ を積分し、また $|p-q|=|\sqrt p-\sqrt q|(\sqrt p+\sqrt q)$ に Cauchy–Schwarz の不等式を適用すると
$$
1-\rho(P,Q)\le d_{\mathrm{TV}}(P,Q)\le \sqrt{1-\rho(P,Q)^2}
$$
となる。積密度の平方根を座標ごとに積分すれば、$\rho(P^{\otimes n},Q^{\otimes n})=\rho(P,Q)^n$ である。従って二状態の等重みでの最小誤判定確率は $\rho(P,Q)^n/2$ 以下である。$\rho=1$ となるのは $\int(\sqrt p-\sqrt q)^2=2(1-\rho)=0$ のとき、すなわち二分布が等しいときに限る。

:::example[既知分散の正規位置を見分ける]
$P=N(0,1)$ と $Q=N(a,1)$ に対して $\sqrt{p(x)q(x)}=(2\pi)^{-1/2}\exp[-(x-a/2)^2/2-a^2/8]$ なので、親和度は $e^{-a^2/8}$ である。例えば $a=2$ なら $n$ 回の観測での最小誤判定確率は $e^{-n/2}/2$ 以下になる。二つの平均の差 $a$ が標本数とともに小さくなるときには、この上界の指数 $na^2/8$ も併せて調べる必要がある。
:::

## 指数型分布族

一試行の Bernoulli 確率 $p^x(1-p)^{1-x}$ は、対数を取ると $x$ と定数に分かれる。独立標本では $x$ に掛かる係数を共通にできるため、標本の和だけでパラメータによる尤度の変化を表せる。

:::definition[自然表示]{#def-stat-exponential-family}
可測なベクトル値関数 $T$ と非負の関数 $h$ を固定する。
$$
A(\eta)=\log\int \exp(\eta^{\mathsf T}T(x))h(x)\,\dd\nu(x),
\qquad
p_\eta(x)=h(x)\exp\{\eta^{\mathsf T}T(x)-A(\eta)\}.
\label{eq-stat-natural-density}
$$
積分が有限かつ正となる $\eta$ の集合を自然パラメータ空間といい、この表示を持つ族を :term[指数型分布族]{en="exponential family" yomi="しすうがたぶんぷぞく"} という。$\eta$ は自然パラメータ、$A$ は対数分配関数である。自然空間内の曲面だけで $\eta$ を動かす場合を曲線指数型分布族という。
:::

自然パラメータの許容集合が $\R^d$ の開集合であるとき、この表示を :term[正則な指数型分布族]{en="regular exponential family" yomi="せいそくなしすうがたぶんぷぞく"} と呼ぶ。許容集合を直線に制限した場合は、基準測度と統計量を取り直すと開区間で表示できることがある。例えば $\eta=\eta_0+tv$ と書けるなら、$e^{\eta_0^{\mathsf T}T}h$ を新しい基準因子、$v^{\mathsf T}T$ を新しい統計量として取れる。

:::theorem[対数分配関数の微分]{#thm-stat-log-partition}
自然空間は凸であり、その内点で $\nabla A=E_\eta T$、$\nabla^2 A=\operatorname{Cov}_\eta T$ が成り立つ。さらに $T$ の積率母関数は $E_\eta e^{s^{\mathsf T}T}=\exp\{A(\eta+s)-A(\eta)\}$ である。
:::

:::proof
二つの指数関数の重み付き幾何平均に Hölder の不等式を使うと、凸結合での積分は有限である。積率母関数は密度に $e^{s^{\mathsf T}T}$ を掛けて積分すれば得られる。

内点 $\eta$ の周囲に辺が座標軸と平行な閉立方体を取り、すべての頂点で積分が有限になるようにする。半分の大きさの立方体内では、$T_i$ や $T_iT_j$ を掛けた指数関数の絶対値は、大きい立方体の頂点での指数関数の和の定数倍で抑えられる。実際、各座標の余裕幅を $\varepsilon>0$ とすると多項式は $C e^{\varepsilon\sum_i |T_i|}$ 以下であり、符号に応じて頂点を選べばよい。したがって積分を二回微分できる。$Z=e^A$ とおくと $\partial_i Z/Z=E_\eta T_i$、$\partial_{ij}Z/Z=E_\eta T_iT_j$ なので、対数微分から結論を得る。
:::

自然空間に内点があり、$h\,\dd\nu$ ほとんど至る所で定数となる非零の線形結合 $v^{\mathsf T}T$ がなければ、Hessian は正定値である。実際、方向 $v$ の二次形式は $\operatorname{Var}_\eta(v^{\mathsf T}T)$ である。逆にそのような線形結合があれば、$\eta$ と $\eta+sv$ が自然空間に入るとき両者の密度は等しい。一般にも、二つの自然パラメータが同じ分布を与える条件は、対数密度比を取れば $(\eta-\eta')^{\mathsf T}T$ が定数となることである。

:::example[Bernoulli と Poisson]
Bernoulli 分布では $\eta=\log[p/(1-p)]$、$A=\log(1+e^\eta)$、$T=x$ である。$p=1/4$ なら $A'=1/4$、$A''=3/16$ となる。Poisson 分布（平均 $\lambda>0$）では $h(x)=1/x!$、$\eta=\log\lambda$ であり、指数級数の和から $A=e^\eta$ を得る。したがって $\lambda=3$ では平均も分散も $3$ である。
:::

:::example[正規分布の二つの自然統計量]
平均 $\mu$、分散 $\sigma^2>0$ の正規密度を展開すると、$T=(x,x^2)$ に対する自然パラメータは $(\mu/\sigma^2,-1/(2\sigma^2))$ である。平方完成により $A=\tfrac12\log(\pi/(-\eta_2))-\eta_1^2/(4\eta_2)$ となる。$(\mu,\sigma^2)=(2,4)$ なら $(\eta_1,\eta_2)=(1/2,-1/8)$ であり、$E(X^2)=8$ である。独立標本で必要になる組は $(\sum_i X_i,\sum_i X_i^2)$ であり、共通の $A$ は標本数倍になる。
:::

一様分布 $\operatorname{Unif}(0,\theta)$ では $\theta$ が正密度の範囲を変える。有限な自然パラメータを使う :eqref[eq-stat-natural-density] 型の表示では指数項は常に正なので、この端点モデルは同じ形で扱えない。

### 曲線上の制約と固定された支持

正規自然パラメータ $(\eta_1,\eta_2)=(\mu/v,-1/(2v))$ に $v=\mu^2$、$\mu>0$ を課すと、$\eta_1=1/\mu$、$\eta_2=-\eta_1^2/2$ となる。元の二次元空間では独立に変えられた二方向のうち、許されるのはこの曲線に沿う方向だけである。平均と分散は連動するが、密度を表すときは $x$ と $x^2$ の双方が必要である。例えば $\eta_1=1$ と $\eta_1=2$ での対数密度比の $x$ に依存する部分は $x-3x^2/2$ であり、$\eta_1=1$ と $\eta_1=3$ では $2x-4x^2$ である。二つは互いの定数倍ではない。従って共通の一つの実数値関数に一つの自然係数を掛ける表示ではこの族を表せない。

:::example[多項分布と冗長な表示]
一観測が $k$ 種類のいずれかに属し、確率が正とする。最後のカテゴリを基準にとり、$T_j(x)=\mathbf1_{\{x=j\}}$、$\eta_j=\log(p_j/p_k)$（$j<k$）、$A=\log(1+\sum_{j<k}e^{\eta_j})$ と置けば自然表示が得られる。全 $k$ 個の指示変数を使うと、その和は常に $1$ なので全自然係数を同じ量だけ動かしても分布が変わらない。$p=(1/2,1/3,1/6)$ なら自然係数は $(\log3,\log2)$、分配関数は $\log6$ である。Hessian の交差成分は $-p_1p_2=-1/6$ であり、一観測で二つのカテゴリが同時には起きないことを反映する。
:::

### 基準測度から自然空間を求める

自然空間には、形式上どの係数を入れられるかよりも、分配関数の積分が収束する範囲が効く。離散で有限な台なら全空間でよい。一方、無限の台では密度の裾で指数を打ち消せる範囲を調べる。さらに開集合に含まれない境界点があれば、積分が有限でも、そこで微分して積率を求められるとは限らない。

:::example[形と率が未知のガンマ分布]
$X>0$ の密度を $\beta^\alpha x^{\alpha-1}e^{-\beta x}/\Gamma(\alpha)$ とする。ここで形 $\alpha>0$、率 $\beta>0$ であり、$\Gamma(\alpha)=\int_0^\infty u^{\alpha-1}e^{-u}\,\dd u$ である。$T(x)=(\log x,x)$、$h(x)=\mathbf1_{\{x>0\}}$、自然係数を $\eta=(\alpha-1,-\beta)$ と置く。原点付近で可積分となる条件が $\eta_1>-1$、無限遠で指数減衰する条件が $\eta_2<0$ である。$\eta_2=0$ では両端の収束条件が互いに矛盾する。$u=(-\eta_2)x$ と変換して
$$
A(\eta)=\log\Gamma(1+\eta_1)-(1+\eta_1)\log(-\eta_2)
$$
を得る。よって $E X=- (1+\eta_1)/\eta_2=\alpha/\beta$、$\operatorname{Var}X=(1+\eta_1)/\eta_2^2=\alpha/\beta^2$ である。$(\alpha,\beta)=(3,2)$ なら順に $3/2,3/4$ となる。独立標本には $\sum_i X_i$ に加え $\sum_i\log X_i$ が現れ、率だけが未知の場合と必要な集約量が異なる。
:::

:::example[密度が定義できても積率が発散する境界点]
$h(x)=2x^{-3}\mathbf1_{\{x\ge1\}}$、$T(x)=x$ とする。$\int e^{\eta x}h(x)\,\dd x$ の収束範囲は $\eta\le0$ である。$\eta<0$ では全ての正整数次の積率が有限で、式 :eqref[eq-stat-natural-density] の微分公式を使える。$\eta=0$ では密度の積分が $1$、一次積率が $2$ であるが、二次積率は $2\int_1^\infty x^{-1}\,\dd x=\infty$ となる。自然空間の中でも、内点を指定したことが二階微分の理由になる。
:::

### 平均で表した自然モデル

統計量に冗長な定数関係がない表示を :term[最小表示]{en="minimal representation" yomi="さいしょうひょうじ"} という。すなわち、$v^{\mathsf T}T(x)$ が基準測度 $h\,\dd\nu$ ほとんど至る所で定数になることは、$v=0$ の場合に限る。最小表示で、自然パラメータの範囲に開集合が含まれる場合に、その内部で平均を座標として使える。

:::proposition[平均写像の単射性]{#prop-stat-mean-map}
最小表示の指数型分布族では、自然空間の内部 $\mathcal H^\circ$ 上の写像 $\eta\mapsto m(\eta)=\nabla A(\eta)$ は単射である。また、その像は開集合であり、像から $\mathcal H^\circ$ への逆写像は連続微分可能である。
:::

:::proof
$\eta_1\ne\eta_2$ とし、$v=\eta_2-\eta_1$ とおく。自然空間は凸なので、両点を結ぶ線分はその内部に入る。基本定理と :ref[thm-stat-log-partition] より
$$
v^{\mathsf T}(m(\eta_2)-m(\eta_1))
=\int_0^1 v^{\mathsf T}\nabla^2A(\eta_1+tv)v\,\dd t
=\int_0^1 \operatorname{Var}_{\eta_1+tv}(v^{\mathsf T}T)\,\dd t>0
$$
である。最小性と共通台から積分の各点で分散は正である。従って平均は異なる。正定値な Hessian は正則なので、各点で :ref[thm-anl-inverse-function]{text="逆関数定理"} を使える。各局所逆写像は単射性により重なる範囲で一致するため、全体の逆写像が得られる。
:::

:::example[正規モデルの平均パラメータが動ける範囲]
自然統計量を $(X,X^2)$ とすると、平均写像は $(\eta_1,\eta_2)\mapsto(\mu,\mu^2+\sigma^2)$ である。点 $(m_1,m_2)$ から $\mu=m_1$、$\sigma^2=m_2-m_1^2$ と戻せるので、像は $m_2>m_1^2$ である。$m=(2,5)$ から $(\mu,\sigma^2)=(2,1)$ と自然係数 $(2,-1/2)$ を得る。一方 $m=(2,4)$ は分散ゼロであり、通常の正規密度が与える範囲の外である。標本を全て同じ値にしたときの経験モーメントがこの境界に来る。
:::

有限台の最小表示では、平均が動ける範囲をさらに求められる。$h\,\dd\nu$ のもとで $T$ の値が有限個 $t_1,\dots,t_m$ に限られ、各値が正の基準質量 $h_i=\int_{\{T=t_i\}}h\,\dd\nu$ を持つとする。自然パラメータが一つでも存在すれば、各 $h_i$ は有限である。よって分配関数は全 $\eta\in\R^d$ で有限になる。値の凸包を $C$ とする。最小性は値が真のアフィン超平面に収まらないことと同値である。各 $m(\eta)$ は全ての $t_i$ の厳密に正の重み付き平均なので $C$ の内部に属する。実際、もしそれが境界なら、そこでの支持超平面の線形汎関数に対し全ての $t_i$ が等号を満たすことになり、最小性に反する。

逆に $y\in\operatorname{int} C$ を取り、半径 $\rho>0$ の閉球が $y$ の周囲で $C$ に入るようにする。単位ベクトル $v$ に対し $\max_i v^{\mathsf T}(t_i-y)\ge\rho$ となる。そこで
$$
A(\eta)-\eta^{\mathsf T}y
=\log\sum_i h_i e^{\eta^{\mathsf T}(t_i-y)}
\ge\log\min_i h_i+\rho\norm{\eta}
$$
と評価できる。この連続関数は十分に大きい球の外で値が増すので最小点を持つ。その点で微分はゼロ、従って $m(\eta)=y$ である。狭義凸性により解は一つである。この証明は、経験平均が凸包の境界にあると自然パラメータで尤度の最大点を得られない理由にもなる。

:::example[二項標本の境界]
成功数 $S$ を二項分布で表し、試行数 $4$、自然パラメータ $\eta=\log[p/(1-p)]$ とする。$A(\eta)=4\log(1+e^\eta)$ なので $A'=4p$ である。観測 $S=1$ の対数尤度の導関数は $1-4p$ で、最大は $p=1/4$、$\eta=-\log3$ である。観測 $S=0$ なら導関数は $-4p<0$ であり、最上値は $\eta\to-\infty$ の極限で近づく。自然空間が全実数であっても、最尤点が有限とは限らない。
:::

自然空間の内点 $\eta_1$ と、自然空間内の $\eta_2$ で二つの分布を比較すると、
$$
E_{\eta_1}\log\frac{p_{\eta_1}(X)}{p_{\eta_2}(X)}
=A(\eta_2)-A(\eta_1)-(\eta_2-\eta_1)^{\mathsf T}\nabla A(\eta_1)
$$
である。右辺は凸関数 $A$ と $\eta_1$ での接平面との差なので非負である。$\eta_2$ が $\eta_1$ に近いときは Taylor 展開により、この差は $\tfrac12(\eta_2-\eta_1)^{\mathsf T}\operatorname{Cov}_{\eta_1}(T)(\eta_2-\eta_1)+o(\norm{\eta_2-\eta_1}^2)$ となる。この二次近似は [不偏推定と情報不等式](/math/statistics/point-estimation/) の情報量でも使う。

## 位置尺度族と群変換

単位や原点を変えても、同じ測定の解釈を保ちたい。そこで、観測の変換がパラメータをどのように動かすかを式で追う。

:::definition[位置尺度族と群作用]{#def-stat-location-scale}
基準の密度を $f$ とする。$X=\mu+\sigma Z$、$Z$ の密度が $f$、$\mu\in\R$、$\sigma>0$ であるモデルを :term[位置尺度族]{en="location-scale family" yomi="いちしゃくどぞく"} という。変換 $g_{a,b}(x)=a+bx$（$b>0$）の合成と逆元は
$$
g_{a,b}g_{c,d}=g_{a+bc,bd},\qquad
(g_{a,b})^{-1}=g_{-a/b,1/b}
$$
である。この群を標本の各座標に同時に作用させる。
:::

:::proposition[密度と変換後のパラメータ]{#prop-stat-affine-action}
密度は $\sigma^{-1}f((x-\mu)/\sigma)$ であり、$g_{a,b}(X)$ のパラメータは $(a+b\mu,b\sigma)$ である。
:::

:::proof
変数変換 $z=(x-\mu)/\sigma$ の微分は $1/\sigma$ である。変換後には $a+bX=(a+b\mu)+(b\sigma)Z$ となり、同じ $Z$ が使える。
:::

位置だけの群では尺度を固定し、尺度だけの群では原点を $0$ に固定する。統計量 $T$ が変換後も $T(gx)=T(x)$ を満たすとき、:term[不変統計量]{en="invariant statistic" yomi="ふへんとうけいりょう"} という。二つの標本で値が一致することと、一方を群で動かして他方にできることが同値なら :term[最大不変量]{en="maximal invariant" yomi="さいだいふへんりょう"} である。

:::example[位置尺度の標準化]
$n\ge2$、$x_1\ne x_2$ の集合では、$(\operatorname{sgn}(x_2-x_1),(x_i-x_1)/|x_2-x_1|,\ 3\le i\le n)$ は最大不変量である。各差に同じ正の $b$ が掛かるので不変である。値が一致する二標本 $x,y$ に対し、$b=|y_2-y_1|/|x_2-x_1|$、$a=y_1-bx_1$ とおくとすべての座標が一致する。例えば $(2,5,8)$ と $(1,3,5)$ は符号 $+$、比 $2$ を共有する。
:::

:::example[位置と尺度に応じて動く推定値]
$(1,3,5)$ の平均は $3$ であり、最大値と最小値の差は $4$ である。$g_{2,3}$ で変換すると標本は $(5,11,17)$ となり、平均は $11=2+3\cdot3$、差は $12=3\cdot4$ である。推定したい量と同じ変換則を満たす規則を同変という。平均は位置に、範囲は尺度に同変である。
:::

### 軌道を代表点で表す

群 $G$ の標本空間への :term[作用]{en="group action" yomi="ぐんさよう"} とは、各 $g\in G$ に可測な全単射を対応させ、単位元と合成を保つことである。点 $x$ から移れる点の集合 $Gx$ を :term[軌道]{en="orbit" yomi="きどう"} という。最大不変量はこの軌道を区別する。同じ軌道の点に同じ値を割り当てるだけなら不変量である。最大不変量では、異なる軌道には異なる値を割り当てる。

:::proposition[位置尺度変換の最大不変量]{#prop-stat-standardized-maximal}
$n\ge2$ とする。標本平均 $\bar x$ と $s(x)=\{\sum_i(x_i-\bar x)^2\}^{1/2}$ を使い、$s(x)>0$ では $u(x)=(x-\bar x\mathbf1)/s(x)$ と置く。定数標本で $u(x)=0$ とする。この $u$ は全標本空間で最大不変量である。位置変換だけでは $x-\bar x\mathbf1$、正の尺度変換だけでは非零点の $x/\norm{x}$ と原点の $0$ がそれぞれ最大不変量である。
:::

:::proof
位置尺度変換に対し $\bar x$ は $a+b\bar x$ に、$s$ は $bs$ に移る。従って $u$ は不変である。$x,y$ が非定数で $u(x)=u(y)$ なら $b=s(y)/s(x)$、$a=\bar y-b\bar x$ とすれば $a\mathbf1+bx=y$ となる。定数標本は平行移動で互いに移り、$u=0$ によって他の軌道と区別する。

位置変換に限れば、同じ残差を持つ標本の差は定数ベクトルである。逆に平行移動すれば残差は変わらない。尺度変換では同じ単位方向を持つ二つの非零ベクトルは正の倍数で結ばれ、原点は固定される。これで三つの主張が成り立つ。
:::

任意の可測な不変量 $V$ は、この $u$ を入力とする可測関数で書ける。実際、非定数軌道では $u$ 自体を平均ゼロ、$s=1$ の代表点に選び、定数軌道では原点を代表とする。$V(x)=V(u(x))$ が成り立つので、関数としての可測性も保たれる。このように代表点を明示すると、軌道の区別だけで済ませず、統計量として計算できる形を得る。

:::example[二観測を正の尺度で標準化する]
$x=(1,4)$ の中心化ベクトルは $(-3/2,3/2)$、その長さは $3/\sqrt2$ なので、$u(x)=(-1/\sqrt2,1/\sqrt2)$ である。非定数の二観測では $u$ は二通りだけで、大小順に対応する。$(4,1)$ は $u$ が反対向きであり、$b>0$ では同じ軌道に移せない。一方、負の $b$ も認める群では $g_{5,-1}$ によって二つが結ばれる。どの変換を許すかによって残る情報が変わる。
:::

### 同変規則と一定リスク

モデルに $gX\sim P_{g\theta}$ という関係があり、行動にも群が作用するとする。$\delta(gx)=g\delta(x)$ とすると、観測とともに推定値が移る。これを :term[同変決定規則]{en="equivariant decision rule" yomi="どうへんけっていきそく"} という。損失を変換しても値が同じなら、規則の誤差の分布も軌道ごとに揃う。

:::proposition[不変損失の下での同変リスク]{#prop-stat-equivariant-risk}
$P_{g\theta}$ が $g$ による $P_\theta$ の押し出しで、損失が $L(g\theta,ga)=L(\theta,a)$ を満たすとする。同変な規則では $R(g\theta,\delta)=R(\theta,\delta)$ である。パラメータ空間上の群作用が推移的なら、リスクは全状態で一定である。
:::

:::proof
$P_{g\theta}$ による期待値で観測を $gX$ と置けば
$$
R(g\theta,\delta)
=E_\theta L(g\theta,\delta(gX))
=E_\theta L(g\theta,g\delta(X))
=R(\theta,\delta)
$$
である。どの二つのパラメータ点も群で結ばれる場合を推移的と呼ぶ。このとき等式は任意の二点で成り立つ。
:::

$n\ge2$ の位置推定量で $\delta(x+a\mathbf1)=\delta(x)+a$ なら、$r=x-\bar x\mathbf1$ として $\delta(x)=\bar x+\delta(r)$ である。位置尺度の両方に同変であれば、非定数標本を $x=\bar x\mathbf1+s u$ と書いて
$$
\delta(x)=\bar x+s\,d(u),\qquad d(u)=\delta(u)
$$
となる。逆に、任意の可測関数 $d$ を選んでこの式を使えば、$u$ の不変性と $\bar x,s$ の変換式から同変性を得る。定数標本では任意の $b>0$ に対し $\delta(0)=b\delta(0)$ が要るので $\delta(0)=0$、従って $\delta(c\mathbf1)=c$ である。同変性に従う候補を組み立てるときは、残す自由度が $d$ に集約される。

:::example[位置の不変損失に尺度を入れる]
独立な $N(\mu,\sigma^2)$ 標本で、$n=4$ の平均を位置推定に使う。損失 $\{(a-\mu)/\sigma\}^2$ では $R(\mu,\sigma)=1/4$ になる。全ての観測に $g_{2,3}$ を適用すると、推定誤差は三倍されるが分母の尺度も三倍される。これを通常の二乗誤差で評価するとリスクは $\sigma^2/4$ であり、尺度変換に対しては一定でない。推定値と同時に、どの損失が測定単位に依存するかを確かめる必要がある。
:::

:::example[尺度族に合わせた補正係数を決める]
$X_i$ は独立な $\operatorname{Unif}(0,\theta)$、$M=\max_i X_i$ とする。尺度同変な候補 $a_c(X)=cM$ を損失 $(a/\theta-1)^2$ で比べる。$H=M/\theta$ の分布関数は $t^n$（$0\le t\le1$）なので、$EH=n/(n+1)$、$EH^2=n/(n+2)$ である。二次式 $c^2 EH^2-2c EH+1$ の最小点は $c=(n+2)/(n+1)$ である。$n=2$ では $c=4/3$、リスクは $1-(2/3)^2/(1/2)=1/9$ となる。平均を $\theta$ に合わせる係数 $3/2$ ではリスク $1/8$ となり、損失で最適化した係数と異なる。
:::

## 損失関数とリスク関数

同じ推定値の誤差でも、在庫の不足と余剰では費用が異なる。観測の分布だけから行動を選べないため、損失を別に定める。

:::definition[損失とリスク]{#def-stat-risk}
行動空間 $\mathcal A$ と非負の可測関数 $L(\theta,a)$ を定める。状態について積分するときは、$\Theta$ に可測構造を入れ、$\theta\mapsto P_\theta$ を確率核、$L$ を共同可測とする。$L$ を :term[損失関数]{en="loss function" yomi="そんしつかんすう"} という。観測から行動を選ぶ可測写像 $\delta:\mathcal X\to\mathcal A$ の :term[リスク関数]{en="risk function" yomi="りすくかんすう"} は
$$
R(\theta,\delta)=\int L(\theta,\delta(x))\,P_\theta(\dd x)
$$
である。
:::

目標が $\psi(\theta)$ であれば、二乗誤差 $(a-\psi(\theta))^2$、絶対誤差 $|a-\psi(\theta)|$、有限分類の $0$–$1$ 損失 $\mathbf1_{\{a\ne\psi(\theta)\}}$ がよく用いられる。二乗誤差は大きい誤差を強く罰する。絶対誤差では、誤差を同じ幅だけ増やしたときの追加損失は一定である。尺度の比較には相対二乗誤差 $(a/\sigma-1)^2$ を使えば、観測と尺度推定値を同じ正の数倍に変えても評価が変わらない。

:::example[Bernoulli 一試行のリスク]
一試行 $X$ から $p$ を二乗誤差で推定する。$\delta=X$ なら $R=p(1-p)$、$\delta=1/2$ なら $R=(p-1/2)^2$ である。$p=1/4$ ではそれぞれ $3/16$ と $1/16$、$p=1/2$ ではそれぞれ $1/4$ と $0$ である。一方、$p$ が $0$ に近ければ $X$ のリスクが小さい。この例では真の $p$ が不明なので、リスク曲線の各点で良い方を選ぶ操作自体は決定規則にならない。
:::

:::example[二つの誤判定の費用]
状態 $\theta\in\{0,1\}$ について、$P_0(X=1)=1/5$、$P_1(X=1)=4/5$ とする。見落としの費用を $3$、誤警報を $1$ とすれば、$\delta=X$ のリスクは $R(0,\delta)=1/5$、$R(1,\delta)=3/5$ である。常に警報を出せば $(1,0)$ なので、より高い見落としの費用だけでは全状態での優劣は決まらない。
:::

:::proposition[二乗誤差と偏りの分解]{#prop-stat-bias-variance}
$E_\theta\delta(X)^2<\infty$ なら、二乗誤差リスクは $\operatorname{Var}_\theta(\delta)+(E_\theta\delta-\psi(\theta))^2$ である。
:::

:::proof
$\delta-\psi=(\delta-E_\theta\delta)+(E_\theta\delta-\psi)$ と分解して二乗する。交差項は $E_\theta(\delta-E_\theta\delta)=0$ により消える。
:::

### 予測分布を行動として報告する場合

出力が点推定値でなく確率ベクトル $q$ で、次の観測 $Y$ のカテゴリを予測する場合を考える。$Y=y$ に対する対数損失を $-\log q_y$ と置く。真のカテゴリ確率 $p$ で平均すると、$q=p$ を報告した場合との差は $\sum_{y:p_y>0}p_y\log(p_y/q_y)$ である。$q_y=0<p_y$ なら差は無限大である。それ以外では $-\log u\ge1-u$ に $u=q_y/p_y$ を代入し、和を取ると差は $1-\sum_{y:p_y>0}q_y\ge0$ となる。等号には全ての正の $p_y$ で $q_y=p_y$ が必要である。対数損失を平均すると真の確率分布が唯一の最適報告になる。

:::example[同じ分類と異なる確率予測]
真の成功率が $3/4$ で、二つの規則がそれぞれ $q=3/4$ と $q=1/2$ を報告する。成功、失敗を $0$–$1$ 損失で決める際に同じ「成功」を返せば両規則の分類リスクは $1/4$ である。一方、対数損失の増分は $(3/4)\log(3/2)+(1/4)\log(1/2)>0$ である。点分類では区別しなかった確率の精度を、予測損失では区別できる。
:::

### 非対称な誤差と分位点の推定

店に在庫を一個追加すると、欠品を減らすと同時に売れ残りを増やしうる。将来の需要 $Y$ に対し、不足一単位の費用と余剰一単位の費用を分けると、求める値は平均から分位点に変わる。

:::definition[分位点損失]{#def-stat-quantile-loss}
$0<\tau<1$ とし、$(u)_+=\max(u,0)$ と置く。:term[分位点損失]{en="quantile loss" yomi="ぶんいてんそんしつ"} を
$$
\rho_\tau(y-a)=\tau(y-a)_++(1-\tau)(a-y)_+
$$
とする。$\tau=1/2$ では絶対誤差の半分である。
:::

:::proposition[分位点損失の最適行動]{#prop-stat-quantile-loss}
$Y$ は可積分、分布関数は $F$ とする。$a$ が $E\rho_\tau(Y-a)$ を最小にすることと $F(a-)\le\tau\le F(a)$ は同値である。
:::

:::proof
各 $y$ で $\rho_\tau(y-a)$ は $a$ の凸関数である。$a<y$ で傾き $-\tau$、$a>y$ で傾き $1-\tau$ を持つ。$a=y$ での左微分は $-\tau$、右微分は $1-\tau$ である。微分商は絶対値 $1$ 以下なので期待値の内側に片側微分を入れられる。そこで期待損失の左微分は $F(a-)-\tau$、右微分は $F(a)-\tau$ になる。凸関数の割線の傾きは非減少なので、最小となる点は左微分が非正、右微分が非負の点と一致する。
:::

:::example[離散需要で在庫数を決める]
$Y$ が $0,1,2$ を確率 $1/5,1/2,3/10$ で取るとし、欠品費用を余剰の三倍とする。共通因子を取り除いた損失では $\tau=3/4$ であり、$F(1)=7/10<3/4$、$F(2)=1$ なので $a=2$ が最適である。実際 $a=1$ なら期待損失は $(1/4)(1/5)+(3/4)(3/10)=11/40$、$a=2$ なら $(1/4)(2/5+1/2)=9/40$ である。等しい費用に戻すと中央値 $1$ が最適となる。
:::

### 行動がベクトルの場合

同じ方向の誤差に異なる重みを与えるときは、対称正定値行列 $W$ を固定し、$L(\theta,a)=(a-\psi(\theta))^{\mathsf T}W(a-\psi(\theta))$ と置ける。$\Sigma_\delta=\operatorname{Cov}_\theta\delta(X)$、$b_\delta=E_\theta\delta(X)-\psi(\theta)$ とし、成分ごとに二乗誤差を展開する。中心化誤差との交差項は各成分の期待値がゼロなので消える。積の跡を展開すると
$$
R(\theta,\delta)=\tr(W\Sigma_\delta)+b_\delta^{\mathsf T}Wb_\delta
$$
となる。この式では、各座標を単独の分散だけで評価しない。$W$ の非対角成分が共分散に重みを掛けるためである。

:::example[差の方向と和の方向を別に評価する]
二つのセンサーの中心化誤差を $D_1,D_2$ とし、各分散を $2$、共分散を $1$ とする。差の二乗の平均は $2+2-2=2$、和の二乗の平均は $2+2+2=6$ である。損失を $(D_1-D_2)^2+(D_1+D_2)^2/2$ にするとリスクは $5$ になる。各分散だけを見て独立と扱うと $4+4/2=6$ となる。共通の誤差が二つのセンサーに載るときは、差と和のうち何を推定するかで評価が変わる。
:::

### 予測の対数損失と分類の損失

二つの確率ベクトル $p,q$ について
$$
D_{\mathrm{KL}}(p\Vert q)
=\sum_{i:p_i>0}p_i\log(p_i/q_i)
$$
を :term[Kullback–Leibler ダイバージェンス]{en="Kullback–Leibler divergence" yomi="かるばっくらいぶらーだいばーじぇんす"} という。上の対数損失の差に相当する。零の確率に正の真の重みが載れば $+\infty$ とする。二乗誤差をカテゴリの指示ベクトルに使う :term[Brier スコア]{en="Brier score" yomi="ぶらいあすこあ"} も確率予測を評価できる。$e_Y$ をカテゴリ $Y$ の座標だけ $1$ とするベクトルとし、損失を $\norm{e_Y-q}^2$ と置く。$Ee_Y=p$ であるから、展開して
$$
E\norm{e_Y-q}^2=1-\norm{p}^2+\norm{q-p}^2
$$
を得る。どちらの損失も期待値を最小化する唯一の確率報告は $p$ である。一方、対数損失は真に起こりうる結果に零を割り当てると発散する。

:::example[小さい確率を零と報告する費用]
二つのカテゴリの確率を $p=(9/10,1/10)$ とする。常に第一カテゴリを予測する $q=(1,0)$ の Brier リスクは、第二カテゴリが起きる場合だけ損失が $2$ なので $1/5$ になる。$q=p$ での値は $1-(81/100+1/100)=9/50$ である。差は $(1/10)^2+(-1/10)^2=1/50$ である。一方 $q=(1,0)$ の対数損失の期待値は無限大になる。どちらを使うかで、極端な確率報告の扱いが変わる。
:::

### 基準となる行動と積分リスク

状態に重みを付ける方法として、$\Theta$ に事前分布 $\pi$ を置き、各リスクを平均できる。この期待値 $r(\pi,\delta)=\int R(\theta,\delta)\,\pi(\dd\theta)$ を :term[Bayes リスク]{en="Bayes risk" yomi="べいずりすく"} と呼ぶ。全ての規則をこの値で比べるとき、重みがどの状態を評価するかを決める。後の [許容性とミニマックス性](/math/statistics/admissibility-minimax/) ではこの考えを最悪状態のリスクの下界に使う。

有限の状態、観測、行動では二重和を $x$ の順にまとめることによって、観測ごとの最適行動を決められる。$m(x)=\sum_\theta\pi(\theta)p_\theta(x)>0$ とし、$\pi(\theta\mid x)=\pi(\theta)p_\theta(x)/m(x)$ と置くと、
$$
r(\pi,\delta)=\sum_x m(x)\sum_\theta L(\theta,\delta(x))\pi(\theta\mid x)
$$
である。従って各 $x$ で後ろの和を最小にする行動を選ぶと積分リスクは最小になる。$m(x)=0$ の点は和に寄与しないので、そこでどの行動を選んでも値は変わらない。

:::example[現地確認を第三の行動として加える]
状態は $0,1$、観測後の状態 $1$ の確率を $q$ とする。誤警報の費用は $1$、見落としの費用は $4$、現地確認はどの状態でも $1/2$ を要し、確認後には正しく行動できるとする。三つの行動の条件付き損失は順に $1-q,4q,1/2$ である。$q<1/8$ では見送り、$1/8<q<1/2$ では確認、$q>1/2$ では警報が最適である。例えば $q=1/4$ では $(3/4,1,1/2)$ なので確認を選ぶ。行動空間を広げると比較に使う条件付き損失の最小値が下がる場合がある。
:::

## 決定関数と許容性

損失を共有しても、異なる未知状態のリスクを一つの値で比較する方法は複数ある。その前に、どの状態でも損をしない変更を見つける。

:::definition[決定関数と許容性]{#def-stat-admissible}
観測ごとに行動を返す可測写像を :term[決定関数]{en="decision function" yomi="けっていかんすう"} という。観測 $x$ ごとに行動の分布 $\kappa(x,\dd a)$ を指定する確率核は :term[確率化決定規則]{en="randomized decision rule" yomi="かくりつかけっていきそく"} である。この場合リスクは損失をまず $\kappa(x,\dd a)$ で平均し、次に $P_\theta$ で平均する。規則 $\delta'$ がすべての $\theta$ で $R(\theta,\delta')\le R(\theta,\delta)$ を満たし、少なくとも一点で狭義に改善するとき、$\delta$ を支配するという。比較する規則のクラス内で支配する規則が存在しないとき、$\delta$ は :term[許容的]{en="admissible" yomi="きょようてき"} である。
:::

:::proposition[凸損失と確率化]{#prop-stat-derandomization}
$\mathcal A=\R^k$ とし、$a\mapsto L(\theta,a)$ は各 $\theta$ で凸とする。確率化規則の行動の平均 $m(x)=\int a\,\kappa(x,\dd a)$ が存在するとき、決定関数 $m$ のリスクは元の規則以下である。
:::

:::proof
$x$ を固定して Jensen の不等式を適用すると、$L(\theta,m(x))\le\int L(\theta,a)\kappa(x,\dd a)$ である。両辺を観測の分布で積分する。
:::

:::example[区間への射影]
$\theta\in[0,1]$ を二乗誤差で推定する際、出力 $a$ を $[0,1]$ へ切り詰める。$a<0$ であれば $|\theta-0|<|\theta-a|$、$a>1$ であれば $|\theta-1|<|\theta-a|$ である。例えば $a=-1/2$、$\theta=1/4$ なら損失は $9/16$ から $1/16$ になる。区間外の値を確率正で出し元のリスクが有限の状態が一つでもあれば、切り詰めた規則が元の規則を支配する。
:::

:::example[一点で損失をゼロにする規則]
全正規密度が $\R$ 上で正であり、$\theta$ が平均であるモデルを考える。定数推定 $a_0$ は $\theta=a_0$ でリスク $0$ である。これを支配する規則はその状態でほぼ確実に $a_0$ を返す必要がある。すべての観測法則は同値なので、どの $\theta$ でも同じ出力しか返せず、狭義改善は起こらない。したがって $a_0$ は許容的である。
:::

### 有限状態でのリスク集合

許容性は各状態での大小を同時に調べる。状態が有限なら、リスクをベクトルにして幾何的に扱える。$\Theta=\{\theta_1,\ldots,\theta_k\}$ に対し、規則の集合が与えるリスクベクトルの集合を $\mathcal R\subset\R^k$ とする。確率化を許すと、二規則を観測前に確率 $t,1-t$ で選ぶことでリスクは $tR_1+(1-t)R_2$ になる。そこで $\mathcal R$ は凸になる。標本空間と行動空間も有限なら、全確率化規則は確率単体の有限直積であり、リスクはその連続な線形像なので $\mathcal R$ はコンパクトである。

:::proposition[狭義に正の重みと許容性]{#prop-stat-positive-prior-admissible}
状態が有限とする。全状態に正の重み $\pi_i$ を付け、$\sum_i\pi_i R(\theta_i,\delta)$ を最小にする規則は、比較のクラス内で許容的である。
:::

:::proof
支配する規則があれば、どの成分でもリスクは増えず、一成分では厳密に減る。正の重みを掛けて和を取ると積分リスクは厳密に減るため、最小性に矛盾する。
:::

重みを零まで許せば、有限次元の凸なリスク集合で許容な点は必ずある線形目的の最小点になる。実際、点 $r\in\mathcal R$ が許容なら開凸集合 $r-\R_{>0}^k$ と $\mathcal R$ は交わらない。二集合の分離により、ある非零 $w$ に対し
$$
\sup_{b\in r-\R_{>0}^k}w^{\mathsf T}b
\le\inf_{s\in\mathcal R} w^{\mathsf T}s
$$
となる。分離に使う超平面の向きは左辺が小さくなるように選んだ。もし $w_i<0$ なら $b_i$ を負側へ際限なく動かして左辺が無限大になり矛盾する。よって $w_i\ge0$ であり、左辺は $w^{\mathsf T}r$ である。和が $1$ になるよう $w$ を割れば、ある事前分布に対する積分リスクを最小化する。この議論には有限次元の凸集合の分離定理を使った。零の重みがある場合、その重みの成分だけを改善する規則が残ることには注意が要る。

:::example[ある事前分布で最適でも支配される規則]
観測 $X$ は状態 $1,2$ のどちらかを誤りなく返すとし、損失は誤分類で $1$ とする。状態 $1$ にだけ重みを置けば、常に $1$ と答える規則は積分リスクを $0$ にする。しかし $X$ を返せばリスクベクトル $(0,0)$ となり、常に $1$ と答える規則の $(0,1)$ を支配する。事前分布の零の重みは支配の判定でも無視できるという意味ではない。
:::

:::example[観測がない二状態問題のリスク境界]
状態 $\theta=0,1$、行動 $a\in[0,1]$、損失 $(a-\theta)^2$ とし、観測は定数とする。決定的規則のリスクは $(a^2,(1-a)^2)$ である。$b<a$ に動かせば第一成分は下がり第二成分は上がる。逆向きでは増減が反転する。さらに確率化規則はその平均で Jensen により改善できるので、どの定値行動も許容である。事前重み $(1-p,p)$ では積分リスク $a^2-2pa+p$ の最小点が $a=p$ となる。$p=1/4$ ではリスク $(1/16,9/16)$ である。
:::

### 制約への射影と損失の形

推定対象が閉凸集合 $C\subset\R^d$ に入っていると分かるなら、二乗距離に対し、推定値の $C$ への射影は各観測での損失を減らす。[内積空間](/math/linear-algebra/inner-product-spaces/) の直交射影は線形部分空間に対する結果である。一般の閉凸集合については、最短点 $a^*$ と $\psi$ を結ぶ線分を使う。

:::proposition[閉凸集合への射影による改善]{#prop-stat-projection-improvement}
空でない閉凸集合 $C\subset\R^d$ と $a\in\R^d$ に対し、$a$ から最近の点 $a^*$ は一意であり、全ての $\psi\in C$ について
$$
\norm{a-\psi}^2\ge\norm{a^*-\psi}^2+\norm{a-a^*}^2
$$
である。
:::

:::proof
最短距離を求めるとき、一つの候補までの距離より長い点を除けるため、閉有界集合上の最小化になる。最小点が二つあれば中点も $C$ に属し、距離の二乗の狭義凸性によりその値が厳密に小さくなる。よって一意である。線分 $a^*+t(\psi-a^*)$（$0\le t\le1$）上の距離二乗は $t=0$ で最小である。そこで右微分から $(a-a^*)^{\mathsf T}(\psi-a^*)\le0$ を得る。$a-\psi=(a-a^*)+(a^*-\psi)$ を二乗すると交差項は非負であり、不等式が従う。
:::

この射影写像は可測である。実際、$a,b$ の射影を $a^*,b^*$ とし、上の内積条件に順に $\psi=b^*,a^*$ を代入して足すと、$\norm{a^*-b^*}^2\le(a-b)^{\mathsf T}(a^*-b^*)$ となる。Cauchy–Schwarz の不等式から Lipschitz 定数は $1$ 以下である。従って推定値を射影した規則は可測で、元の規則がある状態で正の確率で $C$ を外れるとき、有限リスクのもとで狭義に改善できる。

:::example[確率を二成分で推定する]
真のベクトルは $C=\{(t,1-t):0\le t\le1\}$ にあるとする。ある観測で推定値が $a=(4/5,3/5)$ になったとき、距離の二乗を $t$ で微分して $a^*=(3/5,2/5)$ を得る。真値 $\psi=(1/2,1/2)$ では損失は $1/10$ から $1/50$ に下がる。ここでは $a-a^*$ が線分と直交し、差 $2/25$ は全ての真値で同じになる。両成分が区間 $[0,1]$ に入っていても、和の制約を使えばさらに改善できる。
:::

## 統計量による情報の縮約

データをまとめると保存量を減らせる。推測に必要な違いまで消えたかどうかは、縮約後の分布と、元のデータを再現できるかを調べると分かる。

:::definition[統計量と縮約モデル]{#def-stat-statistic}
パラメータを式に含めない可測写像 $T:\mathcal X\to\mathcal T$ を :term[統計量]{en="statistic" yomi="とうけいりょう"} という。縮約された観測 $T(X)$ の法則は $Q_\theta(B)=P_\theta(T^{-1}(B))$ である。
:::

:::proposition[観測を再現できる縮約]{#prop-stat-lossless-reduction}
$T$ の値 $t$ から観測を生成する確率核 $K$ が存在し、すべての $\theta$ で $P_\theta(A)=\int K(t,A)Q_\theta(\dd t)$ とする。任意の元の決定規則は、縮約モデルの確率化規則で同一のリスク関数を実現できる。
:::

:::proof
$t$ を得たら $K(t,\cdot)$ から $x'$ を生成し、元の規則を $x'$ に適用する。$x'$ の法則は仮定から $P_\theta$ である。元の規則も確率化されているなら、その核を $K$ と合成する。非負損失に対して積分順序を交換するとリスクは一致する。逆方向には元の観測から $T$ を計算し、縮約モデルの規則を使えばよい。
:::

:::example[成功回数と再現]
独立な Bernoulli 試行 $3$ 回で成功回数が $2$ なら、観測列は $110,101,011$ のいずれかである。各列の確率は $p^2(1-p)$ なので、条件付き分布では確率が $1/3$ ずつである。各回数で同様に一様に列を引き直せるため、元の列を用いるリスクは縮約で再現できる。一般の $n$ に対しては回数 $s$ の列が $\binom ns$ 個あり、同じ議論が成り立つ。
:::

:::example[符号を消す縮約]
$X$ が $N(\mu,1)$ に従うとき、$T=|X|$ は $\mu$ と $-\mu$ で同一の分布を持つ。$\mu=1$ と $-1$ のどちらかを等確率で与え、誤判定に同じ損失を課すと、$T$ だけでの平均誤判定確率はどの規則でも $1/2$ である。元の観測の符号で判定すれば平均誤判定確率は $\Phi(-1)<1/2$ である。ここで $\Phi$ は標準正規分布関数である。
:::

再現核を元の条件付き分布から作る方法を [十分統計量](/math/statistics/sufficiency/) で扱う。両方向の再現を考えるときは、データから計算できることと、パラメータを知らずに元の実験を再現できることを別々に確かめる。

### 有限実験で再現できないことを損失で確かめる

標本空間 $\mathcal X$、パラメータ空間 $\Theta$、縮約の値域 $\mathcal T$ がいずれも有限とする。任意の損失と元の観測を使う任意の規則に対して、縮約を使い同等以下の積分リスクを達成する規則が存在すると仮定する。このときパラメータに依存しない再現核が存在する。ここで積分に使う事前分布は全状態に正の確率を置く一つの固定分布でよい。

これを示すには、行動空間として $\mathcal X$ 自体を使う。縮約から行動 $a$ を返す際の状態別の分布を並べた行列は $M_{\theta a}=\sum_t Q_\theta(t)K(t,a)$ となる。$K$ の各行は確率単体上を動くから、行列 $M$ の集合はコンパクトかつ凸である。元の観測をそのまま返す規則の行列は $P_{\theta a}=P_\theta(X=a)$ である。これが集合に入らないなら、分離超平面を使い、ある係数 $c_{\theta a}$ によって $\sum c_{\theta a}P_{\theta a}<\inf_M\sum c_{\theta a}M_{\theta a}$ とできる。各行の和が $1$ であるため、$c_{\theta a}$ に行ごとの定数を加え、全成分を非負にしても不等式は保たれる。係数をその状態の事前確率で割った値を損失とすれば、左辺は元の観測を返す規則の積分リスク、右辺は縮約で達成できる最小積分リスクである。これは仮定に反する。従って $P$ を実現する $K$ が存在する。この比較は、ある特定の二乗損失で悪化しないことより強い条件を使っている。

:::example[偶奇だけを残したときに失う率の情報]
独立な Bernoulli 二試行について、$T$ が成功回数の偶奇だけを返すとする。奇数になる確率は $2p(1-p)$ なので、$p=1/4$ と $3/4$ で縮約法則は同じである。従って等重みでの二状態分類では誤り確率を $1/2$ 未満にできない。元の成功回数 $S$ なら $S=0$ で $1/4$ を、$S=2$ で $3/4$ を選び、$S=1$ で公平に選べる。どちらの状態での誤りも $1/16+(1/2)(6/16)=1/4$ である。成功順序を消す縮約と、回数の区別まで消す縮約の違いが上のリスク差に現れる。
:::

### 縮約の前後で距離を比較する

観測値から一つの統計量だけを作ると細かい事象を選べなくなる。その効果は、判別の全変動距離と確率予測の対数損失の差の双方で計算できる。

:::proposition[確率核と全変動距離]{#prop-stat-tv-contraction}
確率核 $K$ で $P,Q$ を共通に変換した後の法則を $PK,QK$ とすると、
$$
d_{\mathrm{TV}}(PK,QK)\le d_{\mathrm{TV}}(P,Q)
$$
である。二つの実験の間で両方向の再現核があれば、任意の二状態での全変動距離は等しい。
:::

:::proof
出力の事象 $B$ に対する差は $\int K(x,B)(p-q)(x)\,\dd\nu(x)$ である。$K(x,B)$ が $0$ と $1$ の間にあるので、上限は $\int(p-q)_+$、下限は $-\int(q-p)_+$ である。共通測度には $P+Q$ を使え、両積分は :ref[prop-stat-tv-classification] の距離に等しい。任意の $B$ で評価が成り立つ。逆に戻す核もあれば、その方向にも同じ不等式を適用して等号になる。
:::

有限標本空間で $P(x),Q(x)>0$ とし、$T$ の下での周辺法則を $P_T,Q_T$ とする。$p(x)=p_T(t)p(x\mid t)$ と $q(x)=q_T(t)q(x\mid t)$ を $t=T(x)$ で対数比に代入し、$p$ で平均すると
$$
D_{\mathrm{KL}}(P\Vert Q)=D_{\mathrm{KL}}(P_T\Vert Q_T)
+\sum_t p_T(t)D_{\mathrm{KL}}(P(\cdot\mid t)\Vert Q(\cdot\mid t))
\label{eq-stat-kl-chain}
$$
である。条件付きの差は全て非負であり、周辺化ではダイバージェンスは増えない。等号になるのは、各繊維で両法則の条件付き分布が一致する場合に限る。有限の正密度モデルなら、固定した一状態 $Q$ と全ての $P_\theta$ で等号になることは、共通条件付き核を使えることを意味する。この形は次章の [十分統計量](/math/statistics/sufficiency/) の定義とつながる。

:::example[三値を二値にまとめたときの差]
$P=(1/2,1/4,1/4)$、$Q=(1/4,1/2,1/4)$ とし、最初の二カテゴリを結合する。両法則の縮約は $(3/4,1/4)$ と同じであるため、全変動距離は $1/4$ から $0$ へ減る。元の $D_{\mathrm{KL}}$ は $(1/2)\log2+(1/4)\log(1/2)=(1/4)\log2$ である。結合されたカテゴリの中では $P(\cdot\mid t)=(2/3,1/3)$、$Q(\cdot\mid t)=(1/3,2/3)$ なので、条件付きの差 $(1/3)\log2$ に周辺確率 $3/4$ を掛けると失われた $(1/4)\log2$ が戻る。
:::

### 近似的な再現

再現核が正確でなくても、元のモデルとどの程度違うかを測れば、損失の悪化に上界を付けられる。決定問題の損失を $0\le L\le M$ に制限し、縮約法則 $Q_\theta$ とある再現核 $K$ が
$$
\sup_\theta d_{\mathrm{TV}}(P_\theta,Q_\theta K)\le\varepsilon
$$
を満たすとする。元の規則 $\delta$ に対し、縮約から $K$ で観測を作って $\delta$ に渡す規則を用いる。そのリスクと元のリスクの差の絶対値は全状態で $M\varepsilon$ 以下になる。$M>0$ なら、両法則の下での平均損失を比べる積分の被積分関数を $M$ で割ると $[0,1]$ に入る。:ref[prop-stat-tv-contraction] の証明と同じ正負の部分の評価を行えばよい。$M=0$ では差は恒等的にゼロである。非有界な損失では、この評価をそのまま使うことはできない。

:::example[順序の記録にごく小さい相違がある場合]
三値の元観測について、状態 $0,1$ の法則がそれぞれ $(0.40,0.35,0.25)$ と $(0.20,0.15,0.65)$ であるとする。最初の二値を一つにまとめ、復元するときその内部を等確率で振り分ける。復元後は $(0.375,0.375,0.25)$ と $(0.175,0.175,0.65)$ である。両状態で全変動距離は $0.025$ となる。例えば $0$–$1$ 損失なら、この核で元の規則を使ったときリスクの差は高々 $0.025$ である。どちらの状態でも最初の二値の確率が等しくないため、この核は正確な再現を与えてはいない。
:::

:::example[一試行の記録を反転させる]
$X\sim\operatorname{Bernoulli}(p)$ とし、確率 $\varepsilon$ で独立に $X$ を反転させた $Y$ を保存する。$Y$ の成功率は $q=\varepsilon+(1-2\varepsilon)p$、従って $d_{\mathrm{TV}}(P_X,P_Y)=\varepsilon|1-2p|\le\varepsilon$ である。$\varepsilon=1/10$ では $p=1/4$ を $q=3/10$ に移す。$Y$ をそのまま擬似観測にすれば任意の $[0,1]$ 損失でリスク差は高々 $1/10$ である。一方 $\varepsilon=1/2$ では全ての $p$ が同じ $q$ に移り、識別可能性も失われる。
:::

### 記録を比較するときの手順

まず同じパラメータと損失を使う実験かを確認する。その上で、どの変換がパラメータに依存せず実行できるかを式にする。元の観測から統計量を作る方向は常に実行できる。逆向きで全状態に共通の核を構成できれば、元の行動規則を縮約後に移せる。逆向きが難しいときは、二状態の判別で元の実験のリスクが厳密に低くなる例を探せば、再現できないことを証明できる。全変動距離の等号を特定の二状態で見つけるだけでは、全状態を一つの核で戻せるとは限らない。

## 演習問題

::::exercise{#exr-stat-statistical-models-1 level=basic}
$P_{\theta}(X=1)=\theta(1-\theta)$、$0<\theta<1$ とする。$\theta$ と $|\theta-1/2|$ の識別可能性を判定せよ。

:::solution
$\theta$ と $1-\theta$ は同じ分布を持つので、$\theta$ は識別不可能である。一方、$\theta(1-\theta)=1/4-(\theta-1/2)^2$ により、$|\theta-1/2|$ は成功確率から一意に決まる。
:::
::::

::::exercise{#exr-stat-statistical-models-2 level=basic}
率 $\lambda>0$ の指数分布 $p_\lambda(x)=\lambda e^{-\lambda x}\mathbf1_{\{x>0\}}$ の自然表示を求め、$\lambda=2$ の分散を計算せよ。

:::solution
$T(x)=x$、$h(x)=\mathbf1_{\{x>0\}}$、$\eta=-\lambda$、$A(\eta)=-\log(-\eta)$ である。$A''(\eta)=1/\eta^2$ なので、$\eta=-2$ では分散は $1/4$ である。
:::
::::

::::exercise{#exr-stat-statistical-models-3 level=basic}
$g_{3,2}g_{1,4}$ と $g_{3,2}^{-1}$ を求めよ。

:::solution
代入すると $3+2(1+4x)=5+8x$ なので積は $g_{5,8}$ である。$y=3+2x$ を解くと $x=-3/2+y/2$ であり、逆元は $g_{-3/2,1/2}$ である。
:::
::::

::::exercise{#exr-stat-statistical-models-4 level=basic}
$X$ が成功確率 $p$ の Bernoulli 分布に従う。$p$ の推定量 $\delta=(1+X)/3$ の二乗誤差リスクを $p=1/2$ で求めよ。

:::solution
出力は $1/3$ と $2/3$ であり、どちらも真値との距離が $1/6$ である。したがって損失の平均は $1/36$ である。
:::
::::

::::exercise{#exr-stat-statistical-models-5 level=advanced}
行動空間を $\mathbb R$ とし、各状態で行動の二次積率が有限とする。二乗誤差のとき、確率化規則とその平均規則のリスク差を条件付き分散で表せ。

:::solution
行動を $A$、その $X=x$ での平均を $m(x)$ とし、二次積率が有限とする。$(A-\theta)^2=(A-m)^2+2(A-m)(m-\theta)+(m-\theta)^2$ の条件付き平均では交差項が $0$ になる。したがって差は $E_\theta[\operatorname{Var}(A\mid X)]$ である。
:::
::::

::::exercise{#exr-stat-statistical-models-6 level=advanced}
$X\sim N(\theta,1)$ とする。固定した $c\in\R$ に対して $\delta=X+c$ の許容性を $c\ne0$ の場合に判定せよ。

:::solution
リスクは全 $\theta$ で $1+c^2$ である。$X$ 自身を返す規則のリスクは全 $\theta$ で $1$ であり、$c\ne0$ ではどの点でも狭義に改善する。したがって $\delta$ は非許容的である。
:::
::::

::::exercise{#exr-stat-statistical-models-7 level=advanced}
縮約 $T$ に再現核があるとする。$Q_\theta=Q_{\theta'}$ なら $P_\theta=P_{\theta'}$ となることを示せ。

:::solution
任意の可測集合 $A$ に対し、$P_\theta(A)=\int K(t,A)\,Q_\theta(\dd t)=\int K(t,A)\,Q_{\theta'}(\dd t)=P_{\theta'}(A)$ である。逆向きは $Q$ が押し出しであることから従う。
:::
::::

::::exercise{#exr-stat-statistical-models-8 level=advanced}
$P_\theta$ が $N(\theta,1)$ で $\Theta=[0,\infty)$ のとき、$|X|$ は識別可能性を保つか。再現核は存在するか。

:::solution
$E_\theta|X|^2=1+\theta^2$ は $\theta\ge0$ で単射なので識別可能性は保たれる。一方、再現核があれば $\theta=0$ と $\theta=1$ の等重み分類において最小の平均誤判定確率は元の観測と同じになる。元の観測では二つの正規密度を比較して $x>1/2$ で $1$ を選ぶと、各 $x$ における平均損失を最小化する。閾値を除き最適行動は一意である。縮約後は符号の異なる $\pm x$（$x>1/2$）に異なる行動を割り当てられず、元の最小値には達しない。よって再現核は存在しない。
:::
::::

::::exercise{#exr-stat-statistical-models-9 level=advanced}
値域が $\{0,1,2\}$ の一試行で、基準質量は各点で $1$、自然統計量は $T(x)=x$ とする。平均が $10/7$ となる自然パラメータを求めよ。さらに、この平均を与える自然パラメータが一つであることを示せ。

:::solution
$z=e^\eta>0$ と置くと、分配関数の指数は $1+z+z^2$、平均は $(z+2z^2)/(1+z+z^2)$ である。従って $7z+14z^2=10+10z+10z^2$、すなわち $(z-2)(4z+5)=0$ となる。正の解は $z=2$ だけなので $\eta=\log2$ である。単射性は、全ての $z>0$ で $T$ が非退化であり、:ref[prop-stat-mean-map] の仮定を満たすことからも従う。
:::
::::

::::exercise{#exr-stat-statistical-models-10 level=advanced}
$X\sim\operatorname{Unif}(0,\theta)$ とし、$c\in(0,1)$ を固定する。$T=\mathbf1_{\{X\le c\}}$ が $\Theta=[c,\infty)$ で識別可能性を保つことを示し、正確な再現核が存在しないことを $\theta=1,2$ の比較から示せ。

:::solution
成功率は $c/\theta$ なので $\Theta$ 全域で単射である。一方、元の二つの分布は共通部分 $[0,1]$ で密度が $1,1/2$ であり、それ以外では一方だけが正である。全変動距離は $1/2$ である。縮約後は成功確率の差 $c-c/2=c/2<1/2$ になる。もし再現核があれば、:ref[prop-stat-tv-contraction] を逆向きに使って距離が元の $1/2$ に戻らなければならないため矛盾する。
:::

## 確認テスト

::::quiz
識別可能性を保証する条件を選べ。

- [ ] どの密度も全実数上で正である。
- [x] パラメータが異なる二点は異なる観測法則を与える。
- [ ] パラメータの次元が標本数より少ない。

:::explanation
識別可能性は $\theta\mapsto P_\theta$ の単射性である。例えば平均が $a+b$ の正規分布では密度が正であっても $(a,b)$ は識別できず、標本数を増やしてもこの重複は残る。

::::quiz{answer="3" tol="1e-6"}
平均 $3$ の Poisson 分布の分散を答えよ。

:::explanation
自然パラメータは $\eta=\log3$ である。$A=e^\eta$ の二階微分は $e^\eta$ であるから分散は $3$ である。
:::
::::

::::quiz
位置尺度変換 $x\mapsto a+bx$（$b>0$）で不変な量を選べ。ただし $x_1\ne x_2$ とする。

- [ ] $\bar x$
- [ ] $x_2-x_1$
- [x] $(x_3-x_1)/(x_2-x_1)$

:::explanation
平均は $a+b\bar x$ に、差は $b(x_2-x_1)$ に変わる。最後の比では分子と分母に共通の $b$ が掛かり、値が保たれる。

::::quiz{answer="0.25" tol="1e-6"}
Bernoulli 一試行 $X$ をそのまま $p$ の推定値とする。$p=1/2$ における二乗誤差リスクを答えよ。

:::explanation
$0$ でも $1$ でも誤差の絶対値は $1/2$ である。二乗して平均するとリスクは $1/4$ になる。

::::quiz
縮約後も元の規則を同じリスクで再現する条件を選べ。

- [x] パラメータに依存しない核で観測法則を復元できる。
- [ ] 統計量の値域が元の観測より小さい。
