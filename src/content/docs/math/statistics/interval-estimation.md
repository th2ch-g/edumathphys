## この章の目標

- 被覆確率と観測後の区間を区別する。
- 枢軸量と検定の反転から信頼区間を構成する。
- 偽の値を含む確率を最小化する信頼集合を説明する。
- 漸近信頼区間と Bayes 信用区間の確率を比較する。

## 信頼区間と被覆確率

点推定値だけでは、観測を取り直したときに推定がどれほど揺れるかを表せない。そこで、真値を指定した頻度で含む区間を標本から作る。

:::definition[信頼集合と被覆]{#def-stat-confidence}
目標 $\psi(\theta)$ の空間の部分集合 $C(X)$ を返す規則を考え、$\{(x,u):u\in C(x)\}$ は積の可測集合とする。$P_\theta(\psi(\theta)\in C(X))$ を :term[被覆確率]{en="coverage probability" yomi="ひふくかくりつ"} という。この確率が全 $\theta$ で $1-\alpha$ 以上なら $C$ は信頼係数 $1-\alpha$ を保証する :term[信頼集合]{en="confidence set" yomi="しんらいしゅうごう"} である。各標本で区間を返す場合は信頼区間という。
:::

:::example[既知分散の正規平均]
$\bar X\sim N(\mu,\sigma^2/n)$ なので $C=[\bar X-z_{1-\alpha/2}\sigma/\sqrt n,\bar X+z_{1-\alpha/2}\sigma/\sqrt n]$ の被覆は全 $\mu$ で $1-\alpha$ である。$n=4,\sigma=2,\bar x=3$ で $z_{1-\alpha/2}=2$ とすれば観測後の区間は $[1,5]$ である。被覆確率はこの固定区間に確率を割り当てる操作ではなく、区間を作る手順を評価する。
:::

:::example[離散観測における保守性]
Bernoulli 一試行で $X=0$ なら $[0,3/4]$、$X=1$ なら $[1/4,1]$ を返す。中間の $p\in[1/4,3/4]$ では被覆は $1$、左の範囲では $1-p>3/4$、右では $p>3/4$ である。被覆の下限は $3/4$ だが、どのパラメータでも実際の被覆はそれより大きい。
:::

### 点ごとの被覆と信頼係数

手順の被覆確率を $c(\theta)=P_\theta\{\psi(\theta)\in C(X)\}$ と書く。保証できる最大の信頼係数は $\inf_\theta c(\theta)$ である。固定した $\theta$ の下で実験全体を独立に $m$ 回繰り返し、真値を含んだ区間を数えれば、被覆の指示変数の平均は大数の法則により $c(\theta)$ に収束する。従って $c(\theta)$ は、同じ真値のもとでの手順の成功率である。一方、どの $\theta$ が真値か分からないため、事前の保証にはその下限を用いる。

:::example[真値の範囲を先に制約する]
$X\sim N(\theta,1)$、$\theta\ge0$ とする。$a>0$ を固定し、元の区間を $[X-a,X+a]$ とすれば被覆は $2\Phi(a)-1$ で一定である。共通部分 $C=[X-a,X+a]\cap[0,\infty)$ を返しても、真値は必ず $[0,\infty)$ に属するので被覆事象は同じである。たとえば $a=2,x=-1$ では $[-3,1]$ が $[0,1]$ になる。$x=-3$ なら共通部分は空であり、その標本では元の区間も真値を含まない。空の場合に $C=\{0\}$ とする変更は、$\theta=0$ だけで被覆を増加させる。実際、$x<-a$ の確率 $\Phi(-a)$ がその点で追加されるため、境界被覆は $\Phi(a)$ になる。
:::

### 複数の量を同時に覆う

二つの真値についてそれぞれ信頼係数を指定しても、両方を含む確率は通常それぞれの保証より低い。調べたい量が複数なら、各区間の失敗の和を先に抑えるか、同時分布から一つの集合を作る。

:::proposition[同時被覆と射影]
各 $\psi_j(\theta)$ を被覆する区間 $C_j$ が $P_\theta(\psi_j(\theta)\notin C_j)\le\alpha_j$ を満たすなら、直積 $\prod_{j=1}^k C_j$ はベクトル $\psi(\theta)$ を確率 $1-\sum_j\alpha_j$ 以上で含む。逆にベクトルの信頼集合 $C$ を任意の写像 $g$ で移した集合 $g(C)$ が共同可測なら、$g(\psi(\theta))$ の被覆確率は元の集合以上になる。$g$ が単射なら被覆は一致する。
:::

:::proof
直積に真値が入らない事象は、少なくとも一座標で外れる事象の和集合である。和集合の確率の上界は各確率の和である。写像を適用する場合、$\psi(\theta)\in C$ なら $g(\psi(\theta))\in g(C)$ である。単射なら後者からも $\psi(\theta)\in C$ が従うため、二つの事象は一致する。
:::

:::example[二平均を同時に記録する]
独立な二観測 $X_j\sim N(\mu_j,1)$ を得るとする。$a>0$ を $P(|Z|\le a)=0.95$ となるように選ぶ。$Z$ は標準正規である。各 $[X_j-a,X_j+a]$ は確率 $0.95$ で真の平均を含むが、独立により同時被覆は $0.95^2=0.9025$ である。同時被覆を $0.95$ にしたければ、各座標で $\sqrt{0.95}$ に合わせればよい。一方、依存関係を使わずに保証したければ $0.025$ を各座標の失敗率に割り当てる。すると両方の区間は $0.975$ であり、和の上界により同時被覆は $0.95$ 以上となる。この割当てで得た直積を差 $g(\mu_1,\mu_2)=\mu_1-\mu_2$ に写すと、中心 $\bar d=X_1-X_2$、半幅 $2z_{0.9875}$ の区間を得る。差の正規分布を直接使えば半幅は $\sqrt2 z_{0.975}$ である。ベクトルを一度に覆う保証は、差だけの区間を作る場合より広い幅を要する。
:::

### パラメータの尺度と区間の形

区間を別の尺度に写すと被覆が維持されても、長さや連結性は変わり得る。非単調な写像なら両端だけで像を表せない場合もある。

:::example[二乗を推定するときに内部の点を確認する]
観測後に $\mu$ の信頼区間が $[-2,1]$ になったとする。$\mu^2$ の像は $[0,4]$ である。端点の二乗だけを昇順に並べた $[1,4]$ は、真の $\mu$ が $0$ に近い可能性を落とす。例えば $\mu=0$ で元の区間が真値を含むなら、像も必ず $0$ を含む。一方、元の区間が $[1,2]$ でも、像は真の $\mu=-3/2$ の二乗を含む。従って非単射の写像では、元の候補を除外しても写した候補が残ることがある。この包含の違いが、射影区間の被覆が元より高くなり得る理由である。
:::

### 将来の観測と母数を分けて覆う

次に得られる観測 $Y$ を同じ確率で含めたい場合、その成功事象は $\{Y\in C(X)\}$ である。$\theta$ を固定したまま $X,Y$ の同時分布で評価するため、観測の揺らぎは学習標本の平均の誤差に加えて、新しい観測の誤差も含む。この区間を :term[予測区間]{en="prediction interval" yomi="よそくくかん"} という。

:::example[正規平均の信頼区間と一観測の予測区間]
既知分散 $\sigma^2$ の正規標本 $X_1,\ldots,X_n$ を観測し、これと独立な $Y\sim N(\mu,\sigma^2)$ を予測する。$Y-\bar X$ の平均は $0$、分散は $\sigma^2(1+1/n)$ なので、$\bar X\pm z_{1-\alpha/2}\sigma\sqrt{1+1/n}$ が厳密な予測区間になる。$n=4,\sigma=2,z_{1-\alpha/2}=2,\bar x=3$ なら半幅は $2\sqrt5$ である。一方、$\mu$ を覆う場合の半幅は $2$ である。標本を増やせば平均の半幅は $0$ に近づくが、予測区間は新しい一観測のばらつき $\sigma^2$ を残す。
:::

### 母集団の一定割合を覆う許容区間

予測区間では新しい一観測を含む確率を、標本とその一観測の両方を動かして評価する。別の目標として、得られた区間が母集団の少なくとも $\gamma$ の割合を覆うことを、標本について確率 $1-\alpha$ 以上で保証したい場合がある。これを :term[許容区間]{en="tolerance interval" yomi="きょようくかん"} という。

連続な母集団の分布関数を $F$ とし、独立標本で $[X_{(r)},X_{(s)}]$（$1\le r<s\le n$）を返す。この区間の母集団での確率は $W=F(X_{(s)})-F(X_{(r)})$ である。$F(X_i)$ は一様なので、:eqref[eq-stat-paired-order-density] で一様順序統計量の同時密度を使える。下端を $u$、上端を $u+w$ と置くと Jacobian は $1$ であり、$w$ の密度は
$$
\frac{n!w^{s-r-1}}{(r-1)!(s-r-1)!(n-s)!}
\int_0^{1-w} u^{r-1}(1-w-u)^{n-s}\dd u
$$
となる。$u=(1-w)v$ と置くと積分は定数と $(1-w)^{n-s+r}$ の積である。従って $W$ は $\operatorname{Beta}(s-r,n+1-s+r)$ に従い、この分布の上側確率 $P(W\ge\gamma)$ から保証を計算できる。

:::example[最小値と最大値で母集団の半分を覆う]
$n=4$、$r=1,s=4$ とすると $W$ は $\operatorname{Beta}(3,2)$ に従う。その密度は $12w^2(1-w)$ であり、$P(W\ge1/2)=11/16$ となる。同じ区間で次の一観測を予測した場合の被覆は $E W=3/5$ であり、こちらは母集団の割合が閾値を超える確率と異なる。
:::

## 枢軸量による構成

分布が未知量を含まない形に観測とパラメータを組み合わせると、その分位点を先に決められる。分位点の不等式を未知量について解けば区間になる。

:::definition[枢軸量]{#def-stat-pivot}
$W(X,\theta)$ の法則が全 $\theta$ で同じなら、この量を :term[枢軸量]{en="pivotal quantity" yomi="すうじくりょう"} という。共通分布で $P(a\le W\le b)=1-\alpha$ なら、$C(X)=\{\theta:a\le W(X,\theta)\le b\}$ の被覆は $1-\alpha$ である。二つの事象が定義上同じだからである。
:::

:::example[未知分散の正規モデル]
:ref[thm-stat-normal-decomposition] と :ref[def-stat-chi-t-f] により $(\bar X-\mu)/(S/\sqrt n)$ は $t_{n-1}$ に従う。従って平均の両側区間は $\bar X\pm t_{n-1,1-\alpha/2}S/\sqrt n$ である。一方 $Q=(n-1)S^2/\sigma^2$ の分位点を $q_L,q_U$ とすると分散の区間は $[(n-1)S^2/q_U,(n-1)S^2/q_L]$ である。分母の分位点の順序が反転する。$n=3,s^2=2$ で分位点として $1,6$ を選べば $[2/3,4]$ となり、被覆は $\chi_2^2$ の積分から $e^{-1/2}-e^{-3}$ である。
:::

:::example[端点の片側割当て]
一様端点モデルで $M/\theta$ の分布関数は $w^n$（$0<w<1$）である。$[\alpha^{1/n},1]$ に入る確率は $1-\alpha$ なので、区間は $[M,M/\alpha^{1/n}]$ である。$n=2,\alpha=1/4,m=3$ なら $[3,6]$ になる。上端 $1$ は枢軸量の台で既知なので両裾に確率を割り振る必要はない。
:::

### 分散比を推定する

独立な二つの正規標本の母分散比 $r=\sigma_1^2/\sigma_2^2$ を推定する。各標本の分散を $S_1^2,S_2^2$ とすれば $W=(S_1^2/S_2^2)/r$ は自由度 $(n_1-1,n_2-1)$ の F 分布に従う。この分布の分位点 $a,b$ を $P(a\le W\le b)=1-\alpha$ に選ぶと、$r$ の区間は $[(S_1^2/S_2^2)/b,(S_1^2/S_2^2)/a]$ になる。標本を入れ替えると、$r$ は逆数になり F の自由度も入れ替わる。分位点は逆数にした上で左右が交換されるので、区間も端の逆数を昇順に並べたものになる。

:::example[二方向で同じ結論になることの確認]
二群とも $n=2$ で $s_1^2/s_2^2=4$ とする。$F_{1,1}$ は独立な標準正規の比の二乗である。二次元正規の角度が一様なので、分布関数は $2\arctan(\sqrt f)/\pi$（$f>0$）になる。$a=1/4,b=4$ を使った区間は $[1,16]$ である。逆比の区間は $[1/16,1]$ であり、この組の端点は両側の裾に同じ確率を配分する。
:::

### 二つの平均の差と分散の仮定

独立な二つの正規標本で母分散が共通の未知値 $\sigma^2$ とする。差 $D=\bar X_1-\bar X_2$ は平均 $\mu_1-\mu_2$、分散 $\sigma^2(1/n_1+1/n_2)$ の正規分布に従う。両標本の :ref[thm-stat-normal-decomposition] を用いれば、$D$ と $Q=(n_1-1)S_1^2+(n_2-1)S_2^2$ は独立であり、$Q/\sigma^2$ は自由度 $\nu=n_1+n_2-2$ のカイ二乗に従う。従って $D\pm t_{\nu,1-\alpha/2}\sqrt{(Q/\nu)(1/n_1+1/n_2)}$ の被覆は厳密に $1-\alpha$ である。

共通分散を仮定しない場合は $W=S_1^2/n_1+S_2^2/n_2$ で差の分散を推定する。$W=\sum_j a_j Z_j$（$Z_j\sim\chi^2_{n_j-1}$ は独立、$a_j=\sigma_j^2/[n_j(n_j-1)]$）である。二つの重みが違う場合には、和は一般に一尺度のカイ二乗にならない。平均 $m=\sum_j\sigma_j^2/n_j$ と分散 $2\sum_j(\sigma_j^2/n_j)^2/(n_j-1)$ を $m\chi_\nu^2/\nu$ に合わせると
$$
\nu=\frac{(\sum_j\sigma_j^2/n_j)^2}{\sum_j(\sigma_j^2/n_j)^2/(n_j-1)}
$$
となる。母分散を標本分散で置き換えた自由度と、標準誤差 $\sqrt W$ を使う方法が Welch の近似である。二つの積率を合わせたことから区間が厳密な被覆を持つとは言えない。

:::example[不均一な二つの標本分散]
$n_1=3,n_2=5,s_1^2=3,s_2^2=10$ とする。$W=1+2=3$ で、近似自由度は $9/(1/2+4/4)=6$ である。この場合は二つの分散をプールした値と、分散を標本数で割って足した値では、差に付ける標準誤差が異なる。平均差が $2$ なら Welch の区間は $2\pm t_{6,1-\alpha/2}\sqrt3$ になる。
:::

:::example[対応のある実験]
同じ個体を前後で測り、差 $(2,4,6,8)$ が得られたとする。各個体の差を独立な共通分散の正規観測とすれば、差の標本平均は $5$、標本分散は $20/3$ である。従って区間は $5\pm t_{3,1-\alpha/2}\sqrt{5/3}$ である。二群の独立性を仮定せず、個体内の共分散を差に取り込んだ計算である。
:::

### 正規標本で平均と分散を同時に推論する

平均と分散には別々の枢軸量があるが、通常の t 枢軸量とカイ二乗枢軸量は同じ標本分散を使う。そのため、この二つを独立とみなして被覆を掛け算することはできない。代わりに、候補の分散を含む二つの枢軸量を使えば同時被覆を計算できる。

:::proposition[独立な枢軸量による同時信頼集合]
正規独立標本 $n\ge2$ で $Q=(n-1)S^2/\sigma^2$、$Z=\sqrt n(\bar X-\mu)/\sigma$ とする。$P(a\le\chi^2_{n-1}\le b)=1-\alpha_1$、$P(|N(0,1)|\le c)=1-\alpha_2$ となる定数 $0<a<b$、$c>0$ に対し、
$$
C(X)=\left\{(\mu,v):
\frac{(n-1)S^2}{b}\le v\le\frac{(n-1)S^2}{a},
\ \abs{\bar X-\mu}\le c\sqrt{v/n}\right\}
$$
の被覆は $(1-\alpha_1)(1-\alpha_2)$ である。
:::

:::proof
:ref[thm-stat-normal-decomposition] によれば正規標本では $\bar X$ と $S^2$ が独立であり、$Z$ は標準正規、$Q$ は自由度 $n-1$ のカイ二乗分布である。真の $v=\sigma^2$ が二つの条件を満たす事象は $\{a\le Q\le b\}\cap\{|Z|\le c\}$ に一致する。独立な二事象の確率を掛ければ表示式を得る。
:::

:::example[平均を射影したときに広がる半幅]
$n=3,s^2=2,\bar x=4$、分散用のカイ二乗の端を $a=1,b=6$、平均用に $c=2$ とする。分散の候補区間は $[2/3,4]$ であり、特定の候補 $v$ で許される平均は $[4-2\sqrt{v/3},4+2\sqrt{v/3}]$ になる。候補 $v$ を動かした像は最も幅の大きい $v=4$ の場合であり、$[4-4/\sqrt3,4+4/\sqrt3]$ となる。この像は同時集合より少なくとも同じ頻度で真の平均を含む。例えば $v=2/3$ と固定したときの半幅は $2\sqrt2/3$ であるが、分散そのものを未知とした射影ではこの半幅だけを使えない。
:::

### 平均が未知のときの将来観測

既知分散の予測区間に標本分散を代入するときは、標準化誤差の分布も更新する必要がある。正規標本では、将来値と標本平均の組が標本分散から独立なので、分布は厳密な t 分布になる。

:::example[正規分布で未来の一測定を予測する]
$n$ 個の正規標本に加えて、独立な同じ分布の観測 $Y$ を考える。$Y$ は標本全体に独立であり、標本内では $\bar X$ と $S^2$ が独立である。よって組 $(Y,\bar X)$ と $S^2$ も独立である。差 $Y-\bar X$ を $\sigma\sqrt{1+1/n}$ で割ると標準正規になるため、
$$
\frac{Y-\bar X}{S\sqrt{1+1/n}}\sim t_{n-1}.
$$
例えば $n=4,\bar x=3,s=2$ で $t_{3,1-\alpha/2}=2$ を選べば予測区間の半幅は $2\sqrt5$ である。標本平均自体の信頼区間の半幅は $2$ である。この予測の保証は学習標本と未来の $Y$ の両方を動かした確率であり、観測済みの特定の $x$ について未知の $\mu,\sigma$ を固定した条件付き確率を一定にする主張ではない。
:::

### 指数分布の率と平均で不等式の方向を確認する

:::example[和を用いたガンマ枢軸量]
独立に $X_i\sim\operatorname{Exp}(\lambda)$、率 $\lambda>0$ とする。$\lambda X_i$ は率 $1$ の指数分布なので、$2\lambda\sum_i X_i$ の積率母関数は $(1-2t)^{-n}$ であり、自由度 $2n$ のカイ二乗分布に等しい。$A=\sum_i X_i$ とし、$P(q_L\le\chi^2_{2n}\le q_U)=1-\alpha$ となる二点を取る。率の範囲は $[q_L/(2A),q_U/(2A)]$、平均時間 $\tau=1/\lambda$ の範囲は $[2A/q_U,2A/q_L]$ である。台が正なので、逆数をとると端点が交換される。$n=1,x=3,q_L=2,q_U=6$ なら、率では $[1/3,1]$、平均では $[1,3]$ となる。被覆は自由度 $2$ の密度を積分して $e^{-1}-e^{-3}$ である。両区間の長さは見かけ上異なるが、扱っている被覆事象は同一である。
:::

### 母中央値を順序だけで覆う

連続な母集団で中央値 $m$ が存在し、$P(X_i<m)=P(X_i>m)=1/2$ とする。このとき中央値より下の観測数 $B=\sum_i\mathbf1_{\{X_i<m\}}$ は $\operatorname{Bin}(n,1/2)$ であり、その法則は母集団の形に依存しない。$B$ は未知の $m$ に依存する枢軸量である。$1\le k\le l\le n$ とすれば、観測が中央値と一致する確率はゼロなので、
$$
X_{(k)}\le m\le X_{(l)}
\quad\Longleftrightarrow\quad
k\le B\le l-1
$$
となる。従って被覆を二項確率の和で正確に計算できる。確率質量が離散なので、任意の指定被覆をちょうど達成するとは限らない。

:::example[七観測で中央値の区間を選ぶ]
$n=7$ で区間 $[X_{(2)},X_{(6)}]$ を返すと、両側の失敗は $B\le1$ と $B\ge6$ である。その確率はそれぞれ $(1+7)/2^7=1/16$ なので、被覆は $7/8$ である。より高い被覆が要るなら $[X_{(1)},X_{(7)}]$ に広げ、$1-2/2^7=63/64$ を得る。標本が $(1,3,3.5,4,5,8,13)$ なら前者は $[3,8]$、後者は $[1,13]$ である。ここで観測値どうしの距離は被覆の計算に入らず、順序だけが条件を決める。
:::

## 検定の反転と信頼集合

未知量の候補を一つずつ帰無仮説として検定し、棄却されなかった候補を集める。この手順は枢軸量を作れないときにも使える。

:::theorem[検定と信頼集合の双対性]{#thm-stat-test-inversion}
各 $u$ について $H_u:\psi(\theta)=u$ の水準 $\alpha$ の検定があるとする。確率化用の乱数も観測空間に含め、全 $u$ に関し受容の指示関数を共同可測とする。受容された $u$ の集合の被覆は $1-\alpha$ 以上である。逆に信頼集合から $u\notin C(X)$ で棄却する検定は水準 $\alpha$ である。
:::

:::proof
真の値 $u=\psi(\theta)$ を代入すると、集合が $u$ を含まない事象と真の仮説が棄却される事象が一致する。よって各方向の不等式が同時に得られる。
:::

:::example[二項分布の厳密区間]
観測 $S=s$ について、下端 $p_L$ は $P_{p_L}(S\ge s)=\alpha/2$（$s=0$ なら $p_L=0$）、上端 $p_U$ は $P_{p_U}(S\le s)=\alpha/2$（$s=n$ なら $p_U=1$）で求める。裾確率の単調性は同じ一様乱数 $U_i$ から $X_i(p)=\mathbf1_{\{U_i\le p\}}$ を作れば分かる。各裾の棄却率が $\alpha/2$ 以下なので全体も $\alpha$ 以下である。$n=2,s=2,\alpha=1/8$ なら $p_L^2=1/16$ から $[1/4,1]$ となる。
:::

:::example[識別対象による非連結性]
$X\sim N(\theta^2,1)$ で $\theta\in\R$ とする。$\theta^2$ に対する区間が $[1,4]$ なら、反転で $\theta$ の集合は $[-2,-1]\cup[1,2]$ となる。反転一般で区間になるとは限らず、この例では符号を分布から識別できない。
:::

### 二項区間と Beta 分位点

二項分布の裾を反転するとき、母数 $p$ を動かすたびに離散確率の和を計算する必要がある。この裾を $p$ の関数として微分すると Beta 密度になるので、同じ端点を連続分布の分位点として求められる。これは数値計算上の対応であり、母数に事前分布を仮定する段階は含まない。

:::proposition[Clopper–Pearson 区間の分位点表示]{#prop-stat-clopper-pearson-beta}
$S\sim\operatorname{Bin}(n,p)$、$0<\alpha<1$ とする。観測 $s$ に対し、下端は $s>0$ なら $\operatorname{Beta}(s,n-s+1)$ の下側 $\alpha/2$ 分位点、上端は $s<n$ なら $\operatorname{Beta}(s+1,n-s)$ の下側 $1-\alpha/2$ 分位点である。端の観測では $s=0$ の下端を $0$、$s=n$ の上端を $1$ とする。この区間は信頼係数 $1-\alpha$ を保証する。
:::

:::proof
$1\le s\le n$ に対し $B_s(p)=\sum_{j=s}^n\binom nj p^j(1-p)^{n-j}$ とおく。微分して $j\binom nj=n\binom{n-1}{j-1}$、$(n-j)\binom nj=n\binom{n-1}{j}$ を代入すると隣り合う項が相殺し、
$$
B_s'(p)=n\binom{n-1}{s-1}p^{s-1}(1-p)^{n-s}
$$
だけが残る。$B_s(0)=0,B_s(1)=1$ なのでこれは正規化された Beta 密度であり、$B_s(p)=\alpha/2$ の解が下端になる。上側の端は $P_p(S\le s)=1-B_{s+1}(p)$ を使えば同じ計算で得られる。

真の $p$ が下端より小さい事象では $P_p(S\ge S_{\mathrm{obs}})<\alpha/2$ であり、上端より大きい事象では $P_p(S\le S_{\mathrm{obs}})<\alpha/2$ である。両確率は :ref[prop-stat-p-valid] によりそれぞれ $\alpha/2$ 以下である。従って補事象である被覆確率は $1-\alpha$ 以上となる。$p=0,1$ でも対応する端を含む規則なので被覆は $1$ である。
:::

:::example[成功ゼロが確率ゼロを意味しない]
$n=4,s=0$ のとき上端の方程式は $(1-p_U)^4=\alpha/2$ である。例えば $\alpha=1/8$ なら $1-p_U=1/2$ なので区間は $[0,1/2]$ である。上限だけが目的なら上側に失敗確率 $\alpha$ を全て配分でき、同じ $s=0$ で上限は $1-(1/8)^{1/4}$ になる。これは両側に予算を分けた上端 $1/2$ より小さい。得られた $0$ はしきい値以下の確率の集まりの一観測結果なので、許される母数を一点に潰す理由にはならない。
:::

### Poisson 率の厳密区間

観測回数だけでなく観測時間を合計できる場合は、合計カウント $S$ を Poisson 変数とする。期待カウントを $\mu=T\lambda$ とし、既知の露出時間 $T>0$ と未知の率 $\lambda$ を分ける。$Q_\nu(q)$ を自由度 $\nu$ のカイ二乗分布の下側 $q$ 分位点とする。

:::example[カウントから露出当たりの率へ換算する]
$S\sim\operatorname{Pois}(T\lambda)$ とする。整数 $s\ge1$ では
$$
P_\mu(S\ge s)=1-e^{-\mu}\sum_{j=0}^{s-1}\frac{\mu^j}{j!}.
$$
$\mu$ で微分すると相殺により $e^{-\mu}\mu^{s-1}/(s-1)!$ となる。右端の密度は形状 $s$、率 $1$ のガンマ分布の密度であり、変数を二倍した分布は $\chi^2_{2s}$ である。従って下端は $Q_{2s}(\alpha/2)/(2T)$ であり、$s=0$ のときは $0$ とする。一方で $P_\mu(S\le s)=1-P_\mu(S\ge s+1)$ なので、上端は $Q_{2(s+1)}(1-\alpha/2)/(2T)$ である。二項の場合と同じく、両裾での失敗の確率はそれぞれ $\alpha/2$ 以下である。例えば $T=3,s=0$ で $1-\alpha=1-2e^{-3}$ とすると、上端は $e^{-3\lambda_U}=e^{-3}$ を満たす $1$ であり、区間は $[0,1]$ になる。
:::

:::example[二つの Poisson 率の比の条件付き区間]
独立な Poisson カウント $A,B$ の平均を $T_1\lambda_1,T_2\lambda_2$ とし、$T_1,T_2>0$ は既知、$\lambda_1\ge0$、$\lambda_2>0$ とする。合計 $M=m$ を条件とすれば $A$ は $\operatorname{Bin}(m,p)$ に従い、$p=T_1\lambda_1/(T_1\lambda_1+T_2\lambda_2)$ である。これは二つの Poisson 質量の積を合計の質量で割って得られる。Clopper–Pearson の区間 $[p_L,p_U]$ の両端を、増加写像 $r(p)=(T_2/T_1)p/(1-p)$ で移すと、$\lambda_1/\lambda_2$ の区間を得る。$p_L=0$ は下限 $0$、$p_U=1$ は上限なしとして扱う。$m=0$ なら全範囲を返す。各 $m$ で条件付き被覆が $1-\alpha$ 以上なので、$M$ で平均した被覆も同じ下限を持つ。

例えば $T_1=1,T_2=3$、$A=2,B=0$、$\alpha=1/8$ なら $p_L=1/4$、$p_U=1$ である。率比の下限は $3(1/4)/(3/4)=1$ となり、区間は $[1,\infty)$ である。第二群で観測が零件でも、露出時間は比を換算するために使う。
:::

### 比を反転するときの非有界集合

二つの平均の比を推定する際、分母が $0$ に近い値をデータが排除できないと、比の区間を短く保てない。これは反転の代数に現れる。比の帰無を線形制約 $\mu_1-r\mu_2=0$ として検定し、二次不等式を求める。

:::proposition[正規平均比の Fieller の集合]{#prop-stat-fieller-ratio}
$(X,Y)$ は平均 $(\mu_1,\mu_2)$、既知の正定値共分散行列 $V=(v_{ij})$ を持つ二変量正規分布に従い、$\mu_2\ne0$ とする。$z=z_{1-\alpha/2}$ とおく。このとき $r=\mu_1/\mu_2$ の信頼集合は
$$
\{r:(y^2-z^2v_{22})r^2-2(xy-z^2v_{12})r+(x^2-z^2v_{11})\le0\}
$$
とでき、被覆は厳密に $1-\alpha$ である。
:::

:::proof
固定した候補 $r$ で $\mu_1=r\mu_2$ なら $X-rY$ の平均は $0$ であり、分散は $v_{11}-2rv_{12}+r^2v_{22}>0$ である。そこで絶対標準化値が $z$ より大きいと棄却する。分散が正なので、受容不等式を二乗して両辺を掛ければ表示式になる。真の比で棄却確率は $\alpha$ なので、反転による被覆は $1-\alpha$ である。
:::

:::example[分母の観測で集合の形が変わる]
$V=I_2$、$z=2$、$x=3$ とする。$y=3$ なら不等式は $5r^2-18r+5\le0$ であり、解は $[(9-2\sqrt{14})/5,(9+2\sqrt{14})/5]$ である。これに対して $y=1$ なら $-3r^2-6r+5\le0$ であり、解は
$$
r\le -1-\frac{2\sqrt6}{3}\quad\text{または}\quad
r\ge -1+\frac{2\sqrt6}{3}
$$
となる。前者では分母の両側区間 $[1,5]$ に $0$ が入らないため二次係数は正である。後者では $[-1,3]$ が $0$ を含み、大きな絶対値の比も排除できない。二次係数が $0$ の場合は一次不等式を解く。二次係数が負で判別式が負なら全実数が残る。従って有限長の連結区間だけを必ず報告する方式では、この反転の被覆をそのまま保てない。
:::

共分散が $\sigma^2 V_0$ で $V_0$ だけ既知でも、$\widehat\sigma^2$ が $(X,Y)$ と独立で $\nu\widehat\sigma^2/\sigma^2\sim\chi_\nu^2$ なら同じ反転を行える。固定候補 $r$ に対し、帰無のもとで
$$
\frac{X-rY}{\widehat\sigma\sqrt{(V_0)_{11}-2r(V_0)_{12}+r^2(V_0)_{22}}}
$$
は標準正規を独立な $\sqrt{\chi_\nu^2/\nu}$ で割った量である。従って既知共分散での二次不等式の $z$ を $t_{\nu,1-\alpha/2}$ に、$V$ を $\widehat\sigma^2 V_0$ に置き換えれば、被覆は厳密に $1-\alpha$ となる。

## 一様最精密信頼区間

真値の被覆を保ちながら、誤った候補をどの程度排除できるかを調べる。区間長だけでなく、候補ごとの包含確率で優劣を付ける。

:::definition[一様最精密性]{#def-stat-most-accurate}
比較クラス内のどの $C'$ に対しても、全 $\theta$ と $u\ne\psi(\theta)$ で $P_\theta(u\in C)\le P_\theta(u\in C')$ となる信頼集合を :term[一様最精密信頼集合]{en="uniformly most accurate confidence set" yomi="いちようさいせいみつしんらいしゅうごう"} という。偽の値を含む確率が $1-\alpha$ 以下になる性質を信頼集合の不偏性という。
:::

:::proposition[最強力検定からの構成]{#prop-stat-uma}
各 $u$ に対する一様最強力検定の反転は一様最精密である。一様最強力不偏検定なら、反転は不偏信頼集合のクラスで一様最精密である。実数値の信頼集合で長さの期待値が定義されるとき、同じクラスで期待長さも最小になる。
:::

:::proof
$u$ を含む確率は $1$ から $H_u$ の検出力を引いたものである。偽の値に対する包含確率条件は検定の不偏性そのものである。さらに Lebesgue 測度 $\lambda$ に対し Tonelli の定理で $E_\theta\lambda(C)=\int P_\theta(u\in C)\,\dd u$ を得る。真値一点は積分に寄与しないので、各偽の点での改善が期待長さにも移る。
:::

:::example[片側下限]
既知分散の正規平均で $H_u:\mu\le u$ を検定すると、:ref[thm-stat-ump-monotone] の規則は $\bar X>u+z_{1-\alpha}\sigma/\sqrt n$ で棄却する。反転は $[\bar X-z_{1-\alpha}\sigma/\sqrt n,\infty)$ である。$u<\mu$ の偽候補の包含を、下限を返す規則のクラスで全点に対して最小にする。
:::

:::example[両側と不偏性]
同じモデルで $H_u:\mu=u$ に対する二裾検定は :ref[thm-stat-umpu-two-tail] の二条件を満たす。反転の中心は $\bar X$、半幅は $z_{1-\alpha/2}\sigma/\sqrt n$ である。片側だけに棄却を割り当てる検定は反対側の小さなずれで検出力が $\alpha$ を下回り、このクラスから外れる。
:::

### 期待長さと被覆を明示して比較する

位置族 $X=\theta+Z$ で、長さを固定した同変区間 $[X-b,X-a]$（$b-a=L>0$）を考える。被覆確率は $P(a\le Z\le a+L)$ である。$Z$ の密度 $f$ が連続かつ左右対称で、原点から離れると厳密に減少するなら、この被覆は $a=-L/2$ で最大になる。実際、$a$ による微分は $f(a+L)-f(a)$ であり、$a<-L/2$ では右端が原点に近いので正、$a>-L/2$ では負である。従って指定被覆に必要な長さは対称な区間で最小である。この議論は指定したクラスでの長さ最適性を示すものであり、異なるクラスへの拡張には :ref[prop-stat-uma] の検定との対応を調べる。

:::example[片側に台を持つ誤差]
$Z\sim\operatorname{Exp}(1)$ なら、長さ $L>0$ の区間で質量を最大にするのは $[0,L]$ である。$a\ge0$ では質量 $e^{-a}(1-e^{-L})$ は $a$ の増加に伴って減少し、$a<0$ では台の外に区間の一部が出るため $a=0$ より小さい。従って被覆 $1-\alpha$ を得る最短の同変区間は $[X+\log\alpha,X]$ である。$\alpha=1/4$ では長さ $\log4$ となる。
:::

### 裾への配分と端点の動き

片側下限の反転で比較する相手を明示する。規則が下限 $L(X)$ を返し、$P_\mu(L\le\mu)\ge1-\alpha$ を全 $\mu$ で満たすとする。候補 $u$ の除外 $\{L>u\}$ は $H_u:\mu\le u$ の水準 $\alpha$ の検定になる。実際、$\mu\le u$ なら $\{L>u\}\subseteq\{L>\mu\}$ である。従って $\mu>u$ に対して一様最強力な検定は、下限規則が偽の小さい値 $u$ を含む確率を最小にする。一方、$u>\mu$ はこの片側の目的に対する対立にはならないので、両側の候補についての定義をそのまま使えない。

:::example[下限が過大な候補を残す確率]
$\bar X\sim N(\mu,\tau^2)$、$\tau=1,z_{1-\alpha}=2$ とする。最適な下限は $L=\bar X-2$ である。$\mu=3$ で偽の小さい候補 $u=1$ を含む確率は $P_3(\bar X\le3)=1/2$ である。$\bar X-3$ を下限にする保守的な規則なら $P_3(\bar X\le4)=\Phi(1)>1/2$ となる。真値を覆う確率を増やす操作が、小さい候補を残す確率も増やした。その一方で上側の候補を除外したい場合には、下限の保証を強めるだけでは目的を満たせない。
:::

### 一点での期待長さを最適にする

一様最精密性は、どの真値で観測しても偽候補の包含確率を減らすことを求める。これに対して、真値のある一点での期待長さを小さくしたいなら、その点へ向かう対立だけを重視して検定を反転できる。これは信頼係数を守ったまま、区間の長さを場所によって変える構成である。

:::proposition[正規位置での一点最小期待長さ]
$X\sim N(\theta,\sigma^2)$、$\sigma>0$ は既知、$0<\alpha<1/2$ とする。固定した点 $\theta_*$ における期待長さを、信頼係数 $1-\alpha$ を保証する全信頼集合の中で最小にする :term[Pratt の区間]{en="Pratt interval" yomi="ぷらっとのくかん"} は
$$
C_*(X)=\bigl[\min(\theta_*,X-z_{1-\alpha}\sigma),
\max(\theta_*,X+z_{1-\alpha}\sigma)\bigr]
$$
である。
:::

:::proof
候補 $u>\theta_*$ の単純帰無を、単純対立 $\theta_*$ に対して比較する。対立と帰無の正規密度比は $X$ の減少関数なので、Neyman–Pearson の補題から $X<u-z_{1-\alpha}\sigma$ で棄却すれば検出力が最大になる。従って $u>\theta_*$ で受容されるのは $u\le X+z_{1-\alpha}\sigma$ の候補である。逆に $u<\theta_*$ の場合は比が増加するため $X>u+z_{1-\alpha}\sigma$ で棄却し、$u\ge X-z_{1-\alpha}\sigma$ を受容する。点 $u=\theta_*$ は常に含める。左右の受容集合とこの点を合わせると表示の区間になる。$u\ne\theta_*$ では真値が $u$ なら各検定のサイズは $\alpha$、真値が $\theta_*$ なら区間は常に被覆するため、信頼係数は $1-\alpha$ である。

任意の信頼集合を反転した検定について、各 $u\ne\theta_*$ の棄却確率は $\theta_*$ の下で上の最強力検定以下である。そのため $P_{\theta_*}(u\in C_*)\le P_{\theta_*}(u\in C)$ を $u$ にわたって積分し、Tonelli の定理で期待長さの最小性を得る。$u=\theta_*$ の一点は積分に寄与しない。
:::

:::example[中心の近くで短く、離れると長くなる]
$\theta_*=0,\sigma=1,z_{1-\alpha}=1$ とする。$x=0$ で区間は $[-1,1]$、$x=3$ では $[0,4]$ になる。一般の $z=z_{1-\alpha}$ について、$\theta=0$ での期待長さは $E[(Z+z)_++(z-Z)_+]$、$Z\sim N(0,1)$ である。対称性と $\int_a^\infty t\phi(t)\dd t=\phi(a)$ を使うと
$$
E_0|C_*|=2\int_{-z}^\infty(t+z)\phi(t)\dd t
=2\{\phi(z)+z\Phi(z)\}.
$$
$z=1$ のとき約 $2.167$ であり、$\theta=0$ に限れば通常の等裾区間の期待長さを上回らない。しかし $|\theta|$ が大きくても区間は常に $0$ を含むため、期待長さは有界に留まらない。この構成では、どの真値における長さを優先するかを先に指定した。
:::

### 尺度パラメータで最短の枢軸区間

尺度族で正の統計量 $A$ があり、$W=A/\sigma$ の密度 $f$ が母数に依存しないとする。$P(a\le W\le b)=1-\alpha$ とする区間は $[A/b,A/a]$ であり、観測した $A>0$ を固定すれば長さは $A(1/a-1/b)$ である。従って同じ枢軸量を使うこのクラスでは、$1/a-1/b$ を最小にする端を探せば各標本の長さも期待長さも最小になる。分位点を等確率に取ることから、この長さ条件は一般に従わない。

:::proposition[最短尺度区間の内点条件]
$W$ の密度 $f$ は $(0,\infty)$ 上で連続かつ正とする。上の尺度区間の長さを最小にする $0<a<b<\infty$ が存在するなら、$a^2 f(a)=b^2 f(b)$ が必要である。
:::

:::proof
左裾確率を $l\in(0,\alpha)$ とし、$F$ を $W$ の分布関数として $a=F^{-1}(l)$、$b=F^{-1}(1-\alpha+l)$ とする。$f>0$ なので $a'(l)=1/f(a)$、$b'(l)=1/f(b)$ である。従って長さの $A$ で割った値の微分は
$$
-\frac{1}{a^2f(a)}+\frac{1}{b^2f(b)}.
$$
両端が有限正のとき $l$ は内点なので、微分を $0$ と置けば必要条件を得る。境界で上端が無限になる場合は、この微分だけで候補を除くことはできない。
:::

:::example[一様尺度では片裾が最短になる]
独立な $\operatorname{Unif}(0,\sigma)$ 標本で $A=M$ とすれば、$W=M/\sigma$ の分布関数は $w^n$（$0\le w\le1$）である。左裾確率 $l\in(0,\alpha]$ に対して $a=l^{1/n}$、$b=(1-\alpha+l)^{1/n}$ であり、長さ係数は $l^{-1/n}-(1-\alpha+l)^{-1/n}$ である。微分は
$$
-\frac1n l^{-1/n-1}+\frac1n(1-\alpha+l)^{-1/n-1}<0
$$
なので $l=\alpha$、$b=1$ が最短である。$n=2,\alpha=1/4,A=3$ ならこの区間の長さは $6-3=3$ である。等裾に分けると $a=\sqrt{1/8},b=\sqrt{7/8}$ なので長さは $3(\sqrt8-\sqrt{8/7})$ となり、先の微分から $3$ より大きいと分かる。有限台の端 $b=1$ から先には確率質量がないので、右裾に割り当てる必要がない。
:::

## 漸近的信頼区間

枢軸量の厳密分布が不明でも、推定量を標準化した極限分布が分かれば区間を近似できる。ここで得られる被覆は通常、各固定した真値での極限である。

:::proposition[Wald 区間]{#prop-stat-wald-interval}
固定した $\theta$ で $\sqrt n(D_n-\psi(\theta))\Rightarrow N(0,v(\theta))$、$v(\theta)>0$、$\widehat v_n\to_p v(\theta)$ とする。このとき $\widehat v_n>0$ で $[D_n\pm z_{1-\alpha/2}\sqrt{\widehat v_n/n}]$ を返す手順の被覆は $1-\alpha$ に収束する。$\widehat v_n\le0$ では任意の可測な集合を返してよい。
:::

:::proof
$v(\theta)>0$ なので、$\widehat v_n\le0$ の確率は $0$ に収束する。Slutsky の補題 :ref[lem-prob-slutsky] により、標準化した誤差は標準正規へ分布収束する。両端点に極限分布の質量がないため、標準化誤差が分位点の間に入る確率が $1-\alpha$ に収束する。
:::

:::example[二項比率の Wald 区間]
$\hat p=S/n$ として $\widehat v=\hat p(1-\hat p)$ を代入する。$n=100,s=25$ では標準誤差は $\sqrt3/40$ である。$s=0$ なら区間は一点 $\{0\}$ に崩れるため、$p$ が標本数に応じて $0$ に近づく場面では点ごとの漸近保証をそのまま使えない。
:::

:::example[スコアの反転と Wilson 区間]
帰無点 $p_0$ で分散を評価し、$(\hat p-p_0)^2\le z^2p_0(1-p_0)/n$ を $p_0$ について解く。中心は $(\hat p+z^2/(2n))/(1+z^2/n)$、半幅は $z\sqrt{\hat p(1-\hat p)/n+z^2/(4n^2)}/(1+z^2/n)$ である。例えば $n=12,s=0,z=2$ なら不等式を整理して $[0,1/4]$ となる。この区間も正規近似を使う。
:::

### 分散安定化と区間の端

変換の効果は一次展開から求められる。例えば $\sqrt n(\widehat p-p)$ が分布収束し、$g$ が $p$ で微分可能なら、$g(\widehat p)-g(p)=g'(p)(\widehat p-p)+o(|\widehat p-p|)$ を $\sqrt n$ 倍する。$\widehat p\to_p p$ と $\sqrt n(\widehat p-p)$ の確率的有界性から、余項は確率収束で零となる。従って極限分散はもとの値の $g'(p)^2$ 倍である。この計算をデルタ法と呼び、ベクトルの場合は勾配と共分散行列の二次形式になる。ベクトルの一次展開でもノルムで同じ余項評価を使える。一般形は [漸近理論](/math/statistics/asymptotics/) で扱う。

Bernoulli 比率 $p$ の分散因子は $p(1-p)$ である。$g(p)=2\arcsin\sqrt p$ とすると $g'(p)=1/\sqrt{p(1-p)}$ なので、固定内点でのデルタ法は $\sqrt n(g(\hat p)-g(p))\Rightarrow N(0,1)$ を与える。$g$ の値域は $[0,\pi]$ なので、$g$ の尺度で作った区間をこの範囲と共通部分にしてから、単調な逆写像 $\sin^2(g/2)$ を適用する。逆写像が単調でない範囲まで延長すると、順序が保たれない。

:::example[中央付近での逆変換]
$\hat p=1/2$ のとき $g(\hat p)=\pi/2$ になる。例えば変換尺度で半幅 $\pi/6$ を使えば区間は $[\pi/3,2\pi/3]$、逆変換は $[1/4,3/4]$ になる。$p$ が $0$ または $1$ に近い場合には $g'$ が発散するため、内点でのデルタ法から一様な保証は得られない。
:::

### 点ごとの近似と一様被覆

Wald 区間の仮定は、母数 $\theta$ を固定した上で標本数を増やしている。全ての母数に対して同じ標本数で被覆が近いと言うには、誤差の上限を母数について一様に抑える必要がある。母数が境界へ近づくと分散が小さくなるモデルでは、標準化の分母も推定しにくくなる。

:::example[希な成功では正規近似が一様でない]
各 $n\ge2$ で $p_n=1/n$ とする。成功数が $0$ のとき Wald 区間は $\{0\}$ であり、正の真値 $p_n$ を含まない。ところが $P_{p_n}(S=0)=(1-1/n)^n\to e^{-1}$ なので、被覆の上極限は $1-e^{-1}$ 以下である。従って例えば名目被覆が $0.95$ なら、一様な被覆近似は成り立たない。任意の $0<\alpha<1$ で同じ結論を得るには、$0<c<-\log\alpha$ として $p_n=c/n$ を用いればよい。零件の確率は $e^{-c}>\alpha$ に近づく。一方、正の固定 $p$ では $P_p(S=0)=(1-p)^n\to0$ である。

また成功数自体は $p_n=1/n$ で Poisson 分布に近づく。実際、固定整数 $k\ge0$ で
$$
P_{p_n}(S=k)=\frac{n(n-1)\cdots(n-k+1)}{k!n^k}
\left(1-\frac1n\right)^{n-k}\longrightarrow\frac{e^{-1}}{k!}.
$$
右の質量の和は $1$ なので分布収束が従う。標準化に使える誤差分布は、母数をどのように動かすかによって変わる。
:::

:::proposition[母数に一様な標準化からの被覆]
$\widehat v_n>0$ の範囲で $Z_{n,\theta}=\sqrt n(D_n-\psi(\theta))/\sqrt{\widehat v_n}$ とし、それ以外で任意に定義する。$\sup_\theta P_\theta(\widehat v_n\le0)\to0$、かつ
$$
\sup_{\theta}\sup_z\left|P_\theta(Z_{n,\theta}\le z)-\Phi(z)\right|\longrightarrow0
$$
なら、Wald 区間の $1-\alpha$ からの被覆誤差の絶対値は母数について一様に $0$ へ収束する。
:::

:::proof
$z_*=z_{1-\alpha/2}$ とする。標準化誤差が $[-z_*,z_*]$ に入る確率は $P(Z_{n,\theta}\le z_*)-P(Z_{n,\theta}<-z_*)$ である。後者は $x\uparrow-z_*$ とした $P(Z_{n,\theta}\le x)$ の極限であり、$\Phi$ の連続性から上の一様誤差と同じ幅で $\Phi(-z_*)$ を近似する。従って全体の誤差はその幅の二倍以下である。分散推定値が非正の事象で Wald 区間をどう定義しても、追加の誤差はその事象確率の上限以下である。二つとも $0$ に収束する。
:::

:::example[二項比率を境界から離して比較する]
$\varepsilon\le p\le1-\varepsilon$（$0<\varepsilon<1/2$）に限る。この範囲で Bernoulli の標準化三次絶対積率は有界なので、:ref[thm-prob-berry-esseen] により $Z_n=\sqrt n(\hat p-p)/\sqrt{p(1-p)}$ の分布関数は一様に $\Phi$ に近づく。Chebyshev の不等式から $\sup_p P_p(|\hat p-p|>\delta)\le 1/(4n\delta^2)$ である。$\hat p(1-\hat p)$ と $p(1-p)$ の差は $|\hat p-p|$ 以下であり、真の分散因子は $\varepsilon(1-\varepsilon)$ 以上である。従って $\widehat v/v$ は一様に $1$ に近づく。

$0<\delta<1$ とし、$1-\delta\le\widehat v/v\le1+\delta$ の事象上で被覆を比較する。$|Z_n|\le z_*\sqrt{1-\delta}$ なら被覆し、被覆するなら $|Z_n|\le z_*\sqrt{1+\delta}$ である。従ってその二つの確率と、比が範囲外に出る確率で被覆を挟める。まず $n\to\infty$、次に $\delta\downarrow0$ として、この内点に限った範囲で被覆が一様に $1-\alpha$ に収束すると分かる。
:::

### 変換で範囲を保つ Wald 区間

標準正規の幅を元の尺度で足し引きすると、確率が負になるなど母数空間の外へ出ることがある。母数の内点で滑らかな単調変換をしてから端点を戻すと、変換の値域が全実数なら、二つの端を元の範囲に保てる。ただし元の母数で対称な区間とはならない。

:::example[二項比率をロジットで標準化する]
$g(p)=\log(p/(1-p))$ なら、$g'(p)=1/[p(1-p)]$ である。従って $0<p<1$ の固定真値で $\sqrt n(g(\hat p)-g(p))$ の漸近分散は $1/[p(1-p)]$ である。$n=16,s=8,z=2$ なら $g(\hat p)=0$、推定標準誤差は $1/\sqrt{16\cdot1/4}=1/2$ なので変換尺度で $[-1,1]$ となる。逆写像 $g^{-1}(u)=e^u/(1+e^u)$ を適用すると
$$
[1/(1+e),e/(1+e)]
$$
であり、元の尺度の Wald 区間 $[1/4,3/4]$ と異なる。ロジットは $s=0,n$ で定義できないため、このような観測では別の規則を決める必要がある。固定内点では端の観測の確率 $p^n+(1-p)^n$ は $0$ に収束するので、そこで任意に区間を定めても点ごとの漸近被覆は維持される。
:::

:::example[Poisson の率比を対数で構成する]
独立に $X_i\sim\operatorname{Pois}(\lambda_1)$、$Y_i\sim\operatorname{Pois}(\lambda_2)$ をそれぞれ $n$ 個観測し、両率は正とする。$g(x,y)=\log x-\log y$ にデルタ法を使うと、$\log(\bar X/\bar Y)$ の漸近分散は $n^{-1}(1/\lambda_1+1/\lambda_2)$ である。実際、勾配は $(1/\lambda_1,-1/\lambda_2)$、平均の共分散は $\diag(\lambda_1,\lambda_2)/n$ なので行列積がこの値になる。$n=10,\sum x_i=20,\sum y_i=10$ なら点推定の比は $2$、対数尺度の推定標準誤差は $\sqrt{1/20+1/10}=\sqrt{3/20}$ である。$z=2$ の場合の区間は
$$
[2e^{-2\sqrt{3/20}},2e^{2\sqrt{3/20}}]
$$
となる。比の尺度で下端と上端の差を別々に計算する必要はなく、対数で足した幅は元の尺度で倍率となる。
:::

### 平滑な関数の同時近似

推定対象がベクトルの場合には、各座標で区間を作る代わりに、標準化したベクトルのノルムを使える。$\widehat\psi_n\in\R^k$ とし、$\sqrt n(\widehat\psi_n-\psi(\theta))\Rightarrow N_k(0,V(\theta))$、正定値の $V(\theta)$ に対し $\widehat V_n\to_p V(\theta)$ とする。逆行列は正則点で連続なので、Slutsky の補題と二次形式の連続性により
$$
n\transp{(\widehat\psi_n-\psi(\theta))}\widehat V_n^{-1}
(\widehat\psi_n-\psi(\theta))\Rightarrow\chi^2_k.
$$
右端の分布は $V^{-1/2}$ を掛けた極限正規ベクトルの各成分が独立な標準正規になることから得られる。従って二次形式が $\chi^2_k$ の下側 $1-\alpha$ 分位点以下となる候補の集合は漸近被覆 $1-\alpha$ である。$V$ が特異なら、この逆行列を用いた形は使えない。例えば分散ゼロの方向が既知で、残りの方向だけを覆う目的なら、正の分散を持つ部分空間への射影で同じ計算を行える。分散ゼロの方向も含めて推定する場合は、その方向で適切な収束尺度を別に調べる。

:::example[楕円から線形結合を射影する]
二次形式を用いた集合を $C=\{u:\transp{(u-\widehat\psi)}V^{-1}(u-\widehat\psi)\le q/n\}$ とする。方向 $c$ への像は $\transp c\widehat\psi\pm\sqrt{(q/n)\transp cVc}$ である。実際、$u-\widehat\psi=V^{1/2}w$、$\norm w\le\sqrt{q/n}$ と書き、Cauchy–Schwarz の等号方向 $w\propto V^{1/2}c$ を選ぶと両端を達成できる。$V=\begin{pmatrix}2&1\\1&2\end{pmatrix}$、$\widehat\psi=(3,1)^{\mathsf T}$、$c=(1,-1)^{\mathsf T}$、$q/n=1/2$ なら、中心は $2$、半幅は $\sqrt{(1/2)\cdot2}=1$ なので像は $[1,3]$ である。全ての方向を同じ楕円から作れば、同時に真値が入る事象は少なくとも元の楕円の被覆事象を含む。
:::

### 尤度の低下量から端点を決める

候補値を課して最大化した対数尤度を、無制約の最大値と比較する方法もある。候補を除く閾値は、真値での対数尤度差の分布に基づいて決める。以下では Poisson モデルでこの分布を直接導く。一般の場合は [尤度に基づく漸近的検定](/math/statistics/likelihood-tests/) で扱う。

:::example[Poisson の対数尤度を反転して非対称になる理由]
露出時間 $T$ に対し $S\sim\operatorname{Pois}(T\lambda)$、$s>0$ とする。最大点は $\widehat\lambda=s/T$ であり、候補を $r\widehat\lambda$、$r>0$ と書くと尤度の低下量の二倍は $2s(r-1-\log r)$ である。$s=10$ で半分の候補 $r=1/2$ を試すと $20(\log2-1/2)$、同じ絶対差の増加側 $r=3/2$ では $20(1/2-\log(3/2))$ になる。前者の方が大きい。実際、その差は $20(\log3-1)>0$ である。そこで閾値 $3$ で反転すると、$r=1/2$ の値は約 $3.86$ なので外れ、$r=3/2$ の値は約 $1.89$ なので残る。尤度で区間を作る場合には、このように左右で同じ距離でも異なる判定が起こる。
:::

上の Poisson モデルで、真値 $\lambda>0$ を固定して露出時間 $T$ を正の整数として増やす。$S$ は $T$ 個の独立な $\operatorname{Pois}(\lambda)$ の和として表せるので、中心極限定理から $Z_T=(S-T\lambda)/\sqrt{T\lambda}\Rightarrow N(0,1)$ である。$S=0$ の確率は $e^{-T\lambda}$ であり、$S>0$ では $r=T\lambda/S$ と置ける。大数の法則で $r\to_p1$ であり、$r-1-\log r=(r-1)^2/2+o((r-1)^2)$ である。よって真値についての尤度の低下量の二倍は
$$
2S(r-1-\log r)=Z_T^2\,\frac{T\lambda}{S}\,(1+o_p(1))
\ \xrightarrow{d}\ \chi_1^2
$$
となる。ここで $r=1$ では Taylor 展開の比を連続に補う。$\chi_1^2$ の $1-\alpha$ 分位点以下となる候補を集めた集合は、このモデルの各内点で漸近被覆 $1-\alpha$ を持つ。

## Bayes 信用区間との比較

信頼区間ではパラメータを固定して標本を反復する。事前分布を導入する場合には、観測を固定してパラメータの事後分布を積分するという別の確率を得る。

:::definition[信用区間]{#def-stat-credible}
事後分布で確率 $1-\alpha$ を持つ観測依存区間を :term[信用区間]{en="credible interval" yomi="しんようくかん"} という。等裾区間は事後分布の両裾に $\alpha/2$ ずつ配分する。連続密度で閾値を選べる場合、密度が閾値以上の集合は最高事後密度集合である。
:::

最高事後密度集合 $A$ と同じ確率を持つ $B$ に対して、$\int_{A\setminus B}f=\int_{B\setminus A}f$ である。閾値 $k>0$ 以上を含む $A$ では左辺は $k\lambda(A\setminus B)$ 以上、右辺は $k\lambda(B\setminus A)$ 以下である。従って $\lambda(A)\le\lambda(B)$ である。密度が多峰ならこの集合は連結とは限らない。

:::example[正規モデルで一致する場合]
既知分散で平均に平坦な事前重みを用いると、正規密度の平方完成により事後は $N(\bar X,\sigma^2/n)$ となる。等裾区間は信頼区間と同じ式になる。平坦な重みは $\R$ 上で正規化できないが、この例では尤度を掛けた積分が有限である。
:::

:::example[事前によって被覆が変わる場合]
$X\sim N(\theta,1)$ に事前 $N(0,1)$ を使うと、事後は $N(X/2,1/2)$ である。等裾区間の半幅は $z_{1-\alpha/2}/\sqrt2$ だが、固定した $\theta$ の被覆は $P(|Z-\theta|\le\sqrt2 z_{1-\alpha/2})$（$Z\sim N(0,1)$）である。$\theta$ の絶対値を大きくすると被覆はゼロに近づく。適切な確率事前で平均した被覆は事後確率の反復期待値から $1-\alpha$ となる。
:::

### 事前予測で平均したときの被覆

固定した母数についての信頼係数と、事後分布で選んだ区間の確率は、異なる積分の順番から得られる。ただし事前を確率分布として定めると、両者を平均の等式で結べる。

:::proposition[信用集合の事前平均被覆]{#prop-stat-prior-average-coverage}
$\theta\sim\pi$ は確率事前とし、$X\mid\theta\sim P_\theta$ とする。観測ごとに可測な集合 $C(X)$ を返し、周辺分布でほとんど全ての $x$ について $\pi(C(x)\mid x)=1-\alpha$ とする。このとき
$$
\int P_\theta(\theta\in C(X))\pi(\dd\theta)=1-\alpha.
$$
:::

:::proof
共同分布で $\mathbf1_{\{\theta\in C(X)\}}$ を平均する。先に $X$ を $\theta$ の条件付き分布で平均すれば左辺であり、先に $\theta$ を $X$ の条件付き分布で平均すれば定数 $1-\alpha$ である。非負の指示関数なので積分順序を交換できる。
:::

:::example[一部の真値で大きく覆い、他で小さく覆う]
$\theta\sim N(0,\tau^2)$、$X\mid\theta\sim N(\theta,1)$、$\tau^2>0$ とする。平方完成で事後は平均 $wX$、分散 $w$、$w=\tau^2/(1+\tau^2)$ となる。半幅 $z\sqrt w$ の等裾区間について、真値を固定し $X=\theta+Z$、$Z\sim N(0,1)$ と書けば
$$
P_\theta(\theta\in C)=
P\left(\left|Z-\frac{1-w}{w}\theta\right|\le\frac{z}{\sqrt w}\right).
$$
$\tau^2=3$ では $w=3/4$ なので、$\theta=0,z=2$ の被覆は $2\Phi(4/\sqrt3)-1$ で、名目値 $2\Phi(2)-1$ より大きい。一方 $\theta=12$ では平均のずれが $4$ となって、覆う確率は $\Phi(4+4/\sqrt3)-\Phi(4-4/\sqrt3)$ まで下がる。共同モデルで平均する場合は $wX-\theta=(w-1)\theta+w Z$ の分散が $(w-1)^2\tau^2+w^2=w$ となるため、標準化すれば名目被覆が戻る。
:::

### 変換前後で最高密度集合を比べる

等裾の区間は、連続で狭義単調な増加変換のもとで端点がそのまま移る。実際、$u=g(\theta)$ なら $P(u\le g(a)\mid x)=P(\theta\le a\mid x)$ であり、分位点が移る。減少変換では左右の裾が交換される。一方、密度を閾値で切る方法は、密度の値そのものが座標によって変わるため、最短集合が同じ仕方で移るとは限らない。

:::example[単調変換で最高密度の側が入れ替わる]
ある観測後に $\theta$ の事後分布が率 $1$ の指数分布であるとする。密度が単調減少なので、確率 $1-\alpha$ の最高事後密度集合は $[0,-\log\alpha]$ である。ここで $u=1-e^{-2\theta}$ と変換する。$0\le u<1$ での逆写像は $\theta=-\frac12\log(1-u)$、Jacobian は $1/[2(1-u)]$ である。従って $u$ の密度は $[2\sqrt{1-u}]^{-1}$ となり、今度は単調増加する。$u$ で失敗確率 $\alpha$ を左に割り当てると、$P(u<c)=1-\sqrt{1-c}=\alpha$ より下端は $1-(1-\alpha)^2$ である。例えば $\alpha=1/4$ なら $u$ での最高密度集合は $[7/16,1)$ である。一方、$\theta$ での最高密度集合 $[0,\log4]$ を写すと $[0,15/16]$ になり、同じ事後確率でも集合は異なる。どの座標で長さを測るかが選択に影響する。
:::

### 枢軸量と一致する事後分布

一部のモデルでは、採用した事前重みでの事後分布を枢軸量へ写すと、真値での標本分布と一致する。この場合、同じ分位点を使えば信用と信頼の両方の意味を持つ。しかし一致は事前重みとモデルの組に依存し、事後区間一般の性質にはならない。

:::example[指数分布で尺度の重みが枢軸量を再現する]
率 $\lambda$ の指数標本について $A=\sum_i x_i>0$ とする。尤度は $\lambda^n e^{-A\lambda}$ に比例する。重み $\dd\lambda/\lambda$ を掛けると事後密度は $\lambda^{n-1}e^{-A\lambda}$ に比例し、形状 $n$、率 $A$ のガンマ分布になる。$n>0,A>0$ なら積分は有限である。従って事後分布で $2A\lambda$ は $\chi^2_{2n}$ になり、真値固定の標本分布でも同じカイ二乗になる。$n=1,A=3$ で $2A\lambda$ の端に $2,6$ を選べば、率の区間 $[1/3,1]$ の事後確率も被覆も $e^{-1}-e^{-3}$ である。これに対し平坦な重み $\dd\lambda$ では事後形状が $n+1$ になり、枢軸量と同じ分布を得ない。
:::

### 未知分散の正規モデルで t 区間を再現する

独立な $N(\mu,v)$ 標本、$n\ge2$、$v>0$ を考える。事前重み $\dd\mu\,\dd v/v$ は確率分布に正規化できないが、$A=\sum_i(x_i-\bar x)^2>0$ の標本では次の計算で事後分布が得られる。

:::proposition[正規平均と分散の一致する等裾区間]
上の正規モデルと重みで、事後分布の $A/v$ は $\chi^2_{n-1}$ に従い、$(\mu-\bar x)/(s/\sqrt n)$ は $t_{n-1}$ に従う。ここで $s^2=A/(n-1)$ である。従って $\mu$ と $v$ 各々の等裾信用区間は、枢軸量から得る厳密信頼区間に一致する。
:::

:::proof
標本の平方和は $A+n(\mu-\bar x)^2$ に分かれる。従って事後密度の非正規化形は
$$
v^{-n/2-1}\exp[-A/(2v)]\exp[-n(\mu-\bar x)^2/(2v)]
$$
である。$v$ を固定して $\mu$ で積分すると最後の因子の積分は $\sqrt{2\pi v/n}$ になるので、$v$ の周辺密度は $v^{-(n+1)/2}e^{-A/(2v)}$ に比例する。$q=A/v$ と変数変換すると、Jacobian の絶対値は $A/q^2$ であり、密度は $q^{(n-1)/2-1}e^{-q/2}$ に比例する。これは積分有限の $\chi^2_{n-1}$ 密度であり、従って共同事後も正規化できる。

条件付き分布では $\mu\mid v,x\sim N(\bar x,v/n)$ である。ゆえに $Z=(\mu-\bar x)\sqrt{n/v}$ の条件付き分布はどの $v$ でも標準正規であり、$Z$ と $q$ は事後で独立である。よって
$$
\frac{\mu-\bar x}{s/\sqrt n}=\frac{Z}{\sqrt{q/(n-1)}}
$$
は $t_{n-1}$ に従う。枢軸量の二側の確率はこれらの事後分布と同じであり、$v$ については逆数の順序を入れ替えれば事後等裾の端点が信頼区間の端点と一致する。
:::

:::example[事後での分散の形を一段ずらす]
$n=5,A=12,\bar x=4$ を観測したとする。上の重みなら $s^2=3$、$\mu$ の区間は $4\pm t_{4,1-\alpha/2}\sqrt{3/5}$ であり、信頼区間の式と一致する。一方、重みを $\dd\mu\,\dd v/v^{3/2}$ に変えると、$v$ の指数がさらに $-1/2$ だけ減るので $A/v$ は $\chi^2_5$ になる。条件付き正規の式は変わらないから、$\mu$ の区間は $4\pm t_{5,1-\alpha/2}\sqrt{12/25}$ になる。分散の小さい側に重みを増やした結果、事後の t 分布の自由度と尺度が変わる。どちらの事前重みでも事後分布は存在するが、通常の正規標本の平均に対する厳密な被覆の証明は前者に対応する。
:::

### 二項比率での端点を比較する

一様事前のもとで $S=s$ の後の密度は $p^s(1-p)^{n-s}$ に比例するので $\operatorname{Beta}(s+1,n-s+1)$ である。これに対して :ref[prop-stat-clopper-pearson-beta] の二つの端に使う Beta 分布は、一般に互いに形状が違う。従って同じ名称の分位点計算でも、二つの端が一つの事後分布を切り出したものかを確かめる必要がある。

:::example[成功ゼロでの一側の上限]
$n=3,s=0$ で事後は $\operatorname{Beta}(1,4)$ であり、$p$ が事後上限 $u$ を超える確率は $(1-u)^4$ である。事後確率 $3/4$ の集合 $[0,u]$ を返すと $u=1-(1/4)^{1/4}=1-1/\sqrt2$ となる。一方、信頼係数 $3/4$ の片側の上限を厳密反転で作ると、帰無 $p=u$ で $S=0$ の確率は $(1-u)^3$ なので $u=1-(1/4)^{1/3}$ となる。指数が一つ違うのは、事後密度の裾を積分する場合と、標本空間で観測事象の確率を計算する場合で、積分対象が異なるためである。
:::

## 演習問題

::::exercise{#exr-stat-interval-estimation-1 level=basic}
$\sigma=6,n=9,\bar x=4$ の正規平均で $z_{1-\alpha/2}=2$ とする。区間を求めよ。

:::solution
標準誤差は $6/3=2$、半幅は $4$ なので $[0,8]$ である。
:::

::::exercise{#exr-stat-interval-estimation-2 level=basic}
一様端点モデルで $n=3,m=2,\alpha=1/8$ の枢軸区間を求めよ。

:::solution
$\alpha^{1/3}=1/2$ なので $[m,2m]=[2,4]$ となる。
:::
::::

::::exercise{#exr-stat-interval-estimation-3 level=basic}
二項区間で全成功 $s=n=3$ のとき下端を $\alpha=1/4$ について求めよ。

:::solution
上側確率は $p_L^3$ である。$p_L^3=1/8$ を解くと $p_L=1/2$ である。
:::
::::

::::exercise{#exr-stat-interval-estimation-4 level=basic}
$C(X)=[X-1,X+1]$ を反転して $H_u$ の棄却条件を求めよ。

:::solution
$u$ が区間に入らない条件は $X-1>u$ または $X+1<u$ である。従って $|X-u|>1$ で棄却する。
:::
::::

::::exercise{#exr-stat-interval-estimation-5 level=advanced}
$X$ が固定した $(\theta,\theta+1)$ 上の一様分布である。$[X-a,X-b]$（$0\le b<a\le1$）の被覆と長さを求めよ。

:::solution
$\theta$ の被覆は $b\le X-\theta\le a$ と同値である。標準一様分布なので確率は $a-b$ であり、長さも $a-b$ である。端点の割当てを変えてもこの量は変わらない。
:::
::::

::::exercise{#exr-stat-interval-estimation-6 level=advanced}
$x\mapsto e^x$ で信頼区間を移した場合の被覆を証明せよ。

:::solution
指数関数は厳密増加なので $L(X)\le\theta\le U(X)$ と $e^{L(X)}\le e^\theta\le e^{U(X)}$ は同一事象になる。従って両者の被覆は等しい。
:::
::::

::::exercise{#exr-stat-interval-estimation-7 level=advanced}
二つの区間が各 $0.95$ 以上で真値を含むとき、両方が同時に含む確率の下界を求めよ。

:::solution
いずれかが外れる事象の確率は和の上界で $0.05+0.05=0.10$ 以下となる。同時被覆は $0.90$ 以上である。独立性を追加する必要はない。
:::
::::

::::exercise{#exr-stat-interval-estimation-8 level=advanced}
$X\mid\theta\sim N(\theta,2)$、$\theta\sim N(0,2)$ で $x=4$ の事後平均と分散を求めよ。

:::solution
指数の二乗項は $-[(4-\theta)^2+\theta^2]/4$ である。これを $-(\theta-2)^2/2$ と定数に分けると、事後は平均 $2$、分散 $1$ の正規分布である。
:::
::::

::::exercise{#exr-stat-interval-estimation-9 level=advanced}
既知共分散 $I_2$ の正規平均比で $x=0,y=1,z_{1-\alpha/2}=2$ とする。Fieller の集合を求め、なぜこの形になるか説明せよ。

:::solution
二次不等式は $(1-4)r^2-4\le0$、すなわち $-3r^2-4\le0$ である。全ての実数 $r$ が満たすので、集合は $\R$ になる。候補 $r$ に対する標準化値の絶対値は $|r|/\sqrt{1+r^2}<1$ であり、どの比の帰無も閾値 $2$ を超えない。この場合は分母が $0$ と区別できないことに加え、分子も $0$ に整合するため、小さい比も大きい比も残る。
:::
::::

::::exercise{#exr-stat-interval-estimation-10 level=basic}
$n=5$ の連続な独立標本で、母中央値より小さい値を取る確率が $1/2$ であるとする。区間 $[X_{(1)},X_{(5)}]$ と $[X_{(2)},X_{(4)}]$ の被覆を求めよ。

:::solution
中央値より下の個数 $B$ は $\operatorname{Bin}(5,1/2)$ である。最小・最大の区間が外れるのは $B=0,5$ なので、被覆は $1-2/32=15/16$ である。二番目と四番目を使う区間が中央値を含むのは $B=2,3$ のときなので、被覆は $(\binom52+\binom53)/32=5/8$ になる。両裾のそれぞれ一順位を除くと、その順位の確率質量が両方失敗側へ移る。
:::
::::

::::exercise{#exr-stat-interval-estimation-11 level=advanced}
指数標本 $n=1,x=4$ について、率の区間を作る枢軸量 $2X\lambda$ の端を $2,4$ とする。区間の端と被覆確率を求め、事前重み $\dd\lambda/\lambda$ による事後確率と比較せよ。

:::solution
不等式 $2\le8\lambda\le4$ を解くと区間は $[1/4,1/2]$ である。枢軸量は自由度 $2$ のカイ二乗分布なので、被覆は $\int_2^4 e^{-q/2}\dd q/2=e^{-1}-e^{-2}$ になる。事後密度は指数 $e^{-4\lambda}$ に比例し、正規化した密度は $4e^{-4\lambda}$ である。区間で積分すれば $e^{-4(1/4)}-e^{-4(1/2)}=e^{-1}-e^{-2}$ を得る。ここでは同じ数値になったが、前者は標本を動かし、後者は事後の $\lambda$ を動かして求めた確率である。
:::

::::quiz
信頼係数 $0.95$ から従う主張を選べ。

- [x] 各真値を固定したとき、手順が真値を含む頻度は少なくとも $0.95$ である。
- [ ] 全標本で区間の観測後の確率は常に $0.95$ である。
- [ ] 区間の長さは必ず $0.95$ である。

:::explanation
被覆の確率は固定したパラメータのもとで標本を変動させて計算する。区間の長さや、事後分布上の確率とは別の量である。
:::

一様端点モデルで $n=2,m=3,\alpha=1/4$ とする。枢軸区間の上端を答えよ。

:::explanation
$P(M/\theta\ge1/2)=1-(1/2)^2=3/4$ なので $\theta\le2M$ を上端の条件にする。答えは $6$ である。

- [x] 棄却されなかった候補すべてを集める。
- [ ] p 値が最も小さい候補だけを返す。

:::explanation

::::quiz{answer="0.875" tol="1e-6"}

:::explanation
