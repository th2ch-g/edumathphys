## この章の目標

- 常微分方程式の解と初期条件を区別し、方向場から解の傾きを読む。
- 変数分離、積分因子、未知関数の置換を使い分ける。
- 割り算で除いた解や、陰関数で表した解の定義区間を確認する。
- 自励方程式と低階に直せる方程式を積分で解く。

## 微分方程式と解の概念・方向場

曲線の値を各点で直接指定する代わりに、その点での傾きを指定することがある。例えば $y'=2y$ は横軸の上で上向き、下で下向きの傾きを与える。傾きの指定だけでは曲線は一つに定まらないので、どの点を通るかという情報を別に与える。

:::definition[常微分方程式と解]{#def-ode-equation}
独立変数が一つの未知関数 $y$ とその導関数に関する関係を :term[常微分方程式]{en="ordinary differential equation" yomi="じょうびぶんほうていしき"} という。現れる導関数の最大次数を**階数**という。$n$ 階方程式 $F(x,y,y',\ldots,y^{(n)})=0$ の古典解とは、開区間 $I$ 上の $C^n$ 関数であって、すべての $x\in I$ で引数が $F$ の定義域に属し、関係を満たすものである。
:::

$x=x_0$ での $y,y',\ldots,y^{(n-1)}$ の値を指定することを :term[初期条件]{en="initial condition" yomi="しょきじょうけん"} といい、方程式と初期条件を合わせた問題を :term[初期値問題]{en="initial value problem" yomi="しょきちもんだい"} という。端点が二つある区間で両端に条件を置く問題は [境界値問題と Sturm–Liouville 理論](/math/ode/boundary-value/) で扱う。

:::example[正規形と陰形式]
$y''=-y$ では最高階の導関数が陽に解かれており、例えば $y(x)=2\cos x+3\sin x$ は初期条件 $y(0)=2,\ y'(0)=3$ を満たす。これに対して $(y')^2=4$ では、導関数として $2$ と $-2$ の二つが許される。連続な $y'$ が連結な区間で符号を変えれば中間値として $0$ を取るため、解は $y=2x+C$ または $y=-2x+C$ である。同じ初期値 $y(0)=1$ を通る二本の解がある。
:::

場合によっては最高階の導関数の係数そのものが消える。例えば $xy'=y$ は $x\ne0$ で $y'=y/x$ と書ける。元の式は $x=0$ で $y(0)=0$ を要求する。左右で $y=C_{\pm}x$ としたとき、原点での微分可能性は $C_+=C_-$ を要求するので、原点を含む区間の解は $y=Cx$ である。係数で割った式の定義域と元の式の定義域を分けて確認する。

:::definition[方向場]{#def-ode-slope-field}
陽な 1 階方程式 $y'=f(x,y)$ に対し、$f$ が定義された各点 $(x,y)$ に傾き $f(x,y)$ の方向を割り当てたものを :term[方向場]{en="slope field" yomi="ほうこうば"} という。横成分を $1$ に固定した接ベクトルは $(1,f(x,y))$ である。
:::

:::example[零勾配線と対角線の通過]
$y'=x-y$ では $y=x$ 上で傾きが $0$、$y<x$ で正、$y>x$ で負である。差 $d=y-x$ を取ると $d'=-d-1$ であるから、$d=0$ では $d'=-1$ となる。従ってグラフは $y=x$ を上側から下側へ横切る。例えば $(0,0)$ を通る解は $y=x-1+e^{-x}$ であり、$x>0$ で $y-x=e^{-x}-1<0$ となる。
:::

ある傾き $m$ を持つ点の集合 $f(x,y)=m$ は :term[等傾線]{en="isocline" yomi="とうけいせん"} である。上の例で $m=1$ なら $y=x-1$ であり、この等傾線そのものが解である。一方、$m=0$ の等傾線 $y=x$ は傾き $1$ の直線なので解ではない。このように、等傾線が解となるには、その線自身の傾きが割り当てられた値と一致する必要がある。

:::example[方向場から刻み幅を持つ近似を作る]
$y'=y,\ y(0)=1$ に対し、現在位置の傾きで幅 $1/2$ だけ進むと順に $(1/2,3/2)$ と $(1,9/4)$ を得る。各区間で初めの点の傾きを使う近似は :term[Euler 法]{en="Euler method" yomi="おいらーほう"} である。厳密な解は $e^x$ であり、$1+1/2<e^{1/2}$ なので $9/4<e$ である。近似点に到達したことと、その点が元の解上にあることは区別する。
:::

### 高階方程式の状態変数

最高階について $y^{(n)}=f(x,y,\ldots,y^{(n-1)})$ と解けるとき、$u_j=y^{(j-1)}$ と置く。すると $u_j'=u_{j+1}$（$j<n$）、$u_n'=f(x,u_1,\ldots,u_n)$ である。逆にこの系の $C^1$ 解から、前の $n-1$ 本の式を順に使って $u_1^{(j)}=u_{j+1}$ を得る。最後の式により $u_1$ は元の $C^n$ 解になる。初期値 $u(x_0)$ は初期条件の組をそのまま持つ。

例えば $y''+3y'+2y=0$ を $u=y,\ v=y'$ として書けば $u'=v,\ v'=-2u-3v$ となる。初期状態 $(u,v)=(1,0)$ において速度ベクトルは $(0,-2)$ である。ここで横軸は状態変数 $u$ であり、$(x,y)$ 平面で描いた 1 階方程式の方向場とは座標の意味が異なる。この表示は [線形微分方程式系](/math/ode/linear-systems/) で一般化する。

### 方程式を作る際の初期条件

一定体積 $V$ の容器に濃度 $c_{\rm in}$ の溶液を毎秒 $q$ の体積だけ注ぎ、同量を排出する。溶質が瞬時に一様に混ざると仮定すると、溶質の量 $m=Vc$ は、流入 $q c_{\rm in}$ と流出 $q c$ の差に従う。従って $c'=(q/V)(c_{\rm in}-c)$ である。$q/V$ は時間の逆数であり、傾きは濃度を時間で割った単位を持つ。初期濃度 $c(0)$ だけを指定すれば、初期の濃度変化率はこの式から決まる。

:::example[一つの初期値が傾きも決める]
$V=10\ \mathrm L,\ q=2\ \mathrm{L/min},\ c_{\rm in}=3\ \mathrm{g/L}$、初期濃度 $1\ \mathrm{g/L}$ とする。分を時間の単位に取ると、$c=3-2e^{-t/5}$ である。時間 $5\ \mathrm{min}$ で初期濃度と流入濃度の差が $1/e$ 倍になる。初期変化率は $2/5\ \mathrm{(g/L)/min}$ であり、これと異なる $c'(0)$ を独立に課すと、同じモデルには解がない。増加率が一定とみなせるのは $t/5$ が小さい間で、$e^{-t/5}=1-t/5+O(t^2)$ から分かる。
:::

二階の位置方程式では、同じ位置でも速度によって未来が異なる。例えば $y''=-4y$ で $y(0)=0$ とすると $y(t)=v_0\sin(2t)/2$ となり、正負の $v_0$ で原点を出る方向が逆になる。従って状態を $(y,y')$ とまとめるのは、位置だけでは初期条件として足りないことを式で表すためである。

### 陰形式から方向場が得られる条件

$F(x,y,p)=0$ の近くに、$F(x_0,y_0,p_0)=0$ かつ $F_p(x_0,y_0,p_0)\ne0$ を満たす点があるとする。$F$ が $C^1$ なら :ref[thm-anl-implicit-function] により、$p_0$ に近い枝に限って $p=f(x,y)$ と書ける。$f$ は $C^1$ なので、この傾きの枝には、[解の存在と一意性](/math/ode/existence-uniqueness/) で扱う局所存在・一意性の定理を適用できる。枝ごとの一意性が意味するのは、点だけでなく傾きの近傍も選んだということである。

:::example[同じ点で傾きが二つある]
$(y')^2=y$ で $(0,1)$ を考える。許される傾きは $p=\pm1$ であり、どちらも $F_p=2p\ne0$。解は初期点の近くで $y=(1+x/2)^2$ と $y=(1-x/2)^2$ である。例えば前者の $y'$ は $1+x/2$ なので、$x>-2$ では正の枝を使う。$x=-2$ に達すると $F_p=0$ となり、元の式はそこでも値と導関数が零の枝を許す。$x<-2$ で $y=0$ とつなぐことも、反対の傾きの枝で同じ放物線を続けることもできる。
:::

:::example[傾きの二枝が合流する点]{#exm-ode-implicit-branch-pasting}
$F(x,y,p)=(p-1)^2-x^2=0$、$y(0)=0$ とする。$x\ne0$ では $p=1+x$ と $p=1-x$ が相異なる。連続な傾きは片側の連結区間上でどちらか一方を選ぶ。例えば右側で枝を替えるなら、$(y'-1)/x$ が $1$ から $-1$ に変わる途中で $0$ を通るはずだが、それでは方程式を満たさない。

片側ごとに積分し、連続性で積分定数を決めると、$x<0$ で $y=x+\sigma_-x^2/2$、$x>0$ で $y=x+\sigma_+x^2/2$ となる。ただし $\sigma_-,\sigma_+\in\{-1,1\}$ である。原点で両側の差商が $1$ に近づき、導関数も両側から $1$ に近づく。従って四通りの $C^1$ 解があり、すべて原点で $F(0,0,1)=0$ を満たす。

一方、$C^2$ 解を求めるなら、原点での二階導関数が存在する必要がある。導関数の差商は左右それぞれ $\sigma_-,\sigma_+$ だから、二つの符号が一致する二通りだけが残る。ここでは初期値も初期傾きも一致するため、解の階数と枝の選択をそれぞれ確認する必要がある。
:::

### 時刻と状態に付ける単位

時刻 $t$ を秒で、位置 $q$ をメートルで測ると、$q'$ の単位は $\mathrm{m\,s^{-1}}$ である。例えば $q'=3\,\mathrm{m\,s^{-1}}-q/(2\,\mathrm{s})$ の右辺は二項とも速度である。$t=2\,\mathrm{s}\,\tau$、$q=6\,\mathrm m\,u$ と置けば $q'=3\,\mathrm{m\,s^{-1}}u_\tau$ であり、$u_\tau=1-u$ となる。方向場の傾き $1-u$ は、縦軸と横軸をこの尺度で測ったときの傾きである。軸の縮尺を変えると線分の角度は変わるが、解が時刻の増加とともに上昇するか下降するかは変わらない。

## 変数分離形と同次形

### 変数分離形と積分の逆写像

$y'=a(x)b(y)$ では、$x$ の寄与と $y$ の寄与が積に分かれる。$b$ が消えない範囲では $1/b$ を掛けることで、左辺を $y$ のみの関数の微分として扱える。

:::proposition[変数分離]{#prop-ode-separation}
$a,b$ はそれぞれ開区間 $I,J$ 上で連続とする。$b$ が $J$ で消えず、$(x_0,y_0)\in I\times J$ とする。$B(y)=\int_{y_0}^{y}b(s)^{-1}\,\dd s$、$A(x)=\int_{x_0}^{x}a(s)\,\dd s$ とおく。$A(x)\in B(J)$ となる集合のうち $x_0$ を含む連結成分上で、$J$ に値を取る初期値解は $y=B^{-1}(A(x))$ で与えられる。
:::

:::proof
:ref[thm-anl-ftc] により $B'=1/b$ は連続で一定符号を持つ。従って $B$ は狭義単調で、:ref[thm-anl-inverse-function] から $B^{-1}$ は $C^1$ である。解ならば合成の微分により $(B(y(x)))'=a(x)$ となるので、初期条件を使って積分すれば $B(y(x))=A(x)$ を得る。逆にこの等式から $y'=a(x)b(y)$ が従い、$x=x_0$ で $B(y)=0$ なので $y=y_0$ である。
:::

$b(c)=0$ のときは $y=c$ が解である。$a$ が $0$ になることは上の証明に影響しない。実際に割った量は $b(y)$ のみである。

:::example[有限の時間で発散する枝]
$y'=xy^2$ で $y(0)=1$ とする。$(-1/y)'=x$ から $y=1/(1-x^2/2)$ となる。この解の区間は $(-\sqrt2,\sqrt2)$ まで広げられる。両端で値が発散するため、その区間を越えて連続にはつなげられない。外側で同じ有理式を評価して得る曲線は別の区間の解である。初期値が $0$ なら定数解 $y=0$ がある。
:::

:::example[ロジスティック方程式の三つの領域]
$y'=2y(1-y)$ の平衡値は $0,1$ である。それ以外では $1/[y(1-y)]=1/y+1/(1-y)$ だから、
$$
\log\abs{\frac{y}{1-y}}=2x+C.
$$
$y(0)=a\ne0,1$ とすると、符号を初期値から戻して $y=a/[a+(1-a)e^{-2x}]$ を得る。$a=1/2$ なら全実軸で $0<y<1$ を保つ。$a=2$ なら $x=-(\log2)/2$ が左側の発散端となり、$a=-1$ なら $x=(\log2)/2$ が右側の発散端となる。いずれも式の分母の零点と初期時刻の位置から決める。
:::

:::example[有限時間で平衡解に接続する]
$y'=2\sqrt{\abs y}$ で $y\ge0$ の枝は $\sqrt y=x-c$、従って $x>c$ で $y=(x-c)^2$ である。$x\le c$ では $y=0$ と置けば、値と一階導関数が $x=c$ で一致し、方程式もその点で満たされる。$c\ge0$ の任意の選択が $y(0)=0$ を満たす。$1/b$ が端点付近で積分可能であるため、逆写像で作った枝が有限時刻で $0$ に届く。
:::

### 比 $y/x$ の置換

$f(x,y)=H(y/x)$ となる方程式は $x$ と $y$ を同じ比率で変えても傾きが同じである。この形を :term[同次形微分方程式]{en="homogeneous differential equation" yomi="どうじけいびぶんほうていしき"} という。$x>0$ と $x<0$ は別々に扱い、$v=y/x$ と置くと
$$
xv'=H(v)-v.
$$
右辺の零点 $v=c$ は直線 $y=cx$ を与える。零点以外では $v$ に関する分離ができ、$\int \dd v/(H(v)-v)=\log\abs{x}+C$ を得る。この節の「同次形」は変数の比に関する性質であり、線形方程式の右辺が $0$ であることを表す「斉次」と用法が異なる。

:::example[正規形で除かれる点]
$y'=y/x+(y/x)^2$ では $v'=v^2/x$ となる。従って $y=0$ または $y=-x/(\log\abs x+C)$ である。$y(1)=1$ なら $C=-1$ であり、解の区間は $(0,e)$ となる。$x=0$ の手前で $y$ の極限は $0$ だが、元の式に $y/x$ があるため、$x=0$ を含む解の区間にはできない。
:::

:::example[平行移動で同次形に戻す]
$y'=(x+y-3)/(x-y+1)$ を考える。分子・分母が同時に消える点 $(1,2)$ を新しい原点とし、$X=x-1,\ Y=y-2$ と置く。すると $Y'=(X+Y)/(X-Y)$ であり、$v=Y/X$ は
$$
Xv'=\frac{1+v^2}{1-v}.
$$
従って $\arctan v-\tfrac12\log(1+v^2)=\log\abs X+C$ である。$v=1$ では元の式が定義されないので、初期点と同じ側の枝を選ぶ。$X=0,\ Y\ne0$ では元の式が定義されるため、置換の除外点を元の式の特異点と同一視しない。
:::

### 異なる倍率で拡大する準同次形

$x>0$ で $f(\lambda x,\lambda^m y)=\lambda^{m-1}f(x,y)$（$\lambda>0$）となる場合を考える。このような :term[準同次形]{en="quasi-homogeneous equation" yomi="じゅんどうじけい"} では、$x$ を $\lambda$ 倍したときに $y$ を $\lambda^m$ 倍すると方程式の形が保たれることを表す。$\lambda=1/x$ とすれば $f(x,y)=x^{m-1}f(1,y/x^m)$。従って $y=x^m v$ を代入すると $xv'=f(1,v)-mv$ となり、通常の同次形と同じ分離積分が使える。$f(1,c)=mc$ の根は分離で除かれるが、元の方程式の解 $y=cx^m$ を与える。

:::example[二次の拡大で不変な方程式]
$y'=2y/x+y^2/x^3$、$x>0$ とする。このとき $m=2$ であり、$y=x^2v$ を代入すると $xv'=v^2$。$y(1)=2$ なら $v(1)=2$ だから
$$
y(x)=\frac{x^2}{1/2-\log x}\qquad(0<x<\sqrt e).
$$
この式は $y(1)=2$ を満たす。分母の零点 $\sqrt e$ では解が発散する。左端 $0$ では $y,y'$ がともに零へ近づくが、$x$ を分母に持つ方程式自体はそこで定義されない。準同次の置換で除いた $v=0$ は元の式の零解である。
:::

### 平衡値に達するまでの時間

自励な分離形 $y'=b(y)$ では、$b>0$ の区間を上向きに進む時間が $\int \dd y/b(y)$ に等しい。$b(c)=0$ でも、その積分が有限なら非定常な枝が $c$ に達する。逆に、$0<b(y)\le C|y-c|$ なら $1/b$ の積分は発散し、有限時間では到達しない。

:::example[消える次数による到達時刻の違い]
$y'=-3 y^\gamma$、$y(0)=1$ を $y\ge0$ で考える。$0<\gamma<1$ なら
$$
y^{1-\gamma}=1-3(1-\gamma)t
$$
であり、$t_*=1/[3(1-\gamma)]$ で $0$ に達する。左導関数は $-3y^\gamma\to0$ なので、その先を $0$ とすると $C^1$ 解である。例えば $\gamma=1/3$ では $y=(1-2t)^{3/2}$、$t_*=1/2$。$\gamma=1$ なら $y=e^{-3t}$、$\gamma=2$ なら $y=1/(1+3t)$ となり、いずれも有限時間では $0$ に達しない。$b$ の零点が同じでも、到達時刻を決めるのはその近くの積分である。
:::

### 分子と分母が平行な場合の置換

$y'=(a x+b y+c)/(d x+e y+f)$ で $(a,b)$ と $(d,e)$ が独立なら、それらの零直線の交点に原点を移せば同次形になる。二つの対が比例する場合は交点が存在しないことがあり、代わりに共通の一次式を独立な未知関数として分離する。

:::example[交点を探す代わりに一次式そのものを使う]
$y'=(2x+y+1)/(2x+y-1)$ とする。$u=2x+y$ と置けば $u'=(3u-1)/(u-1)$。$u=1/3$ は平衡解なので $y=1/3-2x$ である。その他の枝では
$$
x+C=\int\frac{u-1}{3u-1}\dd u
=\frac u3-\frac29\log\abs{3u-1}.
$$
$u=1$ では元の方程式が定義されない。例えば $u(0)=0$ なら $C=0$ で、$u\in(-\infty,1/3)$ では右辺の導関数 $(u-1)/(3u-1)$ が正である。$x\to+\infty$ で $u\uparrow1/3$、$x\to-\infty$ で $u\to-\infty$ となる。ここでは原点から出た枝は元の分母の零点へは向かわない。
:::

分離積分の式が明示的に逆転できなくても、単調性で一つの枝を特定できる。上の例では二次方程式のように根を全て代数式で並べる必要はなく、積分後の関数の値域を調べれば定義区間が決まる。

### 非単調な時間係数による折り返し

変数分離形 $y'=a(x)b(y)$ で $a$ が符号を変えると、$B^{-1}(A(x))$ は同じ値を往復する。例えば $y'=2x\,y(1-y)$、$y(0)=1/2$ なら
$$
y(x)=\frac{1}{1+e^{-x^2}}.
$$
この解は $x=0$ で値 $1/2$ を取り、左右の遠方で $1$ に近づく。$a(x)=2x$ を分母に移して $x$ を $y$ の関数と考えると、$x=0$ で可逆性を失う。:ref[prop-ode-separation] のように $b(y)$ だけで割っておけば、$a=0$ の時刻をまたいで同じ積分式が使える。

:::example[原点を通らない同次形の解を延長する]
$y'=2-y/x$ を $x>0$ で解き、$y(1)=0$ とする。独立変数と従属変数の比を $v=y/x$ とすると $xv'=2-2v$ である。定数解 $v=1$ は直線 $y=x$ に対応する。初期値は $v(1)=0$ なのでこの直線の下側の枝を取る。

$w=1-v$ とすると $w'=-2w/x$ である。$w(1)=1$ を用いて $\log w=-2\log x$、従って $y=x-x^{-1}$ を得る。実際 $y'=1+x^{-2}=2-y/x$ である。導出に使った $w>0$ は $w=x^{-2}$ で全区間にわたって保たれる。

この解は $x\downarrow0$ で $-\infty$ へ向かう。元の式は $x=0$ で定義されないが、分母を払った式 $xy'=2x-y$ へ変更しても、この初期値から出た解は連続に延長できない。一方、除外した定数枝 $y=x$ は分母を払った式なら原点を通過する。元の式の定義域と、式を変えた後の解の延長は別々に確かめる。
:::

:::example[平行移動して同次形にする]
$y'=(y-1)/(x-2)+2$ を $x>2$ で考える。$X=x-2$、$Y=y-1$ と置けば $Y'=Y/X+2$。従って $Y=Xv$ を代入して $v+Xv'=v+2$、$v'=2/X$ となる。$y(3)=2$ を指定すると $X=1$ で $v=1$ だから、
$$
y(x)=1+(x-2)\{1+2\log(x-2)\}\qquad(x>2)
$$
である。

$X\downarrow0$ で $X\log X\to0$ なので、$y$ は値 $1$ へ連続に近づく。一方 $y'=3+2\log X$ は $-\infty$ に発散する。従って分母を払った全平面の式 $(x-2)y'=y-1+2(x-2)$ でもこの枝は $C^1$ に延びない。式を満たす初期点 $(2,1)$ があることと、そこを通る滑らかな解があることは別の条件である。
:::

## 1 階線形方程式

$y'+p(x)y=q(x)$ で、積 $(\mu y)'$ を作るには $\mu'=\mu p$ が必要である。この条件を満たす零でない $\mu$ を求めれば、右辺の積分だけで $y$ が決まる。

:::theorem[1 階線形方程式の求積]{#thm-ode-scalar-linear}
$p,q$ を開区間 $I$ 上の実数値または複素数値の連続関数とし、$x_0\in I$ とする。$\mu(x)=\exp\int_{x_0}^{x}p(s)\,\dd s$ とおく。初期条件 $y(x_0)=y_0$ を満たす解は $I$ 全体で一意で、
$$
y(x)=\frac{y_0+\int_{x_0}^{x}\mu(s)q(s)\,\dd s}{\mu(x)}.
\label{eq-ode-scalar-if}
$$
:::

:::proof
$\mu(x_0)=1,\ \mu'=\mu p$ であるため、$(\mu y)'=\mu(y'+py)=\mu q$ である。これを初期点から積分すれば :eqref[eq-ode-scalar-if] が必要となる。逆に指数関数 $\mu$ は零にならないため、式の右辺は $I$ 上で $C^1$ であり、積分の微分と初期点への代入により両条件を満たす。
:::

この $\mu$ は :term[積分因子]{en="integrating factor" yomi="せきぶんいんし"} と呼ばれる。同じ右辺 $q$ を持つ二つの解の差は斉次方程式を満たす。斉次解は $C/\mu$ だから、非斉次の特解 $y_p$ を一つ知っていれば全解は $y_p+C/\mu$ となる。

:::example[積分の係数をそろえる]
$y'+2y=3x,\ y(0)=1$ に対して $\mu=e^{2x}$ である。部分積分により $\int_0^x 3s e^{2s}\dd s=e^{2x}(3x/2-3/4)+3/4$ だから
$$
y=\frac32 x-\frac34+\frac74 e^{-2x}.
$$
最初の二項が特解であり、最後の項が初期値の選択を記録する。
:::

:::example[同じ積分因子を使う定数変化法]
$y'-xy=x$ では斉次解 $C e^{x^2/2}$ を得る。$C=C(x)$ と変えると、$C'e^{x^2/2}=x$、従って $C=-e^{-x^2/2}+C_0$ である。よって $y=-1+C_0e^{x^2/2}$ となる。$C(x)=\mu(x)y(x)$ と同じ量を先に未知関数に取ったため、積分因子法と同じ計算である。
:::

### 首項の係数が消える場合

$a(x)y'+b(x)y=c(x)$ を $a(x)$ で割る場合、$a\ne0$ の連結区間を先に決める。解を係数の零点に延ばせるかは、元の式と要求する滑らかさから調べる。

:::example[一意性が失われる退化点]
$xy'-2y=0$ を $x\ne0$ で解くと $y=Cx^2$ となる。原点を含む区間では、左右の定数を独立に $C_-,C_+$ とし、$y(0)=0$ と置いても $C^1$ である。原点では $xy'-2y=0$ も満たす。初期条件 $y(0)=0$ から一つの解が選べないのは、正規形の係数 $-2/x$ が原点で連続でないからである。さらに $C^2$ を要求すると二階導関数の左右極限が一致し、$C_-=C_+$ が必要になる。
:::

:::example[入力が初期値より強い影響を持つ場合]
$y'+y=e^{2x}$ の $x=0$ からの解は $y=(y_0-1/3)e^{-x}+e^{2x}/3$ である。二つの初期値の差は $e^{-x}$ 倍に縮む一方、解自体は $x\to+\infty$ で発散する。入力に対する応答と、入力を固定したときの初期値への感度は、別々の項から読む。
:::

### 積分因子の正規化と長時間応答

$\mu$ の積分の起点を替えると $\mu$ は一つの非零定数倍に変わる。起点を変えた因子を $\widetilde\mu$ とすると、式 :eqref[eq-ode-scalar-if] の分子の初期項は $\widetilde\mu(x_0)y_0$ となる。従って初期項、積分項、分母の三箇所で同じ定数が掛かり、解は変わらない。時間 $s$ に加わった右辺の寄与が時刻 $x$ に残る割合を $K(x,s)=\exp(-\int_s^x p)$ と書けば、$x\ge x_0$ で
$$
y(x)=K(x,x_0)y_0+\int_{x_0}^x K(x,s)q(s)\dd s
$$
となる。$p\ge p_0>0$ の場合は $0<K(x,s)\le e^{-p_0(x-s)}$。特に $|q|\le Q$ なら
$$
|y(x)|\le |y_0|e^{-p_0(x-x_0)}+\frac{Q}{p_0}(1-e^{-p_0(x-x_0)})
$$
である。初期値と昔の入力の効果が時間とともに減ることは、この核の評価から従う。

:::example[入力が時間の途中で止まる場合]
$y'+2y=4$ を $0<x<1$、$y'+2y=0$ を $x>1$ で解き、$y(0)=0$ として値を連続につなぐ。前半は $y=2(1-e^{-2x})$。後半では $x=1$ の値が新しい初期値となり、$y=2(1-e^{-2})e^{-2(x-1)}$ である。$x=1$ における微分の差は右辺の跳び $-4$ であり、値には跳びがない。連続入力の場合の古典解と、切替点を許す区分的な解では微分可能性の条件が異なる。
:::

:::example[係数の減衰で初期値の効果が残る]
$y'+(1+x)^{-2}y=0$、$x\ge0$ を解く。積分は $1-1/(1+x)$ なので $y=y_0 e^{-1+1/(1+x)}$。係数は正であるが積分が有限値に収束するため、$y\to e^{-1}y_0$ となる。$p(x)$ の正値性だけでは初期値の効果が消えるとは言えず、$\int_0^\infty p=+\infty$ のときに斉次解が零へ向かう。
:::

### 一つの周期解を選ぶ

$p,q$ がともに周期 $T$ を持つとする。$x_0=0$ から出た解の時刻 $T$ での値は $K(T,0)y_0+\int_0^T K(T,s)q(s)\dd s$ である。これが $y_0$ に等しければ、時刻を $T$ ずらしても同じ初期値問題になるので :ref[thm-ode-scalar-linear] により周期的である。$P=\int_0^T p(s)\dd s$ とおく。$e^{-P}\ne1$ ならこの等式は $y_0$ を一つに定める。$e^{-P}=1$ なら、入力の積分項が零の場合に全初期値が周期解を与え、そうでなければ周期解はない。実係数では $e^{-P}=1$ は $P=0$ と同値であり、複素係数では $P\in 2\pi i\Z$ と同値である。

例えば $y'+y=\sin x$ の周期解は $(\sin x-\cos x)/2$ である。ここから初期条件が違えば差は $Ce^{-x}$。周期の外力が存在することと、任意の初期値が周期解を与えることは別の条件である。

### 首項と初期条件が同時に変わる問題

:::example[首項が零となる点で、解の次数を比較する]
$x y'+y=x^2$ は $x\ne0$ において $(xy)'=x^2$ なので $y=x^2/3+C/x$ である。$x=0$ に連続に延ばすためには、左右それぞれで $C=0$ が必要である。そこで残る $y=x^2/3$ は原点を含めて滑らかで、元の式を満たす。反対に $xy'-y=x^2$ では $(y/x)'=1$ なので $y=x^2+Cx$。連続性は任意の左右の定数を許すが、$C^1$ を要求すると両側の $C$ が一致する。いずれにも係数の退化点があるが、発散を除く条件と傾きをそろえる条件が異なる。
:::

:::example[定数入力に対する時間依存の係数]
$y'+\frac2{1+x}y=1,\ y(0)=0$ を $x>-1$ で解く。因子は $(1+x)^2$、従って
$$
y=\frac{\int_0^x(1+s)^2\dd s}{(1+x)^2}
=\frac{1+x}{3}-\frac1{3(1+x)^2}.
$$
これに対し斉次解は $C/(1+x)^2$。従って初期値の影響は指数ではなく二次の逆数で消える一方、一定の入力に対する応答は線形に増える。$x=-1$ での発散を消すには初期値を $1/3$ に変更する必要がある。その場合に得る $(1+x)/3$ は、元の式に $(1+x)$ を掛けた方程式に限って、$x=-1$ も含めて解となる。
:::

:::example[複素係数で一周期の指数因子が 1 になる場合]
$y'+iy=e^{-ix}$ を $T=2\pi$ で考える。積分因子は $e^{ix}$、従って $(e^{ix}y)'=1$ であり、解は $y=e^{-ix}(y_0+x)$ である。一周期の斉次発展は $e^{-2\pi i}=1$ だが、$y(2\pi)-y(0)=2\pi$ なので周期解は存在しない。右辺を $1$ に変更すると積分因子を掛けた右辺は $e^{ix}$ となり、一周期の積分は零である。この場合は $y=e^{-ix}y_0+(1-e^{-ix})/i$ なので、全ての初期値で周期解になる。
:::

## 完全微分方程式と積分因子

1 階方程式を $M(x,y)\dd x+N(x,y)\dd y=0$ と書くとき、グラフ解の条件は $M(x,y(x))+N(x,y(x))y'(x)=0$ である。もし左辺がある関数の全微分なら、解のグラフ上でその関数が一定になる。

:::definition[完全微分形]{#def-ode-exact}
開集合 $D\subset\R^2$ 上の微分形式 $M\dd x+N\dd y$ が、$F_x=M,\ F_y=N$ を満たす関数 $F$ を持つとき :term[完全微分形式]{en="exact differential form" yomi="かんぜんびぶんけいしき"} という。$F$ をポテンシャルと呼ぶ。
:::

:::theorem[長方形での完全性の判定]{#thm-ode-exact-rectangle}
$D=I\times J$ を開長方形とし、$M,N\in C^1(D)$ とする。完全であるための必要十分条件は $M_y=N_x$ である。
:::

:::proof
ポテンシャルがあれば $F$ は $C^2$ なので、混合偏微分を交換して必要性を得る。逆に $(a,b)\in D$ を取り、
$$
F(x,y)=\int_a^x M(s,b)\dd s+\int_b^y N(x,t)\dd t
$$
とする。$F_y=N$ であり、$F_x=M(x,b)+\int_b^y N_x(x,t)\dd t=M(x,y)$ である。最後の等式では仮定と微積分の基本定理を使った。
:::

$F(x,y(x))$ を微分すると $M+Ny'$ になるので、グラフ解はちょうど $F$ が一定となるグラフである。$N(x_0,y_0)\ne0$ なら :ref[thm-anl-implicit-function] により、局所的に一意なグラフが得られる。一方、$N=0,\ M\ne0$ ならその点を通る有限傾きのグラフ解は存在しない。等位線を $x$ の $y$ に関する関数として描くことはできる。

:::example[楕円の一部分がグラフ解となる]
$2x\dd x+8y\dd y=0$ のポテンシャルは $F=x^2+4y^2$ である。$(0,1)$ を通る枝は $(-2,2)$ 上で $y=\tfrac12\sqrt{4-x^2}$。楕円全体は同じ等位集合に属するが、下半分では $y(0)=-1$ となる。さらに $x=\pm2$ では $N=0$ かつ $M\ne0$ である。
:::

:::example[閉じている形式と大域的なポテンシャル]
原点を除いた平面上で
$$
M=-\frac{y}{x^2+y^2},\qquad N=\frac{x}{x^2+y^2}
$$
とおく。$M_y=N_x=(y^2-x^2)/(x^2+y^2)^2$ なので、各点の近くの長方形ではポテンシャルがある。しかし円 $(\cos t,\sin t)$ に沿う積分は $\int_0^{2\pi}1\dd t=2\pi$ である。大域的な $F$ があれば閉曲線に沿う積分は合成の微分の積分になり $0$ となるので、矛盾する。
:::

### 一変数に依存する積分因子

$\mu M\dd x+\mu N\dd y$ が完全であるための微分条件は $(\mu M)_y=(\mu N)_x$ である。$\mu=\mu(x)$ と仮定すれば
$$
\mu'N=\mu(M_y-N_x),
$$
となるため、$N\ne0$ の長方形で $(M_y-N_x)/N$ が $x$ のみの関数 $g$ なら $\mu=e^{\int g}$ を取れる。同様に $\mu=\mu(y)$ であれば、$M\ne0$ の範囲で $(N_x-M_y)/M$ が $y$ のみの関数であることを調べる。$\mu$ を掛ける前後で解が同じなのは $\mu\ne0$ のためである。

:::example[$x$ の積分因子]
$(y+x)\dd x+x\dd y=0$ は最初から完全で、$F=xy+x^2/2$ を持つ。これに対して $(2y+x)\dd x+x\dd y=0$ では、$x>0$ で $(M_y-N_x)/N=1/x$ なので $\mu=x$ を取る。ポテンシャル $F=x^2y+x^3/3$ から $y=C/x^2-x/3$ となる。$x<0$ でも $x$ は消えないので同じ因子が使える。
:::

:::example[$y$ の積分因子]
$y\dd x+3x\dd y=0$ では $(N_x-M_y)/M=2/y$ である。$y\ne0$ で $\mu=y^2$ を取ると $F=xy^3$ が得られる。元の式のグラフ解 $y=0$ も別に確認できる。ここで $y=0$ において $\mu=0$ だから、因子を掛けた式と元の式の点ごとの同値性はそこでは保証されない。
:::

一般の $\mu(x,y)$ に対して積の条件を展開すると、$N\mu_x-M\mu_y=(M_y-N_x)\mu$ となる。グラフ解を曲線 $(x(s),y(s))$ に拡張して $(\dot x,\dot y)=(N,-M)$ を考えると、その曲線に沿う $\mu$ の方程式は 1 階線形である。従って二変数の積分因子を探す問題は、元の曲線の求積と同程度の情報を必要とする場合がある。

### 星状領域でポテンシャルを作る

点 $O$ と領域内の任意の点を結ぶ線分が領域に含まれるとき、その領域は $O$ に関して星状であるという。$O$ を原点とし、$M_y=N_x$ なら
$$
F(x,y)=\int_0^1 [xM(tx,ty)+yN(tx,ty)]\dd t
$$
と置ける。実際、$x$ で微分した被積分関数は $M+t x M_x+t y N_x=M+t x M_x+t y M_y$。これは $tM(tx,ty)$ の $t$ 微分なので積分は $M(x,y)$ となる。$y$ 微分も同様に $N$ である。長方形の方法が折れ線を使ったのに対し、星状の条件では原点からの線分が使える。

:::example[混合項を線分積分で復元する]
$M=3x^2+2xy,\ N=x^2+4y^3$ は $M_y=N_x=2x$ である。線分上の積分では $xM(tx,ty)+yN(tx,ty)=3t^2x^3+3t^2x^2y+4t^3y^4$。従って $F=x^3+x^2y+y^4$。例えば $(0,1)$ を通る等位集合は $F=1$ で、そこで $F_y=4\ne0$ なので $x$ を独立変数に取れる。$F_x=0$ でも $F_y\ne0$ なら、グラフの傾きは零となるだけである。
:::

### 同次な一形式に使える積分因子

$M,N$ が同じ次数の同次関数なら、半径方向の伸びを使って積分因子を選べる。具体的な計算は :ref[prop-ode-homogeneous-integrating-factor] で示す。

:::example[二変数に依存する積分因子]
$M=x+y,\ N=x-y$ は同次 1 次で、実は $M_y=N_x=1$ なので元の形式も完全である。$G=x^2/2+xy-y^2/2$ に対して $xM+yN=2G$、従って $\mu=1/(2G)$ を掛けると $F=\tfrac12\log|G|$ となる。因子による変換は $G=0$ を除くが、元の式では二直線 $y=(1\pm\sqrt2)x$ が $G=0$ の解である。この例では一形式を掛けることで新しい曲線が生まれるのではなく、同じ等位曲線の表し方が変わる。
:::

また元の形式が完全でない例として $M=y,\ N=-2x$ を取ると $S=-xy$。$xy\ne0$ では $\mu M=-1/x,\ \mu N=2/y$、$F=-\log|x|+2\log|y|$ が候補となる。第一象限では $F=C$ を解いて $y=C_1\sqrt{x}$ となり、元の $y-2xy'=0$ に一致する。

:::proposition[原点を中心とする同次な微分形式の積分因子]{#prop-ode-homogeneous-integrating-factor}
$M,N$ を開集合上の $C^1$ 関数とし、両方が同じ次数 $k$ の同次関数であるとする。すなわち、定義域内で正の倍率 $\lambda$ に対して $M(\lambda x,\lambda y)=\lambda^kM(x,y)$、$N$ にも同じ関係が成り立つ。$H=xM+yN\ne0$ の領域では $1/H$ を掛けた形式は閉じており、各長方形上で完全である。
:::

:::proof
Euler の同次性の式 $xM_x+yM_y=kM$ と $xN_x+yN_y=kN$ は、それぞれ $\lambda=1$ で微分して得る。商の微分で $\partial_y(M/H)-\partial_x(N/H)$ の分子を計算すると、

$$
\begin{aligned}
H(M_y-N_x)-MH_y+NH_x
&=N(xM_x+yM_y)-M(xN_x+yN_y)\\
&=0
\end{aligned}
$$
である。従って :ref[thm-ode-exact-rectangle] が使える。$H=0$ に含まれる解はこの因子を掛ける操作から得られないので、元の式で確かめる。
:::

:::example[同次な形式から傾きが一定の枝を取り戻す]
$M=2x+y$、$N=x$ とすると $H=2x(x+y)$ である。$x>0$、$x+y>0$ では $M/H=1/(2x)+1/(2(x+y))$、$N/H=1/(2(x+y))$ である。従ってポテンシャルは $F=\tfrac12\log x+\tfrac12\log(x+y)$ となる。

$F$ が一定であることは $x(x+y)=C>0$ と同値であり、従って $y=C/x-x$ となる。$x+y<0$ でも $\log|x+y|$ に置き換えれば同じ形で $C<0$ が得られる。除外した $H=0$ の直線 $y=-x$ は $2x+y+xy'=0$ に直接代入すると解である。この枝を合わせて $x>0$ 上の解は任意の $C\in\R$ で表される。
:::

### 極座標を使う積分因子

積分因子が直交座標では一変数の関数でなくても、座標を変えると一変数の形にできる場合がある。原点を除く平面で、$s=x^2+y^2$ とし、形式
$$
\omega=(x-y(1+s))\dd x+(y+x(1+s))\dd y
$$
を考える。$x\dd x+y\dd y=\dd s/2$ であり、偏角の枝を固定した領域上で $x\dd y-y\dd x=s\dd\theta$ である。従って $\omega=\dd s/2+s(1+s)\dd\theta$ となる。第 2 項の係数で割ると
$$
\frac{\omega}{s(1+s)}=\frac{\dd s}{2s(1+s)}+\dd\theta
=\dd\left\{\frac12\log\frac{s}{1+s}+\theta\right\}
$$
である。$\mu=1/[s(1+s)]$ は実平面上で $x,y$ の両方に依存するが、$(s,\theta)$ では $s$ のみの関数である。円に沿って一周すると $\dd s=0$ なので、因子を掛けた形式の積分は $2\pi$ である。従って原点を除く平面全体ではポテンシャルは一価にならない。

:::example[角度から半径を戻す]
$(x,y)=(1,0)$ から出る積分曲線を、そこで $\theta=0$ となる枝で求める。$s(0)=1$ なので積分定数の式は $s/(1+s)=e^{-2\theta}/2$ であり、
$$
s(\theta)=\frac1{2e^{2\theta}-1}
$$
となる。これが正かつ有限なのは $\theta>-(\log 2)/2$ である。$\theta$ を増やすと $s$ は零に近づく。逆に左端では $s\to+\infty$ なので、その角度を越える有限な半径はない。

曲線を $x=\sqrt{s(\theta)}\cos\theta$、$y=\sqrt{s(\theta)}\sin\theta$ と書けば、$\dd s/\dd\theta=-2s(1+s)$ により元の形式を満たす。$\theta=0$ では $\dd x/\dd\theta=-2$ なので、初期点の近くでは $x$ を独立変数とするグラフへ戻せる。一般には $\dd x/\dd\theta$ が零になる点もあり、その点で $x$ を独立変数に取れるとは限らない。偏角を連続に増やした積分曲線と、その一部分としてのグラフ解を区別する。
:::

## Bernoulli 型と Riccati 型

### Bernoulli 型

:::definition[Bernoulli 型]{#def-ode-bernoulli}
$y'+p(x)y=q(x)y^m$ で $m\in\R\setminus\{0,1\}$ の形を :term[Bernoulli 方程式]{en="Bernoulli equation" yomi="べるぬーいほうていしき"} という。任意の実指数について $y>0$ でべきを定義し、$y\le0$ の扱いは元の式に応じて指定する。
:::

正の解に対し $v=y^{1-m}$ と置くと $v'=(1-m)y^{-m}y'$ なので
$$
v'+(1-m)pv=(1-m)q.
$$
この変換は $v>0$ で逆変換 $y=v^{1/(1-m)}$ を持つ。したがって線形方程式を解いた後、$v$ が正の区間を選び、そこで逆変換する。負の領域で同じ計算を使う場合は、選んだべきが定義され、変換が可逆であることを確認する。

:::example[2 乗の非線形項]
$y'+y=y^2$ に対して $v=1/y$ とすれば $v'-v=-1$、従って $v=1+Ce^x$ である。$y(0)=2$ なら $C=-1/2$ であり、初期点を含む解区間は $(-\infty,\log2)$ である。$y=0$ も元の方程式を満たし、$C=0$ は $y=1$ を与える。
:::

:::example[逆変換で平方根の符号を保つ]
$y'+y=\sqrt y$ で $y>0$ とすると、$v=\sqrt y$ は $v'+v/2=1/2$ に従う。$y(0)=4$ から $v=1+e^{-x/2}$、$y=(1+e^{-x/2})^2$ を得る。これに対して $y(0)=1/4$ なら $v=1-e^{-x/2}/2$ であり、正の範囲は $x>-2\log2$ である。そこより左で形式的に $v^2$ とおくと平方根が $-v$ になるので方程式を満たさない。左側を $y=0$ でつなぐと、接続点で値と導関数が一致する。
:::

### Riccati 型

:::definition[Riccati 型]{#def-ode-riccati}
実数値の連続な係数を持つ $y'=a(x)y^2+b(x)y+c(x)$ を :term[Riccati 方程式]{en="Riccati equation" yomi="りっかちほうていしき"} という。この節では実数値の解を考える。
:::

特解 $y_p$ を一つ知っていれば $z=y-y_p$ は
$$
z'=(2ay_p+b)z+az^2
$$
を満たす。この式は二つの方程式の差から得られるので、$z$ が解なら $y_p+z$ が元の解である。$z=0$ が既知の特解に対応し、$z\ne0$ なら $u=1/z$ で
$$
u'+(2ay_p+b)u=-a
$$
となる。

:::example[既知の定数解を引く]
$y'=y^2-4$ に対して $y_p=2$ を選ぶ。$u'+4u=-1$ から $u=Ce^{-4x}-1/4$、従って $y=2+1/(Ce^{-4x}-1/4)$ である。$C=0$ は $y=-2$ を与えるが、$y=2$ はこの式の外にある。$y(0)=0$ なら $u(0)=-1/2$ なので $C=-1/4$ となり、$y=-2\tanh(2x)$ である。
:::

:::proposition[Riccati 方程式と 2 階線形方程式]{#prop-ode-riccati-linear}
$a\in C^1(I)$ が消えず、$b,c\in C(I)$ とする。$u$ が消えない区間で
$$
y=-\frac{u'}{au}
$$
とすると、Riccati 方程式は $u''-(b+a'/a)u'+ac\,u=0$ に対応する。逆に任意の Riccati 解は $u=\exp(-\int a y)$ からこの表示を持つ。
:::

:::proof
$r=u'/u=-ay$ とおくと $r'=u''/u-r^2$ である。Riccati の右辺を代入すると $r'=(a'/a+b)r-r^2-ac$ を得る。従って $u''=(a'/a+b)u'-ac\,u$ となる。各等号は $a,u$ が零でない領域で逆にもたどれ、指数で復元した $u$ はその条件を満たす。
:::

例えば $y'=y^2+1$ には $u''+u=0$ が対応する。$y(0)=0$ から $u'(0)=0$ を取り $u=\cos x$ とすれば $y=\tan x$ となる。$u$ が初めて零になる点で、$y$ は有限値を持たない。線形方程式側の解が全実軸で定義されても、比で表す方程式側には別の定義域が生じる。

### Riccati 方程式の三つの特解と交比

三つの異なる特解 $y_1,y_2,y_3$ が分かると、別の解 $y$ との比を計算できる。実際、二解 $u,v$ の差は $(u-v)'=[a(u+v)+b](u-v)$ なので、差が消えない区間では $(\log|u-v|)'=a(u+v)+b$ となる。従って
$$
\frac{(y-y_1)(y_2-y_3)}{(y-y_3)(y_2-y_1)}
$$
の絶対値の対数を微分すると、四つの $a,b$ の寄与が打ち消し合う。符号も区間で一定だからこの比自体が一定である。定数は初期値から得られ、その関係を $y$ について解けば一次分数の式になる。逆に、交比を初期点で定めて $y$ について解くと、分母が消えない区間の解が得られる。実際、この交比を微分すると、$y'-(ay^2+by+c)$ に $y$ に関する交比の微分を掛けたものになる。三つの既知解の差は消えないので、$y\ne y_3$ ではこの偏微分は零にならない。従って交比が一定なら元の Riccati 方程式が従う。

:::example[一階の比から爆発を見る]
$y'=1+y^2$ で $y(0)=1$ なら、対応する $u''+u=0$ の初期値として $u(0)=1,\ u'(0)=-1$ を選べる。$u=\cos x-\sin x$ なので
$$
y=\frac{\sin x+\cos x}{\cos x-\sin x}.
$$
右端は $\pi/4$、左端は $-3\pi/4$ であり、いずれも $u$ の単純零点である。$y=-u'/u$ はそこで単純極を持つ。直接分離で $\arctan y=x+\pi/4$ として得る定義区間と一致する。
:::

:::example[負の枝も許される Bernoulli 方程式]
$y'-y=y^3$ で $y(0)=-1$ とする。整数指数なので負の解にも元の式が定義される。$v=y^{-2}$ は $v'+2v=-2$、$v(0)=1$ だから $v=2e^{-2x}-1$。逆変換では負の枝を取り、$y=-(2e^{-2x}-1)^{-1/2}$。$v=0$ は $x=(\log2)/2$ で起き、右側にこれを越えて延ばせない。$y=0$ は置換の分母から外れるが、元の式の定数解である。
:::

:::example[定数の既知解から他の全ての枝を求める]
$y'=y^2-4$ には定数解 $y=2$ と $y=-2$ がある。$y\ne2$ の枝で $y=2+1/v$ と置くと $-v'/v^2=4/v+1/v^2$ である。従って $v'+4v=-1$、$v(t)=Ce^{-4t}-1/4$ となる。

例えば $y(0)=0$ では $v(0)=-1/2$、$C=-1/4$ だから $y(t)=2-4/(1+e^{-4t})=-2\tanh(2t)$ である。$v$ はどの時刻でも負なので、この枝は全実軸で定義される。なお $C=0$ はもう一つの定数解 $y=-2$ を含む。

一方 $y(0)=6$ では $C=1/2$ となる。$v=0$ は $e^{-4t}=1/2$、すなわち $t=(\log2)/4$ に起きる。解はその手前で発散する。このように同じ線形化で得た $v$ が全時刻に延びても、逆変換で元の解に戻せる区間には制限がある。
:::

:::example[Riccati 型を二階線形方程式で解く]
$y'=y^2-4$ で $y=-u'/u$ と置く。商を微分すると $y'=-u''/u+y^2$ だから、元の式と合わせて $u''=4u$ となる。初期値 $y(0)=0$ を保つように $u(0)=1$、$u'(0)=0$ とすると、$u=Ae^{2t}+Be^{-2t}$ の係数は $A+B=1$、$2A-2B=0$ より $A=B=1/2$。従って $u=\cosh(2t)$、$y=-2\tanh(2t)$ が得られる。

これに対し $y(0)=6$ なら $u'(0)=-6$ なので $A=-1$、$B=2$。$u$ の零点は $t=(\log2)/4$ であり、その点で $u'$ は零でない。従って $-u'/u$ はそこで単純な極を持つ。この零点は一次の逆変換を使った先の計算の $v=0$ と同じ時刻である。また $u$ に零でない定数を掛けても $y$ は不変なので、二階の自由度二つのうちスカラー倍の自由度は Riccati 型の初期条件には現れない。
:::

## Clairaut 型と特異解

:::definition[Clairaut 型]{#def-ode-clairaut}
$y=xy'+f(y')$ を :term[Clairaut 方程式]{en="Clairaut equation" yomi="くれろーほうていしき"} という。$f$ は考える傾きの区間上で $C^2$ とする。
:::

### 直線族と包絡線

$p=y'$ とおくと、任意の定数 $p=c$ に対して $y=cx+f(c)$ は解である。$C^2$ 解を微分すると
$$
(x+f'(p))p'=0.
$$
$p'\ne0$ の近くでは $x=-f'(p)$ であり、$p$ を媒介変数とした曲線
$$
(x(p),y(p))=(-f'(p), f(p)-p f'(p))
$$
を得る。$f''(p)\ne0$ なら $x'(p)\ne0$ で、$y'(p)/x'(p)=p$ だからこの曲線は実際にグラフ解である。点 $(x(p),y(p))$ は傾き $p$ の直線にも載り、その接線が直線そのものになる。このような曲線を直線族の :term[包絡線]{en="envelope" yomi="ほうらくせん"} という。また、この解を直線族の :term[特異解]{en="singular solution" yomi="とくいかい"} と呼ぶ。

:::example[二次の包絡線と接続]
$y=xy'+(y')^2$ では直線 $y=cx+c^2$ と放物線 $y=-x^2/4$ を得る。放物線の導関数は $-x/2$ なので元の式を満たす。直線 $y=0$ は原点で放物線に接する。$x\le0$ で $0$、$x>0$ で $-x^2/4$ とする関数も $C^1$ 解である。二階導関数の左右極限は一致しないので、$C^2$ 解の導出だけではこの接続解を拾えない。
:::

:::example[媒介変数を消去できる範囲]
$f(p)=p^3$ では $x=-3p^2,\ y=-2p^3$ である。$x<0$ なら $p=\pm\sqrt{-x/3}$ の二枝があり、$y=\mp2(-x/3)^{3/2}$ となる。どちらも $x=0$ で傾き $0$ に近づく。$x>0$ にはこの媒介曲線の点がないが、$y=0$ に $C^1$ で接続できる。逆関数を使う導出が止まることと、元の方程式がそこで成り立つことは別の判定である。
:::

### Lagrange 型への拡張

$y=x\phi(p)+\psi(p)$、$p=y'$ とする。微分すると $p-\phi(p)=(x\phi'(p)+\psi'(p))p'$ である。$p$ が局所座標となり $p-\phi(p)\ne0$ なら
$$
\frac{\dd x}{\dd p}-\frac{\phi'(p)}{p-\phi(p)}x
=\frac{\psi'(p)}{p-\phi(p)}
$$
となる。この線形方程式で $x=x(p)$ を求め、$x'(p)\ne0$ の枝を戻す。定数傾き $p=c$ の候補は $c=\phi(c)$ を満たすもので、$y=cx+\psi(c)$ となる。

:::example[傾きを独立変数にする]
$y=2xp+p^2$ では定数傾きの解は $y=0$ である。$p\ne0$ の枝では $\dd x/\dd p+(2/p)x=-2$、従って $x=C/p^2-2p/3$ である。$C=0$ では $p=-3x/2$ となり、$y=-3x^2/4$ を得る。この解は直接代入により $x=0$ まで延びる。
:::

### 二次の Clairaut 方程式で接続できる枝

$y=xy'+a(y')^2$（$a>0$）では平方を完成して
$$
y+\frac{x^2}{4a}=a\left(y'+\frac{x}{2a}\right)^2
$$
となる。従って全ての $C^1$ 解は包絡線の上側にある。$z=y+x^2/(4a)$ とおくと $z=a(z')^2$ である。$z>0$ の連結区間では $z'$ の符号が一定なので、$(\sqrt z)'=\pm1/(2\sqrt a)$。従って $z=(x-c)^2/(4a)$ となり、$y$ は直線 $(c^2-2cx)/(4a)$ である。$z=0$ の点では $z'=0$ なので、直線の枝を包絡線へ $C^1$ で接続できる。

この計算から零集合の形も分かる。二つの零点の間に正の成分があれば、その開区間の両端が零となるが、一つの二次式 $(x-c)^2/(4a)$ が異なる二点で零になることはない。従って零集合は区間の中で連結である。零集合が空なら全体で一つの直線であり、空でなければ、その区間上で包絡線、各側に枝が残れば端点で接する直線となる。

:::example[有限区間だけを包絡線に沿う]
$a=1$ として、$-1\le x\le1$ で $y=-x^2/4$、$x<-1$ で $y=(1+2x)/4$、$x>1$ で $y=(1-2x)/4$ とする。左境界では値 $-1/4$ と傾き $1/2$ が、右では値 $-1/4$ と傾き $-1/2$ が一致する。従って元の方程式を全実軸上で満たす $C^1$ 解である。包絡線の長さを変えると、同じ初期条件を通る別の接続解も作れる。
:::

:::example[同じ初期値と傾きから異なる包絡線への接続]
$y=xy'-(y')^2$ を考える。傾き $p$ を定数とした解は $y=px-p^2$ である。傾きで右辺を微分すると $x-2p$ なので、包絡線の候補は $p=x/2$、$y=x^2/4$ となる。候補を微分すると $p=x/2$ が戻るため、実際に元の方程式を満たす。

例えば $x=2$ では放物線が直線 $y=x-1$ と値 $1$、傾き $1$ を共有する。$x\le2$ で直線、$x\ge2$ で放物線とすれば、つなぎ目を含めた $C^1$ 解となる。一方、左の二階導関数は $0$、右では $1/2$ なので、つないだ解はその点で $C^2$ ではない。

同様に、放物線の有限区間 $[2,4]$ を残してその両端に接線 $x-1$ と $2x-4$ をつなぐことができる。区間内で非定数の傾きが得られるので、この解はどの一本の直線とも一致しない。包絡線は直線族の近似を与えるだけでなく、解をつなぐ場所をも指定する。
:::

### 傾きの枝を方程式から判定する

$F(x,y,p)=0$ が $C^1$ のとき、$F_p=0$ の点では最高階の導関数を陰関数定理で解く手順が止まる。候補の曲線を見つけるには $F=F_p=0$ を連立する。その曲線が特異解になるには、そのグラフ自身の傾きが連立式の $p$ と一致しなければならない。例えば $(y')^2-y=0$ の候補は $y=p=0$ であり、$y=0$ は元の式を満たす。一方、$(y')^2-x=0$ の候補は $x=p=0$ で、$x=0$ は縦線である。従ってこの候補全体を $x$ の関数として表すことはできない。$x>0$ での解は $y=C\pm 2x^{3/2}/3$ であり、$x=0$ には右から接するが、$x<0$ には実数値の傾きが存在しない。

Clairaut 型で $f''$ が傾き区間の全体で消えない場合には、直線枝と包絡枝による分類を $C^1$ 解にも適用できる。実際、$p=y'$ は連続であり、$x+f'(p)\ne0$ の開集合では $F(x,y,p)=xp+f(p)-y$ から陰関数定理で $p$ が $C^1$ となる。その集合の各連結成分で $(x+f'(p))p'=0$ だから、$p$ は定数 $c$ となる。この直線枝の端点が解区間の内側にあれば、そこで $x=-f'(c)$ となる。同じ枝が異なる二つの内点を端点に持つことはできない。従って $x+f'(p)=0$ を満たす時刻の集合は区間内で連結である。そこでは $x=-f'(p)$ から包絡枝が一意に決まり、その左右に残る部分は端点で接する直線になる。零集合が一点だけの場合、左右に枝があれば両方とも同じ傾きを持つので、全体は一つの直線になる。

## 階数低下法と自励系の求積

### 未知関数または独立変数が現れない式

$y''=f(x,y')$ では $v=y'$ とおけば $v'=f(x,v)$ となり、そこから $y=y_0+\int v$ で復元できる。一方、$y''=f(y,y')$ では $y'$ が消えない区間で $y$ を座標に取り直す。$v(y(x))=y'(x)$ と書くと $y''=v\dd v/\dd y$ なので
$$
v\frac{\dd v}{\dd y}=f(y,v).
$$
この式を満たす消えない $v$ を得れば $y'=v(y)$ を求積できる。反転点では $v=0$ となるため、時間を変数とする元の方程式に戻って左右の解を確認する。

:::example[未知関数が陽に現れない]
$y''=x y'$, $y(0)=1,\ y'(0)=2$ とする。$v'=xv$ を解いて $v=2e^{x^2/2}$、従って $y=1+2\int_0^x e^{s^2/2}\dd s$ である。求積で表せた段階で全実軸上の解が得られており、積分を初等関数で書くことは条件ではない。
:::

:::example[速度と位置の関係]
$y''=(y')^2$ で $y'$ が消えない区間では $\dd v/\dd y=v$ であり、$v=Ce^y$ となる。$y(0)=0,\ y'(0)=2$ なら $C=2$ で、$(e^{-y})'=-2$ より $y=-\log(1-2x)$ となる。$y'=0$ のままの定数解もあり、これは $v$ で割る段階で除外される。
:::

### 保存力と時間の積分

:::proposition[エネルギー積分]{#prop-ode-energy-quadrature}
$V$ を区間上の $C^1$ 関数とする。$y''=-V'(y)$ の任意の $C^2$ 解上で $E=(y')^2/2+V(y)$ は一定である。$E>V(y)$ の区間で運動の向きを $\sigma\in\{1,-1\}$ に固定すると、
$$
x-x_0=\sigma\int_{y_0}^{y(x)}\frac{\dd u}{\sqrt{2(E-V(u))}}.
$$
:::

:::proof
$E'=y'(y''+V'(y))=0$ だから $E$ は一定である。$E>V(y)$ の範囲では $y'=\sigma\sqrt{2(E-V(y))}$ であり、:ref[prop-ode-separation] を適用する。逆にこの積分から作った解は $y'$ が消えないので、エネルギー式を微分して $y'$ で割れば $y''=-V'(y)$ を得る。
:::

:::example[調和振動の反転点]
$y''=-4y$ に $y(0)=0,\ y'(0)=2$ を課すと $E=2$ である。初めの上昇枝では $x=\tfrac12\arcsin y$ なので $y=\sin(2x)$ となる。$x=\pi/4$ で $y=1$、$y'=0$、$y''=-4$ であり、そこからは下降する。元の式へ代入すると $y=\sin(2x)$ は全区間で成り立つ。一定値 $y=1$ はエネルギーだけなら同じ値 $2$ を持つが、元の方程式では加速度 $-4$ が要求される。
:::

:::example[二重の零点への到達には無限時間を要する]
$y''=y$ の $V=-y^2/2$ に対して $E=0$、$y(0)=2,\ y'(0)=-2$ を取る。速度は $-y$ だから $y=2e^{-x}$ となり、原点へ近づくが有限時刻では届かない。時間積分の被積分関数 $1/y$ が $0$ で積分できないことも同じ結論を与える。
:::

$E-V(u)$ が反転点 $u=c$ で単純に消え、$V'(c)\ne0$ なら、近くでは $E-V(u)$ は $|u-c|$ の正の定数倍ではさめる。時間の被積分関数は $|u-c|^{-1/2}$ 以下の定数倍なので到達時刻は有限である。$V'(c)=0$ かつ $V$ が $C^2$ の場合は、$E-V(u)\le C|u-c|^2$ となり、許される側の積分は少なくとも対数的に発散する。反転点と平衡点で振る舞いが異なる理由はこの次数にある。

### 平面自励系から傾きと時刻を回収する

$x'=P(x,y),\ y'=Q(x,y)$ で $P\ne0$ の領域では、軌道は $\dd y/\dd x=Q/P$ に従う。軌道が $y=h(x)$ と得られたら、時間は $\dd t=\dd x/P(x,h(x))$ から回収する。$P=0$ の点でも $Q\ne0$ なら $y$ を座標として使える。両方が消える点では定数解を別に扱う。

:::example[軌道の形だけでは時刻は決まらない]
$x'=2x,\ y'=4y$ で初期値 $(1,3)$ を取る。$x>0$ では $\dd y/\dd x=2y/x$ だから軌道は $y=3x^2$ である。時刻を戻すと $t=\frac12\log x$、従って $(x,y)=(e^{2t},3e^{4t})$ を得る。両成分の右辺を同じ正数倍にしても軌道の形は同じだが、到達時刻はその倍率の逆数になる。
:::

各求積法は、解ける形へ式を変換した後、その変換が可逆な区間で解を戻す。分母・根号・対数の境界に達したときには、元の式、解の極限、必要な滑らかさを照合する。この手順を一般に支える理論が次章の存在・一意性と延長である。

### 変数の対称性を使って逐次積分する

$y^{(n)}=f(x,y^{(k)},\ldots,y^{(n-1)})$ で低い階の $y^{(0)},\ldots,y^{(k-1)}$ が現れないなら、$v=y^{(k)}$ を使って $n-k$ 階に下げられる。$v$ を求めた後、初期値 $y^{(j)}(x_0)$ を使って $k$ 回積分する。各積分で一つずつ初期条件を使うので、先に未知関数を減らしても必要な初期値の個数は変わらない。

:::example[加速度の減衰を二度積分する]
$y'''+2y''=0$、$y(0)=1,\ y'(0)=0,\ y''(0)=4$ とする。$v=y''$ は $v=4e^{-2x}$、従って $y'=2(1-e^{-2x})$、$y=2x+e^{-2x}$ である。加速度は零へ向かうが速度は $2$ に近づく。長時間に位置が収束するかどうかは、低階へ戻す際の積分定数にも依存する。
:::

### 求積で振動の周期を調べる

:ref[prop-ode-energy-quadrature] で $E-V$ が区間 $(a,b)$ で正、両端で単純に消えるとする。$V$ を両端の近傍まで $C^2$ とする。両端での接続には、[解の存在と一意性](/math/ode/existence-uniqueness/) の局所定理を状態 $(y,y')$ に用いる。左右の到達時刻は有限で、端では $V'$ の符号により内側へ折り返す。方程式は時間反転で変わらないため、先ほど通った片道を逆にたどる。このため周期は
$$
T(E)=2\int_a^b\frac{\dd u}{\sqrt{2(E-V(u))}}.
$$
この公式は両端が単純零点であることを使っている。二重零点がある場合、エネルギー曲線が閉じて見えても、端まで無限時間を要することがある。

:::example[振幅に依存する振動周期]
$V(y)=y^4/4$ で正の反転点を $A>0$ とする。反対側の端は $-A$、$E=A^4/4$ である。$u=As$ と置けば
$$
T(E)=\frac{4\sqrt2}{A}\int_0^1\frac{\dd s}{\sqrt{1-s^4}}.
$$
積分は $1$ の近くで $(1-s)^{-1/2}$ と同じ程度なので有限である。$A$ が二倍になれば周期は半分になる。調和振動の $V=2y^2$ では同じ置換で $A$ の因子が完全に消えるので、周期の振幅依存性はポテンシャルの次数に由来する。
:::

### 反転点と境界での接続を比べる

:::example[振り子の小振幅周期を計算する]
質点を長さ $\ell$ の軽い剛体棒でつるし、摩擦を無視する。鉛直下向きからの角度を $y$、重力加速度を $g$ とすると $y''=-(g/\ell)\sin y$ である。$V(y)=(g/\ell)(1-\cos y)$ とし、角振幅を $0<A<\pi$ とする。$V(A)-V(y)=2(g/\ell)(\sin^2(A/2)-\sin^2(y/2))$ であり、$\sin(y/2)=k\sin\theta,\ k=\sin(A/2)$ と置けば周期は
$$
T(A)=4\sqrt{\ell/g}\int_0^{\pi/2}\frac{\dd\theta}{\sqrt{1-k^2\sin^2\theta}}
$$
となる。実際、$\dd y=2k\cos\theta\,\dd\theta/\sqrt{1-k^2\sin^2\theta}$ なので、分母の $2k\cos\theta\sqrt{g/\ell}$ と打ち消し合う。$A\to0$ では被積分関数が一様に $1$ へ近づき、$T\to2\pi\sqrt{\ell/g}$。この極限は $\sin y$ を $y$ で近似した線形方程式の周期に一致する。逆に $A\uparrow\pi$ では被積分関数が $\sec\theta$ へ単調に増え、積分が発散する。最上点ではエネルギー差の零点が二重になるため、無限時間を要するという先の判定と一致する。
:::

求積した式から定義区間と周期を読む際は、分母が消える位置、積分が収束するか、そこで方程式が許す加速度を順に調べる。例えば単振り子では $A<\pi$ なら反転し、$A=\pi$ に至る非定常枝は最高点へ有限時刻では届かない。同じ式の極限でも、端点に達する解を得たことにはならない。

:::example[保存エネルギーから転回点に達する時刻を求める]
$y''=-4y$、$y(0)=0$、$y'(0)=2$ とする。保存量 $E=(y')^2/2+2y^2$ は初期時刻で $2$ である。初めは速度が正なので、$0\le y<1$ の区間では $y'=2\sqrt{1-y^2}$ となる。

従って最初の上りでは $t=\tfrac12\int_0^{y(t)}(1-u^2)^{-1/2}\dd u=\tfrac12\arcsin y(t)$。$y=1$ に達する時刻は $t=\pi/4$ で有限である。そこで $y''=-4<0$ だから、速度は正から負に変わる。この転回点で速度の符号を保ったまま求積式を使うと、その後の解を再現できない。

元の方程式は自励かつ加速度が $y$ だけに依存する。従って $t=\pi/4$ を中心に上りの軌道を時間反転すると下りの解になる。$y=-1$ でも同様に $y''=4>0$ で折り返す。上下の片道にそれぞれ $\pi/2$ かかるから周期は $\pi$ である。$y(t)=\sin(2t)$ を代入して初期値と周期を照合できる。
:::

## 演習問題

::::exercise{level=basic}

$y'=3x^2 y$、$y(0)=-2$ を解け。

:::solution

$y\ne0$ の枝で $(\log\abs y)'=3x^2$ だから $\log\abs y=x^3+\log2$。符号は初期値から負となり、$y=-2e^{x^3}$ である。これは全実軸で微分でき、$y'=3x^2y$ と初期条件を満たす。

:::
::::

::::exercise{level=basic}

$y'+2y=4,\ y(0)=5$ を解け。

:::solution

$e^{2x}$ を掛けると $(e^{2x}y)'=4e^{2x}$。$0$ から積分して $e^{2x}y-5=2(e^{2x}-1)$ を得る。従って $y=2+3e^{-2x}$ である。

:::
::::

::::exercise{level=basic}

$2xy\dd x+(x^2+2y)\dd y=0$ のポテンシャルを求め、$(0,1)$ を通る枝を $y$ について解け。

:::solution

$F_x=2xy$ を積分すると $F=x^2y+g(y)$。$F_y=x^2+2y$ より $g=y^2$ と取れる。初期値から $F=1$ であり、二次方程式の正の根 $y=(\sqrt{x^4+4}-x^2)/2$ を得る。この根は全実軸で滑らかで、合成 $F(x,y(x))=1$ を微分すれば元の式となる。

:::
::::

::::exercise{level=basic}

$y'+2y=2y^3$ で $y(0)=1/2$ の解を求めよ。

:::solution

$v=y^{-2}$ と置くと $v'-4v=-4$ である。$v(0)=4$ なので $v=1+3e^{4x}$。正の初期値を戻して $y=(1+3e^{4x})^{-1/2}$ を得る。$v$ は常に正なのでこの解は全実軸で定義される。

:::
::::

::::exercise{level=advanced}

$y'=y^2+2y+1,\ y(0)=1$ を解き、右端を越えて連続に延長できないことを示せ。

:::solution

$y_p=-1$ を引いて $z=y+1$ とすると $z'=z^2,\ z(0)=2$。従って $(1/z)'=-1$、$y=-1+2/(1-2x)$ である。初期点を含む区間 $(-\infty,1/2)$ でこの式は滑らかだが、$x\uparrow1/2$ で値が $+\infty$ へ発散するため実数値の連続延長はない。

:::
::::

::::exercise{level=advanced}

$x^2 y'-2xy=0$ の $(-1,1)$ 上の $C^1$ 解を分類し、$C^2$ になる条件を求めよ。

:::solution

$x\ne0$ では $(y/x^2)'=0$ だから、左右で $y=C_\pm x^2$。連続性は $y(0)=0$ を要求する。任意の $C_\pm$ について左右の導関数 $2C_\pm x$ は原点で $0$ に収束し、原点の差商も $0$ に収束する。元の式は原点で $0=0$ である。$y'$ の差商の左右極限は $2C_\pm$ なので、$C^2$ になる条件は $C_+=C_-$ である。

:::
::::

::::exercise{level=advanced}

Clairaut 方程式 $y=xy'+3(y')^2$ の直線族と、その包絡線を求めよ。包絡線と原点で接する直線をつないだ $C^1$ 解を一つ作れ。

:::solution

$y'=c$ を置いて $y=cx+3c^2$ を得る。包絡点は $x+6c=0$ なので $c=-x/6$、$y=-x^2/12$。この枝の傾き $-x/6$ を代入すれば元の式を満たす。$c=0$ の直線 $y=0$ と包絡線は原点で値と傾きが一致するため、$x\le0$ で前者、$x>0$ で後者とした関数が条件を満たす。

:::
::::

::::exercise{level=advanced}

$y''=-9y,\ y(0)=0,\ y'(0)=6$ に対し、最初に $y'=0$ となる正の時刻をエネルギー積分で求めよ。

:::solution

$V=9y^2/2$ とすると $E=18$。初期速度は正なので $y'=3\sqrt{4-y^2}$ の枝を使う。最初の反転点は $y=2$ で、到達時刻は $\int_0^2\dd y/(3\sqrt{4-y^2})=\pi/6$。積分を反転すると到達まで $y=2\sin(3x)$ であり、途中で導関数が正であることも確かめられる。

:::
::::

## 確認テスト

::::quiz

$y'=x-y$ の方向場について正しいものを選べ。

- [ ] $y=x$ は解である。
- [x] $y=x$ 上では傾きが $0$ である。
- [ ] $y>x$ の点では傾きが正である。

:::explanation

$x-y$ は $y=x$ で $0$、$y>x$ で負である。直線 $y=x$ 自身の傾きは $1$ なので、その直線は解ではない。

:::
::::

::::quiz{answer="3" tol="1e-8"}

$y'+y=3,\ y(0)=4$ の解の $x\to+\infty$ の極限を求めよ。

:::explanation

$(e^x y)'=3e^x$ を積分すると $y=3+e^{-x}$ である。$e^{-x}\to0$ なので極限は $3$。

:::
::::

::::quiz

$y'=xy^2$ を分離するとき、$y^2$ で割ることで除外される解を選べ。

- [ ] $y=x$
- [ ] $y=1$
- [x] $y=0$

:::explanation

$y^2$ が消えるのは $y=0$ であり、この定数関数は $y'=0=xy^2$ を満たす。$y=1$ は一般の $x$ で右辺が $x$ となり、$y=x$ では左辺が $1$、右辺が $x^3$ なので、いずれも解ではない。

:::
::::

::::quiz{answer="1" tol="1e-8"}

$(2y+x)\dd x+x\dd y=0$ に因子 $\mu=x$ を掛けてポテンシャルを作る。$F(0,0)=0$ と正規化したとき、$3F(1,1)$ を $4$ で割った値はいくつか。

:::explanation

$F=x^2y+x^3/3$ とすると $\dd F=x(2y+x)\dd x+x^2\dd y$ であり、原点で $0$ となる。$F(1,1)=4/3$ だから $3F(1,1)/4=1$ である。

:::
::::

::::quiz{answer="9" tol="1e-8"}
$y=xy'-(y')^2$ の包絡線の $x=6$ における値を求めよ。

:::explanation
傾きを $p$ と置くと、直線族の右辺は $xp-p^2$ である。$p$ に関する微分 $x-2p$ が零となる $p=x/2$ を代入すると $y=x^2/4$ を得る。この式を微分すると $y'=x/2$ なので元の方程式も満たす。従って $x=6$ では $y=36/4=9$ である。
:::
::::
