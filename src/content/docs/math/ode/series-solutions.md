## この章の目標

- 正則点での係数漸化式と収束範囲を求める。
- 確定特異点の指数を計算し、整数差で対数が現れる条件を判定する。
- 代表的な特殊関数の方程式、級数、微分公式、直交性を導く。
- 収束級数と漸近展開を区別し、剰余を評価する。

## 正則点におけるべき級数解

$y''+p(x)y'+q(x)y=g(x)$ で $p,q,g$ が $x_0$ の近傍で収束べき級数を持つとき、$x_0$ を :term[正則点]{en="ordinary point" yomi="せいそくてん"} という。最高階の係数が $1$ でない場合は、まずそれが消えない範囲で割る。この章では中心を $0$ に移し、$p=\sum p_jx^j$、$q=\sum q_j x^j$、$g=\sum g_jx^j$ とする。

:::theorem[正則点の級数解]{#thm-ode-ordinary-series}
上の係数級数の収束半径がいずれも $R>0$ 以上なら、任意の $a_0=y(0),a_1=y'(0)$ に対する解は $|x|<R$ で収束する級数 $y=\sum_{n\ge0}a_nx^n$ で与えられ、
$$
(n+2)(n+1)a_{n+2}
=g_n-\sum_{j=0}^n \left[p_j(n-j+1)a_{n-j+1}+q_j a_{n-j}\right]
\label{eq-ode-ordinary-series}
$$
が成り立つ。
:::

:::proof
べき級数を代入し $x^n$ の係数を等置すると式が必要である。形式的に定めた係数の収束を示すため、$u=(y,y',1)^\top$、$u'=A(x)u$ と拡大する。$A$ は第 1 行 $(0,1,0)$、第 2 行 $(-q,-p,g)$、第 3 行 $(0,0,0)$ を持つ。ある $0<\sigma<\rho<R$ を取り $A(x)=\sum A_jx^j$、$\norm{A_j}\le C\rho^{-j}$ とする。これは絶対収束から得られる。$u=\sum u_nx^n$ の漸化式は $(n+1)u_{n+1}=\sum_{j=0}^n A_j u_{n-j}$ である。

$\norm{u_k}\le M\sigma^{-k}$（$k\le n$）なら、右辺は $CM\sigma^{-n}\sum_{j=0}^n(\sigma/\rho)^j$ 以下である。従って $n+1\ge C\sigma/(1-\sigma/\rho)$ のとき $\norm{u_{n+1}}\le M\sigma^{-(n+1)}$。有限個の最初の係数を覆うように $M$ を選べば帰納法が閉じる。よって $|x|<\sigma$ で収束し、$\sigma$ は $R$ に任意に近づけられる。項別微分と積の級数は :ref[prop-anl-analytic-series] により正当化され、初期値と方程式を満たす。実区間での一意性は [常微分方程式の線形系の全区間での存在](/math/ode/linear-systems/#thm-ode-linear-existence) による。
:::

:::example[次数が三つずつ進む Airy 方程式]
$y''-xy=0$ では $a_2=0$、$a_{n+2}=a_{n-1}/((n+2)(n+1))$（$n\ge1$）。$(a_0,a_1)=(1,0)$ の解は $1+x^3/6+x^6/180+\cdots$、$(0,1)$ では $x+x^4/12+x^7/504+\cdots$ となる。両方の級数が全実軸で収束するのは、係数の収束半径が無限大だからである。
:::

:::example[係数が有理関数のときの収束半径]
$(1+x^2)y''+2xy'=0$ では $((1+x^2)y')'=0$ である。$y(0)=0,y'(0)=1$ の解は $\arctan x$ で、係数を正規化したときの収束半径は $1$ である。展開 $\sum_{k\ge0}(-1)^kx^{2k+1}/(2k+1)$ の係数比から、解の級数も半径 $1$ と分かる。実軸上には係数の特異点がなくても、複素平面での零点 $\pm i$ が原点中心の級数を制限する。
:::

### 初期値と級数の対称性

係数に偶奇の対称性があれば、解の係数を二系列に分けられる。例えば $p$ が奇、$q$ が偶で斉次なら、$y(-x)$ も同じ方程式を満たす。初期値 $(1,0)$ では二つの値と初期傾きが一致するので解は偶、初期値 $(0,1)$ では $-y(-x)$ が同じ初期値を持つので解は奇である。漸化式でも偶数次と奇数次は互いに混ざらない。

:::example[非斉次項が偶奇を選ぶ]
$y''+x^2y=1,\ y(0)=y'(0)=0$ では $a_2=1/2$、$a_{n+2}=-a_{n-2}/[(n+2)(n+1)]$（$n\ge2$）。従って先頭は $x^2/2-x^6/60+x^{10}/5400$ である。斉次部分の偶解は定数項から始まるため、同じ偶関数でも現れる次数が異なる。打切りを式へ代入すると、最初に残る残差は $x^{12}/5400$ であり、許した次数まで係数が合うかを検算できる。
:::

### 既知の定数の繰り返し積分と級数解

正則な連立系 $u'=A(x)u$ の Picard 反復を各次数で見ると、$k$ 回目の反復では解の $k$ 次までの係数が確定している。実際、二つの曲線の級数が $x^{k+1}$ からしか違わなければ、$A(x)$ を掛けても差の開始次数は下がらず、積分で少なくとも一つ上がる。従って、初期定数曲線を始点として反復すると、差が初めて現れる次数が反復ごとに上がる。収束を一様ノルムで示した Picard の方法と、係数を一つずつ決定する級数法は、この意味では同じ積分方程式を扱っている。

:::example[基底を係数から再構成する]
$y''-2x y'=0$ に $y(0)=0,y'(0)=1$ を課す。直接には $y'=\exp(x^2)$、$y=\int_0^x e^{s^2}\dd s$ である。級数法からは $(n+2)(n+1)a_{n+2}=2n a_n$（$n\ge0$）で、$a_1=1,a_0=0$。奇数係数を順に求めると $a_3=1/3,a_5=1/10,a_7=1/42$。指数を項別積分した一般項 $x^{2k+1}/[(2k+1)k!]$ と一致する。係数に $k!$ があるため全実軸で収束しても、積分の値を初等関数で表す必要はない。
:::

:::example[正則点の漸化式と厳密解を照合する（指数 1、角速度 2）]
$y''-(2)y'+(5)y=0$、$y(0)=1$、$y'(0)=1$ に対し、原点展開を六次まで求める。

二階微分の $x^j$ の係数は $(j+2)(j+1)c_{j+2}$ であり、一階微分の係数は $(j+1)c_{j+1}$ である。従って二つの初期係数から後続の係数を順に決められる。

$$
\begin{aligned}
(j+2)(j+1)c_{j+2}&=2(j+1)c_{j+1}-5c_j\\
(c_0,\dots,c_6)&=\left( 1, \  1, \  - \frac{3}{2}, \  - \frac{11}{6}, \  - \frac{7}{24}, \  \frac{41}{120}, \  \frac{13}{80}\right)
\end{aligned}
$$

この係数で作った部分和 $P_6$ を微分演算子に戻す。初めの五つの係数を消すように作ったため、残差は $x^5$ から始まるか、それより高い次数から始まる。

$$
\begin{aligned}
P_6(x)&=\frac{13 x^{6}}{80} + \frac{41 x^{5}}{120} - \frac{7 x^{4}}{24} - \frac{11 x^{3}}{6} - \frac{3 x^{2}}{2} + x + 1\\
LP_6(x)&=\frac{13 x^{6}}{16} - \frac{29 x^{5}}{120}\\
y(x)&=e^{x} \cos{\left(2 x \right)}
\end{aligned}
$$

厳密解は特性根の共役対を使っても得られる。その Taylor 展開は漸化式と同じ初期係数を持つので、全次数で一致する。打切り解を代入した際の残差の次数は、二階微分で次数が二つ下がることを含めて求める。
:::

## 確定特異点と Frobenius の方法

係数が $0$ で発散しても、微分の階数に応じた冪を掛ければべき級数に戻る場合がある。その場合、整数冪だけに限らず、最初に $x^r$ を掛けた級数を試す。

:::definition[確定特異点と決定多項式]{#def-ode-regular-singular}
正規形 $y''+p(x)y'+q(x)y=0$ に対し、$xp(x)=P(x)$、$x^2q(x)=Q(x)$ が $0$ まで解析的に延びるとする。$0$ が正則点でなければ :term[確定特異点]{en="regular singular point" yomi="かくていとくいてん"} という。$P_0=P(0),Q_0=Q(0)$ に対し
$$
F(r)=r(r-1)+P_0r+Q_0
$$
を :term[決定多項式]{en="indicial polynomial" yomi="けっていたこうしき"} という。
:::

:::theorem[Frobenius 級数の構成と収束]{#thm-ode-frobenius}
$P,Q$ の級数が $|x|<R$ で収束するとする。$F(r)=0$ で、$F(r+n)\ne0$ が全ての整数 $n\ge1$ で成り立つなら、$0<x<R$ 上に $y=x^r\sum_{n\ge0}a_nx^n$、$a_0=1$ の解があり、
$$
F(r+n)a_n=-\sum_{j=1}^n [P_j(r+n-j)+Q_j]a_{n-j}.
\label{eq-ode-frobenius}
$$
複素 $r$ では $x^r=e^{r\log x}$ とする。
:::

:::proof
$x^2 y''+xP(x)y'+Q(x)y=0$ に代入すると、$x^r$ の係数は $F(r)a_0=0$、それ以降は :eqref[eq-ode-frobenius] である。$0<\sigma<\rho<R$ を取り $|P_j|+|Q_j|\le C\rho^{-j}$ とする。大きい $n$ では $|F(r+n)|\ge c n^2$、$|r+n-j|+1\le C_1 n$ が成り立つ。既に $|a_k|\le M\sigma^{-k}$（$k<n$）なら
$$
|a_n|\le\frac{C C_1 M}{c n}\sigma^{-n}
\sum_{j=1}^n(\sigma/\rho)^j.
$$
右辺の定数部分は大きい $n$ で $1$ 以下となる。残りの有限個の係数を覆う $M$ を取ると帰納法により $|x|<\sigma$ で収束する。任意の $\sigma<R$ について成り立ち、項別微分により解となる。
:::

この方法を :term[Frobenius の方法]{en="Frobenius method" yomi="ふろべにうすのほうほう"} という。二根 $r_1,r_2$ の差が整数でなければ両方に適用できる。$W(y_1,y_2)=x^{r_1+r_2-1}(r_2-r_1+O(x))$ となり、$x>0$ の小区間で消えないので独立である。両根が共役で非実の場合、実部と虚部を取れば実基底を得る。

:::example[半整数の差を持つ Euler 型]
$x^2y''-\tfrac12 xy'=0$ は $F(r)=r(r-3/2)$ を持つ。$P,Q$ が定数なので高次係数が全て零となり、$1,x^{3/2}$ が基底となる。$x^{3/2}$ は $0$ で $C^1$ に延びるが、二階導関数 $3/(4\sqrt x)$ は有界でない。特異点を含まない解区間と、端点での連続性は別に調べる。
:::

:::example[虚数指数は対数時間の振動を表す]
$x^2y''+xy'+4y=0$ の指数は $\pm2i$ である。$x^{2i}$ の実部と虚部は $\cos(2\log x),\ \sin(2\log x)$ で、両方とも $x\downarrow0$ で何度も振動する。
:::

### 変数を変えたときの指数

$z=z(x)$ が解析的で $z(0)=0,\ z'(0)\ne0$ なら $z(x)^r=x^r[z(x)/x]^r$ である。第二因子は $0$ 近くで消えない解析的関数なので、指数 $r$ は変わらない。これに対し $z=x^m$ とすると $z^r=x^{mr}$ となり、指数は $m$ 倍になる。後者は原点で可逆な解析座標変換ではない。連鎖律から係数の特異性を調べる場合は、変数変換がどちらに当たるかを確認する。

:::example[冪の変換で非整数指数が整数になる]
$z^2Y''+\tfrac12 zY'=0$ の指数は $0,1/2$ である。$z=x^2$、$u(x)=Y(x^2)$ とすると $u''=2Y'+4x^2Y''=0$（$x>0$）。$Y=1,\sqrt z$ はそれぞれ $u=1,x$ へ移る。$z=0$ は確定特異点だが、$x$ 側の式は正規形で原点でも正則である。平方写像を使ったため、このことは可逆な座標で特異性が変わることを意味しない。
:::

:::proposition[正則で消えない因子を掛けても決定根は変わらない]{#prop-ode-frobenius-gauge-invariance}
$y''+p(x)y'+q(x)y=0$ の原点を確定特異点とし、解析的で $g(0)\ne0$ の $g$ によって $y=gv$ とする。すると $v$ の方程式の決定多項式は元と同じである。
:::

:::proof
$v''+(p+2g'/g)v'+(q+pg'/g+g''/g)v=0$ を得る。$g'/g,g''/g$ は原点近傍で有界なので、$x(2g'/g)\to0$、$x^2(pg'/g+g''/g)\to0$。後者には $xp$ が有界であることを用いた。従って $xp,x^2q$ の定数項が変わらない。$g(0)\ne0$ だから、同じ指数を持つ級数の先頭係数の零・非零も変わらない。
:::

:::example[確定特異点と解析因子を分ける（指数差 1/2）]
$x>0$ で $y''+py'+qy=0$、$p=\frac{2}{x + 1} + \frac{1}{2 x}$、$q=\frac{1}{2 x \left(x + 1\right)}$ とする。原点の指数を求め、二つの Frobenius 解を閉じた形で表す。

まず係数の極の次数を確認する。$xp$ と $x^2q$ の値から決定式を書き、二根の差が整数かどうかを確認する。

$$
\begin{aligned}
\lim_{x\downarrow0}xp&=\frac{1}{2}\\
\lim_{x\downarrow0}x^2q&=0\\
P(r)&=\frac{r \left(2 r - 1\right)}{2}
\end{aligned}
$$

一階微分の係数のうち原点で正則な項を消すため $y=gv$ と置く。$2g'/g$ を足すと Euler 型になり、この例では零階係数も消える。

$$
\begin{aligned}
g(x)&=\frac{1}{x + 1}\\
\widetilde p(x)&=\frac{1}{2 x}\\
\widetilde q(x)&=0\\
(y_1,y_2)&=\left( \frac{1}{x + 1}, \  \frac{\sqrt{x}}{x + 1}\right)
\end{aligned}
$$

各解を $x^r$ で割った部分は同じ解析因子であり、原点で値 $1$ を持つ。収束円の端にある $x=-1$ の極はその因子に現れる。決定根の計算では原点だけの情報を使い、収束半径を調べる段階では他の点も見る。
:::

:::example[確定特異点と解析因子を分ける（指数差 2/3）]
$x>0$ で $y''+py'+qy=0$、$p=\frac{4}{x + 1} + \frac{1}{3 x}$、$q=\frac{2 \left(4 x + 1\right)}{3 x \left(x + 1\right)^{2}}$ とする。原点の指数を求め、二つの Frobenius 解を閉じた形で表す。

まず係数の極の次数を確認する。$xp$ と $x^2q$ の値から決定式を書き、二根の差が整数かどうかを確認する。

$$
\begin{aligned}
\lim_{x\downarrow0}xp&=\frac{1}{3}\\
\lim_{x\downarrow0}x^2q&=0\\
P(r)&=\frac{r \left(3 r - 2\right)}{3}
\end{aligned}
$$

一階微分の係数のうち原点で正則な項を消すため $y=gv$ と置く。$2g'/g$ を足すと Euler 型になり、この例では零階係数も消える。

$$
\begin{aligned}
g(x)&=\frac{1}{\left(x + 1\right)^{2}}\\
\widetilde p(x)&=\frac{1}{3 x}\\
\widetilde q(x)&=0\\
(y_1,y_2)&=\left( \frac{1}{\left(x + 1\right)^{2}}, \  \frac{x^{\frac{2}{3}}}{\left(x + 1\right)^{2}}\right)
\end{aligned}
$$

各解を $x^r$ で割った部分は同じ解析因子であり、原点で値 $1$ を持つ。収束円の端にある $x=-1$ の極はその因子に現れる。決定根の計算では原点だけの情報を使い、収束半径を調べる段階では他の点も見る。
:::

:::example[確定特異点と解析因子を分ける（指数差 3/2）]
$x>0$ で $y''+py'+qy=0$、$p=\frac{6}{x + 1} - \frac{1}{2 x}$、$q=\frac{3 \left(3 x - 1\right)}{2 x \left(x + 1\right)^{2}}$ とする。原点の指数を求め、二つの Frobenius 解を閉じた形で表す。

まず係数の極の次数を確認する。$xp$ と $x^2q$ の値から決定式を書き、二根の差が整数かどうかを確認する。

$$
\begin{aligned}
\lim_{x\downarrow0}xp&=- \frac{1}{2}\\
\lim_{x\downarrow0}x^2q&=0\\
P(r)&=\frac{r \left(2 r - 3\right)}{2}
\end{aligned}
$$

一階微分の係数のうち原点で正則な項を消すため $y=gv$ と置く。$2g'/g$ を足すと Euler 型になり、この例では零階係数も消える。

$$
\begin{aligned}
g(x)&=\frac{1}{\left(x + 1\right)^{3}}\\
\widetilde p(x)&=- \frac{1}{2 x}\\
\widetilde q(x)&=0\\
(y_1,y_2)&=\left( \frac{1}{\left(x + 1\right)^{3}}, \  \frac{x^{\frac{3}{2}}}{\left(x + 1\right)^{3}}\right)
\end{aligned}
$$

各解を $x^r$ で割った部分は同じ解析因子であり、原点で値 $1$ を持つ。収束円の端にある $x=-1$ の極はその因子に現れる。決定根の計算では原点だけの情報を使い、収束半径を調べる段階では他の点も見る。
:::

## 決定方程式の根の差が整数の場合

$r_1-r_2=m\in\Z_{\ge0}$ とする。大きい方の根 $r_1$ の級数は作れる。一方 $m\ge1$ のとき、小さい根の漸化式は $n=m$ で左辺が零になる。右辺も零なら $a_m$ を自由に置ける。右辺が非零なら純粋な級数の形では解が存在しない。

:::proposition[整数差と対数項]{#prop-ode-frobenius-log}
$r_1-r_2=m\in\Z_{\ge0}$ で、$y_1=x^{r_1}a(x)$、$a(0)=1$ とする。十分小さい $x>0$ 上の第二解は、
$$
y_2=C\,y_1\log x+x^{r_2}b(x)
\label{eq-ode-frobenius-log}
$$
と書ける。$b$ は解析的で、$m=0$ では $C\ne0$、$m>0$ では $b(0)\ne0$ である。
:::

:::proof
[常微分方程式の既知解からの階数低下](/math/ode/linear-systems/#thm-ode-dalembert) を使う。$p=P_0/x+\widetilde p$、$\widetilde p$ は解析的であるから、積分の中身は定数倍を除いて
$$
\frac{x^{-P_0}\exp(-\int_0^x\widetilde p)}{x^{2r_1}a(x)^2}
=x^{-m-1}B(x),\qquad B(0)=1,
$$
となる。ここでは根の和 $r_1+r_2=1-P_0$ を使った。$a(x)$ が小近傍で消えないため $B$ は解析的である。$B=\sum B_jx^j$ を項別積分すると、$j\ne m$ の項は $B_j x^{j-m}/(j-m)$、$j=m$ の項は $B_m\log x$ となる。係数を $j-m$ で割った尾部は元の級数と同じ小円板で収束する。$y_1$ を掛けると :eqref[eq-ode-frobenius-log] であり、$m=0$ なら $B_m=1$、$m>0$ なら最初の項の係数が $-1/m$ である。
:::

$m>0$ であるとき、漸化式が $n=m$ で整合することと $C=0$ は同値である。整合するなら $a_m$ を決めてそれ以降を漸化式で作り、:ref[thm-ode-frobenius] の大きい $n$ に対する評価を使える。その解は $x^{r_2}$ で始まるため $y_1$ と独立であり、$y_2$ をその解と $y_1$ の線形結合に書くと対数が現れない。逆に $C=0$ なら第二解自身が小さい根の純粋な級数なので整合する。

:::example[整数差があっても対数が出ない]
$x^2y''-2y=0$ では根は $2,-1$ である。係数が定数であるため $n=3$ では $0=0$ となり、$x^2$ と $x^{-1}$ が独立解となる。小さい根において $a_3$ を変えることは $x^2$ の倍を加えることと同じである。
:::

:::example[整数差で互換条件が破れる]
$x^2 y''+xy'+(x^2-1)y=0$ の指数は $\pm1$ である。$r=-1$ に対し漸化式は $n(n-2)a_n=-a_{n-2}$（負の添字は零）。$a_0=1$ から $a_1=0$、$n=2$ で $0=-1$ となる。対数が必要なこの例は次数 $1$ の Bessel 方程式である。
:::

### 対数の係数を直接計算する

整数差での第二解は、最初から $y_1\log x$ と小さい冪の級数を合わせて代入しても求められる。$L=D^2+pD+q$ とし $Ly_1=0$ なら
$$
L(y_1\log x)=2y_1'/x+(p/x-1/x^2)y_1.
$$
右辺に $\log x$ は残らない。従って小さい指数の級数の不整合を、この既知の項の係数で打ち消せる。

:::example[Bessel の次数 1 で最初の対数係数を求める]
$x^2L=x^2D^2+x D+x^2-1$ とし、$y_1=x+O(x^3)$ に規格化する。$x^2L(y_1\log x)=2xy_1'=2x+O(x^3)$ である。一方 $x^{-1}$ を入れると $x^2L(x^{-1})=x$。小さい指数の先頭を $x^{-1}$ に取り、係数が $x$ の項を調節してもその項は決定多項式の根なので $x$ の不整合を消せない。従って $y_2$ の対数係数は $-1/2$ であり、
$$
y_2=x^{-1}-\tfrac12 y_1\log x+O(x)
$$
となる。$O(x)$ の中の $y_1$ の倍は、第二解の基準化で指定できる。
:::

### 重根で生じる標準的な対数を検算する

$x^2y''+x^2 y'+y/4=0$ では $P_0=0,Q_0=1/4$ で、決定式は $(r-1/2)^2$。$P_1=1$ なので $r=1/2$ の漸化式は $n^2 a_n=-(n-1+1/2)a_{n-1}$。従って $a_1=-1/2,a_2=3/16$。$y_1=\sqrt x(1-x/2+O(x^2))$ を使うと、階数低下の被積分関数は $e^{-x}/y_1^2=x^{-1}(1+O(x^2))$ である。積分では最初の $1/x$ が $\log x$ となるが、定数項が消えるので解析的な補正は $x^2$ から始まる。このように重根では対数が必ず現れる一方、その対数を除いた部分は係数によってさらに消えることがある。

:::example[階数低下で整数差 1 の対数項を取り出す]
$y''+py'+qy=0$ とし、$p=- \frac{2}{2 x + 1}$、$q=\frac{2}{x \left(2 x + 1\right)}$ とする。原点の近くで $x>0$、$1+(2)x^1>0$ とし、既知解 $f=x^1$ との独立な解を求める。 $m=1$ とする。

決定式は $r(r-m)$ であり、二根の差は正整数である。小さい根の級数を試す代わりに、$f$ と規格化した第二解の Wronskian を Abel の公式から決める。

$$
\begin{aligned}
f(x)&=x\\
e^{-\int p}&=2 x + 1\\
v'=e^{-\int p}/f^2&=\frac{2}{x} + \frac{1}{x^{2}}
\end{aligned}
$$

$v$ の導関数に $x^{-1}$ が現れるので、その項だけを対数として積分する。積分定数を零とし $g=fv$ と置く。

$$
\begin{aligned}
g(x)&=2 x \log{\left(x \right)} - 1\\
W(f,g)&=2 x + 1\\
Lg&=0
\end{aligned}
$$

第二解の定数項により小さい指数 $0$ が確認できる。$x^m\log x$ の係数が非零なので、どの $f$ の定数倍を足しても対数は消えない。粗い決定式だけでこの係数を予測することはできない。
:::

:::example[階数低下で整数差 2 の対数項を取り出す]
$y''+py'+qy=0$ とし、$p=- \frac{9 x^{2} + 1}{x \left(3 x^{2} + 1\right)}$、$q=\frac{12}{3 x^{2} + 1}$ とする。原点の近くで $x>0$、$1+(3)x^2>0$ とし、既知解 $f=x^2$ との独立な解を求める。 $m=2$ とする。

決定式は $r(r-m)$ であり、二根の差は正整数である。小さい根の級数を試す代わりに、$f$ と規格化した第二解の Wronskian を Abel の公式から決める。

$$
\begin{aligned}
f(x)&=x^{2}\\
e^{-\int p}&=3 x^{3} + x\\
v'=e^{-\int p}/f^2&=\frac{3}{x} + \frac{1}{x^{3}}
\end{aligned}
$$

$v$ の導関数に $x^{-1}$ が現れるので、その項だけを対数として積分する。積分定数を零とし $g=fv$ と置く。

$$
\begin{aligned}
g(x)&=3 x^{2} \log{\left(x \right)} - \frac{1}{2}\\
W(f,g)&=3 x^{3} + x\\
Lg&=0
\end{aligned}
$$

第二解の定数項により小さい指数 $0$ が確認できる。$x^m\log x$ の係数が非零なので、どの $f$ の定数倍を足しても対数は消えない。粗い決定式だけでこの係数を予測することはできない。
:::

:::example[階数低下で整数差 3 の対数項を取り出す]
$y''+py'+qy=0$ とし、$p=- \frac{5 x^{3} - 2}{x \left(x - 1\right) \left(x^{2} + x + 1\right)}$、$q=\frac{9 x}{\left(x - 1\right) \left(x^{2} + x + 1\right)}$ とする。原点の近くで $x>0$、$1+(-1)x^3>0$ とし、既知解 $f=x^3$ との独立な解を求める。 $m=3$ とする。

決定式は $r(r-m)$ であり、二根の差は正整数である。小さい根の級数を試す代わりに、$f$ と規格化した第二解の Wronskian を Abel の公式から決める。

$$
\begin{aligned}
f(x)&=x^{3}\\
e^{-\int p}&=- x^{5} + x^{2}\\
v'=e^{-\int p}/f^2&=- \frac{1}{x} + \frac{1}{x^{4}}
\end{aligned}
$$

$v$ の導関数に $x^{-1}$ が現れるので、その項だけを対数として積分する。積分定数を零とし $g=fv$ と置く。

$$
\begin{aligned}
g(x)&=- x^{3} \log{\left(x \right)} - \frac{1}{3}\\
W(f,g)&=- x^{5} + x^{2}\\
Lg&=0
\end{aligned}
$$

第二解の定数項により小さい指数 $0$ が確認できる。$x^m\log x$ の係数が非零なので、どの $f$ の定数倍を足しても対数は消えない。粗い決定式だけでこの係数を予測することはできない。
:::

## Bessel 方程式と Bessel 関数

円板上の Helmholtz 方程式 $(\Delta+k^2)u=0$（$k>0$）を、極座標で $u(r,\theta)=R(r)e^{i\nu\theta}$ と分離する。$\Delta=\partial_r^2+r^{-1}\partial_r+r^{-2}\partial_\theta^2$ なので、半径の式は $R''+r^{-1}R'+(k^2-\nu^2/r^2)R=0$ となる。円を一周して同じ値に戻る角度成分を選ぶ場合は $\nu\in\Z$ である。ここから半径を無次元化した変数 $x=kr$ に移ると
$$
x^2 y''+xy'+(x^2-\nu^2)y=0
\label{eq-ode-bessel}
$$
を得る。これを :term[Bessel 方程式]{en="Bessel equation" yomi="べっせるほうていしき"} と呼ぶ。以後この方程式を次数 $\nu$ の実数・複素数の値についても考える。原点の決定多項式は $r^2-\nu^2$ である。ここでの $r$ は特性指数を表す。

### 第一種と第二種

$\nu\ge0$ とすると、$r=\nu$ に対し $a_1=0$、$a_{2k}=-a_{2k-2}/[4k(k+\nu)]$。基準化 $a_0=2^{-\nu}/\Gamma(\nu+1)$ を使えば
$$
J_\nu(x)=\sum_{k=0}^\infty
\frac{(-1)^k(x/2)^{2k+\nu}}{k!\,\Gamma(k+\nu+1)}
\label{eq-ode-bessel-j}
$$
を得る。$\Gamma$ の漸化式は :ref[thm-cpx-gamma-extension] による。これを :term[第一種 Bessel 関数]{en="Bessel function of the first kind" yomi="だいいっしゅべっせるかんすう"} という。級数は $x>0$ の任意のコンパクト区間で絶対収束し、$\nu$ を実数または複素数まで延ばせる。実際 $1/\Gamma$ は整関数であり、固定した $\nu$ のコンパクト集合上で大きい $k$ に対し項の比は $O(k^{-2})$ となるため局所一様収束する。

$\nu\notin\Z$ なら $J_\nu,J_{-\nu}$ の先頭冪の係数が非零で、Wronskian の先頭係数も非零なので独立である。$\nu$ が半整数のときも漸化式で奇数係数を零に選べるためこの主張は成立する。標準的な第二種は
$$
Y_\nu(x)=\frac{\cos(\pi\nu)J_\nu(x)-J_{-\nu}(x)}{\sin(\pi\nu)}
$$
とする。整数 $n\ge0$ では $J_{-n}=(-1)^nJ_n$ が級数の $k<n$ の消失と添字の移動から分かる。従って分子・分母の双方に因子 $\nu-n$ をくくり出して極限を定義できる。

:::proposition[Bessel 関数の Wronskian]{#prop-ode-bessel-wronskian}
全ての $\nu\ge0$ について $W(J_\nu,Y_\nu)=2/(\pi x)$ である。
:::

:::proof
まず非整数 $\nu>0$ で、先頭係数から $xW(J_\nu,J_{-\nu})=-2\nu/[\Gamma(1+\nu)\Gamma(1-\nu)]$ を得る。この量は [常微分方程式のAbel の恒等式](/math/ode/linear-systems/#cor-ode-abel) により $x$ によらない。:ref[thm-cpx-gamma-reflection] と $\Gamma(1+\nu)=\nu\Gamma(\nu)$ から右辺は $-2\sin(\pi\nu)/\pi$。従って定義通りの線形結合の Wronskian は $2/(\pi x)$ である。整数では、上で示したパラメータの極限と、$x$ 微分した級数の局所一様収束から同じ式を得る。
:::

### 漸化式と半整数の例

級数の項別微分により
$$
(x^{-\nu}J_\nu)'=-x^{-\nu}J_{\nu+1},
\qquad (x^\nu J_\nu)'=x^\nu J_{\nu-1}.
$$
第一式では $k\ge1$ の項を微分して $k-1$ に置き換える。第二式では $(2k+2\nu)/\Gamma(k+\nu+1)=2/\Gamma(k+\nu)$ を使う。足し引きすれば $2J_\nu'=J_{\nu-1}-J_{\nu+1}$、$2\nu J_\nu/x=J_{\nu-1}+J_{\nu+1}$ を得る。

:::example[半整数を三角関数へ戻す]
$\nu=1/2$ で $y=x^{-1/2}u$ とすると $u''+u=0$ になる。$\Gamma(1/2)=\sqrt\pi$ と漸化式に基づき先頭係数を合わせると
$$
J_{1/2}(x)=\sqrt{\frac2{\pi x}}\sin x,\qquad
J_{-1/2}(x)=\sqrt{\frac2{\pi x}}\cos x.
$$
前者の正の零点は $k\pi$（$k=1,2,\ldots$）である。他の次数の零点については [Sturm の比較定理と振動理論](/math/ode/sturm-comparison/) で比較を行う。
:::

:::example[小さい半径での打切り]
$J_0(x)=1-x^2/4+x^4/64+\cdots$、$J_1(x)=x/2-x^3/16+x^5/384+\cdots$ である。$0\le x\le1$ では$x>0$ で第 $k+1$ 項と第 $k$ 項の絶対値比が $x^2/[4(k+1)(k+1+\nu)]\le1/4$ だから、交代級数として打切り誤差は最初に捨てた項以下である。例えば $J_0(1)$ は $49/64-1/2304$ と $49/64$ の間にある。
:::

### 積分表示と変形 Bessel 方程式

$\nu>-1/2$、$x>0$ とすると
$$
J_\nu(x)=\frac{(x/2)^\nu}{\sqrt\pi\,\Gamma(\nu+1/2)}
\int_{-1}^1(1-u^2)^{\nu-1/2}\cos(xu)\dd u.
$$
実際、余弦の級数は有限区間で一様収束する。偶数次の各積分を $v=u^2$ に置換すれば $\int_{-1}^1(1-u^2)^{\nu-1/2}u^{2k}\dd u=B(k+1/2,\nu+1/2)$ である。Gamma の漸化式から $\Gamma(k+1/2)/(2k)!=\sqrt\pi/(4^kk!)$。従って得られた係数は :eqref[eq-ode-bessel-j] に等しい。この表示は例えば $\nu=1/2$ で重みが一定となり、積分から $\sqrt{2/(\pi x)}\sin x$ を直接与える。

$x^2y''+xy'-(x^2+\nu^2)y=0$ を変形 Bessel 方程式という。正の $x$ で $J_\nu(ix)$ から $i^\nu$ の因子を外すと
$$
I_\nu(x)=\sum_{k\ge0}\frac{(x/2)^{2k+\nu}}{k!\Gamma(k+\nu+1)}
$$
となる。$J_\nu$ との違いは各項の $(-1)^k$ が消えることで、方程式の $x^2$ の符号が反転する。$\nu=1/2$ では $I_{1/2}(x)=\sqrt{2/(\pi x)}\sinh x$。独立な減衰解として $x^{-1/2}e^{-x}$ があり、無限遠に向かう境界条件は増える解の成分を除く。正の振動周波数を持つ Bessel 方程式の零点の議論は、変形方程式にはそのまま適用できない。

### 変形 Bessel 方程式の減衰解

$x>0$、$\nu\in\R$ とし、
$$
K_\nu(x)=\int_0^\infty e^{-x\cosh t}\cosh(\nu t)\dd t
$$
と置く。これは :term[第二種変形 Bessel 関数]{en="modified Bessel function of the second kind" yomi="だいにしゅへんけいべっせるかんすう"} である。$x$ の正のコンパクト区間上で、$x$ 微分により $\cosh t$ の冪が付いても、$e^{-x\cosh t}$ が無限遠でそれを抑える。従って積分内で微分できる。

変形 Bessel の作用素を積分へ入れると、$g(t)=e^{-x\cosh t}$ に対して $\int_0^\infty (g''(t)-\nu^2g(t))\cosh(\nu t)\dd t$ になる。実際 $g''=[x^2\sinh^2t-x\cosh t]g$ である。二回部分積分すると $\partial_t^2\cosh(\nu t)=\nu^2\cosh(\nu t)$ であるため積分は零になる。境界項は無限遠では指数で消え、$t=0$ では $g'(0)=0$ と $\sinh(\nu\cdot0)=0$ から消える。

遠方では $t=s/\sqrt x$ と置くと
$$
\sqrt x\,e^x K_\nu(x)
=\int_0^\infty
e^{-x(\cosh(s/\sqrt x)-1)}\cosh(\nu s/\sqrt x)\dd s
\longrightarrow \int_0^\infty e^{-s^2/2}\dd s=\sqrt{\pi/2}.
$$
$x\ge1$ なら $\cosh(s/\sqrt x)-1\ge s^2/(2x)$ であり、被積分関数は $e^{-s^2/2+|\nu|s}$ で一様に抑えられる。従って優収束を適用できる。一方、$\nu\ge0$ の $I_\nu$ の正の級数には無限遠で増える単項式があるので $I_\nu$ は発散する。このため $K_\nu$ は $I_\nu$ と独立であり、両者で $x>0$ の解空間を張る。

積の公式から $K_\nu'=-(K_{\nu+1}+K_{\nu-1})/2$ である。また $\nu\cosh(\nu t)=(\sinh(\nu t))'$ を用いて一回部分積分すると
$$
\nu K_\nu=x\int_0^\infty e^{-x\cosh t}\sinh t\sinh(\nu t)\dd t
=\frac x2(K_{\nu+1}-K_{\nu-1}).
$$
同じ積分表示から $K_{-\nu}=K_\nu$ である。従って半整数を一つ求めれば、上の差の公式で次数を順に増やせる。

:::example[半整数の減衰を Gaussian 積分で得る]
$\nu=1/2$ では $u=\sinh(t/2)$ と置くと、$\cosh t=1+2u^2$、$\cosh(t/2)\dd t=2\dd u$ である。従って
$$
K_{1/2}(x)=2e^{-x}\int_0^\infty e^{-2xu^2}\dd u
=\sqrt{\frac{\pi}{2x}}e^{-x}.
$$
直前に求めた減衰解 $x^{-1/2}e^{-x}$ の定数を、この積分が指定する。振幅の規格化も含めて、先の正の実方向の漸近式と一致する。
:::

:::example[漸化式で次の次数の減衰解を得る]
差の公式に $\nu=1/2$ を入れると $K_{3/2}=K_{-1/2}+K_{1/2}/x$。偶性から
$$
K_{3/2}(x)=\sqrt{\frac{\pi}{2x}}e^{-x}(1+1/x)
$$
となる。$x\to+\infty$ では $1/x$ は補正だが、$x\downarrow0$ では $x^{-3/2}$ を作る主要項である。原点側では大きい方の指数 $3/2$ を持つ $I_{3/2}$ が消え、遠方側では $K_{3/2}$ が消える。端によって選ぶ基底が異なる。
:::

### 半整数と球 Bessel 関数

$u=x^{-1/2}J_{\ell+1/2}(x)$ は $x^2u''+2xu'+[x^2-\ell(\ell+1)]u=0$ を満たす。これは $x^{1/2}u$ を :eqref[eq-ode-bessel] に代入して得る。規格化 $j_\ell(x)=\sqrt{\pi/(2x)}J_{\ell+1/2}(x)$ を取ると $j_0=\sin x/x$、$j_1=\sin x/x^2-\cos x/x$。例えば $j_1$ の原点での見かけの発散は展開によって相殺され、$j_1=x/3+O(x^3)$ となる。

### 無限遠での Bessel 関数の振幅と位相

正の実軸上の遠方では、:eqref[eq-ode-bessel] の $x^{-1}$ の項は振幅を下げ、無限遠での位相には原点での規格化の情報が残る。積分表示の両端から、その位相の値が出ることを示す。

:::lemma[積分端の冪に対する評価]{#lem-ode-bessel-endpoint}
$\beta>-1$、$h$ を $[0,\infty)$ 上の滑らかなコンパクト支持関数とする。$x\to+\infty$ で
$$
\int_0^\infty u^\beta h(u)e^{-ixu}\dd u
=h(0)\Gamma(\beta+1)e^{-i\pi(\beta+1)/2}x^{-\beta-1}
+O(x^{-\beta-2})
$$
である。
:::

:::proof
$h(0)e^{-u}$ を足し引きする。主項の積分は $\Gamma(\beta+1)(1+ix)^{-\beta-1}$ である。この公式は実の正の Laplace 変数に対する Gamma 積分を、実部正の半平面における積分の正則性で延長して得る。$x\to+\infty$ で $(1+ix)^{-\beta-1}=x^{-\beta-1}e^{-i\pi(\beta+1)/2}(1+O(x^{-1}))$。

余りの振幅 $R(u)=u^\beta[h(u)-h(0)e^{-u}]$ は、$u\downarrow0$ で $R^{(j)}(u)=O(u^{\beta+1-j})$、無限遠で指数減衰する。$0<u<1/x$ の積分は直接 $O(x^{-\beta-2})$。$u\ge1/x$ で $m>\beta+2$ 回部分積分すると、境界項は $x^{-j-1}R^{(j)}(1/x)=O(x^{-\beta-2})$。残る積分は $x^{-m}$ 倍の $\int_{1/x}^\infty |R^{(m)}|$ であり、原点に近い部分が $O(x^{m-\beta-2})$、遠い部分は有限である。従って全ての余りは所望の大きさである。
:::

:::proposition[Bessel 関数の遠方表示]{#prop-ode-bessel-large}
固定した $\nu>-1/2$ に対し
$$
J_\nu(x)=\sqrt{\frac{2}{\pi x}}
\cos\left(x-\frac{\nu\pi}{2}-\frac{\pi}{4}\right)+O(x^{-3/2})
\qquad (x\to+\infty)
\label{eq-ode-bessel-large}
$$
である。$\nu$ が $(-1/2,\infty)$ のコンパクト集合を動くとき剰余は一様に取れる。
:::

:::proof
積分表示の $\cos(xu)$ を $e^{ixu}$ に置き換えても、虚部は奇関数なので積分値は変わらない。両端 $u=\pm1$ と内部へ滑らかに分割する。内部の部分は何度でも部分積分できるので任意の固定次数で小さい。$u=1-v$ の端では $(1-u^2)^{\nu-1/2}=v^{\nu-1/2}(2-v)^{\nu-1/2}$ となり、指数は $e^{ix}e^{-ixv}$。:ref[lem-ode-bessel-endpoint] を $\beta=\nu-1/2$ で使うと主要項は
$$
e^{ix} 2^{\nu-1/2}\Gamma(\nu+1/2)
e^{-i\pi(\nu+1/2)/2}x^{-\nu-1/2}.
$$
反対側はその共役である。二項を足し、積分表示の前因子を掛ければ :eqref[eq-ode-bessel-large] が出る。剰余評価で用いる微分回数 $m$ はコンパクトな $\nu$ の上界を基準に固定でき、端の積分の評価定数も $\nu+1/2$ の正の下界で抑えられるので一様である。
:::

$\nu\ge0$ での導関数については $J_\nu'=\nu J_\nu/x-J_{\nu+1}$ を用いると、:eqref[eq-ode-bessel-large] の余弦を負の正弦に替えた先頭項を得る。振幅の微分に由来する項は $O(x^{-3/2})$。元の漸近式を形式的に微分して誤差の導関数を仮定する必要はない。

### Hankel 関数と進行波

:term[Hankel 関数]{en="Hankel function" yomi="はんけるかんすう"} を $H_\nu^{(1)}=J_\nu+iY_\nu$、$H_\nu^{(2)}=J_\nu-iY_\nu$ と定める。:ref[prop-ode-bessel-wronskian] により $W(H_\nu^{(1)},H_\nu^{(2)})=-4i/(\pi x)$ であり、独立な解の組を成す。

$Y_\nu$ の遠方表示を得るには、まず :eqref[eq-ode-bessel-large] を $J_{-\nu}$ にも使えるようにする。積分表示と端点の評価では複素次数 $\mu$ でも $\Re\mu>-1/2$ なら同じ計算ができる。二端の指数について符号が反対の二式を使えば、その和は同じ余弦となる。剰余はこの半平面のコンパクト集合上で一様である。さらに任意のコンパクトな次数範囲に対して、$J_\mu=2(\mu+1)J_{\mu+1}/x-J_{\mu+2}$ を有限回用いると、右辺の次数をこの半平面まで上げられる。支配項 $-J_{\mu+2}$ は位相が $\pi$ ずれた余弦の負であるから、元の位相の余弦に戻る。こうして :eqref[eq-ode-bessel-large] がその次数範囲でも一様に成り立つ。

$\chi=x-\nu\pi/2-\pi/4$ と置くと、$J_{-\nu}$ の主要項には $\cos(\chi+\pi\nu)$ が現れる。従って $Y_\nu$ の分子の主要項は $\sqrt{2/(\pi x)}\sin(\pi\nu)\sin\chi$ である。整数次数でも同じ結果を得るため、整数 $n$ を中心とした半径 $1/4$ の円を次数平面に取る。円周上では $\sin(\pi\nu)$ は零から離れ、$Y_\nu-\sqrt{2/(\pi x)}\sin\chi$ は一様に $O(x^{-3/2})$。円板の内側では $n$ で除去可能であるため、最大値原理によって同じ評価が中心でも成り立つ。以上から正の実軸上で
$$
Y_\nu(x)=\sqrt{\frac2{\pi x}}\sin\chi+O(x^{-3/2}),\qquad
H_\nu^{(1,2)}(x)=\sqrt{\frac2{\pi x}}e^{\pm i\chi}+O(x^{-3/2})
$$
を得る。例えば $\nu=1/2$ では $H_{1/2}^{(1)}=-i\sqrt{2/(\pi x)}e^{ix}$、$H_{1/2}^{(2)}=i\sqrt{2/(\pi x)}e^{-ix}$ である。時間因子を $e^{-i\omega t}$ とする規約では $e^{ix}$ を持つ枝が外向きに進む。

:::example[半整数の遠方表示を直接照合する]
$\nu=3/2$ なら位相は $x-\pi$ なので主要項は $-\sqrt{2/(\pi x)}\cos x$。実際の式にはさらに $\sqrt{2/(\pi x)}\sin x/x$ があり、差は $O(x^{-3/2})$ である。$\nu=1/2$ なら位相 $x-\pi/2$ から正弦が得られ、この場合は主要項そのものが厳密解になる。
:::

## Legendre 方程式と Legendre 多項式

$$
(1-x^2)y''-2xy'+\lambda y=0
\label{eq-ode-legendre}
$$
を :term[Legendre 方程式]{en="Legendre equation" yomi="るじゃんどるほうていしき"} という。極角の余弦を $x$ とすると、球面上の軸対称な角度作用素が $((1-x^2)y')'$ になる。$x=\pm1$ は確定特異点だが $x=0$ は正則点であり、
$$
(k+2)(k+1)a_{k+2}=[k(k+1)-\lambda]a_k.
$$
$\lambda=n(n+1)$ なら $n$ と同じ偶奇の級数は次数 $n$ で終わる。

:::proposition[Rodrigues 公式と直交性]{#prop-ode-legendre-rodrigues}
$n\ge0$ の整数に対し
$$
P_n(x)=\frac{1}{2^n n!}D^n(x^2-1)^n
$$
は $\lambda=n(n+1)$ に対する解で、$P_n(1)=1$ である。また
$$
\int_{-1}^1 P_n P_m\dd x=\frac{2}{2n+1}\delta_{nm}.
$$
:::

:::proof
$g=(x^2-1)^n$ とすると $(x^2-1)g'=2nxg$ である。この式を $n+1$ 回微分して、積の微分から $(x^2-1)g^{(n+2)}+2xg^{(n+1)}-n(n+1)g^{(n)}=0$ を得る。$x=1$ で $(x-1)^n(x+1)^n$ の $n$ 階微分は $2^n n!$。従って式と基準化を満たす。

$m<n$ なら Rodrigues 公式を $n$ 回部分積分すると、端で $g$ の $n-1$ 階までの導関数が消え、$D^n P_m=0$ なので直交する。$m=n$ のとき最高次係数は $c_n=(2n)!/[2^n(n!)^2]$ で、同じ計算によりノルム二乗は $(c_n/2^n)I_n$、$I_n=\int_{-1}^1(1-x^2)^n\dd x$ となる。$n\ge1$ で $[x(1-x^2)^n]_{-1}^1=0$ を微分積分すれば $(2n+1)I_n=2n I_{n-1}$。$I_0=2$ と合わせて $I_n=2^{2n+1}(n!)^2/(2n+1)!$ を得る。
:::

例えば $P_0=1,\ P_1=x,\ P_2=(3x^2-1)/2,\ P_3=(5x^3-3x)/2$ である。$xP_n$ は次数 $n+1$ で、$m\le n-2$ では $\int xP_n P_m=\int P_n(xP_m)=0$。偶奇から $P_n$ の成分も消える。最高次係数の比と $x=1$ を用いると、$n\ge1$ で
$$
(n+1)P_{n+1}=(2n+1)xP_n-nP_{n-1}
$$
となる。

:::example[両端の条件で解を選ぶ]
$\lambda=0$ では $(1-x^2)y'=C$ なので、第二解は $\frac12\log[(1+x)/(1-x)]$ である。これは両端で発散し、両端有界な解は定数倍の $P_0$ だけである。一般の $n$ でも $P_n(1)=1$ のため、$x=1$ の近くで [常微分方程式の式](/math/ode/linear-systems/#eq-ode-dalembert) の被積分関数は $1/[(1-x^2)P_n^2]$ の定数倍となり、第二解は対数的に発散する。
:::

### 母関数から多項式をまとめて読む

$G(x,t)=(1-2xt+t^2)^{-1/2}$ を考える。$G(x,0)=1$、$(1-2xt+t^2)G_t=(x-t)G$ である。$G=\sum_{n\ge0}b_n(x)t^n$ を代入すると $b_0=1,b_1=x$、$(n+1)b_{n+1}=(2n+1)xb_n-nb_{n-1}$。すでに得た $P_n$ の漸化式と一致するので、$G$ は多項式列の母関数である。例えば $x=1$ では $G=(1-t)^{-1}$ だから全次数で値 $1$ となり、$x=0$ では $(1+t^2)^{-1/2}$ となるため奇数次は全て消える。

### 陪 Legendre 方程式

:eqref[eq-ode-legendre] を $m$ 回微分して $u=D^mP_n$ とすると
$$
(1-x^2)u''-2(m+1)xu'+[n(n+1)-m(m+1)]u=0.
$$
$m$ 階の積の微分では $(1-x^2)$ の三階以上の導関数が零なので、現れる係数は上の三つに限られる。$v=(1-x^2)^{m/2}u$ と置いて積を微分すると
$$
(1-x^2)v''-2xv'+\left[n(n+1)-\frac{m^2}{1-x^2}\right]v=0
$$
になる。例えば $n=2,m=1$ では $v=3x\sqrt{1-x^2}$。規格化の規約によって $(-1)^m$ をさらに掛けることがあるが、方程式と零点は変わらない。この形では $m$ が零でないと端点での指数が通常の Legendre 方程式と異なる。

### 第二種 Legendre 解を積分で作る

$x>1$ に対し
$$
Q_n(x)=\frac12\int_{-1}^1\frac{P_n(t)}{x-t}\dd t
$$
と置く。$K=(x-t)^{-1}$ は $\partial_x[(1-x^2)K_x]=\partial_t[(1-t^2)K_t]$ を満たす。実際、左辺は $2x/(x-t)^2+2(1-x^2)/(x-t)^3$、右辺は $-2t/(x-t)^2+2(1-t^2)/(x-t)^3$ で、差は零になる。積分に左辺の作用素を入れ、二回部分積分すると端で $1-t^2$ が消え、$P_n$ に同じ作用素が移る。従って $Q_n$ は :eqref[eq-ode-legendre] を満たす。

$P_n(1)=1$ なので、$P_n(t)-1=(t-1)R(t)$ と書ける。これを積分に入れ、$x\downarrow1$ とすると $P_n-1$ の項は有界であり、定数項は
$$
Q_0(x)=\frac12\log\frac{x+1}{x-1}
$$
となる。従って $Q_n$ は端で対数的に発散し、$P_n$ から独立である。また $x$ を無限大へ動かすと $(x-t)^{-1}$ の冪展開で $t^k$（$k<n$）との積分は直交性により零になる。$t^n$ には $P_n$ の正の定数倍が含まれるため、その項は零でなく、$Q_n$ は $x^{-n-1}$ の定数倍から始まる。無限遠の二つの指数はこの減衰解と多項式解に対応する。

:::example[次数 1 の第二解]
$t/(x-t)=x/(x-t)-1$ だから $Q_1(x)=xQ_0(x)-1$。$x\to\infty$ で $Q_0(x)=1/x+1/(3x^3)+O(x^{-5})$ を用いれば $Q_1=1/(3x^2)+O(x^{-4})$。積分の前の $-1$ は、最高次の項を相殺して規格化された減衰を作る。
:::

### 両端で有界となる固有値

実数 $\lambda$ を任意に取って :eqref[eq-ode-legendre] を考える。$x=\pm1$ の決定式はどちらも $r^2$ である。:ref[prop-ode-frobenius-log] により、各端で有界な解は特性指数 $0$ の正則解の倍に限られる。従って両端で有界な解 $u$ は閉区間まで連続に延び、$u'$ も各端で有限である。

$u$ と $P_n$ の自己随伴形の方程式を掛け引きして積分する。境界項 $(1-x^2)(uP_n'-u'P_n)$ は両端で消えるため、
$$
[\lambda-n(n+1)]\int_{-1}^1u(x)P_n(x)\dd x=0
$$
となる。もしどの $n$ に対しても $\lambda\ne n(n+1)$ なら、$u$ は全ての多項式と直交する。実際、$P_0,\ldots,P_n$ は異なる次数と非零の最高次係数を持つので、次数 $n$ 以下の多項式を張る。:ref[thm-anl-weierstrass] により $\overline{u}$ を多項式で一様近似すれば $\int |u|^2=0$ となる。よって非零の両端有界解を持つ値は $\lambda=n(n+1)$ のみである。これらでは $P_n$ が存在し、片方の端での有界性だけでも同じ解の定数倍に限られる。

:::proposition[Legendre 多項式の零点の個数]{#prop-ode-legendre-simple-zeros}
$n\ge1$ のとき $P_n$ は $(-1,1)$ にちょうど $n$ 個の零点を持ち、全て単純である。
:::

:::proof
$(-1,1)$ 内の符号を変える零点を $x_1,\dots,x_m$ とする。$m<n$ と仮定し $Q(x)=\prod_{j=1}^m(x-x_j)$ と置くと、$P_nQ$ は区間内で符号を変えず、恒等的に零でもないので積分は零でない。一方、$P_0,\ldots,P_{n-1}$ は次数が一つずつ異なり、それぞれの最高次係数が非零だから、次数が $n-1$ 以下の多項式の基底である。従って :ref[prop-ode-legendre-rodrigues] により $\int_{-1}^1P_n Q=0$ で、矛盾する。従って $m=n$ であり、次数からこれら以外の零点と重根はない。
:::

:::example[Rodrigues 公式から係数と直交性を確認する（次数 2）]

## Hermite 方程式と Laguerre 方程式

### Hermite 多項式

物理学で使う規約では $y''-2xy'+2ny=0$ の次数 $n$ の解を $H_n$ とする。これは :term[Hermite 多項式]{en="Hermite polynomial" yomi="えるみーとたこうしき"} であり、重みは $e^{-x^2}$ である。確率論で別の尺度を使う規約もあるので、方程式と重みを一緒に示す。

$g=e^{-x^2}$、$H_n=(-1)^n g^{-1}D^n g$ とすると $g'=-2xg$ から $H_{n+1}=2xH_n-H_n'$ を得る。$H_0=1$ より次数 $n$、最高次係数 $2^n$ である。$g'+2xg=0$ を $n+1$ 回微分すると $u=g^{(n)}$ は $u''+2xu'+2(n+1)u=0$、$u=(-1)^n gH_n$ を代入して所望の式を得る。また元の式を微分すると $H_n'$ は次数 $n-1$ の方程式を解く。漸化式から同じ次数の多項式解は最高次係数を固定すると一意なので、$H_n'=2nH_{n-1}$ である。

$m\le n$ で $\int_\R gH_nH_m$ に Rodrigues 公式を使い $n$ 回部分積分すると $\int_\R g D^n H_m$ になる。各境界項は多項式と $e^{-x^2}$ の積なので消える。従って $m<n$ で直交し、$m=n$ で $2^n n!\sqrt\pi$ となる。

:::example[最初の三つと偶奇]
$H_1=2x,\ H_2=4x^2-2,\ H_3=8x^3-12x$ である。$H_2$ と $H_3$ の重み付き積は奇関数なので積分は零である。$H_0$ と $H_2$ の積の直交性は偶奇からは出ないが、Rodrigues 公式の部分積分で得られる。
:::

### 一般化 Laguerre 多項式

$\alpha>-1$ とし $xy''+(\alpha+1-x)y'+ny=0$ を考える。係数の漸化式は
$$
(k+1)(k+\alpha+1)a_{k+1}=(k-n)a_k
$$
だから整数 $n\ge0$ で打ち切られる。標準的な規格化を
$$
L_n^{(\alpha)}(x)=\frac{x^{-\alpha}e^x}{n!}D^n(e^{-x}x^{n+\alpha})
$$
とし、これを :term[一般化 Laguerre 多項式]{en="generalized Laguerre polynomial" yomi="いっぱんからげーるたこうしき"} という。Leibniz 則を用いると $x^k$ の係数は
$$
a_k=\frac{(-1)^k}{k!}\frac{\Gamma(n+\alpha+1)}{\Gamma(k+\alpha+1)(n-k)!},
\qquad 0\le k\le n.
$$
この隣接比は上の漸化式に等しく、最高次係数は $(-1)^n/n!$ である。重み $w=x^\alpha e^{-x}$ を掛けると微分方程式は $(xwy')'+nwy=0$ となる。

Rodrigues 公式を使い $n$ 回部分積分すれば、任意の多項式 $p$ について $\int_0^\infty w L_n^{(\alpha)}p=(-1)^n\int_0^\infty e^{-x}x^{n+\alpha}p^{(n)}/n!$。原点の境界項で現れる $D^j(e^{-x}x^{n+\alpha})$（$j\le n-1$）は $O(x^{\alpha+1})$ 以下の大きさであり、無限遠では指数で消える。従って異なる次数で直交し、二乗ノルムは $\Gamma(n+\alpha+1)/n!$ となる。

:::example[一次と二次の係数]
$L_1^{(\alpha)}=\alpha+1-x$、$L_2^{(0)}=1-2x+x^2/2$ である。例えば $\alpha=0$ の一次と二次の積は $1-3x+(5/2)x^2-x^3/2$。重み $e^{-x}$ に対して $x^k$ の積分が $k!$ であることを用いると $1-3+5-3=0$ となり、直交性を直接照合できる。
:::

### Hermite と Laguerre の漸化式を比較する

Hermite では $H_{n+1}=2xH_n-2nH_{n-1}$ である。これは Rodrigues 公式からの微分漸化式に $H_n'=2nH_{n-1}$ を代入して得る。逆に、この式に $H_0=1,H_1=2x$ を与えれば積分や高階微分なしに多項式を作れる。例えば $H_4=16x^4-48x^2+12$ であり、$x^4$ の係数 $16$ と偶性は一般の規約と一致する。

Laguerre では $xL_n^{(\alpha)}$ が $L_{n+1}^{(\alpha)},L_n^{(\alpha)},L_{n-1}^{(\alpha)}$ の一次結合になる。実際、$m\le n-2$ に対する内積は $L_n^{(\alpha)}$ と $xL_m^{(\alpha)}$ の直交性で零である。最高次係数を比べると $L_{n+1}^{(\alpha)}$ の係数は $-(n+1)$、直交性とノルムの比から $L_{n-1}^{(\alpha)}$ の係数は $-(n+\alpha)$ となる。真ん中の係数は一つ下の次数を比較して $2n+\alpha+1$ を得る。従って
$$
(n+1)L_{n+1}^{(\alpha)}
=(2n+\alpha+1-x)L_n^{(\alpha)}-(n+\alpha)L_{n-1}^{(\alpha)}.
$$
例えば $\alpha=0,n=1$ で右辺は $(3-x)(1-x)-1=2-4x+x^2$、$L_2^{(0)}$ に一致する。Hermite の漸化式では偶奇性により真ん中の係数に定数項は出ないが、Laguerre は半直線の重みなので一般に出る。

### 二つの母関数

Hermite では Taylor の公式を $g(x-t)$ に適用すると
$$
e^{2xt-t^2}=e^{x^2}e^{-(x-t)^2}=\sum_{n=0}^\infty H_n(x)\frac{t^n}{n!}
$$
である。$t$ について微分し $(2x-2t)$ を掛けた式と比較すると三項漸化式になる。$x$ について微分すれば $2t$ を掛けるので $H_n'=2nH_{n-1}$。一つの母関数から、次数を上げる操作と下げる操作の両方を確認できる。

Laguerre では $|t|<1$ で
$$
\sum_{n\ge0}L_n^{(\alpha)}(x)t^n
=(1-t)^{-\alpha-1}\exp\left(-\frac{xt}{1-t}\right).
$$
Rodrigues 公式から得た各 $x^k$ の係数に $n=k+j$ と置くと
$$
\sum_{j\ge0}\frac{\Gamma(j+k+\alpha+1)}{\Gamma(k+\alpha+1)j!}t^j
=(1-t)^{-k-\alpha-1}.
$$
残りの因子を足せば $\sum_k[-xt/(1-t)]^k/k!$。絶対値を取った二重和も $(1-|t|)^{-\alpha-1}\exp(|x t|/(1-|t|))$ で有界なので和の順序を変えられる。例えば $x=0,\alpha=0$ では母関数は $(1-t)^{-1}$ だから全て $L_n^{(0)}(0)=1$。$\alpha=1$ では $(1-t)^{-2}$ なので $L_n^{(1)}(0)=n+1$。

### 二つの方程式を偶奇で結ぶ


Hermite 方程式 $y''-2xy'+2ny=0$ に対し、偶解を $y=v(x^2)$ と書く。$y'=2xv'$、$y''=2v'+4x^2v''$ を代入すると $zv''+(\tfrac12-z)v'+(n/2)v=0$、$z=x^2$ である。奇解を $y=xv(x^2)$ と書くと $y'=v+2x^2v'$、$y''=6xv'+4x^3v''$ だから $zv''+(\tfrac32-z)v'+((n-1)/2)v=0$ となる。従って $n=2m$ または $2m+1$ の多項式は、それぞれ $L_m^{(-1/2)}$ または $xL_m^{(1/2)}$ に比例する。最高次係数の比較で
$$
H_{2m}(x)=(-1)^m2^{2m}m!L_m^{(-1/2)}(x^2),
\qquad H_{2m+1}(x)=(-1)^m2^{2m+1}m!xL_m^{(1/2)}(x^2)
$$
となる。偶の場合に積分変数を $z=x^2$ とすれば $e^{-x^2}\dd x$ の両半軸の和は $z^{-1/2}e^{-z}\dd z$ になり、奇同士の積ではさらに $z$ が掛かる。このため、同じ変換が多項式と直交積の両方を結び付ける。

:::example[Hermite の次数 4 を Laguerre の次数 2 へ移す]
$H_4$ を $x^2$ を変数に持つ一般化 Laguerre 多項式から復元し、Hermite の重みでノルムを求める。

先に偶奇で添字を決める。$x^2$ の多項式を作り、Hermite の最高次係数が $2^n$ になるよう定数を掛ける。

$$
\begin{aligned}

H_n(x)&=16 x^{4} - 48 x^{2} + 12
\end{aligned}
$$

二乗ノルムでは左右半軸を合わせ、$z=x^2$ に置換する。変換後の多項式の二乗ノルムに、前段で求めた定数の二乗を掛ければよい。

$$
\begin{aligned}
\int_0^\infty z^\alpha e^{-z}|L_m^{(\alpha)}(z)|^2\dd z&=\frac{3 \sqrt{\pi}}{8}\\
\int_\R e^{-x^2}H_n(x)^2\dd x&=384 \sqrt{\pi}
\end{aligned}
$$

この計算は $H_n$ の二乗を直接展開するより積分の項が少ない。偶関数と奇関数の直交性は元の区間の対称性で従い、同じ偶奇の内部での直交性は Laguerre の重みに移る。
:::

## 不確定特異点と漸近展開（概観）

正規形の特異点で $xp$ と $x^2q$ の少なくとも一方が解析的に延びなければ :term[不確定特異点]{en="irregular singular point" yomi="ふかくていとくいてん"} という。無限遠を調べるときは $z=1/x$ と置く。例えば $y''-y=0$ は $z^4Y''+2z^3 Y'-Y=0$ となり、$z=0$ は不確定特異点である。解は $e^{\pm1/z}$ で、有限の冪を先頭にした Frobenius 形では表せない。

:::definition[漸近展開]{#def-ode-asymptotic}
$x\to+\infty$ に対し、全ての整数 $N\ge1$ で
$$
f(x)-\sum_{k=0}^{N-1}a_k x^{-k}=O(x^{-N})
$$
なら $f(x)\sim\sum_{k\ge0}a_k x^{-k}$ と書く。この意味での :term[漸近展開]{en="asymptotic expansion" yomi="ぜんきんてんかい"} は、各固定次数で打ち切った誤差を指定する。
:::

最小の係数の差を持つ次数が $j$ なら、$N=j+1$ の剰余に $x^j$ を掛けた極限ではその係数差が残る。従って同じ関数に対する係数列は一意である。一方 $f$ と $f+e^{-x}$ の係数は全て同じであり、漸近級数が同じでも関数は一意に定まらない。

:::example[発散する漸近級数の剰余]
$F(x)=\int_0^\infty e^{-s}/(x+s)\dd s$（$x>0$）とする。$t=x+s$ の置換から $F=e^x\int_x^\infty e^{-t}/t\dd t$ となり、$F'=F-1/x$ である。有限の幾何和を使えば
$$
F(x)=\sum_{k=0}^{N-1}\frac{(-1)^k k!}{x^{k+1}}+
\frac{(-1)^N}{x^N}\int_0^\infty\frac{e^{-s}s^N}{x+s}\dd s.
$$
剰余の絶対値は $N!/x^{N+1}$ 以下である。しかし固定 $x$ で隣接項の比 $(k+1)/x$ は無限大へ行くため、無限和は収束しない。この例では方程式に形式級数を入れても係数 $(-1)^k k!$ が得られるが、積分表示がはじめて、その級数が実際の解の漸近展開であることを保証する。
:::

:::example[方向により指数の大小が逆転する]
$e^{-1/z}$ は実正軸上で任意の $z^N$ より速く零に近づく。一方、負の実軸では $|e^{-1/z}|=e^{1/|z|}$ で発散する。複素平面では $|e^{-1/z}|=\exp(-\cos\theta/r)$（$z=r e^{i\theta}$）なので、同じ式の漸近性でも扇形の向きを指定する必要がある。
:::

### 形式解に指数因子が必要な場合

Airy 方程式 $y''-xy=0$ の $x>0$ における遠方を考える。$y=e^{S(x)}$ と仮定して $S''+(S')^2=x$ を得る。最大の次数だけをそろえると $S'\approx\pm\sqrt x$、従って $S\approx\pm2x^{3/2}/3$ である。実際 $y_0=x^{-1/4}e^{\pm2x^{3/2}/3}$ を取ると
$$
y_0''-xy_0=\frac5{16x^2}y_0.
$$
$x^{-1/4}$ を入れることで $x^{-1/2}$ の次数の残差が消える。$y=y_0w$ とすれば $w''+2(y_0'/y_0)w'+5w/(16x^2)=0$、ここへ $w=1+c_1 x^{-3/2}+\cdots$ を形式的に入れられる。$x^{-2}$ の係数から $c_1=\pm5/48$ を得る。符号は指数の符号に対応する。

この操作が保証するのは、打切りを元の式へ入れたとき残る項の次数である。実際の解の相対誤差まで主張するには、積分表示や、残差を制御する積分方程式が必要になる。特に増大枝に任意の減衰枝を足しても、正の実軸では有限次数の相対展開だけでは区別できない。

### Airy の減衰解で剰余を正当化する

$s=2x^{3/2}/3$、$y=x^{-1/4}v(s)$ と置く。$s'=\sqrt x$ なので、微分では $v_s$ の項が相殺し、
$$
v_{ss}-v=-\frac{5}{36s^2}v
$$
となる。減衰の主要部 $e^{-s}$ を取り出して $v=e^{-s}w$ とすると、$w_{ss}-2w_s=-5w/(36s^2)$ である。$w(s)\to1$ とするために次の積分方程式を考える。
$$
w(s)=1-\frac5{72}\int_s^\infty (1-e^{-2(r-s)})\frac{w(r)}{r^2}\dd r .
$$
$s\ge S>0$ の有界連続関数に対し、右辺の積分作用素は一様ノルムで $5/(72S)$ 以下である。従って $S$ が十分大きいとき縮小写像の原理で一意な有界解が得られる。積分を微分すると所望の二階式が戻る。また積分の上界から $w(s)=1+O(s^{-1})$ である。これを被積分関数に戻すと、$\int_s^\infty w(r)/r^2\dd r=s^{-1}+O(s^{-2})$。指数因子を含む部分は $\norm w_\infty\int_s^\infty e^{-2(r-s)}s^{-2}\dd r=O(s^{-2})$ である。従って
$$
y_-(x)=x^{-1/4}e^{-2x^{3/2}/3}
\left(1-\frac{5}{48x^{3/2}}+O(x^{-3})\right)
$$
を得る。ここでは無限遠での係数を $1$ に取った。

独立な増大解は $y_+(x)=2y_-(x)\int_{x(S)}^x y_-(u)^{-2}\dd u$ で作れる。$r=2u^{3/2}/3$ に置き換えると積分は $\int_S^s e^{2r}[1+5/(36r)+O(r^{-2})]\dd r$ となる。$r\le s/2$ の部分は $O(e^s)$、$r\ge s/2$ では $1/r=1/s+O((s-r)/s^2)$ である。後半を積分すると $e^{2s}[1+5/(36s)+O(s^{-2})]/2$。従って $y_+$ では $e^{-s}$ が $e^s$ に、相対補正 $-5/(48x^{3/2})$ が $+5/(48x^{3/2})$ に替わる。積分の下端を変えると減衰解の倍が加わるが、増大解のこの剰余評価は保たれる。

:::example[Laplace 型積分から剰余を押さえる（指数 2、係数 1）]
$F(x)=\int_0^\infty e^{-1s}x^{1}/(x+s)^{2}\dd s$、$x>0$ とする。$x\to+\infty$ の展開を最初の四項まで求める。 $m=2$、$a=1$ とする。

$(m)_j=m(m+1)\cdots(m+j-1)$、$(m)_0=1$ とする。$(1+u)^{-m}$ を $u=0$ で三次まで Taylor 展開する。$j$ 階導関数は $(-1)^j(m)_j(1+u)^{-m-j}$ だから、$u\ge0$ で四次の剰余は $(m)_4u^4/4!$ 以下である。$u=s/x$ とし各項を積分する。

$$
\begin{aligned}
\int_0^\infty s^j e^{-as}\dd s&=j!/a^{j+1}\\
(c_0,c_1,c_2,c_3)&=\left( 1, \  -2, \  6, \  -24\right)\\
\sum_{j=0}^3 c_j x^{-j-1}&=\frac{1}{x} - \frac{2}{x^{2}} + \frac{6}{x^{3}} - \frac{24}{x^{4}}
\end{aligned}
$$

剰余の絶対値を積分すると、主要な四項とは別に有界な残差が得られる。この評価には $s/x<1$ という条件が不要なので、積分範囲を途中で切らなくてよい。

$$
\begin{aligned}
\left|F(x)-\sum_{j=0}^3 c_j x^{-j-1}\right|&=O(x^{-5})\\
\text{上界の定数}&=120
\end{aligned}
$$

同じ証明は任意の固定次数でできる。一方、隣接する項の絶対値の比は $(m+j)/(ax)$ である。固定した $x$ で次数だけを上げると、この比がいつか $1$ を越えるため、打切りの効果と無限和の収束を区別する必要がある。
:::

## 演習問題

::::exercise{level=basic}

$y''=x^2y,\ y(0)=1,\ y'(0)=0$ の $x^8$ までの展開を求めよ。

:::solution

$a_2=a_3=0$、$a_{n+2}=a_{n-2}/((n+2)(n+1))$（$n\ge2$）。従って $a_4=1/12,\ a_8=1/(12\cdot56)=1/672$ であり、他の $8$ 以下の正次数は零である。

:::
::::

::::exercise{level=basic}

$x>0$ で $x^2y''+xy'-9y=0$ の指数と一般解を求めよ。

:::solution

決定式は $r^2-9=0$、根は $3,-3$。係数が定数なので $x^3,x^{-3}$ がそのまま解で、Wronskian は $-6/x\ne0$。よって $y=C_1x^3+C_2x^{-3}$。

:::
::::

::::exercise{level=basic}

$J_0$ の $x^6$ の係数を求めよ。

:::solution

$k=3$ の係数は $(-1)^3/[2^6(3!)^2]=-1/2304$ である。

:::
::::

::::exercise{level=basic}

$P_2$ のノルム二乗を直接積分で求めよ。

:::solution

$P_2^2=(9x^4-6x^2+1)/4$ なので、$[-1,1]$ での積分は $(18/5-4+2)/4=2/5$。

:::
::::

::::exercise{level=advanced}

$x>0$ で $x^2y''+2xy'=0$ の小さい指数から二解を得られることを示せ。

:::solution

根は $0,-1$。係数が定数なので $r=-1$ では $n=1$ の式が $0=0$、$a_1$ が自由である。$x^{-1}(1+a_1x)=x^{-1}+a_1$ が実際の解となり、$a_1$ の変化が定数解を加える。

:::
::::

::::exercise{level=advanced}

$H_2$ と $H_0$ の重み付き直交性を直接確認せよ。

:::solution

$(xe^{-x^2})'=e^{-x^2}(1-2x^2)$ より $e^{-x^2}H_2=-2(xe^{-x^2})'$。両端で $xe^{-x^2}\to0$ なので積分は零となる。

:::
::::

::::exercise{level=advanced}

$\alpha=1$ の $L_2^{(1)}$ を求め、$L_0^{(1)}$ と直交することを示せ。

:::solution

Rodrigues 公式の係数は $3,-3,1/2$ であり、$L_2^{(1)}=3-3x+x^2/2$。重み $xe^{-x}$ に対する積分は $3\cdot1!-3\cdot2!+3!/2=0$ である。

:::
::::

::::exercise{level=advanced}

本文の $F(x)$ を $1/x-1/x^2+2/x^3$ で近似したとき、$x=4$ の誤差の符号と絶対値の上界を求めよ。

:::solution

$N=3$ の積分剰余は $(-1)^3$ と正の積分の積なので負である。絶対値は $3!/4^4=3/128$ 以下となる。

:::

::::quiz

確定特異点の二つの指数の差が正の整数である。必ず成り立つものを選べ。

- [ ] 小さい指数から常に対数のない解が得られる。
- [ ] 第二解には必ず対数が現れる。
- [x] 大きい指数の Frobenius 級数が構成できる。

:::explanation

大きい指数 $r_1$ では $r_1+n$ はどちらの根にもならない。小さい指数では根の差に等しい次数の互換条件が問題になり、それが成立する場合と破れる場合がある。

$H_2(x)$ の $x^2$ の係数を答えよ。

:::explanation

$H_1=2x$ を漸化式 $H_2=2xH_1-H_1'$ に入れると $4x^2-2$ であり、係数は $4$。

::::quiz

$f(x)$ と $f(x)+e^{-x}$ を $x\to+\infty$ で比べる。同じ逆冪漸近展開を持ちうるか。

- [x] 持ちうる。
- [ ] 異なる関数なので持ちえない。

:::explanation

任意の $N$ で $e^{-x}=O(x^{-N})$ である。従って $f$ に逆冪漸近展開があれば、$e^{-x}$ を加えても各打切り剰余の次数が変わらない。
