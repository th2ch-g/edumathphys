## この章の目標

- 正則曲線を弧長で表示し、任意のパラメータから符号付き曲率を計算する。
- 曲率と初期条件から平面曲線を復元し、閉じるための条件を区別する。
- 単純閉曲線に対する接線回転定理を証明し、凸性と曲率を結び付ける。
- 四頂点定理と等周不等式を導き、各定理の仮定が必要な理由を説明する。

## 正則曲線と弧長パラメータ

地図では同じ道を示す曲線でも、それを異なる速さでたどると位置の時間微分は変わる。幾何を比較するには、時刻の代わりに道に沿った距離を使う。以下では平面に標準内積と向きを入れ、微分の回数に断りがなければ曲線は滑らかとする。区間の端点では片側微分、閉曲線では周期的な微分を用いる。

:::definition[正則曲線]{#def-cs-regular-curve}
区間 $I$ から $\R^2$ への滑らかな写像 $\gamma$ をパラメータ付き曲線という。すべての $t\in I$ で速度 $\gamma'(t)$ が零でない曲線を :term[正則曲線]{en="regular curve" yomi="せいそくきょくせん"} という。区間 $I$ への滑らかな微分同相写像 $\phi$ による $\gamma\circ\phi$ は同じ曲線の再パラメータ表示であり、$\phi'>0$ のとき進行方向も保つ。
:::

折れ線の頂点や停止した点では速度の定義だけで幾何を判定しにくい。例えば $(t^3,0)$ の像は直線だが、$t=0$ で速度は零である。逆関数 $x\mapsto x^{1/3}$ は原点で微分できないので、これは定義でいう正則な再パラメータ表示ではない。

:::proposition[弧長による再パラメータ表示]{#prop-cs-unit-speed}
$t_0\in I$ を固定すると、正則曲線の符号付き :term[弧長]{en="arc length" yomi="こちょう"} $s(t)=\int_{t_0}^{t}\norm{\gamma'(u)}\,\dd u$ は $I$ から区間 $s(I)$ への増加微分同相である。逆関数を $t(s)$ と置けば $\alpha(s)=\gamma(t(s))$ は $\norm{\alpha'}=1$ を満たす。進行方向を保つ単位速さ表示は弧長の原点を移す違いしかない。
:::

:::proof
曲線の長さの積分表示は :ref[prop-anl-arc-length] で得た。微積分の基本定理から $s'(t)=\norm{\gamma'(t)}>0$ である。よって $s$ は単射であり、逆関数定理による各局所逆は一致して滑らかな逆 $t$ を定める。連鎖律で $\alpha'(s)=\gamma'(t)/\norm{\gamma'(t)}$ を得る。二つの単位速さ表示を $\tilde\alpha=\alpha\circ\psi$ と関係付けると、微分のノルムから $|\psi'|=1$ となる。増加を仮定すれば $\psi'=1$ であり、積分して結論を得る。
:::

速度を積分するとき、区間の取り方を明示する。曲線が往復すれば往路と復路の長さをともに足す。像の集合だけを見て長さを数えると、こうした重複を失う。

:::example[円を二周する表示]
$\gamma(t)=2(\cos 3t,\sin 3t)$、$0\le t\le4\pi/3$ では速さは $6$ であり、長さは $8\pi$ である。$s=6t$ と置けば $\alpha(s)=2(\cos(s/2),\sin(s/2))$、$0\le s\le8\pi$ である。終点までの間に $s=4\pi$ で一度始点に戻る。
:::

:::example[放物線の弧長]
$\gamma(t)=(t,t^2)$ の速さは $\sqrt{1+4t^2}$ である。$x=2t$ と置いて積分すると、原点から測った弧長は

$$
s(t)=\frac{2t\sqrt{1+4t^2}+\operatorname{arsinh}(2t)}{4}
$$

である。右辺を微分すれば元の速さが得られる。弧長の逆関数を初等関数で書けなくても、連鎖律で $\dv{}{s}=(1+4t^2)^{-1/2}\dv{}{t}$ と計算できる。
:::

:::example[極座標の速さ]
$e_r=(\cos t,\sin t)$、$e_\theta=Je_r$、$J(x,y)=(-y,x)$ とすると、$\gamma(t)=r(t)e_r(t)$ の速度は $r'e_r+re_\theta$ であり、速さは $\sqrt{r'^2+r^2}$ である。$r(t)=e^{2t}$ なら $t=0$ から $t=\log 2$ までの長さは $\sqrt5(4-1)/2$ である。
:::

### 長さを折れ線の極限として確かめる

曲線の長さを速度の積分で定義すると、折れ線で測った値との関係も知りたくなる。$C^1$ 曲線 $\gamma:[a,b]\to\R^2$ では、両者の一致は導関数の一様連続性から従う。

:::proposition[折れ線長と弧長]{#prop-cs-polygonal-length}
分割 $P=(a=t_0<\cdots<t_n=b)$ について $L_P=\sum_i\norm{\gamma(t_{i+1})-\gamma(t_i)}$ とする。$\max_i(t_{i+1}-t_i)\to0$ なら $L_P\to\int_a^b\norm{\gamma'}\,\dd t$ である。またすべての分割についての $L_P$ の上限もこの積分値である。
:::

:::proof
各弦は速度ベクトルの積分なので、三角不等式により長さはその区間での速度の大きさの積分以下である。一方、導関数の連続性の尺度を $\omega(\delta)=\sup_{|u-v|\le\delta}\norm{\gamma'(u)-\gamma'(v)}$ と置く。区間の幅 $\Delta_i=t_{i+1}-t_i$、分割幅 $\delta=\max_i\Delta_i$ に対し

$$
\norm{\gamma(t_{i+1})-\gamma(t_i)-\Delta_i\gamma'(t_i)}
\le \Delta_i\omega(\delta).
$$

従って $L_P$ と速さの左端 Riemann 和の差の絶対値は $(b-a)\omega(\delta)$ 以下である。和は積分へ、誤差は零へ収束する。すべての折れ線長が積分以下であり、その値に近づく分割もあるから、上限も一致する。
:::

:::example[円の四分の一を弦で測る]
半径 $2$ の円弧 $(2\cos t,2\sin t)$、$0\le t\le\pi/2$ を角度で $n$ 等分する。一本の弦の長さは $4\sin(\pi/(4n))$ なので総和は $4n\sin(\pi/(4n))$ である。$n=1$ では $2\sqrt2$、$n=2$ では $8\sin(\pi/8)=4\sqrt{2-\sqrt2}$ となる。極限は $\pi$ であり、速さ $2$ を積分した長さに一致する。各弦を同じ角度幅に取れたのは元のパラメータが等速だからである。速さの変わる曲線でも、等分パラメータで得た折れ線は上の命題により正しい長さへ収束する。
:::


:::example[止まるパラメータと像の正則性を区別する]
$\gamma(t)=(t^3,t^6)$ は $t=0$ で速度が零になるが、像は放物線 $y=x^2$ である。$u=t^3$ と置けば同じ像を $(u,u^2)$ と正則に表示できる。ただし $t=u^{1/3}$ は原点で微分可能ではないため、この二表示は原点を含む区間で滑らかな正則再パラメータ表示の関係にない。例えば $t>0$ では変換の微分が非零となり、その範囲では両者の弧長や曲率を正則再パラメータ表示として比較できる。点集合が滑らかに見えることと、一つの表示の速度が全点で非零であることを別々に調べる。
:::

## 符号付き曲率と Frenet 標構

同じ長さだけ進んだとき、円の半径が小さいほど進行方向は大きく変わる。一方、接線が左に回るか右に回るかは平面の向きを使わなければ区別できない。

:::definition[接線、法線、符号付き曲率]{#def-cs-signed-curvature}
単位速さ表示 $\alpha(s)$ に対して $T=\alpha'$、$N=JT$ と置く。組 $(T,N)$ を平面の :term[Frenet 標構]{en="Frenet frame" yomi="ふれねひょうこう"} という。$T'$ の $N$ 成分 $\kappa=\inner{T'}{N}$ を :term[符号付き曲率]{en="signed curvature" yomi="ふごうつききょくりつ"} という。ここで $N$ は進行方向の左を向く。
:::

:::proposition[平面の Frenet 公式と計算式]{#prop-cs-plane-frenet}
弧長微分について $T'=\kappa N$、$N'=-\kappa T$ である。任意の正則パラメータ $t$ では

$$
\kappa=\frac{\det(\gamma',\gamma'')}{\norm{\gamma'}^3}.
\label{eq-cs-plane-curvature}
$$

:::

:::proof
$\inner TT=1$ を微分すると $\inner{T'}T=0$ だから $T'=\kappa N$ である。これに $J$ を作用させれば $J^2=-\id$ により法線の式を得る。速さを $v$ と置けば $\gamma'=vT$、$\gamma''=v'T+v^2\kappa N$ である。$\det(T,N)=1$ と行列式の交代性から $\det(\gamma',\gamma'')=v^3\kappa$ となる。
:::

平面の標構は $\kappa=0$ でも定義される。これは法線を加速度の正規化で取らず、$JT$ としたためである。進行方向を反転すると $T,N$ は両方反転し、曲率の符号は変わる。鏡映でも行列式の符号が反転する。長さを $c>0$ 倍すると分子は $c^2$ 倍、分母は $c^3$ 倍なので、曲率は $1/c$ 倍である。

:::proposition[接触円]{#prop-cs-osculating-circle}
$\kappa(s_0)\ne0$ のとき、中心 $\alpha(s_0)+N(s_0)/\kappa(s_0)$、半径 $1/|\kappa(s_0)|$ の円が、同じ進行方向で $\alpha$ と位置、単位接線、弧長二階微分を共有する唯一の円である。この円を :term[接触円]{en="osculating circle" yomi="せっしょくえん"} という。
:::

:::proof
円の中心への向きは単位速さの加速度の向きであり、その大きさは半径の逆数である。実際、半径 $R$ の円を $(R\cos(s/R),R\sin(s/R))$ と書いて二回微分すると、加速度は中心へのベクトルの $R^{-2}$ 倍になる。共有すべき加速度は $\kappa(s_0)N(s_0)$ だから半径と中心が一意に定まる。指定の進行方向でその円をたどれば三つの条件を満たす。
:::

:::example[グラフと変曲点]
$\gamma(x)=(x,f(x))$ なら :eqref[eq-cs-plane-curvature] から $\kappa=f''/(1+f'^2)^{3/2}$ である。$f(x)=x^3$ では $\kappa=6x/(1+9x^4)^{3/2}$ で、原点を通ると曲がる向きが変わる。対して $f(x)=x^4$ も原点の曲率は零だが、両側で $f''>0$ なので曲がる向きは同じである。
:::

:::example[楕円の軸端]
$a>b>0$ として $(a\cos t,b\sin t)$ の行列式の分子は $ab$、速さの二乗は $a^2\sin^2t+b^2\cos^2t$ である。したがって $(a,b)=(3,2)$ の場合、$(3,0)$ で $\kappa=3/4$、$(0,2)$ で $\kappa=2/9$ となる。前者の接触円の中心は $(5/3,0)$ である。
:::

### 極座標における曲率と正則性

中心からの距離と角で曲線が与えられる場合、直交座標へ戻して二回微分しなくても曲率を求められる。極座標の基底自体が回転することを微分に入れる必要がある。

:::proposition[極座標の曲率公式]{#prop-cs-polar-curvature}
$\gamma(\phi)=r(\phi)e_r(\phi)$ とし、$e_\theta=Je_r$ とする。$r^2+(r')^2>0$ の点で

$$
\kappa=\frac{r^2+2(r')^2-r r''}{\big(r^2+(r')^2\big)^{3/2}}
\label{eq-cs-polar-curvature}
$$

が成り立つ。ここで微分記号は $\phi$ 微分である。
:::

:::proof
$e_r'=e_\theta$、$e_\theta'=-e_r$ から $\gamma'=r'e_r+re_\theta$、$\gamma''=(r''-r)e_r+2r'e_\theta$。基底が正向き正規直交なので、速度の二乗は $(r')^2+r^2$、行列式は $2(r')^2-r(r''-r)$ となる。:eqref[eq-cs-plane-curvature] へ代入して結論を得る。
:::

この式では、ある点で $r=0$ でも $r'\ne0$ なら正則である。例えば $\phi=0$ で $r=0,r'=1$ なら位置は原点にあるが接線は $e_r(0)$ である。曲線の位置を表すための極座標が原点では一意でないことと、パラメータ付き曲線がそこで正則であることは別の性質である。

:::example[Archimedes の螺旋]
$r=\phi$ と置くと $\kappa=(\phi^2+2)/(1+\phi^2)^{3/2}$ であり、原点で $\kappa=2$ となる。$\phi>0$ で微分すると

$$
\kappa'=-\frac{\phi(\phi^2+4)}{(1+\phi^2)^{5/2}}<0
$$

なので、正の角度の区間では曲率は減少する。この単調性が接触円の配置に及ぼす効果は :ref[thm-cs-tait-kneser] で示す。原点でも速度は $(1,0)$ なので尖点はない。大きな角では $\kappa\sim1/\phi$ であり、半径に反比例する円の曲率と漸近的に一致する。
:::

:::example[対数螺旋と尺度]
$r=e^{2\phi}$ なら $\kappa=e^{-2\phi}/\sqrt5$ である。$\phi$ を $\pi$ 増やすと位置は半回転し、長さが $e^{2\pi}$ 倍に拡大される。従って曲率は $e^{-2\pi}$ 倍になる。この変化は曲率公式の値と一致する。速度を基底 $(e_r,e_\theta)$ で見ると $e^{2\phi}(2,1)$ であり、進行方向と半径方向のなす角は常に $\arctan(1/2)$ である。
:::

:::example[極座標の表示で生じる尖点]
$r=1+\cos\phi$ とすると、$\phi=\pi$ で $r=r'=0$ なので正則性を失う。$t=\phi-\pi$ に対し $r=t^2/2+\order{t^4}$、$\cos\phi=-1+\order{t^2}$、$\sin\phi=-t+\order{t^3}$。従って位置は $(-t^2/2+\order{t^4},-t^3/2+\order{t^5})$ である。横方向は原点の両側のパラメータで同じ向きに伸び、縦方向の符号は反転する。この位置の組から尖点の二枝を区別できる。
:::

### 接触円の中心を結ぶ曲線

曲率半径が定義できる区間では、曲線の点の代わりに接触円の中心を追うことができる。この中心の軌跡には、曲率の大きさそのものよりも曲率半径の変化が直接現れる。

:::definition[縮閉線と伸開線]{#def-cs-evolute}
$\kappa\ne0$ の曲線 $\alpha$ に対し、接触円の中心の軌跡 $C(s)=\alpha(s)+\rho(s)N(s)$ を :term[縮閉線]{en="evolute" yomi="しゅくへいせん"} という。ここで $\rho=1/\kappa$ は符号付き曲率半径である。逆に、単位速さの正則曲線 $C(t)$ とその単位接線 $U=C'$ に対し、$\beta(t)=C(t)+(c-t)U(t)$ を :term[伸開線]{en="involute" yomi="しんかいせん"} という。定数 $c$ は初めに伸ばした糸の長さを決める。
:::

:::proposition[縮閉線の速度と伸開線の逆関係]{#prop-cs-evolute-involute}
縮閉線は $C'=\rho'N$ を満たす。$\rho'\ne0$ の区間では縮閉線の接線は元の曲線の法線に平行であり、その曲率の絶対値は $|\kappa|/|\rho'|$ である。単位速さ曲線 $C$ の曲率が非零で $t\ne c$ なら、伸開線 $\beta$ は正則であり、その縮閉線は $C$ に一致する。
:::

:::proof
$C'=\alpha'+\rho'N+\rho N'$ に $N'=-\kappa T$ を入れると接線成分が消える。$C$ の弧長微分は $|\rho'|^{-1}\dv{}{s}$、その単位接線は $\sgn(\rho')N$ なので、接線の弧長微分のノルムは $|\kappa|/|\rho'|$ になる。

次に $C$ の符号付き曲率を $k$、左法線を $JU$ とすると $\beta'=(c-t)kJU$ である。仮定によりこれは非零である。$\eta=\sgn((c-t)k)$ と書くと $\beta$ の単位接線は $\eta JU$、左法線は $-\eta U$ となる。接線の $t$ 微分は $-\eta k U$ なので、$\beta$ の曲率は $k/(|c-t|\,|k|)$ である。よって接触円の中心は

$$
\beta+\frac{|c-t|\,|k|}{k}(-\eta U)=\beta-(c-t)U=C
$$

になる。
:::

:::example[放物線の縮閉線]
$\gamma(t)=(t,t^2)$ について $N=(-2t,1)/\sqrt{1+4t^2}$、$\kappa=2/(1+4t^2)^{3/2}$ である。従って中心は

$$
C(t)=(t,t^2)+\tfrac12(1+4t^2)(-2t,1)=(-4t^3,\tfrac12+3t^2).
$$

$t=0$ で $C'$ が消える。平行移動で縦座標を $C_2-1/2$ と置くと、その三乗と横座標の二乗が比例するため、ここで尖点を持つことが分かる。
:::

:::example[円の伸開線]
半径 $2$ の円 $C(t)=2(\cos(t/2),\sin(t/2))$ と $c=0$ を使う。伸開線は

$$
\beta(t)=(2\cos(t/2)+t\sin(t/2),\,2\sin(t/2)-t\cos(t/2))
$$

である。$t>0$ のとき $\norm{\beta'}=t/2$ なので、区間 $[1,3]$ の長さは $\int_1^3t/2\,\dd t=2$ である。円上の糸の接点とその先端との距離は $t$ であり、糸をほどくにつれて長くなる。
:::

:::theorem[接触円の入れ子]{#thm-cs-tait-kneser}
符号付き曲率が非零で厳密に単調な平面曲線の区間では、異なる二点の接触円は交わらず、一方がもう一方の内部にある。
:::

:::proof
進行方向を変えても接触円は変わらないので $\kappa>0$ としてよい。$s_1<s_2$ で二中心の距離について

$$
\norm{C(s_2)-C(s_1)}\le\int_{s_1}^{s_2}|\rho'|\,\dd s
=|\rho(s_2)-\rho(s_1)|
$$

を得る。最後は $\rho$ が単調なためである。等号なら、差ベクトルの単位方向との内積で積分を評価して、$|\rho'|$ が非零の範囲で $C'/|C'|$ が一定でなければならない。厳密な単調性によりどの区間にも $\rho'\ne0$ の点があり、その近くで $C'/|C'|=\pm N$ は $N'=-\kappa T\ne0$ により変化する。よって不等式は厳密である。二中心間距離が半径の差より小さいので、小さい方の円を含む閉円板は大きい方の開円板内にある。
:::

### 速度と曲率の単位を分ける

接線角の時間微分は、速さが一定でなくても計算できる。$\Theta(t)$ を速度の偏角とし、$V(t)=\norm{\gamma'(t)}$ とすると $\Theta'(t)=V(t)\kappa(t)$ である。$\gamma'=V(\cos\Theta,\sin\Theta)$ を微分し、行列式の二本目に現れる $V'$ の項が第一列と平行で消えることでも確かめられる。従って角の回転を距離で測るには、時刻で測った回転率を速さで割る。

:::example[同じ接線を持つ放物線と三次曲線]
$\gamma_1(t)=(t,3t^2)$、$\gamma_2(t)=(t,3t^3)$ はともに原点で右向き水平の接線を持つ。速度を一階、二階と微分すると曲率はそれぞれ

$$
\kappa_1(t)=\frac{6}{(1+36t^2)^{3/2}},\qquad
\kappa_2(t)=\frac{18t}{(1+81t^4)^{3/2}}.
$$

一つ目は原点で左向きに曲がり、中心 $(0,1/6)$ の接触円を持つ。二つ目は原点で曲率が消え、左右で符号を変える。従って原点の法線は決められるが、有限半径の接触円は存在しない。
:::

## 曲率による平面曲線の決定

弧長で測る曲率は接線の角速度である。そこで角度を積分して接線を求め、接線をもう一度積分して位置を求める。ここで角度を $2\pi$ ごとに切り詰めると微分できなくなるため、実数値の連続な角度を選ぶ。

:::lemma[接線角の持ち上げ]{#lem-cs-tangent-angle}
弧長表示された正則平面曲線の区間上で、$T=(\cos\theta,\sin\theta)$ となる滑らかな実数値関数 $\theta$ が存在し、$\theta'=\kappa$ である。二つの選び方は $2\pi$ の整数倍だけ異なる。
:::

:::proof
初期接線を与える角 $\theta_0$ を選び、$\theta(s)=\theta_0+\int_{s_0}^s\kappa(r)\,\dd r$ と置く。この角で定めた単位ベクトル $U$ は $U'=\kappa JU$ を満たす。同じ方程式を $T$ も満たすので、差 $D=T-U$ について $(\norm D^2)'=2\kappa\inner{D}{JD}=0$ である。初期値が零だから $U=T$ となる。任意の二つの角の差は連続で値が $2\pi\Z$ に属するため一定である。
:::

:::theorem[平面曲線の基本定理]{#thm-cs-plane-fundamental}
区間 $I$ 上の滑らかな実数値関数 $k$ は、ある単位速さの正則平面曲線の符号付き曲率になる。その曲線は初期位置と初期単位接線を指定すると一意であり、指定しなければ向きを保つ Euclid 合同の違いしかない。
:::

:::proof
$\theta(s)=\theta_0+\int_{s_0}^s k(r)\,\dd r$ とし、

$$
\alpha(s)=p_0+\int_{s_0}^s(\cos\theta(r),\sin\theta(r))\,\dd r
\label{eq-cs-plane-reconstruction}
$$

と定める。微分すれば速さは $1$ であり、さらに微分すれば $\alpha''=kJ\alpha'$ となる。一意性は :ref[lem-cs-tangent-angle] と位置の積分から従う。初期位置と接線の二組は、接線を合わせる回転の後で平行移動すれば一致する。これらの操作は $k$ を保つ。
:::

:::example[定曲率と曲率が零の点]
初期接線が $(1,0)$、初期位置が原点、$k=2$ なら $\alpha(s)=(\sin(2s)/2,(1-\cos(2s))/2)$ である。$k=0$ なら $\alpha(s)=(s,0)$ となる。$k(s)=2s$ なら $\theta=s^2$ であり、成分を原点で展開すると $\alpha(s)=(s-s^5/10+\order{s^9},s^3/3+\order{s^7})$ となる。
:::

:::proposition[滑らかに閉じる条件]{#prop-cs-plane-closure}
$k$ が周期 $L>0$ を持つとする。:eqref[eq-cs-plane-reconstruction] で作る曲線が周期 $L$ を持つ必要十分条件は

$$
\int_0^L k(s)\,\dd s\in2\pi\Z,\qquad
\int_0^L(\cos\theta(s),\sin\theta(s))\,\dd s=0
\label{eq-cs-plane-closure}
$$

である。
:::

:::proof
曲線が周期的なら接線も周期的であり、第一条件は角の増分、第二条件は位置の増分から得られる。逆に第一条件と $k$ の周期性から $T(s+L)=T(s)$ である。したがって積分 $\int_s^{s+L}T(r)\,\dd r$ は $s$ によらず一定で、第二条件により零となる。
:::

:::example[接線が戻っても位置は戻らない]
$L=2\pi$、$\theta(s)=\eps\sin s$、$0<\eps<1$ とする。$k=\eps\cos s$ の全積分は零だが、$\cos(\eps\sin s)>0$ なので位置の第一成分は増加する。一方、$k=1$ なら水平・鉛直成分の各積分は零で、単位円が閉じる。
:::

### 周期の曲率から弧をつなぐ

:::proposition[周期的な弧の変位と回転]{#prop-cs-plane-periodic-segments}
弧長曲率 $k(s)$ が周期 $p>0$ を持つとする。$\varphi=\int_0^p k(s)\,\dd s$ とし、$R_\varphi$ を角 $\varphi$ の回転と置く。$n$ 個の弧を進んだときの変位は

$$
\alpha(np)-\alpha(0)
=\sum_{j=0}^{n-1}R_\varphi^j(\alpha(p)-\alpha(0)).
$$

特に $R_\varphi\ne I$ かつ $R_\varphi^n=I$ なら、曲線は長さ $np$ で閉じる。
:::

:::proof
曲率の積分から $T(s+p)=R_\varphi T(s)$ を得る。区間 $[jp,(j+1)p]$ で変位を積分すると、最初の弧の変位を $j\varphi$ 回転させたものになる。和に $I-R_\varphi$ を掛けると $I-R_\varphi^n=0$ になる。$\varphi$ が $2\pi$ の整数倍でなければ $I-R_\varphi$ は可逆なので、変位は零である。また接線は $np$ 後に一致し、曲率の周期性により滑らかに接続する。
:::

:::example[三つの合同な弧で閉じる曲線]
$k(s)=1+\frac14\cos3s$、$p=2\pi/3$ とする。$\int_0^p\cos3s\,\dd s=0$ だから $\varphi=2\pi/3$ である。三回の回転の和は零となり、弧長 $2\pi$ で閉じる。さらに $k>0$ で接線角は一周に $2\pi$ 増加する。任意の接点からの法線方向の高さは最初の半回転で厳密に増え、後半で厳密に減って始点の高さへ戻る。従って各接点と同じ点へ途中で戻ることはなく、得られた曲線は単純である。
:::

## 回転数と Hopf の接線回転定理

閉曲線の接線は最後に最初の方向へ戻るが、途中で何周したかは曲線によって異なる。単純性を仮定すると、何周できるかが制約される。

:::definition[回転数]{#def-cs-rotation-number}
円周を定義域とする正則平面曲線を閉曲線といい、それが単射なら単純閉曲線という。閉曲線の長さを $L$ とすると、弧長表示の定義域は $\R/L\Z$ である。単位接線の角の全増分を $2\pi$ で割った整数

$$
m=\frac{\theta(L)-\theta(0)}{2\pi}=\frac{1}{2\pi}\int_0^L\kappa\,\dd s
$$

を :term[回転数]{en="rotation number" yomi="かいてんすう"} という。
:::

:::lemma[方向の境界角]{#lem-cs-angle-winding}
三角形上の連続写像 $F$ が単位円に値を取るとき、境界を一周する間の角の増分は零である。
:::

:::proof
円上で一点の近くにとどまる経路には、その点の角の近くの一意な角を連続的に選べる。任意の連続経路では一様連続性によってこのような短い区間に有限分割でき、区間のつなぎ目で $2\pi$ の整数倍を調整すれば角をつなげられる。閉経路の角の増分は $2\pi\Z$ に属する。閉経路を連続変形するときにも、変形パラメータの十分近い値では経路の各点が円上で一様に近い。各対応点の角の差を $(-\pi,\pi)$ から連続に選べるので、閉経路の増分は変わらない。三角形では境界経路を一点に線形収縮できるため、増分は定値経路の増分と等しい。
:::

:::theorem[Hopf の接線回転定理]{#thm-cs-hopf-turning}
正則単純閉平面曲線の回転数は $1$ または $-1$ である。有界領域を左に見て進む向きでは $1$ となる。
:::

:::proof
単位速さ表示 $\alpha(s)$ の始点を高さが最小の点に取る。平面を平行移動して $\alpha(0)=0$ と置く。有界領域を左に見る向きでは、他の点が上半平面にあるため $T(0)=(1,0)$ である。実際、局所的に境界をグラフに書け、その下側は支持直線より下の点へ境界を横切らずに達する外部である。したがって内部は局所的に上側にある。ここで平面の単純閉曲線が内部と外部を分ける事実は Jordan 曲線定理を用いる。この位相的な結果の証明は :cite[munkres-topology] に譲る。

$0\le s\le t\le L$ の閉三角形を考え、$s<t$ かつ $(s,t)\ne(0,L)$ で

$$
F(s,t)=\frac{\alpha(t)-\alpha(s)}{\norm{\alpha(t)-\alpha(s)}}
$$

と置く。単射性により分母は零でない。対角線では $F(s,s)=T(s)$ として連続に延長できる。残る頂点では、周期性と微分可能性により $\alpha(t)-\alpha(s)=-(L-t+s)T(0)+o(L-t+s)$ だから $F(0,L)=-T(0)$ として連続である。

辺 $(0,0)\to(0,L)$ では方向が上半円にあり、増分は $+\pi$ である。次の辺 $(0,L)\to(L,L)$ は $F(s,L)=-F(0,s)$ だから、増分は同じく $+\pi$ である。最後の辺 $(L,L)\to(0,0)$ では $T$ を逆順にたどるため、増分は $-2\pi m$ である。:ref[lem-cs-angle-winding] から三つの和が零なので $m=1$。逆向きでは曲率積分が反転し $m=-1$ となる。
:::

:::example[単純性を外した場合]
$\gamma(t)=(\cos 3t,\sin 3t)$、$0\le t\le2\pi$ では角を $\theta=3t+\pi/2$ と選べるため回転数は $3$ である。別の例 $\gamma(t)=(\sin t,\sin2t)$ は速度が同時に零とならないが、$t=0,\pi$ で原点を通る。$\gamma(t+\pi)$ は $\gamma(t)$ の鉛直軸に関する鏡映なので、前半と後半の曲率積分が打ち消し合い、回転数は零である。
:::

閉曲線を $C^1$ 位相で連続に変形し、途中で常に正則性を保てば、単位接線も円上で連続変形される。よって :ref[lem-cs-angle-winding] の証明から回転数は保存される。変形の途中で位置の自己交差を許しても、この証明は成り立つ。

### 点のまわりの巻き数と接線の回転数

接線の回転数は、曲線上の点で進行方向がどれだけ回るかを表す。別の量として、平面の固定点から各位置を見る方向がどれだけ回るかも数えられる。固定点を変えるとこちらの値は変わり得る。

:::definition[点のまわりの巻き数]{#def-cs-point-winding}
閉曲線 $\gamma$ の像にない点 $p$ に対し、$(\gamma(t)-p)/\norm{\gamma(t)-p}$ の連続な角の増分を $2\pi$ で割った整数を、$p$ のまわりの :term[巻き数]{en="winding number" yomi="まきすう"} と呼ぶ。
:::

:::proposition[巻き数の積分表示]{#prop-cs-point-winding}
$p=(a,b)$、$\gamma(t)=(x(t),y(t))$ に対して、巻き数は

$$
\frac1{2\pi}\int
\frac{(x-a)y'-(y-b)x'}{(x-a)^2+(y-b)^2}\,\dd t
\label{eq-cs-point-winding}
$$

である。曲線を固定したとき、巻き数は像の補集合の各連結成分で一定である。
:::

:::proof
$\gamma-p=r(\cos\theta,\sin\theta)$ と書いて微分し、$\gamma-p$ とその微分で作った行列式を取る。$r'$ の項が消え、分子は $r^2\theta'$ になる。従って積分は角の増分を表す。点 $p$ を像の外で連続に動かせば単位方向も連続に変形される。:ref[lem-cs-angle-winding] の証明で用いた不変性から、各点の十分小さな近傍で巻き数は一定である。連結成分上で局所定数関数は一定になる。
:::

:::example[楕円と二つの基準点]
$\gamma(t)=(3\cos t,2\sin t)$ の原点のまわりの巻き数は $1$ である。正の伸縮で楕円を単位円へ変形する間、原点を一度も通らないので、単位円の角の増分と同じになる。対して $p=(4,0)$ から見た曲線はすべて左半平面にあり、角を一つの長さ $\pi$ の区間内で選べる。端から端までの角の増分は零なので巻き数は零である。接線の回転数は基準点の選択とは無関係に $1$ である。
:::

:::proposition[単純閉曲線の内外と巻き数]{#prop-cs-jordan-index}
区分的に滑らかな単純閉曲線が有界領域を左に見て進むとき、内点のまわりの巻き数は $1$、外点のまわりの巻き数は $0$ である。ここで境界には正則な小弧が一つあると仮定する。
:::

:::proof
十分遠くの点から見た曲線の方向は開半円内に収まるので巻き数は零である。Jordan 曲線定理と :ref[prop-cs-point-winding] により、非有界成分の全点で零となる。

次に正則な小弧の内点を原点に取り、接線を右向き水平にする。小弧は $y=f(x)$ と書ける。残りの弧は原点から正の距離にある。原点の真上と真下の点 $p_\pm=(0,\pm\eps)$ の巻き数を比べるため、小弧の中で $f$ に滑らかな切断関数を掛け、原点近くを水平な線分に置き換える。これを連続に行っても $x=0$ の位置は原点のままで、$p_\pm$ を通らない。従って巻き数は変わらない。

水平な線分 $-a\le x\le a$ に沿う角度の増分は、$p_+$ に対して $\int_{-a}^a\eps/(x^2+\eps^2)\,\dd x=2\arctan(a/\eps)$、$p_-$ に対してその負である。差は $\eps\downarrow0$ で $2\pi$ に近づく。残りの弧は原点から離れているため、そこでの二つの増分の差は零に近づく。巻き数の差は整数で、その極限が $1$ だから、十分小さい $\eps$ では差が $1$ である。局所グラフの左側は内側なので $p_+$ が内点であり、連結性から内点すべてで巻き数は $1$ となる。
:::

:::example[同じ円周を逆向きに見る]
半径 $2$ の円を時計回りに二周する $\gamma(t)=(2\cos(2t),-2\sin(2t))$、$0\le t\le2\pi$ を考える。原点で :eqref[eq-cs-point-winding] の分子は $-8$、分母は $4$ なので巻き数は $-2$。一方 $p=(0,3)$ では曲線が点 $p$ より常に下側にあるため巻き数は零である。この例でも接線の角は $-2t-\pi/2$ と取れるから、その回転数は $-2$ である。
:::

### 向きの反転と曲線の重ね合わせ

:::example[同じ点を反対向きにたどる]
$\alpha(t)=(2\cos t,-2\sin t)$ を $0\le t\le2\pi$ でたどる。単位接線は $(-\sin t,-\cos t)$ であり、その実数値の角は $-t-\pi/2$ と選べる。従って回転数は $-1$ である。符号付き曲率は $-1/2$、長さは $4\pi$ なので、積分からも $-2\pi$ を得る。また曲線を $t\in[0,4\pi]$ でたどると、同じ像でも回転数は $-2$ になる。弧長積分は各通過を別々に数えるためである。
:::

:::example[基点の巻き数が定義できない場合]
$\alpha(t)=(2\cos t,2\sin t)$ の接線は一周するので回転数は $1$ である。一方、点 $q=(2,0)$ のまわりの巻き数では $t=0$ で $\alpha(t)-q=0$ となり、方向を定義できない。$q=(1,0)$ なら $q$ を原点へ連続的に移しても曲線を横切らないので巻き数は $1$ である。$q=(3,0)$ なら $\alpha(t)-q$ の第一成分が常に負であり、偏角を幅 $\pi$ の区間で選べるので巻き数は $0$ である。このように接線の回転数と点の巻き数は入力が異なる。
:::

## 凸曲線と四頂点定理

有界な凸領域を一周するとき、境界を左に見るなら接線は右へは曲がらない。さらに正曲率の場合、法線の角を変数に選んで曲率半径を周期関数として比較できる。

:::definition[凸曲線と頂点]{#def-cs-oval}
内部を持つコンパクトな凸集合の境界をなす正則単純閉曲線を :term[凸曲線]{en="convex curve" yomi="とつきょくせん"} という。凸とは集合内のどの二点を結ぶ線分も集合に含まれることである。滑らかな曲線で $\dv{\kappa}{s}=0$ となる点を :term[頂点]{en="vertex" yomi="ちょうてん"} という。
:::

:::proposition[凸性の曲率による判定]{#prop-cs-convexity}
正向きの正則単純閉曲線が凸であるための必要十分条件は、$\kappa\ge0$ が全点で成り立つことである。
:::

:::proof
凸の場合、各点の接線は支持線になる。これを見るには接点を原点、接線を水平に取り、境界を局所グラフに書く。局所内部が上側なら、内部の点から原点への線分がすべて領域に属することとグラフの一次項が零であることから、内部の点の高さは非負である。したがって境界の高さは接点で極小となり、その二階微分 $\kappa$ は非負である。

逆に $\kappa\ge0$ とする。:ref[thm-cs-hopf-turning] から $\theta$ は非減少で増分が $2\pi$ である。任意の接点を $s=0$、接線角を零とすると、符号付き高さの微分は $\sin\theta(s)$ で、最初は非負、後半は非正になる。始点と終点の高さが零なので曲線全体が接線の左閉半平面に入る。囲まれた閉領域 $D$ も同じ半平面に入る。線形な高さ関数が $D$ で負なら最小値が内部にしか現れないが、線形関数は内部で極小にならないためである。

全接線の左半平面の共通部分を $C$ とする。$D$ の外の点 $q$ が $C$ に入ると仮定し、$q$ に最も近い $D$ の点 $p$ を取る。$p$ は境界にあり、距離の二乗を境界に沿って微分すると $q-p$ は法線方向となる。$q-p$ が左向きなら、$p$ から少し左に進んだ内点は $q$ により近い。ゆえに $q$ は接線の右にあり $C$ から外れる。従って $D=C$ は凸である。
:::

:::lemma[曲率半径と支持関数]{#lem-cs-support-radius}
正向きの凸曲線で $\kappa>0$ とする。外向き単位法線を $n(\phi)=(\cos\phi,\sin\phi)$、支持関数を $h(\phi)=\inner{\gamma(\phi)}{n(\phi)}$ と置く。$t(\phi)=Jn(\phi)$ とすると

$$
\gamma=h n+h't,\qquad
\dv{\gamma}{\phi}=(h+h'')t,\qquad
\rho\defeq\frac{1}{\kappa}=h+h''.
\label{eq-cs-support-radius}
$$

:::

:::proof
$\phi$ は接線角から $\pi/2$ を引いた角であり、$\dv{\phi}{s}=\kappa$ なので一周を微分同相にパラメータ表示する。$\gamma'$ は $t$ 方向で $n'=t$ だから $h'=\inner{\gamma}{t}$ である。従って $\gamma=h n+h't$。$t'=-n$ を用いて微分し、$\dv{s}{\phi}=1/\kappa$ と比較する。
:::

逆に、$2\pi$ 周期の $h$ について $h+h''>0$ なら :eqref[eq-cs-support-radius] の右辺から凸曲線を作れる。実際、任意の $\phi_0$ について外向き法線方向への座標の微分は $-(h+h'')\sin(\phi-\phi_0)$ である。座標は半周減少し、残りの半周で増加して戻る。このため $\phi_0$ でのみその方向の最大値を取る。これが単射性を与え、その上で :ref[prop-cs-convexity] を適用できる。原点を平行移動すると $h$ は一次の三角関数を加減したものになるが、$h+h''$ は変わらない。

:::proposition[法線角による曲率半径の指定]{#prop-cs-radius-closure}
正の滑らかな $2\pi$ 周期関数 $\rho(\phi)$ が、ある正向きの凸閉曲線の法線角に関する曲率半径となるための必要十分条件は

$$
\int_0^{2\pi}\rho(\phi)\cos\phi\,\dd\phi
=\int_0^{2\pi}\rho(\phi)\sin\phi\,\dd\phi=0
$$

である。法線角の原点を固定すれば、曲線は平行移動の自由度を除いて一意である。
:::

:::proof
必要性は一周の変位 $\int_0^{2\pi}\rho\,t\,\dd\phi$ が零であることから従う。逆にこの二条件が成り立つなら

$$
\gamma(\phi)=p+\int_0^\phi\rho(\xi)(-\sin\xi,\cos\xi)\,\dd\xi
$$

は滑らかな閉曲線である。各点の接線は $t(\phi)$、弧長要素は $\rho\,\dd\phi$ なので、曲率は $1/\rho$ となる。任意の外向き法線方向 $n(\phi_0)$ への座標は $\phi_0$ の直後から半周は厳密に減少し、その次の半周で厳密に増加して戻る。従って $\phi_0$ はその方向の唯一の最大点であり、曲線は単射である。正の曲率と :ref[prop-cs-convexity] から凸性が従う。同じ $\rho$ を持つ二曲線は $\phi$ で微分した値が等しいため、差は定数ベクトルである。
:::

:::example[正の曲率半径でも閉じない場合]
$\rho=2+\cos\phi$ は全点で正だが、$\int_0^{2\pi}\rho\cos\phi\,\dd\phi=\pi$ である。この $\rho$ から一周分の弧を作ると、接線は元に戻る一方で位置の第二成分が $\pi$ 増える。$\rho=2+\cos2\phi$ に替えれば両積分は零であり、正曲率の閉曲線が得られる。その支持関数は $h=2-\tfrac13\cos2\phi$ と取れる。
:::

:::theorem[凸曲線の四頂点定理]{#thm-cs-four-vertex}
$\kappa>0$ の正則単純閉平面曲線は少なくとも四つの頂点を持つ。定曲率でなければ、曲率が局所的に最大となる点と局所的に最小となる点が交互に少なくとも二つずつある。
:::

:::proof
:ref[prop-cs-convexity] により凸である。外向き法線角に関する周期関数 $\rho$ を用いる。閉曲線の位置は一周で戻るので $\int_0^{2\pi}\rho\, t\,\dd\phi=0$。部分積分と周期性を使うと

$$
\int_0^{2\pi}\rho'\,\dd\phi
=\int_0^{2\pi}\rho'\cos\phi\,\dd\phi
=\int_0^{2\pi}\rho'\sin\phi\,\dd\phi=0
$$

を得る。$\rho$ が一定ならすべての点が頂点である。そうでなければ $\rho'$ は正負両方の値を取る。円周上で符号の正負が交互に現れる四点を選べないと仮定する。$\rho'>0$ の点から一周する角度区間を取り、その区間で $\rho'<0$ となる点の下限を $a$、上限を $b$ とする。もし $(a,b)$ に $\rho'>0$ の点があれば、その両側に $\rho'<0$ の点を一つずつ取って、初めに選んだ点と合わせて四点を得る。従って $(a,b)$ では $\rho'\le0$、補弧では $\rho'\ge0$ である。

その境界角を $a,b$（$a<b<a+2\pi$）とし、

$$
q(\phi)=\cos\!\left(\phi-\frac{a+b}{2}\right)-\cos\!\left(\frac{b-a}{2}\right)
$$

と置く。$q$ は弧 $(a,b)$ で正、補弧で負である。必要なら符号を変え、$\rho'$ と符号を合わせる。すると $\int\rho'q>0$ となるが、$q$ は $1,\cos\phi,\sin\phi$ の一次結合なので積分は零である。矛盾から正負が交互に現れる四点が存在する。各隣接点間で、端での導関数の符号を見れば $\rho$ の極大または極小が内部で達成される。$\kappa=1/\rho$ でも極大と極小を交換して同じ結論を得る。
:::

:::example[ちょうど四頂点をもつ支持関数]
$h=3+\frac13\cos2\phi$ なら $\rho=3-\cos2\phi$ である。$\rho>0$ なので凸閉曲線を与える。その導関数 $2\sin2\phi$ は $\phi=0,\pi/2,\pi,3\pi/2$ でのみ消え、曲率の最大値は $1/2$、最小値は $1/4$ である。
:::

:::example[楕円の四頂点]
:ref[prop-cs-plane-frenet] で計算した楕円の曲率は速さの減少関数である。$\dv{}{t}(a^2\sin^2t+b^2\cos^2t)=2(a^2-b^2)\sin t\cos t$ だから、円でない楕円では四つの軸端だけが頂点になる。
:::

### 正曲率を仮定しない四頂点定理

正曲率を使った証明では、接線角を曲線全体の変数に取った。曲率が負になる場合に同じ操作はできない。代わりに曲線を含む最小の円を取り、接点とその間の弧を比較する。以下は Osserman の外接円に着目する方法である。

:::lemma[最小包含円の接点]{#lem-cs-circumscribed-contacts}
平面のコンパクト集合 $E$ が少なくとも二点を持つとする。$E$ を含む最小半径の閉円板は一つだけであり、その外周との共通部分は開半円に収まらない。
:::

:::proof
中心 $c$ に対する半径の下限は $R(c)=\max_{x\in E}\norm{x-c}$ である。これは連続で、中心が無限遠へ行くと発散するから最小点がある。半径 $R$ の二円板が同じ $E$ を含むなら、その中心の中点 $m$ について

$$
\norm{x-m}^2
=\tfrac12\big(\norm{x-c_1}^2+\norm{x-c_2}^2\big)-\tfrac14\norm{c_1-c_2}^2
$$

である。中心が異なると半径を小さくできるので一意である。

接点が開半円に入ったと仮定し、その半円の中央方向を $e$ とする。接点で $\inner{x-c}{e}>0$ であり、コンパクト性から接点全体を含む近傍で一様な正の下界がある。中心を $\eps e$ だけ動かすと距離の二乗の差は $-2\eps\inner{x-c}{e}+\eps^2$ なので、この近傍では厳密に小さくなる。残りは元の円周から正の距離があるため、十分小さい $\eps$ ではやはり距離が $R$ 未満にとどまる。これは最小性に反する。
:::

:::theorem[単純閉曲線の四頂点定理]{#thm-cs-general-four-vertex}
滑らかな正則単純閉平面曲線には、符号付き曲率が局所的に極大または極小になる点が少なくとも四つある。曲率が一定となる区間では、その内部の点をいずれも局所的な極値として数える。
:::

:::proof
曲線を有界領域が左になる向きに取る。:ref[lem-cs-circumscribed-contacts] の最小円板の半径を $R$、円周を $C$ とする。曲線が $C$ と弧を共有すれば、その弧の内部の曲率は一定であり結論を得る。以後共有する弧はないとする。接点集合は閉で少なくとも二点を含むから、曲線上のその補集合には少なくとも二つの連結成分がある。各成分の閉包を $\gamma_1$ とすれば、それは円周にある相異なる端点 $P,Q$ を結び、内部は開円板にある。各接点では接線は円周と一致し、曲線の有界領域は円板内にあるため接線の向きも反時計回りの円周のものと同じである。接点で $\norm{\alpha-c}^2$ を弧長で二回微分して極大条件を使うと $2-2R\kappa\le0$、すなわち $\kappa\ge 1/R$ である。

$C$ 上の反時計回りの弧 $P\to Q$ の中心角を $\delta$ とする。この開弧に曲線との接点はない。これを確かめるため、$\gamma_1$ と二つの円周弧をそれぞれ合わせた二つの Jordan 曲線を考える。いずれも円周部分を反時計回りにたどる向きが正である。開円板で $\gamma_1$ を避ける点のまわりでは、$\gamma_1$ の寄与が逆向きに相殺され、二曲線の巻き数の和は円周の巻き数 $1$ に等しい。:ref[prop-cs-jordan-index] によれば各巻き数は $0$ または $1$ なので、二つの内部は互いに素で、開円板から $\gamma_1$ を除いた部分を覆う。各内部に対応する円周の開弧を加える。円周の開弧上では小近傍の円板内側が対応する内部に入るので、得られる二集合はどちらも円板から $\gamma_1$ を除いた空間で相対開である。

$P$ の近くで円周の反時計回り方向を横軸の正に取る。$P\to Q$ の円周弧と $\gamma_1$ はともに正の横座標へ進む局所グラフなので、その側の領域は $P$ の近くでは二つのグラフの間にある。対して曲線の残りの弧は $P$ から逆向きにたどれば負の横座標へ進む。単純性により途中で $\gamma_1$ に交わらないので、残りの弧は全体がもう一方の側にあり、$P\to Q$ の開弧に触れない。従って :ref[lem-cs-circumscribed-contacts] から $\delta\le\pi$ である。

$\gamma_1$ の後に $C$ の反時計回りの補弧 $Q\to P$ をたどると、接線まで連続な正向き単純閉曲線になる。:ref[thm-cs-hopf-turning] の割線による証明は接線が連続なら同じように適用できるため、接線角の全増分は $2\pi$。円周部分の増分は $2\pi-\delta$ なので $\gamma_1$ の増分は $\delta$ である。

いま $\gamma_1$ 上で $\kappa\ge1/R$ が全点で成立すると仮定する。接線角 $\theta$ は $\gamma_1$ の増加座標であり、$C$ の弧 $P\to Q$ と同じ範囲 $[\theta_0,\theta_0+\delta]$ をたどる。二つの弧の変位はどちらも $Q-P$ なので

$$
\int_{\theta_0}^{\theta_0+\delta}
   (R-1/\kappa)(\cos\theta,\sin\theta)\,\dd\theta=0.
$$

中間角の方向との内積を取ると、角区間の内部では $\cos(\theta-\theta_0-\delta/2)>0$ である。係数 $R-1/\kappa$ は非負なので、積分が零になるには係数が恒等的に零でなければならない。従って接線角を変数にした二つの弧は同じ速度を持ち、始点が同じだから一致する。これは $\gamma_1$ の内部が開円板にあることに反する。よって各成分に $\kappa<1/R$ の点がある。

異なる二成分で曲率の極小点を取る。どちらも端で $\kappa\ge1/R$ なので、極小点は成分の内部にある。この二極小点で曲線を二弧に分けると、各弧の途中で接点に出会う。そこでの値は両端の極小値より大きいので、各弧の内部で極大値が達成される。こうして四つの相異なる局所極値を得る。
:::

:::example[最小円と楕円の接点]
$(3\cos t,2\sin t)$ は半径 $3$ の円板に含まれる。二点 $(3,0),(-3,0)$ の間の距離が $6$ なので、より小さい円板には収まらない。接点の曲率は $3/4>1/3$、各接点間にある軸端の曲率は $2/9<1/3$ であり、一般の証明で使った二種類の点が直接見える。
:::

:::example[曲率半径と座標の周期が異なる例]
支持関数に第四調波を入れ、頂点の位置を外向き法線角から特定する。

外向き法線角を $t$ とする。まず支持関数の二階微分まで求め、曲率半径が全周で正となるかを調べる。そうすれば外向き法線角がそのまま一周のパラメータになる。

$$
\begin{aligned}
&h(t)=\frac{\cos{\left(4 t \right)} + 20}{5},\\
&h''(t)=- \frac{16 \cos{\left(4 t \right)}}{5},\\
&\rho(t)=4 - 3 \cos{\left(4 t \right)},\\
&\kappa(t)=1/\rho(t)
\end{aligned}
$$

点の位置は法線方向の成分 $h$ と接方向の成分 $h'$ で決まる。反対向きの二支持線の間隔は、原点から測った符号付きの二成分を足して得られる。

$$
\gamma(t)=h(t)(\cos t,\sin t)+h'(t)(-\sin t,\cos t),\qquad w(t)=\frac{2 \left(\cos{\left(4 t \right)} + 20\right)}{5}
$$

弧長の増分は $\rho\,\dd t$ なので周長は $\rho$ を積分して求める。面積にはもう一つ因子 $h$ が入り、周長が同じ曲線でも面積は変わり得る。

$$
\begin{aligned}
&L=\int_0^{2\pi}\rho\,\dd t=8 \pi,\\
&A=\frac12\int_0^{2\pi}h\rho\,\dd t=\frac{157 \pi}{10},\\
&L^2-4\pi A=\frac{6 \pi^{2}}{5}
\end{aligned}
$$

$\rho=4-3\cos4t$ は $t=j\pi/4$ で極値を取る。偶数の $j$ では $\rho=1$、奇数の $j$ では $\rho=7$ なので、曲率が最大一と最小 $1/7$ の八頂点を持つ。
:::

## 等周不等式

同じ長さの紐を閉じて囲む面積を比べると、円が最も広い。曲線の二つの座標を別々に比較すると等号の形が見にくくなる。そこで一方の座標に周期関数の不等式を適用し、面積積分で二つを結び付ける。

:::lemma[Wirtinger の不等式]{#lem-cs-wirtinger}
$L$ 周期の滑らかな実数値関数 $f$ が $\int_0^L f=0$ を満たすなら

$$
\int_0^L f^2\,\dd s
\le \left(\frac L{2\pi}\right)^2\int_0^L (f')^2\,\dd s.
$$

等号は $f(s)=a\cos(2\pi s/L)+b\sin(2\pi s/L)$ の場合に限る。
:::

:::proof
$x=2\pi s/L$ で一周期を $2\pi$ に直せばよい。:ref[thm-four-circle-parseval]{full} を $f$ と $f'$ に適用する。複素 Fourier 係数を $c_n$ とすれば平均は $c_0=0$ であり、部分積分から導関数の係数は $inc_n$ となる。従って二つの積分はそれぞれ $2\pi\sum_{n\ne0}|c_n|^2$ と $2\pi\sum_{n\ne0}n^2|c_n|^2$ である。各項を比較すれば不等式が出る。等号条件は $|n|\ge2$ の係数がすべて零となることであり、実数値条件 $c_{-1}=\overline{c_1}$ が結論を与える。
:::

:::theorem[等周不等式]{#thm-cs-isoperimetric}
長さ $L$ の滑らかな正則単純閉平面曲線が囲む面積を $A$ とすると $L^2\ge4\pi A$ である。等号は曲線が円の場合に限る。
:::

:::proof
正向きの弧長表示を $(x(s),y(s))$ とし、平行移動で $x$ の平均を零に取る。:ref[thm-anl-green] を使えば $A=\int_0^L xy'\,\dd s$ となる。Cauchy–Schwarz の不等式、:ref[lem-cs-wirtinger]、相加平均と相乗平均の比較を順に用いると、

$$
\begin{aligned}
A
&\le \left(\int_0^L x^2\,\dd s\right)^{1/2}
         \left(\int_0^L (y')^2\,\dd s\right)^{1/2}\\
&\le \frac L{2\pi}
     \left(\int_0^L (x')^2\,\dd s\right)^{1/2}
     \left(\int_0^L (y')^2\,\dd s\right)^{1/2}\\
&\le \frac L{4\pi}\int_0^L\big((x')^2+(y')^2\big)\,\dd s
=\frac{L^2}{4\pi}.
\end{aligned}
$$

最後に単位速さを用いた。等号なら $x=a\cos(\lambda s)+b\sin(\lambda s)$、$\lambda=2\pi/L$ であり、Cauchy–Schwarz の等号から $y'=cx$、$c>0$ である。最後の不等式の等号から $\int (x')^2=\int(y')^2$ なので $c=\lambda$。従って $y=a\sin(\lambda s)-b\cos(\lambda s)+d$ となり、円を描く。逆に半径 $R$ の円では $L=2\pi R$、$A=\pi R^2$ なので等号である。
:::

:::example[楕円と円の面積比較]
$(3\cos t,2\sin t)$ が囲む面積は $\int_0^{2\pi}6\cos^2t\,\dd t=6\pi$ である。円ではないので長さは $2\pi\sqrt6$ より大きい。具体的な長さを積分しなくても下界が得られる。
:::

:::example[定弧長の面積損失]
正曲率をもつ凸曲線の支持関数を $h(\phi)=R+\eps\cos m\phi$、$m\ge2$、$R>(m^2-1)|\eps|$ とする。:eqref[eq-cs-support-radius] から $L=\int(h+h'')\,\dd\phi=2\pi R$ である。また $\det(n,t)=1$ を使うと、面積は

$$
A=\tfrac12\int_0^{2\pi}\det(\gamma,\gamma')\,\dd\phi
=\pi R^2-\frac{\pi}{2}(m^2-1)\eps^2
$$

となる。この族では変形の一次の項が消え、面積差は二次の項に現れる。
:::

### 支持関数による凸曲線の等周差

一般の単純閉曲線では、弧長座標での Fourier 係数を使った。しかし凸曲線で法線角を座標に選べるなら、等周差を支持関数の係数の和として求められる。面積が円の値に近い場合、どの変形がその差を生んだかまで読み取れる。

:::proposition[支持関数で書いた周長と面積]{#prop-cs-support-area}
正曲率の凸閉曲線で、支持関数を

$$
h(\phi)=R+\sum_{m\ge1}(a_m\cos m\phi+b_m\sin m\phi)
$$

とする。周長と面積は

$$
L=2\pi R,\qquad
A=\pi R^2-\frac\pi2\sum_{m\ge2}(m^2-1)(a_m^2+b_m^2)
\label{eq-cs-isoperimetric-deficit}
$$

である。
:::

:::proof
:ref[lem-cs-support-radius] から $\dd s=(h+h'')\dd\phi$。周期性より $\int h''=0$ なので、周長は $h$ の平均に $2\pi$ を掛けた $2\pi R$ である。面積には :ref[thm-anl-green] を使う。位置が $hn+h't$、速度が $(h+h'')t$ で $\det(n,t)=1$ だから、向き付き面積は $\tfrac12\int h(h+h'')$。部分積分で

$$
A=\frac12\int_0^{2\pi}\big(h^2-(h')^2\big)\,\dd\phi
$$

となる。$h,h'$ の Fourier 係数を比較すれば、$h^2$ の積分で各余弦と正弦の係数の二乗には $\pi$、$(h')^2$ の積分では $\pi m^2$ が掛かる。定数項では前者だけが $2\pi R^2$ となる。従って $m=1$ の差は零であり、残りが式を与える。滑らかな周期関数なので級数はこの積分に使え、例えば Parseval の等式で直接正当化できる。
:::

従って $L^2-4\pi A$ は、周長を決める平均と位置を変える一次成分を除いた残りの非負和である。原点を $q=(q_1,q_2)$ だけ動かすと $h$ は $q_1\cos\phi+q_2\sin\phi$ を引いたものになる。従って $m=1$ が等周差に現れないことは、面積の平行移動に対する不変性を表している。

:::example[変形の次数を比較する]
同じ $R=6$ で、$h_2=6+\frac15\cos2\phi$ と $h_4=6+\frac15\cos4\phi$ を比べる。両者とも $h+h''>0$、周長は $12\pi$ である。面積損失は前者で $3\pi/50$、後者で $15\pi/50$ となる。支持関数の振幅は等しいが、高い次数では二階微分が大きくなるため面積差も大きくなる。
:::

:::example[平行な凸曲線の面積]
外向きに距離 $d\ge0$ だけ移した曲線は $\gamma_d=(h+d)n+h't$ であり、曲率半径は $\rho+d>0$ である。面積の式に $h+d$ を入れて展開すると

$$
L_d=L+2\pi d,\qquad A_d=A+dL+\pi d^2.
$$

従って $L_d^2-4\pi A_d=L^2-4\pi A$。支持関数の係数で見ても、外向き移動で変わるのは平均だけなので等周差が保存される。例えば $h=5+\cos2\phi$、$d=1$ なら $L_d=12\pi$、$A_d=69\pi/2$ となり、差は $6\pi^2$ である。
:::

### 面積変分から見た等周問題

等周不等式の証明とは別に、局所的な停留条件を求められる。正向きの単位速さ曲線を左法線方向へ動かすと、凸の場合は内側へ動かすことになる。符号付き曲率を使えば、凸性なしでも変分式を書ける。

:::proposition[平面閉曲線の長さと面積の第一変分]{#prop-cs-plane-first-variation}
正向き単位速さ単純閉曲線 $\gamma(s)$ を滑らかな周期関数 $\varphi(s)$ によって $\gamma_\eps=\gamma+\eps\varphi N$ と変分する。長さと囲む面積について

$$
L'(0)=-\int_0^L\kappa\varphi\,\dd s,\qquad
A'(0)=-\int_0^L\varphi\,\dd s
$$

が成り立つ。
:::

:::proof
$(\gamma_\eps)'=T+\eps(\varphi'N-\kappa\varphi T)$ だから、速さを $\eps$ で微分して $\eps=0$ と置けば $-\kappa\varphi$ である。$\eps$ が十分小さければ単純性も保たれる。実際、近いパラメータどうしは一方の接線への射影で区別でき、離れたパラメータの像はコンパクト性により正の距離を持つ。この両方が小さい $C^1$ 摂動で保たれる。面積を $\tfrac12\int\det(\gamma_\eps,\gamma_\eps')$ と書いて微分する。第二項を周期的な部分積分で第一項と合わせれば $\int\det(\varphi N,T)=-\int\varphi$ になる。
:::

長さの一階変分を零にする全ての法線変位に対して面積が停留するなら、$\kappa$ は一定である。実際、二つの一次汎関数 $\int\kappa\varphi$ と $\int\varphi$ について、前者の核が後者の核に含まれるなら両者は比例する。前者が零汎関数でないことは曲率の一周積分が $2\pi$ であることによる。比例係数を $c$ とすれば $\int(1-c\kappa)\varphi=0$ が全ての $\varphi$ に対して成り立つので、$\varphi=1-c\kappa$ を取れば曲率は一定になる。これは停留点を絞る議論であり、最大面積の存在と大域的な上界を与えるのは :ref[thm-cs-isoperimetric] である。

### 円に近い曲線の長さと面積を比べる

等周差は、周長から決まる円の面積と実際の面積の差を定数倍したものである。曲線を平行移動しても差は変わらない。従って支持関数の変化を調べるときは、原点の移動による一次の三角関数の項と、形を変える高い次数の項を区別する。

:::example[面積を固定して形を変形する]
$h(t)=4+\cos2t$ とする。曲率半径 $4-3\cos2t$ は正なので凸曲線である。長さは $8\pi$、面積は $\frac12\int_0^{2\pi}(4+\cos2t)(4-3\cos2t)\,\dd t=29\pi/2$ である。ここで $\int_0^{2\pi}\cos2t\,\dd t=0$、$\int_0^{2\pi}\cos^22t\,\dd t=\pi$ を使った。

この曲線と同じ面積を囲む円の半径は $\sqrt{29/2}$ なので、円の周長は $\pi\sqrt{58}$ である。$58<64$ より円の方が短い。周長を固定する比較では半径 $4$ の円の面積 $16\pi$ と比べ、失った面積は $3\pi/2$ と読める。どちらの比較でも等周差は $6\pi^2$ となる。
:::

:::example[原点を変えても等周差は残る]
円から変形した曲線に一次の三角関数を加え、平行移動が等周差に関わるか調べる。

外向き法線角を $t$ とする。まず支持関数の二階微分まで求め、曲率半径が全周で正となるかを調べる。そうすれば外向き法線角がそのまま一周のパラメータになる。

$$
\begin{aligned}
&h(t)=\frac{\sin{\left(2 t \right)} + 4 \cos{\left(t \right)} + 6}{2},\\
&h''(t)=- 2 \left(2 \sin{\left(t \right)} + 1\right) \cos{\left(t \right)},\\
&\rho(t)=- \frac{3 \left(\sin{\left(2 t \right)} - 2\right)}{2},\\
&\kappa(t)=1/\rho(t)
\end{aligned}
$$

点の位置は法線方向の成分 $h$ と接方向の成分 $h'$ で決まる。反対向きの二支持線の間隔は、原点から測った符号付きの二成分を足して得られる。

$$
\gamma(t)=h(t)(\cos t,\sin t)+h'(t)(-\sin t,\cos t),\qquad w(t)=\sin{\left(2 t \right)} + 6
$$

弧長の増分は $\rho\,\dd t$ なので周長は $\rho$ を積分して求める。面積にはもう一つ因子 $h$ が入り、周長が同じ曲線でも面積は変わり得る。

$$
\begin{aligned}
&L=\int_0^{2\pi}\rho\,\dd t=6 \pi,\\
&A=\frac12\int_0^{2\pi}h\rho\,\dd t=\frac{69 \pi}{8},\\
&L^2-4\pi A=\frac{3 \pi^{2}}{2}
\end{aligned}
$$

一次の項は $\rho=h+h''$ では消える。面積を積分するときも $\int\rho\cos t\,\dd t=0$ により相殺する。従って曲率半径と面積を変えたのは二次の項だけである。
:::

## 演習問題

::::exercise{level=basic}
$\gamma(t)=(3\cos2t,3\sin2t)$、$0\le t\le\pi$ の弧長表示と長さを求めよ。

:::solution
速さは $6$ なので $s=6t$、全長は $6\pi$ である。従って弧長表示は $3(\cos(s/3),\sin(s/3))$、$0\le s\le6\pi$ となる。微分のノルムが $1$ であることも直接確かめられる。
:::
::::

::::exercise{level=basic}
$\gamma(t)=(t,2t^2)$ の $t=0$ における曲率と接触円を求めよ。

:::solution
$\gamma'(0)=(1,0)$、$\gamma''(0)=(0,4)$ なので :eqref[eq-cs-plane-curvature] より $\kappa(0)=4$。左法線は $(0,1)$ であり、中心は $(0,1/4)$、半径は $1/4$ である。従って円の方程式は $x^2+(y-1/4)^2=1/16$ となる。
:::
::::

::::exercise{level=basic}
$\gamma(t)=(e^t\cos t,e^t\sin t)$ の符号付き曲率と $0\le t\le\log 3$ の長さを求めよ。

:::solution
$e_r=(\cos t,\sin t)$、$e_\theta=Je_r$ として $\gamma'=e^t(e_r+e_\theta)$、$\gamma''=2e^te_\theta$ なので分子は $2e^{2t}$、速さは $\sqrt2 e^t$ である。よって曲率は $e^{-t}/\sqrt2$、長さは $\sqrt2(3-1)=2\sqrt2$ である。
:::
::::

::::exercise{level=basic}
$\kappa=-3$、$\alpha(0)=(1,0)$、$T(0)=(0,1)$ の単位速さ曲線を求めよ。

:::solution
接線角は $\theta=\pi/2-3s$、従って $T=(\sin3s,\cos3s)$ である。積分すると $\alpha=(1+(1-\cos3s)/3,\sin3s/3)$ となる。中心 $(4/3,0)$、半径 $1/3$ の円を時計回りに進む。
:::
::::

::::exercise{level=advanced}
$\rho(\phi)=4+\cos 3\phi$ を曲率半径とする凸閉曲線を構成し、長さと頂点数を求めよ。

:::solution
$h=4-\frac18\cos3\phi$ とすれば $h+h''=\rho$ である。$\rho\ge3$ なので :eqref[eq-cs-support-radius] で定めた $\gamma=hn+h't$ は単純な凸閉曲線となる。長さは $\int_0^{2\pi}\rho\,\dd\phi=8\pi$。$\dv{\kappa}{s}=-\rho'/\rho^3$ だから、$\rho'=-3\sin3\phi$ の零点が頂点であり、ちょうど六つある。
:::
::::

::::exercise{level=advanced}
正向きの単純閉曲線の曲率の最大値を $M$、長さを $L$ とすると $M\ge 2\pi/L$ であることを示せ。また等号の場合を決定せよ。

:::solution
:ref[thm-cs-hopf-turning] より $2\pi=\int\kappa\,\dd s\le ML$。等号なら連続非負関数 $M-\kappa$ の積分が零なので、各点で $\kappa=M$ となる。:ref[thm-cs-plane-fundamental] と定曲率の円の計算から曲線は半径 $L/(2\pi)$ の円である。逆にその円では等号となる。
:::
::::

::::exercise{level=advanced}
単位速さの曲線 $\alpha$ に対し、平行曲線 $\beta=\alpha+dN$ を考える。$1-d\kappa>0$ として、$\beta$ の曲率を求めよ。半径 $5$ の反時計回りの円と $d=2$ に適用せよ。

:::solution
$\beta'=(1-d\kappa)T$ である。正値の仮定から接線は $T$、弧長微分は $(1-d\kappa)^{-1}\dv{}{s}$ となる。よって曲率は $\kappa/(1-d\kappa)$。円では $\kappa=1/5$ だから新しい曲率は $1/3$ であり、左法線側へ距離 $2$ だけ移した半径 $3$ の円である。
:::
::::

::::exercise{level=advanced}
$h(\phi)=5+\cos2\phi$ の凸曲線について面積を求め、等周不等式の差 $L^2-4\pi A$ を計算せよ。

:::solution
$\rho=5-3\cos2\phi>0$ だから支持関数から凸曲線ができる。長さは $L=10\pi$ である。面積は $\tfrac12\int h\rho\,\dd\phi$ であり、積の定数項は $25$、余弦二乗の項は $-3\cos^22\phi$ である。従って $A=25\pi-3\pi/2=47\pi/2$、差は $100\pi^2-94\pi^2=6\pi^2$ となる。
:::
::::

::::exercise{level=advanced}
$k(s)=2+\sin(6s)$ を弧長曲率に持つ曲線について、$s=0$ から $s=\pi$ までに閉じること、回転数が $1$ になること、および曲率の極値の個数を求めよ。
:::solution
$k$ は周期 $p=\pi/3$ を持つ。一周期での接線角の増分は $\int_0^{\pi/3}k\,\dd s=2\pi/3$。従って三つの区間の変位は、最初の変位を $0,2\pi/3,4\pi/3$ だけ回転したものになる。この三回転の和は零であるため位置が戻る。角の総増分は $2\pi$ で接線も戻り、周期性により高階微分も一致する。回転数は定義から $1$ である。

全区間で $k\ge1$ であり、接線角が一周でちょうど $2\pi$ 増える。任意の始点の接線の左法線方向を取ると、変位の高さは最初の半回転で厳密に増え、後の半回転で厳密に減る。最終の高さは零なので途中のすべてで正である。従って途中で同じ始点には戻らず、閉曲線は単純である。曲率の導関数は $6\cos6s$、零点は $s=(2j+1)\pi/12$、$j=0,\ldots,5$。各零点で符号が変わるので、局所最大と最小が三つずつである。
:::

## 確認テスト

::::quiz
向きを保って正則曲線を再パラメータ表示するとどの量が保たれるか。

- [x] 対応する点での符号付き曲率
- [ ] パラメータ微分で測った速さ
- [ ] パラメータ区間の長さ

:::explanation
対応する点で同じ方向に進み、弧長表示が弧長の原点の違いを除いて一致するので曲率が保たれる。例えば $\gamma(t)=(\cos t,\sin t)$、$t\in[0,2\pi]$ を $\gamma(2u)$、$u\in[0,\pi]$ とすれば、速さは $1$ から $2$ へ、区間の長さは $2\pi$ から $\pi$ へ変わる。一方でどちらの曲率も $1$ である。
:::
::::

::::quiz{answer="2" tol="1e-8"}
曲線 $(t,t^2)$ の $t=0$ での符号付き曲率を求めよ。

:::explanation
原点の速度は $(1,0)$、加速度は $(0,2)$ なので行列式は $2$、速さの三乗は $1$ である。よって曲率は $2$ である。
:::
::::

::::quiz
正向きの正則単純閉曲線について、必ず真であるものを選べ。

- [ ] 符号付き曲率は至る所正である。
- [x] 符号付き曲率の積分は $2\pi$ である。
- [ ] 長さだけで囲む面積が一意に定まる。

:::explanation
接線の角は Hopf の定理により一周で $2\pi$ 増える。曲率は弧長に関する角の微分なので積分は $2\pi$ である。曲率が非負なら凸になるため、くぼみのある単純閉曲線は負曲率の部分を持つ。面積には同じ長さであっても差があり、円だけが等周不等式の上限に達する。
:::
::::

::::quiz{answer="3" tol="1e-8"}
長さ $6\pi$ の正則単純閉平面曲線が囲める最大面積を $A_{\max}$ と置く。$\sqrt{A_{\max}/\pi}$ を求めよ。

:::explanation
等周不等式より $A\le (6\pi)^2/(4\pi)=9\pi$。半径 $3$ の円の長さは $6\pi$ であり、その面積は $9\pi$ なので上限を達成する。よって答えは $3$ である。
:::
::::
