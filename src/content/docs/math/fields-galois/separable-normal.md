## この章の目標

- 正規性を根の所在と埋め込みで判定する。
- 形式微分から分離性を調べる。
- 完全体と純非分離拡大を説明する。
- 有限分離拡大の原始元を構成する。

## 正規拡大と分解体

:::definition[正規拡大]{#def-gal-normal}
代数拡大 $L/K$ において、$L$ に根を一つ持つ $K[X]$ の既約多項式がすべて $L$ で分解するとき、:term[正規拡大]{en="normal extension" yomi="せいきかくだい"} という。
:::

:::theorem[正規性の判定]{#thm-gal-normal}
$L$ を $\overline K$ 内の中間体とする。$L/K$ が正規であることは、すべての $K$ 埋め込み $L\to\overline K$ の像が $L$ であることと同値である。また、$L/K$ が有限なら、これはある多項式の分解体であることと同値である。
:::

:::proof
正規なら埋め込みは任意の $a\in L$ をその共役の一つへ写し、その共役は $L$ にある。さらに、埋め込みは各最小多項式の有限な根集合に単射として作用するから全射でもある。したがって任意の $a$ は像に入る。逆に $a$ の任意の共役 $b$ に対して $a\mapsto b$ が単拡大の同型を定め、:ref[thm-gal-extend-algebraic] により $L$ に延びる。像が $L$ なら $b\in L$ である。

有限正規拡大では有限生成元の最小多項式を掛け合わせると、$L$ はその積の分解体になる。逆に分解体の埋め込みは有限な根集合の置換になり、根が生成元だから像が分解体全体となる。
:::

:::example[実根一つと全根]
$\Q(2^{1/3})$ は $X^3-2$ の非実根を含まないので正規でない。そこに原始三乗根 $\omega$ を加えた体は分解体なので正規である。
:::

:::example[上段と下段]
$L=\Q(2^{1/4},i)$ は $\Q$ 上正規である。$M=\Q(2^{1/4})$ は $\Q$ 上正規でない。一方、$L/M$ は $X^2+1$ の分解体なので正規である。一般にも $L/K$ が正規なら $L/M$ は正規である。実際、各 $M$ 埋め込みは $K$ 埋め込みでもある。
:::

### 正規閉包と基礎体の変更

:::proposition[正規閉包]{#prop-gal-normal-closure}
代数閉包 $\overline K$ の中の代数拡大 $E/K$ を考える。$E$ の各元の最小多項式の全根を添加した体 $N$ は、$E$ を含む最小の正規拡大である。$E/K$ が有限なら $N/K$ も有限であり、有限生成元の最小多項式だけを使って作れる。
:::

:::proof
$K$ 埋め込み $N\to\overline K$ は、添加した根の集合ごとにその集合への単射を与える。各集合は有限なので、どの埋め込みもそれぞれの根集合を保ち、従って $N$ を保つ。:ref[thm-gal-normal] で $N$ は正規である。任意の正規拡大で $E$ を含むものは、正規性の定義によって添加した全根を含む。よって $N$ は最小である。$E=K(a_1,\ldots,a_r)$ のとき、$a_i$ の最小多項式の積の分解体は正規で $E$ を含む。逆にその全根は $N$ に含まれる。従って両者は等しく、分解体の次数の上界から有限性を得る。
:::

この $N$ を $E/K$ の :term[正規閉包]{en="normal closure" yomi="せいきへいほう"} という。$N$ は $E$ のすべての $K$ 埋め込みの像の合成体でもある。任意の像は各元をその共役に移すので $N$ に入る。逆に $a\in E$ の任意の共役 $b$ は $K(a)\to\overline K$ の埋め込み $a\mapsto b$ を与え、それを $E$ に延長できるため、$b$ はある像に入る。

:::example[正規性は塔で推移しない]
$K=\Q$、$M=\Q(\sqrt2)$、$L=\Q(2^{1/4})$ とする。$M/K$ と $L/M$ はともに二次で、各生成元の正負の二根が入るため正規である。一方 $X^4-2$ は $K$ 上既約であり、その非実根は $L$ に入らない。従って $L/K$ は正規でない。正規閉包を取ると、非実根を $2^{1/4}$ で割って $i$ が得られ、$L(i)$ になる。正規な二つの段を合わせるときには、下段の自己同型が上段の根をどこに送るかを確かめる。
:::

:::proposition[正規性を保つ二つの操作]{#prop-gal-normal-base-and-intersection}
同じ代数閉包の中で $E/K$ が正規、$F/K$ が代数的なら、$EF/F$ は正規である。$E/K,F/K$ がともに正規なら $E\cap F$ も $K$ 上正規である。
:::

:::proof
$EF$ の $F$ 埋め込みは $E$ に制限すると $K$ 埋め込みである。その像は $E$ なので、$EF$ の像も $EF$ となる。よって上の判定で正規である。共通部分については、$E\cap F$ に根を持つ $K[X]$ の既約式を取る。$E$ と $F$ のそれぞれですべての根が入るため、全根は共通部分に入る。従って定義から正規である。
:::

$E/K,F/K$ がともに正規なら、合成体 $EF/K$ も正規である。実際、$EF$ の任意の $K$ 埋め込みは制限を取ると $E,F$ をそれぞれ集合として保ち、その二体が生成する $EF$ も保つ。この議論は、同じ代数閉包における任意個の正規拡大の合成にも使える。

:::example[非正規な体と合成した場合]
$a=\sqrt[3]2$、$\omega^2+\omega+1=0$ とし、$E=\Q(\omega)$、$F=\Q(a)$ を取る。$F/\Q$ は正規でないが、$EF/F$ は $X^2+X+1$ の分解体で正規である。逆に $EF/E$ は $X^3-2$ の分解体なのでこの例では正規である。後者については、$F/\Q$ の正規性を使えないため、$E$ が $\omega$ を含むというこの例の条件から直接確かめる。
:::

## 分離多項式と形式微分

:::definition[分離多項式]{#def-gal-separable-polynomial}
代数閉包における根がすべて単根である非零多項式を :term[分離多項式]{en="separable polynomial" yomi="ぶんりたこうしき"} という。係数の移動だけで定義する $f'=\sum_{j\ge1}j a_jX^{j-1}$ を :term[形式微分]{en="formal derivative" yomi="けいしきびぶん"} という。
:::

:::proposition[重根と導関数]{#prop-gal-derivative}
$f$ が分離的であることと $\gcd(f,f')=1$ は同値である。とりわけ既約な正次数の $f$ が分離的でないことと $f'=0$ は同値である。
:::

:::proof
積の微分則は単項式の積で検算してから線形性で示せる。根 $a$ について $f=(X-a)g$ とすると $f'(a)=g(a)$ である。したがって重根は共通根に等しい。互いに素なら Bézout 等式により共通根がない。逆に非定数の最大公約式は代数閉包で共通根を持つ。既約の場合、$f'\ne0$ なら $\deg f'<\deg f$ により最大公約式は $1$ である。
:::

:::example[既約で重根を持つ式]
$K=\F_3(t)$ とする。$X^3-t$ を $\overline K$ で書くと $(X-u)^3$ であり、$u^3=t$ である。一次因子が $K[X]$ にあれば $t$ が立方となるが、$t$ の指数が $1$ なので不可能である。したがってこの三次式は既約だが分離的でない。
:::

:::example[微分が零でないだけでは足りない]
$\Q[X]$ の $(X-1)^2(X+1)$ の形式微分は $3X^2-2X-1$ であり、$X=1$ で零になる。導関数が非零でも、既約性がない場合は最大公約式を調べる必要がある。
:::

### 形式微分が消える回数を読む

:::proposition[非分離多項式の形]{#prop-gal-inseparable-polynomial-form}
標数 $p>0$ で既約な正次数の $f\in K[X]$ は $f(X)=g(X^{p^e})$ と書ける。ここで $e\ge0$、$g$ は既約分離的であり、各根の重複度は $p^e$、相異なる根の数は $\deg g$ である。
:::

:::proof
正指数の非零項の指数すべてを割る最大の $p$ 冪を $p^e$ と置く。その指数を $p^e$ で割って得る多項式が $g$ である。$g$ が可約なら両因子に $X^{p^e}$ を代入して $f$ が可約になる。最大性により $g$ は微分が零でないので既約性から分離的である。代数閉包で $g$ の各根 $b$ は一意の $p^e$ 乗根 $a$ を持ち、$X^{p^e}-b=(X-a)^{p^e}$ である。異なる $b$ からは異なる $a$ が得られるので、数と重複度の主張が従う。
:::

:::example[正標数でも全ての既約式が重根を持つわけではない]
$K=\F_3(t)$ とし、$f=X^3-X-t$ とする。$f'=-1$ なので $f$ は分離的である。$r\in K$ が根なら $r^3-r=t$ である。$r=A(t)/B(t)$ と既約に書き、$B$ の既約因子 $g$ があれば、その点で $r$ の極の位数を $m>0$ とすると $r^3-r$ の極の位数は $3m$ である。これは共通分母 $B^3$ の分子 $A^3-AB^2$ が $g$ で割れないことからも分かる。右辺は多項式なので $B$ は定数である。非定数多項式 $r$ なら $\deg(r^3-r)=3\deg r$ で $1$ にならず、定数ならやはり $t$ にならない。従って根がなく、三次なので既約である。
:::

:::example[重複度が混ざる場合]
$\F_3$ 上で $f=(X-1)^3(X+1)^2$ とする。積の微分則で $f'=2(X-1)^3(X+1)$ なので $\gcd(f,f')=(X-1)^3(X+1)$ である。従って $f/\gcd(f,f')=X+1$ で、根 $1$ が消えている。標数 $0$ なら商は全ての相異なる因子を一回ずつ含むが、正標数で $p$ の倍数の重複度を持つ因子には同じ手順をそのまま使えない。
:::

### 重根を含む式の微分を追う

正標数での最大公約式から、微分で失われる因子を調べる。以下の素体では $a^p=a$ である。そのため、導関数が零の正次数多項式は、指数を $p$ で割った多項式の $p$ 乗になる。特に、素体上の正次数既約式の導関数は零でない。

:::example[微分と最大公約式から重複度を測る]
$\F_{2}[X]$ において $f=X^{8} + X^{7} + X^{6} + X^{2} + X + 1$ を考える。相異なる既約因子の分解が次の形になっているとする。

| モニック既約因子 | 重複度 | $p$ での重複度の剰余 |
| --- | --- | --- |
| $X + 1$ | 2 | 0 |
| $X^{2} + X + 1$ | 3 | 1 |

既約因子 $g$ を一つ固定し $f=g^m h$、$g\nmid h$ と書く。$p\nmid m$ なら $f'=g^{m-1}(mg'h+gh')$ で、括弧は $g$ で割り切れない。有限体上では $g'$ が $g$ と互いに素だからである。$p\mid m$ なら第一項が消え、$f'$ は $g^m$ で割り切れる。

$$
\begin{aligned}
f'(X)&=X^{6} + 1,\\
\gcd(f,f')&=X^{6} + 1,\\
f/\gcd(f,f')&=X^{2} + X + 1
\end{aligned}
$$

微分が零なら最大公約式は $f$ 自身になる。その場合は係数の $p$ 乗根を取り、各指数を $p$ で割って次数を下げる。零でない場合でも、商に現れない因子があるかどうかは表の第三列で決まる。従って商だけから全ての相異なる根を回収するには、重複部分も再帰的に処理する必要がある。
:::

## 分離拡大と分離次数

:::definition[分離拡大と分離次数]{#def-gal-separable}
$L/K$ の元が分離的であるとは、$K$ 上代数的で最小多項式が分離的であることをいう。全元が分離的な拡大を :term[分離拡大]{en="separable extension" yomi="ぶんりかくだい"} と呼ぶ。有限拡大の :term[分離次数]{en="separable degree" yomi="ぶんりじすう"} $[L:K]_{\mathrm{s}}$ は $K$ 埋め込み $L\to\overline K$ の個数である。
:::

:::theorem[埋め込みの個数と分離性]{#thm-gal-separable-degree}
有限な塔 $K\subseteq M\subseteq L$ に対して $[L:K]_{\mathrm{s}}=[L:M]_{\mathrm{s}}[M:K]_{\mathrm{s}}$ である。また $[L:K]_{\mathrm{s}}\le[L:K]$ であり、等号は分離性と同値である。
:::

:::proof
$M$ の任意の $K$ 埋め込みは $\overline K$ の $K$ 自己同型へ延びる。これは :ref[thm-gal-extend-algebraic] の延長と、像が代数閉で $\overline K$ がその上代数的であることによる。延長の一つとの合成で、包含 $M\to\overline K$ の上の埋め込みと任意の埋め込みの上の埋め込みが一対一になる。制限の各逆像が同じ大きさなので積公式が従う。

次に有限生成元を一つずつ添加する。:ref[lem-gal-extend-simple] により各段の埋め込み数は最小多項式の次数以下である。生成元がすべて $K$ 上分離的なら、その各最小多項式の中間体上での因子も分離的であり、すべての段で等号となる。逆に全体で等号なら、任意の $a\in L$ を最初に取った塔 $K\subseteq K(a)\subseteq L$ に適用すると $K(a)/K$ で等号が必要である。よって $a$ は分離的である。
:::

有限個の分離的元で生成される拡大はこの証明により分離的である。したがって代数拡大の中の分離的な元全体は体をなす。また分離性は代数拡大の塔で推移する。実際、任意の上段の元について、その分離的な最小多項式の係数で有限分離拡大 $M_0/K$ を作る。$M_0$ 上の最小多項式はその分離多項式を割るため分離的であり、有限塔の積公式で結論が出る。

:::example[二つの次数が異なる例]
$\F_3(t^{1/3})/\F_3(t)$ は次数が $3$ で、分離次数は $1$ である。一方 $\Q(2^{1/3})/\Q$ では両者は $3$ である。
:::

:::example[相異なる像を復元する]
$\Q(\sqrt2,\sqrt3)$ の四つの埋め込みは各平方根の符号を独立に変える。任意の符号の組は二段階の単拡大補題で実現できる。$\sqrt2+\sqrt3$ の四つの像も異なるので、元の体の次数を像の個数から再確認できる。
:::

### 分離性と合成体

:::proposition[分離性の持ち上げと合成]{#prop-gal-separable-compositum}
$E/K$ が代数的分離拡大、$F/K$ が同じ上位体にある拡大なら、$EF/F$ は代数的分離拡大である。$F/K$ も代数的分離なら、$EF/K$ も代数的分離である。
:::

:::proof
$EF=F(E)$ の元は $E$ の有限個の元を添加した体に入る。$a\in E$ の $F$ 上の最小多項式は $K$ 上の分離多項式を割るため分離的である。従って $F$ と有限個のそのような $a$ が生成する拡大が分離的であり、全元が $F$ 上分離的である。$F/K$ も代数的分離なら、分離性の推移性で $EF/K$ は分離的である。
:::

:::example[同じ次数で埋め込み数の異なる二つの体]
$K=\F_2(t)$ とし、$u^2=t$、$v^2+v=t$ とする。$t$ は平方でないので $K(u)/K$ は二次で、$u$ の像は $u$ 一つである。$X^2+X+t$ に根がないことは分母を払って確認できる。既約分数 $A/B$ を代入すると $A^2+AB=tB^2$ となり、$B$ の非定数既約因子は $A$ を割ってしまう。従って $B$ は定数であり、非定数の解なら左辺の次数が偶数で右辺の次数 $1$ と一致しない。ゆえに $K(v)/K$ も二次であり、像は $v,v+1$ の二通りである。二体は分離性が異なるため別の体である。合成体の次数は四次になる。実際、$X^2+X+t$ が $K(u)$ に根を持てば $K(v)\subseteq K(u)$ となり、両方二次なので矛盾する。分離次数は塔法則で $2$ である。
:::

### 分離的な段と純非分離な段を読む

式の次数を標数の冪で分けると、埋め込みの個数と重複度を別々に計算できる。以下では $p\nmid m$ のとき、$X^m-1$ が $\F_p$ で分解する条件が $m\mid p-1$ であることも使う。実際、$\F_p^\times$ の全元は $X^{p-1}-1$ の根なので、相異なる $m$ 個の根がすべて $\F_p^\times$ にあれば $X^m-1$ は $X^{p-1}-1$ を割る。$p-1=qm+r$、$0\le r<m$ と書くと、この除法の余りは $X^r-1$ である。よって $r=0$ が必要である。逆に $r=0$ なら割り切れ、$X^{p-1}-1$ が $\F_p$ で分解するので $X^m-1$ も分解する。

:::example[二項式の分離次数と正規性を分けて調べる]
$K=\F_{7}(t)$、$a^{147}=t$ とする。$X^{147}-t$ は係数環 $\F_{7}[t]$ の素元 $t$ に関する Eisenstein で既約だから、$L=K(a)$ の次数は $147$ である。

$$
\begin{aligned}
f(X)&=(X^{49})^{3}-t,\\
g(X)&=X^{3}-t,\\
f(X)&=\prod_{\xi^{3}=1}(X-\xi a)^{49}
\end{aligned}
$$

$g'=3X^{2}$ は $g$ と互いに素である。従って相異なる根は $3$ 個、各根の重複度は $49$ である。$a^{49}$ は $g$ を満たすので、次数 $3$ の分離部分を生成する。残る段は純非分離で次数 $49$ である。

次に $L=\F_{7}(a)$ で $a$ は不定元として扱える。従って $L$ に含まれる $\F_{7}$ 上代数的な元は $\F_{7}$ に限られる。根の比 $\xi$ は $\F_{7}$ 上代数的であるため、全根が入ることと $3$ が $7-1$ を割ることが同値である。

ここでは $6$ を $3$ で割った余りが $0$ である。よって $L/K$ は正規である。相異なる根を全て含むが、重複度は一より大きい。
:::

## 完全体

:::definition[完全体]{#def-gal-perfect}
すべての代数拡大が分離的である体を :term[完全体]{en="perfect field" yomi="かんぜんたい"} という。
:::

:::theorem[完全性の判定]{#thm-gal-perfect}
標数 $0$ の体は完全である。標数 $p>0$ の体 $K$ は、Frobenius 写像 $a\mapsto a^p$ が全射であるとき、かつそのときに限り完全である。
:::

:::proof
標数 $0$ では正次数の多項式に対して導関数は非零なので、既約式は分離的である。標数 $p$ では $f'=0$ なら指数はすべて $p$ の倍数である。係数がすべて $p$ 乗なら、二項係数が消えることから $f$ 自体は多項式の $p$ 乗になり、正次数なら既約でない。逆に $a\notin K^p$ なら $X^p-a=(X-b)^p$ のモニック真因子は $(X-b)^j$、$1\le j<p$ である。$X^{j-1}$ の係数 $-jb$ が $K$ に入るなら $b\in K$ となり矛盾する。よって $X^p-a$ は非分離既約式である。
:::

:::example[有限体]
有限体では $a^p=b^p$ なら $(a-b)^p=0$ なので $a=b$ である。有限集合の単射は全射であるため、有限体は完全である。
:::

:::example[有理関数体]
$\F_p(t)$ の Frobenius の像は $\F_p(t^p)$ である。分子・分母の $p$ 乗を取ればこの包含が分かり、逆に $t^p$ の分数式の変数を $t$ に置き換えれば逆像を得る。$t$ は像に入らず、$\F_p(t)$ は完全でない。
:::

### 完全閉包の構成

:::proposition[完全閉包]{#prop-gal-perfect-closure}
標数 $p>0$ の体 $K$ の代数閉包を固定する。各 $e\ge0$ に対して
$$
K^{1/p^e}=\{a\in\overline K:a^{p^e}\in K\}
$$
と置くと、$K^{\mathrm{perf}}=\bigcup_e K^{1/p^e}$ は $K$ を含む最小の完全体である。
:::

:::proof
$p^e$ 乗写像が体の演算を保つため、それによる $K$ の逆像は部分体である。$a^{p^e}\in K$ ならその $p$ 乗も $K$ に入るのでこれらは増加列をなす。合併の元 $a$ が第 $e$ 段に入るなら、その $p$ 乗根は第 $e+1$ 段に入る。従って合併上の Frobenius は全射で、完全である。反対に $K$ を含む完全な部分体では $K$ の各元の反復 $p$ 乗根がすべて存在し、その根は代数閉包の中で一意である。したがって全段を含む。
:::

:::example[一変数の完全閉包]
$K=\F_2(t)$ で $t_e^{2^e}=t$ とする。$K^{1/2^e}=\F_2(t_e)$ である。実際 $(A(t_e)/B(t_e))^{2^e}=A(t)/B(t)$ となり、右辺は $K$ の全元を走る。一意性から $K$ の各元の $2^e$ 乗根はこの形で尽くされる。例えば $(t+1)/(t^2+t+1)$ の平方根は $(t_1+1)/(t_1^2+t_1+1)$ である。次数は $2^e$ なので、完全閉包は有限段では得られない。
:::

### 一変数と多変数の完全閉包

Frobenius が関数の表示をどう移すかを用い、各有限段を基底で明示する。

:::example[反復 Frobenius で基底を組み立てる]
$K=\F_{2}(t_1)$ とする。$t_i$ は独立な不定元であり、$u_i^{2}=t_i$ を満たす根を添加する。$2$ 乗は体の演算を保ち、$\F_{2}$ の各元を固定するため、任意の有理関数 $A(t)/B(t)$ の $2$ 乗根は $A(u)/B(u)$ である。

従って $K^{1/2}=\F_{2}(u_1)$ である。ここで $u_i$ に非零多項式関係があれば、$2$ 乗して $t_i$ に同じ係数の非零多項式関係が生じ、矛盾する。従って $u_i$ は代数的に独立である。

$$
u_1^{i_1},\qquad0\le i_1<2
$$

上の単項式が $K$ 基底である。独立性を確かめるには係数の分母を払い、各 $u_j$ の冪を $2$ で割った余りで整理する。異なる基底元は異なる余りの組に対応する。積では $u_j^{2}=t_j$ を使って元に戻せるので、張る空間は有限次部分環であり体である。

従って $[K^{1/2}:K]=2^1=2$ である。各 $u_i$ の $1$ 乗は $t_i$ の $2$ 乗根で、$t_i$ の素因子指数 $1$ により $K$ にない。従って非分離指数はちょうど $1$ である。
:::

:::example[反復 Frobenius で基底を組み立てる]

従って $K^{1/2}=\F_{2}(u_1,\ldots,u_3)$ である。ここで $u_i$ に非零多項式関係があれば、$2$ 乗して $t_i$ に同じ係数の非零多項式関係が生じ、矛盾する。従って $u_i$ は代数的に独立である。

$$
u_1^{i_1}\cdots u_{3}^{i_3},\qquad0\le i_j<2
$$

上の単項式が $K$ 基底である。独立性を確かめるには係数の分母を払い、各 $u_j$ の冪を $2$ で割った余りで整理する。異なる基底元は異なる余りの組に対応する。積では $u_j^{2}=t_j$ を使って元に戻せるので、張る空間は有限次部分環であり体である。

従って $[K^{1/2}:K]=2^3=8$ である。各 $u_i$ の $1$ 乗は $t_i$ の $2$ 乗根で、$t_i$ の素因子指数 $1$ により $K$ にない。従って非分離指数はちょうど $1$ である。
:::

## 純非分離拡大

:::definition[純非分離拡大]{#def-gal-purely-inseparable}
標数 $p>0$ で、各 $a\in L$ に対しある $e\ge0$ が存在して $a^{p^e}\in K$ となる拡大を :term[純非分離拡大]{en="purely inseparable extension" yomi="じゅんひぶんりかくだい"} という。
:::

:::proposition[純非分離性と共役]{#prop-gal-purely-inseparable-criteria}
標数 $p>0$ の代数拡大 $L/K$ について、次の条件は同値である。

1. $L/K$ は純非分離である。
2. 任意の $a\in L$ の最小多項式は $X^{p^e}-a^{p^e}$ の形である。ここで $e$ は $a^{p^e}\in K$ となる最小の指数である。
3. $K$ 埋め込み $L\to\overline K$ は一つである。
:::

:::proof
純非分離なら最小多項式は $(X-a)^{p^e}=X^{p^e}-a^{p^e}$ を割るので、相異なる根を一つしか持たない。:ref[prop-gal-inseparable-polynomial-form] により、この最小多項式は $X^{p^j}-a^{p^j}$ である。その係数は $K$ に属し、$j\le e$ であるから、$e$ の最小性により $j=e$ である。この形の最小多項式なら各元の像は一つに決まり、延長定理により埋め込みは存在する。逆にある $a$ が相異なる共役を二つ持てば、$K(a)$ の二つの埋め込みがそれぞれ $L$ に延びる。一意性が成り立つときは各最小多項式に根が一つしかないため、同じ形の定理から $p$ の冪を取ると $K$ に戻る。
:::

純非分離性は中間体で上下に分けても保たれる。逆に $L/M$ と $M/K$ が純非分離なら、$a\in L$ の $p$ 冪で $M$ に至り、そこからさらに $p$ 冪を取れば $K$ に至る。また純非分離拡大は正規である。これは任意の元の最小多項式が唯一の根をその拡大体に持つためである。

:::theorem[分離部分と純非分離部分]{#thm-gal-inseparable-decomposition}
標数 $p$ の代数拡大 $L/K$ で、$K$ 上分離的な元の体を $S$ とする。$L/S$ は純非分離である。有限の場合 $[S:K]=[L:K]_{\mathrm{s}}$ かつ $[L:S]$ は $p$ の冪である。
:::

:::proof
$a$ の既約最小多項式は指数の最大公約数の $p$ 部分を切り出して $g(X^{p^e})$ と書ける。$g$ は $g'\ne0$ であり、$g$ の因数分解は元の式の因数分解を与えるので既約である。ゆえに $a^{p^e}$ は分離的で $S$ に属する。

:ref[prop-gal-purely-inseparable-criteria] により、$L/S$ の埋め込み数は一つで、各単拡大の次数は $p$ の冪である。有限生成元の塔に適用すると $[L:S]$ は $p$ の冪であり、分離次数の積公式から $[L:K]_{\mathrm{s}}=[S:K]_{\mathrm{s}}=[S:K]$ となる。
:::

有限拡大では $[L:K]_{\mathrm{i}}=[L:K]/[L:K]_{\mathrm{s}}$ を :term[非分離次数]{en="inseparable degree" yomi="ひぶんりじすう"} と呼ぶ。標数 $p>0$ では上の定理により $[L:S]$ に等しい。塔法則と分離次数の積公式の商を取ると、非分離次数にも塔法則が成り立つ。標数 $0$ では全ての有限拡大の非分離次数は $1$ である。

$L=\overline K$ の場合の $S$ を $K$ の :term[分離閉包]{en="separable closure" yomi="ぶんりへいほう"} という。任意の有限分離拡大 $T/S$ を $\overline K$ に埋め込むと、$T$ の元は分離性の推移性から $K$ 上分離的であり、$S$ に属する。従って $S$ は真の分離代数拡大を持たない。標数 $p>0$ では $\overline K/S$ は純非分離であり、$K$ が不完全なら $K$ の元の $p$ 乗根のうち $S$ に入らないものがある。

:::example[二段の純非分離拡大]
$u$ を不定元とし $K=\F_2(u^4)$ とする。$\F_2(u)/K$ は $X^4-u^4$ の分解体である。次数は $4$ である。実際 $1,u,u^2,u^3$ の関係の分母を払うと指数が $4$ を法として異なる項に分かれ、非自明な関係を持てない。一方、埋め込みは一つなので正規性と分離性は別の条件である。
:::

:::example[混合した拡大]
$K=\F_3(t)$、$L=\F_9(t^{1/3})$ とする。$\F_9=\F_3(i)$ は $i^2=-1$ で与えられ、$K$ にこの根は入らない。有理関数体の相対代数閉包に関する前章の例から従う。したがって $K(i)/K$ は分離二次である。$t$ は $\F_9(t)$ でも立方にならないため、上段は純非分離三次である。全次数は $6$、分離次数は $2$ である。
:::

### 純非分離の指数と分離部分

有限純非分離拡大 $L/K$ で全元に一様に $p^e$ 乗を施して $K$ に戻る最小の $e$ を、拡大の :term[非分離指数]{en="inseparability exponent" yomi="ひぶんりしすう"} という。有限生成元の各々を戻す指数の最大を取れば、加減乗除が $p^e$ 乗で保たれるため、全元に共通する指数が得られる。逆に全元に共通の指数は生成元すべてに使える。従って、最小の指数はそれぞれの生成元の最小指数の最大である。

:::example[同じ次数で指数が異なる場合]
$K=\F_p(s,t)$ とする。第一の体は $K(s^{1/p^2})$ で、$X^{p^2}-s$ が $s$ で Eisenstein だから次数は $p^2$ である。生成元の $p$ 乗根の段は $K$ に含まれないので指数は $2$ である。第二の体は $K(s^{1/p},t^{1/p})$ である。初段を $\F_p(s^{1/p},t)$ と書くと、次の段の式 $X^p-t$ は $t$ に関する Eisenstein で既約である。従って次数は同じ $p^2$ だが、両生成元を $p$ 乗すると $K$ に戻るので指数は $1$ である。
:::

:::example[分離部分を一つの冪から取り出す]
$K=\F_3(t)$ とし、$b^2=t$、$a^3=b$ とする。$X^6-t$ は $t$ で Eisenstein だから $K(a)/K$ は六次である。$K(b)/K$ は二次かつ分離的であり、$K(a)/K(b)$ は純非分離三次である。任意の $K$ 上分離的な元 $c\in K(a)$ は $K(b)$ 上も分離的である。一方 $c^3\in K(b)$ なので、その最小多項式の相異なる根は一つしかない。従って次数は $1$ であり、$c\in K(b)$ である。よって $K(b)$ が分離部分、分離次数は $2$ である。
:::

### 十分大きな Frobenius 冪から分離部分を作る

:::proposition[分離部分の Frobenius による表示]{#prop-gal-separable-part-powers}
標数 $p>0$ の有限拡大 $L/K$ の分離部分を $S$ とする。$p^e$ 乗で $L$ の全元を $S$ に移せるなら、$S=K(L^{p^e})$ である。
:::

:::proof
仮定から $F=K(L^{p^e})\subseteq S$ である。任意の $a\in S$ は $K$ 上分離的なので $F$ 上も分離的である。一方 $a^{p^e}\in L^{p^e}\subseteq F$ であるため、$a$ の $F$ 上の最小多項式は $X^{p^e}-a^{p^e}=(X-a)^{p^e}$ を割る。従って相異なる根は $a$ 一つであり、分離性により最小多項式は一次である。ゆえに $a\in F$ である。なお $L/S$ の有限個の生成元をそれぞれ $S$ に移す指数を求め、その最大を取れば仮定を満たす $e$ が存在する。
:::

:::example[混合拡大で分離部分を復元する]
$K=\F_2(t)$、$a^{12}=t$、$L=\F_2(a)$ とする。$X^{12}-t$ は $t$ に関する Eisenstein で既約である。四乗で $L^4=\F_2(a^4)$ となり、$t=(a^4)^3$ なので $K(L^4)=\F_2(a^4)$ である。この体は $X^3-t$ の根 $a^4$ で生成され、次数 $3$ で分離的である。$L/\F_2(a^4)$ は四乗で元が戻る純非分離拡大だから、この体が $L/K$ の分離部分である。二乗では $a^2$ が分離部分に入らない。入るなら $[L:\F_2(a^4)]=4$ が $[L:\F_2(a^2)]=2$ 以下になって矛盾する。
:::

### 根の比を使う正規性の判定

一根を添加した体がすべての共役を含むかを調べる。正標数では同時に重複度も記録する。

:::example[二項式の分離次数と正規性を分けて調べる]
$K=\F_{3}(t)$、$a^{6}=t$ とする。$X^{6}-t$ は係数環 $\F_{3}[t]$ の素元 $t$ に関する Eisenstein で既約だから、$L=K(a)$ の次数は $6$ である。

$$
\begin{aligned}
f(X)&=(X^{3})^{2}-t,\\
g(X)&=X^{2}-t,\\
f(X)&=\prod_{\xi^{2}=1}(X-\xi a)^{3}
\end{aligned}
$$

$g'=2X^{1}$ は $g$ と互いに素である。従って相異なる根は $2$ 個、各根の重複度は $3$ である。$a^{3}$ は $g$ を満たすので、次数 $2$ の分離部分を生成する。残る段は純非分離で次数 $3$ である。

次に $L=\F_{3}(a)$ で $a$ は不定元として扱える。従って $L$ に含まれる $\F_{3}$ 上代数的な元は $\F_{3}$ に限られる。根の比 $\xi$ は $\F_{3}$ 上代数的であるため、全根が入ることと $2$ が $3-1$ を割ることが同値である。

ここでは $2$ を $2$ で割った余りが $0$ である。よって $L/K$ は正規である。相異なる根を全て含むが、重複度は一より大きい。
:::

## 原始元定理

:::theorem[原始元定理]{#thm-gal-primitive}
有限分離拡大 $L/K$ には $L=K(c)$ となる :term[原始元]{en="primitive element" yomi="げんしげん"} $c$ が存在する。
:::

:::proof
$K$ が無限なら、二つの生成元 $a,b$ を一つにまとめれば帰納法で十分である。$K(a,b)$ の相異なる埋め込み $\sigma,\tau$ について $\sigma(a+\lambda b)=\tau(a+\lambda b)$ は、高々一つの $\lambda\in K$ を排除する。$b$ の像が等しい場合は $a$ の像が異なるため、排除する値はない。埋め込みの組は有限なので、すべての像が相異なる $\lambda$ を選べる。$a+\lambda b$ の最小多項式には少なくとも $[K(a,b):K]$ 個の根がある。塔法則で逆向きの不等式が成り立つので、これが原始元である。

$K$ が有限なら $L$ も有限である。有限な乗法群 $L^\times$ の元の位数の最小公倍数を $m$ とする。各素数 $\ell$ に対し $m$ を割る最大の $\ell$ 冪を位数に持つ元は、適切な元の冪を取れば得られる。それらの積の位数は $m$ である。実際、互いに素な位数の元が可換なら積の冪が $1$ となるには各元の同じ冪が $1$ となる必要がある。一方、全員が $X^m-1$ の根なので $\abs{L^\times}\le m$ である。よって位数 $m$ の元が $L^\times$ を生成し、体としても $L$ を生成する。
:::

:::corollary[純非分離な基礎体の拡大と分離次数]{#cor-gal-separable-pure-base}
$E/K$ を有限分離拡大、$F/K$ を同じ代数閉包に含まれる純非分離拡大とする。このとき $EF/F$ は分離拡大で、$[EF:F]=[E:K]$ である。
:::

:::proof
原始元定理で $E=K(a)$ と書き、$a$ の最小多項式を $f$ とする。$a$ の $F$ 上の最小多項式 $g$ は $f$ を割る。$f$ の根はすべて $K$ 上分離的であるから、その分解体 $N$ の全元も $K$ 上分離的である。一方、代数閉包で $g$ を分解すると、各一次因子の根は $f$ の根でもある。よって $g$ の係数はそれらの根の対称式として $N$ に属する。従って係数は $N\cap F$ に入る。この共通部分の元は $K$ 上分離的かつ純非分離なので $K$ に属する。よって $g\in K[X]$ であり、$f$ の既約性から $g=f$ となる。次数は保たれ、$g$ が分離的なので $F(a)/F$ も分離的である。
:::

:::example[線形結合でまとめる]
$a=\sqrt2,b=\sqrt3$ の場合、$a+b$ の四つの像は $\pm a\pm b$ で互いに異なる。したがって $a+b$ は原始元である。$\lambda=0$ を選ぶと $b$ の符号だけを変える二つの埋め込みは同じ値を与える。
:::

:::example[分離性なしでは失敗する]
$K=\F_p(s^p,t^p)\subseteq L=\F_p(s,t)$ で $s,t$ は独立な不定元とする。$s^it^j$（$0\le i,j<p$）は分母を払って指数の剰余を比較すると一次独立である。添加で得る上界と合わせて $[L:K]=p^2$ である。一方、全元の $p$ 乗が $K$ に入るため $[K(c):K]\le p$ であり、原始元は存在しない。
:::

### 単拡大と中間体の個数

原始元定理では分離性が十分条件であった。分離性がない場合にも、有限拡大が単拡大かどうかは、中間体の個数を用いて判定できる。

:::theorem[有限個の中間体と単拡大]{#thm-gal-simple-intermediate-finite}
有限拡大 $L/K$ が単拡大であることと、中間体が有限個であることは同値である。
:::

:::proof
$L=K(a)$ とし、$M$ を中間体、$g$ を $a$ の $M$ 上の最小多項式とする。$g$ の係数で $K$ 上生成した体を $M_0$ とする。$g$ は $M_0[X]$ にあり、また $M[X]$ で既約なので $M_0[X]$ でも既約である。$M_0(a)=M(a)=L$ だから $[L:M_0]=\deg g=[L:M]$ であり、$M_0=M$ が従う。したがって $M$ は $g$ から決まる。$g$ は $m_{a,K}$ のモニック因子であり、$L[X]$ にモニック因子は有限個しかない。

逆に中間体が有限個であるとする。$K$ が有限なら乗法群の生成元を取ればよい。$K$ が無限なら、有限次元の $K$ ベクトル空間は有限個の真部分空間の合併にならない。これを示すには各真部分空間を消す非零線形汎関数を選び、それらの積を取る。積は非零多項式であり、無限体上では全点で零にならない。そこで真の中間体すべての外から $a$ を取れば、$K(a)$ は真の中間体になれず $L$ に等しい。
:::

:::example[非分離だが単拡大]
$L=\F_p(u)$、$K=\F_p(u^{p^2})$ とする。$L/K$ は純非分離で、$[L:K]=p^2$ である。真の中間体 $M$ があると $[L:M]=p$ であり、$u^p\in M$ が必要である。実際 $u$ の $M$ 上の最小多項式は $X^p-u^p$ となる。次に $K(u^p)$ も次数 $p$ の中間体なので、$M=K(u^p)$ である。単拡大であることは、分離性を意味しない。
:::

:::example[無限個の中間体を区別する]
$K=\F_p(s^p,t^p)$、$L=\F_p(s,t)$ の例では、$c\in K$ ごとに $M_c=K(s+ct)$ が次数 $p$ になる。もし $c\ne d$ で $M_c=M_d$ なら、差から $t$ を得て、さらに $s$ を得る。すると $M_c=L$ になり、$[L:K]=p^2$ と矛盾する。$K$ は無限なので、原始元が存在しないことを中間体の個数からも確認できる。
:::

### 原始元を実際に探す

:::example[三次と二次の生成元をまとめる]
$a=\sqrt[3]2$、$b=\sqrt3$、$c=a+b$ とする。$a=c-b$ を $a^3=2$ に代入すると
$$
c^3+9c-2=(3c^2+3)b
$$
を得る。$c$ は実数なので分母 $3c^2+3$ は正である。したがって $b=(c^3+9c-2)/(3c^2+3)$、$a=c-b$ は $\Q(c)$ に入り、$c$ が原始元になる。もとの二体の次数は互いに素で、合成体は六次である。上式を平方し $b^2=3$ を代入して得るモニックな六次式
$$
(X^3+9X-2)^2-27(X^2+1)^2
$$
は、次数が六次で $c$ を消すので最小多項式に等しい。
:::

:::example[有限個の禁止値を数える]
$L=\Q(\sqrt2,\sqrt3)$ で $c=\sqrt2+\lambda\sqrt3$、$\lambda\in\Q$ とする。四つの埋め込みの像 $\pm\sqrt2\pm\lambda\sqrt3$ が一致する条件を調べる。同じ $\sqrt2$ の符号を持つ二つが一致するなら $\lambda=0$ である。異なる符号を持つものが一致するなら、$\sqrt3$ の項も異なる符号を持つ必要があり、$\lambda=\pm\sqrt{2/3}$ となる。これらは有理数でないので、任意の非零有理数 $\lambda$ について四像は異なる。よって $c$ の最小多項式は四次で、$c$ が $L$ を生成する。たとえば $\lambda=2$ なら $c^2=14+4\sqrt6$ なので最小多項式は $X^4-28X^2+100$ である。
:::

:::example[原始元の選択と相対的な生成]
$K=\F_2(s,t)$、$a^2=s$、$b^2=t$ とする。$L=K(a,b)$ は指数 $1$ の純非分離四次である。任意の $c\in L$ は $c^2\in K$ を満たすので $[K(c):K]\le2$ であり、原始元が存在しない。しかし $K(a)$ を基礎にすれば $L=K(a)(b)$ が単拡大である。単拡大にならないという結論は基礎体を固定した主張である。
:::

### 原始元を共役の表で確定する

原始元候補とその冪に対し、同じ埋め込みがいくつの像を与えるかを比較する。

:::example[共役の衝突を調べて原始元を求める]
$L=\Q(\sqrt{2},\sqrt{5})$ は四次であり、$c=\sqrt{2}+2\sqrt{5}$ とする。各平方根の符号を独立に選ぶと四つの埋め込みを得る。

| 符号 | $c$ の像 | $c^2$ の像 |
| --- | --- | --- |
| $\left( 1, \  1\right)$ | $\sqrt{2} + 2 \sqrt{5}$ | $4 \sqrt{10} + 22$ |
| $\left( 1, \  -1\right)$ | $- 2 \sqrt{5} + \sqrt{2}$ | $22 - 4 \sqrt{10}$ |
| $\left( -1, \  1\right)$ | $- \sqrt{2} + 2 \sqrt{5}$ | $22 - 4 \sqrt{10}$ |
| $\left( -1, \  -1\right)$ | $- 2 \sqrt{5} - \sqrt{2}$ | $4 \sqrt{10} + 22$ |

二つの値が一致すれば、平方根の符号の差を係数とする一次関係ができる。$\sqrt{2}$ と $\sqrt{5}$ の比は有理数でないため、両係数は零である。従って四つの像が相異なり、最小多項式は四次であり、$c$ が原始元になる。

$$
\begin{aligned}
m_{c,\Q}(X)&=X^{4} - 44 X^{2} + 324,\\
c(\sqrt{2}-2\sqrt{5})&=-18
\end{aligned}
$$

前者は共役の積を展開して得られる。後者により逆元を用いて元の二根を取り出せるので、生成体の等しさを次数以外からも確かめられる。一方 $c^2$ は表で二つの値しか持たないため、その元だけからは四次体を生成できない。
:::

## 演習問題

::::exercise{level=basic}
$\Q(\sqrt{11})/\Q$ の正規性と分離性を判定せよ。
:::solution
既約式 $X^2-11$ の二根は体に入り、異なる。分解体なので正規であり、標数 $0$ なので分離的である。
:::
::::

::::exercise{level=basic}
$\F_2[X]$ の $f=X^4+X^2+1$ が分離的か調べよ。
:::solution
$f'=0$ であり、$f=(X^2+X+1)^2$ である。したがって分離的でない。
:::
::::

::::exercise{level=basic}
$\Q(2^{1/5})/\Q$ の分離次数と正規性を求めよ。
:::solution
$X^5-2$ は $2$ で Eisenstein なので既約である。標数 $0$ なので分離次数は $5$ である。体は実数に含まれるが、式には非実根があるので正規でない。
:::
::::

::::exercise{level=basic}
$\F_2(t)/\F_2(t^2)$ の分離次数を求めよ。
:::solution
$t$ は $(X-t)^2=X^2-t^2$ の根であり、任意の基礎体上の埋め込みは唯一の根 $t$ に移す。よって分離次数は $1$ である。
:::
::::

::::exercise{level=advanced}
$\Q(\sqrt2,\sqrt5)$ の原始元として $\sqrt2+2\sqrt5$ を使えることを示せ。
:::solution
$\sqrt5\notin\Q(\sqrt2)$ である。実際、$5$ と $5/2$ はどちらも有理数の平方でない。そのため $X^2-5$ は $\Q(\sqrt2)$ 上の最小多項式であり、係数が有理数なので二つの平方根の符号を独立に選べる。得られる四つの像は、$\sqrt2$ と $2\sqrt5$ が非零で絶対値が異なるため相異なる。従って最小多項式の次数は少なくとも $4$ である。一方、二回の二次添加で全体の次数は $4$ なので、塔法則により $\sqrt2+2\sqrt5$ は全体を生成する。
:::
::::

::::exercise{level=advanced}
有限な分離拡大の中間体上でも全体は分離的であることを示せ。
:::solution
任意の元の中間体上の最小多項式は、基礎体上の最小多項式を割る。分離多項式の因子も重根を持たないので結論を得る。
:::
::::

::::exercise{level=advanced}
分離的かつ純非分離な代数拡大は自明であることを示せ。
:::solution
各元について最小多項式は $X^{p^e}-a$ を割り、根は一つしかない。一方、分離的なら次数と根の個数は等しい。したがって次数が $1$ であり、各元は基礎体に入る。
:::
::::

::::exercise{level=advanced}
正規性が塔で推移しない例を示せ。
:::solution
$\Q\subseteq\Q(\sqrt2)\subseteq\Q(2^{1/4})$ では、二段とも標数 $0$ の二次拡大であり、根 $\alpha$ を含めば二根の和が基礎体にあるので他方の根も含む。一方、全体は $X^4-2$ の非実根を含まないため正規でない。
:::
::::

::::quiz{answer="1" tol="0"}
$\F_3(t^{1/3})/\F_3(t)$ の分離次数はいくつか。
:::explanation
生成元の最小多項式は $X^3-t$ であり、標数 $3$ ではその根は一つである。単拡大の埋め込みの個数は $1$ となる。
:::

- [x] $\Q$
- [x] $\F_5$
- [ ] $\F_5(t)$

:::explanation

:::

$\Q$ 上の $X^3-2$ の分解体に成り立つ条件を選べ。

- [x] 分離的
- [ ] 次数 $3$

:::explanation
分解体なので正規で、標数 $0$ なので分離的である。実根の次数は $3$ だが、非実の三乗根を加えるため全次数は $6$ である。

$\Q(\sqrt2,\sqrt3)/\Q$ の分離次数を求めよ。

:::
