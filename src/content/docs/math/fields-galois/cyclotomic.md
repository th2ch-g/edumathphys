## この章の目標

- 円分多項式の整係数性と既約性を証明する。
- 円分体の群と部分体を計算する。
- Gauss 和から二次体を円分体に埋め込む。

## 1 の冪根と円分多項式

:::definition[原始冪根と円分多項式]{#def-gal-cyclotomic-polynomial}
$n$ を正整数とし、$\zeta_n=e^{2\pi i/n}$ とする。$1$ の $n$ 乗根で乗法位数が $n$ のものを原始 $n$ 乗根と呼ぶ。その全体を根とするモニック多項式
$$
\Phi_n(X)=\prod_{\substack{1\le a\le n\\(a,n)=1}}(X-\zeta_n^a)
$$
を :term[円分多項式]{en="cyclotomic polynomial" yomi="えんぶんたこうしき"} という。$(a,n)$ は最大公約数で、互いに素な剰余類の個数を $\varphi(n)$ と書く。
:::

:::proposition[整係数性と積公式]{#prop-gal-cyclotomic-product}
$\Phi_n\in\Z[X]$、$\deg\Phi_n=\varphi(n)$ であり、$X^n-1=\prod_{d\mid n}\Phi_d(X)$ が成り立つ。
:::

:::proof
$\zeta_n^a$ の位数は $n/(a,n)$ なので、全根を位数で分ければ積公式が得られる。次数は定義の因子の個数である。$d<n$ の $\Phi_d$ が整係数なら、積公式におけるそれらの積はモニックな整係数式である。$X^n-1$ をその積でモニック除法すると商と剰余は整数係数であり、複素係数での割り切れ方から剰余は零、商は $\Phi_n$ である。
:::

同じ積公式の各辺に Möbius 反転を適用すると $\Phi_n=\prod_{d\mid n}(X^d-1)^{\mu(n/d)}$ となる。各 $\Phi_j$ の指数が $\sum_{d:j\mid d\mid n}\mu(n/d)$ となるため、$j=n$ の項だけが残る。

:::example[素数冪]
$p$ を素数、$k\ge1$ とすると $\Phi_{p^k}=(X^{p^k}-1)/(X^{p^{k-1}}-1)=\sum_{j=0}^{p-1}X^{jp^{k-1}}$ である。例えば $\Phi_9=X^6+X^3+1$ である。
:::

:::example[互いに素な二つの素因数]
$\Phi_{12}=(X^{12}-1)(X^2-1)/((X^6-1)(X^4-1))=X^4-X^2+1$ である。最初の商を $X^6+1$ とし、残りの分母を $X^2+1$ に直せばこの結果を得る。
:::

### 約数で整理して円分多項式を計算する

積公式 $X^n-1=\prod_{d\mid n}\Phi_d(X)$ の両辺を、各約数 $e$ での同じ式と組み合わせると
$$
\Phi_n(X)=\prod_{d\mid n}(X^d-1)^{\mu(n/d)}
$$
となる。右辺における $\Phi_e$ の指数は $\sum_{e\mid d\mid n}\mu(n/d)$ であり、$e=n$ のときだけ $1$ になる。負の指数を含んでも、全体はこの計算で多項式に等しい。$n>1$ なら定数項は $1$ になる。実際、$X=0$ を代入すると $(-1)^{\sum_{d\mid n}\mu(n/d)}=1$ である。

:::example[十二次の根から四次式を得る]
$\Phi_{12}(X)$ は $(X^{12}-1)(X^2-1)/((X^6-1)(X^4-1))$ である。分母分子の共通因子を整理すると $(X^6+1)/(X^2+1)=X^4-X^2+1$ になる。次数 $4$ は $12$ と互いに素な指数 $1,5,7,11$ の個数と一致する。
:::

:::example[導手を二倍した式]
$n>1$ が奇数なら、$\zeta$ が原始 $n$ 乗根であるとき $-\zeta$ の位数は $2n$ である。逆に原始 $2n$ 乗根の負は位数 $n$ を持つ。$\varphi(n)$ は互いに素な指数を $a,-a$ の組にできるので偶数である。従って $\Phi_{2n}(X)=\Phi_n(-X)$ となる。例えば $\Phi_9=X^6+X^3+1$ から $\Phi_{18}=X^6-X^3+1$ を得る。
:::

### 積公式と反転を具体的に使う

約数の小さい順に円分式を得る手順と、Möbius 関数を使う一括計算を照合する。

:::example[約数格子から円分多項式を計算する]
$n=15$ とする。$X^n-1$ を、根の位数が等しいものごとにまとめる。各 $d\mid n$ について同じ操作を行い、既に得た真の約数の円分式を除いて $\Phi_d$ を得る。

| 約数 $d$ | $\Phi_d(X)$ | $\mu(n/d)$ |
| --- | --- | --- |
| 1 | $X - 1$ | 1 |
| 3 | $X^{2} + X + 1$ | -1 |
| 5 | $X^{4} + X^{3} + X^{2} + X + 1$ | -1 |
| 15 | $X^{8} - X^{7} + X^{5} - X^{4} + X^{3} - X + 1$ | 1 |

積の反転で、表の第三列が $1$ なら分子、$-1$ なら分母に対応する二項式を置く。零ならその約数からの寄与はない。

$$
\begin{aligned}
\Phi_{15}(X)&=\frac{\left(X - 1\right) \left(X^{15} - 1\right)}{\left(X^{3} - 1\right) \left(X^{5} - 1\right)},\\
\Phi_{15}(X)&=X^{8} - X^{7} + X^{5} - X^{4} + X^{3} - X + 1
\end{aligned}
$$

展開後の次数は $8$ で、$n$ と互いに素な剰余類の個数 $\varphi(15)=8$ と一致する。逆にすべての約数で得た式を掛けると $X^{15}-1$ に戻るので、位数の異なる根を重複して入れていないことも確かめられる。
:::

## 有理数体上の円分多項式の既約性

:::theorem[円分多項式の既約性]{#thm-gal-cyclotomic-irreducible}
任意の $n\ge1$ に対し $\Phi_n$ は $\Q[X]$ で既約である。
:::

:::proof
原始根 $\alpha$ を根に持つ $\Phi_n$ のモニック既約因子を $f$ とする。:ref[thm-ring-poly-ufd]{text="分数体上の因数分解定理"}で $f$ は整係数である。$p\nmid n$ の素数について $\alpha^p$ が同じ $f$ の根であることを示す。反対に別のモニック既約因子 $g$ の根なら、$f$ は $g(X^p)$ を割る。整係数のモニック除法により還元後も $\bar f\mid\bar g(X)^p$ であり、$\bar f,\bar g$ は共通の既約因子を持つ。ところが $fg$ は $X^n-1$ を割り、$X^n-1$ の $p$ での還元は導関数 $nX^{n-1}$ と互いに素である。共通因子は重複を生じるので矛盾する。

任意の正整数 $a$ が $n$ と互いに素なら、その素因子も $n$ を割らない。この議論を順に用いれば、$\alpha^a$ も $f$ の根である。よって原始根すべてが $f$ の根であり、$f=\Phi_n$ となる。
:::

:::example[五次の冪根]
$\Phi_5$ は次の別証でも既約と分かる。$\Phi_5(X+1)=X^4+5X^3+10X^2+10X+5$ は $5$ で Eisenstein の条件を満たす。
:::

:::example[標数を変える]
$\Phi_3=X^2+X+1$ は $\Q$ で既約だが、$\F_7$ では $(X-2)(X-4)$ である。$2,4$ の積が $1$、和が $6$ になるためである。既約性の定理で係数体を指定する理由がここにある。
:::

### 有限体での因子次数

:::proposition[有限体上の円分多項式]{#prop-gal-cyclotomic-mod-factor}
$q$ と $n$ が互いに素とする。$\Phi_n(X)$ を $\F_q[X]$ に移すと、全ての既約因子は同じ次数 $d$ を持つ。$d$ は $(\Z/n\Z)^\times$ における $q$ の位数であり、$n=1$ の場合は $d=1$ とする。
:::

:::proof
$X^n-1$ は標数が $n$ を割らないため単根からなり、根は位数 $n$ の巡回部分群をなす。:ref[prop-gal-cyclotomic-product] の積の恒等式を還元し、約数 $d'\mid n$ の小さい順に考える。$X^{d'}-1$ の根のうち、真の約数の多項式で既に現れた根を除くと位数 $d'$ の根が残る。従って $\Phi_n$ の根は位数がちょうど $n$ のものになる。Frobenius を $k$ 回適用すると $\zeta\mapsto\zeta^{q^k}$ であり、元に戻る条件が $q^k\equiv1\bmod n$ である。各既約因子の根は Frobenius の一軌道なので、全因子の次数は $d$ である。因子数は $\varphi(n)/d$ である。
:::

:::example[同じ多項式を二つの素数で還元する]
$n=5$ では $2$ の位数が $4$ なので $\Phi_5$ は $\F_2$ 上既約である。一方 $q=11$ では $11\equiv1\pmod5$ なので四つの一次式に分解する。実際、$\F_{11}$ で $3$ は位数 $5$ であり、その非自明な冪 $3,9,5,4$ が根になる。
:::

### 標数が添字を割る場合の還元

:::proposition[円分多項式の重複を伴う還元]{#prop-gal-cyclotomic-ramified-reduction}
素数 $p$ に対し $n=p^e m$、$e\ge1$、$p\nmid m$ とする。$\F_p[X]$ では $\overline{\Phi_n}=\overline{\Phi_m}^{\,p^{e-1}(p-1)}$ が成り立つ。
:::

:::proof
複素数体で $z^{p^e}$ の位数が $m$ となる根 $z$ の位数は $mp^j$（$0\le j\le e$）である。逆にこのような $z$ はすべて $\Phi_m(X^{p^e})$ の根であり、根は相異なる。従って $\Phi_m(X^{p^e})$ を $\Phi_m(X^{p^{e-1}})$ で割ると、位数 $mp^e$ の根に対応する $\Phi_{mp^e}(X)$ を得る。この積の等式を標数 $p$ に移すと、$\overline{\Phi_m}(X^{p^j})=\overline{\Phi_m}(X)^{p^j}$ である。分母に相当する因子はモニックで零にならないので、両辺から消去して結論を得る。
:::

有理数上で $f$ と $g$ が異なるモニック既約因子であっても、還元してから共通因子を持つ可能性はある。円分多項式の既約性の証明では、もし原始根 $a$ と $a^p$ が異なる因子に属せば、その共通因子が実際に現れることを示している。そこで $p\nmid n$ を使うと $X^n-1$ の導関数が $nX^{n-1}$ であり、定数項が非零なので互いに素である。従って共通因子の二重出現が矛盾になる。$p$ が $n$ を割るとこの矛盾は得られない。

:::example[還元後に同じ根へ合流する]
$\Phi_8=X^4+1$ は $X=Y+1$ と置き $2$ に関する Eisenstein を使って既約と分かる。ところが標数 $2$ では $X^4+1=(X+1)^4$ である。$8$ 乗根自体が $1$ 一種類になるので、標数 $2$ におけるこの式の根を位数 $8$ の元として扱えない。一方 $3$ では $3^2\equiv1\pmod8$、$3\not\equiv1\pmod8$ である。よって因子次数は $2$ で、計算すると
$$
X^4+1=(X^2+X+2)(X^2-X+2)
$$
となる。両二次式は判別式 $-7\equiv2$ が非平方なので既約である。
:::

## 円分体の Galois 群

:::theorem[円分体の群]{#thm-gal-cyclotomic-group}
$\Q(\zeta_n)$ を第 $n$ :term[円分体]{en="cyclotomic field" yomi="えんぶんたい"} という。$\Q(\zeta_n)/\Q$ は Galois 拡大で、$a\bmod n\mapsto(\zeta_n\mapsto\zeta_n^a)$ は $(\Z/n\Z)^\times$ と Galois 群の同型を与える。
:::

:::proof
$X^n-1$ の全根は $\zeta_n$ の冪であり、標数 $0$ で分離的なので Galois である。最小多項式が $\Phi_n$ なので埋め込みは $\zeta_n$ を任意の原始根へ送る。合成で冪指数が掛け合わされるため、対応は群同型である。
:::

一般に $K$ を体とし、標数が $0$ または $n$ と互いに素とする。このとき $X^n-1$ の分解体の中で根は位数 $n$ の有限乗法群をなし、:ref[thm-gal-finite-cyclic] により原始根 $\zeta$ が存在する。分解体は $K(\zeta)$ であり、係数を固定する自己同型は $\zeta$ を $\zeta^a$（$(a,n)=1$）に送る。従ってこの場合も Galois 群は $(\Z/n\Z)^\times$ に埋め込まれる。例えば $K\subseteq\C$ なら、:ref[thm-gal-compositum] によりその像は $\Q(\zeta_n)\cap K$ を固定する部分群である。$K$ が $\zeta_n$ を含めば群は自明になる。

:::example[群が巡回でない場合]
$n=8$ では単元は $1,3,5,7$ で、全員の平方が $1$ である。したがって群は $C_2\times C_2$ である。
:::

:::example[二つの表示で同じ体]
$n$ が奇数なら $\zeta_{2n}=-\zeta_n^{(n+1)/2}$ であり、逆に $\zeta_n=\zeta_{2n}^2$ である。例えば $\Q(\zeta_6)=\Q(\zeta_3)$ である。
:::

### 素数冪と単元群

中国式剰余定理により、$n=\prod_p p^{e_p}$ なら単元群は各 $(\Z/p^{e_p}\Z)^\times$ の直積である。実際、剰余環の直積表示で、逆元を持つ条件はすべての成分が逆元を持つことである。各素数冪の群は次の通りである。

:::proposition[素数冪を法とする単元群]{#prop-gal-cyclotomic-prime-power-units}
$e\ge1$ とする。$p$ が奇素数なら $(\Z/p^e\Z)^\times$ は位数 $p^{e-1}(p-1)$ の巡回群である。$p=2$ では $e=1$ のとき自明、$e=2$ のとき位数二の巡回群であり、$e\ge3$ では $-1$ と $5$ がそれぞれ位数 $2$ と $2^{e-2}$ の直積因子を生成する。
:::

:::proof
奇素数 $p$ では、$1+p$ の $p^j$ 乗は $1$ と法 $p^{j+1}$ で合同で、法 $p^{j+2}$ では合同でない。$j=0$ で明らかであり、$1+c p^{j+1}$（$p\nmid c$）の $p$ 乗を展開すると、一次の項が $cp^{j+2}$ になり、残る項は $p^{j+3}$ で割れる。従って $1+p$ の位数は $p^{e-1}$ である。一方、$\F_p^\times$ の生成元を持ち上げた単元 $g$ について、$g^{p^{e-1}}$ の位数は $p-1$ を割り、その法 $p$ の像も位数 $p-1$ なので、位数はちょうど $p-1$ である。二つの単元は可換で位数が互いに素だから、その積の位数が群全体の位数になる。

$p=2$ の場合、$5^{2^j}-1$ を割る最大の $2$ の冪は $2^{j+2}$ である。実際 $5^{2^j}\equiv1\pmod 4$ なので、$5^{2^{j+1}}-1=(5^{2^j}-1)(5^{2^j}+1)$ の第二因子は $2$ で割れ、$4$ では割れない。従って $5$ は $1\bmod4$ の単元全体を生成する。残りの単元は $-1$ を掛ければその群に入り、$-1$ 自身は $1\bmod4$ でないので直積が得られる。
:::

例えば $\Q(\zeta_{45})/\Q$ の群は位数 $6$ と $4$ の巡回群の直積である。$45=9\cdot5$ だからである。元の位数は $6,4$ の最小公倍数 $12$ を割るので、この位数 $24$ の群は巡回群ではない。

### 二つの円分体を合わせる

:::proposition[円分体の合成と共通部分]{#prop-gal-cyclotomic-intersection}
正整数 $m,n$ について $d=\gcd(m,n)$、$\ell=\operatorname{lcm}(m,n)$ とする。円分体 $\Q(\zeta_m),\Q(\zeta_n)$ の合成は $\Q(\zeta_\ell)$、共通部分は $\Q(\zeta_d)$ である。
:::

:::proof
$\zeta_m=\zeta_\ell^{\ell/m}$、$\zeta_n=\zeta_\ell^{\ell/n}$ である。指数 $\ell/m,\ell/n$ は互いに素なので Bézout 等式により $\zeta_\ell$ を二つの根の冪の積に書ける。したがって合成体は $\Q(\zeta_\ell)$ である。共通部分は $\Q(\zeta_d)$ を含む。一方、:ref[thm-gal-compositum] と塔法則により共通部分の次数は $\varphi(m)\varphi(n)/\varphi(\ell)$ である。$\ell,d$ の各素数に対する指数は $m,n$ の指数を大きい順に並べたものなので、素数冪ごとの $\varphi$ の積を取ると $\varphi(m)\varphi(n)=\varphi(\ell)\varphi(d)$ となる。したがって共通部分は $\Q(\zeta_d)$ と同じ次数を持ち、包含は等号である。
:::

:::example[共通部分の次数が二の場合]
$m=12,n=18$ なら $\ell=36,d=6$ である。次数はそれぞれ $4,6,12,2$ なので、合成は次数 $12$ で共通部分は次数 $2$ である。共通部分は $\Q(\zeta_6)=\Q(\sqrt{-3})$ である。
:::

:::example[互いに素な導手]
$\Q(\zeta_5)$ と $\Q(\zeta_8)$ の共通部分は $\Q$ である。合成体は次数 $16$ の $\Q(\zeta_{40})$ で、二つの円分体への制限を独立に指定できる。
:::

### 指数の合同で制限と固定体を読む

:::example[二つの円分体の同時作用]
$L=\Q(\zeta_{15})$ とする。$\zeta_{15}^5=\zeta_3$、$\zeta_{15}^3=\zeta_5$ を選べるので、$a\in(\Z/15\Z)^\times$ の二つの制限は $a\bmod3,a\bmod5$ である。例えば $a\equiv2\pmod3$、$a\equiv3\pmod5$ なら $a\equiv8\pmod{15}$ である。$a=8$ の位数は $\operatorname{lcm}(2,4)=4$ である。群全体は $C_2\times C_4$ であり、次数 $8$ でも位数 $8$ の元は存在しない。$\Q(\zeta_5)$ の固定群は $a\equiv1\pmod5$ を満たす $1,11$ の二元である。
:::

### 群の元の位数と制限を表にする

## 円分体の部分体と Gauss 周期

:::definition[Gauss 周期]{#def-gal-gauss-period}
$H\le(\Z/n\Z)^\times$ とし、単元 $a$ に対して $\eta_{aH}=\sum_{h\in H}\zeta_n^{ah}$ と置く。この元を :term[Gauss 周期]{en="Gauss period" yomi="がうすしゅうき"} という。$H$ に固定され、$\sigma_b$ は $\eta_{aH}$ を $\eta_{baH}$ に移す。
:::

:::proposition[素数導手の周期]{#prop-gal-gauss-period-generator}
$n=p$ が素数なら $\Q(\eta_H)=\Q(\zeta_p)^H$ である。
:::

:::proof
$\zeta_p,\dots,\zeta_p^{p-1}$ は $\Q$ 上一次独立である。その関係を表す多項式は次数が高々 $p-1$ かつ定数項が零なので、最小多項式 $\Phi_p$ の定数倍であるなら零しかない。よって異なる剰余類の周期は異なる。$\eta_H$ の固定部分群が $H$ そのものになり、:ref[thm-gal-correspondence] で結論が出る。
:::

同じ生成結果は $n$ が平方自由の場合にも成り立つ。実際、$n>1$ を相異なる素数 $p$ の積とし、Bézout 等式で $\sum_{p\mid n}c_p(n/p)=1$ とする。法 $p$ に移すと $c_p$ は単元であり、$\zeta_n^a=\prod_{p\mid n}\zeta_p^{ac_p}$ となる。$a$ が法 $n$ の単元を動くと、中国式剰余定理により指数 $ac_p\bmod p$ の組は各素数について独立に全非零剰余類を動く。各 $\Q(\zeta_p)$ は対応する原始根を基底に持つので、これらの積は :ref[prop-gal-compositum-degree-bound] により合成体 $\Q(\zeta_n)$ を張る。その個数は $\prod_{p\mid n}(p-1)=\varphi(n)$ だから基底になる。従って異なる剰余類の周期の差は零にならず、$\eta_H$ の固定部分群は $H$ である。$n=1$ のとき固定体は $\Q$ であり、結論は自明である。

:::example[最大実部分体]
$n\ge3$ とする。共役は $\zeta_n$ を $\zeta_n^{-1}$ に送るので、$\zeta_n+\zeta_n^{-1}$ は実元である。この元を $u$ とすれば $\zeta_n$ は $X^2-uX+1$ を満たし非実である。したがって $\Q(u)$ は指数 $2$ で、共役の固定体に一致する。$n=8$ では $u=\sqrt2$ である。
:::

:::example[周期から二次式を作る]
$p=5$、$H=\{1,4\}$ なら $\eta=\zeta_5+\zeta_5^4$ と $\eta'=\zeta_5^2+\zeta_5^3$ の和は $-1$ である。積を展開すると非自明な五乗根が一つずつ出るので $-1$ である。よって $\eta,\eta'$ は $X^2+X-1$ の根であり、固定体は $\Q(\sqrt5)$ となる。
:::

### Gauss 周期を掛けて最小多項式を求める

:::example[七乗根から実三次体を取り出す]
$u=\zeta_7+\zeta_7^{-1}$、$v=\zeta_7^2+\zeta_7^{-2}$、$w=\zeta_7^3+\zeta_7^{-3}$ とする。等比和から $u+v+w=-1$ である。積を展開し指数を $7$ で整理すると $uv=u+w$、$vw=u+v$、$wu=v+w$ となる。従って $uv+vw+wu=-2$ である。さらに $uvw=(u+w)w=wu+w^2$ であり、$w^2=2+u$ だから $uvw=1$ である。よって
$$
(X-u)(X-v)(X-w)=X^3+X^2-2X-1.
$$
三周期が相異なることは :ref[prop-gal-gauss-period-generator] の独立性から分かる。$u$ の固定群は $\{1,-1\}$ であり、この三次式は $u$ の最小多項式である。
:::

:::example[合成導手では周期が生成しない場合]
$n=8$、$H=\{1,5\}$ とする。$\zeta_8^5=-\zeta_8$ なので $\eta_H=0$ である。ところが $H$ の指数は二で、固定体は二次である。$\zeta_8^2=i$ が $H$ に固定され、$\Q(i)/\Q$ は二次なので、固定体は $\Q(i)$ である。素数導手の場合に使った冪の一次独立性が、ここでは $\zeta_8+\zeta_8^5=0$ のため成立しない。
:::

群の剰余類から生成元を作り、周期の最小多項式を求める。

## 二次体の円分体への埋め込みと Gauss 和

:::definition[二次 Gauss 和]{#def-gal-gauss-sum}
奇素数 $p$ に対し $\chi(0)=0$、非零平方で $\chi(a)=1$、それ以外で $\chi(a)=-1$ とする。巡回群 $\F_p^\times$ の平方の部分群は指数 $2$ なので $\chi$ は乗法的である。$\tau=\sum_{a\in\F_p}\chi(a)\zeta_p^a$ を :term[二次 Gauss 和]{en="quadratic Gauss sum" yomi="にじがうすわ"} という。
:::

:::theorem[Gauss 和の平方]{#thm-gal-gauss-square}
$\tau^2=\chi(-1)p=(-1)^{(p-1)/2}p$ であり、$a\in\F_p^\times$ に対して $\sigma_a(\tau)=\chi(a)\tau$ である。
:::

:::proof
指数を $b$ から $ab$ に置き換えると、$\sigma_a(\tau)=\chi(a^{-1})\tau=\chi(a)\tau$ である。特に複素共役は $\overline\tau=\chi(-1)\tau$ を与える。一方、
$$
\tau\overline\tau=\sum_{b\ne0}\sum_{t\in\F_p}\chi(t)\zeta_p^{b(t-1)}
$$
となる。これはもとの二重和で $a=bt$ としたものであり、$\chi(bt)\chi(b)=\chi(t)$ を用いた。和の順序を交換して $b$ に関する和を先に取ると $t=1$ のとき $p-1$、他の $t$ では $-1$ である。$\sum_t\chi(t)=0$ だから総和は $p-1+1=p$ となる。最後に $\F_p^\times$ の生成元を $g$ とすれば $-1=g^{(p-1)/2}$ かつ $\chi(g)=-1$ である。
:::

任意の二次体は平方自由整数 $d$ を使って $\Q(\sqrt d)$ と書ける。実際、二次の最小多項式の平方完成で、有理数の平方根を生成元にできる。分母の平方と分子の平方因子を外せば $d$ が得られる。各奇素因子 $p$ に対して上の Gauss 和を取り、$\sqrt2=\zeta_8+\zeta_8^{-1}$ と $i=\zeta_8^2$ で $2$ と符号を補正する。これらの積として $\sqrt d$ が得られるので、導手の候補として $8$ と奇素因子の積を取れば円分体への埋め込みが得られる。

:::example[負の平方根]
$p=3$ では $\tau=\zeta_3-\zeta_3^2$ であり、平方は $-3$ である。$\Q(\sqrt{-3})=\Q(\zeta_3)$ となる。
:::

:::example[複数の素因数]
$d=6$ では $\sqrt{-3}$ と $\sqrt2$ の積を $i$ で割ると $\sqrt6$ の一方の符号になる。したがって $\Q(\sqrt6)\subseteq\Q(\zeta_{24})$ である。
:::

### Gauss 和の還元と平方剰余

Gauss 和の平方が分かると、一つの素数を法とする平方剰余を、別の素数での Frobenius で調べられる。$p,q$ は異なる奇素数とし、$\chi_p(q)$ は $q$ の $p$ における二次指標である。

:::proposition[二次相互法則]{#prop-gal-quadratic-reciprocity}
$\chi_p(q)\chi_q(p)=(-1)^{(p-1)(q-1)/4}$ である。
:::

:::proof
標数 $q$ の代数閉包で位数 $p$ の根 $\xi$ を取る。実際 $q\nmid p$ なので $X^p-1$ は単根からなり、$1$ 以外の根は位数 $p$ を持つ。$T=\sum_a\chi_p(a)\xi^a$ と置く。:ref[thm-gal-gauss-square] の積の計算で用いるのは $\xi^p=1$ と $\xi\ne1$ による等比和だけなので、$\overline\tau$ の代わりに $\sum_a\chi_p(a)\xi^{-a}=\chi_p(-1)T$ を使えば
$$
T^2=(-1)^{(p-1)/2}p
$$
が標数 $q$ でも成り立つ。右辺は非零である。$q$ 乗を取ると係数は固定され、指数を $aq$ に置き換えるため $T^q=\chi_p(q)T$ である。従って
$$
\chi_p(q)=T^{q-1}
=\left((-1)^{(p-1)/2}p\right)^{(q-1)/2}
=(-1)^{(p-1)(q-1)/4}\chi_q(p).
$$
最後の等式は $\F_q^\times$ の巡回性から従う。生成元の指数が偶数か奇数かに応じて、$(q-1)/2$ 乗の値が $1,-1$ になるからである。標数 $q$ では $1,-1$ が異なるため、等式は整数の符号の等式にもなる。
:::

補充法則は $\chi_p(-1)=(-1)^{(p-1)/2}$ と $\chi_p(2)=(-1)^{(p^2-1)/8}$ である。前者は Gauss 和の平方の証明で得た。後者では標数 $p$ の代数閉包で原始八乗根 $\xi$ を取り、$r=\xi+\xi^{-1}$ と置く。$\xi^2+\xi^{-2}=0$ なので $r^2=2$ である。$p\equiv\pm1\pmod 8$ なら $r^p=r$、$p\equiv\pm3\pmod 8$ なら $\xi^3=-\xi^{-1}$ と $\xi^{-3}=-\xi$ から $r^p=-r$ となる。一方 $r^{p-1}=2^{(p-1)/2}=\chi_p(2)$ である。四つの剰余類で $(p^2-1)/8$ の偶奇を比べると同じ符号が得られる。

:::example[二つの奇素数]
$p=3,q=7$ では $7\equiv1\pmod3$ なので $\chi_3(7)=1$ である。両素数が $3\bmod4$ であるため、相互法則から $\chi_7(3)=-1$ となる。実際 $\F_7$ の非零平方は $1,2,4$ である。
:::

### 指標の核として二次部分体を求める

:::example[十一乗根の二次部分体]
$\F_{11}^\times$ の平方は $1,3,4,5,9$ である。$H$ をこれらの指数の群とすると、$2$ は非平方なので $\sigma_2$ は $H$ の周期とその補集合の周期を交換する。二周期の和は $-1$、差は $\tau$ なので、平方は $-11$ である。従って周期は $(-1\pm\sqrt{-11})/2$ で、その最小多項式は $X^2+X+3$ である。$H$ は巡回群の唯一の指数二部分群だから、$\Q(\sqrt{-11})$ はこの円分体の唯一の二次部分体である。
:::

:::example[二つの符号が相殺する二次体]
$3\equiv7\equiv3\pmod4$ なので、$\Q(\zeta_{21})$ は $\sqrt{-3},\sqrt{-7}$ を含む。二つを掛けると $\sqrt{21}$ の一方の符号が得られる。$a$ による作用は二次指標の積 $\chi_3(a)\chi_7(a)$ である。例えば $a=2$ のとき $2\bmod3$ は非平方、$2\bmod7$ は平方なので $\sqrt{21}$ の符号が反転する。一方 $a=-1$ では二つの符号がともに反転し、積が固定される。実二次体が現れることは複素共役の作用からも確認できる。
:::

### Gauss 和の平方を展開で検算する

相互法則に使った一般式を、素数ごとの指標の値から確認する。

:::example[二次 Gauss 和の平方を指数ごとに計算する]
$p=5$ で、指標 $\chi(a)$ は非零平方で $1$、非平方で $-1$ である。平方剰余は $\left( 1, \  4\right)$ である。Gauss 和を $X=\zeta_p$ で評価する前の多項式にすると次のようになる。

$$
S(X)=X^{4} - X^{3} - X^{2} + X
$$

平方を展開して $X^p=1$ でまとめると、指数 $j$ の係数は $\sum_a\chi(a)\chi(j-a)$ である。各指数について和を取った値を並べる。

| 指数 $j$ | 係数 |
| --- | --- |
| 0 | 4 |
| 1 | -1 |
| 2 | -1 |
| 3 | -1 |
| 4 | -1 |

$$
\begin{aligned}
S(X)^2&\equiv - X^{4} - X^{3} - X^{2} - X + 4\pmod{X^{5}-1},\\
S(\zeta_{5})^2&=5
\end{aligned}
$$

最後の等式では $\zeta_p+\cdots+\zeta_p^{4}=-1$ を使った。一般公式 $\chi(-1)p$ と一致し、$\Q(\sqrt{5})$ がこの円分体に入ると分かる。指数 $a$ の自己同型はこの平方根を $\chi(a)$ 倍する。
:::

## Kronecker–Weber の定理（主張）

:::theorem[Kronecker–Weber の定理]{#thm-gal-kronecker-weber}
$L/\Q$ が有限 Galois 拡大で $\operatorname{Gal}(L/\Q)$ が可換なら、ある $n\ge1$ について $L\subseteq\Q(\zeta_n)$ である。逆に円分体の任意の部分体は $\Q$ 上有限可換 Galois 拡大である。
:::

:::proof
円分体の部分体については :ref[thm-gal-cyclotomic-group] の群が可換であり、部分群がすべて正規なので :ref[thm-gal-normal-subgroup] を適用できる。順方向の一般の証明は、局所体での分岐と局所から大域への帰着を用いるため、証明は :cite[neukirch-ant]{loc="第 V 章 §1 定理 (1.10)"} を参照されたい。二次の場合は前節の Gauss 和で証明した。
:::

:::example[二つの二次体の合成]
$\Q(\sqrt2,\sqrt5)\subseteq\Q(\zeta_{40})$ である。両生成元はそれぞれ $\Q(\zeta_8)$ と $\Q(\zeta_5)$ に入り、$8,5$ が $40$ を割るためである。
:::

:::example[可換性が必要な理由]
$X^3-2$ の分解体の群は $S_3$ である。どの円分体の部分体も可換 Galois なので、この分解体は円分体に含まれない。
:::

### 有限可換拡大の最小の導手

:::proposition[最小の円分導手]{#prop-gal-minimal-cyclotomic-conductor}
有限可換 Galois 拡大 $E/\Q$ に対し、$E\subseteq\Q(\zeta_n)$ となる最小の正整数 $n$ を $E$ の :term[導手]{en="conductor" yomi="どうしゅ"} という。導手は同じ包含を満たすすべての $m$ を割る。
:::

:::proof
存在は :ref[thm-gal-kronecker-weber] から従う。$E$ が $n,m$ の両円分体に入れば、:ref[prop-gal-cyclotomic-intersection] により $E\subseteq\Q(\zeta_{\gcd(n,m)})$ である。最小性から $\gcd(n,m)=n$ となり、$n\mid m$ が従う。反対に $n\mid m$ なら $\zeta_n$ を $\zeta_m$ の冪として取れるため包含が成り立つ。
:::

:::example[二次体の導手を小さい候補から絞る]
$\Q(\sqrt2)$ は $\Q(\zeta_8)$ に入る。最小の導手は $8$ を割る。$\Q(\zeta_1)=\Q(\zeta_2)=\Q$ であり、$\Q(\zeta_4)=\Q(i)$ の実部分は $\Q$ である。これらは $\sqrt2$ を含まないため、最小の導手は $8$ である。また $\Q(\sqrt5)$ は $\Q(\zeta_5)$ に入り、$5$ の真の約数は $1$ なので導手は $5$ である。従って両者の合成体を含む円分体の導手は $8,5$ の両方の倍数であり、最小は $40$ になる。
:::

:::proposition[二次体の導手]{#prop-gal-quadratic-conductor}
$d\ne1$ を零でない平方自由整数とする。$\Q(\sqrt d)$ の導手は $d\equiv1\pmod 4$ なら $\abs{d}$、それ以外なら $4\abs{d}$ である。
:::

:::proof
$P$ を $\abs{d}$ の奇素因子の積とし、各奇素数に対して $p^*=(-1)^{(p-1)/2}p$ と置く。$d=(-1)^\epsilon 2^\beta\prod_{p\mid P}p^*$ と一意に書ける。ただし $\epsilon,\beta\in\{0,1\}$ である。$\sqrt d$ の一方の符号は $i^\epsilon(\sqrt2)^\beta\prod_{p\mid P}\tau_p$ で得られる。ここで $\tau_p$ は :ref[thm-gal-gauss-square] の Gauss 和である。従って含む円分体の添字として、$\beta=1$ なら $N=8P$、$\beta=0,\epsilon=1$ なら $N=4P$、両方零なら $N=P$ が使える。各 $p^*$ は $1\bmod4$ なので、この $N$ は命題の式に一致する。

導手は $N$ を割るので、$N$ から素因数を一つ除いた添字 $N/\ell$ の円分体に $\sqrt d$ が入らないことを示す。$\ell$ が奇素数なら、$\ell$ で非平方、$N/\ell$ で $1$ になる単元 $a\bmod N$ を中国式剰余定理で選ぶ。$\sigma_a$ は $\Q(\zeta_{N/\ell})$ を固定するが、Gauss 和の作用公式により $\tau_\ell$ だけの符号を変える。従って $\sqrt d$ はその円分体に入らない。

$N=4P$ なら、$a\equiv3\pmod4$、$a\equiv1\pmod P$ と取ると、$\sigma_a$ は $\Q(\zeta_{2P})$ を固定し、$i$ の符号を変える。$N=8P$ なら $a\equiv5\pmod8$、$a\equiv1\pmod P$ と取る。すると $\sigma_a$ は $\Q(\zeta_{4P})$ と $i$ を固定し、$\zeta_8+\zeta_8^{-1}=\sqrt2$ の符号を変える。こうして $N$ のどの素因数も除けず、導手は $N$ と決まる。
:::

### 円分体への包含から最小の導手を求める

二つの素数の二次指標を組み合わせ、候補の導手を絞る。

:::example[二つの二次指標を合成して導手を判定する]
$\Q(\zeta_{15})$ は $\sqrt{-3}$ と $\sqrt{5}$ を含む。各平方根は $3$ と $5$ の Gauss 和から得られる。従って積を取ると $\sqrt{-15}$ が入り、その作用は二つの指標の積になる。

| 指数 $k$ | $\chi_p(k)$ | $\chi_q(k)$ | 積 |
| --- | --- | --- | --- |
| 1 | 1 | 1 | 1 |
| 2 | -1 | -1 | 1 |
| 4 | 1 | 1 | 1 |
| 7 | 1 | -1 | -1 |
| 8 | -1 | -1 | 1 |
| 11 | -1 | 1 | -1 |
| 13 | 1 | -1 | -1 |
| 14 | -1 | 1 | -1 |

表で積が $1$ となる行の指数が固定群であり、半数の $4$ 元が該当する。ゆえに固定体は $\Q(\sqrt{-15})$ である。導手の最小性を調べると、候補は $n=15$ の約数であり、真の約数は $1,3,5$ である。

$3$ の円分体の唯一の二次体は $\Q(\sqrt{-3})$ である。$5$ の円分体でも同様に $\Q(\sqrt{5})$ である。平方類 $-15$ はいずれとも異なるため、求める二次体はどちらにも含まれない。従って最小の導手は $15$ である。

この例では大きい円分体に入ることを Gauss 和で構成し、真の約数の候補を固定群から除いた。包含の証明と最小性の証明はこの二段階になる。
:::

## 演習問題

::::exercise{level=basic}
$\Phi_8$ を求めよ。

:::solution
$\Phi_8=(X^8-1)/(X^4-1)=X^4+1$ である。
:::
::::

::::exercise{level=basic}
$[\Q(\zeta_{15}):\Q]$ を求めよ。

:::solution
$15$ 個の剰余類から $3$ または $5$ の倍数を除くと $15-5-3+1=8$ 個なので次数は $8$ である。
:::
::::

::::exercise{level=basic}
$\Q(\zeta_7)$ の複素共役を単元で表せ。

:::solution
$\zeta_7$ を逆元に送るので $-1\equiv6\pmod7$ である。
:::
::::

::::exercise{level=basic}
$\Phi_6$ を求めよ。

:::solution
原始六乗根は原始三乗根の負である。$\Phi_3(-X)=X^2-X+1$ である。
:::
::::

::::exercise{level=advanced}
$\Q(\zeta_{11})$ の二次部分体を求めよ。

:::solution
群は $\F_{11}^\times$ で位数 $10$ の巡回群である。指数 $2$ の部分群は一つで、Gauss 和は平方 $-11$ を持つ。したがって $\Q(\sqrt{-11})$ が唯一の二次体である。
:::
::::

::::exercise{level=advanced}
$\Q(\zeta_5)$ の最大実部分体の次数を求めよ。

:::solution
共役の位数が $2$ なので $4/2=2$ である。周期の例では $\Q(\sqrt5)$ に一致する。
:::
::::

::::exercise{level=advanced}
$\Q(i,\sqrt5)$ を含む円分体を一つ求めよ。

:::solution
$i=\zeta_{20}^5$ であり、$\zeta_{20}^4=\zeta_5$ である。Gauss 和による $\sqrt5$ の表示があるので $\Q(\zeta_{20})$ が使える。
:::
::::

::::exercise{level=advanced}
$n\ge3$ の $\Phi_n$ が定数項 $1$ を持つことを示せ。

:::solution
逆元で原始根を対にすると両根の積は $1$ である。原始根は $\pm1$ でないから各対は異なる元を持ち、対応する二次因子の定数項は $1$ である。
:::
::::
