## この章の目標

- 冪根による可解性を群の可解性で判定する。
- 三次・四次の解法を分解式から導く。
- 一般五次と具体的な五次式の非可解性を示す。

## 冪根拡大と冪根による可解性

以下では標数 $0$ とし、拡大は共通の代数閉包で取る。解の公式で加減乗除と冪根を繰り返すには、一回の冪根ごとにその値を係数として使える体を作る。

:::definition[冪根の塔]{#def-gal-radical-tower}
$K=K_0\subseteq\cdots\subseteq K_r$ の各段が $K_i=K_{i-1}(b_i)$、$b_i^{n_i}\in K_{i-1}$、$n_i\ge2$ と書けるとき、$K_r/K$ を :term[冪根拡大]{en="radical extension" yomi="べきこんかくだい"} と呼び、この列を冪根の塔という。非零多項式の全根がこのような塔の上端に入るとき、その多項式は :term[冪根で可解]{en="solvable by radicals" yomi="べきこんでかかい"} である。
:::

:::example[二次式]
$X^2+bX+c=0$ を $(2X+b)^2=b^2-4c$ に直せば、必要な添加は $\sqrt{b^2-4c}$ だけである。例えば $X^2-X-1$ では $\sqrt5$ を添加する。
:::

:::example[一根と全根]
$X^3-2$ は実根 $2^{1/3}$ のほかに非実根二つを持つ。$i\sqrt3=\sqrt{-3}$ を添加すると $\omega=(-1+\sqrt{-3})/2$ が得られ、$\omega^j2^{1/3}$ の三根全てが塔に入る。
:::

### 一段の冪根添加と多段の冪根添加

冪根の塔では次の段の右辺に、その時点で得た元を使える。例えば $\sqrt{1+\sqrt2}$ はまず $\sqrt2$ を添加し、次に $1+\sqrt2$ の平方根を添加して得る。$b=\sqrt{1+\sqrt2}$ がこの塔の最上段を生成するのは、$b^2-1=\sqrt2$ だからである。基礎体の元の冪根だけを一度に並べる操作は、塔の定義より強い制約を課す。

:::example[平方根を重ねて得る四次体]
$b=\sqrt{1+\sqrt2}$ に対し $b^4-2b^2-1=0$ である。$1+\sqrt2$ が $\Q(\sqrt2)$ で平方だとすると、二次体のノルムが有理数の平方になる。しかし $N(1+\sqrt2)=(1+\sqrt2)(1-\sqrt2)=-1$ なので不可能である。従って上段も二次で、この四次式は最小多項式である。もう一方の二根は $\pm\sqrt{1-\sqrt2}$ であり、$b$ と掛けて平方すると $-1$ になる。従って $\Q(b,i)$ が四根を含む。
:::

### 平方根の塔を計算で確かめる

前の段の元を次の段の右辺にして、二次添加が本当に必要かをノルムで調べる。

:::example[二段の平方根とその正規閉包を追う]
$d=2$、$b^2=1+2\sqrt{2}$ とし、$b$ を正の実根とする。まず $\Q(\sqrt{2})$ を作り、次に $1+2\sqrt{2}$ の平方根を添加する。下の体のノルムは $1^2-2\cdot 2^2=-7$ である。負の有理数は平方でなく、平方元のノルムは有理数の平方であるため、上の段は真の二次である。

$$
\begin{aligned}
\sqrt{2}&=\frac{b^2-1}{2},\\
f(X)&=(X^2-1)^2-8=X^{4} - 2 X^{2} - 7
\end{aligned}
$$

生成元 $b$ の体に下の平方根が戻るので、四次の関係式は最小多項式である。残る根の平方はもとの右辺の共役である。これに対する平方根 $c$ を求める。

$$
\begin{aligned}
b^2c^2&=(1+2\sqrt{2})(1-2\sqrt{2})=-7,\\
c&=\frac{\sqrt{-7}}{b}
\end{aligned}
$$

従って $\Q(b,\sqrt{-7})$ が全根を含む。逆に全根を持てば $bc$ を通して $\sqrt{-7}$ が入る。$\Q(b)$ は実の体で第二の平方根は非実なので、分解体の次数は $8$ である。冪根の塔を作るとき、途中の生成元と全ての根を収める段を分けて考えられる。
:::

## 冪根で解ける方程式の Galois 群は可解群

群の可解性は :ref[def-grp-solvable] の意味で用いる。冪根の塔そのものが正規である必要はない。そこで各段を、基礎体上の共役も含む Galois 拡大で覆う。

:::theorem[冪根可解性の必要条件]{#thm-gal-radical-necessity}
標数 $0$ で、冪根で可解な多項式の分解体の Galois 群は可解群である。
:::

:::proof
冪根指数 $n_i$ の最小公倍数を $N$ とし、まず $E_0=K(\mu_N)$ を取る。これは分離分解体であり、その群は冪指数への作用により $(\Z/N\Z)^\times$ の部分群で可換である。$E_{i-1}$ が $K_{i-1}$ を含み $K$ 上 Galois として、$a_i=b_i^{n_i}$ の全ての $K$ 共役 $g(a_i)$（$g\in\operatorname{Gal}(E_{i-1}/K)$）の $n_i$ 乗根を添加して $E_i$ を作る。$a_i=0$ なら添加は不要である。$E_i$ は $K_i$ を含み、$K$ 埋め込みは $E_{i-1}$ を保ち、全共役の根の集合を置換するので正規である。標数 $0$ なので分離的である。

$\operatorname{Gal}(E_i/E_{i-1})$ の元は、各生成根をその根の $\mu_{n_i}$ 倍に移す。根ごとの倍率を並べると、可換群 $\prod\mu_{n_i}$ への単射が得られる。倍率は下の体にあるので、自己同型を合成すると根ごとに倍率が掛け合わされ、単射は群準同型である。制限の完全列と :ref[thm-grp-solvable-extension] を各段で適用すると $\operatorname{Gal}(E_r/K)$ は可解である。元の分解体は $E_r$ の正規中間体なので、その群は可解群の商であり可解である。
:::

:::example[二つの段の違い]
$K=\Q$ とする。$X^3-2$ では $K(\mu_3)$ の群は $C_2$、その上の群は $C_3$ である。全体の $S_3$ は可換でないが、二段の商が可換なので可解である。
:::

:::example[四乗根の分解体]
$X^4-2$ では $E_0=\Q(i)$、次に $2^{1/4}$ を加える。上段は $C_4$、下段は $C_2$ で、全体の $D_4$ は可解である。
:::

### 正規閉包を作るときに共役を揃える

$K$ が全ての必要な冪根を含む場合でも、途中の右辺 $a_j$ が $K$ にあるとは限らない。下の段の埋め込み $\sigma$ によって、$X^m-a_j$ は $X^m-\sigma(a_j)$ に移る。このため正規な上位体を作るには、各共役の右辺に対する根を添加する必要がある。

:::example[共役な二つの右辺が等価な場合]
$K=\Q$、$a=1+\sqrt2$、$a'=1-\sqrt2$ とする。$aa'=-1$ なので $b^2=a$ を添加した後、$i$ があれば $i/b$ が $a'$ の平方根になる。このことから $\Q(b,i)$ は前節の四次式の分解体である。$b$ は実数で次数四、$i$ は $\Q(b)$ にないので分解体の次数は八である。$b\mapsto i/b$ は $\Q(b)$ の埋め込みを定め、$i^2+1=0$ が $\Q(b)$ 上の最小多項式なので $i\mapsto-i$ として分解体の自己同型 $r$ に延長できる。$r^2(b)=-b$、$r^2(i)=i$ であり $r$ の位数は四である。複素共役を $s$ とすると $srs(b)=-i/b=r^{-1}(b)$、$srs(i)=-i=r^{-1}(i)$ となる。$s$ は $b$ を固定する非自明元だが、$r$ の非自明な冪はいずれも $b$ を動かす。従って $r,s$ が位数八の全群を生成し、この群は二面体群 $D_4$ である。
:::

### 全根を同時に収めて可解群を確かめる

冪根の右辺が有理数にある場合は、必要な円分部分を先に用意する。

:::example[素数次の冪根拡大を円分体の上で正規にする]
$f=X^{3}-7$ の実根を $a=7^{1/3}$ とする。$X^{3}-7$ は $7$ で Eisenstein だから、$\Q(a)$ は $3$ 次である。分解体 $L$ は $\Q(a,\zeta_{3})$ であり、円分部分の次数は $2$ である。二つの次数は互いに素なので $[L:\Q]=6$ となる。

各自己同型が $a\mapsto\zeta^u a$、$\zeta\mapsto\zeta^v$ とすると、根 $\zeta^j a$ の指数は $u+vj$ に移る。ここで $v\in(\Z/3\Z)^\times$、$u\in\Z/3\Z$ である。可能な対の個数が次数と一致するため、全ての対が実現する。

$$
\begin{aligned}
(u,v)(u',v')&=(u+vu',vv'),\\
\operatorname{Gal}(L/\Q(\zeta))&=\{(u,1):u\in\Z/3\Z\}
\end{aligned}
$$

右側の群は位数 $3$ の平行移動群である。商は乗数 $v$ の群で位数 $2$ であり、例えば $v=2$ が生成元である。次の表でその冪が非零の指数を巡る。

| 指数 | $v^j$ の剰余 |
| --- | --- |
| 0 | 1 |
| 1 | 2 |

核と商はいずれも巡回だから全群は可解である。また $\zeta_{3}$ は $1$ の $3$ 乗根、$a$ は $7$ の $3$ 乗根である。群の判定と冪根の塔を、この例では両方向から確認できる。
:::

## 可解な Galois 群をもつ方程式の冪根による解法

:::theorem[冪根可解性の十分条件]{#thm-gal-radical-sufficiency}
標数 $0$ で、分解体の Galois 群が可解なら多項式は冪根で可解である。
:::

:::proof
分解体を $L/K$ とし、$N$ を群の位数とする。$N=1$ なら全根が既に $K$ に属する。$N>1$ なら $F=K(\mu_N)$ は原始 $N$ 乗根を $1$ の冪根として加える段である。:ref[thm-gal-compositum] から $LF/F$ の群は元の可解群の部分群である。可解群の導来列の各商は有限可換であり、有限可換群の部分群列を選ぶと各商を素数位数の巡回群に分けられる。この列を逆像で持ち上げると、各段が直前の部分群に正規な列になる。

有限 Galois 対応で逆順の体の塔を得る。その各段は素数次 $\ell$ の巡回拡大であり、$\ell$ は $N$ を割る。したがって基礎体に $\mu_\ell$ があり、:ref[thm-gal-cyclic-radical] により各段は一つの冪根で生成される。末尾 $LF$ は $L$ を含む。
:::

:::example[三次の巡回群]
巡回三次拡大は $\zeta_3$ を加えた後に高々一回の立方根添加で得られる。例えば $X^3-3X+1$ は有理根の候補 $1,-1$ のどちらも根に持たないので既約である。判別式は $81$ で平方だから、その推移的な Galois 群は $A_3$ となる。
:::

:::example[可換な群]
双二次体で $G=C_2\times C_2$ なら位数 $2$ の部分群を一つ選ぶことで二つの二次段になる。例えば $\Q\subset\Q(\sqrt2)\subset\Q(\sqrt2,\sqrt3)$ である。
:::

### 群の列から中間体の列へ戻す

部分正規列 $G=G_0\supseteq G_1\supseteq\cdots\supseteq G_s=1$ を使うとき、必要な正規性は $G_{j+1}\triangleleft G_j$ である。それにより $L^{G_{j+1}}/L^{G_j}$ が Galois となる。$G_{j+1}$ が $G$ 全体で正規である必要はない。商を素数位数の巡回群にできれば、適切な冪根を含む基礎体の上で各段に Kummer 理論を使える。

:::example[三次式の分解体の塔]
$f=X^3-5$ の分解体 $L$ の群は $S_3$ である。$S_3\supset A_3\supset1$ から $\Q\subset\Q(\omega)\subset L$ を得る。最初の段は $\omega=(-1+\sqrt{-3})/2$ から平方根で作れ、第二段は $\sqrt[3]5$ の添加である。$\Q(\sqrt[3]5)$ を途中に置く塔でも根を得られるが、その三次段は正規でない。固定体を $A_3$ で選ぶと、全根を含む段が巡回三次になる。
:::

## 3 次・4 次方程式の解の公式の Galois 理論的導出

変数を $X=Y-b/n$ と置けば、モニック $n$ 次式の $X^{n-1}$ の係数 $b$ を消せる。減次した三次式の根を $x_0,x_1,x_2$ とし、$\omega$ を原始三乗根とする。:ref[prop-gal-resolvent-transform] の等比和による反転をここでは三根の添字に使う。根の和が零なので、$u=\frac13\sum_j\omega^{-j}x_j$、$v=\frac13\sum_j\omega^j x_j$ とおけば $x_j=\omega^j u+\omega^{-j}v$ である。

添字の三巡回は $u,v$ をそれぞれ $\omega,\omega^{-1}$ 倍し、その三乗を固定する。$x_1$ と $x_2$ の交換は $u^3,v^3$ を入れ替える。従って $u^3,v^3$ の和と積は対称式として係数から求まる。具体的に二元積の和は $-3uv=p$、三元の積は $u^3+v^3=-q$ である。これで $u^3,v^3$ を根に持つ二次式が決まる。

:::proposition[Cardano の解法]{#prop-gal-cardano}
$X^3+pX+q=0$ で $p\ne0$ とする。$U,V$ を $Z^2+qZ-p^3/27$ の根とし、$u^3=U$、$v=-p/(3u)$ と置くと、$\omega^j u+\omega^{-j}v$（$j=0,1,2$）が重複度込みの根である。
:::

:::proof
積 $UV=-p^3/27$ は非零であり、$v^3=V$ となる。三つの候補の和は零、二元積の和は $-3uv=p$、全積は $u^3+v^3=-q$ である。後者は $(u+v)(u^2-uv+v^2)$ の積で確かめられる。したがって候補から構成したモニック多項式は元の式である。$p=0$ の場合は $X^3=-q$ を直接解く。$u,v$ の立方根を独立に選ぶと $uv=-p/3$ を壊し得るので、一方の選択から他方を計算する。
:::

:::example[整数になる立方根]
$X^3-6X-9$ では $U,V$ は $8,1$ である。$u=2$ を選ぶと $v=1$ となり、一根 $3$ と残りの $2\omega+\omega^2,2\omega^2+\omega$ が得られる。
:::

四次では三次分解式の根が四根の対分割に対応する。例えば $(x_1,x_2)$ と $(x_3,x_4)$ に分け、対ごとの積を $t=x_1x_2$、$w=x_3x_4$ とする。根の総和が零なので、二因子の積は $(X^2+sX+t)(X^2-sX+w)$ と書ける。係数を比べると $p=t+w-s^2$、$q=s(w-t)$、$r=tw$ である。$Y=t+w$ は対の選び方を保つ置換に固定され、三つの対分割から :ref[def-gal-cubic-resolvent]{text="三次分解式"} の三根が得られる。$m=(t+w)/2$ と置けば、因子の積を平方差にできる。

:::proposition[Ferrari の解法]{#prop-gal-ferrari}
$X^4+pX^2+qX+r$ で $q\ne0$ とする。$(2m-p)(m^2-r)=q^2/4$ の根 $m$ を取り、$s^2=2m-p$ とすれば
$$
X^4+pX^2+qX+r=(X^2+m)^2-(sX-q/(2s))^2
$$
である。したがって三次式と二次式で解ける。
:::

:::proof
$q\ne0$ なので $s$ は非零である。右辺の $X^2$ と $X$ の係数は $2m-s^2=p$ と $q$ になり、定数項は $m^2-q^2/(4s^2)=r$ である。平方差の二因子はモニック二次なので各々に二次公式を使う。$q=0$ なら $Y=X^2$ による二次式を解く。ここで $Y=2m$ と置くと $Y^3-pY^2-4rY+4pr-q^2=0$ になり、:ref[def-gal-cubic-resolvent] の三次式に一致する。
:::

:::example[平方差を作る]
$X^4+X^2+2X$ では $m=1,s=1$ が使える。$(X^2+1)^2-(X-1)^2$ なので $(X^2-X+2)(X^2+X)$ となり、根は $0,-1,(1\pm\sqrt{-7})/2$ である。
:::

### 根の選択と分解式の符号

:::example[三つの実根を持つ三次式]
$f=X^3-3X+1$ では $p=-3,q=1$ で、Cardano の二つの立方の値は $(-1\pm i\sqrt3)/2$ である。$u$ を一方の立方根に選び、$v=1/u$ と置くと $uv=-p/3=1$ を保つ。$u^3v^3=1$ なので $v^3$ はもう片方の値である。$u^3$ は絶対値 $1$ だから $v=\bar u$ であり、$u+v$ は実数である。$u$ を $\omega u$ と $\omega^2u$ に変えれば $v$ は逆の因子で変わり、三根が得られる。判別式は $81>0$ であるが、公式の途中では非実数を使う。
:::

:::proposition[三つの実根を持つ既約三次式と実冪根]{#prop-gal-casus-irreducibilis}
$K\subseteq\R$ 上の既約三次式が相異なる三実根を持つとき、その根は、各段で実数の冪根だけを添加する塔には入らない。この場合を :term[還元不能の場合]{en="casus irreducibilis" yomi="かんげんふのうのばあい"} という。
:::

:::proof
実数の冪根を添加する各段は、指数を素因数に分け、元の根の適切な冪を順に加えることで素数指数の段に分けられる。実部分体 $F$ の上で実数 $b\ne0$ が $b^\ell\in F$ を満たすとする。$\ell$ が素数で $b\notin F$ なら $[F(b):F]=\ell$ である。実際、最小多項式の次数を $d$ とすると、その根は $b$ の $\ell$ 乗根倍である。定数項は符号を除いて $b^d$ とある $\ell$ 乗根の積であり、実数なのでその $\ell$ 乗根は $\pm1$ のいずれかである。よって $b^d\in F$ である。$d<\ell$ なら $\gcd(d,\ell)=1$ から $b\in F$ となってしまう。

元の三次式が初めて可約になる段を $F\subset F(b)$ とする。三次式なのでそこで一根を持ち、それまで既約だったのでその根の $F$ 上の次数は三である。従って $\ell=3$ となり、その根が $F(b)$ を生成する。この三次式の三根が実なので、$F(b)$ から $\R$ への $F$ 埋め込みは三つある。一方 $b$ の最小多項式 $X^3-b^3$ は実根を一つしか持たないので、その埋め込みは一つである。矛盾から、そのような段は存在しない。
:::

:::example[四次の分解式で平方の差を作る]
$f=X^4-5X^2+6$ とする。$f=(X^2-5/2)^2-1/4$ であるため $X^2-5/2=\pm1/2$ となり、根は $\pm\sqrt2,\pm\sqrt3$ である。Ferrari の平方差を作る操作は、$X$ の一次項がないときにこの平方完成へ帰着する。一方 $X^4-X-1$ では二次の式を二乗しただけでは一次項を再現できないため、二乗同士の差にして一次項を作る。分解式の根を見つけた後に二次式を解く段を区別すると、どこで三乗根が必要になるか分かる。
:::

### 三次と四次の解法を減次から実行する

最初の平行移動を戻すまで、各段の式を明示する。

:::example[減次と立方根の組を順に決める]
$P(X)=X^{3} + 3 X^{2} - 3 X - 14$ を解く。$X=Y-(1)$ と置くと三次の二次項が消える。定数項と一次項を読み直すと以下の式になる。

$$
\begin{aligned}
P(Y-(1))&=Y^{3} - 6 Y - 9,\\
U+V&=-(-9),\qquad UV=-\frac{(-6)^3}{27}
\end{aligned}
$$

二つの数は二次式の根として求める。ここでは立方根の値を二つ独立に選ばず、片方を選んでから積の条件で他方を決める。

$$
\begin{aligned}
U&=8,\qquad V=1,\\

## 一般 n 次方程式と対称式

:::theorem[対称式の基本定理]{#thm-gal-symmetric-polynomials}
$K[x_1,\ldots,x_n]$ の対称多項式は基本対称式 $s_1,\ldots,s_n$ の多項式として一意に書ける。対称有理関数全体は $K(s_1,\ldots,s_n)$ である。
:::

:::proof
斉次成分ごとに辞書式順序を使う。対称多項式の最大単項式の指数列 $\lambda_1,\dots,\lambda_n$ は降順である。逆順の対があれば交換でより大きな項が現れるからである。$\lambda_{n+1}=0$ とし、$\prod_i s_i^{\lambda_i-\lambda_{i+1}}$ を作ると最大単項式が一致する。同じ先頭係数を掛けて引けば、同次数のより小さい項だけが残る。同次数の単項式は有限なので手続きは停止する。一意性は :ref[thm-gal-generic-symmetric] の独立性で従う。有理関数については同定理の固定体が $K(s_1,\ldots,s_n)$ であるため従う。
:::

:::example[平方和]
$x_1^2+x_2^2+x_3^2=s_1^2-2s_2$ である。例えば $(1,2,3)$ なら $36-22=14$ になる。
:::

:::example[三乗和]
$\sum_i x_i^3=s_1^3-3s_1s_2+3s_3$ である。積を展開すると $x_i^2x_j$ の項が消え、三変数の積の係数も $6-9+3=0$ になる。$(1,2,3)$ なら $216-198+18=36$ である。
:::

:::proposition[交代式の分解]{#prop-gal-alternating-polynomials}
標数 $2$ 以外で、変数の互換で符号が変わる多項式を :term[交代式]{en="alternating polynomial" yomi="こうたいしき"} と呼ぶ。任意の交代式は $\prod_{i<j}(x_i-x_j)$ と対称多項式の積に一意に書ける。
:::

:::proof
交代式 $P$ に $x_i=x_j$ を代入すると、その値は自分の負に等しく零になる。$x_i$ を変数とする除法により $x_i-x_j$ は $P$ を割る。全ての対についてこれらは互いに同伴でない素因子なので、その積 $V$ も $P$ を割る。$V$ は互換で符号が変わるため、商 $P/V$ は各互換に固定される。互換は対称群を生成するので商は対称多項式であり、整域で $V\ne0$ なので一意である。
:::

### 冪和と係数を相互に求める

:::proposition[Newton の恒等式]{#prop-gal-newton-identities}
$s_0=1$、$s_k=0$（$k>n$）とし、$P_j=\sum_i x_i^j$ と置く。$k\ge1$ について
$$
P_k-s_1P_{k-1}+s_2P_{k-2}-\cdots+(-1)^{k-1}s_{k-1}P_1+(-1)^k k s_k=0
$$
である。
:::

:::proof
$F(T)=\prod_i(1-x_iT)=\sum_j(-1)^j s_jT^j$ とする。定数項が $1$ なので形式冪級数環で逆元を持つ。積を微分して $-F'(T)/F(T)=\sum_i x_i/(1-x_iT)=\sum_{j\ge1}P_jT^{j-1}$ となる。両辺に $F(T)$ を掛け、$T^{k-1}$ の係数を比較すると主張を得る。
:::

:::example[根を求めずに四乗和を出す]
$X^3-6X-9$ の根では $s_1=0,\ s_2=-6,\ s_3=9$ である。従って $P_1=0,\ P_2=12,\ P_3=27$ となる。$k=4$ では $s_4=0$ なので $P_4=-s_2P_2+s_3P_1=72$ である。方程式 $x_i^3=6x_i+9$ に $x_i$ を掛けて総和を取っても同じ値になる。
:::

:::remark
標数 $0$ なら各整数 $k$ で割れるので冪和から基本対称式も順に復元できる。標数が $k$ を割るとき、この復元には同じ式を使えない。一方、式自体は整数係数の多項式恒等式なのでそのまま成り立つ。
:::

### 対称式の計算に必要な係数体

:::example[Newton の恒等式で割れない場合]
標数 $2$ で二変数 $x,y$ を取る。第一冪和は $p_1=x+y$、第二冪和は $p_2=x^2+y^2=p_1^2$ である。恒等式 $p_2-s_1p_1+2s_2=0$ では $2s_2=0$ になる。そのため $p_1,p_2$ から $xy$ を復元できない。実際 $\F_4$ で $x=u,y=u+1$ とし $u^2+u+1=0$ とすれば $p_1=p_2=1$、$xy=1$ であるが、$(x,y)=(0,1)$ も同じ冪和を持ち $xy=0$ である。基本対称式による生成の定理は標数を問わないが、最初の冪和から基本対称式へ戻す手順には標数の条件がある。
:::

### 対称式の係数を冪和から復元する

既に得た基本対称式を次の式へ代入する。次数が根の数を超えた後の使い方も確かめる。

:::example[Newton の恒等式を下の次数から解く]
$\left( 1, \  2, \  3\right)$ を根とするモニック式について、冪和 $P_j$ から基本対称式を求める。冪和は各根を同じ指数で累乗して足す。次に $s_1,s_2,\ldots$ の順に Newton の恒等式を解く。

| 添字 $j$ | $P_j$ | 既知の項の和 | 求めた $s_j$ |
| --- | --- | --- | --- |
| 1 | 6 | 6 | 6 |
| 2 | 14 | -22 | 11 |
| 3 | 36 | 18 | 6 |

例えば第三列は $P_j-s_1P_{j-1}+\cdots+(-1)^{j-1}s_{j-1}P_1$ の値である。その値を $(-1)^{j+1}$ 倍して $j$ で割ると $s_j$ になる。係数の符号は交互なので、次の式に戻せる。

$$
\begin{aligned}
\prod_i(X-x_i)&=X^{3} - 6 X^{2} + 11 X - 6,\\
P_{5}&=276
\end{aligned}
$$

$j=5$ は根の個数 $3$ を超えるから $s_j=0$ であり、今度はこの式を $P_j$ に関して解ける。すなわちそれ以前の冪和と $s_i$ から高い冪和を再帰できる。根を直接累乗して足した値も同じ $276$ である。
:::

$\left( 1, \  1, \  2, \  4\right)$ を根とするモニック式について、冪和 $P_j$ から基本対称式を求める。冪和は各根を同じ指数で累乗して足す。次に $s_1,s_2,\ldots$ の順に Newton の恒等式を解く。

| 添字 $j$ | $P_j$ | 既知の項の和 | 求めた $s_j$ |
| --- | --- | --- | --- |
| 1 | 8 | 8 | 8 |
| 2 | 22 | -42 | 21 |
| 3 | 74 | 66 | 22 |
| 4 | 274 | -32 | 8 |

例えば第三列は $P_j-s_1P_{j-1}+\cdots+(-1)^{j-1}s_{j-1}P_1$ の値である。その値を $(-1)^{j+1}$ 倍して $j$ で割ると $s_j$ になる。係数の符号は交互なので、次の式に戻せる。

$$
\begin{aligned}
\prod_i(X-x_i)&=X^{4} - 8 X^{3} + 21 X^{2} - 22 X + 8,\\
P_{7}&=16514
\end{aligned}
$$

$j=7$ は根の個数 $4$ を超えるから $s_j=0$ であり、今度はこの式を $P_j$ に関して解ける。すなわちそれ以前の冪和と $s_i$ から高い冪和を再帰できる。根を直接累乗して足した値も同じ $16514$ である。
:::

## 5 次以上の一般方程式の非可解性

:::theorem[一般方程式の冪根による非可解性]{#thm-gal-abel-ruffini}
標数 $0$ で $n\ge5$ とする。独立な不定元を係数とする一般モニック $n$ 次式は、その係数体上冪根で可解でない。
:::

:::proof
:ref[thm-gal-generic-symmetric] で一般式の Galois 群は $S_n$ である。:ref[thm-grp-alternating-simple] により $A_n$ は非可換単純である。よって交換子群は非自明な正規部分群なので $A_n$ 全体に等しく、導来列は単位群に達しない。$S_n$ の可解性は部分群の可解性を含意するため $S_n$ も可解でない。:ref[thm-gal-radical-necessity] を適用する。
:::

:::example[五次式で解ける場合]
$X^5-2$ の根は $\zeta_5^j2^{1/5}$ であり、明示的な冪根の塔に入る。一般式の主張は、任意の個別の五次式についての非可解性を意味しない。
:::

:::example[六次式で解ける場合]
$X^6-5X^3+6=(X^3-2)(X^3-3)$ では二つの立方根と共通の $\zeta_3$ を加えればよい。次数が六でも、係数の特殊な関係で三次式に分けられる。
:::

### 一般式と特殊化に対する二つの主張

一般五次式の基礎体は五つの独立な係数が生成する有理関数体である。この体上で全根を冪根で表せないという主張は、すべての有理数係数への特殊化で不可能という主張を含まない。例えば $X^5-2$ の全根は $2^{1/5}$ と $\zeta_5$ から得られる。$\zeta_5$ は $1$ の五乗根として冪根の塔で添加できる。従って次数が五であってもこの式は可解である。正規閉包では群が $\zeta_5$ の像を決めた後に $2^{1/5}$ の像を選ぶ構造を持ち、二つの段の巡回性が可解性と両立する。

### 高次の一般式で残る障害を追う

一般式では根の独立性を仮定している。その仮定の下で、少数の根に作用する部分群が非可解性を与える。

:::example[高次の一般方程式に残る非可換な部分]
$n=5$ とし、独立な $x_1,\ldots,x_5$ の一般多項式を考える。係数を固定したまま根を置換すると $S_5$ が作用する。特に最初の五根だけに作用する $A_5$ が部分群に入る。

$$
\begin{aligned}
a&=(1\,2\,3),\qquad b=(3\,4\,5),\\
a b a^{-1} b^{-1}&=(1\,4\,3)
\end{aligned}
$$

交換子が恒等でないので、この部分群は可換でない。また交代群の単純性により、その交換子部分群は非自明な正規部分群として $A_5$ 自身である。従って導来列は自明群に達しない。

可解群の任意の部分群は可解である。実際、部分群の各導来群は全群の同じ段の導来群に含まれる。よって $S_5$ も可解でない。群が可解でないことを一般式に戻すと、係数の有理関数を基礎にした冪根の塔の中に全根を入れることはできない。
:::

## 冪根で解けない具体的な 5 次方程式

:::proposition[具体的な非可解五次式]{#prop-gal-unsolvable-quintic}
$f=X^5-4X+2\in\Q[X]$ は冪根で可解でない。
:::

:::proof
$2$ に関する Eisenstein の判定法で既約である。$f(-2)=-22,\ f(-1)=5,\ f(0)=2,\ f(1)=-1,\ f(2)=26$ より三つの互いに素な区間 $(-2,-1),(0,1),(1,2)$ に実根がある。導関数 $5X^4-4$ の実根は二つである。もし四つ以上の実根があれば Rolle の定理で導関数の実根が三つ以上になるので、実根はちょうど三つである。複素共役は残る二根を交換する互換であり、既約性から根への作用は推移的である。:ref[prop-gal-prime-transposition] で群は $S_5$ であり、可解群でない。
:::

:::example[別の判定法の読み取り方]
五次既約式の分離的な還元が次数 $2,3$ の因子に分かれる場合、:ref[thm-gal-dedekind] で得た元を三乗すると互換になる。したがって実根を数えずに $S_5$ と判定できる場合もある。
:::

:::example[既約性だけでは決まらない]
$X^5-2$ も $2$ で Eisenstein だが、根の体は $\Q(\zeta_5,2^{1/5})$ で次数は高々 $20$ である。そのため、推移性はあっても位数 $120$ の $S_5$ にはならない。
:::

### 可解な素数次方程式の根への作用

:::proposition[可解な素数次の推移群]{#prop-gal-solvable-prime-action}
素数 $p$ に対し、$p$ 点に推移的に作用する置換群 $G$ について、次の三条件は同値である。

- $G$ は可解である。
- 点を $\F_p$ で添字付けると、$G$ の全ての作用を $x\mapsto ax+b$（$a\ne0$）と書ける。
- 相異なる二点を固定する元は恒等写像だけである。
:::

:::proof
$G$ が可解なら、その導来列の最後の非自明な群 $A$ は可換かつ $G$ の正規部分群である。$G$ は $A$ の軌道を置換するので、推移性から全軌道の大きさが同じである。$p$ が素数であり、$A$ は非自明な置換群だから、軌道は一つである。可換な推移群のある一点を固定する元は、その点から他の点へ移す全ての元と可換なので全点を固定する。よって $A$ の点固定群は自明であり、$|A|=p$ である。

$A$ の生成元 $\tau$ を取り、一点を $0$ として $\tau^j(0)$ に $j\in\F_p$ を対応させる。正規性から $g\tau g^{-1}=\tau^a$（$a\ne0$）である。$g(0)=b$ なら $g(\tau^j(0))=\tau^{aj}(b)$ となり、所望の表示が得られる。この形の写像が相異なる二点を固定すれば $a=1,b=0$ である。

逆に二点を同時に固定する非自明元がないなら、点固定群は残り $p-1$ 点に自由に作用する。従ってその位数 $d$ は $p-1$ を割り、$|G|=pd$ である。Sylow の定理により Sylow $p$ 部分群の個数は $d$ を割り $1\bmod p$ なので一つである。この正規な部分群は位数 $p$ の巡回群であり、非自明な元は $p$ 巡回だから推移的に作用する。先と同じ添字付けにより $G$ は $x\mapsto ax+b$ の群に含まれる。この群は平行移動の核と $\F_p^\times$ の商がともに可換なので可解であり、$G$ も可解である。
:::

実部分体上の既約な素数次式が二つ以上の実根と非実根を持つとき、複素共役は二点を固定する非自明元である。従ってその式は冪根で可解でない。例えば :ref[prop-gal-unsolvable-quintic] では、こうして Galois 群を同定せずとも非可解性を示せる。

### 一根だけを求める場合

:::corollary[既約式の一根と全根]{#cor-gal-one-radical-root}
標数 $0$ の既約多項式 $f$ の一根がある冪根の塔に属するなら、$f$ は冪根で可解である。
:::

:::proof
:ref[thm-gal-radical-necessity] の証明で作った Galois 拡大は、元の冪根の塔の上端を含み、その群は可解である。一根が入れば正規性により他の全根も入る。従って $f$ の分解体の群は可解群の商であり、:ref[thm-gal-radical-sufficiency] により $f$ は冪根で可解である。
:::

例えば :ref[prop-gal-unsolvable-quintic] の式は既約であるため、三つの実根のどれについても有理数から冪根の塔では到達できない。可約式では因子ごとにこの議論を適用する。例えば $(X-1)(X^5-4X+2)$ は根 $1$ を有理数として持つが、五次因子の根は冪根では求められない。

### 一つの素数で失敗しても他の素数を調べる

:::example[根の数だけでは巡回型が決まらない]
五次式を $\F_p$ に還元し一次因子がないとする。この時点では既約な五次の場合と、既約二次と既約三次の積の場合が残る。後者なら三乗で互換を得る。前者は五巡回を与え、モニック整係数式であれば有理数上の既約性も示す。二つの型は同じ「一次根なし」の条件を満たすため、二次因子があるかを $X^{p^2}-X$ との最大公約式で判定する。因子が重複しないことは導関数との最大公約式で別に調べる。
:::

### 還元から五次式の非可解性を証明する

五次式の係数を固定し、一つずつ既約性と互換の存在を検査する。

ここで使う五次還元の既約性は、:ref[thm-gal-finite-frobenius] の有限体の構造から確認できる。可約な五次式には次数 $1$ または $2$ の既約因子がある。そのような因子は $\F_{p^2}$ で分解するので $X^{p^2}-X$ を割る。逆に $X^{p^2}-X$ の既約因子の次数は $2$ を割る。従って $X^{p^2}-X$ を還元式で割った剰余との最大公約式が $1$ なら、五次式は既約である。

| 五次式 | 素数 $p$ | $X^{p^2}-X$ を還元式で割った剰余 | 最大公約式 |
| --- | --- | --- | --- |
| $X^5-3X+1$ | $7$ | $-3X^4+X^3+2X+3$ | $1$ |
| $X^5-X-3$ | $5$ | $1$ | $1$ |
| $X^5-X+1$ | $3$ | $-X^4-1$ | $1$ |
| $X^5-X+2$ | $3$ | $X^4+1$ | $1$ |

例えば最後の行では、還元式から剰余の $X$ 倍を引くと $X+2$ になる。さらに $X^4+1$ の $X=1$ での値は $2\ne0$ なので最大公約式は $1$ である。分解型 $(2,3)$ の行では、表示した二次・三次因子がそれぞれ $\F_p$ に根を持たないことを調べれば、両因子の既約性が分かる。

:::example[具体的な五次式が冪根で解けないことを証明する]
$f=X^{5} - 3 X + 1$ を考える。まず $7$ と $2$ での分解を比べる。重根がある素数は巡回型の判定に使えないため、同時に導関数との最大公約式を調べる。

| 素数 | 還元の既約因子 | 最大公約式 | 巡回型 |
| --- | --- | --- | --- |
| 7 | $\left(X^{5} - 3 X + 1\right)$ | $1$ | $\left( 5,\right)$ |
| 2 | $\left(X^{2} + X + 1\right)\left(X^{3} + X^{2} + 1\right)$ | $1$ | $\left( 2, \  3\right)$ |

$7$ での還元は五次既約だから $f$ は有理数上既約で、群は五点で推移的である。$2$ での因子次数 $\left( 2, \  3\right)$ により、単独の長さ二の巡回を含む元を得る。その元の三乗を取れば、長さ二の巡回だけが残る。

素数次の互換の判定で群は $S_5$ になる。$A_5$ が非可解な部分群であるため、もとの多項式は冪根で可解でない。さらに一根が冪根の塔に入るなら、その塔を可解群の Galois 拡大で覆って全共役も入れられる。そのため、この既約式には冪根で表せる根が一つもない。

ここで還元は二種類の役割を持つ。既約な行で有理数上の推移性を示し、別の行で群を小さくできない理由を示した。
:::

:::example[具体的な五次式が冪根で解けないことを証明する]
$f=X^{5} - X + 2$ を考える。まず $3$ と $13$ での分解を比べる。重根がある素数は巡回型の判定に使えないため、同時に導関数との最大公約式を調べる。

| 素数 | 還元の既約因子 | 最大公約式 | 巡回型 |
| --- | --- | --- | --- |
| 3 | $\left(X^{5} - X - 1\right)$ | $1$ | $\left( 5,\right)$ |
| 13 | $\left(X^{2} + X + 3\right)\left(X^{3} - X^{2} - 2 X + 5\right)$ | $1$ | $\left( 2, \  3\right)$ |

$3$ での還元は五次既約だから $f$ は有理数上既約で、群は五点で推移的である。$13$ での因子次数 $\left( 2, \  3\right)$ により、単独の長さ二の巡回を含む元を得る。その元の三乗を取れば、長さ二の巡回だけが残る。

素数次の互換の判定で群は $S_5$ になる。$A_5$ が非可解な部分群であるため、もとの多項式は冪根で可解でない。さらに一根が冪根の塔に入るなら、その塔を可解群の Galois 拡大で覆って全共役も入れられる。そのため、この既約式には冪根で表せる根が一つもない。

ここで還元は二種類の役割を持つ。既約な行で有理数上の推移性を示し、別の行で群を小さくできない理由を示した。
:::

## 演習問題

::::exercise{level=basic}
$X^2-6X+2$ の根を冪根で求めよ。

:::solution
平方完成で $(X-3)^2=7$ なので $3\pm\sqrt7$ である。
:::
::::

::::exercise{level=basic}
$X^3-6X-9$ に対する Cardano の二次式を求めよ。

:::solution
$p=-6,q=-9$ なので $Z^2-9Z+8=(Z-8)(Z-1)$ である。
:::
::::

::::exercise{level=basic}
$X^4-5X^2+4$ を解け。

:::solution
$X^2=Y$ と置くと $(Y-1)(Y-4)=0$ なので根は $\pm1,\pm2$ である。
:::
::::

::::exercise{level=basic}
$\sum_{i<j}x_ix_j$ はどの基本対称式か。

:::solution
二つずつ異なる変数を選んだ積の和なので $s_2$ である。
:::
::::

::::exercise{level=advanced}
$S_3$ が可解であることを列で示せ。

:::solution
$1\triangleleft A_3\triangleleft S_3$ の商は順に $C_3,C_2$ なので可解である。
:::
::::

::::exercise{level=advanced}
$X^5-4X+2$ に対し $\Q$ 上の既約性と実根の個数を求めよ。

:::solution
$2$ が全非最高次係数を割り、$4$ は定数項 $2$ を割らない。導関数は二実根だけを持ち、値の符号から $(-2,-1),(0,1),(1,2)$ に各一根がある。Rolle の定理による上界と一致するので実根は三つである。
:::
::::

::::exercise{level=advanced}
$X^6-5X^3+6$ の全根を列挙せよ。

:::solution
$X^3=2,3$ に分かれるため、$\omega^j2^{1/3},\omega^j3^{1/3}$（$j=0,1,2$）である。
:::
::::

::::exercise{level=advanced}
標数 $0$ の既約三次式で、一根が冪根の塔に属するとき全根もある冪根の塔に属することを示せ。

:::solution
その根を $a$ とする。塔の終端で元の式をモニックにし、$X-a$ で割ると二次式になる。その判別式の平方根を追加すれば残りの二根が得られる。
:::
::::

::::quiz{answer="120" tol="0"}
$X^5-4X+2$ の分解体の次数を求めよ。

:::explanation
群は $S_5$ であり、位数は $5!=120$ である。

::::quiz
$X^5-2$ について正しいものを選べ。

- [x] 冪根で可解である。
- [ ] 五次なので必ず冪根で可解でない。
- [ ] 有理根を持つ。

:::explanation
根は $\zeta_5^j2^{1/5}$ である。$2$ で Eisenstein なので有理根はない。
:::
::::

::::quiz{answer="2" tol="0"}
$X^4-5X^2+4$ の正の実根はいくつあるか。

:::explanation
$X^2=1,4$ より正の根は $1,2$ である。
:::
::::

::::quiz
標数 $0$ で冪根による可解性と同値な条件を選べ。

- [x] 分解体の Galois 群が可解群である。
- [ ] 分解体の Galois 群が必ず巡回群である。
- [ ] 根がすべて実数である。

:::explanation
冪根の塔から可換な商を持つ群の列ができ、逆に可解群の列から巡回段を作って冪根を添加できる。
:::
::::

::::quiz{answer="42" tol="0"}
$X^7-2$ の有理数体上の分解体の次数を求めよ。

:::explanation
一根を添加した体の次数は Eisenstein により $7$。原始七乗根を添加した円分体は $6$ 次で、二つの次数は互いに素である。全根はこの合成体で得られ、逆に根の比から原始七乗根を得るため分解体の次数は $7\cdot6=42$ である。
:::
