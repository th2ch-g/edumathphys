## この章の目標

- 埋め込みの延長を生成元の像として記述する。
- 多項式の分解体を構成して次数を見積もる。
- 任意の体の代数閉包を構成する。
- 一意性の主張と延長の選択を区別する。

## 体の埋め込みと共役

:::definition[埋め込みと共役]{#def-gal-embeddings}
単位元を保つ体準同型を :term[体の埋め込み]{en="field embedding" yomi="たいのうめこみ"} という。核は真のイデアルであり、体の真のイデアルは零のみなので単射である。共通の拡大体の中で $K$ 上代数的な二元の最小多項式が等しいとき、互いに $K$ 上 :term[共役]{en="conjugate" yomi="きょうやく"} であるという。
:::

:::lemma[単拡大における延長]{#lem-gal-extend-simple}
$\sigma:K\to\Omega$ を埋め込みとし、$\alpha$ を $K$ 上代数的とする。$\sigma$ を延長する埋め込み $K(\alpha)\to\Omega$ は $\sigma m_{\alpha,K}$ の $\Omega$ における相異なる根と一対一に対応する。
:::

:::proof
$0=m_{\alpha,K}(\alpha)$ の像は $(\sigma m_{\alpha,K})(\tau\alpha)$ なので、延長 $\tau$ は $\alpha$ を指定の根に写す。逆に根 $\beta$ に対し、係数に $\sigma$ を施して $X$ に $\beta$ を代入する写像は $(m_{\alpha,K})$ を消す。:ref[thm-gal-simple-extension] により商から体準同型が得られる。$1$ が $1$ に移るので、これは埋め込みである。一意性は多項式表示による。
:::

:::corollary[有限拡大の埋め込み数の上界]{#cor-gal-finite-embedding-bound}
有限拡大 $L/K$ と埋め込み $\sigma:K\to\Omega$ に対し、$\sigma$ の $L$ への延長 $L\to\Omega$ は高々 $[L:K]$ 通りである。
:::

:::proof
有限個の生成元を一つずつ添加する塔を取る。各段で既に決めた埋め込みの延長数は、係数を移した最小多項式の根の数であり、その次数を超えない。各段の上界を掛けると塔法則で $[L:K]$ になる。途中で根が見つからない場合、その選択からは延長が得られない。
:::

:::example[共役の行き先]
$X^3-2$ の根は実根 $a=2^{1/3}$ と $\omega a,\omega^2a$ である。ただし $\omega^2+\omega+1=0$、$\omega\ne1$ とした。したがって $\Q(a)\to\C$ は三通りあるが、$\Q(a)\to\R$ は一通りである。
:::

:::example[係数も動く場合]
$\sqrt2\mapsto-\sqrt2$ で $\Q(\sqrt2)$ を写すと $X^2-\sqrt2$ は $X^2+\sqrt2$ になる。延長は $2^{1/4}$ を $\pm i2^{1/4}$ のどちらかに移す。係数の像を取ってから根を選ぶ必要がある。
:::

### 生成元を指定するときの整合性

単拡大の延長補題では、像を根として選べば全体の写像が決まる。生成元が複数あるときは、一つ目を選んだあとに係数体を更新する。次の選択の自由度は、元の基礎体上の最小多項式の次数でなく、更新した体上の多項式で決まる。

:::example[二つの像を独立には選べない場合]
$a=\sqrt2$、$b=\sqrt8$ とする。$a$ の共役は $\pm a$、$b$ の共役は $\pm b$ である。しかし $b=2a$ なので、$a$ を $-a$ に送る埋め込みは必ず $b$ を $-b$ に送る。$a$ の像を選んだ後では、$b$ の最小多項式は $X-2a$ であり、その係数を移すと $X+2a$ になる。したがって四通りの符号の組のうち、同じ符号を選ぶ二通りだけが実現する。
:::

:::example[行き先を実数に制限した塔]
$a=2^{1/4}$ を正とする。$\Q(a)$ の埋め込みを $\Q(a^2)=\Q(\sqrt2)$ に制限すると、$a^2\mapsto \sqrt2$ と $a^2\mapsto-\sqrt2$ の二つが候補である。第一の場合、延長には $X^2-\sqrt2$ の根 $a,-a$ が使える。第二の場合、候補の式は $X^2+\sqrt2$ である。実数にはその根がないので、第二の埋め込みは $\R$ を終域とする延長を持たない。終域を $\C$ に変えると $ia,-ia$ が使える。
:::

:::proposition[超越的な元の像]{#prop-gal-extend-transcendental}
$\sigma:K\to\Omega$ を埋め込み、$t$ を $K$ 上超越的な元とする。$\sigma$ の $K(t)$ から $\Omega$ への延長は、$\sigma(K)$ 上超越的な $\Omega$ の元と一対一に対応する。
:::

:::proof
延長が $t$ を $u$ に送るとする。仮に $u$ を消す非零の $\sigma(K)$ 係数の式があれば、各係数を $K$ に戻した多項式の $t$ での値は非零であるが、その像は零となる。埋め込みの単射性に反する。逆に超越的な $u$ を指定すれば、$K[t]$ の非零多項式は係数を移してから代入しても消えない。従って $\frac{A(t)}{B(t)}\mapsto\frac{(\sigma A)(u)}{(\sigma B)(u)}$ が定義できる。分数の等しさは交差積で判定できるので表示には依存せず、体の演算を保つ。生成元の値で全体が決まるので一意である。
:::

:::example[超越的な像と全射性]
不定元 $t$ について $\Q(t)\to\Q(t)$、$t\mapsto t^2$ は埋め込みである。像は $\Q(t^2)$ であり、$t$ がそこに入らないことは、$t\mapsto-t$ が $t^2$ を固定する一方で $t$ を固定しないことから分かる。従って定義域と終域が同じでも、無限次元では埋め込みが自己同型とは限らない。
:::

### 像を選ぶ順番と根の関係

複数の生成元から、埋め込みがどの値を取るかを表にする。積の像は二つの因子の像で決まる。

$a^2=r,b^2=s$、$z=Aa+Bb+Cab$ とする。$a$ の符号 $\epsilon$ を固定し、$b$ の二つの符号に対応する因子を先に掛けると
$$
(X-A\epsilon a)^2-s(B+C\epsilon a)^2
=X^2+D-2\epsilon a(AX+sBC),\qquad D=A^2r-s(B^2+C^2r)
$$
となる。次に $\epsilon=1,-1$ の式を掛ければ、軌道積は $(X^2+D)^2-4r(AX+sBC)^2$ である。

まず $a$ の像を選ぶ。$b$ の最小多項式の係数は有理数なので、どちらの像を選んでも $b$ の像は独立に選べる。ただし積 $ab$ の像は、それらの積と一致しなければならない。

| --- | --- | --- |

| $\left( 1, \  -1\right)$ | $- \sqrt{10}$ | $- 2 \sqrt{5} - \sqrt{10} + \sqrt{2}$ |
| $\left( -1, \  1\right)$ | $- \sqrt{10}$ | $- \sqrt{10} - \sqrt{2} + 2 \sqrt{5}$ |

## 分解体の存在

:::definition[分解体]{#def-gal-splitting-field}
非零多項式 $f\in K[X]$ が拡大体 $L$ 上で一次式の積に分解し、かつ $L$ がその根すべてで生成されるとき、$L$ を $f$ の :term[分解体]{en="splitting field" yomi="ぶんかいたい"} という。非零定数の分解体は $K$ とする。
:::

:::theorem[分解体の構成と次数の上界]{#thm-gal-splitting-exists}
非零多項式の分解体は存在する。次数 $d$ の多項式の分解体 $L/K$ は有限であり、$[L:K]\le d!$ である。
:::

:::proof
$d=0$ は定義による。$d>0$ なら既約因子 $g$ を取り、$K_1=K[X]/(g)$ に根 $\alpha=[X]$ を作る。商が体であるのは多項式の互除法で非零類の逆元を作れるためである。$f=(X-\alpha)f_1$ と割って、帰納法で $K_1$ 上の $f_1$ の分解体 $L$ を取る。$K_1=K(\alpha)$ そのものなので $L$ は $K$ と $f$ の根全体で生成される。$[K_1:K]=\deg g\le d$、$[L:K_1]\le(d-1)!$ であり、塔法則から評価を得る。
:::

:::example[三次式の分解体]
$X^3-2$ の分解体は $\Q(a,\omega)$ である。すべての根を含む体には $(\omega a)/a=\omega$ が入る。逆に三根はこの体に入る。$\Q(a)$ は実数の部分体なので非実根 $\omega$ は含まない。よって $[\Q(a,\omega):\Q]=2\cdot3=6$ である。
:::

:::example[重根を含む多項式]
$\F_2[T]$ の分数体上で $X^2-T$ の根を $u$ とすると、$X^2-T=(X-u)^2$ である。$T$ は有理関数の平方にならない。実際、$T$ の指数は $1$ であり、平方の分子・分母から求めた指数は偶数である。よって分解体の次数は $2$ で、相異なる根は一つである。
:::

### 根の添加を一段で済ませられる場合

根の間に恒等式があると、定義の上では全根を添加する構成でも、実際には少数の根だけで生成できる。分解体の計算では「候補の体が全根を含む」ことと「候補の生成元が根から復元できる」ことの二方向を分けると確実である。

:::example[四次式が二つの二次式に分かれる]
$X^4+4=(X^2-2X+2)(X^2+2X+2)$ である。実際、右辺は $(X^2+2)^2-(2X)^2$ となる。根は $1\pm i,-1\pm i$ なので $\Q(i)$ が全根を含む。さらに一根から $i$ を差し引きで復元できるので、分解体は $\Q(i)$ である。四次の多項式であっても分解体の次数は二次で済む。
:::

:::example[平方の関係を先に利用する]
$X^4+X^2+1=(X^2+X+1)(X^2-X+1)$ である。第一因子の根を $\omega,\omega^2$ とすれば、第二因子の根は $-\omega,-\omega^2$ である。したがって分解体は $\Q(\omega)$ であり、次数は $2$ である。別の計算では $(X^2-1)(X^4+X^2+1)=X^6-1$ であるため、$1,-1$ 以外の六乗根の体を探せばよい。
:::

:::proposition[共通の上位体における分解体]{#prop-gal-splitting-in-overfield}
非零多項式 $f\in K[X]$ が拡大体 $\Omega/K$ で一次式の積に分解するなら、$\Omega$ 内での $f$ の分解体は一意な部分体である。有限個の非零式がすべて $\Omega$ で分解するとき、それらを同時に分解する最小の部分体は、個々の分解体の合成体である。
:::

:::proof
$\Omega$ 内で $f$ が分解する任意の部分体には、$\Omega$ での全根が入る。実際、その部分体の一次因子の根を並べれば $\Omega$ における分解になり、積が零になる点はその一次因子の根に尽きる。そのため根で生成される体が最小である。複数の式については根集合の和集合で生成するので、個別の生成体をすべて含む最小の体が得られる。
:::

### 二項式を分解するときに必要な根

:::proposition[二項式の分解体]{#prop-gal-binomial-splitting}
$a\in K^\times$、$n\ge1$ とし、分解体を含む拡大で $\alpha^n=a$ とする。$1$ の $n$ 乗根全体を $\mu_n$ とすれば $X^n-a$ の分解体は $K(\alpha,\mu_n)$ である。標数 $p>0$ で $n=p^e m$、$p\nmid m$ の場合には $K(\alpha,\mu_m)$ である。
:::

:::proof
非零の根 $\alpha$ を一つ固定すると、$\beta$ が根であることと $\beta/\alpha$ が $1$ の $n$ 乗根であることは同値である。よって根はすべて $K(\alpha,\mu_n)$ に入り、反対に任意の $\zeta\in\mu_n$ は根の比 $(\alpha\zeta)/\alpha$ で復元できる。正標数では $Y^n-1=(Y^m-1)^{p^e}$ なので、相異なる根の集合は $\mu_m$ に等しい。この場合も同じ生成体が得られる。
:::

:::example[六次式でも円分部分は二次]
$a=2^{1/6}>0$ とする。$1$ の六乗根は $\pm1,\pm\omega,\pm\omega^2$ なので $X^6-2$ の分解体は $\Q(a,\omega)$ である。$X^6-2$ は $2$ に関する Eisenstein の判定法で既約だから $[\Q(a):\Q]=6$ である。$\omega$ は非実数で二次であるため、上の段は二次であり分解体の次数は $12$ となる。$\Q(a)$ が既に実数の二次体 $\Q(a^3)=\Q(\sqrt2)$ を含むことは、非実の $\omega$ の添加には影響しない。
:::

:::example[基礎体に必要な冪根がある場合]
$K=\Q(i)$、$a=\sqrt2$ とする。$X^4-4$ の根は $a,ia,-a,-ia$ であり、$K(a)$ が分解体である。$a\notin K$ は $K$ の実元が有理数に限られることから従う。従ってこの四次式の $K$ 上の分解体は二次である。$\Q$ 上では全根を含む体に比 $ia/a=i$ が入るため、同じ分解体でも次数は四次になる。
:::

:::proposition[基礎体を広げた分解体]{#prop-gal-splitting-base-change}
共通の上位体において $L$ が $f$ の $K$ 上の分解体であり、$F$ が $K$ を含むなら、$f$ の $F$ 上の分解体は合成体 $LF$ である。その次数は $[L:K]$ 以下である。
:::

:::proof
$f$ の全根を $S$ と置けば、$L=K(S)$ である。$F$ 上の分解体は $F(S)$ であり、$F(S)$ は $L$ と $F$ を含む最小の体なので $LF$ である。:ref[prop-gal-compositum-degree-bound] で $[LF:F]\le [L:K]$ を得る。
:::

:::example[同じ三次式の基礎体を三通りに選ぶ]
$f=X^3-2$、$a=2^{1/3}$、$L=\Q(a,\omega)$ と置く。$F=\Q$ のとき $[LF:F]=6$ である。$F=\Q(a)$ のときは $LF=L$ であり次数は $2$ である。$F=\Q(\omega)$ のときも $LF=L$ だが、今度は塔法則で次数は $3$ になる。さらに $F=\Q(i)$ を取ると $i\notin L$ であることを示す別の議論が必要になる。判別式や部分体からその条件を判定する方法は [Galois の基本定理](/math/fields-galois/galois-correspondence/) で扱う。
:::

### 根の比で分解体を決める

二項式の形から全根を列挙できる。そのとき根を一つ添加した体、冪根を添加した体、両者の合成体の三つを比較する。以下では素数 $\ell$ に対し $\Phi_\ell(X)=1+X+\cdots+X^{\ell-1}$ と置く。$(X-1)\Phi_\ell(X)=X^\ell-1$ なので、その根は $1$ を除く $\ell$ 乗根である。また
$$
\Phi_\ell(Y+1)=\frac{(Y+1)^\ell-1}{Y}
=\sum_{j=1}^{\ell}\binom{\ell}{j}Y^{j-1}
$$
は定数項が $\ell$ で、最高次以外の各係数が $\ell$ の倍数である。従って Eisenstein の判定法により $\Phi_\ell$ は $\Q$ 上既約である。他の添字への一般化は [円分体](/math/fields-galois/cyclotomic/) で扱う。

:::example[素数次二項式の全根を揃える]
$f=X^{3} - 7$ とし、$a=7^{1/3}>0$、$\zeta$ を原始 $3$ 乗根とする。$a$ は Eisenstein の判定法で次数 $3$、$\zeta$ は $3$ に対する円分多項式で次数 $2$ である。ここでは円分式に $X=Y+1$ を代入すると $3$ に関して Eisenstein になる。

$$
\begin{aligned}
f(X)&=\prod_{j=0}^{2}(X-a\zeta^j),\\
\Phi_{3}(Y+1)&=Y^{2} + 3 Y + 3
\end{aligned}
$$

候補の体は二つの生成元から全根を作る。逆に、全根を含む体には $a$ と $a\zeta$ があり、比を取れば $\zeta$ が得られる。従って候補が分解体に一致する。

二つの次数 $3,2$ は互いに素だから、合成体の次数は $6$ である。基礎体を $\Q(\zeta)$ に変えれば分解体の次数は $3$ となる。基礎体が $\Q(a)$ なら、既に一根を持つので残りのための次数は $2$ である。

$\Q(a)$ の埋め込みは全て $a$ の像で決まる。実数を終域とすると $a>0$ の一つに限られるが、分解体を終域とすれば $3$ 通りが得られる。
:::

## 同型の延長と分解体の一意性

:::theorem[分解体への同型の延長]{#thm-gal-splitting-unique}
$\sigma:K\overset{\sim}{\to}K'$ とし、$L,L'$ がそれぞれ $f,\sigma f$ の分解体であるとする。$\sigma$ を延長する同型 $L\to L'$ が存在する。
:::

:::proof
$L$ のすべての根を $\alpha_1,\ldots,\alpha_r$ とする。すでに $K(\alpha_1,\ldots,\alpha_j)$ が $L'$ へ埋め込まれたとして、次の根の最小多項式を $g$ と置く。$g$ は $f$ を割るから、移した $g$ は $L'$ で分解する。その根を一つ選び、:ref[lem-gal-extend-simple] を適用する。こうして得た埋め込みは $f$ の相異なる根を $\sigma f$ の相異なる根へ写す。両者の個数が同じことも次のように分かる。$L$ における一次因子分解にこの埋め込みを施せば、その像の根だけで $\sigma f$ が完全に分解する。したがって像は $L'$ を生成し、写像は全射である。
:::

:::example[二つのモデル]
$\Q[X]/(X^2+1)$ の $[X]$ を $i$ または $-i$ に移すと、どちらも $\Q(i)$ への同型になる。分解体の一意性は同型の存在であり、写像が一つに決まるという意味ではない。
:::

:::example[二つの多項式を同時に分解する]
$\Q$ 上の $X^2-2$ と $X^2-3$ を同時に分解する最小の体は $\Q(\sqrt2,\sqrt3)$ である。積 $(X^2-2)(X^2-3)$ の分解体として一度に構成できる。この議論は有限個の非零多項式の積にもそのまま使える。
:::

### 途中で指定した写像を保つ

:::proposition[中間体の埋め込みの延長]{#prop-gal-splitting-intermediate-extension}
$f\in K[X]$、$\sigma:K\to K'$ を同型とする。$L,L'$ が $f,\sigma f$ の分解体であり、$M$ が $L/K$ の中間体であるとする。$\sigma$ を延長する埋め込み $\tau:M\to L'$ は同型 $L\to L'$ に延びる。
:::

:::proof
$L$ は同じ $f$ の $M$ 上の分解体である。実際、根の集合を $S$ とすれば $K(S)=L$ なので $M(S)=L$ である。一方 $L'$ は $\tau f=\sigma f$ の $\tau(M)$ 上の分解体である。$\tau(M)$ は $K'$ を含み $L'$ に含まれるので、同じ生成の議論が適用できる。この二つの分解体に :ref[thm-gal-splitting-unique] を使う。
:::

:::example[一つの根を指定したあとの延長数]
$a^3=2$、$L=\Q(a,\omega)$ とする。$a$ を $\omega a$ に送る同型は、$\omega$ の像を $\omega$ または $\omega^2$ にして $L$ に延ばせる。実際、$X^2+X+1$ は $\Q(a)$ で既約であり、$a$ を移しても係数はそのままである。単拡大の延長補題から二通りが得られ、いずれも全根を置換するから全射である。この二通りの違いは、比から得られる冪根の像に現れる。
:::

:::example[根の置換の可否を関係式で調べる]
$X^4-4$ の根を $a,-a,ia,-ia$ とする。$a$ は $X^2-2$ の根であるが $ia$ は $X^2+2$ の根である。従って、$a$ を $ia$ に送る置換は $\Q$ を固定する同型からは生じない。一方 $a$ を $-a$ に送り $i$ を固定する写像なら $X^2-2$ の $\Q(i)$ 上の根の交換であり、全体の同型を定める。$f$ の根を置換するだけでなく、その根が満たすすべての $K$ 上の関係を保つ必要がある。
:::

### 同型を途中から指定する

中間体の像を先に指定しても延長の選択はできる。相対的な最小多項式を使って数える。

:::example[二次因子ごとに延長の選択を整理する]
$f=X^{4} - 7 X^{2} + 10=(X^2-2)(X^2-5)$ の分解体は $L=\Q(a,b)$、$a^2=2$、$b^2=5$ である。$a$ と $b$ の正の根を取る。$2,5$ の平方類が異なるので $[L:\Q]=4$ である。

まず中間体 $M=\Q(ab)$ 上の二つの埋め込みを指定し、それぞれから $L$ へ延長する。$a$ が入れば $b=ab/a$ が得られる。$a$ は $M$ 上で $X^2-2$ を満たし、$[L:M]=2$ なのでこれは最小多項式である。

| $ab$ の像 | $a$ の像 | 決まる $b$ の像 |
| --- | --- | --- |
| $\sqrt{10}$ | $\sqrt{2}$ | $\sqrt{5}$ |
| $\sqrt{10}$ | $- \sqrt{2}$ | $- \sqrt{5}$ |
| $- \sqrt{10}$ | $\sqrt{2}$ | $- \sqrt{5}$ |
| $- \sqrt{10}$ | $- \sqrt{2}$ | $\sqrt{5}$ |

各行は単拡大の延長補題によって一つの同型を与える。同型の数を求める際には、$ab$ の符号と $a$ の符号を選び、$b$ の符号は関係式から決めた。逆に最初の二次体を $\Q(a)$ にすれば $a$ の符号と $b$ の符号を独立に選ぶ。結果の四通りは同じである。

## 代数閉体と代数閉包の存在

:::definition[代数閉体と代数閉包]{#def-gal-algebraic-closure}
正次数多項式がすべて根を持つ体を :term[代数閉体]{en="algebraically closed field" yomi="だいすうへいたい"} という。$K$ の代数拡大である代数閉体を $K$ の :term[代数閉包]{en="algebraic closure" yomi="だいすうへいほう"} という。
:::

:::proposition[代数閉性の判定]{#prop-gal-algebraically-closed}
体 $A$ について、すべての正次数多項式が分解すること、すべての既約多項式が一次であること、真の代数拡大を持たないことはそれぞれ代数閉性と同値である。
:::

:::proof
根を一つずつ剥がせば完全分解する。完全分解するなら既約式は一次である。既約式が一次なら任意の代数拡大の元の最小多項式が一次なので、拡大は自明である。真の代数拡大を持たないなら、次数が二以上の既約式 $g$ に対する商 $A[X]/(g)$ は作れない。よって正次数多項式は一次の既約因子を持つ。
:::

:::theorem[代数閉包の存在]{#thm-gal-closure-exists}
任意の体 $K$ は代数閉包を持つ。
:::

:::proof
まず正次数の各モニック $f\in K[X]$ に変数 $U_f$ を割り当て、環 $R=K[U_f:f]$ を作る。イデアル $I=(f(U_f):f)$ は真である。仮に $1$ が有限個の生成元の $R$ 線形結合なら、その有限個の $f$ の積の分解体に各 $U_f$ を対応する根として代入し、その他の変数を $0$ にすれば $1=0$ となるからである。

:ref[thm-sets-maximal-ideal] で $I$ を含む極大イデアル $\mathfrak m$ を取り、$K_1=R/\mathfrak m$ とする。非零定数は単元なので $\mathfrak m$ と交わらず、$K$ は $K_1$ に埋め込まれる。$K_1$ は $K$ 上代数的な生成元 $[U_f]$ で生成される。各元の表示は有限個の変数を使うので :ref[prop-gal-finite-algebraic] により $K_1/K$ は代数的である。

この操作を $K_0=K$ から順に繰り返し、埋め込みを包含と見なして $\Omega=\bigcup_{n\ge0}K_n$ を得る。有限個の元は一つの $K_n$ に入るため、合併は体である。推移性から各 $K_n/K$ は代数的であり、$\Omega/K$ も代数的である。$\Omega[X]$ の多項式は係数を有限個しか持たないので、モニックに直せばある $K_n$ 上の多項式である。その根は $K_{n+1}$ にあるため $\Omega$ は代数閉体である。
:::

:::example[有限体は代数閉でない]
$K$ が有限集合なら、$\prod_{a\in K}(X-a)+1$ はどの $a\in K$ でも値が $1$ である。したがって有限体は代数閉体でない。特に $\F_2$ ではこの式が $X^2+X+1$ になる。
:::

:::example[大きな代数閉体の中で閉包を取る]
$K\subseteq A$、$A$ が代数閉体なら、$A$ の中の $K$ 上代数的な元全体 $B$ は :ref[thm-gal-relative-algebraic-closure] で体になる。$B[X]$ の任意の正次数多項式の根を $A$ で取れば、その根は $B$ 上代数的であり、推移性で $K$ 上代数的である。よって $B$ は代数閉包である。例えば $\C$ の代数閉性を用いれば $\Q$ の複素代数的数全体が得られる。$\C$ の代数閉性の証明は [Galois の基本定理](/math/fields-galois/galois-correspondence/) で扱う。
:::

### 代数閉包の大きさと構成の選択

:::proposition[代数拡大の濃度の上界]{#prop-gal-algebraic-cardinality}
$L/K$ が代数拡大なら $|L|\le\max(|K|,\aleph_0)$ である。特に可算体の代数閉包は可算である。
:::

:::proof
全ての元は $K[X]$ の非零多項式の根である。次数が固定された多項式は有限個の係数から作られるので、その個数は $|K|$ の有限冪で抑えられる。次数を動かした可算和は $\max(|K|,\aleph_0)$ 以下である。一つの多項式が持つ根は有限個であり、この濃度を超える元は得られない。有限体の代数閉包が有限でないことは、有限集合の元を全て避ける多項式の例から従う。
:::

:::example[代数閉でも代数閉包とは限らない]
$\C$ は $\Q$ を含む代数閉体であるが、$\Q$ の代数閉包ではない。実際、$\Q$ 上の代数的数は可算である一方、$\R$ だけでも非可算である。$\C$ の中の代数的数全体を取ると、代数性と代数閉性を両方満たす体になる。
:::

:::example[個々の根と全ての根の違い]
$\Q$ のすべての二次式の根を添加しても代数閉にはならない。添加した元の有限個が生成する体の次数は、二次以下の段を重ねるため $2$ の冪に限られる。$2^{1/3}$ の次数は $3$ なので、そこで $X^3-2$ の根は得られない。このため構成では全ての次数の式を対象にする。
:::

### 可算体に対する逐次構成

極大イデアルを使う構成では、一度に無限個の多項式に根を与えた。基礎体が可算であれば、分解すべき式を列に並べて有限の問題に順に帰着できる。

:::proposition[可算体の代数閉包を有限段で作る]{#prop-gal-countable-algebraic-closure}
可算体 $K$ の代数閉包は、$K$ の有限拡大の増加列 $K_0\subseteq K_1\subseteq\cdots$ の合併として作れる。各 $K_i$ は $K$ 上の多項式の分解体として選べる。
:::

:::proof
$K[X]$ の正次数モニック多項式を $f_1,f_2,\ldots$ と列挙する。$K_0=K$ として $K_i$ を $f_i$ の $K_{i-1}$ 上の分解体とする。このとき $K_i$ は $f_1\cdots f_i$ の $K$ 上の分解体であり、各段は有限拡大である。合併 $A$ は代数拡大であり、$K[X]$ の全多項式が $A$ で分解する。

$h\in A[X]$ が正次数であるとし、分解体の存在を使ってある拡大の中に根 $a$ を取る。$a$ は $A$ 上代数的であり、$A/K$ は代数的だから $a$ は $K$ 上代数的である。その最小多項式は $A$ ですでに一次式の積に分解している。その積に $a$ を代入すると零なので、零積の性質により $a$ はその一次因子の根の一つとして $A$ に属する。従って $A$ は代数閉体である。
:::

:::example[有理数体の小さい次数の部分]
$\Q$ 上の多項式を列挙する際、最初を $X^2+1,X^2-2,X^4-2$ としてよい。最初の二段は $\Q(i)$ と $\Q(i,\sqrt2)$ であり、後者は実無理数を添加したので四次である。三段目は $a=2^{1/4}$ を添加すれば十分である。既に $i$ を含むため、全根 $\pm a,\pm ia$ が揃う。$\Q(a)$ は四次の実体で $i$ の添加が二次だから、三段目は八次である。
:::

:::example[既に代数閉である部分体を含む場合]
$A$ を代数閉体、$t$ をその上の不定元とする。$A(t)$ の代数閉包 $B$ は $A$ を含むが、$A$ の代数閉包は $A$ 自身である。逆に $A(t)$ は代数閉でない。もし $u^2=t$ を満たす $u=A_1(t)/B_1(t)$ があれば、$t$ における分子と分母の因子の指数差を二倍した値が $1$ になり、不可能だからである。$A$ が代数閉でも、関数体を作ると改めて根を添加する必要が生じる。
:::

## 代数閉包の一意性

:::theorem[代数拡大から代数閉体への延長]{#thm-gal-extend-algebraic}
$L/K$ を代数拡大、$\Omega$ を代数閉体とする。任意の埋め込み $\sigma:K\to\Omega$ は $L\to\Omega$ に延びる。特に $K$ の二つの代数閉包の間には $K$ 上の同型がある。
:::

:::proof
中間体 $M$ と延長 $\tau:M\to\Omega$ の組を、包含と制限で順序付ける。鎖に対して定義域の合併は体であり、写像の合併は矛盾なく定義できる。よって :ref[thm-sets-zorn] により極大の組がある。$M\ne L$ なら $\alpha\in L\setminus M$ を取り、像の最小多項式の根を $\Omega$ で選んで :ref[lem-gal-extend-simple] を適用する。これは極大性に反する。したがって $M=L$ である。

代数閉包 $L,L'$ の場合、この方法で得た埋め込みの像は $L$ と同型なので代数閉体である。$L'$ は $K$ 上代数的であり、像を基礎体としても代数的なので、:ref[prop-gal-algebraically-closed] で像は $L'$ 全体となる。
:::

:::example[延長の自由度]
$\Q(i)$ の $i\mapsto-i$ は $\overline\Q$ の自己同型に延びる。$\Q(i,\sqrt2)$ までの段階で $\sqrt2$ の像を $\sqrt2$ と $-\sqrt2$ のどちらにも選べる。実際、$\Q(i)$ の実元は有理数なので $X^2-2$ はそこで既約である。
:::

:::example[空間が足りないとき]
$\Q$ の恒等写像は $\Q(\sqrt2)$ から $\Q$ への埋め込みには延びない。$X^2-2$ の根が終域にないためである。終域を $\overline\Q$ に替えれば二つの根が選べる。
:::

### 代数閉包の像を求める

:::corollary[代数閉体への像の同定]{#cor-gal-closure-image}
$\overline K/K$ を代数閉包とし、$\sigma:K\to A$ を代数閉体 $A$ への埋め込みとする。$\sigma$ を延長する任意の $\overline K\to A$ の像は、$A$ 内で $\sigma(K)$ 上代数的な元全体である。
:::

:::proof
写像の像 $B$ は $\sigma(K)$ 上代数的であり、$\overline K$ と同型なので代数閉体である。$a\in A$ が $\sigma(K)$ 上代数的なら $B$ 上も代数的である。その最小多項式は代数閉性により一次であり、$a\in B$ である。この二方向で像が決まる。
:::

:::example[代数閉包の同型で指定できる部分]
$\overline\Q\subseteq\C$ とし、$a=\sqrt[3]2>0$ とする。$a\mapsto\omega a$ は $\Q(a)$ から $\overline\Q$ への埋め込みである。延長定理を $\overline\Q/\Q(a)$ に適用し、像の同定を基礎体 $\Q$ について使うと、得られた写像は $\overline\Q$ の自己同型である。この自己同型は実の $a$ を非実数に送る。従って $\overline\Q$ の $\Q$ 自己同型が実数部分を集合として保つとは限らない。
:::

:::example[可算な像と大きな終域]
$\Q$ を $\C$ に標準的に埋め込む。どの $\overline\Q\to\C$ も、その像は複素代数的数全体である。異なる延長で像の集合は変わらなくても、たとえば $i$ の像は $i$ または $-i$ で変わり得る。一方、$\Q(t)$ の埋め込みでは $t$ を $\C$ の任意の超越数に送れるので、像を同定するときの基礎体自体が変わる。
:::

### 代数閉包への延長を有限段で比較する

閉包への延長は存在する。ここでは同じ有限部分体の上から始め、延長先の有限段で異なる写像がどのように現れるかを見る。

:::example[有限体の埋め込みを代数閉包まで延長する]
$L=\overline{\F_{2}}$ の中で、$E_d$ を $X^{2^d}-X$ の根の体とする。$E_{2}$ 上の $a\mapsto a^2$ を延長したい。$L$ 全体で $2$ 乗は単射で、任意の元が $L$ に $2$ 乗根を持つので全射である。従ってこれが一つの延長である。

有限段 $E_{6}$ が $E_{2}$ を含むので、それぞれの $2$ 乗写像を比較する。$E_{6}$ での $2$ 乗写像の位数は $6$ である。真に小さい冪が恒等なら、全元が次数 $2^j<2^6$ の多項式 $X^{2^j}-X$ の根になるからである。

| 指数 $j$ | $E_{2}$ への制限の指数 | 条件を満たすか |
| --- | --- | --- |
| 0 | 0 | 満たさない |
| 1 | 1 | 満たす |
| 2 | 0 | 満たさない |
| 3 | 1 | 満たす |
| 4 | 0 | 満たさない |
| 5 | 1 | 満たす |

従って有限段では条件 $j\equiv1\pmod{2}$ を満たす $3$ 通りの延長が得られる。ここでは基礎体 $\F_{2}$ を固定する埋め込みの総数が $[E_{6}:\F_{2}]=6$ 以下であるため、$2$ 乗の冪で全てを尽くす。

## 演習問題

::::exercise{level=basic}
$\Q(\sqrt5)$ から $\C$ への $\Q$ 埋め込みを列挙せよ。
:::solution
$X^2-5$ は有理根を持たず、その根は $\sqrt5,-\sqrt5$ である。単拡大の延長補題により、生成元をそれぞれの根へ写す二通りがすべてである。
:::
::::

::::exercise{level=basic}
$X^4-1$ の $\Q$ 上の分解体と次数を求めよ。
:::solution
根は $1,-1,i,-i$ であり、生成体は $\Q(i)$ である。$X^2+1$ が既約なので次数は $2$ である。
:::
::::

::::exercise{level=basic}
$X^4-2$ の $\Q$ 上の分解体の次数を求めよ。
:::solution
正の四乗根 $a$ を取ると根は $a,-a,ia,-ia$ で、分解体は $\Q(a,i)$ である。$X^4-2$ は $2$ で Eisenstein なので下段の次数は $4$ である。$\Q(a)$ は実体なので $i$ の添加は二次であり、次数は $8$ である。
:::
::::

::::exercise{level=basic}
$\F_3$ が代数閉体でないことを二次式で示せ。
:::solution
$\F_3$ の平方は $0,1$ に限られる。したがって $X^2+1$ が根を持つために必要な $x^2=2$ は解を持たない。
:::
::::

::::exercise{level=advanced}
$f\in\Q[X]$ を非零とする。同じ代数閉包における $f$ と $f^2$ の分解体が一致することを示せ。
:::solution
体では $f(a)^2=0$ と $f(a)=0$ が同値なので、両者は同じ根集合を持つ。分解体はこの集合で生成され、重複度は生成体に影響しない。
:::
::::

::::exercise{level=advanced}
$X^3-2$ と $X^3-4$ の $\Q$ 上の分解体が同じことを示せ。
:::solution
$X^3-2$ の各根 $a,\omega a,\omega^2a$ を平方すると $X^3-4$ の三根をすべて得る。逆に $b^3=4$ なら $(b^2/2)^3=2$ かつ $(b^2/2)^2=b$ であるから、根を互いに復元できる。
:::
::::

::::exercise{level=advanced}
共通の上位体に含まれる二つの代数閉体について、その共通部分も代数閉体であることを示せ。
:::solution
共通部分を $B$ とし、任意の正次数多項式 $f\in B[X]$ を取る。一方の代数閉体での一次因子分解と他方での分解は、共通の上位体で因数分解の一意性により同じ根を与える。したがって根はすべて両方の体に入り、$f$ は $B$ で分解する。
:::
::::

::::exercise{level=advanced}
$L/K$ が代数拡大なら、$K$ の代数閉包への $K$ 埋め込みで $L$ をその部分体とみなせることを示せ。
:::solution
$K\to\overline K$ の包含を :ref[thm-gal-extend-algebraic] で $L$ に延長する。この延長は単位元を保ち単射なので、その像を $L$ と同一視できる。
:::
::::

## 確認テスト

::::quiz{answer="6" tol="0"}
$X^3-2$ の $\Q$ 上の分解体の次数を求めよ。
:::explanation
$X^3-2$ は有理根を持たず既約なので、正の根 $a$ の添加が三次である。全根は $a,\omega a,\omega^2a$ であり、根の比から $\omega$ を回収できるため、分解体は $\Q(a,\omega)$ である。$\Q(a)$ は実体なので $X^2+X+1$ の非実根 $\omega$ の添加は二次となり、塔法則で $6$ である。
:::
::::

::::quiz
代数閉包の定義に必要な条件をすべて選べ。

- [x] 基礎体の代数拡大である。
- [x] 正次数多項式はすべて根を持つ。
- [ ] 基礎体上有限次である。

:::explanation
代数閉包は代数的かつ代数閉な拡大である。例えば $\F_2$ の有限次拡大は有限集合であり、有限体は代数閉性を持たない。
:::
::::

::::quiz
代数的な単拡大への埋め込みの延長を決めるために指定するものを選べ。

- [x] 生成元の最小多項式を係数の像で移した式の根
- [ ] 生成元の属する体の任意の元
- [ ] 最小多項式の最高次係数

:::explanation
評価写像で最小多項式の関係を保存できる像は、係数を移した式の根に限られる。その根を選べば商の表示から延長が一意に決まる。
:::
::::

::::quiz{answer="2" tol="0"}
$\Q(i)$ の $\Q$ 上の自己同型はいくつあるか。
:::explanation
最小多項式 $X^2+1$ の根 $i,-i$ がともに $\Q(i)$ を生成するので、二つの埋め込みはいずれも全射である。
:::
::::

::::quiz{answer="20" tol="0"}
$X^5-3$ の $\Q$ 上の分解体の次数を求めよ。

:::explanation
一つの正の根と原始五乗根の合成体である。前者の次数は Eisenstein により $5$、後者の次数は円分式を平行移動して $4$ である。互いに素なので積は $20$ である。
:::
