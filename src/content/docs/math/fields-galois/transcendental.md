## この章の目標

- 代数的独立性と超越基底を定義する。
- 超越次数の一意性と加法性を証明する。
- Lüroth の定理と分離生成を説明する。
- Hermite の積分法で基本的な超越数を証明する。

## 代数的独立性

:::definition[代数的独立性]{#def-gal-algebraic-independence}
$L/K$ の部分集合 $B$ が :term[代数的独立]{en="algebraically independent" yomi="だいすうてきどくりつ"} であるとは、相異なる任意の有限個 $b_1,\dots,b_n\in B$ に対する評価準同型 $K[X_1,\dots,X_n]\to L$ が単射であることをいう。
:::

:::proposition[一点の追加]{#prop-gal-independence-add}
$B$ が代数的独立で $a\notin B$ なら、$B\cup\{a\}$ が代数的独立であることと $a$ が $K(B)$ 上超越的であることは同値である。
:::

:::proof
関係を $a$ の冪で整理すると、各係数は有限個の $B$ の元の多項式である。元の多項式が非零なら、独立性により少なくとも一つの係数が非零となる。逆に $K(B)$ 係数の非零多項式の関係の分母を払えば、有限個の $B$ の元と $a$ に対する非零多項式の関係になる。
:::

:::example[各元の超越性だけからは決まらない]
$t,t^2$ は各々 $\Q$ 上超越的である。後者は非零の $P(X)$ に対し $P(t^2)$ の各指数が相異なるからである。一方、二元を同時に取ると $Y-X^2=0$ の関係がある。
:::

:::example[変数の有理的な置換]
独立な $s,t$ に対して $u=s+t,v=s-t$ とする。標数 $2$ でなければ $s=(u+v)/2,t=(u-v)/2$ と逆変換できるので、評価は単射である。標数 $2$ では二つの値が等しく、二変数の独立性が失われる。
:::

### 単項式の指数から独立性を読む

:::example[二変数の組み替え]
$u,v$ を独立な不定元とする。$a=uv,b=u/v$ と置くと $a^i b^j=u^{i+j}v^{i-j}$ である。整数の組 $(i+j,i-j)$ から $(i,j)$ を復元できるので、異なる単項式は異なる Laurent 単項式になる。負の指数があっても共通の冪を掛ければ通常の多項式になり、相殺しない。従って $a,b$ は代数的に独立である。一方 $a=u v,b=u^2 v^2$ なら $b=a^2$ で従属である。両方の元が基礎体上超越的であることは、二元の独立性を保証しない。
:::

### 指数の線形写像から独立性を判断する

変数を積や商に置き換える場合、指数を先に計算すると多項式の相殺を判定できる。

$$

$$

| --- | --- |
| $\left( 0, \  0\right)$ | $\left( 0, \  0\right)$ |
| $\left( 0, \  1\right)$ | $\left( 1, \  -1\right)$ |
| $\left( 0, \  2\right)$ | $\left( 2, \  -2\right)$ |
| $\left( 1, \  0\right)$ | $\left( 1, \  1\right)$ |

| $\left( 2, \  1\right)$ | $\left( 3, \  1\right)$ |
| $\left( 2, \  2\right)$ | $\left( 4, \  0\right)$ |

表で衝突するかどうかは小さい指数の観察である。全ての次数については、行列が整数の指数をどのように移すかを判定する。

行列式は $-2$ であり、整数の指数の写像は単射である。従って異なる単項式が同じ Laurent 単項式にはならず、非零多項式が消えることはない。$a,b$ は代数的独立である。

さらに余因子行列を用いて、$u,v$ の冪を $a,b$ から復元する。

$$
\begin{aligned}
u^{-2}&=\frac{1}{a b},\\
v^{-2}&=\frac{b}{a}
\end{aligned}
$$

従って $u,v$ は $K(a,b)$ 上代数的であり、二つの新しい元が独立であり、その生成体上で全体が代数的になる。行列の逆が整数行列なら、$u,v$ 自身を Laurent 単項式で復元できる。
:::

## 超越基底と超越次数

:::definition[超越基底]{#def-gal-transcendence-basis}
代数的独立な部分集合 $B\subseteq L$ で $L/K(B)$ が代数的であるものを :term[超越基底]{en="transcendence basis" yomi="ちょうえつきてい"} と呼ぶ。
:::

:::theorem[超越基底の存在]{#thm-gal-transcendence-basis}
任意の代数的独立集合は超越基底に拡張できる。
:::

:::proof
指定された集合を含む独立集合を包含で順序付ける。鎖の合併の有限部分集合はある一段に入るので合併は独立である。:ref[thm-sets-zorn] により極大独立集合を取れる。外の元が生成体上超越的なら :ref[prop-gal-independence-add] で追加でき、極大性に反する。
:::

:::example[代数拡大]
$\Q(\sqrt2)/\Q$ は代数拡大なので空集合が基底である。空集合が生成する体は $\Q$ である。
:::

:::example[有限の代数段があっても基底が同じ場合]
$t$ が不定元なら $\Q(t,\sqrt t)/\Q(t)$ は二次である。$t$ は $\Q$ 上超越的なので $\{t\}$ は $\Q(t,\sqrt t)$ の $\Q$ 上の超越基底である。
:::

### 超越基底と代数的な段を分ける

有限生成体 $L=K(x_1,\ldots,x_m)$ では、超越基底を与えられた生成元の中から選べる。生成元を順に調べ、現在の集合が生成する体上で超越的な元だけを採用する。不採用の元はその時点で代数的なので、最後の生成体上でも代数的である。採用した集合は :ref[prop-gal-independence-add] により独立であり、残る有限個の生成元を加えると有限代数拡大になる。体の代わりに有限生成整域を扱うとき、対応する多項式環を整域の中に選ぶ方法は [Noether 正規化](/math/commutative-algebra/integral-extensions/) で扱う。

:::example[同じ拡大の二種類の超越基底]
$L=\Q(u,v)$ とし、$u,v$ は代数的独立とする。$B_1=\{u,v\}$ は超越基底で $[L:\Q(B_1)]=1$ である。$B_2=\{u^2,v^3\}$ も、単項式が異なる指数に写るので独立である。$u$ と $v$ はそれぞれ二次、三次の式を満たすので $L/\Q(B_2)$ は代数的である。指数を $2,3$ で割った余りの組で整理すると $1,v,v^2,u,uv,uv^2$ が基底の候補になる。分母を払って異なる剰余の項を比べれば独立であり、張る空間は積に閉じる。この空間は整域の中の有限次元部分環なので、非零元を掛ける線形写像は単射であり、従って全射である。特に逆元を取れるので、空間は $u,v$ を含む体 $L$ に等しい。従って代数的な上段の次数は六である。超越基底の大きさは同じでも、上段の次数は基底の選択に依存する。
:::

### 同じ超越次数の上に残る有限拡大を測る

基底を不定元の冪で選ぶと、上に残った有限次数を余りの組で計算できる。

:::example[基底を冪で取り替えたときの有限次数を求める]
$L=K(u,v)$、$E=K(a,b)$、$a=u^2,b=v^3$ とする。$u,v$ は独立な不定元であり、$a,b$ も異なる単項式を異なる指数へ移すため独立である。従って $\{a,b\}$ は $L/K$ の超越基底の候補である。

$$
\begin{aligned}
u^{2}-a&=0,\\
v^{3}-b&=0
\end{aligned}
$$

これらの式が $u,v$ を $E$ 上代数的にする。実際の次数は、$u^iv^j$（$0\le i<2,0\le j<3$）で測る。係数を $a,b$ の有理式にして一次関係があれば分母を払う。各単項式の $u,v$ の指数の余りが $(i,j)$ なので、異なる組の項は消し合わない。

| 第一の余り $i$ | 第二の余りの範囲 | 基底に対応する冪 |
| --- | --- | --- |
| 0 | $0\le j<3$ | $u^0v^j$ |
| 1 | $0\le j<3$ | $u^1v^j$ |

積の冪は $u^{2}=a,v^{3}=b$ で減らせる。従って張る空間は有限次部分環なので体となる。以上から基底を確定し、次数 $2\cdot 3=6$ を得る。

標数零では二つの関係式はいずれも分離的である。従って二元の冪を基底とした上段も分離拡大になる。
:::

## 超越次数の一意性

:::lemma[交換の一段]{#lem-gal-transcendence-exchange}
$a$ が $F$ 上超越的で $F(b)$ 上代数的なら、$b$ は $F(a)$ 上代数的である。
:::

:::proof
分母を払って $0\ne P(X,Y)\in F[X,Y]$ で $P(a,b)=0$ を得る。$a$ が超越的なので $P(a,Y)$ は非零である。従って $b$ を消す多項式となる。
:::

:::theorem[超越次数と塔の公式]{#thm-gal-transcendence-degree}
超越基底は全て同濃度を持つ。この濃度を :term[超越次数]{en="transcendence degree" yomi="ちょうえつじすう"} と呼ぶ。また $K\subseteq M\subseteq L$ において
$$
\operatorname{trdeg}_K L=\operatorname{trdeg}_K M+\operatorname{trdeg}_M L
$$
である。
:::

:::proof
$L$ が $K(b_1,\ldots,b_m)$ 上代数的で、$a_1,\ldots,a_n$ が独立とする。$a_i$ を一つずつ入れ、同時に残りの $b_j$ の一つを除いても $L$ が生成体上代数的となるようにする。実際 $F=K(a_1,\ldots,a_{i-1})$ 上で $a_i$ は超越的であるが、現在残っている $b_j$ をすべて加えると代数的となる。最初に代数的となる段の $b_j$ が :ref[lem-gal-transcendence-exchange] で $a_i$ と交換できる。前後の他の元を残せば、推移性により代数性を保てる。したがって $n\le m$ である。有限基底があるなら他の基底の有限部分集合がこの上界を満たすので、他の基底も有限である。両方向の不等式で等濃度となる。

双方の基底 $B,C$ が無限なら、各 $c\in C$ は有限な $B_c\subset B$ が生成する体上で代数的である。$B_0=\bigcup_c B_c$ とすると推移性により $L/K(B_0)$ は代数的である。$B_0\ne B$ なら、外の基底元が $K(B_0)$ 上超越的で矛盾する。従って $|B|\le|C|$ であり、逆も同様である。

塔において $B$ を $M/K$ の基底、$C$ を $L/M$ の基底とする。$B\cup C$ の関係を $C$ の多項式と見ると、その係数は $B$ の多項式の値である。二つの独立性により非自明な関係はない。$M(C)/K(B,C)$、$L/M(C)$ は代数的であるため、$B\cup C$ は超越基底となる。
:::

:::example[変数を分ける]
$K\subseteq K(s)\subseteq K(s,t,u)$ では超越次数は下段 $1$、上段 $2$、全体 $3$ である。
:::

:::example[代数段の寄与]
$u^2=s$ とすると $K(s,t)\subset K(u,t)$ は代数拡大である。両方の $K$ 上の超越次数は $2$ であり、代数段の寄与は零である。
:::

### 塔における超越基底の結合

:::proposition[超越次数の加法性]{#prop-gal-transcendence-degree-additive}
体の塔 $K\subseteq E\subseteq L$ に対して $B$ を $E/K$ の超越基底、$C$ を $L/E$ の超越基底とする。このとき $B\cup C$ は $L/K$ の超越基底である。特に超越次数は加法的である。
:::

:::proof
$C$ は $E$ 上独立であり、$B\subseteq E$ なので両集合は交わらない。$B\cup C$ に非零な多項式関係があると仮定し、$C$ に関する単項式で整理する。各係数は $B$ の有限個の元の $K$ 上の多項式である。$B$ の独立性で少なくとも一係数は非零となり、$C$ の $E$ 上の独立性に反する。次に、$E(C)/K(B,C)$ は $K(B)$ 上代数的な $E$ の元で生成されるため代数的である。$L/E(C)$ も代数的だから推移性で $L/K(B,C)$ が代数的となる。従って和集合が超越基底である。
:::

## 純超越拡大と Lüroth の定理

独立集合 $B$ の生成体 $K(B)$ を :term[純超越拡大]{en="purely transcendental extension" yomi="じゅんちょうえつかくだい"} という。変数一つの場合、中間体も一変数の有理関数体になる。

:::lemma[有理関数による拡大次数]{#lem-gal-rational-function-degree}
$t$ を不定元とし、$r=A(t)/B(t)$ は非定数、$A,B\in K[t]$ は互いに素とする。このとき $[K(t):K(r)]=\max(\deg A,\deg B)$ である。
:::

:::proof
$r$ は $K$ 上超越的である。実際 $A(X)-rB(X)$ は非零で $t$ を消すので、$r$ が代数的なら推移性により $t$ も代数的になる。$A(X)-YB(X)$ は $K[X,Y]$ で既約である。$Y$ 次数が一なので、非自明な因数分解には $Y$ に依存しない因子が必要で、その因子が $A,B$ の両方を割るからである。:ref[thm-ring-poly-ufd]{text="分数体上の因数分解定理"}から $K(Y)[X]$ で既約であり、$Y$ を $r$ へ移して次数を得る。
:::

:::theorem[Lüroth の定理]{#thm-gal-luroth}
$K\subsetneq E\subseteq K(t)$ なら $E=K(r)$ となる $r\in K(t)\setminus K$ がある。
:::

:::proof
$E$ に非定数元があるので補題から $[K(t):E]=d<\infty$ である。$t$ の $E$ 上の最小多項式を $m(X)$ とする。各 $u\in E$ を既約分数 $A_u(t)/B_u(t)$ と書く。$E[X]$ において多項式 $h_u=A_u(X)-uB_u(X)$ の族の最大公約式 $g$ を、族の生成するイデアルのモニックな生成元として取る。このため $g$ は有限個の $h_u$ の $E[X]$ 係数の一次結合でもある。

$m$ は全ての $h_u$ を割る。逆に商 $E[X]/(g)$ では各 $B_u$ は単元である。実際 $g,B_u$ の共通因子は $h_u$ と $B_u$ を割って $A_u$ も割るが、$A_u,B_u$ は互いに素である。この商で $u=A_u(X)/B_u(X)$ が成立する。$m(t)=0$ に出る各係数 $u$ を $A_u(t)/B_u(t)$ に置き換えて分母を払うと、$t$ が不定元であるため $K[X]$ の恒等式を得る。その恒等式を商で読み直すと $m(X)=0$ となるので $g$ は $m$ を割る。共にモニックなので $m=g$ である。

$K[T,X]$ で $A_u(X)B_u(T)-A_u(T)B_u(X)$（$u$ は非定数）の族の最大公約式を $G(T,X)$ とする。各式は $K[T]$ 上原始的である。もし係数が共通の既約式で割れれば、その根 $\beta$ を代入して $A_u(X)B_u(\beta)-A_u(\beta)B_u(X)=0$ となる。非定数性より $A_u,B_u$ は比例しないから両値が零になるが、互いに素であることに反する。したがって $G$ は原始的であり、前段の Bézout 等式と Gauss の補題により $K(t)[X]$ では $m$ の定数倍に等しい。変数を交換すると族の各式は符号だけ変わるので、$G(X,T)$ は $G(T,X)$ の定数倍である。従って $\deg_T G=\deg_X G=d$ である。

$G$ を最高次係数で割ると $m$ になるので、その各係数は $t$ に関する次数が高々 $d$ の分子と分母を持つ。少なくとも一係数 $r$ は非定数である。そうでなければ $m(t)=0$ が $K$ 上の代数関係になる。補題から $[K(t):K(r)]\le d$ であり、$K(r)\subseteq E$ と塔法則からこの次数は $d$ の倍数である。よって $E=K(r)$ である。
:::

:::example[二次の有理関数]
$r=t+1/t$ では分子 $t^2+1$、分母 $t$ なので $[K(t):K(r)]=2$ である。実際 $t^2-rt+1=0$ を満たす。
:::

:::example[中間体の生成元]
$E=K(t^2,t^3)$ なら $t=t^3/t^2\in E$ なので $E=K(t)$ である。一方 $K(t^2,t^4)=K(t^2)$ は次数 $2$ の中間体である。
:::

:::corollary[一変数有理関数体の生成元と自己同型]{#cor-gal-mobius-generators}
$K(t)$ の $K$ 上の生成元は $(at+b)/(ct+d)$（$a,b,c,d\in K$、$ad-bc\ne0$）で尽くされる。このため $t$ を移す一次分数変換が $K(t)$ の $K$ 自己同型すべてを与える。
:::

:::proof
:ref[lem-gal-rational-function-degree] により、非定数の既約分数 $A(t)/B(t)$ が全体を生成するのは $\max(\deg A,\deg B)=1$ の場合に限る。分子 $at+b$ と分母 $ct+d$ が比例せず、分母が零多項式でもないことは $ad-bc\ne0$ と同値である。非定数の有理関数は超越的なので、$t$ をこの元へ移す写像は $K$ 埋め込みになる。像が全体であることと生成条件が一致する。
:::

また $K$ 上代数的な $K(t)$ の元は $K$ に限る。非定数の元は同じ補題により超越的だからである。変数を一つずつ減らすと、任意の純超越拡大において $K$ が相対代数閉であることも従う。元の表示には有限個の変数しか使わないので、無限個の不定元があっても同じ議論を適用できる。

### 有理関数の合成と次数

:::example[合成した有理関数の次数]
$r=t+1/t$、$s=r^2$ とする。既約分数の分子分母の次数の最大を取ると $[K(t):K(r)]=2$ である。また $r$ は超越的で、$K(r)/K(r^2)$ は二次である。従って $[K(t):K(s)]=4$ である。実際 $s=(t^2+1)^2/t^2$ の分子は四次で、$t$ とは互いに素である。この計算は任意の標数で成り立つ。ただし標数二では二段目の $K(r)/K(r^2)$ は純非分離になる。次数の積と分離性は別々に判定する。
:::

:::example[二つの有理関数が生成する体]
$E=K(t^4,t^6)$ なら $t^6/t^4=t^2$ であり、逆に $t^4,t^6$ は $t^2$ の冪だから $E=K(t^2)$ である。一般に正整数 $m,n$ に対し $K(t^m,t^n)=K(t^{\gcd(m,n)})$ である。Bézout 等式 $am+bn=\gcd(m,n)$ により $t^{\gcd(m,n)}$ は二つの冪の積になり、負の指数は分数体で使える。これで Lüroth の定理の生成元を具体的に得られる場合がある。
:::

### 変数を二つ置いて最大公約式を取る

証明の最大公約式による方法を、係数を明示した二つの有理関数に適用する。$T=t$ と見なすと、それぞれの分母を払う前の式は $E[X]$ に属する。$E[X]$ から $K(t)[X]$ へ係数を広げても、Bézout 等式と割り切れ方によってモニック最大公約式は変わらない。従って $K[T,X]$ で最大公約式を非零定数倍の違いまで計算し、$X$ についてモニックにした式を使える。

:::example[二つの有理関数から Lüroth 生成元を復元する]
$E=K(A(t),B(t))\subseteq K(t)$ を標数零で考える。$A(T)=\frac{T^{4} + T^{3} + 2 T^{2} + T + 1}{T^{2}}$、$B(T)=\frac{T^{6} + 3 T^{4} + 3 T^{2} + 1}{T^{3}}$ である。表示中の $T$ は独立な変数で、$t$ は有理関数体の生成元を表す。

各分数 $h(T)=P(T)/Q(T)$ について、$h(X)=h(T)$ の分母を払った $H_h=P(X)Q(T)-P(T)Q(X)$ を作る。二つの式の最大公約式を $X,T$ の多項式として計算する。

$$
\begin{aligned}
\deg_X H_A&=4,\qquad \deg_X H_B=6,\\
\gcd(H_A,H_B)&=- T^{2} X + T X^{2} + T - X
\end{aligned}
$$

最大公約式を $X$ の最高次係数で割ると、$X$ についてモニックな式を得る。

$$
m(X)=\frac{- T^{2} X + T X^{2} + T - X}{T}
$$

この式は $t$ の $E$ 上の最小多項式に一致する。実際、生成元 $A,B$ に対する最大公約式の商では、$A(X)=A(T),B(X)=B(T)$ が成り立つ。その分数式である全 $h\in E$ に対しても成り立つ。分母の非零値はこの商の中で対応する $E$ の非零元となり可逆だからである。

もとの二式を作る前の関数 $r(T)=T + \frac{1}{T}$ に対して $A=r^2+r$、$B=r^{3}$ だから、$E\subseteq K(r(t))$ である。$r$ の次数から $[K(t):K(r(t))]=2$ を得て、上のモニックな最大公約式の次数も $2$ で一致する。塔法則で $E=K(r(t))$ となる。
:::

## 分離生成拡大

:::definition[分離生成]{#def-gal-separably-generated}
有限生成拡大 $L/K$ に、$L/K(B)$ が有限分離となる超越基底 $B$ があるとき、:term[分離生成]{en="separably generated" yomi="ぶんりせいせい"} であるといい、その $B$ を :term[分離超越基底]{en="separating transcendence basis" yomi="ぶんりちょうえつきてい"} と呼ぶ。
:::

:::theorem[完全体上の分離生成]{#thm-gal-perfect-separating-basis}
完全体上の有限生成拡大は分離生成である。
:::

:::proof
標数 $0$ は分離性の判定から直ちに従う。標数 $p$ では超越次数を $r$ とし、有限超越基底 $t_1,\dots,t_r$ を取る。$F=K(t_1,\dots,t_r)$、$K=K^p$ より $F^p=K(t_1^p,\dots,t_r^p)$ である。各指数を $p$ で割った剰余で整理すると $[F:F^p]=p^r$ である。また Frobenius による同型から $[L^p:F^p]=[L:F]$ である。塔法則で $[L:L^p]=p^r$ を得る。

$L^p$ 上で $L$ を作るため、未添加の元を必要な限り一つずつ選ぶ。各元の $p$ 乗はすでに下の体にあるため、真の段は次数 $p$ である。従って $r$ 個の元 $b_1,\dots,b_r$ で $L=L^p(b_1,\dots,b_r)$ となり、指数が全て $p$ 未満の単項式は基底になる。もし $b_i$ に $K$ 上の関係があれば全次数最小の関係を選ぶ。指数の剰余で分けると、基底の独立性により各群の係数が $L^p$ で零になる。その係数は、$K$ が完全なので $K$ 上の低次数多項式の値の $p$ 乗である。少なくとも一つの非零多項式が得られるので最小性に反する。ゆえに $b_i$ は超越基底である。

$E=K(b_1,\dots,b_r)$ と置くと $L=EL^p$ である。これを繰り返すと $L=EL^{p^j}$ が全 $j$ で従う。一方 $L/E$ の分離部分を $S$ とすると $L/S$ は有限純非分離であり、有限生成元の指数の最大を取れば十分大きな $j$ で $L^{p^j}\subseteq S$ となる。したがって $L=S$ である。
:::

:::example[完全体上でも選び方による]
$\F_p(t)/\F_p$ で $\{t\}$ は分離超越基底であるが、$\{t^p\}$ の上では純非分離 $p$ 次となる。
:::

:::example[不完全体で失敗する例]
$K=\F_p(s)$、$u^p=s$、$L=K(u,t)$ とする。任意の超越基底 $B$ の生成体 $K(B)$ に $u$ は入らない。純超越拡大では基礎体が相対代数閉であるためであり、これは一変数の結果を有限個の変数に繰り返せば従う。従って $u$ は $K(B)$ 上の非分離元であり、分離生成でない。
:::

### 不完全体上で使える判定

標数 $p$ の体 $K$ で、有限個の元の指数を $0,\ldots,p-1$ に制限した単項式を考える。どの有限部分集合についてもこの単項式が $K^p$ 上一次独立で、集合全体と $K^p$ が $K$ を生成するとき、その集合を :term[$p$ 基底]{en="p-basis" yomi="ぴーきてい"} と呼ぶ。有限部分集合に対する単項式の張る空間は積に閉じる。有限次元なので、前に見たように逆元も含み、その有限部分集合の生成体になる。従って単項式を全て取ると $K$ の $K^p$ 基底になる。

このような集合は存在する。単項式の独立性を満たす集合を包含で並べると、鎖の合併でも有限部分集合ごとの条件は保たれる。そこで :ref[thm-sets-zorn] で極大集合を選ぶ。その生成体の外に元 $z$ があれば、$z^p$ は生成体に入っていて $z$ の次数は $p$ なので、この独立性を保って追加できる。従って極大集合が $p$ 基底になる。

:::proposition[分離生成と $p$ 基底]{#prop-gal-separating-p-basis}
標数 $p$ の有限生成拡大 $L/K$ が分離生成であることは、$K$ の $p$ 基底の指数 $p$ 未満の単項式が $L^p$ 上も一次独立であることと同値である。
:::

:::proof
$B$ を $K$ の $p$ 基底とする。まず $L/E$ が有限分離で、$E=K(t_1,\ldots,t_r)$ が純超越的であるとする。$B$ の単項式は $E^p=K^p(t_1^p,\ldots,t_r^p)$ 上独立である。分母を払うと、各 $t_1^p,\ldots,t_r^p$ の単項式の係数に関して $K^p$ 上の独立性を使えるからである。任意の相異なる有限個 $b_1,\ldots,b_m\in B$ について、$E^p$ に一つずつ加える各段は純非分離 $p$ 次である。各段を $L^p$ と合成しても次数は $p$ のままである。実際、$L^p/E^p$ は分離拡大であり、各段の下の体を加えた合成体も、その下の体上分離的である。そのため次に加える $b_i$ のような、下の体に属さない純非分離元はまだ入っていない。よって上でも全段の次数が $p$ となり、単項式は独立である。

逆に独立性を仮定する。$L/K$ は有限生成なので、$K L^p$ に元 $z_1,\ldots,z_m$ を一つずつ加え、各段の次数を $p$ として $L$ を生成できる。従ってこの $m$ 個の元の指数 $p$ 未満の単項式は $K L^p$ 上の基底となる。これらと $B$ の単項式を掛け合わせたものは $L^p$ 上一次独立である。$z_i$ の単項式で整理してから、各係数について $B$ の独立性を使えばよい。

$z_1,\ldots,z_m$ に $K$ 上の関係があるとし、非零な関係式のうち全次数が最小の多項式を取る。その各係数を $B$ の単項式で $K^p$ 上展開し、$z_i$ の各指数を $p$ で割って余りごとにまとめる。このとき各組の単項式に掛かる係数は、$z_i$ に関する $K$ 係数の多項式の値の $p$ 乗になる。前段の独立性により全ての係数が零になる。少なくとも一つの非零多項式が得られ、その全次数は最小とした次数を $p$ で割った値以下である。元の関係式の次数は正なので矛盾する。従って $z_1,\ldots,z_m$ は代数的独立である。

$F=K(z_1,\ldots,z_m)$ とおけば $L=F L^p$ である。$t_1,\ldots,t_d$ を $L/F$ の超越基底、$E=F(t_1,\ldots,t_d)$ とする。$F E^p=F(t_1^p,\ldots,t_d^p)$ なので、指数の剰余で整理すると $[E:F E^p]=p^d$ である。一方、$L^p/E^p$ の基底は係数体を $F E^p$ に広げても合成体を張るので、$[F L^p:F E^p]\le[L^p:E^p]=[L:E]$ である。$L=F L^p$ より $[L:E]p^d=[F L^p:F E^p]\le[L:E]$ となり $d=0$ である。従って $L/F$ は有限である。$L=F L^p$ を繰り返して $L=F L^{p^j}$ を得る。十分大きな $j$ で $L^{p^j}$ が分離部分に入るので、$L/F$ は分離的である。
:::

:::example[基礎体の $p$ 基底に関係が生まれる例]
$K=\F_p(a,b)$、$L=K(x,y)$ とし、$a,b,x$ は独立で $y^p=ax^p+b$ とする。$K$ の $p$ 基底 $a,b$ に対して、$1,a,b$ には $L^p$ 係数の関係 $y^p-x^pa-b=0$ がある。従って $L/K$ は分離生成でない。これに対し $L=\F_p(a,x,y)$ は $\F_p$ 上純超越である。このことは $L$ の超越次数が三で、三元 $a,x,y$ が $b=y^p-ax^p$ も生成することから従う。基礎体をどこに置くかによって、同じ上の体でも分離生成性が変わる。
:::

共通の体に含まれる二つの拡大 $L/K$ と $M/K$ について、$M$ の $K$ 上一次独立な有限個の元が $L$ 上でも一次独立であるとき、:term[線形無交叉]{en="linearly disjoint" yomi="せんけいむこうさ"} であるという。例えば $M=K^{1/p}$、すなわち $p$ 乗が $K$ に入る元の体なら、$p$ 乗操作により $K$ 上の一次関係は $K$ の元の $K^p$ 上の一次関係に、$L$ 上の一次関係は $L^p$ 上の一次関係に対応する。従って :ref[prop-gal-separating-p-basis] は、$L$ が $K^{1/p}$ と $K$ 上線形無交叉であることを分離生成の条件とするものでもある。

### 微分から分離性を調べる

有限生成拡大で変数を見分けるには、形式的に変数を微分して得る情報も使える。ここでいう微分は極限を使わない。

:::definition[導分]{#def-gal-field-derivation}
$L/K$ の $K$ 線形写像 $D:L\to L$ が $D(ab)=aD(b)+D(a)b$ を満たすとき、$K$ 上の :term[導分]{en="derivation" yomi="どうぶん"} と呼ぶ。$D(1)=D(1\cdot1)=2D(1)$ から $D(1)=0$ であり、従って $D$ は $K$ を消す。
:::

:::proposition[導分の分離拡大への延長]{#prop-gal-derivation-extension}
有限分離拡大 $M/F$ と $K\subseteq F$ に対し、$F$ 上の $K$ 導分 $D:F\to F$ は $M$ 上の $K$ 導分へ一意に延びる。
:::

:::proof
:ref[thm-gal-primitive] で $M=F(a)$ とする。$a$ の最小多項式 $f=\sum_i c_i X^i$ の関係を微分すると、延長は $D(a)=-\sum_i D(c_i)a^i/f'(a)$ を満たす必要がある。分離性により分母は非零である。実際にこの値を $b$ とし、多項式 $h$ に対して係数を微分した多項式を $D_{\mathrm{coef}}h$ と書いて
$$
\delta(h)=(D_{\mathrm{coef}}h)(a)+h'(a)b
$$
と定める。積に対する規則 $\delta(hk)=h(a)\delta(k)+\delta(h)k(a)$ が成り立つ。$\delta(f)=0$、$f(a)=0$ なので $(f)$ を消し、商 $F[X]/(f)$ に所望の延長を誘導する。任意の延長の値は基礎体と $a$ の値から決まるため一意である。
:::

:::example[二次式の陰関数]
標数 $0$ で $a^2=t^3+1$ とする。$D(t)=1$ の導分は $D(a)=3t^2/(2a)$ として $K(t,a)$ に延びる。生成元の関係を微分して値を求める点は、通常の陰関数微分と同じである。
:::

:::example[純非分離では延びない場合]
標数 $p$ で $a^p=t$ とする。$K(t)$ の $D(t)=1$ を延ばせば、$D(a^p)=p a^{p-1}D(a)=0$ と $D(t)=1$ の両方が必要になる。従って延長は存在しない。一方、$D=0$ からは $K(a)$ 上で $D(a)$ に任意の値を与える延長があり、一意性も一般には失われる。
:::

### 不完全体上で分離基底を選べる例

:::example[基礎体が不完全でも純超越拡大は分離生成である]
$K=\F_p(s)$、$L=K(t)$ とする。$\{t^p\}$ は超越基底で、その上の拡大は純非分離 $p$ 次である。一方 $\{t\}$ の上の拡大は自明なので分離生成である。この例では基礎体の不完全性と、所与の拡大が分離生成かどうかを別に考える必要がある。
:::

:::example[有理関数の微分と分離性]
$r=t^p+t$ なら $t$ は $X^p+X-r$ を満たす。$[K(t):K(r)]=p$ なのでこれが最小多項式であり、導関数は $1$ であるため分離的である。$r=t^p$ なら同じ次数 $p$ で導関数が零なので純非分離である。導分 $D(t)=1$ を使うと前者では $D(r)=1$、後者では $D(r)=0$ になる。$t$ の関係式を微分したとき、$D(t)$ を係数から決められるかどうかにもこの違いが現れる。
:::

## e と π の超越性

整数係数の代数関係に積分の評価を組み合わせる。積分が十分小さくなる一方、その和が零でない整数になるように多項式を選ぶ。

:::lemma[Hermite の積分による補題]{#lem-gal-hermite-integral}
$\beta_1,\ldots,\beta_s$ を非零代数的数の有限多重集合とし、整数の重みも含めて $\Q$ 上の全共役で不変とする。すなわち任意の共役置換は重み $w_j$ を保つとする。整数 $k\ne0$ について $k+\sum_j w_j e^{\beta_j}$ は非零である。
:::

:::proof
共役不変性から $\prod_j(X-\beta_j)\in\Q[X]$ であり、整数倍したものを $G(X)\in\Z[X]$ とする。整数 $D\ge1$ を選んで全 $D\beta_j$ を代数的整数にする。これは各元を消す整数多項式の最高次係数を掛けるとモニック関係になることから可能である。代数的整数の和・積が代数的整数になるのは、有限個の代数的整数が生成する整係数環が、モニック関係によって有限生成の自由 $\Z$ 加群となり、乗法に Cayley–Hamilton を適用できるからである。また有理数である代数的整数は有理根の定理で整数である。

$p$ を $kDG(0)$ を割らない素数、$N=(p-1)+p\deg G$ とし
$$
f(X)=\frac{D^N X^{p-1}G(X)^p}{(p-1)!},\qquad F(X)=\sum_{i=0}^{N} f^{(i)}(X)
$$
と置く。$F-F'=f$ である。$F(0)$ は整数であり $F(0)\equiv D^NG(0)^p\pmod p$ である。実際、$p-1$ 未満の微分は零、$p-1$ 次は右辺、$p$ 次以上は $i!/(p-1)!$ を係数因子に持つ。各 $\beta_j$ では $f$ が少なくとも $p$ 重根を持つ。よって $F(\beta_j)/p$ は代数的整数である。高階微分の係数の整数因子に加え、$D^N$ が $\beta_j$ の全冪に対する分母を消すからである。重み付き和は共役不変で有理数だから $\sum_j w_j F(\beta_j)$ は $p$ の倍数の整数である。

$k+\sum_j w_j e^{\beta_j}=0$ と仮定する。線分積分により
$$
\int_0^{\beta_j}e^{\beta_j-z} f(z)\,\dd z=e^{\beta_j}F(0)-F(\beta_j).
$$
実際、$z=s\beta_j$（$0\le s\le1$）と置いて $e^{\beta_j-s\beta_j}F(s\beta_j)$ の実変数 $s$ に関する微分を取ると、$F-F'=f$ から積分の被積分式に負号を付けたものが得られる。
重み付き和は $-kF(0)-\sum_j w_j F(\beta_j)$ に等しい。これは $p$ で零にならない整数である。一方、有限本の線分で $z$、$G(z)$、$e^{\beta_j-z}$ は有界であり、$D^N$ も $p$ の指数関数で上から抑えられる。各積分の絶対値に $|w_j|$ を掛けた和は定数 $C_0,C_1$ により $C_0 C_1^p/(p-1)!$ 以下であり、$p$ を大きくすれば $1$ 未満になる。これが矛盾である。
:::

:::theorem[$e$ と $\pi$ の超越性]{#thm-gal-e-pi}
$e$ と $\pi$ は $\Q$ 上超越的である。
:::

:::proof
$e$ の非零整数係数の関係があれば、$e\ne0$ なので最小の冪で割って非零定数項を持たせる。指数 $j$ は整数なので補題を適用でき、矛盾する。

$\pi$ が代数的と仮定し、$i\pi$ の全共役を $\alpha_1,\dots,\alpha_n$ とする。Euler の公式で $e^{i\pi}=-1$ だから $\prod_j(1+e^{\alpha_j})=0$ である。この積を展開すると部分集合の和を指数とする項が現れる。零の指数を集めた定数項は、空集合の寄与があるので正の整数となる。残る非零指数の多重集合は共役置換で不変であり、全重みが $1$ である。補題で矛盾する。
:::

:::example[有理数倍]
$2\pi$ が代数的なら $2$ で割った $\pi$ が代数的になるので、$2\pi$ も超越的である。
:::

:::example[個別の超越性と関係]
$e^2$ は超越的である。代数的なら $e$ がその体上の二次式を満たすからである。ただし $e$ と $e^2$ には $Y-X^2$ の関係がある。
:::

### 代数的な操作で超越性を移す

:::proposition[非定数有理式による超越性の保存]{#prop-gal-transcendental-rational-value}
$z$ が $K$ 上超越的で、$r(T)\in K(T)$ が非定数なら $r(z)$ も $K$ 上超越的である。
:::

:::proof
$r(T)=A(T)/B(T)$ と置く。$z$ の超越性で $B(z)\ne0$ である。$w=r(z)$ とすれば $A(X)-wB(X)$ は $z$ を消す。これが零多項式なら、$B$ の非零係数の箇所を見て $w\in K$ であり、同時に $r(T)=w$ が定数になる。従って $z$ は $K(w)$ 上代数的である。$w$ が $K$ 上代数的なら推移性で $z$ が $K$ 上代数的となり矛盾する。
:::

:::example[超越数の式と二元の関係]
$e+1/e$ と $\pi/(1+\pi^2)$ はそれぞれ非定数有理式の値なので超越的である。一方 $u=e+1/e$ と $e$ は $e^2-ue+1=0$ を満たす。各元が超越的であっても、どちらも一つの超越的元の有理式であれば超越次数は一である。$e$ と $\pi$ の二つについては、この章の個別の超越性の証明から代数的独立性は従わない。
:::

### 積分の証明に現れる多項式を検算する

微分の消失、剰余、積分と整数の対応を具体的な小さい多項式で追う。

:::example[Hermite の構成で微分の階数を具体的に調べる]
$G(X)=X - 1$、$p=2$ と置き、$f(X)=X^{p-1}G(X)^p/(p-1)!$ を作る。$G$ の根は整数なので分母を消すための $D$ は $1$ でよい。$f$ は $0$ で $1$ 重、$G$ の各根で $2$ 重である。

## 演習問題

::::exercise{level=basic}
$\Q(t,t^2)$ の超越次数を求めよ。

:::solution
$t^2\in\Q(t)$ なので生成体は $\Q(t)$ に等しく、基底は $\{t\}$ である。
:::
::::

::::exercise{level=basic}
$K(t)/K(t^4)$ の次数を求めよ。

:::solution
分子 $t^4$、分母 $1$ を有理関数の次数公式に入れると $4$ である。
:::
::::

::::exercise{level=basic}
代数拡大の超越次数を求めよ。

:::solution
空集合で生成した体は基礎体であり、拡大はその上代数的なので空集合が基底である。超越次数は $0$ である。
:::
::::

::::exercise{level=basic}
$\pi+1$ が超越的な理由を述べよ。

:::solution
代数的なら $1$ を引いて $\pi$ が代数的になる。代数的数の集合は体であるため矛盾する。
:::
::::

::::exercise{level=advanced}
$K(t)/K((t^3+1)/(t^2+1))$ の次数を標数 $0$ で求めよ。

:::solution
$t^2+1$ の根は $i,-i$ であり、$t^3+1$ の値はそれぞれ $1-i,1+i$ で非零である。分子と分母は互いに素で、最大次数 $3$ が拡大次数である。
:::
::::

::::exercise{level=advanced}
$K(s,t)$ で $s+t,st$ が代数的独立であることを示せ。

:::solution
$s,t$ は $X^2-(s+t)X+st$ の根なので、元の体は二つの値が生成する体上代数的である。後者の超越次数は塔の公式により $2$ である。もし二元が従属なら、超越的な一方を選んで他方を代数的とでき、超越次数は高々 $1$ となる。
:::
::::

::::exercise{level=advanced}
$\F_p(t)/\F_p(t^p)$ の分離性を判定せよ。

:::solution
次数は $p$ だが、$X^p-t^p=(X-t)^p$ の相異なる根は一つである。したがって非分離である。
:::
::::

::::exercise{level=advanced}
$e^{-1}$ が代数的か判定せよ。

:::solution
もし代数的なら非零代数的数の逆元 $e$ も代数的となる。超越性の定理に矛盾する。
:::
::::
