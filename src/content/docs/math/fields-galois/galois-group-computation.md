## この章の目標

- 次数と置換作用の推移性を結び付ける。
- 三次式と四次式の Galois 群を求める。
- 素数を法とする因数分解の次数を置換の巡回型に変換する。

## Galois 群の置換表現と推移性

:::proposition[根への忠実な作用]{#prop-gal-root-action}
分離多項式 $f\in K[X]$ の相異なる根を $\alpha_1,\dots,\alpha_n$ とし、$K$ 上の分解体を $L$ とする。$G=\operatorname{Gal}(L/K)$ は根への作用により $S_n$ に埋め込まれる。軌道は $K[X]$ での既約因子の根集合である。
:::

:::proof
自己同型は係数を固定するため根を置換し、また全根を固定すれば生成体を固定する。根の像は同じ最小多項式の根である。逆に同じ既約因子の二根の間の単拡大の同型を $L$ に延長すると、正規性により自己同型となる。
:::

:::example[推移作用]
$X^3-2$ は有理根を持たず三根が一軌道になる。実根を添加した三次体に非実の原始三乗根を添加すると二次なので、分解体の次数は $6$ である。従って実根の固定部分群の位数は $6/3=2$ である。
:::

:::example[可約式での作用]
$(X^2-2)(X^2-3)$ では二つの軌道がある。根を各因子ごとに交換できるので、群は $S_2\times S_2$ である。
:::

### 既約因子、軌道、安定化群

モニック分離多項式 $f=\prod_i f_i$ を相異なる既約因子に分ける。根の軌道は各 $f_i$ の根集合である。係数を固定する置換は異なる因子の根を混ぜない。一方、同じ $f_i$ の二根の間の単拡大同型は分解体へ延びるので、一つの軌道になる。そのため群は $\prod_i S_{\deg f_i}$ に埋め込まれる。ただし各軌道上の置換が独立に生じるためには、対応する分解体の共通部分や合成体の次数を調べる必要がある。

:::example[可約でも二つの軌道に同じ符号が現れる]
$f=(X^2-2)(X^2-8)$ の分解体は $\Q(\sqrt2)$ である。根を $\sqrt2,-\sqrt2,2\sqrt2,-2\sqrt2$ の順で並べると、非自明な元は $(12)(34)$ である。どちらの二根も交換する写像はあるが、一方だけを交換する写像はない。$2\sqrt2$ という関係を保つ必要があるためである。対照的に $f=(X^2-2)(X^2-3)$ なら分解体は四次であり、前章の計算により各対を独立に交換できる。
:::

:::example[安定化群と根の体]
$f=X^3-5$ は $5$ に関する Eisenstein で既約であり、分解体は $L=\Q(\sqrt[3]5,\omega)$ である。$\Q(\sqrt[3]5)$ が実体なので $\omega$ の添加は二次であり、$[L:\Q]=6$ となる。群は三根に忠実に作用するため $S_3$ である。根 $\sqrt[3]5$ の安定化群は複素共役で生成され、他の二根だけを交換する。根の体の次数 $3$ はこの群の指数 $6/2$ からも得られる。
:::

## 判別式と交代群

:::definition[判別式]{#def-gal-polynomial-discriminant}
モニックな $f$ の根に順番を付けて $D=\prod_{i<j}(\alpha_i-\alpha_j)$ とし、$\Delta(f)=D^2$ を :term[判別式]{en="discriminant" yomi="はんべつしき"} という。
:::

:::proposition[偶置換の判定]{#prop-gal-discriminant-sign}
分離多項式で $\operatorname{char}K\ne2$ とする。$\Delta(f)\in K$ であり、$G\le A_n$ と $\Delta(f)$ が $K$ の平方であることは同値である。
:::

:::proof
隣り合う二根を交換すると $D$ の符号だけが反転する。隣接互換は $S_n$ を生成するため $\sigma D=\sgn(\sigma)D$ である。ゆえに $D^2$ は全群に固定され $K$ に入る。$D$ は非零で $D\ne-D$ なので、$D\in K$ と $G\le A_n$ が同値になる。また $a^2=D^2$ の解は $\pm D$ だけなので、平方性と $D\in K$ は同値である。
:::

計算には $\Delta(f)=(-1)^{n(n-1)/2}\prod_i f'(\alpha_i)$ が使える。実際、$f'(\alpha_i)=\prod_{j\ne i}(\alpha_i-\alpha_j)$ であり、各対が逆符号の因子を二つ出す。

判別式が非平方のとき、$G\cap A_n$ に対応する中間体は $K(D)$ である。実際 $D$ を固定する元はちょうど偶置換であり、$D$ は $X^2-\Delta(f)$ の根である。この二次体の上で同じ多項式を考えると、分解体を保ったまま群が偶置換に限られる。

:::example[二次式]
$X^2-X-1$ の二根の差の平方は $1+4=5$ である。非平方なので群は二根の互換を含む。
:::

:::example[判別式が平方になる可約式]
$(X^2-2)(X^2-8)$ の分解体は $\Q(\sqrt2)$ である。符号反転は二対を同時に交換する偶置換なので、判別式は有理数の平方である。
:::

### 標数二で符号を調べる

標数 $2$ では $1=-1$ なので、根の差の積の符号から偶置換と奇置換を区別できない。代わりに、根の順序を入れ替えると値が $1$ だけ変わる式を使う。

:::proposition[標数二の判別式]{#prop-gal-char-two-discriminant}
標数 $2$ で分離多項式の根を $\alpha_1,\ldots,\alpha_n$ とする。
$$
B=\sum_{i<j}\frac{\alpha_i}{\alpha_i+\alpha_j},\qquad
\Delta_2=B^2+B=\sum_{i<j}\frac{\alpha_i\alpha_j}{(\alpha_i+\alpha_j)^2}
$$
と置くと $\Delta_2\in K$ であり、$G\subseteq A_n$ であることは $Y^2+Y=\Delta_2$ が $K$ に解を持つことと同値である。
:::

:::proof
異なる根なので分母は零でない。隣り合う根の交換では、それら二根に関する一項だけが $\alpha_i/(\alpha_i+\alpha_j)$ から $\alpha_j/(\alpha_i+\alpha_j)$ に変わり、差は $1$ である。他の項は単に並べ替えられる。従って偶置換は $B$ を固定し、奇置換は $B+1$ へ移す。$B^2+B$ はどちらでも同じなので係数体に属す。二根は $B,B+1$ であるから、$K$ の解があることと $B$ が固定されることは同値である。最後の和の表示は標数 $2$ で各項の二乗と元の項を加えると得られる。
:::

:::example[奇置換が見える可約式]
$\F_2$ の $X(X^2+X+1)$ の根を $0,u,u+1$ とする。零を含む対の寄与は全て零であり、残る対の和と積はどちらも $1$ なので $\Delta_2=1$ である。$\F_2$ では $Y^2+Y$ は常に零であるため、二つの二次根を交換する奇置換が群に入る。
:::

### 導関数の値から判別式を計算する

:::proposition[導関数の積としての判別式]{#prop-gal-discriminant-resultant}
$f$ をモニックで次数 $n$ の分離多項式とし、根を $a_i$ とする。このとき
$$
\Delta(f)=(-1)^{n(n-1)/2}\prod_i f'(a_i).
$$
また異なるモニック分離多項式 $g,h$ の根集合が交わらないなら、$\Delta(gh)=\Delta(g)\Delta(h)\prod_{g(a)=0}h(a)^2$ である。
:::

:::proof
$f'(a_i)=\prod_{j\ne i}(a_i-a_j)$ である。積の中で添字の組 $i<j$ ごとに $(a_i-a_j)(a_j-a_i)=-(a_i-a_j)^2$ が現れるため最初の式を得る。二番目については、$gh$ の根の対を同じ因子内の対と異なる因子間の対に分ける。同じ因子内の積は各判別式であり、異なる因子間は $\prod_{g(a)=0}\prod_{h(b)=0}(a-b)^2=\prod_{g(a)=0}h(a)^2$ である。
:::

モニックな $f$ の判別式は、商環 $K[X]/(f)$ で $f'$ を掛ける線形写像の行列式に $(-1)^{n(n-1)/2}$ を掛けた値でもある。$f$ が分離的なら、根を含む拡大体上で商を根での評価の直積へ移すと、対角成分が $f'(a_i)$ になる。$f$ に重根があれば $\gcd(f,f')$ は非定数なので、$f'$ は商で非単元となり、掛け算の行列式も判別式も零になる。

:::example[三次二項式から群の二次体を得る]
$f=X^3-5$ では $f'(a_i)=3a_i^2$ と $\prod_i a_i=5$ から $\Delta(f)=-27\cdot25=-675$ となる。$-675=-3\cdot15^2$ なので、全根の差の積が生成する二次体は $\Q(\sqrt{-3})$ である。これは $\omega$ が生成する二次体に等しい。三根の偶置換はその積を固定し、奇置換は符号を変える。
:::

:::example[根を式で求めずに積の判別式を出す]
$g=X^2-2$、$h=X^2-3$ なら $\Delta(g)=8,\Delta(h)=12$ であり、$g$ の根では $h(a)=-1$ だから交差項の積は $1$ である。従って $\Delta(gh)=96$ となる。これが非平方であることは、二つの対の片方だけを交換する自己同型が存在することと両立する。一方 $h=X^2-8$ では $\Delta(h)=32$、各 $h(a)=-6$ であり $8\cdot32\cdot6^4$ は平方になる。両対の交換が連動することが判別式にも現れている。
:::

### 導関数の積を因子ごとに検算する

二次因子の根を具体的に展開せず、他方の因子を代入して残る定数から交差項を得る。

:::example[二つの二次因子の判別式を組み立てる]
$f_1=X^{2} - 5$、$f_2=X^{2} - 13$ とする。どちらも二次で、共通根はない。判別式はそれぞれ $20,52$ である。一方 $f_1(a)=0$ なら $f_2(a)=-8$ であり、$f_1$ の二根でこの値を掛けると $64$ になる。

$$
\begin{aligned}
\Delta(f_1f_2)&=\Delta(f_1)\Delta(f_2)\left(\prod_{f_1(a)=0}f_2(a)\right)^2,\\
\Delta(f_1f_2)&=20\cdot 52\cdot 64^2=4259840
\end{aligned}
$$

| 素因数 | 判別式に現れる指数 |
| --- | --- |
| 2 | 16 |
| 5 | 1 |
| 13 | 1 |

奇数の指数を持つ素数があるので非平方である。二つの平方根の平方類は異なり、片方だけの反転も可能である。単独の互換が存在することと判別式は一致している。
:::


:::example[二つの二次因子の判別式を組み立てる]

$$

## 3 次多項式の Galois 群

:::proposition[既約三次式]{#prop-gal-cubic-group}
標数 $2$ 以外の体上の既約かつ分離的な三次式の群は、判別式が平方なら $A_3$、そうでなければ $S_3$ である。
:::

:::proof
推移性により位数は $3$ の倍数である。$S_3$ の位数は $6$ なので、可能性は $3,6$ である。前者の群は三巡回で生成され $A_3$ である。あとは :ref[prop-gal-discriminant-sign] を適用する。
:::

$f=X^3+pX+q$ なら $\prod_i(3\alpha_i^2+p)=27q^2+4p^3$ である。展開では $\sum_i\alpha_i^2=-2p$、$\sum_{i<j}\alpha_i^2\alpha_j^2=p^2$、$\prod_i\alpha_i^2=q^2$ を使う。よって $\Delta=-4p^3-27q^2$ である。

一般のモニック三次式 $X^3+bX^2+cX+d$ の判別式は
$$
b^2c^2-4c^3-4b^3d-27d^2+18bcd
$$
である。標数 $0$ では $X=Y-b/3$ と置くと、$Y$ の係数は $p=c-b^2/3$、定数項は $q=d-bc/3+2b^3/27$ となる。根の差は平行移動で変わらないので、$-4p^3-27q^2$ を展開すれば上の式になる。両辺を独立な三根の多項式として書くと、整数係数の恒等式である。従って式は標数 $3$ を含む任意の標数で成り立つ。標数 $2$ で既約分離三次式の群を判定するには、通常の判別式の平方性の代わりに :ref[prop-gal-char-two-discriminant] の方程式を調べる。推移的な群の位数が $3$ または $6$ になる議論はそのまま使える。

:::example[非可換な群]
$X^3-2$ の判別式は $-108$ であり、平方でないので $S_3$ である。
:::

:::example[巡回三次]
$X^3-3X+1$ は $\pm1$ を根に持たず既約である。判別式は $108-27=81$ であり、群は $C_3$ である。
:::

### 三次式の一根から残りの二根を求める

:::example[根の体に判別式の平方根を添加する]
$f=X^3+pX+q$ の相異なる根を $a,b,c$ とし、$V=(a-b)(a-c)(b-c)$ と置く。$b+c=-a$ であり、$f'(a)=(a-b)(a-c)$ だから $b-c=V/f'(a)$ となる。標数が二でなければ
$$
b=\frac{-a+V/f'(a)}2,\qquad
c=\frac{-a-V/f'(a)}2
$$
である。従って $K(a,V)$ が分解体である。例えば $X^3-2$ では $V=6\sqrt{-3}$ の符号を選べば $V/f'(a)=2\sqrt{-3}/a^2=a\sqrt{-3}$ となる。上式は $a$ の二つの非実共役を与える。既約三次式で $V\notin K$ なら、三次体に二次体は含まれないので、この添加が二次であることも確かめられる。
:::

:::example[平方判別式の場合の直接計算]
$f=X^3-3X+1$ は $\pm1$ が根でないから既約である。$\Delta(f)=81$ なので、$a$ を一根として $V=9$ を選ぶと $b-c=3/(a^2-1)$ である。$a^3=3a-1$ を使うと
$$
(a^2-1)(2a^2+a-4)=3.
$$
したがって $b=a^2-2$、$c=-a^2-a+2$ となる。$a\mapsto b$ は他の根を巡回させる。実際 $(a^2-2)^2-2=-a^2-a+2$ であり、$a,b,c$ は相異なる。全部の根が一根の体に入ることを判別式の判定と式の両方で確認できる。
:::

## 4 次多項式と 3 次分解式

$f=X^4+bX^3+cX^2+dX+e$ の根を $a_1,\dots,a_4$ とする。四点を二対に分ける三通りの組合せを数で記録するため、$u=a_1a_2+a_3a_4$、$v=a_1a_3+a_2a_4$、$w=a_1a_4+a_2a_3$ と置く。

:::definition[三次分解式]{#def-gal-cubic-resolvent}
$u,v,w$ を根とする式
$$
R_f(Y)=Y^3-cY^2+(bd-4e)Y+4ce-b^2e-d^2
$$
を :term[三次分解式]{en="cubic resolvent" yomi="さんじぶんかいしき"} と呼ぶ。
:::

係数を確かめるため、$s_i$ を根の第 $i$ 基本対称式とする。和は $s_2$ である。二個ずつの積の和は、$s_1s_3$ の展開で四根を一度ずつ含む四項を除いたものなので $s_1s_3-4s_4$ となる。三個の積の展開は、$s_4\sum_i a_i^2$ と四つの三重積の平方和である。前者は $s_4(s_1^2-2s_2)$、後者は $s_3^2-2s_4s_2$ なので積は $s_1^2s_4+s_3^2-4s_2s_4$ である。ここに $(s_1,s_2,s_3,s_4)=(-b,c,-d,e)$ を代入する。差 $u-v=(a_1-a_4)(a_2-a_3)$ と同様の式から、$f$ が分離的なら三根は相異なる。

:::theorem[既約四次式の群の判定]{#thm-gal-quartic-group}
標数 $2$ 以外とする。既約分離四次式について、$R_f$ が既約なら $\Delta(f)$ が平方のとき $A_4$、そうでなければ $S_4$ である。$R_f$ が三つの一次式の積なら Klein の四元群 $V_4$ である。因子次数が $1,2$ なら $C_4$ または位数 $8$ の二面体群 $D_4$ であり、根一つの生成体が正規かどうかで順に区別できる。
:::

:::proof
三分割への $S_4$ の準同型は全射である。例えば互換と三巡回の像はそれぞれ互換と三巡回になる。核は恒等写像と三つの二重互換からなる $V_4$ である。推移的な $G$ は位数が $4$ の倍数である。分解式が既約なら像の位数は $3$ の倍数なので、$|G|=12,24$ に限られる。位数 $12$ の部分群は指数 $2$ であり、全互換が共役だから商への写像は全互換を同じ非自明元へ送る。よって群は $A_4$ である。

像が自明なら、$G\subseteq V_4$ と次数から等号になる。像の位数が $2$ なら $G$ は一つの分割を保つ。全安定化群は各対の内側を交換し、対どうしも交換できる位数 $8$ の群であり、正方形の対角線の分割と同一視すると $D_4$ である。$|G|=4$ の場合、像が非自明であるため $G$ は $V_4$ でない。四点への推移作用では単独の互換は固定点を持つため、位数 $4$ の群に入れない。したがって位数 $4$ の置換があり $G=C_4$ となる。この場合だけ根の固定群が自明で、根一つの生成体が分解体となる。位数 $8$ の場合に根の体が正規なら、正規な根の体には四根がすべて入るため次数が $4$ のはずであり矛盾する。
:::

この証明の置換に関する部分は標数 $2$ でも成り立つ。すなわち、分解式が既約のときだけ偶奇の判定を :ref[prop-gal-char-two-discriminant] に替えればよい。分解式が一次因子を持つ場合は、元の四次式が分離的であれば、分解式の因子次数と根の体の正規性による判定をそのまま用いられる。

:::example[二面体群]
$X^4-2$ では $R_f=Y^3+8Y=Y(Y^2+8)$ である。実根の体は非実根を含まないため $D_4$ である。
:::

:::example[巡回群と四元群]
$X^4+X^3+X^2+X+1$ は $X\mapsto X+1$ の後で $5$ に関する Eisenstein を使える。全根が一根の冪なので根の体が正規で、$2$ 乗を取る置換は根を長さ $4$ で巡る。この群は $C_4$ である。一方 $X^4-10X^2+1$ の根は $\pm\sqrt2\pm\sqrt3$ であり、群は独立な符号反転の $V_4$ である。
:::

### 四次の判定を実際に止める条件

分解式の因子次数が $1,2$ のとき、三根を改めて求める必要はない。四次式の一根 $\alpha$ を形式的に添加した $K[X]/(f)$ で $f/(X-\alpha)$ を分解する。三次の商が完全分解なら根の体は正規で $C_4$、一つでも非一次因子があれば正規性がなく $D_4$ である。これは :ref[thm-gal-quartic-group] の最後の判定を商環の演算で行ったものである。

:::example[既約な分解式と非平方判別式]
$f=X^4-X-1$ の標数 $2$ の還元は $X^4+X+1$ である。$0,1$ のどちらも根にならず、唯一の既約二次 $X^2+X+1$ で割った剰余が $1$ なので既約である。モニック整係数の因数分解があれば還元後も同じ次数で分解するので、$f$ は $\Q$ で既約である。分解式は $Y^3+4Y-1$ であり、$\pm1$ のいずれも根でないため既約である。

判別式は $-283$ である。これを導関数 $f'=4X^3-1$ の根 $\beta_j$ で計算する。$\beta_j^3=1/4$ から $f(\beta_j)=-3\beta_j/4-1$ である。$f$ と $f'$ の根の差を積にした式は両方向で同じ符号になる。次数の積が $12$ だからである。従って
$$
\Delta(f)=4^4\prod_{j=1}^3\left(-1-\frac34\beta_j\right)
=4^4\left(-1-\frac{27}{256}\right)=-283.
$$
よって正方ではなく、群は $S_4$ となる。
:::

:::example[既約な分解式と平方判別式]
$f=X^4-2X^3+2X^2+2$ を考える。$2$ で Eisenstein なので既約である。分解式は $Y^3-2Y^2-8Y+8$ で、有理根の候補 $\pm1,\pm2,\pm4,\pm8$ はどれも根にならない。この三次式では $Y=Z+2/3$ と置くと $p=-28/3,q=56/27$ の減次形になる。したがって判別式は $-4p^3-27q^2=3136=56^2$ である。

四次式と分解式の判別式は等しい。実際、$u-v$、$v-w$、$w-u$ をそれぞれ根の差二つの積と書くと、全ての根の対の差が一度ずつ出る。符号は平方で消える。よってこの例の群は $A_4$ である。
:::

### 分解式の係数を根から導く

四根を $a,b,c,d$ とし、$u=ab+cd,v=ac+bd,w=ad+bc$ と置く。基本対称式を $s_1,s_2,s_3,s_4$ とすれば $u+v+w=s_2$ である。また $uv+vw+wu$ は、$a^2bc$ の形の十二項を各一回ずつ含む。$s_1s_3$ はこれに $4abcd$ を加えたものである。最後に $uvw$ は $abcd(a^2+b^2+c^2+d^2)$ と $(abc)^2+(abd)^2+(acd)^2+(bcd)^2$ の和である。第一部分は $s_4(s_1^2-2s_2)$、第二部分は $s_3^2-2s_4s_2$ になる。この三式から
$$
R_f(Y)=Y^3-s_2Y^2+(s_1s_3-4s_4)Y-(s_1^2s_4+s_3^2-4s_2s_4)
$$
が従う。$u-v=(a-d)(b-c)$ などの式から $u,v,w$ は相異なり、根の二対への分割を忠実に区別する。

:::example[二次の式に落とせる四次式]
$f=X^4-5X^2+5$ を考える。$5$ に関する Eisenstein により既約である。根を $a,-a,b,-b$ とすれば $a^2+b^2=5$、$a^2b^2=5$ であり、$R_f=(Y+5)(Y^2-20)$ になる。$a^2$ の値を $(5+\sqrt5)/2$ と取ると $\sqrt5=2a^2-5\in\Q(a)$ である。そのため $b=\sqrt5/a$ が $\Q(a)$ に入り、他の根も全て入る。分解式の因子次数が $1,2$ で根の体が正規だから、群は $C_4$ である。$X^4-2$ の場合とはここで判定が分かれる。
:::

## 素数次既約多項式と対称群

:::proposition[素数個の点と互換]{#prop-gal-prime-transposition}
素数 $p$ 個の点に推移的に作用する部分群 $G\le S_p$ が互換を含むなら $G=S_p$ である。
:::

:::proof
互換 $(a\,b)$ の $G$ 共役の端点を辺とするグラフを作る。$G$ は連結成分を推移的に交換するため、成分の大きさは等しく $p$ を割る。辺があるので成分の大きさは $1$ でなく、グラフは連結である。経路で隣り合う互換を合成・共役すると両端の互換が得られる。例えば $(a\,b)(b\,c)(a\,b)=(a\,c)$ である。よって全互換が $G$ に属する。
:::

:::example[複素共役を使う]
有理係数の素数次既約式で非実根がちょうど二つなら、複素共役は互換である。したがって群は全対称群である。三次式 $X^3-2$ が小さな例である。
:::

:::example[合成数では結論が変わる]
$X^4-2$ の群は推移的で、複素共役が非実根 $ia,-ia$ だけを交換する。しかし群は位数 $8$ であり、互換の共役で作る辺は二つの対に分かれる。
:::

### 互換を単独で取り出す

群が巡回型 $(m_1,\ldots,m_r,2)$ の元を持ち、$m_i$ がすべて奇数であれば、$m_i$ の最小公倍数を冪に取ると、長さ $2$ の巡回だけが残る。従って素数次の既約式では、互換そのものを得る前に別の巡回型を探してもよい。

:::example[七点で冪を取る]
巡回型 $(3,2,1,1)$ の元 $g=(123)(45)$ について $g^3=(45)$ である。七点に推移的な群なら、互換の共役から作るグラフの連結成分はすべて同じ大きさを持つ。一つの成分は互換の辺を含み大きさが二以上なので、七が素数であることからグラフ全体が連結になる。従って七点の対称群を含む。これに対し $(3,2,2)$ の元では三乗が二重互換になり、この手順からは単独の互換を得られない。
:::

:::example[小さい素数次では奇置換と互換が近い]
三点上では奇置換は互換なので、非平方判別式と推移性で直ちに $S_3$ を得る。五点では四巡回も奇置換であり、その二乗は二重互換である。従って非平方判別式だけから素数次の互換定理を使うことはできない。例えば $\F_5$ の元の集合に作用する $x\mapsto 2x$ は零を固定し非零元を四巡回する。平行移動を加えて生成する二十元の推移群は $S_5$ より小さい。実際、これらは $x\mapsto ax+b$（$a\in\F_5^\times,b\in\F_5$）という二十通りの写像に尽きる。
:::

五次式が既約だと分かれば、さらに互換一つから群が決まる。相異なる素数に二つの役割を持たせる。

## Dedekind の定理（素数を法とする還元）

:::theorem[還元による巡回型]{#thm-gal-dedekind}
モニック $f\in\Z[X]$ と素数 $p$ に対し、$\F_p[X]$ の還元 $\bar f$ が相異なる既約因子に分かれ、その次数が $d_1,\dots,d_r$ なら、$f$ の $\Q$ 上の Galois 群は巡回型 $(d_1,\dots,d_r)$ の元を持つ。
:::

:::proof
ここでは $p$ 進整数を $\Z_p=\varprojlim_k\Z/p^k\Z$ として用いる。元は両立する剰余の列であり、$p$ で零でない元は各段で逆元を取れるので単元である。また非零元は最初の非零剰余を読むことで $p^j$ と単元の積に書ける。二つの非零元の積の指数は指数の和になるため、$\Z_p$ は整域である。非零整数はすべての $p^k$ で割れることはないので、$\Z$ はこの環に埋め込まれる。

$k$ を $\bar f$ の $\F_p$ 上の分解体とする。$k$ は有限次なので有限体であり、完全性と :ref[thm-gal-primitive] により $k=\F_p[\bar u]$ と書ける。$a\mapsto a^p$ は $k$ の自己同型で、固定元は $X^p-X$ の根である $\F_p$ の元に限られる。既約因子の一根の Frobenius 軌道の積は係数が固定されるので $\F_p[X]$ に属する。一方でこの軌道はすべてその既約因子の根である。従って軌道の長さはその因子の次数である。

$\bar u$ のモニック最小多項式 $\bar g$ を $g\in\Z_p[X]$ に持ち上げ、$A=\Z_p[X]/(g)$ とする。$A$ はモニック除法により有限階数の自由 $\Z_p$ 加群で、$A/pA=k$ である。$p$ の全冪で割れる元は零であり、非零元から最大の $p$ 冪を外せば非零剰余を持つ。非零剰余の積は非零なので $A$ は整域である。

$A$ の任意の多項式 $h$ に対し、$\bar h$ の単根は $A$ に一意に持ち上がる。解 $z$ が $p^j$ で与えられたら、$z+p^j v$ への更新で
$$
h(z+p^jv)\equiv h(z)+p^jv h'(z)\pmod{p^{j+1}}
$$
となる。$v\bmod p$ は $k$ で一意に決まり、列を取ると自由加群の各座標で極限が存在する。この操作を $g$ の根 $\bar u^p$ に行い、持ち上げた根を $\beta$ とする。$X$ の類を $\beta$ に移す $A$ の準同型は、剰余上で $p$ 乗写像である。逆の Frobenius にも同じ根の持ち上げを行えば、二つの合成は $X$ の像を元と同じ剰余を持つ $g$ の根に送る。一意性から合成は恒等写像であり、よって自己同型である。

$f$ の各単根を同じ方法で $A$ に持ち上げると、相異なる $n=\deg f$ 個の根が得られる。この自己同型はそれらを $k$ の Frobenius と同じ巡回型で置換し、$A$ の分数体内で $\Q$ と根が生成する体を保つ。この生成体は $f$ の分解体なので、制限が求める元である。
:::

:::example[三巡回の検出]
$X^3-2$ を $7$ で還元する。立方の値は $0,1,-1$ だけなので式は既約である。よって群に三巡回が含まれる。
:::

:::example[互換の検出]
$X^3-2$ の $5$ での還元は $(X-3)(X^2+3X+4)$ である。二次因子の判別式は $3$ で非平方なので、巡回型は $(1,2)$ である。
:::

### 単根の持ち上げを一段ずつ計算する

:::example[整数の剰余から二次式の根を持ち上げる]
$X^2-2$ は $7$ を法として $3$ が根であり、導関数 $2\cdot3=6$ が非零である。$z=3+7v$ を入れると
$$
z^2-2\equiv 7(1+6v)\pmod{49}
$$
である。$1+6v\equiv0\pmod7$ から $v=1$ となり、$z\equiv10\pmod{49}$ を得る。次に $10+49w$ を入れると
$$
(10+49w)^2-2\equiv 49(2+20w)\pmod{343}
$$
であり、$w=2$ なので $z\equiv108\pmod{343}$ となる。初期剰余 $-3$ からは各段で負の解が得られる。$7$ での因子次数は $1,1$ なので、この素数から検出される巡回型は恒等置換である。
:::

:::example[悪い素数では根の剰余が衝突する]
同じ $X^2-2$ を $2$ で還元すると $X^2$ であり、根 $0$ は重根である。$z=2v$ は $z^2-2\equiv2\pmod4$ となり、剰余の根を法 $4$ まで持ち上げられない。標数 $0$ の根が相異なっていても、還元して得た多項式の根が相異なるという仮定が必要である。
:::

### 因子次数の記録から群を絞る

モニックな整数係数の $f$ に対して、判別式は整数であり、$\bar f$ が平方自由なための必要十分条件は $p\nmid\Delta(f)$ である。実際、冪基底で $f'$ を掛ける行列を作るにはモニックな $f$ で割って剰余を取るだけなので、行列の成分は整数である。その行列を還元すると $\bar f'$ を掛ける行列になる。行列式が非零である条件は、$\bar f'$ が商環で逆元を持つこと、すなわち $\gcd(\bar f,\bar f')=1$ である。

還元一回で得るのは、群にある巡回型が含まれるという情報である。ある型が一つの還元に出ないことから、その型が群に存在しないとは結論できない。既約な還元が一つあれば :ref[thm-ring-poly-reduction]{text="還元既約判定"}で元の式の既約性を示せる。一方、小さい因子を持つ還元があっても、元の式の可約性を直ちには示せない。三次の例 $X^3-2$ では $7$ で既約かつ $5$ で一次と二次に分かれ、両条件は両立している。

## Galois の逆問題と一般多項式

:::definition[逆 Galois 問題]{#def-gal-inverse-problem}
与えられた有限群 $G$ を $\Q$ 上の有限 Galois 拡大の群として実現できるかという問いを :term[逆 Galois 問題]{en="inverse Galois problem" yomi="ぎゃくがろあもんだい"} という。
:::

すべての有限群についての答えは未解決である。係数体を自由に選べば、有限群を有限 Galois 群として実現できる。実際、$G$ を左乗法によって $S_{|G|}$ に埋め込み、次に示す一般多項式の分解体の中で $G$ の固定体を基礎体とすればよい。

:::theorem[一般多項式の群]{#thm-gal-generic-symmetric}
$K$ 上独立な不定元 $x_1,\ldots,x_n$ とその基本対称式 $s_i$ に対し、$K(x_1,\ldots,x_n)/K(s_1,\ldots,s_n)$ は Galois 拡大で群が $S_n$ である。また $s_i$ は代数的に独立である。
:::

:::proof
$\prod_i(X-x_i)$ は係数が $K(s_1,\ldots,s_n)$ に入り、相異なる全根が上の体を生成するので Galois である。各変数置換が係数体を固定し、根への忠実な作用により群は $S_n$ に等しい。辞書式順序 $x_1>\cdots>x_n$ で $s_i$ の先頭項は $x_1\cdots x_i$ である。積 $s_1^{a_1}\cdots s_n^{a_n}$ の先頭項の指数列は $(a_1+\cdots+a_n,a_2+\cdots+a_n,\dots,a_n)$ で、元の指数列を回復できる。したがって $s_i$ の非零多項式の最大先頭項は消えず、代数的独立性を得る。
:::

:::example[一般式と特殊化]
一般三次式の群は $S_3$ であるが、$X^3-3X+1$ に係数を特殊化すると $C_3$ になる。一般式の係数は独立な不定元なので、その群だけでは個々の特殊化の群は決まらない。
:::

:::example[有理数上の小さな実現]
$\Q(\sqrt2,\sqrt3)/\Q$ は $C_2\times C_2$ を実現し、$X^4-2$ の分解体は $D_4$ を実現する。一般多項式の係数体は有理関数体なので、上の定理の係数体と逆問題の係数体を区別する。
:::

### 有理数体上で対称群を実現する

:::theorem[還元を指定して対称群を作る]{#thm-gal-symmetric-realization}
任意の $n\ge2$ に対して、$\Q$ 上に Galois 群 $S_n$ を持つモニック既約 $n$ 次多項式が存在する。
:::

:::proof
$n=2$ は $X^2-2$ が例になる。$n\ge3$ では $n$ より大きい相異なる三素数を取り、それぞれを法とする多項式の因子次数を $(n)$、$(n-1,1)$、$(2,1,\ldots,1)$ と指定する。素数 $p$ と任意の正整数 $d$ について、$X^{p^d}-X$ の分解体で根の集合は $p^d$ 乗写像の固定体であり、導関数が $-1$ なので $p^d$ 個の元を持つ。従って根でできた体は $\F_p$ 上 $d$ 次である。有限体は完全なので、原始元定理で生成元を取り、その最小多項式を使えば $d$ 次の既約式を得る。有限体の一般論は [有限体](/math/fields-galois/finite-fields/) で扱う。

一次因子は互いに異なる根を選び、既約因子はいずれも分離的である。よって還元は三つとも平方自由である。:ref[thm-ring-crt]{text="中国式剰余定理"}により、各係数の三つの剰余を同時に持つモニック整係数式を作れる。

最初の還元が既約なので、:ref[thm-ring-poly-reduction]{text="還元による既約性の判定"}により式は $\Q$ で既約である。従って群は推移的である。第二の還元から $(n-1)$ 巡回が得られ、その固定点の安定化群は残りの点に推移的に作用する。他の点の安定化群も共役なので同じ性質を持つ。従って全群は異なる二点の順序付きの組に推移的である。第三の還元から互換が得られ、二点の組への推移性によりこれを共役して任意の互換を得られる。従って全群は $S_n$ である。
:::

:::example[四次で三種類の還元を作る]
$f=X^4+14X^3+2X^2+3X-5$ は $2$ を法として $X^4+X+1$ となる。これは線形因子を持たず、唯一の既約二次で割った剰余は $1$ である。$3$ を法としては $(X-1)(X^3-X-1)$ となり、三次因子は $X^3-X$ が全元で零になることから既約である。$5$ を法としては $X(X-1)(X^2+2)$ となり、$-2$ は平方でないので二次因子は既約である。従って巡回型の三条件から群は $S_4$ である。
:::

### 置換の作用から基礎体の生成元を作る

:::example[三次交代群を適切な基礎体の上で実現する]
独立な $a,b,c$ と $K$ に対し $L=K(a,b,c)$、$M=K(a+b+c,ab+bc+ca,abc)$ とする。標数を二以外とし、$V=(a-b)(a-c)(b-c)$ を取る。$V^2\in M$、$V\notin M$ なので $M(V)/M$ は二次である。交代群 $A_3$ は $V$ を固定するため $L/M(V)$ の Galois 群は $A_3$ になる。別の基礎体 $M(a)$ を選ぶと群は $a$ の安定化群である位数二の群になる。同じ分解体のどの元を基礎体に降ろすかで、実現される群が変わる。
:::

:::example[有理数体上の巡回群と置換表現の違い]
$\Q(\zeta_5)/\Q$ の自己同型は $\zeta_5\mapsto\zeta_5^j$（$j=1,2,3,4$）であり、$j=2$ は位数四である。従って位数四の巡回群を実現する。また $\Q(\sqrt2,\sqrt3)/\Q$ は同じ位数で四元群を実現する。どちらも原始元の最小多項式を使えば四根に正則に作用する。後者には四巡回がなく、非自明元がすべて二重互換である。群の位数と作用の推移性だけでは、二つを識別できない。
:::

## 演習問題

::::exercise{level=basic}
$X^3-3X+1$ の判別式を求めよ。

:::solution
$-4(-3)^3-27=108-27=81$ である。
:::
::::

::::exercise{level=basic}
$X^4-2$ の三次分解式を求めよ。

:::solution
$b=c=d=0,\ e=-2$ を代入すると $Y^3+8Y$ である。
:::
::::

::::exercise{level=basic}
$\Q$ 上の分離式 $f=(X^2-2)(X-1)$ の群を根の置換で書け。

:::solution
分解体は $\Q(\sqrt2)$ である。$1$ は固定され、非自明元は $\pm\sqrt2$ を交換する。
:::
::::

::::exercise{level=basic}
$X^3-2$ の $5$ での還元が単根からなることを確認せよ。

:::solution
導関数は $3X^2$ で唯一の根は $0$ だが、元の式は $0$ で $-2$ となる。共通根がなく分離的である。
:::
::::

::::exercise{level=advanced}
$X^3+X+1$ の $\Q$ 上の群を求めよ。

:::solution
$\pm1$ のいずれも根でない。判別式は $-4-27=-31$ で平方ではないので $S_3$ である。
:::
::::

::::exercise{level=advanced}
三次分解式が $Y(Y-1)(Y+1)$ となる既約分離四次式が標数 $0$ の体上にあるとする。その群を求めよ。

:::solution
三分割の根がすべて基礎体にあるので作用の像は自明である。核は $V_4$ であり、推移性から位数は少なくとも $4$ なので $V_4$ となる。
:::
::::

::::exercise{level=advanced}
モニックな $f\in\Z[X]$ の $\F_p$ 上の還元が既約な二次因子と三次因子の積なら、$f$ の $\Q$ 上の群に互換が入ることを示せ。

:::solution
因子が相異なる既約式なら :ref[thm-gal-dedekind] により互いに素な二巡回と三巡回の積が入る。その三乗は二巡回だけになる。
:::
::::

::::exercise{level=advanced}
$X^4-10X^2+1$ の三次分解式を分解せよ。

:::solution
代入すると $Y^3+10Y^2-4Y-40$ である。$Y^2(Y+10)-4(Y+10)=(Y+10)(Y-2)(Y+2)$ と分けられる。
:::

::::quiz{answer="3" tol="0"}
標数 $0$ の体上の既約三次式の判別式が $49$ なら、群の位数はいくつか。

:::explanation
$49=7^2$ なので群は $A_3$ で位数は $3$ である。

::::quiz
分離的な還元で因子次数が $1,4$ である。群に存在することが従う元を選べ。

- [x] 一つの点を固定する長さ $4$ の巡回
- [ ] 長さ $5$ の巡回
- [ ] 長さ $3$ の巡回

:::explanation
巡回の長さは因子次数と一致するので、長さ $1$ と $4$ の組である。
:::

::::quiz{answer="8" tol="0"}
$X^4-2$ の $\Q$ 上の分解体の群の位数を求めよ。

:::explanation
実四乗根で次数 $4$、$i$ の添加で次数 $2$ なので、分解体の次数と群の位数は $8$ である。
:::

::::quiz
一般三次式の係数を特殊化したときについて正しい記述を選べ。

- [x] 特殊化により $C_3$ になる例がある。
- [ ] 常に $S_3$ である。
- [ ] 常に三次式は可約になる。

:::explanation
$X^3-3X+1$ は有理根を持たない既約式で、その判別式 $81$ が平方なので群は $C_3$ である。

::::quiz{answer="120" tol="0"}
分離的な既約五次式の群に巡回型 $(2,3)$ が含まれるとき、群の位数を求めよ。

:::explanation
この元の三乗が互換である。既約性から五点で推移的であり、素数次の互換の判定から対称群になる。位数は $5!=120$ である。
