## この章の目標

- 冪根の添加から巡回拡大を作る。
- Kummer 対応と双対性を証明する。
- 標数が次数を割る場合に Artin–Schreier 方程式を使う。

## 巡回拡大の特徴付け

:::definition[巡回拡大]{#def-gal-cyclic-extension}
有限 Galois 拡大で Galois 群が巡回群であるものを :term[巡回拡大]{en="cyclic extension" yomi="じゅんかいかくだい"} と呼ぶ。
:::

:::theorem[原始冪根を含む体上の巡回拡大]{#thm-gal-cyclic-radical}
$\operatorname{char}K\nmid n$ とし、$K$ が原始 $n$ 乗根 $\zeta$ を含むとする。$a\in K^\times$ に対して $K(\sqrt[n]{a})/K$ は次数が $n$ を割る巡回拡大である。逆に次数 $n$ の巡回拡大はこの形である。
:::

:::proof
$b^n=a$ とすれば全根は $\zeta^i b$ であり、分解体は $K(b)$ で分離的である。$\sigma\mapsto\sigma(b)/b$ は $\mu_n=\langle\zeta\rangle$ への単射な群準同型である。逆向きには生成元 $\sigma$ に対し線形作用素 $P=\sum_{j=0}^{n-1}\zeta^{-j}\sigma^j$ を考える。指標の独立性によって $P$ は非零であり、$\sigma P=\zeta P$ である。$b=P(x)\ne0$ を取ると $b^n\in K$ であり、$b$ を固定するのは $\sigma^0$ だけなので $L=K(b)$ である。
:::

:::example[平方根]
標数 $2$ 以外では $-1$ が原始二乗根である。例えば $\Q(\sqrt7)$ は符号反転の生成する二次巡回拡大である。
:::

:::example[原始冪根が必要な場面]
$\Q(2^{1/3})/\Q$ は冪根添加であるが正規でなく、巡回拡大ではない。$\Q(\zeta_3)$ を基礎体にすれば三根が同じ体に入り、巡回三次になる。
:::

### 固有空間を使って巡回拡大を計算する

$\mu_n\subset K$、$\operatorname{char}K\nmid n$、$L/K$ が巡回 $n$ 次とする。生成元 $\sigma$ を $K$ 線形写像と見れば $\sigma^n=I$ であり、$X^n-1$ は $K$ 上で相異なる一次因子に分かれる。従って直和に分かれる。実際、各根 $\lambda$ に対し $(X^n-1)/(X-\lambda)$ を $\lambda$ での値で割った多項式は、他の固有値の成分を消す射影を与える。固有空間がすべて一次元であることは、原始冪根 $\zeta$ に対して $\sigma(b)=\zeta b$ となる非零 $b$ を選び、$1,b,\ldots,b^{n-1}$ が相異なる固有値を持つことから分かる。この基底で掛け算は指数を加えて $b^n$ を係数に移すだけである。

:::example[巡回四次拡大で一つの固有ベクトルを選ぶ]
$K=\Q(i)$、$L=K(b)$、$b=2^{1/4}>0$ とする。$\Q(b)$ は実の四次体で $i$ の添加が二次だから、$[L:K]=4$ である。$\sigma(b)=ib$ に対し $b^2$ は固有値 $-1$ を持つ。従って $K(b^2)$ は二次中間体であり、群では $\langle\sigma^2\rangle$ に固定される。$b+b^3$ は二つの異なる固有空間の成分を持つ。$\sigma^2$ がこれを負にするためこの元は $K(b^2)$ に入らず、四次体を生成する。単独の固有ベクトルでなくても原始元になり得る。
:::

### 固有値と冪基底を確認する

有限体の例では $K=\F_q$ とし、各基底元に対する $q$ 乗 Frobenius を計算する。円分条件は $n\mid q-1$ と同値である。

:::example[巡回生成元の固有空間を商で計算する]
$K=\F_{3}$、$a^{2}=2$ とする。$K^\times$ の生成元は $2$ であり、$n=2$ と置くと $K$ は $n$ 乗根を含む。$L=K(a)$ は有限体であり、$\sigma(x)=x^{3}$ が Galois 群を生成する。

$$
\begin{aligned}
\sigma(a)&=a^{3}=a(a^{2})^{1}=2a,\\
\sigma(a^j)&=2^j a^j
\end{aligned}
$$

$\zeta=2$ の位数は $2$ である。従って $a$ の Frobenius 軌道の長さは $2$ で、拡大次数も $2$ になる。さらに $1,a,\ldots,a^{1}$ の固有値は相異なり、基底の作用は次の通りである。

| 基底元 | 固有値 | 作用の結果 |
| --- | --- | --- |
| $a^0$ | 1 | $1$ |
| $a^1$ | 2 | $- a$ |

$i+j$ が $2$ 以上なら $a^ia^j=2a^{i+j-2}$ になる。固有値も積を取ると $\zeta^{i+j}$ であり、添字を $2$ で読むことは体の乗法と両立する。

この表示では共役の作用を一列ずつ追うだけで済む。任意の元を固有成分に分けるには、最後の節で扱う分解式の射影が使える。
:::

## Kummer 拡大

:::definition[Kummer 拡大]{#def-gal-kummer-extension}
$\operatorname{char}K\nmid n$ かつ $\mu_n\subseteq K$ とする。$K$ の非零元の $n$ 乗根を有限個添加して得る拡大を :term[Kummer 拡大]{en="Kummer extension" yomi="くんまーかくだい"} と呼ぶ。その Galois 群の指数、すなわち群の元の位数の最小公倍数は $n$ を割る。このことは次の節で証明する。
:::

:::proposition[次数と冪類の位数]{#prop-gal-kummer-degree}
$b^n=a\in K^\times$ に対し $[K(b):K]$ は $a$ の類の商群 $K^\times/K^{\times n}$ における位数である。
:::

:::proof
自己同型の像が $\mu_n$ の位数 $d$ の部分群なら、$b^s$ が固定されるのは $d\mid s$ のときに限る。$a^s=c^n$（$c\in K^\times$）なら $(b^s/c)^n=1$ なので $b^s\in K$ である。逆に $b^s\in K$ なら $a^s=(b^s)^n$ である。したがって類の位数は $d$ である。
:::

:::corollary[冪根を含む体での二項式の既約性]{#cor-gal-kummer-binomial}
同じ仮定の下で、$X^n-a$（$a\in K^\times$）が既約であることと、$n$ を割る全ての素数 $\ell$ について $a\notin K^{\times\ell}$ であることは同値である。
:::

:::proof
根の最小多項式が次数 $n$ であることは :ref[prop-gal-kummer-degree] により $[a]$ の位数が $n$ であることと同値である。位数は $n$ を割るので、それが $n$ 未満となるのは $[a]^{n/\ell}=1$ となる素数 $\ell\mid n$ がある場合に限る。この等式から $a^{n/\ell}=c^n$ と書ける。従って $a/c^\ell\in\mu_{n/\ell}$ であり、$\mu_n$ の $\ell$ 乗写像の像は $\mu_{n/\ell}$ なので、$a$ は $K$ の $\ell$ 乗である。逆に $a=c^\ell$ なら $a^{n/\ell}=c^n$ となる。
:::

:::example[次数が冪根の指数より小さい]
$K=\Q(i)$ で $b^4=4$ の根として $b=\sqrt2$ を取る。$4$ は $K$ の四乗ではないが $4^2=2^4$ である。実際、$b$ は $K$ に入らないので類は位数 $2$ であり、拡大も二次である。
:::

:::example[生成元を掛け合わせる]
$\Q(\sqrt2,\sqrt3)$ には $\sqrt6$ も入る。逆に $\sqrt6$ と $\sqrt2$ があれば $\sqrt3$ が得られる。生成元を掛けたり割ったりする操作は、冪類を積や逆元で組み替える操作である。
:::

### 冪類の位数から次数を読む

:::example[四乗根を取っても拡大が二次の場合]
$K=\Q(i)$ とし $a=4$ とする。$a$ は四乗ではない。実際、$z^4=4$ の根は $\pm\sqrt2,\pm i\sqrt2$ であり、$\Q(i)$ の実元は有理数なのでどれも $K$ に入らない。一方 $a^2=16=2^4$ である。従って $K^\times/K^{\times4}$ の $[a]$ の位数は二であり、$K(\sqrt[4]4)=K(\sqrt2)$ の次数も二である。$X^4-4=(X^2-2)(X^2+2)$ が可約であっても、根を添加した体が両因子を分解する。基礎体に $i$ があるからである。
:::

:::example[冪根の条件を外したときの循環性]
$X^3-2$ の実根 $b$ を $\Q$ に加えると三次であるが、$\omega b,\omega^2b$ が入らないので Galois 拡大ではない。$\Q(\omega)$ を基礎にすると同じ $b$ の添加が巡回三次となる。実際、全分解体は六次で $[\Q(\omega):\Q]=2$ であり、基礎体が $\mu_3$ を含む。従って、冪根で生成されることから巡回性を論じる際には根の比を基礎体が含むかを確認する。
:::

:::theorem[一般の体における二項式の既約性]{#thm-gal-binomial-irreducibility}
$n\ge2$、$\operatorname{char}K\nmid n$、$a\in K^\times$ とする。$X^n-a$ が既約であることと、次の二条件が成り立つことは同値である。

- $n$ を割る全ての素数 $\ell$ について $a\notin K^{\times\ell}$ である。
- $4\mid n$ なら $a\notin -4K^{\times4}$ である。
:::

:::proof
$a=b^\ell$ なら $Y^\ell-b^\ell$ に $Y-b$ という因子があり、$Y=X^{n/\ell}$ を代入すれば可約になる。また $4\mid n$ で $a=-4b^4$ なら、$Y=X^{n/4}$ と置くと
$$
Y^4+4b^4=(Y^2-2bY+2b^2)(Y^2+2bY+2b^2)
$$
となる。これで二条件の必要性が従う。

逆向きの証明では、まず素数 $\ell$ について確認する。$X^\ell-a$ が可約なら、次数 $0<d<\ell$ のモニック因子を取り、その根の積を $c\in K^\times$ とする。各根の $\ell$ 乗は $a$ なので $c^\ell=a^d$ である。$\gcd(d,\ell)=1$ により $rd+s\ell=1$ となる整数 $r,s$ があり、$a=(c^r a^s)^\ell$ となる。

一般の $n$ について帰納法を使う。奇素数の約数があればその一つを $\ell$ とし、なければ $\ell=2$ とする。$n=m\ell$ とおくと $m$ も二条件を満たすので、帰納法で $X^m-a$ は既約である。その根 $\alpha$ と $\beta^\ell=\alpha$ を取る。$X^\ell-\alpha$ が $K(\alpha)$ 上で既約なら、塔法則で $[K(\beta):K]=m\ell$ となり、$X^n-a$ は既約である。素数の場合により、失敗するとすれば $\alpha$ が $K(\alpha)$ の $\ell$ 乗である。$\ell$ が奇素数なら、ノルムを取ると $(-1)^{m+1}a$ も $K$ の $\ell$ 乗となる。符号は $\ell$ 乗に吸収できるため、第一条件に反する。

従って残るのは $n=2^k$、$k\ge2$ である。$m=n/2$、$\gamma=\alpha^{m/2}$ とおけば $\gamma^2=a$ で、$K(\gamma)/K$ は二次である。$\alpha$ が $K(\alpha)$ の平方なら、$K(\alpha)$ から $K(\gamma)$ へのノルムで $(-1)^{m/2+1}\gamma$ も平方になる。実際 $\alpha$ は $K(\gamma)$ 上で次数 $m/2$ であり、最小多項式は $X^{m/2}-\gamma$ である。$(u+v\gamma)^2=\pm\gamma$（$u,v\in K$）と書いて係数を比べると $u^2+av^2=0$、$2uv=\pm1$ である。従って $a=-u^2/v^2=-4u^4$ となり、第二条件に反する。
:::

:::example[指数が四の倍数のときの例外]
$X^4+4$ では $-4$ は有理数の平方ではないが、$-4\cdot1^4$ なので $X^2-2X+2$ と $X^2+2X+2$ の積になる。一方 $X^4+16$ の $-16$ は平方でなく、$-16=-4b^4$ なら $b^4=4$ となって有理数の $b$ が存在しない。従って後者は有理数体上既約である。
:::

### 基礎体に原始冪根がない場合の分解体

$\operatorname{char}K\nmid n$ とし、$m\ge1$ 個の $a_i\in K^\times$ について $b_i^n=a_i$ とする。$F=K(\mu_n)$ を先に作ると、$L=F(b_1,\ldots,b_m)$ は各 $X^n-a_i$ の全根を含む。逆に、一つの二項式の根の比から既に全ての $\mu_n$ が得られるので、$L$ はこれらの二項式の $K$ 上の分解体である。制限により
$$
1\longrightarrow\operatorname{Gal}(L/F)\longrightarrow\operatorname{Gal}(L/K)
\longrightarrow\operatorname{Gal}(F/K)\longrightarrow1
$$
が完全である。核は $F$ 上の Kummer 群として計算でき、商は $(\Z/n\Z)^\times$ の部分群である。

$g\in\operatorname{Gal}(L/K)$ に対し、$c_i(g)=g(b_i)/b_i$ と置く。合成すると $c_i(gh)=c_i(g)\,g(c_i(h))$ になる。$K$ が $\mu_n$ を含む場合には指標であったが、一般には商 $\operatorname{Gal}(F/K)$ の作用が式に残る。原始根 $\zeta$ を選び、$g(\zeta)=\zeta^{d(g)}$、$c_i(g)=\zeta^{e_i(g)}$ と書くと、合成は
$$
(e,d)(e',d')=(e+d e',dd')
$$
である。組 $(e,d)$ は $\zeta,b_1,\ldots,b_m$ の像を全て指定するので、群はこの演算を持つ半直積 $(\Z/n\Z)^m\rtimes(\Z/n\Z)^\times$ に埋め込まれる。ただし、上の完全列が分裂するには、商の全体をこの群に持ち上げる群準同型が別に必要である。

:::example[制限の完全列が分裂しない例]
$X^8+1$ の分解体は $L=\Q(\zeta_{16})$ であり、$F=\Q(\zeta_8)$ である。制限は $(\Z/16\Z)^\times\to(\Z/8\Z)^\times$ の還元である。後者で $5$ の類は位数 $2$ だが、その逆像の $5,13$ はどちらも法 $16$ で二乗が $9$ になる。このため位数 $2$ の持ち上げがなく、完全列は分裂しない。
:::

## Kummer 理論と双対性

:::theorem[Kummer 対応]{#thm-gal-kummer-duality}
上と同じ $K,n$ について、$K^\times/K^{\times n}$ の有限部分群 $B$ と、Galois 群が可換で指数が $n$ を割る有限 Galois 拡大 $L/K$ は、共通の代数閉包の中で
$$
B\longmapsto K(\sqrt[n]{a}:[a]\in B),\qquad
L\longmapsto (K^\times\cap L^{\times n})/K^{\times n}
$$
により対応する。ペアリング $(\sigma,[a])\mapsto \sigma(\sqrt[n]{a})/\sqrt[n]{a}$ は、それぞれの群を相手から $\mu_n$ への準同型群と同一視する。
:::

:::proof
$B$ から作る $L$ は分離分解体である。値は根を替えても代表を替えても変わらず、両変数で乗法的である。左側で全値が $1$ なら自己同型は生成元をすべて固定して自明である。右側で全値が $1$ なら根は $K$ に属し、類は自明である。したがって $G$ は $\Hom(B,\mu_n)$ に、$B$ は $\Hom(G,\mu_n)$ に単射である。前者から $G$ は可換で指数が $n$ を割る。有限可換群を巡回群の直積に分けると、位数が $n$ を割る各巡回因子の指標の数はその位数に等しい。よって $|G|=|B|$ となり、両方向の単射は全射である。

$B'=(K^\times\cap L^{\times n})/K^{\times n}$ と置く。全ての $g\in G$ に固定される根は $K$ に属するので、上と同じ対応で $B'$ も $\Hom(G,\mu_n)$ に単射する。よって $B\subseteq B'$ かつ $|B'|\le |G|=|B|$ となり、$B'=B$ である。

逆に $G$ が可換で指数が $n$ を割る有限 Galois 拡大を取る。各 $\chi:G\to\mu_n$ について $\sum_g\chi(g)^{-1}g$ は指標の独立性で非零作用素である。この値として非零の $b_\chi$ を取ると $g(b_\chi)=\chi(g)b_\chi$、したがって $b_\chi^n\in K$ である。有限可換群の巡回因子ごとの指標は全ての非自明元を識別するので、$b_\chi$ をすべて固定する群は自明である。よって全ての $b_\chi$ が $L$ を生成する。
:::

:::example[双二次の場合]
$B=\langle[2],[3]\rangle$ は有理数の素因数の指数で判定すると四元である。したがって生成体の次数は $4$ であり、二つの基本指標は各平方根の符号を読み取る。
:::

:::example[共通する冪類]
$[8]=[2]$ が $\Q^\times/\Q^{\times2}$ で成り立つので $\sqrt2,\sqrt8$ を二つとも添加しても拡大次数は $2$ のままである。
:::

### 一般の冪類を指標に移す

代数閉包の中の $K$ 上分離的な元全体を $K^{\mathrm{sep}}$ と書く。これは分離的な元がなす部分体であり、分離閉包という。この体の中で、ある $a\in K^\times$ の $n$ 乗根 $b$ を取る。$\mu_n\subseteq K$、$\operatorname{char}K\nmid n$ の仮定の下では、各自己同型による比 $\sigma(b)/b$ は指標となる。有限拡大を指定せずに考えると、これにより $K^\times/K^{\times n}$ と、有限 Galois 段を経由する $\mu_n$ 値指標全体が対応する。

:::corollary[冪類と有限段の指標]{#cor-gal-kummer-characters}
各 $a\in K^\times$ に対する指標 $\sigma\mapsto\sigma(\sqrt[n]{a})/\sqrt[n]{a}$ は、その類のみに依存し、全ての有限段の指標はこの形で得られる。
:::

:::proof
根の選択を替えると $b$ が $\mu_n$ の元倍になり、この値を変えない。代表元を $K^{\times n}$ 倍した場合も同様である。有限 Galois 段の自己同型は代数閉包へ延長でき、$K$ 上の分離性を保つので $K^{\mathrm{sep}}$ の自己同型に制限できる。よって指標が自明なら $b$ の分離分解体の Galois 群が $b$ を固定し、$b\in K$ となる。根を掛けると指標も掛け合わされるため、異なる類は異なる指標になる。逆に有限 Galois 段 $L/K$ の指標 $\chi$ に対し、$\sum_g\chi(g)^{-1}g$ の非零な値を一つ取ると $\chi$ に従う固有ベクトルとなる。その $n$ 乗が $K$ に入るので所望の類を与える。
:::

:::example[有限体の冪類]
$K=\F_7$、$n=3$ とする。$3$ は位数 $6$ を持つ。三乗写像の像は $\{1,-1\}$ なので $[3]$ は冪類商の生成元である。よって $X^3-3$ は既約で、分解体は $\F_{343}$ である。その根 $b$ に Frobenius を作用させると $b^7=b(b^3)^2=2b$ となる。$2$ は $\F_7$ の原始三乗根であり、この倍数が指標の値である。
:::

### 対応する部分群を消滅条件で指定する

有限の Kummer 拡大 $L/K$ に対応する冪類群を $B$ とし、対を $\langle g,[a]\rangle=g(\sqrt[n]a)/\sqrt[n]a$ とする。$C\le B$ に対し $K$ と $C$ の各代表の冪根が生成する体は、$C$ を消す $g$ 全体の固定体である。これはその体を固定することが根の一つずつを固定することと同値だからである。反対に $H\le G$ に対し、$H$ を消す指標は $G/H$ の指標に等しい。$G/H$ は指数が $n$ を割る有限可換群なので、その指標は各非自明元を識別する。従ってこれらの指標に対応する冪根を全て固定する群は $H$ となり、それらの冪根は $L^H$ を生成する。

さらに $B$ の各類に対して代表 $a$ と根 $b_a$ を一つずつ選ぶと、これらの $b_a$ は $L$ の $K$ 基底になる。異なる類に対する指標が異なるからである。実際、ある指標 $\chi$ に対し $\sum_g\chi(g)^{-1}g$ を一次関係に作用させると、$\chi$ を持つ項だけが $|G|$ 倍されて残る。他の項は非自明な指標 $\psi$ の和が零になるため消える。これは $\psi(h)\ne1$ なる $h$ で和を掛けても、添字が置換されて値が変わらないためである。$|G|$ の素因子はすべて $n$ を割るので、$|G|$ は $K$ で零にならない。これで独立性が従い、個数は $|B|=[L:K]$ に等しい。

:::example[三つの二次部分体を指標で求める]
$K=\Q$、$L=K(\sqrt2,\sqrt5)$ とする。$[2],[5]$ は素数の指数の偶奇を比べれば独立であり、$B=\{1,[2],[5],[10]\}$ である。$s$ は $\sqrt2$ のみ、$t$ は $\sqrt5$ のみを反転させるとする。$s$ が消す類は $1,[5]$、$t$ が消す類は $1,[2]$、$st$ が消す類は $1,[10]$ である。従って固定体はそれぞれ $K(\sqrt5),K(\sqrt2),K(\sqrt{10})$ となる。積に対応する冪類を忘れなければ、部分体が三つすべて得られる。
:::

## Artin–Schreier 拡大

:::theorem[標数 $p$ の巡回 $p$ 次拡大]{#thm-gal-artin-schreier}
標数 $p$ の体 $K$ で $\wp(x)=x^p-x$ とする。$X^p-X-a$ は $a\in\wp(K)$ なら完全分解し、そうでなければ既約で、その分解体は巡回 $p$ 次である。また全ての巡回 $p$ 次拡大はこの形である。
:::

:::proof
$b$ を一根とすると根は $b+c$（$c\in\F_p$）であり、導関数は $-1$ である。したがって分解体は $K(b)$ で Galois 群は $\sigma\mapsto\sigma(b)-b$ により $\F_p$ の加法群に埋め込まれる。群の位数は $1$ または $p$ である。前者は根が $K$ にある場合であり、後者では最小多項式の次数が $p$ なので既約である。

逆方向では群の生成元を $\sigma$ とする。$\Tr(1)=p=0$ だから、:ref[thm-gal-hilbert-90]{text="加法的 Hilbert の定理 90"}で $\sigma(b)-b=1$ を満たす $b$ を取れる。すると $\sigma(b^p-b)=(b+1)^p-(b+1)=b^p-b$ なので $a=b^p-b\in K$ である。$\sigma$ が $b$ を動かすので $K(b)$ は真の拡大であり、素数次性から全体を生成する。
:::

同じ非自明な拡大を与える $a$ の類は $K/\wp(K)$ の同じ一次元 $\F_p$ 部分空間を張る。実際、$b,b'$ が同じ拡大を生成すると $\sigma(b)-b,\sigma(b')-b'$ はともに $\F_p^\times$ に入り、その比を $c$ とすると $b'-cb\in K$ となる。逆も $b'=cb+d$（$c\in\F_p^\times,d\in K$）と置けば従う。

:::example[有限体上の方程式]
$\F_3$ では $b^3-b=0$ が全元で成り立つので $X^3-X-1$ は既約である。根を $u$ とすると Frobenius は $u\mapsto u+1$ で、三回で元に戻る。
:::

:::example[極の位数を利用する]
$\F_p(t)$ では $t$ は $\wp$ の像に入らない。$x$ が無限遠で位数 $r>0$ の極を持つと、$x^p-x$ の極の位数は $pr$ になる。$x$ が極を持たなければ差も極を持たない。$t$ の極の位数は $1$ なのでどちらでも一致しない。
:::

### 加法的な双対性

:::proposition[基本可換 $p$ 拡大の分類]{#prop-gal-artin-schreier-duality}
標数 $p$ の体 $K$ について、$K/\wp(K)$ の有限次元 $\F_p$ 部分空間を $B$ とする。各類 $[a]\in B$ から代表元 $a$ を選び、$b_a^p-b_a=a$ を満たす根を $K$ に加えて $L$ を作る。このとき $\operatorname{Gal}(L/K)$ と $B$ は、$(g,[a])\mapsto g(b_a)-b_a$ により互いの $\F_p$ 線形双対と同一視される。特に $[L:K]=p^{\dim_{\F_p}B}$ である。逆に群が基本可換 $p$ 群である有限 Galois 拡大はこの形になる。
:::

:::proof
$L$ は有限個の分離多項式の分解体なので有限 Galois である。$a$ の代表を $\wp(d)$ だけ変えると根を $d$ だけ変えればよい。根の選択の差は $\F_p$ に入る。従って差は代表と根に依存しない。$\wp$ は $\F_p$ 線形なので、根の一次結合を使えば $B$ に関する線形性が分かる。$g(b_a)-b_a$ は $\F_p$ に入って $g$ によって固定されるため、群変数についても加法的である。一方の核は全生成元を固定する写像なので自明であり、もう一方の核では根が全群に固定されて $K$ に属す。前者から Galois 群は $B$ の $\F_p$ 線形双対の部分群であり、特に $\F_p$ ベクトル空間である。後者から $B$ もその双対に埋め込まれ、次元が一致する。

逆に $L/K$ が基本可換 $p$ 群 $G$ を持つとする。任意の $\F_p$ 線形指標 $\chi:G\to\F_p$ は加法的な合成規則を満たす。:ref[thm-gal-hilbert-cocycle] により、ある $b\in L$ で $g(b)-b=\chi(g)$ となる。すると $\wp(b)$ は固定され $K$ に入る。指標全体が群の各非自明元を区別するため、こうして得る $b$ の生成体の固定群は自明である。従って生成体は $L$ である。また $[a]$ の根が $L$ に入るもの全体を取っても $G$ の双対に単射するので、もとの $B$ より大きくはならない。こうして $L$ から $B$ を一意に復元できる。
:::

:::example[異なる極を持つ二つの式]
$K=\F_p(t)$ における $t$ と $1/t$ の類は独立である。実際、$ct+d/t$（$c,d\in\F_p$）で $c\ne0$ なら無限遠で単純極を持つ。$c=0,d\ne0$ なら $t=0$ で単純極を持つ。いずれも $\wp$ の像の極の位数が $p$ の倍数であることに反する。従って二式の分解体の合成は次数 $p^2$ となる。
:::

### Artin–Schreier 類の標準化

$K=\F_p(t)$ の多項式に含まれる $t^{pm}$ の項は、$\wp(t^m)=t^{pm}-t^m$ を引けば一段低い冪に移る。係数が $\F_p$ にあるので、同じ操作を各項に適用できる。こうして指数が $p$ で割れない項だけを残せる。この形の非定数多項式は $\wp(K)$ に入らない。無限遠での極の位数は最高次数で、これは $p$ の倍数でないためである。定数のうち零以外も $\wp(K)$ に入らない。もし $\wp(r)$ が定数なら $r$ には有限の極も無限遠での極もなく $r\in\F_p$ であり、その像は零である。

:::example[異なる右辺が同じ拡大を与える]
$K=\F_3(t)$ で $a=t^9+2t^6+t+1$ とする。$\wp(t^3)=t^9-t^3$ と $\wp(2t^2)=2t^6-2t^2$ を引くと $t^3+2t^2+t+1$ を得る。さらに $\wp(t)=t^3-t$ を引けば $2t^2+2t+1$ である。この多項式は次数二なので $\wp(K)$ に入らず、拡大は三次になる。もとの式の根から $t^3+2t^2+t$ を引けば新しい式の根になるため、二つの拡大は同じである。
:::

## Lagrange の分解式

:::definition[Lagrange の分解式]{#def-gal-lagrange-resolvent}
巡回 $n$ 次拡大 $L/K$ で $\operatorname{char}K\nmid n$ とする。$K$ に原始 $n$ 乗根 $\zeta$ があり、$\sigma$ は群の生成元とする。$\alpha\in L$ に対し $\alpha_j=\sigma^j(\alpha)$ と置く。
$$
R_k=\sum_{j=0}^{n-1}\zeta^{-kj}\alpha_j
$$
を :term[Lagrange の分解式]{en="Lagrange resolvent" yomi="らぐらんじゅのぶんかいしき"} と呼ぶ。
:::

:::proposition[分解式の変換と反転]{#prop-gal-resolvent-transform}
$\sigma R_k=\zeta^kR_k$、$R_k^n\in K$ であり、$\alpha_j=n^{-1}\sum_{k=0}^{n-1}\zeta^{kj}R_k$ である。
:::

:::proof
最初の等式は添字を一つずらして得る。両辺を $n$ 乗すれば固定される。反転式の右辺を展開すると $\alpha_i$ の係数は $n^{-1}\sum_k\zeta^{k(j-i)}$ であり、幾何級数により $i=j$ なら $1$、それ以外は $0$ になる。
:::

:::example[二次での反転]
$\alpha=2+\sqrt3$ なら $R_0=4$、$R_1=2\sqrt3$ である。$R_1^2=12$ から $\alpha=(R_0+R_1)/2$ を再構成できる。
:::

:::example[三次で一成分だけ残る場合]
$\alpha^3=2$、$\sigma\alpha=\zeta_3\alpha$ の巡回拡大を $\Q(\zeta_3)$ 上で考える。$R_1=3\alpha$、$R_0=R_2=0$ である。$\alpha$ がすでに一つの固有空間に入るためである。
:::

### 分解式を射影として扱う

$P_k=\frac1n\sum_{j=0}^{n-1}\zeta^{-kj}\sigma^j$ と置く。$P_k(\alpha)=R_k/n$ である。固有値 $\zeta^m$ の元に作用させると前節の等比和により $k=m$ では元をそのまま返し、$k\ne m$ では零を返す。従って $P_kP_m=0$（$k\ne m$）、$P_k^2=P_k$、$\sum_k P_k=I$ である。固有成分の積を取ると固有値が掛け合わさるので、$P_k(L)P_m(L)\subseteq P_{k+m}(L)$ となる。ただし添字は $n$ を法として読む。

:::example[三つの固有成分をすべて追う]
$K=\Q(\omega)$、$b^3=2$、$\sigma b=\omega b$ とし、$\alpha=1+2b+b^2$ とする。$1,b,b^2$ の固有値は $1,\omega,\omega^2$ なので $R_0=3,R_1=6b,R_2=3b^2$ である。$R_1^3=432$、$R_2^3=108$、$R_1R_2=36$ となる。三乗の等式から根を選ぶだけでは、二つの根の組が元の共役を再構成するとは限らない。ここでは $R_1R_2=36$ を保つように選ぶと、$\omega$ の因子を互いに逆向きに掛けることになり、三つの共役が得られる。
:::

### 分解式で固有成分を抽出する

円分根が基礎体にある場合に、共役から冪根の値を読み取る。

:::example[Lagrange の分解式から共役を再構成する]
$K=\F_{3}$、$b^{2}=2$、$\zeta=2$ とする。$L=K(b)$ の Frobenius $\sigma$ は $b\mapsto\zeta b$ である。$a=2 b + 1$ を取り、まず各共役を $b$ の冪基底で書く。

| 添字 $j$ | $\sigma^j(a)$ |
| --- | --- |
| 0 | $1 - b$ |
| 1 | $b + 1$ |

$R_k=\sum_j\zeta^{-kj}\sigma^j(a)$ で、$b^m$ の係数に掛かる和は $\sum_j\zeta^{(m-k)j}$ である。$m=k$ のとき $2$、それ以外は $0$ になる。従って次の表で $R_k$ とその $n$ 乗が得られる。

| $k$ | $R_k$ | $R_k^n$ の剰余 |
| --- | --- | --- |
| 0 | $-1$ | 1 |
| 1 | $b$ | 2 |

$$
\begin{aligned}
a&=\frac{R_0+\cdots+R_{1}}{2}=2 b + 1,\\
\sigma(a)&=\frac{\sum_k\zeta^k R_k}{2}=b + 1
\end{aligned}
$$

分解式の和を $n$ で割ると元に戻り、重み $\zeta^k$ を変えると共役に戻る。$R_k^n$ だけを知って各根を選ぶときには、たとえば $R_kR_l$ の値が別途分かっていれば、その積も一致するように選ぶ。固有値だけでは各成分に掛ける冪根の選択は制約されない。
:::

\end{aligned}
$$

分解式の和を $n$ で割ると元に戻り、重み $\zeta^k$ を変えると共役に戻る。$R_k^n$ だけを知って各根を選ぶときには、たとえば $R_kR_l$ の値が別途分かっていれば、その積も一致するように選ぶ。固有値だけでは各成分に掛ける冪根の選択は制約されない。
:::

## 演習問題

::::exercise{level=basic}
$\Q(i,\sqrt2)/\Q(i)$ の群の位数を求めよ。

:::solution
$\Q(i)$ の実元は有理数なので $\sqrt2$ は含まれない。二次添加だから群の位数は $2$ である。
:::
::::

::::exercise{level=basic}
$\Q^\times/\Q^{\times2}$ で $12$ と同じ類を表す平方自由整数を求めよ。

:::solution
$12=4\cdot3$ なので $[12]=[3]$ である。
:::
::::

::::exercise{level=basic}
$\F_2$ で $X^2-X-1$ が既約か調べよ。

:::solution
$\wp(0)=\wp(1)=0$ なので $1$ は像に入らない。したがって既約である。
:::
::::

::::exercise{level=basic}
$\alpha=3+\sqrt2$ の二次の分解式を求めよ。

:::solution
和が $R_0=6$、差が $R_1=2\sqrt2$ である。
:::
::::

::::exercise{level=advanced}
$\Q(\sqrt2,\sqrt8,\sqrt{18})$ の次数を求めよ。

:::solution
$\sqrt8=2\sqrt2$、$\sqrt{18}=3\sqrt2$ なので体は $\Q(\sqrt2)$ に等しく次数は $2$ である。
:::
::::

::::exercise{level=advanced}
$\F_5(t)$ で $X^5-X-(t^5+t)$ が既約であることを示せ。

:::solution
$\wp(t)=t^5-t$ を引くと $2t$ になる。無限遠の極の位数 $1$ は $\wp$ の像に不可能なので、元の右辺も像に入らない。
:::
::::

::::exercise{level=advanced}
$\Q^\times/\Q^{\times2}$ で $[2],[3],[5]$ が生成する部分群の大きさを求めよ。

:::solution
$2^a3^b5^c$（$a,b,c\in\{0,1\}$）が平方なら各素数の指数は偶数である。したがって八通りが別の類で、群は位数 $8$ である。
:::
::::

::::exercise{level=advanced}
$s,t$ を独立な不定元とし、$K=\Q(i)(s,t)$ とする。$L=K(\sqrt[4]{s},\sqrt t)$ の Galois 群と $K$ 基底を求めよ。

:::solution
$\sqrt t$ は $t^2$ の四乗根として扱える。$s^j t^{2k}$ が $K$ の四乗なら、既約元 $s,t$ の分子と分母における指数の差はそれぞれ $4$ の倍数である。従って $4\mid j$、$2\mid k$ となる。逆にこの条件なら四乗である。よって $[s],[t^2]$ が生成する四乗類の部分群は $C_4\times C_2$ であり、Kummer 対応により Galois 群も $C_4\times C_2$ である。各四乗類の根を一つずつ選んだ基底は $(\sqrt[4]{s})^j(\sqrt t)^k$（$0\le j<4$、$0\le k<2$）である。
:::
::::
