## この章の目標

- 任意の空間に対して特異鎖複体を作る。
- プリズム演算子と接続準同型を構成して計算する。
- 重心細分を使って切除と Mayer–Vietoris 完全列を導く。
- 単体的な計算が特異ホモロジーを与える理由を示す。

## 特異鎖複体と特異ホモロジー

三角形を正確に貼り合わせなくても、標準三角形から空間への連続写像を取れる。同じ方法を各次元に用いて、三角形分割を持たない空間にも鎖を定義する。

:::definition[特異単体と特異鎖]{#def-at-singular-chain}
連続写像 $\sigma:\Delta^n\to X$ を :term[特異単体]{en="singular simplex" yomi="とくいたんたい"} と呼ぶ。$C_n(X)$ は全特異 $n$ 単体を基底とする自由 Abel 群であり、各鎖は有限和である。頂点 $i$ を飛ばす面の包含を $\delta_i$ とすると
$$
\partial\sigma=\sum_{i=0}^n(-1)^i\sigma\delta_i
$$
と置く。通常の複体では $\partial_0=0$ とする。この鎖複体のホモロジーを :term[特異ホモロジー]{en="singular homology" yomi="とくいほもろじー"} と呼ぶ。
:::

二つの面を削る順序の交換で符号が反転するため、:ref[lem-at-boundary-square] と同じ理由で $\partial^2=0$ である。写像 $f:X\to Y$ は基底を $f\sigma$ に送る鎖写像 $f_\#$ を定める。制限と合成は可換なので、$f_\#$ は輪体と境界を保つ。合成と恒等は基底上で保たれ、ホモロジー上でも保たれる。

:::example[一点上の複体]
一点では各次元に一つだけ特異単体がある。$\partial_n$ は $n>0$ が偶数なら $1$、奇数なら $0$ を掛ける。そのため $H_0=\Z$ であり、正次数のホモロジーは消える。定値の特異単体を鎖の定義で最初から零にしてはいない点に注意する。
:::

:::example[点の特異鎖は各次数に残る]
一点空間の $C_n$ は定値単体 $\sigma_n$ で生成される自由群である。$\partial\sigma_n=\sum_{i=0}^n(-1)^i\sigma_{n-1}$ なので、正の偶数次数からの境界は恒等、奇数次数からは零である。例えば $C_3\to C_2\to C_1$ は $\Z\xrightarrow{0}\Z\xrightarrow{1}\Z$ となる。従って $H_2=0$ であり、$H_1$ も $\partial_2$ の全射性で消える。特異単体には退化したものも含まれるので、点でも鎖群とホモロジー群の大きさは異なる。
:::

### 退化単体が境界式に入る理由

:::example[定値辺と定値三角形]
定値な特異辺 $e$ の両端は同じ点なので $\partial e=0$ である。一方、その点への定値な二単体 $t$ の三辺はすべて $e$ だから $\partial t=e-e+e=e$ となる。従って $e$ は零鎖ではないが $H_1$ では零になる。例えば円周上のループに定値辺を一つ足すと別の特異鎖になるものの、その差は定値二単体の境界なので同じ一次類を表す。定値辺を鎖の段階で零とみなすと、この境界の式がどこで使われたかを見失いやすい。
:::

### 退化単体を取り除く正規化

単体の像が低次元に入っているだけでは、鎖複体からその単体を除けるとは限らない。例えば円周を回る特異二単体でも、辺の座標をどのように使っているかにより境界が違う。ここでは二つの連続する頂点を重ねる座標写像を通る場合だけを、代数的な退化として扱う。

標準単体の隣り合う二座標を足す写像 $\Delta^{n+1}\to\Delta^n$ と特異単体を合成する操作を $s_j$ とする。足すのは第 $j,j+1$ 座標である。また第 $i$ 面の制限を $d_i$ とする。座標で確かめると、$d_is_j$ は $i<j$ で $s_{j-1}d_i$、$i=j,j+1$ で恒等、$i>j+1$ で $s_jd_{i-1}$ になる。二回座標を足す順序については $s_i s_j=s_{j+1}s_i$（$i\le j$）である。これらは、どちらの順序でも同じ頂点の座標を同じ組にまとめることから従う。

:::proposition[正規化された特異鎖]
$D_*(X)$ を $s_j$ の像の全てが張る部分群とする。これは特異鎖の部分複体であり、ホモロジーは全て零である。従って商 $C_*(X)/D_*(X)$ は特異ホモロジーを計算する。
:::

:::proof
境界 $\partial s_j$ の和で $i=j,j+1$ は逆符号の恒等なので相殺する。残りは別の $s_i$ の像だから $D_*$ は部分複体である。より細かく、$D^p_*$ を $s_0,\ldots,s_p$ の像で張った部分複体とする。$D^{-1}=0$ とする。$D^p/D^{p-1}$ の元は $s_p y$ で代表できる。この商上で $h=(-1)^p s_p$ と置くと、$s_p s_i=s_i s_{p-1}$（$i<p$）により低い段を保つので写像が定まる。商が零の次数では零写像にする。

$x=s_p y$ とする。$\partial s_p x+s_p\partial x$ で $i>p+1$ の境界項は、添字を一つ戻すと $s_p\partial$ の $i>p$ の項と逆符号で消える。$\partial s_p x$ の $i<p$ の項は $D^{p-1}$ に入り、$i=p,p+1$ は相殺する。残るのは $\sum_{i\le p}(-1)^i s_p d_i x$ である。このうち $i<p$ は $d_i s_p=s_{p-1}d_i$ により再び低い段に入る。$i=p$ では $s_p d_p x=x$ なので、商で残るものは $(-1)^p x$ である。従って $\partial h+h\partial=\id$ となり、商は可縮な鎖複体である。

$D^{p-1}\to D^p\to D^p/D^{p-1}$ の完全列で帰納すると各段のホモロジーは零になる。任意の輪体は有限和なので一つの段に属し、そこで境界になる。従って $D_*$ のホモロジーも零である。商の完全列から正規化の準同型がホモロジー同型を誘導する。商の群は退化していない特異単体を基底とし、退化した面は境界を取った後に零とみなせる。
:::

:::example[定値単体が商で消える]
一点空間では正次数の定値単体は、一つ下の定値単体にどの $s_j$ を適用しても得られる。従って商鎖複体には零次の $\Z$ だけが残る。これに対し非退化な特異辺が両端で同じ点を取る場合、定値辺とは限らない。例えば円周を一周する辺は $s_0$ の像ではない。商鎖でもこの辺は残り、その境界は両端が一致するので零である。この区別により、同じ頂点名が二度出ても必要な一次輪体を消さずに済む。
:::

:::example[軌跡の幾何学的な像だけでは境界が決まらない]
単体 $\Delta^1$ を区間と同一視し、$e(t)=t$、$e'(t)=1-t$ を $I$ の特異辺とする。両者の像集合は同じだが、境界はそれぞれ $[1]-[0]$ と $[0]-[1]$ である。また $e$ と $-e'$ は鎖群の等しい元ではない。$e$ と $e'$ は別々の基底元だからである。一方 $e+e'$ は輪体となり、区間が可縮なのでホモロジーでは零になる。これを鎖で表すには、三角形の頂点を時刻 $0,1,0$ へ送り、内部をアフィンに区間へ写す。その境界は $e'+e-c_0$ である。ここで $c_0$ は $0$ への定値辺であり、定値二単体の境界である。従って二枚の特異二単体の和が $e+e'$ の境界を与える。向きの反転を最初から鎖の負と同一視するか、境界で後から比較するかは、単体鎖と特異鎖で扱いが違う。
:::

:::definition[係数を指定した特異鎖]
Abel 群 $G$ に対し、$C_n(X;G)=C_n(X)\otimes_\Z G$ とする。有限個の特異単体に $G$ の係数を付けた鎖を用い、境界は同じ符号で面を足す。対の短完全列は各次数で基底の分割から分裂するので、係数を替えても完全である。以下のプリズムと重心細分は整数の鎖写像や鎖ホモトピーの等式で与えられるため、係数を $G$ に替えても等式を保つ。従って切除と Mayer–Vietoris 完全列の証明も同じように適用できる。
:::

## 被約ホモロジーと 0 次ホモロジー

:::definition[増大と被約ホモロジー]{#def-at-reduced-homology}
$\eps:C_0(X)\to\Z$ を係数和とする。$\eps\partial_1=0$ なので $C_{-1}=\Z$、$\partial_0=\eps$ として鎖複体を延ばせる。そのホモロジーを :term[被約ホモロジー]{en="reduced homology" yomi="ひやくほもろじー"} $\widetilde H_n(X)$ と呼ぶ。$X\ne\varnothing$ なら $\widetilde H_{-1}=0$ である。
:::

:::proposition[道成分と零次ホモロジー]{#prop-at-hzero}
$H_0(X)$ は道成分を基底とする自由 Abel 群である。$X$ が $r\ge1$ 個の道成分を持つなら $\widetilde H_0(X)\cong\Z^{r-1}$ である。
:::

:::proof
各点をその道成分へ送る写像は、道の境界である二点の差を零にする。逆に各成分から代表点を選び、任意の点とその代表の差を道の境界で表すと、係数和が成分ごとに零の鎖は境界になる。被約群は全成分での係数和が零となる部分であり、一成分を固定して残りの成分との差を取ると基底が得られる。
:::

:::example[連結と道連結]
$H_0$ で数えるのは道成分である。例えば離散三点では $H_0=\Z^3$、被約群は $\Z^2$ であり、基底に $[b]-[a]$ と $[c]-[a]$ を取れる。区間ではどの二点の差も境界になるため、被約零次群は零である。
:::

:::example[道成分が無限個ある場合]
$X=\{0\}\cup\{1/n:n\ge1\}$ では、任意の異なる二点の間に $X$ に含まれない実数がある。その値で $X$ を二つの開閉部分に分けられるので、各道成分は一点である。よって $H_0(X)$ は各点に一つ生成元を持つ直和であり、$\widetilde H_0(X)$ の基底は $[1/n]-[0]$ である。$1/n$ が $0$ に収束しても特異鎖は有限和であり、無限に多くの係数を同時に持つ直積にはならない。
:::

:::example[二つの道成分の境界を直接解く]
$X=[-2,-1]\cup[1,2]$ とし、$c=3[-2]-[-1]-2[1]$ を零鎖とする。全係数の和は零なので被約零次の輪体である。左側の係数和は $2$、右側は $-2$ であり、一本の特異辺はどちらかの区間内に収まるため、この成分ごとの係数和は境界で変わらない。実際、左の二点の差を境界として取り除くと $c$ は $2([-2]-[1])$ と同じ類である。よってこれは被約零次群 $\Z$ の生成元の二倍であり、零にならない。
:::

:::example[被約零次群の写像には基底の移動が現れる]
$X$ の三つの道成分を $A,B,C$、$Y$ の二成分を $P,Q$ とする。写像 $f:X\to Y$ が $A,C$ を $P$ へ、$B$ を $Q$ へ送るとする。$X$ の被約零次基底を $[B]-[A]$、$[C]-[A]$ とすれば、第一は $[Q]-[P]$ に、第二は零に移る。例えば係数組 $(3,-2)$ の像は $3([Q]-[P])$ である。基準成分を $C$ に替えた場合は座標が変わるが、各成分の差を元の写像で送る規則は変わらない。これにより任意の有限個の道成分の例で誘導写像を行列として読める。
:::

:::example[連結でも道成分で区別される零次群]
平面内の $\{(x,\sin(1/x)):0<x\le1\}$ の閉包を $X$ とする。グラフは区間からの連続像なので連結であり、閉包も連結である。一方、グラフの部分と付け加わる縦線分 $\{0\}\times[-1,1]$ を結ぶ道はない。実際、道が縦線分から始まって正の第一座標に到達するとき、正の第一座標を持つ時間帯の一つの連結成分の左端を考える。その端では第一座標が零へ近づくため、途中の値は任意に小さい正数を取る。従ってその端に近い時刻で $\sin(1/x)$ が $1$ と $-1$ をそれぞれ取る列を選べ、第二座標の連続性に反する。各部分自体は道連結なので道成分は二つであり、$H_0(X)=\Z^2$ である。例えば両部分から一点ずつ取った差は被約零次の生成元になる。この群を計算するためには連結性と道連結性を区別する必要がある。
:::

## ホモトピー不変性

:::definition[鎖ホモトピー]{#def-at-chain-homotopy}
鎖写像 $F,G:C_*\to D_*$ の間の :term[鎖ホモトピー]{en="chain homotopy" yomi="さほもとぴー"} は $P_n:C_n\to D_{n+1}$ で $G-F=\partial P+P\partial$ を満たす族である。輪体に当てると差は境界なので、この二写像はホモロジー上で一致する。
:::

:::theorem[プリズムとホモトピー不変性]{#thm-at-prism}
連続写像 $f,g:X\to Y$ がホモトピックなら $f_*=g_*$ である。
:::

:::proof
$\Delta^n\times I$ の下の頂点を $v_i$、上を $w_i$ とし、アフィン単体 $[v_0,\dots,v_i,w_i,\dots,w_n]$ を $Q_i$ とする。$H:f\simeq g$ に対して
$$
P(\sigma)=\sum_{i=0}^n(-1)^i H(\sigma\times\id_I)Q_i
$$
と置く。$\partial P(\sigma)$ で隣り合う $Q_i,Q_{i+1}$ の共通面は、$Q_i$ から $w_i$、$Q_{i+1}$ から $v_{i+1}$ を除くことで現れ、削る位置はともに $i+1$ なので相殺する。$Q_0$ から $v_0$ を除いた上面の符号は $+1$、$Q_n$ から $w_n$ を除いた下面は $-1$ である。側面のうち $v_j$ を除く項で $j<i$ なら符号は $(-1)^{i+j}$ であり、元の第 $j$ 面のプリズムの二重頂点は $i-1$ へ繰り上がる。$w_j$ を除く項で $j>i$ なら削る位置は $j+1$ であり、符号は $(-1)^{i+j+1}$ である。いずれも $P\partial$ の反対符号になる。よって $\partial P+P\partial=g_\#-f_\#$ である。
:::

:::example[区間と円筒]
一点への縮約から、空でない可縮空間の被約ホモロジーは全て零である。同様に円筒 $X\times I$ の包含と射影は互いに逆をホモロジーに誘導し、上下の包含は同じ写像を誘導する。
:::

:::example[一本の辺のプリズム]
$\sigma:\Delta^1\to X$ の両端を $v_0,v_1$、それらの上下の点を $v_i^0,v_i^1$ と書く。プリズムは $[v_0^0,v_0^1,v_1^1]-[v_0^0,v_1^0,v_1^1]$ となる。境界を取ると共有対角辺 $[v_0^0,v_1^1]$ は消え、上辺から下辺を引いたものに左の側辺を足し、右の側辺を引いた式が残る。$P\partial \sigma$ は右から左を引いた側辺であり、和を取れば $g_\#\sigma-f_\#\sigma$ になる。一次元ではこの符号を図に頼らず六つの項で確認できる。
:::

:::example[区間の縮約で明示的な境界を作る]
凸集合 $X\subset\R^m$ の点 $b$ を固定し、各 $\sigma:\Delta^n\to X$ を $b$ を最初の頂点とする特異錐に延長する。重心座標を $\lambda_0,\ldots,\lambda_{n+1}$ とすると、錐の値は
$$
\lambda_0 b+(1-\lambda_0)\sigma\left(\frac{\lambda_1}{1-\lambda_0},\ldots,\frac{\lambda_{n+1}}{1-\lambda_0}\right)
$$
であり、$\lambda_0=1$ では $b$ と置く。$\sigma$ の像がコンパクトなので、重み $1-\lambda_0$ が零に近づけば連続である。境界で最初の頂点を除くと $\sigma$、それ以外では対応する面への錐が反対符号で現れ、正次数では $\partial(b*c)=c-b*\partial c$ を得る。零次では $\partial(b*c)=c-\eps(c)[b]$ であり、増大複体で $b*1=[b]$ と取れば同じ式になる。例えば $[-1,1]$ で正方向に進む辺と逆方向に進む辺を足した輪体を取ると、二辺を $b=0$ と結んだ二つの特異二単体の和がその輪体を境界として持つ。
:::

:::example[相対ホモトピーで境界が固定されるとき]
対 $(X,A)$ から $(Y,B)$ への二写像を、全時刻で $A$ が $B$ に入るホモトピーで結ぶ。$A$ 内の特異単体にプリズムを適用すると、ホモトピーの全時刻を通じて $B$ 内に収まる。従ってプリズム写像は相対鎖の商に降り、相対ホモロジーでも二写像は同じ作用をする。例えば $(I,\{0,1\})$ の自己写像で両端を固定するものは、恒等写像と点ごとの線形補間で結べるので、相対一次群に恒等を誘導する。一方、両端を交換する写像との間にはこのようなホモトピーは存在しない。相対一次群で $-1$ の作用が現れるためである。
:::

:::example[円筒の両側の輪体をプリズムで比較する]
円筒 $X=S^1\times I$ の上下の円周を $i_0,i_1:S^1\to X$ とする。標準の特異辺を円周を一周する $\sigma$ とすれば、$H(z,t)=(z,t)$ のプリズムから $i_{1\#}\sigma-i_{0\#}\sigma=\partial P\sigma$ が従う。両側の端点に関するプリズムは同じ点に出るため相殺する。従って両円周は一次ホモロジーで同じ類である。この輪体を第二の円周上で向きを逆にして読み替えると符号も逆になる。高さが違うことと周回方向が違うことは別々に扱える。例えば上下を繋ぐ円柱を有向面として考えると、境界は上の周回から下の同向きの周回を引いたものになる。この幾何学的な境界がプリズムの符号式にそのまま現れている。
:::

### 積の三角形分割と境界

:::proposition[特異鎖の外積]{#prop-at-singular-cross-product}
特異単体 $\sigma:\Delta^p\to X$、$\tau:\Delta^q\to Y$ の積を、$\Delta^p\times\Delta^q$ の向き付き三角形分割を $\sigma\times\tau$ で送った鎖 $\sigma\times\tau\in C_{p+q}(X\times Y)$ として定める。これを双線形に延長すると
$$
\partial(c\times d)=\partial c\times d+(-1)^p c\times\partial d,\qquad c\in C_p(X)
$$
が成り立つ。連続写像の積は、この外積と可換である。
:::

:::proof
積単体の頂点を $(i,j)$ と書く。$(0,0)$ から $(p,q)$ まで、各歩で添字の一方を $1$ 増やす格子道を取る。その通過頂点を順に並べたものが一枚の $(p+q)$ 単体になる。これらが積を分割することは、二つの重心座標の累積和を一つの昇順の列に並べると分かる。具体的には、累積和の点で $[0,1]$ を分ける。各小区間が定める二つの添字 $(i,j)$ に、その長さを係数として割り当てると、積内の元の点を復元する。同時刻の累積和があれば対応する係数が零となり、順序の違いは共有面上に限られる。

各小単体には第一因子を先にした積の向きを与える。内部の面は二つの単体から同じ頂点順で現れ、向きの符号が反対なので相殺する。外側では各面上の分割が、残った頂点の順序による同じ分割に一致する。第一因子を境界にした面は $\partial c\times d$ の符号を持つ。第二因子を境界にした面では、外向き方向を先頭に置くとき第一因子の $p$ 本の向きベクトルをまたぐので $(-1)^p$ が付く。写像の積との可換性は、各小単体を先に貼り合わせても後に貼り合わせても同じ合成写像になることから従う。

対 $(X,A)$ と $(Y,B)$ の相対鎖では、$A$ に入る単体と $Y$ の単体の積、または $X$ の単体と $B$ に入る単体の積が $A\times Y\cup X\times B$ に入る。そのため外積は相対鎖にも降りる。特に向き付き円板対の生成元同士の外積は、積円板とその境界の対の生成元を与える。積を上の分割で表すと各頂次単体が積の向きで現れるため、いずれか一枚の内点へ局所化するとその向きの生成元が残る。円板の相対群からこの局所群への写像は、境界球面から小球面への放射変形と接続の自然性により同型である。
:::

## 鎖複体の短完全列とジグザグ補題

:::theorem[ホモロジー長完全列]{#thm-at-zigzag}
鎖複体の次数ごとの短完全列 $0\to A_*\xrightarrow{i}B_*\xrightarrow{p}C_*\to0$ は
$$
\cdots\to H_n(A)\xrightarrow{i_*}H_n(B)\xrightarrow{p_*}H_n(C)
\xrightarrow{\delta}H_{n-1}(A)\to\cdots
$$
を誘導する。この列は短完全列の写像に関して自然である。
:::

:::proof
輪体 $c$ を $b$ に持ち上げる。$p\partial b=\partial c=0$ なので $\partial b=ia$ となる $a$ が一意に存在し、単射性から $\partial a=0$ である。$\delta[c]=[a]$ と置き、:term[接続準同型]{en="connecting homomorphism" yomi="せつぞくじゅんどうけい"} と呼ぶ。別の持ち上げでは $b$ が $id$ だけ変わるので $a$ は境界だけ変わる。代表を $c+\partial e$ に変えると $b$ に $e$ の持ち上げの境界を加えればよく、$a$ は変わらない。

$H_n(B)$ で $[p b]=0$ なら $p b=\partial c'$ である。$c'$ の持ち上げの境界を $b$ から引くと核に入り、$i$ から来る輪体を得る。$H_n(C)$ で $[a]=0$ なら $a=\partial d$ なので、$b-id$ は輪体の持ち上げである。$H_{n-1}(A)$ で $[ia]=0$ なら $ia=\partial b$ であり、$p b$ は $[a]$ を接続で与える輪体である。各逆向きの包含は、合成を代表元で計算して零となることから従う。可換な短完全列の写像は選んだ $b$ を別の持ち上げに送り、境界と可換であるため自然性も従う。
:::

:::example[接続写像がねじれを拾う短完全列]
鎖複体 $D$ を $D_1=D_0=\Z$、境界を $6$ 倍とする。$C\subset D$ として各次数に $4\Z$ を置けば、商 $E$ は各次数に $\Z/4$、境界は $2$ 倍である。$[2]\in E_1$ は輪体であり、整数の持ち上げ $2\in D_1$ の境界は $12\in C_0$ である。$H_0(C)=4\Z/24\Z$ であり、$4$ を生成元として見ると接続は $[3]\in\Z/6$ を与える。それは位数二であり、$H_0(C)\to H_0(D)$ の $4$ 倍写像の核を生成する。
:::

:::example[相対鎖を持ち上げ直した場合の符号]
$0\to A\to B\to C\to0$ で $c\in C_n$ の持ち上げ $b$ を $b+i(a)$ に替えると、$db$ の $A$ での代表は $da$ だけ変わる。さらに $c$ を $c+d v$ に替えるなら、$v$ の任意の持ち上げ $w$ により $b+dw$ を使える。その境界は $d^2w=0$ なので全く変わらない。この二種類の変更は、相対類の代表と持ち上げが別々に任意であることを区別している。例えば $(I,\{0,1\})$ の区間の鎖に端点 $0$ の定値辺を足しても、定値辺の境界は零なので接続は同じ $[1]-[0]$ である。
:::

:::proposition[三つ組の完全列]
$B\subset A\subset X$ に対して
$$
\cdots\to H_n(A,B)\to H_n(X,B)\to H_n(X,A)
\xrightarrow{\partial}H_{n-1}(A,B)\to\cdots
$$
が自然に完全である。
:::

:::proof
すべての鎖を $C_*(B)$ で先に割る。$C_*(A)/C_*(B)$ から $C_*(X)/C_*(B)$ への自然な包含は単射であり、さらに $C_*(A)/C_*(B)$ を割った余核は $C_*(X)/C_*(A)$ である。従ってジグザグ補題を使える。接続は $X$ の鎖に持ち上げて境界を取り、その $A$ 内の鎖を $B$ で割る操作になる。例えば $B$ の鎖を持ち上げに足した場合、その境界は $C_*(B)$ に入るので相対鎖には影響しない。$A$ の鎖を足した場合も、$A$ における境界の差だけになるためホモロジー類は変わらない。
:::

:::example[三点を段階的に同一視する]
$X=I$、$A=\{0,1/3,1\}$、$B=\{0,1\}$ とする。$H_1(X,B)=\Z$ の生成元は全区間であり、$H_1(X,A)=\Z^2$ の二基底は左と右の区間である。全区間を細分すると二部分の和になるため、前者から後者への写像は $1\mapsto(1,1)$ である。三つ組の接続は左部分の境界 $[1/3]-[0]$ と右部分の境界 $[1]-[1/3]$ を $B$ で割るから、$(a,b)\mapsto a-b$ を与える。これは $H_0(A,B)=\Z[1/3]$ へ全射であり、核は $(1,1)$ の張る直線である。各相対群を個別に計算しただけでなく、包含で何が移るかまで特定できる。
:::

:::example[次数ごとに分裂しても接続が零とは限らない]
$D_1=\Z a,D_0=\Z b$、$d(a)=3b$ とし、部分複体 $C$ を $C_1=0,C_0=D_0$ とする。商 $E$ は次数一に $\Z[a]$ だけを持つ。各次数で $0\to C\to D\to E\to0$ は分裂するが、$[a]$ の持ち上げ $a$ の境界は $3b$ であるため、接続 $H_1(E)\to H_0(C)$ は三倍である。それは単射であり、余核が $H_0(D)=\Z/3$ になる。もし鎖写像として分裂できれば $E$ の輪体 $[a]$ は $D$ 内で輪体に持ち上がるはずである。しかし $D_1$ において $[a]$ を表す唯一の持ち上げ $a$ の境界は非零であり、鎖レベルの分裂はできない。
:::

## 相対ホモロジーと対の長完全列

:::definition[相対ホモロジー]{#def-at-relative-homology}
$A\subset X$ について $C_n(X,A)=C_n(X)/C_n(A)$ と置き、そのホモロジー $H_n(X,A)$ を :term[相対ホモロジー]{en="relative homology" yomi="そうたいほもろじー"} と呼ぶ。相対輪体の代表 $c$ は $\partial c\in C_{n-1}(A)$ を満たせばよい。
:::

短完全列から :ref[thm-at-zigzag] を適用すると対の長完全列になる。接続写像は相対輪体の境界を $A$ で読む。対のホモトピーではプリズムが $C_*(A)$ を相手側の部分空間の鎖に送るため、相対群にもホモトピー不変性がある。

:::example[区間と端点]
$(I,\{0,1\})$ では $H_1(I)=0$ なので接続で $H_1(I,\{0,1\})$ を $\Ker(\Z^2\to\Z)$ と同一視できる。写像は和であり、核は $[1]-[0]$ が生成する。区間の恒等単体がその元を与える。$H_0(I,\{0,1\})$ は和が全射なので零である。
:::

:::example[三点を目印に置いた閉区間]
対 $(I,A)$ の $A=\{0,1/3,1\}$ とする。$H_1(I)=0$ であり、$H_0(A)=\Z^3\to H_0(I)=\Z$ は三座標の和である。従って $H_1(I,A)$ は $\Z^2$、$H_0(I,A)=0$ である。左の区間と右の区間をそれぞれ増加する方向に進む特異辺を取ると、接続の像は $(-1,1,0)$ と $(0,-1,1)$ になる。任意の $(a,b,c)$ で $a+b+c=0$ なら、これらの $-a$ 倍と $c$ 倍の和であるから、二辺の相対類は基底になる。
:::

:::example[二球面のウェッジにおける相対群]
$X=S^2\vee S^3$、$A=S^2$ とする。後で導く Mayer–Vietoris 完全列で各球面とウェッジを計算すると、$X$ の正次数ホモロジーは二因子の直和である。包含 $A\to X$ は次数二で同型なので、対の完全列で $H_3(X)\to H_3(X,A)$ は同型、$H_2(X,A)=0$ となる。これは $X/A=S^3$ の被約群とも一致する。一方 $A$ を三次の球面に替えれば、相対群に残るのは次数二である。相対群を計算するときは、除外する部分の次数と、全空間での包含の像を併せて見る必要がある。
:::

:::example[局所群が接合点で変わる]
三本の閉区間の左端を一点 $v$ に貼り合わせたグラフ $X$ を取る。$X$ 自身は木なので可縮である。$X\setminus\{v\}$ は三本の半開区間の非交和であり、零次群は $\Z^3$ である。従って対の完全列から $H_1(X,X\setminus\{v\})=\Z^2$ である。これに対して一つの辺の内部の点 $x$ では、小近傍は開区間で、その点を除くと二成分なので局所一次群は $\Z$ である。端点では小近傍を半開区間に取れ、端点を除いても一成分しかないため局所一次群は零になる。この一例では、局所群の階数で端、内部、分岐を見分けられる。
:::

:::example[閉円板と開円板を相対群で区別する]
$D^2$ の境界上の一点 $x$ と内部の一点 $y$ で、局所群 $H_2(D^2,D^2\setminus\{x\})$ と $H_2(D^2,D^2\setminus\{y\})$ を比べる。$x$ の近傍には閉半平面の小半円板を取れる。頂点を除いた半円板は内側の一点へ、例えば座標で直線に沿って動かすことで可縮となる。従って局所二次群は零である。内部の $y$ では円板から中心を除くと円周に変位レトラクトするため、長完全列から局所二次群は $\Z$ である。どちらの近傍も除去前は可縮だが、除去後のホモロジーが局所群を変える。円板の任意の自己同相はこの局所群を保つため、内部の点を境界の点には送れない。
:::

:::proposition[錐の先端における局所ホモロジー]
$L$ を空でない空間、$CL$ を錐、$v$ を先端とする。このとき $H_n(CL,CL\setminus\{v\};\Z)\cong\widetilde H_{n-1}(L;\Z)$ が $n\ge1$ で成り立ち、相対零次群は零である。
:::

:::proof
$CL=(L\times[0,1])/(L\times\{0\})$ は先端へ可縮である。先端を除けば $L\times(0,1]$ になり、$t$ を $1$ に動かす変形収縮で $L$ に戻る。対の長完全列で $n\ge2$ の接続の両隣の $CL$ の群は零なので、接続が所望の同型を与える。$n=1$ では $H_0(CL\setminus\{v\})\to H_0(CL)$ が各道成分を一つの成分へ送る。核は係数和が零の群であり、これが $\widetilde H_0(L)$ である。$L$ は空でないので零次の写像は全射となり、相対零次群は零になる。いずれも写像は小さい錐の包含や $L$ の写像に関して自然である。
:::

:::example[三本の半直線が会う点を区別する]
一点 $v$ で終点を貼った三本の閉線分は三点の錐である。従って $v$ の一次局所群は $\widetilde H_0(\{1,2,3\})=\Z^2$ である。各線分の内部の点の近くは二点の錐に同相なので一次局所群は $\Z$、外側の端点では一点の錐なので零になる。例えば $v$ では接続は、異なる二本の腕を結ぶ相対道を両端点の差へ送る。第三の腕の外側の端点を基準にして最初の二つとの差を取れば、それぞれが独立な基底を与える。この計算は空間全体が可縮だという事実と両立する。可縮性から分かるのは絶対群であり、ここでは各点を除いた対を変えているからである。
:::

## 切除定理と重心細分

:::lemma[小さい鎖の補題]{#lem-at-small-chains}
各元の内部の和が $X$ となる部分集合族 $\mathcal U$ を取る。各像が一つの部分集合に入る特異単体の張る部分複体 $C_*^{\mathcal U}(X)$ の包含は、ホモロジー同型を誘導する。各部分空間で制限した被覆を用いれば相対版も成り立つ。
:::

:::proof
標準単体の重心細分の各小単体を、重心を元の面の次元順に並べたアフィン写像で表す。それぞれに環境の向きとの一致を表す符号を付け、$\sigma$ と合成して $\operatorname{sd}(\sigma)$ を定義する。この頂点順によって共有面は二つの小単体から同じ特異単体として現れる。誘導される向きは逆なので係数が相殺し、外側は面の細分に一致する。従って細分は鎖写像である。$\id-\operatorname{sd}$ との鎖ホモトピーを次元順に作る。$\Delta^n$ 内で
$$
W_n=[\id_{\Delta^n}]-\operatorname{sd}[\id_{\Delta^n}]-T\partial[\id_{\Delta^n}]
$$
と置く。すでに面で作った $T$ の式と $\partial^2=0$ より $W_n$ は輪体である。$n=0$ では細分と恒等が一致し $T=0$ でよい。$n>0$ では重心を最初の頂点とする錐を各特異単体に取る。アフィンパラメータにより任意の特異単体を錐にでき、符号付き境界は $\partial(b*c)=c-b*\partial c$ である。従って $T[\id_{\Delta^n}]=b*W_n$ を $\sigma$ で押し出すと、$\partial T+T\partial=\id-\operatorname{sd}$ を満たす。どの項も元の単体の像の中に収まる。

有限鎖の各 $\Delta^n$ に逆像被覆の Lebesgue 数を使い、:ref[thm-at-simplicial-approximation] の径の見積もりから、十分細分すればその鎖が小さくなる。任意の輪体は細分した小さい輪体と同じ類なので全射である。小さい輪体 $z$ が $\partial c$ なら、十分細分して $\operatorname{sd}^k z=\partial\operatorname{sd}^k c$ を得る。$z$ と細分との差は元の像にとどまる鎖ホモトピーから小さい境界であり、従って単射である。相対の場合は細分と $T$ が $A$ 内の鎖を保つので同じ議論を商で行える。
:::

:::theorem[切除]{#thm-at-excision}
$Z\subset A\subset X$ とし $\overline Z\subset\operatorname{int}_X A$ とする。このとき包含 $(X\setminus Z,A\setminus Z)\to(X,A)$ はホモロジー同型を誘導する。この性質を :term[切除]{en="excision" yomi="せつじょ"} という。
:::

:::proof
$\operatorname{int} A$ と $X\setminus\overline Z$ は $X$ を覆うので、$\mathcal U=\{A,X\setminus Z\}$ は小さい鎖の補題を満たす。小さい鎖を $C_*(A)$ で割ると、自由基底の比較から $C_*(X\setminus Z)/C_*(A\setminus Z)$ になる。:ref[lem-at-small-chains] の相対版を適用する。
:::

:::example[点の近くの相対群]
Hausdorff 空間の点 $x$ と開近傍 $U$ に対し、$(X,X\setminus\{x\})$ から $X\setminus U$ を切除できる。従って局所的な対 $(U,U\setminus\{x\})$ でその相対群を計算できる。$U$ に円板の内部を取れるなら、円板の外側にどのような空間を足してもこの相対群は変わらない。
:::

:::proposition[近傍変位レトラクトの商]
$X$ を Hausdorff、$A\ne\varnothing$ を閉部分空間とし、開近傍 $U$ が $A$ に変位レトラクトするとする。商写像は $H_n(X,A)\cong\widetilde H_n(X/A)$ を誘導する。
:::

:::proof
$A\to U$ はホモトピー同値なので、対の完全列を比較すると $H_n(X,A)\cong H_n(X,U)$ である。$A\subset U$ は閉かつ $U$ は開なので、$H_n(X,U)\cong H_n(X\setminus A,U\setminus A)$ である。$X\setminus A$ は $(X/A)\setminus\{*\}$ と同相であり、同じことが $U$ でも成立する。商でも点 $\{*\}$ を切除できるので、これらの同型を合わせると $H_n(X,U)\cong H_n(X/A,U/A)$ となる。ここで $U/A$ は開であり、点 $\{*\}$ は閉である。$U$ の変位レトラクションは商に降りるため $U/A$ は可縮である。よって被約版の対の完全列で $H_n(X/A,U/A)\cong\widetilde H_n(X/A)$ が従う。
:::

例えばトーラス $X=T^2$ とウェッジ $A=S^1\vee S^1$ の対では、上の一枚の二胞体の外側の襟を使って近傍を取れる。商は $S^2$ なので相対群は二次で $\Z$、それ以外で零である。相対群の生成元の接続として、トーラスの接着ループを $H_1(A)$ で読むと零になる。実際、接着語の二種の辺の係数がそれぞれ $1-1$ だからである。

:::example[切除で区間を二つの端に分ける]
$X=[-3,3]$、$A=[-3,-1)\cup(1,3]$ とする。$Z=[-3,-2]\cup[2,3]$ は閉じており、$A$ は $X$ の中で開いているので切除できる。残る対は $((-2,2),(-2,-1)\cup(1,2))$ である。両側とも $X$ の部分は可縮、$A$ の部分は二成分なので $H_1$ の相対群は $\Z$ である。例えば左の $-3/2$ から右の $3/2$ を結ぶ辺は切除前と後の両方で相対輪体であり、接続は右成分から左成分を引いた生成元である。
:::

:::example[切除の仮定を外した反例]
$(X,A)=(I,\{0,1\})$ で $Z=\{0\}$ を取り除く。元の対の $H_1$ は両端点の差により $\Z$ である。しかし取り除いた対は $((0,1],\{1\})$ で、全体が $1$ に変位レトラクトするため $H_1=0$ になる。ここでは $Z$ は $A$ に含まれるが、$\operatorname{int}_X A$ が空なので閉包の条件を満たさない。相対部分からただ一点を取り除くだけでも、接続に表れる成分数を変えれば相対群は変わる。
:::

### 小さい鎖への鎖レベルの戻し方

:::proposition[小さい鎖の包含は鎖ホモトピー同値]
内部で空間を覆う族 $\mathcal U$ に対し、小さい鎖の複体の包含 $C_*^{\mathcal U}(X)\hookrightarrow C_*(X)$ は鎖ホモトピー逆を持つ。
:::

:::proof
細分を $S$、$\id-S=\partial T+T\partial$ を満たす局所的な鎖ホモトピーを $T$ とする。各特異単体 $\sigma$ について、重心細分を $m(\sigma)$ 回行うと、すべての小単体の像がそれぞれ一つの $\mathcal U$ の元に入るような最小の非負整数を取る。ここでは係数が打ち消し合うかによらず各小単体の像を検査する。面の重心細分はその面に沿う細分と一致するので、面 $\tau$ では $m(\tau)\le m(\sigma)$ である。

$T_m=\sum_{j=0}^{m-1}TS^j$ とすれば $\id-S^m=\partial T_m+T_m\partial$ である。各基底 $\sigma$ に対して $D(\sigma)=T_{m(\sigma)}(\sigma)$ とおき、$\rho=\id-\partial D-D\partial$ と定める。$\rho$ は $\partial^2=0$ から鎖写像である。さらに
$$
\rho(\sigma)=S^{m(\sigma)}\sigma+(T_{m(\sigma)}-D)\partial\sigma
$$
と変形できる。第一項は小さい鎖である。第二項は面 $\tau$ ごとに $j=m(\tau),\ldots,m(\sigma)-1$ の $TS^j(\tau)$ を足したものである。$S^j(\tau)$ はすでに小さく、$T$ は各単体の像の中だけを使うため、こちらも小さい。従って $\rho$ は小さい鎖へ値を取る。

初めから小さい $\sigma$ では $m(\sigma)=0$ であり、すべての面でも零なので $\rho(\sigma)=\sigma$ となる。従って $\rho$ と包含の一方の合成は恒等で、もう一方の差は $\partial D+D\partial$ である。また $D$ は部分空間内の鎖をその部分空間に送るため、相対版にも同じ式を使える。この結果により、コチェインを双対化したときにも小さい鎖の複体へ置き換えられる。
:::

### 有限個の点の除去を切除で計算する

:::proposition[有限点の補空間の被約群]
$n\ge1$ とし、$P=\{x_1,\ldots,x_m\}\subset\R^n$ を相異なる点の有限集合とする。$\R^n\setminus P$ の被約整数ホモロジーは次数 $n-1$ に $\Z^m$、ほかの非負次数で零である。
:::

:::proof
各 $x_i$ の周りに互いに素な開球 $U_i$ を取る。$Z=\R^n\setminus \bigcup_iU_i$ は閉じており、すべての $x_i$ を避ける。従って対 $(\R^n,\R^n\setminus P)$ から $Z$ を切除できる。切除後は $\coprod_i (U_i,U_i\setminus\{x_i\})$ となる。各特異単体は道連結な像を持つので、非交和の鎖複体は成分ごとの直和である。従って相対群も各相対群の直和になる。$U_i$ は可縮であり、点を抜いた開球は小球面へ変位レトラクトする。対の被約完全列から $(U_i,U_i\setminus\{x_i\})$ の非零群は $n$ 次に $\Z$ である。$n=1$ の場合は、小球面が二点なのでその被約零次群が $\Z$ となる。

元の全空間 $\R^n$ は可縮であり、補空間は非空だから、対の接続は相対 $n$ 次群と補空間の被約 $(n-1)$ 次群を同型にする。よって $m$ コピーの $\Z$ が得られ、他の次数は消える。各 $x_i$ の局所群を小円板の基本類で表すと、接続はその境界の小球面を返す。そのため補空間の基底を、除去点を一つずつ囲む球面の類に選べる。この説明は $n=1$ でも有効であり、小区間の二端点の差が被約零次類の一つを与える。
:::

:::example[二次元で三つの穴を回る輪体]
$\R^2$ から $(-2,0),(0,0),(2,0)$ を除く。それぞれのまわりに半径 $1/2$ の小円を置けば、三つの円周が $H_1=\Z^3$ の基底になる。半径 $4$ の大円の類は、三小円をすべて反時計回りに選んだ和である。実際、大円の閉円板を対 $(\R^2,\R^2\setminus P)$ の相対輪体とみなすと、各点での局所相対類は同じ向きの生成元であり、切除の直和で係数 $(1,1,1)$ になる。接続ではこれを一括して大円の境界へ、各成分では小円の境界へ送る。大円の内部をそのまま補空間の絶対鎖にすることはできないため、相対類で比較する手順が必要である。
:::

:::example[一次元では点の左右の差が残る]
$\R$ から $-1,2$ を除く。残る三つの区間を左から $L,M,R$ とし、それぞれ代表点を取る。$-1$ だけを囲む小区間の相対境界は $[M]-[L]$、$2$ だけを囲むものは $[R]-[M]$ である。係数和零の整数三つ組 $(a,b,c)$ はこれらを $-a$ 倍と $c$ 倍した和で表せる。実際、中央は $-a-c=b$ となる。従って二点を除くと被約零次の階数が二になる。同じ点の個数を二次元から除くと、被約零次ではなく一次の輪体に階数が移る。
:::

## Mayer–Vietoris 完全列

:::theorem[Mayer–Vietoris 完全列]{#thm-at-mayer-vietoris}
$X=U\cup V$ が開被覆なら
$$
\cdots\to H_n(U\cap V)\to H_n(U)\oplus H_n(V)\to H_n(X)
\xrightarrow{\delta}H_{n-1}(U\cap V)\to\cdots
$$
は完全である。第一の写像は包含を $(+,-)$ の符号で、第二は $(+,+)$ の符号で加える。増大鎖複体を使えば被約版も成立する。交わりが空なら $\widetilde H_{-1}(\varnothing)=\Z$ が列に現れる。
:::

:::proof
鎖で $c\mapsto(c,-c)$ と $(a,b)\mapsto a+b$ と置く。二つの鎖の共通基底は交わりに入る単体だけなので列は完全であり、和の像は小さい鎖複体である。増大の次数 $-1$ でも $0\to\Z\to\Z^2\to\Z\to0$ が完全である。小さい鎖の補題で $H_n(X)$ をこの小さい鎖のホモロジーと同一視する。ジグザグ補題によれば、小さい輪体 $z$ を $a+b$ と分けたとき、接続の値は $\delta[z]=[\partial a]$ である。
:::

:::example[球面の被約ホモロジー]
二つの極をそれぞれ除いた $S^n$ を開集合二つで覆う。両方とも $\R^n$ と同相であり、交わりは $S^{n-1}$ に変位レトラクトする。$n\ge1$ で完全列は $\widetilde H_k(S^n)\cong\widetilde H_{k-1}(S^{n-1})$ を与える。$S^0$ の被約零次群が $\Z$ なので、$S^n$ の被約群は次数 $n$ でだけ $\Z$ である。
:::

:::example[円周の接続写像を零鎖に落とす]
円周を二開弧で覆い、交わりの二成分に点 $x,y$ を置く。$U$ の中を $x$ から $y$ へ進む辺を $\alpha$、$V$ の中を $y$ から $x$ へ進む辺を $\beta$ とする。$\alpha+\beta$ は一次輪体で、小さい鎖としての分解はすでに与えられている。第一成分の境界は $[y]-[x]$ である。両開弧の被約ホモロジーが消えるため、この差を生成元とする被約零次群と $H_1(S^1)$ の間で接続は同型である。
:::

:::example[懸垂で一つ上の群を得る]
$X$ を空でないコンパクト Hausdorff 空間とし、$SX$ の両頂点をそれぞれ除いた開集合を取る。それぞれ残る頂点へ錐として縮み、共通部分は $X\times(0,1)$ と同相である。従って $\widetilde H_k(SX)\cong\widetilde H_{k-1}(X)$ である。例えば $X=S^1\vee S^1$ のとき、$H_2(SX)=\Z^2$、$H_1(SX)=0$ となる。各円周の一次輪体を上半分と下半分の錐で挟んだ二次輪体は、接続によりその一次輪体に移る。
:::

:::example[二つの可縮な開集合による円環の計算]
円環を、円周の二開弧と開区間との積で覆う。各開集合は可縮、交わりは二つの可縮な成分の和である。従って Mayer–Vietoris の接続は $H_1$ を交わりの被約零次群 $\Z$ と同一視する。開区間の座標を固定した芯の円周から得る一次輪体は、$U$ 側の辺の終点と始点の差に移るため生成元である。円環を横切る方向に幅を変えても、二つの成分と接続の符号だけで同じ答えを回収できる。
:::

:::example[被覆の交わりが二成分のときの行列]
$X=U\cup V$ で $U,V$ が道連結、交わりが二成分 $W_0,W_1$ を持つとする。Mayer–Vietoris の零次の第一写像は
$$
\Z^2\to\Z\oplus\Z,\qquad (a,b)\mapsto(a+b,-a-b)
$$
である。核は $(1,-1)$ の張る $\Z$ であり、これは $H_1(X)$ の接続像になる。従って $H_1(X)$ は必ずこの $\Z$ へ全射する。例えば $U,V$ が可縮なら、前から来る一次群も零なので $H_1(X)=\Z$ となる。一方各側に既に一次輪体があれば、それらの像も $H_1(X)$ の接続の核として残り得る。完全列の右側の情報だけで群全体を $\Z$ と決めないことが必要である。
:::

:::example[懸垂を二度使って二つの成分を拾う]
三点集合 $D$ の被約零次群は $\Z^2$ である。懸垂同型を一度使えば $SD$ は被約一次だけに $\Z^2$ を持つ。さらに $S(SD)$ では被約二次だけに $\Z^2$ が移る。例えば $D=\{a,b,c\}$ で $[b]-[a]$ を選ぶと、$SD$ では $b$ の母線と $a$ の母線を逆向きにつないだ周回になる。二回目の懸垂では、その周回を両極に向けて錐にし、共通する周回の境界を逆符号にして足すと二次輪体になる。二つの Mayer–Vietoris 接続はこの輪体を元の二点の差まで戻す。
:::

:::corollary[部分複体を貼る場合の Mayer–Vietoris 完全列]
CW 複体を二つの部分複体 $A,B$ で覆うと、$A\cap B,A,B,A\cup B$ のホモロジーに Mayer–Vietoris 完全列が成り立つ。
:::

:::proof
:ref[lem-at-subcomplex-neighborhood] により、$N(A)\cap N(B)=N(A\cap B)$ となる開近傍を取る。$A$、$B$、$A\cap B$ からそれぞれの近傍への包含はホモトピー同値であり、包含の図式と可換である。開近傍の完全列をこの同型に沿って移せば、部分複体での完全列が得られる。被約版も同じである。
:::

### 相対版の Mayer–Vietoris 完全列

:::proposition[部分空間を同時に割る開被覆]
$X=U\cup V$ を開被覆とし $A\subset X$ とする。$(U,U\cap A)$ と $(V,V\cap A)$ の相対群には、交わりの対 $(U\cap V,U\cap V\cap A)$ と全体の対 $(X,A)$ を結ぶ Mayer–Vietoris 完全列がある。
:::

:::proof
$C_*^{\mathcal U}(X)=C_*(U)+C_*(V)$ とし、$A$ の小さい鎖も対応する和とする。商 $C_*^{\mathcal U}(X)/C_*^{\mathcal U}(A)$ に対し、自然な列
$$
\begin{aligned}
0\longrightarrow C_*(U\cap V,U\cap V\cap A)
&\xrightarrow{(+, -)}
C_*(U,U\cap A)\oplus C_*(V,V\cap A)\\
&\xrightarrow{\,\mathrm{sum}\,}
C_*^{\mathcal U}(X)/C_*^{\mathcal U}(A)\longrightarrow0
\end{aligned}
$$
を取る。特異単体の基底を、$A$ に属すものと属さないものに分けると、各相対群は後者による自由群である。共通の基底はさらに $U,V$ の両方に属すものに限る。従って左矢印は単射で、和で消える鎖は共通基底の係数が正負で一致するものに限る。右端は小さい単体を $U$ か $V$ に選んで持ち上げれば全射である。全ての写像は鎖写像である。相対版の小さい鎖の補題により右端のホモロジーは $H_*(X,A)$ と一致し、ジグザグ補題で完全列が得られる。

例えば相対輪体 $z$ を小さくして $z=c_U+c_V$ と分けると、$\partial c_U+\partial c_V$ は $A$ 内の鎖である。従って商で $\partial c_U$ と $-\partial c_V$ は共通の基底から来る同じ相対鎖になる。接続を取るにはそれを交わりの対で読む。絶対の場合と式は同じだが、境界の一致は $A$ の部分を除いてから判定する。
:::

:::example[円環の縦の境界を相対的に読む]
$X=S^1\times I$、$A=S^1\times\partial I$ とする。$U,V$ を二開弧と $I$ の積に取る。それぞれの対は $(I,\partial I)$ と同値なので一次相対群に $\Z$ を持ち、交わりの対では二成分によって $\Z^2$ を持つ。一次の完全列の写像は、縦方向の辺を同じ向きに選ぶと $(a,b)\mapsto(a+b,-a-b)$ になる。従って $H_2(X,A)=\Z$ はこの写像の核、$H_1(X,A)=\Z$ は余核である。前者は円環全体の相対基本類、後者は上下の境界を結ぶ縦の辺の類で表せる。絶対の場合では $H_2(X)=0$ であり、相対条件によって二次の面の境界を両端の円周として許した結果が異なる。
:::

:::example[二つの球面を基点で貼った場合]
$X$ を二つの球面のウェッジとし、球面の一方の基点の小近傍を他方に付けて二開集合 $U,V$ を作る。各開集合は対応する球面に変位レトラクトし、共通部分は二つの小円板を基点で貼った可縮空間である。被約完全列で交わりの群がすべて零になるため、二球面の各類は全体の別々の生成元になる。例えば球面の次元が $2,3$ なら $\widetilde H_2=\widetilde H_3=\Z$、両方が $2$ なら $\widetilde H_2=\Z^2$ である。代わりに二球面を離れたまま取ると、正次数の計算は同じ直和でも、被約零次群に $\Z$ が追加される。ウェッジで零になるのは基点の貼り合わせによる道成分の違いである。
:::

### 交わりが空の被覆

被約群で完全列を書く場合、空集合で切れた段を落とすと零次の計算が変わる。増大鎖複体では空集合であっても次数 $-1$ に $\Z$ を置く。従って $\widetilde H_{-1}(\varnothing)=\Z$ であり、非空な空間では一点の零鎖の増大が $1$ になるので $\widetilde H_{-1}=0$ である。

:::proof[増大鎖複体での Mayer–Vietoris 完全列]
開被覆 $X=U\cup V$ について、Mayer–Vietoris の短完全列に次数 $-1$ の鎖群を足す。次数 $-1$ の写像は
$$
0\longrightarrow\Z\xrightarrow{a\mapsto(a,-a)}
\Z\oplus\Z\xrightarrow{(b,c)\mapsto b+c}\Z\longrightarrow0
$$
であり完全である。零鎖の増大は係数和なので、この二つの写像は直上の次数の包含、和と可換になる。従って増大鎖複体の短完全列を得る。小さい鎖の包含も次数 $-1$ で恒等であり、細分と鎖ホモトピーの式は零次の増大と両立する。よって長完全列が被約群で次数 $-1$ まで続く。$U,V$ のどちらかが空でも、この鎖の列は同じ式で定義される。
:::

:::example[二成分をつなぐ被約零次の接続]
$X$ を互いに素な二本の開区間 $U,V$ の和とする。$u\in U$、$v\in V$ を選ぶと $\widetilde H_0(X)$ の生成元は $[u]-[v]$ である。短完全列の持ち上げは $([u],-[v])$ であり、その増大は $(1,-1)$ である。これは次数 $-1$ の包含で $1$ の像なので、接続は $[u]-[v]\mapsto1$ を与える。もし空な交わりで次数 $-1$ の群を零と置けば、この二成分の差に相当する項がなくなる。普通の零次群を使う場合は $H_0(U)\oplus H_0(V)\to H_0(X)$ がそのまま同型である。被約群では、その二つの生成元の係数和を零とした部分が接続の定義域となり、空集合に対する群へ同型に移る。
:::

## 単体的ホモロジーと特異ホモロジーの同値性

:::theorem[単体鎖から特異鎖への比較]{#thm-at-simplicial-singular}
Δ 複体 $K$ の特性写像を特異単体とみなす鎖写像は $H_n^\Delta(K)\cong H_n(|K|)$ を誘導する。
:::

:::proof
$K^m$ を $m$ 骨格とする。有限複体の場合、$(|K^m|,|K^{m-1}|)$ において $|K^{m-1}|$ は開近傍 $N$ の変位レトラクトである。各 $m$ 単体で重心に近い小閉球を除き、残りを外の境界へ放射状に押す。境界を固定するので貼り合わせて連続になる。対の完全列から、第二項を $N$ に広げても相対群は同じである。さらに骨格と円板の境界近くの閉じた襟を $N$ の内部から切除すると、相対群は各 $m$ 単体の $(D^m,S^{m-1})$ の相対群の直和になる。例えば近傍 $N$ に半径 $r>1/3$ の襟を使い、骨格と $r\ge2/3$ の閉襟を切除する。残る各対は $(\{r<2/3\},\{1/3<r<2/3\})$ である。半径を $\min(3r/2,1/2)$ に送れば、これから半径 $1/2$ の閉円板と境界球面の対への写像を得る。包含との両合成は、半径の線形補間により対の恒等写像とホモトピックである。$m=0$ なら離散空間について直接確かめられる。

各相対群は $m$ 次にだけ $\Z$ に等しく、恒等単体の相対類がその生成元である。生成性は次元帰納法で示す。$m=1$ では端点の差が被約生成元である。$m>1$ では恒等単体の境界が境界球面の面の交代和である。境界球面の任意の一面の内点を除いた補空間は可縮なので、球面の $m-1$ 次群はその一点での局所相対群に同型に写る。そこで当該面だけが残り、切除と次元帰納法によって生成元になる。接続写像で恒等単体の類も生成元となる。

比較鎖写像は骨格で両側の対の長完全列を可換にする。相対群上で生成元を対応させ、下の骨格で同型なら、完全性による五項の図式追跡で中間の絶対群も同型となる。骨格の帰納法で有限複体の結論を得る。一般の場合、コンパクトな像は有限部分複体に入る。無限個の開単体を訪れれば各開単体から点を選べるが、閉単体は有限個の面しか含まないので選んだ集合は無限閉離散となり矛盾する。従って有限鎖とそれらの境界関係は有限部分複体で判定できる。
:::

:::example[頂次の輪体と特性写像]
二枚の三角形を境界で貼った球面の単体輪体 $z=\sigma-\tau$ を考える。$\sigma$ の開内部の点 $x$ を取って相対対 $(S^2,S^2\setminus\{x\})$ へ移すと、$\tau$ の項は消える。$\sigma$ は切除で一枚の二単体の局所類に戻り、前の証明で示した生成元を与える。従って特異ホモロジーに移しても $z$ は消えず、符号を選べば生成元である。単体鎖で向きを両方とも反転すると輪体の符号が変わる。特異鎖では頂点の並べ替えが別の基底単体を与えるので、ここで符号の反転を主張するのは比較写像が誘導するホモロジー類についてである。
:::

:::example[同じ空間の二つの三角形分割を比較する]
三角形の周の一次輪体 $z=[01]+[12]-[02]$ を考える。各辺を中点で分割すると、細分後の対応する六辺の向き付きの和 $z'$ が得られる。例えば辺 $[01]$ の両半分は $0$ から中点、中点から $1$ へ進む。三角形の内部を使わなくても、辺を連続な特異単体とみなし、その再パラメータ化の二単体を使えば、元の辺と二分割の和の差は特異境界になる。これは重心細分との鎖ホモトピーを辺だけで用いた場合である。従って二つの分割の生成元は同じ特異ホモロジー類へ写る。
:::

:::example[単体鎖の計算で後から加える係数]
二枚の三角形で作った射影平面で、整数の二次境界の Smith 成分が $1,2$ である場合を考える。$\F_2$ では $1$ だけが非零なので、一次の輪体に対する関係は一つ、二次境界の核は一次元である。従って $H_1,H_2$ はそれぞれ $\F_2$ となる。比較定理は係数付きでも成立する。相対の一枚の単体で得た整数の生成元を係数の基底に替えれば、相対群の比較も同じ同型になるためである。一方、整数群を次数ごとに $\F_2$ とテンソルするだけでは、整数で零だった二次群を回収できない。この違いは、比較の前後いずれでも鎖の段階で係数を変更することに由来する。
:::

:::example[単体近似を介した誘導写像の計算]
円周を三角形の周 $K$ とし、$f:S^1\to S^1$ を二乗写像とする。定義域を六辺の円周とし、各頂点を $0,1,2,0,1,2$ の順に値域 $K$ の頂点へ送れば、一周につき同じ三辺を二度進む単体写像になる。向き付きの一次輪体は六辺の和であり、誘導される鎖写像では値域の三辺の和の二倍となる。比較定理で各向き付き辺を特異単体として送ると、同じ周回の像が計算される。この場合、各辺のパラメータを線形に取れば写像の連続な実現はもとの二乗写像と同じである。したがって $H_1$ の誘導写像は $2$ 倍であり、基本群の巻き数とも一致する。頂点の順序を逆に進む辺では、その向きを符号として記録すると同じ手順で負の次数が得られる。
:::

:::proposition[単体写像と比較の自然性]
単体写像 $f:K\to L$ が誘導する向き付き単体鎖写像は、比較同型の下で、実現の連続写像 $|f|$ が誘導する特異ホモロジーの写像に対応する。頂点順序の保存は仮定しない。
:::

:::proof
比較の二通りの鎖写像を $F,G:C_*^\Delta(K)\to C_*(|L|)$ とする。両者は頂点で一致し、各単体 $\sigma$ に対して像の鎖が同じ閉単体 $f(\sigma)$ に入る。$F-G=\partial P+P\partial$ を構成する。零次で $P=0$ とし、次元 $n>0$ まで来たら $(F-G)\sigma-P\partial\sigma$ を考える。その境界は一つ下の次数の鎖ホモトピーの等式と $\partial^2=0$ により零である。この鎖は閉単体 $f(\sigma)$ に入る。実際、$\sigma$ の面を像へ送ると $f(\sigma)$ の面になる。そこで閉単体内の錐を取れば輪体を埋められる。この錐を $P(\sigma)$ とすれば等式が次の次数でも成立する。従って両鎖写像はホモロジー上で一致する。
:::

単体近似が誘導する写像も、実現の連続写像が特異ホモロジーに誘導する写像と一致する。近似は元の写像とホモトピックであり、細分の鎖写像は特異群に移すと恒等と鎖ホモトピックだからである。従って単体近似によるホモロジー写像は、恒等写像と合成を保つ。二つの異なる三角形分割で得た群も、同じ空間の特異群を経て比較できる。

係数を $G$ に替えた相対単体鎖の比較にも、同じ骨格の証明を使える。単体対と球面の計算では一個の整数生成元を置いた場所に $G$ を一コピーずつ置く。面の符号と接続写像は係数ごとに同じなので、相対生成元の比較は各コピーの恒等写像である。従って次数ごとの比較は任意の係数群で成り立つ。

## 演習問題

::::exercise{level=basic}
一点上の $\partial_4$ と $\partial_5$ を計算せよ。
:::solution
符号の和は $\partial_4$ で $1-1+1-1+1=1$、$\partial_5$ で $1-1+1-1+1-1=0$ である。
:::
::::

::::exercise{level=basic}
道成分が五個なら $\widetilde H_0$ の階数を求めよ。
:::solution
$H_0=\Z^5$ から係数和を取った核なので、階数は $5-1=4$ である。
:::
::::

::::exercise{level=basic}
$(D^2,S^1)$ の $H_2$ を計算せよ。
:::solution
円板の $H_2,H_1$ はともに零なので、接続により $H_2(D^2,S^1)\cong H_1(S^1)=\Z$ である。
:::
::::

::::exercise{level=basic}
$S^3$ の $H_2$ を求めよ。
:::solution
二半球の被約完全列で $\widetilde H_2(S^3)\cong\widetilde H_1(S^2)\cong\widetilde H_0(S^1)=0$ となる。
:::
::::

::::exercise{level=advanced}
$(I,\{0,1\})$ から $(I,\{0,1\})$ への反転が相対 $H_1$ にどう作用するか求めよ。
:::solution
接続は区間の類を $[1]-[0]$ に送る。反転でこの差が $[0]-[1]$ となるため、自然性によって相対群で $-1$ 倍である。
:::
::::

::::exercise{level=advanced}
$S^1$ を交わりが二成分の二つの弧で覆い、接続の像を求めよ。
:::solution
二弧は可縮なので、被約完全列で $\widetilde H_1(S^1)$ は $\widetilde H_0(U\cap V)$ と同型である。後者は二成分の差が生成する $\Z$ である。
:::
::::

::::exercise{level=advanced}
各特異単体の定義域を一回重心細分する鎖写像が輪体の類を変えないことを示せ。
:::solution
細分との差は $\partial Tz+T\partial z$ であり、$\partial z=0$ なので $\partial Tz$ という境界である。
:::
::::

::::exercise{level=advanced}
$X$ が空でない可縮空間で $A$ が三点の離散部分空間なら $H_1(X,A)$ を求めよ。
:::solution
$H_1(X)=0$ であり、$H_0(A)\to H_0(X)$ は $\Z^3\to\Z$ の和である。よって接続でその核に同型となり $\Z^2$ を得る。
:::
::::

::::exercise{level=advanced}
$\R^2$ から四点 $x_1,x_2,x_3,x_4$ を取り除く。$x_1,x_2$ を内部に含み $x_3,x_4$ を含まない閉円板の境界を正向きに一周するループと、$x_2,x_3$ だけを同じ向きに囲むループを考える。これらの一次ホモロジー類を小円の基底で書き、その差が零になるか答えよ。

:::solution
四点を除いた平面の $H_1$ は $\Z^4$ であり、各除去点を囲む正向きの小円を基底 $e_i$ とできる。はじめの円板の内部を相対輪体と見れば、切除による四つの局所成分のうち、内部に含む $x_1,x_2$ だけで局所生成元になる。外側の点は全鎖がその点を避けるので局所化が零である。従って接続により最初の境界は $e_1+e_2$ である。同様に二番目は $e_2+e_3$ である。

差は $e_1-e_3$ となる。自由群の異なる基底の差は零ではないので、これらの周回を特異二鎖の境界だけで変更して一致させることはできない。二本の周回が共有して囲む $x_2$ の係数は差で打ち消し合うため、共通して囲まれる点に関しては違いが残らない。ここで半径や円の中心の座標は使っていない。各円がどの点を内側に持つかだけを局所化から読んだ。
:::
::::

::::exercise{level=advanced}
$X$ は $S^1$ に度 $m$ と度 $n$ の二つの写像で円板を貼った空間、$A=S^1$ とする。$m,n$ は両方同時には零でないとする。相対群と、その接続、絶対の $H_1,H_2$ を求めよ。

:::solution
$A$ の襟を取って商を用いると、$X/A$ は二つの二球面のウェッジである。従って $H_2(X,A)=\Z^2$ であり、他の正次数の相対群は零である。各円板の内部を正向きに取ると、接続の値は接着写像に沿って円周を $m$ 回または $n$ 回進む類になる。従って $\partial:\Z^2\to H_1(A)=\Z$ は $(a,b)\mapsto ma+nb$ である。

対の完全列では $H_2(A)=0$ から $H_2(X)$ が相対二次群に単射で入り、その像はこの接続の核である。$d=\gcd(m,n)>0$ とし、$m/d,n/d$ は互いに素であるから、核は $(n/d,-m/d)$ が張る $\Z$ である。次の $H_1(X,A)$ は零なので、$H_1(X)$ は接続の余核となり $\Z/d$ である。例えば $(m,n)=(6,-4)$ なら $d=2$ で、二つの相対円板を $(-2,-3)$ の比で足せば境界が零になる。$H_2$ の計算では二枚の関係の間の従属性を、$H_1$ の計算ではどの倍数が境界になったかを読んでいる。
:::
::::

::::exercise{level=advanced}
$L=S^1\vee S^2$ の錐 $CL$ の先端 $v$ に対し、すべての相対群 $H_q(CL,CL\setminus\{v\};\Z)$ を求めよ。さらに円周因子を一点へ潰し球面因子を固定する写像を錐へ延長すると、局所群にどのように作用するか。
:::solution
楔点を含むそれぞれの因子の小さい近傍を合わせた開被覆を取る。各開集合は一方の因子に変形収縮し、交わりは可縮にできる。Mayer–Vietoris の被約完全列から、$L$ の被約群は一次に円周からの $\Z$、二次に二球面からの $\Z$ があり、他では零である。錐と穴あき錐の対では、接続で $H_q(CL,CL\setminus\{v\})\cong \widetilde H_{q-1}(L)$ となる。従って二次と三次に $\Z$ が一つずつあり、残りは零になる。

錐の延長は $[\ell,t]\mapsto[g(\ell),t]$ とでき、$t>0$ は $t>0$ のままなので対の写像を定める。穴あき錐は $t=1$ の $L$ に収縮し、その収縮とこの写像は可換である。従って接続の自然性から局所二次は円周の被約一次群と同じく零へ、局所三次は二球面の頂次群と同じく恒等へ送られる。二次の局所生成元は、円周の輪体を錐にしてその境界を穴あき錐に置いたものでも表せる。
:::
::::
