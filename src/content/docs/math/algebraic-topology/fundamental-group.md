## この章の目標

- 端点を固定した道の変形から群を構成する。
- 基点変更と写像による準同型の関係を示す。
- 円周の巻き数を求め、不動点や多項式の零点の存在に使う。
- 積空間とホモトピー同値が基本群に及ぼす効果を証明する。

## 道とそのホモトピー

:::definition[道と端点相対ホモトピー]{#def-at-path-homotopy}
$X$ の :term[道]{en="path" yomi="みち"} は連続写像 $\alpha:I\to X$ である。$\alpha(0)=x$、$\alpha(1)=y$ のとき $x$ から $y$ への道という。$x=y$ のときは :term[ループ]{en="loop" yomi="るーぷ"} という。端点の一致する道の間で $\{0,1\}$ を固定する :ref[def-at-homotopy]{text="ホモトピー"} を端点相対ホモトピーという。
:::

$\alpha(1)=\beta(0)$ なら、$\alpha*\beta$ は前半で $\alpha(2t)$、後半で $\beta(2t-1)$ となる道である。$\bar\alpha(t)=\alpha(1-t)$ とし、$x$ にとどまる道を $c_x$ とする。

:::lemma[道の演算]{#lem-at-path-laws}
連結は相対ホモトピー類上で定まり、結合的である。$c_x*\alpha\simeq\alpha\simeq\alpha*c_y$、$\alpha*\bar\alpha\simeq c_x$、$\bar\alpha*\alpha\simeq c_y$ が端点相対で成り立つ。
:::

:::proof
連結する二本のホモトピーを時間の各半分に貼ると、接続点は固定されているので連続である。再パラメータ化 $\alpha\circ u$ と $\alpha\circ v$ は、$u,v:I\to I$ が同じ端点を保てば $\alpha((1-s)u(t)+sv(t))$ で結べる。三連結は等しい三分割の道を区分線形に再パラメータ化したものとして比較できる。定値道を入れた場合も一方の半区間を端点へ送る再パラメータ化である。最後に $\alpha*\bar\alpha$ は $\alpha((1-s)(1-|2t-1|))$ で $c_x$ に変形する。$\bar\alpha$ に同じ式を使うと後者の逆の式を得る。
:::

:::example[平面と円周の違い]
$\R^2$ では端点を共有する任意の道が点ごとの線分で結ばれる。例えば $(t,4t(1-t))$ と $(t,0)$ の中間の道の高さは $2t(1-t)$ である。円周では同じ端点を持つ道でも中間の線分が円周から外れる。そこで軌跡を角度に引き戻して比較する。
:::

道のホモトピー類は、先に進む道の終点と後に進む道の始点が一致するときに連結できる。このように、点を対象、道の類を射とし、全ての射に逆がある仕組みを :term[基本亜群]{en="fundamental groupoid" yomi="きほんあぐん"} と呼ぶ。例えば二つの互いに素な区間の和では、同じ区間にある二点の間に射が一つあり、異なる区間の点の間には射がない。各点で自身に戻る射だけを集めると、次の群が得られる。

:::example[往復を区間内で消す]
$\alpha(t)=(t,2t)$ を原点から $(1,2)$ への道とする。往復 $\alpha*\bar\alpha$ を縮めるとき、$H(t,s)=\alpha((1-s)(1-|2t-1|))$ の折り返し点は $((1-s),2(1-s))$ である。例えば $s=3/4$ の時点では $(1/4,1/2)$ までしか進まない。始点と終点は全時刻で原点なので、この往復はどの値域に含めても端点相対に消せる。曲がった道でも $\alpha$ の式をそのまま置き換えればよい。
:::

:::lemma[四辺の交換]{#lem-at-path-square-boundary}
正方形上の連続写像の下辺と右辺を続けた道は、左辺と上辺を続けた道に端点相対でホモトピックである。
:::

:::proof
正方形内で二つの折れ線を $\lambda(t),\mu(t)$ とする。いずれも $(0,0)$ から $(1,1)$ へ向かう。$(1-s)\lambda(t)+s\mu(t)$ は正方形内にとどまり、両端を固定する。これを正方形上の写像と合成する。逆に四辺の周回路が縮むなら、縮約の終端 $S^1\times\{1\}$ を一点に潰した錐を円板として使うことで、与えた四辺の値を正方形全体へ延長できる。円周から正方形の境界への放射状同相で向きと始点を合わせればよい。
:::

### 円板上の写像と閉曲線の縮約

:::proposition[円板への延長判定]{#prop-at-loop-disk-extension}
基点 $x_0$ のループ $\alpha:I\to X$ を円周値域でなく円周を定義域とする写像 $a:S^1\to X$ とみなす。$a$ が $D^2\to X$ に延長する必要十分条件は $\alpha$ の基本群の類が単位元であることである。
:::

:::proof
$\alpha$ の端点相対の縮約があれば、時間 $s=0$ で $\alpha$、$s=1$ で定値となる正方形の写像がある。左右の辺の値はどの時間も等しいので、円周の円柱に降りる。円柱の最後の円周は一点に潰せ、その商が円板である。従って所望の延長が得られる。

逆に円板への延長 $A$ を取る。円周の基点を $1$ とし、円板上で円周上の点 $z$ を $(1-s)z+s$ に移す。この線分は閉円板に入る。基点 $1$ では全時刻で値が $1$ であり、終時刻ですべての点が $1$ になる。$A$ と合成すると $\alpha$ の端点を固定した縮約を得る。円板の中心に縮めなくてもよいことが、基点を保つために役立つ。
:::

:::example[円周の包含を円板へ延長する]
$a:S^1\to\R^2$ を $a(z)=(\Re z,\Im z)$ とする。円板への延長は円板の包含である。上の縮約では $z=-1$ の像は $s=1/2$ で原点、終点で $1$ になる。これを値域 $S^1$ に替えると、同じ途中の式は原点で値域から出る。後に計算するように $S^1$ 値での閉曲線そのものは巻き数一であるため、別の延長を取ることもできない。定義域の円板が同じでも、値域がどこまで許されるかで結論が変わる。
:::

:::example[円板で道を入れ替える]
平面の正方形の左下から右上へ二通りの道を取り、下辺と右辺を通る方を $\alpha$、左辺と上辺を通る方を $\beta$ とする。それぞれを二辺等分の速度で進めると、時刻 $t=1/2$ には $(1,0),(0,1)$ にいる。線形補間の時間 $s=1/3$ ではこの分点が $(2/3,1/3)$ になる。中心を除いた正方形を値域にすると時間 $s=1/2$ の分点が中心を通るため、同じ補間は定義できない。このとき二つの道を続けてできる境界ループが、除去点を一周することが障害になる。
:::

:::proposition[端点の固定と端点の追跡]
道のホモトピー $H:I\times I\to X$ に対し、底辺と上辺の道を $\alpha,\beta$、左辺と右辺の道を $\lambda,\rho$ とする。端点の動きを補うと $\alpha*\rho$ と $\lambda*\beta$ は端点相対でホモトピックである。
:::

:::proof
これらは正方形の左下から右上へ向かう二つの辺に沿う道を $H$ で送ったものである。:ref[lem-at-path-square-boundary] により正方形内で端点相対に結べる。例えば $\lambda=\rho=c$ なら、定値道を取り除くことで $\alpha\simeq\beta$ が端点相対で従う。ループの自由ホモトピーでは二辺が同じ $\lambda=\rho$ になるが、定値とは限らない。その場合は積の左右にこの道が残り、次の節での共役の式になる。
:::

:::example[端点が同じ時刻に戻っても途中の道が異なる場合]
円周で $H(s,t)=e^{2\pi i st}$ を取る。時刻 $t=0$ の道は定値で、$t=1$ では一回転するループになる。左端は全時刻で $1$ だが、右端は $e^{2\pi it}$ と一回転し、その始点と終点はともに $1$ である。四辺の式では底に右をつないだ類が一回転、左に上をつないだ類も一回転で一致する。従って両端で基点を共有している二つのループでも、この正方形が端点相対ホモトピーを与えるとは言えない。右端が動く間に一つの巻き数が増えた。
:::

### 穴を避ける道の端点相対分類

:::example[始点と終点が異なる場合も角度で分類できる]
$\C\setminus\{0\}$ で $2$ から $3i$ へ向かう道を考える。正規化した角度を実数値に持ち上げ、始点で $0$ にすると、終点は $1/4+k$（$k\in\Z$）となる。端点相対ホモトピーでこの整数は変わらない。実際、正規化して角度の持ち上げを取ると、終点は離散な集合 $1/4+\Z$ に連続に値を取る。逆に二つの道の角度の終点が同じなら、持ち上げた角度を線形に補間できる。元の半径も二道の半径の凸結合で補間すれば正であり、始点の半径 $2$ と終点の半径 $3$ が保たれる。よって補間した半径と角度の指数を掛ければ端点相対ホモトピーになる。

どの $k$ も $(2+t)e^{2\pi i(1/4+k)t}$ によって実現できる。例えば $k=0$ の道は正向きに四分の一周し、$k=-1$ の道は逆向きに四分の三周する。両者は同じ始終点を持つが、端点相対に変形できない。差をループとして読めば、前者と後者の逆の連結は巻き数一である。ループでない道に整数を割り当てるときは、終点の角度の基準を一つ決める必要がある。
:::

## 基本群の定義と基点の取り替え

:::definition[基本群]{#def-at-pi-one}
$(X,x_0)$ のループを端点相対ホモトピーで割った集合を :term[基本群]{en="fundamental group" yomi="きほんぐん"} $\pi_1(X,x_0)$ と呼ぶ。積は $[\alpha][\beta]=[\alpha*\beta]$ とする。:ref[lem-at-path-laws] により単位元は $[c_{x_0}]$、逆元は $[\bar\alpha]$ である。道連結で基本群が自明な空間を :term[単連結]{en="simply connected" yomi="たんれんけつ"} という。
:::

:::proposition[道に沿った基点変更]{#prop-at-change-basepoint}
$\gamma:x\to y$ は $\tau_\gamma:\pi_1(X,y)\to\pi_1(X,x)$、$[\beta]\mapsto[\gamma*\beta*\bar\gamma]$ を誘導する。これは同型であり、$\tau_{\gamma*\delta}=\tau_\gamma\tau_\delta$ である。
:::

:::proof
二つの像の積の中央に現れる $\bar\gamma*\gamma$ は $c_y$ に変形できるので準同型になる。同じ消去で $\tau_\gamma\tau_{\bar\gamma}$ とその逆順が恒等になる。合成則は結合律と逆向きの道の順序から従う。
:::

:::example[基点変更の依存性]
$\gamma,\gamma'$ がともに $x$ から $y$ へ向かうなら、$\tau_{\gamma'}$ は $\tau_\gamma$ の後で $[\gamma'*\bar\gamma]$ による共役を取った写像である。よって道連結空間では基本群の同型型だけが基点によらない。群が可換な場合は基点を結ぶ道の選択によらない。
:::

:::example[基点を角度 $1/4$ へ移す]
$\gamma(t)=e^{2\pi it/4}$ は $1$ から $i$ への道である。$i$ に基づく $\beta(t)=ie^{6\pi it}$ の前後に $\gamma$ と $\bar\gamma$ を添えると、角度は $0$ から $1/4$、次に $13/4$、最後に $3$ へ動く。従って $\tau_\gamma[\beta]$ は基点 $1$ で三回転する類である。$\gamma'(t)=e^{-3\pi it/2}$ を選ぶと途中の角度は $-3/4$ と $9/4$ に替わるが、最後の角度は同じ $3$ になる。
:::

:::proposition[自由ホモトピーと共役]
道連結空間 $X$ で基点 $x$ を共有する二つのループの $S^1\to X$ としてのホモトピー類が等しい必要十分条件は、$\pi_1(X,x)$ における二つの元が共役であることである。
:::

:::proof
自由ホモトピーを正方形に引き戻し、縦辺を同じループ $\gamma$ と読む。:ref[lem-at-path-square-boundary] により $[\alpha][\gamma]=[\gamma][\beta]$ となる。逆にこの等式が成り立てば $\alpha*\gamma*\bar\beta*\bar\gamma$ は縮む。四辺の交換の補題の証明で構成した延長を使って、底に $\alpha$、上に $\beta$、左右に同じ $\gamma$ を持つ正方形の写像を得る。この写像は左右の辺の同一視に関して一定なので $S^1\times I$ に降りる。
:::

### 基点を固定した単連結性

:::proposition[道の一意性による単連結性の判定]
道連結な空間 $X$ では、基本群が自明であることと、同じ始点・終点を持つ任意の二道が端点相対でホモトピックであることは同値である。
:::

:::proof
同じ始点 $x$、終点 $y$ の二道 $\alpha,\beta$ を取る。基本群が自明なら、基点変更により $\pi_1(X,x)$ も自明である。従って $\alpha*\bar\beta\simeq c_x$ である。両側の終点は $x$ なので右に $\beta$ を連結できる。左側の $\bar\beta*\beta$ は終点 $y$ での定値道に縮み、右側は $\beta$ と同値だから $\alpha\simeq\beta$ を得る。逆に同じ端点の二道が常に同値なら、基点から出て同じ点へ戻る任意のループを定値道と比較できる。よって基本群は自明である。
:::

:::example[円柱の主部分に基点がない場合]
$X=S^1\times[-1,1]$、$x=(1,-1)$、$y=(1,0)$ とする。$\gamma(t)=(1,t-1)$ を用いると、中央の円周を三回まわるループから、$x$ を基点とするループ $\gamma*\beta*\bar\gamma$ が得られる。円周へ第一射影すると $\gamma,\bar\gamma$ はどちらも定値なので、巻き数は中央のループの $3$ のままである。下端でも円周を三回まわるループと同じ類になるのは、上下を平行に動かすホモトピーがこの $\gamma$ を基点の軌跡として使うためである。この比較では異なる二点の群を等号で結ばず、道が誘導する同型を通している。
:::

:::proposition[位相群の基本群]
位相群 $G$ の単位元での基本群は可換である。ループの連結で定めた積は、時刻ごとに群演算で掛けた積と同じ類を与える。
:::

:::proof
時刻ごとの積を $\alpha\cdot\beta$ とし、連結を $*$ とする。どちらの操作も端点相対ホモトピーを保ち、定値ループを単位元に持つ。二つの演算は
$$
(\alpha*\beta)\cdot(\gamma*\delta)
=(\alpha\cdot\gamma)*(\beta\cdot\delta)
$$
を満たす。これは前半と後半で同じ式になることから分かる。類の段階で $\beta,\gamma$ を単位元に置くと、$\alpha\cdot\delta=\alpha*\delta$ が従う。今度は $\alpha,\delta$ を単位元とすると、$\beta\cdot\gamma=\gamma*\beta$ になる。二つの等式を合わせれば連結は可換である。位相群そのものの演算には可換性を仮定しておらず、使ったのは連続な二つの操作が同じ単位元を持つことである。
:::

:::example[基点を動かしたときに自由群で起きる変化]
群が二元の自由群 $F(a,b)$ となる空間を考える。その空間の例は [Seifert–van Kampen の定理](/math/algebraic-topology/van-kampen/) で扱う。基点を $a$ に沿って一周させると、$b$ の像は $aba^{-1}$ である。この語は簡約しても $b$ と異なるため、基点が同じ点へ戻っても基点変更の自己同型は恒等とは限らない。一方円周自身の群は可換なので、同じ方法でどの巻き数のループに沿って基点を動かしても共役は恒等になる。この二例では、基点変更が空間の形だけでなく選んだ道に依存する理由を語の積で確認できる。
:::

## 誘導準同型と関手性

:::proposition[基本群の関手性]{#prop-at-pi-one-functor}
$f:(X,x)\to(Y,y)$ は $f_*[\alpha]=[f\circ\alpha]$ で群準同型を定める。$\id_*=\id$、$(gf)_*=g_*f_*$ である。$f$ と $g$ が基点付きホモトピーで結ばれるなら $f_*=g_*$ である。
:::

:::proof
道のホモトピーを $f$ と合成しても連続で端点は保たれる。道の連結の区分式は合成と可換である。恒等と合成の式は各ループに適用して確かめられる。基点付きホモトピー $H$ があれば $H(\alpha(t),s)$ が誘導されたループの端点相対ホモトピーである。
:::

基点が動く場合に現れる補正も具体的である。$\eta(s)=H(x,s)$ とすると
$$
f_*=\tau_\eta g_*
\label{eq-at-pi-one-moving-basepoint}
$$
である。実際、正方形 $(t,s)\mapsto H(\alpha(t),s)$ の底と右を進む道は、左と上を進む道と端点相対でホモトピックである。正方形内の二つの道を凸性で結べばよい。したがって $f\alpha*\eta\simeq\eta*g\alpha$ となり右に $\bar\eta$ を連結できる。

:::example[レトラクションが与える分裂]
$ri=\id_A$ なら $r_*i_*=\id$ である。よって $i_*$ は単射、$r_*$ は全射になる。円板と境界の間でそのような $r$ が存在すれば、後で求める円周の基本群が円板の自明群に単射で入ることになる。
:::

:::example[積への対角写像と射影]
$\Delta:X\to X\times X$ を $x\mapsto(x,x)$ とし、$p_j$ を射影とする。任意の $[\alpha]$ から $\Delta$ が作るループは $(\alpha,\alpha)$ である。両方の射影で $[\alpha]$ に戻るので $p_{j*}\Delta_*=\id$ である。$X=S^1$ のとき、積の基本群を後節のように二つの巻き数で表せば $\Delta_*:n\mapsto(n,n)$ となる。例えば $(2,3)$ は第一・第二座標とも何らかの円周ループから来るが、対角の像には入らない。
:::

:::example[レトラクションへの包含が全射にならない場合]
$T^2$ の第一因子円周 $A=S^1\times\{1\}$ へのレトラクションを $r(z,w)=(z,1)$ とする。$i_*:\pi_1(A)\to\pi_1(T^2)$ は $n\mapsto(n,0)$ で単射である。第二因子の生成元 $(0,1)$ は第一因子に沿うどのループからも得られず、$i_*$ は全射ではない。実際、第二射影と $i$ の合成が定値であることから、$i_*$ の像の第二成分は必ず零である。従ってこのレトラクトは変位レトラクトではない。代数の分裂とホモトピー同値の違いが、第二因子の残る生成元に現れる。
:::

:::example[定値写像へ縮む写像の誘導準同型]
連続写像 $f:X\to Y$ が定値写像にホモトピックであるとする。基点を動かす補正式を使うと $f_*$ は定値写像の自明な準同型と基点変更の合成であり、群の単位元しか取らない。例えばトーラスの第一射影は第一因子の一周を生成元に送るので、定値には縮まない。一方 $h(z,w)=e^{i(\Re z+\Im w)}$ は $H((z,w),t)=e^{i(1-t)(\Re z+\Im w)}$ で縮む。基点が途中に移っても、誘導準同型の自明性は基点変更で変わらない。
:::

:::example[包含と射影の二つの合成を区別する]
$X=S^1\times S^1$、$A=S^1$ とし、$i:A\to X$ を $i(z)=(z,z^2)$、$r:X\to A$ を第一射影とする。$ri=\id_A$ であり、群への作用は $i_*(n)=(n,2n)$、$r_*(m,n)=m$ である。従って $r_*i_*=\id$ となる。一方 $i_*r_*$ は $(m,n)$ を $(m,2m)$ に送り、例えば $(0,1)$ を消す。よって反対の合成は恒等にホモトピックでない。この例の $i(A)$ はレトラクトだが変位レトラクトではない。包含の片側の逆がある場合も、反対側の合成を確認する必要がある。
:::

## 円周の基本群

円周上で角度は整数回転だけずれる。道の始点で角度を選び、細かい小区間ごとに連続な角度を選べば、そのずれを終点まで追跡できる。

:::lemma[連続な角度の持ち上げ]{#lem-at-circle-lift}
$p:\R\to S^1$ を $p(u)=e^{2\pi i u}$ とする。道 $\alpha$ と $p(a)=\alpha(0)$ を満たす $a$ に対して、$\widetilde\alpha(0)=a$、$p\widetilde\alpha=\alpha$ を満たす連続な $\widetilde\alpha$ がただ一つ存在する。端点相対ホモトピーにわたって同じ始点を選ぶと、終点は一定である。
:::

:::proof
円周は開弧で覆われ、各開弧上で $p$ に連続な局所逆がある。道の逆像被覆の Lebesgue 数を使い、各部分区間を一つの開弧へ写るように分割する。各区間で局所逆に整数を足して左端を前の区間に合わせる。一意性は二つの持ち上げの差が連続整数値で始点で $0$ であることから従う。

ホモトピーの正方形も各小正方形が一つの開弧に写るように分割する。底辺を既に持ち上げて下の行から左から右へ進む。各小正方形では角で整数を調節すると、既に定めた辺と連続整数値の差が $0$ になる。従って大域的な持ち上げを貼れる。左右の辺の像はそれぞれ一つのファイバーに入り、連続性から一定である。
:::

:::theorem[円周の基本群]{#thm-at-circle-pi-one}
円周の任意のループ $\alpha$ に対し、持ち上げの両端の差 $\widetilde\alpha(1)-\widetilde\alpha(0)$ を :term[巻き数]{en="winding number" yomi="まきすう"} という。始点の角度を変えても持ち上げ全体が整数だけ平行移動するので、巻き数は変わらない。基点を $1$ に取ると、巻き数は $\pi_1(S^1,1)\cong\Z$ を与える。
:::

:::proof
:ref[lem-at-circle-lift] が代表元の選択によらないことを保証する。積の持ち上げでは後半の角度に前半の終点の整数を足すため巻き数は加わる。$t\mapsto p(nt)$ の巻き数は $n$ なので全射である。巻き数が $0$ の持ち上げは両端が $0$ の実数値の道であり、線形に $0$ へ縮めて $p$ と合成すればループを縮められる。よって核は自明である。
:::

:::example[回転と反転]
$z\mapsto z^5$ は基本群で $n\mapsto5n$ を誘導し、$z\mapsto\bar z$ は $n\mapsto-n$ を誘導する。角度の持ち上げで前者は $u\mapsto5u$、後者は $u\mapsto-u$ になるからである。従って合成は $n\mapsto-5n$ である。
:::

:::proposition[円周値写像のホモトピー分類]
二つの写像 $S^1\to S^1$ がホモトピックであるための必要十分条件は、標準ループと合成した巻き数が等しいことである。基点を保つ二写像については、同じ条件で基点付きホモトピーが存在する。
:::

:::proof
必要性は式 :eqref[eq-at-pi-one-moving-basepoint] と、円周の基本群の共役が自明なことによる。十分性を示すため、標準ループに沿った二つの角度の持ち上げを $u,v:I\to\R$ とする。仮定から $u(1)-u(0)=v(1)-v(0)=d$ である。$w_s=(1-s)u+sv$ でも同じ差 $d$ なので、$e^{2\pi i w_s(t)}$ は $t=0,1$ で一致する。従ってこの連続写像は $S^1\times I$ に降りてホモトピーになる。基点を保つ場合は $u(0)=v(0)=0$ と取れ、全ての $s$ で基点の像も $1$ のままである。
:::

:::example[回転を伴う冪写像]
$f(z)=iz^{-3}$ と $g(z)=z^{-3}$ は巻き数がともに $-3$ なので自由ホモトピックである。具体的には $H(z,t)=e^{i\pi(1-t)/2}z^{-3}$ で結べる。一方 $f(1)=i$、$g(1)=1$ なので同じ基点を固定したホモトピーにはできない。
:::

:::example[原点以外の点のまわりの巻き数]
閉曲線 $z(t)=2+3e^{2\pi it}$ の点 $a$ に関する巻き数を $(z(t)-a)/|z(t)-a|$ の巻き数と定める。$a=4$ では $-2s+3e^{2\pi it}$ が $0\le s\le1$ で零にならないため、この巻き数は $1$ である。$a=6$ では $-4+3se^{2\pi it}$ が零にならず、定値ループに縮むから $0$ である。境界上の $a=5$ では $t=0$ に正規化が定義できない。
:::

:::example[根の個数を巻き数にする]
$a$ を通らない円周では因子 $z-a$ の巻き数は $a$ が内部なら $1$、外部なら $0$ である。複数の非零因子の積を正規化すると、正規化した因子の積になる。連続な角度の持ち上げは足し算できるので、巻き数も足し算される。例えば $(z-1)^2(z+3)$ の $|z|=2$ 上の巻き数は $2+0=2$ である。根を重複度つきで数える理由は、同じ因子が現れる回数だけ角度の変化が加わることにある。
:::

### 円周の商と持ち上げの端点

:::proposition[円周値の写像に実数値の角度がある条件]
$h:S^1\to S^1$ が $h(z)=e^{2\pi i A(z)}$ を満たす連続な $A:S^1\to\R$ を持つ必要十分条件は、$h$ の巻き数が零であることである。存在するとき二つの $A$ の差は一定の整数である。
:::

:::proof
$h\circ p|_I$ の持ち上げ $a:I\to\R$ を取る。巻き数が零なら両端が一致するので $a$ は円周の商へ降り、$A$ を与える。逆に $A$ があれば $A\circ p|_I$ は両端が一致する持ち上げなので、巻き数は零である。二つの $A$ の差は各点で整数になり、円周が連結なので一点での差が全域で一定となる。
:::

:::example[振動を含む回転写像]
$h(e^{2\pi it})=e^{2\pi i(2t+3\sin2\pi t)}$ とする。振動の項は区間の両端で零なので巻き数は $2$ であり、円周全体では実数角度を選べない。他方 $z^{-2}h(z)$ では巻き数が零であり、$A(z)=3\Im z$ が角度である。値が何度も往復しても、各往復は持ち上げの終点差に寄与しない。従って同じ巻き数を持つ冪写像へ変形する式は、振動の係数 $3$ を時間とともに $0$ へ減らすだけでよい。
:::

:::example[角度が不連続でも値が連続な場合]
円周を $[0,1]/(0\sim1)$ で表し、$t\mapsto t$ の指数を取る。閉区間上では $t$ は連続角度であり、指数は両端で $1$ になる。ところが実数値の $t$ 自身は商へ降りない。両端の差が $1$ であることは、どのように局所逆を選んでも消せない。別の始点角度に替えると実数値の道全体に同じ整数が足されるためである。基点で角度を合わせただけでは、円周上の角度を一価に選んだことにはならない。
:::

:::example[逆向きに二周する曲線を閉円板に延ばせるか]
円周のループ $z\mapsto z^{-2}$ は $\C\setminus\{0\}$ に値を取る写像でもある。この値域を円周に正規化すると巻き数は $-2$ のままであり、円板に零を避けて延長すると巻き数が零になるはずなので延長できない。他方 $\C$ 値であれば $w\mapsto\bar w^2$ は同じ境界値を持つ延長である。原点を通ることが許されるため、円板上で巻き数の障害を回避できる。
:::

### 積分から読み取る巻き数

:::proposition[微分可能な閉曲線の巻き数]
$\gamma:I\to\C\setminus\{0\}$ を区分的に連続微分可能な閉曲線とする。このとき
$$
\operatorname{wind}(\gamma)=\frac{1}{2\pi i}\int_0^1\frac{\gamma'(t)}{\gamma(t)}\,dt
$$
である。左辺は $\gamma/|\gamma|$ の巻き数である。
:::

:::proof
非零の曲線を $\gamma(t)=r(t)e^{2\pi i a(t)}$ と書く。$r(t)=|\gamma(t)|$ は正であり、$a(t)$ は角度の持ち上げである。各小区間では微分可能な角度の枝を使え、そこでは $a$ とその枝は定数だけ異なるので、同じ微分を持つ。そのため微分して
$$
\frac{\gamma'}{\gamma}=\frac{r'}r+2\pi i a'
$$
となる。区分ごとに積分すると $\log r(1)-\log r(0)=0$ であり、角度の項は $2\pi i(a(1)-a(0))$ となる。分点では連続な持ち上げを使っているので、途中の角度がすべて相殺する。
:::

:::example[半径が変動しても巻き数は一定]
$\gamma(t)=(2+\cos 2\pi t)e^{-6\pi it}$ とする。半径は $1$ 以上で、微分の商の実部は $\frac{d}{dt}\log(2+\cos2\pi t)$ である。その積分は零になる。虚部の積分は $-6\pi$ なので、巻き数は $-3$ である。途中で半径が増減することは、最後の偏角の整数差を変えない。例えば半径を定数 $2$ へ線形に変えるホモトピーでも、途中に零ができず同じ結論を得る。
:::

:::example[楕円を円周へ動かす]
$\gamma(t)=3\cos2\pi t+i\sin2\pi t$ は原点を囲む楕円である。実部の係数を $3$ から $1$ へ連続に減らすと、どの時刻でも実部と虚部が同時に零になることはない。実部が零なら $\cos2\pi t=0$、そのとき虚部は $\pm1$ だからである。従って標準円周と同じ巻き数 $1$ を持つ。虚部を先に負にして作った楕円では標準円周の逆向きになり、巻き数は $-1$ になる。線形変換が原点のまわりの向きを保つかどうかを、この変形で直接区別できる。
:::

### 実数値の角度を空間全体で選ぶ

:::proposition[円周値写像と連続な角度の選択]
$X$ を道連結かつ局所道連結、$x_0\in X$ とする。$f:X\to S^1$ に $f(x)=e^{2\pi i a(x)}$ を満たす連続な $a:X\to\R$ が存在する必要十分条件は、$f_*:\pi_1(X,x_0)\to\pi_1(S^1,f(x_0))$ が自明であることである。存在するとき $a(x_0)$ を指定した解は一意である。
:::

:::proof
角度が存在すれば $f$ は実直線を経る。実直線では各ループを端点相対に線形に縮められるため、$f_*$ は自明である。逆に $f_*$ が自明とする。規格化した角度 $a(x_0)$ を選び、$x_0$ から各 $x$ への道 $\gamma$ に沿って $f\gamma$ の角度を持ち上げる。終点を $a(x)$ とする。二つの道を比べるには、片方の後にもう一方の逆をつなぐ。この像は基本群の仮定で巻き数零なので、角度の終点が同じである。従って $a$ は選んだ道に依存しない。

$f(x)$ を含む短い開弧を取り、その逆像の中で $x$ の道連結開近傍 $W$ を選ぶ。$W$ 内であれば $x_0$ から $x$ までの道に $W$ 内の道を足してよい。この最後の部分の角度は、短い開弧で選んだ局所逆に一定の整数を足したものとなる。従って $a$ は $W$ 上で連続であり、全点で同じことが言える。二つの角度の差は連続整数値だから、道連結な $X$ 上では一定であり、基点での指定があれば一意である。
:::

:::example[開いた円環で連続な対数を判断する]
$X=\{z:1<|z|<3\}$ とし、$f(z)=z^2e^{i\Re z}/|z|^2$ を取る。半径二の円を一周すると、$z^2/|z|^2$ の持ち上げは二回転し、$e^{i\Re z}$ の角度は初期と最後で同じ値に戻る。従って巻き数は $2$ であり、連続な角度はない。一方 $g(z)=|z|^3 e^{i\Re z}$ に対して、実部 $3\log |z|$、虚部 $\Re z$ を持つ複素対数が明示できる。同じ領域で絶対値が変わることは対数の存在を妨げない。障害は正規化した円周値写像が作る巻き数である。
:::

## 代数学の基本定理と 2 次元 Brouwer の不動点定理

:::theorem[代数学の基本定理]{#thm-at-fundamental-algebra}
次数 $n\ge1$ の複素多項式は少なくとも一つの複素零点を持つ。
:::

:::proof
$P(z)=a_nz^n+\sum_{k<n}a_kz^k$ とする。$R>1$ を $\sum_{k<n}|a_k|R^k<|a_n|R^n$ となるように取る。$|z|=R$ 上で $a_nz^n+s\sum_{k<n}a_kz^k$ は零にならない。従って絶対値で割って得る円周のループは巻き数 $n$ を持つ。ここでは始点の動きによる共役が $\Z$ で自明であることを使った。もし $P$ が零点を持たなければ、$P(rRe^{2\pi i t})/|P(rRe^{2\pi i t})|$ を用いて $r=1$ から $0$ へ動かし、巻き数を $0$ にできて矛盾する。
:::

:::theorem[円板の不動点]{#thm-at-brouwer-two}
任意の連続写像 $f:D^2\to D^2$ は不動点を持つ。
:::

:::proof
不動点がないと仮定し、$v=x-f(x)\ne0$ に沿って $x+\lambda v$ を外側へ延ばす。$\lambda\ge0$ で境界に達する最後の値は
$$
\lambda(x)=\frac{-x\cdot v+\sqrt{(x\cdot v)^2+\norm v^2(1-\norm x^2)}}{\norm v^2}.
$$
これは連続である。$\norm x=1$ なら $x\cdot v=1-x\cdot f(x)>0$ である。等号なら Cauchy–Schwarz の等号条件より $f(x)=x$ になってしまう。従って $\lambda=0$ であり、$x\mapsto x+\lambda(x)v$ は境界へのレトラクションを与える。円板の基本群は凸性で自明だが、円周の基本群は $\Z$ である。そのため誘導写像でレトラクションの等式を満たせない。
:::

:::example[大きな円周の見積もり]
$P(z)=z^4+2z+3$ に対して $R=2$ を取ると $16>7$ である。従って円周上の $P$ の巻き数は $4$ になる。さらに半径 $2$ の円板内に零点が一つもない場合は、この円板内だけで巻き数を $0$ に縮められるので矛盾する。
:::

:::proposition[比較による円板内の零点の計数]
複素多項式 $P,Q$ に対し、円周 $|z|=R$ 上で $|Q(z)|<|P(z)|$ とする。この円板の内部にある $P$ と $P+Q$ の零点の数は、重複度込みで等しい。
:::

:::proof
境界上で $|P+sQ|\ge |P|-s|Q|>0$ なので二つの正規化ループはホモトピックである。代数学の基本定理と因数分解によって、それぞれの多項式を一次因子に分ける。前節で示した通り、円内の因子は巻き数に $1$ を、円外の因子は $0$ を足す。境界に零点はなく、二つの巻き数が等しいため結論が従う。
:::

:::example[異なる半径で根を分ける]
$z^5-4z^2+1$ を $|z|=1$ で見ると、$|-4z^2|=4$ が $|z^5+1|\le2$ より大きい。従って単位円内には二根ある。一方 $|z|=2$ では $|z^5|=32$ が $|-4z^2+1|\le17$ より大きいので五根が半径 $2$ の内側にある。二境界に根がないため、間の円環には三根ある。
:::

:::example[摂動が小さいと根の個数が変わらない]
$P(z)=(z-1)^2$ と $Q(z)=z/4$ を取り、中心 $1$、半径 $1$ の円周を使う。境界上の $|P|=1$ に対し $|Q|\le (1+1)/4=1/2$ である。中心を平行移動して比較の定理を使うと、$P+Q$ の二根はともにこの円板内にある。一方 $|z|=1$ の円周では $P$ が $z=1$ で零になるので、同じ比較はできない。境界上の不等式が成立する領域を選ぶことが、根の位置を制約する手順の一部である。
:::

:::example[境界の射影方向から不動点を探す]
$D^2$ の自己写像 $f(x,y)=(-y/2,x/2)$ を考える。これは長さを半分にするので値域は円板内である。方程式 $x=-y/2,\ y=x/2$ に代入すると $(5/4)x=0$ となり、不動点は原点一つである。もし全空間で $f(x)\ne x$ なら $x-f(x)$ の方向を使って境界へのレトラクションが得られるが、この例ではちょうど原点で方向が定義できない。境界上では $x-f(x)$ が外向き成分を持つため、境界点のレトラクションの値はそもそも元の点と一致する。内部での零点がこの延長を妨げている。
:::

:::example[円板の境界条件から零点の存在を示す]
連続な $F:\overline{D(0,2)}\to\C$ が境界上で $|F(z)-z|<2$ を満たすとする。境界では $z+s(F(z)-z)$ は絶対値が少なくとも $2-s|F(z)-z|>0$ である。従って $F$ の境界の巻き数は $1$ である。もし内部にも零がなければ、半径を減らすホモトピーで境界を定値にできるので矛盾する。例えば $F(z)=z+\bar z^2/16-1/2$ は境界上で $|F(z)-z|\le4/16+1/2=3/4<2$ を満たし、少なくとも一つの零点がある。多項式の根の数と違い、この手順で保証されるのは連続な $F$ の零点の存在である。本例では零点が孤立するかどうかを使っていない。
:::

:::example[円板内で値を押し戻す不動点の計算]
円板上の写像に含まれる外向きの線分を使う不動点の証明では、境界点で最後の交点が出発点になる。例えば固定点を仮定する前の式を、定値写像 $f(x)=(1/2,0)$ の点 $x=(0,0)$ で評価する。方向 $v=(-1/2,0)$ なので $\lambda=2$ となり、境界点は $(-1,0)$ である。ところが $x=(1/2,0)$ では方向が零なのでこの連続な式は定義できない。他方 $x=(1,0)$ では $x\cdot v=1/2>0$ で平方根とその前の項が打ち消し合い、$\lambda=0$ となる。これがレトラクションで境界を固定する計算である。
:::

:::example[根を含まない領域から係数への制約を得る]
$P(z)=2z^6-3z^2+1$ を考える。$|z|=1/2$ では $|2z^6-3z^2|\le1/32+3/4=25/32<1$ なので、定数項との比較によりこの円板に根はない。一方 $|z|=2$ では $|2z^6|=128$ に対して $|-3z^2+1|\le13$ である。従って半径二の円板には六根すべてが入る。この二つの境界には零点がないから、全根はその間の開円環に入る。係数を小さく変えても二つの厳密な不等式が保たれる範囲では同じ結論になる。多項式を因数分解せず、異なる半径で支配的な項を選ぶだけで位置を制約できる。
:::

## 2 次元 Borsuk–Ulam の定理

:::lemma[円周上の奇写像]{#lem-at-odd-circle}
$g:S^1\to S^1$ が $g(-z)=-g(z)$ を満たすなら、$g\circ p|_I$ の巻き数は奇数である。
:::

:::proof
このループの持ち上げを $a(t)$ とする。$a(t+1/2)-a(t)$ は $0\le t\le1/2$ で $1/2+\Z$ に属し、連続ゆえ一定である。$t=0$ と $1/2$ で同じ値を足すと $a(1)-a(0)=1+2k$ となる。
:::

:::theorem[二次元 Borsuk–Ulam]{#thm-at-borsuk-ulam-two}
$f:S^2\to\R^2$ が連続なら、$f(x)=f(-x)$ となる $x$ が存在する。
:::

:::proof
そのような点がなければ $g(x)=(f(x)-f(-x))/\norm{f(x)-f(-x)}$ は $S^2\to S^1$ の奇写像である。赤道上の制限は :ref[lem-at-odd-circle] により奇数の巻き数を持つ。一方、北半球への延長が既にあるため円板を縮めると巻き数は $0$ になる。これは矛盾である。
:::

:::example[二つの観測値]
球面上の連続実数値関数 $u,v$ に対して、$f=(u,v)$ とすると $u(x)=u(-x)$ と $v(x)=v(-x)$ を同時に満たす点がある。例えば $u(x,y,z)=x$、$v(x,y,z)=y$ では二つの極が条件を満たす。
:::

:::example[偶関数を一成分に含む場合]
$f:S^2\to\R^2$ を $f(x,y,z)=(x^2+2y^2,z+x)$ とする。第一成分は対蹠点で等しい。第二成分は奇関数なので $f(x,y,z)=f(-x,-y,-z)$ は $z+x=0$ と同値になる。従って解集合は原点を通る平面と球面の交わりであり、例えば $(1/\sqrt2,0,-1/\sqrt2)$ とその反対点が解になる。一般の連続写像では解集合が大円になるとは限らない。射影 $(x,y,z)\mapsto(x,y)$ の解集合が二極だけであることと比較できる。
:::

:::example[奇写像の非存在と目標次元]
$S^2\to S^1$ の奇写像が存在すれば、$S^1\subset\R^2$ への写像として Borsuk–Ulam の結論を満たす。奇性からその点で $g(x)=-g(x)$ となるので $g(x)=0$ が必要になり、円周に入ることに反する。他方、目標を $\R^3$ に替えると包含写像 $x\mapsto x$ には等値を取る対蹠点が存在しない。従って結論の成立には目標の次元が関与している。
:::

:::example[円周での Borsuk–Ulam の直観]
任意の連続 $u:S^1\to\R$ で $v(z)=u(z)-u(-z)$ と置く。$v(-z)=-v(z)$ なので、$v(z)=0$ でなければ半円の両端で符号が異なる。中間値の定理でその半円内に零点がある。例えば $u(e^{it})=\cos t+2\cos2t$ では偶数倍の周波数の項が差から消え、$v=2\cos t$ なので $i,-i$ が解である。二次元の場合には実数の符号をそのまま使えないため、差の向きを円周へ正規化し、奇写像の巻き数で同じ矛盾を作る。
:::

:::example[高さと別の連続量を同時に揃える]
$f:S^2\to\R^2$ を $f(x,y,z)=(z,x+y+2z)$ とする。両成分とも奇関数なので、$f(x)=f(-x)$ は $z=0$、$x+y=0$ と同値である。球面との交わりは $(1/\sqrt2,-1/\sqrt2,0)$ とその反対点の二点である。例えば第二成分に $x^2$ を加えてもその偶関数項は反対点の間の差で消え、解は同じである。一般にはこのように奇部分の零点を直接解けないが、差の正規化を使う証明は、二成分の値が揃う少なくとも一つの反対点の組を保証する。
:::

:::example[対蹠点で方向と長さを同時に揃える]
連続写像 $f:S^2\to S^1\times(0,\infty)$ を考える。$(z,r)\mapsto rz$ は平面の原点を除いた部分への同相であり、逆は $(w/|w|,|w|)$ である。従って合成に二次元 Borsuk–Ulam を適用すると、方向 $z$ と正の長さ $r$ がともに一致する反対点がある。例えば $f(x,y,z)=(e^{i\pi x/2},2+y)$ なら、第一成分の等値条件は $e^{i\pi x}=1$ であり $|x|\le1$ なので $x=0$ である。第二成分は $y=0$ を要求する。従って二極が解となる。片方の量が実数でなく円周値であっても、値域を平面へ同相に移せる場合はこのように判定できる。
:::

:::example[円周の奇写像の巻き数を指定する]
任意の奇数 $d$ に対して $z\mapsto z^d$ は奇写像で、巻き数は $d$ である。さらに同じ巻き数を持つ二つの奇写像を $g_0,g_1$ とすると、その商 $h=g_1/g_0$ は $h(-z)=h(z)$ を満たす。従って $h(z)=k(z^2)$ と書ける。$h$ の巻き数は差を取って零であり、二乗写像との合成で巻き数は二倍になるから、$k$ の巻き数も零である。連続な実数角度 $A$ を $k=e^{2\pi i A}$ と取ると、$g_0(z)e^{2\pi i t A(z^2)}$ は全時刻で奇写像であり、$g_0$ と $g_1$ を結ぶ。従って円周では奇写像だけを通る変形でも、巻き数で類を完全に区別できる。
:::

## 積空間の基本群とホモトピー不変性

:::theorem[積の基本群]{#thm-at-pi-one-product}
$\pi_1(X\times Y,(x,y))\cong\pi_1(X,x)\times\pi_1(Y,y)$ である。
:::

:::proof
二つの射影の誘導準同型を組にする。逆は $([\alpha],[\beta])\mapsto[t\mapsto(\alpha(t),\beta(t))]$ である。二つの端点相対ホモトピーの積も端点相対であるため逆は代表に依存せず、二つの射影を逆候補の前後で合成し、成分ごとに比較すれば互いに逆である。
:::

:::corollary[ホモトピー不変性]{#cor-at-pi-one-invariance}
ホモトピー同値 $f:X\to Y$ に対して $f_*:\pi_1(X,x)\to\pi_1(Y,f(x))$ は同型である。
:::

:::proof
ホモトピー逆を $g$ とする。式 :eqref[eq-at-pi-one-moving-basepoint] で $gf\simeq\id_X$ を比較すると $g_*f_*$ は基点変更の同型であり、$f_*$ は単射である。$fg\simeq\id_Y$ を比較すると $f_*$ の基点 $gf(x)$ における版は全射である。$x$ と $gf(x)$ を結ぶ $gf\simeq\id$ の軌跡を使うと、その版と元の $f_*$ は両側の基点変更で共役する。これは $\tau_\gamma$ の式に $f$ を適用すれば従う。従って元の $f_*$ も全射である。
:::

:::example[トーラスと穴あき平面]
$T^2$ のループ $(e^{4\pi i t},e^{-6\pi i t})$ は $(2,-3)\in\Z^2$ を表す。$\R^2\setminus\{0\}$ は円周に変位レトラクトするので基本群は $\Z$ である。この二つの群は $\Z/2$ への準同型の個数がそれぞれ $4$ と $2$ で異なり、空間はホモトピー同値でない。
:::

:::example[トーラスの整数行列写像]
$f(z,w)=(z^2w^{-1},zw^3)$ が $T^2$ の基本群に誘導する写像を求める。ループの二成分の連続な角度を $u(t),v(t)$ と取ると、合成の二成分は $2u-v,u+3v$ を角度に持つ。従って巻き数の列 $(m,n)$ は $(2m-n,m+3n)$ に移る。この写像は行列式 $7$ を持ち、整数上で単射である。$(1,0)$ の逆像を解くと $(3/7,-1/7)$ なので全射ではない。従って $f$ はホモトピー同値ではない。
:::

:::example[円筒の二境界の包含]
$S^1\times[0,1]$ の二境界を $j_i(z)=(z,i)$ で含めると、$H(z,s)=(z,s)$ が両包含のホモトピーである。基点間の道 $\eta(s)=(1,s)$ による補正を含めると、二つの写像は同じ生成元を運ぶ。一方、上境界のパラメータを $z\mapsto(\bar z,1)$ と選ぶと、第一射影との合成の巻き数は $-1$ である。この差は基点を変えても消えない。従って両境界が同じホモトピー型を持つことと、各パラメータ付き包含のホモトピー類が一致することは別の条件である。
:::

:::example[トーラスの自己同相を整数行列で作る]
$A=\begin{pmatrix}2&1\\1&1\end{pmatrix}$ の行列式は $1$ であり、$A^{-1}=\begin{pmatrix}1&-1\\-1&2\end{pmatrix}$ は整数行列である。従って $\R^2/\Z^2$ で $[v]\mapsto[Av]$ を定めると、$[w]\mapsto[A^{-1}w]$ が連続な逆である。基本群では $A$ がそのまま作用する。例えば $(3,-2)$ は $(4,1)$ に移り、逆行列で元へ戻る。これに対し行列式が $2$ の整数行列も連続なトーラス写像を誘導するが、像部分群の指数は二であり、ホモトピー同値にはならない。
:::

### 行列の空間での変位レトラクト

:::example[正の行列式を持つ二次行列の基本群]
$A\in\GL(2,\R)$ が $\det A>0$ を満たすとする。列に Gram–Schmidt 法を施し、$A=QR$ と分ける。ただし $Q$ は回転行列、$R$ は対角成分がともに正の上三角行列である。実際、第一列の正規化で最初の単位ベクトルが決まり、第二列からその方向への射影を引いて正規化すれば二番目が決まる。分母は両列の独立性で消えないため $Q,R$ は $A$ に連続に依存する。$H(A,t)=Q((1-t)R+t I)$ とすると、対角成分は各時刻で正なので $H(A,t)$ は同じ空間に属する。$A=Q$ がすでに回転なら $R=I$ であり、全時間で固定される。従ってこの空間は $SO(2)\cong S^1$ に変位レトラクトし、基本群は $\Z$ である。

例えば $A=\begin{pmatrix}0&-2\\3&1\end{pmatrix}$ では $Q=\begin{pmatrix}0&-1\\1&0\end{pmatrix}$、$R=\begin{pmatrix}3&1\\0&2\end{pmatrix}$ である。時刻 $1/2$ で右側の因子は $\begin{pmatrix}2&1/2\\0&3/2\end{pmatrix}$ となり、行列式は $3$ である。最終値は $Q$ である。この変形では列のせん断と伸縮を取り除いた後に回転だけが残る。負の行列式の成分も固定した反射を左から掛けると正の成分に移るため同相である。
:::

:::example[積の基本群で写像を合成する]
$f(z,w)=(z^2w,z^{-1}w)$ と $g(z,w)=(z^3,w^2)$ を取る。基本群の行列は $A=\begin{pmatrix}2&1\\-1&1\end{pmatrix}$ と $B=\diag(3,2)$ であり、$g\circ f$ では $BA=\begin{pmatrix}6&3\\-2&2\end{pmatrix}$ になる。実際に写像を合成すると $(z^6w^3,z^{-2}w^2)$ であり、各指数からも同じ行列が出る。一方 $f\circ g$ の第一成分は $z^6w^2$ である。基本群自身は可換だが、二つの自己写像が誘導する準同型は互いに交換するとは限らない。順序は写像の合成と同じである。
:::

### トーラスの間の写像を整数行列で分類する

:::proposition[トーラス写像のホモトピー分類]
$T^r=(S^1)^r$ から $T^s$ への自由ホモトピー類は、基本群に誘導する整数 $s\times r$ 行列で一意に決まる。すべての行列が実現される。基点を各成分 $1$ に取り、基点付き写像の類を考えても同じ分類になる。
:::

:::proof
第一に $f:T^r\to S^1$ を考える。各座標円周の巻き数を $a_1,\ldots,a_r$ とし、$g(z_1,\ldots,z_r)=\prod_j z_j^{a_j}$ を作る。両写像の商 $f/g$ では各座標円周の巻き数が零である。これは角度の積で巻き数が加法的であるためである。積の基本群は座標円周の類で生成されるので、$f/g$ の誘導準同型は自明である。従って連続角度 $u:T^r\to\R$ があり、$f=g e^{2\pi i u}$ と書ける。$u$ の係数を連続に $0$ へ動かすと $f$ から $g$ へのホモトピーが得られる。基点付きなら $u(1,\ldots,1)=0$ を指定でき、全時刻で基点の像は $1$ である。

逆にホモトピックな写像は基本群で同じ準同型を与える。基点が動く場合にも円周の群の共役は自明であるため、基点を固定した場合と同じ巻き数になる。値域が $T^s$ であれば各座標について独立にこの手順を使い、上の式を同時に動かす。これで行列に対応する冪の積の写像を得る。任意の行列の各行から同じ式を作れるため、どの行列でも実現できる。
:::

:::example[像が一本の円周に縮むトーラス写像]
$f(z,w)=(z^2w^4,z^3w^6)$ を取る。誘導行列の第二列は第一列の二倍である。写像は $q(z,w)=zw^2$ と $j(u)=(u^2,u^3)$ の合成であり、$q_*$ は $(m,n)\mapsto m+2n$、$j_*$ は $k\mapsto(2k,3k)$ である。従って核は $(-2,1)$ の張る $\Z$、像は $(2,3)$ の張る $\Z$ となる。例えば第一成分に $e^{i\Re w}$ を掛けても、足した角度は実数値に選べて巻き数を変えないので同じ写像類である。元の写像の像は実際に一円周に入るが、摂動した写像の像が同じ集合に入る必要はない。ホモトピー類を計算するのは巻き数の行列である。
:::

## 演習問題

::::exercise{level=basic}
同じ端点を持つ道 $\alpha,\beta:I\to\R^n$ を端点相対で結べ。
:::solution
$H(t,s)=(1-s)\alpha(t)+s\beta(t)$ とすれば両端における二つの値が一致するので端点を固定する。
:::
::::

::::exercise{level=basic}
$\gamma:x\to y$ と $\beta$ を $y$ のループとする。$\tau_\gamma([\beta]^2)$ を書け。
:::solution
$\gamma*(\beta*\beta)*\bar\gamma$ の類である。積の中央の $\bar\gamma*\gamma$ が消えるので $[\gamma*\beta*\bar\gamma]^2$ と等しい。
:::
::::

::::exercise{level=basic}
$t\mapsto e^{2\pi i(3t+\sin(2\pi t))}$ の巻き数を求めよ。
:::solution
持ち上げは $3t+\sin(2\pi t)$ である。終点 $3$ から始点 $0$ を引くので巻き数は $3$ である。
:::
::::

::::exercise{level=basic}
$z\mapsto z^{-4}$ が巻き数 $3$ のループを送る先の巻き数を求めよ。
:::solution
持ち上げに $-4$ を掛ける。従って巻き数は $-4\cdot3=-12$ である。
:::
::::

::::exercise{level=advanced}
$z^3+z+1$ が $|z|<2$ に零点を持つことを巻き数で示せ。
:::solution
半径 $2$ では $|z^3|=8>|z+1|$ である。低次項を消すホモトピーから境界像の巻き数は $3$ である。円板内で零点がなければ円板で正規化でき巻き数は $0$ になる。
:::
::::

::::exercise{level=advanced}
連続写像 $g:D^2\to S^1$ は境界で $g(-z)=-g(z)$ を満たせるか。
:::solution
境界の巻き数は円板への延長から $0$ である。一方、奇写像の持ち上げでは半回転の角度差が半整数となり全周の巻き数は奇数である。従って満たせない。
:::
::::

::::exercise{level=advanced}
写像 $F:T^2\to T^2$、$F(z,w)=(z^2w,z^{-1}w^3)$ の誘導写像を求めよ。
:::solution
持ち上げの成分を $u,v$ とすると像の持ち上げは $(2u+v,-u+3v)$ である。よって $(m,n)\mapsto(2m+n,-m+3n)$ である。例えば $(2,-1)$ は $(3,-5)$ へ移る。
:::
::::

::::exercise{level=advanced}
円周の写像 $z\mapsto z^2$ はホモトピー同値であるか。
:::solution
基本群で $n\mapsto2n$ を誘導する。この写像は $1$ を像に持たず、ホモトピー同値の誘導写像が同型になることと両立しない。
:::
::::

::::exercise{level=advanced}
$\C\setminus\{0\}$ の二つの道
$$
\alpha(t)=(2+t)e^{2\pi i(1/4+2)t},\qquad
\beta(t)=(2+t^2)e^{2\pi i((1/4-1)t+2\sin 2\pi t)}
$$
が端点相対でホモトピックか調べよ。さらに $\alpha*\bar\beta$ の巻き数を求めよ。

:::solution
両道は時刻零で $2$、時刻一で $3i$ である。絶対値は全時刻で正なので、書かれた指数の変数をそれぞれ連続角度とみなせる。始点の角度は両方で零であり、$\alpha$ の終点の角度は $9/4$、$\beta$ は $\sin(2\pi)=0$ なので $-3/4$ である。差は $9/4-(-3/4)=3$ である。端点相対ホモトピーで終点角度は変わらないため、両道はそのようなホモトピーでは結べない。

$\bar\beta$ の持ち上げを $\alpha$ の終点角度 $9/4$ から始めるには、$\beta$ の角度を逆向きにしたものに $3$ を足せばよい。この後半の終点は $\beta$ の始点角度 $0$ に $3$ を足した値である。従って閉じた連結の巻き数は $3$ となる。振動の項が連続角度の途中の値を大きく変えても、両端の差には寄与しない。
:::
::::

::::exercise{level=advanced}
$T^2$ の写像 $f(z,w)=(z^2w,z^5w^2)$ について、基本群の行列を求めてホモトピー同値か判定せよ。さらにこの写像の逆を円周座標で一つ書け。

:::solution
ループの巻き数を $(m,n)$ とすると、第一成分の巻き数は $2m+n$、第二成分は $5m+2n$ である。従って行列は $A=\begin{pmatrix}2&1\\5&2\end{pmatrix}$ で、行列式は $4-5=-1$ である。よって整数の逆行列
$$
A^{-1}=\begin{pmatrix}-2&1\\5&-2\end{pmatrix}
$$
を持つ。この行列に対応する写像は $g(u,v)=(u^{-2}v,u^5v^{-2})$ である。

指数が行列の積に従うので $gf$ と $fg$ の行列は恒等である。この二写像はどちらも指数だけの写像であり、指数が恒等行列なら各成分は対応する座標そのものである。実際、$f$ の二成分を $g$ に代入すると第一成分は $z^{-4}w^{-2}z^5w^2=z$、第二成分は $z^{10}w^5z^{-10}w^{-4}=w$ である。よって $f$ はホモトピー同値であるだけでなく、この代表では同相である。例えば同じ行列を保つ位相の摂動をかけた写像について、行列の分類からはホモトピー同値まで保証される。
:::
::::

::::exercise{level=advanced}
$P(z)=z^4-5z^2+1$ が $|z|<1$ と $|z|<3$ に持つ零点の数を、重複度を含めて求めよ。各境界に零点がないことも示せ。
:::solution
半径一では $|-5z^2|=5$、残りは $|z^4+1|\le2$ である。従って $-5z^2+s(z^4+1)$、$0\le s\le1$ は境界で零を避ける。$-5$ の因子は一定の回転と正の拡大なので、端の $-5z^2$ の巻き数は $2$ である。よって $P$ の半径一の巻き数は $2$ になる。

半径三では $|z^4|=81$、残りは $|-5z^2+1|\le46$ である。今度は $z^4+s(-5z^2+1)$ を取ると巻き数が $4$ と分かる。どちらの場合も見積もりは狭義なので、$s=1$ すなわち $P$ に境界の根はない。各一次因子 $z-a$ の巻き数は $|a|<r$ なら $1$、$|a|>r$ なら $0$ である。前者は定数項を零へ、後者は $z$ の項を零へ縮めても境界では消えないためである。因子分解して巻き数を足せば、内側にそれぞれ $2,4$ 個、従って $1<|z|<3$ に二個となる。確かめとして $z^2=(5\pm\sqrt{21})/2$ であり、負号側は $0<z^2<1$、正号側は $1<z^2<9$ となる。
:::

::::exercise{level=advanced}
$X=\C\setminus\{-1,1\}$ で $z(t)=2e^{2\pi it}$ とする。$a=-1,1,3$ のそれぞれに対する $z-a$ の巻き数と、ループ $P(z(t))=(z(t)-1)^2(z(t)+1)^{-3}$ の原点に対する巻き数を求めよ。$z(t)$ 自体が $X$ で定値へ縮むかも答えよ。
:::solution
$a=-1,1$ では $|a|=1<2$ なので、$2e^{2\pi it}-sa$ の長さは逆三角不等式により $2-s|a|$ 以上であり、従って $1$ 以上である。従って両方の巻き数は $1$ になる。この整数は円周の半径を変えても、途中で穴を通らない限り保たれる。$a=3$ では $2se^{2\pi it}-3$ が常に長さ $1$ 以上で、$s=0$ の定値へ動かせる。従って巻き数は $0$ である。

複素数の積をすると角度の持ち上げを足すことができ、逆数ではその符号が反転する。従って $P(z(t))$ の巻き数は $2\cdot1-3\cdot1=-1$ である。$z\mapsto(z-1)/|z-1|$ は $X$ の全体で連続なので、もし $z(t)$ が $X$ で定値に縮めば、この写像で送った巻き数も零になるはずである。ところがその巻き数は $1$ なので縮まない。二つの穴を区別するには各穴を引いた別々の写像を用いることができ、一つの合成の巻き数から二値を復元する必要はない。
:::

::::exercise{level=advanced}
$T^2=\R^2/\Z^2$ とし、$\Theta(x,y)=(2x+y+\tfrac18\sin 2\pi y,\ x+y+\tfrac14\sin 2\pi x)$ と置く。これがトーラスの連続写像を定めることを確認し、基本群への作用と、ホモトピー逆写像となる整数行列写像を求めよ。
:::solution
$(x,y)$ に整数ベクトル $v$ を加えても正弦の値は変わらない。従って $\Theta((x,y)+v)-\Theta(x,y)=Av$、$A=\begin{pmatrix}2&1\\1&1\end{pmatrix}$ であり差は整数ベクトルだから商で値が定まる。正弦にだけ係数 $s\in[0,1]$ を掛けても同じ等式が成り立つ。原点を固定したまま $s=1$ から $s=0$ に動かすと、元の連続写像は線形な $A$ の写像とホモトピックになる。

二つの座標の生成ループは、それぞれ持ち上げの終点が $A(1,0)=(2,1)$、$A(0,1)=(1,1)$ である。従って基本群 $\Z^2$ への作用は $A$ である。$\det A=1$ なので $A^{-1}=\begin{pmatrix}1&-1\\-1&2\end{pmatrix}$ も整数行列であり、商上で逆の線形写像を作れる。この線形写像を $\Theta$ が誘導する写像と両順序で合成すれば、先のホモトピーで恒等写像に至る。この論証によりホモトピー逆は得られるが、正弦を含む元の式が全単射かどうかは論証に使っていない。
:::

::::exercise{level=basic}
平面の頂点 $1,i,-1,-i$ をこの順に結んで閉じる折れ線を $\gamma$ とする。原点と点 $2$ に対する巻き数を求めよ。さらに、最初の辺だけをその辺に沿った往復と元の辺との連結に置き換えたとき、巻き数が変わるか答えよ。
:::solution
原点について最初の辺は $z(s)=1-s+is$ であり、偏角を $0$ から $\pi/2$ まで連続に取れる。各次の辺はこれを $i$ 倍した辺なので、貼り合わせた持ち上げの終値は $2\pi$ になる。巻き数は $1$ である。点 $2$ については、すべての辺で $\Re(\gamma(t)-2)\le-1$ である。左半平面に偏角を一価に取れるので初値と終値は同じになり、巻き数は零である。挿入する往復の偏角変化は、進む辺を戻ると同じ持ち上げを逆にたどるため零である。従ってどちらの巻き数も変わらない。
:::
