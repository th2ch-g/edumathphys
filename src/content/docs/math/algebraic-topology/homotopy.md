## この章の目標

- 写像のホモトピーと空間のホモトピー同値を区別し、具体式で与える。
- 球面、トーラス、射影平面を胞体の接着として記述する。
- CW 対のホモトピー拡張性質を証明し、可縮な部分複体を潰す。
- 写像柱と写像錐を構成し、基点付きの場合の違いを理解する。

積空間と商空間の位相は :ref[thm-top-product-property] と :ref[thm-top-quotient-property] に従う。写像は連続であるとする。$I=[0,1]$ を時間の範囲として用いる。

## ホモトピーとホモトピー同値

写像を連続的に動かすと、各点は道を描く。点ごとの道を任意に選ぶと近い点が突然離れることがあるので、点と時刻の両方に関する連続性を課す。

:::definition[ホモトピー]{#def-at-homotopy}
写像 $f,g:X\to Y$ に対して $H:X\times I\to Y$ が $H(x,0)=f(x)$、$H(x,1)=g(x)$ を満たすとき、$H$ を $f$ から $g$ への :term[ホモトピー]{en="homotopy" yomi="ほもとぴー"} と呼び、$f\simeq g$ と記す。$A\subset X$ 上でさらに全時刻に $H(a,t)=f(a)=g(a)$ なら $A$ に相対的という。
:::

:::proposition[ホモトピーの演算]{#prop-at-homotopy-laws}
$\simeq$ は同値関係であり、前合成と後合成で保たれる。
:::

:::proof
定値の時間変化が反射律、$H(x,1-t)$ が対称律を与える。$H:f\simeq g$ と $K:g\simeq h$ をつなぐには前半で $H(x,2t)$、後半で $K(x,2t-1)$ とする。$t=1/2$ で両式は $g$ に一致するので :ref[lem-top-pasting] により連続である。$a:W\to X$ と $b:Y\to Z$ に対して $bH(a(w),t)$ は $bfa\simeq bga$ である。相対条件も、合成後に固定される部分上で保たれる。
:::

:::definition[ホモトピー同値]{#def-at-homotopy-equivalence}
$f:X\to Y$ に対し $gf\simeq\id_X$、$fg\simeq\id_Y$ となる $g:Y\to X$ が存在すれば $f$ を :term[ホモトピー同値]{en="homotopy equivalence" yomi="ほもとぴーどうち"} という。このとき $g$ をホモトピー逆と呼び、空間についても $X\simeq Y$ と書く。
:::

二つの逆 $g,g'$ があれば $g\simeq g(fg')=(gf)g'\simeq g'$ である。合成に関する性質から、空間のホモトピー同値も同値関係になる。

:::example[凸な値域への写像]
$Y$ が実位相ベクトル空間の凸部分集合なら $H(x,t)=(1-t)f(x)+tg(x)$ がホモトピーである。$X=I$、$Y=\R^2$、$f(x)=(x,2x)$、$g(x)=(2x,0)$ なら $H(1/2,1/4)=(5/8,3/4)$ である。値域から原点を除くと、$f=1$ と $g=-1$ をこの式で結ぶことはできない。$\C\setminus\{0\}$ では $e^{\pi i t}$ が代わりになる。
:::

:::example[離散空間]
離散空間 $Y$ へのホモトピーでは各 $t\mapsto H(x,t)$ が一定である。区間 $I$ の連結性による。したがって、離散空間同士のホモトピー同値は互いに逆な全単射を与える。二点を持つ離散空間を一点に縮めることもできない。
:::

:::proposition[対のホモトピー同値]
写像 $f:(X,A)\to(Y,B)$ と $g:(Y,B)\to(X,A)$ があり、$gf\simeq\id_X$ の全時刻で $A$ の像が $A$ に、$fg\simeq\id_Y$ の全時刻で $B$ の像が $B$ に入るとする。このとき制限 $f|_A$、商に誘導される写像 $\bar f:X/A\to Y/B$ もホモトピー同値である。ただし商を取る場合は $A,B$ は空でないとする。
:::

:::proof
制限の逆とホモトピーは $g$ と与えられたホモトピーをそれぞれ部分空間へ制限して得る。各時刻で、$A$ の全体が商 $X/A$ で同じ点へ送られる。従って $X\times I\to X/A$ のホモトピーは商の積 $(X/A)\times I$ に降りる。ここで商写像と区間の積が商写像であることを使う。この性質は本章の CW 対の拡張性質の証明で示す。$Y$ でも同様なので、$\bar g$ が $\bar f$ のホモトピー逆である。
:::

例えば $(I,\{0,1\})$ と $(\{0\},\{0\})$ の全空間はホモトピー同値である。対のホモトピー同値があれば二端点の空間も一点と同値になるが、離散空間の例で見たようにこれは成立しない。

### 変形を連続写像として組み立てる

:::proposition[道成分とホモトピー]
$f,g:X\to Y$ がホモトピックなら、道成分の集合 $\pi_0(X)\to\pi_0(Y)$ に誘導する写像は一致する。従ってホモトピー同値は道成分の集合の全単射を誘導し、対応する道成分の制限もホモトピー同値である。
:::

:::proof
$X$ の道は $f$ と合成して $Y$ の道になるので、道成分から道成分への写像が定まる。各 $x$ について $H(x,t)$ は $f(x)$ と $g(x)$ を結ぶので二つの写像は等しい。ホモトピー逆 $h$ があれば、$\pi_0(h)$ は集合上で逆になる。道成分 $P$ 上の $hf\simeq\id$ の像は常に $P$ に入る。実際、各 $x\in P$ に対して時刻の道が $x$ に至る。値域を部分空間 $P$ に制限すれば連続であり、もう一方の合成にも同じ議論を用いる。
:::

:::example[穴の個数と道成分]
$[-2,2]\setminus\{-1,1\}$ は三つの区間を持つ。それぞれ $-2,0,2$ へ線形に縮めると、三点空間とのホモトピー同値を得る。三区間は相対位相で開なので、区間ごとの式は連続である。一方、$\R^2\setminus\{(-1,0),(1,0)\}$ は道連結である。任意の二点 $x,y$ に対し、除去した点と $x$ または $y$ を通る高々四本の直線の外に点 $z$ を取れば、線分 $[x,z]$ と $[z,y]$ は除去点を通らない。そのため両空間はホモトピー同値でない。
:::

:::proposition[積のホモトピー同値]
$f:X\to Y$ と $f':X'\to Y'$ がホモトピー同値なら、$f\times f'$ もホモトピー同値である。相対ホモトピーで固定した部分集合が $A\subset X$ と $A'\subset X'$ なら、積のホモトピーは $A\times A'$ 上で一定である。
:::

:::proof
逆候補を $g\times g'$ とする。一方の合成を恒等写像へ移すには、$gf$ のホモトピー $H$ と $g'f'$ のホモトピー $H'$ を同時に進め、$((x,x'),t)\mapsto(H(x,t),H'(x',t))$ と置く。座標射影と積の普遍性から連続である。もう一方の合成も、値域側の二つのホモトピーを同じ式に入れればよい。固定集合の各点については座標ごとに時刻に依存しない。
:::

:::example[円環の積とトーラス]
$A=\{x\in\R^2:1<\norm{x}<4\}$ を半径 $2$ の円に縮めるとき、点 $x$ の半径は $(1-t)\norm{x}+2t$ と動く。両端が $(1,4)$ 内であるから途中も同区間に入る。$A\times A$ で各円への変形を同時に行うとトーラスへの変位レトラクションになる。例えば半径が $3$ と $3/2$ の組は、$t=1/2$ で半径 $5/2$ と $7/4$ に移る。二つの偏角はともに一定である。
:::

:::example[同相を要しない逆写像]
$\R$ から $[0,1]$ への定値写像 $f(x)=1/2$ と逆候補 $g(y)=0$ を取る。$gf$ から $\id_{\R}$ へは $H(x,t)=tx$、$fg$ から $\id_{[0,1]}$ へは $K(y,t)=(1-t)/2+ty$ で動ける。従って二空間はホモトピー同値である。$[0,1]$ はコンパクトで $\R$ は開被覆 $(-n,n)$ に有限部分被覆がないので、同相ではない。ホモトピー同値から局所的な形やコンパクト性を復元することはできない。
:::

### ホモトピー類を合成する

前後の合成によってホモトピーが保たれるので、連続写像そのものを使う代わりに、そのホモトピー類を写像として扱える。空間を対象とし、$X$ から $Y$ への射を $[X,Y]$ とする圏を :term[ホモトピー圏]{en="homotopy category" yomi="ほもとぴーけん"} という。合成は $[g][f]=[gf]$ であり、恒等射は $[\id_X]$ である。例えば二つの代表を同時に変えても、先に前側の代表、次に後側の代表を変形すれば合成のホモトピー類は変わらない。このため式は代表の選択とは独立である。

:::proposition[逆を合成で検査する]
$f:X\to Y$ について、任意の空間 $W$ に対し前から $f$ を掛ける写像 $[W,X]\to[W,Y]$ が全単射なら、$f$ はホモトピー同値である。逆に $f$ がホモトピー同値なら、この写像も、後ろから $f$ を掛ける写像 $[Y,W]\to[X,W]$ も全単射である。
:::

:::proof
$W=Y$ として全射性を用いると、$[\id_Y]$ へ移る $[g]$ が得られ、$fg\simeq\id_Y$ となる。すると $f(gf)=(fg)f\simeq f=f\id_X$ である。今度は $W=X$ での単射性を使い、$gf\simeq\id_X$ が得られる。従って $g$ はホモトピー逆である。逆に逆写像 $g$ があれば、どちら側からの合成でも $g$ による合成がホモトピー類の集合上で逆になる。
:::

:::example[可縮な因子を忘れるときの写像類]
射影 $p:S^1\times[0,2]\to S^1$ と切断 $j(z)=(z,1)$ を取る。$pj=\id$ であり、$jp$ は第二座標を $1$ に移すので恒等にホモトピックである。任意の値域 $Y$ への写像 $f$ は、$H((z,s),t)=f(z,(1-t)s+t)$ により $(fj)p$ へ変形される。例えば $f(z,s)=ze^{\pi i s}$ を取ると $fj(z)=-z$ であり、$s=2$ にある点の時刻 $1/2$ の値は $ze^{3\pi i/2}=-iz$ である。値域を一つ選んで空間の形を調べる方法は次章の基本群にも通じるが、ここでは任意の $Y$ で同じ変形を使える。
:::

:::example[離散な値域で同値を見分ける]
$Y=\{0,1\}$ に離散位相を入れ、$X$ を二つの閉区間の非交和とする。各区間の像は定値となり、二成分で値を独立に選べるので $[X,Y]$ は四元である。一点空間 $P$ からの写像類は二元だけであるため、$X$ と $P$ はホモトピー同値でない。一方、二点空間 $D$ から各区間の中点を選ぶ写像はホモトピー同値であり、実際 $[D,Y]$ も四元である。道成分ごとの区別が写像類の個数に現れた例である。
:::

:::example[対の同値と全空間の同値を区別する]
$X=Y=I$ とし、$A=\{0,1\}$、$B=\{0\}$ とする。全空間だけなら恒等写像でも同値である。対の間には定値写像を使えば互いの方向に写像を作れる。しかし対のホモトピー同値なら、制限によって $A\simeq B$ となる。二点から一点への写像とその逆候補の合成は $A$ で定値であり、離散空間への時間軌跡は一定なので恒等とホモトピックにならない。商も $X/A\cong S^1$ と $Y/B\cong I$ に分かれる。相対条件があることで、商に移しても変形が保つべき情報が残る。
:::

### 時間座標の変更と経路の制約

ホモトピーを作った後、始終の近くに時間の余裕を置きたいことがある。$u:I\to I$ が連続で $u(0)=0,u(1)=1$ を満たせば、$H'(x,t)=H(x,u(t))$ は同じ端を持つ。$u(t)=0$ を $0\le t\le1/4$、$u(t)=2t-1/2$ を $1/4\le t\le3/4$、$u(t)=1$ を $3/4\le t\le1$ に取れば、最初と最後の四分の一で写像が止まる。この停留を使うと、複数の変形のつなぎ目がどこか指定しやすくなる。固定部分の値も $H$ と同じである。

:::example[値域から原点を除いたときの直接の変形]
写像 $f,g:I\to\C\setminus\{0\}$ を $f(x)=1+x$、$g(x)=-(1+2x)$ とする。線分による補間では各 $x$ で途中に零が現れる。半径と偏角を別に選び、$H(x,t)=((1-t)(1+x)+t(1+2x))e^{\pi it}$ とすれば、半径は常に $1$ 以上で零にならない。例えば $x=1/2,t=1/2$ では半径は $7/4$、角は $\pi/2$ なので値は $7i/4$ である。値域の除去点を避けるために補間の経路を変えたのであり、元の二つの写像の値は入口と出口で正確に保たれる。
:::

## 可縮空間と変位レトラクト

:::definition[可縮空間と変位レトラクト]{#def-at-deformation-retract}
一点とホモトピー同値な空間を :term[可縮空間]{en="contractible space" yomi="かしゅくくうかん"} という。$i:A\hookrightarrow X$ と $r:X\to A$ が $ri=\id_A$ を満たし、$\id_X\simeq ir$ が $A$ に相対的に成り立つとき、$A$ を :term[変位レトラクト]{en="deformation retract" yomi="へんいれとらくと"} と呼ぶ。
:::

:::proposition[縮約の特徴付け]{#prop-at-contractible}
空でない $X$ が可縮であることは、$\id_X$ がある定値写像にホモトピックであることと同値である。変位レトラクト $A$ の包含はホモトピー同値である。
:::

:::proof
一点への唯一の写像 $p$ と一点からの写像 $s$ を取ると、$ps$ は恒等写像で $sp$ は定値写像である。よって同値は定義から従う。変位レトラクトについては $r$ を包含のホモトピー逆に使えばよい。
:::

:::example[点を除いた空間]
$\R^n\setminus\{0\}$ は $S^{n-1}$ に変位レトラクトする。実際
$$
H(x,t)=\left(1-t+\frac{t}{\norm{x}}\right)x
$$
の係数は正で、終点の長さは $1$ である。例えば $x=(0,4)$ に対する途中の長さは $4-3t$ となる。$n=1$ では二つの半直線がそれぞれ $-1$、$1$ に縮む。
:::

:::example[空間の積]
$X\times I$ は $X\times\{0\}$ に変位レトラクトする。$((x,s),t)\mapsto(x,(1-t)s)$ である。したがって円周を持つ円筒と円周はホモトピー同値である。円筒の上下の境界を潰した場合は、この変形をそのまま使えない。時刻が途中だと上端の一点として同一視した点が分離するためである。
:::

### 縮約の中心と途中の軌跡

:::proposition[可縮空間の正則な一点]
$X$ が可縮で、$\{a\}$ が閉じ、$(X,\{a\})$ がホモトピー拡張性質を持つなら、$\{a\}$ は $X$ の変位レトラクトである。
:::

:::proof
まず縮約の終点を $a$ に変更する。縮約 $C$ の終点を $b$ とすると $C(a,t)$ が $a$ から $b$ への道を与えるので、縮約の後にこの道を逆にたどる定値写像の族をつなぐ。こうして $H:\id_X\simeq a$ を得る。$H(a,t)$ は $a$ に戻る道である。任意のループ $\ell$ は $H(\ell(s),t)$ によって自由に縮む。端点を固定するには、各時刻の道の前に $u\mapsto H(a,tu)$、後ろにその逆を付ける。$t=1$ で残った往復道は、進む距離を減らすことで定値に縮む。従って $H(a,t)$ 自身を端点相対で定値に変形できる。

この端点相対の変形を $X\times I$ 上へ拡張する。$(X,\{a\})$ の拡張性質は、次節以降で用いるレトラクション判定により $X\times\{0\}\cup\{a\}\times I$ への円柱のレトラクションと同値である。$(X\times I, X\times\partial I\cup\{a\}\times I)$ にも拡張性質がある。これを具体的に見るには、二つの時刻が作る正方形の境界上で、底辺と左右の側辺の合併を底辺一本へ送る区分線形同相を取る。境界の同相は中心から放射状に延長できる。すると指定部分は $X\times I\times\{0\}\cup\{a\}\times I\times I$ に移る。ここへは、$X$ と最後の時刻に元の対のレトラクションを適用し、中央の座標を保つことでレトラクトできる。延長の終時刻を取れば $\id_X\simeq a$ が $\{a\}$ 相対になる。
:::

:::example[原点を中心とする星形領域]
$X$ を横長の長方形 $[-3,3]\times[-1,1]$ と縦長の長方形 $[-1,1]\times[-3,3]$ の合併とする。$X$ のどの点も原点まで同じ長方形内で線分に沿って動くので、$H(x,t)=(1-t)x$ は縮約である。$x=(3,1)$ と $y=(1,3)$ を結ぶ線分の中点 $(2,2)$ は $X$ の外にある。このため、星形領域で線分を用いるときは縮約の中心を指定する必要がある。例えば $(0,2)$ を中心に同じ式を使うと $(3,1)$ との中点 $(3/2,3/2)$ が領域から出る。
:::

:::example[境界を固定する変位レトラクト]
$X=S^1\times\R$ とし $A=S^1\times[-1,1]$ を取る。$r(s)=\max(-1,\min(1,s))$ と置くと、$H((z,s),t)=(z,(1-t)s+tr(s))$ は $A$ 上で一定である。例えば $s=-4$ は時刻 $1/3$ で $-3$ となり、終時刻で $-1$ へ移る。続いて $A$ を $S^1\times\{0\}$ に縮められるが、その変形では当初の $A$ は固定されない。このように、何を固定するかは目標となる部分空間ごとに指定する。
:::

:::example[レトラクトと変位の違い]
$X=[-2,-1]\amalg[1,2]$ を $\R$ の部分空間とみなし、$A=[-2,-1]$ とする。右側の区間を $-1$ へ送る写像は左側を固定し、両区間が開なので連続である。従って $A$ はレトラクトである。ところが変位レトラクションがあれば、$x=2$ の時間軌跡が右の区間と左の区間を結ぶ。連結な区間の像は一つの道成分に入るため、このような軌跡は存在しない。
:::

### 部分空間を縮めた後の変形

:::proposition[二段階の変位レトラクション]
$B\subset A\subset X$ とし、$A$ が $X$ の変位レトラクト、$B$ が $A$ の変位レトラクトであるとする。このとき $B$ は $X$ の変位レトラクトである。
:::

:::proof
$A$ への変形 $H$ を前半で実行し、その終点 $r_A(x)$ に対して $B$ への変形 $K$ を後半で実行する。式は $t\le1/2$ で $H(x,2t)$、$t\ge1/2$ で $K(r_A(x),2t-1)$ である。つなぎ目では両者が $r_A(x)$ を与えるので連続である。$b\in B$ は $A$ にも $B$ にも入るので両変形で固定され、終写像は $r_Br_A$ である。
:::

:::example[直交射影を二段階で使う]
$\R^3$ で平面 $A=\{z=0\}$ と直線 $B=\{y=z=0\}$ を取る。$H$ は $z$ を $(1-t)z$ に送り、$K$ は $A$ 内で $y$ を $(1-t)y$ に送る。点 $(1,2,3)$ は全時間で $x=1$ を保ち、時刻 $1/4$ で $(1,2,3/2)$、時刻 $3/4$ で $(1,1,0)$、終時刻で $(1,0,0)$ になる。後半は既に $A$ 内で動く。これに対して $y,z$ を同時に減らす式でも $B$ への変形は作れるが、途中で $A$ に入る時刻は異なる。固定する部分と終点が同じでも、時間ごとの軌跡は一意でない。
:::

:::proposition[可縮空間のレトラクト]
可縮空間 $X$ の非空なレトラクト $A$ は可縮である。
:::

:::proof
包含を $i$、レトラクションを $r$ とし、$\id_X$ から $b$ への縮約を $H$ とする。$rH(i(a),t)$ は時刻 $0$ に $ri(a)=a$、時刻 $1$ に $r(b)$ を与える。そのため $\id_A$ が定値にホモトピックである。途中の点が $X$ では $A$ の外に出ても、$r$ を合成した後は値域が $A$ にとどまる。
:::

:::example[レトラクトの非存在を零次で判定する]
区間 $I$ の二端点 $\{0,1\}$ はレトラクトでない。もしレトラクションがあれば、可縮性を移して二点空間を一点に縮約できるはずである。しかし二点空間では異なる点の間に道がない。直接には $r:I\to\{0,1\}$ の連続像が連結であるため、$r$ が二つの端点を両方とも固定できないということでもある。円板と境界円周はどちらも道連結である。この対に対しては、[基本群](/math/algebraic-topology/fundamental-group/) でレトラクションが存在しないことを調べる。
:::

:::example[可縮でも任意の中心を固定できるわけではない]
櫛形空間
$$
C=(I\times\{0\})\cup(\{0\}\times I)\cup
\bigcup_{j\ge1}(\{1/j\}\times I)
$$
を考える。まず $(x,y)$ を $(x,(1-t)y)$ に移して基線に縮め、次に基線上で原点へ縮められる。従って $C$ は可縮である。ところが $a=(0,1)$ を全時刻に固定する縮約があると仮定すると、$x_j=(1/j,1)$ の軌跡は $a$ に至るまでに必ず基線を通る。実際、$y>0$ の部分空間では第一座標は収束列 $\{0,1,1/2,\ldots\}$ に値を取り、その連結部分は一点だけである。基線を通る時刻 $t_j$ の部分列が $t_*$ に収束すると、連続性から $H(a,t_*)$ も基線に入ってしまう。これは $a$ を固定することに反する。この空間で $a$ の包含に拡張性質を仮定できないことも、先の命題から分かる。
:::

## 胞体の接着と CW 複体

円周を作るには、線分の両端を同じ点に貼る。高次元でもこの手順を繰り返し、閉球の境界をそれまでの空間に貼る。

:::definition[胞体接着]{#def-at-cell-attachment}
$D^n=\{x\in\R^n:\norm{x}\le1\}$、$S^{n-1}=\partial D^n$ とする。$D^0$ は一点、$S^{-1}$ は空集合とする。写像 $\varphi_\alpha:S^{n-1}\to X$ に沿って胞体を接着した空間は
$$
X\cup_{\varphi_\alpha}\coprod_\alpha D_\alpha^n
=\bigl(X\amalg\coprod_\alpha D_\alpha^n\bigr)/(u\sim\varphi_\alpha(u))
$$
である。$\varphi_\alpha$ を :term[接着写像]{en="attaching map" yomi="せっちゃくしゃぞう"}、$D_\alpha^n$ から商空間への写像を特性写像と呼ぶ。
:::

商の普遍性から、この空間からの連続写像は、$X$ と各円板上の連続写像で境界値が合うものに対応する。$X$ は閉部分空間として埋め込まれる。実際、$X$ の閉集合 $B$ は各円板で $\varphi_\alpha^{-1}(B)\subset S^{n-1}$ に引き戻され、商位相で閉じている。この接着段階では、各開球は開部分空間に同相に写る。開球の内部の開集合は商写像に関して飽和しているためである。

:::definition[CW 複体]{#def-at-cw}
離散な $0$ 骨格 $X^0$ から出発し、$X^n$ を $X^{n-1}$ に $n$ 胞体を接着して作る。$X=\bigcup_n X^n$ に、すべての骨格への制限で閉性を判定する位相を入れた Hausdorff 空間を :term[CW 複体]{en="CW complex" yomi="しーだぶりゅーふくたい"} とする。各胞体の閉包が有限個の胞体からなる部分複体に入ることを :term[閉包有限性]{en="closure finiteness" yomi="へいほうゆうげんせい"} という。:term[部分複体]{en="subcomplex" yomi="ぶぶんふくたい"} は、胞体を選んで作る部分空間であり、選んだ胞体の閉包をすべて含む。
:::

この :term[弱位相]{en="weak topology" yomi="じゃくいそう"} で集合が閉じていることは、全特性写像で閉集合に引き戻されることと同値である。各骨格への接着を次元順にたどればこの同値が得られる。各骨格の位相は全空間からの部分空間位相に等しい。実際、$X^{n-1}$ の閉集合の逆像は各接着円板で境界球面の閉部分に当たり、従って $X^n$ でも閉である。この議論を後の骨格にも繰り返し、弱位相を使う。

:::lemma[コンパクト集合が出会う胞体の有限性]{#lem-at-finite-cell-support}
各胞体の閉包は有限部分複体に含まれる。また、CW 複体のコンパクト部分集合は有限部分複体に含まれる。
:::

:::proof
零骨格では各胞体の閉包は一点である。$X^{n-1}$ の各胞体の閉包が有限部分複体に含まれると仮定する。この骨格のコンパクト集合が無限個の開胞体と交わるなら、各開胞体から集合に属す点を一つずつ選ぶ。各特性写像の像は有限部分複体に含まれるので、選んだ点の任意の部分集合の逆像は有限個の閉集合の合併となる。弱位相から、選んだ集合は閉であり、部分空間として離散である。これはコンパクト集合の中に無限の閉離散部分空間があることになり矛盾する。従って、コンパクト集合が出会う開胞体の閉包を含む有限部分複体を合わせれば、その集合を覆える。

$n$ 胞体の接着像は球面の連続像なので、下の骨格のコンパクト集合である。先の議論でその像を含む有限部分複体を取り、新しい胞体を一つ加えると閉包全体を含む。実際、特性円板の像はコンパクトで Hausdorff 空間内で閉じており、開円板が閉円板で稠密なので、その像は開胞体の閉包に等しい。これで次元の帰納法が進み、全ての胞体で閉包有限性を得る。全空間でも同じ閉離散集合の議論を使えるため、コンパクト集合は有限個の開胞体にしか出会わない。
:::

:::lemma[部分複体の開襟]{#lem-at-subcomplex-neighborhood}
CW 複体の部分複体 $A$ は、$A$ に変位レトラクトする開近傍 $N(A)$ を持つ。近傍は二つの部分複体 $A,B$ について $N(A)\cap N(B)=N(A\cap B)$ となるよう選べる。
:::

:::proof
零骨格では $N^0(A)=A\cap X^0$ とする。次の骨格で、$A$ の胞体は全体を加える。他の胞体では、特性円板の放射座標 $(r,u)$ で $r>1/2$ かつ $\varphi(u)\in N^{n-1}(A)$ となる襟を加える。境界上で既に取った開集合と一致するから、$N^n(A)$ は商位相で開である。全骨格で合わせた $N(A)$ も弱位相で開となる。

$A$ に入らない $n$ 次元の襟は、時刻 $[2^{-n},2^{-n+1}]$ に境界へ押す。任意の特性円板上では、その次元より高い襟を押す時間帯に変化はない。続く有限個の時間帯では、各襟の放射変形と下の骨格での変形を、時間の端と円板の境界で一致させて貼る。従って各特性円板から引き戻した写像は連続である。商写像と区間の積は商写像なので全体で連続であり、$A$ を固定する。零骨格までにはすべての点が $A$ に入る。

二つの近傍の交わりについては、各胞体で閾値 $1/2$ を共通に使う。両方が胞体全体を取れば交わりも全体であり、一方だけが襟を取れば交わりもその襟である。両方が襟を取るなら、両者の境界条件を同時に満たす襟が残る。骨格で帰納すると、交わりは $N(A\cap B)$ になる。
:::

:::proposition[CW 複体の局所可縮性]{#prop-at-cw-locally-contractible}
CW 複体の任意の点は可縮な開近傍からなる近傍基を持つ。特に CW 複体は局所道連結である。
:::

:::proof
点 $x$ の属する開胞体の次元を $k$ とし、指定された開近傍を $W$ とする。$X^k$ では、その胞体の内部に $x$ を含む小開球を $W$ の中に取れる。高次の円板では、接着先が既に作った近傍に入り、しかも自分から境界までの放射線分全体が特性写像による $W$ の逆像に入る点からなる襟だけを足す。使う半径は $r>1/2$ とする。放射線分はコンパクトなので、条件を満たす方向と半径の近くでも同じ条件が成り立つ。境界では接着先の開近傍の逆像をすべて含む。このため各段で開集合ができ、全空間でも弱位相で開になる。襟の放射線分は最初から $W$ に入るように選んだので、高次の襟から順に押し出すと、この開近傍は最初の開球へ変位レトラクトする。開球を $x$ へ縮めればよい。
:::

:::example[球面]
一点に $n$ 胞体一個を貼ると $D^n/S^{n-1}$ になる。$n\ge1$ で $x=ru$ に対し $[x]\mapsto(\sin(\pi r)u,\cos(\pi r))$ と置くと球面 $S^n\subset\R^{n+1}$ への連続全単射である。中心と境界で第一成分は $0$ になる。定義域がコンパクトで値域が Hausdorff なので同相である。$n=0$ の球面は二点の $0$ 胞体からなる。
:::

:::example[正方形の二種類の接着]
正方形の向かい辺を平行移動で貼ると、写像 $(s,t)\mapsto(e^{2\pi i s},e^{2\pi i t})$ が $S^1\times S^1$ への同相を誘導する。角は一個の頂点になり、辺は二個の $1$ 胞体になる。境界を下、右、上、左の順に進むと、二つの辺を $a,b$ として $aba^{-1}b^{-1}$ を読む。他方、円板の境界の対蹠点を同一視すると、その境界は円周となり、接着写像は $z\mapsto z^2$ である。円板を $S^2$ の閉半球とみなせば、得られた空間は対蹠商 $\R P^2$ に同相である。
:::

### 接着の普遍性と骨格の読解

:::proposition[閉部分空間への胞体の接着]
空でない閉部分空間 $A\subset X$ に像を持つ接着写像 $\varphi:S^{n-1}\to A$ があるとする。このとき $A\cup_\varphi D^n$ は $X\cup_\varphi D^n$ に閉部分空間として埋め込まれる。またこの部分空間を潰す商は $X/A$ に同相である。
:::

:::proof
包含は点集合として単射である。小さい接着空間の閉集合 $F$ の逆像は $A$ と $D^n$ で閉じている。$A$ が $X$ で閉であるため $X$ での逆像も閉じている。大きい接着空間への像が閉であることが従い、包含が閉埋め込みと分かる。二つの商を比較するには $X$ の各点を対応する商の点へ送る。$D^n$ は全部潰れるので大きい空間の商から $X/A$ への連続写像は、$X$ 上で商写像、$D^n$ 上で定値写像を用いて作れる。逆写像も $X$ の包含と商写像の合成から誘導される。
:::

:::example[円周の胞体分解を細かくする]
$S^1$ を一点と一本の辺で作る場合、特性写像 $t\mapsto e^{2\pi it}$ の両端の像が等しい。二点 $1,-1$ を $0$ 胞体に取る場合には、$t\mapsto e^{\pi it}$ と $t\mapsto -e^{\pi it}$ が二本の辺の特性写像になる。後者では各辺の閉包は閉区間と同相であり、前者では閉包は円周である。同じ位相空間でも、特性写像が閉球上で単射になるかは胞体分解の選択で変わる。
:::

:::example[Möbius 帯の骨格]
$[0,1]\times[-1,1]$ の左右を $(0,u)\sim(1,-u)$ で貼る。二つの頂点は左下と右上の組、および左上と右下の組である。上下の二辺と共通になった左右の辺の三本が $1$ 胞体であり、内部が一個の $2$ 胞体である。中央の円は $(s,0)$ の像であり、$u\mapsto(1-t)u$ でそこへ変位レトラクトする。この変形が商に降りるのは $-(1-t)u=(1-t)(-u)$ による。この円自体を部分複体にするには、中央の線分で長方形を分割してから貼る。
:::

:::example[立方体の境界]
立方体 $[-1,1]^3$ の各面の内部、各辺の内部、各頂点を胞体とする。例えば面 $x=1$ の閉包は四本の辺と四頂点を含み、閉正方形からの特性写像で記述できる。境界から球面への $x\mapsto x/\norm{x}$ の逆は $u\mapsto u/\max_i|u_i|$ である。従って $S^2$ は $8$ 個の頂点、$12$ 本の辺、$6$ 個の面を持つ CW 分解も持つ。三種類の胞体数の交代和は $8-12+6=2$ で、一点と一つの $2$ 胞体による分解では $1+1=2$ である。この一致を一般化したものが後章の Euler 標数である。
:::

### 骨格ごとの指定を貼り合わせる

:::proposition[閉胞体による連続性の検査]
CW 複体 $X$ の各閉円板の特性写像 $\Phi_e$ に対して連続写像 $f_e:D^{\dim e}\to Y$ を選び、$X$ の同じ点へ送られる二つの点の値をすべて一致させる。このとき各 $f_e$ を制限に持つ連続写像 $X\to Y$ が一意に存在する。
:::

:::proof
全特性写像の非交和は $X$ への全射であり、弱位相によって商写像である。両立条件は各ファイバー上で値が一定であることに当たるので、連続写像は商の普遍性で一意に降りる。言い換えると、既に骨格 $X^{n-1}$ 上の写像を作ったときは、$n$ 円板上の指定が境界で $X^{n-1}$ の写像と一致するかどうかを調べればよい。この手順をすべての次元に行っても、弱位相があるので連続性が保証される。
:::

:::example[円周への写像を一本の辺で指定する]
$S^1$ を頂点一つと辺一つで作る。辺の式 $t\mapsto e^{2\pi i(3t+t(1-t))}$ は両端で $1$ なので円周の写像になる。端点の差に整数を必要とするのは、貼り合わせ先が円周であり角度を等しい点として評価するためである。式の $3t$ を $(5/2)t$ に替えると、終点は $-1$ となって始点と合わない。どちらも閉区間では連続だが、後者は商へ降りない。円周からさらに円板を貼る場合は、辺が作る閉曲線を円板に延長できることも検査する必要がある。
:::

:::example[三つの骨格で作る射影空間]
$\R P^3$ の各点を $\R^4$ の実直線とする。最後に非零となる座標の添字を $j$ とし、その座標を $1$ にそろえると、先行する $j-1$ 座標が自由になる。この集合は開胞体 $\R^{j-1}$ である。添字 $4$ の胞体は $S^3$ の閉上半球の内部を使って作り、球面の赤道 $S^2$ では反対点を貼って $\R P^2$ に入る。これを $j=3,2,1$ でも行うと各次元に一胞体になる。例えば添字 $3$ の開胞体の点 $[3:-2:1:0]$ は $(3,-2)$ で表示されるが、第三座標が零になるとその表示からは出て下の骨格に入る。このように「開胞体」は、それ単独で Euclid 空間と同相であることを述べる言葉であり、全空間で開とは限らない。
:::

:::example[三次元トーラスの積胞体]
$T^3$ を立方体の各対向面の貼り合わせで作る。三座標のうち $k$ 個を開区間、残りを両端を同一視した頂点に取ると、$k$ 胞体が $\binom3k$ 個ある。従って胞体数は $(1,3,3,1)$ である。例えば $x,y$ を動かし $z$ を基点とした二胞体の境界は、$x$、$y$ の円を $aba^{-1}b^{-1}$ の順で進む。三胞体の境界にある各二胞体は対向する二面の像に現れる。この見方により、どの低次の胞体が各特性写像の境界に現れるかを座標から読める。
:::

## 空間の基本操作（積・商・懸垂・結・ウェッジ和・スマッシュ積）

:::definition[空間の積と商から作る空間]{#def-at-space-operations}
積 $X\times Y$ は積位相を持つ。$X/A$ は空でない $A$ を一点に潰した商である。$CX=(X\times I)/(X\times\{1\})$ を錐、$SX=(X\times I)/(X\times\{0\},X\times\{1\})$ を :term[懸垂]{en="suspension" yomi="けんすい"} と呼ぶ。懸垂では両端を別々に潰す。$X*Y$ は $X\times Y\times I$ で $t=0$ のとき $y$ を、$t=1$ のとき $x$ を忘れる商であり、:term[結]{en="join" yomi="けつ"} と呼ぶ。
:::

:::definition[ウェッジ和とスマッシュ積]{#def-at-smash}
点 $x_0\in X$、$y_0\in Y$ を選ぶ。$X\amalg Y$ で二点を同一視した商を :term[ウェッジ和]{en="wedge sum" yomi="うぇっじわ"} $X\vee Y$ と呼ぶ。積の部分集合 $(X\times\{y_0\})\cup(\{x_0\}\times Y)$ を一点に潰した商を :term[スマッシュ積]{en="smash product" yomi="すまっしゅせき"} $X\wedge Y$ と呼ぶ。
:::

閉点を基点に選ぶと、ウェッジ和は上の部分集合へ自然に同相に写る。実際、二つの閉部分空間上で閉性を判定できるので、部分空間位相と商位相が一致する。無限 CW 複体の積については、通常の積位相と胞体から決めた弱位相の一致を個別に確認する必要がある。

:::example[球面の結]
$x\in S^m$、$y\in S^n$ に対し
$$
[x,y,t]\longmapsto \bigl(\sqrt{1-t}\,x,\sqrt t\,y\bigr)
$$
は $S^m*S^n\to S^{m+n+1}$ の同相を与える。第二成分の長さの二乗から $t$ を回復でき、両成分が非零なら正規化によって $x,y$ が決まる。端点の残りの自由度は定義の同一視そのものである。コンパクト性より連続全単射は同相である。例えば $S^0*S^1\cong S^2$ となる。$S^0*X$ は $X$ の二つの錐を底面で貼る空間であり、$SX$ と同じ商である。
:::

:::example[球面のスマッシュ積]
$m,n\ge1$ とし、潰した境界を球面の基点にする。このとき $S^m\wedge S^n$ は $D^m\times D^n$ の境界を潰した商に同相である。各商はコンパクト Hausdorff であり、自然な連続全単射がある。積の球を $\max(\norm{x},\norm{y})\le1$ と見れば、原点から放射状に境界の長さを調節することで Euclid 球と境界を保って同相になる。そのため $S^m\wedge S^n\cong S^{m+n}$ である。$m=n=1$ ではトーラス中の二つの因子円周を潰すと $S^2$ が得られる。
:::

### 商が区別する端点と基点

:::proposition[有限個の離散点の懸垂]
$r\ge1$ 個の点からなる離散空間 $D_r$ の懸垂は、$r-1$ 個の円周のウェッジ和とホモトピー同値である。$r=1$ のとき右辺は一点とする。
:::

:::proof
$D_r\times I$ は $r$ 本の閉区間の非交和である。下端を一つの頂点 $v_0$ に、上端を別の頂点 $v_1$ に同一視するので、懸垂は二頂点を結ぶ $r$ 本の辺からなるグラフである。一本の閉辺を取ると、両頂点を含む可縮な部分複体になる。:ref[cor-at-collapse-contractible] によりこの辺を潰してもホモトピー型は保たれる。残りの各辺の両端は共通の一点になり、商の普遍性からウェッジ和と同相である。
:::

:::example[閉区間と円周の結]
$S^1*\{*\}$ は錐 $CS^1$ である。写像 $[z,*,t]\mapsto(1-t)z$ は閉単位円板に値を取り、原点以外では $z=w/|w|$ と $t=1-|w|$ が一意に定まる。原点の逆像は錐の頂点である。連続全単射で定義域がコンパクトなので同相である。さらに $S^1*I$ はこの錐へ変位レトラクトする。$I$ 座標 $u$ を $(1-s)u$ に動かすと、端点で忘れる座標の条件を保ったまま商に降りるからである。ここでは第二因子を一点へ縮めたことで結が可縮になった。
:::

:::example[三点空間を用いた三つの操作]
基点付き三点空間 $A=\{*,a,b\}$ と基点付き二点空間 $B=\{*,c\}$ を取る。$A\times B$ には六点あり、ウェッジ和をなす部分集合は $(*,*),(a,*),(b,*),(*,c)$ の四点である。これを一点に潰すと $A\wedge B$ の残りは $(a,c),(b,c)$ であり、$A$ と基点付き同相である。懸垂 $SA$ には二頂点と三辺があるので、先の命題により二円のウェッジ和と同値である。結 $A*B$ には五頂点と六辺があり、各 $A$ の点から $B$ の各点へちょうど一本の辺がある。$(*,*)$ の両頂点を結ぶ辺、$A$ の残り二点から $B$ の基点への二辺、$B$ の $c$ から $A$ の基点への一辺を選ぶと、四辺の木ができる。この木を潰すと残り二辺が円になる。
:::

:::example[一点コンパクト化とスマッシュ積]
$\R^m$ の一点コンパクト化を $(\R^m)^+$ と書き、追加点を基点とする。積 $(\R^m)^+\times(\R^n)^+$ のうち、どちらか一方が追加点である集合を潰す。残った点は $(x,y)\in\R^{m+n}$ に一対一に対応する。商で基点の近傍を取ると、その補集合は積空間内の閉集合であり、コンパクトで、かつ $\R^{m+n}$ の中にある。逆に $\R^{m+n}$ のコンパクト集合は積空間でも閉じているので補集合は基点の開近傍へ降りる。このため商は $(\R^{m+n})^+$ に同相である。例えば $m=2,n=3$ では、二つの追加点を含む座標断面を一つの点にまとめて $S^5$ を得る。
:::

### 錐を値域にした延長

:::proposition[錐への延長と零ホモトピー]
空でない空間 $X$ から $Y$ への連続写像 $f$ が、錐 $CX$ へ連続に延長できる必要十分条件は、$f$ が定値写像へホモトピックであることである。
:::

:::proof
底面の包含を $x\mapsto[x,0]$ とする。延長 $F:CX\to Y$ があれば $F([x,t])$ は連続で、$t=0$ に $f$、$t=1$ に錐の頂点の値を取る。逆に $H:X\times I\to Y$ が $f$ から定値へのホモトピーなら、$t=1$ のすべての値が一致する。従って商写像の普遍性により $H$ は $CX$ へ降りる。貼り合わせの前にホモトピーを作っておけば、商の頂点における連続性も同時に得られる。
:::

:::example[距離が無限に大きい場合の錐の頂点]
$X=\R$ の錐 $CX$ を考える。$U$ を $X\times I$ の開集合
$$
\{(x,t):1-t<1/(1+|x|)\}
$$
の像とすると、$U$ は頂点の開近傍である。元の集合は $X\times\{1\}$ をすべて含むため同一視に対して飽和しているからである。いかなる $\epsilon>0$ に対しても $X\times(1-\epsilon,1]$ の像が $U$ に含まれるわけではない。$x$ を大きく取れば右辺の高さが $\epsilon$ より小さくなる。このため非コンパクトな底を持つ錐で、頂点近くの連続性を一様な高さだけで判定する方法は使えない。一方、錐上の写像を作るだけなら、連続な円柱の式を商に降ろす方法で十分である。
:::

:::example[区間を懸垂して得る円板]
$I$ の懸垂で、$t$ を高さ、$x$ を区間座標とする。
$$
[x,t]\longmapsto\bigl((2x-1)\sqrt{1-(2t-1)^2},\,2t-1\bigr)
$$
は閉単位円板へ値を取る。高さが $\pm1$ でないとき $t$ と $x$ は順に一意に戻り、高さが $\pm1$ のときはそれぞれの極だけである。コンパクトな商から Hausdorff 空間への連続全単射なので同相である。例えば $(x,t)=(3/4,1/2)$ は $(1/2,0)$ へ、$(1/2,3/4)$ は $(0,1/2)$ へ移る。懸垂という同じ操作でも、底が円周なら球面、底が区間なら円板になる。
:::

:::example[積で潰す座標断面]
$S^1\wedge I$ で区間の基点を $0$ とする。$H([z,u],t)=[z,(1-t)u]$ はスマッシュ積上の連続な縮約である。もし $z$ が基点か $u=0$ なら、変形後も潰す部分に属するため式は商に降りる。他方、区間の両端を同一視して $S^1$ にした第二因子を使うと、この縮約には $u=1$ と $u=0$ の像を一致させる必要がある。途中で $(1-t)u$ が両端を一致させなくなるため同じ式は使えない。その商では実際に球面 $S^2$ が現れる。
:::

## ホモトピー拡張性質とその帰結

$A$ 上でだけ指定した動きを $X$ 全体で実現したい。初期時刻の写像は $X$ 上にあり、その後の動きは $A$ にある。この二つの領域の合併を円柱の内側から押し戻せれば、拡張が得られる。

:::definition[ホモトピー拡張性質]{#def-at-hep}
$A\subset X$ について、任意の空間 $Y$ と連続写像 $f:X\to Y$、$h:A\times I\to Y$ で $h(a,0)=f(a)$ を満たすものに対し、両者を制限として持つ $H:X\times I\to Y$ が存在するとき、$(X,A)$ は :term[ホモトピー拡張性質]{en="homotopy extension property" yomi="ほもとぴーかくちょうせいしつ"} を持つという。その包含を余ファイブレーションという。
:::

:::lemma[円柱の底と側面へのレトラクション]{#lem-at-disk-cylinder}
$D^n\times I$ は $D^n\times\{0\}\cup S^{n-1}\times I$ にレトラクトする。
:::

:::proof
$(0,2)$ から $(x,t)$ を通る半直線を $\lambda\ge1$ へ延ばす。底へ達する値は $\lambda_0=2/(2-t)$ で、側面への値は $x\ne0$ のとき $\lambda_1=1/\norm{x}$ である。そこで
$$
\lambda=\frac{1}{\max((2-t)/2,\norm{x})},\qquad
r(x,t)=(\lambda x,2+\lambda(t-2))
$$
と置く。分母は $1/2$ 以上である。$\lambda$ は二つの壁への値の小さい方なので像は底か側面に入る。元の点が底か側面にあると $\lambda=1$ になる。$n=0$ の場合は区間から底点への定値写像である。
:::

:::theorem[CW 対の拡張性質]{#thm-at-cw-hep}
CW 複体 $X$ と部分複体 $A$ の対はホモトピー拡張性質を持つ。
:::

:::proof
$A$ 上の $h$ から出発し、$A\cup X^n$ に次元順に拡張する。$A$ に含まれない $n$ 胞体では、特性写像で円板に引き戻した初期写像と、境界上で既に得たホモトピーを貼り合わせる。:ref[lem-at-disk-cylinder] の $r$ と合成すれば円柱全体に延長できる。接着写像に沿った値は変わらないので、すべての円柱の写像は両立する。

最後に積の連続性を確認する。商写像 $q$ と局所コンパクト Hausdorff 空間 $I$ の積 $q\times\id_I$ は商写像である。実際、積空間から任意の空間 $Y$ への写像の連続性は、コンパクト開位相を入れた写像空間 $C(I,Y)$ への随伴写像で判定できる。順方向はコンパクト集合を覆う有限個の積近傍から、逆方向は時刻のコンパクト近傍を取って評価写像の連続性から従う。随伴写像には $q$ の商の普遍性を適用できる。これを全特性写像の非交和から $X$ への商写像に適用すると、円柱ごとに作った写像が $X\times I$ 上で連続である。
:::

:::corollary[可縮な部分複体を潰す]{#cor-at-collapse-contractible}
空でない可縮な部分複体 $A\subset X$ について $q:X\to X/A$ はホモトピー同値である。
:::

:::proof
$\id_A$ から $a_0$ への縮約を $\id_X$ から始まる $H$ に拡張する。$H_1$ は $A$ 上で定値なので $g:X/A\to X$ に降り、$gq=H_1\simeq\id_X$ となる。また $qH$ は各時刻で $A$ 上定値である。商と区間の積の性質により $qH$ は $(X/A)\times I$ に降り、$\id_{X/A}\simeq qg$ を与える。
:::

:::example[三角形の周と木]
三角形の周から二辺を選ぶと、三頂点を含む木が得られる。この部分複体は線分に同相で可縮である。潰した商では残りの辺の両端が同じ頂点になるので円周になる。この手順は木を含むグラフの計算に使える。
:::

:::example[収束列の対]
$X=\{0\}\cup\{1/n:n\ge1\}\subset\R$ と $A=\{0\}$ を考える。$X\to I$ を最初に定値 $0$ とし、$h(0,t)=t$ としても拡張は存在する。$H(x,t)=t$ でよい。一方、これだけから対の拡張性質は結論できない。$X\times\{0\}\cup A\times I$ 自身を値域とし恒等写像を拡張しようとすると、$x=1/n$ から出る道は第一成分が常に $1/n$ で第二成分が常に $0$ である。$(0,1)$ で連続性が成り立たないため、この対は拡張性質を持たない。
:::

### 延長問題をレトラクションへ移す

:::lemma[ホモトピー拡張性質の判定]{#lem-at-hep-retraction}
$A$ が $X$ に閉じているとする。対 $(X,A)$ がホモトピー拡張性質を持つことと、$S=X\times\{0\}\cup A\times I$ が $X\times I$ のレトラクトであることは同値である。
:::

:::proof
拡張性質を仮定し、値域を $S$、最初の写像を $x\mapsto(x,0)$、$A$ 上のホモトピーを $(a,t)\mapsto(a,t)$ とする。拡張は $S$ の各点を固定するからレトラクションになる。逆にレトラクション $R$ があれば、任意の初期値 $f$ と部分ホモトピー $h$ を $S$ 上で貼る。両部分は $A$ の閉性により $S$ で閉じているので貼った写像 $\Phi$ は連続である。$\Phi R$ が求める拡張になる。
:::

:::proposition[閉余ファイブレーションの近傍による判定]
閉部分空間 $A\subset X$ がホモトピー拡張性質を持つことは、連続な $u:X\to I$ と $h:X\times I\to X$ で次の条件を満たすものがあることと同値である。
$$
u^{-1}(0)=A,\qquad h(x,0)=x,\qquad h(a,t)=a,\qquad u(x)<1\ \Longrightarrow\ h(x,1)\in A.
$$
このような組が存在する $(X,A)$ を :term[NDR 対]{en="neighborhood deformation retract pair" yomi="えぬでぃーあーるつい"} という。
:::

:::proof
:ref[lem-at-hep-retraction] のレトラクションを $r(x,t)=(r_1(x,t),r_2(x,t))$ と書く。$h(x,t)=r_1(x,t)$ とし、$u(x)=\max_{t\in I}|t-r_2(x,t)|$ と置く。最大値は各 $x$ で存在し、$u$ は連続である。実際、$x$ の近くで上界を保つには、時刻ごとの連続性で得られる積近傍を $I$ 上で有限個選び、その第一座標の近傍を交わらせればよい。逆向きの下界は最大を達成する時刻を一つ固定して得られる。$a\in A$ では $r(a,t)=(a,t)$ だから $u(a)=0$ である。$x\notin A$ なら、$r_1(x,0)=x$ と $A$ の閉性から、十分小さい正の時刻で $r_1(x,t)\notin A$ である。レトラクションの像の条件からそこで $r_2(x,t)=0$ となり、$u(x)>0$ となる。また $u(x)<1$ なら $r_2(x,1)>0$ なので $h(x,1)\in A$ である。

逆に $u,h$ が与えられたら
$$
r(x,t)=
\begin{cases}
(h(x,t/u(x)),0), & u(x)>0,\ t\le u(x),\\
(h(x,1),t-u(x)), & t\ge u(x)
\end{cases}
$$
と置く。二式は重なる点で一致する。第二成分が正になるときは $u(x)<1$ なので、像は $X\times\{0\}\cup A\times I$ にある。底辺では $r(x,0)=(x,0)$、$A\times I$ では $r(a,t)=(a,t)$ となる。$u=0$ の点で第一式の商が不定にならないかを確認する。$h(a,s)=a$ が全時刻で成り立つため、$a$ の近くでは $h(x,s)$ は $s$ の選択によらず $a$ の任意の近傍に入る。これは区間のコンパクト性による。第二成分は $\max(0,t-u(x))$ で連続なので、$u=0$ の点でも二成分は連続である。従って求めるレトラクションとなる。
:::

:::example[端点で指定した円周値ホモトピー]
$X=I,A=\{0,1\}$ とし、$f(s)=1$、$h(0,t)=e^{2\pi it}$、$h(1,t)=1$ とする。例えば
$$
H(s,t)=e^{2\pi i(1-s)t}
$$
が拡張である。右端は全時刻で固定され、左端は時刻 $1$ で出発点へ戻る。従って終時刻の各端点は初期点と一致するが、道 $H(s,1)$ は負の向きに円周を一周する。端点が途中に動くホモトピーからは、初期と最後の道の端点相対ホモトピーは結論できない。
:::

:::example[時間途中からの延長]
$D^2$ 上で時刻 $0$ から $1/3$ まで連続な写像族 $H_0$ が与えられ、境界上だけ時刻 $1$ まで動きを指定したとする。境界の指定が $H_0$ の境界制限と一致すれば、$u=(3t-1)/2$ で $[1/3,1]$ を $I$ に取り替え、初期写像 $H_0(-,1/3)$ と境界値に :ref[thm-at-cw-hep] を適用する。$t=1/3$ の両側で同じ値を取るから、二つの時間帯を貼って全体で連続になる。例えば時刻 $t=2/3$ は新しい時刻 $u=1/2$ に当たる。
:::

:::example[接着写像を定値に動かしたときの延長]
$A\subset X$ を閉余ファイブレーションとし、$f:X\to Y$ の制限 $f|_A$ が $y_0$ に縮むとする。延長性質で $f$ から始まるホモトピーを作ると、終写像 $f_1$ は $A$ 上で $y_0$ に等しい。従って $f\simeq \bar f q$ と、$q:X\to X/A$ を経る代表を得る。例えば $A$ を四角形の周の三辺、$X$ を周全体とすると、$A$ は線分であり、$f|_A$ の縮約は端点の一方への線形変形を $f$ と合成して作れる。その結果、周全体での写像を、一本の辺だけに変化が集中する写像へ変形できる。
:::

### ホモトピー逆を変位レトラクションにする

:::proposition[閉余ファイブレーションと変位レトラクト]
閉余ファイブレーション $i:A\hookrightarrow X$ がホモトピー同値なら、$A$ は $X$ の変位レトラクトである。
:::

:::proof
ホモトピー逆 $g:X\to A$ を取る。$gi\simeq\id_A$ を、拡張性質により $g$ から出発する $A$ 値のホモトピーへ拡張する。その終写像 $r:X\to A$ は $A$ 上で恒等であり、$r\simeq g$ だから $ir\simeq\id_X$ である。

$H:\id_X\simeq ir$ を取る。$H(x,t)$ を実行した後、$H(ir(x),t)$ を逆向きに実行すると、再び $\id_X$ から $ir$ へのホモトピーを得る。$a\in A$ では $ir(a)=a$ なので、この新しいホモトピーは $H(a,-)$ の往復である。往復する長さを連続に零まで減らせば、始終を固定したまま全時刻の値を $a$ にできる。先に一点の場合に用いた正方形の整形と :ref[lem-at-hep-retraction] は、閉部分空間 $A$ に対してもそのまま使える。従ってこの変形を、$X\times\partial I$ を固定して $X\times I$ 全体へ拡張できる。終時刻の写像族が $A$ に相対的な $\id_X\simeq ir$ を与える。
:::

### 接着と変形を同時に扱う

:::proposition[余ファイブレーションの接着による保存]
$A\subset X$ は閉余ファイブレーション、$f:A\to Y$ は連続とする。$P=(X\amalg Y)/(a\sim f(a))$ を作ると、自然な包含 $Y\subset P$ は閉余ファイブレーションである。
:::

:::proof
任意の閉集合 $C\subset Y$ の像の商への逆像は $C$ と $f^{-1}(C)\subset A$ である。後者は $A$ の中で閉じ、$A$ は $X$ で閉じているので $P$ での像も閉である。包含は点集合として単射であるから閉埋め込みである。次に $P$ 上の初期写像 $g$ と $Y$ 上のホモトピー $h$ を取る。$X$ の初期写像は $X\to P\xrightarrow{g}Z$ とし、$A\times I$ では $h(f(a),t)$ を指定する。初期時刻に一致するため閉余ファイブレーションの条件で $X\times I$ 上へ延長できる。この延長と $h$ は全時刻にわたって商の関係を尊重する。商と区間の積は商写像なので、その両者は $P\times I$ 上の一つの連続写像に降りる。
:::

:::example[一枚の円板を貼った場合の拡張]
$S^1$ を $Y$ とし、$D^2$ を境界で $z\mapsto z^3$ に沿って貼る。初期写像を $P\to\C$ の定値 $0$ とし、$Y$ 上のホモトピーを $h(z,t)=tz$ とする。円板境界で必要な値は $tz^3$ である。円板の内部まで同じ多項式を使い、$\widetilde h(w,t)=tw^3$ とすれば全体の延長になる。例えば時刻 $1/2$、$w=i/2$ では値は $-i/16$ である。値域を $\C$ から変えたときにこの多項式が使えなくても、余ファイブレーションの定理は初期値と境界の動きに対する延長を保証する。
:::

:::example[境界での値を指定する拡張]
$I$ の両端を $A$ とし、$f:I\to\R$ を $x\mapsto x$ とする。$A$ 上で左端の値を $2t$、右端の値を $1-t$ と指定したとき、線形で内挿して $H(x,t)=2t(1-x)+x(1-t)$ と置ける。例えば $t=1/3$ では両端が $2/3$ となり、中間の全点も同じ値となる。しかし $t=2/3$ では左端は $4/3$、右端は $1/3$ であり、途中で順番が反転している。このホモトピーは連続写像の拡張であり、各時刻で単射となることまでは仮定していない。
:::

### 固定された部分と円柱のレトラクション

閉じた対 $(X,A)$ で、$X\times I$ の商に $A$ の時間軌跡をまとめたいとき、まず $X\times\{0\}\cup A\times I$ 上で値を作ればよい。:ref[lem-at-hep-retraction] によってそこへのレトラクションを一本求めれば、値域ごとに延長を作り直さずに済む。一方、レトラクションが存在しないことを示すときは、この部分空間自体を値域にすればよい。収束列の対の例では、その値域の中で $x=1/n$ の時間軌跡を動かせる方向がないことが連続性を妨げた。

:::example[円板で底に当たる場合と側面に当たる場合]
:ref[lem-at-disk-cylinder] の式を $n=2$ で用いる。$(x,t)=((1/4,0),3/4)$ では $\max((2-t)/2,\norm{x})=5/8$ なので、$\lambda=8/5$、像は $((2/5,0),0)$ である。これに対して $x=(3/4,0)$ とすると同じ時刻で分母は $3/4$、$\lambda=4/3$ なので $((1,0),1/3)$ に達する。二つの候補が等しくなる $\norm{x}=5/8$ では、像は底と側面の境目にある。このため場合分けを用いても連続な一本の写像が得られる。
:::

## 写像柱・写像錐と基点付き空間

:::definition[写像柱と写像錐]{#def-at-mapping-cylinder}
$f:X\to Y$ に対し $M_f=(X\times I\amalg Y)/((x,0)\sim f(x))$ を :term[写像柱]{en="mapping cylinder" yomi="しゃぞうちゅう"} と呼ぶ。さらに $X\times\{1\}$ を一点に潰した $C_f$ を :term[写像錐]{en="mapping cone" yomi="しゃぞうすい"} と呼ぶ。
:::

:::proposition[写像の分解]{#prop-at-cylinder-factor}
$f$ は $j:X\to M_f$、$x\mapsto[x,1]$ と $p:M_f\to Y$、$[x,s]\mapsto f(x)$、$p(y)=y$ の合成に分解する。$j$ は閉余ファイブレーションで、$p$ は $Y$ への変位レトラクトを与えるレトラクションである。
:::

:::proof
$j(X)$ の閉性と部分空間位相は商で調べる。閉集合 $B\subset X$ の像の逆像は $B\times\{1\}$ だけなので閉である。$[x,s]$ を $[x,(1-t)s]$ へ動かし、$Y$ を固定すると $p$ への変形になる。底で一致し、商と区間の積の性質で連続である。

$j$ の拡張性質を示すには、$I\times I$ の底辺と左右の側辺へのレトラクションを使う。:ref[lem-at-disk-cylinder] の $n=1$ を座標変換して得られる。底辺に初期写像、右側辺に $j(X)$ の上の変形、左側辺に $f(x)$ の初期値を全時間固定して指定する。レトラクションとの合成で円柱上に延長でき、左側辺を固定したので $Y$ 上の一定の変形と貼り合う。
:::

:::example[写像錐の三例]
$X\ne\varnothing$ とする。$f=\id_X$ なら $C_f=CX$ であり、$[x,s]\mapsto[x,s+t(1-s)]$ で頂点に縮められる。$X\to\{*\}$ の写像錐は $SX$ である。$n\ge1$ で $S^{n-1}\hookrightarrow D^n$ の写像錐は、$D^n$ と別の $D^n=CS^{n-1}$ を境界で貼るので $S^n$ になる。
:::

:::definition[基点付きホモトピー]{#def-at-based-homotopy}
空間とその点の組 $(X,x_0)$ を :term[基点付き空間]{en="pointed space" yomi="きてんつきくうかん"} と呼ぶ。基点付き写像は基点を基点へ移し、基点付きホモトピーは全時間にわたって基点の像を固定する。基点付き写像のホモトピー類の集合を $[X,Y]_* $ と記す。$S^1\wedge X$ を被約懸垂と呼ぶ。
:::

被約懸垂は $X\times I$ の両端と $\{x_0\}\times I$ を一つの点に潰した空間である。CW 複体 $X$ の頂点を $x_0$ に取ると、通常の懸垂から被約懸垂への商は区間の部分複体を潰す。そのため :ref[cor-at-collapse-contractible] によりホモトピー同値である。基点の軌跡に注意すると、[基本群](/math/algebraic-topology/fundamental-group/) で扱う端点相対の道の変形に進める。

### 接着写像を変形したときの写像錐

:::proposition[写像錐の接着写像への依存]
$f,g:X\to Y$ がホモトピックなら $C_f$ と $C_g$ は $Y$ を固定するホモトピー同値で結ばれる。
:::

:::proof
$H(x,s)$ を $f$ から $g$ へのホモトピーとする。$C_f$ の錐座標 $t\le1/2$ では $H(x,2t)\in Y$ に、$t\ge1/2$ では $[x,2t-1]\in C_g$ に送る。$t=1/2$ で値は $g(x)$ となり一致する。底面で $f(x)$ を保ち、頂点も頂点へ送るため商に降りる。$Y$ 上は恒等である。逆向きは $H(x,1-s)$ で同じ式を作る。

合成では、錐の初めの部分を $H$ とその逆に沿って移し、続いて残りで錐を進む。$H$ とその逆を続けた道は、$s=1$ まで進む代わりに $s=1-u$ まで進んで戻る式で縮む。$u=1$ で錐の初めの区間は $f(x)$ にとどまる。その後にこの区間の長さを零へ縮め、残りの区間の錐座標を線形に伸ばせば恒等写像へのホモトピーになる。すべての接続時刻で値が一致し、底と頂点への同一視が保たれるため連続である。逆順の合成も同様に縮む。
:::

:::example[定値写像で接着する]
定値写像 $f:X\to Y$ の値を $y_0$ とすると、$C_f$ では錐の底面が $y_0$ にまとまる。そのため通常の懸垂 $SX$ の一方の端点を $Y$ の $y_0$ と貼ったウェッジ和と同じ商である。例えば $X=S^1$、$Y=S^1$ なら $S^1\vee S^2$ になる。これに対して恒等写像に沿って貼ると $CS^1\cong D^2$ になる。接着前の二空間が同じでも、接着写像によって結果が変わる。
:::

### 余ファイバーを二回取る

:::proposition[写像錐の商と次の錐]
$f:X\to Y$ に対し、$X,Y$ は空でないとする。$C_f/Y$ は $SX$ と同相である。$X,Y$ が CW 複体で、$f$ が各骨格を対応する骨格に送るとする。このとき $Y\hookrightarrow C_f$ の写像錐は $SX$ とホモトピー同値である。
:::

:::proof
第一の商では $X\times\{0\}$ が $Y$ とともに潰れ、$X\times\{1\}$ は元から別の点になっている。残る同一視は懸垂の定義である。第二の主張では $C_f$ の胞体分解を使う。$Y$ と錐の頂点のほか、$X$ の各 $n$ 胞体に対応する $n+1$ 胞体を取る。閉 $n$ 円板の錐は閉 $n+1$ 円板と境界を保って同相であり、その底は $Y^n$ に、側面はより低次元の錐に入る。商の構成が弱位相を与えるので $Y$ は部分複体である。$Y$ の写像錐には付け加えた $CY$ が可縮な部分複体として入る。それを潰すと $C_f/Y$ となり、:ref[cor-at-collapse-contractible] が適用できる。
:::

:::example[二点から一点への写像の余ファイバー]
$f:S^0\to\{*\}$ の写像錐では二本の錐の母線が共通の底点と頂点を持つので $C_f\cong S^1$ である。$S^1$ に含まれる $Y$ は底点一個であり、それを潰す商は $S^1$ のままである。もし $f$ を $S^0$ の恒等写像に替えると、二本の母線の底点は別々のままなので $C_f$ は閉区間になる。ただし二つの底点 $Y=S^0$ を潰せば円周になり、第二の錐のホモトピー型はどちらの場合も $S^1$ となる。
:::

:::example[基点の軌跡が閉曲線になる場合]
基点 $1$ を持つ $S^1$ から自分自身への恒等写像について、$H(z,t)=ze^{2\pi it}$ は恒等写像から恒等写像へのホモトピーである。$H$ は基点付きホモトピーではない。例えば時刻 $1/4$ の基点の像は $i$ である。一方、同じ始写像と終写像には $K(z,t)=z$ という基点付きホモトピーが存在する。この例では写像の両端が基点を保つことと、指定されたホモトピー自身が基点を保つことを区別する。
:::

### 写像錐が表す延長条件

:::proposition[合成の縮約と写像錐]
空でない $X,Y$ と連続写像 $f:X\to Y$、$g:Y\to Z$ に対し、$g$ が $C_f$ に連続に延長できる必要十分条件は $gf$ が定値写像にホモトピックであることである。
:::

:::proof
写像錐は $Y$ と $X\times I$ の貼り合わせであり、$t=0$ に $f$、$t=1$ に頂点の同一視がある。$C_f$ 上の延長から円柱への制限を取ると、$t=0$ が $gf$、$t=1$ が頂点の値のホモトピーになる。逆にこのようなホモトピーを $Y$ 上の $g$ と合わせると、底面では境界条件が合い、上端では値が一定なので商に降りる。
:::

:::example[写像錐への延長を異なる写像で比べる]
$f:S^1\to S^1$ を $f(z)=z^3$ とし、$g(z)=z^{-2}$ とする。合成は巻き数 $-6$ を持つので、[円周の基本群](/math/algebraic-topology/fundamental-group/) の計算により定値にホモトピックではなく、$g$ を $C_f$ まで円周値で延長できない。同じ $g$ を $\C$ 値として扱うと、$gf$ を $H(z,t)=(1-t)z^{-6}$ で零へ縮められる。この場合はそのままホモトピーを円錐部分の値にして延長できる。写像錐は同じであっても、延長の可否は値域で可能な変形に依存する。
:::

### 被約懸垂の写像を道の族として読む

:::proposition[懸垂とループの対応]
$X,Y$ を基点付き空間とする。$Y$ の基点を両端に持つ道の全体を $\Omega Y$ と書き、コンパクト開位相を入れる。$S^1\wedge X$ から $Y$ への基点付き写像と、$X$ から $\Omega Y$ への基点付き写像は一対一に対応する。この対応は基点付きホモトピー類でも全単射になる。
:::

:::proof
懸垂上の写像を $X\times I$ に引き戻すと、$t=0,1$ と $x=x_0$ で値が基点になる。従って $x$ ごとに $t$ の道を取り出すと、基点を保つ $\Omega Y$ 値写像になる。区間は局所コンパクト Hausdorff なのでコンパクト開位相の随伴により連続である。逆に $x$ にループ $\lambda_x$ が連続に対応すれば、評価の連続性から $(x,t)\mapsto\lambda_x(t)$ が連続である。基点条件により潰す集合全体で同じ値を取るので、被約懸垂へ降りる。構成は互いに逆である。ホモトピーの追加時刻についても同じ方法を使う。評価は三変数で連続であり、懸垂の商と追加時刻の積が商写像であるため、ホモトピーは基点を固定したまま降りる。
:::

:::example[基点付き二点空間からの写像]
$X=S^0=\{*,a\}$ なら $\Sigma X$ は円周である。実際、$a$ の区間の両端が共通の点に潰れ、$*$ の区間は全体が潰れる。上の対応で $\Omega Y$ 値写像は $a$ に任意のループを選ぶことに当たる。例えば $Y=S^1$ とし、$a$ を $t\mapsto e^{4\pi it}$ へ送ると、$\Sigma X\to S^1$ は巻き数二の写像となる。$a$ に逆向きのループを選べば巻き数は $-2$ になる。被約懸垂の基点を指定したことで、ループの両端も始めから指定されている。
:::

## 演習問題

::::exercise{level=basic}
$[0,6]$ を点 $2$ に縮約し、時刻 $3/4$ における点 $6$ の像を求めよ。
:::solution
$H(x,t)=(1-t)x+2t$ は区間内にあり、$2$ を固定する。$H(6,3/4)=6/4+6/4=3$ である。
:::
::::

::::exercise{level=basic}
$S^1\times[1,3]$ を下端の円周へ変位レトラクトさせよ。
:::solution
$H((z,s),t)=(z,(1-t)s+t)$ と置く。第二座標は $1$ から $3$ の間にあり、$s=1$ の点は固定され、$t=1$ で全点が下端に入る。
:::
::::

::::exercise{level=basic}
正方形から作るトーラスで、二つの $1$ 胞体の和を一点に潰した商を求めよ。
:::solution
角は一つの頂点であり、正方形の境界全体が二つの辺に写る。二つの辺を潰す商は正方形の境界を一度に潰す商と同じ普遍性を持つ。正方形は閉円板に同相なので商は $S^2$ である。
:::
::::

::::exercise{level=basic}
$S^2*S^3$ と $S^2\wedge S^3$ を求めよ。
:::solution
前者では $(x,y)$ が $\R^3\oplus\R^4$ の単位球面を与えるので $S^6$ である。後者は積円板 $D^2\times D^3$ の境界商であるため $S^5$ である。
:::
::::

::::exercise{level=advanced}
空でない可縮空間 $X$ から $Y$ への任意の写像が定値写像にホモトピックであることを示せ。
:::solution
縮約 $H$ が $\id_X$ を $x_0$ に変形するなら、$fH$ は $f$ を $f(x_0)$ に変形する。定値写像同士がホモトピックであるための必要十分条件は値が同じ道成分に入ることである。必要性は $x_0$ における軌跡、十分性は $x$ に依存しないホモトピーによる。
:::
::::

::::exercise{level=advanced}
$X$ と $Y$ がともに可縮なら $X\times Y$ が可縮であることを示せ。
:::solution
それぞれの縮約を $H,K$ とすると $((x,y),t)\mapsto(H(x,t),K(y,t))$ が積を点に縮める。逆に積が可縮で両因子が空でなければ、$y_0$ を固定した切断から積へ入り、縮約の後で第一射影を取ると $X$ の縮約を得る。第二因子にも同じ構成を使える。
:::
::::

::::exercise{level=advanced}
$A$ が CW 部分複体であるとき、$X/A$ が商と両立する胞体構造を持つことを示せ。
:::solution
$A$ が空でなければ新しい頂点を一個置く。$A$ に含まれない各胞体を維持し、その接着写像を元の接着写像と下の商写像の合成にする。得られた空間からの写像は各残存特性写像と新頂点によって連続性が判定される。これは $X$ からの $A$ 上一定の連続写像の条件に一致する。閉包有限性は元の有限部分複体の像から従う。Hausdorff 性を示すため、商の異なる二点を選び、それらの逆像に値 $0,1$ を指定する。$A$ 上の値は一定とし、各残存円板で境界から値を延長する。内部に指定点があれば、互いに素な小球で値を局所的に調整する。弱位相で得られる連続関数は $A$ 上で一定なので商へ降り、選んだ二点を分離する。
:::
::::

::::exercise{level=advanced}
任意の $f:X\to Y$ に対し、$Y\hookrightarrow M_f$ と $p:M_f\to Y$ の双方がホモトピー同値であることを示せ。
:::solution
$p$ は $Y$ 上で恒等である。$p$ を包含と合成した写像は $[x,s]$ を $f(x)$ へ移す。$[x,s]\mapsto[x,(1-t)s]$ と $y\mapsto y$ を貼ると恒等写像からこの合成へのホモトピーになる。よって両写像は互いのホモトピー逆である。
:::
::::

## 確認テスト

::::quiz

- [ ] $X$ は常に可縮である。

$S^3*S^3$ の球面としての次元を答えよ。
:::explanation
それぞれの球面は $\R^4$ の単位球面である。結は $\R^4\oplus\R^4$ の単位球面になるため次元は $8-1=7$ である。
:::

::::quiz{answer="5" tol="0"}
$S^2\wedge S^3$ の球面としての次元を答えよ。
:::explanation
積円板 $D^2\times D^3$ の境界を潰すと五次元球面になる。
:::
