## この章の目標

- 立方体モデルで高次ホモトピー群と可換性を説明する。
- 相対ホモトピーの接続写像と胞体近似を使う。
- Whitehead の定理で弱ホモトピー同値を判定する。
- 懸垂と Hurewicz 同型から球面の群を計算する。

## ホモトピー群の定義と可換性

:::definition[高次ホモトピー群]{#def-at-homotopy-group}
$n\ge1$ とする。対の写像 $(I^n,\partial I^n)\to(X,\{x_0\})$ を境界相対ホモトピーで割った集合を :term[ホモトピー群]{en="homotopy group" yomi="ほもとぴーぐん"} $\pi_n(X,x_0)$ と書く。境界を潰すと $I^n/\partial I^n\cong S^n$ なので、基点付き球面写像の類ともみなせる。第一座標方向の連結を積とする。
:::

再パラメータ化の線形補間は他の座標を変えないので、基本群と同じ理由で結合律、単位元、逆元がある。逆元は第一座標を $1-t$ に置き換えて表現する。

:::theorem[Eckmann–Hilton の議論]{#thm-at-eckmann-hilton}
$\pi_n(X,x_0)$ は $n\ge2$ で可換群である。
:::

:::proof
第一と第二の座標の連結を $\cdot$、$\star$ とする。同じ四分割を横から作るか縦から作るかにより
$$
(a\cdot b)\star(c\cdot d)=(a\star c)\cdot(b\star d)
$$
が成り立つ。両演算の単位元 $e$ は定値写像である。$(a\cdot e)\star(e\cdot b)=a\cdot b$ なので両演算は一致する。一方 $(e\cdot a)\star(b\cdot e)=b\cdot a$ なので同じ積は可換である。
:::

:::example[積と被覆]
積空間の立方体写像とそのホモトピーは成分ごとの組であるから $\pi_n(X\times Y)\cong\pi_n(X)\times\pi_n(Y)$ である。被覆 $p:E\to X$ は $n\ge2$ で $\pi_n$ の同型を誘導する。立方体の写像は単連結な定義域からなので :ref[thm-at-lifting-criterion] で持ち上がる。境界は連結で離散ファイバーへ行くため定値である。ホモトピーも :ref[thm-at-cover-lifts] で境界の値を保って持ち上がる。従って $\pi_n(S^1)=0$ と $\pi_n(T^2)=0$ が $n\ge2$ で成り立つ。
:::

:::example[左右と上下の和を同じ写像から得る]
基点付き $S^2$ への写像を四角形の境界を一点に潰す古典的モデルで書く。小四角形を四つ置き、左下と右上だけに同じ代表 $f$ の縮尺版を置き、他を基点にする。縦に読めば第一方向での和、横に読めば第二方向での和である。二つの読み方とも、間に挟まった定値写像を再パラメータ化で除くと $2[f]$ を表す。このように Eckmann–Hilton の交換式では、小四角形に移した写像同士が境界の基点で一致することが必要である。球面の写像度を評価すると、$f$ の度が $3$ の場合にこの和は $6$ となる。
:::

### 基点を動かすときの基本群の作用

:::proposition[道による高次群の輸送]
道 $\gamma:x_0\to x_1$ は $n\ge2$ に対し $\tau_\gamma:\pi_n(X,x_1)\to\pi_n(X,x_0)$ を誘導する。輸送は端点相対ホモトピー類だけで決まり、$\tau_{\gamma*\eta}=\tau_\gamma\tau_\eta$ である。特に基点を一周する道は $\pi_n(X,x_0)$ に自己同型として作用する。
:::

:::proof
球面の写像を $(D^n,S^{n-1})\to(X,x_1)$ として表す。半径 $1/2$ の内側にその代表を縮尺して置き、外側の襟の半径 $r$ の点を $\gamma(2-2r)$ に送る。$r=1/2$ で $x_1$、$r=1$ で $x_0$ になるので貼り合わせは連続である。代表や道をホモトピックなものに替えたときは、円板部分または襟だけホモトピーを進めればよい。二つの道を順に使った場合は襟が二重になり、内側から $\bar\eta$、$\bar\gamma$ の順に進む。半径を再パラメータ化して一つの襟に読み直すと $\gamma*\eta$ の輸送と同じになる。定値道では余分な襟を縮めて元の写像になり、逆道は逆の輸送を与える。

群演算を比較するには、二つの代表の内側部分を互いに素な二小円板へ写すピンチ写像を使う。各小円板に襟を付けた和と、大きい円板の外だけに襟を付けた和の間で、各角をつなぐ領域には $\gamma$ の像を通る写像を置く。具体的には、二小円板上の代表は固定し、その補集合では最初と最後の襟の時刻を二つの連続な $I$ 値関数として取る。小円板の境界では両方とも $1$、大円板の境界では両方とも $0$ である。二つの時刻関数の線形補間を $\gamma$ と合成すると境界を固定したホモトピーを与える。従って輸送は和を保つ。
:::

:::example[実射影平面における反転作用]
$\R P^2$ の普遍被覆は $S^2$ である。基点の一方の持ち上げから見て $\pi_2(\R P^2)$ の元を、持ち上げた球面写像の写像度で表せる。底の非自明なループは持ち上げると反対点へ進むので、基点を元の持ち上げに戻して比較するには対蹠写像を取る。対蹠写像の写像度は $-1$ であり、球面で基点を移すだけの操作は度を変えない。従って $\pi_1=\Z/2$ の非自明な元は $\pi_2=\Z$ に符号反転で作用する。例えば $3$ を表す球面写像はこの輸送で $-3$ を表す。
:::

:::example[被覆で高次の代表を持ち上げる]
$p:E\to X$ を被覆とする。$n\ge2$ なら $S^n$ は単連結なので、基点 $e$ を選ぶと任意の基点付き球面写像 $S^n\to X$ は $E$ に一意に持ち上がる。基点付きホモトピーも初期の持ち上げから持ち上がり、基点の時間軌跡は離散ファイバー内で一定となる。逆に持ち上げた二つの代表の射影が基点付きでホモトピックなら、そのホモトピーの終時刻は指定された基点での一意性によって第二の代表になる。従って $p_*$ は $n\ge2$ で同型である。例えば $\R P^4$ では、$\pi_2,\pi_3$ は零、$\pi_4=\Z$ である。基本群では $\pi_1(S^4)=0$ から $\pi_1(\R P^4)=\Z/2$ への写像なので、この同型は一度下の次数では成り立たない。
:::

:::example[高次群と積の射影]
二つの基点付き空間の積への球面写像は、二つの成分への球面写像の組である。ホモトピーと立方体の連結も成分ごとに取れるため、$\pi_n(X\times Y)\cong\pi_n(X)\times\pi_n(Y)$ である。例えば $S^1\times S^3$ では $\pi_1=\Z$、$\pi_2=0$、$\pi_3=\Z$ である。$\pi_3$ の生成元は第二因子の包含である。第一因子の円周を一周しても、第二因子の写像を全時刻で保つ基点変更を作れるため、$\pi_1$ の $\pi_3$ への作用は自明である。ウェッジでは、円周を持ち上げたとき球面が別の頂点へ移る例と対照的である。
:::

:::example[基本群が球面の持ち上げを移す場合]
$X=S^1\vee S^2$ の普遍被覆は、整数を頂点とする実直線の各頂点に二球面を一つ貼った空間である。直線を円周へ送り、各球面を元の一つの球面へ恒等に送ると被覆になる。直線を潰すと球面の可算楔和とホモトピー同値になり、その二次ホモロジーは $\bigoplus_{j\in\Z}\Z e_j$ である。Hurewicz 同型と被覆の持ち上げから、これが $X$ の $\pi_2$ を与える。円周を一回進むループに対応する被覆変換は頂点 $j$ を $j+1$ へ移すので、基本群の作用は、生成元をその変換に対応させれば $e_j\mapsto e_{j+1}$ である。例えば $2e_0-e_1$ は $2e_1-e_2$ に移る。球面一つの写像を基点から測った位置は違いを生むので、$\pi_2$ が可換でも基本群の作用は自明とは限らない。
:::

## 相対ホモトピー群と対の長完全列

:::definition[相対ホモトピー群]{#def-at-relative-pi}
$A\subset X$、$x_0\in A$ とする。$I^n$ の上面 $F=I^{n-1}\times\{1\}$ を $A$ へ送り、残りの境界面の合併 $J$ を $x_0$ に送る写像を、その条件を保つホモトピーで割る。これを $\pi_n(X,A,x_0)$ とする。$n\ge2$ では上面と平行な第一座標で積を取る。$n\ge3$ では上面と平行な座標が二つ以上あるので可換である。$n=1$ では基点付き集合として扱う。
:::

:::theorem[対のホモトピー長完全列]{#thm-at-relative-pi-exact}
包含、相対化、上面への制限で
$$
\cdots\to\pi_n(A)\to\pi_n(X)\to\pi_n(X,A)
 \xrightarrow{\partial}\pi_{n-1}(A)\to\pi_{n-1}(X)\to\cdots
$$
は完全である。末端は $\pi_1(X)\to\pi_1(X,A)\to\pi_0(A)\to\pi_0(X)$ である。群を持たない項での完全性は、基点の逆像と直前の写像の像が一致するという意味である。
:::

:::proof
相対写像の上面は $X$ 内で残りの立方体によって縮む。逆に $A$ の上面の写像が $X$ で縮むなら、その縮小を立方体へ入れて相対類を得る。相対写像の上面が $A$ で縮む場合は上にその縮小の立方体を足す。再パラメータ化により同じ相対類を表し、上面が定値になったので絶対類から来る。最後に絶対類が相対的に零になる場合、相対ホモトピーの上面に現れる $I^{n-1}\times I\to A$ は境界で定値である。その立方体を逆向きに付ければ、絶対類と $A$ から来る類の差を絶対的に縮められる。これはホモトピーの $(n+1)$ 立方体の境界で、非定値の二面が同じ類を表すという関係である。逆向きの包含は、$A$ 内の写像を上面へ押し出せば相対的に零になることから従う。$n=1$ の終端では、基点から $A$ への道をその終点の道成分へ送り、$A$ 内で終点を基点へ戻せることが核の条件になる。
:::

:::example[円板対の相対群]
$D^n$ は可縮なので、$n\ge2$ なら $\pi_n(D^n,S^{n-1})\cong\pi_{n-1}(S^{n-1})$ である。特に $n=2$ で、この同型は円板の恒等写像を円周の巻き数一のループへ送る。
:::

:::example[円板対の接続が同型になる理由]
$n\ge2$ とし、$(D^n,S^{n-1})$ の長完全列を取る。可縮な $D^n$ ではすべての正次数の群が消えるので、$\partial:\pi_n(D^n,S^{n-1})\to\pi_{n-1}(S^{n-1})$ は同型である。円板の恒等写像の境界を読むモデルは、相対立方体の一面から境界球面へ写る代表を選び直したものであり、その像は球面の恒等類である。例えば $n=2$ の相対群は $\Z$ で、境界は円周の巻き数を返す。円板内ではそのループ自体が縮むことと、相対群に生成元として残ることは完全列の中で両立する。
:::

:::example[対の完全列で接着の境界を読む]
$X=S^2\cup_f D^3$ を写像度 $m$ の $f$ で作り、$A=S^2$ とする。相対三次の特性写像を、立方体の基点部分を潰すモデルで表せば、$\partial$ は $f$ の類を返す。従ってこの特性写像の境界は $\pi_2(A)=\Z$ の $m$ である。相対 Hurewicz により特性写像の類は $\pi_3(X,A)$ の生成元になるので、$\pi_2(A)\to\pi_2(X)$ の核は $m\Z$ になる。また二胞体より高い相対胞体しかないので、包含は $\pi_2$ で全射である。例えば $m=-4$ でも核は $4\Z$ であり、向きに依存しない商 $\Z/4$ が残る。この例では相対の接続は、絶対群でどの倍数を殺したかを表している。
:::

:::example[境界を共有する二枚の円板が違いを表す]
$A=S^2\subset X=S^2\vee S^3$ とする。$X$ の三胞体は定値で貼ったので、その相対三次特性写像の境界は $\pi_2(A)$ で零になる。従って対の長完全列では特性写像の相対類は、$X$ に含めた $S^3$ の絶対三次類から来る。一方、同じ三胞体を度 $2$ の写像で貼ると、相対三次の境界は $2\in\Z$ になる。相対類は依然として円板で表せるが、今度は絶対三次類で表すことができない。境界の零非零は、円板を球面へ閉じられるかを測る。
:::

:::example[球面と積を比べる相対群]
$(X,A)=(S^2\times S^2,S^2\vee S^2)$ とする。相対胞体は四胞体一つなので、対は三連結で相対 $\pi_4$ は相対 Hurewicz により $\Z$ である。この生成元の境界は頂次胞体の接着写像 $\omega$ である。完全列から $\pi_3(A)\to\pi_3(X)$ は全射で、その核は $\omega$ の生成する部分群になる。二つの射影で $\omega$ の成分は零である。このため $\pi_3(X)$ に移して各因子の群だけを計算すると、ウェッジでの付着の情報は消える。$\omega$ が非零であることは積のカップ積で検出でき、その非零性はこの核が実際に存在することを示す。
:::

## 胞体近似定理と CW 近似

:::definition[胞体写像]{#def-at-cellular-map}
CW 複体間の写像 $f$ で $f(X^n)\subset Y^n$ を全 $n$ について満たすものを :term[胞体写像]{en="cellular map" yomi="ほうたいしゃぞう"} という。
:::

:::lemma[高次胞体の一点を避ける]{#lem-at-avoid-open-cell}
写像 $D^n\to Y^m$ の境界が $Y^{n-1}$ に入るとする。$m>n$ の開 $m$ 胞体内のある点を避けるように、この写像を境界相対で変形できる。
:::

:::proof
胞体の内部に座標球で同心の閉球 $B_1\subset\operatorname{int}B_2$ を取る。その逆像は円板内部のコンパクト部分にある。$B_2$ の内側の座標関数を、そこで必要なコンパクト近傍に制限して円板全体の連続実数値関数へ延長する。各成分は個別に延長できる。円板を有限単体分割して十分細分し、各頂点の値を線形補間すると一様近似が得られる。$B_1$ の逆像の近くで近似と置き換え、その外では連続な切替関数で元の写像へ戻す。切替領域を $B_1$ から正距離のある帯に選び、近似誤差をその距離より小さくすれば、$B_1$ のさらに内側への逆像は線形近似の部分に限られる。線形近似の像は有限個の高々 $n$ 次元のアフィン部分空間に含まれる。$m>n$ なので、それらを避ける点が $B_1$ の内側にある。補間のホモトピーは同じ胞体の座標内で行い、境界を固定する。
:::

:::theorem[胞体近似]{#thm-at-cellular-approximation}
CW 複体間の写像は胞体写像にホモトピックである。部分複体上で既に胞体写像なら、その部分を固定できる。
:::

:::proof
まず一つの $n$ 胞体の円板で境界が $Y^{n-1}$ に写る場合を考える。コンパクト性により像は有限部分複体に入る。最高次の各胞体で :ref[lem-at-avoid-open-cell] を使い一点を避ける。穴を開けた円板は放射状に境界へ変位レトラクトし、下の骨格は固定される。そのため最高次を消し、同じ手順を $n+1$ 次まで繰り返せる。$n=0$ でも同じ議論で頂点まで移せる。

$X$ の $n$ 胞体ごとにこの手順でホモトピーを作り、境界上で固定して貼り合わせる。次元ごとのホモトピーを :ref[thm-at-cw-hep] で $X$ 全体に延長し、既に処理した骨格と指定した部分複体を保つ。時刻 $1-2^{-n-1}$ までに $n$ 骨格を処理すると、各閉胞体上では以後その写像は一定である。時刻 $1$ の写像も各円板上に定まり、弱位相と区間との積で連続になる。
:::

:::proposition[CW 近似]{#prop-at-cw-approximation}
任意の道連結空間 $Y$ に対し、道連結 CW 複体 $X$ から $\pi_n$ の同型を全て誘導する写像 $f:X\to Y$ がある。$Y$ が $(r-1)$ 連結、$r\ge2$ なら、$X$ は一頂点と $r$ 次元以上の胞体だけで作れる。
:::

:::proof
一点から始める。写像の $\pi_1$ の全射性を得るには代表ループの円周を付け、核の代表ループに零ホモトピーを選んで円板を接着する。一般の段階ではまず $n$ 次の全射性を得るため、$n$ 球面をウェッジし代表写像を指定する。次に核の各元を境界とする $(n+1)$ 胞体を接着し、選んだ零ホモトピーで $f$ を延長する。胞体近似を円板と球面に適用すると、$n$ 次元より高い胞体の追加は $\pi_n$ への全射性を保ち、$n+1$ 次元より高い追加は $\pi_n$ の同型を保つ。核の段階で元の $\pi_n$ の核の全てが消され、新しい $\pi_n$ の元は $n$ 骨格に近似できるため増えない。従って段階を上げて全次数の同型を得る。無限段階で各代表とホモトピーが有限骨格に入ることは :ref[lem-at-cw-compact] による。連結性の仮定がある場合、$n<r$ で代表を補う必要はない。
:::

:::example[積への包含が低次の群を変えない範囲]
$S^2\times S^3$ の胞体分解は次元 $0,2,3,5$ に一胞体ずつを持つ。$S^2\vee S^3$ は五胞体を除いた部分複体である。$\pi_i$ の代表に $i$ 次元球面の胞体近似を施すと、$i\le4$ では五胞体を通らなくてよい。二つの代表をつなぐホモトピーは次元 $i+1$ の CW 対から来るので、$i\le3$ ならそれも五胞体を避けられる。よって包含は $\pi_i$ で $i\le3$ の同型と、$\pi_4$ の全射を与える。この差は代表とその関係を調べる空間の次元が一つ違うことに対応する。
:::

:::example[相対条件を固定した胞体近似]
立方体の縁を二次球面へ値を持つ既存の写像で送り、立方体全体の写像が四次元の CW 複体に入るとする。より具体的に $Y=S^2\vee S^4$、$X=D^3$、$A=S^2$ とし、境界の写像が $Y$ の二骨格に入る場合を考える。境界の胞体写像を既に固定していれば、胞体近似により全体を $Y^3=S^2$ に値を取るように変形できる。従って四次球面の部分に値を取る自由があっても、度 $1$ の境界写像をこの値域に延長することはできない。もし延長があれば、変形後に $S^2$ 値の延長ができ、境界の度が零となるはずだからである。
:::

:::proposition[高次胞体を貼ったときに群を保つ範囲]
CW 対 $(X,A)$ で、$X$ が $A$ に次元 $d$ 以上の胞体だけを貼ったものであり、$d\ge2$ とする。包含は $\pi_i(A)\to\pi_i(X)$ で $i\le d-2$ に同型、$i=d-1$ に全射を誘導する。
:::

:::proof
基点は $A$ の頂点に取る。任意の $i$ 次の絶対代表は $i$ 球面を一点と一個の $i$ 胞体で作った基点付き写像である。胞体近似を、$A$ の側の任意の既存の胞体構造を含む相対骨格に対して使う。相対胞体を避けるという近似は通常の証明と同じく、代表の像を含む有限部分複体の高次胞体の内部を最高次から順に押し出す。代表の次元 $i<d$ ならすべての相対胞体を避けられる。既に $A$ に入る二つの代表をつなぐホモトピーでは、定義域の次元は $i+1$ である。両端と基点の円柱を固定したまま同じ押し出しを行い、$i+1<d$ なら全時刻の像を $A$ に入れられる。よって全射性と単射性には次元が一つずれた条件が得られる。
:::

:::example[低い骨格だけを使って写像を作る]
$Y$ を単連結で $\pi_2(Y)=A$ とし、定義域を一頂点と二つの二胞体からなる $S^2\vee S^2$ とする。各二胞体を境界相対に送る値として $a,b\in A$ を選べば、一つの写像が作れる。異なる代表を取っても球面上の基点付きホモトピーを貼れるため、写像類は $(a,b)$ で決まる。次に三胞体を度の組 $(2,3)$ で貼ると、境界の像が $2a+3b$ になり、その元が零の場合に限って写像を三胞体へ伸ばせる。例えば $A=\Z/6$、$(a,b)=(3,2)$ では $2a+3b=12=0$ となる。$(1,0)$ では $2$ が残るので延長できない。この手順は [障害理論](/math/algebraic-topology/eilenberg-maclane/) で各段階に広げられる。
:::

## Whitehead の定理

:::theorem[Whitehead]{#thm-at-whitehead}
CW 複体間の写像 $f:X\to Y$ が道成分の全単射と、全ての基点で $n\ge1$ の $\pi_n$ の同型を誘導すれば、$f$ はホモトピー同値である。
:::

:::proof
胞体近似をして $f$ を胞体写像にする。写像柱 $M_f$ は、$Y$ の胞体と、$X$ の上端の胞体、各 $X$ の胞体の円柱の内部で作る CW 複体である。円柱の側面は低次の円柱へ、底面は胞体性で同次以下の $Y$ へ行く。上端 $X$ は部分複体である。写像柱が $Y$ に変位レトラクトすることと対の長完全列から $\pi_n(M_f,X)$ は全て自明である。

$\id_{M_f}$ を $X$ 上固定して、各胞体の像を $X$ へ順に押し込む。頂点は対応する道成分内の道で $X$ に移せる。$n$ 胞体のとき先に境界のホモトピーを円板へ延長し、終時刻で境界が $X$ に入る写像を得る。相対立方体の $J$ を北半球に対応させた上で、境界球面の北極からの角 $\theta$ を $\max(0,2\theta-\pi)$ へ動かす。角の線形補間を円板の放射方向に延ばすと、境界の像が $X$ に入る条件を保って $J$ 上定値な相対写像に変形できる。$n=1$ では底点をそのまま基点にする。$\pi_n(M_f,X)=0$ なので、境界を $X$ 内で動かしながら円板写像を $X$ に押し込める。

最初の境界を固定するには、まず円板写像を小さい内側の円板へ縮尺し、境界値を外側の襟に放射状に引き戻す。その形への変形は境界を固定して行える。次に内側の円板で先ほどの相対ホモトピーを行い、外側の襟では時刻を内側の $t$ から外端の $0$ へ線形に減らして同じ境界ホモトピーを使う。終時刻では内側も襟も $X$ に入り、外端では元の値のままである。従って胞体ごとに前の骨格を固定できる。:ref[thm-at-cellular-approximation] と同じ時間分割と拡張で全空間の変形が得られる。この変形と $M_f\simeq Y$ を合わせると $f$ はホモトピー同値である。
:::

:::proposition[弱ホモトピー同値と特異ホモロジー]{#prop-at-weak-equivalence-homology}
任意の空間の間の弱ホモトピー同値は、任意の Abel 群を係数とする特異ホモロジーとコホモロジーの同型を誘導する。
:::

:::proof
写像を写像柱の上端の包含 $X\hookrightarrow M_f$ に置き換える。対のホモトピー長完全列からこの対の相対群は全て自明である。Whitehead の定理の証明にある胞体ごとの押し込みは、値域の対が CW 対でなくても使える。実際、必要なのは相対ホモトピー群が消えることと、定義域の CW 対のホモトピー拡張性質である。従って任意の CW 対 $(K,L)$ から $(M_f,X)$ への写像は、$L$ 上を固定して全体が $X$ に入るように変形できる。まず頂点を $X$ へ向かう道で動かし、各円板で境界を固定した押し込みを行えばよい。

有限個の特異 $n$ 単体からなる相対輪体 $z$ を取る。その鎖に現れる各単体のコピーを用意し、同じ特異面を表す $(n-1)$ 面を頂点順序を保って全て同一視する。低い面の同一視もこれに従うため、有限 Δ 複体 $K$ が得られる。各特異単体は貼り合わせて $K\to M_f$ を作り、$z$ の係数で $K$ の各特性単体を足した鎖は $z$ に写る。同じ特異面の係数は $K$ でも合算されるので、その境界の支えは $X$ に写る部分複体 $L$ に入る。従って $[z]$ は $(K,L)$ の相対類の像である。上で示した押し込みで写像を $X$ に値を取るものへ変形すると、相対群への像は零になる。このため $H_n(M_f,X)=0$ であり、係数を変えても同じである。対の長完全列で絶対群の同型を得る。コホモロジーについては、普遍係数定理の自然な短完全列を比較すれば従う。
:::

:::example[可縮性を Whitehead で証明できる場合]
道連結 CW 複体 $X$ のすべての正次数のホモトピー群が消えるとする。一点の包含は道成分とすべての群で同型を与えるので、Whitehead の定理により $X$ は可縮である。例えば有限支えの実単位ベクトル全体 $S^\infty$ の CW モデルでは、球面からの任意の写像の像が有限次元球面に入る。一つ新しい座標方向への単位ベクトルと線形補間して正規化すれば零を通らず、より大きい球面内で定値まで変形できる。基点が途中で動く場合はその軌跡による基点変更で零の類に戻る。従って全ホモトピー群が消え、CW 空間として可縮である。
:::

:::example[連結成分も仮定に必要である]
一点から二点離散空間への包含は、選んだ基点で全正次数のホモトピー群の同型を誘導する。両側の群が自明だからである。しかし道成分の写像は一点から二点への包含で全射ではない。ホモトピー同値があれば道成分を全単射に対応させるので、この包含はホモトピー同値ではない。二つの群の同型だけを比較するときは、何を基点に選んだかと、ほかに道成分が残るかを確認する。
:::

:::example[同じ道成分と高次群を持つ二つの位相]
有理数の集合に離散位相を入れた $\Q_{\mathrm{disc}}$ から、実直線の相対位相を入れた $\Q$ への恒等写像を考える。どちらでも各連結部分集合は一点である。相対位相の場合、異なる二つの有理数の間に無理数を選ぶと、その左右が開閉集合として二点を分けるからである。従って道成分は一点ずつであり、正次元球面の連続な像は一点なので全ての正次数のホモトピー群が零である。この連続写像は弱ホモトピー同値である。

一方、もしホモトピー逆があれば、道成分が一点ずつなので両側の合成は点ごとに恒等でなければならない。例えば一つの点のホモトピー中の軌跡は道であり、その軌跡は定値になる。そのため候補は逆向きの恒等写像に限られるが、$\Q$ の一点集合は開でなく、$\Q_{\mathrm{disc}}$ では開である。従って逆向きの恒等は連続でなく、ホモトピー同値にはならない。Whitehead の定理で CW 複体の仮定が必要となる場合である。
:::

:::corollary[弱同値の CW 複体からの写像に対する作用]
任意の弱ホモトピー同値 $f:X\to Y$ と基点付き CW 複体 $K$ について、基点が頂点であれば $f$ は $[K,X]_*\to[K,Y]_*$ の全単射を誘導する。
:::

:::proof
通常の写像柱 $M_f$ の上端に $X$、下端に $Y$ を入れる。退縮 $r:M_f\to Y$ は、基点 $x_0$ の円柱線分を $y_0=f(x_0)$ に送る。$X\to M_f$ は弱ホモトピー同値なので、この対の全ての相対ホモトピー群は自明である。任意の基点付き写像 $g:K\to Y$ に対し、まず $K$ の基点一つを下端の $y_0$ から上端の $x_0$ にこの線分に沿って動かす。$(K,\{*\})$ の拡張性質により、これを $K$ 全体の写像のホモトピーに延ばせる。終時刻で基点は上端にあるので、前に示した押し込みで基点を固定したまま写像全体を $X$ に入れられる。この二つのホモトピーを $r$ で送ると $y_0$ は全時刻で固定され、$g$ と、得られた $K\to X$ に $f$ を合成した写像を結ぶ。従って全射である。

単射性のため、二つの基点付き写像 $u_0,u_1:K\to X$ が $f$ で送ると $Y$ 内で基点付きホモトピックだとする。写像柱の円柱で $u_0$ を上から下へ動かし、下端でホモトピーを行い、最後に $u_1$ に沿って上端へ戻る。この間、基点の軌跡は一つの線分の往復である。これは両端を固定して上端の定値道へ縮められる。そこで $(K\times I,K\times\partial I\cup\{*\}\times I)$ の拡張性質を使い、端で $u_0,u_1$ を保ったまま基点の軌跡を定値に替える。指定した部分は CW 部分複体である。同じ対の押し込みでその部分を固定してホモトピー全体を $X$ に移すと、$u_0$ と $u_1$ が $X$ 内で基点付きホモトピックだと分かる。
:::

## ホモトピー切除定理と Freudenthal の懸垂定理

対が $r$ 連結であるとは、全基点で相対群が次数 $r$ 以下で自明であり、道成分についても全射の条件を満たすことである。

:::theorem[Blakers–Massey のホモトピー切除]{#thm-at-blakers-massey}
$X=A\cup B$ が CW 部分複体の合併で、$C=A\cap B$ は道連結、$(A,C)$ は $r$ 連結、$(B,C)$ は $s$ 連結とする。$r,s\ge1$ なら包含 $\pi_i(A,C)\to\pi_i(X,B)$ は $i<r+s$ で同型、$i=r+s$ で全射である。
:::

:::proof
まず $C$ を保って $(A,C),(B,C)$ をそれぞれ相対 CW 近似する。$(A,C)$ に対する近似の最初の操作は、$\pi_r(C)\to\pi_r(A)$ の核を $(r+1)$ 胞体で殺すことである。その各円板は $A$ における零ホモトピーで送る。同じ次元の球面をウェッジして $\pi_{r+1}(A)$ の残りの代表を加え、以後は :ref[prop-at-cw-approximation] と同じ操作を続ける。仮定により $r$ 次元以下の胞体は要らない。$r=1$ では核の生成ループを殺す操作を基本群の正規閉包として読む。$B$ についても同様に次元 $s+1$ 以上の相対胞体だけを取れる。得られた写像を $C$ 相対で胞体近似する。Whitehead の証明の押し込みを $C$ 上で固定して行えば、この写像は $C$ を保つホモトピー逆を持つ。具体的には、$C\times I$ を $C$ へ潰した写像柱で元の定義域を固定し、相対ホモトピー群の消滅を使って胞体を一つずつ上端へ押し込む。従って両部分の逆とホモトピーを $C$ で貼り合わせてよい。以後は各側がこの次元条件を満たすとする。

三つ組 $(X;A,B)$ の $q$ 次の代表を、立方体 $I^{q-1}\times I$ からの写像で表す。最後の座標が $0$ の面は基点へ、$1$ の面は $B$ へ送る。前の $q-1$ 座標について、最後の一面を $A$ へ、残りの側面は基点へ送る。その側面と $B$ の面との共通部分では値が $C$ にある。条件を保つホモトピーで割った集合を $\pi_q(X;A,B)$ と書く。最後の座標を道として読むと、これは基点から $B$ に至る $X$ 内の道の空間と、基点から $C$ に至る $A$ 内の道の空間との対の $\pi_{q-1}$ である。従って対の長完全列から
$$
\pi_{q+1}(X;A,B)\to\pi_q(A,C)\to\pi_q(X,B)\to\pi_q(X;A,B)
$$
を得る。示すべきことは、$q\le r+s$ で三つ組の相対類が消えることである。

立方体の像は有限部分複体に入るので、相対胞体が有限個の場合に帰着できる。必要なら有限本の道を加えて交わりを道連結にしておく。有限個の胞体を一つずつ付けた場合から帰納する。まず $C\subset A'\subset A$ で $A$ が $A'$ に一胞体を貼った空間とし、$X'=A'\cup B$ とする。$(X';A',B)$ と $(X;A,X')$ に結論があれば、三つの入れ子の対 $(A,A',C)$ と $(X,X',B)$ の完全列を比較して $(X;A,B)$ の結論を得る。この完全列は同じ立方体の面の制限で作るか、基点からの道空間の対に対の完全列を適用して得られる。比較で真ん中の全射性には隣の二対の全射性と一つ下の単射性を使い、単射性には一つ上の全射性と同じ次数の単射性を使う。その範囲は $q\le r+s$ と $q<r+s$ である。次に $B$ 側で一胞体を外して $B'$ とすると、$(X;A,B)$ の比較写像は $(A,C)\to(A\cup B',B')\to(X,B)$ と因数分解する。二番目は $(X;A\cup B',B)$ の比較である。これで両側一胞体の場合に帰着する。

単一の相対胞体の次元を $a\ge r+1$、$b\ge s+1$ とする。写像の値が各開胞体の中央の小閉球に入る所では、その胞体の座標で写像を区分線形に近似できる。実際、:ref[lem-at-avoid-open-cell] と同様、閉球より広い帯で座標値を切り替える。近似誤差を帯の幅より小さく取れば、変形後も小閉球の逆像では近似だけが使われる。変更は二つの胞体の内部で別々に行うので、立方体の各面が満たす値域の条件は維持される。変形後を $g$ とする。

$B$ 側の小閉球の内部で、区分線形近似の階数が $b$ 未満となる各単体の像を避けて点 $y$ を選ぶ。$g^{-1}(y)$ は高々 $q-b$ 次元の有限個の凸多面体の和に含まれ、$q<b$ なら空である。前の $q-1$ 座標への射影を $\operatorname{pr}$ とする。逆像を最後の座標方向へ延ばした柱 $\operatorname{pr}^{-1}\operatorname{pr}(g^{-1}(y))$ は、これらの多面体を同じ方向へ延ばした柱の和に含まれる。各多面体の射影で次元は増えず、延ばす方向は一つなので、その次元は高々 $q-b+1\le a-1$ である。$A$ 側の小閉球で像を読む部分では $g$ は区分線形であるため、この柱の像が小閉球を覆うことはない。その像を避けて $A$ 側の点 $x$ を選ぶ。すると $g^{-1}(x)$ と $g^{-1}(y)$ の第一成分への射影は互いに交わらない。側面は $A$ に入るため、$y$ の逆像の射影は $I^{q-1}$ の境界とも交わらない。

そこで $I^{q-1}$ 上で、$y$ の逆像の射影上で $1$、$x$ の逆像の射影と境界上で $0$ となる連続関数 $\lambda$ を取る。二つの閉集合への距離の比で作れる。最後の座標を $s$ とし、$(z,s)\mapsto(z,(1-t\lambda(z))s)$ を $g$ に前合成する。この変形は底面と側面を固定する。上面で $\lambda>0$ の点はその柱上に $x$ の逆像を持たず、$\lambda=0$ では上面の値は元から $B$ にある。従って変形中の上面は $X\setminus\{x\}$ に入る。終時刻には $y$ の逆像を持っていた柱全体が底面へ移るので、写像は $y$ を避ける。

$x$ を抜いた $A$ 側の胞体を境界へ放射状に押すと $X\setminus\{x\}$ は $B$ へ変位レトラクトする。$y$ を抜いた $B$ 側の胞体を押すと、三つ組 $(X\setminus\{y\};A,X\setminus\{x,y\})$ は $(A;A,A\setminus\{x\})$ へ変位レトラクトする。後者では二つの道空間が一致するので相対類は自明である。従って上面の条件を $B$ から $X\setminus\{x\}$ に広げた三つ組で元の類が消える。最初の変位レトラクションと対の完全列は、この条件の変更が相対類の同型を与えることを示す。これで元の三つ組でも類が消え、切除の結論が従う。
:::

この証明では三つ組の相対類を使って、二つの胞体の内部を同じ柱で同時に通ることを防いだ。一般の切除三つ組に対する定式化は :cite[may-concise]{loc="第11章"} を参照せよ。

:::corollary[Freudenthal の懸垂]{#cor-at-freudenthal}
基点が頂点である $(r-1)$ 連結 CW 複体 $X$、$r\ge1$ に対し $E:\pi_i(X)\to\pi_{i+1}(\Sigma X)$ は $i\le2r-2$ で同型、$i=2r-1$ で全射である。$\Sigma X$ は被約懸垂である。
:::

:::proof
懸垂を二つの錐 $A,B$ の和として作る。交わりは $X$ であり、両方の対 $(A,X),(B,X)$ はそれぞれ $r$ 連結である。切除の写像は $\pi_{i+1}(A,X)\to\pi_{i+1}(A\cup B,B)$ になる。対の完全列で両側を $\pi_i(X)$ と $\pi_{i+1}(SX)$ に同一視すると、円板の相対写像を二つの錐で閉じる操作なので懸垂である。通常の懸垂から被約懸垂への商は :ref[cor-at-collapse-contractible] で同値であり、範囲は切除の $i+1<2r$ と $i+1=2r$ から従う。
:::

:::example[安定範囲に入る懸垂の一歩手前]
$S^3$ は $2$ 連結なので、$i\le4$ で $\pi_i(S^3)\to\pi_{i+1}(S^4)$ は同型、$i=5$ で全射である。同じ次数差 $k=2$ を追う場合、初めの $\pi_5(S^3)$ から $\pi_6(S^4)$ へは全射であり、その次の $\pi_7(S^5)$ へは同型になる。従って安定群の任意の元は $S^3$ を目標とする写像で既に表現できるが、$S^3$ における二つの代表の違いが懸垂後に消える可能性はこの範囲だけでは判定できない。
:::

:::example[懸垂が写像度を保存する]
$S^n\to S^n$ の $f$ に懸垂を取る。二つの錐の開被覆を使うと、$H_{n+1}(S^{n+1})\to H_n(S^n)$ の Mayer–Vietoris 接続は同型であり、$\Sigma f$ と $f$ による写像の正方形は可換である。従って $\deg(\Sigma f)=\deg f$ になる。例えば円周で巻き数 $-2$ の写像を二回懸垂しても、$S^3$ の写像度は $-2$ のままである。これは懸垂が低次の写像類をすべて保つという意味ではない。写像度の場合は、球面と写像の次元が等しいためこの特定のホモロジー群で比較できる。
:::

:::example[懸垂の全射性が現れる最初の次数]
後で示すように、$S^2$ の $\pi_3$ は Hopf 写像を生成元とする $\Z$ である。Freudenthal で次の $\pi_4(S^3)$ への写像は全射となるが、この範囲から単射性は出ない。下の節で計算する通り、生成元の二倍は懸垂して零になり、生成元自身は消えない。この例で始域の次数 $3$ は $2r-1$ に等しい。$\pi_4(S^3)\to\pi_5(S^4)$ では始域次数 $4$ が新しい $2r-2$ に等しく、今度は同型である。どちらも一回の懸垂だが、安定範囲の境界を一つ越えている。
:::

## Hurewicz の定理

:::theorem[最初の非自明次数の Hurewicz 同型]{#thm-at-hurewicz}
$(r-1)$ 連結 CW 複体 $X$、$r\ge2$ では $H_i(X;\Z)=0$（$0<i<r$）であり $h_r:\pi_r(X)\to H_r(X;\Z)$ は同型である。$h_r[f]=f_*[S^r]$ と定める。
:::

:::proof
球面のピンチ写像は頂次の基本類を両因子の基本類の和へ移す。各因子への射影の写像度が $1$ であるためである。従って $h_r$ は加法的である。胞体のない低次数の消滅は、一頂点と $r$ 以上の胞体からなる CW 近似を作り :ref[thm-at-whitehead] を用いると従う。以後その構造を仮定する。

$\pi_r(S^r)\cong\Z$ は懸垂から先に求まる。$\pi_1(S^1)=\Z$ から $\pi_2(S^2)$ への懸垂は全射である。恒等の懸垂は写像度 $1$ の恒等写像であるため、その生成元に非零の整数倍の関係はない。後の懸垂は :ref[cor-at-freudenthal] の同型範囲にある。$X^r$ は $r$ 球面のウェッジである。有限ウェッジから球面の積への包含は $2r$ 以上の胞体の接着であり、胞体近似により $\pi_r$ の同型を与える。よって $\pi_r(X^r)$ は各球面の恒等写像からなる自由 Abel 群である。無限の場合はコンパクト性で有限のウェッジに帰着する。

$(r+1)$ 胞体を付けたとき、対 $(X^{r+1},X^r)$ の相対 $\pi_{r+1}$ は各接着円板で生成される。実際、$X^r$ に錐を貼る三つ組でホモトピー切除を使うと、$(X^{r+1},X^r)$ と $(X^{r+1}\cup CX^r,CX^r)$ の比較は $r+1<2r$ で同型である。ここで切除に使う二つの対は $(X^{r+1},X^r)$ と $(CX^r,X^r)$ であり、前者は胞体近似で、後者は $X^r$ の $(r-1)$ 連結性と錐の可縮性によって $r$ 連結である。錐を潰すと $(r+1)$ 球面のウェッジとなり、各接着円板がその生成元へ移る。対の完全列で、$\pi_r$ はそれらの境界の像で割られる。高次胞体は胞体近似で $\pi_r$ を変えない。各接着写像を各 $r$ 胞体へ射影した成分は写像度であり、胞体ホモロジーの境界係数と一致する。従って $\pi_r$ と $H_r$ は同じ生成元と関係を持ち、各生成元を対応させる同型が $h_r$ である。
:::

$r=1$ では :ref[thm-at-hurewicz-one] の可換化が結論になる。対を扱うときは、部分空間を錐で埋めて絶対版に移せる範囲を先に確かめる。

:::theorem[単連結な対の相対 Hurewicz]{#thm-at-relative-hurewicz}
$X,A$ を単連結な CW 対とし、$(X,A)$ が $(r-1)$ 連結であるとする。$r\ge2$ なら $H_i(X,A)=0$（$i<r$）で、相対 Hurewicz 写像 $\pi_r(X,A)\to H_r(X,A)$ は同型である。円板の相対写像を、円板対の相対基本類の像へ送る写像を用いる。
:::

:::proof
$Y=X\cup_A CA$ とする。$A$ が単連結なので $(CA,A)$ は少なくとも $2$ 連結である。$(X,A)$ の連結性は $r-1$ であるため、:ref[thm-at-blakers-massey] により $\pi_i(X,A)\to\pi_i(Y,CA)$ は $i<r+1$ で同型である。対の長完全列と $CA$ の可縮性から、右辺は正次数で $\pi_i(Y)$ に対応する。従って $Y$ は $(r-1)$ 連結である。絶対 Hurewicz 定理を $Y$ に使えば、次数 $r$ で $\pi_r(Y)\cong H_r(Y)$、それより低い正次数は消える。

ホモロジーでは $Y/CA=X/A$ であり、両方を相対胞体鎖で計算できる。$(X,A)$ と $(Y,CA)$ は同じ残存胞体と接着係数を持つので、包含は相対群の同型を与える。可縮な $CA$ の対の長完全列で $H_i(Y,CA)\cong\widetilde H_i(Y)$ である。これらの同型を相対円板の基本類にたどると、$CA$ 内で境界を錐で閉じた球面の基本類になる。従って絶対 Hurewicz での対応は相対 Hurewicz 写像に一致する。零次も対が道連結なので零である。
:::

:::corollary[基本群の作用を含む相対 Hurewicz]{#cor-at-hurewicz-coinvariants}
道連結な CW 対 $(X,A)$ で $\pi_1(A)\to\pi_1(X)=G$ が同型とする。$(X,A)$ が $(r-1)$ 連結で $r\ge2$ なら、$H_i(X,A;\Z)=0$（$i<r$）であり、相対 Hurewicz 写像は $G$ の作用による差で割った同型
$$
\pi_r(X,A)_G \cong H_r(X,A;\Z)
$$
を誘導する。ここで作用は基点の取り替えであり、左辺では $g\cdot u-u$ の張る部分群で割る。
:::

:::proof
$\widetilde X\to X$ を普遍被覆とする。$\pi_1(A)\to\pi_1(X)$ の全射性により $A$ の逆像 $\widetilde A$ は道連結であり、単射性により単連結でもある。相対立方体とホモトピーは指定した基点から持ち上がり、その上面は $\widetilde A$ に入る。よって $\pi_i(\widetilde X,\widetilde A)\cong\pi_i(X,A)$ である。特に次数二では群が可換である。実際、被覆対の相対二次群は対の完全列で絶対二次群の商である。この同一視の下でデッキ変換による基点の変更が $G$ の作用を与える。:ref[thm-at-relative-hurewicz] により被覆対の $i<r$ の相対整数ホモロジーは零であり、次数 $r$ では同変な Hurewicz 同型がある。

被覆対の相対胞体鎖複体 $C$ は群環 $\Z[G]$ 上自由であり、各胞体の持ち上げを一つ取るとそのデッキ変換の軌道が対応する胞体の全てである。$i<r$ での完全性から、底の次数から順に $C_{i+1}\to B_i(C)$ を切断できる。最初は $B_0=C_0$ が自由であり、次の $B_i=Z_i(C)$ は $C_i$ の直和因子なので射影的である。このため次数 $r$ 以下で、鎖群を境界への切断と輪体群の直和に分けられる。$G$ の作用を忘れる商を取っても、切断された部分は対になって消える。次数 $r$ の群は残った $Z_r(C)$ の商を $B_r(C)$ の像で割るため、商を取る操作の右完全性から $H_r(C)_G$ である。商を取った鎖は $(X,A)$ の相対胞体鎖であり、被覆からの押し出しはこの商に対応する。従って同変な Hurewicz 同型から表示の同型が得られる。
:::

:::corollary[単連結 CW 複体のホモロジー同値]
単連結 CW 複体の間で整数ホモロジー同型を誘導する写像はホモトピー同値である。
:::

:::proof
胞体近似後の写像柱の対 $(M_f,X)$ を取る。対のホモロジー長完全列によりすべての相対群は零である。両空間が単連結なので、相対ホモトピー群に非自明なものがあれば最小次数 $r\ge2$ を取れる。相対 Hurewicz により $\pi_r(M_f,X)\cong H_r(M_f,X)=0$ となって矛盾する。よって相対ホモトピー群はすべて自明であり、対の長完全列から $f$ は弱ホモトピー同値である。Whitehead の定理によりホモトピー同値となる。
:::

:::example[二つの接着写像から最初のホモトピー群を求める]
$S^3\vee S^3$ に二個の四胞体を貼り、各境界の二つの球面への写像度を $(2,4)$、$(0,6)$ とする。この空間は $2$ 連結であり、$\pi_3$ は Hurewicz で $H_3$ に対応する。胞体境界の第二行から第一行の二倍を引けば $\diag(2,6)$ になり、$\pi_3=\Z/2\oplus\Z/6$ である。写像度の組を読むだけでよいのは最初の非零次数にいるからであり、次の $\pi_4$ を同じ余核で置き換えることはできない。
:::

:::example[単連結空間のホモロジーを同時に検査する]
$S^2\vee S^3$ の自己写像で、二次球面に度 $-1$、三次球面に度 $1$ の写像を取る。両球面の基点を固定する代表を選べばウェッジ上の写像になる。この写像は零次と正の二、三次の整数群で同型を誘導し、他の群は零である。従って単連結版の Whitehead 判定でホモトピー同値である。一方、三次球面の写像だけを二倍へ替えると、$\pi_2$ には影響がないが $H_3$ では像が $2\Z$ となり、同値でなくなる。
:::

:::example[相対 Hurewicz が最初の接着円板を拾う]
$A=S^2$ に三胞体を二枚貼り、接着写像の度を $4,6$ とする。対は二連結であり、相対三次群は相対 Hurewicz により $\Z^2$ である。各基底は一枚の特性円板を表す。接続 $\pi_3(X,A)\to\pi_2(A)$ は $(a,b)\mapsto4a+6b$ になるので像は $2\Z$ である。従って $\pi_2(X)=\Z/2$ となる。核は $(3,-2)$ の張る $\Z$ であり、絶対三次群から来る相対類はこの整数倍である。ここでは相対三次群を求めても絶対三次群全体は決まらない。絶対三次における $\pi_3(A)$ の像がさらに寄与し得るためである。
:::

:::corollary[最初の非零のホモロジーから連結性を戻す]
単連結 CW 複体 $X$ で $H_i(X)=0$ が $0<i\le r$ で成り立つなら、$X$ は $r$ 連結である。
:::

:::proof
もし $\pi_i(X)\ne0$ となる最初の次数が $r$ 以下にあれば、その次数を $s$ とする。単連結性により $s\ge2$ であり、定義から $X$ は $(s-1)$ 連結である。このとき Hurewicz 写像は $\pi_s(X)\cong H_s(X)$ を与えるが、右辺は仮定で零なので矛盾する。従って正の $r$ 次以下の群はすべて消える。例えば $H_2,H_3$ の両方が零なら、二次の球面写像が縮むことに続いて三次の球面写像も縮むと結論できる。
:::

:::example[ホモロジー球面から球面写像を選ぶ]
$X$ を単連結 CW 複体とし、整数ホモロジーが $n\ge2$ の球面と同じとする。前の判定で $X$ は $(n-1)$ 連結であり、$H_n(X)=\Z$ の生成元を表す $S^n\to X$ を Hurewicz 同型から選べる。この写像は頂次で同型、零次では道連結性により同型であり、他の群はともに零である。従って単連結版 Whitehead の判定によりホモトピー同値である。ここでホモロジーの群の同型だけを与えられても、実際のホモトピー同値の候補は最初の非零次数の Hurewicz 同型を使って選ぶ必要がある。
:::

## 球面のホモトピー群の計算例と安定ホモトピー群

:::example[次元以下の球面写像]
$i<n$ なら $\pi_i(S^n)=0$ である。胞体近似で写像を一点の $i$ 骨格へ移せる。$i=n$ では Hurewicz 同型が写像度を与えて $\pi_n(S^n)=\Z$ になる。この二点を合わせると $S^2$ では $\pi_1=0$、$\pi_2=\Z$ である。
:::

:::definition[安定ホモトピー群]{#def-at-stable-homotopy}
固定した次数差 $k\ge0$ に対し、$\pi_{n+k}(S^n)$ を懸垂でつないだ直極限を :term[球面の安定ホモトピー群]{en="stable homotopy group of spheres" yomi="きゅうめんのあんていほもとぴーぐん"} $\pi_k^S$ とする。
:::

$S^n$ は $(n-1)$ 連結なので、$n+k\le2n-2$、すなわち $n\ge k+2$ ならすでに安定値である。$k=0$ の安定群は $\Z$ であり、生成元は恒等写像の懸垂列で表される。例えば $k=2$ なら $\pi_6(S^4)\to\pi_7(S^5)$ は同型であるが、安定範囲だけでは群の値は決まらない。次の補題では球面から有限射影空間への代表を、複素直線の単位ベクトルへ持ち上げる。局所自明化を使う一般論は [Hopf ファイブレーション](/math/algebraic-topology/fibrations/) で扱う。

:::example[接着次数で作る Moore 空間]
$n\ge2$ とし、$S^n$ に写像度 $m\ne0$ の写像で $(n+1)$ 胞体を貼る。この空間 $M$ は $(n-1)$ 連結であり、最初の群は $\pi_n(M)\cong H_n(M)=\Z/m$ である。具体的に $m=6$ なら、下の球面の包含の六倍は接着円板で縮む。一方三倍は $H_n$ で位数二の元を与えるため縮まない。さらに $M$ の懸垂は $S^{n+1}$ に写像度 $m$ で胞体を貼った空間と同値である。円板と球面の被約懸垂で接着を保ち、懸垂が写像度を保つことを使う。この計算からも $\pi_n(M)\to\pi_{n+1}(\Sigma M)$ が同型になることが分かる。
:::

:::example[弱同値の仮定を確かめる]
包含 $S^1\vee S^2\hookrightarrow S^1\times S^2$ は $\pi_1$ 上で同型である。積への追加胞体は三次元であり、基本群を変えないためである。一方、左の普遍被覆は整数頂点を線分で結んだ直線に、各整数点で一つずつ $S^2$ を貼った空間である。直線を潰すと可算個の二次元球面のウェッジとなり、Hurewicz 同型で $\pi_2$ は可算無限階数の自由 Abel 群 $\bigoplus_{j\in\Z}\Z$ である。右の普遍被覆は $\R\times S^2$ で $\pi_2=\Z$ なので、包含はホモトピー同値でない。Whitehead の定理で基本群だけを調べると足りないことが分かる。
:::

:::example[球面の直積の二次ホモトピーと作用]
$S^2\times S^2$ の $\pi_2$ は二因子の $\Z$ の直積である。実際、基点付きの写像とホモトピーは成分に分けられる。因子交換の写像は $(m,n)$ を $(n,m)$ に送り、対角の包含は $\pi_2(S^2)$ の生成元を $(1,1)$ に送る。Hurewicz 同型でこの元は二つの基本球面の和を表す。例えば $(3,-2)$ は対角の像に属さないが、二つの射影ではそれぞれ度 $3,-2$ の類として見える。
:::

:::example[積の接着写像は個々の射影からは見えない]
$S^n\times S^n$（$n\ge2$）の唯一の $2n$ 胞体の接着を $\omega:S^{2n-1}\to S^n\vee S^n$ とする。第一射影と第二射影は積全体で定義されるので、それぞれと $\omega$ の合成は円板へ延長できる。従って各成分のホモトピー類は零である。しかし $\omega$ 自身は零ではない。もし零なら写像錐の接着を定値へ動かせるので、積は $S^n\vee S^n\vee S^{2n}$ とホモトピー同値になる。ウェッジでは任意の二つの $n$ 次類の積が零である。各球面への制限で確認でき、$2n$ 次で非零になり得るのは $S^{2n}$ の因子だが、その因子では $n$ 次の制限が零だからである。一方、積空間で二因子から引き戻した $n$ 次類の外積は $H^{2n}$ の生成元である。環の違いから矛盾する。この付着を一般化して Whitehead 積を定義する。
:::

### 同型範囲の端で生まれる関係

:::lemma[球面のループ空間の連結積]{#lem-at-loop-product-mv}
$n\ge2$ とする。$\Omega S^{n+1}$ は、基点から出て基点へ戻る道の空間で、コンパクト開位相を持つ。懸垂座標を進むループの族 $j:S^n\to\Omega S^{n+1}$ が定める $u=j_*[S^n]$ に対し、$u,u^2$ はそれぞれ $H_n,H_{2n}$ の自由生成元である。積は鎖の外積をループの連結で押し出して定める。
:::

:::proof
$P$ を基点から出る道の空間とし、終点で $S^{n+1}$ に写す。$P$ は道を始点へ短縮すると可縮である。球面を北と南の開半球を広げた二つの開集合で覆い、それぞれで基点から終点 $y$ へ至る連続な道 $s_U(y),s_V(y)$ を選ぶ。例えば南極を基点にし、南側では南極から子午線を進む。北側では固定した子午線で北極まで進み、そこから $y$ に向かう。このような道の選択がある開集合上では、終点が $y$ の道に $s_U(y)$ の逆道を連結するとループとなり、逆にループに $s_U(y)$ を連結すると終点が $y$ の道となる。往復の部分を縮めると、これらは互いにホモトピー逆である。全ての式は時刻の再パラメータ化で連続に書ける。

赤道へ変形収縮する重なりの上で両方の表示を比較すると、ループの後ろに $c(y)=s_U(y)*\overline{s_V(y)}$ を連結する。赤道上の $c$ は、$y$ の子午線を南極から北極まで進み、固定した子午線を戻るループの族である。固定子午線を潰すと往路は被約懸垂の座標線になり、復路は定値になる。この商は可縮な部分複体を潰す同値であり、基点での往復も縮められる。従って $c_*[S^n]$ は向きを揃えると $j_*[S^n]$ である。

$F=\Omega S^{n+1}$ と書く。Mayer–Vietoris では重なりから二つの開集合への写像が、全次数 $k>0$ で $H_k(F)\oplus H_{k-n}(F)\to H_k(F)\oplus H_k(F)$ の同型を与える。両端の全空間のホモロジーは、可縮性により零だからである。第一の直和因子は、赤道の一点での二つの表示に対応し、符号を除いて対角へ行く。実際、固定ループとの連結は $F$ の道連結性により恒等にホモトピックである。第二因子は赤道の基本類との外積で表され、一方の表示では射影で零、他方では $a$ を $a u$ に送る。対角成分を消去すれば、$k\ge n$ で $a\mapsto au$ が $H_{k-n}(F)\to H_k(F)$ の同型と分かる。$H_0(F)=\Z$ に $k=n,2n$ を順に適用すればよい。
:::

:::proposition[球面の懸垂の端と Whitehead の平方]
$n\ge2$ とする。懸垂 $\pi_{2n-1}(S^n)\to\pi_{2n}(S^{n+1})$ の核は、$S^n\times S^n$ の頂次胞体の接着写像と二つの球面の折り畳みとの合成 $w_n:S^{2n-1}\to S^n$ で生成される。この $w_n$ を恒等類の Whitehead の平方という。
:::

:::proof
まず $Z=(S^n\times S^n)/\sim$ を取り、二つの軸 $S^n\times\{*\}$ と $\{*\}\times S^n$ を同じ $S^n$ に折り畳む。それ以外では点を同一視しない。積の胞体分解から $Z=S^n\cup_{w_n} D^{2n}$ である。$S^n$ の終域への写像 $j:S^n\to\Omega S^{n+1}$ は、懸垂座標を進むループ $t\mapsto[x,t]$ で表せる。これを $Z$ へ延長するには、二つの点から来るループを連結した写像が、どちらかの点が基点のとき残りのループに正確に一致するように作る必要がある。

距離により $\ell(x)=d(x,*)$ を取り、連結の第一のループの時間を $\ell(x)/(\ell(x)+\ell(y))$、第二の時間を残りにする。片方の時間が零ならその部分を飛ばし、両方零なら定値ループとする。正の時間の部分では通常の線形な再パラメータ化で連続である。時間が零になり得る部分では、該当する $x$ または $y$ が基点に近づくため、そのループの全時刻の像は基点の任意の近傍へ入る。これは懸垂写像 $S^n\times I\to S^{n+1}$ と区間のコンパクト性から従う。この観察で時刻の境界と両方の時間が零になる所での連続性も分かる。従ってコンパクト開位相で連続なループの族となる。軸上ではまさに $j$ であるから $Z$ へ降りる。積空間上でこの連結を均等な時間に直すホモトピーも、区切り時刻を $1/2$ まで補間すれば同じ連続性の議論で作れる。

この $Z\to\Omega S^{n+1}$ は、頂次の $H_{2n}$ で生成元を生成元へ送る。なぜなら $S^n\times S^n\to Z$ は頂次胞体上で相対の生成元を保ち、ループ空間への合成はホモロジーで $u$ と $u$ の Pontryagin 積 $u^2$ を与えるからである。ここで $u=j_*[S^n]$ は Hurewicz と懸垂の同型によって一次の非零次数 $n$ の生成元であり、$u^2$ の生成性は :ref[lem-at-loop-product-mv] による。二つの写像は $S^n$ 上で一致するので、相対の $H_{2n}$ でも同型である。

$Z$ と $S^n$ の対は $(2n-1)$ 連結であり、ループ空間側の写像柱と $S^n$ の対も Freudenthal の定理で $(2n-1)$ 連結になる。後者ではループ空間を CW 近似して、$S^n$ の写像を同じ $n$ 次類で表す写像に取り替え、写像柱を比較すれば相対 Hurewicz を使える。$S^n$ で近似を経由する写像と元の $j$ を結ぶホモトピーを、対 $(Z,S^n)$ の拡張性質で先に $Z$ 全体へ延ばす。その後、近似の写像柱へ入れると制限は写像柱の上端までのホモトピーを持つので、それも $Z$ へ延長して上端に合わせられる。弱同値の写像柱の相対ホモトピー群は零なので、Whitehead の証明の胞体ごとの押し込みで、その制限を保つ近似への写像が得られる。従って相対 $H_{2n}$ の同型は相対 $\pi_{2n}$ の同型を与える。$Z$ 側の特性円板の境界は $w_n$ だから、ループ空間側でも境界の像はその一元で生成される。完全列の次の写像が懸垂であるため主張が従う。
:::

:::example[三球面の端で核が消える理由]
$S^3$ は単位四元数の積を持つ。積 $\mu:S^3\times S^3\to S^3$ は二つの軸上で恒等写像なので、折り畳み写像は積全体へ延長されている。従って $w_3$ は頂次円板で延長でき、零である。上の核の計算により、$\pi_5(S^3)\to\pi_6(S^4)$ は Freudenthal の全射の端であっても単射となる。安定範囲を求める一般の不等式は、個別の球面でこのような核を調べる余地を残す。
:::

### 安定一次群の計算

:::lemma[複素 Hopf 写像の高次群への作用]{#lem-at-hopf-high-pi}
射影 $p:S^{2m+1}\to\C P^m$ は $i\ge3$ で $\pi_i$ の同型を誘導する。$m=1$ では $p:S^3\to S^2$ が $\pi_3(S^2)$ の生成元を表す。
:::

:::proof
射影空間の点を複素直線への直交射影で表す。二つの射影の差の作用素ノルムが $1$ 未満なら、一方の単位ベクトルを他方へ射影しても零にならない。コンパクトなパラメータ上の直線のホモトピーを時間方向に一様に細分し、各区間の始めの単位ベクトルを新しい直線に射影して正規化すれば、初期値から連続な単位ベクトルを選べる。定値な直線ではベクトルは動かない。円板上の直線族では縮約のホモトピーを使い、全円板上で選べる。

$S^i$ の両半球で単位ベクトルを選ぶ。赤道上での差は $S^{i-1}\to S^1$ であり、$i\ge3$ では実数値の角度へ持ち上がる。この角度を片方の半球へ延長して局所代表を調整すると、球面全体で一致する。基点で定数倍すれば指定した初期ベクトルに合わせられる。持ち上げた二写像の射影が基点付きでホモトピックなら、時間の細分で一方からそのホモトピーを持ち上げる。終時刻と第二の写像との差は基点付きの $S^i\to S^1$ なので零ホモトピックであり、これを使って両者をつなげる。従って全射かつ単射である。$m=1$ では $\C P^1\cong S^2$ であり、$p$ は $S^3$ の恒等類の像なので生成元となる。
:::

次元差が一定になると Freudenthal の範囲から懸垂が同型になる。しかし、最初に安定範囲へ入るところで、どの元が消えるかは別に計算する必要がある。二球面の Hopf 写像を出発点とし、一つ上の球面のループ空間を使うと、その核をコホモロジーの積で測れる。

:::proposition[最初の正の安定ホモトピー群]
$\pi_4(S^3)=\Z/2$ であり、$\pi_1^S=\Z/2$ となる。生成元は Hopf 写像 $S^3\to S^2$ の懸垂である。
:::

:::proof
$n=2$ の Whitehead の平方 $w_2$ を考える。その写像錐は $S^2\times S^2$ の二軸を折り畳んだ空間である。下の球面に $1$ を評価する二次類の引き戻しは、二因子の生成元の和 $a+b$ である。頂次の胞体は折り畳みで保たれるので、以下、この写像錐の二次類の平方が頂次類の何倍かを $H(w_2)$ と書く。$(a+b)^2=2ab$ から $H(w_2)=2$ である。

複素 Hopf 写像 $\eta:S^3\to\C P^1$ の写像錐は $\C P^2$ である。実際、最後の座標を非負にした特性円板は $z\mapsto[z:\sqrt{1-\norm{z}^2}]$ であり、境界で $\eta$ となる。超平面類の平方は頂次生成元なので $H(\eta)=1$ である。任意の整数 $d$ について、$d[\eta]$ は $\eta$ の前に度 $d$ の $S^3$ の自己写像を合成して表される。写像錐の比較は下の球面で恒等、頂次胞体の商で度 $d$ となるため $H(d\eta)=dH(\eta)$ である。従って $w_2=2[\eta]$ である。

懸垂の核は $w_2$ が生成し、懸垂写像は全射なので、$\pi_4(S^3)=\Z/2$ を得る。生成元は $E\eta$ であり、$n\ge3$ の球面では次数差一が Freudenthal の同型範囲にあるため、全ての後続段階でも生成元を与える。
:::

:::example[二球面の四次群を Hopf 束で読む]
:ref[lem-at-hopf-high-pi] により $\pi_4(S^3)\to\pi_4(S^2)$ は同型であり、$\pi_4(S^2)=\Z/2$ である。代表は $\eta:S^3\to S^2$ を Hopf 写像とし、その懸垂 $E\eta:S^4\to S^3$ と合成した $\eta E\eta$ である。先ほどの $\pi_4(S^3)$ の生成元を射で送ったものなので、零ではない。$\pi_3(S^2)=\Z$ と比べると、定義域を一つ上げただけで自由部分が消えて有限位数の類だけが残る。
:::

:::example[偶数次元球面の懸垂で無限位数の関係が消える]
$n\ge2$ を偶数とする。$w_2$ と同じ写像錐の計算を $S^n\times S^n$ に用いると、中間次の類の平方は $(a+b)^2=2ab$ である。度 $d$ の自己写像を接着写像の前に合成すれば頂次の比較写像は度 $d$ となるので、$d w_n$ に対応する平方の係数は $2d$ である。接着写像が零なら写像錐は球面のウェッジとなり、平方は零である。従って $w_n$ は無限位数であり、臨界次数の懸垂は無限巡回の核を持つ。懸垂後の群の有限性は [Serre の有限性定理](/math/algebraic-topology/spectral-sequences/) で扱う。
:::

:::example[複素射影平面の低次群と最初のねじれ]
$\C P^2$ は二骨格 $S^2$ に四胞体を貼った空間なので、胞体近似により $\pi_2(\C P^2)=\Z$ である。三次以上では :ref[lem-at-hopf-high-pi] により $\pi_i(S^5)\to\pi_i(\C P^2)$ が同型である。従って $\pi_3,\pi_4$ は零、$\pi_5$ は $\Z$、$\pi_6$ は安定一次群の計算で $\Z/2$ である。空間が四次元の有限 CW 複体でも、それより高いホモトピー群が残る。胞体近似で消えるのは、定義域の次元に対応する骨格が一点しかない場合である。
:::

:::example[同じ普遍被覆を持つレンズ空間の高次群]
$L(p;q_1,q_2)$ の普遍被覆は $S^3$ なので $\pi_2=0$、$\pi_3=\Z$、$\pi_4=\Z/2$ である。被覆の生成変換は二つの複素座標に単位複素数を掛ける写像であり、各回転角を零から指定値へ動かすと恒等写像からのホモトピーがある。従って被覆変換が高次群に与える作用も、基点の移動を補正すれば恒等である。基点の移動の補正が道の選択によらないのは、被覆全空間 $S^3$ が単連結だからである。例えば $p=5$ の異なる貼り合わせを選んでも、この範囲の群の値と基本群の作用は同じになる。被覆で形を簡単にして得る情報と、底での貼り合わせの細部を表す情報は異なる。
:::

:::solution
$S^5$ では $r=5$ なので上限は $2\cdot5-2=8$ である。始域の次数がちょうど上限なので同型である。
:::

:::solution

::::exercise{level=advanced}
$\pi_4^S$ が安定範囲に入ると保証される最小の球面次元を求めよ。
:::solution
$k=4$ として $n+4\le2n-2$ を解くと $n\ge6$ である。従ってこの範囲から得る最小値は六である。

::::exercise{level=advanced}
$X=S^3$ に四胞体を二枚貼り、その度を $8$ と $12$ とする。$\pi_3(X)$ と、絶対 $\pi_4(X)$ から相対 $\pi_4(X,S^3)$ に写る部分群を求めよ。さらにその部分群の生成元が絶対群で有限位数になり得るか判定せよ。

:::solution
$(X,S^3)$ は三連結なので、相対 Hurewicz により $\pi_4(X,S^3)\cong\Z^2$ である。二枚の特性円板を基底とすると、その境界は $S^3$ の恒等類の $8$ 倍と $12$ 倍であり、接続は $(a,b)\mapsto8a+12b$ となる。像は $\gcd(8,12)\Z=4\Z$ である。三次相対群は零なので、対の長完全列から $\pi_3(X)=\Z/4$ となる。

絶対四次から来る相対類は、同じ完全列により接続の核である。$8a+12b=0$ は $2a+3b=0$ と同値であり、整数解は $(a,b)=k(3,-2)$ である。これが無限巡回群をなす。絶対群の位数有限の元は準同型で位数無限の元へ移らない。従って相対の生成元 $(3,-2)$ を持ち上げる絶対四次類は必ず無限位数である。ただし絶対四次群のうちこの写像で見えない部分は、$S^3$ の四次群から来る可能性があり、今回の核の計算だけでは特定されない。
:::
::::

::::exercise{level=advanced}
$\C P^3$ の $\pi_2,\pi_3,\ldots,\pi_8$ を求めよ。さらに $\pi_8$ の生成元をどの写像の合成で表せるか説明せよ。

:::solution
$\C P^3$ は二骨格 $S^2$ に四胞体と六胞体を貼った空間なので、$\pi_2(\C P^3)\cong\Z$ である。$i\ge3$ では :ref[lem-at-hopf-high-pi] により $p:S^7\to\C P^3$ は $\pi_i(S^7)\cong\pi_i(\C P^3)$ を与える。胞体近似で $3\le i\le6$ の群は零、Hurewicz で $i=7$ の群は $\Z$ である。$i=8$ では次数差一の安定範囲に入っており、$\pi_8(S^7)=\pi_1^S=\Z/2$ を得る。

$\pi_4(S^3)$ の生成元は複素 Hopf 写像 $\eta:S^3\to S^2$ の懸垂である。さらに四回懸垂すると $S^8\to S^7$ となり、その間の懸垂は全て同型なので生成元を表す。従って $\pi_8(\C P^3)$ の生成元は $S^8\xrightarrow{\Sigma^5\eta}S^7\xrightarrow{p}\C P^3$ である。ホモロジーでは $\C P^3$ の次元を超えた八次は零だが、ここではホモトピー長完全列がその次数の非零類を検出した。
:::
