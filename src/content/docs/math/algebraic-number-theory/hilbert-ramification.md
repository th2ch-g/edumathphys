## この章の目標

- Galois 群が素イデアルに推移的に作用することを示す。
- 分解群、惰性群と剰余体の Galois 群の関係を証明する。
- Frobenius の共役類を計算し、不分岐素イデアルの剰余次数を求める。
- 分解体と惰性体を区別し、中間体での分裂を軌道から読む。

以下では $L/K$ を代数体の有限 Galois 拡大とし、$A=\mathcal O_K$、$B=\mathcal O_L$、$G=\operatorname{Gal}(L/K)$ とする。$K$ の有限素イデアル $\mathfrak p$ と、その上にある $L$ の素イデアル $\mathfrak P$ を固定する。中間体と部分群の対応には :ref[thm-gal-correspondence] を用いる。

## Galois 群の素イデアルへの推移的作用

$\sigma\in G$ は整方程式を保つので $B$ を自分自身に移す。また $A$ の各元を固定するため、$\mathfrak P$ を $\mathfrak p$ 上の素イデアルへ移す。この作用の軌道は局所的な分解情報を運ぶ。

:::theorem[素イデアルへの推移的作用]{#thm-ant-prime-transitivity}
$G$ は $\mathfrak p$ の上の素イデアル集合に推移的に作用する。従って分岐指数 $e$ と剰余次数 $f$ は上に選んだ素イデアルによらず、素イデアル数を $g$ とすると $efg=[L:K]$ である。
:::

:::proof
$\mathfrak Q$ が $\mathfrak P$ の軌道に入らないと仮定する。中国剰余定理により、$\mathfrak Q$ で $0$、各 $\sigma\mathfrak P$ で $1$ に合同な元 $a\in B$ が存在する。そのノルム $b=\prod_{\sigma\in G}\sigma(a)$ は $A$ に属し、恒等置換の因子 $a$ を含むので $\mathfrak Q$ に属する。よって $b\in\mathfrak p$ である。一方、全ての $\sigma$ について $\sigma(a)\equiv1\pmod{\mathfrak P}$ なので $b\equiv1\pmod{\mathfrak P}$ であり、矛盾する。

環の自己同型 $\sigma$ は $\mathfrak pB$ の素冪分解を保つため、$\mathfrak P$ と $\sigma\mathfrak P$ の分岐指数が同じになる。剰余体も $A/\mathfrak p$ 上同型になるため剰余次数が同じになる。従って :ref[thm-ant-fundamental-equality] の各項が $ef$ に等しい。
:::

:::example[分裂する素数]
$\Q(i)$ の $5$ 上の二つの素イデアルは $(5,i-2)$ と $(5,i+2)$ である。複素共役がこれらを入れ替える。例えば $(5,-i-2)=(5,i+2)$ なので、素イデアルを生成元から追跡できる。
:::

:::example[非正規拡大で異なる剰余次数]
$X^3-2$ は $\F_5$ 上で $(X-3)(X^2+3X+9)$ となる。後者の判別式は $-27\equiv3\pmod 5$ で平方でない。冪基底の判別式 $-108$ は $5$ と互いに素であり、指数も $5$ と互いに素である。従って $\Q(\sqrt[3]2)$ で $5$ の上に剰余次数 $1,2$ の素イデアルがある。$efg$ の式を非正規拡大に適用するとこの違いを見落とす。
:::

### 推移性から素イデアルの識別へ

正規拡大では同じ $\mathfrak p$ の上の素イデアルは $G$ による一つの軌道である。しかし、選んだ中間体でそれらを制限すると、必ずしも一つの軌道に見えない。$K\subset E\subset L$、$H=\operatorname{Gal}(L/E)$ とする。$E$ の素イデアル $\mathfrak q$ を一つ固定すると、その上の $L$ の素イデアルだけに $H$ の推移性が働く。従って $\mathfrak p$ 上の $E$ の素イデアルは $H$ の軌道の集合である。この見方は後で二重剰余類を数えるときに使う。

:::proposition[剰余環上の置換作用と固定環]{#prop-ant-frobenius-fixed}
$L/K$ が Galois で $\mathfrak p$ が不分岐なら、$\bigl(\mathcal O_L/\mathfrak p\mathcal O_L\bigr)^G$ は $\mathcal O_K/\mathfrak p$ と自然に同型である。
:::

:::proof
中国剰余定理で剰余環を $\prod_{\mathfrak P\mid\mathfrak p}k(\mathfrak P)$ と書く。$G$ は添字を推移的に置換し、$\mathfrak P$ を選べば不変な組はその成分だけで決まる。選んだ成分は安定化群 $D_{\mathfrak P}$ に不変である。逆に $D_{\mathfrak P}$ に不変な成分 $a$ は、$\sigma\mathfrak P$ 成分に $\sigma a$ を置くことで一意に全てへ延びる。剰余体への全射 :ref[thm-ant-inertia-exact] により $D_{\mathfrak P}$ の固定体が $k(\mathfrak p)$ である。
:::

$e>1$ では剰余環に冪零元があるため、この議論をそのまま使うことはできない。例えば $\Z[i]/2$ で $t=i+1$ とすれば $t^2=0$ である。共役は $i$ を $-i=i$ に送るので全環が不変であり、基礎の $\F_2$ より大きい。剰余環を根基で割った後なら上と同じ成分の議論が使える。

## 分解群と惰性群

素イデアルを固定する元だけが、その素イデアルにおける剰余体へ作用できる。さらに剰余体に作用しない元を取り出すと、剰余次数の寄与から分岐の寄与を分離できる。

:::definition[分解群と惰性群]{#def-ant-decomposition-inertia}
$D_{\mathfrak P}=\{\sigma\in G:\sigma\mathfrak P=\mathfrak P\}$ を :term[分解群]{en="decomposition group" yomi="ぶんかいぐん"} という。$\sigma\in D_{\mathfrak P}$ は $k_{\mathfrak P}=B/\mathfrak P$ 上に $k_{\mathfrak p}=A/\mathfrak p$ を固定する自己同型 $\bar\sigma$ を誘導する。この準同型の核 $I_{\mathfrak P}$ を :term[惰性群]{en="inertia group" yomi="だせいぐん"} という。
:::

:::theorem[剰余体への全射]{#thm-ant-inertia-exact}
次の列は完全である。
$$
1\longrightarrow I_{\mathfrak P}\longrightarrow D_{\mathfrak P}
\longrightarrow\operatorname{Gal}(k_{\mathfrak P}/k_{\mathfrak p})
\longrightarrow1.
$$
また $|D_{\mathfrak P}|=ef$、$|I_{\mathfrak P}|=e$ である。
:::

:::proof
$k_{\mathfrak P}^{\times}$ の生成元 $\bar a$ を選ぶ。特に $\bar a\ne0$ で、$\bar a$ は $k_{\mathfrak P}$ を $k_{\mathfrak p}$ 上生成する。中国剰余定理で $\bar a$ に持ち上がり、$\mathfrak p$ 上の他の全素イデアルで $0$ に合同な $a\in B$ を取る。多項式
$$
H(X)=\prod_{\sigma\in G}(X-\sigma(a))
$$
の係数は $G$ で不変な整元なので $A$ に属する。$H$ を $\mathfrak P$ で還元すると、$\sigma\notin D_{\mathfrak P}$ の因子の根はすべて $0$ で、他の根は $\bar\sigma(\bar a)\ne0$ である。$\tau\in\operatorname{Gal}(k_{\mathfrak P}/k_{\mathfrak p})$ はこの多項式の係数を固定するので、$\tau(\bar a)$ は非零の根でなければならない。よってある $\sigma\in D_{\mathfrak P}$ について $\tau(\bar a)=\bar\sigma(\bar a)$ となる。生成元で一致するため $\tau=\bar\sigma$ である。

軌道と安定化群の公式と :ref[thm-ant-prime-transitivity] より $|D_{\mathfrak P}|=[L:K]/g=ef$ である。$\operatorname{Gal}(k_{\mathfrak P}/k_{\mathfrak p})$ は有限体拡大の次数 $f$ 個の元を持つため、全射の核の位数が $e$ になる。
:::

$\mathfrak P'=\tau\mathfrak P$ に対して $D_{\mathfrak P'}=\tau D_{\mathfrak P}\tau^{-1}$ となる。これは $\sigma$ が $\mathfrak P'$ を固定する条件が $\tau^{-1}\sigma\tau$ が $\mathfrak P$ を固定する条件と同じだからである。同じ移送は剰余体の同型も与えるため、$I_{\mathfrak P'}=\tau I_{\mathfrak P}\tau^{-1}$ も成り立つ。

:::example[惰性する場合]
$\Q(i)$ の $3$ の上には素イデアルが一つだけあるので、分解群は位数 $2$ の全群である。不分岐だから惰性群は自明である。実際、剰余体は $\F_9=\F_3[i]$ であり、$i^3=-i$ なので複素共役が算術的 Frobenius を誘導する。
:::

:::example[完全分岐する場合]
$\Q(i)$ の $2$ の上の素イデアルは $(1+i)$ だけで、剰余体は $\F_2$ である。したがって分解群は位数 $2$、惰性群も位数 $2$ である。この場合は複素共役が非自明であっても、剰余体上では恒等である。
:::

### 完備化で分解群を実現する

分解群の各元は $\mathfrak P$ による可除性を保つ。従って $L$ 上の作用を完備化に連続に延ばせる。逆に、完備化の自己同型が $L$ に制限できることには、$L/K$ が正規であることを用いる。

:::proposition[分解群と局所 Galois 群]{#prop-ant-decomp-completion}
有限 Galois 拡大 $L/K$ と素イデアル $\mathfrak P\mid\mathfrak p$ に対し、連続延長は
$$
D_{\mathfrak P}\simeq\operatorname{Gal}(L_{\mathfrak P}/K_{\mathfrak p})
$$
を与え、この同型で惰性群は剰余体への作用の核に対応する。
:::

:::proof
$\sigma\in D_{\mathfrak P}$ は $v_{\mathfrak P}(\sigma x)=v_{\mathfrak P}(x)$ を満たすので、Cauchy 列を保つ。従って完備化に延び、その延長は稠密な部分体 $L$ での値から一意に決まる。逆元も同じ方法で延びるため、延長は自己同型である。

[付値と完備化](/math/algebraic-number-theory/valuations/) で示す完備化の直積分解により $L_{\mathfrak P}$ は $K_{\mathfrak p}$ 上有限である。$L=K(\theta)$ とすると $L_{\mathfrak P}=K_{\mathfrak p}(\theta)$ である。実際、右辺は有限拡大として完備で、稠密部分体 $L$ を含む。$\theta$ の $K_{\mathfrak p}$ 上の最小多項式は $K$ 上のものを割り、後者は $L$ で分離的に分解する。従って $L_{\mathfrak P}/K_{\mathfrak p}$ は Galois であり、任意の局所自己同型 $\tau$ は $\theta$ を $L$ の元に送る。$\tau|_L$ は $K$ 上の自己同型で、付値の一意延長により $\mathfrak P$ を固定する。従って $\tau$ は $\tau|_L$ の延長である。最後に、完備化は剰余体を変えないので惰性群も対応する。
:::

例えば $\Q(i)$ を $5$ 上のどちらかの素イデアルで完備化すると $\Q_5$ になる。共役は二つの埋め込みを交換するので、その一方を保つ局所自己同型にはならない。$3$ の上では剰余次数が $2$ で、共役は $\Q_3(i)$ の自己同型となる。$2$ の上でも共役は自己同型だが、剰余体 $\F_2$ への作用は自明である。

以下の例では、$m=p^a r$（$p\nmid r$）と分け、$K_r=\Q(\zeta_r)$ での不分岐部分と $p^a$ 乗根による完全分岐部分を使う。この分解の根拠は [円分体における素数の分解](/math/algebraic-number-theory/cyclotomic-fields/) にある。ここではその結果を使い、群の元を合同類で書き出す。

:::example[分岐する円分体の分解群を求める・法 12 と素数 2]
$L=\Q(\zeta_{12})$ において $12=4\cdot 3$ と分ける。$\zeta_{4}$ は完全分岐部分を与え、$\zeta_{3}$ は不分岐部分を与える。後者での Frobenius の指数の冪は法 $3$ で $2,1$ となる。従って分解群は指数がこの集合に入るもの、惰性群はそのうち $1\bmod 3$ に合同なものである。中国剰余定理で完全分岐側は自由に動かせる。


$$
\begin{aligned}D&=\{1,5,7,11\},& I&=\{1,7\},\\
|D|&=2\cdot2,& [G:D]&=1.\end{aligned}
$$


各元は法 $12$ の代表である。従って選んだ素イデアルでの完備化の次数は $4$ であり、剰余体は $\F_{4}$ になる。惰性作用の全てが円分根の指数を動かすが、その像はその剰余体では自明である。$D/I$ における Frobenius の位数 $2$ と、$D$ の任意の持ち上げの位数は区別する必要がある。
:::

## Frobenius 置換と Artin 記号

有限体 $k_{\mathfrak p}$ の位数を $q$ とすると、剰余拡大の Galois 群は $x\mapsto x^q$ で生成される。これを体の自己同型に持ち上げると、素点の分解を群の元として記録できる。

:::definition[Frobenius と Artin 記号]{#def-ant-frobenius}
剰余体上の $q$ 乗写像を :term[算術的 Frobenius]{en="arithmetic Frobenius" yomi="さんじゅつてきふろべにうす"} という。分岐している場合には、その逆像は $D_{\mathfrak P}/I_{\mathfrak P}$ の一つの元を与える。不分岐の場合には $I_{\mathfrak P}=1$ なので、一意な持ち上げを $\operatorname{Frob}_{\mathfrak P/\mathfrak p}$ と書く。$\mathfrak P$ を変えたときに得られる共役類を :term[Artin 記号]{en="Artin symbol" yomi="あるてぃんきごう"} と呼ぶ。アーベル拡大では一元の集合なので $(L/K,\mathfrak p)$ と書く。
:::

:::proposition[Frobenius の位数と塔]{#prop-ant-frobenius-tower}
不分岐な素点では Frobenius の位数が $f$ である。中間体 $E$ が $K$ 上 Galois で、$\mathfrak q=\mathfrak P\cap\mathcal O_E$ とすると、$\operatorname{Frob}_{\mathfrak P/\mathfrak p}$ の $E$ への制限は $\operatorname{Frob}_{\mathfrak q/\mathfrak p}$ である。また $L/E$ に対する Frobenius は $\operatorname{Frob}_{\mathfrak P/\mathfrak p}^{f(\mathfrak q/\mathfrak p)}$ である。
:::

:::proof
不分岐では :ref[thm-ant-inertia-exact] が $D_{\mathfrak P}\simeq\operatorname{Gal}(k_{\mathfrak P}/k_{\mathfrak p})$ を与える。$q$ 乗写像の位数は $f$ である。$E$ の剰余体に制限しても $q$ 乗写像となるため、制限についての主張が従う。$k_{\mathfrak q}$ に限れば $q$ 乗写像の $f(\mathfrak q/\mathfrak p)$ 乗は恒等である。$E/K$ の不分岐性と先の同型より、体の自己同型もその冪で $E$ を固定する。また $|k_{\mathfrak q}|=q^{f(\mathfrak q/\mathfrak p)}$ なので、その冪は $L/E$ の Frobenius の合同式を満たす。
:::

:::example[多項式の根に対する置換]
$X^3-2$ の分解体を $L$ とし、$5$ の上の素イデアルで根を還元する。$L$ は $\Q(\sqrt[3]2)$ と $\Q(\zeta_3)$ の合成体である。二つの判別式は $5$ で単元なので :ref[prop-ant-compositum-ramification] より不分岐である。$X^3-2$ の剰余分解には一次式と既約二次式が一つずつ出るため、Frobenius は根を一つ固定し、残りを入れ替える。異なる根の還元が一致しないのは、剰余多項式が平方因子を持たないためである。
:::

:::example[位数と素イデアル数]
$\Q(\zeta_5)$ で $2$ の Frobenius は $\zeta_5\mapsto\zeta_5^2$ である。$2^2\equiv-1$、$2^4\equiv1\pmod 5$ なので位数は $4$ であり、$2$ の上には剰余次数 $4$ の素イデアルが一つある。逆元で定義する幾何的 Frobenius を使っても位数は同じだが、合同式は $q$ 乗写像と逆になる。
:::

### 制限・持ち上げ・基底拡大

:::proposition[Frobenius の基底拡大]{#prop-ant-frob-basechange}
$L/K$ を有限 Galois 拡大、$E/K$ を有限拡大とする。$L/K$ が $\mathfrak p$ で不分岐であり、$LE$ の素イデアル $\mathfrak R$ が $\mathfrak P\subset\mathcal O_L$ と $\mathfrak q\subset\mathcal O_E$ の上にあるとする。このとき $LE/E$ は $\mathfrak q$ で不分岐で、
$$
\operatorname{Frob}(\mathfrak R/\mathfrak q)|_L
=\operatorname{Frob}(\mathfrak P/\mathfrak p)^{f(\mathfrak q/\mathfrak p)}
$$
である。
:::

:::proof
$A'=\mathcal O_{K,\mathfrak p}$、$B'=\mathcal O_L\otimes_{\mathcal O_K} A'$、$C=\mathcal O_{E,\mathfrak q}$ とする。不分岐性により $B'$ の $A'$ 上のトレース行列式は単元である。$B'\otimes_{A'}C$ の $C$ 上のトレース行列は、基底を移した同じ行列なので、行列式は引き続き単元である。分数代数 $L\otimes_K E$ は分離拡大の直積であり、その一因子は $LE$ である。各整元はトレース双対に入るので、このトレース行列式が単元であることから $B'\otimes_{A'}C$ は直積の整閉包に等しい。これは :ref[prop-ant-compositum-ramification] と同じ議論である。各直積因子の判別式は単元であり、特に $LE/E$ は $\mathfrak q$ で不分岐である。

$\mathfrak q$ の剰余体の位数は $(N\mathfrak p)^{f(\mathfrak q/\mathfrak p)}$ である。Frobenius の $L$ への制限は $\mathfrak P$ を固定し、$k_{\mathfrak P}$ 上ではこの位数による冪乗写像を誘導する。$L/K$ の惰性群が自明なので、この作用から制限が一意に決まる。
:::

分岐素点では標準的に得られるのは $D/I$ の Frobenius である。$D$ から持ち上げを選べば、持ち上げ同士は $I$ の元だけ異なる。そのため、後の Artin $L$ 因子では $V^I$ に作用を制限してから行列式を取る。任意に選んだ持ち上げを $V$ 全体で使うと、結果が選択に依存する。

:::example[Frobenius の基底拡大を追う・法 7、素数 3、二次体 2]
$K=\Q$、$L=\Q(\zeta_{7})$、$E=\Q(\sqrt{2})$ とする。$E$ の判別式は $8$ で、$p=3$ における Kronecker 記号は $-1$ である。よって $p$ の上に取った素イデアル $\mathfrak q$ の剰余次数は $2$ で、$N\mathfrak q=9$ である。$L/K$ での Frobenius は指数 $3$、その位数は $6$ である。


$$
\begin{aligned}(\operatorname{Frob}_{\mathfrak q}|_L)(\zeta_{7})&=\zeta_{7}^{9}=\zeta_{7}^{2},\\
\operatorname{ord}_{7}(2)&=3=\frac{6}{\gcd(6,2)}.\end{aligned}
$$


合成体 $LE/E$ での剰余次数は $3$ である。実際、$E_{\mathfrak q}$ を固定する自己同型は $L$ への制限で一意なので、局所 Frobenius の位数も同じになる。この式は、$p$ の上で選んだ $E$ の素イデアルが変わっても、その剰余次数が同じである限り同じ結果を与える。
:::

## 分解体と惰性体

固定体によって群の包含関係を体の塔に移せる。ここで固定体は選んだ $\mathfrak P$ に依存するので、中間体における他の素イデアルの振る舞いとは区別する。

:::definition[分解体と惰性体]{#def-ant-decomposition-inertia-fields}
$K_D=L^{D_{\mathfrak P}}$ を $\mathfrak P$ の :term[分解体]{en="decomposition field" yomi="ぶんかいたい"}、$K_I=L^{I_{\mathfrak P}}$ を :term[惰性体]{en="inertia field" yomi="だせいたい"} という。$K\subset K_D\subset K_I\subset L$ である。
:::

:::theorem[塔における分解の三段階]{#thm-ant-decomposition-tower}
$\mathfrak p_D=\mathfrak P\cap\mathcal O_{K_D}$、$\mathfrak p_I=\mathfrak P\cap\mathcal O_{K_I}$ とする。このとき次が成り立つ。

| 層 | 選んだ素イデアルの分岐指数 | 剰余次数 |
|---|---:|---:|
| $K_D/K$ | $1$ | $1$ |
| $K_I/K_D$ | $1$ | $f$ |
| $L/K_I$ | $e$ | $1$ |

$[K_D:K]=g$、$[K_I:K_D]=f$、$[L:K_I]=e$ である。
:::

:::proof
$E=L^H$ を任意の中間体とし、$\mathfrak q=\mathfrak P\cap\mathcal O_E$ とする。$L/E$ は Galois であり、その分解群は $D_{\mathfrak P}\cap H$、惰性群は $I_{\mathfrak P}\cap H$ である。剰余体 $k_{\mathfrak P}$ 上で恒等となる条件は基礎の剰余体を変えても同じだからである。

$H=D_{\mathfrak P}$ と取ると、$L/K_D$ での分岐指数と剰余次数は $e,f$ となる。塔の公式より $\mathfrak p_D/\mathfrak p$ の両指数は $1$ である。$H=I_{\mathfrak P}$ と取ると $L/K_I$ の分解群と惰性群は共に $I_{\mathfrak P}$ であり、指数は $e$、次数は $1$ になる。$K_I/K_D$ の値も塔の公式で決まる。各拡大次数は固定部分群の指数である。
:::

:::example[惰性体が全体になる場合]
$\Q(\zeta_5)$ で $2$ は不分岐かつ惰性するので、$D=G$、$I=1$ である。このとき $K_D=\Q$、$K_I=\Q(\zeta_5)$ であり、塔の寄与は全て剰余次数に現れる。
:::

:::example[分解体が全体になる場合]
同じ体で $11\equiv1\pmod 5$ だから $11$ の Frobenius は恒等であり、$D=I=1$ である。$K_D=K_I=L$ となる。完全分裂のときは一つの剰余体が大きくなる代わりに、素イデアルが体の次数と同じ個数に増える。
:::

### 任意の中間体における分解

分解体で分岐指数と剰余次数が $1$ になるのは、選んだ素イデアルについての結論である。分解群が正規でないときは、同じ中間体の別の素イデアルで異なる剰余次数が現れ得る。これを記述するには、中間体の埋め込みを分解群で動かす。

:::proposition[二重剰余類と中間体の指数]{#prop-ant-prime-double-cosets}
$E=L^H$ と置く。$E$ における $\mathfrak p$ の上の素イデアルは $D_{\mathfrak P}\backslash G/H$ と対応する。$g\in G$ に対応する素イデアルを $\mathfrak q_g$ とし、$D'=D_{\mathfrak P}\cap gHg^{-1}$、$I'=I_{\mathfrak P}\cap gHg^{-1}$ とすると
$$
e(\mathfrak q_g/\mathfrak p)=[I_{\mathfrak P}:I'],\qquad
f(\mathfrak q_g/\mathfrak p)=[D_{\mathfrak P}:I_{\mathfrak P}D']
$$
である。その積は $D_{\mathfrak P}$ が $gH$ に作る軌道の長さに等しい。
:::

:::proof
$g^{-1}\mathfrak P$ を $E$ に制限して $\mathfrak q_g$ を得る。$g$ の左から $D_{\mathfrak P}$ の元を掛けても素イデアルは変わらない。右から $H$ の元を掛けても $E$ 上は同じになる。逆に二つの元 $g_1,g_2$ が同じ $\mathfrak q$ を与えるなら、$L/E$ の推移性により $g_1^{-1}\mathfrak P=h g_2^{-1}\mathfrak P$ となる $h\in H$ がある。従って $g_1 h g_2^{-1}\in D_{\mathfrak P}$ となり、同じ二重剰余類を与える。また任意の $\mathfrak q$ は $L$ に持ち上がり、$L/K$ の推移性によってこの形になる。

$g(E)$ を中間体と見れば、選んだ $\mathfrak P$ における $L/g(E)$ の群は $D',I'$ である。従って塔の式により $e(\mathfrak q_g/\mathfrak p)=|I_{\mathfrak P}|/|I'|$、$f(\mathfrak q_g/\mathfrak p)=(|D_{\mathfrak P}|/|I_{\mathfrak P}|)/(|D'|/|I'|)$ である。$I_{\mathfrak P}$ は $D_{\mathfrak P}$ で正規なので $|I_{\mathfrak P}D'|=|I_{\mathfrak P}||D'|/|I'|$ となる。これを代入すると表示を得る。両指数の積は $[D_{\mathfrak P}:D']$ であり、$D'$ は $gH$ の安定化群である。
:::

:::example[非正規な分解体に現れる二種類の素イデアル]
$L$ を $X^3-2$ の分解体とする。群は $S_3$ である。三次多項式は既約で、虚二次体 $\Q(\zeta_3)$ を添加すると次数 $6$ になるためである。$5$ の Frobenius は互換である。根を選び直して、その互換が固定する根を $\theta$ とすれば、分解体は $E=\Q(\theta)$ になる。$G/H$ は三つの根で指標付けられ、互換の軌道は固定された一つと、交換される二つである。従って $5$ の上に剰余次数 $1$ の素イデアルと剰余次数 $2$ の素イデアルが一つずつある。選んだ素イデアルの条件を他の軌道へ拡張すると、この違いを見落とす。
:::

:::example[惰性群と分解群が別の働きをする場所]
同じ $L$ の $2$ 上の完備化では、$X^3-2$ が Eisenstein なので $\theta$ を加えた拡大は完全分岐三次である。$\zeta_3$ は $X^2+X+1\bmod2$ が既約であるため不分岐二次拡大を与える。この二つを合わせると $(e,f)=(3,2)$ であり、局所次数は $6$ になる。従って $D=S_3$、$I=C_3$ である。三次体に対応する $H$ は位数 $2$ なので $I'=1$、$D'=H$ である。二重剰余類の式から $e=3,f=1$ となり、$E$ 側では不分岐二次の寄与が消える。逆に $\Q(\zeta_3)$ に対応する $H=I$ では、$e=1,f=2$ となる。
:::

### 分解体で一つの素イデアルが消える仕組み

$D=G_{\mathfrak P}$ とし $E=L^D$ と置く。$\mathfrak q=\mathfrak P\cap E$ の上の $L/E$ の分解群は $D\cap\operatorname{Gal}(L/E)=D$ である。従って $\mathfrak q$ の上には $\mathfrak P$ が一つしかなく、$e(\mathfrak P/\mathfrak q)=|I|$ と $f(\mathfrak P/\mathfrak q)=|D/I|$ がそのまま残る。一方で $e(\mathfrak q/\mathfrak p)=f(\mathfrak q/\mathfrak p)=1$ である。ここから $\mathfrak q$ の上の局所次数が $1$ と分かる。$E/K$ が非正規なら、同じ $\mathfrak p$ の上の別の素イデアルに局所次数 $1$ が現れるとは限らない。

:::proposition[分解体と惰性体の極大性]{#prop-ant-decomposition-maximal}
$K\subset E\subset L$ とし、選んだ $\mathfrak P$ を $E$ に制限して $\mathfrak q$ とする。$e(\mathfrak q/\mathfrak p)=f(\mathfrak q/\mathfrak p)=1$ であることと $E\subset L^D$ は同値であり、$e(\mathfrak q/\mathfrak p)=1$ であることと $E\subset L^I$ は同値である。
:::

:::proof
$H=\operatorname{Gal}(L/E)$ とすると、$D\cap H$ と $I\cap H$ が $L/E$ の分解群と惰性群である。塔での乗法性から
$$
e(\mathfrak q/\mathfrak p)=[I:I\cap H],\qquad
e(\mathfrak q/\mathfrak p) f(\mathfrak q/\mathfrak p)=[D:D\cap H]
$$
となる。各指数が $1$ であることを包含 $I\subset H$、$D\subset H$ に言い換え、Galois 対応で向きを反転すればよい。
:::

:::proposition[正規中間体への分解群と惰性群の制限]{#prop-ant-inertia-quotient}
$H\triangleleft G$、$E=L^H$ とし、$\mathfrak q$ を $\mathfrak P$ の $E$ への制限とする。$E/K$ の $\mathfrak q$ における分解群は $DH/H$、惰性群は $IH/H$ である。また $\mathfrak P/\mathfrak p$ の剰余 Frobenius は、この商を経て $\mathfrak q/\mathfrak p$ の剰余 Frobenius に移る。
:::

:::proof
$E/K$ で $\mathfrak q$ を固定する自己同型を $G$ の元 $\sigma$ に持ち上げる。すると $\sigma\mathfrak P$ も $\mathfrak q$ の上にある。$L/E$ の素イデアルへの推移性により、$H$ の元を左から掛けて $\sigma\mathfrak P$ を $\mathfrak P$ に戻せる。従って $D$ の制限は全射であり、核は $D\cap H$ である。

$I$ の像は $k_{\mathfrak q}$ を固定するので $E/K$ の惰性群に入る。像の位数は $|I|/|I\cap H|$ であり、分岐指数の乗法性により $e(\mathfrak q/\mathfrak p)$ に等しい。これは $E/K$ の惰性群の位数なので、包含は等号になる。最後に $k_{\mathfrak P}$ の $|k_{\mathfrak p}|$ 乗写像を制限すると、$k_{\mathfrak q}$ でも同じ冪乗写像となる。
:::

例えば $D=I$ なら同じ選択について分解体と惰性体が一致する。一方 $I=\{1\}$ なら惰性体は $L$ 全体であり、そのときも $D$ に位数 $>1$ の元があれば分解体は真部分体である。

## アーベル拡大における素イデアルの分解

群が可換なら共役による移送で部分群も元も変わらない。このため有限素点から群への写像を乗法的に連結できる。

:::proposition[アーベル拡大での分解判定]{#prop-ant-abelian-splitting}
有限アーベル拡大で不分岐な $\mathfrak p$ に対し、$\sigma=(L/K,\mathfrak p)$ とすると $f=\operatorname{ord}(\sigma)$、$g=[L:K]/f$ である。中間体 $E=L^H$ において $\mathfrak p$ が完全分裂するための必要十分条件は $\sigma\in H$ である。
:::

:::proof
$\sigma$ は選んだ素イデアルに依存せず、:ref[prop-ant-frobenius-tower] により分解群は $\langle\sigma\rangle$ である。中間体の Frobenius は $G/H$ での像である。その位数が $1$ であることと $\sigma\in H$ は同値である。全ての指数が $1$ なので、完全分裂は剰余次数 $1$ と同値である。
:::

分岐素イデアルを避けた分数イデアル群は、許された素イデアルを基底とする自由アーベル群である。従って $\prod\mathfrak p^{n_{\mathfrak p}}\mapsto\prod(L/K,\mathfrak p)^{n_{\mathfrak p}}$ は一意な準同型を与える。どの主イデアルが核に入るかは [大域類体論の主定理](/math/algebraic-number-theory/class-field-theory/) で扱う。

:::example[双二次体の符号]
$L=\Q(i,\sqrt5)$ で $p=3$ は不分岐である。$\Q(i)$ で $X^2+1$ は $\F_3$ 上既約、$\Q(\sqrt5)$ の整数生成元の $X^2-X-1$ も $\F_3$ 上既約である。よって Frobenius は $i$ と $\sqrt5$ の符号を両方変える。位数が $2$ なので $L$ で $3$ は二つに分かれ、各剰余次数は $2$ である。積 $i\sqrt5$ の符号は変えないため、$\Q(\sqrt{-5})$ では完全分裂する。
:::

:::example[Artin 記号の積]
$\Q(i)/\Q$ では $3$ と $7$ の Artin 記号はどちらも複素共役である。したがって分数イデアル $(3)(7)^{-1}$ は Artin 記号が恒等になる。素イデアルの記号と分数イデアル全体への拡張をこの計算で区別できる。
:::

### 指標値で巡回部分体を選ぶ

$G$ が有限アーベルなら、有限位数指標 $\chi:G\to\C^\times$ により巡回部分体 $E=L^{\Ker\chi}$ を取れる。不分岐 $\mathfrak p$ の $E/K$ における剰余次数は $\chi(\operatorname{Frob}_{\mathfrak p})$ の乗法位数である。実際、$G/\Ker\chi$ が $\chi(G)$ と同型で、分解群は Frobenius の生成する部分群に制限される。互いに異なる指標の値を記録すると、大きなアーベル拡大の分解を複数の小さな商に分けて調べられる。

:::example[群の元から三つの商を同時に判定する]
$G=C_4\times C_2$ を加法で書き、Frobenius を $(2,1)$ と仮定する。第一成分への射影では位数 $2$、第二成分でも位数 $2$ である。ところが $G\to C_2$ を $(a,b)\mapsto a\bmod2$ とすると像は零であり、この商に対応する二次体では完全分裂する。同じ $\mathfrak p$ が $G\to C_2$、$(a,b)\mapsto a\bmod2+b$ に対応する二次体では惰性する。全体の元の位数は $2$ で、$L$ には $4$ 個の素イデアルが現れる。従って Frobenius の位数一つでは、どの二次部分体で分裂するかを復元できない。
:::

アーベル拡大では任意の部分群 $H$ が正規なので、:ref[prop-ant-inertia-quotient] を適用できる。特に $\mathfrak p$ が $L$ で分岐していても、$I\subset H$ なら $L^H$ では不分岐である。したがって通常の Frobenius を定められる最大の中間体は惰性体 $L^I$ である。

## 例：二次体と円分体

二次体では自己同型が二つしかないため、分解の表を直接作れる。一方で円分体では自己同型を合同類で表せるため、位数の計算に帰着する。

:::proposition[奇素数での二次体の Frobenius]{#prop-ant-quadratic-frobenius}
$d\ne1$ を平方因子を持たない非零整数とし、$p$ を $2d$ を割らない素数とする。$L=\Q(\sqrt d)$ で
$$
(L/\Q,p)(\sqrt d)=\left(\frac d p\right)\sqrt d
$$
が成り立つ。右の記号は $d$ が $p$ で平方なら $1$、そうでなければ $-1$ である。
:::

:::proof
冪基底 $(1,\sqrt d)$ の判別式 $4d$ が $p$ で単元なので、指数は $p$ と互いに素である。さらに $p$ は不分岐である。Frobenius の合同式は $\sigma(\sqrt d)\equiv(\sqrt d)^p\equiv d^{(p-1)/2}\sqrt d$ である。有限体の乗法群が巡回であることから $d^{(p-1)/2}$ は平方なら $1$、非平方なら $-1$ になる。$p$ は奇数で $\sqrt d$ は還元後も非零なので、二つの候補の符号を区別できる。
:::

:::proposition[円分体の Frobenius]{#prop-ant-cyclotomic-frobenius}
$L=\Q(\zeta_m)$ とし、$p\nmid m$ とする。このとき $p$ は不分岐であり、その Frobenius は $\zeta_m\mapsto\zeta_m^p$ である。
:::

:::proof
最小多項式 $\Phi_m$ は $X^m-1$ を $\Z[X]$ で割る。$p\nmid m$ なので、$X^m-1$ と導関数 $mX^{m-1}$ は $\F_p[X]$ 上互いに素である。従って冪基底の判別式は $p$ で単元であり、体の判別式も単元になる。また $m$ 個の根の還元は相異なる。もし二つが衝突すれば分裂している還元多項式に重根が生じるからである。よって Frobenius の合同式から $\zeta_m^p$ が体での像だと決まる。
:::

:::example[同じ次数でも異なる Frobenius]
$\Q(\zeta_8)$ の $3,5,7$ はすべて位数 $2$ の Frobenius を持つ。実際、$3^2,5^2,7^2$ はいずれも $1\bmod8$ である。ところが $\Q(i)$ への制限は法 $4$ で決まり、$5$ だけが恒等に制限される。従って全拡大での分解型だけでは各部分体での分解は決まらない。
:::

:::example[非正規部分体を軌道で調べる]
$L/K$ を有限 Galois、$E=L^H$ とし、$\mathfrak p$ を不分岐とする。$G/H$ の元 $gH$ に $\mathfrak P$ を $g(E)$ に制限し $g^{-1}$ で $E$ に戻した素イデアルを対応させる。$H$ 倍は $E$ 上恒等なので対応は剰余類に依存しない。$D_{\mathfrak P}$ の左作用は $\mathfrak P$ を固定するため同じ素イデアルを与える。逆に二つの対応先が一致すれば、$L/E$ の推移性から二つの $g^{-1}\mathfrak P$ は $H$ で共役であり、二つの剰余類は同じ $D_{\mathfrak P}$ 軌道に入る。剰余類 $gH$ の軌道長は $|D_{\mathfrak P}|/|D_{\mathfrak P}\cap gHg^{-1}|$ で、塔の公式により対応先の剰余次数である。例えば $X^3-2$ の三つの根に対する互換の軌道長が $1,2$ なら、三次体における分解型は $(1,2)$ になる。
:::

### 多項式の判別式と符号

:::proposition[根への置換の符号]{#prop-ant-frob-sign}
$F$ を $\Z[X]$ のモニック分離多項式、$L$ を分解体とする。奇素数 $p$ が $\operatorname{disc}(F)$ を割らないとし、$F\bmod p$ の既約因子の個数を $r$、次数を $n=\deg F$ とする。このとき
$$
\left(\frac{\operatorname{disc}(F)}p\right)=(-1)^{n-r}.
$$
:::

:::proof
$p$ を割る素イデアルで $F$ の根の剰余は相異なる。各根の剰余を固定する惰性群は、根を一つずつ固定するから自明である。Frobenius の各サイクルの長さは法 $p$ の既約因子次数に等しい。長さ $d$ の巡回置換の符号は $(-1)^{d-1}$ なので、全体の符号は $(-1)^{n-r}$ である。一方、根の差の積 $\Delta$ は置換の符号を掛けられ、$\Delta^2=\operatorname{disc}(F)$ である。還元後に $\Delta\ne0$ で、$\Delta^{p-1}=(\Delta^2)^{(p-1)/2}$ がその符号に一致する。Euler の判定法を適用すると結論が従う。
:::

例えば三次の場合、型 $(3)$ と $(1,1,1)$ の置換は偶置換、型 $(1,2)$ は奇置換である。判別式の平方剰余記号が $1$ でも、二つの偶置換の型は区別できない。そこで具体的な根の数を追加で調べる。

### 実素点と無限素点の分岐

$v$ を $K$ の実埋め込み、$\tau$ をその $L$ への延長とし、$\tau$ と $\bar\tau$ を同じ無限素点 $w$ と見なす。$G$ は $v$ への制限を持つ埋め込みに合成で推移的に作用するので、無限素点にも推移的に作用する。$w$ の分解群は $\tau\circ\sigma\in\{\tau,\bar\tau\}$ を満たす $\sigma\in G$ の集まりである。$\tau$ が実埋め込みなら群は自明であり、$v$ の上に $[L:K]$ 個の実素点がある。$\tau$ が非実埋め込みなら、$v$ が実であるため $\bar\tau$ も $v$ を延長する。従って $\tau\circ\sigma=\bar\tau$ となる $\sigma$ が存在し、二度合成すると恒等に戻る。分解群はこの複素共役で生成される位数 $2$ の群であり、$v$ の上には $[L:K]/2$ 個の複素素点がある。この場合を $v$ の分岐と呼ぶ。

一方、$v$ が複素素点なら、その共役対から代表を一つ選ぶと、$w$ に属する埋め込みのうちちょうど一つがその代表を延長する。従って分解群は自明である。例えば $\Q(i,\sqrt5)/\Q$ では唯一の実素点が分岐し、上には二つの複素素点がある。各分解群の非自明元は $i$ を $-i$ に送り、$\sqrt5$ を固定する。

:::example[三次多項式の因子と二次部分体を同時に読む・素数 5]
$F=X^3-2$ の分解体は $\Q(\sqrt[3]2,\zeta_3)$ であり、群は $S_3$ である。三次多項式は Eisenstein で、さらに原始三乗根が実三次体に含まれないので分解体の次数は $6$ である。$p=5$ は判別式 $-108$ を割らないため、剰余の既約因子が Frobenius の巡回を与える。


$$
\begin{aligned}\overline F(X)&=\left(X + 2\right)\left(X^{2} - 2 X - 1\right),&\text{巡回長}&=(1,2),\\
\operatorname{ord}(\operatorname{Frob})&=2,& \left(\frac{-108}{5}\right)&=-1.\end{aligned}
$$


Frobenius の符号は $(-1)^{3-2}=-1$ であり、これは二次部分体 $\Q(\sqrt{-3})$ での作用に一致する。一方、分解体全体での素イデアル数は $6/2=3$ である。三次部分体では法 $5$ の因子数 $2$ が素イデアル数になる。この二つの個数を求めるための群の作用は、一方が正則作用、他方が三つの根への作用である。
:::

## 演習問題

::::exercise{level=basic}
$[L:K]=12$ の Galois 拡大で、ある素イデアルの分岐指数を $2$、剰余次数を $3$ とする。上にある素イデアル数と分解群の位数を求めよ。
:::solution
$ef=2\cdot3=6$ なので $g=12/6=2$ である。分解群は素イデアル集合への作用の安定化群なので、位数は $12/2=6$ である。
:::
::::

::::exercise{level=basic}
$\Q(i)$ で $11$ と $13$ の Frobenius を求めよ。
:::solution
$i$ の位数は $4$ で、両素数は $4$ と互いに素である。従って $i$ の像は $i^{11}=i^3=-i$、$i^{13}=i$ となる。$11$ は複素共役、$13$ は恒等である。
:::
::::

::::exercise{level=basic}
$\Q(\zeta_7)$ における $2$ の剰余次数と素イデアル数を求めよ。
:::solution
$2,2^2,2^3$ の法 $7$ での剰余は $2,4,1$ なので剰余次数は $3$ である。円分体の次数は $\varphi(7)=6$ だから素イデアル数は $6/3=2$ である。
:::
::::

::::exercise{level=basic}
$\Q(\sqrt{13})$ で $3$ と $5$ は分裂するか。
:::solution
$13\equiv1\pmod3$ は平方なので $3$ は分裂する。$13\equiv3\pmod5$ は非平方である。実際、法 $5$ の非零平方は $1,4$ なので $5$ は惰性する。
:::
::::

::::exercise{level=advanced}
全ての不分岐な $\mathfrak p$ で、その Artin 記号の代表元の位数が $1$ であることと、$\mathfrak p$ が完全分裂することの同値を、群が可換とは仮定せず示せ。
:::solution
不分岐時は惰性群が自明なので、$D_{\mathfrak P}$ は剰余体の Galois 群と同型であり、Frobenius で生成される。従って代表元の位数が $1$ なら分解群は自明で、軌道長は $[L:K]$ である。逆に完全分裂では軌道長が $[L:K]$ なので安定化群は自明である。共役元の位数は変わらないので代表元の選び方に依存しない。
:::
::::

::::exercise{level=advanced}
$L/K$ が有限アーベル拡大で、素イデアル $\mathfrak p$ の分解体が $K_D$ であるとする。$\mathfrak p$ が $K_D$ で完全分裂することを分岐の場合も含めて証明せよ。
:::solution
可換群の部分群 $D$ は正規なので $K_D/K$ は Galois である。:ref[thm-ant-decomposition-tower] により選んだ素イデアルの $e,f$ はともに $1$ である。:ref[thm-ant-prime-transitivity] により他の素イデアルでも $e=f=1$ である。基本等式を適用すると素イデアル数は $[K_D:K]$ であり、完全分裂する。
:::
::::

::::exercise{level=advanced}
$\Q(\zeta_{15})$ で $2$ が分解する個数を求め、$\Q(\zeta_3)$ と $\Q(\zeta_5)$ での剰余次数から説明せよ。
:::solution
法 $3$ で $2$ の位数は $2$、法 $5$ では $4$ である。中国剰余定理によって法 $15$ での位数はその最小公倍数 $4$ である。$2\nmid15$ なので不分岐であり、次数 $\varphi(15)=8$ を $4$ で割ると素イデアル数 $2$ が得られる。
:::
::::

::::exercise{level=advanced}
$\Q(i,\sqrt5)$ の $3$ の分解体と惰性体を求めよ。
:::solution
$3$ は不分岐で、Frobenius は $i,\sqrt5$ を共に負に移す。従って分解群はこの位数 $2$ の元で生成される。その固定体は次数 $2$ であり、固定元 $i\sqrt5$ が有理数でないので $\Q(\sqrt{-5})$ である。惰性群は自明なので惰性体は $\Q(i,\sqrt5)$ 全体である。
:::
::::

::::exercise{level=advanced}
$\Q(\zeta_{13})$ における $3$ の分解体の次数を求め、その上に残る拡大を述べよ。

:::solution
法 $13$ における $3$ の冪は $3,9,1$ である。分解群の位数は $3$、惰性群は自明なので分解体の次数は $12/3=4$ である。分解体では $3$ が四つの素イデアルに分かれ、その各々の上に剰余次数 $3$ の不分岐三次拡大が残る。
:::
