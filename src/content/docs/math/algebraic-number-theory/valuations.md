## この章の目標

- 絶対値の同値性を定義し、代数体の素点を分類する。
- 弱近似によって有限個の素点で元を近似する。
- 完備体上での絶対値の一意性と、完備化の直積分解を示す。
- 無限素点と有限素点の正規化を選び、積公式を導く。

## 絶対値と付値

素イデアルによる可除性を桁数として記録すると、二つの元の差がどれほど深く割れるかを測れる。一方、実数や複素数への埋め込みでは通常の距離を使う。

:::definition[絶対値と素点]
体 $K$ 上の :term[絶対値]{en="absolute value" yomi="ぜったいち"} は、零元でのみ $0$ となり、乗法的で三角不等式を満たす写像 $K\to\R_{\ge0}$、$x\mapsto\abs{x}$ である。$\abs{x+y}\le\max(\abs{x},\abs{y})$ が成り立つとき非 Archimedes 的という。$K^\times$ 上で恒等的に $1$ である絶対値を自明と呼ぶ。非自明な絶対値が定める位相の同値類を :term[素点]{en="place" yomi="そてん"} という。代数体 $K$ の素点全体を $M_K$ と書く。
:::

非 Archimedes 的な絶対値から $v(x)=-\log\abs{x}$（$x\ne0$）、$v(0)=+\infty$ と置く。これは $v(xy)=v(x)+v(y)$、$v(x+y)\ge\min(v(x),v(y))$ を満たす加法付値である。逆に、この条件を満たす実数値付値から $c^{-v(x)}$（$c>1$）によって非 Archimedes 的な絶対値を得る。$v(K^\times)$ が非零かつ離散なら、その最小正元で割って $v(K^\times)=\Z$ と正規化できる。この $v$ を :term[離散付値]{en="discrete valuation" yomi="りさんふち"} と呼び、$v(\pi)=1$ を満たす元 $\pi$ を一様化元という。$\{x:v(x)\ge0\}$ は付値環、$\{x:v(x)>0\}$ は極大イデアルである。$\abs{x}>\abs{y}$ のとき $\abs{x+y}=\abs{x}$ である。上からは強三角不等式、下からは $x=(x+y)-y$ に同じ不等式を使う。

:::proposition[絶対値の同値条件]{#prop-ant-absolute-equivalence}
二つの非自明な絶対値が同じ位相を定めることと、片方が他方の正の実数乗であることは同値である。
:::

:::proof
正の冪を取っても零の近傍が同じになる。逆に位相が同じなら、$x^n\to0$ の条件から $\abs{x}_1<1$ と $\abs{x}_2<1$ が同値になる。$a$ を $\abs{a}_1>1$ として固定する。任意の有理数 $m/n$ に対し $\abs{x^n a^{-m}}_i<1$ は $\log\abs{x}_i/\log\abs{a}_i<m/n$ と同値であり、左右の絶対値で真偽が一致する。有理数の稠密性から二つの比が一致する。これを指数に戻せばよい。
:::

$\Q$ 上の $5$ 進加法付値は $v_5(75/14)=2$ で、$\abs{75/14}_5=1/25$ となる。これに対し $\abs{75/14}_\infty=75/14$ であり、$5^n$ が前者で零に近づき後者で発散することから素点は異なる。

### 絶対値が与える球の構造

:::proposition[非 Archimedes 的な球]{#prop-ant-ultrametric-balls}
非 Archimedes 的な絶対値に対し $B_r(a)=\{x:\abs{x-a}\le r\}$、$r>0$ とする。$b\in B_r(a)$ なら $B_r(a)=B_r(b)$ である。二つの閉球が交われば小さい方が大きい方に含まれる。また $B_r(a)$ は開集合でもある。
:::

:::proof
$x$ が $B_r(a)$ に属すれば $\abs{x-b}\le\max(\abs{x-a},\abs{a-b})\le r$ である。$a,b$ を交換すれば等号になる。半径 $r\le R$ の二つの球に共通点 $z$ があればどちらも中心を $z$ に取れるので包含が得られる。さらに $x\in B_r(a)$ の開球 $\abs{y-x}<r$ は $B_r(a)$ に入るので、各 $x$ は内点である。
:::

離散付値の場合、整数環内で半径 $q^{-n}$ の球は剰余類 $a+\pi^n\mathcal O$ である。例えば $\Z_3$ の半径 $1/9$ の球 $4+9\Z_3$ は中心を $13$ に変えられるが、半径を $1/27$ に下げると $4+27\Z_3$、$13+27\Z_3$、$22+27\Z_3$ に分かれる。半径の値が値群に入らない場合、隣の値群の元まで半径を下げても球が同じことがある。

### 離散性の仮定

非 Archimedes 的な値群には離散でないものもある。例えば $\bigcup_n\Q_p(p^{1/n!})$ の絶対値を延長して $v(p)=1$ とすると、一様化の役割を果たす最小正値は存在しない。実際 $X^{n!}-p$ は Eisenstein で、根は付値 $1/n!$ を持つ。正の付値を持つ元全体のイデアルを一元生成と仮定すると、その生成元より小さい正の付値を持つ元がそのイデアルに入ることに反する。従って強三角不等式だけから DVR 性は従わない。

## 代数体の絶対値と Ostrowski の定理

:::theorem[Ostrowski の定理]{#thm-ant-ostrowski}
$\Q$ の非自明な絶対値は通常の絶対値またはただ一つの素数に対する $p$ 進絶対値と同値である。
:::

:::proof
全ての正整数 $m$ が $\abs m\le1$ を満たせば、二項展開により $\abs{x+y}^n\le(n+1)\max(\abs x,\abs y)^n$ となる。$n$ 乗根を取って極限を取ると非 Archimedes 的である。$\{m\in\Z:\abs m<1\}$ は素イデアルである。非自明な絶対値ならこのイデアルは非零であり、$(p)$ と書ける。$p$ と互いに素な整数は絶対値 $1$ なので、素因数分解により $\abs x=\abs p^{v_p(x)}$ である。

ある整数 $b\ge2$ が $\abs b>1$ を満たす場合を考える。任意の $m\ge2$ の $m^n$ を $b$ 進表示すると、桁は $b$ 未満で桁数は $\lfloor n\log_b m\rfloor+1$ である。各桁の絶対値の上限を $C_b$ とすると、三角不等式で
$$
\abs m^n\le C_b(\lfloor n\log_b m\rfloor+1)\max(1,\abs b)^{n\log_b m}
$$
となる。$n$ 乗根の極限から $\log\abs m\le(\log m/\log b)\log\abs b$ である。同じ議論で底を $m$ にして、もし $\abs m\le1$ なら $\abs b\le1$ となる矛盾を得る。従って $\abs m>1$ であり、底を交換した不等式から両辺が等しくなる。整数での等式から分数でも通常の絶対値の同じ冪になる。最後に、素数 $p$ 自身の値は $p$ 進では $1$ 未満、他の素数に対応する絶対値では $1$、通常の絶対値では $1$ より大きい。この区別は正の冪を取っても保たれるので、分類した素点は互いに異なる。
:::

有限代数拡大において非自明な絶対値の制限が自明になることはない。実際、制限が自明なら、$\abs{x}>1$ の元のモニック方程式を右辺の低次の和で評価し、同じ議論を $x^n$ の最小多項式に適用すると $\abs{x}^n$ は拡大次数以下になる。$x^{-1}$ も同じ議論で $\abs{x}^{-1}\le1$ となるからである。

非 Archimedes 的な $\Q$ 上の絶対値を延長すると、絶対値 $1$ 以下の環は $\mathcal O_K$ を含む。二項係数の絶対値は $1$ 以下なので上の二項展開により依然として非 Archimedes 的であり、整方程式において $\abs{x}>1$ なら最高次項だけが最大となって矛盾する。$\mathcal O_K$ の中で絶対値 $1$ 未満の集合 $\mathfrak p$ は $p$ 上の素イデアルである。そこで $A=(\mathcal O_K)_{\mathfrak p}$ の単元は絶対値 $1$ で、一様化元の値が $1$ 未満だから、絶対値は $v_{\mathfrak p}$ の指数表示である。逆に各 $\mathfrak p$ の離散付値は絶対値を与える。

通常の絶対値を延長する場合、後で示す有限拡大の完備化分解により、完備体は $\R$ または $\C$ である。従って無限素点は実埋め込み一つずつと、複素埋め込みの共役対一つずつに対応する。実際、同値な絶対値でも $\Q$ 上の制限を通常の絶対値にそろえると、$2$ の値を比較することで冪指数が $1$ と分かる。従って二つの埋め込みが同じ素点を定めるなら、それらは完備化の $\R$ 上の同型で結ばれる。そのような $\C$ の自己同型は恒等と複素共役だけであり、$\R$ の自己同型は恒等だけである。例えば $\Q(i)$ の二つの埋め込みは同じ絶対値を与え、$\Q(\sqrt2)$ の二つの埋め込みは $1+\sqrt2$ で異なる大小関係を与える。

### 素点の制限と代表の選び方

例えば $K=\Q(\sqrt5)$ では $2$ は惰性、$5$ は分岐し、$11$ は分裂する。整数基底の元 $(1+\sqrt5)/2$ は $X^2-X-1$ を満たし、法 $2$ では $X^2+X+1$、法 $5$ では $(X-3)^2$、法 $11$ では $(X-4)(X-8)$ となるためである。そこで $11$ 上の二つの付値はどちらも $\Q$ 上で $11$ 進付値に制限される。しかし、元 $\theta-4$ は一方で正、他方で零の付値を持つ。制限した絶対値が同値であることは、延長した絶対値が同値であることを意味しない。

$\mathfrak P$ の整数値付値を $v_{\mathfrak P}$、$p$ 上の分岐指数を $e$ とすると $v_{\mathfrak P}(p)=e$ である。$\Q_p$ の値と一致する絶対値は $p^{-v_{\mathfrak P}(x)/e}$ である。一方、局所 Haar 測度と積公式に合わせた大きさは $(p^f)^{-v_{\mathfrak P}(x)}$ である。両者の比は定数ではなく、後者が前者の $ef$ 乗である。例えば $\Q(\sqrt5)$ の $5$ 上では $\sqrt5$ が付値 $1$ で、前者は $5^{-1/2}$、後者は $5^{-1}$ となる。

## 弱近似定理

有限個の異なる素点では、一つの元で別々の指定値に近づける。基礎体だけで行える近似であり、無限個の合同条件は含まない。

:::theorem[弱近似]{#thm-ant-weak-approximation}
互いに非同値な非自明な絶対値 $\abs{\cdot}_1,\ldots,\abs{\cdot}_r$ について、対角写像 $K\to\prod_{i=1}^r K_i$ の像は稠密である。$K_i$ は各絶対値における完備化とする。
:::

:::proof
素点が一つなら完備化の定義から従う。以下では二つ以上とする。

まず二つの非同値な値なら、第一で $>1$、第二で $<1$ となる元がある。実際、$\abs{x}_1<1$ と $\abs{x}_2<1$ の集合が同じなら :ref[prop-ant-absolute-equivalence] の証明で同値になる。第一の集合だけに入る元があるなら、逆元を取って $\abs{x}_1>1,\abs{x}_2\le1$ を得る。第二で値が $1$ なら、第二で $<1$ の元を掛ける前に $x$ を十分大きい冪にして第一の厳密な不等式を保つ。第二の集合だけに入る元がある場合は、直接 $\abs{x}_1\ge1,\abs{x}_2<1$ となる。第一で値が $1$ なら、第一で $>1$ の元を掛ける前に $x$ を十分大きい冪にして第二の厳密な不等式を保つ。

次に $r$ について帰納し、第一で $>1$、他で $<1$ となる元を作る。先に第一で $>1$、第 $2$ から第 $r-1$ で $<1$ となる $a$ と、第一で $>1$、第 $r$ で $<1$ となる $b$ を取る。$\abs a_r<1$ なら $a$ が使える。$\abs a_r=1$ なら $a^nb$ が使える。$\abs a_r>1$ なら $a^n b/(1+a^n)$ は第一と第 $r$ で $b$ に、途中の全ての素点で $0$ に収束するので十分大きい $n$ で条件を満たす。

第一を各 $i$ に置き換え、そこで大きく他で小さい $a_i$ を取る。$a_i^n/(1+a_i^n)$ は第 $i$ 成分で $1$、他で $0$ に向かう。従って $x_i\in K$ に対し $\sum_i x_i a_i^n/(1+a_i^n)$ は各 $x_i$ に同時に近づく。任意の完備化の成分は $K$ の元で前もって近似できるので結論が従う。
:::

例えば $x\equiv2\bmod9$ かつ $x\equiv1\bmod5$ を満たす整数は $11+45\Z$ である。さらに実数として $0$ に近づけるには $x=11+45n$ とするだけでは足りない。代わりに任意の大きな $q\equiv1\bmod45$ を取り $x=11/q$ とすれば合同条件を保って実数として小さくなる。

### 有限素点と実素点を合同式で同時に近似する

$S=\{p_1,\ldots,p_r\}$ を有理素数の有限集合とする。目標 $a_i\in\Q_{p_i}$ と誤差 $p_i^{-m_i}$ を指定する。まず $D=\prod p_i^{h_i}$ の指数を大きく取って $Da_i\in\Z_{p_i}$ とし、さらに $m_i+h_i>0$ とする。整数 $b_i$ で $b_i\equiv Da_i\bmod p_i^{m_i+h_i}$ を満たすものを取り、$M=\prod p_i^{m_i+h_i}$ とすると、中国剰余定理で $b\equiv b_i\bmod p_i^{m_i+h_i}$ を同時に解ける。従って $b/D$ は全ての有限条件を満たす。

実数 $a$ への近似も指定するなら、$Q$ を $1\bmod M$ に合同な大きい正整数とし、$b$ を $M$ の倍数だけ動かして $b/(DQ)$ を $a$ に最も近くする。有限素点では $Q$ が単数で $Q\equiv1\bmod p_i^{m_i+h_i}$ なので条件は保たれ、実数での間隔 $M/(DQ)$ は零に近づく。分母が $S$ に属さない素数を含む可能性は、後の強近似との違いである。

## 完備化と完備付値体

:::definition[完備化]
絶対値から得る距離 $d(x,y)=\abs{x-y}$ で、すべての Cauchy 列が収束する体を完備という。Cauchy 列を、差が零に収束する場合に同一視して得る体を :term[完備化]{en="completion" yomi="かんびか"} と呼び、$K_v$ と書く。
:::

Cauchy 列は有界なので、和と積を成分ごとに取っても Cauchy 列になる。零でない同値類では絶対値の極限が正であり、十分後ろの項の逆数は Cauchy 列になる。絶対値の極限が新しい絶対値で、定数列の像は稠密である。完備性は、新しい体の Cauchy 列の第 $n$ 項を距離 $2^{-n}$ 未満で定数列により近似し、近似列の同値類を極限に取ることで示せる。連続な体の埋め込みは稠密な部分体での値によって一意に決まり、絶対値を保つ埋め込みから完備体への延長は列の極限で与えられる。

離散付値では付値環の完備化は $\varprojlim A/\pi^n A$ と同型である。Cauchy 列の各桁は安定し、逆に整合的な剰余類の持ち上げを選ぶと Cauchy 列になる。完備化で新たに非零の値が増えないのは、非零元に十分近い近似元は同じ付値を持つためである。例えば $\Q_{{5}}$ で $1+5+5^2+\cdots=1/(1-5)=-1/4$ となる。通常の絶対値ではこの級数は発散する。

### 逆極限と桁の繰り上がり

:::proposition[桁展開と絶対値]{#prop-ant-completion-digits}
$A$ を離散付値環、$\pi$ を一様化元とする。$A/\pi A$ の代表系 $R$ を $0$ を含めて選べば、$\widehat A$ の各元は $\sum_{j\ge0}a_j\pi^j$（$a_j\in R$）と一意に書ける。最初に異なる桁の添字が $n$ なら、二元の差の付値は $n$ である。
:::

:::proof
まず法 $\pi$ で $a_0$ を選び、差を $\pi$ で割って同じ操作を繰り返す。$\widehat A$ は離散付値の完備化であるから、割った元がまた $\widehat A$ に入る。部分和との差は $\pi^{n+1}$ で割れ、完備性から表示が収束する。二つの表示で最初に異なる桁の差は剰余体で非零であり、高い桁の差はいずれも $\pi^{n+1}$ で割れる。これで一意性と付値の主張が同時に従う。
:::

例えば $\Z_5$ の $-1$ の展開は $4+4\cdot5+4\cdot5^2+\cdots$ である。第 $n$ 桁までの和が $5^{n+1}-1$ なので、差の付値が $n+1$ になる。一方、$\F_5[[T]]$ では $-1=4$ で高い桁は不要である。同じ有限剰余体を持っていても、代表元を足したときに桁の繰り上がりがあるかは標数に依る。

## 完備体における付値の拡張の一意性

非 Archimedes 的な絶対値を有限代数拡大へ延長するには :ref[thm-comm-chevalley] で付値環を延長する。付値を延長したときの値群の指数 $e$ は拡大次数以下である。異なる値群の剰余類から代表元を取ると、それらの線形結合で最小付値の項が一つに決まり、線形独立になるためである。新しい値群の元 $\gamma$ は $e$ 倍すると元の値群に入る。そこで元の値群で $e\gamma$ を実数とみなし、$e$ で割った数を $\gamma$ に割り当てる。この対応は順序を保つ単射であり、もとの付値環に対応する絶対値を延長できる。

:::proposition[完備 Archimedes 体の分類]{#prop-ant-complete-archimedean}
Archimedes 的な絶対値を持つ完備体は $\R$ または $\C$ に同型である。絶対値は通常の絶対値の正の冪である。
:::

:::proof
全整数の絶対値が $1$ 以下なら二項展開によって非 Archimedes 的になるので、標数は $0$ である。Ostrowski の定理により $\Q$ 上の絶対値は通常の絶対値の $\alpha$ 乗であり、$0<\alpha\le1$ である。$|x|_0=|x|^{1/\alpha}$ と置く。二項展開の第 $j$ 項のもとの絶対値は $\bigl(\binom nj |x|_0^j|y|_0^{n-j}\bigr)^\alpha$ で、これは $(|x|_0+|y|_0)^{n\alpha}$ 以下である。従って $|x+y|_0\le(n+1)^{1/(n\alpha)}(|x|_0+|y|_0)$ となる。極限を取れば三角不等式が従い、$|\cdot|_0$ は $\Q$ 上で通常の絶対値と一致する。完備性により $\R$ が入る。

$K$ が $i$ を含む場合、埋め込まれた $\C$ 上で $|\cdot|_0$ は通常の絶対値に等しい。実際、通常の絶対値が $1$ の複素数 $z$ について、$z^n$ の実部と虚部はともに $1$ 以下の絶対値を持つ。$|i|_0=1$ だから $|z^n|_0\le2$ であり、$z^{-1}$ にも同じ議論を使うと $|z|_0=1$ になる。任意の非零複素数はこのような元と正の実数の積である。従って $K$ は複素 Banach 体であり、:ref[thm-fa-gelfand-mazur] により $\C$ に等しい。

$K$ が $i$ を含まない場合、$K[i]=K[X]/(X^2+1)$ は体である。$a+ib$ に $M(a+ib)=\sup_\theta|a\cos\theta-b\sin\theta|_0$ を割り当てると、これは複素スカラーに関して通常の絶対値で斉次である。また $\max(|a|_0,|b|_0)\le M(a+ib)\le |a|_0+|b|_0$ なので完備である。積の実部と虚部をそれぞれ評価すると $M(zw)\le4M(z)M(w)$ である。そこで $z$ 倍写像の作用素ノルムを使えば、これは $M(z)\le\norm z\le4M(z)$ を満たし、積について劣乗法的で $\norm 1=1$ となる。こうして同じ定理を適用でき、$K[i]=\C$ である。$a+ib\mapsto a-ib$ は $\R$ を固定して $i$ を $-i$ に送るので複素共役であり、その固定体は $K=\R$ である。
:::

:::theorem[絶対値の一意延長]{#thm-ant-valuation-extension}
完備絶対値体 $K$ の任意の有限拡大 $L$ に絶対値が一意に延長し、$L$ も完備になる。延長は $\abs{x}_L=\abs{N_{L/K}(x)}_K^{1/[L:K]}$ で与えられる。
:::

:::proof
非 Archimedes 的な場合の存在は先の付値環の議論による。Archimedes 的な場合、:ref[prop-ant-complete-archimedean] により真の拡大は $\R$ から $\C$ への拡大だけである。通常の絶対値の冪の指数は $1$ 以下なので、同じ冪を複素絶対値に用いれば延長が得られる。

延長した絶対値を $K$ ベクトル空間 $L$ のノルムと見る。任意の基底に対する座標最大ノルムと同値になる。上からの評価は三角不等式による。下からの評価を次元で帰納する。基底の最後の元を $b$、残りの張る空間を $W$ とすると、帰納法から $W$ は完備である。よって $W$ は閉で、$b$ から $W$ への距離は $\delta>0$ である。$w+ab$ のノルムは $\delta\abs a$ 以上であり、$\norm w\le\norm{w+ab}+\abs a\norm b$ なので、帰納法による $w$ の座標も $\norm{w+ab}$ の定数倍で抑えられる。よって全体の完備性も従う。

二つの延長は座標ノルムと同値なので比は上下から正の定数で抑えられる。$x^m$ で比較して $m$ 乗根を取れば、二つの値は等しい。分離拡大では正規閉包への延長は全共役の値を等しくする。ノルムは共役の積であり、非分離拡大なら分離共役を非分離次数ずつ重ねて数える。よってノルムの式となる。
:::

無限素点の場合、$\Q$ の通常の値の完備化は $\R$ であり、有限拡大は $\R$ と $\C$ だけである。両方には通常の絶対値が存在するから、一意性の証明が適用される。$\C/\R$ では $N(z)=z\bar z$ なのでノルム公式は $\abs z$ を返す。

:::proposition[完備離散付値体の有限拡大と基本等式]{#prop-ant-complete-dvr-degree}
$K$ を完備離散付値体、$L/K$ を有限拡大とする。延長した付値の値群の指数を $e$、剰余次数を $f$ とすると $[L:K]=ef$ である。$L$ の一様化元 $\pi_L$ と、剰余体の基底の持ち上げ $b_1,\ldots,b_f$ を選べば、$\pi_L^i b_j$（$0\le i<e$、$1\le j\le f$）は $\mathcal O_L$ の $\mathcal O_K$ 基底をなす。
:::

:::proof
値群の指数 $e$ は有限であり、$v_K$ を延長した付値 $\widetilde v$ の値群は $\frac1e\Z$ である。剰余体で独立な元の持ち上げは $K$ 上独立である。実際、線形関係の係数を基礎の一様化元の冪で割り、最小付値を零にそろえて還元すると、剰余体で非自明な関係が得られてしまう。このため $f$ も有限である。さらに $v_L=e\widetilde v$ として整数値に直すと、添字 $i$ が異なる項の付値は法 $e$ で異なり、同じ $i$ の項は先の剰余の独立性で最小付値が保たれる。従って $\pi_L^i b_j$ は $K$ 上独立である。

任意の非零整元から始め、その付値を $er+i$ と書く。$\pi_K^r\pi_L^i$ で割った剰余を $\bar b_j$ で表し、その係数を持ち上げた一次結合を引けば、残差の付値は少なくとも $1$ 増える。残差が零になれば表示が得られる。反復を続ける場合も付値は無限大に向かい、各係数の補正は $\pi_K^r$ の倍数で $r$ が増大するので、$\mathcal O_K$ で収束する。極限の係数を使うと元の整元が表示される。よってこれらは $\mathcal O_K$ 基底であり、分数体に移すと次数は $ef$ になる。
:::

### 行列式で延長した付値を求める

:::corollary[ノルムによる局所付値]{#cor-ant-via-norm}
完備離散付値体の有限拡大 $L/K$ において、$v_K$、$v_L$ をそれぞれ整数値に正規化し、$n=[L:K]$、$e=e(L/K)$ とする。任意の $a\in L^\times$ について
$$
v_K(N_{L/K}a)=\frac ne\,v_L(a)
$$
が成り立つ。また $n/e=f$ である。
:::

:::proof
$K$ の絶対値を $c^{-v_K}$ とする。一意延長した値は $c^{-v_L/e}$ である。:ref[thm-ant-valuation-extension] のノルム式で指数を比較すればよい。最後の等式は :ref[prop-ant-complete-dvr-degree] による。
:::

例えば $L=\Q_7(\sqrt7)$ では $e=2$、$f=1$ である。$1+\sqrt7$ のノルムは $-6$ で $7$ 進単数だから、元自身も単数である。一方 $7+\sqrt7$ のノルムは $42$ なので $v_L(7+\sqrt7)=1$ である。これは二項の $v_L$ がそれぞれ $2,1$ で最小値が一意になることとも一致する。$K$ の値を延長した $v_L/2$ では同じ元の値は $1/2$ である。

:::example[延長した付値をノルムから計算する・2 進二次体、平方根 2]
$L=\Q_{2}(\alpha)$、$\alpha^2=2$ とする。方程式は Eisenstein なので $e=2$, $f=1$ である。 元 $u=6+1\alpha$ の乗法行列は基底 $1,\alpha$ に関して次のとおりである。


$$
\begin{aligned}M_u&=\left[\begin{matrix}6 & 2\\1 & 6\end{matrix}\right],&N(u)&=6^2-2\cdot 1^2=34,\\
v_{2}(N(u))&=1,&v_L(u)&=1,& \abs{u}_{\mathrm{ext}}&=\frac{\sqrt{2}}{2}.\end{aligned}
$$


$v_L$ は $L$ で整数値に正規化している。$\abs{\cdot}_{\mathrm{ext}}$ は $\Q_{2}$ の絶対値を延長したものなので、$p^{-v_L(u)/e}$ を返す。二項の $v_L$ は $2$ と $1$ である。最小値を持つ項が一つなので、その最小値からも確認できる。
:::

:::example[延長した付値をノルムから計算する・3 進二次体、平方根 3]

$v_L$ は $L$ で整数値に正規化している。$\abs{\cdot}_{\mathrm{ext}}$ は $\Q_{3}$ の絶対値を延長したものなので、$p^{-v_L(u)/e}$ を返す。二項の $v_L$ は $4$ と $1$ である。最小値を持つ項が一つなので、その最小値からも確認できる。
:::

:::example[延長した付値をノルムから計算する・5 進二次体、平方根 5]

## 不完備な体における付値の拡張と素イデアルの分解

:::theorem[完備化の直積分解]{#thm-ant-completion-product}
有限分離拡大 $L/K$ と素点 $v$ に対し
$$
L\otimes_K K_v\simeq \prod_{w\mid v} L_w
$$
が成り立つ。代数体の有限素点では $[L_w:K_v]=e(w/v)f(w/v)$ である。
:::

:::proof
$L=K[\alpha]$ の最小多項式 $F$ を $K_v[X]$ で相異なる既約多項式 $F_i$ に分ける。中国剰余定理で左辺は $\prod K_v[X]/(F_i)$ になる。各因子は一意な絶対値を持つ完備体で、$K[\alpha]$ の像が稠密である。任意の因子の元は $\alpha$ の像の多項式として書け、その係数を $K$ の中で近似できるからである。逆に $L_w$ では $\alpha$ が満たす $F$ の因子が一つあり、対応する因子体の像は完備なので閉である。そこに稠密な $L$ が入るため、像は $L_w$ になる。二つの異なる因子が同じ絶対値を与えるなら完備化の一意性により $K_v$ 上同型で、$\alpha$ の像を保つので最小多項式が一致してしまう。

代数体の有限素点では、完備化で値群も剰余体も変わらない。従って :ref[prop-ant-complete-dvr-degree] が局所次数の表示を与える。整数環での対応は $\mathfrak p^j\mathcal O_L=\prod_{w\mid v}\mathfrak P_w^{j e(w/v)}$ の中国剰余分解を逆極限に取っても得られる。各 $w$ について指数 $j e(w/v)$ は任意の正整数をやがて超えるため、その列で極限を取ると $\mathfrak P_w$ における完備整数環になる。
:::

例えば $\Q(i)\otimes_\Q\R=\C$ である。$\Q(i)\otimes_\Q\Q_3$ は二次体であり、$\Q(i)\otimes_\Q\Q_5$ は $\Q_5^2$ になる。$X^2+1$ の法 $5$ における根 $\pm2$ が単純であり、[局所体](/math/algebraic-number-theory/local-fields/) の Hensel の補題でそれぞれが持ち上がるためである。

### 大域ノルムを局所因子へ分ける

有限分離拡大のノルムは $K$ 線形乗法の行列式である。$K_v$ に基底変換し、完備化の直積分解を用いると、その行列は各 $L_w$ に関する乗法行列の直和になる。このため
$$
N_{L/K}(a)=\prod_{w\mid v}N_{L_w/K_v}(a)
$$
が $K_v$ で成り立つ。同じ議論でトレースは局所トレースの和になる。各因子体を一つずつ選ぶことと、素点 $v$ の下で $L$ の全ての成分を合わせることを区別できる式である。

例えば $L=\Q(i)$ の $v=5$ では $i$ が二つの平方根 $u,-u$ に移る。$u\equiv2\bmod5$ と選ぶと $2+i$ は二成分で $2+u$ と $2-u$ になり、積は $5$ である。第一成分は $4\bmod5$ なので単数で、第二成分の付値は積から $1$ になる。一方 $3$ では二次不分岐体であり、一つの成分のノルムが $5$ となる。$2+i$ の $3$ 上の付値は $0$ だが、$a=3$ に変えれば局所ノルム $9$ の付値は $2$ となる。

## 積公式

:::theorem[積公式]{#thm-ant-product-formula}
$x\in K^\times$ とする。有限素点では $\abs x_v=(N\mathfrak p)^{-v_{\mathfrak p}(x)}$、実素点では $\abs{\sigma(x)}$、複素素点では $\abs{\sigma(x)}^2$ と定めると
$$
\prod_{v\in M_K}\abs{x}_v=1
$$
である。
:::

:::proof
元のノルム $N_{K/\Q}(x)$ は全埋め込みの積なので、通常の絶対値を取ると無限素点の積になる。複素対からは絶対値の二乗が現れる。有限素点の積は :ref[thm-ant-principal-ideal-norm] により、分数主イデアル $(x)$ の絶対ノルムの逆数であり、これは $\abs{N_{K/\Q}(x)}^{-1}$ に等しい。非零の付値は有限個なので積が定義される。
:::

複素素点の二乗は乗法的な大きさであり、完備化の構成では通常の複素絶対値を使う。二乗は位相を変えないが、通常の三角不等式を満たさない。例えば $\Q(i)$ の $x=1+i$ は、唯一の無限素点で値 $2$、有限素点 $(1+i)$ で値 $1/2$、ほかで $1$ なので積が $1$ である。

### 高さと正規化の検算

積公式から、$x\in K^\times$ の有限・無限全体で $\sum_v\log\abs{x}_v=0$ となる。一側だけを数える :term[対数高さ]{en="logarithmic height" yomi="たいすうたかさ"} を
$$
h(x)=\frac1{[K:\Q]}\sum_v\log\max(1,\abs{x}_v)
$$
と定義する。$\log\max(1,t^{-1})=\log\max(1,t)-\log t$ を各成分に適用すると、$h(x)=h(x^{-1})$ が分かる。さらに $E/K$ に移すと $\abs{x}_w=\abs{x}_v^{[E_w:K_v]}$ である。有限素点では $e,f$ の正規化から、無限素点では $\C/\R$ の局所次数 $2$ からこの式が出る。$w\mid v$ の局所次数の和が $[E:K]$ なので、$h(x)$ は元 $x$ を置いた体に依存しない。

例えば $x=-14/15$ では $3$ と $5$ だけが正の有限寄与を持ち、通常の絶対値は $1$ 未満なので $h(x)=\log15$ である。逆元 $-15/14$ では有限寄与は $\log14$、無限寄与は $\log(15/14)$ であり、和は同じである。一般に互いに素な $a,b\in\Z$、$ab\ne0$ なら有限寄与が $\log|b|$ なので $h(a/b)=\log\max(|a|,|b|)$ となる。

:::example[複素無限素点を含む積公式・2 と 1 と分母 3]
$K=\Q(i)$ の元 $\alpha=(2 + i)/3$ を取る。無限素点は一つの複素対なので、そこでの絶対値の規約は $|\alpha|_\infty=(a^2+b^2)/c^2=\frac{5}{9}$ である。有限では $p$ の上の全成分を掛けると $p^{-v_p(N_{K/\Q}\alpha)}$ になる。

| $p$ | $v_p(N\alpha)$ | $p$ の上の積 |
| --- | --- | --- |
| 3 | -2 | $9$ |
| 5 | 1 | $\frac{1}{5}$ |


有限成分全体の積は $\frac{9}{5}$ であり、無限の $\frac{5}{9}$ と掛けると $1$ である。表に出ない素数はノルムの付値が零で、上にある素点全体の積に寄与しない。ただし $p$ が分裂する場合は、個々の付値が互いに打ち消すこともある。この表は、同じ $p$ の上の絶対値を一つずつ求める場合には個別の剰余根が必要であることも示している。
:::

## 演習問題

::::exercise{level=basic}
$\abs{18/25}_5$ を求めよ。
:::solution
$5$ の指数は分子で $0$、分母で $2$ なので付値は $-2$、絶対値は $5^2=25$ である。
:::
::::

::::exercise{level=basic}
$\Q$ の $3$ 進完備化で $1+3+3^2+\cdots$ を求めよ。
:::solution
有限和は $(1-3^{n+1})/(1-3)$ である。$3^{n+1}$ が $3$ 進で零に収束するので、和は $-1/2$ である。
:::
::::

::::exercise{level=basic}
$\Q(\sqrt5)$ の無限素点数を求めよ。
:::solution
$\sqrt5$ の像は $\sqrt5,-\sqrt5$ の二つで、双方が実埋め込みである。元 $1+\sqrt5$ に対する絶対値はそれぞれ $1+\sqrt5,\sqrt5-1$ であり異なる。従って無限素点は二つである。
:::
::::

::::exercise{level=basic}
$\Q(i)$ で $x=2+i$ の積公式を確かめよ。
:::solution
$N(x)=5$ で、$(x)$ はノルム $5$ の素イデアルである。その素点の値は $1/5$、他の有限素点では $1$、複素素点では $|2+i|^2=5$ であるから積は $1$ である。
:::
::::

::::exercise{level=advanced}
$x\equiv1\bmod8$、$x\equiv2\bmod9$ を満たし、実数として任意に零に近い有理数を構成せよ。
:::solution
$x_0=65$ は $1\bmod8$ かつ $2\bmod9$ である。$q_n=1+72n$ は $8$ と $9$ で $1$ なので $x_n=65/q_n$ は両合同を満たす。実数では分母が増大するので $x_n\to0$ である。
:::
::::

::::exercise{level=advanced}
非 Archimedes 的な体で $\abs{x-y}<\abs y$ なら $\abs x=\abs y$ であることを示せ。
:::solution
$x=y+(x-y)$ から $\abs x\le\abs y$ である。もし厳密な不等式なら、$y=x-(x-y)$ の右辺の両項が $\abs y$ 未満となり強三角不等式に反する。従って等しい。
:::
::::

::::exercise{level=advanced}
$\Q(\sqrt{13})$ の $2$、$3$、無限素点での完備化の直積を求めよ。
:::solution
整数生成元の最小多項式は $X^2-X-3$ である。$2$ では既約なので次数 $2$ の不分岐体が一つである。$3$ では互いに異なる一次式二つに分かれて $e=f=1$ だから $\Q_3\times\Q_3$ である。二つの埋め込みは実なので $\R\times\R$ となる。
:::
::::

::::exercise{level=advanced}
ノルム公式で $\C$ に延長した $\R$ の通常絶対値が、$z=3+4i$ で取る値を求めよ。
:::solution
$N_{\C/\R}(z)=(3+4i)(3-4i)=25$ である。拡大次数は $2$ なので延長値は $25^{1/2}=5$ である。積公式向けに二乗する正規化では $25$ となる。
:::
::::

::::exercise{level=advanced}
$x\equiv3\bmod8$、$x\equiv4\bmod25$ を保ちつつ、実数として $1$ の両側から近づく有理数を構成せよ。

:::solution
中国剰余定理の解は $179\bmod200$ である。$D_j=1+200j$ として $x_j^+=(D_j+178)/D_j$、$x_j^-=(D_j-22)/D_j$ を取る。両方の分子は $179\bmod200$、分母は $1\bmod200$ なので合同は保たれる。実誤差 $178/D_j$ と $-22/D_j$ は符号が反対で、$j\to\infty$ でともに零へ収束する。
:::
