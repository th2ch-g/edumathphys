## この章の目標

- 局所体を標数によって分類する。
- Hensel の補題と Newton 多角形で根と因数を調べる。
- 不分岐拡大と完全分岐拡大を生成元から構成する。
- 順分岐拡大と、拡大体の同型類の有限性を説明する。

## 局所体の定義と分類

:::definition[局所体]
有限剰余体 $k$ を持つ完備離散付値体 $K$ を :term[局所体]{en="local field" yomi="きょくしょたい"} という。整数環を $\mathcal O_K$、極大イデアルを $\mathfrak m$、$v(\pi)=1$ を満たす元を一様化元 $\pi$ とする。
:::

:::theorem[局所体の分類]{#thm-ant-local-classification}
$|k|=q$ とし、$p=\operatorname{char}k$ とする。標数 $p>0$ の場合 $K\simeq\F_q((T))$ であり、標数 $0$ の場合 $K$ は $\Q_p$ の有限拡大である。逆に、これらの体は局所体である。
:::

:::proof
標数 $p$ では $X^q-X$ の根が $k$ の各元から Hensel の補題で一意に持ち上がる。これらの根は $q$ 乗写像が環準同型であることから体を作る。この体から桁を順に選び、$\pi$ の冪級数で整数環の全元を一意に書ける。表示の一意性は最初の非零桁の付値で分かり、存在は剰余の差を一様化元で割る操作を繰り返して完備性を使えばよい。

標数 $0$ では $v(p)=e>0$ なので $\Q$ の埋め込みが $\Q_p$ に延長する。$f=[k:\F_p]$ とすると、$\mathcal O_K/p$ には $k$ の層が $e$ 個あり、$\F_p$ 上の次元は $ef$ である。基底を $b_1,\ldots,b_{ef}$ に持ち上げる。法 $p$ で任意の元をこの基底で書き、残差を $p$ で割って繰り返すと、$b_i$ に対する係数は $\Z_p$ で収束する。関係式は法 $p$ で全係数が零であることを繰り返して剰余を取ると自明である。従って $[K:\Q_p]=ef$ となる。

逆に $\F_q((T))$ は係数ごとに収束することから $T$ 進付値で完備で、剰余体は $\F_q$ である。$\Q_p$ の有限拡大は :ref[thm-ant-valuation-extension] によって完備になり、:ref[prop-ant-complete-dvr-degree] により値群の指数と剰余次数は有限である。従ってこの場合も離散付値と有限剰余体を持つ。
:::

整数環は有限集合 $\mathcal O_K/\mathfrak m^n$ の逆極限なのでコンパクトである。例えば $\F_4((T))$ では原始三乗根 $\alpha$ が $\alpha^2+\alpha+1=0$ を満たし、$T^{-2}+\alpha+T$ の付値は $-2$ である。また $\Q_5(\sqrt5)$ では $\sqrt5$ が一様化元で、$5$ の付値は $2$ である。

:::proposition[有限拡大における基本等式]{#prop-ant-local-fundamental}
局所体 $K$ の有限拡大 $L$ は局所体であり、分岐指数 $e$ と剰余次数 $f$ は $[L:K]=ef$ を満たす。$v_K$ による正規化を $L$ に延長すると値群は $\frac1e\Z$ になる。
:::

:::proof
:ref[thm-ant-valuation-extension] により一意な延長が存在し、$L$ は完備である。:ref[prop-ant-complete-dvr-degree] によって値群は $\frac1e\Z$ であり、剰余体は基礎の有限剰余体の有限次拡大である。従って $L$ は局所体であり、同じ命題から基本等式も得られる。
:::

この証明は $L/K$ が分離であることを使わない。例えば $\F_3((T))$ に $T^{1/3}$ を添加する純非分離拡大では、値群は $\frac13\Z$、剰余体は $\F_3$ である。$\Q_3(i,\sqrt3)$ では $i$ が不分岐二次拡大を与え、その上で $X^2-3$ は Eisenstein なので $(e,f)=(2,2)$ になる。

### 局所コンパクト性と有限剰余体

:::proposition[完備離散付値体の局所コンパクト性]{#prop-ant-local-compact-dvr}
非自明な離散付値を持つ完備体 $K$ は、剰余体が有限であるとき、かつそのときに限り局所コンパクトである。
:::

:::proof
有限剰余体の場合、整数環は有限離散環の逆極限であり、直積の閉部分集合なのでコンパクトである。整数環は $0$ の開近傍でもある。逆に $0$ にコンパクト近傍があれば、そこにある付値の閉球 $\pi^n\mathcal O_K$ を取れる。閉球はそのコンパクト集合の閉部分集合であり、$\pi^{-n}$ 倍すれば $\mathcal O_K$ もコンパクトになる。すると離散空間 $\mathcal O_K/\mathfrak m$ は連続像としてコンパクトであり、従って有限である。
:::

例えば $\F_5((T))$ と $\Q_5$ はともに半径を一段小さくするごとに球が $5$ 個に分かれる。これに対し $\Q((T))$ の整数環 $\Q[[T]]$ は $T$ による完備環だが、定数項が $\Q$ の任意の値を取れるため局所コンパクトではない。等標数か混合標数かの判定と、局所コンパクト性の判定には別の条件が必要である。

## 一般の Hensel の補題と Newton 多角形

:::theorem[Hensel の補題]{#thm-ant-hensel}
$F\in\mathcal O_K[X]$、$a\in\mathcal O_K$ について $v(F(a))>2v(F'(a))$ とする。すると $v(b-a)>v(F'(a))$ を満たす根 $b$ がただ一つある。また、モニックな $F$ の剰余が互いに素なモニック因子の積 $\bar g\bar h$ なら、その次数を保つモニック因子分解 $F=gh$ に一意に持ち上がる。
:::

:::proof
$s=v(F'(a))$、$t=v(F(a))$ とする。仮定から $s$ は有限である。$F(a)\ne0$ なら $d=-F(a)/F'(a)$ を加えると $v(d)=t-s>s$ となる。Taylor 展開により $F(a+d)$ は $d^2$ の倍数であり、$F'(a+d)-F'(a)$ は $d$ の倍数である。従って次の $s$ は同じで、$t-2s$ は少なくとも倍になる。途中で根に達すればそこで止める。そうでなければ補正が零に収束し、絶対値の強三角不等式によって反復列は Cauchy 列である。その極限は根であり、初期値との差は付値が $s$ より大きい。最初から $F(a)=0$ の場合も含め、近傍内の任意の根 $b$ で $v(F'(b))=s$ である。同じ近傍に別の根 $b+u$ があれば $v(u)>s$ だが、$0=u(F'(b)+uH)$ の括弧は付値 $s$ を持つ。従って $u=0$ である。

因子分解については、$F-gh\in\pi^n\mathcal O_K[X]$ を仮定し、$g,h$ に $\pi^n u,\pi^n w$ を加える。次の段階の条件は $\bar h\bar u+\bar g\bar w=\overline{(F-gh)/\pi^n}$ である。$\deg u<\deg g$、$\deg w<\deg h$ の範囲では、この線形写像は単射である。核の元は $\bar g$ が $\bar u$ を割ることから $\bar u=0$、同様に $\bar w=0$ だからである。次元が等しいので全射であり、補正が一意に決まる。係数ごとに極限を取ればよい。
:::

:::proposition[Newton 多角形と根の付値]{#prop-ant-newton-polygon}
$F(X)=\sum a_j X^j$ の :term[Newton 多角形]{en="Newton polygon" yomi="にゅーとんたかくけい"} を、$a_j\ne0$ の点 $(j,v(a_j))$ の下側凸包とする。定数項が非零なら、各辺の傾きの負が根の付値で、水平方向の長さがその重複度である。
:::

:::proof
値を分解体へ延長する。$w_t(F)=\min_j(v(a_j)+jt)$ とする。二つの多項式で最小を与える最小添字をそれぞれ $j,k$ とする。積の $j+k$ 次係数には、最小の値を与える項がこの一組しかない。従って $w_t$ は積を和に移す。一次因子 $X-b$ で $w_t=\min(t,v(b))$ だから、全体の折れ目は根の付値に現れ、その左右での傾きの差は重複度になる。この同じ式は、凸包の傾きが $-t$ の辺の左右端の添字で傾きが変わることを示す。
:::

$X^2-2$ は $\Q_7$ で $3\bmod7$ から根を持つ。$3^2-2=7$ で導関数は $6$ なので単純根である。$X^3+3X+9$ を $\Q_3$ で見ると点 $(0,2),(1,1),(3,0)$ が折れ線を作り、根の付値は $1$ が一つ、$1/2$ が二つである。

### 多角形から分解を確定する

Newton 多角形の辺の傾きは、根を分解体で測った値である。この情報を基礎体での因数分解に戻すには、同じ既約因子の根の付値が全て等しいことを用いる。付値の一意延長のため、分解体の自己同型は付値を保つ。従って異なる傾きに属する根を一つの既約因子が混ぜることはない。また傾きの負が $a/b$（既約分数）なら、その根を加えた拡大の値群が $a/b$ を含むので、$b$ は分岐指数を割り、従って根の次数を割る。ある辺の長さが $b$ に等しいとき、その根の部分は一つの既約因子である。

:::example[多角形だけで次数を決める]
$\Q_5$ で $F=X^5+5X^2+25$ を考える。点 $(0,2),(2,1),(5,0)$ の下側凸包の傾きは $-1/2,-1/3$ である。よって根は付値 $1/2$ を持つもの二つと、付値 $1/3$ を持つもの三つである。前者の根の次数は $2$ の倍数、後者は $3$ の倍数なので、$F$ は二次と三次の既約因子に分解する。各根の体は完全分岐である。これに対し、分母が $2$ で長さ $4$ の辺だけを見ても、四次既約か二次因子二つかは判定できない。
:::

:::example[単純根版では検出できない平方根]
$F=X^2-17$ を $\Q_2$ で考え、$a=1$ とする。$v_2(F(a))=4$、$v_2(F'(a))=1$ だから一般の Hensel の条件 $4>2$ を満たす。最初の補正は $-(-16)/2=8$ で、新しい近似は $9$ となる。$9^2-17=64$ の付値は $6$ であり、$t-2s$ が $2$ から $4$ へ増えた。法 $2$ では $F'(a)=0$ となるので単純根版は直接適用できない。
:::

## 局所体の乗法群の構造

:::proposition[単数の分解]{#prop-ant-local-units}
$U_K^j=1+\mathfrak m^j$ とする。$K^\times\simeq\pi^\Z\times\mu_{q-1}\times U_K^1$ であり、$j\ge1$ で $U_K^j/U_K^{j+1}\simeq(k,+)$ である。混合標数で $v(p)=e$ のとき、$j>e/(p-1)$ なら $\log$ と $\exp$ が $U_K^j$ と $\mathfrak m^j$ の同型を与える。
:::

:::proof
任意の元は $\pi^n$ と単元の積に一意に書ける。$X^{q-1}-1$ の剰余根はすべて単純なので、一意な持ち上げが乗法と両立する。この根の群が単元の還元写像を分裂させる。$1+\pi^j a\mapsto\bar a$ は積の交差項の付値が $2j\ge j+1$ なので準同型であり、全射で核が $U_K^{j+1}$ である。

対数の $n$ 次項と指数の $n$ 次項の付値はそれぞれ $nj-ev_p(n)$ と $nj-ev_p(n!)$ 以上である。$v_p(n!)=\sum_{r\ge1}\lfloor n/p^r\rfloor\le(n-1)/(p-1)$ より、第 $2$ 項以降は付値が $j$ より大きく、項の付値は無限大に行く。形式的な逆関係と積に関する対数の恒等式は、ここでは収束によって評価できる。よって所期の同型となる。
:::

$\Q_3$ では $j=1$ で対数が使え、$\Q_2$ では $j=2$ が十分である。$\Q_2$ の $U^1$ には $-1$ が含まれ、加法群 $2\Z_2$ への同型を $j=1$ まで延ばせない。

### 混合標数の主単数のねじれ

ある $j$ で対数が同型となるとき、$U_K^j\simeq\mathfrak m^j\simeq\Z_p^{[K:\Q_p]}$ である。また $U_K^1/U_K^j$ は $p$ 群である。従って $U_K^1$ は有限生成 $\Z_p$ 加群と見なせる。具体的には $a\in\Z_p$ が整数列 $a_i$ の極限なら、$u^a=\lim_i u^{a_i}$ と置く。$u^{p^m}$ はどの有限商でも最終的に $1$ になるので極限は存在し、選んだ列に依らない。$U_K^j$ の基底と有限商の生成元の持ち上げを取れば有限生成性が従う。$\Z_p$ 上の有限生成加群の構造定理により、$U_K^1$ は有限ねじれ群と $\Z_p^{[K:\Q_p]}$ の直積である。ねじれ群は $K$ に入る $p$ 冪位数の 1 の根であり、有限体の中の根の個数の議論と同様に、体の乗法群の有限部分群は巡回である。

例えば $\Q_2$ では $U^1=\{\pm1\}\times U^2$ である。任意の奇数は $\pm$ を選んで $1\bmod4$ に移せ、$-1$ は $U^2$ に属さない。$\Q_3$ では $U^1\simeq3\Z_3$ なので $3$ 冪位数のねじれはないが、$\Q_3(\zeta_3)$ には $\mu_3$ が含まれる。等標数でも各層は有限加法群であるものの、例えば $(1+T)^{p^n}=1+T^{p^n}$ となるため混合標数の対数を用いた判定は使えない。

:::proposition[等標数の主単数]{#prop-ant-equal-characteristic-units}
$K=\F_q((T))$、$q=p^s$ とし、$b_1,\ldots,b_s$ を $\F_q$ の $\F_p$ 基底とする。$U_K^1$ の各元は
$$
\prod_{\substack{n\ge1\\p\nmid n}}\prod_{j=1}^s(1+b_j T^n)^{a_{n,j}},
\qquad a_{n,j}\in\Z_p
$$
と一意に書ける。従って $U_K^1$ は位相群として $\prod_{n\ge1,\,p\nmid n}\Z_p^s$ に同型である。
:::

:::proof
$a_{n,j}=\sum_{r\ge0}a_{n,j,r}p^r$ と桁で表すと、標数 $p$ では $(1+b_jT^n)^{p^r}=1+b_j^{p^r}T^{np^r}$ である。従って法 $T^N$ で積に効く桁は有限個であり、指数と積は完備性により定義できる。各正整数 $m$ は $m=np^r$（$p\nmid n$）と一意に書ける。すでに次数 $m-1$ まで目標と一致したとき、$m$ 次の差を基底 $b_j^{p^r}$ で表すと必要な桁 $a_{n,j,r}$ が一意に決まる。この組は Frobenius が $\F_p$ 線形な全単射なので基底である。これで存在と一意性が得られる。整数指数の乗法則は剰余での極限を取れば $\Z_p$ 指数にも成り立つ。各有限桁と各有限剰余が他方の有限個のデータで決まるので、同型は両方向に連続である。
:::

## 不分岐拡大と最大不分岐拡大

:::theorem[不分岐拡大の分類]{#thm-ant-unramified-local}
固定した分離閉包に、各 $f\ge1$ に対して次数 $f$ の不分岐拡大がただ一つある。この拡大は Galois で、剰余体の算術的 Frobenius に対応する元が群を生成する。これらの合併 $K^{\mathrm{nr}}$ の Galois 群は $\widehat{\Z}$ である。
:::

:::proof
$\F_{q^f}/k$ の乗法群の生成元の最小多項式をモニックに持ち上げる。還元が既約なので持ち上げも既約であり、根の整数環は冪基底を持つ。実際、冪基底のトレース行列式の還元は分離剰余拡大の判別式で非零だから、トレース双対がこの環自身になる。従って剰余体は $\F_{q^f}$ で、拡大次数が $f$ だから $e=1$ である。

任意の不分岐拡大では $\F_{q^f}^\times$ の元が Hensel の補題により $X^{q^f-1}-1$ の根として一意に持ち上がる。生成元の持ち上げが体を生成するのは、剰余次数だけで体の次数に達するためである。従って体はこの分離多項式の分解体で一意である。還元で恒等となる自己同型は持ち上げの一意性によりすべての根を固定するので、還元写像は単射である。体と剰余体の Galois 群の位数はともに $f$ であり、従ってこの写像は同型になる。各次数の巡回群を制限で逆極限に取ると $\widehat{\Z}$ になる。
:::

$\Q_3(i)$ は $X^2+1$ が法 $3$ で既約なので不分岐二次であり、Frobenius は $i$ を $-i$ に移す。有限分離拡大 $L/K$ でも、その剰余体の乗法群を持ち上げると $L$ の中に唯一の最大不分岐部分体ができる。残る拡大では剰余体が等しく、完全分岐である。

### 不分岐拡大の合成・交わり

$K_m,K_n$ を固定した分離閉包の中の不分岐拡大とする。$K_m\subset K_n$ と $m\mid n$ が同値である。必要性は次数を比べればよく、十分性は $\F_{q^m}^\times\subset\F_{q^n}^\times$ の各元を 1 の根に持ち上げれば得られる。従って交わりは $K_{\gcd(m,n)}$、合成は $K_{\operatorname{lcm}(m,n)}$ である。後者については、右辺が二体を含み、その合成が両方の次数で割れる次数を持つからである。

$L/K$ が有限拡大で剰余次数 $f$ なら、$L\cap K_m$ の次数は $\gcd(f,m)$ である。$L$ の最大不分岐部分が $K_f$ だからである。$LK_m/L$ は剰余体の拡大次数 $m/\gcd(f,m)$ の不分岐拡大になる。実際 $LK_m$ は $L$ に $q^m-1$ 乗根を添加して作れ、その剰余体が $\F_{q^{\operatorname{lcm}(f,m)}}$ になる。例えば $f=6,m=4$ なら交わりの次数は $2$、$L$ の上の次数は $2$ である。

:::proposition[不分岐拡大の単数ノルム]{#prop-ant-unramified-unit-norm}
$L/K$ が不分岐次数 $f$ の拡大なら $N_{L/K}(\mathcal O_L^\times)=\mathcal O_K^\times$ であり、$N_{L/K}(U_L^j)=U_K^j$ が $j\ge1$ で成り立つ。$N_{L/K}(L^\times)$ は $K^\times$ のうち付値が $f$ の倍数の元全体である。
:::

:::proof
両方の体で同じ一様化元 $\pi$ を使う。単数ノルムを法 $\pi$ で還元すると、剰余体のノルム $x\mapsto x^{(q^f-1)/(q-1)}$ になる。巡回群の生成元の像は位数 $q-1$ を持つので、この写像は全射である。さらに $j\ge1$ では、共役の積を展開すると
$$
N_{L/K}(1+\pi^j a)\equiv 1+\pi^j\operatorname{Tr}_{k_L/k}(\bar a)\pmod{\pi^{j+1}}
$$
となる。交差項は $\pi^{2j}$ で割れるからである。有限体のトレース形式は非退化であり、$1$ との対を取ればトレース写像が非零、従って全射と分かる。そこで目標の主単数に対し、現在のノルムとの比を法 $\pi^{j+1}$ で合わせる補正元を順に選べる。補正元が $1$ に収束するので積は完備な $\mathcal O_L^\times$ で収束し、そのノルムは目標に等しい。最初の剰余ノルムの全射性を合わせると全単数を得る。最後に $\pi$ のノルムは $\pi^f$ だから、付値からの条件も十分である。
:::

## 完全分岐拡大と Eisenstein 多項式

:::proposition[Eisenstein 生成元]{#prop-ant-eisenstein-local}
有限分離完全分岐拡大 $L/K$ では任意の一様化元 $\pi_L$ が $L$ を生成し、その最小多項式は Eisenstein である。整数環も $\mathcal O_L=\mathcal O_K[\pi_L]$ である。
:::

:::proof
$n=[L:K]$ とすると $\pi_L^j$ の付値は $0\le j<n$ で法 $n$ において異なる。従ってそれらの $K$ 線形結合は、非零項の最小付値を持つ。このため $n$ 個の冪は基底であり、線形結合が整であることと全係数が $\mathcal O_K$ に属することは同値である。最小多項式は一次以上で最高次以外の係数が極大イデアルに入る。根の共役の絶対値は同じで、各基本対称式が正の付値を持つためである。定数項はノルムであり、全根の付値を $v_K$ に合わせると $n$ 個とも $1/n$ なので定数項の付値は $1$ である。
:::

逆に Eisenstein 多項式は既約である。その根の付値は Newton 多角形の一辺から $1/n$ になるので、分岐指数が少なくとも $n$ になるからである。例えば $X^3-5$ は $\Q_5$ 上で完全分岐三次拡大を与え、根は付値 $1/3$ を持つ。

### 冪基底で付値と差積を計算する

$L=K(\alpha)$、$\alpha^n=\pi$、$K$ が標数 $0$ とする。任意の元 $u=\sum_{j=0}^{n-1}a_j\alpha^j$ の各非零項の整数値付値は $nv_K(a_j)+j$ であり、相異なる剰余類に入る。従って $v_L(u)$ はこれらの最小値である。$u$ が整であることと全係数が整であることがこの式から直接分かる。差積は冪基底の導関数 $n\alpha^{n-1}$ で生成されるため、その指数は $nv_K(n)+n-1$ である。

例えば $X^4-3$ を $\Q_3$ 上で考えると指数は $3$ であり、$\alpha+3$ の付値は $\min(1,4)=1$ である。一方 $X^3-3$ を同じ体で考えると差積指数は $3+2=5$ になる。$n-1$ に加わる成分は $v_K(n)$ に由来する。完全分岐であっても分岐が順分岐かどうかで判別式の指数が変わる。

:::example[Eisenstein 冪基底で差積と元の付値を求める・素数 2、次数 3]
$F=X^3-2$ は $\Q_{2}$ 上の Eisenstein 多項式で、根 $\alpha$ を $v_L(\alpha)=1$ と正規化する。整数環の基底は $1,\alpha,\ldots,\alpha^{2}$ である。二項の元 $u=4+3\alpha^{2}$ では係数の付値を $3$ 倍し、第二項にはさらに $2$ を加える。


$$
\begin{aligned}v_L(4)&=6,& v_L(3\alpha^{2})&=2,&v_L(u)&=2,\\
v_L(F^\prime(\alpha))&=3v_{2}(3)+2=2.\end{aligned}
$$


二項の値は法 $3$ で異なるので相殺はない。差積は $F^\prime(\alpha)$ が生成する。整数基底が冪基底なので多項式の判別式 $-108$ の $2$ 進付値も $2$ である。完全分岐で剰余次数が $1$ のため、差積の指数をノルムへ移しても数値は変わらない。$2$ が $3$ を割れるかによって、この指数に $n-1$ 以外の項が現れるかどうかが決まる。
:::

## 順分岐拡大

:::definition[順分岐拡大]
剰余標数 $p$ が分岐指数を割らない局所体の有限分離拡大を :term[順分岐拡大]{en="tamely ramified extension" yomi="じゅんぶんきかくだい"} という。
:::

:::proposition[完全順分岐拡大の生成元と同型類]{#prop-ant-tame-uniformizer}
$e$ は $p$ と互いに素とし、$\pi$ を $K$ の一様化元とする。完全分岐次数 $e$ の拡大は $X^e-u\pi$（$u\in\mathcal O_K^\times$）の根で生成できる。二つの単数が $K$ 上で同型な拡大を与えることと、その剰余の比が $k^\times$ の $e$ 乗であることは同値である。従って同型類は $\gcd(e,|k|-1)$ 個である。
:::

:::proof
拡大の一様化元 $t$ に対し、$t^e/\pi$ と同じ剰余を持つ基礎の単数 $u$ を取る。剰余体は変わらないのでこの選択ができる。$t^e/(u\pi)\equiv1$ であり、$e$ が単元なので、その $e$ 乗根が拡大体に Hensel の補題で存在する。$t$ をその根で割ると $e$ 乗が $u\pi$ になる。逆に $X^e-u\pi$ は Eisenstein で、$p\nmid e$ なので分離的である。

同型があれば同じ拡大の中で $\alpha^e=u\pi$、$\beta^e=u'\pi$ と書ける。$\alpha,\beta$ はともに一様化元なので、$\beta/\alpha$ の剰余を取ると $\overline{u'/u}$ の $e$ 乗根が $k$ 内に得られる。逆にその剰余根を $K$ に持ち上げれば、$\alpha$ にその根を掛けて $\beta$ を作れる。最後に $k^\times$ は位数 $|k|-1$ の巡回群なので、$e$ 乗による商群の大きさが同型類の個数になる。
:::

:::proposition[最大順分岐拡大]{#prop-ant-max-tame}
最大不分岐拡大の上で、全ての $p$ と互いに素な $e$ について $\pi^{1/e}$ を添加した合併が最大順分岐拡大である。
:::

:::proof
有限順分岐拡大の最大不分岐部分体を $K_f$ とすると、:ref[prop-ant-tame-uniformizer] により残りは $X^e-u\pi$ で生成される。$K_f$ の有限不分岐拡大を選び、剰余体に $\bar u$ の $e$ 乗根とすべての $e$ 乗根の 1 を含める。$p\nmid e$ なので各根を Hensel の補題で持ち上げられる。その上では $X^e-u\pi$ の各根は $\pi^{1/e}$ の既知の単数倍である。従って与えられた順分岐拡大は $K^{\mathrm{nr}}(\pi^{1/e})$ に含まれる。

逆に、この形の拡大の任意の有限部分は有限不分岐拡大 $K_f$ とある $\pi^{1/e}$ の合成に入る。$X^e-\pi$ は $K_f$ の上でも Eisenstein なので、合成体の $K$ 上の分岐指数は $e$ である。部分体の分岐指数はこの $e$ を割るため、$p$ と互いに素である。異なる有限個の $e$ を同時に扱うにはその最小公倍数を使えるので、これらの合併は体である。
:::

$\Q_5$ の $X^3-5$ は順分岐だが、$\F_5^\times$ の位数は $4$ なので $\Q_5$ は原始三乗根を持たない。完全分岐三次体内の剰余体も同じだから、この体も原始三乗根を持たず、拡大は Galois ではない。

### 順分岐の半直積と Frobenius の持ち上げ

$e$ が $p$ と互いに素で $e\mid q^f-1$ とする。$K_f$ を次数 $f$ の不分岐拡大、$L=K_f(\alpha)$、$\alpha^e=\pi$ と置く。$K_f$ は原始 $e$ 乗根 $\xi$ を含む。惰性群の生成元 $\tau$ を $\alpha\mapsto\xi\alpha$ と選び、$K_f$ の算術的 Frobenius を $\alpha$ を固定して持ち上げた写像を $\sigma$ とする。具体的には冪基底の係数に Frobenius を作用させる。$\alpha^e=\pi$ の関係を保つためこれは自己同型であり、$\sigma^f=1$ である。$\sigma(\xi)=\xi^q$ なので、$\sigma\tau\sigma^{-1}=\tau^q$ となる。従ってこの構成では $\operatorname{Gal}(L/K)=C_e\rtimes C_f$ である。

$f$ を $q$ の法 $e$ の位数に取れば、この $L$ は $X^e-\pi$ の分解体である。実際、全根を含む体は根の比からすべての $e$ 乗根の 1 を含み、不分岐拡大 $K_f$ を含む。これに対し、一つの根 $\alpha$ が生成する完全分岐体の剰余体は $k$ のままである。従ってこの体だけに含まれる根は $\zeta\alpha$（$\zeta\in\mu_e\cap K$）であり、その数は $\gcd(e,q-1)$ である。例えば $q=5,e=8$ では四つの根が完全分岐体にあり、残りの根を得るには不分岐二次拡大が要る。

例えば $K=\Q_5,e=3,f=2$ では $5\equiv-1\bmod3$ なので群は $S_3$ である。$e=4,f=1$ なら $4\mid5-1$ なので $C_4$ になる。同じ $X^e-\pi$ 型でも分解体を求めるには根の付値だけでなく剰余体に含まれる 1 の根の位数も調べる。

## Krasner の補題と局所体の拡大の有限性

:::lemma[Krasner の補題]{#lem-ant-krasner}
$K$ を局所体、$\alpha,\beta$ を分離代数的な元とする。$\alpha$ の他の全ての $K$ 共役 $\alpha'$ に対し $\abs{\beta-\alpha}<\abs{\alpha-\alpha'}$ なら $K(\alpha)\subset K(\beta)$ である。
:::

:::proof
有限 Galois 拡大の中で全共役を取る。$\beta$ を固定する自己同型 $\sigma$ は絶対値を保つので、$\abs{\sigma\alpha-\alpha}\le\max(\abs{\sigma\alpha-\beta},\abs{\beta-\alpha})=\abs{\beta-\alpha}$ である。この距離で $\alpha$ と異なる共役は存在しない。従って $\beta$ の固定群は $\alpha$ を固定する。
:::

:::corollary[混合標数での有限性]{#cor-ant-local-finiteness}
混合標数の局所体では、所与の次数の拡大は同型を除いて有限個である。
:::

:::proof
不分岐部分の次数は全体の次数の約数なので選択肢は有限である。それを固定すると、完全分岐部分は固定次数 $d$ の Eisenstein 多項式で生成される。係数の組は $\mathfrak m\setminus\mathfrak m^2$ と $\mathfrak m^{d-1}$ の直積なのでコンパクトである。各多項式 $F$ の根 $\alpha$ を選ぶと、十分近い多項式 $G$ では $G(\alpha)$ の付値が任意に高く、$G'(\alpha)$ の付値は $F'(\alpha)$ と同じである。$\mathcal O_{K(\alpha)}$ の Hensel の補題で $G$ の根 $\beta$ が $K(\alpha)$ の中にあり、$\alpha$ と任意に近くなる。Krasner の補題により $K(\beta)=K(\alpha)$ となる。従って各多項式の開近傍で同型類が一定であり、有限部分被覆を取ればよい。
:::

等標数では有限性は一般に成り立たない。$\F_p((T))$ で $m>0$、$p\nmid m$ に対する $X^p-X-T^{-m}$ を考える。$y$ に極があると $y^p-y$ の極次数は $p$ の倍数なので、方程式の右辺はその形にならない。根の差は $\F_p$ の元であり、分解体の Galois 群は $\F_p$ の加法部分群に埋め込まれるため、拡大次数は $p$ である。異なる $m,n$ が同じ体を与えたとすると、その群の生成元に対する両根の差分の比 $c\in\F_p^\times$ を使って $\alpha_n-c\alpha_m$ が基礎体に属する。すると $T^{-n}-cT^{-m}=y^p-y$ となるが、最大の極次数が $p$ の倍数でないので矛盾する。

### 同型類を調べるための一様な係数精度

$F$ を混合標数の局所体 $K$ 上の次数 $n$ の Eisenstein 多項式とし、根 $\alpha$ に対して $v_L(\alpha)=1$ とする。$F'(\alpha)$ の非零項 $i a_i\alpha^{i-1}$ は整数値付値が法 $n$ で互いに異なる。最高次から来る項の値は $nv_K(n)+n-1$ なので
$$
v_L(F'(\alpha))\le nv_K(n)+n-1=:B
$$
である。いま $G$ の係数が $F$ と法 $\pi_K^N$ で一致し、$nN>2B$ なら $v_L(G(\alpha))\ge nN$、$v_L(G'(\alpha))=v_L(F'(\alpha))$ である。従って $G$ の根が $L$ に存在する。$G$ も Eisenstein ならその根が次数 $n$ の体を生成し、$L$ に一致する。この条件はコンパクト性による有限性を、有限剰余環で係数候補を列挙できる形にする。ただし候補同士が同型かは追加で判定する必要がある。

例えば $K=\Q_3,n=3$ なら $B=5$ なので $N=4$ で十分である。$F=X^3-3$ と $G=X^3+81X-84$ は法 $81$ で一致し、どちらも Eisenstein である。従って両方の根の生成する体は同型である。ここでは $G(\alpha)=81(\alpha-1)$ なのでその付値は $12>10$ となる。

:::example[係数精度から同じ局所体を判定する・素数 2、次数 2]
$F=X^2-2$ と $G=X^{2} + 16 X + 46$ はともに $\Q_{2}$ 上で Eisenstein である。$\alpha$ を $F$ の根とし、$n=2$ とすると $F^\prime(\alpha)=n\alpha^{n-1}$ の整数値付値は $B=3$ である。$F,G$ の係数は法 $16$ で一致し、その係数精度は $N=4$ である。


$$
\begin{aligned}v_L(G(\alpha))&\ge nN=8>2B=6,\\
v_L(G^\prime(\alpha))&=v_L(F^\prime(\alpha))=3.\end{aligned}
$$


第二式は導関数の差の付値が少なくとも $nN$ であることによる。従って $L=\Q_{2}(\alpha)$ の中で Hensel の補題を適用できる。その根 $\beta$ は Eisenstein により $\Q_{2}$ 上次数 $2$ を持つから、$\Q_{2}(\beta)=L$ である。変えた係数が大きい通常の整数であっても、判定に使うのは $p$ 進での差の精度である。
:::

$F=X^3-7$ と $G=X^{3} + 98 X + 238$ はともに $\Q_{7}$ 上で Eisenstein である。$\alpha$ を $F$ の根とし、$n=3$ とすると $F^\prime(\alpha)=n\alpha^{n-1}$ の整数値付値は $B=2$ である。$F,G$ の係数は法 $49$ で一致し、その係数精度は $N=2$ である。


$$
\begin{aligned}v_L(G(\alpha))&\ge nN=6>2B=4,\\
v_L(G^\prime(\alpha))&=v_L(F^\prime(\alpha))=2.\end{aligned}
$$


第二式は導関数の差の付値が少なくとも $nN$ であることによる。従って $L=\Q_{7}(\alpha)$ の中で Hensel の補題を適用できる。その根 $\beta$ は Eisenstein により $\Q_{7}$ 上次数 $3$ を持つから、$\Q_{7}(\beta)=L$ である。変えた係数が大きい通常の整数であっても、判定に使うのは $p$ 進での差の精度である。
:::

## 演習問題

::::exercise{level=basic}
$\Q_5$ で $X^2-6$ が根を持つことを示せ。
:::solution
$a=1$ で $F(a)=-5$、$F'(a)=2$ である。$1=v_5(-5)>2v_5(2)=0$ だから $1\bmod5$ の根が存在する。
:::
::::

::::exercise{level=basic}
$\F_9((T))$ の $U^2/U^3$ の位数を求めよ。
:::solution
$1+aT^2\bmod T^3$ で $a\in\F_9$ が一意に決まる。積では係数が加算されるので位数は $9$ である。
:::
::::

::::exercise{level=basic}
$\Q_3$ における $X^4-3$ の根の付値を求めよ。
:::solution
Newton 多角形は $(0,1),(4,0)$ を結ぶ一辺なので全四根の付値は $1/4$ である。
:::
::::

::::exercise{level=basic}
$\Q_7(\sqrt[3]7)/\Q_7$ の分岐指数と剰余次数を求めよ。
:::solution
$X^3-7$ は Eisenstein なので $(e,f)=(3,1)$ である。$7\nmid3$ だから順分岐である。
:::
::::

::::exercise{level=advanced}
$\Q_3$ の不分岐次数 $2$ と $3$ の拡大の合成体の次数を求めよ。
:::solution
剰余体の合成は $\F_{3^6}$ である。次数 $6$ の不分岐拡大は双方を含み、一方で両方を含む部分体の次数は $2,3$ の両方で割れる必要がある。従って合成体の次数は $6$ である。
:::
::::

::::exercise{level=advanced}
$\Q_2$ の $X^2-17$ について $a=1$ から Hensel の条件を確かめよ。
:::solution
$F(1)=-16$ は付値 $4$、$F'(1)=2$ は付値 $1$ なので $4>2$ である。よって $1$ から付値 $1$ より近いところに根がある。
:::
::::

::::exercise{level=advanced}
$\Q_3$ 上で $X^3+3X+9$ が少なくとも二次因子を必要とする理由を述べよ。
:::solution
Newton 多角形により付値 $1/2$ の根が二つある。$\Q_3$ の値群は $\Z$ なので、これらは一次因子に属さない。付値 $1$ の根はただ一つであり、共役で絶対値が保たれるため基礎体に入る。従って残る因子は既約二次式である。
:::
::::

::::exercise{level=advanced}
$\F_2((T))$ で $y^2-y=T^{-3}$ が解を持たないことを示せ。
:::solution
$y$ が整なら左辺も整である。そうでなければ $v(y^2)=2v(y)<v(y)$ より左辺の付値は偶数で、$-3$ と一致しない。従って解がない。
:::
::::

::::exercise{level=advanced}
$\Q_7$ の $\sqrt2$ のうち $3\bmod7$ に合同なものを法 $343$ まで求めよ。

:::solution
$F=X^2-2$ とすると $F(3)/7=1$、$F^\prime(3)\equiv6\bmod7$ なので第一補正は $7$、近似は $10$ となる。次に $F(10)/49=2$、$F^\prime(10)\equiv6\bmod7$ より第二補正は $2\cdot49$ である。従って根は $108\bmod343$ で、$108^2-2=34\cdot343$ と検算できる。各桁の補正が一意なので、最初の剰余根に対応する値である。
:::
::::
