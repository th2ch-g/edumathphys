## この章の目標

- 二つの臨界点を持つ多様体を二枚の円板で表す。
- 測地線の指数を有限次元の二次形式に帰着する。
- Lie 群のループ空間と安定ホモトピー群を関連付ける。
- Morse 指数を超平面切断と勾配軌道の計数に使う。

## Reeb の定理

極小で現れた円板に、最後の極大の円板を貼るだけなら、途中で生じる穴はない。ただし、境界の貼り込みは一般の微分同相であり、滑らかな構造に影響する。

:::theorem[Reeb の定理]{#thm-dtop-reeb}
閉連結滑らかな $n$ 次元多様体（$n\ge1$）が臨界点をちょうど二つ持つ Morse 関数を持つなら、$S^n$ と同相である。
:::

:::proof
コンパクト性により二点は最小点と最大点である。:ref[thm-dtop-morse-lemma] により最小値のすぐ上の劣位集合と最大値のすぐ下の優位集合は円板である。ここで近傍の外で最小値や最大値から正の隔たりがあることを用いる。中間の帯は :ref[thm-dtop-morse-regular-band] により $S^{n-1}\times[0,1]$ である。その帯の半分ずつをそれぞれの円板の襟に吸収すると、$D^n\cup_\phi D^n$ と書ける。任意の境界同相 $\phi$ は原点を固定する放射延長 $ru\mapsto r\phi(u)$ で円板の同相に延びる。よって一方の円板をその延長で座標変更すれば恒等写像による貼り合わせになり、これは球面である。
:::

:::example[半球と高さ]
単位 $S^5$ の高さの Hessian は下極で正定値、上極で負定値であり、指数は $0,5$ である。中間の帯は $S^4$ を高さで移動させて得る。
:::

:::example[回転による貼り込み]
二円板の境界を $e^{it}\mapsto e^{i(t+\pi/3)}$ で貼るとする。この場合の放射延長は平面の線形回転であり、原点でも滑らかである。一般の境界微分同相の放射延長が原点で微分可能なら、その微分が全放射方向を $\phi$ どおりに写すので延長は線形でなければならない。
:::

### 境界地図の同位と滑らかな貼り合わせ

:::proposition[同位な境界写像による貼り合わせ]{#prop-dtop-twisted-sphere-isotopy}
$\phi_0,\phi_1\colon S^{n-1}\to S^{n-1}$ が滑らかな同位で結ばれるとする。すると $D^n\cup_{\phi_0}D^n$ と $D^n\cup_{\phi_1}D^n$ は微分同相である。
:::

:::proof
$\psi_t=\phi_t\phi_0^{-1}$ と置くと $\psi_0=\id$ である。一方の円板の境界襟に内向き座標 $s$ を取り、$s$ に応じて $1$ から $0$ へ移る滑らかな関数 $\rho(s)$ を用意する。境界の近傍では $\rho=1$、襟の内側では $\rho=0$ とする。襟で $(p,s)\mapsto(\psi_{\rho(s)}(p),s)$ と置けば、逆は同じ式で $\psi_{\rho(s)}^{-1}$ を使って得られる。内側では恒等写像へ滑らかにつなぎ、他方の円板上では恒等写像を使う。境界で $\psi_1\phi_0=\phi_1$ であり、短い襟上では $\rho=1$ なので貼り目の座標でも滑らかである。この二円板上の写像は貼り合わせ全体の微分同相を与える。
:::

:::example[円周上の向きを保つ微分同相]
$\phi(e^{it})=\exp(i(t+\eps\sin t))$、$|\eps|<1$ とする。角の微分 $1+\eps\cos t$ は正であり、角は一周で $2\pi$ 増えるので $\phi$ は円周の微分同相である。$t+s\eps\sin t$ の角地図で恒等から同位が得られる。従ってこの写像で円板を貼った曲面は滑らかな球面である。$\eps\ne0$ のとき角の移動は一定でないため放射延長は線形回転ではないが、襟の中だけで同位を使う上の延長なら原点付近は恒等になる。
:::

:::example[すべての円周の向きを保つ微分同相]
向きを保つ円周の微分同相の角の持ち上げを $\theta(t)$ とする。$\theta(t+2\pi)=\theta(t)+2\pi$、$\theta'(t)>0$ であるため、$(1-s)t+s\theta(t)$ も同じ条件を満たす。従って向きを保つものはすべて恒等と同位である。向きを反転するものは鏡映との合成で向きを保つものになる。鏡映は円板全体の線形反射へ延びるので、この場合も貼り合わせは標準二球面と微分同相である。Reeb の結論が滑らかな構造まで決めるために、境界の微分同相を円板へ滑らかに延長できるかどうかが使われた。
:::

### 二臨界点を持つ関数を逆に作る

:::example[任意の二円板の貼り合わせに高さを入れる]
二円板を境界の微分同相 $\phi$ で貼る。下側の円板で $-1+\norm x^2$、上側で $1-\norm x^2$ を使うと、境界でともに値は零である。襟の内向き変数を $s=1-\norm x^2$ と取れば、それぞれ $-s$ と $+s$ である。貼り目の符号付き襟座標で二式は同じ一次式になるため滑らかで、そこに臨界点はない。円板の中心だけがそれぞれ指数 $0,n$ の非退化臨界点になる。従って二円板で表せる滑らかな多様体には必ずこのような Morse 関数がある。ここでは貼り目付近の法微分を両側で合わせたので、$\phi$ の放射延長を微分可能にする必要がない。
:::

:::example[同じ Euler 標数でも二臨界点から外れる例]
$S^2\times S^3$ の Euler 標数は $(1+1)(1-1)=0$ であり、$S^5$ と同じである。しかし $H_2(S^2\times S^3;\Z)=\Z$ であるため $S^5$ と同相でない。二臨界点しかない Morse 関数であれば Reeb の定理に反する。実際、各因子の高さを足した関数では指数 $0,2,3,5$ の四点があり、係数体上の Betti 数から最低でも四点が必要である。Euler 標数は四点の交代和だけを測るので、二点か四点かを区別できない。
:::

## 道空間の Morse 理論と測地線

### エネルギーの変分

Riemann 多様体で両端固定の区分的滑らかな道に $E(\gamma)=\tfrac12\int_0^1|\dot\gamma|^2\,dt$ を対応させる。変分方向 $V$ は両端で零とする。接続の捩率が零なので $\nabla_s\partial_t\gamma=\nabla_t\partial_s\gamma$ である。節点 $t_i$ で時間区間を分け、それぞれで部分積分すると、
$$
dE_\gamma(V)=-\sum_i\int_{t_i}^{t_{i+1}}\inner{V}{\nabla_t\dot\gamma}\,dt
+\sum_{0<t_i<1}\inner{V(t_i)}{\dot\gamma(t_i^-)-\dot\gamma(t_i^+)}
$$
となる。区間内部の変分を使うと各区間で測地線の方程式を得る。次いで折れ目に任意の値を取る変分を使うと左右の速度が一致する。よって臨界点は全区間で滑らかな定速測地線である。曲率を $R(X,Y)Z=\nabla_X\nabla_Y Z-\nabla_Y\nabla_X Z-\nabla_{[X,Y]}Z$ とすると、測地線での二階変分は
$$
I_\gamma(V,W)=\int_0^1\big(\inner{\nabla_tV}{\nabla_tW}
 -\inner{R(V,\dot\gamma)\dot\gamma}{W}\big)\,dt
$$
である。実際、一階変分中の加速度を変分すると $\nabla_t^2V+R(V,\dot\gamma)\dot\gamma$ となり、再び部分積分する。この作用素の零解を :term[Jacobi 場]{en="Jacobi field" yomi="やこびば"} という。区分的な変分で核を取ると、積分と折れ目の項から Jacobi 場とその一階微分が折れ目で一致することも従う。

:::proposition[折れ線への指数の還元]{#prop-dtop-broken-geodesic}
区間を十分細かく分けると、測地線の指数と退化次数は、分割点の位置を変数とする短い測地線の折れ線のエネルギーの Hessian の指数と退化次数に等しい。
:::

:::proof
平行正規枠を取る。曲率項を抑える定数を $K$ とすると、長さ $h$ の小区間で端点零の場について Cauchy–Schwarz から $\int |V|^2\le h^2\int|\nabla_tV|^2$ である。$Kh^2<1$ なら $I$ はこの部分空間上で正定値である。任意の節点値をつなぐ Jacobi 場は各小区間で一意に存在する。実際、始点の値を決めて初速度を変えたときの終点値への線形写像は、端点零の非零 Jacobi 場が正定値性に反するため単射であり、同次元なので全射である。任意の場をその節点値を補間する区分 Jacobi 場と、節点ですべて零になる場に分解できる。部分積分と Jacobi 方程式で二項は $I$ に関して直交する。前者は分割点を動かして短い測地線でつないだときの変分である。短い測地線は強凸な測地球内で端点に滑らかに依存するため、そのエネルギーを有限次元関数と見なせる。後者は正定値なので負指数と核は前者から得られる。
:::

測地線の内部で、始点とその点の両方で消える非零 Jacobi 場があれば、その点は :term[共役点]{en="conjugate point" yomi="きょうやくてん"} である。各共役点の重複度はそのような場の空間の次元である。

:::theorem[Morse の指数定理]{#thm-dtop-geodesic-index}
両端固定の測地線の指数は、始点に共役な内部の点の重複度の総和である。退化次数は終点の重複度である。
:::

:::proof
長さパラメータ $T$ を変え、区間 $[0,T]$ 上の指数を比較する。初期の小区間では前述の評価で正定値である。任意の $T_0>0$ の近傍で、十分細かい固定の内部分割点を選び、最後の分割点を $T$ に取る。:ref[prop-dtop-broken-geodesic] で有限個の節点値に対する滑らかな対称行列 $B(T)$ を得る。核は端点で消える Jacobi 場に一致する。$T_0$ で核に属する場 $J$ の節点値を固定し、終端だけを動かして区分 Jacobi 場 $J_T$ にする。終点では $\partial_TJ_T(T_0)=-\nabla_tJ(T_0)$ となる。可変上端の微分から $|\nabla_tJ(T_0)|^2$、積分内の微分を部分積分した境界項から $-2|\nabla_tJ(T_0)|^2$ が出る。節点は固定で、その変分値は零である。よって核上で $B'(T_0)(J,J)=-|\nabla_tJ(T_0)|^2$ となる。終点で値と微分がともに零なら線形常微分方程式の一意性で $J=0$ なので、これは負定値である。

核と補空間によるブロック表示を用いると、補空間ブロックは近くで可逆で指数一定である。Schur 補行列は $T=T_0$ で零、微分は上記の負定値形式だから、その固有値は左で正、右で負になる。したがって指数はこの点の直後に核の次元だけ増え、点自体ではその次元はまだ指数に入らない。交差は孤立し、零近傍では存在せず、有限の区間では有限個である。従って総和公式が成り立つ。
:::

:::example[単位球面の大円]
弧長 $s$ の単位速大円では接線と直交する方向の Jacobi 方程式は $J''+J=0$ である。始点零の法方向解は $\sin s$ であり、共役点は正の $\pi$ の整数倍、重複度は $n-1$ である。$S^3$ 上の長さ $5\pi/2$ の道なら内部に二点あり、指数は $4$ である。
:::

:::example[平坦なトーラス]
平坦計量では $I(V,V)=\int|\nabla_tV|^2$ である。両端固定の平行場は零なので、各測地線の指数は零である。端点の持ち上げ先を格子だけずらしたものが別々の直線測地線を作り、それぞれの道の成分でエネルギーを最小にする。
:::

### エネルギーの有限な範囲での近似

:::proposition[折れ線によるエネルギー劣位集合]{#prop-dtop-energy-reduction}
$M$ を完備 Riemann 多様体とし、両端を固定した $H^1$ 級の道のエネルギーの上限を $C$ に取る。時間の分割を十分細かくすると、$E\le C$ の集合は短い測地線を継いだ道からなる部分集合へ強変形収縮する。
:::

:::proof
$H^1$ 級の道は連続であり、各時間区間 $[t_i,t_{i+1}]$ の部分の長さは $\sqrt{2C(t_{i+1}-t_i)}$ 以下である。特に道の像は始点を中心とする半径 $\sqrt{2C}$ の閉球に含まれ、この球は Hopf–Rinow の定理によりコンパクトである。従って道を含む範囲で一様な正の強凸半径が取れる。部分の長さがその半径より小さくなるように分割する。各区間では、左端から途中の時刻 $s$ までの道を、同じ端点を結ぶ一意な最短測地線へ時間幅を保って置き換え、残りの部分をそのままにする。$s$ を左端から右端まで動かすと、元の道から全区間の測地線への変形となる。Cauchy–Schwarz により元の部分のエネルギーは距離の二乗を時間幅の二倍で割った値以上である。置き換えた定速測地線はその下限を達成し、エネルギーを増やさない。

区間幅が正なら最短測地線は端点に滑らかに依存する。幅が零に近づくときは、置き換え部分のエネルギーが元の短区間上のエネルギー以下で零に近づき、位置も初期点へ一様に近づく。したがって $H^1$ 位相で変形は連続である。同じ議論は、道も近づく場合にエネルギー密度の $L^1$ 収束を使えば一様に成り立つ。最初から定速の短い測地線でできている道では、部分最短測地線は同じ速度の元の曲線なので全変形で固定される。
:::

この還元でエネルギーは、内挿点 $(x_i)$ に対する $\sum_i d(x_i,x_{i+1})^2/(2(t_{i+1}-t_i))$ となる。端点間の短い測地線が一意な領域で距離二乗は滑らかであり、折れ線の臨界点で接続する速度が一致することが、一階変分から従う。エネルギー上限を固定して分割を選ぶ順序が重要であり、無制限な全道空間に対して一つの分割が使えるとは限らない。

:::example[一次元の境界値問題]
直線上で $0$ から $3$ へ時間 $1$ で進み、途中の時刻 $1/2$ の位置を $x$ とする。折れ線エネルギーは $x^2+(3-x)^2=2(x-3/2)^2+9/2$ である。節点の唯一の臨界値は $x=3/2$ で Hessian は $4$、両区間の速度はどちらも $3$ になる。
:::

### 曲率が一定な各方向の指数を比較する

:::example[球面の端点が共役点に一致する場合]
単位 $S^4$ 上の長さ $3\pi$ の大円弧を考える。内部の共役点は弧長 $\pi,2\pi$、重複度は各 $3$ であり、終端 $3\pi$ の重複度も $3$ である。従って指数は $6$、退化次数は $3$ である。長さを $3\pi-\eps$ とすると指数は同じで退化次数が零、$3\pi+\eps$ とすると指数は $9$ になる。臨界点が退化するちょうどその値では、零固有値を指数に数えないことが重要である。弧長方向の成分の Jacobi 方程式は $u''=0$ であり、両端零なら $u=0$ なので、重複度に接線方向は含まれない。
:::

:::example[負曲率のモデル]
一定曲率 $-1$ の空間で単位速測地線を取り、法方向を平行移動でそろえる。各成分の方程式は $u''-u=0$ であり、始点が零なら $u(s)=a\sinh s$ である。$s>0$ で $\sinh s>0$ なので共役点はない。指数形式そのものも法方向では $\int(|u'|^2+|u|^2)\,ds$、接線方向では $\int|u'|^2\,ds$ であり、端点零の条件で正定値である。従って長さによらず指数と退化次数はともに零である。曲率が正のときに共役点が現れる仕組みが、方程式の正弦と双曲正弦の違いに対応する。
:::

:::example[直積の測地線]
$S^2\times\R$ で、時間 $[0,1]$ の間に大円を長さ $5\pi/2$ だけ進み、直線方向を速度 $3$ で進む測地線を取る。直積接続では曲率作用は球面成分と平坦成分に分かれる。球面の法方向の方程式は $u''+(5\pi/2)^2u=0$ であり、共役時刻は内部に $2/5,4/5$ の二点で各重複度一である。球面の接線方向と直線方向はそれぞれ $u''=0$ なので共役方向を追加しない。従って全体の指数は $2$ であり、直線方向の長さを変えても値は変わらない。
:::

### 節点のエネルギーを行列で調べる

:::example[二つの自由節点を持つ直線の折れ線]
$0$ と $6$ を結ぶ道に、時刻 $1/3,2/3$ の節点 $x,y$ を置く。折れ線のエネルギーは
$$
E(x,y)=\tfrac32\bigl(x^2+(y-x)^2+(6-y)^2\bigr).
$$
微分を零にする条件は $2x-y=0$、$2y-x-6=0$ であり、解は $(2,4)$ である。Hessian は $\begin{pmatrix}6&-3\\-3&6\end{pmatrix}$ で、$(1,1)$ と $(1,-1)$ に対する固有値は $3,9$ である。符号により指数は零である。二つの節点が同方向に動く変分でも、反対方向に動く変分でもエネルギーが増えるが、後者では中間の線分の長さがより大きく変わる。極小エネルギーは各線分で速度六なので $18$ である。
:::

:::example[整数の持ち上げごとに異なるエネルギーを持つ]
平坦な $T^2=\R^2/\Z^2$ の $[0,0]$ から $[1/3,1/2]$ へ向かう。始点を $0$ に持ち上げると終点は $(m+1/3,n+1/2)$、$m,n\in\Z$ である。各成分の最短測地線のエネルギーは $\tfrac12((m+1/3)^2+(n+1/2)^2)$ である。最小の値は $(m,n)=(0,0),(0,-1)$ で等しく $13/72$ である。$(m,n)=(-1,0)$ の測地線も自分の成分では唯一の極小だが、そのエネルギーは $25/72$ である。相異なる成分の極小同士は、端点を固定した道の変形では結ばれない。エネルギーの臨界値が同じでも、臨界点同士の局所的な退化とは関係しない。
:::

:::example[エネルギー上限から必要な分割を選ぶ]
強凸半径として $\rho>0$ が与えられ、$E\le C$ を考える。分割幅 $h$ での弧長は Cauchy–Schwarz により $\sqrt{2Ch}$ 以下である。一様分割で $h=1/N$ なら $N>2C/\rho^2$ を選べば、全区間の端点が同じ強凸球に入る。例えば $\rho=1/2$、$C=3$ なら $N=25$ がこの十分条件を満たす。ある一つの短い測地線に必要な分割と、劣位集合のあらゆる道に共通の分割は異なる。エネルギー上限を四倍にすると、同じ見積もりで幅を四分の一にする必要がある。
:::

### 球面の指数を節点の行列で再計算する

:::proposition[等分割した球面測地線の指数行列]{#prop-dtop-spherical-index-matrix}
単位 $S^n$ 上の単位速測地線の長さを $L$ とする。$N$ 等分割して $h=L/N<\pi$ とし、両端で零の法方向の場を節点値 $b_1,\dots,b_{N-1}$ で表す。一つの平行な法方向での指数形式の行列は対角成分 $2\cot h$、隣接成分 $-\csc h$ の三重対角行列である。その固有値は
$$
\lambda_j=\frac{2(\cos h-\cos(j\pi/N))}{\sin h},\qquad 1\le j<N
$$
である。
:::

:::proof
一小区間 $0\le s\le h$ で端の二値 $a,b$ を結ぶ Jacobi 場の成分は
$$
J(s)=\frac{a\sin(h-s)+b\sin s}{\sin h}
$$
である。方程式 $J''+J=0$ を使って部分積分すると、その指数形式は $[JJ']_0^h=\cot h(a^2+b^2)-2\csc h\,ab$ である。全小区間を合わせ、両端の節点値を零とすると各内点の二乗が二回ずつ現れ、隣接間の積は一回ずつ現れる。従って主張の行列となる。$b_i^{(j)}=\sin(ij\pi/N)$ とすれば、$b_{i-1}^{(j)}+b_{i+1}^{(j)}=2\cos(j\pi/N)b_i^{(j)}$ であり、外端も零を満たす。この代入で掲げた固有値を得る。$0<j\pi/N<\pi$ の範囲で余弦は厳密に減るため、これらは異なる固有値であり、非零の固有ベクトル $N-1$ 本が全空間を張る。残る端点零の節点内の成分は、:ref[prop-dtop-broken-geodesic] と同じ直交分解で正定値である。$h<\pi$ の全範囲での正定値性は区間の Dirichlet 不等式 $\int |V'|^2\ge(\pi/h)^2\int |V|^2$ からも従う。滑らかな端点零の関数を正弦級数に展開すると、各係数の微分エネルギーに $(j\pi/h)^2$ が掛かり、最小値が $(\pi/h)^2$ である。$H^1$ の端点零の関数には近似で同じ式が移る。
:::

:::example[同じ分割点数で三つの長さを比較する]
$N=4$ とし、$L=5\pi/2,3\pi,7\pi/2$ を比べる。対応する $h$ は $5\pi/8,3\pi/4,7\pi/8$ であり、どれも $\pi$ 未満である。$\lambda_j<0$ の条件は $j\pi<L$ で、$\lambda_j=0$ の条件は $j\pi=L$ である。従って三つの固有値の符号列は順に $(-,-,+)$、$(-,-,0)$、$(-,-,-)$ となる。$S^4$ では法方向が三本あり、接線方向の指数形式は正なので、全指数と退化次数の対は $(6,0),(6,3),(9,0)$ である。節点法の固有値の交差が、共役点を終端に含む瞬間を捉えている。
:::

### 連続道との比較と臨界点の有限性

:::proposition[道空間の二つの位相の比較]{#prop-dtop-path-models}
完備 Riemann 多様体上の両端固定道空間で、$H^1$ 級の道から連続道への包含は弱ホモトピー同値である。
:::

:::proof
球面または円板などのコンパクトなパラメータ空間 $K$ から連続道空間への写像は、$K\times[0,1]$ の連続写像に対応する。一様連続性を使い、全パラメータの道で各時間小区間が強凸な測地球に収まるよう、一つの共通の分割を取る。各小区間を短い測地線で置き換えれば、節点値の連続な変化によって $H^1$ 位相で連続な族になる。一方、置き換える区間を左端から徐々に伸ばすホモトピーは、連続道空間の一様位相で連続である。これによりすべてのホモトピー類は $H^1$ の族で表せる。

次に $H^1$ の連続な族が連続道空間で延長されるとする。円板全体で共通分割を選び、同じ測地線置換を行う。境界の $H^1$ の族にはコンパクト性で共通のエネルギー上界があり、分割をさらに細かくすれば前節の $H^1$ 連続な置換を境界上で適用できる。境界の置換ホモトピーと置換後の円板を貼れば、最初の族は $H^1$ 道空間で延長される。基点が定数道であるときは、それをすべての置換で固定する。一般の基点では置換中の基点の道でホモトピー群の基点移動を行う。従ってすべてのホモトピー群と成分集合で同型である。
:::

:::example[一般の終点とエネルギーの上限]
始点 $p$ を固定し、指数写像 $\exp_p\colon T_pM\to M$ の正則値 $q$ を選ぶ。$p$ から $q$ に至る定速測地線は初速度 $v$ で一意に決まり、$E\le C$ は $\norm v\le\sqrt{2C}$ に対応する。正則値の逆像は零次元であり、この閉球との交わりはコンパクトなので有限である。指数写像の垂直微分の核は終点で消える始点零の Jacobi 場に対応する。従って各臨界測地線は非退化である。例えば単位球面で $q$ が $p$ でもその対蹠点でもなければ、両点を通る大円は一つであり、二方向に有限回余分に周回する測地線だけが有界エネルギーに現れる。対蹠点を終点にすると、どの大円方向にも長さ $\pi$ の測地線があるため、正則値の仮定が失われる。
:::

:::proposition[正則な終点に至る道空間の胞体]{#prop-dtop-geodesic-cells}
完備連結 Riemann 多様体の点 $p,q$ を取り、$q$ は $\exp_p$ の正則値とする。$p$ から $q$ への連続道の空間は、測地線一本につきその指数の胞体を一つ持つ可算 CW 複体とホモトピー同値である。
:::

:::proof
測地線は正則性によって非退化であり、エネルギー上限ごとに有限本である。臨界値を避けて上限 $C_j\to\infty$ を選ぶ。各 $C_j$ に対し、前段の分割を細分する形で :ref[prop-dtop-energy-reduction] の分割を取る。節点空間でのエネルギー劣位集合を $B_j$ とする。強凸半径に対して各節点間距離に厳しい上界を課してあるため、この劣位集合は有限次元の開節点空間内でコンパクトである。各測地線の節点 Hessian は :ref[prop-dtop-broken-geodesic] により元の指数と同じである。従って :ref[thm-dtop-handle-attachment] により、上限の間に現れる測地線に対して、その指数の芯が一つずつ加わる。同じ値を持つ測地線の近傍は互いに素に取れる。

細分しても、もとの区分測地線は同じ道なので $B_j$ は次の節点モデルにも含まれる。そのモデルの $C_j$ 以下の部分は $B_j$ へ強変形収縮する。実際、粗い分割での測地線置換を段階的に行い、各時刻で細かい分割へ測地線置換し直せば、全変形は細かい節点モデル内に入り、$B_j$ を固定し、エネルギーを増やさない。従って次の上限に移る際は、この強変形収縮で前のモデルへ貼り込みを移せる。:ref[thm-dtop-morse-cw] のように芯へ縮め、貼り込みのホモトピーを新セルの襟に入れれば、先に定義した写像を保ちながら胞体を追加できる。

得られた可算 CW 複体から道空間への写像を考える。CW 複体側の球面や円板の像は有限部分複体に含まれる。$H^1$ 道空間側のコンパクトな族は共通のエネルギー上限を持ち、その段の節点への強変形収縮が使える。従って成分と全ホモトピー群で同型になる。:ref[prop-dtop-path-models] により、連続道空間への写像も弱ホモトピー同値である。

連続道空間を $X$ とする。多様体を Euclid 空間に閉埋め込みし、開管状近傍 $U$ を取る。$U$ 内を進む両端固定の連続道は、Euclid 空間値の連続道の Banach 空間のうち両端を固定したアフィン部分空間で開集合をなす。実際、各道の像はコンパクトで $U$ の補集合から離れている。管状射影を各時刻の値に作用させると $X$ へのレトラクションになる。この開集合は凸な小球で覆える。凸な有限交叉は可縮であり、1 の分割と重心細分を使う前章の神経の証明によって開集合は CW 型を持つ。従って、ある CW 複体 $L$ と写像 $a\colon X\to L$、$b\colon L\to X$ があって $ba\simeq\id_X$ となる。

構成した弱同値を $g\colon K\to X$ とする。弱同値は CW 複体からのホモトピー類の集合に同型を誘導する。これには $g$ を写像道のファイブレーションで置き換え、そのファイバーのホモトピー群がすべて零であることを使う。各胞体上の持ち上げは、その境界の球面がファイバー内で縮むため延長できる。ホモトピーについても円柱の相対胞体を同じように扱えば、持ち上げはホモトピーまで一意である。従って $b$ はある $\widetilde b\colon L\to K$ を通じてホモトピーまで持ち上がる。$h=\widetilde b a$ と置くと $gh\simeq ba\simeq\id_X$ である。$ghg\simeq g$ から、CW 複体 $K$ に対する一意性を使うと $hg\simeq\id_K$ となる。このため $g$ はホモトピー同値である。道空間のこの構成は :cite[milnor-morse] の基本定理に当たる。
:::

:::example[球面の道空間に現れる胞体の次数]
単位 $S^n$ で $n\ge2$ とし、端点のなす角を $0<\theta<\pi$ とする。長さの昇順に $\theta,2\pi-\theta,2\pi+\theta,4\pi-\theta,\ldots$ の大円測地線が一本ずつある。零から番号を付けた第 $j$ 番目の長さは $j\pi$ と $(j+1)\pi$ の間にある。各 $\pi$ の倍数で共役点の重複度は $n-1$ なので、指数は $j(n-1)$ である。従って道空間の CW 型は $0,n-1,2(n-1),\ldots$ 次元に一つずつ胞体を持つ。固定した一つの道の逆向きと連結すればこの道空間は $\Omega S^n$ とホモトピー同値であり、逆操作との往復は収縮できる。
:::

## Lie 群とループ空間のホモトピー型

### ループを群で考える

基点 $e$ を持つ空間 $X$ の :term[基点付きループ空間]{en="based loop space" yomi="きてんつきるーぷくうかん"} $\Omega X$ は $\gamma(0)=\gamma(1)=e$ を満たす連続な道の空間で、コンパクト開位相を入れる。Lie 群 $G$ ではループの連結に加え、各時刻の群演算による積がある。

:::proposition[次数を一つ下げる同型]{#prop-dtop-loop-adjunction}
$k\ge1$ について $\pi_k(\Omega X)\cong\pi_{k+1}(X)$ である。道成分集合 $\pi_0(\Omega X)$ は連結の積で $\pi_1(X)$ に同型である。
:::

:::proof
立方体表示では $[0,1]^k$ から $\Omega X$ への写像で境界の値を定数ループにする。評価により $[0,1]^k\times[0,1]$ から $X$ への写像で全境界の値が $e$ のものに対応する。コンパクト開位相の指数法則によりこの対応とその逆は連続写像を保つ。同じ対応をホモトピーに適用でき、立方体の第 1 座標の連結積も保つ。$k=0$ では道成分の比較が両端固定の道ホモトピーそのものである。
:::

:::example[トーラスのループ空間]
$T^d=\R^d/\Z^d$ の基点を零とする。基点付きループは零から格子点 $m$ に至る道に一意に持ち上がり、終点 $m$ はホモトピーで一定である。同じ $m$ のすべての道は $\gamma(t)\mapsto(1-u)\gamma(t)+ut m$ で直線に変形収縮する。道の持ち上げは細分した時間区間で局所逆写像を使って連続に行えるので、各成分は可縮である。よって $\Omega T^d\simeq\Z^d$ である。
:::

:::example[$SU(2)$ の場合]
行列 $\begin{pmatrix}a&-\overline b\\b&\overline a\end{pmatrix}$ に $(a,b)$ を対応させると、$|a|^2+|b|^2=1$ で $SU(2)\cong S^3$ となる。したがって $\pi_2(\Omega SU(2))=\pi_3(S^3)\cong\Z$ であり、最後の同型は :ref[thm-dtop-hopf-degree] から従う。
:::

### ループの二つの積と連結成分

:::proposition[群値ループの積の比較]{#prop-dtop-loop-products}
位相群 $G$ の基点を単位元とする。二つの基点付きループの点ごとの積は、時間方向に連結したループと基点付きでホモトピックである。さらに、任意のループの成分は、点ごとの積で単位成分と同相である。
:::

:::proof
$\alpha,\beta$ の点ごとの積を $\alpha(a_0(t))\beta(b_0(t))$ と書き、$a_0(t)=b_0(t)=t$ とする。$a_1(t)=\min(2t,1)$、$b_1(t)=\max(2t-1,0)$ に置き換えると、前半は $\alpha$、後半は $\beta$ だけが進む。$a_s=(1-s)a_0+sa_1$ と $b_s$ の同じ補間を使えば、端点が常に基点である連続なホモトピーが得られる。固定ループ $\lambda$ に左から点ごとの積を取る写像は連続であり、$\lambda^{-1}$ を使う写像が逆である。従って単位ループを含む成分は $\lambda$ を含む成分へ同相に写る。
:::

:::example[円周上の二つのループ]
$\alpha(t)=e^{2\pi i(2t)}$、$\beta(t)=e^{-2\pi it}$ とする。点ごとの積は $e^{2\pi it}$ で巻数 $1$ である。連結では前半に角が $4\pi$ 増え、後半に $2\pi$ 減るので、全変化は同じ $2\pi$ になる。途中の角の進み方は違うものの、:ref[prop-dtop-loop-products] の補間がその違いを連続に変える。成分を固定することは、特定の時刻の速度や位置を固定することではない。
:::

:::example[$U(n)$ の各成分を行列式で読む]
最後の列を使う束の長完全列から $\pi_1(U(1))\to\pi_1(U(n))$ は同型である。標準包含では $z\mapsto\diag(z,1,\ldots,1)$ なので、行列式はこの包含との合成で $z$ を返す。従って行列式が誘導する $\pi_1(U(n))\to\pi_1(S^1)$ は逆同型である。例えば $\diag(e^{4\pi it},e^{-6\pi it},1)$ の行列式は $e^{-2\pi it}$ なので、$\Omega U(3)$ の成分は整数 $-1$ である。各対角成分の巻数はそれぞれ $2,-3,0$ だが、群全体のループの成分に残るのはその和である。
:::

:::example[閉ループ空間と基点付きループ空間]
Lie 群 $G$ の自由ループ $\gamma$ に対し、$(\gamma(0),\gamma(0)^{-1}\gamma(t))$ を対応させる。この後者は基点付きであり、逆は $(g,\lambda)\mapsto g\lambda(t)$ であるから、自由ループ空間は $G\times\Omega G$ と同相になる。例えば $G=S^1$ では $\Omega S^1$ の成分は各々可縮だが、自由ループの各成分は $S^1$ のホモトピー型を持つ。基点を固定するかどうかで、ループ全体を一様に移動する自由度が残るかが変わる。
:::

:::proposition[コンパクト単連結 Lie 群のループ空間]{#prop-dtop-compact-lie-loop-cells}
コンパクト単連結 Lie 群 $G$ の基点付きループ空間には、各偶数次数に有限個の胞体を持ち、奇数次数に胞体を持たない CW 型がある。従って奇数次の整数ホモロジーは零であり、偶数次は有限階数の自由 Abel 群である。
:::

:::proof
コンパクト群の平均化によって随伴不変な内積を選び、両側不変計量を作る。曲率作用は後で計算するように $R(V,A)A=-\operatorname{ad}_A^2(V)/4$ である。各測地線の初速度を $A$ とすると、$\operatorname{ad}_A$ は内積に関して反対称である。そこで実空間を核と回転二平面の直交和に分ける。平行枠では回転二平面に同じ周波数の Jacobi 方程式が二本出る。両端固定の各共役時刻における寄与は平面ごとに二であり、従って Morse 指数は偶数である。

Lie 代数の中心が非零なら、中心の非零元に内積双対な左不変一次形式が得られる。この形式は交換子を消すので閉である。単連結性により実数値関数の微分になるが、左不変でどこでも非零なので、その関数がコンパクトな $G$ で極値を取ることに反する。従って中心は零で、$A\mapsto\operatorname{ad}_A$ は単射である。単位球面上でその作用素ノルムの下限が正なので、$\norm{\operatorname{ad}_A}\ge c\norm A$ となる。最大周波数に対応する一平面だけでも、$\norm A$ が増えるにつれて内部共役時刻の個数は無限に増える。ゆえに指数に上界を課すと初速度とエネルギーも有界である。

始点 $e$ に対して $\exp_e$ の正則値 $q$ を選ぶ。指数が一定の臨界測地線は、先のエネルギー上界と正則性により有限本である。:ref[prop-dtop-geodesic-cells] により $e$ から $q$ への道空間には偶数次の胞体だけが現れる。固定した道との点ごとの積でこの空間を $\Omega G$ と同相にできる。奇数次の鎖群が零なので胞体境界はすべて零となり、各偶数次の鎖群がそのままホモロジーになる。
:::

## Bott の周期性定理の概観

:::theorem[Bott の複素周期性]{#thm-dtop-bott}
標準包含 $U(n)\to U(n+1)$ の直極限を $U$、安定複素ベクトル束の分類空間を $BU$ とする。基点付き弱ホモトピー型として $\Omega U\simeq\Z\times BU$、$\Omega^2 U\simeq U$ である。従って安定群 $\pi_j(U)$ は偶数次数で $0$、奇数次数で $\Z$ である。
:::

以下では特殊ユニタリ群の測地線で定数ループの成分を計算する。古典群全体を扱う証明は :cite[milnor-morse] を参照する。

安定範囲は $U(n+1)$ の最後の列を取る束 $U(n)\to U(n+1)\to S^{2n+1}$ から読める。最後の列を近傍で Gram–Schmidt によりユニタリ基底に完成すれば局所自明になる。球面の $2n$ 以下のホモトピー群が零なので、長完全列において $\pi_j(U(n))\to\pi_j(U(n+1))$ は $j<2n$ で同型である。初期値は $\pi_0(U)=0$ と $\pi_1(U)=\Z$ である。前者はユニタリ行列を対角化して固有値の角を連続に零へ動かせば従い、後者は上の安定範囲で $U(1)=S^1$ から従う。二重ループの同値でこの二値が二周期で続く。

:::example[安定な次数]
$U(3)$ の $\pi_5$ は $5<6$ なので安定し $\Z$ である。同じ不等式は $\pi_6(U(3))$ には適用できない。
:::

:::example[ループ成分と高次の群]
$\Omega U$ の成分は $\pi_1(U)=\Z$ で区別される。一方、定数ループの成分の $\pi_2$ は $\pi_3(U)=\Z$ であり、各成分を点とみなす近似ではこの情報が消える。
:::

### 安定群へ移る不等式の境界

束のホモトピー長完全列で $\pi_{j+1}(S^{2n+1})$ と $\pi_j(S^{2n+1})$ の両方が零なら、$U(n)\hookrightarrow U(n+1)$ は $\pi_j$ で同型になる。$j=2n$ では右の群は零だが左は $\Z$ であり、包含が全射であることまでしかこの議論は保証しない。境界の左の群から来る像が、不安定成分を生じる場所である。

:::example[$U(2)$ とその跡]
$U(2)$ の行列式を $S^1$ へ送る写像には $\operatorname{diag}(z,1)$ という切断があり、ファイバーは $SU(2)\cong S^3$ である。高次群では $S^1$ の両隣の群が零なので $\pi_j(SU(2))\to\pi_j(U(2))$ は $j\ge2$ で同型である。$j=3$ については球面への写像度から $\Z$ が得られ、安定範囲 $3<4$ に入ることと一致する。
:::

### 最短測地線の臨界部分多様体が現れる理由

:::example[$U(2m)$ の対角行列から作る測地線]
$U(2m)$ に Lie 代数上の内積 $-\Re\tr(AB)$ を移した両側不変計量を入れる。左不変場に対する Koszul の公式では内積の微分項が零となり、括弧の随伴不変性から $\nabla_A B=[A,B]/2$ となる。従って $\exp(tA)$ は一定速度の測地線である。$I$ から $-I$ へ時間一で進むなら、$A$ の固有値は $i\pi$ の奇数倍であり、エネルギーはその絶対値の二乗の総和の半分である。最短の候補では固有値はすべて $\pm i\pi$ である。さらに $SU(2m)$ 内に道を取るには $\tr A=0$ なので、各符号が $m$ 個ずつ現れる。従って最短測地線を決める自由度は正の固有空間の $m$ 次元複素部分空間であり、$Gr_m(\C^{2m})$ に対応する。
:::

:::example[四次元で一つ長い固有角が現れる場合]
$SU(4)$ で対角の固有角を $\pi(1,1,-1,-1)$ に取ると和は零で、終点は $-I$、エネルギーは $2\pi^2$ である。$\pi(3,-1,-1,-1)$ に替えても和は零、終点は同じだが、エネルギーは $6\pi^2$ となる。最短の候補は固有角の並べ替えだけでは区別されず、正の固有空間を連続に動かせる。一方、長い測地線の存在を確かめるだけでは周期性は出ない。それらが低次のホモトピー群を変えないことを示すには、指数の下界が必要である。
:::

### 安定範囲で数値として何が決まるか

:::example[安定群と不安定な球面群を比べる]
$U(1)=S^1$ なので $\pi_3(U(1))=0$ である。一方、$\pi_3(U(2))=\Z$ で、$3<4$ より安定群へ同型に写る。従って $U(1)$ の包含から $\pi_3(U)$ を求めることはできない。$j=5$ では $U(2)$ は範囲 $5<4$ を満たさず、$U(3)$ は $5<6$ を満たす。一般に $\pi_{2r-1}(U(r))$ は奇数の安定値 $\Z$ を直接読む最初の安定範囲にあり、$\pi_{2r}(U(r))$ はちょうど境界にある。包含先の安定群が零でも、包含元の群が零とは限らない。
:::

:::example[偶数球面の安定複素束]
$d\ge2$ の球面上では、二半球に制限した複素束は自明である。赤道で二つの自明化をつなぐ写像を $GL(r,\C)$ 値から極分解で $U(r)$ 値へ変えられる。半球上の自明化の変更が赤道に与える写像は半球へ延びるので定数に縮む。一方、二つの貼り合わせ写像のホモトピーは球面と区間の積の上に束を与え、両端の束は同型である。従って階数を増やして自明束を加えると、安定類は安定化した $\pi_{d-1}(U)$ で分類できる。$d=4$ では $\Z$、$d=5$ では $0$ である。$S^4$ では $\pi_3(U(2))$ がすでに安定であり、階数二の束で非自明な安定類を実現できる。一方 $\pi_3(U(1))=0$ なので、この球面上の複素直線束はすべて自明である。一般の底空間での構成は [ベクトル束の分類](/math/differential-topology/bundle-classification/) で扱う。
:::

### 行列群の共役点を固有角から数える

:::proposition[両側不変計量での固有角と指数]{#prop-dtop-bott-index}
$SU(N)$ に $\langle X,Y\rangle=-\Re\tr(XY)$ の両側不変計量を入れる。$A=i\diag(a_1,\ldots,a_N)$、$\sum_i a_i=0$ とし、$[0,1]$ 上の測地線 $\gamma(t)=\exp(tA)$ を考える。各対 $j<k$ は Jacobi 方程式の周波数 $|a_j-a_k|/2$ を持つ実二次元の法方向を与える。従ってその対の指数への寄与は $0<2\pi\ell<|a_j-a_k|$ を満たす正整数 $\ell$ の個数の二倍、退化次数への寄与は $|a_j-a_k|$ が正の $2\pi$ の整数倍のときに $2$ である。
:::

:::proof
左不変場で $\nabla_XY=[X,Y]/2$ を使うと、
$$
R(X,Y)Z=\tfrac14[X,[Y,Z]]-\tfrac14[Y,[X,Z]]-\tfrac12[[X,Y],Z]
=-\tfrac14[[X,Y],Z]
$$
である。最後は Jacobi 恒等式による。従って $R(V,A)A=-\tfrac14\operatorname{ad}_A^2V$ である。平行移動した枠での曲率作用を求めるために、左自明化の成分 $W(t)$ を書く。平行場の式は $W'+[A,W]/2=0$ であり、$W(t)=\exp(-t\operatorname{ad}_A/2)W(0)$ となる。この移動は $\operatorname{ad}_A^2$ と可換なので、平行枠でも曲率作用は一定である。

対角方向では $\operatorname{ad}_A=0$ であり、Jacobi 方程式は二階微分零になる。非対角成分の対 $(j,k)$ を、一つの複素数 $z$ と反対側の $-\bar z$ で表す。この平面で $[A,W]_{jk}=i(a_j-a_k)z$ なので、その平方は $-(a_j-a_k)^2$ 倍である。従って平行枠の二つの実成分に同じ周波数の正弦方程式が現れる。始点で零の場は $\sin(|a_j-a_k|t/2)$ の倍となり、共役時刻は $2\pi\ell/|a_j-a_k|$ である。等しい二角の場合は周波数零なので共役時刻はない。他の成分と直交して方程式が分かれるため、:ref[thm-dtop-geodesic-index] を各対へ適用して和を取れる。
:::

:::example[$SU(4)$ の最短軌道と長い軌道を比較する]
$a=\pi(1,1,-1,-1)$ の場合、異符号の対が四つあり角差が $2\pi$ である。同符号の対は角差零である。従って指数は零、退化次数は $2\cdot4=8$ である。これは最短軌道の集合 $\mathrm{Gr}_2(\C^4)$ の実次元 $2\cdot2\cdot2=8$ と一致する。

一方 $a=\pi(3,-1,-1,-1)$ の場合、最初の列と残る三列の角差は $4\pi$ である。各対で $t=1/2$ が内部共役時刻、$t=1$ が終端の共役時刻になる。他の対は角差零だから、指数は $6$、退化次数は $6$ である。正の固有空間が複素直線なので、この軌道の共役で得られる臨界部分多様体は $\C P^3$ で実次元六である。指数の六と退化の六は同じ数だが、前者はエネルギーを下げる方向、後者は臨界族を動く方向を表している。
:::

:::example[最短の軌道以外の指数に下界を与える]
$SU(2m)$ の $I$ から $-I$ への軌道では、$a_j/\pi$ は奇数で和が零である。全てが $\pm1$ なら最短である。そうでなければ、全角の符号を必要に応じて反転し、ある角が少なくとも $3\pi$ であるとできる。$a_j/\pi=1+2b_j$、$b_j\in\Z$ とすると $\sum b_j=-m$ であり、ある $b_j\ge1$ がある。最大の $b_j=B\ge1$ を一つ取り、この角と他の角の差による指数寄与を足す。:ref[prop-dtop-bott-index] により第 $k$ 角との寄与は $2\max(B-b_k-1,0)$ である。よって
$$
\sum_{k\ne j}2\max(B-b_k-1,0)
\ge 2\big((2m-1)(B-1)+m+B\big)\ge 2m+2.
$$
他の角の対は非負の寄与なので同じ下界が保たれる。$m=2$ の前例は指数六でこの下界に達する。安定範囲が広がる仕組みは、最短の族以外の臨界集合から来る指数が $m$ とともに高くなることにある。
:::

### 最短の族から複素周期性を得る

まず有限次元の臨界部分多様体 $C$ を通過する場合を考える。$C$ がコンパクトで、Hessian の核が $TC$ なら、法束上で $f-c=B(p,v)(v,v)$ と書ける。ここで $B$ はファイバー方向の Taylor 積分で得た対称形式であり、$B_0(p)=B(p,0)$ は法束上で非退化である。$L=B_0^{-1}B$ は恒等に近く $B_0$ に関して自己共役なので、恒等の周りのべき級数で $A=L^{1/2}$ が滑らかに定まる。$B(p,v)(v,v)=B_0(p)(Av,Av)$ であり、$(p,v)\mapsto(p,Av)$ は零切断上で法微分が恒等である。小さい法ディスクに制限すればコンパクト性と逆関数定理で座標変更になる。$B_0$ の正負の固有束を $E^+,E^-$ とし、それぞれ $\pm B_0$ で測れば $f=c-|u|^2+|v|^2$ と書ける。

この式で $|v|\le b$、$|u|^2\le\epsilon+|v|^2$ の領域を選ぶと、接着部は $|u|^2=\epsilon+|v|^2$ である。束の中で $(u,-v)$ を用いる下降流は自由境界と下の等位面に内向きであり、:ref[thm-dtop-handle-attachment] と同じ通過時刻の議論で、この領域を下の劣位集合に貼った形へ収縮する。余芯側を縮めると、対として残るのは $(D(E^-),S(E^-))$ である。$C$ の CW 分解を使うと、階数 $\lambda$ の負束は各胞体の特性円板上で自明である。底の次元 $i$ の円板上の対は
$$
(D^i\times D^\lambda,\ 
 (\partial D^i\times D^\lambda)\cup(D^i\times S^{\lambda-1}))
$$
なので、相対胞体の次元は $i+\lambda$ である。従って最小値集合を越えた後に指数が $\lambda$ 以上の臨界部分多様体しか現れなければ、次元 $\lambda$ 未満の相対胞体は加わらない。

$SU(2m)$ の $I$ から $-I$ への道でエネルギー上限を固定し、:ref[prop-dtop-energy-reduction] の節点モデルを使う。節点の隣接距離を一様な強凸半径未満に取ると、各距離二乗は滑らかである。エネルギー上限から各節点間の距離にはさらに小さい上界があるので、節点モデルの該当する劣位集合はコンパクトである。各臨界部分多様体は固有角の多重集合を固定した共役軌道である。エネルギー上限の下では固有角の候補は有限個であり、軌道はコンパクトである。相異なる角を混ぜる行列成分の実二平面は一つずつ共役軌道に接する。その角差は $2\pi$ の整数倍なので :ref[prop-dtop-bott-index] の退化次数にも $2$ を寄与する。対角方向には核がない。よって Hessian の核は軌道の接束に一致し、上の接着を使える。最短の族 $Gr_m(\C^{2m})$ 以外の指数は少なくとも $2m+2$ である。胞体近似により、この族の包含は次数 $j<2m+1$ のホモトピー群で同型、$j=2m+1$ で全射を誘導する。全道空間へ移る際には、球面や円板から来る $H^1$ 道の族のエネルギーが一様に有界であることを使う。連続道の族にも :ref[prop-dtop-path-models] が適用できる。

各 $m$ で基準の正固有空間 $V_0$ を固定し、$V$ への直交射影を $P_V$ とする。最短の道 $\gamma_V(t)=\exp(i\pi t(2P_V-I))$ から $\gamma_V(t)\gamma_{V_0}(t)^{-1}$ で基点付きループを作る。基準道との点ごとの積は道空間とループ空間の同相を与える。$V$ と $V_0$ をともに新しい正の直線で拡張し、負の直線も一つ足すと、新しい二成分の指数関数は積で消える。従って Grassmann 多様体の安定化はループ側のブロック包含と可換である。各段の包含が同型を与える範囲は $m$ とともに広がるため、極限で $BU$ の Grassmann 模型から $\Omega SU$ への弱同値を得る。

この Grassmann 模型で $BU$ が安定な分類空間になる理由は、階数 $r$ と補空間の次元 $s$ を独立に増やす $Gr_r(\C^{r+s})$ の系にある。有限 CW 複体上の複素束は、局所自明化を 1 の分割で合わせると、有限次元の自明束へのファイバーごとの単射を持つ。像の部分空間を取れば Grassmann 多様体への写像で束を表せる。二つの単射は別々の周囲座標へ入れ、係数を $(1-t,t)$ で補間すれば各時刻で単射なので、補空間の次元を増やした後のホモトピーを与える。階数の増加は自明直線を足す操作である。任意の $(r,s)$ は $(m,m)$ で $m$ を十分大きく取ればそこへ移るため、対角の極限だけで安定な分類が得られる。

極限におけるホモトピー群は有限段の直極限で計算できる。実際、閉包含による直極限でコンパクト集合がどの有限段にも含まれなければ、各段と有限個の点でしか交わらない無限列を選べる。その列の任意の部分集合が終位相で閉となるので、コンパクト集合が無限閉離散部分集合を含むことになって矛盾する。ループのコンパクトな族については、時刻も込めた像に同じ事実を適用する。

行列式写像の積分解 $U(N)\cong S^1\times SU(N)$ は $\operatorname{diag}(z,1,\ldots,1)$ を使えば包含と可換に選べる。行列式は $\pi_1$ で同型なので、この分解から $SU(N)$ の基本群が零であることも分かる。従って $\Omega U$ の各成分は $\Omega SU$ と弱同値で、成分は巻数で $\Z$ に対応する。さらに主束 $U\to EU\to BU$ の全空間は可縮なので、道空間ファイブレーションと比較すると $\Omega BU$ と $U$ は弱同値である。具体的には $EU$ を基点へ縮める道を $BU$ へ射影して、ファイバー $U$ から $\Omega BU$ への写像を得る。そのホモトピー群への作用の逆が :ref[prop-at-classifying-pi] の接続写像である。以上から $\Omega U\simeq\Z\times BU$ と $\Omega^2 U\simeq U$ を得る。

実直交群では安定周期は八である。安定群 $O$ の $\pi_j(O)$ は $j\bmod 8=0,1,\ldots,7$ の順に $\Z/2,\Z/2,0,\Z,0,0,0,\Z$ となる。実版の証明では直交群、ユニタリ群、斜交群とそれらの等質空間に現れる最短の族を順に追う。この八段の同定と指数評価は :cite[milnor-morse] を参照する。

## Lefschetz 超平面定理

### 複素構造から指数を抑える

:::theorem[Lefschetz 超平面定理]{#thm-dtop-hyperplane}
$X\subset\C P^N$ を滑らかな連結複素射影多様体とし、$\dim_\C X=d\ge1$ とする。$Y=X\cap H$ を横断的な超平面切断とする。$X$ は $Y$ の閉管状近傍に指数 $d$ 以上のハンドルを付けて得られる。従って対 $(X,Y)$ は次数 $d$ 未満の相対胞体を持たない CW 対とホモトピー同値である。その結果、$H_i(Y;\Z)\to H_i(X;\Z)$ および基点付き $\pi_i(Y)\to\pi_i(X)$ は $i<d-1$ で同型、$i=d-1$ で全射である。次数零のホモトピーは成分についての主張とする。
:::

:::proof
射影空間の標準 Hermite 計量で、超平面を定める切断 $s$ の長さを測り、$X\setminus Y$ で $f=-\log|s|^2$ とする。超平面外のアフィン座標では加法定数を除いて $f=\log(1+\sum |z_j|^2)$ である。複素 Hessian を $\xi$ に評価すると
$$
\frac{(1+|z|^2)|\xi|^2-|\inner{\xi}{z}|^2}{(1+|z|^2)^2}>0\qquad(\xi\ne0)
$$
であり、複素部分多様体への制限でも正である。もし $Y$ が空なら、この関数はコンパクトな $X$ 全体で定義されて最大点を持つ。その点で複素 Hessian は、複素直線の実二方向の Hessian の和に比例するため非正となり、正値性に反する。従って $Y$ は非空である。$Y$ 近くでは法複素座標 $w$ によって $f=-\log|w|^2+g$ と書ける。$g$ は滑らかなので、十分 $Y$ に近いところで動径微分は $-2/|w|+O(1)$ で非零である。コンパクトな $Y$ の管状近傍においても、法半径 $r$ を使えば $|s|^2=r^2a(p,r,\theta)$、$a>0$ であり、十分小さい半径で単調に増加する。各ファイバーで長さ $\sqrt{|s|^2}$ の小さい一定値に達するまでの領域は、境界を滑らかに持つディスク近傍であり、法ファイバーを収縮すれば $Y$ に変形収縮する。

$f$ の臨界点があり得る部分はコンパクトである。そこで $C^2$ 小さく切断した摂動により、複素 Hessian の正値性を保ちながら $f$ を Morse にできる。臨界点で実 Hessian を $B$、複素構造を $J$ とすると、$B(v,v)+B(Jv,Jv)>0$ である。もし負定値部分空間 $W$ が $d$ より高次元なら $W\cap JW\ne0$ であり、$v,Jv$ がともに $W$ に入る非零 $v$ が存在して矛盾する。従って指数は高々 $d$ である。

$f$ の高い等位面から $-f$ の劣位集合を順に広げることは、法ディスク近傍の境界からアフィン部分を付け足すことに当たる。:ref[thm-dtop-handle-attachment] により各ハンドルの指数は $2d-\lambda\ge d$ となる。臨界値をすべて通れば $X$ 全体が得られる。従って相対 CW 型は次数 $d$ 未満の胞体を持たない。相対セル鎖複体と相対胞体近似により次数 $<d$ の相対群が消え、対の長完全列が主張を与える。
:::

:::example[射影空間の標準切断]
$\C P^3$ を切ると $\C P^2$ になる。$d=3$ なので基本群の同型と $\pi_2$ の全射が従う。実際には $\C P^3$ の残る射影セルは実次元 $6$ であるため、この例での同型範囲はさらに広い。
:::

:::example[曲線と点]
平面の滑らかな二次曲線を横断的な直線で切ると二点になる。$d=1$ の定理が保証するのは成分の全射だけであり、二点が一成分にまとまることと両立する。
:::

### 複素 Hessian の正値性と実指数

:::example[実 Hessian に負方向があっても複素 Hessian は正になる]
$\C^2$ の $z_j=x_j+iy_j$ に対し $q=-x_1^2+3y_1^2-2x_2^2+5y_2^2$ とする。$q$ の実 Hessian は $\diag(-2,6,-4,10)$ で、実指数は二である。複素構造 $J$ は各 $(x_j,y_j)$ の成分を交換して一方の符号を反転するので、$B(v,v)+B(Jv,Jv)$ は第 1 複素座標で $4|v_1|^2$、第 2 複素座標で $6|v_2|^2$ となる。従って複素 Hessian が正であるにもかかわらず、実の最小点ではない。この例では指数は複素次元二に等しく、一般の上界がちょうど達成される。
:::

:::example[複素曲線の二つの局所座標での微分]
$\C P^1$ のアフィン座標 $z$ で $f=\log(1+|z|^2)$ とすると $\partial_z\partial_{\bar z}f=(1+|z|^2)^{-2}$ である。$z=0$ では実 Hessian は $2I_2$ となり、唯一の臨界点は指数零である。反対側の座標 $w=1/z$ では $f=-\log|w|^2+\log(1+|w|^2)$ であり、$w=0$ に近づくと発散する。$f\le C$ は $|z|^2\le e^C-1$ の円板となる。逆向きに一つの点の管状近傍を広げると、残りを指数二のハンドル一つで閉じる。定理の下界 $d=1$ を満たすが、個々の例で最小の指数がちょうど $d$ になる必要はない。
:::

:::example[曲面の超平面切断で保証される範囲]
$X=\C P^1\times\C P^1$ を Segre 写像 $([a:b],[c:d])\mapsto[ac:ad:bc:bd]$ で $\C P^3$ に埋める。超平面 $ad-bc=0$ の切断は対角である。例えば両因子を $a,c\ne0$ の座標にすると方程式は $d/c-b/a=0$ であり微分は全射である。残る点にも同様に $b,d\ne0$ の座標を使えるので横断する。$d=\dim_\C X=2$ から定理は成分の同型と基本群の全射を保証する。実際には双方とも単連結だが、$H_2(Y)=\Z$ の生成元は $H_2(X)=\Z\oplus\Z$ で $(1,1)$ に写るだけである。二次の全射を期待するとこの例で失敗する。両射影との合成がそれぞれ次数一なので、像の計算には対角の埋め込みの式だけを使える。
:::

### 補集合のハンドル次数

:::example[複素射影空間のアフィン補集合]
$X=\C P^d$ で $Y=\{z_0=0\}$ とすると補集合は $\C^d$ である。そこに $f=\log(1+\norm z^2)$ を置くと、原点だけが臨界点で指数零である。従って補集合は半径を増やす向きでは $0$ ハンドル一つでできる。逆向きに $Y$ から $X$ を作ると、その臨界点は指数 $2d$ になる。例えば $d=3$ では $\C P^2$ へ実六次のセルを貼る。$Y$ の管状近傍の複雑さを、補集合の臨界点の個数と混同する必要はない。
:::

### 指数上界をアフィン補集合に使う

:::example[境界から外側と内側のどちらに付けるか]
$X\setminus Y$ 上の狭義多重劣調和な Morse 尽くし関数 $f$ を使う。有限な正則劣位集合は $f$ の臨界点を小さい値から通過するとき、実指数 $\lambda\le d$ のハンドルでできる。一方、同じ帯を $Y$ の近傍から見ると、$-f$ の高さを増やしているため指数は $2d-\lambda\ge d$ となる。例えば $d=3$ で $\lambda=1$ の点が一つあれば、補集合を広げる向きで一次の芯となり、$Y$ から $X$ を広げる向きでは五次の芯である。前者は補集合の基本群を変える可能性があるが、後者は相対一次・二次群を作らない。どちらの主張にも同じ実 Hessian の指数を使っている。
:::

:::example[開補集合での高次数の消滅]
超平面切断が横断であり、$f$ が $Y$ の近くに臨界点を持たないようにした場合、十分高い値 $c$ の外側では臨界点のない帯の議論を各有限区間に適用できる。$c$ からの正規化流により外側は $f^{-1}(c)\times[0,\infty)$ となる。各有限の帯は固有性でコンパクトだから時間を延ばせる。従って補集合は $X_c=\{f\le c\}$ に変形収縮する。$X_c$ には指数 $d$ 以下のハンドルしかないので、その CW 型の次元は $d$ 以下である。例えば $\C P^2$ の滑らかな二次曲線は、すべての二次単項式を並べた Veronese 埋め込みでの超平面切断である。従ってその補集合では $H^j=0$ が $j>2$ で従う。二次の群のねじれを求めるには、胞体の境界写像をさらに調べる必要がある。
:::

## Morse ホモロジーの概観

### 臨界点間を結ぶ軌道

計量に対する負勾配の流れで、臨界点 $p$ に過去で収束する点の集合を不安定多様体 $W^u(p)$、未来で収束する点の集合を安定多様体 $W^s(p)$ という。$W^u(p)$ の次元は指数であり、$W^s(p)$ の余次元も指数である。すべての $W^u(p),W^s(q)$ が横断的に交わるとき :term[Morse–Smale 条件]{en="Morse–Smale condition" yomi="もーすすめいるじょうけん"} という。非定数軌道では時間平行移動が自由なので、指数差 $1$ の軌道空間を時間移動で割ると零次元になる。

:::theorem[Morse ホモロジーの定理]{#thm-dtop-morse-homology}
閉多様体の Morse–Smale 対について、指数 $k$ の臨界点を基底とする $\Z$ 加群 $C_k$ を取る。各不安定多様体を向き付け、指数差 $1$ の非パラメータ化下降軌道を誘導符号で数えて、係数を $\partial p$ に入れる。この微分は $\partial^2=0$ を満たし、誘導ホモロジーは特異ホモロジーに同型である。$\F_2$ 上では向きは不要である。
:::

Morse–Smale 対の一般性、流れの軌道空間のコンパクト化と貼り合わせの解析には、安定多様体定理と流れの収束の評価が要る。その証明と特異ホモロジーとの比較は Schwarz の論文を参照する。 [Morse ホモロジーと特異ホモロジーの比較](https://arxiv.org/abs/math/9905152)

各 $W^u(q)$ の向きは、$q$ で $W^s(q)$ の法商に移し、安定円板とその逆流への延長の上で連続に運ぶ。指数差一の軌道上では、横断性により $TW^u(p)$ からこの法商への写像の核が流れ方向の直線になる。そこで下降方向を先に置き、その後に法商の正基底の持ち上げを並べる。結果が $W^u(p)$ の向きと一致すれば符号は $+1$、反転すれば $-1$ である。$W^u(p)$ の向きを変えると対応する鎖基底の符号を変えることになる。

ハンドルを指数順に配置し、不安定円板を芯、安定円板を余芯とする記述では、隣接する指数の間の正則値面で接着球とベルト球を交わらせる。各交点は下降軌道を一つ与え、面上の交叉符号は先の法商の規約と一致する。下のハンドルの余芯の近くでは、接着球から芯の球面商への写像は法座標への射影で表される。従って交点の符号付き個数はその写像度であり、対応する胞体境界係数である。軌道空間から直接示す方法では、指数差 $2$ の一次元軌道空間のコンパクト化の端が二段の折れた軌道になり、境界符号は二軌道の符号の積と共通の次数符号で与えられる。その符号付き境界の総和が零であることが $\partial^2=0$ を与える。

:::example[円の二本の軌道]
円の高さには極大と極小が一つずつある。極大から極小へ半円ずつ二本の下降軌道がある。向き付き一次元芯の端の符号は互いに逆なので境界は零であり、$H_0,H_1$ はともに $\Z$ になる。
:::

:::example[平坦トーラスの積関数]
$f(\theta,\phi)=\cos\theta+2\cos\phi$ では二つの角の流れが独立である。指数差 $1$ の組では一方の角を固定し、他方が円の極大から極小へ移る。二軌道の符号は打ち消し合うため、境界は全次数で零、Betti 数は $(1,2,1)$ になる。
:::

### 指数差一の軌道が有限個になる理由

正則値面 $f^{-1}(c)$ を二臨界値の間に置くと、非定数下降軌道はその面とちょうど一度交わる。指数差一の軌道空間は、面の中で安定多様体と不安定多様体を交わらせた零次元集合として見える。ここで面はコンパクトだが、安定多様体の像が閉であるとは限らない。従って軌道点の列の極限が別の軌道へ分かれないことを確かめる必要がある。

臨界値を分離しても軌道を変えないようにできる。下降場を $V=-\grad f$ とし、各臨界点の近くで定数となる十分小さな台付き関数を $f$ に加えて $\widetilde f$ を作る。切断関数が変化するコンパクトな部分では $d f(V)$ は厳密に負で、零から離れているので、$d\widetilde f(V)<0$ が保たれる。この箇所では $V$ と $\Ker d\widetilde f$ を直交させ、$V$ の長さの二乗を $-d\widetilde f(V)$ とする計量を取れる。臨界点の近くでは元の計量が同じ条件を満たす。$g(V,\cdot)=-d\widetilde f$ は計量に対して線形だから、局所計量を 1 の分割で貼れば新しい関数の負勾配は同じ $V$ になる。

途中の各臨界値の間に正則値を一つ選んで、各軌道の各面での交点を記録する。有限個のコンパクトな面の積で部分列を取れば全交点が収束する。隣の面へ進む時間が有界なら、流れの連続な依存性で極限点同士が同じ軌道に属する。時間が発散する場合、レベル帯から出られない極限軌道の集積点は臨界点に限られる。実際、勾配が非零な点の十分小さい近傍を無限回通ると、流れの速さの上界と勾配の下界により一様の正の高さ差を繰り返し消費するためである。二面の間には臨界点が一つしかないので、一方の極限軌道は未来でその点に、他方は過去でその点に収束する。出発点の直下と到着点の直上では、十分小さい安定・不安定円板から切り出したコンパクトな断面を使って軌道の端を保てる。

従って列が途中で分かれると、少なくとも一つの中間臨界点を通る折れた軌道が出る。Morse–Smale 条件の下では非定数軌道の存在が指数差 $\ge1$ を含意する。区間が二つなら全指数差は $\ge2$ であり、指数差一に反する。従ってこの場合は列の極限も同じ零次元空間に残り、コンパクトかつ離散なので有限である。指数差二では二つの軌道へ折れることが初めて可能になる。その折れた軌道を一次元コンパクト化の端として扱う部分に、貼り合わせの解析が必要である。

### 安定・不安定円板の向きから係数を得る

:::example[円上で二つの極小を結ぶ場合]
$f(\theta)=\cos2\theta$ では極大 $p_0,p_1$ は $\theta=0,\pi$、極小 $q_0,q_1$ は $\theta=\pi/2,3\pi/2$ である。各極大の不安定円板を $\theta$ の増加方向に向き付ける。$p_0$ の右端は $q_0$、左端は $q_1$ へ向かうため $\partial p_0=q_0-q_1$ である。$p_1$ では右端が $q_1$、左端が $q_0$ なので $\partial p_1=q_1-q_0$ である。従って境界行列は $\begin{pmatrix}1&-1\\-1&1\end{pmatrix}$ であり、核は $p_0+p_1$ の張る $\Z$、余核は $q_0,q_1$ を同一視した $\Z$ となる。二臨界点だけの高さでは境界行列が零だったが、臨界点を増やしても得られるホモロジーは同じである。
:::

:::example[指数差二における二通りの折れ]
$T^2$ で二つの円周高さの和を用い、各因子で極大から極小へ至る半円を一本ずつ固定する。極大対から極小対に向かう積の軌道は、二つの半円の流れを相対時間差 $a\in\R$ だけずらして述べられる。全体の時間平行移動を除くと $a$ だけが残る。$a\to+\infty$ では第一因子が先に極小となる折れに近づき、$a\to-\infty$ では第二因子が先になる折れに近づく。付け加えた二端は区間の境界として符号が逆である。各半円の選び方ごとに同じ区間が現れるので、折れを二段の境界として足すと符号付き和は零になる。これは指数差二で端が二段の軌道に対応するモデルである。
:::

:::example[軌道の形を変えずに時刻だけを変える]
計量 $g$ を正の関数 $a(p)$ 倍した計量 $g'=ag$ に替えると $\grad_{g'} f=a^{-1}\grad_g f$ となる。閉多様体で $a$ は正の下界と有限の上界を持つため、積分曲線の時間を正の速度で取り直しても両方の無限時間端は保たれる。従って非パラメータ化軌道と安定・不安定多様体は同じであり、横断性も変わらない。向きを固定すれば軌道符号も保たれる。例えば角速度 $\sin\theta$ の円周の場を $(2+\cos\theta)^{-1}\sin\theta$ に替えると、極大から極小までの半円の速度は変わるが、境界係数を作る二つの半円は同じである。
:::

:::example[安定・不安定多様体を局所線形式で見る]
Morse 座標で $f=c-\norm u^2+\norm v^2$、計量を座標の Euclid 計量とする。負勾配の方程式は $u'=2u,v'=-2v$ であり、解は $u(t)=e^{2t}u(0),v(t)=e^{-2t}v(0)$ である。未来に臨界点へ収束する局所点は $u=0$、過去に収束する局所点は $v=0$ である。従って不安定円板の次元は $\dim u$、安定円板の余次元も $\dim u$ になる。この計算で得られるのは座標近くにとどまる解であり、全体の安定多様体は逆向きの流れでこの円板を運んで得る。座標の外で円板が他の臨界点の不安定多様体と交わるかどうかは別の幾何的条件である。
:::

### 積の Morse 境界の符号を確認する

:::example[三つの円の積で消える境界]
$T^3$ 上で $f(\theta,\phi,\psi)=\cos\theta+2\cos\phi+4\cos\psi$ とし、標準積計量を使う。各角が $0$ にある因子を選んだ集合を $A$ とすると、臨界点の指数は $|A|$ である。任意の二臨界点の不安定多様体と安定多様体は、各因子で極点または開弧の積になる。交わるところでは、各一次元因子で少なくとも一方の接方向が全空間を張るため、全体で横断に交わる。

指数差一の下降軌道では、$A$ から一要素だけ取り除く。この角に二本の半円の軌道があり、残りの角は固定される。例えば指数三の極大の不安定接方向を $(\partial_\theta,\partial_\phi,\partial_\psi)$ の順に向き付ける。$\phi$ の角だけが動く二軌道では、その因子の左端と右端の符号が逆であり、他の二方向を同じ順に並べる際の符号は両軌道に共通である。従って係数は零になる。この理由はどの要素を除く場合も同じである。全 Morse 鎖群の階数は $(1,3,3,1)$、全微分は零であり、積のホモロジーを回復する。
:::

:::example[円周の高さを五つの谷に増やす]
$f(\theta)=\cos5\theta$ を考える。極大を $p_j$、そこから正方向にある極小を $q_j$ とする。左側の極小は $q_{j-1}$ なので、増加方向に向き付けた不安定弧の境界は $\partial p_j=q_j-q_{j-1}$ である。添字は $5$ を法として扱う。核に属する $\sum a_jp_j$ では $q_j$ の係数は $a_j-a_{j+1}$ であり、この差が全て零だから係数は全て同じである。一方、余核ではすべての $q_j$ が同じ類となり、その和を数える写像が $\Z$ を与える。従って整数係数の $H_0$ と $H_1$ は各 $\Z$ であり、非零の境界行列があっても零ホモロジーになるという意味ではない。階数は $5-1=4$ であり、Morse 多項式の差 $4+4t$ とも整合する。
:::

Reeb の定理の仮定で $n=3$ の Morse 指数を求めよ。

:::solution
二点は極小と極大である。正定値 Hessian の負固有値は零個、負定値 Hessian では三個であるから、指数は $0,3$ である。

::::exercise{level=basic #exr-dtop-morse-applications-2}
$S^2$ の大円で長さ $7\pi/2$ の測地線の指数と退化次数を求めよ。

:::solution
内部の共役点は $\pi,2\pi,3\pi$ で、各重複度は $1$ である。終点は共役ではないので指数 $3$、退化次数 $0$ である。

::::exercise{level=basic #exr-dtop-morse-applications-3}
$\Omega T^3$ の成分をどう分類するか。

:::solution
ループを零から $\R^3$ に持ち上げたときの終点 $\Z^3$ で分類する。同じ終点の道は線形補間により両端固定でホモトピックであり、違う終点間の補間は持ち上げた終点の連続性に反する。
:::

::::exercise{level=basic #exr-dtop-morse-applications-4}
安定 $\pi_9(U)$ と $\pi_{10}(U)$ を求めよ。

:::solution
Bott 周期性で次数を偶奇まで下げる。$\pi_9(U)=\pi_1(U)=\Z$、$\pi_{10}(U)=\pi_0(U)=0$ である。
:::

::::exercise{level=advanced #exr-dtop-morse-applications-5}
射影多様体の複素次元が $5$ のとき、超平面切断のホモロジー同型が保証される最大次数を求めよ。

:::solution
$i<5-1$ が同型範囲であるから最大整数は $3$ である。次数 $4$ は全射が保証範囲である。
:::
::::

::::exercise{level=advanced #exr-dtop-morse-applications-6}
区分 Jacobi 場と節点で零の場との指数形式の交差項が消えることを示せ。

:::solution
各小区間で $J$ を Jacobi 場、$V$ を節点零の場とし、$\int\inner{\nabla_tJ}{\nabla_tV}$ を $J$ 側へ部分積分する。端点項は $V=0$ で零であり、内部項は $\nabla_t^2J+R(J,\dot\gamma)\dot\gamma=0$ だから零である。全区間で足しても零である。
:::
::::

::::exercise{level=advanced #exr-dtop-morse-applications-7}
$n\ge2$ とする。$S^n$ 上で長さ $2\pi$ の大円測地線の指数と退化次数を求めよ。

:::solution
内部共役点は $\pi$ の一つだけで、終端 $2\pi$ も共役である。どちらの重複度も $n-1$ なので指数と退化次数はいずれも $n-1$ である。
:::
::::

::::exercise{level=advanced #exr-dtop-morse-applications-8}
指数 $k$ と $\ell$ の臨界点間の横断な非定数下降軌道の空間の次元を求めよ。

:::solution
出発点の不安定多様体の次元は $k$、到着点の安定多様体の余次元は $\ell$ である。横断交叉は次元 $k-\ell$ である。各非定数軌道は流れの一自由度を持ち、正則値面で各軌道と一度交わる局所切断を取れるので、時間平行移動で割った次元は $k-\ell-1$ である。
:::

:::explanation
負部分空間の次元が $4$ を超えると $W\cap JW$ に非零元があり、$B(v,v)+B(Jv,Jv)>0$ に反する。
:::

指数差 $1$ の Morse–Smale 軌道について正しいものを選べ。

- [x] 時間平行移動で割った軌道を境界係数に数える。
- [ ] 軌道上の各点を独立に数える。
- [x] mod $2$ 係数なら向きを選ばずに数えられる。

:::explanation

:::
