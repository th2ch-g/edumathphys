## この章の目標

- 局所指数の座標不変性を証明する。
- 退化零点と非退化零点の指数を計算する。
- 指数の保存から Poincaré–Hopf の定理を導く。
- Gauss 写像と非消失場の存在条件を説明する。

## ベクトル場の孤立零点の指数

ベクトル場の零点を小球で囲むと、球面上でベクトルの方向だけを取り出せる。この方向写像が球面を何回覆うかが、零点を摂動しても追跡できる整数になる。

:::definition[孤立零点の指数]{#def-dtop-index}
$n\ge2$ とし、滑らかな多様体上のベクトル場 $X$ の零点 $p$ を孤立とする。$p$ を中心とする座標球 $D$ を取り、座標成分 $F$ が $p$ 以外で零でないようにする。外向き法線を先に置いて $\partial D$ を向き付け、$\partial D\to S^{n-1}$、$x\mapsto F(x)/\norm{F(x)}$ の写像度を :term[指数]{en="index of a zero" yomi="しすう"} $\operatorname{ind}_p X$ とする。一次元では $\operatorname{ind}_p X=(\sgn F(a_+)-\sgn F(a_-))/2$ とする。ここで $a_-<p<a_+$ は小区間の端点である。
:::

:::proof[定義の独立性]
同心球の半径変更は零点を含まない環状領域での正規化によりホモトピーである。二つの座標の変換を $\phi$ とし、$\phi(0)=0$ とする。新座標の成分は $D\phi(x)F(x)$ になる。小球上で $D\phi(tx)$ を $t=1$ から $0$ に縮めると可逆行列のホモトピーだから方向は消えない。基点を移す $\phi$ の球面に対する向きの符号は $\sgn\det D\phi(0)$ である。同時にベクトル成分に掛かる $D\phi(0)$ も同じ符号を寄与する。実際、向き付けられた小球とその座標像の境界の向きは微分同相で移り、より小さい球との間の領域には零点がないので、二つの境界上の写像度は境界の向きを合わせれば一致する。この最後の等式は領域から球面への写像の共通正則値の逆像を取り、向き付き一次元多様体の端を数えて得られる。符号が二つ掛かるので指数は同じである。一次元でも座標を反転すると両端と成分の符号が同時に反転する。
:::

:::proposition[非退化零点]{#prop-dtop-index-linear}
$F(0)=0$ かつ $A=DF(0)$ が可逆なら $\operatorname{ind}_0 X=\sgn\det A$ である。
:::

:::proof
$\norm{Ax}\ge c\norm{x}$ となる $c>0$ がある。$F(x)=Ax+o(\norm x)$ なので、小さい球で $\norm{F(x)-Ax}<c\norm x$ である。線形補間は球上で非零であり、正規化すると $Ax/\norm{Ax}$ へのホモトピーとなる。極分解 $A=QP$ の正定値因子 $P$ を恒等へ線形補間すると、向きは直交因子 $Q$ の行列式で決まる。一次元では左右の符号差を直接計算しても同じ結果を得る。
:::

:::example[鞍点と退化零点]
$X=(2x,-3y)$ の指数は $-1$ である。一方、$X=(x^2,y)$ は原点に孤立零点を持つが、正規化の像は第 1 成分が非負で $(-1,0)$ を避けるから指数は $0$ である。
:::

:::example[任意の整数を作る平面場]
複素座標で $X(z)=z^k$ とすれば、$k\ge1$ のとき半径 $\rho$ の円で方向は $\exp(ik\theta)$ なので指数は $k$ である。$X(z)=\overline z^k$ なら指数は $-k$ である。例えば $X=(x^2-y^2,2xy)$ の指数は $2$ である。
:::

### 退化零点を正則値で計算する

小球の閉包で成分関数 $F$ が定義され、境界で $\norm F\ge\delta>0$ とする。$\norm y<\delta$ の正則値 $y$ を選べば、$F-y$ と $F$ の間で境界の方向は消えない。従って $F-y$ の零点は全て非退化であり、その符号和を数えれば $F$ の境界次数が得られる。局所公式を使うには、球の外にある他の逆像を数えないよう、最初に球を指定しておく。

:::example[二次の退化零点をほどく]
$F(x,y)=(x^2-y^2,2xy)$ から $(a,0)$ を引く。$a>0$ なら $2xy=0$ と $x^2-y^2=a$ から二零点 $(\pm\sqrt a,0)$ が出る。Jacobian の行列式は $4(x^2+y^2)$ で、どちらも正なので和は $2$ である。十分小さい $a$ を選べば、半径 $\rho$ の境界で $|F|=\rho^2>a$ であり、この計算が元の退化零点の指数を与える。
:::

:::example[二方向の退化と符号の相殺]
$F(x,y)=(x^2,y^2)$ から $(a,b)$ を引き、$a,b>0$ とする。四つの零点 $(\pm\sqrt a,\pm\sqrt b)$ で行列式は $4xy$ であり、二点ずつ符号が異なる。$\min_{\partial D}|F|$ は正なので、$a,b$ を十分小さくすれば境界上で非零のまま摂動できる。従って全指数は零である。
:::

### 原点における最初の非零項

微分が特異なときでも、最初に現れる同次項が方向を全周で決める場合がある。これは、零点の周りで場を拡大したときに同じ方向写像が残るという考えである。

:::proposition[同次近似による局所指数]{#prop-dtop-index-leading-term}
座標原点で $X(x)=P(x)+R(x)$ とする。$P\colon\R^n\to\R^n$ が次数 $k\ge1$ の同次多項式写像で単位球面上に零を持たず、$R(x)=o(\norm x^k)$ なら、原点は孤立零点であり、その指数は $P/\norm P$ の球面上での度である。
:::

:::proof
単位球面上で $\norm P$ の最小値を $m>0$ とする。$x=ru$、$\norm u=1$ であれば同次性から $\norm{P(x)}\ge mr^k$ である。$r$ を十分小さくすると $R(x)$ は全方向で $mr^k/2$ 未満になるので、$P(x)+sR(x)$ は $0\le s\le1$ で非零である。従って原点以外の十分小さい点では $X\ne0$ である。半径 $r$ の球面でこの族を長さで割れば、$X$ と $P$ の方向写像のホモトピーを得る。$r^k$ は正だから $P$ の方向写像は単位球面上のものと一致する。
:::

:::example[複素共役を含む同次場]
$\C\simeq\R^2$ 上で $X(z)=z^4\conj z^2+z^7$ とする。先頭項は $z=re^{i\theta}$ において $r^6e^{2i\theta}$ となる。残りの大きさは $r^7$ なので $r<1/2$ では先頭項の半分未満である。従って原点は孤立零点で指数は $2$ である。$z^2\conj z^4$ へ置き換えると先頭項の角は $-2\theta$ となるため指数は $-2$ になる。両方とも先頭項の多項式次数は六である。一方の次数だけから指数を決めることはできず、球面上で角がどう動くかを計算する必要がある。
:::

:::example[先頭項に零方向がある場合]
$X_+(x,y)=(x^2,y^3)$ と $X_-(x,y)=(x^3,y^2)$ を比べる。どちらも先頭の二次部分は球面の二方向で零になり、同次近似の命題は適用できない。$X_+$ の方向写像は第一成分が非負、$X_-$ の方向写像は第二成分が非負であるため、いずれも像が一つの半円に入って指数は零である。さらに $Y(x,y)=(x^3,y)$ と $Z(x,y)=(-x^3,y)$ は先頭の一次項が同じだが、$x^3$ と $-x^3$ の符号差により指数は $+1,-1$ である。例えば $Y$ は $(1-s)x^3+sx$ を第一成分に取って恒等場へ非零方向のまま変形できる。$Z$ では同じ式に負号を掛けると鏡映場になる。
:::

### 一変数ごとに分けられる零点

:::proposition[座標ごとの場の指数]{#prop-dtop-index-coordinate-product}
$X(x_1,\ldots,x_n)=(a_1x_1^{k_1},\ldots,a_nx_n^{k_n})$、$a_i\ne0$、$k_i\ge1$ とする。すべての $k_i$ が奇数なら原点の指数は $\prod_i\sgn(a_i)$ であり、一つでも偶数なら指数は零である。
:::

:::proof
$k_i$ が偶数なら第 $i$ 座標の符号は $\sgn(a_i)$ 側に限られ、方向写像は反対の軸の点を避けるので度は零である。すべて奇数なら $x_i^{k_i}$ と $x_i$ は同じ符号で零点も同じである。各成分を $a_i((1-t)x_i^{k_i}+t x_i)$ と補間しても、全成分が消えるのは原点だけである。従って原点での指数は対角線形場の指数に等しく、行列式の符号が主張を与える。
:::

:::example[三変数での退化]
$X(x,y,z)=(-2x^3,3y^5,z)$ では三成分のべきが奇数なので指数は $-1$ となる。正則値を使っても同じ値が得られる。$(a,b,c)$ を小さく、$ab\ne0$ とすると、各変数の方程式にはただ一つの実根があり、Jacobian は $\diag(-6x^2,15y^4,1)$ だから符号は負である。第三成分を $z^2$ に置き換えると $c>0$ で $z=\pm\sqrt c$ による二根が現れ、第三の微分が反対符号となって加算が零になる。$c<0$ の逆像が空であることとも一致する。
:::

:::example[異なる尺度での境界の選択]
$X(x,y)=(x^5,y)$ は細長い長方形 $[-a,a]\times[-b,b]$ の境界でも非零である。値の摂動が $(u,v)$ で $|u|<a^5$、$|v|<b$ なら同じ境界を使える。その内部の正則値 $(u,v)$、$u\ne0$ の逆像は $(u^{1/5},v)$ の一つで、行列式は $5u^{4/5}>0$ である。従って局所指数は $1$ である。丸い球を使う定義でも、双方に含まれる小球と外境界の間に零点がないため同じ度になる。成分ごとに別の縮尺を使うと、摂動が境界に達しない条件を直接判定できる。
:::

### 座標の回転と場だけの回転

:::example[座標を反転した鞍点]
原点付近の座標で $X=(x,-y)$ とする。新座標 $(u,v)=(-x,y)$ では成分も同じ線形変換を受けるので、$X$ は $(u,-v)$ になる。従って行列式は依然 $-1$ である。座標を固定したまま場だけを $(-X_1,X_2)$ に置き換えるなら $(-x,-y)$ となり、行列式は $+1$ である。座標変換では定義域と成分空間を同時に変更するが、場を別の場に替える操作では成分空間だけを変更する。この違いが指数の符号に残る。
:::

:::example[複素線形場の回転角]
$J(x,y)=(-y,x)$ とし、$X_\alpha=(\cos\alpha)I+(\sin\alpha)J$ を線形場として用いる。行列式は $\cos^2\alpha+\sin^2\alpha=1$ である。したがって角 $\alpha$ を $0$ から $\pi/2$ まで動かすと、外向き放射場を円周に接する回転場へ変形でき、指数は常に $1$ となる。逆向きの放射場まで角を $\pi$ にしても同じである。平面では内向きと外向きの線形場が同じ指数を持つことがこの経路からも分かる。
:::

:::example[二つの偶次数成分を持つ退化場]
三次元の接座標で $X(x_1,x_2,x_3)=\bigl(x_{1}^{2},- 2 x_{2}^{3},3 x_{3}^{4}\bigr)$ とする。階数の落ちた零点の指数を、横断な小さな値への摂動で計算する。

**摂動値を決める。** 各方程式の次数に合わせ、$s>0$ を小さくして次の値を取る。

$$
y_s=\bigl(s^{2},2 s^{3},3 s^{4}\bigr)
$$

各根が $s$ に比例するので、半径固定の局所球を使って全ての根を調べられる。

**逆像の枝を数える。** 各成分の実根の候補を左から順に書く。全逆像はこの三集合の直積である。

$$
\{- s,s\}\quad\times\quad\{- s\}\quad\times\quad\{- s,s\}
$$

各存在する方向では根がすべて零でない。元の零点以外で場が零になることはないため、値を十分小さくするとこれらの根は選んだ球の内側に入る。

**局所符号を合計する。** Jacobian は対角である。逆像の各点で行列式の符号を取り、境界の方向写像の次数へ戻す。

$$
\det DX=- 144 x_{1} x_{2}^{2} x_{3}^{3}, \qquad \operatorname{ind}_0X=0
$$

現れた符号列は $\bigl(-1,1,1,-1\bigr)$ である。
:::

:::example[三成分で向きが反転する退化場]
三次元の接座標で $X(x_1,x_2,x_3)=\bigl(- 2 x_{1}^{3},- 3 x_{2},- x_{3}^{5}\bigr)$ とする。階数の落ちた零点の指数を、横断な小さな値への摂動で計算する。

**摂動値を決める。** 各方程式の次数に合わせ、$s>0$ を小さくして次の値を取る。

$$
y_s=\bigl(- 2 s^{3},3 s,- s^{5}\bigr)
$$

各根が $s$ に比例するので、半径固定の局所球を使って全ての根を調べられる。

**逆像の枝を数える。** 各成分の実根の候補を左から順に書く。全逆像はこの三集合の直積である。

$$
\{s\}\quad\times\quad\{- s\}\quad\times\quad\{s\}
$$

各存在する方向では根がすべて零でない。元の零点以外で場が零になることはないため、値を十分小さくするとこれらの根は選んだ球の内側に入る。

**局所符号を合計する。** Jacobian は対角である。逆像の各点で行列式の符号を取り、境界の方向写像の次数へ戻す。

$$
\det DX=- 90 x_{1}^{2} x_{3}^{4}, \qquad \operatorname{ind}_0X=-1
$$

現れた符号列は $\bigl(-1\bigr)$ である。
:::

:::example[空の正則ファイバーで指数を求める]
三次元の接座標で $X(x_1,x_2,x_3)=\bigl(2 x_{1},- x_{2}^{2},4 x_{3}^{3}\bigr)$ とする。階数の落ちた零点の指数を、横断な小さな値への摂動で計算する。

**摂動値を決める。** 各方程式の次数に合わせ、$s>0$ を小さくして次の値を取る。

$$
y_s=\bigl(2 s,s^{2},4 s^{3}\bigr)
$$

各根が $s$ に比例するので、半径固定の局所球を使って全ての根を調べられる。

**逆像の枝を数える。** 各成分の実根の候補を左から順に書く。全逆像はこの三集合の直積である。

$$
\{s\}\quad\times\quad\varnothing\quad\times\quad\{s\}
$$

偶数乗の成分で値と係数の符号が反対である。従って逆像全体が空であり、この値は空逆像を持つ正則値となる。

**局所符号を合計する。** Jacobian は対角である。逆像の各点で行列式の符号を取り、境界の方向写像の次数へ戻す。

$$
\det DX=- 48 x_{2} x_{3}^{2}, \qquad \operatorname{ind}_0X=0
$$

空和を零と数える。
:::

:::example[一対の符号が消える三成分の場]
三次元の接座標で $X(x_1,x_2,x_3)=\bigl(x_{1}^{3},2 x_{2}^{2},- x_{3}\bigr)$ とする。階数の落ちた零点の指数を、横断な小さな値への摂動で計算する。

**摂動値を決める。** 各方程式の次数に合わせ、$s>0$ を小さくして次の値を取る。

$$
y_s=\bigl(s^{3},2 s^{2},s\bigr)
$$

各根が $s$ に比例するので、半径固定の局所球を使って全ての根を調べられる。

**逆像の枝を数える。** 各成分の実根の候補を左から順に書く。全逆像はこの三集合の直積である。

$$
\{s\}\quad\times\quad\{- s,s\}\quad\times\quad\{- s\}
$$

各存在する方向では根がすべて零でない。元の零点以外で場が零になることはないため、値を十分小さくするとこれらの根は選んだ球の内側に入る。

**局所符号を合計する。** Jacobian は対角である。逆像の各点で行列式の符号を取り、境界の方向写像の次数へ戻す。

$$
\det DX=- 12 x_{1}^{2} x_{2}, \qquad \operatorname{ind}_0X=0
$$

現れた符号列は $\bigl(1,-1\bigr)$ である。
:::

### 接ベクトル場の指数と写像の局所次数

同じ座標表示であっても、接ベクトル場と任意の写像では、座標を替えたときに指数の符号が同じように変わるとは限らない。一般の写像 $F\colon M^n\to N^n$ の局所次数では、定義域の向きを反転すると符号が反転し、値域の向きだけを反転しても反転する。一方、ベクトル場を $T_pM$ の成分で表示する場合には、定義域の座標を変えると成分も同じ変換を受ける。そこで向きの付かない多様体でも整数の指数を定められる。

:::example[非線形の座標変更で二つの反転が相殺する]
原点で $X(x,y)=(x^3,-y)$ とする。指数は奇数べきの積の法則により $-1$ である。座標を $(u,v)=(-x,y+x^2)$ に変えると、$du(X)=-x^3=u^3$、$dv(X)=-y+2x^4=-v+u^2+2u^4$ である。従って新座標表示は
$$
\widetilde X(u,v)=(u^3,-v+u^2+2u^4).
$$
第二成分の $u$ の項を零へ線形に縮めても、第一成分が零になるのは $u=0$ のときだけであり、その条件下で第二成分は $-v$ のままである。従って方向写像は同じ指数 $-1$ を持つ。第一成分だけに座標の負号を掛けて値域の変換を省くと、この結果を再現できない。
:::

:::example[楕円形の境界での巻き数]
$X(x,y)=(x^2-y^2,2xy)$ を円周ではなく楕円 $x=a\cos\theta$、$y=b\sin\theta$、$a,b>0$ へ制限する。この写像は複素二乗であるから、まず $z=a\cos\theta+ib\sin\theta$ の原点の周りの巻き数を求めればよい。$a,b$ を $1$ に連続に動かしても $z$ は零にならず、巻き数は一である。二乗は位相角の変化を二倍するので、場の方向の巻き数は二である。中心を囲む境界で非消失が保たれる限り、円板より扱いやすい境界を使っても指数は同じである。
:::

:::example[半径を大きくすると指数が変わる]
複素平面上で $X(z)=z^2-z^3=z^2(1-z)$ とする。$|z|=r<1$ では $1-z$ は右半平面内なので巻き数零であり、方向写像の度は二である。$r>1$ では $1-z$ を $t-z$、$0\le t\le1$ で $-z$ へ変形しても非零なので、この因子の巻き数は一である。従って境界全体の度は三になる。半径一では $z=1$ の零点を通過し、方向写像が定義できなくなる。$z=1$ の微分は $2-3=-1$ の複素線形写像であり、実行列式は正だから指数は一である。二つの外境界の度の差が、この零点の指数に一致する。
:::

## Poincaré–Hopf の定理

### 零点を動かしたときの保存

:::lemma[局所指数の加法性]{#lem-dtop-index-add}
座標球 $D$ の境界で非零な場が内部に有限個の孤立零点を持つとする。外境界上の方向写像の写像度は、各零点の指数の和に等しい。
:::

:::proof
零点を互いに素な小閉球で除いた領域で方向写像を考える。外境界と各内境界に対し正則な値を選び、さらに内部でも正則な値を Sard の定理で選ぶ。逆像はコンパクトな向き付き一次元多様体である。領域としての内境界は各小球としての向きと逆であるから、境界数の総和が零であることが加法性である。一次元では小区間の両端の符号差を足すと、非零区間の両端の符号が等しいため中間項が消える。
:::

:::lemma[全指数の不変性]{#lem-dtop-index-invariant}
閉多様体上の、孤立零点しか持たない二つの滑らかな場の全指数は等しい。
:::

:::proof
最初に各零点を小球で囲み、残りのコンパクト集合上でのノルムの正の下界を使って、十分小さな摂動の零点を球内に制限する。束を局所自明化し、局所フレームに切断関数を掛けた有限組の大域切断を選べば、各点でその値がファイバーを張る。これらの小さな定数係数線形結合を場に加えると、全パラメータ写像は零切断に横断的である。:ref[thm-dtop-parametric] で非退化零点だけを持つ摂動が得られる。球の境界では線形補間が非零なので :ref[lem-dtop-index-add] により全指数は変わらない。

そこで両端を非退化として、$[0,1]\times M$ 上で場を線形補間し端では時間を一定にする。中間を零切断に横断化する。ここでは定義域の点を動かさず、上で用いたフレーム切断を時空間の切断関数で局所化してファイバー方向だけを動かせば、:ref[prop-dtop-relative-transverse] と同じパラメータ論法が使える。零集合はコンパクトな一次元多様体となる。$M$ が向き付けられなくても、零集合には向きが入る。実際、法条件の値域は $TM$ である。時空間の方向と値域の方向を同時に $TM$ の局所向きから決めれば、その局所向きの反転は二か所で起きるので、残る零集合の向きは変わらない。端での時間方向の符号は $\sgn\det DX$ である。境界の符号和が零なので両端の全指数は一致する。
:::

:::theorem[Poincaré–Hopf の定理]{#thm-dtop-poincare-hopf}
閉滑らかな多様体 $M$ 上の孤立零点だけを持つ滑らかなベクトル場 $X$ に対し、
$$
\sum_{X(p)=0}\operatorname{ind}_p X=\chi(M)
$$
である。正の次元では向き付けを仮定しない。
:::

:::proof
$n>0$ とする。:ref[lem-dtop-index-invariant] の証明で用いた横断摂動により、各小球における指数和を保ったまま零点をすべて非退化にできる。$M$ が向き付きなら、以下の :ref[prop-dtop-flow-lefschetz-index] を負の小時間に適用する。流れは恒等写像にホモトピックなので Lefschetz 数は $\chi(M)$ であり、各固定点の指数は元の場の指数に等しい。連結成分が複数ある場合は、成分ごとの式を足す。

向き付けられない成分では、向きの二重被覆 $\widetilde M\to M$ に場を持ち上げる。各零点には二つの持ち上げがあり、局所座標は被覆で移せるので指数はどちらも元と同じである。Euler 標数も二倍になることを確かめるには、$M$ に Riemann 計量を入れ、十分小さい強凸測地球で有限被覆する。各球内の二点を結ぶ一意な最短測地線が球に留まるため、非空な有限交叉も一点に収縮する。コンパクト性によりこのような球を有限個選べる。交叉が可縮であるため、その二重被覆はそれぞれ二つのコピーに分かれる。Mayer–Vietoris 完全列の交代次元和を有限被覆に帰納的に適用すると、Euler 標数は各有限交叉の Euler 標数の交代和となる。従って被覆側の標数は二倍である。向き付きの式を $\widetilde M$ に適用して二で割れば $M$ での式を得る。零次元では各点に指数 $1$ を割り当てると式は点数の等式になる。
:::

勾配場を使う別の証明は [Morse 関数と Morse 理論](/math/differential-topology/morse-functions/) のハンドル接着と結び付く。

:::example[零点対の誕生]
$X_s(x,y)=(x^2-s,y)$ では $s>0$ の二点 $(\pm\sqrt s,0)$ における行列式は $\pm2\sqrt s$ であり、指数和は零である。$s<0$ では零点がなく和は同じである。
:::

:::example[球面の高さ]
$S^2$ 上の高さの勾配は北極と南極で消える。北極では負定値、南極では正定値であり、二次元なので両行列式は正である。全指数は $2$ となる。
:::

### 時空間の零曲線の向きを決める

局所座標 $(t,x_1,\ldots,x_n)$ で場の成分を $F(t,x)$ とする。$F^{-1}(0)$ が横断な零曲線なら、$dF$ が全射である。$dF$ で標準基底へ写る $n$ 本のベクトル $u_i$ を選び、零曲線のベクトル $\tau$ の後に並べる。$(\tau,u_1,\ldots,u_n)$ が時空間の向きになるよう $\tau$ の向きを決める。$u_i$ に零曲線の成分を足しても行列式は変化しない。座標を反転すると、時空間と成分の向きが同時に反転するので $\tau$ の向きには影響しない。

端の近くで $F(t,x)$ が $t$ に依らず、$D_xF$ が可逆の場合を考える。このとき $u_i=(0,(D_xF)^{-1}e_i)$ と選べるので、$\tau$ が時刻増加方向を向くのは $\det D_xF>0$ の場合である。時刻 $1$ では増加方向が外向き、時刻 $0$ では減少方向が外向きである。よって零曲線の境界符号は終端で $\sgn\det D_xF$、始端でその負になる。これが :ref[lem-dtop-index-invariant] における端点と行列式の一致である。

:::example[二つの端点が同じ時間面に現れる]
$F(t,x,y)=(x^2-t,y)$ とすれば、零曲線は $(t,x,y)=(x^2,x,0)$ である。$-1\le t\le1$ の範囲では $-1\le x\le1$ であり、両端とも $t=1$ の面にある。時刻射影の微分は $2x$ だから、片方の端では曲線を進むと時間が増え、もう片方では減る。実際、端点での $D_{(x,y)}F$ は $\diag(2x,1)$ となり、符号は $-1$ と $+1$ で打ち消し合う。途中の $x=0$ では時刻射影だけが臨界で、$F$ の微分には $-dt$ があるため零曲線は滑らかに続く。
:::

:::example[一本の零曲線が両端をつなぐ]
$F(t,x,y)=(x-t,y)$ では零曲線は $(t,t,0)$ であり、両方の時刻端を結ぶ。$D_{(x,y)}F=I$ なので両時刻で指数は $+1$ である。曲線の向きが時刻増加方向であるため、境界符号は $(t,x,y)=(0,0,0)$ で $-1$、$(1,1,0)$ で $+1$ となる。各時刻での零点の指数は同じだが、全曲線の符号付き境界は零である。端の符号と各場の指数は役割が異なる。
:::

### 向き付けを仮定する一般の束との違い

任意の階数 $n$ の実束 $E\to M^n$ で、零点が非退化なら $D_ps\colon T_pM\to E_p$ は同型である。しかし $\det D_ps$ の符号を比較するには $T_pM$ と $E_p$ の向きの対応が必要になる。これが各点の間で連続に選ばれていることを、行列式直線 $\Hom(\det TM,\det E)$ の向き付けと言い換えられる。接束の場合は $E=TM$ なので、恒等写像がこの直線を大域的に自明化する。

:::example[円周上の Möbius 束の零点を数える]
基底を $\theta\bmod2\pi$ とし、ファイバーの座標を一周で $v\mapsto-v$ と同一視する。係数 $h(\theta)=\cos(\theta/2)$ は $h(\theta+2\pi)=-h(\theta)$ を満たし、滑らかな切断になる。零点は $\theta=\pi$ の一つで、選んだ区間では微分は $-1/2$ である。基底の向きは固定したままファイバーの枠を全区間で逆に選べば、微分の符号は $+1$ に変わる。従ってこの一点に符号を与えて接束と同じ整数の法則を得ることはできない。一方、非退化零点の mod $2$ 個数は枠の符号と無関係である。この例では一本の横断切断の零点個数は奇数である。
:::

### 固定点と対角によるもう一つの導出

:::proposition[小時間の流れで得る指数和]{#prop-dtop-flow-lefschetz-index}
閉向き付き多様体 $M$ 上の滑らかな場 $X$ が非退化零点だけを持つとする。十分小さい $t\ne0$ に対し、流れ $\Phi_t$ の固定点はちょうど $X$ の零点である。負の時間の固定点指数は場の指数に等しく、正の時間では $(-1)^{\dim M}$ 倍である。
:::

:::proof
零点の近くで、座標の変位 $\Phi_t(x)-x$ を $t$ で割る。これは $\int_0^1 X(\Phi_{st}(x))\,ds$ であり、$t=0$ まで滑らかに延長して $X(x)$ となる。零点で $D X$ は可逆なので、陰関数定理で各零点の近くに固定点は一つに限られる。元の零点は全時刻の固定点だから、新しい枝は出ない。残りのコンパクト領域では零点がなく、有限枚の座標で変位を $t$ で割ったものは $X$ に一様に近づく。よって小時間に固定点はない。

零点 $p$ では変分方程式により $d\Phi_t(p)=\exp(t D_pX)$ である。$I-d\Phi_t(p)=-t(D_pX+O(|t|))$ なので、その行列式の符号は十分小さい $t\ne0$ に対して $\sgn(-t)^n\sgn\det D_pX$ である。:ref[thm-dtop-lefschetz] の局所符号と :ref[prop-dtop-index-linear] を比べれば、時間の向きによる二つの式が従う。
:::

:::example[円周上の小時間の固定点]
$S^1$ で $X=\sin\theta\,\partial_\theta$ とする。$\theta=0$ で微分 $1$、$\theta=\pi$ で $-1$ なので、場の指数は順に $+1,-1$ である。流れの微分は順に $e^t,e^{-t}$ であり、$I-d\Phi_t$ の符号は順に負、正となる。二つの和が零であることは $S^1$ の Euler 標数と一致する。一次元なので両方の局所符号が個別に反転する。
:::

## Euler 標数との一致

### 曲面と境界

向き付き閉曲面で種数 $g$ の場合、$0$ 次細胞一つ、$1$ 次細胞 $2g$ 個、$2$ 次細胞一つの多角形表示により $\chi=2-2g$ である。従ってすべての零点が非退化なら、正の零点数から負の零点数を引くと $2-2g$ が得られる。閉奇数次元の向き付き多様体では Poincaré 双対性で $b_i=b_{n-i}$ だから各対が打ち消し合う。向き付けられない場合は向きの二重被覆を取り、胞体を持ち上げて $\chi(\widetilde M)=2\chi(M)$ とすれば同じ結論である。

:::proposition[境界で外向きな場の公式]{#prop-dtop-index-outward}
コンパクトな境界付き多様体 $M$ 上の場 $X$ が境界で厳密に外向きで、内部に孤立零点だけを持つなら、全指数は $\chi(M)$ である。
:::

:::proof
連結成分ごとに示せばよい。境界を持たない成分には :ref[thm-dtop-poincare-hopf] を使えるので、以下では $M$ は連結で境界は非空とする。零点を含む内部の小球で横断摂動すれば、境界と各小球の指数和を保って零点を非退化にできる。まず $M$ は向き付きとする。$M$ を襟で二重化した閉向き付き多様体を $D(M)$ とする。$X$ を境界越しに滑らかに延ばすには、境界の局所座標で各成分を延長し、1 の分割で合わせればよい。$-X$ は境界で内向きなので、その小さな正時間 $t$ の流れ $\psi_t$ は $M$ を内部へ送る。実際、境界から出発する軌道は直ちに内部へ入り、内部の軌道が初めて境界に達するには、そこで内向き座標の導関数が非正でなければならず、厳密な内向き性に反する。

一方のコピーへの折り畳みを $r\colon D(M)\to M$、そのコピーの包含を $i\colon M\to D(M)$ とする。$F=i\psi_t r$ は連続で、値はそのコピーの内部にある。従って固定点も同じ内部にあり、その近傍では $F=\psi_t$ で滑らかである。:ref[prop-dtop-flow-lefschetz-index] の局所計算により、固定点は $X$ の零点だけであり、指数は $X$ の指数に等しい。各次数で $F^*=r^*\psi_t^*i^*$、$i^*r^*=\id$ なので、有限次元空間の跡の巡回性から $\tr F^*=\tr\psi_t^*$ である。さらに $\psi_t$ は $M$ 内で恒等写像にホモトピックである。従って $L(F)=\chi(M)$ であり、:ref[thm-dtop-lefschetz] を固定点近傍で適用して式を得る。

向き付けられない場合は向きの二重被覆を取る。境界から離れた球と、境界近くで半球となる小さい測地球により有限被覆を作る。半球には二重化の境界襟で積計量を選ぶとよい。十分小さい測地球を選べば、境界を横切り得る最短測地線は積計量の領域内にあり、符号付き襟座標はその測地線上で一次関数になる。従って一方のコピーで切った球も強凸であり、閉多様体の証明と同じ有限交叉の計算により Euler 標数は二倍である。場の持ち上げは境界で外向きで、局所指数の総和も二倍なので、向き付きの場合の式を二で割ればよい。
:::

:::example[円板の動径場]
単位円板 $D^2$ 上の $X=(x,y)$ は境界で外向きで、唯一の零点の指数は $1$ である。円板は収縮可能なので $\chi=1$ である。
:::

:::example[環状領域の非消失場]
$1\le x^2+y^2\le4$ で $X=(-y,x)$ は非消失であり、領域は円に変形収縮して $\chi=0$ である。境界に接するこの場を境界で外向きにしたいなら、小さな半径方向成分を加える。内周では内側の穴へ、外周では外側へ向くよう半径方向成分の符号を変えても、接線方向が消えないので全体は非零である。
:::

### 境界の向きと Euler 数

境界で厳密に内向きな場 $X$ に対しては、$-X$ が外向きである。局所方向写像への対蹠写像の合成は $S^{n-1}$ で次数 $(-1)^n$ を掛けるから、内向きの指数和は $(-1)^n\chi(M)$ である。境界の各成分で向きが異なると、全体を反転するだけでは外向き条件にできない。

:::example[三次元円板の内向き場]
$D^3$ の $X=-x$ は原点で行列式 $-1$ を持つ。指数和は $-1$ で $\chi(D^3)=1$ の負である。偶数次元の円板で同じ向き反転を行うと行列式は正なので、指数和は $+1$ のままである。
:::

:::example[向き付けられない曲面]
$\R P^2$ は次数 $0,1,2$ に一つずつ胞体を持つので Euler 標数は $1$ である。指数は座標の向きの変更を二度受けるため、接束の大域向きがなくてもここでの指数和は整数の $1$ になる。全零点が非退化なら、正符号の零点は負符号より一つ多い。
:::

### 細胞の数をどこまで回復できるか

場の零点を指数で足す式は、零点の個数そのものを決めない。例えば同じ Euler 標数を持つ多様体でも、Morse 関数の Hessian の指数別個数は異なり得る。場の指数が区別するのは各 Hessian の負固有値の個数の偶奇である。一方で Morse 複体は各次数を分けるため、次数ごとの Betti 数にも制約を与える。従って同じ場から何を読み取るかは、その場が勾配であるか、Hessian の情報をどこまで使うかによる。

:::example[三次元の場と Euler 標数]
$T^3$ で $f(x_1,x_2,x_3)=\cos x_1+\cos x_2+\cos x_3$ を標準平坦計量で考える。各角は $0,\pi$ の二択で、Hessian は $\diag(-\cos x_1,-\cos x_2,-\cos x_3)$ となる。Hessian の負固有値が $\lambda$ 個となる点は $\binom3\lambda$ 個である。指数和は $1-3+3-1=0$ となる。一方、定数場 $\partial_{x_1}$ には零点がない。勾配場には最大と最小で必ず零点があるので、閉多様体上で非消失場を求めるとき、勾配場に限定すると存在するはずの場を見落とす。
:::

:::example[非向き付き曲面の三つの臨界点]
$\R P^2$ 上で
$$
f([x:y:z])=\frac{x^2+2y^2+4z^2}{x^2+y^2+z^2}
$$
とする。球面上の制約付き臨界点は対角行列 $\diag(1,2,4)$ の固有方向であり、商では三点である。$[1:0:0]$ の座標 $(y/x,z/x)$ での二次項は $u^2+3v^2$、$[0:1:0]$ では $-u^2+2v^2$、$[0:0:1]$ では $-3u^2-2v^2$ となる。従って勾配場の指数は順に $+1,-1,+1$ で、和は $1$ である。被覆 $S^2$ には各点の持ち上げが二つあり、持ち上げの局所座標で同じ符号になる。被覆側の和が $2$ となることは、Euler 標数の被覆公式とも一致する。
:::

:::example[境界の各成分で異なる向き]
円環 $A=\{1\le r\le3\}$ 上で $X=r\partial_r$ とする。これは平面の原点から遠ざかる場であり、円環では非零である。外周では外向きだが、内周での $A$ の外向きは $-\partial_r$ であるから、そこで内向きになる。外周を平面座標で反時計回りにたどると $X/\norm X$ の度は $+1$、内周を境界向きの時計回りにたどると $-1$ である。和は零であり、どちらか一方の境界だけを使うと零点数の式を得られない。
:::

### 流入境界と流出境界を分ける

:::proposition[境界成分ごとの内向き補正]{#prop-dtop-index-inflow}
コンパクトな $n$ 次元多様体 $M$ の境界成分の一部を $B$ とする。滑らかな場 $X$ が $B$ で厳密に内向き、他の境界成分で厳密に外向きで、内部に孤立零点だけを持つとする。このとき全指数は $\chi(M)-\chi(B)$ である。
:::

:::proof
$B$ に外側の襟 $B\times[-1,0]$ を継ぎ足す。座標 $t$ は増加方向が元の $M$ の内向きである。元の $X$ は零点のない小襟で $+\partial_t$ に変えられる。具体的には $dt(X)>0$ である範囲で切断関数を用いて線形補間すれば、$dt$ 成分は正のままである。継ぎ足した襟に $Y=h(t)\partial_t+\psi(t)Z(p)$ を置く。ここで $h=-1$ を $t=-1$ の近傍、$h=1$ を $t=0$ の近傍で満たすようにし、途中の一時刻 $t_0$ だけで $h=0$、そこで $h'>0$ とする。$\psi=1$ を $t_0$ の近傍、$\psi=0$ を両端の近傍で満たすようにし、$Z$ を $B$ 上の非退化零点だけを持つ場とする。

襟内の零点は $t=t_0$ かつ $Z(p)=0$ の点に限られる。微分は対角ブロックが $h'(t_0)$ と $D_pZ$ であり、指数は $\operatorname{ind}_pZ$ に等しい。従って :ref[thm-dtop-poincare-hopf] により襟に加わる全指数は $\chi(B)$ である。継ぎ足した多様体は襟の伸縮で $M$ と微分同相であり、境界で場はすべて外向きとなる。境界付きの外向き公式を適用すれば、元の和と $\chi(B)$ の和が $\chi(M)$ となる。$n=1$ では $B$ の各点の指数を $1$ と数え、同じ証明で各襟の $h$ の単純零点が一つ加わる。
:::

:::example[円柱と区間での補正]
$M=S^1\times[0,1]$ で $X=\partial_t$ とすると、$B=S^1\times\{0\}$ で内向き、上端で外向きである。$\chi(M)=\chi(B)=0$ なので全指数は零であり、実際に零点はない。同じ場を区間 $M=[0,1]$ で考えると、$\chi(M)=1$、内向き境界 $B=\{0\}$ の Euler 標数も $1$ なので全指数は零である。これに対し $X=(t-1/2)\partial_t$ は両端で外向きで、内部に指数 $+1$ の零点を一つ持つ。内向き境界が消えることが、補正式の右辺を $1$ 増やす。
:::

:::example[一つの内向き境界球]
三次元の殻 $M=\{1\le r\le2\}$ で $X=\partial_r$ は内側球で内向き、外側球で外向きである。$M\simeq S^2$ から $\chi(M)=2$、また $B=S^2$ から $\chi(B)=2$ なので全指数は零となる。外向きの場 $X=(r-3/2)\partial_r$ では中間球面全体が零点なので、そのまま局所指数を足せない。中間球面近くに切断関数で球面の高さの勾配場を足すと、零点は中間球面の両極だけになる。法方向の微分は正であり、接方向の二指数は両方 $+1$ なので、外向き場の全指数は $2$ となる。
:::

### 平面領域の境界上で指数を計算する

:::proposition[平面領域の境界回転と指数]{#prop-dtop-planar-boundary-index}
平面の向きを入れたコンパクトな領域 $M$ の境界を滑らかとし、$X$ は境界で非零かつ内部に有限個の孤立零点を持つとする。境界を外向き優先で向き付けると、$X/\norm X$ の境界成分ごとの巻き数の和は内部の指数和に等しい。
:::

:::proof
各零点を互いに素な円板で除く。残る領域では方向写像 $u$ が定義され、単位円の積分 $1$ の角形式 $\omega$ の引き戻しは閉である。全境界上の積分は $d(u^*\omega)=0$ による Stokes で零である。元の境界成分は向きを保ち、除いた円板の境界は円板の標準向きと逆になる。従って外側の合計から各円板上の積分を引いた値が零である。円板側の積分はそれぞれ局所指数である。境界が複数ある場合、平面の通常の向きでは外周は反時計回り、孔の周囲は時計回りに取る。
:::

:::example[二つの穴の近くで場を比較する]
半径三の閉円板から、中心を $(1,0)$ と $(-1,0)$ とする半径 $1/3$ の二開円板を除く。$X=(x,y)$ は外周で巻き数 $1$ を持つ。各内周円板は原点を含まないため、その境界の方向写像は円板へ延長でき、各内周の巻き数は零である。従って内部の指数和は $1$ であり、原点の一零点と一致する。一方、境界で厳密に外向きな別の場では各内周で巻き数 $-1$、外周で $1$ になるので指数和は $-1$ である。二場の境界の方向が異なるため、境界で非零を保ちながら一方から他方へ連続に変形することはできない。
:::

:::example[法線と接線を一定角だけ回す]
境界成分上で外向き単位法線を $\nu$ とする。平面の正の直角回転を $J$ とすると、境界の単位接線は $J\nu$ である。どの角 $\alpha$ でも $\cos\alpha\,\nu+\sin\alpha\,J\nu$ は長さ一なので、元の $\nu$ と同じ巻き数を持つ。従って場が全境界で接線に一致する場合も、境界の指数和は外向きの場合と同じになる。例えば単位円板で $X=(-y,x)$ を取ると、境界では接線であり、内部の線形行列の行列式は $1$ なので指数も $1$ である。この説明は、単に場が境界に接することだけでなく、境界で非消失であることを使っている。
:::

## Gauss 写像の写像度と Hopf の定理

:::theorem[Gauss 写像に対する Hopf の定理]{#thm-dtop-hopf-gauss}
$M^n\subset\R^{n+1}$ を閉向き付き超曲面とし、単位法線 $G$ が先に来る向きの規約を取り、$n>0$ を偶数とする。このとき $\deg G=\chi(M)/2$ である。
:::

:::proof
$u,-u$ が $G$ の正則値となる単位ベクトル $u$ を取る。高さ $h(x)=\inner{x}{u}$ の臨界点は $G(x)=\pm u$ の点である。法線と接ベクトルの直交関係を微分すると $\inner{D_v w}{G}=-\inner{w}{dG(v)}$ であり、臨界点で $\mathrm{Hess}\,h(v,w)=-\inner{G}{u}\inner{dG(v)}{w}$ となる。球面の接空間は $G^\perp$ であり、向きの規約が $T_xM$ と同じなので、$\det\mathrm{Hess}\,h$ の符号は $(-\inner{G}{u})^n$ と Gauss 写像の局所符号の積である。$n$ が偶数なら前者は $1$ である。正則性で臨界点は非退化になり、指数和は $G^{-1}(u)$ と $G^{-1}(-u)$ でそれぞれ $\deg G$ となる。:ref[thm-dtop-poincare-hopf] により $\chi(M)=2\deg G$ である。
:::

:::example[偶数次元球面]
標準 $S^4$ の外向き Gauss 写像は恒等だから写像度は $1$、公式は $\chi(S^4)=2$ を与える。
:::

:::example[奇数次元の符号]
$S^3$ の Gauss 写像も恒等であるが、$\chi(S^3)=0$ である。高さの上極では Hessian の行列式が負、下極では正であり、二点の指数は打ち消し合う。
:::

### 曲率と方向写像の Jacobian

超曲面の法線の微分を接空間間の写像と見なし、$\kappa_1,\ldots,\kappa_n$ を $dG$ の固有値とする。$dG$ が対称なのは、局所パラメータ $F$ について $\langle\partial_iG,\partial_jF\rangle=-\langle G,\partial_i\partial_jF\rangle$ の右辺が $i,j$ に関して対称だからである。単位球面の体積形式 $\omega$ の引き戻しは
$$
G^*\omega=(\kappa_1\cdots\kappa_n)\,d\mathrm{vol}_M
$$
である。両方の向きを法線優先にして同じ接空間へ移すと、この式は体積形式に対する行列式の変換則になる。形状作用素を $-dG$ と定める規約では、対応する固有値の積に $(-1)^n$ が掛かる。偶数次元では符号が一致する。従って :ref[prop-dtop-degree-integration] と :ref[thm-dtop-hopf-gauss] から、偶数次元では $\int_M(\kappa_1\cdots\kappa_n)\,d\mathrm{vol}_M=(\chi(M)/2)\,\mathrm{vol}(S^n)$ である。

:::example[半径を変えても積分が変わらない理由]
半径 $R$ の二球面では $G(p)=p/R$ で二固有値はともに $1/R$ である。曲率積は $1/R^2$、面積は $4\pi R^2$ なので積分は $4\pi$ である。単位球面の面積で割ると写像度 $1$ になる。
:::

### 単位法線を具体的に微分する

:::example[楕円体の Gauss 写像は微分同相]
$M=\{\sum_{i=1}^{n+1}x_i^2/a_i^2=1\}$、$a_i>0$ とする。$Q=\diag(a_i^{-2})$ とおけば、外向き法線は $G(x)=Qx/\norm{Qx}$ である。任意の $u\in S^n$ に対して $Qx$ が $u$ の正倍である条件と $x^TQx=1$ を合わせると、
$$
x=\frac{Q^{-1}u}{\sqrt{u^TQ^{-1}u}}
$$
と一意に戻る。これは滑らかな逆写像である。従って Gauss 写像の次数は $\pm1$ である。$a_i$ を連続に $1$ へ動かして標準球面と同じ座標 $x_i=a_i v_i$ を使うと、$G$ は恒等写像へホモトピックで次数は $1$ となる。例えば $a_1=2,a_2=a_3=1$ で法線が $e_1$ の点は $(2,0,0)$ だけである。
:::

:::example[回転トーラスの四つの臨界点]
$R>r>0$ とし、
$$
F(u,v)=((R+r\cos v)\cos u,(R+r\cos v)\sin u,r\sin v)
$$
とする。外向き法線は $G(u,v)=(\cos v\cos u,\cos v\sin u,\sin v)$ である。$G_u$ は $F_u$ の $\cos v/(R+r\cos v)$ 倍、$G_v$ は $F_v$ の $1/r$ 倍である。従って $G^{-1}(e_1)$ には $(0,0),(\pi,\pi)$ の二点があり、局所符号は前者で正、後者で負である。$G^{-1}(-e_1)$ にも $(\pi,0),(0,\pi)$ の二点があり、やはり符号は反対である。高さ $x_1$ の臨界点は合わせて四点で、各対の指数和は零となる。$e_3$ を値に選ぶと $v=\pi/2$ の円全体が逆像になり、第一の固有値が零なので正則値ではない。
:::

:::example[トーラスの曲率積を積分する]
前のトーラスで面積要素は $r(R+r\cos v)\,du\,dv$ である。曲率積は $\cos v/(r(R+r\cos v))$ であり、積分では半径を含む因子が打ち消される。従って積分は
$$
\int_0^{2\pi}\int_0^{2\pi}\cos v\,du\,dv=0
$$
である。例えば $R=3,r=1$ では外側 $v=0$ の曲率積が $1/4$、内側 $v=\pi$ では $-1/2$ となる。絶対値が違っても面積要素が違うため、符号付き積分は零になる。
:::

:::example[内向き法線に替えるときの二つの向き]
$S^2$ の標準向きを保ったまま $G(x)=x$ を $-G(x)=-x$ へ替えれば、写像度は $-1$ になる。しかし :ref[thm-dtop-hopf-gauss] で法線を先に置く向きの規約を保つなら、法線の符号反転とともに定義域の向きも反転する。従って二つの符号は相殺され、公式に入れる度は再び $1$ となる。この区別は、曲率積が二固有値の積なので法線反転で変わらないことにも現れる。曲率積を向き付き体積形式へ掛ける際には、選んだ法線に合わせてその体積形式の向きを決める。
:::

### 平面曲線では Gauss 写像の次数と Euler 標数が別になる

:::example[水平線の速度を持つ楕円の法線]
$\gamma(t)=(a\cos t,b\sin t)$、$a,b>0$ の外向き法線は $(\cos t/a,\sin t/b)$ を長さで割ったものである。対角線形変換が向きを保つため、$S^1\to S^1$ の法線写像の度は $1$ である。例えば方向 $(1,0)$ の逆像は $t=0$ の一つであり、そこで方向の角速度は $a/b>0$ となる。一方、曲線自体は円周なので Euler 標数は零である。高さ $x$ の臨界点は $t=0,\pi$ で、二階微分は順に $-a,a$ である。高さの極値の指数では、一方の符号が法線写像の局所符号と反転する。偶数次元に限って両法線のファイバーを同じ符号で加えられる理由が一次元でも見える。
:::

:::example[法線が一定な平面成分の臨界値]
閉曲面の小領域が平面と一致していると、その領域では Gauss 写像が一定である。その法線方向の高さは領域内ですべての点が臨界になり、Hessian も零になる。別の方向に高さを選ぶと、この平面領域の微分は投影した非零接ベクトルになるため、領域内に臨界点は存在しない。Gauss 写像に Sard の定理を使うのは、任意の高さが Morse であると仮定せず、両端の方向が同時に正則になるものを選ぶためである。
:::

## 零点を持たないベクトル場の存在条件

:::theorem[非消失ベクトル場の条件]{#thm-dtop-nonzero-field}
連結な正次元の閉多様体 $M$ は、零点を持たない滑らかな接ベクトル場を持つことと $\chi(M)=0$ が同値である。
:::

:::proof
必要性は :ref[thm-dtop-poincare-hopf] でわかる。一次元の連結な閉多様体は円であり、単位接場を取れる。$n\ge2$ とし、まず場を横断摂動して零点を非退化にする。全指数が零なので正の零点と負の零点を対にできる。一対を他の零点を避ける滑らかな埋め込み弧で結ぶ。道を作って座標内の自己交叉を取り除き端を滑らかにすればそのような弧を選べる。弧を端の外まで延ばし、管状近傍の小さな厚みを取り角を丸めると、その弧を含む閉 $n$ 球 $D$ が得られる。$D$ は他の零点を避ける。

弧の近傍で $TM$ を自明化し、境界で場を正規化する。:ref[lem-dtop-index-add] による境界写像の度は $1-1=0$ である。:ref[thm-dtop-hopf-degree] よりその方向写像は零ホモトピックであるため、$D$ 内で非零方向へ延長できる。境界の小襟では元の方向を保持し、より内側でホモトピーを使い、中心の近傍は定数とする。元の長さが既知の襟上ではその値に合わせ、内部は正の長さを用い、滑らかな正の切断関数で補間する。方向のホモトピーは相対平滑化できるため滑らかな場が得られる。これで一対が除かれ、同じ手順を有限回繰り返せば非消失場になる。
:::

:::example[奇数次元球面の明示場]
$S^{2k+1}\subset\C^{k+1}$ で $X(z)=iz$ とする。実内積で $\inner{iz}{z}=0$、長さは $1$ なので全点で接し非消失である。
:::

:::example[トーラスと種数二の曲面]
$T^2$ では $\R^2$ の定数場 $(1,0)$ が商に降りる。種数二の向き付き閉曲面では $\chi=-2$ なので、どの場にも少なくとも一つの零点がある。零点がすべて非退化なら負の指数の零点が正の零点より二つ多い。
:::

### 零点の総数を減らす局所操作

非消失場の証明では、零点の場所を自由に選ぶために一対を含む球を取った。同じ操作で、Euler 標数が零でない場合にも、非退化零点の数を最小まで減らせる。

:::proposition[非退化零点数の最小値]{#prop-dtop-index-minimum}
連結な正次元の閉多様体 $M$ において、非退化零点だけを持つ滑らかな場の零点数の最小値は $|\chi(M)|$ である。
:::

:::proof
各指数は $\pm1$ であり、全指数は $\chi(M)$ なので、零点数はその絶対値以上である。$n=1$ では $\chi(M)=0$ で、円周の非消失場を使える。$n\ge2$ では非退化零点だけを持つ場から始め、正と負の両方が残っている間は :ref[thm-dtop-nonzero-field] の証明の局所操作を適用する。この操作の条件は、全体の指数が零であることではなく、選んだ球内の指数和が零であることである。球の外では場が変わらないため、他の零点は非退化のままである。有限回で残る零点の符号がすべて同じになる。その個数は $|\chi(M)|$ である。
:::

:::example[種数三の曲面の最小値]
種数三の向き付き閉曲面の Euler 標数は $2-6=-4$ である。従って :ref[prop-dtop-index-minimum] の構成で負の零点四つだけを持つ場を作れる。閉曲面の実数値関数の勾配がこの場に等しいとすれば、最小点も非退化な零点になる。そこで微分は正定値 Hessian と正定値な計量の逆行列の積なので、指数が正となり、四点がすべて負という条件に反する。
:::

:::example[退化を許すと零点数と指数が分かれる]
$S^2$ を複素射影直線で記述し、アフィン座標 $z$ 上で係数 $X_z=1$ の実ベクトル場を取る。もう一枚の座標 $w=1/z$ では連鎖律で $X_w=-w^2$ となる。これは $w=0$ まで滑らかに延び、そこだけで零になる。方向写像の角は $2\theta+\pi$ であるため局所指数は $2$ である。従ってこの場は一零点で Euler 標数 $2$ を実現する。:ref[prop-dtop-index-minimum] が非退化性を要求する理由は、一つの退化零点に複数の単純零点の指数を集められることにある。
:::

:::example[各連結成分で障害を確認する]
$M$ を球面 $S^2$ と種数二の閉曲面との非交和とする。全体の Euler 標数は $2+(-2)=0$ である。しかし球面上の任意の場には指数和 $2$ の零点が必要で、種数二の成分にも指数和 $-2$ の零点が必要である。一つの球を使う除去操作は、同じ連結成分にある零点だけを結べる。従って非連結な閉多様体では、非消失場の必要十分条件は全体の Euler 標数の消滅ではなく、すべての成分で Euler 標数が零となることである。
:::

### いくつかの独立な場を求める場合

:::example[三次元球面上の独立な三場]
$S^3$ を単位四元数の集合と見る。$q\in S^3$ で $iq,jq,kq$ を取る。右から $q$ を掛ける線形変換はノルムを保存するので、$(q,iq,jq,kq)$ は $\R^4$ の正規直交基底である。最初の $q$ は外法線であり、残る三つは接空間の正規直交基底を与える。従って $TS^3$ は自明である。$S^{2k+1}$ 上で一場 $iz$ を作ることから、常に接束全体が自明であると結論することはできない。独立な複数の場を求めるには、残りの直交補にさらに非消失切断があるかを調べる。
:::

:::example[第一の場が選べると法補束が残る]
計量を持つ $M$ で単位接場 $X$ があれば、任意の $v\in T_pM$ は $\inner{v}{X}X+(v-\inner{v}{X}X)$ と一意に分かれ、$TM=\underline{\R}X\oplus X^\perp$ となる。$X$ と点ごとに独立な場 $Y$ があれば、$Y-\inner{Y}{X}X$ は $X^\perp$ の非消失切断である。逆に $X^\perp$ の非消失切断は $X$ と独立である。このため第一の場が存在するときにも、第二の場の問題は残る。例えば二次元の向き付き多様体では $X^\perp$ の正の単位方向を向きと計量から一意に選べるので、第一の場だけで接束が自明になる。
:::

### 退化を許す場合の最小零点数

:::theorem[一零点に全指数を集める]{#thm-dtop-index-one-zero}
連結な閉正次元多様体 $M$ で、零点が孤立する滑らかな場の最小零点数は $\chi(M)=0$ なら零、$\chi(M)\ne0$ なら一である。後者では残る一点の指数は $\chi(M)$ となる。
:::

:::proof
$\chi=0$ の場合は :ref[thm-dtop-nonzero-field] による。$\chi\ne0$ なら一次元ではないので $n\ge2$ であり、:ref[thm-dtop-poincare-hopf] から少なくとも一点が必要である。存在の証明では横断場を選び、有限個の零点を小閉球で囲う。球を一つずつ結ぶ埋め込み弧を選び、既存の球や結んだ領域の内部を通らないようにする。連結な $n$ 次元多様体から有限個の互いに素な開球を除いても、各球を横切る道をその連結な境界へ迂回できるため連結である。ここでは $n\ge2$ を用いた。道の自己交叉を小座標内で取り除いて弧にできる。各接続で二つの球とそれらを結ぶ細い $1$ ハンドルの和は、角を丸めると一つの $n$ 球になる。実際、接着先の二つの小 $(n-1)$ 円板を各球の標準平らな端面へ移せば、全体は円板断面の半径が両端へ向かって縮む一つの筒として表示できる。帰納してすべての零点を含む閉球 $D$ を得る。

$TD$ を座標で自明化し、外側の小襟では元の非零場を残す。その襟の内側で、半径引数を滑らかに一定値へ取り直し、方向と長さが半径によらない小領域を作る。ここで使う半径は元の場が非零な襟の範囲に限る。凍結した単位方向を $u(\theta)$ と書く。内側ではその方向を各半直線に沿って使い、長さを原点近くで $\exp(-1/r^2)$、$r>0$ とする。襟で凍結した長さとこの長さは正の切断関数による補間でつなぐ。中心では値を零と定める。$u$ は球面上で滑らかなので $r>0$ で角微分の任意階は $r^{-1}$ の有限べきで評価できる。$\exp(-1/r^2)$ はその全てに勝って零へ近づき、階数ごとに同じ評価を微分の積の式へ適用すると、中心で全微分が零に延びる。従って新しい場は滑らかであり、$D$ 内の零点は中心だけである。外境界における方向写像は変えていないので :ref[lem-dtop-index-add] により新しい局所指数はもとの全指数に等しい。
:::

:::example[負の指数を一点へ集める]
種数四の閉向き付き曲面では $\chi=2-8=-6$ である。非退化零点だけなら負の点を少なくとも六つ必要とする。しかし上の構成では、場を六点の周囲だけで取り替える一つの球を取り、その境界方向の度 $-6$ を中心一点へ集められる。平面上の次数 $-6$ の方向写像は $\theta\mapsto e^{-6i\theta}$ とホモトピックなので、内側の小円周の方向をこの標準形に整えることもできる。すると中心の近くでは $\exp(-1/r^2)e^{-6i\theta}$ となり、微分は零である。もし中心が非退化なら指数は $\pm1$ に限られるから、この退化は個数を一つに減らすために必要である。
:::

## 演習問題

::::exercise{level=basic #exr-dtop-vector-field-index-1}
$X=(-4x,5y)$ の指数を求めよ。

:::solution
零点は原点のみで、微分の行列式は $-20$ なので指数は $-1$ である。
:::
::::

::::exercise{level=basic #exr-dtop-vector-field-index-2}
$X(z)=\overline z^3$ の指数を求めよ。

:::solution
$\rho e^{it}$ における正規化は $e^{-3it}$ なので、角の導関数が負の三つの逆像を数えて $-3$ である。
:::
::::

::::exercise{level=basic #exr-dtop-vector-field-index-3}
一次元の $X(x)=x^4$ の指数を求めよ。

:::solution
左右の成分がともに正なので、符号差を $2$ で割ると零である。
:::
::::

::::exercise{level=basic #exr-dtop-vector-field-index-4}
種数 $3$ の向き付き閉曲面で正の零点が $2$ つあり、すべて非退化とする。負の零点数を求めよ。

:::solution
Euler 標数は $2-6=-4$ である。負の個数を $m$ とすると $2-m=-4$ なので $m=6$ である。
:::
::::

::::exercise{level=advanced #exr-dtop-vector-field-index-5}
$\R^2$ で $X=(x^3,y)$ の指数を直接求めよ。

:::solution
原点のみで消える。$F_s=((1-s)x^3+sx,y)$ は、$x\ne0$ のとき第 1 成分が $x$ と同符号であり、$y\ne0$ のとき第 2 成分が非零である。従って球面で方向が消えず、恒等場へホモトピックなので指数は $1$ である。
:::
::::

::::exercise{level=advanced #exr-dtop-vector-field-index-6}
閉向き付き多様体の微分同相で場を押し出すと指数が保存されることを示せ。

:::solution
押し出し先で元の座標を微分同相の逆写像を通じて移せば、成分関数は同じである。よって座標での境界写像が一致する。座標独立性により別の座標で計算しても同じであり、微分同相の向きの符号には依らない。
:::
::::

::::exercise{level=advanced #exr-dtop-vector-field-index-7}
奇数次元の閉多様体で、ある場のすべての零点が非退化かつ正の指数ならどうなるか。

:::solution
奇数次元の Euler 標数は向きによらず零である。全指数は正の零点数に等しいので、零点は一つもない。
:::
::::

::::exercise{level=advanced #exr-dtop-vector-field-index-8}
回転トーラスの Gauss 写像が球面に全射であることを示し、Gauss 写像の度から Euler 標数を求めよ。

:::solution
法線は $G(u,v)=(\cos v\cos u,\cos v\sin u,\sin v)$ である。$-\pi/2\le v\le\pi/2$ として第 3 成分を指定し、極以外では $u$ を水平成分の偏角に選べば任意の方向が得られる。一方、正則値 $e_1$ の逆像は $(u,v)=(0,0),(\pi,\pi)$ である。法微分の行列式の符号は $\cos v$ の符号なので、第 1 点は正、第 2 点は負であり、度は零である。従って :ref[thm-dtop-hopf-gauss] により $\chi=2\deg G=0$ である。
:::
::::

::::quiz{answer="1" tol="1e-6"}
$\diag(-1,-2,3)$ を微分に持つ非退化零点の指数はいくつか。

:::explanation
行列式は $6$ なので指数は $+1$ である。
:::

::::quiz{answer="5" tol="1e-6"}
$X(z)=z^5$ の原点での指数はいくつか。

:::explanation
正規化すると $e^{it}$ が $e^{5it}$ に写る。$1$ の五つの逆像はいずれも正である。
:::
::::

::::quiz
孤立零点について正しい記述を選べ。

- [x] 退化零点の指数が零の場合がある。
- [ ] 孤立零点の指数は常に $1$ か $-1$ である。
- [x] 非退化零点の指数は微分の行列式の符号である。

:::explanation
$(x^2,y)$ の原点の指数は像が一方の半円に入るため零であり、$z^k$ では $k$ になる。可逆な微分を持つ場合は線形近似と非消失ホモトピーを使うと符号に帰着する。
:::
::::

::::quiz{answer="-6" tol="1e-6"}
種数 $4$ の閉向き付き曲面上の全指数はいくつか。

:::explanation
Poincaré–Hopf の定理から全指数は $\chi=2-2\cdot4=-6$ である。
:::
::::

::::quiz
非消失接ベクトル場を持つものを選べ。

- [x] $S^3$
- [x] $T^2$
- [ ] $S^2$

:::explanation
$S^3$ は複素座標で $X(z)=iz$ を持ち、$T^2$ は平面の定数場を商に降ろせる。$S^2$ の Euler 標数は $2$ なので Poincaré–Hopf の定理により非消失場は存在しない。
:::
