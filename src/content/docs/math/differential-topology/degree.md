## この章の目標

- 正則値での逆像から写像度を計算する。
- 横断逆像を用いてホモトピー不変性を証明する。
- 交叉数と Lefschetz 数を対角から求める。
- 回転数と絡み数を写像度として計算する。

## mod 2 写像度

逆像に点が何個あるかは値により変わる。それでも、一対の点が生じたり消えたりする変化だけなら偶奇は保たれる。まず点の向きを使わない計数を扱う。

:::definition[mod 2 写像度]{#def-dtop-mod-two-degree}
$M$ をコンパクト境界なし、$N$ を連結境界なしとし、$\dim M=\dim N=n$ とする。滑らかな $f\colon M\to N$ と正則値 $y$ に対し、$\#f^{-1}(y)\bmod2$ を :term[mod 2 写像度]{en="degree modulo two" yomi="もっどにしゃぞうど"} という。集合は正則値定理により離散であり、コンパクトなので有限である。
:::

:::proof[値の選び方によらないこと]
二つの正則値 $y_0,y_1$ を結ぶ滑らかな道 $\gamma$ を取り、端点近傍では定数とする。$(x,t)\mapsto(f(x),\gamma(t))$ を対角と比較する。道の中間部分を値域の局所流で摂動すれば、第 2 成分のパラメータ方向を自由に動かせる。対角の法方向は両成分の差なので、この全写像は中間で対角に横断的になる。端点付近では $df$ が全射であるため既に横断的である。:ref[thm-dtop-parametric] を用いて端点を保つ横断な道を選ぶと、逆像はコンパクトな一次元多様体となる。その境界は $f^{-1}(y_0)\sqcup f^{-1}(y_1)$ である。コンパクト一次元多様体は円と閉区間の有限非交和であり、各閉区間には端点が二つある。よって両方の個数は同じ偶奇を持つ。
:::

:::example[角を三倍する写像]
$S^1$ 上の $\exp(it)\mapsto\exp(3it)$ では $1$ の逆像は角 $0,2\pi/3,4\pi/3$ の三点であり、mod 2 写像度は $1$ である。
:::

:::example[球面の射影]
$S^2\to\R^2$、$(x,y,z)\mapsto(x,y)$ では $(0,0)$ の逆像は北極と南極である。外側の値 $(2,0)$ の逆像は空である。二つの正則値について偶奇はともに $0$ になる。
:::

### 写像度をファイバーの変化から読む

:::example[折り目を越えると二点が増える]
$f\colon S^1\to S^1$ を $f(e^{it})=\exp(i\pi\cos t/2)$ とする。$1$ の逆像は $t=\pi/2,3\pi/2$ であり、角の微分 $-\frac{\pi}{2}\sin t$ はそれぞれ負と正である。この二点を mod $2$ で足すと零になる。$-1$ の逆像は空なのでやはり零である。$i$ に移ると逆像は $t=0$ の一つになるが、そこで角の微分が消える。従ってこの一つを使って mod $2$ 写像度を求めることはできない。二つの逆像が臨界値で一つになった後で消えるので、正則値で比較する限り偶奇は変わらない。
:::

:::example[向き付けの可否と mod 2 計数]
$\R P^2$ の小円板 $D$ を選び、外側を一点に潰して $D/\partial D\simeq S^2$ を得る。円板の内部に対応する点の逆像は一つであり、潰し写像はその点の近くで滑らかな局所微分同相に選べる。残りの領域は標的の基点の近くに写るので、相対平滑近似でその点の逆像を変えずに滑らかな写像を得られる。従って mod $2$ 写像度は $1$ である。一方、$\R P^2$ には大域的な向きを入れられないため、この構成に向き付き写像度は定義しない。局所円板に向きがあっても、別の点まで向きを運ぶ際に符号が曖昧になるためである。
:::

:::example[被覆のシート数]
$T^2=\R^2/\Z^2$ の写像 $([x],[y])\mapsto([2x],[3y])$ は全点で正則である。任意の値 $([a],[b])$ に対して $x=(a+j)/2$ の二通りと $y=(b+k)/3$ の三通りが独立に選べるので、各逆像は六点である。したがって mod $2$ 写像度は $0$ だが、この写像は全射である。同じ計算を $([3x],[5y])$ に対して行うと逆像は十五点となり、mod $2$ 写像度は $1$ である。この場合は偶奇だけでも全射性を結論できる。
:::

### 値域の連結成分

値域が非連結なら、値を同じ成分で動かしたときにだけ、正則値の逆像を道で比較できる。例えば $M=S^1$、$N=S^1\sqcup S^1$ とし、$M$ を第一成分へ恒等に写す。第一成分の値の逆像は一つで、第二成分の値の逆像は空である。両方とも正則値だが、偶奇は異なる。定義域が非連結で値域が連結の場合は、各定義域成分の計数を足す。コンパクト多様体には有限個の連結成分しかない。連結成分は開であり、それらによる開被覆に有限部分被覆があるからである。そのため有限和として写像度が定まる。

## 向き付けられた写像度

:::definition[向き付き写像度]{#def-dtop-oriented-degree}
$M$ をコンパクト境界なし、$N$ を連結境界なしとし、両者は同じ次元で向き付けられているとする。滑らかな $f\colon M\to N$ の正則値 $y$ に対し、各 $p\in f^{-1}(y)$ で $df_p$ が向きを保つとき $\eps_p=1$、反転するとき $\eps_p=-1$ とする。和 $\sum_p\eps_p$ を :term[写像度]{en="degree of a map" yomi="しゃぞうど"} $\deg f$ という。
:::

:::proof[符号付き計数の値による独立性]
前節の一次元多様体 $W$ は、法方程式の微分 $df-\dot\gamma\,dt$ で向き付ける。ここでは、法方向の向き付き基底の持ち上げを先に置き、その後に $TW$ の基底を置くと $TM\oplus T[0,1]$ の向きになるようにする。端点で $df$ が可逆なので、時間が増える接ベクトルの $W$ 内での符号は $\eps_p$ である。したがって境界の符号は $t=0$ で $-\eps_p$、$t=1$ で $\eps_p$ である。向き付き区間の境界符号の和は零であるから両端の和が一致する。
:::

:::proposition[合成と全射性]{#prop-dtop-degree-properties}
連結な閉向き付き $n$ 次元多様体間では $\deg(gf)=\deg g\deg f$ である。写像度が非零なら写像は全射である。
:::

:::proof
$g$ と $gf$ の臨界値を同時に避ける $y$ を :ref[thm-dtop-sard] で取る。$g^{-1}(y)$ の各点は $f$ の正則値である。連鎖律により合成の局所符号は二つの符号の積であり、$g^{-1}(y)$ の各点の上で $f$ の符号付き計数を行えば積の公式を得る。逆像が空の値があれば、その値は正則で符号和は零なので、非零写像度から全射性が従う。
:::

:::example[鏡映と対蹠写像]
球面の向きを外向き法線を最初に置いて定める。直交変換は法線を法線へ送るから、球面上での局所符号は ambient 行列式である。よって超平面での鏡映は写像度 $-1$、$S^n$ の対蹠写像は $(-1)^{n+1}$ である。
:::

:::example[複素累乗の局所符号]
$S^1$ 上の $z\mapsto z^{-4}$ は角を $-4$ 倍する。$1$ の逆像は四点で、すべての点で角の向きが反転するから写像度は $-4$ である。
:::

### 基本類から定義する写像度

連結な閉向き付き $M^n,N^n$ の整数基本類を $[M],[N]$ とする。写像度は $f_*[M]=d[N]$ を満たす整数 $d$ としても定まる。この記述は滑らかさを要しない。ここでの基本類は、各点の局所ホモロジー $H_n(N,N\setminus\{y\};\Z)$ で、向きによる生成元へ移る類である。

:::proposition[基本類と局所符号の一致]{#prop-dtop-degree-fundamental}
滑らかな写像に対し、基本類による写像度は正則値の符号付き点数に一致する。
:::

:::proof
正則値 $y$ の有限逆像を $p_1,\ldots,p_s$ とする。相対群 $H_n(M,M\setminus f^{-1}(y))$ は切除により、互いに素な小球上の局所ホモロジーの直和である。$[M]$ は各小球の局所向きの生成元に移る。$f$ を十分小さい各球に制限すると局所微分同相なので、相対群への押し出しはそれぞれ符号 $\eps_{p_i}$ 倍である。すべて同じ $H_n(N,N\setminus\{y\})$ へ送られるので係数を足すと $\sum\eps_{p_i}$ である。一方、絶対群から相対群への自然写像では $d[N]$ が単位生成元の $d$ 倍に移る。この二通りの比較で $d=\sum\eps_{p_i}$ となる。$\F_2$ の基本類を使えば向きを仮定せず同じ議論ができる。
:::

:::example[積と係数]
$S^1\times S^1$ の写像 $(z,w)\mapsto(z^3,w^{-2})$ は、正則値 $(1,1)$ に六点の逆像を持つ。角座標の微分は $\diag(3,-2)$ なので全点で符号が負、写像度は $-6$ である。基本類の外積も、各因子で $3,-2$ 倍されるので同じ結果になる。
:::

### 固有写像と局所写像度

コンパクトな定義域を使う理由は、逆像が有限であることと、値を動かす途中の逆像をコンパクトに保つことであった。固有写像ならこの二つが同じように成立する。

:::proposition[固有写像の写像度]{#prop-dtop-proper-degree}
$M,N$ を境界なしの向き付き $n$ 次元多様体とし、$N$ は連結とする。固有な滑らかな写像 $f\colon M\to N$ の正則値における符号和は値に依存しない。さらに、$M\times[0,1]\to N$ として固有な滑らかなホモトピーでこの符号和は変わらない。
:::

:::proof
正則ファイバーはコンパクトな離散集合だから有限である。二つの正則値 $y_0,y_1$ を滑らかな道 $\gamma$ で結ぶ。道の近くでは、値域の有限個のコンパクト台ベクトル場を使って、端点を固定したまま $f$ と互いに横断な道を選べる。具体的には $\gamma$ を端の襟で一定にし、中間の時刻を覆う有限個の小区間で値域の座標方向の流れを加える。端では $f$ がファイバーの全点で沈め込みであり、中間ではパラメータ方向が全射となる。写像 $(x,t,s)\mapsto(f(x),\gamma_s(t))$ を対角へ横断にした上で、:ref[thm-dtop-parametric] により小パラメータを固定する。道の軌跡を一つのコンパクト集合に入れれば、すべての交点の $x$ はその逆像のコンパクト集合にとどまる。向き付き一次元ファイバー積の境界は二つの正則ファイバーであり、外向き優先の規約で一方の符号が反転する。従って両端の符号和が等しい。

ホモトピーについては全写像と両端の写像の臨界値集合を避けた共通の正則値を Sard の定理で選ぶ。その逆像は固有性によりコンパクトで、両端のファイバーを境界に持つ向き付き一次元多様体である。同じ境界符号の比較により結論を得る。
:::

:::example[多項式の両端を比較する]
$f(x)=x^3-3x$ は固有である。値 $0$ の三つの逆像 $-\sqrt3,0,\sqrt3$ で微分は $6,-3,6$ であり、度は $1$ である。値 $3$ には正の側に一根だけあり、そこで微分は正である。値 $-2,2$ を越えると根の個数は変わるが、固有写像の度は $1$ のままである。対して $g(x)=x^2$ の正の値では二根の符号が反対なので度は $0$ となり、負の値の空ファイバーと一致する。
:::

:::example[各時刻の固有性とホモトピーの固有性]
$F(x,t)=(1-t)x^2+x$ とする。$t<1$ では偶数次多項式なので写像度は $0$、$t=1$ では恒等写像なので度は $1$ である。各時刻の写像は固有でも、$t<1$ における零点 $-1/(1-t)$ は $t\to1$ で無限遠へ向かう。従って $F^{-1}(0)$ はコンパクトでなく、ホモトピー全体は固有でない。この例で変化する符号は、無限遠へ逃げる根に由来する。
:::

:::proposition[局所写像度と正則値]{#prop-dtop-local-degree}
次元 $n\ge1$ の向き付き Euclid 空間の間で、閉球 $B$ 上の滑らかな写像 $f$ が $y$ を $\partial B$ 上で取らないとする。境界写像 $(f-y)/\norm{f-y}$ の度は、$y$ の十分小さい近傍の任意の正則値 $z$ における $B$ 内の局所符号の和に等しい。$n=1$ では $S^0$ の被約零次ホモロジー上の作用を度とする。
:::

:::proof
$n=1$ は次に示す端点の符号差で計算できる。$n\ge2$ とし、$\partial B$ 上で $\norm{f-y}$ の最小値を $d>0$ とする。$\norm{z-y}<d$ なら、$y$ と $z$ を結ぶ線分は $f(\partial B)$ を避ける。従って二つの方向写像は線分に沿うホモトピーを持つ。$z$ における各逆像点の周りに互いに素な小球を除けば、方向写像は穴あき球の全体に延びる。共通の球面正則値を選ぶとその逆像はコンパクトな一次元多様体となり、境界に現れる符号の総和が零である。内側の小球の向きは穴あき球の境界として反転するので、外側の度は小球の度の和である。小球の境界で線形近似との差は $o(r)$、線形近似の長さは可逆性により $cr$ 以上である。十分小さい半径なら非零のまま線形近似へ変形できるため、小球の度は行列式の符号である。
:::

:::example[向き反転を含む積写像]
$f(z,t)=(z^3,-2t)$ を $\C\times\R$ からそれ自身への写像とする。$z\ne0$ の点では複素微分 $3z^2$ が実二次元で行列式 $9|z|^4$ を持つ。$t$ 方向の行列式は $-2$ なので局所符号は常に負である。例えば値 $(1,-4)$ の逆像は三乗根 $1,e^{2\pi i/3},e^{4\pi i/3}$ と $t=2$ の組であり、度は $-3$ である。原点を含む小球での局所度も、近傍の値 $(a,0)$、$a>0$ が三つの小さい根を持つことから $-3$ となる。
:::

### 一次元での局所度

$n=1$ の小球は区間 $[a,b]$ であり、向き付き境界は $[b]-[a]$ である。方向写像の度は $S^0$ の被約 $H_0$ に誘導する整数とし、
$$
\frac{\sgn(f(b)-y)-\sgn(f(a)-y)}2
$$
で求める。正則な $z$ の根を左から順に並べると、各根で $f-z$ の符号が負から正への変化なら微分は正、逆なら負である。両端の符号差を各小区間の差として足すと、隣り合う端の符号は相殺し、各根の変化の半分だけが残る。従って :ref[prop-dtop-local-degree] の計数は一次元でも成り立つ。例えば $[-1,1]$ で $f(x)=x^4$、$y=0$ なら両端が正だから零であり、近くの正の値の二根の符号が相殺する。$x^3$ なら左右の符号が反対なので度は $1$ である。

## 写像度のホモトピー不変性

:::theorem[写像度のホモトピー不変性]{#thm-dtop-degree-homotopy}
コンパクトな境界なし多様体 $M$ と連結な境界なし多様体 $N$ は等次元とする。このとき、互いにホモトピックな連続写像 $M\to N$ は同じ mod 2 写像度を持つ。両多様体が向き付けられていれば、同じ整数写像度を持つ。連続写像の度は滑らかな代表の度で定義できる。
:::

:::proof
連続写像には :ref[cor-dtop-manifold-approximation] により滑らかな代表がある。従って滑らかな両端を結ぶ連続ホモトピーについて示せば、代表の選び方によらないことも従う。端で定数になるよう時間を取り直し、端の襟が滑らかになったところで相対近似を適用する。得られた滑らかな $H\colon M\times[0,1]\to N$ の内部と両端の写像の臨界値の和を避けて $y$ を取る。:ref[thm-dtop-transverse-preimage] により $H^{-1}(y)$ はコンパクト一次元多様体である。前節と同じ法方向優先の向きを使うため、積の向きは $TM$、時間の順に取る。境界符号が端の局所符号に $-1,1$ を掛けたものになるから、境界総和が零であることにより等式を得る。向きなしでは同じ境界点集合を mod $2$ で数える。
:::

:::example[定数に縮められない写像]
$z\mapsto z^2$ の写像度は $2$、定数写像の写像度は $0$ であるから、円への写像としてホモトピックではない。
:::

:::example[球面を球体へ縮められない理由]
球体から境界への連続なレトラクションがあれば、球体の収縮をレトラクションと合成して球面の恒等写像が定数写像にホモトピックになる。両者の写像度はそれぞれ $1,0$ なので矛盾する。
:::

### 球体の固定点と平面の局所次数

:::corollary[Brouwer の固定点定理]{#cor-dtop-brouwer}
任意の連続写像 $f\colon D^n\to D^n$ は固定点を持つ。
:::

:::proof
固定点がなければ、$f(x)$ から $x$ を通って延ばした半直線が、その後に球面と交わる点を $r(x)$ とする。$u=x-f(x)\ne0$、$a=\inner{x}{u}$ とすると、交点は $x+t u$、ただし
$$
t=\frac{-a+\sqrt{a^2+\norm{u}^2(1-\norm{x}^2)}}{\norm{u}^2}
$$
である。内部ではこれは唯一の正の解であり、境界では $a=1-\inner{x}{f(x)}>0$ なので $t=0$ である。従って $r$ は連続で境界上で恒等である。前節の写像度の議論により、そのようなレトラクションは存在しない。$n=1$ では同じ結論が $f(x)-x$ の中間値からも得られる。$n=0$ では円板は一点である。
:::

:::example[球体を内側へ縮める写像]
$D^2$ 上で $f(x)=Ax+b$、$A=\diag(1/2,1/3)$、$b=(1/4,0)$ とする。$\norm{f(x)}\le1/2+1/4<1$ なので自己写像である。固定点は $(I-A)x=b$ から $(1/2,0)$ である。固定点の局所符号は $\det(I-A)=1/3>0$ である。
:::

:::example[境界を保つ写像の角]
$D^2$ を $\C$ の単位円板として $z\mapsto z^4$ を考える。境界への制限の写像度は $4$ である。円板内部の $1/16$ の逆像は四点であり、複素微分の実行列式は $|4z^3|^2>0$ である。境界の四回転が内部の符号付き根の個数と一致する。
:::

### ストークスの定理による別の計数

:::proposition[最高次形式による写像度]{#prop-dtop-degree-integration}
$M,N$ は等次元で向き付けられた閉多様体、$N$ は連結とする。滑らかな $f\colon M\to N$ と $N$ の最高次形式 $\omega$ に対して、
$$
\int_M f^*\omega=\deg f\int_N\omega
$$
である。
:::

:::proof
正則値 $y$ の小座標球 $U$ を取る。逆像の各点で逆関数定理を適用し、残りのコンパクトな領域の像から $y$ が離れていることを使うと、$f^{-1}(U)$ は $U$ への有限個の微分同相の枝に分かれる。従って $U$ に台を持つ積分 $1$ の最高次形式 $\omega_0$ について、変数変換公式により $\int_M f^*\omega_0=\deg f$ である。

積分零の最高次形式が完全であることを直接示す。まず $\R^n$ のコンパクト台形式 $q(x',t)\,dx_1\wedge\cdots\wedge dx_{n-1}\wedge dt$ を考える。$g(x')=\int_\R q(x',t)\,dt$ とし、積分 $1$ のコンパクト台関数 $\rho(t)$ を選ぶと、$q-g\rho$ の $t$ 積分は各 $x'$ で零である。$t$ について $-\infty$ から積分した原始関数はコンパクト台を持ち、これに $(-1)^{n-1}\,dx_1\wedge\cdots\wedge dx_{n-1}$ を掛けて外微分を取れば対応する最高次形式を得る。残る項 $g\rho$ については $\int g=0$ なので、次元 $n-1$ で同じ議論を使う。$n=1$ では初めの積分だけで終わる。

一般の $N$ では 1 の分割で形式を座標球内に台を持つ有限個の形式に分ける。各形式は、同じ球内の積分 $1$ の形式にその積分値を掛けたものと、完全形式だけ異なる。二つの座標球が交われば、交わりの小球に積分 $1$ の形式を置いて比較でき、双方の差はそれぞれの座標球で完全である。連結性により有限被覆の交わりのグラフは連結なので、すべての積分を同じ $\omega_0$ に移せる。従って $\omega-(\int_N\omega)\omega_0$ は完全である。その引き戻しの積分は Stokes の定理で零となり、式が従う。零次元の連結な $N$ は一点であり、その場合は点の向き付き計数そのものになる。
:::

滑らかなホモトピーの両端を比べる場合は、最高次形式の時空間への引き戻しが閉なので、Stokes の定理だけで両端の積分の一致を示せる。固有写像とコンパクト台を使う版は [コンパクト台コホモロジー](/math/differential-topology/compact-support/) で扱う。

:::example[円周の角形式]
$S^1\subset\R^2$ の点 $(x,y)$ で $\omega=(x\,dy-y\,dx)/(2\pi)$ とする。$(\cos t,\sin t)$ に引き戻すと $dt/(2\pi)$ となる。$f(e^{it})=\exp(i(3t+2\sin t))$ なら $f^*\omega=(3+2\cos t)dt/(2\pi)$ であり、積分は $3$ になる。$2\sin t$ を $2s\sin t$ に替えたホモトピーでも積分は $3$ である。係数を $4$ に替えると角の微分が負になる区間を持つが、積分値は依然として $3$ であり、逆像の局所符号が反対の枝の寄与が相殺される。
:::

:::example[境界を通って入る逆像]
$M=[0,1]$ で $f_t(x)=x-t$ とする。値 $0$ の逆像は $0<t<1$ で一点、$t<0$ では空である。変化は $t=0$ に根が側面 $x=0$ を通って入るためである。実際、時空間の零集合は $x=t$ という線分であり、時間の端以外の境界に点を持つ。閉多様体の証明で境界に現れる符号を二つの時刻だけから足せるのは、側面がないからである。境界付きの場合は、側面で値を避ける条件を加える。
:::

:::example[曲面の鏡映を恒等へ変形できない理由]
$S^2$ の鏡映 $R(x,y,z)=(-x,y,z)$ は、外法線を含めて周囲の向きを反転させるため度 $-1$ である。恒等写像の度は $1$ なので、両者を連続な写像の族で結べない。対して $R^2=\id$ の度は $(-1)^2=1$ である。さらに回転 $U_\theta$ は $U_0=\id$ を含む族をなすためどの角でも度は $1$ である。写像を直交行列で与える場合、行列式がこの二つの可能性を見分ける。
:::

### 球体からの延長を度で妨げる

:::proposition[球面への延長の判定]{#prop-dtop-sphere-extension}
$n\ge1$ とする。$g\colon S^n\to S^n$ に対して、球体 $D^{n+1}$ への連続な延長が存在することと $\deg g=0$ は同値である。
:::

:::proof
延長 $G$ があれば、$g(x)$ を $G(sx)$ で $s=0$ まで動かすと定数写像に縮むから度は零である。逆に :ref[thm-dtop-hopf-degree] により、度零の写像は定数へ連続に縮む。$H(x,1)=g(x)$、$H(x,0)=p$ と書き、$G(rx)=H(x,r)$ と置く。中心では $H(x,0)$ が一定であり、$S^n\times[0,1]$ のコンパクト性から $H(x,r)\to p$ は一様である。よって中心でも連続である。
:::

:::example[三乗写像の延長先]
$S^1$ の写像 $z\mapsto z^3$ は $D^2$ から $\C$ への写像としては同じ式で延長できる。ところが $S^1$ に値を取る延長なら、上の判定で $3=0$ が必要となる。どの $\C$ 値延長も原点を取る。もし取らなければ、延長をその絶対値で割って $S^1$ 値の延長が得られるからである。従って「延長できるか」は値域を保つ条件と合わせて考える。
:::

## Hopf の定理（球面への写像のホモトピー分類）

### 一点の周りだけに写像を集める

:::theorem[Hopf の写像度定理]{#thm-dtop-hopf-degree}
$n\ge1$ とし、$M$ を連結な閉向き付き $n$ 次元多様体とする。連続写像 $M\to S^n$ の自由ホモトピー類は写像度により $\Z$ と一対一に対応する。
:::

:::proof
まず $n=1$ なら $M$ は向き付き円である。角パラメータを $0\le t\le2\pi$ とし、写像を $\exp(i\theta(t))$ と持ち上げる。端点差は $2\pi k$ であり、線形ホモトピーで $\theta(t)$ を $\theta(0)+kt$ に変えられる。したがって類は写像度 $k$ で尽くされる。

$n\ge2$ とする。滑らかな代表を選び、正則値 $y$ の周りの小閉球 $B$ を取る。逆像の各点で局所微分同相であり、残りのコンパクト領域の像が $y$ を避けるため、$B$ を十分小さくすれば逆像は $B$ に微分同相な互いに素な球の和である。$S^n\setminus\operatorname{int}B$ を一点に潰し、$B/\partial B$ を $S^n$ と同一視する写像を後置する。この潰し写像は極角に対する非減少写像を恒等の極角に線形補間すれば恒等写像にホモトピックである。合成後の写像は、小球の外で基点に写り、各小球の商上で正または負の標準写像を与える。

この小球は、他の中心を避ける道を通じて、向きを保つ座標同位で動かせる。具体的には小球を自身の座標内で縮め、道を有限個の座標箱に分け、各箱で切断した定数ベクトル場により中心を運ぶ。必要なら球の各像をさらに縮める。同じ操作で全小球を一つの座標箱に入れて第 1 座標方向に順に並べられる。小球上のパラメータは、局所微分同相を中心で縮小して微分へ連続変形し、向きを保つ線形写像を恒等へ、向きを反転する線形写像を鏡映へ変えれば統一できる。これは小球の境界を基点に潰す形を保つ。箱の境界も基点に潰すと、各小球上の標準写像の和は、$[0,1]^n/\partial[0,1]^n$ の第 1 座標による連結で表される。鏡映を施した写像はその座標を走る道を逆行させるため、正負の連続する一対は道と逆行道を続けて走る部分を縮めて消せる。よって残るのは符号和の個数だけである。逆に標準写像または鏡映を任意個並べれば、任意の整数を実現できる。:ref[thm-dtop-degree-homotopy] により違う整数は区別される。
:::

:::example[反射との合成]
$M=S^2$ で写像度 $3$ の写像に球面の鏡映を後置すると写像度は $-3$ である。どちらも全射だが、定理によって異なるホモトピー類に属する。
:::

:::example[トーラスから球面へ]
$T^2$ の小円板以外を一点に潰すと、商円板から $S^2$ への向き付き標準写像が得られる。円板内部の正則値は一つの正の逆像を持つから写像度は $1$ である。連結閉曲面の種数を変えても、この構成は使える。
:::

### 対蹠点を同時に選ぶ

:::corollary[Borsuk–Ulam の定理]{#cor-dtop-borsuk-ulam}
連続な $f\colon S^n\to\R^n$ には $f(x)=f(-x)$ となる点 $x$ が存在する。
:::

:::proof
$n=0$ は点への写像で明らかである。$n=1$ で $h(x)=f(x)-f(-x)$ は $h(-x)=-h(x)$ を満たす。もし $h(x)\ne0$ なら $x$ と $-x$ を結ぶ道で中間値の定理を使える。$n\ge2$ で一致点がないと仮定すると、正規化した差は奇写像 $g\colon S^n\to S^{n-1}$ になる。従って実射影空間の商写像 $\bar g\colon\R P^n\to\R P^{n-1}$ が定まる。その mod $2$ 一次生成元 $a_{n-1}$ は $a_n$ に引き戻される。実際、二重被覆の持ち上げの端点が入れ替わるかどうかは基本群から $\F_2$ への準同型であり、$x$ から $-x$ へ持ち上がるループで値が $1$ なので一次生成元を与える。$\bar g$ で写したループの持ち上げの両端も $g(x),-g(x)$ なので、やはり値は $1$ である。:ref[thm-at-real-projective-ring] により $a_{n-1}^n=0$ だが $a_n^n\ne0$ である。引き戻しは積を保つので矛盾する。
:::

:::example[球面上の二つの測定値]
$S^2$ の上で連続な二つの実数値測定を組み合わせて $f=(f_1,f_2)$ とすると、両方の測定値が一致する対蹠点を一組選べる。例えば $f(x,y,z)=(x+y,z)$ では $z=0$、$x+y=0$ を満たす $(1/\sqrt2,-1/\sqrt2,0)$ とその反対点がその組である。
:::

### 一つの円板に集約したときの群演算

小球を一つの箱へ集める証明は、写像を足す操作も与える。$[0,1]^n$ の境界を基点へ写す二写像 $a,b$ を、第 1 変数の前半と後半で続けて使う写像を $a*b$ とする。境界を基点へ送るため $t=1/2$ で値は一致する。区間の切り方を動かせば $(a*b)*c$ と $a*(b*c)$ は基点を保ってホモトピックであり、定数部分は区間を縮めて消せる。第 1 変数を反転した逆写像と合わせると、各固定した残りの座標について道を進んで戻る。折返し地点を $1$ から $0$ に動かせば全体が定数に縮む。そこで $a$ の度を $d$ とすれば、$a$ と反転した $a$ の連結の度は $d-d=0$ である。一般の $a*b$ でも二つの内部から正則値の逆像を独立に取れるので $\deg(a*b)=\deg a+\deg b$ となる。滑らかな代表が必要なら継ぎ目を一定の襟にし、相対近似を施す。

:::example[二つと一つの局所球を合わせる]
閉曲面の互いに素な三つの座標円板に基点へ潰す写像を置き、第一、第二の円板で正向き、第三の円板で反転させる。残りを基点に送ると度は $1+1-1=1$ である。第三の円板を第二の近くへ移し、箱の中で第二、第三の写像の連結を逆行で消せば、第一の円板だけに局在した写像が残る。これは曲面上の異なる位置で指定した局所データが同じ大域的な類を与える例である。
:::

:::example[合成と加法の違い]
$S^2$ の度 $2$ と度 $3$ の写像を考える。合成では第 2 写像の各局所シートに第 1 写像の逆像が現れるため度は $2\cdot3=6$ となる。一方で球面を二つの円板へ潰し、別々に二写像を使うと度は $2+3=5$ である。従って二つの操作で作った写像はホモトピックでない。代数的には、合成が次数の積、$*$ が次数の和に対応する。
:::

:::example[偶奇を使う奇写像の判定]
奇写像 $a\colon S^n\to S^n$ なら $\deg a$ は奇数である。$n=1$ では角の持ち上げ $\theta$ に対し $\theta(t+\pi)-\theta(t)$ が連続で $\pi+2\pi\Z$ に値を取るので一定である。全周の角差はその二倍になり、度は奇数である。$n\ge2$ では商写像 $\bar a$ が $\R P^n$ の一次 mod $2$ 類を保ち、その $n$ 乗も保つため mod $2$ 度が $1$ となる。滑らかな奇写像の正則値 $y$ を取れば、商の $[y]$ の逆像の各軌道には $y$ へ写る点がちょうど一つある。このため $a$ と $\bar a$ の mod $2$ 度は等しい。連続な奇写像の場合は Euclid 値近似 $b$ を $(b(x)-b(-x))/2$ に替え、非零になるほど近く取って規格化すれば、奇写像としてホモトピックな滑らかな代表が得られる。
:::

### $S^0$ を別に見る理由

$S^0$ は正点と負点の二つからなる。各点は連結成分なのでホモトピーで像を変更できない。恒等、入替え、二つの定数写像という四つの写像があり、被約零次ホモロジーでの作用は順に $1,-1,0,0$ である。二つの定数写像は同じ作用を持つが、点間を結ぶ道がないのでホモトピックではない。従って $n\ge1$ における写像度による分類を $n=0$ までそのまま伸ばすことはできない。

## 交叉数と自己交叉数

:::definition[交叉数]{#def-dtop-intersection}
閉向き付き部分多様体 $A^a,B^b$ が向き付き $N^{a+b}$ 内で横断的に交わるとする。各点で $TA$ の正基底の後に $TB$ の正基底を並べて $TN$ の向きと比較し、符号を足したものを :term[交叉数]{en="intersection number" yomi="こうさすう"} $I(A,B)$ とする。ここでは交わりがコンパクトとなる場合を扱う。各点の符号を変えずに基底を取り換えられるため定義は基底によらない。
:::

例えば $A,B$ がともにコンパクトで、一方を滑らかに動かすとき、端点で横断であれば途中のホモトピーを相対的に横断化できる。具体的には動かす埋め込みを値域内の流れで摂動する。全写像を対角への横断にした上でパラメータを選べば、両者の一致を表す逆像はコンパクトな向き付き一次元多様体となる。「$TA$、$TB$、時間」の順の積の向きを入れ、法方向を先に置いてその一次元多様体を向き付ける。両端で共通の符号を除けば、境界符号は交叉符号の差になる。境界符号の和は零なので交叉数が保たれる。特に、コンパクトな $A$ の自己交叉数は、一方を法束の小さな切断のグラフに動かして求められる。切断が零切断に横断なら、交点は切断の非退化零点である。順序 $TA,TB$ の行列からグラフの接方向の $TA$ 成分を引けば、符号は切断の法微分の行列式の符号である。

:::example[トーラスの曲線]
$T^2=\R^2/\Z^2$ の曲線 $t\mapsto(2t,t)$ と $s\mapsto(s,2s)$ は原始整数ベクトルで定まる埋め込みである。接ベクトルを並べると行列式 $3$ である。交点条件 $2t-s\in\Z$、$t-2s\in\Z$ より $3t\in\Z$ で $s=2t\bmod1$ である。交点は三つとも正なので $I=3$ である。曲線の順を逆にすれば $-3$ になる。
:::

:::example[自分と交わらない押し出し]
トーラスの水平円の法束には垂直方向の非零切断があり、そのグラフは異なる水平円である。互いに素なので自己交叉数は零である。
:::

### 非退化でない固定点を局所的に数える

孤立固定点 $p$ のまわりで、像も入る座標を取り、境界に固定点がない小球 $B$ を選ぶ。$\partial B$ 上の $x-f(x)$ の方向写像の度を :term[局所固定点指数]{en="local fixed point index" yomi="きょくしょふどうてんしすう"} とする。座標を変えると、$x-f(x)$ の変換には $D\phi$ の線分上の平均が掛かる。十分小球ではこれは $D\phi(p)$ に一様に近く、可逆なまま $D\phi(p)$ へホモトープである。境界の座標の向きと値域の向きに同じ符号が掛かるため、指数は変わらない。球をさらに縮めた場合も、二つの境界の間で方向写像が延びるので度は保たれる。:ref[prop-dtop-local-degree] により、小球内で $x-f(x)$ を横断摂動すれば、局所固定点指数は非退化固定点の符号和として得られる。

:::example[退化しても符号が残る固定点]
$\R^2$ で $f(x,y)=(x-x^3,0)$ とすると、原点の $I-df$ は退化するが $x-f$ の成分は $(x^3,y)$ である。方向写像は $(x,y)$ の方向へ線形補間できるので局所指数は $1$ である。
:::

:::example[孤立していて指数零の固定点]
$f(x,y)=(x-x^2,0)$ では $x-f$ の第一成分が非負である。その方向写像は $(-1,0)$ を避けるので指数は零である。固定点が孤立しているという条件だけでは符号 $\pm1$ のどちらかに限られない。
:::

### 交叉の符号を逆像から求める

:::proposition[交叉の順序と法切断]{#prop-dtop-intersection-sign}
定義 :ref[def-dtop-intersection] の規約で $I(B,A)=(-1)^{ab}I(A,B)$ である。$A^a\subset N^{2a}$ が閉向き付きで、法束を「$TA$、法束」の順に向き付けたとする。このとき $I(A,A)$ は、法束の横断切断の零点の符号和である。
:::

:::proof
$a$ 本の接基底を $b$ 本の接基底の後へ移す置換は $ab$ 回の交換を必要とする。従って各局所符号が $(-1)^{ab}$ 倍になる。自己交叉では法座標で押し出した部分多様体を横断切断 $s$ のグラフとする。$s(p)=0$ で最初に $TA$ の基底、次いでグラフの接基底を並べると、接成分を引いた後の行列は対角ブロックが $I_a,Ds_p$ となる。よって符号は $\det Ds_p$ の符号に等しい。切断を変えた場合には二つを線形に補間し、端の横断性を保ったまま相対横断化する。切断の軌跡と零切断の逆像はコンパクトな向き付き一次元多様体なので、両端の符号和は同じである。
:::

:::example[奇数次元の自己交叉]
$a$ が奇数なら $(-1)^{a^2}=-1$ である。グラフによる小さい押し出しを $A'$ とすると、$I(A,A')$ は、自分自身を近い横断代表へ動かすという意味で自己交叉数である。$(A,A')$ を同時に管状座標内で動かすと、順序を保ったまま $(A',A)$ へ移すホモトピーを取れる。具体的には法ファイバーで第 1 を $ts$ へ、第 2 を $(1-t)s$ へ動かし、中間を横断化する。従って $I(A,A')=I(A',A)=-I(A,A')$ であり、整数として零である。例えば向き付き曲面に埋めた円に対して、平行押し出しで零となる計算をこの符号公式からも得る。
:::

:::example[対角の自己交叉]
$S^2\times S^2$ の対角の法束は $(v,w)\mapsto w-v$ により $TS^2$ と同一視できる。対角を先に、法方向を後に並べると、$(v,v),(0,w)$ の行列は対角ブロックが $I_2,I_2$ なのでこの同一視は向きを保つ。高さの勾配場 $V(p)=e_3-zp$ の零点は両極である。接方向 $u$ では両極で $dV(u)=-zu$ となり、二次元なので両方の行列式が正である。従って自己交叉数は $2$ となる。押し出す前の対角同士はすべての点で一致するが、押し出しの切断で二つの点の計数に置き換えられる。
:::

:::example[実二次元の法束の曲がりが残る例]
$\C P^2$ の複素直線 $A=\{z_2=0\}$ を考える。別の直線 $B=\{z_2=\eps z_0\}$ は $\eps\ne0$ に対し $A$ と $[0:1:0]$ でのみ交わる。そこでアフィン座標 $(u,v)=(z_0/z_1,z_2/z_1)$ を取ると、二直線は $v=0$ と $v=\eps u$ である。接ベクトルを複素列として並べた行列は $\begin{pmatrix}1&1\\0&\eps\end{pmatrix}$ で、実行列式は $|\eps|^2>0$ である。従って交叉数は $1$ であり、$\eps\to0$ の族は $B$ が $A$ の押し出しであることを示す。この例の法束には非零切断を取れない。もし取れれば近い押し出しと $A$ は交わらず、自己交叉数が零になるからである。
:::

### 交叉の保存にはコンパクトな軌跡を使う

:::example[無限遠を通って移る交点]
平面内の水平軸 $A=\{y=0\}$ と、直線 $B_s=\{y=sx-1\}$ をともに $x$ の増加方向に向ける。$s\ne0$ では交点は $(1/s,0)$ で、接ベクトルの行列式は $s$ となる。$s=0$ では平行なので交点は空である。各時刻の交叉がコンパクトでも、変形全体の交叉軌跡は無限遠へ逃げる。従って $I(A,B_s)$ が $-1$ から $1$ へ変わることは、コンパクトなコボルディズムの保存則と矛盾しない。
:::

:::example[射影直線と交叉の重複]
$\C P^2$ の直線 $A=\{z_2=0\}$ と二次曲線 $B_a=\{z_0z_1=z_2^2+a z_1^2\}$ を考える。$a\ne0$ でも $a=0$ でも、交点は $[1:0:0]$ と $[a:1:0]$ である。前者の座標 $(u,v)=(z_1/z_0,z_2/z_0)$ では $B_a$ の式は $u-v^2-a u^2=0$ で、その $u$ 微分は原点で $1$ である。後者の座標 $(u,v)=(z_0/z_1-a,z_2/z_1)$ では式は $u-v^2=0$ である。どちらも $v=0$ と横断し、複素の向きによる符号は正なので交叉数は $2$ である。これに対し二次曲線 $z_1^2=z_0z_2$ では $A$ との交点が $[1:0:0]$ に集まり、$v=u^2$ と $v=0$ の接線が一致する。$z_1^2-\eps z_0^2=z_0z_2$ へ摂動すると $u=\pm\sqrt\eps$ の二つの正の交点に分かれる。退化した一交点の近くの交叉指数は $2$ となる。
:::

## Lefschetz 数と Lefschetz の不動点定理

### 対角とグラフ

$X$ を連結閉向き付き $n$ 次元多様体とする。写像 $f\colon X\to X$ に対し :term[Lefschetz 数]{en="Lefschetz number" yomi="れふしぇっつすう"} を $L(f)=\sum_i(-1)^i\tr(f^*|H^i(X;\R))$ と定める。グラフを第 1 座標で向き付け、対角も同様とする。固定点が非退化とは $I-df_p$ が可逆であることをいう。グラフと対角をこの順に並べた接行列は
$$
\begin{pmatrix}I&I\\df_p&I\end{pmatrix}
$$
なので局所交叉符号は $\sgn\det(I-df_p)$ である。

:::theorem[滑らかな多様体の Lefschetz 不動点定理]{#thm-dtop-lefschetz}
連続写像 $f\colon X\to X$ に対し、$L(f)\ne0$ なら固定点がある。固定点の近傍で $f$ が滑らかで、固定点がすべて非退化なら $L(f)=\sum_{f(p)=p}\sgn\det(I-df_p)$ である。
:::

:::proof
:ref[prop-at-cup-pairing] の双対対合と :ref[thm-at-kunneth] を使う。以下 $\int_X a$ はコホモロジー類 $a$ の基本類での評価を表す。$u_{ij}$ を $H^i(X;\R)$ の基底、$v_{ij}$ を $\int_X u_{ij}v_{ik}=\delta_{jk}$ となる双対基底とする。対角の法向きは「対角の接方向、法方向」の順で決める。対角の小さな閉法ディスク束を $D$、その境界を $S$ とする。:ref[thm-at-poincare-lefschetz] で、すべての $c\in H^n(D;\R)$ について $\langle c\,\tau,[D,S]\rangle=\langle c,[\Delta]\rangle$ となる相対類 $\tau\in H^n(D,S;\R)$ を取る。この積の順は底の向きを先に置く規約に対応する。

$\tau$ の各法ディスクへの制限は正の相対生成元である。実際、底の一点 $p$ に台を持つ局所最高次類を、点の補集合に相対的な類として円板束に引き戻す。その絶対類を $c$ に使うと右辺は $1$ である。積を評価するときは、その点の近傍と法ディスクの積に切除でき、底の局所生成元が先にあるので、評価は法ディスクへの $\tau$ の制限の係数となる。従ってその係数は $1$ である。$D\setminus\Delta$ は $S$ へ変形収縮するので、$\tau$ は切除で $H^n(X\times X,(X\times X)\setminus\Delta;\R)$ の類を与える。その絶対群への像を $\delta$ とする。相対カップ積の自然性と基本類の切除によって $\int_{X\times X}c\,\delta=\int_X\Delta^*c$ を得る。積の第 1、第 2 射影を $\pi_1,\pi_2$ とすると、
$$
\delta=\sum_{i,j}(-1)^i\,\pi_1^*u_{ij}\,\pi_2^*v_{ij}
$$
である。実際、$\delta$ を右に置いて $\pi_1^*a\,\pi_2^*b$ との積をとる。$\deg a=n-i$、$\deg b=i$ のとき、第 2 因子の $b$ を $u_{ij}$ の前から後へ移す符号 $(-1)^i$ が係数を打ち消す。積分は $\sum_j\int_X a u_{ij}\int_X b v_{ij}=\int_X ab$ となる。他の次数では対応する項は零である。Künneth の公式と双対性がこの類を一意に決める。

グラフへの引き戻しの評価は $\sum_{i,j}(-1)^i\int_X u_{ij} f^*v_{ij}$ である。対角の法射影は $(a,b)\mapsto b-a$ であり、グラフでの微分は $df-I$ である。従ってグラフと対角の順の交叉数に合わせるには $(-1)^n$ を掛ける。よって $(-1)^n\int_{\Gamma_f}\delta=\sum_{i}(-1)^{n+i}\tr(f^*|H^{n-i})=L(f)$ となる。固定点が非退化なら、グラフによる相対類の引き戻しを固定点ごとの小球に切除できる。法射影の局所写像が可逆であるため、各小球の評価は $\sgn\det(df-I)$ となり、$(-1)^n$ を掛ければ章頭の行列計算と一致する。固定点がなければグラフは対角の補空間を経由し、$\delta$ の制限は相対群の完全列により零である。固定点の存在を導くこの部分は連続な $f$ にも適用できる。
:::

:::corollary[孤立固定点の指数和]{#cor-dtop-lefschetz-local-index}
$n\ge1$ とし、$X$ は上の定理と同じ仮定を満たすとする。連続写像 $f\colon X\to X$ の固定点がすべて孤立していれば、各点の局所固定点指数の和は $L(f)$ に等しい。
:::

:::proof
固定点集合は閉かつ離散なので有限である。相対類 $\tau$ のグラフへの引き戻しを、固定点を囲む互いに素な小球 $B_p$ に切除する。対角の局所法座標を $(x,y)\mapsto y-x$ と取ると、$B_p$ での引き戻しは $f(x)-x$ が法円板の相対生成元に及ぼす作用である。その係数は、相対ホモロジーから境界の被約ホモロジーへの接続と自然性を使うと、$\partial B_p$ 上の方向写像の度になる。$x-f(x)$ へ替える符号は $(-1)^n$ であり、これは $L(f)$ とグラフの評価を結び付ける符号と等しい。各小球の寄与を足せば主張が従う。
:::

:::example[トーラスの整数線形写像]
$A=\diag(2,3)$ による $T^2$ の写像では $L=1-(2+3)+6=2$ である。固定点の条件は $x\in\Z$、$2y\in\Z$ なので二点であり、各点で $\det(I-A)=2>0$ なので局所符号は正である。
:::

:::example[固定点があっても Lefschetz 数が零の場合]
$S^1$ の恒等写像では $H^0,H^1$ への作用がともに恒等で $L=1-1=0$ である。すべての点が固定点ではあるが、局所行列式の計数を使うには固定点が非退化である必要がある。
:::

### 交代跡の計算を小さい行列に落とす

:::proposition[トーラスの Lefschetz 数]{#prop-dtop-lefschetz-torus}
整数 $n$ 次行列 $A$ が定める $T^n$ の写像 $f_A$ について $L(f_A)=\det(I-A)$ である。$\det(I-A)\ne0$ なら固定点数は $|\det(I-A)|$ であり、各固定点の局所指数は $\sgn\det(I-A)$ である。
:::

:::proof
一次コホモロジー上の作用は標準座標の一次形式を基底とすると $A$ の転置である。トーラスの環はこの一次空間の外積代数なので、第 $k$ 次コホモロジー上の作用の跡は $A$ の $k$ 次主小行列式の和である。実際、基底ウェッジ $e_{j_1}\wedge\cdots\wedge e_{j_k}$ の像のうち同じ基底の係数が、その行と列を選んだ行列式となる。$\det(I-A)$ を各列から恒等の列か $-A$ の列かを選ぶように展開すると、この主小行列式が $(-1)^k$ 倍で現れる。これが交代跡の式である。

$B=I-A$ が可逆なら、固定点は $Bx\in\Z^n$ を満たす $x\bmod\Z^n$ であり、群として $B^{-1}\Z^n/\Z^n\simeq\Z^n/B\Z^n$ である。$B\Z^n$ の基本平行体の体積は $|\det B|$、$\Z^n$ の基本平行体の体積は $1$ である。一つの前者の基本領域を、境界を除いて後者の並進の剰余類ごとに切り分ければ、包含する剰余類数は体積比である。従って固定点数は $|\det B|$ である。全固定点で微分は $A$ なので、:ref[thm-dtop-lefschetz] の局所符号は共通である。
:::

:::example[負の指数の固定点が複数ある]
$A=\begin{pmatrix}3&1\\1&1\end{pmatrix}$ では $I-A=\begin{pmatrix}-2&-1\\-1&0\end{pmatrix}$ の行列式が $-1$ である。実際、$x=0$、$y=0$ が唯一の固定点で、指数は $-1$ となる。$A$ を $\diag(4,-1)$ に替えると $I-A=\diag(-3,2)$ である。固定点は $x=0,1/3,2/3$ と $y=0,1/2$ の組の六点で、全ての符号が負となる。交代跡は $1-3-4=-6$ で計数と一致する。
:::

:::example[同じ Lefschetz 数で固定点集合が変わる]
$T^2$ で $f(x,y)=(2x,y)$ と $g(x,y)=(2x,y+1/2)$ を比較する。両者は第 2 成分の平行移動を連続に動かせばホモトピックであり、誘導するコホモロジー写像も同じである。$L=1-(2+1)+2=0$ となる。$f$ の固定点は $x=0$ の円全体であるが、$g$ の第 2 成分には固定点がない。Lefschetz 数零のときには、固定点が存在する場合と存在しない場合がどちらもある。
:::

:::example[球面の固定点を次数から求める]
$S^n$ では零次と $n$ 次だけが実コホモロジーを持つので $L(f)=1+(-1)^n\deg f$ である。例えば $S^2$ の鏡映は度 $-1$ で $L=0$ となり、固定点は大円全体である。同じ $L$ を持つ対蹠写像には固定点がない。これに対し回転角が $0$ でない $z$ 軸回転は度 $1$ なので $L=2$ である。固定点は両極であり、接平面上の回転 $R_\theta$ に対して $\det(I-R_\theta)=2-2\cos\theta>0$ だから、両極の指数は $+1$ である。
:::

### 局所指数を調べるための摂動

:::example[二根が消える退化固定点]
座標近傍で $F_a(x,y)=(x-x^2+a,y/2)$ とする。固定点条件は $x^2=a,y=0$ であり、$a>0$ で二点が現れる。その点で $I-dF_a=\diag(2x,1/2)$ なので二つの行列式は $\pm\sqrt a$ である。$a=0$ の原点では $x-F_0$ の第一成分が $x^2\ge0$ であり、方向写像が半円内に入るから局所度は零である。$a<0$ では固定点が消える。大域的な写像にこの局所モデルを入れる場合、摂動の台を小球に限定すれば小球外の固定点の寄与を変えずに、この退化点の寄与だけを求められる。
:::

:::example[積写像の固定点指数]
$T^2=S^1\times S^1$ で $(z,w)\mapsto(z^3,\overline w)$ を考える。第一因子の固定点は $z=\pm1$、第二因子の固定点は $w=\pm1$ であり、四点がある。角座標での $I-df$ は $\diag(-2,2)$ なので各指数は $-1$ である。コホモロジーからは各円の Lefschetz 数が $1-3=-2$ と $1-(-1)=2$ となり、積が $-4$ である。一般の積写像でも、Künneth 分解で次数 $i+j$ の跡は各テンソル因子の跡の積になり、$(-1)^{i+j}$ を分けて和を取ると二つの Lefschetz 数の積を得る。
:::

## 回転数と絡み数

### 平面の角と空間の方向

滑らかな正則閉曲線 $\gamma\colon S^1\to\R^2$ の :term[回転数]{en="rotation number" yomi="かいてんすう"} は単位接ベクトル写像 $\gamma'/\norm{\gamma'}$ の写像度である。曲線が自己交叉しても速度が零でなければ定義できる。

:::proposition[回転数の積分]{#prop-dtop-rotation}
$\gamma(t)=(x(t),y(t))$ を $0\le t\le2\pi$ で一周する向き付き表示とすると、
$$
\operatorname{rot}(\gamma)=\frac{1}{2\pi}\int_0^{2\pi}\frac{x'y''-y'x''}{(x')^2+(y')^2}\,dt .
$$
:::

:::proof
単位接ベクトルの角を区間上で $\theta(t)$ に持ち上げる。$\gamma'=\norm{\gamma'}(\cos\theta,\sin\theta)$ を微分して分子を行列式で計算すると $\norm{\gamma'}^2\theta'$ になる。積分は $\theta(2\pi)-\theta(0)$ を $2\pi$ で割るため、写像度に一致する。
:::

互いに素な向き付き閉曲線 $\gamma,\eta$ について、:term[絡み数]{en="linking number" yomi="からみすう"} を
$$
G(s,t)=\frac{\eta(t)-\gamma(s)}{\norm{\eta(t)-\gamma(s)}}\colon S^1\times S^1\to S^2
$$
の写像度と定める。積の順序は $\gamma,\eta$ であり、球面の向きは外向きとする。$w=\eta-\gamma$ と書くと $\det(G,G_s,G_t)=\det(w,-\gamma',\eta')/\norm w^3$ である。正規化の微分で $w$ に平行な補正が生じるが行列式では消える。積分で写像度を表す公式を用いると、絡み数はこの行列式の一周積分を $4\pi$ で割った値となる。空間内の変形で曲線同士が出会わなければ $G$ のホモトピーがあるから値は保たれる。

:::example[楕円と反転]
$\gamma(t)=(2\cos t,\sin t)$ の分子は $2$ である。正の軸比を $2$ から $1$ に動かす間、速度は消えないので回転数は $1$ である。時間を逆にたどると角写像の次数が反転して $-1$ になる。
:::

:::example[絡んだ二円]
$\gamma(s)=(\cos s,\sin s,0)$、$\eta(t)=(1+\cos t,0,\sin t)$ を考える。$G=e_3$ の条件は $\sin s=0$、$1+\cos t=\cos s$、$\sin t>0$ である。解は $s=0,t=\pi/2$ のみで、$w=e_3$、$-\gamma'=-e_2$、$\eta'=-e_1$ だから局所行列式は $-1$ である。よってこの順序と向きで絡み数は $-1$ である。
:::

### 絡み数を張る曲面との交点に移す

:::proposition[絡み数と張る曲面の交叉数]{#prop-dtop-linking-surface}
$\gamma$ が向き付きコンパクト曲面 $A\subset\R^3$ の向き付き境界であり、$\eta$ は $\gamma$ と互いに素で $A$ の内部に横断的とする。方向写像を $G=(\eta-\gamma)/\norm{\eta-\gamma}$ と取る規約では $\operatorname{lk}(\gamma,\eta)=I(A,\eta)$ である。
:::

:::proof
$A\times S^1$ に積の向きを入れ、$F(p,t)=\eta(t)-p$ と置く。零点の微分の列は $(-u,-v,\dot\eta)$ であり、$(u,v)$ を $TA$ の正基底に取ると、符号は $I(A,\eta)$ の局所符号に等しい。境界 $\partial(A\times S^1)$ では外向き優先の積の向きにより $F$ の方向写像が $G$ になる。内部の零点の周囲の小球を除けば方向写像は全域に定義される。共通の正則値の逆像を取り、向き付き端点を数えると、外境界の次数は小球の次数の総和である。各小球の次数は可逆な線形近似の符号だから主張が従う。
:::

:::example[円板で絡み数を再計算する]
前の二円で、$\gamma$ が張る $xy$ 平面の単位円板を上向き法線で向き付ける。$\eta(t)=(1+\cos t,0,\sin t)$ が平面と交わるのは $t=0,\pi$ であり、点 $(2,0,0)$ は円板外、点 $(0,0,0)$ は円板内部である。内部の交点では $\dot\eta=(0,0,-1)$ なので符号は $-1$ である。方向写像で得た $-1$ と一致する。
:::

### Hopf ファイブレーションの二ファイバー

複素単位球面 $S^3\subset\C^2$ から直線を取る写像 $S^3\to\C P^1$ は、単位複素数倍をファイバーとする。座標軸に対応する二つのファイバーは $\gamma(s)=(e^{is},0)$ と $\eta(t)=(0,e^{it})$ である。これらを $\R^4$ に置くと、互いに直交する二つの平面にある円だが、周囲を $S^3$ として見ると絡んでいる。

:::example[一方の円を張る半球]
$S^3$ を $(x_1,y_1,x_2,y_2)$ の順の向きから外法線優先で向き付ける。$y_2=0$、$x_2\ge0$ の半球 $A$ は $\gamma$ を境界とする円板である。$A$ の $x_2>0$ では $(x_1,y_1)$ が座標であり、その順で向き付けると境界の角 $s$ が増える方向である。$\eta$ との共通点は $t=0$ の $(0,0,1,0)$ だけである。そこで $A$ の正基底は $(e_1,e_2)$、$\eta$ の接方向は $e_4$ である。球面の外法線 $e_3$ を先に置いた $(e_3,e_1,e_2,e_4)$ は周囲の正基底と同じ向きなので交叉符号は $+1$ である。曲面と二円を避けた一点から立体射影すれば $\R^3$ 内での同じ交叉計算になるよう向きを選べる。よってこの組は絡み数 $+1$ を持つ。
:::

### 回転数と点の周りの巻き数

回転数は接線の向きに対する写像度である。これに対し、平面の一点 $p$ に対する巻き数は位置の方向写像 $(\gamma-p)/\norm{\gamma-p}$ の写像度である。前者を定義するには速度が非零であることを、後者を定義するには $\gamma$ が $p$ を避けることを要求する。

:::example[巻き数が零でも回転数が残る]
$\gamma(t)=(3+2\cos t,\sin t)$ とする。原点に対する位置の第一成分は $1$ 以上なので、方向写像は右半円に含まれ巻き数は零である。一方、速度は $(-2\sin t,\cos t)$ であり、標準円の接ベクトルを向きを保つ線形写像で伸ばしたものなので回転数は $1$ である。中心 $(3,0)$ に対する巻き数は位置が $(2\cos t,\sin t)$ となるため $1$ である。従って巻き数には基準点が必要だが回転数には不要である。
:::

:::example[八の字の正則閉曲線]
$\gamma(t)=(\sin t,\sin 2t)$ とする。速度 $(\cos t,2\cos 2t)$ は同時に零にならない。接ベクトルが上向き $e_2$ になるには $\cos t=0$ かつ $\cos 2t>0$ が必要だが、$t=\pi/2,3\pi/2$ では $\cos 2t=-1$ である。よって $e_2$ は空逆像を持つ正則値であり、回転数は零である。自己交点があっても定義は成立する。これに対し標準円の回転数は $1$ なので、速度が消えない閉曲線の変形で標準円へ移すことはできない。
:::

:::example[多重にたどる楕円の積分]
$\gamma(t)=(a\cos kt,b\sin kt)$、$a,b>0$、$k$ を非零整数とする。:ref[prop-dtop-rotation] の分子は $abk^3$、分母は $k^2(a^2\sin^2kt+b^2\cos^2kt)$ である。$k=1$ では一象限の積分を $u=\tan t$ で計算すると
$$
\int_0^\infty \frac{ab}{a^2u^2+b^2}\,du=\frac{\pi}{2}.
$$
四象限を合わせれば $2\pi$ である。$k>0$ では周回の回数により全積分が $2\pi k$ になる。$k<0$ では逆方向に $|k|$ 回たどるため同じ式で負になる。例えば $a=2,b=3,k=-4$ なら回転数は $-4$ である。
:::

### 絡み数の対称性と一回の通過

:::proposition[絡み数の符号規則]{#prop-dtop-linking-sign}
定義の順序を入れ替えても $\operatorname{lk}(\gamma,\eta)=\operatorname{lk}(\eta,\gamma)$ である。一方だけの向きを反転すれば絡み数は負になり、両方を反転すれば元の値になる。
:::

:::proof
因子の入替え $S^1\times S^1\to S^1\times S^1$ は二つの一次元接方向を交換するため度 $-1$ である。方向ベクトルの差の順も逆になり、$S^2$ の対蹠写像の度が $-1$ なので、二つの符号は相殺される。一方の向きだけを変える場合、定義域の向きだけが反転し、標的側には追加の変換がない。両方を反転すれば二つの符号が相殺される。
:::

:::example[二円の中心を移して交差を越える]
$\gamma(s)=(\cos s,\sin s,0)$ と $\eta_a(t)=(a+\cos t,0,\sin t)$ を取り、$a>0$ とする。$\eta_a$ が $\gamma$ の張る円板の平面を横切る点は $x=a+1,a-1$ である。第 1 点は常に円板の外であり、第 2 点は $0<a<2$ のときに限り内部にある。そこで速度の第 3 成分は $-1$ だから、絡み数は $0<a<2$ で $-1$、$a>2$ で $0$ になる。ちょうど $a=2$ において二曲線が交わり方向写像の分母が零となる。この時刻を通過するので、一方から他方へ移す族は絡み数を保つ変形の仮定を満たさない。
:::

:::example[円板を横切っても符号が相殺される]
$\gamma$ を半径 $3$ の水平円、$\eta(t)=(\cos t,0,\sin t)$ を垂直な単位円とする。垂直円は水平円板の内部を $x=1$ と $x=-1$ で横切る。前者の速度の第 3 成分は $+1$、後者は $-1$ であり、交叉数は零である。幾何的に二回横切ることだけでは、絡み数の絶対値が二になるとは限らない。符号付きで足すとこの例のように消えることがある。
:::

:::example[二重被覆で絡み数を増やす]
絡んだ二円のうち $\eta$ を $\eta(kt)$ として $k$ 回たどる。方向写像は $(s,t)\mapsto(s,kt)$ との前合成になるため、新しい写像度は $k$ 倍である。例えば一周で $-1$ の向きなら $k=-3$ で $+3$ になる。この曲線は埋め込みではなく多重に被覆する閉曲線だが、もう一方と互いに素である限り方向写像による計数は定義できる。実際、円板との交点を時刻で数えると三回とも向きが反転し、各局所符号は正である。
:::

### 平面の巻き数を零点計数に使う

:::example[複素多項式の境界写像]
$P(z)=z^3-1$ を $|z|=2$ に制限する。この円周では $|z^3|=8>1$ なので、$z^3-s$ は $0\le s\le1$ の全時刻で非零である。従って $P/|P|$ の度は $z^3/|z^3|$ と同じく $3$ である。三つの根では微分 $3z^2$ は可逆な複素線形写像だから、:ref[prop-dtop-local-degree] の局所符号はすべて正である。同じ境界上で $P(z)+az$ と摂動すると、$2|a|<7$ であれば非零条件が保たれる。従って三つの単根を維持できる範囲では根は依然三つであり、重根があるときにも局所度の総和は $3$ である。例えば $a=-3$ では半径 $2$ の境界上で $|az|=6<7$ となり、根の配置が変わっても全度は変わらない。
:::

:::example[巻き数に対する零点と極]
円 $|z|=2$ の上で $f(z)=(z-1)^2/(z+1)$ を考える。分子と分母は円周上で非零である。$z-1$ と $z+1$ はそれぞれ $z$ へ線形に変形しても非零なので、方向写像の角の変化は各 $2\pi$ である。従って商の角は $2(2\pi)-2\pi=2\pi$ だけ増え、巻き数は $1$ となる。内部の $z=1$ に次数二の零点があり、$z=-1$ の小円周では分母の角が一周するので局所寄与は $-1$ となる。極を含めて穴あき領域で方向写像を延長すれば、外周の巻き数は $2-1$ と再計算できる。
:::

### 平面への射影から絡み数を数える

:::proposition[異成分の交差符号と絡み数]{#prop-dtop-link-crossings}
$\gamma$ と $\eta$ を互いに素な向き付き正則閉曲線とする。両方の値 $\pm n$ が方向写像 $G$ の正則値となる単位ベクトル $n$ を取り、$n^\perp$ を $(n,e_1,e_2)$ が正になる向きで向き付ける。射影で二曲線が一致する各パラメータ対に
$$
-\sgn\inner{\eta-\gamma}{n}\cdot
 \sgn\det(\pi\gamma',\pi\eta')
$$
を割り当てると、絡み数はこの符号和の半分である。
:::

:::proof
射影で一致するのは差 $\eta-\gamma$ が $n$ に平行なときである。曲線が互いに素なので差は非零であり、一致対は $G^{-1}(n)$ と $G^{-1}(-n)$ に分かれる。方向写像を微分するとその接平面への列は正の倍率を除いて $-\pi\gamma',\pi\eta'$ である。$G=n$ のときは指定した平面向きと球面向きが一致し、列の最初の負号が局所符号に入る。$G=-n$ では球面の外向き法線が $-n$ なので、接平面の向きが逆になり、これが高さの符号の反転に当たる。各正則値の符号和はともに $\deg G$ だから、両方を足して二で割ればよい。Sard の定理により二つとも正則になる $n$ を選べる。
:::

:::example[二つの射影交差から負の絡み数を得る]
$\gamma(s)=(\cos s,\sin s,0)$、$\eta(t)=(1+\cos t,0,\sin t)$ を取り、$n=(0,1,1)/\sqrt2$ とする。正向きの平面座標は $(x,(y-z)/\sqrt2)$ である。射影一致は $\cos s=1+\cos t$、$\sin s=-\sin t$ である。二式から $\cos t=-1/2$ となり、解は $(s,t)=(-\pi/3,2\pi/3),(\pi/3,4\pi/3)$ である。第一の点では平面行列式が $\sqrt3/(2\sqrt2)$、高さの差が $\sqrt{3/2}$ で、第二では両方とも負で同じ絶対値になる。従って両符号は $-1$ であり、半和は $-1$ である。この計算は円板を用いた交叉の符号と一致する。
:::

## 演習問題

::::exercise{level=basic #exr-dtop-degree-1}
$z\mapsto z^7$ の整数写像度と mod $2$ 写像度を求めよ。

:::solution
$1$ の逆像は七つで、角の導関数 $7$ がすべて正である。よって整数値は $7$、mod $2$ では $1$ である。
:::
::::

::::exercise{level=basic #exr-dtop-degree-2}
$S^4$ の対蹠写像の写像度を求めよ。

:::solution
ambient 空間の次元は $5$ であり、行列式は $(-1)^5=-1$ である。外向き法線が外向き法線に写るので球面上の局所符号も $-1$ である。
:::
::::

::::exercise{level=basic #exr-dtop-degree-3}
トーラス上で方向 $(1,3)$ と $(2,1)$ の原始曲線の交叉数を求めよ。

:::solution
方向を列に並べた行列式は $1-6=-5$ である。交点条件から $t=2s$、$3t=s\bmod1$、従って $5s=0\bmod1$ である。五点で符号はすべて負なので $-5$ である。
:::
::::

::::exercise{level=basic #exr-dtop-degree-4}
$S^2$ の恒等写像の Lefschetz 数を求めよ。

:::solution
$H^0,H^2$ は一次元で両方の作用が恒等である。奇数次は零なので $L=1+1=2$ である。
:::
::::

::::exercise{level=advanced #exr-dtop-degree-5}
$n\ge1$ とし、連続写像 $f\colon S^n\to S^n$ が固定点を持たないとする。写像度を求めよ。

:::solution
$H_t(x)=((1-t)f(x)-tx)/\norm{(1-t)f(x)-tx}$ とする。分母が零になるなら、単位長より $t=1/2$、$f(x)=x$ となるため矛盾する。これは $f$ と対蹠写像のホモトピーである。よって写像度は $(-1)^{n+1}$ である。
:::
::::

::::exercise{level=advanced #exr-dtop-degree-6}
トーラスの平行移動が固定点を持たなくても恒等写像にホモトピックであることを示し、Lefschetz 数を求めよ。

:::solution
零でない $a\bmod\Z^2$ による移動を $t a$ に線形補間すると恒等写像へのホモトピーを得る。ホモトピー不変性で各コホモロジーへの作用は恒等である。各次元は $1,2,1$ なので $L=1-2+1=0$ である。
:::
::::

::::exercise{level=advanced #exr-dtop-degree-7}
$\gamma(t)=(\sin t,\sin2t)$ の回転数を求めよ。

:::solution
単位接写像が $e_2$ を取るには $\cos t=0$ かつ $2\cos2t>0$ が必要である。しかし $\cos t=0$ では $\cos2t=-1$ である。したがって $e_2$ の逆像は空で回転数は零である。
:::
::::

::::exercise{level=advanced #exr-dtop-degree-8}
絡み数が二曲線の順序交換で変化しないことを示せ。

:::solution
積の因子交換 $S^1\times S^1\to S^1\times S^1$ は向きを変える。差ベクトルの順序を逆にする操作は $S^2$ の対蹠写像で写像度 $-1$ である。二つの操作の積で符号は $1$ となる。
:::
::::

## 確認テスト

::::quiz{answer="-3" tol="1e-6"}
$z\mapsto z^{-3}$ の整数写像度はいくつか。

:::explanation
任意の値の逆像は三点あり、角の導関数 $-3$ はすべて負である。よって $-3$ である。
:::
::::

::::quiz{answer="1" tol="1e-6"}
整数写像度が $-5$ の写像の mod $2$ 写像度はいくつか。

:::explanation
局所符号 $1,-1$ はともに mod $2$ で $1$ なので、$-5\bmod 2=1$ である。
:::
::::

::::quiz
互いにホモトピックな閉向き付き多様体間の写像では何が一致するか。

- [x] 同じ向きで計算した写像度。
- [ ] 任意の正則値の逆像の点数。
- [ ] 各点での微分行列式。

:::explanation
ホモトピーの横断逆像の境界符号和が零なので写像度が一致する。異なる符号の点が対で生成され得るため点数までは保たれない。
:::
::::

::::quiz{answer="6" tol="1e-6"}
$T^2$ に $\diag(3,4)$ を作用させたときの Lefschetz 数はいくつか。

:::explanation
$H^0,H^1,H^2$ での跡が $1,7,12$ なので $1-7+12=6$ である。
:::
::::

::::quiz
向き付き $S^2$ の対蹠写像に関する正しい記述を選べ。

- [x] 写像度は $-1$ である。
- [x] 固定点を持たない。
- [ ] Lefschetz 数は $2$ である。

:::explanation
$\R^3$ の $-I$ の行列式は $-1$ である。$x=-x$ を満たす単位点はなく、Lefschetz 数は $1-1=0$ である。
:::
