## この章の目標

- Sard の定理を次元による帰納法と Taylor 展開から証明する。
- 正則値の逆像を局所座標で記述する。
- 滑らかな近似とはめ込み、埋め込みの次元条件を区別する。
- 射影が失敗する方向を接線と割線から求める。

## 測度 0 集合と Sard の定理

逆像を方程式の解集合として扱うには、方程式の微分が独立になる値を選びたい。Sard の定理は、独立性が一か所でも破れる値の集合を測度で評価する。

### 零集合と座標

$\R^n$ の集合 $A$ が :term[測度零]{en="measure zero" yomi="そくどぜろ"} であるとは、任意の $\eps>0$ に対して体積の総和が $\eps$ 未満の可算個の直方体で覆えることをいう。Lebesgue 測度の定義は :ref[def-meas-lebesgue] を参照する。可算和は第 $j$ 集合の被覆に $\eps 2^{-j}$ を割り当てれば零集合になる。滑らかな座標変換は、定義域をコンパクトな小立方体で可算被覆すると、各立方体で微分が有界なので Lipschitz である。辺長 $h$ の立方体の像は辺長 $C h$ の立方体に収まる。したがって同次元では零集合を零集合に写し、多様体上でも零集合を座標によらず定義できる。

$f\colon M^m\to N^n$ の微分 $df_p$ が全射でない点を臨界点とする。その集合を $\mathcal C(f)$ と書く。以下、多様体は Hausdorff、第二可算、滑らかであり、境界は特に断らない限り空とする。

:::definition[はめ込み、埋め込み、固有写像]{#def-dtop-embedding}
すべての点で微分が単射である滑らかな写像を :term[はめ込み]{en="immersion" yomi="はめこみ"} という。像への同相でもあるはめ込みを :term[埋め込み]{en="embedding" yomi="うめこみ"} という。また、コンパクト集合の逆像がコンパクトな写像を :term[固有写像]{en="proper map" yomi="こゆうしゃぞう"} という。
:::

:::lemma[低次元からの像]{#lem-dtop-small-image}
$m<n$ なら滑らかな写像 $f\colon M^m\to N^n$ の像は測度零である。
:::

:::proof
定義域と値域の座標を選び、定義域を座標内のコンパクトな立方体で可算被覆する。辺長 $L$ の立方体を各軸で $k$ 分割する。微分の上界を $B$ とすると、一片の像は直径 $\le B\sqrt m L/k$ なので、その全体を体積 $O(k^m k^{-n})$ で覆える。$m<n$ により上界は零に収束する。$m=0$ の場合は可算個の点の像である。
:::

:::theorem[Sard の定理]{#thm-dtop-sard}
$n\ge1$ とする。滑らかな写像 $f\colon M^m\to N^n$ の臨界値集合 $f(\mathcal C(f))$ は測度零である。
:::

:::proof
座標と可算性により、開集合 $U\subset\R^m$ から $\R^n$ への写像で示せばよい。定義域の次元 $m$ について、すべての $n\ge1$ を同時に帰納する。$m=0$ は低次元の場合である。$C_j$ を $f$ の全成分について $1$ 階から $j$ 階までの偏導関数が消える集合とする。$C=\mathcal C(f)$ は $C_1\supset C_2\supset\cdots$ を含む。$C\setminus C_1$、$C_j\setminus C_{j+1}$、最後に十分大きい $j$ の $C_j$ を別々に調べる。

まず $p\in C\setminus C_1$ とする。成分と座標を入れ替えると $\partial_1f_1(p)\ne0$ である。逆関数定理により $(f_1(x),x_2,\ldots,x_m)$ を座標に取り、局所的に $f(t,u)=(t,g_t(u))$ と書ける。この座標では $\rank df=1+\rank d_ug_t$ である。$n=1$ ならこの場合に臨界点はない。$n>1$ なら第 $t$ 切片における臨界値の像は $g_t$ の臨界値に含まれ、帰納法により零集合である。Fubini を適用するため、座標近傍をコンパクトな小箱 $K$ で可算被覆し、閉集合 $C\cap K$ のコンパクトな像を使う。その各切片は測度零であるから像も測度零である（:ref[thm-meas-fubini]）。

次に $p\in C_j\setminus C_{j+1}$ とする。ある $j$ 階偏導関数 $h$ は $C_j$ 上で消え、$dh_p\ne0$ である。よって $C_j$ の近傍部分は滑らかな超曲面 $h=0$ に含まれる。$C_j$ 上では $df=0$ なので、$f|_{h=0}$ の微分も零である。帰納法をこの制限写像に用いると、その臨界値集合は測度零である。両段階で必要な座標近傍は第二可算性によって可算個に絞れる。

最後に $(j+1)n>m$ となる $j$ を取り、$K\subset U$ をコンパクトな立方体とする。$K$ を $k^m$ 個の小立方体に分け、各小立方体が $C_j$ と交わるなら交点 $p$ を一つ取る。$p$ における $j$ 次までの Taylor 項は定数項を除いて消える。$K$ 上で $j+1$ 階偏導関数は有界なので、小立方体内の $q$ について $\norm{f(q)-f(p)}\le D k^{-(j+1)}$ となる。像は総体積 $O(k^{m-(j+1)n})$ の箱で覆えるから、$f(C_j\cap K)$ は零集合である。$U$ はこのような $K$ で可算被覆できる。以上で $C$ の像が測度零となる。
:::

:::example[次元だけで測度が決まる場合]
$t\mapsto(t,t^2,t^3)$ の像は $\R^3$ で測度零である。例えば $|t|\le2$ で各成分の微分の絶対値は $1,4,12$ 以下であり、長さ $1/k$ の区間の像は辺長 $24/k$ の立方体に収まる。区間は $4k$ 個に分けられるので、体積上界は $4\cdot24^3/k^2$ である。
:::

:::example[切片への帰着]
$f(x,y)=(x,y^3-3xy)$ の Jacobian 行列式は $3(y^2-x)$ である。臨界値は $(y^2,-2y^3)$ であり、第 1 座標を固定した切片は高々二点である。切片ごとの零集合を Fubini で合わせる段階がここでは直接見える。
:::

### 同次元の場合に必要な微分の階数

滑らかさを仮定した証明では消える高階微分を用いた。同次元では、一次近似がつぶれる一方向を直接数えれば、微分が一階連続で足りる。

:::proposition[$C^1$ の同次元 Sard 定理]{#prop-dtop-sard-equal-dimension}
$U\subset\R^n$ が開、$f\colon U\to\R^n$ が $C^1$ なら、その臨界値集合は測度零である。
:::

:::proof
$U$ 内のコンパクト立方体 $K$ を辺長 $h$ の小立方体に分ける。$K$ 上の $df$ のノルム上界を $B$、連続性の係数を $\omega$ とする。臨界点 $p$ を含む小立方体について、任意の $q$ に対し線分上で微分を積分すれば
$$
\norm{f(q)-f(p)-df_p(q-p)}\le \sqrt n\,h\,\omega(\sqrt n\,h)
$$
である。線形像 $\Img df_p$ は上限 $n-1$ 次元なので、これと直交する単位ベクトルを一つ選ぶ。その方向における像の厚さは $2\sqrt n\,h\,\omega(\sqrt n\,h)$ 以下であり、残りの方向では辺長 $2\sqrt n\,h(B+\omega(\sqrt n\,h))$ の箱に収まる。回転による体積は変わらないため、小立方体全部の像の体積上界は定数倍の $\omega(\sqrt n\,h)$ である。$h\to0$ で零になり、$K$ の可算被覆を取ればよい。
:::

この証明では各箱が別々の臨界点を選ぶ。すると薄い方向も箱ごとに変わるが、外測度の劣加法性には同じ向きの箱を使うという条件がない。$m>n$ でこの見積もりをそのまま使うと、箱数の因子 $h^{-m}$ に対し像の因子は $h^n\omega(h)$ にとどまる。そのため高階微分を利用する必要がある。一般の有限階では $C^k$、$k>\max(m-n,0)$ で Sard の結論が成り立つ。最小限の正則性を示すには、臨界集合に沿う Taylor データを保って低次元へ制限する拡張の議論が必要である。その版の証明は :cite[hirsch-dt] を参照する。

### 次元と臨界値集合の形は別の情報である

Sard の結論は像の測度についてであり、臨界値の集合が滑らかな部分多様体になることは要求しない。例えば $f(x,y)=(x,y^3-3xy)$ の臨界値曲線 $(y^2,-2y^3)$ を消去すると $v^2=4u^3$、$u\ge0$ となる。原点の両枝は同じ接線を持つが、原点を含む近傍では一つの滑らかなグラフで表示できない。なぜなら接線は $u$ 軸で、もし滑らかな曲線ならその座標軸への射影は局所微分同相になる一方、任意の小さい $u>0$ には $v=\pm2u^{3/2}$ の二点があるためである。それでも各切片は有限であり、全体の二次元測度は零である。

:::example[退化の階数と臨界値の次元]
$f(x,y,z)=(x^2,y^2)$ では法条件の微分は $\begin{pmatrix}2x&0&0\\0&2y&0\end{pmatrix}$ である。$xy\ne0$ なら階数二、$x,y$ のちょうど一方だけが零なら階数一、両方が零なら階数零である。臨界値は正の二座標軸と原点を合わせた集合であり、原点では二本の枝が直角に会う。例えば $(1,4)$ の逆像は $(\pm1,\pm2,z)$ の四本の直線である。$(0,4)$ の逆像は二本の直線で滑らかな集合だが、値は臨界である。このように逆像がたまたま滑らかでも、臨界値でないとは結論できない。
:::

:::example[一階の零点集合と高階の零点集合]
$f(x,y)=x^4+y^2$ を考える。$df=(4x^3,2y)$ により $C_1=\{0\}$ である。そこで $\partial_y^2f=2$ なので $C_2$ は空である。Sard の証明の $C_1\setminus C_2$ の段階では、$h=\partial_y f=2y$ を選んで $h=0$ という直線に制限する。その上の $x^4$ では臨界点は原点だけで、像の値は零である。臨界集合の点の周りで微分がどこまで消えるかに応じ、どの超曲面へ制限するかが決まる。
:::

### 高階の消失条件を区別する

:::example[二次近似が消える平面]
$f(x,y,z)=(x^3,y^4)$ とする。$df=0$ の点は $x=y=0$ である。この直線上では二階偏導関数も消えるが、$\partial_x^3 f_1=6$ は消えない。従って $C_1=C_2=\{x=y=0\}$、$C_3=\varnothing$ である。$C_2$ を含む超曲面を作るには $h=\partial_x^2f_1=6x$ を使う。この超曲面上の写像は $(y,z)\mapsto(0,y^4)$ なので、全域が臨界点である。像は半直線となり、二次元測度は零である。
:::

:::example[余次元が二になる臨界像]
$f(x,y,z)=(x,y^2+z^2,y^2+z^2)$ では、微分の後ろ二行が同じであるため全点が臨界である。$r=\sqrt{y^2+z^2}$ と置くと、臨界像は $(x,r^2,r^2)$ で表せる半平面である。一方で $df$ の階数が一になる $r=0$ の部分の像は直線である。ここでは値域の次元三と比較するために、画像全体を二変数で覆えば足りる。零集合の証明では、臨界点集合そのものの次元を見積もる必要はない。
:::

:::example[局所測度の選択]
球面の赤道を北極・南極を除いた二枚の立体射影座標で見ると、それぞれの像は単位円になる。単位円を角変数で $k$ 分割すると、像を一辺 $4\pi/k$ の正方形 $k$ 個に収められるので、面積の上界は $16\pi^2/k$ である。赤道上に一次元の弧長を入れれば長さは $2\pi$ となる。Sard の定理で用いるのは、値域である球面の二次元測度である。
:::

### 正則性を一階に下げたときの反例

:::example[臨界値が区間を満たす $C^1$ 写像]
三進 Cantor 集合の点を $x=\sum_{j\ge1}2\epsilon_j3^{-j}$、$\epsilon_j\in\{0,1\}$ と書き、$g(x)=\sum_{j\ge1}\epsilon_j4^{-j}$ と定める。二点で初めて桁が違う箇所を $j$ とすると、元の点の差の絶対値は少なくとも $3^{-j}$ であり、$g$ の値の差は高々 $(4/3)4^{-j}$ である。従って Cantor 集合上で $|g(x)-g(y)|\le(4/3)|x-y|^\alpha$、$\alpha=\log 4/\log 3>1$ となる。

第 $j$ 段の除去区間 $(a,b)$ では、$t=(x-a)/(b-a)$ とし、$g(x)=g(a)+(g(b)-g(a))(3t^2-2t^3)$ で補間する。導関数は両端で零であり、区間内の大きさは定数倍の $(3/4)^j$ 以下である。Cantor 集合上の点 $x$ に他の点 $y$ を近づけるとき、$y$ が除去区間にあれば、その間にある区間端 $e$ で値の差を二つに分ける。$x,e$ の差商は上の $\alpha>1$ の評価で零に近づく。$e,y$ の項は、区間の段数が増えるなら導関数の上界で零に近づく。固定した区間で $y$ が端に近づく場合にも、その端での導関数が零なので同じ結論を得る。従って $g$ は Cantor 集合で微分可能で、微分は零である。区間内の上界と端点の値から微分は連続である。$[0,1]$ の外側を定数で延長しても $C^1$ である。

$F(x,y)=g(x)+2g(y)$ と置く。この写像の微分は Cantor 集合の直積上で零である。一方、その像は四進展開 $\sum d_j4^{-j}$ の各桁を $d_j=\epsilon_j+2\eta_j$ と書くことで $[0,1]$ 全体になる。従って臨界値集合は正の測度を持つ。定義域の二次元と値域の一次元の差があるとき、同次元で使えた $C^1$ の仮定だけでは Sard の結論を得られない。
:::

## 臨界値と正則値

### 正則値の逆像

微分が退化する点が存在しても、値を選べばその点を避けられる。条件は一つの点の微分に課す場合と、逆像全体に課す場合で異なる。

:::definition[臨界点と正則値]{#def-dtop-regular-value}
$df_p$ が全射なら $p$ は :term[正則点]{en="regular point" yomi="せいそくてん"}、そうでなければ :term[臨界点]{en="critical point" yomi="りんかいてん"} である。ある臨界点の像を :term[臨界値]{en="critical value" yomi="りんかいち"} という。臨界値でない $y\in N$ を :term[正則値]{en="regular value" yomi="せいそくち"} という。逆像が空の値も正則値である。
:::

:::theorem[正則値定理]{#thm-dtop-regular-level}
$y$ が $f\colon M^m\to N^n$ の正則値なら、空でない $f^{-1}(y)$ は余次元 $n$ の埋め込まれた部分多様体であり、$T_p f^{-1}(y)=\Ker df_p$ である。
:::

:::proof
$p$ を逆像の点とし、$p,y$ を原点とする座標を取る。$df_p$ は全射だから $n$ 列の小行列式が非零である。変数を入れ替えてその列を最初の $n$ 列に取ると、$x\mapsto(f_1(x),\ldots,f_n(x),x_{n+1},\ldots,x_m)$ は局所微分同相である。この座標の最初の $n$ 座標を零と置いた集合が逆像であり、その接空間はちょうど $\Ker df_p$ である。
:::

:::example[同じ値を取る正則点と臨界点]
$g(x)=x^3-3x$ の臨界点は $\pm1$、臨界値は $\mp2$ である。$g^{-1}(2)=\{-1,2\}$ で、$g'(2)=9$ であっても $2$ は臨界値である。これに対し $g^{-1}(0)=\{0,\pm\sqrt3\}$ の三点では微分がいずれも非零である。
:::

:::example[円周と一点]
$f(x,y)=x^2+4y^2$ では臨界値は $0$ のみである。$f^{-1}(4)$ は楕円で $(0,1)$ における接線は $dy=0$ である。$f^{-1}(0)$ は一点であり、余次元は $1$ にならない。一方、$-1$ は正則値で逆像が空である。
:::

コンパクトな $M$ では $\mathcal C(f)$ が閉であるため、その像はコンパクトである。このとき正則値全体は開かつ稠密である。非コンパクトな場合は開性を仮定できない。例えば可算個の実直線の非交和で第 $j$ 成分の写像を定数 $1/j$ とすれば $0$ は正則値だが、そのどの近傍にも臨界値がある。

### 正則値の近くでファイバーを比較する

正則値定理は一つのファイバー上の局所座標を与える。正則値の近傍で全ファイバーを比較するには、遠くから新しい点が入り込まない条件も要る。

:::proposition[固有沈め込みの局所自明性]{#prop-dtop-proper-submersion}
境界なし多様体間の固有な沈め込み $f\colon M\to N$ は、その像上で滑らかな局所自明束である。
:::

:::proof
計量で $\Ker df$ の直交補を取り、これを水平空間とする。水平空間への $df$ の制限は同型なので、値域座標 $y_1,\ldots,y_n$ の座標ベクトル場を水平に持ち上げられる。$y=0$ の周囲の小閉立方体を座標領域内に選ぶ。水平流は値域で座標線を進み、値域の道がこの立方体内にある間は、その逆像のコンパクト性によって延長できる。

$y$ が立方体内部にあるとき、原点から $y$ まで座標を $1,\ldots,n$ の順に動かし、持ち上げた流れを $f^{-1}(0)$ 上の点へ適用する。逆順に逆時間の流れを適用すれば元の点へ戻る。流れの滑らかな依存性により、これは $f^{-1}(0)$ と立方体内部の積から逆像への微分同相である。異なる水平場が可換である必要はない。順序を選び、その逆順で戻せることを使っている。
:::

:::example[空でない正則ファイバーが分かれる例]
$f(t)=t^3-3t$ は固有である。臨界値は $\pm2$ なので $(-2,2)$ の上では各ファイバーに三点ある。$(2,\infty)$ の上では一つである。値域を一つの区間に制限して各枝の逆関数を使うと自明化が得られるが、$2$ を含む近傍には伸びない。
:::

:::example[沈め込みだが固有でない例]
$\R^2\setminus\{0\}\to\R$、$(x,y)\mapsto x$ の微分は全点で全射である。$x=0$ のファイバーは二成分、$x\ne0$ のファイバーは一成分なので、零近傍では局所自明でない。線分の持ち上げが除去した点に到達し得ることが、証明のコンパクト性に対応する。
:::

### 階数が一定な写像の局所標準形

:::proposition[定階数の局所形]{#prop-dtop-constant-rank-form}
$f\colon M^m\to N^n$ が $p$ の近傍で一定の階数 $r$ を持つなら、$p$ と $f(p)$ を原点とする座標で $f(u,v)=(u,0)$ と書ける。ここで $u\in\R^r$、$v\in\R^{m-r}$ である。
:::

:::proof
階数 $r$ の小行列式が非零となる成分と変数を先に並べる。逆関数定理で $(f_1,\ldots,f_r,x_{r+1},\ldots,x_m)$ を定義域の新座標 $(u,v)$ とする。その座標で $f=(u,g(u,v))$ であり、微分の最初の $r$ 列は独立である。残りの列の第 1 ブロックは零なので、階数が $r$ にとどまるには残りの列の第 2 ブロックも零でなければならない。従って $\partial_v g=0$ である。座標域を積の小箱へ縮めれば $v$ を直線で動かして積分できるので、$g=g(u,0)$ となる。標的座標を $(u,w)\mapsto(u,w-g(u,0))$ と変えれば所望の形になる。$r=0$ では連結な座標近傍で $df=0$ なので定数写像であり、同じ結論となる。
:::

:::example[階数一の像]
$f(x,y)=(x+y,(x+y)^2,x+y+1)$ はどの点でも微分に等しい二列 $(1,2(x+y),1)$ を持つので階数一である。定義域の $u=x+y,v=x-y$ と値域の $(a,b,c)\mapsto(a,b-a^2,c-a-1)$ により $(u,v)\mapsto(u,0,0)$ となる。逆像が存在する値では一般に直線 $x+y=a$ が逆像になるが、値域次元が三であり臨界値である。
:::

:::example[階数が変化すると局所形も変わる]
$f(x,y)=(x,xy)$ は $x\ne0$ で階数二、$x=0$ で階数一である。$x=0$ 上の一点の階数を使っても、その周りの写像を射影 $(x,y)\mapsto(x,0)$ に変えられない。変換の前後で各点の階数が一致するためである。原点の逆像が直線になる一方、原点を離れた正則値では逆像は高々一点である。
:::

### 正則値変化と連結成分

:::example[球面の高さ]
$h\colon S^2\to\R$ を $h(x,y,z)=z$ とする。点 $p$ における $dh$ は $e_3$ と接ベクトルとの内積である。従って $dh=0$ であるのは、$e_3$ が法線 $p$ と平行な場合、すなわち $p=\pm e_3$ に限る。臨界値は $\pm1$ である。$-1<c<1$ ならファイバーの半径は $\sqrt{1-c^2}$ であるから、$(\cos\theta,\sin\theta,c)\mapsto(\sqrt{1-c^2}\cos\theta,\sqrt{1-c^2}\sin\theta,c)$ と各ファイバーを同時に表示できる。端の値に近づくと半径が零になる。自明化を臨界値まで伸ばせないことが式から分かる。
:::

:::example[同じ次元で穴が開くファイバー]
$f(x,y)=xy$ の微分は $(y,x)$ である。$c>0$ のファイバーは $(t,c/t)$、$t>0$ と $t<0$ の二枝であり、$c<0$ でも枝は二つだが入る象限が異なる。$f^{-1}(0)$ は二軸の合併である。原点以外では二軸のどの点も正則点だが、値 $0$ には原点も入るので正則値ではない。開集合 $(0,\infty)$ の上では自明化 $(t,c)\mapsto(t,c/t)$ が明示できる。この例では固有性がなくても具体的な式から局所自明性を確かめられる。
:::

:::example[法方向を二本同時に課す]
$F\colon\R^4\to\R^2$ を $F(x,y,z,w)=(x^2+y^2,z^2+w^2)$ とする。値 $(4,9)$ の逆像は半径 $2,3$ の円の積である。$(2,0,3,0)$ では $dF(v)=(4v_x,6v_z)$ なので接空間は $v_x=v_z=0$ である。値 $(0,9)$ では最初の行が零になり、逆像は一つの円になる。逆像が滑らかであることと、方程式が独立な微分を持つことをこの二つの値で比較できる。
:::

## Whitney の近似定理

### 局所有限な平滑化

連続写像をホモトピーの入力に使える場合でも、微分を使うには滑らかに直す必要がある。近似誤差を点ごとに指定すると、非コンパクトな定義域にも対応できる。

:::theorem[Euclid 空間値の Whitney 近似]{#thm-dtop-whitney-approximation}
連続写像 $f\colon M\to\R^q$ と連続な $\eps\colon M\to(0,\infty)$ に対し、$\norm{g-f}<\eps$ を満たす滑らかな $g$ が存在する。閉集合 $A$ の近傍で $f$ が滑らかなら、$g=f$ を $A$ の近傍で満たすようにも取れる。
:::

:::proof
各点 $p$ において、連続性により $\norm{f(p)-f(x)}<\eps(x)$ を満たす近傍 $U_p$ がある。局所有限な滑らかな 1 の分割 $\rho_i$ をこの被覆に従属させ、各 $\rho_i$ に対応する中心 $p_i$ を取る。$g_0=\sum_i\rho_i f(p_i)$ は局所有限和なので滑らかである。三角不等式と $\sum_i\rho_i=1$ により点ごとの誤差を満たす。$f$ が滑らかな開集合 $V\supset A$ があるなら、$A$ の近傍で $1$、台が $V$ に含まれる滑らかな $\eta\in[0,1]$ を 1 の分割から作る。$g=\eta f+(1-\eta)g_0$ は $V$ 上では滑らかであり、$V$ の外の各点の近傍では $g_0$ と一致する。誤差は $(1-\eta)\norm{g_0-f}$ である。
:::

### 多様体値の相対近似

:::lemma[閉 Euclid 部分多様体への最近点射影]{#lem-dtop-nearest-retraction}
閉な埋め込まれた部分多様体 $N\subset\R^a$ には、$N$ を含む開集合 $W$ 上で一意な最近点を与える滑らかな写像 $\pi\colon W\to N$ がある。
:::

:::proof
$y\in\R^a$ に対する最近点は、$N$ が空でなければ存在する。実際、一つの候補までの距離を半径とする閉球内で最小値を取ればよい。$p\in N$ を固定すると、$y$ の任意の最近点 $q$ は $\norm{q-p}\le2\norm{y-p}$ を満たす。また、距離の二乗を $N$ に沿って微分すると $y-q\perp T_qN$ である。局所的な法束で $(q,v)\mapsto q+v$ を考えると、$(p,0)$ における微分は $T_pN\oplus(T_pN)^\perp\to\R^a$、$(u,w)\mapsto u+w$ であり可逆である。$y$ が $p$ に十分近ければ、すべての最近点に対応する $(q,y-q)$ は同じ逆関数の定義域に入る。従って最近点は一意であり、局所逆写像の底成分なので滑らかである。各 $p$ で得る開近傍を合わせても、一意性によって定義は一致する。
:::

:::corollary[多様体値の相対 Whitney 近似]{#cor-dtop-manifold-approximation}
連続写像 $f\colon M\to N$ は、任意の正の連続な誤差 $\eps\colon M\to(0,\infty)$ に対して、距離が点ごとに $\eps$ 未満の滑らかな写像へホモトープである。$f$ が閉集合 $A$ の近傍で滑らかなら、$A$ の近傍でホモトピーを固定できる。距離には $N$ の任意の Riemann 距離を使える。
:::

:::proof
値域を本章後半の固有埋め込みで閉 Euclid 部分多様体として表し、:ref[lem-dtop-nearest-retraction] の $\pi$ を取る。各 $x$ について $f(x)$ の Euclid 小球が $W$ に含まれ、球のすべての点の $\pi$ による像が距離 $\eps(x)$ 未満に収まるようにする。$\pi$、$f$、$\eps$ の連続性から、半径は $x$ の近傍で共通の正定数を取れる。各点の近くで有効な半径を 1 の分割で平均すれば、連続な正の許容誤差が得られる。:ref[thm-dtop-whitney-approximation] でその誤差内の Euclid 値近似 $g$ を取り、$H(x,t)=\pi((1-t)f(x)+tg(x))$ と置く。線分は上の小球に収まるので、終点の近似と途中のホモトピーがともに距離条件を満たす。相対版では $g=f$ の領域で線分が定数となる。
:::

法束全体を使って同じ射影を記述する構成は [横断性と管状近傍](/math/differential-topology/transversality/) で扱う。

:::example[絶対値の近似]
$\sqrt{x^2+\delta^2}$ は $\delta>0$ で滑らかであり、誤差は $0<\sqrt{x^2+\delta^2}-|x|\le\delta$ を満たす。右側の不等式は $(|x|+\delta)^2\ge x^2+\delta^2$ から従う。原点の微分可能性を回復しても一様誤差は任意に小さくできる。
:::

:::example[円への射影と誤差]
$f$ が $S^1$ に値を取り、$\norm{g-f}<1/3$ とする。$\norm{g}>2/3$ であり、$\pi(g)=g/\norm g$ が定義できる。また $\norm{\pi(g)-g}=|1-\norm g|\le\norm{g-f}$ より、円上での近似の距離は $2/3$ 未満である。
:::

### 近似とホモトピーの端点

閉条件を保持する平滑化は、写像の滑らかさをホモトピー類の問題から切り離す。例えば端点で滑らかな $f_0,f_1$ が連続ホモトピー $H$ で結ばれているとき、時間の再パラメータ化により端の開襟上で $H$ を $f_i$ と一致させる。再パラメータ化は $0$ と $1$ の近傍で定数であり、中間では全区間を通る。次いで :ref[cor-dtop-manifold-approximation] で相対平滑化すると、端を固定した滑らかなホモトピーを得る。時間区間を少し外へ延ばして端の近くで定数にしておけば、境界上の平滑化を境界なしの開集合に帰着できる。

:::example[逆像の条件を近似で保持する]
$\gamma\colon[0,1]\to\R^2\setminus\{0\}$ が連続とする。$d=\min_t\norm{\gamma(t)}>0$ である。誤差を $d/2$ 未満にすれば、$\gamma$ と近似との間の全線分は原点から $d/2$ 以上離れている。ゆえに原点を避けるホモトピーになる。同じ議論で非コンパクトな定義域では $\norm{\gamma(x)}/2$ のような点ごとの誤差を使う。
:::

:::example[微分を保存するには別の位相がいる]
$g_\delta(t)=t+\delta\sin(t/\delta^2)$ は恒等写像に一様収束するが、$g_\delta'(t)=1+\delta^{-1}\cos(t/\delta^2)$ は $0<\delta<1$ で零になる点を持つ。したがって近似誤差を値にだけ課すと、もとのはめ込み条件が保たれるとは限らない。
:::

### 微分も近づける近似

:::proposition[$C^r$ 写像の滑らかな近似]{#prop-dtop-whitney-cr}
$M$ を境界なしの滑らかな多様体、$f\colon M\to\R^q$ を $C^r$ 写像、$r<\infty$ とする。局所有限な座標箱において、全ての $r$ 階以下の偏微分を、各コンパクト小箱で任意に指定した正の誤差で近づけられる。座標箱は小箱ごとに有限個しか交わらないよう選ぶ。閉集合の近傍で $f$ が滑らかな場合はその集合の近傍で固定できる。
:::

:::proof
座標箱に従属する局所有限な滑らかな 1 の分割 $\rho_i$ を取り、各 $\rho_i$ は座標内でコンパクト台を持つように選ぶ。$f=\sum_i\rho_i f$ と分け、各項を座標内で $\R^m$ へ零延長する。積分 $1$ の滑らかなコンパクト台関数 $\varphi$ を選び、$\varphi_\delta(x)=\delta^{-m}\varphi(x/\delta)$ で畳み込む。$\delta$ を小さくすれば台はまだ元の座標箱の内側にある。各 $|\alpha|\le r$ について
$$
\partial^\alpha(\varphi_\delta*g-g)(x)
=\int\varphi(u)\big(\partial^\alpha g(x-\delta u)-\partial^\alpha g(x)\big)\,du .
$$
右辺はコンパクトな範囲での一様連続性により零へ一様収束する。座標変換で微分を評価する場合も、コンパクト小箱との共通部分では連鎖律の係数が有界である。各項の台の少し広いコンパクト近傍が交わる評価用小箱は有限個なので、各箱で必要な精度を、その箱に交わる項数で割り当ててから $\delta_i$ を選べる。畳み込みの和は局所有限で滑らかであり、要求した精度を満たす。固定したい領域では滑らかな切断関数 $\eta$ を掛けて $\eta f+(1-\eta)g$ とする。Leibniz 則で $\eta$ の微分の有限な上界を費用に入れて近似の精度を選べば、相対版でも同じ要求を満たせる。
:::

:::example[二次式の畳み込み誤差]
対称な $\varphi$ に対し $f(x)=x^2$ を畳み込むと、$f_\delta(x)=x^2+\delta^2\int u^2\varphi(u)\,du$ である。一次の項の積分は対称性で零になる。したがって値には定数誤差が生じるが、一次・二次微分には誤差が生じない。
:::

:::example[局所平滑化に伴う微分誤差]
$f(x)=x^3$ を対称な積分 $1$ の核で平滑化する。$f(x-\delta u)=x^3-3\delta x^2u+3\delta^2xu^2-\delta^3u^3$ のうち奇数次の $u$ の項は消え、$f_\delta(x)-f(x)=3\delta^2x\int u^2\varphi(u)\,du$ になる。従って $|x|\le2$ での関数の誤差は $6\delta^2\int u^2\varphi$ 以下、一次導関数の誤差は $3\delta^2\int u^2\varphi$ であり、二次以上の誤差は零である。コンパクトな小箱ごとに変える平滑化の幅が、値と微分の双方の制御に使える理由がこの計算に表れている。
:::

### Convolution を用いる局所近似

:::example[鋭い折れ目の平均化]
$\rho\colon\R\to[0,\infty)$ を偶関数で $(-1,1)$ に台を持ち、$\int\rho=1$ を満たす滑らかな関数とする。$u_a(x)=\int\rho(t)|x-at|\,dt$ と置く。$|x|>a$ では $x-at$ の符号が一定であり、$\int t\rho(t)\,dt=0$ により $u_a(x)=|x|$ となる。任意の $x$ で $|u_a(x)-|x||\le a\int |t|\rho(t)\,dt\le a$ である。一方、変数を $s=x-at$ に替えると被積分関数の $x$ 依存性は滑らかな核 $a^{-1}\rho((x-s)/a)$ に移る。$x$ のコンパクト区間ごとに積分の台は共通のコンパクト集合に収まるため、積分の下で何度でも微分できる。従って誤差の発生する範囲を折れ目の近傍に限定した近似が得られる。
:::

:::example[点ごとに違う誤差]
$f\colon\R\to\R$ を $f(x)=|\sin x|$ とし、$\eps(x)=e^{-x^2}/10$ とする。定数半径の近似 $\sqrt{\sin^2x+a^2}$ では $x=k\pi$ における誤差がすべて $a$ なので、この許容誤差には収まらない。これに対し $g(x)=\sqrt{\sin^2x+\eps(x)^2/4}$ は平方根の中が正なので滑らかであり、$0<g-f\le\eps(x)/2$ が各点で成り立つ。非コンパクトな定義域で近似を指定するときは、一様誤差と点ごとの誤差を区別する必要がある。
:::

:::example[滑らかな端を持つ円周上の道]
$\gamma(t)=\exp(i\pi |2t-1|/2)$、$0\le t\le1$ を考える。$a<1/2$ とし、前の平均化を $u_a(2t-1)$ に適用すると、$\gamma_a(t)=\exp(i\pi u_a(2t-1)/2)$ は端の近傍で $\gamma$ と一致する。位相角を $(1-s)|2t-1|+su_a(2t-1)$ で補間すれば端を固定したホモトピーが得られる。弧の距離を評価するには $\lvert e^{iv}-e^{iw}\rvert=2\lvert\sin((v-w)/2)\rvert\le |v-w|$ を使い、近似誤差は $\pi a/2$ 以下である。
:::

## Whitney のはめ込み定理

### 接ベクトルを失う方向

射影がはめ込みの条件を壊すのは、射影の核が像のどこかの接方向を含むときである。そこで、すべての接方向を単位ベクトルにして球面内の集合として調べる。

:::lemma[有限個の座標から作る埋め込み]{#lem-dtop-compact-high-embedding}
コンパクト多様体 $M^m$ はある有限次元 Euclid 空間へ滑らかに埋め込める。
:::

:::proof
座標 $\phi_i\colon U_i\to\R^m$ と、$\rho_i=1$ となる $U_i$ 内の小近傍が $M$ を覆い、$0\le\rho_i\le1$、$\operatorname{supp}\rho_i\subset U_i$ となる有限個の滑らかな関数を取る。$F=(\rho_i,\rho_i\phi_i)_i$ とし、各成分を $U_i$ 外で零に延長する。$p$ で $\rho_i=1$ の小近傍を選ぶと $\rho_i\phi_i=\phi_i$ なので $dF_p$ は単射である。$F(p)=F(q)$ なら同じ成分から $\rho_i(q)=1$ と $\phi_i(p)=\phi_i(q)$ が従い、$p=q$ である。コンパクト空間から Hausdorff 空間への連続単射は像への同相である。よって $F$ は埋め込みである。
:::

:::theorem[弱 Whitney はめ込み定理]{#thm-dtop-weak-immersion}
コンパクトな $m$ 次元滑らかな多様体は $\R^{2m}$ へはめ込める。ただし $m\ge1$ とする。
:::

:::proof
$F\colon M\to\R^q$ をはめ込みとし、$M$ に Riemann 計量を入れる。単位接ベクトル束 $S(TM)$ は、局所的に $U\times S^{m-1}$ であるから次元 $2m-1$ である。方向写像 $(p,v)\mapsto dF_p(v)/\norm{dF_p(v)}$ の像は $q-1>2m-1$ のとき :ref[lem-dtop-small-image] により $S^{q-1}$ で測度零である。この像の外に $w$ を取る。像は $v\mapsto-v$ で不変だから $-w$ も外にある。$w^\perp$ への射影 $P_w$ について $\Ker P_w=\R w$ であり、$P_wdF_p$ は全点で単射となる。:ref[lem-dtop-compact-high-embedding] から出発し、$q>2m$ の間繰り返す。初めの空間が必要な次元より小さければ零成分を補う。
:::

:::example[方向によって退化する円の射影]
$(\cos t,\sin t,0)$ を $z$ 軸に沿って射影しても接ベクトルは変わらない。一方、$x$ 軸に沿う射影の微分は $(0,\cos t,0)$ であり、$t=\pi/2,3\pi/2$ で消える。
:::

:::example[単射でないはめ込み]
$f(t)=(\sin t,\sin 2t)$ では $f'(t)=(\cos t,2\cos2t)$ の成分は同時に零にならない。一方 $f(0)=f(\pi)=(0,0)$ である。二点を分離するには接方向の条件だけでは足りない。
:::

### 微分が単射になる射影の全体

$F\colon M\to\R^q$ がはめ込みで $M$ がコンパクトな場合、単位接束の像はコンパクトである。従って接方向を避ける射影方向は球面上で開く。さらに $q>2m$ ならその補集合が測度零なので、開稠密集合となる。方向に小さな変更を加えたときも微分が単射であると言えるのは、このコンパクト性のおかげである。

:::example[半径を変えても接方向は同じ]
$F(t)=(2\cos t,3\sin t,0)$ の接ベクトルは $(-2\sin t,3\cos t,0)$ である。第 3 成分が零の任意の方向はこのベクトルのある実倍である。そのため禁止方向は $S^2$ の赤道全体になる。$w=(1,2,3)$ ならこの集合に入らず、射影後も微分は全点で単射である。
:::

:::example[接方向が退化する点を方程式で求める]
円柱螺旋 $F(t)=(\cos t,\sin t,t)$ の接ベクトルは $(-\sin t,\cos t,1)$ である。核を $(0,1,1)$ で張る直交射影では、$t=0\bmod2\pi$ でこの微分が消える。核を $(0,0,1)$ に変えると射影後の微分は消えない。ただし射影像では $t$ と $t+2\pi$ を区別できない。
:::

### はめ込みを保つ近似の大きさ

:::proposition[コンパクトな定義域でのはめ込みと埋め込みの安定性]{#prop-dtop-embedding-open}
コンパクト $M$ からの滑らかなはめ込み、埋め込みはそれぞれ $C^1$ 位相で開条件である。
:::

:::proof
はめ込み条件は各点である最大サイズの小行列式が非零となることである。定義域のコンパクト性により、非零小行列式を固定できる小座標近傍を有限個選べる。それぞれ少し狭いコンパクト小箱の上で行列式の絶対値の下界を取り、摂動の微分に同時に誤差を課せば単射性が保たれる。

埋め込みでは近い点の組と離れた点の組を分ける。まず元の $f$ の各点で、値域の適当な $m$ 座標への射影 $\pi$ に対する $d(\pi f)$ が可逆である。その点の近傍で定義域の座標を $\pi f$ に変更すると、$\pi f$ は恒等になる。コンパクトな凸小箱で摂動後の $\pi g$ の微分を恒等から作用素ノルム $1/2$ 未満だけずらすと、同じ箱の二点 $x,y$ について
$$
\norm{\pi g(x)-\pi g(y)-(x-y)}\le\tfrac12\norm{x-y}
$$
となる。線分上で微分を積分した見積もりであり、$\pi g$ は箱で単射である。箱の内部を有限個選んで $M$ を覆う。Lebesgue 数より十分近い二点は同じ箱に入る。残る離れた二点の組は $M\times M$ のコンパクト集合である。その集合上で $f(p),f(q)$ の距離には正の最小値があるため、値の一様な小さい摂動では一致できない。従って $g$ は単射なはめ込みであり、コンパクト性で像への同相になる。
:::

:::example[区間での微分の下界]
$f\colon[-1,1]\to\R^2$、$f(t)=(t,t^2)$ を考える。第一成分の導関数が $1/2$ 以上の摂動では、平均値の定理によりその成分は厳密に増加する。従って全写像も単射である。第二成分を大きく変更しても第一成分のこの条件が保たれる限り、はめ込みと埋め込みは同時に保たれる。
:::

### はめ込みと同じ次元の余域

:::example[閉多様体の同次元へのはめ込み]
$S^1$ を $\R$ へはめ込むことはできない。滑らかな実数値関数はコンパクトな円周で最大値を取り、その点で微分が零になる。一般に、空でないコンパクトな境界なし $m$ 次元多様体から $\R^m$ へのはめ込みが存在すると、その微分は各点で可逆となる。よって逆関数定理により像は開集合である。一方、像はコンパクトなので閉でもあり、$\R^m$ の連結性から全空間になる。$m>0$ では全空間はコンパクトでないから矛盾する。この議論には写像の単射性を使わない。
:::

## Whitney の埋め込み定理

### 割線で点を分離する

:::theorem[弱 Whitney 埋め込み定理]{#thm-dtop-weak-embedding}
コンパクトな $m$ 次元滑らかな多様体は $\R^{2m+1}$ に埋め込める。
:::

:::proof
:ref[lem-dtop-compact-high-embedding] で得た $F$ から始める。$P_wF(p)=P_wF(q)$ が $p\ne q$ に対して起こるのは、$w$ が割線方向写像
$$
(p,q)\longmapsto\frac{F(p)-F(q)}{\norm{F(p)-F(q)}},\qquad
(p,q)\in M\times M\setminus\Delta_M
$$
の像に入るときに限る。定義域は $2m$ 次元である。$F\colon M\to\R^a$ に対して $a-1>2m$ なら、:ref[lem-dtop-small-image] により球面上でその像は測度零である。接方向の像も測度零なので、球面上でその和集合の外を選べる。選んだ射影は単射なはめ込みであり、コンパクト性で像への同相になる。この操作を $\R^{2m+1}$ に達するまで続ける。
:::

:::proposition[固有な単射はめ込み]{#prop-dtop-proper-immersion}
多様体間の固有な単射はめ込みは埋め込みである。
:::

:::proof
閉集合 $A$ の像に収束する列 $f(x_j)\to y$ を考える。$\{y\}\cup\{f(x_j)\mid j\ge1\}$ はコンパクトであり、その逆像もコンパクトである。$x_j\in A$ は部分列で $x\in A$ に収束するため $f(x)=y$ である。値域は第一可算なので $f(A)$ は閉であり、連続単射 $f$ の逆写像は連続になる。
:::

:::example[円柱の埋め込み]
$S^1\times\R\to\R^3$、$(t,s)\mapsto(\cos t,\sin t,s)$ は、微分の列が直交し長さ $1$ なので、はめ込みである。逆像では高さ $s$ が制限されるため固有であり、角と高さで点が定まるので単射である。
:::

:::example[単射はめ込みの逆写像が不連続になる例]
$(0,2\pi)\to\R^2$、$t\mapsto(\sin t,\sin2t)$ は単射である。同じ第 1 成分を持つ二点が異なるなら第 2 成分の符号が逆であり、両者が零になる内点は $\pi/2,\pi,3\pi/2$ で、その第 1 成分は相異なる。ところが $t_j\to0^+$ で像は $f(\pi)$ に収束する。微分は先の例と同じく単射であるが、像への同相ではない。
:::

### 非コンパクトな場合の弱い次元評価

多様体のコンパクト部分を局所的に埋め込んでも、無限遠から像が戻ると埋め込みにならない。そこで、固有性を検出する座標を固定する。非負の滑らかな固有関数 $h$ は、相対コンパクトな開集合による増大列 $U_j$（$\overline{U_j}\subset U_{j+1}$）を取り、$\chi_j$ を $\overline{U_j}$ の近傍で $1$、$U_{j+1}$ の外で $0$ として $\sum_{j\ge1}(1-\chi_j)$ とすれば得られる。各点の近傍では有限項しか残らず、$U_{k+1}$ の外では先頭 $k$ 項が $1$ である。

$h^{-1}([j-1,j+1])$ を有限個の小座標で覆い、その座標から得た写像 $F_j$ によりその集合上の点を分離し、そこで微分を単射にする。すると各 $F_j$ を有限回の射影で $2m+1$ 成分にできる。射影の禁止方向は、その集合での接方向および二点の割線方向であり、もとの写像がはめ込み・単射となる開条件を満たす点だけで方向写像を定義すれば先の次元評価が使える。$j\ge0$ とし、帯域 $(j-2,j+2)$ に台を持ち $[j-1,j+1]$ の近傍で $1$ の滑らかな関数 $\eta_j$ を取る。$j$ の $4$ を法とする剰余ごとに $\eta_j(h)F_j$ を足すと、同じ剰余の項の非零領域が互いに素になる。これら四つのベクトル値関数と $h$ を並べると、高さが違う点は $h$ で、高さが同じ点はそれらを含む帯域の $F_j$ で分離される。微分も同じ帯域で単射なので、有限次元の固有埋め込みが得られる。

次に高さを保つ線形射影を考える。高さ以外の成分が $a$ 個のとき、禁止方向は単位球面 $S^{a-1}$ 上の接方向および割線方向のうち高さ成分が零のものである。高さ以外への方向写像を、成分が零でない開集合上で定義すれば、定義域の次元は高々 $2m$ である。よって $a>2m+1$ の間は候補から方向を選べる。射影後も $h$ の座標を残すので固有性が保たれ、$\R^{2m+2}$ への固有埋め込みが得られる。

### 高さ座標も落とす

有限次元への固有埋め込みを $F=(g,h)$ とし、横成分を $g/\sqrt{1+\norm g^2}$ で置き換える。これは $\R^a$ から開単位球への微分同相を横方向へ適用したものなので埋め込みを保ち、$h$ はそのままなので固有性も保つ。横方向が有界になったことを使えば、高さ軸を固定しない射影でも固有性を保てる。実際、高さ単位ベクトル $e$ に対し $P_w e\ne0$ なら、
$$
\norm{P_w F(p)}\ge |h(p)|\norm{P_w e}-1.
$$
そのため像がコンパクト集合に入ると $h$ が有界になり、逆像がコンパクトになる。禁止する方向は接線・割線の方向に $\pm e$ を加えた集合である。射影後の写像を座標に取り直す代わりに、$P_we$ に沿う成分を新しい高さに、直交成分を新しい横成分にすれば、後者は依然有界である。前者は $h$ の正定数倍に有界な誤差を足したものなので固有である。従って最終射影を繰り返せば、一般の場合の弱定理でも $\R^{2m+1}$ への固有埋め込みが得られる。$m\ge1$ ならその後は割線禁止を外して接方向だけを避ければ、$\R^{2m}$ への固有はめ込みも得られる。可算無限の零次元多様体では、固有な写像の余域には少なくとも一次元が必要である。

:::example[螺旋を高さで分ける]
$F(t)=(\cos t,\sin t,t)$ の水平成分は長さ $1$ である。$w=(1,0,0)$ に沿って射影すると $(\sin t,t)$ になり、高さがすべての点を分けるので固有埋め込みである。$w=(0,0,1)$ では高さが消え、各円周点の逆像に無限個の点が現れる。
:::

### 任意の写像を埋め込みに近づける

埋め込みが存在することと、与えられた写像の近くに存在することは異なる。ある高次元埋め込みを固定し、その座標を小さく加えると、元の写像の値と微分を保ちながら、同一点への重なりや接方向の退化を避けられる。

:::theorem[Euclid 空間への一般位置近似]{#thm-dtop-euclidean-general-position}
$M$ をコンパクト $m$ 次元多様体とする。滑らかな $f\colon M\to\R^n$ は、$n\ge2m$ なら任意に $C^\infty$ 近いはめ込みで近似できる。$n\ge2m+1$ なら任意に $C^\infty$ 近い埋め込みで近似できる。
:::

:::proof
:ref[lem-dtop-compact-high-embedding] で $i\colon M\to\R^q$ を固定する。$A$ を $n$ 行 $q$ 列の実行列とし、$f_A=f+Ai$ と置く。$A$ が零に近づくと、コンパクトな座標領域上で各階の導関数も元のものへ一様に近づく。

まず、計量の単位接束 $S(TM)$ と行列空間の積で
$$
\mathcal T(p,v,A)=df_p(v)+A\,di_p(v)
$$
を考える。$di_p(v)$ は非零である。従って任意の $w\in\R^n$ に対し、$di_p(v)$ を $1$ に写す線形汎関数 $\ell$ を使って行列変分 $B=w\ell$ を作れば、$A$ に沿った微分は $B\,di_p(v)=w$ である。つまり $\mathcal T$ は沈め込みである。零点集合の次元は、行列空間の次元 $nq$ に $2m-1-n$ を足したものである。$n\ge2m$ ならこれは $nq$ 未満である。零点集合から行列空間への射影の像は :ref[lem-dtop-small-image] によって測度零であり、その外の $A$ では、どの非零接ベクトルも消えない。

次に相異なる点の組の空間で
$$
\mathcal S(p,q',A)=f(p)-f(q')+A\big(i(p)-i(q')\big)
$$
を考える。$i$ は単射なので、$A$ の変分で前と同じ議論ができ、$\mathcal S$ も沈め込みである。零点集合の次元は $nq+2m-n$ である。$n\ge2m+1$ なら行列空間より小さく、禁止行列の集合は測度零になる。二つの禁止集合の和を除けば、原点の任意の小近傍で $A$ を選べ、$f_A$ は単射なはめ込みになる。コンパクト性で埋め込みである。$m=0$ では単位接束の段階は空であり、有限個の点同士の差の段階だけが残る。
:::

この証明は固定した埋め込みへの射影による証明と同じ次元差を使うが、パラメータは射影方向一つでなく、元の写像にどの座標の組を加えるかを表す行列である。接方向の退化と相異なる二点の一致の双方について、最初に全パラメータで沈め込みを作る点が、横断性の摂動法と共通している。値域が曲がった多様体の場合は、局所フレームに従う流れを摂動に使う。

:::example[二成分の曲線に小さな高さを付ける]
$f(t)=(\sin t,\sin 2t,0)$ を円から $\R^3$ への写像とする。$i(t)=(\cos t,\sin t)$ とし、$A$ の第 3 行を $(\delta,0)$、他の行を零とする。すると $f_A=(\sin t,\sin 2t,\delta\cos t)$ であり、$\delta\ne0$ なら第一、第三成分で $\sin t,\cos t$ が戻るので単射になる。この二成分の微分 $(\cos t,-\delta\sin t)$ は同時に零にならず、はめ込みでもある。各階の微分の変更は第 3 成分に限られ、その上界は $|\delta|$ である。従って任意に小さい摂動で埋め込みにできる。
:::

:::example[線形摂動量の禁止集合]
$f\colon S^1\to\R^2$ を定数とし、$i(t)=(\cos t,\sin t)$ へ $2$ 次正方行列 $A$ を掛けて摂動する。$\det A\ne0$ なら像は楕円で、逆行列から元の円の点が戻るので埋め込みになる。$\rank A=1$ なら像は線分であり、円の接方向が $\Ker A$ に一致する二点で微分が消える。$\det A=0$ が禁止集合であることが、この例では行列空間上で直接分かる。一般位置近似で $n=2m$ が保証するのははめ込みまでだが、この定数写像の例では埋め込みも得られる。
:::

## 強 Whitney 埋め込み定理の概観

一般射影は、禁止方向を定義する空間と候補を選ぶ球面との間に厳密な次元差があるときに働く。埋め込み先を $\R^{2m}$ に落とす境界では、この差がなくなる。二重点をまず孤立させ、それを大域的な変形で扱うのが強定理の要点である。

:::theorem[強 Whitney 埋め込み定理]{#thm-dtop-strong-embedding}
$m\ge1$ の第二可算な滑らかな $m$ 次元多様体は $\R^{2m}$ に滑らかに埋め込める。
:::

証明は :cite[hirsch-dt] から案内される Whitney の原論文を参照する。 [Whitney の埋め込み定理の証明](https://doi.org/10.2307/1969265)。一般の証明では孤立した二重点を調べ、その符号を調整してから変形で除く。低次元では別の扱いも必要になるため、ここでは定理の概観にとどめる。測度零を使う射影との違いは、接方向を与える空間が $2m-1$ 次元であるのに対し、割線方向を与える空間は $2m$ 次元であることにある。

強はめ込み定理は $m>1$ の滑らかな $m$ 次元多様体を $\R^{2m-1}$ にはめ込めるという主張である。この定理も境界次元の特異点除去が必要であり、証明は Whitney の原論文にある。 [Whitney のはめ込み定理の証明](https://webhomes.maths.ed.ac.uk/~v1ranick/papers/singular.pdf)

:::example[境界次元で二重点を解く]
$f(t)=(\sin t,\sin2t)$ の原点における二本の接ベクトルは $(1,2)$ と $(-1,2)$ で、並べた行列式は $4$ である。$F(t)=(\sin t,\sin2t,\cos t)$ では、元の二点の高さは $1,-1$ となる。$F$ は $(\sin t,\cos t)$ が円上の点を決めるので埋め込みであるが、高さを捨てると再び二重点が生じる。
:::

:::example[トーラスの明示埋め込み]
$F(u,v)=((3+\cos v)\cos u,(3+\cos v)\sin u,\sin v)$ とする。円柱座標の半径から $\cos v$ が、最後の座標から $\sin v$ が戻り、半径が正なので $u$ も戻る。微分の二列は直交し、その二乗ノルムは $(3+\cos v)^2,1$ である。二次元多様体でも個別には強定理の $4$ より小さい次元で埋め込める。
:::

### 余次元一での向きの障害

閉なコンパクト超曲面 $M\subset\R^{m+1}$ は向き付け可能である。外側の固定点と任意の補集合の点を結ぶ道を取り、交点では超曲面の局所定義関数と道との合成が単純零点を持つようにする。そのような道の選び方を示すため、道 $F$ を端で一定にし、定数区間を除いて正となる切断関数 $\rho$ を取る。$\rho(x)>0$ の領域では $(x,a)\mapsto F(x)+\rho(x)a$ の $a$ 微分が全射である。局所定義関数と合成すれば、その零集合は正則値定理により滑らかである。零集合から $a$ 空間への射影の正則値を Sard の定理で選ぶと、$x$ 方向の微分だけで局所定義関数の微分が全射となる。実際、$a$ 方向の任意のベクトルを射影で持ち上げるには、そのベクトルの法成分を $x$ 方向で打ち消せなければならない。よって $a$ を小さく選ぶと道の端を保ちつつ、交点をすべて単純にできる。

道の交点の偶奇を、終点に付ける色とする。二つの道の差は閉ループになり、円板に滑らかに延ばせる。具体的には境界の道を半径方向に一定とし、半径が十分小さい領域では切断関数を使って一点に固定する。境界の近くでは道の接方向だけで局所定義関数の微分が全射である。そこで先と同じ摂動を円板の内部に適用し、境界付近の定数襟の中で切断関数を零から正へ移す。零集合は内部では次元一であり、境界付近では有限個の交点と半径区間の積である。このコンパクトな一次元多様体の境界点数は偶数だから、二つの道の色は一致する。局所的な超曲面の両側では、短い法線を横切る道がちょうど一回交わるため色が異なる。同じ色を向く単位法線を選べば局所法線は重なりで一致し、周囲の向きと合わせて $M$ を向き付けられる。この摂動の一般形は [横断性と管状近傍](/math/differential-topology/transversality/) で扱う。

:::example[$\R P^2$ と保証次元]
$\R P^2=S^2/(x\sim-x)$ の被覆変換は、球面の向きを反転する。実際、外向き法線を先に置く向きで対蹠変換の符号は $\det(-I_3)=-1$ である。商が向き付けられればその向きの引き戻しは被覆変換で保存されるので矛盾する。従って $\R P^2$ は上の余次元一の議論から $\R^3$ に埋め込めない。一方、強定理により $\R^4$ には埋め込める。この例では $2m=4$ が実際に必要である。
:::

### 境界次元での一般位置と局所計算

$m$ 次元のコンパクトな $M$ を考える。:ref[thm-dtop-euclidean-general-position] で、まず $\R^{2m}$ へのはめ込み $f$ を選ぶ。埋め込み $i\colon M\to\R^q$ を固定し、$i$ の座標に関する二次以下の $\R^{2m}$ 値多項式 $P$ を $f$ に加える。二点または三点を固定すると、それぞれで $P$ の値を独立に指定できる。実際、ある線形汎関数で $i(p_j)$ の像を相異なる実数 $t_j$ に写し、一変数の補間多項式を使えばよい。禁止される汎関数は有限個の超平面の和にすぎない。

二点の場合、$F_P(p_1,p_2)=(f+P\circ i)(p_2)-(f+P\circ i)(p_1)$ とする。三点の場合は $p_3$ と $p_1$ の差も並べる。いずれも係数 $P$ に沿った微分が全射なので、全零集合は多様体である。その零集合から係数空間への射影に Sard の定理を適用する。射影の正則値では、任意の係数変分による差を点の変分で打ち消せるので、点の変分だけでも差の微分は全射である。十分小さい係数を二つの例外集合の外で選べば、はめ込みを保ちつつ、二点の一致は $2m-2m=0$ 次元になり、三点の一致は $3m-4m<0$ なので起こらない。二点の一致は対角へ集積しない。極限の点を含むはめ込みの局所単射近傍には、十分後の両端点がともに入るからである。対角以外では一致点が孤立しているため、コンパクト性から二重点は有限個にとどまる。この計算の多様体値への拡張は [二点のジェット横断性](/math/differential-topology/transversality/) で扱う。

:::example[横断な二重点の安定性]
$F(t)=(\sin t,\sin2t)$ の交点に対応する $(t,s)=(0,\pi)$ を取り、$H(t,s)=F(t)-F(s)$ とする。そこでの二列は $(1,2)$ と $(1,-2)$ なので行列式は $-4$ である。$H$ で座標を取り直せば、元の差は原点の近くで恒等写像になる。半径 $r$ の閉円板で、摂動後の差を $J$ とし、$\norm{J(0)}<r/2$、$\norm{dJ-I}<1/2$ となるほど $C^1$ で近づける。すると $x\mapsto x-J(x)$ は円板を自分自身に写す縮小写像である。その固定点では $J=0$ であるため、二重点が残る。$C^0$ 摂動にも及ぶ別の証明は [写像度と交叉数](/math/differential-topology/degree/) で使う境界上の写像度から得られる。
:::

:::example[次元を下げたときの階数一の特異点]
$F\colon\R^2\to\R^3$、$F(u,v)=(u,v^2,uv)$ とする。微分の二列 $(1,0,v),(0,2v,u)$ は原点以外で独立で、原点では階数一である。また $F(0,v)=F(0,-v)$ であり、自己交叉する二枝の組が特異点へ集積する。これが、はめ込みを維持した射影の二重点と、微分が退化する射影の二重点との違いである。
:::

### 射影の極限と二重点の符号

割線の長さで規格化した方向は対角上で定義しない。しかし、対角へ近づく列の極限は接線として記録できる。これによってコンパクトな多様体では、正則な射影方向が変形で突然失われる仕組みを限定できる。

:::proposition[割線方向の閉包]{#prop-dtop-secant-closure}
$M$ をコンパクトな境界なし多様体、$F\colon M\to\R^q$ を埋め込みとする。単位割線方向の閉包は、単位割線方向と単位接方向の和集合である。
:::

:::proof
方向が収束する割線の列を取り、コンパクト性から端点の組を部分列で $(p,q)$ に収束させる。$p\ne q$ なら分母は非零のままなので極限はその割線方向である。$p=q$ なら一枚の座標で端点を $x_j,y_j$ と書き、$u_j=(x_j-y_j)/\norm{x_j-y_j}$ を部分列で単位ベクトル $u$ に収束させる。線分上で微分を積分すると
$$
\frac{F(x_j)-F(y_j)}{\norm{x_j-y_j}}=
\int_0^1 dF_{y_j+s(x_j-y_j)}(u_j)\,ds
\longrightarrow dF_p(u).
$$
$dF_p$ が単射であるため右辺は非零であり、再規格化した極限は接方向になる。逆に任意の非零接ベクトルは、座標でそれを初速度に持つ曲線とその始点を結ぶ割線の極限として得られる。
:::

:::example[固有埋め込みでも無限遠の割線が残る]
$F(t)=(t,\arctan t)$ を考える。第一成分が $t$ なので固有埋め込みである。任意の有限な二点と、任意の接方向の勾配は正である。ところが両端点を $t$ と $t+1$ にして $t\to+\infty$ とすると、第二成分の差は零へ収束し、割線方向は $(1,0)$ に近づく。水平軸に沿う射影は $\arctan t$ になり、はめ込みかつ像への同相ではあるが、$\R$ に値を取る固有写像ではない。方向の極限と像の端がどちらも無限遠から生じるので、コンパクト版の閉包の議論をそのまま適用できない。
:::

:::example[局所交点の消滅を起こす変形]
$\R^2$ の二曲線 $y=0$ と $y=x^2-a$ をそれぞれ $x$ の増加方向に向ける。$a>0$ で交点は $x=\pm\sqrt a$ であり、順に二本の接ベクトルを並べた行列式は $2x$ である。従って負と正が一つずつ現れる。$a=0$ では接ベクトルが平行となり、$a<0$ では交点が消える。片方の交点だけを含む小区間では、両端で高さの差が反対符号である。従って、その端の高さの符号を保つ限り、中間値の定理により少なくとも一交点が残る。二点をまとめて含む区間では両端の符号が同じになり、上の変形で反対符号の二交点が一緒に消える。
:::

### 曲面の具体的な四次元埋め込み

:::example[実射影平面の二次式表示]
$S^2$ の点 $(x,y,z)$ から
$$
([x:y:z])\longmapsto(xy,xz,yz,x^2-y^2,x^2+y^2-2z^2)
$$
と写す。これは単位ベクトル $v=(x,y,z)^T$ に対する対称行列 $vv^T-I/3$ を、跡零対称行列の五次元空間で座標表示したものである。行列から $vv^T$ が復元できるため、像の点は直線 $\R v$ を決める。接ベクトル $w\perp v$ に対する行列の微分は $wv^T+vw^T$ であり、これを $v$ に作用させると $w$ が出るので微分は単射である。

この五次元空間を跡零行列 $D=\diag(1,1,-2)$ に沿って四次元へ射影する。異なる射影点が重なれば $vv^T-uu^T$ は $D$ の非零倍になる。しかし左辺の像は高々 $\spn(v,u)$ に含まれ、右辺は階数三である。接ベクトルの微分も像が $\spn(v,w)$ に含まれるので、同じ階数の比較で接方向はつぶれない。従って射影後は単射なはめ込みであり、コンパクト性によって $\R^4$ への埋め込みである。この例では次元による測度評価の代わりに、割線と接線を表す行列の階数から使える射影方向を選べる。
:::

## 演習問題

::::exercise{level=basic #exr-dtop-sard-whitney-1}
$f(t)=t^4-2t^2$ の臨界点と臨界値を求めよ。

:::solution
$f'(t)=4t(t-1)(t+1)$ なので点は $-1,0,1$ である。$f(\pm1)=-1$、$f(0)=0$ であるから値の集合は $\{-1,0\}$ である。
:::
::::

::::exercise{level=basic #exr-dtop-sard-whitney-2}
$f(x,y)=x^2+9y^2$ の等位集合 $f^{-1}(9)$ の $(0,1)$ における接線を求めよ。

:::solution
$df_{(0,1)}=18\,dy$ なので接空間は $\R(1,0)$、点を通る接線は $y=1$ である。
:::
::::

::::exercise{level=basic #exr-dtop-sard-whitney-3}
$f(x,y)=(x,xy)$ の臨界値を求めよ。

:::solution
微分行列式は $x$ である。直線 $x=0$ が臨界点集合で、その像は一点 $(0,0)$ である。
:::
::::

::::exercise{level=basic #exr-dtop-sard-whitney-4}
半径 $2$ の円を $(1,0,1)$ に平行に射影すると、はめ込みが保たれることを示せ。

:::solution
円を $z=0$ に置くと接ベクトルの第 3 成分は常に零である。射影の核は第 3 成分が零でないベクトルで張られ、接線との共通部分が零なので微分が単射である。
:::
::::

::::exercise{level=advanced #exr-dtop-sard-whitney-5}
$H\colon\R^n\to\R^n$ が $C^1$ で各点で $\rank dH<n$ なら、その像は測度零であることを、線形近似を使って示せ。

:::solution
コンパクト立方体を辺長 $h$ の小立方体で分割する。微分の一様連続性により各片の像は、基点での線形像から距離 $h\omega(h)$ 以内にあり、$\omega(h)\to0$ である。線形像は半径 $Ch$ の高々 $(n-1)$ 次元円板に含まれる。直交座標で囲うとその近傍の体積は $O(h^n\omega(h))$ である。片数が $O(h^{-n})$ なので全体の外測度は任意に小さい。コンパクト立方体の可算和で結論を得る。
:::
::::

::::exercise{level=advanced #exr-dtop-sard-whitney-6}
連続関数 $f\colon\R\to\R$ が $[-1,1]$ の近傍で滑らかとする。$|g(x)-f(x)|<e^{-x^2}$ で、$[-1,1]$ 上で一致する滑らかな $g$ の存在を示せ。

:::solution
$\eps(x)=e^{-x^2}$ を正の連続関数として :ref[thm-dtop-whitney-approximation] を用いる。各中心 $p_i$ の値を従属する重みで平均すれば誤差は凸結合の不等式で抑えられる。$[-1,1]$ の近傍で $1$、滑らかさが既知の領域に台を持つ $\eta$ を取り、$\eta f+(1-\eta)g_0$ とすれば局所一致も得られる。
:::
::::

::::exercise{level=advanced #exr-dtop-sard-whitney-7}
$f\colon M\to\R^a$ が固有な埋め込みなら、$\norm{g-f}\le1$ の連続写像 $g$ も固有であることを示せ。

:::solution
$K\subset\R^a$ がコンパクトなら、その閉 $1$ 近傍 $K_1$ は閉有界でコンパクトである。$g^{-1}(K)$ は $f^{-1}(K_1)$ の閉部分集合である。固有性から後者はコンパクトであり、前者もコンパクトである。
:::
::::

::::exercise{level=advanced #exr-dtop-sard-whitney-8}
標準球面 $S^2\subset\R^3$ に対して、どの平面への直交射影もはめ込みにならないことを示せ。

:::solution
射影の核の方向を $w\ne0$ とする。$p\perp w$ となる単位点 $p$ を選ぶと、$T_pS^2=p^\perp$ に $w$ が入る。そこで射影の微分は $w$ を零に送る。
:::
::::

::::quiz{answer="16" tol="1e-6"}
$t\mapsto t^3-12t$ の正の臨界値はいくつか。

:::explanation
導関数は $3(t^2-4)$ なので臨界点は $\pm2$ であり、値は $-16,16$ である。
:::
::::

::::quiz{answer="1" tol="1e-6"}
$f(x,y,z)=(x,y^2+z)$ のすべての非空な逆像の次元はいくつか。

:::explanation
$x,z$ 列の小行列が単位行列で微分は全射である。正則値定理によって次元は $3-2=1$ である。
:::
::::

::::quiz
正則値について正しい記述を選べ。

- [x] 逆像が空なら正則値である。
- [ ] 同じ逆像に正則点が一つあれば正則値である。
- [ ] 臨界点を持つ写像には正則値がない。

:::explanation
逆像のすべての点で微分が全射という条件なので空なら成立する。一方、一点でも臨界点を含む逆像の値は臨界値である。
:::

埋め込みの直交射影で単射性を失う方向を選べ。

- [x] 相異なる二点の割線方向。
- [ ] 接方向すべて。

:::explanation
二点の像が等しいことと、その差が射影の核の直線に入ることは同値である。
:::

次元 $4$ のコンパクト多様体に弱 Whitney 埋め込み定理を適用したとき、保証される Euclid 空間の次元はいくつか。
