## この章の目標

- 完全積分の包絡線が方程式を満たす理由を説明する。
- 特性帯の方程式を導き、初期勾配の適合条件を確かめる。
- 凸 Hamilton 関数に対して Hopf–Lax 公式を導く。
- 試験関数を用いて角のある解を判定し、比較原理を証明する。
- 最適制御の価値関数と動的計画法を対応づける。

## 完全積分と包絡線

:ref[thm-pde-quasilinear-local]{text="準線形方程式の特性曲線法"} では位置と値を追った。最高階の微分そのものが非線形に入ると、勾配も未知量として追う必要がある。まず解の族が直接見つかる場合を調べると、その族の包絡線からさらに多くの解を作れる。

:::definition[完全積分]{#def-pde-complete-integral}
$F(x,z,p)=0$ の解族 $v(x,A)$ が $n$ 個の実パラメータ $A$ を持ち、$D_A(v,D_xv)$ の階数が $n$ であるとき、この族を局所的な :term[完全積分]{en="complete integral" yomi="かんぜんせきぶん"} と呼ぶ。
:::

:::proposition[包絡線の構成]{#prop-pde-envelope}
$v(x,a)$ を $C^2$ な解族とし、$a=a(x)$ を $C^1$ 写像とする。$D_av(x,a(x))=0$ ならば $u(x)=v(x,a(x))$ は解である。特に $D^2_{aa}v$ が停留点で可逆なら、陰関数定理でこのような $a(x)$ が局所的に得られる。
:::

:::proof
連鎖律により $D_xu=D_xv+(D_xa)^\top D_av=D_xv$ である。よって $F(x,u,D_xu)=F(x,v,D_xv)=0$ である。可逆条件の主張は $D_av=0$ に :ref[thm-anl-implicit-function] を適用して得る。
:::

:::example[二次 Hamilton 関数の包絡線]
$u_t+\frac12u_x^2=0$ に対し $v(t,x;p,c)=px-tp^2/2+c$ は完全積分である。$c=-p^2/4$ を選び $p$ について停留させると $p=2x/(1+2t)$、$u=x^2/(1+2t)$ になる。$t=0$ で $u=x^2$ である。$t=-1/2$ ではパラメータの停留式から $p$ を決められない。
:::

:::example[Clairaut 型の偏微分方程式]
$u=x\cdot Du-|Du|^2$ には平面 $u=A\cdot x-|A|^2$ の解族がある。$x-2A=0$ で停留させると $u=|x|^2/4$ が得られる。平面では勾配が一定である一方、包絡線では勾配が点ごとに変わる。
:::

### 一般積分と特異積分

完全積分 $v(x,a)$ のパラメータをすべて固定すれば一つの解になる。ここから任意関数を含む局所解を作るには、$a=(p,q)$、$p\in\R^{n-1}$ と分け、$q=\psi(p)$ として $W(x,p)=v(x,p,\psi(p))$ の包絡線を取る。$W_p=0$ と $\det W_{pp}\ne0$ が成り立つ点で $p=p(x)$ を陰関数として解けば、$D_x W(x,p(x))=D_x W(x,p)$ である。この等式を元の式へ入れると解になる。従って固定パラメータの解、任意関数を選んだ族の包絡線、全パラメータについて停留させた包絡線は区別される。最後のものが固定パラメータで表せない場合は、通常 :term[特異積分]{en="singular integral" yomi="とくいせきぶん"} と呼ぶ。

:::example[平面族から放物面を作る]
二変数で $u=xu_x+yu_y+u_x^2+u_y^2$ とする。$v=ax+by+a^2+b^2$ とおけば $D_xv=(a,b)$ なので任意の $(a,b)$ について解である。全パラメータについて停留させると $a=-x/2$、$b=-y/2$ になり、$u=-(x^2+y^2)/4$ を得る。一方、$b=2a$ に制限すると $W=a(x+2y)+5a^2$ なので $W_a=0$ は $a=-(x+2y)/10$ となる。得られる $u=-(x+2y)^2/20$ の Hessian は階数一で、全パラメータの包絡面の Hessian は階数二である。どちらの場合も $x u_x+y u_y=2u$、$u_x^2+u_y^2=-u$ なので元の式を満たす。
:::

:::example[端点に止まる下包絡線]
$u=xu'+(u')^2$ の直線解 $ax+a^2$ のうち $a\in[-1,1]$ だけを使う。最小点は $a=-x/2$ を区間に切り詰めた値なので
$$
u(x)=\begin{cases}
x+1&x<-2,\\
-x^2/4&-2\le x\le2,\\
-x+1&x>2.
\end{cases}
$$
$x=-2$ で中央部の導関数は $1$、$x=2$ で $-1$ である。従って導関数が両端でつながり、各区分で成り立つ式が継ぎ目でも連続性で成立する。中央部を作るには停留条件が使えるが、外側では許容範囲の端点を固定している。
:::

:::example[完全積分の包絡線と二階微分]
$u=xu_x+u_x^2/3+2$ を考える。直線族 $J(a;x)=ax+a^2/3+2$ は全て解なので、その包絡線を取り、$x=2$ で $a=-3,-2$ と比べる。

まず候補の選択を一変数 $a$ の問題にする。停留条件は $J_a=0$ であり、境界や無限遠も許される場合は停留点と分けて扱う。次の式では一階微分を取って零になる点を求め、二階微分を残しておく。

$$
\begin{aligned}
J(a)&=\frac{a^{2}}{3} + a x + 2\\
J_a&=\frac{\partial}{\partial a} \left(\frac{a^{2}}{3} + a x + 2\right)=\frac{2 a + 3 x}{3}\\
J_{aa}&=\frac{\partial^{2}}{\partial a^{2}} \left(\frac{a^{2}}{3} + a x + 2\right)=\frac{2}{3}\\
a_*&=- \frac{3 x}{2}\\
J_a(a_*)&=0,\qquad a=- \frac{3 x}{2}
\end{aligned}
$$

停留値と、その点から $h$ だけ動かした差を計算する。一次項が相殺しているため、展開の先頭から局所の振る舞いが分かる。一方、停留点が全体で最小か最大かを結論するには、許容範囲全体でこの差の符号を調べる必要がある。

$$
\begin{aligned}
J(a_*)&=2 - \frac{3 x^{2}}{4}=- \frac{3 x^{2} - 8}{4},\qquad a=- \frac{3 x}{2}\\
J_{aa}(a_*)&=\frac{2}{3}\\
J(a_*+h)-J(a_*)&=x \left(h - \frac{3 x}{2}\right) + \frac{\left(h - \frac{3 x}{2}\right)^{2}}{3} + \frac{3 x^{2} - 8}{4} + 2=\frac{h^{2}}{3}\\
\text{二次係数}&=\frac{1}{3}
\end{aligned}
$$

指定した値で目的関数を比較する。$a$ 自体の値と、そこでの目的関数の値は別の量である。解の族を作る場合は、選んだ $a$ を元の式に代入して得られる $J(a_*;x)$ が包絡線または値関数になる。

$$
\begin{aligned}
a_*\text{ の具体値}&=-3\\
J_*\text{ の具体値}&=-1\\
J&=-1,\qquad a=-3\\
J&=- \frac{2}{3},\qquad a=-2\\
\text{二つの値の差}&=\frac{1}{3}\\
\text{停留点まわりの差}&=\frac{h^{2}}{3}
\end{aligned}
$$

停留値は $u=2-3x^2/4$ である。$u_x=-3x/2$ を PDE に代入すると $xu_x+u_x^2/3+2=2-3x^2/4$ になる。固定した $a$ の直線は勾配一定だが、包絡線の勾配は $x$ とともに変わる。この差は $J_a=0$ で初めて $a$ が動いても PDE を保てることによる。
:::

:::example[任意関数で制限した完全積分の族]
$u=xu_x+yu_y+u_x^2+u_y^2$ の平面族から $p_y=1-p_x$ の制限を選ぶ。このとき $J=ax+(1-a)y+a^2+(1-a)^2$ である。

まず候補の選択を一変数 $a$ の問題にする。停留条件は $J_a=0$ であり、境界や無限遠も許される場合は停留点と分けて扱う。次の式では一階微分を取って零になる点を求め、二階微分を残しておく。

$$
\begin{aligned}
J(a)&=a^{2} + a x + y \left(1 - a\right) + \left(1 - a\right)^{2}\\
J_a&=\frac{\partial}{\partial a} \left(a^{2} + a x + y \left(1 - a\right) + \left(1 - a\right)^{2}\right)=4 a + x - y - 2\\
J_{aa}&=\frac{\partial^{2}}{\partial a^{2}} \left(a^{2} + a x + y \left(1 - a\right) + \left(1 - a\right)^{2}\right)=4\\
a_*&=- \frac{x}{4} + \frac{y}{4} + \frac{1}{2}\\
J_a(a_*)&=0,\qquad a=- \frac{x}{4} + \frac{y}{4} + \frac{1}{2}
\end{aligned}
$$

停留値と、その点から $h$ だけ動かした差を計算する。一次項が相殺しているため、展開の先頭から局所の振る舞いが分かる。一方、停留点が全体で最小か最大かを結論するには、許容範囲全体でこの差の符号を調べる必要がある。

$$
\begin{aligned}
J(a_*)&=x \left(- \frac{x}{4} + \frac{y}{4} + \frac{1}{2}\right) + y \left(\frac{x}{4} - \frac{y}{4} + \frac{1}{2}\right) + \left(- \frac{x}{4} + \frac{y}{4} + \frac{1}{2}\right)^{2} + \left(\frac{x}{4} - \frac{y}{4} + \frac{1}{2}\right)^{2}=- \frac{x^{2} - 2 x y - 4 x + y^{2} - 4 y - 4}{8},\qquad a=- \frac{x}{4} + \frac{y}{4} + \frac{1}{2}\\
J_{aa}(a_*)&=4\\
J(a_*+h)-J(a_*)&=x \left(h - \frac{x}{4} + \frac{y}{4} + \frac{1}{2}\right) + y \left(- h + \frac{x}{4} - \frac{y}{4} + \frac{1}{2}\right) + \left(- h + \frac{x}{4} - \frac{y}{4} + \frac{1}{2}\right)^{2} + \left(h - \frac{x}{4} + \frac{y}{4} + \frac{1}{2}\right)^{2} + \frac{x^{2} - 2 x y - 4 x + y^{2} - 4 y - 4}{8}=2 h^{2}\\
\text{二次係数}&=2
\end{aligned}
$$

指定した値で目的関数を比較する。$a$ 自体の値と、そこでの目的関数の値は別の量である。解の族を作る場合は、選んだ $a$ を元の式に代入して得られる $J(a_*;x)$ が包絡線または値関数になる。

$$
\begin{aligned}
a_*\text{ の具体値}&=0\\
J_*\text{ の具体値}&=2\\
J&=2,\qquad a=0\\
J&=4,\qquad a=1\\
\text{二つの値の差}&=2\\
\text{停留点まわりの差}&=2 h^{2}
\end{aligned}
$$

$J_a=0$ から求めた $a_*$ での $u_x$ は $a_*$、$u_y$ は $1-a_*$ であり、その和は $1$ である。従って全パラメータを止めた $-(x^2+y^2)/4$ とは別の解である。例えば $(x,y)=(3,1)$ では $a_*=0$ で、$u=2$、$u_x=0,u_y=1$ となる。
:::

## 特性帯の方法

### 勾配を含む軌道

$F$ を $(x,z,p)\in\R^n\times\R\times\R^n$ の $C^2$ 関数とする。$C^2$ 解 $u$ に対し、$F(x,u(x),Du(x))=0$ を $x_i$ で微分すると

$$
F_{x_i}+F_z u_i+\sum_j F_{p_j}u_{ji}=0.
$$

$X'=F_p$ を選ぶと最後の項は $P_i'=d(u_i(X))/ds$ になる。さらに $Z'=P\cdot X'$ であるから、:term[特性帯]{en="characteristic strip" yomi="とくせいたい"} は

$$
X'=F_p,\qquad Z'=P\cdot F_p,\qquad P'=-F_x-F_zP .
\label{eq-pde-charpit}
$$

に従う。右辺の各偏微分は $(X,Z,P)$ で評価する。

:::theorem[特性帯による局所構成]{#thm-pde-characteristic-strip}
$\sigma$ を階数 $n-1$ の $C^2$ 初期面、$g$ をその上の $C^2$ データとする。$P_0$ が

$$
P_0\cdot\partial_{y_i}\sigma=\partial_{y_i}g,\qquad
F(\sigma,g,P_0)=0
$$

を満たし、$F_p(\sigma,g,P_0)$ が初期面に横断的とする。選んだ $P_0(y_0)$ の枝に対応する局所 $C^2$ 解が存在し、同じ初期勾配を持つ局所 $C^2$ 解の中で一意である。
:::

:::proof
$P_0$ の接成分は $Dg$ により決まる。法線成分を未知数にすると $F=0$ のその成分に関する微分が $F_p\cdot\nu\ne0$ であり、陰関数定理で $C^1$ の枝が得られる。ODE :eqref[eq-pde-charpit] を初期値 $(\sigma,g,P_0)$ で解く。連鎖律で

$$
(F(X,Z,P))'=F_x\cdot F_p+F_z P\cdot F_p+F_p\cdot(-F_x-F_zP)=0
$$

なので、帯の上では $F=0$ である。$q_i=Z_{y_i}-P\cdot X_{y_i}$ と置く。$Z'=P\cdot X'$ を $y_i$ 微分して積の法則を使うと $q_i'=P_{y_i}\cdot F_p+(F_x+F_zP)\cdot X_{y_i}$ である。他方 $0=\partial_{y_i}F=F_x\cdot X_{y_i}+F_z Z_{y_i}+F_p\cdot P_{y_i}$ なので $q_i'=-F_zq_i$ となる。初期値は $0$ であるから $q_i=0$ である。$s$ 方向にも $Z'=P\cdot X'$ がある。横断性により $(s,y)\mapsto X$ は可逆な局所座標なので、$u=Z\circ X^{-1}$ は $Du=P\circ X^{-1}$ を満たす。$P$ の $C^1$ 性から $u$ は $C^2$ である。任意の候補解のグラフと勾配は同じ ODE に従うので一意性も従う。
:::

:::example[枝の選択が必要な場合]
$F=|p|^2-1$ に $x_2=0$ 上で $u=x_1/2$ を課す。適合する $p=(1/2,\pm\sqrt3/2)$ はどちらも $2p$ の第 2 成分が $0$ でなく、それぞれ $u=x_1/2\pm\sqrt3x_2/2$ を与える。同じ値の条件に対し二つの枝があるので、横断性は初期勾配を選ばずに一意性を主張する条件にはならない。
:::

:::example[勾配と値が一緒に変わる場合]
$F=p_x+z-2x$、$u(0,y)=y$ とする。$X=(s,y)$、$Z'=2s-Z$ であるから $u=2x-2+(y+2)e^{-x}$ である。$P_y'=-P_y$ より $P_y=e^{-x}$ となり、構成した $u_y$ と一致する。
:::

### 接触形式による整合性の伝播

特性帯では $p$ を独立変数として運ぶ。その値が実際に $D_xu$ かどうかは、軌道を作るだけでは分からない。そこで $(x,z,p)$ 上の一次微分形式 $\alpha=\dd z-p\cdot\dd x$ を考える。滑らかな解のグラフの上では $z=u(x)$、$p=Du(x)$ なので $\alpha$ をすべての接方向に評価すると零になる。

:::lemma[接触条件の同次方程式]{#lem-pde-contact-transport}
$F=0$ に入る初期帯を特性方程式で運び、ラベル $a$ の一成分について $E=z_a-p\cdot x_a$ と置く。このとき $\dot E=-F_z E$ である。
:::

:::proof
$\dot z=p\cdot F_p$、$\dot p=-F_x-pF_z$、$\dot x=F_p$ から
$$
\begin{aligned}
\dot E
&=p_a\cdot F_p+p\cdot (F_p)_a
 +(F_x+pF_z)\cdot x_a-p\cdot (F_p)_a\\
&=\partial_a F-F_z(z_a-p\cdot x_a).
\end{aligned}
$$
一方 $\dot F=F_x\cdot F_p+F_z(p\cdot F_p)-F_p\cdot(F_x+pF_z)=0$ なので、初期帯上の値が零なら $\partial_aF=0$ である。従って $E(a,s)=E(a,0)\exp(-\int_0^s F_z\dd\tau)$ であり、接方向の整合性を保つ。軌道方向では $\alpha(\partial_s)=\dot z-p\cdot\dot x=0$ が直接成り立つ。これらの方向が投影後に基底を作れば、$p$ はそこで解の勾配である。
:::

:::example[初期勾配に二つの枝がある]
$F=p_x^2+p_y^2-4=0$ で、$y=0$ に $z=x$ を与える。接方向の条件で $p_x=1$、方程式で $p_y=\pm\sqrt3$ であり、どちらも $F_{p_y}=2p_y\ne0$ である。各点 $a$ の軌道は $(x,y)=(a+2s,\pm2\sqrt3s)$、$z=a+8s$ なので、$u=x\pm\sqrt3 y$ となる。非特性であることは、選んだ初期勾配の枝の周りで一意になるための条件である。この例では $z$ のデータだけでは枝を決められない。
:::

### 初期面の eikonal 方程式

$|Du|=1$ の境界値問題を滑らかな曲線 $\sigma(a)$ の近くで考える。$u(\sigma(a))=0$ とすれば接方向の微分が零なので、初期勾配は選んだ単位法線 $\nu(a)$ または $-\nu(a)$ である。ここでは正の枝を選び、$F(p)=(|p|^2-1)/2$ とすると $\dot X=P$、$\dot P=0$、$\dot Z=|P|^2=1$ なので
$$
X(a,s)=\sigma(a)+s\nu(a),\qquad P(a,s)=\nu(a),\qquad Z(a,s)=s
$$
である。$\sigma$ を弧長でパラメータ化し、$\nu'=-\kappa\sigma'$ として符号付き曲率 $\kappa$ を定めれば、$X_a=(1-s\kappa)\sigma'$、$X_s=\nu$ である。したがって $1-s\kappa\ne0$ で局所的に解 $u(X)=s$ を作れる。曲率が一定でないときは退化する距離も初期点で違い、局所解の範囲を決めるには、離れた点の法線が交差しないことも確かめる。

:::example[円の内側まで法線を延ばす]
半径 $2$ の円で内向き法線 $\nu=-\sigma/2$ を選ぶと、$X=(1-s/2)\sigma(a)$ である。$0\le s<2$ で半径は $2-s$、従って $u(x)=2-|x|$ となる。$|x|=1/2$ では $u=3/2$、勾配は $-x/|x|$ で大きさ $1$ である。$s=2$ ではすべての法線が中心に来る。中心の値は $2$ に連続に延長できるが、対向する方向からの勾配が異なるため古典解には延長できない。定常式の粘性条件では、上から触れるときに $|D\phi|-1\le0$、下から触れるときに逆向きの不等式を課す。中心で上から触れる勾配は単位球内にあり、$|p|-1\le0$ を満たす。下から触れる勾配は存在しないので、この連続延長は eikonal 式の粘性解である。
:::

### $z$ と勾配が掛け合わされる特性帯

$F(z,p)=zp-1$、$x$ を一変数とする。初期点 $x=0$ の値を $z(0)=2$ とすれば $p(0)=1/2$ であり、$F_p=z=2$ なので点から解を作れる。特性方程式は
$$
\dot X=Z,qquad \dot Z=PZ,qquad \dot P=-P^2 .
$$
$PZ=1$ が保たれるため $Z=2+s$、$P=(2+s)^{-1}$、$X=2s+s^2/2$ となる。従って $s>-2$ の枝では $Z=\sqrt{4+2X}$ であり、$u(x)=\sqrt{4+2x}$（$x>-2$）である。$u_x=1/\sqrt{4+2x}=P$ なので $u u_x=1$ を直接確認できる。$x=1/2$ では値は $\sqrt5$、勾配は $1/\sqrt5$ である。$s\downarrow-2$ で $X\downarrow-2$、$\dot X=Z\downarrow0$ となり、$P$ は発散する。

この例では最初から $(u^2/2)'=1$ と積分しても解ける。ただしそれは $u$ の符号を別に選ぶ必要がある。特性帯では初期の値 $2$ が正の枝を選び、$Z$ が零に近づくまで投影を反転する。同様に初期値 $-2$ なら負の枝となる。$u=0$ で $zp=1$ を保つ有限な勾配は存在しないため、連続に境界へ近づくこととそこで方程式を古典的に満たすことは異なる。

## Hamilton–Jacobi 方程式と Hamilton 方程式

:::definition[Hamilton–Jacobi 方程式]{#def-pde-hamilton-jacobi}
関数 $H(t,x,p)$ に対し $u_t+H(t,x,D_xu)=0$ を :term[Hamilton–Jacobi 方程式]{en="Hamilton–Jacobi equation" yomi="はみるとんやこびほうていしき"} と呼ぶ。
:::

独立変数に $t$ を含め、$F=p_t+H(t,x,p)$ として :eqref[eq-pde-charpit] を適用する。$t'=1$ なので $t$ で軌道をパラメータ化できる。空間の位置 $X$ と勾配 $P$ と値 $U$ は

$$
\dot X=H_p,\qquad \dot P=-H_x,\qquad \dot U=P\cdot H_p-H
\label{eq-pde-hamilton-characteristics}
$$

を満たす。最初の二式を :term[Hamilton 方程式]{en="Hamilton equations" yomi="はみるとんほうていしき"} という。時間に陽に依存しない $H$ について $dH/dt=H_x\cdot H_p-H_p\cdot H_x=0$ である。時間依存があれば $dH/dt=H_t$ が残る。

$H=H(p)$ のとき、初期値 $u(0,a)=g(a)$ による軌道は $P=Dg(a)$、$X=a+tDH(P)$、$U=g(a)+t(P\cdot DH(P)-H(P))$ である。$H=|p|^2/2$、$g(a)=a^2$ なら $X=(1+2t)a$、$U=(1+2t)a^2$ なので、包絡線と同じ $u=x^2/(1+2t)$ を得る。

:::example[調和振動子]
$H=(p^2+x^2)/2$、$g=0$ とする。$X=a\cos t$、$P=-a\sin t$ であり、$\dot U=(P^2-X^2)/2=-a^2\cos(2t)/2$ である。$U=-a^2\sin(2t)/4$ から $|t|<\pi/2$ で $u=-x^2\tan t/2$ を得る。$t=\pi/2$ では初期位置が全て同じ空間点に投影される。
:::

:::example[線形ポテンシャル]
$H=p^2/2+2x$、$g(x)=x$ なら $P=1-2t$、$X=a+t-t^2$ である。$u$ の空間微分は $P$ に等しいので $u=(1-2t)x+C(t)$ とおく。方程式に代入して $C'=-(1-2t)^2/2$、$C(0)=0$ を得る。よって $C=-t/2+t^2-2t^3/3$ である。
:::

### 作用の端点微分と位相空間の面積

$t$ の範囲を固定し、Hamilton 方程式を満たす軌道をパラメータ $a$ で動かす。作用を $\mathcal A=\int_0^t(P\cdot\dot X-H(s,X,P))\,\dd s$ と定める。$a$ に関する微分を $\delta$ と書くと

$$
\delta\mathcal A
=\int_0^t\big(\delta P\cdot(\dot X-H_p)+P\cdot\delta\dot X-H_x\cdot\delta X\big)\dd s
=[P\cdot\delta X]_0^t .
\label{eq-pde-action-endpoint}
$$

最初の項は $\dot X=H_p$ で消え、二つ目を部分積分すると内部は $-\dot P-H_x=0$ で消える。従って初期値を $g(a)$、$X(0)=a$、$P(0)=Dg(a)$ と選べば、$U=g(a)+\mathcal A$ の $a$ 微分は $P(t)\cdot\delta X(t)$ に等しくなる。これが勾配と特性の整合性を作用から見る方法である。

Hamilton 系では位相空間 $(X,P)$ の面積形も保存される。二つの初期値方向に対する変分を $(\delta_i X,\delta_i P)$ とし、$\omega=\delta_1X\cdot\delta_2P-\delta_2X\cdot\delta_1P$ とおく。線形化した式は $\delta\dot X=H_{px}\delta X+H_{pp}\delta P$、$\delta\dot P=-H_{xx}\delta X-H_{xp}\delta P$ である。積を微分すると、$H_{pp},H_{xx}$ の対称性で純粋な二つの同種項が消え、$H_{xp}=(H_{px})^\top$ で混合項も消える。従って $\omega'=0$ である。この保存は位置への投影の可逆性を意味しない。

:::example[位相空間の回転と位置の集中]
$H=(p^2+x^2)/2$ の流れは $(X,P)=(x\cos t+p\sin t,-x\sin t+p\cos t)$ であり、行列式は $1$ である。初期点を $p=0$ の直線上に限ると、$t=\pi/2$ で $X=0$ に集中する。しかし $P=-x$ が異なるので、拡大した空間では二点が同じ点へ重なることはない。
:::

### 作用を端点の関数として計算する

$H(x,p)=|p|^2/2+V(x)$ とし、$t>0$ における端点 $(a,x)$ を指定する。端点を滑らかに結ぶ軌道が一意に選べる範囲で、作用を
$$
A_t(a,x)=\int_0^t\left(\tfrac12|\dot X(s)|^2-V(X(s))\right)\dd s
$$
と置く。軌道の変分を $Y$ とすると、第一変分は
$$
[\dot X\cdot Y]_0^t-\int_0^t(\ddot X+DV(X))\cdot Y\dd s
$$
であり、軌道上で積分項は零である。よって $D_xA_t=P(t)$、$D_aA_t=-P(0)$ である。終端時刻を動かし位置を固定すると、固定時刻で見た曲線の変分は $Y(t)=-\dot X(t)\delta t$ である。積分の上端から $L(t)\delta t$ が加わるので $\partial_t A=L-P\cdot\dot X=-H(x,P(t))$ となる。従って $g(a)+A_t(a,x)$ の停留条件は $P(0)=Dg(a)$ であり、その滑らかな停留値は Hamilton–Jacobi 方程式を満たす。

:::example[調和振動子の端点作用]
$V(X)=X^2/2$、$0<t<\pi$ とする。$X(s)=a\cos s+(x-a\cos t)\sin s/\sin t$ で端点を満たす。$X''=-X$ なので $(X\dot X)'=\dot X^2-X^2$ であり、
$$
A_t(a,x)=\tfrac12[x\dot X(t)-a\dot X(0)]
=\frac{(x^2+a^2)\cos t-2ax}{2\sin t}.
$$
例えば $t=\pi/2$ では $A=-ax$ であり、$D_x A=-a$ は終端速度と一致する。$t\uparrow\pi$ では $X(t)$ が初期速度に依存しなくなるため、$x\ne-a$ の固定端点を保つ初期速度は発散する。作用の端点表示にも同じ退化が現れる。
:::

:::example[自由粒子と初期データの接線条件]
$H(p)=2p^2$ では $v=4p$、$L(v)=v^2/8$ である。初期作用 $g(a)=a^2/2$ から出る軌道を、最小作用として計算する。

終点 $(t,x)$ を固定し、初期位置 $a$ と平均速度 $v=(x-a)/t$ で費用を書く。$a$ に関する一階微分を零とする候補を求め、二階微分の符号も調べる。目的関数が狭義凸で無限遠に向かって増大する場合、この候補が唯一の最小点になる。

$$
\begin{aligned}
J(a;t,x)&=\frac{4 a^{2} t + a^{2} - 2 a x + x^{2}}{8 t}\\
J_a&=\frac{\partial}{\partial a} \frac{4 a^{2} t + a^{2} - 2 a x + x^{2}}{8 t}=- \frac{- 4 a t - a + x}{4 t}\\
J_{aa}&=\frac{\partial^{2}}{\partial a^{2}} \frac{4 a^{2} t + a^{2} - 2 a x + x^{2}}{8 t}=\frac{4 t + 1}{4 t}\\
a_*&=\frac{x}{4 t + 1}
\end{aligned}
$$

最小点の値を代入する。また終点について微分して運動量を得る。停留条件のため、最小点自身を微分したときの寄与は零である。この勾配から $H(p)=vp-L(v)$ を計算し、時間微分と比較する。

$$
\begin{aligned}
u(t,x)&=\frac{x^{2}}{2 \left(4 t + 1\right)}\\
p&=u_x=\frac{\partial}{\partial x} \frac{x^{2}}{2 \left(4 t + 1\right)}=\frac{x}{4 t + 1}\\
H(p)&=\frac{2 x^{2}}{\left(4 t + 1\right)^{2}}\\
u_t&=\frac{\partial}{\partial t} \frac{x^{2}}{2 \left(4 t + 1\right)}=- \frac{2 x^{2}}{\left(4 t + 1\right)^{2}}\\
u&=1,\qquad t=\frac{1}{4},x=2\\
p&=1,\qquad t=\frac{1}{4},x=2
\end{aligned}
$$

初期の運動量は $p=a_*$ で、Hamilton 方程式は $P$ 一定かつ $X(s)=a_*+4sa_*$ を与える。終点 $X(t)=x$ を解くと同じ $a_*$ になる。従って端点の作用を最小化した軌道と、初期位置に勾配を付けて前進した軌道はこの場合同じである。
:::

### 特性の交差まで Hessian を追う

$u_t+|Du|^2/2=0$、初期値 $g\in C^2$ とする。運動量 $Du$ は特性上で $Dg(a)$ に固定され、$X(t,a)=a+tDg(a)$ である。$I+tD^2g(a)$ が可逆とし、$Du(t,X)=Dg(a)$ を $a$ について微分すれば
$$
D^2u(t,X)=D^2g(a)(I+tD^2g(a))^{-1}
$$
を得る。二つの行列は同じ対称行列の関数なので可換であり、初期 Hessian の固有値 $\mu$ は $\mu/(1+t\mu)$ へ写る。$\mu>0$ なら減少し、$\mu<0$ なら $t=-1/\mu$ に負に発散する。$g(a_1,a_2)=a_1^2-3a_2^2/2$ では $X=((1+2t)a_1,(1-3t)a_2)$ である。$0\le t<1/3$ における解は
$$
u(t,x_1,x_2)=\frac{x_1^2}{1+2t}-\frac{3x_2^2}{2(1-3t)}
$$
となる。実際、時間微分と勾配の二乗の各成分が符号を反対にして相殺する。$t=1/6$ で Hessian の固有値は $3/2,-6$ であり、正方向の減衰と負方向の集中が同じ解に生じる。$g$ が下に二次で発散するこの例では、標準の有界初期値の比較原理をそのまま適用しない。

## Hopf–Lax の公式

:::definition[凸共役]{#def-pde-hamilton-conjugate}
凸関数 $H:\R^n\to\R$ に対して $L(v)=H^*(v)=\sup_{p\in\R^n}(p\cdot v-H(p))$ を :term[凸共役]{en="convex conjugate" yomi="とつきょうやく"} と呼ぶ。
:::

ここでは $H$ は $C^2$ で $D^2H>0$、かつ $H(p)/|p|\to\infty$ と仮定する。$p\cdot v-H(p)$ は無限遠で $-\infty$ になるので最大点は存在し、狭義凹性から一意で、$v=DH(p)$ を満たす。局所逆関数定理により $DL(v)=p$、$D^2L=(D^2H)^{-1}$ である。任意の $R>0$ に対して $L(v)\ge R|v|-\max_{|p|=R}H(p)$ なので $L$ も超線形である。また $p\cdot v-L(v)\le H(p)$ で、$v=DH(p)$ において等号だから $L^*=H$ である。

:::theorem[Hopf–Lax 作用素]{#thm-pde-hopf-lax}
$g:\R^n\to\R$ は Lipschitz 連続とする。$t>0$ に対し

$$
S_tg(x)=\min_{a\in\R^n}\left(g(a)+tL((x-a)/t)\right),\qquad S_0g=g
\label{eq-pde-hopf-lax}
$$

とおく。最小点は存在し、$(x-a)/t$ は $t,x$ に依存しない有界集合に入る。$S_t$ は $g$ の Lipschitz 定数を増やさず、$S_{t+s}=S_tS_s$ を満たす。
:::

:::proof
$K$ を $g$ の Lipschitz 定数とし、$a=x-tv$ と書く。$g(x-tv)+tL(v)\ge g(x)+t(L(v)-K|v|)$ である。$v=0$ の候補と比較すると、最小点は $L(v)-K|v|\le L(0)$ に含まれ、この集合は超線形性でコンパクトである。$v$ 表示で $x$ だけを変えると Lipschitz 定数は $K$ 以下になる。さらに Jensen の不等式により

$$
sL((b-a)/s)+tL((x-b)/t)\ge (s+t)L((x-a)/(s+t)).
$$

$b=a+s(x-a)/(s+t)$ を選べば等号になる。両辺に $g(a)$ を足して最小化すれば半群性が従う。$S_hg-g$ は $h\inf_v(L(v)-K|v|)$ と $hL(0)$ の間である。同じ評価を $S_tg$ に適用すれば時間方向にも Lipschitz 連続である。
:::

$g$ が微分可能なら、最小点で $Dg(a)=DL((x-a)/t)$ となる。よって候補は Hamilton 方程式から得た位置関係 $x=a+tDH(Dg(a))$ に従う。ただし停留点は複数あり得るので、値を決めるには最小条件まで調べる。

:::proposition[最小点と微分可能性]{#prop-pde-hopf-lax-minimizer}
:ref[thm-pde-hopf-lax] の仮定のもと、$t>0$ を固定する。$S_tg$ が $x$ で空間微分可能であることと、そこでの最小点 $a$ が一つであることは同値である。一意な最小点を持つ $(t,x)$ では時空間の微分が存在し、$v=(x-a)/t$、$p=DL(v)$ とおくと
$$
D_x S_tg=p,\qquad \partial_t S_tg=L(v)-p\cdot v=-H(p)
$$
となる。
:::

:::proof
最小点 $a$ を固定すると、$S_tg$ は $g(a)+tL((x-a)/t)$ によって上から支えられる。したがって $S_tg$ が $x$ で空間微分可能なら、すべての最小点で $DL((x-a)/t)$ がその勾配に等しい。$DL$ は $DH$ の逆写像なので単射であり、最小点は一つになる。

逆に $(t,x)$ で最小点が一つとする。近接点 $(t+h,x+k)$ の最小点 $a_{h,k}$ は速度の一様上界によって共通のコンパクト集合に入り、部分列極限は費用の連続性により $(t,x)$ の最小点になる。したがって $a_{h,k}\to a$ である。費用を $J(t,x;b)=g(b)+tL((x-b)/t)$ と書くと、$S_{t+h}g(x+k)-S_tg(x)$ は
$$
J(t+h,x+k;a_{h,k})-J(t,x;a_{h,k})
$$
以上、$J(t+h,x+k;a)-J(t,x;a)$ 以下である。二つの差を $(t,x)$ について展開する。偏微分は $b$ について連続であるため、両側の一次項は同じ極限を持ち、余項を足しても $o(|h|+|k|)$ である。$J$ の偏微分を計算すると主張を得る。
:::

空間と時間の Lipschitz 評価に Rademacher の定理を適用すれば、方程式はほとんど至る所で点ごとの意味でも成り立つ。ただし角での選択はこの等式だけでは決まらない。そのため、粘性条件では微分できない点にも試験関数を当てる。

:::example[二次の初期値]
$H(p)=p^2/2$、$g(a)=a^2$ なら $L(v)=v^2/2$ である。最小化する式 $a^2+(x-a)^2/(2t)$ の導関数を $0$ とすると $a=x/(1+2t)$ である。二階微分は $2+1/t>0$ であり、値は $x^2/(1+2t)$ になる。$g$ は全空間で Lipschitz でないが、この例では二次式の直接計算で最小値を得られる。
:::

:::example[角のある凸な初期値]
$H(p)=p^2/2$、$g(a)=2|a|$ とする。$x\ge0$ なら負の $a$ を $|a|$ に変えると二乗距離は増えない。$a\ge0$ での最小点は $a=\max(0,x-2t)$ なので、対称性により $|x|\le2t$ では $u=x^2/(2t)$、$|x|>2t$ では $u=2|x|-2t$ である。境界で値と勾配が一致する。
:::

### 最小化の枝と二階微分の片側評価

:::proposition[Hopf–Lax 公式の半凹性]{#prop-pde-hopf-lax-semiconcavity}
$D^2H\ge\lambda I$、$\lambda>0$ とする。Lipschitz な初期値に対し

$$
S_tg(x+h)+S_tg(x-h)-2S_tg(x)\le |h|^2/(\lambda t)
\label{eq-pde-hopf-lax-semiconcavity}
$$

である。
:::

:::proof
:ref[def-pde-hamilton-conjugate] から $D^2L\le\lambda^{-1}I$ である。$x$ で選んだ最小点 $a$ を $x\pm h$ の両方の候補に使うと、左辺は $t(L(v+h/t)+L(v-h/t)-2L(v))$ 以下である。$v=(x-a)/t$ とする。線分上の二次の Taylor 余項を積分で評価すると、目的の上界が得られる。
:::

この性質を :term[半凹性]{en="semiconcavity" yomi="はんおうせい"} と呼ぶ。$S_tg(x)-|x|^2/(2\lambda t)$ は中点で凹であり、連続性により任意の割合の凹性が従う。従って上向きの尖った角は許されないが、下向きの角では傾きが跳び得る。その跳びは原始関数から保存則への微分で不連続になる。

:::example[二つの最小点を区別する]
$g(a)=-|a|$、$H(p)=p^2/2$ で $x=0$ とする。右半直線で $-a+a^2/(2t)$ は $a=t$ で最小となり、左では $a=-t$ で同じ値を取る。$x>0$ では $a=x+t$ が最小で、$x<0$ では $a=x-t$ が最小である。従って $S_tg=-|x|-t/2$ であり、原点で右微分 $-1$ と左微分 $1$ が異なる。両枝の停留式がそれぞれ正しくても、枝が交替する場所では微分を取れない。
:::

### 非微分可能な Hamiltonian の凸共役

$H$ を有限値の連続凸関数とする。凸共役 $L(v)=\sup_p(p\cdot v-H(p))$ は値 $+\infty$ を取り得るが、$H(p)=\sup_v(p\cdot v-L(v))$ は保たれる。実際 $H$ のグラフの任意の点に支持平面 $H(q)\ge H(p)+v\cdot(q-p)$ を取ると、$L(v)=p\cdot v-H(p)$ になる。逆向きの不等式は上限の定義から従う。支持平面の構成は凸集合の分離定理で、グラフの下から上図を分離して極限を取ればよい。$H$ が全空間で有限かつ連続であるため、極限の支持超平面が垂直になることはない。

:::example[勾配の大きさが Hamiltonian になる場合]
$H(p)=2|p|$ とする。$|v|\le2$ なら $p\cdot v-H(p)\le0$ で $p=0$ が等号を与える。$|v|>2$ なら $p=\lambda v/|v|$ で上限は無限大である。したがって
$$
S_tg(x)=\min_{|x-y|\le2t}g(y).
$$
$g(y)=|y-3|$ の場合は $y$ を区間 $[x-2t,x+2t]$ の中で $3$ に最も近い点へ動かすので、$S_tg(x)=(|x-3|-2t)_+$ である。$x=0$ では $t=3/2$ で零に達し、その後は零のままである。最小化の範囲が時間とともに広がることで、平坦な領域が拡大する。
:::

:::example[複数の最小点と下向きの角]
$H(p)=p^2/2$、$g(y)=-|y|$ とする。$y\ge0$ では最小候補が $y=x+t$、$y\le0$ では $y=x-t$ であり、それぞれが許容半直線に入らない場合は境界 $y=0$ が候補となる。$x>0$ なら $g$ が偶関数なので、$y<0$ を $-y$ に反射すると同じ $g$ で距離が短くなる。従って最小点は $x+t$ で、値は $-x-t/2$ である。反対側は対称性から $x-t$ で、値は $x-t/2$ である。$x=0$ では二点 $\pm t$ の値が一致する。結局 $u=-|x|-t/2$ であり、最小点の切替えが勾配の下向きの跳躍を生む。この例は $g$ が有界でないが、二次費用が一次の増大を支配するため最小化は成立する。
:::

:::example[二次初期値での最小点と振幅の変化]
$H(p)=p^2/2$、$g(a)=3a^2/2-2a+1$ とする。凸共役は $L(v)=v^2/2$ であり、$g$ は非有界だが二次費用との和は下に強圧である。

終点 $(t,x)$ を固定し、初期位置 $a$ と平均速度 $v=(x-a)/t$ で費用を書く。$a$ に関する一階微分を零とする候補を求め、二階微分の符号も調べる。目的関数が狭義凸で無限遠に向かって増大する場合、この候補が唯一の最小点になる。

$$
\begin{aligned}
J(a;t,x)&=\frac{3 a^{2} t + a^{2} - 4 a t - 2 a x + 2 t + x^{2}}{2 t}\\
J_a&=\frac{\partial}{\partial a} \frac{3 a^{2} t + a^{2} - 4 a t - 2 a x + 2 t + x^{2}}{2 t}=- \frac{- 3 a t - a + 2 t + x}{t}\\
J_{aa}&=\frac{\partial^{2}}{\partial a^{2}} \frac{3 a^{2} t + a^{2} - 4 a t - 2 a x + 2 t + x^{2}}{2 t}=\frac{3 t + 1}{t}\\
a_*&=\frac{2 t + x}{3 t + 1}
\end{aligned}
$$

最小点の値を代入する。また終点について微分して運動量を得る。停留条件のため、最小点自身を微分したときの寄与は零である。この勾配から $H(p)=vp-L(v)$ を計算し、時間微分と比較する。

$$
\begin{aligned}
u(t,x)&=\frac{2 t + 3 x^{2} - 4 x + 2}{2 \left(3 t + 1\right)}\\
p&=u_x=\frac{\partial}{\partial x} \frac{2 t + 3 x^{2} - 4 x + 2}{2 \left(3 t + 1\right)}=\frac{3 x - 2}{3 t + 1}\\
H(p)&=\frac{\left(3 x - 2\right)^{2}}{2 \left(3 t + 1\right)^{2}}\\
u_t&=\frac{\partial}{\partial t} \frac{2 t + 3 x^{2} - 4 x + 2}{2 \left(3 t + 1\right)}=- \frac{\left(3 x - 2\right)^{2}}{2 \left(3 t + 1\right)^{2}}\\
u&=1,\qquad t=1,x=2\\
p&=1,\qquad t=1,x=2
\end{aligned}
$$

最小位置が $a_*=(x+2t)/(1+3t)$ になるので、初期点の勾配 $3a_*-2$ は終点の $u_x$ に一致する。特に $u_{xx}=3/(1+3t)>0$ だが、$1/t$ の半凹性上界より小さい。時間が進むと曲率が小さくなり、初期に二次だった解がこの例で角を作ることはない。
:::

:::example[負の初期曲率と費用の強圧性]
$H(p)=p^2/2$、$g(a)=-a^2/2$、$0<t<1$ とする。$x=1,t=1/2$ で初期点を比較する。

まず候補の選択を一変数 $a$ の問題にする。停留条件は $J_a=0$ であり、境界や無限遠も許される場合は停留点と分けて扱う。次の式では一階微分を取って零になる点を求め、二階微分を残しておく。

$$
\begin{aligned}
J(a)&=- \frac{a^{2}}{2} + \frac{\left(- a + x\right)^{2}}{2 t}\\
J_a&=\frac{\partial}{\partial a} \left(- \frac{a^{2}}{2} + \frac{\left(- a + x\right)^{2}}{2 t}\right)=- \frac{a t - a + x}{t}\\
J_{aa}&=\frac{\partial^{2}}{\partial a^{2}} \left(- \frac{a^{2}}{2} + \frac{\left(- a + x\right)^{2}}{2 t}\right)=- \frac{t - 1}{t}\\
a_*&=\frac{x}{1 - t}\\
J_a(a_*)&=- \frac{\frac{t x}{1 - t} + x - \frac{x}{1 - t}}{t}=0,\qquad a=\frac{x}{1 - t}
\end{aligned}
$$

停留値と、その点から $h$ だけ動かした差を計算する。一次項が相殺しているため、展開の先頭から局所の振る舞いが分かる。一方、停留点が全体で最小か最大かを結論するには、許容範囲全体でこの差の符号を調べる必要がある。

$$
\begin{aligned}
J(a_*)&=- \frac{x^{2}}{2 \left(1 - t\right)^{2}} + \frac{\left(x - \frac{x}{1 - t}\right)^{2}}{2 t}=\frac{x^{2}}{2 \left(t - 1\right)},\qquad a=\frac{x}{1 - t}\\
J_{aa}(a_*)&=- \frac{t - 1}{t}\\
J(a_*+h)-J(a_*)&=- \frac{x^{2}}{2 \left(t - 1\right)} - \frac{\left(h + \frac{x}{1 - t}\right)^{2}}{2} + \frac{\left(- h + x - \frac{x}{1 - t}\right)^{2}}{2 t}=- \frac{h^{2} \left(t - 1\right)}{2 t}\\
\text{二次係数}&=- \frac{t - 1}{2 t}
\end{aligned}
$$

指定した値で目的関数を比較する。$a$ 自体の値と、そこでの目的関数の値は別の量である。解の族を作る場合は、選んだ $a$ を元の式に代入して得られる $J(a_*;x)$ が包絡線または値関数になる。

$$
\begin{aligned}
a_*\text{ の具体値}&=2\\
J_*\text{ の具体値}&=-1\\
J&=- \frac{1}{2},\qquad a=1\\
J&=-1,\qquad a=2\\
\text{二つの値の差}&=- \frac{1}{2}\\
\text{停留点まわりの差}&=\frac{h^{2}}{2}
\end{aligned}
$$

二階微分 $1/t-1$ は $0<t<1$ で正だが $t=1$ で零になる。$t=1$ には $x\ne0$ で目的関数は下に有界でなく、$x=0$ なら全ての $a$ が同じ値を与える。これは有界または Lipschitz な初期値の仮定を外したときの現象であり、Hopf–Lax の標準定理の反例ではない。
:::

### 拡張実数値の費用による Hopf–Lax 表示

有限値の連続凸関数 $H$ と、大域 Lipschitz な実関数 $g$ を考える。$g$ の Lipschitz 定数を $K$ とし、凸共役 $L$ は $+\infty$ を許す。各 $A>0$ について $M_A=\max_{|p|=A} H(p)$ とすれば、$p$ を $v$ と同方向の長さ $A$ のベクトルに取って
$$
L(v)\ge A|v|-M_A
$$
を得る。また $L(v_0)<\infty$ となる $v_0$ がある。例えば原点での $H$ の支持勾配を選べば $L(v_0)=-H(0)$ となる。費用を $g(x-tv)+tL(v)$ と書き、$g(x)-Kt|v|$ を $g$ の下界に使う。$A=K+1$ なら
$$
g(x-tv)+tL(v)\ge g(x)+t(|v|-M_{K+1}).
$$
一方 $v=v_0$ の費用は $g(x)+t(K|v_0|+L(v_0))$ 以下である。よって最小化は $x,t$ に依らない有界な速度集合で行え、下半連続性で最小値が達成される。$|S_tg-g|\le Ct$ が両側から従い、同じ速度を候補に取れば $S_tg$ は $K$-Lipschitz である。

二時刻の合成では速度 $v_1,v_2$ を時間で重み付けした平均を使う。凸性により $tL(v_1)+sL(v_2)\ge(t+s)L((tv_1+sv_2)/(t+s))$ である。逆向きには $v_1=v_2$ を取れば等号である。従って $S_sS_tg=S_{s+t}g$ が成立し、時間に関しても Lipschitz になる。上から触れる試験関数に対して、$L(v)<\infty$ の任意の固定速度で短時間の比較を使うと $\phi_t+D\phi\cdot v\le L(v)$ を得る。$v$ に関する上限により $\phi_t+H(D\phi)\le0$ となる。下から触れる場合は最小速度 $v_h$ を取り、共通の有界性で部分列 $v_h\to v$ を取る。Taylor 展開の余項は速度が有界なので $o(h)$ で一様であり、$L$ の下半連続性から $\phi_t+D\phi\cdot v\ge L(v)$ が従う。よって $\phi_t+H(D\phi)\ge0$ である。従って $H$ や $L$ が微分不可能な場合でも、凸共役の双対性と速度の有界性から粘性解の表示が得られる。

## 粘性解の定義と一意性

:::definition[粘性解]{#def-pde-viscosity}
連続関数 $u$ と $C^1$ 試験関数 $\phi$ を考える。内点で $u-\phi$ が局所最大なら $\phi_t+H(t,x,D_x\phi)\le0$ を要求するものを :term[粘性劣解]{en="viscosity subsolution" yomi="ねんせいれっかい"} と呼ぶ。局所最小で逆の不等号を要求するものを粘性優解と呼ぶ。両方を満たすものが :term[粘性解]{en="viscosity solution" yomi="ねんせいかい"} である。
:::

小さな拡散項を持つ $u^\eps_t+H(Du^\eps)=\eps\Delta u^\eps$ では、上から接する $\phi$ に対して $\Delta u^\eps\le\Delta\phi$ である。従って $\eps\downarrow0$ で残る不等号は劣解の向きになる。例えば局所一様収束を仮定し、接触を $\phi+|(t,x)-(t_0,x_0)|^4$ で狭義にすれば、近くでの最大点が接点へ収束するので $C^2$ 試験関数についてこの極限をとれる。

:::proposition[Hopf–Lax 解の粘性条件]{#prop-pde-hopf-lax-viscosity}
:ref[thm-pde-hopf-lax] の解は $u_t+H(D_xu)=0$ の粘性解である。
:::

:::proof
上から接する場合、半群性から任意の固定 $v$ に対して $u(t,x)\le u(t-h,x-hv)+hL(v)$ である。接触を使うと $\phi(t,x)-\phi(t-h,x-hv)\le hL(v)$ になり、$h\downarrow0$ として $\phi_t+D_x\phi\cdot v\le L(v)$ を得る。$v$ で上限を取れば劣解条件である。下から接する場合は半群性で最小速度 $v_h$ を選ぶ。前節の一様有界性で部分列 $v_h\to v$ があり、等号と接触から $\phi_t+D_x\phi\cdot v\ge L(v)$ を得る。すると $\phi_t+H(D_x\phi)\ge0$ である。時間 $0$ での連続性も前節の評価から従う。
:::

:::theorem[比較原理の基本形]{#thm-pde-viscosity-comparison}
$H(p)$ は連続とする。有界で一様連続な劣解 $u$ と優解 $v$ が $[0,T]\times\R^n$ 上にあり、$u(0,x)\le v(0,x)$ なら、$u\le v$ である。
:::

:::proof
内時刻で正の差があると仮定し、その時刻より大きい $T'<T$ を選ぶ。$\eta>0$ を小さく取って同じ点で $u-v-\eta/(T'-t)>0$ とする。変数を倍にし、$0\le t<T'$、$0\le s\le T$ において

$$
u(t,x)-v(s,y)-\frac{|x-y|^2+|t-s|^2}{2\eps}
-\delta(|x|^2+|y|^2)-\frac{\eta}{T'-t}
$$

を最大化する。$\delta>0$ が小さければ、正の差を仮定した点に二組の変数を一致させて、$\eps,\delta$ によらない正の下界を得る。空間の罰則項と $t=T'$ で発散する項により最大点は存在する。有界性から $|x-y|+|t-s|=O(\sqrt\eps)$、$\delta(|x|^2+|y|^2)=O(1)$、$t$ は $T'$ から一様に離れる。時刻の一方が $0$ なら初期順序と一様連続性で最大値は $o(1)$ 以下になる。また $s\le t+O(\sqrt\eps)<T$ が小さい $\eps$ で成り立つ。したがって両時刻は内点である。ここで $\eps$ を小さく固定し、その後で $\delta\downarrow0$ とする。$p=(x-y)/\eps$ は固定した $\eps$ に対し $O(\eps^{-1/2})$ の有界集合に入るので、その集合上では $H$ の一様連続性を使える。最大点で他方の変数を固定した試験関数を使うと

$$
\frac{\eta}{(T'-t)^2}\le H(p-2\delta y)-H(p+2\delta x)
$$

である。右辺は有界な勾配集合での一様連続性により $\delta\downarrow0$ で $0$ に収束するが、左辺は $\eta/(T')^2$ 以上なので矛盾する。終時刻は連続性で従う。
:::

:::example[折れ方で解が選ばれる]
$u=-|x|-t/2$ は $H=p^2/2$ の粘性解である。$x=0$ に上から接するとき $\phi_t=-1/2$、$\phi_x\in[-1,1]$ なので劣解条件が成り立ち、下から接する $C^1$ 関数は存在しない。対して $|x|-t/2$ には $x=0$ で下から $\phi=-t/2$ が接するため、$\phi_t+\phi_x^2/2=-1/2$ となり優解条件を破る。両関数は $x\ne0$ では同じ方程式を満たす。
:::

### 一様極限と粘性条件

:::proposition[局所一様極限での安定性]{#prop-pde-viscosity-stability}
連続な $H_j(t,x,p)$ が $H$ に局所一様収束し、連続な粘性劣解 $u_j$ が $u$ に局所一様収束するとする。$u_j$ は $u_t+H_j(t,x,D_xu)=0$ の劣解であるとき、$u$ は極限方程式の劣解である。優解にも同様のことが成り立つ。
:::

:::proof
内点 $(t_0,x_0)$ で $u-\phi$ が最大とする。$\phi$ に $|(t,x)-(t_0,x_0)|^4$ を加えると、値と一階の微分を変えずに狭義の最大にできる。中心と十分小さい閉球の境界との間には値の差があるため、$u_j-\phi$ の最大点は大きい $j$ で球の内部にある。その最大点の任意の部分列極限は $u-\phi$ の最大点であり、狭義性で $(t_0,x_0)$ である。$u_j$ の粘性不等式をこの最大点で使い、$\phi$ の微分の連続性と $H_j$ の局所一様収束により極限を取ればよい。優解には最小値と四次項の負号を使う。
:::

:::corollary[一様連続な初期値の Hopf–Lax 解]{#cor-pde-hopf-lax-continuous}
:ref[thm-pde-hopf-lax] の $H$ に対して、有界な一様連続初期値 $g$ であれば、同じ最小化式は有界な時間区間ごとに有界かつ一様連続な唯一の粘性解を与える。
:::

:::proof
$g$ を平滑化すると、有界 Lipschitz な $g_j$ が一様に $g$ に収束する。任意の初期値二つについて、同じ始点と費用を使う比較から $\sup_x|S_tg_1(x)-S_tg_2(x)|\le\norm{g_1-g_2}_\infty$ である。従って $S_tg_j$ は時間も含め一様な Cauchy 列であり、極限は最小化式で与えられる。$g$ が有界で $L$ は超線形なので、固定した $(t,x)$ ごとの最小値は達成される。極限は一様連続で $t=0$ の値も保つ。:ref[prop-pde-viscosity-stability] で解であること、:ref[thm-pde-viscosity-comparison] で一意性が従う。
:::

:::example[初期値が Lipschitz でなくても解がある]
$g(x)=\min(\sqrt{|x|},1)$、$H(p)=p^2/2$ とする。$g$ は有界で $1/2$-Hölder 連続である。$t>0$ に $x=0$ では $a=0$ が初期費用と移動費用を両方 $0$ にするので $S_tg(0)=0$ である。また任意の $x$ で $a=0$ を候補に使うと $0\le S_tg(x)\le x^2/(2t)$ である。初期時刻の原点の角は Lipschitz でもないが、正の時刻には原点で空間微分が存在して $0$ になる。
:::

### 角で試験関数が持てる勾配

左右からの片側微分が異なるとき、試験関数に許される勾配を先に決めれば、粘性条件を直接判定できる。$w$ が $(t_0,0)$ で時間微分 $\beta$ を持ち、左・右の空間微分を $p_-,p_+$ とする。上から触れる $\phi$ について $x>0$ の差商から $\phi_x\ge p_+$、$x<0$ から $\phi_x\le p_-$ が従う。また $\phi_t=\beta$ である。下から触れる場合は $p_-\le\phi_x\le p_+$ となる。これらは必要条件であり、区分線形で時間に線形な例では対応する接平面が実際に試験関数になる。

:::example[下向きの角を許し上向きの角を排除する]
$H(p)=p^2/2$ とし、$w=-2|x|-2t$ を考える。$x\ne0$ では $w_t+H(w_x)=-2+4/2=0$ である。$x=0$ で上から接する勾配は $[-2,2]$ に含まれ、$-2+p^2/2\le0$ である。下から接する勾配は存在しないので、粘性優解の条件も満たされる。次に $v=2|x|-2t$ では $x\ne0$ で同じ古典式が成り立つ。しかし $\phi=-2t$ は $x=0$ で下から触れ、$\phi_t+H(\phi_x)=-2<0$ である。従って $v$ は粘性優解ではない。
:::

:::example[定数項を足した場合の比較]
$u_t+H(Du)=f(t)$ で $f$ が連続なら、$v(t,x)=u(t,x)-\int_0^t f(s)\dd s$ と置けば同次式に帰着する。実際 $v$ に触れる $\phi$ に積分項を戻した関数が $u$ に触れ、粘性不等式から $f(t)$ が相殺される。例えば $H(p)=p^2/2$、$u(0,x)=0$、$f(t)=6t$ なら $v=0$、$u=3t^2$ なので $t=2$ の値は $12$ である。空間依存の外力を引くと $Du$ も変わるため、この帰着には外力が時間のみに依存することが必要である。
:::

### 最大・最小の包絡と粘性不等式

同じ方程式の二つの粘性劣解 $u_1,u_2$ について $w=\max(u_1,u_2)$ は再び劣解である。実際 $w-\phi$ が局所最大を取る点で、$w=u_i$ となる添字を一つ選ぶ。近傍で $u_i-\phi\le w-\phi$、接点で等号なので $\phi$ はその $u_i$ の上側の試験関数になる。従って劣解の不等式が従う。同様に粘性優解の最小は優解である。この結論では試験関数が少なくとも一つの枝に触れることだけを使った。正反対の組合せにした場合には、試験関数が各枝に同じ側から触れるとは限らない。

:::example[二つの古典解の最大と最小で何が違うか]
$H(p)=p^2/2$ で $u_1=2x-2t$ と $u_2=-2x-2t$ は両方とも古典解である。最大は $2|x|-2t$、最小は $-2|x|-2t$。最大に対して $x=0$ で上から触れる試験関数は存在しないので劣解であるが、$\phi=-2t$ が下から触れ残差は $-2$ なので優解ではない。最小では下から触れるものがなく、上から触れるときの勾配は $[-2,2]$ に入るので、残差は $-2+\phi_x^2/2\le0$。従ってこの最小は劣解でもあり、粘性解になる。包絡を作ったときに反対側の粘性条件まで成り立つかは、角で許される勾配の区間と Hamiltonian の値を使って改めて判定する。
:::

### 比較から得る非斉次項の安定性

$u_t+H(Du)=f$、$v_t+H(Dv)=g$ とする。$\sup_x|f(t,x)-g(t,x)|\le M(t)$ で $M$ は連続とし、考える解のクラスで非斉次式の比較が使えるとする。$V=v+\norm{u(0)-v(0)}_\infty+\int_0^t M(s)\dd s$ は $u$ の方程式の優解である。実際、下から触れる試験関数から加えた時刻の関数を引けば $v$ に下から触れ、$v$ の不等式に $M$ を足すと $f$ 以上になる。初期値で $u\le V$ なので比較を使い、$u,v$ を交換すれば
$$
\norm{u(t)-v(t)}_\infty\le
\norm{u(0)-v(0)}_\infty+\int_0^tM(s)\dd s
$$
となる。例えば初期値が同じで $|f-g|\le 2t$ なら時刻 $2$ の差は $4$ 以下である。$f-g=2t$ が空間に依存しないときは $u=v+t^2$ が実際に成り立ち等号となる。これは空間の二階微分や古典解の存在を仮定しない誤差の評価である。

:::example[一様近似で角を丸めても残差の符号は選べる]
$u_\eps=-\sqrt{x^2+\eps^2}-t/2$ とすれば、$u_{\eps,t}+u_{\eps,x}^2/2=-\eps^2/(2(x^2+\eps^2))\le0$ である。従って各 $u_\eps$ は古典的な劣解であり、$|\sqrt{x^2+\eps^2}-|x||\le\eps$ なので $-|x|-t/2$ へ一様に収束する。残差は $x=0$ で常に $-1/2$ であり、一様に零になるわけではない。それでも極限が優解になることは、角で下から接する微分可能な試験関数が存在しないことを別に確かめれば分かる。残差の一様収束に頼らずに解を確認できる例である。
:::

## 最適制御と動的計画法

### 曲線の費用と時間の分割

$t$ 時間を使って $x$ に到着する絶対連続曲線 $\gamma$ の費用を $g(\gamma(0))+\int_0^t L(\dot\gamma)\,\dd s$ と定める。その下限を :term[価値関数]{en="value function" yomi="かちかんすう"} と呼ぶ。Jensen の不等式により、始点 $a$ と終点 $x$ を固定したとき積分費用は $tL((x-a)/t)$ 以上で、等速直線で達成される。従って価値関数は :eqref[eq-pde-hopf-lax] に一致する。

走行費用を $\ell(x,v)$ とすれば経路は一般に曲がる。それでも終点が $x$ の曲線を最後の長さ $h$ の区間で切ると

$$
u(t,x)=\inf_{\gamma(h)=x}
\left\{u(t-h,\gamma(0))+\int_0^h\ell(\gamma(s),\dot\gamma(s))\,\dd s\right\}.
\label{eq-pde-dynamic-programming}
$$

実際、任意の全経路の前半費用は $u$ 以上であるから左辺は右辺以上である。逆に後半の任意の経路に、前半費用が下限から $\eps$ 以内の経路を連結すると左辺が右辺以下になる。この分割を :term[動的計画原理]{en="dynamic programming principle" yomi="どうてきけいかくげんり"} と呼ぶ。

速度をコンパクトな集合 $V$ に制限し、$\ell$ を連続とする。価値関数が $C^1$ なら :eqref[eq-pde-dynamic-programming] は

$$
u_t+\max_{v\in V}\{D_xu\cdot v-\ell(x,v)\}=0
$$

を与える。実際、$h$ 区間内で $|\gamma(s)-x|\le h\max_V|v|$ だから、$u(t-h,\gamma(0))=u(t,x)-hu_t-D_xu\cdot\int_0^h\dot\gamma\,\dd s+o(h)$ であり、費用も $\ell(x,\dot\gamma)$ に置換した誤差が一様に $o(h)$ である。積分の下限は被積分関数の最小値に $h$ を掛けたものであり、一定速度で達成される。試験関数を使う場合も、上から接するときは一定速度の経路、下から接するときは費用が下限から $h^2$ 以内の経路を選ぶことで同じ不等号が得られる。

:::example[最大速度を持つ移動]
一次元で $V=[-2,2]$、$\ell=0$、$g(x)=|x|$ とする。到達可能な初期点は $[x-2t,x+2t]$ なので $u=\max(|x|-2t,0)$ である。Hamilton 関数は $2|p|$ である。$t=1$、$x=5$ では $u=3$ になる。
:::

:::example[同じ到着点でも費用で始点が変わる]
$L(v)=v^2/2$、$g(a)=(a-2)^2$ とする。$t=1$、$x=5$ では $2(a-2)+(a-5)=0$ より $a=3$ を選ぶ。初期費用は $1$、移動費用は $2$、合計は $3$ であり、費用の片方だけを最小化する $a=2$ または $a=5$ より小さい。
:::

### 値関数の連続性と割引

速度集合 $V$ をコンパクトとし、$g$ は有界一様連続、費用 $\ell(x,a)$ は有界連続で $a\in V$ に一様に $x$ について一様連続とする。後退を表す曲線 $X(s)=x-\int_0^s a(r)\dd r$ に沿う費用に割引率 $\rho\ge0$ を入れ、
$$
U(t,x)=\inf_a\left\{\int_0^t e^{-\rho s}\ell(X(s),a(s))\dd s+e^{-\rho t}g(X(t))\right\}
$$
とする。すべての制御で絶対値は $t\norm\ell_\infty+\norm g_\infty$ 以下である。同じ制御で二つの始点を比較すれば軌道の差が固定されるので、空間の連続度は $\omega_g(r)+T\omega_\ell(r)$ 以下である。時間の最初の長さ $h$ を切り離すと、あらゆる最初の制御区間について後続の下限が $U(t-h,X(h))$ になる。逆向きには、その終点から $\eps$ 以内の後続制御を選んで連結する。これで動的計画等式を得る。最初の区間で $|X(h)-x|\le h\max_V |a|$、費用の絶対値は $h\norm\ell_\infty$ 以下である。従って既に得た空間の連続度と $|1-e^{-\rho h}|\le\rho h$ により、時間についても一様連続になる。

接点で $\phi(t,x)=U(t,x)$ となるよう試験関数を定数で調整する。上から触れる $\phi$ を任意の定数制御に適用すると
$$
\phi(t,x)\le\int_0^h e^{-\rho s}\ell(X(s),a)\dd s
+e^{-\rho h}\phi(t-h,x-ha).
$$
$h$ で割り極限を取ると $\phi_t+a\cdot D\phi+\rho U\le\ell(x,a)$ である。下から触れるときは最初の区間に誤差 $h^2$ 以下の制御を選ぶ。$\phi$ の微分の連続性と $\ell$ の空間の連続度により $h$ で割った誤差は $o(1)$ である。得られる
$$
\phi_t+\rho U\ge\frac1h\int_0^h(\ell(x,a(s))-a(s)\cdot D\phi)\dd s-o(1)
\ge\inf_{a\in V}(\ell(x,a)-a\cdot D\phi)-o(1)
$$
から粘性優解の不等式を得る。従って $U_t+\sup_{a\in V}(a\cdot DU-\ell(x,a))+\rho U=0$ である。

:::example[制御を使う利益が費用を上回る場合]
$V=[-1,1]$、$\ell(a)=a^2/2$、$\rho=0$、$g(x)=2x$ とする。$g$ は全空間で有界ではないが、各軌道の変位が $t$ 以下なので各 $(t,x)$ で費用は有限である。費用は $2x+\int_0^t(a(s)^2/2-2a(s))\dd s$ となる。被積分関数は $[-1,1]$ で減少するので $a=1$ が最小、値は $2x-3t/2$ である。Hamiltonian に $p=2$ を代入すると $\sup_{|a|\le1}(2a-a^2/2)=3/2$ であり、$U_t=-3/2$ と打ち消し合う。制約を外すと最適速度は $2$ になり、同じ時間での費用はさらに小さくなる。
:::

### 状態依存の速度と Hamilton–Jacobi–Bellman 方程式

制御集合 $V$ を空でないコンパクト集合とする。速度 $b(x,a)$ は有界連続で $x$ について一様に Lipschitz、走行費用 $\ell(x,a)$ は有界連続で $x$ について一様に一様連続とする。初期費用 $g$ は有界一様連続、割引率 $\rho\ge0$ とする。後ろ向きの軌道を $X(0)=x$、$\dot X=-b(X,a(s))$ とし、可測な制御 $a(s)\in V$ について前と同じ割引費用の下限を取る。軌道は積分方程式の Picard 反復で構成できる。実際、短区間では $b$ の Lipschitz 定数と区間長の積が $1$ 未満なので反復写像は縮小し、有界な速度で順に延長できる。

同じ制御に対して初期位置 $x,y$ を変えると $|X_x(s)-X_y(s)|\le e^{Ls}|x-y|$ である。費用の一様連続性を使うと、任意の有限時間区間で価値関数 $U$ は空間について一様連続になる。軌道の一意性により長さ $h$ の先頭部分と残りを連結できるので、動的計画等式の証明は速度が一定のときと同じである。$|X(h)-x|\le h\norm b_\infty$ をその等式に入れれば、時間についても一様連続になる。

試験関数を用いる短時間の計算では、$\int_0^h b(X(s),a(s))\dd s$ を $\int_0^h b(x,a(s))\dd s$ に替える誤差は $O(h^2)$、費用の同じ置換の誤差は $o(h)$ である。従って上側では任意の定数制御、下側では費用が下限から $h^2$ 以内の制御を使い、
$$
U_t+H(x,D_xU)+\rho U=0,\qquad
H(x,p)=\sup_{a\in V}\{p\cdot b(x,a)-\ell(x,a)\}
$$
の粘性不等式を得る。これを :term[Hamilton–Jacobi–Bellman 方程式]{en="Hamilton–Jacobi–Bellman equation" yomi="はみるとんやこびべるまんほうていしき"} という。

この式も有界一様連続な解のクラスで比較できる。実際、:ref[thm-pde-viscosity-comparison] の変数倍化を用いると、Hamilton 関数の差は
$$
L|x-y||p|+\omega_\ell(|x-y|)
+2\norm b_\infty\delta(|x|+|y|)
$$
以下である。割引項は正の差を仮定した最大点で $\rho(u-v)\ge0$ となり、比較に有利な向きに加わる。最大点で $y$ を $x$ に取り替えた値と比較すると
$$
\frac{|x-y|^2}{2\eps}\le\omega_v(|x-y|)+\delta\big(|x|^2-|y|^2\big)
$$
である。ここで右辺第2項は絶対値が $C\sqrt\delta\,|x-y|$ 以下である。先に $\delta\downarrow0$、次に $\eps\downarrow0$ とすれば、$|x-y||p|=|x-y|^2/\eps$ も零に向かう。従って正の時間罰則に矛盾し、与えた初期費用を持つ解は一意である。

例えば一次元で制御を一つに固定し、$b(x)=\tanh x$、$\ell=0$ とする。後退軌道では $\frac{\dd}{\dd s}\sinh X=-\sinh X$ なので $X(s)=\operatorname{arsinh}(e^{-s}\sinh x)$ である。値は $e^{-\rho t}g(X(t))$ となり、線形輸送の表示と一致する。

:::example[運動費用と終点の位置を同時に選ぶ]
時間 $t$、終点 $x$ に到着する経路の費用を $\int_0^t |\dot X|^2/4$、初期費用を $g(a)=(a-1)^2$ とする。端点 $a,x$ 間では Cauchy–Schwarz により等速の経路が最小費用を与える。

まず候補の選択を一変数 $a$ の問題にする。停留条件は $J_a=0$ であり、境界や無限遠も許される場合は停留点と分けて扱う。次の式では一階微分を取って零になる点を求め、二階微分を残しておく。

$$
\begin{aligned}
J(a)&=\left(a - 1\right)^{2} + \frac{\left(- a + x\right)^{2}}{4 t}\\
J_a&=\frac{\partial}{\partial a} \left(\left(a - 1\right)^{2} + \frac{\left(- a + x\right)^{2}}{4 t}\right)=- \frac{- 4 a t - a + 4 t + x}{2 t}\\
J_{aa}&=\frac{\partial^{2}}{\partial a^{2}} \left(\left(a - 1\right)^{2} + \frac{\left(- a + x\right)^{2}}{4 t}\right)=\frac{4 t + 1}{2 t}\\
a_*&=\frac{4 t + x}{4 t + 1}\\
J_a(a_*)&=- \frac{4 t - \frac{4 t \left(4 t + x\right)}{4 t + 1} + x - \frac{4 t + x}{4 t + 1}}{2 t}=0,\qquad a=\frac{4 t + x}{4 t + 1}
\end{aligned}
$$

停留値と、その点から $h$ だけ動かした差を計算する。一次項が相殺しているため、展開の先頭から局所の振る舞いが分かる。一方、停留点が全体で最小か最大かを結論するには、許容範囲全体でこの差の符号を調べる必要がある。

$$
\begin{aligned}
J(a_*)&=\left(-1 + \frac{4 t + x}{4 t + 1}\right)^{2} + \frac{\left(x - \frac{4 t + x}{4 t + 1}\right)^{2}}{4 t}=\frac{\left(x - 1\right)^{2}}{4 t + 1},\qquad a=\frac{4 t + x}{4 t + 1}\\
J_{aa}(a_*)&=\frac{4 t + 1}{2 t}\\
J(a_*+h)-J(a_*)&=\left(h - 1 + \frac{4 t + x}{4 t + 1}\right)^{2} - \frac{\left(x - 1\right)^{2}}{4 t + 1} + \frac{\left(- h + x - \frac{4 t + x}{4 t + 1}\right)^{2}}{4 t}=\frac{h^{2} \left(4 t + 1\right)}{4 t}\\
\text{二次係数}&=\frac{4 t + 1}{4 t}
\end{aligned}
$$

指定した値で目的関数を比較する。$a$ 自体の値と、そこでの目的関数の値は別の量である。解の族を作る場合は、選んだ $a$ を元の式に代入して得られる $J(a_*;x)$ が包絡線または値関数になる。

$$
\begin{aligned}
a_*\text{ の具体値}&=3\\
J_*\text{ の具体値}&=8\\
J&=16,\qquad a=1\\
J&=8,\qquad a=3\\
\text{二つの値の差}&=-8\\
\text{停留点まわりの差}&=2 h^{2}
\end{aligned}
$$

値関数は $(x-1)^2/(1+4t)$ であり、$u_t+(u_x)^2=0$ を満たす。例えば $x=5,t=1/4$ では $a_*=3$ で、速度は $8$。始点を $1$ に固定すれば初期費用は零になるが移動費用が大きい。最小化はこの二つの費用の釣り合いを取る。
:::

### 制御制約が作る区分的な Hamiltonian

$V=[-A,A]$、$\ell(a)=a^2/2$ とする。$pa-a^2/2=-(a-p)^2/2+p^2/2$ なので、最大を取る制御は $p$ を区間に切り詰めた値である。従って
$$
H(p)=
\begin{cases}
p^2/2,& |p|\le A,\\
A|p|-A^2/2,& |p|>A .
\end{cases}
$$
$|p|=A$ の両側で値と導関数は一致するが、二階微分は $1$ と $0$ で異なる。速度の制約は大きい勾配での費用の増え方を線形に変える。初期値 $g(x)=px+b$ なら時間区間にわたり定数制御を選ぶことで、費用は $g(x)+t(a^2/2-pa)$。時刻によって制御を変えても各時刻の被積分関数の最小より小さくならない。従って値関数は $g(x)-tH(p)$ であり、古典的にも式を満たす。例えば $A=2,p=3,b=1$ では $H=4$、$u(1,1)=0$。速度制約を外すと $H=9/2$ となり、同じ観測点の最小費用は $-1/2$ に下がる。

$u_t+u_x^2=0$ の平面解を用いて $g(x)=x^2$ の解を求めよ。

$v=px-tp^2-p^2/4$ を $p$ で停留させると $p=2x/(1+4t)$、$u=x^2/(1+4t)$ である。$u_t=-4x^2/(1+4t)^2$ と $u_x^2=4x^2/(1+4t)^2$ が相殺する。

$H(p)=3p^2/2$ の凸共役を求め、$g(x)=2x$ の Hopf–Lax 最小値を直接計算せよ。

:::solution
$pv-3p^2/2$ は $p=v/3$ で最大となり $L=v^2/6$ である。$2a+(x-a)^2/(6t)$ は $a=x-6t$ で最小となり、値は $2x-6t$ である。

$u_x+u=0$、$u(0,y)=2y$ の特性帯を求めよ。

:::solution
$F=p_x+z$ なので $X=(s,y)$、$Z'=-Z$、$P'=-P$ である。初期条件は $Z(0)=2y$、$P(0)=(-2y,2)$ である。従って $u=2ye^{-x}$、$(u_x,u_y)=(-2y,2)e^{-x}$ となる。

速度を $[-1,3]$ に制限し走行費用を $0$ とする。初期費用 $|x|$ から $u(2,7)$ を求めよ。

:::solution
始点 $a$ は $a\in[7-3\cdot 2,7+2]=[1,9]$ である。最小費用は $a=1$ での $1$ であり、速度 $3$ がこれを実現する。

::::exercise{level=advanced}
$F=p_1^2+p_2^2-4$ に $x_2=0$ で $u=2x_1$ を課す。初期勾配と横断性を判定せよ。

:::solution
接微分は $p_1=2$ である。$F=0$ から $p_2=0$ なので、速度 $F_p=(4,0)$ は初期面に接する。横断性は成立しないが $u=2x_1$ は解である。従って横断性は局所解の十分条件に使われ、欠けただけで不存在は導けない。
:::
::::

::::exercise{level=advanced}
$g(a)=-2|a|$、$H(p)=p^2/2$ の Hopf–Lax 公式を求め、原点で粘性条件を検証せよ。

:::solution
$x\ge0$ では非負の $a$ を選べる。すると二次式の最小点が $a=x+2t$ であり、対称性で $u=-2|x|-2t$ となる。原点で上から接する傾きは $[-2,2]$、時間微分は $-2$ なので $\phi_t+\phi_x^2/2\le0$ である。下から接するには $\phi_x$ が同時に $2$ 以上かつ $-2$ 以下となる必要があり、そのような試験関数はない。
:::
::::

::::exercise{level=advanced}
$H=p^2/2$、$g(x)=\cos x$ とする。$0<t<1$ で最小点が一意であることを示し、$x=0$ の $u_{xx}$ を求めよ。

:::solution
目的関数の二階微分は $1/t-\cos a>0$ で、無限遠で発散するので最小点は一意である。条件 $x=a-t\sin a$ を微分すると $a_x=(1-t\cos a)^{-1}$ である。$x=0$ では $a=0$ であり、$u_x=-\sin a$ より $u_{xx}(t,0)=-1/(1-t)$ である。
:::
::::

::::exercise{level=advanced}
$g_1,g_2$ を Lipschitz 連続とし、$g_1-g_2$ は有界とする。Hopf–Lax 作用素が一様ノルムで縮小的であることを証明せよ。

:::solution
$M=\sup|g_1-g_2|$ とする。全ての始点で $g_2-M\le g_1\le g_2+M$ だから、両辺に同じ費用を足し下限を取ると $S_tg_2-M\le S_tg_1\le S_tg_2+M$ になる。$g_1=g_2+c$ なら等号となるので定数 $1$ は改善できない。
:::
