## この章の目標

- 多元環の定義を中心への準同型と双線形な積の両方で説明する。
- 群環、行列環、テンソル代数の積を計算する。
- 対称代数と外積代数を関係式から構成し、行列式を外積で表す。
- 四元数の積と逆元を求め、有限次元実斜体を分類する。

## 多元環の定義と例

### スカラー倍と積を両立させる

:::definition[多元環]{#def-ring-algebra}
体 $K$ 上の :term[多元環]{en="algebra over a field" yomi="たげんかん"} は、$K$ ベクトル空間 $A$ に結合的な双線形積とその単位元 $1_A$ を備えたものである。写像は環準同型かつ $K$ 線形とする。
:::

この定義は、環 $A$ と環準同型 $K\to Z(A)$ を与えることに等しい。双線形性より $(c1_A)a=c a=a(c1_A)$ であり、$c\mapsto c1_A$ は積、和、単位元を保つ。逆に $\eta\colon K\to Z(A)$ から $ca=\eta(c)a$ と置けば分配性と結合性でベクトル空間の公理が成り立つ。中心性で $(ca)b=a(cb)=c(ab)$ となる。

任意の両側イデアル $I$ は $K$ 線形部分空間でもある。実際 $c\in K$、$u\in I$ なら $cu=(c1_A)u\in I$ である。そのため商 $A/I$ には剰余の積とスカラー倍から多元環の構造が入る。準同型 $A\to B$ の核で割ると像の多元環に同型になる。環の第一同型定理の写像 $[a]\mapsto f(a)$ がスカラー倍も保つためである。

:::example[二次拡張と冪零元]
$\C$ は実数を係数とする実多元環であり、基底 $1,i$ と積 $i^2=-1$ をもつ。例えば $(2+i)(1-3i)=5-5i$ である。これに対して $\R[t]/(t^2)$ は基底 $1,\eps$ と積 $\eps^2=0$ をもち、$(2+\eps)(1-3\eps)=2-5\eps$ となる。体上の次元が同じでも積の関係により違う環になる。
:::

:::example[部分多元環]
$M_2(\Q)$ の上三角行列全体は和、スカラー倍、積で閉じ、単位行列を含むため部分多元環である。$E_{11},E_{12},E_{22}$ が基底である。$E_{11}E_{12}=E_{12}$ かつ $E_{12}E_{11}=0$ なので非可換である。
:::

### 構造定数と生成関係を使う

有限次元では基底を一つ固定して積を表にすれば、どの元の積も計算できる。結合性は基底に対して調べるだけでよい。なぜなら $(ab)c-a(bc)$ が三変数で線形だからである。

:::proposition[構造定数による結合性の判定]{#prop-ring-algebra-structure-constants}
基底 $e_1,\ldots,e_n$ に対して積を $e_i e_j=\sum_k c_{ij}^k e_k$ で定める。これが結合的であることと、全ての $i,j,k,m$ について $\sum_\ell c_{ij}^\ell c_{\ell k}^m=\sum_\ell c_{jk}^\ell c_{i\ell}^m$ が成り立つことは同値である。
:::

:::proof
左辺は $(e_i e_j)e_k$ の $e_m$ 係数であり、右辺は $e_i(e_j e_k)$ の係数である。従って結合性はこれらの等式を含む。逆に全ての等式が成り立つなら、任意の三元を基底で展開して分配することで、基底での結合性が任意の元へ従う。
:::

:::example[関係式 $x^2=-3$ による積の簡約]
$g=x^{2} + 3$ とし、整数係数の剰余環で $u=[x]$ と書く。任意の $x^j$ は、指数が $2$ 以上なら $u^2=-3$ を使って指数を $2$ 下げられる。従って $A+Bu$ にしてから積を計算できる。二つの一次以下の式の差がモニックな $g$ の倍数になるためには、その差が零でなければならない。従ってこの表示は一意である。

$f=2 x + 1$ の類を掛けると、定数係数と一次係数の列は $\begin{pmatrix}1&-6\\2&1\end{pmatrix}$ を掛けたものになる。実際、$a+bu$ を掛けた結果は $(aA+cbB)+(bA+aB)u$ である。ここで $c=-3$ は $u^2$ の値である。列 $(1,0)^\top$ にこの行列を順に掛けた結果を、各冪の余りでも確かめる。

| 指数 | $f^j$ の余り | 定数係数 | 一次係数 |
| --- | --- | --- | --- |
| $0$ | $1$ | $1$ | $0$ |
| $1$ | $2 x + 1$ | $1$ | $2$ |
| $2$ | $4 x - 11$ | $-11$ | $4$ |
| $3$ | $- 18 x - 35$ | $-35$ | $-18$ |
| $4$ | $73 - 88 x$ | $73$ | $-88$ |

$a^2-cb^2=13$ は $\Q$ では非零なので、$\Q[x]/(g)$ での逆元は $(1 - 2 x)/(13)$ である。整数係数の環で同じ元に逆元があるのは、この積の行列が整数行列として逆をもつとき、すなわち行列式が $\pm1$ のときに限る。必要性は行列式を掛け合わせると $1$ になるためであり、十分性は同じ逆元の式で分母が $\pm1$ になるためである。
:::

:::proposition[有限次元多元環での単元判定]{#prop-ring-algebra-unit-multiplication}
有限次元 $K$ 多元環 $A$ の元 $a$ が単元であることと、左乗法 $L_a\colon x\mapsto ax$ の行列式が非零であることは同値である。右乗法を使っても同値である。
:::

:::proof
$a$ が単元なら $L_{a^{-1}}$ が $L_a$ の逆である。逆に行列式が非零なら $L_a$ は全単射なので、$ab=1$ となる $b$ を取れる。すると $a(ba-1)=(ab)a-a=0$ であり、$L_a$ の単射性から $ba=1$ となる。右乗法の場合も左と右を交換すれば、まず左逆を求め、単射性で右逆でもあることを示せる。
:::

:::example[関係式 $x^2=0$ による積の簡約]
$g=x^{2}$ とし、整数係数の剰余環で $u=[x]$ と書く。任意の $x^j$ は、指数が $2$ 以上なら $u^2=0$ を使って指数を $2$ 下げられる。従って $A+Bu$ にしてから積を計算できる。二つの一次以下の式の差がモニックな $g$ の倍数になるためには、その差が零でなければならない。従ってこの表示は一意である。

$f=3 x + 2$ の類を掛けると、定数係数と一次係数の列は $\begin{pmatrix}2&0\\3&2\end{pmatrix}$ を掛けたものになる。実際、$a+bu$ を掛けた結果は $(aA+cbB)+(bA+aB)u$ である。ここで $c=0$ は $u^2$ の値である。列 $(1,0)^\top$ にこの行列を順に掛けた結果を、各冪の余りでも確かめる。

| 指数 | $f^j$ の余り | 定数係数 | 一次係数 |
| --- | --- | --- | --- |
| $0$ | $1$ | $1$ | $0$ |
| $1$ | $3 x + 2$ | $2$ | $3$ |
| $2$ | $12 x + 4$ | $4$ | $12$ |
| $3$ | $36 x + 8$ | $8$ | $36$ |
| $4$ | $96 x + 16$ | $16$ | $96$ |

$a^2-cb^2=4$ は $\Q$ では非零なので、$\Q[x]/(g)$ での逆元は $(2 - 3 x)/(4)$ である。整数係数の環で同じ元に逆元があるのは、この積の行列が整数行列として逆をもつとき、すなわち行列式が $\pm1$ のときに限る。必要性は行列式を掛け合わせると $1$ になるためであり、十分性は同じ逆元の式で分母が $\pm1$ になるためである。
:::

:::example[関係式 $x^2=1$ による積の簡約]
$g=x^{2} - 1$ とし、整数係数の剰余環で $u=[x]$ と書く。任意の $x^j$ は、指数が $2$ 以上なら $u^2=1$ を使って指数を $2$ 下げられる。従って $A+Bu$ にしてから積を計算できる。二つの一次以下の式の差がモニックな $g$ の倍数になるためには、その差が零でなければならない。従ってこの表示は一意である。

$f=x + 1$ の類を掛けると、定数係数と一次係数の列は $\begin{pmatrix}1&1\\1&1\end{pmatrix}$ を掛けたものになる。実際、$a+bu$ を掛けた結果は $(aA+cbB)+(bA+aB)u$ である。ここで $c=1$ は $u^2$ の値である。列 $(1,0)^\top$ にこの行列を順に掛けた結果を、各冪の余りでも確かめる。

| 指数 | $f^j$ の余り | 定数係数 | 一次係数 |
| --- | --- | --- | --- |
| $0$ | $1$ | $1$ | $0$ |
| $1$ | $x + 1$ | $1$ | $1$ |
| $2$ | $2 x + 2$ | $2$ | $2$ |
| $3$ | $4 x + 4$ | $4$ | $4$ |
| $4$ | $8 x + 8$ | $8$ | $8$ |

$[1+x][1-x]=0$ が剰余環で成立する。$[1-x]$ は非零なので、$f$ の類は零因子である。
:::

:::example[積の表から代数の同型を判定する]
$A=\Q[u]/(u^2-3u+2)$ の基底を $1,[u]$ とする。$(u-1)(u-2)$ は二点で零なので、評価 $(f(1),f(2))$ が $A\to\Q^2$ を定める。一次までの余り $a+bu$ の像は $(a+b,a+2b)$ で、逆は $b=v-w,a=2w-v$（像を $(w,v)$ とする）である。従ってこの写像は代数の同型である。基底 $1,[u]$ で見ると $[u]^2=3[u]-2$ だが、座標ごとに見ると $(1,2)^2=(1,4)$ であり、実際 $(1,4)=3(1,2)-2(1,1)$ である。基底変更で積の表が変わり、同型先では成分ごとの積として簡約される。
:::

:::example[同じ二次元でも単元の条件が異なる]
$K[t]/(t^2)$ の元 $a+bu$（$u=[t]$）に単元がある条件は $a\ne0$ である。実際その場合には $a^{-1}-a^{-2}bu$ が逆元であり、$a=0$ なら平方が零である。一方 $K\times K$ の元 $(a,b)$ が単元となるには $a,b$ が両方とも非零でなければならない。例えば $K=\F_3$ とすると前者の単元は $2\cdot3=6$ 個、後者では $2\cdot2=4$ 個である。二つの代数は同じ次元であるが、単元の個数を保つ同型は存在しない。さらに任意の体 $K$ についても、前者には非零の冪零元 $u$ があり、後者にはないため区別できる。
:::

## 群環と行列環

### 積を基底の上で指定する

群 $G$ に対する群環 $K[G]$ は $[g]$ を基底とし $[g][h]=[gh]$ とする多元環である。有限和の積と結合性の詳細は [環とイデアル](/math/rings-modules/rings/) を参照する。任意の多元環 $A$ について、群準同型 $\rho\colon G\to A^\times$ は $\sum c_g[g]\mapsto\sum c_g\rho(g)$ により多元環準同型に一意に延長する。基底積が保たれるので積全体も保たれ、逆に多元環準同型の制限は、$[g^{-1}]$ が逆元であることにより単元群に入る。

:::example[二元の群と直積]
$G=\langle g\rangle$ を位数 $2$ の巡回群とすると、$K[G]\cong K[t]/(t^2-1)$ である。$t\mapsto[g]$ による準同型は全射で、商の基底 $1,t$ が基底 $[e],[g]$ に移るため単射である。標数が $2$ と異なれば $\frac12([e]+[g])$ と $\frac12([e]-[g])$ は積が零の冪等元で、和が $[e]$ になる。対応する成分で環は $K\times K$ に分かれる。標数 $2$ では逆に $[g]-[e]$ が非零で二乗が零になる。
:::

$M_n(K)$ の積は $E_{ij}E_{kl}=\delta_{jk}E_{il}$ により決まる。従って $K$ 倍の単位行列は中心に入る。中心の元 $A$ が全ての $E_{jj}$ と可換なら、$AE_{jj}$ は第 $j$ 列だけ、$E_{jj}A$ は第 $j$ 行だけを残すので $A$ は対角である。次に $E_{ij}$ と可換なら $i,j$ の対角成分は等しい。よって中心は $K I$ に等しい。例えば $M_2(K)$ で $(E_{11}+2E_{12})(3E_{21}+E_{22})=6E_{11}+2E_{12}$ となる。

### 多元環のテンソル積

:::proposition[テンソル積での積]{#prop-ring-algebra-tensor-product}
$K$ 多元環 $A,B$ に対し、$A\otimes_K B$ には $(a\otimes b)(a'\otimes b')=aa'\otimes bb'$ で定まる多元環の構造がある。
:::

:::proof
この式は $a,b,a',b'$ の各変数で線形であり、各対について係数を隣の因子に移しても値が一致する。テンソル積の普遍性を両側で適用すると二つのテンソル積からの双線形な積が定まる。結合性と単位元 $1_A\otimes1_B$ の性質は純テンソルで確認でき、双線形性により一般の元にも従う。$a\otimes1$ と $1\otimes b$ はどちらの順に掛けても $a\otimes b$ である。
:::

:::example[複素数の係数を拡大する]
$\C\otimes_\R\C$ を左の $\C$ で係数を付けた多元環とみなす。$1\otimes1,1\otimes i$ は $\C$ 上の基底である。これは右の $\C$ が実基底 $1,i$ をもち、テンソル積がその二つの直和を二つの $\C$ に移すためである。$u=1\otimes i$ とすると $u^2=-1$ であるから $\C\otimes_\R\C\cong\C[t]/(t^2+1)$ である。さらに $t-i,t+i$ は互いに素なので、中国式剰余定理で $\C\times\C$ に分かれる。写像を純テンソルに書くと $z\otimes w\mapsto(zw,z\bar w)$ である。例えば $i\otimes i$ は $(-1,1)$ に写るため、二因子の虚数単位は同じ作用をしていないことが分かる。
:::

### 巡回群とテンソル積を具体的に計算する

:::example[位数 3 の巡回群の群環で積を取る]
位数 $3$ の巡回群の生成元を $g$ とし、$[g]$ を $t$ と書く。群環の元 $A=3 t^{2} - t + 2$ および $B=- 2 t^{2} + t + 1$ を掛ける。通常の多項式積では $x^i x^j=x^{i+j}$ だが、群環では $t^i t^j=t^{(i+j)\bmod 3}$ となる。従って $(i+j)$ を法 $3$ で還元して、同じ位置に入る積の係数を足す。

| 基底の指数 | 寄与する積 | 係数の和 | 係数環での代表 |
| --- | --- | --- | --- |
| $0$ | $(2)+(2)+(3)$ | $7$ | $7$ |
| $1$ | $(2)+(-1)+(-6)$ | $-5$ | $-5$ |
| $2$ | $(-4)+(-1)+(3)$ | $-2$ | $-2$ |

この表の最後の列を集めた結果は $- 2 t^{2} - 5 t + 7$ である。係数は $\Q$ に取る。 群の元の添字の還元と、係数の還元を別々に行っている。通常の積を先に作り $t^{3}=1$ で割った余りをとっても同じ式になり、この一致が $K[C_{3}]\cong K[t]/(t^{3}-1)$ の積を具体的に確認する。
:::

:::example[位数 4 の巡回群の群環で積を取る]
位数 $4$ の巡回群の生成元を $g$ とし、$[g]$ を $t$ と書く。群環の元 $A=- t^{3} + 2 t + 1$ および $B=t^{3} + 3 t^{2} + 2$ を掛ける。通常の多項式積では $x^i x^j=x^{i+j}$ だが、群環では $t^i t^j=t^{(i+j)\bmod 4}$ となる。従って $(i+j)$ を法 $4$ で還元して、同じ位置に入る積の係数を足す。

| 基底の指数 | 寄与する積 | 係数の和 | 係数環での代表 |
| --- | --- | --- | --- |
| $0$ | $(2)+(2)+(0)+(0)$ | $4$ | $4$ |
| $1$ | $(0)+(4)+(0)+(-3)$ | $1$ | $1$ |
| $2$ | $(3)+(0)+(0)+(-1)$ | $2$ | $2$ |
| $3$ | $(1)+(6)+(0)+(-2)$ | $5$ | $5$ |

この表の最後の列を集めた結果は $5 t^{3} + 2 t^{2} + t + 4$ である。係数は $\Q$ に取る。 群の元の添字の還元と、係数の還元を別々に行っている。通常の積を先に作り $t^{4}=1$ で割った余りをとっても同じ式になり、この一致が $K[C_{4}]\cong K[t]/(t^{4}-1)$ の積を具体的に確認する。
:::

:::example[位数 5 の巡回群の群環で積を取る]
位数 $5$ の巡回群の生成元を $g$ とし、$[g]$ を $t$ と書く。群環の元 $A=t^{3} + t^{2} + 1$ および $B=t^{4} + t^{2} + t$ を掛ける。通常の多項式積では $x^i x^j=x^{i+j}$ だが、群環では $t^i t^j=t^{(i+j)\bmod 5}$ となる。従って $(i+j)$ を法 $5$ で還元して、同じ位置に入る積の係数を足す。

| --- | --- | --- | --- |
| $0$ | $(0)+(0)+(0)+(1)+(0)$ | $1$ | $1$ |
| $1$ | $(1)+(0)+(1)+(0)+(0)$ | $2$ | $0$ |
| $2$ | $(1)+(0)+(0)+(1)+(0)$ | $2$ | $0$ |
| $3$ | $(0)+(0)+(1)+(0)+(0)$ | $1$ | $1$ |
| $4$ | $(1)+(0)+(1)+(1)+(0)$ | $3$ | $1$ |

この表の最後の列を集めた結果は $t^{4} + t^{3} + 1$ である。係数は法 $2$ とする。 群の元の添字の還元と、係数の還元を別々に行っている。通常の積を先に作り $t^{5}=1$ で割った余りをとっても同じ式になり、この一致が $K[C_{5}]\cong K[t]/(t^{5}-1)$ の積を具体的に確認する。
:::

:::example[行列単位の添字を組にして大きい行列を作る]
$M_2(K)\otimes_K M_3(K)$ の基底元 $E_{ij}\otimes E_{ab}$ を、第 $3(i-1)+a$ 行、第 $3(j-1)+b$ 列に $1$ がある $6\times6$ の行列単位に送る。一致すべき中間添字は $j=k$ と $b=c$ である。これは行列の大きい添字が一致することに等しいので、基底の積が保たれる。全行と全列を一度ずつ得るため、これらの像は $M_6(K)$ の基底を尽くす。また単位元のテンソルは六つの対角単位の和に写る。従って写像は代数の同型となる。例えば $E_{12}\otimes E_{31}$ は行 $3$、列 $4$ の行列単位であり、$E_{21}\otimes E_{12}$ を右に掛けると行 $3$、列 $2$ の行列単位を得る。
:::

### 群環の増大イデアルと評価を調べる

:::definition[増大写像と増大イデアル]{#def-ring-augmentation}
群環 $K[G]$ の :term[増大写像]{en="augmentation map" yomi="ぞうだいしゃぞう"} $\varepsilon\colon K[G]\to K$ を $\sum_g c_g[g]\mapsto\sum_g c_g$ と定める。核を :term[増大イデアル]{en="augmentation ideal" yomi="ぞうだいいである"} と呼ぶ。
:::

群の自明な準同型 $g\mapsto1$ を線形に延長したものなので $\varepsilon$ は多元環準同型である。係数の和が零であれば $\sum_g c_g[g]=\sum_g c_g([g]-[e])$ なので、増大イデアルは $[g]-[e]$ の線形包である。$G$ が巡回群なら $[g]$ を表す変数を $1$ にする評価に等しい。

:::proposition[有限群の群環の中心]{#prop-ring-group-algebra-center}
有限群 $G$ に対し、各共役類 $C$ の類和 $\sum_{g\in C}[g]$ が $Z(K[G])$ の基底をなす。
:::

:::proof
元 $a=\sum_g c_g[g]$ が中心に属することは、基底をなす全ての $[h]$ と可換であることと同値である。さらに $[h]$ は可逆なので、これは全ての $h$ で $[h]a[h]^{-1}=a$ と同値である。左辺の $[g]$ の係数は $c_{h^{-1}gh}$ であるから、各共役類の上で係数が一定であればよい。類和はこの条件を満たし、異なる共役類は互いに素なので類和の線形独立性も従う。
:::

:::example[二つの因子で有理群環を分ける]
$\Q[C_3]\cong\Q[t]/(t^3-1)$ とする。$t^3-1=(t-1)(t^2+t+1)$ であり、$t^2+t+1$ が $t=1$ で $3$ になるので二因子は互いに素である。後者の二次式は判別式 $-3$ で有理根を持たない。従って剰余は $\Q\times\Q(\sqrt{-3})$ である。第一の成分にだけ $1$ を持つ冪等元は $e=(1+t+t^2)/3$ である。実際 $t=1$ では値が $1$、第二の商で値が零になる。$f=2+t$ なら第一成分は $3$ であり、第一への射影は $ef=1+t+t^2$、残りは $f-ef=1-t^2$ である。後者は $t=1$ の評価で零であり、第二成分だけを表す。複素係数なら二次式も異なる一次因子に分かれるため、三つの評価先を使える。係数体を変えたときどの因子が分かれるかを先に調べれば、群環の積をより小さい環の中で行える。
:::

:::example[標数と群の位数が一致すると冪零が現れる]
$\F_3[C_3]\cong\F_3[t]/(t^3-1)$ では $t^3-1=(t-1)^3$ である。$u=[t]-1$ とすると $u^3=0$、$u^2=[t]^2+[t]+1$ であり、群の三つの基底元の和なので非零である。従って $\F_3[t]/(t^3-1)\cong\F_3[u]/(u^3)$ となる。例えば $[t]^{-1}=[t]^2=1-u+u^2$ である。実際 $(1+u)(1-u+u^2)=1+u^3=1$ である。$t=1$ の評価は両方の係数体で定められるが、有理係数の場合と異なり、この標数では評価の核が冪零になる。従って直積の分解を作るために必要な、互いに素な二因子は存在しない。
:::

## テンソル代数と対称代数

### 順序を持つ語から積を作る

:::definition[テンソル代数と対称代数]{#def-ring-tensor-symmetric-algebras}
$K$ ベクトル空間 $V$ の :term[テンソル代数]{en="tensor algebra" yomi="てんそるだいすう"} は $T_K(V)=\bigoplus_{d\ge0} V^{\otimes d}$ である。$V^{\otimes0}=K$ とし、積はテンソルを連結する。$uv-vu$（$u,v\in V$）の生成する両側イデアルで割った商を :term[対称代数]{en="symmetric algebra" yomi="たいしょうだいすう"} $\operatorname{Sym}_K(V)$ と呼ぶ。
:::

テンソル積の普遍性で、連結は各成分に対する双線形積として定まり、有限和に分配して全体の積になる。純テンソルの三項積はどちらの括り方でも同じ語を連結するので結合的である。次数零成分の $1_K$ が単位である。

一般に多元環が $A=\bigoplus_{d\ge0}A_d$ と分かれ、$1_A\in A_0$、$A_pA_q\subseteq A_{p+q}$ を満たすとき、:term[次数付き多元環]{en="graded algebra" yomi="じすうつきたげんかん"} という。連結で長さを足すテンソル代数はこの例である。対称代数の関係 $uv-vu$ は同じ次数の項からなる。その生成するイデアルで、各元を次数ごとの成分に分けても各成分は同じイデアルに属する。実際、関係を左右から掛ける元を次数ごとに分ければよい。従って商である対称代数にも次数分解が入る。同じ議論は、二次の関係 $v^2$ で割る外積代数にも適用できる。

:::theorem[テンソル代数と対称代数の普遍性]{#thm-ring-tensor-algebra-universal}
任意の線形写像 $V\to A$ は多元環準同型 $T_K(V)\to A$ に一意に延長する。像の任意の二元が可換なら $\operatorname{Sym}_K(V)$ を通じて一意に分解する。基底 $(v_i)_{i\in I}$ に対し $\operatorname{Sym}_K(V)\cong K[X_i\mid i\in I]$ である。
:::

:::proof
$f\colon V\to A$ について積 $f(v_1)\cdots f(v_d)$ は $d$ 重線形であり、テンソル積の普遍性で各次数に写像が定まる。次数零では $c\mapsto c1_A$ とする。連結で積が保たれ、$V$ の像で全ての純テンソルの値が強制されるため一意である。可換な値を取ると $uv-vu$ が零に写るので剰余の普遍性で分解する。逆に分解があれば関係式から像は可換である。特に $v_i\mapsto X_i$ と $X_i\mapsto[v_i]$ で相互の準同型を作れる。後者では全ての $[v_i]$ が可換なので代入できる。両合成は生成元を固定するため恒等である。
:::

:::example[積の順序が消える場所]
$V$ の基底を $u,v$ とする。$T_K(V)$ の次数 $2$ は $uu,uv,vu,vv$ を基底とする（:ref[thm-linalg-tensor-basis]）。対称代数では $uv=vu$ となるため、次数 $2$ では $u^2,uv,v^2$ の三つが基底となる。特に $(u+v)^2=u^2+2uv+v^2$ は対称代数での式であり、テンソル代数では中央は $uv+vu$ である。
:::

### 各次数の基底を数える

:::proposition[テンソル冪と対称冪の次元]{#prop-ring-algebra-graded-dim}
$V$ の次元が $n\ge1$ なら $T_K(V)$ の次数 $d$ の次元は $n^d$、$\operatorname{Sym}_K(V)$ の次数 $d$ の次元は $\binom{n+d-1}{d}$ である。
:::

:::proof
テンソル積の基底（:ref[thm-linalg-tensor-basis]）を繰り返し使うと、長さ $d$ の基底元の順序付きの列がテンソル冪の基底を与える。各位置に $n$ 通りの選択がある。対称冪では $n$ 変数の全次数 $d$ の単項式が基底であり、指数は非負整数の組 $(a_1,\ldots,a_n)$ で和が $d$ である。$d$ 個の印と $n-1$ 個の仕切りを並べ、第 $i$ 区画にある印の数を $a_i$ とすると全ての指数組に一意に対応する。従って印の位置の選び方の数が答えである。
:::

:::example[異なる積の次数を比較する]
三次元 $V$ の次数 $3$ を考える。テンソル冪では $3^3=27$ 語が基底である。対称冪では三乗 $3$ 個、二乗と別の変数の積 $3\cdot2=6$ 個、三変数の積 $1$ 個で計 $10$ 個となる。四次の対称冪を求めるなら、同じ区分を全て列挙する代わりに $\binom64=15$ を用いられる。対称代数への射影の次数 $3$ の核は次元 $27-10=17$ であり、順序を交換した語の差から生じる。
:::

## 外積代数と行列式

### 同じベクトルを掛けると零になる積

:::definition[外積代数]{#def-ring-exterior-algebra}
$T_K(V)$ を全ての $v^2$（$v\in V$）が生成する両側イデアルで割った商を :term[外積代数]{en="exterior algebra" yomi="がいせきだいすう"} $\bigwedge V$ と呼ぶ。積を $\wedge$ と書き、次数 $d$ の成分を $\bigwedge^d V$ とする。
:::

関係 $(u+v)^2=0$ と $u^2=v^2=0$ から $u\wedge v=-v\wedge u$ を得る。標数 $2$ でも $v^2=0$ は別に課している。$V\to A$ の線形写像が全ての平方を零にすれば、:ref[thm-ring-tensor-algebra-universal] と剰余により外積代数を通じて分解する。次数 $d$ への制限は交代 $d$ 線形写像に対応する。実際、交代写像は隣接する同じ二元を含む純テンソルを零にする。関係イデアルの次数 $d$ はそれらの線形結合であり、逆にこの関係が成り立てば交換で符号が変わり、離れた二元が等しくても交換して隣接させれば零となる。

:::proposition[外積の基底と行列式]{#prop-ring-exterior-det}
順序をもつ基底 $e_1,\ldots,e_n$ に対し、$e_{i_1}\wedge\cdots\wedge e_{i_d}$（$i_1<\cdots<i_d$）が $\bigwedge^d V$ の基底となる。特に $V$ の自己準同型 $A$ が最高外積 $\bigwedge^n V$ に誘導する写像は $\det A$ 倍である。
:::

:::proof
繰り返しの添字があれば積は零、そうでなければ隣接交換で昇順にできるので候補は生成系である。独立性を示すため、有限部分集合 $I$ ごとに形式基底 $b_I$ をもつ空間を作る。$I\cap J\ne\varnothing$ のとき $b_I b_J=0$、それ以外では $b_I b_J=(-1)^{|\{(i,j)\in I\times J\mid i>j\}|} b_{I\cup J}$ と置く。三集合に重複があればどちらの括り方も零であり、全て互いに素なら符号は三つの組の逆転数の和なので結合的である。空集合が単位である。$e_i\mapsto b_{\{i\}}$ は任意の一次結合の平方を零にする。対角の積は零であり、異なる添字の二順序が相殺するからである。従って外積代数からこの空間へ写せ、候補が異なる形式基底に写るので独立である。

$e_i\mapsto A e_i$ から外積への写像が定まる。$A e_1\wedge\cdots\wedge A e_n$ を成分で展開すると、重複を含む項は消え、各順列の項がその符号を掛けて最高外積の基底に寄与する。係数は行列式の順列和そのものである。
:::

:::example[面積を係数として得る]
$u=2e_1+3e_2,\ v=e_1+4e_2$ とする。同じ添字の積を零にすると $u\wedge v=(8-3)e_1\wedge e_2=5e_1\wedge e_2$ となる。順序を逆転した $v\wedge u$ の係数は $-5$ である。
:::

:::corollary[外積の次数付き交換則]{#cor-ring-exterior-graded-commutativity}
$a\in\bigwedge^pV$、$b\in\bigwedge^qV$ に対し、$a\wedge b=(-1)^{pq}b\wedge a$ である。
:::

:::proof
純外積では、最初の $p$ 個の各因子を最後の $q$ 個の因子の向こうへ移すと、隣接交換は $pq$ 回である。隣接交換一回ごとに $-1$ を掛けるので式を得る。純外積は各次数を張り、積は双線形だから一般の元でも成り立つ。
:::

:::example[二次外積の平方が非零になる]
$V=K^4$ で $\omega=e_1\wedge e_2+e_3\wedge e_4$ とする。各項の平方は添字の繰り返しで零になる。二つの交差項は符号 $(-1)^4=1$ で一致するので、$\omega\wedge\omega=2 e_1\wedge e_2\wedge e_3\wedge e_4$ である。体の標数が $2$ と異なればこれは非零であり、一次の元に課した $v^2=0$ は全次数の元にそのまま適用できない。
:::

:::corollary[外積の成分と双対空間の対応]{#cor-ring-exterior-dual}
有限次元 $V$ に対して、$\bigwedge^d(V^*)$ と $(\bigwedge^d V)^*$ は自然に同型である。純外積 $\alpha_1\wedge\cdots\wedge\alpha_d$ に対応する汎関数は、$v_1\wedge\cdots\wedge v_d$ を $\det(\alpha_i(v_j))_{i,j=1}^{d}$ に送る。
:::

:::proof
行列式は行にも列にも交代的で多重線形である。従って $v_j$ の組について外積を通り、さらに $\alpha_i$ の組についても外積を通る。$V$ の基底とその双対基底を取り、双方の次数 $d$ の外積を昇順に並べる。同じ添字集合の組で評価すると単位行列の行列式で $1$、異なる添字集合なら零行を含むため $0$ である。従って得られる汎関数は外積基底の双対基底であり、写像は同型である。定義式自体には基底の選択を含まない。
:::

:::example[非可換な値では対称代数からの写像が作れない]
$V=Ku+Kv$ から $M_2(K)$ へ $u\mapsto E_{12}$、$v\mapsto E_{21}$ と送る。各語をその順序で行列積に送ればテンソル代数の準同型が得られる。$u^2,v^2$ は零に写り、$uv,vu$ はそれぞれ $E_{11},E_{22}$ に写る。従って二つの行列単位の積と逆順の積が異なり、対称代数を通る写像は得られない。また $(u+v)^2$ の像は $I$ なので、個々の基底元の平方が零であっても外積代数を通るには十分でない。普遍性で必要な条件は、生成元の間の交換関係か、全線形結合に対する平方の関係である。
:::

:::example[二次外積への誘導写像を計算する]
線形写像を行列 $\left[\begin{matrix}2 & 0 & 1\\1 & 2 & 0\\0 & 1 & 3\end{matrix}\right]$ で与える。外積の基底を $e_1\wedge e_2,e_1\wedge e_3,e_2\wedge e_3$ の順とする。$Ae_j\wedge Ae_k$ を展開すると $e_r\wedge e_s$ の係数は第 $r,s$ 行と第 $j,k$ 列の小行列式になる。二つの寄与に逆順の符号を付けて足すためである。

| --- | --- | --- | --- |
| $\left( 1, \  2\right)$ | $\left( 1, \  2\right)$ | $\left[\begin{matrix}2 & 0\\1 & 2\end{matrix}\right]$ | $4$ |
| $\left( 1, \  2\right)$ | $\left( 1, \  3\right)$ | $\left[\begin{matrix}2 & 1\\1 & 0\end{matrix}\right]$ | $-1$ |
| $\left( 1, \  2\right)$ | $\left( 2, \  3\right)$ | $\left[\begin{matrix}0 & 1\\2 & 0\end{matrix}\right]$ | $-2$ |
| $\left( 1, \  3\right)$ | $\left( 1, \  2\right)$ | $\left[\begin{matrix}2 & 0\\0 & 1\end{matrix}\right]$ | $2$ |
| $\left( 1, \  3\right)$ | $\left( 1, \  3\right)$ | $\left[\begin{matrix}2 & 1\\0 & 3\end{matrix}\right]$ | $6$ |
| $\left( 1, \  3\right)$ | $\left( 2, \  3\right)$ | $\left[\begin{matrix}0 & 1\\1 & 3\end{matrix}\right]$ | $-1$ |
| $\left( 2, \  3\right)$ | $\left( 1, \  2\right)$ | $\left[\begin{matrix}1 & 2\\0 & 1\end{matrix}\right]$ | $1$ |
| $\left( 2, \  3\right)$ | $\left( 1, \  3\right)$ | $\left[\begin{matrix}1 & 0\\0 & 3\end{matrix}\right]$ | $3$ |
| $\left( 2, \  3\right)$ | $\left( 2, \  3\right)$ | $\left[\begin{matrix}2 & 0\\1 & 3\end{matrix}\right]$ | $6$ |

これらを三列に置くと $\bigwedge^2 A$ の行列は $\left[\begin{matrix}4 & -1 & -2\\2 & 6 & -1\\1 & 3 & 6\end{matrix}\right]$ である。例えば最初の列の $e_1\wedge e_2$ の入力では、出力の係数は順に $2\cdot2-0\cdot1=4$、$2\cdot1-0\cdot0=2$、$1\cdot1-2\cdot0=1$ となる。最高外積に移ると基底は一元であり、$\det A=13$ が唯一の係数になる。
:::

### 小行列式と合成を照合する

:::example[外積への誘導作用の合成]
$A=\begin{pmatrix}1&2&0\\0&1&1\\2&0&1\end{pmatrix}$、$B=\begin{pmatrix}1&0&2\\2&1&0\\0&3&1\end{pmatrix}$ とする。二次外積の基底は添字対 $(1,2),(1,3),(2,3)$ の順で取る。$A$ の誘導作用の第 $(i,j)$ 成分は、出力の添字対で行を選び、入力の添字対で列を選んだ二次小行列式である。従って両作用の行列を次のように書ける。


$$
\bigwedge^2 A=\begin{pmatrix}1&1&2\\-4&1&2\\-2&-2&1\end{pmatrix},\qquad\bigwedge^2 B=\begin{pmatrix}1&-4&-2\\3&1&-6\\6&2&1\end{pmatrix}
$$


例えば $B$ の後に $A$ を適用し、入力も出力も $(1,2)$ とする。$B(e_1)\wedge B(e_2)$ を各中間の添字対に分け、そこからの $A$ の係数を掛ける。

| 中間の添字対 | $B$ の係数 | $A$ の係数 | 積 |
| --- | --- | --- | --- |
| $(1, 2)$ | $1$ | $1$ | $1$ |
| $(1, 3)$ | $3$ | $1$ | $3$ |
| $(2, 3)$ | $6$ | $2$ | $12$ |

最後の列の和は $16$ であり、$AB$ 自体の $(1,2)$ 行・列による小行列式も同じ値である。ほかの成分も同じ方法で求まり、全体として $\bigwedge^2(AB)=\begin{pmatrix}16&1&-6\\11&21&4\\-2&8&17\end{pmatrix}$ である。元の積で各項を一度に展開する代わりに、中間の基底で展開してから移せることが、行列積の形でここに現れている。
:::

:::example[外積への誘導作用の合成]
$A=\begin{pmatrix}2&1&1\\0&1&2\\1&0&2\end{pmatrix}$、$B=\begin{pmatrix}0&1&0\\1&0&0\\0&0&1\end{pmatrix}$ とする。二次外積の基底は添字対 $(1,2),(1,3),(2,3)$ の順で取る。$A$ の誘導作用の第 $(i,j)$ 成分は、出力の添字対で行を選び、入力の添字対で列を選んだ二次小行列式である。従って両作用の行列を次のように書ける。

\bigwedge^2 A=\begin{pmatrix}2&4&1\\-1&3&2\\-1&-2&2\end{pmatrix},\qquad\bigwedge^2 B=\begin{pmatrix}-1&0&0\\0&0&1\\0&1&0\end{pmatrix}
$$


例えば $B$ の後に $A$ を適用し、入力も出力も $(1,2)$ とする。$B(e_1)\wedge B(e_2)$ を各中間の添字対に分け、そこからの $A$ の係数を掛ける。

| 中間の添字対 | $B$ の係数 | $A$ の係数 | 積 |

| $(1, 2)$ | $-1$ | $2$ | $-2$ |
| $(1, 3)$ | $0$ | $4$ | $0$ |

:::

:::proposition[外積の消滅と像の次元]{#prop-ring-exterior-rank}
有限次元ベクトル空間の間の線形写像 $T$ の階数を $r$ とする。$\bigwedge^d T$ の階数は $\binom rd$ である。ただし $d>r$ なら零とする。
:::

:::proof
$\Img T$ の基底 $w_1,\ldots,w_r$ を、目標の基底に延長する。像の元を全て $\Img T$ で展開すると、外積の像は $w_{i_1}\wedge\cdots\wedge w_{i_d}$ の線形結合に入る。各 $w_i$ の前像 $v_i$ を取れば、それらの外積は対応する $w_i$ の外積に写るので、これらは全て実際に像にある。目標空間の基底の外積の一部であるから独立であり、添字の選び方を数えて結論を得る。
:::

:::example[最高外積が零でも二次外積が残る]
$T$ を $\Q^3$ で $Te_1=e_1$、$Te_2=e_2$、$Te_3=e_1+e_2$ とする。最高外積は $e_1\wedge e_2\wedge(e_1+e_2)=0$ である。一方二次外積では、$e_1\wedge e_2$ は固定され、$e_1\wedge e_3$ は $e_1\wedge e_2$、$e_2\wedge e_3$ は $-e_1\wedge e_2$ に写る。従って二次外積の像は一次元である。三次の行列式は零という情報しか持たないが、二次外積の成分を調べれば像に独立な二列があることが分かる。
:::

:::proposition[外積による Cauchy–Binet の公式]{#prop-ring-exterior-cauchy-binet}
$A$ を $r\times n$ 行列、$B$ を $n\times s$ 行列とする。昇順の $d$ 個の行添字 $I$ と列添字 $J$ を選ぶと、
$$
\det((AB)_{I,J})=\sum_{\substack{L\subseteq\{1,\ldots,n\}\\ |L|=d}}\det(A_{I,L})\det(B_{L,J})
$$
である。各部分行列の添字 $L$ は昇順に並べる。
:::

:::proof
$d$ 個の列に対する外積を展開すると、同じ行添字を選んだ項は消え、異なる添字の並びは昇順に並べた添字集合ごとに符号をつけて足される。その係数は選んだ行と列での $d$ 次小行列式である。従って $\bigwedge^d(AB)$ の $(I,J)$ 成分は左辺である。一方 $\bigwedge^d(AB)=(\bigwedge^d A)(\bigwedge^d B)$ は各基本外積の因子に $B$、次に $A$ を適用して分かる。行列積の $(I,J)$ 成分は中間の外積基底 $L$ を走る和であり、上述の小行列式の係数を代入すれば右辺に一致する。$d>n$ の場合は通過する外積空間が零なので和は空になり、左辺も零である。
:::

:::example[外積への誘導作用の合成]
$A=\begin{pmatrix}2&0&1\\2&1&3\\0&1&2\end{pmatrix}$、$B=\begin{pmatrix}1&0&0\\0&2&0\\1&3&1\end{pmatrix}$ とする。二次外積の基底は添字対 $(1,2),(1,3),(2,3)$ の順で取る。$A$ の誘導作用の第 $(i,j)$ 成分は、出力の添字対で行を選び、入力の添字対で列を選んだ二次小行列式である。従って両作用の行列を次のように書ける。


$$
\bigwedge^2 A=\begin{pmatrix}2&4&-1\\2&4&-1\\2&4&-1\end{pmatrix},\qquad\bigwedge^2 B=\begin{pmatrix}2&0&0\\3&1&0\\-2&0&2\end{pmatrix}
$$


例えば $B$ の後に $A$ を適用し、入力も出力も $(1,2)$ とする。$B(e_1)\wedge B(e_2)$ を各中間の添字対に分け、そこからの $A$ の係数を掛ける。

| 中間の添字対 | $B$ の係数 | $A$ の係数 | 積 |
| --- | --- | --- | --- |
| $(1, 2)$ | $2$ | $2$ | $4$ |
| $(1, 3)$ | $3$ | $4$ | $12$ |
| $(2, 3)$ | $-2$ | $-1$ | $2$ |

最後の列の和は $18$ であり、$AB$ 自体の $(1,2)$ 行・列による小行列式も同じ値である。ほかの成分も同じ方法で求まり、全体として $\bigwedge^2(AB)=\begin{pmatrix}18&4&-2\\18&4&-2\\18&4&-2\end{pmatrix}$ である。元の積で各項を一度に展開する代わりに、中間の基底で展開してから移せることが、行列積の形でここに現れている。
:::

## 四元数体と斜体

### 逆元はあるが積の順序が効く

:::definition[斜体]{#def-ring-division-ring}
非零環で、全ての非零元が単元であるものを :term[斜体]{en="division ring" yomi="しゃたい"} という。可換な斜体は体である。斜体では $ab=0$ かつ $a\ne0$ なら $a^{-1}$ を左から掛けて $b=0$ となる。
:::

:::proposition[四元数体の構成]{#prop-ring-quaternion}
$\C$ 行列
$$
H(z,w)=\begin{pmatrix}z&w\\-\overline w&\overline z\end{pmatrix},\qquad z,w\in\C
$$
全体は四次元実斜体である。これを :term[四元数体]{en="quaternion division algebra" yomi="しげんすうたい"} $\mathbb H$ と呼ぶ。
:::

:::proof
$H(z,w)H(z',w')=H(zz'-w\overline{w'},zw'+w\overline{z'})$ と計算できるので積で閉じる。和、実スカラー倍、単位行列にも閉じ、結合性は行列積による。$H(z,w)H(\overline z,-w)=H(|z|^2+|w|^2,0)$ であり、逆順でも同じ値になる。非零なら係数は正であり、後者を割れば逆元になる。$1=H(1,0)$、$i=H(i,0)$、$j=H(0,1)$、$k=H(0,i)$ は実基底である。積の表示から $i^2=j^2=-1$、$ij=k=-ji$、従って $k^2=-1$、$jk=i=-kj$、$ki=j=-ik$ である。
:::

$q=a+bi+cj+dk$ に対し $\bar q=a-bi-cj-dk$ とすれば $q\bar q=a^2+b^2+c^2+d^2$ である。これは行列式にも一致するので $N(q)=q\bar q$ と置くと $N(qr)=N(q)N(r)$ である。例えば $(1+i)j=j+k$ だが $j(1+i)=j-k$ であり、$(1+i+j)^{-1}=(1-i-j)/3$ である。

:::example[共役の順序を逆にする]
$q=1+i$、$r=1+j$ とする。$qr=1+i+j+k$ なので $\overline{qr}=1-i-j-k$ である。$\bar r\bar q=(1-j)(1-i)=1-i-j+ji=1-i-j-k$ となるが、$\bar q\bar r$ の $k$ の成分は $+1$ になる。一般に行列表示の共役は複素共役転置に一致し、積の順序を逆転する。次に $N(q)=N(r)=2$ なので $N(qr)=4$ であり、実際 $qr$ の係数の平方和も $4$ になる。非可換性は共役の順序には現れるが、この実数値のノルムの積には影響しない。
:::

:::example[ノルムと平方が異なる]
$v=2i-j+2k$ とすると、異なる虚数単位の交差項は $ij+ji=0$ などで消える。従って $v^2=-(4+1+4)=-9$ であり、共役は $-v$ なので $N(v)=9$ である。$v/3$ の平方は $-1$ になり、$1,v/3$ が張る平面は積で閉じて $\C$ と同型となる。ただし $i$ と $v/3$ は可換でない。実際 $iv-vi=-2k-4j$ である。一つの複素部分を選べることと、それが斜体全体の中心にあることは別である。
:::

### 四元数の積を実成分と虚成分に分ける

:::example[四成分と複素行列で積を照合する]
$q=1+2i-j+k$、$r=2-i+3j$ とする。積の実成分は、実部の積から虚部の同じ添字の積を引いた和である。異なる虚数単位の積は、$ij=k$ の巡回順で正、逆順で負になる。従って虚部では、実部と虚部の二通りの積に、虚部どうしの符号付きの積が加わる。

| 積 | 実成分 | $i$ 成分 | $j$ 成分 | $k$ 成分 |
| --- | --- | --- | --- | --- |
| $qr$ | $7$ | $0$ | $0$ | $7$ |
| $rq$ | $7$ | $6$ | $2$ | $-3$ |

これらは $qr=7+7k$ および $rq=7+6i+2j-3k$ となる。例えば $q$ の複素行列は $\begin{pmatrix}1 + 2 i&-1 + i\\1 + i&1 - 2 i\end{pmatrix}$ であり、$r$ の複素行列を右から掛けると $\begin{pmatrix}7&7 i\\7 i&7\end{pmatrix}$ になる。その第一行の実部と虚部を読むと表の $qr$ の四成分が復元できる。

逆元は $q^{-1}=\frac{1}{7}-\frac{2}{7}i+\frac{1}{7}j-\frac{1}{7}k$ である。左積と右積を展開するとどちらも $N(q)^{-1}q\bar q=1$ となる。$N(q)=7$ であり、積のノルムは $98$ である。四成分を求め直して平方和を取っても、最初に両者のノルムを求めて掛けても一致する。積の順序によって四成分が変わっても、ノルムが変わらないことを確認できる。
:::

:::example[四成分と複素行列で積を照合する]
$q=i+2j+2k$、$r=2i-j+k$ とする。積の実成分は、実部の積から虚部の同じ添字の積を引いた和である。異なる虚数単位の積は、$ij=k$ の巡回順で正、逆順で負になる。従って虚部では、実部と虚部の二通りの積に、虚部どうしの符号付きの積が加わる。

| $rq$ | $-2$ | $-4$ | $-3$ | $5$ |

これらは $qr=-2+4i+3j-5k$ および $rq=-2-4i-3j+5k$ となる。例えば $q$ の複素行列は $\begin{pmatrix}i&2 + 2 i\\-2 + 2 i&- i\end{pmatrix}$ であり、$r$ の複素行列を右から掛けると $\begin{pmatrix}-2 + 4 i&3 - 5 i\\-3 - 5 i&-2 - 4 i\end{pmatrix}$ になる。その第一行の実部と虚部を読むと表の $qr$ の四成分が復元できる。

逆元は $q^{-1}=-\frac{1}{9}i-\frac{2}{9}j-\frac{2}{9}k$ である。左積と右積を展開するとどちらも $N(q)^{-1}q\bar q=1$ となる。$N(q)=9$ であり、積のノルムは $54$ である。四成分を求め直して平方和を取っても、最初に両者のノルムを求めて掛けても一致する。積の順序によって四成分が変わっても、ノルムが変わらないことを確認できる。
:::

:::example[四成分と複素行列で積を照合する]
$q=2+3i+j-2k$、$r=1-2i+j+3k$ とする。積の実成分は、実部の積から虚部の同じ添字の積を引いた和である。異なる虚数単位の積は、$ij=k$ の巡回順で正、逆順で負になる。従って虚部では、実部と虚部の二通りの積に、虚部どうしの符号付きの積が加わる。

| 積 | 実成分 | $i$ 成分 | $j$ 成分 | $k$ 成分 |
| --- | --- | --- | --- | --- |
| $qr$ | $13$ | $4$ | $-2$ | $9$ |
| $rq$ | $13$ | $-6$ | $8$ | $-1$ |

これらは $qr=13+4i-2j+9k$ および $rq=13-6i+8j-k$ となる。例えば $q$ の複素行列は $\begin{pmatrix}2 + 3 i&1 - 2 i\\-1 - 2 i&2 - 3 i\end{pmatrix}$ であり、$r$ の複素行列を右から掛けると $\begin{pmatrix}13 + 4 i&-2 + 9 i\\2 + 9 i&13 - 4 i\end{pmatrix}$ になる。その第一行の実部と虚部を読むと表の $qr$ の四成分が復元できる。

:::example[共役が虚数単位を回す]
$u=(1+i)/\sqrt2$ とする。この元のノルムは $1$ で、$u^{-1}=(1-i)/\sqrt2$ である。$u$ は $i$ と可換なので $uiu^{-1}=i$ である。また $uju^{-1}=(1+i)j(1-i)/2=k$、$uku^{-1}=-j$ となる。後者は $k=ij$ と共役の乗法性からも得られる。三成分の長さを保ちつつ $j,k$ 平面を回すこの写像は、積が非可換であるため恒等にならない。反対に実数のように中心に属する元で共役すれば全ての元が固定される。

## Frobenius の定理（実斜体の分類）

### 一つの虚数単位と可換な部分から調べる

:::theorem[Frobenius の実斜体の分類]{#thm-ring-frobenius-division}
単位元付き有限次元実多元環 $D$ が斜体なら、実多元環として $\R,\C,\mathbb H$ のいずれかと同型である。
:::

:::proof[複素部分を見つける]
$D=\R 1$ なら第一の場合である。そうでなければ非実の元 $a$ を選ぶ。$D$ が有限次元なので $1,a,a^2,\ldots$ は一次従属であり、$a$ の零化多項式のイデアルは非零である。モニックな生成元 $f$ は既約である。分解 $f=gh$ があれば $g(a)h(a)=0$ であり、斜体なので少なくとも一方が零となって最小次数に反するためである。実係数既約多項式の次数は $1$ または $2$ である（:ref[prop-linalg-irreducible-real-complex]）。非実性から二次で $f=x^2+bx+c$、判別式が負である。従って $i=(a+b/2)/\sqrt{c-b^2/4}$ は $i^2=-1$ を満たす。実数と $i$ が張る部分は $\C$ と同型である。
:::

:::proof[可換部分と反可換部分]
$i$ と可換な $u$ を取る。$u$ の冪の実線形関係により $\C[x]\to D$、$x\mapsto u$ の核は非零であり、中心に入っていない $\C$ の像も、この $u$ とは可換なので評価は準同型になる。零化多項式を $\C$ 上で一次因子に分解すると、斜体での積の零性により $u$ がそのどれかの根に一致する。従って可換な部分は $\C$ 自身である。

写像 $\sigma(u)=iui^{-1}$ は $\sigma^2=1$ を満たす。$u$ を $(u+\sigma(u))/2+(u-\sigma(u))/2$ と分けると、第一の部分は $i$ と可換、第二は $i$ と反可換であり、共通部分は零である。反可換な部分が零なら $D=\C$ である。そうでなければその非零元を $v$ とする。$v^2$ は $i$ と可換だから複素部分に属する。しかも $v$ と可換であり、$v(a+bi)=(a-bi)v$ よりその虚部は零である。$v^2$ は非零で、正なら $(v-\sqrt{v^2})(v+\sqrt{v^2})=0$ から $v$ は実数となって反可換性に反する。よって $v^2<0$ であり、$j=v/\sqrt{-v^2}$ とすれば $j^2=-1,\ ji=-ij$ となる。任意の反可換元 $w$ に対し $wj^{-1}$ は $i$ と可換である。従って反可換部分は $\C j$ である。基底 $1,i,j,ij$ の積は四元数の関係と同じなので、:ref[prop-ring-quaternion] の $\mathbb H$ と同型を得る。
:::

例えば実次元 $3$ や $8$ の結合的な実斜体は存在しない。有限次元の仮定は、各元の冪に線形関係を与える箇所で使う。結合性も、多項式の評価と共役による分解に必要である。

:::example[二次の関係から実斜体を同定する]
$D=\R[t]/(t^2-2t+5)$ とする。$u=([t]-1)/2$ と置くと $u^2=-1$ である。任意の元は $a+bu$ と一意に書ける。非零なら共役との積 $a^2+b^2$ が正なので逆元をもち、斜体である。定理の証明で非実の元の二次関係を平方完成する段階が、この例では $([t]-1)^2=-4$ に対応する。$D$ は可換で、明示的同型は $a+bu\mapsto a+bi$ である。
:::

:::example[非可換な実四次元多元環でも仮定を確かめる]
$M_2(\R)$ は実四次元で積も結合的だが、$E_{11}E_{22}=0$ で両因子が非零なので斜体ではない。$E_{11}$ の満たす $t^2-t$ は零化多項式だが既約ではない。分解 $(E_{11}-1)E_{11}=0$ から一方の因子が零とは結論できないためである。四元数体と同じ実次元というだけでは同型にならないことが、Frobenius の証明で斜体を使う箇所からも分かる。
:::

### 可換部分と反可換部分の計算

:::example[四成分と複素行列で積を照合する]
$q=4+2i+3j-k$、$r=i$ とする。積の実成分は、実部の積から虚部の同じ添字の積を引いた和である。異なる虚数単位の積は、$ij=k$ の巡回順で正、逆順で負になる。従って虚部では、実部と虚部の二通りの積に、虚部どうしの符号付きの積が加わる。

| 積 | 実成分 | $i$ 成分 | $j$ 成分 | $k$ 成分 |
| --- | --- | --- | --- | --- |
| $qr$ | $-2$ | $4$ | $-1$ | $-3$ |
| $rq$ | $-2$ | $4$ | $1$ | $3$ |

これらは $qr=-2+4i-j-3k$ および $rq=-2+4i+j+3k$ となる。例えば $q$ の複素行列は $\begin{pmatrix}4 + 2 i&3 - i\\-3 - i&4 - 2 i\end{pmatrix}$ であり、$r$ の複素行列を右から掛けると $\begin{pmatrix}-2 + 4 i&-1 - 3 i\\1 - 3 i&-2 - 4 i\end{pmatrix}$ になる。その第一行の実部と虚部を読むと表の $qr$ の四成分が復元できる。

ここでは $i$ による共役 $\sigma(q)=iqi^{-1}$ を調べる。$1,i$ は $i$ と可換で、$j,k$ は反可換だから $\sigma(q)=4+2i-3j+k$ である。従って $(q+\sigma(q))/2=4+2i$、$(q-\sigma(q))/2=3j-k$ となる。後者は $(3-i)j$ であり、右から $j^{-1}$ を掛けると複素部分に戻る。$i$ の共役の固有値 $1,-1$ で分ける操作は、実斜体の分類の証明で反可換な部分を取り出す段階に当たる。
:::

:::example[四成分と複素行列で積を照合する]
$q=1-i+2j+5k$、$r=j$ とする。積の実成分は、実部の積から虚部の同じ添字の積を引いた和である。異なる虚数単位の積は、$ij=k$ の巡回順で正、逆順で負になる。従って虚部では、実部と虚部の二通りの積に、虚部どうしの符号付きの積が加わる。

| 積 | 実成分 | $i$ 成分 | $j$ 成分 | $k$ 成分 |
| --- | --- | --- | --- | --- |
| $qr$ | $-2$ | $-5$ | $1$ | $-1$ |
| $rq$ | $-2$ | $5$ | $1$ | $1$ |

これらは $qr=-2-5i+j-k$ および $rq=-2+5i+j+k$ となる。例えば $q$ の複素行列は $\begin{pmatrix}1 - i&2 + 5 i\\-2 + 5 i&1 + i\end{pmatrix}$ であり、$r$ の複素行列を右から掛けると $\begin{pmatrix}-2 - 5 i&1 - i\\-1 - i&-2 + 5 i\end{pmatrix}$ になる。その第一行の実部と虚部を読むと表の $qr$ の四成分が復元できる。

ここでは $i$ による共役 $\sigma(q)=iqi^{-1}$ を調べる。$1,i$ は $i$ と可換で、$j,k$ は反可換だから $\sigma(q)=1-i-2j-5k$ である。従って $(q+\sigma(q))/2=1-i$、$(q-\sigma(q))/2=2j+5k$ となる。後者は $(2+5i)j$ であり、右から $j^{-1}$ を掛けると複素部分に戻る。$i$ の共役の固有値 $1,-1$ で分ける操作は、実斜体の分類の証明で反可換な部分を取り出す段階に当たる。
:::

:::example[生成元の二乗を変えると零因子ができる]
$M_2(\R)$ で $i=\begin{pmatrix}0&-1\\1&0\end{pmatrix}$、$j=\begin{pmatrix}1&0\\0&-1\end{pmatrix}$ と置く。すると $i^2=-I$、$j^2=I$、$ji=-ij$ となる。$I,j$ は対角部分を張り、$i,ij$ は非対角部分を張るため、四元は基底である。反可換性は四元数と同じだが、$(I-j)(I+j)=0$ で両因子は非零である。従ってこの代数は斜体ではない。Frobenius の証明で $j^2$ の符号を負と確定する箇所では、正の平方からこのような零積が生じることを排除している。
:::

:::example[複素係数に拡大すると斜体性を失う]
四元数の複素行列表現を $\C$ 線形に延長すると $\C\otimes_\R\mathbb H\to M_2(\C)$ が得られる。$1,i$ の像は対角の $\begin{pmatrix}1&0\\0&1\end{pmatrix}$ と $\begin{pmatrix}i&0\\0&-i\end{pmatrix}$ であり、$j,k$ の像は $\begin{pmatrix}0&1\\-1&0\end{pmatrix}$ と $\begin{pmatrix}0&i\\i&0\end{pmatrix}$ である。それぞれの対は $\C$ 上一次独立なので、四像は行列環の基底である。従って延長した写像は同型である。この環で外側の複素単位を $i_0$、四元数の虚数単位を $i_1$ と書けば、$(1+i_0i_1)(1-i_0i_1)=0$ である。各因子は行列の対角の一成分だけが非零である。実斜体の分類の仮定は係数拡大後には保たれない。
:::

:::example[四成分と複素行列で積を照合する]
$q=3+4j-2k$、$r=1+i$ とする。積の実成分は、実部の積から虚部の同じ添字の積を引いた和である。異なる虚数単位の積は、$ij=k$ の巡回順で正、逆順で負になる。従って虚部では、実部と虚部の二通りの積に、虚部どうしの符号付きの積が加わる。

| 積 | 実成分 | $i$ 成分 | $j$ 成分 | $k$ 成分 |
| --- | --- | --- | --- | --- |
| $qr$ | $3$ | $3$ | $2$ | $-6$ |
| $rq$ | $3$ | $3$ | $6$ | $2$ |

これらは $qr=3+3i+2j-6k$ および $rq=3+3i+6j+2k$ となる。例えば $q$ の複素行列は $\begin{pmatrix}3&4 - 2 i\\-4 - 2 i&3\end{pmatrix}$ であり、$r$ の複素行列を右から掛けると $\begin{pmatrix}3 + 3 i&2 - 6 i\\-2 - 6 i&3 - 3 i\end{pmatrix}$ になる。その第一行の実部と虚部を読むと表の $qr$ の四成分が復元できる。

ここでは $i$ による共役 $\sigma(q)=iqi^{-1}$ を調べる。$1,i$ は $i$ と可換で、$j,k$ は反可換だから $\sigma(q)=3-4j+2k$ である。従って $(q+\sigma(q))/2=3$、$(q-\sigma(q))/2=4j-2k$ となる。後者は $(4-2i)j$ であり、右から $j^{-1}$ を掛けると複素部分に戻る。$i$ の共役の固有値 $1,-1$ で分ける操作は、実斜体の分類の証明で反可換な部分を取り出す段階に当たる。
:::

## 演習問題

::::exercise{level=basic}
$\R[t]/(t^2)$ で $2+3[t]$ の逆元を求めよ。

:::solution
$u=[t]$ とすると $u^2=0$ である。$(2+3u)(a+bu)=2a+(2b+3a)u$ なので $a=1/2,b=-3/4$ を取ればよい。従って逆元は $1/2-3u/4$ である。
:::
::::

::::exercise{level=basic}
$\Q[C_2]$ で $(2[e]+[g])([e]-2[g])$ を計算せよ。

:::solution
$[g]^2=[e]$ を使うと定数成分は $2-2=0$、$[g]$ 成分は $-4+1=-3$ である。従って積は $-3[g]$ である。
:::
::::

::::exercise{level=basic}
$u=3e_1+e_2,v=2e_1+5e_2$ の外積を求めよ。

:::solution
同じ添字は零になり、$e_2\wedge e_1$ は $-e_1\wedge e_2$ に等しい。従って $u\wedge v=(15-2)e_1\wedge e_2=13e_1\wedge e_2$ である。
:::
::::

::::exercise{level=basic}
$q=2+i-2k$ のノルム $N(q)$ と逆元を求めよ。

:::solution
$N(q)=4+1+4=9$ である。符号を反転した共役は $\bar q=2-i+2k$ であり、両順序で積が $9$ なので逆元は $(2-i+2k)/9$ である。
:::
::::

::::exercise{level=advanced}
$2$ 次元 $V$ で $T_K(V)$ の次数 $3$ と対称代数の次数 $3$ の次元を求めよ。

:::solution
テンソル代数では二つの基底元から作る長さ $3$ の語が基底なので $2^3=8$ である。対称代数では指数の和が $3$ の単項式が基底であり、$x^3,x^2 y,xy^2,y^3$ の四つである。
:::
::::

::::exercise{level=advanced}
$\bigwedge^2 K^3$ における $(e_1+e_2)\wedge(e_2+e_3)$ を昇順基底で表示せよ。

:::solution
展開すると $e_1\wedge e_2+e_1\wedge e_3+e_2\wedge e_2+e_2\wedge e_3$ であり、第 3 項は零である。残りは全て昇順なので、三つの基底における係数は $(1,1,1)$ である。
:::
::::

::::exercise{level=advanced}
$\mathbb H$ の中心を求めよ。

:::solution
$q=a+bi+cj+dk$ が $i$ と可換なら、$iq-qi=2ck-2dj=0$ なので $c=d=0$ である。さらに $j$ と可換なら $jq-qj=-2bk=0$ なので $b=0$ である。実数倍の単位元は全ての元と可換なので中心は $\R$ である。
:::
::::

::::exercise{level=advanced}
体 $K$ の標数が $2$ のとき、外積代数の積が可換になることを示し、対称代数と異なる例を示せ。

:::solution
生成元の交換則 $uv=-vu$ で $-1=1$ となるため生成元どうしが可換であり、任意の積も交換できる。$V=Ke$ なら外積代数で $e^2=0$ だが対称代数 $K[e]$ で $e^2$ は基底単項式で非零である。
:::
::::

::::exercise{level=advanced}
四元数 $q=2+i+j$ について $qiq^{-1}$ を求めよ。

:::solution
$N(q)=4+1+1=6$ なので $q^{-1}=(2-i-j)/6$ である。$qi=-1+2i-k$ であり、$(qi)(2-i-j)=4i+2j-4k$ となる。従って求める元は $(2i+j-2k)/3$ である。そのノルムは $(4+1+4)/9=1$ であり、ノルム $1$ の $i$ を共役で移した結果と一致する。
:::
::::

::::quiz
実多元環上のスカラー作用を環準同型で与えるとき、その像はどこに入るか。

- [x] 中心
- [ ] 非零の冪零元全体
- [ ] 単位元を含まない真のイデアル

:::explanation
$c$ の像は $c1_A$ であり、双線形性から任意の $a$ について $(c1_A)a=ca=a(c1_A)$ となるので中心に入る。単位元 $1$ の像は $1_A$ である。
:::

::::quiz{answer="6" tol="1e-9"}
四元数 $1+i+2j$ のノルム $q\bar q$ を求めよ。

:::explanation
係数の平方和なので $1^2+1^2+2^2+0^2=6$ である。
:::

::::quiz
有限次元の結合的な実斜体の実次元として可能なものを全て選べ。

- [x] $1$
- [x] $2$
- [ ] $3$
- [x] $4$
- [ ] $8$

:::explanation
分類による候補は $\R,\C,\mathbb H$ であり、順に基底の元の個数は $1,2,4$ である。この三つは実際に斜体なので三次元と八次元を除く選択肢が成り立つ。
:::

::::quiz{answer="6" tol="1e-9"}
$\bigwedge^2\Q^4$ の次元を求めよ。

:::explanation
四つの座標基底から異なる二つを昇順に選んだ外積が基底である。その個数は $\binom42=6$ である。
:::
::::

::::quiz{answer="10" tol="1e-9"}
四次元空間の二次外積を除き、外積代数の全次数の次元を足すといくつになるか。

:::explanation
四次元では外積の基底は基底添字の部分集合に対応するので、全体の次元は $2^4=16$ である。二次外積では二元の部分集合の個数 $\binom42=6$ を除く。従って残る次数の次元の和は $16-6=10$ である。
:::
