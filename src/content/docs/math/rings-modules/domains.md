## この章の目標

- 整域の約分と体の逆元の違いを説明する。
- 分数体と局所化を同値類として構成し、準同型の延長を与える。
- 局所化における零元と単元を判定する。
- イデアルの拡大・縮約と素イデアルの対応を計算する。

## 整域と体

### 消去と除法

:ref[thm-ring-prime-max-quotient] で用いた整域では、$a\ne0$ のとき $ab=ac$ から $a(b-c)=0$、従って $b=c$ となる。逆にこの消去がどの非零元にも成り立つ非零可換環は、$ab=a0$ に消去を適用できるため整域である。体であれば $a^{-1}$ が環内にあるので消去だけでなく $ax=b$ をいつでも解ける。そこで、この方程式の解を外に付け加えることを考える。

:::example[整域と体の境界]
$\Z$ は整域であり $3b=3c$ は $b=c$ を意味する。ただし $3x=1$ は $\Z$ で解けない。$\Q[x]$ では非零多項式の積の最高次係数は非零であるので整域となるが、$xg(x)=1$ は左辺の定数項が零になるため解けない。$\Z/(15)$ では $3\cdot5=3\cdot0=0$ なので $3$ を消去できない。
:::

:::proposition[有限整域と標数]{#prop-ring-finite-domain}
有限整域は体である。整域の標数は $0$ または素数である。
:::

:::proof
有限整域で $a\ne0$ とすると、$x\mapsto ax$ は消去により単射である。有限集合の単射は全射なので $1$ の逆像があり、これが $a$ の逆元である。標数 $n>0$ の場合、$n=1$ は $1\ne0$ に反する。$n=ab$ と $1<a,b<n$ で分解できれば、$a1_R,b1_R$ はともに非零で積が $n1_R=0$ となる。従って $n$ は素数である。
:::

:::example[有限整域]
$\F_3[x]/(x^2+1)$ の元は $a+bu$、$u^2=-1$ と表す。$a,b$ が同時に零でなければ $a^2+b^2$ は $1$ または $2$ なので、共役 $a-bu$ をこれで割れば逆元になる。例えば $(1+u)^{-1}=2+u$ である。この体の元は $9$ 個だが標数は $3$ である。
:::

### 零積と標数を判定する

整域では積が零になることを手がかりに因子を調べられる。例えば整数を整域へ送るとき、標数に二つの非単元因子があれば直ちに零積ができる。

:::proposition[整域の標数と多項式環]{#prop-ring-domain-characteristic}
整域 $R$ の標数は零か素数である。また $R[x]$ は整域で、非零な $f,g$ に対して $\deg(fg)=\deg f+\deg g$ である。
:::

:::proof
正の標数 $n$ が合成数なら $n=ab$ に $1<a,b<n$ を取れる。$(a\cdot1)(b\cdot1)=n\cdot1=0$ となるが、$a\cdot1,b\cdot1$ は標数の最小性によりともに非零であり、整域の条件に反する。次に $f,g$ の最高次数を $m,n$、その係数を $a,b$ とすれば積の $m+n$ 次の係数は $ab$ である。他の項の次数はこれより小さく、$ab\ne0$ である。従って積は非零で、次数の式も得る。
:::

:::example[最高次項で単元を判定する]
$\Q[x]$ の $x^2+x+1$ が単元なら、逆多項式 $g$ との積が次数零になる必要がある。しかし両因子は非零であり、積の次数は $2+\deg g\ge2$ である。従ってこの元は非単元である。一方 $f=x^2+x+1$ について $fh=fk$ なら $f(h-k)=0$ から $h=k$ となる。従って約分はできる。同じ約分可能性を出発点に、次の節では多項式を分母に加える。
:::

:::example[同じ一次の関係式が整域性を変える]
$\Q[x,y]/(y-3x-1)$ で $y$ を $3x+1$ に置き換えると、各元は $x$ の多項式になる。任意の式と置換後の式の差は $y-(3x+1)$ の倍数である。これは $y^j-a^j=(y-a)\sum_{i=0}^{j-1}y^{j-1-i}a^i$ から分かる。逆に $y-(3x+1)$ の倍数は評価で零になる。従って剰余は $\Q[x]$ で整域である。一方、同じ関係式を平方した $(y-3x-1)^2$ だけを零とする環では、一次の関係式の類は非零で平方が零になる。イデアルの生成元の零点が同じでも、剰余に零因子が生じることがある。
:::

:::example[二次の剰余を逆元で判定する]
$\F_3[x]/(x^2+1)$ で $u=[x]$ とする。$a+bu$ を $a-bu$ と掛けると $a^2+b^2$ になる。法 $3$ で非零元の平方は $1$ なので、$(a,b)\ne(0,0)$ ならこの和は $1$ または $2$ である。いずれも法 $3$ で逆元を持つので、全ての非零元に逆がある。例えば $1+u$ の積の相手 $1-u$ は積 $2$ を与えるから、逆元は $2-2u$ となる。この環は $a,b$ を独立に選べるので $9$ 元の体である。有限環で元を直接反転できれば、整域性も同時に確認できる。
:::

:::example[関係式 $x^2=3$ による積の簡約]
$g=x^{2} - 3$ とし、整数係数の剰余環で $u=[x]$ と書く。任意の $x^j$ は、指数が $2$ 以上なら $u^2=3$ を使って指数を $2$ 下げられる。従って $A+Bu$ にしてから積を計算できる。二つの一次以下の式の差がモニックな $g$ の倍数になるためには、その差が零でなければならない。従ってこの表示は一意である。

$f=3 x + 5$ の類を掛けると、定数係数と一次係数の列は $\begin{pmatrix}5&9\\3&5\end{pmatrix}$ を掛けたものになる。実際、$u^2=c$ と書けば $(a+bu)(A+Bu)=(aA+cbB)+(bA+aB)u$ である。列 $(1,0)^\top$ にこの行列を順に掛けた結果を、各冪の余りでも確かめる。

| 指数 | $f^j$ の余り | 定数係数 | 一次係数 |
| --- | --- | --- | --- |
| $0$ | $1$ | $1$ | $0$ |
| $1$ | $3 x + 5$ | $5$ | $3$ |
| $2$ | $30 x + 52$ | $52$ | $30$ |
| $3$ | $306 x + 530$ | $530$ | $306$ |
| $4$ | $3120 x + 5404$ | $5404$ | $3120$ |

$a=5,b=3,c=3$ に対し $a^2-cb^2=-2$ は $\Q$ では非零なので、$\Q[x]/(g)$ での逆元は $(5 - 3 x)/(-2)$ である。整数係数の環で同じ元に逆元があるのは、この積の行列が整数行列として逆をもつとき、すなわち行列式が $\pm1$ のときに限る。必要性は行列式を掛け合わせると $1$ になるためであり、十分性は同じ逆元の式で分母が $\pm1$ になるためである。
:::

:::example[二次の整数環とその分数体で割り算を比較する]
$R=\Z[\sqrt3]$ において $1+\sqrt3$ と $2+\sqrt3$ を考える。両者は実数体の非零元なので $R$ で約分できる。$a+b\sqrt3$ と $a-b\sqrt3$ の積 $a^2-3b^2$ は整数であり、共役は積を保つ。従って元が単元ならこの整数の値は $\pm1$ でなければならない。逆に値が $\pm1$ なら共役に符号を掛けて逆元が得られる。$1+\sqrt3$ では値が $-2$ なので逆元は $R$ に無い。一方 $2+\sqrt3$ では値が $1$ なので $2-\sqrt3$ が逆元である。分数体では前者にも $(\sqrt3-1)/2$ という逆元ができる。この例では、非零性、約分可能性、逆元の所属を同じ元の上で一つずつ検査できる。
:::

:::example[有限個の元を持つことが必要な箇所]
$\F_5[x]$ で $x$ による乗法は、各係数を一つ高い位置に移す。従って二つの異なる多項式の像が一致することはない。一方、像は定数項が零の多項式に限り、$1$ を得られない。係数体 $\F_5$ は有限でも、多項式の次数は上に有界でないため環自体は無限である。実際 $1,x,x^2,\ldots$ は全て異なる。このため、有限整域で単射な乗法から全射性を得た論証をこの環に適用することはできない。
:::

## 分数体の構成と普遍性

### 分子と分母に同じ倍率を掛ける

:::definition[分数体]{#def-ring-fraction-field}
整域 $R$ の対 $(a,s)$、$a\in R,\ s\in R\setminus\{0\}$ に $(a,s)\sim(b,t)\iff at=bs$ と定める。同値類を $a/s$ と書き、
$$
\frac as+\frac bt=\frac{at+bs}{st},\qquad
\frac as\frac bt=\frac{ab}{st}
$$
で演算する体を :term[分数体]{en="field of fractions" yomi="ぶんすうたい"} $\operatorname{Frac}(R)$ という。
:::

:::proof[分数体の構成]
反射性と対称性は等式から従う。$at=bs$、$bu=ct$ なら $atu=bsu=cts$ となり、$t\ne0$ の消去で $au=cs$ である。演算について $as'=a's$、$bt'=b't$ を用いると
$$
\begin{aligned}
(at+bs)s't'&=(a't'+b's')st,\\
ab\,s't'&=a'b'\,st
\end{aligned}
$$
となる。従って代表を換えても類は変わらない。三分数の和は共通分母の積を用いて分子の三項の和に、三分数の積は分子と分母それぞれの三因子の積にできるので結合的である。分配法則は、$a/s$ と $b/t+c/u$ の積の分子 $a(bu+ct)$ を展開し、右辺の和で分母を $stu$ に揃えて確かめられる。零元と単位元は $0/1,1/1$、加法逆元は $-a/s$ である。$a/s=0$ と $a=0$ が同値なので、非零元には $s/a$ が存在する。
:::

:::theorem[分数体への延長]{#thm-ring-frac-universal}
$i\colon R\to\operatorname{Frac}(R), a\mapsto a/1$ は単射の準同型である。$R$ から体 $K$ への単射な準同型 $f$ は、$\operatorname{Frac}(R)\to K$ にただ一通り延長する。その像は $f(R)$ を含む $K$ の最小の部分体となる。
:::

:::proof
$i$ が演算を保つことは分母 $1$ の式で分かり、$a/1=b/1$ なら $a=b$ である。$f(s)\ne0$ なので $\bar f(a/s)=f(a)f(s)^{-1}$ と定められる。$at=bs$ の像に $f(s)^{-1}f(t)^{-1}$ を掛ければ代表によらない。演算を保つことは式に代入して確かめられる。$a/s=(a/1)(s/1)^{-1}$ により公式は強制される。核に属する分数は $f(a)=0$ より $a=0$ であり、像は体である。$f(R)$ を含む部分体は全ての $f(a)f(s)^{-1}$ を含むので最小性も従う。
:::

:::example[二つの分数体]
$\operatorname{Frac}(\Z)$ は $\Q$ である。$\operatorname{Frac}(\Q[x])$ は有理関数体 $\Q(x)$ であり、$(x^2-1)/(x-1)=x+1$ である。この等式は分数体内の等式である。左辺を実数への部分関数とみなしたときは $x=1$ に値を定めていないので、定義域の情報とは区別する。
:::

:::example[二つの整数環から同じ分数体が得られる]
$\Z[i]$ の分数体を $\C$ の中で考えると $\Q(i)=\{a+bi\mid a,b\in\Q\}$ に等しい。整数係数の分数 $(u+vi)/(w+zi)$ に $w-zi$ を分母と分子に掛けると分母は非零整数 $w^2+z^2$ になり、分子は整数係数の Gauss 整数になる。逆に有理数の二係数の分母をそろえれば $\Z[i]$ の分数になる。例えば $(3+2i)/(1-i)=(1+5i)/2$ である。$\Z[2i]=\Z+2i\Z$ は $i$ を含まないが、分数体では $2i/2=i$ なので同じ $\Q(i)$ になる。分数体が一致しても、埋め込んだ整域の元や単元は一致するとは限らない。
:::

### 分数の代表を選び直して計算する

零でない分母を選ぶという条件は、もとの整域のどの元を逆にしたかを示す。分数体では全ての非零元を逆にするので、二つの分数の等しさは交差積だけで判定できる。

:::proposition[分数体の部分環による特徴付け]{#prop-ring-fraction-subfield}
整域 $R$ が体 $L$ の部分環であるとき、$L$ において $R$ を含む最小の部分体は $\{ab^{-1}\mid a,b\in R,\ b\ne0\}$ である。これは $R$ の分数体と同型である。
:::

:::proof
$R$ を含む任意の部分体は各非零 $b$ の逆元を含むので表示された元を全て含む。表示された集合は通分と分子分母の乗法により差と積で閉じ、非零分数の反転でも閉じる。従ってそれ自体が部分体である。$ab^{-1}=cd^{-1}$ は $ad=bc$ と同値であり、演算も一致するため構成した分数体との同型を得る。
:::

:::example[多項式の交差積と約分]
$K=\Q$ とし、$\operatorname{Frac}(K[x])$ の二元 $A=\frac{{\left(x - 1\right) \left(x + 2\right)}}{{\left(x - 1\right) \left(x + 3\right)}}$、$B=\frac{{x + 1}}{{x - 2}}$ を考える。分母はいずれも非零多項式なので、分数体の構成に使える。$A$ の分子と分母の最大公約元は $x - 1$ である。この共通因子を取り除いた代表は $\frac{x + 2}{x + 3}$ である。同様に $B$ の既約代表は $\frac{x + 1}{x - 2}$ である。ここで既約とは、分子と分母が単元以外の共通因子を持たないことを指す。

| 式 | 通分または乗法の分子と分母 | 約分した元 |
| --- | --- | --- |
| $A+B$ | $2 x^{3} + 2 x^{2} - 5 x + 1\ ;\ x^{3} - 7 x + 6$ | $\frac{2 x^{2} + 4 x - 1}{x^{2} + x - 6}$ |
| $AB$ | $x^{3} + 2 x^{2} - x - 2\ ;\ x^{3} - 7 x + 6$ | $\frac{x^{2} + 3 x + 2}{x^{2} + x - 6}$ |

例えば $A=f/g$、$B=h/k$ の加法の結果は、その表示の分子と分母を $fk+hg$ と $gk$ に交差して掛ければ確かめられる。多項式としてこの等式が成り立てば分数の同値性が成立する。分母がある点で値零になることは、分母が零多項式であることとは異なる。従って分数体での約分はできるが、最初の式から直接値を代入できる点と、約分した代表から値を取れる点は分けて考える。
:::

:::example[多項式の交差積と約分]
$K=\Q$ とし、$\operatorname{Frac}(K[x])$ の二元 $A=\frac{{\left(x + 1\right)^{2}}}{{x^{2} - 1}}$、$B=\frac{{x - 2}}{{x + 1}}$ を考える。分母はいずれも非零多項式なので、分数体の構成に使える。$A$ の分子と分母の最大公約元は $x + 1$ である。この共通因子を取り除いた代表は $\frac{x + 1}{x - 1}$ である。同様に $B$ の既約代表は $\frac{x - 2}{x + 1}$ である。ここで既約とは、分子と分母が単元以外の共通因子を持たないことを指す。

| 式 | 通分または乗法の分子と分母 | 約分した元 |
| --- | --- | --- |
| $A+B$ | $2 x^{3} + x^{2} + 2 x + 3\ ;\ x^{3} + x^{2} - x - 1$ | $\frac{2 x^{2} - x + 3}{x^{2} - 1}$ |
| $AB$ | $x^{3} - 3 x - 2\ ;\ x^{3} + x^{2} - x - 1$ | $\frac{x - 2}{x - 1}$ |

例えば $A=f/g$、$B=h/k$ の加法の結果は、その表示の分子と分母を $fk+hg$ と $gk$ に交差して掛ければ確かめられる。多項式としてこの等式が成り立てば分数の同値性が成立する。分母がある点で値零になることは、分母が零多項式であることとは異なる。従って分数体での約分はできるが、最初の式から直接値を代入できる点と、約分した代表から値を取れる点は分けて考える。
:::

:::example[交差積で有理数の計算を確かめる]
第一の元 $A$ の代表を $14/45$、第二の元 $B$ の代表を $22/63$、第三の元 $C$ の代表を $11/56$ とする。分数体の構成では、各代表の分母が非零であることを先に確認する。加法では共通の分母を作り、乗法では分子と分母を別々に掛ける。商では第三の代表の分子も非零であることを確かめてから逆転する。

| 演算 | 構成で得られる代表 | 既約な代表 |
| --- | --- | --- |
| $A+B$ | $\frac{1872}{2835}$ | $\frac{208}{315}$ |
| $AB$ | $\frac{308}{2835}$ | $\frac{44}{405}$ |
| $(A+B)/C$ | $\frac{104832}{31185}$ | $\frac{1664}{495}$ |

たとえば和が $\frac{208}{315}$ になることは、各分数を整数の組と見て交差積を取れば確認できる。表の中央列を先に約分してから最後の割り算を行ってもよい。実際、等しい分数に同じ非零分数の逆を掛けても等しいという性質は、交差積の両辺に同じ因子を掛けることで得られる。この点が、手計算での約分を代表の変更として正当化する。
:::

:::example[同じ整域を異なる体へ入れる]
$R=\Z[u]/(u^2-2)$ から $\R$ へ $[u]$ を $\sqrt2$ に送る。任意の元は $a+b[u]$ に簡約され、$a+b\sqrt2=0$ なら $\sqrt2$ の無理性から $a=b=0$ である。従ってこれは埋め込みである。$-\sqrt2$ への写像も同じ理由で埋め込みとなる。どちらの部分体も $\Q+\Q\sqrt2$ である。実際、非零元 $a+b\sqrt2$ を $a-b\sqrt2$ と掛けた $a^2-2b^2$ は非零の有理数で、分数の形はこの集合内で閉じる。ただし二つの埋め込みは $[u]$ の像が異なり、分数体への延長もそれぞれの像を保つ。
:::

### 二変数の順序を変えて分数体を構成する

:::proposition[反復した分数体]{#prop-ring-fraction-iterate}
整域 $R$ の分数体を $K$ とする。$R[x]$ の分数体は $K[x]$ の分数体と同型である。特に体 $k$ について $k(x,y)$ は $k(x)(y)$ と同型である。
:::

:::proof
係数の単射 $R\to K$ を多項式の係数に適用すると $R[x]\hookrightarrow K[x]$ であり、非零分母は非零のままなので分数体に延長できる。延長は $f/g$ が零なら $f$ の像が零という理由で単射である。逆に $F,G\in K[x]$（$G\ne0$）の係数は合わせても有限個である。その分母の積 $d\in R$ は非零で、$dF,dG\in R[x]$ となる。従って $F/G=(dF)/(dG)$ であり、延長は全射である。最後は $R=k[x]$、多項式変数を $y$ と置いて適用する。
:::

:::example[分数を多項式係数に戻す]
$\Q(x)(y)$ で
$$
F=\frac{\dfrac{y}{x+1}+\dfrac{1}{x}}{\dfrac{y-1}{x}+\dfrac{y}{x+1}}
$$
とする。$x(x+1)$ を分子分母の両方に掛けると、分子は $xy+x+1$、分母は $(2x+1)y-x-1$ となる。分母は $y$ の係数が零でないため非零多項式である。従ってこの分数は $\Q[x,y]$ の二元の比である。この表示で初めて $x,y$ が同じ立場に見えるが、元の表示では $y$ についての係数体の中で $x$ を先に約分できることに利点がある。例えば $y=0$ の代入は両表示で $-1$ を与える一方、$x=-1$ を直接入れるには元の表示では係数の分母が消える。多項式の比に直した後、必要な評価や約分を別に行う。
:::

## 積閉集合による分数環

### 零因子を分母にしてよい場合

分数体の構成では $at=bs$ の推移性に非零元の消去を用いた。零因子のある環で分母 $s$ を可逆にすると $sa=0$ から $a=0$ が強制される。この情報を同値関係に含める。

:::definition[積閉集合と局所化]{#def-ring-localization}
可換環 $R$ の部分集合 $S$ が $1$ を含み積で閉じるとき :term[積閉集合]{en="multiplicative set" yomi="せきへいしゅうごう"} と呼ぶ。$R\times S$ に
$$
(a,s)\sim(b,t)\iff \text{ある }v\in S\text{ について }v(at-bs)=0
\label{eq-ring-local-equivalence}
$$
と置き、類 $a/s$ に分数体と同じ和と積を入れた環を :term[局所化]{en="localization" yomi="きょくしょか"} $S^{-1}R$ と呼ぶ。$0\in S$ なら全ての類が等しく零環になる。
:::

:::proof[同値関係と演算]
反射性では $v=1$ を取れ、対称性は符号の変更である。$v(at-bs)=0$ と $w(bu-ct)=0$ なら、両差にそれぞれ $u,s$ を掛けて足すと $vw\,t(au-cs)=0$ を得る。$vwt\in S$ であるため推移性が従う。和の二つの代表による交差積の差は、$as'-a's$ の $tt'$ 倍と $bt'-b't$ の $ss'$ 倍の和である。積の場合の差は $(as')(bt')-(a's)(b't)$ であり、$(as'-a's)bt'+a's(bt'-b't)$ と展開できる。元の同値の証拠を掛け合わせれば両差が消える。結合性、分配法則、単位元については分数体の計算に消去を使っていないため、同じ共通分母で確かめられる。
:::

:::theorem[局所化の普遍性と核]{#thm-ring-local-univ}
$\lambda\colon R\to S^{-1}R,\ a\mapsto a/1$ は環準同型であり、$S$ の像を全て単元にする。この性質をもつ可換環 $T$ への準同型 $f$ は $\lambda$ を通じて一意に分解する。また
$$
\Ker\lambda=\{a\in R\mid va=0\text{ となる }v\in S\text{ がある}\}.
$$
:::

:::proof
分数演算から $\lambda$ は準同型で、$s/1$ の逆元は $1/s$ である。$a/s$ と $b/t$ が同じなら $f(v)(f(a)f(t)-f(b)f(s))=0$ なので $f(v)$ を消去できる。従って $a/s\mapsto f(a)f(s)^{-1}$ が定まる。分数演算を代入して準同型であることが分かる。分数を $\lambda(a)\lambda(s)^{-1}$ と書くと一意性も従う。最後に :eqref[eq-ring-local-equivalence] で $a/1=0/1$ を判定すると核の式が得られる。
:::

:::example[一つの整数を逆にする]
$S=\{2^n\mid n\ge0\}\subset\Z$ と置くと $S^{-1}\Z=\Z[1/2]$ である。$3/8+5/4=13/8$ であるが $1/3$ は含まれない。$1/3=a/2^n$ なら $3a=2^n$ となり、右辺は $3$ で割れないためである。
:::

:::example[一つの成分を消す]
$R=\Z/(12),\ S=\{[2]^n\mid n\ge0\}$ とする。法 $3$ への写像は $2$ の像を単元にする。一方 $[3]/1=0$ である。実際 $[4][3]=0$ で $[4]\in S$ である。従って $S^{-1}R$ では $2/1=-1/1$ であり、全ての分数は分母 $1$ にできる。法 $3$ の写像と $R/(3)\to S^{-1}R$ の合成はそれぞれ生成元に対して恒等なので $S^{-1}R\cong\Z/(3)$ である。
:::

:::proposition[単元判定]{#prop-ring-local-unit}
$a/s$ が $S^{-1}R$ の単元であることと $ab\in S$ となる $b\in R$ が存在することは同値である。
:::

:::proof
逆元を $b/t$ とすると、ある $v\in S$ で $v(ab-st)=0$ となる。従って $a(vb)=vst\in S$ である。逆に $ab\in S$ なら $sb/(ab)$ を掛けると $1$ になる。
:::

この判定で分子になれる単元の候補を集めた $\widetilde S=\{a\in R\mid ab\in S\text{ となる }b\in R\text{ がある}\}$ を $S$ の :term[飽和]{en="saturation" yomi="ほうわ"} という。$\widetilde S$ は $S$ を含み、$ab,cd\in S$ なら $(ac)(bd)\in S$ なので積閉である。また $uv\in\widetilde S$ なら $uvw\in S$ となる $w$ があり、$u,v$ はともに $\widetilde S$ に入る。$S^{-1}R$ では $\widetilde S$ の元も単元なので、標準写像は $\widetilde S^{-1}R\to S^{-1}R$ を誘導する。反対向きの写像は $S\subseteq\widetilde S$ から得られ、普遍性の一意性により両者は互いに逆である。

:::example[同じ局所化を異なる分母で表す]
$S=\{12^j\mid j\ge0\}\subseteq\Z$ の飽和は $\{\pm2^a3^b\mid a,b\ge0\}$ である。$12^j$ は $2,3$ 以外の素因数を持たず、逆に $2^a3^b$ は $2j\ge a,j\ge b$ とすれば $12^j$ を割る。同じ理由で $\{6^j\mid j\ge0\}$ の飽和もこの集合である。従って $\Z[1/12]=\Z[1/6]$ が $\Q$ の中で成立する。例えば $1/8$ は前者では $216/12^3$、後者では $27/6^3$ と表せる。
:::

### 単元を一つ付け加える表示への変換

:::proposition[一元の局所化の表示]{#prop-ring-local-presentation}
$a\in R$ と $S=\{a^n\mid n\ge0\}$ に対し $S^{-1}R\cong R[t]/(at-1)$ である。
:::

:::proof
$t$ を $1/a$ に送る多項式の評価は $at-1$ を零にするので商への写像を与える。逆に商では $a$ の像が $[t]$ を逆元にもつ。そのため局所化の普遍性で $R\to R[t]/(at-1)$ が $S^{-1}R$ からの写像に一意に延長する。二写像の合成は $R$ の像と $[t]$、または $R$ の像と $1/a$ を固定する。これらはそれぞれの環を生成するので合成は恒等である。
:::

:::example[零になる成分を関係式で確認する]
$R=\Z/(20)$ で $a=[2]$ を逆にする。$2t=1$ と $20=0$ から $5=20t^2=0$ が従う。従って商で $2$ の逆元は $3$ であり、$t=3$ と書ける。逆に $\Z/(5)$ で $t$ に $3$ を代入すると $2t-1=0$ になる。二方向の写像が各生成元で逆になるため、局所化は $\Z/(5)$ である。例えばこの環で $3/4$ は $3\cdot4^{-1}\equiv2$ となる。
:::

:::example[零因子を逆にしても全体は消えない]
$R=K[x,y]/(xy)$ において $x$ を逆にすると $\bar x\bar y=0$ に逆元を掛けて $\bar y=0$ を得る。従って結果は $K[x,x^{-1}]$ となる。具体的には $R\to K[x,x^{-1}]$ を $\bar x\mapsto x,\bar y\mapsto0$ として延長し、逆を $x\mapsto\bar x/1,\ x^{-1}\mapsto1/\bar x$ とすればよい。例えば $(x+y)/x=1$ になる。この例では $x$ は零因子だが冪零ではないので、局所化は零環ではない。
:::

### 取り除く分母と消える成分

積閉集合に零因子が入ると、別々だった二元が局所化後に等しくなることがある。消える元を判定するときは、分数の値を比べる前に分子が許された分母の倍で零になるかを調べる。

:::example[法 60 での局所化]
$R=\Z/(60)$ において $S$ を $[a]$ の冪全体とし、$a=6$ とする。法 $60$ の各素数冪を、$a$ がその素数で割れる群と割れない群に分ける。前者の積は $12$, 後者の積は $5$ である。法 $12$ では $a$ が冪零で、法 $5$ では単元である。この違いが局所化で成分を消すかどうかを決める。

法 $5$ への還元で $a$ の像の逆は $1$ である。従って $[j]/[a]^\ell\mapsto[j1^\ell]$ を法 $5$ で定められる。代表の同値性を調べるときは $a$ の因子を法 $5$ で約分できるため、この値は表示によらない。全射性は $\ell=0$ の像だけで分かる。

| 分子 | $[j]/1$ の像 | $[j]/[a]$ の像 |
| --- | --- | --- |
| $0$ | $0$ | $0$ |
| $1$ | $1$ | $1$ |
| $5$ | $0$ | $0$ |
| $7$ | $2$ | $2$ |
| $59$ | $4$ | $4$ |

この写像の核が零であることも確かめる。分子が $5$ の倍数であれば、$6^{2}$ を掛けると $12$ の因子を全て補えるので、法 $60$ で零である。逆に $6$ の冪を掛けて零になるなら、法 $5$ では $6$ が単元なので分子自体が $5$ の倍数である。従って元の環からの核は $([5])$ であるが、局所化から $\Z/(5)$ への写像の核は零である。よって $S^{-1}R\cong\Z/(5)$ を得る。
:::

:::example[法 126 での局所化]
$R=\Z/(126)$ において $S$ を $[a]$ の冪全体とし、$a=14$ とする。法 $126$ の各素数冪を、$a$ がその素数で割れる群と割れない群に分ける。前者の積は $14$, 後者の積は $9$ である。法 $14$ では $a$ が冪零で、法 $9$ では単元である。この違いが局所化で成分を消すかどうかを決める。

| 分子 | $[j]/1$ の像 | $[j]/[a]$ の像 |
| --- | --- | --- |
| $0$ | $0$ | $0$ |
| $1$ | $1$ | $2$ |
| $9$ | $0$ | $0$ |
| $23$ | $5$ | $1$ |
| $125$ | $8$ | $7$ |

この写像の核が零であることも確かめる。分子が $9$ の倍数であれば、$14^{2}$ を掛けると $14$ の因子を全て補えるので、法 $126$ で零である。逆に $14$ の冪を掛けて零になるなら、法 $9$ では $14$ が単元なので分子自体が $9$ の倍数である。従って元の環からの核は $([9])$ であるが、局所化から $\Z/(9)$ への写像の核は零である。よって $S^{-1}R\cong\Z/(9)$ を得る。
:::

:::example[12 の冪だけを分母に選ぶ]
$\Z[1/12]$ が $\Q$ のどの分数を含むか調べる。$\Z$ では局所化の同値関係から分母の交差積を取れるので、$\Z[1/12]$ を $\Q$ 内で調べてよい。考える分数を既約にすると $\frac{7}{18}$ である。

$18\mid 12^{2}$ なので $\frac{7}{18}=56/12^{2}$ と書ける。これは定義通りの表示である。$12^{2}$ は分母 $18$ を割り切る最初の冪である。

この判定を単元にも応用できる。分数が環に属し、その逆 $\frac{18}{7}$ も環に属すれば単元である。整数 $r$ が単元であるには、$r$ の全ての素因数が $12$ を割ることが必要十分である。なぜなら $1/r$ を $c/12^k$ に直せる条件が $r\mid 12^k$ だからである。従って整数で約分できることと、ここで逆元を持つことの間にはなお違いがある。
:::

### 零因子を除いた分母で全商環を作る

:::definition[全商環]{#def-ring-total-quotient}
可換環の元 $s$ による乗法が単射であるとき $s$ を :term[正則元]{en="regular element" yomi="せいそくげん"} という。正則元全体 $S$ で局所化した環を :term[全商環]{en="total ring of fractions" yomi="ぜんしょうかん"} と呼ぶ。
:::

正則な元による乗法の合成は単射なので $S$ は積閉である。$s a=0$ から $a=0$ が従うため、全商環への標準写像は単射である。整域では非零元が正則元なので、分数体と一致する。零因子を残す例では、全商環は体とは限らない。

:::example[二つの枝を別々に反転する]
$R=K[x,y]/(xy)$ の元は $c+xf(x)+yg(y)$ に一意に書ける。これは混合項が全て消え、残りが $xy$ の倍数になれば零だからである。従って $R$ は $K[x]\times K[y]$ のうち、二つの定数項が等しい組 $(F,G)$ 全体と同型である。$(F,G)$ が正則である条件は両方が非零であることに等しい。両方が非零なら各環が整域であるため、積を零にする相手は両成分が零である。片方が零なら、その成分だけに $x$ または $y$ を持つ相手を掛けて非零の零積ができる。

従って全商環から $K(x)\times K(y)$ への成分ごとの写像が定まり、両成分に零になる分数は元から零である。全射性も成り立つ。任意の組 $(A/B,C/D)$ について $B,D\ne0$ とし、分子を $(xA,yC)$、分母を $(xB,yD)$ と取れば、それぞれの定数項は両方零である。分母の両成分は非零なので正則であり、所望の分数が得られる。例えば $[x]/[x+y]$ は成分 $(1,0)$ となる。元の $R$ には定数項が異なるこの組はないが、正則な分母を入れると二つの枝を分けられる。
:::

:::example[法 504 での局所化]
$R=\Z/(504)$ において $S$ を $[a]$ の冪全体とし、$a=12$ とする。法 $504$ の各素数冪を、$a$ がその素数で割れる群と割れない群に分ける。前者の積は $72$, 後者の積は $7$ である。法 $72$ では $a$ が冪零で、法 $7$ では単元である。この違いが局所化で成分を消すかどうかを決める。

法 $7$ への還元で $a$ の像の逆は $3$ である。従って $[j]/[a]^\ell\mapsto[j3^\ell]$ を法 $7$ で定められる。代表の同値性を調べるときは $a$ の因子を法 $7$ で約分できるため、この値は表示によらない。全射性は $\ell=0$ の像だけで分かる。

| 分子 | $[j]/1$ の像 | $[j]/[a]$ の像 |
| --- | --- | --- |
| $0$ | $0$ | $0$ |
| $1$ | $1$ | $3$ |
| $7$ | $0$ | $0$ |
| $53$ | $4$ | $5$ |
| $503$ | $6$ | $4$ |

この写像の核が零であることも確かめる。分子が $7$ の倍数であれば、$12^{3}$ を掛けると $72$ の因子を全て補えるので、法 $504$ で零である。逆に $12$ の冪を掛けて零になるなら、法 $7$ では $12$ が単元なので分子自体が $7$ の倍数である。従って元の環からの核は $([7])$ であるが、局所化から $\Z/(7)$ への写像の核は零である。よって $S^{-1}R\cong\Z/(7)$ を得る。
:::

:::example[10 の冪だけを分母に選ぶ]
$\Z[1/10]$ が $\Q$ のどの分数を含むか調べる。$\Z$ では局所化の同値関係から分母の交差積を取れるので、$\Z[1/10]$ を $\Q$ 内で調べてよい。考える分数を既約にすると $\frac{21}{44}$ である。

分母を割る素数 $11$ は $10$ を割らない。もし $\frac{21}{44}=c/10^k$ と書けるなら $21\cdot10^k=44c$ である。右辺は $11$ で割れるが左辺は割れないので矛盾する。従ってこの分数は環に属さない。

この判定を単元にも応用できる。分数が環に属し、その逆 $\frac{44}{21}$ も環に属すれば単元である。整数 $r$ が単元であるには、$r$ の全ての素因数が $10$ を割ることが必要十分である。なぜなら $1/r$ を $c/10^k$ に直せる条件が $r\mid 10^k$ だからである。従って整数で約分できることと、ここで逆元を持つことの間にはなお違いがある。
:::

## 素イデアルでの局所化と局所環

### 一つの素イデアルの近くに残る情報

:::definition[局所環]{#def-ring-local-ring}
極大イデアルをただ一つもつ可換環を :term[局所環]{en="local ring" yomi="きょくしょかん"} という。素イデアル $\mathfrak p$ の外側 $S=R\setminus\mathfrak p$ による局所化を $R_{\mathfrak p}$ と書く。
:::

:::theorem[素イデアルにおける局所化]{#thm-ring-local-prime}
$R_{\mathfrak p}$ は局所環であり、唯一の極大イデアルは $\mathfrak pR_{\mathfrak p}=\{a/s\mid a\in\mathfrak p,\ s\notin\mathfrak p\}$ である。その剰余体 $\kappa(\mathfrak p)$ は $\operatorname{Frac}(R/\mathfrak p)$ に同型である。
:::

:::proof
$S$ は素性により積閉である。分子が $\mathfrak p$ の外にあれば分子も分母にできるので単元である。分子が $\mathfrak p$ にあれば任意の $b$ で $ab\in\mathfrak p$ なので :ref[prop-ring-local-unit] により非単元である。これら非単元の集合は演算式から差と吸収性で閉じるイデアルで、全ての真のイデアルはその中に入る。従って唯一の極大イデアルとなる。また $a/s\mapsto \bar a/\bar s$ は普遍性で定まり、全ての非零 $\bar s$ は $s\notin\mathfrak p$ から来るので全射である。核は $\bar a=0$ の分数全体なので第一同型定理で剰余体を得る。
:::

:::example[素数を一つ残す]
$\Z_{(5)}$ の分母には $5$ の倍数を使えない。$2/3$ は単元で、$10/3$ は極大イデアル $(5)\Z_{(5)}$ に入る。剰余への写像は $2/3\mapsto[2][3]^{-1}=[4]\in\F_5$ を与える。$\Z[1/5]$ では逆に $5$ が単元になるため、添字と分母生成元の書き方を区別する。
:::

:::example[極大でない素点]
$R=\Q[x,y]$、$\mathfrak p=(x)$ を取る。$y$ は $\mathfrak p$ に含まれないので局所化で単元になる。剰余体は $\Q(y)$ であり、$(y+x)/(1+y)$ の像は $y/(1+y)$ である。原点の極大イデアル $(x,y)$ に局所化した場合には $y$ は単元にならず、剰余体は $\Q$ になる。
:::

### 局所環で単元と極大イデアルを見分ける

:::proposition[局所環の非単元と剰余体]{#prop-ring-local-single-max}
非零可換環 $R$ について、極大イデアルが一つであることと、非単元全体がイデアルであることは同値である。このとき $\mathfrak m$ を唯一の極大イデアルとすると、$a\in R$ は $R/\mathfrak m$ での像が非零のとき、かつそのときに限り単元である。
:::

:::proof
非単元 $a$ では $(a)$ が真であり、ある極大イデアルに含まれる。極大イデアルの元は単元でないので、非単元全体は極大イデアルの合併に等しい。従って極大イデアルが一つならこの集合はイデアルである。逆にこの集合がイデアルなら $1$ を含まないので真で、全ての極大イデアルを含む。任意の一つの極大イデアルはこれと一致せざるを得ない。剰余での像の消滅は $\mathfrak m$ への所属で判定できる。
:::

:::example[5 での局所環と分数]
$\Z_{(5)}$ では分母から $5$ の倍数を除く。従って分数 $\frac{35}{12}$ の所属は、分子と分母の共通因子を全て約分してから判断する。任意の別表示についての判定は整数での交差積 $ad=bc$ により、表示だけで結果を変えられないことを使う。

縮約された分数の分母 $12$ は $5$ で割れない。従って環に属する。分子の $5$ の指数は $1$ なので、この元は極大イデアルの $1$ 乗に入るが、その次の冪には入らない。剰余体の像は $0$ である。

整数のイデアル $(35)$ をこの局所環に拡大すると $(5^{1})$ である。分子 $35$ を $5^{1}\cdot (7)$ と分けると $7$ は単元なので、両方の元は同じイデアルを生成する。縮約もまた $(5^{1})$ である。実際、$s$ が $5$ の倍数でなければ $5^{1}\mid sr$ と $5^{1}\mid r$ は同値である。このため局所化後のイデアル所属を調べるには $5$ の指数だけを比較すればよい。
:::

:::example[7 での局所環と分数]
$\Z_{(7)}$ では分母から $7$ の倍数を除く。従って分数 $\frac{11}{49}$ の所属は、分子と分母の共通因子を全て約分してから判断する。任意の別表示についての判定は整数での交差積 $ad=bc$ により、表示だけで結果を変えられないことを使う。

既約分数の分母に $7$ が残る。分母を $7$ の倍数でない整数に変えようとして $a/b=c/d$ とすると、$ad=bc$ の右辺だけが $7$ で割れる。従ってこの分数は局所環に入らない。

整数のイデアル $(11)$ をこの局所環に拡大すると $(7^{0})$ である。分子 $11$ を $7^{0}\cdot (11)$ と分けると $11$ は単元なので、両方の元は同じイデアルを生成する。縮約もまた $(7^{0})$ である。実際、$s$ が $7$ の倍数でなければ $7^{0}\mid sr$ と $7^{0}\mid r$ は同値である。このため局所化後のイデアル所属を調べるには $7$ の指数だけを比較すればよい。
:::

:::example[3 での局所環と分数]
$\Z_{(3)}$ では分母から $3$ の倍数を除く。従って分数 $\frac{18}{5}$ の所属は、分子と分母の共通因子を全て約分してから判断する。任意の別表示についての判定は整数での交差積 $ad=bc$ により、表示だけで結果を変えられないことを使う。

縮約された分数の分母 $5$ は $3$ で割れない。従って環に属する。分子の $3$ の指数は $2$ なので、この元は極大イデアルの $2$ 乗に入るが、その次の冪には入らない。剰余体の像は $0$ である。

整数のイデアル $(18)$ をこの局所環に拡大すると $(3^{2})$ である。分子 $18$ を $3^{2}\cdot (2)$ と分けると $2$ は単元なので、両方の元は同じイデアルを生成する。縮約もまた $(3^{2})$ である。実際、$s$ が $3$ の倍数でなければ $3^{2}\mid sr$ と $3^{2}\mid r$ は同値である。このため局所化後のイデアル所属を調べるには $3$ の指数だけを比較すればよい。
:::

:::example[点での値を剰余にする]
$\Q[x]_{(x-2)}$ の分母は $x=2$ で値が非零である。従って $\frac{x^2-4}{x+1}$ の剰余体への像は $0$ である。この元は $(x-2)(x+2)/(x+1)$ であり、$(x+2)/(x+1)$ の像は $4/3$ だから単元である。従って $\frac{x^2-4}{x+1}$ は極大イデアルを生成する。一方 $\frac{x+2}{x-2}$ は交差積を取ると $x-2$ が分子を割らないため、この局所環には入らない。評価できるかどうかは表示された分母だけでなく、約分後に残る因子から分かる。
:::

### 素イデアルの包含に沿って分母を増やす

:::proposition[局所化の再局所化]{#prop-ring-local-nested}
素イデアル $\mathfrak p\subseteq\mathfrak q$ に対し $(R_{\mathfrak q})_{\mathfrak pR_{\mathfrak q}}\cong R_{\mathfrak p}$ である。
:::

:::proof
$R\setminus\mathfrak q\subseteq R\setminus\mathfrak p$ なので、$R_{\mathfrak q}\to R_{\mathfrak p}$ が存在する。$R_{\mathfrak q}\to\operatorname{Frac}(R/\mathfrak p)$、$a/s\mapsto\bar a/\bar s$ は普遍性から定まる。その核は $a\in\mathfrak p$ の分数全体であり、$\mathfrak pR_{\mathfrak q}$ に等しい。実際、この集合はイデアルで、分母 $1$ の $\mathfrak p$ の像を含み、各分数は $(a/1)(1/s)$ だからである。従って $\mathfrak pR_{\mathfrak q}$ は素であり、$a/s$ がその外にある条件は $a\notin\mathfrak p$ である。このような $a/s$ は $R_{\mathfrak p}$ で $s/a$ を逆に持つので、写像は二段階の局所化に延長する。一方、二段階の標準写像は $a\notin\mathfrak p$ をすべて逆にするので $R_{\mathfrak p}$ を経由する。両合成は $R$ の元と、逆元にした元を固定するので恒等である。
:::

:::example[曲線を残す局所化と点を残す局所化]
$R=\Q[x,y]$ で $\mathfrak p=(x)$、$\mathfrak q=(x,y)$ とする。$R_{\mathfrak q}$ では定数項が非零な多項式が分母に使える。例えば $x+y+1$ は単元だが $y$ は極大イデアルに入り単元でない。$R_{\mathfrak p}$ では $x$ で割れない多項式が分母に使えるため、$y$ は単元になる。従って $x/y$ は後者には入るが前者には入らない。もし $x/y=a/b$ で $b(0,0)\ne0$ なら $xb=ya$ となり、$y=0$ を代入すると $x b(x,0)=0$ だから $b(x,0)=0$ で矛盾する。

$\mathfrak q$ での剰余体は $(0,0)$ での評価による $\Q$ である。一方 $\mathfrak p$ での剰余体では $x=0$ として $y$ の非零多項式をすべて分母に使えるため $\Q(y)$ となる。点の全座標を零にする操作と、$x$ だけを零にして残った変数を分数の係数にする操作では剰余体が異なる。
:::

:::example[一変数多項式を一点で局所化したときの全イデアル]
$A=\Q[x]_{(x-1)}$ とし、$u=x-1$ とする。非零な $f/g\in A$ について $g(1)\ne0$ であり、$f=u^m h$、$h(1)\ne0$ と一意な指数 $m\ge0$ を取れる。従って $f/g=u^m(h/g)$ で、$h/g$ は逆元 $g/h$ を持つ。別の表示と交差積を比較しても、分母は $u$ の因子を持たないため同じ指数になる。この指数は積で足し合わされる。

非零イデアル $J$ からこの指数が最小の元 $a$ を選び、その指数を $m$ とする。$a$ は $u^m$ と単元の積だから $u^m\in J$ である。他方、任意の非零元の指数は $m$ 以上なので全て $u^m$ の倍数である。従って $J=(u^m)$ であり、$A$ のイデアルはこれと零で尽くされる。例えば $(x^2-1)$ と $((x-1)(x+2)/(x+3))$ は $A$ では両方 $(u)$ となる。理由は $x+1,x+2,x+3$ の値が $x=1$ で全て非零だからである。$\Q[x]$ で異なる因子を持つ式でも、この局所環では $x-1$ 以外の因子は単元として取り除ける。
:::

## 分数環のイデアルと素イデアルの対応

### 何を拡大し、何が戻るか

:::definition[拡大と縮約]{#def-ring-extension-contraction}
$R\to T$ に対し、$I\subset R$ の像で生成される $T$ のイデアルを :term[拡大]{en="extension" yomi="かくだい"} $I^e$ といい、$J\subset T$ の逆像を :term[縮約]{en="contraction" yomi="しゅくやく"} $J^c$ という。局所化のとき $I^e=S^{-1}I$ とも書く。
:::

:::theorem[局所化とイデアル]{#thm-ring-local-ideals}
$S^{-1}I=\{a/s\mid a\in I,\ s\in S\}$ であり、局所化の全てのイデアルは $J=(J^c)^e$ を満たす。また
$$
(I^e)^c=\{a\in R\mid va\in I\text{ となる }v\in S\text{ がある}\}.
$$
拡大と縮約は $S$ と交わらない $R$ の素イデアルと、$S^{-1}R$ の全素イデアルの間の包含を保つ全単射を与える。
:::

:::proof
表示された分数の集合は分数演算でイデアルになり、$a/s=(a/1)(1/s)$ なので像で生成される。$a/s\in J$ なら $a/1=(s/1)(a/s)\in J$、逆に $a/1\in J$ なら $a/s\in J$ なので $J=(J^c)^e$ である。$a/1=b/s$ で $b\in I$ なら、ある $v$ で $vsa=vb\in I$ となる。逆に $va\in I$ なら $a/1=(va)/v$ である。

素イデアルの縮約は素であり、$S$ の像は単元なので $S$ と交わらない。$\mathfrak p\cap S=\varnothing$ なら $va\in\mathfrak p,\ v\in S$ から $a\in\mathfrak p$ となり、$(\mathfrak p^e)^c=\mathfrak p$ である。従って $\mathfrak p^e$ は真である。$(a/s)(b/t)\in\mathfrak p^e$ なら $ab/1\in\mathfrak p^e$ なので $ab\in\mathfrak p$ であり、$a/s,b/t$ の一方が $\mathfrak p^e$ に入る。従って拡大は素となる。以上の二つの合成の式と、拡大・縮約それぞれの単調性から従う。
:::

この対応で $S^{-1}R$ の極大イデアルを縮約すると、$S$ を避ける素イデアルの中の極大元が得られる。実際、全ての極大イデアルは素であり、真の素イデアルもある極大イデアルに含まれる。従って包含を保つ対応の両辺で極大元を選べばよい。ただし縮約が $R$ の極大イデアルになるとは限らない。例えば $\Z$ の全ての非零元を分母にすると体 $\Q$ になり、その極大イデアル $(0)$ の縮約は $\Z$ の $(0)$ である。これは $\Z$ では $(2)$ に真に含まれる。

$S$ と交わらない全ての素イデアルの和集合を $U$ とすると、$S$ の飽和は $R\setminus U$ である。$a\in R$ の像が単元にならないとき、その像を含む極大イデアルを $S^{-1}R$ で取れる。その縮約は $S$ と交わらない素イデアルであり、$a\in U$ となる。逆に $a\in U$ なら、その素イデアルを拡大した真のイデアルに像が属するため、単元ではない。そこで :ref[prop-ring-local-unit] を使うと等式が従う。

:::example[消える素イデアル]
$\Z[1/6]$ の素イデアルは、零イデアルと素数 $p\ne2,3$ で生成されるイデアルである。$2,3$ は $6$ を割るため単元になる。一方 $(30)\Z[1/6]=(5)\Z[1/6]$ であり、その縮約は $(30)$ ではなく $(5)$ である。
:::

:::proposition[剰余と局所化]{#prop-ring-local-quotient}
$\bar S$ を $R/I$ における $S$ の像とすると、$(S^{-1}R)/(S^{-1}I)\cong\bar S^{-1}(R/I)$ である。
:::

:::proof
普遍性により $a/s\mapsto\bar a/\bar s$ が準同型になり、全ての代表を持ち上げられるので全射である。零になる条件は $va\in I$ となる $v\in S$ の存在である。このとき $a/s=(va)/(vs)\in S^{-1}I$ であり、逆に $S^{-1}I$ の分子は $I$ に選べるから像が零になる。第一同型定理を適用する。
:::

:::proposition[局所化と根基・イデアル商]{#prop-ring-local-radical-colon}
任意のイデアル $I$ と積閉集合 $S$ に対し $S^{-1}\sqrt I=\sqrt{S^{-1}I}$ である。また $J$ が有限生成なら $S^{-1}(I:J)=(S^{-1}I:S^{-1}J)$ である。
:::

:::proof
$a/s\in S^{-1}\sqrt I$ なら分子を $\sqrt I$ から選んで冪を取ればよい。逆に $(a/s)^n\in S^{-1}I$ なら、分母を払って $va^n\in I$ となる $v\in S$ がある。すると $(va)^n=v^{n-1}(va^n)\in I$ なので、$a/s=(va)/(vs)$ の分子は $\sqrt I$ に選べる。イデアル商について、左辺の元が右辺に入ることは積の式による。逆に $a/s$ が右辺に属し $J=(b_1,\ldots,b_n)$ とすれば、各 $i$ に対し $ab_i/s\in S^{-1}I$ なので $v_iab_i\in I$ となる $v_i\in S$ がある。$v=\prod_i v_i$ とすると $vaJ\subseteq I$ であり、$a/s=(va)/(vs)$ は左辺にも属する。
:::

:::example[有限生成でないイデアルの商]
$A=\Q[x,y_1,y_2,\ldots]$、$S=\{x^j\mid j\ge0\}$ とし、$J=(y_1,y_2,\ldots)$、$I=(xy_1,x^2y_2,\ldots)$ とする。局所化後は $x$ が単元なので $S^{-1}I=S^{-1}J$ となり、そのイデアル商は環全体である。一方、$1$ が $S^{-1}(I:J)$ に属するには $x^k J\subseteq I$ となる $k\ge0$ が必要である。しかし $x^k y_{k+1}$ は、どの生成単項式 $x^iy_i$ でも割れないため $I$ に属さない。よってこの場合はイデアル商と局所化を交換できない。
:::

### 分母を選ばずに確かめる局所判定

:::proposition[イデアルの所属の局所判定]{#prop-ring-local-membership}
可換環 $R$ のイデアル $I$ について、$a\in I$ と、全ての極大イデアル $\mathfrak m$ で $a/1\in IR_{\mathfrak m}$ となることは同値である。
:::

:::proof
一方向は拡大の定義による。$a\notin I$ なら $(I:(a))=\{r\mid ra\in I\}$ は $1$ を含まないので、これを含む極大イデアル $\mathfrak m$ を取れる。$a/1\in IR_{\mathfrak m}$ なら拡大と縮約の式によりある $s\notin\mathfrak m$ が $sa\in I$ を満たす。これは $s\in(I:(a))\subseteq\mathfrak m$ に反する。
:::

:::example[素数ごとに指数を検査する]
$\Z$ で $I=(180)=(2^2\cdot3^2\cdot5)$ とする。局所化 $\Z_{(p)}$ で生成元は $p$ の指数だけを残し、$p=2,3,5$ でそれぞれ $4,9,5$ になる。他の素数では $180$ が単元となる。$a=90$ は $3$ と $5$ における条件は満たすが、$2$ における指数が $1$ なので $I$ に入らない。$a=540$ は $2,3,5$ における指数が $2,3,1$ なので全てを満たし、実際 $540=3\cdot180$ である。
:::

:::example[整数のイデアルを拡大して縮約する]
正整数 $n,d$ に対し、$\Z[1/n]$ へ $(d)$ を拡大してから $\Z$ に戻す。$n$ を割る各素数 $p$ は $n=p(n/p)$ により単元になる。従って $d$ からそれらの素冪を全て除いた $q$ が拡大イデアルの生成元になる。$n^ka\in(d)$ なら $q\mid n^ka$ であり、$\gcd(q,n)=1$ から $q\mid a$ である。$q\mid a$ なら、除いた因子が $n^k$ を割るように $k$ を大きく取れる。従って縮約も $(q)$ に等しい。

| 逆にする $n$ | 元の生成元 $d$ | 取り除く因子 $d/q$ | 縮約の生成元 $q$ |
| --- | --- | --- | --- |
| $6$ | $35$ | $1$ | $35$ |
| $12$ | $72$ | $72$ | $1$ |
| $30$ | $360$ | $360$ | $1$ |
| $14$ | $105$ | $7$ | $15$ |
| $8$ | $420$ | $4$ | $105$ |
| $9$ | $432$ | $27$ | $16$ |
| $10$ | $280$ | $40$ | $7$ |
| $7$ | $588$ | $49$ | $12$ |

$n=12,d=72$ では $2,3$ の双方を逆にするので $72$ が単元となる。これに対し $n=6,d=35$ では除く因子がなく、縮約すると元の $(35)$ に戻る。$n=14,d=105$ では $7$ だけを除いて $15$ が残る。$n=9,d=432$ では $n$ との最大公約数 $9$ を一回取り除いてもまだ $3$ が残るため、$3^3$ を除く必要がある。
:::

### 拡大で単元になる因子を除く

:::example[6 を逆にしたときのイデアル]
$S=\{6^k\mid k\ge0\}$、$R=\Z$ とする。整数 $2520$ の素因子のうち $6$ を割るものは、$6$ を逆にした後すべて単元になる。実際 $6=pc$ なら $p(c/6)=1$ である。反対に $6$ を割らない素数 $p$ は $p(a/6^k)=1$ を満たせない。交差積を取ると $p\mid 6^k$ に反するからである。拡大後に各生成元から取り除ける素因子は次の表の通りである。

| 素数 | 元の指数 | 局所化後に残る指数 |
| --- | --- | --- |
| $2$ | $3$ | $0$ |
| $3$ | $2$ | $0$ |
| $5$ | $1$ | $1$ |
| $7$ | $1$ | $1$ |

従って $S^{-1}(2520)=(35)$ である。縮約は $(35)\subseteq\Z$ である。実際整数 $r$ がこのイデアルに入るためには $6^k r$ が $35$ で割れればよい。ここで $\gcd(6,35)=1$ なので、これは $r$ が直接 $35$ で割れることと同値である。さらに剰余を取ると $S^{-1}\Z/(35)\cong\Z/(35)$ である。$6$ は法 $35$ で逆元をもつので、剰余写像を分数に延長したとき全射性が保たれ、核はこのイデアルになる。
:::

| 素数 | 元の指数 | 局所化後に残る指数 |
| --- | --- | --- |
| $2$ | $2$ | $0$ |
| $3$ | $2$ | $2$ |
| $5$ | $1$ | $1$ |
| $7$ | $2$ | $0$ |

従って $S^{-1}(8820)=(45)$ である。縮約は $(45)\subseteq\Z$ である。実際整数 $r$ がこのイデアルに入るためには $14^k r$ が $45$ で割れればよい。ここで $\gcd(14,45)=1$ なので、これは $r$ が直接 $45$ で割れることと同値である。さらに剰余を取ると $S^{-1}\Z/(45)\cong\Z/(45)$ である。$14$ は法 $45$ で逆元をもつので、剰余写像を分数に延長したとき全射性が保たれ、核はこのイデアルになる。
:::

:::proposition[イデアルの等しさの局所判定]{#prop-ring-ideals-local-test}
可換環 $R$ のイデアル $I,J$ に対し、全ての極大イデアル $\mathfrak m$ で $I_{\mathfrak m}=J_{\mathfrak m}$ なら $I=J$ である。
:::

:::proof
$a\in I\setminus J$ があれば $(J:(a))$ は $1$ を含まないので、ある極大イデアル $\mathfrak m$ に含まれる。$a/1\in I_{\mathfrak m}=J_{\mathfrak m}$ だから、$s\notin\mathfrak m$ で $sa\in J$ となる $s$ がある。ところが $s\in(J:(a))\subseteq\mathfrak m$ であり矛盾する。逆の包含も $I,J$ を入れ替えて従う。
:::

:::example[単項イデアルの指数を局所的に比較する]
$\Z$ の $(84)$ と $(126)$ を比較する。$84=2^2\cdot3\cdot7$、$126=2\cdot3^2\cdot7$ である。$7$ で局所化すると両者は同じ $(7)$ になるが、$2$ で局所化すると $(4)$ と $(2)$、$3$ では $(3)$ と $(9)$ になり、異なる。例えば $2$ は $\Z_{(2)}$ で $4$ の倍数でない。なぜなら $2=4(a/b)$（$b$ 奇数）なら $b=2a$ となるからである。互いに逆方向の不一致が二つの点で起こるため、元の二つのイデアルはどちらも他方を含まない。
:::

### 縮約の結果を元の環だけで記述する

:::proposition[局所化と有限交叉]{#prop-ring-local-intersections}
有限個のイデアル $I_1,\ldots,I_m$ に対し $S^{-1}(\bigcap_i I_i)=\bigcap_i S^{-1}I_i$ である。さらに $(S^{-1}I)^c=\bigcup_{s\in S}(I:(s))$ であり、$S=\{f^n\mid n\ge0\}$ ならこれは $(I:(f^n))$ の昇鎖の合併である。
:::

:::proof
第一式の一方の包含は明らかである。右辺の $a/t$ を取ると、各 $i$ に対して $s_i\in S$ があり $s_i a\in I_i$ となる。全てを掛けた $s$ を取れば $sa$ は同時に全イデアルに入り、$a/t=(sa)/(st)$ だから左辺に属する。縮約の式は $a/1\in S^{-1}I$ とある $s$ で $sa\in I$ になることが同値であることをそのまま書いたものである。$s=f^n$ の場合、$f^n a\in I$ ならさらに $f$ を掛けても $I$ に入るため昇鎖になる。
:::

:::example[無限交叉には同時に使える分母がない]
$\Z$ で $S=\{2^j\mid j\ge0\}$ とし、$I_i=(2^i)$ を $i\ge1$ について取る。各イデアルの局所化は $2^i$ が単元になるため環全体である。一方、全ての $2^i$ で割れる整数は零だけだから、交叉の局所化は零である。例えば各段で $1$ が拡大イデアルに入ることを示すには、その段の $2^i$ を分子に掛ければよい。しかし全段に通用する単一の $2^j$ は存在しない。このため有限個での共通分母の証明は、無限個の交叉にはそのまま延長しない。
:::

:::example[15 を逆にしたときのイデアル]
$S=\{15^k\mid k\ge0\}$、$R=\Z$ とする。整数 $2100$ の素因子のうち $15$ を割るものは、$15$ を逆にした後すべて単元になる。実際 $15=pc$ なら $p(c/15)=1$ である。反対に $15$ を割らない素数 $p$ は $p(a/15^k)=1$ を満たせない。交差積を取ると $p\mid 15^k$ に反するからである。拡大後に各生成元から取り除ける素因子は次の表の通りである。

| 素数 | 元の指数 | 局所化後に残る指数 |
| --- | --- | --- |
| $2$ | $2$ | $2$ |
| $3$ | $1$ | $0$ |
| $5$ | $2$ | $0$ |
| $7$ | $1$ | $1$ |

従って $S^{-1}(2100)=(28)$ である。縮約は $(28)\subseteq\Z$ である。実際整数 $r$ がこのイデアルに入るためには $15^k r$ が $28$ で割れればよい。ここで $\gcd(15,28)=1$ なので、これは $r$ が直接 $28$ で割れることと同値である。さらに剰余を取ると $S^{-1}\Z/(28)\cong\Z/(28)$ である。$15$ は法 $28$ で逆元をもつので、剰余写像を分数に延長したとき全射性が保たれ、核はこのイデアルになる。
:::

## 演習問題

::::exercise{level=basic}
$\Z[1/5]$ で $7/25-2/5$ を計算し、結果が単元か判定せよ。

:::solution
共通分母を使うと $7/25-10/25=-3/25$ である。$(-3)b$ は $5$ の冪にならないので、:ref[prop-ring-local-unit] により非単元である。
:::
::::

::::exercise{level=basic}
$\Q[x]$ の分数体で $(x^3-1)/(x^2-1)$ を約分せよ。

:::solution
分子は $(x-1)(x^2+x+1)$、分母は $(x-1)(x+1)$ である。共通の非零因子を消せることは交差積の等式から従い、結果は $(x^2+x+1)/(x+1)$ である。分子を $x=-1$ で評価すると $1$ なので $x+1$ はこれ以上消せない。
:::
::::

::::exercise{level=basic}
$\Z_{(7)}$ で $3/5$ の剰余体への像を求めよ。

:::solution
剰余体は $\F_7$ である。$5\cdot3\equiv1\pmod7$ なので $[3][5]^{-1}=[9]=[2]$ となる。
:::
::::

::::exercise{level=basic}
$S=\{2^j\mid j\ge0\}$ とする。$\Z$ の $(84)$ を $S^{-1}\Z$ に拡大して縮約せよ。

:::solution
$84=4\cdot21$ で $4$ は局所化で単元だから拡大は $(21)S^{-1}\Z$ である。$84\mid 2^j a$ なら互いに素な $21$ は $a$ を割る。逆に $21\mid a$ なら $84\mid4a$ なので縮約は $(21)$ である。
:::
::::

::::exercise{level=advanced}
$e^2=e$ である $e\in R$ に対し、$S=\{1,e\}$ による局所化を剰余環として表せ。

:::solution
$e$ が単元になれば $e^2=e$ の両辺に逆元を掛けて $e=1$ である。従って $(1-e)/1=0$ となり、どの分数も分母 $1$ にできる。$\lambda$ の核に属する $a$ は $a=0$ または $ea=0$ を満たす。後者なら $a=(1-e)a$、逆に $e(1-e)=0$ なので核は $(1-e)$ である。よって $S^{-1}R\cong R/(1-e)$ である。
:::
::::

::::exercise{level=advanced}
$S,T$ を可換環 $R$ の積閉集合とし、$ST=\{st\mid s\in S,t\in T\}$ とする。$S$、次に $T$ の像で局所化する結果と $(ST)^{-1}R$ が同型であることを示せ。

:::solution
$S,T$ の像を両方単元にする写像は $ST$ の像も単元にする。逆に $1\in S,T$ なので $S,T\subseteq ST$ である。この性質をもつ任意の写像は、普遍性により二段階でも、一回で $(ST)^{-1}R$ を通じても一意に分解する。双方の標準写像に相手の普遍性を適用して得る二つの準同型の合成は、$R$ からの標準写像との合成を変えず、一意性でそれぞれ恒等となる。
:::
::::

::::exercise{level=advanced}
可換環 $R$ の元 $a$ が、全ての極大イデアル $\mathfrak m$ に対し $R_{\mathfrak m}$ で零になるなら $a=0$ を示せ。

:::solution
$a\ne0$ と仮定すると $\{r\mid ra=0\}$ は $1$ を含まないイデアルである。これを含む極大イデアル $\mathfrak m$ を取る。$a/1=0$ ならある $s\notin\mathfrak m$ について $sa=0$ となるが、これは $s$ がこのイデアルに属することに反する。
:::
::::

::::exercise{level=advanced}
$S=\{(xy)^n\mid n\ge0\}$、$R=\Q[x,y]$ とする。$S^{-1}R$ は $x,y$ を個別に逆にした環と同型であることを示せ。

:::solution
$xy$ が単元なら $x$ の逆元は $y(xy)^{-1}$、$y$ の逆元は $x(xy)^{-1}$ である。逆に $x,y$ が単元なら $xy$ が単元である。従って両環は $x,y$ の像が単元になる準同型を一意に分解する同じ普遍性をもつ。また $x^{-i}y^{-j}$ は $N=\max(i,j)$ として $x^{N-i}y^{N-j}/(xy)^N$ と書けるので、具体的表示も一致する。
:::
::::

::::exercise{level=advanced}
$R=\Z/(180)$ で $[12]$ を逆にした環と、$R$ からの自然な写像の核を求めよ。
:::solution
$180=2^2\cdot3^2\cdot5$ であり、$12$ は法 $5$ で単元、法 $36$ で冪零である。法 $5$ への還元は局所化へ一意に延長でき、全射である。法 $5$ で像が零とは分子が $5$ の倍数であることに等しい。$[12]^2$ をその分子に掛けると法 $180$ で零になるため、この分数は局所化で零である。よって局所化は $\Z/(5)$ で、元の写像の核は $([5])$ である。
:::
::::

## 確認テスト

::::quiz
$S^{-1}R$ の分数 $a/s$ が零になる必要十分条件はどれか。

- [ ] $a=0$。
- [x] ある $v\in S$ が $va=0$ を満たす。
- [ ] $sa=0$。

:::explanation
零分数 $0/1$ との同値条件は $v(a\cdot1-0\cdot s)=0$ である。分子が零なら成り立つが必要ではない。例えば $\Z/(6)$ で $2$ の冪を逆にすると、$3/1=0$ になる一方 $1\cdot3\ne0$ である。
:::
::::

::::quiz{answer="3" tol="1e-9"}
$\Z_{(5)}$ で $4/3$ の剰余体への像を $0$ から $4$ の代表で答えよ。

:::explanation
$\F_5$ で $3^{-1}=2$ であるから $4\cdot2\equiv3\pmod5$ である。
:::
::::

::::quiz
$\Z[1/10]$ で拡大すると環全体になる素イデアルを選べ。

- [x] $(2)$
- [ ] $(3)$
- [x] $(5)$
- [ ] $(0)$

:::explanation
$(2)$ と $(5)$ は積閉集合 $\{10^n\}$ と交わるため拡大に単元が入る。$(3)$ と $(0)$ は交わらず、局所化の素イデアル対応により真の素イデアルに移る。
:::
::::

::::quiz{answer="7" tol="1e-9"}
$\Z[1/3]$ への拡大後に縮約した $(63)$ の正の生成元を答えよ。

:::explanation
$63=9\cdot7$ なので $3$ の冪を逆にすると生成元は $7$ でよい。$7$ は $3$ と互いに素なので、$7\mid3^j a$ なら $7\mid a$ となり、縮約も $(7)$ である。
:::
::::

::::quiz{answer="4" tol="1e-9"}
$\Z_{(7)}$ の $11/8$ の剰余体への像を $0$ 以上 $6$ 以下の整数で表せ。
:::explanation
分母 $8$ は法 $7$ で $1$ になり、その逆元も $1$ である。分子 $11$ は法 $7$ で $4$ なので、分数の像は $4\cdot1=4$ である。
:::
