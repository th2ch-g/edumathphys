## この章の目標

- Artin 条件と Noether 条件を判定し、短完全列で調べる。
- 組成列を構成し、Jordan–Hölder の定理と長さの加法性を証明する。
- Fitting の補題で自己準同型の可逆な部分と冪零な部分を分ける。
- Krull–Schmidt の定理で直既約因子を同定する。

## Artin 加群と Noether 加群

### 昇鎖と降鎖が有限回で止まるか

:::definition[Artin 加群と Noether 加群]{#def-ring-chain-modules}
部分加群の任意の降鎖が停留するとき :term[Artin 加群]{en="Artinian module" yomi="あるてぃんかぐん"}、任意の昇鎖が停留するとき :term[Noether 加群]{en="Noetherian module" yomi="ねーたーかぐん"} と呼ぶ。
:::

昇鎖条件は非空の部分加群族に極大元があることと同値である。極大元がなければ真に増える鎖を繰り返し選べる。逆に鎖の元の族の極大元以後は変化しない。降鎖条件は同じ議論で極小元の存在と同値である。さらに Noether 条件は全ての部分加群の有限生成性と同値である。有限生成なら昇鎖の合併の生成系は一段に収まり、逆に有限生成でない部分加群では有限個の元で張った加群に外の元を毎回足して真の昇鎖を作れる。

:::proposition[短完全列での鎖条件]{#prop-ring-module-chain-extension}
短完全列 $0\to A\to B\to C\to0$ で、$B$ の Noether 性は $A,C$ の Noether 性と同値であり、Artin 性についても同様である。
:::

:::proof
$A$ を $B$ の部分加群、$C$ を剰余とみなす。$A$ の鎖はそのまま $B$ の鎖であり、$C$ の鎖は逆像で $B$ の鎖になるため、$B$ から双方への保存性が従う。逆に $B$ の鎖 $B_i$ について $A\cap B_i$ と $C$ における像はそれぞれ同じ向きの鎖であり、やがて停留する。包含 $U\subseteq V$ でこの共通部分と像が等しいなら $U=V$ である。実際 $v\in V$ に対し像の一致で $u\in U$ を同じ像にでき、$v-u\in A\cap V=A\cap U$ なので $v\in U$ である。これを鎖の隣り合う項に適用する。
:::

:::example[片方の条件だけが成立する場合]
$\Z$ はイデアルが全て単項なので Noether 加群である。ただし $\Z\supsetneq2\Z\supsetneq4\Z\supsetneq\cdots$ により Artin 加群ではない。一方、素数 $p$ に対する $\Z[1/p]/\Z$ の各元は位数が $p^j$ の巡回部分群を生成し、その部分群は $[1/p^j]$ が生成する部分群に一致する。分子が $p$ と互いに素なので法 $p^j$ で逆が取れるためである。位数が無制限に現れる部分群は全体に等しく、有界な場合は最大の位数をもつ元の巡回部分群に等しい。従って真に減る鎖は一度真の部分群に入れば有限群の中で止まる。一方 $[1/p^j]$ の巡回群を $j$ 順に並べれば昇鎖が止まらない。
:::

:::example[有限直和と無限直和の鎖を比較する]
$K^n$ では真の包含で部分空間の次元が少なくとも一つ変わるので、昇鎖も降鎖も高々 $n$ 回しか真に変化しない。対して可算無限の自由加群 $K^{(\N)}$ では、最初の $j$ 個の基底が張る空間が真の昇鎖を与える。さらに第 $j$ 番目以後の基底が張る空間は真の降鎖を与える。双方の鎖が無限に続くのは、直和の各成分が単純でも全体に無限個の座標があるからである。有限直和での短完全列の議論を無限個に繰り返しても、鎖が止まるとは結論できない。
:::

### 鎖条件を満たす方向を区別する

:::proposition[昇鎖条件と有限生成部分加群]{#prop-ring-noetherian-submodule-fg}
加群 $M$ が Noether 加群であることと、全ての部分加群が有限生成であることは同値である。
:::

:::proof
Noether 加群なら部分加群 $N$ の有限生成部分加群全体は極大元 $L$ を持つ。無ければ真に大きい元を選び続けて停留しない昇鎖になる。$N\ne L$ なら $a\in N\setminus L$ を加えた $L+Ra$ は有限生成で、極大性に反する。逆に全ての部分加群が有限生成なら、部分加群の昇鎖の合併も有限生成である。その全ての生成元が有限個なので同時にある段階に入り、以後はその合併と等しい。
:::

:::corollary[左 Noether 環上の有限生成加群]{#cor-ring-fg-over-left-noetherian}
環 $R$ の左正則加群が Noether 加群なら、有限生成の左 $R$ 加群 $M$ も Noether 加群である。特に $M$ の任意の部分加群は有限生成である。
:::

:::proof
$R^n$ は $R$ の有限直和なので :ref[prop-ring-module-chain-extension] を繰り返すと Noether 加群である。有限生成系から全射 $R^n\to M$ を取り、同じ命題をこの剰余に適用する。部分加群の有限生成性は :ref[prop-ring-noetherian-submodule-fg] から従う。
:::

:::example[整数加群は上へは止まり下へは止まらない]
$\Z$ の非零部分加群は $n\Z$ である。正の元のうち最小のもの $n$ を取れば、剰余をとった余りが部分加群に入るので、全ての元が $n$ の倍数であると分かる。昇鎖では非零になった後に $n$ が真に減るたびにしか増大できないので、有限回で止まる。一方 $\Z\supsetneq2\Z\supsetneq4\Z\supsetneq\cdots$ は各段の生成元が次の段に入らないため厳密な降鎖である。このため $\Z$ は Noether だが Artin ではない。
:::

:::example[Prüfer 群は下へは止まり上へは止まらない]
素数 $p$ に対し $E=\Z[1/p]/\Z$ とする。位数がちょうど $p^j$ の元 $[a/p^j]$ は分子が $p$ と互いに素なので、$[1/p^j]$ と同じ部分群 $E_j$ を生成する。従ってある部分群の元の位数が有界なら、最大の位数の元を取ればその部分群は $E_j$ である。位数が有界でなければ、任意の $j$ について $E_j$ を含むため全体である。従って真の部分群は全て有限で、降鎖は最初に真に降りた段階から有限回で止まる。一方 $E_1\subsetneq E_2\subsetneq\cdots$ は停留しない。よって $E$ は Artin だが Noether ではない。
:::

:::example[同じ空間でも作用を変えると鎖が変わる]
$\Q[x]$ を $\Q$ 加群と見れば、$K\cdot1\subset K\cdot1+K\cdot x\subset\cdots$（$K=\Q$）は増大する部分加群の鎖である。この鎖の各段は $x$ を掛けると外に出る。従って $\Q[x]$ 加群としての鎖ではない。自己への乗法による $\Q[x]$ 加群としては、部分加群はイデアルで、一変数の除法により単項であるから Noether である。それでも $(x^j)$ は真の降鎖になるので Artin ではない。鎖条件の判定には、部分集合がどの係数の作用で閉じるべきかを先に指定する。
:::

### 循環部分と拡大を通して鎖条件を調べる

:::example[部分加群の有限生成性が壊れる環を作る]
$K$ を体とし、$R=K\oplus V$、$V=\bigoplus_{i\ge1}Ke_i$ とする。積を $(a,v)(b,w)=(ab,aw+bv)$ で定める。三元の積はどちらの順でも定数部が $abc$、$V$ 成分が $abz+acw+bcv$ になるので結合的である。単位元は $(1,0)$ であり、分配法則は成分の線形性で成り立つ。$V$ は積が零のイデアルで、任意の $r=(a,v)$ による $V$ への作用は $a$ 倍である。従って正則加群 $R$ は $1$ で生成されるが、部分加群 $V$ は有限生成でない。どの有限個の元も台が有限で、その外の $e_i$ が生成できないからである。

$V_n=Ke_1+\cdots+Ke_n$ は厳密な昇鎖を与える。他方 $W_n=\bigoplus_{i\ge n}Ke_i$ は厳密な降鎖になる。$R/V\cong K$ は一次元で両鎖条件を満たすが、$V$ がどちらの鎖条件も満たさないので $R$ にはそれらの条件が伝わらない。有限生成な加群の部分加群が有限生成だと結論するには環側の Noether 性が必要である。
:::

## 組成列と Jordan–Hölder の定理

### 間に部分加群を挟めないところまで細分する

:::definition[単純加群と組成列]{#def-ring-composition-series}
$0$ でなく、部分加群が $0$ と自分自身だけの加群を :term[単純加群]{en="simple module" yomi="たんじゅんかぐん"} という。有限列 $0=M_0\subsetneq M_1\subsetneq\cdots\subsetneq M_r=M$ で各 $M_i/M_{i-1}$ が単純なら :term[組成列]{en="composition series" yomi="そせいれつ"} と呼び、商を組成因子と呼ぶ。零加群には空の因子列を認める。
:::

:::proposition[組成列の存在条件]{#prop-ring-composition-existence}
$M$ が組成列をもつことと $M$ が Artin かつ Noether であることは同値である。
:::

:::proof
単純加群の部分加群の鎖は二段階だけなので両条件を満たす。組成列の短完全列に :ref[prop-ring-module-chain-extension] を順に適用すれば $M$ も両条件を満たす。逆に $M\ne0$ なら Noether 性により真の部分加群に極大元 $N$ がある。剰余 $M/N$ の部分加群の対応により単純である。$N$ が非零なら同じ操作を $N$ に対して繰り返す。Artin 性で真の降鎖は有限回で止まるため、零までの列が得られる。
:::

:::lemma[鎖の長さの上限]{#lem-ring-length-bound}
$M$ に長さ $r$ の組成列があれば、$M$ の部分加群の真の有限鎖の段数は $r$ 以下である。
:::

:::proof
$r=0$ は明らかである。最後の直前の項を $N$ とする。任意の有限昇鎖の各真の包含では $N$ との共通部分か $M/N$ への像の少なくとも一方が真に増える。両者が同時に変化しないなら :ref[prop-ring-module-chain-extension] の証明で元の二項も一致するからである。共通部分側は帰納法で高々 $r-1$ 回、単純商への像は高々 $1$ 回しか増えない。従って段数は $r$ 以下である。
:::

:::theorem[Jordan–Hölder の定理]{#thm-ring-jordan-holder}
同じ加群の任意の二つの組成列は同じ長さをもち、因子の同型類は順序を除いて重複も含めて一致する。
:::

:::proof
長さの上限を双方の列について比較すると長さは一致する。この長さ $r$ で帰納する。$r=0$ では両列とも因子がない。$r\ge1$ として直前の極大部分加群を $A,B$ とする。$A=B$ なら帰納法を $A$ に適用し、最後の因子も同じである。$A\ne B$ なら極大性により $A+B=M$ である。$D=A\cap B$ とすると同型定理で $A/D\cong M/B$、$B/D\cong M/A$ となる。$D$ は両鎖条件を継ぐので組成列をもつ。この列に $A$ を足したものは $A$ の組成列であり、$B$ を足したものは $B$ の組成列である。$A,B$ の鎖の長さは $r$ 未満なので帰納法で元の二列の直前までをこれらに置き換えられる。すると残る因子は同じ $D$ の因子と $M/A,M/B$ であり、最後の二因子の順序だけが変わる。
:::

:::example[順序は変わるが因子は同じ]
$\Z/(12)$ で $0\subset(6)/(12)\subset(3)/(12)\subset\Z/(12)$ の商の位数は $2,2,3$ である。一方 $0\subset(4)/(12)\subset(2)/(12)\subset\Z/(12)$ の商の位数は $3,2,2$ である。どれも素数位数の巡回群なので単純であり、異なる組成列が同じ三つの因子を与える。
:::

### 一般の有限鎖を同じ因子まで細かくする

:::lemma[Zassenhaus の補題]{#lem-ring-butterfly}
同じ加群の部分加群 $A'\subseteq A$、$B'\subseteq B$ について
$$
\frac{A'+(A\cap B)}{A'+(A\cap B')}
\cong
\frac{B'+(A\cap B)}{B'+(A'\cap B)}
$$
が成り立つ。
:::

:::proof
$H=A\cap B$ と置く。左の商への $H$ からの写像は全射であり、核は $(A'\cap B)+(A\cap B')$ である。実際 $h=a'+z$ と書ける $h\in H$、$a'\in A'$、$z\in A\cap B'$ では $h,z\in B$ なので $a'\in B$ である。逆の包含も直接従う。右の商への $H$ からの写像は同様に全射で、$h=b'+w$ と書いた $w\in A'\cap B$ に対して $h,w\in A$ なので $b'\in A\cap B'$ となり、同じ核をもつ。第一同型定理を双方に適用する。
:::

:::proposition[Schreier の細分定理]{#prop-ring-schreier}
同じ加群を両端とする二つの有限列 $0=A_0\subseteq\cdots\subseteq A_r=M$ と $0=B_0\subseteq\cdots\subseteq B_s=M$ は、因子が順不同で同型になる細分をもつ。
:::

:::proof
$A_i$ と $A_{i+1}$ の間に $A_i+(A_{i+1}\cap B_j)$ を $j=0,\ldots,s$ の順で入れる。同様に $B_j$ と $B_{j+1}$ の間には $B_j+(A_i\cap B_{j+1})$ を $i=0,\ldots,r$ の順で入れる。どちらも包含の列で端点が元の項に一致する。補題を $A'=A_i,A=A_{i+1},B'=B_j,B=B_{j+1}$ に適用すると、二つの細分で位置 $(i,j)$ の因子が同型になる。重複する項は零因子を与え、対応する零因子を双方から削除できる。元が組成列なら単純商の中に真の中間項を挿入できないので、細分には元の因子だけが残る。
:::

:::example[二つの因子を交換する]
$M=\Z/(6)$ で $A=\langle[2]\rangle$、$B=\langle[3]\rangle$ とする。和は $[3]-[2]=[1]$ を含むので $M$ であり、位数 $3$ と $2$ の群の交わりは零である。補題の上側の二項と下側の二項をそれぞれ $(M,A)$ と $(B,0)$ にすると $M/A\cong B$ を得る。反対側も同じく $M/B\cong A$ である。二つの組成列は長さ $2$ で、最初の群と最後の商の型を交換する。
:::

### 異なる順序で素数の因子を取り出す

:::example[法 72 の群で組成列を作る]
$M=\Z/(72)$ の部分群を $M_d=([d])$ と書く。ただし $d$ は $72$ の正の約数とする。この群は $d$ の倍数類からなり、位数は $72/d$ である。$d\mid e$ なら $M_e\subseteq M_d$ であり、$M_d/M_e$ は $[d]$ の類が生成する巡回群である。この生成元の位数は $e/d$ である。なぜなら $j[d]$ が $M_e$ に入る条件は $e\mid jd$ だからである。

| --- | --- | --- | --- | --- | --- |
| $1$ | $1$ | $2$ | $72$ | $36$ | $2$ |
| $2$ | $2$ | $4$ | $36$ | $18$ | $2$ |

:::

各段で比 $e/d$ が素数であり、商には真の非零部分群がない。従ってこの下降列を逆に読んだものは組成列である。$d=1$ で全体、$d=105$ で零となる。長さは $3$ であるが、素数を並べる順を変えると中間部分群を変えられる。この例では位数が各段で素数倍ずつ変わるため、商の型の集まりは素因数の重複度と一致する。
:::

:::example[同じ単純因子があっても拡大は異なる]
$\Z/(4)$ の唯一の非零真部分群は $([2])$ で、その部分群と商はともに $\Z/(2)$ である。一方 $(\Z/(2))^2$ は第一座標の部分群を取れば、同じ二つの商を持つ組成列になる。ところが $\Z/(4)$ では位数 $4$ の元があり、後者は全ての元が $2$ 倍で零になる。従って二加群は同型でない。Jordan–Hölder の定理で固定されるのは組成因子の多重集合であり、中央の加群での持ち上げがどのように接続されるかは別の情報になる。
:::

### 細分の各項を行と列で比較する

:::example[互いに異なる中間項から同じ二因子を得る]
$K=\Q$、$M=K^3$ とする。$A_1=Ke_1$、$A_2=Ke_1+Ke_2$、$B_1=Ke_2$、$B_2=Ke_2+Ke_3$ とし、両列の下端を零、上端を $M$ とする。$A_1\cap B_2=0$、$A_2\cap B_1=Ke_2$、$A_2\cap B_2=Ke_2$ である。従って $A_1$ から $A_2$ の間で細分したとき、$B_1$ を使った項 $A_1+(A_2\cap B_1)$ がすでに $A_2$ になる。同様に、$B_1$ から $B_2$ の間では $A_2$ を使った項も $B_1$ のままであり、$A_3=M$ を使った段だけが増える。

| 上下の段 | 最初の列を細分したときに増える段 | 商の基底の代表 |
| --- | --- | --- |
| $0\subset A_1$ | $B_2\subset B_3$ | $e_1$ |
| $A_1\subset A_2$ | $0\subset B_1$ | $e_2$ |
| $A_2\subset M$ | $B_1\subset B_2$ | $e_3$ |

最後の行では $M\cap B_2=B_2$ により $A_2+B_2=M$ である。表を第二列の順に読めば、もう一方の列の細分での因子に対応する。各因子の体上の次元は $1$ なので今回は同型類が同じだが、どの段の商を対応させたかは交叉と和で明示できる。
:::

:::example[途中の商を素数冪まで細分する]
$M=\Z/(24)$ で $A=([4])$、$B=([6])$ とする。$A\cap B=([12])$ は位数 $2$、$A+B=([2])$ は位数 $12$ である。第一の列 $0\subset A\subset M$ では、最初の区間に $A\cap B$、第二の区間に $A+B$ を挿入する。段ごとの位数は $1,2,6,12,24$ だから商の位数は $2,3,2,2$ である。第二の列 $0\subset B\subset M$ に同じ二項を挿入すると $1,2,4,12,24$ となり、商は $2,2,3,2$ の順になる。この対応では中間の $A/(A\cap B)$ が $(A+B)/B$ に、$B/(A\cap B)$ が $(A+B)/A$ に同型になる。例えば $A$ の $[4]$ は前者の両方で位数 $3$ の生成元になる。単に位数を並べるだけでなく、具体的な元がどこへ移るかを同型定理で復元できる。
:::

## 加群の長さ

### 短完全列の両端を足す

:::definition[長さ]{#def-ring-module-length}
組成列をもつ加群を :term[有限長加群]{en="module of finite length" yomi="ゆうげんちょうかぐん"} といい、組成因子の個数を長さ $\ell_R(M)$ と呼ぶ。
:::

:::theorem[長さの加法性]{#thm-ring-length-additive}
短完全列 $0\to A\to B\to C\to0$ で $B$ が有限長であることと $A,C$ が有限長であることは同値であり、その際 $\ell_R(B)=\ell_R(A)+\ell_R(C)$ である。
:::

:::proof
有限長と両鎖条件の同値および短完全列での鎖条件から最初の主張を得る。$A$ の組成列の後に、$C$ の組成列の各項の $B$ への逆像を付ける。逆像の隣接商は $C$ の対応する商に同型である。実際上の項を対応する商に送る写像は全射であり、核は直前の逆像である。従って得られた列は $B$ の組成列で、数を足せばよい。
:::

:::example[同じ群でも係数で長さが変わる]
$\C$ は $\C$ 上では一次元なので長さ $1$、$\R$ 上では $0\subset\R\subset\C$ の長さ $2$ である。一般に体上の有限次元ベクトル空間の単純商はちょうど一次元である。非零元を一つ取ってその張る空間を考えれば、単純なら全体に等しいためである。従って体上の長さは次元に等しい。
:::

有限長加群の自己準同型は単射なら全射、全射なら単射である。核と像の短完全列で長さを足すと一方から他方が従う。例えば有限次元行列の階数と核の次元の関係はこの式の特別な場合である。

:::example[有限巡回群の長さと位数は違う量である]
$\Z/(180)$ の組成列として、整数のイデアルの像 $(180)\subset(90)\subset(45)\subset(15)\subset(5)\subset(1)$ を取る。各商の位数は $2,2,3,3,5$ なので単純であり、長さは $5$ である。$(15)/(180)$ の部分群は位数 $12$ で長さ $3$、この部分群による剰余は $\Z/(15)$ なので長さ $2$ である。全体の位数は $12\cdot15=180$ と乗法的であるが、長さは $3+2=5$ と加法的である。
:::

:::proposition[PID 上の長さと素因数の指数]{#prop-ring-pid-module-length}
PID $R$ の有限生成加群が有限長となるのは、$R$ が体であるか、加群の自由階数が零である場合に限る。ねじれ部分の長さは、初等因子 $p^e$ の指数 $e$ を重複も含めて足した値である。
:::

:::proof
:ref[thm-ring-pid-structure] により、加群は自由部分と素冪を法とする巡回商の直和に分かれる。$R/(p^e)$ では $(p^j)/(p^e)$（$0\le j\le e$）が降鎖をなし、隣接商は $p^j$ 倍で $R/(p)$ と同型になる。$R/(p)$ は体なので、この商は単純 $R$ 加群である。従って各巡回商の長さは $e$ で、直和の長さは加法性から総和になる。$R$ が体なら、自由部分の長さはその次元である。$R$ が体でなければ、非零非単元 $a$ に対し $R\supsetneq aR\supsetneq a^2R\supsetneq\cdots$ が厳密な降鎖である。等号が一度でも成り立てば整域で約分して $a$ が単元になるためである。自由階数が正なら、この降鎖が自由直和因子内で現れ、有限長にならない。
:::

:::example[係数体での次元と多項式環上での長さ]
$\Q[x]$ 加群 $M=\Q[x]/((x^2+1)^2)\oplus\Q[x]/(x-2)$ を考える。第一の法には既約な二次式が二回、第二の法には一次式が一回現れるため、長さは $2+1=3$ である。一方 $\Q$ に係数を制限すると、除法によって一次元ずつの数え方が変わり、次元は $4+1=5$ となる。差の二は、第一の単純因子 $\Q[x]/(x^2+1)$ がそれぞれ $\Q$ 上二次元あることから生じる。
:::

:::proposition[有限長加群の自己準同型と長さ]{#prop-ring-length-endo}

:::

:::proof
$0\to\Ker f\to M\to\Img f\to0$ と $0\to\Img f\to M\to\operatorname{coker}f\to0$ に長さの加法性を適用する。両方が同じ $\ell(M)$ を与えるため $\ell(\Img f)$ を引いて等式を得る。長さ零の加群は零加群に限るので、単射と全射の同値性が従う。
:::

### 部分加群の和と交わりで長さを計算する

:::proposition[長さの二部分加群公式]{#prop-ring-length-modular}
有限長加群 $M$ の部分加群 $A,B$ に対し $\ell(A+B)+\ell(A\cap B)=\ell(A)+\ell(B)$ である。さらに $A\subset B$ で $\ell(A)=\ell(B)$ なら $A=B$ である。
:::

:::proof
$A/(A\cap B)\to (A+B)/B$ は、$A$ を包含し商へ送った写像から得られる同型である。全射性は $a+b$ の剰余を $a$ で代表できること、核の記述は $A$ の中で $B$ に属することから従う。二つの商の長さを加法性で書き直して等式を得る。最後の主張は $B/A$ の長さが零なら加群が零であることから従う。
:::

:::example[長さだけでは同じ部分加群か分からない]
$M=\Z/(12)\oplus\Z/(4)$ において $A=\langle([3],[0])\rangle$、$B=\langle([3],[2])\rangle$ とする。どちらの生成元も位数 $4$ なので長さは $2$ である。しかし第二成分から $A$ と $B$ は異なる。$B$ の元で第二成分が零であるには生成元を偶数倍する必要がある。従って交わりは $([6],[0])$ の生成する位数 $2$ の群である。和では $B$ の生成元から $A$ の生成元を引いた $(0,[2])$ が得られ、これと $A$ の直和になる。従って和の長さは $2+1=3$ であり、交叉を加えると $4$ で両者の長さの和に一致する。長さが等しいだけで等号を結論するには包含関係が別に要る。
:::

:::example[長さの加法性を素数ごとに調べる]
$B=\Z/(216)$ で $A=([18])$ とする。この部分群は $18$ の倍数類で、位数は $12$ である。$[r]\mapsto[18r]$ が $\Z/(12)\cong A$ を与える。商 $C=B/A$ は法 $18$ での還元によって $\Z/(18)$ となる。

| --- | --- | --- | --- |

| $3$ | $1$ | $3$ | $2$ |

これに対し分裂するかは別の条件である。切断で法 $18$ の $[1]$ を持ち上げると、代表は $1+18k$ となる。$18$ 倍で零になるには $12\mid1+18k$ が必要十分である。$1+18k$ は $6$ を法として常に $1$ なので、$12$ の倍数にできない。従って切断は存在しない。

:::proposition[有限完全列での長さの交代和]{#prop-ring-length-alternating}
有限長加群からなる有限完全列 $0\to M_1\to\cdots\to M_n\to0$ では $\sum_{i=1}^n(-1)^i\ell(M_i)=0$ である。
:::

:::proof
$B_i$ を $M_i$ に入る写像の像とし、$B_{n+1}=0$ と置く。完全性から各 $i$ で $0\to B_i\to M_i\to B_{i+1}\to0$ は短完全である。従って $\ell(M_i)=\ell(B_i)+\ell(B_{i+1})$ である。これを交代符号で足すと内側の $\ell(B_i)$ は符号を変えて二回ずつ現れる。両端の $B_1,B_{n+1}$ は零なので、残る項もない。
:::

:::example[像の長さを追わずに余核の長さを得る]
法 $24$ の加群の $6$ 倍写像を取る。核は $[4]$ の倍数類で位数 $6$、余核は法 $6$ の加群である。位数の計算とは独立に、$0\to\Ker f\to M\xrightarrow f M\to\operatorname{coker}f\to0$ の交代和を見ると、中央二項が同じなので核と余核の長さは等しい。核の組成因子は法 $2,3$ の単純加群が一回ずつなので余核の長さは $2$ である。この式を使えば核を一つずつ求められる場合に余核の長さを短く計算できる。
:::

## Fitting の補題

### 反復すると止まる核と像を対応させる

:::lemma[Fitting の補題]{#lem-ring-fitting}
有限長加群 $M$ の自己準同型 $f$ に対し、十分大きい $n$ で
$$
M=\Ker f^n\oplus\Img f^n
$$
となる。第一の成分で $f$ は冪零、第二の成分で可逆である。
:::

:::proof
核の昇鎖と像の降鎖がともに停留する $n\ge1$ を取る。$y=f^n(x)\in\Ker f^n$ なら $x\in\Ker f^{2n}=\Ker f^n$ なので $y=0$ である。一方任意の $m$ に対し $f^n(m)\in\Img f^n=\Img f^{2n}$ なので、$f^{2n}(x)=f^n(m)$ となる $x$ を選べる。すると $m-f^n(x)$ は核に入り、和が全体を覆う。核上での冪零性は定義通りである。像上での全射性は $\Img f^{n+1}=\Img f^n$、単射性は $\Ker f\subseteq\Ker f^n$ と共通部分が零であることから従う。
:::

:::example[剰余での分解]
$\Z/(12)$ で $f$ を $2$ 倍とする。$f^2$ の核は $[3]$ の生成する四元、像は $[4]$ の生成する三元である。核では二乗が零になり、像では $2$ 倍が二つの非零元を交換する。従って第一が冪零部分、第二が可逆部分である。
:::

:::example[安定する段階と直和の二因子を計算する]
$M=\Z/(360)$ で $f$ を $6$ 倍とする。$f^j$ の核は $d=\gcd(360,6^j)$ として $[360/d]$ が生成する。これは $360\mid6^ja$ と $360/d\mid a$ が同値なためである。像は $[d]$ が生成する。全ての値は $d$ の倍数であり、Bézout 等式で $[d]$ 自体も像に入る。

| $j$ | $6^j$ | 核の位数 | 核の生成元 | 像の位数 | 像の生成元 |
| --- | --- | --- | --- | --- | --- |
| $0$ | $1$ | $1$ | $360$ | $360$ | $1$ |
| $1$ | $6$ | $6$ | $60$ | $60$ | $6$ |
| $2$ | $36$ | $36$ | $10$ | $10$ | $36$ |
| $3$ | $216$ | $72$ | $5$ | $5$ | $72$ |
| $4$ | $1296$ | $72$ | $5$ | $5$ | $72$ |
| $5$ | $7776$ | $72$ | $5$ | $5$ | $72$ |

$360=2^3\cdot3^2\cdot5$ なので $j=3$ で核は位数 $72$ の群、像は位数 $5$ の群になり、その後も変わらない。共通部分は位数が互いに素なので零である。$29\cdot5-2\cdot72=1$ により全ての元が両成分の和になる。核の成分では三乗で消え、像では $6\equiv1\pmod5$ なので $f$ は恒等となる。
:::

### 安定するまで反復し、二つの成分を特定する

:::example[法 72 で 6 倍の Fitting 分解を求める]
$M=\Z/(72)$ で $f([r])=[6r]$ とする。$f^j$ は $6^j$ 倍なので、その核は $72/\gcd(72,6^j)$ の倍数類、像は $\gcd(72,6^j)$ の倍数類である。前者は $72\mid 6^jr$ を約分して得られ、後者は整数の Bézout 等式を還元すれば得られる。

| $j$ | $a^j\bmod n$ | 核の生成元 | 像の生成元 | 核の位数 | 像の位数 |
| --- | --- | --- | --- | --- | --- |
| $1$ | $6$ | $12$ | $6$ | $6$ | $12$ |
| $2$ | $36$ | $2$ | $36$ | $36$ | $2$ |
| $3$ | $0$ | $1$ | $72$ | $72$ | $1$ |
| $4$ | $0$ | $1$ | $72$ | $72$ | $1$ |

生成元が隣接する二段で同じになったところから、核も像も停留する。核への射影は $E=[1]$ を掛ける写像である。この元は法 $72$ で $1$、法 $1$ で $0$ であるため、前者に対応する成分を残して後者だけを消す。逆に $1-E$ を掛ければ安定した像への射影になる。従って任意の $r$ は $Er+(1-E)r$ に分かれ、交わりは零である。

核の因子の位数は $72$ であり、$6$ の反復で消える。一方像の因子は法 $1$ に同型で、$6$ はこの法と互いに素だから可逆に作用する。単に $f$ の核だけを調べた場合、二回以上の反復で初めて消える元を取り除けないことがある。
:::

### 安定成分への射影を自己準同型から作る

:::proposition[Fitting 成分の保存と直和の一意性]{#prop-ring-fitting-canonical}
有限長加群 $M$ の自己準同型 $f$ について、Fitting の二成分は、$f$ が一方で冪零、他方で可逆であるような $f$ 不変直和分解として一意である。さらに $f$ と可換な写像は二成分を保ち、各成分への射影と可換である。
:::

:::proof
$M=A\oplus B$ の両因子が $f$ で安定で、$f^n A=0$、$f|_B$ が可逆とする。すると $f^n$ は $a+b$ を $f^n b$ に送る。従ってその核は $A$ で、像は $B$ である。同じことが全ての $m\ge n$ で成立するので、この二つは安定した核と像で定まる。$gf=fg$ なら $g f^n=f^n g$ であり、$g$ は核の元を核へ、像の元 $f^n x$ を再び像の元 $f^n g(x)$ へ送る。両因子を保つので、一方を残す射影と $g$ をどちらの順に適用しても同じである。
:::

:::example[作用の行列を核の増分から読む]
$\Q^{3}$ における線形写像 $T$ を、標準座標では $A=\begin{pmatrix}-1&3&-2\\-1&-1&2\\-1&-3&4\end{pmatrix}$ とする。特性多項式は $x^{2} \left(x - 2\right)$ である。同じ固有値のブロックが何個あるかは、この多項式の次数だけでは分からない。そこで固有値 $a$ に対し、$N_a=T-aI$ の冪の核を順に求める。標準基底で行列を掛け、零に送られる空間の次元を表に並べる。

| 固有値 $a$ | 冪 $j$ | $\dim\Ker N_a^j$ | 直前からの増分 |
| --- | --- | --- | --- |
| $0$ | $1$ | $1$ | $1$ |
| $0$ | $2$ | $2$ | $1$ |
| $2$ | $1$ | $1$ | $1$ |

各増分は、その段階でもまだ新しい核ベクトルを与える鎖の本数である。従って上の表から長さごとの本数は、隣接する増分の差として読み取れる。この例では、ブロックを並べる行列 $J=\begin{pmatrix}0&1&0\\0&0&0\\0&0&2\end{pmatrix}$ に対して、列を $P=\begin{pmatrix}1&1&0\\1&2&2\\1&2&3\end{pmatrix}$ と並べると $AP=PJ$ である。これを確認するには各列の像と、隣の列から来る項を比較する。行列式 $1$ の $P$ は基底を与えるので、核の増分から得た形が実際に実現した。

最小多項式は $x^{2} \left(x - 2\right)$ である。各固有値で最長の鎖を消すために必要な指数は、その長さに等しい。異なる固有値の一次因子は互いに素なので、その積を取ると全体を消せる。どれかの指数を一つ落とせば、対応する最長鎖では作用が零にならない。
:::

:::example[有限長でない場合に像と核の一方だけが止まる]
$\Z$ の $2$ 倍では全ての冪の核が零だが、像 $2^j\Z$ はどこまでも減る。像が可逆成分だけであるという分解を作ると、核が零なので全体で $2$ 倍が可逆でなければならず、$1$ が像に入らないことに反する。反対に $E=\Z[1/2]/\Z$ の $2$ 倍では像は全て $E$ で、核は位数 $2^j$ の巡回群として増える。この場合も安定した核と像の和を作ることはできない。この二例は、両方の鎖の安定性を証明で使う箇所をそれぞれ分けて示している。
:::

## 直既約分解と Krull–Schmidt の定理

### 直和因子では可逆な自己準同型を選べる

:::definition[直既約加群]{#def-ring-indecomposable}
非零加群で、二つの非零加群の直和に分かれないものを :term[直既約加群]{en="indecomposable module" yomi="ちょくきやくかぐん"} という。
:::

:::lemma[直既約因子の自己準同型]{#lem-ring-indecomp-end}
有限長の直既約加群 $U$ の自己準同型は単元か冪零である。また $\End_R U$ の非単元全体は両側イデアルをなす。
:::

:::proof
:ref[lem-ring-fitting] の二成分の片方が零なので任意の自己準同型は可逆または冪零である。$ab$ が可逆なら $a$ は全射、$b$ は単射となる。有限長性からともに可逆なので、非単元にどちら側から元を掛けても非単元となる。非単元 $a,b$ の和 $a+b=u$ が可逆だと仮定する。$u^{-1}a$ は非単元だから冪零であり、:ref[prop-ring-unit-cancel] により $1-u^{-1}a$ は可逆になる。しかしこれは $u^{-1}b$ なので非単元である。よって和も非単元で、負号は単元 $-1$ を掛ける操作なので差も閉じる。
:::

:::theorem[Krull–Schmidt の定理]{#thm-ring-krull-schmidt}
有限長加群は有限個の直既約加群の直和に分解できる。その因子は順序と同型を除いて一意である。
:::

:::proof
存在は長さで帰納する。零なら空の直和を取る。非零で直既約ならその加群一つを取る。残る場合は二つの非零直和因子の長さが加法性でいずれも減るため、それぞれを分解できる。

一意性では、$M=0$ なら両方とも空の直和である。$M\ne0$ として同じ $M$ を $\bigoplus_i U_i=\bigoplus_j V_j$ と分ける。$U_1$ の包含と射影を $i,p$、$V_j$ の包含と射影を $\iota_j,q_j$ と書く。$\sum_j\iota_jq_j=1_M$ を左右から合成すると $1_{U_1}=\sum_j p\iota_jq_j i$ である。全て非単元であれば非単元イデアルに $1$ が入るので、ある $j$ の項は可逆である。すると $q_j i\colon U_1\to V_j$ は左逆 $(p\iota_j q_j i)^{-1}p\iota_j$ をもつ。従って $V_j$ ではその像が直和因子をなし、非零かつ $V_j$ は直既約なので $q_j i$ は同型である。

このとき $M=U_1\oplus\bigoplus_{k\ne j}V_k$ である。実際 $q_j$ の任意の値を $U_1$ から一意に持ち上げられるため、任意の元からその持ち上げを引くと $q_j$ の核に入り、共通部分も零である。商 $M/U_1$ を取ると、残りの $U_i$ と残りの $V_k$ が同じ加群の直和分解を与える。その長さは元より小さいので帰納法を適用する。
:::

:::corollary[有限直和からの消去]{#cor-ring-finite-length-cancellation}
有限長加群 $A,B,C$ に対して $A\oplus C\cong B\oplus C$ なら $A\cong B$ である。
:::

:::proof
三つの加群をそれぞれ直既約因子に分ける。一意性により、各直既約型について $A$ と $C$ での多重度の和が $B$ と $C$ での和に等しい。$C$ の多重度を引くと、$A$ と $B$ では各型が同じ回数現れるので同型である。
:::

直既約因子の自己準同型環では非単元全体が真の両側イデアルであり、その商は斜体になる。この性質を持つ環を、非可換環も含めて局所環と呼ぶ。一意性の証明で各因子の有限長性を使ったのは、この性質を得る箇所と帰納の箇所である。従って、有限個の直既約因子の直和が既に与えられ、各因子の自己準同型環が局所環であれば、因子の個数で帰納することで同じ一意性が得られる。

:::example[組成因子と直既約因子の違い]
$\Z/(4)$ と $\Z/(2)\oplus\Z/(2)$ は双方とも組成因子が $\Z/(2)$ 二個である。ただし $\Z/(4)$ の任意の非零部分群は $[2]$ を含むので非零直和に分かれず、後者は表示通り二つに分かれる。Jordan–Hölder が同じ結論を与える二加群を、直既約分解では区別できる。
:::

:::example[長さが同じ直既約加群を見分ける]
$K[x]/(x^2)$ と $K[x]/((x-1)^2)$ は、いずれも真の非零部分加群を一つだけもつため直既約である。実際、剰余の部分加群は、それぞれの法を含む主イデアルに対応する。前者では $x$ が二乗で零になるが、後者では $x=1+u$、$u^2=0$ なので $x$ が可逆に作用する。よって同型でない。この例で両者は長さが $2$ で等しい一方、単純な組成因子の型は異なる。型ごとの情報は直既約因子を置き換える際にも必要である。
:::

### 射影と自己準同型環から直既約性を調べる

:::proposition[冪等自己準同型と直既約性]{#prop-ring-indecomp-idempotent}
非零加群 $M$ が直既約であることと、$\End_R M$ にある冪等元が $0,1$ のみであることは同値である。
:::

:::proof
直和 $M=A\oplus B$ があれば $A$ への射影 $e$ は冪等である。両因子が非零なら $A$ 上で恒等、$B$ 上で零なので $e\ne0,1$ である。逆に $e^2=e$ があれば $m=e(m)+(m-e(m))$ と分ける。最初の項は像、後は核に入る。像の元 $w=e(v)$ が核にも入るなら $w=e^2(v)=e(w)=0$ である。従って直和である。$e\ne0,1$ なら像と核はどちらも非零である。実際、像が零なら $e=0$、核が零なら $m-e(m)=0$ が全ての元で成り立ち $e=1$ である。
:::

:::example[法 360 の冪等元と座標]
$R=\Z/(360)$ を相異なる素数の冪を法とする環の直積に移す。各成分で $e^2=e$ なら $e(e-1)=0$ である。整数の連続する二元は互いに素なので、素数冪はどちらか片方を割らなければならない。従って各成分の値は $0,1$ の二択である。このため次の表で冪等元を尽くす。

| $e$ の代表 | $\bmod 8$ | $\bmod 9$ | $\bmod 5$ |
| --- | --- | --- | --- |
| $0$ | $0$ | $0$ | $0$ |
| $1$ | $1$ | $1$ | $1$ |
| $81$ | $1$ | $0$ | $1$ |
| $136$ | $0$ | $1$ | $1$ |
| $145$ | $1$ | $1$ | $0$ |
| $216$ | $0$ | $0$ | $1$ |
| $225$ | $1$ | $0$ | $0$ |
| $280$ | $0$ | $1$ | $0$ |

ここから $e=[225]$ を選ぶ。$eR$ の元は $e$ の座標が零である全ての場所で零となる。逆に、その場所で零になる任意の組は $e$ を掛けても変わらないので $eR$ に入る。従って $eR$ の元は $8$ 個あり、$R/(e)$ は $45$ 個の元をもつ。

同じ議論を $1-e$ に適用すると、残りの座標との対応が得られる。実際、整数の最大公約数で生成元を取り直すと $(e)=([45])$ と $(1-e)=([8])$ である。両者の和は $1$ を含み、積は零である。各元は $e r+(1-e)r$ と書け、二項はそれぞれのイデアル成分に入るため、商を二つに分けて座標を復元できる。
:::

:::example[2 準素部分の層を数える]
$M$ を法 $4,\ 8,\ 18,\ 25$ の巡回群の直和とする。位数全体は $14400$ である。素数 $p=2$ に対し、各法の $p$ の指数は $2,\ 3,\ 1,\ 0$ である。各成分で $p^j$ 倍して零になる条件は、その法が $p^j$ 倍した代表を割ることである。法 $n_i$ での核の位数は $\gcd(n_i,p^j)$ であり、全体ではこれらの積になる。

| $j$ | $\lvert \Ker(p^j)\rvert$ | $\lvert p^j M_p\rvert$ | 層の次元 | 指数がちょうど $j$ の個数 |
| --- | --- | --- | --- | --- |
| $1$ | $8$ | $8$ | $3$ | $1$ |
| $2$ | $32$ | $2$ | $2$ | $1$ |
| $3$ | $64$ | $1$ | $1$ | $1$ |
| $4$ | $64$ | $1$ | $0$ | $0$ |

ここで $M_p$ は $p$ の冪で消える部分であり、その位数は $64$ である。$|p^j M_p|$ はこの位数を核の位数で割った値である。従って隣接する二つの像を比較すると、$p^{j-1}M_p/p^jM_p$ は次元が表の第四列の $\F_p$ ベクトル空間になる。この次元は長さが少なくとも $j$ の巡回成分を一個ずつ数える。次の行との差を取ると、最後の列の通り指数がちょうど $j$ の成分の個数になる。この手順は、最初に表示から分解を推測できなくても、乗法の核や像を計算できる場合に使える。
:::

:::example[3 準素部分の層を数える]
$M$ を法 $8,\ 9,\ 18,\ 25$ の巡回群の直和とする。位数全体は $32400$ である。素数 $p=3$ に対し、各法の $p$ の指数は $0,\ 2,\ 2,\ 0$ である。各成分で $p^j$ 倍して零になる条件は、その法が $p^j$ 倍した代表を割ることである。法 $n_i$ での核の位数は $\gcd(n_i,p^j)$ であり、全体ではこれらの積になる。

| $j$ | $\lvert \Ker(p^j)\rvert$ | $\lvert p^j M_p\rvert$ | 層の次元 | 指数がちょうど $j$ の個数 |
| --- | --- | --- | --- | --- |
| $1$ | $9$ | $9$ | $2$ | $0$ |
| $2$ | $81$ | $1$ | $2$ | $2$ |
| $3$ | $81$ | $1$ | $0$ | $0$ |

ここで $M_p$ は $p$ の冪で消える部分であり、その位数は $81$ である。$|p^j M_p|$ はこの位数を核の位数で割った値である。従って隣接する二つの像を比較すると、$p^{j-1}M_p/p^jM_p$ は次元が表の第四列の $\F_p$ ベクトル空間になる。この次元は長さが少なくとも $j$ の巡回成分を一個ずつ数える。次の行との差を取ると、最後の列の通り指数がちょうど $j$ の成分の個数になる。この手順は、最初に表示から分解を推測できなくても、乗法の核や像を計算できる場合に使える。
:::

:::example[ある上三角作用の直既約性]
$M$ を $\Q^2$ とし、$\Q[x]$ 上で $x$ が $N=\begin{pmatrix}0&1\\0&0\end{pmatrix}$ と作用する。自己準同型の行列 $\begin{pmatrix}a&b\\c&d\end{pmatrix}$ と $N$ を両順序で掛け、$c=0,d=a$ が必要十分と分かる。この自己準同型は $aI+bN$ である。$a\ne0$ なら逆は $a^{-1}I-a^{-2}bN$ で、$a=0$ なら平方が零となる。冪等と仮定すると $a^2=a$ と $2ab=b$ であり、$a=0,1$ のいずれでも $b=0$ となる。従って $M$ は直既約である。これに対して $N=0$ とした作用では任意の線形写像が準同型になり、座標への射影が非自明な分解を与える。
:::

### 局所的な自己準同型環から因子を交換する

:::example[異なる補因子から同じ直既約型を取り出す]
$M=\Z/(4)\oplus\Z/(2)$、$U=\Z/(4)\oplus0$ とし、$W$ を $([2],[1])$ の生成する部分群とする。$W$ は位数 $2$ で、第二成分が非零の元を持つため $U$ との交わりは零である。さらに任意の $([a],[b])$ から $b([2],[1])$ を引くと第二成分が零になる。従って $U\oplus W=M$ である。一方、もとの分解の第二因子 $V=0\oplus\Z/(2)$ は $W$ とは異なる。商 $M/U$ では $V,W$ は同じ法 $2$ の因子であり、どちらも商への射影を通じて同型となる。ここで一意なのは同型型の多重集合であって、加群の内部の各部分集合が決まるわけではない。
:::

:::example[一つの直既約因子でできる自己準同型の計算]
$U=K[x]/(x^3)$ とする。自己準同型は $[1]$ の像 $a+bx+cx^2$ で決まる。任意の像に対し始域の関係 $x^3[1]=0$ が保たれるので、自己準同型環はこの剰余と同型である。例えば $1+2x+3x^2$ の逆元は $1-2x+x^2$ である。実際二式の積で一次と二次の係数は零になり、高次は消える。これに対し $2x+3x^2$ は平方が $4x^2$、三乗が零であり、逆が無い。従って非単元は定数項零のイデアルであり、この中の二つを足しても単元は作れない。Krull–Schmidt の証明で直既約因子の恒等写像をいくつかの合成に分けるとき、全ての項がこのイデアルに入ることはない。
:::

:::example[同型な因子の混合を交換の手順でほどく]
$M=K^2$ に $K[x]$ の $x$ を零として作用させる。座標で $U_1=Ke_1$、$U_2=Ke_2$ とし、別に $V_1=K(e_1+e_2)$、$V_2=Ke_2$ とする。第二の分解での射影は $q_1(a,b)=a(e_1+e_2)$、$q_2(a,b)=(b-a)e_2$ である。$U_1$ へ戻す座標射影 $p_1$ を適用すると、$p_1q_1$ は $U_1$ 上で恒等、$p_1q_2$ は零である。従って最初の合成を用いて $U_1$ と $V_1$ を対応させる。実際 $q_1|_{U_1}$ は $e_1$ を $e_1+e_2$ に送る同型であり、$\Ker q_1=V_2$ だから $M=U_1\oplus V_2$ が成り立つ。最後に $U_1$ を割ると、残る因子が両方で $Ke_2$ に対応する。この二次元の例では、恒等の和から可逆な項を選ぶ証明を射影の式まで追える。
:::

## 演習問題

::::exercise{level=basic}
$\Z/(18)$ の組成列を一つ与え、長さを求めよ。

:::solution
$0\subset(9)/(18)\subset(3)/(18)\subset\Z/(18)$ とする。各段の部分群の位数が $1,2,6,18$ なので商の位数は $2,3,3$ である。素数位数群は単純だから組成列であり長さは $3$ である。
:::
::::

::::exercise{level=basic}
体 $K$ について $K[x]/(x^4)$ の $K[x]$ 加群としての長さを求めよ。

:::solution
商の中で $0\subset([x]^3)\subset([x]^2)\subset([x])\subset K[x]/(x^4)$ とする。隣接商では単独の冪 $x^j$ が生成し $x$ が零に作用するため $K[x]/(x)$ と同型である。よって長さは $4$ である。
:::
::::

::::exercise{level=basic}
$\Z/(20)$ の $2$ 倍の Fitting 分解を求めよ。

:::solution
$2^2$ 倍の核は $[5]$ の倍数、像は $[4]$ の倍数であり、位数はそれぞれ $4,5$ である。その後の核と像は変化しない。前者では $2^2$ 倍が零、後者では法 $5$ と同じく $2$ に逆元がある。
:::
::::

::::exercise{level=basic}
$\Z/(8)$ は直既約か。

:::solution
任意の非零元は位数が $2,4,8$ のいずれかであり、その巡回部分群は位数 $2$ の唯一の部分群 $\langle[4]\rangle$ を含む。従って非零部分群どうしの共通部分が零にならず、直既約である。
:::
::::

::::exercise{level=advanced}
有限長加群 $M$ の準同型 $f\colon M\to M$ で $\ell_R(\Ker f)=2$ のとき余核の長さを求めよ。

:::solution
二つの短完全列 $0\to\Ker f\to M\to\Img f\to0$ と $0\to\Img f\to M\to\operatorname{coker}f\to0$ から、双方の差 $\ell_R(M)-\ell_R(\Img f)$ が核と余核の長さになる。従って余核も長さ $2$ である。
:::
::::

::::exercise{level=advanced}
$n\ge1$ とする。$K[x]/(x^n)$ が直既約であることを示せ。

:::solution
部分加群は $(x^n)$ を含む $K[x]$ のイデアルに対応する。$K[x]$ は PID なので、生成元は $x^n$ を割り、単元倍を除いて $x^j$ である。非零部分加群は全て $(x^{n-1})/(x^n)$ を含むため、二つの非零部分加群の直和にはできない。
:::
::::

::::exercise{level=advanced}
有限長直既約加群の冪等な自己準同型を全て求めよ。

:::solution
Fitting の補題により自己準同型は可逆か冪零である。可逆な $e$ で $e^2=e$ なら逆を掛けて $e=1$ となる。冪零なら $e^n=0$ となる一方 $e^n=e$ なので $e=0$ である。両者は実際に冪等である。
:::
::::

::::exercise{level=advanced}
$\Z/(4)\oplus\Z/(9)$ の長さと直既約因子の個数を求めよ。

:::solution
各素冪の巡回群では $p$ 倍の降鎖が組成列を与え、いずれも長さ $2$ なので全体は長さ $4$ である。各素冪群の非零部分加群は位数 $p$ の部分群を含むため直既約であり、直既約因子は二つである。
:::
::::

::::exercise{level=advanced}
$\Z/(96)$ の $6$ 倍の Fitting 分解を求めよ。

:::solution
$96=2^5\cdot3$ であり、$6^j=2^j3^j$ である。従って $96\mid6^j$ となる最小の正整数 $j$ は $5$ である。四回目では $\gcd(96,6^4)=48$ なので、核は偶数類全体に限り、像は $[48]$ が生成する位数 $2$ の群である。五回目で写像全体が零になり、以後の像は零、核は全体である。よって Fitting 分解の冪零成分は全体、可逆成分は零である。
:::
::::

## 確認テスト

::::quiz
組成列をもつ加群に必要十分な条件はどれか。

- [ ] Noether 性だけ
- [ ] Artin 性だけ
- [x] Artin 性と Noether 性の両方

:::explanation
組成列では単純な商が両条件を満たし、短完全列を通じて全体に伝わる。逆に Noether 性が極大な真の部分加群を与え、Artin 性がそれらを取る手続きを有限で止める。
:::
::::

::::quiz{answer="3" tol="1e-9"}
$\Z/(8)$ の $\Z$ 加群としての長さを答えよ。

:::explanation
$0\subset\langle[4]\rangle\subset\langle[2]\rangle\subset\Z/(8)$ では三つの商がいずれも $\Z/(2)$ で単純である。よって長さは $3$ である。
:::
::::

::::quiz
有限長な直既約加群の自己準同型はどの性質を満たすか。

- [x] 可逆か冪零である。
- [ ] 全て可逆である。
- [ ] 全て冪零である。

:::explanation
Fitting の分解の一方が直既約性で零になるため、写像は可逆か冪零である。零写像は非零加群上で可逆でなく、恒等写像は冪零でないので後の二つは一般に成り立たない。
:::
::::

::::quiz{answer="5" tol="1e-9"}
$K$ 上の $K^2\oplus K^3$ の長さを答えよ。

:::explanation
体上の組成因子は一次元であり、座標基底に沿う列で $2+3=5$ 個の因子が得られる。
:::
::::

::::quiz{answer="5" tol="1e-9"}
$\Z/(72)$ の $\Z$ 加群としての組成列の長さはいくつか。

:::explanation
$72=2^3\cdot3^2$ である。約数 $1,2,4,8,24,72$ が生成する部分群を順に並べると、下への各商の位数は $2,2,2,3,3$ となり単純である。従って組成列の段数は $5$ であり、組成列の長さは $5$ となる。
:::
