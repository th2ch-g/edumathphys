## この章の目標

- 行列、多項式、群、関数から環を構成する。
- 単元、零因子、冪零元を定義から判定する。
- 左・右・両側イデアルの役割を区別し、可換環でイデアルの演算を計算する。
- 剰余と準同型の普遍性を使って環を同定する。

## 環の定義と例（行列環・多項式環・群環・関数環）

### 二つの演算を同時に扱う

整数を負の数まで含めると、和と差はいつでも計算できる。積も整数になるが、除法の結果は整数とは限らない。環の公理はこの状況に加え、行列のように積の順序が重要な状況を扱う。

:::definition[環]{#def-ring-ring}
集合 $R$ に加法と乗法が備わり、加法で Abel 群、乗法で単位元 $1$ をもつ結合的な演算をなし、両側の分配法則
$$
a(b+c)=ab+ac,\qquad (a+b)c=ac+bc
$$
を満たすとき、$R$ を :term[環]{en="ring" yomi="かん"} という。乗法が可換なら :term[可換環]{en="commutative ring" yomi="かかんかん"} という。本科目では環に単位元を要求する。$0=1$ の一元環も認め、:term[零環]{en="zero ring" yomi="れいかん"} と呼ぶ。
:::

:::proposition[零元と符号の計算]{#prop-ring-sign}
任意の環で $a0=0=0a$、$a(-b)=-(ab)=(-a)b$、$(-a)(-b)=ab$ が成り立つ。さらに $0=1$ なら環は零環である。
:::

:::proof
$a0=a(0+0)=a0+a0$ から加法逆元を加えて $a0=0$ を得る。右から掛ける場合も分配法則で同じ計算をする。$ab+a(-b)=a0=0$ と $ab+(-a)b=0b=0$ から前半の符号の等式が従う。それらを続けて用いると $(-a)(-b)=-((-a)b)=-(-(ab))=ab$ である。$0=1$ なら全ての $a$ について $a=a1=a0=0$ である。
:::

### 四つの構成

:::example[行列環]
環 $R$ と $n\ge 1$ に対し、:term[行列環]{en="matrix ring" yomi="ぎょうれつかん"} $M_n(R)$ の加法は成分ごとに、積は $(AB)_{ij}=\sum_k a_{ik}b_{kj}$ で定める。積の結合性は $((AB)C)_{ij}$ と $(A(BC))_{ij}$ がともに $\sum_{k,l}a_{ik}b_{kl}c_{lj}$ になることから従う。分配法則は各項に $R$ の分配法則を適用して得る。対角成分が $1$ の単位行列が乗法単位元である。

第 $(i,j)$ 成分のみが $1$ の行列を $E_{ij}$ と書けば $E_{ij}E_{kl}=\delta_{jk}E_{il}$ である。例えば $M_2(\Z)$ では $E_{12}E_{21}=E_{11}$、$E_{21}E_{12}=E_{22}$ となり、積は可換でない。
:::

:::example[多項式環]
環 $R$ の係数をもつ有限台の列 $(a_i)_{i\ge0}$ を $\sum_i a_ix^i$ と書く。和は成分ごとであり、積の第 $n$ 係数は $\sum_{i+j=n}a_i b_j$ である。結合性は積の第 $n$ 係数を $\sum_{i+j+k=n}a_ib_jc_k$ と展開して確かめる。分配法則も有限和で確かめられ、$1+0x+\cdots$ が単位元である。この環を :term[多項式環]{en="polynomial ring" yomi="たこうしきかん"} $R[x]$ と書く。$x$ は係数と可換である。$R$ が可換なら積の添字を交換できるので $R[x]$ も可換である。

例えば $\Z[x]$ では $(2+x)(3-x+x^2)=6+x+x^2+x^3$ である。この等式は各次数の係数の等式を表す。環を $\F_2$ とした場合、$x^2+x$ は零多項式と異なるが、$0$ と $1$ のどちらでも値は $0$ である。係数列と値の表を区別するとこの違いを説明できる。
:::

:::example[群環]
群 $G$ に対し、:term[群環]{en="group ring" yomi="ぐんかん"} $R[G]$ を有限和 $\sum_{g\in G}a_g[g]$ 全体とし、$a_g[g]b_h[h]=a_gb_h[gh]$ と置いて分配する。$G$ と $R$ の積の結合性から三項積の係数は $\sum_{ghk=u}a_gb_hc_k$ に一致する。有限台の積が有限なのでこの和は有限である。単位元は $1[e]$ である。例えば $R=\Z$、$G=\{e,g\}$、$g^2=e$ とすると
$$
(2[e]+3[g])([e]-[g])=-[e]+[g].
$$
$R$ が非零で $gh\ne hg$ なら、係数が $1$ の基底元の積 $[gh]$ と $[hg]$ が異なるため群環も非可換である。
:::

:::example[関数環と直積]
集合 $X$ 上の $R$ 値関数全体 $R^X$ に対し $(f+h)(t)=f(t)+h(t)$、$(fh)(t)=f(t)h(t)$ と置く。環の等式は各 $t$ で $R$ の等式になり、定数関数 $1$ が単位元である。$X=\{1,2\}$ の場合は直積環 $R\times R$ であり、例えば $R=\Z$ では $(2,3)(4,5)=(8,15)$ である。複数の異なる環を使う直積でも、各成分で演算して同じ公理を確かめられる。
:::

:::definition[反対環と中心]{#def-ring-opposite-center}
$R$ と同じ加法をもち、積を $a*b=ba$ に変えた環を :term[反対環]{en="opposite ring" yomi="はんたいかん"} $R^{\mathrm{op}}$ と呼ぶ。また全ての $r\in R$ と可換な元 $z$ の集合を :term[中心]{en="center" yomi="ちゅうしん"} $Z(R)$ と呼ぶ。
:::

反対環の単位元は $1$ であり、$(a*b)*c=cba=a*(b*c)$ となる。二つの分配法則は元の環の反対側の分配法則に移る。中心では $z,w$ が $r$ と可換なら $(z-w)r=r(z-w)$、$(zw)r=z(rw)=r(zw)$ であり、$0,1$ も中心に入る。このため中心自体が可換環になる。行列の転置では $(AB)^\top=B^\top A^\top$ である。この反転は係数が可換な場合に成り立ち、一般には $M_n(R)\to M_n(R^{\mathrm{op}})$ とすれば成分の順序も反転できる。

### 多項式を別の環へ送る

環準同型とは、この章の最後で定義する、和・積・単位元を保つ写像である。多項式を代入するときは、その三つを保つための条件を確認する。

:::proposition[多項式環の普遍性]{#prop-ring-poly-universal}
環準同型 $f\colon R\to T$ と、$f(R)$ の全ての元と可換な $t\in T$ を取る。$f$ を延長し $x$ を $t$ に送る準同型 $R[x]\to T$ が一意に存在する。
:::

:::proof
$\sum_i a_ix^i\mapsto\sum_i f(a_i)t^i$ と置くと加法と単位元を保つ。積では $t^i f(b_j)=f(b_j)t^i$ と移せるので、二つの像の積の各項は $f(a_i b_j)t^{i+j}$ となる。これは積の像の展開である。多項式の有限和表示により、延長の値はこの式に強制される。逆にどの延長の $x$ の像も、$x$ と係数の可換関係を保つため $f(R)$ と可換である。
:::

:::example[非可換環への代入]
$\Z[x]\to M_2(\Z)$ で係数を整数倍の単位行列に送り、$x$ の像を $A=E_{12}$ とする。係数の像は任意の $A$ と可換であり、$A^2=0$ なので $f(x)=a_0+a_1x+\cdots$ の像は $a_0 I+a_1E_{12}$ となる。零行列になる条件は $a_0=a_1=0$ であり、核は $(x^2)$ である。従って、像は整数係数の双対数の環 $\Z[x]/(x^2)$ に同型である。

係数環を $M_2(\Z)$ として全係数をそのまま $M_2(\Z)$ に送る場合、同じ $A$ を $x$ の像に選べない。例えば $xE_{21}=E_{21}x$ の像が $E_{11}=E_{22}$ になってしまうためである。任意の環に多項式を代入する際には、代入値だけでなく係数の行き先も確認する。
:::

:::example[整数値の条件を加えた関数環]
集合 $X=\{1,2,3\}$ に対し、$\Z^X$ のうち $f(1)\equiv f(2)\pmod 2$ となるものは部分環である。差については同じ合同を引き、積については二つの合同を掛ければよい。定数関数 $1$ も条件を満たす。ただし外の関数 $h=(1,0,0)$ を $1$ に掛けると条件を満たさないため、$\Z^X$ のイデアルにはならない。この条件は座標二つを関連付けており、各成分に独立な条件を課した直積とは異なる。
:::

### 構成を区別するための標数と積

同じ記号 $2$ でも、整数の環と標数 $2$ の環では意味が異なる。そこで環の中の整数がどのように働くかを、単位元を用いて記録する。

:::definition[標数]{#def-ring-characteristic}
$n\in\Z$ に対し、$n\cdot1_R$ を単位元の整数倍とする。$n\cdot1_R=0$ となる最小の正整数を $R$ の :term[標数]{en="characteristic" yomi="ひょうすう"} といい、$\operatorname{char}R$ と書く。そのような正整数がなければ $\operatorname{char}R=0$ とする。
:::

:::proposition[整数の像と有限直積の標数]{#prop-ring-characteristic-product}
$n\mapsto n\cdot1_R$ は加法と積を保ち、その像は $Z(R)$ に含まれる。有限個の環の直積の標数は、全成分の標数が正ならその最小公倍数であり、少なくとも一つの標数が零なら零である。$n\ge1$ のとき $M_n(R)$ の標数は $R$ に等しい。
:::

:::proof
分配法則を用いると、非負整数 $a,b$ では $(a\cdot1_R)(b\cdot1_R)=ab\cdot1_R$ となる。整数全体では符号の公式を用いれば同じである。$r(a\cdot1_R)=(a\cdot1_R)r$ は両辺が $r$ の $a$ 倍であることから従う。$d=\operatorname{char} R>0$ のとき、$n\cdot1_R=0$ なら $n=qd+r$、$0\le r<d$ と割って $r\cdot1_R=0$ を得る。$d$ の最小性から $r=0$ である。直積の条件は成分全てで同時に $n\cdot1=0$ になることである。最後に行列環の $n$ 回の和は対角に係数環での和を並べるため、同じ整数が単位元を消す。
:::

:::example[直積と行列の標数を比較する]
$R=M_2(\Z/(6))\times\Z/(10)$ で $1_R=(I,[1])$ である。整数 $m$ の像が零になる条件は、対角成分から $6\mid m$、右成分から $10\mid m$ となることである。最小の正の解は $30$ である。例えば $15$ の像は $(3I,[5])$ で、その二倍は零になるが元自体は非零である。また $6$ の像は $(0,[6])$ であり、第一成分だけを見てその元が零とは判定できない。係数の還元をどこまで行うかは成分ごとに指定する必要がある。
:::

:::example[群の異なる元を還元後も区別する]
$C_3=\{e,g,g^2\}$ 上の群環 $\F_2[C_3]$ で $h=[e]+[g]+[g^2]$ と置く。$[g]h=h$ であり、左から $[g^2]$ を掛けても同じである。従って $h^2=3h=h$ である。他方、$1+[g]$ を $h$ に掛けると $h+h=0$ となる。係数を法 $2$ に移すと $3$ の像は $1$ になるが、$[e],[g],[g^2]$ は異なる座標であり、この三つの元の和は非零である。計算を整理するには、係数の消滅と、添字が群の演算で一致することを別々に追う。
:::

:::example[点ごとの積で関数の台を追う]
三点上の有理数値関数環で $f=(2,0,-3)$、$g=(0,4,5)$ を取る。和は $(2,4,2)$、積は $(0,0,-15)$ である。各非零値は体で約分できるから、$fh=0$ になる $h$ は $(0,t,0)$ の形に限る。写像 $h\mapsto fh$ の像は $(u,0,v)$ 全体である。実際 $(u/2,0,-v/3)$ を掛ければ所望の像を得る。各点で独立に解けるため、核と像の座標がここでは互いに補い合う。係数環に零因子があれば非零値を約分できない点が増える。
:::

:::example[一つの行列と可換な部分環]
$M_2(\Q)$ で $T=\begin{pmatrix}3&2\\4&3\end{pmatrix}$ とし、$HT=TH$ を満たす行列 $H$ の全体を調べる。$HT=TH$ と $JT=TJ$ なら $(H-J)T=T(H-J)$ であり、$(HJ)T=H(TJ)=T(HJ)$ である。単位行列も条件を満たすから、これは部分環である。

$H=\begin{pmatrix}u&v\\w&k\end{pmatrix}$ と書くと交換子は $\begin{pmatrix}4 v - 2 w&- 2 k + 2 u\\4 k - 4 u&- 4 v + 2 w\end{pmatrix}$ になる。従って $k=u$ かつ $4v=2w$ が必要十分である。$2$ で割って係数を求めると、$H=uI+\frac{v}{2}(T-3I)$ と書ける。この表示は任意の $u,v$ を許す。従って可換な部分環を求める問題を、二つの係数に帰着できた。

例えば $I+T=\begin{pmatrix}4&2\\4&4\end{pmatrix}$ と $2T-3I=\begin{pmatrix}3&4\\8&3\end{pmatrix}$ の積はどちらの順序でも $\begin{pmatrix}28&22\\44&28\end{pmatrix}$ である。これは二元が共に $T$ の多項式であることと一致する。ただし元の行列環にはこの部分環に入らない行列がある。例えば $E_{11}$ では $u=1,k=0$ なので条件を満たさない。
:::

## 単元・零因子・冪零元

### 逆元と約分を調べる

:::definition[単元、零因子、冪零元]{#def-ring-units-zero-nil}
$a\in R$ に対し $ab=ba=1$ となる $b$ があれば、$a$ は :term[単元]{en="unit" yomi="たんげん"} である。$a\ne0$ で、ある $b\ne0$ について $ab=0$ または $ba=0$ となるとき $a$ は :term[零因子]{en="zero divisor" yomi="れいいんし"} と呼ぶ。$a^m=0$ となる正整数 $m$ があれば $a$ は :term[冪零元]{en="nilpotent element" yomi="べきれいげん"} である。零元も冪零元に含む。
:::

:::proposition[単元と消去]{#prop-ring-unit-cancel}
単元全体 $R^\times$ は群をなす。単元は左右から約分でき、非零冪零元は零因子である。$1-a$ は $a$ が冪零なら単元である。
:::

:::proof
左逆元 $c$ と右逆元 $b$ があれば $c=c(ab)=(ca)b=b$ となるので、逆元は一意である。$u,v$ が単元なら $v^{-1}u^{-1}$ が $uv$ の両側逆元であり、群の閉性が従う。$ux=uy$ に左から $u^{-1}$ を掛けると $x=y$ であり、右の約分も同様である。非零冪零元 $a$ の零になる最小の冪を $m$ とすると $m\ge2$、$a^{m-1}\ne0$、$a\,a^{m-1}=0$ である。さらに $a^m=0$ なら
$$
(1-a)(1+a+\cdots+a^{m-1})=1-a^m=1
$$
であり、多項式の二因子は互いに可換なので逆順でも積は $1$ になる。
:::

:::example[剰余の計算]
整数を $12$ で割った余りで足し掛けする環では $5^2=1$、$3\cdot4=0$、$6^2=0$ である。$5$ は単元、$3,4$ は零因子、$6$ は非零冪零元である。$3$ のどの正の冪も $3$ で割った余りは $0$ だが、$4$ で割った余りは $3$ と $1$ を交互に取る。したがって $3$ は冪零元ではない。
:::

:::example[関数の単元]
$f\in R^X$ が単元なら各値 $f(t)$ は単元である。逆に各値が単元なら $g(t)=f(t)^{-1}$ で逆元を定められる。例えば $\R^{\{1,2\}}$ では $(2,3)^{-1}=(1/2,1/3)$ であり、$(1,0)(0,1)=0$ である。各成分が体なら冪零元は全成分が零の関数だけである。
:::

:::example[片側逆元]
有理数上の、有限台の列の空間に基底 $e_0,e_1,\ldots$ を取る。右シフト $Ue_i=e_{i+1}$ と左シフト $Ve_0=0,\ Ve_{i+1}=e_i$ を線形に延長すると、合成を積とする自己準同型環で $VU=1$ だが $UV e_0=0$ である。従って $U,V$ は両側単元ではない。同じ計算で $P=1-UV$ が $e_0$ への射影であり、$PU=0,\ VP=0$ と分かる。
:::

:::proposition[有限環の非単元]{#prop-ring-finite-unit}
有限の非零環の非零元は、単元か零因子のいずれかである。
:::

:::proof
$L_a\colon r\mapsto ar$ が単射なら有限性から全射となり、$ab=1$ となる $b$ がある。$a(ba-1)=0$ と単射性から $ba=1$ である。$L_a$ が単射でなければ $ar=as$ となる異なる $r,s$ があり、$a(r-s)=0$ なので $a$ は零因子である。単元の消去性から二つの条件は同時に成立しない。
:::

有限性が外れると、例えば $\Z$ の $2$ は約分できるが単元ではない。また $e^2=e$ となる元 $e$ を :term[冪等元]{en="idempotent element" yomi="べきとうげん"} という。このとき $e(1-e)=0$ なので、$e\ne0,1$ なら $e$ は零因子である。

### 冪零元を足せる範囲

:::proposition[可換する冪零元の和]{#prop-ring-nilpotent-sum}
$a^m=b^n=0$ かつ $ab=ba$ なら $(a+b)^{m+n-1}=0$ である。可換環では冪零元全体がイデアルになる。
:::

:::proof
可換する二元について二項定理を使うと、各項の二指数の和は $m+n-1$ である。従って一方は少なくとも $m$ または $n$ に達し、その項は零である。可換環では $(-b)^n=0$ なので差も冪零であり、$(ra)^m=r^ma^m=0$ なので吸収性も成り立つ。
:::

:::example[行列での失敗]
$A=E_{12}$ と $B=E_{21}$ はどちらも二乗が零である。しかし $(A+B)^2=E_{11}+E_{22}=I$ である。従って $A+B$ は冪零どころか単元である。二項展開で混合項 $AB+BA$ が残るため、可換環で用いた冪のまとめ方は使えない。
:::

:::example[冪零の指数が増える場合]
$\Q[x,y]/(x^2,y^3)$ で $u=[x]$、$v=[y]$ とすると $u^2=v^3=0$ である。$(u+v)^3=3uv^2$ は非零である。実際イデアル $(x^2,y^3)$ の元は各単項式が $x^2$ か $y^3$ の倍数であり、$xy^2$ がこれらに入らない。四乗では全ての項が消えるので冪零の指数は $4$ である。
:::

### 冪等元を使う逆元と有限環での判定

非可換環でも、単一の元だけから作った二つの多項式は互いに可換である。これを利用すると、冪等元の作る二成分で単元を調べられる。

:::proposition[冪等元による単元の構成]{#prop-ring-idempotent-unit}
$e^2=e$ とし、$u,v$ を $e$ と可換な単元とする。$a=ue+v(1-e)$ は単元で、逆は $u^{-1}e+v^{-1}(1-e)$ である。
:::

:::proof
単元が $e$ と可換なら、その逆元も両側に逆元を掛けることで $e$ と可換である。積を展開すると交差項は $e(1-e)=(1-e)e=0$ によって消える。残った項は $uu^{-1}e+vv^{-1}(1-e)=1$ である。逆の順も同じ計算で $1$ となる。
:::

## 部分環とイデアル

### 部分環と吸収性

:::definition[部分環とイデアル]{#def-ring-ideal}
$1_R$ を含み、$R$ の演算で環をなす部分集合を :term[部分環]{en="subring" yomi="ぶぶんかん"} という。加法部分群 $I$ が $r\in R,\ i\in I$ に対して $ri\in I$ を満たすとき :term[左イデアル]{en="left ideal" yomi="ひだりいである"}、$ir\in I$ を満たすとき :term[右イデアル]{en="right ideal" yomi="みぎいである"} と呼ぶ。両者を満たすものを :term[両側イデアル]{en="two-sided ideal" yomi="りょうがわいである"} と呼び、単にイデアルといえばこちらを指す。$I\ne R$ のとき真のイデアルという。
:::

部分環の判定は $1$ の包含と差、積の閉性で足りる。実際、$1-1$ で $0$、$0-a$ で $-a$、$a-(-b)$ で $a+b$ が入る。イデアルの判定では空集合を除き、差と吸収性を調べる。$1\in I$ なら任意の $r=r1$ が $I$ に入る。従って真のイデアルは単元を含まない。なぜなら $u\in I$ が単元なら $u^{-1}u=1\in I$ となるからである。

:::example[同じ集合の見方]
$\Z$ は $\Q$ の部分環である。$1$ が含まれ、引き算と掛け算で閉じるためである。ところが $1$ に $\Q$ の $1/2$ を掛けると $\Z$ から出るので、$\Q$ のイデアルにはならない。$2\Z$ は $\Z$ のイデアルであり、$1$ を含まないのでここでの部分環の定義を満たさない。
:::

:::example[行列の片側イデアル]
$M_2(\Q)$ で第 2 列が零の行列全体 $L$ を考える。左から掛けても第 2 列は零なので $L$ は左イデアルである。一方 $E_{11}\in L$ に右から $E_{12}$ を掛けると $E_{12}$ になり $L$ から出る。これに対し第 2 行が零の集合では右からの積が閉じ、$E_{21}E_{11}=E_{21}$ により左からの積が閉じない。
:::

:::proposition[生成イデアル]{#prop-ring-generated-ideal}
$S\subset R$ を含む最小の両側イデアルは、$r,s\in R,\ a\in S$ を用いた $ras$ の有限和全体である。これを $(S)$ と書く。可換環では $\sum_j r_ja_j$ の形で十分である。特に可換環では $(a)=Ra$ であり、:term[単項イデアル]{en="principal ideal" yomi="たんこういである"} と呼ぶ。
:::

:::proof
有限和の差も有限和であり、負号を左の係数に入れれば逆元も入る。左右からの積は両端の係数に吸収され、各 $a=1a1$ が入る。$S$ を含むイデアルは吸収性と加法によってこれら全ての有限和を含む。可換なら $ras=(rs)a$ であり、右係数を $1$ にすれば逆の包含も得る。空和は $0$ とする。
:::

:::example[一つの成分から全体を生成する]
$R=M_2(\Q)$ で $E_{12}$ が生成する両側イデアルは $R$ である。$E_{i1}E_{12}E_{2j}=E_{ij}$ なので四つの行列単位を含み、対角成分の和 $E_{11}+E_{22}=1$ も含む。この計算は左イデアル $RE_{12}$ の場合には使えない。実際 $RE_{12}$ の第 1 列は零である。
:::

:::example[整数のイデアル]
$6\Z=(6)$ と $15\Z=(15)$ の両方を含むイデアルは $15-2\cdot6=3$ を含む。逆に $(3)$ は両者を含むので $(6,15)=(3)$ である。このように生成元を減らすには、新旧の各生成元を他方の線形結合で表せばよい。
:::

### 行列環と有限直積のイデアル

:::proposition[行列環の両側イデアル]{#prop-ring-matrix-ideals}
環 $R$ と $n\ge1$ について、$M_n(R)$ の両側イデアルは $R$ の両側イデアル $I$ に対する $M_n(I)$ に限る。
:::

:::proof
両側イデアル $J\subseteq M_n(R)$ に対して $I=\{a\in R\mid a E_{11}\in J\}$ と置く。差は閉じ、$ra E_{11}=(r E_{11})(a E_{11})$、$ar E_{11}=(a E_{11})(r E_{11})$ で吸収性が従う。$A\in J$ の任意の $(i,j)$ 成分 $a$ について $E_{1i}AE_{j1}=a E_{11}\in J$ なので $A\in M_n(I)$ である。逆に $a\in I$ なら $E_{i1}(a E_{11})E_{1j}=a E_{ij}\in J$ であり、その和で全ての $M_n(I)$ の元を得る。
:::

:::example[成分の最大公約数]
$M_2(\Z)$ の行列 $\begin{pmatrix}6&9\\15&0\end{pmatrix}$ が生成する両側イデアルを考える。行列単位で成分を $(1,1)$ に移せるため、そこには $9-6=3$ を置ける。一方、元の行列は全成分が $3$ の倍数であり、両側から整数行列を掛けてもその性質は保たれる。従って生成イデアルは $M_2(3\Z)$ であり、商の加法と積は成分ごとの還元で $M_2(\F_3)$ に移る。
:::

:::proposition[有限直積のイデアル]{#prop-ring-product-ideals}
有限直積 $\prod_{i=1}^n R_i$ の両側イデアルは $\prod_{i=1}^n I_i$ の形であり、$I_i$ は $R_i$ の両側イデアルである。
:::

:::proof
イデアル $J$ の第 $i$ 射影 $I_i$ は差に関して閉じ、任意の係数を第 $i$ 成分にもつ組を左右から掛けられるのでイデアルである。$a_i\in I_i$ を取ると $J$ のある元の第 $i$ 成分が $a_i$ である。第 $i$ 成分だけ $1$ の元を掛ければ、$a_i$ のみをもつ元も $J$ に属する。有限個の成分を足せば $\prod_i I_i\subseteq J$ となり、逆包含は射影の定義による。
:::

無限直積では、各成分でどの値も取れる有限台の元のイデアルがある。その各射影は環全体だが、非零環が無限個あれば単位元の組は有限台ではないためイデアルは真である。ここでは最後に行った有限和が無限和には使えない。

### 片側イデアルを行空間で分類する

行列を左から掛けると行の線形結合ができる。従って体上の行列環では、左イデアルの条件を許される行の集合で記述できる。列を固定する条件とは異なる点に注意する。

:::proposition[体上の行列環の左イデアル]{#prop-ring-left-matrix-ideals}
$K$ を体とする。$M_n(K)$ の左イデアルは、部分空間 $W\subseteq K^{1\times n}$ に対して、全ての行が $W$ に入る行列全体 $L_W$ の形である。$L_W$ の $K$ 上の次元は $n\dim_K W$ である。
:::

:::proof
$L_W$ では差を取っても行は $W$ に残り、左積の各行はもとの行の線形結合なので再び $W$ に属する。逆に左イデアル $L$ を取り、第一行として現れる行全体を $W$ と置く。行の引き算と左からのスカラー行列の乗法で $W$ は部分空間である。$A\in L$ の第 $i$ 行は $E_{1i}A$ の第一行になるので $L\subseteq L_W$ である。$w\in W$ を第一行として持つ $B\in L$ を取ると、$E_{j1}B$ は $j$ 行目が $w$ で他が零である。この操作を行数分だけ加えて $L_W\subseteq L$ を得る。行が独立に $W$ から選べることが次元の式を与える。
:::

:::example[二つの異なる左イデアル]
$M_2(\F_3)$ で $W=\F_3(1,1)$ なら $L_W$ は二列が等しい行列の集合である。一方、$U=\F_3(1,0)$ に対応する左イデアルの第二列は零である。両者の共通部分は零である。任意の行 $(a,b)$ は $(a-b,0)+(b,b)$ であるため、対応する二つの左イデアルの和は全体である。例えば $\begin{pmatrix}2&1\\0&2\end{pmatrix}$ は $\begin{pmatrix}1&0\\1&0\end{pmatrix}+\begin{pmatrix}1&1\\2&2\end{pmatrix}$ と一意に書ける。ここで第二の行の $-2$ を法 $3$ に直して $1$ にした。
:::

:::example[左イデアルを生成する行を取り出す]
$A=\begin{pmatrix}1&2&3\\2&4&6\\1&0&1\end{pmatrix}\in M_3(\Q)$ とする。左積で得られる各行は $(1,2,3)$ と $(1,0,1)$ の線形結合である。逆に任意の三行をそれらの線形結合として指定すると、組み合わせの係数を左因子の第一列と第三列に並べることで所望の行列を得る。この二つの行は第二成分で区別できるので一次独立である。従って $M_3(\Q)A$ は次元 $6$ である。ところが $A$ の一成分が $1$ であるため、両側から掛けて生成するイデアルは行列環全体である。
:::

:::example[整数係数の合同条件を行列に課す]
$M_2(\Z)$ で第一列と第二列の差が全成分で偶数となる行列全体を $L$ とする。差を取っても条件は保たれ、左積では列の差に左から同じ行列が掛かるので $L$ は左イデアルである。例えば $A=\begin{pmatrix}1&1\\0&2\end{pmatrix}$ は $L$ に入るが、$AE_{11}=\begin{pmatrix}1&0\\0&0\end{pmatrix}$ は入らない。両側イデアルを求めるときは、このような条件を係数ごとのイデアルにまで弱める必要がある。実際 $A$ の成分 $1$ を行列単位で取り出せば、$A$ の生成する両側イデアルは全体になる。
:::

:::example[一つの行列と可換な部分環]
$M_2(\Q)$ で $T=\begin{pmatrix}0&3\\2&0\end{pmatrix}$ とし、$HT=TH$ を満たす行列 $H$ の全体を調べる。$HT=TH$ と $JT=TJ$ なら $(H-J)T=T(H-J)$ であり、$(HJ)T=H(TJ)=T(HJ)$ である。単位行列も条件を満たすから、これは部分環である。

$H=\begin{pmatrix}u&v\\w&k\end{pmatrix}$ と書くと交換子は $\begin{pmatrix}2 v - 3 w&- 3 k + 3 u\\2 k - 2 u&- 2 v + 3 w\end{pmatrix}$ になる。従って $k=u$ かつ $2v=3w$ が必要十分である。$3$ で割って係数を求めると、$H=uI+\frac{v}{3}T$ と書ける。この表示は任意の $u,v$ を許す。従って可換な部分環を求める問題を、二つの係数に帰着できた。

例えば $I+T=\begin{pmatrix}1&3\\2&1\end{pmatrix}$ と $2T-3I=\begin{pmatrix}-3&6\\4&-3\end{pmatrix}$ の積はどちらの順序でも $\begin{pmatrix}9&-3\\-2&9\end{pmatrix}$ である。これは二元が共に $T$ の多項式であることと一致する。ただし元の行列環にはこの部分環に入らない行列がある。例えば $E_{11}$ では $u=1,k=0$ なので条件を満たさない。
:::

## イデアルの和・積・共通部分・商

### 和、積、共通部分

:::definition[イデアルの演算]{#def-ring-ideal-operations}
両側イデアル $I,J$ に対し $I+J=\{a+b\mid a\in I,\ b\in J\}$、$IJ=\{\sum_k a_kb_k\mid a_k\in I,\ b_k\in J\}$ と定める。$I\cap J$ もイデアルである。可換環では :term[イデアル商]{en="ideal quotient" yomi="いであるしょう"} を $(I:J)=\{r\in R\mid rJ\subseteq I\}$ と定める。
:::

:::proposition[包含と演算律]{#prop-ring-ideal-lattice}
$I+J$ は両方を含む最小のイデアル、$I\cap J$ は両方に含まれる最大のイデアルであり、$IJ\subseteq I\cap J$ である。積は結合的で、$(I+J)K=IK+JK$ および $K(I+J)=KI+KJ$ が成り立つ。可換環で $LJ\subseteq I$ と $L\subseteq(I:J)$ は同値である。
:::

:::proof
和と共通部分は、引き算と左右の吸収性で閉じる。和を含むべきイデアルが各 $a+b$ を含む事実と、共通部分の定義がそれぞれ最小性と最大性を与える。積は差に関して閉じ、左右からの積は有限和の各項の外側の因子に吸収できる。$ab$ は $I$ にも $J$ にも属するため $IJ\subseteq I\cap J$ である。$I(JK)$ と $(IJ)K$ はともに $abc$ の有限和である。$(a+b)c=ac+bc$ を展開すると $(I+J)K\subseteq IK+JK$ であり、$I,J\subseteq I+J$ から逆包含である。右の分配法則も同じ展開を反対側で行う。

可換環では $(r-s)J\subseteq I$ と $arJ\subseteq I$ がそれぞれ差と吸収性を示し、$0J\subseteq I$ なので $(I:J)$ はイデアルである。$L\subseteq(I:J)$ は各 $l\in L,j\in J$ について $lj\in I$ という条件である。$I$ は有限和に閉じるので積全体の包含と同値である。
:::

:::example[整数環での四つの演算]
$I=(12)$、$J=(18)$ とする。$18-12=6$ かつ両方が $6$ の倍数なので $I+J=(6)$ である。共通の倍数は $36$ の倍数であり $I\cap J=(36)$、これに対し $IJ=(216)$ である。最後に $12\mid18r$ は $2\mid 3r$、従って $2\mid r$ と同値なので $(I:J)=(2)$ である。
:::

:::example[一つの条件を消去する]
$R=\Q[x,y]$、$I=(x^2,xy)$ とする。$rx\in I$ なら $rx=ax^2+bxy$ と書け、係数比較で $x$ を消去して $r=ax+by$ となる。逆にこの形の $r$ なら $rx\in I$ なので $(I:(x))=(x,y)$ である。さらに $r(x,y)\subseteq I$ のためには $rx$ と $ry$ の両方を調べる。$ry\in I$ なら $x=0$ の代入で $r(0,y)y=0$ となり $x\mid r$、逆に $x\mid r$ なら両条件を満たす。従って $(I:(x,y))=(x)$ である。
:::

:::example[イデアルの四演算を並べて比較する]
正整数 $a,b$ を生成元とする二つのイデアルを取る。$ua+vb=d$ で $d=\gcd(a,b)$ となる係数 $u,v$ を選ぶと、和の生成元は $d$ である。正の共通倍数で最小のものは $ab/d$、積イデアルの生成元は $ab$ となる。商 $((a):(b))$ については $a\mid rb$ を $a/d\mid r(b/d)$ と書き直す。$a/d,b/d$ は互いに素なので、これは $a/d\mid r$ と同値である。

| $a$ | $b$ | $u$ | $v$ | 和 | 積 | 共通部分 | 商 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| $12$ | $30$ | $-2$ | $1$ | $6$ | $360$ | $60$ | $2$ |
| $35$ | $49$ | $3$ | $-2$ | $7$ | $1715$ | $245$ | $5$ |
| $8$ | $9$ | $-1$ | $1$ | $1$ | $72$ | $72$ | $8$ |
| $15$ | $60$ | $1$ | $0$ | $15$ | $900$ | $60$ | $1$ |
| $42$ | $70$ | $2$ | $-1$ | $14$ | $2940$ | $210$ | $3$ |
| $81$ | $27$ | $0$ | $1$ | $27$ | $2187$ | $81$ | $3$ |

$a=8,b=9$ の行では和が全環となり、積と共通部分の生成元が一致する。$a=15,b=60$ の行では $(60)\subseteq(15)$ であるから、共通部分は小さいイデアル $(60)$ であり、商は全環となる。生成元の正整数としての大きさと、イデアルの包含の向きが逆になることが、この二つの列に現れている。
:::

### イデアル演算の計算と商の向き

イデアル商で $J$ を大きくすると、$rJ\subseteq I$ の条件は厳しくなる。一方 $I$ を大きくすると条件は緩む。従ってどの変数に対して包含が反転するかを確認してから式を簡約する。

:::proposition[イデアル商と共通部分]{#prop-ring-colon-identities}
可換環で $(I:J+K)=(I:J)\cap(I:K)$、$(I\cap J:K)=(I:K)\cap(J:K)$、$((I:J):K)=(I:JK)$ が成り立つ。
:::

:::proof
$r(J+K)\subseteq I$ なら $J,K\subseteq J+K$ なので両方の条件を得る。逆に両方の条件を満たせば分配法則で和全体が $I$ に入る。第二の式では $rK$ が共通部分に入ることと、両方に入ることが同値である。第三の式の左辺は全ての $k\in K,j\in J$ について $rkj\in I$ という条件を課す。これは $I$ が有限和に閉じ、$JK$ がその積の有限和からなることにより右辺の条件と同値である。
:::

:::example[整数のイデアルを演算ごとに比較する]
$I=(84)$、$J=(30)$、$K=(14)$ とする。イデアル $I$ の元は $84$ の倍数である。積に属するかを調べる場合は、積の各項に含まれる共通の因子を取り出す。商を求める場合は向きが変わり、元 $r$ を指定した生成元に掛けて $I$ の中に入るかを調べる。

| 演算 | 元または生成元の条件 | 生成イデアル |
| --- | --- | --- |
| $I+J$ | $6=\gcd(84,30)$ | $(6)$ |
| $I\cap J$ | $84\mid r,\ 30\mid r$ | $(420)$ |
| $IJ$ | $84\cdot30\mid r$ | $(2520)$ |
| $(I:J)$ | $84\mid 30r$ | $(14)$ |
| $(I:JK)$ | $84\mid 420r$ | $(1)$ |

例えば $(I:J)$ では $84\mid 30r$ から共通因子 $6$ を両方から取り除く。残る ${84}/{6}$ と ${30}/{6}$ は互いに素なので、$r$ 自身が $14$ の倍数でなければならない。逆にその倍数なら生成元 $30$ を掛けた値が $I$ に入り、任意の $J$ の元でも条件が保たれる。

さらに $(I:J):K$ は $(14):(14)$ であり、同じ方法で $(1)$ となる。一方、最初に $JK=(420)$ を作ってから商を求めても、必要条件は $84\mid 420r$ であり、同じ $(1)$ を得る。元が満たすべき割り切り条件を書けば、括弧を移したときに比較すべきものが明確になる。
:::

:::example[分配法則が成立する場所を区別する]

## 剰余環

### 剰余類の演算

イデアル $I$ を零にしたいとき、$a-b\in I$ なら $a$ と $b$ を同じものとして扱う。積を代表元に依存させないには、差に左右両方から任意の元を掛けても $I$ にとどまる必要がある。

:::definition[剰余環]{#def-ring-quotient}
両側イデアル $I$ に対し、加法剰余類 $a+I$ の集合 $R/I$ に
$$
(a+I)+(b+I)=a+b+I,\qquad (a+I)(b+I)=ab+I
$$
を入れたものを :term[剰余環]{en="quotient ring" yomi="じょうよかん"} という。
:::

:::proof[剰余類の演算が定まる理由]
$a'-a,b'-b\in I$ なら加法の差はその和なので $I$ に入る。積の差は $a'b'-ab=(a'-a)b'+a(b'-b)$ であり、両側の吸収性から $I$ に入る。従って演算は代表元に依存しない。結合性と分配性は代表元の等式から従い、加法零元は $I$、逆元は $-a+I$、乗法単位元は $1+I$ である。逆に加法部分群 $I$ の類にこの積が定義できるなら、$i+I=0+I$ に $r+I$ を左右から掛けて $ri,ir\in I$ を得る。
:::

:::proposition[環の合同関係とイデアル]{#prop-ring-congruence-ideals}
環 $R$ 上の同値関係 $\sim$ が和と積に適合するとは、$a\sim a'$、$b\sim b'$ なら $a+b\sim a'+b'$、$ab\sim a'b'$ が成り立つことをいう。このとき $I=\{a\mid a\sim0\}$ は両側イデアルであり、$a\sim b$ と $a-b\in I$ は同値である。逆に任意の両側イデアル $I$ からこの条件で和と積に適合する同値関係を得る。
:::

:::proof
$a\sim b$ なら両辺に $-b$ を足して $a-b\sim0$ となる。逆向きは $b$ を足せばよい。特に $b\sim0$ から $0\sim-b$ となり、$a,b\sim0$ のとき $a-b\sim0$ が従う。$a\sim0$ に $r\sim r$ を左右から掛けると $ra,ar\sim0$ なので、$I$ は両側イデアルである。逆向きでは $a-b\in I$ は加法剰余類の一致であり、その類の和と積は上の構成により定まる。
:::

:::example[剰余の掛け算]
$\Z/(12)$ では $[7][9]=[63]=[3]$ である。$7$ の代表を $-5$ に、$9$ の代表を $-3$ に換えても $[-5][-3]=[15]=[3]$ となる。
:::

:::example[関係式による簡約]
$\Z[x]/(x^2+1)$ で $u=x+(x^2+1)$ と置くと $u^2=-1$ なので $(2+3u)(1-u)=5+u$ である。各多項式は $x^2$ 以上を $x^2=-1$ で順に置き換えて $a+bu$ になる。その表示の差 $a-a'+(b-b')x$ が $(x^2+1)$ に入るなら零である。非零の倍数は最高次項が消えず次数が $2$ 以上になるからである。
:::

:::example[定数項だけを残す]
任意の環 $R$ について $R[x]/(x)$ では $f$ の定数項だけが残る。差の定数項が零であることと差が $x$ の倍数であることは同じであり、積の定数項は定数項どうしの積である。同じ考え方で $R[x]/(x^3)$ には定数項、一次項、二次項が残り、積の三次以上を捨てて計算する。
:::

### 剰余での計算と冪等元による分解

剰余を具体的に計算するとき、代表元を一意に選べるとは限らない。整数の剰余では間隔をそろえ、多項式のモニックな関係式では次数を下げると、一意な代表が得られる。

:::example[法 20 で 8 が定める計算]
$R=\Z/(20)$ の元 $[8]$ による乗法を調べる。整数の等式 $(-2)\cdot 8+(1)\cdot 20=4$ を法 $20$ に移すと $[4]$ は $[8]$ の倍数である。逆に $4$ は $8$ を割るから、$([8])=([4])$ となる。従ってこのイデアルの元は $4$ の倍数類である。

二つの剰余類 $[b],[c]$ の差がこのイデアルに入る条件は $4\mid b-c$ である。この条件は、代表 $b,c$ を法 $20$ の別の代表で取り替えても変わらない。下表は商写像の各逆像を表す。

| 行の番号 | 法 20 の代表 |
| --- | --- |
| $0$ | $0$, $4$, $8$, $12$, $16$ |
| $1$ | $1$, $5$, $9$, $13$, $17$ |
| $2$ | $2$, $6$, $10$, $14$, $18$ |
| $3$ | $3$, $7$, $11$, $15$, $19$ |

商における $[2]^2$ は $[4]$ の行に入り、その番号は $0$ である。二つの元を足すときも、先に法 $20$ の代表で足してから $4$ で還元するか、先に行の番号をとってから足すかで結果は同じである。このため $R/([8])\cong\Z/(4)$ となる。もとの環から商へ移る際に一つにまとめられるのは、表の同じ行の元である。
:::

| --- | --- |
| $0$ | $0$, $6$, $12$, $18$ |
| $1$ | $1$, $7$, $13$, $19$ |
| $2$ | $2$, $8$, $14$, $20$ |

:::example[関係式 $x^2=2$ による積の簡約]

$f=2 x + 3$ の類を掛けると、定数係数と一次係数の列は $\begin{pmatrix}3&4\\2&3\end{pmatrix}$ を掛けたものになる。実際、$u^2=c$ と書けば $(a+bu)(A+Bu)=(aA+cbB)+(bA+aB)u$ である。列 $(1,0)^\top$ にこの行列を順に掛けた結果を、各冪の余りでも確かめる。

| 指数 | $f^j$ の余り | 定数係数 | 一次係数 |
| --- | --- | --- | --- |
| $0$ | $1$ | $1$ | $0$ |
| $1$ | $2 x + 3$ | $3$ | $2$ |
| $2$ | $12 x + 17$ | $17$ | $12$ |
| $3$ | $70 x + 99$ | $99$ | $70$ |
| $4$ | $408 x + 577$ | $577$ | $408$ |

:::

| 指数 | $f^j$ の余り | 定数係数 | 一次係数 |
| --- | --- | --- | --- |

## 環準同型と同型定理

### 準同型の核と像

:::definition[環準同型]{#def-ring-hom}
写像 $f\colon R\to S$ が加法、乗法、単位元を保つとき :term[環準同型]{en="ring homomorphism" yomi="かんじゅんどうけい"} という。全単射の準同型を環同型と呼ぶ。$\Ker f=\{a\mid f(a)=0\}$、$\Img f=\{f(a)\mid a\in R\}$ をそれぞれ核、像と呼ぶ。
:::

加法については :ref[thm-grp-first-iso] が使える。積についても同じ写像が演算を保つことを確認すれば、環の同型を得られる。

:::theorem[剰余の普遍性と第一同型定理]{#thm-ring-first-iso}
$f\colon R\to S$ を環準同型とする。$\Ker f$ は両側イデアルであり、$\Img f$ は $S$ の部分環である。$I\subseteq\Ker f$ なら $f$ は自然な射影 $\pi\colon R\to R/I$ を通してただ一通りに分解する。特に $R/\Ker f\cong\Img f$ である。
:::

:::proof
$f$ は加法群の準同型なので核は加法部分群である。$a$ が核に入ると $f(ra)=f(r)0=0=f(ar)$ なので両側イデアルとなる。像は差と積で閉じ、$f(1)=1$ を含む。$I\subseteq\Ker f$ なら $a+I=b+I$ から $f(a)=f(b)$ が従い、$\bar f(a+I)=f(a)$ が定まる。剰余環の演算式から $\bar f$ は準同型であり、$\pi$ の全射性から一意である。$I=\Ker f$ なら $\bar f(a+I)=0$ は $a\in I$ と同値なので $\bar f$ は単射であり、像への全射性は定義から従う。全単射の逆写像も、二元を元の環に戻して演算を適用すれば準同型である。
:::

:::theorem[イデアルの対応と二つの同型]{#thm-ring-ideal-correspondence}
$\pi\colon R\to R/I$ による像と逆像は、$I$ を含む両側イデアルと $R/I$ の両側イデアルの間の包含を保つ全単射である。$I\subseteq J$ のとき $(R/I)/(J/I)\cong R/J$ である。また部分環 $A\subseteq R$ と両側イデアル $I$ について $A/(A\cap I)\cong (A+I)/I$ である。
:::

:::proof
全射によるイデアルの像がイデアルなのは、掛ける元を前像に持ち上げてから吸収性を使えるためである。逆像は差と左右の積で閉じる。$J\supseteq I$ なら $\pi^{-1}(\pi(J))=J$ である。実際 $\pi(r)=\pi(j)$ なら $r=j+i$ と書ける。$\pi(\pi^{-1}(H))=H$ は全射性による。$r+I\mapsto r+J$ は $I\subseteq J$ により定まり、核が $J/I$、像が $R/J$ となる。最後に $A+I$ は $(a+i)(b+j)=ab+aj+ib+ij$ と差の閉性から部分環であり、$A$ から $R/I$ への制限の像は $(A+I)/I$、核は $A\cap I$ である。二つの写像に第一同型定理を適用する。
:::

:::example[整数からの写像と標数]
任意の環 $R$ に対し、$n\mapsto n1_R$ は環準同型である。分配法則で $(m1_R)(n1_R)=mn1_R$ となり、加法を保つことは整数倍の定義から従う。単位元を保つため他の準同型は存在しない。核が零なら :term[標数]{en="characteristic" yomi="ひょうすう"} を $0$ とし、核が非零ならその最小正元を標数とする。最小正元 $d$ がある場合、任意の核の元を $d$ で割った余りも核に入り、最小性から余りは零である。例えば $\Z/(4)\times\Z/(6)$ の核は $4$ と $6$ の公倍数全体なので標数は $12$ である。
:::

:::example[代入と核]
$\Q[x]\to\Q$、$f\mapsto f(2)$ は全射である。$x^j-2^j=(x-2)\sum_{k=0}^{j-1}x^{j-1-k}2^k$ から $f(x)-f(2)\in(x-2)$ である。逆に $(x-2)$ の元は $2$ で消える。従って $\Ker f=(x-2)$ と読め、$\Q[x]/(x-2)\cong\Q$ を得る。多変数でも、$x$ だけに値を代入すると核は $(x-a)$ であり、残りの変数をもつ環が像になる。
:::

### 環準同型を組み立てる二つの普遍性

いくつかの生成元の行き先から写像を作るとき、定義関係が行き先でも成立するかを調べる。関係式が保たれれば、剰余を通した写像を得る。

:::proposition[直積と剰余の写像]{#prop-ring-product-quotient-maps}
環準同型 $T\to R_i$ の族は、成分にそれらを持つ一意な環準同型 $T\to\prod_i R_i$ を定める。また $T\to R$ がイデアル $I$ を零に送るなら $T/I\to R$ に一意に下りる。
:::

:::proof
前半で準同型であることは各成分で確かめられ、値の組は全成分を指定すれば一意である。後半では $t+I$ の像を $t$ の像と定める。代表元の差は $I$ に入り、零に送られるので値に依存しない。加法、積、単位元については代表を使って計算すれば保たれる。射影が全射なので一意である。
:::

:::proposition[群環の普遍性]{#prop-ring-group-algebra-universal}
環準同型 $f\colon R\to T$ と群準同型 $\rho\colon G\to T^\times$ があり、各 $\rho(g)$ が $f(R)$ の全ての元と可換であるとする。このとき $f$ を延長し $[g]$ を $\rho(g)$ に送る環準同型 $R[G]\to T$ が一意に存在する。
:::

:::proof
$\sum_g a_g[g]$ を $\sum_g f(a_g)\rho(g)$ に送ると、加法と単位元を保つ。積については $f(a_g)\rho(g)f(b_h)\rho(h)=f(a_gb_h)\rho(gh)$ を全ての対について足す。各 $a_g[g]$ の像は係数と $[g]$ の像で決まるので、この写像は一意である。逆に環準同型は単元を単元に送り、$[g][h]=[gh]$ と $[g]a=a[g]$ を保つため、指定された二つの条件が必要である。
:::

:::example[係数の和を取る準同型]
前の命題で $T=R$、$f=\id$、$\rho(g)=1$ とすると、係数の和を取る準同型 $\varepsilon\colon R[G]\to R$ を得る。その核は $[g]-[e]$（$g\in G$）が生成する両側イデアルである。実際、$\sum_g a_g=0$ のとき $\sum_g a_g[g]=\sum_g a_g([g]-[e])$ であり、逆に各 $[g]-[e]$ は核に属する。群 $G$ が集合 $S$ で生成されるなら、核のイデアル生成元は $s\in S$ に絞れる。恒等式
$$
[gh]-[e]=[g]([h]-[e])+([g]-[e]),\qquad
[g^{-1}]-[e]=-[g^{-1}]([g]-[e])
$$
により、$S$ の元と逆元を順に掛けて得る全ての群元を扱えるからである。
:::

:::proposition[中心冪等元と直積分解]{#prop-ring-central-idempotent-product}
環 $R$ において中心に属する冪等元 $e$ に対し、$R\to eR\times(1-e)R$、$r\mapsto(er,(1-e)r)$ は環同型である。成分環の単位元はそれぞれ $e,1-e$ である。逆に $R$ が二環の直積に同型なら、第一成分だけが単位元である組の逆像は中心冪等元であり、上の構成がその直積分解を与える。
:::

:::proof
$e$ は中心に属するため、$er(es)=ers$ であり、$er$ に両側から $e$ を掛けても元に戻る。$1-e$ についても同じである。異なる成分の積は、$e(1-e)=(1-e)e=0$ であるため両順序で零になる。従って和を取る写像が環準同型になり、$er+(1-e)r=r$ と、各成分に $e$ または $1-e$ を掛けた結果から二つの写像は互いに逆である。直積では $(1,0)$ は中心冪等元であり、これと $(0,1)$ の乗法で各成分を抽出できる。直積同型を通してこれらの性質を $R$ に戻せば逆が従う。
:::

:::example[中心にない冪等元では積が残る]
$M_2(\Q)$ で $e=E_{11}$ とすると $E_{12}\in eR$、$E_{21}\in(1-e)R$ であるが、$E_{12}E_{21}=E_{11}\ne0$ である。従って足し算による分解だけから環の直積分解は得られない。一方 $R=\Z/(12)$ の $e=[4]$ は中心冪等元である。$eR$ は $[0],[4],[8]$ の三元で、$[4]$ を単位元として $\Z/(3)$ に同型である。$[1]-e=[9]$ に対応する成分は $[0],[3],[6],[9]$ の四元で、$\Z/(4)$ に同型である。この二つの成分を足すと元の剰余類を復元できる。
:::

:::example[固有値 2 の行列への代入]
$K=\Q$ とし、$N=E_{12}$ に対して $A=\begin{pmatrix}2&3\\0&2\end{pmatrix}$ と置く。$A=aI+bN$ と書くと $a=2,b=3$ である。$N^2=0$ かつ $b=3\ne0$ である。$aI$ は $N$ と可換なので、任意の多項式 $f$ について $f(x)$ を $x-a$ の冪で書き直し、$x-a$ の像を $bN$ にすればよい。次数 $2$ 以上の冪は全部零になる。

例えば $f=x^{5}$ を $(x-a)^2$ で割って得られる余りは $80 x - 128$ である。従って $f(A)=\begin{pmatrix}32&240\\0&32\end{pmatrix}$ となる。この式は $A$ を直接 $5$ 回掛けた結果と一致する。なぜならその展開でも、各項のうち $N$ を二回以上選ぶものが消えるからである。

一般に $f$ の余りを $c_0+c_1(x-a)$ と書けば、像は $c_0 I+c_1bN$ である。この行列が零なら対角成分から $c_0=0$、右上成分から $c_1=0$ となる。従って核は $((x-a)^2)$ である。逆に全ての $c_0,c_1$ を一次式で指定できるので、像は $K I+K N$ である。その積律は $(\alpha I+\beta N)(\gamma I+\delta N)=\alpha\gamma I+(\alpha\delta+\beta\gamma)N$ であり、核を使った剰余の積と一致する。
:::

:::example[固有値 -1 の行列への代入]

:::example[固有値 0 の行列への代入]
$K=\Q$ とし、$N=E_{12}$ に対して $A=\begin{pmatrix}0&5\\0&0\end{pmatrix}$ と置く。$A=aI+bN$ と書くと $a=0,b=5$ である。$N^2=0$ かつ $b=5\ne0$ である。$aI$ は $N$ と可換なので、任意の多項式 $f$ について $f(x)$ を $x-a$ の冪で書き直し、$x-a$ の像を $bN$ にすればよい。次数 $2$ 以上の冪は全部零になる。

例えば $f=x^{3}$ を $(x-a)^2$ で割って得られる余りは $0$ である。従って $f(A)=\begin{pmatrix}0&0\\0&0\end{pmatrix}$ となる。この式は $A$ を直接 $3$ 回掛けた結果と一致する。なぜならその展開でも、各項のうち $N$ を二回以上選ぶものが消えるからである。

:::example[基底元をすべて単位元に送る]
$G=C_3=\{e,g,g^2\}$ とし、$\Z[G]\to\Z$ を $\sum_{h\in G}a_h[h]\mapsto\sum_h a_h$ で定める。積の係数を合計すると $(\sum_h a_h)(\sum_k b_k)$ になるため、これは環準同型である。$a+b+c=0$ なら $a[e]+b[g]+c[g^2]=b([g]-[e])+c([g^2]-[e])$ であり、$[g^2]-[e]=([g]-[e])([g]+[e])$ である。従って核は $([g]-[e])$ である。逆向きの包含は $[g]-[e]$ の像が零であることによる。定数の像で全射性が分かり、従ってこの核での剰余は $\Z$ である。
:::

:::example[法 180 の冪等元と座標]
法 $M=180$ の元を法 $4,9,5$ での値の組に送る。この写像は成分ごとに和、積、単位元を保つ。全ての値が零なら各法の積 $180$ で割れるので、核は零である。逆に第 $i$ の法 $n_i$ を除いた積 $M_i=M/n_i$ を作る。$M_i$ と $n_i$ は互いに素なので、整数 $v_i$ を選んで $M_i v_i\equiv1\pmod{n_i}$ とできる。残りの法では $M_i v_i$ は零である。従って値の組 $(a_i)_i$ には $\sum_i a_i M_i v_i$ を割り当てられる。これで全射となり、成分ごとの演算を持つ積への同型を得る。


$R=\Z/(180)$ を相異なる素数の冪を法とする環の直積に移す。各成分で $e^2=e$ なら $e(e-1)=0$ である。整数の連続する二元は互いに素なので、素数冪はどちらか片方を割らなければならない。従って各成分の値は $0,1$ の二択である。このため次の表で冪等元を尽くす。

| $e$ の代表 | \bmod 4 | \bmod 9 | \bmod 5 |
| --- | --- | --- | --- |
| $0$ | $0$ | $0$ | $0$ |
| $1$ | $1$ | $1$ | $1$ |
| $36$ | $0$ | $0$ | $1$ |
| $45$ | $1$ | $0$ | $0$ |
| $81$ | $1$ | $0$ | $1$ |
| $100$ | $0$ | $1$ | $0$ |
| $136$ | $0$ | $1$ | $1$ |
| $145$ | $1$ | $1$ | $0$ |

ここから $e=[81]$ を選ぶ。$eR$ の元は $e$ の座標が零である全ての場所で零となる。逆に、その場所で零になる任意の組は $e$ を掛けても変わらないので $eR$ に入る。従って $eR$ の元は $20$ 個あり、$R/(e)$ は $9$ 個の元をもつ。

同じ議論を $1-e$ に適用すると、残りの座標との対応が得られる。実際、整数の最大公約数で生成元を取り直すと $(e)=([9])$ と $(1-e)=([20])$ である。両者の和は $1$ を含み、積は零である。各元は $e r+(1-e)r$ と書け、二項はそれぞれのイデアル成分に入るため、商を二つに分けて座標を復元できる。
:::

## 演習問題

::::exercise{level=basic}
$A=\begin{pmatrix}0&2\\0&0\end{pmatrix}$ とする。$A^2$ と $(1-A)^{-1}$ を求めよ。

:::solution
$A=2E_{12}$ で $E_{12}^2=0$ だから $A^2=0$ である。両方の順序で $(1-A)(1+A)=1-A^2=1$ となるので逆元は $\begin{pmatrix}1&2\\0&1\end{pmatrix}$ である。
:::
::::

::::exercise{level=basic}
$\Z/(18)$ で $5$ の逆元を求め、$6$ と $3$ が冪零か判定せよ。

:::solution
$5\cdot11=55=3\cdot18+1$ なので逆元は $11$ である。$6^2=36$ なので $6$ は冪零である。$3^m$ は全て奇数だから偶数である $18$ の倍数にはならず、$3$ は冪零でない。
:::
::::

::::exercise{level=basic}
$\Z$ で $(8)+(20)$、$(8)\cap(20)$、$(8)(20)$、$((8):(20))$ を求めよ。

:::solution
$20-2\cdot8=4$ かつ両生成元は $4$ の倍数なので和は $(4)$ である。共通の倍数は $40$ の倍数なので共通部分は $(40)$ である。積は $(160)$ である。最後に $8\mid20r$ は $2\mid5r$、すなわち $2\mid r$ と同値であり、イデアル商は $(2)$ である。
:::
::::

::::exercise{level=basic}
$\Z[x]/(x^2-2)$ で $u=[x]$ とし、$(1+2u)(3-u)$ を $a+bu$ の形で表せ。

:::solution
分配すると $3+5u-2u^2$ となり、$u^2=2$ を代入すると $-1+5u$ となる。$x^2-2$ がモニックなので、その非零倍の次数は少なくとも $2$ であり、この表示は一意である。
:::
::::

::::exercise{level=advanced}
環 $R$ と集合 $X$ に対し、$Y\subset X$ 上で零になる関数の $R^X$ におけるイデアルを $I_Y$ とする。生成元を一つ与え、剰余環を求めよ。

:::solution
$e(t)=0$ を $t\in Y$ で、$e(t)=1$ を $t\notin Y$ で定める。$fe$ は $Y$ で零であり、$Y$ で零の $f$ は $fe=f$ だから $I_Y=(e)$ である。制限 $R^X\to R^Y$ は全射である。任意の関数を $X\setminus Y$ 上で零に延長すればよい。その核は $I_Y$ なので剰余環は $R^Y$ である。
:::
::::

::::exercise{level=advanced}
体 $K$ 上の $M_n(K)$ の両側イデアルを全て求めよ。

:::solution
非零のイデアル $I$ から $A=(a_{ij})\ne0$ を取り、$a_{ij}\ne0$ を一つ選ぶ。任意の $p,q$ に対し $E_{pi}AE_{jq}=a_{ij}E_{pq}$ が $I$ に属する。左から $a_{ij}^{-1}1$ を掛けると $E_{pq}\in I$ となる。対角の行列単位を足すと $1\in I$ だから $I=M_n(K)$ である。零イデアルと環そのものが実際にイデアルであるため、これで全てである。
:::
::::

::::exercise{level=advanced}
可換環 $R$ で $((I:J):K)=(I:JK)$ を証明せよ。また $I=(60),J=(6),K=(4)$ で計算せよ。

:::solution
左辺への所属は、全ての $k\in K$ について $rk\in(I:J)$、つまり全ての $j,k$ について $rkj\in I$ と同値である。積イデアル $JK$ は $jk$ の有限和なので、これは右辺の所属条件と同値である。整数の場合は $60\mid6r$ が $10\mid r$ と同値であり、さらに $10\mid4r$ は $5\mid r$ と同値である。直接には $JK=(24)$ で $60\mid24r$ から同じく $5\mid r$ を得る。
:::
::::

::::exercise{level=advanced}
可換環の元 $e$ が $e^2=e$ を満たすとき、$R\cong R/(e)\times R/(1-e)$ を示せ。

:::solution
$a\mapsto (a+(e), a+(1-e))$ は準同型である。任意の代表 $x,y$ に対し $(1-e)x+ey$ が所望の像をもつので全射である。核の元 $a$ は $a=eb=(1-e)c$ と書ける。前者から $ea=a$、後者から $ea=0$ となり $a=0$ である。従ってこの全射は単射でもある。
:::
::::

::::exercise{level=basic}
$\Z/(48)$ で $[18]$ を掛ける写像の像と核を求めよ。また $[18]$ が冪零か判定せよ。
:::solution
$48=2^4\cdot3$ で、$\gcd(18,48)=6$ である。$3\cdot18-48=6$ と $18=3\cdot6$ により、像は $([6])$ である。$48\mid18b$ は $8\mid3b$、従って $8\mid b$ と同値だから、核は $([8])$ である。$18^4$ は $2^4$ と $3$ の両方で割れ、$18^3$ の $2$ の指数は $3$ なので、最初に零になるのは四乗である。
:::
::::

::::exercise{level=advanced}
環 $R$ の冪等元 $e$ に対し、$eR$ が $R$ の積で単位元 $e$ を持つ環となり、$r\mapsto re$ が $R\to eR$ の環準同型を定めるための必要十分条件が、$e$ が中心に属することであると示せ。
:::solution
写像が定義され、$e$ が $eR$ の単位元なら $re\in eR$ なので $re=e(re)=ere$ となる。他方、$er\in eR$ なので $er=(er)e=ere$ となる。従って $re=er$ である。逆に $e$ が中心にあれば両集合は等しく、$e$ はその両側単位元である。さらに $(re)(se)=rse$ なので積を保つ。加法と単位元もそれぞれ分配法則と $1e=e$ により保つ。
:::

イデアルは定義により加法部分群であり、左右の吸収性により剰余類の積が定まる。真のイデアルが $1$ を含めば $r=r1$ により環全体になる。同様に単元を一つでも含めばその逆元を掛けて $1$ が得られる。$(2)\subset\Z$ が非零の真のイデアルの例である。

$\Z/(12)$ における $[7]$ の逆元を $0$ 以上 $11$ 以下の整数で答えよ。

::::quiz
$\Q[x]\to\Q$ の $x=3$ での評価の核はどれか。

- [ ] $(3x)$
- [ ] $(x)$
- [x] $(x-3)$
- [ ] $(x+3)$

:::explanation
任意の $j\ge1$ について $x^j-3^j$ は $x-3$ の倍数なので、$f(3)=0$ なら $f=f-f(3)\in(x-3)$ である。逆に $x-3$ の倍数は全て評価で零になる。残りの選択肢の生成元を $3$ で評価するとそれぞれ $9,3,6$ となる。
:::

::::quiz{answer="30" tol="1e-9"}
$\Z/(6)\times\Z/(10)$ の標数はいくつか。

:::explanation
単位元の $n$ 倍が零になるには $6\mid n$ と $10\mid n$ が必要十分である。最小の正の公倍数は $30$ なので標数は $30$ である。
:::

::::quiz{answer="8" tol="1e-9"}
環 $\Z/(48)$ で $[18]$ の乗法の像には何個の剰余類があるか。
:::explanation
$\gcd(18,48)=6$ であり、$3\cdot18-48=6$ なので、像は法 $48$ の $6$ の倍数類全体である。$0,6,\ldots,42$ が相異なる代表であり、個数は $48/6=8$ である。
:::
