## この章の目標

- 完全性と分裂を定義し、短完全列の分裂条件を証明する。
- 図式追跡で五項補題と蛇の補題を証明する。
- Hom の左完全性とテンソル積の右完全性を区別する。
- 生成元と関係式からテンソル積を計算し、係数を拡大する。

## 完全列と分裂完全列

以下、$R$ は単位元をもつ環とする。特に断らない限り、準同型は左 $R$ 加群の間のものとする。

### 一つ前の像が次の核を尽くす

:::definition[完全列]{#def-ring-exact-sequence}
準同型の列で各中間項における「前の写像の像」と「次の写像の核」が等しいとき、:term[完全列]{en="exact sequence" yomi="かんぜんれつ"} という。形が $0\to A\xrightarrow{i}B\xrightarrow{p}C\to0$ の完全列を :term[短完全列]{en="short exact sequence" yomi="たんかんぜんれつ"} という。これは $i$ が単射、$p$ が全射、$\Img i=\Ker p$ であることを意味する。$u\colon A\to B$ の :term[余核]{en="cokernel" yomi="よかく"} は $B/\Img u$ であり、以後 $\operatorname{coker}u$ と書く。
:::

:::theorem[分裂の判定]{#thm-ring-splitting}
短完全列について、$ps=1_C$ となる $s\colon C\to B$ があること、$ri=1_A$ となる $r\colon B\to A$ があること、$B\cong A\oplus C$ が $i,p$ と整合して成り立つことは同値である。このとき列は :term[分裂]{en="split exact" yomi="ぶんれつ"} するという。
:::

:::proof
$s$ があれば $b-s(p(b))$ が $\Ker p$ に属する。従って $i(a)+s(c)$ の形に書け、$p$ を適用すると $c$ が決まり、$i$ の単射性で $a$ も決まる。よって $(a,c)\mapsto i(a)+s(c)$ は整合する同型である。これがあれば $A$ への射影から $r$ を作れる。$r$ があれば $B=\Img i\oplus\Ker r$ である。実際 $b=i(r(b))+(b-i(r(b)))$ と分けられ、共通部分は $ri=1$ から零である。$p$ を $\Ker r$ に制限すると単射であり、任意の $p(b)$ は $b-i(r(b))$ の像でもあるから全射である。この制限の逆を $s$ とする。
:::

:::example[分裂しない二つの巡回群の間の列]
$0\to\Z/(2)\xrightarrow{[a]\mapsto[2a]}\Z/(4)\to\Z/(2)\to0$ は完全である。最後の射影は法 $2$ への還元で、核の二元が包含の像である。ただし $[1]$ を持ち上げる元は $[1],[3]$ で、どちらも $2$ 倍すると $[2]\ne0$ になる。準同型による持ち上げなら $2$ 倍は零でなければならないので、分裂しない。
:::

### 短完全列を別の端に沿って移す

:::proposition[引き戻しと押し出し]{#prop-ring-pullback-pushout}
短完全列 $0\to A\xrightarrow{i} B\xrightarrow{p} C\to0$ を取る。$f\colon C'\to C$ に対して
$$
B_f=\{(b,c')\in B\oplus C'\mid p(b)=f(c')\}
$$
から短完全列 $0\to A\to B_f\to C'\to0$ を得る。また $g\colon A\to A'$ に対して
$$
B_g=(B\oplus A')/\{(i(a),-g(a))\mid a\in A\}
$$
から短完全列 $0\to A'\to B_g\to C\to0$ を得る。前者を :term[引き戻し]{en="pullback" yomi="ひきもどし"}、後者を :term[押し出し]{en="pushout" yomi="おしだし"} という。
:::

:::proof
$B_f$ は二つの準同型の差の核であり、$C'$ への射影は $p$ の全射性で全射である。核は $(i(a),0)$ の全体で、この $a$ は $i$ の単射性で一意である。任意の対象 $X$ から $B,C'$ への二写像が $C$ の上で一致すれば、その組の像は $B_f$ に入り、射影に合う写像を一意に与える。

$B_g$ では $(b,a')\mapsto p(b)$ が関係を零にするので商に降り、全射である。核の元では $b=i(a)$ とでき、その類は $(0,a'+g(a))$ の類である。$(0,a')$ が関係として零なら $i(a)=0$ なので $a=0$、従って $a'=0$ である。これで $A'$ の像が核に一致する。$B,A'$ から $X$ への写像が $A$ 上で一致するなら、二写像の和は関係を消して $B_g$ に一意に降りる。
:::

:::example[分裂しない列が引き戻しで分裂することがある]
$0\to\Z\xrightarrow{4}\Z\to\Z/(4)\to0$ を $f\colon\Z\to\Z/(4)$、$n\mapsto[2n]$ に沿って引き戻す。$B_f=\{(b,n)\mid b-2n\in4\Z\}$ なので $B_f$ の各元は $(4a+2n,n)$ と一意に書ける。従って $\Z\to B_f$、$n\mapsto(2n,n)$ が最後の射影の右逆である。元の列では $[1]$ を $\Z$ へ群準同型で持ち上げられない。引き戻しでは生成元に課す周期の関係が変わるため、この違いが生じる。
:::

### 短完全列で射影と切断を作る

:::proposition[切断の差と準同型]{#prop-ring-sections-difference}
$0\to A\xrightarrow{i}B\xrightarrow{p}C\to0$ が分裂するとする。一つの切断 $s_0\colon C\to B$ を固定すると、他の切断は $s_0+i f$（$f\in\Hom_R(C,A)$）と一意に書ける。
:::

:::proof
$s,s_0$ が切断なら $p(s-s_0)=0$ なので、差の像は $\Ker p=\Img i$ に入る。$i$ は $A$ とその像の同型なので、$s-s_0$ を $A$ への準同型 $f$ として一意に書き直せる。逆に $p(s_0+i f)=p s_0=\id_C$ なので、どの $f$ からも切断が得られる。
:::

:::example[同じ商を持ち上げる方法を数える]
$B=\Z/(6)\oplus\Z/(9)$、$p$ を第二成分への射影とする。切断は $[a]\mapsto([ja],[a])$ である。第一成分で代表に依らない条件は $6\mid9j$、すなわち $2\mid j$ である。従って $j=0,2,4$ の三通りである。例えば $j=2$ を選んだときの左への射影は $([b],[a])\mapsto[b-2a]$ である。第一成分の包含の後にこの射影を取ると恒等である。切断が定まれば、商の持ち上げを引いた分が左端になる。
:::

:::example[台を変えて完全性を確かめる]
$\Z^3\to\Z$ を $p(a,b,c)=2a+3b+6c$ とする。$s(1)=(-1,1,0)$ なら $p s(1)=1$ なので全射である。核の条件は $2a=-3b-6c$ であり、右辺が偶数になるため $b=2j$ と書ける。すると $a=-3j-3c$ であるから、核の基底は $(-3,2,0),(-3,0,1)$ である。任意の元から $p(a,b,c)$ 倍の $s(1)$ を引くと核の元になり、逆に核の座標と最後の値を足し合わせて戻せる。従って三列を並べると $\Z^3$ の基底になる。この操作は列の全単射を元の完全性から構成している。
:::

:::example[全射でも切断の有無は異なる]
$\Z/(12)\to\Z/(4)$ を代表の還元で定める。これは全射であり、核は $0,4,8$ の三元である。$[1]$ の前像は $1,5,9$ であり、その $4$ 倍を法 $12$ に直すと順に $4,8,0$ になる。従ってこの場合は切断があり $1\mapsto9$ で定まる。一方 $\Z/(16)\to\Z/(4)$ の前像は $1,5,9,13$ で、どの $4$ 倍も法 $16$ で $4$ になる。従ってこちらは分裂しない。どちらも整数で $1$ を持ち上げられるが、さらに商の関係式 $4[1]=0$ を保つことが必要である。
:::

### 完全列を核と余核で分割する

:::proposition[長い完全列の短完全列による記述]{#prop-ring-cycle-short-sequences}
合成が零の写像列 $\cdots\xrightarrow{d_{i-1}}C_i\xrightarrow{d_i}C_{i+1}\to\cdots$ を取る。$B_i=\Img d_{i-1}$、$Z_i=\Ker d_i$ と置く。この列が完全であることと、各 $i$ で $0\to B_i\to C_i\xrightarrow{d_i}B_{i+1}\to0$ が短完全であることは同値である。
:::

:::proof
合成が零なので $B_i\subseteq Z_i$ である。制限した $d_i$ の値域は、$B_{i+1}$ の定義によって全体であり、その核は $Z_i$ のままである。従って短完全性のうち、中央だけを確認すればよく、その条件は $B_i=Z_i$ である。逆に各中央で等しければ元の列が完全になる。
:::

:::example[周期的な列で完全性を各段で確かめる]
$R=\Q[t]/(t^2)$ で $\cdots\xrightarrow{t}R\xrightarrow{t}R\xrightarrow{t}R\xrightarrow{t}\cdots$ とする。$t^2=0$ により合成は零である。$t(a+bt)=at$ なので核は $(t)$、像も $(t)$ であり、各段で完全になる。しかし対応する短完全列の右端 $(t)$ を $R$ に持ち上げる切断は存在しない。右端の $t$ の前像は $1+bt$ であるから、どれも $t$ を掛けると $t$ になる。準同型であれば右端の $t$ は $t$ 倍で零になるという関係を保つ必要があり、矛盾する。完全性を各段で確認できても、射影を用いて一段ずつ直和にはできない。
:::

:::example[合成が零でも完全性が足りない場合]
$R=\Z/(12)$ 上で $R\xrightarrow{6}R\xrightarrow{4}R$ とする。$4\cdot6=24=0$ だから連続した合成は零である。$6$ 倍の像は $\{[0],[6]\}$ で、$4$ 倍の核は $\{[0],[3],[6],[9]\}$ である。従って像が核の中に真に含まれる。核を像で割った商は $[3]$ の類が生成し、$2[3]=[6]$ は消えるが $[3]$ は消えないので法 $2$ の加群である。完全性が壊れた分を測るには、合成が零であることを確認してからこの商を作る。
:::

## 五項補題と蛇の補題

### 可換図式で元の行き先を追う

:::theorem[五項補題]{#thm-ring-five-lemma}
完全な二列 $A_1\to A_2\to A_3\to A_4\to A_5$ と $B_1\to B_2\to B_3\to B_4\to B_5$ の間の縦写像を $f_i$ とし、各四角形が可換とする。$f_1$ が全射で $f_2,f_4$ が同型、$f_5$ が単射なら $f_3$ は同型である。
:::

:::proof
単射性では $a_3\in\Ker f_3$ を取る。その右像は $f_4$ で零になるため零で、$a_3$ は $a_2$ から来る。$f_2(a_2)$ の右像は零なので、ある $b_1$ から来る。$f_1$ の全射で $b_1$ を $a_1$ に持ち上げ、$a_2$ から $a_1$ の右像を引くと $f_2$ の核に入る。これは零なので $a_3$ は $a_1$ の二つ先への像、すなわち零である。

全射性では $b_3$ の右像を $f_4$ によって $a_4$ に持ち上げる。$a_4$ の右像を $f_5$ に送ると $b_3$ の二つ先への像で零であり、単射性で $a_4$ の右像は零である。よって $a_4$ は $a_3$ から来る。$b_3-f_3(a_3)$ は右で零になるので $b_2$ から来る。$b_2$ を $a_2$ に持ち上げて、その右像を $a_3$ に加えれば $b_3$ を得る。
:::

:::theorem[蛇の補題]{#thm-ring-snake}
次の図式で各行は短完全であり、二つの四角形は可換であるとする。
$$
\begin{array}{ccccccccc}
0&\to&A&\xrightarrow{i}&B&\xrightarrow{p}&C&\to&0\\
&&\downarrow f&&\downarrow g&&\downarrow h\\
0&\to&A'&\xrightarrow{i'}&B'&\xrightarrow{p'}&C'&\to&0
\end{array}
$$
このとき自然な写像と連結準同型 $\delta$ により
$$
0\to\Ker f\to\Ker g\to\Ker h\xrightarrow{\delta}
\operatorname{coker}f\to\operatorname{coker}g\to\operatorname{coker}h\to0
$$
が完全になる。
:::

:::proof[連結準同型の構成]
$c\in\Ker h$ を $b\in B$ に持ち上げる。$p'g(b)=h(c)=0$ なので $g(b)=i'(a')$ となる $a'$ が一意に存在する。$\delta(c)=[a']$ と置く。別の持ち上げとの差は $i(a)$ なので $a'$ の差は $f(a)$ であり、剰余類は変わらない。和やスカラー倍の持ち上げは選んだ持ち上げの和やスカラー倍にできるので準同型である。核の間の写像は $i,p$ の制限、余核の間の写像は $i',p'$ の誘導写像であり、可換性で定義できる。
:::

:::proof[完全性]
左端は $i$ が単射である。$b\in\Ker g$ で $p(b)=0$ なら $b=i(a)$ であり、$i'f(a)=g(b)=0$ から $f(a)=0$ になるので $\Ker g$ で完全である。$c\in\Ker h$ の $\delta(c)$ が零なら、構成中の $a'$ は $f(a)$ と書け、持ち上げを $b-i(a)$ に修正すると $\Ker g$ に入る。逆に $\Ker g$ から来るときは $a'=0$ とできる。

$[a']$ が余核の次の項で零なら $i'(a')=g(b)$ である。$h(p(b))=0$ かつ $\delta(p(b))=[a']$ となる。逆に構成から $\delta$ の像は次の写像で零になる。$[b']$ が $\operatorname{coker}h$ で零なら $p'(b')=h(c)$ と書ける。$c=p(b)$ として $b'-g(b)$ を取ると $p'$ の核に入るので $i'(a')$ と書ける。逆に $i'$ の像は $p'$ で零になる。最後の全射性は $p'$ の全射性から従う。
:::

:::example[連結写像が非零になる]
上下に $0\to\Z\xrightarrow{\,4\,}\Z\to\Z/(4)\to0$ を並べ、縦写像を全て $2$ 倍にする。左と中央の核は零、右の核は $[2]$ の生成する二元である。$[2]$ を整数 $2$ に持ち上げ、縦に $2$ 倍して $4$ を得る。下段の $4$ 倍で戻した値は $1$ なので、$\delta([2])=[1]\in\Z/(2)$ である。
:::

:::corollary[蛇の補題で必要な端の条件]{#cor-ring-snake-general-rows}
可換図式の上段が $A\xrightarrow{i}B\xrightarrow{p}C\to0$、下段が $0\to A'\xrightarrow{i'}B'\xrightarrow{p'}C'$ として完全なら、同じ構成で六項列 $\Ker f\to\Ker g\to\Ker h\to\operatorname{coker} f\to\operatorname{coker} g\to\operatorname{coker} h$ は内側の四項で完全である。上段の $i$ も単射なら左に $0$ を、下段の $p'$ も全射なら右に $0$ を付けられる。
:::

:::proof
$c$ の持ち上げに必要なのは上段の $p$ の全射性であり、その像を下段の左に戻した $a'$ の一意性に必要なのは $i'$ の単射性である。持ち上げを変えた差が $i(a)$ となるのは上段の中央での完全性による。内側の四項の完全性の追跡には、この三条件と下段の中央での完全性だけを使う。端の単射性と全射性はそれぞれ $i$ と $p'$ が持つ場合に、その制限と剰余への誘導写像にも引き継がれる。
:::

:::remark[連結準同型の自然性]
二つの蛇の図式の間に、全ての矢印と可換な準同型があるとする。最初の図式で $c$ の持ち上げ $b$ を選んで $g(b)=i'(a')$ と書くと、第二の図式で対応する $b$ の像が $c$ の像の持ち上げになる。さらに、その縦写像での像は $a'$ の像を下段の包含に送ったものである。従って先に連結写像を取ってから余核へ移しても、先に核へ移してから連結写像を取っても同じ類を得る。
:::

:::example[整数の図式で連結準同型をまとめて求める]
二列とも $0\to\Z\xrightarrow{n}\Z\to\Z/(n)\to0$ とし、全ての縦写像を $k$ 倍にする。$n,k>0$ とする。$d=\gcd(n,k)$ とすると、右の縦写像の核は $[n/d]$ が生成し、位数は $d$ である。連結写像では生成元を整数 $n/d$ へ持ち上げ、その $k$ 倍を下段の $n$ 倍で戻すので、$\delta([n/d])=[k/d]\in\Z/(k)$ となる。

| $n$ | $k$ | 右の核の位数 | 核の生成元 | 連結写像の像 |
| --- | --- | --- | --- | --- |
| $8$ | $2$ | $2$ | $4$ | $1$ |
| $8$ | $4$ | $4$ | $2$ | $1$ |
| $12$ | $8$ | $4$ | $3$ | $2$ |
| $12$ | $15$ | $3$ | $4$ | $5$ |
| $15$ | $5$ | $5$ | $3$ | $1$ |
| $18$ | $6$ | $6$ | $3$ | $1$ |
| $24$ | $18$ | $6$ | $4$ | $3$ |

$[k/d]$ の位数も $d$ なので連結写像は単射である。左と中央の縦写像の核が零であることにも合う。例えば $(n,k)=(12,8)$ では $[3]$ を整数 $3$ に持ち上げて $24$ を得る。これは $12$ の二倍なので返す値は $[2]\in\Z/(8)$ である。ここで返す値の法 $8$ は縦写像から来ており、右端の法 $12$ とは由来が異なる。
:::

### 接続写像の順序と剰余を計算する

:::example[持ち上げて境界写像を計算する]
上段と下段に $0\to\Z\xrightarrow{12}\Z\to\Z/(12)\to0$ を置く。縦の全写像を $8$ 倍とすれば、整数の積が可換なので図式は可換である。初めの二つの縦写像の核は零であり、余核はそれぞれ $\Z/(8)$ である。第三の縦写像の核は $12\mid 8r$ を満たす $[r]$ である。

各 $[r]$ を整数 $r$ として上段中央に持ち上げる。縦に $8$ 倍した値は $12$ の倍数だから、下段左からの像として一意に $8r/12$ を得る。この元を縦写像の余核、すなわち法 $8$ に移した値が接続写像である。

| $r$ | $kr$ | 下段左での代表 | 接続写像の値 |
| --- | --- | --- | --- |
| $0$ | $0$ | $0$ | $0$ |
| $3$ | $24$ | $2$ | $2$ |
| $6$ | $48$ | $4$ | $4$ |
| $9$ | $72$ | $6$ | $6$ |

持ち上げを $r+12z$ に変えると下段左の元は $8z$ だけ変わる。従って右端の値は変わらない。接続写像の像は法 $8$ の $2$ の倍数全体であり、これは余核の上で $12$ 倍して零になる類と一致する。実際、法 $8$ において $12u=0$ は $2\mid u$ と同値である。このように元の列の完全性に加え、接続写像の像と次の核も具体的に照合できる。
:::

:::example[持ち上げて境界写像を計算する]
上段と下段に $0\to\Z\xrightarrow{18}\Z\to\Z/(18)\to0$ を置く。縦の全写像を $12$ 倍とすれば、整数の積が可換なので図式は可換である。初めの二つの縦写像の核は零であり、余核はそれぞれ $\Z/(12)$ である。第三の縦写像の核は $18\mid 12r$ を満たす $[r]$ である。

各 $[r]$ を整数 $r$ として上段中央に持ち上げる。縦に $12$ 倍した値は $18$ の倍数だから、下段左からの像として一意に $12r/18$ を得る。この元を縦写像の余核、すなわち法 $12$ に移した値が接続写像である。

| $r$ | $kr$ | 下段左での代表 | 接続写像の値 |
| --- | --- | --- | --- |
| $0$ | $0$ | $0$ | $0$ |
| $3$ | $36$ | $2$ | $2$ |

### 五項補題から単射と全射を個別に取り出す

:::proposition[四項での単射・全射の判定]{#prop-ring-four-lemma}
二行の完全列 $A\to B\to C\to D$ があり、縦写像を左から $a,b,c,d$ として可換とする。

1. $a$ が全射で $b,d$ が単射なら、$c$ は単射である。
2. $a,c$ が全射で $d$ が単射なら、$b$ は全射である。
:::

:::proof
最初に $v\in\Ker c$ が $C\to D$ で消えるなら $v$ を $B$ の $u$ に持ち上げられる。$b(u)$ は下段で $C$ に行くと零なので、下段の $A$ から来る。$a$ の全射性で上段の $A$ に戻し、その $B$ での像を $u$ から引けば、差は $b$ で零になる。$b$ の単射性から差が零となり、$v=0$ である。$d$ が単射なら $v\in\Ker c$ の $D$ での像は $d$ で零なので消え、最初の場合を適用できる。

全射の主張では下段の $B$ の元 $u'$ を取る。その $C$ での像を $v'$ とし、$c$ の全射性で上段の $v$ を取る。$v$ の $D$ での像は $d$ を通すと零であり、$d$ の単射性からすでに零である。従って上段の $B$ の $u$ に戻せる。$u'-b(u)$ は下段の $C$ に送ると零なので、その前の $A$ の像である。$a$ が全射なので上段の $A$ の元を求め、その $B$ での像を $u$ に加えれば $u'$ を持ち上げられる。
:::

:::example[単射を仮定した端の何を使うか]
二行とも $\Z/(6)\xrightarrow{2}\Z/(6)\xrightarrow{3}\Z/(6)\xrightarrow{2}\Z/(6)$ とする。$2$ 倍の像は偶数類、$3$ 倍の核も偶数類である。$3$ 倍の像は $\{[0],[3]\}$ で、次の $2$ 倍の核に等しい。縦の全写像に $5$ 倍を取れば可換で、$5$ は逆元 $5$ を持つので両方の判定が適用できる。他方、同じ行に対して縦を一律 $2$ 倍にすると $D$ の縦写像は単射でない。例えば上段の $[3]$ は $B$ でも $C$ でも縦で消える。五項や四項の補題に数値を入れるとき、縦の端の単射・全射の条件は元の列が完全であることからは得られない。
:::

## Hom 関手と左完全性

### Hom の変数と矢印の向き

加群 $X$ を固定し、$\Hom_R(X,-)$ は写像に後合成を、$\Hom_R(-,X)$ は前合成を対応させる。後合成は同じ向き、前合成は反対向きである。双方とも恒等写像を恒等写像に送り、合成を対応する順で保つので関手である。値は Abel 群であり、$R$ が可換なら値に $R$ 加群の構造も入る。

:::theorem[Hom の左完全性]{#thm-ring-hom-left-exact}
短完全列 $0\to A\to B\to C\to0$ に対し
$$
\begin{aligned}
0&\to\Hom_R(X,A)\to\Hom_R(X,B)\to\Hom_R(X,C),\\
0&\to\Hom_R(C,X)\to\Hom_R(B,X)\to\Hom_R(A,X)
\end{aligned}
$$
は完全である。
:::

:::proof
一列目の初めの単射性は $A\to B$ の単射性から点ごとに従う。$X\to B$ の合成が $C$ で零なら像が $A$ に入るので、一意に $A$ へ値を取る写像に戻せる。逆の包含は元の合成が零であることによる。二列目の初めの単射性は $B\to C$ の全射性から従う。$B\to X$ の制限が $A$ で零なら剰余 $C$ を通して一意に分解し、逆に $C$ を通して分解する写像は $A$ で零である。
:::

:::example[末尾が全射にならない]
分裂しない列 $0\to\Z/(2)\to\Z/(4)\to\Z/(2)\to0$ で $X=\Z/(2)$ を取る。$\Hom_\Z(X,\Z/(4))$ の各像は $[0]$ または $[2]$ に含まれ、射影に合成すると零である。反変の場合も $\Hom_\Z(\Z/(4),X)$ の各写像は $[2]$ を零にするため、包含との合成はいつも零である。
:::

:::example[単射になる向きを Hom で確かめる]
$0\to\Z\xrightarrow{6}\Z\to\Z/(6)\to0$ に $X=\Z/(4)$ を固定する。$\Hom_\Z(-,X)$ で $\Hom(\Z,X)\cong X$ と同定すると、真ん中の写像は前合成で $6$ 倍になる。$X$ の $6$ 倍の核は $[0],[2]$ である。一方 $\Hom(\Z/(6),X)$ の写像の $[1]$ の像は $6$ 倍で消える元に限られ、像の候補も $[0],[2]$ である。従って左完全性はこの二集合の一致として見える。最後の $6$ 倍は $[1]$ を像に含まないので全射ではない。
:::

## テンソル積の構成と普遍性

### 双線形な規則を一つの線形写像にする

:::definition[テンソル積]{#def-ring-module-tensor}
右 $R$ 加群 $M$ と左 $R$ 加群 $N$ から、集合 $M\times N$ 上の自由 Abel 群を作る。その基底元を $[m,n]$ と書き、次の元が生成する部分群で割る。
$$
\begin{aligned}
[m+m',n]-[m,n]-[m',n],\\
[m,n+n']-[m,n]-[m,n'],\\
[mr,n]-[m,rn].
\end{aligned}
$$
得られる :term[テンソル積]{en="tensor product" yomi="てんそるせき"} を $M\otimes_R N$、基底元の像を $m\otimes n$ と書く。各変数に加法的で最後の等式を満たす写像を平衡写像と呼ぶ。
:::

:::theorem[テンソル積の普遍性]{#thm-ring-tensor-universal}
Abel 群 $L$ への平衡写像は、$M\otimes_R N\to L$ の群準同型をただ一つ定める。また可換環 $R$ の場合には $r(m\otimes n)=rm\otimes n=m\otimes rn$ で $R$ 加群となり、$R$ 加群 $L$ への $R$ 双線形写像は $R$ 線形な写像を定める。
:::

:::proof
各 $[m,n]$ を指定した値に送ると、自由群からの写像が定まる。三種の関係式を零にすることが平衡の条件なので剰余へ降り、純テンソルが生成するため一意である。可換環で第 1 成分を $r$ 倍する操作は三種の関係を保つ。特に $(rm)s=r(ms)$ と $rsm=srm$ により平衡関係を保つ。公理は生成元で確認でき、第 2 成分との一致は平衡による。双線形写像の延長はこのスカラー倍を保つ。
:::

準同型 $f,g$ に対し $f(m)\otimes g(n)$ は平衡なので $f\otimes g$ が定まる。恒等や合成の規則は純テンソルでの一致から従う。可換環では $m\otimes n\mapsto n\otimes m$ が関係を保ち、逆も同じ交換である。また $(L\otimes M)\otimes N\cong L\otimes(M\otimes N)$ は $(l\otimes m)\otimes n\mapsto l\otimes(m\otimes n)$ で与えられる。右辺は $l,m,n$ の各変数で加法的で隣接係数を移せるので、普遍性を二度使って定義できる。逆向きも同様に定義でき、純テンソルに対する両合成が恒等である。

:::example[係数を片側に動かす]
$\Z$ 上では $(2[1])\otimes[1]=[1]\otimes(2[1])$ である。$\Z/(4)\otimes_\Z\Z/(6)$ では $t=[1]\otimes[1]$ が全体を生成し、$4t=6t=0$ なので $2t=0$ となる。平衡写像 $([a],[b])\mapsto[ab]\in\Z/(2)$ は $t$ を非零に送るため $t$ の位数はちょうど $2$ である。
:::

:::example[非零元の純テンソルが零になる例]
$M=\Z/(2)$、$N=\Z/(3)$ で $t=[1]\otimes[1]$ を考える。$2t=[2]\otimes[1]=0$、$3t=[1]\otimes[3]=0$ なので $t=3t-2t=0$ である。任意の純テンソルは $t$ の整数倍なので、加群全体が零になる。両方の $[1]$ はそれぞれの因子で非零だが、平衡関係を課すと消える。これに対し $\Z/(2)\otimes\Z/(4)$ の対応元は非零である。積を法 $2$ に還元する平衡写像がそれを $[1]$ に送るためである。
:::

:::proposition[単位加群と任意の直和のテンソル積]{#prop-ring-tensor-direct-sums}
右加群 $M$ について $M\otimes_R R\cong M$ である。また左加群の任意の族 $(N_i)_{i\in I}$ について
$$
M\otimes_R\bigoplus_{i\in I}N_i\cong \bigoplus_{i\in I}(M\otimes_R N_i)
$$
が成り立つ。右側の因子を固定しても対応する同型がある。
:::

:::proof
最初の同型は $m\otimes r\mapsto mr$ であり、逆は $m\mapsto m\otimes1$ である。$mr\otimes1=m\otimes r$ なので両合成は恒等となる。直和の式では、$(m,(n_i)_i)\mapsto(m\otimes n_i)_i$ が有限台で平衡なので写像が定まる。逆は各 $N_i$ の包含から誘導された写像の有限和である。各 $n=(n_i)_i$ が成分の有限和であることから、両合成は純テンソルを固定する。右加群の直和でも同じ成分表示を用い、平衡条件は変わらない。左側の単位加群との同型は $r\otimes n\mapsto rn$ である。
:::

### 釣合い条件と生成元の関係を往復する

:::example[法 16 と 24 のテンソル積]
$e=[1]\otimes[1]$ とする。各単純テンソル $[a]\otimes[b]$ は $ab\,e$ である。従って $e$ がテンソル積を生成し、$16e=24e=0$ となる。整数の等式 $8=(-1)\cdot 16+(1)\cdot 24$ によって $8e=0$ である。

### テンソル積の結合と係数を置く位置

:::proposition[テンソル積の結合の同型]{#prop-ring-module-tensor-assoc}
$R,S$ を環、$L$ を右 $R$ 加群、$M$ を左 $R$・右 $S$ 双加群、$N$ を左 $S$ 加群とする。二つの作用が可換なら、Abel 群として $(L\otimes_R M)\otimes_S N\cong L\otimes_R(M\otimes_S N)$ である。
:::

:::proof
$L\otimes_R M$ の右 $S$ 作用を $(l\otimes m)s=l\otimes(ms)$ と定める。左 $R$ 作用との可換性のおかげで $lr\otimes m=l\otimes rm$ は右作用を施した後にも成立する。同様に $M\otimes_S N$ は左 $R$ 加群になる。$(l\otimes m)\otimes n\mapsto l\otimes(m\otimes n)$ は各変数で加法を保つ。$R$ の係数を左二因子で移すことも、$S$ の係数を右二因子で移すことも、像での平衡関係に等しい。従って普遍性を二度用いると準同型になる。括弧を逆に変える写像も同じ理由で定義でき、両合成は生成する純テンソル上で恒等になる。
:::

:::example[同じ係数をどの段で降ろしても同じ結果になる]
$L=\Z/(12)$、$M=\Z/(18)$、$N=\Z/(8)$ とする。先に左二つを取れば $L\otimes M\cong\Z/(6)$、それと $N$ のテンソル積は $\Z/(2)$ である。先に右二つを取れば $M\otimes N\cong\Z/(2)$、それと $L$ のテンソル積も $\Z/(2)$ である。例えば $([5]\otimes[7])\otimes[3]$ は $5\cdot7\cdot3=105$ の類 $[1]$ であり、括弧を変えても同じ値を取る。これは偶然に位数が等しいというだけでなく、各係数をどちらから順に移しても共通の生成元へ同じ整数を掛けることによる。
:::

## テンソル積の右完全性と計算例

### 関係式を移すと右端が完全になる

:::theorem[テンソル積の右完全性]{#thm-ring-tensor-right-exact}
右 $R$ 加群 $M$ と左加群の完全列 $A\to B\to C\to0$ について、
$$
M\otimes_R A\longrightarrow M\otimes_R B\longrightarrow M\otimes_R C\longrightarrow0
$$
は完全である。
:::

:::proof
$B\to C$ は全射なので $m\otimes c$ は全て持ち上がる。$D$ を中央の加群の最初の像による商とする。$(m,c)\mapsto[m\otimes b]\in D$ とし $b$ を $c$ の持ち上げとする。持ち上げとの差は $A$ の像なので $D$ で零となる。加法や作用の持ち上げを用いると平衡条件が成り立つため、$M\otimes_R C\to D$ が定まる。反対向きは元の合成が零なので定まり、互いに純テンソルの類を元に戻す。このため中央の核は最初の像である。
:::

:::proposition[商と巡回加群の計算]{#prop-ring-tensor-quotient}
可換環では $(R/I)\otimes_R M\cong M/IM$ である。特に $R/I\otimes_R R/J\cong R/(I+J)$ である。
:::

:::proof
$[a]\otimes m\mapsto[am]$ は代表によらず平衡なので定まる。逆に $m\mapsto [1]\otimes m$ は全ての $im$ を $[i]\otimes m=0$ に送り、商からの写像になる。両合成は生成元で恒等である。$I(R/J)$ は $(I+J)/J$ なので第二の主張を得る。
:::

:::corollary[二つの表示からテンソル積の関係行列を作る]{#cor-ring-tensor-presentation}
可換環 $R$ 上で $M$ が $m$ 個、$N$ が $n$ 個の生成元を持ち、関係元の列をそれぞれ $A$ と $B$ に並べるとする。$M\otimes_R N$ は $mn$ 個の基底元 $e_i\otimes f_j$ を持つ自由加群を、$A$ の各列と各 $f_j$ のテンソル、および各 $e_i$ と $B$ の各列のテンソルで割った加群である。
:::

:::proof
$R^m\otimes_R R^n$ は :ref[prop-ring-tensor-direct-sums] により指定の基底を持つ。最初に $A$ 側の関係を課すと、右完全性で $M\otimes_R R^n$ を得る。そこで $B$ 側の関係を課すと、再び右完全性で $M\otimes_R N$ を得る。第二段の関係は任意の $m\in M$ と $B$ の列のテンソルで生成されるから、$R^m$ の基底の像だけを用いれば十分である。この関係を元の自由加群に持ち上げたものが、記述の第二種の列である。
:::

:::example[単射が消える]
$\Z\xrightarrow{2}\Z$ は単射だが $\Z/(2)$ とテンソル積を取ると $\Z/(2)\xrightarrow{0}\Z/(2)$ になる。実際、$\Z\otimes M\to M$ と $m\mapsto1\otimes m$ は平衡関係で互いに逆であり、この同型で $2$ 倍が零になる。
:::

:::example[テンソル積を関係行列から求める]
$M=\Z^2/\Z(6,10)$ とし、$\Z/(4)$ とテンソル積を取る。右完全性により、結果は $(\Z/(4))^2$ を関係元 $([6],[10])=([2],[2])$ で割る余核になる。座標変換 $(a,b)\mapsto(a,b-a)$ は可逆で、関係元を $([2],[0])$ に移す。従って結果は $\Z/(2)\oplus\Z/(4)$ である。同じ $M$ に対して $\Q$ とテンソル積を取ると、関係 $(6,10)$ が張る部分空間は一次元であり、商も一次元になる。整数の関係式の同じ表示から、二つの係数環で違う結果が出る。
:::

### 右完全性を表示の計算に用いる

:::example[法 2 への係数拡大で表示を変える]
$\Z$ 加群 $M$ を関係行列 $A=\begin{pmatrix}2&4\\6&8\\2&2\end{pmatrix}$ の余核とする。$\F_{2}$ に係数を拡大すると、$\F_{2}\otimes_\Z M$ は各成分を法 $2$ で還元した関係行列の余核になる。これは行列の列を関係式として指定してから、テンソル積の右完全性を適用するためである。


$$
\begin{pmatrix}0&0\\0&0\\0&0\end{pmatrix}\longrightarrow \begin{pmatrix}0&0\\0&0\\0&0\end{pmatrix}
$$


右辺は法 $2$ で行の基本変形を行った行列である。全成分が零なので階数は $0$ である。従って余核の次元は行数から階数を引いて $3$ である。この計算で行を変えることは新しい基底で関係を表示することであり、零になった列を削ることは関係を減らすことである。

整数行列としては Smith 対角形が $\begin{pmatrix}2&0\\0&2\\0&0\end{pmatrix}$ である。この行列の法 $2$ で非零な対角成分は $0$ 個で、還元した階数をもう一度得る。整数で可逆な座標変換は、法 $2$ でも行列式が $1$ または $-1$ のままで可逆である。従って還元前後の二通りの計算が一致する。
:::

:::example[単射がテンソル後に零になる]

:::example[イデアルの共通部分と積から失われた単射を求める]

## 係数拡大と係数制限

### 作用の係数を移す

:::definition[係数拡大と制限]{#def-ring-scalar-change}
環準同型 $R\to S$ に対し、左 $S$ 加群の作用を $R$ に引き戻すことを :term[係数制限]{en="restriction of scalars" yomi="けいすうせいげん"} という。一方、左 $R$ 加群 $M$ の :term[係数拡大]{en="extension of scalars" yomi="けいすうかくだい"} は $S\otimes_R M$ であり、$t(s\otimes m)=ts\otimes m$ で左 $S$ 加群とする。ここで $S$ の右 $R$ 作用は環準同型を通した右積である。
:::

:::proposition[係数拡大の普遍性]{#prop-ring-scalar-extension}
左 $S$ 加群 $N$ への $S$ 線形写像 $S\otimes_R M\to N$ と、係数を制限した $N$ への $R$ 線形写像 $M\to N$ は一対一に対応する。
:::

:::proof
前者を $m\mapsto1\otimes m$ と合成する。逆に $R$ 線形写像 $f$ から $(s,m)\mapsto sf(m)$ を作ると平衡の条件 $(sr)f(m)=sf(rm)$ が成り立つ。従って $S$ 線形写像が得られ、両合成が元に戻ることは $1\otimes m$ と $s\otimes m$ で確認できる。
:::

:::example[係数制限で増える準同型]
$\C$ の左からの乗法を複素ベクトル空間として見ると、$\C\to\C$ の複素線形写像は $z\mapsto az$ に限る。実数へ係数制限すると、共役 $z\mapsto\bar z$ も線形写像になる。これを同じ写像のまま複素線形とすることはできない。実際 $i\cdot1$ の像は $-i$ だが、$1$ の像を $i$ 倍すると $i$ である。
:::

:::example[整数の関係式を別の環へ移す]
$\Q\otimes_\Z\Z/(6)=0$ である。$6$ を逆にできるため $q\otimes[1]=(q/6)\otimes[6]=0$ である。これに対し $\F_3\otimes_\Z\Z/(6)\cong\F_3$ となる。実際 $6\F_3=0$ なので :ref[prop-ring-tensor-quotient] を使える。
:::

### 局所化を加群の係数拡大として表す

:::proposition[局所化の分数表示]{#prop-ring-localization-module}
可換環の積閉集合 $S$ に対し、$(S^{-1}R)\otimes_R M$ の各元は $(1/s)\otimes m$ と書ける。この元と $(1/t)\otimes n$ が等しいことは、ある $u\in S$ に対して $u(tm-sn)=0$ となることと同値である。
:::

:::proof
有限個の純テンソルでは $(a/s)\otimes m=(1/s)\otimes am$ とでき、分母の積にそろえると一つの純テンソルにまとまる。次に $(m,s)$ の同値類を、提示した条件で定める。$R$ の局所化と同じく二つの差にさらに分母を掛けて足すと推移性が従い、和は $(m,s)+(n,t)=(tm+sn,st)$ で定まる。可換環の局所化の分数の確認と同じ展開で代表に依存しない。この Abel 群を $L$ とする。

写像 $(a/s,m)\mapsto(am,s)$ の類は、分子と分母の同値の条件を $m$ に作用させると代表によらず、加法と平衡条件を満たす。従ってテンソル積から $L$ への準同型を得る。逆に $(m,s)$ の類に $(1/s)\otimes m$ を対応させると、二代表の差は $(1/(stu))\otimes u(tm-sn)$ なので零であり、定義できる。二方向の対応は生成元で互いに逆である。
:::

:::example[整数加群のねじれが分母で消える]
$S=\{2^j\mid j\ge0\}$、$M=\Z/(12)$ とする。$[3]/1=0$ なのは $4[3]=0$ のためである。逆に $[1]/1=0$ なら $2$ の冪が $12$ の倍数となる必要があり、不可能である。$[1]/1$ の位数は $3$ で、分母 $2$ 倍はこの三元の群の自己同型なので、$[1]/2=[2]/1$ である。結果は $\Z/(3)$ に同型である。
:::

### 関係式が消える場合と単元になる場合

:::example[3 を逆にしたときのイデアル]
$S=\{3^k\mid k\ge0\}$、$R=\Z$ とする。整数 $90$ の素因子のうち $3$ を割るものは、$3$ を逆にした後すべて単元になる。実際 $3=pc$ なら $p(c/3)=1$ である。反対に $3$ を割らない素数 $p$ は $p(a/3^k)=1$ を満たせない。交差積を取ると $p\mid 3^k$ に反するからである。拡大後に各生成元から取り除ける素因子は次の表の通りである。

| 素数 | 元の指数 | 局所化後に残る指数 |
| --- | --- | --- |
| $2$ | $1$ | $1$ |
| $3$ | $2$ | $0$ |
| $5$ | $1$ | $1$ |

従って $S^{-1}(90)=(10)$ である。縮約は $(10)\subseteq\Z$ である。実際整数 $r$ がこのイデアルに入るためには $3^k r$ が $10$ で割れればよい。ここで $\gcd(3,10)=1$ なので、これは $r$ が直接 $10$ で割れることと同値である。さらに剰余を取ると $(S^{-1}\Z)/(10)\cong\Z/(10)$ である。$3$ は法 $10$ で逆元をもつので、剰余写像を分数に延長したとき全射性が保たれ、核はこのイデアルになる。
:::

:::example[10 を逆にしたときのイデアル]
$S=\{10^k\mid k\ge0\}$、$R=\Z$ とする。整数 $360$ の素因子のうち $10$ を割るものは、$10$ を逆にした後すべて単元になる。実際 $10=pc$ なら $p(c/10)=1$ である。反対に $10$ を割らない素数 $p$ は $p(a/10^k)=1$ を満たせない。交差積を取ると $p\mid 10^k$ に反するからである。拡大後に各生成元から取り除ける素因子は次の表の通りである。

| 素数 | 元の指数 | 局所化後に残る指数 |
| --- | --- | --- |
| $2$ | $3$ | $0$ |
| $3$ | $2$ | $2$ |
| $5$ | $1$ | $0$ |

従って $S^{-1}(360)=(9)$ である。縮約は $(9)\subseteq\Z$ である。実際整数 $r$ がこのイデアルに入るためには $10^k r$ が $9$ で割れればよい。ここで $\gcd(10,9)=1$ なので、これは $r$ が直接 $9$ で割れることと同値である。さらに剰余を取ると $(S^{-1}\Z)/(9)\cong\Z/(9)$ である。$10$ は法 $9$ で逆元をもつので、剰余写像を分数に延長したとき全射性が保たれ、核はこのイデアルになる。
:::

:::example[複素化で一次因子が分かれる]
$M=\R[x]/(x^2+1)$ とし、$\R[x]\to\C[x]$ で係数拡大する。表示のため
$$
\C[x]\otimes_{\R[x]}M\cong\C[x]/(x^2+1)
$$
である。右辺から $f\mapsto(f(i),f(-i))$ で $\C^2$ へ写す。余り $a+bx$ の像は $(a+bi,a-bi)$ であり、逆に $(c,d)$ から $a=(c+d)/2$、$b=(c-d)/(2i)$ と求められる。従ってこれは同型である。拡大後の $x$ 作用はこの座標では $(c,d)\mapsto(ic,-id)$ となる。係数を制限したときは元の $\R[x]$ 線形性だけを指定できるので、この二成分の複素スカラーまで保つことは仮定に含まれない。
:::

:::example[局所化で有限位数の元が消える]
$\Z/(18)$ に $\Z[1/3]$ をテンソルする。$18=2\cdot3^2$ なので、拡大後のイデアル $(18)$ は $(2)$ と等しい。従って剰余は $\Z/(2)$ である。写像を直接見れば $[a]\mapsto[a]\bmod2$ で、元の加群で偶数類は $3^2$ 倍すると零になるため局所化で消える。奇数類は $3^k$ を掛けても奇数のままなので消えない。これに対し $\Z[1/2]$ での同じ計算では $(18)$ が $(9)$ となり、法 $9$ の成分が残る。逆にした係数の素因子によってどの関係が残るかが変わる。
:::

:::example[法 2 への係数拡大で表示を変える]
$\Z$ 加群 $M$ を関係行列 $A=\begin{pmatrix}2&4&6\\4&2&8\\8&4&10\end{pmatrix}$ の余核とする。$\F_{2}$ に係数を拡大すると、$\F_{2}\otimes_\Z M$ は各成分を法 $2$ で還元した関係行列の余核になる。これは行列の列を関係式として指定してから、テンソル積の右完全性を適用するためである。


$$
\begin{pmatrix}0&0&0\\0&0&0\\0&0&0\end{pmatrix}\longrightarrow \begin{pmatrix}0&0&0\\0&0&0\\0&0&0\end{pmatrix}
$$


右辺は法 $2$ で行の基本変形を行った行列である。全成分が零なので階数は $0$ である。従って余核の次元は行数から階数を引いて $3$ である。この計算で行を変えることは新しい基底で関係を表示することであり、零になった列を削ることは関係を減らすことである。

整数行列としては Smith 対角形が $\begin{pmatrix}2&0&0\\0&2&0\\0&0&18\end{pmatrix}$ である。この行列の法 $2$ で非零な対角成分は $0$ 個で、還元した階数をもう一度得る。整数で可逆な座標変換は、法 $2$ でも行列式が $1$ または $-1$ のままで可逆である。従って還元前後の二通りの計算が一致する。
:::

:::example[整数の同じ表示を二つの係数環へ移す]
$M=\Z^2/\langle(2,4)\rangle$ とする。整数の基底を $(1,2),(0,1)$ にすると唯一の関係は第一元の $2$ 倍であり、$M\cong\Z/(2)\oplus\Z$ である。$\F_2$ への係数拡大では関係の列そのものが零になり、$\F_2\otimes_\Z M$ は二次元である。一方 $\Q$ への係数拡大では関係を二で割れるので、$\Q\otimes_\Z M$ は第二元が張る一次元空間になる。さらに $\Z[1/3]$ へ移した場合、$2$ は単元にならず $\Z/(2)$ の成分が残る。列が零になる、元が単元になる、どちらでもない、という三通りに分けると係数拡大後の関係の意味を追いやすい。
:::

:::proposition[局所化の完全性]{#prop-ring-module-localization-exact}
可換環 $R$ の積閉集合 $S$ に対して、加群の局所化 $M\mapsto S^{-1}M$ は完全列を完全列に送る。
:::

:::proof
連続する写像を $A\xrightarrow{f}B\xrightarrow{g}C$ とし、$B$ で完全とする。局所化後の像が核に入るのは合成が零だからである。逆に $b/s$ が局所化した $g$ の核に入るとする。:ref[prop-ring-localization-module] の分数の判定から、ある $u\in S$ で $u g(b)=0$ となる。元の列が完全なので $u b=f(a)$ となる $a$ があり、$b/s=ub/(us)=f(a)/(us)$ となる。従って局所化した像に入る。この議論はどの中間項にも適用できる。両端に零加群があれば、それを局所化しても零であり、同じ議論から端の単射性と全射性も得られる。
:::

:::example[局所化で異なる二つの分裂を得る]
$0\to\Z/(4)\xrightarrow{[a]\mapsto[2a]}\Z/(8)\to\Z/(2)\to0$ は完全である。整数 $2$ を逆にすれば三加群とも零になる。次に $0\to\Z/(3)\xrightarrow{[a]\mapsto[4a]}\Z/(12)\to\Z/(4)\to0$ を同じく局所化すると、左から $\Z/(3),\Z/(3),0$ になる。左の写像は法 $3$ では $4$ 倍、すなわち恒等である。最初の列は全体が消えるが、第二の列では $2$ の倍数でない位数を持つ部分が残る。どちらも分裂する局所化になったが、局所化は最初の列そのものの分裂を意味しない。
:::

## 演習問題

::::exercise{level=basic}
$0\to\Z\xrightarrow{3}\Z\to\Z/(3)\to0$ が完全で分裂しないことを示せ。

:::solution
$3$ 倍は単射で像は法 $3$ の還元の核である。最後の還元は全射である。分裂すれば $[1]$ の持ち上げが $3$ 倍で零になるが、$\Z$ でそのような元は $0$ だけなので不可能である。
:::
::::

::::exercise{level=basic}
$\Z/(15)\otimes_\Z\Z/(9)$ を計算せよ。

:::solution
商の公式で $\Z/((15)+(9))$ となる。両数は $3$ の倍数で $2\cdot9-15=3$ なので和は $(3)$ であり、答えは $\Z/(3)$ である。
:::
::::

::::exercise{level=basic}
$\F_5\otimes_\Z\Z/(10)$ と $\F_5\otimes_\Z\Z/(3)$ を求めよ。

:::solution
第一は $\F_5/10\F_5=\F_5$ である。第二は $3$ が $\F_5$ で単元なので $\F_5/3\F_5=0$ である。
:::
::::

::::exercise{level=basic}
上段と下段に $0\to\Z\xrightarrow{6}\Z\to\Z/(6)\to0$ を置き、縦を $3$ 倍にする。$\delta([2])$ を求めよ。

:::solution
$[2]$ を $2$ に持ち上げると縦の像は $6$ である。下段の $6$ 倍で戻すと $1$ なので $\delta([2])=[1]\in\Z/(3)$ である。
:::
::::

::::exercise{level=advanced}
任意の右加群 $M$ に対し $M\otimes_R(N\oplus P)\cong (M\otimes_R N)\oplus (M\otimes_R P)$ を示せ。

:::solution
$m\otimes(n,p)\mapsto(m\otimes n,m\otimes p)$ は平衡写像から定まる。逆は二つの包含から誘導される写像を足して作る。$(n,p)=(n,0)+(0,p)$ なので両合成は純テンソルで恒等であり、従って全体で恒等である。
:::
::::

::::exercise{level=advanced}
短完全列で両端の縦写像が同型なら中央も同型であることを示せ。

:::solution
両列を $0,A,B,C,0$ の五項として、最初と最後の零加群の間に唯一の写像を置く。左端の写像は全射、右端の写像は単射であり、中間の $A,C$ の写像が同型であるから五項補題で $B$ の写像も同型である。
:::
::::

::::exercise{level=advanced}
可換環 $R$ の二つのイデアル $I,J$ に対し、$R/I\otimes_R J\to R/I\otimes_R R$ の核を求めよ。

:::solution
商の公式で写像は $J/IJ\to R/I$、$j+IJ\mapsto j+I$ である。像が零になるのは $j\in J\cap I$ と同値なので、核は $(I\cap J)/IJ$ である。
:::
::::

::::exercise{level=advanced}
環準同型 $R\to S\to T$ について $T\otimes_S(S\otimes_R M)\cong T\otimes_R M$ を示せ。

:::solution
$t\otimes(s\otimes m)\mapsto ts\otimes m$ と $t\otimes m\mapsto t\otimes(1\otimes m)$ を考える。平衡条件は、それぞれ係数を隣の因子へ移す等式で確認できる。$ts\otimes(1\otimes m)=t\otimes(s\otimes m)$ なので、一方の合成ももう一方の合成も恒等である。
:::
::::

::::exercise{level=advanced}
上段と下段が $0\to\Z\xrightarrow{20}\Z\to\Z/(20)\to0$、縦が $12$ 倍の図式で、接続写像の像を求めよ。

:::solution
右端の縦写像の核は $20\mid12r$、すなわち $5\mid r$ を満たす類である。代表 $r=0,5,10,15$ を中央の整数に持ち上げ、下段の左端では $12r/20$ を取る。これを左の縦写像の余核 $\Z/(12)$ に移すと $[0],[3],[6],[9]$ を得る。従って像は法 $12$ の $3$ の倍数類全体である。代表を $20$ だけ変えると左端の値は $12$ だけ変わるので、この値は代表によらない。
:::
::::

## 確認テスト

::::quiz
短完全列 $0\to A\xrightarrow{i}B\xrightarrow{p}C\to0$ の分裂条件を選べ。

- [x] $p$ に右逆がある。
- [x] $i$ に左逆がある。
- [ ] $p$ に核がない。

:::explanation
右逆があれば任意の $b$ から $s(p(b))$ を引いて $A$ の成分を得られる。左逆があればその核に $p$ を制限して $C$ と同型になる。一方、分裂していても $A\ne0$ なら $p$ の核は非零である。
:::
::::

::::quiz{answer="6" tol="1e-9"}
$\Z/(18)\otimes_\Z\Z/(30)$ の位数を求めよ。

:::explanation
商の公式で $(18)+(30)=(6)$ を法とする整数の剰余群となるので、位数は $6$ である。
:::
::::

::::quiz
テンソル積を固定した側に取る関手は、一般にどの性質をもつか。

- [x] 右完全である。
- [ ] 常に単射を保つ。
- [ ] 常に左完全である。

:::explanation
右完全性は商の関係を剰余にも移せることから従う。$\Z$ の $2$ 倍の単射でも $\Z/(2)$ とテンソル積を取ると零写像になるため、単射を常に保つわけではない。
:::
::::

::::quiz{answer="2" tol="1e-9"}
$\Q\otimes_\Z(\Z^2\oplus\Z/(7))$ の $\Q$ 次元を求めよ。

:::explanation
直和はテンソル積に移り、自由成分から $\Q^2$ が得られる。$7$ は $\Q$ で単元なので $\Q\otimes\Z/(7)=\Q/7\Q=0$ である。従って次元は $2$ である。
:::
::::

::::quiz{answer="3" tol="1e-9"}
$\Z/(12)\otimes_\Z\Z/(15)$ には何個の元があるか。

:::explanation
$[1]\otimes[1]$ が生成し、$12$ 倍と $15$ 倍で零になるから、差の $3$ 倍で零である。逆に乗法 $([a],[b])\mapsto[ab]\bmod3$ がテンソル積から法 $3$ へ下り、生成元を $[1]$ に送る。従って位数はちょうど $3$ である。
:::
::::
