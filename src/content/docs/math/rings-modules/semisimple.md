## この章の目標

- Schur の補題を証明し、単純加群の自己準同型環を調べる。
- 半単純加群と半単純環の同値な条件を証明する。
- Wedderburn–Artin の定理で半単純環を行列環の積に分解する。
- Jacobson 根基、Nakayama の補題、Jacobson の稠密性定理を使う。

## 単純加群と Schur の補題

以下では単位元をもつ環の単位的左加群を扱う。環 $E$ の反対環を $E^{\mathrm{op}}$ と書く（:ref[def-ring-opposite-center]）。

### 単純加群の間の写像は零か同型

単純加群とは、零と自分自身以外の部分加群をもたない非零加群であった（:ref[def-ring-composition-series]）。任意の非零元 $s$ が加群 $S$ を生成する。実際 $Rs$ は非零部分加群である。従って $r\mapsto rs$ は全射で、その核は極大左イデアル $L$ となる。部分加群の対応により $S\cong R/L$ の単純性と $L$ の極大性は同値である。可換環なら $L$ は極大イデアルで、$R/L$ は体となる。

:::lemma[Schur の補題]{#lem-ring-schur}
単純加群 $S,T$ の間の非零準同型は同型である。従って $S,T$ が同型でなければ $\Hom_R(S,T)=0$ であり、$\End_R S$ は合成を積とする斜体である。
:::

:::proof
非零準同型の核は真の部分加群だから零である。非零の像は $T$ の部分加群だから全体である。全単射の逆は作用と加法を保つため同型である。$T=S$ の場合に適用すれば、全ての非零自己準同型には合成の逆元がある。また $1_S\ne0$ である。
:::

:::example[行列環の列加群]
斜体 $D$ と $R=M_n(D)$ に対し列加群 $D^n$ は単純である。非零列 $v$ の $j$ 成分 $v_j\ne0$ を選ぶと、任意の列 $w$ について、第 $j$ 列が $w v_j^{-1}$、他列が零の行列が $v$ を $w$ に送るからである。$R$ 線形自己準同型は、$E_{11}$ が像を固定することから $e_1$ を $e_1d$ に送り、$e_i=E_{i1}e_1$ より全ての $e_i$ を $e_i d$ に送る。任意の列は $A e_1$ と書けるので全体では右から $d$ を掛ける写像となる。右積の合成では順序が反転するため $\End_R(D^n)\cong D^{\mathrm{op}}$ である。
:::

:::example[体の拡大が自己準同型環に現れる]
$R=\R[x]$、$S=R/(x^2+1)$ とする。この剰余は体なので、$R$ 加群としての部分加群は剰余のイデアルに対応し、$S$ は単純である。任意の $R$ 線形な写像 $S\to S$ は $[1]$ の像 $a$ を決めると $[r]\mapsto[r]a$ と定まり、逆にこの写像は定義できる。従って $\End_R S\cong\C$ である。$S$ を二次元の実ベクトル空間と見たときの自己準同型環は $M_2(\R)$ であるが、$R$ 線形性を求めると $x$ による回転と可換な写像だけに絞られる。このため Schur の斜体は係数をどこまで保つかに依存する。
:::

### 準同型を生成元の像から判定する

:::example[多項式の剰余で Schur の補題を計算する]
$R=\Q[x]$、$S=R/(f)$、$T=R/(g)$ とし、$f=x^{2} + 1,g=x^{2} + 2$ を取る。ここで両多項式は二次で、有理根を持たないため既約である。従って商は体であり、そのイデアルに対応する部分加群は零と全体だけである。従って両加群は単純である。

準同型 $h\colon S\to T$ は $w=h([1])$ で定まる。始域の関係 $f[1]=0$ から $fw=0$ が必要であり、逆にこの条件だけで任意の $[a]\mapsto aw$ が定義できる。目標での $f$ の作用は次の計算で確認する。

| 目標の基底の指数 $i$ | $fx^i$ の余り |
| --- | --- |
| $0$ | $-1$ |
| $1$ | $- x$ |

二式の最大公約元が $1$ であり、$1=(-1)f+(1)g$ である。$g$ を零とした剰余で $f$ は可逆になるため、$f\cdot w=0$ から $w=0$ が従う。従ってこの二つの単純加群の間の準同型は零写像だけである。

これにより、単純加群について「準同型が零である場合」と「自己準同型の環が体になる場合」を、生成元に対する一つの関係式から調べられる。同じ $\Q$ 上の次元でも、多項式の作用が異なれば途中の関係式は異なる。
:::

:::example[多項式の剰余で Schur の補題を計算する]
$R=\Q[x]$、$S=R/(f)$、$T=R/(g)$ とし、$f=x^{2} + 2,g=x^{2} + 2$ を取る。ここで両多項式は二次で、有理根を持たないため既約である。従って商は体であり、そのイデアルに対応する部分加群は零と全体だけである。従って両加群は単純である。

準同型 $h\colon S\to T$ は $w=h([1])$ で定まる。始域の関係 $f[1]=0$ から $fw=0$ が必要であり、逆にこの条件だけで任意の $[a]\mapsto aw$ が定義できる。目標での $f$ の作用は次の計算で確認する。

| 目標の基底の指数 $i$ | $fx^i$ の余り |
| --- | --- |
| $0$ | $0$ |
| $1$ | $0$ |

$f=g$ なので $f\cdot w=0$ は任意の $w$ で成立する。自己準同型は $w$ による乗法である。例えば $w=x+2$ による乗法の逆元は $\frac{1}{3} - \frac{x}{6}$ による乗法である。実際二多項式の積を $g$ で割った余りは $1$ である。

これにより、単純加群について「準同型が零である場合」と「自己準同型の環が体になる場合」を、生成元に対する一つの関係式から調べられる。同じ $\Q$ 上の次元でも、多項式の作用が異なれば途中の関係式は異なる。
:::

:::example[多項式の剰余で Schur の補題を計算する]
$R=\Q[x]$、$S=R/(f)$、$T=R/(g)$ とし、$f=x^{2} - 2,g=x^{2} + 1$ を取る。ここで両多項式は二次で、有理根を持たないため既約である。従って商は体であり、そのイデアルに対応する部分加群は零と全体だけである。従って両加群は単純である。

| 目標の基底の指数 $i$ | $fx^i$ の余り |
| --- | --- |
| $0$ | $-3$ |
| $1$ | $- 3 x$ |

二式の最大公約元が $1$ であり、$1=(- \frac{1}{3})f+(\frac{1}{3})g$ である。$g$ を零とした剰余で $f$ は可逆になるため、$f\cdot w=0$ から $w=0$ が従う。従ってこの二つの単純加群の間の準同型は零写像だけである。

これにより、単純加群について「準同型が零である場合」と「自己準同型の環が体になる場合」を、生成元に対する一つの関係式から調べられる。同じ $\Q$ 上の次元でも、多項式の作用が異なれば途中の関係式は異なる。
:::

:::example[異なる環を同じベクトル空間に作用させる]
$\R^2$ を $M_2(\R)$ の列加群とする。例えば $(1,2)^\top$ を $(3,4)^\top$ へ送るには、第一列に $(3,4)^\top$ を置き第二列を零とすればよい。従って任意の非零列が全体を生成する。一方、作用をスカラー行列だけに制限すると全ての実直線が部分加群になる。回転 $J(a,b)=(-b,a)$ とスカラーで生成される部分環に制限すれば、$v,Jv$ は非零 $v$ に対して実一次独立なので再び単純である。このとき自己準同型は $J$ と可換な $aI+bJ$ であり、行列環全体に対する自己準同型 $aI$ より大きい。単純性と Schur の斜体は、どの環の作用を保つかでそれぞれ変わる。
:::

## 半単純加群の特徴付け

### 補部分をいつでも選べる加群

:::definition[半単純加群]{#def-ring-semisimple-module}
単純加群の外部直和に同型な加群を :term[半単純加群]{en="semisimple module" yomi="はんたんじゅんかぐん"} という。零加群は空の直和である。
:::

:::theorem[半単純加群の特徴付け]{#thm-ring-semisimple-module}
加群 $M$ について次は同値である。
1. $M$ は半単純である。
2. $M$ は単純部分加群の和である。
3. $M$ の全ての部分加群は直和因子である。

半単純加群の部分加群と剰余加群も半単純である。
:::

:::proof
1 なら各標準因子の像により 2 を得る。2 の下で部分加群 $N$ を固定し、単純部分加群の族で、その和が直和かつ $N$ と零で交わるものを取る。族の包含で順序付けると、鎖の合併も同じ条件を満たす。直和の関係式と交わりの元は有限個の部分加群にしか関わらず、鎖の一段で判定できるためである。Zorn の補題で極大な族を取り、その直和を $L$ とする。$N+L\ne M$ なら $N+L$ に含まれない単純部分加群 $S$ がある。$S\cap(N+L)=0$ なので $S$ を族に加えられ、極大性に反する。従って $M=N\oplus L$ であり、3 を得る。

3 の下で任意の非零部分加群 $U$ から $0\ne u\in U$ を選ぶ。巡回部分加群 $Ru$ の真の部分加群の鎖の合併は $u$ を含まないから、極大な真の部分加群 $W$ がある。3 で $M=W\oplus P$ と分けると $Ru=W\oplus(Ru\cap P)$ である。後者の因子は $Ru/W$ と同型なので単純であり $U$ に含まれる。全ての単純部分加群の和を $N_0$ とすると、3 により補部分がある。補部分が非零ならそこに単純部分加群があって $N_0$ と交わるから矛盾する。よって 2 であり、2 から 3 の証明で $N=0$ と取ると 1 も得る。

任意の準同型の下で単純加群の像は零または単純である。従って 2 を使えば剰余加群が半単純であり、部分加群も直和因子なのでその射影の像として半単純である。
:::

:::example[同じ Abel 群での分裂の差]
$\Z/(6)\cong\Z/(2)\oplus\Z/(3)$ は単純加群の和であり、各部分群には補部分がある。$\Z/(4)$ では $(2)/(4)$ が唯一の非零真部分群であり、補部分を取れない。従ってこちらは半単純でない。
:::

単純加群が無限個並ぶ直和も半単純である。半単純で有限生成なら、有限個の生成元の台を合わせた有限部分直和だけで全体が生成されるので、実際は有限個の単純加群の直和である。

半単純加群では単純加群の型ごとに、選んだ直和表示に依存しない成分を取り出せる。

:::proposition[単純型ごとの成分と多重度]{#prop-ring-isotypic-multiplicity}
半単純加群 $M$ と単純加群 $S$ に対し、$S$ に同型な単純部分加群の和を $M_S$ とする。任意の単純直和表示で $S$ 型の因子を集めた部分は $M_S$ に一致する。また $S$ 型の多重度は、斜体 $E=\End_R S$ 上の右ベクトル空間 $\Hom_R(S,M)$ の次元に等しい。右作用は $f\cdot a=f\circ a$ で与える。
:::

:::proof
$S$ に同型な単純部分加群から、異なる型の直和因子への座標写像は Schur の補題で零である。そのため、この部分加群の全ての元は $S$ 型の成分だけに台を持つ。逆に表示の $S$ 型の各因子は $M_S$ に入るため等号が成り立つ。さらに $S$ は一元生成なので、任意の $f\colon S\to M$ の像は有限個の座標に収まる。従って $\Hom_R(S,M)$ は、各因子への Hom 群の直和に一致する。異なる型の項は零であり、$S$ 型の項は同型を一つ選べば右 $E$ 上の一次元の空間となる。よって基底の個数が多重度を与える。
:::

:::example[直和因子を二つの射影で作る]
$R=K\times K$ 上で $M=K^2$ に $(a,b)(u,v)=(au,bv)$ と作用させる。$e_1=(1,0)$ と $e_2=(0,1)$ を掛けると、それぞれ第 1 と第 2 成分への射影になる。任意の部分加群 $N$ の元はこの二つの射影の像に分かれ、各像は零か対応する座標軸全体である。従って $N$ は二つの軸から選んだ直和であり、選ばなかった軸を足すと補部分になる。斜めの直線 $\{(u,u)\}$ はベクトル部分空間だが $e_1$ を掛けると外に出るため、検査する部分加群には含まれない。
:::

### 半単純な部分と補因子を取り出す

:::definition[底部]{#def-ring-module-socle}
加群 $M$ の単純部分加群を全て足した部分加群を :term[底部]{en="socle" yomi="ていぶ"} といい、$\operatorname{Soc} M$ と書く。単純部分加群がなければ零とする。
:::

:::proposition[最大の半単純部分加群]{#prop-ring-socle-max}
$\operatorname{Soc}M$ は半単純であり、$M$ の全ての半単純部分加群を含む。任意の準同型 $f\colon M\to N$ は $\operatorname{Soc} M$ を $\operatorname{Soc} N$ に送る。
:::

:::proof
底部は単純部分加群の和であり、:ref[thm-ring-semisimple-module] の特徴付けから半単純である。逆にどの半単純部分加群も、その単純部分加群の和として得られるから底部に入る。単純加群の準同型像は零か単純なので、単純部分加群ごとに像が底部に入り、和でも成立する。
:::

:::example[長さの加法性を素数ごとに調べる]
$B=\Z/(36)$ で $A=([6])$ とする。この部分群は $6$ の倍数類で、位数は $6$ である。$[r]\mapsto[6r]$ が $\Z/(6)\cong A$ を与える。商 $C=B/A$ は法 $6$ での還元によって $\Z/(6)$ となる。

| 単純因子の素数 | 左端での個数 | 中央での個数 | 右端での個数 |
| --- | --- | --- | --- |
| $2$ | $1$ | $2$ | $1$ |
| $3$ | $1$ | $2$ | $1$ |

各列の指数を足すと長さは $A$ が $2$、$B$ が $4$、$C$ が $2$ である。列の長さの加法性に加え、素数で区別した単純因子ごとにも多重度が加わることが分かる。剰余側の組成列の逆像は全て $A$ を含み、そこで各段の商が $C$ の同じ段の商と同型である。

これに対し分裂するかは別の条件である。切断で法 $6$ の $[1]$ を持ち上げると、代表は $1+6k$ となる。$6$ 倍で零になるには $6\mid1+6k$ が必要十分である。$1+6k$ は $6$ の倍数にできないので、この列は分裂しない。さらに $B$ の単純部分加群は、位数 $2$ の $([18])$ と位数 $3$ の $([12])$ に限る。これらの和は $([6])=A$ であるから、この例では $A$ が底部である。
:::

:::example[長さの加法性を素数ごとに調べる]
$B=\Z/(60)$ で $A=([5])$ とする。この部分群は $5$ の倍数類で、位数は $12$ である。$[r]\mapsto[5r]$ が $\Z/(12)\cong A$ を与える。商 $C=B/A$ は法 $5$ での還元によって $\Z/(5)$ となる。

| 単純因子の素数 | 左端での個数 | 中央での個数 | 右端での個数 |
| --- | --- | --- | --- |
| $2$ | $2$ | $2$ | $0$ |
| $3$ | $1$ | $1$ | $0$ |
| $5$ | $0$ | $1$ | $1$ |

各列の指数を足すと長さは $A$ が $3$、$B$ が $4$、$C$ が $1$ である。列の長さの加法性に加え、素数で区別した単純因子ごとにも多重度が加わることが分かる。剰余側の組成列の逆像は全て $A$ を含み、そこで各段の商が $C$ の同じ段の商と同型である。

これに対し分裂するかは別の条件である。切断で法 $5$ の $[1]$ を持ち上げると、代表は $1+5k$ となる。$5$ 倍で零になるには $12\mid1+5k$ が必要十分である。$k=7$ で $1+5k=36$ が $12$ の倍数となり、$[1]\mapsto[36]$ が切断を与える。$B$ の底部は位数 $2,3,5$ の部分加群の和 $([30])+([20])+([12])=([2])$ である。底部と $A$ の共通部分は $([10])$ であり、位数 $5$ の単純部分加群は補因子に属する。
:::

:::example[冪零作用を消される部分が底部になる]
$M=K[t]/(t^4)\oplus K[t]/(t^2)$ を $K[t]$ 加群とする。単純部分加群 $S$ では $t$ が冪零に作用するので、$\Ker(t|_S)$ は非零であり、単純性から全体である。従って $S\subseteq\Ker t$ である。一方 $\Ker t$ は $([t^3],0),(0,[t])$ が張る二次元空間で、$t$ は零に作用する。それぞれの直線は単純だから、底部はこの空間である。例えば第一の直線から $([t^2],0)$ を足してできる二次元部分加群では、$t$ が上の元を下の元に送る。この作用は独立な二つの単純成分に分離できない。
:::

## 半単純環

### 正則加群で環全体を調べる

:::definition[半単純環]{#def-ring-semisimple-ring}
自分自身への左乗法で作る加群 $R$ が半単純である環を :term[半単純環]{en="semisimple ring" yomi="はんたんじゅんかん"} という。
:::

:::proposition[加群全体の特徴付け]{#prop-ring-semisimple-ring-criteria}
環 $R$ が半単純であること、全ての左 $R$ 加群が半単純であること、全ての左 $R$ 加群の短完全列が分裂することは同値である。
:::

:::proof
$R$ が半単純なら自由加群は単純の直和をさらに並べたものなので半単純である。任意の加群は自由加群の剰余であり、:ref[thm-ring-semisimple-module] により半単純である。全加群が半単純なら短完全列の中央で左端への射影を取れるため分裂する。逆に全ての短完全列が分裂するなら、全ての左イデアル $I$ について $0\to I\to R\to R/I\to0$ が分裂し、:ref[thm-ring-semisimple-module] により左正則加群は半単純である。
:::

左正則加群が Artin 加群である環を左 Artin 環、Noether 加群である環を左 Noether 環と呼ぶ。半単純環では任意の加群が射影かつ入射である。全射は右逆を、単射は左逆をもつので、合成して持ち上げと延長を作れるためである。また左正則加群は $1$ で生成されるので単純加群の有限直和であり、従って左 Artin かつ左 Noether である。

:::example[同じ分解を全ての加群に適用する]
$R=\F_2\times\F_3$ で $e=(1,0)$、$f=(0,1)$ とする。任意の $R$ 加群 $M$ に対し $m=em+fm$ であり、$ef=0$ により $eM\cap fM=0$ である。それぞれは $\F_2,\F_3$ 上のベクトル空間であり、体上の基底に沿って単純加群の直和に分かれる。例えば $M=R^2$ では $\F_2$ 型が二つと $\F_3$ 型が二つであり、左加群としての長さは $4$ である。正則加群の分解を使うだけでなく、任意の加群に対応する分解を直接作れる例である。
:::

:::example[積の成分が分離しないと短完全列が分裂しない]
$R=K[t]/(t^2)$ のイデアル $I=(t)$ は $t$ が零に作用する一次元加群であり、$R/I$ にも $t$ は零に作用する。それでも $0\to I\to R\to R/I\to0$ は $R$ 線形には分裂しない。$[1]\in R/I$ の持ち上げは $1+a[t]$ となり、$[t]$ を掛けた値は $[t]\ne0$ になる。分裂を与える準同型ならこの値は零でなければならない。従ってこの二次元環は半単純環ではない。
:::

### 環全体から任意の加群の分解を作る

:::proposition[直積の加群を中心冪等元で分ける]{#prop-ring-product-module-split}
$R=\prod_{i=1}^h R_i$ とし、$e_i$ を第 $i$ 成分だけ $1$ の元とする。任意の左 $R$ 加群 $M$ は $\bigoplus_i e_iM$ となり、各成分では作用は $R_i$ を通して定まる。$R$ 線形写像はこれらの成分を保つ。
:::

:::proof
$1=\sum_i e_i$ から分解の和を得る。もし $\sum_i m_i=0$（$m_i\in e_iM$）なら $e_j$ を掛けると $m_j=0$ になる。各 $e_i$ は中心にあるので像は部分加群であり、第 $i$ 成分が零である係数はこの部分を零にする。準同型は $f(e_i m)=e_i f(m)$ を満たす。
:::

:::example[法 252 の冪等元と座標]
$R=\Z/(252)$ を相異なる素数の冪を法とする環の直積に移す。各成分で $e^2=e$ なら $e(e-1)=0$ である。整数の連続する二元は互いに素なので、素数冪はどちらか片方を割らなければならない。従って各成分の値は $0,1$ の二択である。このため次の表で冪等元を尽くす。

| $e$ の代表 | $\bmod 4$ | $\bmod 9$ | $\bmod 7$ |
| --- | --- | --- | --- |
| $0$ | $0$ | $0$ | $0$ |
| $1$ | $1$ | $1$ | $1$ |
| $28$ | $0$ | $1$ | $0$ |
| $36$ | $0$ | $0$ | $1$ |
| $64$ | $0$ | $1$ | $1$ |
| $189$ | $1$ | $0$ | $0$ |
| $217$ | $1$ | $1$ | $0$ |
| $225$ | $1$ | $0$ | $1$ |

ここから $e=[217]$ を選ぶ。$eR$ の元は $e$ の座標が零である全ての場所で零となる。逆に、その場所で零になる任意の組は $e$ を掛けても変わらないので $eR$ に入る。従って $eR$ の元は $36$ 個あり、$R/(e)$ は $7$ 個の元をもつ。

同じ議論を $1-e$ に適用すると、残りの座標との対応が得られる。実際、整数の最大公約数で生成元を取り直すと $(e)=([7])$ と $(1-e)=([36])$ である。両者の和は $1$ を含み、積は零である。各元は $e r+(1-e)r$ と書け、二項はそれぞれのイデアル成分に入るため、商を二つに分けて座標を復元できる。
:::

:::example[異なる型の準同型が消える理由]
$R=\F_3\times M_2(\F_2)$ とし、$M=\F_3^2\oplus(\F_2^2)^3$ にそれぞれの成分で作用させる。$e_1=(1,0)$ は最初の二つの単純因子を固定し、残る三つを零にする。従って最初の因子から残りへの準同型 $f$ については $f(m)=f(e_1m)=e_1 f(m)=0$ である。他方、同じ第二型の三因子の間の準同型は、各列加群の間のスカラー倍を成分として持つ。従って $M$ の自己準同型環は $M_2(\F_3)\times M_3(\F_2)$ である。正則加群でない $M$ の多重度 $2,3$ は、環自体の行列サイズ $1,2$ と一致する必要がない。
:::

:::example[正則加群の分裂がイデアルの積とは別の意味を持つ]
$R=M_2(\F_3)$ を列ごとに $RE_{11}\oplus RE_{22}$ に分ける。任意の $X$ から第一列を取り出す写像は右から $E_{11}$ を掛けるので左 $R$ 線形であり、例えば $X=\begin{pmatrix}1&2\\2&0\end{pmatrix}$ は $\begin{pmatrix}1&0\\2&0\end{pmatrix}+\begin{pmatrix}0&2\\0&0\end{pmatrix}$ となる。二因子の元どうしを掛けると必ず零になるわけではない。実際 $E_{21}$ は第一因子、$E_{12}$ は第二因子に属し、$E_{21}E_{12}=E_{22}\ne0$ である。従って左加群としての直和を、同じ二つの片側イデアルによる環の直積と見なすことはできない。環の直積分解に対応するのは、各因子が中心冪等元から得られる場合である。
:::

### 有限群の作用を平均して補部分を作る

:::theorem[Maschke の定理]{#thm-ring-maschke}
有限群 $G$ と体 $K$ に対し、$K[G]$ が半単純環であることと、整数 $|G|$ の $K$ での像が非零であることは同値である。
:::

:::proof
まず $|G|$ が $K$ で可逆であるとする。任意の $K[G]$ 加群 $M$ の部分加群 $N$ を取る。$K$ 線形な射影 $p\colon M\to N$ は基底の延長で得られる。写像
$$
P(m)=\frac1{|G|}\sum_{g\in G}g^{-1}p(gm)
$$
を考える。$N$ は $G$ で安定なので値は $N$ に属し、$m\in N$ なら各項は $m$ であり $P(m)=m$ である。$h\in G$ について $u=gh$ と置けば $g^{-1}=hu^{-1}$ なので $P(hm)=hP(m)$ である。$P$ は $K$ 線形でもあるので $K[G]$ 線形になる。従って $M=N\oplus\Ker P$ である。特に正則加群の全ての部分加群が直和因子なので、環は半単純である。

逆に $|G|=0$ が $K$ で成立するとする。$K[G]\to K$ を各群元を $1$ に送る増大写像（:ref[def-ring-augmentation]）とし、$K$ には群の全ての元が恒等として作用する。もし環が半単純ならこの写像は加群として分裂する。すると $1\in K$ の持ち上げは全ての $h\in G$ の左作用で固定される。左乗法は基底 $G$ を推移的に置換するので、固定ベクトルは $c\sum_g g$ に限る。その増大像は $c|G|=0$ であり、$1$ にならない。従ってこの場合は分裂も半単純性も成り立たない。
:::

:::example[一つの射影の平均を行列で求める]
$G=C_2$ とし、$\Q^2$ に $g(a,b)=(b,a)$ と作用させる。固定直線 $N=\Q(1,1)$ への $\Q$ 線形な射影として $p(a,b)=(a,a)$ を選ぶ。$gp(g(a,b))=(b,b)$ なので平均 $P$ は $((a+b)/2,(a+b)/2)$ である。$P$ の核は $\Q(1,-1)$ であり、そこでは $g$ が $-1$ 倍になる。実際 $(2,4)=(3,3)+(-1,1)$ と対応する二成分へ分かれる。最初の $p$ は $g$ と可換でないため、その核は群加群の補因子とは限らない。平均して得た $P$ では、$g$ との可換性が核の安定性を保証する。
:::

:::example[同じ入れ替えを標数二に移す]
$\F_2^2$ に同じ $g(a,b)=(b,a)$ を作用させる。固定直線は $\F_2(1,1)$ である。ほかの二直線は $\F_2(1,0)$、$\F_2(0,1)$ で、$g$ が互いに交換するのでどちらも部分加群でない。従って固定直線に加群としての補空間がない。実際 $(g-1)^2=g^2-2g+1=0$ であり、$g-1$ の像は固定直線全体である。この冪零作用が残っているため、二つの固有直線に分けることができない。平均式でも分母の $2$ が零になるため、同じ手順は適用できない。
:::

## Wedderburn–Artin の構造定理

### 同型な単純因子をまとめて行列を得る

:::theorem[Wedderburn–Artin の構造定理]{#thm-ring-wedderburn-artin}
半単純環は、有限個の斜体 $D_i$ 上の正方行列環 $M_{n_i}(D_i)$ の直積に同型である。逆も成り立つ。斜体の同型類とサイズの組は順序を除いて一意である。零環には空の積を対応させる。
:::

:::proof
左正則加群を $\bigoplus_i S_i^{n_i}$ と書き、相異なる $i$ の $S_i$ は非同型とする。:ref[lem-ring-schur] により異なる型の間の写像は零であり、一つの型の自己準同型は各成分間の写像を並べた行列である。合成を計算すると行列積になり、$\End_R(R)\cong\prod_i M_{n_i}(\End_R S_i)$ である。一方 $R$ の自己準同型は $x\mapsto xa$ であり $a=f(1)$ が一意に決める。合成では右係数の順が逆になるので、この環は $R^{\mathrm{op}}$ と同型である。反対環を取り、行列の転置が $M_n(E)^{\mathrm{op}}\cong M_n(E^{\mathrm{op}})$ を与えることを使うと、斜体は $D_i=(\End_R S_i)^{\mathrm{op}}$ となる。

逆に $M_n(D)$ は左正則加群として、各列を一つずつ残す部分加群の直和である。各列は先に示したように単純である。有限直積では各成分の単純加群に対応する射影を通して作用を入れられ、それらの直和が正則加群全体となる。よって半単純である。一意性は正則加群の組成因子の型と重複度が Jordan–Hölder で一意であることから従う。実際、各行列環成分には対応する列加群がサイズの個数だけ現れ、別成分の列加群とは作用する成分が異なるので同型でない。斜体はその自己準同型環の反対環として復元できる。
:::

:::example[単純な型の個数と重複度]
$R=M_2(\R)\times\C$ では左正則加群は $\R^2$ 型を二個、$\C$ 型を一個含む。長さは $3$ である。第一の型には第 2 成分が零作用し、第二の型には第 1 成分が零作用するので二型は同型にならない。自己準同型斜体はそれぞれ $\R,\C$ である。
:::

:::example[行列成分を組成因子から復元する]
半単純環の正則加群で、同型でない単純型 $S,T$ がそれぞれ三回と二回現れ、自己準同型環が $\R$ と $\mathbb H^{\mathrm{op}}$ であるとする。異なる型の間の写像は零なので、正則加群の自己準同型環は $M_3(\R)\times M_2(\mathbb H^{\mathrm{op}})$ となる。正則加群では右積の合成により反対環が現れるため、環そのものは $M_3(\R)\times M_2(\mathbb H)$ になる。左正則加群の長さは $3+2=5$ である。この直積の実次元を数えると、実係数が九個、四元数係数が四個あるので $9+4\cdot4=25$ を得る。長さは列加群の個数で決まり、実次元には列ごとの係数の次元も加わる。
:::

### 行列単位を使って加群を座標に分ける

:::proposition[行列環の加群における列の取り出し]{#prop-ring-matrix-module-reconstruct}
$R=M_n(D)$、$D$ は斜体とし、$e=E_{11}$ とする。左 $R$ 加群 $M$ の $W=eM$ は $eRe\cong D$ 上の左ベクトル空間であり、$W$ の基底の各元から一つずつ自然な列加群を得て、$M$ はそれらの直和に分かれる。
:::

:::proof
$w\in W$ に $d\in D$ を掛けるとは、$dE_{11}$ を左から作用させることである。$E_{11}$ は $W$ で恒等なので左 $D$ ベクトル空間の公理を満たす。任意の $m$ は $\sum_{i=1}^n E_{i1}(E_{1i}m)$ と書け、$E_{1i}m\in W$ である。逆に $\sum_i E_{i1}w_i=0$ に $E_{1j}$ を左から掛けると $w_j=0$ が分かる。従って $W$ の基底を $\{w_\alpha\}$ とすると各 $m$ は $E_{i1}$ を通した有限個の $w_\alpha$ の係数で一意に書ける。行列 $A=(a_{ij})$ について $AE_{j1}=\sum_i E_{i1}(a_{ij}E_{11})$ だから、各 $\alpha$ に関する $n$ 個の係数への作用は通常の列への左行列積である。
:::

:::example[独立な列の行き先を行列にする]
$M_{2}(\Q)$ の列加群で、入力と指定した出力の組をそれぞれ列として並べる。入力の行列を $V=\begin{pmatrix}1&2\\2&3\end{pmatrix}$、出力の行列を $W=\begin{pmatrix}3&2\\0&1\end{pmatrix}$ とする。$\det V=-1\ne0$ なので入力列は基底である。従って全ての指定を満たす作用 $A$ は $AV=W$、すなわち $A=WV^{-1}$ で一意に定まる。

| $i$ | $V^{-1}e_i$ | $A e_i$ |
| --- | --- | --- |
| $1$ | $\begin{pmatrix}-3\\2\end{pmatrix}$ | $\begin{pmatrix}-5\\2\end{pmatrix}$ |
| $2$ | $\begin{pmatrix}2\\-1\end{pmatrix}$ | $\begin{pmatrix}4\\-1\end{pmatrix}$ |

表では標準基底 $e_i$ を入力列の組で表した係数を求め、その係数で出力列を合成した。従って $A$ は右列を並べた行列 $\begin{pmatrix}-5&4\\2&-1\end{pmatrix}$ である。これを $V$ に掛けると各列は確かに指定した値になる。入力が基底全体でなければ、入力を基底へ延長して残りの列を自由に選べる。ここで一意になるのは全ての方向の作用を指定したためである。
:::

:::example[行列環と斜体を正則加群から区別する]
$R=M_2(\mathbb H)\times\R$ の左正則加群は、第一成分から $\mathbb H^2$ 型を二つ、第二成分から $\R$ 型を一つ持つ。第一型の実次元は $8$、第二型は $1$ なので、全実次元は $2\cdot8+1=17$ である。長さは $3$ である。第一型の自己準同型は右からの四元数の作用であり、合成は反対順序になる。従ってその自己準同型環は $\mathbb H^{\mathrm{op}}$ である。これを行列環の斜体へ戻す段階でもう一度反対環に移る。実次元の計算だけではこの積の順序は分からない。
:::

:::example[単純環の中心を復元する]
$R=M_3(D)$ で $E_{ii}$ と可換な元は全て対角である。さらに $E_{ij}$ と可換なら対角成分は同一の $a$ である。対角上の $dE_{ii}$ と可換であることは $ad=da$ と同値である。従って中心は $Z(D)I$ である。例えば $D=\mathbb H$ では $i,j$ と共に可換な四元数は実数に限るので、$M_3(\mathbb H)$ の中心は $\R$ である。よって $M_3(\C)$ と $M_3(\mathbb H)$ はともに正則加群の長さが $3$ でも、中心の体が異なるため同型ではない。
:::

## Jacobson 根基と Nakayama の補題

### 全ての単純加群を消す元

:::definition[Jacobson 根基]{#def-ring-jacobson}
全ての極大左イデアルの共通部分を :term[Jacobson 根基]{en="Jacobson radical" yomi="やこぶそんこんき"} $J(R)$ と呼ぶ。空の共通部分は $R$ とする。
:::

:::proposition[根基の判定]{#prop-ring-jacobson-test}
$J(R)$ は全ての単純左加群の零化イデアルの共通部分であり、両側イデアルである。$a\in J(R)$ であるための必要十分条件は、全ての $r\in R$ に対して $1-ra$ が単元となることである。
:::

:::proof
単純加群の任意の非零元 $s$ に対し $r\mapsto rs$ の核は極大左イデアルなので、共通部分の元は全ての $s$ を消す。逆に極大左イデアル $L$ に対し単純加群 $R/L$ の $1+L$ を消す元は $L$ に入る。零化イデアルの共通部分だから両側イデアルである。

まず単元を左逆の存在に弱めた条件を考える。$a\in J(R)$ なら $1-ra$ が左逆をもたない場合、左イデアル $R(1-ra)$ が真である。Zorn の補題により極大左イデアルに含まれ、$ra$ もそこに入るので $1$ が入って矛盾する。逆に $a\notin J(R)$ なら $a\notin L$ となる極大左イデアルがあり、$L+Ra=R$ からある $r$ で $1-ra\in L$ となる。左逆があれば $1$ も入って矛盾する。最後に $a\in J(R)$ のとき $u=1-ra$ に左逆 $b$ を取ると $b=1+bra$ である。これも $1-r'a$ の形なので左逆 $c$ があり、$c=cbu=u$ となる。従って $ub=1$ も成り立ち、$u$ は単元である。
:::

:::theorem[Nakayama の補題]{#thm-ring-nakayama}
$I\subseteq J(R)$ を両側イデアル、$M$ を有限生成左加群とする。$IM=M$ なら $M=0$ である。また $M=N+IM$ なら $M=N$ である。
:::

:::proof
$M\ne0$ とする。真の部分加群の鎖の合併は真である。全体であれば、有限個の生成元が鎖の一段に全て入ってしまうからである。よって Zorn の補題で極大な真の部分加群 $L$ を取れる。単純商 $M/L$ は $I$ によって零化されるので $IM\subseteq L$ となり、$IM=M$ に反する。後半では有限生成な $M/N$ に最初の主張を適用する。
:::

:::example[局所環上の生成元を持ち上げる]
$(R,\mathfrak m)$ を可換局所環とする。$J(R)=\mathfrak m$ なので、有限生成 $M$ について $M/\mathfrak m M$ の基底を持ち上げた元が $M$ を生成する。実際、持ち上げの張る $N$ は $M=N+\mathfrak m M$ を満たす。例えば $R=\Z_{(5)}$ と $M=R/(25)\oplus R/(5)$ では商 $M/5M$ は $\F_5^2$ なので標準の二元が最小の生成系である。一元では商の二次元を張れない。
:::

:::proposition[左 Artin 環と根基零]{#prop-ring-artinian-radical}
環 $R$ が半単純であることと、左 Artin で $J(R)=0$ であることは同値である。
:::

:::proof
半単純なら正則加群は有限長であり、全ての単純左加群を消す元は正則加群の単純直和成分を消す。従って $1$ を消すため零である。逆に左 Artin なら極大左イデアルの有限個の共通部分の族に極小元 $L$ がある。空の共通部分 $R$ も許すので族は非空である。任意の極大左イデアルをさらに交わらせても極小性から変わらないので $L=J(R)=0$ である。従って $R$ から対応する有限個の単純商の直和への写像が単射である。半単純加群の部分加群も半単純なので結論を得る。
:::

:::corollary[単純 Artin 環の分類]{#cor-ring-simple-artin-matrices}
非零の単純環が左 Artin であれば、ある斜体 $D$ 上の行列環 $M_n(D)$ と同型である。逆に各 $M_n(D)$ は単純で左 Artin である。ここで単純環とは、両側イデアルが零と全体だけの非零環である。
:::

:::proof
非零環には極大左イデアルがあるので、単純環の Jacobson 根基は真の両側イデアル、従って零である。:ref[prop-ring-artinian-radical] から半単純であり、Wedderburn–Artin 分解が二つ以上の成分を持てば、成分一つだけを残した真の非零両側イデアルがある。従って成分は一つである。逆に $M_n(D)$ は左正則加群が有限個の単純列加群の直和なので左 Artin である。両側イデアルに非零行列 $X$ が入ったとき、$X$ の非零成分 $x_{ij}$ を行列単位で切り出すと $E_{ki}XE_{j\ell}=x_{ij}E_{k\ell}$ になる。$x_{ij}^{-1}E_{kk}$ を左から掛けると任意の $E_{k\ell}$ がそのイデアルに入り、対角和 $1$ も入る。
:::

### Artin 環では根基が有限回で消える

:::proposition[Artin 環の半単純商]{#prop-ring-artinian-radical-nilpotent}
左 Artin 環 $R$ の $J=J(R)$ はある $n$ で $J^n=0$ を満たす。また $R/J$ は半単純環である。
:::

:::proof
降鎖 $J\supseteq J^2\supseteq\cdots$ は停留する。安定した冪を $L$ とすると $L^2=L$、$JL=L$ である。$L\ne0$ だと仮定し、$LA\ne0$ となる左イデアル $A$ のうち極小なものを取る。$R$ 自身が候補であり、降鎖条件で極小なものがある。$Lx\ne0$ となる $x\in A$ を選ぶ。$Rx\subseteq A$ で $L(Rx)=Lx\ne0$ だから $Rx=A$ である。さらに $Lx$ は左イデアルで $L(Lx)=L^2x=Lx\ne0$ なので $Lx=A$ である。従って $JA=J(Lx)=Lx=A$ だが、$A$ は一元生成なので Nakayama の補題で零となる。これは $LA\ne0$ に反する。従って $L=0$ である。

剰余 $R/J$ は左正則加群の剰余なので左 Artin 環である。その極大左イデアルは $J$ を含む $R$ の極大左イデアルに対応する。定義で全ての極大左イデアルが $J$ を含むので、対応する共通部分は $J/J=0$ である。従って :ref[prop-ring-artinian-radical] により半単純環である。
:::

:::corollary[左 Artin 環の正則加群は有限長]{#cor-ring-hopkins-levitzki}
左 Artin 環は左 Noether 環である。またその上の有限生成左加群は有限長である。
:::

:::proof
前の命題を用いると、$R=J^0\supseteq J\supseteq\cdots\supseteq J^n=0$ は有限の列である。各層 $J^i/J^{i+1}$ は $J$ によって消されるから、半単純環 $R/J$ 上の加群として半単純である。さらに正則加群の部分加群の商なので Artin 加群である。単純直和に無限個の成分があれば、相異なる成分を一つずつ除いて真の降鎖を作れる。このため各層は有限個の単純成分からなり有限長である。長さの加法性により左正則加群も有限長となり、特に左 Noether である。有限生成左加群はこの正則加群の有限直和の商なので有限長である。
:::

:::proposition[冪零イデアルと加群の根基]{#prop-ring-module-radical-artinian}
冪零な両側イデアル $I$ は $J(R)$ に含まれる。$R/J(R)$ が半単純であれば、任意の左加群 $M$ の極大部分加群の共通部分は $J(R)M$ に等しい。
:::

:::proof
単純加群 $S$ で $IS$ は部分加群なので、非零なら $IS=S$ である。その場合 $I^kS=S$ が全ての $k$ で成り立ち、冪零性に反する。従って $I$ は全ての単純加群を消し、根基に含まれる。

極大部分加群 $L$ に対し単純商 $M/L$ は $J=J(R)$ で消されるので、$JM\subseteq L$ である。逆に $m$ が $JM$ に入らなければ、その像は半単純加群 $M/JM$ のある単純直和成分への射影で非零になる。その射影を商写像と合成すると単純加群への全射になり、核は $m$ を含まない極大部分加群である。よって共通部分は $JM$ に一致する。
:::

:::example[上三角行列の対角を残す]
体 $K$ 上の $3\times3$ 上三角行列環 $T$ を考える。狭義上三角行列のイデアル $N$ は $N^3=0$ を満たす。三つの成分を三回続けて掛けるには、添字が三回厳密に増える必要があり、三つの添字では起こらないためである。従って $N\subseteq J(T)$ である。逆に各対角成分の射影 $T\to K$ は全射で、$K$ はそれを通して単純左加群となるため $J(T)$ は各対角成分を零にする。よって $J(T)=N$ である。$E_{12}E_{23}=E_{13}\ne0$ から $N^2\ne0$ であり、半単純商は対角成分を組にした $K^3$ である。
:::

:::example[有限剰余環の根基とその冪を追う]
$R=\Z/(n)$ で $n$ の異なる素因数の積を $d$ とする。極大イデアルは各 $p\mid n$ に対する $(p)/(n)$ なので、その共通部分は $(d)/(n)$ である。$J^k$ は $[d^k]$ が生成するが、そのイデアルは $[\gcd(d^k,n)]$ によっても生成される。これは整数の Bézout 等式を法 $n$ に移せば分かる。最初に $J^k=0$ になる指数は $n$ の素因数の指数の最大値である。

| $18$ | $6$ | $3$ | $6$, $18$ | $2$ |
| $24$ | $6$ | $4$ | $6$, $12$, $24$ | $3$ |

### 左から定義しても右の根基と一致する

:::proposition[根基の左右対称性]{#prop-ring-jacobson-symmetric}
$J(R)$ は全ての極大右イデアルの共通部分にも等しい。
:::

:::proof
$1-ab$ が逆元 $u$ をもつとする。$1-ba$ と $1+bua$ をこの順に掛けると
$$
(1-ba)(1+bua)=1-ba+b(1-ab)ua=1
$$
である。逆順も $u(1-ab)=1$ を使って積が $1$ となる。$a,b$ を交換すれば逆向きも得られる。従って $1-ra$ が全ての $r$ について単元であることと、$1-ar$ が全ての $r$ について単元であることは同値である。:ref[prop-ring-jacobson-test] を $R$ とその反対環に適用すると、前者は左の共通部分への所属、後者は右の共通部分への所属を意味する。
:::

:::example[片方の逆元からもう片方の逆元を求める]
$R=M_2(\Q)$ で $a=E_{12}$、$b=2E_{21}$ とする。$ab=2E_{11}$、$ba=2E_{22}$ である。$1-ab=\diag(-1,1)$ は自分自身が逆元である。この逆元 $u$ に対し $bua=-2E_{22}$ なので $1+bua=\diag(1,-1)$ となり、実際 $1-ba$ の逆元である。この計算では $ab$ と $ba$ は異なる行列だが、単元性の判定は対応する。
:::

### 根基を割った後の冪等元を持ち上げる

:::lemma[冪零イデアルを越えた冪等元の持ち上げ]{#lem-ring-idempotent-lift}
$R$ を環、$I$ を両側イデアルとし、ある $m\ge1$ について $I^m=0$ とする。$R/I$ の各冪等元は $R$ の冪等元の像である。
:::

:::proof
$a$ を持ち上げとすると $b=a^2-a\in I$ であり、$a,b$ は可換である。$a'=a-(2a-1)b$ と置くと $a'-a\in I$ である。$c=2a-1$ と書けば $c^2=1+4b$ だから
$$
(a')^2-a'=b-c^2b+c^2b^2=-3b^2+4b^3
$$
となる。従って $b\in I^j$ なら次の誤差は $I^{2j}$ に入る。同じ式を新しい $a'$ に適用し、何回か繰り返すと $2^k\ge m$ となって誤差が零になる。各変更は $I$ の元だけなので、結果は元の剰余類を持ち上げる冪等元である。
:::

:::example[持ち上げは中心に入らず一意でもない]
上三角二次行列環 $T$ の根基は $J=KE_{12}$ であり、商は二つの対角成分の直積である。$(1,0)$ は商で中心冪等元である。$E_{11}$ と $E_{11}+cE_{12}$ は任意の $c\in K$ についてそこへ写り、後者も二乗すると $E_{11}+cE_{12}$ である。一方 $E_{12}$ と掛けた二順序はそれぞれ $E_{12}$ と零であり、いずれも $E_{12}$ と可換でない。このため商が二成分に分解しても、元の環に同じ直積分解があるとは限らない。元の環をその二部分に分けるには、冪等元の存在に加えて中心性が必要である。
:::

:::example[根基零だけでは半単純にならない]
$\Q[x]$ の任意の非零多項式 $f$ には $f(a)\ne0$ となる $a\in\Q$ が存在する。非零多項式の根の個数は次数以下であり、$\Q$ は無限集合だからである。従って $f$ は極大イデアル $(x-a)$ に入らず、全ての極大イデアルの共通部分は零である。しかし $(x)\supsetneq(x^2)\supsetneq\cdots$ は止まらず、$\Q[x]$ は Artin でない。さらに $0\to(x)\to\Q[x]\to\Q[x]/(x)\to0$ で $[1]$ の持ち上げは $x$ によって零にならないので、短完全列が分裂しない。このため根基が零であることだけでは、半単純性に必要な補部分を構成できない。
:::

## Jacobson の稠密性定理

### 有限個の独立なベクトルへの作用を指定する

:::theorem[Jacobson の稠密性定理]{#thm-ring-jacobson-density}
$V$ を単純左 $R$ 加群とし、$D=(\End_R V)^{\mathrm{op}}$ と置く。$V$ は $v\cdot f^{\mathrm{op}}=f(v)$ による右 $D$ ベクトル空間である。右 $D$ 上で一次独立な $v_1,\ldots,v_n$ と任意の $w_1,\ldots,w_n$ に対し、ある $r\in R$ が全ての $rv_i=w_i$ を満たす。
:::

:::proof
右作用の公理は反対環での積の反転と自己準同型の加法性で成り立つ。各 $r$ の左作用は自己準同型と可換なので右 $D$ 線形である。$n=1$ なら $v_1\ne0$ より $Rv_1=V$ である。帰納法で $n-1$ について成り立つとし、
$$
W=\{(rv_1,\ldots,rv_n)\mid r\in R\}\subseteq V^n
$$
を取る。最初の $n-1$ 成分への射影の像は帰納法で全体である。核は最後の成分内の部分加群であるため、単純性により $0$ または $V$ である。核が $V$ なら最初の成分を合わせた後に最後を任意に調整でき、$W=V^n$ である。

核が零なら射影は同型となり、$W$ は準同型 $F\colon V^{n-1}\to V$ のグラフになる。この $F$ は各成分からの自己準同型 $f_i$ の和として書ける。$r=1$ の組を考えると $v_n=\sum_{i<n} f_i(v_i)=\sum_{i<n}v_i\cdot f_i^{\mathrm{op}}$ となり独立性に反する。従って前の場合だけが可能である。
:::

有限次元の右 $D$ 空間なら、基底全体に定理を適用すると $R\to\End_D(V)$ は全射であり、核は $\operatorname{Ann}_R V$ である。このため $V$ が忠実、すなわち零化イデアルが零なら $R\cong M_n(D)$ となる。無限次元の場合に主張するのは有限個の元への作用を同時に実現できることである。従属な元を含む有限集合でも、その張る空間の基底の像を合わせれば指定した $D$ 線形写像と全ての元で一致できる。

有限集合 $F\subseteq V$ に対して、$D$ 線形写像 $T$ と $F$ 上で一致する写像の集合を $T$ の基本近傍とする。二つの基本近傍の共通部分では、指定する有限集合を合わせればよい。この近傍で定まる位相を :term[有限位相]{en="finite topology" yomi="ゆうげんいそう"} と呼ぶ。定理は、左作用による $R$ の像が $T$ のどの基本近傍にも入ること、すなわちこの位相で稠密であることを示す。

忠実単純左加群を持つ環を :term[左原始環]{en="left primitive ring" yomi="ひだりげんしかん"} という。例えば行列環の列加群は忠実単純である。逆に左原始環の忠実単純加群の右 $D$ 次元が有限なら、稠密性からその環は行列環である。この結論で基底を有限個に限る必要は、次の例で確かめられる。

### 有限個の指定と全体の指定を区別する

:::example[稠密な真の部分環]
$V$ を可算無限基底をもつ $K$ ベクトル空間とし、$R$ を $\End_K(V)$ のうち $\lambda 1+F$（$\lambda\in K$、$F$ は有限階数）で書ける写像全体とする。有限階数の写像の和は有限階数で、任意の写像との両側の合成でも有限階数になるため、$R$ は環である。非零 $v$ に対し $\phi(v)=1$ となる線形汎関数を選び、$F(u)=\phi(u)w$ とすると $v$ を任意の $w$ へ送れる。よって $V$ は単純左 $R$ 加群である。

任意の $R$ 線形自己準同型 $f$ は $K$ 線形であり、基底元一つへの座標射影と可換なのでその基底元をあるスカラー倍に送る。任意の二基底元を結ぶ行列単位とも可換なのでスカラーは全て等しい。従って $\End_R V=K$ である。任意の有限次元部分空間上の線形写像をその空間の補空間上で零に延長すれば、指定の作用を実現する有限階数の元が得られる。ところがシフト $e_j\mapsto e_{j+1}$ は $R$ に属さない。どの $\lambda$ についても $e_{j+1}-\lambda e_j$ は有限線形結合の最高添字を調べると一次独立であり、シフトから $\lambda 1$ を引いても階数が無限だからである。
:::

:::example[従属なベクトルの行き先には関係が残る]
$M_2(\Q)$ の列空間で $v_1=(1,0)^\top$、$v_2=(1,1)^\top$、$v_3=(2,1)^\top$ を取る。$v_3=v_1+v_2$ なので、任意の行列 $A$ で $Av_3=Av_1+Av_2$ を満たす。例えば $Av_1=(2,0)^\top$、$Av_2=(0,3)^\top$ を指定すると、第 1 列は $(2,0)^\top$、第 2 列は $Av_2-Av_1=(-2,3)^\top$ である。この行列で $Av_3=(2,3)^\top$ となる。$Av_3=(0,0)^\top$ も独立に指定することはできない。稠密性の定理の独立性の仮定は、有限個の値なら常に任意に選べるという主張を避けるために必要である。
:::

### 基底の行き先を指定して作用を求める

:::example[独立な列の行き先を行列にする]
$M_{2}(\Q)$ の列加群で、入力と指定した出力の組をそれぞれ列として並べる。入力の行列を $V=\begin{pmatrix}2&1\\3&2\end{pmatrix}$、出力の行列を $W=\begin{pmatrix}1&0\\2&3\end{pmatrix}$ とする。$\det V=1\ne0$ なので入力列は基底である。従って全ての指定を満たす作用 $A$ は $AV=W$、すなわち $A=WV^{-1}$ で一意に定まる。

| $i$ | $V^{-1}e_i$ | $A e_i$ |
| --- | --- | --- |
| $1$ | $\begin{pmatrix}2\\-3\end{pmatrix}$ | $\begin{pmatrix}2\\-5\end{pmatrix}$ |
| $2$ | $\begin{pmatrix}-1\\2\end{pmatrix}$ | $\begin{pmatrix}-1\\4\end{pmatrix}$ |

表では標準基底 $e_i$ を入力列の組で表した係数を求め、その係数で出力列を合成した。従って $A$ は右列を並べた行列 $\begin{pmatrix}2&-1\\-5&4\end{pmatrix}$ である。これを $V$ に掛けると各列は確かに指定した値になる。入力が基底全体でなければ、入力を基底へ延長して残りの列を自由に選べる。ここで一意になるのは全ての方向の作用を指定したためである。
:::

:::example[独立な列の行き先を行列にする]
$M_{3}(\Q)$ の列加群で、入力と指定した出力の組をそれぞれ列として並べる。入力の行列を $V=\begin{pmatrix}1&1&0\\0&1&2\\1&0&1\end{pmatrix}$、出力の行列を $W=\begin{pmatrix}0&2&1\\1&1&0\\3&0&2\end{pmatrix}$ とする。$\det V=3\ne0$ なので入力列は基底である。従って全ての指定を満たす作用 $A$ は $AV=W$、すなわち $A=WV^{-1}$ で一意に定まる。

| $i$ | $V^{-1}e_i$ | $A e_i$ |
| --- | --- | --- |
| $1$ | $\begin{pmatrix}\frac{1}{3}\\\frac{2}{3}\\- \frac{1}{3}\end{pmatrix}$ | $\begin{pmatrix}1\\1\\\frac{1}{3}\end{pmatrix}$ |
| $2$ | $\begin{pmatrix}- \frac{1}{3}\\\frac{1}{3}\\\frac{1}{3}\end{pmatrix}$ | $\begin{pmatrix}1\\0\\- \frac{1}{3}\end{pmatrix}$ |
| $3$ | $\begin{pmatrix}\frac{2}{3}\\- \frac{2}{3}\\\frac{1}{3}\end{pmatrix}$ | $\begin{pmatrix}-1\\0\\\frac{8}{3}\end{pmatrix}$ |

表では標準基底 $e_i$ を入力列の組で表した係数を求め、その係数で出力列を合成した。従って $A$ は右列を並べた行列 $\begin{pmatrix}1&1&-1\\1&0&0\\\frac{1}{3}&- \frac{1}{3}&\frac{8}{3}\end{pmatrix}$ である。これを $V$ に掛けると各列は確かに指定した値になる。入力が基底全体でなければ、入力を基底へ延長して残りの列を自由に選べる。ここで一意になるのは全ての方向の作用を指定したためである。
:::

:::example[有限個の値を変える自己準同型]
可算基底 $(e_i)_{i\ge0}$ を持つ空間 $V$ とし、有限階数写像とスカラー写像の和からなる環を取る。$v_1=e_0+2e_1$、$v_2=e_1$ をそれぞれ $e_3$ と $e_2-e_3$ に送りたい。$F(e_1)=e_2-e_3$ とし、$F(e_0)=e_3-2(e_2-e_3)=-2e_2+3e_3$ とすればよい。他の基底元は全て零に送る。像が二次元以内なので $F$ は環に属し、所望の二値を実現する。ただし他の基底の無限個の像まで任意に指定すると有限階数の条件に反することがある。指定範囲が有限次元であるため、像の次元も有限に抑えられた。
:::

:::example[独立な列の行き先を行列にする]
$M_{3}(\Q)$ の列加群で、入力と指定した出力の組をそれぞれ列として並べる。入力の行列を $V=\begin{pmatrix}2&2&0\\1&2&0\\1&1&1\end{pmatrix}$、出力の行列を $W=\begin{pmatrix}4&2&0\\2&2&-1\\0&1&3\end{pmatrix}$ とする。$\det V=2\ne0$ なので入力列は基底である。従って全ての指定を満たす作用 $A$ は $AV=W$、すなわち $A=WV^{-1}$ で一意に定まる。

| $i$ | $V^{-1}e_i$ | $A e_i$ |
| --- | --- | --- |
| $1$ | $\begin{pmatrix}1\\- \frac{1}{2}\\- \frac{1}{2}\end{pmatrix}$ | $\begin{pmatrix}3\\\frac{3}{2}\\-2\end{pmatrix}$ |
| $2$ | $\begin{pmatrix}-1\\1\\0\end{pmatrix}$ | $\begin{pmatrix}-2\\0\\1\end{pmatrix}$ |
| $3$ | $\begin{pmatrix}0\\0\\1\end{pmatrix}$ | $\begin{pmatrix}0\\-1\\3\end{pmatrix}$ |

表では標準基底 $e_i$ を入力列の組で表した係数を求め、その係数で出力列を合成した。従って $A$ は右列を並べた行列 $\begin{pmatrix}3&-2&0\\\frac{3}{2}&0&-1\\-2&1&3\end{pmatrix}$ である。これを $V$ に掛けると各列は確かに指定した値になる。入力が基底全体でなければ、入力を基底へ延長して残りの列を自由に選べる。ここで一意になるのは全ての方向の作用を指定したためである。
:::

:::example[零化イデアルで割ると忠実になる]
$R=M_2(\Q)\times\Q$ の列加群 $V=\Q^2$ に第一成分で作用を入れる。第二成分は全て零に作用するので、:ref[def-ring-module-annihilator]{text="零化イデアル"} は $0\times\Q$ を含む。第一成分の行列が全ての列を零に送れば、その各列が零でなければならない。そのため作用写像の核は第二成分を超えない。任意の右 $\Q$ 線形写像は行列を第一成分に置いて実現できるが、同じ行列を第一に持つ $R$ の元は全て同じ作用になる。従って有限次元の場合に稠密性から得る同型は $R/\operatorname{Ann}_R V\cong M_2(\Q)$ であり、$R$ 自身の同型を得るには忠実性が要る。
:::

## 演習問題

::::exercise{level=basic}
$\Z$ の単純加群を全て求めよ。

:::solution
単純加群は非零元一つで生成されるので、極大イデアルを法とする $\Z$ の剰余である。整数の極大イデアルは素数 $p$ に対する $(p)$ なので、答えは全ての $\Z/(p)$ である。これらは剰余が体なので実際に単純である。
:::
::::

::::exercise{level=basic}
$M_3(\Q)$ の左正則加群の長さを求めよ。

:::solution
行列を列ごとに分けると左加群として $\Q^3$ の三つのコピーの直和である。各列加群は非零列を全ての列に送れるため単純であり、長さは $3$ である。
:::
::::

::::exercise{level=basic}
$\Z/(12)$ の Jacobson 根基を求めよ。

:::solution
極大イデアルは $(2)/(12)$ と $(3)/(12)$ である。共通部分は $2$ と $3$ の公倍数の類なので $(6)/(12)=\{[0],[6]\}$ である。
:::
::::

::::exercise{level=basic}
$\Q[x]/(x^3)$ の Jacobson 根基を求めよ。

:::solution
$[x]$ は冪零なので、その像は任意の体剰余で零となる。従って全ての極大イデアルが $([x])$ を含む。このイデアルの剰余は $\Q$ なのでそれ自体が極大であり、唯一である。根基は $([x])$ である。
:::
::::

::::exercise{level=advanced}
$M_2(K)$ の自然な列加群 $V$ で、$v_1=(1,1)^\top,\ v_2=(1,0)^\top$ をそれぞれ $(2,3)^\top,(4,5)^\top$ に送る行列を求めよ。

:::solution
$v_2=e_1$ なので第 1 列は $(4,5)^\top$ である。$v_1-v_2=e_2$ なので第 2 列は $(2,3)^\top-(4,5)^\top=(-2,-2)^\top$ である。従って行列は $\begin{pmatrix}4&-2\\5&-2\end{pmatrix}$ で、指定値を再現する。
:::
::::

::::exercise{level=advanced}
両側イデアル $I$ がある $n$ で $I^n=0$ となるとき、$I\subseteq J(R)$ を示せ。

:::solution
$a\in I$ と任意の $r$ に対し $ra\in I$ なので $(ra)^n=0$ である。有限等比和 $1+ra+\cdots+(ra)^{n-1}$ は $1-ra$ の両側逆元である。:ref[prop-ring-jacobson-test] により $a\in J(R)$ である。
:::
::::

::::exercise{level=advanced}
半単純可換環は有限個の体の直積であることを示せ。

:::solution
Wedderburn–Artin の分解で $n_i\ge2$ なら $E_{12}E_{21}\ne E_{21}E_{12}$ により非可換となる。従って全て $n_i=1$ であり、各斜体は可換性により体である。逆は各体が行列サイズ $1$ の場合なので半単純である。
:::
::::

::::exercise{level=advanced}
可換局所環 $R$ について有限生成加群 $M$ が $M/\mathfrak m M=0$ を満たすなら $M=0$ を示し、有限生成性を外す反例を示せ。

:::solution
$J(R)=\mathfrak m$ なので $M=\mathfrak m M$ に Nakayama の補題を適用する。反例は $R=\Z_{(2)}$ とその分数体 $\Q$ である。$2$ が $\Q$ で可逆なので $\mathfrak m\Q=2\Q=\Q\ne0$ である。有限個の有理数の分母の $2$ の指数には上限があり、$R$ の係数は分母に $2$ を加えられない。従ってより大きな $2$ の冪を分母とする元を生成できず、$\Q$ は有限生成でない。
:::
::::

::::exercise{level=advanced}
$R=\Z/(200)$ の $J=J(R)$ と、$J^j$ が初めて零になる指数を求めよ。

:::solution
$200=2^3\cdot5^2$ なので極大イデアルの共通部分は $([10])$ である。$J^2=([100])\ne0$ であり、$1000$ は $200$ の倍数なので $J^3=0$ である。従って最初の指数は $3$ である。法 $8$ と法 $25$ の成分ではそれぞれ $(2)^3=0$、$(5)^2=0$ となり、その大きい方まで必要である。
:::
::::

## 確認テスト

::::quiz
単純加群 $S$ について $\End_R S$ は常に何になるか。

- [x] 斜体
- [ ] 可換体
- [ ] 零環

:::explanation
非零写像は核が零で像が全体となるので可逆である。また恒等写像は非零である。斜体 $D$ を左正則加群として取ると自己準同型環が $D^{\mathrm{op}}$ になるため、可換性は一般には従わない。
:::
::::

::::quiz{answer="3" tol="1e-9"}
$M_2(\Q)\times\Q$ の左正則加群の長さを求めよ。

:::explanation
行列成分には二つの単純な列加群が現れ、体成分は自分自身が単純である。従って長さは $2+1=3$ である。
:::
::::

::::quiz
半単純環上で必ず成り立つものを選べ。

- [x] 全ての左加群の短完全列は分裂する。
- [ ] 全ての左加群は単純である。
- [x] Jacobson 根基は零である。

:::explanation
半単純加群の部分加群は直和因子なので全ての短完全列が分裂する。根基の元は正則加群の単純成分を全て消すので零である。一方、非零の単純加群を二つ直和すると真の部分加群ができる。
:::
::::

::::quiz{answer="3" tol="1e-9"}
$\Z/(18)$ の Jacobson 根基に属する元の個数を求めよ。

:::explanation
極大イデアルは $(2)/(18)$ と $(3)/(18)$ であり、共通部分は $(6)/(18)$ である。この集合は $[0],[6],[12]$ の三元である。
:::
::::

::::quiz{answer="7" tol="1e-9"}
$M_4(\Q)\times M_3(\C)$ の左正則加群の組成列の長さはいくつか。

:::explanation
第一の環の各列は一つの単純部分加群を与え、列ごとの直和で左正則加群になっているので長さは $4$ である。第二の環も同じ理由で長さは $3$ である。有限直積ではこれらの全列を直和として取れるため、長さは $4+3=7$ である。
:::
