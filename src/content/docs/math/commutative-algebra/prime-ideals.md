## この章の目標

- イデアルの積、共通部分、商を計算する。
- 素イデアルの存在定理から根基の表示を導く。
- 中山の補題で有限生成加群の生成元を判定する。
- Zariski 位相の閉集合と基本開集合を求める。
- 環準同型に付随する連続写像を追跡する。

環は単位元をもつ可換環、準同型は単位元を保つものとする。イデアルの基礎は [環とイデアル](/math/rings-modules/rings/) を参照する。素イデアルの商による判定は :ref[thm-ring-prime-max-quotient] でも扱う。零環も許すが、整域と体では $1\ne0$ とする。

## イデアルの演算と商環

方程式をまとめて課すときは、各方程式の環の係数による線形結合も同時に零になる。そこで式のリストを、その線形結合全体に置き換える。

:::definition[イデアルの演算]{#def-comm-ideal-operations}
$I,J$ を環 $A$ のイデアルとする。$I+J$ は $i+j$ の全体、$IJ$ は $ij$ の有限和の全体である。共通部分 $I\cap J$ もイデアルである。さらに $(I:J)=\{a\in A\mid aJ\subset I\}$ を :term[イデアル商]{en="ideal quotient" yomi="いであるしょう"} という。$J=(b)$ のとき $(I:b)$ と略記する。
:::

:::proposition[積と商の計算]{#prop-comm-ideal-calculus}
$IJ\subset I\cap J$ が成り立つ。$I+J=A$ ならば $IJ=I\cap J$ であり、自然な写像は $A/(IJ)\simeq A/I\times A/J$ を誘導する。任意のイデアル $L$ について $LJ\subset I$ と $L\subset(I:J)$ は同値である。
:::

:::proof
積の各項は両方のイデアルに属する。$1=i+j$ と書けるとき、$a\in I\cap J$ に対して $a=ai+aj\in IJ$ となる。対 $(\bar u,\bar v)$ は $ju+iv$ の像であり、自然な写像は全射である。核は $I\cap J$ である。最後の同値は、$LJ$ が $\ell j$ で生成されることから従う。
:::

:::example[整数環での計算]
$\Z$ で $(12)+(18)=(6)$、$(12)(18)=(216)$、$(12)\cap(18)=(36)$ となる。和の生成元は最大公約数、共通部分の生成元は最小公倍数である。$12\mid18a$ は $2\mid a$ と同値なので $(12:18)=(2)$ である。
:::

:::example[同じ零点と異なる商環]
$k[x]$ で $(x^2)\subsetneq(x)$ である。$k[x]/(x)$ は $k$ だが、$k[x]/(x^2)$ では $x$ の像が零でなく、その平方が零になる。この差は後に閉集合へ移ると消える。
:::

:::proposition[商環のイデアル対応]{#prop-comm-ideal-correspondence}
$A/I$ のイデアルは $I$ を含む $A$ のイデアルと、逆像によって包含を保って一対一に対応する。また $J\supset I$ に対して $(A/I)/(J/I)\simeq A/J$ である。
:::

:::proof
商写像 $\pi$ は全射なので $\pi(\pi^{-1}H)=H$ である。逆に $\pi(a)\in\pi(J)$ ならば $a-j\in I$ となる $j\in J$ があり、$a\in J$ である。商写像 $A\to A/J$ は $A/I$ を経由し、その誘導写像の核は $J/I$ である。
:::

### 商写像とイデアル商を組み合わせる

:::example[二つの合成条件]
$A=k[x,y]$ で $I=(x^2,xy)$、$J=(x)$ とする。条件 $fx\in I$ は、ある $g,h$ で $fx=gx^2+hxy$ と書けることである。多項式環は整域なので $x$ を消去でき、$f=gx+hy$ となる。従って $(I:J)=(x,y)$ である。ここで先に $A/I$ に移ると、$x$ による乗法の核は $(x,y)/I$ である。この核が「$x$ を掛けると零になる元」を直接表す。

一方、同じ $I$ について $(I:y)=(x)$ である。$fy\in I$ なら $x$ が $fy$ を割るので、$x$ が $y$ を割らないことから $x\mid f$ となる。逆に $f=xg$ なら $fy=xyg\in I$ である。$x$ と $y$ の役割が対称でないのは、$x^2$ は関係式にあり $y^2$ がないためである。
:::

:::proposition[商の反復]{#prop-comm-colon-identities}
任意のイデアル $I,J,K$ に対し $((I:J):K)=(I:JK)$ であり、$(I:J+K)=(I:J)\cap(I:K)$ である。また $(I\cap J:K)=(I:K)\cap(J:K)$ である。
:::

:::proof
$a\in((I:J):K)$ は、任意の $k\in K$ で $ak\in(I:J)$、すなわち任意の $j\in J,k\in K$ で $ajk\in I$ と同値である。有限和によりこれは $aJK\subset I$ と同値である。第二式では $a(J+K)\subset I$ を二つの包含に分ける。第三式では $aK\subset I\cap J$ を二つの包含に分ける。
:::

生成イデアルの包含を確かめる場合、各生成元の所属を個別に判定できる。対照的にイデアルの積が含まれる場合の素性の使用では、両方のイデアルが含まれないときに一つずつ反例を取って積にする。例えば $(x)(y)\subset(xy)$ でも、$(x),(y)$ のいずれも $(xy)$ に含まれない。この事実を商で見ると $\bar x,\bar y$ の積が零であり、$(xy)$ が素でないことが分かる。

### 和・積・共通部分の区別

等式を同時に課すにはイデアルの和を取り、どちらか一方に属する点を集めるには積または共通部分を取る。この違いは商環にも現れる。

:::proposition[二つの商環の接合]{#prop-comm-ideal-fiber-product}
$I,J\subset A$ に対し、$A/(I\cap J)$ は $A/I\times A/J$ のうち二つの成分が $A/(I+J)$ で一致する組のなす部分環に同型である。また $(I+J)=A$ なら $I\cap J=IJ$ である。
:::

:::proof
写像 $a\mapsto(a+I,a+J)$ の核は $I\cap J$ である。組 $(a+I,b+J)$ が $A/(I+J)$ で一致するとは、$a-b=i+j$ と $i\in I,j\in J$ で書けることである。このとき $a-i=b+j$ が同じ組を与える。さらに $I+J=A$ なら $1=i+j$ と書ける。$r\in I\cap J$ に対して $r=ri+rj$ であり、右辺の各項は $IJ$ に入る。$IJ\subset I\cap J$ は積の定義から従う。
:::

:::example[座標軸上の値を接合する]
$A=k[x,y]$、$I=(y)$、$J=(x)$ とする。$I\cap J=(xy)$ である。実際、両方に属する多項式の各単項式は $xy$ を因子にもつ。$A/I=k[x]$ と $A/J=k[y]$ の共通の商は $k$ であるから、二つの多項式 $p(x),q(y)$ は定数項が等しい場合に接合できる。その値を $c$ とすると $p(x)+q(y)-c$ が一つの持ち上げである。例えば $(2+x^2,2-y)$ の持ち上げは $2+x^2-y$ である。
:::

:::example[合同条件が衝突する場合]
$\Z$ で $I=(12)$、$J=(18)$ を取ると和、共通部分、積は順に $(6),(36),(216)$ である。$a\equiv5\pmod{12}$ と $a\equiv11\pmod{18}$ は両辺が法 $6$ で一致するため接合できる。実際 $a=29$ が解で、全解は $29+36\Z$ である。第二の条件を $a\equiv10\pmod{18}$ に変えると法 $6$ で一致しないので解がない。
:::

### 元を消す条件を商として使う

$a\in A$ と $I\subset A$ を取る。$A/I$ で $a$ を掛ける写像の核は $(I:a)/I$ であり、像は $(I+(a))/I$ である。実際、$r+I$ が核に属する条件は $ra\in I$ で、像の元は $ra+I$ と書ける。従って完全列

$$
0\longrightarrow A/(I:a)\xrightarrow{\ \cdot a\ } A/I\longrightarrow A/(I+(a))\longrightarrow0
$$

を得る。第一の写像は $r+(I:a)$ を $ra+I$ に送る。$A/I$ 上の乗法写像が単射であることと $(I:a)=I$ は同値である。

:::example[次数ごとの標準形]
$I=(x^3,x^2y,y^4)\subset k[x,y]$ とする。$x$ を掛けて $I$ に入る単項式は $x^2,xy,y^4$ のいずれかで割れる。よって $(I:x)=(x^2,xy,y^4)$ である。$I+(x)=(x,y^4)$ なので、$A/I$ の基底を $x$ で割れる部分と割れない部分に分けられる。前者は $x,x^2,xy,xy^2,xy^3$ の $5$ 個、後者は $1,y,y^2,y^3$ の $4$ 個であり、全体で $9$ 個である。前者を $x$ で割ると $A/(I:x)$ の基底に移る。
:::

### 積が共通部分と異なる理由を商で捉える

$I\cap J$ と $IJ$ の違いを調べるとき、両方の条件を満たす元が積から作れるかを見ればよい。例えば $A=k[x,y]$ で $I=(x,y^2)$、$J=(x^2,y)$ とする。共通部分は $(x^2,xy,y^2)$ であり、積は $(x^3,xy,x^2y^2,y^3)=(x^3,xy,y^3)$ である。前者の計算は両方に入る単項式を選ぶものであり、後者の計算は四組の生成元の積を並べるものである。特に $x^2,y^2$ は共通部分には入るが積には入らない。$A/IJ$ では、$(I\cap J)/IJ$ は $x^2,y^2$ を基底とする二次元の $k$ 加群となり、極大イデアル $(x,y)$ は双方を消す。

積と共通部分が同じ根基をもつことには素イデアルでの理由がある。$P$ が $IJ$ を含む素で $I\not\subset P$ なら、$a\in I\setminus P$ を一つ取り、任意の $b\in J$ について $ab\in P$ から $b\in P$ を得る。従って $IJ$ を含む素は $I$ または $J$ を含む。また $IJ\subset I\cap J$ であり、$I\cap J$ は $I,J$ のいずれにも含まれるので、$I\cap J$ を含む素も同じである。この一致が商環の素スペクトルにどう反映されるかは、後の Zariski 位相の節で扱う。

### 二つの商の完全列を組み立てる

:ref[prop-comm-ideal-fiber-product] は、$A$ 加群の短完全列としても使える。写像 $A/I\oplus A/J\to A/(I+J)$ を $(a+I,b+J)\mapsto(a-b)+(I+J)$ とすると、これは全射であり、核が接合可能な組全体である。従って
$$
0\longrightarrow A/(I\cap J)\longrightarrow A/I\oplus A/J
\longrightarrow A/(I+J)\longrightarrow0
$$
を得る。第一の矢印は商環の準同型であるが、最後の差を取る矢印は加群準同型である。例えば $(1,0)$ と $(0,1)$ の積は零だが、それらの像の積は $-1$ であり、一般に乗法を保たない。余核に現れる共通の商は、二つの点への評価が食い違う部分を測っている。

:::example[有限次元商で基底の個数を検算する]
$A=k[x,y]$、$I=(x^2,y)$、$J=(x,y^3)$ とする。$A/I$ の基底は $1,x$、$A/J$ の基底は $1,y,y^2$、$A/(I+J)$ は $k$ である。従って完全列より $A/(I\cap J)$ の次元は $2+3-1=4$ である。単項式で直接計算すると $I\cap J=(x^2,xy,y^3)$ であり、実際に $1,x,y,y^2$ が基底である。$x$ と $y$ の両方に関する関係を同時に課す商 $A/(I+J)$ と、二つの商の値を接合する $A/(I\cap J)$ では、求める像が異なる。
:::

## 極大イデアルの存在と素イデアル

商環で積が零になったとき、因子の一方が必ず零になる条件を考える。元を零にする操作と、この条件を結び付けるのが素イデアルである。

:::definition[素イデアルと極大イデアル]{#def-comm-prime-maximal}
真のイデアル $\mathfrak p$ が :term[素イデアル]{en="prime ideal" yomi="そいである"} であるとは、$ab\in\mathfrak p$ なら $a\in\mathfrak p$ または $b\in\mathfrak p$ となることをいう。真のイデアルの中で包含に関して極大なものを :term[極大イデアル]{en="maximal ideal" yomi="きょくだいいである"} という。
:::

$A/\mathfrak p$ が整域であることは、素イデアルの条件を商の元で書いたものである。:ref[prop-comm-ideal-correspondence] により、$\mathfrak m$ が極大であることは $A/\mathfrak m$ のイデアルが零と全体に限られることと同値である。後者の条件の下では非零元の生成するイデアルが全体となり、その元に逆元がある。従って極大イデアルは素イデアルである。

:::theorem[乗法的集合から離れた素イデアル]{#thm-comm-prime-separation}
$S\subset A$ は $1$ を含み積に閉じるとする。$I\cap S=\varnothing$ ならば $I$ を含み $S$ と交わらない素イデアルがある。
:::

:::proof
$I$ を含み $S$ と交わらないイデアルを包含で順序付ける。空でない鎖の合併はイデアルであり、合併が $S$ の元を含めば鎖のどれかもその元を含む。空の鎖には $I$ が上界となる。よって Zorn の補題で極大な $P$ を取れる。$a,b\notin P$ ならば $P+(a),P+(b)$ はそれぞれ $S$ の元 $s,t$ を含む。$ab\in P$ とすると積 $st$ は展開によって $P$ に属する。これは $st\in S$ に反する。
:::

$S=\{1\}$ とすれば任意の真のイデアルを含む極大イデアルが存在する。このため単元でない元は極大イデアルのどれかに属する。例えば $\Z[x]$ の $(2)$ は商が $\F_2[x]$ なので素であるが、$(2,x)$ に真に含まれる。後者は商が $\F_2$ なので極大である。唯一の極大イデアル $\mathfrak m$ をもつ環を :term[局所環]{en="local ring" yomi="きょくしょかん"} といい、$(A,\mathfrak m,k)$ と書く。ここで $k=A/\mathfrak m$ は剰余体である。

:::lemma[有限素回避]{#lem-comm-prime-avoidance}
イデアル $I$ が有限個の素イデアル $\mathfrak p_i$ の合併に含まれるなら、$I$ はいずれか一つに含まれる。
:::

:::proof
互いに包含のあるものから小さい方を除く。残りのどれにも $I$ が含まれないと仮定し、$x_i\in I\setminus\mathfrak p_i$ と、各 $j\ne i$ について $y_{ij}\in\mathfrak p_j\setminus\mathfrak p_i$ を取る。$z_i=x_i\prod_{j\ne i}y_{ij}$ は素性により $\mathfrak p_i$ の外にあり、他の全ての $\mathfrak p_j$ に入る。従って $\sum_i z_i\in I$ は全ての $\mathfrak p_i$ の外にある。
:::

### 素イデアルを商で検査する

:::example[整数係数の方程式]
$A=\Z[x]$ で $P=(3,x^2+1)$ とすると $A/P\simeq\F_3[x]/(x^2+1)$ である。$\F_3$ の平方は $0,1$ なので $x^2+1$ は既約であり、この商は $9$ 元の体である。従って $P$ は極大である。同じ根拠で $(3)$ は素だが、商 $\F_3[x]$ では $x$ が単元でないため極大ではない。$(5,x^2+1)$ の場合は $x^2+1=(x-2)(x+2)$ が法 $5$ で成立する。両因子の像は非零で積が零なので、このイデアルは素でない。
:::

:::example[極小の素を選ぶ]
$A=k[x,y,z]$、$I=(xy,xz)$ とする。$I$ を含む素 $P$ で $x\notin P$ ならば $y,z\in P$ となる。一方、$(x)$ と $(y,z)$ はどちらも商が多項式環なので素であり、互いに含まない。従って $I$ 上の極小素はこの二つである。さらに $I=(x)\cap(y,z)$ である。実際 $xg$ が $(y,z)$ に属するとき、$y=z=0$ を代入して $xg(x,0,0)=0$ となるため $g\in(y,z)$ である。
:::

一般に $I$ を含む素 $P$ の下には $I$ 上極小な素がある。実際、$I\subset Q\subset P$ を満たす素イデアルの全順序部分集合の共通部分は素である。$ab$ が共通部分に属し $a,b$ がそれぞれ共通部分に属さないなら、$a$ を含まない素と $b$ を含まない素の小さい方は両方を含まないので矛盾する。共通部分は $I$ を含むから、逆包含順序で Zorn の補題を適用できる。

### 有限素回避を選択に使う

有限素回避の証明では、冗長な素を除いて $P_i$ が互いに含まない形にする。イデアル $I$ が全ての $P_i$ に対して $I\not\subset P_i$ なら $a_i\in I\setminus P_i$ を取れる。また $j\ne i$ ごとに $b_{ij}\in P_j\setminus P_i$ を取る。$c_i=a_i\prod_{j\ne i}b_{ij}$ は $I$ に入り、$P_i$ の外であるが、他の全ての $P_j$ に入る。従って $\sum_i c_i$ は各 $P_i$ を避ける。この作り方は、係数体が有限の場合でも成り立つ。

:::example[三つの素を同時に避ける]
$A=\F_2[x,y]$ で $P_1=(x)$、$P_2=(y)$、$P_3=(x+y)$ とする。$I=(x,y)$ の非零一次式は $x,y,x+y$ の三つであり、それぞれどれかの素に入る。しかし $f=x^2+xy+y^2$ を取ると、各商への像は順に $y^2,x^2,x^2$ となり、全て非零である。有限体では一次結合だけを試すと失敗することがあるが、イデアルの積を使う素回避ではその制限がない。
:::

### 素でないイデアルも二つまで避けられる

:::proposition[二つの非素イデアルを許す有限回避]{#prop-comm-extended-prime-avoidance}
$I,J_1,\ldots,J_r$ をイデアルとし、$J_i$ のうち素でないものは高々二つとする。$I\subset\bigcup_i J_i$ ならば、ある $j$ で $I\subset J_j$ である。
:::

:::proof
どの $J_j$ も $I$ を含まないと仮定する。別の $J_i$ に入るものは合併から除けるので、$J_i$ は互いに含まないとしてよい。まず非素イデアルを全部避ける $a\in I$ を選ぶ。二つ $J_1,J_2$ を避ける必要があるなら $a_i\in I\setminus J_i$ を選び、どちらももう一方を避けない場合だけ $a_1+a_2$ を取る。この和が例えば $J_1$ に入れば $a_2\in J_1$ なので $a_1\in J_1$ となって矛盾し、$J_2$ についても同じである。

$a$ が属する素 $J_i$ ごとに、$c_i\in I$ を $J_i$ の外で他の全ての $J_j$ の内側に選ぶ。これには $I\setminus J_i$ の一元と各 $J_j\setminus J_i$ の一元の積を使う。素性によって積は $J_i$ の外である。$a+\sum_i c_i$ は、非素 $J_j$ および $a$ が最初から避けた素 $J_j$ では $a$ と同じ剰余をもつ。$a\in J_i$ だった各素では $c_i$ と同じ非零の剰余をもつ。従ってこの元は全てを避け、最初の包含と矛盾する。
:::

:::example[非素イデアルも混ぜて回避する]
$\Z$ で $I=(6)$、$J_1=(12)$、$J_2=(18)$、$J_3=(5)$ とする。$30$ は法 $12,18$ で零にならないが、$(5)$ に入る。$c=36$ は $I$、$(12)$、$(18)$ に入り、$5$ で割れない。そのため $30+36=66$ は法 $12,18$ ではそれぞれ $6,12$、法 $5$ では $1$ となって、三つを同時に避ける。二つの非素イデアルでの剰余を変えずに、最後の素だけから抜け出した。
:::

:::example[無限族には有限素回避を使えない]
$k[x,y]$ の $(x,y)$ を取る。そこに属する任意の非零多項式 $f$ は定数項が零である。$f$ を既約分解すると定数項の積が零になるため、既約因子の少なくとも一つ $g$ の定数項が零であり、$f\in(g)$ となる。UFD なので各 $(g)$ は素である。従って $(x,y)$ はこの無限族の合併に含まれる。一方、そこに現れる一つの $(g)$ が $x,y$ の両方を含むことはない。互いに素な $x,y$ に共通の非単元の約数はないためである。有界な数の条件を避ける証明で、ほかの全イデアルから選んだ元を掛ける段階には有限性が必要である。
:::

## ニルラジカルと Jacobson 根基

多項式 $f^2$ を零にしても、点での値を体の中で測る限り $f$ は零に見える。この操作で失われる元を根基が記録する。

:::definition[二種類の根基]{#def-comm-radicals}
$\sqrt I=\{a\mid a^n\in I\text{ となる }n\ge1\text{ がある}\}$ を $I$ の :term[根基]{en="radical" yomi="こんき"} と呼ぶ。$\sqrt{(0)}$ を :term[ニルラジカル]{en="nilradical" yomi="にるらじかる"} と呼ぶ。全極大イデアルの共通部分を :term[Jacobson 根基]{en="Jacobson radical" yomi="やこぶそんこんき"} $J(A)$ と書く。空共通部分は $A$ と約束する。
:::

:::theorem[根基の素イデアル表示]{#thm-comm-radical-intersection}
$\sqrt I=\bigcap_{\mathfrak p\supset I}\mathfrak p$ であり、特に $\sqrt I$ はイデアルである。
:::

:::proof
素イデアルは、元の正のべきが入れば元も含む。逆向きには $a\notin\sqrt I$ に対し $S=\{1,a,a^2,\ldots\}$ を取る。:ref[thm-comm-prime-separation] が与える素イデアルは $I$ を含み、$a$ を含まない。
:::

これより $\sqrt{IJ}=\sqrt{I\cap J}=\sqrt I\cap\sqrt J$ となる。実際、素イデアルが積を含むなら一方を含む。どちらのイデアルも含まなければ、各イデアルから素イデアルの外の元を取れる。その積も外に残るためである。また $\sqrt{\sqrt I}=\sqrt I$ は、$a^n\in\sqrt I$ なら $(a^n)^m\in I$ となることから従う。$A$ が被約であるとは $\sqrt{(0)}=0$ をいう。

:::proposition[単元による Jacobson 根基の判定]{#prop-comm-jacobson-unit}
$a\in J(A)$ であるための必要十分条件は、全ての $b\in A$ に対して $1-ab$ が単元となることである。
:::

:::proof
$a$ が全極大イデアルに入るなら、$1-ab$ が極大イデアルに入ることはない。逆に $a\notin\mathfrak m$ ならば、体 $A/\mathfrak m$ で $\bar a$ の逆元を持ち上げた $b$ に対して $1-ab\in\mathfrak m$ となる。
:::

:::example[二種類の根基の差]
$\Z/72\Z$ では極大イデアルが $(2),(3)$ であり、共通部分は $(6)$ である。$6^3$ は $72$ で割り切れるので、$(6)$ はニルラジカルにも一致する。一方、$\Z_{(2)}=\{a/b\in\Q\mid b\text{ は奇数}\}$ では、分子が奇数の元は単元であり、残る元は $(2)$ をなす。この環は整域なのでニルラジカルは $0$ だが、Jacobson 根基は $(2)$ である。
:::

### 根基の冪と冪零元の個数

:::lemma[有限生成された根基の冪]{#lem-comm-radical-power}
$\sqrt I=(a_1,\ldots,a_s)$ で $a_i^{e_i}\in I$、$e_i\ge1$ とする。$N=1+\sum_i(e_i-1)$ と置くと $(\sqrt I)^N\subset I$ である。
:::

:::proof
$N$ 次の積 $a_1^{n_1}\cdots a_s^{n_s}$ ですべての $n_i<e_i$ なら、全次数は高々 $\sum_i(e_i-1)$ となる。従って $N$ 次の積は少なくとも一つの $a_i^{e_i}$ を因子にもち、$I$ に入る。これらの積が $(\sqrt I)^N$ を生成する。
:::

:::example[冪零指数の上界と実際の指数]
$A=k[x,y]/(x^3,y^4)$ とする。$x,y$ の像が生成するイデアルの $6$ 乗は零であり、その商は $k$ であるため、それがニルラジカルである。一方 $x^2y^3$ は零でないのでニルラジカルの $5$ 乗は残る。ただし個々の元の指数は異なる。例えば標数 $2$ では $(x+y)^4=x^4+y^4=0$ だが、標数 $0$ では $(x+y)^5=10x^2y^3\ne0$ である。
:::

:::example[根基の元がどれも冪零でも一様な冪はない]
$A=k[x_1,x_2,\ldots]/(x_i^2\mid i\ge1)$ とする。定数項が零の元は有限個、例えば $s$ 個の変数だけを使う。$s+1$ 個の正次数単項式を掛ければ重なる変数があるので、その元の $s+1$ 乗は零である。一方積 $x_1\cdots x_N$ は任意の $N$ について商で非零である。よってニルラジカルのどのべきも零にならない。
:::

### 別の環へ移ったときの根基

準同型 $f:A\to B$ と $J\subset B$ に対し $f^{-1}(\sqrt J)=\sqrt{f^{-1}(J)}$ である。$a$ の像のべきが $J$ に入る条件は $a^n$ が縮約に入る条件そのものだからである。一方、拡大では $\sqrt I B\subset\sqrt{IB}$ であって、等号は一般に成り立たない。例えば $A=k[t]$、$B=k[u]$ を $t=u^2$ で結ぶと、$I=(t)$ は根基だが $IB=(u^2)$ の根基は $(u)$ である。なお $\sqrt{\sqrt I B}=\sqrt{IB}$ は成り立つ。包含 $I\subset\sqrt I$ を拡大して一方を得て、逆向きは $\sqrt I$ の各元のべきが $I$ に入ることから得る。

Jacobson 根基の振る舞いは縮約でも一般には同じでない。$\Z_{(3)}\to\Q$ の逆像で $J(\Q)=0$ は零に戻るが、$J(\Z_{(3)})=(3)$ である。単元判定を適用する際には、元の環での逆元と拡大先に新たに現れた逆元を区別する。

### 冪等元を冪零誤差から持ち上げる

:::proposition[冪零な誤差をもつ冪等元]{#prop-comm-idempotent-nil-lift}
$N$ を $A$ の元がすべて冪零であるイデアルとする。$A\to A/N$ は冪等元の一対一対応を与える。
:::

:::proof
$\bar e^2=\bar e$ の持ち上げを $a$ とすると $r=a^2-a$ は冪零である。$(2a-1)^2=1+4r$ は有限な幾何級数で可逆なので、$2a-1$ も単元である。$b=a-r/(2a-1)$ で補正すると $b$ は同じ持ち上げであり、$b^2-b=r^2/(2a-1)^2$ となる。従って繰り返し補正すれば誤差は元の $r$ の指数を二倍ずつ上げた式となり、ある段で零になる。

二つの冪等元 $e,f$ が $A/N$ で等しいとする。$(e-f)(e+f-1)=0$ であり、$e+f-1=(2e-1)+(f-e)$ である。$2e-1$ の平方は $1$、$f-e$ は冪零なので、後者は単元に冪零元を加えた形で可逆である。従って $e-f=0$ である。この証明では $N$ 全体を消す共通の指数を使わず、各誤差に対してその指数を取った。
:::

:::example[法 $6$ の冪等元を法 $36$ へ持ち上げる]
$A=\Z/36\Z$、$N=(6)$ とする。法 $6$ の $3$ は冪等元である。$a=3$ では $r=6$、$2a-1=5$ の逆元は $29$ なので $b=3-6\cdot29\equiv9\pmod{36}$ である。実際 $9^2-9=72$ で法 $36$ で零になる。中国剰余定理で見ると $9$ は法 $4$ で $1$、法 $9$ で $0$ である。元の $3$ は法 $2$ で $1$、法 $3$ で $0$ なので、両方の座標が対応している。
:::

## 中山の補題

剰余体で線形代数を行い、その結果から環上の加群の生成系を復元したい。有限生成性があると、係数行列の行列式によって係数の誤差を吸収できる。

:::lemma[行列式の技巧]{#lem-comm-determinant-trick}
$M$ を有限生成 $A$ 加群、$I$ をイデアルとし、$\phi(M)\subset IM$ となる $\phi\in\End_A(M)$ を取る。$M$ を消す作用素 $\phi^r+c_1\phi^{r-1}+\cdots+c_r$ が存在し、$c_j\in I^j$ とできる。
:::

:::proof
生成元 $m_1,\ldots,m_r$ に対して $\phi(m_i)=\sum_j a_{ij}m_j$、$a_{ij}\in I$ と書く。行列 $TI_r-(a_{ij})$ とその随伴行列との積は、その行列式を対角成分とするスカラー行列である。$T$ を $\phi$ として生成元の列に作用させると行列式は各 $m_i$ を消す。$T^{r-j}$ の係数は $a_{ij}$ を $j$ 個ずつ掛けた項の和なので $I^j$ に入る。
:::

:::theorem[中山の補題]{#thm-comm-nakayama}
$I\subset J(A)$ とし、$M$ を有限生成 $A$ 加群とする。部分加群 $N\subset M$ に対して $M=IM+N$ なら $M=N$ である。特に局所環で $M/\mathfrak m M$ の基底を持ち上げた元は $M$ の最小個数の生成系をなす。
:::

:::proof
$L=M/N$ は有限生成で $IL=L$ である。:ref[lem-comm-determinant-trick] で $\phi=\id_L$ と置くと $1+c$、$c\in I$ が $L$ を消す。:ref[prop-comm-jacobson-unit] により $1+c$ は単元なので $L=0$ である。局所環の場合は持ち上げの生成する部分加群を $N$ とする。任意の生成系の剰余類は剰余ベクトル空間を張るので、基底の次元より少ない個数では生成できない。
:::

:::example[生成元と有限生成性]
$A=k[x,y]/(x,y)^2$ の極大イデアル $\mathfrak m$ は $x,y$ の像を基底とする $k$ ベクトル空間であり、$\mathfrak m^2=0$ である。従って $\mathfrak m$ の最小生成元数は $2$ である。一方、$A=\Z_{(2)}$ 上の $\Q$ は $2\Q=\Q$ を満たすが非零である。従って $\Q$ は $A$ 上有限生成でない。有限生成性を外すと補題の結論が破れる。
:::

### 全ての元を消す係数と一つの生成元を消す係数

行列式の技巧からは Jacobson 根基を仮定しなくても結論が一つ得られる。$IM=M$ なら $1-a$、$a\in I$ が $M$ を消す。逆にこのような $a$ があれば任意の $m\in M$ は $am$ に等しいので $IM=M$ である。従って有限生成加群では $IM=M$ と $I+\operatorname{Ann}_A M=A$ は同値である。ここで $\operatorname{Ann}_A M=\{c\mid cM=0\}$ である。

:::example[Jacobson 根基に入らないイデアル]
$A=\Z$、$M=\Z/5\Z$ とする。$(2)M=M$ である。例えば $2\cdot3=6$ は商で $1$ であり、$1-6=-5$ は $M$ を消す。有限生成性は $IM=M$ から零化元の存在を与えるが、$-5$ は $\Z$ の単元ではないので $M$ を零とは結論できない。
:::

:::example[剰余体では基底でも自由とは限らない]
$A=k[t]/(t^3)$、$M=(t)\subset A$ とする。$M/(t)M$ の次元は $1$ で、その基底の持ち上げ $t$ は $M$ を生成する。しかし $A\to M$、$a\mapsto at$ の核は $(t^2)$ である。実際 $a=a_0+a_1t+a_2t^2$ と書くと $at=a_0t+a_1t^2$ なので、$at=0$ には $a_0=a_1=0$ が必要である。最小生成元数と自由階数を区別する必要がある。
:::

### 行列式の技巧を複数の加群に使う

:::proposition[加群を生成する元の最小個数]{#prop-comm-local-min-generators}
局所環 $(A,\mathfrak m,k)$ の有限生成加群 $M$ の最小生成元数を $\mu_A(M)$ と書くと、$\mu_A(M)=\dim_k M/\mathfrak m M$ である。生成系が包含に関して極小であることと、剰余類が $k$ 上の基底であることは同値である。
:::

:::proof
生成系の剰余類は全体を張る。従ってどの生成系の個数も右辺以上である。有限個の基底の持ち上げが生成する部分加群を $N$ とすれば $M=N+\mathfrak mM$ であり、:ref[thm-comm-nakayama] を $M/N$ に使うと $N=M$ である。生成系の剰余類に従属関係があれば、一つを除いても剰余体上で全体を張るため、同じ議論で元の加群を生成する。逆に剰余類が基底なら一つも除けない。
:::

:::example[ねじれのある加群の生成元数]
$A=\Z_{(3)}$、$M=A/(9)\oplus A/(27)\oplus A$ とする。$M/3M$ は $\F_3^3$ に同型であり、$M$ の最小生成元数は $3$ である。例えば $(1,1,0),(0,1,1),(0,0,1)$ は剰余類の座標行列の行列式が $1$ なので生成する。第三の元を $(0,0,3)$ に変えると剰余類が零になり、前の二つと合わせても生成しない。
:::

:::example[有限生成性を外した場合]
$M=\Q$ を $A=\Z_{(3)}$ 上の加群とすると $3M=M$ である。有限個の有理数を取って各分母の $3$ の指数の最大値を $n$ とすれば、それらの $A$ 線形結合はすべて $3^{-n}A$ に入る。しかし $3^{-(n+1)}$ はそこに入らない。従って $M$ は有限生成でなく、中山の補題の仮定を満たさない。
:::

### 有限生成加群の全射を環の単元問題に変える

$A$ 加群 $M$ の全射自己準同型 $\phi$ が同型であることは、$T\cdot m=\phi(m)$ として $M$ を $A[T]$ 加群にすることで示せる。$M$ は $A[T]$ 上も有限生成であり、全射性から $TM=M$ である。行列式の技巧を恒等写像に適用すると、ある $p(T)\in A[T]$ で $1-Tp(T)$ が $M$ を消す。従って $p(\phi)\phi=\phi p(\phi)=\id_M$ となり、逆写像を得る。ここでは $(T)$ が Jacobson 根基に属するとは限らないが、$1-Tp(T)$ が消すという情報を写像の等式として使える。

:::example[写像の逆を生成元から得る]
$M=(\Z/8\Z)^2$ 上で $\phi$ の行列を $\begin{pmatrix}1&2\\3&1\end{pmatrix}$ とする。行列式は $-5\equiv3\pmod8$ で単元だから全射である。特性多項式は $T^2-2T-5$ であり、$T=\phi$ に代入すると $\phi(\phi-2)=5\id$ となる。法 $8$ の $5^{-1}=5$ を掛けて $\phi^{-1}=5(\phi-2)$ を得る。実際その行列は $\begin{pmatrix}3&2\\7&3\end{pmatrix}$ であり、両者の積は単位行列に等しい。
:::

### 同じ剰余基底をもつ二つの表示

局所環 $(A,\mathfrak m,k)$ で有限加群 $M$ の二つの最小生成系を取る。両者の長さは $\dim_k M/\mathfrak mM$ で等しい。第二の各元を第一の元で表した行列を $C$ とする。剰余では二つの基底の取り換え行列なので $\det C\notin\mathfrak m$ である。従って $C$ は $A$ 上可逆である。第一の生成系の自由全射を $\pi:A^r\to M$、第二を $\pi'$ とすると $\pi'=\pi C$ なので、核は $\Ker\pi'=C^{-1}(\Ker\pi)$ と対応する。このため最小自由表示の階数は、生成元の持ち上げ方に依存しない。

:::example[生成系の取り換えで関係を移す]
$A=\Z_{(3)}$、$M=A/(3)\oplus A/(9)$ とする。標準生成元を $e_1,e_2$、新しい生成元を $f_1=e_1+e_2$、$f_2=e_2$ とする。行列は $\begin{pmatrix}1&0\\1&1\end{pmatrix}$ で可逆である。標準の関係 $3e_1=0,9e_2=0$ は $3f_1-3f_2=0,9f_2=0$ に移る。$f_1$ 自身は $3$ では消えないが、差 $f_1-f_2$ は消える。従って剰余基底だけから個々の元の零化イデアルは決まらず、関係を持ち上げるには行列を追う必要がある。
:::

## イデアルの拡大と縮約

環を変えると元の式は新しい係数で結合できる。逆に、新しい環で得た条件を元の環の元に読み替えることもできる。

:::definition[拡大と縮約]{#def-comm-extension-contraction}
$f:A\to B$ に対し、$I^e=f(I)B$ を $I$ の :term[拡大]{en="extension of an ideal" yomi="かくだい"}、$J^c=f^{-1}J$ を $J$ の :term[縮約]{en="contraction of an ideal" yomi="しゅくやく"} とする。
:::

:::proposition[拡大と縮約の随伴関係]{#prop-comm-extension-adjoint}
$I^e\subset J$ と $I\subset J^c$ は同値である。従って $I\subset I^{ec}$、$J^{ce}\subset J$、$I^{ece}=I^e$、$J^{cec}=J^c$ である。
:::

:::proof
$J$ はイデアルなので $f(I)\subset J$ と $f(I)B\subset J$ は同値である。ここから最初の二つの包含は $J=I^e$、$I=J^c$ を代入して得られる。$I\subset I^{ec}$ の拡大と $H^{ce}\subset H$（$H=I^e$）を合わせると $I^{ece}=I^e$ となる。$J$ に関する等式は二つの包含を縮約に適用して得られる。
:::

拡大は和と積を保つ。実際、拡大先でも和と積は像の加法と乗法で生成される。縮約は共通部分を保つ。これは集合の逆像の性質である。素イデアルの縮約は素である。$ab$ の像が素イデアルに入れば因子の像の一方が入り、$1$ の像は真のイデアルの外にあるからである。

:::example[逆操作で戻らない例]
$\Z\to\Q$ では $(6)^e=\Q$ なので $(6)^{ec}=\Z$ である。また $\Z\to\Z[i]$ に対し、$(1+i)$ の縮約は $(2)$ である。実際 $(1+i)(a+bi)=(a-b)+(a+b)i$ が整数となるには $b=-a$ が必要である。拡大し直した $(2)$ は $(1+i)^2$ と等しく、$(1+i)$ より小さい。
:::

### 核と分母の影響を見分ける

:::example[拡大して新たな倍数が現れる]
包含 $A=k[t^2,t^3]\subset k[t]=B$ と $I=(t^2)A$ を考える。$t^3=t\cdot t^2$ なので $t^3\in IB\cap A$ である。一方 $t^2a(t)$ の $t^3$ の係数は $a(t)$ の $t$ の係数である。$A$ の元には $t$ の項がないので $t^3\notin I$ である。したがって拡大・縮約は単射な環準同型でも元のイデアルを広げ得る。
:::

:::example[縮約して見失う生成元]
$A=k[x]$、$B=k[x,y]$ とし、$J=(y-x^2)$ を取る。$B\to k[x]$ の代入 $y\mapsto x^2$ は $x$ 上恒等であり、その核は、$y$ についてモニックな $y-x^2$ で割ることにより $J$ と分かる。従って $J\cap A=0$ である。これを再び $B$ に拡大しても $0$ なので、$J$ の方程式は $x$ の変数だけでは記録できない。
:::

$B=A[x]$ への包含ではどの $I\subset A$ も縮約で戻る。実際 $IB$ は係数がすべて $I$ に入る多項式全体である。特に定数多項式として入る元は $I$ そのものである。多項式変数を加えることと、元を別の環で新しい係数によって割ることは区別する必要がある。

### 剰余環と包含では何を縮約するか

全射 $A\to A/K$ では $I$ の拡大の縮約が $I+K$ になる。また商の任意の $J$ はその縮約の拡大である。これは :ref[prop-comm-ideal-correspondence] から従う。一方、$A\to A[x]$ では全ての $I$ は戻るが、$A[x]$ 側のイデアルが全て縮約から得られるわけではない。この二つの方向を区別すると、どちら側からイデアルを指定すべきか分かる。

:::example[同じ縮約から二つの素が出る]
$A=\Q[x]$、$B=A[y]$ とする。$Q_1=(x,y)$ と $Q_2=(x,y-1)$ の縮約はどちらも $(x)$ である。実際、$B/Q_i$ では $x$ は $0$、$y$ はそれぞれ $0,1$ となるため、$\Q[x]$ 上の核は同じである。$(x)$ を拡大した $(x)B$ は商 $B/(x)=\Q[y]$ が整域なので素であり、両方の $Q_i$ に真に含まれる。拡大縮約の対応は点の一対一対応を自動的には与えない。
:::

### イデアルの縮約で単元化を検出する

任意の $A\to B$ と $I\subset A$ に対し、$IB=B$ なら $I^{ec}=A$ である。例えば $\Z\to\Z[1/6]$ では $(2),(3),(6)$ は全て単位イデアルへ拡大される。$(12)$ も同じであり、$12$ の $2,3$ の因子が双方とも逆元をもつためである。これに対し $(10)$ は $(5)$ へ拡大され、縮約も $(5)$ である。実際、$\Z[1/6]/(5)$ は $\F_5$ であり、$\Z$ からの合成の核は $(5)$ である。この計算で $(10)$ と $(5)$ の区別が失われる一方、$5$ を含む条件自体は残る。

二つのイデアル $I\subset A$、$J\subset B$ について $I\subset J^c$ と $I^e\subset J$ が同値であるため、拡大は和を、縮約は共通部分を保つ。このことは定義からも確認できる。$I_\lambda$ の全ての元で生成されるイデアルを拡大すれば、各 $I_\lambda$ の像の生成する和を得る。また逆像の共通部分は共通部分の逆像である。逆方向に共通部分を拡大する等式は保証されない。例えば $\Z[x]\to\F_2[x]$ の $I=(x)$、$J=(x+2)$ を取ると、像は双方 $(x)$ だが共通部分は $(x(x+2))$ なので像は $(x^2)$ になる。共通部分の等式は、$x,x+2$ が UFD $\Z[x]$ の異なる素元であることから従う。

## 素スペクトルと Zariski 位相

イデアルの元が点で零になる条件を、点に相当する素イデアルに入る条件として表す。この定式化は体の選択を必要としない。

:::definition[素スペクトルと基本開集合]{#def-comm-spectrum}
全素イデアルの集合を :term[素スペクトル]{en="prime spectrum" yomi="そすぺくとる"} $X=\operatorname{Spec}A$ と書く。$V(I)=\{\mathfrak p\mid I\subset\mathfrak p\}$ を閉集合とする位相を :term[Zariski 位相]{en="Zariski topology" yomi="ざりすきいそう"} という。$D(f)=X\setminus V((f))$ を :term[主開集合]{en="principal open subset" yomi="しゅかいしゅうごう"} という。
:::

:::proposition[閉集合の演算]{#prop-comm-zariski-closed}
$V(0)=X$、$V(A)=\varnothing$、$V(IJ)=V(I)\cup V(J)$、$V(\sum I_\lambda)=\bigcap V(I_\lambda)$ である。従って閉集合の公理を満たす。$D(f)\cap D(g)=D(fg)$ であり、任意の開集合は主開集合の和集合である。
:::

:::proof
真のイデアルは $0$ を含み $1$ を含まない。また素イデアルが $IJ$ を含むのは、一方のイデアルを含むときに限る。和の包含は全ての項の包含と同値である。補集合を取ると主開集合に関する結論が従う。最後に $X\setminus V(I)=\bigcup_{f\in I}D(f)$ である。
:::

:::proposition[点の閉包と既約閉集合]{#prop-comm-generic-points}
点 $\mathfrak p$ の閉包は $V(\mathfrak p)$ である。非空閉集合 $V(I)$ が :term[既約]{en="irreducible" yomi="きやく"}、すなわち二つの真の閉部分集合の和集合に書けないための必要十分条件は $\sqrt I$ が素イデアルとなることである。このとき $V(I)$ は唯一の :term[生成点]{en="generic point" yomi="せいせいてん"} をもつ。
:::

:::proof
$\mathfrak p$ を含む閉集合 $V(J)$ には $J\subset\mathfrak p$ が必要なので $V(\mathfrak p)\subset V(J)$ である。従って $V(\mathfrak p)$ を二つの閉集合で覆うと $\mathfrak p$ を含む方が $V(\mathfrak p)$ 全体を含む。逆に $ab\in\sqrt I$ なら $V(I)\subset V((a))\cup V((b))$ である。既約性により片方が $V(I)$ を含み、:ref[thm-comm-radical-intersection] より $a$ または $b$ が $\sqrt I$ に入る。非空性により $\sqrt I\ne A$ である。生成点 $\mathfrak p$ があれば $V(I)=V(\mathfrak p)$ から $\sqrt I=\mathfrak p$ となるので一意である。
:::

:::example[二直線の交差]
$A=k[x,y]/(xy)$ では素イデアルが $x$ と $y$ の少なくとも一方を含むので $X=V((x))\cup V((y))$ である。各商 $k[y]$、$k[x]$ は整域であり、二つの集合は既約である。交わりは $V((x,y))$ であり、商が $k$ なのでただ一点である。
:::

### 点の特殊化と既約成分

点 $P$ が $Q$ に :term[特殊化]{en="specialization" yomi="とくしゅか"} するとは $Q\in\overline{\{P\}}$ をいう。:ref[prop-comm-generic-points] より、これは $P\subset Q$ と同値である。また $P$ が閉点であることと、$P$ が極大であることは同値である。実際、$V(P)$ が一元集合なら、$P$ を含む極大イデアルが $P$ そのものになる。逆に極大性があれば $V(P)=\{P\}$ である。

:::example[平面内の直線の生成点]
$A=k[x,y]$ とする。$(y)$ を含む素イデアルは、$k[x]$ の素イデアルに対応する。従って $(y)$ 自身と、既約多項式 $g(x)$ に対する $(y,g(x))$ が $V(y)$ の点である。例えば $k=\Q$ では $(y,x^2-2)$ は閉点である。$(y)$ は $V(y)$ に含まれるどの閉点にも特殊化する。実際 $\overline{\{(y)\}}=V(y)$ である。
:::

:::example[積と既約成分]
$A=k[x,y,z]$ において $V(xy,xz)=V(x)\cup V(y,z)$ である。それぞれの定義イデアルは素なので両方とも既約で、互いに他方に含まれない。既約集合がこの合併に入るなら、その二つの閉集合との共通部分のどちらかが集合全体である。従ってこの例の既約成分は平面 $V(x)$ と直線 $V(y,z)$ で尽きる。
:::

### スペクトルの分離性を点と閉包で判定する

$\operatorname{Spec}A$ は $T_0$ である。実際、異なる素イデアル $P,Q$ は等しくないので、例えば $a\in P\setminus Q$ と取れれば $D(a)$ が $Q$ を含み $P$ を含まない。逆の差しかないときは役割を交換すればよい。これに対して全点が閉点である $T_1$ 条件は、全ての素が極大であることと同値である。従って $\operatorname{Spec}k[x]$ は $T_0$ だが $T_1$ ではない。一般点 $(0)$ が全ての閉点へ特殊化するからである。

同じ例で非空な二つの開集合は交わる。どちらも非空な主開を含み、$D(f),D(g)$ が非空なら $f,g\ne0$ で、$(0)\in D(fg)$ だからである。従って $\operatorname{Spec}k[x]$ は異なる閉点をもっても Hausdorff ではない。逆に $\Z/30\Z$ のスペクトルは三点からなる離散空間である。三つの素は全て極大なので各一点が閉であり、有限集合ではその補集合も有限個の閉点の合併で閉になる。

### 既約性と連結性を別々に判定する

$k[x,y]/(xy)$ のスペクトルは $V(x)\cup V(y)$ であり、それぞれが一変数多項式環のスペクトルなので既約である。交わりは $V(x,y)$ という一点である。一般に二つの連結集合が交わる場合、その合併は連結である。合併の開閉分割があれば、二つの連結集合はそれぞれ片側に含まれる。共通点があるので、選ばれる側は一致する。また既約集合は連結である。もし二つの空でない開閉部分に分かれれば、二つの真の閉集合の合併になってしまう。よって二本の軸のスペクトルは連結だが既約でない。

:::example[同じ二成分が交わる場合と離れる場合]
$k[x,y]/(x(x-1))$ では $V(x)$ と $V(x-1)$ の交わりは空である。両イデアルの和が $1$ を含むためである。従ってスペクトルは二つの開閉部分に分かれる。冪等元 $x$ は $x=0$ 側で $0$、$x=1$ 側で $1$ となり、その主開が片側だけを指定する。これに対し $k[x,y]/(xy)$ で $x$ は冪等でなく、$D(x)$ の補集合には他方の軸だけでなく原点が入る。この二例は既約成分の個数が同じでも開閉分解が同じとは限らないことを示す。
:::

### 既約成分の生成点をイデアルから求める

一般の環でも、スペクトルの既約成分は $V(P)$（$P$ は極小素）に限る。実際、任意の既約閉集合は一意な素を生成点としてもつ。また $V(P)\subset V(Q)$ は $Q\subset P$ と同値である。よって極大な既約閉集合であることは、対応する素が極小であることに等しい。さらに任意の素 $Q$ の下に極小素が存在するので、どの点も少なくとも一つの既約成分に入る。極小素の個数の有限性はこの議論に使っていない。例えば $A=\prod_{i=1}^r k_i$ が体の有限直積なら、各座標の射影の核が極小かつ極大な素であり、各成分は一点である。これを確かめるには座標冪等元 $e_i$ の積が $i\ne j$ で零であり、和が $1$ であることを使う。任意の素は一つを除く全ての $e_i$ を含まなければならず、残る体への射影の核となる。

## Spec の関手性と準コンパクト性

環準同型が式を送る向きと、式を評価する点を引き戻す向きは逆になる。この逆向きの対応は、主開集合の逆像を直接計算すると扱いやすい。

:::theorem[反変性と準コンパクト性]{#thm-comm-spec-quasicompact}
$f:A\to B$ は連続写像 $f^*:\operatorname{Spec}B\to\operatorname{Spec}A$ を $\mathfrak q\mapsto f^{-1}\mathfrak q$ で定める。$(g\circ f)^*=f^*\circ g^*$ であり、恒等写像も保つ。また $\operatorname{Spec}A$ と各 $D(a)$ は :term[準コンパクト]{en="quasi-compact" yomi="じゅんこんぱくと"}、すなわち任意の開被覆から有限部分被覆が取れる。
:::

:::proof
閉集合の逆像は $V(I^e)$、主開集合の逆像は $D(f(a))$ となる。合成と恒等写像については逆像を順に取ればよい。基底で開被覆を細分できるので $D(a)\subset \bigcup_\lambda D(b_\lambda)$ を考える。この包含は $V((b_\lambda)_\lambda)\subset V((a))$ と同値である。:ref[thm-comm-radical-intersection] より $a^n\in (b_\lambda)_\lambda$ となる $n$ が存在する。その表示に現れる有限個の $b_\lambda$ が $D(a)$ を覆う。$a=1$ とすれば全体についても従う。
:::

:::corollary[商環の閉埋め込み]{#cor-comm-spectrum-quotient}
商写像 $A\to A/I$ が誘導する写像は $\operatorname{Spec}(A/I)\simeq V(I)$ という同相写像を与える。
:::

:::proof
:ref[prop-comm-ideal-correspondence] が与える一対一対応は整域商を保つ。$A/I$ の閉集合 $V(H)$ の像は $V(\pi^{-1}H)$ であるから、誘導写像は連続な閉写像である。
:::

:::example[整数環の開集合]
$\operatorname{Spec}\Z$ は $(0)$ と各素数 $p$ に対する $(p)$ からなる。$D(30)$ は $(2),(3),(5)$ を除く全ての点を含む。$D(6)\cup D(10)=D(2)$ である。実際 $(6,10)=(2)$ である。$\operatorname{Spec}\Z$ のどの非空開集合も $(0)$ を含むので、異なる二点を互いに交わらない開近傍で分離できない。
:::

開被覆の有限化では、各点での情報を有限個の環の元に落としている。次章では $D(f)$ 上で $f$ を可逆にする局所化を作り、この有限化と組み合わせる。

### 開閉分解と冪等元

:::proposition[開閉集合を与える冪等元]{#prop-comm-clopen-idempotent}
$\operatorname{Spec}A$ の開かつ閉な集合は $D(e)$、$e^2=e$ の形であり、そのような $e$ は一意である。
:::

:::proof
$e$ が冪等なら $e(1-e)=0$、$e+(1-e)=1$ なので、$D(e)$ と $D(1-e)$ は交わらず全体を覆う。逆に $X=V(I)\amalg V(J)$ と分かれたとする。$I+J=A$ なので $f+g=1$、$f\in I,g\in J$ と書ける。$fg$ は全素に入るから、ある $N$ で $f^Ng^N=0$ である。$f^N,g^N$ をともに含む極大イデアルがあれば $f,g$ も含むことになり、$f+g=1$ に反する。従って $u f^N+v g^N=1$ と書けるので、$e=v g^N$ と置く。$e(1-e)=uvf^Ng^N=0$ である。$V(J)$ では $e$ が零、$V(I)$ では $1-e$ が零になるので $D(e)=V(I)$ である。二つの冪等元 $e,e'$ が同じ主開集合を与えるなら、$e(1-e')$ と $e'(1-e)$ は全素に入る冪等元であり、冪零性によって零になる。従って $e=ee'=e'$ である。
:::

:::example[剰余環の開閉分解]
$\Z/12\Z$ で $e=4$ とすると $e^2=16\equiv4$ である。$D(e)$ は $(3)$ の点だけを含む。$1-e=9$ の主開集合は $(2)$ の点である。中国剰余表示 $\Z/12\Z\simeq\Z/4\Z\times\Z/3\Z$ で $e$ は $(0,1)$ であり、点の分解が環の座標に対応している。
:::

単に $V(I)\cup V(J)=X$ と書けるだけなら対応する冪等元を得られないことがある。例えば二直線の例では二成分が原点で交わるので、成分は閉だが開ではない。上の証明では交わらないことから $f+g=1$ を作る段階にこの差が現れる。

### 反変な写像の像を計算する

:::proposition[スペクトルの像の閉包]{#prop-comm-spectrum-dense-image}
環準同型 $f:A\to B$ に対して、$\operatorname{Spec}B$ の像の閉包は $V(\Ker f)$ である。従って像が稠密である条件は $\Ker f\subset\sqrt{(0)}$ である。
:::

:::proof
集合 $X\subset\operatorname{Spec}A$ を含む閉集合 $V(I)$ の条件は $I\subset\bigcap_{P\in X}P$ なので、閉包はこの共通部分の零点集合である。$X$ が像のとき、共通部分は $f^{-1}(\bigcap_{Q\in\operatorname{Spec}B} Q)=f^{-1}(\sqrt{(0)_B})$ である。$f(a)$ が冪零である条件は $a^n\in\Ker f$ となる $n$ があることなので、このイデアルは $\sqrt{\Ker f}$ に等しい。根基を取っても $V$ は変わらない。
:::

:::example[稠密だが全射でない写像]
$\Z\to\Q$ は単射なので、スペクトルの像は稠密である。この像は $(0)$ 一点だけであり、$(2)$ や $(3)$ は現れない。一方 $\Z\to\Z/12\Z$ の像は $V(12)=\{(2),(3)\}$ という閉集合になる。前者では分母の導入で閉点が外れ、後者では商により指定された定数が零となる点だけが残る。
:::

:::example[主開の有限部分被覆を作る]
$\Z$ では $D(12),D(18),D(25)$ が全体を覆う。$12$ と $25$ について $25-2\cdot12=1$ なので、すでに $D(12)\cup D(25)$ が全体である。逆に $D(12)\cup D(18)$ は $(2)$ と $(3)$ のどちらも含まない。元の族が無限でも、$1$ のイデアル表示に使う元は有限個なので同じ方法で部分被覆が得られる。
:::

### 主開が準コンパクトであることを直接示す

$D(f)$ が $\bigcup_\lambda D(g_\lambda)$ に含まれるとする。補集合を取ると $V((g_\lambda)_\lambda)\subset V(f)$ となり、$f\in\sqrt{(g_\lambda)_\lambda}$ である。そこで $f^N=\sum_{i=1}^r a_i g_{\lambda_i}$ と書ける。$D(f)$ の素は $f^N$ を含まないから右辺のどれかの $g_{\lambda_i}$ を含まず、有限個の主開で覆える。任意の開被覆は主開で細分できるので $D(f)$ は準コンパクトである。その結果、有限個の主開の合併は準コンパクトであり、逆に準コンパクトな開集合は基底による被覆から有限個の主開の合併になる。

:::example[開集合と有限生成イデアル]
$k[x,y]$ の原点を除いた開集合は $D(x)\cup D(y)$ である。$D(x^2),D(y^3)$ に置き換えても集合は同じである。$x^2,y^3$ は $(x,y)$ を生成しないが、根基が同じであるためである。一般に $D(I)=\bigcup_{f\in I}D(f)$ が準コンパクトなら、有限個の $f_i\in I$ で同じ開集合を覆え、$\sqrt I=\sqrt{(f_1,\ldots,f_r)}$ となる。従って準コンパクト性が与える有限性は、イデアルそのものより根基についての有限性である。
:::

### 既約成分の交わりから連結成分を求める

$X=\operatorname{Spec}A$ が有限個の既約成分 $X_1,\ldots,X_r$ の合併であるとする。この有限性は [Noether 環と Artin 環](/math/commutative-algebra/noetherian-artinian/) で Noether 環について証明する。交わりが空でない二成分を辺で結ぶ有限グラフを作る。グラフの同じ連結部分に属する成分の合併は連結である。実際、道に沿って交わりを一つずつ使うと、もし二つの開閉集合に分かれた場合でも道の両端は同じ方に入らなければならない。別のグラフ連結部分の合併は交わりをもたず、それぞれ有限個の閉集合の合併なので閉であり、その補集合も閉である。従ってグラフの連結部分はちょうどスペクトルの連結成分を与える。

:::example[三成分の交わりを順に見る]
$A=k[x,y]/(x(x-1)y)$ とする。既約成分は $V(x),V(x-1),V(y)$ である。$V(x)$ と $V(x-1)$ は交わらないが、$V(y)$ は前者と $(x,y)$ で、後者と $(x-1,y)$ で交わる。従ってグラフは道になり、スペクトルは連結である。主開 $D(y)$ に制限すると $V(y)$ は除かれる。残る $V(x)\cap D(y)$ と $V(x-1)\cap D(y)$ は非空で互いに交わらず、どちらも $D(y)$ で閉なので、$D(y)$ は非連結である。
:::

### 開閉分解を環の直積に移す

冪等元 $e$ に対し $A\to eA\times(1-e)A$、$a\mapsto(ea,(1-e)a)$ は環の同型である。$eA$ と $(1-e)A$ の単位元はそれぞれ $e$ と $1-e$ であり、写像は $1$ をこれらの組に送る。逆写像は $(b,c)\mapsto b+c$ である。実際 $e(1-e)=0$ なので $ec=(1-e)b=0$、また $eb=b$ と $(1-e)c=c$ である。逆写像の積も交差項が消えるので保たれる。従ってスペクトルで開閉な二つの部分に分かれることと、対応する環が積に分かれることは同じ情報である。

:::example[三座標に関数を分ける]
$A=\Z/60\Z$ で $60=4\cdot3\cdot5$ とする。$e_4=45$ は法 $4$ で $1$、法 $3,5$ で $0$ となる。$e_3=40$ は法 $3$ で $1$、他で $0$ である。$e_5=36$ は法 $5$ で $1$、他で $0$ である。従ってこれらは冪等元で、異なる二つの積は零、和は $121\equiv1$ である。任意の $a$ は $e_4a+e_3a+e_5a$ と一意に分かれ、例えば $a=7$ の三部分の代表は $15,40,12$ である。$e_4A$ だけを取り出すと $\Z/4\Z$ になり、そのスペクトルは閉点 $(2)$ 一つである。同じ操作を各座標に施すことで三点の開閉分解と三因子の直積が対応する。
:::

:::example[一点ずつを分離できる条件]
$\Z$ のスペクトルにおいて、異なる二素数 $p,q$ の閉点はそれぞれ $D(q),D(p)$ に入る。しかしこれらの開集合は一般点 $(0)$ で交わる。実際、$(p)$ を含む任意の非空開集合はある $D(f)$ を含み、$f\ne0$ なので $(0)$ も含む。同じ理由で $(q)$ を含む任意の開集合も $(0)$ を含む。従って両点を含む互いに交わらない近傍は作れない。これと $\operatorname{Spec}(\Z/60\Z)$ の違いは、商環で閉点を切り出す際に一般点が除かれ、座標ごとの冪等元が現れたことにある。
:::

## 演習問題

::::exercise{level=basic}
$\Z$ で $(24)+(36)$、$(24)\cap(36)$、$(24:36)$ を求めよ。

:::solution
最大公約数は $12$ なので和は $(12)$ である。最小公倍数は $72$ なので共通部分は $(72)$ である。$24\mid36a$ は $2\mid3a$、従って $2\mid a$ と同値なのでイデアル商は $(2)$ である。
:::
::::

::::exercise{level=basic}
$\Z/60\Z$ の極大イデアルとニルラジカルを求めよ。

:::solution
極大イデアルは商対応より $(2),(3),(5)$ である。これらが全ての素イデアルでもあり、共通部分は $(30)$ である。実際 $30^2=900$ は $60$ の倍数である。
:::
::::

::::exercise{level=basic}
$k[x,y]/(xy)$ において $V((x,y-2))$ を求めよ。

:::solution
$x=0$、$y=2$ を課すと商は $k$ である。従って対応する極大イデアルただ一点からなる。これは標数 $2$ でも成り立ち、その場合は $y-2=y$ である。
:::
::::

::::exercise{level=basic}
$A=k[x]/(x^4)$ で $M=(x^2)$ の最小生成元数を求めよ。

:::solution
$A$ の唯一の極大イデアルは $(x)$ である。$\mathfrak mM=(x^3)$ なので $M/\mathfrak mM$ は $x^2$ の像を基底とする一次元空間となる。:ref[thm-comm-nakayama] より答えは $1$ である。
:::
::::

::::exercise{level=advanced}
$\sqrt{I+J}=\sqrt{\sqrt I+\sqrt J}$ を証明し、$\sqrt I+\sqrt J$ が根基イデアルにならない例を与えよ。

:::solution
$I,J$ を含む素イデアルと $\sqrt I,\sqrt J$ を含む素イデアルは一致するので、根基の素イデアル表示から等式が従う。$I=(y)$、$J=(y-x^2)$ を $k[x,y]$ で考えると両者の商は $k[x]$ なので素である。和は $(y,x^2)$ であり、$x^2$ を含むが $x$ を含まない。
:::
::::

::::exercise{level=advanced}
互いに素なイデアル $I,J$ に対し $I^r+J^s=A$ を示せ。ただし $r,s\ge1$ とする。

:::solution
$i+j=1$ として $(i+j)^{r+s-1}$ を展開する。各項では $i$ の指数が $r$ 以上か、$j$ の指数が $s$ 以上である。従って和 $1$ が $I^r+J^s$ に入る。
:::
::::

::::exercise{level=advanced}
$X=\operatorname{Spec}A$ において $D(f)=D(g)$ と $\sqrt{(f)}=\sqrt{(g)}$ が同値であることを示せ。

:::solution
補集合が一致することは、二つの主イデアルを含む素イデアル族が同じであることを意味する。:ref[thm-comm-radical-intersection] より根基も等しい。逆向きには各素イデアルへの包含は根基に置き換えても同値である。
:::
::::

::::exercise{level=advanced}
有限生成加群 $M$ の全射自己準同型 $\phi$ が同型になることを示せ。

:::solution
$T$ が $\phi$ として作用する $A[T]$ 加群と見る。$A$ 上の生成元は $A[T]$ 上でも生成し、全射性により $M=TM$ である。:ref[lem-comm-determinant-trick] を $I=(T)$、作用素 $\id$ に適用すると $1+Th(T)$ が $M$ を消す。よって $-h(\phi)$ は $\phi$ の逆である。
:::
::::

::::exercise{level=advanced}
$\Z/84\Z$ の素スペクトルの全点と、冪等元の個数を求めよ。

:::solution
$84=4\cdot3\cdot7$ であり、これらは対ごとに互いに素である。従って中国剰余定理により $\Z/4\Z\times\F_3\times\F_7$ になる。局所因子は各一つの素をもち、元の環では $(2),(3),(7)$ である。各局所因子の冪等元は $0,1$ の二つである。実際 $e(1-e)=0$ かつ $e,1-e$ の少なくとも一方は単元なので、その逆元を掛ければ分かる。三座標で独立に選べるので冪等元は $2^3=8$ 個である。
:::
::::

## 確認テスト

::::quiz
$A/\mathfrak p$ が整域ならば何が従うか。

- [ ] 必ず極大イデアルである。
- [x] 素イデアルである。
- [ ] 必ず零イデアルである。

:::explanation
零積の因子の一方が零となる性質を逆像に移すと、素イデアルの条件が得られる。例えば $\Z[x]/(2)=\F_2[x]$ は体ではない。
:::
::::

::::quiz{answer="3" tol="1e-6"}
$\operatorname{Spec}(\Z/84\Z)$ の点はいくつあるか。

:::explanation
$84=2^2\cdot3\cdot7$ である。商対応により、素イデアルは $(2),(3),(7)$ に対応する。
:::
::::

::::quiz
$D(f)\cap D(g)$ はどれに等しいか。

- [x] $D(fg)$
- [ ] $D(f+g)$
- [ ] $V((fg))$

:::explanation
素イデアルが積を含まないことと、因子をどちらも含まないことは同値である。
:::
::::

::::quiz{answer="2" tol="1e-6"}
$k[x,y]/(x,y)^3$ の極大イデアルの最小生成元数を答えよ。

:::explanation
極大イデアルをその平方で割ると、一次単項式 $x,y$ が基底を与える。よって :ref[thm-comm-nakayama] より $2$ である。
:::
::::

::::quiz{answer="8" tol="1e-6"}
$\Z/180\Z$ の冪等元の個数を答えよ。

:::explanation
$180=4\cdot9\cdot5$ なので中国剰余定理で三つの局所環の直積になる。各因子で $e^2=e$ の解は $0,1$ であり、直積の各座標は独立に選べる。従って $2\cdot2\cdot2=8$ 個である。
:::
::::
