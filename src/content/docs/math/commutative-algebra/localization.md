## この章の目標

- 零因子を含む分母でも分数を定義し、普遍性を用いる。
- 加群の局所化が完全であることを証明する。
- 局所環での検査から元や準同型の大域的な性質を判定する。
- 素イデアルの対応を使って主開集合を環として記述する。

## 環の局所化と普遍性

$\Z$ で $2$ のべきだけを分母に使うと、$3$ を可逆にせずに $2$ だけを可逆にできる。一般の環では分母に零因子が入る可能性がある。このため分数の同値関係には分母を追加する余地を設ける。

:::definition[分数と局所化]{#def-comm-localization}
$S\subset A$ は $1\in S$、$SS\subset S$ を満たすとする。$(a,s)\sim(b,t)$ を、ある $u\in S$ に対して $u(ta-sb)=0$ と定める。類を $a/s$ と書く。加法を $(ta+sb)/(st)$、乗法を $ab/(st)$ とした環 $S^{-1}A$ を :term[局所化]{en="localization" yomi="きょくしょか"} という。
:::

推移性では $u(ta-sb)=0$、$v(rb-tc)=0$ なら $uvt(ra-sc)=0$ となる。反射性と対称性は式から直接従う。代表を一方だけ変える場合、和の交差差は元の交差差にもう一方の分母の平方を掛けたものになり、積の場合はもう一方の分子と分母を掛けたものになる。従って演算は代表に依存しない。分母を揃えて分子を計算すれば結合律と分配律が従い、零元は $0/1$、単位元は $1/1$ である。

:::theorem[局所化の普遍性]{#thm-comm-localization-universal}
$i:A\to S^{-1}A$ を $a\mapsto a/1$ とする。$f:A\to B$ が $S$ を単元に送るなら、$f$ は $i$ を経由する唯一の準同型をもつ。
:::

:::proof
候補は $a/s\mapsto f(a)f(s)^{-1}$ である。$u(ta-sb)=0$ に $f$ を適用し、$f(u)f(s)f(t)$ で割ると同値な分数の像は等しい。分数の演算式より候補は準同型であり、各分数が $i(a)i(s)^{-1}$ であるため一意である。
:::

:::example[零因子を反転する場合]
$A=\Z/12\Z$ で $S=\{1,2,2^2,\ldots\}$ とすると、$2^2\cdot3=0$ なので $3/1=0$ である。逆に $2$ は $\Z/3\Z$ で単元なので商写像は局所化を経由する。局所化では $3=0$ かつ $2^{-1}=2$ なので、得られる環は $\Z/3\Z$ である。一般に $a/1=0$ と $sa=0$ となる $s\in S$ の存在は同値であり、$0\in S$ なら局所化は零環になる。
:::

### 局所化が忘れる情報

:::proposition[局所化の核と二段階の局所化]{#prop-comm-localization-stages}
$A\to S^{-1}A$ の核は $\bigcup_{s\in S}(0:s)$ である。別の乗法的集合 $T\subset A$ に対して、$S^{-1}A$ を $T$ の像で局所化した環は $(ST)^{-1}A$ と同型である。ここで $ST=\{st\mid s\in S,t\in T\}$ である。
:::

:::proof
$a/1=0/1$ の条件を分数の定義に代入すれば核の式を得る。また $ST$ を単元に写す準同型は $S,T$ の双方を単元に写し、逆も成り立つ。従って両環への準同型が局所化の普遍性で互いに得られる。合成は $A$ の像で恒等であり、反転した元の逆元も固定するので恒等である。
:::

:::example[零因子を含む積の局所化]
$A=k[x,y]/(xy)$ とする。$A_x$ では $y=x^{-1}xy=0$ なので、$A_x$ は Laurent 多項式環 $k[x,x^{-1}]$ である。商 $A/(y)=k[x]$ では $x$ のべきが非零元を消さないため、核はちょうど $(y)$ である。一方 $A_{xy}=0$ である。$xy=0$ を可逆にすると $0=1$ となるためである。
:::

:::example[分母を二段階で加える]
$\Z[1/6]$ の $5$ による局所化は $\Z[1/30]$ である。後者では $6^{-1}=5/30$、$5^{-1}=6/30$ が存在する。例えば $(7/36)/5^2=7/900$ で、$900=30^2$ を使用できる。他方 $7$ はどの $30^n$ も割らないため、$1/7$ は入らない。
:::

### どの元が単元になるか

$S$ の元だけでなく、その約数も局所化では単元になる。正確には $a/1$ が単元であることは $ab\in S$ となる $b\in A$ が存在することと同値である。逆元が $c/s$ なら $a c/s=1/1$ なので、ある $u\in S$ で $uac=us$ となる。従って $a(uc)=us\in S$ である。逆に $ab\in S$ なら $b/(ab)$ が逆元になる。この条件を満たす元を集めると乗法的集合であり、これを反転しても同じ局所化を得る。実際、既に $S^{-1}A$ でそれらが単元だから普遍性で双方の環に写像ができ、$A$ の像と分母の逆元で合成は恒等になる。

例えば $A=\Z$ で $S=\{12^n\}$ を取ると、$2,3$ の両方が単元となる。さらに $\Z[1/12]=\Z[1/6]$ となる。包含の一方では $1/6=2/12$ を、他方では $1/12=3/36$ を使う。このように局所化は同じ素因子を反転していれば指数によらない。

### 局所化を写像から認識する

:::proposition[局所化の特徴付け]{#prop-comm-localization-recognition}
$f:A\to B$ は $S$ を単元に写すとする。普遍性による $S^{-1}A\to B$ が同型であるための条件は、次の二つである。

- 任意の $b\in B$ は $f(a)f(s)^{-1}$ と書ける。
- $f(a)=0$ なら、ある $s\in S$ について $sa=0$ が成り立つ。
:::

:::proof
第一の条件は誘導写像の全射性そのものである。$a/s$ がその核に属することと $f(a)=0$ は $f(s)$ が単元なので同値である。このとき第二の条件は $a/s=0$ を与える。逆に誘導写像が単射なら $f(a)=0$ に対して $a/1=0$ であり、分数の同値関係から第二の条件が従う。
:::

:::example[整数の冪零成分を消してから分母を入れる]
$A=\Z/108\Z$ で $6$ のべきを反転すると $6^3=216$ が $A$ で零なので零環を得る。一方 $2$ のべきだけを反転した場合、$108=4\cdot27$ である。$\Z/27\Z$ への写像は $2$ を単元に送り、全射である。その核の元 $\bar a$ は $27\mid a$ を満たし、$4a=0$ である。従ってこの写像は $A_2\simeq\Z/27\Z$ を与える。例えば $2^{-1}$ の像は $14$ なので $7/2^2$ の像は $7\cdot14^2\equiv22\pmod{27}$ である。$2$ が単元になったことと、$27$ の倍数が消えたことを分けて検査できる。
:::

:::example[分母の条件を一つの関係にする]
$A=k[x,y]$ で $xy$ を反転すると $x^{-1}=y/(xy)$、$y^{-1}=x/(xy)$ が入る。逆に両方の逆元を入れれば $(xy)^{-1}=x^{-1}y^{-1}$ が入るので、$A_{xy}=k[x,x^{-1},y,y^{-1}]$ である。例えば $x^2/y^3=x^5/(xy)^3$ と書ける。この例では元の環が整域なので表示の等号を分数体で確認できる。一般の環では、同じ計算は局所化の普遍性で正当化できる。
:::

### 乗法的集合の飽和を素イデアルで記述する

$S$ を避ける素の集合を $U$ とすると、$S^{-1}A$ で可逆になる $A$ の元の集合は $A\setminus\bigcup_{P\in U}P$ である。実際 $a/1$ が単元なら $ab\in S$ となる $b$ があり、$a$ を含む素は必ず $S$ と交わる。逆に $(a)$ が $S$ と交わらなければ :ref[thm-comm-prime-separation] により $a$ を含んで $S$ を避ける素が存在する。従ってそのような素がなければ $ab\in S$ と書ける。$0\in S$ の場合は $U$ が空で、すべての元が零環の単元 $0=1$ に移る。

さらに二つの乗法的集合 $S,T$ が同じ $U$ を与えれば、$S,T$ のどちらから出発しても $A$ 上同型な局所化を得る。それぞれの写像がもう一方の分母も単元に送るので、普遍性で互いに逆の写像を作れるためである。$S\subset T$ なら $T$ を避ける素の方が少なく、写像の向きは $S^{-1}A\to T^{-1}A$ となる。

### 準同型に沿って逆元を引き継ぐ

$f:A\to B$ に対し、$B$ における $S$ の像を $f(S)$ と書く。自然な写像
$$
(S^{-1}A)\otimes_A B\ \longrightarrow\ f(S)^{-1}B,\qquad
(a/s)\otimes b\longmapsto f(a)b/f(s)
$$
は環の同型である。逆向きの写像は $B\to (S^{-1}A)\otimes_A B$、$b\mapsto1\otimes b$ が $f(s)$ を可逆にすることから得られる。実際、$1\otimes f(s)=(s/1)\otimes1$ の逆元は $(1/s)\otimes1$ である。両合成は $B$ の像と逆元を固定し、これらが双方を生成するので恒等となる。

:::example[基底の変更で分母が零になる]
$A=\Z[x]$、$S=\{2^n\}$、$B=\F_2[x]$ とする。$2$ は $B$ で零なので $f(S)^{-1}B=0$ であり、$\Z[1/2][x]\otimes_{\Z[x]}\F_2[x]=0$ となる。これに対し係数体を $\F_3$ に替えると $2$ は既に可逆なので、同じ構成は $\F_3[x]$ を与える。二つの結果の違いは、$B$ の側で分母の像を調べれば決まる。
:::

## 加群の局所化と完全性

加群の元にも環の元と同じ分母を導入できる。特に、局所化後に元が零になるかどうかは分母の一つで消えるかどうかで決まる。

:::definition[加群の局所化]{#def-comm-module-localization}
$M$ を $A$ 加群とする。$M\times S$ に $u(tm-sn)=0$（ある $u\in S$）で同値関係を入れ、類を $m/s$ と書く。加法は分母を揃えて定義し、$(a/t)(m/s)=am/(ts)$ とする。得られる $S^{-1}A$ 加群を $S^{-1}M$ と書く。
:::

推移性と演算の整合性は、環の場合の交差差の計算において分子の一方を加群の元として行えば得られる。準同型 $h:M\to N$ は $m/s\mapsto h(m)/s$ を誘導する。$M\otimes_A S^{-1}A\simeq S^{-1}M$ は $m\otimes(a/s)\mapsto am/s$ で与えられる。逆写像 $m/s\mapsto m\otimes(1/s)$ は、交差差が $u$ で消えるときテンソル積でも両辺に可逆な $ust$ を掛けると差が零になるので定まる。

:::theorem[局所化の完全性]{#thm-comm-localization-exact}
$L\xrightarrow{f}M\xrightarrow{g}N$ が $M$ で完全なら、局所化した列も $S^{-1}M$ で完全である。
:::

:::proof
合成は零である。逆に $g(m)/s=0$ なら、ある $u\in S$ で $ug(m)=0$ である。元の完全性から $um=f(\ell)$ となる $\ell$ がある。従って $m/s=f(\ell)/(us)$ は像に属する。
:::

:::example[商とねじれ]
$S=\{2^n\mid n\ge0\}$ とする。$2^2\cdot3=0$ が $\Z/12\Z$ で成立するので局所化後の $3$ は消える。完全性を $12\Z\to\Z\to\Z/12\Z$ に使うと $S^{-1}(\Z/12\Z)=\Z[1/2]/(3)$ が得られる。一方 $S^{-1}\Z\simeq\Z[1/2]$ では $2$ のべきが非零元を消さないので、$\Z$ は単射で入る。
:::

### 商・共通部分・テンソル積

:::corollary[部分加群の局所化]{#cor-comm-localization-submodules}
$N,L\subset M$ に対し、$S^{-1}(M/N)\simeq S^{-1}M/S^{-1}N$、$S^{-1}(L\cap N)=S^{-1}L\cap S^{-1}N$ である。特に、$S^{-1}A/S^{-1}I$ は $A/I$ の $S$ の像による局所化と同型である。
:::

:::proof
$0\to N\to M\to M/N\to0$ を局所化すると第一の式を得る。共通部分を調べるには $L\to M/N$ を取り、その核が $L\cap N$ であることを使う。局所化した写像は $S^{-1}L\subset S^{-1}M$ から $S^{-1}M/S^{-1}N$ への写像なので、その核は右辺である。環の商の場合は $(a+I)/(s+I)\leftrightarrow a/s+S^{-1}I$ が同型を与える。
:::

:::example[写像の核を局所化の前後で計算する]
$\Z/60\Z$ 上の $10$ 倍写像の核は $6$ が生成する位数 $10$ の群である。$2$ を反転すると $\Z/60\Z$ は $\Z/15\Z$ となり、局所化した核は $6$ の像が生成する位数 $5$ の群になる。実際、法 $15$ で $10r=0$ となる条件は $3\mid r$ であり、$(6)=(3)$ である。
:::

:::example[無限共通部分を交換できない場合]
$S=\{2^n\mid n\ge0\}$、$N_i=2^i\Z\subset\Z$ とする。$\bigcap_{i\ge0}N_i=0$ だから、その局所化は零である。一方 $S^{-1}N_i=\Z[1/2]$ なので、局所化した全ての部分加群の共通部分は $\Z[1/2]$ である。有限共通部分では分母をまとめられるが、この例では $1\in S^{-1}N_i$ の分母として任意に高い $2$ のべきが必要になる。
:::

### 自由表示から局所化を計算する

:::example[整数行列の余核の局所化]
$A=\Z$、$M$ を行列 $\begin{pmatrix}6&2\\0&10\end{pmatrix}$ の余核とする。行と列の交換、整数倍の加減を施すと、最初の非零対角成分を $2$、次を $30$ にできる。実際列を交換して $\begin{pmatrix}2&6\\10&0\end{pmatrix}$ とし、第二行から第一行の $5$ 倍を引いてから第二列から第一列の $3$ 倍を引けば対角になる。従って $M\simeq\Z/2\Z\oplus\Z/30\Z$ である。$2$ を反転すれば $M_2\simeq\Z/15\Z$ となる。$(2)$ で局所化すれば $3,5$ が単元となり、二成分はどちらも $\F_2$ になる。$A_2$ では $2$ を含む素を除き、$A_{(2)}$ では $(2)$ に属さない元を分母にする。このため、二つの局所化で残るねじれの素因子が異なる。
:::

### 有限表示と Hom の局所化

:::proposition[有限表示加群からの Hom の局所化]{#prop-comm-local-hom}
$M$ は有限表示とする。任意の $N$ について $S^{-1}\Hom_A(M,N)\to\Hom_{S^{-1}A}(S^{-1}M,S^{-1}N)$ は同型である。
:::

:::proof
$A^u\to A^v\to M\to0$ を有限自由表示とする。$\Hom_A(M,N)$ は、生成元の像を表す $N^v$ から、関係式をその像に代入して得る $N^u$ への写像の核である。局所化は核を保ち、有限直和と交換する。また局所化した表示は局所化後の $M$ の表示である。従って両辺は同じ写像の核を与える。
:::

有限表示性がなければ、分母を一度に払えない。$M=\bigoplus_{i\ge0}\Z$、$N=\Z$、$S=\{2^j\}$ とする。$\bigoplus_i\Z[1/2]$ から $\Z[1/2]$ へ第 $i$ 基底元を $2^{-i}$ に送る写像がある。元の Hom の局所化から来るなら全ての値を一つの $2^j$ で払えるはずだが、$i>j$ の値がその条件に反する。

### 加群の普遍性と分母で消える部分

:::proposition[加群の局所化と写像]{#prop-comm-local-module-universal}
$N$ を $S^{-1}A$ 加群とする。制限 $\operatorname{Hom}_{S^{-1}A}(S^{-1}M,N)\to\operatorname{Hom}_A(M,N)$ は全単射である。
:::

:::proof
右辺の $h$ に対し $\tilde h(m/s)=(s/1)^{-1}h(m)$ とする。$m/s=m'/s'$ なら $u(s'm-sm')=0$ となる $u\in S$ がある。$h$ を適用すると像の交差差が $u/1$ で消える。$u/1$ は単元なので差は零であり、$s/1,s'/1$ で割れば像が一致する。加法とスカラー倍は分数の定義から保たれる。逆に $S^{-1}A$ 線形写像は $m/1$ の像によって $m/s$ の像まで決まる。
:::

$M\to S^{-1}M$ の核を $T_S(M)$ と書くと、これはある $s\in S$ で消える元の部分加群である。二つの元を別々の $s,t$ が消す場合は積 $st$ が和を消す。$S^{-1}T_S(M)=0$ なので、$M\to M/T_S(M)$ は局所化して同型となる。各 $s\in S$ は $M/T_S(M)$ 上で単射に作用する。実際 $sm$ が $T_S(M)$ に入れば、ある $t$ について $tsm=0$ なので $m$ も $T_S(M)$ に入る。従ってこの商では分数の等号を交差差が直接零になることだけで判定できる。

:::example[ねじれを消しても自由部分は残る]
$M=\Z\oplus\Z/18\Z\oplus\Z/20\Z$ に対し $S=\{2^n\mid n\ge0\}$ を取る。第一座標には $S$ の元で消える元がなく、第二座標では $9$ の倍数、第三座標では $5$ の倍数が消える。実際、$2^na$ が $18$ の倍数なら $9\mid a$ であり、$2^na$ が $20$ の倍数なら $5\mid a$ である。逆向きにはそれぞれ $2,4$ を掛ければよい。よって $M/T_S(M)=\Z\oplus\Z/9\Z\oplus\Z/5\Z$ であり、最後の二成分では $2$ が既に可逆である。従って
$$
M_2\simeq\Z[1/2]\oplus\Z/9\Z\oplus\Z/5\Z
$$
となる。例えば $(14,\bar4,\bar7)/2$ はこの表示で $(7,\bar2,\bar1)$ である。
:::

### テンソル積、直和、スカラーの変更

$A$ 加群 $M,N$ の局所化には自然な同型
$$
S^{-1}(M\otimes_A N)\simeq
(S^{-1}M)\otimes_{S^{-1}A}(S^{-1}N)
$$
がある。右から左へ $(m/s)\otimes(n/t)\mapsto(m\otimes n)/(st)$ と送る。例えば $u(s'm-sm')=0$ を $n$ とテンソルすれば、右辺で代表を取り替えても像が同じと分かる。両変数で同様であり、$S^{-1}A$ 上のつり合いも積の分数式から従う。逆向きには $m\otimes n\mapsto(m/1)\otimes(n/1)$ を加群の普遍性で一意に延長する。合成は単純テンソルとその分数を固定するため恒等である。

同じく $S^{-1}(\bigoplus_iM_i)\simeq\bigoplus_i S^{-1}M_i$ である。有限個の非零座標の分母は一つにまとめられるので右辺の元は持ち上がる。左辺の元 $m/s$ の像が零なら、$m$ の有限個の非零座標を消す分母の積を取れば $m/s=0$ となる。直積ではこの有限性がない。例えば $\prod_{i\ge1}\Z/2^i\Z$ の各成分は $2$ を反転すると零になるが、全座標が $1$ の元はどの $2^n$ でも消えず、直積の局所化は非零である。

:::example[テンソル積と局所化の順序を比べる]
$\Z/12\Z\otimes_{\Z}\Z/18\Z$ は $\Z/18\Z$ を $12$ 倍の像で割った加群である。$12,18$ の最大公約数は $6$ なのでこれは $\Z/6\Z$ である。その $2$ による局所化は $\Z/3\Z$ となる。先に $2$ を反転すると二つの加群は $\Z/3\Z$ と $\Z/9\Z$ となり、後者の $3$ 倍の像で割って再び $\Z/3\Z$ を得る。同型は最初の二つの巡回生成元のテンソルを最後の剰余類 $1$ に送る。
:::

### 加群を有限個の分母で表示する

有限表示 $A^p\xrightarrow{C}A^q\to M\to0$ の行列 $C$ の係数をそのまま $S^{-1}A$ へ写せば、局所化後の表示を得る。さらに逆向きに、有限表示 $S^{-1}A$ 加群の係数行列は、有限個の分母の積 $s$ を使って $A_s$ の行列へ持ち上がる。その行列の余核を $N$ とすれば $S^{-1}N$ が元の加群である。関係式ごとに分母をすべて掛けて $A$ の行列に直してもよい。局所化先では各列を掛けた分母が単元になり、生成される関係部分加群は同じだからである。

ただし、持ち上げた表示が元の加群を局所化以前から一意に決めるわけではない。例えば $\Z[x]/(2x)$ と $\Z[x]/(x)$ は $2$ の反転後にはどちらも $\Z[1/2]$ となる。前者では $x$ の像が非零で $2$ に消され、後者では $x$ 自身が零である。局所化の前に共通分母を掛ける操作で増えた関係の差が、このようなねじれに現れる。

### 零化イデアルとイデアル商を局所化する

$M$ を有限生成 $A$ 加群とすると、
$$
S^{-1}\operatorname{Ann}_A(M)=
\operatorname{Ann}_{S^{-1}A}(S^{-1}M)
$$
である。一方の包含は定義から従う。逆向きに $a/s$ が局所化した加群を消すなら、各生成元 $m_i$ に対し $u_i a m_i=0$ となる $u_i\in S$ を取れる。有限個の $u_i$ を掛け合わせた $u$ に対し $ua$ は $M$ の全体を消し、$a/s=(ua)/(us)$ となる。同じ理由で $J$ が有限生成イデアルなら
$$
(S^{-1}I:S^{-1}J)=S^{-1}(I:J)
$$
である。右辺の元が左辺に入ることは乗法から従う。逆向きには、$J$ の有限生成元 $b_i$ ごとに $u_i a b_i\in I$ となる分母を選び、積を取れば $uaJ\subset I$ となる。

:::example[無限個の零化条件に共通の分母がない]
$M=\bigoplus_{i\ge1}\Z/2^i\Z$ とし、$S=\{2^n\}$ を取る。各元は有限個の成分しか持たず、ある $2^n$ に消されるため $S^{-1}M=0$ である。従って局所化した加群の零化イデアルは $\Z[1/2]$ 全体である。一方、$M$ 全体を消す整数はすべての $2^i$ で割れなければならず、零に限る。従って $\operatorname{Ann}_{\Z}(M)=0$ であり、その局所化も零である。別々の元を消す指数を選べることと、すべての元に一つの指数で足りることが異なる。
:::

:::example[イデアル商の前後で同じ方程式が残る]
$A=k[x,y]$、$I=(x^4,x^2y^3)$、$J=(x,y^2)$ とする。$(I:x)=(x^3,xy^3)$、$(I:y^2)=(x^4,x^2y)$ なので、$(I:J)$ は両者の共通部分 $(x^4,x^3y,x^2y^3)$ である。例えば $x^3y$ は $x$ 倍で $I$ の第一生成元の倍数となり、$y^2$ 倍では第二生成元の倍数となる。$y$ を反転すると $I$ は $(x^2)$、$J$ は単位イデアルになるから、局所化先のイデアル商は $(x^2)$ である。先に計算した三生成元のうち $x^2y^3$ が $x^2$ の単元倍になり、同じ結果が得られる。
:::

## 局所的性質

$\mathfrak p$ が素なら $A\setminus\mathfrak p$ は積に閉じる。この集合での局所化を $M_{\mathfrak p}$ と書く。

:::proposition[局所化での零判定]{#prop-comm-local-zero}
$M=0$ と、全極大イデアル $\mathfrak m$ で $M_{\mathfrak m}=0$ となることは同値である。従って準同型の単射性、全射性、列の完全性はこれらの局所化で判定できる。
:::

:::proof
非零元 $m$ を取り、真のイデアル $\operatorname{Ann}(m)=\{a\mid am=0\}$ を含む極大イデアル $\mathfrak m$ を選ぶ。$\mathfrak m$ の外の元で $m$ は消えないので $m/1\ne0$ である。残りは核、余核、または （合成が零なら）$\Ker g/\Img f$ に :ref[thm-comm-localization-exact] と零判定を適用する。各局所化で合成が零なら、合成の像加群に零判定を適用して、もとの合成も零と分かる。
:::

有限生成 $M$ について $M_{\mathfrak p}=0$ なら、生成元それぞれを消す分母の積が $M$ 全体を消す。従って $M_s=0$ となる $s\notin\mathfrak p$ が取れる。例えば $\Z/15\Z$ は $(2)$ で消え、$15$ を反転した全ての点でも消える。有限生成性がない場合、$\bigoplus_{p\text{ 素数}}\Z/p\Z$ は $(0)$ では消えるが、どの非零整数を反転してもそれを割らない素数の成分が残る。

### 元と部分加群の所属を局所的に判定する

:::proposition[局所的な所属判定]{#prop-comm-local-membership}
$N\subset M$ と $u\in M$ を取る。全極大イデアル $\mathfrak m$ で $u/1\in N_{\mathfrak m}$ なら $u\in N$ である。従って、同じ加群の二つの部分加群は全極大での局所化が一致すれば等しい。
:::

:::proof
$u$ の $M/N$ での像を $\bar u$ とする。各 $\mathfrak m$ で $\bar u/1=0$ なので、巡回部分加群 $A\bar u$ もそこで零になる。:ref[prop-comm-local-zero] を $A\bar u$ に適用すると $\bar u=0$ となる。二つの部分加群の等しさはこの所属判定を双方に適用して得る。
:::

:::example[二つの整数イデアルの比較]
$18\Z$ と $12\Z$ を比較する。$(2)$ では $18$ は $2$ の単元倍で、$12$ は $4$ の単元倍なので、局所的には $12\Z_{(2)}\subsetneq18\Z_{(2)}$ である。$(3)$ では $18$ は $9$ の単元倍で、$12$ は $3$ の単元倍なので包含が逆になる。他の極大では双方が単位イデアルである。従って大域的にはどちらも他方を含まない。
:::

局所化は非零かどうかを調べるのに有効だが、各局所環で同じ階数であるという条件だけから大域的な基底を選ぶことはできない。後の [離散付値環と Dedekind 整域](/math/commutative-algebra/dedekind/) では、どの極大でも単項になるが大域的には単項でないイデアルを見る。

### 加群の有限生成性は一点だけでは判定できない

有限生成 $M$ の消滅が主開へ広がるのと同様に、写像 $f:N\to M$ の余核が有限生成であれば $f_P$ の全射性はある $D(s)$、$s\notin P$ 上に広がる。これは余核の各生成元を消す分母をまとめられるためである。一方、有限生成性を仮定しなければ、全ての局所環で有限生成でも大域的に有限生成とは限らない。例えば $M=\bigoplus_p\Z/p\Z$ は各 $(p)$ で一次元、$(0)$ で零だが、有限個の元は有限個の素数成分にしか台をもたない。従ってその有限集合は無限にある成分の全体を生成できない。

### 一点の自由基底を主開上へ広げる

$M$ を有限表示 $A$ 加群とする。$M_P$ が $A_P$ 上自由なら、ある $s\notin P$ で $M_s$ は $A_s$ 上自由である。実際 $M_P$ は有限生成なので階数は有限である。自由基底とその逆写像を $\operatorname{Hom}_{A_P}((A^r)_P,M_P)$ と $\operatorname{Hom}_{A_P}(M_P,(A^r)_P)$ の元と見る。両 Hom は :ref[prop-comm-local-hom] により $A$ 上の Hom の局所化なので、有限個の分母の積 $f\notin P$ を反転して二つの写像を $A_f$ 上へ持ち上げられる。両方向の合成と恒等写像の差は $P$ で消えるため、$A_f$ 上の Hom の中でそれぞれを消す分母がある。さらにその積を反転すれば二つの写像は互いに逆になり、所望の主開上の基底を得る。

有限生成だけでは、この議論に使う Hom の局所化が成立しない。$A=\prod_{n\ge1}\Z/2^n\Z$、$I=\bigoplus_{n\ge1}\Z/2^n\Z$、$S=\{2^j\mid j\ge0\}$ とする。$I$ の各元は有限個の座標しか持たないので $S^{-1}I=0$ である。一方 $1$ はどの $2^j$ でも消えないため $S^{-1}A\ne0$ である。$A/I$ は巡回加群だが、$\Hom_A(A/I,A)=0$ である。$I$ は全ての一座標だけで $1$ となる元を含むので、$I$ を消す元は全座標が零でなければならないためである。局所化後の $S^{-1}(A/I)$ は $S^{-1}A$ に同型なので、局所化後の Hom には恒等写像が含まれる。よって元の Hom からこの恒等写像を作れない。

### 有限生成と有限表示を有限主開被覆から降ろす

:::proposition[有限性の主開被覆による判定]{#prop-comm-local-finite-cover}
$f_1,\ldots,f_r$ が単位イデアルを生成し、$M$ を $A$ 加群とする。各 $M_{f_i}$ が有限生成なら $M$ は有限生成である。各 $M_{f_i}$ が有限表示なら $M$ は有限表示である。
:::

:::proof
各局所化で有限生成元を選び、分母を除いた分子を全て集めて部分加群 $N$ を作る。$C=M/N$ は各 $f_i$ の局所化で零である。任意の $c\in C$ に対し $f_i^{n_i}c=0$ とできる。どの極大イデアルも全ての $f_i^{n_i}$ を含まないから、それらは単位イデアルを生成し、$c=0$ である。従って $N=M$ となる。

有限表示の場合、まず上の議論から有限自由加群 $A^q$ から $M$ への全射を取り、核を $K$ と置く。有限表示加群 $L$ に対する任意の有限自由全射 $F\to L$ の核は有限生成である。これを確かめるには、核が有限生成な別の有限自由全射 $F'\to L$ を取る。基底を持ち上げて $L$ 上で可換となる写像 $u:F\to F'$ と $v:F'\to F$ を作る。$\Ker(F\to L)$ は $v(\Ker(F'\to L))$ と $(1-vu)F$ で生成される。実際 $x$ が核なら $u(x)\in\Ker(F'\to L)$ であり、$x=v u(x)+(1-vu)x$ と書ける。右辺の双方は元の核に属し有限生成である。これを各 $f_i$ で $M_{f_i}$ に適用すると $K_{f_i}$ が有限生成であり、前半から $K$ が有限生成となる。
:::

:::example[二つの局所表示から一つの表示へ戻す]
$M=(6,10)\Z$ を各 $D(2),D(5)$ で比較する。$D(2)$ では生成元 $6,10$ から $3,5$ を得て $M_2=\Z[1/2]$ となる。$D(5)$ では $10$ から $2$ が得られ、$M_5=2\Z[1/5]$ である。$D(2)$ 上で選んだ生成元 $1$ は $(2/2)$ として持ち上がり、$D(5)$ 上の $2$ は既に整数である。分子として $2$ を選べば双方を生成するので $M=2\Z$ となる。実際 $2=2\cdot6-10$ である。局所的に選んだ分数の分子が大域的な生成元の候補になる。
:::

### 環の性質を極大イデアルで判定する

:::proposition[被約性とイデアルの局所判定]{#prop-comm-local-reduced}
$A$ が被約であることは全ての $A_{\mathfrak m}$ が被約であることと同値である。任意のイデアル $I$ に対し、$I$ が根基イデアルであることは、全ての $IA_{\mathfrak m}$ が根基イデアルであることと同値である。
:::

:::proof
$A$ が被約で $(a/s)^n=0$ なら、ある $u\in S$ で $ua^n=0$ である。すると $(ua)^n=0$ なので $ua=0$ となり、$a/s=0$ である。逆向きには $a$ が冪零なら全ての $A_{\mathfrak m}$ でその像が冪零で、被約性により零になる。:ref[prop-comm-local-membership] を $N=0$ に適用すると $a=0$ となる。イデアルの主張は $A/I$ に適用する。極大イデアルのうち $I$ を含まないものについては局所商が零環となる。
:::

:::example[局所的には整域でも大域的に零積がある]
$A=k\times k$ の極大イデアルは $k\times0$ と $0\times k$ であり、各局所化は対応する座標の体 $k$ である。一方 $(1,0)(0,1)=0$ なので $A$ は整域ではない。各局所化で積が零のとき、どちらの因子が零かは点によって変わる。これに対し一つの元の冪零性を調べる場合、各点で同じ元が零になるので、大域的に零と結論できる。
:::

### 局所的に有限生成でも有限被覆を選べない場合

$A=\prod_{n\ge1}k$、$I=\bigoplus_{n\ge1}k$ とする。各座標冪等元 $e_n$ を使うと $I=\sum_n Ae_n$ である。素 $P$ がある $e_n$ を避ける場合、$I_P=A_P$ となる。逆に全ての $e_n$ が $P$ に入る場合、$(1-e_n)e_n=0$ で $1-e_n\notin P$ なので $I_P=0$ となる。従って全ての素で $I_P$ は高々一元生成である。しかし $I$ の任意の有限個の元は有限個の座標にしか成分をもたず、その生成するイデアルも同じ座標の外で零だから、$I$ は有限生成でない。有限生成という情報が主開全体に広がるための仮定と、有限被覆から有限生成を降ろす手順は別々に必要になる。

### 各点の自由基底から直和因子を作る

:::proposition[有限表示加群の局所自由性]{#prop-comm-local-finite-projective}
有限表示 $A$ 加群 $M$ について、すべての $M_{\mathfrak m}$ が自由であることと、$M$ が有限自由 $A$ 加群の直和因子であることは同値である。
:::

:::proof
まず各極大イデアルで自由であるとする。有限表示によりその基底を主開へ広げられる。これらの主開は全極大を覆うため、全ての素も覆う。準コンパクト性から有限主開被覆 $D(f_i)$ を選べる。有限自由加群から全射 $\pi:A^n\to M$ を取り、写像
$$
\operatorname{Hom}_A(M,A^n)\longrightarrow\operatorname{End}_A(M),
\qquad h\longmapsto \pi h
$$
を考える。各 $D(f_i)$ で $M_{f_i}$ の基底を $\pi_{f_i}$ で持ち上げると局所切断が得られる。Hom と局所化の交換により、$\id_M$ の余核での像は各 $f_i$ で零である。各分母の適当なべきがこの像を消し、それらのべきが単位イデアルを生成するので大域でも零である。従って $\pi h=\id_M$ となる $h$ があり、$M$ は直和因子となる。

逆に直和因子なら、極大イデアルで局所化しても有限自由加群の直和因子である。$R=A_{\mathfrak m}$、$L=M_{\mathfrak m}$ とし、剰余体上の基底を持ち上げて $R^r\to L$ を作る。中山の補題でこれは全射となる。$L$ は自由加群の直和因子なのでこの全射は分裂する。実際、$L$ への射影を有限自由加群の基底ごとに $R^r$ へ持ち上げ、$L$ の包含と合成すれば切断になる。従って核 $K$ は $R^r$ の直和因子であり有限生成である。分裂を剰余体に移し、選んだ元の像が基底であることを使うと $K/\mathfrak m R K=0$ である。再び中山の補題により $K=0$ なので $L$ は自由である。
:::

:::example[局所的な階数が二つに分かれる]
$A=k\times k$、$e=(1,0)$ とし $M=eA$ とする。$A=eA\oplus(1-e)A$ なので、$M$ は自由加群 $A$ の直和因子である。$D(e)$ に対応する点では $M$ は自由階数 $1$、$D(1-e)$ に対応する点では階数 $0$ である。大域的に $M\simeq A^r$ なら、どちらの点に局所化しても階数は $r$ でなければならないので矛盾する。有限表示加群の自由階数は、自由になる主開の上では一定である。大域的には階数が一定かどうかと、大域基底があるかどうかを別々に調べる。
:::

## 局所化における素イデアルの対応

どの分母も単元になるので、分母を含む素イデアルは局所化後には点を残さない。

:::theorem[素イデアルの局所化対応]{#thm-comm-localization-primes}
$\operatorname{Spec}(S^{-1}A)$ と $\{\mathfrak p\in\operatorname{Spec}A\mid\mathfrak p\cap S=\varnothing\}$ は縮約と拡大で互いに対応する。この対応は部分空間位相について同相である。
:::

:::proof
任意のイデアル $J$ について $a/s\in J$ と $a/1\in J$ は同値なので $J^{ce}=J$ である。$I^{ec}=\{a\mid sa\in I\text{ となる }s\in S\}$ は、拡大の元を共通分母で書いて分数の等号を用いれば得られる。$I$ が $S$ と交わらない素イデアルならこの式は $I^{ec}=I$ を与える。また $(S^{-1}A)/(S^{-1}I)$ は $A/I$ の分母の像による局所化であり、$I$ がそのような素イデアルなら非零整域である。従って拡大は素であり、逆に素イデアルの縮約は全ての分母を避ける。$D(a/s)$ は対応によって $D(a)$ と像集合の共通部分に移るので、双方向の連続性が従う。
:::

:::example[残る点]
$\Z[1/6]$ には $(0)$ と、$2,3$ 以外の素数による点が残る。$S$ を全非零整数とすれば、残るのは $(0)$ だけであり、環は $\Q$ になる。
:::

### 飽和イデアルの対応

以下、局所化の拡大イデアルと $A$ の共通部分という記号は、局所化写像が単射でない場合も含めて $A$ への逆像を表す。

$I$ を任意のイデアルとしたときの縮約 $(S^{-1}I)\cap A$ は、$I$ の $S$ に関する :term[飽和]{en="saturation" yomi="ほうわ"} という。「$sa\in I$ なら $a\in I$」が全ての $s\in S$ で成り立つイデアルを飽和イデアルという。:ref[thm-comm-localization-primes] の証明は、$S^{-1}A$ の全イデアルと $A$ の飽和イデアルとの対応を与える。実際、拡大して縮約する操作はイデアルを飽和にし、飽和なら元に戻す。また縮約して拡大すれば初めのイデアルに戻る。

:::example[残る極大と新たに極大となる素]
$A=k[x,y]$ とし $S=A\setminus(x)$ とする。残る素は $(x)$ 以下の素である。$(0)$ と $(x)$ の間に別の非零素 $Q$ があれば、$0\ne f\in Q$ を $x^rg$、$x\nmid g$ と書き、素性から $x\in Q$ を得るため矛盾する。従って局所化には二点だけがあり、$A$ では極大でなかった $(x)$ が局所化では極大になる。
:::

:::example[非開な像]
$\Z_{(5)}$ のスペクトルの像は $\{(0),(5)\}$ である。これは $(0)$ を含むため、開ならある $D(n)$、$0\ne n\in\Z$ を含む。しかし $n$ の素因子は有限個なので、$D(n)$ は $5$ 以外の点も含む。よってこの像は開でない。一般の乗法的集合による局所化と一元の反転を区別する例である。
:::

### 閉集合の原像を局所化後のイデアルで表す

$\operatorname{Spec}S^{-1}A$ を分母を避ける部分空間 $U$ と同一視すると、$V(S^{-1}I)$ は $U\cap V(I)$ になる。実際、$I$ の拡大を含むことは縮約が $I$ を含むことと同値である。$U$ の中で二つの閉集合が等しいのは、対応する局所化イデアルの根基が等しい場合である。例えば $A=k[x,y]$ で $S$ を $y$ のべきとすると、$I=(x^2,xy)$ と $J=(x)$ はともに $A_y$ で $(x)$ になる。この場合は根基だけでなくイデアルが等しい。これに対し $I'=(x^2)$ は同じ閉集合を与えるが、局所化した商には $\bar x\ne0$ が冪零で残る。

### 部分加群と飽和の束

イデアルについての拡大・縮約は部分加群にも成り立つ。$L\subset S^{-1}M$ に対し $L^c=\{m\mid m/1\in L\}$ とする。$m/s\in L$ と $m/1\in L$ は同値だから $S^{-1}L^c=L$ である。$N\subset M$ を局所化してから縮約した結果は
$$
N^{\mathrm{sat}}=\{m\in M\mid \text{ある }s\in S\text{ について }sm\in N\}
$$
である。実際 $m/1$ の商 $S^{-1}(M/N)$ における像が零になる条件である。従って $S^{-1}N=S^{-1}N'$ と $N^{\mathrm{sat}}=(N')^{\mathrm{sat}}$ は同値である。

:::example[局所化した格子を整数格子へ戻す]
$M=\Z^2$、$N$ を $(6,0),(0,10)$ が生成する部分加群、$S=\{2^n\mid n\ge0\}$ とする。$2^n(a,b)\in N$ であるには $3\mid a$ と $5\mid b$ が必要であり、この二条件が成り立てば $n=1$ で足りる。従って $N^{\mathrm{sat}}=3\Z\oplus5\Z$ となる。$M/N$ の中で $2$ のべきに消される元は $N^{\mathrm{sat}}/N$ で、各座標に一つずつ $\Z/2\Z$ が現れる。局所化した商は $\Z/3\Z\oplus\Z/5\Z$ に同型である。
:::

### 像の位相と分母の個数

$U=\bigcap_{s\in S}D(s)$ は一般に開とは限らない。ただし $S$ が有限個の $f_i$ で乗法的に生成されるなら、$U=D(f_1\cdots f_r)$ である。逆に $U$ が開であれば、ある $s\in S$ で $U=D(s)$ と表せる。実際、補集合を $V(I)$ と書くと、商 $S^{-1}(A/I)$ のスペクトルは $U\cap V(I)=\varnothing$ である。非零環には極大イデアルがあるので、これは零環である。従って $1+I$ を消す分母 $s\in S$ があり、$s\in I$ となる。この $s$ に対し $U\subset D(s)$ であり、$s\in I$ なので $D(s)\subset U$ である。

この場合、$S$ と $\{s^n\}$ は同じ素を避けるから、局所化は $A_s$ と同型になる。例えば $\Z_{(5)}$ の像は開でないので、どの $n$ 一つを使ってもこの局所環を $\Z[1/n]$ として得られない。像の開性の証明では、閉集合の被覆から有限部分被覆を取ったわけではない。閉集合に対応する商で局所化が零になるという、環の条件を使って分母を一つ選んだ。

### 極大イデアルを局所化前後で区別する

任意の $S$ について、$S^{-1}A$ の極大イデアルは $S$ を避ける素のうち包含極大なものに対応する。従って、縮約が $A$ で極大かどうかは別に判定する。$A=k[x,y]$ で $S$ を $k[x]$ の非零元全体とすると、$S^{-1}A=k(x)[y]$ である。その極大イデアル $(y)$ の縮約は $(y)\subset k[x,y]$ である。実際、分数を法 $y$ で取ると写像は $k[x,y]\to k(x)$、$y\mapsto0$ となる。$k[x,y]/(y)=k[x]$ は体でないので、これはもとの環では極大でない。一方、$A$ の極大イデアルが $S$ を避ければ、その拡大は対応の包含保存性から必ず局所化先でも極大である。

## 局所環と剰余体

:::proposition[素イデアルにおける局所環]{#prop-comm-local-residue}
$A_{\mathfrak p}$ は極大イデアル $\mathfrak p A_{\mathfrak p}$ をもつ局所環であり、その剰余体 $\kappa(\mathfrak p)$ は $\operatorname{Frac}(A/\mathfrak p)$ と自然に同型である。
:::

:::proof
$a/s$ で $a\notin\mathfrak p$ なら逆元は $s/a$ である。他の元は全て真のイデアル $\mathfrak pA_{\mathfrak p}$ に入る。商を取ると $A/\mathfrak p$ の全非零元を分母とする局所化が得られる。
:::

:::example[閉点と一般点の剰余体]
$A=\Q[x]$ の $\mathfrak p=(x^2-2)$ では剰余体は $\Q(\sqrt2)$ である。実際 $x^2-2$ は有理根をもたず既約であり、$x$ を $\sqrt2$ に送る写像の核である。一方 $(0)$ の剰余体は $\Q(x)$ である。$A_{(x^2-2)}$ では $x$ は単元になるが $x^2-2$ は単元にならない。
:::

### 剰余体での値と局所環での元

:::example[一般点で評価する]
$A=k[x,y]$、$P=(x)$ とする。剰余体は $k(y)$ であり、$A_P$ の元 $(x+y)/(y^2-x)$ の像は $1/y$ である。分母の $y^2-x$ は $P$ に入らず、代入 $x=0$ でも非零である。一方、閉点 $(x,y)$ ではこの分母は極大イデアルに入る。従って同じ分数がそこで元になるかは別に調べる必要がある。もし原点の局所環に属するなら、ある $s\notin(x,y)$ で $s(x+y)$ が $y^2-x$ の倍数になる。$x=y^2$ を代入すると左辺は $s(y^2,y)(y^2+y)$ である。第一因子は定数項が非零で、第二因子も $k[y]$ で非零なので矛盾する。
:::

:::example[剰余体への局所準同型]
$k[x,y]\to k[t]$ を $x\mapsto t^2$、$y\mapsto t^3$ とし、$(t)$ の縮約を $(x,y)$ とする。原点で単元となる分母は定数項が非零で、像でも定数項が非零になる。さらに像が $(t)$ に入るのは分子の定数項が零のときに限る。従って極大イデアルを極大イデアルへ縮約する局所準同型 $k[x,y]_{(x,y)}\to k[t]_{(t)}$ が得られる。剰余体上の写像は $k\to k$ の恒等であるが、局所環の写像には $y^2-x^3$ という非零の核の元がある。
:::

### 分数体・局所環・剰余体を並べて比較する

:::example[高さ一で残る別の変数]
$A=k[x,y]$、$P=(y)$ とする。$k[x]$ の非零元は全て $P$ を避けるため $k(x)\subset A_P$ である。さらに $k(x)[y]$ において $y$ の定数項が非零の多項式は、係数の分母を払うと $P$ の外の元になる。従って $A_P=k(x)[y]_{(y)}$ である。この環の分数体は $k(x,y)$、剰余体は $k(x)$ である。$\frac{y^2+x}{y+x^2}$ の剰余は $1/x$ であり、$\frac{1}{y}$ は分数体には入るが局所環には入らない。
:::

### 局所準同型と剰余体の拡大

:::proposition[局所化した準同型]{#prop-comm-local-morphism}
$f:A\to B$ と $Q\in\operatorname{Spec}B$ を取り、$P=f^{-1}Q$ とする。$f$ は局所準同型 $A_P\to B_Q$ を誘導し、さらに体の包含 $\kappa(P)\to\kappa(Q)$ を誘導する。
:::

:::proof
$s\notin P$ なら $f(s)\notin Q$ なので $B_Q$ で可逆であり、局所化の普遍性で分数を送れる。分数 $a/s$ の像が $QB_Q$ に属するのは $f(a)\in Q$ のときに限る。これは $a\in P$ と同値である。従って極大イデアルの逆像は $PA_P$ であり、剰余体への写像の核は零となる。
:::

:::example[同じ基底の素に二種類の剰余体が現れる]
$A=\Q[x]$、$B=\Q[x,y]$ で $P=(x)$ とする。$Q_1=(x)$ と $Q_2=(x,y^2-2)$ はどちらも $P$ に縮約される。$\kappa(P)=\Q$ に対し、$\kappa(Q_1)=\Q(y)$ は超越拡大であり、$\kappa(Q_2)=\Q(\sqrt2)$ は二次代数拡大である。実際 $B/Q_1=\Q[y]$ であり、$B/Q_2=\Q[y]/(y^2-2)$ は体である。$B$ の環としての生成元が一つ増えただけでも、選んだ素によって一般点の分数体と閉点の数体が得られる。
:::

### 局所環を主開上の環の極限として見る

$P\in\operatorname{Spec}A$ に対し、$f\notin P$ となる主開 $D(f)$ は $P$ の開近傍の基底である。二つの近傍の共通部分は $D(fg)$ である。写像 $A_f\to A_P$ を全て並べると、任意の $a/s\in A_P$ は $A_s$ で表せる。さらに $a/f^n$ と $b/g^m$ の像が $A_P$ で等しいなら、ある $u\notin P$ で $u(g^ma-f^nb)=0$ である。この等式は $A_{fgu}$ で $u$ を消去できることを意味するから、二つの元は共通の小さい主開で等しくなる。従って $A_P$ はこれらの環と制限写像の帰納極限である。同じ証明は $M_P$ にも適用できる。

:::example[一点での等号を小さい主開へ移す]
$A=k[x,y]/(xy)$、$P=(y)$ とする。$x\notin P$ であり、$y=0$ は $A_P$ で成立する。等号を先に $A_x$ で確認できる。実際 $xy=0$ と $x^{-1}$ から $y=0$ を得る。反対に原点 $(x,y)$ を含むどの主開でも $y$ は零にならない。$f(0,0)\ne0$ なら $A\to k[y]$、$x\mapsto0$ による $f$ の像が非零であり、対応する局所化の像で $y$ は非零だからである。
:::

### 局所環の単元と根基を計算する

局所環 $(A,\mathfrak m,k)$ の元 $a$ は、剰余体での像が非零であるとき、かつそのときに限り単元である。任意の非単元はある極大イデアルに入るためである。$A_P$ の任意の分数 $a/s$ についてこれは $a\notin P$ と同値である。また $P$ に属さない元を分母にしたとき、局所環から剰余体への写像は $a/s\mapsto\bar a/\bar s$ で与えられる。一方、環を局所化してから Jacobson 根基を取ると、もとの Jacobson 根基の拡大と一致しないことがある。例えば $J(\Z)=0$ だが $J(\Z_{(p)})=p\Z_{(p)}$ である。$J(A)$ はもとの極大を全て使うのに対し、局所化先で極大になる点は分母を避ける範囲での極大性によって決まる。

:::example[局所環の剰余体から単元の逆元を確認する]
$R=k[x]_{(x)}$ とし、$a=(x+2)/(x+1)$ を取る。標数が $2$ と異なれば $a$ の剰余は $2$ であり、逆元は $(x+1)/(x+2)$ である。その剰余は $1/2$ となる。標数 $2$ では $a=x/(x+1)$ となり、分母は可逆だが分子は極大イデアルに入る。このとき $aR=xR$ であり、$a$ は単元ではない。分母が許されることだけでは分数全体の可逆性は保証されない。
:::

## 主開集合 D(f) と局所化 A_f

$f$ のべきを分母とする局所化を $A_f$ と書く。:ref[thm-comm-localization-primes] より $\operatorname{Spec}A_f\simeq D(f)$ である。さらに $A_f\simeq A[T]/(fT-1)$ を得る。両環への準同型は $T\mapsto1/f$ と、商に対する局所化の普遍性から作られ、生成元上で合成を取れば恒等となる。

:::proposition[有限主開被覆での貼り合わせ]{#prop-comm-local-gluing}
$(f_1,\ldots,f_r)=A$ とする。元 $m_i\in M_{f_i}$ が各 $M_{f_if_j}$ で一致するなら、全ての局所化で $m_i$ となる $m\in M$ が一意にある。
:::

:::proof
分母を揃えて $m_i=a_i/f_i^n$ と書く。一致より $(f_if_j)^t(f_j^na_i-f_i^na_j)=0$ となる共通の $t$ が取れる。$b_i=f_i^t a_i$、$N=n+t$ と置くと $f_j^Nb_i=f_i^Nb_j$ である。どの極大イデアルも $f_i^N$ を全て含むことはないので $\sum c_i f_i^N=1$ と書ける。$m=\sum c_i b_i$ なら $f_j^N m=b_j$ であり、所望の元を得る。二つの候補の差は各 $f_i$ のべきで消える。それらのべきが単位イデアルを生成するので差は零である。
:::

例えば $D(2),D(3)$ は $\operatorname{Spec}\Z$ を覆う。$\Z[1/2]$ と $\Z[1/3]$ の元が $\Z[1/6]$ で同じなら、それは整数である。分数を既約形に直せば、分母は $2$ のべきであると同時に $3$ のべきなので $1$ となる。

### 飽和と有限表示の局所化

イデアルの飽和を計算すると、主開集合に制限した後にどの方程式が残るかが分かる。$S=\{f^n\}$ の場合、$IA_f\cap A=\bigcup_{n\ge0}(I:f^n)$ である。例えば $I=(x^2y,xy^2)\subset k[x,y]$ なら $(I:y)=(x^2,xy)$、$(I:y^2)=(x)$ であり、以降は変化しない。単項式イデアルへの所属が各単項式の割り切れ方で決まることを用いた。$D(y)$ では $x=0$ という方程式だけが残り、原点近くでの高いべきは残らない。

### 既約成分を除いてから貼る

:::example[主開上での方程式の減少]
$A=k[x,y]/(xy(x-y))$ とする。$D(x)$ では $xy(x-y)=0$ が $y(x-y)=0$ となる。そこで $(y)$ と $(x-y)$ は和に単元 $x$ を含むため互いに素である。:ref[thm-ring-crt] により $A_x\simeq k[x,x^{-1}]\times k[x,x^{-1}]$ である。例えば $(1,0)$ に対応する冪等元は $1-y/x$ であり、$y=0$ では $1$、$y=x$ では $0$ となる。
:::

:::example[開被覆で分数を貼り合わせる]
$A=\Z$、$f_1=4$、$f_2=9$ とする。$1=9-2\cdot4$ なので全体を覆う。$m_1=20/4$ と $m_2=45/9$ は共通部分で一致する。貼り合わせの式に $b_1=20,b_2=45,c_1=-2,c_2=1$ を入れると $m=-40+45=5$ となる。$m_2$ を $44/9$ に置くと共通部分で値が異なるので持ち上げはない。
:::

$D(f)\subset D(g)$ なら $V(g)\subset V(f)$ なので $f\in\sqrt{(g)}$ である。従って $f^n=ga$ という式が取れ、$A_f$ では $g$ が逆元 $a/f^n$ をもつ。よって制限写像 $A_g\to A_f$ が定まり、これらは三つの主開の包含に関して合成と両立する。これは貼り合わせで用いる値の比較を環準同型として与える。

### 開被覆で方程式の解を降ろす

有限主開被覆で貼り合わせられるのは加群の元に限らず、加群準同型の解にも及ぶ。$u:M\to N$、$b\in N$ に対し、各 $D(f_i)$ 上で $u_i(x_i)=b/1$ を満たす $x_i\in M_{f_i}$ があれば、$b$ の余核での像は全ての $f_i$ の局所化で零である。各 $f_i$ のべきで消えて、これらのべきが単位イデアルを生成するので、$b$ は元から像に属する。各 $x_i$ が共通部分で一致しなくても、解が一つ存在するという結論は得られる。指定した局所解そのものを貼るときには、共通部分での一致が必要になる。

:::example[別の局所解から大域解を求める]
$\Z^2\to\Z$ を $(a,b)\mapsto4a+9b$ とする。$D(4)$ 上で $(1/4,0)$、$D(9)$ 上で $(0,1/9)$ はともに右辺 $1$ の解である。共通部分でもこの二組は等しくないため、そのまま同じ大域元の制限にはならない。一方 $1=9-2\cdot4$ だから $(-2,1)$ は大域解である。各局所解との差は核に入るので、解集合を貼ることと特定の解を貼ることを区別できる。
:::

### 主開集合の任意の被覆と貼り合わせ

任意の主開 $D(f)$ を主開 $D(g_\lambda)\subset D(f)$ で覆うとする。$A_f$ のスペクトル上でこれらは $g_\lambda/1$ の主開であり、準コンパクト性から有限個で覆える。その有限個の $g_\lambda/1$ は $A_f$ の単位イデアルを生成する。部分加群の貼り合わせを $A_f$ と $M_f$ に適用すると、相互に一致する局所元から $m\in M_f$ を一意に得る。有限部分被覆に含まれなかった $g_\mu$ についても、$D(g_\mu)$ と有限部分被覆との交わりの上では $m$ の像と指定された元が一致する。従って一意性をその交わりの有限被覆に適用すれば、$D(g_\mu)$ 上でも一致する。この議論により、元の貼り合わせは任意個の主開からなる被覆について成立する。

:::example[一つの主開を二つに分けてから元を戻す]
$A=\Z$ で $D(2)$ を $D(6)$ と $D(10)$ で覆うと、$6,10$ の最大公約数が $2$ であることから被覆と分かる。$A_2$ では $3,5$ が被覆を与え、$2\cdot3-5=1$ である。$D(6)$ の元 $9/6$ と $D(10)$ の元 $15/10$ は $D(30)$ で一致する。$A_2$ 上で分母を $3,5$ とした分子は $9/2,15/2$ なので、貼り合わせは $2(9/2)-15/2=3/2$ となる。両方の分数を使って $D(2)$ 上の元を得た。
:::

### 分数体の中で局所環の共通部分を取る

$A$ が整域で分数体を $K$ とする。各局所環 $A_{\mathfrak m}$ は $K$ の部分環になり、$\bigcap_{\mathfrak m}A_{\mathfrak m}=A$ である。実際 $x=a/b\in K$ とし、$I=\{r\in A\mid rx\in A\}$ を取る。$x\in A_{\mathfrak m}$ は $I$ が $\mathfrak m$ の外に元をもつことと同値である。全極大でこれが成り立てば $I=A$ なので $x\in A$ である。同様に $D(f)$ の全点 $P$ に対する $A_P$ の共通部分は $A_f$ となる。実際 $A_f$ の極大に対応する点は $D(f)$ 内にあり、二段の局所化でその点の局所環が得られる。

:::example[分母の素因子を開集合から読み取る]
$\Q$ 内で $\bigcap_{p\ne2,3}\Z_{(p)}=\Z[1/6]$ である。既約な有理数 $a/b$ の分母に $p$ があれば $a/b$ は $\Z_{(p)}$ に入らない。共通部分に入るには、分母の素因子が $2,3$ だけであればよい。例えば $28/45$ は $(5)$ での局所環に入らないが、$28/27$ は全ての $p\ne2,3$ で許される。この判定は、除いた点と分母に許された素因子の対応を示す。
:::

### 局所化を繰り返すと制限の合成になる

$D(f)\subset D(g)$ の場合、$A_g$ の $(f/1)$ による局所化は $A_{fg}$ と同型である。$A_f$ では $g$ がすでに単元であるため、$A_{fg}$ と $A_f$ は自然に同型となる。従ってこの包含に対応する写像は $A_g$ から $f$ を反転する写像としても得られる。二つの包含を続けた場合、合成は $A$ の像と $A_g$ に入っていた分母の逆元を固定しているので、直接得られる制限写像と一致する。主開の包含が等号なら双方の制限が互いに逆である。例えば $D(f^n)=D(f)$ であり、$A_{f^n}\simeq A_f$ は $f^{-1}=f^{n-1}/f^n$ を与える。

### 貼り合わせの一意性を零因子のある環で検査する

$A=\Z/12\Z$ の $D(2),D(3)$ は全体を覆い、交わりは $D(6)=\varnothing$ である。$A_2\simeq\Z/3\Z$、$A_3\simeq\Z/4\Z$ であり、共通部分の環は零環になる。従って二つの局所元に対して一致の条件は自動的に満たされる。例えば局所元をそれぞれ $2,3$ とする。元の環の $4$ は法 $3$ で $1$、法 $4$ で $0$ であり、$9$ は逆の二つの値をとる。従って $2\cdot4+3\cdot9=35\equiv11\pmod{12}$ が持ち上げである。差の局所像が双方で零になるなら、その差は $3$ と $4$ の両方で割れるため零であり、一意性も直接確かめられる。この場合の貼り合わせは二つの離れた点に値を指定する中国剰余定理を再現する。

## 演習問題

::::exercise{level=basic}
$\Z[1/6]$ で $1/4-1/9$ を計算せよ。

:::solution
双方に分母 $36$ を使うと $(9-4)/36=5/36$ である。$36=6^2$ なので許された分母である。
:::
::::

::::exercise{level=basic}
$A=\Z/18\Z$ で $A_3$ を求めよ。

:::solution
$3^2\cdot2=0$ なので局所化では $2=0$ である。また $\Z/2\Z$ では $3=1$ なので、商写像は局所化を経由する。逆に局所化の全ての分数は分母が $1$ に等しく、商からの写像は全射である。従って $A_3\simeq\Z/2\Z$ である。
:::
::::

::::exercise{level=basic}
$\Z_{(3)}$ で $9/10$ と $10/9$ のうちどちらが属し、単元になるかを答えよ。

:::solution
$9/10$ は分母が $3$ の倍数でないので属するが、分子が $3$ の倍数なので単元でない。$10/9$ は既約分数の分母が $9$ なので属さない。
:::
::::

::::exercise{level=basic}
$\Q[x]_x$ の Laurent 多項式 $(x+1)/x^2$ に $x^{-1}$ を掛けよ。

:::solution
分母は $x^3$ となるので $x^{-2}+x^{-3}$ である。
:::
::::

::::exercise{level=advanced}
$S^{-1}(I\cap J)=S^{-1}I\cap S^{-1}J$ を示せ。

:::solution
右辺の元 $a/s$ について、ある $t,u\in S$ で $ta\in I$、$ua\in J$ となる。すると $uta\in I\cap J$ なので左辺に入る。左辺から右辺への包含は自然である。
:::
::::

::::exercise{level=advanced}
任意のイデアル族に対して前問の等式が破れる例を与えよ。

:::solution
$\Z$、$S=\{2^n\}$、$I_n=(2^n)$ とする。全ての拡大は局所化環全体になるが、$\bigcap_n I_n=0$ なので左辺は零である。
:::
::::

::::exercise{level=advanced}
$A_f\otimes_A A_g\simeq A_{fg}$ を証明せよ。

:::solution
左辺への環写像は $f,g$ を可逆にするので $A_{fg}$ から左辺への写像がある。逆に $fg$ が可逆なら $f,g$ はともに可逆である。両局所化から $A_{fg}$ への写像を取り、積を通じてテンソル積からの写像を得る。合成は $A$ と逆元の生成元を固定するので互いに逆である。
:::
::::

::::exercise{level=advanced}
極大イデアルの全てで $I_{\mathfrak m}=J_{\mathfrak m}$ なら $I=J$ と示せ。

:::solution
$(I+J)/J$ の局所化は全て零なので :ref[prop-comm-local-zero] により $I\subset J$ となる。$I,J$ を交換すれば逆の包含を得る。
:::
::::

::::exercise{level=advanced}
$I=(x^4,x^2y^3)\subset k[x,y]$ とする。$(IA_y)\cap A$ を求め、最小の $n$ で $(I:y^n)$ がこの縮約に等しくなるものを求めよ。

:::solution
$y$ を反転すると $x^2y^3$ が $x^2$ の単元倍になるので $IA_y=(x^2)A_y$ である。$A/(x^2)$ では単項式の基底が $y^i,xy^i$（$i\ge0$）であり $y$ 倍は単射だから、$(x^2)$ は拡大・縮約で戻る。$y^3x^2\in I$ より $(I:y^3)=(x^2)$ である。$n<3$ なら $x^2y^n$ は $I$ のどちらの生成単項式でも割れないため、$(I:y^n)$ は $x^2$ を含まない。よって最小値は $3$ である。
:::
::::

::::exercise{level=advanced}
$A=\Z/180\Z$、$S=\{6^n\mid n\ge0\}$ とする。$A$ の局所化の核と $7/6$ の像を求めよ。

:::solution
$180=36\cdot5$ であり、$\Z/5\Z$ への写像は $6$ を $1$ に送る。その核は $5$ の倍数の剰余類であり、$6^2=36$ 倍でそのすべてが消える。逆に $6$ は法 $5$ で単元だから、$6^n a=0$ なら $a$ は $5$ の倍数である。よって $S^{-1}A\simeq\Z/5\Z$ であり、分数 $7/6$ の像は $2/1=2$ である。
:::
::::

::::exercise{level=advanced}
$I=(x^3y^2,xy^4)\subset k[x,y]$ を $x$ の冪で飽和させよ。また飽和に達する最小指数を求めよ。

:::solution
$x$ を反転すると $I$ は $(y^2)$ となり、$k[x,y]/(y^2)$ では $x$ 倍が単射なので縮約は $(y^2)$ である。$x^3y^2\in I$ から $(I:x^3)$ は $(y^2)$ を含み、飽和に含まれるので等号である。一方 $n<3$ なら $x^ny^2$ はどちらの生成単項式でも割れず、$(I:x^n)$ は $y^2$ を含まない。よって最小指数は $3$ である。
:::
::::

## 確認テスト

::::quiz
$S^{-1}A$ で $a/s=0$ になる条件を選べ。

- [ ] 必ず $a=0$。
- [ ] 必ず $s=0$。
- [x] ある $u\in S$ で $ua=0$。

:::explanation
$a/s$ と $0/1$ の交差差は $a$ である。分数の同値関係より、分母の一つを掛けて消えることが判定条件となる。
:::
::::

::::quiz{answer="5" tol="1e-6"}
$(\Z/45\Z)_3$ の元の個数を答えよ。

:::explanation
$3^2\cdot5=0$ なので $5$ が消える。$\Z/5\Z$ では $3$ が可逆であり、局所化はこの商環と同型である。従って元の個数は $5$ である。
:::
::::

::::quiz
$\kappa((0))$ を $\Z$ について選べ。

- [ ] $\Z$
- [x] $\Q$
- [ ] $\F_2$

:::explanation
$(0)$ の外の元は全非零整数である。これを可逆にすると $\Q$ になり、極大イデアルは零である。
:::
::::

::::quiz{answer="1" tol="1e-6"}
$\operatorname{Spec}((\Z/90\Z)_6)$ の点を数えよ。

:::explanation
$90=2\cdot3^2\cdot5$ であり、$6$ を含む $(2),(3)$ は除かれる。残る素イデアルは $(5)$ 一つである。
:::
::::

::::quiz{answer="9" tol="1e-6"}
$\Z/360\Z$ で $10$ を反転した環の元は何個か。

:::explanation
$360=8\cdot9\cdot5$ である。$(8)$ と $(5)$ の商では $10$ のべきが零になるので、局所化後に両成分は消える。$\Z/9\Z$ では $10=1$ で単元であり、その成分だけが残る。従って $9$ 個である。
:::
::::
