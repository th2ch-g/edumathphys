## この章の目標

- 素数で割れる度合いを付値と距離で記述する。
- $\Q_p$ と $\Z_p$ を構成し、桁表示と合同式を対応させる。
- Hensel の補題を使って方程式の根と平方類を求める。
- 有理数の絶対値を分類し、Hilbert 記号の積公式を証明する。



## p 進付値と p 進絶対値

整数の通常の差が大きくても、差が高い $p$ の冪で割れれば、法 $p^k$ では多くの桁が一致する。この一致を距離に変える。

:::definition[付値と絶対値]{#def-nt-padic-valuation}
素数 $p$ に対し、$x\in\Q^\times$ を $x=p^k a/b$（$p\nmid ab$）としたとき $v_p(x)=k$、$\abs x_p=p^{-k}$ とする。$v_p(0)=+\infty$、$\abs0_p=0$ と定める。これを :term[p 進付値]{en="p-adic valuation" yomi="ぴーしんふち"} と :term[p 進絶対値]{en="p-adic absolute value" yomi="ぴーしんぜったいち"} という。
:::

:::proposition[強三角不等式]{#prop-nt-ultrametric}
$v_p(xy)=v_p(x)+v_p(y)$、$v_p(x+y)\ge\min(v_p(x),v_p(y))$ であり、二つの付値が異なる場合に後者は等号である。従って $d_p(x,y)=\abs{x-y}_p$ は距離であり、三角不等式の右辺を二辺の最大値に替えられる。
:::

:::proof
零を含む場合は $v_p(0)=+\infty$ から従う。非零元の積の付値は素因数分解で求まる。和について、$v_p(x)\le v_p(y)$ として $p^{v_p(x)}$ をくくり、残りを $p$ と互いに素な共通分母で通分する。結果の分子は整数なので不等式が出る。$v_p(x)<v_p(y)$ なら第一の分子は $p$ で割れず、第二の分子は $p$ の倍数なので、和も $p$ で割れない。絶対値に直せば距離の主張を得る。
:::

法 $5$ では $1/25$ の絶対値は $25$、$125$ の絶対値は $1/125$ である。$1+24=25$ では二項の付値がともに $0$ でも和の付値は $2$ になる。距離では $7$ と $132$ が $125$ だけ離れているので、$5$ 進距離は $1/125$ である。球の内部の点を新しい中心にしても球は変わらない。実際、強三角不等式を両向きに使うと同じ半径で同じ集合が得られる。

### 積公式と分母に現れる素数

有理数 $x\ne0$ を $x=\pm\prod_p p^{e_p}$ と表す。有限個以外の $e_p=0$ であり、通常の絶対値 $\abs{x}_\infty$ は $\prod_p p^{e_p}$、局所絶対値は $p^{-e_p}$ になる。従って $\abs{x}_\infty\prod_p\abs{x}_p=1$ である。普通の絶対値で大きくても、すべての局所絶対値が同時に大きいわけではない。例えば $3/10$ は $\abs{x}_3=1/3$、$\abs{x}_2=2$、$\abs{x}_5=5$ であり、通常の絶対値 $3/10$ を掛けると $1$ になる。分子と分母で素数の指数が打ち消されている場合は、その素数は積に寄与しない。

## ℚ の完備化としての ℚ_p

:ref[thm-top-completion-exists] に従い、$d_p$ に関する有理 Cauchy 列を、差が $0$ へ行く列どうしで同一視する。こうして得た完備距離空間を :term[p 進数体]{en="p-adic number field" yomi="ぴーしんすうたい"} $\Q_p$ とする。体になることを確認する。

:::proposition[完備化上の体演算]{#prop-nt-padic-completion}
和、積、絶対値は $\Q_p$ へ連続に延び、$\Q_p$ は体である。非零元の絶対値は $p$ の整数冪である。
:::

:::proof
Cauchy 列は有界である。積の差 $a_nb_n-a_mb_m=(a_n-a_m)b_n+a_m(b_n-b_m)$ に強三角不等式を使うと、積の列が Cauchy であることと、代表列への非依存性が同時に従う。和は差の和に同じ不等式を使えばよい。零を表さない列では、ある $\eta>0$ に対し $\abs{a_n}_p\ge\eta$ の項が無限にある。列の尾部で全ての距離が $\eta$ 未満になるようにすると、尾部の絶対値は強三角不等式の等号条件で一致する。その値を極限元の絶対値とすれば $p$ の整数冪である。零を表す場合は絶対値を $0$ とする。積と強三角不等式は極限へ移る。

非零元の代表列の尾部では $\abs{a_n^{-1}-a_m^{-1}}_p=\abs{a_n-a_m}_p/(\abs{a_n}_p\abs{a_m}_p)$ なので逆数も Cauchy である。その積が $1$ を表すので逆元となる。環の法則は各有理項で成り立ち、列の同値類にも移る。
:::

$\sum_{j=0}^\infty p^j$ は各項の絶対値が $0$ に行くので収束し、部分和に $1-p$ を掛けると $1-p^{N+1}\to1$ である。従って和は $1/(1-p)$ になる。例えば $p=3$ なら和は $-1/2$ である。一般にも強三角不等式により、級数の収束と各項が $0$ に行くことは同値である。

## ℤ_p と射影極限

$x\in\Q_p^\times$ の付値を $\abs{x}_p=p^{-v_p(x)}$ で定め、$v_p(0)=+\infty$ とする。この付値が非負の元を集めた部分環を :term[p 進整数環]{en="p-adic integers" yomi="ぴーしんせいすうかん"} と呼ぶ。

:::theorem[剰余列と桁表示]{#thm-nt-padic-inverse-limit}
$\Z_p=\{x\in\Q_p\mid v_p(x)\ge0\}$ は部分環であり、
$$
\Z_p\simeq\varprojlim_k\Z/p^k\Z
$$
である。右辺は、法を下げる還元写像に関する :term[射影極限]{en="inverse limit" yomi="しゃえいきょくげん"}、すなわち還元と両立する剰余列の環である。任意の $x\in\Z_p$ は $0\le a_j<p$ を満たす整数桁を使って $x=\sum_{j\ge0}a_jp^j$ と一意に表される。
:::

:::proof
閉性は付値の法則による。$x$ を近似する有理列は十分後ろでは付値が非負で、分母を $p$ と互いに素にできる。この分母の逆元を使って法 $p^k$ に還元すると、Cauchy 条件により一定になる。その剰余は代表列によらず、法を下げる操作と両立する。全剰余が $0$ なら付値が全整数 $k$ 以上なので $x=0$ である。逆に両立する列の最小非負代表 $r_k$ は $r_{k+1}\equiv r_k\pmod{p^k}$ なので Cauchy 列であり、その極限が所望の剰余をもつ。四則のうち和と積は各還元で保たれる。

整数として $0\le r_{j+1}<p^{j+1}$、$0\le r_j<p^j$ なので $r_{j+1}=r_j+a_jp^j$ で $a_j$ の範囲が決まる。$r_0=0$ とすれば桁表示が出る。各桁は隣接剰余から決まるので一意である。
:::

$\Z_p$ の単元は $v_p(x)=0$ のものに限る。剰余写像の核は $p^k\Z_p$ である。$-1$ の代表は法 $p^k$ で $p^k-1$ なので、全桁が $p-1$ である。$1/2\in\Z_5$ は法 $5,25,125$ で $3,13,63$ に対応し、最初の三桁は $3,2,2$ である。任意の非零 $\Q_p$ 元は $p^k$ と $\Z_p$ の単元の積なので、負の添字の桁は有限個だけである。

### イデアルと剰余体

非零イデアル $I$ から付値が最小の元 $x=p^ku$（$u$ は単元）を選ぶ。$x$ を $u^{-1}$ 倍すれば $p^k\in I$ であり、最小性により全元が $p^k$ の倍数である。従って $I=p^k\Z_p$ となる。このように各非零イデアルが付値で決まる環を :term[離散付値環]{en="discrete valuation ring" yomi="りさんふちかん"} という。唯一の極大イデアルは $p\Z_p$ であり、その剰余体は $\F_p$ である。

### 球の中から収束部分列を取る

$\Z_p$ の任意の列に対し、法 $p$ の剰余が一定な無限部分列を選べる。そこからさらに法 $p^2$ が一定な無限部分列を選び、続けて法を一段ずつ上げる。第 $k$ の部分列から前より後ろの項を一つ取る対角列は、どの固定された法でも最終的に剰余が一定になるため Cauchy である。完備性から極限は $\Z_p$ に属する。従って $\Z_p$ は逐次コンパクトであり、距離空間での同値性によりコンパクトである。$p^j\Z_p$ とその平行移動についても、拡大縮小が連続な逆を持つので同じことが言える。$\Q_p$ 全体では $p^{-n}$ の絶対値が無限に増え、この列は収束部分列をもたない。

### 有理数の桁列が周期的になる理由

$x=a/b\in\Z_p$ を $b>0$、$p\nmid b$ と書き、$x_0=x$、$x_{j+1}=(x_j-d_j)/p$ とする。ここで $d_j$ は $x_j$ の法 $p$ での代表である。$x_j=a_j/b$ とすると $a_{j+1}=(a_j-bd_j)/p$ は整数である。通常の絶対値で $\abs{a_{j+1}}\le\abs{a_j}/p+b(p-1)/p$ なので、全分子は $\max(\abs a,b)$ 以下に留まる。従って有限個の整数しか取り得ず、同じ分子の再出現以降は周期的になる。逆に桁列がある位置から $h$ 桁ごとに繰り返すなら、尾部は多項式に $\sum_{k\ge0}p^{hk}=1/(1-p^h)$ を掛けたものなので有理数である。



### 複数の場所で同時に近似する

有限個の素数 $p$ で $x_p\in\Q_p$ を指定し、実数 $x_\infty$ も指定する。一つの有理数を、これら全ての場所で任意の精度まで近づけられる。これを :term[弱近似]{en="weak approximation" yomi="じゃくきんじ"} という。

各有限場所で要求する誤差の付値の下限を $k_p$ とする。まず正整数 $D$ を取って $Dx_p\in\Z_p$ を全ての $p$ で満たすようにし、$N_p=\max(1,k_p+v_p(D))$ とおく。次に、指定した素数と互いに素で大きな正整数 $B$ を選ぶ。中国式剰余定理によって $y\equiv BDx_p\bmod p^{N_p}$ を同時に満たす整数 $y$ は、法 $M=\prod_p p^{N_p}$ の一つの剰余類をなす。この剰余類の元を $BDx_\infty$ の近くに取れば、$x=y/(BD)$ は実数上で誤差 $M/(BD)$ 以下となる。また $p\nmid B$ なので、有限場所では $v_p(x-x_p)\ge N_p-v_p(D)\ge k_p$ である。$M,D$ を固定して $B$ を大きくできるため、全ての誤差を指定の範囲に入れられる。

## Hensel の補題

有限段の持ち上げ :ref[thm-nt-finite-hensel] を繰り返せば単根の極限が得られる。導関数が単元でない場合も、元の誤差が十分小さければ Newton 法で修正できる。

:::theorem[Newton 型 Hensel の補題]{#thm-nt-padic-hensel}
$f\in\Z_p[X]$、$a\in\Z_p$、$s=v_p(f'(a))<\infty$ とする。$v_p(f(a))>2s$ なら $v_p(\alpha-a)>s$ を満たす根 $\alpha\in\Z_p$ が一意に存在する。
:::

:::proof
$f(a)=0$ なら $a$ を根として取る。そうでない場合は $h=-f(a)/f'(a)$ とおく。$v_p(h)>s$ なので $a+h\in\Z_p$ であり、Taylor 展開の二次以上の項から $v_p(f(a+h))\ge2v_p(h)$ となる。導関数の値の変化は $h$ の倍数なので新しい導関数も付値 $s$ である。従って $v_p(f(a))-2s$ は反復ごとに少なくとも二倍になり、修正量が $0$ に行く。完備性と連続性によって極限が根になる。すべての修正が付値 $s+1$ 以上なので極限も指定の球に入る。

同じ球内の $b,c$ の差を取ると $f(b)-f(c)=(b-c)F(b,c)$ である。多項式の差を各単項式で展開すると $F(a,a)=f'(a)$ であり、$F(b,c)-F(a,a)$ は $p^{s+1}$ の倍数である。従って $F(b,c)\ne0$ であり、$b,c$ がともに根なら $b=c$ である。
:::

例えば $X^2-2$ は $a=3$ から $\Z_7$ で根をもち、:ref[thm-nt-finite-hensel] の結果と同じく法 $49$ で $10$ に還元される。$X^2-17$ は $p=2$、$a=1$ とすると $v_2(f(a))=4>2v_2(f'(a))=2$ なので $\Z_2$ に根がある。反対に $X^2-5$ では $v_2(f(1))=2$ に留まり、奇数平方が $1\bmod8$ であることから根はない。

### 多項式の因子を持ち上げる

$f$ を $\Z_p[X]$ のモニック多項式とし、法 $p$ で $\bar f=gh$ をモニックな互いに素な多項式の積とする。これを同じ次数のモニックな因子へ持ち上げる。法 $p^k$ の近似因子を $G,H$ とし、法 $p^{k+1}$ での補正を $G+p^kU,H+p^kV$ と書く。すると必要な一次方程式は
$$
hU+gV\equiv(f-GH)/p^k\pmod p,\qquad \deg U<\deg g,\quad \deg V<\deg h
$$
である。この線形写像は核が零である。実際 $\bar g\mid \bar hU$ なら互いに素なので $\bar g\mid U$ であり、次数から $U=0$、次いで $V=0$ である。定義域と値域の次元はともに $\deg f$ なので全射でもある。各段で補正が一つ定まり、係数の極限が因子を与える。この証明は一根の場合の傾きを、係数ベクトルに対する可逆な写像に置き換えたものである。

## Ostrowski の定理

:::theorem[有理数の絶対値の分類]{#thm-nt-ostrowski}
$\Q$ 上の非自明な絶対値は、通常の絶対値の $\alpha$ 乗（$0<\alpha\le1$）、またはある素数 $p$ の $p$ 進絶対値の正の冪である。
:::

:::proof
絶対値を $A$ と書く。ある整数 $b\ge2$ が $A(b)>1$ を満たすとする。整数 $m^k$ を $b$ 進展開すると桁数は $1+\lfloor k\log_b m\rfloor$ であり、各桁の絶対値は固定定数で抑えられる。等比和の評価から $A(m)^k\le C_b A(b)^{k\log_b m}$ を得る。$k$ 乗根を取って極限を取ると $A(m)\le m^{\log_b A(b)}$ である。一方 $m\ge2$ で $A(m)\le1$ なら $b^k$ の $m$ 進展開は $A(b)^k=O(k)$ を与えて矛盾する。従って全 $m\ge2$ が $A(m)>1$ であり、基数 $m,b$ を交換した同じ評価から等号が出る。乗法性により有理数へ延びる。また三角不等式から $A(n)\le nA(1)=n$ であるため、指数は $1$ 以下である。逆に $0<\alpha\le1$ なら $(u+v)^\alpha\le u^\alpha+v^\alpha$（$u,v\ge0$）なので、通常の絶対値のこの冪も絶対値になる。非零の $u$ で割れば、後者の不等式は $(1+t)^\alpha-1\le t^\alpha$ であり、$t>0$ で導関数を比べれば分かる。$p$ 進絶対値の正の冪では、強三角不等式がそのまま保たれる。

すべての整数で $A(n)\le1$ なら、$(x+y)^N$ の二項展開から $A(x+y)^N\le(N+1)\max(A(x),A(y))^N$ であり、極限で強三角不等式になる。非自明性と分解の一意性から $A(p)<1$ の素数がある。二つの素数 $p,q$ でこの不等式が成り立つなら $up+vq=1$ に強三角不等式を適用して $A(1)<1$ となるので矛盾する。他の素数では絶対値が $1$ であるため $A(x)=A(p)^{v_p(x)}$ であり、所望の形になる。
:::

例えば $A(x)=\abs{x}_3^{1/2}$ は同じ Cauchy 列と完備化を与える。冪によって距離は変わるが、距離が $0$ へ行く条件は同じである。一方 $\max(\abs x_2,\abs x_3)$ は一般に乗法的ではない。$x=2,y=3$ では各値が $1$ であるのに、積では $\max(1/2,1/3)=1/2$ になる。

### 離散付値から位相を読む

$A(x)=\abs{x}_p^c$（$c>0$）に換えても、$A(x-y)<r$ は $\abs{x-y}_p<r^{1/c}$ と同値なので、開集合は変わらない。これに対して $p\ne q$ のとき、列 $p^n$ は $\Q_p$ では零へ行くが $\abs{p^n}_q=1$ である。普通の絶対値では同じ列は発散する。従って分類に現れる各 $p$ と通常の絶対値は異なる位相を与える。また、通常の絶対値を二乗した関数は $A(1+1)=4>2=A(1)+A(1)$ なので、分類の指数の上限は不可欠である。

## ℚ_p の乗法群の構造と平方類

:::proposition[単元の構造と平方の判定]{#prop-nt-padic-square-classes}
$\Q_p^\times=p^\Z\times\Z_p^\times$ である。奇素数 $p$ では $\Z_p^\times=\mu_{p-1}\times(1+p\Z_p)$ であり、$\mu_{p-1}$ は $p-1$ 乗根の巡回群である。奇素数では単元が平方であることと法 $p$ の像が平方であることは同値である。$p=2$ の場合は単元が平方であることと $1\bmod8$ であることが同値であり、$\Z_2^\times=\{\pm1\}\times(1+4\Z_2)$ である。
:::

:::proof
付値を分離すれば最初の分解を得る。奇素数 $p$ では $X^{p-1}-1$ の全非零の法 $p$ の根が単根である。Hensel の補題により各元がちょうど一つ持ち上がる。積を法 $p$ へ落としても積が保たれるので、これらの根は $\F_p^\times$ に同型な群となる。各単元から対応する根を割れば $1+p\Z_p$ に入る。平方について、平方根の法 $p$ の像が非零なら $X^2-u$ の導関数 $2x$ は単元なので、Hensel の補題で持ち上がる。逆向きは還元すればよい。

$2$ 進では奇数平方が法 $8$ で $1$ である。逆に $u\equiv1\pmod8$ なら $X^2-u$ に $a=1$ を使うと $v_2(f(a))\ge3>2$ なので根が得られる。最後の分解は法 $4$ の単元を $\pm1$ で代表して行える。
:::

従って $\Q_p^\times/\Q_p^{\times2}$ は奇素数で $1,u,p,up$（$u$ は法 $p$ の非平方単元）、$p=2$ で $1,3,5,7,2,6,10,14$ を代表とする。例えば $\Q_7$ で $14$ は付値 $1$ のため平方ではないが、$98=7^2\cdot2$ では $2\equiv3^2\pmod7$ なので平方である。$\Q_2$ で $68=4\cdot17$ は平方になる。

### 主単元と付値を保つ指数表示

奇素数 $p$ の $1+p\Z_p$ と $p=2$ の $1+4\Z_2$ は、加法群 $\Z_p$ と同型である。奇素数では $g=1+p$、$p=2$ では $g=5$ を取る。前者では二項展開から $v_p(g^{p^j}-1)=j+1$、後者では :ref[prop-nt-two-power-units] の証明により $v_2(5^{2^j}-1)=j+2$ である。これを $v_p(g^{p^j}-1)=j+c$（$c=1$ または $2$）と書く。$p\nmid m$ のとき $Y=1+p^su$ に $Y^m-1$ の展開を適用すると、一次項の付値がちょうど $s$ で、他の項は全てより大きい。従って正の整数 $k$ について $v_p(g^k-1)=c+v_p(k)$ であり、逆数を取れば負の整数も同じである。

$t\in\Z_p$ の整数近似 $t_j$ に対し $g^t=\lim_j g^{t_j}$ と定義する。指数の差の付値が上がると $g^{t_i}$ と $g^{t_j}$ の差の付値も上がるので、極限は存在し近似列によらない。整数上の積の法則が極限に移り、加法を積に送る。法 $p^{k+c}$ で $g$ の位数は $p^k$ であり、$1$ に $p^c$ の倍数を足した単元の個数も $p^k$ である。したがって全ての主単元について指数の剰余類が各段で一意にあり、互いに両立する。:ref[thm-nt-padic-inverse-limit] によりその指数が $\Z_p$ の一元に定まる。例えば $1+5=6$ の法 $125$ の冪は位数 $25$ であり、$6^5\equiv26\pmod{125}$ は主単元の第二桁だけを動かす。対数を導入しなくても、有限剰余と持ち上げからこの群構造を得られる。

### Teichmüller の代表

奇素数 $p$ と $u\in\Z_p^\times$ について、$u^{p^n}$ は同じ剰余をもつ唯一の $(p-1)$ 乗根 $\omega(u)$ に収束する。実際 $u=\omega(u)v$、$v\in1+p\Z_p$ と分けると、$\omega(u)^{p^n}=\omega(u)$ である。$v-1$ の付値が $k\ge1$ のときは二項展開で $v^{p^n}-1$ の付値が $k+n$ になり、$v=1$ のときも収束する。この代表によって法 $p$ の非零類の掛け算を厳密に持ち上げられるが、和については決まった代表に繰り上がりが入る。例えば $p=3$ の非零代表は $1,-1$ であり、$1+1=2$ は $-1$ に等しくない。

## Hilbert 記号と積公式

:::definition[Hilbert 記号]{#def-nt-hilbert-symbol}
$F=\Q_p$ または $\R$、$a,b\in F^\times$ とする。$z^2=ax^2+by^2$ が $F$ に非零解をもつとき $(a,b)_F=1$、そうでないとき $-1$ とする。これを :term[Hilbert 記号]{en="Hilbert symbol" yomi="ひるべるときごう"} といい、$F=\R$ のとき添字を $\infty$ と書く。
:::

$a$ が非平方なら、解では $y\ne0$ であるから、記号が $1$ であることは $b$ が $F(\sqrt a)$ からのノルム $z_0^2-ax_0^2$ になることと同値である。従って $b$ を $-ab$ に替えても値は同じである。これは $-a$ が $\sqrt a$ のノルムであり、ノルムが乗法的であるためである。$a$ が平方なら全ての $b$ で記号は $1$ なので同じ変形が使える。

方程式で $x,y$ を入れ替えると $(a,b)_F=(b,a)_F$ である。また $(a,-a)_F=1$ は $(x,y,z)=(1,1,0)$ を代入すれば分かる。

:::theorem[局所公式]{#thm-nt-hilbert-formulas}
$a=p^\alpha u,b=p^\beta v$ とし、$u,v$ は単元とする。奇素数では
$$
(a,b)_p=\left(\frac{-1}p\right)^{\alpha\beta}
\left(\frac up\right)^\beta\left(\frac vp\right)^\alpha .
$$
$p=2$ では $\epsilon(u)=(u-1)/2\bmod2$、$\omega(u)=(u^2-1)/8\bmod2$ を奇数剰余で計算し、
$$
(a,b)_2=(-1)^{\epsilon(u)\epsilon(v)+\alpha\omega(v)+\beta\omega(u)} .
$$
実数では $a,b$ がともに負の場合だけ $-1$ である。
:::

:::proof
平方を掛けても変数の拡大で値は不変なので $\alpha,\beta$ は $0,1$ でよい。奇素数で両方が単元なら、$y=1$ とした $z^2-u x^2=v$ を法 $p$ で解ける。$z^2$ と $v+ux^2$ の値の集合がいずれも $(p+1)/2$ 個なので交わるからである。$x,z$ は同時に $0$ にならず、一方の変数で Hensel の補題を使える。$a=pu,b=v$ なら原始な解を法 $p$ で見て $z^2=v y^2$、かつ $y\not\equiv0$ が必要である。もし $y,z$ が $p$ の倍数なら $x$ も $p$ の倍数となるからである。逆に $v$ が平方なら $x=0$ で解ける。両方の付値が $1$ の場合は $b$ を $-ab$ に替え、平方 $p^2$ を除けば前の場合に帰着する。

$p=2$ で $a,b$ が単元なら、両者が $3\bmod4$ の場合に法 $4$ で原始解がない。実際、$x,y$ の奇数の個数が一つなら右辺が $3$、二つなら $2$、零なら全変数が偶数になる。例えば $a\equiv1\pmod4$ なら $x=1$ とし、$y=0$ または $2$ を選ぶと $a+by^2\equiv1\pmod8$ にできる。$b\equiv1\pmod4$ でも役割を交換する。$a=2u,b=v$ なら原始解で $y,z$ が奇数でなければならない。両者が偶数だと法 $4$ から $x$ も偶数となる。法 $8$ で残る条件は $v\equiv1$ または $v+2u\equiv1$ であり、これらは $y=1$、$x=0$ または $1$ で十分でもある。$v=1,3,5,7\bmod8$ の順に条件は常に真、$u\equiv3\bmod4$、常に偽、$u\equiv1\bmod4$ であり、指数 $\epsilon(u)\epsilon(v)+\omega(v)$ が偶数である場合と一致する。両付値が $1$ なら $b$ を $-ab$ に替えて単元 $-uv$ とする。$\epsilon(-uv)=1+\epsilon(u)+\epsilon(v)$、$\omega(-uv)=\omega(u)+\omega(v)$ が法 $2$ で成り立ち、$\epsilon(u)(1+\epsilon(u))=0$ なので表示した式になる。実数の場合は符号から分かる。
:::

:::theorem[Hilbert の積公式]{#thm-nt-hilbert-product}
任意の非零有理数 $a,b$ に対し $(a,b)_\infty\prod_p(a,b)_p=1$ である。
:::

:::proof
局所公式から各変数について乗法的である。$p=2$ では、奇整数 $u,v$ について $uv-1=(u-1)+(v-1)+(u-1)(v-1)$ と展開して $2$ で割ると、$\epsilon(uv)=\epsilon(u)+\epsilon(v)$ が法 $2$ で従う。同様に $u^2v^2-1=(u^2-1)+(v^2-1)+(u^2-1)(v^2-1)$ を $8$ で割ると、$\omega(uv)=\omega(u)+\omega(v)$ が従う。いずれも法 $8$ の剰余で計算できるので奇単元でも成り立つ。記号は有限個以外で $1$ であり、平方の寄与はない。従って $-1,2$ と奇素数を生成元とする組だけを調べればよい。

$(-1,-1)$ では $2,\infty$ の二箇所で符号 $-1$ が出る。$(-1,2),(2,2)$ は全て $1$ になる。奇素数 $p$ に対する $(-1,p),(2,p),(p,p)$ では $p$ での値が順に $\left(\frac{-1}p\right),\left(\frac2p\right),\left(\frac{-1}p\right)$ であり、$2$ での値も順に $(-1)^{\epsilon(p)},(-1)^{\omega(p)},(-1)^{\epsilon(p)}$ である。二つの補充法則によって対応する値は等しい。異なる奇素数 $p,q$ の組では、$p,q,2$ の三か所での積が $\left(\frac qp\right)\left(\frac pq\right)(-1)^{\epsilon(p)\epsilon(q)}=1$ となる。ここでは :ref[thm-nt-quadratic-reciprocity] を使った。他の箇所は奇素数の単元どうし、または正数を含む実数の場合なので全て $1$ である。
:::

例えば $(2,5)_5=-1$、$(2,5)_2=-1$ であり、他の箇所では $1$ である。$(-1,-1)_2=-1$ は $z^2+x^2+y^2=0$ の原始解が法 $4$ で存在しないことを表す。局所記号の積が常に $1$ であるため、一箇所の値を残りから復元できる。

### ノルム群の指数を平方類から求める

非平方 $a$ に対し、$b\mapsto(a,b)_p$ は平方類群から $\{1,-1\}$ への準同型である。非自明性は局所公式から分かる。奇素数では $v_p(a)$ が奇数なら非平方単元 $b$、$v_p(a)$ が偶数で単元部分が非平方なら $b=p$ を取る。$p=2$ では付値が奇数なら $b=5$ を取る。付値が偶数で単元部分が $3,7\bmod8$ なら $b=-1$、$5\bmod8$ なら $b=2$ である。いずれも符号は $-1$ になる。従ってノルム群は添字二であり、平方類のちょうど半分がノルムになる。局所的なノルムの有無は二次形式の表現と同じ問題である。

:::solution
$45=3^2\cdot5$ で分母 $28$ は $3$ と互いに素である。従って付値は $2$、絶対値は $3^{-2}=1/9$ である。

$\sum_{j\ge0}5^{2j}$ の $5$ 進での値を求めよ。

:::

:::solution
$3\cdot17=51\equiv1\pmod{25}$ であり、$0\le17<25$ なので代表は $17$ である。
:::

$10,45$ が $\Q_5$ で平方かを判定せよ。
:::solution
両数とも $5$ の指数が $1$ である。平方の付値は偶数なのでどちらも平方ではない。
:::

どちらも単元であり、法 $8$ の余りはそれぞれ $1,5$ である。:ref[prop-nt-padic-square-classes] により前者だけが平方である。
:::

::::exercise{level=advanced}
$(3,7)_3$、$(3,7)_7$、$(3,7)_2$ を求めよ。
:::solution
奇素数ではそれぞれ $\left(\frac73\right)=1$ と $\left(\frac37\right)=-1$ である。$2$ 進では両単元が $3\bmod4$ なので指数が奇数となり $-1$ である。他の場所は $1$ なので積公式にも一致する。
:::
::::

::::exercise{level=advanced}
$\Q_p$ の任意の有限和で、一項だけが最小の付値をもつなら和は $0$ ではないことを示せ。
:::solution
残りの全項の和は強三角不等式により、その最小の付値よりも大きい付値をもつ。従って最小の項を加えたときには付値が異なる場合の等号条件が使え、和には最小の付値が残る。有限の付値をもつ元は非零である。
:::
::::

::::exercise{level=advanced}
$1/7$ の $2$ 進表示の最初の六桁を下位から求めよ。
:::solution
分子 $a_0=1$ に対し $d_j\equiv a_j/7\equiv a_j\pmod2$、$a_{j+1}=(a_j-7d_j)/2$ とする。分子は $1,-3,-5,-6,-3,-5$ と進み、桁は $1,1,1,0,1,1$ である。六桁の和は $1+2+4+16+32=55$ であり、$7\cdot55=385\equiv1\pmod{64}$ と確認できる。
:::

## 確認テスト

::::quiz
$\abs{x-y}_p<\abs x_p$ のとき必ず成り立つものはどれか。

- [x] $\abs y_p=\abs x_p$
- [ ] $\abs y_p<\abs x_p$
- [ ] $\abs y_p>\abs x_p$

:::explanation
$y=x+(y-x)$ と書ける。二項の絶対値が異なるので、強三角不等式の等号条件により和の絶対値は大きい方の $\abs x_p$ である。
:::
::::

::::quiz{answer="3" tol="1e-6"}
$v_2(24)$ を求めよ。
:::explanation
$24=2^3\cdot3$ で奇数部分は $3$ なので付値は $3$ である。
:::
::::

::::quiz{answer="8" tol="1e-6"}
$\Q_2^\times/\Q_2^{\times2}$ の元の個数を求めよ。
:::explanation
付値の偶奇が二通り、奇単元の法 $8$ の余りが四通りある。比が平方になるには両条件が一致することが必要十分なので $2\cdot4=8$ である。
:::
::::

::::quiz
$(a,b)_\infty=-1$ となる条件を選べ。

- [x] $a<0,b<0$
- [ ] $a,b$ の一方だけが負
- [ ] $ab>0$ だけで十分

:::explanation
右辺の二平方の係数が両方負なら、$z^2=ax^2+by^2$ は零ベクトル以外で成り立たない。一方どちらかが正なら、対応しない変数を零にして実平方根を取れば非零解が得られる。
:::
::::

::::quiz{answer="11" tol="1e-6"}
$1/3$ の法 $32$ での最小非負代表を求めよ。
:::explanation
$3\cdot11-1=32$ なので $11$ が逆元である。$3$ と $32$ は互いに素であり、逆元は法 $32$ で一意である。
:::
