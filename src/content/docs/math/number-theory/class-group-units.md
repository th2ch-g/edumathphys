## この章の目標

- 格子の基本領域から Minkowski の凸体定理を証明する。
- 判別式でイデアル類の代表のノルムを抑え、類数を計算する。
- 単数の対数像が全階数格子になることを示す。
- 実二次体の基本単数と Pell 方程式を対応させる。



## 格子と Minkowski の凸体定理

連続的な領域に対して格子点の存在を保証するには、領域を格子の基本領域に折り畳む。体積が一枚分を越えれば、異なる二点の差が格子点になる。

:::definition[格子と余体積]{#def-nt-lattice}
$\R^n$ の基底 $v_1,\dots,v_n$ の整数係数の結合全体 $\Lambda$ を :term[格子]{en="lattice" yomi="こうし"} という。$0\le t_i<1$ として $\sum t_i v_i$ の全体は基本平行体であり、その体積 $\abs{\det(v_1,\dots,v_n)}$ を余体積 $\operatorname{covol}(\Lambda)$ という。
:::

:::theorem[Minkowski の凸体定理]{#thm-nt-minkowski-convex}
$\R^n$ の有界な閉凸集合 $C$ が原点対称で、$\operatorname{vol}(C)\ge2^n\operatorname{covol}(\Lambda)$ なら $C$ は非零格子点を含む。
:::

:::proof
まず真の不等式の場合を考える。$C/2$ を基本平行体の格子平行移動ごとに切り、各断片を基本平行体へ戻す。断片の体積和が基本平行体の体積を越えるため、異なる移動から来た二点が重なる。元の二点 $x,y$ は差 $x-y\in\Lambda\setminus\{0\}$ をもち、$2x,-2y\in C$ の中点なので $x-y\in C$ である。等号の場合は $(1+1/k)C$ に真の不等式を使う。有界集合に格子点は有限個しかなく、無限回現れる非零点は閉性により $C$ に属する。
:::

例えば $\Lambda=2\Z\times3\Z$ の余体積は $6$ である。$[-2,2]\times[-3/2,3/2]$ は体積 $12$ なので定理の閾値には届かないが、実際には $(2,0)$ を含む。$[-2,2]\times[-3,3]$ は体積 $24$ で閾値に達する。一方 $(-2,2)\times(-3,3)$ では同じ体積で非零点がないので、等号では閉性が必要である。

### 有限指数と余体積

$\Lambda'\subset\Lambda$ が同じ階数をもつとする。$\Lambda$ の基底で $\Lambda'$ の基底を列に並べると整数正則行列 $A$ を得る。$\Z^n/A\Z^n$ の位数は $\abs{\det A}$ である。実際、整数の可逆な行・列操作で Smith 標準形へ移すと、商は対角成分を法とする巡回群の直積になり、行列式の絶対値は操作で変わらない。従って $\operatorname{covol}(\Lambda')=[\Lambda:\Lambda']\operatorname{covol}(\Lambda)$ である。例えば $\Z^2$ の中で $(2,1),(1,3)$ が張る部分格子は指数 $5$、余体積 $5$ である。

## 代数体の埋め込みと Minkowski 空間

$n=[K:\Q]=r_1+2r_2$ とする。実埋め込み全部と複素共役対から一つずつを選び、$K$ を
$$
K_\R=\R^{r_1}\times\C^{r_2}
$$
へ送る。ここでは複素座標を実部と虚部で測り、通常の Lebesgue 体積を用いる。

:::proposition[整数環とイデアルの余体積]{#prop-nt-minkowski-covolume}
非零整イデアル $I$ の埋め込み像は全階数格子であり、余体積は $2^{-r_2}\sqrt{\abs{d_K}}NI$ である。
:::

:::proof
$O$ は :ref[thm-nt-integral-basis] により自由 $\Z$ 加群であり、$[O:I]=NI<\infty$ なので $I$ も階数 $n$ の自由 $\Z$ 加群である。その基底の埋め込み行列で複素共役の行 $u,\bar u$ を $(u+\bar u)/2,(u-\bar u)/(2i)$ に替える。変換行列の行列式の絶対値は各対で $1/2$ である。従って :ref[prop-nt-discriminant-change] と指数公式により、実座標での行列式の絶対値は $2^{-r_2}\sqrt{\abs{d_K}}[O:I]$ である。これが非零なので全階数格子となる。
:::

例えば $\Q(i)$ の基底 $(1,i)$ の像は $\Z^2$ で余体積は $1$ である。公式でも $2^{-1}\sqrt4=1$ になる。$\Q(\sqrt5)$ の整数基底の二つの実像を並べると余体積は $\sqrt5$ であり、複素座標による因子はない。

### 座標の規約を替えた場合の余体積

複素埋め込みの実部と虚部に $\sqrt2$ を掛けて測る規約もある。このとき一対で面積は $2$ 倍なので、余体積は $\sqrt{\abs{d_K}}NI$ になる。これは複素の二共役から得る絶対値二乗の和を、実 Euclid ノルムの平方に一致させるための規約である。元の規約と混ぜず、Minkowski の凸体定理に入れる領域の体積にも同じ変換を適用する。両辺が $2^{r_2}$ 倍されるため、この変更で最終的なノルムの上限は変わらない。

## Minkowski の判別式評価

:::theorem[Minkowski のイデアル評価]{#thm-nt-minkowski-bound}
任意の非零整イデアル $I$ に対し、ある $0\ne\alpha\in I$ が
$$
\abs{N_{K/\Q}(\alpha)}\le
\left(\frac4\pi\right)^{r_2}\frac{n!}{n^n}\sqrt{\abs{d_K}}\ NI
$$
を満たす。
:::

:::proof
$t>0$ とし、$\sum_{i\le r_1}|x_i|+2\sum_{j\le r_2}|z_j|\le t$ の領域を使う。これは凸対称でコンパクトである。実座標の符号をまとめると係数 $2^{r_1}$、複素座標を極座標にして $y_j=2|z_j|$ とおくと各対で体積要素 $(\pi/2)y_j\,dy_j$ となる。従って体積は
$$
2^{r_1}(\pi/2)^{r_2}\,t^n/n!
$$
である。積分に現れる各因子 $y_j$ は、非負の二変数の和を $y_j$ に固定した断面の長さである。そのため積分は $n$ 変数の単体の体積 $t^n/n!$ となる。これを $2^n$ 倍の余体積に等しく取ると $t^n=(4/\pi)^{r_2}n!\sqrt{\abs{d_K}}NI$ になる。

凸体定理で非零 $\alpha$ を取る。$n$ 個の非負数として実座標の絶対値を一回、複素座標の絶対値を二回ずつ並べると、和は $t$ 以下、積は $\abs{N(\alpha)}$ である。相加相乗平均から積は $(t/n)^n$ 以下となる。
:::

$I=O$ では非零整数ノルムが絶対値 $1$ 以上なので、$\sqrt{\abs{d_K}}\ge(\pi/4)^{r_2}n^n/n!$ が得られる。例えば二次虚数体なら $\sqrt{\abs{d_K}}\ge\pi/2$ となり、判別式の下限として $\abs{d_K}\ge3$ を得る。$\Q(i)$ に対するイデアルの定数 $(2/\pi)\sqrt4=4/\pi$ は約 $1.27$ である。

特に次数 $n\ge2$ では $|d_K|>1$ である。実際、$r_2\le n/2$ と $n!\le((n+1)/2)^n$ から、平方根の下限は $(\sqrt\pi\, n/(n+1))^n$ 以上である。$n/(n+1)\ge2/3$ かつ $2\sqrt\pi/3>1$ なので、この下限は $1$ を超える。:ref[thm-nt-ramification-discriminant] を合わせると、$\Q$ の任意の非自明な有限拡大で、少なくとも一つの有理素数が分岐する。

### 判別式に対する次数と符号数の制約

$I=O$ では $\abs{N(\alpha)}\ge1$ なので、:ref[thm-nt-minkowski-bound] の定数は少なくとも $1$ である。全実三次体なら $r_2=0,n=3$ だから $\sqrt{\abs{d_K}}\ge27/6=9/2$、従って絶対値は $21$ 以上である。実埋め込み一つの三次体なら同じ式は $\sqrt{\abs{d_K}}\ge9\pi/8$ となり、絶対値は $13$ 以上である。これらは体が実際にその下限で存在するという主張ではない。異なる埋め込み数で同じ判別式を比較するときに、どの体積の係数を使うかが決まる。

## 類数の有限性

:::definition[イデアル類群]{#def-nt-ideal-class-group}
非零分数イデアルの群を、非零単項分数イデアル全体で割った商群を :term[イデアル類群]{en="ideal class group" yomi="いであるるいぐん"} $\mathrm{Cl}(K)$ という。イデアルが同じ類であるとは、一方が他方の $K^\times$ 倍になることをいう。
:::

:::theorem[類の代表と有限性]{#thm-nt-class-finite}
各イデアル類はノルム
$$
M_K=\left(\frac4\pi\right)^{r_2}\frac{n!}{n^n}\sqrt{\abs{d_K}}
$$
以下の整イデアルで代表できる。従って類群は有限である。
:::

:::proof
求める類の逆類を表す整イデアル $I$ を選ぶ。分数イデアルから分母を払えばそのような整イデアルが取れる。:ref[thm-nt-minkowski-bound] の $\alpha\in I$ に対し $J=(\alpha)I^{-1}\subset O$ とおく。これは $I$ の逆類に属し、ノルムは $\abs{N(\alpha)}/NI\le M_K$ となる。有限指数 $m$ の部分群 $J$ では $mO\subset J$ が成り立つ。実際、加法群 $O/J$ の任意の元の位数は $m$ を割る。固定した $m$ に対し $J$ は有限群 $O/mO$ の部分群に対応するため有限個である。$m\le M_K$ の有限範囲を合わせれば結論を得る。
:::

有限群の位数を $h_K$ と書く。$M_K<2$ なら各類の代表はノルム $1$ の $O$ しかないので $h_K=1$ である。また一般にノルム上限以下の素イデアルの類が類群を生成する。各代表の素因数は乗法性から同じ上限以下だからである。

$h_K=1$ と $O$ が単項イデアル整域であることは定義から同値であり、この場合は元の素因数分解も一意である。逆に元の素因数分解が一意なら、任意の非零素イデアル $P$ の非零元を既約元に分解すると、少なくとも一因子 $\pi$ が $P$ に入る。一意分解整域では既約元が素元なので $(\pi)$ は非零素イデアルであり、Dedekind 性により極大である。従って $P=(\pi)$ となる。すべての非零イデアルは素イデアルの積なので単項となり、$h_K=1$ に戻る。

### 小さいノルムの有限候補を生成する手順

$M_K$ 以下の整イデアルは、各有理素数 $p\le M_K$ の上の素イデアルを、ノルムの積が上限以下になる指数で組み合わせて得られる。指数を別々に制限するだけでは全体の積を超えるので、積を最後に調べる。たとえば $3<M_K<4$ なら候補ノルムは $1,2,3$ であり、ノルム $2$ の素イデアルの平方は候補から外れる。一方、その平方が単項かどうかは類群の関係を決めるために調べてよい。代表の上限は、関係式に現れるすべてのイデアルのノルムを制限するものではない。

## 類数の計算例（二次体）

$\Q(\sqrt{-5})$ は $d_K=-20$、$M_K=(2/\pi)\sqrt{20}$ が $2$ と $3$ の間である。ノルム $2$ のイデアルは $P=(2,1+\sqrt{-5})$ だけであり、$(2)=P^2$ である。ノルム $2$ の元がないので $P$ は単項ではなく、候補二つがともに異なる類になる。従って $h_K=2$ である。

$\Q(\sqrt{-23})$ では $M_K=(2/\pi)\sqrt{23}$ が $3$ と $4$ の間である。$\theta=(1+\sqrt{-23})/2$ の最小多項式 $X^2-X+6$ は法 $2,3$ で $X(X-1)$ になる。$P_i=(2,\theta-i)$、$Q_i=(3,\theta-i)$（$i=0,1$）と置く。$N(\theta)=6$ なので $(\theta)=P_0Q_0$ であり、$Q_0$ の類は $P_0$ の逆である。$N(1+\theta)=8$ で $1+\theta$ が入る $2$ 上の素イデアルは $P_1$ だけなので $(1+\theta)=P_1^3$ である。従って $P_0$ の類が全群を生成し、その位数は $3$ を割る。$N(a+b\theta)=a^2+ab+6b^2=(a+b/2)^2+23b^2/4$ は $2$ を取らないので主類ではない。従って $h_K=3$ である。二元二次形式での $h(-23)$ の計算とも一致する。

実二次体の例では $\Q(\sqrt5)$ の上限は $\sqrt5/2<2$ なので類数 $1$ である。これは単数が有限個という意味ではない。類群での有限性と単数の階数は異なる量から生じる。

虚二次体の表では、ノルムの探索と別に :ref[thm-nt-form-ideal-correspondence] で類数を計算できる。基本判別式 $D<0$ なら、正定値原始形式の真の類と整数環のイデアル類が対応する。簡約形では $|b|\le a\le c$ なので $|D|=4ac-b^2\ge3a^2$ となる。そこで $1\le a\le\sqrt{|D|/3}$ と $-a\le b\le a$ を走らせ、$c=(b^2-D)/(4a)$ が整数で $c\ge a$、$\gcd(a,b,c)=1$ となる組を残す。$|b|=a$ または $a=c$ なら $b\ge0$ とすれば、境界で同じ類を二度数えずに済む。例えば $D=-31$ では $a\le3$ であり、$a=1,2$ から $(1,1,8),(2,\pm1,4)$ が出る。$a=3$ では奇数の $b=\pm1,\pm3$ に対して $b^2+31$ が $12$ で割れない。従って三類である。

### 虚二次体で単項性を有限探索する

$\omega=(1+\sqrt D)/2$（$D<0$、$D\equiv1\pmod4$）なら
$$
N(x+y\omega)=\left(x+\frac y2\right)^2+\frac{|D|y^2}{4}
$$
である。ノルム $m$ の元の候補は $\abs y\le2\sqrt{m/\abs D}$ を満たす。各 $y$ に対し、残りの平方を調べれば有限個の候補を全て得られる。特にノルム $m$ の元が存在しなければ、ノルム $m$ のイデアルはどれも単項でない。元が見つかった場合は、その単項イデアルが目的の素因子を含むかを剰余で確認する必要がある。例えばノルム $p$ の元を共役に移すと、分裂した二つの素イデアルの片方から他方へ移る。

## Dirichlet の単数定理

単数の全共役の絶対値の積は $1$ である。対数を取ればこの積が線形条件となるため、単数の増え方を一つの超平面上で調べられる。

:::theorem[Dirichlet の単数定理]{#thm-nt-unit-theorem}
$K$ の $1$ の冪根の全体を $\mu(K)$ とすると
$$
O^\times\simeq\mu(K)\times\Z^{r_1+r_2-1}.
$$
$\mu(K)$ は有限巡回群である。
:::

:::proof
$r=r_1+r_2$ とし、実座標には $d_i=1$、複素座標には $d_i=2$ を割り当てる。任意の $x\in K^\times$ の対数ベクトルを $\ell(x)=(d_i\log|\sigma_i(x)|)_i$ とする。成分和は $\log|N(x)|$ なので、単数の像は $H=\{t\in\R^r\mid\sum_i t_i=0\}$ にある。単数の対数像を有界範囲に限れば、埋め込みの絶対値も有界であり、:ref[prop-nt-minkowski-covolume] の格子性により元は有限個しかない。従って対数像は離散的であり、核も有限である。核の各元の全ての冪が核に入るので根の一つである。逆に $1$ の冪根の全ての共役の絶対値が $1$ なので核に入る。有限乗法群の巡回性は :ref[lem-nt-finite-field-cyclic] の証明が任意の体で使えることから従う。

対数像が $H$ を張ることを示す。$t\in H$ を任意に取り、$|\sigma_i(x)|\le C\exp(t_i/d_i)$ で定める箱を考える。実座標では区間、複素座標では円板の積であり、体積は $2^{r_1}\pi^{r_2}C^n\exp(\sum t_i)$ で、$t$ に依存しない。$C>1$ を十分大きく選び、Minkowski の凸体定理で非零整数 $\alpha$ を得る。このとき
$$
\ell_i(\alpha)-t_i\le d_i\log C,\qquad 1\le |N(\alpha)|\le C^n.
$$
成分和が非負なので、各 $\ell_i(\alpha)-t_i$ は他成分の上限の和の負値でも下から抑えられる。従って $\ell(\alpha)$ は $t$ から一定距離の範囲にある。

$(\alpha)$ のノルムが有界だから、可能な単項イデアルは有限個である。それぞれ一つの生成元 $\alpha_j$ を選べば $\alpha/\alpha_j$ は単数である。従って対数像の点が任意の $t$ から一定距離の内側に存在する。もし像の実線形包が $H$ の真部分空間なら、そこから距離を無限に増やす方向があるので矛盾する。

離散部分群 $\Gamma=\ell(O^\times)$ から $H$ の基底になる元を $r-1$ 個選ぶ。それらの整数張り $\Gamma_0$ で割ると、すべての剰余類を基本平行体内で代表できる。有界領域に $\Gamma$ の点は有限個なので指数は有限である。その指数を $m$ とすると、$\Gamma$ は $\Gamma_0$ と $m^{-1}\Gamma_0$ の間にあるから、自由加群として階数 $r-1$ である。$\Gamma$ の基底の単数への持ち上げは自由部分群を生成し、その積で任意の単数を核へ移せる。従って表示した直積が得られる。
:::

例えば $\Q(i)$ の単数は $\mu(K)=\{\pm1,\pm i\}$ のみで、階数は零である。実二次体では $r_1=2$ なので階数一、二つの対数座標は互いに反対になる。複素座標の重み $2$ は複素共役対を一つだけ記録することに対応する。

### Regulator と対数格子の測り方

$\Gamma=\ell(O^\times)$ は $H$ の全階数格子なので、基本単数 $\varepsilon_1,\dots,\varepsilon_{r-1}$ の対数を列に並べられる。各列の成分和は零であり、任意の一行を除いた正方行列の行列式の絶対値は同じになる。実際、除いた行は他の行の負の和であり、ある行を除く代わりにその行を戻して別の行を除くと、行列式の多重線形性で一項だけが残る。基底を替えると右から整数の可逆行列が掛かり、その行列式の絶対値は $1$ である。従ってこの量は単数の基底によらず、:term[Regulator]{en="regulator" yomi="れぎゅれーたー"} と呼ぶ。階数零では空行列の行列式を $1$ とする。

この規約の Regulator は、$H$ の Euclid 体積による格子の余体積を $\sqrt r$ で割ったものである。最後の座標を省いて $(t_1,\dots,t_{r-1})$ に展開すると、戻す写像の列は $e_i-e_r$ である。その Gram 行列は単位行列に全成分 $1$ の行列を足したもので、固有値は $1$ が $r-2$ 個、$r$ が一つである。従って体積は $\sqrt r$ 倍になる。$r=1$ では空積の規約で同じ結論である。例えば実二次体ではこの違いが $\sqrt2$ 倍であり、Regulator の値は正の実埋め込みでの基本単数 $\varepsilon$ の $\log\varepsilon$ である。[ゼータ関数と Dirichlet L 関数](/math/number-theory/zeta-functions/) の実二次体の類数公式では、まさにこの測り方の値が現れる。

### 単数の対数格子と符号

各単数について実埋め込みでの符号を並べると $\{\pm1\}^{r_1}$ への準同型になる。実埋め込みでの値がすべて正である単数を全正単数といい、その群はこの写像の核である。像は有限なので全正単数の対数像も同じ階数の部分格子である。実二次体で基本単数 $\varepsilon>1$ のノルムが $-1$ なら、もう一方の実像は負になるため、全正単数は $\varepsilon^2$ の整数冪である。ノルムが $1$ なら $\varepsilon$ 自身が両方の埋め込みで正であり、全正単数はその整数冪である。

:::proposition[狭義類群と単数の符号]{#prop-nt-narrow-class-group}
全実埋め込みで正となる元が生成する主分数イデアルだけで割った群を :term[狭義イデアル類群]{en="narrow ideal class group" yomi="きょうぎいであるるいぐん"} $\mathrm{Cl}^+(K)$ という。実埋め込みが $r_1$ 個あるとき、
$$
\ker\bigl(\mathrm{Cl}^+(K)\to\mathrm{Cl}(K)\bigr)
\simeq \{\pm1\}^{r_1}/\operatorname{sgn}(O^\times)
$$
である。したがって実二次体では、ノルム $-1$ の単数があれば $h_K^+=h_K$、なければ $h_K^+=2h_K$ となる。
:::

:::proof
整数基底の Minkowski 埋め込み行列は実座標で可逆である。従ってその基底の有理結合の像、すなわち $K$ の像は Minkowski 空間で稠密である。各符号を指定する実座標の領域は開で空でないので、$K^\times$ の元がその符号を実現する。主イデアル $(\alpha)$ の生成元の符号は、生成元を替えると単数の符号だけ変わる。従って主イデアルから符号の商への写像が定まり、今の稠密性により全射である。その核は、単数倍で全正にできる主イデアルの全体である。これは狭義類群から通常の類群へ移る際の核を記述している。実二次体では $-1$ が同符号の二通りを与え、ノルム $-1$ の単数があれば異符号の二通りも得る。
:::

例えば $\Q(\sqrt3)$ の類数は $\sqrt{12}/2<2$ から $1$ である。ノルム $-1$ の整数解 $a^2-3b^2=-1$ は法 $3$ で $a^2\equiv2$ となるため存在せず、狭義類数は $2$ になる。一方、$\Q(\sqrt5)$ にはノルム $-1$ の単数 $(1+\sqrt5)/2$ があるため、狭義類数も $1$ である。

## 実二次体の基本単数と Pell 方程式

$d>1$ を平方自由とし、$\sqrt d>0$ の実埋め込みを固定する。単数の対数像が一次元離散群なので、$\varepsilon>1$ の最小の正単数が存在し、単数全体は $\pm\varepsilon^k$ と書ける。これを :term[基本単数]{en="fundamental unit" yomi="きほんたんすう"} という。実数体に入る $1$ の冪根は $\pm1$ のみである。

$d\not\equiv1\pmod4$ なら、整数環は $\Z[\sqrt d]$ なので単数条件は $u^2-dv^2=\pm1$ である。$\varepsilon$ のノルムが $1$ ならそれが正の Pell 解の生成元であり、$-1$ なら $\varepsilon^2$ が生成元である。$d=2$ では $\varepsilon=1+\sqrt2$、ノルム $-1$ なので $3+2\sqrt2$ がノルム $1$ の最小元となる。最小性については $\varepsilon>1$ のとき $v=(\varepsilon-\varepsilon')/(2\sqrt d)>0$ である。$d=2$ では $v=1$ の最小の $u$ が $1$ で、$v\ge2$ なら正の単数の共役が絶対値 $1$ 未満であることから元の値は $2v\sqrt2-1>1+\sqrt2$ となる。

$d\equiv1\pmod4$ では単数は $(a+b\sqrt d)/2$、$a,b$ が同じ偶奇で $a^2-db^2=\pm4$ を満たす。Pell の整数解には、この中で $a,b$ が偶数の部分だけが使える。例えば $\Q(\sqrt5)$ では $\phi=(1+\sqrt5)/2$ のノルムが $-1$ である。$1<u<\phi$ が単数なら、$b=(u-u')/\sqrt5$ は正整数だが $(u+1/u)/\sqrt5<(\phi+1/\phi)/\sqrt5=1$ となるため矛盾する。従って $\phi$ は基本単数である。$\phi^2=\phi+1$、$\phi^3=2+\sqrt5$ なので $\Z[\sqrt5]$ に初めて入る正の冪は三乗である。その整数係数の単数群は $\pm\phi^{3k}$ であり、ノルム $1$ の生成元は $\phi^6=9+4\sqrt5$ である。連分数から求めた整数解とは、扱う整環を限定してから比較する。

### 部分整環に入る単数を合同で見つける

$d\equiv1\pmod4$ で $\omega=(1+\sqrt d)/2$ とすると、$\Z[\sqrt d]=\Z+2O$ である。従って $O$ の単数 $u$ がこの部分整環に入ることは、その法 $2O$ の像がスカラーであることと同値である。スカラーのうち単元は $1$ だけなので、求める指数は $(O/2O)^\times$ での $\varepsilon$ の像の位数である。$u^{-1}=\pm\bar u$ であり共役もこの部分整環に入るため、入った単数は部分整環でも可逆である。

:ref[cor-nt-quadratic-splitting] により、$d\equiv1\pmod8$ では $O/2O\simeq\F_2\times\F_2$ で、単元は $(1,1)$ しかない。従って $\varepsilon$ 自身が整数係数をもつ。$d\equiv5\pmod8$ では $O/2O\simeq\F_4$ で、単元群の位数は三である。従って $\varepsilon$ または $\varepsilon^3$ が整数係数をもつ最初の正の冪となる。

例えば $d=13$ では $\omega$ の最小多項式が $X^2-X-3$ で、法 $2$ で $X^2+X+1$ となる。従って商は四元体である。$\varepsilon=(3+\sqrt{13})/2=\omega+1$ の像は $1$ でない単元なので位数が三であり、最初に整数係数へ戻るのは $\varepsilon^3=18+5\sqrt{13}$ である。この単数はノルム $-1$ なので、正の Pell 方程式の最小解はその二乗である $649+180\sqrt{13}$ から得られる。:ref[thm-nt-pell] の周期を用いる方法と同じ答えになる。

### 調べる単数の範囲を先に決める

最小の正単数を探すとき、まず何らかの単数 $U>1$ を Pell 方程式から得る。$1<u\le U$ なら共役は $\pm u^{-1}$ である。従って $u=(a+b\sqrt d)/2$ と書くと $0<b\le(U+1/U)/\sqrt d$ であり、$a=u+u'>0$ である。この範囲で $db^2\pm4$ が平方になるかを調べ、$d\equiv1\pmod4$ では $a,b$ の偶奇が等しいものを、他の場合は両方偶数のものを残す。候補の値そのものを比較すれば基本単数が求まる。

例えば $d=7$ では $U=8+3\sqrt7$ がノルム $1$ の単数である。$u=a'+b'\sqrt7$ と書くと、上の評価から $b'\le8/\sqrt7<4$ である。$b'=1,2,3$ で調べる平方候補は $6,8,27,29,62,64$ となり、平方なのは $64$ だけである。したがって $U$ が基本単数である。

## 演習問題

::::exercise{level=basic}
$(2,0),(1,3)$ の生成する平面格子の余体積を求めよ。
:::solution
列を並べた行列は $\begin{pmatrix}2&1\\0&3\end{pmatrix}$ であり、行列式の絶対値は $6$ である。
:::
::::

::::exercise{level=basic}
$\Q(i)$ の Minkowski 空間で $(2+i)$ の余体積を求めよ。
:::solution
整数環の余体積は $1$ であり、イデアルのノルムは $(2+i)(2-i)=5$ である。従って余体積は $5$ である。
:::
::::

::::exercise{level=basic}
Minkowski の上限を使って $\Q(\sqrt{-7})$ の類数を求めよ。
:::solution
二次虚数体なので $M_K=2\sqrt7/\pi<2$ である。各類はノルム $1$ のイデアルで代表され、そのイデアルは整数環自身なので類数は $1$ である。
:::
::::

::::exercise{level=basic}
$\Q(\zeta_5)$ の単数群の自由階数を求めよ。
:::solution
次数は $4$ で、実埋め込みはない。複素埋め込みは二対なので $r_1+r_2-1=0+2-1=1$ である。
:::
::::

::::exercise{level=advanced}
$\Q(\sqrt{-5})$ でノルム $3$ のイデアルの類を求めよ。
:::solution
法 $3$ で $X^2+5=X^2-1$ なので二つのノルム $3$ の素イデアルがある。どちらも単項ならノルム $3$ の元が必要だが $a^2+5b^2=3$ には解がない。類群は二元なので両者とも唯一の非主類である。
:::
::::

::::exercise{level=advanced}
$\Q(\sqrt{13})$ に対し $\varepsilon=(3+\sqrt{13})/2$ が基本単数であることを示せ。
:::solution
$\varepsilon$ のノルムは $(9-13)/4=-1$ なので単数である。$1<u<\varepsilon$ の単数では $u'=\pm1/u$ であり、$b=(u-u')/\sqrt{13}$ は正整数となる。しかし $u+1/u$ は $u>1$ で増加し、$\varepsilon+1/\varepsilon=\sqrt{13}$ なので $b<1$ である。従ってこれより小さい正単数はない。
:::
::::

::::exercise{level=advanced}
虚二次体の単数が全て $1$ の冪根であることを、対数空間を使わずに示せ。
:::solution
ノルムは $u\bar u$ なので単数なら $|u|=1$ である。整数環の像は平面格子なので、単位円上の元は有限個である。各単数の冪も単位円上にあり、二つの冪が一致するためその差の指数で $1$ になる。
:::
::::

::::exercise{level=advanced}
$\Q(\sqrt5)$ で $\phi^6$ を求め、ノルム $1$ の Pell 解を確かめよ。
:::solution
$\phi^3=2+\sqrt5$ を二乗して $9+4\sqrt5$ を得る。そのノルムは $9^2-5\cdot4^2=1$ であり、$(9,4)$ が正の解である。
:::
::::

::::exercise{level=advanced}
$K=\Q(\sqrt{-11})$ について Minkowski の上限から類数を求めよ。
:::solution
判別式は $-11$ であり、$M_K=2\sqrt{11}/\pi$ は $2$ と $3$ の間である。整数基底の生成元の最小多項式は $X^2-X+3$ で、法 $2$ では $X^2+X+1$ が既約である。従って $2$ は惰性で、唯一の素イデアルのノルムは $4$ である。ノルム $2$ の整イデアルは存在せず、Minkowski の上限を満たす代表はノルム $1$ の整数環だけである。従って類数は $1$ である。
:::

Minkowski の上限は $2$ より大きく $3$ 未満なので、ノルム $1,2$ の代表だけを見ればよい。ノルム $2$ の分岐素イデアルはノルム方程式に解がないため非主である。従って二類になる。
:::

:::explanation

::::quiz{answer="3" tol="1e-6"}
$\Q(\sqrt{-6})$ で $M_K$ 以下のノルムをもつ非零整イデアルは何個か。
:::explanation
判別式は $-24$ なので $3<2\sqrt{24}/\pi<4$ である。$2,3$ はともに分岐し、各々の上にノルムがその素数となる素イデアルが一個ずつある。これら二個と、ノルム $1$ の $O$ を合わせて三個である。
:::
