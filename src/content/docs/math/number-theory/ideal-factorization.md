## この章の目標

- 整数環の非零素イデアルが極大であることを示す。
- 逆イデアルを構成し、イデアルの一意分解を証明する。
- 剰余次数と分岐指数を判別式および多項式から求める。
- 二次体と円分体の素数分解を具体的に計算する。



## 整数環の Dedekind 性

$\Z[\sqrt{-5}]$ では $6=2\cdot3=(1+\sqrt{-5})(1-\sqrt{-5})$ であり、元の分解には問題が生じる。実際、ノルム $x^2+5y^2$ は $2,3$ を取らない。ノルムを掛けると $2,3,1\pm\sqrt{-5}$ はすべて既約であり、ノルム $4,9,6$ と単元 $\pm1$ から二分解は同伴で説明できない。ここでは元の代わりにその倍数の集合を扱う。

:::definition[Dedekind 整域]{#def-nt-dedekind}
整閉な Noether 整域で、すべての非零素イデアルが極大であるものを :term[Dedekind 整域]{en="Dedekind domain" yomi="でできんとせいいき"} という。Noether 性とはイデアルの昇鎖が停止することであり、:ref[thm-ring-noetherian] により全イデアルが有限生成であることと同値である。
:::

:::proposition[整数環の Dedekind 性]{#prop-nt-number-ring-dedekind}
代数体 $K$ の整数環 $O=\mathcal O_K$ は Dedekind 整域である。非零イデアル $I$ に対し $O/I$ は有限である。
:::

:::proof
整閉性は :ref[prop-nt-integrally-closed] で示した。$O$ は :ref[thm-nt-integral-basis] により有限階数の自由 $\Z$ 加群なので、イデアルはその部分加群として有限生成であり、同じ生成元で $O$ 上でも生成される。$I$ の非零元 $\alpha$ のモニック最小多項式を $X^m+\cdots+a_0$ とする。$a_0\ne0$ であり、$\alpha$ の式から $a_0\in(\alpha)\subset I$ である。従って $O/I$ は有限な $O/a_0 O$ の商である。$I$ が素ならこの有限商は整域である。非零元による乗法は単射で有限性から全射なので、逆元があり体になる。
:::

例えば $\Q(i)$ では $(1+i)$ の商は $i\equiv-1$、$2\equiv0$ により $\F_2$ である。一方 $(2)$ では $(1+i)^2=2i$ なので零でない元 $1+i$ が二乗で零に落ちる。この例では素元として現れるのは $2$ そのものではない。

### ノルムで元の既約性だけを判定する

$\alpha\in O$ が単数であることは、体ノルムの絶対値が $1$ であることと同値である。実際、$\alpha$ の乗法行列は整数基底上の整数行列で、行列式の絶対値が $1$ なら逆行列も整数係数である。従って $1$ の逆像は $O$ に入る。逆に単数なら逆元も整数環にあり、二つの整数ノルムの積が $1$ となる。

この判定から、ノルムの絶対値が素数の元は既約である。分解を仮定すると一方の因子の絶対ノルムは $1$ だからである。一方、$\Q(\sqrt{-5})$ ではノルム $4$ の元 $2$ も既約である。ノルム $2$ の整数がないためである。しかし $(1+\sqrt{-5})(1-\sqrt{-5})=6$ は $2$ で割れ、個々の因子は $2$ で割れない。イデアル $(2)$ の商で非零な二元の積が零になるので、既約性と素性が分かれる。

## イデアルの素因数分解の一意性

非零分数イデアルとは、非零整数を掛ければ $O$ の非零イデアルになる $O$ 部分加群である。積は元どうしの積の有限和で定める。$I^{-1}=\{x\in K\mid xI\subset O\}$ と置くと $O\subset I^{-1}$（$I$ が整イデアルの場合）である。非零 $\alpha\in I$ から $I^{-1}\subset\alpha^{-1}O$ なので、これは分数イデアルである。

:::lemma[素イデアルの可逆性]{#lem-nt-prime-ideal-inverse}
任意の非零素イデアル $P$ に対し $PP^{-1}=O$ である。
:::

:::proof
まず非零イデアル $I$ は非零極大イデアル有限個の積を含む。含まないイデアルが存在すると仮定して、昇鎖条件から極大の反例 $I$ を取る。$I$ は素イデアルなら自身を含むので素でない。$a,b\notin I$ かつ $ab\in I$ を取ると $I+(a),I+(b)$ は各々素イデアルの積を含む。$O$ 自身では空積を使える。両イデアルの積が $I$ に入るので反例でないことになり矛盾する。

$0\ne a\in P$ を取り、$(a)$ に入る素イデアルの積のうち因子数が最小のものを選ぶ。積が $P$ に入るので、一因子が $P$ に含まれ、極大性から $P$ に等しい。残りの積は最小性により $(a)$ に入らない。そこから $b\notin(a)$ を取れば $bP\subset(a)$ である。ゆえに $b/a\in P^{-1}\setminus O$ となる。

$P\subset PP^{-1}\subset O$ なので $PP^{-1}$ は $P$ か $O$ である。前者なら $b/a$ は有限生成加群 $P$ を自身へ写す。:ref[lem-nt-integral-determinant] を $A=O$ に適用し、整閉性を使うと $b/a\in O$ となり矛盾する。従って後者である。
:::

:::theorem[素イデアル分解]{#thm-nt-ideal-factorization}
非零整イデアルは非零素イデアルの積に一意に分解する。分数イデアルは同じ素イデアルの整数指数の積に一意に分解し、すべて可逆である。
:::

:::proof
真の非零整イデアル $I$ を含む極大イデアル $P$ を取り、$J=IP^{-1}$ とする。$I\subset J\subset O$ である。$I=J$ なら $P^{-1}$ の任意の元が $I$ を自身へ写し、行列式の判定と整閉性から $P^{-1}\subset O$ となるが、前補題の構成と矛盾する。従って真の昇鎖になり、有限回で $O$ に達する。各段を $I=JP$ と戻せば積を得る。

二分解の一方の因子 $P$ は他方の積を含むため、他方のある因子を含む。ともに極大なので等しく、逆イデアルを掛けて消去できる。反復して一意性を得る。分数イデアルは一度整数倍して分解し、その整数の単項イデアルの分解を引けばよい。一意性は分母を払って整イデアルの場合から従う。
:::

$I=\prod P^{a_P}$、$J=\prod P^{b_P}$ なら $I\subset J$ と全ての $a_P\ge b_P$ は同値である。実際、包含は $IJ^{-1}\subset O$ と同値で、整イデアルの分解では指数が非負である。従って和と共通部分では指数の最小と最大を取る。例えば $(1+i)$ を $P$ とすれば $\Z[i]$ で $(2)=P^2$ なので、$(2)+P=P$、$(2)\cap P=(2)$ である。

### 一つの素イデアルでの局所化

非零素イデアル $P$ に対して $v_P(x)$ を $(x)$ の $P$ 指数とし、$v_P(0)=+\infty$ とする。包含の判定を使うと $v_P(x+y)\ge\min(v_P(x),v_P(y))$ である。実際、$(x+y)$ は $(x)+(y)$ に含まれる。異なる指数の場合に等号が崩れると、同じ不等式を $x=(x+y)-y$ または $y=(x+y)-x$ に適用して矛盾する。積では指数が加わる。

:::proposition[局所化は離散付値環になる]{#prop-nt-dedekind-local-dvr}
$O_P=\{a/s\mid a\in O,\ s\in O\setminus P\}$ は $\{x\in K\mid v_P(x)\ge0\}$ に一致する。$\pi\in P\setminus P^2$ を取れば、任意の非零元は $\pi$ の非負整数冪と単元の積であり、非零イデアルは $(\pi^j)$ の形をしている。
:::

:::proof
$s\notin P$ なら $v_P(s)=0$ なので一方の包含が分かる。逆に $v_P(x)\ge0$ とする。分母を消すイデアル $D_x=\{a\in O\mid ax\in O\}$ は、各素イデアル $Q$ の指数が $\max(0,-v_Q(x))$ となる積である。これは各 $a$ に $v_Q(a)\ge0$ と $v_Q(a)+v_Q(x)\ge0$ を同時に課したものだからである。従って $D_x$ は $P$ に含まれず、$s\in D_x\setminus P$ を取ると $a=sx\in O$ となる。ゆえに $x=a/s$ である。

$P\ne P^2$ は $P$ の可逆性から従う。そこで $\pi\in P\setminus P^2$ を取ると $v_P(\pi)=1$ である。$x\in O_P\setminus\{0\}$ の $P$ 指数を $j$ とすれば $x/\pi^j$ とその逆元はともに指数零で $O_P$ に入る。したがって単元倍で $\pi^j$ と等しい。非零イデアルの中で指数が最小の元を取ると、その元が全ての他の元を割るので生成元になる。
:::

このような環を :term[離散付値環]{en="discrete valuation ring" yomi="りさんふちかん"} という。例えば $O=\Z[i]$ で $P=(1+i)$ とすると $v_P(2)=2$、$v_P(1+i)=1$、$v_P(3)=0$ である。局所化では $3$ の逆数を許す一方、$1/(1+i)$ は負の指数になるため許さない。元の分解が一意でない整数環でも、一つの素イデアルで局所化すれば指数だけで整除を判定できる。

### 指数で分数イデアルの整除条件を書く

分数イデアル $I,J$ について $(I:J)=\{x:xJ\subset I\}$ を考える。$J$ は可逆なので $xJ\subset I$ を $J^{-1}$ 倍すれば $(x)\subset IJ^{-1}$ となる。逆に最後の包含を $J$ 倍すればもとに戻る。従って $(I:J)=IJ^{-1}$ であり、指数は $I$ の指数から $J$ の指数を引いたものである。$x\in I$ の判定は $(x)\subset I$ だから、各指数が $I$ の指定以上になることと同値である。元での整除、イデアルでの包含、指数の比較という三つを行き来できる。

## イデアルのノルム

:::definition[イデアルのノルム]{#def-nt-ideal-norm}
非零整イデアル $I$ について $NI=\#(O/I)$ を :term[イデアルノルム]{en="ideal norm" yomi="いであるのるむ"} という。
:::

:::theorem[ノルムの乗法性]{#thm-nt-ideal-norm-product}
$N(IJ)=NI\,NJ$ である。非零 $\alpha\in O$ について $N((\alpha))=\abs{N_{K/\Q}(\alpha)}$ である。
:::

:::proof
素イデアル $P$ と $k\ge0$ について $\pi\in P\setminus P^2$ を取る。$\pi^k$ による乗法は $O/P\to P^k/P^{k+1}$ を定め、包含の指数判定から核は零である。また $(\pi^k)+P^{k+1}=P^k$ なので全射である。従って $NP^e=(NP)^e$ となる。異なる素イデアルの冪は和が $O$ である。二つのイデアル $I,J$ が和 $O$ を満たすとき、$u+v=1$（$u\in I,v\in J$）から剰余を組み合わせられる。核は $I\cap J=IJ$ なので、反復して素イデアル冪の直積へ分かれる。従って $NI=\prod_P(NP)^{v_P(I)}$ であり、乗法性が従う。

単項イデアルでは整数基底上の $\alpha$ による乗法の像が $(\alpha)$ である。像の指数は行列式の絶対値であり、行列式の定義から体ノルムになる。
:::

例えば $\Z[i]$ で $N(2+i)=5$ であり、実際 $i$ を $-2$ に送る法 $5$ の写像の核が $(2+i)$ になる。$P=(1+i)$ に対して $NP=2$、$NP^3=8$ である。分数イデアルへも素因数の指数を整数としてノルムを掛け、正の有理数値に延長できる。

### 整数格子の行列式でノルムを求める

基底 $1,\omega$ をもつ二次体で、整イデアルの格子基底が $a,b+c\omega$（$a,c>0$）なら、行列は $\begin{pmatrix}a&b\\0&c\end{pmatrix}$ で、指数は $ac$ である。実際任意の元の $\omega$ の係数をまず法 $c$ で還元し、次に定数成分を法 $a$ に還元でき、剰余は一意である。例えば $\Z[i]$ の $(2+i)$ の基底を $2+i,i(2+i)$ とすると行列は $\begin{pmatrix}2&-1\\1&2\end{pmatrix}$ であり、行列式 $5$ がノルムになる。

## 素イデアルの分解と Kummer–Dedekind の定理

自然な写像 $O\to O/P$ の整数部分の核は、非零素イデアル $(p)\subset\Z$ である。このとき $P$ は $p$ の上にあるという。$pO=\prod_i P_i^{e_i}$ と書けば、$P_i$ は $p$ の上にあるすべての素イデアルである。指数 $e_i$ を :term[分岐指数]{en="ramification index" yomi="ぶんきしすう"}、$f_i=[O/P_i:\F_p]$ を :term[剰余次数]{en="residue degree" yomi="じょうよじすう"} という。ノルムを取ると $p^{[K:\Q]}=\prod_i p^{e_i f_i}$、すなわち $\sum_i e_i f_i=[K:\Q]$ となる。

:::theorem[Kummer–Dedekind の定理]{#thm-nt-kummer-dedekind}
$K=\Q(\theta)$、$\theta\in O$、$f$ を最小多項式とする。$p\nmid[O:\Z[\theta]]$ とし、$\bar f=\prod_i \bar g_i^{m_i}$ を $\F_p[X]$ の相異なるモニック既約因子への分解とする。各 $g_i$ を同じ次数のモニックな整数係数の持ち上げとすると、$P_i=(p,g_i(\theta))$ は $p$ 上の相異なる素イデアルで、分岐指数が $m_i$、剰余次数が $\deg g_i$ である。
:::

:::proof
$A=\Z[\theta]$ とする。有限群 $O/A$ で $p$ 倍が可逆なので、$A/pA\to O/pO$ は同型である。全射は $O=A+pO$ から得られ、単射は $a=px\in A$ なら $x\bmod A$ が $p$ で零になるので $x\in A$ から得られる。ゆえに
$$
O/pO\simeq\F_p[X]/(\bar f)\simeq\prod_i\F_p[X]/(\bar g_i^{m_i}).
$$
各因子の唯一の極大イデアルは $\bar g_i$ が生成し、対応する剰余体が次数 $\deg g_i$ を与える。持ち上げた極大イデアルは $P_i$ である。また $pO=\prod_i P_i^{e_i}$ としたとき、中国式剰余定理で $O/P_i^{e_i}$ へ分かれる。どちらの直積でも $O\setminus P_i$ の元を可逆にすると、第 $i$ 成分はそのまま残る。実際、第 $i$ 成分で $1$、他の成分で $0$ となる冪等元は $O\setminus P_i$ から持ち上がり、これを可逆にすると他の成分が消える。従って対応する二成分は同型であり、濃度を比較すると $p^{e_i\deg g_i}=p^{m_i\deg g_i}$ なので $e_i=m_i$ である。
:::

例えば $\Z[i]$ で $p=5$ とすれば $X^2+1=(X-2)(X+2)\pmod5$ であり、$(5)=(5,i-2)(5,i+2)$ である。法 $3$ では既約なので $(3)$ が素で剰余体の位数は $9$ である。指数条件は重要である。$\theta=\sqrt5$ では $X^2-5=(X-1)^2\pmod2$ だが、整数基底の生成元 $\eta=(1+\sqrt5)/2$ では $X^2-X-1$ が法 $2$ で既約なので実際は分岐しない。

### 素イデアルへの元の還元

最小多項式の因子 $\bar g_i$ から得た $P_i$ に対し、元を $\theta$ の整数多項式 $A(\theta)$ と書ける場合、$A(\theta)\in P_i$ と $\bar g_i\mid\bar A$ は同値である。剰余体への写像は $\theta\mapsto X\bmod \bar g_i$ なので、因子の剰余を零と判定すればよい。この条件は指数が少なくとも $1$ であることを与える。冪 $P_i^j$ への所属を知るには付値やノルムをさらに使う。例えば $i-2$ は法 $5$ の根 $2$ に対応する素イデアルに入り、根 $-2$ に対応するものには入らない。元のノルムが $5$ なので指数は $1$ で止まる。

### 冪基底の指数を法 $p$ で判定する

:::proposition[Dedekind の指数判定]{#prop-nt-dedekind-index}
:ref[thm-nt-kummer-dedekind] と同じ記号を用い、$G=\prod_i g_i$、$H=\prod_i g_i^{m_i-1}$、$R=(f-GH)/p$ と置く。$p$ が $[O:\Z[\theta]]$ を割ることは、$m_i\ge2$ かつ $\bar g_i\mid\bar R$ となる $i$ があることと同値である。
:::

:::proof
$p$ と互いに素な整数を可逆にした環を $A=\Z_{(p)}[\theta]$、$B=O\otimes_\Z\Z_{(p)}$ と置く。有限加群 $B/A$ は $p$ の冪で消える。$J=(p,G(\theta))A$ は $A/pA$ の冪零元全体の逆像なので $J=\sqrt{pA}$ である。また $J=A\cap\sqrt{pB}$ である。実際、$u\in A$ のある冪が $pB$ に入れば、$p^rB\subset A$ となる $r$ を選び、さらに $r+1$ 乗して $pA$ に入れられる。

$A\ne B$ なら $B/A$ の非零元で $J$ によって消えるものがある。実際、$J$ のある冪は $pA$ に含まれるため、$J$ は $B/A$ 上で冪零に作用し、最後の非零な像から元を選べる。代表 $x\in B\setminus A$ は $xJ\subset A\cap\sqrt{pB}=J$ を満たす。逆に $x\in K\setminus A$ が $xJ\subset J$ を満たせば、有限生成加群 $J$ に対する :ref[lem-nt-integral-determinant] から $x$ は $A$ 上整であり、$x\in B$ となる。最後の包含は、整方程式の分母を $p$ と互いに素な共通分母で払えば、その整数倍が $O$ に入ることによる。従って $p$ が指数を割る条件は、このような $x$ の存在である。

$p\in J$ なので $px\in J$ であり、$A$ の元を引いて $x=G(\theta)b(\theta)/p$ とできる。$x\notin A$ は $\bar H\nmid\bar b$ と同値である。さらに $xG(\theta)\in J$ を満たすには、まず $G(\theta)^2b(\theta)\in pA$、すなわち $\bar H\mid\bar G\bar b$ が必要である。この条件の下で $Gb=Hd+pe$ と書くと、$f(\theta)=0$ より $xG(\theta)=G(\theta)e(\theta)-R(\theta)d(\theta)$ である。従って $xG(\theta)\in J$ の残りの条件は $\bar G\mid\bar R\bar d$ となる。

$\bar H\nmid\bar b$ なら、ある $i$ で $m_i\ge2$ かつ $\bar b$ における $\bar g_i$ の指数がちょうど $m_i-2$ である。これは $\bar H\mid\bar G\bar b$ と $\bar G$ の平方自由性による。この $i$ では $\bar d$ の指数は零なので $\bar g_i\mid\bar R$ が必要である。逆にそのような $i$ があれば $\bar b=\bar H/\bar g_i$ と選べる。このとき $\bar d=\bar G/\bar g_i$ なので $\bar G\mid\bar R\bar d$ が成り立ち、所望の $x$ を得る。
:::

例えば $f=X^3-10$ の法 $3$ では $G=X-1$、$H=(X-1)^2$ と取ると $R=X^2-X-3$ であり、$R(1)\equiv0\pmod3$ なので指数は $3$ で割れる。判別式 $\operatorname{disc}f=-2700$ の $3$ 指数は $3$ なので、基底の指数が $9$ で割れることはない。局所的な基底を得るには $w=(1+\theta+\theta^2)/3$ を加える。実際 $\theta w=w+3$、$w^2=w+\theta+2$ であり、$w^3-w^2-3w-3=0$ だから $w$ は整である。$1,\theta,w$ が張る格子は冪基底に対して指数 $3$ の拡大であり、法 $3$ の整数環の商を計算できる。法 $3$ では $\theta=w^2-w-2$ なので、$W\mapsto w$ により $\F_3[W]/(W^2(W-1))\simeq O/3O$ を得る。従って $(3)=(3,w)^2(3,w-1)$ であり、元の冪基底から重複度 $3$ を読み取ると誤る。

後の表で使う冪基底の指数も、この判定で確かめられる。$f=X^3-c$ の判別式は $-27c^2$ なので、指数を割る候補は $3$ と $c$ の素因数である。$p\mid c$ で $p^2\nmid c$ なら、$G=X$、$H=X^2$、$R=-c/p$ から指数に入らない。$p=3$ では $G=X+1$ を $c=2,5,17$ に使い、$G=X-1$ を $c=10$ に使う。重根での $R$ の値はそれぞれ $-1,-2,-6,-3$ なので、$3$ が指数を割るのは $c=17,10$ の場合である。この二つでは判別式の $3$ 指数が $3$ なので、冪基底の指数はちょうど $3$ である。$X^3-X-1$ では判別式 $-23$ が平方自由なので指数は $1$ である。$X^4-2$ では判別式 $-2048$ から候補は $2$ だけであり、$G=X$、$H=X^3$ に対し $R=-1$ なので指数は $1$ となる。

### Galois 拡大での分解群と惰性群

:::proposition[Galois 拡大での素イデアルの共役]{#prop-nt-galois-prime-decomposition}
$K/\Q$ を有限 Galois 拡大とし、$pO$ の素因子の個数を $g$ とする。$p$ 上の素イデアルは互いに共役であり、共通の分岐指数を $e$、剰余次数を $f$ とすると $efg=[K:\Q]$ である。$P$ を一つ選ぶと、その固定部分群 $D_P=\{\sigma:\sigma P=P\}$ から $\operatorname{Gal}(O/P\,/\,\F_p)$ への還元は全射で、その核 $I_P$ の位数は $e$ である。
:::

:::proof
ある $P$ の軌道に属さない $Q$ があるとする。中国式剰余定理により、軌道内の各素イデアルで $0$、$Q$ の軌道内の各素イデアルで $1$ に合同な $\alpha\in O$ を取る。$N_{K/\Q}(\alpha)=\prod_\sigma\sigma(\alpha)$ は $P$ に入るので $p$ で割れるが、$Q$ では $1$ に合同なので矛盾する。従って作用は推移的である。共役はイデアルの積と剰余体を保つから $e,f$ は一定であり、$\sum_i e_i f_i=[K:\Q]$ を使えば $efg=[K:\Q]$ となる。軌道と固定部分群の公式により $\#D_P=ef$ である。

$O/P$ を $\F_p$ 上生成する非零元を $u$ とする。$u$ に還元され、他の $p$ 上の素イデアルでは $0$ に還元される $\alpha\in O$ を取る。$\prod_\sigma(X-\sigma(\alpha))$ は $\Z[X]$ に属し、法 $P$ で $u$ を根にもつ。従って $\F_p$ 上の $u$ の全共役もこの還元した多項式の根である。これらは非零であり、$\sigma\notin D_P$ なら $\sigma(\alpha)\equiv0\pmod P$ だから、いずれの共役も $D_P$ の元から得られる。$u$ が剰余体を生成するので還元写像は全射である。剰余体の Galois 群の位数は $f$ だから、核の位数は $e$ となる。
:::

$D_P$ を :term[分解群]{en="decomposition group" yomi="ぶんかいぐん"}、$I_P$ を :term[惰性群]{en="inertia group" yomi="だせいぐん"} という。$e=1$ のとき剰余体上の $x\mapsto x^p$ は $D_P$ に一意に持ち上がり、その元を :term[Frobenius 元]{en="Frobenius element" yomi="ふろべにうすげん"} という。例えば $\Q(i)$ の $p=3$ では $i^3=-i$ なので Frobenius 元は複素共役である。一方、$p=5$ は二つの一次の素イデアルに分かれ、各分解群は自明である。

### 中間体を挟んだときの指数

$\Q\subset K\subset L$ を代数体の塔とし、$Q$ を $L$ の整数環の素イデアル、$P$ を $K$ の整数環への縮約とする。$P$ の拡大イデアルにおける $Q$ の指数を $e(Q/P)$、剰余体の拡大次数を $f(Q/P)$ とする。$K$ での $pO_K$ の分解を $O_L$ に拡大し、$Q$ の指数を読むと $e(Q/p)=e(Q/P)e(P/p)$ である。実際、$Q$ を含む拡大イデアルに対応する $K$ 側の因子は、その縮約 $P$ だけである。また有限体の次数の塔公式により $f(Q/p)=f(Q/P)f(P/p)$ である。したがって相対的な分岐を調べるとき、有理素数の上で得た指数は中間体での分だけ割って読む。

## 分岐と判別式

:::theorem[分岐の判別式判定]{#thm-nt-ramification-discriminant}
$p$ の上に $e_i>1$ の素イデアルがあることと $p\mid d_K$ は同値である。
:::

:::proof
整数基底で計算したトレース対の行列を法 $p$ へ落とすと、有限 $\F_p$ 代数 $O/pO$ における乗法写像のトレース形式となる。$e_i>1$ があれば、$P_i/P_i^{e_i}$ の非零元を一成分に置いて、全代数の非零冪零元 $x$ を得る。任意の $y$ に対し $xy$ も冪零であり、その乗法写像は冪零だからトレースが $0$ になる。従って対は退化する。

逆に全 $e_i=1$ なら CRT で有限体の直積である。有限体の拡大は分離的なので、各体のトレース対は :ref[thm-gal-trace-nondegenerate] により非退化である。直積の対はこれらの直交和なので非退化であり、判別式は法 $p$ で非零である。
:::

例えば $K=\Q(\sqrt{-5})$ で $d_K=-20$ なので、分岐するのは $2,5$ に限る。法 $2$ では $X^2+5=(X+1)^2$、法 $5$ では $X^2+5=X^2$ であり、実際どちらも素イデアルの平方になる。分岐は素数が二つの異なる素イデアルに分かれることとは異なり、同じ因子に指数が付く現象である。

### 体の判別式と冪基底の判別式を区別する

$f$ が最小多項式なら $\operatorname{disc} f=[O:\Z[\theta]]^2 d_K$ である。$p$ が $\operatorname{disc} f$ を割らないなら指数も $d_K$ も割らず、分岐しない。$p$ が $\operatorname{disc} f$ を割るときは、その因子が指数に由来するのか、$d_K$ に由来するのかを区別する。例えば $\Q(\sqrt{17})$ で $X^2-17$ の判別式は $68$ だが、体の判別式は $17$ なので $2$ は分岐しない。整数基底の生成元では $X^2-X-4$ であり、法 $2$ で $X(X-1)$ に分かれる。

## 二次体における素数の分解法則

:::corollary[二次体の分解則]{#cor-nt-quadratic-splitting}
二次体の判別式を $D$ とする。奇素数 $p$ では、$\left(\frac Dp\right)=0,1,-1$ の場合にそれぞれ分岐、分裂、惰性となる。$p=2$ では $D$ が偶数なら分岐し、$D\equiv1\pmod8$ なら分裂、$D\equiv5\pmod8$ なら惰性となる。
:::

:::proof
:ref[thm-nt-quadratic-integers] の生成元の最小多項式の判別式が $D$ である。奇素数なら平方完成によって根の有無と重複が $D$ の平方性で決まる。二次多項式が重根を一つ、単根を二つ、根なしと変わる三場合に Kummer–Dedekind の定理を適用する。$p=2$ で $D$ が偶数なら :ref[thm-nt-ramification-discriminant] を用いる。$D$ が奇数なら最小多項式は $X^2-X+(1-D)/4$ で、法 $2$ で定数項が $0$ なら二根、$1$ なら既約となる。
:::

二次体での :term[分裂]{en="splitting" yomi="ぶんれつ"} は、別々の次数一の素イデアルに $(p)=P_1P_2$ と分かれることをいう。これに対して :term[惰性]{en="inertness" yomi="だせい"} は、$(p)$ が素のまま剰余次数二になる場合である。例えば $D=17$ では $2$ が分裂する。$D=5$ の $11$ は $5\equiv4^2\pmod{11}$ なので分裂し、$3$ では $5\equiv2$ なので惰性である。

### 元の分解に失敗する例をイデアルで解く

$\theta=\sqrt{-5}$ とする。$P=(2,1+\theta)$、$Q_+=(3,\theta-1)$、$Q_-=(3,\theta+1)$ と置く。法 $2$ では重根、法 $3$ では $\pm1$ の二根なので、$(2)=P^2$、$(3)=Q_+Q_-$ である。$1+\theta$ は $P,Q_-$ に入り $Q_+$ には入らない。元のノルムは $6$、入り方から $PQ_-$ のノルムも $6$ なので、$(1+\theta)=PQ_-$ となる。同様に $(1-\theta)=PQ_+$ である。したがって
$$
(6)=P^2 Q_+Q_-
$$
であり、元の二つの分解は三種類の素イデアルを異なる組合せでまとめていたと分かる。この説明では $P,Q_\pm$ が単項である必要はない。

### 共役による分裂因子の交換

二次体で $\omega$ の最小多項式の根が法 $p$ で $r,s$ に分かれるとする。共役は $\omega\mapsto \operatorname{Tr}(\omega)-\omega$ であり、根の和は $\operatorname{Tr}(\omega)$ の剰余なので、$r$ と $s$ を交換する。従って $(p,\omega-r)$ の共役は $(p,\omega-s)$ である。分岐時には同じ根しかないので素イデアルは固定され、惰性時にも唯一の素イデアルは固定される。例えば $\Q(\sqrt5)$ で $p=11$ の根は $4,8$ であり、$1-4\equiv8\pmod{11}$ と交換する。

## 円分体における素数の分解法則

:::theorem[円分体の分解則]{#thm-nt-cyclotomic-splitting}
$m=p^a h$、$p\nmid h$ とする。$K=\Q(\zeta_m)$ において、$p$ 上の各素イデアルの分岐指数は $\varphi(p^a)$、剰余次数は $\operatorname{ord}_h(p)$、個数は $\varphi(h)/\operatorname{ord}_h(p)$ である。$h=1$ では位数を $1$ と約束する。
:::

:::proof
$p\nmid h$ なので $\Phi_h\bmod p$ の根は標数 $p$ における位数 $h$ の元であり、相異なる。実際、$X^h-1=\prod_{d\mid h}\Phi_d$ は平方自由で、各 $d$ の因子の根を小さい $d$ から分ければ位数で分類できる。Frobenius 写像 $x\mapsto x^p$ の軌道の長さは、$h\mid p^f-1$ となる最小の $f$ である。:ref[thm-gal-finite-frobenius] により軌道が既約因子を与えるので、各因子の次数はその長さである。

$a>0$ のとき $\Phi_{hp^a}(X)=\Phi_h(X^{p^a})/\Phi_h(X^{p^{a-1}})$ である。分子の根の位数は $hp^j$（$0\le j\le a$）であり、分母が $j<a$ の根を除くためである。法 $p$ では分子、分母がそれぞれ $\bar\Phi_h^{p^a},\bar\Phi_h^{p^{a-1}}$ となり、よって $\bar\Phi_m=\bar\Phi_h^{\varphi(p^a)}$ である。$a=0$ でも同じ式で指数 $1$ となる。:ref[thm-nt-cyclotomic-integers] から指数条件は自動であり、Kummer–Dedekind の定理で結論を得る。
:::

例えば $\Q(\zeta_7)$ では $2$ の法 $7$ の位数は $3$ なので、次数三の二素イデアルに分裂する。$7$ では $h=1$ なので $e=6,f=1$ となり全分岐する。また $\Q(\zeta_{12})$ では $p=3$ に対し $h=4$、位数 $2$ なので $e=2,f=2$ の素イデアルが一つである。一般に $p=2$ に対して $a=1$ のとき $\varphi(2)=1$ であり、導手を余分な $2$ 倍で記述しただけでは分岐しない。

### 余りの位数が次数に現れる理由

$p\nmid m$ のとき、根 $\xi$ の位数は $m$ で、Frobenius の第 $r$ 回目は $\xi^{p^r}$ である。これが $\xi$ に戻る条件は $m\mid p^r-1$ であり、根の選び方によらない。従ってすべての軌道が等しい長さをもつ。例えば $m=8$ の $p=3,5,7$ はどれも位数二なので、四つの原始根が二軌道に分かれる。$p=17$ ならすべての原始八乗根が基礎体内にあり、四つの素イデアルに完全分裂する。

## 演習問題

::::exercise{level=basic}
$\Z[i]$ で $(2)$ の素イデアル分解を求めよ。
:::solution
$P=(1+i)$ とすれば $O/P\simeq\F_2$ なので素である。$(1+i)^2=2i$ で $i$ は単元だから $(2)=P^2$ である。
:::
::::

::::exercise{level=basic}
$\Z[i]$ における $N((3+2i))$ を求めよ。
:::solution
単項イデアルのノルムは体ノルムの絶対値なので $(3+2i)(3-2i)=13$ である。
:::
::::

::::exercise{level=basic}
$\Q(\sqrt5)$ で $2$ の分解型を求めよ。
:::solution
判別式 $5$ は $5\bmod8$ なので惰性である。実際 $X^2-X-1$ は法 $2$ の二つの値でともに $1$ となり、既約である。従って $e=1,f=2$ となる。
:::
::::

::::exercise{level=basic}
$\Q(\sqrt{-7})$ で $2$ の分解型を求めよ。
:::solution
判別式 $-7\equiv1\pmod8$ なので分裂する。生成元 $\eta=(1+\sqrt{-7})/2$ の最小多項式は $X^2-X+2$ で、法 $2$ で $X(X-1)$ になる。従って $(2)=(2,\eta)(2,\eta-1)$ である。
:::
::::

::::exercise{level=advanced}
$\Q(\zeta_5)$ で $2$ 上の素イデアル数と剰余次数を求めよ。
:::solution
法 $5$ で $2^2\equiv-1$、$2^4\equiv1$ なので位数は $4$ である。従って $f=4$、$e=1$、個数は $\varphi(5)/4=1$ である。
:::
::::

::::exercise{level=advanced}
$\Q(\zeta_{15})$ の $3$ 上の $e,f$ と素イデアル数を求めよ。
:::solution
$m=3\cdot5$ で $\varphi(3)=2$、法 $5$ で $3^2\equiv-1$ なので位数は $4$ である。よって $e=2,f=4$ で個数は一つである。積 $ef=8$ は体の次数に一致する。
:::
::::

::::exercise{level=advanced}
$P,Q$ を異なる非零素イデアルとする。$P^3Q+PQ^4$ と $P^3Q\cap PQ^4$ を求めよ。
:::solution
和は各指数の最小を取るので $PQ$、共通部分は最大を取るので $P^3Q^4$ である。指数判定から前者は二イデアルを含む最小のもの、後者は二イデアルに含まれる最大のものになる。
:::
::::

::::exercise{level=advanced}
$\Z[\sqrt{-5}]$ で $(2,1+\sqrt{-5})$ が単項でないことを示せ。
:::solution
$\sqrt{-5}$ を $1$ に送る法 $2$ の写像で核がこのイデアルなのでノルムは $2$ である。単項なら生成元 $a+b\sqrt{-5}$ が $a^2+5b^2=2$ を満たす必要がある。$b\ne0$ なら左辺は $5$ 以上であり、$b=0$ でも整数平方は $2$ にならない。
:::
::::

::::exercise{level=advanced}
$\Q(\zeta_{20})$ で $2,5,11$ の分岐指数、剰余次数、素イデアル数をそれぞれ求めよ。
:::solution
$p=2$ では $20=2^2\cdot5$ で、$2\bmod5$ の位数は $4$ である。従って $(e,f,g)=(2,4,1)$ となる。$p=5$ では $h=4$ で $5\equiv1\pmod4$ なので $(4,1,2)$ である。$p=11$ では $h=20$、$11^2\equiv1\pmod{20}$ かつ $11\not\equiv1$ なので $(1,2,4)$ となる。どの場合も $efg=8$ で次数と一致する。
:::

::::quiz

- [x] $p$ 上の少なくとも一つの分岐指数が $2$ 以上
- [ ] $p$ 上の剰余次数が常に $1$
- [ ] $p$ が必ず二つの異なる素イデアルに分かれる

:::explanation

:::

::::quiz{answer="9" tol="1e-6"}
$\Z[i]$ でイデアル $(3)$ のノルムを求めよ。
:::explanation
$3$ の共役は $3$ なので体ノルムは $9$ である。商を見ても $X^2+1$ が法 $3$ で既約なので、二次の剰余体の位数は $3^2=9$ である。
:::

::::quiz{answer="3" tol="1e-6"}
$\Q(\zeta_7)$ の $2$ 上の素イデアルの剰余次数を求めよ。

:::

::::quiz
$\Q(\sqrt5)$ で $\theta=\sqrt5$ を用いると、法 $2$ の多項式分解が直接使えない理由を選べ。

- [ ] $\theta$ が整元でない
- [ ] $2$ が体の次数を超える

:::explanation
$11^2\equiv1\pmod{20}$ だが $11\not\equiv1\pmod{20}$ なので、剰余次数は $2$ である。分岐指数は $1$、拡大次数は $\varphi(20)=8$ なので素イデアル数は $4$ である。
:::
