## この章の目標

- 二通りの完備性を区別する。
- Hopf–Rinow の定理と最短弧の存在を証明する。
- 局所等長写像から被覆を構成する。
- Cartan–Hadamard と Preissmann の定理を証明する。

## 測地的完備性と距離完備性

連結 Riemann 多様体上で、有限の距離だけ進んで到達する極限と、測地線が有限時間で止まるかどうかを比較する。

:::definition[二つの完備性]{#def-rg-complete}
すべての測地線の最大定義域が $\R$ であるとき :term[測地的完備]{en="geodesically complete" yomi="そくちてきかんび"} という。距離 $d_g$ の任意の Cauchy 列が収束するとき :term[距離完備]{en="metrically complete" yomi="きょりかんび"} という。
:::

距離完備なら有限時刻 $b$ に近づく定速測地線は Cauchy なのである $p$ に収束する。$p$ の比較的コンパクトな座標域では、計量と Euclid ノルムが一様に比較できるため速度の成分は有界である。:eqref[eq-rg-geodesic-flow] により加速度の成分も有界になる。従って速度は $b$ で極限を持つ。この極限と $p$ を初期値にして解を伸ばせる。負の時刻にも同じ議論が使える。

:::example[開区間の二つの計量]
$(0,1)$ の $dx^2$ では $x=1/2+t$ が時刻 $1/2$ で終わる。一方 $g=dx^2/(x^2(1-x)^2)$ なら $u=\log(x/(1-x))$ は $du=dx/(x(1-x))$ を満たし、像は $\R$ 全体なので完備な Euclid 直線と等長である。
:::

コンパクト多様体は :ref[thm-rg-distance-topology] により距離空間としてコンパクトなので完備である。例えば半径 $2$ の円ではどの測地線も角を定速度で動かせば全時刻に定義できる。

:::example[境界点の距離が無限になる場合]
上半平面の $g=(dx^2+dy^2)/y^2$ では $\norm{\dot\gamma}\ge|(\log y)'|$ である。Cauchy 列の高さは従って $0<a\le y\le b$ に留まる。列の遅い二点を長さ $1$ 未満の弧で結ぶと、その弧の高さも $y\le eb$ に留まり、Euclid の距離は $eb$ 倍の弧長以下である。ゆえに Euclid でも Cauchy で、正の高さに収束する。多様体の位相と距離位相の一致から完備である。
:::

### 有限長で逃げる曲線による判定

:ref[thm-rg-distance-topology] の距離を持つ連結多様体で、曲線がどのコンパクト集合からも最後には出ることを「コンパクト集合から逃げる」と呼ぶ。距離完備性は、そのような区分的滑らかな曲線が有限長を持たないことと同値である。まず有限長なら、終端に近い二点間の距離は曲線長の尾部以下である。完備ならこの点列は収束し、曲線全体も距離で同じ点に近づく。その点の比較的コンパクトな近傍に最後は入るので逃げない。

逆に収束しない Cauchy 列を取り、部分列 $p_j$ が $d(p_j,p_{j+1})<2^{-j-1}$ を満たすように選ぶ。長さ $2^{-j}$ 未満の区分的滑らかな弧で隣同士を結び、例えば時刻 $j$ から $j+1$ に割り当てる。この曲線の全長は $\sum_j2^{-j}<\infty$ である。あるコンパクト集合に任意に遅い時刻で入るなら、入った点の収束部分列を選べる。各点は対応する $p_j$ から距離 $2^{-j}$ 未満なので、$p_j$ もその極限を持つ。Cauchy 列が収束部分列を持つなら全体が収束するため矛盾する。

:::example[端での積分判定]
$(0,\infty)$ に $g=x^{-2a}dx^2$ を入れる。弧長座標を $s(x)=\int_1^x t^{-a}\,dt$ と取ると、$a=1$ では $s=\log x$ で像は $\R$ である。$a\ne1$ では $s=(x^{1-a}-1)/(1-a)$ で、$a<1$ なら $x\downarrow0$、$a>1$ なら $x\uparrow\infty$ で有限の端に達する。例えば $a=2$ で $x=1$ から無限遠まで距離は $1$ に近づく。点が座標の無限遠にあるという事実だけでは、距離が無限かどうかは決まらない。
:::

### 計量を比較して完備性を移す

同じ多様体上で $\widetilde g\ge c^2g$（定数 $c>0$）なら $\widetilde g$ の曲線長は $cL_g$ 以上である。従って $\widetilde g$ の Cauchy 列は $g$ の Cauchy 列でもある。$g$ が完備なら $g$ 距離で収束し、両計量の距離位相が同じことから $\widetilde g$ 距離でも収束する。上界 $\widetilde g\le C^2g$ はこの向きの主張には不要である。逆向きに完備性を移したい場合は、逆の下界が必要になる。

:::example[完備な底を持つ歪積]
$M=B\times F$ に $g=g_B+f(b)^2g_F$ を入れる。両因子が距離完備で $f:B\to(0,\infty)$ が滑らかとする。Cauchy 列 $(b_j,z_j)$ では $B$ への射影が距離を増やさないので $b_j\to b$ である。$b$ の小さな閉距離球を比較的コンパクトな近傍に取り、その上で $f\ge a>0$ とする。十分遅い二点を結ぶ短い曲線の射影は、この球から出ない。球を出るには始点から半径のほぼ全体を進む必要があるからである。その曲線の $F$ 投影の長さは元の長さの $1/a$ 倍以下なので、$z_j$ も Cauchy となる。従って積で収束する。例えば $g=ds^2+e^{-2s}d\theta^2$ の円柱は、円周が $s\uparrow\infty$ で零に近づいても完備である。
:::

### 完備な共形計量を作る

任意の連結多様体の Riemann 計量 $g$ は、適切に共形拡大すると完備にできる。まずコンパクト集合の列 $K_j\subset\operatorname{int}K_{j+1}$ で多様体を尽くす。これは可算個の相対コンパクト座標球から順に有限個を取り、既に選んだ閉包を次の段階の内部に含めて作れる。$0\le\chi_j\le1$ を $K_j$ の近傍で $1$、$K_{j+1}$ の内部に台を持つ滑らかな関数とすると、
$$
f=\sum_{j\ge1}(1-\chi_j)
$$
は滑らかである。各コンパクト集合の近くで、ある番号以降の項は全て零だからである。また $K_{m+1}$ の外では先頭の $m$ 項が $1$ なので $f\ge m$ である。従って $f$ の有界な閉部分レベル集合はコンパクトである。

$\widetilde g=(1+\norm{\grad_g f}_g^2)g$ とおくと、余接ノルムの変換から $\norm{df}_{\widetilde g^{-1}}\le1$ である。従って $f$ は $d_{\widetilde g}$ に対して $1$-Lipschitz であり、Cauchy 列の $f$ の値は有界である。その列はコンパクトな部分レベル集合内で収束部分列を持ち、距離位相の一致から列全体が収束する。例えば開単位球で $f=-\log(1-|x|^2)$ を使うと、境界で $f$ が無限に増すため、どの境界への曲線も新しい計量では無限長となる。

## Hopf–Rinow の定理

:::theorem[Hopf–Rinow]{#thm-rg-hopf-rinow}
連結 Riemann 多様体 $M$ について、距離完備、測地的完備、ある点 $p$ の指数写像が $T_pM$ 全域に定義されること、閉有界集合がすべてコンパクトであることは同値である。このとき任意の二点間に最短測地線が存在する。
:::

:::proof
距離完備なら測地的完備であり、測地的完備なら指数写像の条件がすべての点で成り立つ。ある $p$ で指数写像の条件を仮定する。その $p$ から任意の $q$ への最短弧を次節で構成する。構成後は $\overline B(p,r)$ が $\exp_p$ による閉接球の像になる。一方の包含は動径弧の長さから、逆の包含は最短弧から従う。よって閉距離球はコンパクトで、任意の閉有界集合はその閉部分集合である。最後に Cauchy 列は有界だからコンパクトな閉球で収束部分列を持ち、三角不等式で列全体が同じ極限に収束する。こうして同値性が得られ、最短弧の構成に用いる $p$ を任意に選べる。
:::

:::example[有界性と完備性]
Euclid 空間は完備で直径が無限である。開円板は直径が有限であるが、境界へ向かう放射状の Cauchy 列が内部では収束しない。閉有界集合のコンパクト性は多様体の誘導位相での閉性を要求する。
:::

:::example[閉球の像を明示する]
平坦な $\R/(6\Z)$ で $p=[0]$ の閉半径 $2$ 球は $[-2,2]$ の射影であり、閉半径 $4$ 球は $[-4,4]$ の射影で円全体を覆う。閉接球の指数写像像であるという Hopf–Rinow の証明は、半径が単射の範囲を越えても成り立つ。
:::

### 局所コンパクト性と閉球の膨張

完備性から閉球のコンパクト性を得る部分は、指数写像を使わず長さの性質からも示せる。長さ距離空間 $X$ が完備かつ局所コンパクトであるとする。任意の $p$ で、ある正半径の閉球はコンパクト近傍の閉部分集合になる。$C=\overline B(p,r)$ がコンパクトなら、各 $x\in C$ についてコンパクトな $\overline B(x,3\epsilon_x)$ を選び、小球 $B(x,\epsilon_x)$ の有限被覆を取る。その有限個の $\epsilon_x$ の最小値を $\epsilon$ とする。$d(p,y)\le r+\epsilon/2$ の点で $d(p,y)>r$ なら、長さ $r+\epsilon$ 未満の $p$ から $y$ への曲線を弧長 $r$ で切る。その点は $C$ に属し、$y$ からの距離は $\epsilon$ 未満である。よって $y$ は有限個の $\overline B(x,3\epsilon_x)$ の一つに入る。従って $\overline B(p,r+\epsilon/2)$ はコンパクトである。

もしコンパクトな半径の上限が有限の $R>0$ なら $\overline B(p,R)$ は全有界である。実際、任意の $\delta>0$ で $R-\delta<r<R$ のコンパクト球を取り、先と同じように長さがほぼ $R$ の曲線を切れば $\overline B(p,R)$ はその球の $2\delta$ 近傍に入る。コンパクト球を有限個の半径 $\delta$ の球で覆えば、半径 $3\delta$ の有限被覆が得られる。閉球は完備でもあるので、全有界性からコンパクトになる。これを最初の拡大に入れると $R$ の定義に反する。従って全ての閉球がコンパクトである。ここで用いた長さ距離とは、二点間の距離が曲線長の下限と一致することをいう。近い点の間にそのような曲線が存在することが、閉球を膨張させる段階に入っている。

:::example[完備でも局所コンパクトでない距離]
無限次元 Hilbert 空間 $\ell^2$ の正規直交列 $e_j$ は閉単位球に含まれ、任意の異なる二項に対し距離 $\sqrt2$ を持つ。従って収束部分列がなく、閉単位球はコンパクトでない。線分が距離を達成する完備な長さ空間でも、局所コンパクト性を用いないと閉有界集合についての結論は成り立たない。
:::

## 最短測地線の存在

$L=d_g(p,q)>0$ とし、$0<\epsilon<L$ の小さい正規球を $p$ で取る。その球面 $S_\epsilon$ は閉接球面の像なのでコンパクトである。$q$ に至る長さが $L$ に近い曲線は必ず球面を横切る。横切るまでの長さが $\epsilon$ 以上なので $d_g(x,q)$ の $S_\epsilon$ 上の最小値は $L-\epsilon$ 以下である。逆向きは三角不等式で従う。従って $x=\gamma(\epsilon)$ を満たす単位方向を選べば $d_g(\gamma(\epsilon),q)=L-\epsilon$ である。

:::lemma[動径に沿う等号の延長]{#lem-rg-hopf-extension}
$\gamma$ を $p$ から出る単位速測地線とする。$0<t<L$ で $d_g(\gamma(t),q)=L-t$ なら、十分小さな $h>0$ について $d_g(\gamma(t+h),q)=L-t-h$ となる。
:::

:::proof
小球面の議論を $\gamma(t)$ に適用すると、そこから距離 $h$ の点 $y$ が $d_g(y,q)=L-t-h$ を満たす。$\gamma|_{[0,t]}$ と $y$ への動径弧は合わせて長さ $t+h$ である。三角不等式から $d_g(p,y)\ge L-d_g(y,q)=t+h$ なので、この連結曲線は最短である。:ref[thm-rg-whitehead] の近傍内で継ぎ目を含む短い部分弧を取ると、その部分は一意の定速最短弧である。従って継ぎ目の速度は一致し、測地線の一意性から $y=\gamma(t+h)$ となる。
:::

$\exp_p$ が全域で定義されるなら $\gamma$ は $[0,L]$ に存在する。等式を満たす時刻の集合は閉じており $\epsilon$ を含む。最大時刻が $L$ 未満なら補題により延長できるため矛盾する。従って $\gamma(L)=q$ である。$p=q$ なら定数曲線を取る。

:::example[最短弧が二つある場合]
半径 $2$ の円では対蹠点を結ぶ最短長は $2\pi$ で、両向きの半円が実現する。完備性で得るのは最短弧の存在であり、一意性には追加の条件が要る。
:::

:::example[途中の球面から方向を選ぶ]
Euclid 平面で $p=(0,0)$、$q=(3,4)$ とし $\epsilon=1$ とする。単位円上の $x=(a,b)$ について $|q-x|^2=26-2(3a+4b)$ である。$3a+4b$ の最大は $5$ で、$x=(3/5,4/5)$ で達成される。よって残距離は $4$ である。この最初の方向を保つと時刻 $5$ で $q$ に達する。
:::

### 直接法で得た最短曲線の正則性

完備な $M$ で $p,q$ を固定し、長さが $d(p,q)$ に収束する定速曲線列を $[0,1]$ 上で取る。速さは一様有界で、像は $p$ の共通のコンパクト閉球にある。従って Arzelà–Ascoli で一様収束する部分列を取り、極限を $\alpha$ とする。距離の分割和で定める曲線長は、一様収束で下半連続である。実際、固定した分割での和は連続で、どの和も極限の下極限以下であるから、上限を取って同じ不等式が残る。従って $L(\alpha)\le d(p,q)$ となる。逆は両端だけの分割で得る。

さらに $\alpha$ の Lipschitz 定数は $d=d(p,q)$ 以下である。任意の $0\le s<t\le1$ について
$$
d\le d(p,\alpha(s))+d(\alpha(s),\alpha(t))+d(\alpha(t),q)
\le ds+d(t-s)+d(1-t)=d
$$
なので、中央の距離は $d(t-s)$ になる。近い端点の間では強凸球における一意な定速動径と比較できる。実際、途中の点でも三角不等式で等号なので、二本の短い最短弧を継ぐと全体の最短弧になる。継ぎ目の折れ角は許されないため、途中の点は一つの動径上にあり、時刻に比例する位置である。従って $\alpha$ は局所的に滑らかな測地線である。この証明では曲線列の微分が収束するという仮定を用いていない。

:::example[最短弧の集合がコンパクトになる]
半径 $a$ の球面で $p$ と対蹠点 $q$ を固定する。最短弧は $t\mapsto\cos(\pi t)p+a\sin(\pi t)u$ で、$u$ は $T_pS^n(a)$ の単位方向を走る。すなわち初期方向の集合はコンパクトな $S^{n-1}$ である。一般にも完備な $M$ の $p,q$ について、最短初期ベクトルの集合は $\{v:\norm v=d(p,q),\ \exp_pv=q\}$ という閉球面の閉部分集合である。最短弧の列に収束部分列があることは、初期値に関する ODE の連続性からも従う。
:::

:::example[同じ垂直線上の二点を結ぶ最短弧の大域性]
曲率 $-1$ の上半平面で $p=\left( 0, \  1\right)$、$q=\left( 0, \  4\right)$ とする。同じ $x$ 座標なので測地線は垂直である。双曲面の計算が $\log y$ の弧長座標と一致するかを確認する。双曲面の Lorentz 内積を $B(V,W)=-V_0W_0+V_1W_1+V_2W_2$ とする。上半平面からの等長写像 :ref[prop-rg-half-space-isometry] を代入すると
$$
\begin{aligned}
P&=\begin{pmatrix}1\\0\\0\end{pmatrix}\\
Q&=\begin{pmatrix}\frac{17}{8}\\0\\\frac{15}{8}\end{pmatrix}\\
C=-B(P,Q)&=\frac{17}{8}
\end{aligned}
$$
になる。両点は $B(P,P)=B(Q,Q)=-1$ を満たし、第 0 成分が正なので同じ双曲面上にある。

$Q-CP$ は $B(P,Q-CP)=-C+C=0$ なので接ベクトルである。その二乗長は
$$
B(Q-CP,Q-CP)=-1+2C^2-C^2=C^2-1=\frac{225}{64}
$$
である。従って単位初期方向は $U=(Q-CP)/\sqrt{C^2-1}$ であり、この例では $\begin{pmatrix}0\\0\\1\end{pmatrix}$ となる。曲線
$$
\gamma(t)=\cosh t\,P+\sinh t\,U
$$
は $B(\gamma,\gamma)=-1$、$B(\dot\gamma,\dot\gamma)=1$ を満たす。さらに $\ddot\gamma=\gamma$ は周囲での法方向だから、接加速度は零である。$d=\log(C+\sqrt{C^2-1})$ とすると $C-\sqrt{C^2-1}=(C+\sqrt{C^2-1})^{-1}$ により $\cosh d=C$、$\sinh d=\sqrt{C^2-1}$ であり、$\gamma(d)=Q$ を得る。

この曲線は全体の最短弧である。実際、Lorentz 基底 $(P,U,\text{残りの単位接方向})$ を標準 Lorentz 基底に移すと、$P$ は頂点、$Q$ は動径距離 $d$ の点になる。極座標の速度は動径速度の絶対値以上であるから、どの経路も長さ $d$ 以上である。動径で等号が成立し、この例では $d=\log{\left(4 \right)}$ である。従って指定した初期ベクトルを指数写像に入れるなら $dU$、弧長 $t$ の初速度を指定するなら $U$ を用いる。

中点の計算には $P+Q=(1+\cosh d)P+\sinh d\,U$ を用いる。半角公式で右辺は $2\cosh(d/2)(\cosh(d/2)P+\sinh(d/2)U)$ になる。従って Lorentz 二乗長を $-1$ に正規化した
$$
M=\frac{P+Q}{\sqrt{2+2C}}=\begin{pmatrix}\frac{5}{4}\\0\\\frac{3}{4}\end{pmatrix}
$$
が中点である。上半平面へ戻す式 $y=1/(M_0-M_2)$、$x=M_1/(M_0-M_2)$ から中点は $\left( 0, \  2\right)$ となる。上半平面では垂直線 $x=0$ が軌跡である。弧長座標 $\log y$ での中点に対応するので、高さは二つの高さの幾何平均である。

同じ表示で一般の比率 $\lambda\in[0,1]$ の点は
$$
\gamma(\lambda d)
=\frac{\sinh((1-\lambda)d)}{\sinh d}P+
\frac{\sinh(\lambda d)}{\sinh d}Q
$$
である。$U=(Q-\cosh d\,P)/\sinh d$ を代入し、$\cosh(\lambda d)\sinh d-\sinh(\lambda d)\cosh d=\sinh((1-\lambda)d)$ を使った。二つの係数は通常の線形補間の $1-\lambda,\lambda$ とは異なる。これは $\gamma$ を双曲面上に保ちつつ弧長を比例させるためである。

任意の曲線をこの上半平面に戻しても距離位相の変化はなく、最短弧の一意性は Cartan–Hadamard の結論とも一致する。例えば半径 $r=d$ の閉球の指数写像表示では、接球面の方向 $U$ がちょうど $Q$ に対応する。閉球全体はコンパクトな閉接球の像である。座標上の無限遠に向かう列であっても、その列がここでの有限半径に留まるためには全ての点がそのコンパクトな像に入らなければならない。
:::

## Cartan–Hadamard の定理

:::theorem[Cartan–Hadamard]{#thm-rg-cartan-hadamard}
連結完備な $M$ で $K\le0$ なら、$\exp_p:T_pM\to M$ は被覆写像である。さらに $M$ が単連結なら指数写像は微分同相であり、任意の二点を結ぶ測地線弧の像は一意で、長さは最短である。
:::

:::proof
非正曲率なら両端零の Jacobi 場は零である。実際 $(\norm J^2)''=2\norm{D_tJ}^2-2g(R(J,T)T,J)\ge0$ だからである。:eqref[eq-rg-exp-jacobi] により $\exp_p$ は局所微分同相である。引き戻し計量 $h=\exp_p^*g$ では :ref[lem-rg-gauss] により半径の変化は曲線の長さ以下である。従って $h$ の Cauchy 列の半径は有界で、Euclid の閉接球内で収束部分列を持つ。$h$ が誘導する位相は Euclid 位相と同じなので、列全体が $h$ で収束する。次節の完備な局所等長写像の命題により $\exp_p$ は被覆である。単連結な $M$ への連結被覆は一枚である。そこでは Hopf–Rinow による最短弧の初期速度と異なる速度から同じ終点へは達しない。
:::

:::example[平坦トーラス]
$M=\R^2/\Z^2$ の $p=[0]$ で $\exp_p(v)=[v]$ である。共役点はないが $[(1/2,0)]$ に達する同じ長さの二つの動径がある。単連結性が単射性を保証する際の仮定である。
:::

:::example[被覆上の測地線と商の距離]
曲率 $-1$ の上半平面を $x\mapsto x+1$ で割ると、商でも曲率は負で完備である。高さ $y$ の点からの垂直測地線は商でも同じ長さを持つ。一方、同じ商の点には $x+k$ の全てが対応するため、商の距離を求めるには被覆上の複数の終点への長さを比べる必要がある。指数写像が全域で局所微分同相であることは、この大域的な重複を排除しない。
:::

### 指数写像の長さの下界

$K\le0$ とし、単位速動径上の始点零の垂直 Jacobi 場 $J$ を取る。$J\ne0$ なら正の時刻で零にならない。$f=\norm J$ を二回微分すると
$$
f''=\frac{\norm{D_tJ}^2-g(R(J,T)T,J)-(f')^2}{f}\ge0
$$
である。ここで $(f')^2=g(D_tJ,J)^2/f^2\le\norm{D_tJ}^2$ を用いた。また初期値の展開 $J(t)=tD_tJ(0)+O(t^2)$ から右微分は $\norm{D_tJ(0)}$ である。凸性で $f(t)\ge t\norm{D_tJ(0)}$ となる。従って指数写像の角方向の微分の長さは、接空間での長さ以上である。動径成分は正確に保存され、両成分は Gauss の補題で直交するので
$$
\norm{(d\exp_p)_v w}_g\ge\norm w_{g_p}
$$
となる。単連結完備なら逆写像 $\log_p$ が全域にあり、曲線長にこの評価を適用して
$$
\norm{\log_p(x)-\log_p(y)}_{g_p}\le d(x,y)
$$
を得る。共役点がないという結論だけでなく、逆写像が距離を増やさないことまで分かる。

:::example[双曲面での厳密な拡大]
単位双曲面の頂点から距離 $r$ のところで、接空間の垂直単位ベクトルに対する微分の倍率は $\sinh r/r$ である。$r=\log2$ なら $3/(4\log2)>1$ である。実際、$\sinh r-r$ は $r>0$ で導関数 $\cosh r-1>0$ を持つ。動径方向は倍率 $1$ なので、指数写像全体を一様な単一の倍率で表すことはできない。
:::

:::example[同じ高さの二点を結ぶ最短弧の大域性]
曲率 $-1$ の上半平面で $p=\left( -1, \  1\right)$、$q=\left( 1, \  1\right)$ とする。水平な線分は一般に最短でない。中点の高さを計算すると、最短弧がより高い位置を通ることが分かる。双曲面の Lorentz 内積を $B(V,W)=-V_0W_0+V_1W_1+V_2W_2$ とする。上半平面からの等長写像 :ref[prop-rg-half-space-isometry] を代入すると
$$
\begin{aligned}
P&=\begin{pmatrix}\frac{3}{2}\\-1\\\frac{1}{2}\end{pmatrix}\\
Q&=\begin{pmatrix}\frac{3}{2}\\1\\\frac{1}{2}\end{pmatrix}\\
C=-B(P,Q)&=3
\end{aligned}
$$
になる。両点は $B(P,P)=B(Q,Q)=-1$ を満たし、第 0 成分が正なので同じ双曲面上にある。

$Q-CP$ は $B(P,Q-CP)=-C+C=0$ なので接ベクトルである。その二乗長は
$$
B(Q-CP,Q-CP)=-1+2C^2-C^2=C^2-1=8
$$
である。従って単位初期方向は $U=(Q-CP)/\sqrt{C^2-1}$ であり、この例では $\begin{pmatrix}- \frac{3 \sqrt{2}}{4}\\\sqrt{2}\\- \frac{\sqrt{2}}{4}\end{pmatrix}$ となる。曲線
$$
\gamma(t)=\cosh t\,P+\sinh t\,U
$$
は $B(\gamma,\gamma)=-1$、$B(\dot\gamma,\dot\gamma)=1$ を満たす。さらに $\ddot\gamma=\gamma$ は周囲での法方向だから、接加速度は零である。$d=\log(C+\sqrt{C^2-1})$ とすると $C-\sqrt{C^2-1}=(C+\sqrt{C^2-1})^{-1}$ により $\cosh d=C$、$\sinh d=\sqrt{C^2-1}$ であり、$\gamma(d)=Q$ を得る。

この曲線は全体の最短弧である。実際、Lorentz 基底 $(P,U,\text{残りの単位接方向})$ を標準 Lorentz 基底に移すと、$P$ は頂点、$Q$ は動径距離 $d$ の点になる。極座標の速度は動径速度の絶対値以上であるから、どの経路も長さ $d$ 以上である。動径で等号が成立し、この例では $d=\log{\left(2 \sqrt{2} + 3 \right)}$ である。従って指定した初期ベクトルを指数写像に入れるなら $dU$、弧長 $t$ の初速度を指定するなら $U$ を用いる。

中点の計算には $P+Q=(1+\cosh d)P+\sinh d\,U$ を用いる。半角公式で右辺は $2\cosh(d/2)(\cosh(d/2)P+\sinh(d/2)U)$ になる。従って Lorentz 二乗長を $-1$ に正規化した
$$
M=\frac{P+Q}{\sqrt{2+2C}}=\begin{pmatrix}\frac{3 \sqrt{2}}{4}\\0\\\frac{\sqrt{2}}{4}\end{pmatrix}
$$
が中点である。上半平面へ戻す式 $y=1/(M_0-M_2)$、$x=M_1/(M_0-M_2)$ から中点は $\left( 0, \  \sqrt{2}\right)$ となる。上半平面では軌跡は中心 $c=0$、半径 $\sqrt{2}$ の半円である。中心は両端までの Euclid 二乗距離を等しいと置いた式から求めた。中点を代入しても $(x-c)^2+y^2=R^2$ となる。

同じ表示で一般の比率 $\lambda\in[0,1]$ の点は
$$
\gamma(\lambda d)
=\frac{\sinh((1-\lambda)d)}{\sinh d}P+
\frac{\sinh(\lambda d)}{\sinh d}Q
$$
である。$U=(Q-\cosh d\,P)/\sinh d$ を代入し、$\cosh(\lambda d)\sinh d-\sinh(\lambda d)\cosh d=\sinh((1-\lambda)d)$ を使った。二つの係数は通常の線形補間の $1-\lambda,\lambda$ とは異なる。これは $\gamma$ を双曲面上に保ちつつ弧長を比例させるためである。

任意の曲線をこの上半平面に戻しても距離位相の変化はなく、最短弧の一意性は Cartan–Hadamard の結論とも一致する。例えば半径 $r=d$ の閉球の指数写像表示では、接球面の方向 $U$ がちょうど $Q$ に対応する。閉球全体はコンパクトな閉接球の像である。座標上の無限遠に向かう列であっても、その列がここでの有限半径に留まるためには全ての点がそのコンパクトな像に入らなければならない。
:::

## 局所等長写像と被覆

:::proposition[完備な始域からの局所等長写像]{#prop-rg-local-isometry-cover}
連結な Riemann 多様体の間の局所等長写像 $F:N\to M$ で $N$ が完備なら、$F$ は全射な被覆写像であり $M$ も完備である。
:::

:::proof
局所等長写像は接続を保つ。初期速度を $dF$ で逆に送って $N$ の測地線を解くと、$M$ の測地線の持ち上げが得られる。$N$ の完備性により任意の有限な測地線弧を持ち上げられる。$M$ の任意の点へ有限本の短い測地線弧で到達できる。実際、この形で到達できる点の集合も補集合も強凸近傍によって開いている。これで全射であり、任意の初期値の全時刻の測地線も像として得られる。

$y\in M$ の小さい正規球 $B$ を取る。$x\in F^{-1}(y)$ ごとに $s_x(z)=\exp_x((dF_x)^{-1}\exp_y^{-1}z)$ を作ると $F\circ s_x=\id$ である。像は局所微分同相性で開いている。二つの像が交われば、動径弧を逆向きに持ち上げた終点 $x$ が一意なので同じ像である。$B$ の逆像の任意の点から逆向きの動径を持ち上げればいずれかの $x$ に達し、従って逆像はこれらの互いに素な像で尽くされる。
:::

逆に完備な基底の被覆は引き戻し計量で完備である。基底上の全時刻の測地線を :ref[thm-at-cover-lifts]{text="被覆の経路持ち上げ"} で持ち上げると、持ち上げた曲線は局所等長性により測地線だからである。

:::example[始域の仮定の役割]
$(-\pi,\pi)\to S^1$、$t\mapsto(\cos t,\sin t)$ は局所等長であるが、像は $(-1,0)$ を欠く。有限長でそこへ向かう測地線を始域で延長できない。
:::

:::example[等長的な被覆の持ち上げ]
周長 $2\pi$ の円に対する $F:\R/(6\pi\Z)\to\R/(2\pi\Z)$ は、弧長座標で恒等式を射影したものである。$[0]$ の繊維は $[0],[2\pi],[4\pi]$ である。長さ $\pi/2$ の正方向弧を各点から持ち上げると、終点はそれぞれ $[\pi/2],[5\pi/2],[9\pi/2]$ であり、三つの局所逆が重ならない様子が見える。
:::

### 商の距離と半径

連結完備多様体 $\widetilde M$ に群 $\Gamma$ が自由かつ固有不連続に等長作用するとする。商への射影は局所等長であるから、商も完備である。$x,y$ を上の点として、商の距離は
$$
d_{M}([x],[y])=\min_{\gamma\in\Gamma} d_{\widetilde M}(x,\gamma y)
$$
である。各 $\gamma y$ への上の曲線を射影すれば同じ長さであるため、左辺はどの右辺の候補以下である。逆に商で最短曲線を取り、$x$ から持ち上げると終点はある $\gamma y$ で長さは保存される。従ってその $\gamma$ で右辺が左辺以下となり、最小が得られる。上での距離を先に評価する場合も、閉球はコンパクトで軌道が局所有限であることから有限個の候補に絞れる。

$x$ を中心とする球の半径を $\frac12\inf_{\gamma\ne1}d(x,\gamma x)$ 未満に取ると、その球はどの非自明な移し先とも交わらない。交点があれば三角不等式で中心間距離が半径の二倍未満になるためである。逆に半分より大きい場合、対応する中心間の最短弧の中点が両球に含まれる。これで被覆で重ならない半径を軌道変位から測れる。ただし開球内だけの写像の単射性は、その球内の二点間の大域的な距離まで保存することを意味しない。

:::example[周期を越えると距離は短くなる]
$\R/(6\Z)$ で、上の点 $x=-2,y=2$ を取る。$x,y$ は半径 $5/2$ の球内で、その球の射影は単射である。しかし $\gamma y=2-6=-4$ を選ぶと $\vert -2-(-4)\vert=2$ であり、同じ球内での距離 $4$ より短い。一般に商内での最短弧が一つの被覆の区画に留まるとは限らない。
:::

:::example[直交格子の商で最短弧を持ち上げる]
二本の格子ベクトルを列に並べた行列を $B=\begin{pmatrix}4 & 0\\0 & 6\end{pmatrix}$ とし、平坦トーラス $\R^2/B\Z^2$ を考える。点 $\bar 0$ と $\begin{pmatrix}2\\1\end{pmatrix}$ の像を結ぶ。各座標で独立に周期を選べる。第 1 座標が周期の半分になるので、左右から等しく短い候補が現れる。

始点を原点に固定して曲線を持ち上げると、終点は $v-B(k,j)^\top$ のいずれかである。局所等長性で長さは保存され、Euclid 空間でこの終点への最短曲線は線分なので、距離の二乗は候補の二乗長の最小値である。候補を有限個に絞る。$a=B^{-1}v=\begin{pmatrix}\frac{1}{2}\\\frac{1}{6}\end{pmatrix}$ とし、$v$ 自身への線分の長さを $D=\sqrt{5}$ とする。これより長い候補は捨てられる。$w=v-B(k,j)^\top$ と書くと $B^{-1} w=a-(k,j)^\top$ だから、Cauchy–Schwarz により
$$
|a_i-(k,j)_i|\le\norm{(B^{-1})_{i,\cdot}}_\mathrm{E} D
$$
である。この二つの区間に入る整数だけ調べればよい。残る候補と二乗長は
$$
\begin{aligned}
&(0,0)\mapsto 5,\qquad (1,0)\mapsto 5
\end{aligned}
$$
である。上の列には長さ $D$ を越えるものも含まれ得るが、それらを残しても最小は変わらない。ここから最短の整数対は $(0,0),\ (1,0)$、距離は $\sqrt{5}$ である。

原点からの線分の射影は $2$ 本の最短弧を与える。異なる候補は初期速度が異なるので、同じパラメータの弧なら一意な持ち上げを持つことと矛盾する。逆に最短弧があれば、その持ち上げも上の両端の距離を実現する必要があるので、候補はこれで尽きる。被覆上の各終点では Euclid の線分は一意であるが、商では別の被覆終点が同じ費用で選ばれる。商の完備性は、すべての初期速度の線分が全時刻に伸び、その射影が測地線であることからも分かる。
:::

## 非正曲率多様体の基本群（Cartan の定理と Preissman の定理）

Cartan–Hadamard により、完備非正曲率多様体の普遍被覆は $\R^n$ と微分同相である。よって $i\ge2$ では $S^i$ からの写像は被覆へ持ち上がってそこで縮められ、$\pi_i(M)=0$ である。また可縮な閉測地線は被覆上でも閉じ、指数写像の単射性により定数曲線である。

### 二つの測地線の間の距離

単連結完備で $K\le0$ の多様体で、二つの測地線 $c_0(s),c_1(s)$ を同じ区間上でアフィンパラメータ化する。$L(s)=d(c_0(s),c_1(s))$ は凸関数である。実際、両端を結ぶ最短測地線は、$(x,v)\mapsto(x,\exp_xv)$ の全単射性と局所微分同相性により、端点に滑らかに依存する。$L(s)>0$ の点ではその接続弧に弧長を使い、端点を動かした長さの第二変分を取れる。両端の加速度が零なので境界項は消え、
$$
L''(s)=\int_0^{L(s)}
\bigl(\norm{D_t V^\perp}^2-g(R(V^\perp,T)T,V^\perp)\bigr)\,dt\ge0
$$
となる。ここで積分区間は基準の $s$ に固定し、変分中の接続弧はその区間上で定速にとる。

零点をまたぐ区間でも凸性は続く。各正の成分は凸であり、有限な両端が零ならその成分は正になり得ない。従って零点集合は区間である。左の正の成分から零点に近づく片側の傾きは非正で、右の成分へ入る片側の傾きは非負である。これにより零区間の傾き $0$ を挟んでも、弦の傾きは非減少である。もし $K<0$ で $L$ が一定かつ正なら、式の被積分関数が零なので接続弧に沿う変分の垂直成分は零である。従って両端の移動速度は接続弧と平行である。少なくとも一方の速度が非零なら、その側の測地線は接続弧を含む同じ測地直線上にある。もう一方も非零ならその測地線も同じ直線上にあり、一定曲率を仮定せず二本の軸の一意性に使える。

:::theorem[Cartan の固定点定理]{#thm-rg-cartan-fixed-point}
単連結完備な $K\le0$ の多様体の等長変換群の部分群が有界軌道を持つなら、その部分群は共通固定点を持つ。
:::

:::proof
まず $y$ を固定する。:ref[thm-rg-cartan-hadamard] により $E_y(x)=d(y,x)^2/2$ は大域的に滑らかである。$x\ne y$ で $y$ から $x$ までの最短測地線を $[0,1]$ 上で等速に取り、終点を初速度 $w$ の測地線で動かす。各終点へ $y$ からの測地線を変分に使う。指数写像が全域微分同相なので滑らかな変分が得られる。この変分のエネルギーは $E_y$ に等しく、両端の加速度は零なので :ref[prop-rg-second-variation] から
$$
\operatorname{Hess} E_y(w,w)=I(J,J)\ge \int_0^1\norm{D_tJ}^2\,dt\ge\norm w^2 .
$$
最後は平行標構で $J(0)=0,J(1)=w$ として Cauchy–Schwarz を使った。$x=y$ でも正規座標から Hessian は $g$ である。

有界軌道を $O$ とし、$F(x)=\sup_{y\in O}E_y(x)$ と置く。有界集合上で $E_y$ は $y\in O$ に関し共通の Lipschitz 上界を持つ。これは距離が $1$-Lipschitz で、その値が有界なので二乗も一様に Lipschitz となるためである。従って $F$ は有限かつ連続である。また $F(x)\ge E_{y_0}(x)$ を $y_0\in O$ で用いると、部分レベル集合は Hopf–Rinow によりコンパクトである。従って最小値を取る。

二点 $x_0,x_1$ を結ぶ最短弧の中点を $m$ とする。$E_y$ の Hessian 下界を弧に適用すると、$E_y(m)\le(E_y(x_0)+E_y(x_1))/2-d(x_0,x_1)^2/8$ である。実際、時刻区間 $[0,1]$ で速度の長さを $d(x_0,x_1)$ とし、$E_y$ から二次関数 $t^2d(x_0,x_1)^2/2$ を引けば凸になる。$y$ について上限を取っても同じ不等式が $F$ に成り立つので、最小点は一意である。等長変換は軌道 $O$ を保つため $F$ も保ち、その一意な最小点を固定する。
:::

とくに完備非正曲率多様体の基本群は有限位数の非自明な元を持たない。そのような元があれば普遍被覆で有限群を生成し、有限軌道を持つ。Cartan の定理は共通固定点を与えるが、被覆変換は自由に作用するからである。

:::lemma[自由ホモトピー類の最短曲線]{#lem-rg-free-loop-minimum}
コンパクト多様体の非自明な自由ホモトピー類は長さ最小の非定数閉測地線を持つ。
:::

:::proof
有限個の強凸近傍の被覆の Lebesgue 数を $\delta>0$ とする。長さ $\delta$ 未満の閉曲線は一つの近傍内で収縮するので、指定した類の長さの下限 $L$ は正である。等速の最小化列は一様 Lipschitz で、Arzelà–Ascoli によって一様収束部分列を持つ。十分近い点を端点に持つ最短弧は :ref[thm-rg-whitehead] の証明により端点に滑らかに依存する。対角線のコンパクト性から一様に近い閉曲線をこの弧で結ぶとホモトピーになる。従って極限も指定した類に属する。長さは分割和の上限なので極限で下半連続である。極限を有限分割して短い部分を最短弧に取り替えると、同じ類の区分的滑らかな曲線が得られ、その長さは $L$ 以上である。従って極限も長さ $L$ を持ち、短い部分を縮められない。定速に直すと各部分は測地線であり、始点をまたぐ部分も同様なので閉測地線となる。
:::

:::theorem[Preissmann]{#thm-rg-preissmann}
連結コンパクトな Riemann 多様体の断面曲率が $K<0$ なら、その基本群の非自明な可換部分群は無限巡回群である。
:::

:::proof
非自明な被覆変換 $a$ に対し、対応する自由ホモトピー類の最短閉測地線を持ち上げると、$a$ が正の長さだけ平行移動する測地直線が得られる。自由ホモトピーは共役類に対応するので、必要なら持ち上げを被覆変換で動かして $a$ に合わせる。この直線を軸と呼ぶ。

二本の軸を、それぞれ時刻 $1$ 当たり $a$ が作用するように等速でパラメータ化する。同時刻の点間の距離は、先に示したように凸であり、等長変換 $a$ により周期 $1$ を持つ。全実線上で周期的な凸関数は一定である。値が零なら二本は一致し、正なら負曲率での等号条件により二本は同じ測地直線をたどる。

$a$ と可換な元は軸を別の軸に移すため、その一意な直線を保つ。非零平行移動と可換な直線等長写像は平行移動である。軸上で点を固定する被覆変換は恒等写像なので、平行移動量は可換部分群を $\R$ の加法部分群に単射に埋め込む。被覆作用の固有不連続性により、軸上の一点の像は有界区間内に有限個しかない。従ってこの加法部分群は離散であり、最小の正元の整数倍からなる。
:::

平坦トーラスでは同じ方向に平行な軸が多数あり、$\Z^2$ 全体が可換である。厳密な負曲率は軸の一意性で使われる。

:::example[軸と反復の長さ]
コンパクト負曲率多様体で被覆変換 $a$ の軸の一回の平行移動量が $L$ とする。軸上では $a^m$ の変位は $|m|L$ である。$m\ne0$ の場合、同じ軸は $a^m$ の軸でもあり、:ref[thm-rg-preissmann] の証明で示した一意性から別の軸はない。例えば $m=3$ では閉じる経路は元の軸の商で三周し、基底での像が同じでも指定した自由ホモトピー類は変わる。
:::

:::example[非正曲率から高次ホモトピーを読む]
平坦トーラスは基本群が $\Z^2$ であるが、$\pi_2$ は零である。実際 $S^2$ の任意の写像を普遍被覆 $\R^2$ に持ち上げると、像を線分に沿って一点へ縮められる。そのホモトピーを射影すれば元の写像も可縮である。同じ議論は $S^i$、$i\ge2$ に使える。従って高次ホモトピーが消えても、基本群には二つの独立な可換生成元が残る。
:::

### 変位関数と軸上での最小値

単連結完備な非正曲率多様体で、等長変換 $a$ が単位速測地直線 $c$ を距離 $\ell>0$ だけ移すとする。任意の点 $x$ で
$$
m\ell=d(c(0),a^mc(0))
\le 2d(c(0),x)+d(x,a^m x)
\le 2d(c(0),x)+m\,d(x,ax)
$$
となる。最初の不等式では $x,a^mx$ を経由して三角不等式を適用し、最後は軌道点の列を経由した。$m$ で割り $m\to\infty$ とすれば $d(x,ax)\ge\ell$ であり、軸上で等号を取る。また $d(x,a^m x)$ と $m\ell$ の差は絶対値で $2d(x,c(0))$ 以下である。従って $\ell=\lim_{m\to\infty}m^{-1}d(x,a^m x)$ と見なせ、基点を選ばない。

逆に $x$ が $d(x,ax)$ の正の最小値を取るとする。$x$ と $ax$ の一意な単位速測地線を $\eta$ とし、その両端の速度を $T_0,T_1$ とする。$x$ を $v$ で動かしたとき $ax$ は $da(v)$ で動く。第一変分より
$$
g(T_1,da(v))-g(T_0,v)=0
$$
が全ての $v$ で成立する。従って $T_1=da(T_0)$ であり、$a^m\eta$ を両方向に継ぐと全域で滑らかな測地線を得る。Cartan–Hadamard により任意の有限部分は最短だから、これは軸である。従って自由な作用について、正の変位下限が実現されることは軸の存在と同値である。

:::example[閉でない商で軸が存在しない場合]
上半平面の $a(x,y)=(x+1,y)$ に対し、水平線分の長さは $1/y$ なので $d((x,y),a(x,y))\le1/y$ である。従って変位下限は零である。一方、固定点はなくすべての点で変位は正だから下限は実現しない。この等長変換は軸を持たない。Preissmann の証明でコンパクト性が入るのは、自由ホモトピー類の最短曲線が端へ逃げず、軸を構成できる段階である。
:::

:::example[二点の中点と有限群の固定点]
Euclid 平面で $a(x,y)=(4-x,2-y)$ は位数 $2$ の等長変換である。原点の軌道は $\{(0,0),(4,2)\}$ で、共通固定点は中点 $(2,1)$ である。任意の $x$ から二点までの最大距離は二点間距離の半分 $\sqrt5$ 以上で、中点で達成される。もし別の点でもこの半径が実現するなら三角不等式の等号で二点を結ぶ線分上に限られ、両端まで等距離だから同じ中点となる。Cartan の固定点定理の最小化は、この中点の構成を有界な軌道全体へ拡張している。
:::

### 有限個の点の重心を距離で定める

単連結完備な $K\le0$ の多様体上の点 $y_i$ と、正の重み $a_i$、$\sum_i a_i=1$ に対し、$F(x)=\frac12\sum_i a_i d(x,y_i)^2$ を考える。先に示した Hessian 下界を足すと $\operatorname{Hess}F\ge g$ である。一つの $y_i$ に関する項だけでも $x$ が無限遠へ行くと発散するので、Hopf–Rinow から最小点がある。二点を結ぶ弧上の厳密凸性で最小点は一意である。第一変分によって $\grad F(x)=-\sum_i a_i\log_x(y_i)$ だから、その点では重み付きの初期ベクトルが和で零になる。この重心は有限集合の最大距離を最小にする先の中心とは目的関数が異なる。重み付き配置を保つ等長変換ならどちらの目的関数も保つため、重心も固定する。例えば Euclid の直線上の $0,6$ に重み $2/3,1/3$ を置くと重心は $2$ であるが、最大距離を最小にする中心は $3$ である。

## 演習問題

::::exercise{level=basic}
$(0,\infty)$ の $g=dx^2/x^2$ が完備であることを示せ。

:::solution
$u=\log x$ は像が $\R$ 全体で $du=dx/x$ を満たすので、完備な Euclid 直線と等長である。
:::
::::

::::exercise{level=basic}
$(-2,2)$ の Euclid 計量で $p=0,v=3$ の測地線の最大正時刻を求めよ。

:::solution
$x(t)=3t$ なので $3t<2$ が必要である。正の最大端点は $2/3$ であり、その時刻は定義域に入らない。
:::
::::

::::exercise{level=basic}
半径 $3$ の円の直径を求めよ。

:::solution
小さい方の中心角は最大 $\pi$ であり、対蹠点で実現する。従って直径は $3\pi$ である。
:::
::::

::::exercise{level=basic}
$\R^2/(2\Z\times3\Z)$ で $[0]$ と $[(1,1)]$ の距離を求めよ。

:::solution
持ち上げた終点は $(1+2k,1+3m)$ で、各成分の絶対値の最小は $1$ である。従って Euclid 線分を射影して距離 $\sqrt2$ を得る。
:::
::::

::::exercise{level=advanced}
完備多様体の空でない閉集合への点からの距離が実現されることを示せ。

:::solution
下限に近い点列は閉距離球に入る。:ref[thm-rg-hopf-rinow] により収束部分列を持ち、閉性で極限は集合に属する。距離の連続性によりそこで下限を実現する。
:::
::::

::::exercise{level=advanced}
正次元の単連結完備非正曲率多様体はコンパクトでないことを示せ。

:::solution
:ref[thm-rg-cartan-hadamard] により $M\simeq\R^n$ である。$n>0$ の Euclid 空間は有界でないためコンパクトではなく、微分同相はコンパクト性を保存する。
:::
::::

::::exercise{level=advanced}
コンパクトな連結始域からの局所等長写像の繊維は有限であることを示せ。

:::solution
繊維は点の連続逆像として閉じ、局所微分同相であるため離散である。コンパクトな離散空間は各点の開集合から有限部分被覆を取れるので有限である。
:::
::::

::::exercise{level=advanced}
Preissmann の仮定のもとで基本群は捩れ元を持たないことを示せ。

:::solution
有限位数の非自明な元は有限巡回群を生成する。それは非自明な可換部分群なので、:ref[thm-rg-preissmann] の無限巡回性に反する。
:::
::::

## 確認テスト

::::quiz
距離完備で連結な場合に成り立つものを選べ。

- [x] 二点間に最短測地線がある。
- [ ] 直径が有限である。

:::explanation
最短弧の存在は Hopf–Rinow に含まれる。一方 Euclid 空間は完備で、いくらでも離れた二点がある。
:::
::::

::::quiz{answer="2" tol="1e-6"}
$\R/(4\Z)$ で $[0]$ と $[2]$ の最短測地線の像はいくつあるか。

:::explanation
終点の持ち上げ $2+4k$ の絶対値を最小にするのは $2,-2$ の二つである。射影した二つの半円の像は異なる。
:::
::::

::::quiz{answer="1" tol="1e-6"}
単連結完備非正曲率多様体で異なる二点を結ぶ最短測地線の像はいくつあるか。

:::explanation
Cartan–Hadamard により指数写像は微分同相なので、時刻 $1$ の値を指定する初期速度は一つだけである。
:::
::::

::::quiz
局所等長写像について正しいものを選べ。

- [x] 連結完備な始域から連結な標的への局所等長写像は被覆である。
- [ ] 任意の局所等長写像は全射である。

:::explanation
完備性を用いると測地線を全区間にわたって持ち上げられ、被覆を得る。円への $t\mapsto(\cos t,\sin t)$ を $(-\pi,\pi)$ に制限すると局所等長だが全射でない。
:::
