## この章の目標

- 歩道の個数を隣接行列の固有値と結び付ける。
- 正則グラフで固有値から辺分布を評価する。
- Laplacian の核、変分原理、代数的連結度を導く。
- 強正則グラフと Hoffman–Singleton の次数制限を計算する。
- Cheeger 不等式とランダムウォークの収束評価を証明する。

## 隣接行列とスペクトル

以下では、特に断らなければ有限単純無向グラフを扱う。二次形式と変分原理に使うベクトルは実数値とする。

頂点ラベルを替えると行列の成分は変わるが、行と列が同時に入れ替わる。従って固有値は図の名前に依存しない。行列の固有値が歩道の個数にどう現れるかを見る。

:::definition[隣接スペクトル]{#def-comb-adjacency-spectrum}
$A=A(G)$ の固有値の多重集合を :term[隣接スペクトル]{en="adjacency spectrum" yomi="りんせつすぺくとる"} という。無向グラフでは $A$ が実対称なので :ref[thm-linalg-real-spectral] を適用できる。
:::

:::proposition[スペクトルのモーメント]{#prop-comb-spectral-moments}
固有値を $\theta_1,\dots,\theta_n$ とすると $\sum_i\theta_i^\ell=\tr A^\ell$ は長さ $\ell$ の閉歩道の個数である。特に $\sum_i\theta_i=0$、$\sum_i\theta_i^2=2m$、$\sum_i\theta_i^3$ は三角形数の 6 倍である。
:::

:::proof
実対称行列は直交変換で対角化できる。冪の対角化とトレースの巡回性により等式が成り立つ。:ref[prop-comb-walk-powers] で対角成分は始点と終点を同じにした歩道数である。単純グラフでは長さ 1 の閉歩道はない。長さ 2 は一辺を往復し、どちらの端点から始めてもよい。長さ 3 では内部頂点が相異なるため三角形であり、三始点と二方向から数える。
:::

:::example[完全グラフと星]
$K_n$ では $A=J-I$ なので定数方向の固有値は $n-1$、座標和 0 の空間では $-1$ である。例えば $K_4$ で三乗和は $27-3=24$ なので三角形は 4 個ある。

星 $K_{1,r}$ では葉の座標和が 0 で中心の座標が 0 の空間に $A$ は零作用する。中心座標と全葉に共通の座標に制限すると $(x,y)\mapsto(ry,x)$ なので、残る固有値は $\pm\sqrt r$ である。$K_{1,4}$ の固有値は $2,-2,0,0,0$ である。
:::

### 二部性が現れる固有値の対称性

二部グラフの二側にそれぞれ $+1,-1$ を置いた対角行列を $S$ とする。辺の両端の符号が逆なので $SAS=-A$ である。従って固有ベクトル $x$ で $Ax=\theta x$ なら $A(Sx)=-\theta(Sx)$ となり、多重度込みでスペクトルは 0 を中心に対称である。逆に対称なスペクトルなら、任意の奇数 $\ell$ について $\sum_i\theta_i^\ell=0$ である。:ref[prop-comb-spectral-moments] によれば奇数長の閉歩道がなく、特に奇数長の閉路がない。:ref[thm-comb-bipartite-odd-cycle] によって二部性が分かる。この逆向きでは全ての奇数乗が消える必要があり、三乗和だけでは足りない。

:::example[三角形数が 0 でも二部とは限らない]
$C_5$ では長さ 3 の閉歩道はないが、各頂点を開始点として時計回りと反時計回りに一周する長さ 5 の歩道がある。長さ 5 で元へ戻るには各歩の向きを $\pm1$ として総和が 5 の倍数になる必要があり、奇数和は $\pm5$ の場合だけである。従って $\tr A^3=0$ だが $\tr A^5=10$ である。固有値の三乗和が 0 だけでは対称性を示せない。
:::

### 頂点を除くと固有値が交互に並ぶ

誘導部分グラフの隣接行列は元の行列の同じ添字の行と列を残したものである。固有値の大きさを頂点数の違うグラフで比較するには、座標を零にする前後で二次形式の値を比べる。

:::proposition[誘導部分グラフの固有値の交錯]{#prop-comb-induced-interlacing}
$G$ の隣接固有値を $\theta_1\ge\cdots\ge\theta_n$、その $m$ 頂点の誘導部分グラフ $H$ の隣接固有値を $\eta_1\ge\cdots\ge\eta_m$ とする。このとき
$$
\theta_i\ge\eta_i\ge\theta_{n-m+i}\qquad(1\le i\le m)
$$
である。
:::

:::proof
実対称行列 $A$ と非零ベクトル $x$ に対して $R_A(x)=\transp{x}Ax/\transp{x}x$ と書く。最大側の $i$ 個の固有ベクトルを張る空間では $R_A(x)\ge\theta_i$ である。また任意の $i$ 次元部分空間は、固有値 $\theta_i,\ldots,\theta_n$ に対応するベクトルの張る $(n-i+1)$ 次元部分空間と非零の共通部分を持つ。この交わりにある非零ベクトルでは $R_A(x)\le\theta_i$ である。したがって $i$ 次元空間での $R_A$ の最小値を空間全体で最大にした値が $\theta_i$ である。

$H$ の頂点以外で座標を零にした部分空間を $W$ とする。$W$ の上の二次形式は $H$ の隣接行列の二次形式に等しい。よって $W$ の内部だけで $i$ 次元部分空間を選んだときの最大値 $\eta_i$ は、もとの $\theta_i$ 以下である。一方、$G$ の最大側の $n-m+i$ 個の固有ベクトルの張る空間と $W$ の次元の和は $n+i$ である。交わりの中に $i$ 次元空間を取れば、そこでの $R_A$ は $\theta_{n-m+i}$ 以上である。この空間も $W$ 内の候補なので $\eta_i\ge\theta_{n-m+i}$ となる。
:::

:::example[誘導部分グラフから大きな正固有値を見つける]
同じグラフの中に互いの間に辺がない辺 $ab,cd$ が誘導部分グラフとしてあるとする。その四頂点上の隣接行列は $\begin{pmatrix}0&1\\1&0\end{pmatrix}$ を二つ並べたブロック対角行列なので、固有値は $1,1,-1,-1$ である。したがって元のグラフは 1 以上の固有値を少なくとも二つ、$-1$ 以下の固有値も少なくとも二つ持つ。辺の条件は、二本の辺が単に端点を共有しないことより強い。たとえば $K_4$ に二本の端点を共有しない辺はあるが、四頂点の誘導部分グラフには六辺ある。実際、$K_4$ の正固有値は 3 一つである。
:::

### 道と閉路のスペクトルを求める

交錯を使うと、閉路から一頂点を除いて得る道の固有値を上下から挟める。ここでは両方を直接求め、閉路の周期条件と道の端点条件を比べる。

:::proposition[道と閉路の隣接固有値]{#prop-comb-path-cycle-spectrum}
$n$ 頂点の道 $P_n$ の固有値は $2\cos(\pi j/(n+1))$、$j=1,\ldots,n$ である。$n\ge3$ 頂点の閉路 $C_n$ の固有値は $2\cos(2\pi j/n)$、$j=0,\ldots,n-1$ である。重複を含めてそれぞれ $n$ 個を数える。
:::

:::proof
道の頂点を $1,\ldots,n$ とし、両外側の座標 $x_0$ と $x_{n+1}$ を零とする。すると $(Ax)_k=x_{k-1}+x_{k+1}$ である。$x_k=\sin(k\pi j/(n+1))$ とおけば両外側の条件を満たし、正弦の加法公式で $(Ax)_k=2\cos(\pi j/(n+1))x_k$ になる。$1\le j\le n$ では固有値が互いに異なり、各ベクトルも零でないので独立である。

閉路では添字を $\mathbb Z/n\mathbb Z$ で取り、$\zeta=\exp(2\pi\mathrm{i}/n)$ として $x_k=\zeta^{jk}$ とする。すると周期条件を満たし、行列の固有値は $\zeta^j+\zeta^{-j}=2\cos(2\pi j/n)$ になる。異なる $j,j'$ のベクトルは、内積が $\sum_{k=0}^{n-1}\zeta^{(j-j')k}=0$ なので独立である。複素数で計算しても実対称行列の特性多項式と固有値は変わらない。
:::

:::example[六角形から一頂点を消す]
$C_6$ の固有値を降順に並べると $(2,1,1,-1,-1,-2)$ である。一頂点を消した $P_5$ の固有値は $(\sqrt3,1,0,-1,-\sqrt3)$ である。$\sqrt3$ は 2 と 1 の間に、0 は 1 と $-1$ の間に入る。また重複を持つ $C_6$ の固有値 1 と $-1$ は、交錯の両側が同値なので、$P_5$ の固有値にも同じ値が残る。
:::

:::example[二進ベクトルのグラフ]
$d$ 桁の二進ベクトルを頂点とし、一桁だけ違うものを結ぶグラフを $Q_d$ とする。$J\subseteq\{1,\ldots,d\}$ に対して $f_J(x)=(-1)^{\sum_{i\in J}x_i}$ とおく。第 $i$ 座標を反転すると、$i\in J$ のときだけ符号が逆になる。したがって $(Af_J)(x)=(d-2|J|)f_J(x)$ である。異なる $J,K$ の内積は、対称差の一座標を反転する組で相殺されて零になる。よってこの $2^d$ 本が全固有方向を与え、固有値 $d-2j$ の多重度は $\binom dj$ である。たとえば $Q_3$ では $(3,1,1,1,-1,-1,-1,-3)$ になる。
:::

### 二部グラフの固有値を小さい行列で求める

:::proposition[二部隣接行列と特異値]{#prop-comb-bipartite-singular-spectrum}
二部単純グラフの二部の濃度を $p,q$ とし、左から右への隣接を $p\times q$ の行列 $B$ に記す。$BB^\mathsf{T}$ の正固有値を重複込みで $s_1^2,\dots,s_r^2$ とすると、全体の隣接固有値の非零部分は $s_1,-s_1,\dots,s_r,-s_r$ である。残りの $p+q-2r$ 個は 0 である。
:::

:::proof
$BB^\mathsf{T}u=s^2u$、$s>0$ とし、$v=B^\mathsf{T}u/s$ と置けば $Bv=su$、$B^\mathsf{T}u=sv$ である。従って $\binom{u}{v}$ と $\binom{u}{-v}$ が、隣接行列 $\begin{pmatrix}0&B\\B^\mathsf{T}&0\end{pmatrix}$ の固有値 $s,-s$ に対応する。正固有値に対して直交基底を選ぶと、得られる各 $u$ および各 $v$ はそれぞれ直交する。実際、$B^\mathsf{T}$ を掛けたベクトルの内積は $BB^\mathsf{T}$ の作用を片側へ移した内積で計算できる。一方、全体の核は $\Ker B^\mathsf{T}\oplus\Ker B$ である。$BB^\mathsf{T}$ と $B^\mathsf{T}$ の核は、$u^\mathsf{T}BB^\mathsf{T}u=\norm{B^\mathsf{T}u}^2$ より一致する。従って両方の核の次元の和は $(p-r)+(q-r)$ であり、すべての固有値が得られた。
:::

:::example[完全二部グラフと一辺の欠落]
$K_{2,3}$ では $B$ の全成分が 1 であり、$BB^\mathsf{T}=\begin{pmatrix}3&3\\3&3\end{pmatrix}$ の固有値は 6 と 0 である。従って隣接固有値は $\sqrt6,-\sqrt6,0,0,0$ である。下段の末尾を 0 に変えると $BB^\mathsf{T}=\begin{pmatrix}3&2\\2&2\end{pmatrix}$ になり、特性多項式は $z^2-5z+2$ である。二つの正固有値が $(5\pm\sqrt{17})/2$ なので、隣接行列ではその平方根と符号反転の四つ、それに 0 一つが残る。一辺を削除してランクが増える場合がある。
:::

## 正則グラフと固有値の評価

各頂点の次数が同じなら、定数ベクトルが一つの固有方向になる。その方向を除いて行列の作用が小さいと、二集合間の辺数は均一に混ぜた予想値に近い。

:::proposition[正則グラフの固有値と混合]{#prop-comb-expander-mixing}
$d$ 正則グラフで $A\mathbf1=d\mathbf1$ であり、全固有値は $[-d,d]$ に入る。$\mathbf1^\perp$ 上の固有値の絶対値最大を $\Lambda$ とする。$e(S,T)=\sum_{u\in S,v\in T}A_{uv}$ と数えると
$$
\left|e(S,T)-\frac{d|S||T|}{n}\right|
\le \Lambda\sqrt{|S|(1-|S|/n)|T|(1-|T|/n)} .
$$
$S,T$ が重なる場合、両端が重なりにある辺は二度数える。
:::

:::proof
各行の和が $d$ であり、任意の実ベクトル $x$ に対し
$$
|\transp{x}Ax|\le\sum_{uv\in E}2|x_ux_v|
\le\sum_{uv\in E}(x_u^2+x_v^2)=d\norm{x}^2
$$
なので固有値範囲を得る。集合の指示ベクトルを $(|S|/n)\mathbf1+x$、$(|T|/n)\mathbf1+y$ と中心化する。両変動項は $\mathbf1^\perp$ にあり、交差項は消えるので差は $\transp{x}Ay$ になる。固有基底で $\norm{Ay}\le\Lambda\norm{y}$、Cauchy–Schwarz で結論が従う。$\norm{x}^2=|S|-|S|^2/n$ で、$y$ も同様である。
:::

:::example[四角形の二つの側]
$C_4$ の固有値は $2,0,0,-2$ である。対頂点で座標を反対にした二つのベクトルを $A$ は零に送り、定数ベクトルと交互符号ベクトルをそれぞれ $2$ 倍、$-2$ 倍する。二部分割の $S,T$ には交差辺が 4 本あり、均一な予測は $2$ 本である。$\Lambda=2$ と各中心化ノルム 1 により差の上界はちょうど 2 になる。
:::

### 独立集合を最小固有値で制限する

:::proposition[Hoffman の比の上界]{#prop-comb-hoffman-ratio}
辺のある $d$ 正則グラフで、隣接行列の最小固有値を $\theta_{\min}$ とする。このとき独立集合の最大濃度は
$$
\alpha(G)\le n\frac{-\theta_{\min}}{d-\theta_{\min}}
$$
である。
:::

:::proof
独立集合 $S$ の指示ベクトルを $\mathbf1_S=(s/n)\mathbf1+x$ とする。$s=|S|$ であり、$x\perp \mathbf1$ である。独立性から $\transp{\mathbf1_S}A\mathbf1_S=0$ なので
$$
0=\frac{ds^2}{n}+\transp{x}Ax
\ge \frac{ds^2}{n}+\theta_{\min}\left(s-\frac{s^2}{n}\right)
$$
である。最後の不等式は実対称行列の固有基底で二次形式を評価したもの。$s>0$ として割り、整理すれば結果を得る。分母は正である。実際、$d>0$ に対して固有値の和は 0 なので $\theta_{\min}<0$ である。
:::

:::example[固有値と彩色数の下界]
$C_4$ では $d=2$、最小固有値が $-2$ なので $\alpha\le2$ となり、対頂点の集合で等号が成り立つ。一般に色クラスは独立なので $\chi\ge n/\alpha\ge1-d/\theta_{\min}$ になる。後で見る Petersen グラフでは $d=3,\theta_{\min}=-2$ なので $\alpha\le4$、$\chi\ge3$ である。$[5]$ の二元集合で 1 を含むもの四つを選べば互いに素な対がなく、大きさ 4 の独立集合が得られる。
:::

### 次数を固定すると非自明な固有値にも下限がある

正則グラフで $\Lambda$ が小さいほど、二集合間の辺の分布は平均に近づく。そこで、次数を固定したまま頂点数を増やしても、この量を任意に小さくできるかを調べる。短い閉歩道の個数を使うと、固有値の絶対値に下限を与えられる。

:::theorem[正則グラフでの Alon–Boppana 型下限]{#thm-comb-alon-boppana-absolute}
$d\ge2$ を固定する。頂点数が無限に増える有限 $d$ 正則グラフの列について、定数ベクトルに直交する空間での隣接固有値の最大絶対値を $\Lambda_n$ と書く。このとき
$$
\liminf_{n\to\infty}\Lambda_n\ge2\sqrt{d-1}
$$
である。
:::

:::proof
頂点 $v$ を固定し、$v$ から出る歩道のうち直前の辺をその場で戻らないものを、別の木の頂点とみなす。長さ零の歩道を根とし、一歩だけ延ばした歩道を子とする。根は $d$ 個の子を持ち、その他の頂点は $d-1$ 個の子を持つ。各点を歩道の終点へ写すと、木での各頂点に接する辺は、元のグラフで像に接する $d$ 本の辺へ一対一に対応する。根以外では親に向かう辺が「その場で戻る」一本を補うためである。したがって元のグラフでの歩道を一歩ずつ与えると、根から出る木での歩道は一意に復元できる。特に木で根に戻る歩道の像は、元のグラフで相異なる閉歩道である。

高さが 0 から始まり、$k$ 回の上昇、$k$ 回の下降を経て 0 に戻り、負にならない列を一つ選ぶ。この列に沿って木を進むと、上昇のたびに少なくとも $d-1$ 通りの子を選べ、下降では親が一意に決まる。列の個数は $C_k=\binom{2k}{k}/(k+1)$ である。実際、上昇と下降を同数、任意の順に置いた $\binom{2k}k$ 列のうち、高さが初めて $-1$ になるまでを反転すると、上昇が $k+1$ 回、下降が $k-1$ 回の列に一対一に対応する。その差 $\binom{2k}k-\binom{2k}{k-1}$ が $C_k$ になる。よって元のグラフで各始点につき少なくとも $C_k(d-1)^k$ 本の長さ $2k$ の閉歩道がある。

トレースを閉歩道数と固有値の両方で捉えると
$$
n C_k(d-1)^k\le \tr A^{2k}\le d^{2k}+(n-1)\Lambda_n^{2k}
$$
となる。$k$ を固定して頂点数を増やせば $\liminf_n\Lambda_n\ge C_k^{1/(2k)}\sqrt{d-1}$ である。中央の二項係数は $\sum_{i=0}^{2k}\binom{2k}i=4^k$ の最大項なので $\binom{2k}k\ge4^k/(2k+1)$ であり、同時に $\binom{2k}k\le4^k$ である。従って $k\to\infty$ で $C_k^{1/(2k)}\to2$ となり、結論を得る。
:::

:::example[次数三の族で可能な差]
$d=3$ の場合、$\liminf\Lambda_n\ge2\sqrt2$ である。仮に $d$ と $\Lambda_n$ の差を毎回 $1/2$ 以上にすると、$\Lambda_n\le5/2<2\sqrt2$ となり、頂点数を無限に増やせない。一方、単独の $K_4$ は 3 正則で $\Lambda=1$ である。証明で $n$ を増やす操作が必要なのは、有限の小さなグラフでは $d^{2k}$ の寄与を無視できないためである。
:::

:::remark[絶対値を使うと二部グラフで値が大きくなる]
連結な $d$ 正則二部グラフでは、二部で符号を入れ替えたベクトルが固有値 $-d$ を持つ。従って $\Lambda_n=d$ となり、上の下限は満たされる。$-d$ を取り除いた固有値だけで下限を考えるなら、トレースの上界にもう一つ $d^{2k}$ を分けて加える。固定した $k$ で $n$ を増やせばその項も $n$ で割ると消える。実例を比較するときは、どの固有値を除いた量かを揃える必要がある。
:::

:::corollary[Alon–Boppana の下限]{#cor-comb-alon-boppana}
固定した $d\ge2$ に対し、頂点数が無限に増える $d$ 正則グラフの列の第二最大隣接固有値を $\theta_2$ とすると、$\liminf\theta_2\ge2\sqrt{d-1}$ である。
:::

:::proof
上側の固有値を評価するために $A+dI$ を使う。その全固有値は非負である。:ref[thm-comb-alon-boppana-absolute] の閉歩道数の評価と、$\binom{2j}{j}\ge4^j/(2j+1)$ を使う。固定した整数 $k\ge1$ と $2j\le k$ について $C_j\ge4^j/(k+1)^2$ なので、$b=2\sqrt{d-1}$ とおくと
$$
\begin{aligned}
\frac1n\tr(A+dI)^k
&\ge\sum_{0\le2j\le k}\binom{k}{2j}d^{k-2j} C_j(d-1)^j\\
&\ge\frac{(d+b)^k+(d-b)^k}{2(k+1)^2}
\ge\frac{(d+b)^k}{2(k+1)^2}.
\end{aligned}
$$
奇数冪のトレースも歩道数なので非負であり、最初の下界では省ける。最後は $d\ge b$ による。一方、定数方向の固有値は $2d$、残りは $d+\theta_2$ 以下なので、同じトレースは $(2d)^k+(n-1)(d+\theta_2)^k$ 以下である。$k$ を固定して $n\to\infty$ とすると、定数方向の寄与を $n$ で割った値は消える。従って $\liminf(d+\theta_2)\ge(d+b)/(2(k+1)^2)^{1/k}$ であり、最後に $k\to\infty$ とすればよい。
:::

### 隣接行列から異なる集合間の辺数を挟む

:::example[三次元立方体で辺数を評価する]
三次元立方体 $Q_3$ の頂点は二進三桁で、一桁だけ違う頂点を結ぶ。各座標を反転したときに符号が変わる座標の集合を $S$ とすると、関数 $f_S(x)=(-1)^{\sum_{i\in S}x_i}$ の固有値は $3-2|S|$ である。各頂点で三つの隣接先のうち $|S|$ 箇所だけ符号が反転するためである。八つの $f_S$ は互いに直交するので、スペクトルは $3,1,1,1,-1,-1,-1,-3$ である。通常の混合評価に入る非定数部分の絶対値の最大は 3 であり、二部性のため最大固有値と同じになる。一方、独立集合の Hoffman の上界は $8\cdot3/(3+3)=4$ で、偶数個の 1 を持つ四頂点が達成する。正の側の二番目の固有値は 1 だが、絶対値で最大の非定数固有値は $-3$ である。非遅延ウォークではその固有値が $-1$ に写り、立方体の各部にある確率が時刻の偶奇で入れ替わる。
:::

:::example[スペクトルから独立集合を抑えた後に彩色を作る]
$K_{3,3}$ の最小隣接固有値は $-3$ であり、$n=6,d=3$ なので Hoffman の上界は $\alpha\le6\cdot3/(3+3)=3$ となる。各部が 3 点の独立集合であるため等号になり、二側を別色にして $\chi=2$ を得る。比の上界で等号になるためには、独立集合の指示ベクトルから定数平均を引いたものが最小固有値空間に属する必要がある。この例では左側で $1/2$、右側で $-1/2$ を取るので、各点で隣接先の三成分を加えると自分の成分の $-3$ 倍になる。大きさの上界だけでなく、この等号条件も直接確認できる。
:::

## Laplacian 行列と代数的連結度

頂点ごとに数値を置き、隣の値との差を測る。隣り合う頂点の値がすべて等しければ、値は連結成分ごとに一定になる。この性質を行列の核で表す。

:::definition[組合せ Laplacian]{#def-comb-laplacian}
次数行列を $D=\diag(d(v))$ とし、$L=D-A$ を :term[組合せ Laplacian]{en="combinatorial Laplacian" yomi="くみあわせらぷらしあん"} と呼ぶ。$n\ge2$ で固有値の昇順の二番目を :term[代数的連結度]{en="algebraic connectivity" yomi="だいすうてきれんけつど"} $\lambda_2(L)$ という。
:::

:::proposition[エネルギーと核]{#prop-comb-laplacian-kernel}
$$
\transp{x}Lx=\sum_{uv\in E}(x_u-x_v)^2. \label{eq-comb-lap-energy}
$$
$L$ は半正定値で、その核は成分ごとに一定のベクトルの空間である。従って $n\ge2$ で連結性は $\lambda_2(L)>0$ と同値であり、
$$
\lambda_2(L)=\min_{\substack{x\ne0\\\transp{x}\mathbf1=0}}
\frac{\transp{x}Lx}{\norm{x}^2}
$$
である。
:::

:::proof
平方の和で各 $x_v^2$ は $d(v)$ 回現れ、交差項は隣接行列の項に一致する。核の元はエネルギーが 0 なので、各辺の両端で等しい。道に沿って成分内で等しくなる。逆に成分ごとに一定なら、頂点 $v$ での成分 $(Lx)_v=d(v)x_v-\sum_{u\in N(v)}x_u$ が 0 となる。連結成分ごとの指示ベクトルが核の基底を与えるため、零固有値の多重度は連結成分数である。$\mathbf1$ を正規化したものを最初の固有ベクトルとし、直交補上で固有基底を使えば、商は残りの固有値の重み付き平均で、その最小値は $\lambda_2$ になる。
:::

:::example[道の両端を辺で結ぶ]
$P_3$ の Laplacian は $\begin{pmatrix}1&-1&0\\-1&2&-1\\0&-1&1\end{pmatrix}$ である。$\transp{(1,1,1)},\transp{(1,0,-1)},\transp{(1,-2,1)}$ に対し固有値は $0,1,3$ となる。両端を結ぶと $K_3$ になり、代数的連結度は 3 に増える。一般に辺を加えると分子の平方項だけが増えるので、変分式から $\lambda_2$ は減少しない。
:::

### 固有値から全域木を数える

連結グラフの Laplacian 固有値を $0,\lambda_2,\dots,\lambda_n$ とする。このとき
$$
\tau(G)=\frac{1}{n}\prod_{i=2}^n\lambda_i
$$
である。行列木定理 :ref[thm-comb-matrix-tree] の各余因子を足すとこの式を得る。実際、$\det(tI+L)$ の $t$ の係数を行列式の列の多重線形性から計算する。一つの列だけ $tI$ の成分を選ぶと、その列を余因子展開して対応する $L^{(r)}$ を得る。全ての $r$ について足すので係数は $n\tau(G)$ である。一方、対角化で行列式は $t\prod_{i=2}^n(t+\lambda_i)$ なので、同じ係数は $\prod_{i=2}^n\lambda_i$ である。

:::example[四角形のスペクトルから木を読む]
$C_4$ の Laplacian は $L=2I-A$ であるため、固有値は $0,2,2,4$ である。全域木の数は $2\cdot2\cdot4/4=4$ となる。実際に四角形の辺を一本ずつ除く四通りに対応する。孤立点を付けると零固有値が二つになり、$\det(tI+L)$ の一次係数も 0 になる。従って同じ計算法で木がないことが分かる。
:::

### 最小の正固有値を距離から評価する

Laplacian の固有値は、隣り合う頂点の差を二乗して足した値から得られた。グラフ全体で値が大きく違う二頂点を選ぶと、それらを結ぶ短い道に差が現れる。

:::proposition[代数的連結度の削除単調性と直径による下界]{#prop-comb-algebraic-connectivity-distance}
同じ $n\ge2$ 頂点上のグラフに辺を足すと、$\lambda_2(L)$ は減らない。また連結なグラフの直径を $D$ とすると
$$
\lambda_2(L)\ge\frac4{nD}
$$
である。
:::

:::proof
$\mathbf1^\perp$ の非零ベクトル $f$ に対する比
$$
\frac{\sum_{uv\in E}(f_u-f_v)^2}{\sum_v f_v^2}
$$
の最小は $\lambda_2(L)$ である。辺を足しても分母は変わらず、分子は新しい辺の差の二乗だけ増えるので、単調性が得られる。

次に $M=\max_v f_v$、$m=\min_v f_v$ とする。$(M-f_v)(f_v-m)\ge0$ なので $f_v^2\le(M+m)f_v-Mm$ である。$\sum_v f_v=0$ を使って足し合わせると
$$
\sum_v f_v^2\le -nMm\le n(M-m)^2/4
$$
となる。$M,m$ を取る二頂点を長さ $\ell\le D$ の最短路で結ぶ。この道に沿って $f$ の差を足すと $M-m$ であり、Cauchy–Schwarz で
$$
(M-m)^2\le \ell\sum_{uv\in E}(f_u-f_v)^2
$$
である。二つの評価を比に代入すれば直径による下限を得る。
:::

:::example[星から葉の間に辺を加える]
$K_{1,4}$ の Laplacian の固有値は $0,1,1,1,5$ である。中心の座標を零にし、葉の座標の和を零とする三次元空間で $L$ は恒等作用となる。残りでは、定数ベクトルが固有値 0、中心の値を 4、各葉の値を $-1$ としたベクトルが固有値 5 を持つ。従って $\lambda_2=1$ であり、直径は 2 なので上の下限は $4/(5\cdot2)=2/5$ である。葉の集合内に一辺だけ加えた場合、その二葉では値を共通にし、和が零で中心の値が零となるベクトルを取れる。そのベクトルの比は依然 1 なので、単調性の等号が成り立つ。
:::

:::example[道と輪で距離も固有値も変わる]
$P_3$ の Laplacian の固有値は $0,1,3$、端点を結んだ $C_3$ の Laplacian の固有値は $0,3,3$ である。前者では両端の値が $1,-1$ で中央の値が 0 のベクトルが固有値 1 に対応する。追加した辺の両端でそのベクトルの値は異なるため、対応する比は増える。後者は $L=3I-J$ なので定数方向以外の固有値が 3 に揃う。この例では、直径も 2 から 1 へ縮む。
:::

### デカルト積では各座標の固有値を足す

道を縦と横に並べた格子グラフでは、どの辺も片方の座標だけを変える。この分解を行列に移すと、二つの小さなグラフの固有ベクトルから全体の固有ベクトルを作れる。

:::definition[グラフのデカルト積]{#def-comb-cartesian-graph-product}
単純グラフ $G,H$ の :term[デカルト積]{en="Cartesian product" yomi="でかるとせき"} $G\square H$ は頂点を $(u,v)\in V(G)\times V(H)$ とする。$(u,v)$ と $(u',v')$ の間に辺があるのは、$u=u'$ かつ $vv'\in E(H)$ であるか、$v=v'$ かつ $uu'\in E(G)$ である場合である。
:::

:::proposition[デカルト積の隣接固有値と Laplacian 固有値]{#prop-comb-cartesian-spectrum}
$G,H$ の隣接固有値をそれぞれ $(\theta_i)_i,(\eta_j)_j$ とすると、$G\square H$ の隣接固有値は重複を含めて $\theta_i+\eta_j$ である。Laplacian でも同じように各固有値を足す。両グラフが連結でそれぞれ二頂点以上であれば、$\lambda_2(L(G\square H))=\min\{\lambda_2(L(G)),\lambda_2(L(H))\}$ である。
:::

:::proof
$G$ 上の関数 $f$ と $H$ 上の関数 $g$ の積 $F(u,v)=f(u)g(v)$ を考える。隣接する頂点を、第一座標が変わるものと第二座標が変わるものに分けて足すと、
$$
(A_{G\square H}F)(u,v)=(A_G f)(u)g(v)+f(u)(A_Hg)(v)
$$
である。次数は $d_G(u)+d_H(v)$ なので、同じ式は $A$ を $L$ に替えても成り立つ。よって $f,g$ がそれぞれ固有ベクトルであれば、$F$ は固有値の和に対する固有ベクトルである。

各因子の正規直交固有基底を取る。二つの積ベクトルの内積は、第一座標に関する内積と第二座標に関する内積の積になる。したがって積ベクトルは正規直交し、その本数は $|V(G)||V(H)|$ である。これは全体の次元なので固有値をすべて得たことになる。連結な各因子で Laplacian の最小固有値 0 は単純である。和の中で正になる最小の値は一方の零と他方の最小の正固有値の組から得られ、結論が従う。
:::

:::example[格子の全域木]
$P_2\square P_3$ について、$P_2$ の Laplacian 固有値は $0,2$、$P_3$ では $0,1,3$ である。従って積グラフの固有値は $0,1,2,3,3,5$ になる。その全域木数は正の Laplacian 固有値の積を頂点数で割った $1\cdot2\cdot3\cdot3\cdot5/6=15$ である。横の道が長いこの格子で、代数的連結度は長い方の道と同じ 1 になる。
:::

:::example[立方体の辺の変化を分ける]
二進ベクトルのグラフ $Q_d$ は $P_2$ の $d$ 回のデカルト積である。その Laplacian 固有値は各座標から 0 または 2 を足して得るので $2j$ が $\binom dj$ 回ずつ現れる。$Q_3$ の全域木数は $2^3 4^3 6/8=384$ である。$Q_d$ の次数が $d$ であることから $L=dI-A$ を使うと、前に符号関数で計算した隣接固有値 $d-2j$ とも一致する。
:::

### ブロックの間の辺を除いて代数的連結度を評価する

:::proposition[二分割の試験ベクトル]{#prop-comb-laplacian-cut-vector}
$n$ 頂点のグラフで $\varnothing\ne S\subsetneq V$、$|S|=a$、$|V\setminus S|=b$ とし、二側の間の辺数を $c$ とする。Laplacian の二番目に小さい固有値は $\lambda_2\le c(1/a+1/b)$ を満たす。
:::

:::proof
ベクトル $f$ を $S$ では $1/a$、補集合では $-1/b$ と置く。全成分の和は 0、平方和は $1/a+1/b$ である。辺での差が 0 でないのは二側を結ぶ辺だけなので、Laplacian の二次形式は $c(1/a+1/b)^2$ に等しい。定数ベクトルに直交するベクトルの Rayleigh 商の最小が $\lambda_2$ である。従ってこの試験ベクトルの商が上界を与える。
:::

:::example[二つの三角形を橋で結ぶ]
三角形を二つ用意して一辺だけで結ぶと、$a=b=3,c=1$ なので $\lambda_2\le2/3$ である。橋を両端が共通しない三本の辺に替えると三角柱になり、同じ分割の上界は 2 に上がる。この場合は $K_3$ と $K_2$ のデカルト積として、Laplacian 固有値を $0,2$ と $0,3,3$ の和で求められる。全体は $0,2,3,3,5,5$ で、$\lambda_2=2$ となり、後者の上界は等号である。両側に置いた定数が、各頂点から反対側への辺数が一定という条件で固有ベクトルになっている。
:::

三角柱のように二つの側の大きさと各点の交差次数がともに等しいとき、$1,-1$ を両側に置いたベクトルは固有ベクトルである。各点では側内の辺からの寄与は 0 で、交差辺一本につき符号付きで 2 が加わるからである。ただしその固有値が第二最小かどうかは、残りの固有値も比較して判定する。

## 強正則グラフと Hoffman–Singleton の定理

隣接か非隣接かだけで二歩の行き方の数が決まるとする。隣接行列を二乗したときも限られた行列で書けるので、固有値が少数の候補に限られる。

:::definition[強正則グラフ]{#def-comb-strongly-regular}
$0<d<n-1$ の $d$ 正則グラフで、隣接対の共通近傍が常に $\lambda$ 個、非隣接対の共通近傍が常に $\mu$ 個なら、パラメータ $(n,d,\lambda,\mu)$ の :term[強正則グラフ]{en="strongly regular graph" yomi="きょうせいそくぐらふ"} という。
:::

:::proposition[強正則性の行列恒等式]{#prop-comb-srg-identity}
パラメータが $(n,d,\lambda,\mu)$ なら
$$
A^2=(d-\mu)I+(\lambda-\mu)A+\mu J,\qquad
(n-d-1)\mu=d(d-\lambda-1).
$$
$\mathbf1^\perp$ 上の固有値は $x^2-(\lambda-\mu)x-(d-\mu)=0$ の根である。
:::

:::proof
$A^2$ の対角は $d$、非対角は共通近傍数なので行列恒等式を得る。定数ベクトルにその両辺を作用させて $d^2=(d-\mu)+(\lambda-\mu)d+\mu n$ を整理する。直交補では $Jx=0$ なので固有値の二次式を得る。
:::

:::example[二元集合による Petersen グラフ]
$[5]$ の二元集合を頂点とし、互いに素な二集合を辺で結ぶ。各頂点からその補集合の三元から二元を選べるので次数 3 である。隣接対は合併が四元で共通近傍はなく、非隣接対は合併が三元で共通近傍はその補集合だけである。従ってパラメータは $(10,3,0,1)$、固有値は $3,1,-2$ である。定数方向以外の多重度を $a,b$ とすると $a+b=9$、$3+a-2b=0$ より $a=5,b=4$ となる。
:::

:::theorem[Hoffman–Singleton の次数制限]{#thm-comb-hoffman-singleton}
直径 2、内周 5 の $d$ 正則グラフの次数は $2,3,7,57$ のいずれかである。次数 $2,3,7$ では例が存在する。
:::

:::proof
任意の頂点から距離 1 の $d$ 個と距離 2 の $d(d-1)$ 個の頂点が重複しない。三角形がないため二歩の先は距離 1 にならず、四角形がないため二歩の先に重複がない。直径が 2 なので $n=d^2+1$ である。また任意の非隣接対は共通近傍をちょうど一つ持ち、隣接対については 0 個である。

直交補の固有値は $r=(-1+\sqrt{4d-3})/2$、$s=(-1-\sqrt{4d-3})/2$ で、多重度 $a,b$ は $a+b=d^2$ と $d+ar+bs=0$ を満たす。従って
$$
(a-b)\sqrt{4d-3}=d(d-2).
$$
平方根が無理数なら $a=b$ が必要なので $d=2$ である。整数 $t=\sqrt{4d-3}$ なら $t$ は奇数で、$t$ は $d(d-2)$ を割る。$16d(d-2)=(t^2+3)(t^2-5)$ なので $t\mid15$ であり、$t=1,3,5,15$ から $d=1,3,7,57$ を得る。直径 2 には $d\ge2$ が必要である。

$d=2$ は $C_5$ で実現する。$d=3$ は前例の Petersen グラフで実現する。実際、$\lambda=0,\mu=1$ から直径は 2 で、三角形と四角形はない。二元集合を二桁で略記すると $12,34,15,23,45,12$ が長さ 5 の閉路である。

$d=7$ の例を $\Z/5\Z$ の添字で作る。頂点を $P_{ij},Q_{kl}$ とし、同じ $i$ の $P$ 同士では第二添字が $\pm1$ ずれたとき辺、同じ $k$ の $Q$ 同士では $\pm2$ ずれたとき辺とする。$P_{ij}$ と $Q_{kl}$ の交差辺は $j=ik+l$ のとき置く。各頂点は同種の二隣接先と異種の五隣接先をもつ。

同種で第一添字が同じ二頂点は五角形内の関係により、隣接なら共通近傍 0、非隣接なら 1 である。同じ異種頂点に隣接することは第二添字が違うためない。同種で第一添字が異なる場合は、二つの交差辺の条件を連立すると、異種の共通近傍が一つに決まる。例えば $P_{ij},P_{i'j'}$ なら $(i-i')k=j-j'$ を解き、次に $l$ を決める。

異種の $P_{ij},Q_{kl}$ について $q=j-ik-l$ とする。$q=0$ なら隣接し、同種辺を一つ用いるどの二歩でも相手へ届かないので共通近傍は 0 である。$q=\pm1$ のとき $P$ の側に一つ、$q=\pm2$ のとき $Q$ の側に一つだけ共通近傍がある。よって $(50,7,0,1)$ を得る。三角形も四角形もないが各五角形に長さ 5 の閉路があり、直径は 2 である。
:::

次数制限は $57$ の実現を保証しない。その場合に必要な頂点数は $57^2+1=3250$ であり、固有値の候補と多重度が整数になることだけでは存在を決められない。

### 固有値の種類と多重度で強正則性を調べる

:::proposition[三種類の固有値による強正則性の判定]{#prop-comb-srg-three-eigenvalues}
連結な $d$ 正則グラフで $0<d<n-1$ とする。このグラフが強正則であることと、相異なる隣接固有値がちょうど三種類あることは同値である。第二・第三の値を $r>s$、それぞれの多重度を $a,b$ とすれば
$$
a=\frac{-d-(n-1)s}{r-s},\qquad b=\frac{d+(n-1)r}{r-s}
$$
である。
:::

:::proof
連結な正則グラフで定数方向の固有値 $d$ は単純である。実際、$Ax=dx$ なら $Lx=0$ なので :ref[prop-comb-laplacian-kernel] から $x$ は定数である。強正則ならその直交補上で固有値は二次式の根に限られる。もし固有値が一種類 $r$ だけなら $A=rI+(d-r)J/n$ となる。この式では全非対角成分が等しく、辺も非辺もある条件に反する。よって固有値は合計三種類である。

逆に $d,r,s$ の三種類なら、$(A-rI)(A-sI)$ は定数方向で $(d-r)(d-s)$ 倍、直交補で零となる。従って
$$
A^2=(r+s)A-rsI+\frac{(d-r)(d-s)}{n}J .
$$
その非対角成分は隣接するかどうかだけで決まるため、共通近傍数はそれぞれ一定となる。多重度の式は $a+b=n-1$ と $\tr A=d+ar+bs=0$ を解いて得られる。
:::

:::example[次数 57 で整数性を確認する]
Hoffman–Singleton の次数制限で残った $d=57$ を代入すると、$n=3250$、非定数の固有値は $7,-8$ である。その多重度はそれぞれ $1729,1520$ で、和は 3249、$57+7\cdot1729-8\cdot1520=0$ となる。従ってそのグラフを存在しないと結論するには、固有値の多重度が整数であること以外の条件が必要である。
:::

### 補グラフと固有値の対応

強正則グラフの補グラフは次数 $n-d-1$ である。補グラフの隣接対は元で非隣接で、その二頂点を除いた $n-2$ 点のうち少なくとも一方に隣接する点は $2d-\mu$ 個ある。従って補で共通近傍は $n-2-2d+\mu$ 個である。補で非隣接な対は元で隣接であり、自分たちを近傍から除くと少なくとも一方に隣接する点が $2(d-1)-\lambda$ 個なので、補での共通近傍は $n-2d+\lambda$ 個である。よって補も強正則である。

:::example[補グラフの強正則パラメータ]
例えば Petersen グラフの補は $(10,6,3,4)$ である。行列では $\overline A=J-I-A$ なので、定数方向は $n-1-d$、直交補上の各固有値 $\theta$ は $-1-\theta$ に移る。Petersen の場合、補の非定数固有値は $-2$ が 5 個、$1$ が 4 個になる。補で固有値を直接二次式に入れても同じである。
:::

### 固有空間の次元から頂点数を抑える

:::proposition[強正則グラフの多重度による絶対上界]{#prop-comb-srg-absolute-bound}
$G$ とその補グラフがともに連結な強正則グラフを考える。非定数の固有値一つの多重度を $f$ とすると、頂点数は $n\le f(f+3)/2$ である。
:::

:::proof
非定数の固有値を $r>s$ とする。$r>0$、$s<-1$ を先に示す。もし $\mu=d$ なら、非隣接な二点は近傍が同じであり、等しいか非隣接であるという関係が同値関係になる。すると $G$ は完全多部グラフであり、辺があるので補グラフは非連結になる。従って $\mu<d$ であり、強正則性の二次式の定数項が負なので $r>0>s$ である。また $\lambda=d-1$ なら、隣接する二点の閉近傍が同じとなり、連結性から全点が互いに隣接してしまう。従って $\lambda<d-1$ である。強正則性の二次式に $-1$ を入れると $1+\lambda-d<0$ となるため、$s<-1$ を得る。

多重度 $f$ の固有空間への直交射影を $E$ とする。例えば固有値 $r$ への射影は $E=(A-sI-(d-s)J/n)/(r-s)$ であり、$s$ への射影も $r,s$ を交換して書ける。従って $E$ の対角成分はすべて等しく、跡が $f$ なので各成分は $f/n$ である。また、非対角成分は隣接対と非隣接対でそれぞれ一定である。

$e_u$ を頂点 $u$ の座標ベクトルとし、$E e_u$ を $\sqrt{f/n}$ で割った単位ベクトルを $x_u$ とする。$x_u$ は $f$ 次元の固有空間の点であり、二点間の内積は高々二種類 $a,b$ である。相異なる $u,v$ で内積が 1 なら $x_u=x_v$ となり、$E(e_u-e_v)=0$ である。$e_u-e_v$ は定数方向にも直交するため、残りの非定数固有値に属する。しかし $u$ 成分で固有方程式を見れば固有値は $-A_{uv}\in\{0,-1\}$ であり、今示した $r,s$ の範囲から矛盾する。よって $a,b$ は 1 と異なる。

各 $x_u$ に対して二次多項式 $(\langle x_u,x\rangle-a)(\langle x_u,x\rangle-b)$ を取る。これは $x_u$ で非零、他の $x_v$ で零だから、単位球面上の関数として $n$ 個が一次独立である。$f$ 変数の次数 2 以下の多項式は $1+f+f(f+1)/2$ 次元であり、球面上では少なくとも $\sum_i x_i^2-1$ の一つの関係で次元が減る。従って $n\le f+f(f+1)/2$ である。
:::

同じ射影は、さらに行列の成分ごとの積から必要条件を与える。二つの射影 $E,F$ の成分ごとの積は半正定値である。実際、$E_{uv}=\langle Ee_u,Ee_v\rangle$、$F_{uv}=\langle Fe_u,Fe_v\rangle$ だから、その積はベクトル $Ee_u\otimes Fe_u$ の Gram 行列の成分である。グラフの強正則性から積の各成分は対角、隣接、非隣接の三種類で一定であり、$I,A,J$ の一次結合で書ける。従って定数方向と二つの非定数固有空間で固有値を計算し、いずれも非負かを確かめられる。この必要条件を Krein 条件という。

### 次数 3 の実現が一意である理由

直径 2、内周 5 の 3 正則グラフに五角形を一つ取る。外の頂点はその五角形に高々一つしか隣接できない。五角形上の任意の二頂点の距離が高々 2 であり、両方に隣接すると三角形か四角形になるためである。頂点総数は 10、五角形の各頂点には外への辺が一本ずつあるため、外の五頂点はちょうど一人ずつ対応する。外の誘導グラフは各頂点の次数が 2 で、単純な 5 頂点なので一つの五角形に限られる。その辺が元の五角形で対応する隣接対を結ぶと、二つの対応辺と合わせて四角形になる。従って外の辺は元の五角形の非隣接対の位置だけであり、対応関係込みで同型が一意である。これは上の集合モデルの Petersen グラフで実現している。

### パラメータだけで存在の候補を絞る

:::example[五角形の共通近傍から固有値を求める]
$C_5$ の相隣接する二点に共通近傍はなく、非隣接の二点の共通近傍は一つなので、パラメータは $(5,2,0,1)$ である。定数に直交する固有値は $z^2+z-1=0$ の根である。二根の重複度の和は 4 であり、隣接行列のトレースが 0 であることから両方とも 2 重になる。実際、根の和は $-1$ なので、2 重ずつなら定数方向の固有値 2 を消す。二根が異なるため、トレース条件を満たす重複度は一意である。補グラフも $C_5$ であり、非定数固有値を $z\mapsto-1-z$ で写すと二根が入れ替わる。
:::

:::example[正の整数のパラメータを満たしても存在しない]
$(v,k,\lambda,\mu)=(10,3,2,1)$ を候補とする。ある頂点から距離 2 の頂点へ二辺で至る道を数えると、必要な等式 $k(k-\lambda-1)=\mu(v-k-1)$ の左辺は $3(3-2-1)=0$、右辺は 6 なので存在しない。一方 $(9,4,1,2)$ では両辺が 8 で一致する。これは $3\times3$ の升を頂点として、同じ行か同じ列にあれば結んで実現できる。行を共有する隣接二点には行内の残り一点だけが共通近傍である。行も列も異なる二点には、双方の行と列を交差させて得られる二点が共通近傍である。この実現では、距離 2 の道を数える式を辺と共通近傍の両方で照合できる。
:::

## エクスパンダーと Cheeger 不等式

全体がつながっていても、二つの大きな領域を一本の辺だけでつなぐと横断に時間がかかる。小さい側の大きさに対してどれだけ出口があるかを測る。

:::definition[辺拡大率]{#def-comb-expansion}
$n\ge2$ のグラフで $h(G)=\min_{0<|S|\le n/2}|\delta(S)|/|S|$ とする。次数を一様に抑えながら $h(G)$ が正の定数以上であるグラフ族を :term[エクスパンダー]{en="expander graph" yomi="えくすぱんだー"} と呼ぶ。
:::

:::theorem[正則グラフの Cheeger 不等式]{#thm-comb-cheeger}
$d\ge1$ の $d$ 正則グラフでは
$$
\frac{h(G)^2}{2d}\le\lambda_2(L)\le2h(G).
$$
:::

:::proof
上界には $x=\mathbf1_S-(|S|/n)\mathbf1$ を使う。エネルギーは $|\delta(S)|$、平方ノルムは $|S|(1-|S|/n)\ge|S|/2$ なので、$h$ を実現する $S$ で結論を得る。

下界には $\lambda_2$ の零平均固有ベクトル $f$ を取り、符号を反転して正の台の大きさを $n/2$ 以下にする。$f$ は非零で平均 0 なので正と負の値をともに持つ。$g_v=\max(f_v,0)$ とすると、各辺で
$$
(f_u-f_v)(g_u-g_v)\ge(g_u-g_v)^2
$$
である。これは正の部分を取る写像が単調で差を拡大しないためである。辺和を取り、左辺を $\transp{g}Lf=\lambda_2\transp{g}f=\lambda_2\norm{g}^2$ と書けば $\transp{g}Lg\le\lambda_2\norm{g}^2$ である。

$S_t=\{v:g_v^2>t\}$ と置く。各辺が $S_t$ を横切る $t\ge0$ の区間長は $|g_u^2-g_v^2|$ である。各 $S_t$ の大きさは高々 $n/2$ なので
$$
h\norm{g}^2=h\int_0^\infty |S_t|\,\dd t
\le\sum_{uv\in E}|g_u^2-g_v^2|.
$$
右辺に Cauchy–Schwarz を適用すると $\sqrt{\transp{g}Lg}\,\sqrt{\sum_{uv\in E}(g_u+g_v)^2}$ 以下である。第二平方根の中は $\sum_{uv}2(g_u^2+g_v^2)=2d\norm{g}^2$ 以下である。$\norm{g}^2>0$ で割り、二乗して下界を得る。
:::

:::example[長い閉路の切り口]
偶数 $n\ge4$ の $C_n$ では、連続する $n/2$ 頂点の集合のカットに 2 辺しかないので $h\le4/n$ である。他の非空真部分集合も円周を一周するなら出入りが少なくとも一つずつあるため、$h=4/n$ となる。頂点数が増えると拡大率は 0 に近づく。
:::

### 次数を正規化する場合

次数が違うグラフでは、頂点数の代わりに $\operatorname{vol}(S)=\sum_{v\in S}d(v)$ を使う。孤立頂点がないとし、$\operatorname{vol}(S)$ が全体の半分以下の非空集合に対して $|\delta(S)|/\operatorname{vol}(S)$ の最小を $\Phi$ とする。対称行列 $\mathcal L=D^{-1/2}LD^{-1/2}$ の二番目の固有値 $\sigma_2$ に対し、$\Phi^2/2\le\sigma_2\le2\Phi$ となる。

これは :ref[thm-comb-cheeger] の証明で、$\norm{x}^2$ を $\sum_v d(v)x_v^2$ に、零平均条件を $\sum_v d(v)x_v=0$ に置き換えて得る。変数 $y=D^{1/2}x$ を使うと、この商の分子は $\transp{x}Lx$ で、定数ベクトルに対応する固有方向との直交条件は次数付きの零平均である。上界の試験関数を $x=\mathbf1_S-\operatorname{vol}(S)/\operatorname{vol}(V)$ とすれば分母は $\operatorname{vol}(S)(1-\operatorname{vol}(S)/\operatorname{vol}(V))\ge\operatorname{vol}(S)/2$ である。

下界では固有ベクトルを $x$ 座標へ戻した零平均ベクトル $f$ が $Lf=\sigma_2 Df$ を満たす。符号を選んで正の部分 $g$ の台の体積を全体の半分以下とする。差の積の不等式から $\transp{g}Lg\le\sigma_2\sum_v d(v)g_v^2$ である。さらに $S_t=\{v:g_v^2>t\}$ の体積を積分すると $\sum_v d(v)g_v^2$ になる。Cauchy–Schwarz の第二因子の二乗は $\sum_{uv}(g_u+g_v)^2\le2\sum_v d(v)g_v^2$ である。このように正則性でくくった $d$ の代わりに、頂点ごとの次数が直接現れる。$d$ 正則なら $\Phi=h/d,\sigma_2=\lambda_2(L)/d$ となり、元の式に戻る。

:::example[完全グラフでは Cheeger 上界が等号になる]
$K_4$ では大きさ $s\le2$ の集合のカットは $s(4-s)$ 本である。比は $4-s$ なので $h=2$ である。$L=4I-J$ の非零固有値は全て 4 なので、代数的連結度は $2h=4$ に一致する。下界は $h^2/(2d)=2/3$ である。上界と下界のどちらが精密かはグラフによって変わり、この例では上界が精密である。
:::

### 固有値による下界と具体的なカットによる上界

:::example[三角柱の辺膨張率を確定する]
二つの三角形の対応点を一本ずつ結んだ三角柱は 3 正則で、Laplacian の $\lambda_2$ は 2 である。記法 $h=\min_{0<|S|\le n/2}|\partial S|/|S|$ では Cheeger の下側 $\lambda_2/2\le h$ から $h\ge1$ となる。三角形の一方を $S$ に取ると $|S|=3$、境界が対応する三本なので $h\le1$ である。従って $h=1$ が確定する。正規化した膨張率では同じ集合の体積が $3|S|$ になるので値は $1/3$ である。
:::

:::example[閉路では二つの尺度に差がある]
長さ 8 の閉路 $C_8$ では、真に空でない集合の境界には少なくとも二辺がある。閉路に沿って集合内外を移る回数は、入る回数と出る回数が同じだからである。四つの連続点を取れば境界が二辺で $|S|=4$ なので $h=1/2$ である。Laplacian のギャップは $2-2\cos(\pi/4)=2-\sqrt2$ であり、$\lambda_2/2=1-\sqrt2/2$ は $1/2$ より小さい。一般の偶数長 $n$ の閉路でも $h=4/n$、$\lambda_2=2-2\cos(2\pi/n)$ で、前者は $n^{-1}$、後者は $n^{-2}$ の尺度で減る。Cheeger の二つの不等式が同じ次数を与えるとは限らない。
:::

## グラフ上のランダムウォーク

各時刻に隣接先を一様に選ぶと、よく訪れる頂点は次数が大きい。分布がどの速さで均衡するかは、定数方向以外の固有値で決まる。

:::proposition[定常分布と可逆性]{#prop-comb-walk-stationary}
孤立頂点のない連結無向グラフで $P=D^{-1}A$ とし、$\pi_v=d(v)/(2m)$ とする。$\pi$ は定常分布であり、$\pi_u P_{uv}=\pi_v P_{vu}$ が成り立つ。この等式を可逆性という。$P$ は重み付き内積 $\langle f,g\rangle_\pi=\sum_v\pi_v f_vg_v$ で自己共役であり、固有値は $[-1,1]$ に入る。
:::

:::proof
両方向の積は辺なら $1/(2m)$、それ以外は 0 である。片方の添字で足せば定常性が得られ、両方向の等式を内積の定義に入れると自己共役性が従う。また $D^{1/2}PD^{-1/2}=D^{-1/2}AD^{-1/2}$ は実対称である。任意の実固有ベクトルの絶対値最大の座標では、$P$ による出力は隣接先の値の平均だから元の最大絶対値を超えない。よって固有値の絶対値は 1 以下である。
:::

:::theorem[遅延ランダムウォークの収束]{#thm-comb-lazy-walk}
前命題の $P$ に対し $Q=(I+P)/2$ とする。$\pi$ で重みを付けた内積で $\mathbf1$ と直交する空間における最大固有値を $\rho$ とすると $0\le\rho<1$ である。初期分布 $\nu$ から $t$ 歩後の全変動距離は
$$
\frac12\sum_v|(\nu Q^t)_v-\pi_v|
\le\frac12\rho^t\sqrt{\sum_v\pi_v\left(\frac{\nu_v}{\pi_v}-1\right)^2}.
$$
$d$ 正則なら $1-\rho=\lambda_2(L)/(2d)$ である。
:::

:::proof
$P$ の $1$ 固有ベクトルは定数だけである。最大座標の頂点では隣接先の平均がその最大値に等しく、全隣接先も同じ値となる。連結性で全体に広がる。$Q$ の固有値は $(1+\theta)/2$ なので非負であり、定数以外では 1 未満である。

分布の密度 $f_t(v)=(\nu Q^t)_v/\pi_v$ を取る。可逆性により $f_{t+1}=Q f_t$ である。$\sum_v\pi_v(f_0(v)-1)=0$ なので、重み付き内積の固有基底で $\norm{f_t-1}_\pi\le \rho^t\norm{f_0-1}_\pi$ を得る。Cauchy–Schwarz により全変動距離は $\tfrac12\norm{f_t-1}_\pi$ 以下である。正則なら $Q=I-L/(2d)$ なので固有値の順序を反転して最後の式を得る。
:::

:::example[二部性と遅延]
$K_{1,2}$ では $\pi$ は中心に $1/2$、二葉にそれぞれ $1/4$ を置く。中心から始めた通常のウォークは偶数時刻で必ず中心、奇数時刻で必ず葉にいるので収束しない。半分の確率で留まるウォークでは各時刻にこの偶奇の強制がなくなり、定理により定常分布に収束する。
:::

### 初めて到達するまでの時間

連結な無向グラフで、頂点 $t$ に初めて達するまでの期待歩数を $h^t(v)$ とする。有限であることは、各 $v$ から長さ高々 $n-1$ の道に従う確率に、全 $v$ 共通の正の下限があることから分かる。$n-1$ 歩ごとにこの下限を使うと、生き残り確率は幾何級数で抑えられる。最初の一歩で条件分けすると
$$
h^t(t)=0,\qquad
h^t(v)=1+\frac{1}{d(v)}\sum_{u\in N(v)}h^t(u)
\quad(v\ne t)
$$
である。解の一意性は、二解の差が $t$ で 0、他点で隣接値の平均となることから従う。もし差の最大が正ならその最大値は隣接先に伝播し、連結性により $t$ にも達して矛盾する。負の最小にも符号を反転して同じ議論を使う。

電流を $s$ で一単位注入し $t$ で取り出すとき、各辺の抵抗を 1 とし、頂点電位 $v$ を $Lv=e_s-e_t$ で定める。右辺は定数ベクトルに直交するので、:ref[prop-comb-laplacian-kernel] で解は定数の差を除いて一意である。電位差 $R(s,t)=v_s-v_t$ を有効抵抗という。辺 $uw$ の $u$ から $w$ への電流を $v_u-v_w$ とすれば、その頂点ごとの流出の合計が $Lv$ なので方程式は収支を表している。

:::proposition[往復時間と有効抵抗]{#prop-comb-commute-time}
連結な有限無向グラフの相異なる二頂点について
$$
h^t(s)+h^s(t)=2mR(s,t)
$$
である。
:::

:::proof
期待歩数の式から $v\ne t$ で $(Lh^t)_v=d(v)$ である。$L$ の全行の和は 0 ベクトルなので、$t$ の成分は総和を 0 にする値になる。従って $Lh^t=d-2m e_t$ である。ここで $d$ は次数ベクトルである。同様に $Lh^s=d-2m e_s$ である。差を取れば $h^t-h^s$ は単位電流の電位の $2m$ 倍と定数の差しかない。$s,t$ で値の差を取れば $h^t(t)=h^s(s)=0$ により式が得られる。
:::

:::example[三角形の往復]
三角形で $t$ の電位を 0 とすると、残り二頂点の電位は $\begin{pmatrix}2&-1\\-1&2\end{pmatrix}v=\transp{(1,0)}$ を解いて $2/3,1/3$ となる。$R(s,t)=2/3$ なので往復の期待時間は $6\cdot2/3=4$ である。対称性で各方向 2 歩であり、各歩で $t$ でない頂点から $t$ を選ぶ確率が $1/2$ という直接計算とも一致する。
:::

### 時刻の偶奇と、定常分布に収束する条件

遅延ウォークでは固有値を $[0,1]$ へ移した。通常のウォークで収束が妨げられる場合を決めるには、固有値 $-1$ が現れる条件を調べればよい。

:::proposition[通常のランダムウォークの収束と二部性]{#prop-comb-walk-aperiodic}
有限で連結な無向グラフに少なくとも一本の辺があるとする。通常のランダムウォークについて $-1$ が固有値であることと、グラフが二部であることは同値である。グラフが二部でなければ任意の初期分布から定常分布に収束する。グラフが二部の場合、任意の一点から始めた分布は定常分布に収束しない。
:::

:::proof
$Pf=-f$ なら $(D+A)f=0$ なので、
$$
0=\transp{f}(D+A)f=\sum_{uv\in E}(f_u+f_v)^2
$$
である。従って辺を渡るたびに値は符号だけ変わる。ある頂点で零でなければ、連結性で全頂点の絶対値が同じ非零値になり、正と負の頂点が二部分割を与える。逆に二部なら一方を $+1$、他方を $-1$ とした関数が $-1$ の固有関数になる。

二部でない場合は、定数以外の固有値がすべて絶対値 1 未満である。最初に分布を $\pi$ で割って密度に直し、可逆性を使うと、その密度は $P$ を順に掛けて得られる。密度のうち定数 1 を除いた成分は各固有値の冪で減衰するので収束する。一方二部なら、端点から始めて一歩ごとに部が交代する。どちら側の次数和も $m$ で定常確率は $1/2$ ずつだから、一方の部に確率が集中した分布は、各時刻で定常分布と少なくとも $1/2$ の全変動距離を持つ。
:::

:::example[三角形で通常のウォークを追う]
$K_3$ の一頂点を $s$ とし、$s$ に戻っている確率を $p_t$ とする。時刻 $t$ に $s$ 以外にいれば次の歩で $1/2$ の確率で $s$ へ進むので $p_{t+1}=(1-p_t)/2$ である。この式を定常値 $1/3$ からのずれで書き直すと
$$
p_t=\frac13+\frac23(-1/2)^t
$$
となる。$t=0,1,2,3$ で $1,0,1/2,1/4$ となるので、定常値の両側を交互に通って収束する。負の固有値が存在しても、絶対値が 1 より小さければ揺れは消える。
:::

### 流れのエネルギーを最小にする

一本道を電流が流れる場合は、有効抵抗を辺の本数から求められる。複数の道がある場合は、二経路にどう電流を分けるかで必要な電位差が変わる。ランダムウォークの往復時間と対応させるため、まず各辺の抵抗を 1 とした場合の最小化を示す。

:::proposition[有効抵抗の変分表示]{#prop-comb-resistance-variational}
各辺にあらかじめ一つの向きを選び、$F_{uv}$ をその向きに流れる符号付きの量とする。各頂点で流出から流入を引いた差を $\operatorname{div}F$ と書く。同じ連結成分の相異なる $s,t$ について
$$
R(s,t)=\min_{\operatorname{div}F=e_s-e_t}\ \sum_{uv\in E} F_{uv}^2
$$
である。また
$$
\frac1{R(s,t)}=\min_{g_s=1,\,g_t=0}\ \sum_{uv\in E}(g_u-g_v)^2
$$
である。
:::

:::proof
$Lv=e_s-e_t$ を解き、$t$ での値を 0 とする。電位差から作る流れ $F^*_{uv}=v_u-v_v$ は $\operatorname{div}F^*=Lv$ を満たす。他の許容流れ $F$ との差 $U=F-F^*$ は各点で収支が零なので、
$$
\sum_{uv\in E}(v_u-v_v)U_{uv}
=\sum_w v_w(\operatorname{div}U)_w=0
$$
である。この等式は各辺の二つの端点への寄与を集めると得られる。従って $\sum_e F_e^2=\sum_e(F_e^*)^2+\sum_e U_e^2$ である。$\sum_e(F_e^*)^2=\transp{v}Lv=v_s-v_t=R(s,t)$ だから、単位流れの最小値が分かる。

この値は正である。もし零なら $\operatorname{div}F^*=e_s-e_t$ を満たす流れが全辺で零になるためである。そこで $g^*=v/R(s,t)$ とおくと $g_s^*=1,g_t^*=0$ を満たす。他の許容電位との差 $h=g-g^*$ は $s,t$ で零である。二つの電位差の積を全辺で足すと $\transp{h}Lg^*=(h_s-h_t)/R(s,t)=0$ となる。よって電位差の二乗和も $g^*$ の値と $h$ の値の和になり、最小は $g^*$ で達する。その値は $\transp{g^*}Lg^*=R(s,t)/R(s,t)^2=1/R(s,t)$ である。
:::

:::example[二経路に電流を分ける]
六角形で隣接する $s,t$ を選ぶと、長さ 1 と長さ 5 の二経路がある。中間の頂点での収支は零なので、各経路に流れる電流はその経路の各辺で一定である。短い経路に $x$、長い方に $1-x$ を流すと二乗和は $x^2+5(1-x)^2$ であり、$x=5/6$ で最小値 $5/6$ になる。往復時間は $2\cdot6\cdot(5/6)=10$ であり、両方向が対称なので片道の期待時間は 5 である。
:::

:::example[余分な枝を加えると何が変わるか]
$P_4$ で両端を $s,t$ とすると、単位流れは三辺をすべて一単位ずつ流れるので抵抗は 3、往復時間は $2\cdot3\cdot3=18$ である。道の中央に葉を一枚付けても、葉での収支が零なので、新しい辺の電流は零である。抵抗は 3 のままだが、全辺数は 4 になり往復時間は 24 へ増える。ウォークは葉へそれて戻ることがあり、その時間が加わる。
:::

### 固有値から分布の距離を評価する

:::proposition[全変動距離の固有値評価]{#prop-comb-walk-tv-spectral}
辺を一つ以上持つ連結な無向グラフの遅延ランダムウォークを $Q$、定常分布を $\pi$ とする。点 $s$ から時刻 $t$ の分布を $p_t$、$\pi$ で重みを付けた内積で定数に直交する部分での $Q$ の最大固有値を $\theta$ とすると、
$$
\frac12\sum_v|p_t(v)-\pi(v)|\le\frac12\theta^t\sqrt{\frac1{\pi(s)}-1}.
$$
:::

:::proof
比の偏差を $g_t(v)=p_t(v)/\pi(v)-1$ とする。詳細釣合い $\pi(u)Q(u,v)=\pi(v)Q(v,u)$ により、$\sum_u p_t(u)Q(u,v)/\pi(v)=\sum_u Q(v,u)p_t(u)/\pi(u)$ なので $g_{t+1}=Qg_t$ である。$\sum_v\pi(v)g_t(v)=0$ だから、重み付き内積で定数に直交する。遅延によってすべての固有値は非負であり、直交固有基底に分解して $\norm{g_t}_{2,\pi}\le\theta^t\norm{g_0}_{2,\pi}$ を得る。初期値は $g_0(s)=1/\pi(s)-1$、他点では $-1$ なので、平方ノルムは $1/\pi(s)-1$ である。最後に Cauchy–Schwarz により $\sum_v \pi(v)|g_t(v)|\le\norm{g_t}_{2,\pi}$ として上界を得る。
:::

:::example[完全グラフで係数を比較する]
$K_4$ では通常の遷移行列が $(J-I)/3$ で、遅延版 $Q=(I+P)/2$ は定数直交空間で固有値 $1/3$ を持つ。従って始点を $s$ にした分布は $\pi+3^{-t}(\delta_s-\pi)$ と正確に書ける。全変動距離は $(3/4)3^{-t}$ であり、評価式は $(\sqrt3/2)3^{-t}$ を与える。両方の減少率は同じだが、定数は Cauchy–Schwarz を使った評価の方が大きい。この例ではすべての非定数方向が同じ率で減るため、分布自身も一つの幾何級数で表せる。
:::

## 演習問題

::::exercise{level=basic}
$K_5$ の隣接行列の固有値の二乗和を求めよ。
:::solution
固有値は 4 が一つと $-1$ が四つなので $16+4=20$ である。握手補題では辺が 10 本で、閉歩道の二歩の個数としても 20 になる。
:::

::::exercise{level=basic}
$K_{1,9}$ の隣接スペクトルを求めよ。
:::solution
中心と全葉一定の二次元部分空間で固有値は $\pm\sqrt9=\pm3$ である。葉の座標和 0 で中心が 0 の空間は次元 8 なので、固有値 0 が八つ残る。
:::
::::

::::exercise{level=advanced}
$K_4$ の一辺を消したときの三角形数を求め、隣接行列の三乗トレースを与えよ。
:::solution
元は $\binom43=4$ 個である。消した辺を含む三角形は残り二頂点を第三頂点とする 2 個なので 2 個残る。各三角形が 6 を寄与するのでトレースは $12$ である。
:::
::::

::::exercise{level=basic}
孤立頂点一つと $K_3$ の非交和について Laplacian の固有値を求めよ。
:::solution
$K_3$ のブロックは $3I-J$ で、固有値は $0,3,3$ である。孤立頂点のブロックは 0 なので全体は $0,0,3,3$ である。0 の多重度は成分数 2 と一致する。
:::
::::

::::exercise{level=advanced}
$(50,7,0,1)$ の強正則グラフで非自明固有値の多重度を求めよ。
:::solution
二次式は $x^2+x-6=0$ で根は $2,-3$ である。多重度を $a,b$ とすると $a+b=49$、$7+2a-3b=0$ であり、これを解いて $a=28,b=21$ になる。
:::
::::

::::exercise{level=advanced}
$K_{r,r}$ の辺拡大率を $r=4$ で求めよ。
:::solution
$S$ の左右の大きさを $a,b$、$s=a+b$ とするとカットの辺数は $4s-2ab$ である。$ab\le s^2/4$、$s\le4$ から比は $4-2ab/s\ge4-s/2\ge2$。$a=b=2$ で等号なので $h=2$ である。
:::
::::

::::exercise{level=basic}
道 $P_4$ の単純ランダムウォークの定常分布を求めよ。
:::solution
次数は $1,2,2,1$ で和は 6 である。従って道に沿う順に $(1/6,1/3,1/3,1/6)$ が定常分布になる。端と中央で同じ確率になるわけではない。
:::
::::

::::exercise{level=advanced}
$n\ge2$ の $K_n$ で遅延ウォークの $\rho$ を求めよ。
:::solution
$P=A/(n-1)$ で、定数直交補上の $A$ の固有値は $-1$ である。従って $Q$ の非定数固有値は $\frac12(1-1/(n-1))=(n-2)/(2(n-1))$ だけであり、これが $\rho$ である。
:::
::::

::::exercise{level=advanced}
$K_{3,3}$ の隣接固有値と Laplacian 固有値を全て求める。さらに、遅延ランダムウォークで一点から出発したときの全変動距離の固有値上界を式で表せ。

:::solution
二部間の行列 $B$ は全 1 の三次行列であり、$BB^\mathsf{T}$ の正固有値は 9 が一つである。隣接固有値は $3,-3$ と四重の 0 である。正則次数が 3 なので $L=3I-A$ の固有値は 0、6、四重の 3 となる。遅延ウォークでは固有値 $\lambda$ が $\frac12(1+\lambda/3)$ に移るので、定数に直交する部分では 0 と四重の $1/2$ である。定常分布は一様で各点 $1/6$ だから、全変動距離は $\frac{\sqrt5}{2}\,2^{-t}$ 以下である。遅延を入れない場合は $-3$ が固有値 $-1$ に移るため、二部を交互に訪れ、一点からの分布は定常分布へ収束しない。
:::
