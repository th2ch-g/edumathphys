## この章の目標

- 収束に頼らず、係数ごとに級数を演算する。
- 通常母関数と指数型母関数を使い分ける。
- Lagrange 反転で暗黙的な漸化式から係数を取り出す。
- 五角数定理から分割数の漸化式を導く。
- 有限状態を転送行列で表す。

## 形式的べき級数環

級数は数列を一つの記号にまとめる。$x$ を数値に置き換える必要がなければ、各次数の係数が有限回の計算で決まるかを確認すればよい。

:::definition[形式的べき級数]{#def-comb-formal-series}
単位元をもつ可換環 $R$ に対し、係数列 $(a_0,a_1,\dots)$ を $\sum_{n\ge0}a_nx^n$ と書き、:term[形式的べき級数]{en="formal power series" yomi="けいしきてきべききゅうすう"} と呼ぶ。$[x^n]F=a_n$ と書く。$R[[x]]$ では和を成分ごとに、積を $[x^n](FG)=\sum_{j=0}^n a_jb_{n-j}$ で定める。
:::

:::proof[環の演算の整合性]
係数の和と積は $R$ の有限和と積である。結合律は積三つの $n$ 次係数が添字 $i+j+k=n$ の同じ有限和になることから従う。分配律と可換性も各係数に $R$ の法則を適用すればよい。定数級数 1 が乗法単位元である。
:::

:::proposition[逆元と合成]{#prop-comb-series-operations}
$F=\sum_na_n x^n$ が逆元をもつ必要十分条件は $a_0$ が単元であること。$G(0)=0$ なら $F(G)$ は定義できる。さらに $G(0)=0$ かつ $[x]G$ が単元ならば、両側の合成逆元が一意に存在する。
:::

:::proof
$FB=1$ の定数項から $a_0b_0=1$ が必要である。$b_0=a_0^{-1}$ とし、$n\ge1$ で $b_n=-a_0^{-1}\sum_{j=1}^na_jb_{n-j}$ と定めれば十分である。$G^k$ は次数 $k$ 未満を持たないので $F(G)$ の各係数は有限個の項だけで決まる。

$G(H)=x$ を $H(0)=0$ で解くと、次数 $n\ge1$ の式は $[x]G\cdot[x^n]H$ と既知の低次係数だけからなる。よって逐次一意に解ける。得られた $H$ の一次係数も単元であり、同じ構成で $H(J)=x$ を解けば $J=G(H(J))=G$ となる。合成の結合律は、各次数で式を切れば有限の多項式の代入で確かめられる。
:::

:::example[解析的な収束を要しない級数]
$\sum_{n\ge0}n!x^n$ は形式的な級数である。数値 $x\ne0$ では項の絶対値の比が $(n+1)|x|$ になり、項が 0 に近づかない。一方、$1-x$ を掛けたときの係数は $n\ge1$ で $n!-(n-1)!$ と決まる。
:::

:::example[有限打切りによる逆元]
$(1-2x-x^2)^{-1}$ の 3 次までの係数は $1,2,5,12$ である。逆元を $b_n$ とすれば $b_n=2b_{n-1}+b_{n-2}$、$b_0=1,b_{-1}=0$ だからである。
:::

### 微分、対数、冪

係数を番号 $n$ 倍してから一段下げる操作を形式微分という。積の係数に $(i+j)$ を掛けると $i$ を掛けた和と $j$ を掛けた和に分かれるため、積の微分則が成り立つ。合成で内側の級数の定数項が 0 なら、各次数は有限の打切りで計算できる。単項式の微分則を適用し有限和を取ると、合成の連鎖則も成り立つ。

標数 0 の係数体で $F(0)=0$ なら $\exp F=\sum_{k\ge0}F^k/k!$、$\log(1+F)=\sum_{k\ge1}(-1)^{k-1}F^k/k$ を定義できる。前者の微分は $F'\exp F$、後者は $F'/(1+F)$ であり、単項式を微分してそれぞれ指数級数と幾何級数に戻す。$\log(\exp F)$ の微分は $F'$ と同じで定数項も 0 なので $\log(\exp F)=F$ である。また $\exp(\log(1+F))/(1+F)$ は微分が 0 で定数項 1 なので $\exp(\log(1+F))=1+F$ である。標数 0 の仮定は、微分が 0 なら定数という事実と、$k$ や $k!$ での除算に使う。

:::example[式を微分して係数を移す]
$F=(1-x)^{-1}=\sum_{n\ge0}x^n$ とすると $xF'=x/(1-x)^2=\sum_{n\ge0}nx^n$ である。さらに $x(xF')'=x(1+x)/(1-x)^3$ となり、これは $\sum_{n\ge0}n^2x^n$ である。従って後者の 5 次係数は $25$ になる。通常の微積分の式と同じ見かけでも、$x$ の値は使っていない。
:::

:::example[指数と対数の三次打切り]
$\exp(x+x^2)$ を 3 次まで求める。一次の項 $F$ は $x+x^2$、$F^2/2$ は $x^2/2+x^3$、$F^3/6$ は $x^3/6$ を寄与するので $1+x+\frac32 x^2+\frac76x^3$ となる。この級数の定数項 1 を除いた $G$ を $\log(1+G)=G-G^2/2+G^3/3+\cdots$ に入れると、二次係数が $3/2-1/2=1$、三次係数が $7/6-3/2+1/3=0$ に戻る。
:::

### 無限和と無限積を打ち切る位置

級数 $F$ が最初に非零の係数をもつ次数を $\nu(F)$ と書き、$F=0$ なら $\nu(F)=\infty$ とする。係数環が整域なら $\nu(FG)=\nu(F)+\nu(G)$ である。実際、両方の最初の非零項の積は、その次数に寄与できる唯一の項であり、整域なので非零である。零因子がある環では積の次数はこれより上がることがある。例えば $\Z/4\Z$ で $(2x)^2=0$ になる。

級数列 $F_j$ に対し、どの固定次数 $d$ でも $\nu(F_j)\le d$ の $j$ が有限個なら、$\sum_j F_j$ が定義できる。各次数を計算する際、和を有限個に限ってよいからである。同じ条件で各 $F_j(0)=0$ とすれば、$\prod_j(1+F_j)$ も定義できる。第 $d$ 係数を求めるとき、$\nu(F_j)>d$ の因子は 1 に置き換えても低次項に影響しない。任意の次数で結果が安定するという意味であり、数値代入の収束条件と違う。

:::example[高次の因子が低次に寄与しない]
$\prod_{j\ge1}(1+x^{2^j})$ の $x^{10}$ の係数を求める。使える指数は $2,4,8$ のみであり、$10=8+2$ と一通りに書けるため答えは 1 である。一般に $j=0$ から始めれば、どの非負整数も二進表示が一意なので全ての係数が 1 になる。これは形式的な恒等式
$$
\prod_{j\ge0}(1+x^{2^j})=(1-x)^{-1}
$$
を与える。代数的にも $(1-x)\prod_{j=0}^{m}(1+x^{2^j})=1-x^{2^{m+1}}$ であり、固定次数では $m$ が大きくなると最後の項が消える。
:::

### 合成逆元を有限次数まで求める

$U(t)=t+t^2$ とすると、逆級数 $W=x+a x^2+b x^3+c x^4+\cdots$ は $W+W^2=x$ を満たす。二次係数の比較で $a+1=0$、三次で $b+2a=0$、四次で $c+a^2+2b=0$ となる。従って $W=x-x^2+2x^3-5x^4+\cdots$ である。$\Q$ 上の形式級数としては $(\sqrt{1+4x}-1)/2$ とも表せる。平方根は定数項が 1 の枝に対応し、方程式 $(1+2W)^2=1+4x$ から分かる。各係数が順に決まる点は、二次方程式の公式を使わなくても証明できる。

合成逆元に必要なのは一次係数が単元であることである。例えば $\Q$ 上で $U(t)=2t$ の逆級数は $x/2$ である。例えば $U=t^2$ では定数項 0 の $W$ を代入しても $U(W)$ の一次係数は 0 である。従って合成逆元は存在しない。乗法逆元の条件が定数項であるのに対し、定数項 0 の合成逆元では一次係数を調べる。

### 係数の比較で平方根を取る

形式級数に平方根を取るときは、定数項を先に選ぶ。高次の項は、すでに決まった低次の項から順に求められる。

:::proposition[単元の冪根]{#prop-comb-series-root}
標数 0 の体 $K$ 上で、$F(0)=1$ とする。整数 $r\ge1$ に対し、$H(0)=1$ かつ $H^r=F$ を満たす $H\in K[[x]]$ は一意に存在する。
:::

:::proof
$H=1+\sum_{n\ge1}h_nx^n$ と書く。積 $H^r$ の $n$ 次係数では、一つの因子から $h_nx^n$ を取る場合が $r$ 通りある。残りの項は $h_1,\dots,h_{n-1}$ のみを使う。従って $h_n$ には一次方程式が成り立ち、その係数 $r$ は可逆である。$n=1$ から順に解けば全次数で係数が一致し、同じ方程式が解の一意性を示す。
:::

:::example[平方根の最初の四項]
$H^2=1-4x$、$H(0)=1$ とすると、一次から三次までの式は $2h_1=-4$、$2h_2+h_1^2=0$、$2h_3+2h_1h_2=0$ となる。従って $H=1-2x-2x^2-4x^3+\cdots$ である。四次では $2h_4+2h_1h_3+h_2^2=0$ なので $h_4=-10$ となる。後で $C=1+xC^2$ を解くときは $(1-H)/(2x)$ を選ぶ。この式は分子の定数項が消えるので形式級数として解釈できる。
:::

## 通常母関数と線形漸化式

$n$ 個分の対象を、長さ $k$ の前半と長さ $n-k$ の後半に分けると、両者の計数を掛けて $k$ で足す。この畳み込みが級数の積に一致する。

:::definition[通常母関数]{#def-comb-ogf}
数列 $(a_n)$ の :term[通常母関数]{en="ordinary generating function" yomi="つうじょうぼかんすう"} を $A(x)=\sum_{n\ge0}a_nx^n$ とする。
:::

:::proposition[定数係数漸化式]{#prop-comb-ogf-linear}
$d\ge1$ とし、$a_n=\sum_{j=1}^dc_ja_{n-j}$ が $n\ge d$ で成り立つとする。$Q=1-\sum_{j=1}^dc_jx^j$ とすると $QA=P$ は次数 $d$ 未満の多項式であり、$[x^n]P=a_n-\sum_{j=1}^{n}c_j a_{n-j}$ が $n<d$ で成り立つ。逆に $QA=P$ なら $n>\deg P$ で同じ係数比較が漸化式を与える。負の添字の $a_n$ は 0 とする。
:::

:::proof
積の規則から $[x^n](QA)=a_n-\sum_{j=1}^dc_ja_{n-j}$ である。高次側の消滅と漸化式は同じ式の二つの読み方である。
:::

:::example[Fibonacci 数列]
$F_0=0,F_1=1,F_n=F_{n-1}+F_{n-2}$ の級数は $x/(1-x-x^2)$ である。$\alpha=(1+\sqrt5)/2$、$\beta=(1-\sqrt5)/2$ とすると
$$
\frac{x}{1-x-x^2}=\frac{1}{\alpha-\beta}
\left(\frac{1}{1-\alpha x}-\frac{1}{1-\beta x}\right).
$$
幾何級数から $F_n=(\alpha^n-\beta^n)/\sqrt5$ である。例えば $F_6=8$ となる。
:::

:::example[重根]
$(1-x)^{-2}$ の $n$ 次係数は $\sum_{j=0}^n1=n+1$ であり、$[x^4]$ は $5$ である。一般に $(1-x)^{-r}$ は $r$ 個の幾何級数の積であり、:ref[prop-comb-stars-bars] から係数は $\binom{n+r-1}{r-1}$ である。したがって分母を因数分解して部分分数を取ると、根の重複度は係数列の多項式因子に反映される。
:::

### 漸化式に外力や和がある場合

定数係数の漸化式でも、右辺に別の数列が加わる場合には、その数列の母関数を一緒に残す。たとえば $a_0=0$、$a_n=2a_{n-1}+n$ なら、$n\ge1$ で和を取って $(1-2x)A=x/(1-x)^2$ になる。部分分数分解は
$$
A=\frac{2}{1-2x}-\frac{1}{1-x}-\frac{1}{(1-x)^2}
$$
なので $a_n=2^{n+1}-n-2$ である。$n=4$ で値は $26$ となり、元の系でも $a_1=1,a_2=4,a_3=11,a_4=26$ になる。

部分和列 $s_n=\sum_{j=0}^na_j$ の母関数は $A/(1-x)$ である。幾何級数との積で、$x^n$ の係数が各 $j\le n$ に対し $a_j$ を一度ずつ足すからである。逆に隣り合う部分和の差は $(1-x)$ 倍で求まる。初項を $s_{-1}=0$ としておけば、$n=0$ でも同じ式が成り立つ。

:::example[三つの硬貨額を使う配分]
額面 1, 2, 5 の硬貨を何枚でも使うとする。合計額を $n$ とする方法数の母関数は
$$
\frac{1}{(1-x)(1-x^2)(1-x^5)}
$$
である。$n=10$ のとき 5 の枚数は $0,1,2$ であり、残りを 1,2 で払う方法はそれぞれ $6,3,1$ 通りで、計 $10$ 通りである。選んだ硬貨を出す順番まで区別するなら、各手が 1,2,5 のいずれかとなるので、級数は $\sum_{\ell\ge0}(x+x^2+x^5)^\ell$ に変わる。
:::

### 部分分数を係数列に直す

$\C$ 上の有理級数 $A=P/Q$ で $Q(0)=1$ を考える。$P,Q$ を約分して分母を $\prod_j(1-\alpha_jx)^{m_j}$ と因数分解する。まず多項式部分を割り算で除き、真分数を
$$
\sum_j\sum_{\ell=1}^{m_j}\frac{b_{j,\ell}}{(1-\alpha_jx)^\ell}
$$
と表す。ここで $\alpha_j$ は相異なる非零数である。この部分分数表示は次のように確かめられる。 $Q$ の次数を $d$ とすると、各分数に $Q$ を掛けたものは $d$ 未満の多項式で、個数が $d$ である。線形関係があれば、ある $j$ の最大の極次数の候補について足し合わせた分数に $(1-\alpha_jx)^\ell$ を掛け、$x=1/\alpha_j$ と置く。他の候補が消え、その係数が 0 になる。繰り返すと全係数が 0 であり、これらは次数 $d$ 未満の空間の基底になる。従って任意の余りを展開できる。

幾何級数の $\ell$ 乗から
$$
[x^n](1-\alpha x)^{-\ell}=\binom{n+\ell-1}{\ell-1}\alpha^n
$$
である。従って各根は、$n$ の多項式を前に掛けた指数列を生む。多項式部分は有限個の初期係数にだけ寄与する。例えば $A$ を約分した後の分母に $(1-2x)^2$ が残れば、その根から $2^n$ と $(n+1)2^n$ の寄与が出る。約分前の式で分かるのは候補であり、実際に残る項は分子を見て決める。

:::example[単根と重根の両方をもつ漸化式]
$$
A(x)=\frac{1}{(1-2x)^2(1-x)}
$$
とする。部分分数を求めるため、分母を掛けて定数、一次、二次を比較すると
$$
A=\frac{1}{1-x}-\frac{2}{1-2x}+\frac{2}{(1-2x)^2}
$$
になる。よって $a_n=1-2^{n+1}+(n+1)2^{n+1}=1+n2^{n+1}$ である。$a_0=1,a_1=5,a_2=17,a_3=49$ となる。分母は $1-5x+8x^2-4x^3$ なので、$a_3=5\cdot17-8\cdot5+4\cdot1=49$ で検算できる。指数の底が 2 の項が二つあっても、重根に対応する $n2^n$ は単なる定数倍ではない。
:::

### ひとつの極が主な増え方を決める

約分後の部分分数で、$|\alpha_*|$ が他の全てより大きく、$\alpha_*>0$ とする。対応する最大次数を $m$ とし、$b_{*,m}\ne0$ とする。このとき
$$
a_n\sim\frac{b_{*,m}}{(m-1)!}n^{m-1}\alpha_*^n
$$
である。同じ $\alpha_*$ の低い次数は $n$ の次数が少なくとも一つ小さい。$|\alpha_j|<\alpha_*$ の他の指数列は、比を取ると多項式に $|\alpha_j/\alpha_*|^n$ が掛かり 0 に近づく。二項係数の最高次項は $n^{m-1}/(m-1)!$ であり、これで漸近式が得られる。前の例では $b_{*,2}=2,\alpha_*=2$ なので $a_n\sim 2n2^n$ である。

絶対値が最大の特性根が複数あるときは、対応する極の位数も比べる。同じ位数なら係数への寄与の尺度がそろい、位数が大きい方は $n$ の高い冪を伴う。例えば $(1-x^2)^{-1}$ の二つの根は指数列 $1,(-1)^n$ を生み、係数は $(1+(-1)^n)/2$ である。奇数と偶数で値が変わり、単一の定数倍として漸近式を書くことはできない。周期を持つ状態の計数にこのような現象が現れる。

:::example[部分和は根を一つ追加しうる]
$a_n=2^n$ なら $A=1/(1-2x)$ で、部分和の級数は $1/((1-x)(1-2x))$ である。部分分数分解は $2/(1-2x)-1/(1-x)$ なので、和は $2^{n+1}-1$ である。$a_n=1$ の場合には、もとの根 $1$ が重根に変わり、和は $n+1$ となる。同じ $1/(1-x)$ を掛ける操作でも、もとの分母にその因子があるかで係数の形は異なる。
:::

### 畳み込みから漸化式を作る

既知の列を入力とする漸化式では、初期値の効果と各時刻の入力の効果を分けて読める。

:::example[時刻ごとに入る増分を追う]
$a_0=0$、$a_n=2a_{n-1}+n$ とする。$A(x)=\sum_n a_nx^n$ を用いれば $(1-2x)A=x/(1-x)^2$ である。従って
$$
A=\frac{2}{1-2x}-\frac{2}{1-x}-\frac{x}{(1-x)^2},
\qquad a_n=2^{n+1}-2-n .
$$
有理式を求めた後には、各時刻 $j$ の入力 $j$ が、$n-j$ 回の更新を経て $j2^{n-j}$ になると読める。例えば $n=4$ では $8+8+6+4=26$ である。初期値が $a_0=c$ に変われば、入力は同じなので差は $c2^n$ となる。
:::

:::example[Fibonacci 数の畳み込みとずらし]
$F_0=0,F_1=1$ とし、$F_{n+2}=F_{n+1}+F_n$ とする。$G(x)=x/(1-x-x^2)$ である。$b_n=\sum_{j=0}^n F_jF_{n-j}$ の母関数は $G^2$ で、分母は $1-2x-x^2+2x^3+x^4$ になる。従って $n\ge4$ では $b_n=2b_{n-1}+b_{n-2}-2b_{n-3}-b_{n-4}$ となる。初めの項は $0,0,1,2$ であり、続いて $5,10,20$ を得る。例えば $b_6=1\cdot5+1\cdot3+2\cdot2+3\cdot1+5\cdot1=20$ である。
:::

## 指数型母関数

ラベル付きの対象では、前半に入れるラベルを選ぶ $\binom nk$ 通りが積に加わる。係数を $n!$ で割ると、この因子を自動的に組み込める。

:::definition[指数型母関数]{#def-comb-egf}
$\Q$ 上で数列 $(a_n)$ に対応する $\sum_{n\ge0}a_n x^n/n!$ を :term[指数型母関数]{en="exponential generating function" yomi="しすうがたぼかんすう"} という。
:::

:::proposition[ラベル付き積と集合]{#prop-comb-egf-set}
指数型母関数 $A,B$ の積の $n! [x^n]$ は $\sum_{j=0}^n\binom nj a_j b_{n-j}$ である。各ブロックに $A$ の構造を載せた空でないラベル付きブロックの集合を数える級数は $\exp A$ となる。ただし $A(0)=0$ とする。
:::

:::proof
$1/(j!(n-j)!)=\binom nj/n!$ を係数積に代入する。積を繰り返すと $A^k$ は $k$ 個の順序付きブロックを数える。ブロックは非空でラベル集合が互いに素なので、ブロック順を忘れる写像の各逆像は $k!$ 個である。$\sum_{k\ge0}A^k/k!$ はブロック数をすべて足した式である。
:::

:::example[集合分割と巡回置換]
非空部分集合一つの級数は $e^x-1$ である。ゆえに $k$ ブロックへの分割の指数型母関数は $(e^x-1)^k/k!$、Bell 数では $\exp(e^x-1)$ になる。4 元の場合、$4![x^4](e^x-1)^2/2=7$ である。

長さ $j$ の巡回置換は $(j-1)!$ 個なので、その級数は $\sum_{j\ge1}x^j/j$ である。固定点を許さないと $j=1$ を外すから、攪乱順列の級数は $e^{-x}/(1-x)$ になる。ここで $\exp(\sum_{j\ge1}x^j/j)=(1-x)^{-1}$ は両辺が定数項 1 で、形式微分により同じ方程式 $(1-x)y'=y$ を満たすことから分かる。例えば $3![x^3]e^{-x}/(1-x)=2$ である。
:::

### ブロック数と巡回数を記録する二変数級数

ブロック数 $k$ に $u^k$ の重みを付けると、集合分割の式は
$$
\sum_{n,k}S(n,k)u^k\frac{x^n}{n!}
=\exp\bigl(u(e^x-1)\bigr)
$$
となる。各ブロックに重み $u$ を一つ掛けて :ref[prop-comb-egf-set] を用いる。$u$ で微分すると指定一ブロックの選択を記録し、$x$ で微分すると指定一ラベルを含む構造を記録する。後者では $(x^n/n!)'=x^{n-1}/(n-1)!$ となるので、指定ラベルを取り除いた大きさで比較できる。

符号なし第 1 種 Stirling 数では、各巡回に $u$ を掛けると
$$
\sum_{n,k}c(n,k)u^k\frac{x^n}{n!}
=\exp\left(u\sum_{j\ge1}\frac{x^j}{j}\right)
=(1-x)^{-u}
$$
を得る。最後の式は $\exp(-u\log(1-x))$ の略記であり、$u$ を任意の数に固定する必要はない。例えば $u=2$ とすれば $[x^4]$ は $5$ であり、$\sum_k c(4,k)2^k=4!\cdot5=120$ になる。一方、$u=0$ の場合は空置換だけを残す。

:::example[偶数サイズの組への分割]
ブロックの大きさを偶数に限ると一ブロックの指数型母関数は $\sum_{j\ge1}x^{2j}/(2j)!=\cosh x-1$ である。6 元を偶数ブロックに分ける方法は、型 $6$ が 1、$4+2$ が $\binom62=15$、$2+2+2$ が $6!/(2!^3\,3!)=15$ であり、合計 31 である。級数でも $6![x^6]\exp(\cosh x-1)$ は同じ値になる。
:::

### 構造を合成する

ラベル付きの非空な成分をまず作り、成分の集合に別の構造を付ける。成分一つの級数を $B(x)$、外側の構造の数を $a_k$ とし、$A(t)=\sum a_k t^k/k!$ とする。最終構造の指数型母関数は $A(B(x))$ になる。実際、$k$ 個の成分に順番を振れば $B(x)^k$ がラベル分割と成分の構造を数える。成分番号上の構造が $a_k$ 通りあり、成分番号の付け替えは $k!$ 通りの同じ結果を与える。非空な成分どうしはもとのラベル集合で区別されるので、番号の付け方は常に $k!$ 通りである。

:::example[分割したブロックを一列に整列する]
非空なブロックを順序付きに並べるなら、外側には $a_k=k!$ 個の配置があり $A(t)=1/(1-t)$ である。従って母関数は $1/(2-e^x)$ になる。3 元の場合は一ブロックが 1 通り、二ブロックが $3\cdot2!=6$ 通り、三ブロックが $3!=6$ 通りで合計 13 である。順序を忘れると一ブロック当たりの重みを同じにした Bell 数 $B_3=5$ に戻る。
:::

### Bell 数を二つの式で読む

$B(x)=\exp(e^x-1)$ とする。形式微分から $B'=e^xB$ なので、指数型母関数の積の係数を読むと
$$
B_{n+1}=\sum_{j=0}^n\binom nj B_j
$$
である。数え上げでは、指定した一元が属するブロックの外に $j$ 元を残す方法と、その $j$ 元を分割する方法を掛けていた。$B'$ の微分は指定した一元を取り除いた大きさを記録し、右辺の $e^x$ はその元と同じブロックにいた残りの集合を記録している。

また固定した $n$ について
$$
B_n=e^{-1}\sum_{k=0}^\infty\frac{k^n}{k!}
$$
が成り立つ。これは Dobiński の公式である。形式的には $e^{e^x}$ の内側の定数項が 1 なので、合成をそのまま有限和の約束で使えない。しかし実または複素数の $x$ については $e^{e^x}=\sum_{k\ge0}e^{kx}/k!$ である。$|x|\le R$ で各項の絶対値は $e^{kR}/k!$、$n$ 階微分の絶対値は $k^n e^{kR}/k!$ 以下であり、どちらも項の比の判定から総和が収束する。従って一様収束で微分と総和を交換し、$x=0$ の $n$ 階微分を読める。形式と解析のどちらの条件で式を扱っているかが、この公式では重要である。

:::example[三乗を下降階乗で分解する]
$k^3=(k)_{\underline3}+3(k)_{\underline2}+(k)_{\underline1}$ を Dobiński の式へ入れる。各 $j\ge1$ で $\sum_{k\ge0}(k)_{\underline j}/k!=\sum_{k\ge j}1/(k-j)!=e$ である。ゆえに $B_3=e^{-1}(e+3e+e)=5$ である。一般に Stirling 数の基底変換を入れれば、同じ方法で $B_n=\sum_j S(n,j)$ と対応する。
:::

### 固定点数と全置換を同時に記録する

置換の固定点は長さ 1 の巡回である。固定点ごとに変数 $u$ を掛け、他の巡回の重みを 1 とすれば、各長さの巡回の集合という分解から
$$
\sum_{n\ge0}\sum_{\pi\in S_n}u^{\#\{i:\pi(i)=i\}}\frac{x^n}{n!}
=\exp\left(ux+\sum_{j\ge2}\frac{x^j}{j}\right)
=\frac{e^{(u-1)x}}{1-x}
$$
となる。$u=0$ では攪乱順列、$u=1$ では全置換の級数に戻る。$u$ の $k$ 次係数は $\frac{x^k}{k!}e^{-x}/(1-x)$ である。従って固定点がちょうど $k$ 個の置換は、$n!$ を掛けて $\binom nkD_{n-k}$ 個と読める。選んだ固定点と残りの攪乱という二成分の分解にも一致する。

:::example[二変数級数の四次係数]
分子の指数級数を $x^4$ まで、分母を幾何級数として展開すると、$4![x^4]\bigl(e^{(u-1)x}/(1-x)\bigr)$ は
$$
24+24(u-1)+12(u-1)^2+4(u-1)^3+(u-1)^4
=9+8u+6u^2+u^4
$$
になる。$u^3$ がないことは三元を固定すれば残りも固定されることに対応する。$u$ の係数 8 は固定元を $4$ 通りで選び、残りの三元を二通りの 3 巡回にする個数でもある。$u=1$ で 24 になることは、変数を一つだけ消して全数に戻す検算である。
:::

### ラベル付き構造を円に並べる

ブロックに順序を付けて数えた後、回転で同一視する。そのとき、ブロックは空でない互いに素なラベル集合を使うため、異なるブロックがラベルつきの構造として一致することはない。

:::proposition[ラベル付き構造の巡回列]{#prop-comb-egf-cycles}
非空のラベル付き構造の指数型母関数を $B(z)$ とする。その構造を巡回順に $k\ge1$ 個並べ、ラベルを重複なく使うものの指数型母関数は $B(z)^k/k$ である。個数を固定しない場合は $\sum_{k\ge1}B(z)^k/k=-\log(1-B(z))$ である。
:::

:::proof
順序付きの $k$ 個の構造はラベル付き積により $B(z)^k$ で数えられる。各巡回順に対し、どのブロックを先頭にするかでちょうど $k$ 個の列ができる。$B(0)=0$ なので、無限和の任意次数の係数には有限個の $k$ しか寄与しない。対数の形式展開は $\sum_{k\ge1}t^k/k=-\log(1-t)$ なので代入できる。
:::

:::example[一元と二元のブロックを円に置く]
一元または二元の集合をブロックとするなら $B=z+z^2/2$ である。4 ラベルを使い、円に並べるブロック数が 2 の場合は $4![z^4]B^2/2=3$ 通りである。3 ブロックでは二元集合が一つあり、ラベルの取り方が $\binom42$、ブロックの巡回順が $2!$ なので 12 通りである。4 ブロックではラベル自身を並べて $3!=6$ 通りである。合計は 21 通りである。二元ブロックの内部順序を付けると、$B$ の二次の係数が変わる。
:::

## Catalan 数と Lagrange の反転公式

二進木の根を外すと左右の木に分かれる。同じ分解は、途中で負にならない上下の歩みを、最初に高さ 0 へ戻る点で切ると現れる。

:::definition[Catalan 数]{#def-comb-catalan}
長さ $2n$ の $+1,-1$ の列で、総和が $0$、すべての途中和が非負のものを :term[Dyck 路]{en="Dyck path" yomi="でぃっくろ"} とする。その個数を :term[Catalan 数]{en="Catalan number" yomi="かたらんすう"} $C_n$ とする。
:::

:::proposition[最初の帰還と反射]{#prop-comb-catalan}
$$
C_0=1,\qquad C_n=\sum_{j=0}^{n-1}C_jC_{n-1-j},\qquad
C_n=\binom{2n}{n}-\binom{2n}{n+1}=\frac{1}{n+1}\binom{2n}{n}.
$$
:::

:::proof
非空の路は $+1$、高さを 1 上げた Dyck 路、$-1$、別の Dyck 路に、最初に高さ 0 に戻る時刻で一意に分解される。これが漸化式を与える。総和 0 の列のうち非負条件を破るものでは、最初に高さ $-1$ に達するまでの符号を反転する。結果は総和 $2$ の列となる。逆に総和 $2$ の列は高さ $1$ を初めて通るので、その時点まで反転すると元に戻る。したがって不適格な列の数は上り $n+1$ 回を選ぶ $\binom{2n}{n+1}$ 個である。
:::

:::theorem[Lagrange の反転公式]{#thm-comb-lagrange}
標数 0 の体上で $\phi(0)\ne0$ とする。$W(0)=0$ を満たす $W=x\phi(W)$ の解は一意であり、任意の形式的級数 $F$ と $n\ge1$ に対して
$$
[x^n]F(W)=\frac{1}{n}[t^{n-1}]F'(t)\phi(t)^n. \label{eq-comb-lagrange}
$$
:::

:::proof
$W$ は $U(t)=t/\phi(t)$ の逆級数であり、:ref[prop-comb-series-operations] が使える。Laurent 級数（有限個の負次数を許す級数）の $t^{-1}$ 係数を $\operatorname{Res}_t$ と書く。$U(t)=tu(t)$、$u(0)\ne0$ なら $\operatorname{Res}_t H(U)U'=\operatorname{Res}_x H(x)$ である。単項式 $H=x^j$ で確かめると、$j\ne-1$ の場合 $U^jU'=(U^{j+1})'/(j+1)$ は微分であり、$t^{-1}$ の係数は 0 である。$j=-1$ では $U'/U=1/t+u'/u$ の留数が 1 である。各留数に寄与する次数は有限個なので線形性で一般の場合を得る。

微分により $n[x^n]F(W)=\operatorname{Res}_x F'(W)W' x^{-n}$ と書く。$x=U(t)$ として $W(U(t))=t$ を微分すると $W'(U(t))U'(t)=1$ である。従って留数は $\operatorname{Res}_t F'(t)t^{-n}\phi(t)^n$ になる。
:::

:::example[二分木と三分木]
$C=1+xC^2$ より $W=C-1$ は $\phi(t)=(1+t)^2$ をもつ。:eqref[eq-comb-lagrange] は $C_n=\binom{2n}{n-1}/n$ を与え、例えば $C_4=14$ である。同様に各内部頂点が 3 個の順序付き子をもつ木の級数は $T=1+xT^3$ である。内部頂点を $n\ge1$ 個に固定すると $\binom{3n}{n-1}/n$ 通りであり、$n=3$ で $12$ 通りになる。変数は葉でなく内部頂点を記録する。
:::

### 山の個数を指定した Dyck 路

上りの直後に下りが来る箇所を山と呼ぶ。長さだけを数える最初の帰還分解に、山の個数も記録する。空でない路の最初の上りと帰還の下りに囲まれた内部が空なら山が一つ増え、内部が非空ならその山は内部の数に含まれる。

:::proposition[山の数の係数式]{#prop-comb-narayana}
$n\ge1$ で、長さ $2n$ の Dyck 路のうち山がちょうど $k$ 個のものは
$$
\frac1n\binom nk\binom n{k-1}
$$
個である。
:::

:::proof
$x$ で半長、$u$ で山の個数を記録した母関数を $D$ とする。最初の帰還分解より $D=1+x(u+D-1)D$ である。従って $W=D-1$ は $W=x(u+W)(1+W)$ を満たす。$\Q(u)$ 上で :eqref[eq-comb-lagrange] を用いると $[x^n]W=n^{-1}[t^{n-1}](u+t)^n(1+t)^n$ になる。$u^k$ は第一因子から $\binom nk t^{n-k}$ を伴って現れ、必要な第二因子の次数は $k-1$ なので結論を得る。係数は $u$ の多項式だから、途中で体 $\Q(u)$ を使っても最終式は多項式として読める。
:::

:::example[半長 4 の全体と分布]
$n=4$ では $k=1,2,3,4$ の個数が $1,6,6,1$ である。山が一つなら $++++----$、四つなら $+-+-+-+-$ に限る。和を取ると $14$ となる。一般に公式の和は Vandermonde の恒等式で $\binom{2n}{n-1}/n$ になり、長さだけを記録した結果と一致する。
:::

### 根を持つラベル付き木への応用

木とは、全頂点が辺をたどって互いに到達でき、頂点を重複なく一周する閉路を持たない無向単純グラフである。根付き木は、その木の頂点を一つ根に指定したものである。根を除いた各連結成分には、元の根の隣接先が少なくとも一つある。根からその成分へ行くには、最初の辺で成分に入る必要があるためである。隣接先が二つあれば成分内の道と根に接する二辺が閉路を作るので、隣接先はちょうど一つである。それを新しい根とすれば各成分は根付き木となり、成分どうしに順序はない。詳しい性質は [木](/math/combinatorics-graphs/trees/) で扱う。

非空の根付きラベル付き木の指数型母関数を $T$ とすると、根のラベル一つと部分木の集合の積なので $T=xe^T$ である。Lagrange 反転で
$$
[x^n]T=\frac1n[t^{n-1}]e^{nt}=\frac{n^{n-1}}{n!}.
$$
従って根付きでは $n^{n-1}$ 個である。同じ木の根の選び方は $n$ 通りなので、根を忘れると $n\ge2$ では $n^{n-2}$ 個になる。$n=4$ の場合、根付きは $64$、根なしは $16$ である。

### 高さを指定する反射原理

上りを $p$ 回、下りを $q$ 回行い、$p\ge q$ とする。初期高さが 0 で途中も非負の路の数は
$$
\binom{p+q}{q}-\binom{p+q}{q-1}
$$
である。途中で初めて $-1$ になるまで上下を交換すると、上りが $p+1$ 回、下りが $q-1$ 回の路になる。逆にその路では最終高さが $p-q+2\ge2$ なので、初めて $1$ に上がるまでを交換すれば元へ戻る。$q=0$ なら不適格な路がなく、負の下引数の二項係数を 0 として同じ式になる。

初期点を除いて途中の高さがすべて正という条件では、$p>q$ のとき最初の一歩は上りである。これを削除して残りを高さ 1 から測ると、上り $p-1$、下り $q$ の非負の条件になる。従って個数は
$$
\binom{p+q-1}{q}-\binom{p+q-1}{q-1}
=\frac{p-q}{p+q}\binom{p+q}{q}
$$
である。上りを候補者 A の票、下りを候補者 B の票と読めば、開票のどの時点でも A が厳密に先行する割合が $(p-q)/(p+q)$ になる。同点を許す場合は最初の式を使う。

:::example[票が五対三の場合]
全順序は $\binom83=56$ 通りである。一度も負けず、同点を許す順序は $56-\binom82=28$ 通りである。最初から最後まで常に勝つ順序は $(5-3)/(5+3)$ 倍の 14 通りである。最終的に勝ったという条件は初めから固定しているため、ここで求めているのは開票途中の順序の割合である。
:::

### 分解する対象の見かけが異なる場合

凸 $(n+2)$ 角形の、頂点を増やさない対角線による三角形分割の数を考える。外周の一辺を指定すると、その辺に接する三角形が一つある。その第三頂点を取ると、残る領域が二つの多角形に分かれる。どちらかが辺だけなら分割数を 1 とする。三角形の総数から一つ使ったので、左右の三角形数は合計 $n-1$ である。左側の三角形数 $j$ を決めれば第三頂点が一意に定まり、左右の分割は独立である。従って :ref[prop-comb-catalan] と同じ漸化式で $C_n$ となる。例えば六角形は $n=4$ なので、三角形分割は 14 通りである。

また円周上に $2n$ 点を置き、交差しない $n$ 本の弦で全点を二点ずつ対にする。固定した一番目の点の相手を選ぶと、弦の両側に偶数個の点が残る必要がある。弦を横切って組を作れないからである。片側に $2j$ 点あれば他側には $2(n-1-j)$ 点あり、二側は独立である。各 $j$ について相手の位置は一つなので、これも同じ漸化式になる。たとえば六点の円では 5 通りである。Dyck 路、三角形分割、弦の対を直接同一視しなくても、一意な分解が同じ再帰を与えることで個数が一致する。

### 多分岐の木の係数を一般に求める

各内部頂点が $d\ge2$ 個の順序付きの子をもつ木について、内部頂点を $x$ で数えた母関数を $T$ とする。葉だけが 1、内部頂点が根の場合は $xT^d$ を寄与する。従って $W=T-1$ は $W=x(1+W)^d$ を満たし、:eqref[eq-comb-lagrange] から
$$
[x^n]T=\frac1n\binom{dn}{n-1}
=\frac{1}{(d-1)n+1}\binom{dn}{n}
$$
である。ここでは $n\ge1$ であり、$n=0$ では一枚の葉だけの木を数えて 1 となる。最後の式は二項係数の比を整理したもので、この値を Fuss–Catalan 数という。$d=4,n=3$ では $\binom{12}{2}/3=22$ 個である。葉の数を数えるなら、頂点数が内部 $n$ と葉 $\ell$、辺数が $dn$ であることから $\ell=(d-1)n+1$ となるので、変数の意味を変換できる。

### 始点で高さを確保する

Dyck 路で終点の高さを指定した場合にも、初めて負になる箇所で反射できる。これにより、二候補が得票順で一度も逆転しない確率を求められる。

:::proposition[投票問題]{#prop-comb-ballot-count}
$a>b\ge0$ とする。$A$ の票 $a$ 枚、$B$ の票 $b$ 枚を一列に置き、どの空でない接頭部でも $A$ の票が $B$ より多いようにする方法は
$$
\frac{a-b}{a+b}\binom{a+b}{b}
$$
通りである。
:::

:::proof
最初は $A$ に限られる。これを外すと、残りは上り $a-1$ 回、下り $b$ 回で全ての途中和が非負であればよい。悪い列を最初に $-1$ に達する時点まで反転すると、上りが $a$ 回、下りが $b-1$ 回の列になる。$b\ge1$ なら反転後の終点は正なので最初の高さ 1 が存在し、同じ位置まで反転して逆写像を得る。$b=0$ では悪い列がない。よって良い列の数は $\binom{a+b-1}{b}-\binom{a+b-1}{b-1}$ であり、二項係数を整理すると求める値になる。
:::

:::example[五票と三票]
$A$ が 5 票、$B$ が 3 票を得る場合に票を一様に並べる。先頭を $A$ とした残りは $\binom73=35$ 通りあり、そのうち反射で数えられる悪いものは $\binom72=21$ 通りである。先頭から常にリードするのは 14 通りであり、全 $\binom83=56$ 通りに対して確率は $1/4$ である。同点を一時的に許せば、最初の票を外す条件がなくなり、個数は $\binom83-\binom82=28$ となる。
:::

## 分割数の母関数と Euler の五角数定理

整数分割では大きさ $j$ の部分を使う回数を独立に決める。無限積を取るが、総和 $n$ の分割を求める際に $j>n$ の因子は影響しない。

:::proposition[分割の積表示]{#prop-comb-partition-ogf}
分割数 $p(n)$ について $\sum_{n\ge0}p(n)x^n=\prod_{j\ge1}(1-x^j)^{-1}$ である。異なる部分のみを許す級数は $\prod_{j\ge1}(1+x^j)$ であり、奇数部分のみを許す級数と等しい。
:::

:::proof
$1+x^j+x^{2j}+\cdots$ は部分 $j$ の重複度を記録する。異なる部分だけなら重複度が 0 または 1 である。$1+x^j=(1-x^{2j})/(1-x^j)$ を掛け合わせると偶数の因子が消える。各次数で有限打切りが可能なので、積の消去は合法である。
:::

:::theorem[Euler の五角数定理]{#thm-comb-pentagonal}
$$
\prod_{j\ge1}(1-x^j)
=1+\sum_{k\ge1}(-1)^k\left(x^{k(3k-1)/2}+x^{k(3k+1)/2}\right).
$$
:::

:::proof
左辺は異なる部分への分割を、部分数の偶奇に応じて $\pm1$ で数える。空でない分割を $\lambda_1>\dots>\lambda_k$ とし、最小部分を $m$、先頭から差が 1 で続く部分の個数を $r$ とする。

$m\le r$ なら最小部分を除き、最初の $m$ 部分に 1 ずつ足す。実行できるのは $m<k$ のときである。新しい先頭連続部は長さ $m$ になり、新しい最小部分は $m$ より大きい。実際、$m$ 個目の次が残るなら、その境界で差が少なくとも 2 になる。逆は先頭 $m$ 部分から 1 ずつ引き、新しい最小部分 $m$ を付け足す操作である。

$m>r$ なら最初の $r$ 部分から 1 ずつ引き、新しい最小部分 $r$ を加える。$r<k$ のとき先頭連続部の直後に差が 2 以上あり、減らしても狭義減少が保たれる。$r=k$ のときは減らした元の最小部分が $m-1$ となるので、$m=r+1$ の場合を除けば $r$ を付け足せる。新しい先頭連続部は少なくとも $r$ 個あるため、前の段落の操作がこれを元に戻す。

例外は $m=r=k$ と $m=k+1,r=k$ である。前者は $(2k-1,\dots,k)$、後者は $(2k,\dots,k+1)$ である。総和はそれぞれ $k(3k-1)/2$ と $k(3k+1)/2$ であり、符号はいずれも $(-1)^k$ である。ほかの分割は総和を保って部分数が 1 変わる対に分かれる。空分割の寄与を加えて等式を得る。
:::

両辺に分割の母関数を掛け、$p(n)=0$ を $n<0$ にも定義すると、$n>0$ で
$$
p(n)=\sum_{k\ge1}(-1)^{k-1}\bigl(p(n-k(3k-1)/2)+p(n-k(3k+1)/2)\bigr)
$$
を得る。

例えば $p(7)=p(6)+p(5)-p(2)-p(0)=11+7-2-1=15$ である。対合の具体例では $(7,6,3)$ の $r=2,m=3$ から $(6,5,3,2)$ に移り、部分数が 3 から 4 に変わる。

### 分割図を長方形と残りに分ける

分割図に入る最大の左上正方形の一辺を $d$ とする。その右側に残るのは高々 $d$ 行、下側に残るのは一行の長さが高々 $d$ の分割である。逆にそれぞれをこの条件で独立に選び、$d\times d$ の正方形に貼り合わせると、最大正方形は $d$ のままである。下の行長が高々 $d$ であり、どの候補正方形も $d+1$ 行目の長さを超えられないからである。

行数高々 $d$ の分割の級数は、共役により $\prod_{j=1}^d(1-x^j)^{-1}$ である。従って最大正方形で分類すると
$$
\sum_{n\ge0}p(n)x^n
=\sum_{d\ge0}\frac{x^{d^2}}{\prod_{j=1}^d(1-x^j)^2}
$$
となる。この正方形を :term[Durfee 正方形]{en="Durfee square" yomi="だーふぃーせいほうけい"} という。

:::example[7 の分割を二群に分ける]
$n=7$ なら $d=1,2$ だけが寄与する。$d=1$ の項は $x/(1-x)^2$ なので $[x^7]$ が 7 である。$d=2$ では $[x^3](1-x)^{-2}(1-x^2)^{-2}$ を取り、$4+2\cdot2=8$ である。よって $7+8=15$ になり、五角数定理からの計算と一致する。
:::

### 分割の条件を一つの変数で切り替える

整数 $r\ge2$ を取り、部分の重複度を高々 $r-1$ に制限すると、サイズ $j$ の因子は $(1-x^{rj})/(1-x^j)$ である。全て掛けると $r$ の倍数のサイズに対応する幾何因子が消える。従って重複度が $r$ 未満の分割数と、部分に $r$ の倍数が現れない分割数は等しい。

全単射でも確かめられる。$r$ の倍数でないサイズ $j$ の重複度を $r$ 進展開 $\sum_b m_b r^b$ にして、サイズ $jr^b$ を $m_b$ 回使う。逆に任意のサイズを $r$ の倍数でない $j$ と冪 $r^b$ の積に一意に分けて戻す。例えば $r=3$ で $2$ を 5 回使う場合、$5=1\cdot3+2$ により $6$ を一回と $2$ を二回に置き換え、総和 10 を保つ。

:::example[同じ分割数を制限付き積で確かめる]
部分が $1,2,3$ に限られる分割の母関数は $(1-x)^{-1}(1-x^2)^{-1}(1-x^3)^{-1}$ である。総和 6 では、部分 3 を使う回数を $0,1,2$ に分ける。残りを 1 と 2 で作る方法はそれぞれ $4,2,1$ 通りで、合計 7 通りになる。共役を取ると、これは 6 のうち高々 3 部分への分割数に等しい。実際、6 の各分割を部分数で分類した個数は $1,3,3,2,1,1$ なので最初の三項を足して 7 である。
:::

### 分割数の別の再帰を対数微分で作る

$P=\prod_{j\ge1}(1-x^j)^{-1}$ に $x$ を掛けた対数微分を取る。各係数で有限積に切ってから微分できるため、$xP'/P=\sum_{j\ge1} j x^j/(1-x^j)$ である。右辺の $x^k$ 係数は、$j$ が $k$ を割るときにだけ $j$ を寄与する。そこで約数の和を $\sigma(k)=\sum_{j\mid k}j$ と置けば
$$
n p(n)=\sum_{k=1}^{n}\sigma(k)p(n-k)
$$
になる。実際、$P$ を再び掛けて係数を比較しただけである。五角数定理の再帰は項を足したり引いたりする一方、この再帰は約数和を用いた正の和であり、最後に $n$ で割る。どちらも同じ初期値 $p(0)=1$ から各次数を決める。

:::example[六の分割数を約数和で確かめる]
$\sigma(1),\dots,\sigma(6)$ は $1,3,4,7,6,12$ である。$p(0),\dots,p(5)$ が $1,1,2,3,5,7$ なので、
$$
6p(6)=1\cdot7+3\cdot5+4\cdot3+7\cdot2+6\cdot1+12\cdot1=66
$$
である。従って $p(6)=11$ になる。五角数定理では $p(6)=p(5)+p(4)-p(1)=7+5-1=11$ であり、項数が少ない。約数和の再帰はどのサイズの部品が寄与するかを係数に反映し、五角数の再帰は相殺を先に使って少ない項にまとめている。
:::

### 異なる方法で分割の条件を保存する

$q$ を使った長方形分割の多項式は、縦の制限を $a$、横の制限を $b$ とする両制約付きの母関数である。縦を固定し横を大きくしたとき、固定次数で分子の $1-x^{b+i}$ は 1 に置き換えられる。従って長方形分割の積からも、高々 $a$ 部分の母関数 $\prod_{i=1}^a(1-x^i)^{-1}$ を復元できる。一方、$x$ の数値を代入せずに $a,b$ の両方を大きくすれば、全分割の級数へ係数ごとに移る。

:::example[二つの制限で係数が変わる]
総和 5 の分割で、部分数が高々 2 とする。可能なのは $(5),(4,1),(3,2)$ の三つである。さらに最大部分を 4 に抑えると $(5)$ だけが除かれて 2 個になる。$2\times4$ の長方形分割の式の $x^5$ 係数を読むと、分子の $1-x^5$ が高々 2 部分の母関数の定数項 1 を一回引く。次の $1-x^6$ はまだ影響しない。このように分子の次数を見て、上限制約がどの次数から作用するかが分かる。
:::

### 部分の重複度を変えても総和を保つ

:::proposition[重複度と倍数部分の全単射]{#prop-comb-glaisher-bijection}
整数 $r\ge2$ を固定する。$r$ の倍数の部分を使わない $n$ の分割と、各部分が高々 $r-1$ 回しか現れない $n$ の分割には全単射がある。
:::

:::proof
各部分 $u$ を $r$ の倍数でないものに限り、その重複度 $m_u$ を $r$ 進展開 $m_u=\sum_{j\ge0}d_{u,j}r^j$ で書く。部分 $u$ の集まりを、各 $j$ について部分 $ur^j$ が $d_{u,j}$ 個あるものに置き換える。総和は $\sum_um_uu$ で保存される。正整数の部分 $a$ は $a=ur^j$ と一意に書けるので、重複度が $r$ 未満の分割から桁 $d_{u,j}$ を読み、それを足して $m_u$ を復元できる。
:::

:::example[三進の繰り上がりをまとめる]
$r=3$ とし、部分 1 が 10 個、部分 2 が 4 個、部分 4 が 2 個ある分割を考える。三進桁を用いると 10 は $9+1$、4 は $3+1$ なので、部分 $9,1,6,2,4,4$ を得る。もとの総和は $10+8+8=26$、新しい総和も 26 である。逆に 9 を九つの 1 に、6 を三つの 2 に割れば、もとの分割を復元できる。
:::

### Durfee 長方形と Jacobi の三重積

Durfee 正方形の幅を高さより $k$ 大きくすると、分割の積表示に二つ目の変数を加えられる。$(q;q)_d=\prod_{j=1}^{d}(1-q^j)$、$(q;q)_0=1$ と書く。

:::theorem[Jacobi の三重積恒等式]{#thm-comb-jacobi-triple-product}
形式級数環 $\Z[z,z^{-1}][[q]]$ において
$$
\prod_{j\ge1}(1-q^j)(1+zq^{j-1})(1+z^{-1}q^j)
=\sum_{k\in\Z} z^k q^{k(k-1)/2}
$$
が成り立つ。
:::

:::proof
$\prod_{j\ge0}(1+zq^j)$ の $z^a$ 係数は、$0\le j_1<\cdots<j_a$ の組を指数の和で数えたものである。$j_i$ から $i-1$ を引けば非減少な非負整数列になる。逆順にし、末尾の 0 を除くと高々 $a$ 部分の分割なので、係数は $q^{a(a-1)/2}/(q;q)_a$ である。次に $\prod_{j\ge1}(1+z^{-1}q^j)$ の $z^{-b}$ 係数は、同じ計算で各指数が 1 ずつ上がり、$q^{b(b+1)/2}/(q;q)_b$ となる。

従ってこの二積の $z^k$ 係数は、$k\ge0$ なら $a=b+k$ を代入して
$$
q^{k(k-1)/2}\sum_{b\ge0}\frac{q^{b(b+k)}}{(q;q)_{b+k}(q;q)_b}
$$
である。分割図の左上に入る高さ $b$、幅 $b+k$ の長方形を、最大の $b$ で取る。右に高々 $b$ 行の分割、下に最大部分が高々 $b+k$ の分割が残る。下の最初の行が $b+k+1$ 以上なら、より大きな長方形を取れるからである。逆にこの条件の二分割を貼れば長方形は最大になる。$b=0$ では最大部分が高々 $k$ の全分割が該当する。従って和は全分割の級数 $\prod_{j\ge1}(1-q^j)^{-1}$ である。

よって左辺の $z^k$ 係数は $q^{k(k-1)/2}$ である。左辺の二つの色付き因子の積は $z\mapsto q/z$ で互いに交換される。従って $k>0$ の $z^{-k}$ 係数は $z^k$ の係数の $q^k$ 倍であり、$q^{k(k+1)/2}$ となる。この比較では、置換後も各因子の $q$ 指数は非負であり、各次数の展開に関わる因子は有限個にとどまる。
:::

:::example[五角数定理を再び得る]
$q=x^3$、$z=-x$ とすると左辺の三種類の因子の指数は、正整数を法 3 の剰余で分けたものになる。積は $\prod_{j\ge1}(1-x^j)$ である。右辺は $\sum_{k\in\Z}(-1)^k x^{k(3k-1)/2}$ になり、$k$ と $-k$ の項をまとめると :ref[thm-comb-pentagonal] に戻る。
:::

### 全分割数の増え方を見積もる

約数和や五角数の再帰は各 $p(n)$ を厳密に求める。これに対し、大きな $n$ での増加率は次の漸近式で分かる。

:::theorem[Hardy–Ramanujan の漸近式]{#thm-comb-partition-asymptotic}
$n\to\infty$ のとき
$$
p(n)\sim\frac{1}{4n\sqrt3}\exp\!\left(\pi\sqrt{\frac{2n}{3}}\right).
$$
:::

証明は :cite[vanlint-wilson] の分割数の漸近評価を参照せよ。積表示から係数の主項と誤差を評価するには、ここまでの形式演算に加えて、積を解析関数として扱う議論が必要になる。

:::example[整数 100 の分割数]
五角数定理の再帰を $p(0)=1$ から $n=100$ まで用いると $p(100)=190569292$ である。漸近式の右辺を同じ $n$ で評価すると約 $199280893$ であり、厳密値に対する相対誤差は約 $4.6\%$ である。
:::

## 有理母関数と転送行列法

禁止パターンのある列を全部記録する代わりに、次の一手に必要な情報だけを状態とする。有限個の状態間の遷移なら、同じ計算を行列積で繰り返せる。

:::theorem[転送行列]{#thm-comb-transfer}
有限状態間の $i\to j$ の一歩の選択数を $M_{ij}$ とし、初期重みを行ベクトル $u$、終端重みを列ベクトル $v$ とする。長さ $n$ の経路の重みの総和は $uM^nv$、通常母関数は $u(I-xM)^{-1}v$ である。体上ではこれは有理関数である。
:::

:::proof
空経路の行列は $I$ である。長さ $n+1$ の最後の遷移で分けると長さ $n$ の行列に $M$ を右から掛けるので、帰納法で $M^n$ になる。級数 $\sum_n x^nM^n$ に $I-xM$ を掛けると隣り合う項が消えて $I$ になる。余因子展開 :ref[thm-linalg-adjugate-identity] により成分の分母には $\det(I-xM)$ を取れる。定数項は 1 である。
:::

:::example[隣接する 1 を禁止した二進列]
直近が 1 かどうかを状態にする。$M=\begin{pmatrix}1&1\\1&0\end{pmatrix}$、$u=(1,0)$、$v=\transp{(1,1)}$ である。逆行列を計算すると母関数は $(1+x)/(1-x-x^2)$ になる。長さ $0,1,2,3,4$ の個数は $1,2,3,5,8$ である。空列を一度数えるために初期状態を一つに決める。
:::

:::example[交互に現れる二状態]
$M=\begin{pmatrix}0&1\\1&0\end{pmatrix}$ を使い、初期と終端を第 1 状態に固定すれば、経路の個数は偶数長で 1、奇数長で 0 である。母関数 $1/(1-x^2)$ は周期をそのまま示す。同じ行列でも両状態を終端に許せば長さによらず 1 通りになり、母関数は $1/(1-x)$ である。
:::

発生した有理式を約分すると不要な因子が落ちることがある。従って行列の大きさと、係数列の最小漸化式の次数は一致するとは限らない。逆に、任意の有理級数 $P/Q$ で $Q(0)\ne0$ なら、:ref[prop-comb-ogf-linear] の係数比較で十分大きな添字から定数係数漸化式を得る。

### 直近二文字を状態に残す

二進列で $000$ を禁止するとき、最後に連続する $0$ の個数を $0,1,2$ の三状態にする。$1$ を読むとどこからでも状態 $0$ に戻り、$0$ を読むと次の状態へ進むが、状態 $2$ からの $0$ は許さない。従って
$$
M=\begin{pmatrix}1&1&0\\1&0&1\\1&0&0\end{pmatrix},
\quad u=(1,0,0),\quad v=\transp{(1,1,1)} .
$$
$u(I-xM)^{-1}v$ を計算すると $(1+x+x^2)/(1-x-x^2-x^3)$ である。同じ結果は、末尾にある $1$ の後の $0$ の個数が $0,1,2$ であることから求まる。$1$ がない語は空列と $0,00$ で、母関数 $1+x+x^2$ を作る。$1$ がある語は末尾から $1,10,100$ のいずれかを切り落とす。従って $A=(1+x+x^2)+(x+x^2+x^3)A$ となる。長さ $0,\dots,5$ の個数は $1,2,4,7,13,24$ である。先頭や末尾に余分な区切り記号を置かず、空列を初期状態一つで表す。

### 定数係数漸化式から行列へ戻す

逆方向に、ある数列が $a_{n+d}=c_1a_{n+d-1}+\cdots+c_da_n$ を満たすとする。縦に並べた $X_n=\transp{(a_n,\dots,a_{n+d-1})}$ は $X_{n+1}=MX_n$ を満たす。最初の $d-1$ 行は座標を左へ一つずらし、最後の行は $(c_d,\dots,c_1)$ である。従って $a_n$ は初期ベクトルに $M^n$ を掛けた第 1 成分であり、行列を用いた表示は有限状態の計数に限らない。ただし負の係数がある場合は、遷移の数という解釈をそのまま適用できない。

例えば $a_{n+2}=4a_{n+1}-3a_n$、初期値 $a_0=2,a_1=4$ とする。$M=\begin{pmatrix}0&1\\-3&4\end{pmatrix}$ であり、$M^3\transp{(2,4)}=\transp{(28,82)}$ である。通常母関数では $(2-4x)/(1-4x+3x^2)=1/(1-x)+1/(1-3x)$ なので $a_n=1+3^n$ になる。行列で得た値と部分分数で得た値は一致する。

### 遷移の種類の使用数を追う

隣接する 1 を避ける二進列に戻り、1 を読む遷移に変数 $y$ を付ける。初期を状態 0、終端を両状態とすると
$$
M_y=\begin{pmatrix}1&y\\1&0\end{pmatrix},\qquad
A(x,y)=\frac{1+xy}{1-x-x^2y}.
$$
長さ 1 では $1+y$ が得られ、長さ 2 では $1+2y$ になる。母関数を「末尾が 0、または末尾が 01」の分解で見ても、長さ 2 以上の係数に $a_n=a_{n-1}+y a_{n-2}$ が成立し、上と同じ式になる。末尾が 1 なら、その直前は 0 で、二位置を取り除いても前半に制約は残らないためである。

長さ $n$ でちょうど $k$ 個の 1 がある場合、その位置を $a_1<\dots<a_k$ とする。隣接禁止は $a_{i+1}-a_i\ge2$ に等しいので、$a_i-(i-1)$ は $[n-k+1]$ の相異なる $k$ 元である。逆に順に $i-1$ を足すと許される位置を復元できる。従って個数は $\binom{n-k+1}k$ である。例えば $n=6,k=2$ なら $\binom52=10$ であり、行列で計算した $a_6=1+6y+10y^2+4y^3$ の二次係数と一致する。

### 円としてつなぐと初期状態も合わせる

同じ禁止条件で、先頭と末尾を隣接させる円形のラベル付き列を $n\ge2$ で考える。各位置の状態が直近の文字なので、終わった状態と初めの状態を一致させなければならない。従って個数の多項式は $\tr(M_y^n)$ である。実際、円上の配置が与えられれば、位置 1 を読む直前の状態は位置 $n$ の文字に一意に決まり、閉じた遷移列の計数と一対一になる。$\sum_n x^n\tr(M_y^n)$ の定数項は 2 であり、空の円を一つと扱うなら、その次数だけ別にする。状態ごとの空経路を数えた結果である。

1 が $k\ge1$ 個ある円では、一つの 1 に印を付ける。印の位置は $n$ 通りであり、時計回りに隣の 1 が現れるまでの 0 の数は $k$ 個の正整数で和が $n-k$ になる。条件を満たす各列に印を付ける方法は $k$ 通りなので、$n\ge2k$ なら
$$
\frac{n}{k}\binom{n-k-1}{k-1}
=\frac{n}{n-k}\binom{n-k}{k}
$$
個である。$n<2k$ なら 0、$k=0$ なら全て 0 の一列である。$n=6$ では、$k=1,2,3$ で $6,9,2$ となる。線形の長さ 6 の列に比べて、末尾と先頭の両方が 1 の列が除かれたため、$k=2$ では一つ少なく、$k=3$ では二つ少ない。円上の位置には名前があり、回転で同一視する場合は別の群作用が必要である。詳細は [Pólya の数え上げ](/math/combinatorics-graphs/polya/) を参照する。

:::example[周期を持つ状態と閉じた遷移]
二つの状態を毎回交代する行列 $T=\begin{pmatrix}0&1\\1&0\end{pmatrix}$ では $T^2=I$ である。従って閉じた経路は奇数歩ではなく、正の偶数歩では始点の選択により二つある。母関数は定数項を含めて $2/(1-x^2)$ となる。すべての始点と終点を独立に許すと、奇数歩でも各始点から一つずつ経路があるので母関数は $2/(1-x)$ になる。同じ遷移を用いても条件を変えると母関数が変わる。
:::

### 色の使用回数と直近の位置を同時に追う

:::example[各種類の歩数が必要な有限状態系]
$0,1,2$ の列で、同じ記号を連続させず、0 の使用回数を $u$ で記録する。空列から 0、1、2 を書く重みは $u,1,1$ である。直近の記号が行、次の記号が列となる転送行列を
$$
M=\begin{pmatrix}0&1&1\\u&0&1\\u&1&0\end{pmatrix}
$$
とすれば、長さ $n\ge1$ の重みは $(u,1,1)M^{n-1}\transp{(1,1,1)}$ である。長さ 4 で 0 を二回使うなら、その位置の組は $\{1,3\},\{1,4\},\{2,4\}$ に限られる。中央に非零記号が続くのは $\{1,4\}$ の場合だけで、これは 2 通り、残る二場合は 4 通りずつだから係数は 10 である。行列を三回掛けると $2+12u+10u^2$ が得られ、$u=1$ では $3\cdot2^3=24$ となる。この形式なら重みの変数を先に 1 にするか、最後に係数を読むかで、合計と条件付きの個数を使い分けられる。
:::

### 一つ手前の状態を使わずに繰り返しを検出する

:::proposition[Hankel 列の有限次元性と有理性]{#prop-comb-hankel-rational}
体 $K$ 上の数列 $(a_n)_{n\ge0}$ に対し、無限列 $h_j=(a_{i+j})_{i\ge0}$ を $K^{\N}$ のベクトルと見なす。$h_j$ 全体が張る空間が有限次元であることと、$\sum_{n\ge0}a_nx^n$ が有理級数であることは同値である。
:::

:::proof
まず列空間が有限次元なら、ある $d$ について $h_0,\dots,h_d$ が一次従属である。$h_0=0$ なら零列なので除き、最初に従属する $d$ を選ぶ。$h_d=\sum_{j<d}c_jh_j$ であり、各成分を読めば $a_{i+d}=\sum_{j<d}c_ja_{i+j}$ が $i\ge0$ で成り立つ。定数係数漸化式から分母を持つ級数を得る。逆に有理なら、分母の定数項を 1 に正規化することで、十分後の添字について同様の漸化式を得る。従って十分大きな $j$ では、$h_j$ の全成分が同じ漸化式で前の有限個の列から表される。その位置までの列が全体を張る。
:::

:::example[早い位置にだけ残る項]
級数 $A(x)=x+1/(1-2x)$ は $a_0=1,a_1=3,a_n=2^n$（$n\ge2$）を持つ。漸化式 $a_n=2a_{n-1}$ が全ての $n\ge3$ で成立するので、$h_3=2h_2$ であり、それ以後の列も $h_2$ の倍数である。初めの三列の先頭三成分は $\begin{pmatrix}1&3&4\\3&4&8\\4&8&16\end{pmatrix}$ で、行列式は $-16$ になる。従って列空間の次元は 3 である。分母の次数が 1 でも、漸化式が全成分で成立するまでには例外の初期項があり、最初から列空間を張る次元が分母の次数とは限らない。
:::

### 剰余類ごとに係数を多項式で表す

剰余 $n\bmod M$ ごとに $a_n$ が $n$ の多項式で与えられるとき、$a_n$ を周期 $M$ の :term[準多項式]{en="quasipolynomial" yomi="じゅんたこうしき"} という。少数の初期値を除いてこの性質を持つ場合も、母関数の分母から検出できる。

:::proposition[有限周期の多項式係数]{#prop-comb-quasipolynomial}
$M,d\ge1$ とする。$\Q$ 上の通常母関数 $F$ が分母 $(1-x^M)^d$ を持つ形で書けることと、十分大きい $n$ について $[x^n]F$ が各剰余類で次数高々 $d-1$ の多項式に一致することは同値である。
:::

:::proof
$F=P(x)/(1-x^M)^d$ とする。分子の各単項式 $p_jx^j$ は $n\equiv j\pmod M$ かつ $n\ge j$ の場合に $p_j\binom{(n-j)/M+d-1}{d-1}$ を寄与する。$n\ge\deg P$ であれば、剰余を固定したとき寄与する $j$ が一定なので多項式になる。

逆向きでは、各剰余 $r$ について $n=Mk+r$ と置く。その上で $k$ の多項式を下降階乗の基底 $\binom{k}{j}$、$0\le j\le d-1$ で展開する。$\sum_{k\ge0}\binom{k}{j}y^k=y^j/(1-y)^{j+1}$ である。これは $(1-y)^{-(j+1)}$ の係数を $j$ だけずらしたものである。$y=x^M$ として $x^r$ を掛け、各剰余類の式を足せば分母が $(1-x^M)^d$ にそろう。有限個の初期値の訂正は多項式の追加なので、その分母を変える必要はない。
:::

:::example[二種類の部品だけで総和を作る]
非負整数解 $2a+3b=n$ の数を $u_n$ とする。母関数は $1/((1-x^2)(1-x^3))$ であり、分母を $(1-x^6)^2$ にそろえると分子は $(1+x^2+x^4)(1+x^3)$ になる。従って十分大きい $n$ では剰余 6 ごとに一次式になる。実際 $n=6k+r$、$0\le r<6$ と置くと、$b$ は $0,\dots,\lfloor n/3\rfloor$ のうち $n$ と同じ偶奇の値を取る。その数は $r=1$ なら $k$、他の剰余では $k+1$ である。例えば $u_{13}=2$、$u_{14}=3$ になる。
:::

## 演習問題

::::exercise{level=basic}
$(1-x)^{-3}$ の $x^5$ の係数を求めよ。
:::solution
三つの幾何級数の積なので、非負整数 $a+b+c=5$ を数える。星と仕切りの全単射で $\binom72=21$ である。
:::
::::

::::exercise{level=basic}
$a_0=1,a_1=2,a_n=3a_{n-1}-2a_{n-2}$ の通常母関数を求めよ。
:::solution
$(1-3x+2x^2)A=1-x$ となる。分母は $(1-x)(1-2x)$ なので $A=(1-2x)^{-1}$、従って $a_n=2^n$ である。
:::
::::

::::exercise{level=advanced}
形式級数 $F^2=1+x$ で $F(0)=1$ を満たすものを $\Q$ 上で一意に作り、3 次まで求めよ。
:::solution
$F=1+\sum_{n\ge1}b_nx^n$ の第 $n$ 係数は $2b_n+\sum_{i=1}^{n-1}b_i b_{n-i}$ である。右辺の指定値から $b_n$ を逐次一意に解ける。$b_1=1/2$、$b_2=-1/8$、$b_3=1/16$ である。
:::
::::

::::exercise{level=basic}
6 ラベルを 3 個の無順序の対にする方法を指数型母関数で数えよ。
:::solution
対の級数は $x^2/2!$ である。対の集合のうち対が 3 個の部分は $(x^2/2!)^3/3!$ なので、係数を $6!$ 倍すると $15$ を得る。
:::
::::

::::exercise{level=advanced}
$W=x(1+W)^2$ の $[x^4]W^2$ を求めよ。
:::solution
:ref[thm-comb-lagrange] に $F(t)=t^2$、$\phi(t)=(1+t)^2$ を入れる。$\tfrac14[t^3]2t(1+t)^8=\tfrac12\binom82=14$ である。
:::
::::

::::exercise{level=basic}
五角数定理から $p(8)$ を求めよ。
:::solution
次数 8 以下の非定数項は $-x-x^2+x^5+x^7$ である。$p(0),\dots,p(7)$ は順に $1,1,2,3,5,7,11,15$ となるので、$p(8)=15+11-3-1=22$ である。
:::
::::

::::exercise{level=advanced}
二進列で 1 を偶数個含むものを有限状態で数えよ。
:::solution
偶奇を状態とし、0 で同じ状態を保ち、1 で移る。転送行列は全成分 1 の $J_2$ であり、$J_2^n=2^{n-1}J_2$ が $n\ge1$ で成り立つ。開始と終了を偶に固定すると長さ $n>0$ で $2^{n-1}$、空列で 1 である。母関数は $1+x/(1-2x)$ となる。
:::
::::

::::exercise{level=advanced}
ちょうど $k$ 部分への分割の通常母関数を求めよ。
:::solution
各部分から 1 を引くと総和を $k$ 減らした高々 $k$ 部分への分割が得られる。逆には 0 を補って $k$ 部分とし 1 ずつ足す。高々 $k$ 部分は共役により部分がすべて高々 $k$ と等しい。よって級数は $x^k\prod_{j=1}^k(1-x^j)^{-1}$ である。
:::
::::

::::exercise{level=advanced}
$(1-3x)^{-2}(1+x)^{-1}$ の係数について、増え方を決める主項を求めよ。最初の三係数も確認せよ。
:::solution
絶対値最大の指数の底は 3 で、対応する極は二重である。二重極の係数は式に $(1-3x)^2$ を掛けて $x=1/3$ と置いた $1/(1+1/3)=3/4$ である。従って $a_n\sim(3/4)n3^n$ である。初期係数は、$(1-3x)^{-2}=1+6x+27x^2+\cdots$ に $1-x+x^2+\cdots$ を掛けて $1,5,22$ になる。極の位置は漸近の変化を決めるが、初めの係数を求めるときは小さい極の項も必要である。
:::
::::

::::exercise{level=advanced}
8 箇所の番号付き円で 1 がちょうど 3 個あり、どの二つも隣接しない二進列は何個か。同じ条件で長さ 8 の直線と比較せよ。
:::solution
一個の 1 に印を付けて円上のその位置を決める。8 通りあり、次の 1 までの 0 の個数を 3 個の正整数にすると総和は $8-3=5$ である。組成は $\binom42=6$ 通りで、印は各配置につき 3 通りある。従って円では $8\cdot6/3=16$ 個である。直線なら $a_i-(i-1)$ で間隔条件をなくせるので $\binom63=20$ 個である。差の 4 個は最初と最後がともに 1 の列であり、その場合は残る 1 を 3,4,5,6 番目のいずれかに置ける。
:::
::::


::::exercise{level=advanced}
長さ 6 の語を記号 $0,1,2$ で作り、同じ記号を隣接させないとする。0 がちょうど 3 回現れる語の数を求め、0 の位置の選び方ごとの寄与を比較せよ。

:::solution
0 の間に少なくとも一箇所を挟む。三つの 0 の位置 $x_i$ から $i-1$ を引いた三元集合は $[4]$ の部分集合であり、逆にどれからでも位置を復元できる。従って位置は $\{1,3,5\},\{1,3,6\},\{1,4,6\},\{2,4,6\}$ の四通りである。各非零区間の最初の文字は 1 または 2 の二択であり、以後は交互に書く必要がある。最初と最後の位置集合は非零区間が三つなので 8 通りずつ、中央の二つは非零区間が二つなので 4 通りずつである。全体で 24 通りになる。これは節末の転送行列で $u^3$ の係数を取ることにも当たる。
:::

ラベル付きの積に対応する指数型母関数の係数に現れる因子はどれか。

::::quiz
$F(G)$ が、任意の形式的べき級数 $F$ に対して通常の係数ごとの代入で定義できる十分条件を選べ。

- [ ] $F(0)=0$
- [x] $G(0)=0$
- [ ] $[x]G=0$

:::explanation

::::quiz{answer="14" tol="0"}
票総数の内訳が $A$ に 5 票、$B$ に 3 票のとき、最初から常に $A$ が得票で先行する並べ方はいくつか。
