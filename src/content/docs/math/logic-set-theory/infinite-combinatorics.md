## この章の目標

- 正則基数上の閉非有界集合と定常集合を判定する。
- Fodor の補題と有限集合の Δ システム補題を証明する。
- Aronszajn 木を構成して Suslin 木との条件を比べる。
- 無限 Ramsey の定理と非可算分割関係を示す。

## 閉非有界集合と定常集合

$\kappa$ を非可算正則基数とする。$C\subseteq\kappa$ が :term[閉非有界集合]{en="closed unbounded set" yomi="へいひゆうかいしゅうごう"} とは、上に非有界であり、$\delta<\kappa$ が非零極限で $\sup(C\cap\delta)=\delta$ なら $\delta\in C$ となることをいう。各閉非有界集合と交わる集合を :term[定常集合]{en="stationary set" yomi="ていじょうしゅうごう"} と呼ぶ。閉非有界集合を club と略す。

:::lemma[club の交叉]{#lem-logic-club-intersection}
$\kappa$ 未満の個数の club の共通部分は club である。長さ $\kappa$ の club の列 $(C_i)_{i<\kappa}$ について、対角共通部分 $\{\delta<\kappa:\forall i<\delta\,(\delta\in C_i)\}$ も club である。
:::

:::proof
通常の共通部分の閉性は各集合の閉性から従う。非有界性には出発点 $\beta$ を任意に取る。$\beta_n$ を選んだら各 $C_i$ の中から $\beta_n$ より大きい点を取り、それらをすべて上回る $\beta_{n+1}<\kappa$ を取る。正則性により一段ごとに選べる。$\delta=\sup_n\beta_n$ は $\kappa$ 未満であり、各 $C_i$ の選んだ点が $\delta$ に共終なので $\delta$ は全ての $C_i$ に入る。空族の共通部分は $\kappa$ そのものである。

対角共通部分の閉性では、対角部分の点が $\delta$ に共終なら各 $i<\delta$ より大きい点が共終にあり、それらは $C_i$ に入る。従って $\delta$ も $C_i$ に入る。非有界性では第 $n$ 段で添字 $i\le\beta_n$ に限って点を選ぶ。任意の $i<\sup_n\beta_n$ がいつかその範囲に入り、それ以降の列が同じ閉性を使える。
:::

:::example[可算共終の点の集合]
$S=\{\delta<\kappa:\operatorname{cf}(\delta)=\omega\}$ は定常である。任意の club から厳密に増える可算列を選ぶ。その上限は正則性により $\kappa$ 未満で、閉性で club に属し、共終数は $\omega$ である。一方、後続順序数の集合は非有界だが、非零極限順序数全体の club と交わらない。
:::

### 対角交叉は長い族を扱う

$\kappa$ を非可算正則基数とし、各 $\xi<\kappa$ に club $C_\xi$ を取る。対角交叉とは $\{\delta<\kappa:\forall\xi<\delta\,(\delta\in C_\xi)\}$ である。通常の交叉と違い、$\delta$ ごとに検査するのは添字 $\delta$ より前だけである。非有界性を示すには、任意の $\beta$ から $\alpha_0>\beta$ を取り、$\alpha_{n+1}>\alpha_n$ を $\bigcap_{\xi\le\alpha_n}C_\xi$ から選ぶ。この交叉は $\kappa$ 未満個の club の交叉なので非有界である。$\delta=\sup_n\alpha_n<\kappa$ とすると、各 $\xi<\delta$ について十分後の全項が $C_\xi$ に入るため、閉性により $\delta\in C_\xi$ である。閉性についても、対角交叉の元が極限 $\delta$ に共終なら、任意の $\xi<\delta$ を超えるそうした元だけを見れば $C_\xi$ に共終な列が得られ、$\delta$ 自身も $C_\xi$ に属する。

:::example[末尾の club の族]
$C_\xi=\{\alpha<\omega_1:\xi<\alpha\}$ とする。通常の全交叉は空である。一方対角交叉には全 $\delta<\omega_1$ が入る。実際、$\xi<\delta$ だけを調べるので要求は常に真である。$\delta=0$ でも検査する添字がないため入る。
:::

:::example[非有界でも定常でない場合]
$\omega_1$ 未満の後続順序数全体は、どの $\beta<\omega_1$ よりも上に $\beta+1$ があるので非有界である。しかし非零極限順序数の集合は club であり、その集合と後続順序数全体は交わらない。閉性は非零極限の共終な集合の上限も非零極限になること、非有界性は $\beta+\omega$ が使えることから従う。
:::

### 閉包点を一つずつ作る

$\kappa$ を非可算正則基数とし、$f:\kappa\to\kappa$ とする。各 $\alpha<\delta$ で $f(\alpha)<\delta$ となる $\delta<\kappa$ を $f$ の閉包点と呼ぶ。閉包点の集合は club になる。実際、出発点 $\beta$ の上で $\gamma_0$ を取り、$\gamma_{n+1}$ を $\gamma_n$ と $\{f(\alpha):\alpha<\gamma_n\}$ の全元より大きくする。この集合の濃度は $\kappa$ 未満なので、正則性により上界は $\kappa$ 未満で取れる。$\delta=\sup_n\gamma_n$ は正則性で $\kappa$ 未満である。各 $\alpha<\delta$ はある $\gamma_n$ より小さく、従って $f(\alpha)<\gamma_{n+1}<\delta$ となる。閉性は、閉包点が $\delta$ に共終なら各 $\alpha<\delta$ の上にそのような点 $\eta<\delta$ を取り、$f(\alpha)<\eta<\delta$ とできることから従う。

同様に、有限組を入力とする関数 $g:[\kappa]^{<\omega}\to\kappa$ の閉包点も club になる。$\gamma_n$ の有限部分集合は $\kappa$ 未満個なので、その全像を抑えて次の段へ進める。任意の有限集合が $\delta$ に含まれれば、ある $\gamma_n$ にすでに含まれる。閉性でも、有限集合の全元より上に一つの閉包点を選べばよい。関数が有限個ある場合には閉包点の有限交差を、$\kappa$ 未満個ある場合には通常の交差を取れる。対象が $\kappa$ 個ある場合は、対角交差を用いて $\delta$ より前に添字付けた関数に対する閉性を得られる。

:::example[初期区間で対の番号を保存する]
$\omega_1\times\omega$ と $\omega_1$ の全単射 $b$ を固定する。各 $\alpha$ に対して、$b[\{(\alpha,n):n<\omega\}]$ を抑える順序数を返す関数を作れる。また各 $\xi$ に対して $b^{-1}(\xi)$ の第一成分を返す関数もある。両方の閉包点から $\omega$ 以上の点 $\delta$ を取ると、$b$ は $\delta\times\omega$ を $\delta$ へ全単射で移す。順方向は第一の閉性、逆方向は第二の閉性を使う。従って $\omega_1$ 全体で符号を付けた後も、club をなす切断では小さい順序数だけからその範囲の符号を復元できる。
:::

### 任意の小さい正則共終数の点を探す

$\mu<\kappa$ を無限正則基数とする。共終数が $\mu$ である $\delta<\kappa$ の集合を $S^\kappa_\mu$ と書く。任意の club $C$ に対して、$C$ の中で長さ $\mu$ の狭義増加列 $(c_i)_{i<\mu}$ を取る。各段で先行値の上限は $\kappa$ 未満であり、$C$ は非有界なので続けられる。$\delta=\sup_i c_i$ は $\kappa$ 未満で、$C$ の閉性により $\delta\in C$ である。列が共終なので $\operatorname{cf}(\delta)\le\mu$ である。逆に濃度 $\mu$ 未満の共終集合があれば、その各点を超える $c_i$ の添字を一つずつ取れる。その添字の集合は $\mu$ の正則性で有界なので、元の共終集合も一つの $c_i$ 以下となる。これは矛盾する。従って $\operatorname{cf}(\delta)=\mu$ であり、$S^\kappa_\mu$ は定常である。

:::example[同じ正則基数に互いに素な二定常集合がある]
$\kappa=\omega_2$ では $\mu=\omega$ と $\mu=\omega_1$ を別々に使える。$S^{\omega_2}_\omega$ と $S^{\omega_2}_{\omega_1}$ はそれぞれ任意の club に交わるが、共終数の値が違うので互いに素である。従って二つの定常集合の交差が定常とは限らず、交差が空でも矛盾しない。これに対し二つの club は共通部分も club なので、その交差は空にならない。
:::

### 非定常集合のイデアルを使う

$\kappa$ の非定常部分集合全体を $\mathrm{NS}_\kappa$ と書く。各非定常集合はある club と交わらないので、その任意の部分集合も非定常である。$\kappa$ 未満個の非定常集合の和を考えると、各集合を避ける club の共通部分も club であり、その和を避ける。従って $\mathrm{NS}_\kappa$ は $\kappa$ 未満個の和で閉じている。一方各一元集合はその点より上の club を避けるが、$\kappa$ 個の一元集合の和は $\kappa$ そのもので定常である。従って閉性における個数の制限は必要である。

定常集合 $S$ と club $C$ の共通部分は定常である。任意の club $D$ に対して $C\cap D$ は club なので、$S$ の点を $C\cap D$ から取れるからである。特に定常集合から有界集合を除いても定常性は保たれる。外した有界集合を避ける末尾 club と交差すれば、その定常集合が残るためである。これで定常性の証明では、初めの有限段や有界な例外を切り離せる。

## Fodor の補題

:::theorem[Fodor の補題]{#thm-logic-fodor}
$S\subseteq\kappa\setminus\{0\}$ が定常で、$f(\alpha)<\alpha$ がすべての $\alpha\in S$ で成り立つなら、ある定常な部分集合上で $f$ は定数である。このような $f$ を :term[退行関数]{en="regressive function" yomi="たいこうかんすう"} という。
:::

:::proof
すべての繊維 $f^{-1}\{i\}$ が非定常だとする。各繊維を避ける club $C_i$ を選び、:ref[lem-logic-club-intersection] の対角共通部分を取る。定常性で $S$ と交わる点 $\delta$ を取れる。すると $i=f(\delta)<\delta$ なので $\delta\in C_i$ である。一方 $f(\delta)=i$ だから $C_i$ は $\delta$ を含まないはずであり矛盾する。
:::

:::example[上からの制約が必要な理由]
$f(\alpha)=\alpha$ の各繊維は一元であり、その点より後の末尾 club と交わらない。従って退行条件を外すと定常な定数部分を得られない。
:::

### 定常集合を分割する最初の例

定常集合 $S\subseteq\omega_1$ を非可算個の互いに素な定常集合へ分けられる。各可算無限順序数 $\beta$ に $\omega$ から $\beta$ への全単射 $e_\beta$ を一つ選ぶ。各 $\xi<\omega_1,n<\omega$ に
$$
A_n^\xi=\{\beta\in S:\beta\ge\omega,\ \xi<\beta,\ e_\beta(n)=\xi\}
$$
を取る。$\xi$ を固定すると、$S$ の $\xi$ より上かつ無限の部分は club との交叉なので定常であり、可算個の $A_n^\xi$ で覆われる。このうち少なくとも一つが定常になる。そうでなければ各々を避ける club の可算交叉が $S$ の末尾に交わってしまう。各 $\xi$ に最小のその $n$ を割り当てる。$\omega_1$ を可算個の可算集合で覆えないので、ある $n$ が非可算個の $\xi$ に対応する。その固定した $n$ に対する $A_n^\xi$ は、同じ $\beta$ の $e_\beta(n)$ が一意であるため互いに素である。分割全体が $S$ を覆うように、余った元は一つの部分へ加えられる。

:::example[値が小さい条件を確認する]
$S$ を $\omega_1$ 未満の非零極限順序数とし、各 $\delta\in S$ で可算共終列 $(a^\delta_n)_n$ を一つ選ぶ。$f(\delta)=a^\delta_2$ は確かに $\delta$ 未満なので Fodor の補題を適用できる。従って第三項が同じ定常部分がある。ただし各 $n$ の定常部分を独立に得ても、それらの可算交叉が定常とは限らない。このため全共終列が同じと結論することはできない。
:::

:::example[特異な添字で失敗する形]
$\kappa=\aleph_\omega$ とし、$S=\{\aleph_n:n<\omega\}$ を考える。$S$ は $\kappa$ に非有界で、$\kappa$ 未満に極限点を持たないため閉である。しかし $\{\aleph_n+1:n<\omega\}$ も同様に閉非有界で、$S$ と交わらない。非可算正則性を落とすと、club の有限交叉の議論自体がこの段階で失敗し得る。
:::

### 対角和と Fodor の補題の関係

非定常集合の列 $(A_i)_{i<\kappa}$ について、対角和を
$$
\nabla_{i<\kappa}A_i=\{\delta<\kappa:\exists i<\delta\ (\delta\in A_i)\}
$$
とする。各 $A_i$ を避ける club $C_i$ を取り、対角交差を作る。その対角交差の任意の $\delta$ は、各 $i<\delta$ について $C_i$ に入るため、同時に $A_i$ のどれにも入らない。従って対角和も非定常である。通常の和では $\kappa$ 個の非定常集合を合わせると定常になり得たが、添字を $\delta$ より前に限ると非定常性が保たれる。この性質を非定常イデアルの正規性という。

Fodor の補題はこの正規性からも読める。$f:S\to\kappa$ が退行的で、全ての繊維 $A_i=\{\delta\in S:f(\delta)=i\}$ が非定常なら、各 $\delta\in S$ で $f(\delta)<\delta$ なので $S\subseteq\nabla_i A_i$ となる。正規性によれば右辺は非定常であり、$S$ の定常性に反する。逆に Fodor を使って正規性を得るには、対角和が定常と仮定し、各 $\delta$ に対し $\delta\in A_i$ となる最小の $i<\delta$ を選ぶ。Fodor でその最小値が一定の定常部分を取れるが、その部分は一つの非定常な $A_i$ に含まれ、矛盾する。このように同じ定理を関数の繊維と集合の演算の二通りで表せる。

### 後続基数上で定常集合を分割する

$\lambda$ を無限基数、$\kappa=\lambda^+$ とし、$S\subseteq\kappa$ を定常とする。$\lambda\le\beta<\kappa$ の各 $\beta$ に対し全単射 $e_\beta:\lambda\to\beta$ を選ぶ。$\xi<\kappa,i<\lambda$ に対し
$$
A_i^\xi=\{\beta\in S:\lambda\le\beta,\ \xi<\beta,\ e_\beta(i)=\xi\}
$$
と定める。固定した $\xi$ で $i<\lambda$ を動かすと、全単射の全射性によりこれらの和は $S$ の末尾部分になる。末尾部分は定常であり、非定常集合を $\lambda<\kappa$ 個合わせても非定常なので、そのうち一つは定常である。そこで各 $\xi$ に対し $A_i^\xi$ が定常となる最小の $i$ を付ける。

もし各 $i$ に対応する $\xi$ が $\kappa$ 未満個なら、それらの和も $\kappa$ 未満個である。実際 $\kappa$ は正則で、ここで合わせる集合の個数 $\lambda$ は $\kappa$ 未満だからである。ところが全 $\kappa$ 個の $\xi$ に値を付けたので矛盾する。従ってある一つの $i$ は $\kappa$ 個の $\xi$ に対応する。この $i$ を固定すれば $e_\beta(i)$ は一価であり、異なる $\xi$ に対する $A_i^\xi$ は互いに素である。こうして $\kappa$ 個の互いに素な定常部分を得る。まだ分割に入らない元は一つの部分に加えてよい。この証明で使う配列を :term[Ulam 行列]{en="Ulam matrix" yomi="うらむぎょうれつ"} と呼ぶ。

:::example[どの行を固定するかを確認する]
$\lambda=\omega$ なら、各可算順序数 $\beta\ge\omega$ の元を自然数で列挙する。ある $\xi$ を固定すると、それが列の何番目に現れるかは $\beta$ ごとに違ってよい。まず $\xi$ ごとに、定常に多くの $\beta$ で使われる位置を一つ選ぶ。次にその位置を固定すると、同じ $\beta$ がその位置に二つの $\xi$ を置けないため、異なる列値に対応する定常部分が互いに素になる。この順序を逆にすると、どの位置の部分も定常であるとは限らないため、同じ結論は出ない。
:::

### 正則極限基数にも分割を広げる

:::theorem[Solovay の定常集合分割定理]{#thm-logic-solovay-partition}
$\kappa$ を非可算正則基数とする。任意の定常集合 $S\subseteq\kappa$ は、$\kappa$ 個の互いに素な定常集合に分割できる。
:::

:::proof
まず $S$ のうち $\operatorname{cf}(\alpha)<\alpha$ である点が定常な場合を考える。Fodor の補題により、ある定常部分 $W$ で $\operatorname{cf}(\alpha)=\mu$ にそろえられる。有界な初めの部分と後続順序数を除けば、$\mu$ は無限で $\mu<\kappa$ である。各 $\alpha\in W$ に狭義増加な共終列 $(b^\alpha_i)_{i<\mu}$ を選ぶ。ある一つの $i<\mu$ に対して、どの $\eta<\kappa$ でも $\{\alpha\in W:b^\alpha_i\ge\eta\}$ が定常になる。そうでなければ、各 $i$ に対し $b^\alpha_i<\eta_i$ を強いる club $C_i$ を選べる。それらの共通部分は club であり、$\sup_i\eta_i<\kappa$ である。その上限を超える共通部分上の $\alpha\in W$ を取ると、$\alpha$ の共終列全体がその上限以下に抑えられて矛盾する。

残る場合は $S$ の正則非可算基数からなる部分 $S_0$ が定常である。実際 $\operatorname{cf}(\alpha)=\alpha$ となる無限順序数は正則基数であり、それ以外の部分が非定常なら $S_0$ に定常性が残る。この場合、$S_0\cap\alpha$ が $\alpha$ で非定常となる $\alpha\in S_0$ の集合 $W$ は定常である。任意の club $C\subseteq\kappa$ について、$C$ の非零極限点の集合 $C'$ も club である。非有界性は $C$ の狭義増加な可算列を取ってその上限を作ればよく、閉性は極限点の下で各上界を越える点を $C$ から探せることによる。そこで $S_0\cap C'$ の最小の元 $\alpha$ を取る。$\alpha$ は正則非可算なので、$\alpha$ 内で同じ可算列の構成を行えば $C'\cap\alpha$ は $\alpha$ の club となる。最小性のため $S_0\cap\alpha$ はこの club と交わらない。また $\alpha\in C'\subseteq C$ なので、$W$ は $C$ と交わる。

各 $\alpha\in W$ に $W\cap\alpha$ を避ける $\alpha$ の club を選び、その中で長さ $\alpha$ の狭義増加な連続共終列 $(b^\alpha_i)_{i<\alpha}$ を作る。後続では前の値を超える点を取り、極限では正則性と閉性を使って上限を取る。ある一つの $i<\kappa$ に対し、どの $\eta<\kappa$ でも $\{\alpha\in W:i<\alpha,\ b^\alpha_i\ge\eta\}$ は定常である。もしそうでなければ、各 $i$ について $i<\alpha$ のとき $b^\alpha_i<\eta_i$ を強いる club $C_i$ がある。その対角交差と、写像 $i\mapsto\eta_i$ の閉包点の club を交差させる。その共通部分内の $W$ から $\gamma<\delta$ を選ぶ。各 $i<\gamma$ について $\delta\in C_i$ かつ $\eta_i<\gamma$ なので $b^\delta_i<\gamma$ である。長さ $\gamma$ の狭義増加列の上限は少なくとも $\gamma$ であり、ここでは全項が $\gamma$ 未満なので上限は $\gamma$ に等しい。$\gamma$ は非零極限だから、列の連続性により $b^\delta_\gamma=\gamma$ となる。ところが列は $W\cap\delta$ を避けており、$\gamma\in W$ なので矛盾する。

いずれの場合も、固定した位置 $i$ の値がどの境界 $\eta$ 以上にも定常に現れる。その各定常部分で退行関数 $\alpha\mapsto b^\alpha_i$ に Fodor を適用すると、ある値 $\nu\ge\eta$ が定常に現れる。従って定常な繊維を持つ値の集合は $\kappa$ に非有界で、正則性により濃度 $\kappa$ である。異なる繊維は互いに素なので、これで $\kappa$ 個の定常部分を得る。余った点はその一つに加えれば分割になる。
:::

### Fodor の補題から Silver の定理を導く

:::theorem[Silver の定理]{#thm-logic-silver}
$\lambda$ を非可算共終数を持つ特異基数とする。全ての無限基数 $\mu<\lambda$ で $2^\mu=\mu^+$ なら、$2^\lambda=\lambda^+$ である。
:::

:::proof
$\theta=\operatorname{cf}(\lambda)$ とし、$\theta$ より大きい無限基数から始まる狭義増加な連続列 $(\lambda_i)_{i<\theta}$ を、$\lambda$ に共終に取る。極限では先行値の上限が基数であり、共終数の定義で $\lambda$ 未満に留まるので、再帰で作れる。仮定により各 $\mathcal P(\lambda_i)$ を $\lambda_i^+$ で添字付けられる。$A\subseteq\lambda$ を、各 $i$ で $A\cap\lambda_i$ の添字を返す関数 $f_A$ に送る。異なる $A,B$ はどこか一元で違い、その元は十分後の全ての $\lambda_i$ に入る。従って $f_A,f_B$ は十分後の全添字で異なる。

$\theta$ の club を含む集合はフィルターを作るので、超フィルター $U$ に延長する。これは真のフィルターを包含で極大に取る Zorn の補題による。極大なら、ある $A$ が入らないとき $A$ を加えると有限交差で空になり、もとのフィルターに $A$ と素な元がある。その上側の $\theta\setminus A$ が入るため超フィルターである。各 $i$ で値を順序数として比較し、$\{i:f_A(i)<f_B(i)\}\in U$ のとき $f_A<f_B$ と定める。異なる二関数が等しい添字の集合は有界なので $U$ に入らず、超フィルター性によって残る二方向のうちちょうど一つが入る。推移性は二つの比較集合の交差上で点ごとの推移性を使えばよい。従って関数族には線形順序が入り、その各点の真の前任者を数えられる。

一つの $f$ を固定し、その真の前任者 $g<f$ を数える。$g(i)<f(i)$ となる集合は $U$ に属すため、全ての club と交わり定常である。各 $i$ で $f(i)<\lambda_i^+$ なので、$f(i)$ 未満の順序数全体を $\lambda_i$ に移す単射 $b_i$ をあらかじめ選べる。非零極限 $i$ で $g(i)<f(i)$ なら、連続性から $b_i(g(i))<\lambda_j$ となる $j<i$ がある。非零極限点の club と上の定常集合との交差で、その最小の $j$ は退行的である。Fodor の補題で、ある定常集合 $T_g$ と一つの $j_g$ を取り、全 $i\in T_g$ で $b_i(g(i))<\lambda_{j_g}$ とできる。

$g$ を組 $\bigl(T_g,(b_i(g(i)))_{i\in T_g}\bigr)$ に送ると単射になる。同じ組なら $b_i$ の単射性で $T_g$ の全点で元の値が一致し、この集合は非有界である。異なる二関数が十分後の全添字で違うことに反するのである。$T_g$ の候補数は $2^\theta<\lambda$ である。固定した $T_g$ に対し、ある $\lambda_j$ に値が入る関数の数は高々 $\lambda_j^\theta\le2^{\lambda_j}=\lambda_j^+<\lambda$ である。$\theta$ 個の $j$ について合わせても高々 $\lambda$ 個であり、$T_g$ の候補も含めて高々 $\lambda$ 個である。従って線形順序の各点の真の前任者は高々 $\lambda$ 個しかない。

もし全体の濃度が $\lambda^+$ を超えれば、長さ $\lambda^++1$ の狭義増加列をこの線形順序で作れる。各段ではこれまでの高々 $\lambda^+$ 点とその全前任者を合わせても高々 $\lambda^+$ 個なので、そこに含まれない点を一つ選べる。線形順序だから新しい点は全先行値より後にある。しかし最後の点は $\lambda^+$ 個の前任者を持ち、上の評価に反する。従って関数族の濃度 $2^\lambda$ は高々 $\lambda^+$ である。Cantor の定理が逆の不等式を与え、等号が従う。
:::

## Δ システム補題

:::theorem[有限集合の Δ システム]{#thm-logic-delta-system}
相異なる有限集合からなる非可算族には、任意の二つの共通部分が同じ有限集合 $r$ となる非可算部分族がある。$r$ を根とする :term[Δ システム]{en="delta system" yomi="でるたしすてむ"} という。
:::

:::proof
可算個の可算集合の和は可算なので、あるサイズ $n$ の集合に限っても非可算である。$n$ の帰納法を使う。$n=0$ の非可算族はない。ある元 $x$ が非可算個の集合に属するなら、それらから $x$ を除く。相異なる $n-1$ 元集合の非可算族に帰納法を適用し、得た根へ $x$ を戻す。

残る場合は各元が可算個の集合にしか属さない。長さ $\omega_1$ の再帰で、毎回それ以前の全選択と交わらない集合を選ぶ。前段までに現れた元は可算個であり、それらのどれかを含むために除く集合も可算個である。従って候補はまだ存在する。得られる根は空集合である。
:::

:::example[根と花弁]
$\{\{0,\alpha,\alpha+1\}:\alpha=\omega\cdot\xi,\ 0<\xi<\omega_1\}$ は根 $\{0\}$ の Δ システムである。異なる正の極限順序数 $\omega\cdot\xi$ とその後者からなる二元部分が互いに交わらないためである。
:::

### 根の大きさで場合を分ける

同じ有限の濃度 $m$ に揃えるだけでなく、どの元が何度現れるかが Δ システムの証明を決める。ある元が非可算個に現れれば、その元を除いた族に帰納法を使い、最後の根に元を戻す。どの元も可算個にしか現れない場合は、既に選んだ可算個の集合の和と交わる候補が可算個しかない。従って $\omega_1$ 段の再帰で互いに素な花弁を選べる。

:::example[定義域から両立性を決める]
部分関数 $p_1,p_2,p_3$ の定義域をそれぞれ $\{0,2\},\{0,5\},\{0,7\}$ とする。根は $\{0\}$ である。根での値が順に $1,0,1$ なら $p_1$ と $p_3$ は和を取れる一方、$p_2$ はどちらとも値が衝突する。根での一致を得るため、定義域の Δ システムを取った後に値をそろえる段階が要る。
:::

:::example[可算集合への拡張が難しい理由]
$A_\alpha=\alpha$ として、$\omega\le\alpha<\omega_1$ の可算集合を考える。$\alpha<\beta<\gamma$ なら $A_\alpha\cap A_\beta=A_\alpha$ だが $A_\beta\cap A_\gamma=A_\beta$ である。従って三つからなる Δ システムすらない。有限の共通サイズへの絞り込みと有限帰納法が、可算集合の族にはそのまま移らない。
:::

### 非可算正則基数まで一般化する

:::theorem[小さい集合族の Δ システム]{#thm-logic-general-delta-system}
$\kappa$ を非可算正則基数、$\mu<\kappa$ を無限正則基数とする。各 $\eta<\kappa$ の $\mu$ 未満の濃度の部分集合の全体が $\kappa$ 未満個であると仮定する。濃度 $\mu$ 未満の相異なる集合からなる濃度 $\kappa$ の族には、濃度 $\kappa$ の Δ システムがある。
:::

:::proof
族の和は $\kappa$ 個の濃度 $\mu$ 未満の集合の和なので濃度高々 $\kappa$ である。従って全体を単射で $\kappa$ に移し、$(A_\xi)_{\xi<\kappa}$ を $\kappa$ の部分集合の族として扱える。各 $A_\xi$ は $\kappa$ の正則性で有界であり、$A_\xi$ を部分集合として含む順序数 $f(\xi)<\kappa$ を選ぶ。閉包点の club $C$ を取ると、$\beta\in C$ と $\xi<\beta$ に対し $A_\xi\subseteq\beta$ になる。

$S=C\cap S^\kappa_\mu$ は定常である。$\alpha\in S$ では $|A_\alpha|<\mu=\operatorname{cf}(\alpha)$ なので、$A_\alpha\cap\alpha$ を部分集合として含む順序数 $g(\alpha)<\alpha$ がある。ここで $\alpha$ は極限であり、選んだ上界の後者も $\alpha$ 未満だからである。Fodor の補題で、ある定常部分上で $g(\alpha)=\eta$ を一定にできる。この部分では $A_\alpha\cap\alpha\subseteq\eta$ であり、仮定からその形は $\kappa$ 未満個しかない。もしどの形も非定常にしか現れなければ、$\kappa$ 未満個の非定常集合の和で定常部分を覆うことになる。そこである共通の形 $R$ を持つ定常部分 $S'$ がある。

$\alpha<\beta$ を $S'$ から取る。$\beta\in C$ より $A_\alpha\subseteq\beta$ であり、$A_\beta\cap\beta=R$ である。従って $A_\alpha\cap A_\beta=A_\alpha\cap R=R$ となる。後の等号では $R=A_\alpha\cap\alpha$ を使った。$S'$ は定常なので非有界であり、正則性により濃度は $\kappa$ である。よって添字が $S'$ に属する部分族が求める Δ システムである。
:::

:::example[有限集合と可算集合に必要な仮定を比べる]
$\mu=\omega$ なら $\eta<\kappa$ の有限部分集合は高々 $\max(\aleph_0,|\eta|)<\kappa$ 個である。従って有限集合の任意の濃度 $\kappa$ の族に一般化した定理を使える。一方、$\kappa=\omega_2,\mu=\omega_1$ で可算集合を扱うなら、$\eta<\omega_2$ の可算部分集合が $\omega_2$ 未満個であることを確認する必要がある。CH の下では各 $\eta$ の濃度は高々 $\aleph_1=2^{\aleph_0}$ であり、$\aleph_1^{\aleph_0}=\aleph_1$ だからこの仮定が成り立つ。有限集合のときに使った有限列の計算だけでは、この可算集合版の仮定は出ない。
:::

### 互いに素な花弁から近傍を選ぶ

有限集合族の Δ システムから根 $R$ を除くと、異なる集合の花弁は互いに素である。従って有限集合 $B$ が与えられたとき、$B\setminus R$ と交わる花弁の個数は高々 $|B\setminus R|$ である。実際、そのような花弁から $B\setminus R$ の元を一つずつ選べば、花弁が素なので異なる元を選ぶことになる。$B$ が可算であっても、可算個の花弁しか排除されない。従って非可算族において、既に指定した可算集合と根の外で衝突しない花弁を残せる。

:::example[有限部分写像の衝突を一つの根に集める]
非可算個の有限部分写像 $p$ を取り、値域を可算集合 $A$ に限る。固定した有限定義域に対する写像は可算個以下なので、相異なる非可算個の定義域を選べる。有限の Δ システム補題で非可算個に絞ると、定義域の共通部分は一つの有限集合 $R$ になる。$R$ への制限は $|A|^{|R|}$ 個以下で、これは可算である。従って同じ制限を持つ非可算部分族がある。その部分族の任意の有限個の和は、根の外の定義域が素なので再び有限部分写像となる。二条件が両立することより強く、有限個なら同時に延長できることが分かる。
:::

## 木と Aronszajn 木

:::definition[木とその高さ]{#def-logic-tree}
狭義半順序 $(T,<_{T})$ で、各ノードの真の前任者が整列するものを木という。その順序型がノードの高さであり、同じ高さのノード全体を水準と呼ぶ。すべてのノードの高さの後続の上限を木の高さとする。高さ $\omega_1$、各水準が可算で、長さ $\omega_1$ の枝がない木を :term[Aronszajn 木]{en="Aronszajn tree" yomi="あろんしゃいんき"} という。
:::

:::theorem[Aronszajn 木の存在]{#thm-logic-aronszajn}
ZFC には Aronszajn 木が存在する。
:::

:::proof
水準ごとに木を作り、ノード $t$ に有理数 $h(t)$ を付けて枝で狭義増加させる。さらに以前の任意のノード $s$ と $r>h(s)$ に対して、新しい水準に $s$ の延長 $t$ で $h(t)<r$ となるものを作る。初段は一点でよい。後続段では各ノードに、そのラベルより大きい有理数を一つずつラベルとした子を置く。要求の $s$ が直前の水準にあるなら、その $s$ から直接、ラベルが $h(s)$ と $r$ の間にある子を選べる。さらに低い水準にあるなら、まず直前の水準でラベルが $r$ 未満の延長を取り、そのラベルと $r$ の間の子を選ぶ。

可算極限段 $\delta$ では、以前のノードと有理数の要求 $(s,r)$ が可算個しかない。各要求について $h(s)<r'<r$ を取り、$\delta$ に共終な水準列を選ぶ。以前の延長条件を使って、ラベルがすべて $r'$ 未満の増加鎖を選ぶ。各鎖とその前任者を新ノードの前任者とし、$r'$ と $r$ の間のラベルを付ける。鎖は共終なので前任者の順序型は $\delta$ である。この操作で水準は可算で、延長条件が保たれる。最後に長さ $\omega_1$ の枝があれば、その相異なるラベルが $\Q$ に非可算個あることになり矛盾する。
:::

### 枝と水準の濃度を見分ける

$\omega_1$ 木とは高さ $\omega_1$ で全水準が可算の木である。枝とは極大な鎖をいう。任意の鎖を極大な鎖へ延ばせるので、長さ $\omega_1$ の枝の存在は長さ $\omega_1$ の鎖の存在と同値である。高さ $\omega_1$ に共終な鎖があれば、その全前任者を加えた鎖は各水準を一回ずつ通る。これは各ノードの前任者が整列しており、同じ高さに二つの前任者はないことによる。

:::example[幅が狭くても長い枝がある]
$T=\omega_1$ を通常の順序で木とする。$\alpha$ の前任者集合は $\alpha$ なので水準 $\alpha$ のノードは $\alpha$ 一つである。全水準が一元でも、$T$ 自体が長さ $\omega_1$ の枝になる。従って Aronszajn 木に必要なのは幅の条件だけではない。
:::

:::example[ラベルで枝の上限を設ける]
有理数ラベルを使う構成で、既存ノードのラベルが $1$、新水準への上限の要求が $2$ とする。共終な鎖を $3/2$ 未満のラベルだけで伸ばした後、新ノードに $7/4$ を付けることができる。この値はすべての前任者のラベルより大きく、要求 $2$ より小さい。上限ぎりぎりまで鎖を伸ばすと新ラベルの余地がなくなるため、中間の $3/2$ を先に確保する。
:::

### 木の枝と有限分岐

木でノード $t$ の高さを $\operatorname{ht}(t)$ とする。$\alpha<\operatorname{ht}(t)$ なら、$t$ の前任者のうち高さ $\alpha$ のものはただ一つ存在する。実際、前任者集合をその順序型へ移したときの $\alpha$ 番目の元がそれであり、前任者の前任者は元の列の初期区間になる。従って同じ水準の異なるノードが共通の子孫を持つことはない。もし持てば、その子孫は同じ高さに異なる二つの前任者を持つことになる。逆に二ノードが比較可能なら、大きい方が両方の延長になる。この性質が、木の反鎖を半順序の非両立性へ移すときに使われる。

有限分岐の高さ $\omega$ の木において、根が一つで各ノードの直後の子が有限個なら、無限枝がある。根には任意の有限高さの子孫がある。あるノードが任意に高い子孫を持つとき、少なくとも一つの子が同じ性質を持つ。全ての子の子孫の高さが有界なら、有限個の上界の最大値で親の子孫も抑えられるからである。そこで各段で任意に高い子孫を持つ子を選び続けると、全ての有限水準を通る枝ができる。これが木についての König の補題である。König の基数不等式とは別の主張であり、ここで使うのは有限個の子の高さを一つの有限上界で抑える操作である。

:::example[可算分岐では各有限水準があっても枝がない]
根から出る子を $t_n$、$n<\omega$ とし、$t_n$ の上に長さ $n$ の一本道だけを置く。木全体の高さは $\omega$ である。ところがどの枝も最初に一つの $t_n$ を通り、その上で有限段のうちに終わる。この木では、根の子の高さの上界は各 $n$ ごとに存在しても、それらを抑える有限な共通上界はない。従って同じ帰納法は可算分岐にそのまま拡張できない。
:::

### Aronszajn 木を可算個の反鎖に分ける

木 $T$ が可算個の反鎖の和であることは、比較可能な相異なる二ノードで値が異なる写像 $f:T\to\omega$ があることと同値である。写像があれば各繊維が反鎖である。逆に反鎖の列が $T$ を覆うなら、各ノードにそれを含む最小の反鎖番号を付ける。一つの反鎖番号を共有する二ノードは比較不能である。こうした Aronszajn 木を :term[特殊 Aronszajn 木]{en="special Aronszajn tree" yomi="とくしゅあろんしゃいんき"} という。有理数を枝に沿って狭義増加に付けた上の木は、同じラベルのノードで反鎖に分けられるので特殊である。

特殊な $\omega_1$ 木には非可算な枝がない。枝のノードについては、反鎖番号がすべて異なるため、枝は可算である。一方、木全体には各水準から一点を選ぶだけで $\aleph_1$ 個のノードがある。可算個の反鎖でそれを覆うなら、そのうち一つは非可算である。従って特殊な $\omega_1$ 木は Suslin 木になれない。ここで反鎖に分けることは、水準に分けることより強い。水準の族は $\omega_1$ 個あるのに対し、特殊性では可算個の反鎖しか使わない。

:::example[ラベルの順序条件と識別条件]
木のノードを $\omega$ でラベル付けして比較可能な点の値を変えるだけなら、増加を要求していない。例えば有限の鎖ではラベルを $2,0,5$ の順に置いても識別条件は成り立つ。先の Aronszajn 木の構成では、極限段で共通のラベル上界を用意するため、さらに枝に沿う増加を要求した。特殊性を示す段階では、増加性から比較可能な点で等しくならないことだけを取り出して使う。
:::

## Suslin 問題

:term[Suslin 木]{en="Suslin tree" yomi="すすりんき"} は高さ $\omega_1$ で、非可算鎖も非可算反鎖もない木である。各水準は反鎖なので可算となり、Suslin 木は Aronszajn 木である。Suslin 線は、端点のない稠密で Dedekind 完備な線形順序で、互いに素な非空開区間の族が全て可算だが、可算稠密部分集合を持たないものである。Suslin 問題はこのような線の存在を問う。

:::theorem[Suslin 仮説の位置付け]{#thm-logic-suslin}
Suslin 線が存在することと Suslin 木が存在することは同値である。ZFC が無矛盾なら、Suslin 木の存在も非存在も ZFC と相対的に無矛盾である。
:::

木と線の対応は、区間を細分する構成と辞書式順序の完備化で証明する。存在側は、[構成可能集合と相対無矛盾性](/math/logic-set-theory/constructible/) で扱う $L$ における Jensen の $\diamondsuit$ と、下で示す木の構成を組み合わせる。非存在側は、下で示す $\mathrm{MA}_{\aleph_1}$ からの帰結と、[強制法と独立性証明](/math/logic-set-theory/independence/) で扱う $\mathrm{MA}_{\aleph_1}$ の相対無矛盾性を組み合わせる。先の Aronszajn 木の構成でラベルが等しい二ノードは比較不能である。可算個のラベルで非可算個の全ノードを分けるから、あるラベルには非可算個が集まる。従ってその木は Suslin 木ではない。

### Martin の公理と Suslin 木

$\mathrm{MA}_{\aleph_1}$ は Suslin 木が存在しないことを含意する。この形の公理は [強制法と独立性証明](/math/logic-set-theory/independence/) で定義する。仮に Suslin 木 $T$ があるとし、子孫の高さが $\omega_1$ に非有界なノードだけを残す。各水準のノードがすべて有界な高さにしか子孫を持たないなら、可算個の上界の上限が木全体をその水準より上で抑えてしまう。従って残った木には各水準のノードがある。同様に残ったノード $t$ と任意のより高い水準 $\alpha$ に対し、$t$ の $\alpha$ にある子孫のうち一つは非有界な子孫を持つ。さもなければそれら可算個の上界が $t$ の子孫の高さを抑える。

残った木を、子孫を強い条件とする半順序にする。共通の子孫を持つ二条件は、その子孫の前任者の線形性により比較可能である。比較可能な二条件は強い方を共通の強化にできる。従って強制の反鎖は木の反鎖に一致し、半順序は ccc である。各 $\alpha<\omega_1$ について水準 $\alpha$ 以上の条件が稠密である。公理でこれら $\aleph_1$ 個の稠密集合をすべて訪れるフィルターを取ると、フィルター上の任意の二条件は両立するので鎖になり、高さは $\omega_1$ に共終である。これは Suslin 木の定義と矛盾する。

:::example[線形順序の二つの条件を比較する]
通常の実数直線では互いに素な非空開区間の族から、各区間に入る有理数のうち固定した列挙で最初のものを選べる。区間が互いに素なので、この対応は有理数への単射である。従ってこの直線は区間族についての可算鎖条件を満たす。しかし有理数自身が可算稠密集合なので Suslin 線にはならない。Suslin 問題は、この可算鎖条件と可算稠密性を分離できるかを問う。
:::

### Suslin 線から区間の木を作る

Suslin 線 $X$ を仮定し、根を全区間 $X$ とする。ある水準 $\alpha$ の開区間 $I$ ごとに、閉包が $I$ に入る非空有界開区間を互いに素に並べた極大家族を子とする。各 $I$ の中に少なくとも二つのそのような区間を先に置き、Zorn の補題で極大まで延ばせる。子の和は $I$ に稠密である。もしその和と交わらない非空開区間が $I$ 内にあれば、その内部に別の閉包ごと入る区間を取れて極大性に反するからである。極限水準 $\lambda<\omega_1$ では、それまでの全水準を通る入れ子の列の交叉の内部が非空のものを取り、その内部を新しいノードにする。内部は開区間であり、元の列がある水準で異なればその水準の二区間は素なので、新しい二区間も素になる。各水準は互いに素な非空区間の族なので可算である。

各極限水準が空でないことを示す。先行水準は可算個であり、全先行区間の有限の端点全体は可算である。Suslin 線には可算稠密部分集合がないので、端点を含まない非空開区間 $U$ を取れる。帰納的に $U$ が各水準のある区間に入ることを示す。後続では子の和が親の中で稠密なので、$U$ はある子と交わる。$U$ にその子の端点が含まれないから、$U$ 全体がその子に入る。極限では先行水準を通る列の交叉が $U$ を含むので、その内部に $U$ が入る。この議論は任意の可算極限段で使え、後続も必ず延長できるため、木は高さ $\omega_1$ を持つ。

木の順序を先行区間から後続区間への包含の向きとする。比較不能な二ノードの区間は、初めて異なる水準で分離しているので素である。従って非可算反鎖はない。非可算鎖があれば、その全前任者を加えて各水準を通る枝にできる。各後続段では、親区間のうち子の閉包から外れる部分に非空開区間がある。後の枝は子の内部にいるため、こうして各段で取った開区間は互いに素である。その非可算族は $X$ の可算鎖条件に反する。よってこの木は Suslin 木である。

### Suslin 木から線形順序を作る

逆に Suslin 木 $T$ を取り、子孫の高さが $\omega_1$ に非有界なノードだけに縮める。上で示した正則性の議論により、この木の任意のノードにはどの後続水準にも延長がある。この意味で枝が伸ばせる木の中では、各ノード $s$ に比較不能な二子孫がある。もし $s$ の子孫がすべて比較可能なら、非有界な高さの鎖となって Suslin 性に反するためである。一方を今後分割する側、もう一方を保持する側にして反復すると、$s$ の上に相互に比較不能な可算無限個の子孫が得られる。

この性質で水準を間引く。ある可算水準を選んだら、その全ノードに対してこの可算族を取り、全ての高さより上に来る新水準を選ぶ。各族をその新水準まで延ばしても相互に比較不能である。従って選んだ二水準の間では、各ノードが後者に可算無限個の子を持つ。極限添字では先行する水準の上限を選び、最初の水準も同じ分割操作によってノードが可算無限個になるよう上へ移せる。残したノードの順序は元の木から制限する。新しい水準 $\alpha$ のノードは以前に選んだ全水準に前任者を一つずつ持つので、その木での高さは $\alpha$ である。

最初の水準と各後続水準で、同じ前任者列を持つノードの間を $\Q$ と同型の順序で並べる。後続水準ではこの族はちょうど一つの親の子全体である。極限水準の同じ前任者列を持つノードの族は、任意の線形順序で並べてよい。二ノードの順序を、その前任者列を本人まで含めて比較した辞書式順序とし、一方が他方の接頭列なら短い方を先に置く。最初に異なる水準では先行列が一致するので、その水準に選んだ比較が適用できる。辞書式順序が推移的なのは、三列を比較したとき二つの最初の相違のうち早い方が全体の相違を決め、同じ位置なら局所の線形順序の推移律を使えるためである。接頭列の比較も、列が終わる印を他の値より先に置いたものと考えれば同じである。

あるノード自身とその全子孫の集合は、この線形順序で凸である。外のノードはそのノードの先祖か、それ以前の水準で分岐するため、子孫の間には入り込まない。任意の $x<y$ の間には、このような子孫の集合を丸ごと一つ入れられる。$x,y$ が木で比較不能なら $x$ の真の子孫の一つから始めれば、その延長は全て $x$ より後、$y$ より前になる。$x$ が $y$ の先祖なら、$y$ の方へ向かう $x$ の直後の子より辞書式で早い別の子を取れる。子の順序に最小元がないので、その子の延長全体が $x$ と $y$ の間にある。逆に $y$ が $x$ の先祖だった場合は、短い列が先になるので $x<y$ に反する。従って順序は稠密である。最初の水準に最小元がないことと、各ノードに子があることにより端点もない。

互いに素な開区間が非可算個あれば、各区間に入る子孫集合の根を一つずつ選ぶ。その根が二つ比較可能なら子孫集合が交わるため、根は木の非可算反鎖となる。従って線形順序も可算鎖条件を満たす。他方、可算のノード集合の高さは有界であり、その上の水準から始まる子孫集合の内部にはその可算集合と交わらない非空開区間がある。従って可算稠密部分集合を持たない。

最後に非空真の初期区間で最大元のないものを包含で整列する Dedekind 完備化を取る。元の点 $x$ は $x$ 未満の初期区間として埋め込まれる。二つの異なる切断 $A\subsetneq B$ に対し $b\in B\setminus A$ を取り、$b$ より大きい $c<d$ を $B$ に取れば、$d$ 未満の初期区間は $A$ と $B$ の間に真に入る。よって元の順序は完備化に稠密で、任意の非空上有界な切断族の和は、最大元のない非空真の初期区間であって上限になる。完備化に端点がないのは、各切断の内外の両側で元の点を取れることから従う。開区間の非可算な互いに素な族が完備化にあれば、各区間内の元の二点を端点とする区間も元の順序にそのような族を作る。可算稠密部分集合が完備化にあれば、その順序付き二点間の各区間から元の点を一つ選ぶことで、元の順序に可算稠密部分集合を作れる。どちらも先の結論に反するため、完備化は Suslin 線である。

### ダイヤモンド原理を使って反鎖を閉じ込める

$\diamondsuit_{\omega_1}$ は、各 $\delta<\omega_1$ に $A_\delta\subseteq\delta$ を割り当て、どの $A\subseteq\omega_1$ に対しても $\{\delta:A\cap\delta=A_\delta\}$ が定常となるようにできるという原理である。この原理から Suslin 木を構成する。原理が $L$ で成り立つことは、[構成可能集合と相対無矛盾性](/math/logic-set-theory/constructible/) で凝縮補題を用いて示す。

構成する木のノードは各水準 $\alpha$ に可算個とし、$(\alpha,n)$ の形で名付ける。$\omega_1\times\omega$ と $\omega_1$ の全単射を固定する。club をなす $\delta$ の集合で、この全単射は $\delta\times\omega$ と $\delta$ の間の全単射に制限される。実際、任意の可算段から、そこまでの組の像とそこまでの符号の逆像の第一座標を全部含むさらに大きい段を選べる。これは可算個の順序数の上限が可算であることによる。可算回繰り返した上限では像と逆像の両方向の閉性を得る。閉性も増加する閉包段の和で保たれる。

後続水準では各ノードに二つの子を置く。極限水準 $\delta$ ではその前の木を考える。極限より下の各ノードには、これまでの各水準への延長があると仮定する。$\delta$ には可算共終列が取れるため、あるノードから始め、共終な水準へ一段ずつ伸ばして $\delta$ までの枝を作れる。これを各先行ノードについて一つずつ行い、その枝を前任者とするノードを作れば、すべての先行ノードに新水準への延長がある。必要な枝は可算個である。

その際、$A_\delta$ の符号が $\delta$ 未満の木の極大反鎖 $B$ を表している場合は、各選ぶ枝が $B$ の元を一つ通るようにする。任意の始点 $t$ に対し極大性で $t$ と比較可能な $b\in B$ がある。$b$ が既に $t$ の先祖なら $t$ から続け、$b$ が $t$ の子孫なら $b$ まで先に伸ばす。その後に共終な水準を順に訪れればよい。新水準の全ノードが $B$ の元を前任者に持つ。従ってそれより上の全ノードも $B$ の元と比較可能になる。$A_\delta$ の符号がそのような反鎖を表さないときは、追加条件なしで枝を選ぶ。

完成した木の任意の極大反鎖 $A$ を考える。各ノード $t$ について $A$ の比較可能なノードを一つ選ぶ。これらの選択のため、club をなす $\delta$ の集合で、$\delta$ 未満のノードに対する選択がすべて $\delta$ 未満に入り、$A\cap T_{<\delta}$ は $T_{<\delta}$ の極大反鎖となる。club であることは、各段の下にある可算個のノードの選択先を抑える関数について、先と同様に可算回閉じることで確認できる。符号の閉性を持つ club とも交わらせ、さらに $\diamondsuit_{\omega_1}$ が $A$ の符号を正しく予測した定常段から一つ選ぶ。この $\delta$ では $B=A\cap T_{<\delta}$ が予測されている。それ以後のノードは $B$ のいずれかと比較可能なので、反鎖 $A$ の新しい元にはなれない。従って $A$ は可算である。任意の反鎖は極大反鎖へ延ばせるため、非可算反鎖はない。

もし長さ $\omega_1$ の枝があれば、各後続水準で枝に入らない方の子を一つ取れる。異なる水準のそうした子は、早い分岐の時点で互いに比較不能である。従って非可算反鎖を得てしまう。よって非可算枝もなく、この木は Suslin 木である。

:::example[極限段で予測が役立つ状況]
ある水準より前で、二つの子 $u,v$ が全ての枝の分岐先を尽くすとする。$\{u,v\}$ が予測された極大反鎖なら、新水準のノードには $u$ または $v$ を前任者に持たせる。$u$ と $v$ の上で別々に共終な枝を選ぶことができるので、延長性を失わない。この有限の根の例では予測がなくても同じ条件を満たすが、一般の可算の極大反鎖で同じ操作をするには、極限段に至る前の反鎖を予測しておく必要がある。
:::

## 無限 Ramsey 理論と分割関係

:::theorem[無限 Ramsey の定理]{#thm-logic-infinite-ramsey}
有限の正整数 $n,r$ に対して $\omega\to(\omega)^n_r$ が成り立つ。すなわち、$\N$ の $n$ 元部分集合を $r$ 色に塗ると、すべての $n$ 元部分集合が同色になる無限部分集合がある。
:::

:::proof
$n=1$ は、有限個の有限集合の和が有限であることから従う。$n+1$ の場合、無限集合から最小元 $a_0$ を取る。それを除いた無限集合の $n$ 元組に、$a_0$ を付けた組の色を与える。帰納法でその色が一定になる無限部分集合を取る。次にその集合の最小元 $a_1$ について同じ操作を繰り返し、入れ子の無限集合を作る。各 $a_i$ に対応する一定の色 $j_i$ がある。無限個の $i$ で同じ $j_i$ を選ぶ。選んだ点の任意の $n+1$ 元組で、最小元が $a_i$ なら残りはその段階で残した集合に属すので色は $j_i$ である。
:::

非可算では二色とも非可算同色集合を得られるとは限らない。$\omega_1$ の各 $\alpha$ に異なる実数 $r_\alpha$ を対応させ、$\alpha<\beta$ で $r_\alpha<r_\beta$ かどうかを色にする。非可算な同色集合は実数の厳密増加列または減少列を長さ $\omega_1$ で与える。その隣接する点の間から相異なる有理数を選ぶことになるため不可能である。

:::proposition[非対称な分割関係]{#prop-logic-omega-one-partition}
$\omega_1$ の二元部分集合の二色彩色には、色 $0$ の非可算同色集合か色 $1$ の可算無限同色集合がある。
:::

:::proof
色 $0$ の非可算同色集合がないと仮定する。任意の非可算 $X$ には、$X$ 内に非可算個の色 $1$ の隣接点を持つ元がある。なければ各元の色 $1$ の隣接点は可算である。$\omega_1$ 段の再帰で、既出の点とその色 $1$ の隣接点をすべて除いて次を選ぶと、色 $0$ の非可算同色集合ができてしまう。そこで $X_0=\omega_1$ から、非可算個の色 $1$ の隣接点を持つ $x_n\in X_n$ を選び、その隣接点集合を $X_{n+1}$ とする。選んだ点は二点ごとに色 $1$ で結ばれる。
:::

### 有限 Ramsey 数をコンパクト性で得る

正整数 $n,r,k$ を $n\le k$ として固定する。どの有限の $N$ に対しても、$k$ 点の同色集合を持たない $r$ 色彩色があると仮定する。各 $n$ 元部分集合に一色を与え、各 $k$ 元集合の中の $n$ 元部分集合すべてが同色になることを禁止する命題の集合を、$\omega$ 上で作る。有限部分が使う頂点は有限個なので、仮定でその有限部分を満たせる。命題コンパクト性から全条件を満たす彩色が得られるが、無限 Ramsey の定理から無限同色集合があり、その中から $k$ 元を取ると矛盾する。

:::example[六点で単色三角形を得る]
完全グラフの辺を赤青で塗る。六点のうち一点 $v$ を取り、残る五点への辺を見る。少なくとも三辺が同じ色であり、その色を赤とする。三つの端点の間に赤辺があれば $v$ と合わせて赤三角形になる。なければその三点の辺がすべて青なので青三角形になる。一方五点では五角形の周を赤、対角線を青とすればどちらの色も五角形を作り三角形がない。従ってこの条件の最小点数は $6$ である。
:::

:::example[分割関係の否定の書き方]
$\omega_1\nrightarrow(\omega_1)^2_2$ の反例では、相異なる実数 $r_\alpha$ を用いた先の彩色が使える。非可算な同色集合があれば添字を昇順に並べ、実数側では増加か減少の一方向になる。各隣接対に有理数を一つ挟むので非可算個の異なる有理数が必要になる。他方この議論は可算無限の単色集合を排除しない。可算無限の増加有理列と減少有理列はともに存在するためである。
:::

### 大きな基数から同色な対を取る

:::theorem[対についての Erdős–Rado の定理]{#thm-logic-erdos-rado-pairs}
$\kappa$ を無限基数、$\lambda=(2^\kappa)^+$ とする。$\lambda$ の二元部分集合を $\kappa$ 色で彩色すると、濃度 $\kappa^+$ の同色部分集合がある。すなわち $\lambda\to(\kappa^+)^2_\kappa$ である。
:::

:::proof
色を $c(\{\alpha,\beta\})\in\kappa$ と書く。各端点 $\beta<\lambda$ について、増加列 $(a_i)$ を作る。段 $i$ で、それ以前の全 $a_j$ より大きく、各 $j<i$ で
$$
c(\{a_j,a_i\})=c(\{a_j,\beta\})
$$
となる最小の $a_i\le\beta$ を取る。$\beta$ にまだ達していなければ $\beta$ が候補なので、各段で選択できる。$a_i=\beta$ ならその段で終了する。まず長さ $\kappa^+$ まで終了しない端点 $\beta$ があったとする。その列なら任意の $j<i<\kappa^+$ で、対の色が早い添字 $j$ だけに依存する。各 $j$ に色 $c(\{a_j,\beta\})$ を付け、$\kappa$ 色のうち一色を持つ添字が $\kappa^+$ 個あることを使う。全ての色の添字が $\kappa$ 個以下なら、それらの和は $\kappa$ 個以下となるためである。選んだ添字の点の間では、常に早い方の色が同じなので同色集合を得る。

従って、全ての端点がある $i<\kappa^+$ で終了すると仮定して矛盾を導けばよい。各端点を、終了位置 $i$ と列 $(c(\{a_j,\beta\}))_{j<i}$ の組で符号化する。同じ符号を持つ二つの端点について、段 $j\le i$ で選ばれる点は全て同じである。実際、帰納的に既出の点が一致すれば、次の点が満たすべき色も全て一致する。各端点が候補となるので、最小の候補を選ぶときに「その端点以下」という制限を外しても、選ぶ最小値は同じである。従って全段で選択が一致し、最後の点である端点も一致する。これで符号化は単射である。

一方 $i<\kappa^+$ なら $|i|\le\kappa$ なので、各位置 $i$ の符号は高々 $\kappa^\kappa=2^\kappa$ 個である。位置は $\kappa^+$ 個以下であり $\kappa^+\le2^\kappa$ だから、符号全体も $2^\kappa$ 個以下である。$\lambda=(2^\kappa)^+$ 個の端点をその集合へ単射で入れられない。従って終了しない端点があり、前半の議論で定理を得る。
:::

:::example[可算色でも非可算な同色集合を得る]
$\kappa=\aleph_0$ とすると、$(2^{\aleph_0})^+$ の対を可算個の色に塗っても、$\aleph_1$ 個の点の対がすべて一色になる場合を取れる。$\omega_1$ の二色彩色だけでは、相異なる実数の大小を使った反例があった。正の結果の証明では、端点の個数を連続体より大きくしたことで、同色列を作れない場合の符号の上界を超えている。
:::

### 分割記号で色ごとの結論を表す

正整数 $n$ と色数 $r$ に対し、$\kappa\to(\lambda)^n_r$ は、$[\kappa]^n$ の任意の $r$ 色彩色に濃度 $\lambda$ の同色集合があることをいう。二色で色ごとに要求が違うとき、$\kappa\to(\lambda_0,\lambda_1)^n$ を、色 $0$ で濃度 $\lambda_0$ の同色集合があるか、色 $1$ で濃度 $\lambda_1$ の同色集合があるという意味で使う。この記法により :ref[prop-logic-omega-one-partition] は $\omega_1\to(\omega_1,\omega)^2$ と表せる。一方、実数の大小の彩色は $\omega_1\nrightarrow(\omega_1)^2_2$ を示す。求める集合の濃度を両方 $\omega_1$ に上げると、正の結論から負の結論に変わる。

始域を大きくすると、彩色を元の大きさの部分集合に制限して正の関係を保てる。また色の数を減らすと、それをより多い色のうち一部だけを使う彩色と見なせるので、同じ正の結論が従う。結論の濃度を小さくすると、既に得た同色集合の部分集合を取ればよい。否定の例を移すときには、こうした含意の対偶を使い、変数を変える向きを確かめる必要がある。

:::example[対の色を三元組へ移す]
$\omega_1$ の対の二色彩色 $c$ で、非可算同色集合がないものを取る。$\{\alpha,\beta,\gamma\}$ を $\alpha<\beta<\gamma$ と並べて $d(\{\alpha,\beta,\gamma\})=c(\{\alpha,\beta\})$ とする。もし $d$ に非可算な同色集合 $X$ があれば、任意の $\alpha<\beta$ を $X$ から取ったとき、その上の $\gamma\in X$ が存在する。非可算な $X\subseteq\omega_1$ は有界ではないからである。そこで $c(\{\alpha,\beta\})$ は $d$ の共通色に等しく、$X$ が $c$ にも同色となり矛盾する。従って三元組でも同じ非可算同色性は成り立たない。
:::

## 演習問題

::::exercise{level=basic}
$\{\alpha<\omega_1:\alpha>\beta\}$ が club であることを示せ。
:::solution
任意の点より大きい点を取れるので非有界である。この集合の点が極限 $\delta$ に共終なら $\delta>\beta$ であり、閉性も成り立つ。
:::
::::

::::exercise{level=basic}
二つの club の交叉が空になるか判定せよ。
:::solution
交叉補題で二つの交叉は club である。非有界な集合は非空なので空にはならない。
:::
::::

::::exercise{level=basic}
$\{\{0,1\},\{0,2\},\{0,3\}\}$ の Δ システムの根を求めよ。
:::solution
異なる二集合には共通して $0$ があり、第二の元は異なる。共通部分は毎回 $\{0\}$ であり、これが根である。
:::
::::

::::exercise{level=basic}
真の前任者が一列に二点あるノードの高さを求めよ。
:::solution
二点からなる整列順序の順序型は $2$ である。ノード自身は数えない。
:::
::::

::::exercise{level=advanced}
定常集合を可算個に分けると定常な部分があることを示せ。
:::solution
全てが非定常なら各部分を避ける club を取る。可算個の交叉も club で、元の定常集合を避けることになって矛盾する。
:::
::::

::::exercise{level=advanced}
Aronszajn 木のラベルが有理数なら、同じラベルのノードが反鎖となることを示せ。
:::solution
比較可能な相異なるノードではラベルが枝に沿って厳密に増える。等しいラベルを持つ二ノードは比較不能である。
:::
::::

::::exercise{level=advanced}
定常集合が非有界であることを示せ。
:::solution
有界ならその上界の後の末尾 club を取れる。定常集合と交わるという定義に反する。
:::
::::

::::exercise{level=advanced}
$\omega$ の二元組を和の偶奇で二色にした場合の無限同色集合を一つ与えよ。
:::solution
偶数全体を取る。二つの偶数の和は常に偶数なので、すべての二元組で同じ色となる。
:::
::::

::::exercise{level=advanced}
$\kappa$ を非可算正則基数とする。各 $\alpha<\kappa$ で $f(\alpha)<\kappa$ とする。$C=\{\delta<\kappa:\forall\alpha<\delta\, f(\alpha)<\delta\}$ が club であることを示せ。
:::solution
任意の $\beta<\kappa$ に対し $\beta<\gamma_0<\kappa$ を選ぶ。$\gamma_{n+1}$ は $\gamma_n$ と全 $\alpha<\gamma_n$ の $f(\alpha)$ を超えるように取る。それらは $\kappa$ 未満個なので正則性により可能である。$\delta=\sup_n\gamma_n<\kappa$ に対して各 $\alpha<\delta$ はある $\gamma_n$ 未満なので、$f(\alpha)<\gamma_{n+1}<\delta$ である。従って $C$ は非有界である。$C\cap\delta$ が $\delta$ に共終な極限点なら、各 $\alpha<\delta$ に対し $\alpha<\eta<\delta$ の $\eta\in C$ から $f(\alpha)<\eta<\delta$ が従い、$\delta\in C$ である。
:::
::::

::::exercise{level=advanced}
高さ $\omega_1$ の木で、各ノードが各後続水準へ延長でき、かつ各直後の水準に少なくとも二つの子を持つとする。非可算枝の存在が非可算反鎖の存在を含意する理由を示せ。
:::solution
非可算枝の高さの集合は $\omega_1$ に非有界である。もし有界なら可算順序数未満の各水準で一元しか取れず、枝は可算になる。枝の前任者をすべて足し、各水準に一元あるようにする。各水準 $\alpha$ で枝のノードの二つの子のうち、枝に入らないものを一つ取る。$\alpha<\beta$ のとき、$\beta$ で取った子は $\alpha+1$ の枝上のノードを前任者に持つ。$\alpha$ で取った子はそれと異なるため、二つは比較不能である。従って全ての選択を合わせると非可算反鎖になる。
:::
::::

::::exercise{level=advanced}
$\omega_2$ を共終数 $\omega$ の点の集合と、それ以外の点の集合に分ける。二つの部分はともに定常か。
:::solution
第一の部分は $S^{\omega_2}_\omega$ であり、正則な $\omega<\omega_2$ を用いた共終列の構成で定常である。第二の部分は $S^{\omega_2}_{\omega_1}$ を含む。$\omega_1$ も $\omega_2$ 未満の正則基数なので、この集合も定常であり、それを含む第二の部分も定常である。従って二つは互いに素であっても、それぞれが任意の club に交わる。
:::
