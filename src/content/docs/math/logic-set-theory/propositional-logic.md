## この章の目標

- 括弧付きの式の一意読み取りを証明し、構造帰納法で式の性質を示す。
- 真理関数を標準形や少数の結合子で表示する。
- Hilbert 流の体系で演繹定理と完全性定理を証明する。
- コンパクト性を用いて有限の検査から無限の割り当てを構成する。

## 論理式の帰納的定義と一意読み取り

[集合と論理](/math/sets-logic/logic/) で扱った結合子を、文字列を作る規則として捉え直す。式を機械的に処理するには、まずどの部分がどの結合子の引数かを決める必要がある。

:::definition[論理式]{#def-logic-propositional-formula}
各命題変数 $p_i$ を一つの字句とし、括弧および結合子 $\neg,\to$ と区別する。:term[論理式]{en="formula" yomi="ろんりしき"} 全体は、変数を含み、$A,B$ を含むなら $\neg A$ と $(A\to B)$ を含む最小の文字列集合である。最小集合はこれらの条件を満たすすべての集合の共通部分で作れる。
:::

変数から始め、各段で前段までの式に二つの生成規則を施す。有限段の和集合は規則で閉じ、どの閉じた集合にも含まれる。したがって各式には有限の生成過程がある。これが :term[構造帰納法]{en="structural induction" yomi="こうぞうきのうほう"} の根拠である。性質を満たす式の集合が変数を含み、生成規則で閉じるなら、最小性により全式が性質を満たす。同様に、生成過程の末端から式の値を計算する手続きが構造再帰である。その値が過程の選び方によらないことは次の結果で保証される。

:::proposition[一意読み取り]{#prop-logic-unique-parse}
論理式は変数、否定、含意のいずれか一つであり、その直下の部分式は一意である。
:::

:::proof
文字列の先頭が変数、否定記号、左括弧のどれかで最外の規則が決まる。括弧の深さを左括弧で $1$ 増し右括弧で $1$ 減る数とする。式の深さは各接頭部で非負、末尾で $0$ となる。さらに含意記号は必ず深さ $1$ 以上にある。三性質は変数、否定、含意の各生成規則で保たれる。したがって $(A\to B)$ の深さ $1$ の含意記号は外側の規則が置いた一個のみである。その左右を切れば $A,B$ を復元できる。否定の場合は先頭を除くだけである。
:::

例えば $(p\to(q\to p))$ の含意は深さ $1,2$ に一つずつある。これに対し $(p\to q\to p)$ の深さ $1$ には二個あるため、後者はこの文法の式ではない。慣用的に右結合を採用すれば $p\to q\to p$ は前者の略記となる。データとしての文字列と、紙面で読みやすくする略記とを区別する。

:::example[木の高さと出現回数]
高さを変数で $0$、否定で子の高さに $1$ を足した値、含意で大きい側の高さに $1$ を足した値とする。$(\neg p\to(q\to p))$ の二つの子の高さはそれぞれ $1$ であるから、全体の高さは $2$ である。変数の出現は $3$ 回であり、変数の種類は $2$ 個である。
:::

:::example[葉と二分岐の数]
葉の数を $l(A)$、含意の数を $b(A)$ とすると $l(A)=b(A)+1$ である。変数では $1=0+1$ である。否定は両方を変えない。含意では葉の数を足し、二分岐の数を足して $1$ を加えるため、差は左右の差の和から $1$ を引いた値 $1$ となる。この証明では否定が何個現れてもよい。
:::

### 前置記法の読み取り

括弧付きの記法では括弧の深さが境界を示す。結合子を引数より先に書く前置記法では、各記号が要求する引数の個数から同じ境界を復元できる。変数、$\neg$、$\to$ のアリティをそれぞれ $0,1,2$ とし、初めに空の引数枠を一個置く。左から記号 $s$ を一個読むたびに枠を一個埋め、$s$ のアリティだけ新しい枠を作る。

:::proposition[前置記法の判定]{#prop-logic-prefix-slots}
有限の字句列が一つの式の前置表記であるための必要十分条件は、枠の個数がすべての真の接頭部で正、列の末尾で零となることである。条件を満たす字句列の読み取りは一意である。
:::

:::proof
式が変数なら、枠の列は $1,0$ となる。式が否定なら最初の記号で枠が一個残り、以降は子の列と一致する。含意なら最初の記号で枠が二個になる。左の子を読む間はその子に必要な枠に右の子のための一枠を加えた数となる。左の子の末尾で一枠になり、右の子の末尾で零となる。この帰納法により必要性を得る。

逆に、枠は式の根と各未確定の子を位置付きで表す。読むたびに最も左の未確定の位置を埋め、その位置に必要な子を左から順に追加する。真の接頭部で枠が正なので途中で操作が止まらず、末尾で零なので未確定の子が残らない。各段の操作が決まっているので木は一意である。
:::

:::example[前置記法から括弧を戻す]
$\to\neg p\to q p$ を読む。各字句の直後の枠数は順に $2,2,1,2,1,0$ である。最初に一枠へ戻るのは $\neg p$ を読み終えた時点なので、根の左の子は $\neg p$ である。残り $\to q p$ が右の子であり、式は $(\neg p\to(q\to p))$ になる。
:::

:::example[末尾の余分な字句]
$\to p q r$ では $\to p q$ の時点で枠が零になる。従って $r$ までを一式として読む方法はない。一方、先頭から式を一個ずつ読むなら、これは $(p\to q)$ と $r$ の二式に分かれる。「途中で零にしない」という条件は、末尾の枠数だけ調べる場合に抜け落ちる。
:::

### 式の形と式の数

出現位置を区別すると、同じ字面を持つ部分式にも別々の頂点を割り当てられる。例えば $(p\to p)$ の木には二つの葉があり、その葉が表す式はどちらも $p$ である。部分式の集合を作ると $p$ は一要素にまとまる。この区別は、式の長さを測る場合と、同じ部分式の計算結果を共有する場合に関わる。

:::proposition[高さを制限した式の個数]{#prop-logic-height-count}
$m\ge 1$ 個の変数を許し、高さが高々 $h$ の式の個数を $N_h$ とおくと、$N_0=m$ かつ $N_{h+1}=m+N_h+N_h^2$ である。
:::

:::proof
高さが $0$ の式は変数である。次の段では変数のほかに、子一つを高さ $h$ までから選ぶ否定と、左右の子を順序付きで選ぶ含意がある。:ref[prop-logic-unique-parse] により三種類は互いに素であり、それぞれの選択から得る式も異なる。よって和をとる。
:::

:::example[二変数で高さ二まで]
変数を $p,q$ に絞ると、$N_0=2$、$N_1=2+2+4=8$、$N_2=2+8+64=74$ である。高さがちょうど二である式は $74-8=66$ 個ある。このうち否定で始まる式は、子が高さ一であるものに限るから $8-2=6$ 個である。残る $60$ 個は含意である。含意から直接数えても、高さ一以上の子を少なくとも一方に持つので $8^2-2^2=60$ となる。
:::

### 構造帰納法と文字列の帰納法

構造帰納法では、結論が変数で成り立ち、否定では一つの子、含意では二つの子について成り立つと仮定して示せばよい。文字列の長さに関する強い帰納法として実行するなら、まず :ref[prop-logic-unique-parse] で子を特定する。子の長さは親より狭義に短いので、強い帰納法をそれぞれに適用できる。単純な一段の帰納法で「長さ $n$ から長さ $n+1$」だけを引き継ぐと、子の長さが $n$ より短い場合を取りこぼす。従って「長さ $n$ 以下のすべての式」という性質に強める必要がある。

:::example[括弧の総数を数える]
$\to$ 以外に括弧を追加しない文法では、各含意は括弧を一対増やす。左括弧数 $L(A)$ と右括弧数 $R(A)$ はどちらも含意数 $b(A)$ に等しい。変数で三値は $0$、否定でいずれも変わらず、含意では左右の数の和にそれぞれ $1$ を加える。例えば $(p\to(\neg(q\to r)\to p))$ には含意三個と否定一個があるので、葉は四個、括弧は六個で、結合子を含めた字句長は $4+6+4=14$ である。
:::

:::example[完全な部分式と接頭部]
$(p\to q)$ の真の接頭部 $(p$ は式にならない。右括弧を欠くからである。また $\neg\neg p$ の真の接頭部 $\neg\neg$ は子を欠く。一般にある式の前置表記が別の式の真の接頭部になることはない。前者の末尾で枠が零になるため、後者は真の接頭部で枠が正という条件を破る。これは字句そのものが一変数ずつ切り出せることを前提とする。例えば $p_{12}$ を $p_1$ と $2$ の二字句に分けてはいけない。
:::

## 真理値割り当てと恒真式

:::definition[評価と論理的帰結]{#def-logic-propositional-valuation}
:term[真理値割り当て]{en="truth assignment" yomi="しんりちわりあて"} $v$ は変数から $\{0,1\}$ への写像である。$v(\neg A)=1-v(A)$、$v(A\to B)=1-v(A)(1-v(B))$ と再帰的に延長する。すべての割り当てで $1$ となる式を :term[恒真式]{en="tautology" yomi="こうしんしき"} という。ある割り当てで $1$ となる式を充足可能という。$\Gamma\models A$ は $\Gamma$ の全式を $1$ にする割り当てが $A$ も $1$ にすることを表す。
:::

$A\land B$ を $\neg(A\to\neg B)$、$A\lor B$ を $\neg A\to B$、$A\leftrightarrow B$ を $(A\to B)\land(B\to A)$ と略す。真理値は順に論理積、論理和、一致の指示関数であり、評価式に代入して確かめられる。$\bot$ と $\top$ が必要なら、一つの変数 $p$ を用いて $\neg(p\to p)$ と $p\to p$ と書く。

:::proposition[局所性と代入]{#prop-logic-prop-substitution}
$A$ の真理値は $A$ に出現する変数の値だけで決まる。変数 $p$ を式 $\sigma(p)$ に一斉に置き換えた式を $A^\sigma$ とすると、$v(A^\sigma)=w(A)$ が成り立つ。ただし $w(p)=v(\sigma(p))$ である。
:::

:::proof
変数ではどちらも定義そのものである。否定では子の評価が一致すれば $1$ から引いた値が一致する。含意では二つの子の評価が一致すれば $1-a(1-b)$ の値が一致する。したがって二つの主張はそれぞれ構造帰納法で従う。
:::

$m$ 個の変数に対する評価は $2^m$ 通りである。有限の真理表で恒真性を判定できる一方、変数が増えると行の数が指数的に増える。例えば $(p\to q)\lor(q\to p)$ が偽なら前半から $p=1,q=0$、後半から $q=1,p=0$ が必要で矛盾する。このように、全行を列挙せずに偽になる条件を追うこともできる。

:::example[逆と対偶]
$(p\to q)\to(q\to p)$ は $p=0,q=1$ の行で偽である。一方 $p\to q$ と $\neg q\to\neg p$ の偽になる条件はともに $p=1,q=0$ である。したがって後二式は同じ真理関数を表す。
:::

:::example[仮定集合が充足不能な場合]
$\Gamma=\{p,\neg p\}$ を満たす割り当ては存在しない。したがって $\Gamma\models q$ である。これに対し $\{p\}\models q$ は $p=1,q=0$ が反例となる。帰結とは反例が存在しないという条件である。
:::

### 反例の探索と同値置換

有限の仮定からの帰結を判定するときは、仮定を真に、結論を偽にした状態から始められる。含意に偽を要求すれば、その左に真と右に偽を置く必要がある。含意に真を要求した場合は左に偽を置く場合と右に真を置く場合に分けられる。否定は要求する値を反転させる。この処理を変数に達するまで繰り返すと、枝ごとに変数への等式が残る。

:::proposition[符号付きの分解]{#prop-logic-signed-search}
有限個の要求 $v(A_i)=e_i$ を上の規則で分解する。各枝で一変数に二値を要求した場合にその枝を閉じると、元の要求を満たす割り当てが存在することと、閉じない末端が存在することは同値である。
:::

:::proof
否定の場合は $v(\neg A)=1-v(A)$ により要求を一つ置き換える。含意を偽にする要求は $v(A)=1$ と $v(B)=0$ の両方に等しい。真にする要求は $v(A)=0$ または $v(B)=1$ に等しく、枝全体の他の要求は両側に残す。よって一段の分解の前後で解集合は変わらない。二分岐のときは子の解集合の和を取る。各枝で未分解式に現れる結合子の総数は一段で減るので、分解は有限で終わる。末端には変数の要求しかなく、矛盾しなければ指定されない変数を任意に補える。
:::

:::example[三つの含意を同時に偽にできるか]
$(p\to q)\lor(q\to r)\lor(r\to p)$ を偽と仮定する。各選言肢が偽であるため、順に $(p,q)=(1,0)$、$(q,r)=(1,0)$、$(r,p)=(1,0)$ が必要になる。最初の二条件だけで $q=0$ と $q=1$ が衝突する。従って全八行を列挙しなくても恒真性が示せる。
:::

:::example[もっともらしい帰結に反例を作る]
$\{p\to q,r\to q\}\models p\to r$ の反例を探す。結論を偽とするには $p=1,r=0$ とする。第一の仮定により $q=1$ が必要である。第二の仮定の左は $0$ なので、その含意は真になる。従って $(p,q,r)=(1,1,0)$ が反例であり、この三変数に関しては一意である。
:::

式の一箇所を穴にした式を $C[-]$ と書く。$A,B$ の真理関数が一致するなら $C[A],C[B]$ の真理関数も一致する。穴から木の根まで上がるたびに、否定なら同じ値から同じ値を作り、含意ならもう一方の子の値が固定されているため結果が一致する。例えば $(p\land\neg p)\to q$ は $\bot\to q$ と同じ真理関数を表す。ただし $p\land\neg p$ と $\bot$ は展開先によって別の木である。

### 定義式を増やすときに真理値を保存する

新しい二項結合子 $\leftrightarrow$ を既存の結合子の式で定義した場合、任意の元の評価を新言語に一意に延長できる。定義式の評価が各引数値の組で定まり、新しい式の内部頂点ごとにそれを適用する。逆に新言語の式を展開して元の言語に戻すと、構造帰納法で評価が一致する。例えば $p\leftrightarrow q$ は両者が同じ行では真である。$(p\leftrightarrow q)\leftrightarrow r$ は三変数が全部等しいと主張しない。$(p,q,r)=(0,0,1)$ なら内側が真であり、外側は $1\leftrightarrow1$ で真になる。全員が等しい条件は $(p\leftrightarrow q)\land(q\leftrightarrow r)$ である。

:::example[式が成り立つ割り当ての集合を比較する]
$p\to(q\land r)$ と $(p\to q)\land(p\to r)$ を比較する。$p=0$ の四行では両方とも真である。$p=1$ の四行では両辺が $q\land r$ と同じ値を持つため、真は $(p,q,r)=(1,1,1)$ の一行だけである。従って真となる行は五行であり、二式は同値である。これに対し $p\land(q\to r)$ は $p=0$ だと常に偽なので、括弧の位置を変えて同じ結論にはならない。
:::

:::example[独立な仮定の分離]
$\Gamma=\{p\to q,q\to r,p\}$ とする。三式を同時に満たす $(p,q,r)$ は $(1,1,1)$ のみである。第一式を落とせば $(1,0,0)$、第二式を落とせば $(1,1,0)$、第三式を落とせば $(0,0,0)$ が残る二式を満たして $r$ を偽にする。従って各仮定が単独でも必要であり、$\Gamma\models r$ のために三つとも使っている。
:::

## 関数完全性と標準形

真理表から式を復元するには、各行を識別する式があればよい。選言標準形では満たしたい行を拾い、連言標準形では除きたい行を塞ぐ。

:::theorem[二つの完全標準形]{#thm-logic-prop-normal-form}
$n\geq1$ とする。任意の $n$ 変数真理関数 $f$ は :term[選言標準形]{en="disjunctive normal form" yomi="せんげんひょうじゅんけい"} と :term[連言標準形]{en="conjunctive normal form" yomi="れんげんひょうじゅんけい"} の両方で表せる。
:::

:::proof
$a\in\{0,1\}^n$ に対し、$a_i=1$ なら $l_i=p_i$、$a_i=0$ なら $l_i=\neg p_i$ とおく。$m_a=\bigwedge_i l_i$ は評価が $a$ のときに限り真である。そこで $f(a)=1$ を満たす行について $m_a$ の論理和をとる。各行における値が $f$ と一致する。逆に $\neg m_a$ は行 $a$ のみで偽であり、その値は反対のリテラルを並べた選言の値に等しい。$f(a)=0$ の行についてこの選言の論理積をとる。空の論理和は $\bot$、空の論理積は $\top$ とする。
:::

:::example[排他的論理和]
真になる行は $(0,1)$ と $(1,0)$ である。したがって選言標準形は $(\neg p\land q)\lor(p\land\neg q)$ である。偽の行 $(0,0)$ と $(1,1)$ を除くと、連言標準形は $(p\lor q)\land(\neg p\lor\neg q)$ になる。
:::

:::example[三人の多数決]
少なくとも二人が賛成する条件は $(p\land q)\lor(q\land r)\lor(r\land p)$ である。各項は賛成者の対を一つ指定するので、賛成者が二人以上の行とちょうど一致する。全員賛成の行は三つの項に重複して現れる。重複は真偽に影響しないため、完全標準形より短くできる。
:::

:::definition[関数完全性]
結合子の集合が :term[関数完全]{en="functionally complete" yomi="かんすうかんぜん"} であるとは、それだけを用いて各正のアリティの真理関数を表せることである。
:::

:ref[thm-logic-prop-normal-form] により $\{\neg,\land,\lor\}$ は関数完全である。既出の略記により $\{\neg,\to\}$ も関数完全である。$A\uparrow B=\neg(A\land B)$ なら $A\uparrow A$ は否定、$(A\uparrow B)\uparrow(A\uparrow B)$ は連言になるので NAND 一つで足りる。NOR $A\downarrow B=\neg(A\lor B)$ も $A\downarrow A$ で否定、$(A\downarrow B)\downarrow(A\downarrow B)$ で選言を表せる。一方 $\to$ 単独では、変数すべてを $1$ とする評価の結果が構造帰納法で常に $1$ であるため、否定を表せない。零引数の定数記号を文字として要求する規約では、定数記号を持たない集合は別に扱う。

### 節の消去と充足可能性

連言標準形の各選言を :term[節]{en="clause" yomi="せつ"} と呼ぶ。一つの変数 $p$ を消去したいとき、$p$ と $\neg p$ の現れる節がそれぞれどのような値を要求するかを調べる。節に同じリテラルが重複すれば一つにできる。また相反するリテラルが同じ節にあれば、その節は常に真なので外してよい。

:::proposition[導出された節による変数消去]{#prop-logic-resolution-elimination}
恒真な節と重複リテラルを除いた節集合 $S$ を、$p\lor C_i$、$\neg p\lor D_j$、$p$ が正負どちらの形でも現れない節に分ける。第三の群の節を残し、各対 $(i,j)$ に $C_i\lor D_j$ を加えた節集合を $S'$ とする。他の変数の割り当てが $S'$ を満たすことと、その割り当てが $S$ の充足割り当てへ延長できることは同値である。
:::

:::proof
延長があれば、$C_i,D_j$ が同時に偽になることはない。両方が偽なら $p=1$ と $p=0$ が同時に必要になるためである。従って全ての新しい節が真で、変えなかった節も真となる。逆に $S'$ が真であるとする。偽の $C_i$ が一つでもあれば、すべての $D_j$ が真なので $p=1$ と置ける。偽の $C_i$ がなければ $p=0$ と置くとすべての節が真になる。どちらかの型の節が一つもない場合も、この選び方はそのまま働く。
:::

$C_i\lor D_j$ を二つの節の :term[導出節]{en="resolvent" yomi="どうしゅつせつ"} と呼ぶ。すべての変数を順に消去すると、最後に残り得る偽の節は空の選言だけである。従って有限の節集合が充足不能なら、この操作を有限回繰り返して空節を得られる。各導出節は元の二節の帰結なので、逆に空節が出れば充足不能である。この判定は新しい節を増やすことがあり、節の重複を除いても最悪の場合は大きな計算になる。

:::example[三つの変数の節消去]
$p\lor q,\neg p\lor r,\neg q,\neg r$ を課す。$p$ を消すと $q\lor r,\neg q,\neg r$ が残る。次に $q$ を消すと $r,\neg r$ になり、最後に空節を得る。もし $\neg r$ を最初から外していたら、$r=1,q=0$ に続き $p=1$ を選ぶことで元の式をすべて満たせる。
:::

### 補助変数を使う節化

真理表による標準形は元の変数だけで式を作る。一方、充足可能性だけが必要なら、部分式の値を新変数に預けることで節を短くできる。

:::proposition[線形個の節への変換]{#prop-logic-tseitin}
$\neg,\land,\lor$ で書いた式 $A$ の各内部頂点に新しい変数を一つ割り当てる。内部頂点が $m$ 個なら、元の評価が $A$ を満たすことと同値な拡張条件を、高々 $3m+1$ 個の節で与えられる。元の変数の値を固定すると、拡張が存在する場合は一意である。
:::

:::proof
頂点値 $t$ が否定 $\neg a$ に等しい条件は $(t\lor a)\land(\neg t\lor\neg a)$ である。$t=a\land b$ には $(\neg t\lor a)\land(\neg t\lor b)\land(t\lor\neg a\lor\neg b)$ を課す。前二節が $t=1$ から両入力の真を要求し、最後の節が両入力の真から $t=1$ を要求する。また $t=a\lor b$ には $(t\lor\neg a)\land(t\lor\neg b)\land(\neg t\lor a\lor b)$ を課す。前二節が各入力の真から $t=1$ を要求し、最後が $t=1$ から少なくとも一入力の真を要求する。

最後に根の値を真とする単位節を加える。葉の値を固定すると、木の下から各内部頂点の値が一意に定まり、その値で当該頂点の全節を満たす。根の単位節をも満たせるのは $A$ が真である場合に限る。根が葉である場合も、その葉に単位節を課せばよい。
:::

:::example[含意の連鎖を節で表す]
$A=(p\lor q)\land(\neg p\lor r)$ とし、補助変数を $u=p\lor q$、$v=\neg p$、$w=v\lor r$、$t=u\land w$ に割り当てる。制約は次の通りである。

$$
\begin{aligned}
&u\lor\neg p,\quad u\lor\neg q,\quad\neg u\lor p\lor q,\\
&v\lor p,\quad\neg v\lor\neg p,\\
&w\lor\neg v,\quad w\lor\neg r,\quad\neg w\lor v\lor r,\\
&\neg t\lor u,\quad\neg t\lor w,\quad t\lor\neg u\lor\neg w,\quad t .
\end{aligned}
$$

$(p,q,r)=(1,0,1)$ では $(u,v,w,t)=(1,0,1,1)$ に拡張できる。$(1,0,0)$ では $w=0$ が強制され、$t$ と $\neg t\lor w$ を同時に満たせない。補助変数を任意に選んでよい場合の同値であるため、元の式を補助変数を含んだ言語へそのまま読み替えて全割り当てで比べると、同じ真理関数にはならない。
:::

### 単位節と Horn 節

負のリテラルと正のリテラルを区別すると、正のリテラルが高々一個の節は規則として処理できる。この形を :term[Horn 節]{en="Horn clause" yomi="ほーんせつ"} という。正のリテラルがあるとき、$\neg p_1\lor\cdots\lor\neg p_k\lor q$ を $p_1\land\cdots\land p_k\to q$ と読む。ないときは同じ前件から $\bot$ を導く禁止条件と読む。

:::proposition[Horn 節の最小解]{#prop-logic-horn-least}
有限の Horn 節集合のうち、結論が変数である規則をすべて満たす真変数の最小集合が存在する。この集合が禁止条件も満たすなら節集合は充足可能であり、満たさないなら充足不能である。
:::

:::proof
真変数の集合を空から始め、前件の変数がすべて真になった規則の結論を追加する。空前件の規則は最初から適用できる。追加は有限回しか起こらず、終了時にはすべての規則で閉じている。また、各段の集合がどの規則充足集合にも含まれることは、追加された変数の前件がすでにその集合に含まれていることから帰納的に従う。従って終了時の集合が最小である。禁止条件を破ると、その前件は最小集合の上位集合すべてでも真になる。禁止条件を破らなければ最小集合そのものが解になる。
:::

:::example[依存規則から矛盾まで]
節 $p,\neg p\lor q,\neg q\lor\neg p\lor r,\neg r$ を見る。第一の節から $p$、第二から $q$、第三から $r$ を順に得る。最後の節は $r$ を禁止するので充足不能である。第一の節を削ると新たに真になる変数はなく、全変数を偽にする解を得る。ここで $\neg q\lor\neg p\lor r$ を「$p$ か $q$ のどちらかが真なら $r$」と読むと、別の規則になる。
:::

### 関数完全性を妨げる保存則

ブール関数を合成するときに壊れない性質を探すと、表現できない関数が分かる。次の五つは、いずれも射影が持ち、同じ性質を持つ関数同士を合成しても保たれる。

- $0$ 保存性とは、全入力が $0$ のとき値が $0$ であることをいう。内側の関数に零列を入れると全部が零なので、外側を適用しても零になる。
- $1$ 保存性は全入力が $1$ のときの同じ条件である。
- 単調性とは、全座標で $a_i\le b_i$ なら $f(\vec a)\le f(\vec b)$ になることをいう。内側の関数により座標ごとの不等式が保たれ、外側でも保たれる。
- 双対性を自分自身が満たすとは $f(\neg\vec x)=\neg f(\vec x)$ が成り立つことをいう。入力のビットを全部反転すると内側の出力が全部反転し、外側の値も反転する。この性質を自己双対性という。
- アフィン性とは $\F_2$ 上で $f=c+\sum_i c_i x_i$ と書けることをいう。内側のアフィン式を外側の同じ形に代入し、係数をまとめると再びこの形になる。

定数 $1$ は $0$ 保存性を、定数 $0$ は $1$ 保存性を破る。ここで定数も正のアリティで一定値を返す真理関数として考える。否定は単調性を破り、定数は自己双対性を破る。連言がアフィンであるとすれば、$(0,0)$ での値から定数項は $0$、$(1,0),(0,1)$ での値から両係数も $0$ となり、$(1,1)$ を真にできない。従って関数完全であるには、結合子の集合がこれら五条件のどれについても、その条件を破る少なくとも一つの関数を含む必要がある。

:::lemma[ブール関数の多重線形表示]{#lem-logic-boolean-anf}
任意の $n$ 変数ブール関数は $\F_2$ 上で一意に
$$
f(x_1,\ldots,x_n)=\sum_{S\subseteq\{1,\ldots,n\}}c_S\prod_{i\in S}x_i
$$
と表せる。
:::

:::proof
$1_T$ を、添字が $T$ に属する座標だけ $1$ である入力とする。右辺を $1_T$ で評価すると $\sum_{S\subseteq T}c_S$ になる。そこで $T=\varnothing$ から濃度の順に $c_T=f(1_T)+\sum_{S\subsetneq T}c_S$ と決めれば、各点で一致する。各段で $c_T$ はそれより短い係数と値によって一意に決まる。
:::

:::theorem[Post の関数完全性判定]{#thm-logic-post-functional-completeness}
正のアリティの真理関数の族が関数完全であるための必要十分条件は、零保存、一保存、単調、自己双対、アフィンのそれぞれを破る関数を少なくとも一つずつ含むことである。
:::

:::proof
必要性は上の合成に関する計算で従う。十分性を示す。零保存を破る関数 $f$ の引数全部を $x$ にした一変数関数 $g$ は $g(0)=1$ である。一保存を破る関数も同様に使い、$h(1)=0$ を満たす一変数関数 $h$ を取る。どちらかが否定ならすでに否定が得られる。両方が否定でなければ $g$ は定数 $1$、$h$ は定数 $0$ である。

否定が得られた場合、すでに片方の定数があればその否定で他方が得られる。両定数を欠くなら、自己双対でない関数 $k$ を使う。ある $\vec a$ で $k(\vec a)=k(\neg\vec a)$ である。$a_i=0$ の座標には $x$、$a_i=1$ の座標には $\neg x$ を代入する。$x$ の二値で得る二入力が $\vec a,\neg\vec a$ なので、この一変数関数は一定になる。その否定で逆の定数を作れる。反対に定数が先に得られて否定がまだない場合は、単調でない関数を使う。ある $\vec a\le\vec b$ に対し値が順に $1,0$ である。一致する座標に定数、不一致の座標に $x$ を入れると $x=0,1$ で値が $1,0$ になる。従っていずれの場合も両定数と否定が得られる。

次にアフィンでない関数 $f$ を取る。:ref[lem-logic-boolean-anf] により、次数が $2$ 以上の係数 $1$ の単項式がある。その二変数を $x_i,x_j$ とすれば、多項式を $f=A x_ix_j+B x_i+C x_j+D$ と整理でき、残りの変数の多項式 $A$ は零でない。多重線形表示の一意性により、$A$ が $1$ となる残りの変数の値がある。それらを定数で固定し、二変数関数 $xy+bx+cy+d$ を作る。これに $x+c,y+b$ を代入すると $xy+bc+d$ になる。引数の足し算が $1$ なら否定、$0$ なら元の変数を使い、出力の定数項が $1$ でも否定して消せる。これで $xy$、すなわち連言が得られる。否定と連言で選言が作れるため :ref[thm-logic-prop-normal-form] で関数完全となる。
:::

:::example[排他的論理和に何を足すべきか]
$\{\oplus,\neg\}$ から $p\oplus p=0$ とその否定で $1$ を作れる。それでもすべての合成はアフィンであるため、連言は作れない。そこで二項 $f(p,q)=p\land q$ を足すと、否定と連言が揃うので関数完全となる。反対に、いくつの定数を追加してもアフィン性を破れない。
:::

:::example[条件だけで NAND の完全性を判定する]
$\operatorname{NAND}(0,0)=1$ と $\operatorname{NAND}(1,1)=0$ から零保存、一保存を破り、同時にこの二行により単調性も破る。$(0,1)$ と $(1,0)$ の値がどちらも $1$ なので自己双対性を破る。また四行で値を $\F_2$ 上足すと $1+1+1+0=1$ である。アフィン関数なら定数項は四回、各変数項は二回ずつ足されて和が零になるので、アフィン性も破る。従って個別の翻訳を作る前に :ref[thm-logic-post-functional-completeness] から関数完全と分かる。
:::

### 枝分かれと単位伝播

節集合で一つのリテラルに値を与えたら、真となった節を外し、残りの節から偽となったリテラルを削る。続けて単位節があればそのリテラルを真にする。元の集合を満たす評価はその単位節の値を必ず選ぶので、単位伝播は解を落とさない。空節に達した枝には解がなく、すべての節が消えた枝は残りの値を任意に選べる。どちらにも達せず単位節がないなら、現れる変数を一つ選んで二値に分ける。この各枝で少なくとも一つの変数の値が固定されるため、有限節集合では終了する。各解は分岐した二値のうち片方に残るので、終端の判定までの帰納法で正しさが従う。

:::example[二枝で判定する]
節 $p\lor q,\neg p\lor r,\neg q\lor r,\neg r\lor p$ を考える。初めには単位節がないので $p$ を分岐させる。$p=0$ なら第一節から $q=1$、第三節から $r=1$、第四節から $r=0$ が必要になり閉じる。$p=1$ なら第二節が $r=1$ を要求し、残る節はすべて真になる。従って $q$ の値は自由であり、元の割り当ては $(1,0,1),(1,1,1)$ の二つである。単位伝播が選択する値は、その枝の仮定の下でのみ強制される。
:::

### 二リテラル節を到達可能性で解く

各節が高々二リテラルなら、空節があればその時点で充足不能である。空節がなければ、次の有向グラフを作れる。単位節 $A$ は $A\lor A$ と書く。節 $A\lor B$ に対し、リテラルを頂点として $\neg A\to B$ と $\neg B\to A$ に対応する二辺を入れる。ここでリテラルの否定とは、変数の正負を入れ替える操作である。二辺は同じ節の二つの読み方であり、割り当てが節を満たすことと、辺を真の頂点からたどるなら行き先も真であることは同値である。

:::proposition[二リテラル節の判定]{#prop-logic-two-sat}
空節のない有限の二リテラル節集合は、ある変数 $p$ とその否定 $\neg p$ が互いに到達可能となる場合に限り充足不能である。
:::

:::proof
$p$ と $\neg p$ が互いに到達可能なら、どちらが真であっても辺に沿って反対側が真になり矛盾する。逆に、相互に到達可能な頂点を同一視して強連結成分を取る。同値関係であることは道の連結から従う。縮めたグラフに閉路があればその成分間で相互に到達可能になるため、異なる成分からなる閉路はない。有限の閉路のないグラフの頂点は、すべての辺が先から後ろへ進む順に並べられる。実際、入辺のない頂点がないと仮定すると、入辺を繰り返し逆にたどる途中で有限個の頂点のいずれかを再訪し、閉路が生じる。そこで入辺のない頂点を一つ先頭へ移す操作を繰り返す。

辺 $a\to b$ と同時に $\neg b\to\neg a$ があるため、道も否定して逆向きにできる。従って同じ成分 $C$ のリテラルの否定は一つの成分 $\overline C$ にまとまる。仮定により $C\ne\overline C$ である。各変数について、先の並びでより後ろにある成分側のリテラルを真にする。これでちょうど一方が真になる。もし辺 $a\to b$ で $a$ が真、$b$ が偽なら、成分の番号について
$$
\operatorname{num}(a)\le\operatorname{num}(b)<
\operatorname{num}(\neg b)\le\operatorname{num}(\neg a)<
\operatorname{num}(a)
$$
となり矛盾する。従って全辺で真から偽への移動がなく、全節を満たす。
:::

:::example[相互到達で空節を検出する]
$p\lor q,\ p\lor\neg q,\ \neg p\lor q,\ \neg p\lor\neg q$ を課す。$p$ から $q$ への辺は第三節から、$q$ から $\neg p$ は第四節から出る。逆に $\neg p$ から $q$ は第一節から、$q$ から $p$ は第二節から出る。従って $p$ と $\neg p$ は同じ成分にあり、充足不能である。第四節を外すと $p=q=1$ で残る三節を満たす。同じ節消去を大きい連言標準形で行う場合には、この二頂点間の辺だけでは三リテラル以上の制約を表せない。
:::

### 真理関数を回路として実装する

同じ入力について同じ部分式を何度も計算する必要はない。計算した値を複数箇所へ渡せるようにするには、構文木を :term[論理回路]{en="Boolean circuit" yomi="ろんりかいろ"} に変える。ここでの回路は、入力とゲートを頂点とする有限の有向非巡回グラフである。各ゲートには結合子を割り当て、各入線が引数のどの位置に入るかを指定する。出力頂点を一つ指定すれば、入力を固定したときその出力が真理関数を定める。閉路がないため、前のゲートの出力だけを使う順序で評価できる。例えば一段ごとの値が互いを参照している回路は、この定義から外れる。

:::proposition[式と論理回路の表現力]{#prop-logic-circuit-representation}
結合子の集合を固定すると、その集合を使う式で表せる正アリティの真理関数と、同じ集合を使う回路で表せる真理関数は一致する。
:::

:::proof
式の葉を入力、各内部頂点を結合子のゲートにする。親のゲートへ各子の値を送り、根を出力にすれば、木の構造帰納法により回路の値と式の値は等しい。葉が同じ変数なら、一つの入力を複数のゲートにつないでもその値は変わらない。

逆に回路の各入力には対応する命題変数を割り当てる。ゲートを、各入線の始点が先に来る順序に並べる。各ゲートで、すでに定めた各入力元の式をそのゲートの結合子に入れれば式が得られる。この構成を最後まで行うと、各ゲートの式はすべての割り当てでそのゲートと同じ値を持つ。特に出力頂点に割り当てた式が回路の真理関数を表す。同じ入力元から二本の線が来る場合、対応する式を二箇所へ書く。
:::

:::example[複数の出力を持つ半加算器]
二進数の一桁 $p,q$ を加えると、下位桁は $s=p\oplus q$、繰上りは $c=p\land q$ である。$p+q=s+2c$ が四行すべてで成り立つ。具体的に $(p,q)=(0,0)$ なら $(s,c)=(0,0)$、一方だけが $1$ なら $(1,0)$、両方が $1$ なら $(0,1)$ である。二つの出力は同じ入力頂点から値を受け取る。NAND だけを使う場合、$u=p\uparrow q$ を共用できる。$c=u\uparrow u$、$s=(p\uparrow u)\uparrow(q\uparrow u)$ と書ける。後者の二つの内側はそれぞれ $\neg p\lor q$ と $p\lor\neg q$ である。その連言は $p=q$ の条件なので、外側の NAND は不一致を返す。
:::

:::example[回路を展開するときの重複]
$n$ 段の回路で $t_0=p$、各段で $t_{i+1}=t_i\uparrow t_i$ とする。回路では段ごとに NAND を一個だけ置き、同じ値を両入力へ渡す。前の式を両入力に書く翻訳をそのまま用いると、葉の数が段ごとに倍になるので展開後の葉は $2^n$ 個である。一方、各段は否定なので、最終関数は $n$ の偶奇により $p$ または $\neg p$ である。指数的になるのは指定した展開手順であり、この関数を表すすべての式についての下界ではない。
:::

真理表から回路を作る場合、真にしたい行のリテラルを連言ゲートでまとめ、最後に選言で結ぶ。逆に回路を節に変える場合は、各ゲートの出力変数を一度だけ導入する。:ref[prop-logic-tseitin] の局所制約は各ゲートで同じように働き、評価順に値が一意に決まるので、ゲート数に比例する節で済む。ここで大きさを抑えているのは、ゲートの式を複製せず、信号を変数のまま次段へ渡す操作である。

## Hilbert 流の証明体系

証明を有限の文字列列として記録する。体系の中で許す操作は公理図式と推論規則で尽くされる。そのため、意味論の事実から直接に証明行を書き足すことはできない。ここでは完全性の構成を見通しやすくするため、互いに冗長な図式を含める。

:::definition[公理と導出]{#def-logic-hilbert-prop}
$A,B,C$ を任意の式とする。以下の各行を :term[公理図式]{en="axiom schema" yomi="こうりずしき"} とする。

$$
\begin{aligned}
\mathrm{K}:&\ A\to(B\to A),\\
\mathrm{S}:&\ (A\to(B\to C))\to((A\to B)\to(A\to C)),\\
\mathrm{E}:&\ \neg A\to(A\to B),\\
\mathrm{I}:&\ A\to(\neg B\to\neg(A\to B)),\\
\mathrm{D}:&\ A\to\neg\neg A,\\
\mathrm{C}:&\ (A\to C)\to((\neg A\to C)\to C).
\end{aligned}
$$

唯一の推論規則 :term[モーダスポネンス]{en="modus ponens" yomi="もーだすぽねんす"} は $A,A\to B$ から $B$ を得る。$\Gamma\vdash B$ は、末尾が $B$ であり各行が仮定、図式の例、または先行行からの推論である有限列が存在することを表す。
:::

:::example[恒等式を導出する]
K により $A\to((A\to A)\to A)$ と $A\to(A\to A)$ を得る。S に $B=(A\to A),C=A$ を入れた式に最初の K を適用すると $(A\to(A\to A))\to(A\to A)$ を得る。次に二つ目の K を適用すれば $A\to A$ が出る。
:::

:::theorem[命題論理の演繹定理]{#thm-logic-prop-deduction}
$\Gamma\cup\{A\}\vdash B$ と $\Gamma\vdash A\to B$ は同値である。
:::

:::proof
左から右へは、元の導出の行 $D$ ごとに $A\to D$ の導出を作る。$D=A$ なら先の恒等式を使う。$D$ が公理または $\Gamma$ の元なら、$D$ と K の $D\to(A\to D)$ を使う。行 $D$ が $E,E\to D$ から出た場合、既に得た $A\to E,A\to(E\to D)$ と S から $A\to D$ が出る。右から左へは $A$ を仮定として加え、モーダスポネンスを使う。
:::

:::example[含意の合成]
$A\to B,B\to C,A$ を仮定して $B$、次に $C$ を得る。最後の仮定だけに :ref[thm-logic-prop-deduction] を適用すれば $\{A\to B,B\to C\}\vdash A\to C$ である。同じ操作を残る仮定にも適用すれば、仮定なしの式が得られる。
:::

### 仮定の管理と証明の合成

導出の一行を出発点からたどると、使った仮定を有限個まで絞れる。仮定の総数が無限でも、この点は変わらない。また仮定を外す順番を変えると、結果の含意の並びも変わる。例えば $\Gamma,A,B\vdash C$ に対して $B$ を先に外すと $\Gamma\vdash A\to(B\to C)$ となり、$A$ を先に外すと $\Gamma\vdash B\to(A\to C)$ となる。

:::proposition[導出の接合]{#prop-logic-proof-splice}
$\Delta\vdash B$ と $\Gamma\cup\{B\}\vdash C$ ならば $\Gamma\cup\Delta\vdash C$ である。
:::

:::proof
まず $\Delta$ からの導出を書き、$B$ の行を記録する。次に $\Gamma\cup\{B\}$ からの導出を順に読み、仮定 $B$ の行は先ほどの行を参照する。それ以外の仮定と公理は新しい列に書き写す。モーダスポネンスの行では、参照していた二行を、書き写した行または先ほどの $B$ の行に付け替える。終端が書き写される場合はその行が $C$ であり、省略される場合は $C=B$ なので最初の導出が使える。
:::

:::example[含意の引数順を換える]
$H=A\to(B\to C)$ とおく。仮定 $H,B,A$ の下で、$H,A$ から $B\to C$、次に $B$ から $C$ を得る。$A$ を外すと $H,B\vdash A\to C$、$B$ を外すと $H\vdash B\to(A\to C)$、$H$ を外すと $\vdash H\to(B\to(A\to C))$ となる。ここでは仮定列の物理的な並びも、証明行を読み進める順番も変えず、演繹定理の適用順だけを使った。
:::

:::example[正の仮定と負の仮定を両方使う導出]
$\Gamma=\{A\to B,\neg B\}$ とする。仮定 $A$ を足すと $B$ を得る。E の $\neg B\to(B\to\neg A)$ と順に合わせると $\neg A$ が出るため、$\Gamma\vdash A\to\neg A$ である。恒等式で $\Gamma\vdash\neg A\to\neg A$ でもある。C に $C=\neg A$ を入れ、二式へモーダスポネンスを用いると $\Gamma\vdash\neg A$ を得る。従って演繹定理で対偶の一方向 $(A\to B)\to(\neg B\to\neg A)$ を証明できる。
:::

### 代入と証明行の番号を追う

公理図式の例は式そのものだが、どの式がどの図式の例かは構文で判定する。K なら外側を含意二つに分け、最初と最後に現れる式の構文木が同じか確かめる。S でも同じメタ変数が現れる位置で、同じ木が入っているかを照合する。真理値が同じだけでは図式の例にならない。

:::example[五行で恒等を作る]
$B=A\to A$ とする。まず K で $A\to(B\to A)$ と $A\to B$ を二行に書く。次に S で
$$
(A\to(B\to A))\to((A\to B)\to(A\to A))
$$
を第三行に置く。第一行と第三行を参照して $(A\to B)\to(A\to A)$ を第四行に出し、第二行と第四行を参照して $A\to A$ を第五行に出す。$B$ が $A\to A$ であることは二行目を K にするために使う。初めから $A\to B$ を示したい最終式として参照しているわけではない。
:::

:::example[仮定を複数回使う証明]
$H=A\to(A\to B)$ と仮定 $A$ を用いる。一回目のモーダスポネンスの結果は $A\to B$、二回目の結果は $B$ である。二回とも同じ $A$ の行を参照してよい。演繹定理により $H\vdash A\to B$ となり、さらに $\vdash H\to(A\to B)$ を得る。仮定の使用回数を数えると二回だが、外した仮定は式 $A$ 一つである。
:::

## 健全性と完全性

真理表で正しい式を証明できるかを考える。まず導出が真を保つことを調べる。逆向きには、真理表の各行をリテラルの仮定に読み替え、最後に場合分けで仮定を外す。

:::theorem[命題論理の健全性]{#thm-logic-prop-soundness}
$\Gamma\vdash A$ ならば $\Gamma\models A$ である。
:::

:::proof
K が偽なら $A=1$ かつ $B\to A=0$ となり矛盾する。S が偽なら $A\to(B\to C)=A\to B=1$ と $A\to C=0$ が必要である。後者から $A=1,C=0$、中項から $B=1$ となり、前者に反する。E の二つの仮定 $\neg A,A$ は同時に真にならない。I の二つの仮定 $A,\neg B$ が真なら $A\to B$ は偽である。D は二重否定の評価から、C は $A$ と $\neg A$ のいずれかが真であることから真になる。モーダスポネンスは $1$ を保つため、行番号の帰納法が使える。
:::

:::lemma[真理表の各行の導出]{#lem-logic-prop-signed-line}
$A$ の変数の値を指定するリテラル集合を $\Gamma_v$ とする。$v(A)=1$ なら $\Gamma_v\vdash A$、$v(A)=0$ なら $\Gamma_v\vdash\neg A$ である。
:::

:::proof
変数の場合は仮定をそのまま取る。$A=\neg B$ で $B$ が偽なら帰納法で $\neg B$ を得る。$B$ が真なら $B$ と D から $\neg\neg B$ を得る。$A=B\to C$ の場合、$B$ が偽なら $\neg B$ と E で $B\to C$ を得る。$C$ が真なら $C$ と K で $B\to C$ を得る。残る行は $B$ が真、$C$ が偽の場合であり、$B,\neg C$ と I から $\neg(B\to C)$ を得る。
:::

:::theorem[有限仮定と恒真式の完全性]{#thm-logic-prop-finite-completeness}
有限集合 $\Gamma$ について $\Gamma\models A$ ならば $\Gamma\vdash A$ である。
:::

:::proof
まず $A$ が恒真なら、:ref[lem-logic-prop-signed-line] により全行で $A$ が導出される。末尾の変数 $p$ の値だけが異なる二行を選ぶ。その二行の共通仮定を $\Delta$ とすると、演繹定理で $\Delta\vdash p\to A,\neg p\to A$ が得られる。C と二回の推論で $\Delta\vdash A$ になる。変数を一つずつ除けば $\vdash A$ となる。

$\Gamma=\{B_1,\ldots,B_m\}$ の場合、$B_1\to(\cdots\to(B_m\to A))$ が偽なら全 $B_i$ が真で $A$ が偽である。仮定によってその行は存在しないから、今示した結果でこの入れ子の含意を証明できる。各 $B_i$ を使う順にモーダスポネンスを適用し、$A$ を得る。
:::

:::example[行を二つにまとめる]
$\{q,p\}\vdash q$ と $\{q,\neg p\}\vdash q$ では末尾が同じ仮定 $q$ である。演繹定理で $q$ から $p\to q$ と $\neg p\to q$ を出し、C で $q$ を回収できる。完全性の構成でも同じ操作で最後の列を消す。
:::

### 完全性の証明を実行する

真理表の行に付けた仮定を消す際には、消去する変数を決め、残りの変数の値を一致させる。途中で出来上がる導出は、残りの値だけを仮定に持つ。これを追跡すると、どの段にどの仮定が残るかを誤りにくい。

:::example[二重否定除去を C で得る]
$B=\neg\neg p\to p$ とする。$p$ を仮定した枝では、K の $p\to(\neg\neg p\to p)$ で $B$ を得る。$\neg p$ を仮定した枝では、E の $A=\neg p$ により $\neg\neg p\to(\neg p\to p)$ が得られる。より直接には、仮定を $\neg\neg p$ まで増やせば E と二回の推論で $p$ が得られ、$\neg\neg p$ を演繹定理で外すと $B$ が得られる。二枝に演繹定理を適用して $p\to B$ と $\neg p\to B$ を得て、C で $B$ とする。
:::

:::example[反例がある場合の枝]
$B=(p\to q)\to(q\to p)$ とする。$p=0,q=1$ の行では、$\neg p$ と E により $p\to q$、$q,\neg p$ と I により $\neg(q\to p)$ を得る。この二つを I に入れると $\neg B$ が出る。従ってこの行では完全性の証明で用いた符号付き導出が $B$ でなく $\neg B$ を出す。実際、同じ仮定から $B$ も導出できるとすると健全性に反する。
:::

:::proposition[矛盾の三つの判定]{#prop-logic-prop-inconsistent}
仮定集合 $\Gamma$ に対し、次は同値である。

1. $\Gamma$ からある式 $A$ と $\neg A$ の両方を導出できる。
2. $\Gamma$ から任意の式を導出できる。
3. $\Gamma$ のある有限部分が充足不能である。
:::

:::proof
1 から 2 は E と二回のモーダスポネンスによる。2 なら任意の変数とその否定を選べるため 1 である。1 が成り立つとき、二つの証明で実際に使った仮定の和を取れば有限であり、健全性によりそれを満たす割り当てはないので 3 が従う。3 ならその有限部分は任意の式を意味論的に含意するため、:ref[thm-logic-prop-finite-completeness] を任意の結論に適用して 2 を得る。
:::

### 強い証明と短い証明は別の主張である

真理表完全性は、任意の恒真式を有限時間で形式的な導出へ変換する方法を与える。その方法で各変数の値を全部指定すると、$m$ 変数では $2^m$ 個の行別導出を作る。最後の変数を消した直後は $2^{m-1}$ 個、その変数も消すと $2^{m-2}$ 個である。従って二枝合成だけでも $2^m-1$ 回の操作が必要になる。これはこの構成の数え方であり、同じ式にもっと短い証明がある場合もある。

:::example[仮定なしで短くなる場合]
$A\to A$ の内部に $m$ 種類の変数が現れるとする。真理表からは $2^m$ 行が作られるが、Hilbert 流の五行の証明では式 $A$ の中身を展開しない。K と S は任意の式をそのまま引数にするため、変数が何個あっても五行の形は変わらない。ただし各行の文字数には $A$ の長さが反映される。
:::

:::example[仮定のない恒真式を帰結に使う]
$\vdash(A\land B)\to A$ は有限完全性で得られる。$\Gamma\vdash A\land B$ が与えられれば、この恒真式の証明を付け加えてモーダスポネンスで $\Gamma\vdash A$ を作れる。両者を合わせるときに必要なのは、恒真式に証明があることと、実際に導出済みの行を参照することである。単に $\Gamma\models A$ と書いただけでは形式的な一行にならない。
:::

## 命題論理のコンパクト性

各有限部分に対して充足する割り当てが存在しても、同じ割り当てを選べるとは限らない。そこで変数の値を固定するとき、その後も有限充足性を保つ枝を選ぶ。

:::theorem[コンパクト性]{#thm-logic-prop-compactness}
可算個の命題変数上で、任意の有限部分集合が充足可能な式集合 $\Gamma$ は充足可能である。
:::

:::proof
$p_0,p_1,\ldots$ の順に、$\Gamma$ と既に選んだリテラルの和集合が有限充足可能という条件を保つ。次の $p_i,\neg p_i$ をそれぞれ加えると有限充足性が壊れると仮定する。二つの失敗を起こした有限部分の和集合は、$p_i$ のいずれの値でも満たせず、追加前の有限充足性に反する。したがって少なくとも一方を選べる。割り当て $v$ をその選択で定める。$A\in\Gamma$ の変数は有限なため、すべて選択済みとなる段がある。$A$ とその変数のリテラルを含む有限部分は充足可能であり、:ref[prop-logic-prop-substitution] により $v(A)=1$ となる。
:::

変数の集合が整列可能なら、同じ操作をその整列順で行える。極限段で有限個の式が問題となる場合、それらはすべて極限より前のある一段に含まれる。したがって有限充足性が保たれる。一般の変数集合に整列順を選ぶには、メタ理論で選択公理を使える。可算の場合は $0$ が選べるときは $0$ と決めればよい。

:::corollary[有限性と強完全性]{#cor-logic-prop-strong-completeness}
$\Gamma\models A$ なら、ある有限 $\Gamma_0\subseteq\Gamma$ について $\Gamma_0\models A$ である。したがって $\Gamma\models A$ と $\Gamma\vdash A$ は同値である。
:::

:::proof
$\Gamma\cup\{\neg A\}$ は充足不能であるから、:ref[thm-logic-prop-compactness] の対偶により有限の充足不能部分がある。そこから $\neg A$ を取り除いた $\Gamma_0$ と $\neg A$ は同時に真にならない。よって有限完全性で $\Gamma_0\vdash A$、したがって $\Gamma\vdash A$ である。逆向きは健全性である。
:::

:::example[有限グラフの彩色から無限グラフへ]
$k\ge 1$ とし、任意の頂点集合に対するコンパクト性を用いる。各頂点 $v$ と色 $i\in\{1,\ldots,k\}$ に変数 $p_{v,i}$ を置く。各頂点の「少なくとも一色」と「二色を同時に選ばない」を式にし、各辺 $\{v,w\}$ に $\neg(p_{v,i}\land p_{w,i})$ を色ごとに課す。有限個の式が関わる頂点は有限個なので、すべての有限誘導部分グラフが $k$ 彩色可能なら有限充足性を得る。コンパクト性による割り当ては、各頂点にちょうど一色を与え、辺の両端を異なる色にする。
:::

:::example[可算和と有限式]
$\Gamma=\{p_i:i\in\N\}$ の全条件を一つの式 $A$ で表すことはできない。仮に表せるなら、$A$ の変数に現れない $p_j$ を選べる。全変数を真にした割り当てから $p_j$ だけを偽にしても $A$ の値は変わらず、$\Gamma$ の条件は破れる。コンパクト性は無限の論理積を言語に追加する定理ではない。
:::

### 有限列の木から割り当てを得る

可算個の変数の場合には、有限充足性を有限二分木の性質へ写せる。長さ $n$ の二進列 $s$ を、第 $n$ 変数より前の変数だけを含む $\Gamma$ の式すべてを満たすときに木へ入れる。第 $n$ 変数より前の変数に限った条件は式として無限個あり得るが、区別できる行は $2^n$ 個しかない。

:::lemma[有限分岐の木の無限枝]{#lem-logic-prop-konig-branch}
空列から始まり、各節点の子が有限個で、任意の有限の高さに節点を持つ木には無限枝がある。
:::

:::proof
空列の下には任意の有限の高さの節点がある。これと同じ性質を持つ節点を得たとする。子がすべて有限の高さまでしか子孫を持たなければ、子の有限個の上界の最大値に一を足した値が、節点の下の高さの上界になる。従って同じ性質を持つ子を一つ選べる。各節点の子に順がある場合は最小のものを選ぶ。これを各有限段で行って得られる鎖は無限枝である。
:::

各 $n$ で上の二進列が一つも残らないなら、$2^n$ 行それぞれについて排除する式を一つ選べる。その有限個の式は同時に満たせず、仮定に反する。許される列を切り詰めた列は許され、従って :ref[lem-logic-prop-konig-branch] を適用できる。枝の値を割り当てとすれば、どの式も自身の変数が全部現れる高さで真になる。

:::example[局所条件の連鎖]
$\Gamma=\{p_n\lor p_{n+1},\neg p_n\lor\neg p_{n+1}:n\in\N\}$ は隣り合う二変数の値が異なることを要求する。長さ三の許容列は $010$ と $101$ である。それぞれに次の値を付ける方法が一つだけあり、無限枝は $0101\cdots$ と $1010\cdots$ になる。さらに $p_0$ を加えると後者だけが残る。さらに $p_2$ の否定を加えると、隣接条件の最初の二つの対と合わせた有限部分でもう矛盾する。
:::

:::example[無限個の二項選択]
変数 $p_0,p_1,\ldots$ に、$i<j$ のたび $\neg p_i\lor\neg p_j$ を課す。長さ $n$ の許容列は、全零の列一つと $1$ がちょうど一つの列 $n$ 個である。木の無限枝は全零と、一度だけ $1$ が現れる列である。「少なくとも一つ $1$」はこの言語の単独の有限式に書けない。実際、そのような式が有限個の変数しか見ないなら、それらの外に一つだけ $1$ を置く評価と全零の評価を区別できない。
:::

### 極大な有限充足部分を作る

命題変数の集合が任意の場合も、メタ理論で選択公理を用いれば有限充足性から割り当てを作れる。有限充足可能な式集合 $\Gamma$ を含む有限充足可能な式集合を包含で順序付ける。鎖の和の任意の有限部分はある鎖の元に含まれるため、和はその族の上界である。:ref[thm-sets-zorn] により極大元 $S$ が得られる。もし命題変数 $p$ に対して $p,\neg p$ のどちらも入らなければ、両方を別々に加えることで有限充足性を壊す有限集合がある。二つの有限集合を合わせると、$p$ の両値が排除されて元の有限充足性に反する。従って $S$ は各変数に一意の値を与える。任意の $A\in S$ は有限個の変数しか含まず、その全値を指定した有限部分を充足できるため、得られた割り当てで真になる。

:::example[候補を一つ選ぶだけなら有限充足性で足りる]
$\Gamma=\{\neg p_n:n\in\N\}$ の有限部分には未指定の変数がいくらでもあり、二通り以上の評価を持つ。全体の充足割り当てはすべての $p_n$ が偽となる一通りだけである。従って、各有限部分に二つの割り当てがあるという条件を一意性の否定に使うことはできない。一方、指定の変数 $p_0$ で異なる二評価を各有限部分が持つと仮定すれば、$\Gamma\cup\{p_0\}$ と $\Gamma\cup\{\neg p_0\}$ に別々にコンパクト性を適用できる。これで $p_0$ の値が違う二つの全体解が得られる。
:::

## 演習問題

::::exercise{level=basic}
$(p\to\neg(q\to p))$ の高さ、葉の数、含意の数を求めよ。
:::solution
$(q\to p)$ の高さは $1$、その否定は $2$ であり、外側の含意を加えると高さは $3$ である。葉は左から $p,q,p$ の $3$ 個、含意は内外の $2$ 個である。
:::
::::

::::exercise{level=basic}
$p\to(q\to r)$ が偽になる割り当てをすべて求めよ。
:::solution
最外の含意が偽なら $p=1$ で $q\to r$ が偽である。内側の含意が偽になる条件は $q=1,r=0$ である。したがって $(1,1,0)$ の一行のみである。
:::
::::

::::exercise{level=basic}
$p\leftrightarrow q$ の二つの完全標準形を求めよ。
:::solution
真の行は $(0,0),(1,1)$ なので $(\neg p\land\neg q)\lor(p\land q)$ になる。偽の行 $(0,1),(1,0)$ を除くと $(p\lor\neg q)\land(\neg p\lor q)$ になる。
:::
::::

::::exercise{level=basic}
NOR のみで $p\land q$ を表せ。
:::solution
$(p\downarrow p)\downarrow(q\downarrow q)$ を用いる。内側は $\neg p,\neg q$ であり、外側はこの両方が偽のときに限り真である。この条件は $p=q=1$ と一致する。
:::
::::

::::exercise{level=advanced}
$\vdash (A\to(B\to C))\to(B\to(A\to C))$ を示せ。
:::solution
$A\to(B\to C),B,A$ を仮定する。最初と最後から $B\to C$ を得て、$B$ との推論で $C$ を得る。$A,B,A\to(B\to C)$ の順に演繹定理を適用すると指定式が出る。
:::
::::

::::exercise{level=advanced}
公理図式と規則だけで $\{\neg\neg A\}\vdash A$ を示せ。
:::solution
$\neg\neg A,\neg A$ から E の $X=\neg A,Y=A$ の例を用いて $A$ を得る。演繹定理により $\neg\neg A$ の下で $\neg A\to A$ を得る。恒等式 $A\to A$ と C の $C=A$ の例を順に使うと $A$ が出る。
:::
::::

::::exercise{level=advanced}
$\{p_i\to p_{i+1}:i\in\N\}\cup\{p_0,\neg p_3\}$ の充足不能な有限部分と、そのどの一式を落としても充足可能であることを示せ。
:::solution
最初の三つの含意と二つの端の条件を取る。$p_0=1$ から順に $p_1=p_2=p_3=1$ が必要なので矛盾する。$p_0$ を外せば全て $0$、$\neg p_3$ を外せば全て $1$ でよい。第 $i$ の含意を外したら添字 $i$ までは $1$、以降を $0$ にすると残る式を満たす。
:::
::::

::::exercise{level=advanced}
無限の式集合 $\Gamma$ がどの有限部分にも二通り以上の割り当てを持つとする。この条件で $\Gamma$ 自体にも二通り以上あるかを判定せよ。
:::solution
$\Gamma=\{p_i:i\in\N\}$ を考える。各有限部分では現れない変数の値を $0$ と $1$ に変えられる。しかし全体ではすべての変数に $1$ を指定する一通りだけである。二つの割り当てがどの変数で異なるかが有限部分ごとに変わり得る。
:::
::::

::::exercise{level=advanced}
二項結合子 $f(p,q)=\neg p\lor q$ と $g(p)=0$ は関数完全な族をなすか。満たす場合は $\neg p$ と $p\land q$ の具体的な翻訳を与えよ。
:::solution
$f(p,g(p))=\neg p\lor0=\neg p$ である。従って否定を作った後、$f(p,\neg q)=\neg p\lor\neg q$ をさらに否定すれば $p\land q$ を得る。$f(p,g(p))$ の形をこの外側の否定にも使えば、二つのもとの結合子だけで書ける。否定と連言で選言も作れるから :ref[thm-logic-prop-normal-form] により関数完全である。$g$ は引数を持つ定数関数なので、正のアリティの規約にも合う。
:::
::::

::::exercise{level=advanced}
節集合 $p\lor q,\neg p\lor r,\neg q\lor r,\neg r\lor s,\neg s$ の充足可能性を、単位伝播と二リテラル節の判定の双方で調べよ。
:::solution
単位節から $s=0$、第四節から $r=0$ を得る。第二と第三節からそれぞれ $p=0,q=0$ となり、第一節と矛盾する。有向グラフでは $p\to r\to s\to\neg s\to\neg r\to\neg p$ と進める。逆向きには $\neg p\to q\to r\to s\to\neg s\to\neg r\to\neg q\to p$ と進める。従って $p$ とその否定が同じ強連結成分にあり、:ref[prop-logic-two-sat] からも充足不能となる。
:::
::::

## 確認テスト

::::quiz{answer="7" tol="0"}
三変数の式 $(p\land q)\to r$ が真になる行は何行か。
:::explanation
全 $2^3=8$ 行のうち、偽になるには $p=q=1$ かつ $r=0$ が必要十分である。その一行を除いた $7$ 行で真となる。
:::

::::quiz
$\Gamma\vdash A$ の意味として正しいものを選べ。

- [x] 公理と仮定と規則で作った有限列がある。
- [ ] $A$ を真にする割り当てが一つある。
- [ ] $\Gamma$ の全式がある一つの証明に現れる。

:::explanation
導出は各行の出所が指定された有限列である。$A$ の充足可能性は意味論の別の条件であり、仮定集合が無限であっても一つの証明が使う仮定は有限である。
:::

::::quiz{answer="16" tol="0"}
二変数の真理関数は何個あるか。
:::explanation
入力の組は四通りである。各行の出力に独立に $0,1$ を選ぶので $2^4=16$ 個である。
:::

::::quiz
命題論理のコンパクト性から従うものを選べ。

- [ ] 充足可能な無限集合にはすべての変数が偽となる解がある。
- [x] 充足不能な式集合には充足不能な有限部分がある。
- [ ] 充足不能な式集合の全有限部分が充足不能である。

:::explanation
定理の対偶は、充足不能な式集合のうち、有限回の検査だけで矛盾を示せる部分が存在することを述べる。例えば $\{p,\neg p\}$ は充足不能だが $\{p\}$ は充足可能である。また $\{p\}$ の解では $p$ が必ず真である。
:::
