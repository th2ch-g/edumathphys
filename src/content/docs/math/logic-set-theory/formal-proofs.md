## この章の目標

- 一階論理の論理公理と一般化規則を使い分ける。
- 自由変数に関する条件を確認して演繹定理を適用する。
- 自然演繹とシークエント計算で同じ帰結を導出する。
- 各規則が真を保つ理由を、量化子の規則を含めて説明する。

## 公理系と推論規則

命題論理の証明に量化を加えるには、全称文から具体例を取り出す操作と、任意に取った元についての証明を全称文にまとめる操作を分ける。後者ではその元に関する仮定が残っているかを調べる。

:::definition[一階の Hilbert 体系]{#def-logic-hilbert-first}
命題論理の :ref[def-logic-hilbert-prop] の図式に一階の式を代入したものと、次の図式を論理公理とする。

$$
\begin{aligned}
&\forall x\,A\to A[t/x],\\
&\forall x(A\to B)\to(\forall x A\to\forall x B),\\
&A\to\forall x A\quad(x\notin\mathrm{FV}(A)),\\
&t=t,\qquad t=u\to(A[t/x]\to A[u/x]).
\end{aligned}
$$

図式で使う項は自由に代入可能とする。仮定集合 $\Gamma$ の下で、モーダスポネンスと :term[一般化]{en="generalization" yomi="いっぱんか"} を使う。一般化では $A$ から $\forall x A$ を得るが、$x$ は用いた仮定のどれにも自由に現れてはならない。厳密には、各行は有限の依存集合を持ち、公理では空集合、仮定では自分だけ、モーダスポネンスでは前提の依存集合の和集合、一般化では前提と同じ集合を付ける。
:::

等号に関する最後の図式を使うと、$s=t$ から $t=s$ が得られる。$s,t,u$ に現れない変数 $x$ を選ぶ。$A(x)$ を $x=s$ とすると $s=t$ と $s=s$ から結論が出る。推移律では $s=t,t=u$ を仮定して $A(x)$ を $s=x$ とする。さらに $f(s)=f(t)$ を得るには $A(x)$ を $f(s)=f(x)$ とすればよい。図式に任意の式を許しているため、関係だけでなく量化を含む式でも同じ方法で置換できる。

:::example[全称文の具体化]
$\forall xP(x)$ と $\forall x(P(x)\to Q(f(x)))$ を仮定する。両方に $c$ を代入して $P(c)$ と $P(c)\to Q(f(c))$ を得る。モーダスポネンスで $Q(f(c))$ が出る。この手順で $c$ は解釈を持つ定数である。
:::

:::example[一般化できない仮定]
$P(x)$ を唯一の仮定とする導出で、仮定そのものから $\forall xP(x)$ へ進むことは禁じる。実際、二元構造で $P=\{0\},s(x)=0$ とすれば前者だけが真となる。他方、$P(x)\to P(x)$ は仮定なしに導出できるため $x$ について一般化できる。
:::

### 論理公理と固有公理を識別する

群の結合法則 $\forall x\forall y\forall z((xy)z=x(yz))$ は群の理論の公理である。これに対し $\forall x\,\varphi(x)\to\varphi(t)$ は、代入条件を守る限り、群以外の構造でも真となる論理公理である。証明検査では、一行ごとにどちらの公理を使ったか、その照合に変数条件があるかを記録する。

:::example[全称の消去を二度行う]
$\forall x\forall y\,R(x,y)$ を仮定し、閉項 $a,b$ を使う。第一段の公理例は $\forall x\forall y R(x,y)\to\forall y R(a,y)$ である。モーダスポネンスで $\forall y R(a,y)$ が出る。第二段の公理例 $\forall y R(a,y)\to R(a,b)$ と合わせて $R(a,b)$ を得る。$a,b$ が閉項であるため、代入による変数捕獲はない。
:::

:::example[仮定を文にする効用]
$\forall x(P(x)\to Q(x))$ と $\forall x P(x)$ から $\forall x Q(x)$ を導く。まず両全称を新変数 $u$ に特殊化し、$P(u)\to Q(u)$ と $P(u)$ から $Q(u)$ を得る。仮定は二つとも文で $u$ は自由に現れないので、一般化で $\forall u Q(u)$ を得る。第二の仮定が $P(u)$ であれば一般化の条件が壊れ、$P^\mathcal M=Q^\mathcal M=\{0\}$ の二元モデルが帰結の反例になる。
:::

### 導出の依存集合を検査する

証明に登場する仮定と、末尾まで引き継ぐ仮定は一致するとは限らない。例えば仮定 $P(x)$ を途中に書いた後、別の行から $Q(x)\to Q(x)$ を論理だけで導いたなら、後者の依存集合は空である。よってその直後に $x$ で一般化できる。証明候補を検査するときは、各規則が参照した行の依存集合だけを合併する。この方法では使っていない仮定に制約を課さず、使った仮定に関する健全性を保てる。

:::example[二行の依存を合わせる]
仮定 $A=P(x)$、$B=\forall y(P(y)\to R(y))$ を取る。$B$ の具体化 $P(x)\to R(x)$ の依存集合は $\{B\}$ である。$P(x)$ と合わせた $R(x)$ の依存集合は $\{A,B\}$ となる。この行から $x$ について一般化できない。ところが $A$ を演繹定理で外した $P(x)\to R(x)$ は再び $B$ のみに依存し、$B$ は文なので全称化できる。
:::

## 演繹定理

:::theorem[一階の演繹定理]{#thm-logic-first-deduction}
$\Gamma\cup\{A\}\vdash B$ ならば $\Gamma\vdash A\to B$ である。逆も成り立つ。
:::

:::proof
元の導出の各行 $D$ に対して、$A$ を除いた依存集合から $A\to D$ を導く。仮定と公理の行、およびモーダスポネンスの行は :ref[thm-logic-prop-deduction] と同じ構成で処理する。一般化の行を $D=\forall x E$ とする。

$E$ が $A$ に依存しない場合、前提から $D$ までの導出も $A$ に依存しない。その導出と公理 K で $A\to D$ を得る。$E$ が $A$ に依存する場合、元の規則により $x\notin\mathrm{FV}(A)$ である。帰納法で得た $A\to E$ を $x$ について一般化できる。分配の図式から $\forall x A\to\forall x E$ を得る。さらに $A\to\forall x A$ と含意の合成で $A\to\forall x E$ を得る。逆は $A\to B$ と仮定 $A$ にモーダスポネンスを適用すればよい。
:::

仮定のラベルを追跡すると、使わなかった仮定に自由変数が現れても一般化できる。例えば $\{P(x)\}$ を利用可能な集合に入れても、仮定なしの恒等式の導出は妨げられない。

:::example[量化子と含意]
$x$ が $A$ に自由に出ないとする。$\forall x(A\to B)$ と $A$ を仮定して、変数 $x$ で具体化し $B$ を得る。二つの仮定に $x$ の自由出現はないので $\forall x B$ を得る。:ref[thm-logic-first-deduction] で両仮定を外せば $\forall x(A\to B)\to(A\to\forall xB)$ が導ける。
:::

### 一般化を含む行の変換

ある証明の仮定を一つ外す作業は、その証明のどこで任意の元が必要だったかを確認する作業でもある。例えば $\forall x(P(x)\to Q(x)),\forall xP(x)\vdash\forall xQ(x)$ の第二仮定を外すと、各行の前に $\forall xP(x)\to$ を付けた証明を作れる。特に末尾の一般化では、$u$ がこの前件に自由に出ないため、$\forall u(\forall xP(x)\to Q(u))$ から $\forall xP(x)\to\forall u Q(u)$ へ移れる。

:::example[条件を不必要に強めると使える導出を逃す]
$\Gamma=\{P(x),\forall y(R(y)\to R(y))\}$ とする。$\Gamma$ の第一式は $x$ を自由に含むが、第二式だけから $R(z)\to R(z)$ を得る作業に第一式は不要である。実際には $R(z)\to R(z)$ は論理だけから導けるので、仮定をすべて外して $\forall x(R(z)\to R(z))$ を導き、最後に $\Gamma$ を許した証明として使える。一般化に使えない仮定が集合に含まれる場合でも、使った仮定を絞れば一般化が可能なことがある。
:::

:::example[含意と量化の順序]
$\forall x(P(x)\to Q)\models(\exists x P(x))\to Q$ は、$x$ が $Q$ に自由に出ない場合に成り立つ。存在の証人 $a$ を取り、全称の $x$ にその値を指定すれば $Q$ が真になる。$Q$ の評価は割り当ての $x$ 成分に依存しないので結論に戻せる。$Q=P(x)$ と取ると全称の仮定は恒真である。領域 $\{0,1\}$、$P=\{0\}$、$s(x)=1$ とすれば、右辺の前件 $\exists xP(x)$ は真で後件 $P(x)$ は偽になる。従ってこの割り当てが反例となる。
:::

### 無限の仮定を有限の証明で扱う

$\Gamma$ が無限集合でも証明は有限列なので、末尾の依存集合は有限である。従って $\Gamma\vdash B$ ならある有限 $\Gamma_0\subseteq\Gamma$ があって $\Gamma_0\vdash B$ となる。逆に仮定を増やしても使った行とその依存集合はそのままなので、$\Gamma_0\vdash B$ から $\Gamma\vdash B$ が従う。演繹定理を繰り返し使えば $\vdash A_1\to(\cdots\to(A_n\to B))$ になる。この有限性は証明の形式から出ており、意味論での有限性は [完全性定理とコンパクト性定理](/math/logic-set-theory/completeness/) で扱う。

:::example[三つの仮定を二つに絞る]
$\Gamma=\{P(x), P(x)\to Q(x), R(x)\}$ から $Q(x)$ を導くとき、規則が参照するのは先頭二式だけである。$R(x)$ を除いた後、$P(x)$ を外せば仮定 $P(x)\to Q(x)$ と同一の式を結論として得る。続けてその仮定も外すと $\vdash(P(x)\to Q(x))\to(P(x)\to Q(x))$ になる。末尾が同一式になることは、先に外した仮定を物理的に削除するだけでは導出を保てないことも示している。
:::

## 一般化定理と同値置換

:::theorem[全称閉包と同値置換]{#thm-logic-first-congruence}
$\Gamma$ が文集合なら、$\Gamma\vdash A$ と $\Gamma\vdash\forall\vec x A$ は同値である。ただし $\vec x$ は $A$ の自由変数の列である。また $\vdash A\leftrightarrow B$ なら、指定された部分式の出現を $A$ から $B$ に置き換えた二式の同値は証明できる。
:::

:::proof
文には自由変数がないため、順に一般化して全称閉包を得る。逆は束縛に使った変数そのもので順に具体化する。

置換について、置換位置から外側へ一段ずつ進む。否定と含意の位置では、部分の同値から全体の同値が従う式が恒真である。したがって :ref[thm-logic-prop-finite-completeness] と代入で必要な導出を得る。例えば $A\to B$ と $B\to A$ から $\neg B\to\neg A$ と $\neg A\to\neg B$ を得る。量化子の位置では $A\to B$ と $B\to A$ をそれぞれ一般化し、分配の図式を適用する。得られた二つの含意を連言にまとめる。存在量化の場合は否定と全称の略記に戻す。
:::

:::example[量化子の交換]
$\forall x\forall yP(x,y)$ を仮定する。まず $x$、次に $y$ のままで具体化して $P(x,y)$ を得る。仮定は文なので $x$、次に $y$ について一般化できる。演繹定理で $\forall x\forall yP(x,y)\to\forall y\forall xP(x,y)$ を得て、逆も同じ手順で導く。
:::

:::example[量化子の下での等価変形]
$\neg(P(x)\lor Q(x))$ と $\neg P(x)\land\neg Q(x)$ は命題論理で同値である。したがって両方に $\forall x$ を付けた式は同値となる。逆に、局所仮定 $P(x)\leftrightarrow Q(x)$ の下では、同じ手順で全称文の同値を導けない。$x$ で一般化する時点でその仮定が自由変数条件に触れる。
:::

### 定数を新変数に移す

新定数 $c$ を追加した証明の中で、$c$ を含まない仮定から $B(c)$ を導けたとする。証明全体に出ない変数 $z$ を選び、全行で $c$ を $z$ にする。代入公理で使用した束縛変数にも一般化で使用した変数にも $z$ は現れていない。従って置換によって既存の代入条件は壊れず、各行が同じ規則の例になる。仮定の側には $z$ が現れないので、末尾に一般化を施せる。この操作は、特定の公理系の証明に新定数を仮に導入して、最後にその名前を消したいときに使う。

:::example[特定の定数を消せない場合]
$P(c)$ が固有公理なら、上と同じ置換の後に $P(z)$ を仮定として残す必要がある。従って $\forall z P(z)$ は導けない。$P$ が $c$ の値でだけ成り立つ二元構造が反例である。証明の内部にある新定数と、理論の仮定で特性を指定された定数を区別する必要がある。
:::

:::example[局所同値を量化子の下に移せない場合]
$\Gamma=\{P(x)\leftrightarrow Q(x)\}$ から、$P(x)$ と $Q(x)$ の同値は直接得られる。ところが $P^\mathcal M=\{0,1\}$、$Q^\mathcal M=\{0\}$、$s(x)=0$ とすれば仮定は真で、$\forall xP(x)$ と $\forall xQ(x)$ は異なる値を持つ。量化子の下での同値置換には、各候補について同値を再確認できる全称閉包または変数条件が必要になる。
:::

### 固定した式の適切な実例を取る

定理 $\vdash A$ の自由変数を項で置き換えたいとする。まず自由変数の全称閉包を取り、それぞれに全称除去の公理を適用する。代入項の中にほかの自由変数が出るときは、先に全称化する変数をすべて新しい名前に変えてから閉包する。そうすれば後で一つを具体化しても、以前に入れた項の自由変数を次の全称子が束縛しない。この操作は、証明全体を一律に代入して一般化の変数まで変更する場合に生じる問題を避けられる。

:::example[全称閉包から引数を交換する]
$Q(x,y)\to Q(x,y)$ の全称閉包を、新変数 $u,v$ を使って $\forall u\forall v(Q(u,v)\to Q(u,v))$ とする。まず $u$ に $y$、次に $v$ に $x$ を代入する。結果は $Q(y,x)\to Q(y,x)$ になる。元の $\forall x\forall y$ に最初に $y$ を入れると、内側の $y$ が捕獲するためそのままの公理例にはならない。
:::

### 束縛変数の改名と代入

捕獲を避ける改名が真偽を保つことは :ref[lem-logic-substitution] から分かる。ここでは完全性を使わず、改名前後の同値を証明する。$y$ が $A$ に現れないとする。$\forall x A$ から全称具体化で $A[y/x]$ を得る。唯一の仮定 $\forall x A$ に $y$ が自由に出ないので、$\forall y A[y/x]$ を得る。逆に $\forall y A[y/x]$ を $x$ で具体化すれば $A$ に戻る。実際、$y$ に変更された位置は元の自由な $x$ の位置だけなので、それらの上に $x$ の束縛子はない。また仮定 $\forall y A[y/x]$ に $x$ は自由に残っていないので、$x$ で一般化できる。両方向に演繹定理を適用し、命題論理の連言導入で同値を得る。存在の場合は $\neg\forall x\neg A$ に同じ議論を適用し、否定による同値置換を使う。部分式の中の改名は :ref[thm-logic-first-congruence] で全体に広げられる。

:::example[項を挿入する前に改名する]
$\forall x\exists y\,R(x,y)$ から外側の $x$ に項 $f(y)$ を入れたいとする。内側の $y$ を残したまま $R(f(y),y)$ を作ると、代入項の自由な $y$ が捕獲される。内側の存在式をまず $\exists z\,R(x,z)$ に改名し、その同値を外側の全称に伝える。すると $\forall x\exists z\,R(x,z)$ を証明でき、$f(y)$ を自由に代入した $\exists z\,R(f(y),z)$ に進める。さらに元の仮定は文なので、この結論を $y$ で全称化できる。
:::

:::proposition[定理への同時代入]{#prop-logic-theorem-substitution}
$\vdash A$ とし、$x_1,\ldots,x_n$ を相異なる変数とする。任意の項 $t_1,\ldots,t_n$ に対し、捕獲を避けた同時代入 $A[\vec t/\vec x]$ も定理である。
:::

:::proof
まず、代入項に出る変数との衝突を避けるよう束縛変数を改名する。さらに $A$、全代入項、$x_1,\ldots,x_n$ のいずれにも現れない相異なる $u_1,\ldots,u_n$ を選ぶ。$x_n,\ldots,x_1$ の順で一般化して、外側から $x_1,\ldots,x_n$ が並ぶ全称式を得る。その全称子を $u_i$ に改名した後、外側から $t_1,\ldots,t_n$ で具体化する。各 $t_i$ はほかの $u_j$ を含まず、内部の量化子にも捕獲されない。よって最後の式は同時代入の結果である。別の新変数を用いて代入を定めた場合も、改名の同値からその式を得られる。
:::

仮定がある場合も、元の導出にある量化子を直接書き換える必要はない。使った有限個の仮定 $A_1,\ldots,A_m$ を演繹定理で外し、$\vdash A_1\to(\cdots\to(A_m\to B))$ を得る。この一式に :ref[prop-logic-theorem-substitution] を用い、置換した $A_i$ を順に適用する。各仮定と結論を別々に代入して得た束縛名が異なる場合は、同値置換で合わせる。例えば $P(x),P(x)\to Q(x,y)\vdash Q(x,y)$ で $x,y$ を入れ替えると、$P(y),P(y)\to Q(y,x)\vdash Q(y,x)$ が得られる。

### 仮定を証明で置き換える

先に証明した $B$ を、別の証明で仮定した $B$ の代わりに使いたいとする。そのまま貼り付けると、後者の一般化で用いる依存集合が変わることがある。例えば $P(x)\vdash\exists yP(y)$ と $\{\exists yP(y)\}\vdash\forall x\exists yP(y)$ を考える。後者の一般化は文 $\exists yP(y)$ の下で許されるが、その仮定を前者の導出で置き換えると依存集合に $P(x)$ が入る。この場合は先に $\exists yP(y)\to\forall x\exists yP(y)$ を空虚全称化の公理として使えば、目的の結論を得られる。

:::proposition[演繹定理による導出の接合]{#prop-logic-first-proof-splice}
$\Delta\vdash B$ かつ $\Gamma\cup\{B\}\vdash C$ ならば $\Gamma\cup\Delta\vdash C$ である。
:::

:::proof
二つ目の導出に :ref[thm-logic-first-deduction] を適用して $\Gamma\vdash B\to C$ を得る。これと $\Delta$ 下の $B$ の導出を、仮定集合 $\Gamma\cup\Delta$ の下で並べる。各行の依存集合は変わらない。最後にモーダスポネンスで $C$ を得る。
:::

### 量化の分配と範囲

$\forall x(A\land B)$ から二つの全称を得るには、具体化した連言から $A,B$ を取り、その各々を一般化する。逆向きには $\forall x A,\forall x B$ から各実例を取り、$A\land B$ を作って一般化する。いずれも $x$ は元の仮定に自由に出ない。各向きの仮定を外して $\forall x(A\land B)\leftrightarrow(\forall x A\land\forall x B)$ を得る。この分配と否定の双対から $\exists x(A\lor B)\leftrightarrow(\exists x A\lor\exists x B)$ が出る。具体的には左を $\neg\forall x(\neg A\land\neg B)$ と同値にし、分配した後に De Morgan の法則を使う。

:::example[分配の逆が失敗する場合]
$\exists xA\land\exists xB$ が真でも、同じ元が二つの条件を満たすとは限らない。相異なる二元をそれぞれ一方の述語にだけ入れた構造が反例である。同じ構造は $\forall x(A\lor B)\to(\forall x A\lor\forall x B)$ の反例にもなる。各元はいずれかに入る一方、どちらの述語も全域を尽くさないからである。健全性を用いれば、これらの含意には導出がないことも分かる。
:::

## 自然演繹

:term[自然演繹]{en="natural deduction" yomi="しぜんえんえき"} では、仮定を付けて部分証明を開き、規則で仮定を解除する。$\bot$ を常に偽の記号、$\neg A$ を $A\to\bot$ とみなした古典体系を記す。$\land,\lor,\exists$ はこの節では規則を持つ結合子として扱う。

| 記号 | 導入 | 除去 |
|---|---|---|
| $\land$ | $A,B$ から $A\land B$ | $A\land B$ から各成分 |
| $\lor$ | 片方から $A\lor B$ | $A\lor B$ と $A,B$ 各々を仮定した $C$ の導出から $C$ |
| $\to$ | 仮定 $A$ から $B$ を得て $A$ を解除 | $A\to B,A$ から $B$ |
| $\forall x$ | $A$ から $\forall x A$、未解除仮定に $x$ が自由に出ない | 自由代入できる項 $t$ について $A[t/x]$ |
| $\exists x$ | 自由に代入可能な $t$ に対し $A[t/x]$ から $\exists xA$ | $\exists xA$ と $A[y/x]$ を仮定した $C$ の導出から $C$ |

選言除去では二つの仮定を解除する。存在除去では $A[y/x]$ を解除し、$y$ は結論、存在式、残る仮定に自由に出ない新変数とする。等号は $t=t$ と、$t=u,A[t/x]$ から $A[u/x]$ を得る規則で扱う。$\bot$ から任意の式を得る規則と、$\neg A$ を仮定して $\bot$ を得た部分証明から $A$ を得る古典的背理法を加える。

:::example[存在文から存在文へ]
$\forall x(P(x)\to Q(x))$ と $\exists xP(x)$ から $\exists xQ(x)$ を導く。存在除去の部分証明で $P(y)$ を仮定する。全称除去で $P(y)\to Q(y)$ を得て $Q(y)$、存在導入で $\exists xQ(x)$ を得る。$y$ は結論や他の仮定に出ないため、$P(y)$ を解除できる。
:::

:::example[古典的な二重否定除去]
$\neg\neg A$ を仮定する。さらに $\neg A$ を仮定すると含意除去で $\bot$ を得る。古典的背理法で内側の仮定を解除して $A$ を得る。外側の仮定を含意導入で解除すれば $\neg\neg A\to A$ である。
:::

### 仮定と固有変数を一緒に記録する

自然演繹の未解除仮定は、証明木の分岐ごとに異なる。例えば $A\lor B$ から $B\lor A$ を得るとき、左枝で仮定する $A$ は右枝の $B$ とは別の仮定である。その二枝から同じ $B\lor A$ を得るときだけ、選言除去によって両方を解除できる。このように証明木の結論に残る仮定は、すべての葉の仮定の単なる和集合ではない。

:::example[同じ証人を使う場合と別々に使う場合]
$\exists xP(x)\land\forall x(P(x)\to Q(x))$ から $\exists x(P(x)\land Q(x))$ を導く。まず連言除去で存在式と全称式を取り出す。証人の仮定 $P(a)$ の枝で全称式を $a$ に具体化し、$Q(a)$ を得る。$P(a)\land Q(a)$ に存在導入を適用した結論は $a$ を自由に含まない。従ってその枝を閉じて存在除去できる。ここで $\exists xQ(x)$ だけを別途導き、その証人を $P$ の証人と同じだと解釈することはできない。結論が共通の証人を求めるため、同じ枝で二つの述語を示す必要がある。
:::

:::example[固有変数を出すと何が失敗するか]
$\exists xP(x)$ から、$P(y)$ を仮定する枝を作り、その仮定を存在除去で解除して直接 $P(y)$ を得ようとする。結論に $y$ が自由に出るので規則の条件が破れる。二元構造で $P=\{0\}$ とし、外の $y$ に $1$ を与えると、存在式は真だが結論は偽となる。証人のために一時的に $y=0$ を使った情報は、枝の外の割り当てには移せない。
:::

### 証人の名前が使える範囲を追跡する

自然演繹では、存在除去の証人を一行だけ自由に取り出すことはできない。$\exists x A(x)$ の証人を $u$ と仮定した部分証明を作り、そこで結論 $B$ まで進み、$u$ が $B$ や他の開いた仮定に自由に出ない場合に部分証明を閉じる。例えば「ある要素が $A$ かつ $B$ を満たす」から「$A$ を満たす要素がある」を導くとき、証人名を結論から消す。

:::example[二つの存在結論を得る]
$\exists x(P(x)\land Q(x))$ を使う。新しい $u$ に対して一時的に $P(u)\land Q(u)$ と置く。連言除去で $P(u)$ と $Q(u)$、二度の存在導入で $\exists xP(x)$ と $\exists xQ(x)$ を得る。連言導入で両方を合わせてから存在除去を適用する。この連言に $u$ は自由に現れないため、結論が特定の証人名に依存しない。
:::

:::example[違う証人を結合する誤り]
$\exists xP(x)$ と $\exists xQ(x)$ の二つから $\exists x(P(x)\land Q(x))$ を導こうとする。第一の存在除去の途中で $P(u)$ を仮定したなら、次に $Q(u)$ を第二の存在除去の一時仮定にすることはできない。$u$ が開いた仮定 $P(u)$ に自由に出るためである。新しい $v$ を使えば $Q(v)$ を得るが、$P(u)\land Q(v)$ は共通の証人を与えない。
:::

### 自然演繹と Hilbert 流の翻訳

$\bot$ を Hilbert 流の $\neg\forall x(x=x)$ に翻訳し、自然演繹の結合子を既出の略記に訳す。自然演繹の各部分証明について、未解除仮定からその結論を Hilbert 流で導けることを、最後の規則で検査する。仮定、含意除去、全称導入、全称除去、等号は対応する規則と公理を使う。含意導入は :ref[thm-logic-first-deduction] を使う。連言導入と除去、選言導入は対応する命題恒真式である。選言除去では二枝から $A\to C$ と $B\to C$ を得て、$A\lor B$ と合わせる命題恒真式を使う。爆発と背理法は $\bot$ の否定が定理であることと、有限命題完全性で得る古典論理の帰結を使う。存在導入は、$\forall x\neg A\to\neg A[t/x]$ の対偶と二重否定の同値により得られる。

残る存在除去を考える。未解除の仮定集合を $\Gamma$、固有変数を $y$ とする。枝の導出から $\Gamma\vdash A[y/x]\to C$ が演繹定理で出る。$y$ は $\Gamma$ と $C$ に自由に出ないので、対偶 $\neg C\to\neg A[y/x]$ を $y$ で一般化し、$\neg C\to\forall y\neg A[y/x]$ を得る。この対偶から $\exists y A[y/x]\to C$ を得て、束縛名を $x$ に戻す。既に得ている $\exists xA$ とモーダスポネンスで $C$ が出る。従って、存在除去の固有変数制約はこの翻訳の中でも必要である。

逆方向には Hilbert 流の各公理例を自然演繹で導く。K は $A$ の仮定の下で $B$ を仮に加えても $A$ を使えること、S は二つの含意の前件に同じ $A$ を入れ、$B\to C$ と $B$ から $C$ を出すことによる。E は $\neg A,A$ で $\bot$ を得て爆発、I は $A,\neg B,A\to B$ から矛盾を得て三仮定を閉じる。D は $A,\neg A$ から矛盾し、$\neg A$ を閉じて $\neg\neg A$ を得る。C は $A\to C,\neg A\to C$ の下で $\neg C$ を仮定する。$A$ を追加すると $C$ と矛盾するので $\neg A$ を得る。これを第二含意に適用すると再び $C$ と矛盾し、古典的背理法で $C$ が出る。量化公理のうち具体化は全称除去、分配は二全称を新変数 $u$ に具体化して含意除去した後に全称導入し、仮定を閉じる。空虚全称化の公理は $A$ の仮定で $x$ が自由に出ないため全称導入できる。等号公理は対応する導入・置換規則で得た後に仮定を閉じる。二つの推論規則は含意除去と全称導入に対応し、依存集合の制約は同じである。従って両体系はこの翻訳の下で同じ帰結を導く。

:::example[存在除去を全称と対偶へ翻訳する]
$\exists xP(x),\forall x(P(x)\to Q(x))\vdash\exists xQ(x)$ を考える。第二仮定から $P(y)\to Q(y)$ を得る。また $\neg\exists xQ(x)$ の下では $\forall x\neg Q(x)$ と同値なので $\neg Q(y)$ が出る。これに対偶を使って $\neg P(y)$ を得る。$y$ は二つの仮定に自由に出ないため、これを一般化できる。従って $\neg\exists xQ(x)\to\neg\exists xP(x)$ が第二仮定から出て、その対偶と第一仮定から結論を得る。証人を一時仮定にする自然演繹と、反例が全元に及ぶように一般化する Hilbert 流が対応している。
:::

### 略記した結合子を自然演繹で扱う

二つの体系で証明を比較する際、片方で基本記号になっている語をもう片方でどう書くかを明示する。自然演繹の存在式を Hilbert 流で $\neg\forall x\neg A$ と読む。逆に戻した式が、自然演繹でも元の存在式と同値になることは次の二つの導出で確かめられる。

まず $\exists x A$ を仮定し、さらに $\forall x\neg A$ を仮定する。存在除去の枝で新変数 $u$ に対する $A[u/x]$ を仮定する。全称式から $\neg A[u/x]$ を得るので、その枝で $\bot$ が出る。$u$ は $\bot$ にも他の仮定にも自由に出ないので、枝を閉じて $\bot$ を得る。全称式を仮定した部分を含意導入で閉じれば $\neg\forall x\neg A$ となる。逆向きには $\neg\forall x\neg A$ の下で $\neg\exists x A$ を仮定する。新変数 $u$ の実例 $A[u/x]$ を仮定すると、存在導入で $\exists x A$ が出て矛盾する。この枝を閉じて $\neg A[u/x]$ を得る。$u$ は残る仮定に自由に出ないので全称導入で $\forall x\neg A$ が得られ、最初の仮定と矛盾する。古典的背理法で $\exists x A$ に至る。

連言の略記について、$A\land B$ の下で $A\to\neg B$ を仮定すると、連言除去の $A,B$ から矛盾を得る。これで $\neg(A\to\neg B)$ が出る。逆向きには $\neg(A\to\neg B)$ を仮定する。さらに $\neg A$ を仮定すると、$A$ の下で矛盾から $\neg B$ が出るので $A\to\neg B$ を得る。最初の仮定に反するため、背理法で $A$ が出る。次に $\neg B$ を仮定すると今度はその式を $A$ の下でも使えるので、やはり $A\to\neg B$ を得る。背理法で $B$ が出て、連言導入で $A\land B$ になる。

選言 $A\lor B$ から $\neg A\to B$ を得るには、$\neg A$ を仮定し、各選言の枝で $B$ を導く。$A$ の枝は矛盾から $B$、$B$ の枝は仮定そのものから $B$ である。逆に $\neg A\to B$ と $\neg(A\lor B)$ を仮定する。$A$ から選言導入で矛盾になるため $\neg A$ を得て、第一仮定から $B$ を得る。再び選言導入で矛盾になるので、背理法で $A\lor B$ を得る。

最後に Hilbert 流で用いた $\bot$ の略記 $\neg\forall x(x=x)$ も戻せる。自然演繹で反射律を一般化すると $\forall x(x=x)$ である。その否定を仮定すれば $\bot$ に達する。逆向きは爆発である。これで、基本記号へ一度展開してから戻しても各結合子は同じ推論を表す。内部の部分式が同値な場合、二項結合子では仮定を置いて各方向を導けば外側の同値が得られる。量化式では自由に出ない新変数で前後の本体を比較し、全称導入・除去または存在導入・除去で外側へ移せる。

:::example[全称と存在の否定]
$\neg\exists x A$ から $\forall x\neg A$ を得る場合は、新変数 $u$ に対する $A[u/x]$ を仮定する。存在導入と元の否定で矛盾が出るので、本体の否定を導いて全称化する。逆向きには $\forall x\neg A$ の下で $\exists x A$ を仮定し、存在除去の枝を開く。証人を使って全称を具体化すれば矛盾になる。$\bot$ には固有変数が自由に出ないため、存在除去で枝を閉じられる。最後に存在式の仮定を解除して目的の否定を得る。
:::

### 等号を入れ子の項へ伝える

等号規則は式のどの位置を置換するかまで指定する。例えば $u=v$ と $R(g(u),h(u))$ から、第一引数だけを変えた $R(g(v),h(u))$ を導きたいとする。$z$ を新変数とし $A(z)=R(g(z),h(u))$ と設定すれば、規則の二つの実例は $R(g(u),h(u))$、$R(g(v),h(u))$ である。さらに $A'(z)=R(g(v),h(z))$ に適用すれば第二引数も変わる。$A''(z)=R(g(z),h(z))$ と選んだときは、一回の置換で両引数が変わる。

項に自由変数がある場合は量化子との衝突も確認する。例えば $z$ を $v$ に換えると内側で捕獲される式 $\forall v R(z,v)$ では、そのまま $z=v$ による置換公理を作れない。内側の束縛変数を $w$ に改名した $\forall w R(z,w)$ なら $v$ の代入が許される。$z=v$ の下で得られる結果は $\forall w R(v,w)$ である。ここで右辺の自由な $v$ が等式に現れた項であり、束縛された $w$ は全領域を走る。

## シークエント計算

:term[シークエント]{en="sequent" yomi="しーくえんと"} $\Gamma\Rightarrow\Delta$ は、有限多重集合 $\Gamma$ の全てが真で $\Delta$ の全てが偽になる場合がないことを表す。左辺の空集合は仮定なし、右辺の空集合は矛盾を表す。ここでは $\neg,\to,\forall$ を基本とし、他の結合子は略記とする。

初期シークエントは $A\Rightarrow A$ である。弱化は左右に式を一つ加え、縮約は同じ側の重複二個を一個にし、順序の入れ替えは多重集合として吸収する。カットは $\Gamma\Rightarrow\Delta,A$ と $A,\Pi\Rightarrow\Lambda$ から $\Gamma,\Pi\Rightarrow\Delta,\Lambda$ を得る規則である。論理規則は次を用いる。

$$
\begin{aligned}
&\frac{\Gamma\Rightarrow\Delta,A}{\neg A,\Gamma\Rightarrow\Delta}
&&\frac{A,\Gamma\Rightarrow\Delta}{\Gamma\Rightarrow\Delta,\neg A}\\
&\frac{\Gamma\Rightarrow\Delta,A\qquad B,\Pi\Rightarrow\Lambda}{A\to B,\Gamma,\Pi\Rightarrow\Delta,\Lambda}
&&\frac{A,\Gamma\Rightarrow\Delta,B}{\Gamma\Rightarrow\Delta,A\to B}\\
&\frac{A[t/x],\Gamma\Rightarrow\Delta}{\forall x A,\Gamma\Rightarrow\Delta}
&&\frac{\Gamma\Rightarrow\Delta,A[y/x]}{\Gamma\Rightarrow\Delta,\forall x A}.
\end{aligned}
$$

左全称規則は自由に代入可能な $t$ を用いる。右全称規則では、$y$ を $\Gamma,\Delta,\forall x A$ に自由に現れず、$x$ に自由に代入できる新変数とする。等号を含む場合は $t=t$ および等号置換図式を右辺だけに持つ初期シークエントを加える。この追加方式と、等号を規則に組み込む方式は、[証明論のカット除去](/math/logic-set-theory/proof-theory/) を論じるときに区別する。

### 存在の左右を基本規則で導く

$\exists x A$ を $\neg\forall x\neg A$ と展開する。右存在では、$\Gamma\Rightarrow\Delta,A[t/x]$ に否定左を使って $\neg A[t/x],\Gamma\Rightarrow\Delta$ とする。全称左で $\forall x\neg A,\Gamma\Rightarrow\Delta$ を得て、否定右で $\Gamma\Rightarrow\Delta,\exists x A$ とする。左存在では、$A[y/x],\Gamma\Rightarrow\Delta$ に否定右を使い、$\Gamma\Rightarrow\Delta,\neg A[y/x]$ とする。全称右で $\Gamma\Rightarrow\Delta,\forall x\neg A$ を得て、否定左で $\exists x A,\Gamma\Rightarrow\Delta$ とする。後者の $y$ は $\Gamma,\Delta,\exists x A$ に自由に現れず、$A$ の $x$ に自由に代入可能でなければならない。どちらの変換にもカットを使わない。

:::example[具体化を木にする]
$P(c)\Rightarrow P(c)$ に左全称を適用して $\forall xP(x)\Rightarrow P(c)$、次に右含意を適用して $\Rightarrow\forall xP(x)\to P(c)$ を得る。この木では前提から結論まで二つの規則を通る。
:::

:::example[含意を使う]
$A\Rightarrow A$ と $B\Rightarrow B$ に左含意を適用すると $A\to B,A\Rightarrow B$ となる。さらに右含意で $A\to B\Rightarrow A\to B$ が得られる。同じ終点には初期シークエントからも到達できる。
:::

### シークエントの左右と構造規則

$\Gamma$ の全式が真なら $\Delta$ の少なくとも一式が真である、とシークエントを読む。従って左辺に仮定を増やすことと、右辺に選択肢を増やすことは、どちらも条件を満たしやすくする。交換と縮約は、この読みでは同じ真理条件を持つ二列の書き換えである。リストとしてシークエントを扱う場合、論理規則で式を置く位置をそろえるため交換が必要になる。

:::example[切断による補助結論の消去]
$P(a),P(a)\to Q(a)\Rightarrow Q(a)$ と $Q(a),Q(a)\to R(a)\Rightarrow R(a)$ を得たとする。各式は含意左規則と恒等のシークエントから得られる。$Q(a)$ でカットすると $P(a),P(a)\to Q(a),Q(a)\to R(a)\Rightarrow R(a)$ になる。$Q(a)$ は両前提のうち、前半では結論で、後半では仮定として働く。このカットの正しさは $Q(a)$ が前半から真となり後半の推論に渡せることにある。
:::

:::example[空の片側]
$A\Rightarrow A$ に否定左を適用すると $\neg A,A\Rightarrow$ が得られる。空の右辺は「真の選択肢がない」という意味であり、左の連言の充足不能性を述べる。また $A\Rightarrow A$ に否定右を適用すれば $\Rightarrow A,\neg A$ になる。空の左辺は前提が常に満たされるので、こちらは右辺の選言が恒真であることを表す。
:::

### 開いたシークエントを一つの式へ写す

有限文脈 $\Gamma,\Delta$ のシークエントを $(\bigwedge\Gamma)\to(\bigvee\Delta)$ と読める。空の連言は $\top$、空の選言は $\bot$ とする。左の有限仮定と右の複数候補を一つにまとめると、例えば $A,B\Rightarrow C,D$ は $(A\land B)\to(C\lor D)$ に対応する。右辺の各式が別々に証明できるとは限らないので、$C\land D$ へは変えられない。

:::example[右辺が二式でも片方を選べない]
$\Rightarrow P,\neg P$ は $P\Rightarrow P$ から否定右で得られる。一方 $\Rightarrow P$ は $P$ が偽となる割り当て、$\Rightarrow\neg P$ は $P$ が真となる割り当てで偽である。多結論のシークエントから個別の結論へ狭められないのは、元の後件が割り当てごとに異なる式で真になり得るからである。
:::

### シークエントを Hilbert 流へ翻訳する

右辺が複数ある導出も一つの結論を持つ導出へ移せる。$\bot=\neg\forall x(x=x)$、$\top=\forall x(x=x)$ とし、$D_\Delta=\bigvee\Delta$ とおく。空の $\Delta$ では $D_\Delta=\bot$ とする。この略記の真偽条件は、空の後件や前件も含めて一貫している。

:::proposition[シークエント計算から Hilbert 流への翻訳]{#prop-logic-sequent-to-hilbert}
$\Gamma\Rightarrow\Delta$ が導出可能なら、$\Gamma\vdash D_\Delta$ である。左辺の重複は仮定集合で同一視する。
:::

:::proof
導出木の帰納法を使う。$A\Rightarrow A$ は仮定 $A$ の導出になり、等号の初期シークエントは Hilbert 流の公理となる。左弱化は使える仮定を増やし、左縮約は同じ仮定を一つにする。右の弱化、縮約、並び替えは選言の追加、冪等性、交換に対応する。それぞれ :ref[thm-logic-prop-finite-completeness] を使える。後件が空のときは $\vdash\neg\bot$ と命題論理を用いる。特に $\bot\to A$ は $\neg\bot$ と爆発図式から従う。

カットでは、共通の仮定集合 $\Gamma\cup\Pi$ の下で $D_\Delta\lor A$ と $A\to D_\Lambda$ を得る。後者には演繹定理を使った。前者で $D_\Delta$ が真なら $D_\Delta\lor D_\Lambda$ は真であり、$A$ が真なら後者で $D_\Lambda$ が真になる。この真理条件を命題完全性で導出に移す。空の選言を付加したときは、先に $D_{\Delta,A}$ と $D_\Delta\lor A$ の同値を命題論理で処理する。

否定左では $\Gamma\vdash D_\Delta\lor A$ と追加仮定 $\neg A$ から $D_\Delta$ を得る。否定右では $A,\Gamma\vdash D_\Delta$ を $A\to D_\Delta$ に変え、$D_\Delta\lor\neg A$ を得る。含意左では $D_\Delta\lor A$、$B\to D_\Lambda$ と追加仮定 $A\to B$ を使う。$D_\Delta$ が偽なら最初の式で $A$ が真、追加仮定で $B$ が真、二つ目の式で $D_\Lambda$ が真になる。よって $D_\Delta\lor D_\Lambda$ への命題推論を適用できる。含意右では $A$ を外して $A\to(D_\Delta\lor B)$ を得る。$D_\Delta$ が偽の場合にも $A\to B$ が真なので、$D_\Delta\lor(A\to B)$ へ進める。

全称左では、前提の導出で用いた仮定 $A[t/x]$ を演繹定理で外す。追加仮定 $\forall x A$ の具体化でその前件を得て、モーダスポネンスで $D_\Delta$ に戻る。全称右では $\Gamma\vdash D_\Delta\lor A[y/x]$ を $\Gamma\vdash\neg D_\Delta\to A[y/x]$ に変える。$y$ は $D_\Delta$ にも $\Gamma$ にも自由に現れない。$y$ で一般化し、分配と空虚全称化の公理から $\Gamma\vdash\neg D_\Delta\to\forall y A[y/x]$ を得る。ここから $\Gamma\vdash D_\Delta\lor\forall x A$ を得るには、束縛名の改名と命題完全性を使えばよい。$y$ が $A$ の内部で束縛名として使われていれば、そこでの束縛子を改名してからこの変換を行う。
:::

### Hilbert 流をシークエントへ翻訳する

逆向きにも命題論理の完全性をシークエントの健全性から推論する必要はない。まず量化子を含まない命題の真理表に相当する導出を作り、次に個別の量化公理を翻訳する。

:::lemma[命題公理のシークエントへの翻訳]{#lem-logic-sequent-prop}
真理関数として恒真な命題式の各一階代入例 $B$ について、$\Rightarrow B$ のシークエント導出がある。
:::

:::proof
変数 $p_1,\ldots,p_m$ に代入する式を $A_1,\ldots,A_m$ とする。一つの真理表の行に対し、真の $A_i$ を左の文脈 $\Gamma$、偽の $A_i$ を右の文脈 $\Delta$ に置く。任意の部分式 $E$ の代入例を $E'$ とすると、$E$ がその行で真なら $\Gamma\Rightarrow\Delta,E'$、偽なら $E',\Gamma\Rightarrow\Delta$ を作れることを示す。変数は恒等式と弱化による。否定は子が置かれた側を反対に移す否定規則で得られる。

$E=F\to G$ が真で $F$ が偽なら、子から $F',\Gamma\Rightarrow\Delta$ が得られる。$G'$ を右弱化で足し、含意右を使う。$G$ が真の場合は $\Gamma\Rightarrow\Delta,G'$ に $F'$ を左弱化で足して含意右を使う。含意が偽なら $F$ が真で $G$ が偽である。二つの子のシークエントに含意左を使い、左右に重複した文脈を縮約する。

根の $B$ はすべての行で真なので、どの行の導出でも右辺に置かれる。一つの $A_i$ の位置だけが違う二行から、それぞれ $\Gamma\Rightarrow\Delta,B,A_i$ と $A_i,\Gamma\Rightarrow\Delta,B$ を得る。$A_i$ でカットし、重複を縮約すれば、この $A_i$ の位置を指定しない導出となる。代入した他の式が $A_i$ と字面上同じ場合にも、位置を区別しておけば指定した一対だけをカットできる。これを全変数に繰り返すと $\Rightarrow B$ が得られる。
:::

:::proposition[Hilbert 流からシークエント計算への翻訳]{#prop-logic-hilbert-to-sequent}
$\Gamma\vdash A$ なら、ある有限 $\Gamma_0\subseteq\Gamma$ に対し $\Gamma_0\Rightarrow A$ が導出できる。
:::

:::proof
各行の依存集合に対応する前件で証明する。仮定行は恒等式である。命題公理は :ref[lem-logic-sequent-prop]、等号公理は指定した初期シークエントを使う。具体化公理には $A[t/x]\Rightarrow A[t/x]$ から全称左と含意右を用いる。空虚全称化は $A\Rightarrow A$ から全称右で $A\Rightarrow\forall x A$ を出して含意右を使う。全称右の変数は、新しい $y$ を選んでよい。$x$ が自由に出ない場合は $A[y/x]=A$ である。

分配公理には、全称式の外に出ない新変数 $y$ を取り、$A_y=A[y/x]$、$B_y=B[y/x]$ とおく。二つの恒等式から含意左で $A_y\to B_y,A_y\Rightarrow B_y$ を作る。前件二式に全称左を適用して、$\forall x(A\to B),\forall x A\Rightarrow B_y$ を得る。$y$ は前件に自由に出ないので全称右で $\forall xB$ を右辺に置ける。二回の含意右で公理の形を得る。

モーダスポネンスの行では、帰納法で $\Gamma_1\Rightarrow B$ と $\Gamma_2\Rightarrow B\to A$ がある。二つの恒等式から $B\to A,B\Rightarrow A$ が導出できる。これに先の二つのシークエントをカットで順に合わせ、左の重複を縮約する。一般化の行では $\Gamma_0\Rightarrow B$ から $\Gamma_0\Rightarrow\forall xB$ を作る。$x$ は $\Gamma_0$ にも $\forall xB$ にも自由に出ず、$B[x/x]=B$ なので右全称の条件を満たす。
:::

例えば $P(u),P(u)\to Q(u)\Rightarrow Q(u)$ は含意左だけで得られる。Hilbert 流の推論をそのまま上の手順で移すとカットを含み得るが、この短い導出では前提二式がそのまま左辺に来るためカットは不要である。翻訳が与える導出と、最初から目標に合わせて作る導出は、同じ終点であっても規則の使用回数が異なる。

## 健全性定理

:::theorem[三体系の健全性]{#thm-logic-first-soundness}
Hilbert 流と自然演繹で導出できる式は、その未解除仮定の論理的帰結である。シークエント計算で導出できるシークエントには反例がない。
:::

:::proof
Hilbert 流では命題公理とモーダスポネンスに命題論理の健全性を使う。全称具体化は :ref[lem-logic-substitution] に従う。分配の図式では全ての $a$ について $A$ と $A\to B$ が真なら全ての $a$ で $B$ が真である。変数が自由に出ない式は、:ref[lem-logic-assignment-locality] によりその値を更新しても真である。等号公理は項の値の反射性と、代入補題で同じ値を割り当てることから従う。一般化では任意に変数を更新しても依存する仮定が真なので、前提式が全ての更新で真となる。以上を導出行に沿って適用する。

自然演繹では部分証明が開いている間、その仮定も含めて帰結を評価する。含意導入では追加仮定が偽なら含意が真、真なら部分証明の帰結が真となる。選言除去では少なくとも一方の仮定が真で、その枝から結論が出る。連言の両規則と選言導入は真理表で保たれる。全称の両規則は Hilbert 流と同じであり、存在導入は項の値を証人にする。存在除去では証人 $a$ を新変数 $y$ に与えて部分証明を評価する。この更新は他の仮定と結論を変えない。等号は同じ値の代入で保たれる。$\bot$ が真となる割り当てはなく、背理法では $A$ が偽とすると部分証明が $\bot$ を真とする矛盾が生じる。

シークエントでは結論に反例を仮定し、少なくとも一つの前提に反例があることを示す。初期シークエントに反例はなく、弱化と縮約では反例がそのまま前提にも通用する。カットでは $A$ が偽なら左、真なら右の前提が破れる。否定の左右は $A$ の真偽の反転で処理できる。左含意では $A$ が偽なら第一前提、真なら $B$ も真なので第二前提が破れる。右含意が偽なら $A$ が真で $B$ が偽である。左全称では $t$ の値を使えば $A[t/x]$ が真であり、右全称が偽なら反例となる元を $y$ に割り当てても文脈の真偽が変わらない。従って導出木の帰納法が適用できる。
:::

### 証明形式を変えたときの健全性

カットの妥当性を反例から追う。結論の両左辺が真で両右辺がすべて偽だとすると、カット式は第一前提を守るため真でなければならない。しかしそれを第二前提の左に置くと、第二前提の全左辺が真で全右辺が偽になる。この矛盾によりカットは妥当である。存在左と全称右は、反例の割り当てで固有変数を証人に指定することで同様に示せる。文脈に固有変数が出ないため、元の反例の文脈の評価が保たれる。

:::example[全称右で固有変数を誤用する]
$P(u)\Rightarrow P(u)$ は恒等の公理である。右側を $u$ で一般化するだけで $P(u)\Rightarrow\forall xP(x)$ が得られるとすれば、領域 $\{0,1\}$、$P^\mathcal M=\{0\}$、$s(u)=0$ が反例になる。左辺に $u$ が自由に出るため、この一般化は固有変数条件を満たさない。
:::

:::example[全称式を存在の証人に適用する]
$\forall x(P(x)\to Q(x))$ と $\exists xP(x)$ を左、$\exists xQ(x)$ を右に置く。反例があれば左の存在から証人 $a$ を取り、全称を $a$ に適用して $Q(a)$ を得る。これは右の存在が偽だとする仮定に反する。対応するシークエント証明では、二つの恒等式から含意左で $P(u)\to Q(u),P(u)\Rightarrow Q(u)$ を作る。存在右で右辺を $\exists xQ(x)$ にまとめ、全称左で $P(u)\to Q(u)$ を元の全称式に戻す。ここで $u$ は他の式に自由に現れないので、最後に存在左で $P(u)$ を元の存在式に戻せる。
:::

### 自然演繹の仮定に番号を付ける

自然演繹の木では、仮定が同じ式でも異なる枝で開けば別の出現として扱える。解除された仮定の出現を番号で示すと、結論の依存を検査しやすい。次は $A\land B$ から $B\land A$ を得てから、一つの仮定を閉じる木である。
$$
\frac{\displaystyle
      \frac{\displaystyle\frac{[A\land B]^1}{B}\qquad
            \displaystyle\frac{[A\land B]^1}{A}}
           {B\land A}}
     {(A\land B)\to(B\land A)} .
$$
ここでは左右の葉をともに仮定 $1$ とし、最下段の含意導入で両方を解除する。番号 $1$ の葉の片方を別の番号にするなら、片方だけを解除した結論は残る番号の仮定に依存する。閉じた定理を得たい場合、どの出現を解除したかを確認する必要がある。

:::example[解除する仮定を選ぶ]
$A\to B$ を仮定 $1$、$B\to C$ を仮定 $2$ とし、$A$ を仮定 $3$ とする。含意除去を二回用いて $C$ を得たら、$3$ を閉じて $A\to C$ にする。ここで $1,2$ はまだ開いている。続けて $2$、$1$ の順に閉じると $(A\to B)\to((B\to C)\to(A\to C))$ が得られる。$2$ と $1$ の順を交換すれば、外側の二含意の前件も交換される。
:::

:::example[証人の仮定を参照できる範囲]
$\exists xP(x)$ を仮定し、新変数 $u$ で $P(u)$ の枝を開く。その枝では $P(u)$ を使って $\exists xP(x)$ を再び得られる。存在除去を適用して枝を閉じれば、得られる式は $\exists xP(x)$ であり、$P(u)$ は利用できなくなる。別に $\forall x(P(x)\to R)$ があり、$x$ が $R$ に自由に出ない場合は、その全称式を枝に持ち込み、$P(u)$ と合わせて $R$ を得てから閉じられる。$u$ はこの $R$ にも自由に出ないように選ぶ。このように、外の仮定は内側の枝で使えるが、枝だけで開いた仮定は外に持ち出せない。
:::

### 固有変数が結論と文脈を区別する

シークエント $\Rightarrow\forall x R(x,y)$ の右全称で、$x$ の代わりに $y$ を使うと、一般には本体 $R(y,y)$ しか調べていない。これは全称式全体に自由な $y$ が残っているため条件を満たさない。仮にこの制約を外すと、$R$ を等号にしたとき、等号の初期シークエント $\Rightarrow y=y$ から $\Rightarrow\forall x(x=y)$ を得てしまう。二元構造ではどの $y$ に対しても別の $x$ が存在するので、結論は偽である。固有変数はその他の自由変数から独立に動かせなければならない。

:::example[右全称を最後に使う]
$\forall xA(x)\Rightarrow\forall yA(y)$ を得るとする。ここで $A$ の表示されていない自由変数として $y$ は出ないものとする。最初に新変数 $u$ を取り、$A(u)\Rightarrow A(u)$ を置く。左全称を一回使って $\forall xA(x)\Rightarrow A(u)$ を作る。その後 $u$ を固有変数とする右全称で $\forall yA(y)$ を得る。左辺に $u$ が現れなくなってから右全称を適用することが、依存条件を満たす順序になっている。
:::

### 等号公理をカットで使う

例えば $a=b,P(f(a))\Rightarrow P(f(b))$ を、等号置換図式を初期シークエントに入れた体系で作る。$D=P(f(a))$、$E=P(f(b))$ とおく。恒等式 $D\Rightarrow D$ と $E\Rightarrow E$ に含意左を適用し、$D\to E,D\Rightarrow E$ を得る。これと $a=b\Rightarrow a=b$ に含意左を適用すると
$$
a=b\to(D\to E),\ a=b,\ D\Rightarrow E
$$
となる。等号の初期シークエント $\Rightarrow a=b\to(D\to E)$ で左端の式をカットすれば目的のシークエントを得る。使用した置換の本体は $P(f(z))$ であり、$z$ は $a,b$ に現れない変数として選べる。等号の公理を初期式にする設計では、適用する公理そのものを途中のカット式として書ける。この選択は、等号置換を直接のシークエント規則とする設計と区別する必要がある。

### 証明と反例を同じ仮定で調べる

開いた式を扱うとき、健全性の結論は「仮定を真にした同じ割り当てが結論も真にする」と述べる。例えば $P(x)\to Q(x),P(x)\vdash Q(x)$ では、先に $P(x)$ を真にした元を $Q(x)$ の評価にも使う。仮定ごとに異なる割り当てを採れば、$P$ が二元とも真、$Q$ が一元だけで真となる構造で、含意を真にする元と結論を偽にする元を別々に選べてしまう。これは共通の割り当てに対する反例にはならない。

:::example[妥当性は一つの導出を検査して得られる]
$\forall xP(x)\Rightarrow\exists xP(x)$ を考える。新変数 $u$ に対する恒等式 $P(u)\Rightarrow P(u)$ から、左全称で $\forall xP(x)\Rightarrow P(u)$、右存在で $\forall xP(x)\Rightarrow\exists xP(x)$ を得る。この証明では $u$ の値が領域の一元であることを用いる。領域を非空とした :ref[def-logic-structure] が、この導出の意味論に使われている。従って $\forall xP(x)$ が真の構造では、任意の割り当ての $u$ を一つの存在証人にできる。
:::

## 演習問題

::::exercise{level=basic}
等号図式から $a=b,b=c\vdash a=c$ を得よ。
:::solution
置換式を $A(x)=(a=x)$ とする。$b=c\to(a=b\to a=c)$ から仮定を順に使えば $a=c$ が得られる。
:::
::::

::::exercise{level=basic}
$\forall xP(x)\vdash P(f(c))$ を Hilbert 流で導出せよ。
:::solution
具体化公理に項 $f(c)$ を入れる。仮定と公理 $\forall xP(x)\to P(f(c))$ から一回のモーダスポネンスで得られる。
:::
::::

::::exercise{level=basic}
自然演繹で $A\land B\vdash B\land A$ を導け。
:::solution
連言除去を二回使って $B$ と $A$ を得る。連言導入にこの順で渡せば $B\land A$ になる。
:::
::::

::::exercise{level=basic}
$A\to B,A\Rightarrow B$ をカットなしで導け。
:::solution
二つの初期シークエント $A\Rightarrow A$ と $B\Rightarrow B$ を置く。第一の右の $A$ と第二の左の $B$ を左含意に渡すと指定の結論になる。
:::
::::

::::exercise{level=advanced}
$\forall x(A\to B),\forall x A\vdash\forall x B$ を、分配公理を使わずに導け。
:::solution
両方を変数 $x$ 自身で具体化すると $A\to B,A$ が得られる。モーダスポネンスで $B$ を得る。両仮定に $x$ は自由に現れないため一般化できる。
:::
::::

::::exercise{level=advanced}
自然演繹で $\exists x(P(x)\land Q(x))\vdash\exists xP(x)\land\exists xQ(x)$ を導け。
:::solution
証人の仮定 $P(y)\land Q(y)$ を開く。連言除去で各成分を取り、個別に存在導入する。この二式から連言を作り、新変数 $y$ を含まないため存在除去で証人の仮定を解除する。
:::
::::

::::exercise{level=advanced}
右全称の新変数条件を落とした場合の反例を示せ。
:::solution
初期シークエント $P(y)\Rightarrow P(y)$ に右全称を適用できると $P(y)\Rightarrow\forall xP(x)$ になる。二元構造で $P=\{0\}$ とし $y=0$ を与えると左辺が真、右辺が偽である。
:::
::::

::::exercise{level=advanced}
$A\to B,B\to C\Rightarrow A\to C$ をカットなしで導け。
:::solution
初期シークエント $B\Rightarrow B,C\Rightarrow C$ から左含意で $B\to C,B\Rightarrow C$ を得る。$A\Rightarrow A$ とこれに左含意を適用し $A\to B,B\to C,A\Rightarrow C$ を得る。右含意で $A$ を移して結論を得る。
:::
::::

::::exercise{level=advanced}
$\forall x(P(x)\to Q)$ と $\exists xP(x)$ から $Q$ を自然演繹で導出せよ。ただし $x$ は $Q$ に自由に出ない。必要な固有変数条件も挙げよ。
:::solution
両前提と $Q$ に出ない変数 $u$ を取る。存在除去の枝で $P(u)$ を一時仮定とする。第一前提を $u$ で具体化すると $P(u)\to Q$ を得る。$x$ は $Q$ に自由にないため右辺は代入で変わらない。含意除去で $Q$ を得る。$u$ は結果にも他の開いた仮定にも、開いた存在前提にも自由に現れない。従って $P(u)$ を解除する存在除去で $Q$ に達する。
:::
::::

::::exercise{level=advanced}
$\forall x(P(x)\to Q(x))\Rightarrow(\exists xP(x))\to\exists xQ(x)$ をカットなしで導け。
:::solution
新変数 $u$ に対する二つの恒等 $P(u)\Rightarrow P(u)$ と $Q(u)\Rightarrow Q(u)$ から、含意左で $P(u),P(u)\to Q(u)\Rightarrow Q(u)$ を得る。存在右で後件を $\exists xQ(x)$ に変える。次に全称左で $P(u)\to Q(u)$ を $\forall x(P(x)\to Q(x))$ にまとめると、この全称式と右辺に $u$ はいない。従って存在左で $P(u)$ を $\exists xP(x)$ に変えられる。含意右でこの最後の存在文を右辺の含意の前件へ移せばよい。
:::

$A\to B,B\to C\Rightarrow A\to C$ のカットなしの解答で用いる論理規則は何回か。初期シークエントは数えない。
:::explanation
左含意で二つの含意を処理し、右含意で一つの含意を作る。従って合計は $2+1=3$ 回である。

::::quiz
Hilbert 流で、依存する仮定に $x$ が自由に現れるときの一般化について正しい説明を選べ。

- [ ] 仮定が一つなら一般化できる。
- [ ] 束縛出現も同じ理由で禁止される。
- [x] 一般化の条件を満たさない。

:::explanation
一般化では割り当ての $x$ を任意に変える。その更新後も仮定が真だと使えるように、自由出現を禁止する。量化による束縛出現は自由変数条件に抵触しない。
:::

::::quiz{answer="3" tol="0"}
$A\Rightarrow A$ から弱化のみで $B,C,A\Rightarrow A,D$ を得るには何回の規則が必要か。
:::explanation
弱化一回で一式を追加する。左に $B,C$、右に $D$ の計三式を追加するので三回が必要十分である。

::::quiz
$\Gamma\Rightarrow\varnothing$ の反例を選べ。

- [x] 左辺をすべて真にする割り当て
- [ ] 左辺をすべて偽にする必要がある割り当て
- [ ] 右辺の式を一つ真にする割り当て

:::explanation
右辺に真になり得る式がないので、左辺をすべて真にする割り当てがあればそれが反例である。左辺が空なら任意の割り当てが左辺を満たす。
