## この章の目標

- カットを含む導出とカットなし導出の関係を証明する。
- 部分論理式性の意味と量化式の実例を区別する。
- Herbrand の有限化と Craig の補間を証明する。
- LJ と LK の結論側の差を理解し、算術の証明への順序数の導入を説明する。

## シークエント計算 LK

:term[シークエント計算]{en="sequent calculus" yomi="しーくえんとけいさん"} では、論理記号を左または右から一段ずつ導入する。[形式的証明](/math/logic-set-theory/formal-proofs/) の規則に沿い、ここでは純粋な第一階論理を扱うときは等号を持たない言語を使う。等号を非論理公理として左に入れる方式では、カット除去はその公理を前件に持つ帰結として適用できる。

:::definition[LK の規則]{#def-logic-lk}
両側を有限多重集合とし、初期式 $A\Rightarrow A$、弱化、縮約、カットを持つ。$\neg,\to,\forall$ は既出の規則を使う。$\land$ の左では二成分を左に持つ前提を一つ取り、右では同じ文脈で各成分を右に持つ二前提を取る。$\lor$ の左では同じ文脈で各成分を左に持つ二前提を取り、右では両成分を右に持つ一前提を取る。$\exists x A$ の左は、結論のどの式にも自由出現しない新変数 $y$ を使って $A[y/x]$ を左に置く。右は自由代入可能な項 $t$ で $A[t/x]$ を右に置く。定数 $\bot$ の左は前提なしで許す。
:::

二前提の規則で文脈を共有する方式と分ける方式は、弱化で不足を補い、縮約で重複を除けば互いに模倣できる。例えば分割した二つの文脈を前提ごとに弱化して同じ文脈にそろえると、共有する方式の規則を使える。

:::example[カットが表す補題の使用]
$A\Rightarrow B$ と $B\Rightarrow C$ があれば、$B$ をカットして $A\Rightarrow C$ を得る。$B$ は終式に現れないこともある。そこでカットを除くことは、証明にだけ現れる中間式への依存をなくす操作になる。
:::

### 規則を上下に読む

論理規則の下向きは証明を組み立てる操作であり、上向きは証明の候補を探す操作である。例えば $\Gamma\Rightarrow\Delta,A\land B$ の右辺を上向きに調べると、$\Gamma\Rightarrow\Delta,A$ と $\Gamma\Rightarrow\Delta,B$ の両方が課題になる。反例を構成する場合は、どちらか一方を偽にすれば足りるため、上向きの木で二枝に分かれる。

:::example[連言の交換のカットなし導出]
恒等 $B\Rightarrow B$ と $A\Rightarrow A$ を左弱化し、$A,B\Rightarrow B$ と $A,B\Rightarrow A$ を得る。連言右で $A,B\Rightarrow B\land A$、次に連言左で $A\land B\Rightarrow B\land A$ を得る。含意右を施せば、仮定なしで $(A\land B)\to(B\land A)$ が出る。各枝に文脈の二式を揃えたのは、ここで使う連言右が共有文脈を要求するからである。
:::

:::example[量化の両側で使う項]
$\forall x P(x)\Rightarrow\exists x P(x)$ を示す。任意の新変数 $u$ で恒等 $P(u)\Rightarrow P(u)$ を取り、存在右で $P(u)\Rightarrow\exists xP(x)$、全称左で目標を得る。ここでは $u$ は一つの任意項として使われ、全称右の固有変数条件は登場しない。領域が非空であることが、任意の割り当てで $u$ に値を与えられる根拠である。
:::

### 恒等式の初期化を原子式に絞る

任意の $A$ に対する $A\Rightarrow A$ は、原子式の恒等とカットなしの規則だけでも用意できる。連言 $A=B\land C$ の場合、二つの恒等を弱化して $B,C\Rightarrow B$ と $B,C\Rightarrow C$ とし、連言右と連言左を順に使う。選言では $B\Rightarrow B,C$ と $C\Rightarrow B,C$ を弱化で得て、各々に選言右、最後に選言左を使う。含意では $B\Rightarrow B$ と $C\Rightarrow C$ から含意左で $B,B\to C\Rightarrow C$ とし、含意右を使う。否定では $B\Rightarrow B$ から否定左で $\neg B,B\Rightarrow$ とし、否定右で $B$ を右へ移す。定数 $\bot$ は左規則で前提なしに閉じる。量化子では新変数 $y$ の実例 $B[y/x]\Rightarrow B[y/x]$ を出発点に、全称左のあと全称右、または存在右のあと存在左を使う。いずれも結論に $y$ は自由に現れない。従って式の構造帰納法で原子恒等のみに絞れる。

:::example[一段深い恒等を展開する]
$A=\forall x(P(x)\land Q(x))$ とする。新しい $y$ に対し二つの原子恒等を弱化し、連言右と連言左から $P(y)\land Q(y)\Rightarrow P(y)\land Q(y)$ を得る。次に全称左で左を $\forall x(P(x)\land Q(x))$ にし、全称右で右も全称にする。最後の前提の左側で $y$ が自由に残らないことを確認してから全称右を適用する。
:::

## カット除去定理

:::theorem[LK のカット除去]{#thm-logic-cut-elimination}
等号なしの純粋な LK で導出可能なシークエントはカットなしでも導出可能である。
:::

:::proof
健全性より導出可能なら妥当である。妥当なシークエントにカットなし導出があることを、探索が無限に続けば反例を作る方法で示す。終式に現れる有限の記号に、新定数を可算個足す。自由変数は最初は互いに異なる定数として扱う。

根から上向きに、各逆向き規則で真偽の条件を分解する。左の式は真、右の式は偽にしたい。左連言では二成分を左に追加し、右連言では片方ずつを右に追加する二枝を作る。左選言では二枝を作り、右選言では両成分を右に追加する。否定では側を反転する。左含意では前件を右へ置く枝と後件を左へ置く枝を作る。右含意では前件を左、後件を右へ置く。左全称と右存在に対しては、閉項を順に使ってそれぞれ左と右に実例を追加する。右全称と左存在では新しい定数で反例または証人を一つ追加する。これは固有変数を新定数で記した規則である。同じ辺にある主式を枝で残しても、弱化、規則適用、縮約により子の導出を親の導出に戻せる。

各枝で現れる仕事を発生順に並べ、閉項の実例については可算列挙と交互に処理して、有限の段で現れた個々の仕事を後で必ず処理する。原子式が両側に現れる枝や $\bot$ が左に現れる枝を閉じる。閉じた葉は初期式と弱化で導出できる。木が有限ですべて閉じれば、導出を葉から根に合成できる。固有定数を新変数に取り替え、終式のパラメータ定数を元の変数に戻すと、元の言語の導出になる。終式に出ず証人でもない定数は、新しく取った自由変数へ一斉に替えられる。

逆に閉じた有限木が得られないなら、有限分岐木には無限の枝がある。各段で無限の子孫がある子を選べばこの枝を作れる。拡張言語で作れる全閉項を領域とし、各関数を項形成として解釈する。左に出た原子式だけを真とする。枝が閉じなかったので右の原子式は偽になる。式の構造帰納法で、左の全式は真で右の全式は偽になる。結合子では選んだ枝が必要な成分を含む。全称の真と存在の偽では公平性によってすべての閉項が検査されており、残りの量化では新定数が証人となる。これは終式の反例であり、妥当性に反する。
:::

この証明は有限証明を探し直すことでカットなし導出の存在を与える。局所的な変形も確認できる。例えばカット式が $A\land B$ で、左右の直前の規則がその連言を導入したなら、右導入の各前提と左導入の前提を $A,B$ で順にカットし、共通文脈を縮約する。量化の場合、$\forall x A$ を右で作った固有変数は、左で使った項に変えてから $A[t/x]$ でカットする。名前の衝突を避けておけば置換で規則は保たれる。

### 公平な探索を具体化する

各ノードで式に出現番号を付ける。結合子の分解と新しい証人を要求する量化は、その出現について一度処理すればよい。左全称と右存在は、出現番号と閉項列挙の番号の対を仕事として持つ。一つの枝で手順 $n$ に達したら、出現番号と閉項番号がいずれも $n$ 以下で処理されていない仕事を番号和の順に処理する。新しい出現には未使用の番号を与える。各手順には有限個の仕事しかなく、任意の固定の仕事は自分の二番号を越えた段で処理される。二分岐のときは既処理の集合も子へ引き継ぎ、その枝に現れた式だけに処理を追加する。

:::example[全称左を一度で済ませられない場合]
$\forall x(P(x)\to P(f(x))),P(c)\Rightarrow P(f(f(c)))$ を考える。左全称を $c$ で実例化すれば $P(c)\to P(f(c))$ がある。さらに $f(c)$ で実例化し、$P(f(c))\to P(f(f(c)))$ を得る。上向きには片方の実例だけを使うと、$P(c),P(f(c))$ を真、$P(f(f(c)))$ を偽にした枝が残る。二番目の実例を追加して含意左を分解すると、その枝が閉じる。
:::

:::example[固有変数の分離]
$\exists xP(x)\Rightarrow\forall yP(y)$ の探索で、存在左の証人を $c$、全称右の反例を $d$ とする。枝は $P(c)$ を真、$P(d)$ を偽にできるので閉じない。両方で同じ新定数を選べばこの枝は誤って閉じる。新しさの条件は左右の役割を分けるためだけでなく、前の割り当てが固定した値を制約しないためにある。
:::

### カット式を両側で導入した場合

単純な例でカットの高さを測る。左の最後が含意右、右の最後が含意左でカット式が $A\to B$ だとする。含意右の前提は $A,\Gamma\Rightarrow\Delta,B$ である。含意左の前提は $\Pi\Rightarrow\Lambda,A$ と $B,\Sigma\Rightarrow\Theta$ とする。まず $\Pi$ 側と含意右の前提を $A$ でカットすると $\Pi,\Gamma\Rightarrow\Lambda,\Delta,B$ になる。次に $B$ で第三の前提とカットすると、$\Pi,\Gamma,\Sigma\Rightarrow\Lambda,\Delta,\Theta$ を得る。元の二側をカットした場合の結論と同じ式を持ち、各カット式の論理記号数は $A\to B$ より小さい。文脈を共有する規約では、余分に重なった文脈を縮約する。

片側の最後がカット式と無関係な一前提規則なら、カットをその規則の前へ移し、カットの後で規則を再適用できる。二前提規則なら対応する枝ごとにカットを配り、再適用する。固有変数は他側の証明に出ないものへ改名する。縮約でカット式そのものが二つになった場合には、同じ階数のカットが複製される。上の探索による証明はその場合にもカットなし導出を与える。局所手続きだけで停止性まで示すには、複数の同一カット式をまとめて消す規則で、階数と高さを同時に管理する。

### 交換を省いた表で規則を確認する

左右を多重集合としたので、式の並び順を変えるだけの規則は省ける。例えば否定と連言に対しては次の形を使う。
$$
\begin{aligned}
&\dfrac{\Gamma\Rightarrow\Delta,A}{\neg A,\Gamma\Rightarrow\Delta}
&&\dfrac{A,\Gamma\Rightarrow\Delta}{\Gamma\Rightarrow\Delta,\neg A}\\[4pt]
&\dfrac{A,B,\Gamma\Rightarrow\Delta}{A\land B,\Gamma\Rightarrow\Delta}
&&\dfrac{\Gamma\Rightarrow\Delta,A\qquad\Gamma\Rightarrow\Delta,B}
{\Gamma\Rightarrow\Delta,A\land B}.
\end{aligned}
$$
負の結合子の規則では式が辺を移る。連言の規則では真であるべき左辺で両成分を要求し、右辺では両方を別々に証明する。このため右の連言は二前提になる。選言ではこの左右の形が逆転し、左が二前提、右が一前提である。含意は次である。
$$
\begin{aligned}
&\dfrac{\Gamma\Rightarrow\Delta,A\qquad B,\Pi\Rightarrow\Lambda}
{A\to B,\Gamma,\Pi\Rightarrow\Delta,\Lambda}
&&\dfrac{A,\Gamma\Rightarrow\Delta,B}
{\Gamma\Rightarrow\Delta,A\to B}.
\end{aligned}
$$
含意左では $A$ の偽または $B$ の真が含意を真にするので、妥当性の証明側ではその両分岐を閉じる。全称左と存在右は自由代入できる任意の項 $t$ を使う。
$$
\begin{aligned}
&\dfrac{A[t/x],\Gamma\Rightarrow\Delta}{\forall x A,\Gamma\Rightarrow\Delta}
&&\dfrac{\Gamma\Rightarrow\Delta,A[t/x]}{\Gamma\Rightarrow\Delta,\exists x A}\\[4pt]
&\dfrac{\Gamma\Rightarrow\Delta,A[y/x]}{\Gamma\Rightarrow\Delta,\forall x A}
&&\dfrac{A[y/x],\Gamma\Rightarrow\Delta}{\exists x A,\Gamma\Rightarrow\Delta}.
\end{aligned}
$$
第二行では $y$ が結論のどの式にも自由に出ないことを要する。例えば全称右の結論に反例があれば、その全称を偽にする元を $y$ に与えることで前提の反例になる。$y$ による更新で文脈の値が変わらないことがこの反例構成の根拠である。存在左も同じ方法で存在の証人を $y$ に与える。

:::example[二つの量化子を外側から処理する]
$\forall x\forall y\,R(x,y)\Rightarrow\forall y\forall x\,R(x,y)$ を導く。新変数 $u,v$ を取り、$R(u,v)\Rightarrow R(u,v)$ から全称左を二回適用して、左を $\forall x\forall y R(x,y)$ にする。適用順は内側に対応する $y$ が先、$x$ が後である。右では $u$ で全称右を使い $\forall xR(x,v)$ を得て、次に $v$ で全称右を使う。第一の適用では結論の右に $v$ は残ってよいが $u$ は残らない。左は文なのでどちらの固有変数も自由に出ない。従って両側を逆順で量化しても規則の条件を保てる。
:::

### 否定標準形での構文的なカット除去

探索による証明は、与えられた導出の構造から離れて、終式を根とする新しい木を作る。ここでは否定を原子式まで押し込んだ一側シークエントについて、元の証明木から局所的にカットを消す方法を示す。この形は後の算術の無限分岐体系にも使う。

式はリテラル、$\top,\bot$、$\land,\lor,\forall,\exists$ からなる。$\overline A$ を $A$ の双対とし、リテラルでは肯定と否定を交換し、定数では $\top,\bot$ を交換する。複合式では $\land,\lor$ と $\forall,\exists$ をそれぞれ交換し、成分にも双対を取る。シークエントは式の有限集合 $\Gamma$ で、その選言を主張する。初期式は相補的なリテラルの対を含むもの、または $\top$ を含むものとする。連言は両成分の二前提、選言は指定した一成分の一前提で導入する。全称には固有変数の実例、存在には任意の自由代入可能な項の実例を使う。文脈を集合にしたので、論理規則で導入する式はその文脈にも残してよい。カットは $\Gamma,C$ と $\Delta,\overline C$ から $\Gamma,\Delta$ を得る規則である。式の階数は結合子と量化子の個数とする。

各論理規則は、左の式を双対にして右へ移した LK の形である。例えば二成分を前提に置く LK の選言右は、一成分から選言を導入してもう一成分を文脈に残し、その成分でも同じ選言を導入すれば一側の形で模倣できる。一側の選言規則は逆に、弱化で欠けた成分を足してから LK の選言右を使えばよい。量化規則で使う固有変数条件は変わらない。

まず弱化はカットなしの導出の高さを増やさずにできる。加える式に現れる自由変数と固有変数を区別してから、各節点の文脈に同じ式を加えればよい。また項の代入も高さを増やさずにできる。代入項に現れる変数と、代入される変数と、導出で固有変数として使われる名前の衝突を避けるよう、有限木の固有変数を先に改名する。以後、文脈の追加や代入を行う場合はこの準備を含める。

:::lemma[連言と全称の反転]{#lem-logic-finite-inversion}
カットなしで $\Gamma,A_0\land A_1$ が導出できるなら、各 $i$ で $\Gamma,A_i$ が同じ高さ以下で導出できる。同様に、$\Gamma,\forall xA$ から任意の自由代入可能な $t$ について $\Gamma,A[t/x]$ を同じ高さ以下で導出できる。
:::

:::proof
文脈 $\Gamma$ に置き換える式そのものがあれば、もとの証明に目的の成分を弱化で足せばよい。そうでなければ高さで帰納する。初期式では、連言や全称を除いても初期式の根拠が残る。最後の規則が対象を導入する場合は、指定した成分の前提を取る。全称ならその固有変数に $t$ を代入する。対象が前提の文脈にも残る場合は、対応する前提に帰納法を適用して、その残りも同じ成分へ置き換える。全称の場合にはまず前提の固有変数を $t$ へ置換し、それから帰納法で前提に残る全称を取り除く。この順序なら残る全称の自由変数に対して意図しない代入は起きない。

最後の規則が別の式を導入する場合は、各前提中の対象を帰納法で変形し、同じ規則を再適用する。もし対象と同じ式が、その規則から消える補助式としても必要なら、適用前に弱化で補助式だけを戻す。適用後にはその式を残さない。固有変数は追加する式に自由に現れないものへ改名できる。この変形では前提の高さの上界を保つため、再適用後の高さも増えない。
:::

:::lemma[カットなし証明の合成]{#lem-logic-finite-cut-admissibility}
$\Gamma,C$ と $\Delta,\overline C$ のカットなし導出があるなら、$\Gamma,\Delta$ のカットなし導出がある。
:::

:::proof
$C$ の階数で外側の帰納法を行う。もし $C\in\Gamma\cup\Delta$ または $\overline C\in\Gamma\cup\Delta$ なら、対応する片側の入力導出を弱化して終わる。以下ではいずれも目標の文脈にはないとする。

$C$ がリテラルなら、左の導出の高さについて帰納する。最終規則が初期式で、その根拠の対が $\Gamma$ に入れば結論も初期式である。根拠が $C$ と $\overline C$ の対なら $\overline C\in\Gamma$ なので右の導出の弱化で足りる。$\top$ による初期式の根拠は $C$ がリテラルなら $\Gamma$ に残る。論理規則が最後の場合、$C$ は主式にはならない。各前提と右の導出を帰納法で合わせ、必要な補助式を加えてから同じ論理規則を再適用する。定数をカットする場合は、$\bot$ を含む側から $\bot$ を除く。初期式の根拠にならず、導入規則もないため、高さの帰納法で全ての文脈から消せる。消える補助式としてだけ必要ならその規則の直前に戻す。最後に他方の文脈を弱化で加える。

$C$ が複合式なら、必要なら左右を交換し、$C$ の外側を $\lor$ または $\exists$ にする。左の導出の高さで帰納する。初期式なら根拠が $\Gamma$ に残る。最後の規則が別の式を導入するなら、前提の高さが低いので、各前提と右の導出に帰納法を適用できる。規則の補助式が $C$ と等しい場合、それを適用前に弱化で補う。もし補助式が $C$ と等しくて元の文脈に $C$ が残っていた場合にも、一側では同じ一出現で両方の役割を果たす。再適用の文脈には $C$ を入れず、必要だった補助式だけを主式の導入で消す。

最後の規則が $C$ を導入する場合、前提には選んだ選言肢または存在の実例 $D$ がある。文脈として $C$ が前提に残るなら、低い高さの帰納法を使って $\Gamma,\Delta,D$ を得る。残らないなら同じシークエントを前提の弱化で得る。右の $\overline C$ は連言または全称なので、反転補題で $\Delta,\overline D$ を得る。ここで右側の全称に入れる項は、左側の存在で使った同じ項である。最後に $D$ をカット式として外側の帰納法を適用する。$D$ の階数は $C$ より小さいので、$\Gamma,\Delta$ のカットなし導出が得られる。
:::

この補題を用いると、一側計算でカットを含む導出全体を変形できる。元の有限木の上から順に、まず各前提をカットなしにする。最後の規則が論理規則ならそのまま適用する。カットなら、両前提を :ref[lem-logic-finite-cut-admissibility] で合成する。式の重複を許す LK の縮約に相当する箇所は、一側の証明で主式が文脈に残る場合として扱った。単にカットを一段上へ移すだけでは同じ階数の処理が繰り返されるため、内側の帰納法で前提の高さを別に比較することが効いている。

:::example[存在と全称のカットが一つの実例へ移る]
$C=\exists xP(x)$ とし、左で $P(f(c))$ から導入したとする。右には $\overline C=\forall x\neg P(x)$ がある。反転補題で右を $\neg P(f(c))$ に移すと、左の $P(f(c))$ と同じ項で対応する。新しいカットの階数は零であり、全称の導出が最初どの固有変数名を使ったかは影響しない。左の前提に $C$ が文脈として残っていれば、下がった高さでその $C$ の処理を終えた後にリテラルを消す。
:::

## 部分論理式性と Herbrand の定理

カットなし導出を根から上へ読むと、各論理規則は前提の式を結論式の部分式にする。量化の前提には項を代入した実例が現れるため、部分論理式性の表現ではこの代入を許す。弱化を逆に読むと式が減る。縮約は同じ式の複写であり、新しい形の式を持ち込まない。したがって等号なしの体系では、終式の部分式の実例だけでカットなし導出を構成できる。

:::theorem[Herbrand の定理の存在形]{#thm-logic-herbrand}
等号なしの言語で量化子なしの $B(\vec x)$ に対し、$\vec x$ が $B$ の全自由変数を含むとする。$\exists\vec x\,B(\vec x)$ が妥当であることと、有限個の閉項の組 $\vec t_i$ によって $\bigvee_i B(\vec t_i)$ を命題論理の恒真式にできることは同値である。閉項がなければ新定数を加えてよい。
:::

:::proof
有限の選言が恒真なら、任意の構造で少なくとも一つの実例が真となるため、存在文は妥当である。逆にどの有限選言も恒真でなければ、すべての $\neg B(\vec t)$ の有限部分が命題的に充足可能となる。:ref[thm-logic-prop-compactness] で全実例を偽にする原子閉式の割り当てを得る。閉項の構造にその割り当てを関係の解釈として入れると、全領域のどの組を選んでも $B$ は偽である。新定数を忘れても元の存在文は偽なので、妥当性に反する。
:::

:::example[相異なる項の実例]
$\exists x(P(x)\to P(f(x)))$ の一つの実例は、一般には恒真式にならない。そこで $c$ を新定数に取り、二つの実例を考える。$P(c)\to P(f(c))$ が偽なら $P(f(c))$ は偽なので、次の $P(f(c))\to P(f(f(c)))$ は真である。従ってこの二実例の選言が恒真になる。
:::

### 普遍文の反証を有限の実例にする

量化子なしの $D_i$ を持つ普遍文集合 $T=\{\forall\vec x\,D_i(\vec x):i\in I\}$ を考える。全閉項の実例 $D_i(\vec t)$ のうち、有限個で命題的に充足不能な集合があれば $T$ は充足不能である。逆に全有限部分が命題的に充足可能なら、命題コンパクト性で全実例を真にする評価を取る。閉項を領域にして、評価が真にした原子閉式で関係を解釈すると、任意の量化変数の値は閉項なので全普遍文を満たす。この証明は、等号を論理記号に取る場合にはそのまま使えない。例えば命題評価が $c=c$ を偽とすることを防げない。等号を二項関係に翻訳し、同値関係と各記号の合同公理を普遍文として加えれば、最後に閉項の商を取れる。

:::example[閉項の列から矛盾を得る]
$P(c)$、$\forall x(P(x)\to P(f(x)))$、$\neg P(f(f(c)))$ を課す。この反証には $x=c$ と $x=f(c)$ の二実例で十分である。前者と $P(c)$ で $P(f(c))$、後者で $P(f(f(c)))$ が真になり、最後の仮定に反する。$x=c$ だけを採用した集合は、$P(c),P(f(c))$ を真、$P(f(f(c)))$ を偽にすれば命題的には充足可能である。
:::

:::example[存在と全称を正しい向きで交換する]
$\neg\forall x\exists y\,R(x,y)$ を存在形にすると $\exists x\forall y\,\neg R(x,y)$ になる。この最初の存在を新定数 $c$ で Skolem 化すると $\forall y\,\neg R(c,y)$ である。この変換は充足可能性を保つ。別の普遍文と合わせて充足不能性を調べる場合には、全称の実例を閉項へ落として有限反証を求められる。全称変数 $y$ まで同時に定数に置換すると、元はすべての $y$ に求めていた条件を一元だけに弱めてしまう。
:::

### 有限化で何を抽出しているか

等号なしの存在形の Herbrand 定理は、有限個の実例のうち、どれが真かは構造に応じて変わってよいことを述べる。実例の組の個数は、領域が有限であることを主張しない。各実例を真にする構造を選ぶのではなく、任意の構造で少なくとも一つが真となるように選言する。例えば $\exists x(P(x)\to P(f(x)))$ では、$P(c)=0$ の構造なら最初の実例が真だが、$P(c)=1,P(f(c))=0$ なら二番目に頼る。

:::example[二つの項がどちらも必要な有限反証]
$P(c)$、$\forall x(P(x)\to P(f(x)))$、$\neg P(f^2(c))$ の例で、$x=f(c)$ の実例だけでは $P(c)=1,P(f(c))=P(f^2(c))=0$ として満たせる。$x=c$ の実例だけでは $P(c)=P(f(c))=1,P(f^2(c))=0$ として満たせる。両実例を揃えると $P(c)\to P(f(c))\to P(f^2(c))$ の二段が使え、どの命題評価も残らない。必要な実例の選び方と、個々の実例の論理的役割がここで見える。
:::

### 小さい節集合では実例の長さも追える

閉項 $c,f(c),\ldots,f^n(c)$ を使う理論
$$
P(c),\qquad \forall x(P(x)\to P(f(x))),\qquad \neg P(f^n(c))
$$
を考える。$n\ge1$ とする。閉項の構造に出る $P(f^j(c))$ を独立な命題変数 $p_j$ と読む。$j=0,\ldots,n-1$ の各実例を入れれば、$p_0$ から順に $p_1,\ldots,p_n$ を得て最後の否定と矛盾する。この有限反証では必要な実例の個数も示せる。ある $j<n$ で $p_j\to p_{j+1}$ がないなら、$p_i$ を $i\le j$ のとき真、それより後で偽とする割り当てを取る。唯一失敗する含意は取り除いたものなので、他のどの有限部分を足してもこの割り当てを排除できない。従って任意の有限反証はこの $n$ 個の異なる実例を含む。この族では、量化文一つを使うだけでも、必要な閉項の数に上界を与えるには目標の項を読む必要がある。

:::example[長さ三の有限反証を節の導出で作る]
$n=3$ では $\{p_0,\neg p_0\lor p_1,\neg p_1\lor p_2,\neg p_2\lor p_3,\neg p_3\}$ となる。解消を左から使うと $p_1,p_2,p_3$、最後に空節を得る。逆に中間の $\neg p_1\lor p_2$ がなければ、$p_0=p_1=1$ と $p_2=p_3=0$ で他の四節を満たす。カットに関する証明木上の中間式と、Herbrand の定理で得た有限反証の実例は別の役割を持つ。前者を除去しても、後者で必要な閉項の種類が一つになるわけではない。
:::

### Skolem 化で一般の文から普遍文を得る

一般の閉文の充足可能性は、冠頭形に直してから存在量化を関数記号へ移すことで、普遍文の問題にできる。先行する全称変数を $\vec u$ とし、最初の存在量化子までを $\forall\vec u\exists y\,D(\vec u,y)$ と書く。残りの量化子は $D$ の中にあってよい。まだ使っていない関数記号 $f$ を用意し、これを $\forall\vec u\,D(\vec u,f(\vec u))$ に替える。全称変数がない場合は $f$ を新定数とする。

元の文を満たす構造 $M$ では、各 $\vec a$ に対し $D(\vec a,b)$ を満たす $b$ が少なくとも一つある。メタ理論でこれらの証人から一つずつ選び、$f^M(\vec a)$ に指定すれば新しい文を満たす拡大を得る。逆に新しい文のモデルでは、各 $\vec a$ について $f^M(\vec a)$ が元の存在量化の証人になる。従って新記号を忘れると元の文を満たす。この二方向を繰り返せば、各存在量化を取り除いて普遍文が得られる。複数の文を処理するときは、新しい関数記号を文の間で共有しない。そうすれば拡大の選択が互いに干渉しない。

:::example[後から選ぶ変数の依存先]
$\forall x\exists y\forall z\exists u\,R(x,y,z,u)$ を変換すると
$\forall x\forall z\,R(x,f(x),z,g(x,z))$
となる。$y$ は $z$ を見る前に選ばれるため、$f$ の引数は $x$ だけである。$u$ を選ぶ段階では $x,z$ をともに使ってよい。既に選んだ $y$ の値も $f(x)$ で決まるので、別の独立した引数として残す必要はない。最初の $f$ に $z$ を渡すと、元の文が許さない依存を導入してしまう。
:::

この普遍文から閉項の有限反証を得るには、前の節で示した普遍文の形の Herbrand の定理を使える。例えば元の帰結 $A\models B$ を示すときは $A\land\neg B$ を充足不能の問題として変換できる。Skolem 化は元の式と新式の同じ言語内での論理的同値を保証する操作ではない。拡大が存在することと、元の構造が条件を満たすことの対応を使っている。

## Craig の補間定理

:::theorem[Craig の補間]{#thm-logic-craig}
等号を論理記号として許す一階言語で $A,B$ が文であり $A\models B$ なら、共通する非論理記号だけを持つ文 $C$ があり、$A\models C$ かつ $C\models B$ である。
:::

:::proof
$A,B$ の言語を $L_1,L_2$、共通言語を $L_0$ とする。空の連言には論理定数 $\top=\neg\bot$ を用いる。まず二理論 $T_1,T_2$ が、同じ完全な $L_0$ 理論 $S$ と両立する場合に、共通の領域上で両方を実現できることを示す。$T_1\cup S$ のモデル $M_0$ を取る。$T_2\cup S$ のモデルは $M_0$ の共通言語の初等図式を満たすように初等拡大できる。実際、図式の有限部分の連言を存在閉包した $L_0$ 文は $S$ に属すため、各有限部分は充足可能である。コンパクト性により $M_0$ の還元を初等部分構造に持つ $L_2$ モデル $N_0$ ができる。

ここで初等図式とは、モデルの各元に名前を付け、その言語で真になる文をすべて集めたものである。等号を含むため異なる元の名前は不等式で区別され、記号の解釈と全式の真理が保存される。次に $M_0$ の $L_1$ 初等図式と $N_0$ の $L_0$ 初等図式を合わせる。有限個の式で $M_0$ 内の元を固定し、$N_0$ の新しい定数だけを存在量化すると、共通言語の文は $M_0$ 側でも真である。従って有限充足性があり、$M_0$ の初等拡大 $M_1$ に $N_0$ の還元を初等的に含められる。以後は言語の役割を交互に替えて同じ操作を行う。初等鎖の和で各段が初等的であることは、式の構造帰納法で分かる。例えば和で存在文が真なら、その証人と有限個のパラメータを含む一段を取れる。帰納法でその段が本体を満たし、初等性でパラメータを含む最初の段へ存在文を戻せる。逆に一段での証人は和でも使える。$L_1$ と $L_2$ の各鎖の台の和は交互の包含から同じであり、共通言語の解釈も各段で一致している。従って二言語の解釈は和で両立し、両理論を同時に満たす。

$T_0$ を $A$ の全 $L_0$ 帰結とする。$T_0\cup\{\neg B\}$ にモデルがあると仮定し、その共通言語の完全理論を $S$ とする。$A$ と $S$ が両立しないなら、コンパクト性により $S$ の有限連言の否定が $A$ の $L_0$ 帰結となる。これは $T_0$ を満たすモデルで $S$ が真であることに反する。そこで先に示した構成を $A$ と $\neg B$ に適用すると $A\models B$ に反する。従って $T_0\cup\{\neg B\}$ は充足不能である。コンパクト性で有限個の $T_0$ の文を取り、その連言を $C$ とすればよい。
:::

### 補間文の確認

補間文が三つの条件を満たすには、使う記号を共通部分に絞り、左右の帰結を別々に検査する必要がある。共通記号が空の場合にも $\top$ と $\bot$ が使える。

:::example[一方だけの定数名を消去する]
$A=P(c)\land R(c)$、$B=\exists xP(x)\lor S(d)$ とする。二文の共通記号は $P$ のみである。$C=\exists xP(x)$ を取る。$A$ が真なら $c$ の値が $C$ の証人になり、$C$ が真なら $B$ の第一選言肢が真になる。単に $P(c)$ を中間式に選ぶと二つの帰結は満たせるが、右側の言語にない $c$ を含むため補間文の条件を満たさない。
:::

:::example[共有される関係がない場合]
$A=\forall xP(x)\land\exists x\neg P(x)$、$B=\forall xQ(x)$ とする。ここで $A$ は充足不能なので $C=\bot$ を取れる。反対に $A$ が充足可能で $B$ が恒真である場合は $C=\top$ が補間文になる。等号を論理記号として許すと、共有の非論理記号がない場合でも領域の大きさを述べる中間文が存在する。例えば $A=\exists x\exists y(P(x)\land\neg P(y))$ と $B=(\exists x\exists y(x\ne y))\lor\exists xQ(x)$ を取る。$A$ の証人は相異なるため、等号だけの $C=\exists x\exists y(x\ne y)$ が補間文になる。$B$ は $Q$ が空の一元構造では偽になるので、ここでは単なる $\top$ では補間できない。
:::

### 補間から定義の一意性を式にする

理論 $T$ を語彙 $L$ に単項述語 $P$ を加えた言語の有限個の文とし、その連言も $T$ と書く。同じ $L$ 構造上の二つの $T$ の拡大で $P$ の解釈が必ず一致するなら、$P$ を $L$ の式で定義できる。実際、新しい述語 $Q$ に $P$ を置換した文を $T_Q$ とし、さらに新定数 $c$ を置く。この仮定から $T\land P(c)\models T_Q\to Q(c)$ である。共通の非論理記号は $L$ と $c$ に限られるから、:ref[thm-logic-craig] により補間文 $\theta(c)$ がある。従って $T\models P(c)\to\theta(c)$ である。また $\theta(c)\models T_Q\to Q(c)$ の $Q$ を $P$ に換えると $T\models\theta(c)\to P(c)$ も出る。$c$ は $T$ にない名前なので、自由変数に戻せば $T\models\forall x(P(x)\leftrightarrow\theta(x))$ となる。無限の $T$ でも補間に必要な前提をコンパクト性で有限個に絞れる。

:::example[暗黙の指定から明示的な指定へ]
$L$ に二項関係 $R$ と定数 $d$ があるとする。$T$ が「全 $R$ の $d$ からの隣接元が $P$ に入る」と「非隣接元は $P$ に入らない」を含む場合、$L$ の構造を固定すると $P$ の範囲は一意である。実際、$\theta(x)=R(d,x)$ が二方向の含意を満たす。この例では定義式を直接読めるが、補間を使った証明は $T$ に長い量化式しか現れない場合にも同じ順で進む。
:::

### 命題の補間を真理表で計算する

命題式 $A,B$ に対し、両方に出る変数の集合を $X$、$A$ だけの変数を $Y$、$B$ だけの変数を $Z$ とする。$A\models B$ と仮定する。$X$ の評価 $v$ のうち、$Y$ の値を何か選んで $A$ を真にするものだけを残す。この有限の真理関数を標準形で $C(X)$ に表せる。各 $X$ の行を肯定の項として足すので、$A$ を満たす評価は必ず $C$ も満たす。逆に $C$ を満たすにもかかわらず $B$ が偽となる $X,Z$ の割り当てがあれば、$A$ を真にする $Y$ の証人を合わせられる。$Y$ と $Z$ が素なのでこの選択は $B$ の値を変えず、$A\models B$ に反する。従って $C\models B$ でもある。

:::example[共有変数の条件を表へ戻す]
$A=(p\lor q)\land(\neg p\lor r)$、$B=q\lor r\lor s$ とする。$X=\{q,r\}$ である。$(q,r)=(0,0)$ だと $A$ が $p$ と $\neg p$ の両方を要求するため解がない。$(0,1)$ では $p=1$、$(1,0)$ では $p=0$、$(1,1)$ ではどちらでも $A$ が真になる。従って残った三行を表す $C=q\lor r$ が補間文である。$s$ が真であるかどうかは $C$ では関わらない。
:::

この構成で得る $C$ は、$X$ だけを使う $A$ の帰結のうち最も強い。実際 $C$ を満たす評価は $A$ を満たすように延長できるため、あらゆる $X$ 上の帰結 $\theta$ を満たす。逆に $A\models C$ はすでに確認した。対称に、$B$ の $Z$ のすべての値で真になる $X$ の行を選べば、$B$ を含意する $X$ の式の中で最も弱いものが得られる。従って補間文を探すことは、共有変数の上でこの二つの間に真理関数を置くことと同じである。

:::example[共有変数がなくなると定数になる]
$A$ と $B$ が変数を共有せず、$A\models B$ とする。もし $A$ が充足可能なら、$B$ を偽にする任意の割り当てに $A$ の充足割り当てを合わせられる。従って $B$ は恒真であり $C=\top$ が使える。反対に $A$ が充足不能なら $C=\bot$ が使える。等号つき一階論理では共有の述語がなくても領域の濃度を式で区別できるので、この命題での帰結はそのまま移らない。
:::

## 直観主義論理と LJ

:term[直観主義論理]{en="intuitionistic logic" yomi="ちょっかんしゅぎろんり"} では、証明から証人や選ぶ側を明示できる規則が重要になる。LJ は右辺を高々一式とし、否定を $A\to\bot$ と定義する。右含意は $A,\Gamma\Rightarrow B$ から $\Gamma\Rightarrow A\to B$ を得る。左含意は $\Gamma\Rightarrow A$ と $B,\Pi\Rightarrow C$ から $A\to B,\Gamma,\Pi\Rightarrow C$ を得る。右選言は片方 $A_i$ を証明したとき $A_1\lor A_2$ を得る。空右辺は $\bot$ と同等とみなせる。連言、左選言、量化子は、一つの結論を保つ形で導入規則を使う。

:::example[排中律の失敗]
二点の順序 $w<v$ を取り、命題 $P$ を $v$ だけで真とする。Kripke 意味論では $w$ で $A\to B$ が真とは、$w$ 以上の各点で $A$ が真なら $B$ も真であることをいう。$\bot$ はどの点でも真でない。従って $w$ で $P$ は偽、$\neg P$ も $v$ が反例なので偽である。選言はその点でどちらかの枝が真であることを要求するので、$P\lor\neg P$ は $w$ で真でない。
:::

この命題部分で LJ の規則は真を保つ。真となる点の集合は結合子に関する帰納法により上方閉である。含意右では、現在の点で真な $\Gamma$ が上の点でも真なので、そこで $A$ が真なら前提によって $B$ が真となる。含意左では同じ点で前提から $A$ を得て、含意により $B$、次に $C$ を得る。連言と選言の各規則は同じ点での定義を用い、左の $\bot$ は反例を持たない。弱化、縮約、カットは前提の真の条件を合成する。従って二点モデルは LJ の命題断片での非導出を示す。一階の中間式を使う場合も各点で同じ一元領域を取り、関数をその唯一の値に、等号を同一性に解釈すればよい。この領域では各量化の本体を唯一の元で評価するため、左右の量化規則での項の実例と固有変数の実例が同じ値になる。従って量化規則も真を保ち、一階の LJ でも排中律は導出できない。

### 二重否定と Kripke 意味論

:::example[排中律の二重否定を証明する]
$H=\neg(P\lor\neg P)$ を仮定する。さらに $P$ を仮定すると選言導入で $P\lor\neg P$ が出て、$H$ を適用すると $\bot$ になる。この仮定 $P$ を閉じると $\neg P$ を得る。もう一度選言導入で $P\lor\neg P$ が出るので $H$ と合わせて $\bot$ になる。最後に $H$ を閉じれば $\neg\neg(P\lor\neg P)$ を得る。この導出は背理法で排中律そのものを取り出す規則を使わない。
:::

:::example[二重否定除去の反例]
二点 $w<v$ で $P$ が $v$ にだけ真であるとする。$w$ 以上のどの点でも $\neg P$ は真でない。従って $\neg P\to\bot$ は $w$ で真であり、$P$ は $w$ で偽だから $\neg\neg P\to P$ は $w$ で偽となる。ここで $w$ で $P$ が偽であることだけから $\neg P$ を真にすることはできない。含意には未来の点 $v$ も関わるからである。
:::

### Kripke モデルの命題完全性

LJ の命題断片で、式集合 $\Gamma$ の導出閉包を考える。導出は有限なので、$\Gamma$ が $B$ を導かないとき、$B$ を導かないまま $\Gamma$ を極大に延長できる。ここで可算の語彙では式を列挙して一つずつ加えられるものを加え、不可算の語彙では鎖の和に有限性を使って Zorn の補題を適用できる。得た極大集合 $S$ は演繹閉である。もし $S$ から $A$ が導けるなら、$A$ を加えて初めて $B$ が導けることはない。$A$ の証明を使ってその新しい導出をもとの $S$ から合成できるからである。さらに $S$ は $\bot$ を含まない。爆発により $B$ が出るためである。

$A\lor C\in S$ なら $A,C$ の少なくとも一方が $S$ に入る。両方が入らなければ極大性により $S,A\vdash B$ と $S,C\vdash B$ であり、選言左または選言除去で $S\vdash B$ となり矛盾する。このように演繹閉で矛盾せず、選言について一方を含む集合を素理論という。

:::theorem[命題の Kripke 完全性]{#thm-logic-intuitionistic-prop-completeness}
LJ の命題断片で $\Gamma\nvdash B$ なら、$\Gamma$ の各式が真で $B$ が真でない点を持つ Kripke モデルが存在する。
:::

:::proof
全ての素理論を包含で並べ、変数 $p$ は $p\in S$ の点で真とする。包含に対して原子真理は上方に持ち上がる。各式 $A$ の真偽と $A\in S$ が一致することを帰納する。$\bot$ はどこにもなく、連言の同値は連言規則、選言の同値は素性と選言導入による。$A\to C\in S$ なら各拡大点 $S'$ にも入る。もしそこで $A$ が真なら $A\in S'$ であり、含意除去で $C\in S'$ になる。逆に $A\to C\notin S$ なら $S,A\nvdash C$ である。もし導ければ含意右で $S\vdash A\to C$ となり、演繹閉性に反する。従って $S\cup\{A\}$ を $C$ を導かない素理論 $S'$ に延ばすと、そこで $A$ は真で $C$ は真でない。この上の点が含意の反例となる。最後に最初の $\Gamma$ を $B$ を導かない素理論に延長すれば、その点が目標の反例を与える。
:::

### 有限の Kripke モデルで判定する

:ref[thm-logic-intuitionistic-prop-completeness] で得た反例が無限でも、調べる式 $A$ の部分式だけに注目すれば、有限の反例に縮められる。$\Sigma$ を $A$ の全部分式の集合とし、標準モデルの素理論 $S$ の代わりに $s=S\cap\Sigma$ を点にする。同じ $s$ を生む素理論は同じ点とし、点を包含で並べる。変数 $p\in\Sigma$ は $p\in s$ のとき真であるとする。$\Sigma$ にない変数はどの点でも偽としてよい。この付値は包含に対して上方に閉じている。

任意の $D\in\Sigma$ について、縮めたモデルの点 $s$ で $D$ が真であることと $D\in s$ が同値になる。証明は部分式の帰納法による。原子式と $\bot$ は直接従い、連言と選言は $s$ が素理論の切り詰めであることと、部分式が $\Sigma$ に入ることから従う。$D=B\to C$ が $s$ に入れば、どの $s'\supseteq s$ にも $D$ は入る。$B$ がそこで真なら $B$ も $s'$ に入り、$s'$ を作った素理論の演繹閉性で $C$ が入る。逆に $D\notin s$ とし、代表の素理論 $S$ を一つ取る。標準モデルの含意の場合の証明により、$S$ の拡大で $B$ を含み $C$ を含まない素理論がある。それを $\Sigma$ に制限した点は $s$ 以上で $B$ を真、$C$ を偽とする。従って含意も真ではない。

点は $\Sigma$ の部分集合なので高々 $2^{|\Sigma|}$ 個である。従って $A$ が非導出なら、この大きさ以下の有限 Kripke モデルから反例が得られる。有限個の点上の半順序と、$A$ の有限個の変数に対する単調な付値を全列挙し、各式を再帰的に評価すれば決定手続きになる。健全性で反例があるとき必ず非導出であり、完全性と有限化で反例がないとき導出可能になる。

:::example[排中律に必要な二点]
$A=p\lor(p\to\bot)$ で部分式を $p,\bot,p\to\bot,A$ に絞る。前に使った二点反例では、下点はこの四式のいずれも真にせず、上点は $p,A$ を真にする。包含で二点が並ぶため、有限化のあとも両点は潰れない。もし対象を $p\lor p$ の部分式だけに変更すると、$p\to\bot$ の真偽を追う必要はなくなる。モデルの有限化の目標は、指定した式の真偽を残すことである。
:::

### 古典命題の二重否定を直観主義で導く

命題式 $A$ が古典論理の恒真式なら、LJ で $\neg\neg A$ が導出できる。もし導出できなければ有限 Kripke モデルのある点で $\neg\neg A$ が真でない。含意の意味により、その上の点で $\neg A$ が真である。さらに有限順序上で、その点以上の極大点を取れる。持続性によりそこでも $\neg A$ が真である。一方、極大点では含意を判定する点は自分自身だけであり、変数からの帰納法で全結合子が古典の真理関数に従う。従って古典の恒真式 $A$ はその極大点で真となる。するとそこで $\neg A$ と矛盾する。よって反例は存在しない。

:::example[二重否定を外すと逆方向の例にならない]
$A=P\lor\neg P$ は古典では恒真であり、$\neg\neg A$ は上の議論により LJ で導出できる。しかし $A$ 自身には二点反例がある。古典の妥当性から直観主義の妥当性を直接結論する代わりに、二重否定を付けたことが証明に関わっている。逆に $\neg\neg A$ が LJ で導出できれば古典でも真であり、古典の二重否定は $A$ と同値なので $A$ は古典恒真式になる。
:::

### 一階の Kripke 意味論で量化子を読む

半順序の各点 $w$ に非空の領域 $D_w$ を置き、$w\le v$ なら $D_w\subseteq D_v$ とする。関数と定数の解釈は、前の領域の元について上の点でも同じ値を取る。原子式の真理は上の点に持続すると仮定し、等号を使う場合は元の同一性とする。連言、選言、含意の条件は命題の場合と同じである。存在 $\exists xA(x)$ は現在の領域 $D_w$ から証人を取る。全称 $\forall xA(x)$ は、$w$ 以上の各 $v$ と $D_v$ の各元で本体が真であることを要求する。

真理の持続性は式の構造帰納法で従う。例えば存在の証人は上の領域に残り、本体の真理も帰納法で残る。全称は上へ移ると検査対象の点の範囲が狭まるため持続する。含意も同様に、上の点で課すのは元の点で課した条件の一部である。項の値が点を上げても同じであることは、解釈の約束と項の構造帰納法から従う。

LJ の全称右では、結論の前件を満たす点 $w$ を取り、各 $v\ge w$ と任意の $d\in D_v$ を考える。前件は持続性で $v$ でも真である。固有変数は前件に自由に現れないので、そこへ $d$ を割り当てると前提の結論が真になる。従って $w$ で全称が真となる。存在左では、現在の点の存在証人を固有変数へ割り当て、前件の残りと後件の値を変えずに前提を使う。全称左は現在の点と項の値を使えばよく、存在右ではその値を証人にする。命題部分と構造規則の健全性は既出なので、これで量化規則を含む健全性が得られる。

:::example[現在の領域を尽くしても全称が偽になる]
二点 $w<v$ で $D_w=\{a\}$、$D_v=\{a,b\}$ とし、$P(a)$ は両点で真、$P(b)$ は $v$ で偽とする。$w$ では現在の唯一の元が $P$ を満たすので $\exists xP(x)$ は真である。一方、$v$ の新しい元 $b$ が反例となり、$w$ で $\forall xP(x)$ は真でない。この例で全称を現在の領域だけで評価すると、全称の真理が上の点に持続しなくなる。
:::

## Gentzen による PA の無矛盾性証明と ε₀

順序数 $1,\omega,\omega^\omega,\omega^{\omega^\omega},\ldots$ の上限を $\varepsilon_0$ と呼ぶ。左から順に $\alpha_0=1,\alpha_{n+1}=\omega^{\alpha_n}$ とおけば、その上限 $\lambda$ で $\omega^\lambda=\sup_n\omega^{\alpha_n}=\lambda$ となる。任意の正の固定点 $\eta$ は帰納法で全 $\alpha_n$ 以上なので、$\lambda$ は最小である。順序数の定義と演算は [順序数](/math/sets-logic/ordinals/) を参照。

:::theorem[Gentzen の無矛盾性証明の到達点]{#thm-logic-gentzen-consistency}
原始帰納算術に、$\varepsilon_0$ 未満の標準順序数記法を全て並べた順序に沿う量化子なしの超限帰納法の図式を加えると、Peano 算術の標準的な無矛盾性文を証明できる。
:::

算術の帰納法を用いた導出には、純粋論理の式の複雑さだけでは減少を測れない変形が生じる。そこで $\omega$ の有限段の指数を使って証明変形を測り、矛盾の導出を仮定すると、終わらない厳密減少を構成する。この減少を禁ずるのが記法に沿った超限帰納法である。個々の算術推論、特に帰納法の変換に対して順序数の割当てと減少を証明するには、別の算術シークエント体系と記法の原始帰納的な実装が必要となる。その全構成は :cite[arai-logic] の Gentzen の無矛盾性証明を参照。この節のカット除去を算術の帰納公理にそのまま適用して得られる主張ではない。

### 記法と降下を分ける

$\varepsilon_0$ 未満の順序数を、有限の Cantor 標準形と、同じ方法で書いた指数で記録する。二つの形を比較するには、先頭の指数を再帰で比較し、等しければ係数を調べ、さらに等しければ次の項へ進む。再帰は有限の標準形を対象にするため、どの二記法かを比べる処理自体は有限で終わる。一方、各段の比較が有限で済むことは、任意の厳密下降列が続かないこととは別の性質である。実際、逆向きに並べた自然数でも隣接項の比較は容易だが、$0,1,2,\ldots$ はその順序で無限下降列になる。

:::example[有限係数を超える降下]
$\omega^2>\omega\cdot4+1>\omega\cdot4>\omega\cdot3+5$ を比べる。第一比較では最高指数 $2$ が $1$ を上回る。第二比較では最高項が等しく、末尾の $1$ が消える。第三比較は最高指数が $1$ で同じだが係数が $4$ から $3$ に落ちるため、右の有限末尾 $5$ に関係なく厳密に減る。証明変形の尺度で最高部が下がるなら、低い部に複数の新しい推論が追加されても順序数は減らせる。
:::

:::example[有限段の上界を超える記法]
$\alpha_0=1,\alpha_{n+1}=\omega^{\alpha_n}$ とする。$\omega^2$ は $\alpha_1=\omega$ を超えるが $\alpha_2=\omega^\omega$ 未満である。$\omega^{\omega+1}$ は $\alpha_2$ より大きいが $\alpha_3=\omega^{\omega^\omega}$ 未満である。各有限の記法は有限の段で抑えられるが、どの一段も全記法を抑えない。その上限 $\varepsilon_0$ に沿う全体の帰納法と、最初の有限段までの帰納法を区別する根拠になる。
:::

### 極限の記法を具体化する

$\varepsilon_0$ 未満の極限順序数の末尾を $\beta+\omega^\gamma$ と分ける。ただし末尾係数が二以上なら、最後の一項だけを右に取り、残りを $\beta$ に入れる。$\gamma=\delta+1$ なら $\beta+\omega^\delta(n+1)$ が $n$ とともに共終に上がる。$\gamma$ 自身が極限なら、$\gamma$ の共終列 $\gamma[n]$ を同じ規則で作り、$\beta+\omega^{\gamma[n]}$ を取る。有限の標準形の指数の深さが減るので記法操作はそこで停止する。いずれの場合も上限が $\beta+\omega^\gamma$ になることは右の和と指数の極限での連続性から従う。

:::example[極限順序数の共終列を求める]
$\lambda=\omega^3+\omega^2\cdot2$ とする。$\beta=\omega^3+\omega^2$、$\gamma=2$ とすれば $\lambda[n]=\omega^3+\omega^2+\omega(n+1)$ と取れる。各値は $\lambda$ 未満であり、末尾の $\omega(n+1)$ の上限が $\omega^2$ となるため全体は $\lambda$ に共終である。これに対し末尾をただ $\omega^2\cdot1$ に替えるだけでは、$n$ を増やしても同じ値にとどまり共終にならない。
:::

### 算術の有限証明を無限分岐の体系に移す

算術の順序数解析で使う一つの方法を述べる。式の否定を原子式まで押し込み、$\land,\lor,\forall,\exists$ と算術のリテラルだけを使う。式 $A$ の否定をこの形にしたものを $\overline A$ と書く。シークエント $\Gamma$ は閉じた式の有限集合であり、意図する読みはその選言である。具体的な閉項は計算し、数項にそろえる。真な閉リテラルを含むシークエントを初期式にする。

規則は次の通りである。文脈 $\Gamma$ に主式を入れたままでもよい。この約束によって、集合の記法で縮約を扱える。

- $\Gamma,A_i$ から $\Gamma,A_0\lor A_1$ を得る。ここで $i$ は $0,1$ のいずれかである。
- $\Gamma,A_0$ と $\Gamma,A_1$ から $\Gamma,A_0\land A_1$ を得る。
- $\Gamma,A(\bar n)$ から $\Gamma,\exists xA(x)$ を得る。
- 全 $n<\omega$ の $\Gamma,A(\bar n)$ から $\Gamma,\forall xA(x)$ を得る。これを :term[ω 規則]{en="omega rule" yomi="おめがきそく"} と呼ぶ。
- $\Gamma,A$ と $\Delta,\overline A$ から $\Gamma,\Delta$ を得るカットを許す。

高さの上界として各節点に順序数を与え、前提の高さは結論の高さより厳密に小さいとする。カット階数の上界 $r$ というとき、すべてのカット式の論理記号数は $r$ 未満とする。論理記号数には量化子と二項結合子を数え、リテラルの値は $0$ とする。弱化は導出の高さと階数を増やさない。証明木の全節点に同じ式集合を追加すれば、初期式はなお初期式であり、各規則を同じ場所で再適用できるからである。

まず任意の閉式 $A$ に対する $A,\overline A$ のカットなし導出を構成する。リテラルのとき二つのうち片方は真なので初期式である。$A=B\land C$ とする。$B,\overline B$ から $\overline A$ を選言導入して $B,\overline A$ を得る。同様に $C,\overline A$ を得て連言導入を使う。$A=B\lor C$ のときは $A$ を導入する側と $\overline A$ を導入する側を交換すればよい。$A=\forall xB(x)$ のとき、各 $n$ について $B(\bar n),\overline B(\bar n)$ から存在導入で $B(\bar n),\exists x\overline B(x)$ を得る。これらを $\omega$ 規則で結ぶ。$A=\exists xB(x)$ のときは二側を交換する。各実例の高さは式の論理記号数だけから一様に有限に抑えられるため、$\omega$ 規則を使ってもこの恒等の導出には有限の高さ上界を取れる。

この体系に PA の有限証明を移すには、各自由変数への標準数の割り当てごとに閉じた導出を作る。Hilbert 体系の命題公理は既に示した LK の導出を閉じた式で翻訳できる。LK の両側は、左辺の式の否定を右に加えれば一側になる。例えば LK の選言右で前提に両選言肢がある場合は、片方から選言を導入してもう片方を文脈に残し、その残した成分から同じ選言をもう一度導入する。文脈の集合に同じ式を二度入れても一つになるため、目標を得る。切断はそのまま使える。固有変数を用いる全称右や存在左には、固有変数への全ての数項割り当てを前提として $\omega$ 規則を使う。全称左と存在右では項の値を計算して一つの実例を使う。適切な等号公理は、閉じた二項が同じ標準数に計算された場合に同じ式が置換の前後に現れること、異なる場合に不等号が真なリテラルになることを使う。

PA の有限公理の各数項例は、この体系では数項計算に還元できる。例えば $x\ne0\to\exists y(x=Sy)$ の例を考える。$x=0$ の場合は $x=0$ が真のリテラルである。$x=n>0$ の場合は $y=\overline{n-1}$ を使う。後者の単射性や加法・乗法の公理も、全ての閉項を計算してから、対応する真のリテラルを用いる。各変数の全称閉包は $\omega$ 規則で作り、各枝の高さは数値に依存せず有限に抑えられる。

### 帰納公理に ω 規則を使う

任意の閉パラメータを固定し、$A(n)$ を帰納する式の $n$ 番目の数項例とする。$E=\exists x(A(x)\land\overline{A(Sx)})$ と置く。数項の後者を計算してそろえれば、各 $n$ に対し
$$
\overline{A(n)},\quad E,\quad A(n+1)
$$
をカットなしで導ける。実際文脈を $\Gamma_n=\{\overline{A(n)},A(n+1)\}$ とする。二つの恒等から $\Gamma_n,A(n)$ と $\Gamma_n,\overline{A(n+1)}$ を得る。連言導入で $\Gamma_n,A(n)\land\overline{A(n+1)}$、存在導入で $\Gamma_n,E$ になる。高さは式の論理記号数だけに依存する。

$\overline{A(0)},E,A(0)$ は恒等と弱化で導出できる。そこで $A(n)$ をカット式として上の導出を順に合わせ、各 $n$ に対する $\overline{A(0)},E,A(n)$ を有限の高さで作る。それらを $\omega$ 規則でまとめれば $\overline{A(0)},E,\forall xA(x)$ となる。これは帰納公理を選言に翻訳したものである。各 $n$ で必要な有限の高さは増え得るが、その上界は $\omega$ で足りる。カット式の論理記号数は全 $n$ で変わらない。必要なパラメータの全称閉包を取るときは、その個数に応じて高さを有限回だけ増やす。

従って一個の有限 PA 証明から、有限のカット階数と $\varepsilon_0$ 未満の高さを持つこの体系の導出が得られる。有限証明の木を下からたどると、各固有変数の箇所では前提の閉割り当てに依存しない高さ上界を一つ選べる。一つの論理規則、カット、量化の処理はその高さを有限回増やすだけである。帰納公理の導出には $\omega$ と有限の余分な高さで足りるので、元の証明が有限であることにより一様な上界が取れる。

### 高さを増やしてカット階数を下げる

以下で自然和 $\alpha\mathbin{\#}\beta$ は、両順序数を Cantor 標準形で書き、指数ごとに係数を加える演算である。どちらか一引数を狭義に減らせば全体も狭義に減る。実際、正規形で最初に異なる係数へ同じ値を足しても、そこでの大小が変わらない。

負の向きの式 $A_0\land A_1$ または $\forall x A(x)$ を終式に含む導出は、その一成分 $A_i$ または任意の数項例 $A(\bar n)$ を代わりに含む導出へ、高さとカット階数を増やさずに変形できる。高さに関する帰納法で示す。初期式には取り除く複合式とは別の真なリテラルが残る。最後の規則で取り除く式が主式なら、それに対応する前提を取る。主式が文脈にも残っている場合は、前提に帰納法を使ってそれも同じ成分で置き換える。それ以外なら各前提で文脈中の式を同じ成分に替え、最後の規則を再適用する。前提で取り除く式が他の規則の補助式としても必要なら、弱化でその補助式を戻してから規則を適用する。偽のリテラルの除去も同じ帰納法で可能である。そのリテラルは初期式の根拠にも、論理規則の主式にもならない。カットの前提で同じ式がカット式として必要なら、弱化で一時的に戻せる。

次にカット式 $C$ の論理記号数を $r$ とする。$\Gamma,C$ と $\Delta,\overline C$ に、階数上界 $r$、高さ $\alpha,\beta$ の証明があると仮定する。カットを一つ消して、階数上界 $r$、高さ $\alpha\mathbin{\#}\beta$ の $\Gamma,\Delta$ の導出を作れる。$C$ がリテラルの場合、一方が偽だからその偽リテラルを含む導出から取り除き、弱化で目的の文脈を得る。それ以外では、必要なら両側を交換し、$C$ の最外が選言または存在であるようにする。結論に既に $C$ または $\overline C$ があるなら、対応するもとの導出を弱化するだけで済む。

残る場合を $\alpha$ の帰納法で示す。第一の導出の最後が初期式なら、真なリテラルは複合式 $C$ でなく $\Gamma$ にある。従って結論も初期式である。最後の規則が $C$ 以外を主式とするなら、各前提に第二の導出を合わせる。各前提の高さは $\alpha$ 未満なので、帰納法による高さは $\alpha\mathbin{\#}\beta$ 未満になる。そこで最後の規則を再適用する。最後がカットでも同じであり、再適用するカットの階数は仮定で $r$ 未満である。

最後の規則が $C$ を導入した場合、その前提は $C$ の一つの選言肢または数項例 $D$ を持つ。ここに $C$ が文脈としても残るなら、その前提と第二の導出に帰納法を適用し、$\Gamma,\Delta,D$ を得る。残らなければ弱化で同じシークエントを得る。どちらも高さは $\alpha\mathbin{\#}\beta$ 未満である。一方 $\overline C$ は連言または全称であるから、第二の導出を先の反転により $\Delta,\overline D$ の導出へ変形できる。その高さは $\beta$ 以下であり、今の場合 $\alpha>0$ なので $\alpha\mathbin{\#}\beta$ 未満である。最後に $D$ でカットして $\Gamma,\Delta$ とする。$D$ の記号数は $r$ 未満なので目標の階数を保つ。

この一段の変形から、階数上界 $r+1$、高さ $\alpha$ の導出を、階数上界 $r$、高さ $\omega^\alpha$ へ変形できる。高さに関する帰納法で、各前提を階数上界 $r$ へ下げる。前提の高さ $\alpha_i$ は $\alpha$ 未満なので、変形後の高さ $\omega^{\alpha_i}$ は $\omega^\alpha$ 未満である。最後が通常の規則か既に階数が $r$ 未満のカットなら、単に同じ規則を再適用する。最後が階数 $r$ のカットなら、一段の変形で高さ $\omega^{\alpha_1}\mathbin{\#}\omega^{\alpha_2}$ の証明を得る。この自然和は $\omega^\alpha$ より小さい。実際その最高指数は $\max(\alpha_1,\alpha_2)<\alpha$ であり、係数も有限だからである。従ってどの場合も高さ上界を守る。

有限個の階数を一つずつ下げると、高さには有限回の $\xi\mapsto\omega^\xi$ が作用する。この操作で $\varepsilon_0$ 未満の順序数は $\varepsilon_0$ 未満のままなので、カットなし導出の高さもそこに収まる。空シークエントを結論とするカットなし導出は作れない。空シークエントは真なリテラルを持たず、論理規則の主式になり得る式も持たない。矛盾式 $0=S0$ は偽のリテラルなので、仮にこれだけのシークエントがカットなしで導けても除去により空シークエントになる。従って PA の矛盾の有限証明をこの変換では排除できる。

この説明では、無限導出を外部の木として扱った。:ref[thm-logic-gentzen-consistency] のように原始帰納算術上の主張として得るには、有限 PA 証明から作る無限導出の各節点を有限のコードで生成し、変形後の次の節点と厳密に減る順序数記法を原始帰納的な操作で算出できることを内部で検証する必要がある。その実装を伴う形式化は :cite[arai-logic] に譲る。上の計算で、カット階数を一つ下げるたびに高さがなぜ有限の指数反復で収まるかを確認できる。

### 高さの記法を使った小さいカットの計算

階数 $r$ のカットを除く補題で、左の最後の規則が高さ $\omega+2$、その前提が $\omega+1$、右の導出が高さ $\omega\cdot2+3$ とする。自然和を使った結論の高さは $\omega\cdot3+5$ である。仮に左で選言を導入し、出現している選言をその選言肢の前提にも残したとする。その場合、同じ式の除去を左の前提で先に行う。自然和で抑えた前提の高さは $\omega\cdot3+4$ であり、結論の上界より狭義に低い。右の負の式を選言肢の否定に反転しても高さは $\omega\cdot2+3$ 以下なので、これも結論の上界より低い。最後に前者の選言肢と後者のその否定で新しいカットを行うと、そのカット式の複雑さは $r$ より小さい。高さが低い方の呼出しでは元と同じ式が扱われ、最後の結合では複雑さが低い式に変わる。二つの減少が同じ規則に現れる箇所である。

:::example[カット階数を二段下げた上界]
高さ $\omega+2$、カット階数の上界が $2$ の導出を取る。ここで許されるカット式の記号数は $0,1$ である。一段下げた上界は $\omega^{\omega+2}$、さらに一段下げると $\omega^{\omega^{\omega+2}}$ である。$\omega+2<\varepsilon_0$ であり、$\varepsilon_0$ の固定点性と指数の狭義増加から二つとも $\varepsilon_0$ 未満である。この数は変換に使える上界であり、元の導出によっては除去した証明の高さはもっと小さくなる。
:::

## 演習問題

::::exercise{level=basic}
$A\land B\Rightarrow A$ をカットなしで導け。
:::solution
$A\Rightarrow A$ に左弱化で $B$ を足す。前件の二式を左連言の規則でまとめればよい。
:::
::::

::::exercise{level=basic}
$A\Rightarrow A\lor B$ をカットなしで導け。
:::solution
$A\Rightarrow A$ の右辺に右弱化で $B$ を足す。$A\Rightarrow A,B$ に右選言を適用して $A\Rightarrow A\lor B$ を得る。
:::
::::

::::exercise{level=basic}
$\alpha_0=1,\alpha_{n+1}=\omega^{\alpha_n}$ の $\alpha_2$ を求めよ。
:::solution
$\alpha_1=\omega^1=\omega$ である。次の段は $\alpha_2=\omega^\omega$ となる。
:::
::::

::::exercise{level=basic}
$P\land Q\models P\lor R$ の補間文を求めよ。
:::solution
共通の非論理記号は $P$ である。$P\land Q\models P$ と $P\models P\lor R$ が真理表から従うため $P$ が補間文になる。
:::
::::

::::exercise{level=advanced}
$(P(c)\to P(f(c)))\lor(P(f(c))\to P(f(f(c))))$ の恒真性を示せ。
:::solution
両選言肢が偽なら第一は $P(f(c))$ が偽であることを、第二は真であることを要求する。これは両立しない。
:::
::::

::::exercise{level=advanced}
$\neg P\lor\neg\neg P$ が一般の Kripke モデルで真にならない例を作れ。
:::solution
根に比較不能な二つの終点 $v,u$ を置き、$P$ は $v$ だけで真とする。根で $\neg P$ は $v$ により偽である。$u$ で $\neg P$ が真なので、根で $\neg\neg P$ も偽である。
:::
::::

::::exercise{level=advanced}
補間定理で $A$ と $B$ に非論理記号の共有がない場合、純粋等号なし言語で何が従うか。
:::solution
$A$ が充足可能で $B$ が妥当でないと仮定し、$A$ のモデル $M$ と $\neg B$ のモデル $N$ を取る。共通の非空領域 $M\times N$ に、$A$ の記号を第一座標の射影、$B$ の記号を第二座標の射影を通して解釈する。関係は対応する射影の逆像で解釈し、関数と定数は対応する座標で元の値を、他の座標で固定元を返すようにする。二語彙は共通記号を持たないので両解釈は両立する。等号がないため、一方の式の原子式の真偽は対応する射影で保存される。量化でも射影が全射なので、式の構造帰納法で全文の真偽が保存される。従ってこの構造では $A\land\neg B$ が真となり矛盾する。ゆえに $A$ が充足不能なら $\bot$、そうでなければ妥当な $B$ に対して $\top$ が補間文となる。
:::
::::

::::exercise{level=advanced}
カットなし導出において、量化式の文字列としての部分式だけでは足りない例を挙げよ。
:::solution
$\forall xP(x)\Rightarrow P(f(c))$ は左全称で $P(f(c))$ を実例にして導ける。代入により、左の全称式の本体 $P(x)$ に含まれない項が実例に現れる。
:::
::::

::::exercise{level=advanced}
$A\to C,\ B\to C\Rightarrow A\lor B\to C$ のカットなし導出を作る。共有文脈型の選言左を使う場合に、どこで弱化するかも示せ。
:::solution
恒等 $A\Rightarrow A,\ C\Rightarrow C$ から含意左で $A,A\to C\Rightarrow C$ を作り、$B\to C$ を左弱化で加える。第二枝では $B\Rightarrow B,\ C\Rightarrow C$ を用い、$B,B\to C\Rightarrow C$ に $A\to C$ を左弱化で加える。両枝で $A\to C,B\to C$ が共通文脈になったので、選言左で $A\lor B,A\to C,B\to C\Rightarrow C$ とできる。最後に含意右で $A\lor B$ を右の含意の前件へ移す。中間結論を別に証明してカットする必要はない。
:::
::::

::::exercise{level=advanced}
無限分岐のカット除去で、二つの変形済み前提の高さが $\omega^{\alpha_0}$ と $\omega^{\alpha_1}$、$\alpha_0,\alpha_1<\alpha$ であるとする。自然和が $\omega^\alpha$ 未満であることを、二つの指数が等しい場合と異なる場合に分けて示せ。
:::solution
両指数が同じ $\beta$ なら自然和は $\omega^\beta\cdot2$ であり、$\omega^\beta\cdot\omega=\omega^{\beta+1}\le\omega^\alpha$ より真に小さい。異なるなら大きい方を $\beta$、小さい方を $\gamma$ として自然和は $\omega^\beta+\omega^\gamma$ である。$\omega^\gamma<\omega^\beta$ によりこれは $\omega^\beta\cdot2$ 以下であり、同じ評価で $\omega^\alpha$ 未満である。従って最高指数が同じ場合に係数が二になることまで考えても、前提の高さの減少が全体の上界を保つ。
:::
