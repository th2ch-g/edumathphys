## この章の目標

- 記号の型と引数の数を区別し、項と式を構成する。
- 変数捕獲を避けて代入を計算し、代入補題を証明する。
- 構造と変数割り当てを指定し、量化式の真偽を判定する。
- 同型、初等同値、定義可能性を例によって区別する。

## 言語・項・論理式

例えば $f(0)$ は対象を表すが、$f(0)=0$ はその対象について述べる式である。この区別を構文で定めれば、どの式を量化できるかも明確になる。

:::definition[一階の言語と項]{#def-logic-signature}
:term[言語]{en="language" yomi="げんご"} $L$ は関数記号と関係記号の互いに素な集合、および各記号の非負整数のアリティからなる。零項関数記号を :term[定数記号]{en="constant symbol" yomi="ていすうきごう"} と呼ぶ。論理記号、等号、可算無限個の変数はこれらの記号とは区別する。:term[項]{en="term" yomi="こう"} は変数、定数、または $n>0$ 項関数記号 $f$ と項 $t_1,\ldots,t_n$ に対する $f(t_1,\ldots,t_n)$ である。ここで各定義は有限回の構成で得られる最小集合を取る。
:::

:::definition[原子論理式と量化]{#def-logic-first-formula}
$t=u$ および $n$ 項関係記号 $R$ に対する $R(t_1,\ldots,t_n)$ を :term[原子論理式]{en="atomic formula" yomi="げんしろんりしき"} という。式は原子式から $\neg\varphi$、$(\varphi\to\psi)$、$\forall x\,\varphi$ を有限回作って得られる。$\exists x\,\varphi$ は $\neg\forall x\,\neg\varphi$ の略記である。
:::

外側の記号から生成規則を決め、関数や関係の引数は括弧の深さを数えてコンマで切る。原子等式の等号は深さ $0$ に一つだけある。含意の二つの子は :ref[prop-logic-unique-parse] と同じ方法で分離できる。したがって以下では直下の項や式を一意に取り出して再帰を行える。

:::example[環の言語]
$0,1$ を定数、$+,\cdot$ を二項関数、$-$ を一項関数とする。$+(x,\cdot(y,y))$ は項であり、$x+y^2$ はその略記である。$\forall x\exists y\,(x+y=0)$ は加法逆元の存在を表す文である。これに対し $+(x)$ はアリティが合わない。
:::

:::example[順序の言語]
二項関係 $<$ を持つ言語では $x<y$ は原子式、$\forall x\neg(x<x)$ は式である。$x<(y<z)$ の右引数は式なので、これは原子式にならない。$x<y<z$ と書く場合は $(x<y)\land(y<z)$ の略記とする。
:::

### 言語を設計する

対象のどの情報を言語に含めるかは、後で何を表現できるかを決める。例えば単純グラフの言語には二項関係 $E$ を一つ置き、反射律の否定 $\forall x\neg E(x,x)$ と対称性 $\forall x\forall y(E(x,y)\to E(y,x))$ を別途課す。二公理のうち片方だけでは単純グラフにならない。例えば二頂点上の有向辺 $0\to1$ は前者を満たすが後者を破る。関数記号で辺を表すと、全域性と一意性が構造の定義に入るため、同じ記述にはならない。

:::example[同じ字面と違うアリティ]
$L$ に二項関係 $R$、一項関数 $f$、零項関数 $c$ があるとする。$R(f(c),x)$ は原子式であり、引数は項 $f(c)$ と $x$ である。$R(f,c)$ は $f$ を一項関数として適用していないので式にならない。$f(R(c,x))$ は $R(c,x)$ が式であるため項にならない。ソートを備えた言語を考える前でも、構文の型だけで二つの失敗を検出できる。
:::

:::example[自由な項代数]
言語が定数 $c$ と一項関数 $f$ だけを持つとする。変数を含まない項を :term[閉項]{en="closed term" yomi="へいこう"} という。この言語での閉項は $c,f(c),f(f(c)),\ldots$ である。任意の閉項を一番外から見れば、$c$ か、より短い閉項に $f$ を作用させたものかのいずれかなので、この一覧に漏れはない。各項は作用回数で区別できる。この集合を領域、$c$ を項 $c$、$f$ を項の外に $f$ を一個追加する操作とすれば、閉項が互いに異なる値を持つ構造が得られる。一方、一点構造ではすべて同じ値になる。
:::

### 項と式を一回の走査で読む

関数の引数に式を書いた場合、括弧の対応は合っていても入力を受理してはならない。そのため、構文を読み取る際には記号の個数だけでなく、各位置で項を待っているか式を待っているかを記録する。括弧を省いた前置表記を用いると、その記録の仕方が明確になる。例えば関数適用 $f(c,x)$ は字句列 $f\,c\,x$、等式 $f(c,x)=y$ は $=\,f\,c\,x\,y$ とする。量化子と直後の変数名は一対で一つの指示として扱う。

:::proposition[型を付けた前置記法の一意読み取り]{#prop-logic-typed-parsing}
関数記号と関係記号の種別・アリティが字句ごとに分かるとする。前置表記の有限字句列が一個の項または式を表すかどうかは、次の走査で決まり、受理された列の構文木は一意である。
:::

:::proof
最初に、項または式を要求する枠を一つ用意する。最も左の未確定の枠を次の字句で埋める。項の枠には変数または関数記号を入れる。変数には子がなく、$n$ 項関数には $n$ 個の項の枠を付ける。式の枠には等号、関係記号、結合子、量化子を入れる。等号なら項の枠二個、関係記号ならアリティ分の項の枠、否定と量化子なら式の枠一個、含意なら式の枠二個を付ける。量化子の指示は変数名を伴う必要があるので、名前がなければそこで拒否する。許されない字句が来た場合、枠が尽きたのに入力が残る場合、または入力が尽きたのに枠が残る場合も拒否する。

定義に沿った構文木を前置順に書いた場合、各字句に到達した時点で、その字句が埋めるべき枠は祖先の処理で作られている。記号の種別と子の数が一致するので拒否は起きず、最後に枠が尽きる。逆に受理した列の処理記録から、すべての枠が埋まった有限木が得られる。各頂点が要求された種別の子を持つため、葉から帰納的に見ればその木は項または式の生成規則に従う。また枠の位置と追加する枠の型は一段ごとに一意なので、別の構文木は得られない。
:::

:::example[空の組を読む]
$C$ を零項関数、$R$ を零項関係とする。項を要求する枠に $C$ が来れば一字で項が完成し、式を要求する枠に $R$ が来れば一字で式が完成する。$=\,C\,C$ は二つの項の枠をともに埋めるので式であるが、$=\,C\,R$ では二番目の項の枠に関係記号が来る。$\forall x\,R$ は式として受理される。量化する変数が式の本体に現れることは、構文の条件に含まれない。
:::

:::example[項の末尾と式の末尾を区別する]
$f$ を二項関数、$P$ を単項関係とする。式の列 $\to\,P\,f\,x\,y\,\neg\,P\,x$ を読むと、含意が二つの式の枠を作る。左の式の枠は $P$ により一項を要求し、その項は $f$ によって $x,y$ を吸収する。従って五字目までで左の式 $P(f(x,y))$ が完成する。次の否定は右の式の枠を受け持ち、$P(x)$ をその子に取る。もし左の $f$ を単項関数として宣言していたなら、五字目の $y$ を右の式の枠に入れることになり拒否される。
:::

普段の括弧付き表記では、先頭にある関数記号や関係記号からアリティを読み、括弧が指定する各引数を同じ条件で調べる。等号を中置で書く場合も、深さ零の等号を境に二つの項へ分ければ、前置表記と同じ木を得る。$x+y$ や $x<y$ は記号の位置を変えた略記なので、優先順位を決めない限り括弧を省いてはならない。

### 構文を測る二つの長さ

項や式の木の頂点数は、式の読み取りと代入が終わることを示す尺度になる。原子式を一頂点だけとみなす式の大きさと、内部の項まで数える構文木の大きさを区別する。例えば $t=u$ に含まれる量化子は零個であるが、$t,u$ に関数適用が多ければ式全体の文字列は長くなる。式の結合子だけに関する帰納法では原子式を基底とし、原子式中の項の値を調べる場面では項に対する別の帰納法を使う。

:::example[項の高さと量化の階数]
$t=f(f(f(x)))$ の項の高さは変数を零とすれば三である。式 $\forall y(t=y\to P(y))$ には量化子が一段しか入れ子になっていない。よって、量化子の評価で領域を走査する段数を測るには項の高さを数える必要はない。反対に、全称の本体を実際に評価するには $f$ を三回適用した値が必要になる。
:::

## 自由変数と代入

変数は式の内部で値を取り直す場合がある。そこで出現ごとに、その値を決める量化子があるかを調べる。

:::definition[自由変数と文]{#def-logic-free-variables}
原子式では項に現れる変数をすべて自由とする。否定では自由変数集合は同じであり、含意では二つの自由変数集合の和集合を取る。$\forall x\,\varphi$ では $\mathrm{FV}(\varphi)$ から $x$ を除く。式に自由変数がなければ :term[文]{en="sentence" yomi="ぶん"} と呼ぶ。量化子が値を指定する出現を束縛出現という。
:::

$\varphi[t/x]$ は、$\varphi$ における $x$ の自由出現を $t$ に置き換える操作である。$t$ に含まれる変数が置換位置で束縛される場合は、まず対応する束縛変数を、元の式にも代入項にも現れない新変数に改名する。捕獲が起きない場合に「$t$ は $\varphi$ で $x$ に自由に代入可能」という。文法に変数を可算無限個用意したので、有限個の式と項に出ない新変数を選べる。以下で $\varphi[t/x]$ を公理の実例として使うときは、改名済みの式に対する自由代入条件を確認する。

:::example[変数捕獲]
$\exists y(x<y)$ に $y$ を代入する。直接置換すると $\exists y(y<y)$ となり、代入した $y$ が束縛される。まず $\exists z(x<z)$ としてから代入すれば $\exists z(y<z)$ となり、$y$ は自由のままである。
:::

:::example[同名の自由出現と束縛出現]
$(P(x)\to\exists x\,Q(x,y))[f(y)/x]$ は $P(f(y))\to\exists x\,Q(x,y)$ である。右側の $x$ は量化子に束縛されている。元の式の自由変数は $x,y$、代入後は $y$ のみである。
:::

同時代入では指定した自由出現を同時に置換する。例えば $P(x,y)$ で $x,y$ を交換すると $P(y,x)$ となる。順次代入で $x$ を $y$ にしてから $y$ を $x$ にすると、$P(x,x)$ になり結果が異なる。

### 出現の位置を記録する

$\forall x$ の下にもう一つ $\forall x$ があるとき、内側の $x$ の出現を決めるのは最も近い量化子である。実際に改名するには、この対応を木の位置ごとに記録し、指定した束縛子に結び付く葉だけを置換する。

:::example[名前の再利用と改名]
$\forall x(P(x,y)\to\exists x\,R(x,y))$ を考える。外側の量化子を $u$ に改名すると $\forall u(P(u,y)\to\exists x\,R(x,y))$ になる。$R$ の第一引数は内側の量化子に結び付くので変更しない。その後で $x$ に項 $f(y)$ を自由代入しても変化しない。元の式で自由変数は $y$ のみだからである。
:::

:::example[二つの捕獲を同時に避ける]
$\forall y\exists z\,R(x,y,z)$ において $x$ に $f(y,z)$ を入れる。$y,z$ のいずれもそのまま使うと捕獲される。量化子と対応する出現を $u,v$ に改名してから代入し、$\forall u\exists v\,R(f(y,z),u,v)$ とする。改名後の自由変数は $y,z$ である。$u$ と $v$ の別の新しい名前を選んでも、どの項を自由に評価するかは変わらない。
:::

### 代入の合成を正確に記述する

置換 $\sigma$ は各変数に項を対応させ、指定していない変数はその変数自身に送る。ここで扱う置換は有限個の変数だけを変える。同時代入 $t^\sigma$ は、元の $t$ に現れる各変数を $\sigma$ の値に替える。替えた後の項の中に再び $\sigma$ を適用することはない。式では自由出現に限るため、必要な束縛名の改名を先に行う。

:::lemma[同時代入の合成]{#lem-logic-simultaneous-substitution}
$\sigma,\tau$ を二つの有限置換とし、$\upsilon(x)=\sigma(x)^\tau$ とする。項では $(t^\sigma)^\tau=t^\upsilon$ である。式では捕獲を避けると両辺は束縛名の違いを除いて同じ式を与える。
:::

:::proof
項が変数のときは $\upsilon$ の定義そのものであり、定数はどちらでも不変である。関数適用の場合は各引数に帰納法を適用する。これで式の原子段階が成立する。否定と含意は部分式に対応を適用するだけである。量化式では、最初に $\sigma,\tau$ が変える変数、その置換先の項に現れる変数、元の式に現れる変数を避けて、各束縛子に異なる名前を用意する。値の項は自由出現だけを置換するので、新しい束縛名はどちらの代入でも固定される。従って本体で二代入を合成しても、同じ量化子がその同じ位置を束縛する。別の新しい名前を用意した場合、どの量化子がどの出現を束縛するかが同じなので、名前を対応させれば式が一致する。
:::

:::example[後から入れた変数も次段では置換される]
$\sigma(x)=f(y)$、$\tau(y)=g(z)$ とし、他の変数は固定する。$P(x,y,z)^\sigma=P(f(y),y,z)$ であり、後から $\tau$ を適用すると $P(f(g(z)),g(z),z)$ になる。合成の値は $\upsilon(x)=f(g(z))$、$\upsilon(y)=g(z)$ なので、一回の同時代入でも同じである。単に $\sigma$ と $\tau$ の置換指定を並べた場合は、$x$ の値の内部が変わらず $P(f(y),g(z),z)$ になる。
:::

### 自由代入を位置から判定する

$t$ が $A$ で $x$ に自由に代入可能かどうかは、代入対象となる各出現から式の根へ向かって調べられる。その経路上の量化子の変数が $t$ に現れると、その出現で捕獲が起こる。一方、$x$ 自身を束縛する量化子の下にある $x$ は代入対象から外れる。従って $x$ が自由に現れない式では、どの項も条件を満たし、置換は式を変えない。

再帰的にも同じ判定ができる。原子式では量化子がない。否定では子の判定、含意では二つの子の判定を合わせる。$\forall y B$ では、$y=x$ または $x\notin\mathrm{FV}(B)$ ならその部分の置換を打ち切る。それ以外では $y$ が $t$ に出ず、かつ $t$ が $B$ で $x$ に自由に代入可能であることが必要十分となる。$y$ が $t$ に出ていれば、$B$ に残る自由な $x$ のどれに代入しても、その上に量化子 $\forall y$ があるからである。この条件は、構文を改名せずに使う代入と、改名してから行う捕獲回避代入とを区別する。

:::example[別の枝にある量化子]
$A=(\forall y P(y))\to Q(x,y)$ とする。$y$ を $x$ に入れるとき、自由な $x$ は右の枝にしかない。左の $\forall y$ は右の枝を束縛しないため、結果は $(\forall y P(y))\to Q(y,y)$ である。$y$ が式のどこかで束縛されているという理由だけで、自由代入を禁止する必要はない。
:::

:::example[同時代入でも捕獲を各位置で調べる]
$A=(\forall y P(x,y))\land(\forall x Q(x,y))$ で $x,y$ を同時に交換する。第一の本体では自由な $x$ に $y$ を入れるため、最初の量化子を $u$ に改名する。第二の本体では自由な $y$ に $x$ を入れるため、第二の量化子を $v$ に改名する。結果は $(\forall u P(y,u))\land(\forall v Q(v,x))$ である。代入後の自由な $y$ をもう一度 $x$ に戻す操作はない。
:::

### 自由変数集合を代入の結果から読む

:::proposition[捕獲回避代入と自由変数]{#prop-logic-free-variables-after-substitution}
$A^\sigma$ を有限置換 $\sigma$ による捕獲回避の同時代入とする。このとき
$$
\mathrm{FV}(A^\sigma)=
\bigcup_{x\in\mathrm{FV}(A)}\operatorname{Var}(\sigma(x))
$$
である。ここで $\operatorname{Var}(t)$ は項に現れる変数全体を表し、指定外の $x$ では $\sigma(x)=x$ とする。
:::

:::proof
最初に各量化子を異なる名前に変更し、すべての名前が代入項の変数と元の自由変数を避けるようにする。原子式の自由変数は項の変数であり、各変数を項に換えたとき現れる変数は、その項の変数の和集合である。否定では自由変数集合が変わらず、含意では両方の和集合を取る。量化子の内部を読むとき、付け直した束縛名 $u$ は置換で固定され、そのほかの代入項には出ない。よって内部の結果から $u$ を除く操作は、もとの自由変数集合から $u$ を除いた後で和集合を取ることと可換である。これで帰納法が完了する。
:::

この式は置換の台と式の自由変数の関係も明らかにする。例えば $P(x)\land Q(y)$ で $x$ に閉項 $c$ を入れると、$x$ に由来する自由変数は消える。一方 $x$ に $f(y,z)$ を入れれば、$y$ はもとからある自由変数と同じ名前にまとまり、$z$ が加わる。$x$ に自由出現が二回あっても、自由変数の集合では同じ名前を一回しか数えない。

## 構造と充足関係

式に値を付けるには変数の値に加え、記号が表す演算と関係を決める。例えば $<$ を通常の順序と読む場合と逆順序と読む場合とでは、同じ原子式の値が変わる。

:::definition[構造と項の値]{#def-logic-structure}
$L$ :term[構造]{en="structure" yomi="こうぞう"} $\mathcal M$ は非空集合 $M$ と、各 $n$ 項関数記号に対する全域関数 $f^\mathcal M:M^n\to M$、各 $n$ 項関係記号に対する部分集合 $R^\mathcal M\subseteq M^n$ からなる。零項関数の値は $M$ の一元であり、零項関係の値は空組を含むかどうかで決まる。割り当て $s$ は変数から $M$ への写像である。項の値 $t^\mathcal M[s]$ は変数で $s(x)$、定数で解釈の値、合成項で各引数を評価して $f^\mathcal M$ を適用した値である。
:::

:::definition[充足]{#def-logic-satisfaction}
:term[充足関係]{en="satisfaction relation" yomi="じゅうそくかんけい"} $\mathcal M,s\models\varphi$ は次で再帰的に定まる。

- $t=u$ は二つの項の値が等しいとき真である。
- $R(\vec t)$ は項の値の組が $R^\mathcal M$ に属するとき真である。
- 否定と含意の真偽は命題論理と同じである。
- $\forall x\,\psi$ は各 $a\in M$ で $\mathcal M,s[x\mapsto a]\models\psi$ となるとき真である。

したがって $\exists x\,\psi$ は条件を満たす $a\in M$ が一つでもあれば真である。
:::

:::lemma[自由変数への依存]{#lem-logic-assignment-locality}
項の値は項の変数の値のみに依存し、充足関係は式の自由変数の値のみに依存する。
:::

:::proof
項については変数と定数で直接に成り立ち、合成項では引数の値が一致すれば関数値が一致する。これを原子式に適用すると式の帰納法の基底が得られる。否定と含意では部分式の値から結果が決まる。$\forall x\,\psi$ の場合、自由変数上で一致する $s,s'$ をどの $a$ についても同じ値 $a$ に更新すれば、二つの更新は $\mathrm{FV}(\psi)$ 全体で一致する。帰納法の仮定を各 $a$ に適用する。
:::

:::lemma[代入補題]{#lem-logic-substitution}
$t$ が $\varphi$ の $x$ に自由に代入可能なら
$\mathcal M,s\models\varphi[t/x]$ と
$\mathcal M,s[x\mapsto t^\mathcal M[s]]\models\varphi$ は同値である。
:::

:::proof
変数、定数、関数適用の順の帰納法で、代入後の項の値は $s[x\mapsto t^\mathcal M[s]]$ による代入前の値と一致する。したがって等式と関係の原子式が成り立つ。否定と含意では同値を各部分式に適用すればよい。$\forall y\,\psi$ で $y=x$ の場合、外から与えた $x$ の値は内部で更新されるため影響しない。$y\ne x$ で $x$ が内部で自由に現れない場合は :ref[lem-logic-assignment-locality] を使う。それ以外では $y$ は $t$ に現れないから、$s[y\mapsto a]$ と $s$ で $t$ の値が等しい。異なる二変数の更新は可換なので、各 $a$ について帰納法の仮定が適用できる。
:::

特に $\forall x\,\psi$ の束縛変数を新しい $z$ に変えるとき、$z$ を $a$ に割り当てて代入補題を適用する。その結果は $x$ に $a$ を割り当てた $\psi$ の真偽である。$z$ は $\psi$ に現れないので元の割り当てにおける $z$ の値も影響しない。この理由で捕獲を避ける改名が意味を保つ。

:::example[順序と量化子]
$M=\{0,1,2\}$ に通常の $<$ を入れる。$\forall x\exists y\,(x<y)$ は $x=2$ で失敗する。$\exists x\forall y\,\neg(y<x)$ は $x=0$ を証人として真である。$M=\Z$ では $y=x+1$ を選べるため前者が真となり、$y=x-1$ が各候補 $x$ を退けるので後者は偽となる。
:::

:::example[量化子の順序]
$M=\{0,1\}$ では $\forall x\exists y\,(x=y)$ は $y=x$ で真となる。$\exists y\forall x\,(x=y)$ はどちらの $y$ に対しても異なる $x$ があるので偽となる。前者では $x$ の値ごとに証人を選ぶ。
:::

### 有限構造で充足を計算する

有限構造では量化ごとに全候補を列挙できる。自由変数が $k$ 個、領域が $m$ 元なら、式が定める解関係は $m^k$ 行の表を作れば得られる。関数記号がある場合は、原子式を評価する前に引数の項を内側から計算する。

:::example[三元環で量化子を入れ替える]
環 $\Z/3\Z$ で $A(x,y)$ を $x+y^2=0$ とする。$y=0$ なら $x=0$、$y=1,2$ なら $x=2$ がちょうど条件を満たす。よって $\forall y\exists x\,A(x,y)$ は真である。一方、$x=1$ の行には証人が一つもなく、$\forall x\exists y\,A(x,y)$ は偽である。$\exists x\forall y\,A(x,y)$ も偽であり、$y=0$ と $y=1$ が異なる $x$ を要求する。
:::

:::example[量化範囲と否定]
有向グラフの領域を $\{0,1,2\}$、辺を $\{(0,1),(1,2),(2,2)\}$ とする。各頂点に少なくとも一つの出辺があるため $\forall x\exists y E(x,y)$ は真である。一方 $\neg\forall y\exists x E(x,y)$ も真であり、$\exists y\forall x\neg E(x,y)$ に直せば $y=0$ が証人になる。二文が両立する理由は、前者が出辺を、後者が入辺を調べていることにある。
:::

### 全称を取ることと割り当てを固定すること

$\varphi(x_1,\ldots,x_n)$ を全称閉包すると、構造内での全割り当てが真であることを一つの文で述べられる。一方で各割り当てに対する充足関係は、変数を動かさず候補を選んでいる。このため、全称閉包を取ってしまうと異なる自由変数の共有関係が見えなくなる。

:::example[同じ式の二つの空所]
$P(x)\to P(y)$ は、$x,y$ がたまたま同じ元の割り当てでは真である。領域 $\{0,1,2\}$ のうち $P^\mathcal M=\{0,1\}$ とすると、偽になる組は $(0,2),(1,2)$ である。$x,y$ を別々に全称化するとその二組も検査するので偽となる。最初から $y$ を $x$ へ代入した $P(x)\to P(x)$ は三元どの値でも真であり、全称閉包も真になる。
:::

## 論理的帰結と恒真性

:::definition[モデルと帰結]{#def-logic-first-consequence}
文 $\varphi$ が構造 $\mathcal M$ の全割り当てで真なら $\mathcal M\models\varphi$ と書く。:ref[lem-logic-assignment-locality] により文ではどの割り当てで調べても同じである。文集合 $T$ の全要素を満たす構造を $T$ の :term[モデル]{en="model" yomi="もでる"} と呼ぶ。$T\models\varphi$ はすべての $T$ のモデルが文 $\varphi$ を満たすことをいう。開いた式も含む場合は同じ構造と同じ割り当てで仮定と結論を評価する。
:::

$\models\varphi$ というときは全構造と全割り当てにおける真理を主張している。例えば $\forall x\,P(x)\to\exists x\,P(x)$ は領域が非空なので恒真である。一方 $\forall x\,P(x)$ が単にあるモデルで真となるには、そのモデルで $P$ が領域全体であればよい。

:::example[反例の設計]
$\exists x(P(x)\land Q(x))$ から $\exists xP(x)\land\exists xQ(x)$ は従う。同じ証人を二つの存在文に使えるからである。逆向きには $M=\{0,1\}$、$P^\mathcal M=\{0\}$、$Q^\mathcal M=\{1\}$ を取れば、証人は別々に存在するが共通の証人がない。
:::

:::example[同じ割り当ての条件]
$P(x)\models\exists yP(y)$ では $s(x)$ を証人にする。これに対し $P(x)\models P(y)$ は、$P^\mathcal M=\{0\}$ の二元構造で $s(x)=0,s(y)=1$ とすると偽である。$P(x)$ と $P(y)$ の全称閉包は同じ真理条件を持つが、開いた式の帰結はそれより細かい。
:::

### 冠頭標準形と関数による証人の記録

量化子を一箇所にまとめれば、どの証人が先に選ばれた元に依存するかを読み取れる。式の先頭に量化子だけが並び、その後の本体に量化子がない形を :term[冠頭標準形]{en="prenex normal form" yomi="かんとうひょうじゅんけい"} と呼ぶ。

:::proposition[冠頭標準形への変換]{#prop-logic-prenex-form}
非空領域で考える一階論理の任意の式は、自由変数を変えずに、同値な冠頭標準形に直せる。
:::

:::proof
まず含意を否定と選言に直す。否定は連言と選言を交換して内側へ移し、$\neg\forall xA$ と $\neg\exists xA$ は量化子を交換した $\exists x\neg A$ と $\forall x\neg A$ に直す。これらは充足の定義により同値である。次に二式を連言または選言で結ぶ箇所で、各束縛変数を相手の式に出ない名前にする。

$Q$ を $\forall$ または $\exists$、$\circ$ を連言または選言とすると、$x$ が $B$ に自由に出ない場合、$(Qx\,A)\circ B$ と $Qx(A\circ B)$ は同値である。割り当てを固定すると $B$ の値は $x$ で変わらない。連言の $B$ が真、または選言の $B$ が偽なら両式は $QxA$ になる。残る場合は量化する本体の値が一定になり、非空領域で両式が一致する。同じ操作を左右双方に使えば冠頭の二列を順に外へ出せる。式の構造帰納法で原子式から始めれば、全量化子を先頭へ集められる。
:::

:::example[変数の名が重なる場合]
$(\forall x\,P(x))\lor(\exists x\,Q(x,y))$ で右の $x$ を $z$ に変更する。その後に左全称と右存在を順に外へ出し、$\forall x\exists z(P(x)\lor Q(z,y))$ を得る。自由変数は $y$ のままである。
:::

冠頭形の文で各存在変数に、先行する全称変数を引数とする新関数記号を置くと、全称量化のみの文が得られる。例えば $\forall x\exists y\forall z\exists w\,B(x,y,z,w)$ に対し $\forall x\forall z\,B(x,f(x),z,g(x,z))$ を作る。元の文を満たす構造では、選択公理を用い、各 $x$ に残りの式を満たす $y$ を選び、次に各 $(x,z)$ に $w$ を選ぶ。これを関数の解釈にできる。逆に新文のモデルから新記号を忘れれば、その関数の値を証人にして元の文を満たす。一般の有限列も存在変数の出現順に証人を選べば同じである。この :term[Skolem 化]{en="Skolemization" yomi="すこーれむか"} はモデルの拡大と縮小を対応させ、充足可能性を保つ。元のモデル上で新関数を任意に解釈して真偽が一致するわけではない。

### 理論を言語の拡大と縮小で比較する

$L\subseteq L'$ とする。$L'$ 構造から $L'\setminus L$ の記号の解釈を忘れたものを :term[還元]{en="reduct" yomi="かんげん"} という。反対に、同じ領域の上で新記号の解釈を与えたものを拡大と呼ぶ。項と式について再帰すると、$L$ の式の評価に新記号は一度も現れない。従って $L$ の式の真偽は還元をとっても変わらない。

:::example[グラフに証人を追加する]
$\forall x\exists y E(x,y)$ を満たす三頂点の先のグラフを取る。$f(0)=1,f(1)=2,f(2)=2$ とすれば拡大は $\forall x E(x,f(x))$ を満たす。同じグラフに $f(x)=0$ を入れた拡大はそれを満たさない。忘れた後は同じ構造になるため、元の文が真であっても拡大で新文が常に真になるわけではない。
:::

:::example[自由変数を定数に置き換える]
$\varphi(x,y)$ と $\psi(x,y)$ の開いた帰結を調べるために新定数 $c,d$ を置く。ある構造と割り当てが反例なら $c=s(x),d=s(y)$ と解釈して、文 $\varphi(c,d)$ と $\neg\psi(c,d)$ のモデルを得る。逆にそのモデルから定数の値を割り当てへ移せば反例になる。従って開いた帰結の判定には、同じ新定数を両文で共有させる必要がある。
:::

### 一階の文が無限の公理図式を必要とするとき

例えば群において元 $a$ が無限位数であることは、名前 $a$ を加えた言語で $a^n\ne e$ をすべての正整数 $n$ について課せば表せる。固定した一つの正整数 $n$ については積 $a^n$ を有限項で作れる。しかし自然数の指数回数をそのまま対象言語の量化変数にすることはできない。群言語の変数が走るのは群の元であり、外部の自然数そのものではない。この種類の図式を一文にまとめられるかは、[完全性定理とコンパクト性定理](/math/logic-set-theory/completeness/) のような手法で調べる。

:::example[有限個の元を指定する]
「少なくとも三元」を $\exists x\exists y\exists z(x\ne y\land x\ne z\land y\ne z)$ と書く。「高々三元」は $\exists x\exists y\exists z\,\forall u(u=x\lor u=y\lor u=z)$ である。後者に $x,y,z$ の相異条件を加えないため、一元または二元の領域でも一つの元に名前を重複して割り当てられる。両条件を一つにすれば、ちょうど三元を表せる。
:::

## 準同型・同型と初等同値

:::definition[写像による構造の比較]{#def-logic-structure-maps}
:term[準同型]{en="homomorphism" yomi="じゅんどうけい"} $h:M\to N$ は定数と関数値を保ち、$R^\mathcal M(\vec a)$ なら $R^\mathcal N(h(\vec a))$ を満たす。単射で関係を反映する準同型を埋め込みと呼ぶ。全単射な埋め込みを :term[同型]{en="isomorphism" yomi="どうけい"} という。二構造が同じ $L$ 文の集合を満たすとき :term[初等同値]{en="elementary equivalence" yomi="しょとうどうち"} といい $\mathcal M\equiv\mathcal N$ と書く。
:::

:::proposition[保存される式]{#prop-logic-isomorphism-invariance}
準同型は原子式および原子式から $\land,\lor,\exists$ で作る式の真を保存する。同型はすべての式の真偽を保つ。
:::

:::proof
項の帰納法により $h(t^\mathcal M[s])=t^\mathcal N[h\circ s]$ である。関数の場合は引数の等式を得たのち準同型の条件を使う。よって等式と関係の真は保存される。連言と選言は保存条件をそのまま引き継ぎ、存在式の証人は $h$ の像に移せる。同型では単射性と関係の反映によって原子式の偽も保存する。否定と含意は真偽を保ち、全称式では全射性により $N$ の全候補が $h(a)$ の形で得られる。よって式の帰納法で主張が従う。
:::

:::example[単射性と量化の限界]
加法群の自然な写像 $\Z\to\Z/2\Z$ は準同型である。$2\ne0$ は像では偽になる。一方 $\Z\hookrightarrow\Q$ は加法群の埋め込みだが、$1$ をパラメータとする $\exists y(y+y=1)$ は $\Z$ で偽、$\Q$ で真である。
:::

:::example[同型でない初等同値]
等号だけの言語における二つの無限集合を考える。式の自由変数への割り当てが同じ等号のパターンを持つとき、式の真偽が一致することを帰納法で示す。量化で新しい値を選ぶ場合、既出の有限個の値のいずれかと等しければ対応する値を選ぶ。どれとも異なればもう一方の無限集合にも未使用の値がある。これで原子式と量化の帰納段階が成立し、結合子は真理関数で処理できる。したがって $\N$ とその冪集合はこの言語では初等同値であり、:ref[thm-sets-cantor] によって同型にならない。
:::

### 有限構造は一つの文で記述できるか

有限言語 $L$ の有限構造 $M$ を考える。領域の全元を並べる変数 $x_1,\ldots,x_n$ を取り、相異なる条件と $\forall y\bigvee_{i=1}^n y=x_i$ を課す。各定数 $c$ に対し値を指す $c=x_i$、各正アリティの関数記号と各入力の組に対し値を指す $f(\vec x)=x_j$ を課す。各関係記号と入力の組についても、$M$ で真なら原子式、偽ならその否定を課す。全条件の連言を $\vec x$ で存在量化すると一文になる。この文のモデルでは、証人と $M$ 内の列挙との対応が全単射で、列挙した条件がすべての記号を保存・反映する。従ってモデルは $M$ と同型である。逆に $M$ はこの文を満たすので、同型不変性で同型な全構造が満たす。

:::example[二点の矢印]
$E$ を二項関係とし、二元構造でただ一つ $E(0,1)$ が真であるとする。記述文は
$$
\begin{aligned}
\exists a\exists b\bigl(&a\ne b\land\forall x(x=a\lor x=b)\\
&{}\land E(a,b)\land\neg E(b,a)\land\neg E(a,a)\land\neg E(b,b)\bigr)
\end{aligned}
$$
である。$E(a,b)$ だけを書けば、両向きの辺を持つ構造も通ってしまう。偽である原子情報が埋め込みに必要なのはこのためである。
:::

無限言語でも有限構造の初等同値から同型が従う。領域の大きさは有限の文で指定できるため、二構造の間には有限個の全単射しかない。同型がなければ各全単射を破る記号を一つ選び、その有限個の記号だけへ還元する。この有限言語ではすでに同型でなく、上の構成で二構造を分ける文が得られる。

### 量化の深さと有限の比較

関係記号だけの言語で、量化子の入れ子の最大深さを量化階数という。原子式は階数零、否定は階数を変えず、二項結合子は両辺の最大を取り、量化で一を加える。深さを $n$ に限った場合には、一度の量化で選ばれた元に対し、相手側で対応する元を一つ選ぶ作業を $n$ 回追えばよい。

:::proposition[有限往復と量化階数]{#prop-logic-finite-back-and-forth}
関係言語の二構造で既に有限組 $\vec a,\vec b$ が対応しているとする。零回対応できるとは、$\vec a,\vec b$ の全原子式が一致することとする。$n+1$ 回対応できるとは、全原子式が一致し、どちらで一元を追加しても相手側に一元を選んで拡張した組が $n$ 回対応できることとする。$n$ 回対応できる組は、階数が高々 $n$ の全式で一致する。
:::

:::proof
$n$ に関する帰納法を行い、その固定された $n$ では式の構造に沿って調べる。原子式は直接の条件によって一致する。否定と含意は部分式の真偽から定まる。$\exists x\,\psi$ の階数が高々 $n$ なら $n\ge1$ であり、$\psi$ の階数は $n-1$ 以下である。一方に真の証人があれば、対応条件により他方で証人を追加して $n-1$ 回対応する組を得る。帰納法で $\psi$ の真偽は一致するので、他方でも存在が真になる。初めに選ぶ側を交換すれば逆も成立する。全称は否定と存在に直せる。
:::

:::example[純粋等号で三元と四元を分ける]
等号しかない言語では、対応の途中でどの座標が同じ元を指すかだけが原子式の全情報である。三元構造と四元構造を空の組から三回比べる。既出元の選択には対応元を選び、新元の選択には今までに選んだ点が二つ以下なので、相手にも新元が残る。従って階数三以下のどの文も同じ真偽を持つ。同じ四回を要求すると、四元側で四回とも新元を選ぶ場合に三元側は最後の対応ができない。「少なくとも四元」の文は階数四であり、実際に両者を分ける。
:::

### 有限言語で往復の失敗を一つの式にする

:ref[prop-logic-finite-back-and-forth] の逆向きは、有限の関係言語では量化階数ごとの式の型を数えることで証明できる。自由変数を $x_1,\ldots,x_k$ に限る。階数零で使える原子式は、等号と有限個の関係記号に有限個の変数を入れたものだけなので有限個である。従って階数零の式の意味論的な同値類は、これらの原子式の命題真理関数の数で抑えられる。

階数 $n+1$ では、各量化式の本体の階数は $n$ 以下で、自由変数は既存の $k$ 個と新しい $y$ 一個に限れる。本体には帰納法で有限個の代表しかなく、存在量化した式の集合も有限である。全称は否定と存在で書ける。従って階数 $n+1$ の式は、元の原子式とその有限個の存在式の命題結合として表せる。これで任意の $n,k$ で同値類は有限になる。この帰納法は、$n$ を一段下げるときに $k+1$ の場合も使うため、初めから全 $k$ について同時に主張している。

いま二構造の組 $\vec a,\vec b$ が階数 $n+1$ 以下の全式で一致するとする。$M$ の任意の追加元 $a$ について、拡張組 $(\vec a,a)$ が満たす階数 $n$ 以下の全情報を一つの式 $\delta(\vec x,y)$ にまとめる。具体的には階数 $n$ の同値類から代表を一つずつ取り、真な代表はそのまま、偽の代表は否定して連言を作る。その階数は $n$ 以下である。代表が一つもない場合、空の連言は $y=y$ とする。$M$ の $\vec a$ で $\exists y\,\delta(\vec x,y)$ が真なので、仮定によって $N$ 側にも証人 $b$ がある。すると拡張組は階数 $n$ 以下の全式で一致する。初めの選択を $N$ 側でしても同じであり、階数の帰納法で $n+1$ 回の対応ができる。従って有限関係言語では、往復の判定は低い階数の文の一致と厳密に対応する。

:::example[二つの関係が同じ階数で現れる]
言語が一項述語 $P,Q$ だけを持つとする。階数一の閉文では、一元についての原子情報を $P,Q$ の真偽の組として調べられる。例えば「$P$ だが $Q$ でない元がある」は $\exists x(P(x)\land\neg Q(x))$ である。四種類それぞれの存在文に対する答えが同じ二構造は、最初にどちらで一点を選んでも同じ種類の点で応答できる。これで階数一の全閉文が一致する。一方 $(P,Q)=(1,0)$ の種類が一元だけか二元あるかは、階数二の $\exists x\exists y(x\ne y\land P(x)\land\neg Q(x)\land P(y)\land\neg Q(y))$ が区別する。一元についての原子情報と、二元が相異なるという追加の情報が必要な階数を変える。
:::

## 定義可能集合

:::definition[定義可能性]{#def-logic-definable-set}
式 $\varphi(\vec x,\vec y)$ と固定した $\vec b\in M^{|\vec y|}$ に対し、
$\{\vec a\in M^{|\vec x|}:\mathcal M\models\varphi(\vec a,\vec b)\}$ を $\vec b$ をパラメータとする :term[定義可能集合]{en="definable set" yomi="ていぎかのうしゅうごう"} という。パラメータを使わず表せるとき、パラメータなしで定義可能という。
:::

同じアリティの定義可能集合の共通部分は連言、和集合は選言、補集合は否定で表す。座標への射影は消去した座標を存在量化すれば得られる。例えば $\Z$ 上で $x=y+y$ の解集合を $x$ 軸に射影すると、偶数全体が得られる。このとき加法の記号は必要だが、特定の整数を指すパラメータは使わない。

:::proposition[自己同型による判定]{#prop-logic-definable-invariant}
$\vec b$ を固定する $\mathcal M$ の自己同型は、$\vec b$ から定義された集合を保つ。
:::

:::proof
自己同型とは構造からそれ自身への同型である。:ref[prop-logic-isomorphism-invariance] を $\varphi(\vec a,\vec b)$ に適用する。パラメータに対応する値は変わらない。逆写像も自己同型なので集合の像は元の集合と等しい。
:::

:::example[順序だけで原点を選べるか]
$(\Z,<)$ の平行移動 $n\mapsto n+1$ は自己同型である。$\{0\}$ はこの写像で $\{1\}$ に移るので、パラメータなしには定義できない。$0$ をパラメータに許せば $x=0$ が定義を与える。
:::

:::example[連続する元の定義]
$(\Z,<)$ で $y=x+1$ に相当する関係は $x<y\land\neg\exists z(x<z\land z<y)$ で定義できる。$x<y$ で $y\ne x+1$ なら $z=x+1$ が間にある。$(\Q,<)$ では $z=(x+y)/2$ が常に間に入るので、同じ式が空関係を定義する。
:::

### 定義可能性の判定に使える範囲

自己同型で保たれることは定義可能性の必要条件である。逆を使うには構造についてさらに仮定が必要になる。例えば $(\N,<)$ は自己同型が恒等写像だけである。最小元は順序だけで決まり、最初の $n$ 元が固定されれば残りの最小元も固定されるため、帰納的に全元が固定される。従ってどの部分集合も自己同型で保たれる。一方、式と有限の自然数パラメータの組は可算個に限られる。部分集合は Cantor の定理により非可算個あるので、定義できないものもある。

:::example[グラフによる関数の定義]
$(\Z,<)$ で後者のグラフを定義するには、$x<y$ かつその間に元がない条件を使った。どの $x$ に対しても $x+1$ は存在し、その条件を満たす $y$ は一意である。そこで式を関数記号を含む新言語に翻訳したい場合、後者の値を表す新変数を一つ存在量化し、このグラフの条件を加えればよい。例えば「$x$ の後者が $z$ より小さい」は $\exists y(x<y\land\neg\exists u(x<u\land u<y)\land y<z)$ となる。関数の一意性があるので、同じ変換を入れ子の項にも内側から使える。
:::

### 定義による記号の追加

$T\models\forall\vec x\exists!y\,\theta(\vec x,y)$ とする。新関数 $f$ を加え、$\forall\vec x\,\theta(\vec x,f(\vec x))$ を課すと、各 $T$ モデルはただ一つの拡大を持つ。各引数の組について一意に存在する値が $f$ の値を決める。零項の場合は定義可能な元の名前になる。

:::proposition[関数を定義式で取り除く]{#prop-logic-definitional-extension}
上の拡大言語の各式は、拡大公理の下で $L$ の式と同値である。特に拡大公理を追加しても、新たな $L$ 文の帰結は生じない。
:::

:::proof
項 $t$ の値が $y$ であることを表す式 $V_t(y)$ を再帰で作る。変数または定数では $y=t$ とする。関数適用 $h(t_1,\ldots,t_k)$ では新変数 $u_1,\ldots,u_k$ を取り、$\bigwedge_i V_{t_i}(u_i)$ と $y=h(\vec u)$ の連言を $\vec u$ で存在量化する。ただし $h=f$ のときは値の条件として $\theta(\vec u,y)$ を使う。この手続きで $V_t(y)$ はただ一つの元で真となり、その元は項の値に等しい。

原子式では項を全部新変数に置き、その値を与える式を連言する。等式または関係を新変数に課した後、値用の変数を存在量化する。構造帰納法で、否定、含意、量化は得られた式にそのまま適用できる。最後に、任意の $T$ モデルが拡大を持つので、拡大における $L$ 文の帰結はそのモデルでも真である。
:::

:::example[連続する三点]
$S(x,y)$ が $(\Z,<)$ の後者関係を表すとする。関数 $f$ を追加した式 $f(f(x))=z$ は $\exists u(S(x,u)\land S(u,z))$ へ翻訳される。例えば $x=2$ なら $u=3$ が一意に決まり $z=4$ が必要になる。後者が存在しない稠密順序では $f$ を同じ定義公理によって追加できない。
:::

### 一階の定義と集合演算の対応

$\vec x$ に関する定義可能集合を $D_\varphi$ と書く。$\varphi,\psi$ が同じ自由変数のスロットを使うなら、積集合の同じ基礎空間において $D_{\varphi\land\psi}=D_\varphi\cap D_\psi$、$D_{\varphi\lor\psi}=D_\varphi\cup D_\psi$、$D_{\neg\varphi}$ は $D_\varphi$ の補集合である。パラメータは両式が使うパラメータ組の和を許せばよい。射影 $\pi:M^{k+1}\to M^k$ については $\pi[D_\varphi]=D_{\exists y\varphi}$ となる。逆に定義可能な関係の射影の補集合を取ることは、すべての候補 $y$ が元の関係に入らないという全称条件に当たる。

:::example[射影の前に補集合を取ると結果が変わる]
$M=\{0,1\}$ の等号だけの言語で、関係 $D=\{(0,0),(1,1)\}$ を $x=y$ で定義する。第一座標への射影は $M$ 全体で、その補集合は空である。一方 $D$ の補集合は $\{(0,1),(1,0)\}$ なので、その射影も $M$ 全体である。前者が $\neg\exists y(x=y)$、後者が $\exists y(x\ne y)$ に対応する。否定を量化の内側へ動かす際に存在を全称へ換える理由が、この有限関係でも分かる。
:::

### 定義可能な領域へ量化を相対化する

全構造を使って、定義可能な部分集合だけに関する主張を述べたいことがある。例えば群の中で定義可能な部分群の元だけを量化したい場合、式の量化範囲を制限する。具体的に $D$ を $\delta(x,\vec b)$ の解集合とし、$D$ が非空で定数を含み、すべての関数で閉じているとする。言語の関数と関係を $D$ に制限すれば部分構造 $\mathcal D$ ができる。量化子を
$$
(\exists x A)^D=\exists x(\delta(x,\vec b)\land A^D),\qquad
(\forall x A)^D=\forall x(\delta(x,\vec b)\to A^D)
$$
と翻訳する。原子式は変えず、結合子は翻訳した部分式を同じ結合子でつなぐ。$\vec b$ を表す自由変数は、翻訳前に束縛変数と重ならないようにしておく。

:::proposition[相対化の充足補題]{#prop-logic-relativized-satisfaction}
$D$ 内で自由変数の値を指定すると、$\mathcal D$ での $A$ の値は $\mathcal M$ での $A^D$ の値と同じである。$\vec b$ は $D$ を定義するパラメータのまま評価する。
:::

:::proof
閉性と定数の条件により、$D$ の引数を代入した項はどちらの構造で評価しても同じ値になり、その値は $D$ に入る。関係が制限であることから原子式の値が一致する。結合子の値は子の値で決まる。存在式の相対化では、$\delta(x,\vec b)$ により $x$ の候補を $D$ に限る。その候補ごとに本体の値が帰納法で一致するので、証人の有無が一致する。全称式では、$D$ の外では前件 $\delta(x,\vec b)$ が偽であるため含意が真になる。$D$ の内側だけを検査すると $\mathcal D$ の全称式と同じ条件になる。
:::

:::example[順序群で偶数だけを見る]
$(\Z,0,+,-,<)$ で $\delta(x)=\exists y(x=y+y)$ とする。$D=2\Z$ は $0$ を含み、加法と符号反転で閉じる。「$2$ が最小の正元である」という主張は $2$ をパラメータに取れば、$D$ 上で $0<2\land\forall x(0<x\to 2\le x)$ と表せる。相対化すると全称の範囲が偶数に限定され、$\Z$ の中でも真になる。相対化前の文をそのまま $\Z$ で読むと $x=1$ で偽である。そのため、この部分構造は初等的ではない。
:::

### 他の言語の構造を式で組み立てる

相対化では記号の解釈をそのまま制限した。別の言語の記号を式によって解釈することもできる。例として $\mathcal M$ の中で非空の領域 $D$ を $\delta(\vec x)$ により $M^k$ の部分集合として定める。新言語 $L'$ の各変数の値は $D$ の元なので、元の言語では長さ $k$ の変数組で表す。新しい関係記号には組の関係を定める式を選び、関数記号には $D$ 上で全域かつ一意な出力を定めるグラフの式を選ぶ。定数は一意の組を定める零項関数として扱う。これらのデータから $D$ 上の $L'$ 構造が決まる。

:::proposition[式による解釈の翻訳]{#prop-logic-formula-interpretation}
上の解釈を固定すると、各 $L'$ 式に元の言語の式が対応する。$D$ の元を自由変数に入れたとき、$L'$ 構造での値と翻訳式の $\mathcal M$ での値は一致する。
:::

:::proof
項 $t$ の値が組 $\vec u$ であるという条件 $V_t(\vec u)$ を再帰で作る。変数の場合は、割り当てられた組と $\vec u$ の座標ごとの等式を使う。関数適用の場合は、各引数を表す組 $\vec v_i$ を量化し、各 $V_{t_i}(\vec v_i)$ と、関数グラフが $(\vec v_1,\ldots,\vec v_n,\vec u)$ で真である条件を連言する。出力が一意で $D$ に属することから、各項の翻訳はただ一つの値を指定する。原子等式は二項の値の組が座標ごとに等しいかを調べ、原子関係式は指定した関係の式を項の値に適用する。どちらも値を表す内部の組は存在量化する。

否定と含意は子の翻訳を同じ結合子で合わせる。$\exists x A$ は対応する組を存在量化し、$\delta(\vec x)$ と $A$ の翻訳を連言する。$\forall x A$ では $\delta(\vec x)$ を含意の前件とする。各変換で補助変数を新しく選ぶので、もとの自由変数を捕獲しない。項についての帰納法と、量化式で候補を $D$ に限ることから、式の構造帰納法で主張が従う。
:::

:::example[座標の対を元とする順序]
$(\Q,<)$ から領域 $\Q^2$ の辞書式順序を解釈する。領域は全ての対である。新言語の順序 $u<v$ を
$$
x_1<y_1\lor(x_1=y_1\land x_2<y_2)
$$
に換える。ただし $u=(x_1,x_2)$、$v=(y_1,y_2)$ である。二元の等号は $(x_1=y_1)\land(x_2=y_2)$ へ翻訳する。例えば「$u,v$ の間に $w$ がある」は、二つの順序式を連言して $w$ の二座標を存在量化する。第一座標が同じなら第二座標の中点、第一座標が異なるなら第一座標の中点を使える。これにより辞書式順序も稠密であることが分かる。
:::

同値類を元にする解釈では、座標ごとの等号を定義可能な同値関係に替える。関係の値と関数の出力の類は代表元によらなければならない。すると同じ帰納法で項は一つの類を定め、量化は全代表元を走査する。各類は少なくとも一つの代表を持つので、存在式と全称式の値は商上での評価と一致する。

:::example[剰余類を等価な組として扱う]
加法群 $(\Z,0,+,-)$ に定数 $1$ を加える。$x\sim y$ を $\exists z(x-y=z+z)$ と定義すると、偶数だけ異なる整数を同一視する。反射性、対称性、推移性は偶数の集合が部分群であることから従う。$x\sim x'$ かつ $y\sim y'$ なら $(x+y)-(x'+y')=(x-x')+(y-y')$ は偶数である。したがって加法は類の上に降りる。「商のどの元も二倍すると零になる」は $\forall x\,\exists z(x+x=z+z)$ に翻訳され、$z=x$ で真である。「商に零と異なる元がある」は $\exists x\neg\exists z(x=z+z)$ に翻訳され、$x=1$ が証人となる。
:::

## 演習問題

::::exercise{level=basic}
$\forall x(P(x,y)\to\exists yQ(x,y,z))$ の自由変数を求めよ。
:::solution
$P(x,y)$ の自由変数は $x,y$ である。$\exists yQ(x,y,z)$ の自由変数は $x,z$ である。含意で和集合を取り、外側で $x$ を除くので結果は $\{y,z\}$ である。
:::
::::

::::exercise{level=basic}
$\forall y\,R(x,y)$ に項 $f(y)$ を $x$ の代わりに代入せよ。
:::solution
束縛変数を新しい $z$ に変更して $\forall z\,R(x,z)$ とする。自由な $x$ を置き換えれば $\forall z\,R(f(y),z)$ である。
:::
::::

::::exercise{level=basic}
$\{0,1,2\}$ の通常の順序で $x<y$ を満たす組を列挙せよ。
:::solution
$x=0$ なら $y=1,2$、$x=1$ なら $y=2$、$x=2$ なら候補なしである。よって $(0,1),(0,2),(1,2)$ である。
:::
::::

::::exercise{level=basic}
$\forall x(P(x)\lor Q(x))$ から $\forall xP(x)\lor\forall xQ(x)$ が従うか判定せよ。
:::solution
二元構造で $P=\{0\},Q=\{1\}$ とする。各元はどちらか一方に入るので仮定は真である。どちらの述語にも含まれない元がそれぞれ一つあるため、二つの全称式はともに偽である。
:::
::::

::::exercise{level=advanced}
各正整数 $k$ に対して、領域がちょうど $k$ 元であることを述べる等号言語の文を作れ。
:::solution
$\exists x_1\cdots\exists x_k\,(\bigwedge_{i<j}x_i\ne x_j\land\forall y\,\bigvee_{i=1}^k y=x_i)$ とする。連言の前半で $k$ 個の相異なる元を要求し、後半で全領域をその列に含める。領域が $k$ 元なら全元を列挙して文を満たせる。
:::
::::

::::exercise{level=advanced}
$\forall x(P(x)\to Q(y))$ と $(\exists xP(x))\to Q(y)$ が $x\ne y$ の下で同値であることを示せ。
:::solution
$Q(y)$ が真なら両辺が真である。偽なら前者はすべての $a$ で $P(a)$ が偽である条件、後者は $P$ を満たす元が存在しない条件になる。$y$ の評価は $x$ の更新に影響されないため、二場合で尽くされる。
:::
::::

::::exercise{level=advanced}
$(\Q,<)$ で $b\in\Q$ を固定する全自己同型により保たれる一変数集合を求め、定義可能性を示せ。
:::solution
$b$ より小さい二数 $u,v$ について、$x\mapsto b+\frac{v-b}{u-b}(x-b)$ は順序を保ち $b$ を固定し $u$ を $v$ に移す。同じ計算が $b$ より大きい二数にも使える。したがって不変集合は $(-\infty,b),\{b\},(b,\infty)$ の一部の和集合に限る。各部分は $x<b,x=b,b<x$ で定義でき、選言でその和を取る。空集合は $x\ne x$ で得られる。
:::
::::

::::exercise{level=advanced}
すべての $L$ 文が同型で真偽を保つことから、構造の同型類が一つの文で定義できるとは限らない理由を示せ。
:::solution
純粋等号言語の可算無限集合と非可算集合は、有限個の値の等号パターンで比較する議論により初等同値である。一方、濃度が違うので同型でない。片方だけで真となる文が存在しないため、どちらの同型類も一つの文では定義できない。
:::
::::

::::exercise{level=advanced}
単純グラフの言語に、各頂点のある隣接元を返す関数 $f$ を加える。$\forall x E(x,f(x))$ を満たす拡大が存在するための条件を述べ、それが一意とは限らないことを五頂点以内のグラフで示せ。
:::solution
必要条件は $\forall x\exists y E(x,y)$ である。各 $x$ に対し $f(x)$ が証人になる。逆に各頂点に隣接元があれば、各頂点の非空の隣接集合から一元ずつ選んで $f$ を定められる。有限の場合は有限の選択で足り、一般の場合はメタ理論の選択公理を使う。三角形では各頂点に二つの候補がある。各候補から一つ選ぶだけなので $2^3=8$ 個の異なる拡大があり、一意性は成立しない。
:::
::::

::::exercise{level=advanced}
等号の言語の二元構造と三元構造について、階数 $2$ 以下の文で区別できないことを示し、階数 $3$ の区別文を挙げよ。
:::solution
最初の選択にはどちらにも元があり、次に既出元を選べば対応する元、新元を選べば別の元を選べる。原子式の情報は選んだ二元が同じかどうかだけなので、これで二回対応できる。:ref[prop-logic-finite-back-and-forth] により階数 $2$ 以下の文では区別できない。三回では $\exists x\exists y\exists z(x\ne y\land x\ne z\land y\ne z)$ があり、三元構造で真、二元構造で偽である。
:::

::::quiz{answer="2" tol="0"}
$\{0,1,2\}$ の通常の順序で $\exists z(x<z\land z<y)$ を満たさない狭義昇順対は何組か。ただし $x<y$ とする。
:::explanation
昇順対は $(0,1),(0,2),(1,2)$ である。このうち $(0,2)$ の間には $1$ があるので、条件を満たさないのは $(0,1),(1,2)$ の $2$ 組である。
:::

::::quiz
純粋等号言語で無限集合どうしが満たす性質を選べ。

- [ ] 同じ領域濃度を持つ。
- [x] 初等同値である。
- [ ] 必ず同型である。

:::explanation
どの式も評価中に指定する有限個の値について等号パターンだけを調べる。無限の領域では既出の値と異なる値をいつでも選べるため、すべての文で真偽が一致する。濃度が異なる無限集合を取れば他の二つは成立しない。
:::

四元の狭義全順序で $x<y$ を満たす順序対は何組か。
:::explanation
相異なる二元の集合につき、小さい元を先に置く順序が一つある。組数は $\binom 42=6$ である。

::::quiz
変数捕獲を避けた $(\exists yP(x,y))[y/x]$ を選べ。

- [ ] $\exists yP(y,y)$
- [ ] $\forall zP(y,z)$
- [x] $\exists zP(y,z)$

:::explanation
$\exists y$ の変数を新変数 $z$ に変えて $\exists zP(x,z)$ とする。その後に自由な $x$ を $y$ に変える。自由な $y$ を残し、量化子の種類は変えない。
