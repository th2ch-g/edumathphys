## この章の目標

- 普遍射をコンマ圏の始対象として記述する。
- 積・等化子・引き戻しを構成し、双対の構成と比較する。
- 積と等化子から任意の小さい極限を組み立てる。
- 集合でフィルター余極限と有限極限が交換する理由を説明する。

## 普遍射と普遍性

対象を作る方法がいくつかあるとき、外からその対象へ写す射、またはそこから外へ写す射を指定すると、構成に必要な条件を記述できる。例えば集合 $S$ の元を群へ送る写像から、$S$ を生成元とする自由群の準同型を作りたい。必要なのは指定した写像を延長でき、延長が一つに定まることである。

:::definition[普遍射]{#def-cat-universal-arrow}
$F:\mathcal D\to\mathcal C$ と $X\in\mathcal C$ に対し、:term[普遍射]{en="universal arrow" yomi="ふへんしゃ"} $u:X\to FA$ とは、任意の $v:X\to FB$ にただ一つの $h:A\to B$ があり $Fh\,u=v$ となる射である。双対の普遍射 $FB\to X$ は、任意の $FA\to X$ がただ一つの $A\to B$ の像を経由することを要求する。これがコンマ圏 $(F\downarrow X)$ の終対象の条件である。
:::

:ref[def-cat-comma] に照らすと、$u$ 自身が $(X\downarrow F)$ の始対象である。自由群の包含 $S\to U(F_S)$ がこの条件を満たすことは :ref[thm-grp-free-universal] で示されている。別の例として集合 $X$ を位相空間に移すとき、離散位相を入れた $X$ から任意の $Y$ への集合写像が連続である。したがって忘却関手に対する普遍射は台集合の恒等写像である。密着位相を使うと逆向きの普遍射になる。密着空間への全ての写像が連続だからである。

### 普遍射を Hom の表示に直す
構成の候補を具体的に作った後、その構成がどの対象に対しても同じ対応を与えることを示す必要がある。Hom で書くと、普遍性に必要な存在と一意性を一つの全単射で確認できる。

:::proposition[普遍射の Hom 判定]
関手 $R:\mathcal B\to\mathcal A$ と $A\in\mathcal A$ に対し、$\eta:A\to RB$ が普遍射であることは

$$
\Hom_{\mathcal B}(B,Y)\longrightarrow \Hom_{\mathcal A}(A,RY),\quad u\longmapsto R(u)\eta
$$

が全ての $Y$ で全単射であることに等しい。この全単射は $Y$ で自然である。
:::

:::proof
右辺の元 $\xi$ はコンマ圏の対象 $(Y,\xi)$ に当たる。$(B,\eta)$ からその対象への射は、左辺のうち $Ru\,\eta=\xi$ を満たす元である。各ファイバーが一点という条件は始対象の条件と一致する。$Y\to Y'$ を $v$ とすると $R(vu)\eta=R(v)R(u)\eta$ であるから自然性も従う。
:::

:::example[整数係数の自由対象]
二点を $\Z^2$ の二基底に送る写像を取る。Abel 群 $A$ の二元 $x,y$ を選ぶと、$(m,n)\mapsto mx+ny$ は加法を保ち、二基底の像に一致する。逆に準同型は基底の像で決まる。例えば $A=\Z/4$、$x=1$、$y=3$ なら $(2,3)$ の像は $2+9=11\equiv3$ である。二点からの写像自体は加法を持たないが、普遍射を通して整数係数の式が定まる。
:::

:::example[商行列からの因子化]
$\Q^3$ の $e_1+2e_2$ を消す写像をすべて表す商を考える。$q(x,y,z)=(y-2x,z)$ は全射であり、核は $\Q(1,2,0)$ である。$f$ がこの核を消すとき $\bar f(u,v)=f(0,u,v)$ とすれば、$(x,y,z)-(0,y-2x,z)=x(1,2,0)$ なので $f=\bar f q$ となる。$q$ が全射なので $\bar f$ は一意である。例えば $f(x,y,z)=6x-3y+5z$ は $-3u+5v$ へ降りる。
:::

### 具体例での計算

以下では候補を具体的に作ってから、比較射が存在する条件と、その一意性を順に確認する。

:::example[順序での最小候補]
二つの順序圏を $A=\{0,\ldots,5\}$、$B=\{0,\ldots,3\}$ とする。$R:B\to A$ を値の一覧 $R=(2,2,2,5)$ で定める。値は減少しないので、$y\le z$ なら $R(y)\le R(z)$ である。この関手を通して $x\in A$ から写せる $B$ の対象を調べる。

| $x$ | 条件 $x\le R(y)$ を満たす $y$ | 最小候補 |
| --- | --- | --- |
| 0 | 0, 1, 2, 3 | 0 |
| 1 | 0, 1, 2, 3 | 0 |
| 2 | 0, 1, 2, 3 | 0 |
| 3 | 3 | 3 |
| 4 | 3 | 3 |
| 5 | 3 | 3 |

候補があれば、最小候補はその行の全ての候補以下にある。前順序を圏として読むと、候補を互いに比較する射は、不等式が成立する場合に一つだけ存在する。空の行には最小候補が存在しない。 $x\to R(y)$ を対象とするコンマ圏では、最小候補は始対象である。実際 $y_0\le y$ で比較射が存在し、前順序の条件により比較の三角形は可換となる。各行の計算はこの始対象を直接求めている。
:::

:::example[可換な成分の組]
一つの矢印を持つ添字圏 $0\to1$ を固定する。二つの集合値図式は、それぞれ値の一覧 $f=(0,1,2,0,1)$ と $g=(0,0,1,1,2)$ によって指定する。従って前者の二頂点の濃度は $(5,3)$、後者は $(5,3)$ である。各集合の添字は $0$ から始める。

$f$ から $g$ への比較の成分 $u,v$ を、それぞれ頂点 $0,1$ に置く。恒等射については追加条件がなく、生成矢印について $gu=vf$ を解けばよい。そのために $v$ を先に選ぶ。$f(i)=j$ となる各 $i$ で $u(i)$ は $g^{-1}(v(j))$ から選べる。異なる $i$ での選択は独立なので、$u$ の候補数は

$$
\prod_{j=0}^{2} |g^{-1}(v(j))|^{|f^{-1}(j)|}
$$

である。空のファイバーからは指定する $i$ がないので、指数 $0$ の因子は $1$ とする。

| $v$ の値 | 許される $u$ の数 |
| --- | --- |
| $(0,0,0)$ | 32 |
| $(0,0,1)$ | 32 |
| $(0,0,2)$ | 16 |
| $(0,1,0)$ | 32 |
| $(0,1,1)$ | 32 |
| $(0,1,2)$ | 16 |
| $(0,2,0)$ | 8 |
| $(0,2,1)$ | 8 |
| $(0,2,2)$ | 4 |
| $(1,0,0)$ | 32 |
| $(1,0,1)$ | 32 |
| $(1,0,2)$ | 16 |
| $(1,1,0)$ | 32 |
| $(1,1,1)$ | 32 |
| $(1,1,2)$ | 16 |
| $(1,2,0)$ | 8 |
| $(1,2,1)$ | 8 |
| $(1,2,2)$ | 4 |
| $(2,0,0)$ | 8 |
| $(2,0,1)$ | 8 |
| $(2,0,2)$ | 4 |
| $(2,1,0)$ | 8 |
| $(2,1,1)$ | 8 |
| $(2,1,2)$ | 4 |
| $(2,2,0)$ | 2 |
| $(2,2,1)$ | 2 |
| $(2,2,2)$ | 1 |

異なる行の成分は $v$ で区別できる。従って表の和は $405$ 本となる。例えば $u=(0,0,0,0,0),v=(0,0,0)$ とすると、$gu$ の値の一覧は $(0,0,0,0,0)$ であり、$vf$ も同じなので確かに正方形が可換になる。

比較が可逆なら各頂点で逆の成分があるため、$u,v$ は両方とも全単射である。一方、両方が全単射なら $gu=vf$ に $v^{-1}$ と $u^{-1}$ を掛けて $v^{-1}g=fu^{-1}$ を得る。従って逆の成分も可換正方形を作る。上の数え上げで二つの全単射を要求すると $8$ 本になる。表に候補があっても、対象の濃度が合わなかったり、ファイバーの濃度が合わなかったりすると可逆なものは得られない。
:::

## 始対象と終対象

:::definition[始対象・終対象]{#def-cat-initial-terminal}
任意の $X$ への射 $I\to X$ がただ一本ある $I$ を :term[始対象]{en="initial object" yomi="したいしょう"} という。任意の $X$ からの射 $X\to T$ がただ一本ある $T$ を :term[終対象]{en="terminal object" yomi="しゅうたいしょう"} という。
:::

:::proposition[一意性]{#prop-cat-universal-uniqueness}
二つの始対象の間にはただ一つの同型がある。終対象でも同様である。
:::

:::proof
始対象 $I,J$ から互いへの唯一の射を $i,j$ とする。$ji$ は $I\to I$ なので恒等射に等しく、$ij$ も恒等射に等しい。双対圏に移すと終対象の主張を得る。
:::

$\mathbf{Set}$ の始対象は $\varnothing$、終対象は一点集合である。$\mathbf{Grp}$ では自明群が両者を兼ねる。このとき零対象と呼び、任意の二対象間に零対象を経由する零射がある。例えば $\Z\to\Z$ の零射は全整数を $0$ に送る。前順序の圏では始対象は最小元、終対象は最大元である。極小元は他の全ての元と比較できるとは限らないので、始対象の条件には足りない。

### 空図式と零射
空の添字圏からは制約となる射が一つも来ない。極限では試験対象からの射を、余極限では試験対象への射を数えるので、空の場合の条件はそれぞれ終対象と始対象になる。

:::proposition[零対象が与える零射]
始対象かつ終対象である対象 $0$ があれば、$X\to0\to Y$ で $0_{X,Y}$ が定まる。これは零対象の選び方によらず、$a0_{X,Y}=0_{X,Z}$、$0_{X,Y}b=0_{W,Y}$ を満たす。
:::

:::proof
二つの零対象の間の唯一の射は相互逆である。従って別の零対象を通る合成は、この同型を二つの片側に挿入して同じ射と分かる。例えば $a:Y\to Z$ の後合成では $0\to Y\to Z$ が始対象からの唯一の射である。前合成では $W\to X\to0$ が終対象への唯一の射となり、同じ結論が出る。
:::

:::example[集合と点付き集合]
集合では $\varnothing$ が始対象、一点集合が終対象である。空集合からの写像は存在し、空集合への写像は非空な始域に対して存在しない。点付き集合では一点集合が両方を兼ねる。始対象として使うと点を指定された基点へ送る必要があり、終対象として使うと全点を一点へ送る必要がある。例えば基点 $0$ を持つ三点集合と四点集合の間の零射は全てを $0$ に送る。
:::

:::example[連続写像の上の終対象]
$\mathbf{Top}/B$ では $\id_B$ が終対象である。実際 $p:X\to B$ からの射の台写像 $u$ は $\id_B u=p$ を満たすので $u=p$ に決まる。始対象は空空間から $B$ への写像であり、各 $p$ に唯一の空写像で写る。$B$ が二点空間ならこれらの台集合は濃度 $2$ と $0$ だから、$\mathbf{Top}/B$ に零対象はない。
:::

### 具体例での計算

以下では候補を具体的に作ってから、比較射が存在する条件と、その一意性を順に確認する。

:::example[順序での最小候補]
二つの順序圏を $A=\{0,\ldots,4\}$、$B=\{0,\ldots,3\}$ とする。$R:B\to A$ を値の一覧 $R=(0,1,2,3)$ で定める。値は減少しないので、$y\le z$ なら $R(y)\le R(z)$ である。この関手を通して $x\in A$ から写せる $B$ の対象を調べる。

| $x$ | 条件 $x\le R(y)$ を満たす $y$ | 最小候補 |
| --- | --- | --- |
| 0 | 0, 1, 2, 3 | 0 |
| 1 | 1, 2, 3 | 1 |
| 2 | 2, 3 | 2 |
| 3 | 3 | 3 |
| 4 | 空 | なし |

候補があれば、最小候補はその行の全ての候補以下にある。前順序を圏として読むと、候補を互いに比較する射は、不等式が成立する場合に一つだけ存在する。空の行には最小候補が存在しない。 $x\to R(y)$ を対象とするコンマ圏では、最小候補は始対象である。実際 $y_0\le y$ で比較射が存在し、前順序の条件により比較の三角形は可換となる。各行の計算はこの始対象を直接求めている。
:::

:::example[共通値のファイバー]
二つの集合 $A,B$ の元に $0$ から順に番号を付ける。写像 $f:A\to C$ と $g:B\to C$ の値を順に

$$
f=(0,1,2,0,1),\qquad g=(0,0,1,1,2)
$$

とする。値域 $C$ は表に現れる値全体とする。条件 $f(i)=g(j)$ を満たす対を求めるとき、共通の値でいったん分類すると数え落としを防げる。

| 共通値 $c$ | 左の添字 $i$ | 右の添字 $j$ | 組数 |
| --- | --- | --- | --- |
| 0 | 0, 3 | 0, 1 | $2\cdot2=4$ |
| 1 | 1, 4 | 2, 3 | $2\cdot2=4$ |
| 2 | 2 | 4 | $1\cdot1=1$ |

共通値を固定すれば左右を独立に選べる。異なる行に同じ対が現れることはない。従って最後の列を合計して $9$ 組を得る。実際、適合する対の集合は次のとおりである。

$$
\{(0,0),(0,1),(1,2),(1,3),(2,4),(3,0),(3,1),(4,2),(4,3)\}
$$

この集合から $A$ と $B$ への射影を取り、さらに $f,g$ を合成すると一致する。試験集合 $T$ から $u:T\to A$、$v:T\to B$ を選んで $fu=gv$ が成り立つなら、各 $t$ で $(u(t),v(t))$ は表の同じ行から選ばれた対である。従って $t\mapsto(u(t),v(t))$ が求める因子である。射影を指定した以上、その値を別の対に換えることはできない。この確認により、対の濃度だけでなく、その集合がどの射に対して普遍的かも決まる。

表から第一射影の像を読むには、右側に候補がある行だけを残して左側の添字を集めればよい。実際、そこにある添字だけが第二成分を補える。従って $g$ が全射なら第一射影も全射である。さらに $g$ が単射なら、補う第二成分は高々一つなので第一射影も単射である。$f$ と $g$ の役を交換すると第二射影についても同じ判定ができる。
:::

## 積と余積

二点 $Y$ と三点 $Z$ から同時に値を選ぶとき、組 $(y,z)$ にすれば射影で各選択を取り出せる。この操作が任意の圏で成り立つ条件を積と呼ぶ。

:::definition[積と余積]{#def-cat-product}
族 $(D_i)_{i\in I}$ の :term[積]{en="product" yomi="せき"} は対象 $P$ と射 $p_i:P\to D_i$ で、$q_i:X\to D_i$ の任意の族に対し $p_iq=q_i$ となる唯一の $q:X\to P$ があるものをいう。双対の :term[余積]{en="coproduct" yomi="よせき"} には包含 $j_i:D_i\to C$ があり、$f j_i=f_i$ となる唯一の $f:C\to X$ を要求する。
:::

集合の積は直積であり、求める写像は $x\mapsto(q_i(x))_i$ である。余積は添字付きの非交和であり、$f(i,x)=f_i(x)$ と一意に定まる。二点と三点の積は $6$ 点、余積は $5$ 点である。空族の積は終対象、余積は始対象となる。加群では有限積と有限余積が一致し、無限積の要素には無限個の非零成分を許すが、無限余積では有限個だけを許す。群の余積は自由積である。例えば $C_2$ 二つの余積には有限位数二の生成元が二つあるが、それらを交互に掛けた語は自由積の簡約形で長さが伸びる。

### 双積と成分表示
積への射は行き先ごと、余積からの射は出発点ごとに決まる。二つの性質が同じ対象で成り立つと、線形代数の行列のように各成分から全体を組み立てられる。

:::example[加群の有限直和と無限の場合]
有限族 $R^{n_i}$ の積と直和は同じ台加群である。例えば $R^2$ と $R$ では、$g_1:R^2\to M,g_2:R\to M$ に対し $g(x,y,z)=g_1(x,y)+g_2(z)$ が二つの制限を持つ唯一の線形写像である。積の普遍性は $u(t)=(u_1(t),u_2(t))$ で従う。無限個の $\Z$ では積には $(1,1,\ldots)$ が入るが、直和には入らない。各標準成分を固定したまま直和を積に送る唯一の写像は有限台列の包含であるから、その比較は同型ではない。
:::

:::example[集合では積と余積の濃度が違う]
$A=\{a,b\}$、$B=\{0,1,2\}$ の積は六点、余積は五点である。試験集合 $T=\{s,t\}$ から積への写像は、各点で独立な六択なので $6^2=36$ 本である。積の普遍性を使えば $\Hom(T,A)$ の四本と $\Hom(T,B)$ の九本の対を数えても $36$ 本になる。一方、余積から $T$ への写像は $2^5=32$ 本であり、余積の普遍性で $2^2\cdot2^3=32$ とも数えられる。試験対象の側が入れ替わる点に注意する。
:::

### 具体例での計算

以下では候補を具体的に作ってから、比較射が存在する条件と、その一意性を順に確認する。

:::example[共通値のファイバー]
二つの集合 $A,B$ の元に $0$ から順に番号を付ける。写像 $f:A\to C$ と $g:B\to C$ の値を順に

$$
f=(0,0,1,1),\qquad g=(0,1,1,1)
$$

とする。値域 $C$ は表に現れる値全体とする。条件 $f(i)=g(j)$ を満たす対を求めるとき、共通の値でいったん分類すると数え落としを防げる。

| 共通値 $c$ | 左の添字 $i$ | 右の添字 $j$ | 組数 |
| --- | --- | --- | --- |
| 0 | 0, 1 | 0 | $2\cdot1=2$ |
| 1 | 2, 3 | 1, 2, 3 | $2\cdot3=6$ |

共通値を固定すれば左右を独立に選べる。異なる行に同じ対が現れることはない。従って最後の列を合計して $8$ 組を得る。実際、適合する対の集合は次のとおりである。

$$
\{(0,0),(1,0),(2,1),(2,2),(2,3),(3,1),(3,2),(3,3)\}
$$

この集合から $A$ と $B$ への射影を取り、さらに $f,g$ を合成すると一致する。試験集合 $T$ から $u:T\to A$、$v:T\to B$ を選んで $fu=gv$ が成り立つなら、各 $t$ で $(u(t),v(t))$ は表の同じ行から選ばれた対である。従って $t\mapsto(u(t),v(t))$ が求める因子である。射影を指定した以上、その値を別の対に換えることはできない。この確認により、対の濃度だけでなく、その集合がどの射に対して普遍的かも決まる。

:::

:::example[可換な成分の組]
一つの矢印を持つ添字圏 $0\to1$ を固定する。二つの集合値図式は、それぞれ値の一覧 $f=(0,0,0,1,1)$ と $g=(0,0,1,1,2)$ によって指定する。従って前者の二頂点の濃度は $(5,2)$、後者は $(5,3)$ である。各集合の添字は $0$ から始める。

$f$ から $g$ への比較の成分 $u,v$ を、それぞれ頂点 $0,1$ に置く。恒等射については追加条件がなく、生成矢印について $gu=vf$ を解けばよい。そのために $v$ を先に選ぶ。$f(i)=j$ となる各 $i$ で $u(i)$ は $g^{-1}(v(j))$ から選べる。異なる $i$ での選択は独立なので、$u$ の候補数は

$$
\prod_{j=0}^{1} |g^{-1}(v(j))|^{|f^{-1}(j)|}
$$

である。空のファイバーからは指定する $i$ がないので、指数 $0$ の因子は $1$ とする。

| $v$ の値 | 許される $u$ の数 |
| --- | --- |
| $(0,0)$ | 32 |
| $(0,1)$ | 32 |
| $(0,2)$ | 8 |
| $(1,0)$ | 32 |
| $(1,1)$ | 32 |
| $(1,2)$ | 8 |
| $(2,0)$ | 4 |
| $(2,1)$ | 4 |
| $(2,2)$ | 1 |

異なる行の成分は $v$ で区別できる。従って表の和は $153$ 本となる。例えば $u=(0,0,0,0,0),v=(0,0)$ とすると、$gu$ の値の一覧は $(0,0,0,0,0)$ であり、$vf$ も同じなので確かに正方形が可換になる。

比較が可逆なら各頂点で逆の成分があるため、$u,v$ は両方とも全単射である。一方、両方が全単射なら $gu=vf$ に $v^{-1}$ と $u^{-1}$ を掛けて $v^{-1}g=fu^{-1}$ を得る。従って逆の成分も可換正方形を作る。上の数え上げで二つの全単射を要求すると $0$ 本になる。表に候補があっても、対象の濃度が合わなかったり、ファイバーの濃度が合わなかったりすると可逆なものは得られない。
:::

## イコライザとコイコライザ

:::definition[イコライザとコイコライザ]{#def-cat-equalizer}
平行な $f,g:X\rightrightarrows Y$ に対し、:term[イコライザ]{en="equalizer" yomi="いこらいざ"} は $fe=ge$ を満たす $e:E\to X$ であり、同じ条件を満たす $h:W\to X$ が一意に $e$ を通る。:term[コイコライザ]{en="coequalizer" yomi="こいこらいざ"} は双対である。
:::

イコライザは左から消去できる射である。$ea=eb$ なら同じ射の二つの因子分解なので $a=b$ である。集合では $E=\{x:f(x)=g(x)\}$ で、例えば $\Z$ 上で $f(n)=n^2,g(n)=n+2$ とすれば $E=\{-1,2\}$ である。集合のコイコライザは対 $(f(x),g(x))$ を全て含む最小の同値関係で $Y$ を割った集合である。条件 $qf=qg$ を満たす写像は同値関係を生成する各対で値が等しく、従ってその推移閉包上で一定である。加群ではこれらは $\Ker(f-g)$ と $Y/\Img(f-g)$ となる。

### 等式を課す側と商にする側
二本の射について、始域で値の一致を要求するとイコライザになる。終域で値の差を消すとコイコライザになる。加群では差を使えるので、同じ行列から両方を計算できる。

:::proposition[加群での等化子と余等化子]
二つの線形写像 $f,g:M\to N$ のイコライザは $\Ker(f-g)\hookrightarrow M$、コイコライザは $N\to N/\Img(f-g)$ である。
:::

:::proof
$u:T\to M$ について $fu=gu$ と $(f-g)u=0$ は同値である。従って $u$ の像は核に入り、核の包含が単射なので因子は一意である。$h:N\to T$ について $hf=hg$ と $h(f-g)=0$ は同値である。従って $h$ は像の上で零になり、各剰余類にその代表の $h$ による値を割り当てられる。商への射が全射なので因子は一意である。
:::

:::example[一つの差で二つの計算]
$f,g:\Z^2\to\Z^2$ の差を $(x,y)\mapsto(2x+4y,0)$ とする。核では $x=-2y$ だから、包含の行列は $\binom{-2}{1}$ と取れる。像は $2\Z\times0$ である。実際 $2x+4y$ は常に偶数であり、$y=0$ にすれば全偶数を得る。従ってコイコライザは $(u,v)\mapsto([u]_2,v)$ である。イコライザには捩れがなく、コイコライザには位数二の元が残る。
:::

:::example[集合では推移閉包まで取る]
$A=\{a,b\}$、$B=\{0,1,2,3\}$ として $(f(a),g(a))=(0,1)$、$(f(b),g(b))=(1,2)$ とする。$hf=hg$ なら $h(0)=h(1)$ と $h(1)=h(2)$ が必要なので、$h(0)=h(2)$ も必要になる。コイコライザの類は $\{0,1,2\}$ と $\{3\}$ である。一方で $A$ 上には $f(x)=g(x)$ となる元がなく、イコライザは空集合である。
:::

### 具体例での計算

以下では候補を具体的に作ってから、比較射が存在する条件と、その一意性を順に確認する。

:::example[等式と同一視]
集合 $A,B$ の元を $0$ から順に並べ、同じ始域と終域を持つ二写像 $f,g:A\to B$ を値で指定する。各行で二値を比べる方法と、終域の各点を辺で結ぶ方法を同じデータに適用する。

| 始域の添字 | 第一の値 | 第二の値 | 一致 |
| --- | --- | --- | --- |
| 0 | 0 | 0 | はい |
| 1 | 0 | 1 | いいえ |
| 2 | 1 | 1 | はい |
| 3 | 1 | 1 | はい |

始域で二値が一致する添字は $\{0,2,3\}$ である。$u:T\to A$ が二射を等化するとは、全ての $u(t)$ がこの集合に属することである。つまり $u$ をこの集合への写像とみなせば因子を得る。包含後に合う必要があるので、因子の値は $u(t)$ に決まる。

一方、終域では同じ行の二値を無向の辺で結び、辺を続けて進める点を同一視する。得られる類は $\{0,1\}$ である。$h:B\to T$ が $hf=hg$ を満たせば、辺の両端で値が同じである。さらに経路に沿って等号をつなぐと、各類で同じ値になる。逆に類に値を指定すると、辺の両端は同じ類なので等号が成立する。よってこの商の $1$ 個の元への値を選べば、二射を等化する $h$ が全て得られる。

同じ条件を自由 Abel 群の標準基底に移すと、各辺 $(j,k)$ が $e_j-e_k$ という関係に変わる。ある類の代表まで辺をたどれば、すべての $e_j$ が代表の基底と同じ類になる。逆に類ごとに座標を合計する写像は全ての差を消し、代表基底を別々の基底へ送る。従ってこの商は階数 $1$ の自由 Abel 群である。差の列を並べた行列

$$
\begin{pmatrix}0 & 1 & 0 & 0\\0 & -1 & 0 & 0\end{pmatrix}
$$

は階数 $1$ となる。この行列の核は階数 $3$ である。集合のイコライザに当たるのは差が零になる列である。加群の核にはさらに、差が非零な複数の列の線形結合で零になるベクトルも入る。
:::

## 引き戻しと押し出し

$x$ と $y$ が別の集合にあっても、共通の集合 $Z$ での像を比べられる。同じ像をもつ対だけを集めたものを考える。

:::definition[引き戻しと押し出し]{#def-cat-pullback}
$X\xrightarrow{f}Z\xleftarrow{g}Y$ の :term[引き戻し]{en="pullback" yomi="ひきもどし"} は $P\to X,P\to Y$ からなる可換四角形であり、同じ可換条件を満たす任意の射の対が一意に $P$ を通る。:term[押し出し]{en="pushout" yomi="おしだし"} は双対である。
:::

集合では $P=\{(x,y):f(x)=g(y)\}$ である。例えば $X$ の $Z$ 上の二つのファイバーの大きさが $2,1$、$Y$ の対応する大きさが $3,4$ ならば $|P|=2\cdot3+1\cdot4=10$ である。加群では $\Ker[(f,-g):X\oplus Y\to Z]$ を取る。押し出しでは $X\leftarrow Z\to Y$ の二つの射 $f,g$ に対し $(X\oplus Y)/\{(f(z),-g(z)):z\in Z\}$ を取る。各成分の写像を足し合わせた写像は、共通の $Z$ 上で値が一致するとき、かつそのときに限りこの商を通る。

集合の押し出しは非交和を作り $f(z)$ と $g(z)$ を同一視する。例えば各々 $3,4$ 点の集合に一点を含めて貼り合わせると、二点だけが一つになるので $6$ 点となる。例えば $Z=\{a,b\}$ とし、$X=\{x\}$ への写像を定値、$Y=\{y_0,y_1\}$ への写像を全単射とする。押し出しでは $y_0$ と $y_1$ がともに $x$ と同一視されるので、$Y$ からの構造射は単射でない。

### 二つの脚の一方を変える
引き戻しは二つの写像の値を同時に指定する構成である。押し出しでは共通部分についてだけ同じ写像を要求する。両者を図式の貼り合わせに使うときは、内側と外側の普遍性の関係が役に立つ。

:::proposition[引き戻しの貼り合わせ]
横に並んだ二つの可換四角形で右が引き戻しとする。左が引き戻しであることと、外側の長方形が引き戻しであることは同値である。
:::

:::proof
上段を $A\to B\to C$、下段を $D\to E\to F$ とする。右の引き戻しにより、任意の $T$ から $B$ への射は $T\to C$ と $T\to E$ のうち $F$ で一致する対と同じである。左の引き戻しを試すためのデータは $T\to B$ と $T\to D$ が $E$ で一致することである。従って先の対の $E$ 成分は $T\to D\to E$ に決まり、残るデータは $T\to C$ と $T\to D$ が $F$ で一致することである。この対応で $T\to A$ を自然に比較すると、左の普遍性と外側の普遍性の全単射は同じ条件になる。
:::

:::example[整数上で合同条件を引き戻す]
$\Z\to\Z/6$ と、部分群 $2\Z/6\hookrightarrow\Z/6$ の引き戻しは $2\Z$ である。実際 $n$ の剰余が部分群に入ることは $n$ が偶数であることに等しく、二脚の第二成分は $[n]_6$ に決まる。さらに零部分群を $2\Z/6$ に入れて引き戻せば $6\Z$ となる。二段階の外側では最初から $[n]_6=0$ を課しても同じ結果になる。
:::

:::example[整数の二つの倍写像の押し出し]
$\Z\xleftarrow{4}\Z\xrightarrow{6}\Z$ の押し出しは $\Z^2/\Z(4,-6)$ である。二つの写像 $a,b:\Z\to M$ が $a(4)=b(6)$ を満たすとき $(u,v)\mapsto a(u)+b(v)$ は関係を消し、一意に商を通る。$\binom{2}{-3}$ と $\binom{1}{-1}$ は行列式 $1$ の $\Z$ 基底であり、関係は第一基底の二倍である。従って押し出しは $\Z/2\oplus\Z$ となる。共通始域の二射がともに単射でも、押し出した対象は自由とは限らない。
:::

### 具体例での計算

以下では候補を具体的に作ってから、比較射が存在する条件と、その一意性を順に確認する。

:::example[共通値のファイバー]
二つの集合 $A,B$ の元に $0$ から順に番号を付ける。写像 $f:A\to C$ と $g:B\to C$ の値を順に

$$
f=(0,0,0,1,1),\qquad g=(0,0,1,1,2)
$$

とする。値域 $C$ は表に現れる値全体とする。条件 $f(i)=g(j)$ を満たす対を求めるとき、共通の値でいったん分類すると数え落としを防げる。

| 共通値 $c$ | 左の添字 $i$ | 右の添字 $j$ | 組数 |
| --- | --- | --- | --- |
| 0 | 0, 1, 2 | 0, 1 | $3\cdot2=6$ |
| 1 | 3, 4 | 2, 3 | $2\cdot2=4$ |
| 2 | 空 | 4 | $0\cdot1=0$ |

共通値を固定すれば左右を独立に選べる。異なる行に同じ対が現れることはない。従って最後の列を合計して $10$ 組を得る。実際、適合する対の集合は次のとおりである。

$$
\{(0,0),(0,1),(1,0),(1,1),(2,0),(2,1),(3,2),(3,3),(4,2),(4,3)\}
$$

この集合から $A$ と $B$ への射影を取り、さらに $f,g$ を合成すると一致する。試験集合 $T$ から $u:T\to A$、$v:T\to B$ を選んで $fu=gv$ が成り立つなら、各 $t$ で $(u(t),v(t))$ は表の同じ行から選ばれた対である。従って $t\mapsto(u(t),v(t))$ が求める因子である。射影を指定した以上、その値を別の対に換えることはできない。この確認により、対の濃度だけでなく、その集合がどの射に対して普遍的かも決まる。

表から第一射影の像を読むには、右側に候補がある行だけを残して左側の添字を集めればよい。実際、そこにある添字だけが第二成分を補える。従って $g$ が全射なら第一射影も全射である。さらに $g$ が単射なら、補う第二成分は高々一つなので第一射影も単射である。$f$ と $g$ の役を交換すると第二射影についても同じ判定ができる。
:::

:::example[整数の関係行列]
整数行列を一つ指定し、自由 Abel 群の写像の核と商を同時に調べる。標準基底の順に列を読むものとする。

$$
A=\begin{pmatrix}0 & 8 & 4\\6 & 0 & 2\end{pmatrix}:\Z^{3}\to\Z^{2}
$$

有理数上の階数は $2$ だが、この数だけでは像の指数が分からない。整数上で行と列の基本操作を行い、対角上の正の成分が順に整除する表示を使う。この表示の存在は :ref[thm-ring-smith] による。許す基本操作は交換、符号の反転、一列または一行の整数倍を別の列または行に加える操作であり、どの操作にも整数係数の逆操作がある。従って座標変換として核と余核を保つ。

サイズ $k$ の小行列式が生成するイデアルは座標変換で変わらない。実際、行の加法操作をした小行列式を選ぶと、多重線形性で元の小行列式の整数線形結合になる。交換と符号反転でも同様であり、逆操作も使えば逆の包含を得る。列操作にも同じ議論を適用できる。対角形では整除関係から、非零なサイズ $k$ の小行列式の最大公約数 $\Delta_k$ は先頭の $k$ 個の対角成分の積である。従って $\Delta_0=1$ とすれば、対角成分は $\Delta_k/\Delta_{k-1}$ になる。

この行列で小行列式を計算すると次のようになる。重複する絶対値は省いた。階数を越えるサイズのものは全て零である。

| サイズ | 小行列式の絶対値 | $\Delta_k$ | 対角成分 |
| --- | --- | --- | --- |
| 1 | 0,2,4,6,8 | 2 | 2 |
| 2 | 16,24,48 | 8 | 4 |

従って非零対角成分の一覧は $(2,4)$ になる。商の各対角座標はその成分による剰余になるので、有限巡回因子は $(2,4)$ を位数に持つもの、自由階数は $0$ である。成分が $1$ なら対応する巡回因子は零である。一方、核は対角成分のある入力座標を零にしたものだから自由階数 $1$ となる。これで有理数上の階数に加え、整数で残る捩れも計算できた。
:::

## 極限と余極限の一般論

:::definition[錐と極限]{#def-cat-limit}
小圏 $J$ による図式とは関手 $D:J\to\mathcal C$ である。頂点 $X$ の :term[錐]{en="cone" yomi="すい"} は $\lambda_j:X\to D(j)$ の族で $D(a)\lambda_i=\lambda_j$ を各 $a:i\to j$ について満たす。:term[極限]{en="limit" yomi="きょくげん"} は錐の圏の終対象、:term[余極限]{en="colimit" yomi="よきょくげん"} は余錐の圏の始対象である。
:::

錐の射 $h:X\to Y$ は $\lambda_j^Y h=\lambda_j^X$ を満たす。従って極限は $\Hom(X,\lim D)\cong\operatorname{Nat}(\Delta X,D)$ を与える。ここで $\Delta X$ は各対象を $X$、各射を $\id_X$ に送る定値図式である。左辺の射の前合成は右辺の錐の全成分の前合成に一致する。離散形の極限は積、平行射の形の極限はイコライザ、二本が同じ対象へ入る形の極限は引き戻しである。図式形 $J$ が始対象 $i$ をもつとき、$D(i)$ を頂点として唯一の $i\to j$ から錐を作れる。任意の錐は $i$ での成分を使ってこの錐を通るので極限である。双対的に $J$ に終対象があればそこでの値が余極限になる。

集合の余極限は $\coprod_j D(j)$ を $(i,x)\sim(j,D(a)x)$ が生成する同値関係で割った集合である。任意の余錐は生成関係を保つため商の写像を作り、その値は代表上で既に決まる。例えば $2\xrightarrow{}3\xrightarrow{}4$ 点と続く図式の余極限は最後の $4$ 点であり、最初の $2$ 点が繰り返し数えられることはない。

### 添字圏の変更

余極限を計算するとき、図式の全対象を同じように追う必要がないことがある。例えば $\N$ による列の余極限は偶数段階だけで記述できる。各段階は後の偶数まで移り、二つの持ち上げはさらに後の段階で比較できるためである。

:::theorem[終関手による余極限の比較]{#thm-cat-final-functor}
$u:I\to J$ とする。各 $j$ について $(j\downarrow u)$ が非空かつ連結なら、任意の図式 $D:J\to\mathcal C$ の余極限を $Du$ の余極限で計算できる。この条件を満たす $u$ を :term[終関手]{en="final functor" yomi="しゅうかんしゅ"} という。逆に、$\mathbf{Set}$ 値のすべての図式で余極限の比較が全単射なら、この条件が成り立つ。連結とは任意の二対象を向きを問わない有限本の射の列でつなげることである。双対では $(u\downarrow j)$ に同じ条件を課せば極限を比較できる。
:::

:::proof
$Du$ から $X$ への余錐 $\lambda_i$ が与えられたとする。$j$ ごとに $(i,f:j\to ui)$ を選び、$\lambda_j$ を $\lambda_iD(f)$ と置く。コンマ圏の射 $(i,f)\to(i',f')$ では $u(a)f=f'$ かつ $\lambda_{i'}D(u(a))=\lambda_i$ なので値は一致する。連結性により選択に依らない。$j\to k$ に対しては $k\to ui$ を前合成すれば同じ計算で余錐条件が出る。$j=ui$ で $f=\id$ を使えば元の余錐へ戻る。逆に $D$ の余錐から制限した場合、延長の値は元の余錐条件で決まる。従って余錐の集合が頂点に自然に同型であり、余極限を同じ対象で表せる。

逆向きには $j$ を固定して $D(k)=\Hom_J(j,k)$ とする。この図式の余極限は、$j$ が始域である各射が $1_j$ と同じ類になるので一点である。$Du$ の非交和の元は $(i,f:j\to ui)$ であり、余極限の関係はコンマ圏 $(j\downarrow u)$ の射で生成される。その商が一点であることは、コンマ圏に対象があり、どの二対象も向きを問わず射で結ばれることに等しい。双対の条件と結論は矢印を逆にして従う。
:::

例えば $j=3$ なら偶数段階の候補は $4,6,8,\ldots$ であり、最小の $4$ を通して比較できる。一般の有向集合でも、共終な部分集合で二つの候補をさらにその部分集合の共通上界に移せれば、同じ定理が使える。非空性だけでは候補間の比較ができない。二対象離散圏から終圏への関手を取り、終圏の一点定値図式を制限すると、余極限が一点から二点に変わる。

### 極限の可換条件と添字の縮小
図式を紙に書くと、見えている矢印に加えて合成した矢印も含まれている。生成矢印に沿う条件が成り立てば、合成矢印に対する等式も従う。これを使うと、小さい図式の極限を実際の未知数と方程式に直せる。

:::proposition[始対象と終対象を持つ添字圏]
$J$ に始対象 $i$ があれば、任意の $D:J\to\mathcal C$ の極限は $D(i)$ である。$J$ に終対象 $t$ があれば余極限は $D(t)$ である。
:::

:::proof
$D(i)\to D(j)$ を $i\to j$ の像で定める。$j\to k$ と合成した射も唯一の $i\to k$ なので錐となる。任意の錐 $(u_j:T\to D(j))$ は $i$ の成分 $u_i$ から各 $u_j=D(i\to j)u_i$ を復元できる。従って極限であり、逆圏で同じ証明を使えば余極限も従う。
:::

:::example[平行二射を一方だけ残した場合]
$D(0)=\{a,b\}$、$D(1)=\{0,1\}$ とし、平行な $f,g:0\rightrightarrows1$ を $f(a)=g(a)=0$、$f(b)=1$、$g(b)=0$ とする。極限の組 $(x,y)$ は $y=f(x)=g(x)$ を満たすので $(a,0)$ 一つである。$f$ だけなら $(b,1)$ も加わる。従って、対象を両方含むだけでは極限を計算するのに十分な添字部分圏とは限らない。
:::

:::example[可算鎖の逆極限の桁表示]
$D(n)=\Z/2^n$ を剰余写像でつなぐ。整合列の各 $x_n$ を $0\le x_n<2^n$ で代表させると、$x_{n+1}=x_n+\eps_n2^n$、$\eps_n\in\{0,1\}$ である。この漸化式で全ての整合列が得られる。例えば $\eps_n=1$ を全て選ぶと各剰余は $-1$ になり、$\eps_0=1,\eps_{n>0}=0$ とすれば $1$ の剰余になる。積の全列から整合列を選ぶ条件は異なる桁同士を結ぶ。
:::

### 具体例での計算

以下では候補を具体的に作ってから、比較射が存在する条件と、その一意性を順に確認する。

:::example[共通値のファイバー]
二つの集合 $A,B$ の元に $0$ から順に番号を付ける。写像 $f:A\to C$ と $g:B\to C$ の値を順に

$$
f=(0,1,2,2,3),\qquad g=(0,0,1,3,3)
$$

とする。値域 $C$ は表に現れる値全体とする。条件 $f(i)=g(j)$ を満たす対を求めるとき、共通の値でいったん分類すると数え落としを防げる。

| 共通値 $c$ | 左の添字 $i$ | 右の添字 $j$ | 組数 |
| --- | --- | --- | --- |
| 0 | 0 | 0, 1 | $1\cdot2=2$ |
| 1 | 1 | 2 | $1\cdot1=1$ |
| 2 | 2, 3 | 空 | $2\cdot0=0$ |
| 3 | 4 | 3, 4 | $1\cdot2=2$ |

共通値を固定すれば左右を独立に選べる。異なる行に同じ対が現れることはない。従って最後の列を合計して $5$ 組を得る。実際、適合する対の集合は次のとおりである。

$$
\{(0,0),(0,1),(1,2),(4,3),(4,4)\}
$$

この集合から $A$ と $B$ への射影を取り、さらに $f,g$ を合成すると一致する。試験集合 $T$ から $u:T\to A$、$v:T\to B$ を選んで $fu=gv$ が成り立つなら、各 $t$ で $(u(t),v(t))$ は表の同じ行から選ばれた対である。従って $t\mapsto(u(t),v(t))$ が求める因子である。射影を指定した以上、その値を別の対に換えることはできない。この確認により、対の濃度だけでなく、その集合がどの射に対して普遍的かも決まる。

表から第一射影の像を読むには、右側に候補がある行だけを残して左側の添字を集めればよい。実際、そこにある添字だけが第二成分を補える。従って $g$ が全射なら第一射影も全射である。さらに $g$ が単射なら、補う第二成分は高々一つなので第一射影も単射である。$f$ と $g$ の役を交換すると第二射影についても同じ判定ができる。
:::

:::example[像と核の照合]
係数体を $\Q$ とし、三つのベクトル空間を次の行列でつなぐ。

$$
\Q^{2}\xrightarrow{B}\Q^{4}\xrightarrow{A}\Q^{2},\quad B=\begin{pmatrix}1 & 2\\-1 & -2\\1 & 2\\-1 & -2\end{pmatrix},\quad A=\begin{pmatrix}1 & 0 & 0 & 1\\0 & 1 & 1 & 0\end{pmatrix}
$$

中間の空間で、前から到達するベクトルと後ろに移すと消えるベクトルの関係を求める。それには第一の写像の像、第二の写像の核、そして合成の三つを同じ座標で計算する。

合成の第 $j$ 列は $B$ の第 $j$ 列に $A$ を掛けたものである。従って計算は次のようになる。

$$
AB=\begin{pmatrix}0 & 0\\0 & 0\end{pmatrix}
$$

$A$ を基本行変形すると既約行階段形は

$$
\begin{pmatrix}1 & 0 & 0 & 1\\0 & 1 & 1 & 0\end{pmatrix}
$$

である。非零行の数は $2$ であり、自由な変数を一つずつ $1$ にして他を $0$ にした解が核の基底を与える。得られる核の基底は $\{\begin{pmatrix}0\\-1\\1\\0\end{pmatrix},\ \begin{pmatrix}-1\\0\\0\\1\end{pmatrix}\}$ である。一方、$B$ の列を左から見て、先の列の線形結合にならない列を残す。こうして得る像の基底は $\{\begin{pmatrix}1\\-1\\1\\-1\end{pmatrix}\}$ である。

この積は零なので $\Img B\subseteq\Ker A$ が成立する。像の基底に、核の基底を左から順に追加する。ただし既存のベクトルで張られるものは除く。得た追加分の剰余類は商の基底である。実際、元の像の基底と合わせて核を張り、追加分から零の類を作る関係式があれば全体の基底に線形関係ができる。この例で残る代表の集合は $\{\begin{pmatrix}0\\-1\\1\\0\end{pmatrix}\}$ であり、次元は $\dim\Ker A-\rank B=2-1=1$ である。

中間の座標を可逆行列 $S$ で換えると $A,B$ は $AS^{-1},SB$ に変わる。従って積は $AB$ のままである。核と像は両方とも $S$ で運ばれるので、同じ関係が新しい座標でも得られる。基本行変形で得た方程式を読んだ後に代表を使う場合は、行変形した $A$ の核の解を取り、$B$ については元の列に戻す必要がある。
:::

### 図式を比較する射が極限に誘導する射

各図式 $D:J\to\mathcal C$ に極限を一つずつ選べるとする。自然変換 $\alpha:D\to E$ に対し、極限射影 $p_j^D$ と $\alpha_j$ の合成は $E$ への錐になる。従って $\lim\alpha:\lim D\to\lim E$ が一意に定まり、$p_j^E\lim\alpha=\alpha_j p_j^D$ を満たす。恒等射や二つの自然変換の合成を考えると、各射影で同じ式が従うので $\lim$ は関手になる。同じ構成を余錐の向きで行うと $\operatorname{colim}$ も関手になる。このとき

$$
\Hom(\operatorname{colim}D,X)\cong\operatorname{Nat}(D,\Delta X),\qquad
\Hom(X,\lim D)\cong\operatorname{Nat}(\Delta X,D)
$$

は $X$ と $D$ の両方に自然である。$D$ の変換に対する自然性は、比較射を構造射との合成で定めた式にほかならない。

:::example[逆極限の環構造]
$\Z/2^n$ を剰余写像でつないだ図式の整合列では、和・積・単位を各段階で取れる。例えば $-1$ に対応する列 $(2^n-1)_n$ と $1$ に対応する列を足すと各段階で零になり、整合列でも零になる。任意の環からこの図式への錐の比較写像は、全射影の下で環準同型なので自身も環準同型である。こうして集合の逆極限に環構造を入れるだけで環の逆極限を得る。
:::

:::example[段階ごとに位数を増やす群の余極限]
素数 $p$ について $\Z/p^n\to\Z/p^{n+1}$ を $[a]\mapsto[pa]$ とする。各段階を $\Q/\Z$ に $[a]\mapsto a/p^n+\Z$ で埋め込むと、二つの連続する埋め込みはこの構造射と両立する。像の和集合は $p$ の冪で殺される元の群である。任意の余錐に対し各元を表示できる段階で像を定め、二つの段階で表示できれば大きい段階で一致することを使うと、一意な群準同型を得る。例えば $p=2$ の最初の三段階の生成元は $1/2,1/4,1/8$ の類で、これらの位数は $2,4,8$ である。
:::

## 積とイコライザによる極限の構成

:::theorem[積とイコライザによる極限]{#thm-cat-limit-by-equalizer}
小さい積とイコライザがある圏には小さい極限がある。有限の場合、有限積とイコライザで有限極限を構成できる。
:::

:::proof
$P=\prod_i D(i)$ と $Q=\prod_{a:i\to j}D(j)$ を作る。$s,t:P\to Q$ の $a$ 成分をそれぞれ $D(a)p_i,p_j$ とし、$e:L\to P$ を両者のイコライザとする。積 $Q$ への射の等しさは成分で判定できるから、$p_i e$ は錐である。任意の錐はまず唯一の $X\to P$ を定め、その合成が $s,t$ で一致するため一意に $L$ を通る。添字が有限なら必要な積は有限である。
:::

双対化すると、余積とコイコライザから小さい余極限を作れる。例えば $X\to Z\leftarrow Y$ の極限では、$X\times Y\times Z$ の中で $z=f(x)$ と $z=g(y)$ を課す。$z$ が $(x,y)$ から定まるため、先に作った引き戻しと同型である。積の中の条件を一つ余分に書いても、普遍性が同じなら構成結果は一意の同型でつながる。

### 積から作る二本の比較写像
図式の全対象を積に並べた時点では、射の条件はまだ課されていない。射の添字で第二の積を作ると、各条件の両辺を二本の射に束ねられる。ここではある条件が他から従う場合も、束ね方の計算は同じである。

:::example[点の成分を三つに取る]
$A=\{0,1,2\}$ と $B=\{0,1\}$ の間の写像を $f(x)=x\bmod2$ とし、$C=\{0,1,2,3\}$ から $B$ へ $g(z)=z\bmod2$ とする。対象の積 $A\times B\times C$ から $B^2$ への二射を $(x,y,z)\mapsto(f(x),g(z))$ と $(x,y,z)\mapsto(y,y)$ とすると、等化子の元は $f(x)=y=g(z)$ の三つ組である。偶数側から $2\cdot2=4$、奇数側から $1\cdot2=2$ が残り、計六点である。$y$ を忘れる射は $A\times_B C$ に全単射であり、逆は共通の値を $y$ に戻す。
:::

:::example[二段階の商を一度に取る]
加群の図式 $\Z\leftarrow\Z\to\Z$ の左右の射を $2,3$ とする。全対象の直和に中央の基底 $e_0$、左の基底 $e_1$、右の基底 $e_2$ を置く。射の添字ごとの関係は $e_0-2e_1$ と $e_0-3e_2$ である。最初の関係で $e_0$ を消去すると、第二は $2e_1-3e_2$ となる。$(2,-3),(1,-1)$ は行列式 $1$ の基底なので、残る商は $\Z$ であり、例えば $(u,v)\mapsto3u+2v$ がその表示となる。商からの射のデータは二つの関係を消すことと同値で、これが余錐の条件である。
:::

### 具体例での計算

以下では候補を具体的に作ってから、比較射が存在する条件と、その一意性を順に確認する。

:::example[像と核の照合]
係数体を $\Q$ とし、三つのベクトル空間を次の行列でつなぐ。

$$
\Q^{2}\xrightarrow{B}\Q^{3}\xrightarrow{A}\Q^{2},\quad B=\begin{pmatrix}2 & 3\\1 & 0\\0 & 1\end{pmatrix},\quad A=\begin{pmatrix}0 & 0 & 0\\0 & 0 & 0\end{pmatrix}
$$

中間の空間で、前から到達するベクトルと後ろに移すと消えるベクトルの関係を求める。それには第一の写像の像、第二の写像の核、そして合成の三つを同じ座標で計算する。

合成の第 $j$ 列は $B$ の第 $j$ 列に $A$ を掛けたものである。従って計算は次のようになる。

$$
AB=\begin{pmatrix}0 & 0\\0 & 0\end{pmatrix}
$$

$A$ を基本行変形すると既約行階段形は

$$
\begin{pmatrix}0 & 0 & 0\\0 & 0 & 0\end{pmatrix}
$$

である。非零行の数は $0$ であり、自由な変数を一つずつ $1$ にして他を $0$ にした解が核の基底を与える。得られる核の基底は $\{\begin{pmatrix}1\\0\\0\end{pmatrix},\ \begin{pmatrix}0\\1\\0\end{pmatrix},\ \begin{pmatrix}0\\0\\1\end{pmatrix}\}$ である。一方、$B$ の列を左から見て、先の列の線形結合にならない列を残す。こうして得る像の基底は $\{\begin{pmatrix}2\\1\\0\end{pmatrix},\ \begin{pmatrix}3\\0\\1\end{pmatrix}\}$ である。

この積は零なので $\Img B\subseteq\Ker A$ が成立する。像の基底に、核の基底を左から順に追加する。ただし既存のベクトルで張られるものは除く。得た追加分の剰余類は商の基底である。実際、元の像の基底と合わせて核を張り、追加分から零の類を作る関係式があれば全体の基底に線形関係ができる。この例で残る代表の集合は $\{\begin{pmatrix}1\\0\\0\end{pmatrix}\}$ であり、次元は $\dim\Ker A-\rank B=3-2=1$ である。

中間の座標を可逆行列 $S$ で換えると $A,B$ は $AS^{-1},SB$ に変わる。従って積は $AB$ のままである。核と像は両方とも $S$ で運ばれるので、同じ関係が新しい座標でも得られる。基本行変形で得た方程式を読んだ後に代表を使う場合は、行変形した $A$ の核の解を取り、$B$ については元の列に戻す必要がある。
:::

:::example[整数の関係行列]
整数行列を一つ指定し、自由 Abel 群の写像の核と商を同時に調べる。標準基底の順に列を読むものとする。

$$
A=\begin{pmatrix}2 & 6 & 4\\4 & 12 & 8\end{pmatrix}:\Z^{3}\to\Z^{2}
$$

有理数上の階数は $1$ である。余核の捩れを求めるには整数上の計算が必要である。整数上で行と列の基本操作を行い、対角上の正の成分が順に整除する表示を使う。許す基本操作は交換、符号の反転、一列または一行の整数倍を別の列または行に加える操作であり、どの操作にも整数係数の逆操作がある。従って座標変換として核と余核を保つ。

サイズ $k$ の小行列式が生成するイデアルは座標変換で変わらない。実際、行の加法操作をした小行列式を選ぶと、多重線形性で元の小行列式の整数線形結合になる。交換と符号反転でも同様であり、逆操作も使えば逆の包含を得る。列操作にも同じ議論を適用できる。対角形では整除関係から、非零なサイズ $k$ の小行列式の最大公約数 $\Delta_k$ は先頭の $k$ 個の対角成分の積である。従って $\Delta_0=1$ とすれば、対角成分は $\Delta_k/\Delta_{k-1}$ になる。

この行列で小行列式を計算すると次のようになる。重複する絶対値は省いた。階数を越えるサイズのものは全て零である。

| サイズ | 小行列式の絶対値 | $\Delta_k$ | 対角成分 |
| --- | --- | --- | --- |
| 1 | 2,4,6,8,12 | 2 | 2 |

従って非零対角成分の一覧は $(2)$ になる。商の各対角座標はその成分による剰余になるので、有限巡回因子は $(2)$ を位数に持つもの、自由階数は $1$ である。成分が $1$ なら対応する巡回因子は零である。一方、核は対角成分のある入力座標を零にしたものだから自由階数 $2$ となる。これで有理数上の階数に加え、整数で残る捩れも計算できた。
:::

### 関手圏の極限と余極限

:::proposition[各点での極限と余極限]{#prop-cat-functor-pointwise-limits}
$D:J\to[\mathcal C,\mathcal E]$ を図式とする。各 $c$ で $L(c)=\lim_{j\in J}D(j)(c)$ が存在すれば、この対象族に関手構造が入り、$D$ の極限を与える。各点の余極限についても双対の主張が成り立つ。
:::

:::proof
$p^c_j:L(c)\to D(j)(c)$ を極限射影とする。$h:c\to c'$ に対し $D(j)(h)p^c_j$ は $c'$ での図式の錐である。実際 $D(a):D(i)\to D(j)$ の自然性により

$$
D(a)_{c'}D(i)(h)p_i^c=D(j)(h)D(a)_c p_i^c=D(j)(h)p_j^c
$$

となる。従って $L(h)$ が一意に定まる。恒等射と合成を保つことはすべての $p^{c'}_j$ あるいは $p^{c''}_j$ との後合成で確認できる。$L(h)$ の定義により各 $p_j$ は自然変換になる。$H$ から $D$ への錐を各 $c$ で比較して $k_c:H(c)\to L(c)$ を得る。$L(h)k_c$ と $k_{c'}H(h)$ は射影後に一致するので $k$ も自然であり、その一意性も各点の極限で従う。余極限の証明は全射を逆に向けて得る。
:::

:::example[自然変換の等化条件は構造写像で保たれる]
二つの自然変換 $\alpha,\beta:F\to G$ のイコライザを集合値関手で作ると、$E(c)=\{x\in F(c):\alpha_c(x)=\beta_c(x)\}$ になる。$h:c\to d$ に沿って $x$ を $F(h)x$ に移すと、$\alpha_d F(h)x=G(h)\alpha_c(x)=G(h)\beta_c(x)=\beta_d F(h)x$ である。従って $E$ の値が部分集合として与えられただけでも、射の作用は指定した性質から一意に定まる。
:::

### 極限どうしと余極限どうしの交換

$D:I\times J\to\mathcal C$ に対し、両段階の極限が取れる場合、$\lim_i\lim_jD(i,j)$ は積圏 $I\times J$ 上の極限である。試験対象 $X$ からの射は $D(i,j)$ への射の族で、$I$ と $J$ の各方向に可換条件を満たすものに等しい。積圏の任意の射 $(a,b)$ は $(a,1)$ と $(1,b)$ の合成であるため、その二方向の条件から全射に沿う条件が従う。逆に積圏の錐は各方向の条件を満たし、各方向で順に極限へ因子化する。従って逆順の極限も存在すれば両者は錐を保つ一意な同型で結ばれる。双対的に余極限どうしも交換する。

この証明を積とイコライザに適用すると、積の添字と等化条件を先にまとめるか、各図式で等化してから積を取るかを選べる。余極限と極限を混ぜた場合は同じ論法を適用できない。余錐は射の向きが逆であり、一つの試験対象から全成分への射で両方の普遍性を同時に表せないからである。

### 小さい圏の完備性と大きさ

:::proposition[小圏の積と前順序]{#prop-cat-small-complete-preorder}
小圏 $\mathcal C$ がすべての小さい積をもつなら、$\mathcal C$ の各 Hom は高々一点である。
:::

:::proof
圏のすべての射を集めた集合を $S$ とする。$X\to Y$ に異なる二射 $f,g$ があれば、$S$ 個の $Y$ の積を取り、各 $s\in S$ で $f,g$ のいずれかを射影として指定できる。指定が異なれば積への射も異なる。従って $X\to\prod_{s\in S}Y$ の集合には $\mathcal P(S)$ が単射で入る。しかしこの Hom は $S$ に含まれ、Cantor の定理に反する。よって各 Hom は高々一点である。
:::

集合の圏はすべての小さい積をもつが、この命題の小圏ではない。全射の集合を同じ宇宙の中で添字集合にするという箇所が、小圏と局所小圏を区別している。

## フィルター余極限と有限極限の交換

フィルター余極限では有限個の段階や等式を一段階へまとめられる。有限条件をまとめられない添字では交換は成立しないことがある。例えば二対象の離散圏による余極限は余積であり、一点定値図式を二点集合に送るため、空図式の極限である終対象を保たない。これが積の座標数や図式中の制約数が有限のときに効く。

:::definition[フィルター圏]{#def-cat-filtered}
小圏 $I$ が :term[フィルター圏]{en="filtered category" yomi="ふぃるたーけん"} であるとは、非空で、任意の二対象に共通の行き先があり、任意の平行射 $u,v$ をある後合成で等しくできることをいう。
:::

:::lemma[集合のフィルター余極限での等号]{#lem-cat-filtered-equality}
$x\in D(i)$ と $y\in D(j)$ が余極限で等しいことと、ある $i\to k\gets j$ により像が等しくなることは同値である。
:::

:::proof
共通段階での等式は余極限の関係から従う。逆に共通段階で一致するという関係は反射的、対称的である。推移性では、$x,y$ の共通段階と $y,z$ の共通段階に共通の行き先を取る。この時点で $y$ からの平行射が二本あるので、さらに後合成で等しくすると $x,z$ も一致する。従ってこの同値関係は余極限を定義する各対を含み、余極限で等しいならこの関係に入る。
:::

:::theorem[有限極限との交換]{#thm-cat-filtered-finite-limits}
$I$ をフィルター小圏、$J$ を対象と射が有限個の圏、$D:I\times J\to\mathbf{Set}$ を関手とする。このとき自然な比較

$$
\operatorname{colim}_{i\in I}\lim_{j\in J}D(i,j)
\longrightarrow
\lim_{j\in J}\operatorname{colim}_{i\in I}D(i,j)
$$

は全単射である。
:::

:::proof
空図式の極限である一点集合は、段階が非空で任意の二段階が共通の行き先をもつため、余極限でも一点集合になる。有限積については、各成分の代表を有限個選び共通段階に運べば比較写像が全射になる。二つの組の像が等しいなら、成分ごとの証人を上の補題で選ぶ。それらを一段階に集め、元の二段階からの有限本の平行射を順に後合成で揃えると、全成分が同時に一致し、単射性が従う。

イコライザについて、余極限で $f(x)=g(x)$ なら、像が一致する段階を補題で選び、$x$ の段階からの平行射を揃える。そこで $x$ の像は等化条件を満たすので全射である。単射性は代表を一致させる共通段階で等化条件も保たれることから従う。:ref[thm-cat-limit-by-equalizer] により任意の有限極限に適用できる。
:::

集合の圏で有限性を外すと、$D_n=\{0,\ldots,n\}$ の包含列の可算積を考えられる。$\N^\N$ の点 $(0,1,2,\ldots)$ は個々の座標には段階があるが、全座標を含む一段階がない。従って比較は全射にならない。

### フィルター性の有限性を使う
余極限の元は一つの段階の元で代表できる。二つの代表を比べるときは将来の同じ段階に移せばよい。さらに有限個の条件なら、その等号が成立する段階をまとめて選べる。

:::example[有理数を作る有向系]
$\Z$ の列で $n$ から $n+1$ への射を $n+1$ 倍とする。ただし段階 $n\ge0$ の $\Z$ を $a\mapsto a/n!$ で $\Q$ に入れる。これらの包含の像の和集合は $\Q$ である。任意の正分母 $q$ は $q!$ を割るため、分数は段階 $q$ に現れる。二つの分数が等しい場合は大きい方の段階で整数の等号になり、余極限で同じ元になる。局所化がテンソルの計算で有用なのは、有限個の分母を共通にできるからである。
:::

:::example[無限積とは交換しない]
$X_i=\{0,\ldots,i\}$ を包含でつないだとき $\operatorname{colim} X_i=\N$ である。自然写像 $\operatorname{colim}_i X_i^{\N}\to(\operatorname{colim}_i X_i)^{\N}$ の像は有界な自然数列である。左辺の元は一つの有限な $i$ で全座標を指定し、逆に有界列はその上界の段階に属するからである。列 $(0,1,2,\ldots)$ は右辺に属するが左から来ない。有限個の成分だけなら最大値を取って段階を合わせられるので、この失敗は成分が無限個であることに対応する。
:::

### 具体例での計算

以下では候補を具体的に作ってから、比較射が存在する条件と、その一意性を順に確認する。

:::example[順序での最小候補]
二つの順序圏を $A=\{0,\ldots,6\}$、$B=\{0,\ldots,4\}$ とする。$R:B\to A$ を値の一覧 $R=(0,2,3,3,5)$ で定める。値は減少しないので、$y\le z$ なら $R(y)\le R(z)$ である。この関手を通して $x\in A$ から写せる $B$ の対象を調べる。

| $x$ | 条件 $x\le R(y)$ を満たす $y$ | 最小候補 |
| --- | --- | --- |
| 0 | 0, 1, 2, 3, 4 | 0 |
| 1 | 1, 2, 3, 4 | 1 |
| 2 | 1, 2, 3, 4 | 1 |
| 3 | 2, 3, 4 | 2 |
| 4 | 4 | 4 |
| 5 | 4 | 4 |
| 6 | 空 | なし |

候補があれば、最小候補はその行の全ての候補以下にある。前順序を圏として読むと、候補を互いに比較する射は、不等式が成立する場合に一つだけ存在する。空の行には最小候補が存在しない。 $x\to R(y)$ を対象とするコンマ圏では、最小候補は始対象である。実際 $y_0\le y$ で比較射が存在し、前順序の条件により比較の三角形は可換となる。各行の計算はこの始対象を直接求めている。
:::

### 加群の余極限と有限表示

集合のフィルター余極限には台加群の構造を入れられる。$[i,x]+[j,y]$ は、$i,j$ の行き先 $k$ で二元の像を足し、その類を取る。二つの代表や行き先の選び方を比較するときは、:ref[lem-cat-filtered-equality] で得た等号と選んだ有限本の射を一段階にまとめる。その段階では両成分が同じ元になるため、和の類は選択に依らない。スカラー倍は $[i,x]\mapsto[i,rx]$ と定め、有限個の元を共通段階に移せば加群の各公理が従う。台の余極限から余錐への因子は、和を同じ段階で計算するため線形である。従って集合上の構成は加群の余極限を与える。加群の有限極限も、直積に等化条件を課すと成分ごとの演算で閉じるため、集合での有限極限に加群構造を入れて作れる。比較写像は線形であり :ref[thm-cat-filtered-finite-limits] によって台写像が全単射なので、加群においても交換が成り立つ。

:::proposition[有限表示加群からの射]{#prop-cat-finitely-presented-filtered}
左 $R$ 加群 $M$ が有限表示をもつとき、小さいフィルター図式 $N:I\to R\text{-}\mathbf{Mod}$ に対する比較

$$
\operatorname{colim}_{i\in I}\Hom_R(M,N_i)
\longrightarrow \Hom_R(M,\operatorname{colim}_{i\in I}N_i)
$$

は全単射である。
:::

:::proof
有限表示 $R^p\xrightarrow{d}R^q\to M\to0$ を選ぶ。$M\to P$ は $R^q\to P$ のうち $d$ との合成が零になるものなので、自然に $P^q\rightrightarrows P^p$ のイコライザである。比較する二射は $d$ による前合成と零写像である。$p,q$ は有限なので、:ref[thm-cat-filtered-finite-limits] でイコライザと二つの積を余極限の外へ移せる。その同型は各段階で $M$ からの射を構造射と合成する写像によって誘導されるので、表示された比較に等しい。
:::

:::example[有限生成の仮定を外した場合]
$N_i=\bigoplus_{k=0}^i\Z$ を包含でつなぐと、余極限は $N=\bigoplus_{k\ge0}\Z$ である。$M=N$ とすると $\id_N$ の像は全体にわたり、一つの $N_i$ を経由しない。そのため比較は全射にならない。有限表示の場合には生成元の像を共通段階に運び、さらに有限個の関係式が成立する段階まで運ぶから、この障害が起こらない。
:::

## 演習問題

::::exercise{level=basic #exr-cat-universal-properties-1}
一点集合が集合の終対象であることを示せ。

:::solution
どの集合からも全ての点を唯一の値に送る写像がある。その値以外を取れないので写像は一意である。空集合からの空写像も一意である。
:::
::::

::::exercise{level=basic #exr-cat-universal-properties-2}
二点集合と四点集合の積・余積の点数を求めよ。

:::solution
積の点は二つの選択を独立に行うため $2\cdot4=8$ 点である。余積は添字が異なるので全て別の点となり $2+4=6$ 点である。
:::
::::

::::exercise{level=basic #exr-cat-universal-properties-3}
集合の圏で、整数上の写像 $f(x)=2x$、$g(x)=x+3$ のイコライザを求めよ。

:::solution
方程式 $2x=x+3$ は $x=3$ と同値である。任意の等化写像は値が $3$ だけなので、イコライザは包含 $\{3\}\hookrightarrow\Z$ である。
:::
::::

::::exercise{level=basic #exr-cat-universal-properties-4}
加群の引き戻し $\Z\xrightarrow{2}\Z\xleftarrow{3}\Z$ を求めよ。

:::solution
$2,3$ は掛け算による加群準同型である。引き戻しには $2x=3y$ を満たす $(x,y)$ が必要である。$3$ が $2x$ を割るので $x=3t$ と書け、$y=2t$ が従う。従って $\Z$ からの射影はそれぞれ $3,2$ 倍である。
:::
::::

::::exercise{level=advanced #exr-cat-universal-properties-5}
$P=X\times_Z Y$ を $f:X\to Z$ と $g:Y\to Z$ の引き戻しとする。$f$ がモノ射なら射影 $p_Y:P\to Y$ がモノ射であることを示せ。

:::solution
$f:X\to Z$ が左消去可能とし $p_Ya=p_Yb$ とする。可換性より $fp_Xa=gp_Ya=gp_Yb=fp_Xb$ なので $p_Xa=p_Xb$ である。両射影が一致するため引き戻しの一意性で $a=b$ となる。
:::
::::

::::exercise{level=advanced #exr-cat-universal-properties-6}
全順序 $0<1<2$ の圏で $1$ と $2$ の積・余積を求めよ。

:::solution
積は共通下界の最大、余積は共通上界の最小である。$1$ は両方以下で、共通下界は全て $1$ 以下なので積は $1$ である。同じ議論を逆向きにして余積は $2$ である。
:::
::::

::::exercise{level=advanced #exr-cat-universal-properties-7}
$\Z\xleftarrow{2}\Z\xrightarrow{3}\Z$ の加群としての押し出しを求めよ。

:::solution
商は $\Z^2/\langle(2,-3)\rangle$ である。写像 $(x,y)\mapsto3x+2y$ は $(1,-1)$ に $1$ を与えるので全射であり、核は $(x,y)=(2t,-3t)$ である。従って押し出しは $\Z$、二つの構造射は $3,2$ 倍である。
:::
::::

::::exercise{level=advanced #exr-cat-universal-properties-8}
フィルター圏が任意の有限図式に余錐を与えることを示せ。

:::solution
有限個の対象を共通の行き先に移す。各図式射について、現在の行き先への直接の射と図式射を経由する射を後合成で揃える。有限回行えば済み、一度得た等式は後合成で保たれる。空図式には非空性を使う。
:::
::::

::::exercise{level=advanced #exr-cat-universal-properties-9}
$F_n=\Z^n$ を末尾に零を加える線形写像でつなぐ。各段階の線形写像 $g_n:F_n\to F_n$ を二倍写像とする。余極限上の $g=\operatorname{colim}_n g_n$ を求め、余極限と $\Ker$ の交換をこの例で確認せよ。

:::solution
余極限は有限台整数列の加群である。各元はある段階の有限列から来て、$g_n$ は全座標を二倍するため、$g$ も全座標を二倍する。各 $F_n$ は捩れがないので各 $\Ker g_n=0$ であり、その余極限も零である。余極限の有限台整数列にも非零の二捩れはないので $\Ker g=0$ である。比較写像は零加群間の同型となる。
:::
::::
