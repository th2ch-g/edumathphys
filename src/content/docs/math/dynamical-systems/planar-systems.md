## この章の目標

- 行列の跡、行列式、Jordan 形から線形系の軌道を分類する。
- 線形化または Lyapunov 関数によって非線形平衡点の安定性を判定する。
- 平面の横断面の順序を使って Poincaré–Bendixson の定理を証明する。
- Liénard 方程式、指数、Bendixson–Dulac の判定を周期軌道の問題に使う。

## 線形系の相図の分類

$\dot z=Az$ を考える。:ref[thm-linalg-matrix-exp] により解は $z(t)=e^{tA}z(0)$ である。実基底をとり直すと $A$ は相似な行列に置き換わる。したがって各 Jordan 形について解を明示すれば、相図の分類が得られる。相図とは、軌道の集合を時間の向きとともに描いたものである。

$\tau=\tr A$、$\Delta=\det A$ と置くと特性多項式は $\lambda^2-\tau\lambda+\Delta$ である。よって $\Delta<0$ では異符号の実固有値があり、$\Delta>0$ では判別式 $D=\tau^2-4\Delta$ が実根か非実根かを決める。

:::proposition[平面線形系の相図]{#prop-dyn-plane-linear-types}
実 $2\times2$ 行列 $A$ に対して次の分類が成り立つ。

| 条件 | 軌道の型 |
| --- | --- |
| $\Delta<0$ | 鞍点 |
| $\Delta>0,\ D\ge0,\ \tau<0$ | 吸引節点 |
| $\Delta>0,\ D\ge0,\ \tau>0$ | 反発節点 |
| $\Delta>0,\ D<0,\ \tau<0$ | 吸引焦点 |
| $\Delta>0,\ D<0,\ \tau>0$ | 反発焦点 |
| $\Delta>0,\ \tau=0$ | 中心 |
| $\Delta=0,\ \tau\ne0$ | 平衡点の直線と、そこから伸びる半直線の軌道 |
| $\Delta=\tau=0,\ A\ne0$ | 平衡点の直線と、それに平行な直線軌道 |
| $A=0$ | 全平面が平衡点 |
:::

:::proof
異なる実固有値に対して固有基底を取ると、解は $(c_1e^{\lambda_1t},c_2e^{\lambda_2t})$ である。符号が異なれば一方の固有軸上の軌道だけが正方向に原点へ行き、他方の固有軸が負方向に原点へ行く。符号が一致すれば全点が同じ時間方向で原点へ収束する。固有値が重なれば $A=\lambda I$ か、一つの Jordan ブロックをもつ。後者では解は $e^{\lambda t}(c_1+c_2t,c_2)$ である。$\lambda\ne0$ なら指数因子が収束の方向を決め、前者では軌道は半直線、後者では非固有方向からの軌道は原点近くで固有直線に接する。

共役な非実固有値 $a\pm ib$ については、実基底で $\dot x=ax-by$、$\dot y=bx+ay$ と書ける。これは $r(t)=r(0)e^{at}$、$\theta(t)=\theta(0)+bt$ を与えるので、$a$ の符号で吸引と反発、$a=0$ で閉曲線になる。

$\Delta=0$ で $\tau\ne0$ なら固有基底で $(x(t),y(t))=(x_0,e^{\tau t}y_0)$ となる。$\Delta=\tau=0$ なら $A^2=0$ なので $e^{tA}=I+tA$ である。$A\ne0$ の場合は $\Img A=\Ker A$ が直線となり、平衡点以外はその方向に平行移動する。$A=0$ では定数解だけである。
:::

:::example[鞍点の軌道の式]
$A=\diag(-2,1)$ では $x(t)=x_0e^{-2t}$、$y(t)=y_0e^t$ である。したがって積 $xy^2$ は一定で、$(2,3)$ からの軌道は $xy^2=18$ の第一象限の枝にある。軸上はこれとは別に調べる。$y=0$ の軸は吸引方向、$x=0$ の軸は反発方向である。
:::

:::example[重根をもつ節点]
$A=\left(\begin{smallmatrix}-1&1\\0&-1\end{smallmatrix}\right)$ に対し $(x_0,y_0)=(0,2)$ からの解は $(2te^{-t},2e^{-t})$ である。原点へ近づくとき $y/x=1/t\to0$ となる。これに対し $A=-I$ の解は初期値の方向を保つ。この二つはともに吸引節点だが、固有方向の数は異なる。
:::

:::example[座標で変わる向き]
$A=\left(\begin{smallmatrix}-2&-3\\3&-2\end{smallmatrix}\right)$ では $r(2\pi/3)=e^{-4\pi/3}r(0)$ である。$\tau=-4$、$\Delta=13$ から吸引焦点と判定できるが、回転の向きは跡と行列式に記録されない。例えば座標 $y$ の符号を逆にすれば回転の向きも逆になる。
:::

### 軌道の形を座標式で調べる

異なる実固有値 $\lambda_1,\lambda_2$ の固有基底で $x$ と $y$ がともに零でない軌道を考える。$|x(t)|/|x_0|=e^{\lambda_1t}$、$|y(t)|/|y_0|=e^{\lambda_2t}$ だから、$\lambda_1\ne0$ のとき

$$
|y|=|y_0|\left(\frac{|x|}{|x_0|}\right)^{\lambda_2/\lambda_1}
$$

を得る。どちらの成分も符号を保つので、この式の一つの象限の枝が軌道となる。指数が正なら両座標が同方向に増減し、指数が負なら一方の増加と他方の減少が組み合わさる。固有値比が変わると、同じ型の中でも軌道の曲率は変わる。

:::example[固有値比による接線方向]
$\dot x=-x$、$\dot y=-4y$ の $(2,3)$ からの軌道は $y=3(x/2)^4$（$x>0$）であり、原点近くで $x$ 軸に接する。$x=0$ の軸上の軌道だけは $y$ 軸のままである。固有値の実部が負であっても、一般の軌道の接線を知るには、遅く減る成分が初期値に含まれるかを確認する。
:::

Jordan ブロック $\dot x=\lambda x+y$、$\dot y=\lambda y$ で $y_0\ne0$、$\lambda\ne0$ なら、比 $x/y$ の時間微分は $1$ である。従って

$$
\frac xy=\frac{x_0}{y_0}+\frac1\lambda\log\frac{|y|}{|y_0|}.
$$

軌道を固有基底で二つの独立な指数の積として書けない代わりに、この対数が現れる。例えば $\lambda=-2$、$(x_0,y_0)=(1,1)$ なら $x=y(1-\log(y)/2)$ となる。$y\to0$ で比は発散するが、$y\log y\to0$ なので両成分とも原点へ近づく。

### 回転を含む線形系の共役

$A=\left(\begin{smallmatrix}a&-b\\b&a\end{smallmatrix}\right)$、$a\ne0$ の焦点を考える。穿孔平面で $(r,\theta)\mapsto(r,\theta-(b/a)\log r)$ と変えると、角速度は $b-(b/a)a=0$ になる。半径は $\dot r=ar$ のままだから、この変換は焦点と $aI$ の節点を時刻まで保って対応させる。変換を原点で $0$ と定めると、半径が変わらないため連続である。逆も角に同じ対数項を加えるだけで半径を保つので連続である。従って線形化の分類表に挙げた「焦点」と「節点」は、座標の中の軌道の形を区別する呼称である。位相共役の下では、対数的に回る座標変更によって両者が同じ型になりうる。滑らかな共役なら不動点の微分を相似にする必要があり、回転の虚部は残る。

### 退化した線形系と臨界減衰

跡と行列式の境界上では、固有値だけから平衡点の個数や時間方向の安定性を読み切れない。零固有値と重複固有値を分けて考えると、指数関数の他に時間の一次式が現れる理由を確認できる。

:::example[零固有値の幾何]
$\dot x=y,\ \dot y=0$ では $y(t)=y_0$、$x(t)=x_0+ty_0$ である。$y_0=0$ の各点は平衡点だが、どの平衡点の任意の近傍にも $y_0\ne0$ の点があり、その軌道は時間とともに近傍を出る。従ってすべての平衡点は不安定である。一方、零固有値と負固有値をもつ $\dot x=0,\ \dot y=-3y$ では、$x=x_0$、$y=e^{-3t}y_0$ なので各平衡点は安定である。$x_0$ が異なると収束先も異なるため、個々の平衡点は漸近安定ではない。
:::

:::example[同じ重根で異なる軌道]
$\dot x=-2x,\ \dot y=-2y$ の原点へ向かう軌道は半直線である。これに対し $\dot x=-2x+y,\ \dot y=-2y$ は $y=e^{-2t}y_0$、$x=e^{-2t}(x_0+t y_0)$ をもつ。例えば $(x_0,y_0)=(0,1)$ から出発すると $x/y=t$ であり、軌道は原点に近づきながら $x$ 軸へ向きを変える。$\dd x/\dd t=e^{-2t}(1-2t)$ だから $t=1/2$ に $x=1/(2e)$ の最大値を取る。全成分が初めから減少する必要はない。
:::

:::proposition[減衰振動子の判別]{#prop-dyn-damped-oscillator-types}
$\ddot x+2\gamma\dot x+\omega_0^2x=0$、$\omega_0>0$、$\gamma\ge0$ とする。$\gamma=0$ では原点は中心、$0<\gamma<\omega_0$ では吸引焦点、$\gamma>\omega_0$ では吸引結節点である。$\gamma=\omega_0$ では非対角化可能な吸引結節点である。
:::

:::proof
$(x,\dot x)$ 座標の行列は $\begin{pmatrix}0&1\\-\omega_0^2&-2\gamma\end{pmatrix}$ である。跡は $-2\gamma$、行列式は $\omega_0^2$、固有値は $-\gamma\pm\sqrt{\gamma^2-\omega_0^2}$ となる。実部と判別式の符号を :ref[prop-dyn-plane-linear-types] に入れる。臨界では行列が $-\gamma I$ でないため固有ベクトルが一次元に限られる。実際この場合に $x=e^{-\gamma t}u$ と代入すれば $u''=0$ となり、独立な二解にそれぞれ $e^{-\gamma t}$ と $t e^{-\gamma t}$ が現れる。
:::

## 平衡点の線形化

平衡点を原点に平行移動して、$C^1$ ベクトル場を $F(z)=Az+R(z)$、$A=DF(0)$、$\norm{R(z)}/\norm z\to0$ と書く。原点近くで二次以上の項が小さくても、線形化に残った成長率が零なら、長時間後の挙動を高次項が決めることがある。

:::definition[平衡点の安定性]{#def-dyn-lyapunov-stable}
任意の $\eps>0$ に対し、ある $\delta>0$ があり、$\norm{z(0)}<\delta$ なら全正時刻で $\norm{z(t)}<\eps$ であるとき、原点は :term[安定]{en="Lyapunov stable" yomi="あんてい"} であるという。さらに十分近い全初期値から $z(t)\to0$ なら漸近安定である。安定でない場合を不安定と呼ぶ。
:::

:::proposition[線形化と吸引・反発]{#prop-dyn-plane-linearization}
$A$ の固有値の実部がすべて負なら原点は指数的に漸近安定である。すべて正なら逆時間で同じ結論が成り立ち、原点は不安定である。
:::

:::proof
Jordan 形により、ある $C,\gamma>0$ に対して $\norm{e^{tA}}\le Ce^{-2\gamma t}$（$t\ge0$）となる。重根の係数 $t$ も少し遅い指数の中へ吸収できるためである。半径 $\rho$ の球で $\norm{R(z)}\le\eta\norm z$ とする。解が球にいる間、変分定数法により

$$
e^{2\gamma t}\norm{z(t)}
\le C\norm{z(0)}+
C\eta\int_0^t e^{2\gamma s}\norm{z(s)}\dd s.
$$

Gronwall の不等式から $\norm{z(t)}\le C\norm{z(0)}e^{-(2\gamma-C\eta)t}$ となる。$\rho$ を縮めて $C\eta<\gamma$、初期値を $\rho/(2C)$ 未満とすれば、最初の退出時刻があると仮定しても境界でノルムが $\rho/2$ 未満になって矛盾する。解はコンパクトな内側に残るので存在区間を延長でき、指数評価が全正時刻に成り立つ。

すべての実部が正なら $-F$ へ適用する。十分小さい固定点 $z_*\ne0$ を $-F$ で進めると $0$ に近づく。その軌道上で十分遅い点から $F$ で出発すれば $z_*$ まで離れるので、正方向の安定性が破れる。
:::

鞍点の不変曲線の存在と、その接線が固有方向であることは [双曲型不動点](/math/dynamical-systems/hyperbolicity/) で安定多様体とともに証明する。平衡点の型を調べる手順は、先に $F(z)=0$ を解き、その点で $DF(z)$ を取り、最後に固有値を計算する順である。

:::example[同じ線形化で異なる安定性]
三つの系を $\dot z=Jz+a\norm{z}^2z$、$J=\left(\begin{smallmatrix}0&-1\\1&0\end{smallmatrix}\right)$、$a\in\{-1,0,1\}$ とする。線形化は全て $J$ であるが、極座標では $\dot r=ar^3$、$\dot\theta=1$ となる。$a=-1$ なら $r(t)=r_0(1+2r_0^2t)^{-1/2}$ で漸近安定、$a=0$ なら円軌道があり安定、$a=1$ なら $r(t)=r_0(1-2r_0^2t)^{-1/2}$ で原点から離れる。
:::

:::example[非線形な平衡点の分類]
$\dot x=x(1-x)$、$\dot y=-y+x^2$ の平衡点は $(0,0),(1,1)$ である。Jacobi 行列は $\left(\begin{smallmatrix}1-2x&0\\2x&-1\end{smallmatrix}\right)$ で、原点の固有値は $1,-1$、$(1,1)$ の固有値は $-1,-1$ である。後者は指数的に漸近安定である。原点近くで $0<x_0<1$ と取ると $x(t)$ は $1$ に増加するので、原点は不安定であることを第一式だけで確かめられる。
:::

### 鞍点の不安定性を二次形式で示す

異符号の実固有値を $\lambda>0$、$-\sigma<0$ とする。固有基底で $F(x,y)=(\lambda x,-\sigma y)+o(\|(x,y)\|)$ と書き、$W=x^2-y^2$ を取る。十分小さい球では
$$
\dot W=2\lambda x^2+2\sigma y^2+o(x^2+y^2)\ge c(x^2+y^2),\qquad c>0
$$
である。球の内部で $W>0$ から出発すると、球にいる間は $\dot W\ge cW$ となる。従って $W$ は少なくとも指数関数的に増加するが、球の中では有界である。よってこの解は有限時間で球を出る。初期点を $y=0$ 上で任意に原点へ近づけられるので、原点は不安定である。

### 線形化を厳密な座標変換と比較する

固有方向に沿う線形系を、逆が明示できる多項式の座標変換で移す。こうすると、変換後に見える不変集合と、元の座標でその集合が曲がる様子を両方計算できる。

:::example[係数を 1 通り目に選んだ場合]
線形部の対角成分は $-1$ と $-3$ であり、変換の項は $2 x^{2}$ である。

新しい座標を $(X,Y)=(x,y+d x^j)$ として、ベクトル場を調べる。

$$
F(x,y)=\left[\begin{matrix}- x\\- 2 x^{2} - 3 y\end{matrix}\right]
$$

第一成分の時間発展は独立である。第二成分は第一成分の 2 次の影響を受ける。

新しい第二座標の時間微分に元の方程式を代入する。

$$
\dot Y=-2x^2-3y+4x(-x)=-3(y+2x^2)=-3Y
$$

この変換の逆は $x=X$、$y=Y-d X^j$ である。従って変換後の二つの独立な指数関数を求め、逆写像を適用できる。

時刻 $t$ の解を初期座標で書き直す。

$$
\phi_t(x,y)=\left[\begin{matrix}x e^{- t}\\- 2 x^{2} e^{- 2 t} + \left(2 x^{2} + y\right) e^{- 3 t}\end{matrix}\right]
$$

原点の線形化は二つの負固有値をもち、元の系でもすべての解が前進で原点へ近づく。しかし線形化で速い第二方向を選んでも、元の変数では第一成分から二次の項が供給される。初期値 $(1,0)$ では $y(t)=2e^{-3t}-2e^{-2t}$ となり、第二成分が零の直線は不変でない。
:::

:::example[係数を 2 通り目に選んだ場合]
線形部の対角成分は $1$ と $-2$ であり、変換の項は $- x^{2}$ である。

新しい座標を $(X,Y)=(x,y+d x^j)$ として、ベクトル場を調べる。

$$
F(x,y)=\left[\begin{matrix}x\\4 x^{2} - 2 y\end{matrix}\right]
$$

第一成分の時間発展は独立である。第二成分は第一成分の 2 次の影響を受ける。

新しい第二座標の時間微分に元の方程式を代入する。

$$
\dot Y=4x^2-2y-2x\cdot x=-2(y-x^2)=-2Y
$$

この変換の逆は $x=X$、$y=Y-d X^j$ である。従って変換後の二つの独立な指数関数を求め、逆写像を適用できる。

時刻 $t$ の解を初期座標で書き直す。

$$
\phi_t(x,y)=\left[\begin{matrix}x e^{t}\\x^{2} e^{2 t} + \left(- x^{2} + y\right) e^{- 2 t}\end{matrix}\right]
$$

線形化では鞍点である。元の不安定曲線は $Y=0$、すなわち $y=x^2$ となる。その上の点の過去極限は原点であり、安定曲線 $x=0$ の非零点は前進時間で原点へ向かう。線形化は接線を与え、二次変換は軌道が折れ曲がる量を与える。
:::

## Lyapunov 関数による安定性解析

軌道の式が得られなくても、軌道に沿って減るスカラー量があれば、初期値がどの小領域に留まるかを示せる。

:::definition[Lyapunov 関数]{#def-dyn-lyapunov-function}
原点の近傍で $C^1$ 関数 $V$ が $V(0)=0$、$z\ne0$ で $V(z)>0$ を満たし、軌道微分 $L_FV(z)=DV(z)F(z)$ が非正であるとき、$V$ を :term[Lyapunov 関数]{en="Lyapunov function" yomi="りゃぷのふかんすう"} と呼ぶ。
:::

:::theorem[劣位集合による安定性と不変集合への収束]{#thm-dyn-lasalle}
原点の近傍で Lyapunov 関数があれば原点は安定である。一般にコンパクトな正不変集合 $K$ の近傍で $V$ が $C^1$ 級であり、$K$ 上で $L_FV\le0$ なら、$z(0)\in K$ の極限集合は $E=\{z\in K:L_FV(z)=0\}$ に含まれる最大不変集合 $M$ に含まれる。特に、原点近傍の Lyapunov 関数と、原点の近傍を含む正不変な $K$ について $M=\{0\}$ なら漸近安定である。
:::

:::proof
任意の小さい球の境界で $V$ は正の最小値 $m$ をもつ。原点近くで $V(z(0))<m$ とすれば、時計を進めても $V$ は増えないため球の境界に着けない。この劣位集合がコンパクトに閉じ込められることから解は延長でき、安定性が従う。

$K$ 内では $V$ は下に有界であり、$V(z(t))$ はある値 $\ell$ に収束する。極限を定める時刻列に連続性を使うと $\omega(z(0))\subset\{V=\ell\}$ である。:ref[thm-dyn-omega-compact] により極限集合は不変だから、その中の点から始めた解に沿って $V$ は一定である。時刻 $0$ で微分すると $L_FV=0$ となるので、極限集合は $M$ に含まれる。距離が極限集合に近づく性質から $d(z(t),M)\to0$ が従う。$M=\{0\}$ なら原点へ収束する。
:::

:::example[散逸が一成分にしかない場合]
$\dot x=y$、$\dot y=-2x-3y$ では $V=x^2+y^2/2$ と置くと $L_FV=-3y^2$ である。$y=0$ で $x\ne0$ なら $\dot y=-2x\ne0$ なので軌道は直ちに $E$ を離れる。したがって $E$ の中の最大不変集合は原点であり、各劣位集合から原点へ収束する。$L_FV=0$ の点が原点以外にもあることは、この結論を妨げない。
:::

:::example[二次形式の作り方]
安定行列 $A$ と対称正定値行列 $Q$ に対して $P=\int_0^\infty e^{tA^\top}Qe^{tA}\dd t$ と置く。指数減衰から積分は収束し、任意の $x\ne0$ について積分の被積分関数が正なので $P$ は正定値となる。行列の微分を積分すると $A^\top P+PA=-Q$ を得る。したがって $V=z^\top Pz$ は線形系で $L_AV=-z^\top Qz$ を満たす。例えば $A=\diag(-1,-2)$、$Q=I$ なら $P=\diag(1/2,1/4)$ となる。非線形摂動 $R=o(\norm z)$ があっても $2z^\top PR=o(\norm z^2)$ を吸収できる。
:::

### 衰減率を与える Lyapunov 関数

安定性には、近くにとどまること、原点に収束すること、一定の指数で収束することの三段階がある。$V$ がノルムの二乗と比較でき、減り方が $V$ 自身で抑えられれば、直接指数速度まで求められる。

:::proposition[二次の比較からの指数評価]{#prop-dyn-lyapunov-rate}
原点近くで定数 $c_1,c_2,c_3>0$ に対し $c_1\norm z^2\le V(z)\le c_2\norm z^2$、$L_FV(z)\le-c_3\norm z^2$ が成り立つなら、十分小さい初期値から

$$
\norm{z(t)}\le\sqrt{c_2/c_1}\,e^{-c_3t/(2c_2)}\norm{z(0)}
$$

である。
:::

:::proof
:ref[thm-dyn-lasalle] の劣位集合の議論で軌道が評価の範囲に留まるよう初期値を選ぶ。その間は $(e^{c_3t/c_2}V(z(t)))'\le0$ である。積分して $V(z(t))\le e^{-c_3t/c_2}V(z(0))$ を得る。両端を二次の比較で評価して平方根を取ればよい。
:::

:::example[非対角の二次形式を使う]
$A=\left(\begin{smallmatrix}-1&4\\0&-2\end{smallmatrix}\right)$ とする。$V=(x^2+y^2)/2$ では $\dot V=-x^2+4xy-2y^2$ で、$x=2y$ の方向に正となる。そこで $A^\top P+PA=-I$ に $P=\left(\begin{smallmatrix}a&b\\b&c\end{smallmatrix}\right)$ を代入すると、$-2a=-1,\ 4a-3b=0,\ 8b-4c=-1$ を得る。よって $a=1/2,\ b=2/3,\ c=19/12$ である。$ac-b^2=25/72>0$ なので $P$ は正定値で、$V=z^\top Pz$ では $\dot V=-\norm z^2$ となる。Euclid 距離の一時的な増加と、別の二次形式による一様な減衰が両立する。
:::

:::example[指数より遅い収束]
$\dot x=-x^3,\dot y=-y$ では $V=(x^2+y^2)/2$ の微分は $-x^4-y^2$ で原点以外で負である。ただし $y=0$ では $|\dot V|/V=2x^2\to0$ なので、:ref[prop-dyn-lyapunov-rate] の $c_3>0$ は選べない。実際 $x(0)\ne0$ について $x(t)=x(0)/\sqrt{1+2t x(0)^2}$ であり、減衰は $t^{-1/2}$ のオーダーである。
:::

### 許される非線形項の大きさを測る

線形近似から作った Lyapunov 関数を非線形系に用いると、局所的にどの範囲で単調性が確実かを定量化できる。微分の符号を確かめた領域の内部に、関数の値による初期状態の制約を置く。

:::proposition[二次形式による吸引域の内側評価]{#prop-dyn-planar-ellipsoid-basin}
$\dot z=Az+R(z)$ とし、実対称正定値行列 $P,Q$ が $A^\top P+PA=-Q$ を満たすとする。$\|z\|\le r_0$ で $\|R(z)\|\le C\|z\|^2$、さらに $0<r<r_0$ と $2\|P\|Cr\le\lambda_{\min}(Q)/2$ を仮定する。$V=z^\top Pz$ とすれば、$V\le a<\lambda_{\min}(P)r^2$ の初期点は前方にこの劣位集合内にとどまり、
$$
V(z(t))\le V(z(0))\exp\!\left(-\frac{\lambda_{\min}(Q)}{2\lambda_{\max}(P)}t\right).
$$
:::

:::proof
微分して $\dot V=-z^\top Qz+2z^\top P R(z)$ である。各項を上から評価すると、$\|z\|\le r$ では $\dot V\le-(\lambda_{\min}(Q)/2)\|z\|^2$ となる。劣位集合は $P$ の最小固有値の下界により半径 $r$ の球の内部に含まれる。$a>0$ の境界上では $\dot V<0$ なので解は外へ出られず、コンパクト性と常微分方程式の解の延長により全正時刻で存在する。$a=0$ の場合は原点だけである。$\|z\|^2\ge V/\lambda_{\max}(P)$ を上の微分不等式に入れ、積分すれば結論を得る。
:::

:::example[交差項のある減衰]
$\dot x=y$、$\dot y=-x-2y+x^2$ とする。$Q=I$ と選び、$P=\begin{pmatrix}p&s\\s&q\end{pmatrix}$ を代入すると、対角成分から $s=1/2$、$2s-4q=-1$、非対角成分から $p-2s-q=0$ となる。従って $q=1/2$、$p=3/2$ である。$P$ の固有値は $1\pm1/\sqrt2$ で、$\|R(z)\|=x^2\le\|z\|^2$ である。例えば $r=1/8$ なら $2\|P\|r<1/2$ である。$a=1/512$ と選べば $a<(1-1/\sqrt 2)/64$ なので、この楕円の内部では指数収束を保証できる。この系には $(1,0)$ にも平衡点があるため、原点への大域的収束をこの局所結論から導けない。
:::

:::example[エネルギーで広い領域を得る]
同じ系で $E=y^2/2+x^2/2-x^3/3$ と置くと $\dot E=-2y^2$ である。$E(1,0)=1/6$ だから、$E<1/6$ で $x<1$ の側から出発する軌道は $x=1$ を横切れない。$x\to-\infty$ でポテンシャルが発散するため、固定した $a<1/6$ に対するこの側の $E\le a$ はコンパクトである。$\dot E=0$ の点では $y=0$ で、その直線にとどまるには $-x+x^2=0$ が必要である。この領域では $x=0$ に限るから、:ref[thm-dyn-lasalle] により原点へ収束する。二次形式は指数率の下界を与え、非線形エネルギーは鞍点の障壁まで吸引域を追う。
:::

## 勾配系とハミルトン系

スカラー関数 $H$ の勾配方向へ進む場合と、その方向に直交して進む場合を比較する。前者では高さが変わり、後者では高さを保つ。

:::definition[勾配系と平面 Hamilton 系]{#def-dyn-gradient-hamiltonian}
関数 $V$ に対する $\dot z=-\grad V(z)$ を :term[勾配系]{en="gradient system" yomi="こうばいけい"} という。平面で $\dot x=H_y$、$\dot y=-H_x$ と書ける系を :term[ハミルトン系]{en="Hamiltonian system" yomi="はみるとんけい"} と呼ぶ。
:::

:::proposition[高さの変化]{#prop-dyn-plane-energy}
勾配系では $\dot V=-\norm{\grad V}^2$ であり、非定常な周期軌道は存在しない。Hamilton 系では $H$ は保存し、$C^2$ 級なら発散は零である。$H$ の正則な等位集合の連結成分がコンパクトな円周なら、それは周期軌道である。
:::

:::proof
連鎖律で勾配系の公式が従う。周期上で積分すれば $V$ の変化は零なので勾配は全時刻で零になり、軌道は定常である。

Hamilton 系でも連鎖律から $H_xH_y-H_yH_x=0$ であり、発散は $H_{yx}-H_{xy}=0$ である。正則等位集合上では速度が零にならず、等位集合に接する。コンパクト成分上で速度の大きさは正の下限をもつので、弧長で一周する時間は有限である。向きは連続で一定であり、一周が最小周期になる。
:::

:::example[二つの井戸をもつ勾配系]
$V(x,y)=(x^2-1)^2/4+y^2/2$ とする。負の勾配系は $\dot x=x-x^3$、$\dot y=-y$ である。$x=0$ は不変で、$0<x<1$ では $x$ が増え、$x>1$ では減る。解の一意性から $x=1$ を越えず、極限は右辺の零点なので、$x_0>0$ は $(1,0)$ に収束する。$x_0<0$ は対称性から $(-1,0)$ に収束する。初期値が $x=0$ の場合だけ原点へ向かう。
:::

:::example[振動と分離曲線]
$H(x,y)=y^2/2+1-\cos x$ を円柱 $\R/2\pi\Z\times\R$ 上で考える。運動は $\dot x=y$、$\dot y=-\sin x$ である。$0<h<2$ の等位曲線では $|x|\le\arccos(1-h)$ に閉じ込められ、二つの符号の枝 $y=\pm\sqrt{2(h-1+\cos x)}$ が端点でつながる。勾配が零になるのは $h=0,2$ だけなので、この成分は周期的である。$h=2$ では鞍点 $(\pi,0)$ に近づく分離軌道が現れる。例えば $y>0$ の枝で $\dot x=2\cos(x/2)$（$-\pi<x<\pi$）であり、$x\to\pi$ では $\dot x$ が $\pi-x$ と同じ一次で零に近づくため、一周に必要な時間は発散する。
:::

### 発散が零の場と平衡点近くの等位曲線

長方形上で $F=(P,Q)$ が $C^1$ 級かつ $P_x+Q_y=0$ を満たすとする。長方形内に基準点 $(x_0,y_0)$ を取り、
$$
H(x,y)=-\int_{x_0}^x Q(u,y_0)\dd u+\int_{y_0}^y P(x,v)\dd v
$$
と定める。$H_y=P$ であり、$H_x=-Q(x,y_0)+\int_{y_0}^yP_x(x,v)\dd v=-Q(x,y)$ である。従って発散が零なら局所的に Hamilton 系として表せる。大域的には、穴の周囲で一形式 $-Q\dd x+P\dd y$ を積分して零になるかを確認する必要がある。例えば穿孔平面上の $F=(x,y)/(x^2+y^2)$ は発散が零だが、この一形式の単位円上での積分は $2\pi$ であり、単一値の大域 Hamiltonian は存在しない。

$H$ の臨界点 $p$ で Hessian が正定値なら、$p$ を中心とする小円上で、$H(p+re)-H(p)=r^2 e^\top D^2H(p)e/2+o(r^2)$ である。単位方向 $e$ ごとの放射微分も $r e^\top D^2H(p)e+o(r)$ であり、十分小さい $r>0$ では一様に正である。よって小さい正の等位差ごとに、各方向でただ一つ半径を解ける。陰関数定理により半径は方向に滑らかに依存し、等位曲線は正則な円周になる。従って :ref[prop-dyn-plane-energy] から $p$ を囲む周期軌道で近傍が埋まる。負定値のときは $-H$ の等位曲線を用いる。例えば $H=x^2/2+y^2/2+x^4/4$ の原点はこの判定で中心になる。

### 保存系の周期を積分する

$H(x,y)=y^2/2+U(x)$ で $U$ が滑らかとする。エネルギー $h$ の二つの折り返し点 $x_-<x_+$ が $U(x_\pm)=h$、$U'(x_\pm)\ne0$ を満たし、その間で $U<h$ とする。正の $y$ の枝では $x$ が増えて $\dd t=\dd x/\sqrt{2(h-U(x))}$ であり、戻りの枝では同じ時間がかかる。従って

$$
T(h)=2\int_{x_-}^{x_+}\frac{\dd x}{\sqrt{2(h-U(x))}}.
$$

端点の近くでは $h-U(x)$ は端点までの距離の正の定数倍に漸近するため、逆平方根の特異性は可積分である。この確認をしないと、折り返し点に着くのに有限時間しかかからないことが分からない。

:::example[非線形ポテンシャルでの周期の尺度]
$U(x)=x^4/4$ の場合、$h>0$ で折り返しは $\pm(4h)^{1/4}$ である。$x=(4h)^{1/4}s$ を代入すると

$$
T(h)=4h^{-1/4}\int_0^1(1-s^4)^{-1/2}\dd s.
$$

積分は $h$ に依らない。従ってエネルギーを $16$ 倍にすると周期は $1/2$ になる。原点で線形化した角周波数は零であり、この系の有限振幅の周期を線形近似から得ることはできない。
:::

:::example[振り子の周期の発散と小振幅極限]
$U=1-\cos x$ の場合は $0<h<2$ について $k=\sqrt{h/2}$ と置き、$\sin(x/2)=k\sin\alpha$ とする。対称性で四分の一周期を積分すると

$$
T(h)=4\int_0^{\pi/2}\frac{\dd\alpha}{\sqrt{1-k^2\sin^2\alpha}}.
$$

実際 $\dd x=2k\cos\alpha\,\dd\alpha/\sqrt{1-k^2\sin^2\alpha}$、$\sqrt{2(h-U)}=2k\cos\alpha$ で因子が相殺する。$k\downarrow0$ では被積分関数は一様に $1$ に近づくので $T\to2\pi$ となる。$k\uparrow1$ では単調収束により $\int_0^{\pi/2}1/\cos\alpha\,\dd\alpha=\infty$ へ向かう。周期軌道が平衡点を含む分離曲線に近づくときは、小振幅の線形周期を使えない。
:::

## Poincaré–Bendixson の定理

横断線分を小さく取ると、流れは線分を常に同じ向きに通る。さらに平面では、二度の交差の間の軌道と線分をつなぐと閉曲線を作れる。この閉曲線の内外を軌道が勝手に移れないことが、平面固有の制約になる。

:::lemma[同じ横断線分に現れる点の順序]{#lem-dyn-plane-section-order}
平面の $C^1$ 流れで、小さい開横断線分 $I$ を向き付ける。非周期軌道が $I$ を三回続けて $a,b,c$ の順に通るとき、$c$ は $a$ から $b$ へ進んだ向きで $b$ より先にある。したがって交点の列は単調である。
:::

:::proof
$a,b$ の間の軌道弧は単純で、$I$ に途中で交わらない。よって線分 $[a,b]$ と合わせると Jordan 閉曲線になる。軌道はその軌道弧を再び横切れない。線分上では流れはすべて同じ側から同じ側へ向く。線分を水平、流れを上向きとしてよい。$a<b$ なら $b$ の近くで閉曲線を作る二枝は左向きの線分と下から来る軌道弧である。従って $b$ の直後は線分の上側と同じ Jordan 成分にある。$a>b$ でも水平座標を反転して同じ議論を使える。従って次の交点は $(a,b)$ 内にない。

念のため逆端側も排除する。$a<b$ として $c<a$ を仮定する。$b$ から $c$ までの弧と $[c,b]$ が作る第二の Jordan 閉曲線を考える。$a$ は新しい線分の内部にあり、$a$ 直後の軌道は線分の流出側に入る。一方、$b$ 近くでは閉曲線を作る二枝が左向きの線分と上へ出る軌道弧なので、$b$ 直前の軌道は線分の下側と同じ成分にある。二つの側は同じ閉曲線の異なる成分に属する。$a$ から $b$ の間の軌道は第二の軌道弧と交わらず、線分とも途中では交わらない。これは矛盾である。端点が再び現れる場合は一意性により周期軌道になる。線分の向きを反転すれば $b<a$ も同様である。
:::

:::theorem[Poincaré–Bendixson]{#thm-dyn-poincare-bendixson}
平面の開集合上の $C^1$ ベクトル場について、ある正の軌道の閉包がその開集合内でコンパクトであり、$\omega(x)$ が平衡点を含まないとする。このとき $\omega(x)$ は一つの周期軌道である。
:::

:::proof
$L=\omega(x)$ と置く。:ref[thm-dyn-omega-compact] により $L$ は空でなくコンパクトで、正負両方向へ不変である。$x$ が周期点なら結論は明らかなので非周期とする。$p\in L$ を通る小さい横断線分をとる。流れ箱により、$x$ が $p$ の近くに来る十分遅い時刻ごとに、その時刻から小さい補正を行って横断面に交わる。横断性と線分を含む流れ箱を使うと、交差時刻に正の一様な間隔を取れる。その交点列は :ref[lem-dyn-plane-section-order] により単調だから、高々一つの極限をもつ。従って線分の内部にある $L$ の点は $p$ に限る。実際、別の極限点にも流れ箱によって交点列を近づけられる。以上は $L$ の任意の点で成立する。

$p\in L$ の前軌道も $L$ 内に留まり、$\omega(p)$ に点 $q$ がある。$q$ に平衡点がないので、$q$ を通る小線分に $p$ の正の軌道が無限に交わる。いずれの交点も $L$ に属し、従って $q$ である。二つの異なる時刻に $q$ を通るから $p$ は周期軌道上にある。

最後に $L$ がこの周期軌道 $\Gamma$ を越えて広がらないことを示す。$q\in\Gamma$ の横断面をとり、$x$ の交点列は $q$ に収束する。:ref[prop-dyn-local-return] により $q$ 近くの点の一周は連続に定まる。交点列の十分先からはこの一周ごとに線分へ戻り、しかもその帰還点は列の次の交点である。帰還時間は $\Gamma$ の周期 $T$ に収束する。交点間の軌道弧は、有界な時刻区間における連続依存性から $\Gamma$ の任意の近傍に最終的に含まれる。よって $L\subset\Gamma$ であり、逆包含は不変性から従う。
:::

:::example[閉じ込めによる周期軌道の存在]
$\dot r=r(2-r^2)$、$\dot\theta=1$ とする。$r=1$ では $\dot r=1>0$、$r=2$ では $\dot r=-4<0$ である。従って $1\le r\le2$ は正不変で平衡点を含まず、定理から周期軌道がある。この例では半径方程式も解釈できる。$r<\sqrt2$ で増加、$r>\sqrt2$ で減少するのでその周期軌道は $r=\sqrt2$ のみで、一周の時間は $2\pi$ である。
:::

:::example[仮定が外れる場合]
$\dot x=-x$、$\dot y=-y$ では前軌道はコンパクトな閉包をもつが、極限集合は平衡点 $\{(0,0)\}$ である。一方、二次元トーラスで $\dot x=1$、$\dot y=\sqrt2$ とすると、$x=0$ への周期ごとの帰還は $y\mapsto y+\sqrt2$ である。:ref[prop-dyn-rotation-orbits] により断面への像が稠密で、任意の $x$ の断面でも同様であるため全軌道は稠密である。この場合は平面の Jordan 分離を使えない。
:::

### 平衡点が極限集合に入るとき

平衡点が含まれる場合でも、極限集合の中の正則な点では前の証明の横断面の順序が使える。平衡点の個数が有限なら、その正則点を通る軌道の両端を分類できる。

:::corollary[平衡点が有限個の場合の接続軌道]{#cor-dyn-planar-connections}
正の軌道がコンパクトな閉包をもち、その極限集合 $L$ に平衡点が有限個しかないとする。$L$ が周期軌道でなく、$p\in L$ が平衡点でもないなら、$p$ の正と負の極限集合はそれぞれ一個の平衡点からなる。
:::

:::proof
$L$ はコンパクト不変なので $p$ の正負の極限集合はともに空でなく連結である。どちらかに正則点 $q$ があれば、$q$ の流れ箱の横断面に $p$ の軌道がその方向で無限回入る。:ref[thm-dyn-poincare-bendixson] の証明では、非周期な元の軌道の横断面上の交点列が単調なことから、横断面内の $L$ の点は $q$ のみであった。この部分では $L$ の他の点が平衡点かどうかを使っていない。従って $p$ の交差はすべて $q$ になり、$p$ は周期点になる。しかし $L$ に周期点があれば、元の軌道をその周期点の断面で追う証明の最後の段階により $L$ はその周期軌道である。これは仮定に反する。従って両極限集合は平衡点だけからなり、連結性と有限性から一個ずつに限る。
:::

この場合の $L$ は平衡点と、それらを結ぶ非定常な全軌道からなる。両端が同じ平衡点となる場合もある。一方、有限個の平衡点を含むだけでは接続軌道が実現するとは限らない。例えば各平衡点が吸引的なら、ある軌道の負の極限にその平衡点が現れることはない。実際、吸引平衡点の近傍から正時間に出られないことを逆に読めば、負時間の十分先がその近傍にある軌道は正時間にもそこから出られず、近傍を任意に縮めれば定常軌道となる。

:::example[平衡点と接続の違い]
$\dot x=1-x^2,\ \dot y=xy$ の $y=0$、$-1<x<1$ にある軌道は $x(t)=\tanh(t+c)$ である。従って $\alpha=\{(-1,0)\}$、$\omega=\{(1,0)\}$ である。二つの極限を結んでいる軌道全体がその軌道自身の $\omega$ 極限集合になるわけではない。接続が極限集合そのものの中に現れるには、たとえば別の前軌道が接続に繰り返し接近するような配置が必要である。
:::

### 放射速度と角速度を独立に計算する

閉曲線の内外で放射速度に異なる符号があると、前向きあるいは後ろ向きに不変な円環を作れる。円環から原点を外すことで、極限集合に平衡点が入らない条件を確認する。

以下では $\dot r=r(A+Br^2)$、$\dot\theta=\omega+cr^2$ とする。$B\ne0$ のとき、正の根は $-A/B>0$ を満たす場合に一つあり、半径は $\sqrt{-A/B}$ である。その根で角速度が零なら円の各点が平衡点になるため、周期を求める前に角速度を確認する。

:::example[半径 1 の周期軌道]
極座標の放射係数と角速度を別々に選ぶと、直交座標の多項式の場が得られる。

$$
F(x,y)=\left[\begin{matrix}x \left(- 2 x^{2} - 2 y^{2} + 2\right) - y \left(x^{2} + y^{2} + 2\right)\\x \left(x^{2} + y^{2} + 2\right) + y \left(- 2 x^{2} - 2 y^{2} + 2\right)\end{matrix}\right]
$$

$\dot r=(x\dot x+y\dot y)/r$、$\dot\theta=(x\dot y-y\dot x)/r^2$ から求める。これにより原点以外での方程式を得る。

放射速度の非零の零点を探し、その半径で角速度を評価する。

$$
\begin{aligned}
\dot r&=r \left(2 - 2 r^{2}\right)\\
\dot\theta&=r^{2} + 2\\
R_*&=1\\
\omega_*&=3\\
T&=\frac{2 \pi}{3}
\end{aligned}
$$

半径が一定なので角が絶対値で $2\pi$ だけ動く時刻が最小周期である。

円を通る放射方向の変分は、放射速度を半径で微分した一定係数に従う。従って断面の一周の微分を次のように求める。

$$
\begin{aligned}
\partial_r\dot r(R_*)&=-4\\
\exp(T\partial_r\dot r(R_*))&=e^{- \frac{8 \pi}{3}}
\end{aligned}
$$

$1/2\le r\le 3/2$ の円環で内周の放射速度は正、外周では負である。ここでは角速度も正で平衡点を含まないから、円環内の前方極限集合は定理により閉軌道である。放射速度の正の零点は一つなので、その軌道を半径 $1$ の円と同定できる。
:::

:::example[半径 1 の周期軌道]
極座標の放射係数と角速度を別々に選ぶと、直交座標の多項式の場が得られる。

$$
F(x,y)=\left[\begin{matrix}x \left(x^{2} + y^{2} - 1\right) - y \left(- x^{2} - y^{2} + 3\right)\\x \left(- x^{2} - y^{2} + 3\right) + y \left(x^{2} + y^{2} - 1\right)\end{matrix}\right]
$$

$\dot r=(x\dot x+y\dot y)/r$、$\dot\theta=(x\dot y-y\dot x)/r^2$ から求める。これにより原点以外での方程式を得る。

放射速度の非零の零点を探し、その半径で角速度を評価する。

$$
\begin{aligned}
\dot r&=r \left(r^{2} - 1\right)\\
\dot\theta&=3 - r^{2}\\
R_*&=1\\
\omega_*&=2\\
T&=\pi
\end{aligned}
$$

半径が一定なので角が絶対値で $2\pi$ だけ動く時刻が最小周期である。

円を通る放射方向の変分は、放射速度を半径で微分した一定係数に従う。従って断面の一周の微分を次のように求める。

$$
\begin{aligned}
\partial_r\dot r(R_*)&=2\\
\exp(T\partial_r\dot r(R_*))&=e^{2 \pi}
\end{aligned}
$$

$3/4\le r\le 5/4$ では逆向きの流れに対し内周と外周が内側を向く。角速度は円環内で零にならない。従って同じ定理を逆時間に適用すれば過去の極限集合が閉軌道であり、元の流れでは反発する半径 $1$ の円だと分かる。
:::

## 極限周期軌道と Liénard 方程式（van der Pol 方程式）

周期軌道が近傍のほかの周期軌道から孤立している場合を :term[極限周期軌道]{en="limit cycle" yomi="きょくげんしゅうききどう"} と呼ぶ。平面では断面上の孤立不動点として調べられる。不動点の片側から距離が減るかは、向き付き座標で帰還変位 $P(s)-s$ の符号を見ると分かる。

:::example[片側だけから吸引する周期軌道]
円環で $\dot r=(r-1)^2$、$\dot\theta=1$ を考える。$r=1$ は孤立周期軌道である。$-1<s_0=r(0)-1<0$ のとき $s(t)=s_0/(1-s_0t)$ は負のまま $0$ に収束する。$s_0>0$ の場合は増加して近傍を離れる。$P'(1)=1$ なので、微分だけでは片側ごとの挙動を判定できない。
:::

Liénard 方程式 $\ddot x+f(x)\dot x+g(x)=0$ を考え、$F(x)=\int_0^x f(s)\dd s$、$y=\dot x+F(x)$ と置くと

$$
\dot x=y-F(x),\qquad \dot y=-g(x).
\label{eq-dyn-lienard}
$$

従って $E(x,y)=\int_0^x g(s)\dd s+y^2/2$ の軌道微分は $\dot E=-g(x)F(x)$ である。$x>0$ で $g(x)>0$ の場合、$F$ の正負に応じてエネルギーが減ったり増えたりする。エネルギーの変化は一周にわたって積分して調べる必要がある。

:::theorem[Liénard の一意性定理の一形式]{#thm-dyn-lienard-cycle}
$f,g$ は $C^1$、$F$ と $g$ は奇関数とする。$x>0$ で $g(x)>0$、$\int_0^\infty g(s)\dd s=\infty$ とする。ある $a>0$ に対し $F(x)<0$ が $0<x<a$ で、$F(a)=0$ が成り立ち、$F$ は $[a,\infty)$ で狭義増加して無限大に発散するとする。このとき系 :eqref[eq-dyn-lienard] にただ一つの非定常な周期軌道があり、これは安定な極限周期軌道である。
:::

:::proof
$y=b>0$ の正の $y$ 軸から右半平面に出る軌道を考え、次に負の $y$ 軸へ帰るとき $y=-B(b)$ と書く。その間 $y$ は減る。軌道は右半平面で $x$ が最初増え、$\dot x=0$ に着くとその場で $\ddot x=-g(x)<0$ なので、その後は $x$ が減り続ける。右半平面内で $x$ が有界なら、有限時間では $|y|\le b+t\max|g|$ も成り立ち解を延長できる。曲がる点が存在する理由は $y\le b$ と $F(x)\to\infty$ により $x$ が有界になり、一定の正の距離だけ $x=0$ から離れた状態が続けば $y$ が下がり続けるからである。減少する $x$ の極限が正なら同じ理由で有限時刻にその下を通る。$x\to0$ の場合、ある時刻で $y<0$ になればその負の値が以後の上限である。$F(x)\to0$ だから最終的に $\dot x$ は負の定数以下となり、$x=0$ に有限時間で着く。$y\ge0$ のままなら $0<x<a$ で $\dot x=y-F(x)>0$ となるので矛盾する。よって $B$ は正の半直線全体で定まる。連続依存性と横断性から $B$ は連続である。二つの弧が交われば、その点を逆向きにたどった最初の $y$ 軸との交差が一致して、同じ始点をもつことになる。このため軌道弧は交わらず、$b_2>b_1$ なら $B(b_2)>B(b_1)$ である。厳密には右半平面の軌道弧は、それぞれ $y$ の狭義単調性から $x=x_b(y)>0$ のグラフをなす。内側の始点の高さ $b_1$ における外側の $x$ は正なので、交わりがない限り外側のグラフは右にあり、負の端点は内側の端点より低い。

右半周のエネルギー変化は

$$
D(b)=\frac{B(b)^2-b^2}{2}
=\int_{(0,b)}^{(0,-B(b))} F(x)\dd y.
$$

軌道が $x=a$ に達しなければ $F<0$、$\dd y<0$ なので $D>0$ である。$x=a$ に達して戻る弧では、右半周を $x\le a$ の二つの枝と $x>a$ の中央弧に分ける。$x\le a$ の枝上の寄与は

$$
\int_0^a\frac{-F(x)g(x)}{y_{\rm out}(x)-F(x)}\dd x
+\int_0^a\frac{-F(x)g(x)}{F(x)-y_{\rm in}(x)}\dd x.
$$

ここで $y_{\rm out}$ は $\dot x>0$、$y_{\rm in}$ は $\dot x<0$ の枝である。外側の弧では交差しないことから $y_{\rm out}$ が上がり $y_{\rm in}$ が下がるので、正の寄与は減る。中央弧の寄与は $\int F(x_b(y))\dd y$ であり、$y$ が減る向きに取る。外側の弧では中央弧の上下端の $y$ の区間が広がり、共通区間では $x_b(y)$ が右に移る。$F$ が右で狭義増加するため、負の寄与は厳密に減る。従って $x=a$ を越える弧では $D(b)$ が狭義減少する。

$D(b)$ は小さい $b$ で正である。半周が $x=a$ を越える場合も、一周で $B(b)\le b$ なら $y$ の全変化は高々 $2b$ となる。一方、軌道が例えば $a/2\le x\le a$ を横切るとき、$\dot x$ は $b+\max_{[0,a]}|F|$ 以下で $g$ は正の下限をもつから、その間の $y$ の減少量には $b\to0$ でも正の下限がある。これは矛盾する。大きな $b$ については、固定した $R>a$ に達するまで $y=b+O(b^{-1})$ である。実際 $0\le x\le R$ で $|F|,g$ は有界なので、$y\ge b/2$ の間は $\dot x\ge b/2-\max|F|$ であり、$x=R$ に達する前に $y=b/2$ には落ちない。その後 $x=R$ を内向きに通るときには $y<F(R)$ である。従って $F(x)\ge F(R)>0$ の間の $y$ の減少が無限大になり、中央弧の寄与は $-\infty$ に向かう。正の寄与は先の単調性から有界であり、$D(b)<0$ となる。

これで $D(b)=0$ となるただ一つの $b_*$ が存在する。ベクトル場の原点対称性により左半周も同じ $B$ で記述でき、全帰還は $B\circ B$ である。増加写像 $B$ では $B^2(b)=b$ なら $B(b)=b$ である。周期軌道は $y$ が一周期で元に戻るため $g(x)$ の符号を両方通らなければならず、正の $y$ 軸を右向きに横切る。周期軌道の最初の帰還が $b$ に一致することも従う。実際、増加写像 $B\circ B$ の反復が $b$ に戻るなら、初回に $b$ より上または下に移った場合の狭義単調性に矛盾する。従って周期軌道は $b_*$ からの一つだけである。$b<b_*$ で $b<B(b)<b_*$、$b>b_*$ で $b>B(b)>b_*$ なので半周写像を繰り返すと $b_*$ に単調収束する。連続依存性を一周の弧に用いれば周期軌道の安定性と近傍からの吸引が従う。
:::

:::example[van der Pol 方程式]
$\ddot x+\mu(x^2-1)\dot x+x=0$、$\mu>0$ に対し $F(x)=\mu(x^3/3-x)$、$g(x)=x$ である。正根 $a=\sqrt3$ の内側で $F<0$、外側で $F'=\mu(x^2-1)>0$ であり $F\to\infty$ である。$g$ の積分は $x^2/2$ なので :ref[thm-dyn-lienard-cycle] の仮定を満たす。例えば $\mu=2$ のとき $x=1$ で $\dot E=4/3>0$、$x=2$ で $\dot E=-8/3<0$ となる。半周期を積分した変位が零になるところが、瞬間的な $\dot E$ の零点とは異なる。
:::

### 半周写像から分かる吸引域

上の Liénard 系で、任意の $x>0$ からの前軌道は負の $y$ 軸に達する。実際、初期値より右へ進む範囲では $y$ は初期値以下であり、$F(x)\to\infty$ が $x$ を上から抑える。$\dot x$ の零点では $\ddot x=-g(x)<0$ なので、右向きから左向きに変わることは一度しかない。もし右半平面に留まるなら、$x$ は最終的に単調で有限の極限をもつ。その極限が正なら $y$ が負の無限大へ下がって矛盾し、極限が零なら $F<0$ の領域で先の証明と同じ議論により有限時間で軸へ達する。左半平面は原点対称性で扱える。軸の上でも原点以外からはすぐどちらかの半平面へ入る。

従って原点以外の点はすべて半周写像の反復で追える。交点の高さの絶対値は $b_*$ に近づき、半周ごとの通過時間は連続依存性と横断性により $b_*$ から出た半周の正の時間へ収束する。そのため交点時刻は無限大へ進み、解は全正時刻で存在する。交差間の軌道弧も連続依存性により極限周期軌道へ近づく。この仮定の下では、吸引域は原点を除く全平面である。

### 弱い van der Pol 項と周期軌道の振幅

Liénard の定理は周期軌道が一つであることを示すが、半径までは与えない。$\mu>0$ が小さい場合には、一周での半径変化を展開して振幅の近似を得られる。$u=x$、$v=-\dot x$、$(u,v)=(r\cos\theta,r\sin\theta)$ と置くと

$$
\begin{aligned}
\dot r&=\mu r(1-r^2\cos^2\theta)\sin^2\theta,\\
\dot\theta&=1+\mu(1-r^2\cos^2\theta)\cos\theta\sin\theta .
\end{aligned}
$$

固定した有界な円環では十分小さい $\mu$ に対して角速度は零から離れる。半径は一周で $O(\mu)$ しか変わらないので、右辺の半径を初期値に固定し $\dot\theta$ を $1$ とした誤差は $O(\mu^2)$ である。従って

$$
P_\mu(r)-r=\mu\pi r(1-r^2/4)+O(\mu^2)
$$

である。積分に使ったのは $\int_0^{2\pi}\sin^2\theta\,\dd\theta=\pi$ と $\int_0^{2\pi}\cos^2\theta\sin^2\theta\,\dd\theta=\pi/4$ である。一周分の常微分方程式の滑らかな初期値依存性から、この展開は $r$ 微分でも成り立つ。変位を $\mu$ で割った式は $\mu=0$ に滑らかに延び、$r=2$ の根で微分が $-2\pi$ である。陰関数定理により $r_\mu=2+O(\mu)$ の不動点があり、乗数は $1-2\pi\mu+O(\mu^2)$ である。:ref[thm-dyn-lienard-cycle] の一意性によりこれが系の極限周期軌道である。点ごとの瞬間的な半径は一定でないが、一周での変化が $O(\mu)$ なので、最大の $|x|$ も $2+O(\mu)$ である。

:::example[瞬間の増幅と一周の変位]
一周の一次変位は $r=1$ で $3\pi\mu/4$、$r=3$ で $-15\pi\mu/4$ である。$r=3$ でも $\cos\theta=0$ の点では瞬間的に $\dot r>0$ となる。従って一周の吸引方向は全角度で瞬間的に内側を向くことを要求しない。
:::

### 三つの円からなる例で孤立性と安定性を区別する

Poincaré–Bendixson の定理で周期軌道が見つかっても、安定性や個数は別途確認する。半径の方程式が分かる場合は、半径の単純根の左右の符号から両方を読み取れる。

:::example[二つの吸引周期軌道とその境界]
$u=x^2+y^2$ とし、$Q(u)=-(u-1)(u-4)(u-9)$ と置く。
$$
\dot x=Q(u)x-y,\qquad \dot y=x+Q(u)y
$$
に対し $\dot u=2uQ(u)$、原点以外で $\dot\theta=1$ である。従って半径 $1,2,3$ の円はすべて最小周期 $2\pi$ をもつ。$Q$ の符号は区間 $(0,1),(1,4),(4,9),(9,\infty)$ の順に $+,-,+,-$ である。よって $u=1,9$ が吸引し、$u=4$ が反発する。$u$ の運動は各区間で単調かつ有限の根に挟まれ、端点でも唯一性が成り立つ。特に $u=4$ から内側の原点以外は $u=1$ に、外側は $u=9$ に収束する。
:::

:::example[横断乗数を求める]
上の系で $u_i=1,4,9$ の円を横切る断面上に $u$ を座標として取る。帰還時刻は常に $2\pi$ であり、変分は $\dot v=2u_iQ'(u_i)v$ に従う。$Q'(1)=-24$、$Q'(4)=15$、$Q'(9)=-40$ だから、乗数は順に $e^{-96\pi}$、$e^{240\pi}$、$e^{-1440\pi}$ である。円の周期が同じでも、横断変分の収縮や拡大は異なる。これらの数は初期点を変えても半径が正で同じ角速度を保つことを使って得た。
:::

:::example[重根と片側安定性]
$Q(u)=-(u-1)^2$ に取り替えると、$u=1$ の閉軌道は孤立し、乗数は $1$ である。$u>1$ では $u$ が単調減少して $1$ に収束する。$0<u<1$ では $u$ が単調減少し、下側に正の根がないため $0$ に収束する。従って円は外側から吸引し、内側からは近傍を離れる。双曲性が失われていても周期軌道は孤立し得る。
:::

## 指数と Bendixson–Dulac の判定法

平衡点の位置を知らなくても、閉曲線に沿ったベクトルの向きや、領域内部での面積の増減から、周期軌道の存在を制約できる。

:::definition[ベクトル場の指数]{#def-dyn-plane-index}
正向きの区分的 $C^1$ 級単純閉曲線 $C$ 上で $F\ne0$ とする。$F/\norm F$ が円周上を何周するかを :term[指数]{en="index" yomi="しすう"} $\operatorname{ind}_C F$ と呼ぶ。連続に持ち上げた偏角の増分を $2\pi$ で割って定める。孤立零点の指数は、その点だけを囲む十分小さい円について定める。
:::

:::proposition[指数の加法性と線形化]{#prop-dyn-index-additivity}
$F$ が $C^1$ 級で、$C$ の内部に孤立零点 $p_1,\dots,p_k$ だけがあるなら、$\operatorname{ind}_C F$ はそれらの指数の和である。$DF(p_i)$ が可逆であれば各指数は $\operatorname{sgn}\det DF(p_i)$ である。正則な周期軌道の指数は $1$ である。
:::

:::proof
内部から各零点だけを囲む小円板を取り除く。零点を避ければ、成分 $F=(u,v)$ から作る一形式 $(u\dd v-v\dd u)/(u^2+v^2)$ は局所的に偏角の全微分である。この領域を偏角が定義できる小領域に分ければ、小領域の境界上での積分は零で、共有辺の積分は相殺する。従って外側の積分は正向きの各小円上の積分の和となる。$2\pi$ で割れば加法性を得る。

零点近くで $F(p+z)=Az+o(\norm z)$、$A=DF(p)$ と書く。$A$ が可逆なら小円上で剰余は $\norm{Az}$ より小さいため、$Az$ への線形ホモトピーは零を通らない。指数はホモトピーで連続に変わる整数なので一定である。可逆線形写像は単位円を楕円へ写し、向きを $\det A$ の符号で決めるから線形場の指数が分かる。

周期軌道上では $F$ は接線方向かその反対であり、符号は一定である。単純閉曲線を正向きに一周すれば接線の全回転は $2\pi$ である。これは単純多角形近似で外角和が $2\pi$ となることと、細かい分割で各辺の向きが対応する接線方向に一様に近づくことから従う。接線を反転しても全回転は変わらない。
:::

:::example[内部に必要な平衡点]
周期軌道の内側に可逆な線形化をもつ零点しかないなら、指数 $+1$ の点の個数から鞍点の個数を引いた値は $1$ である。鞍点が一つだけ内側に見つかり、他の零点がない場合、そこを囲む周期軌道は存在しない。鞍点が一つあっても、指数 $+1$ の点が二つあれば指数の条件は満たすので、存在は別に判定する。
:::

:::theorem[Bendixson–Dulac 判定]{#thm-dyn-bendixson-dulac}
単連結な平面領域 $U$ 上で $F,B$ は $C^1$ とする。$\divg(BF)$ が一定の符号をもち、どの空でない開集合でも恒等的に零でないなら、$U$ 内に周期軌道はない。
:::

:::proof
周期軌道は単純閉曲線である。単連結性からその内部も領域内に入る。境界で $F$ は接線方向なので外向き流束 $\int_{\partial D}BF\cdot\nu\dd s$ は零である。Green の公式によりこれは $\int_D\divg(BF)\dd x\dd y$ である。仮定と連続性から積分は厳密に正または負であり、矛盾する。
:::

:::example[乗数の選択]
第一象限で $\dot x=x(2-x-y)$、$\dot y=y(-1+x-y)$ とし、$B=1/(xy)$ とする。$BF=((2-x-y)/y,(-1+x-y)/x)$ なので $\divg(BF)=-1/y-1/x<0$ である。第一象限は単連結だから周期軌道はない。元の発散は $1-x-3y$ で符号が変わるため、$B=1$ での判定はできない。
:::

:::example[単連結性が必要な理由]
$r>0$ で $\dot r=-(r-1)$、$\dot\theta=1$ とする。$1/2<r<2$ の円環で発散は $r^{-1}\partial_r(r\dot r)=-2+1/r<0$ である。しかし $r=1$ は周期軌道である。軌道の内部の円板が領域に含まれないので、円板に対して Green の公式を使う段階が成り立たない。
:::

### 接続軌道が囲む領域を排除する

Bendixson–Dulac の流束の議論は、双曲型鞍点とその接続軌道からなる単純閉曲線にも使える。仮定は、曲線とその内部が $U$ に入り、$B,F$ が鞍点を含めて $C^1$ 級であることである。鞍点の近くで安定枝と不安定枝は区分的に滑らかな境界を作るので、境界は有限個の角をもつ区分的に滑らかな曲線となる。各弧で $BF$ は接線方向であり、角の有限集合は境界積分に寄与しない。従って流束は零である。:ref[thm-dyn-bendixson-dulac] と同じ発散の符号条件を課すと、内部積分は非零になるためそのような接続も存在しない。

### 線形化が可逆でない零点の指数

行列式の符号で判定できるのは、零点周囲の小円で線形項が剰余を上回る場合である。線形化が特異なら、小円上のベクトルを直接追うか、零を通らないことを別の方法で確認してから式を簡単にする。

:::example[同じ退化でも指数が異なる]
$F=(x^3,y)$ で小円を取る。第一成分を $(1-s)x^3+sx$ に取り替えた $0\le s\le1$ の場は、$y\ne0$ なら第二成分が非零で、$y=0$ なら $x\ne0$ なので第一成分が非零である。従って指数は恒等線形場と同じ $1$ である。対して $F=(x^2,y)$ は小円上でも第一成分が非負である。像の向きは右半円に含まれ、偏角を $[-\pi/2,\pi/2]$ の範囲で連続に選べるので増分が零、指数は $0$ となる。どちらも原点での微分は $\diag(0,1)$ である。
:::

:::example[一つの孤立零点で負の二回転]
$(x,y)$ を $z=x+iy$ と同一視し、場を $\bar z^2=(x^2-y^2)-2ixy$ とする。半径 $r$ の円では $F=r^2e^{-2i\theta}$ となるので、原点の指数は $-2$ である。孤立零点の指数は $\pm1$ に限らない。一方、$F$ を小さな正の実定数 $a$ だけ平行移動すると、$F=a$ の二根 $z=\pm\sqrt a$ が生じる。各根では行列式が $-4a<0$ で指数は $-1$ となり、二根を囲む円上の指数は加法性により変わらない。
:::

:::example[指数が保存される範囲]
$F_\mu=(\mu-x^2,-y)$ を固定した小円で考える。$\mu<0$ では零点がなく、円周上のベクトルの場は左半平面にあるため指数は零である。小さな $\mu>0$ では二つの零点 $(\pm\sqrt\mu,0)$ が円内にあり、そこでの行列式はそれぞれ $\pm2\sqrt\mu$ である。従って指数の和も零である。途中で円周上に零点が現れない限り、内部で二点が生成されても境界上の指数は変わらない。
:::

### 穴をもつ領域での判定

Bendixson–Dulac の証明を局所的に読み直すと、周期軌道とその内部がともに $U$ に入れば、その軌道を排除できる。従って $U$ が円環の場合、発散に厳密な符号があっても、穴を一周する軌道だけは残りうる。ただし、そのような周期軌道が二つあれば、その間を調べられる。

:::corollary[円環内での個数の上界]{#cor-dyn-dulac-annulus}
円環 $U$ で :ref[thm-dyn-bendixson-dulac] と同じ発散の符号条件が成り立つなら、$U$ 内の周期軌道は高々一つである。
:::

:::proof
穴を囲まない周期軌道なら、その円板状の内部も $U$ に入り、元の流束の証明で排除される。穴を囲む周期軌道が二つあれば、軌道の一意性から交わらず、どちらも穴を囲むので一方が他方の内側にある。両者の間の開円環の閉包は $U$ に入る。Green の公式をこの領域に適用すると、外と内の両境界の流束は零だが発散の積分は非零であり、矛盾する。
:::

:::example[上界を達成する円環]
前の $\dot r=-(r-1),\dot\theta=1$ では $1/2<r<2$ で $-2+1/r<0$ であり、$r=1$ が一つの周期軌道である。円環内では $r=1$ の外や内に別の周期軌道を挿入しつつ同じ発散条件を保つことは、上の系によりできない。さらに二つの周期軌道 $r_1<r_2$ がある一般の回転対称系 $\dot r=f(r)$ では、両者の間で $\int_{r_1}^{r_2}((rf(r))'/r)\,r\dd r=r_2 f(r_2)-r_1 f(r_1)=0$ となる。これは両境界で流束が零であることの極座標での表示である。従って発散がどこでも厳密に負という条件は、二つの同心周期軌道とは両立しない。
:::

## 演習問題

::::exercise{level=basic}
$A=\left(\begin{smallmatrix}1&-4\\1&1\end{smallmatrix}\right)$ の原点の型と固有値を求めよ。
:::solution
$\tau=2$、$\Delta=5$ より特性多項式は $\lambda^2-2\lambda+5$ で、根は $1\pm2i$ である。実部が正で虚部が零でないため :ref[prop-dyn-plane-linear-types] の反発焦点に当たる。
:::
::::

::::exercise{level=basic}
$\dot x=-x+y^2$、$\dot y=-2y$ の初期値 $(1,2)$ からの解を求め、線形化の判定と比較せよ。
:::solution
第二式から $y=2e^{-2t}$ であり、第一式に積分因子を使うと $(e^tx)'=4e^{-3t}$ となる。よって $x=e^{-t}[1+(4/3)(1-e^{-3t})]$ であり、両成分とも零に収束する。線形化は $\diag(-1,-2)$ なので :ref[prop-dyn-plane-linearization] も原点近くで指数的な漸近安定性を与える。
:::
::::

::::exercise{level=basic}
$\dot x=y$、$\dot y=-x-x^3-2y$ の原点が大域的に漸近安定であることを示せ。
:::solution
$V=x^2/2+x^4/4+y^2/2$ と置くと $L_FV=(x+x^3)y+y(-x-x^3-2y)=-2y^2$ である。劣位集合は有界かつ閉であり、正不変だから任意の初期値から解は将来へ延長できる。$y=0$ 上で $\dot y=0$ は $x+x^3=0$、すなわち原点だけである。:ref[thm-dyn-lasalle] により原点へ収束し、同定理の安定性も成り立つ。
:::
::::

::::exercise{level=basic}
$H=2x^2+y^2/2$ の Hamilton 系について周期を求めよ。
:::solution
$\dot x=y$、$\dot y=-4x$ から $\ddot x=-4x$ を得る。非零解は角周波数 $2$ の正弦と余弦の一次結合である。$x,\dot x$ の両者が同時に戻る最小の正時刻は $2t=2\pi$ より $t=\pi$ である。
:::
::::

::::exercise{level=advanced}
$\dot r=r(1-r^2)(4-r^2)$、$\dot\theta=1$ について三つの領域 $0<r<1$、$1<r<2$、$r>2$ の各極限集合と、二つの周期軌道の安定性を求めよ。
:::solution
符号は順に正、負、正である。最初の二領域では半径が単調に $1$ へ向かい、一意性により円を有限時刻で越えない。半径の極限は右辺の零点であり、角度は一周するので極限集合は円 $r=1$ である。$r>2$ では増加して、有限な極限があれば右辺の零点になるがそのような根はない。従って最大正時刻までに無限大へ逃げ、全正時刻に定義されないため、:ref[def-dyn-limit-set] の意味での $\omega$ 極限集合は定まらない。最大時刻に向かう有限の集積点もない。実際右辺は大きな $r$ で $r^5$ の定数倍以上なので、$\int^\infty r^{-5}\dd r<\infty$ により発散時刻は有限である。$r=1$ は両側から吸引、$r=2$ は両側へ反発する。
:::
::::

::::exercise{level=advanced}
$\dot x=y$、$\dot y=-x+2(1-x^4)y$ について Liénard の定理を使い、周期軌道の個数を求めよ。
:::solution
$f(x)=2(x^4-1)$、$g(x)=x$ なので $F=2x^5/5-2x$ は奇関数である。正の根は $a=5^{1/4}$ で、$0<x<a$ では負、$x\ge a$ では $F'=2(x^4-1)>0$ である。さらに $F\to\infty$ と $\int_0^\infty g=\infty$ が成り立つ。従って :ref[thm-dyn-lienard-cycle] により一意の安定な極限周期軌道がある。
:::
::::

::::exercise{level=advanced}
$F(x,y)=(x-x^3,-y)$ の全平衡点の指数を求め、三点を囲む単純閉曲線上の指数を求めよ。
:::solution
零点は $(-1,0),(0,0),(1,0)$ である。$DF=\diag(1-3x^2,-1)$ だから、両端で $\det DF=2>0$、原点で $\det DF=-1<0$ である。指数は順に $1,-1,1$ で、その和は $1$ となる。この指数は周期軌道に必要な値だが、実際の系は $V=x^4/4-x^2/2+y^2/2$ の負の勾配系なので周期軌道は存在しない。
:::
::::

::::exercise{level=advanced}
$F=(x(1-x-2y),y(2-3x-4y))$ に対し、第一象限内の閉軌道を排除せよ。
:::solution
$B=1/(xy)$ とすると $BF=((1-x-2y)/y,(2-3x-4y)/x)$ であり、発散は $-1/y-4/x$ となる。第一象限で負なので :ref[thm-dyn-bendixson-dulac] の仮定を満たす。$B$ が発散する境界の軸は定義域に含まれない。軸上ではそれぞれ一次元方程式であり、非定常解は右辺の符号が変わらない区間で単調なので周期をもたない。
:::

::::quiz
