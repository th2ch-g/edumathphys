## この章の目標

- Lagrange 形式、差分商、重心形式から補間多項式を計算する。
- 補間剰余と Lebesgue 定数から節点の選択を評価する。
- Hermite 補間と三次スプラインを構成する。
- 一様近似の交代条件と直交射影による二乗近似を証明する。

## Lagrange 補間と Newton の差分商

節点 $x_0,\ldots,x_n$ は相異なる実数とする。観測値 $y_j$ をすべて通る $n$ 次以下の多項式を作る。$j$ 番目の値だけを選ぶ基底は
$$
\ell_j(x)=\prod_{i\ne j}\frac{x-x_i}{x_j-x_i},\qquad I_nf(x)=\sum_j y_j\ell_j(x)
$$

である。ここで $I_nf$ と書くときは $y_j=f(x_j)$ である。$\ell_j(x_i)=\delta_{ij}$ なので条件を満たし、二つの解の差は次数 $n$ 以下で $n+1$ 個の零点を持つから零である。これを :term[Lagrange 補間]{en="Lagrange interpolation" yomi="らぐらんじゅほかん"} という。

:term[差分商]{en="divided difference" yomi="さぶんしょう"} は $f[x_i]=y_i$ と
$$
f[x_i,\ldots,x_j]=\frac{f[x_{i+1},\ldots,x_j]-f[x_i,\ldots,x_{j-1}]}{x_j-x_i}
$$

で定める。これは該当する補間多項式の最上位係数である。実際、左右の部分節点の補間を $P_{\rm right},P_{\rm left}$ とすると、全節点の補間は $((x-x_i)P_{\rm right}-(x-x_j)P_{\rm left})/(x_j-x_i)$ である。各節点で条件を満たすので一意性が使え、最高次の係数から再帰式を得る。従って節点を追加したときの差は以前の節点で消えることから、Newton 形式は
$$
I_nf(x)=\sum_{j=0}^n f[x_0,\ldots,x_j]\prod_{i<j}(x-x_i)
$$

である。差分商は節点の順序によらないが、Newton 基底の各項は並べ方で変わる。

$\omega_{n+1}(x)=\prod_i(x-x_i)$、$w_j=1/\omega_{n+1}'(x_j)$ とおく。$\ell_j(x)=w_j\omega_{n+1}(x)/(x-x_j)$、$\sum_j\ell_j=1$ から、節点以外では $I_nf=(\sum_j w_jy_j/(x-x_j))/(\sum_jw_j/(x-x_j))$ となる。これが :term[重心形式]{en="barycentric form" yomi="じゅうしんけいしき"} であり、節点上では $y_j$ を直接返す。重みを共通の定数でスケーリングでき、同じ節点で何度も評価するときに使える。

:::example[三点の補間]
$x=0,1,3$ で値 $1,2,10$ を与える。一次差分商は $1,4$、二次差分商は $(4-1)/3=1$ なので、$I_2f=1+x+x(x-1)=1+x^2$ である。
:::

### 節点を追加するときの更新

補間済みの $p$ に新しい節点 $x_{n+1}$ と値 $y_{n+1}$ を加える。旧節点で補正が消えるため、$p_{\rm new}-p$ は $\omega_{n+1}(x)=\prod_{i=0}^n(x-x_i)$ の定数倍である。新節点で値を合わせて
$$
p_{\rm new}(x)=p(x)+\frac{y_{n+1}-p(x_{n+1})}{\omega_{n+1}(x_{n+1})}\omega_{n+1}(x)
$$

と得る。これは Newton 形式に一項だけを加える計算である。重心重みも、旧 $w_i$ を $x_i-x_{n+1}$ で割り、新重みを $1/\omega_{n+1}(x_{n+1})$ にすればよい。新節点が旧節点に非常に近いとき、分母の小ささはデータのわずかな違いを大きな高次係数に変えうる。

:::example[差分商と重心形式で同じ値を得る]
節点 $(-1,0,2)$、値 $(2,1,5)$ とする。一次差分商は $-1,2$、二次差分商は $1$ である。よって $p(x)=2-(x+1)+(x+1)x=1+x^2$ である。重みは $(1/3,-1/2,1/6)$ で、$x=1$ では基底値が $(-1/3,1,1/3)$ になるから $p(1)=2$ である。節点 $3$ に値 $11$ を追加すると、旧値との差は $1$、$\omega_3(3)=4\cdot3\cdot1=12$ である。したがって補正は $(x+1)x(x-2)/12$、$p_{\rm new}(1)=11/6$ となる。旧三点では補正が零であることも確かめられる。
:::

### 等間隔データの差分

$x_i=x_0+ih$ で $h>0$ とする。前進差分を $\Delta f_i=f_{i+1}-f_i$ とすれば、差分商の再帰から $f[x_i,\ldots,x_{i+k}]=\Delta^k f_i/(k!h^k)$ である。実際、$k$ 階で二つの $(k-1)$ 階差分を引いて $kh$ で割れば、分子は $\Delta^k f_i$ となる。$s=(x-x_0)/h$ では Newton 形式は $\sum_{k=0}^n \binom{s}{k}\Delta^k f_0$ であり、$\binom{s}{k}=s(s-1)\cdots(s-k+1)/k!$ とする。

:::example[差分表で整数点と中点を求める]
$f(0),f(1),f(2),f(3)=(0,1,8,27)$ なら、一次差分は $(1,7,19)$、二次は $(6,12)$、三次は $6$ である。$s=3/2$ では $s+6s(s-1)/2+6s(s-1)(s-2)/6=27/8$ となる。これは $x^3$ の値を再現する。$s=4$ にも同じ式を代入すれば $64$ だが、その点は節点の範囲外である。一般の観測で同じ計算を行うときは、補間と外挿の誤差を区別する。
:::

:::example[五点の非等間隔データから差分表を作る]
$x=(-2,-1,0,2,3)$、値 $(4,0,1,3,5)$ とする。第 $j$ 欄の $i$ 行には $f[x_i,\ldots,x_{i+j}]$ を置く。一つ前の欄で隣り合う二値を引き、両端点の距離 $x_{i+j}-x_i$ で割る。距離は節点が一様な場合と違って行ごとにも変わる。右下の空欄は、その段数だけ後ろに節点を持たない場所である。

| $i$ | $x_i$ | $f[x_i]$ | 一次 | 二次 | 三次 | 四次 |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | $-2$ | $4$ | $-4$ | $\frac{5}{2}$ | $- \frac{5}{8}$ | $\frac{17}{120}$ |
| 1 | $-1$ | $0$ | $1$ | $0$ | $\frac{1}{12}$ |  |
| 2 | $0$ | $1$ | $1$ | $\frac{1}{3}$ |  |  |
| 3 | $2$ | $3$ | $2$ |  |  |  |
| 4 | $3$ | $5$ |  |  |  |  |

各欄の最初の値が Newton の係数である。最初の項は $4$、一次項は $-4(x+2)$ で、残りの項は旧節点で零になる。同じ多項式を Lagrange 表示でも確かめる。以下では基底を展開した形を表示した。$b_i$ は $x_i$ だけで $1$ となる。

$$
\begin{aligned}
b_0(x)&=\frac{x^{4}}{40} - \frac{x^{3}}{10} + \frac{x^{2}}{40} + \frac{3 x}{20}\\
b_1(x)&=- \frac{x^{4}}{12} + \frac{x^{3}}{4} + \frac{x^{2}}{3} - x\\
b_2(x)&=\frac{x^{4}}{12} - \frac{x^{3}}{6} - \frac{7 x^{2}}{12} + \frac{2 x}{3} + 1\\
b_3(x)&=- \frac{x^{4}}{24} + \frac{7 x^{2}}{24} + \frac{x}{4}\\
b_4(x)&=\frac{x^{4}}{60} + \frac{x^{3}}{60} - \frac{x^{2}}{15} - \frac{x}{15}\\
p(x)&=\frac{17 x^{4}}{120} - \frac{29 x^{3}}{60} + \frac{7 x^{2}}{120} + \frac{101 x}{60} + 1
\end{aligned}
$$

| 点 | データ | 評価値 |
| --- | --- | --- |
| $-2$ | $4$ | $4$ |
| $-1$ | $0$ | $0$ |
| $0$ | $1$ | $1$ |
| $2$ | $3$ | $3$ |
| $3$ | $5$ | $5$ |

この表示は計算を照合するためであり、評価の際に基底を全て展開する必要はない。例えば Newton 形式なら最高次の係数から始め、順に $(x-x_i)$ 倍して一つ前の係数を加える。展開した係数と丸めた節点を別々に扱うと、表の厳密な一致が最後の桁で崩れることがある。
:::

### 差分商を導関数の平均として表す

$f\in C^n$ とし、$x_0,\ldots,x_n$ がその定義区間にあるとする。$\Delta_n=\{s_j\ge0,\ \sum_{j=1}^n s_j\le1\}$、$s_0=1-\sum_{j=1}^n s_j$ とおくと
$$
f[x_0,\ldots,x_n]=\int_{\Delta_n}
  f^{(n)}\Big(\sum_{j=0}^n s_jx_j\Big)\,\dd s_1\cdots\dd s_n .
$$
$n=1$ は線分上の微積分である。一般に、$s_1,\ldots,s_{n-1}$ を固定し、$s_n$ を $0$ から $1-\sum_{j=1}^{n-1}s_j$ まで積分する。その方向の引数の微分は $x_n-x_0$ なので、$(x_n-x_0)$ を掛けた積分は、$s_0=0$ の面と $s_n=0$ の面での $f^{(n-1)}$ の積分の差である。帰納仮定により順に $f[x_1,\ldots,x_n]$ と $f[x_0,\ldots,x_{n-1}]$ であり、差分商の再帰で等式が従う。単体の体積は $1/n!$ である。これは最後の座標で断面積 $(1-s_n)^{n-1}/(n-1)!$ を積分して帰納的に求まる。従って差分商の絶対値は $\sup|f^{(n)}|/n!$ 以下であり、節点が重なるときにも積分側は連続に延長できる。この表示は、差分商を直接計算する減算に丸めが集中する場合でも、厳密値の大きさを見積もる基準になる。

:::example[三点における三次関数の二次差分商]
$f(x)=x^3$、節点 $-1,1,3$ とする。一次差分商は $1,13$ なので、二次は $(13-1)/4=3$ である。積分表示では $f''=6x$、単体 $\Delta_2$ の体積は $1/2$、三つの重心座標の積分は対称性から各 $1/6$ である。従って積分は $6(-1+1+3)/6=3$ となる。$x_0,x_1$ をともに $1$ へ近づけた場合、同じ計算で $f[1,1,3]=1+1+3=5$ となる。再帰でも $(f[1,3]-f'(1))/(3-1)=(13-3)/2=5$ と確かめられる。
:::

## 補間誤差と Runge 現象

:::theorem[補間剰余]{#thm-num-interpolation-error}
節点と評価点を含む区間で $f$ が $C^{n+1}$ なら、節点外の $x$ について
$$
f(x)-I_nf(x)=\frac{f^{(n+1)}(\xi)}{(n+1)!}\omega_{n+1}(x)
$$

となる $\xi$ がその区間内にある。
:::

:::proof
$E=f-I_nf$ として $E(t)-E(x)\omega_{n+1}(t)/\omega_{n+1}(x)$ を作る。この関数は $n+2$ 個の相異なる零点をもち、Rolle の定理を $n+1$ 回使うとその導関数がどこかで零になる。$I_nf$ の該当次数の導関数は零、$\omega_{n+1}^{(n+1)}=(n+1)!$ なので解けばよい。
:::

:::example[等間隔でも次数を増やせばよいわけではない]
$f(x)=1/(1+25x^2)$ を $[-1,1]$ の等間隔点で補間すると、端に近い部分で一様誤差が増大する。これを :term[Runge 現象]{en="Runge phenomenon" yomi="るんげげんしょう"} という。偶数 $n$ では $p=I_nf$ は偶関数なので $(1+25x^2)p(x)-1=Cx\omega_{n+1}(x)$ となる。$z=i/5$ を代入すると $C=-1/(z\omega_{n+1}(z))$ である。

端に最も近い二節点の中点 $x=1-1/n$ では $|\omega_{n+1}(x)|=(2/n)^{n+1}\prod_{j=0}^{n}|j-1/2|$ である。この積の対数を $n$ で割ると極限は $\log 2-1$ となる。実際、$j\ge1$ で $j-1/2$ と $j$ の比の対数の総和の絶対値は $\sum_{j=1}^n1/j$ 以下であり、残る $\log(n!)$ は $\log t$ の積分で挟める。一方 $n^{-1}\log|\omega_{n+1}(z)|$ は連続関数の Riemann 和なので $\int_0^1\log\sqrt{t^2+1/25}\,\dd t=(1/2)\log(26/25)-1+\arctan(5)/5$ に収束する。前者が後者より大きい。例えば $\log(26/25)<1/25$ と $\arctan(5)<\pi/2$ を使って確かめられる。従ってこの点列での誤差は指数的に増える。
:::

### 有理関数の厳密な剰余

$f(x)=1/(z-x)$ で $z$ が節点の区間外にあるとする。$p=I_n f$ とおけば $(z-x)p(x)-1$ は $\omega_{n+1}$ の定数倍である。次数が高々 $n+1$ で節点すべてに零点を持つからである。$x=z$ を入れると定数は $-1/\omega_{n+1}(z)$ なので
$$
f(x)-p(x)=\frac{\omega_{n+1}(x)}{(z-x)\omega_{n+1}(z)} .
$$

この表示では、実軸上での節点積と極での節点積の比を直接比べられる。

:::example[同じ二点でも中央の誤差が異なる]
$z=2$、$x=0$ とする。節点 $-1,1$ では $\omega_2(0)=-1,\ \omega_2(2)=3$ なので誤差は $-1/6$ である。節点を $\pm1/\sqrt2$ にすると節点積は $x^2-1/2$ で、誤差は $(-1/2)/(2(4-1/2))=-1/14$ となる。両者はこの一点での比較である。全区間の最大誤差を評価するときは、分母の $z-x$ も動くことに注意する。
:::

### 区分一次補間で次数を固定する

一セル $[x_i,x_{i+1}]$ の幅を $h_i$ とすると、二点補間には $|f(x)-I_1 f(x)|\le h_i^2 \sup|f''|/8$ が成り立つ。節点積の絶対値は中点で $h_i^2/4$ になり、剰余の $2!$ で割るからである。微分可能性を仮定しない場合には、補間値が両端値の凸結合であることから、誤差は連続度 $\omega_f(h_i)=\sup_{|x-y|\le h_i}|f(x)-f(y)|$ 以下である。閉区間の連続関数は一様連続なので最大セル幅を零にすれば収束する。

:::example[折点を節点に加える]
$f(x)=|x-1/3|$ を $[0,1]$ で区分一次補間する。折点を含むセルの左右長さを $\delta,h-\delta$ とすると、折点での補間値は $2\delta(h-\delta)/h$ である。他のセルでは $f$ 自体が一次なので厳密である。$h=1/4$ では $\delta=1/12$、誤差の最大は $1/9$ となる。折点 $1/3$ を節点に加えると、全セルで一次式が再現され、誤差は零になる。
:::

### 解析関数では楕円から剰余を評価できる

$T_m$ を $T_0=1,\ T_1=x,\ T_{m+1}=2xT_m-T_{m-1}$ で定める。余弦の加法公式から $T_m(\cos\theta)=\cos(m\theta)$ であり、その根は $x_j=\cos((2j+1)\pi/(2m))$（$0\le j<m$）である。$\rho>1$ とし、$z=(w+w^{-1})/2,\ |w|=\rho$ が描く曲線を Bernstein 楕円の境界とする。$f$ は閉楕円の近傍で正則とし、境界で $|f|\le M$ とする。境界の長さを $L$、境界と $[-1,1]$ の距離を $d>0$ とする。$m=n+1$ 個の $T_m$ の根を節点とすると、節点以外で
$$
f(x)-I_nf(x)=\frac{1}{2\pi i}\oint
\frac{f(z)\omega_m(x)}{(z-x)\omega_m(z)}\,\dd z
$$

である。実際、$z=x$ の留数は $f(x)$、各節点 $x_j$ での留数は $-f(x_j)\ell_j(x)$ であり、留数の和を取ればよい。節点でも両辺は連続なので成立する。Chebyshev の漸化式に $z=(w+w^{-1})/2$ を入れると $T_m(z)=(w^m+w^{-m})/2$ であり、$\omega_m=2^{1-m}T_m$ である。よって $|\omega_m(x)/\omega_m(z)|\le2/(\rho^m-\rho^{-m})$、積分の長さで評価して
$$
\|f-I_nf\|_\infty\le\frac{ML}{\pi d(\rho^m-\rho^{-m})}
$$

となる。楕円内に極が入ると留数に追加項が出るため、解析性を点検してから適用する。

別の近似は $F(w)=f((w+w^{-1})/2)$ の Laurent 展開から得られる。対称性 $F(w)=F(w^{-1})$ から係数 $a_{-k}=a_k$ であり、Cauchy の公式で $|a_k|\le M\rho^{-k}$（$k\ge0$）となる。従って $f(x)=a_0+2\sum_{k\ge1}a_kT_k(x)$ であり、次数 $n$ まで残したときの切捨て誤差は $2M\rho^{-n}/(\rho-1)$ 以下である。これにより最良近似誤差 $E_n(f)=\inf_{\deg p\le n}\|f-p\|_\infty$ にも同じ上界が得られる。

:::example[有理関数の剰余を節点の間まで再現する]
$f(x)=1/(2-x)$ を三点 $-1,0,1$ で補間する。Lagrange 基底で補間した $p$ と、極での値から導いた厳密剰余を比較する。節点積 $\omega_3$ の符号が変わると誤差の符号も変わるが、この区間では $2-x$ と $\omega_3(2)$ は正である。

$$
\begin{aligned}
p(x)&=\frac{x^{2}}{6} + \frac{x}{3} + \frac{1}{2}\\\omega_3(x)&=x^{3} - x\\f(x)-p(x)&=- \frac{x \left(x - 1\right) \left(x + 1\right)}{6 \left(x - 2\right)}
\end{aligned}
$$

| 点 | $f$ | $p$ | 誤差 |
| --- | --- | --- | --- |
| $-1$ | $\frac{1}{3}$ | $\frac{1}{3}$ | $0$ |
| $- \frac{3}{4}$ | $\frac{4}{11}$ | $\frac{11}{32}$ | $\frac{7}{352}$ |
| $- \frac{1}{2}$ | $\frac{2}{5}$ | $\frac{3}{8}$ | $\frac{1}{40}$ |
| $- \frac{1}{4}$ | $\frac{4}{9}$ | $\frac{41}{96}$ | $\frac{5}{288}$ |
| $0$ | $\frac{1}{2}$ | $\frac{1}{2}$ | $0$ |
| $\frac{1}{4}$ | $\frac{4}{7}$ | $\frac{19}{32}$ | $- \frac{5}{224}$ |
| $\frac{1}{2}$ | $\frac{2}{3}$ | $\frac{17}{24}$ | $- \frac{1}{24}$ |
| $\frac{3}{4}$ | $\frac{4}{5}$ | $\frac{27}{32}$ | $- \frac{7}{160}$ |
| $1$ | $1$ | $1$ | $0$ |

端の値も含めて表を追うと、節点における正確さはその間の最大値を決めないことが分かる。例えば $[0,1]$ では $x^3-x\le0$ であり、補間は元の関数より上にある。$[-1,0]$ では逆の符号である。区間外の $x=3/2$ は極に近く、同じ公式でも分母が小さくなる。外挿の値を使うときは、許す範囲でも剰余を評価する。
:::

## Chebyshev 点と Lebesgue 定数

前節の $T_m$ は :term[Chebyshev 多項式]{en="Chebyshev polynomial" yomi="ちぇびしぇふたこうしき"} であり、漸化式から $m\ge1$ の最高次係数は $2^{m-1}$ である。$m=n+1$ に対して $T_m$ の根 $x_j=\cos((2j+1)\pi/(2m))$ を :term[Chebyshev 点]{en="Chebyshev nodes" yomi="ちぇびしぇふてん"} という。

:::proposition[最小のモニック多項式ノルム]{#prop-num-cheb-monic}
$[-1,1]$ 上で $2^{1-m}T_m$ はすべての $m$ 次モニック多項式の中で一様ノルムが最小である。
:::

:::proof
ノルムがより小さいモニック多項式を引くと、$x=\cos(j\pi/m)$ で差の符号が交代する。差は高々 $m-1$ 次なのに $m$ 個の異なる零点をもつことになり、矛盾する。
:::

節点の値を絶対値 $\eta$ 以下だけ動かしたとき、補間の変化は $\eta\Lambda_n$ 以下である。:term[Lebesgue 定数]{en="Lebesgue constant" yomi="るべーぐていすう"} は $\Lambda_n=\max_x\sum_j|\ell_j(x)|$ である。最大点で節点摂動の符号を基底の符号に合わせれば上界を達成する。また任意の $n$ 次以下の $p$ に対し $f-I_nf=(f-p)-I_n(f-p)$ なので、最良近似誤差 $E_n(f)$ に対して $\|f-I_nf\|_\infty\le(1+\Lambda_n)E_n(f)$ である。

Chebyshev 根で $\Lambda_n=\order{\log(n+2)}$ を示す。$x=\cos\theta$、$\theta_j=(2j+1)\pi/(2m)$ とすると、$|T'_m(x_j)|=m/\sin\theta_j$ である。余弦の差の積表示から
$$
|\ell_j(\cos\theta)|\le
\frac{|\cos(m\theta)|}{m|\sin((\theta-\theta_j)/2)|}
\le\frac{\pi|\cos(m\theta)|}{m|\theta-\theta_j|}.
$$

第一不等式には $\sin\theta_j\le2\sin((\theta+\theta_j)/2)$ を使った。最も近い節点では $|\cos(m\theta)|\le m|\theta-\theta_j|$ なので寄与は高々 $\pi$ である。残りの節点は、最も近い節点から添字で $k$ 離れるごとに距離が $(k-1/2)\pi/m$ 以上である。よって片側ずつ調和和で抑えられる。

:::example[二つの Chebyshev 点]
$m=2$ の根は $\pm1/\sqrt2$ である。モニック節点多項式は $x^2-1/2$ でノルム $1/2$、端点 $\pm1$ を節点にすると $x^2-1$ でノルム $1$ になる。
:::

### 重心重みを節点の公式から求める

Chebyshev 根では $\omega_m=2^{1-m}T_m$ なので、重心重みは共通因子を除いて $(-1)^j\sin\theta_j$ である。実際、$T'_m(x_j)=m\sin(m\theta_j)/\sin\theta_j$ で $\sin(m\theta_j)=(-1)^j$ となる。端点を含む点 $x_j=\cos(j\pi/n)$ では、節点多項式は $(x^2-1)T_n'(x)$ に比例する。$T_n$ は $(1-x^2)T_n''-xT_n'+n^2T_n=0$ を満たす。これは $\cos(n\theta)$ を $x=\cos\theta$ で微分すれば従う。この式から内点で節点多項式の導関数は $n^2(-1)^j$ に比例する。端では積の微分により $\pm 2T_n'(\pm1)$ となり、絶対値は $2n^2$ である。従って重みは内点で交互に $\pm1$、両端は同符号規則の半分として使える。根と端点を含む点を取り違えると、重みの式は一致しない。

:::example[三点の照合]
$n=2$ の端点付きの節点は $1,0,-1$ であり、並び順での重みは $(1/2,-1,1/2)$ である。節点多項式が $x^3-x$ なので、その導関数は三点で $2,-1,2$、逆数が上の値に一致する。
:::

### 端での Lebesgue 関数と下界

Chebyshev 根について $x=1$ での基底の絶対値は
$$
|\ell_j(1)|=\frac{\sin\theta_j}{m(1-\cos\theta_j)}
            =\frac1m\cot(\theta_j/2).
$$
$0<\theta_j\le\pi/2$ なら $\cos(\theta_j/2)\ge1/\sqrt2$、$\sin(\theta_j/2)\le\theta_j/2$ だから、和は定数倍の $\sum_{j:\theta_j\le\pi/2}(2j+1)^{-1}$ 以上になる。この調和和は積分比較によって定数倍の $\log(m)$ 以上である。先の上界と併せると、最悪の節点データの増幅は対数程度に増える。$E_n(f)=o(1/\log(n+2))$ なら両者の積は零へ向かう。

:::example[中央の値と一様ノルムを区別する]
端点を含む Chebyshev 四点 $1,1/2,-1/2,-1$ を考える。$x=0$ での Lagrange 基底値は $(-1/6,2/3,2/3,-1/6)$ であり、絶対値の和は $5/3$ である。等間隔四点 $1,1/3,-1/3,-1$ では $(-1/16,9/16,9/16,-1/16)$ となり、この点の和は $5/4$ である。どの点で増幅が最悪かは節点配置によって違う。Chebyshev 根での下界も、中央でなく端点のデータの重みから得た。
:::

### Chebyshev 級数を後ろから評価する

$p(x)=\sum_{k=0}^n c_kT_k(x)$ を直接評価する代わりに、$b_{n+2}=b_{n+1}=0$ として $b_k=c_k+2xb_{k+1}-b_{k+2}$ を $k=n,\ldots,1$ の順に計算する。これが :term[Clenshaw 法]{en="Clenshaw algorithm" yomi="くれんしょうほう"} であり、$p(x)=c_0+xb_1-b_2$ である。実際、$c_k=b_k-2xb_{k+1}+b_{k+2}$ を和へ入れ、$b_j$ ごとの係数を集めると、$j\ge3$ は $T_j-2xT_{j-1}+T_{j-2}=0$ となる。$b_1$ の係数は $T_1=x$、$b_2$ は $T_2-2xT_1=-1$ であり、残りの境界項は初期値で零となる。したがって評価点ごとに二つの過去値だけを保持すればよい。

:::example[低次の和を定数個の記憶で評価する]
$p=2-T_1+3T_2+T_3$、$x=1/2$ とする。$2x=1$ なので後退の中間値は $b_3=1,b_2=4,b_1=2$ である。従って $p(1/2)=2+1-4=-1$ となる。直接に $T_1=1/2,T_2=-1/2,T_3=-1$ を入れても同じ値である。係数が Chebyshev 基底の規格化で与えられている場合、定数項を半分にする規約かどうかを先に確かめる。ここでは $c_0$ はすでに定数項そのものである。
:::

:::example[節点値の誤差がどこで強く現れるかを調べる]
四点の端点付き Chebyshev 節点 $1,1/2,-1/2,-1$ に対する基底を作る。行和は常に $1$ だが、各項の符号を打ち消さずに足した Lebesgue 関数は増えうる。特定の点で最大のデータ摂動を作りたいなら、その点での基底の符号に入力誤差の符号を揃える。

$$
\begin{aligned}
\ell_0(x)&=\frac{2 x^{3}}{3} + \frac{2 x^{2}}{3} - \frac{x}{6} - \frac{1}{6}\\
\ell_1(x)&=- \frac{4 x^{3}}{3} - \frac{2 x^{2}}{3} + \frac{4 x}{3} + \frac{2}{3}\\
\ell_2(x)&=\frac{4 x^{3}}{3} - \frac{2 x^{2}}{3} - \frac{4 x}{3} + \frac{2}{3}\\
\ell_3(x)&=- \frac{2 x^{3}}{3} + \frac{2 x^{2}}{3} + \frac{x}{6} - \frac{1}{6}
\end{aligned}
$$

| $x$ | $\ell_0$ | $\ell_1$ | $\ell_2$ | $\ell_3$ | 絶対値の和 |
| --- | --- | --- | --- | --- | --- |
| $-1$ | $0$ | $0$ | $0$ | $1$ | $1$ |
| $- \frac{3}{4}$ | $\frac{5}{96}$ | $- \frac{7}{48}$ | $\frac{35}{48}$ | $\frac{35}{96}$ | $\frac{31}{24}$ |
| $- \frac{1}{2}$ | $0$ | $0$ | $1$ | $0$ | $1$ |
| $- \frac{1}{4}$ | $- \frac{3}{32}$ | $\frac{5}{16}$ | $\frac{15}{16}$ | $- \frac{5}{32}$ | $\frac{3}{2}$ |

| $\frac{1}{4}$ | $- \frac{5}{32}$ | $\frac{15}{16}$ | $\frac{5}{16}$ | $- \frac{3}{32}$ | $\frac{3}{2}$ |

## Hermite 補間

:term[Hermite 補間]{en="Hermite interpolation" yomi="えるみーとほかん"} は各節点で値と指定次数までの導関数を一致させる。節点 $x_i$ で $0$ 次から $m_i-1$ 次まで指定し、$M=\sum_i m_i$ とする。条件をすべて零とした多項式は $\prod_i(x-x_i)^{m_i}$ で割り切れるので、次数 $M-1$ 以下なら零である。$M$ 次元の線形系の核が零なので解は存在して一意である。

値と一次微分を与える場合、基底は $H_i=(1-2\ell_i'(x_i)(x-x_i))\ell_i^2$ と $K_i=(x-x_i)\ell_i^2$ である。$j\ne i$ で両方二重零点をもち、$x_i$ では $(H_i,H_i')=(1,0)$、$(K_i,K_i')=(0,1)$ である。従って補間は $\sum_i(f(x_i)H_i+f'(x_i)K_i)$ となる。差分商形式では重複する節点の差分商を $f[x_i,\ldots,x_i]=f^{(r)}(x_i)/r!$ とする。これは Taylor 展開または差分商の Rolle による平均値表示から極限を取って得られる。

$f\in C^M$ が節点と評価点を含む区間に定義されているとする。評価点 $x$ が節点でなければ、剰余は :ref[thm-num-interpolation-error] の証明で零点を重複度込みで数えると $f^{(M)}(\xi)\prod_i(x-x_i)^{m_i}/M!$ となる。導関数を取るたびに、多重零点では重複度が一つ減り、異なる隣接零点の間では新しい零点が一つできる。このため零点の総数は高々一つしか減らない。節点では補間条件から誤差が零である。

:::example[両端で水平な補間]
区間 $[0,1]$ で値を $0,1$、導関数をともに零とする。多項式 $3x^2-2x^3$ が四条件を満たすので、これが一意の三次補間である。中点の値は $1/2$、導関数は $3/2$ である。
:::

### 区分 Hermite 補間で値の範囲を保つ

一セルの幅を $h$、端点値を $y_0<y_1$、傾きを $m_0,m_1$、割線傾きを $d=(y_1-y_0)/h$ とする。$s=(x-x_0)/h$ に関する三次式を Hermite の条件で構成して微分すると
$$
\frac{\dd p}{\dd x}=m_0(1-s)^2+2(3d-m_0-m_1)s(1-s)+m_1s^2
$$

となる。実際、右辺は端で $m_0,m_1$ となり、区間積分は $h(m_0+3d-m_0-m_1+m_1)/3=hd$ である。この三条件が二次の導関数を決める。$m_0,m_1\ge0$、$m_0+m_1\le3d$ ならこの式は非負で、補間は単調である。全セルで共有傾きを選べば $C^1$ の区分補間になる。ただし二階微分まで一致させる三次スプラインとは曲率の接続条件が異なる。

:::example[単調な三次曲線]
$h=1,y_0=0,y_1=1$ で $m_0=0,m_1=2$ とすると傾きは $2s(1-s)+2s^2=2s$ である。補間多項式は $s^2$ となり、端点値の間から出ない。
:::

### 重複節点の差分表を作る

一つの節点で値と微分を使うとき、差分表ではその節点を続けて二回書く。隣接する二点が一致する位置だけは割り算の代わりに $f'(x_i)$ を置く。三つ以上が同じときも、全て同じ節点の欄に $f^{(k)}(x_i)/k!$ を置く。相異なる近接節点の補間を考えると、全て同じ節点に近づく差分商は :ref[thm-num-interpolation-error] と同じ Rolle の議論で $f^{(k)}(\xi)/k!$ となり、その極限が指定値である。異なるまとまりでは分母が非零のままなので極限と差分商再帰を交換できる。得られた極限の多項式は補間点の値を保ち、各まとまりの低階差分商の極限で導関数の条件も保つ。

:::example[四つの条件を差分表で照合する]
$f(x)=1/(2-x)$ を $x=0,1$ で値と一次微分に合わせる。並び $0,0,1,1$ の一次欄は $1/4,1/2,1$、二次欄は $1/4,1/2$、三次欄は $1/4$ である。従って
$$
p(x)=\tfrac12+\tfrac14 x+\tfrac14 x^2+\tfrac14 x^2(x-1)
=\tfrac12+\tfrac14 x+\tfrac14 x^3.
$$

中点では $p(1/2)=21/32$、真値は $2/3$ なので誤差は $1/96$ である。$(2-x)p(x)-1$ を展開すると $-x^2(x-1)^2/4$ となる。この二重零点は値と微分の両方が一致することを別の方法で示している。
:::

:::example[三点の値と傾きから五次補間を作る]
$f=x^6-2x^4+x$ の値と傾きを $-1,0,2$ で与える。各節点に値用と傾き用の基底を一つずつ作る。いずれも他の節点で二重に零である。値用には傾きの補正を入れ、傾き用は節点で値が零になるように $(x-x_i)$ を掛ける。

| 節点 | 値 | 傾き |
| --- | --- | --- |
| $-1$ | $-2$ | $3$ |
| $0$ | $0$ | $1$ |
| $2$ | $34$ | $129$ |

$$
\begin{aligned}
H_0&=\frac{8 x^{5}}{27} - \frac{7 x^{4}}{9} - \frac{4 x^{3}}{9} + \frac{44 x^{2}}{27}\\
K_0&=\frac{x^{5}}{9} - \frac{x^{4}}{3} + \frac{4 x^{2}}{9}\\
H_1&=- \frac{x^{5}}{4} + \frac{3 x^{4}}{4} + \frac{x^{3}}{4} - \frac{7 x^{2}}{4} + 1\\
K_1&=\frac{x^{5}}{4} - \frac{x^{4}}{2} - \frac{3 x^{3}}{4} + x^{2} + x\\
H_2&=- \frac{5 x^{5}}{108} + \frac{x^{4}}{36} + \frac{7 x^{3}}{36} + \frac{13 x^{2}}{108}\\
K_2&=\frac{x^{5}}{36} - \frac{x^{3}}{12} - \frac{x^{2}}{18}\\
p(x)&=2 x^{5} + x^{4} - 4 x^{3} - 4 x^{2} + x\\
f(x)-p(x)&=x^{2} \left(x - 2\right)^{2} \left(x + 1\right)^{2}
\end{aligned}
$$

導関数と値を六条件で一致させるので $f-p$ は三つの二重因子を持つ。差の最高次係数は $1$、次数は六次であり、従って誤差は表示した積にそのまま一致する。$x=1$ では誤差は $(2)^2(1)^2(-1)^2=4$ である。ここでは端からの距離だけで誤差を判断できず、全節点からの距離の積を使う。傾きが近似データの場合は、この剰余に傾き用基底がそのデータ誤差を増幅する項を加える。
:::

### 単調 Hermite の傾きを選ぶ

正の割線傾き $d>0$ の一セルで、端の規格化傾きを $\alpha=m_0/d$、$\beta=m_1/d$ とする。既出の導関数を $d$ で割ると
$$
g(s)=\alpha(1-s)^2+2(3-\alpha-\beta)s(1-s)+\beta s^2 .
$$

従って $\alpha,\beta\ge0$ かつ $\alpha+\beta\le3$ は単調性の十分条件である。これは十分条件であって必要条件とは限らない。厳密に判定するには、$g(s)=A s^2+B s+C$ で $A=3(\alpha+\beta-2)$、$B=2(3-2\alpha-\beta)$、$C=\alpha$ として、$g(0),g(1)$ と、$A>0$ で頂点 $-B/(2A)\in(0,1)$ の場合の値 $C-B^2/(4A)$ を調べる。負の割線では全体の符号を反転して同じ条件を使う。割線が零で、セル内の補間を単調にしたいなら、両端が同じ値なのでセル全体を定数にし、端の傾きも零にする必要がある。

実用的な十分条件として、各内部節点で両隣の割線が同符号ならその符号付きの絶対値の小さい方を傾きに取り、異符号またはいずれかが零なら傾きを零とする。端では隣の割線を用いる。すると各セルで端の傾きの大きさはどちらも $|d|$ 以下なので、規格化の和は高々 $2$ であり十分条件を満たす。各節点で同じ傾きを左右から使うので全体は $C^1$ である。曲率や高次精度より過大な極値を避けたいときに使える。

:::example[端の傾きが大きいと単調性を失う]
$y_0=0,y_1=1,h=1$、$m_0=m_1=4$ なら $g(s)=4-18s+18s^2$ であり、中点の導関数は $-1/2$ である。値のデータは増加していてもこの三次式は途中で減る。$m_0=m_1=3$ のときは $\alpha+\beta=6$ だが $g(s)=3(2s-1)^2\ge0$ である。この二例は、傾きの和の条件で失敗することと、実際に単調でないことを区別する。
:::

## スプライン補間

多数の節点すべてを一本の多項式で通す代わりに、区間ごとに三次式を使う。:term[三次スプライン]{en="cubic spline" yomi="さんじすぷらいん"} はここでは各部分区間で三次以下で、全体で $C^2$ の関数である。$h_i=x_{i+1}-x_i>0$、$d_i=(y_{i+1}-y_i)/h_i$、二階導関数の節点値を $M_i$ とする。$s''$ は線形なので積分し、両端の値を合わせると
$$
s(x)=\frac{M_i(x_{i+1}-x)^3+M_{i+1}(x-x_i)^3}{6h_i}
+\left(y_i-\frac{M_i h_i^2}{6}\right)\frac{x_{i+1}-x}{h_i}
+\left(y_{i+1}-\frac{M_{i+1}h_i^2}{6}\right)\frac{x-x_i}{h_i}.
$$

節点 $i$ で左右の一階導関数を比較すると
$$
h_{i-1}M_{i-1}+2(h_{i-1}+h_i)M_i+h_iM_{i+1}=6(d_i-d_{i-1}).
$$

自然境界条件は $M_0=M_n=0$、固定境界条件は $s'(x_0),s'(x_n)$ を指定する。固定条件の左端行は $2h_0M_0+h_0M_1=6(d_0-s'(x_0))$、右端行は $h_{n-1}M_{n-1}+2h_{n-1}M_n=6(s'(x_n)-d_{n-1})$ である。いずれも厳密対角優位なので、斉次方程式の最大成分の行を取れば解は零しかなく、一意に解ける。

真の導関数を固定した等間隔節点で $f\in C^4$ とすると四次の一様収束が得られる。$M_i=f''(x_i)$ を代入した内点の式の残差は $\order{h^3}\|f^{(4)}\|_\infty$ である。実際、$f''(x_i\pm h)=f''(x_i)\pm hf'''(x_i)+\order{h^2}$、$6(d_i-d_{i-1})=6hf''(x_i)+\order{h^3}$ である。端点行でも $f(x_0+h)$ の三次 Taylor 展開で同じ上界を得る。最大誤差成分の行では対角優位の差が少なくとも $h$ なので $\max_i|M_i-f''(x_i)|=\order{h^2}$ となる。線形補間の剰余から $\|s''-f''\|_\infty=\order{h^2}$ である。各セルで $s-f$ は両端で零だから、二階微分の最大値 $B$ に対して $|s-f|\le B(x-x_i)(x_{i+1}-x)/2$ である。これは二次関数を加減して凸性を使えば従い、$\|s-f\|_\infty=\order{h^4}$ を与える。自然条件を使う場合、真の $f''$ が端点で零かどうかが境界の誤差に影響する。

:::example[自然条件で一つの内点]
$(0,0),(1,1),(2,0)$ では $4M_1=-12$ なので $M_1=-3$ である。最初のセルでは $s(x)=3x/2-x^3/2$ となる。特に $s(1/2)=11/16$ であり、直線補間の $1/2$ より高い。
:::

### 局所台を持つ三次 B-spline の一例

等間隔の無限格子を単位幅に規格化する。$B_0$ を $[0,1)$ の指示関数とし、$B_j(t)=\int_0^1B_{j-1}(t-s)\,\dd s$ とする。$B_j$ は非負で台が $[0,j+1]$ に入り、$j\ge1$ で次数 $j$ の区分多項式である。実際、再帰式を $t-1$ から $t$ までの積分として微分すると $B_j'=B_{j-1}(t)-B_{j-1}(t-1)$ になる。$B_1$ は連続な三角形であり、帰納的に $B_3$ は $C^2$ である。切断冪で書くと
$$
B_j(t)=\frac1{j!}\sum_{k=0}^{j+1}(-1)^k{j+1\choose k}(t-k)_+^j
\quad(j\ge1)
$$

である。$j=1$ は三角形の式であり、積分では階乗が一段増え、$s=0,1$ の差から二項係数が Pascal の公式で更新される。平行移動を足すと $\sum_{k\in\Z}B_j(t-k)=1$ である。$j=0$ では各点で一つの指示関数だけが $1$、帰納段では有限個の和と積分を交換すればよい。

この基底を格子幅 $h$ に移して $B_3(x/h-k)$ とすれば、一つの点に寄与する係数は高々四個である。係数が節点値そのものになる帽子関数とは違い、三次の節点値は複数係数の組み合わせになる。無限一様格子の節点 $x=ih$ では $B_3(1),B_3(2),B_3(3)=(1,4,1)/6$ なので、節点条件はこの三点の係数を結ぶ帯行列になる。有限区間では端の基底や境界条件を追加する必要があり、自然条件の連立方程式と同じ補間かどうかはその条件で決まる。

:::example[一つの係数の影響範囲]
正規化した格子で $B_3$ だけを係数 $1$ とすると、$t=0,1,2,3,4$ の値は $(0,1,4,1,0)/6$ である。他のすべての格子点で零であり、連続な関数としても $[0,4]$ の外では零である。この局所性によって、一つの基底係数の誤差が離れた場所へ直接広がることを防げる。
:::

### 自然スプラインは曲げエネルギーを最小化する

節点値を満たす $H^2(a,b)$ の関数 $v$ に対し、自然三次スプライン $s$ は $\int_a^b |v''|^2\,\dd x$ を最小にする。$r=v-s$ とおくと $r(x_i)=0$ である。各セルで部分積分すると
$$
\int_{x_i}^{x_{i+1}}s''r''\,\dd x
=[s''r']_{x_i}^{x_{i+1}}-s'''|_{(x_i,x_{i+1})}\,[r]_{x_i}^{x_{i+1}} .
$$

一次元で $H^2$ の関数とその一階導関数は連続な代表を持つ。従って二項目は節点値により零で、第一項を全セルで足すと内部では $s''$ と $r'$ の連続性により相殺し、両端では自然条件で消える。よって $\int |v''|^2=\int|s''|^2+\int |r''|^2$ となる。等号なら $r$ は一次式で、二つ以上の相異なる節点で零なので恒等的に零である。

:::example[不等間隔で接線をつなぐ]
節点 $(0,1,3)$、値 $(0,1,0)$ とすると $h_0=1,h_1=2$、$d_0=1,d_1=-1/2$ なので $6M_1=-9$ である。$s''$ は $0$ から $-3/2$、次いで $0$ まで線形に変わる。左の一階微分の端値は $1+(2M_1+M_0)/6=1/2$、右からの値も $-1/2-2(2M_1+M_2)/6=1/2$ である。曲げエネルギーは各セルで $h_i(3/2)^2/3$ を加えた $9/4$ となる。直線をセルごとにつなぐと傾きが節点で跳び、ここで最小化している $H^2$ の候補には入らない。
:::

### 不等間隔の B-spline を差分商から導く

狭義に増加する節点列 $(t_i)_{i\in\Z}$ を取り、$i\to\pm\infty$ で $t_i\to\pm\infty$ とする。次数 $p$ の局所基底を
$$
N_{i,p}(x)=(t_{i+p+1}-t_i)[t_i,\ldots,t_{i+p+1}]\big((t-x)_+^p\big)
$$

と書く。差分商は $t$ の関数として取る。$p=0$ では $(t-x)_+^0$ を $t>x$ の指示関数とし、$N_{i,0}$ は $[t_i,t_{i+1})$ の指示関数である。$h(t)=(t-x)_+^{p-1}$ を用いると、差分商の重心表示から
$$
[a_0,\ldots,a_k]\big((t-x)h(t)\big)
=(a_0-x)[a_0,\ldots,a_k]h+[a_1,\ldots,a_k]h
$$

となる。$t-x=(a_0-x)+(t-a_0)$ と分けると、第二項の $t-a_0$ は $a_0$ で零になり、他の項ではその因子が分母から相殺するためである。$L=[t_i,\ldots,t_{i+p}]h$、$R=[t_{i+1},\ldots,t_{i+p+1}]h$ とおけば再帰により $(t_{i+p+1}-t_i)[t_i,\ldots,t_{i+p+1}]h=R-L$ である。上の恒等式に入れて
$$
N_{i,p}(x)
=\frac{x-t_i}{t_{i+p}-t_i}N_{i,p-1}(x)
+\frac{t_{i+p+1}-x}{t_{i+p+1}-t_{i+1}}N_{i+1,p-1}(x)
$$

を得る。これが Cox–de Boor の再帰である。各子の台に限れば重みは非負なので、帰納的に非負で台は $[t_i,t_{i+p+1}]$ に入る。全 $i$ で足すと同じ子に付く二つの係数は和 $1$ であり、従って全基底の和は常に $1$ である。切断 $p$ 次式の有限和なので $p\ge1$ で $C^{p-1}$ である。節点の重複を許す場合、評価点 $x$ が節点以外なら合流差分商は重複した節点での $t$ 微分を使う。重複度 $m\le p+1$ では最小の切断べきが $p-m+1$ になるため、$m\le p$ のとき $C^{p-m}$ の接続が得られる。$m=p+1$ の節点上では右側の極限を使う。この規約は、再帰で半開区間の指示関数を使い、退化区間と分母が零になる項を零とすることに対応する。

:::example[不等幅の区間を三つまたぐ二次基底]
$t_i,\ldots,t_{i+3}=0,1,3,4$ とする。上の再帰で、台 $[0,4]$ の内部での $N_{i,2}$ は順に
$$
\frac{x^2}{3}\quad(0\le x\le1),\qquad
\frac{-x^2+4x-2}{3}\quad(1\le x\le3),\qquad
\frac{(4-x)^2}{3}\quad(3\le x\le4)
$$

である。$x=1,3$ で値は $1/3$、傾きはそれぞれ $2/3,-2/3$ で左右から一致する。中央 $x=2$ では $2/3$ である。これは一つの基底であり、全基底の和を作るには同じ $x$ を含む他の台の基底も足す。等間隔で得た $(1,4,1)/6$ の値をそのまま異なる間隔に移すことはできず、重みは実際の節点差で作る。
:::

:::example[不等間隔の自然スプラインを行列から復元する]
節点 $0,1,2,4,5$、値 $0,1,-1,2,0$ から自然スプラインを作る。幅は $(1,1,2,1)$ である。内点では一階微分の接続から得た三重対角を使い、端の二行は $M_0=M_4=0$ をそのまま置く。$M$ を求めた後、セルごとに $s''$ を線形に補間し、積分定数を両端で合わせる。

| 接続点 | $s(x_i)$ | $s'(x_i)$ | $s''(x_i)$ |
| --- | --- | --- | --- |

### 周期条件と端の第三微分の条件

周期のデータで $y_n=y_0$ とし、$s'(x_n)=s'(x_0)$ と $s''(x_n)=s''(x_0)$ を課す。$M_n=M_0$ を使い、$M_0$ に対する行は前半の内部条件を端で環状に適用して
$$
h_{n-1}M_{n-1}+2(h_{n-1}+h_0)M_0+h_0M_1=6(d_0-d_{n-1})
$$

となる。$n\ge3$ ならこの行と内部行は循環三重対角で、対角の絶対値が他の和より大きい。従って最大成分の行で斉次解が零と分かり、周期スプラインが一意に求まる。値だけを周期にしても微分の接続を課さないなら、端では滑らかな周期延長にならない。

最初の内点と最後の内点で $s'''$ も接続する条件を not-a-knot 条件という。最初では $(M_1-M_0)/h_0=(M_2-M_1)/h_1$ であり、最後は末尾二セルで同じ式である。三つの導関数と値が同じ点で一致すれば三次多項式は同じなので、最初の二セルを事実上一つの三次式にする条件である。$n=3$ の四点では両方の接続条件で全セルの三次式が一つになり、その一意性は通常の三次補間から従う。境界の二階微分が与えられないときに使えるが、端の近似の問題を自然条件と同じには扱えない。

$n\ge4$ の不等間隔格子でも一意である。左端で $a=h_0,\ b=h_1$ と置き、$M_0=(1+a/b)M_1-(a/b)M_2$ を最初の内点の式に代入する。すると $M_1$ の係数は $3a+2b+a^2/b$、$M_2$ の係数は $b-a^2/b$ である。前者は後者の絶対値より大きい。右端でも向きを反転して同じ計算ができ、残る内点行は元から厳密対角優位なので、$M_1,\ldots,M_{n-1}$ が一意に定まる。$M_0,M_n$ は消去した端点条件から戻せる。

:::example[境界を変えると三次多項式を再現できるかが変わる]
$x_i=0,1,2,3$ で $y_i=x_i^3$ とする。not-a-knot では一つの三次式なので $x^3$ が厳密に戻る。真の端傾き $0,27$ を固定しても $x^3$ が条件を満たすから同じである。一方自然条件では $M_0=M_3=0$、$4M_1+M_2=36$、$M_1+4M_2=72$ から $M_1=24/5,M_2=84/5$ となる。真の最終二階微分は $18$ なので、端の条件が違う。第一セルでの自然スプラインは $x/5+4x^3/5$、$x=1/2$ の値は $1/5$ であり、真値 $1/8$ と異なる。セル数や次数が同じでも、近似対象が満たす境界の情報によって再現性が変わる。
:::

## 最良一様近似と Chebyshev の交代定理

:::theorem[交代条件]{#thm-num-alternation}
実連続関数 $f$ を閉区間 $[a,b]$（$a<b$）上で考える。高々 $n$ 次の実多項式による最良一様近似 $p$ は存在し、一意である。$f\ne p$ のとき、$p$ が最良である必要十分条件は、$n+2$ 個の増加点列で誤差 $f-p$ が $\pm\|f-p\|_\infty$ を交互に取ることである。
:::

:::proof
最小化列 $p_k$ の一様ノルムは有界とできる。適当な固定 $n+1$ 点での値が有界なので、対応する Lagrange 表示で係数が有界である。収束部分列の極限が最小値を取る。

交代点があれば、より小さい誤差を与える $q$ との差 $q-p$ はそこで交代する狭義の符号をもつ。従って $n+1$ 零点が必要で次数に反する。逆に最大誤差の正負の集合は互いに離れたコンパクト集合である。交代点が $n+2$ 個なければ、左から見た最大誤差集合は高々 $n+1$ 組の同符号の連続した並びに分かれる。実際、符号が変わるたびに一つずつ点を選べ、正負集合間の正の距離により有限回で終わる。各組の間の空隙に一つずつ単根を置いた次数 $n$ 以下の多項式 $q$ は、全最大点で誤差と同じ符号を持つよう全体の符号を選べる。最大点の近傍でも同符号で $|q|$ は正に下から抑えられる。その外のコンパクト集合では誤差の絶対値が最大値より一様に小さい。従って十分小さい $\epsilon>0$ で $p+\epsilon q$ が誤差を減らすので最良性に反する。

最良近似が二つあるなら平均も最良である。平均の誤差が最大絶対値を取る交代点では、両者の誤差が同符号で同じ最大絶対値を取る。従って二つの多項式はそこで一致し、次数から全体で一致する。誤差が零の場合も一意性は明らかである。
:::

:::example[二次項を一次以下で近似]
$[-1,1]$ で $x^2$ に対し $p=1/2$ を引くと、誤差は $-1,0,1$ の点で $+1/2,-1/2,+1/2$ となる。三点の交代から最良の一次以下の近似である。
:::

### 交代を方程式にして誤差を挟む

増加する $n+2$ 点 $t_i$ で $p(t_i)+(-1)^i E=f(t_i)$ と置く。$w_i=1/\prod_{j\ne i}(t_i-t_j)$ を掛けて足すと $\sum_i w_i p(t_i)=0$ である。$n+1$ 次の Lagrange 補間で、$p$ の最高次係数が零だからである。よって
$$
E=\frac{\sum_i w_i f(t_i)}{\sum_i (-1)^i w_i}.
$$

分母の各項は共通符号なので零にならない。この $E$ を使って残りの $p(t_i)$ を求めれば、補間の最高次係数は零になり、次数は $n$ 以下である。任意の近似 $q$ で $\|f-q\|_\infty<|E|$ なら $q-p$ はこの点で交代符号を持ち、次数に矛盾する。従って最良誤差は $|E|$ 以上、候補 $p$ の最大誤差以下である。

:term[Remez 法]{en="Remez algorithm" yomi="れめつほう"} の交換を一つずつ行う形では、$|E|>0$ とし、$|f-p|$ が $|E|$ より大きい点 $t$ を探す。$t$ が二つの指定点の間なら、両隣のうち誤差の符号が $t$ と同じ点を $t$ に替える。$t$ が並びの外なら、隣接点と同符号のときは隣接点を替え、逆符号のときは $t$ を追加して反対側の端点を外す。こうすると新しい点列で旧誤差の符号が交代し、各点での絶対値は少なくとも $|E|$、新しい一点ではそれより大きい。

新しい点列で交代方程式を解き直すと、$E$ の公式の分子に $f-p$ を使っても同じ値が出る。旧 $p$ の次数が $n$ 以下なので $\sum_i w_i p(t_i)=0$ だからである。従って新しい $|E|$ は新しい点列上の旧誤差の絶対値を $|w_i|$ で平均した値となり、旧 $|E|$ より大きい。この下界と現在の $\|f-p\|_\infty$ の差が指定精度以下になれば停止できる。$E=0$ の場合は符号の交換規則を適用できないので、$f=p$ を確認するか、非零の交代値が出る点列を選び直す。

:::example[一次近似の交代点を移動する]
$[0,1]$ で $f(x)=x^3$ とし、点 $0,1/2,1$ の誤差を $(E,-E,E)$ とする。両端から $p(x)=x-E$、中央から $E=3/16$ となる。誤差の微分は $3x^2-1$ なので、負の極値は $1/\sqrt3$ にある。中央点をそこへ移して方程式を解くと $E=1/(3\sqrt3)$ となる。両端とこの極値で絶対値が揃い、他の点では微分の符号からその範囲内にある。従って $p=x-1/(3\sqrt3)$ は最良近似である。
:::

:::example[交代点を指定して上界と下界を読む]
$f=x^4+x^3$ を $[-1,1]$ で二次以下に近似する。まず試しに四点 $-1,-1/2,1/2,1$ を選び、誤差を $E,-E,E,-E$ とする。連立系の未知数は三係数と $E$ である。解の多項式と誤差式を得たら、指定した点以外で極値を取るかを見る。

$$
\begin{aligned}
p(x)&=\frac{5 x^{2}}{4} + \frac{3 x}{4} - \frac{1}{4}\\
E&=- \frac{1}{4}\\
f(x)-p(x)&=x^{4} + x^{3} - \frac{5 x^{2}}{4} - \frac{3 x}{4} + \frac{1}{4}\\
(f-p)^\prime(x)&=4 x^{3} + 3 x^{2} - \frac{5 x}{2} - \frac{3}{4}
\end{aligned}
$$

| $x_i$ | 指定した交代誤差 | 代入での誤差 |
| --- | --- | --- |
| $-1$ | $- \frac{1}{4}$ | $- \frac{1}{4}$ |
| $- \frac{1}{2}$ | $\frac{1}{4}$ | $\frac{1}{4}$ |
| $\frac{1}{2}$ | $- \frac{1}{4}$ | $- \frac{1}{4}$ |
| $1$ | $\frac{1}{4}$ | $\frac{1}{4}$ |

この四点の交代は最適誤差の下界を与える。例えば別の次数二の多項式で全区間の誤差が $|E|$ より小さいと、差はこの四点で三回符号を変えるので矛盾する。一方、$|E|$ を達成したことを示すには区間内のすべての極値も調べる。実装では誤差の微分の根を求め、現在の点以外の大きな極値を入れ替える。交代の連立系は、それ自体では全区間の保証にならない。
:::

### 近似誤差の上界を Bernstein 多項式から作る

連続な $f$ を $[0,1]$ で考え、
$$
B_n f(x)=\sum_{j=0}^n f(j/n)\binom nj x^j(1-x)^{n-j}
$$

とする。重みは非負で和 $1$ であり、二項分布の $K$ を使うと $B_n f(x)=\mathbb E f(K/n)$ である。$\mathbb E(K/n)=x$、$\operatorname{Var}(K/n)=x(1-x)/n\le1/(4n)$ である。$|K/n-x|\le\delta$ の部分では誤差は連続度 $\omega_f(\delta)$ 以下、他では $2\|f\|_\infty$ 以下であり、後者の確率は Chebyshev の不等式で $1/(4n\delta^2)$ 以下である。従って
$$
\|B_n f-f\|_\infty\le\omega_f(\delta)+\frac{\|f\|_\infty}{2n\delta^2}
$$

である。$\delta=n^{-1/4}$ とすれば右辺は零に向かい、構成的な一様多項式近似が得られる。$f$ が Lipschitz 定数 $L$ を持つ場合、期待絶対値を分散の平方根で抑えて $L/(2\sqrt n)$ と改良できる。最良近似誤差 $E_n$ はいずれもこの構成例以下である。

:::example[二次関数は再現しないが誤差を計算できる]
$f(x)=x^2$ なら $B_n f=x^2+x(1-x)/n$ である。二項の二乗平均は平均二乗と分散の和なのでこの式が得られる。最大誤差は中央で $1/(4n)$ である。$n\ge2$ の最良近似誤差は零であるから、Bernstein の構成を最良近似そのものと見なすと誤る。正の重みと一様な収束の証明を与える点が、この構成の役割である。
:::

## 直交多項式と最小二乗近似

$w$ は有限区間 $[a,b]$ で可積分でほとんど至るところ正とし、実関数に対し $\inner{f}{g}_w=\int_a^b f g w\,\dd x$ を内積とする。$1,x,\ldots$ を Gram–Schmidt で直交化したものが :term[直交多項式]{en="orthogonal polynomials" yomi="ちょっこうたこうしき"} である。$f\in L^2([a,b],w\,\dd x)$ とする。モニックな $p_k$ を使うと、$f$ の二乗誤差を最小にする多項式は $\sum_{k=0}^n p_k\inner{f}{p_k}_w/\inner{p_k}{p_k}_w$ である。残差が各基底に直交し、Pythagoras の等式が成立するからである。複素関数を扱う場合には $g$ を共役して、第 1 変数に関して線形な内積を用いる。

$x p_k$ は次の次数までの基底で展開する。$j<k-1$ では $\inner{xp_k}{p_j}_w=\inner{p_k}{xp_j}_w=0$ なので、三項漸化式 $p_{k+1}=(x-a_k)p_k-b_kp_{k-1}$ を得る。係数は $a_k=\inner{xp_k}{p_k}_w/\|p_k\|_w^2$、$b_k=\|p_k\|_w^2/\|p_{k-1}\|_w^2$ である。後者は $xp_{k-1}$ の最高次係数が $1$ であることによる。この直交性を [数値積分](/math/numerical-analysis/numerical-integration/) で節点の選択に使う。

:::example[一様近似との違い]
$[-1,1]$、$w=1$ で $x^2$ を一次以下で最小二乗近似すると、$1,x$ への射影係数は $1/3,0$ である。従って一様近似の定数 $1/2$ とは異なる。残差 $x^2-1/3$ はモニックな二次の直交多項式であり、ノルム二乗は $8/45$ である。
:::

### Rodrigues の式で Legendre 多項式を作る

$[-1,1]$ の重み $1$ に対し
$$
P_n(x)=\frac{1}{2^n n!}\frac{\dd^n}{\dd x^n}(x^2-1)^n
$$

とおく。最高次係数は $\kappa_n=(2n)!/(2^n(n!)^2)>0$ である。次数 $n-1$ 以下の任意の $q$ に対して $\int P_n q$ を $n$ 回部分積分すると、$(x^2-1)^n$ が両端で $n$ 重の零を持つので境界項は消え、$q^{(n)}=0$ から直交する。$q=P_n$ として同じ計算を行えば $\|P_n\|^2=\kappa_n 2^{-n}J_n$、$J_n=\int_{-1}^1(1-x^2)^n\,\dd x$ である。$x(1-x^2)^n$ の端点の差は $n\ge1$ で零だから、微分の積分により $J_n=2n(J_{n-1}-J_n)$ を得る。$J_0=2$ と合わせて $\kappa_n 2^{-n}J_n=2/(2n+1)$ となる。

:::example[四次項から二次以下を取り出す]
$P_0=1,\ P_2=(3x^2-1)/2,\ P_4=(35x^4-30x^2+3)/8$ なので、係数を比較すると
$$
x^4=\tfrac15P_0+\tfrac47P_2+\tfrac8{35}P_4.
$$

次数 $2$ 以下への射影は $(6/7)x^2-3/35$ である。残差の二乗ノルムは $(8/35)^2(2/9)=128/11025$ となる。ここで空間には奇数次の $P_1$ も含まれるが、偶関数との内積は零である。係数を得た後のノルム計算に相互項が現れないのが、直交基底を選ぶ利点である。
:::

### 直交多項式の射影核と評価の条件

正規直交多項式を $p_j$、三項漸化式の隣接係数を $a_{j+1}>0$ とする。$K_n(x,y)=\sum_{j=0}^n p_j(x)p_j(y)$ とおく。三項式 $x p_j(x)$ に $p_j(y)$ を掛け、$x,y$ を入れ替えたものを引いて $j=0,\ldots,n$ で足す。対角係数の項はそれぞれ消え、内部の隣接項も隣の添字と相殺する。残るのは
$$
(x-y)K_n(x,y)=a_{n+1}
\big(p_{n+1}(x)p_n(y)-p_n(x)p_{n+1}(y)\big)
$$

である。これが Christoffel–Darboux の公式である。$y\to x$ の極限で $K_n(x,x)=a_{n+1}(p'_{n+1}p_n-p_n'p_{n+1})(x)$ を得る。任意の $q\in\mathcal P_n$ に対し $\inner{K_n(x,\cdot)}{q}_w=q(x)$ である。$q$ を基底展開し、各基底に対する積分で $p_j(x)$ だけが残るからである。従って $|q(x)|\le\sqrt{K_n(x,x)}\|q\|_w$ であり、$q$ を $K_n(x,\cdot)$ の倍数にすれば等号となる。二乗ノルムが小さいときの点評価を保証したいなら、この評価汎関数のノルムを用いる。

:::example[値を一つ指定したときの最小ノルム]
$[-1,1]$ の重み $1$、$n=2$ とする。Legendre の係数から
$$
K_2(0,x)=\tfrac12+\tfrac52 P_2(0)P_2(x)=\frac{9-15x^2}{8}
$$

となる。従って $q(0)=1$ のもとでのノルム二乗の最小値は $1/K_2(0,0)=8/9$ であり、それを達成する多項式は $q=1-5x^2/3$ である。直接に $q^2=1-(10/3)x^2+(25/9)x^4$ を積分しても $8/9$ となる。点評価の条件に使われた同じ核を、求積の重みを求める際にも利用できる。
:::

:::example[高次の観測関数を Legendre 係数へ分解する]
$f=x^6+2x^5-x^3+3x^2$ を重み $1$ の $[-1,1]$ で扱う。次数 $d$ の係数は $(2d+1)\int fP_d/2$ であり、$d$ 以下へ射影した残差の二乗ノルムはそれより高い添字の寄与だけを足す。表の係数は基底を正規直交にした場合でなく、$P_d(1)=1$ の規約である。

| 次数 $d$ | $P_d(x)$ | $\int fP_d$ | 係数 | 次数 $d$ 以下への残差二乗 |
| --- | --- | --- | --- | --- |
| 0 | $1$ | $\frac{16}{7}$ | $\frac{8}{7}$ | $\frac{819514}{315315}$ |
| 1 | $x$ | $\frac{6}{35}$ | $\frac{9}{35}$ | $\frac{4028072}{1576575}$ |
| 2 | $\frac{3 x^{2}}{2} - \frac{1}{2}$ | $\frac{104}{105}$ | $\frac{52}{21}$ | $\frac{17928}{175175}$ |
| 3 | $\frac{5 x^{3}}{2} - \frac{3 x}{2}$ | $\frac{44}{315}$ | $\frac{22}{45}$ | $\frac{19328}{567567}$ |
| 4 | $\frac{35 x^{4}}{8} - \frac{15 x^{2}}{4} + \frac{3}{8}$ | $\frac{16}{231}$ | $\frac{24}{77}$ | $\frac{77824}{6243237}$ |
| 5 | $\frac{63 x^{5}}{8} - \frac{35 x^{3}}{4} + \frac{15 x}{8}$ | $\frac{32}{693}$ | $\frac{16}{63}$ | $\frac{512}{693693}$ |
| 6 | $\frac{231 x^{6}}{16} - \frac{315 x^{4}}{16} + \frac{105 x^{2}}{16} - \frac{5}{16}$ | $\frac{32}{3003}$ | $\frac{16}{231}$ | $0$ |

最後の行では元の $f$ が次数六なので誤差は零になる。途中では、係数の大小をそのまま残差への寄与として読まず、基底の $\|P_d\|^2=2/(2d+1)$ を掛ける。例えば奇数次数を使わない近似では $f$ の偶部分だけが寄与し、偶部分を何次まで増やしても奇部分の誤差は残る。点ごとの誤差の最大を比較するときは、直交性が直接与えるこの表の $L^2$ 誤差とは別に評価する。
:::

### Chebyshev の重みを選ぶと Fourier 射影になる

$w(x)=(1-x^2)^{-1/2}$、$[-1,1]$ とする。$x=\cos\theta$ と置くと $w(x)|\dd x|=\dd\theta$ であり、$T_k$ 同士の内積は $\int_0^\pi \cos(k\theta)\cos(\ell\theta)\,\dd\theta$ となる。積和公式により $k\ne\ell$ で零、二乗ノルムは $k=0$ で $\pi$、$k>0$ で $\pi/2$ である。従って Chebyshev の最小二乗係数は偶延長した $f(\cos\theta)$ の余弦係数である。この重みは端に近づくと大きくなるため、区間全体で一様な重みを使う Legendre とは同じ目的を測らない。

:::example[同じ関数でも重みで直交射影が変わる]
$f=x^4$ では $T_2=2x^2-1$、$T_4=8x^4-8x^2+1$ から $x^4=(3T_0+4T_2+T_4)/8$ である。二次以下への Chebyshev 射影は $x^2-1/8$、残差の Chebyshev ノルム二乗は $(1/8)^2(\pi/2)=\pi/128$ である。一様重みの二次以下への射影は $(6/7)x^2-3/35$ であり、こちらの残差ノルムは一様測度で最小になる。二つの残差ノルムを比較するなら、重み付きと無しのどちらの積分を使うかを揃える。
:::

## 演習問題

::::exercise{level=basic}
$(0,1),(2,5)$ を通る一次補間を求めよ。

:::solution
差分商は $(5-1)/2=2$ なので $1+2x$ である。
:::
::::

::::exercise{level=basic}
$0,1,2$ における $f(x)=x^3$ の二次差分商を求めよ。

:::solution
一次差分商は $1,7$ だから二次差分商は $(7-1)/2=3$ である。
:::
::::

::::exercise{level=basic}
$[-1,1]$ の両端で $x^2$ を直線補間し、最大誤差を求めよ。

:::solution
両端値は $1$ なので補間は定数 $1$ である。$1-x^2$ の最大は $x=0$ で $1$ である。
:::
::::

::::exercise{level=basic}
$T_3$ の三根を求めよ。

:::solution
$\cos(3\theta)=0$ より $\theta=\pi/6,\pi/2,5\pi/6$ である。根は $\sqrt3/2,0,-\sqrt3/2$ となる。
:::
::::

::::exercise{level=advanced}
$[0,1]$ の両端で $f=x^4$ の値と傾きを Hermite 補間せよ。

:::solution
左端条件で $p=ax^3+bx^2$ となる。右端で $a+b=1,\ 3a+2b=4$ なので $a=2,\ b=-1$ である。誤差は $x^2(x-1)^2$ となり、剰余公式にも一致する。
:::
::::

::::exercise{level=advanced}
$0,1,2$ で $0,2,0$ を補間する自然三次スプラインの $M_1$ を求めよ。

:::solution
$M_0=M_2=0$、$d_0=2,d_1=-2$ なので $4M_1=6(-4)$ となる。従って $M_1=-6$ である。
:::
::::

::::exercise{level=advanced}
$[-1,1]$ で $x^3$ を二次以下で最良一様近似せよ。

:::solution
$p=3x/4$ とすると $x^3-p=T_3/4$ である。$-1,-1/2,1/2,1$ で値は $-1/4,1/4,-1/4,1/4$ となり、四点交代から最良である。
:::
::::

::::exercise{level=advanced}
$[-1,1]$、重み $1$ で $x^3$ を一次以下で最小二乗近似せよ。

:::solution
奇関数なので定数への射影は零である。$x$ 方向の係数は $\int_{-1}^1x^4\,\dd x/\int_{-1}^1x^2\,\dd x=(2/5)/(2/3)=3/5$ となる。
:::
::::

::::exercise{level=advanced}
$x_0=0,x_1=1,x_2=2$ で $f=x^3$ の二次補間を求め、$x=1/2$ の誤差を節点積から求めよ。

:::solution
一次差分商は $1,7$、二次差分商は $3$ なので $p=x+3x(x-1)=3x^2-2x$ である。$f-p$ は三つの節点で零で最高次係数 $1$ の三次式だから $x(x-1)(x-2)$ に一致する。$x=1/2$ を入れて誤差 $3/8$ を得る。実際、真値 $1/8$、補間値 $-1/4$ の差である。節点の値が非負でも、区間内の高次補間の値が非負になるとは限らない。
:::
