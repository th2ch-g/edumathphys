## この章の目標

- 素イデアルと局所化からアフィンスキームを構成する。
- アフィンスキーム間の射を環準同型で記述する。
- 次数零局所化で Proj を貼り合わせる。
- 閉点とジェネリック点を区別する。

## アフィンスキーム Spec A と構造層

方程式 $t^2=0$ は体に値を取る解だけを見れば $t=0$ と同じである。しかし $t$ に一階の無限小を代入できるかどうかは違う。そこで点の集合に加えて環そのものを局所的に記録する。この章では環を任意の単位元付き可換環とする。

:::definition[スペクトル]{#def-ag-spec}
$\operatorname{Spec}A$ は素イデアルの集合であり、$V(I)=\{\mathfrak p:I\subset\mathfrak p\}$ を閉集合とする。閉集合の公理は $V(\sum I_\lambda)=\bigcap V(I_\lambda)$、$V(IJ)=V(I)\cup V(J)$ から従う。$D(f)=\operatorname{Spec}A\setminus V(f)$ は基本開基をなし、$D(f)\cap D(g)=D(fg)$ である。
:::

:::theorem[アフィンスキームの構造層]{#thm-ag-affine-structure}
$\mathcal O(D(f))=A_f$ を局所化の制限写像で結ぶと、一意に環の層に延びる。茎は $\mathcal O_{\mathfrak p}=A_{\mathfrak p}$ であり、大域切断は $A$ である。
:::
:::proof
$D(g)\subset D(f)$ なら $g^N\in(f)$ なので $f$ は $A_g$ で可逆であり、制限は :ref[thm-comm-localization-universal] で定まる。貼り合わせを $D(f)$ 上で調べるには $A$ を $A_f$ に置き換えればよい。基本開被覆 $\{D(g_i)\}$ がスペクトル全体を覆えば、どの極大イデアルも全ての $g_i$ を含まない。よって $(g_i)=A$ となり、$1$ の表示に使われた有限集合で覆える。

有限被覆と整合する切断 $a_i/g_i^n$ を取る。重なりでの等式から各 $g_i^n a_j-g_j^n a_i$ はある $(g_i g_j)$ の冪で殺される。共通の大きな $m$ を取り、分母を $d_i=g_i^{n+m}$、分子を $b_i=g_i^ma_i$ とすると $d_i b_j=d_j b_i$ になる。$\sum c_id_i=1$ と書き $b=\sum c_ib_i$ とすれば $d_jb=b_j$ で、$b$ が求める切断である。全ての局所化で零になる元は各 $g_i$ の十分高い冪で殺される。それらの冪も単位イデアルを生成するので元は零である。無限被覆の場合は有限部分で貼った切断と各残りの切断を重なりで比較する。これで基底上の層ができ、任意の開集合ではその中の基本開集合の整合族を取れば一意に延びる。茎は $f\notin\mathfrak p$ に沿う局所化の直極限なので $A_{\mathfrak p}$ である。
:::

:::proposition[アフィン反同値]{#prop-ag-spec-adjunction}
任意の局所環付き空間 $X$ について、$X\to\operatorname{Spec}A$ の局所環付き空間の射は環準同型 $A\to\Gamma(X,\mathcal O_X)$ と対応する。特に $\operatorname{Spec}B\to\operatorname{Spec}A$ は $A\to B$ に対応する。
:::
:::proof
準同型 $\alpha$ があるとき、$x$ に $A\to\mathcal O_{X,x}\to\kappa(x)$ の核を対応させる。$D(f)$ の逆像は $\alpha(f)$ の芽が可逆となる開集合である。逆元をもつ芽は近傍上で逆元をもつ切断に持ち上げられ、一意性によりそれらは貼り合う。従って局所化の普遍性で $A_f$ から逆像上の切断への写像ができる。これらは制限と可換であり、茎では極大イデアルの逆像が点の素イデアルの局所化になる。逆に局所環付き空間の射から大域切断の写像を取ると、茎の局所性で点への写像が強制され、局所化の普遍性で層への写像も強制される。
:::

### 基本開被覆と構造層の切断

:::example[整数環の二開で切断を貼る]
$D(2),D(3)$ は $-2+3=1$ により $\operatorname{Spec}\Z$ を覆う。切断環は $\Z[1/2]$、$\Z[1/3]$、交わりでは $\Z[1/6]$ である。$a/2^m=b/3^n$ が交わりで成り立つなら $3^na=2^mb$ なので $2^m$ は $a$ を割り、$3^n$ は $b$ を割る。従って共通の切断は整数である。この例では局所化写像が単射なので切断環を商体内の共通部分として求められる。
:::

:::example[反転と局所環を別に計算する]
$A=k[x,y]/(xy)$ の $D(x)$ では $y=0$ となり、切断環は $k[x,x^{-1}]$ である。原点の局所環 $A_{(x,y)}$ では両方の軸の方程式が残る。実際、$y$ を零にするにはある $s\notin(x,y)$ が $sy=0$ を満たす必要があるが、$x=0$ を代入すると $s(0,y)y=0$ であり、$s(0,0)\ne0$ に反する。
:::

### 基本開と素点への局所化

:::proposition[基本開への制限と局所化]
$f\in A$ とする。$D(f)$ に構造層を制限した局所環付き空間は $\operatorname{Spec}A_f$ と同型である。また $D(f)\subset D(g)$ は $f\in\sqrt{(g)}$ と同値である。
:::

:::proof
$A_f$ の素イデアルは $f$ を含まない $A$ の素イデアルと縮約で対応する。その基本開 $D_{A_f}(a/f^r)$ は $D_A(f)\cap D_A(a)$ に移るので位相同型である。切断環は $(A_f)_a=A_{fa}$ であり、構造層の基本開どうしの制限がいずれも局所化写像であるため層としても同型になる。次に $D(f)\subset D(g)$ は $(g)$ を含む全素イデアルが $f$ を含むことに等しく、素イデアルの共通部分による根基の記述で最後の条件を得る。
:::

:::example[同じ基本開を異なる分母で表す]
$A=\Z[t]/(2t)$ とする。$D(2)$ では $2$ が単元になり $t=0$ なので $A_2=\Z[1/2]$ である。$D(t)$ では $t$ が単元になり $2=0$ なので $A_t=\F_2[t,t^{-1}]$ である。両者の交わりは $D(2t)=D(0)=\varnothing$ である。それぞれの内部では $D(2)=D(2^3)$ と $D(t)=D(t^2)$ が成り立ち、局所化環も同じである。$u^r$ を反転すれば $u^{-1}=u^{r-1}(u^r)^{-1}$ が得られるためである。幾何学的には、どの元を単元にしたかによって異なる成分が消える。
:::

:::example[ゼロ環になる開を計算する]
$A=k[\epsilon]/(\epsilon^3)$ では $D(\epsilon)$ は空である。環では $\epsilon$ が単元だと仮定して $\epsilon^3=0$ に逆元の三乗を掛けると $1=0$ となるので、局所化環は零環である。逆に $D(1+\epsilon)$ は全体である。実際 $(1+\epsilon)(1-\epsilon+\epsilon^2)=1+\epsilon^3=1$ である。この二例の対比から、構造層で「開が空であること」と「対応する切断環が零環であること」の対応が明示的に分かる。
:::

### 任意の近傍の茎を分母で計算する

:::example[整数の局所環とその剰余体]
$A=\Z$ の点 $(5)$ での茎は、$5$ で割れない整数を全て分母に許した $\Z_{(5)}$ である。例えば $2/3$ は元で、その剰余は $\F_5$ で $2\cdot2=4$ になる。$1/5$ は元でない。もし $1/5=a/b$（$5\nmid b$）なら $b=5a$ が矛盾するからである。同じ点を $D(6)$ の中で見ると、先に $2,3$ が分母になっているが、残りの $5$ と素な元を順に反転すれば最終的な茎は変わらない。局所環の計算では、どのアフィン近傍から始めても固定点を含む近傍の系が同じ結果を与える。
:::

### 制限写像の核と貼り合わせの一意性

:::proposition[基本開で零になる切断]
$a\in A$ の $D(f)$ への制限が零になることは、ある $m\ge0$ で $f^m a=0$ になることと同値である。特に $A$ が整域で $f\ne0$ なら制限は単射である。二つ以上の開に制限して零になるかを調べる場合は、対応する全ての局所化の核を交わらせる。
:::

:::proof
局所化で $a/1=0/1$ となる条件は、等号の定義により、分母集合に属する元を $a$ に掛けると零となることである。この集合の元は $f$ の冪だから最初の主張を得る。整域なら $f^m$ は非零因子なので $a=0$ になる。複数の開の場合は、それぞれの制限が零という条件の共通部分を取ればよい。
:::

:::example[片方の成分でだけ消える元]
$A=k[x,y]/(xy)$ を取る。$D(x)$ では $x$ が単元になり $y=0$ である。従って $(y)$ は制限写像の核に含まれる。逆に $a/1=0$ なら、$x^m a=0$ を $A/(y)=k[x]$ へ移すことで、$a$ の像が零であると分かる。よって核は $(y)$ である。同じ計算により $D(y)$ への核は $(x)$ である。両方の開で零になる元は $(x)\cap(y)=0$ である。二開は原点を覆っていないが、この例ではその和へ制限する写像は単射である。各成分の開が元の成分の多項式を決めるためである。
:::

:::example[稠密開への制限でも消える元がある]
$A=k[x,\epsilon]/(x\epsilon,\epsilon^2)$ では点集合は $k[x]$ と同じである。$D(x)$ はその空間で稠密であるが、局所化すると $x\epsilon=0$ により $\epsilon=0$ となる。元の環では $\epsilon$ は非零である。例えば $x=0$ を代入した商 $k[\epsilon]/(\epsilon^2)$ で非零だからである。従って稠密開への制限が単射であるという整域での結論は、この非被約環には適用できない。
:::

### 二つの開の切断から零因子を含む環を復元する

:::example[中国剰余で分かれる基本開]
$A=\Z/12\Z$ の $D(2),D(3)$ は $3-2=1$ により全体を覆う。$D(2)$ では $4$ が単元になるので関係 $12=0$ は $3=0$ となり、切断環は $\Z/3\Z$ である。$D(3)$ では逆に $4=0$ が残り、$\Z/4\Z$ となる。交わりでは $6$ を反転するが $6^2=0$ なので空である。従って二開上の任意の切断は貼れ、大域環は二環の直積になる。例えば $D(2)$ 上で $1$、$D(3)$ 上で $2$ と指定すれば、両合同を満たす $10$ の類が貼った元である。元の大域環には零因子があっても、基本開の貼り合わせの一意性は変わらない。
:::

## スキームの定義と貼り合わせ

:::definition[スキームとアフィン開被覆]{#def-ag-scheme}
局所環付き空間としてのスペクトルをアフィンスキームと呼ぶ。各点にアフィンスキームと同型な開近傍をもつ局所環付き空間を :term[スキーム]{en="scheme" yomi="すきーむ"} という。射は局所環付き空間の射である。
:::

:::proposition[スキームの貼り合わせ]{#prop-ag-scheme-gluing}
スキーム $X_i$、開部分 $U_{ij}\subset X_i$、同型 $\phi_{ij}:U_{ij}\to U_{ji}$ を取る。$U_{ii}=X_i$、$\phi_{ii}=\id$、$\phi_{ji}=\phi_{ij}^{-1}$ とする。さらに $\phi_{ij}(U_{ij}\cap U_{ik})=U_{ji}\cap U_{jk}$ であり、その定義域上で $\phi_{jk}\phi_{ij}=\phi_{ik}$ とする。このとき $X_i$ を指定の開部分に沿ってスキームに貼り合わせられる。
:::
:::proof
空間の直和を指定の同型で同一視した商集合を作る。三重交叉条件は、途中の $X_j$ を経由する同一視が直接の同一視と一致することを保証する。従って各 $X_i$ は商集合へ単射であり、像の交わりは指定の開部分に等しい。商位相ではそれらの像は開であり、各像への写像は同相である。構造層を :ref[thm-ag-sheaf-gluing] で貼ると局所的に元の構造層に一致する。茎は局所環で、元のアフィン開も開近傍として残る。この構成の切断と点の同一視が指定から一意に決まる。
:::

:::example[原点だけを別に保つ貼り合わせ]
二つの $\operatorname{Spec}k[t]$ を $D(t)$ 上で恒等写像により貼る。$t=0$ の素イデアルに対応する点は別々に残り、$(0)$ に対応する点は一つに同一視される。これに対し $t$ と $t^{-1}$ を交換して二つの直線を貼ると射影直線になる。
:::

:::example[アフィン開の和がアフィンにならない場合]
$X=\mathbb A^2_k\setminus\{(0,0)\}=D(x)\cup D(y)$ とする。重なりは $D(xy)$ であり、貼り合わせの条件から
$$
\Gamma(X,\mathcal O_X)=k[x,y,x^{-1}]\cap k[x,y,y^{-1}]
=k[x,y]
$$
である。最後は、一方で許す負の $x$ 指数がもう一方では許されず、$y$ についても同様であることによる。もし $X$ がアフィンなら、:ref[prop-ag-spec-adjunction] により大域環の恒等準同型で誘導される包含 $X\to\mathbb A^2_k$ は同型となる。しかしこの包含の像は原点を欠く。従って二つのアフィン開とそのアフィンな重なりで貼っても、全体がアフィンとは限らない。
:::

### 貼り合わせは重なりを書くところから始める

:::example[射影直線の二つの座標]
$U=\operatorname{Spec}k[t]$ と $V=\operatorname{Spec}k[s]$ の重なりを $D(t),D(s)$ とし、$s=t^{-1}$ で貼る。重なり外に各開から一つずつ点が残る。大域切断は $k[t]\cap k[t^{-1}]\subset k[t,t^{-1}]$ であり、Laurent 展開の指数の共通部分は $0$ だけなので $k$ である。従ってこのスキームはアフィンではない。もしアフィンなら $\operatorname{Spec}k$ となり、点が一つになってしまう。
:::

:::example[同じ重なりを恒等式で貼る]
上と同じアフィン直線を取るが、$s=t$ で貼る。二つの原点は交換されず、原点以外の点が同一視される。大域切断は二つの多項式が $k[t,t^{-1}]$ で等しい組なので $k[t]$ である。大域切断から作る $\operatorname{Spec}k[t]$ への射では、二つの原点が同じ原点に移る。大域切断環が通常の直線と等しくても、貼り合わせで点と射の性質が変わる。
:::

### スキームへの射をアフィン開から貼る

:::proposition[射の局所構成]
$X=\bigcup U_i$ をスキームの開被覆とする。$U_i$ から $Y$ への局所環付き空間の射が重なりで一致すれば、$X\to Y$ の射に一意に貼り合う。
:::

:::proof
まず点写像は一致条件で一意に定義できる。開の逆像は各 $U_i$ での逆像の和なので開であり、連続である。$Y$ の開 $V$ 上の切断を引き戻すには、$f^{-1}(V)\cap U_i$ 上への局所引き戻しを取る。重なりで一致しているため $\mathcal O_X$ の層公理で一つに貼れる。これらの写像は制限と環演算に両立する。茎ではどれか一つの局所射の準同型に等しいので局所的である。一意性は点写像と切断の貼り合わせの一意性から従う。
:::

:::example[射影直線の開に定義した二つの写像が貼れる場合]
$\mathbb P^1_A$ の座標 $t,s=t^{-1}$ をそれぞれ使い、第一開で $t\mapsto t^2$、第二開で $s\mapsto s^2$ に対応する射を作る。重なりで両方が $t$ の逆元を可逆元へ送るため、共通の標的の重なりに入る。逆数を取れば $(t^2)^{-1}=(t^{-1})^2$ なので二つは一致する。従って環 $A$ に冪零元があっても射が貼れる。この射の無限遠での値は $s=0$ を直接代入して求まり、アフィン開で $t$ を無限に大きくするという極限の概念を必要としない。
:::

:::example[同じ二近傍でも制限が一致しない場合]
標数零で、第一開からの射を $t\mapsto t+1$、第二開からの射を $s\mapsto s$ とする。重なりの点 $t=1$ では第一の射が有限座標 $2$ へ送るが、第二の射は $s=1$ から有限座標 $1$ に送る。従って重なりで既に点写像が一致せず、この二射を貼れない。一方 $t\mapsto t+1$ 自体は射影直線の全域へ延ばせる。第二開では標的の逆座標を $s/(1+s)$ とすれば $s=0$ の近くで正則であり、$s=-1$ の近くでは標的の有限座標 $1+1/s$ を使える。制限の不一致を補うには、第二開の射を元の射に合わせて取り直す必要がある。
:::

### 大域切断が誘導するアフィンスキームへの射

:::example[二重原点の大域環から見える射]
二つの直線を $D(t)$ 上で恒等に貼った $X$ では、大域切断は同じ多項式を両開に置いたものなので $k[t]$ である。恒等準同型 $k[t]\to\Gamma(X,\mathcal O_X)$ は $X\to\operatorname{Spec}k[t]$ の射を誘導し、両アフィン開で恒等写像となる。この射は二つの原点を一つへ送るため同型ではない。$X$ からアフィン標的へ向かう任意の射はこの射を一意に経由する。実際、標的を $\operatorname{Spec}B$ とすれば、射の環側の情報は $B\to k[t]$ だけである。この大域環の普遍性は、$X$ 自体がアフィンでない場合にも成り立つ。
:::

### 直和と連結性を貼り合わせから調べる

:::proposition[積環のスペクトル]
二つの環 $A,B$ に対し $\operatorname{Spec}(A\times B)$ は $\operatorname{Spec}A$ と $\operatorname{Spec}B$ の非交叉和に同型である。
:::

:::proof
$e=(1,0)$ と $1-e=(0,1)$ は冪等元で、その積は零である。素イデアルは少なくとも一方を含み、両方を含むと和の $1$ も含んでしまう。従って $D(e)$ と $D(1-e)$ は空でない限り互いに素で、全体を覆う。$e$ を単元にすると $e^2=e$ から $e=1$ となり $(1-e)=0$ になる。その局所化は $A$ への射影と同じ普遍性を持つため $A$ である。同様に他方は $B$ である。基本開の構造層の計算から、これがスキームの非交叉和の表示である。
:::

:::example[冪等元を局所化から復元する]
$k[x]/(x(x-1))$ では $x^2=x$ である。$D(x)$ では $x=1$、$D(1-x)$ では $x=0$ になり、双方の切断環は $k$ である。点 $0,1$ で値 $(a,b)$ を指定すれば $a+(b-a)x$ が大域切断である。例えば値 $(0,1)$ に対応する $x$ は、後者の点の上で $1$、前者で $0$ になる。積環の冪等元は、スキーム上でどの成分を選んだかを切断として表す。
:::

:::example[貼り合わせで二つの開が同じ点を共有する場合]
$k[x,y]/(xy)$ の二成分は閉部分としては二つのアフィン直線であるが、原点を共有する。両成分に制限した大域切断の値は原点で一致するので、環の任意の冪等元は各軸上で定数 $0$ または $1$ となる。原点で一致するため、同じ定数にしかなれない。従ってこの環を二つの非零環の直積には分けられない。位相でも各軸は既約であり、共通点を持つ連結部分の和なので全体は連結である。アフィン直線の二成分という情報だけでなく、それらを空でない場所で貼ったという条件が効いている。
:::

### 二つ以上の開を比較するときは重なりを必ず指定する

:::proposition[アフィン近傍の共通の細分]
スキーム $X$ の点 $x$ と、それを含む開集合 $U,V$ を取る。$x$ を含み $U\cap V$ に入るアフィン開が存在する。特に任意の開部分に制限した局所環付き空間もスキームである。
:::

:::proof
$x$ を含むアフィン近傍 $W=\operatorname{Spec}A$ を一つ取る。$W\cap U\cap V$ は $W$ の開集合である。基本開が開基なので、$x$ を含む $D_W(f)$ をその中に選べる。$D_W(f)$ は局所化 $A_f$ のスペクトルだからアフィンである。任意の開部分内の各点に同じ選択ができるため、制限した構造層と位相はアフィン開で覆われる。
:::

:::proposition[二つのアフィン開に共通する基本開]{#prop-ag-common-principal-open}
二つのアフィン開 $U,V$ の共通点 $x$ に対し、双方で基本開となる共通近傍 $W\subset U\cap V$ を取れる。
:::

:::proof
$U=\operatorname{Spec}A$ の基本開 $D_U(f)$ を $x\in D_U(f)\subset V$ となるように選ぶ。次に $V$ の基本開 $D_V(g)$ を $x\in D_V(g)\subset D_U(f)$ となるように選ぶ。$g$ の $D_U(f)$ への制限は $a/f^r\in A_f$ と書ける。この元の非消滅開は $D_U(af)$ であり、同時に $D_U(f)\cap D_V(g)=D_V(g)$ に等しい。従ってこれを $W$ に取れる。
:::

:::example[交わり全体がアフィンである必要はない]
原点を除く平面 $W=D(x)\cup D(y)$ を重なりとし、二つの $\mathbb A^2$ を恒等で貼る。二開はそれぞれアフィンだが、重なり $W$ はアフィンではない。実際、$W$ の大域環は $k[x,y]$ であり、そこからの自然なアフィンへの射は原点を欠くため同型でない。それでも重なりの各点には $D(x)$ または $D(y)$ のアフィン近傍があるので、貼り合わせはスキームの定義を満たす。この例では二開を重ねる操作と、重なりそのものが単一の環のスペクトルになる条件を区別できる。
:::

## 次数付き環の Proj

:::definition[射影スペクトル]{#def-ag-proj}
非負次数付き環 $S=\bigoplus_{d\ge0}S_d$ と $S_+=\bigoplus_{d>0}S_d$ に対し、$S_+$ を含まない斉次素イデアル全体を :term[射影スペクトル]{en="projective spectrum" yomi="しゃえいすぺくとる"} $\operatorname{Proj}S$ と呼ぶ。閉集合は斉次イデアルを含む点の集合であり、正次数斉次元 $f$ に対し $D_+(f)$ を $f$ を含まない点の集合とする。
:::

:::proposition[Proj のアフィン近傍]{#prop-ag-proj-chart}
$D_+(f)$ は $\operatorname{Spec}(S_f)_0$ と同相であり、これらのアフィンスキームは重なりで自然に一致する。これらを貼り合わせた構造層により $\operatorname{Proj}S$ をスキームとする。
:::
:::proof
局所化で $f$ を避ける斉次素イデアルは $S_f$ の斉次素イデアルに対応する。$e=\deg f$ とする。次数零環の素イデアル $\mathfrak q$ に対し、次数 $d$ の斉次元 $a$ を含める条件を $a^e f^{-d}\in\mathfrak q$ とする。この条件は、$S_f$ の斉次元に対し積と斉次倍で閉じる。同じ次数の和については $(a+b)^{2e}$ の各単項式に $a^e$ または $b^e$ が因子として含まれる。従って $a,b$ が条件を満たすなら $(a+b)^{2e} f^{-2d}\in\mathfrak q$、素性で $(a+b)^e f^{-d}\in\mathfrak q$ となる。斉次元の積がこのイデアルに入るならどちらかが入る。商の最高次数の非零成分を見れば、一般の元の積についても整域条件が従う。逆に斉次素イデアルでの $a$ の所属は $a^e f^{-d}$ の所属で判定できるので、これが縮約の逆操作である。

斉次元 $g$ に対する $D_+(g)$ との重なりは、次数零環の元 $g^e/f^{\deg g}$ の基本開に一致する。この元を逆にすることは、$S_f$ で $g$ も逆にしてから次数零を取ることと同じである。実際 $g^{-1}$ を含む次数零分数は分子分母に $g$ の冪を掛け、$g$ の分母の指数を $e$ の倍数にできる。これにより両近傍の重なりの環は $(S_{fg})_0$ に一致する。三重交叉でも同じ局所化なので :ref[prop-ag-scheme-gluing] が適用できる。
:::

:::proposition[Veronese 部分環と Proj]{#prop-ag-proj-veronese}
$d\ge1$ に対し $S^{(d)}=\bigoplus_{n\ge0}S_{nd}$ と置き、$S_{nd}$ を新しい次数 $n$ とする。$\operatorname{Proj}S^{(d)}\simeq\operatorname{Proj}S$ である。
:::
:::proof
正次数斉次元 $f$ に対し $D_+(f)=D_+(f^d)$ である。$f^d$ は $S^{(d)}$ の元であり、次数が $d$ の倍数である正次数斉次元全体の標準開が $\operatorname{Proj}S$ を覆う。これらの元は $S^{(d)}$ の正次数斉次元すべてを尽くすため、そちらの Proj も覆う。このような $g$ に対して $(S_g)_0=((S^{(d)})_g)_0$ である。次数零分数の分子の次数は分母に等しく、従って分子も $S^{(d)}$ に属する。局所化での等号も $g$ の冪だけで判定できる。これらの同型は重なりで同じ環の局所化から来るので貼り合う。
:::

### 非標準の次数と斉次局所化

:::example[重みつき射影直線の標準開]
$\deg X=1,\deg Y=2$ とした $S=k[X,Y]$ を考える。$D_+(X)$ で次数零になる単項式は $(Y/X^2)^j$、$j\ge0$ で生成される。$D_+(Y)$ では $(X^2/Y)^j$ で生成され、重なりでは二生成元が逆である。従って $\operatorname{Proj}S$ はスキームとして $\mathbb P^1_k$ に同型である。次数二の Veronese 部分環が $k[X^2,Y]$ で、次数を半分にすればどちらも次数一になることからも同じ同型を得る。
:::

:::example[斉次零因子が近傍を変える]
$S=k[X,Y,Z]/(XY)$ を標準次数で取る。$D_+(X)$ では $Y/X=0$ なので $k[Z/X]$、$D_+(Y)$ では $k[Z/Y]$ になる。この二開は交わらない。$D_+(Z)$ では $k[u,v]/(uv)$、$u=X/Z,v=Y/Z$ で、二成分の交点を含む。従って Proj は二本の射影直線を一点で交わらせたスキームである。$D_+(X)$ と $D_+(Y)$ だけでは交点 $[0:0:1]$ を覆えない。
:::

### Proj の射が定義される開を見つける

:::proposition[斉次準同型が誘導する Proj の射]{#prop-ag-proj-induced-map}
次数を保つ準同型 $\phi:S\to T$ は、$\phi(S_+)T$ を含まない $\operatorname{Proj}T$ の開部分から $\operatorname{Proj}S$ への射を誘導する。この開が全体になる条件は $T_+\subset\sqrt{\phi(S_+)T}$ である。
:::

:::proof
指定の開では $\mathfrak p\in\operatorname{Proj}T$ の縮約が $S_+$ を含まない。正次数斉次元 $f\in S$ に対応する標準開の逆像は $D_+(\phi(f))$ であり、$\phi(f)=0$ の場合は空である。空でない場合は、環写像 $(S_f)_0\to(T_{\phi(f)})_0$ を自然に誘導する。制限は局所化なのでこれらの環写像は重なりで一致する。従って射が貼り合う。開が全体なら、$\phi(S_+)T$ を含む全斉次素イデアルが $T_+$ を含む。斉次イデアルの根基はそれを含む斉次素イデアルの共通部分である。実際、ある斉次元のどの冪もイデアルに入らなければ、その冪を避ける極大の斉次イデアルを選べる。二斉次元を加えて作る二つのイデアルにそれぞれ冪が入れば、その積に別の冪が入るので、この極大イデアルは斉次元に関して素となる。最高次成分を取れば素イデアルである。よって開が全体なら根基が $T_+$ を含む。逆は素イデアルが根基を含むことから直ちに従う。
:::

:::example[座標の一部を捨てると一点で定義されない]
$S=k[U,V]$、$T=k[X,Y,Z]$ とし、$U\mapsto X,V\mapsto Y$ と送る。開は $D_+(X)\cup D_+(Y)$ で、$[0:0:1]$ を除いた射影平面である。$X\ne0$ の環写像では $V/U$ が $Y/X$ に移り、$Y\ne0$ では $U/V$ が $X/Y$ に移る。重なりでは比が逆なので貼り合う。環準同型が全域で定義されても、Proj への反変な射に全域が許されるとは限らない。
:::

### 斉次イデアルと Proj の閉部分

:::proposition[斉次商が誘導する閉埋め込み]{#prop-ag-proj-closed-quotient}
非負次数付き環 $S$ と斉次イデアル $I$ に対し、$\operatorname{Proj}(S/I)\to\operatorname{Proj}S$ は閉集合に同相に写り、標準開 $D_+(f)$ 上では $(S_f)_0/(I S_f)_0$ のスペクトルを与える。
:::

:::proof
斉次素イデアルの商の対応から、点の像は $I$ を含むもの全体で閉じている。各 $D_+(f)$ の逆像では、環写像は $(S_f)_0\to((S/I)_f)_0$ である。局所化は商と可換であり、次数零部分を取る操作は斉次加群の完全列を保つ。実際、次数零の元を持ち上げるには任意の持ち上げの次数零成分を取ればよく、核は斉次成分ごとに計算できる。従って写像は全射で、核は $(I S_f)_0$ である。これらの局所商は重なりで同じ斉次局所化になるため、全体の射が得られる。この局所商による射を [閉埋め込み](/math/algebraic-geometry/scheme-properties/) と呼ぶ。
:::

:::example[射影直線上の二重点を覆いから求める]
$S=A[X,Y]$ とし、$I=(Y^2)$ を取る。$D_+(Y)$ の逆像は空であり、$D_+(X)$ では $u=Y/X$ を用いて $A[u]/(u^2)$ となる。従って全体はこのアフィン環のスペクトルである。今度は $I'=(X^2,XY)$ を取ると $D_+(X)$ は空、$D_+(Y)$ での式は $X/Y=0$ なので $\operatorname{Spec}A$ になる。後者の斉次商において $X$ の類が零でない場合にも、$X,Y$ をそれぞれ反転すると消えるため、Proj にはその類が残らない。斉次環にある冪零元が、そのまま全て射影スキームに現れるわけではない。
:::

### 重みが異なる場合の次数零環を計算する

:::example[重み $(1,1,2)$ の標準開]
$S=k[X,Y,Z]$ とし、$X,Y$ の次数を一、$Z$ を二とする。$D_+(X)$ の次数零環は $u=Y/X,v=Z/X^2$ の多項式環である。$D_+(Z)$ では $a=X^2/Z,b=XY/Z,c=Y^2/Z$ が次数零元となる。任意の次数零の単項式は、分子に $X,Y$ を合わせて偶数個含む。これらを二個ずつ組にすれば、$a,b,c$ の積として表せる。関係は $ac=b^2$ だけである。実際、$b$ の指数を $0$ または $1$ に簡約すると、代入先では $X,Y$ の指数がともに偶数または奇数で、異なる単項式が一致しない。従って $D_+(Z)$ は $k[a,b,c]/(ac-b^2)$ のスペクトルである。この開の点 $a=b=c=0$ は二次錐の頂点であり、他の二標準開では見えない。
:::

:::example[同じ Proj を標準次数に移す]
前例の二次 Veronese 部分環は $X^2,XY,Y^2,Z$ で生成される。実際、偶数次数の単項式からまず $Z$ の冪を除くと、残る $X,Y$ の数が偶数なので二個ずつ組にできる。新しい次数一の座標を $A,B,C,D$ とすれば関係は $AC=B^2$ である。関係が他にないことは $B$ の冪を一以下にしてから代入すれば分かる。従って Proj は $\mathbb P^3$ の二次錐 $AC=B^2$ であり、$D=1$ の近傍は先に計算した二次錐のアフィン開である。したがって重み付き環の計算と標準次数の斉次商の計算が同じ局所環を与える。
:::

### Proj と係数環の取り替え

:::proposition[相対的な Proj の基底変換]{#prop-ag-proj-base-change}
$S$ が $R=S_0$ 上の非負次数付き環で、$R\to A$ が環準同型であるとする。このとき $\operatorname{Proj}(S\otimes_R A)$ は $\operatorname{Proj}S$ の $\operatorname{Spec}A$ への基底変換である。ここで基底変換とは、各 $R$ アフィン近傍の環を $A$ とテンソルして同じ重なりで貼る操作をいう。
:::

:::proof
$S\otimes_R A$ の正次数部分は、$S$ の正次数斉次元の像で $A$ 加群として生成される。従ってそれらの像による標準開が新しい Proj を覆う。正次数斉次元 $f$ について、局所化の普遍性により $(S\otimes_R A)_{f\otimes1}=S_f\otimes_R A$ である。さらに $S_f$ は $\Z$ 次数付き環として直和に分かれる。テンソル積は直和と可換なので、次数零成分は $(S_f)_0\otimes_R A$ になる。重なりでの環写像も同じ局所化から来るため、それぞれの標準開が元のものの基底変換で貼り合う。$R\to A$ の平坦性は使っていない。次数零部分を取る操作が、核ではなく次数の直和因子を取る操作だからである。
:::

:::example[二重線の厚みが標数とともに現れる]
$S=\Z[X,Y,Z]/(X^2-2YZ)$ とする。$\Q$ に移すと射影曲線は非特異である。実際、偏微分 $2X,-2Z,-2Y$ は同時に零にならない。一方 $\F_2$ に移すと $X^2=0$ になり、台は直線 $X=0$、$Z=1$ の標準開の切断環には $x^2=0$ の冪零元 $x$ がある。例えば $Y=0$ も課すと、同じ開の環は $\F_2[x]/(x^2)$ となる。この例では特別なファイバーを被約な直線で置き換えると交点の長さが失われる。Proj を作る前でも後でも、環の基底変換を取れば二重線が得られる。
:::

### 斉次素イデアルで茎を表す

:::proposition[射影スペクトルの茎]
$\mathfrak p\in\operatorname{Proj}S$ に対し、$\mathfrak p$ に属さない全ての斉次元を反転した環を $S_{(\mathfrak p)}^{\mathrm{gr}}$ と書く。その次数零部分は $\mathcal O_{\operatorname{Proj}S,\mathfrak p}$ に同型である。
:::

:::proof
正次数の $f\notin\mathfrak p$ を一つ選べば、点は $D_+(f)$ に含まれ、その茎は $B=(S_f)_0$ の $\mathfrak q=(\mathfrak p S_f)_0$ における局所化である。$B_{\mathfrak q}$ の元は同次数の分子と、$\mathfrak p$ に属さない分母を持つ斉次分数へ移る。逆に $a/g$ が同次数 $d$ の斉次分数で、$g\notin\mathfrak p$ とする。$e=\deg f$ と置くと
$$
\frac{a}{g}=\frac{a g^{e-1}/f^d}{g^e/f^d}
$$
であり、分子、分母はともに $B$ に属す。分母は $\mathfrak q$ に属さない。従って所望の局所環の元に戻る。斉次分数の等号も分母集合の元を掛けて判定するため、この対応で一致する。これで標準開の選択によらない表示になる。
:::

:::example[射影直線のジェネリック点の体]
$S=k[X,Y]$ の零素イデアルは Proj のジェネリック点である。次数が等しい二斉次式の比を $X$ の冪で割れば $Y/X=t$ の有理関数になる。逆に任意の $k(t)$ の分数は分子と分母を同じ次数に斉次化して表せる。従ってその点の茎も剰余体も $k(t)$ である。点 $[1:0]$ では斉次素イデアル $(Y)$ を取る。同じ比のうち分母が $Y=0$ で非零なものだけを許すと $k[t]_{(t)}$ になる。点を特殊化したときに許される分母が減ることを、斉次分数から直接確認できる。
:::

## 多様体に付随するスキーム

古典的アフィン多様体 $X$ に $\operatorname{Spec}k[X]$ を対応させる。:ref[prop-ag-affine-recovery] により閉点は古典的な点に等しく、:ref[prop-ag-affine-regular] と :ref[thm-ag-affine-structure] によって閉点の包含に沿った構造層の逆像も古典的な構造層に一致する。実際、基本開上で同じ環 $k[X]_f$ を割り当てるからである。射は :ref[prop-ag-affine-morphism] と :ref[prop-ag-spec-adjunction] で同じ環準同型から得られる。

準射影多様体の閉包に対しては斉次座標環の Proj を作る。:ref[prop-ag-projective-coordinate-localization] により、その標準開は古典的アフィン開に対応する。閉包から取り除いた閉部分集合の斉次式で閉部分スキームを作り、その補集合を取れば元の準射影多様体に対応する。例えば $[s:t]\mapsto[s^2:st:t^2]$ の二つの標準開では、逆座標は $st/s^2$ と $st/t^2$ である。重なりで二つは互いに逆になるため、二次曲線の Proj は射影直線のスキームと同型である。

### 閉点を加群や環の条件へ移す

:::example[同じ古典点をもつ二つの方程式]
代数閉体 $k$ 上の $x=0$ と $x^2=0$ の古典的零点集合はともに一点で、その消滅イデアルは $(x)$ である。多様体に付随するスキームはその消滅イデアルで割るので $\operatorname{Spec}k$ となる。方程式をそのまま記録するなら $\operatorname{Spec}k[x]/(x^2)$ を別に構成できる。例えば後者には $k[\epsilon]/(\epsilon^2)$ からの試験点 $x\mapsto\epsilon$ があり、前者を経由しない。
:::

:::example[開条件が多様体から引き継がれる]
$k$ を代数閉体として $D(x)$ を $\mathbb A^1_k$ から取る。古典側は零以外の閉点の集合であり、補助変数で $xy=1$ と表せる。スキーム側では $D(x)\simeq\operatorname{Spec}k[x,x^{-1}]$ で、同じ補助変数を使って $k[x,y]/(xy-1)$ と同型になる。さらに素イデアル $(0)$ が追加され、関数体 $k(x)$ を剰余体にもつ。開への制限が両方の構成で同じ局所化になる。
:::

### 閉点の空間から有限型の構造を比較する

:::proposition[古典的な準射影多様体からの射の復元]
代数閉体上の準射影多様体 $X,Y$ に付随するスキームを $X^{\mathrm{sch}},Y^{\mathrm{sch}}$ とする。古典的な射は、対応する $k$ スキームの射と一対一に対応する。
:::

:::proof
アフィン近傍では双方の射が座標環の準同型と対応する。古典的な射から始めるとき、標的の各古典アフィン近傍の逆像を基本開で覆い、その上で関数を引き戻す。この基本開に対応するスキームの開上でも同じ環準同型を使う。二つの局所構成が共有する開では、より小さいアフィン開で関数を比較できる。もし古典点の全てで等しければ、局所環の表示は有限型被約環の元であるため零点定理で等しい。従ってスキームの射として一致し、一つに貼れる。

逆にスキームの射は閉点から閉点への写像を誘導する。閉点の剰余体は $k$ である。像の剰余体は $k$ 準同型で $k$ に埋め込まれるので $k$ そのものとなり、有限型環では像の点も極大イデアルである。標的のアフィン開への逆像でアフィン局所に制限すれば、環準同型から古典的な射を取り出せる。重なりで一致して一つに貼れ、ここまでの二操作を順に行っても、アフィン上の同じ環準同型が戻る。従って互いに逆である。
:::

:::example[分母がある古典的な射のスキーム表示]
$D(x)$ から双曲線 $uv=1$ へ $x\mapsto(x^2,x^{-2})$ で送る。対応する環写像は $k[u,v]/(uv-1)\to k[x,x^{-1}]$、$u\mapsto x^2,v\mapsto x^{-2}$ である。閉点 $x=a$ は古典的な点 $(a^2,a^{-2})$ に移る。さらに源の素イデアル $(0)$ は標的の $(0)$ へ移る。実際 $k[u,u^{-1}]\to k[x,x^{-1}]$ は異なる Laurent 指数を異なる偶数指数へ送るので単射である。閉点の対応は古典的な写像を取り戻し、ジェネリック点の対応は像が稠密であることを環の単射として記録する。
:::

### 閉点に制限して忘れるものを確かめる

:::example[閉点だけの構造層が一致する理由]
既約アフィン多様体 $X$ の座標環を $A$ とする。$\operatorname{Spec}A$ の閉点の部分空間は、$D(f)$ を閉点に制限した集合を基底に持つ。古典点での基本開も $D_X(f)$ であり、両方の切断環の計算は $A_f$ である。基本開 $D_X(f)$ 上の切断を、閉点の部分空間における逆像層として読む場合もこの環を得る。実際、$\operatorname{Spec}A$ の任意の空でない局所閉部分集合は閉点を含む。従って $D(f)$ の閉点全てを含む開近傍があれば、その開は $D(f)$ 全体を含む。逆像で必要な近傍は $D(f)$ 自身を含むものだけなので、基本開の切断の直極限は $A_f$ になる。こうして位相と層の両方で古典的な構造が復元される。
:::

:::example[被約性を外した場合の二種類の切断]
$X$ の代わりに同じ台を持つ $k[x,\epsilon]/(\epsilon^2)$ のスペクトルを考える。閉点の全てで $\epsilon$ の剰余は零であるが、$D(1)$ の切断として $\epsilon$ は非零であり、各閉点の茎にもその類が残る。例えば任意の点 $x=a$ で $g(x,\epsilon)$ を反転して $\epsilon$ が零になるなら、$g(x,\epsilon)\epsilon=g(x,0)\epsilon=0$ が必要である。$g(a,0)\ne0$ なら $g(x,0)$ は非零多項式であり、自由基底 $1,\epsilon$ に照らしてこの積は非零である。従って閉点での評価の値の集まりと、閉点における芽の集まりは別の情報を持つ。前者から古典的な多様体へ戻るときには冪零元が消える。
:::

## スキームの点とジェネリック点

:::definition[特殊化とジェネリック点]{#def-ag-generic-point}
$y\in\overline{\{x\}}$ であるとき $y$ は $x$ の :term[特殊化]{en="specialization" yomi="とくしゅか"} という。既約閉集合 $Z$ で $\overline{\{\eta\}}=Z$ を満たす点をその :term[ジェネリック点]{en="generic point" yomi="じぇねりっくてん"} という。
:::

:::proposition[素イデアルと閉包]{#prop-ag-specialization}
$\operatorname{Spec}A$ で $\overline{\{\mathfrak p\}}=V(\mathfrak p)$ である。任意のスキームの空でない既約閉集合にはジェネリック点が一意に存在する。
:::
:::proof
$\mathfrak p$ を含む最小の閉集合は $V(\mathfrak p)$ である。アフィンで $V(I)$ が既約であることは $\sqrt I$ が素であることと同値である。積の零点集合は二閉集合の和なので既約性から素性が従う。逆に素イデアル自身がジェネリック点なのでその閉包は既約である。一般の既約閉集合 $Z$ には空でないアフィン開との交わり $U\cap Z$ がある。これは $U$ の既約閉集合だからジェネリック点をもつ。その $X$ での閉包は $U\cap Z$ の閉包を含み、後者は $Z$ である。任意の別のジェネリック点も $U$ に入る。入らなければ閉集合 $X\setminus U$ に閉包が含まれるからである。アフィン上の一意性が適用できる。
:::

点 $x=\mathfrak p$ の剰余体は $A_{\mathfrak p}/\mathfrak p A_{\mathfrak p}=\operatorname{Frac}(A/\mathfrak p)$ である。古典的多様体で現れた関数体は、対応するスキームのジェネリック点での剰余体になっている。

### 特殊化と剰余体

:::example[平面の三種類の点]
$k$ を代数閉体として $\operatorname{Spec}k[x,y]$ で $(0)\subset(x)\subset(x,y)$ を考える。それぞれの閉包は平面、直線 $x=0$、原点であり、剰余体は $k(x,y),k(y),k$ となる。平面のジェネリック点は全ての非空基本開に入る。直線のジェネリック点は $D(y)$ には入るが $D(x)$ には入らない。閉点を列挙するだけでは分からない包含の鎖が、特殊化として記録される。
:::

:::example[閉でない点の茎]
$A=k[x,y]$ の素イデアル $(x)$ で局所化すると、$k[y]\setminus\{0\}$ が単元になるので $A_{(x)}=k(y)[x]_{(x)}$ と同一視できる。逆向きには $k(y)[x]$ の分母を係数ごとに払い、定数項が非零の分母が $A$ で $(x)$ の外にあることを使う。従って茎では $x$ が極大イデアルを生成し、その剰余体は $k(y)$ である。点の閉包の次元は $1$、茎の次元もこの例で $1$ だが、両者はそれぞれ素イデアルを上へ、下へたどって測っている。
:::

### 有理関数環の中で局所環を比較する

:::proposition[整スキームの切断と局所環の共通部分]{#prop-ag-scheme-rational-intersection}
空でない既約スキーム $X$ があり、非空なアフィン開の座標環はいずれも整域とする。$X$ のジェネリック点を $\eta$、その局所環を $K$ とする。任意の非空開 $U$ について、$\Gamma(U,\mathcal O_X)$ は $K$ の中の $\bigcap_{x\in U}\mathcal O_{X,x}$ と等しい。
:::

:::proof
アフィン開では座標環が整域であり、そのジェネリック点での局所環は分数体である。非空なアフィン開は全て $\eta$ を含むので、この分数体は $K$ に同一視される。任意の非空開から $K$ への写像は単射である。実際、芽が零なら各アフィン開の制限が分数体で零になるため、整域での単射性から各制限が零となる。従って全切断は各茎の像に含まれる。

逆に $f\in K$ が全茎に属するとする。点 $x$ の茎での代表を $x$ の近傍上に選ぶ。任意の二代表は重なりが非空ならそのジェネリック点で同じ $f$ を表す。開集合の切断から $K$ への単射性により重なりで一致するので、一つの切断に貼られる。この議論はアフィンの場合の環と局所化の共通部分表示を、大域の開被覆に移したものである。
:::

:::example[平面から原点を除いても新しい有理関数が正則にならない理由]
$U=D(x)\cup D(y)$ では $k(x,y)$ のうち $D(x)$ 上で正則な分母は $x$ の冪だけであり、$D(y)$ 上では $y$ の冪だけである。$f=a/x^r=b/y^s$ と書けたなら $a y^s=b x^r$ である。$x,y$ は素元で互いに割り合わないので $x^r\mid a$ となり $f$ は多項式である。例えば $1/x$ は $D(x)$ で許されても $D(y)$ には $x=0$ の高さ一素点があるため許されない。欠けた原点だけに極を集中させることはできない。
:::

### 点を体に値を取る射として読む

:::proposition[体からの射と剰余体]
体 $L$ に対して、$\operatorname{Spec}L\to X$ の射は、点 $x\in X$ と体準同型 $\kappa(x)\to L$ の組と一対一に対応する。
:::

:::proof
射の像を $x$ とする。アフィン近傍 $\operatorname{Spec}A$ を取れば、射は $A\to L$ に対応する。核 $\mathfrak p$ が $x$ であり、$A/\mathfrak p$ の各非零元の像は $L$ で可逆なので、写像は $\operatorname{Frac}(A/\mathfrak p)=\kappa(x)$ に一意に延びる。逆に点と埋め込みを与え、$A\to A/\mathfrak p\to\kappa(x)\to L$ と合成すれば射を得る。別のアフィン近傍でも共通のより小さいアフィン近傍を取ると同じ局所環の剰余写像を使うので一致する。よって選択によらず、二操作は互いに逆である。
:::

:::example[数体の閉点が二通りの体値点を持つ]
$X=\operatorname{Spec}\Q[t]$ の点 $(t^2-2)$ の剰余体は $\Q(\sqrt2)$ である。$\Q$ への埋め込みはなく、この点を像とする $\Q$ 値点はない。一方 $L=\R$ には $\sqrt2\mapsto\sqrt2$ と $\sqrt2\mapsto-\sqrt2$ の二つの埋め込みがある。従って二つの異なる実数値点が同じスキームの点を像とする。$L=\Q(t)$ を試験体にして座標の像を同じ名前の超越元に取れば、その核は零であり、像はジェネリック点である。試験体を替えることで閉点だけでなくジェネリック点も一つの点の射として表せる。
:::

:::example[閉点の集まりから閉集合を回復する]
代数閉体上の有限型アフィン環 $A$ で、$V(I)$ の任意の非空な相対基本開 $D(f)\cap V(I)$ を考える。$(A/I)_f$ は補助変数で $fu=1$ を課した有限型 $k$ 代数であり、開が非空なら零環ではない。従って極大イデアルがあり、弱零点定理で剰余体は $k$ になる。その $A$ への縮約は $k$ への評価の核なので極大である。よって相対基本開は $X$ の閉点を含む。これが全ての閉集合で成り立つため、$X$ の閉点のうち $V(I)$ に入るものは $V(I)$ に稠密である。従って二つの閉集合が閉点で一致すれば閉集合全体が一致するが、構造層の冪零な違いまで決まるわけではない。
:::

### ジェネリック点を局所化して成分を読む

:::example[二成分の茎と交点の茎を比較する]
$A=k[x,y]/(xy)$ の極小素イデアルは $(x)$ と $(y)$ である。$(x)$ では $y$ を反転して $x=0$ になるため、茎は $k(y)$ である。同様に $(y)$ の茎は $k(x)$ である。原点 $(x,y)$ の茎では両変数は消えず、$xy=0$ の関係を持つ。そこで例えば $x+y$ は原点での極大イデアルに入るが、二つのジェネリック点ではそれぞれ $y$、$x$ の非零元となる。従って特定の関数がジェネリック点で単元になっていても、交点で単元になるとは限らない。
:::

:::example[ジェネリック点で被約でも閉点に冪零が残る]
$A=k[x,y]/(x^2,xy)$ を考える。全ての素イデアルは $x$ を含むため、台は $k[y]$ のスペクトルである。唯一のジェネリック点 $(x)$ では $y$ が単元となるので $x=0$ となり、茎は $k(y)$ である。一方 $(x,y)$ の茎には $x$ が非零で残る。実際、$x^2=xy=0$ により $A$ の元は $a(y)+bx$ と一意に書ける。定数項 $a(0)$ が非零の元で $x$ を掛けると、その結果は $a(0)x\ne0$ である。従ってどの分母でも $x$ を消せない。ジェネリック点の茎は多様体の関数体を記録するが、特異な閉点付近の冪零元まで検出できるわけではない。
:::

## 例：Spec ℤ・非被約スキーム・射影空間

:::example[整数のスペクトル]
$\operatorname{Spec}\Z$ の点は $(0)$ と $(p)$（$p$ は素数）である。前者の剰余体は $\Q$、後者は $\Z/p\Z$ である。$D(6)$ は $(2),(3)$ だけを除く開集合で、その切断環は $\Z[1/6]$ である。$\operatorname{Spec}\Z$ には標数の異なる剰余体が同じ空間に現れる。
:::

:::example[同じ点をもつ異なるスキーム]
$\operatorname{Spec}k[\epsilon]/(\epsilon^2)$ と $\operatorname{Spec}k$ はどちらも一点である。前者の茎には非零の冪零元 $\epsilon$ があり、後者にはない。従って局所環付き空間としては同型でない。
:::

:::example[射影空間の構造層]
$S=A[X_0,\dots,X_n]$ とする。$D_+(X_i)$ の環は $A[X_j/X_i:j\ne i]$ であるから $\mathbb P^n_A=\operatorname{Proj}S$ は $n+1$ 個のアフィン $n$ 空間で覆われる。$\mathbb P^1_A$ の大域切断は $A[t]\cap A[t^{-1}]=A$ である。これは Laurent 多項式の係数を比較する計算なので $A$ に零因子があっても成り立つ。
:::

:::proposition[射影空間の大域切断]{#prop-ag-proj-space-global}
任意の可換環 $A$ と $n\ge0$ に対して $\Gamma(\mathbb P^n_A,\mathcal O)=A$ である。
:::

:::proof
$n=0$ では唯一の標準開の環が $A$ になる。$n\ge1$ では $D_+(X_0)$ 上の切断を $A[t_1,\ldots,t_n]$ の多項式と書く。$D_+(X_1)$ では座標を $s_0=1/t_1$、$s_j=t_j/t_1$（$j\ge2$）とする。$s_0^{a_0}\prod_{j\ge2}s_j^{a_j}$ は重なりで $t_1^{-a_0-\sum_{j\ge2}a_j}\prod_{j\ge2}t_j^{a_j}$ となる。各単項式の指数は相異なり、$t_1$ の指数は定数項以外で負である。これが第一開の多項式と一致するなら定数しか残らない。さらに任意の標準開の切断環から $D_+(X_0)$ との重なりへの制限は座標変数による局所化で単射である。従って第一開で定数なら全標準開で同じ定数になる。Laurent 単項式の独立性は $A$ に零因子があっても成り立つ。
:::

### 同じ位相を異なる商環で見る

:::example[整数の冪で切り出した閉部分]
$\operatorname{Spec}\Z/(12)$ の素イデアルは $2$ と $3$ の上の二つである。中国剰余定理で $\Z/(12)\simeq\Z/(4)\times\Z/(3)$ となるため各点が開閉である。$2$ の上の茎には非零の平方零元 $2$ があり、$3$ の上の茎は体である。剰余体はそれぞれ $\F_2,\F_3$ であり、茎と剰余体を比較すると $2$ の上にだけ厚みがある。
:::

:::example[射影直線の特殊ファイバー]
$\mathbb P^1_{\Z}$ の二標準開の環は $\Z[t]$ と $\Z[s]$ である。$5$ を零にしたファイバーでは $\F_5[t],\F_5[s]$ と同じ貼り合わせを得る。$\F_5$ 値点は $[1:a]$（$a\in\F_5$）の五つと $[0:1]$ の一つである。一方、閉点には $t^2+2$ に対応するものもある。$\F_5$ の平方は $0,1,4$ に限るのでこの式は既約で、剰余体は $\F_{25}$ となる。有理点の数は閉点全体の数とは異なる。
:::

### 同じ方程式を標数の異なる点で特殊化する

:::example[整数係数の円錐曲線の特別なファイバー]
素数 $p$ に対し、$X=\operatorname{Proj}\Z[X_0,X_1,X_2]/(X_0X_1-pX_2^2)$ を考える。$X_2=1$ の開では $xy=p$ である。$\Q$ 上では $p$ が単元なので $\Q[x,x^{-1}]$ のスペクトルになり、射影閉包は滑らかな二次曲線である。実際、射影の三偏微分 $X_1,X_0,-2pX_2$ は $\Q$ 上の射影点で同時に零にならない。$\F_p$ 上では $X_0X_1=0$ になり、二本の直線が $[0:0:1]$ で交わる。$X_0\ne0$ の近傍では $X_1/X_0=p(X_2/X_0)^2$ が消去でき、環は $\Z[X_2/X_0]$ である。従って無限遠のこの開からも、同じ座標表示で各標数の切断を読める。ファイバーの変化は基底上の $p$ の値を先に決めてから、環の関係を比較すると見える。
:::

:::example[整数の厚みと等標数の厚みを比べる]
$\operatorname{Spec}\Z/9\Z$ と $\operatorname{Spec}\F_3[\epsilon]/(\epsilon^2)$ はどちらも一点で、剰余体は $\F_3$、極大イデアルは平方零である。前者では極大イデアルは $3$ の類で生成され、後者では $\epsilon$ で生成される。両環の長さは二であるが、前者の $3\cdot1$ は非零、後者の $3\cdot1$ は零なので、単位を保つ環同型は存在しない。従って冪零の厚みの長さと剰余体が等しいだけではスキームは決まらない。特に $\Z$ からの構造写像を記録すると、前者は $9=0$ 上、後者は $3=0$ 上で定義される違いが明示される。
:::

:::example[射影平面の混合した二つの座標開]
$\mathbb P^2_{\Z}$ の $D_+(X_0)$ と $D_+(X_1)$ を取る。第一開で $u=X_1/X_0,v=X_2/X_0$、第二開で $s=X_0/X_1,w=X_2/X_1$ と書くと、重なりの写像は $s=1/u,w=v/u$ である。例えば $\F_5$ の点 $(u,v)=(2,3)$ は $(s,w)=(3,4)$ に移る。実際 $2^{-1}=3$、$3/2=9=4$ である。基底を $\Z/25\Z$ に替えても、$u=2$ が単元なので同じ式を使え、今度は $s=13,w=14$ になる。それを $\F_5$ へ移すと先の値が戻る。座標の変換は元の環の単元条件で定義されるので、標数や厚みが変わっても両立する。
:::

### 整数の上の素点を二次方程式で求める

:::example[$\Z[i]$ での三種類の特殊化]
$B=\Z[u]/(u^2+1)$ を考える。素数 $p$ 上のファイバーは $\F_p[u]/(u^2+1)$ である。$p=2$ では $u^2+1=(u+1)^2$ なので、一つの点に平方零の厚みがある。$p=3$ では平方は $0,1$ に限られ、$-1=2$ は平方でない。従って式は既約で、ファイバーは体 $\F_9$ の一点である。$p=5$ では $u^2+1=(u-2)(u+2)$ であり、二根は相異なる。中国剰余で環は $\F_5\times\F_5$ となり、二点を得る。さらに整数のジェネリック点上では $\Q[u]/(u^2+1)=\Q(i)$ となる。同じ整数係数の式が、素点ごとに重根、既約、分解という異なる形をとるため、それぞれの剰余体と厚みが変わる。
:::

### 有限体上の射影点を標準開で重複なく数える

:::example[射影平面の有理点と閉点]
$\mathbb P^2_{\F_3}$ の $\F_3$ 値点は、最初の非零成分が第一、第二、第三のどれであるかで分けられる。第一なら $[1:a:b]$ が $3^2$ 点、第二なら $[0:1:b]$ が $3$ 点、第三なら $[0:0:1]$ の一点であり、合計 $13$ 点である。同じ数は、非零の三成分ベクトル $3^3-1=26$ 個を $\F_3^\times$ の $2$ 個の倍率で割っても得られる。一方、標準開の環 $\F_3[x,y]$ には $(x^2+1,y)$ という極大イデアルがある。剰余体は $\F_9$ で、これは今数えた $13$ 点に含まれない閉点である。有限体上で「点数」と述べる際には、どの試験体に値を取る点かを明示する。
:::

## 演習問題

::::exercise{level=basic}
$\operatorname{Spec}\Z$ の $D(12)$ から除かれる閉点を求めよ。

:::solution
$12=2^2\cdot3$ なので $12$ を含む素イデアルは $(2)$ と $(3)$ である。
:::
::::

::::exercise{level=basic}
$k[t]$ の $(0)$ と $(t)$ の剰余体を求めよ。

:::solution
それぞれ $\operatorname{Frac}k[t]=k(t)$、$\operatorname{Frac}(k[t]/(t))=k$ である。
:::
::::

::::exercise{level=basic}
$D(f)=\varnothing$ となる条件を求めよ。

:::solution
全素イデアルが $f$ を含む条件であり、素イデアルの共通部分は零イデアルの根基なので $f$ の冪零性に等しい。
:::
::::

::::exercise{level=basic}
$\mathbb P^2_A$ の $D_+(X_1)$ の環を求めよ。

:::solution
$u=X_0/X_1,v=X_2/X_1$ を取ると次数零の全ての分数がこの二変数の多項式に書けるので $A[u,v]$ である。
:::
::::

::::exercise{level=advanced}
$\operatorname{Spec}k[x,y]/(xy)$ のジェネリック点を求めよ。

:::solution
素イデアルは $xy=0$ より $x$ または $y$ を含む。$(x)$、$(y)$ の商は多項式環で素であり、両者の包含関係はないため、各既約成分のジェネリック点はこの二点である。
:::
::::

::::exercise{level=advanced}
$\operatorname{Spec}(A\times B)$ の開分解を示せ。

:::solution
$e=(1,0),1-e=(0,1)$ の積は零で和は $1$ である。従って $D(e)$ と $D(1-e)$ は交わらず全体を覆う。$e$ を逆にすると $e=1$ となり $B$ 成分が消える。もう一方では $A$ 成分が消えるので構造層を含めて二つのスペクトルの直和になる。
:::
::::

::::exercise{level=advanced}
$S=k[X,Y]/(Y^2)$ で $\operatorname{Proj}S$ を求めよ。

:::solution
全ての斉次素イデアルが $Y$ を含むため $D_+(X)$ が全体である。次数零元 $u=Y/X$ には $u^2=0$ だけが課されるので $\operatorname{Spec}k[u]/(u^2)$ である。
:::
::::

::::exercise{level=advanced}
$\Z[1/6]$ 上の点を $\operatorname{Spec}\Z$ の点として記述せよ。

:::solution
局所化による素イデアル対応で $6$ の冪を避ける素イデアルに限られる。従って $(0)$ と、$p\ne2,3$ の全ての $(p)$ である。
:::
::::

::::exercise{level=advanced}
$A=\Z/12\Z$、$S=A[X,Y]/(2Y,Y^2)$ を標準次数とする。$\operatorname{Proj}S$ の点と各点の局所環を求めよ。冪零元 $Y$ の情報が各点に残るかも調べよ。

:::solution
$Y^2=0$ なので、全ての斉次素イデアルが $Y$ を含む。従って $D_+(Y)$ は空であり、残る $D_+(X)$ が全体である。$u=Y/X$ とおけば、その次数零環は $A[u]/(2u,u^2)$ である。実際、$X$ を反転して $Y=Xu$ を代入すると斉次関係は $2u=0$ と $u^2=0$ に等しく、$X$ の冪を除いた成分がこの環になる。

$A=\Z/4\Z\times\Z/3\Z$ に分ける。テンソル積または二つの冪等元による分解で
$$
A[u]/(2u,u^2)\simeq
(\Z/4\Z)[u]/(2u,u^2)\ \times\ \Z/3\Z
$$
となる。第二因子では $2$ が単元なので $u=0$ である。第一因子では $2$ と $u$ がともに平方零で、剰余環 $\F_2$ 以外の素点を作らない。具体的には $(2,u)$ が唯一の極大イデアルであるため、第一因子全体がその点の局所環である。$u$ はさらに $2=0$ とした商 $\F_2[u]/(u^2)$ で非零なので第一因子でも非零である。従って点は二つで、$Y/X$ の冪零情報は $2$ の上だけに残る。第二の点の局所環は $\F_3$ である。
:::
::::

::::exercise{level=advanced}
$S=k[X,Y,Z]$ を重み $(1,1,2)$ で次数付ける。$\operatorname{Proj}S$ の点 $\mathfrak p=(X,Y)$ を含む標準開を特定し、その茎と剰余体を求めよ。$D_+(X)$ で同じ点を調べられない理由も述べよ。

:::solution
$\mathfrak p$ は正次数の $Z$ を含まないので Proj に属し、$D_+(Z)$ に入る。次数零環の三つの生成元は $a=X^2/Z$、$b=XY/Z$、$c=Y^2/Z$ である。次数零の単項式は $X,Y$ を二個ずつ組にしてこの三元の積にできる。関係 $ac=b^2$ を使えば $b$ の指数を $0$ または $1$ にでき、代入するとその二種類は $(X,Y)$ の指数の偶奇が異なる。このため独立に残り、次数零環は $B=k[a,b,c]/(ac-b^2)$ となる。

斉次素イデアル $\mathfrak p$ の次数零への縮約は $(a,b,c)$ である。実際この三つはすべて $X,Y$ の正の冪を含み、定数項は $\mathfrak p$ には入らない。よって茎は $B_{(a,b,c)}$ で、その剰余体は $k$ である。$X\in\mathfrak p$ だから $D_+(X)$ はこの点を含まない。$Z$ が可逆という条件で計算した環に、さらに $X$ で割ることを全ての点で許すと、この点そのものが除かれてしまう。
:::
::::

## 確認テスト

::::quiz{answer="2" tol="1e-6"}
$\operatorname{Spec}(\Z/12\Z)$ は何点か。

:::explanation
商環の素イデアルは $(12)$ を含む整数の素イデアルに対応する。該当するのは $(2),(3)$ の二つである。
:::
::::

::::quiz
$\operatorname{Spec}k[t]$ の全空間のジェネリック点を選べ。

- [x] $(0)$
- [ ] $(t)$
- [ ] $(t-1)$

:::explanation
$(0)$ は整域の素イデアルであり、その閉包 $V(0)$ は全空間である。$(t)$ と $(t-1)$ は極大で閉点である。
:::
::::

::::quiz{answer="2" tol="1e-6"}
$k[\epsilon]/(\epsilon^2)$ の $k$ 次元はいくつか。

:::explanation
$1,\epsilon$ の二つが基底であり、二次以上は零なので $2$ である。
:::
::::

::::quiz
$\operatorname{Proj}S$ の $D_+(f)$ の切断環を選べ。

- [x] $(S_f)_0$
- [ ] $S_f$
- [ ] $S/(f)$

:::explanation
$f$ を局所化し、次数零元だけを使って標準開を表す。全局所化環では通常は余分な非零次数の元が入る。
:::
::::
