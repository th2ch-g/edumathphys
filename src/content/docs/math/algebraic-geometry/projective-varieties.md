## この章の目標

- 射影点をアフィン標準開集合の座標で表す。
- 斉次零点定理で空集合と非空集合を区別する。
- 飽和を取って射影閉包を計算する。
- 三種類の埋め込みを方程式と逆写像で説明する。

## 射影空間と斉次座標

平行線の交わりを扱うには、一つのアフィン座標系の外に点を加える必要がある。この章では前章と同様に $k$ を代数閉体とし、$k^{n+1}$ の一次元部分空間を点とみなす。

:::definition[射影空間]{#def-ag-projective-space}
:term[射影空間]{en="projective space" yomi="しゃえいくうかん"} $\mathbb P^n_k$ は $k^{n+1}\setminus\{0\}$ を $a\sim\lambda a$（$\lambda\in k^\times$）で割った集合である。点を $[a_0:\cdots:a_n]$ と書き、代表の成分を :term[斉次座標]{en="homogeneous coordinate" yomi="せいじざひょう"} という。
:::

$S=k[X_0,\dots,X_n]$ を全次数で次数付ける。次数 $d$ の斉次式 $F$ は $F(\lambda a)=\lambda^dF(a)$ を満たすので、零点という条件は代表に依存しない。斉次式の共通零点集合 $V_+(J)$ を閉集合とする。任意交叉は方程式を合わせればよく、二つの閉集合の和は方程式の積で表せるため、これは位相を定める。

:::proposition[標準座標近傍]{#prop-ag-projective-charts}
$U_i=D_+(X_i)=\{[a]:a_i\ne0\}$ は $(a_j/a_i)_{j\ne i}$ を通じて $\mathbb A^n$ と同相である。$U_i\cap U_j$ での座標変換は $X_\ell/X_j=(X_\ell/X_i)/(X_j/X_i)$ である。
:::
:::proof
代表を $a_i=1$ に正規化すると、任意の $n$ 個の座標から点が一意に戻る。斉次方程式を $X_i=1$ として制限すればアフィンの閉集合を得る。逆にアフィン式 $f$ は $X_i^{\deg f}f((X_j/X_i)_{j\ne i})$ によって斉次化できるため、相対閉集合をすべて得る。変換式は分母を揃えれば従う。
:::

:::example[平行線の交点]
$\mathbb A^2$ の直線 $y=1$、$y=2$ を $U_0$ に置く。射影での式は $X_2-X_0$、$X_2-2X_0$ で、両式を引くと $X_0=0$、さらに $X_2=0$ となる。従って交点は $[0:1:0]$ である。
:::

:::example[射影部分空間の方程式]
$k^4$ の部分空間が $X_0+X_1=X_2+X_3=0$ で定まるとする。$(a,-a,b,-b)$ が全ベクトルなので、零以外をスカラー倍で割った点は $[a:-a:b:-b]$ と書ける。従ってこの部分空間を射影化すると射影直線になる。二本の独立な一次方程式が射影空間の次元を二つ下げた例である。
:::

:::example[同次でない式は零を保たない]
式 $X_0+1$ は代表 $( -1,1)$ では零である。これを $\lambda\ne0,1$ で倍すると値は $1-\lambda$ となり、同じ射影点なのに消えない。これに対して $X_0-X_1$ の消滅はどの代表でも同じである。非斉次の式は、まず $X_i=1$ という開集合の規約を指定すれば使える。
:::

### 射影線形部分空間と座標の選択

$W\subset k^{n+1}$ を零でない線形部分空間とする。$W$ 内の一次元部分空間の集合を $\mathbb P(W)$ と書く。$W$ を切り出す一次形式の零点集合なので射影閉集合である。逆に斉次一次方程式だけで定まる非空閉集合は、係数行列の核を $W$ と置けばこの形である。

:::proposition[線形部分空間の交わりと張る空間]
$W_1,W_2$ に対し、$\mathbb P(W_1)\cap\mathbb P(W_2)=\mathbb P(W_1\cap W_2)$ である。右辺で $\mathbb P(0)$ は空とする。また両者を含む最小の射影線形部分空間は $\mathbb P(W_1+W_2)$ である。
:::

:::proof
ある点を表す一次元部分空間が双方に入ることは、その生成ベクトルが $W_1\cap W_2$ に属することに等しい。各 $\mathbb P(W_i)$ を含む $\mathbb P(W)$ は、その点を表すベクトル全てを含むため $W_1+W_2\subset W$ である。逆に $W_1+W_2$ 自身は双方を含む。
:::

:::example[平行線の交点]
$\mathbb A^2$ 内の $y=2x+1$ と $y=2x+3$ を標数零で考える。射影座標を $[X:Y:Z]$ とすれば閉包は $Y=2X+Z$、$Y=2X+3Z$ である。二式の差から $2Z=0$、従って $Z=0$ かつ $Y=2X$ となり、唯一の交点は $[1:2:0]$ である。方向 $(1,2)$ が同じ二直線は無限遠直線で同じ点をもつ。
:::

:::example[三点が張る部分空間]
$\mathbb P^3$ の $[1:0:1:0]$、$[0:1:0:1]$、$[1:1:1:1]$ の代表ベクトルを列に並べると、第三列は最初の二列の和である。最初の二列は独立なので三点は一次元の射影線形空間 $X_0=X_2,\ X_1=X_3$ を張る。$X_0\ne0$ の近傍では $X_2/X_0=1$、$X_1/X_0=X_3/X_0=t$ となる。この近傍に入らない点は $[0:1:0:1]$ の一つである。
:::

### 射影座標を点の配置から決める

原点と基底を使うアフィン座標とは異なり、射影座標では各ベクトルの倍率は点から復元できない。その倍率を揃えるために、座標点に加えて全成分が非零の一点を使う。

:::definition[射影標構]
$\mathbb P^n$ の順序付き $n+2$ 点 $(p_0,\ldots,p_n,q)$ について、どの $n+1$ 点の代表ベクトルも一次独立であるとき、これを :term[射影標構]{en="projective frame" yomi="しゃえいひょうこう"} という。
:::

:::proposition[射影標構を移す変換]{#prop-ag-projective-frame}
二つの射影標構を順序を保って移す射影線形変換がただ一つ存在する。
:::

:::proof
第一の標構の $p_i$ の代表 $v_i$ は基底である。$q$ の代表を $w=\sum_i c_i v_i$ と書く。もし $c_i=0$ なら $q$ と $i$ を除く $n$ 個の点の代表が従属になる。従って全て $c_i\ne0$ である。$e_i$ を $c_i v_i$ へ移す線形同型は、標準の座標点と $[1:\cdots:1]$ をこの標構へ移す。第二の標構についても同じ操作ができるので、逆を一つ合成すれば存在する。一意性のため標準標構を固定する変換を取る。各座標点を固定する行列は対角行列であり、$[1:\cdots:1]$ を固定するには対角成分が同じでなければならない。従って射影点上で恒等である。
:::

:::example[四点で平面の座標を正規化する]
標数零で $p_0=[1:0:1]$、$p_1=[0:1:1]$、$p_2=[0:0:1]$、$q=[2:3:4]$ を取る。三つの代表を列にした行列は行列式 $1$ をもち、$q$ の代表は $2v_0+3v_1-v_2$ である。従って四点は標構をなし、標準標構からの行列として
$$
M=\begin{pmatrix}2&0&0\\0&3&0\\2&3&-1\end{pmatrix}
$$
を取れる。例えば $[1:1:0]$ を移すと $[2:3:5]$ になる。この点は $p_0,p_1$ の張る直線にあり、元の $p_0$ からのベクトル $2v_0$ と $p_1$ からのベクトル $3v_1$ の和で表される。$q$ の係数を揃えず単に三代表を列にすると、$[1:1:1]$ が $[1:1:3]$ へ移り、第四点が指定どおりにならない。
:::

### 射影直線上の四点を比べる複比

$\mathbb P^1$ では相異なる三点は射影標構である。従って三点を $\infty,0,1$ に固定する座標を取れ、残る一点の値が四点の配置を表す。具体的な計算には、二つの代表 $v_i,v_j$ を列に並べた行列式 $[i,j]=\det(v_i,v_j)$ が使える。

:::proposition[複比と正規化]
相異なる四点 $p_a,p_b,p_c,p_d$ に対して
$$
\lambda=\frac{[a,c][b,d]}{[a,d][b,c]}
$$
は代表によらず射影線形変換で保たれる。前三点を $\infty,0,1$ とした座標における第四点の値は $\lambda$ である。
:::

:::proof
各代表を倍率で変えても、その倍率は分子と分母に同じ回数だけ現れる。共通の行列で変換すると各行列式は同じ行列式倍になるので、これも比から消える。有限座標 $t$ の代表を $(1,t)$、無限遠の代表を $(0,1)$ とする。正規化した前三点に対し第四点は有限値 $u$ をもち、行列式は $[a,c]=[a,d]=-1$、$[b,d]=u$、$[b,c]=1$ になるから比は $u$ である。前三点の正規化が一意なので、二組の順序付き四点は複比が等しい場合に限り射影変換で移り合う。
:::

:::example[有限座標だけで複比を求める]
$\C$ 上の四点 $0,1,2,4$ をこの順に取る。有限点の行列式は $[i,j]=t_j-t_i$ なので複比は $(2-0)(4-1)/((4-0)(2-1))=3/2$ である。実際、前三点を $\infty,0,1$ へ移す式は $u=2(t-1)/t$ であり、$t=4$ は $3/2$ に移る。前三点のうち第二点と第三点を入れ替えると座標は $1-u$ になり、値は $-1/2$ になる。点の集合を考えるときと、この順序付きの不変量を使うときでは、並べ替えを許すかどうかを指定する。
:::

## 斉次イデアルと射影的零点定理

斉次イデアルとは、元の全斉次成分が再びイデアルに属するイデアルである。これは斉次生成元をもつことと同値である。集合 $Y\subset\mathbb P^n$ に対し、$Y$ 上で消える斉次式の各次数の空間を直和して $I_+(Y)$ と書く。空でない既約な射影閉集合を :term[射影多様体]{en="projective variety" yomi="しゃえいたようたい"} という。$S_+=(X_0,\dots,X_n)$ は :term[無関係イデアル]{en="irrelevant ideal" yomi="むかんけいいである"} である。

:::theorem[射影的零点定理]{#thm-ag-projective-nullstellensatz}
$J\subset S$ を斉次イデアルとする。$V_+(J)=\varnothing$ であることと $S_+\subset\sqrt J$ は同値である。$V_+(J)\ne\varnothing$ なら $I_+(V_+(J))=\sqrt J$ である。
:::
:::proof
非零ベクトルの零点をスカラー倍で割ると射影零点を得る。真の斉次イデアル $J$ のアフィン零点集合は原点を含む。よって射影零点が空ならアフィン零点は原点だけであり、:ref[thm-ag-affine-nullstellensatz] から $\sqrt J=S_+$ となる。$J=S$ の場合も包含を満たす。逆に $S_+\subset\sqrt J$ なら全座標が零になるので射影点はない。

射影零点があるとき、そこで消える正次数斉次式は非零代表でも原点でも消える。次数零の消える式は零だけである。したがって各斉次成分にアフィン零点定理を適用すると $I_+\subset\sqrt J$ となる。逆のため、$\sqrt J$ が斉次であることを示す。アフィン零点集合はスカラー倍で閉じるので、そこで消える多項式 $F=\sum_d F_d$ については任意の零点 $a$ で $\sum_d \lambda^dF_d(a)=0$ が無限個の $\lambda$ に対し成り立つ。ゆえにすべての $F_d$ が消える。これを零点定理で $\sqrt J$ に移せば、各成分が $I_+$ に入る。
:::

:::example[原点があっても射影点は空]
$\mathbb P^1$ における $J=(X_0^2,X_1^3)$ は真のイデアルであるが、$\sqrt J=(X_0,X_1)$ であるから射影零点をもたない。空集合の $I_+$ は $S$ であり、この場合 $\sqrt J$ と異なる。
:::

### 全標準開での消滅と飽和

:::proposition[無関係イデアルによる飽和]{#prop-ag-projective-saturation}
斉次イデアル $J\subset S=k[X_0,\dots,X_n]$ に対し
$$
I_+(V_+(J))=\sqrt J:S_+^\infty,\qquad
L:S_+^\infty=\bigcup_{m\ge0}\{F:S_+^mF\subset L\}
$$
である。
:::
:::proof
零点が非空なら :ref[thm-ag-projective-nullstellensatz] により $I_+=\sqrt J$ である。これが右辺と等しいことを、斉次式 $F$ で調べる。$S_+^mF\subset I_+$ なら、任意の射影零点で非零な座標 $X_i$ を選び $X_i^mF=0$ と評価できる。従って $F$ は全射影零点で消え、$I_+$ に入る。逆包含はイデアルの性質である。空の場合は $S_+\subset\sqrt J$ だから右辺は全環であり、左辺も全環である。
:::

:::example[同じ閉集合を定める斉次イデアル]
$\mathbb P^2$ で $J=(X_0^2,X_0X_1,X_0X_2)$ を取る。$X_0^2$ があるので零点は $X_0=0$ に限られ、そこで他の二式も消える。根基と $S_+$ による飽和はいずれも $(X_0)$ であるが、$J$ 自体は $X_0$ を含まない。$J$ は一次の元をもたず、$X_0$ は次数 $1$ だからである。
:::

### アフィン錐と無関係な原点

射影閉集合 $X$ の :term[アフィン錐]{en="affine cone" yomi="あふぃんすい"} は、$X$ の点の代表ベクトルと原点を合わせた集合である。$X$ が正次数の斉次方程式で定まるとき、その式をアフィン空間で課せば錐が得られる。空集合の錐は原点だけとする。$X\ne\varnothing$ とすると、錐上で消える多項式 $f=\sum_d f_d$ の各斉次成分も消える。実際、錐上の $a$ を固定し $0\ne t\in k$ を動かすと、$\sum_d t^d f_d(a)$ が無限個の零点をもつ。このため射影消滅イデアルは斉次である。

:::example[同じ射影点を定める異なる斉次商]
$S=k[X,Y]$、$J=(X^2,XY)$ とする。零点条件で $X=0$ となるので $V_+(J)=\{[0:1]\}$ である。$Y\ne0$ の標準開では $XY/Y^2=X/Y$ が生成元となり、座標環は $k$ である。$X\ne0$ の標準開では $X^2/X^2=1$ なので空である。飽和は $(X)$ になる。実際 $X(X,Y)\subset J$ であり、包含 $J\subset(X)$ と、$Y$ を掛けても $(X)$ に入らない元については飽和でも残らないことから逆包含を得る。
:::

:::example[飽和しても残る二重点]
$J=(X^2)\subset k[X,Y]$ とする。今度も点集合は $[0:1]$ だけだが、$Y\ne0$ での環は $k[x]/(x^2)$、$x=X/Y$ である。$Y$ は $S/(X^2)$ で非零因子なので、$h\,(X,Y)^N\subset(X^2)$ なら特に $hY^N\in(X^2)$ から $h\in(X^2)$ となる。従って $J$ は飽和している。飽和は全標準開で見えない項を落とす操作であり、射影点の近くで見える冪零元には根基を取るまで作用しない。
:::

### 既約性を斉次環で判定する

:::proposition[既約な射影閉集合と素イデアル]{#prop-ag-projective-prime}
空でない射影閉集合 $X$ が既約であることと $I_+(X)$ が素イデアルであることは同値である。さらにこのときアフィン錐は既約である。
:::

:::proof
斉次元 $F,G$ の積が $I_+(X)$ に入るなら、$X$ は $F$ と $G$ のそれぞれの零点集合との交わりの和である。既約なら一方が全体で、$F,G$ の一方が $I_+(X)$ に入る。ここで二式の次数は等しい必要がなく、各式の消滅だけを使う。従って斉次商で非零の二つの斉次元の積が非零であり、一般の二元については最高次の非零成分の積を調べれば零積がない。逆に $X=X_1\cup X_2$ が真の閉分解なら、各 $X_i$ で消えて $X$ 全体では消えない斉次元を一つ選べる。例えば $X_i$ を切り出す斉次式が全て $X$ で消えれば $X_i=X$ になる。二つの元の積が $X$ で消えるので商は整域でない。アフィン錐の消滅イデアルは斉次成分を分離する議論で $I_+(X)$ と一致し、素性により既約である。
:::

:::example[無限遠を選び直して同じ交点を見る]
$X=V_+(XY)\subset\mathbb P^2$ の消滅イデアルは $(XY)=(X)\cap(Y)$ である。標準開 $Z\ne0$ では商が $k[x,y]/(xy)$ で交点は原点になる。$X\ne0$ の開では $Y=0$ の成分だけが残り、$Y\ne0$ の開では $X=0$ の成分だけが残る。この場合の交点 $[0:0:1]$ は $Z\ne0$ にあるが、別の座標 $W=X+Y$ を無限遠の式に指定すれば同じ交点が $W=0$ に入る。有限か無限遠かは開集合の選び方による。
:::

### 斉次商から全標準開に共通する飽和を作る

各標準開で正しい式を求められた場合、今度はそれらが同じ射影閉部分を表すかを確かめたい。局所環での式を斉次環へ戻すには、それぞれの開で可逆にした座標を掛けてよいという条件を使う。

:::proposition[飽和の標準開による計算]{#prop-ag-projective-chart-saturation}
$S=k[X_0,\dots,X_n]$ の斉次イデアル $J$ に対して
$$
J:S_+^\infty=\bigcap_{i=0}^n(J:X_i^\infty)
$$
である。また二つの斉次イデアルが全ての標準開で同じ非斉次イデアルを与えることと、両者の飽和が等しいことは同値である。
:::

:::proof
$S_+^N F\subset J$ なら各 $X_i^N F$ が $J$ に入る。逆に各 $i$ に $N_i\ge1$ を取って $X_i^{N_i}F\in J$ とする。$N=1+\sum_i(N_i-1)$ と置けば、全次数 $N$ のどの単項式にも、ある $i$ に対して $X_i^{N_i}$ が因子として現れる。従って $S_+^N F\subset J$ である。これが共通部分の式を示す。

斉次 $F$ の次数を $d$ とし、$D_+(X_i)$ での非斉次式 $F/X_i^d$ を考える。これが $(JS_{X_i})_0$ に入ることは、$F\in JS_{X_i}$ と同値である。両者の差は局所化で可逆な $X_i^d$ を掛けるかどうかだけだからである。局所化の核を確認すると、これは $X_i$ のある冪を掛けた $F$ が $J$ に入る条件に等しい。従って飽和は、全標準開で局所イデアルに入る斉次式を合わせて復元できる。逆に各標準開で飽和を局所化しても、$X_i$ が単元なので元の局所化は変わらない。従って飽和の等式は局所イデアルの等式を含意する。
:::

:::example[三つの開に異なる局所式が現れる]
$J=(X^2,XY,Y^2Z)\subset k[X,Y,Z]$ とする。$D_+(X)$ では $X^2$ が単元を与えるため空である。$D_+(Y)$ では $XY/Y^2=X/Y$、$Y^2Z/Y^3=Z/Y$ により一点 $[0:1:0]$ が残る。$D_+(Z)$ では $x=X/Z,y=Y/Z$ として $(x^2,xy,y^2)$ を得るので $[0:0:1]$ に長さ三が残る。飽和を計算すると
$$
(J:X^\infty)=S,\qquad(J:Y^\infty)=(X,Z),\qquad(J:Z^\infty)=(X,Y)^2
$$
である。例えば第二式では $XY,Y^2Z$ により $X,Z$ が入る。$Y$ だけの単項式はどれだけ $Y$ を掛けても $J$ に入らないので、他の生成元は必要ない。第三式も $Z$ の冪を掛ける条件で単項式ごとに確かめられる。従って飽和は $(X,Z)\cap(X,Y)^2=(X^2,XY,Y^2Z)$ であり、元の $J$ と等しい。二つの点の局所構造を確認しても、無関係イデアルによって消える成分を仮定しなくてよいことが分かる。
:::

:::example[飽和の計算に根基を混ぜない]
上の $J$ に $J'=(X,Y)^3+(Y^2 Z)$ を取って比較する。$D_+(Y)$ では $Y^3$ により $J'$ は単位イデアルになるので、$[0:1:0]$ が消える。$D_+(Z)$ では $(x^3,x^2y,y^2)$ を得て、余りは $1,x,x^2,y,xy$ の五項である。$D_+(Z)$ 上で両イデアルの根基は $(x,y)$ で一致するが、$J$ の局所商には $x^2,xy$ が零になり $J'$ の局所商には残る。従って局所化で失われる原点の寄与と、局所化した環でも残る冪零情報は、この計算で分けて扱える。
:::

### 有限点で斉次式の評価を独立にする

:::proposition[有限集合への斉次補間]
射影空間の $r$ 個の相異なる点について代表ベクトルを固定する。$d\ge r-1$ なら、各点に任意の値を指定する $d$ 次斉次式が存在する。
:::

:::proof
点 $p_i$ ごとに、他の点 $p_j$ では消え $p_i$ では非零の一次式 $\ell_{ij}$ を取る。これは二つの代表が比例しないので、後者を消さず前者を消す線形形式が存在することによる。積 $\prod_{j\ne i}\ell_{ij}$ は次数 $r-1$ で $p_i$ だけで非零である。$p_i$ で非零の一次式をさらに掛けて次数を $d$ に揃え、代表での値を $1$ に規格化する。この式の線形結合で各指定値を与えられる。
:::

:::example[三点が共線な場合とそうでない場合]
$\mathbb P^2$ の三座標点では一次式 $X,Y,Z$ の評価がそれぞれ一つの点で $1$、他で $0$ になる。従って既に次数一で評価階数は三である。一方、$[1:0:0],[0:1:0],[1:1:0]$ の三点には、一次式の値として $(a,b,a+b)$ しか指定できないため階数は二である。次数二では $XY$ が最初の二点で消え第三点で $1$ になるので、$X^2-XY,Y^2-XY,XY$ が独立な三指定を与える。同じ点数の集合でも、点の配置によって小さい次数の斉次商は異なる。
:::

## 射影閉包

:::definition[射影閉包と飽和]{#def-ag-projective-closure}
$U_0\simeq\mathbb A^n$ の部分集合 $X$ の $\mathbb P^n$ における閉包を :term[射影閉包]{en="projective closure" yomi="しゃえいへいほう"} と呼ぶ。$K:X_0^\infty=\{F:\exists m\ge0,\ X_0^mF\in K\}$ を $X_0$ による :term[飽和]{en="saturation" yomi="ほうわ"} という。
:::

:::proposition[生成元の斉次化と飽和]{#prop-ag-homogenization}
$X\subset U_0$ を閉集合とし、$I(X)=(f_1,\dots,f_r)$ とする。$K=(f_i^h)$ を各生成元の斉次化のイデアルとすると $I_+(\overline X)=K:X_0^\infty$ である。
:::
:::proof
斉次式 $F$ が $X$ で消えることと、$F(1,x)$ が $I(X)$ に属することは同値である。$F(1,x)=\sum g_i f_i$ と書き、$N\ge\deg F,\deg g_i+\deg f_i$ を取る。各項を次数 $N$ に斉次化すると $X_0^{N-\deg F}F=\sum_i X_0^{N-\deg g_i-\deg f_i}g_i^hf_i^h$ となる。これは $F\in K:X_0^\infty$ を与える。逆に $X_0$ を $1$ とすれば飽和の斉次元は $X$ で消える。飽和は斉次であり、閉包上の消滅と $X$ 上の消滅は同値なので結論を得る。
:::

:::example[斉次化だけで余分な部分が出る場合]
$X=V(y-x^2,z-x^3)$ を $\mathbb A^3$ に置き、座標を $[W:X:Y:Z]$ とする。生成元を斉次化した $WY-X^2$ と $W^2Z-X^3$ は $W=X=0$ の直線全体で消える。一方、アフィンでは $z-xy$ と $y^2-xz$ も消える。閉包では $WZ-XY=0$、$Y^2-XZ=0$ も課され、無限遠の点は $[0:0:0:1]$ だけになる。
:::

:::example[最高次の項が与える無限遠点]
標数 $2$ でないとし、アフィン曲線 $x^2+y^2=1$ を $U_0$ に置く。この式に重複因子があれば、その因子は二つの偏導関数 $2x,2y$ の共通因子になる。よって元の式は平方因子をもたない。射影閉包は $X_1^2+X_2^2-X_0^2=0$ である。この式は $X_0$ の倍数でないため、主イデアルは $X_0$ に関して飽和している。$X_0=0$ 上で $X_1^2+X_2^2$ は異なる二つの一次因子に分かれ、無限遠点は $[0:1:i]$ と $[0:1:-i]$ である。ここで $i^2=-1$ とした。同じ次数の放物線 $x^2=y$ では無限遠点が一つであるため、無限遠の点の個数は次数だけからは決まらない。
:::

:::example[式を斉次化する順序]
$I=(y-x^2,z-xy)$ のとき、$WY-X^2$ と $WZ-XY$ の差の組み合わせ
$$
X(WZ-XY)-Y(WY-X^2)=W(XZ-Y^2)
$$
を取ると、$XZ-Y^2$ が $W$ による飽和に属する。$W=0$ を上の二式に代入するだけでは $X=0$ しか課されないが、第三式を加えると $Y=0$ も課される。従って生成元を先に二本に絞る場合は、その後に飽和を取る必要がある。閉包の無限遠部分は $W=0$ とその飽和イデアルの共通零点として求める。
:::

### 標準開の外に生じる余分な成分

:::example[連立方程式の斉次化が直線を加える場合]
$\mathbb A^3$ の $y=x^2,\ z=x^3$ を斉次座標 $[W:X:Y:Z]$ で考える。そのまま斉次化した二式は $WY-X^2$、$W^2Z-X^3$ である。$W=0$ とすると $X=0$ だけが残り、全直線 $W=X=0$ が入ってしまう。一方元の曲線では $z=xy$ が成り立つため、閉包では $WZ-XY$ も消える。さらに $x z=y^2$ から $XZ-Y^2$ を得る。三式
$$
WY-X^2=0,\quad WZ-XY=0,\quad XZ-Y^2=0
$$
を課すと、$W=0$ では $X=Y=0$ となり $[0:0:0:1]$ だけが残る。この点は $[s^3:s^2t:st^2:t^3]$ において $s=0$ の像である。$s\ne0$ は $\mathbb P^1$ で稠密なので、その像の閉包に $s=0$ の像も入る。従って三式の零点集合は余分な成分を含まない。
:::

:::example[同じアフィン曲線の異なるコンパクト化]
$t\mapsto(t,t^2)$ の平面での閉包は $W Y=X^2$ であり、$[s:t]\mapsto[s^2:st:t^2]$ が逆座標をもつ同型を与える。これに対し $t\mapsto(t,t^3)$ の閉包は $W^2Y=X^3$ であり、無限遠点 $[0:0:1]$ の近傍 $Y=1$ で $w^2=x^3$ となる。二曲線のアフィン部分はどちらも $t$ で座標付けできるが、無限遠の局所環の極大イデアルの一次部分は前者で一生成、後者で二生成である。従ってアフィン曲線だけから、その特定の射影埋め込みによる無限遠の局所形は決まらない。
:::

### 無限遠に現れる点を斉次化の後で調べる

アフィン曲線を射影閉包に移すとき、$Z=0$ の方程式から無限遠点の候補を得る。ただし複数の式を斉次化した場合は、まず $Z$ で飽和してからその候補を調べる。次の例では無限遠点が二つとも簡単に求まるが、それぞれの局所式は異なる。

:::example[双曲線を射影直線へコンパクト化する]
アフィン曲線 $xy=1$ の射影閉包は $XY=Z^2$ である。商で $Z$ は非零因子である。実際、$XY-Z^2$ は $Y$ について原始一次式なので既約であり、$Z$ を含むイデアルとは異なる。無限遠 $Z=0$ で $XY=0$ となり $[1:0:0]$、$[0:1:0]$ が得られる。$X\ne0$ では $u=Z/X$ として $Y/X=u^2$、$Y\ne0$ では $v=Z/Y$ として $X/Y=v^2$ になる。重なりでは $uv=1$ である。従って二標準開を合わせると $\mathbb P^1$ になり、元のアフィン曲線はその二点を除いた開である。元の $x=X/Z=1/u$ には第一の点で極があり、第二の点では $x=v$ となって零になる。
:::

:::example[アフィンの二成分が無限遠だけで出会う]
$y=1$ または $y=-1$ で定まるアフィン曲線を標数零で考える。消滅イデアルは $(y^2-1)$ である。射影閉包の式は $Y^2-Z^2=(Y-Z)(Y+Z)$ で、$Z$ と共通因子をもたないので追加の飽和は不要である。二つの射影直線は $[1:0:0]$ で交わる。$X=1$ の近傍で両式は $y-z=0$ と $y+z=0$ であり、和イデアルは $(y,z)$ になる。従って交わりは一点の被約構造である。$Z=0$ を閉包の方程式に直接加えると $y^2=0$ が残るので、無限遠直線との交わりは同じ一点でも長さ二になる。二成分間の交わりと、全曲線を無限遠直線で切る操作を区別すると両方の結果が説明できる。
:::

:::example[アフィンの点の射影閉包は点のままである]
アフィン三空間の原点を $(x,y,z)$ で記述する。方程式として $x-y,\ y-z,\ z^2,z(1-z)$ を取ると、最後の二つの和が $z$ なのでイデアルは $(x,y,z)$ である。ところが各生成元だけをその次数で斉次化すると、最後の二式 $Z^2,Z(W-Z)$ から得るのは $ZW$ までで、$Z$ 自体は斉次イデアルに入らない。飽和では $ZW=0$ を $W$ によって約分して $Z$ を得る。結果は $(X,Y,Z)$ で、射影閉包は $[1:0:0:0]$ である。ここでは $Z^2=0$ から全閉点で $Z=0$ となるが、飽和前の商環には $Z$ の類が平方零元として残る。生成元の斉次化を環の等式として使うには局所化との比較が要る。
:::

### 消去で射影閉包の飽和を求める

:::example[二つのグラフ条件を消去する]
$\mathbb A^3$ の $y=x^2,z=xy$ を $W=1$ に置く。生成元の斉次化 $WY-X^2,WZ-XY$ だけから出発すると $W=0,X=0$ の直線が現れる。ここで
$$
X(WZ-XY)-Y(WY-X^2)=W(XZ-Y^2)
$$
であり、飽和により $XZ-Y^2$ が加わる。三項を入れた後の商が整域になることは、$W=s^3,X=s^2t,Y=st^2,Z=t^3$ の核を計算すれば分かる。具体的には各変数に添字 $0,1,2,3$ を与え、二添字の和が等しい二単項式の組の差が三式であることを使う。積の総添字が同じなら、二因子間で差が二以上の添字を一ずつ中心に寄せられる。各回で添字の平方和が小さくなるので停止し、停止時は全添字が高々一しか違わない。この形は因子の個数と総添字から決まるため、同じ像の差は三式で生成される。従って商は $k[s,t]$ の部分環であり、非零の $W$ を掛けても新しく零になる元はない。これで三式を加えた段階で飽和が終わると分かる。
:::

## 斉次座標環

:::definition[斉次座標環]{#def-ag-homogeneous-ring}
射影閉集合 $Y\subset\mathbb P^n$ の :term[斉次座標環]{en="homogeneous coordinate ring" yomi="せいじざひょうかん"} を $A=S/I_+(Y)$ とする。次数零成分を $A_0$ と書き、斉次元 $h$ の局所化における次数零成分を $(A_h)_0$ と書く。
:::

:::proposition[標準開集合の座標環]{#prop-ag-projective-coordinate-localization}
$Y\cap U_i$ のアフィン座標環は $(A_{X_i})_0$ である。非空な $Y$ について $Y$ が既約であることと $A$ が整域であることは同値である。
:::
:::proof
$(A_{X_i})_0$ は各座標比 $X_j/X_i$ で生成される。座標比の多項式 $f$ が $Y\cap U_i$ で消えるなら、その斉次化 $F$ に $X_i$ を掛ければ $Y$ 全体で消えるので $F/X_i^{\deg F}=0$ となる。逆向きは局所化の零判定を $Y\cap U_i$ に評価すれば従う。

$Y$ が既約なら、斉次元 $F,G$ の積が消えるときに片方が消える。非零の一般の二元について最高次数の非零成分の積が非零となるので整域である。逆に $Y$ が二つの真の閉集合に分解されるなら、それぞれで消え $Y$ 全体では消えない斉次式が取れ、それらの積が零になる。
:::

:::example[同じ空間の異なる次数付け]
$[s:t]\mapsto [s^2:st:t^2]$ の像では次数 $1$ の座標が $s^2,st,t^2$ の三つである。元の射影直線では次数 $1$ の座標は $s,t$ の二つなので、同じ空間を表していても次数付き座標環を同一視できない。
:::

:::example[次数ごとの次元で埋め込みを比較する]
二次 Veronese 像では次数 $q$ の成分が $k[s,t]_{2q}$ なので次元は $2q+1$ である。通常の $\mathbb P^1$ の座標環の次数 $q$ の次元は $q+1$ であり、例えば $q=3$ では $7$ と $4$ になる。二つの開集合を貼り合わせた空間は同型であるのに、各次数の次元は違う。次数付けは、空間に加えて埋め込みで使った超平面を記録する。
:::

:::example[二次錐の斉次環と非斉次の標準開]
$A=k[X,Y,Z]/(XZ-Y^2)$ で各変数を次数一とする。$X\ne0$ では $u=Y/X$ が自由で $Z/X=u^2$ となる。局所化した環全体は $k[X,X^{-1},u]$ であるが、$X$ の次数は $1$ なので次数零部分は $k[u]$ に限られる。斉次局所化では逆にした座標の大きさの情報を保持しており、次数零を取ることでスカラー倍に依らない座標になる。
:::

### 斉次成分の次元と座標環

:::example[円錐曲線の斉次成分]
$B=k[X,Y,Z]/(XZ-Y^2)$ とする。項 $Y^2$ を $XZ$ に置換すれば、次数 $d$ の単項式で $Y$ の指数が $0$ または $1$ のものだけが残る。$X=s^2,Y=st,Z=t^2$ を代入すると、$Y$ の指数が $0$ の項は $t$ の指数が偶数、$1$ の項は奇数となり、すべて相異なる単項式になる。従ってこの簡約形は一意である。特に $d\ge1$ の次元は、$Y$ を含まない $d+1$ 項と $Y$ を一回含む $d$ 項を足した $2d+1$ である。$d=3$ なら $X^3,X^2Z,XZ^2,Z^3,X^2Y,XZY,Z^2Y$ が基底となる。
:::

:::example[局所化と次数零を順に取る]
同じ $B$ の $D_+(X)$ を調べる。$u=Y/X,v=Z/X$ と置くと $v=u^2$ なので次数零環は $k[u]$ である。$D_+(Z)$ では $u'=Y/Z$ を使い、$X/Z=(u')^2$ となる。重なりでは $u u'=Y^2/(XZ)=1$ である。こうして同じ次数付き環から二つのアフィン直線と貼り合わせが得られる。一方 $B_X$ 全体では $X$ の冪も残るので $k[u,X,X^{-1}]$ になる。次数零を取る操作が射影座標の共通倍率を除いている。
:::

### 斉次座標環の成分を埋め込みごとに比べる

斉次商の次数 $d$ は、選んだ埋め込みで次数 $d$ の斉次式を制限した空間である。射影多様体が同型でも、埋め込みに使う次数や線形部分系を変えると、この成分の次元は変わる。次の計算では標準開で同型を確認すると同時に、次数ごとの切断がどこまで周囲の座標から来るかを調べる。

:::example[射影直線の二つの座標環]
$\mathbb P^1$ 自身の斉次環は $k[s,t]$ であり、次数 $m$ の基底は $s^m,s^{m-1}t,\ldots,t^m$ である。二次 Veronese による像の環は $k[s^2,st,t^2]$ に標準次数を付けたものであり、次数 $m$ は元の次数 $2m$ に当たる。例えば $m=2$ では $(s^2)^2,s^2(st),s^2t^2,(st)t^2,(t^2)^2$ が独立で次元五である。座標 $A,B,C$ で書けば、六個の二次単項式の間に $AC=B^2$ が一つあるため同じ次元になる。射影直線の標準開二つでは同じ局所環が現れるものの、斉次環の次数一の次元が $2$ と $3$ で異なるので、次数付き環としては同型ではない。
:::

:::example[射影直線の四次埋め込みで一つの切断を外す]
標数零で
$$
[s:t]\longmapsto[s^4:s^3t:st^3:t^4]=[A:B:C:D]
$$
を考える。像では $AD=BC$、$B^3=A^2C$、$C^3=BD^2$ が成り立つ。これら三式の共通零点では $A,D$ が同時に零なら他の二座標も零になってしまう。そこで $A=1$ では $C=B^3,D=B^4$、$D=1$ では $B=C^3,A=C^4$ と読める。逆座標はそれぞれ $t/s=B/A$、$s/t=C/D$ で、重なりで互いに逆である。従って像を被約構造で考えれば射影直線と同型である。

この埋め込みの次数一の成分は $t$ の指数が $0,1,3,4$ の四単項式からなり、$s^2t^2$ が含まれない。次数二では二つの指数を足して $0,1,2,\ldots,8$ の全てが得られる。例えば $2=1+1$、$6=3+3$、$7=3+4$ である。$m\ge2$ で全ての $0,\ldots,4m$ を得たとすると、最後の因子として指数 $0$ と $4$ を使うだけで $0,\ldots,4m$ と $4,\ldots,4m+4$ の和になり、全てを得る。従って次数 $m\ge2$ の次元は $4m+1$ であり、次数一だけが完全な四次 Veronese の成分より一次元小さい。この例で局所的な埋め込みに必要な座標は残っているが、全ての四次式を最初の斉次座標として選んだわけではない。
:::

### 超曲面の斉次成分を数える

:::proposition[超曲面の次数ごとの次元]
標準次数の多項式環 $S=k[X_0,\ldots,X_n]$ と零でない次数 $e\ge1$ の斉次式 $F$ について、
$$
\dim_k(S/(F))_m=\dim_k S_m-\dim_k S_{m-e}
$$
である。ただし $m-e<0$ の成分は零とする。
:::

:::proof
$S$ は整域なので $F$ 倍が単射である。その次数 $m$ の像は、定義により $(F)$ の次数 $m$ 成分である。従って $S_m$ をこの部分空間で割った次元が所望の差になる。$S_m$ の単項式は $n+1$ 個の非負指数の和が $m$ となるものだから $\dim S_m=\binom{m+n}{n}$ である。これは $m$ 個の印の間に区切り $n$ 個を入れる置き場所を数えて得られる。
:::

:::example[同じ次数の超曲面を小さい成分で比べる]
$\mathbb P^2$ の三次式 $F=Y^2Z-X^3$ は既約である。$Y^2Z-X^3$ を $Z$ の一次式と見れば、$X^3,Y^2$ が互いに素だからである。$m=0,1,2,3,4$ の斉次商の次元は $1,3,6,9,12$ となる。$m=3$ では十個の三次単項式から一関係を引く。$m=4$ では十五個から $XF,YF,ZF$ による三関係を引く。これらは $F$ 倍の単射性で独立であり、さらに上の差を展開すると $m\ge3$ の式は $3m$ である。滑らかな三次式に変えてもこの次元列は同じであり、滑らかさを判定するには局所式の Jacobian など他の情報が必要になる。
:::

## Veronese 埋め込みと Segre 埋め込み

:::definition[Veronese 写像と Segre 写像]{#def-ag-veronese-segre}
$d\ge1$ とする。全次数 $d$ の全単項式を座標とする写像を :term[Veronese 埋め込み]{en="Veronese embedding" yomi="ゔぇろねーぜうめこみ"} といい、$([x],[y])\mapsto[x_i y_j]_{ij}$ を :term[Segre 埋め込み]{en="Segre embedding" yomi="せぐれうめこみ"} という。
:::

:::proposition[像と逆座標]{#prop-ag-veronese-segre-image}
両写像の像は射影閉集合であり、座標近傍で写像とその逆は多項式の商で書ける。像の斉次座標環はそれぞれ $k[X]^{(d)}=\bigoplus_{q\ge0}k[X]_{qd}$ と $\bigoplus_{q\ge0}k[x]_q\otimes_k k[y]_q$ である。
:::
:::proof
Veronese の座標を多重添字 $Z_\alpha$ で表す。像では $Z_\alpha^d=\prod_i Z_{d e_i}^{\alpha_i}$ である。さらにすべての $i$ と $\alpha$ に対し $Z_\alpha Z_{d e_i}^{d-1}=\prod_j Z_{(d-1)e_i+e_j}^{\alpha_j}$ が成り立つ。これらを満たす任意の点には $Z_{de_i}\ne0$ がある。そこで $x_i=1$、$x_j=Z_{(d-1)e_i+e_j}/Z_{de_i}$ と置くと、第二の式がすべての $Z_\alpha/Z_{de_i}$ を $x^\alpha$ に戻す。これが閉像と逆座標を同時に与える。座標環は多項式代入の像であり、総次数 $qd$ の単項式は次数 $d$ の単項式 $q$ 個に分けられる。

Segre の座標を行列 $Z$ とみると、像は $2\times2$ 小行列式が消える非零行列を射影化したものである。$Z_{ij}\ne0$ を選ぶと $Z_{ab}/Z_{ij}=(Z_{aj}/Z_{ij})(Z_{ib}/Z_{ij})$ が成り立ち、二つの因子を順に $x_a/x_i$、$y_b/y_j$ として復元する。代入の像は $x,y$ の両方で同じ次数をもつ単項式の張る環であり、各単項式は $x_i y_j$ の積に分解できる。
:::

Segre の像を通じて二つの射影空間の積に Zariski 位相を入れる。$Z_{ij}\ne0$ の開は、両因子の標準開 $x_i\ne0$、$y_j\ne0$ のアフィン積に対応する。上の復元式は全座標比を与えるので、この位相はアフィン積の Zariski 位相を貼り合わせたものである。二つの射影閉集合の積も Segre 像の中で閉じる。実際、各積の標準開では両因子の方程式をそれぞれの座標比に課せばよい。Veronese の場合も、純冪座標が非零の開で像の方程式と逆座標が得られるので、元の射影空間と像が同相になる。

:::example[Segre の二次曲面]
$\mathbb P^1\times\mathbb P^1$ は $Z_{00}Z_{11}-Z_{01}Z_{10}=0$ で表される。$[1:2]$ と $[1:3]$ は $[1:3:2:6]$ に移り、$Z_{00}=1$ の座標近傍で二因子が直ちに復元できる。
:::

:::example[三因子の Segre 座標]
三つの射影直線の点 $[1:2],[1:3],[1:5]$ を取る。添字 $000,001,010,011,100,101,110,111$ の順に積を計算すると
$$
[1:5:3:15:2:10:6:30]
$$
である。最初の座標で割った $100,010,001$ の三比から入力の点を復元できる。最後の座標は三つの比の積であり、独立な八つの座標を選べるわけではない。
:::

:::example[二次 Veronese 面の標準開]
$[x:y:z]$ の二次 Veronese 座標を $[a:b:c:d:e:f]=[x^2:xy:xz:y^2:yz:z^2]$ とする。$a=1$ の開では $b,c$ を選ぶと $d=b^2,e=bc,f=c^2$ となる。ここで $ad-b^2$、$ae-bc$、$af-c^2$ は消えている。点 $[1:2:3]$ は $[1:2:3:4:6:9]$ に移り、前半三成分から後半が決まる。この座標近傍に限れば三本の関係で像が切り出されるが、他の開では別の非零成分を分母に選ぶ必要がある。
:::

### Veronese 部分環と Segre 環

:::proposition[Veronese 像の二次関係]
非負整数ベクトル $\alpha$ で $|\alpha|=d$ を満たすものに変数 $z_\alpha$ を対応させる。$z_\alpha\mapsto x^\alpha$ の核は、$\alpha+\beta=\gamma+\delta$ を満たす $z_\alpha z_\beta-z_\gamma z_\delta$ で生成される。
:::

:::proof
同じ像をもつ二単項式を比較する。全体の変数 $x_i$ の添字列を順に並べ、長さ $d$ ずつ区切った標準形を作る。任意の積を標準形へ移すには、第一の因子の添字を全体の小さい方から $d$ 個に揃えればよい。もし第一因子に余分な添字 $i$ があり必要な添字 $j$ が別の因子にあれば、二因子間で $i,j$ を交換する。この交換の前後では総指数が等しいので二次関係に含まれる。交換のたびに第一因子の必要な添字が一つ増え、有限回で揃う。第一因子を固定し、残りに同じ操作を繰り返すと標準形になる。最後に、核の任意の多項式を像の単項式ごとにまとめる。各組の係数和が零なので、その組は同じ像をもつ二単項式の差の線形結合である。
:::

:::example[三次 Veronese の二次式]
$\mathbb P^1$ の三次 Veronese では $z_0=s^3,z_1=s^2t,z_2=st^2,z_3=t^3$ と置く。$z_0z_2-z_1^2$、$z_0z_3-z_1z_2$、$z_1z_3-z_2^2$ は、それぞれ $t$ の総指数が $2,3,4$ の二項式である。二因子の指数対が同じ総指数をもつ場合を列挙すると、異なる対をもつのはこの三つの総指数だけである。従ってこの三式が核を生成する。$z_0\ne0$ の近傍では $z_2/z_0=(z_1/z_0)^2$、$z_3/z_0=(z_1/z_0)^3$ となり、アフィン部分がねじれ三次曲線の通常の表示になる。
:::

:::example[Segre 像の行列分解の検算]
$\mathbb P^1\times\mathbb P^2$ の Segre 座標として
$$
M=\begin{pmatrix} 2&4&-2\\3&6&-3\end{pmatrix}
=\begin{pmatrix}2\\3\end{pmatrix}\begin{pmatrix}1&2&-1\end{pmatrix}
$$
を取る。各小行列式は零であり、第一列と第一行から $[2:3]$ と $[1:2:-1]$ を復元できる。別の復元に第二列を使うと $[4:6]=[2:3]$ となる。一般に零でない行列の階数が一なら列空間、行空間とも一次元なので、復元した二点は選んだ列や行によらない。
:::

### Segre 像で二つの次数を同時に追う

二つの射影因子にはそれぞれ独立の共通倍率がある。従って積の斉次座標を戻す場合、一方の座標の次数ともう一方の座標の次数を別々に数える。

:::proposition[Segre 環の斉次成分]
Segre 埋め込み $\mathbb P^m\times\mathbb P^n$ の像の斉次環の次数 $d\ge0$ の成分は、$x$ について次数 $d$、$y$ について次数 $d$ の単項式を基底にもつ。従って次元は $\binom{d+m}{m}\binom{d+n}{n}$ である。
:::

:::proof
座標を $Z_{ij}=x_i y_j$ とすれば、$d$ 個の積はこの二つの次数をもつ。逆に、任意の二重次数 $(d,d)$ の単項式について、$x$ から $d$ 個、$y$ から $d$ 個を順に並べ、同じ位置の添字を組にすれば $d$ 個の $Z_{ij}$ の積として表せる。相異なる二重単項式は多項式環で独立なので、対応する像の成分の基底になる。写像の核は像上の消滅イデアルである。実際、任意の斉次式が積の射影点で消えれば、両方の代表が非零の全組で代入後の式が消える。この組はアフィン積で稠密なので、代入後の多項式自体が零である。従って像を用いた計算が斉次座標環の計算に一致する。
:::

:::example[二次曲面の二次式を数える]
$\mathbb P^1\times\mathbb P^1$ の Segre 像の斉次成分は $(d+1)^2$ 次元である。$d=2$ なら $9$ 次元で、四変数の二次式十個の間に $Z_{00}Z_{11}=Z_{01}Z_{10}$ の一関係がある結果と一致する。二重次数側では $(x_0^2,x_0x_1,x_1^2)$ と $(y_0^2,y_0y_1,y_1^2)$ を組にした九個が基底である。例えば $Z_{00}Z_{11}$ と $Z_{01}Z_{10}$ はどちらも $x_0x_1y_0y_1$ であり、同じ基底成分に移る。
:::

:::example[三方向の積への拡張]
$\mathbb P^1$ を三つ掛けた空間では八つの座標 $Z_{ijk}=x_i y_j w_k$ を使える。まず二因子の Segre を行い、さらに第三因子との Segre を合成すれば閉埋め込みになる。次数二での像は三組の二次単項式から作る $3^3=27$ 個の独立な単項式である。一方八変数の二次式は $\binom92=36$ 個ある。従って次数二での関係の空間は九次元である。例えば $Z_{000}Z_{111}$ と $Z_{011}Z_{100}$ はいずれも三組から添字 $0,1$ を一度ずつ用いるので等しくなる。消失する一関係だけを求めた場合には、この九という数が生成候補の検算になる。
:::

### Veronese と Segre を組み合わせる

:::example[二つの因子を異なる次数で写す]
$\mathbb P^1\times\mathbb P^1$ で最初の因子を二次 Veronese、第二の因子を一次のままにして Segre に移す。六つの座標 $x_0^2y_0,x_0x_1y_0,x_1^2y_0,x_0^2y_1,x_0x_1y_1,x_1^2y_1$ を列挙できる。$x_0^2y_0\ne0$ では $u=x_1/x_0$、$v=y_1/y_0$ を復元し、残りの比は $u,u^2,v,uv,u^2v$ である。他の $x_i^2y_j$ が非零の近傍にも同じ式が成り立ち、四近傍が像を覆う。次数 $d$ の像の単項式は $x$ について次数 $2d$、$y$ について次数 $d$ であり、任意の単項式を $d$ 組に分配できる。従って次元は $(2d+1)(d+1)$ である。$d=2$ では $15$ 次元なので、六変数二次式 $21$ 次元との差は $6$ である。この計算は二つの因子を同じ二次で写した場合の $(2d+1)^2$ とは別の埋め込みを扱っている。
:::

## Grassmann 多様体と Plücker 埋め込み

ある $r$ 次元部分空間の基底を行ベクトルに並べると、基底の変更は左からの正則行列の乗法である。このため、$r$ 列を選んだ行列式の一覧は全体として一つのスカラーだけ変わる。

:::definition[Grassmann 多様体と Plücker 座標]{#def-ag-plucker}
$\operatorname{Gr}(r,n)$ を $k^n$ の $r$ 次元部分空間全体とする。基底 $v_1,\dots,v_r$ に対し $[v_1\wedge\cdots\wedge v_r]\in\mathbb P(\bigwedge^r k^n)$ を対応させる写像を :term[Plücker 埋め込み]{en="Plücker embedding" yomi="ぷりゅっかーうめこみ"} という。座標 $p_I$ は列集合 $I$ の小行列式である。
:::

:::proposition[Plücker 座標の復元]{#prop-ag-plucker-image}
$0\le r\le n$ とする。Plücker 写像の像は閉じており、その標準開部分 $p_I\ne0$ は $\mathbb A^{r(n-r)}$ である。
:::
:::proof
$r=0$ のときは $\bigwedge^0 k^n=k$ で像は一点である。以下 $1\le r\le n$ とする。$p_I\ne0$ の下で列 $I$ を単位行列に正規化する。他の列の成分は、$I$ の列を一つ入れ替えた小行列式の比 $p_J/p_I$ に符号を付けたものである。これらを使って復元した行列の全小行列式を計算し、対応する $p_J/p_I$ と一致するという方程式を課す。従って各開集合で像は閉じる。これらの開集合は射影空間を覆うので像は閉じる。自由な $r(n-r)$ 成分は任意に取れ、復元は互いに逆である。
:::

:::proposition[Grassmann 多様体の既約性]{#prop-ag-grassmann-irreducible}
Plücker 像は既約である。
:::

:::proof
$r=0$ または $r=n$ では一点である。$0<r<n$ のとき、$k$ から相異なる元 $a_1,\ldots,a_n$ を選び、第 $j$ 列が $(1,a_j,\ldots,a_j^{r-1})^\top$ である行列を取る。どの $r$ 列も独立である。実際、選んだ $r$ 個の元で消える次数 $r-1$ 以下の多項式は零しかないので、行の非自明な線形関係がない。従ってこの行列が表す点は全標準開に入る。各標準開は :ref[prop-ag-plucker-image] でアフィン空間と同型だから既約である。任意に固定した一つの標準開は他の全標準開に空でない開として交わるため、各標準開で稠密になる。その閉包は全体なので、既約な開の閉包として Plücker 像も既約である。
:::

:::example[$\operatorname{Gr}(2,4)$ の二次方程式]
$p_{12}\ne0$ で行列を $\left(\begin{smallmatrix}1&0&a&b\\0&1&c&d\end{smallmatrix}\right)$ と書くと、$p_{13}=c$、$p_{14}=d$、$p_{23}=-a$、$p_{24}=-b$、$p_{34}=ad-bc$ となる。従って
$$
p_{12}p_{34}-p_{13}p_{24}+p_{14}p_{23}=0
$$
である。逆にこの式と $p_{12}=1$ の下で最初の四つの比から行列を作ると、$p_{34}$ も式により一致する。任意の非零座標を添字の付け替えで $p_{12}$ にでき、式は全体の符号を除き変わらないので、この一式で像が定まる。
:::

### 一般の Plücker 関係式

:::proposition[交換型の二次関係]{#prop-ag-plucker-relations}
$1\le r\le n$ とし、$p_{i_1,\dots,i_r}$ を交代的に拡張し、添字が重複する場合を零とする。$r-1$ 個からなる列 $I$ と $r+1$ 個からなる列 $J=(j_1,\dots,j_{r+1})$ に対する次の式が Plücker 像を切り出す。
$$
\sum_{\ell=1}^{r+1}(-1)^{\ell-1}p_{I,j_\ell}\,p_{J\setminus j_\ell}=0
$$
:::
:::proof
各列を $v_i\in k^r$ とする。$r+1$ 列の線形関係 $\sum_\ell(-1)^{\ell-1}p_{J\setminus j_\ell}v_{j_\ell}=0$ は、各成分について、同じ行が二つある $(r+1)$ 次行列式を一行で展開した式である。これを最後の列として $I$ の列と行列式を取ると必要な関係を得る。

逆に式を満たす点で非零座標 $p_B$ を取り $p_B=1$ に正規化する。列 $B$ を単位行列に固定し、一列を交換した座標に符号を付けて他の列を復元する。この行列の小行列式が残りの座標と一致することを、$B$ に属さない添字の個数で帰納的に示す。二つ以上ある標的添字集合を $K$ とし、$a\in K\setminus B$ を取る。$I=K\setminus\{a\}$、$J=B\cup\{a\}$ の関係では $j_\ell=a$ の項が符号付きで $p_Kp_B$ になる。他の非零項の第一因子は、$K$ の $a$ を $B$ の一つに替えた座標で、帰納法により決まっている。第二因子は $B$ の一列交換なので既知である。したがって $p_K$ は一意に決まり、同じ関係を満たす復元行列の小行列式と一致する。
:::

### Plücker 座標と交わりの判定

:::example[二平面を一つの小行列式で比べる]
$k^4$ の二平面を $U=\operatorname{span}(e_1+2e_3,e_2+e_4)$、$W=\operatorname{span}(e_1,e_2)$ とする。$U$ の行ベクトルを並べた行列の小行列式は順に $(p_{12},p_{13},p_{14},p_{23},p_{24},p_{34})=(1,0,1,-2,0,2)$ である。標数零では $p_{34}=2\ne0$ なので、$U$ から後ろ二座標への射影は同型である。この射影の核は $U\cap W$ なので $U\cap W=0$ となる。Plücker 関係は $1\cdot2-0+1\cdot(-2)=0$ で確かめられる。標数 $2$ ではこの射影の階数が一になり、$e_1$ が交わりに残る。
:::

:::example[Grassmann 標準開の座標変換]
$2\times4$ の行列を
$$
\begin{pmatrix}1&0&a&b\\0&1&c&d\end{pmatrix}
$$
とする。$p_{12}=1$、$p_{13}=c$、$p_{14}=d$、$p_{23}=-a$、$p_{24}=-b$、$p_{34}=ad-bc$ である。$p_{13}\ne0$ なら列 $1,3$ で単位行列を作るために左から $\begin{pmatrix}1&-a/c\\0&1/c\end{pmatrix}$ を掛ける。残る列 $2,4$ は $(-a/c,1/c)^t$、$(b-ad/c,d/c)^t$ となる。例えば $(a,b,c,d)=(2,1,3,4)$ なら後者は $(-5/3,4/3)^t$ である。どの小行列式を分母にしたかを明記すれば、同じ部分空間の別表示を行基本変形で比較できる。
:::

:::example[直線が固定点を通る条件]
$\mathbb P^3$ の射影直線を二平面 $U=\operatorname{span}(u,v)$ で表す。$[1:0:0:0]$ を通る条件は $e_1\wedge u\wedge v=0$ である。$u,v$ が一次独立なので、これは $e_1$ がその張る空間に入ることと同値である。外積を展開すると条件は $p_{23}=p_{24}=p_{34}=0$ となる。このとき $p_{12},p_{13},p_{14}$ は任意の同次座標となる。実際 $U=\operatorname{span}(e_1,p_{12}e_2+p_{13}e_3+p_{14}e_4)$ を取れば復元できる。従って固定点を通る直線の族は Grassmann 多様体の中の射影平面である。
:::

### 旗と部分空間の交わり

Grassmann 多様体では、点を一つ指定するだけでも線形部分空間が一つ指定される。そのため二つの部分空間の交わりの次元を課す条件が、パラメータ空間の閉集合を定める。特に固定された旗との交わりを用いると、Grassmann 多様体をアフィン空間の有限分解として記述できる。

:::definition[旗と Schubert 条件]
$F_i=\operatorname{span}(e_1,\dots,e_i)$（$0\le i\le n$）を標準の :term[完全旗]{en="complete flag" yomi="かんぜんき"} とする。$I=(i_1<\cdots<i_r)$ に対し、$\dim(U\cap F_{i_j})\ge j$ を全て満たす $U\in\operatorname{Gr}(r,n)$ の集合を :term[Schubert 多様体]{en="Schubert variety" yomi="しゅーべるとたようたい"} $\Omega_I$ と呼ぶ。各 $j$ について $\dim(U\cap F_i)$ が $j$ に初めて達する添字が $i_j$ である部分を $\Omega_I^\circ$ と書く。
:::

:::proposition[Schubert 条件とアフィン胞体]{#prop-ag-schubert-cells}
$\Omega_I$ は閉じており、$\Omega_I^\circ$ は $\sum_{j=1}^r(i_j-j)$ 次元のアフィン空間と同型である。$\Omega_I$ は $\Omega_I^\circ$ の閉包であり、$\Omega_J^\circ$ を含む条件は各 $j$ について $h_j\le i_j$（$J=(h_1,\dots,h_r)$）である。
:::

:::proof
Grassmann の各標準開で正規化した基底行列を取る。$U\to k^n/F_{i_j}$ の階数は後ろ $n-i_j$ 列の階数であり、条件はこれが $r-j$ 以下というものである。該当する小行列式の消滅で記述できるので、全ての条件は閉じている。$\dim(U\cap F_i)$ は $i$ が一つ増えるたびに高々一だけ増える。従って値が増える添字を記録すれば一意な列 $J$ が得られ、各 $j$ について $\dim(U\cap F_{i_j})\ge j$ は $h_j\le i_j$ と同値である。

$U\in\Omega_I^\circ$ では $U\cap F_{i_j}$ の $j$ 番目の基底ベクトルを、その最後の非零成分が列 $i_j$ の $1$ になるように取る。前の基底ベクトルを引いて、列 $i_\ell$（$\ell<j$）の成分を零にできる。これで行 $j$ は列 $i_j$ より右で零、すべてのピボット列では $j$ 番目の単位行になる。行 $j$ の残りの自由成分は $i_j-1-(j-1)=i_j-j$ 個である。この形は一意である。複数の表示は選んだピボット列で単位行列になるため、行基本変形の行列も恒等に固定される。従ってこの部分は $p_I\ne0$ のアフィン座標のうち指定した成分を零にした線形部分空間である。

最後に任意の $U\in\Omega_I$ について、順に $u_j\in U\cap F_{i_j}$ を選び、それまでの線形結合に入らないようにする。条件で次元が $j$ 以上なので可能であり、最後には $U$ の基底を得る。$u_j(t)=u_j+t e_{i_j}$ と置く。列 $I$ の行列式は $t$ に関する最高次項 $t^r$ をもつため、一般の $t$ で非零である。各行が $F_{i_j}$ に入るので、このとき階数条件とピボット条件から $\Omega_I^\circ$ に属する。$t=0$ でも元の基底は独立なので、少なくとも別の小行列式が $0$ の近傍で非零となり、そこで点は射として定義できる。稠密開は胞体へ、$0$ は $U$ へ写るので $U$ は胞体の閉包に属する。逆包含は $\Omega_I$ の閉性から従う。
:::

:::example[$\operatorname{Gr}(2,4)$ の胞体の自由成分]
$I=(2,4)$ を取ると、ピボットを列 $2,4$ とした行列は
$$
\begin{pmatrix}a&1&0&0\\b&0&c&1\end{pmatrix}
$$
である。従って胞体は $(a,b,c)$ の三次元である。確かに最初の行は $F_2$ に属し、第二行の第四成分は $1$ なので $\dim(U\cap F_2)=1$ である。閉包の条件はただ $U\cap F_2\ne0$ であり、後ろ二列の行列式 $p_{34}=0$ と同値である。例えば $U=F_2$ は $J=(1,2)$ の胞体にあり閉包に入る。$U'=\operatorname{span}(e_3,e_4)$ では $p_{34}=1$ なので閉包に入らない。
:::

:::example[射影直線の交わりを二つの Schubert 条件にする]
$\mathbb P^3$ で固定直線 $\mathbb P(F_2)$ と交わる直線は $p_{34}=0$、点 $[1:0:0:0]$ を通る直線は $p_{23}=p_{24}=p_{34}=0$ である。後者は固定点が固定直線上にあるため前者に含まれる。閉包の胞体の記法ではそれぞれ $\Omega_{(2,4)}$ と $\Omega_{(1,4)}$ であり、先の不等式 $(1,4)\le(2,4)$ がこの包含を記述する。両方を同じ Grassmann 多様体内で比較すると、直線を指定する条件に何本の独立方程式が必要かを調べられる。
:::

### 部分空間とその消滅空間を交換する

:::proposition[補次元 Grassmann 多様体の双対]
$V$ が次元 $n$ の線形空間のとき、消滅空間 $U^\perp=\{\ell\in V^\vee:\ell(U)=0\}$ を取る操作は $\operatorname{Gr}(r,V)$ と $\operatorname{Gr}(n-r,V^\vee)$ の同型を与える。
:::

:::proof
基底を選んで $p_I\ne0$ の近傍を考え、対応する $r$ 列を単位行列として $U$ の基底を $(I_r,A)$ と書く。$\ell$ の前半と後半の成分を列 $c,d$ とすると、消滅条件は $c+Ad=0$ である。従って $U^\perp$ の基底は $(-A^t,I_{n-r})$ となる。よって局所座標で変換は符号と転置だけで行われる。重なりでも同じ消滅空間を表すので射が貼り合う。有限次元なので二度消滅空間を取ると元の部分空間に戻り、逆射となる。
:::

:::example[二平面の消滅空間]
標数零で $U=\operatorname{span}((1,0,2,1),(0,1,3,4))\subset k^4$ とすると、消滅条件は $c_1=-2d_1-d_2$、$c_2=-3d_1-4d_2$ である。従って双対側の二基底を $(-2,-3,1,0)$、$(-1,-4,0,1)$ と取れる。第一の行列の最後二列の小行列式は $2\cdot4-1\cdot3=5$ であり、双対側では最初の二列の小行列式が $(-2)(-4)-(-1)(-3)=5$ となる。選んだ列の補集合に小行列式が移ることが、この例では符号なしで確認できる。
:::

## 演習問題

::::exercise{level=basic}
$[2:4:6]\in\mathbb P^2_{\C}$ の $U_1$ での座標を求めよ。

:::solution
$X_1=1$ に正規化するため $4$ で割る。残りの座標は $(1/2,3/2)$ である。
:::
::::

::::exercise{level=basic}
$V_+(X_0^2,X_1^2)\subset\mathbb P^2$ を求めよ。

:::solution
$X_0=X_1=0$ となり $X_2$ は非零である。したがって $[0:0:1]$ が唯一の点である。
:::
::::

::::exercise{level=basic}
$y=x^2$ の射影閉包と無限遠点を求めよ。

:::solution
斉次化は $X_0X_2-X_1^2$ である。$X_0$ と互いに素なので生成する主イデアルは $X_0$ に関して飽和している。$X_0=0$ を入れると $X_1=0$ なので無限遠は $[0:0:1]$ である。
:::
::::

::::exercise{level=basic}
標数零で Segre 像 $[2:6:4:12]$ の二因子を求めよ。

:::solution
最初の座標で割ると $[1:3:2:6]$ である。第一列が $[1:2]$、第一行が $[1:3]$ を与え、その積が全成分を再現する。
:::
::::

::::exercise{level=advanced}
三次 Veronese 写像 $\mathbb P^1\to\mathbb P^3$ の像を三式で切り出せ。

:::solution
座標を $[W:X:Y:Z]=[s^3:s^2t:st^2:t^3]$ とすると $WY=X^2$、$WZ=XY$、$XZ=Y^2$ が必要である。$W\ne0$ なら $W=1$ として $X=u$ から $Y=u^2$、$Z=u^3$ を得る。$W=0$ なら $X=Y=0$ なので $[0:0:0:1]$ となり、これも像に属する。
:::
::::

::::exercise{level=advanced}
$V_+(X_0X_2-X_1^2)\cap U_2$ の座標環を求めよ。

:::solution
$U_2$ で $u=X_0/X_2$、$v=X_1/X_2$ と置くと $u=v^2$ である。代入により $k[u,v]/(u-v^2)\simeq k[v]$ となる。
:::
::::

::::exercise{level=advanced}
$p_{12}=1$、$p_{13}=2$、$p_{14}=3$、$p_{23}=4$、$p_{24}=5$ のとき $p_{34}$ を求めよ。

:::solution
正規化行列は $\left(\begin{smallmatrix}1&0&-4&-5\\0&1&2&3\end{smallmatrix}\right)$ である。最後の二列の行列式は $(-4)3-(-5)2=-2$ となる。
:::
::::

::::exercise{level=advanced}
$\mathbb P^2$ の二次 Veronese 像の斉次座標環で次数 $2$ 成分の次元を求めよ。

:::solution
次数 $2$ 成分は $s,t,u$ の全次数 $4$ 成分に等しい。$s$ の指数を $j$ とすると残りは $5-j$ 通りである。$j=0,\dots,4$ で足すと $15$ になる。
:::
::::

## 確認テスト

::::quiz{answer="4" tol="1e-6"}
$\mathbb P^3$ の標準開集合 $U_i$ の個数はいくつか。

:::explanation
$X_i\ne0$ の開集合を $i=0,1,2,3$ の各座標に一つずつ取るため $4$ 個である。
:::
::::

::::quiz
射影零点が空になる条件を選べ。

- [x] $S_+\subset\sqrt J$
- [ ] $J\subset S_+$
- [ ] $J\ne0$

:::explanation
:ref[thm-ag-projective-nullstellensatz] により、すべての座標が根基に入ると、非零ベクトルの零点は存在しない。逆もアフィン零点定理から従う。
:::
::::

::::quiz{answer="6" tol="1e-6"}
$\operatorname{Gr}(2,5)$ の標準開集合のアフィン座標はいくつあるか。

:::explanation
基底行列の選んだ二列が単位行列に固定される。残りは $2\times3$ 行列で、六成分が自由である。
:::
::::

::::quiz
Segre 像の条件を選べ。

- [x] すべての二次小行列式が零である
- [ ] すべての座標が非零である
- [ ] すべての行の成分和が零である

:::explanation
座標を行列として並べると、それは非零の階数 $1$ 行列である。したがってすべての $2\times2$ 小行列式が零である。
:::
