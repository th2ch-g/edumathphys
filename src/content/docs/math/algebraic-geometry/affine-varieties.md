## この章の目標

- 零点集合から Zariski 位相を定め、閉包と基本開集合を計算する。
- 零点定理を用いて、閉集合を根基イデアルで記述する。
- 既約成分を極小素イデアルに対応させる。
- パラメータ表示から方程式と座標環を求める。

## 代数的集合と Zariski 位相

方程式 $x^2=0$ と $x=0$ は体の上で同じ解をもつ。このため、解集合から方程式を復元するときは、最初に選んだ方程式の一覧よりも、その集合上で消えるすべての多項式を使うとよい。この章では $k$ を代数閉体とし、環準同型は単位元を保つとする。

:::definition[アフィン空間と零点集合]{#def-ag-affine-zero-set}
$\mathbb A^n_k=k^n$ とし、$R=k[x_1,\dots,x_n]$ とおく。$S\subset R$ の共通零点集合を $V(S)=\{p\in k^n:\ f(p)=0\ \text{for all }f\in S\}$ と書く。この形の集合を :term[アフィン代数的集合]{en="affine algebraic set" yomi="あふぃんだいすうてきしゅうごう"} という。
:::

:::proposition[閉集合の公理]{#prop-ag-zariski-closed}
$\{V(S):S\subset R\}$ は閉集合系をなす。この閉集合系で定まる位相を :term[Zariski 位相]{en="Zariski topology" yomi="ざりすきいそう"} という。
:::

:::proof
$V(1)=\varnothing$、$V(0)=k^n$ である。$\bigcap_\lambda V(S_\lambda)=V(\bigcup_\lambda S_\lambda)$ は条件をすべて満たすという意味である。また $S T=\{fg:f\in S,\ g\in T\}$ とすると $V(S)\cup V(T)=V(ST)$ である。左辺の外では消えない $f$ と $g$ を一つずつ取れ、その積も消えない。逆包含はどちらかの因子が常に消えることから従う。この二項和を繰り返せば有限和が閉じる。
:::

閉集合 $X$ の相対位相で、$D_X(f)=\{p\in X:f(p)\ne0\}$ を :term[基本開集合]{en="principal open set" yomi="きほんかいしゅうごう"} と呼ぶ。任意の開集合は $D_X(f)$ の和であり、$D_X(f)\cap D_X(g)=D_X(fg)$ である。したがって開近傍を調べるときには一つの非消滅条件に絞れる。

:::example[アフィン直線での収束と閉集合]
非零一変数多項式の根の個数は次数以下である。反対に有限集合 $\{a_1,\dots,a_r\}$ は $\prod_i(x-a_i)$ の零点集合である。ゆえに $\mathbb A^1_k$ の真の閉集合は有限集合であり、無限集合は稠密である。代数閉体は無限体であるため、二つの空でない開集合は共通点をもつ。よってこの直線は Hausdorff 空間ではない。一方、各点は閉じている。
:::

:::example[基本開集合の方程式表示]
$D_{\mathbb A^2}(xy)$ では $x$ と $y$ がともに非零である。補助変数 $u$ を導入すると、各 $(x,y)$ にただ一つ $u=(xy)^{-1}$ を対応させることができる。この対応により、開集合を閉集合 $V(xyu-1)\subset\mathbb A^3$ として扱える。
:::

$T\subset\mathbb A^n_k$ に対し、$I(T)=\{f:\forall p\in T,\ f(p)=0\}$ と定める。和と任意の多項式による積で消滅が保たれるので、これはイデアルである。$f^m\in I(T)$ なら $f\in I(T)$ であるから、$I(T)$ は根基イデアルである。ここでイデアルの根基 $\sqrt J=\{f:f^m\in J\text{ for some }m\ge1\}$ の一般論は :ref[def-comm-radicals]{text="イデアルの根基"} を参照する。

### 閉包と相対的な開集合

:::example[直線の部分集合が平面で稠密か]
$t\mapsto(t,2t+1)$ の像から有限個の点を除いた集合を $T$ とする。$T$ は直線の中では稠密になる。実際、任意の $f(x,y)$ の制限 $f(t,2t+1)$ が $T$ 上で消えれば無限個の零点をもつ一変数多項式なので恒等的に消える。一方、この直線を切り出す多項式 $y-2x-1$ は平面全体では零にならない。従って平面での閉包は直線である。稠密性を述べるときは、どの空間で閉包を取るかを指定する。
:::

:::example[有限集合の相対位相]
$\mathbb A^2$ の点 $(0,0),(1,0),(0,1)$ からなる集合 $F$ を考える。$F$ では $D_F(1-x-y)$ が $(0,0)$ だけ、$D_F(x)$ が $(1,0)$ だけ、$D_F(y)$ が $(0,1)$ だけを含む。従って相対位相は離散である。この各点は平面の開集合にはならない。実際、その点を通る直線への制限を取ると、その点を含む平面の基本開近傍は直線上でも非零多項式の非消滅集合であり、無限個の点を含む。
:::

### アフィン線形座標と方程式による閉包

原点と基底を選ぶと、アフィン空間の点を $n$ 個のスカラーで指定できる。別の原点と基底を使うと、座標は $x\mapsto Mx+b$（$M$ は可逆）で変わる。閉集合の定義がこの選択によらないことを確かめておくと、例えば二本の直線を座標軸へ移して計算できる。

:::proposition[座標変換と基本開集合]
可逆なアフィン線形変換は Zariski 位相の同相写像である。一般に多項式座標をもつ写像は連続であり、$V(g_i:i\in I)$ の逆像は $V(g_i\circ f:i\in I)$ である。
:::

:::proof
逆像の各点で $g_i(f(x))$ が零になるという条件は、合成して得た多項式の零点条件である。アフィン線形変換では逆写像の座標も $M^{-1}(x-b)$ という一次式なので同じ議論を使える。特に基本開集合の逆像は合成した多項式による基本開集合になる。
:::

:::example[四点のうち一辺だけを残す]
$F=\{(0,0),(0,2),(3,0),(3,2)\}\subset\mathbb A^2_{\C}$ とする。各座標が二つの候補をもつので $F=V(x(x-3),y(y-2))$ である。$F$ に制限した $y-2$ は、値 $0$ と $-2$ をとる。従って $D_F(y-2)=\{(0,0),(3,0)\}$ であり、これは $V_F(y)$ にも等しい。さらに $D_F(x(y-2))=\{(3,0)\}$ である。この例では有限集合の相対位相で計算したため、平面の開集合が一点であるとは結論しない。
:::

:::example[閉包が斜め方向に広がる集合]
$\C^2$ の部分集合 $T=\{(m,m^2+1):m\in\Z\}$ の Zariski 閉包を求める。$f(x,y)$ を $y-(x^2+1)$ で $y$ に関して割れば、余りは $r(x)=f(x,x^2+1)$ である。$T$ 上の消滅には $r(m)=0$ が全整数で必要であり、これは $r=0$ と同値である。従って $I(T)=(y-x^2-1)$ で、閉包は放物線全体になる。例えば整数座標をもたない $(1/2,5/4)$ も閉包に含まれる。この結論は、一変数では無限個の零点をもつ非零多項式が存在しないことを使ったものである。
:::

:::example[平面で稠密な格子]
同じ $\C^2$ でも $T=\Z\times\Z$ の閉包は平面全体である。$f(x,y)=\sum_{j=0}^d a_j(x)y^j$ が格子上で消えるなら、固定した整数 $m$ ごとに $f(m,y)$ が無限個の整数根をもつ。よって各 $a_j(m)$ が零である。$m$ を動かすと各 $a_j$ が無限個の根をもつため、すべての係数が零となる。従って $I(T)=0$ である。座標射影が両方とも稠密になるだけではこの結論は出ない。直前の放物線の例では、両座標の射影は無限集合だが連立条件 $y=x^2+1$ が残る。
:::

:::example[通常の位相とは異なる積]
$\mathbb A^1_{\C}$ の二つの Zariski 位相の積と、$\mathbb A^2_{\C}$ の Zariski 位相を比べる。対角 $\Delta=V(x-y)$ の補集合に属する $(0,1)$ を取る。積位相の任意の基本近傍 $U\times W$ では、$U,W$ は直線の有限集合の補集合である。$U\cap W$ から $a$ を取れば $(a,a)\in U\times W$ となる。従って対角の補集合は積位相で開かない。一方、開長方形 $D(f)\times D(g)$ は平面では $D(f(x)g(y))$ である。よって平面の Zariski 位相は積位相より真に細かい。この違いは、後に対角を用いてスキームの分離性を判定するときにも現れる。
:::

### アフィン直線の有限補集合にある開の構成

:::example[三点を除いた空間を閉集合で表示する]
$\mathbb A^1_{\C}$ から $-1,0,2$ を除いた開を考える。$f=t(t+1)(t-2)$ とすれば開は $D(f)$ である。$u f=1$ を課した平面曲線の点に移すと、$t$ が許された範囲を動くたびに $u=1/f(t)$ が一意に決まる。例えば $t=1$ で $u=-1/2$、$t=3$ で $u=1/12$ になる。補助変数を加えた埋め込みで無限遠の点を調べるには、[射影閉包](/math/algebraic-geometry/projective-varieties/) を参照。
:::

## イデアルと代数的集合の対応

:::proposition[閉包と消滅イデアル]{#prop-ag-closure-ideal}
任意の $T$ に対し、$\overline T=V(I(T))$ および $I(T)=I(\overline T)$ である。
:::

:::proof
$V(I(T))$ は $T$ を含む。任意の閉集合 $V(J)\supset T$ について $J\subset I(T)$ なので $V(I(T))\subset V(J)$ となる。よって閉包に等しい。また $f\in I(T)$ なら閉集合 $V(f)$ が $\overline T$ を含み、逆向きは $T\subset\overline T$ から従う。
:::

:::theorem[零点集合と根基イデアル]{#thm-ag-affine-nullstellensatz}
$J\subset R$ に対し $I(V(J))=\sqrt J$ である。したがって $V$ と $I$ は根基イデアルと閉集合の間の包含を逆にする全単射を与える。
:::

:::proof
$\sqrt J\subset I(V(J))$ は体で冪が零なら元が零であることから従う。逆向きには :ref[thm-comm-weak-nullstellensatz]{text="Hilbert の弱零点定理"}を用いる。$f$ が $V(J)$ 上で消え、$f\ne0$ とする。$R[u]$ のイデアル $(J,1-uf)$ が真なら共通零点 $(p,u_0)$ がある。すると $p\in V(J)$ で $f(p)=0$ なのに $1-u_0f(p)=0$ となる。したがって $1=\sum_i a_i(x,u)g_i(x)+b(x,u)(1-uf)$ と書ける。ここで $g_i\in J$ である。局所化 $R_f$ で $u=f^{-1}$ を代入し、分母を払えば $f^N\in J$ を得る。$f=0$ の場合は自明である。全単射は :ref[prop-ag-closure-ideal] から従う。
:::

閉集合 $X,Y$ について $I(X\cup Y)=I(X)\cap I(Y)$ である。これに対して $X\cap Y$ は $V(I(X)+I(Y))$ なので、対応するイデアルは $\sqrt{I(X)+I(Y)}$ である。共通部分で根基を取る理由は、例えば $V(y)$ と $V(y-x^2)$ の交わりを見ると分かる。和イデアルは $(y,x^2)$ であるが、交点 $(0,0)$ の消滅イデアルは $(x,y)$ である。

:::example[有限点の消滅イデアル]
$P=(0,0)$、$Q=(1,0)$ とする。$y$ を法として多項式を $k[x]$ に移すと、両点で消える条件は $x$ と $x-1$ の両方で割れることである。互いに素なので $I(\{P,Q\})=(y,x(x-1))$ となる。評価写像は $a+(b-a)x$ を $(a,b)$ に送るので、その像は $k^2$ 全体である。
:::

### 座標射影の閉包と消去

:::proposition[閉包と消去の二段階]
$X\subset\mathbb A^{m+n}$ がイデアル $I$ の零点集合で、$\pi$ が後ろ $n$ 座標を忘れる射影であるとする。$R=k[x_1,\ldots,x_m]$ とおくと $\overline{\pi(X)}=V(I\cap R)$ である。
:::

:::proof
$f\in R$ が $\pi(X)$ で消えることは、$f$ を大きい多項式環の元とみなして $X$ で消えることと同値である。アフィン零点定理により $I(\pi(X))=\sqrt I\cap R$ である。$f$ の冪が大きい環で $I$ に入れば、その冪は $R$ にもあるため $I\cap R$ に入る。逆も成り立つので $\sqrt I\cap R=\sqrt{I\cap R}$ である。:ref[prop-ag-closure-ideal] から結論が従う。
:::

:::example[パラメータの射影と消去]
$k$ を標数零の代数閉体として、$\mathbb A^3$ の $z^2=x$、$y=z^3$ を同時に満たす集合を $(x,y)$ 平面へ射影する。代入すると $y^2=x^3$ を得る。逆にこの式を満たして $x\ne0$ なら $z=y/x$ と置ける。実際 $z^2=y^2/x^2=x$、$z^3=xz=y$ となる。$x=0$ では $y=0$ で $z=0$ が対応する。従ってこの例では像が既に閉じており、消去の結果と一致する。$f(x,y)$ を $y^2-x^3$ で割り、余りを $a(x)+yb(x)$ とする。代入すると $a(z^2)+z^3b(z^2)$ であり、偶指数と奇指数に分かれるから、これが零になるのは両係数が零の場合だけである。従って消去イデアル自体は $(y^2-x^3)$ である。
:::

:::example[値域の穴を別に求める]
今度は $xz=1$、$y=z^2x^2$ を課す。前者から $z=1/x$ が必要であり、後者から $y=1$ となる。従って像は $V(y-1)\cap D(x)$ である。消去イデアルは $(y-1)$ である。実際、関係を用いて得る商環は $k[x,x^{-1}]$ であり、$k[x,y]$ の像は $k[x]$、核は $y-1$ だけである。故に閉包は $V(y-1)$ 全体だが $x=0$ の点は像にない。消去で閉包を求めた後、元の方程式を特殊化して像に属するかを判定できる。
:::

### イデアルの商による開部分の閉包

:::proposition[閉集合から基本開部分を残したときの閉包]{#prop-ag-affine-open-closure}
$X=V(I)$ とし、$I$ は根基イデアルとする。$\mathbb A^n$ における $X\cap D(f)$ の閉包の消滅イデアルは $(I:f)=\{g:fg\in I\}$ である。また $(I:f)=(I:f^\infty)$ である。
:::
:::proof
$g$ が $X\cap D(f)$ で消えるなら、$fg$ は $X$ の残りでも $f$ が消えるため $X$ 全体で消える。従って $fg\in I$ である。逆にこの積が $I$ にあれば $f\ne0$ の点で $g=0$ である。これで消滅イデアルが求まる。他方 $f^mg\in I$ なら $(fg)^m=f^m g^m\in I$ であり、根基性で $fg\in I$ となる。したがって任意冪を許しても同じである。
:::

:::example[成分を取り除く飽和]
$X=V(xy)$ から $x=0$ 上の点を取り除くと $y=0$ 上の $x\ne0$ の点が残る。多項式環で $(xy):x=(y)$ であるため、閉包は横の軸全体である。一方、$D(x+y)$ を使うと各軸から原点を除くだけであり、閉包は両軸である。実際、$x+y$ は $x,y$ のどちらとも互いに素なので、両因子を消すことはできない。
:::

### 根基を計算するための手順

イデアルを指定する式が少ないときにも、根基がどの生成元を必要とするかは別に調べる必要がある。計算では、候補となるイデアルが根基であることと、候補の各生成元の冪が元のイデアルに入ることを独立に示すとよい。

:::proposition[根基の検算]
$J,K\subset R$ をイデアルとし、$K=(g_1,\dots,g_r)$ とする。$J\subset K$、$R/K$ が被約、各 $i$ について $g_i^{m_i}\in J$ となる $m_i\ge1$ が存在する、という三条件が成り立てば $\sqrt J=K$ である。さらに $K^{1+\sum_i(m_i-1)}\subset J$ である。
:::

:::proof
被約性により $K$ は根基なので、第一条件から $\sqrt J\subset K$ となる。第三条件から各 $g_i$ が $\sqrt J$ に入り、これがイデアルであるため $K\subset\sqrt J$ となる。最後に $M=1+\sum_i(m_i-1)$ とおく。$K^M$ を生成する各積 $g_1^{a_1}\cdots g_r^{a_r}$ について $\sum_i a_i=M$ である。どの $a_i$ も $m_i-1$ 以下なら総和は $M-1$ 以下になるので、少なくとも一つは $m_i$ 以上である。その因子を分けると積が $J$ に入る。
:::

:::example[一変数を消去すると重根が表れる例]
$J=(y-x^2,y^2-4y+4)$ とする。第一式で $y=x^2$ を代入すると第二式は $(x^2-2)^2$ になる。標数零で $K=(y-x^2,x^2-2)$ とおけば、$R/K\simeq k[x]/(x^2-2)\simeq k\times k$ である。この同型は相異なる根 $\sqrt2,-\sqrt2$ での評価から得られる。$(x^2-2)^2$ は $J$ に入るため、$K=\sqrt J$ である。点は $(\sqrt2,2)$ と $(-\sqrt2,2)$ の二つであり、商 $R/J$ では $x^2-2$ の類は零でない平方零元である。点の計算で重根を除いても、局所環を用いる交点計算ではこの元が残る。
:::

:::example[冪零の式を外して直線が現れる例]
$J=(x^2(x-1),xy,y^2)$ とする。$y^2\in J$ により全点で $y=0$ となるため、この方程式では直線は残らず $(0,0),(1,0)$ だけが残る。二点の消滅イデアルは $K=(y,x(x-1))$ である。代数側では $(x(x-1))^2=(x-1)x^2(x-1)\in J$ と $y^2\in J$ が証明書になる。今度は $y^2$ を生成元から外して $J'=(x^2(x-1),xy)$ とすると、$x=0$ のとき $y$ が自由になり、$x=1$ のときは $y=0$ となる。従って $\sqrt{J'}=(x)\cap(x-1,y)=(x(x-1),xy)$ である。最後の等式は、$(x-1,y)$ を法として $x$ が $1$ になるので、$xh\in(x-1,y)$ なら $h\in(x-1,y)$ となることから直接従う。
:::

:::example[余分な補助変数による空集合の判定]
$J=(xy-1,x(y-2))$ で定まる零点集合に $y=0$ の点はない。これは $xy=1$ から分かるが、環でも $(J,y)$ が $1$ を含むことで確認できる。また $xy-1$ で商を取ると $x$ は単元になるので、$x(y-2)=0$ から $y=2$ が従う。標数零では $x=1/2$ である。例えば $x(y-2)-(xy-1)=1-2x$ を先に求めれば、除法の代わりにイデアル演算で同じ点を取り出せる。標数 $2$ ではこの差が $1$ になり、零点集合は空である。
:::

### 最小の方程式と既約分解に使う方程式

$V(J)$ を計算する際、方程式の生成元を選び直しても $J$ は同じであるが、根基へ移ると環そのものが変わる。例えば $J=(x^2,y)$ から $(x,y)$ に移る前は $1,x$ が商の基底となり、移った後には $1$ だけになる。点集合を問う場合は後者を使い、接触の次数を問う場合は前者の $x$ も使う。何を保存する計算かを最初に決めると、途中で根基を取ってよいかが明確になる。

### 飽和を補助変数と剰余類で検算する

:::proposition[局所化の核と飽和]{#prop-ag-affine-saturation-ring}
$J\subset R$、$f\in R$ とする。$R/(J:f^\infty)$ は $R/J$ を $f$ で局所化した環への $R$ からの像である。新しい変数 $z$ を使えば $(J:f^\infty)=(J,fz-1)R[z]\cap R$ である。
:::

:::proof
$R\to(R/J)_f$ において $h/1=0$ となる条件は、局所化の等号の定義から、ある $N$ について $f^Nh\in J$ となることである。次に $(R/J)[z]/(fz-1)$ と $(R/J)_f$ の間には、$z\mapsto f^{-1}$ と係数環からの写像が誘導する互いに逆の写像がある。これは両環で $f$ に逆元を持たせた普遍性が同じであることによる。従って $R[z]$ の商に移したときの核を $R$ へ縮約しても同じ条件になる。
:::

:::example[根基を取らない飽和で成分の厚みを残す]
$J=(x^2y^3)\subset k[x,y]$ を $x$ で飽和する。$x^Nh$ が $x^2y^3$ で割れるためには $y^3$ が $h$ を割る必要がある。逆に $h=y^3a$ なら $x^2h\in J$ である。従って $(J:x^\infty)=(y^3)$ であり、$x=0$ の成分が除かれても $y=0$ の三重構造は残る。今度は根基を先にとると $\sqrt J=(xy)$ となり、飽和は $(y)$ になる。この違いは、開集合での局所化後も $y$ が零になるとは限らず、$y^3$ までの関係だけが残ることからも分かる。
:::

:::example[何回飽和すれば安定するか]
$J=(x^3y^2,x^2y^4)$ とする。$x$ との商イデアルを一回ずつ取ると
$$
\begin{aligned}
J:x&=(x^2y^2,xy^4),\\
J:x^2&=(xy^2,y^4),\\
J:x^3&=(y^2,y^4)=(y^2).
\end{aligned}
$$
各行は、単項式がイデアルに入る条件を二生成元のどちらかで割れることと書いて得る。一般の多項式も項ごとに判定できる。三回目の結果は $x$ を掛けても条件が変わらないので、以降安定する。点集合だけを見ると $(y)$ が対応するが、この計算には指数 $2$ までの情報が残る。一般の Noether 環でも商イデアルの昇鎖は安定するので、飽和が有限段で止まる。
:::

:::example[共通零点がないことを証明書で示す]
標数零で $J=(x^2-1,xy-1,y-2)$ とすると、$xy-1-x(y-2)=2x-1$ が $J$ に入る。さらに $4(x^2-1)-(2x-1)(2x+1)=-3$ も $J$ に入るので $J=R$ である。従って共通零点はない。標数 $3$ ではこの証明書の最後が零になり、$y=2$、$x=2$ が三式を満たす。このように、有理係数で求めた消去イデアルの証明書を別の体で使う場合は、最後に割った定数が可逆か確認する。
:::

## 既約性と既約成分分解

:::definition[既約性と既約成分]{#def-ag-irreducible}
空でない位相空間 $X$ が二つの真の閉部分集合の和にならないとき :term[既約]{en="irreducible" yomi="きやく"} であるという。包含に関して極大な既約閉部分集合を :term[既約成分]{en="irreducible component" yomi="きやくせいぶん"} という。
:::

:::proposition[既約性の判定]{#prop-ag-affine-prime}
空でない閉集合 $X$ について、$X$ の既約性と $I(X)$ の素性は同値である。空でない位相空間で既約性は、空でない任意の二つの開集合が交わることとも同値である。
:::

:::proof
閉集合の和を補集合に移せば後半が従う。$fg$ が $X$ 上で消えるなら $X=(X\cap V(f))\cup(X\cap V(g))$ であるから、既約なら $f$ または $g$ が消える。逆に $X=Y\cup Z$ を真の閉集合の和とする。包含反転対応より $f\in I(Y)\setminus I(X)$ と $g\in I(Z)\setminus I(X)$ を取れる。$fg\in I(X)$ なので $I(X)$ は素でない。
:::

空でない開部分集合 $U$ は、$X$ が既約なら稠密かつ既約である。実際 $X$ の任意の空でない開集合は $U$ と交わる。また $U$ の相対開集合は $X$ でも開なので、空でない二つは交わる。さらに連続写像 $f$ による既約集合の像も既約である。像の閉集合への分解を逆像に移すと、片方の逆像が全体になり、その閉集合が像を覆う。一般の既約部分集合の閉包が既約であることも、閉包の閉分解を部分集合に制限し、片方に含まれると判定してもう一度閉包を取れば分かる。

:::example[三本の直線]
$V(xy(x-y))\subset\mathbb A^2$ は $x=0$、$y=0$、$x=y$ の和である。各直線の剰余環は $k[t]$ なので定義イデアルは素である。これらのうちどの直線も他の直線を含まない。既約集合が有限和に含まれるならどれか一つに入るので、これが成分の全体である。
:::

有限な既約閉分解を得たとき、包含されている項を削除すると既約成分の一意なリストになる。実際、任意の既約閉部分集合 $C$ は、分解の各項との交わりで有限個の閉集合に分解されるため、どれか一項に含まれる。したがって極大な $C$ はその項に等しい。包含を逆転すると、$X$ の成分は $I(X)$ を含む極小の素イデアルと一対一に対応する。

### 超曲面の成分と因子分解

:::proposition[一式で定まる集合の成分]{#prop-ag-hypersurface-factorization}
非定数多項式 $f$ の既約因子分解を $f=c\prod_{i=1}^r f_i^{e_i}$ とする。同伴な因子はまとめてあるとする。このとき $V(f)$ の既約成分は $V(f_i)$ であり、$I(V(f))=(\prod_i f_i)$ である。
:::
:::proof
多項式環は一意分解整域なので、$f_i$ は素元である。従って $V(f_i)$ は :ref[prop-ag-affine-prime] で既約である。二つの間に包含があればイデアルの反転により一方の $f_i$ が他方で割れ、相異なるという仮定に反する。積の零点集合は和に等しく、一つも冗長でないので成分を得る。各成分の消滅イデアルの共通部分は、全ての相異なる素元で割れる元全体である。この条件は積で割れる条件に等しい。
:::

:::example[交点を共有する成分]
標数が $2$ でないとし、$V((y-x)^3(y+x)^2)$ を取る。傾きが $1,-1$ の二直線を得る。原点は二成分に同時に入るが、原点は各成分に真に含まれるため成分ではない。消滅イデアルは $(y^2-x^2)$ となり、二式の指数は点集合からは戻らない。
:::

### 局所閉集合と開部分の成分

:::definition[局所閉集合]
位相空間 $X$ の部分集合が、ある開集合とある閉集合の共通部分であるとき、:term[局所閉集合]{en="locally closed subset" yomi="きょくしょへいしゅうごう"} という。
:::

:::proposition[閉包と開部分への成分の制限]
$X$ が有限個の既約成分 $X_1,\dots,X_r$ で覆われ、$U$ が開集合であるとする。$U$ と交わる $X_i$ に対して $U\cap X_i$ が $U$ の成分を与える。また部分集合 $T$ が局所閉であることは、$T$ が $\overline T$ の開部分であることと同値である。
:::

:::proof
交わり $U\cap X_i$ は $X_i$ の空でない開集合なので既約かつ稠密である。$U$ 上で $U\cap X_i\subset U\cap X_j$ となるなら、$X$ で閉包を取って $X_i\subset X_j$ を得るため、$i=j$ である。従って $U$ の有限既約閉分解の項に冗長なものはない。次に $T=U'\cap F$ と書けるなら $\overline T\subset F$ なので $T=U'\cap\overline T$ である。逆は相対位相の定義から従う。
:::

:::example[一成分だけを消す開集合]
$X=V(xy(x-y))\subset\mathbb A^2$ から $x=0$ を除く。$D_X(x)$ に残るのは $y=0$ と $y=x$ の上で $x\ne0$ を満たす点である。二つの枝の唯一の共通点であった原点が除かれたため、この開集合は二つに分かれる。閉包は $V(y(x-y))$ である。これに対して $D_X(x+y)$ を取ると、標数 $2$ では $x=y$ の成分が全て消え、標数零ではどの成分も原点以外を残す。従って同じ文字式の開条件でも、係数体で成分への制限を評価する必要がある。
:::

:::example[連結だが成分は二つ]
$V(xy)$ では二つの座標軸が原点で交わる。各軸は既約なので連結である。空でない互いに素な開集合で $V(xy)$ が分割されたとすると、各軸は片方だけに入る。両軸は原点を共有するので同じ側に入らなければならず、もう片方は空になる。従って $V(xy)$ は連結である。他方 $V(x(x-1))$ では $x=0$ と $x=1$ の直線が交わらず、それぞれが全体で開かつ閉なので非連結である。既約成分を求めた後に、その交わりを調べればこの二例を区別できる。
:::

:::example[平面と直線を同じ空間で取り出す]
$\mathbb A^3$ の $V(xy,xz)$ を考える。$x=0$ なら $y,z$ は任意であり、$x\ne0$ なら $y=z=0$ である。従って $V(xy,xz)=V(x)\cup V(y,z)$ である。座標環がそれぞれ $k[y,z]$ と $k[x]$ になるので双方が既約であり、どちらも他方を含まない。さらに $(x)\cap(y,z)=(xy,xz)$ である。実際、$xh\in(y,z)$ なら $k[x]$ における $x\bar h=0$ から $\bar h=0$ となる。このイデアルは根基だが、$x$ と $y$ の像が非零で積は零なので素ではない。
:::

### 既約集合が閉じている必要がない場面

既約な集合の像を扱うとき、像が閉じているかは別問題になる。例えば $\mathbb A^1$ から $(t,t^2)$ へ送る写像を $t\ne0$ に制限すると、像は放物線から原点を除いた部分である。$k[t,t^{-1}]$ が整域であること、または既約空間の開部分であることから像は既約である。その閉包を取れば放物線に戻る。以降、像の既約性を使うときは、必要な結論が像そのものについてか、閉包についてかを明示する。

### 成分が連結成分にまとまる条件

:::proposition[成分の交わりと連結性]
$X$ が有限個の既約成分 $X_1,\dots,X_r$ で覆われているとする。添字を頂点とし、$X_i\cap X_j\ne\varnothing$ のときだけ辺を結ぶ。グラフの各連結成分に属する $X_i$ の和は、$X$ の一つの連結成分である。
:::

:::proof
既約空間は連結である。実際、二つの非空な開集合で分離すれば既約性に反する。連結部分空間の和で二つに分離できると仮定すると、各部分空間は片側にしか入れない。辺がある二成分は点を共有するので同じ側に入る。グラフの連結成分内では任意の二頂点が辺の列で結ばれるため、該当する和は連結である。他のグラフ成分に属する和とは交わらない。既約成分が有限なので、各和とそれ以外の成分の和はともに閉であり、各和は開でもある。従って二つ以上を含む連結部分集合は存在せず、連結成分が得られる。
:::

:::example[三成分を介して連結になる]
$\mathbb A^2$ の $V(x(x-1)y)$ を標数零で考える。成分は $x=0,x=1,y=0$ の三つである。最初の二直線は互いに交わらないが、第三の直線が $(0,0),(1,0)$ でそれぞれに交わる。従ってグラフは二辺をもつ連結な道であり、全体は連結である。一方、$D(x(x-1))$ に制限すると縦二成分は消え、横一成分の $x\ne0,1$ だけが残るので既約である。$D(y)$ へ制限した場合は横成分が消え、縦二成分の原点を避けた部分が互いに交わらないため、二つの連結成分になる。
:::

:::example[冪等元で連結でないことを検出する]
$A=k[x,y]/(x(x-1))$ では $x^2=x$ なので $x$ は冪等元である。$x=0$ と $1-x=0$ は同時には成り立たず、$x(1-x)=0$ なのでどちらかは成り立つ。従って二閉集合は互いに補集合である。逆に $X=Y\sqcup Z$ が二つの非空閉集合に分かれるとき、$I(Y)+I(Z)=A$ である。$a+b=1$ を $a\in I(Y),b\in I(Z)$ で表せば、$a$ は $Y$ で $0$、$Z$ で $1$ なので $a^2-a$ は全点で消えて $A$ では零であり、非自明な冪等元となる。この証明は任意のアフィン代数的集合に適用できる。
:::

## Noether 位相空間

:::definition[Noether 位相空間]{#def-ag-noetherian-space}
閉集合の任意の降鎖 $X_1\supset X_2\supset\cdots$ が安定するとき、$X$ を :term[Noether 位相空間]{en="Noetherian topological space" yomi="ねーたーいそうくうかん"} という。補集合を取ると、開集合の昇鎖が安定する条件と同じである。
:::

:::theorem[有限既約分解]{#thm-ag-noetherian-components}
Noether 位相空間の閉集合は有限個の既約成分の和である。特にアフィン代数的集合は Noether 位相空間である。
:::

:::proof
有限既約分解をもたない閉集合があると仮定する。降鎖条件により、その中から極小の $Y$ を取れる。$Y$ は空でなく既約でもないので $Y=Y_1\cup Y_2$ と真の閉集合に分かれる。極小性から両方が有限既約分解をもち、和を取れば $Y$ も分解できる。よって反例は存在しない。前節の議論から、冗長な項を取り除いたものが成分である。

アフィン閉集合の降鎖に $I$ を適用すると $R$ のイデアルの昇鎖を得る。:ref[thm-comm-hilbert-basis]{text="Hilbert の基底定理"} よりこの昇鎖は安定し、$V$ を適用すると元の降鎖も安定する。
:::

:::proposition[部分空間と有限被覆]{#prop-ag-noetherian-quasicompact}
Noether 空間の任意の部分空間は Noether であり、特に任意の開被覆から有限部分被覆を選べる。
:::

:::proof
部分空間 $Y$ の閉集合 $F$ は $Y\cap\overline F^X$ と書ける。よって $Y$ の閉降鎖を $X$ で閉包に移して安定させ、その後 $Y$ と交わらせればよい。有限被覆の主張は、開被覆の有限部分和の集合から開昇鎖条件で極大な和 $W$ を選んで示す。$W\ne Y$ ならその外の点を覆う開集合を追加して真に大きな和を作れてしまう。
:::

:::example[無限和と有限方程式]
$\mathbb A^1$ は無限個の点の和であり、それらのどの有限部分和にも等しくない。有限部分被覆の主張は開被覆についてである。一方、無限集合 $S$ で与えた $V(S)$ は有限個の元で定まる。実際、$(S)$ の有限生成元を各々 $S$ の有限個の元の線形結合で書けば、そこに現れる元だけで $(S)$ が生成される。
:::

:::proposition[局所 Noether 性と有限被覆]{#prop-ag-finite-noetherian-cover}
位相空間が有限個の Noether 部分空間で覆われれば Noether である。Noether 部分空間の連続像も Noether である。
:::
:::proof
降鎖を有限被覆の各項に制限する。各制限が安定する段階の最大値を取ると、すべての点で集合への所属が安定する。連続像の閉降鎖は定義域への逆像の閉降鎖になる。像への射が全射なので逆像の等しさは元の閉集合の等しさを含意する。
:::

:::example[鎖が停止しても長さに一様な上界がない例]
$\mathbb A^1_k$ は閉降鎖を無限に厳しく続けられない。最初に有限集合へ落ちた後、その個数が各段階で減るからである。ただし降鎖の長さに一様な上界はない。任意の $r$ 個の相異なる点を用意し、一つずつ除けば長さ $r$ 以上にできる。後に定義する次元では既約閉集合の鎖だけを用いるため、これらの列から一次元を超える結論は得られない。
:::

### 開被覆から単位元の表示を得る

:::proposition[基本開被覆の代数条件]
アフィン代数的集合 $X\subset\mathbb A^n$ に対し、$A=k[x_1,\dots,x_n]/I(X)$ とする。$\{D_X(f_\lambda)\}_\lambda$ が $X$ を覆うことは、$1$ が $f_\lambda$ たちの生成するイデアルに入ることと同値である。
:::

:::proof
$1=\sum_{i=1}^r a_i f_{\lambda_i}$ と書けるなら、任意の点で右辺の少なくとも一項が零でないため被覆となる。逆に生成イデアルが真なら、ある極大イデアルに含まれる。その極大イデアルを周囲の多項式環に引き戻すと、弱零点定理により共通零点が得られる。引き戻しは $I(X)$ を含むから、共通零点は $X$ に属する。その点は全ての $D_X(f_\lambda)$ の外になる。
:::

:::example[無限被覆に有限の証明書を与える]
$X=\mathbb A^1_{\C}$ 上で、整数 $m\ge1$ ごとに $D(x-m)$ を取る。$D(x-1)$ と $D(x-2)$ だけで既に覆う。実際 $(x-1)-(x-2)=1$ である。各個の開集合は一点を取り除くが、二つの除外点が相異なるので共通の除外点がない。単位元の表示は、どの点でも少なくとも一つの分母が使えることを証明する。
:::

:::example[体の標数で被覆が変わる]
$\mathbb A^2_k$ 上の $D(x)$、$D(y)$、$D(x+y-2)$ を考える。標数が $2$ でなければ $x+y-(x+y-2)=2$ から単位元を得るので被覆である。任意の二つについては共通零点がある。例えば $x$ と $x+y-2$ は $(0,2)$ で同時に消える。標数 $2$ では三式とも原点で消えるため、被覆ではない。この場合には部分被覆を探す前に共通零点を調べる必要がある。
:::

:::example[Noether 性と準コンパクト性の違い]
$X=\{0\}\cup\{1/n:n\ge1\}\subset\R$ に通常の相対位相を与える。$0$ を含む任意の開集合はある $N$ 以降の $1/n$ を全て含む。残りは有限なので、任意の開被覆は有限部分被覆をもつ。一方 $F_m=\{0\}\cup\{1/n:n\ge m\}$ は、補集合が孤立点の有限和で開になるため閉集合である。$F_m\supsetneq F_{m+1}$ が無限に続くので $X$ は Noether ではない。空間全体に有限部分被覆があることと、全ての部分空間で同じ性質が成り立つことは区別する必要がある。
:::

:::proposition[全開部分の準コンパクト性]
位相空間 $X$ が Noether であることは、任意の開部分 $U\subset X$ が準コンパクトであることと同値である。ここで準コンパクトとは任意の開被覆から有限部分被覆を選べることをいう。
:::

:::proof
順方向は :ref[prop-ag-noetherian-quasicompact] である。逆に開昇鎖 $U_1\subset U_2\subset\cdots$ を取り、$U=\bigcup_n U_n$ とおく。$U$ が準コンパクトなので有限個の $U_n$ が $U$ を覆う。鎖なので最大の添字 $N$ を選べば $U=U_N$ であり、以降は安定する。
:::

### 降鎖条件が保証する帰納法

:::proposition[閉集合に関する Noether 帰納法]
Noether 空間 $X$ の閉集合に関する性質 $\mathcal P$ を考える。任意の閉集合 $Z$ について、その全ての真の閉部分集合が $\mathcal P$ を満たせば $Z$ も満たすと仮定する。このとき全ての閉集合が $\mathcal P$ を満たす。
:::

:::proof
反例の集合が空でなければ包含に関する極小元を取れる。極小な反例が存在しないとすれば、一つの反例からそれに真に含まれる反例を選べて、その操作から無限の真の降鎖が生じるからである。極小な反例 $Z$ の真の閉部分集合は全て $\mathcal P$ を満たす。そこで仮定を適用すると $Z$ も満たし、反例であることと矛盾する。
:::

:::example[局所閉集合の有限分解]
$X=V(xy(x-y))$ から有限集合 $F=\{(0,0),(1,0),(1,1)\}$ を除く。三成分それぞれから、その成分に入る $F$ の点を除くと、三つの既約な局所閉集合を得る。成分間の交点はすべて原点に集中しており、これを除いた後は三集合が互いに交わらない。一般には成分の和をそのまま互いに素な分解として使えない。この例のように交わりの有限集合を先に除いてから取り出せば、開部分における成分を重複なく扱える。取り除いた集合も付け戻したい場合には、各点を別の局所閉集合として足す。
:::

:::example[有限被覆は成分ごとの判定で縮められる]
$X=V(xy)$ を標数零で考える。$D(x)$ と $D(y)$ だけでは原点を覆わない。これに $D(1-x-y)$ を加えると全体を覆う。実際 $x+y+(1-x-y)=1$ なので、三式が同時に零になる点はない。少なくともこの三開の中から選ぶ限り、いずれも省けない。$D(x)$ を除くと $(1,0)$、$D(y)$ を除くと $(0,1)$、最後の開を除くと原点が覆えない。準コンパクト性は有限部分被覆を保証するが、いくつの開が必要かは方程式の零点を調べて決まる。
:::

## 座標環とアフィン多様体

:::definition[座標環とアフィン多様体]{#def-ag-coordinate-ring}
閉集合 $X\subset\mathbb A^n$ の :term[座標環]{en="coordinate ring" yomi="ざひょうかん"} を $k[X]=k[x_1,\dots,x_n]/I(X)$ とする。アフィン代数的集合が既約であるとき :term[アフィン多様体]{en="affine variety" yomi="あふぃんたようたい"} と呼ぶ。この規約では多様体は空でない。
:::

商を取ることで、$k[X]$ の元を $X$ 上の多項式関数と同一視できる。したがって $k[X]$ は被約であり、:ref[prop-ag-affine-prime] により $X$ が多様体である場合は整域である。

:::proposition[座標環から点と閉集合を復元する]{#prop-ag-affine-recovery}
$A=k[X]$ とする。$X$ の点は $A$ の極大イデアルと全単射に対応し、$X$ の閉集合は $A$ の根基イデアルと包含を逆にして対応する。また任意の有限生成被約 $k$ 代数はあるアフィン代数的集合の座標環である。
:::

:::proof
$p$ に評価の核 $\mathfrak m_p$ を対応させると $A/\mathfrak m_p=k$ となる。逆に、極大イデアルを多項式環に引き戻すと、弱零点定理から共通零点 $p$ がある。そのイデアルは評価の核に含まれ、極大性で等しくなる。異なる点の座標はいずれか一つが違うから評価の核も違う。閉集合との対応は :ref[thm-ag-affine-nullstellensatz] を商環に移せばよい。有限生成被約代数 $B$ に生成元を取ると全射 $k[x_1,\dots,x_n]\to B$ を得る。その核は被約性により根基イデアルであり、零点集合を取ると座標環が $B$ になる。
:::

:::example[双曲線と座標環の単元]
$A=k[x,y]/(xy-1)$ とする。$x$ は単元であり $y=x^{-1}$ なので、$k[t,t^{-1}]\to A$、$t\mapsto x$ は全射である。逆向きに $x\mapsto t$、$y\mapsto t^{-1}$ と送れるから同型である。Laurent 多項式の積の最低次数と最高次数はそれぞれ足し算で決まるため、単元は $ct^m$（$c\ne0$）に限られる。
:::

:::example[多項式写像のグラフ]
$f_1,\dots,f_r\in k[x_1,\dots,x_n]$ とする。グラフの方程式 $y_i-f_i=0$ で商を取ると、任意の多項式は $y_i=f_i$ を代入した形に簡約される。代入写像でその簡約形は一意なので、商は $k[x_1,\dots,x_n]$ に同型である。よってグラフは既約である。
:::

:::proposition[積の座標環]{#prop-ag-affine-product-ring}
アフィン代数的集合 $X\subset k^m,Y\subset k^n$ について $k[X\times Y]\simeq k[X]\otimes_k k[Y]$ である。$X,Y$ がともに既約なら $X\times Y$ も既約である。
:::
:::proof
二種類の座標で生成されるため、自然な準同型 $k[X]\otimes_k k[Y]\to k[X\times Y]$ は全射である。核の元を $\sum_i f_i\otimes g_i$ と書き、$g_i$ は一次独立になるよう取り直す。任意の $p\in X$ について $\sum_i f_i(p)g_i$ は関数として零だから、各 $f_i(p)=0$ である。従って各 $f_i$ は零となる。

二つの非零関数 $a,b$ を同様に第二因子で一次独立な基底に展開する。第一因子で少なくとも一つの係数が非零となる点の集合は、$a,b$ それぞれについて非空開集合である。$X$ が既約だから両者が重なる点 $p$ が取れる。そこで $a(p,-),b(p,-)$ はどちらも $Y$ 上の非零関数であり、$Y$ の既約性から同時に非零となる点 $q$ が取れる。この $(p,q)$ で $(ab)(p,q)\ne0$ である。ゆえに座標環は整域である。
:::

:::example[二重の Laurent 多項式環]
二つの双曲線 $V(xy-1)$ と $V(uv-1)$ の積は、$x,u$ を残すと座標環 $k[x,x^{-1},u,u^{-1}]$ をもつ。一方、$\mathbb A^2$ の通常の多項式環では $x,u$ は単元ではない。座標環の単元を調べると、座標の一部を逆にした開集合と元の空間を区別できる。
:::

### 値の補間と基本開集合の座標環

:::proposition[有限点での値の指定]
$X\subset\mathbb A^n$ の相異なる点 $p_1,\dots,p_s$ における評価 $k[X]\to k^s$ は全射であり、核は $\bigcap_i\mathfrak m_{p_i}$ である。
:::

:::proof
$i\ne j$ なら $p_i,p_j$ の異なる座標がある。その座標を $x_{h(i,j)}$ とし、$\ell_{ij}=(x_{h(i,j)}-(p_j)_{h(i,j)})/((p_i)_{h(i,j)}-(p_j)_{h(i,j)})$ とおく。すると $\ell_{ij}(p_i)=1$、$\ell_{ij}(p_j)=0$ である。$e_i=\prod_{j\ne i}\ell_{ij}$ は $p_i$ で $1$、他の全点で $0$ になる。指定した値 $a_i$ に対して $\sum_i a_i e_i$ が求める元である。核は全点で消える元の集合なので、評価の核の共通部分になる。
:::

:::example[四点で同時に値を指定する]
$\C^2$ の $(0,0),(2,0),(0,3),(2,3)$ で値 $1,4,-2,5$ を順に指定する。各値を拠点にした補間は
$$
(1-x/2)(1-y/3)+4(x/2)(1-y/3)-2(1-x/2)(y/3)+5(x/2)(y/3)
=1+\tfrac32x-y+\tfrac23xy
$$
である。例えば最後の点での値は $1+3-3+4=5$ となる。二つの多項式が同じ四値を与えることは、その差が $(x(x-2),y(y-3))$ に入ることと同値である。実際このイデアルで割ると、$1,x,y,xy$ で張られる剰余に簡約できる。これらの一次結合が全四点で消えれば、まず $(0,0)$ で定数項が消え、残り三点で順に $x,y,xy$ の係数が消える。
:::

:::proposition[逆元を変数で表した開集合]
$A=k[X]$ と $f\in A$ に対し、$D_X(f)$ と $X\times\mathbb A^1$ 内の閉集合 $W=V_{X\times\mathbb A^1}(fz-1)$ の間に、射影と $p\mapsto(p,f(p)^{-1})$ による互いに逆の連続写像がある。$W$ の座標環は $A_f$ である。
:::

:::proof
対応する点が一意であることは $fz=1$ から従う。射影は座標の多項式で与えられるため連続である。$A[z]$ の元 $g$ を逆向きの写像で引き戻すと $g(p,1/f(p))$ になる。$D_X(f)$ 上では $f$ が非零なので、$f$ の十分高い冪を掛けて得られる多項式の零点条件と同値である。従って閉集合の逆像が閉じる。環については $A[z]/(fz-1)\simeq A_f$ が、$z$ と $1/f$ を対応させる局所化の普遍性で従う。$A$ は被約であり、局所化も被約である。実際 $(a/f^r)^m=0$ なら $f^s a^m=0$ となる $s$ があり、$(f^s a)^m=0$ から $f^s a=0$ を得る。従って方程式 $(fz-1)$ は $A[z]$ で根基であり、商環がそのまま $k[W]$ となる。
:::

:::example[開部分で消える元を確認する]
$X=V(xy)$、$f=x$ とする。$A$ では $y\ne0$ であるが、$A_x$ では $y=(xy)/x=0$ である。補助変数の式 $xz-1=0$ を加えると $y=yxz=z(xy)=0$ となり、環は $k[x,z]/(xz-1)\simeq k[x,x^{-1}]$ になる。従って局所化写像は一般には単射でない。一方 $f=x+y$ を使うと、$fg=0$ なら両方の軸上で $g$ が原点以外で消え、各軸上の多項式として零である。よって $g=0$ であり、$A\to A_f$ は単射になる。
:::

:::example[点だけで比較できない部分環]
$k[t^2,t^3]\subset k[t]$ を考える。像集合 $V(y^2-x^3)$ の点は $(t^2,t^3)$ で表せて、$x\ne0$ のとき $t=y/x$、原点では $t=0$ で変数が一意に決まる。しかし $t$ は $k[t^2,t^3]$ には入らない。実際この部分環の単項式は指数 $0,2,3,4,\dots$ をもち、指数 $1$ の係数は常に零である。点集合の全単射を作った場合にも、逆向きの座標が多項式関数かどうかは別に調べる。この例は [平面曲線の正規化](/math/algebraic-geometry/plane-curves/) で再び扱う。
:::

### 既約成分の環を値の一致条件で合わせる

:::proposition[二閉集合の座標環の差写像]
$X_1,X_2\subset\mathbb A^n$ の消滅イデアルを $I_1,I_2$ とし、$R$ を周囲の多項式環とする。$k[X_1\cup X_2]$ は $R/I_1\oplus R/I_2$ のうち $R/(I_1+I_2)$ への二つの像が一致する対の環である。
:::

:::proof
$R$ から二商への対角の核は $I_1\cap I_2=I(X_1\cup X_2)$ である。像に入る対は同じ $R$ の元から来るため、さらに $I_1+I_2$ を法として一致する。逆に代表 $a,b$ が $a-b=i_1+i_2$（$i_j\in I_j$）を満たすなら、$a-i_1=b+i_2$ が両方の代表となる。従って対は像に入る。和に根基を取らずに比較するのは、二成分の交わりで高次の係数まで一致する必要がある場合があるためである。
:::

:::example[交差する二直線と接する二曲線]
二軸では $I_1=(y)$、$I_2=(x)$ なので、対応する $(a(x),b(y))$ に必要なのは $a(0)=b(0)$ だけである。次に $I_1=(y)$、$I_2=(y-x^2)$ とする。第二の曲線の環も $k[x]$ であるが、今度は $R/(I_1+I_2)=k[x]/(x^2)$ である。従って対 $(a(x),b(x))$ は定数項と一次項が一致して初めて大域座標環に入る。例えば $(1+x,1+2x)$ は標数零で定数項が一致しても入らない。$(1+x,1+x+3x^2)$ なら $1+x+3y$ で持ち上げられる。二曲線の台が一点で交わることだけでは、座標環を組み立てる際の条件数は決まらない。
:::

:::example[互いに素な成分では一致条件が消える]
$X=V(x(x-1))\subset\mathbb A^2$ に対して $I_1=(x)$ と $I_2=(x-1)$ は和が $R$ である。従って任意の多項式対 $(a(y),b(y))$ が許される。明示的には $(1-x)a(y)+xb(y)$ が両直線に指定した値を与える。環の積構造では $x$ は $(0,1)$ に移るので、先の非自明な冪等元が確認できる。成分が交わるときは、同じ補間の式が使えるかどうかを共通の商で判定する。
:::

## 例：平面曲線・行列式多様体・ねじれ三次曲線

方程式から既約性を調べる方法と、パラメータ表示から方程式を調べる方法を対比する。多項式写像 $\phi:k^m\to k^n$ は閉集合の逆像が代入した方程式で定まるので連続である。$k$ が無限体のため $k^m$ 上で恒等的に消える多項式は零である。これは変数を一つ取り、各係数を残りの変数の多項式とみて一変数の場合を帰納的に適用すれば分かる。したがって像の消滅イデアルは代入準同型の核であり、像の閉包はその核で定まる。

:::example[平面の尖点]{#exm-ag-affine-cusp}
$\phi(t)=(t^2,t^3)$ とする。$y^2-x^3$ で割ると各多項式は $a(x)+yb(x)$ と合同である。代入後の $a(t^2)$ は偶数次数だけ、$t^3b(t^2)$ は奇数次数だけをもつ。したがって核は $(y^2-x^3)$ であり、座標環は $k[t^2,t^3]$ である。点 $(x,y)$ が方程式を満たし $x\ne0$ なら $t=y/x$ から $t^2=x$ および $t^3=y$ を得る。$x=0$ なら $y=0$ なので $t=0$ をとる。この例では像そのものが閉じている。
:::

:::example[階数が 1 以下の行列]{#exm-ag-rank-one-variety}
行列 $(z_{ij})$ の階数が 1 以下である条件は、すべての $2\times2$ 小行列式が消えることである。非零成分 $z_{ij}$ を選ぶと小行列式の式から $z_{ab}=z_{aj}z_{ib}/z_{ij}$ となり、列と行の積で書ける。零行列も含め、従ってこの閉集合は $(u,v)\mapsto (u_iv_j)$ の像である。定義域が既約であり写像が連続なので、像も既約である。

$2\times2$ の場合、$z_{11}z_{22}=z_{12}z_{21}$ で割ると、$z_{11}$ と $z_{22}$ の両方を含む単項式を除ける。画像 $u_1^{r_1}u_2^{r_2}v_1^{c_1}v_2^{c_2}$ の行和・列和を固定すると、残る単項式では $z_{11}$ の指数が $\max(0,c_1-r_2)$ に決まる。他の指数も行和・列和で決まるため、簡約後の異なる単項式の像は一次独立である。このことから行列式一つが核を生成すると分かる。
:::

:::example[アフィンねじれ三次曲線]{#exm-ag-affine-twisted-cubic}
$t\mapsto(t,t^2,t^3)$ の像は $y-x^2=0$ と $z-x^3=0$ で定まる。最初の座標を残して他の二つを消去できるため、座標環は $k[x]$ である。$z-xy$ を第二の式に使うこともできる。実際 $z-x^3=(z-xy)+x(y-x^2)$ だから、二組は同じイデアルを生成する。射影座標でこれらの式を用いると無限遠の点も考える必要がある。
:::

:::example[パラメータの像と閉包]
$(s,t)\mapsto (s,st)$ の像は $D(x)\cup\{(0,0)\}$ である。$x\ne0$ なら $s=x$、$t=y/x$ と取れ、$x=0$ なら $st=0$ になる。$D(x)$ は既約な平面の空でない開集合なので稠密であり、像の閉包は平面全体である。
:::

### 行列の方程式が生成するイデアル

:::proposition[階数一の行列式イデアル]{#prop-ag-rank-one-minors}
$m\times n$ 行列の環 $k[z_{ij}]$ から $k[u_1,\dots,u_m,v_1,\dots,v_n]$ への $z_{ij}\mapsto u_i v_j$ の核は、全ての $2\times2$ 小行列式で生成される。
:::
:::proof
各小行列式が核に入ることは積の交換法則から分かる。逆に、多項式の単項式を行ごとの因子数と列ごとの因子数で分類する。二つの単項式の像が同じなのは、その両方のリストが一致するときに限る。そのとき各単項式の因子の行の添字を昇順に並べ、一方の列の添字の並びを他方へ移す置換を取れる。置換を互換に分ける。二因子の列添字を交換した前後の差は、同じ行または列なら零であり、そうでなければ小行列式に残りの因子を掛けたものになる。従って同じ分類の単項式はこのイデアルを法として等しい。像が零の多項式では分類ごとに係数の和が零なので、全ての項がこのイデアルを法として消える。
:::

:::example[三列目を割って消去する]
行列 $\left(\begin{smallmatrix}x&y&z\\a&b&c\end{smallmatrix}\right)$ の核を生成する三式は $xb-ya,xc-za,yc-zb$ である。$z\ne0$ では $a=xc/z,b=yc/z$ と解け、残りの式は自動的に成り立つ。その開の座標環は $k[x,y,z,z^{-1},c]$ である。$z=0$ を含む全体ではこの除法はできないが、三式によるイデアルの記述はそのまま使える。
:::

### 消去から像の方程式を求める

:::proposition[多項式像の閉包とパラメータ消去]
$\phi:\mathbb A^r\to\mathbb A^n$ の座標を $f_1(t),\dots,f_n(t)$ とし、$J=(x_1-f_1,\dots,x_n-f_n)\subset k[t,x]$ とする。このとき $I(\overline{\operatorname{Im}\phi})=J\cap k[x]$ である。
:::

:::proof
$k[t,x]$ から $k[t]$ への代入写像の核は $J$ である。これは一変数ずつ $x_i-f_i$ で割ると余りが $g(t,f(t))$ になることによる。$g\in k[x]$ が像の全点で消えるなら、$g(f(t))$ が $k^r$ の全点で消える。$k$ は無限なので、変数を一つずつ固定して一変数の根の個数を用いれば零多項式に限る。従って消滅イデアルは $J\cap k[x]$ であり、閉包を取っても消滅イデアルは変わらない。
:::

:::example[消去は閉包を与える]
$\phi(s,t)=(s,st)$ とする。任意の $s\ne0,y$ に対して $t=y/s$ を取れる。また $s=0$ では像は原点だけである。従って像は $D(x)\cup\{(0,0)\}$ である。代数的には $\sum_j a_j(x)y^j$ の代入像は $\sum_j a_j(s)s^j t^j$ である。これが零なら $k[s]$ が整域であるためすべての $a_j$ が零になる。従って消去イデアルは零で、閉包は平面全体である。消去結果には像から抜けている点 $(0,1)$ も入る。
:::

:::example[二つの分岐点をもつパラメータ]
$t\mapsto(t^2-1,t(t^2-1))$ とする。$y^2=x^2(x+1)$ が成り立つ。逆に $x\ne0$ なら $t=y/x$ で復元し、$x=0$ では $(0,0)$ が $t=1,-1$ の両方から得られる。方程式で割ると余りは $a(x)+yb(x)$ であり、代入後の偶部分は $a(t^2-1)$、奇部分は $t(t^2-1)b(t^2-1)$ である。標数零では両者が独立なので、余りが零になるのは $a=b=0$ の場合だけである。従って消滅イデアルはこの一式で生成される。パラメータ直線の像が既約であることと、原点に二つの前像があることは両立する。
:::

:::example[階数二以下の三次行列式]
$3\times3$ 行列 $M$ の集合で $\det M=0$ を考える。これは階数が $2$ 以下である条件に等しい。列空間から基底を高々二本取り、不足分には零列を加えて $3\times2$ 行列 $U$ とする。$M$ の各列の係数を並べた $2\times3$ 行列を $V$ とすれば $M=UV$ である。逆に $UV$ の列は $U$ の二列の線形結合なので階数は $2$ 以下である。従って積写像でアフィン $12$ 空間から全射があり、この零点集合は既約である。例えば
$$
\begin{pmatrix}1&0\\0&1\\1&1\end{pmatrix}
\begin{pmatrix}2&0&1\\1&3&4\end{pmatrix}
=\begin{pmatrix}2&0&1\\1&3&4\\3&3&5\end{pmatrix}
$$
では左上の二次小行列式が $6$ なので標数零で階数はちょうど $2$ である。最後の行が最初の二行の和になることから三次式は消える。
:::

:::example[ねじれ三次曲線の近縁となる四次曲線]
$t\mapsto(t,t^2,t^3,t^4)$ を考える。$x_2-x_1^2$、$x_3-x_1x_2$、$x_4-x_1x_3$ を順に使うと、全ての座標を $x_1$ の式に直せる。逆に $x_1=t$ と置けば元に戻る。よって商は $k[t]$ であり、この三式が消滅イデアルを生成する。第一座標を除いて $(t^2,t^3,t^4)$ だけにすると、$t^4=(t^2)^2$ のため座標環は $k[t^2,t^3]$ となる。方程式で得たアフィン像と、パラメータ変数を見失う射影の違いを環が記録している。
:::

### 階数条件から座標を復元する

:::proposition[一般の階数以下の行列の既約性]
$m\times n$ 行列の階数が $r$ 以下の集合は、全ての $(r+1)$ 次小行列式で定まる既約閉集合である。ただし $0\le r\le\min(m,n)$ とする。
:::

:::proof
階数が $r$ を超えると $r+1$ 本の独立な列を取れ、その行列には $r+1$ 本の独立な行があるため、対応する小行列式は非零になる。逆にそのような小行列式が非零なら対応する列が独立である。従って方程式は正しく閉条件を与える。階数が $s\le r$ の行列の列空間の基底を $s$ 本取り、足りない分を零列で埋めて $m\times r$ 行列 $U$ を作る。各列の係数を並べると $r\times n$ 行列 $V$ ができ、元の行列は $UV$ になる。逆にどの積も列空間が $U$ の列で張られるため階数が $r$ 以下である。アフィン空間の積からこの集合への多項式写像が全射となる。始域は既約であり、連続像は既約である。
:::

:::example[小行列式を一つ反転して自由座標を読む]
$M$ をブロックで $\begin{pmatrix}A&B\\C&D\end{pmatrix}$ と書き、最初の $r$ 行列でできる正方ブロック $A$ の行列式が非零だとする。左から $\begin{pmatrix}I&0\\-CA^{-1}&I\end{pmatrix}$ を掛けて下左を消去すると、下右は $D-CA^{-1}B$ になる。従って階数が $r$ 以下であることは $D=CA^{-1}B$ と同値である。周囲の開集合ではこれは閉方程式である一方、$A,B,C$ の成分は $\det A\ne0$ の条件のもとで自由に選べる。例えば $r=2$、$A=\begin{pmatrix}1&1\\0&2\end{pmatrix}$、$B=\begin{pmatrix}3\\4\end{pmatrix}$、$C=(2,1)$ なら $A^{-1}B=(1,2)^t$ なので $D=4$ となる。これで階数が正確に二である唯一の補完が得られる。
:::

:::example[曲線を射影したときに消える座標]
標数零で $X=\{(t^2,t^3,t^5):t\in k\}$ とする。$x=t^2,y=t^3,z=t^5$ なら $z=xy$、$y^2=x^3$ である。逆に二式を満たす点は $x\ne0$ なら $t=y/x$、$x=0$ なら $t=0$ で表せる。環の核もこの二式である。$z$ を除き、$y$ の次数を一以下にした余りを $t$ に代入すると、偶数と奇数の指数が重ならず、係数はすべて零でなければならない。この例では第三座標を追加しても座標環の部分代数は増えない。対して新座標として $t$ 自体を足せば、環は $k[t]$ に変わる。この違いは、正規化のように点の情報を保ちながら環を拡大する操作を見分ける際に使える。
:::

## 演習問題

::::exercise{level=basic}
$V(x^2,xy)$ の消滅イデアルを求めよ。

:::solution
$x^2=0$ から $x=0$ であり、すると第二式は自動的に成り立つ。$f(0,y)$ がすべての $y$ で消える条件は $f(0,y)=0$ が多項式として成り立つことである。よって消滅イデアルは $(x)$ である。
:::
::::

::::exercise{level=basic}
$V(y-x^2)\cap V(y-4)$ を求めよ。ただし $\operatorname{char}k\ne2$ とする。

:::solution
$y=4$ より $x^2=4$ となる。$x^2-4=(x-2)(x+2)$ で二根は異なるので、交わりは $(2,4)$ と $(-2,4)$ である。
:::
::::

::::exercise{level=basic}
$V((x-1)y^2)$ の既約成分と消滅イデアルを求めよ。

:::solution
閉集合は $V(x-1)\cup V(y)$ である。各直線は座標環が一変数多項式環で既約であり、互いを含まない。消滅イデアルは $(x-1)\cap(y)=((x-1)y)$ である。最後の等号は、多項式環で $x-1$ と $y$ が相異なる素元であることから従う。
:::
::::

::::exercise{level=basic}
$D_{\mathbb A^1}(x(x-1))$ をアフィン平面の閉集合で表示し、その座標環を与えよ。

:::solution
点 $x$ に $(x,1/[x(x-1)])$ を対応させればよい。閉集合は $V(x(x-1)u-1)$ である。商では $x(x-1)$ が可逆なので局所化 $k[x,1/(x(x-1))]$ から写像を得る。逆向きは $u\mapsto1/(x(x-1))$ で与えられ、二つは逆である。商が整域なので方程式のイデアルは根基である。
:::
::::

::::exercise{level=advanced}
$t\mapsto(t^2,t^5)$ の像と消滅イデアルを求めよ。

:::solution
$y^2-x^5$ で割って $a(x)+yb(x)$ にすると、代入後の偶数次数と奇数次数が重ならないため、核は $(y^2-x^5)$ である。$x\ne0$ の解で $t=y/x^2$ とすれば $t^2=x$、$t^5=t(t^2)^2=y$ となる。$x=0$ の解は原点だけなので像は零点集合全体である。
:::
::::

::::exercise{level=advanced}
$\{(t,t^{-1}):t\in k^\times\}$ の $\mathbb A^2$ での閉包と座標環を求めよ。

:::solution
像は $xy=1$ の解全体である。さらに $k[x,y]/(xy-1)\simeq k[t,t^{-1}]$ は整域であるから、閉包は $V(xy-1)$、座標環はこの Laurent 多項式環である。
:::
::::

::::exercise{level=advanced}
$V(xz,yz)$ の既約成分と消滅イデアルを求めよ。

:::solution
$z=0$ の平面と $x=y=0$ の直線の和である。両方とも多項式環を座標環にもつ既約集合で、包含関係がない。消滅イデアルは $(z)\cap(x,y)$ である。$zh\in(x,y)$ なら $k[z]$ で $z\bar h=0$ となるので $h\in(x,y)$ である。したがって交わりは $(xz,yz)$ に等しい。
:::
::::

::::exercise{level=advanced}
$t\mapsto(t^2,t^3)$ の像上の関数 $t$ が座標環に属さないことを示せ。

:::solution
座標環を :ref[exm-ag-affine-cusp] のように $k[t^2,t^3]$ に埋め込む。この環の単項式の指数は $2a+3b$（$a,b\ge0$）である。$2a+3b=1$ を満たす組は存在しないため、任意の元の $t$ の係数は零である。よって $t$ は元にならない。
:::
::::

## 確認テスト

::::quiz{answer="3" tol="1e-6"}
$V(xy(x-1))$ の既約成分の個数はいくつか。

:::explanation
$x=0$、$y=0$、$x=1$ の三直線の和である。それぞれ既約で、互いに包含しないので三成分となる。
:::
::::

::::quiz
$V(J)$ から常に復元できるイデアルを選べ。

- [x] $\sqrt J$
- [ ] $J$
- [ ] $J^2$

:::explanation
:ref[thm-ag-affine-nullstellensatz] により $I(V(J))=\sqrt J$ である。例えば $J=(x^2)$ なら $I(V(J))=(x)$ なので、任意の $J$ 自体は復元できない。
:::
::::

::::quiz{answer="3" tol="1e-6"}
$\operatorname{char}k=0$ とする。$V(x^3-x)\subset\mathbb A^1$ は何点か。

:::explanation
$x^3-x=x(x-1)(x+1)$ なので、相異なる $0,1,-1$ の三点である。
:::
::::

::::quiz
$\mathbb A^1_k$ の Zariski 位相について正しいものを選べ。

- [x] 任意の無限部分集合は稠密である
- [ ] 点は閉集合ではない
- [ ] すべての有限部分集合は開集合である

:::explanation
一変数の非零多項式は根を有限個しかもたない。したがって空でない開集合の補集合は有限であり、任意の無限部分集合の閉包は全体である。点は $V(x-a)$ なので閉じている。
:::
::::
