## この章の目標

- 代数多様体の次元を計算する。
- 閉集合の交わりと一般ファイバーの次元を見積もる。
- Jacobian 行列から接空間を求める。
- 平面曲線をブローアップして固有変換を計算する。

## 次元と超越次数

パラメータの個数だけでは次元は決まらない。例えば $(s,t)\mapsto(st,(st)^2)$ の二つの成分は、一つの変数 $st$ だけから復元できる。そこで鎖と関数体の双方から自由度を測る。以下 $k$ は代数閉体である。

:::definition[次元]{#def-ag-dimension}
空でない既約閉集合の真の包含の鎖 $Z_0\subsetneq\cdots\subsetneq Z_d$ の長さ $d$ の上限を :term[次元]{en="dimension" yomi="じげん"} $\dim X$ とする。
:::

:::theorem[次元と超越次数]{#thm-ag-dimension-transcendence}
既約多様体 $X$ について $\dim X=\operatorname{trdeg}_k k(X)$ である。任意の非空開集合は同じ次元をもち、閉点 $p$ では $\dim\mathcal O_{X,p}=\dim X$ である。
:::
:::proof
アフィンの場合、零点定理で鎖は座標環の素イデアルの鎖に反転する。:ref[thm-comm-affine-dimension]{text="有限生成整域の次元公式"}を適用すると、$\dim A=\operatorname{trdeg}_k\operatorname{Frac}A$ である。また $\operatorname{ht}\mathfrak m_p=\dim A$ となる。これは次元公式 $\operatorname{ht}\mathfrak p+\operatorname{trdeg}_k\operatorname{Frac}(A/\mathfrak p)=\operatorname{trdeg}_k\operatorname{Frac}A$ の右辺から、$A/\mathfrak m_p=k$ の超越次数零を引いたものである。

一般の場合、既約閉集合の有限鎖の最小の項と交わるアフィン開近傍に鎖を制限する。各項で交わりは稠密だから、制限後も包含は真である。逆にアフィン開集合の鎖は $X$ で閉包を取れば、開集合に制限して元に戻るので真の鎖になる。よって次元はアフィン開の次元の上限である。各アフィン開の関数体は :ref[prop-ag-fraction-field] により共通なので全て同じ次元をもつ。局所環もアフィン開近傍で計算できる。
:::

:::example[ねじれ三次曲線と行列式多様体]
:ref[exm-ag-affine-twisted-cubic] の座標環は $k[t]$ なので次元は $1$ である。$m\times n$ の階数 $1$ 以下の行列の集合では $z_{11}\ne0$ 上で第 $1$ 列と第 $1$ 行のほかの成分は全て $z_{i1}z_{1j}/z_{11}$ で決まる。逆に残した $m+n-1$ 個は $z_{11}\ne0$ 以外自由であるから次元は $m+n-1$ である。
:::

### 次元を三通りに計算する

:::example[行列式で定まる三次元錐]
$X=V(ad-bc)\subset\mathbb A^4$ とする。$ad-bc$ は $d$ に関する原始一次式なので既約である。$a\ne0$ なら $d=bc/a$ であり、座標環は $k[a,a^{-1},b,c]$ になる。従って関数体の超越次数は $3$ である。実際 $V(a,b,c,d)\subsetneq V(b,c,d)\subsetneq V(c,d)\subsetneq X$ は長さ $3$ の既約閉集合の鎖である。面 $V(c,d)$ に対応する $k[X]$ の素イデアルは $(c,d)$ であり、$X$ 内での高さは $3-2=1$ となる。周囲の四次元空間での高さ $2$ と区別する。
:::

:::example[可約な集合では局所次元が変わる]
$X=V(xy,xz)$ には二次元の面 $x=0$ と一次元の直線 $y=z=0$ がある。直線上の $x\ne0$ の点の近傍では $y=z=0$ が従うため局所次元は $1$ である。原点では両成分が通り、局所環の素イデアルの鎖を各極小素イデアルから始められるので、局所次元は二成分の最大値 $2$ となる。
:::

### 行列式多様体の次元公式

:::proposition[階数上限と次元]{#prop-ag-rank-locus-dimension}
$0\le r\le\min(m,n)$ とする。$m\times n$ 行列の階数が $r$ 以下のアフィン多様体 $X_r$ の次元は $r(m+n-r)$ である。$r=0$ では一点とする。
:::

:::proof
$r>0$ では、階数が $r$ 以下の行列全体が $U V$（$U$ は $m\times r$、$V$ は $r\times n$）という形で得られる。従ってアフィン空間からの像として既約である。左上 $r\times r$ の小行列式が非零である開は、左上を単位行列、他を零とする行列を含むので空でない。そこでブロック $\begin{pmatrix}A&B\\C&D\end{pmatrix}$ の階数条件は下左を行操作で消去して $D=CA^{-1}B$ と同値になる。従ってその開の座標環は $A,B,C$ の成分の多項式環を $\det A$ で局所化したものである。独立な成分の個数は $r^2+r(n-r)+(m-r)r=r(m+n-r)$ であり、非空開と全体の関数体が同じなのでこの個数が次元である。
:::

:::example[二つの階数の段を比較する]
$m=4,n=5$ で $X_2$ は次元 $2(4+5-2)=14$ であり、$X_1$ は次元 $1(4+5-1)=8$ である。従って周囲の二十次元空間に対し $X_2$ の余次元は $6$、$X_2$ の中での $X_1$ の余次元は $6$ である。例えば $A=I_2$ の開で $B$ を $2\times3$、$C$ を $2\times2$ とすると下右の六成分が $CB$ に固定される。これらは、その開でのみ六方程式に簡約した表示である。
:::

### 有限な座標への射影と次元

次元の計算には二つの手順がある。関数体の生成元のうち代数的に独立なものを探すか、座標環で Noether 正規化を探す。前者は分数を許すので開集合での計算に向き、後者は全体からの有限射とそのファイバーも与える。

:::example[座標関数の一部が正規化を与える例]
$X=V(y^2-x^3-x)\subset\mathbb A^2$ を標数零で考える。$x^3+x$ は $x=0$ で位数一なので $k(x)$ の平方ではなく、$y^2-x^3-x$ は $k(x)[y]$ で既約である。$y$ についてモニックなので $k[x,y]$ での商も整域であり、$A$ は $k[x]$ 上で $1,y$ を基底とする有限自由加群である。従って $x$ 軸への射は有限で、次元は一である。$x=a$ のファイバーでは $y^2=a^3+a$ となり、右辺が非零なら二点、零なら長さ二の一点である。自由基底の計算から、どちらでも全長が二になる理由が読める。
:::

:::example[最初に選んだ射影が有限とは限らない]
$X=V(xy-1)\subset\mathbb A^2$ で $x$ を残す射は $k[x]\to k[x,x^{-1}]$ を誘導する。後者は、有限個の Laurent 多項式を生成元とすると最低指数に共通の下界ができるため、$k[x]$ 上有限ではない。ところが $u=x+y$ を選べば $x,y$ は $T^2-uT+1=0$ を満たし、$y=u-x$ である。従って $k[X]=k[u][x]/(x^2-ux+1)$ となり、$u$ に関する射は有限自由である。$u$ が超越的であるのは、もし $u$ が $k$ 上代数的ならこの式で $x$ も代数的になるためである。このように、同じ一次元の多様体でも残す座標を替えると有限性が変わる。
:::

:::example[行列の三つのパラメータを取り違えない]
階数一以下の $2\times2$ 行列を $a d=b c$ で記述する。$a\ne0$ では $a,b,c$ を自由に選べるので関数体は $k(a,b,c)$ である。全体の環では $1/a$ を使えないため、それだけで三つの座標への射が有限と結論できない。実際 $a=b=c=0$ の上には $d$ が任意の直線がある。一方 $z=a+d$、$b,c$ を選べば $a$ は $a^2-za+bc=0$ を満たし、$d=z-a$ である。従ってこの三成分への射は有限自由である。$b,c,z$ の独立性は、$k[b,c,z][a]$ のモニック多項式による商において係数環が単射で入ることから従う。関数体の基底として使える変数と、有限射を与える座標との違いが、この二つの射影に現れる。
:::

### 閉点から始まる鎖と成分の次元

:::proposition[閉点における可約集合の局所次元]
アフィン代数的集合 $X$ の成分を $X_i$ とする。閉点 $p$ での $\dim\mathcal O_{X,p}$ は、$p\in X_i$ となる成分の $\dim X_i$ の最大値である。
:::

:::proof
$A=k[X]$ とし、$p$ の極大イデアルを $\mathfrak m$ とする。局所環の素イデアルの鎖は $A$ の素イデアルで $\mathfrak m$ に含まれるものの鎖に対応する。任意の鎖の最初の素イデアルには $A$ の極小素イデアルが含まれ、それは $\mathfrak m$ にも含まれる。その極小素イデアルを法とした商 $A/\mathfrak p_i$ は成分 $X_i$ の整域である。従って鎖の長さは、ある $X_i$ における $p$ の局所次元以下である。逆にその商の局所環での鎖は局所化の商の対応で元の局所環へ持ち上がる。既約な場合の次元公式で $\dim\mathcal O_{X_i,p}=\dim X_i$ なので、最大値が得られる。
:::

:::example[互いに異なる局所次元を一つの空間で見る]
$\mathbb A^4$ で $X=V(xz,xw,yz,yw)$ を考える。四式は $(x,y)$ と $(z,w)$ の積に当たり、少なくとも一方の組が全て零でなければならない。従って $X$ は二つの二次元平面の和で、全閉点の局所次元は $2$ である。一方 $X'=V(xy,xz,xw)$ は三次元超平面 $x=0$ と一次元直線 $y=z=w=0$ の和である。直線上で $x\ne0$ の点では局所次元は $1$、原点では最大値 $3$ となる。四つの座標から作る積の方程式でも、成分の次元と局所次元の分布は生成元の組み方に依存する。
:::

## 超曲面と射影空間内の交わりの次元

:::proposition[方程式の本数と余次元]{#prop-ag-codimension-bound}
純次元 $d$ のアフィン代数的集合に $r$ 本の方程式を追加すると、空でない各成分の次元は少なくとも $d-r$ である。整なアフィン多様体上の非零の正則関数が零点をもてば、その各成分は次元 $d-1$ である。
:::
:::proof
各成分を含む元の既約成分に制限する。そこでも得られた新しい成分は極大なので、対応する素イデアルは $r$ 生成イデアル上の極小素イデアルである。:ref[thm-comm-height]{text="Krull の高さ定理"} により高さは高々 $r$ である。次元公式が高さを次元の差に移す。整域で非零の一式の場合は零イデアルがその式を含まないため高さが少なくとも $1$ であり、上の上界と合わせて等号を得る。
:::

:::theorem[射影空間での次元不等式]{#thm-ag-projective-intersection-dim}
$X,Y\subset\mathbb P^n$ を既約閉集合とする。$\dim X+\dim Y\ge n$ なら交わりは非空であり、交わりの各成分の次元は $\dim X+\dim Y-n$ 以上である。交わりがある場合の次元不等式は右辺が負の場合も成り立つ。
:::
:::proof
各アフィン錐を $\widehat X,\widehat Y\subset\mathbb A^{n+1}$ とする。非空標準開の上では、錐の点を射影座標と非零の倍率に分けられる。よってその開集合は標準開と $\mathbb G_m=\mathbb A^1\setminus\{0\}$ の積であり、錐の次元は元より $1$ 大きい。錐は斉次座標環が整域なので既約である。既約アフィン多様体の積が既約で次元が足し算になることは、各因子の Noether 正規化をテンソルし、有限多項式部分環を得ることから次元について従う。既約性については、積上の二つの非零多項式関数を固定し、それぞれが恒等的に消えないよう第一因子の点を選ぶ。その条件は係数を第二因子の座標環の有限個の一次独立な元で展開して得る非空開条件である。両条件を満たす点で第二因子の既約性を使えば、二つの関数が同時に非零となる。

錐の積に $x_i-y_i=0$ を $n+1$ 本課すと対角上の交わりである。その成分は上の命題より次元が少なくとも $\dim X+\dim Y-n+1$ であり、原点は必ず含まれる。この下界が正なら原点以外にも点がある。射影交叉の各成分に対応する錐は、原点以外の部分を標準開で見れば次元が $1$ 大きいため、射影化して所望の下界を得る。
:::

:::example[射影平面での超曲面]
$\mathbb P^2$ の曲線と直線の次元はそれぞれ $1$ なので必ず交わる。アフィン平面の $x=0$ と $x=1$ には交点がなく、射影化すると共通の無限遠点 $[0:0:1]$ が現れる。
:::

### 余次元の和が実際の余次元になる場合

:::example[共通成分があると下界は等号にならない]
$\mathbb P^3$ の二次曲面 $X_0X_1=0$ と $X_0X_2=0$ は、ともに次元 $2$ である。交わりは平面 $X_0=0$ と直線 $X_1=X_2=0$ の和である。実際 $X_0\ne0$ の近傍で後二式が必要であり、直線の残りの点も閉条件を満たす。余次元の和からは次元 $1$ 以上しか従わず、平面の成分では次元が $2$ になる。
:::

:::example[アフィンで空でも射影閉包は交わる]
アフィン二平面の $y=0$ と $y=1$ は交わらない。それらの射影閉包は $Y=0$ と $Y=Z$ であり、$Y=Z=0$ から $[1:0:0]$ で交わる。射影次元不等式の仮定の下では、方向を表す無限遠点にも交わりを探す必要がある。
:::

### 対角を使ってアフィンの交わりを評価する

二つの閉集合 $X,Y\subset\mathbb A^n$ の交わりは、積 $X\times Y$ の中で二組の座標が一致する部分である。この表現を使うと、元の二つの消滅イデアルの生成元数を知らなくても交わりの次元の下界が出る。

:::proposition[アフィンでの交わりの次元]{#prop-ag-affine-intersection-dimension}
既約な閉集合 $X,Y\subset\mathbb A^n$ に対し、$X\cap Y$ の空でない各既約成分は次元 $\dim X+\dim Y-n$ 以上である。
:::

:::proof
積の座標環は $k[X]\otimes_k k[Y]$ で整域である。各因子に Noether 正規化で有限な多項式部分環を取る。テンソル積はそれらの多項式環のテンソル積上有限である。実際、各加群の有限生成系の単純テンソルが生成し、係数環同士の包含は体上のテンソル積で単射を保つ。従って積の次元は $\dim X+\dim Y$ である。積の中で $x_i-y_i=0$ を $n$ 本課すと対角との交わりになる。この部分は各点を同じ二点の組に送る写像で $X\cap Y$ と同型であり、:ref[prop-ag-codimension-bound] の下界を適用できる。
:::

:::example[下界が達成されない交わり]
$\mathbb A^3$ で $X=V(z)$ と $Y=V(yz)$ を比較する。$Y$ は可約なので成分を分けると、第一成分 $V(y)$ と $X$ の交わりは直線、第二成分 $V(z)$ との交わりは平面そのものである。どちらの対でも次元の下界は $2+2-3=1$ であり、同じ超平面が現れる後者では不等号が厳しい。交わりの方程式が独立だと見なす前に、片方の条件がもう片方に含まれているかを調べる必要がある。
:::

:::example[次元の下界が正でもアフィンでは空になる]
$\mathbb A^3$ の超平面 $x=0$ と $x=1$ を取る。次元の和からの下界は $1$ だが、アフィンでは差が $1$ なので共通零点はない。射影閉包の式 $X=0,X=W$ は $X=W=0$ という無限遠の射影直線で交わる。従って射影での非空性の主張と、アフィンで空でない場合だけの下界には違いがある。
:::

### 一般の超平面で次元を一つずつ下げる

:::proposition[超平面を順に選ぶ]
空でない射影閉集合 $X\subset\mathbb P^n$ の次元を $d$ とする。$k$ は代数閉体とする。超平面を $d+1$ 個順に選んで全てとの交わりを空にできる。また $X$ と交わらない線形部分空間で余次元 $d+1$ のものを選べる。ただし $d=n$ の場合は空の線形部分空間を許す。
:::

:::proof
閉集合の各成分に点を一つ選ぶ。その点全てを避ける一次式は存在する。実際、各点で消える一次式の集合は一次式の空間の真の線形部分空間で、その有限和集合で全空間を覆うことは無限体上ではできない。各成分に対し、この超平面が成分を含まないので交わりは真の閉部分であり次元が少なくとも一つ下がる。$d$ 回繰り返せば零次元以下で、残った有限点を次の超平面で避ければよい。各段で、既に選んだ一次式の張る真部分空間も禁止条件に加える。$d\le n$ なので $d+1$ 個を独立に選べる。共通零点は余次元 $d+1$ の線形部分空間になる。
:::

:::example[二次曲面と交わらない線形部分空間の範囲]
$\mathbb P^3$ の二次曲面 $X_0X_3-X_1X_2=0$ は次元二である。任意の射影直線はこの曲面と交わる。実際、その直線上で式を二変数二次式とみなすと、式が恒等的に零なら直線全体、そうでなければ少なくとも一つの射影点が零となる。これに対し $[1:0:0:1]$ では式が $1$ なので、余次元三の線形部分空間で曲面と交わらないものが得られる。余次元二では不可能、余次元三では可能という違いは、射影次元不等式の境目に一致する。
:::

## 射のファイバーの次元

:::definition[ファイバー]{#def-ag-classical-fiber}
射 $f:X\to Y$ と点 $y\in Y$ に対し、方程式 $f(x)=y$ で定まる閉集合 $f^{-1}(y)$ を :term[ファイバー]{en="fiber" yomi="ふぁいばー"} と呼ぶ。
:::

:::theorem[一般ファイバーの次元]{#thm-ag-generic-fiber-dim}
既約多様体間の支配的な射 $f:X\to Y$ に対し、ある非空開集合 $V\subset Y$ 上で、各ファイバーは非空で次元 $\dim X-\dim Y$ をもつ。
:::
:::proof
$Y$ の非空アフィン開に制限し、その逆像を有限個の非空アフィン開 $U_i$ で覆う。各 $U_i$ 上で $B=k[Y]\hookrightarrow A_i=k[U_i]$ は単射である。実際 $U_i$ は稠密で、像の閉包が真の閉集合ならその逆像が $U_i$ を含み、従って $X$ を含む。$K=\operatorname{Frac}B$ 上で $K\otimes_B A_i$ に :ref[thm-comm-noether-normalization]{text="Noether 正規化"} を適用する。$d=\operatorname{trdeg}_K\operatorname{Frac}A_i=\dim X-\dim Y$ 個の代数的独立な元 $t_j$ により、この代数は $K[t_1,\dots,t_d]$ 上有限になる。各 $t_j$ の分母と各 $A_i$ の生成元の整方程式の分母を一つの非零元 $b_i$ で払うと、$(A_i)_{b_i}$ は $B_{b_i}[t_1,\dots,t_d]$ 上有限整となる。単射性は $K$ 上で判定できる。

$V=D(\prod b_i)$ において、この有限整拡大を点 $y$ の剰余体に移す。lying over により元の有限写像は全射であり、その $y$ 上への制限も全射である。従ってファイバーはアフィン $d$ 空間へ有限全射であり、整拡大の going up と incomparability によって次元が $d$ になる。ファイバーの全体はこれらのアフィン開で覆われるので次元は $d$ である。
:::

:::example[特殊ファイバーでの次元の増加]
$(x,y)\mapsto(x,xy)$ について $x\ne0$ の標的点 $(a,b)$ では唯一の原像 $(a,b/a)$ をもつ。$(0,0)$ のファイバーは直線であり、$(0,b)$ で $b\ne0$ のファイバーは空である。この例の一般次元は $2-2=0$ である。
:::

:::corollary[全ファイバーの各成分の下界]{#cor-ag-fiber-component-dim}
既約多様体の射 $X\to Y$ について、空でないファイバーのすべての既約成分は次元 $\dim X-\dim Y$ 以上である。射が支配的なら、:ref[thm-ag-generic-fiber-dim] の開集合上のファイバーは純次元 $\dim X-\dim Y$ である。
:::
:::proof
点 $y$ のアフィン近傍 $V$ を Noether 正規化により有限射 $V\to\mathbb A^e$ に移す。$e=\dim Y$ である。$y$ の像の逆像は有限集合であり、そこから $y$ 以外を除いて近傍を小さくする。この近傍では $y$ は集合として $e$ 本の正則関数で切り出される。実際、$\mathbb A^e$ で像の各座標を固定する $e$ 式を引き戻せばよい。始域にもこれらを引き戻すと $y$ のファイバーを切り出す。同じ次元をもつ始域のアフィン開上で :ref[prop-ag-codimension-bound] を適用すると、ファイバーの各成分に下界が得られる。一般開ではファイバーの次元そのものが下界に等しいので、全成分の次元が一致する。
:::

:::example[純次元が壊れる特殊ファイバー]
$(x,y,z)\mapsto(xy,xz)$ を考える。標的 $(a,b)$ が原点以外なら $x\ne0$ であり、原像は $x\in k^\times$ と $y=a/x,z=b/x$ で表される一次元の集合である。原点上では $x=0$ の平面と $y=z=0$ の直線の和になる。どちらの成分も下界 $3-2=1$ を満たす一方、純次元ではない。
:::

### ファイバーごとに環を求める

:::example[ファイバーの点数と次元]
標数零の写像 $\mathbb A^1\to\mathbb A^1$、$x\mapsto x^3$ を考える。$a\ne0$ では $x^3-a$ の根が三つあり、$a=0$ では一つである。どちらも次元は $0$ である。方程式の商で見ると $a=0$ でも $1,x,x^2$ が基底なので長さは $3$ である。このように次元が一定でも点の個数は変わり得る。
:::

:::example[値域と閉包の違い]
$(x,y)\mapsto(x,xy)$ のファイバーを $(a,b)$ で求める。$a\ne0$ なら $(a,b/a)$ の一点、$a=b=0$ なら直線 $x=0$、$a=0,b\ne0$ なら空である。値域には $D(a)$ が含まれるため写像は支配的だが全射ではない。一般ファイバーの次元 $2-2=0$ は空のファイバーを除いた開集合上で達成される。
:::

### 射の像を局所閉集合に分ける

一般ファイバーの定理は、像の閉包の中に像の開部分があることも保証する。残りの点へ同じ方法を適用すると、全体の像を有限個の局所閉集合で表せる。ここでは :term[構成可能集合]{en="constructible set" yomi="こうせいかのうしゅうごう"} を、有限個の局所閉集合の和とする。

:::theorem[古典的多様体に対する Chevalley の定理]{#thm-ag-chevalley-classical}
準射影多様体の射 $f:X\to Y$ は、構成可能集合を構成可能集合に送る。また既約多様体の射の像は、その閉包の非空開集合を含む。
:::

:::proof
既約な $X$ について $Z=\overline{f(X)}$ とすれば、$Z$ は既約で $f$ は $Z$ への支配的な射として扱える。一般ファイバーの定理で $Z$ の非空開 $V$ 上の全ファイバーが空でないようにできる。従って $V\subset f(X)$ である。

閉集合 $C\subset X$ の像が構成可能であることを、$C$ に関する Noether 帰納法で示す。空集合は構成可能である。$C$ が可約なら、有限個の真の既約成分の像の和なので帰納法で従う。$C$ が既約なら、前段を $C$ に適用して $\overline{f(C)}$ 内の非空開 $V\subset f(C)$ を取る。$C'=C\cap f^{-1}(\overline{f(C)}\setminus V)$ は $C$ の真の閉集合である。その像は帰納法で構成可能であり、$f(C)=V\cup f(C')$ となる。$V$ は $Y$ の局所閉部分なので結論を得る。任意の局所閉部分集合 $U\subset X$ に $f$ を制限すると、$U$ は準射影であり同じ議論が使える。構成可能集合はそのような有限和なので、像も構成可能である。
:::

:::example[積の射に見える二つの局所閉部分]
$(x,y,z)\mapsto(x,xy,xz)$ の像は $D(a)\cup\{(0,0,0)\}$ である。実際、$a\ne0$ なら $(a,b,c)$ を $(a,b/a,c/a)$ から得る。一方 $a=0$ では第二、第三座標も零になる。像に含まれる非空開は $D(a)$ であり、残りは真の閉部分 $a=0$ に制限すれば一点になる。従って定理の帰納の各段をこの例では直接計算できる。
:::

:::example[消去だけでは像の補集合は決まらない]
射 $V(xy-1)\to\mathbb A^1$ の像は $D(x)$ である。他方 $V(z-x^2)\to\mathbb A^1$、$(x,z)\mapsto x$ の像は全体である。いずれの場合も $k[x]$ から座標環への引き戻しは単射なので、消去で得る閉包のイデアルは零で同じである。像の構成可能な表示を求めるには、一般の開だけでなく、そこから除いた値におけるファイバーも調べる必要がある。
:::

### ファイバー次元の上半連続性を射影で証明する

特殊ファイバーが大きくなる様子は、行列の階数が落ちると核が大きくなる場合に似ている。射影射では、ある次元以下であることを「固定した線形空間でファイバーを避けられる」と言い換えられる。この判定には前節の超平面の選択が使える。

:::proposition[射影射のファイバー次元の上半連続性]{#prop-ag-projective-fiber-upper-semicontinuity}
$X$ を $\mathbb P^n\times Y$ の閉部分とし、$f:X\to Y$ を射影とする。任意の整数 $r$ について $\{y:\dim f^{-1}(y)\le r\}$ は開である。ただし空集合の次元を $-1$ とする。
:::

:::proof
$r<-1$ では空、$r\ge n$ では全体である。$r=-1$ では像の補集合となり、射影の閉性で開である。$0\le r<n$ とし、点 $y_0$ のファイバーが次元 $r$ 以下とする。前節の命題によって、ファイバーを避ける余次元 $r+1$ の線形部分空間 $L\subset\mathbb P^n$ を選べる。空のファイバーなら任意の $L$ でよい。ファイバーの次元が $r$ より小さい場合も、避けるより大きな線形部分空間の中に所定の $L$ を取ればよい。閉集合 $X\cap(L\times Y)$ の射影像は閉じており $y_0$ を含まない。従ってその補集合で $L$ はファイバーを避ける。

もしこの補集合であるファイバーに次元 $r+1$ 以上の成分 $Z$ があれば、$L$ の次元は $n-r-1$ なので二者の次元和が $n$ 以上になる。:ref[thm-ag-projective-intersection-dim] が交わりの存在を与え、$L$ を避けることに矛盾する。よって $y_0$ の周りで次元が $r$ 以下のままであり、該当する集合は開である。
:::

:::example[線形部分空間の繰り返しで飛びを求める]
$\mathbb P^2_{[X:Y:Z]}\times\mathbb A^1_t$ の $tX=tY=0$ を考える。$t\ne0$ では一点 $[0:0:1]$、$t=0$ では平面全体がファイバーになる。点のファイバーを避ける直線として $Z=0$ を取ると、$X\cap(V(Z)\times\mathbb A^1)$ の射影像は $t=0$ である。従って定理で使う開はこの場合に正確に $D(t)$ になる。$r=1$ に対しても $[1:0:0]$ を避ける条件から同じ開が得られる。一方 $r=2$ では全ファイバーが条件を満たす。
:::

:::example[アフィン射には同じ判定を適用できない]
$\{(x,t):xt=1\}\to\mathbb A^1_t$ は $t\ne0$ で一点、$t=0$ で空のファイバーをもつ。従って次元が $-1$ 以下の値の集合は $\{0\}$ で開でない。射影閉包を $\mathbb P^1_{[X:Z]}\times\mathbb A^1$ に取ると $tX=Z$ となり、$t=0$ にも $[1:0]$ の一点が入る。新しいファイバー射では全点で次元が零となり、先の判定と矛盾しない。ファイバーが空になる点の集合の開性に既に閉射影の仮定が効いている。
:::

:::example[全射でも標的上のファイバー次元は上半連続とは限らない]
$\mathbb A^3_{s,t,u}$ の閉集合 $V(st-1)\cup\{(0,0,0)\}$ を $s$ へ射影する。$s\ne0$ では $t=s^{-1}$ が決まり $u$ が自由なのでファイバーは直線である。$s=0$ では第二成分の一点だけが残る。従って射は全射だが、$s=0$ のファイバーだけが零次元になる。よって $\{s:\dim X_s\le0\}=\{0\}$ は開でない。

:::

### ファイバーの式が線形なら階数を直接読む

:::example[二変数の係数で像とファイバーを同時に区別する]
$\mathbb A^3_{s,t,u}\to\mathbb A^3_{a,b,c}$ を $(s,t,u)\mapsto(s,st,su)$ とする。$s\ne0$ の上では $t=b/a,u=c/a$ が一意であり、$a=0$ では $(b,c)=(0,0)$ を要求する。その場合のファイバーは $(t,u)$ が自由で二次元である。像は $D(a)\cup\{0\}$ で、ファイバー次元が一になる点はない。値域の次元から次元差を求めると一般次元は零だが、それだけでは特殊ファイバーが一段ずつ次元を増やすと結論できない。係数の二つが同じ $s$ で同時に零となるため、二自由度が同時に現れる。
:::

## Zariski 接空間

曲線の接線を一次近似とみなすなら、一次の無限小だけを残す環が適している。$k[\epsilon]/(\epsilon^2)$ に値を取る座標 $p+\epsilon v$ を方程式へ代入すると、二次以上の誤差が全て消える。

:::definition[Zariski 接空間]{#def-ag-zariski-tangent}
点 $p$ の :term[Zariski 接空間]{en="Zariski tangent space" yomi="ざりすきせっくうかん"} を $T_pX=\Hom_k(\mathfrak m_p/\mathfrak m_p^2,k)$ と定める。ここで $\mathfrak m_p$ は局所環の極大イデアルである。
:::

:::proposition[一次近似による記述]{#prop-ag-tangent-jacobian}
$X\subset\mathbb A^n$ の消滅イデアルを $f_1,\dots,f_r$ が生成するとき
$$
T_pX=\{v\in k^n:\ \sum_j \partial_j f_i(p)v_j=0\ \text{for all }i\}.
$$
:::
:::proof
$A=k[X]$ から双対数環への $k$ 準同型で剰余が $p$ の評価であるものは、$a\mapsto a(p)+\epsilon D(a)$ と書ける。積を比較すると $D(ab)=a(p)D(b)+b(p)D(a)$ となる。これは $D$ が定数と $\mathfrak m_p^2$ を殺し、$\mathfrak m_p/\mathfrak m_p^2$ 上の線形形式を与える条件である。逆に任意の線形形式を $a-a(p)$ に適用するとこの積法則が得られる。$p$ で非零の元は双対数環で可逆なので、この議論は局所化後も変わらない。一方、座標の像を $p_j+\epsilon v_j$ とおくと、多項式の二項展開で $f_i$ の像は $\epsilon\sum_j\partial_j f_i(p)v_j$ である。これらが零であれば生成イデアル全体が零に移る。
:::

:::example[接線と交叉する二枝]
$k$ の標数が $2$ でないとき $V(y^2-x^2)$ の原点で一次項はすべて零なので、接空間は $k^2$ である。各枝だけを取れば接線は $y=x$ と $y=-x$ である。二枝の和そのものは線形空間でないため、接空間はそれらを含む平面になる。
:::

:::example[交わる多様体の接空間]
原点における $V(xy)$ と $V(z-x-y)$ の交わりを考える。この例で二式が消滅イデアルを生成することは、$z$ を消去した商 $k[x,y]/(xy)$ が被約であることから分かる。第一式の一次項は零、第二式の一次項は $z-x-y$ である。両式の商で一次の無限小を代入すると、許される方向は $v_z-v_x-v_y=0$ となる。これは二つの接空間の交わりである。一方、交わりそのものは $z=y$ 上の $x=0$ の枝と、$z=x$ 上の $y=0$ の枝であり、次元は一である。接方向の線形条件だけから成分の個数は分からない。
:::

### 接写像と定義式の一次部分

:::proposition[接写像の合成]
射 $f:X\to Y$ と点 $p$ に対し、局所環の引き戻しが $\mathfrak m_{f(p)}/\mathfrak m_{f(p)}^2\to\mathfrak m_p/\mathfrak m_p^2$ を誘導する。その双対 $df_p:T_pX\to T_{f(p)}Y$ は合成と両立する。
:::

:::proof
局所環の引き戻しは点で消える関数を点で消える関数へ送り、積を保つためその平方イデアルも保つ。従って商上で線形写像が定まる。引き戻しは合成の順を反転し、双対で再度反転するので $d(gf)_p=dg_{f(p)}df_p$ となる。双対数への代入では $v$ を各座標の一次偏微分で作用させる写像として同じ式が得られる。
:::

:::example[原点で消える微分]
$t\mapsto(t^2,t^3)$ の接写像を $t=0$ で考える。$t=\epsilon a$ とすると両座標は零になるので接写像は零である。一方、標的の尖点では $y^2-x^3$ の一次項が零で接空間は二次元である。$t=1$ では微分は $(2a,3a)$ であり、標数零で標的の微分条件 $-3v_x+2v_y=0$ の全ての解を与える。
:::

### 接空間の線形条件と接錐の最低次数

接空間は一次の無限小を全て数える。そのため方程式が二次以上から始まる点では接空間が大きくなる。実際の曲線がどの方向からその点に近づくかを調べるには、一次項に加えて最初に現れる非零の同次項が必要になる。

:::example[双対数への写像と接錐の方向を比べる]
$X=V(y^2-x^3)$ で原点を考える。双対数に $x=\epsilon a,y=\epsilon b$ を代入すると $y^2-x^3=0$ は任意の $(a,b)$ で成り立つので、接空間は二次元である。ところが $\epsilon^3=0$ の三重の無限小に $x=\epsilon a+\epsilon^2c,\ y=\epsilon b+\epsilon^2d$ を代入すると、式は $\epsilon^2 b^2$ になる。そこで延長できるためには $b=0$ が必要である。実際 $b=0$ ならこの次数まではどの $c,d$ でも式を満たす。一次だけでは全方向に進めるが、二次まで見ると最低次同次項 $y^2$ が条件を課す。
:::

:::example[滑らかな点でも二次の補正が必要になる]
原点で $Y:y-x^2=0$ を考える。双対数への代入は $y$ の一次成分を零に固定するので接方向は $(a,0)$ である。この方向を $\epsilon^3=0$ まで持ち上げるため $x=a\epsilon+b\epsilon^2$ とすると、$y=a^2\epsilon^2$ が必要である。例えば $a=2$ なら $y=4\epsilon^2$ である。一次の接線 $y=0$ に沿ったそのままの写像は、$a\ne0$ では二次まで持ち上がらない。曲線の接方向を保ったまま $y$ に二次補正を加えることができる点が、前例の一部の接方向がそもそも延びない現象と異なる。
:::

:::proposition[直積の接空間]
アフィン代数的集合 $X,Y$ の閉点 $p,q$ について、$T_{(p,q)}(X\times Y)\simeq T_pX\oplus T_qY$ である。
:::

:::proof
直積の座標環は $k[X]\otimes_k k[Y]$ である。双対数への $k$ 準同型は、その二つの因子への制限で一意に定まる。逆に二写像があれば、値が可換なのでテンソル積の元 $a\otimes b$ を二つの像の積へ送れる。剰余の点が $(p,q)$ である条件は各因子で剰余が $p,q$ である条件に等しい。一次成分に対する加法とスカラー倍は因子ごとに行うため、これは接空間の線形同型である。座標での同じ説明は、直積の方程式で変数が二組に分かれるため Jacobian が二つの対角ブロックに分かれることである。
:::

:::example[平滑な因子を加えると接空間と局所次元が同じだけ増える]
尖点曲線にアフィン直線を掛けると原点の接空間の次元は $2+1=3$、局所次元は $1+1=2$ である。方程式 $y^2-x^3=0$ は第三座標 $z$ を含まないので、原点の上の各 $z$ で同じ差が出る。一方 $x\ne0$ で勾配が零でなければ接空間は曲線に沿う一方向と $z$ の一方向をもつ。このように直積の平滑な因子で次元を増やしても、特異点での余分な接方向は消えない。
:::

## 非特異点と Jacobian 判定法

:::definition[非特異点]{#def-ag-nonsingular-point}
閉点 $p$ において $\dim_k T_pX=\dim\mathcal O_{X,p}$ となるとき、$p$ を :term[非特異点]{en="nonsingular point" yomi="ひとくいてん"} という。
:::

:::corollary[Jacobian 判定法]{#cor-ag-jacobian}
$d$ 次元の既約アフィン多様体 $X\subset\mathbb A^n$ で、消滅イデアルの生成元による Jacobian 行列 $(\partial_j f_i(p))$ の階数が $n-d$ であることと、$p$ が非特異であることは同値である。特異点集合は閉じている。
:::
:::proof
:ref[prop-ag-tangent-jacobian] の核の次元は $n-\rank(\partial_jf_i(p))$ である。:ref[thm-ag-dimension-transcendence] は局所環の次元を $d$ とする。局所環の次元が極大イデアルの生成元数以下になることは Krull の高さ定理で分かる。従って階数はどこでも $n-d$ 以下であり、非特異集合はある $(n-d)$ 次の小行列式が非零となる開集合の和である。
:::

:::theorem[非特異な点は稠密開集合をなす]{#thm-ag-nonsingular-dense}
代数閉体上の既約多様体は、空でない非特異点の開集合をもつ。この開集合は稠密である。
:::

:::proof
まず $X\subset\mathbb A^n$ を次元 $d$ の既約アフィン多様体、$A$ をその座標環、$K$ を分数体とする。:ref[thm-comm-differential-sequences]{text="微分の基本完全列"} により、$\Omega_{K/k}$ は $K^n$ を定義式の Jacobian の行で割ったものである。従って $\dim_K\Omega_{K/k}=d$ を示せば、階数 $n-d$ の小行列式が $A$ で非零となる。そこで :ref[cor-ag-jacobian] を適用できる非空開が得られる。

標数零では、超越基底 $t_1,\ldots,t_d$ を取ると $K$ は $E=k(t_1,\ldots,t_d)$ 上の有限分離拡大である。$E$ の $k$ 導分を $K$ に延ばすとき、代数元 $u$ の微分はその最小多項式 $G$ の係数の微分と $G'(u)\ne0$ によって一意に決まる。逆にこの値を入れれば関係 $G(u)=0$ の微分が零となるため、導分は商と分母の反転へ延びる。生成元を順に加えれば $dt_i$ は $K$ 上の基底になる。

標数 $p>0$ では、$k$ が完全なので $k\subset K^p$ である。任意の $k$ 導分は $p$ 乗を殺すから、$\Omega_{K/k}=\Omega_{K/K^p}$ である。同じ $E$ について $[E:E^p]=p^d$ である。各 $t_i$ の指数を $p$ 未満にした単項式が基底をなすことは、一変数ずつ分子の指数を $p$ で分け、分母はその $p$ 乗に直して示せる。また Frobenius の体同型により $[K^p:E^p]=[K:E]$ である。$E^p\subset E\subset K$ と $E^p\subset K^p\subset K$ を比べて $[K:K^p]=p^d$ を得る。従って :ref[prop-comm-field-differentials] の微分次元の公式で $\dim_K\Omega_{K/K^p}=d$ である。

一般の既約多様体ではアフィン開上にこの結果を適用する。非特異性は局所環で判定するのでアフィン開ごとの非特異集合が全体の開集合になり、非空開なので既約性により稠密である。
:::

:::example[尖点と滑らかな二次曲線]
標数零で $f=y^2-x^3$ の勾配は $(-3x^2,2y)$ なので、原点だけが特異である。$f=y-x^2$ なら $\partial_y f=1$ なので、全点が非特異である。非根基の方程式 $(y-x^2)^2$ を使うと全点で勾配が零になるため、古典的な点集合の判定には消滅イデアルを使う必要がある。
:::

### 行列式の微分と特異集合

:::example[階数で変わる特異性]
三次正方行列の $\det M=0$ を考える。成分 $m_{ij}$ による偏微分は余因子である。行列の積によるパラメータ表示から零点集合は既約で、従って行列式は一つの既約因子の冪の定数倍である。$\operatorname{diag}(1,1,0)$ で $m_{33}$ による偏微分が $1$ になるため、その冪は一である。よって行列式は消滅イデアルを生成する。階数 $2$ の点では少なくとも一つの二次小行列式が非零なので勾配が非零になり、局所次元 $8$ と接空間の次元が一致する。階数が $1$ 以下なら全ての余因子が零で接空間は九次元である。例えば $\operatorname{diag}(1,1,0)$ では接空間は $v_{33}=0$、$\operatorname{diag}(1,0,0)$ では全方向を許す。
:::

:::example[係数体で変わる Jacobian 判定]
$y^2=x^3+x$ を考える。標数零では勾配が零なら $y=0$、$x^2=-1/3$ だが、この $x$ は曲線式 $x(x^2+1)=0$ を満たさない。標数 $2$ では $\partial_y f=0$、$\partial_x f=x^2+1$ となり、$x=1,y=0$ が特異点である。平行移動 $x=1+u$ では $f=y^2+u^2+u^3=(y+u)^2+u^3$ になるため、その点に一次項がないことを直接確認できる。
:::

### 行列式多様体の平滑な部分を階数で取り出す

階数が正確に上限である点では、可逆な小行列を使って他の成分を消せる。階数が小さい点で同じ操作をすると、低階数の行列を原点で調べる問題が残る。

:::proposition[行列の階数条件の特異集合]{#prop-ag-rank-locus-singular}
$1\le r<\min(m,n)$ とする。$m\times n$ 行列の階数が $r$ 以下の被約多様体 $X_r$ の特異点集合は $X_{r-1}$ である。
:::

:::proof
点 $M$ の階数を $s$ とする。$s>0$ なら行と列を並べ替えて、左上 $s\times s$ ブロック $A$ が可逆な開を取る。$M=\begin{pmatrix}A&B\\C&D\end{pmatrix}$ に対し $D'=D-CA^{-1}B$ を新変数とする。これは開の座標変換で、逆は $D=D'+CA^{-1}B$ である。左右から可逆なブロック行列を掛けると $\operatorname{diag}(A,D')$ になるので階数条件は $\rank D'\le r-s$ である。その点では $D'=0$ である。従って近傍は自由な $A,B,C$ の開と、$(m-s)\times(n-s)$ 行列の階数 $r-s$ 以下の集合との積である。$s=0$ なら自由な成分はなく、もとの原点の計算そのものである。

$s=r$ では残る $D'$ が零という条件なので局所座標は開アフィン空間になり非特異である。$s<r$ のとき、残る行列の階数が一の座標軸は全てこの集合に属する。従って消滅イデアルの任意の式の一次項は各軸で消え、全成分について係数が零になる。よって原点での接空間は周囲の行列空間全体である。積の接空間を取ると $M$ での接空間の次元は $mn$ になる。ところが多様体の次元は $r(m+n-r)=mn-(m-r)(n-r)<mn$ なので特異点である。ここでは小行列式の生成するイデアルが素かどうかを仮定せず、消滅イデアルの一次部分を軸の包含から求めた。
:::

:::example[三行四列の階数二の点]
$m=3,n=4,r=2$ とすると次元は $2(3+4-2)=10$ である。$M=\begin{pmatrix}1&0&0&0\\0&2&0&0\\0&0&0&0\end{pmatrix}$ を標数零で取る。左上の二次小行列式が非零なので、自由な $A$ の四成分、$B$ の四成分、$C$ の二成分を持ち、$D$ の二成分が決まる。点では $B,C$ が零なので $CA^{-1}B$ の一次微分は零であり、接空間の二条件は下右二成分が零という式である。階数一の点へ変えると、残る行列の階数一以下の錐の頂点で全一次条件が消え、接空間が十二次元になる。
:::

### Jacobian の行を取り替えても接空間は同じになる

:::example[冗長な生成元が階数を変えない理由]
$p$ で全て消える $f,g$ と任意の係数多項式 $a,b$ を取る。$af+bg$ の微分を $p$ で評価すると、$f(p)=g(p)=0$ のため $a(p)\,df_p+b(p)\,dg_p$ だけが残る。例えば $f=y-x^2$ を $f,(1+x)f,yf$ に増やしても、$p=(1,1)$ では行は $(-2,1),(-4,2),(-2,1)$ となり、張る空間は同じである。従って生成元を追加したこと自体で階数は増えない。逆に $f$ を $f^2$ だけに置き換えると、同じ零点集合を定めても消滅イデアルを生成しないため一次条件が変わる。
:::

## 非特異性と正則局所環

Noether 局所環 $(A,\mathfrak m)$ は、$\mathfrak m$ の最小生成元数が $\dim A$ に等しいとき :term[正則局所環]{en="regular local ring" yomi="せいそくきょくしょかん"} という。Nakayama の補題により、剰余体上の $\mathfrak m/\mathfrak m^2$ の基底を持ち上げた元が $\mathfrak m$ を生成する。また任意の生成集合の像はこの商を張る。よって最小生成元数は $\dim_k\mathfrak m/\mathfrak m^2$ であり、非特異性と正則局所環の条件は同値である。

:::example[同じ関数体と異なる埋め込み次元]
$k[t]_{(t)}$ では極大イデアルが $t$ 一元で生成される。$k[t^2,t^3]_{(t^2,t^3)}$ の極大イデアルでは $t^2,t^3$ の像が二つとも商 $\mathfrak m/\mathfrak m^2$ に残る。実際 $\mathfrak m^2$ の元の $t$ での位数は $4$ 以上であり、二元の非零な $k$ 線形結合の位数は $2$ または $3$ である。どちらの局所環も次元 $1$ で、正則性は異なる。正則局所環のより一般の構造は :ref[thm-comm-serre-regular]{text="正則局所環の構造定理"}で扱う。
:::

:::proposition[非特異点の近傍を余次元本の式で切り出す]{#prop-ag-local-equations-nonsingular}
$X\subset\mathbb A^n$ を次元 $d$ の既約多様体とし、$p$ を非特異点とする。$I(X)$ の生成元から $n-d$ 本を選んで、$p$ のある基本開近傍における消滅イデアルを生成できる。その各式の一次部分は $p$ で一次独立である。
:::

:::proof
Jacobian の階数が $n-d$ なので、その個数の独立な行を選び、それに対応する式を $g_1,\ldots,g_{n-d}$ とする。周囲の多項式局所環 $R$ の余接空間でこれらの類は独立である。従って正則パラメータ系の一部をなし、$R/(g_1,\ldots,g_{n-d})$ は $d$ 次元の正則局所整域である。この商の性質は [正則局所環の一次独立な元による商](/math/commutative-algebra/regular-local-rings/) を参照。この整域から $R/I(X)R$ への商写像の核が非零なら、商の任意の素イデアルの鎖の先頭へ零素イデアルを加えられるため、商の次元は高々 $d-1$ になる。しかし $p$ での局所次元は $d$ である。よって二つのイデアルは局所環で一致する。各生成元の等式で分母を払い、その有限個の積を $h$ とすれば $h(p)\ne0$ である。$D(h)$ へ制限すると全ての等式が成立し、主張を得る。
:::

### 正則パラメータと随伴次数付き環

:::example[超曲面の滑らかな点のパラメータ]
$xy-z^2=0$ の $p=(1,0,0)$ では $x$ は単元となるため $y=z^2/x$ と消去できる。局所環は $k[x,z]_{(x-1,z)}$ であり、$x-1,z$ が正則パラメータである。原点では $xy-z^2$ は次数二なので $\mathfrak m/\mathfrak m^2$ に $x,y,z$ が独立に残る。随伴次数付き環でも同じ二次関係が残る。実際、もとの関係が斉次であるため、次数 $r$ の項を $\mathfrak m^{r+1}$ で割ったものは斉次商の次数 $r$ と同じである。二点の局所次元は $2$ で共通だが生成元の数で区別できる。
:::

:::example[平面曲線の正則局所環における消滅次数]
$y-x^3=0$ の原点では、$x$ が極大イデアルの生成元である。曲線上で $y=x^3$ なので $y$ は第三冪に入り第四冪には入らない。一方 $y+x^2=x^2(1+x)$ は $1+x$ が単元なので消滅次数が $2$ である。周囲の平面の一次式である $y$ も、曲線に制限すると次数が変わる。この局所環での次数が交点重複度の計算に使われる。
:::

### 完備局所環でパラメータを次数順に使う

局所環の元を点の近くで展開すると、最初の係数は剰余体、その次の係数は $\mathfrak m/\mathfrak m^2$ に属する。正則局所環では、その後の係数も最初に選んだパラメータの単項式で表せる。

:::proposition[正則な閉点の形式座標]{#prop-ag-completed-regular-point}
$k$ 上の多様体の $k$ 有理な非特異閉点 $p$ の局所環を $A$、その次元を $d$ とする。$t_1,\dots,t_d$ が $\mathfrak m/\mathfrak m^2$ の基底を持ち上げた元なら、$T_i\mapsto t_i$ によって $k[[T_1,\dots,T_d]]\simeq\widehat A$ となる。
:::

:::proof
正則局所環の随伴次数付き環が $\mathfrak m/\mathfrak m^2$ の対称代数であることは :ref[prop-comm-regular-graded]{text="随伴次数付き環による正則性の判定"} による。従って各 $r$ で、次数 $r$ の $t_i$ の単項式が $\mathfrak m^r/\mathfrak m^{r+1}$ の基底となる。係数体 $k$ は $A$ の定数を通じて入り、閉点の剰余写像で恒等になる。任意の完備化の元について、まず定数項を合わせ、差の次数一の成分を合わせ、以下順に残りの成分を合わせられる。この各段で同次係数が一意に選ばれ、得た冪級数が全ての剰余環で元に一致する。従って写像は全射である。一方非零な冪級数には最初の非零同次成分があり、その像は該当する随伴次数で非零である。従って単射である。元の写像は各有限段で多項式の代入から来るので、積との両立も極限を取れば従う。
:::

:::example[滑らかな曲線上で局所座標を展開する]
標数零で $y^2=1+x$ の点 $(0,1)$ を考える。$v=y-1$ とすると $2v+v^2=x$ である。$v=a_1x+a_2x^2+a_3x^3+\cdots$ と置くと、次数ごとに $2a_1=1$、$2a_2+a_1^2=0$、$2a_3+2a_1a_2=0$ となる。従って
$$
y=1+\tfrac12x-\tfrac18x^2+\tfrac1{16}x^3+\cdots
$$
である。各段で新係数に掛かる $2$ は $p$ における $\partial(y^2-1-x)/\partial y$ に等しい。$x$ がパラメータであることは局所環でも $x=(y-1)(y+1)$ で $y+1$ が単元であることから確認できる。冪級数による表示は完備化での等式であり、有限個の多項式による表示を述べているわけではない。
:::

:::example[特異点で次数二の関係が残る]
$A=k[x,y]_{(x,y)}/(xy)$ では $\mathfrak m/\mathfrak m^2$ の基底は $x,y$ の類である。二次の随伴成分では $x^2,y^2$ が独立で、$xy$ だけが零である。もし $A$ が二次元の正則局所環ならば二次成分は三次元になるはずであり、この関係は存在しない。実際この局所環の Krull 次元は一で、完備化も $k[[x,y]]/(xy)$ である。二枝への制限から見ると、任意の元は定数項を共有する $k[[x]]$ と $k[[y]]$ の対になる。正則点の単一のパラメータ表示ではこの二枝を同時には表せない。
:::

## ブローアップと特異点の解消の例

平面の原点には方向を区別する座標がない。原点の上に方向 $[u:v]$ を置き、原点以外では方向が点の比 $[x:y]$ と一致するようにすると、点を通る枝を別々に調べられる。

:::definition[原点のブローアップと固有変換]{#def-ag-plane-blowup}
$\{((x,y),[u:v]):xv=yu\}\subset\mathbb A^2\times\mathbb P^1$ の平面への射を、原点の :term[ブローアップ]{en="blow-up" yomi="ぶろーあっぷ"} と呼ぶ。曲線の原点以外の部分の逆像の閉包を :term[固有変換]{en="strict transform" yomi="こゆうへんかん"} と呼ぶ。
:::

$u\ne0$ では $v/u=t$ と置いて $y=xt$、$v\ne0$ では $u/v=s$ と置いて $x=ys$ となる。これらはそれぞれアフィン平面であり、重なりでは $s=1/t$、$y=xt$ で貼り合わされる。原点の上の $\mathbb P^1$ は前者で $x=0$、後者で $y=0$ と書ける。原点の外では $[u:v]=[x:y]$ が一意なので射は同型である。

:::example[尖点の解消]
$y^2=x^3$ を $u\ne0$ で引き戻すと $x^2(t^2-x)=0$ になる。$x\ne0$ の部分の閉包は $x=t^2$ である。実際このグラフは既約でその $x\ne0$ 部分が稠密である。他方の近傍では $y^2(1-ys^3)=0$ となり、固有変換は $ys^3=1$ で例外集合 $y=0$ と交わらない。よって固有変換は全体として滑らかであり、原点の上で $t=0$ の一点をもつ。
:::

:::example[異なる接線をもつ二枝]
$y^2-x^2-x^3=0$ の固有変換は第一近傍で $t^2-1-x=0$ となる。標数が $2$ でなければ例外集合上の点は $t=\pm1$ の二点である。原点で重なっていた二方向が異なる点に分かれる。
:::

### 接錐と例外集合の交わり

:::proposition[最低次数と固有変換]
平面曲線の方程式を次数順に $f=f_m+f_{m+1}+\cdots$、$f_m\ne0$、$m\ge1$ と書く。$f$ は被約な平面曲線の消滅イデアルの生成元とする。原点のブローアップで $y=xt$ の近傍における固有変換は $f_m(1,t)+x f_{m+1}(1,t)+\cdots=0$ である。例外直線の上で両方の方程式を課した商環は $k[t]/(f_m(1,t))$ である。
:::

:::proof
代入で $f(x,xt)=x^m G(x,t)$ となり、$G(0,t)=f_m(1,t)$ は非零である。従って $x$ と $G$ は共通因子をもたない。$x^r h\in(G)$ なら一意分解性で $h\in(G)$ なので、$x$ による飽和で $G$ は変わらない。これが $x\ne0$ の部分の閉包の方程式である。例外集合は $x=0$ なので、局所商では $G$ を $x=0$ に制限する。もう一方の近傍の計算も $f_m(s,1)$ となり、斉次式 $f_m$ の射影零点に貼り合わさる。
:::

:::example[二回のブローアップが必要な曲線]
$y^2=x^5$ を $y=xt$ に代入すると固有変換は $t^2=x^3$ である。原点の接錐は $y^2$ なので、第一の例外直線と交わる点は $t=0$ の一つで、その点はまだ特異である。そこで $t=xu$ とする第二の近傍では $u^2=x$ が固有変換になり、$x$ に関する偏微分が $-1$ なので滑らかである。もう一方の近傍では第一回の式は $1-y^3s^5=0$、第二回の式は $1-t v^3=0$（$x=t v$）となり、どちらも該当する例外直線を避ける。
:::

### 単項曲線の特異点を指数で追跡する

:::example[再び現れる尖点を指数の差で調べる]
標数零で $y^3=x^7$ の原点を取る。第一回で $y=xt$ と置くと $x^3(t^3-x^4)=0$ で、固有変換は $t^3=x^4$ である。この曲線の例外直線上の点は $(x,t)=(0,0)$ だけである。第二回で $t=xu$ と置くと $x^3(u^3-x)=0$ なので、固有変換は $x=u^3$ となって滑らかである。他方の開では第一回の固有変換は $1-y^4s^7=0$（$x=ys$）、第二回は $1-t v^4=0$（$x=tv$）となり、どちらもその回の例外直線と交わらない。従って各回で追うべき特異点が一つであることが全標準開で分かる。最後のパラメータを $u$ とすると $x=u^3,t=u^4,y=u^7$ に戻り、元の単項表示を復元できる。
:::

:::example[接線が異なる二枝の固有変換]
標数が $2$ でないとし、$y^2=x^2+x^4$ を取る。$y=xt$ では固有変換が $t^2-1-x^2=0$ である。例外直線 $x=0$ の上に $t=1,-1$ があり、両点で $2t$ が非零なので固有変換は滑らかである。さらに $t$ は局所的に $x$ で決まり、局所変数は $x$ なので例外直線とそれぞれ横断する。他方の開 $x=ys$ では全変換が $y^2(1-s^2-y^2s^4)=0$ であり、$y=0$ で $s=\pm1$ を得る。二点は $s=1/t$ で先に得た二点と一致するため、他の開が新しい点を追加することはない。
:::

### 二次錐の頂点を一回で解消する

:::example[行列式の二次錐]
$\mathbb A^3$ の $xy=z^2$ を原点でブローアップする。周囲の空間で方向 $[X:Y:Z]$ を加え、$[X:Y:Z]=[x:y:z]$ である点の閉包を取る。$X\ne0$ では $y=xu,z=xv$ と置くと全変換は $x^2(u-v^2)=0$、固有変換は $u=v^2$ である。局所座標は $x,v$ で、例外曲線はその中の $x=0$ である。$Y\ne0$ でも同様に $x=y u',z=y v'$ により $u'=(v')^2$ となる。残る $Z\ne0$ では $x=za,y=zb$ と置き、$ab=1$ を得る。この近傍は $z,a,a^{-1}$ を用いて表されるため滑らかである。

三近傍の例外曲線では $XY=Z^2$ という同次式が成立する。$X$ または $Y$ が非零の二開で覆われ、その座標 $v=Z/X$、$v'=Z/Y$ は重なりで $vv'=1$ である。従って例外曲線は射影直線である。元の曲面では原点のみが特異であり、その外では方向が一意なのでブローアップは同型である。頂点を一点の局所環のまま修正する代わりに、全ての方向の曲線を置き、各方向の近傍で方程式を一つずつ消去したことが解消になっている。
:::

### 単項曲線で解消が停止することを示す

:::proposition[互いに素な指数をもつ曲線の解消]{#prop-ag-monomial-curve-resolution}
互いに素な正整数 $a,b$ に対し、平面曲線 $y^a=x^b$ の原点の上に残る特異点を順にブローアップすると、有限回で固有変換が滑らかになる。必要な近傍の方程式は、指数の組の大きい方から小さい方を引く操作で求まる。
:::

:::proof
$a=1$ なら $y=x^b$、$b=1$ なら $x=y^a$ であり、既に滑らかである。両方が $2$ 以上なら互いに素なので相異なる。式 $y^a-x^b$ が被約な曲線の消滅イデアルを生成することを先に確かめる。$x=w^a,y=w^b$ を代入し、$y^a-x^b$ で割った余りを $\sum_{j=0}^{a-1}h_j(x)y^j$ と書く。代入後の各項の指数は、$a$ を法として互いに異なる $bj$ に属する。従って消えるのは全ての $h_j=0$ の場合だけであり、代入準同型の核は $(y^a-x^b)$ である。像は整域だからこのイデアルは素である。以降の曲線式でも指数の互いに素という条件が保たれるため同じ議論が使える。$a<b$ としてよい。原点での最低次項は $y^a$ であり、全接方向が $y=0$ に集中する。$y=xt$ の近傍では
$$
y^a-x^b=x^a(t^a-x^{b-a})
$$
である。括弧内は $x$ で割れないので固有変換であり、新しい例外直線との交わりには $x=t=0$ の一点だけがある。他の近傍 $x=ys$ では $y^a(1-y^{b-a}s^b)$ になるため、例外直線に面する別の点はない。従って上の一点を調べるには、新しい曲線 $t^a=x^{b-a}$ だけでよい。$b<a$ の段階では $x,y$ の役割を逆にすれば同じである。

各操作で $\gcd(a,b)$ が保存され、和 $a+b$ は正整数のまま真に減る。そのため有限段で等しい二数か一方が $1$ の組に達する。等しい二数なら最大公約数が $1$ なので両方 $1$ であり、いずれの場合も一つの変数を消去できて滑らかになる。各ブローアップは中心の外で同型である。初めの曲線は原点以外で滑らかである。原点以外では両座標が非零であり、標数が $a,b$ の両方を割ることはないので、少なくとも一つの偏微分が非零となる。従って新しく調べた例外点以外に特異点は残らない。
:::

:::example[指数を三段に簡約する]
$y^5=x^8$ では第一回で $t^5=x^3$ となる。新しい最低次数は $x^3$ なので次は $x=tu$ と置き、$t^3(t^2-u^3)=0$ から $t^2=u^3$ を得る。最後に $t=uv$ と置くと $u^2(v^2-u)=0$ となり、固有変換は $u=v^2$ で滑らかである。元の座標に戻ると $t=uv=v^3$、$x=tu=v^5$、$y=xt=v^8$ となる。指数の組は $(5,8)$、$(5,3)$、$(2,3)$、$(2,1)$ と移り、パラメータの冪を追う計算でも同じ結果が得られる。
:::

:::remark[滑らかな固有変換と例外直線との接触]
固有変換が滑らかになっても、例外直線との交わりが横断するとは限らない。例えば最後の近傍の $u=v^2$ は、例外直線 $u=0$ と局所長さ二で交わる。ここでの停止条件は固有変換の非特異性である。全変換を成分が横断する形にするには、例外成分の交点と接触も別に調べる。
:::

## 演習問題

::::exercise{level=basic}
$V(z-x^2-y^2)$ の次元を求めよ。

:::solution
$z$ を消去すると座標環は $k[x,y]$ となる。関数体の独立な変数は $x,y$ なので次元は $2$ である。
:::
::::

::::exercise{level=basic}
$\mathbb A^4$ の座標平面 $V(x_1,x_2)$ と $V(x_3,x_4)$ の交わりの次元を求めよ。

:::solution
四座標がすべて零になり、交わりは原点だけである。座標環は $k$ なので次元は $0$ である。
:::
::::

::::exercise{level=basic}
$y=x^2$ の $(1,1)$ での接空間の式を求めよ。

:::solution
$y-x^2$ の微分を点で評価すると $v_y-2v_x=0$ となる。特に $(1,2)$ がこれを張る。
:::
::::

::::exercise{level=basic}
標数零で $xy=0$ の原点の接空間と局所次元を求めよ。

:::solution
勾配 $(y,x)$ は原点で零なので接空間は二次元である。二本の直線はどちらも原点を通り局所次元は $1$ なので原点は特異である。
:::
::::

::::exercise{level=advanced}
$f(x,y,z)=(x,xy)$ の $(a,b)$ 上のファイバーを求めよ。

:::solution
$a\ne0$ なら $x=a,y=b/a$ で $z$ は任意となり直線である。$(0,0)$ なら $x=0$ だけなので平面である。$a=0,b\ne0$ なら第二式が矛盾するため空である。
:::
::::

::::exercise{level=advanced}
$\operatorname{char}k=0$ とする。$y^2=x^5$ を原点で一回ブローアップしたとき、特異点が残るか。

:::solution
$y=xt$ で引き戻すと $x^2(t^2-x^3)$ となる。固有変換は $t^2=x^3$ であり、点 $(0,0)$ で両偏微分が消える。したがって尖点が残る。他方の開集合では固有変換は $1-y^3s^5=0$ で例外集合を避ける。
:::
::::

::::exercise{level=advanced}
$k[t^3,t^4,t^5]$ の原点での接空間の次元を求めよ。

:::solution
極大イデアルは $t^3,t^4,t^5$ で生成される。二乗の全ての元は位数 $6$ 以上で、三つの非零線形結合の位数は $5$ 以下である。よって商に三次元の基底を与える。
:::
::::

::::exercise{level=advanced}
$\mathbb P^4$ の二つの射影平面が一点で交わる例を与えよ。

:::solution
座標を $X_0,\dots,X_4$ とし、片方を $X_3=X_4=0$、他方を $X_1=X_2=0$ とする。両方を課すと $X_0$ だけが非零にでき、交点は $[1:0:0:0:0]$ となる。
:::
::::

::::exercise{level=advanced}
$3\times4$ 行列の階数二以下の多様体で、標準座標行列 $E_{11}$ における接空間の次元と局所環の次元を求めよ。ここで $E_{11}$ は左上成分だけが $1$ の行列とする。

:::solution
左上成分を $a$、同じ行の残りを行 $B$、同じ列の残りを列 $C$、下右のブロックを $D$ とする。$a\ne0$ では $D'=D-CB/a$ に取り替えると、条件は $2\times3$ 行列 $D'$ の階数が一以下となることである。$E_{11}$ では $B,C,D'$ は零である。$D'$ の各座標軸が階数一以下なので、原点ではどの一次式も消滅イデアルの非零な一次部分にはなれない。従ってこの部分の接空間は六次元である。自由な $a,B,C$ の六方向を足すと、元の接空間は行列空間全体の十二次元になる。

一方、$D'$ の多様体自体の次元は :ref[prop-ag-rank-locus-dimension] で $1(2+3-1)=4$ である。自由な六方向を足した局所次元は $10$ となる。従ってこの点は特異で、接空間と局所次元の差は $2$ である。
:::
::::

## 確認テスト

::::quiz{answer="6" tol="1e-6"}
$4\times3$ 行列の階数 $1$ 以下の集合の次元はいくつか。

:::explanation
:ref[prop-ag-rank-locus-dimension] に $m=4,n=3,r=1$ を入れると $1(4+3-1)=6$ となる。左上成分を非零にした近傍では、第一行と第一列の独立成分から同じ数が得られる。
:::
::::

::::quiz
局所環の次元が $2$、接空間の次元が $3$ の閉点について正しいものを選べ。

- [x] 点は特異である
- [ ] 点は非特異である
- [ ] この二つの次元は常に等しい

:::explanation
最小生成元数は接空間の次元に等しい。従って極大イデアルには $3$ 個の生成元が必要で、次元 $2$ より大きいため点は特異である。
:::
::::

::::quiz{answer="2" tol="1e-6"}
標数零の平面曲線 $y^2=x^3$ の原点で接空間の次元はいくつか。

:::explanation
勾配 $(-3x^2,2y)$ が原点で零なので、二成分とも自由である。
:::
::::

::::quiz
$y^2=x^3$ のブローアップで $y=xt$ の近傍における固有変換を選べ。

- [x] $t^2=x$
- [ ] $x=0$
- [ ] $t^2=x^3$

:::explanation
代入すると $x^2(t^2-x)=0$ になる。$x\ne0$ の逆像は $t^2=x$ 上にあり、その部分はグラフで稠密なので固有変換は $t^2=x$ である。
:::
::::
