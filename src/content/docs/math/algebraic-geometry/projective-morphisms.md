## この章の目標

- 可逆層を生成する切断から射影空間への射を作る。
- 豊富性と基点を切断の非消滅で調べる。
- ブローアップを相対 Proj で構成して普遍性を証明する。
- 例外因子と固有変換を計算する。

## 大域切断による射影空間への射

:::theorem[射影空間への射と生成切断]{#thm-ag-projective-sections}
$S$ スキーム $X$ から $\mathbb P^n_S$ への射は、可逆層 $\mathcal L$ とそれを生成する $n+1$ 個の大域切断 $s_0,\dots,s_n$ の組の同型類と対応する。対応する $\mathcal L$ は $f^*\mathcal O(1)$ である。
:::
:::proof
切断が生成するとは、各点で剰余体に移した切断のうち一つが非零になることである。局所基底で表せば、一つの係数が単元であるという条件だからである。$s_i$ が生成する開 $U_i$ で $s_j/s_i$ を正則関数とし、これを第 $i$ 標準開の座標に使う。重なりでは比の変換式で一致するので射に貼れる。引き戻した $X_i$ と $s_i$ は同じ移行係数をもつため、局所基底の対応 $f^*X_i\mapsto s_i$ は可逆層の同型に貼り合う。逆に射から $\mathcal O(1)$ とその座標切断を引き戻すと生成切断を得る。比による構成と互いに逆である。
:::

例えば $\mathbb P^1$ 上の $s^2,st,t^2$ は $\mathcal O(2)$ を生成し、:ref[prop-ag-veronese-segre-image] の二次埋め込みを与える。二切断 $s^2,t^2$ も同じ可逆層を生成するが、標数零では $t/s$ と $-t/s$ が同じ点に写り、閉埋め込みにならない。層と切断の組の両方が射を決める。

### 大域切断と局所座標比

:::example[係数で変わる生成条件]
$\mathbb P^1$ の $\mathcal O(2)$ の切断 $s^2,t^2$ は全点で同時には消えないので、$[s:t]\mapsto[s^2:t^2]$ を定める。$s\ne0$ の近傍では $u=t/s$ が $u^2$ に移り、$t\ne0$ では $v=s/t$ が $v^2$ に移る。これらは重なりで逆数の関係を保つ。一方 $s^2,st$ は $s=0$ で両方消えるため、同じ束の切断であっても生成系ではない。
:::

:::example[射の引き戻しで次数を得る]
$[s:t]\mapsto[s^3:s^2t:t^3]$ を考える。三式は同時に消えず、第一と第三の切断がそれぞれ $s\ne0,t\ne0$ の局所基底を与える。両者の比は $(t/s)^3$ であるため、引き戻した $\mathcal O(1)$ は $\mathcal O(3)$ である。像の $X_0\ne0$ では $(X_1/X_0,X_2/X_0)=(u,u^3)$ となる。一方 $t\ne0$ の点 $s=0$ の近傍では比が $(v^3,v^2)$ になり、像はそこで尖点をもつ。生成切断があることと閉埋め込みになることは別々に判定する。
:::

### 射影座標を単元イデアルで判定する

:::example[整数環上の射影点の表示]
$R=\Z$ 上で可逆層は自由なので、$\mathbb P^1_\Z(R)$ は $R^2\to R$ の全射に対応する。座標 $(a,b)$ が全射を定める必要十分条件は $(a,b)=R$ であり、これは $\gcd(a,b)=1$ である。例えば $(2,3)$ は $3-2=1$ なので点を定める。$D(2)$ 上では第一座標で割り $3/2$、$D(3)$ 上では第二座標で割り $2/3$ で表示できる。閉点 $2$ では $[0:1]$、閉点 $3$ では $[1:0]$ である。一方 $(2,4)$ は $2$ の上で全座標が消えるため $\Z$ 上の点を与えない。$\Q$ 上の点としてなら $[1:2]$ に等しいが、その全域の表示には共通因子を除く必要がある。
:::

:::example[可逆層が自明でない標準切断]
$X=\mathbb P^1_k$ の恒等射は二座標による $\mathcal O_X^2\to\mathcal O_X(1)$ に対応する。もし同じ射を自明な可逆層の二つの大域切断で表せれば、引き戻した $\mathcal O(1)$ が自明でなければならない。しかし $\operatorname{Pic}(X)$ では $\mathcal O(1)$ と $\mathcal O_X$ の類が異なる。従って射影空間への射は、一般には $X$ 上の正則関数を何本か並べて定義するものではない。局所自明化でのみ関数の組になり、重なりでは同じ可逆な係数倍で変わることが必要になる。
:::

### 射影束へ普遍的な商を一般化する

:::proposition[射影束が表す可逆商]{#prop-ag-projective-bundle-quotient}
基底 $S$ 上の有限階数局所自由層 $\mathcal E$ に対し、$\mathbb P_S(\mathcal E)=\operatorname{Proj}_S\operatorname{Sym}\mathcal E$ とする。$S$ 上の射 $f:T\to\mathbb P_S(\mathcal E)$ は、$T$ 上の $\mathcal E$ の引き戻しから可逆層への全射の同型類に対応する。
:::

:::proof
$\mathcal E$ を自明化した基底開上では、対称代数は次数一変数を持つ多項式環であり、相対 Proj は通常の射影空間である。その開へ写る $T$ の部分では、可逆商は基底元の像である生成切断の組と同じなので、射影空間の普遍性を適用できる。自明化を変えると基底は可逆行列で変わり、可逆商への像の組も同じ線形変換を受ける。この変換は Proj の標準座標の貼り合わせに使うものと同じだから、得られた局所射は重なりで一致する。逆に局所射から座標切断による商を作ると、同じ可逆行列で一致し、全域の可逆商に貼れる。互いに逆であることは各開で確認できる。
:::

:::example[射影束の切断を可逆商で作る]
$S=\mathbb P^1$、$\mathcal E=\mathcal O\oplus\mathcal O(2)$ とする。第一成分への射影と第二成分への射影は、ともに可逆商なので $\mathbb P_S(\mathcal E)$ の切断を与える。各ファイバーでは二つの異なる座標点になる。第一の切断に沿う $\mathcal O(1)$ の引き戻しは $\mathcal O$、第二では $\mathcal O(2)$ である。局所的に同じ射影直線の二座標点であっても、切断の全体を基底上で見ると直線束の類が異なる。商の約束を採用したため、ここでは基底側の二つの成分への射影をそのまま用いている。
:::

### 生成切断の選び方で像の環が変わる

:::example[同じ三次の直線束で二つの異なる像]
$\mathbb P^1$ の $\mathcal O(3)$ について全切断 $s^3,s^2t,st^2,t^3$ を使えば、ねじれ三次曲線への埋め込みを得る。部分系 $s^3,s^2t,t^3$ でも基点はないが、像は $Y^3=X^2Z$ である。$X=1$ の近傍では $u=t/s$ を使って $(Y,Z)=(u,u^3)$ となり、ここでは $u$ を復元できる。一方 $Z=1$ の近傍で $v=s/t$ とすると $(X,Y)=(v^3,v^2)$ になる。環 $k[v^2,v^3]$ には次数一の $v$ が含まれず、原点で逆の局所写像を作れない。全切断を使う場合は同じ近傍で座標 $st^2/t^3=v$ も残るため、$v$ が復元できる。束の次数だけでは像の特異性は決まらず、どの切断を用いたかまで指定する必要がある。
:::

:::example[射影束を直線束でねじっても点の関手は同じ]
$\mathcal E$ に基底上の可逆層 $\mathcal M$ をテンソルして $\mathcal E\otimes\mathcal M$ に替える。任意の $T$ 上で $\mathcal E_T\to\mathcal L$ という可逆商は、テンソル積で $(\mathcal E\otimes\mathcal M)_T\to\mathcal L\otimes\mathcal M_T$ に移る。$\mathcal M_T^{-1}$ を掛ければ逆になる。従って二つの射影束は同型である。一方、ねじった束の $\mathcal O(1)$ は、同型で移した元の $\mathcal O(1)$ に基底からの $\mathcal M$ を掛けたものになる。例えば $\mathcal E=\mathcal O\oplus\mathcal O(2)$ を $\mathcal M=\mathcal O(-1)$ でねじると、$\mathcal O(-1)\oplus\mathcal O(1)$ の射影束と同じ全空間を得るが、第一の切断への $\mathcal O(1)$ の制限は $\mathcal O$ から $\mathcal O(-1)$ に変わる。
:::

## 豊富な直線束と非常に豊富な直線束

:::definition[豊富性]{#def-ag-ample}
スキーム $X$ の可逆層 $\mathcal L$ について、正冪の大域切断 $s\in\Gamma(X,\mathcal L^{\otimes m})$ の非消滅開集合 $X_s$ のうちアフィンであるものが位相の基底をなすとき、$\mathcal L$ を :term[豊富な直線束]{en="ample line bundle" yomi="ほうふなちょくせんそく"} という。$k$ スキーム上で閉埋め込み $X\hookrightarrow\mathbb P^n_k$ の $\mathcal O(1)$ の引き戻しなら :term[非常に豊富な直線束]{en="very ample line bundle" yomi="ひじょうにほうふなちょくせんそく"} という。
:::

:::proposition[射影閉埋め込みからの豊富性]{#prop-ag-very-ample-is-ample}
非常に豊富な可逆層は豊富である。射影空間の $\mathcal O(d)$（$d>0$）は非常に豊富である。
:::
:::proof
射影空間の正次数の斉次式の非消滅開は位相の基底である。閉部分スキームとの交わりは標準アフィン開での閉部分なのでアフィンであり、切断は $\mathcal O(1)$ の正冪の切断を制限して得られる。後半は全次数 $d$ の全単項式が与える Veronese 写像で示す。$X_i^d$ の非消滅開で、比 $X_i^{d-1}X_j/X_i^d$ が元の全アフィン座標を復元する。従ってそこでは座標環の全射である。標数に依存しない斉次関係と標準開による :ref[prop-ag-veronese-segre-image] の計算は、各開の商環でも同じ座標の代入で逆を与える。像は閉じており、したがってスキームでも閉埋め込みである。:ref[thm-ag-projective-sections] で引き戻しは $\mathcal O(d)$ となる。
:::

逆に $\mathbb P^1$ の $\mathcal O(d)$ が豊富なら $d>0$ である。$d<0$ ではどの正冪も非零切断をもたず、$d=0$ の非零切断の非消滅開は全体だけで位相の基底にならない。

### 豊富性を次数と開集合で検算する

:::example[自明束の非消滅開]
$\mathbb P^1$ の $\mathcal O$ には定数切断しかないので、非零切断の非消滅開は全体である。$\mathbb P^1$ は大域正則関数環が $k$ で一点より多くの点をもつためアフィンでない。どの正のテンソル冪も同じ事情であり、$\mathcal O$ は豊富でない。
:::

:::example[二つの因子方向が必要になる]
$\mathbb P^1\times\mathbb P^1$ 上の $\mathcal O(1,1)$ は四つの積切断 $s_i t_j$ により Segre 閉埋め込みを与える。$\mathcal O(1,0)$ の任意の正の冪の切断は第二因子に沿って定数である。実際、第一因子で束を自明化した開に制限すると各ファイバー上に関数があり、射影直線の大域関数は定数である。従ってどの正の冪の写像も第二因子を縮め、非常に豊富にならない。またどの非消滅開も射影直線を閉部分として含むためアフィンではない。よって $\mathcal O(1,0)$ は豊富でもない。
:::

### 生成される束を非常に豊富な束と掛ける

:::proposition[非常に豊富な束と大域生成な束の積]
射影 $k$ スキーム $X$ に対し、$\mathcal A$ が非常に豊富、$\mathcal B$ が有限個の大域切断で生成される可逆層であるとする。すると $\mathcal A\otimes\mathcal B$ は非常に豊富である。
:::

:::proof
$\mathcal A$ の閉埋め込みを $i:X\hookrightarrow\mathbb P^r$、$\mathcal B$ の生成切断が与える射を $g:X\to\mathbb P^s$ とする。$(i,g):X\to\mathbb P^r\times\mathbb P^s$ は、$g$ のグラフへの閉埋め込みを $i\times\id$ と合成した射である。グラフは標的の射影空間が分離であるため閉じている。続いて Segre の閉埋め込みを合成する。Segre の座標は二つの因子の座標切断の積であり、積の非消滅開では両可逆層の局所基底のテンソル積に等しい。従って引き戻した $\mathcal O(1)$ は $\mathcal A\otimes\mathcal B$ である。こうしてこの束の切断による閉埋め込みを得る。
:::

:::example[片方だけが正でも、豊富な束に掛ければ埋め込める]
$\mathbb P^1\times\mathbb P^1$ の $\mathcal O(1,0)$ は第一因子の座標切断で生成され、第二因子を縮める。一方 $\mathcal O(1,1)$ は Segre 埋め込みを与える。両者の積 $\mathcal O(2,1)$ は、二次 Veronese の第一因子と第二因子の Segre でも得られる。局所座標 $(t,u)$ の開で、積切断の比のうち $t$ と $u$ がそれぞれ残るため両変数を復元できる。積の結果で第二因子の切断が増えたのは、最初の非常に豊富な束が両方向の値をすでに区別していたためである。
:::

### 豊富な束の十分高い冪を埋め込みに使う

:::proposition[射影スキーム上の豊富な束の高冪]
$X$ を体上の射影スキームとする。可逆層 $\mathcal L$ が豊富であれば、十分大きい全ての $m$ に対して $\mathcal L^m$ が非常に豊富である。
:::

:::proof
固定した非常に豊富な可逆層を $\mathcal A$ とする。$\mathcal A^{-1}\otimes\mathcal L^m$ が大域生成となることを示せば、前命題でよい。豊富性により正冪の切断 $s_i$ のアフィンな非消滅開で $X$ が覆える。有限個を選び、次数を公倍数 $d$ に揃える。各 $r=0,\dots,d-1$ について $\mathcal F_r=\mathcal A^{-1}\otimes\mathcal L^r$ を考える。$X_{s_i}$ 上でこの連接層の有限個の生成切断を選ぶ。

それぞれの生成切断 $v$ を $s_i^N$ 倍して $\mathcal F_r\otimes\mathcal L^{Nd}$ の大域切断に延ばせる。これを確かめるため、$X$ を $\mathcal L^d$ が自明な有限アフィン開で覆う。各開で $X_{s_i}$ との交わりは $s_i$ の局所係数の基本開である。準連接性から分母を払えば局所切断になり、有限個なので共通の指数を取れる。二開の重なりでの差は $s_i$ を反転すると零である。重なりも準コンパクトなので有限個のアフィン開で調べ、さらに共通の冪を掛ければ差が零になる。従って全ての開で一致し、大域切断になる。$X_{s_i}$ では $s_i$ が基底だから、その冪を掛けてもねじった束を生成する。

指数が $m\equiv r\bmod d$ で十分大きければ、各切断の延長で使った指数からさらに $s_i$ の冪を掛けて同じ $m$ に揃えられる。有限個の剰余類と有限個の生成切断を扱うため、すべてに通用する下限が取れる。従って $\mathcal A^{-1}\otimes\mathcal L^m$ は大域生成である。前命題を適用すると結論を得る。
:::

### 豊富性を開への制限と正冪で扱う

:::proposition[豊富性と正冪]
可逆層 $\mathcal L$ が豊富であることと、一つの正整数 $d$ について $\mathcal L^d$ が豊富であることは同値である。また閉部分スキームへの制限は豊富である。
:::

:::proof
$\mathcal L$ が豊富なら、位相の基底をなすアフィン非消滅開 $X_s$ を取る。$s$ を $d$ 乗しても各点で非零かどうかは同じであり、$s^d$ は $\mathcal L^d$ の正冪の切断である。従って同じ開の族が $\mathcal L^d$ の豊富性を示す。逆に $\mathcal L^d$ の正冪の切断は $\mathcal L$ の正冪の切断でもあるため、その開の基底をそのまま使える。閉部分への制限では $X_s$ と閉部分の交わりはアフィンの閉部分であり、相対位相の基底をなす。これは制限した切断の非消滅開であるから、閉部分に対しても豊富である。
:::

:::example[射影平面の曲線に制限した非常に豊富な束]
滑らかな平面曲線 $C=V(F)$ に $\mathcal O_{\mathbb P^2}(m)$ を制限する。$m>0$ なら Veronese に元の閉埋め込みを合成することで $\mathcal O_C(m)$ は非常に豊富になる。例えば $m=2$ に対し $X^2$ が非零の開では、$XY/X^2=Y/X$、$XZ/X^2=Z/X$ が曲線の通常の座標を復元する。もし $C$ の次数が二なら、周囲の六個の二次座標の間に $F=0$ が一つあり、像は対応する超平面に含まれる。しかし閉埋め込みであることは損なわれない。非常に豊富性では、像が標的の全空間を張ることは要求しない。
:::

:::example[符号の異なるねじりを積から判定する]
$\mathbb P^1\times\mathbb P^1$ の $\mathcal O(2,-1)$ は豊富でない。第二因子を動かす閉ファイバーへ制限すると $\mathcal O(-1)$ となり、そのどの正冪も切断を持たないからである。これに対し $\mathcal O(2,3)$ は第一因子の二次 Veronese と第二因子の三次 Veronese の積を Segre に送れば閉埋め込みを与える。例えば $s_0^2t_0^3$ が非零な近傍では、$s_1/s_0$ と $t_1/t_0$ をそれぞれ一回だけ含む切断の比から得る。二方向の次数の符号は、写像が両方向の座標を区別できるかを制限によって示す。
:::

### 豊富性を閉部分スキームと像から調べる

閉埋め込みを与える直線束は、部分スキームに制限しても座標を区別できる。これを使うと、直線束が豊富かどうかを、制限先で切断が得られるかという問題に帰着できる。

:::proposition[射影スキームの閉部分スキームへの制限]
$X$ を体上の射影スキーム、$Y\hookrightarrow X$ を閉部分スキームとする。$X$ 上の非常に豊富な直線束 $\mathcal L$ の $Y$ への制限は非常に豊富である。$\mathcal L$ が豊富なら、その制限も豊富である。
:::

:::proof
非常に豊富なら閉埋め込み $i:X\hookrightarrow\mathbb P^n$ と $\mathcal L\simeq i^*\mathcal O(1)$ を取る。閉埋め込みの合成は閉埋め込みであり、実際アフィン標準開の座標環では二つの全射の合成も全射である。従って $Y$ 上の引き戻しは非常に豊富である。豊富性を非消滅アフィン開の基底によって定義する場合は、$X_s$ と $Y$ の交わりが $X_s$ の閉部分スキームであるためアフィンであり、$s|_Y$ の非消滅開に等しい。これらが $Y$ の位相の基底をなすことから、豊富性も従う。
:::

:::example[二つの射の像で線形系を検査する]
$X=\mathbb P^1\times\mathbb P^1$ に閉曲線 $C$ を、第一因子と第二因子の同じ点を結ぶ対角として入れる。$C\simeq\mathbb P^1$ 上では $\mathcal O(a,b)|_C=\mathcal O(a+b)$ である。例えば $\mathcal O(3,-2)|_C$ は $\mathcal O(1)$ となるが、第二因子を動かした直線上への制限は $\mathcal O(-2)$ なので、周囲で豊富であることは従わない。一つの閉曲線で非豊富性が分かれば周囲でも非豊富であるため、豊富性を調べるときは、線形系が像を小さくする方向を先に探すとよい。
:::

:::example[非被約部分への制限で一次の情報を調べる]
$\mathbb P^1$ の点 $[1:0]$ の近傍の座標を $t$ とし、$Y=V(t^2)$ を長さ二の閉部分スキームとする。$\mathcal O(1)$ の二切断を $1,t$ と書くと、生成元 $1$ で割った比の像は $k[t]/(t^2)$ の $t$ である。この元は零でないため、二切断は点の剰余体だけでなく冪零方向も回復する。これに対して $\mathcal O(2)$ の部分系 $1,t^2$ を $Y$ へ制限した写像は一定である。二つの束はどちらも非常に豊富だが、埋め込みを与えるかどうかは束と選んだ切断系を合わせて判定する。
:::

## 線形系と基点

:::definition[線形系と基点]{#def-ag-linear-system}
$k$ スキーム $X$ 上の可逆層 $\mathcal L$ と有限次元部分空間 $0\ne V\subset H^0(X,\mathcal L)$ を取る。$V$ の一次元部分空間をパラメータとする射影空間を :term[線形系]{en="linear system" yomi="せんけいけい"} といい、全切断が消える点を :term[基点]{en="base point" yomi="きてん"} という。一次元商を用いる本章の規約では、切断を並べるパラメータ空間は $\mathbb P(V^\vee)$ であり、評価写像が定める射の標的は $\mathbb P(V)$ である。基点のスキーム構造は評価写像 $V\otimes_k\mathcal L^{-1}\to\mathcal O_X$ の像のイデアルで定まる。$V=H^0(X,\mathcal L)$ が有限次元で非零なら、これを完全線形系という。
:::
基点の外では切断が生成するので、$V$ の基底を選ぶと :ref[thm-ag-projective-sections] の射になる。基底を替えると標的座標に正則行列が作用する。元が整で $V$ に非零切断があるならこの開は稠密なので有理写像を得る。例えば $\mathbb P^2$ の二次式 $XY,XZ$ の線形系には直線 $X=0$ 全体が基点として含まれる。共通因子 $X$ を取り除いた有理写像は $[Y:Z]$ であり、残る真の不定点は $[1:0:0]$ である。

:::proposition[線形系のグラフとブローアップ]{#prop-ag-linear-system-graph}
整スキーム上で、可逆層の有限個の切断が定める有理写像 $X\dashrightarrow\mathbb P^n$ を考える。少なくとも一つの切断は非零とする。基点イデアルに沿うブローアップは、その有理写像のグラフのスキーム論的閉包と同型である。
:::
:::proof
可逆層を自明化したアフィン近傍で切断を $f_0,\dots,f_n$ とする。斉次準同型 $A[Y_0,\dots,Y_n]\to\mathcal R(I)$、$Y_i\mapsto f_i T$ は全射なので、ブローアップは $\mathbb P^n_X$ に閉埋め込みをもつ。局所基底を替えると全ての $f_i$ に同じ単元が掛かり、次数 $d$ の像がその $d$ 乗倍になるだけなので Proj で同じ閉埋め込みに貼り合う。基点の外ではブローアップは同型で、斉次比は元の写像の座標比である。この閉部分スキームは整である。実際、各非空標準開の環は次節の比の環として $A$ の分数体に入る整域であり、基点の外の同じ稠密な開集合を共有する。したがって稠密なグラフ部分のスキーム論的閉包はブローアップ全体である。
:::

:::example[Cremona 変換の基点を分ける]
$\mathbb P^2$ の線形系 $YZ,ZX,XY$ では三つの座標点が基点である。$X=1$ で $y=Y/X,z=Z/X$ とするとイデアルは $(yz,z,y)=(y,z)$ である。ブローアップの近傍 $z=yt$ では座標式は $[y^2t:yt:y]$ となる。共通因子 $y$ を除いて $[yt:t:1]$ とすれば例外曲線 $y=0$ 上でも射が定まり、そこで $[0:t:1]$ を得る。原点に近づく方向によって像が変わる現象が、例外曲線の座標に移されている。
:::

### 基点の台と基点イデアル

:::example[同じ基点を異なる厚みで記録する]
$\mathbb P^2$ の切断 $X^2,XY,Y^2$ は、$Z=1$ ではイデアル $(x,y)^2$ を生成する。その商の基底は $1,x,y$ なので基点の長さは $3$ である。切断 $X,Y$ の基点は同じ $[0:0:1]$ だが、イデアルは $(x,y)$ で長さ $1$ である。前者の有理写像は後者の後に二次 Veronese を合成したものである。基点の台だけからどの線形系が使われたかは復元できない。
:::

:::example[固定因子を除いた可動部分]
$X^2Y,X^2Z$ は直線 $X=0$ を重複度 $2$ の固定成分にもつ。二式の最大公約因子が $X^2$ であるため、これを除くと固定成分は残らない。残る写像 $[Y:Z]$ は $[1:0:0]$ で不定で、その点の近傍で $y,z$ を使うと両座標軸から異なる値をとる。固定因子の除去で直線上の見かけの不定点は消えるが、残った一点には方向を記録する必要がある。
:::

### 固定成分を取り除いた後も基点を調べる

:::proposition[固定 Cartier 因子の除去]
空でない整スキーム $X$ と可逆層 $\mathcal L$ の線形系 $V$ に対し、ある有効 Cartier 因子 $D$ への全切断の制限が、層の切断として零になるとする。$D$ の標準切断で割って得る $\mathcal L(-D)$ の線形系は、元と同じ有理写像を定める。元の基点イデアルは可動側のイデアルに $\mathcal O(-D)$ を掛けたものである。
:::

:::proof
$D$ の局所式を $a_i$ とし、$\mathcal L$ の局所基底で切断が $s_{ij}=a_i h_{ij}$ と書ける。$a_i$ は非零因子なので商は一意である。重なりで $a_i$ は単元倍で変わり、この比が $\mathcal L$ の基底の移行係数に加わるため、$h_{ij}$ は $\mathcal L(-D)$ の切断に貼り合う。$D$ の外では共通因子が単元なので、両者の射影座標比は同じである。従って有理写像は同じである。基点イデアルの局所生成元は元で $a_i h_{ij}$、新しい方で $h_{ij}$ なので、前者は $(a_i)$ と後者の積に等しい。
:::

:::example[平面の三次線形系から直線の固定成分を除く]
$\mathbb P^2$ 上の $X^2Y,XYZ,XZ^2$ を取る。共通因子 $X$ を除くと $XY,YZ,Z^2$ が残る。後者の基点では $Z=0$ かつ $XY=0$ なので、二つの点 $p=[1:0:0]$ と $q=[0:1:0]$ である。$p$ の近傍 $X=1$ では基点イデアルは $(y,yz,z^2)=(y,z^2)$ で長さ二である。$q$ の近傍 $Y=1$ では $(x,z,z^2)=(x,z)$ で長さ一である。同じ基点集合に入る二点でも、どの切断がどの次数から消えるかにより基点の厚みが違う。この情報はブローアップの局所式の選び方に関わる。
:::

### 基点のない場合と点からの線形射影

:::proposition[閉埋め込みを与える線形系の判定]
$X$ を代数閉体 $k$ 上の射影スキームとし、可逆層 $\mathcal L$ を生成する有限次元空間 $V$ を取る。対応する射 $f:X\to\mathbb P(V)$ が閉埋め込みであることと、次の二条件は同値である。

1. 異なる閉点 $p,q$ は異なる点に写る。
2. 各閉点 $p$ で $T_pX\to T_{f(p)}\mathbb P(V)$ が単射である。
:::

:::proof
閉埋め込みは点を区別し、局所環が全射なので余接空間への写像も全射である。従って接空間への写像は単射である。逆に二条件を仮定する。$f$ は閉グラフで $X\times_k\mathbb P(V)$ に入り、$X$ 自身の射影埋め込みと合わせると射影射である。特に固有である。標的の閉点 $y$ 上のファイバーは有限型 $k$ スキームであり、第一条件で高々一つの閉点をもつ。有限型 $k$ スキームの閉点はどの閉部分集合にも稠密である。従って空でないファイバーは零次元であり、台はその一点 $p$ だけである。その余接空間は $\mathfrak m_p/(\mathfrak m_p^2+\mathfrak m_y\mathcal O_{X,p})$ である。第二条件でこれは零なので、Nakayama の補題でファイバーの局所環の極大イデアルも零となる。その剰余体は $k$ であるため、ファイバーは $\operatorname{Spec}k$ である。

相対射影空間で、その一点を避ける相対超平面を取る。ファイバーが空なら任意の標準超平面を取ってよい。超平面と $X$ の交わりの像は閉じており、$y$ を含まない。その像を除いたアフィン近傍では $X$ 全体が相対アフィン空間の閉部分となる。従って $f$ はこの近傍でアフィンであり、アフィン固有射の有限性により有限である。閉点をすべて含む開は標的全体であるため、$f$ は至る所で有限である。

アフィン開で有限代数 $A\to B$ を取る。各閉点の剰余体にテンソルすると、ファイバーは空か剰余体そのものなので写像は全射である。$B/\operatorname{im}(A)$ は有限 $A$ 加群であり、閉点でのファイバーがすべて零だから Nakayama の補題により全体で零である。従って $A\to B$ は全射で、$f$ は閉埋め込みである。
:::

第一条件は、$p,q$ への評価 $V\to\mathcal L(p)\oplus\mathcal L(q)$ の全射性に等しい。生成切断の比を取れば、第二条件は $p$ で消える切断の一次部分が $\mathfrak m_p/\mathfrak m_p^2$ を張る条件に等しい。これは $p$ を台とする任意の長さ二の閉部分スキームへの切断の全射性と同値である。実際、そのような閉部分は局所環から $k[\epsilon]/(\epsilon^2)$ への全射で与えられ、非零の接ベクトルに対応する。任意の非零接ベクトルをある切断の一次部分が検出するなら、これらの一次部分は余接空間を張る。

:::example[超平面の部分系が与える射影]
$\mathbb P^3$ で点 $p=[1:0:0:0]$ を通る超平面の式を集めると、$X_1,X_2,X_3$ が基底となる。この組の基点は $p$ であり、基点の外で写像は $[X_1:X_2:X_3]$ になる。例えば標的の点 $[1:2:3]$ の前像は、$p$ と $[0:1:2:3]$ を通る直線から $p$ を除いた部分である。局所座標付けでは $X_1$ が単元なので $X_2/X_1=2,X_3/X_1=3$ を固定し、$X_0/X_1$ だけが自由である。埋め込まれた部分多様体に同じ線形系を制限する場合、この直線との交わりがファイバーになり、基点が多様体上にあるかもその制限で変わる。
:::

### 基点が局所式の共通因子だけに由来するかを判定する

:::example[厚い基点を解くと異なる二近傍が現れる]
$\mathbb P^2$ の部分系 $X^2,YZ$ を考える。基点は $[0:1:0]$ と $[0:0:1]$ の二つである。前者の開 $Y=1$ では $(x^2,z)$、後者の開 $Z=1$ では $(x^2,y)$ という有限長のイデアルである。前者で写像を $[x^2:z]$ と書く。ブローアップの標準開 $D_+(zT)$ では $u=x^2/z$ を加えて $zu=x^2$、射影値は $[u:1]$ である。もう一方の標準開 $D_+(x^2T)$ では $v=z/x^2$ を加えて $z=x^2v$、射影値は $[1:v]$ である。第二の開は $k[x,v]$ の平面だが、第一の開には二次の関係が残る。基点が二点あるという情報だけでは、ブローアップ後の局所環の形を決められない。
:::

### イデアルに可逆な因子を掛けても同じブローアップになる

:::proposition[共通の可逆因子と Rees 代数]
$\mathcal J$ を可逆イデアル層とし、$\mathcal I$ を有限型の準連接イデアル層とする。$\mathcal J\mathcal I$ に沿うブローアップは $\mathcal I$ に沿うブローアップと自然に同型である。
:::

:::proof
$\mathcal J$ の局所生成元を $a$ とする。$a$ は非零因子なので、各次数 $d$ の写像 $I^d\to a^d I^d$ は掛け算による同型であり、次数付き代数の乗法とも両立する。従って各開で Rees 代数と Proj の同型を得る。生成元を $ua$（$u$ は単元）に替えると次数 $d$ の写像は $u^d$ 倍だけ変わる。Proj の標準開では分子と分母の次数が等しいので、この倍率は分数の両方に同じ冪で現れて消える。従って局所同型は重なりで一致する。元のブローアップ上では $\mathcal I\mathcal O$ と $\mathcal J\mathcal O\cdot\mathcal I\mathcal O$ は可逆イデアルだが、後者の局所式には $a$ が残る。
:::

:::example[固定成分を除く順序と例外因子の違い]
$\mathbb A^2$ で $[x^2:xy]$ を取る。基点イデアルは $x(x,y)$ である。ブローアップ空間は $(x,y)$ のブローアップと同じになる。実際 $x$ に沿う可逆イデアルを共通に掛けても比 $y/x$ は変わらない。一方、$y=xt$ の開では元の基点イデアルの引き戻しは $(x^2)$、共通因子を除いた基点イデアルの引き戻しは $(x)$ である。従ってこの開では元の例外因子の係数は二、共通因子を除いた方の係数は一である。空間が同じであっても、どのイデアルの可逆化を記述しているかで有効因子が異なる。
:::

## 相対 Proj とスキームのブローアップ

:::definition[相対 Proj とブローアップ]{#def-ag-relative-proj}
準連接な非負次数付き $\mathcal O_X$ 代数 $\mathcal S$ に対し、アフィン開 $U$ 上で $\operatorname{Proj}\Gamma(U,\mathcal S)$ を作り貼ったものを :term[相対 Proj]{en="relative Proj" yomi="そうたいぷろじぇくと"} とする。準連接イデアル層 $\mathcal I$ に対し $\mathcal R(\mathcal I)=\bigoplus_{d\ge0}\mathcal I^d$ を :term[Rees 代数]{en="Rees algebra" yomi="りーすだいすう"} といい、その相対 Proj を :term[ブローアップ]{en="blow-up" yomi="ぶろーあっぷ"} $\operatorname{Bl}_{\mathcal I}X$ とする。
:::
基底の基本開への制限は係数の次数零元の局所化であり、斉次分数の局所化と可換である。従って相対 Proj の標準開は重なりで同じ環になり、貼り合う。アフィンで $I=(f_1,\dots,f_m)$ の場合、Rees 代数は $A[T]$ 内の $\sum I^dT^d$ である。$f_iT$ の非消滅開の次数零環は $A[f_1/f_i,\dots,f_m/f_i]\subset A_{f_i}$ である。実際、分母は $(f_iT)^d$ で、分子は $I^dT^d$ の元だからその比で生成される。写像の核が零なのは、分子が $A_{f_i}$ で零なら $f_i$ の冪が分子を殺すためである。

:::proposition[ブローアップの普遍性]{#prop-ag-blowup-universal}
ブローアップ上の $\mathcal I\mathcal O$ は可逆イデアルである。射 $g:Y\to X$ 上で $\mathcal I\mathcal O_Y$ が可逆イデアルなら、$g$ はブローアップを一意に経由する。
:::

:::proof
比の環では $I$ の全ての元が $f_i$ の倍数であり、$f_i$ は $A_{f_i}$ で単元なのでその部分環で非零因子である。従って引き戻したイデアルは各開で可逆になる。$Y$ 上で像のイデアルが可逆なら、$g^*f_i$ がその基底になる開が全体を覆う。そこでは $g^*f_j=g^*f_i b_j$ の比 $b_j$ が一意に定まるので、比の環からの環写像が得られる。実際、比の関係は $f_i$ の冪を掛ければ $A$ の関係に戻り、その像を $Y$ 上で $g^*f_i$ の冪で約分できる。重なりで比は可逆な座標変換に従うため射を貼り合わせられる。任意の因子化では同じ比になる。しかもその逆像の標準開は $g^*f_i$ がイデアルを生成する開と一致する。標準開上での一意性が従う。
:::

有限型の中心イデアルを持つブローアップは固有である。実際、基底のアフィン開上で有限個の生成元を選ぶと、各変数を $f_iT$ に送る斉次多項式代数から Rees 代数への全射を得る。この商は相対射影空間への閉埋め込みを与えるので、アフィン基底上で射影的である。固有性の三条件は標的の開被覆で判定でき、普遍閉性については任意の基底変換後の引き戻しでも開被覆で調べられる。従って基底全体で固有である。中心イデアルが大域的に有限個の切断で生成される場合は、基底全体の射影空間に閉埋め込みを得る。

### Rees 代数を局所比から比較する

:::example[冪を取ってもブローアップ空間は変わらない]
$I=(x,y)$ に対して $\mathcal R(I^2)$ の次数 $d$ は $I^{2d}$ である。従って $\mathcal R(I^2)$ は $\mathcal R(I)$ の二次 Veronese 部分環と同じであり、Proj は同型である。ただし $I^2\mathcal O=(I\mathcal O)^2$ なので例外因子の局所式は $x^2$ または $y^2$ となる。空間が同じでも中心から引き戻した例外因子の重複度は異なる。
:::

:::example[非平坦な基底変換で中心を計算し直す]
$X=\operatorname{Spec}k[x,y]$ を $k[x]$ 上で見て、中心を $(x,y)$ とする。$x=0$ の基底変換後の中心は $(y)$ という可逆イデアルなので、そこでのブローアップは恒等射である。他方、もとのブローアップの $y$ 近傍は $x=ys$ であり、$x=0$ を課すと $ys=0$ となる。元のブローアップのファイバーには例外成分が残る。この違いは、$I\otimes_{k[x]} k$ から基底変換後の環への写像で $x$ の類が零に送られることに対応する。
:::

### Rees 代数と平坦基底変換

:::proposition[ブローアップと平坦基底変換]{#prop-ag-blowup-flat-base-change}
基底 $S$ 上のスキーム $X$ と準連接イデアル層 $\mathcal I$ に対し、$S'\to S$ が平坦なら、$\operatorname{Bl}_{\mathcal I}X$ の $S'$ への基底変換は拡大イデアル $\mathcal I\mathcal O_{X_{S'}}$ に沿うブローアップである。
:::

:::proof
アフィン開で基底環を $R\to R'$、スキームの環を $A$ とする。各 $I^d\hookrightarrow A$ は $R'$ とのテンソルで単射を保つ。その像は $I^d$ の元の像で生成され、$I^d$ 自体が $d$ 個の $I$ の元の積で生成されているため、この像は拡大イデアルの $d$ 乗に等しい。従って Rees 代数を次数ごとに比較でき、乗法も元の積から来るので斉次環が同型である。相対 Proj の標準開の環は斉次局所化の次数零部分であり、局所化はテンソル積と、次数零部分は直和分解と両立する。故に標準開の同型が得られ、重なりも同じ局所化なので貼り合わさる。
:::

:::example[係数を体拡大しても局所比は保たれる]
$\Q$ 上の $I=(x,y^2)$ を $\C$ に拡大する。$x$ に対応する開は $u=y^2/x$ を加えた $\Q[x,y,u]/(xu-y^2)$ である。商が実際に比の部分環になることは、$xu-y^2$ が $u$ について原始一次式で、$x$ と共通因子をもたず、$x$ の局所化で比の環と一致することから分かる。$\C$ に拡大しても同じ式であり、$y^2$ を分母とするもう一方の開では $v=x/y^2$ を加えるので $\C[y,v]$ になる。重なりで $uv=1$ も保たれるため、どちらの順で計算しても同じ貼り合わせを得る。
:::

### ブローアップの例外部分を次数付き環から得る

:::proposition[例外因子と随伴次数付き環]{#prop-ag-blowup-exceptional-graded}
$I$ を環 $A$ の有限生成イデアル、$X'=\operatorname{Bl}_I(\operatorname{Spec}A)$ とする。$I\mathcal O_{X'}$ で定まる例外因子は
$$
\operatorname{Proj}\bigoplus_{d\ge0}I^d/I^{d+1}
$$
である。
:::

:::proof
Rees 代数 $R=\bigoplus_{d\ge0}I^d T^d$ を取る。$I$ は次数零の係数環 $A$ のイデアルなので、$IR$ の次数 $d$ は $I^{d+1}T^d$ である。従って $R/IR$ は式の随伴次数付き環に同型である。各標準開で $R/IR$ の Proj を求めるには、分母となる次数一元を反転して次数零部分を取る。この操作は斉次イデアルの商と可換なので、元の開の環を $I$ の像で割ったものを得る。これは例外因子のイデアル $I\mathcal O_{X'}$ による局所商であるため、全体で一致する。
:::

:::example[線形部分空間を中心にした場合]
$A=k[x_1,\dots,x_r,y_1,\dots,y_s]$ で $I=(x_1,\dots,x_r)$ を取る。$I^d/I^{d+1}$ は $x$ について総次数がちょうど $d$ の単項式を $k[y_1,\dots,y_s]$ 上の基底に持つ。従って随伴次数付き環は $r$ 変数の標準次数付き多項式環である。例外因子は $\mathbb A^s\times\mathbb P^{r-1}$ となる。例えば $r=3,s=1$ では、中心の任意の点の上に射影平面が一つ載る。$x_1$ に対応する標準開では $x_2=x_1u_2,x_3=x_1u_3$ と置けるため、例外因子の座標は $x_1=0$ のもとで $(u_2,u_3,y_1)$ であり、随伴次数付き環の標準開とも一致する。
:::

### Rees 代数は比の関係を保存する

:::proposition[正則列で切り出した中心の例外因子]
Noether スキーム $X$ の閉部分スキーム $Z$ のイデアル $\mathcal I$ が局所的に長さ $r\ge1$ の正則列で生成されるとする。ブローアップの例外因子は $\mathbb P_Z(\mathcal I/\mathcal I^2)$ であり、$Z$ 上の射影束である。
:::

:::proof
$Z$ の点の局所環 $A$ で、$I=(f_1,\dots,f_r)$ とする。随伴次数付き環には $\operatorname{Sym}_{A/I}(I/I^2)$ から乗法による全射がある。これが同型になることを、次数 $j$ について、$f_1^{a_1}\cdots f_r^{a_r}$（$\sum a_i=j$）が $I^j/I^{j+1}$ の $A/I$ 基底であると示して証明する。

正則列は Noether 局所環では順番を交換できる。隣接する二元を $a,b$ と書くと、$bx=0$ なら $x$ は $a$ の倍数であり、$a$ を約分して繰り返すと $x$ は全ての $a$ の冪に属する。Krull の共通部分定理で $x=0$ である。また $ax=by$ なら、$b$ が $A/(a)$ で非零因子なので $y=ay'$ と書け、$a$ を約分して $x=by'$ になる。よって $b,a$ の順でも正則である。先行する元で割った局所環でこの操作を適用すれば任意の順序に移れる。

$r=1$ の基底の主張は $f_1^j$ の約分で従う。$r>1$ とし、$J=(f_1,\dots,f_{r-1})$、$f=f_r$ と置く。$r$ に関する帰納法で $J^i/J^{i+1}$ は $A/J$ 上自由なので、$A/J$ で非零因子の $f$ はこの各商でも非零因子である。有限フィルトレーションを使えば $f$ は $A/J^{j+1}$ でも非零因子になる。いま次数 $j$ の単項式の線形結合が $I^{j+1}$ に入るとする。まず $A/(f)$ に移すと、残りの $r-1$ 元は正則列なので、$f$ を含まない単項式の係数は帰納法ですべて $I$ に入る。これらの項を引くと、残りは $fH$ となる。$I^{j+1}=J^{j+1}+fI^j$ だから、$f$ の $A/J^{j+1}$ 上での非零因子性により $H\in I^j$ である。$H$ は次数 $j-1$ の単項式の和であり、次数に関する帰納法でその係数も全て $I$ に入る。次数零は $A/I$ そのものであるから帰納法が始まる。

特に次数一で余法加群は自由階数 $r$ であり、各次数の乗法はその対称積と同型である。この写像は生成元の選択によらないので層として同型になる。:ref[prop-ag-blowup-exceptional-graded] の随伴次数付き環の Proj を取ると結論を得る。
:::

:::example[二つの生成元の非対称なブローアップ]
$I=(x,y^2)\subset k[x,y]$ を取る。$x$ に対応する開は $u=y^2/x$ を加え、$xu=y^2$ とした環である。$x$ の局所化に入ることは、$xu-y^2$ が $u$ に関する原始一次式で素イデアルを生成することから確認できる。一方 $y^2$ に対応する開では $v=x/y^2$ を加え、$x=y^2v$ と消去できる。この開は $k[y,v]$ である。二開の重なりは $u,v$ が可逆な場所であり、$uv=1$ と $x=y^2v$ が座標変換である。第一開の原点では $xu-y^2$ の一次部分がなく、通常の点のブローアップと違って特異点が残る。中心を一つの原点という台だけで指定すると、この非対称な局所環は再現できない。
:::

### 二つの正則な生成元で Rees 代数を表示する

:::proposition[二元の正則列の Rees 代数]{#prop-ag-rees-two-regular}
環 $A$ の元 $f,g$ が正則列をなし、$I=(f,g)$ とする。$U\mapsto fT,V\mapsto gT$ は
$$
A[U,V]/(fV-gU)\simeq \mathcal R(I)
$$
を与える。
:::

:::proof
全射性と関係式は定義で分かる。核の斉次式 $H$ の次数を $d$ とし、$V^d$ の係数を $h$ とする。$H(f,g)=0$ を $f$ で割った環へ移すと $hg^d=0$ である。$g$ は $A/(f)$ の非零因子なので $h=fh'$ と書ける。$h'V^{d-1}(fV-gU)$ を $H$ から引くと $V^d$ の項が消える。残りは $U$ の倍数 $UH_1$ である。その評価は $fH_1(f,g)=0$ であり、$f$ は $A$ の非零因子なので $H_1(f,g)=0$ である。次数が一つ下がるからこの操作を繰り返せる。次数零の核は零である。従って核の全斉次成分は $(fV-gU)$ に属し、同型を得る。
:::

:::example[対称代数にある余分な例外点を除く]
$A=k[x,y]$ の $I=(x^2,xy,y^2)=(x,y)^2$ を取る。基点の原点の剰余体へ移すと、$I/(x,y)I$ には $x^2,xy,y^2$ の三基底がある。従って対称代数の原点への制限の Proj は $\mathbb P^2$ となる。一方 Rees 代数では三生成元に対応する $U,V,W$ に $V^2=UW$ がある。原点上の次数 $d$ の環は $(x,y)^{2d}/(x,y)^{2d+1}$ であり、次数 $2d$ の単項式が基底である。従って例外ファイバー全体は二次 Veronese の円錐曲線である。ブローアップでは、生成元の間の線形関係だけでなく、実際の積による二次の関係も保持する必要がある。
:::

### 局所表示が空になる場合を含めて普遍性を使う

:::example[中心が全空間か空集合か]
$I=0$ の Rees 代数では正次数部分が零であるため、Proj は空である。任意の非空な $Y$ 上で引き戻した零イデアルが可逆になることはないから、普遍性とも一致する。一方 $I=A$ では Rees 代数は $A[T]$ になり、標準開 $D_+(T)$ の次数零環は $A$ である。従ってブローアップは恒等である。$I=(a)$ が非零因子一つで生成される場合も $T\mapsto aT$ は次数ごとに単射を保つため Rees 代数は $A[T]$ と同じである。中心が空集合でなくても、既に可逆なイデアルを可逆にする空間は元のままである。
:::

## 例外因子と固有変換

ブローアップ上で $\mathcal I\mathcal O$ が定める有効 Cartier 因子を :term[例外因子]{en="exceptional divisor" yomi="れいがいいんし"} と呼ぶ。$Z$ の外では $\mathcal I=\mathcal O$ であり、Rees 代数は $\mathcal O[T]$ なので射は同型である。閉部分スキームの $Z$ の外の逆像のスキーム論的閉包を固有変換と呼ぶ。アフィン近傍で例外因子の式が $f_i$、全変換のイデアルが $J$ なら、固有変換のイデアルは $J:f_i^\infty$ である。これは $J$ を局所化した後に元の環に引き戻したイデアルであり、逆像の外側を変えずに最大のイデアルを取るからである。

:::proposition[固有変換と閉部分のブローアップ]
閉部分スキーム $Y\subset X$ の固有変換は、$Y$ 上の拡大イデアル $\mathcal I\mathcal O_Y$ に沿うブローアップと同型である。
:::

:::proof
アフィンの環を $A$、$Y$ の環を $B=A/J$ とする。$f_i$ に対応する比の環 $A[I/f_i]$ で、中心の外は $D(f_i)$ である。ここで $f_i$ を逆にすると環は $A_{f_i}$ になり、その上にある $Y$ の逆像の環は $B_{f_i}$ である。よってこの逆像の閉包の環は $A[I/f_i]\to B_{f_i}$ の像である。その像は $B$ と $I$ の各元の像を $f_i$ の像で割った比が生成し、ちょうど $Y$ のブローアップの標準開の環になる。$B_{f_i}$ が零の場合にはどちらも空である。比の写像は重なりでさらに同じ比を逆にする操作と可換なので、これらの同型は全体で貼り合う。
:::

:::example[原点のブローアップ]
$I=(x,y)$ では比の開は $k[x,y/x]=k[x,t]$（$y=xt$）と $k[y,x/y]=k[y,u]$（$x=yu$）である。例外因子はそれぞれ $x=0$、$y=0$ で、重なりで $u=t^{-1}$ なので $\mathbb P^1$ である。曲線 $y-x^2$ の全変換は第一開で $x(t-x)=0$ であり、飽和で $t-x=0$ を得る。曲線の固有変換は例外因子と $(x,t)=(0,0)$ で横断する。
:::

### 全変換の係数を読み取る

:::example[例外曲線に二次の交点が残る]
$y^2-x^3=0$ を $y=xt$ の開で引き戻すと $x^2(t^2-x)=0$ になる。全変換の例外係数は $2$、固有変換は $x=t^2$ である。例外直線との交わりでは $x=0$ も課すため $k[t]/(t^2)$ が残る。従って固有変換自体が滑らかになることと、例外直線との交わりが横断することは異なる。
:::

:::example[軸の固有変換は分離する]
$xy=0$ をブローアップする。$y=xt$ の開では $x^2t=0$ で、固有変換は $t=0$ である。$x=ys$ の開では $y^2s=0$ で、固有変換は $s=0$ である。重なりでは $s,t$ がともに可逆なので、これら二つの固有変換は重ならない。例外直線では二枝がそれぞれ $[1:0]$、$[0:1]$ を通る。
:::

### 例外因子の可逆層の符号を確認する

:::proposition[ブローアップのねじり層と例外因子]{#prop-ag-exceptional-twist}
$X'=\operatorname{Bl}_{\mathcal I}X$ の例外因子を $E$ とすると、Rees 代数の $\mathcal O_{X'}(1)$ は $\mathcal I\mathcal O_{X'}=\mathcal O_{X'}(-E)$ に同型である。
:::

:::proof
$f_iT$ の標準開で、Rees 代数のねじり層 $\mathcal O(1)$ の基底を $f_iT$ と書く。同じ開で $\mathcal I\mathcal O$ の生成元は $f_i$ であり、基底を対応させられる。重なりでの比は $(f_jT)/(f_iT)=f_j/f_i$ である。これはイデアルの基底の比と同じなので、局所同型が貼り合う。$E$ はこのイデアルで定まる有効 Cartier 因子だから、イデアル層自体は $\mathcal O(-E)$ である。従って $\mathcal O(E)$ は負のねじり層に対応する。
:::

:::example[原点のブローアップで例外直線の法束を求める]
$\mathbb A^2$ の原点のブローアップで、局所式は第一開で $x$、第二開で $y$ である。重なりで $y=t x$ だから $\mathcal O(-E)$ の基底の移行は $t$ である。例外直線に制限すると座標 $t$ と $1/t$ の貼り合わせであるため、これは $\mathcal O_{\mathbb P^1}(1)$ である。従って $\mathcal O(E)|_E=\mathcal O_{\mathbb P^1}(-1)$ になる。例外因子を太くする局所式は $x^2,y^2$ となり、移行は $t^2$ である。これらの違いは後に曲面の自己交点を法束の次数として計算する際に使う。
:::

### 固有変換と代入した全変換を比較する

:::example[二重の接方向は例外因子上にも残る]
$C:y^2-x^2(1+x)=0$ を標数零でブローアップする。$y=xt$ を入れると $x^2(t^2-1-x)=0$ で、例外係数は二である。固有変換の $x=0$ への制限は $t^2-1=0$ となり、二つの異なる点に各一の重みがある。一方 $C':y^2-x^3=0$ では $x^2(t^2-x)=0$ となり、例外係数は同じ二だが、例外因子との交わりは $t^2=0$ で一点の長さ二である。従って全変換の例外係数が等しくても、固有変換の方向とその接触は異なる。
:::

:::example[非主イデアルの固有変換では全体で飽和する]
平面の有限部分を $Z: (y,x^2)$ で取る。原点のブローアップの第一開では全変換のイデアルは $(xt,x^2)$ である。その $x$ による飽和は単位イデアルである。実際 $x^2$ がすでに入るので $1$ まで飽和に入る。もう一方の開でも $y$ が第一の生成元の像なので飽和は単位イデアルである。従って固有変換は空であり、全変換は例外因子上にだけ残る。本来の $Z$ は中心の外に点を持たないため、固有変換が空になるのは閉包の定義とも一致する。各生成元を個別に共通因子で割るだけでは、飽和で $1$ が入る段階を見落とす場合がある。
:::

### 解消後の写像が引き戻す超平面束

:::proposition[基点の例外因子を除いた線形系]
$\mathcal L$ の切断の組が基点イデアル $\mathcal I$ を定めるとする。ブローアップ $\pi:X'\to X$ の上でそれらの引き戻しは $\pi^*\mathcal L\otimes\mathcal O_{X'}(-E)$ を生成する。従って解消した射 $h:X'\to\mathbb P^n$ に対し
$$
h^*\mathcal O(1)=\pi^*\mathcal L\otimes\mathcal O_{X'}(-E)
$$
である。
:::

:::proof
$X$ の自明化開で切断の係数を $f_i$ とする。ブローアップで $\mathcal I\mathcal O$ が $a$ により生成される開では、各引き戻しは $a b_i$ の形になる。$a$ は非零因子であり $a$ 自身が $a b_i$ の線形結合なので、約分して $\sum_i c_i b_i=1$ を得る。従って $b_i$ の少なくとも一つが各点で単元である。$\pi^*\mathcal L$ の局所基底に $a$ を掛けたものが $\pi^*\mathcal L\otimes\mathcal O(-E)$ の局所基底であり、引き戻した切断のこの基底での係数は $b_i$ である。従って生成切断による射の定理を使える。基点の外では $a$ は単元で比は元と同じなので、これが所定の解消した射である。
:::

:::example[一点から射影するときの引き戻し]
$\mathbb P^2$ の点 $p=[0:0:1]$ からの射影 $[X:Y:Z]\dashrightarrow[X:Y]$ を考える。基点イデアルは $p$ の極大イデアルであり、ブローアップ後の引き戻しは $\pi^*\mathcal O(1)\otimes\mathcal O(-E)$ である。$Z=1$ の開で $y=xt$ と置くと、切断の係数は $x,xt$ であり $x$ を共通に除いて $1,t$ を得る。例外直線上でもこの比が定義され、$E$ を標的の $\mathbb P^1$ へ同型に送る。従って「例外因子」という名は $\pi$ がその曲線を縮めることを指す。別の射 $h$ に対しては例外直線が全ての方向を区別するファイバーの基底となる。
:::

## 例：射影空間の自己同型群

:::theorem[射影空間の自己同型]{#thm-ag-aut-projective-space}
代数閉体 $k$ と $n\ge1$ に対し、$\Aut_k(\mathbb P^n_k)=\operatorname{PGL}_{n+1}(k)$ である。
:::
:::proof
自己同型は :ref[cor-ag-pic-projective] の無限巡回群の生成元を $\mathcal O(1)$ または $\mathcal O(-1)$ に移す。引き戻しは大域切断を保ち、$\mathcal O(1)$ には非零切断がある。$\mathcal O(-1)$ にはない。実際、各点を通る射影直線に制限するとねじり層の移行係数により $\mathcal O_{\mathbb P^1}(-1)$ となり、切断は零である。したがって全点で零になり、被約性によって元の切断も零である。

$\mathcal O(1)$ の切断は一次斉次式である。標準開での斉次分数を同じ次数一の Laurent 多項式とみなすと、全ての開で正則である条件は、どの変数の指数も非負であることである。従って座標式が基底となる。自己同型と $\mathcal O(1)$ との同型を選ぶと、この切断空間上の作用は正則行列となる。逆に正則行列は生成条件を保ち、逆行列が逆射を与える。可逆層の同型の選択は大域単元 $k^\times$ だけ異なる。これは大域正則関数が定数だからである。従って行列は非零スカラー倍を除き一意である。
:::

### 射影変換の行列と固定点

:::example[三点で射影直線の変換を決める]
標数零で $t=0,1,\infty$ を順に $1,0,\infty$ に移す変換を求める。$\infty$ を固定する分数一次式は $at+b$（$a\ne0$）である。$b=1$、$a+b=0$ から $t\mapsto1-t$ が一意に決まる。これは $[X:Y]\mapsto[X:X-Y]$ であり、行列の行列式は $-1$ なので自己同型である。二回合成で $1-(1-t)=t$ に戻る。
:::

:::example[線形変換と高次数の全域射]
$\mathbb P^2$ の $[X:Y:Z]\mapsto[Y:Z:X]$ は置換行列で与えられ、三回で恒等となる。これに対して $[X:Y:Z]\mapsto[X^2:Y^2:Z^2]$ は全点で定義されるが、標数零で $[1:1:1]$ と $[1:-1:1]$ が同じ点に写る。引き戻しでも前者は $\mathcal O(1)$、後者は $\mathcal O(2)$ となり、この Picard 群上の差からも後者が自己同型でないと分かる。
:::

### 射影変換の固定点を固有ベクトルで読む

:::proposition[固定点と固有空間]
体 $k$ 上で $M$ を可逆な $(n+1)\times(n+1)$ 行列とする。拡大体 $K/k$ 上の固定点は、$K$ 上の固有ベクトルの張る一次元部分空間である。幾何学的な固定点の全体を求めるには、代数閉包上で各固有空間を射影化して合わせればよい。
:::

:::proof
$[v]$ が固定されることは $Mv=\lambda v$ を満たす $\lambda\ne0$ が存在することと同値である。$M$ の可逆性により零の固有値は現れない。この方程式は代表のスカラー倍に両立する。逆に任意の固有ベクトルはこの式を満たすので対応する射影点が固定される。各固有空間の射影化を合わせると全て得られる。これは固定点の集合についての判定であり、対角を引き戻した固定点スキームには重複が残る場合がある。
:::

:::example[固定点の台は一点でも厚みが二つある]
標数零で $\mathbb P^1$ の $t\mapsto t+1$ を考える。有限点で $t+1=t$ は成り立たず、唯一の固定点は無限遠である。逆座標 $s=1/t$ では変換が $s\mapsto s/(1+s)$ なので、無限遠の近くで固定点の式は $s/(1+s)-s=-s^2/(1+s)=0$ である。分母は単元だから固定点スキームの局所長さは二である。行列の固有空間の次元一は固定点の台が一点であることを示すが、局所式の二重根まではこの次元だけから読めない。
:::

### 三点を移す射影直線の自己同型を構成する

:::example[指定した三点を固定座標に正規化する]
標数零で $0,2,3$ を順に $\infty,0,1$ に移す自己同型を求める。最初の二条件から分子は $t-2$、分母は $t$ の定数倍になる。$t=3$ で値を $1$ とするには倍率が $3$ なので $u=3(t-2)/t$ である。逆を解くと $t=6/(3-u)$ となる。例えば $t=4$ の像は $3/2$ であり、これを逆へ代入すると $4$ に戻る。三つの点を固定する自己同型は恒等である。実際、正規化後の $\infty,0$ を固定する式は $u\mapsto c u$ であり、さらに $1$ を固定するには $c=1$ が必要である。
:::

### 射影行列が指定した部分空間を保つ条件

:::example[一点と超平面の固定をブロックで読む]
$\mathbb P^n$ の $p=[1:0:\cdots:0]$ を固定する行列は、第一列が $(a,0,\dots,0)^t$（$a\ne0$）である。従ってブロック表示では $\begin{pmatrix}a&b\\0&C\end{pmatrix}$ となり、$C$ は可逆である。さらに $X_0=0$ の超平面全体も保つなら、そこからの任意のベクトル $(0,v)$ の第一成分が $bv=0$ であるため $b=0$ となる。例えば標数零で $\mathbb P^2$ の $C=\operatorname{diag}(2,3)$、$a=1$ とすると、$p$ を通る直線の方向は $[Y:Z]\mapsto[2Y:3Z]$ へ移る。$p$ 自体の固定と、そこを通る任意の直線の固定は別であり、後者には $C$ がスカラー行列である条件が要る。
:::

:::example[円錐曲線の上で Veronese 座標の作用を作る]
$\mathbb P^1$ の $[s:t]\mapsto[s:s+t]$ は二次斉次式の三基底に作用する。$X=s^2,Y=st,Z=t^2$ と置けば $X$ は $X$、$Y$ は $X+Y$、$Z$ は $X+2Y+Z$ へ移る。従って $\mathbb P^2$ の可逆行列による変換になり、二次式は
$$
X(X+2Y+Z)-(X+Y)^2=XZ-Y^2
$$
と保たれる。逆変換は $t\mapsto t-s$ から得られ、曲線の自己同型と周囲の射影変換が対応する。一般に $\mathcal O(d)$ の全切断を使うと、射影直線の変換が次数 $d$ の単項式の線形変換として実現される。
:::

## 演習問題

::::exercise{level=basic}
$\mathcal O(2)$ の切断 $s^2,t^2$ の共通零点を求めよ。

:::solution
共通零点なら $s=t=0$ になるが、それは射影座標では許されない。従って二切断は全点で生成する。
:::
::::

::::exercise{level=basic}
$\mathbb P^2$ の切断 $X,Y$ の基点を求めよ。

:::solution
$X=Y=0$ より基点は $[0:0:1]$ だけである。$Z=1$ でのイデアルは座標二つを生成するので被約な点である。
:::
::::

::::exercise{level=basic}
ブローアップの $y=xt$ の開で $y^2-x^3$ の固有変換を求めよ。

:::solution
引き戻しは $x^2(t^2-x)$ である。$x$ を可逆にしてから戻すと $(t^2-x)$ になる。商は $k[t]$ で $x=t^2$ は非零因子なのでこれ以上飽和で変化しない。
:::
::::

::::exercise{level=basic}
$\mathbb P^1$ で行列 $\left(\begin{smallmatrix}1&2\\0&1\end{smallmatrix}\right)$ の逆射を求めよ。

:::solution
像は $[s+2t:t]$ なので、第一成分から第二成分の二倍を引く $[u-2v:v]$ が逆射である。
:::
::::

::::exercise{level=advanced}
可逆イデアルに沿うブローアップが恒等であることを示せ。

:::solution
イデアルが非零因子 $f$ 一つで生成される開では Rees 代数は $A[U]$ に $U\mapsto fT$ で同型である。Proj は $D_+(U)$ 一つで覆われ、その次数零環は $A$ である。局所同型は構造射なので貼り合う。
:::
::::

::::exercise{level=advanced}
$\mathbb A^2$ の原点のブローアップで $xy=0$ の固有変換を二開で求めよ。

:::solution
$y=xt$ では全変換 $x^2t=0$ から $x$ で飽和して $t=0$ となる。$x=yu$ では同様に $u=0$ となる。重なりでは $t,u$ は可逆なので固有変換の二成分は交わらない。
:::
::::

::::exercise{level=advanced}
$\mathbb P^1$ 上の写像 $[s:t]\mapsto[s^3:s^2t:st^2:t^3]$ が引き戻す直線束を求めよ。

:::solution
四切断は $\mathcal O(3)$ に属し、$s,t$ の片方が非零なので常に生成する。:ref[thm-ag-projective-sections] により引き戻しは $\mathcal O(3)$ である。
:::
::::

::::exercise{level=advanced}
原点のブローアップの例外因子 $E$ の $\mathcal O(E)$ を $E$ に制限せよ。

:::solution
イデアル $\mathcal O(-E)$ の局所基底は第一開で $x$、第二開で $y=tx$ である。例外因子に制限した二基底も比が $t$ なので、$\mathcal O_{\mathbb P^1}(1)$ の移行係数に一致する。双対を取ると $\mathcal O(E)|_E=\mathcal O_{\mathbb P^1}(-1)$ である。
:::
::::

::::exercise{level=advanced}
平面の有限部分スキーム $Z=V(x^2,y^3)$ に沿うブローアップを二開で表示せよ。$Z$ 上の例外因子と原点の剰余体上のファイバーをそれぞれ求め、二つの中心 $V(x,y)$ と $Z$ に沿うブローアップがどちらも滑らかか判定せよ。基礎体は標数零の代数閉体とする。

:::solution
$x^2$ は平面の座標環の非零因子である。また $k[x,y]/(x^2)=k[y]\oplus xk[y]$ では $y^3$ は各成分への乗法について単射であり、二生成元は正則列をなす。そこで :ref[prop-ag-rees-two-regular] により Rees 代数は $k[x,y,U,V]/(x^2V-y^3U)$ となる。次数一の $U,V$ は順に $x^2T,y^3T$ に写る。$D_+(U)$ では $u=V/U$ を加えた $k[x,y,u]/(x^2u-y^3)$、$D_+(V)$ では $v=U/V$ を加えた $k[x,y,v]/(x^2-y^3v)$ である。前者で $I$ の引き戻しは $(x^2)$、後者では $(y^3)$ である。

従って例外因子を計算するには前者の環で $x^2=0$、後者で $y^3=0$ を加える。関係式から他方の生成元も零になり、二開の商はそれぞれ $k[x,y,u]/(x^2,y^3)$、$k[x,y,v]/(x^2,y^3)$ となる。重なりで $v=u^{-1}$ であり、基底の変数 $x,y$ は共通なので、例外因子は $Z\times\mathbb P^1$ と同型である。一方原点の剰余体へ移すには $x,y$ 自体をともに零にするため、二開は $k[u], k[v]$ となり、ファイバーは被約な $\mathbb P^1_k$ である。長さ六の基礎スキーム $Z$ の厚みは例外因子に残る。

第一の開の式 $x^2u-y^3$ の偏導関数は $2xu,-3y^2,x^2$ であり、$x=y=0$ で全て消える。式は非零な既約式である。実際 $u$ について一次で係数の最大公約因子は単元なので、$k(x,y)[u]$ で一次であることと Gauss の補題を使える。従ってこの超曲面は次元二であるが、原点のファイバー上で接空間は三次元となり、滑らかでない。反対に $V(x,y)$ でブローアップすると標準開は $k[x,y,u]/(xu-y)=k[x,u]$ と $k[x,y,v]/(x-yv)=k[y,v]$ で、一方の基底座標を消去できる。両開が滑らかなので全体も滑らかである。この比較では、剰余体上のファイバーが同じ射影直線でも、周囲の局所環は変わる。
:::
::::

::::exercise{level=advanced}
標数零で $\mathbb P^1$ の変換 $M([s:t])=[2s+t:s+t]$ を二次 Veronese 円錐曲線へ移せ。三次元の座標行列を求め、曲線の周囲でも可逆であることと二次方程式を保つことを直接示せ。点 $[4:2:1]$ の像を求め、逆変換で確認せよ。

:::solution
$X=s^2,Y=st,Z=t^2$ として、三つの積を展開する。
$$
\begin{aligned}
X'&=(2s+t)^2=4X+4Y+Z,\\
Y'&=(2s+t)(s+t)=2X+3Y+Z,\\
Z'&=(s+t)^2=X+2Y+Z.
\end{aligned}
$$
この係数行列の第一行で余因子展開すると、行列式は $4(3-2)-4(2-1)+(4-3)=1$ である。元の行列の逆は $[s':t']\mapsto[s'-t':-s'+2t']$ なので、周囲の逆は
$$
[X':Y':Z']\longmapsto
[X'-2Y'+Z':-X'+3Y'-2Z':X'-4Y'+4Z']
$$
となる。三つの式は同じ展開で得られ、二つの係数行列の積が単位行列になることも確かめられる。

曲線の式の不変性は、対称行列 $Q=\left(\begin{smallmatrix}X&Y\\Y&Z\end{smallmatrix}\right)$ を使うと確かめられる。ここでは $M$ を $[s:t]$ の変換を表す二次行列とする。新座標の対称行列は $M Q M^{\mathsf t}$ であるため、行列式の乗法性により $X'Z'-(Y')^2=(\det M)^2(XZ-Y^2)=XZ-Y^2$ となる。従って周囲の変換は部分スキームのイデアルを保つ。

最後に $[4:2:1]$ は $[2:1]$ に対応する。元の変換で $[2:1]\mapsto[5:3]$ となるから、求める像は $[25:15:9]$ である。逆の三式へ代入すると、第一成分は $25-30+9=4$、第二成分は $-25+45-18=2$、第三成分は $25-60+36=1$ となる。剰余体上の点の検算と、周囲の同型としての証明はこのように両方行える。
:::
