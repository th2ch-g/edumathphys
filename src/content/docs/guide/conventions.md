## 定理環境と番号

本文では次の環境を用いる。番号は「章番号.通し番号」で、定義・定理・命題・補題・系・例などは**共通の通し番号**を持つ。式番号と演習番号はそれぞれ別に数える。

:::definition[定義の例]
新しい概念を導入する。太字の語が定義される用語で、括弧内は対応する英語である。
:::

:::theorem[定理の例]
重要な結果を述べる。命題・補題・系も同様の枠で表示される。
:::

:::proof
証明は「証明.」で始まり、末尾の ∎ で終わる。
:::

:::example
具体例や計算例を示す。
:::

:::remark
補足や注意を述べる（番号は付けない）。
:::

$$
e^{i\pi} + 1 = 0 \label{eq-guide-euler}
$$

式番号は右端に表示され、本文からは :eqref[eq-guide-euler] のように参照される。

## 数学の記号

| 記号 | 意味 |
|---|---|
| $\N, \Z, \Q, \R, \C$ | 自然数（1 から始まる）・整数・有理数・実数・複素数全体 |
| $\K$ | 係数体（主に $\R$ または $\C$） |
| $A \subset B$ | $A$ は $B$ の部分集合（等号の場合を含む） |
| $\defeq$ | 左辺を右辺で定義する |
| $\transp{A}, \adj{A}$ | 行列の転置、随伴（共役転置） |
| $\Ker f, \Img f$ | 線形写像の核と像 |
| $\inner{x}{y}$ | 内積（数学の科目では第 1 引数について線形） |

各科目に固有の記号は、科目のトップページの「記法と規約」と[記号表](/notation/)にまとめてある。

## 物理の規約

- 単位系は原則として SI 単位系を用いる。
- 量子力学では Dirac 記法 $\braket{\phi}{\psi}$ を用い、内積は**第 2 引数（ケット）について線形**である。数学の科目の内積とは線形性の位置が逆なので注意すること。
- 特殊相対論・一般相対論では計量の符号を $(-,+,+,+)$、場の量子論と素粒子物理では $(+,-,-,-)$ とする。いずれも各科目の冒頭で改めて宣言する。
- 場の量子論以降では自然単位系 $\hbar = c = 1$ を用いる。

## 演習と確認テスト

- **演習**には「基本」「発展」の区別がある。解答は折りたたまれているので、まず自力で解いてから開くこと。
- **確認テスト**は選択式または数値入力式で、「答え合わせ」を押すと正誤と解説が表示される。結果はブラウザに保存され、[学習進捗](/progress/)に反映される。
