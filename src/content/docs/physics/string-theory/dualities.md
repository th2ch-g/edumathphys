## この章の目標

- 強結合で軽くなる BPS 励起を調べる。
- Type IIB の結合と電荷の変換を求める。
- D0 と円周運動量、M2 と M5 の縮約を対応させる。
- ヘテロティック弦と Type I 弦の低エネルギー場を対応させる。

## 強結合の超弦理論

閉弦の種数を一つ上げると $g_s^2$ が掛かる。$g_s$ が大きくなると個々の種数から全振幅を近似できなくなる。一方 :eqref[eq-string-dp-tension] によれば D ブレインの張力は弦の単位で $1/g_s$ に比例する。例えば D0 の質量 $1/(g_s\ell_s)$ は $g_s=10$ なら $M_s/10$ である。強結合に向かうとこのような状態を取り入れた変数が必要になる。超対称性代数の BPS 限界で電荷と質量が結ばれれば異なる結合で状態を比較できるが、一般の非 BPS 質量は同じ方法だけでは追跡できない。

### 重いソリトンが軽くなる二つの比

摂動的な F1 は $T_{\rm F1}=1/(2\pi\ell_s^2)$、D1 は $T_{\rm D1}=T_{\rm F1}/g_s$ である。これは弦フレームでの比であり、両方を同じ Einstein フレームに移しても比は保たれる。NS5 の弦フレーム張力は $1/[(2\pi)^5g_s^2\ell_s^6]$、D5 は同じ式で $g_s^{-1}$ である。前者の結合の冪は NS–NS 作用の $e^{-2\Phi}$ と整合する。これらは質量で比較するには同じ内部体積に巻くか、張力同士を比較する必要がある。

:::example[十次元での結合の反転]
元の理論で $g_s=5$ なら $T_{\rm D1}/T_{\rm F1}=1/5$、$T_{\rm NS5}/T_{\rm D5}=1/5$ である。$g_s'=1/5$ では $T'_{\rm F1}/T'_{\rm D1}=1/5$ である。同じ Einstein フレームで弦と五ブレインの電気・磁気電荷の組が入れ替わる。
:::

:::example[電荷を固定したループ展開]
閉弦四点で球面の重みは $g_s^2$、種数 1 は $g_s^4$ であり比は $g_s^2$ である。$g_s=1/4$ で比は $1/16$、$g_s=4$ で 16 となる。この次数比較は固定した外状態についてのものであり、二理論の外状態が双対性でどう移るかは別に指定する。
:::

### 摂動の次数と非摂動の作用

向き付けられた閉じた世界面に種数 $h$ と正規化した閉弦の外線が $n$ 本あるとする。定数ディラトンの項と各頂点の結合を合わせると、寄与の全体の冪は $g_s^{2h-2+n}$ である。境界 $b$ 個を持つ面では Euler 標数が $2-2h-b$ に変わり、外線のある場合は各頂点の規格化も指定する。従って「結合が強い」とは、固定した外状態についてこの展開の低い次数だけで制御できなくなるという意味である。さらに $N$ 枚の D ブレインがあれば境界の Chan–Paton 跡が $N$ を与える場合がある。閉弦ループを $g_s$ で抑えられても開弦の境界の追加が有効に $g_sN$ で重くなることがあり、平坦背景での枚数を固定した展開の判定と区別する。

Euclid D$p$ が体積 $V_{p+1}$ の周期に巻くなら定数ディラトンの古典作用は $A/g_s$、$A=V_{p+1}/[(2\pi)^p\ell_s^{p+1}]>0$ である。RR ポテンシャルの積分は位相を与える。$g_s\to0^+$ では、任意の整数 $m\ge0$ について $g_s^{-m}e^{-A/g_s}\to0$ になる。実際 $x=A/g_s$ と置くと $x^m e^{-x}/A^m$ に帰着する。従って $e^{-A/g_s}$ の効果はどの有限次数の種数展開にも現れない。強弱双対性を考えるとき、元の変数で指数的に小さい効果が、変換した変数で同じように小さいとは限らない。

:::example[点状の Euclid D ブレイン]
$p=-1$ を形式的に張力の式へ入れると $T_{-1}=2\pi/g_s$ である。この章の軸子の向きで電荷 $+1$ とし、軸子の周期を 1 とすると寄与は $e^{-2\pi/g_s+2\pi i C_0}=e^{2\pi i\tau}$ になる。反インスタントンでは位相が逆で、作用の実部は同じである。例えば $C_0=1/4$ では前者の位相は $i$、後者は $-i$ である。全ての振幅でこの一単位の寄与が非零になるとは限らず、どの観測量がフェルミオン零モードを飽和するかも調べる必要がある。
:::

### 双対比較で同じ物差しを選ぶ

弦フレームの $G_{\rm str}$ は基本弦の σ 模型に現れ、Einstein フレーム $G_E=e^{-\Phi/2}G_{\rm str}$ は重力作用の標準形に現れる。一定の $\Phi$ なら、世界体積が $p+1$ 次元の物体について同じ幾何学的な作用は $T_p^{E}=e^{(p+1)\Phi/4}T_p^{\rm str}$ を要求する。実際、誘導計量の行列式を平方根にすると、一方向につき $e^{\Phi/4}$ が掛かる。粒子質量では一方向、弦張力では二方向の因子を使う。IIB の $S$ が保つのは Einstein フレームであり、変換前後の弦フレームの数値をそのまま比較すると重力の単位が揃わない。

:::example[五ブレインの張力の交換]
定数軸子がゼロのとき、D5 と NS5 の Einstein フレームの張力は共通の $[(2\pi)^5\ell_s^6]^{-1}$ に対し $g_s^{1/2}$ と $g_s^{-1/2}$ になる。従って $g_s=9$ の D5 は $g'_s=1/9$ の NS5 と同じ値を持つ。同じ円周に巻いた粒子として比べる場合は、両側で Einstein フレームの体積を掛ける必要がある。
:::

## Type IIB 理論の S 双対性

$\tau_{\mathrm{IIB}}=C_0+ie^{-\Phi}$ とする。Einstein フレームでのこのスカラーの計量は $\dd\tau\dd\bar\tau/(2(\Im\tau)^2)$ である。$\tau'=(a\tau+b)/(c\tau+d)$、$ad-bc=1$ とすると $\dd\tau'=\dd\tau/(c\tau+d)^2$、$\Im\tau'=\Im\tau/|c\tau+d|^2$ なので不変である。古典連続群のうち、整数に量子化された電荷の格子を保つ変換が $\operatorname{SL}(2,\Z)$ である。$C_0=0$ で $S:\tau\mapsto-1/\tau$ とすると $g_s'=1/g_s$ となる。量子論全体でこれが双対性になるという主張には非摂動的な入力が必要であり、BPS スペクトルと超重力解による検査は :cite[bbs-string] を参照する。

Einstein フレームを $G_E=e^{-\Phi/2}G_{\mathrm{str}}$ とし、F1 と D1 の電荷を $(p,q)$ で表す。符号規約を $p+q\tau$ と取ると BPS 張力は
$$
T_{p,q}^{E}=\frac1{2\pi\alpha'}\frac{|p+q\tau|}{\sqrt{\Im\tau}}.
\label{eq-string-pq-tension}
$$
$C_0=0$ の F1 と D1 の値はそれぞれ $g_s^{1/2}/(2\pi\alpha')$ と $g_s^{-1/2}/(2\pi\alpha')$ である。弦の面積をフレーム変換すると $e^{\Phi/2}$ が掛かるため、弦フレームの張力と一致する。一般の変換では $p'+q'\tau'=(p+q\tau)/(c\tau+d)$ と定める。係数を比較すると $p'=ap-bq$、$q'=-cp+dq$ であり、整数電荷の組と張力を保つ。$S$ では $(p,q)\mapsto(q,-p)$ になる。例えば $\tau=i$、$(p,q)=(3,4)$ の張力は F1 の 5 倍である。

### 整数電荷の変換で張力を保つ

張力を $|p+q\tau|/(2\pi\alpha'\sqrt{\Im\tau})$ とする規約では、$p'=ap-bq$、$q'=-cp+dq$ と変換する。実際、$p'+q'\tau'=[(cp'+aq')\tau+(dp'+bq')]/(c\tau+d)=(p+q\tau)/(c\tau+d)$ である。$\sqrt{\Im\tau'}=\sqrt{\Im\tau}/|c\tau+d|$ なので張力は不変である。$T$ では $\tau\mapsto\tau+1$、$(p,q)\mapsto(p-q,q)$ であり、軸子を単に変えて電荷を固定する操作とは異なる。

:::example[軸子を含む電荷の比較]
$\tau=1/2+i$、$(p,q)=(1,2)$ なら $p+q\tau=2+2i$ であり、無次元張力 $2\pi\alpha'T=2\sqrt2$ である。$T$ で $\tau'=3/2+i$、$(p',q')=(-1,2)$ となり、同じ $2+2i$ を得る。
:::

:::example[束縛の三角不等式]
$\tau=i$ で $(1,0)$ と $(0,1)$ の張力は各 1 単位だが、$(1,1)$ は $\sqrt2$ 単位である。どちらの電荷も非零で、一方が他方の正の実数倍でない限り、$|z_1+z_2|<|z_1|+|z_2|$ である。従って同じ総電荷を持つ別々の直線の張力を足すと、BPS の下限より大きい値になる。
:::

### 二つの電荷を一つの射影に組み合わせる

軸子ゼロで平行に張った F1 と D1 の超対称性射影は、共通の $\Gamma^{01}$ に Type IIB の二つの超電荷の添字へ作用する別々の Pauli 行列を掛けて書ける。符号の向きを選んで $A=\Gamma^{01}\sigma_3$、$B=\Gamma^{01}\sigma_1$ と置けば $A^2=B^2=1$、$\{A,B\}=0$ である。$Z_F=pT^E_{\rm F1}$、$Z_D=qT^E_{\rm D1}$ とする。中心電荷の行列 $\mathcal Z=Z_F A+Z_D B$ は
$\mathcal Z^2=(Z_F^2+Z_D^2)I$
を満たす。トレースはゼロなので、非零の電荷では二つの固有値が同数となる。正の超電荷反交換式から $T^E\ge\sqrt{Z_F^2+Z_D^2}$ であり、飽和した状態には $(\mathcal Z/\sqrt{Z_F^2+Z_D^2})\epsilon=\epsilon$ の一つの射影がかかる。$T_{\rm F1}^E=\sqrt{g_s}/(2\pi\alpha')$、$T_{\rm D1}^E=1/(2\pi\alpha'\sqrt{g_s})$ とすれば、:eqref[eq-string-pq-tension] の $C_0=0$ に一致する。

別々の射影 $A\epsilon=\epsilon$ と $B\epsilon=\epsilon$ を同時に課すと、$AB\epsilon=\epsilon$ と $BA\epsilon=\epsilon$ が反交換性と矛盾する。束縛した弦は、二つの独立な射影を満たすのではなく中心電荷の和で定まる一つの射影を保つ。

:::example[電荷の比から射影を選ぶ]
$g_s=1$、$(p,q)=(3,4)$ なら $\mathcal Z/T=(3A+4B)/5$ である。二乗は $9/25+16/25=1$ なので $(1+\mathcal Z/T)/2$ は階数 16 の射影である。張力は $5/(2\pi\alpha')$ になり、分離した二スタックの張力 $7/(2\pi\alpha')$ より小さい。
:::

### 三形式の組まで作用を変換する

:eqref[eq-string-iib-pseudo-action] では三形式の運動項の和を $-|F_3-\tau H_3|^2/(2\Im\tau)$ と書ける。絶対値は複素共役と時空計量の両方を使う縮約である。二成分を $(C_2,B_2)^\mathsf T$ の順に取り、$M=\begin{pmatrix}a&b\\c&d\end{pmatrix}$ を左から掛けると
$$
F_3'-\tau'H_3'=\frac{F_3-\tau H_3}{c\tau+d}
$$
である。分子に $c\tau+d$ を掛けて $ad-bc=1$ を使えば得られる。従って運動項はスカラーの計量と同じ理由で不変である。また
$$
F_5=\dd C_4+\tfrac12(B_2\wedge F_3-C_2\wedge H_3)
$$
の括弧は二成分の反対称積であり、行列式 1 によって不変である。$H_3'\wedge F_3'=(da-cb)H_3\wedge F_3$ は三形式同士の交換の符号から従う。よって $C_4$ と Einstein 計量を固定すれば擬作用と自己双対性の条件が保たれる。

弦の電気結合を $\int(q C_2+p B_2)$ と書く。二形式が $M$ で変わるとき、電荷の行ベクトル $(q,p)$ は右から $M^{-1}$ を掛ける。この規約では新しい電荷は $(q',p')=(dq-cp,ap-bq)$ であり、張力の式と一致する。一方、磁気電荷は三形式の流束の組で測るので列ベクトル $m=(m_C,m_B)^\mathsf T$ が $M$ で変わる。組合せ $(q,p)m$ は明らかに不変である。この組は Dirac の電気・磁気の積であり、電荷を両方とも同じ表現で変換すると保存しない。

:::example[軸子シフトに対する電気結合]
$T$ では $C_2'=C_2+B_2$、$B_2'=B_2$ となる。$(p,q)=(2,3)$ のとき $(p',q')=(-1,3)$ なので $3(C_2+B_2)-B_2=3C_2+2B_2$ である。磁気側で $(m_C,m_B)=(0,1)$ を取ると $(1,1)$ に移り、積は変換前の 2 と変換後の $3-1=2$ で一致する。
:::

### 原始電荷と量子化を DBI から照合する

平行な $q>0$ 枚の D1 に共通な電場 $E$ だけを置き、背景は平坦、ディラトンと $C_0$ は一定とする。相対的な非可換場をゼロとした一様な場について、向きを選んだ弦フレームの密度は
$$
\mathcal L=-q T_{\rm D1}\sqrt{1-e^2}-q T_{\rm F1} C_0 e,
\qquad e=2\pi\alpha' E ,
$$
である。ここでは二形式の電気結合の規約を $p+q\tau$ に合わせ、軸子項を負に取った。$B_2$ も残したときの Wess–Zumino 二形式はこの章では $C_2-C_0(B_2+2\pi\alpha'F)$ とする。$C_0$ の線形項を正に書く規約と照合するときは、その軸子をここでの $-C_0$ に読み替え、電荷と三形式の変換もそろえる。D ブレイン章で用いた $C_0=0$ の DBI の式は両規約で共通である。円周での Wilson 線 $\oint A$ は周期 $2\pi$ なので、その正準運動量 $p=\partial_E\mathcal L$ は整数である。従って $p+qC_0=(q/g_s)e/\sqrt{1-e^2}$ である。Legendre 変換では軸子項は $peT_{\rm F1}$ と組になり、
$$
\mathcal H=T_{\rm F1}\sqrt{(p+qC_0)^2+q^2/g_s^2}
$$
になる。弦フレームから Einstein フレームに $g_s^{1/2}$ を掛けると :eqref[eq-string-pq-tension] を再現する。$q=0$ の純粋な F1 はこの D1 の変分の外にあるが、式の張力は $|p|T_{\rm F1}$ に一致する。

固定した正準変数 $p$ と、電場で測る変位 $p+qC_0$ は一致する必要がない。軸子を 1 増やしたとき電場を保つには $p$ を $q$ だけ減らす。この操作が電荷格子上の $T$ の作用を実現する。BPS 状態の安定性には電荷の原始性も関わる。例えば整数電荷を二つに分けて張力を等しく加えられるなら、三角不等式の等号から二つの電荷は同じ向きで比例する。$\Im\tau>0$ では $(p,q)\mapsto p+q\tau$ は実線形同型であるため、原始電荷を同じ向きの非零整数電荷に分けることはできない。

:::example[変位がゼロの電荷]
$C_0=1/2$、$(p,q)=(-1,2)$ なら $p+qC_0=0$ なので $E=0$ であり、弦フレームの張力は $2T_{\rm D1}$ である。ここで整数 $p$ はゼロでない。軸子を含む Wess–Zumino 項が正準運動量に寄与するからである。電場をゼロにしたことから、基本弦の電荷量子数もゼロだとはいえない。
:::

### 基本領域と自己双対点

$\tau=x+iy$、$y>0$ とする。$T$ で $|x|\le1/2$ に移し、$|\tau|<1$ なら $S$ で虚部を増やす。これが有限回で止まって $|\tau|\ge1$ になる理由は、変換後の虚部が $y/|c\tau+d|^2$ であり、元の虚部以上になる整数対 $(c,d)$ は有限個だからである。実際 $|c\tau+d|\le1$ は $|c|y\le1$ と $|cx+d|\le1$ を含む。従って増幅を無限に続けられない。この領域内では $y\ge\sqrt3/2$ であるが、小さい $g_s$ が必要な近似のためにはさらに $y\gg1$ が必要である。双対性を使うだけで任意の結合を任意に小さくできるわけではない。

:::example[自己双対点の最大の虚部]
$\tau=i$ では任意の $\operatorname{SL}(2,\Z)$ 変換で $y'=1/(c^2+d^2)\le1$ である。等号は $(c,d)$ が $(\pm1,0)$ または $(0,\pm1)$ のときに限る。従って $g_s=1$ のこの軌道には結合が 1 より小さい元がない。$S$ が元のスカラーを固定する一方、電荷の組には作用するため、自己双対点は全ての状態が不変であることを意味しない。
:::

### 二電荷を持つ弦の結節で力を釣り合わせる

一定の $\tau$ の平坦背景で弦が同じ空間平面の一点に集まる静的配置を考える。全ての枝の向きを結節から外向きに取り、その向きで整数電荷 $(p_a,q_a)$ を指定する。電荷の保存は $\sum_a p_a=\sum_a q_a=0$ である。これは電気結合 $\sum_a\int(p_a B_2+q_aC_2)$ のゲージ変分が、各世界面の境界に同じ一形式の積分を作り、その係数が合計電荷になるためである。結節に別の電荷源を置かない条件である。弦の力の大きさは :eqref[eq-string-pq-tension] の張力であり、向きは平面上の単位複素数 $\zeta_a$ と書ける。

電荷 $Z_a=p_a+q_a\tau$ の位相と実空間の角度をそろえ、$\zeta_a=e^{i\varphi_0}Z_a/|Z_a|$ を取る。このとき結節に働く合力は
$$
\sum_a T_{p_a,q_a}^E\,\zeta_a
=\frac{e^{i\varphi_0}}{2\pi\alpha'\sqrt{\Im\tau}}\sum_a Z_a=0
$$
である。この条件は、枝の端を固定した総張力エネルギーの変分からも得られる。結節の位置を $\vb x$、端点を $\vb x_a$ とすれば $E(\vb x)=\sum_a T_a|\vb x_a-\vb x|$ である。枝の長さが非零なら $\partial_{\vb x} E=-\sum_a T_a\hat{\vb u}_a$ である。二次変分は $\sum_a T_a[|\delta\vb x|^2-(\hat{\vb u}_a\cdot\delta\vb x)^2]/|\vb x_a-\vb x|$ となり、非平行な二枝があれば平面上で正である。従ってこの力の釣合いは静的エネルギーの局所最小になる。超対称性を残す条件には、さらに各枝の向きと二電荷の行列を結ぶ同時射影を検査する。

$\operatorname{SL}(2,\Z)$ は $Z_a$ 全てに共通の複素数 $(c\tau+d)^{-1}$ を掛ける。従って比 $Z_a/Z_b$ が一定で、枝の相対角は同じである。張力も変わらないので、力の釣合いを保つ幾何は全体の回転を除いて同じである。軸子や結合を変えながら電荷を固定する場合は $Z_a/Z_b$ が変化し、同じ配置のまま力が釣り合うとは限らない。

:::example[三枝の張力三角形]
$\tau=i$ で $(1,0),(0,1),(-1,-1)$ を取る。第一枝と第二枝を正の直交二軸に沿って張ると、第三枝は南西へ向かい、張力は第一枝の $\sqrt2$ 倍となる。単位を $1/(2\pi\alpha')$ に取った力ベクトルは $(1,0),(0,1),(-1,-1)$ なので合力がゼロである。$\tau=2i$ へ結合を変えると正の縦方向の電荷の大きさが横の二倍になり、第三枝の傾きは 2 となる。各枝の長さは電荷だけから決まらず、端点の配置を設定する必要がある。
:::

## 11 次元への持ち上げと M 理論

IIA の D0 は R–R 一形式に結合する。BPS の電荷 $n$ を持つ束縛状態の系列を $|n|/(g_s\ell_s)$ の質量とすると、これは半径
$$
R_{11}=g_s\ell_s,\qquad \ell_{11}^3=g_s\ell_s^3
\label{eq-string-m-circle}
$$
の円周の Kaluza–Klein 運動量と一致する。状態の存在と各電荷での多重度はこの質量比較だけでは証明できない。D0 の力学と BPS 指数を用いる根拠は :cite[bbs-string] を参照する。二つ目の式は $2\kappa_{11}^2=(2\pi)^8\ell_{11}^9$ と $2\kappa_{10}^2=2\kappa_{11}^2/(2\pi R_{11})$、:eqref[eq-string-dp-tension] を合わせれば得られる。従って $R_{11}/\ell_{11}=g_s^{2/3}$ であり、大きい $g_s$ では十一番目の方向が大きくなる。

円周方向 $y$ を持つ計量は、漸近ディラトンからの差を $\varphi$ として $ds_{11}^2=e^{-2\varphi/3}ds_{10,\mathrm{str}}^2+e^{4\varphi/3}(\dd y+C_1)^2$ と分解できる。座標のシフト $y\mapsto y-\lambda(x)$ に $C_1\mapsto C_1+\dd\lambda$ が伴う。三形式の円周成分が $B_2$、残りが $C_3$ を与える。局所的な低エネルギー極限は :eqref[eq-string-eleven-action] であり、この極限を持つ十一の時空次元の理論を :term[M 理論]{en="M-theory" yomi="えむりろん"} と呼ぶ。

### 円周運動量の間隔と十一の微分展開

十一番目の方向の運動量は $n/R_{11}$ なので、エネルギー $E$ 以下に入る非零モードの番号は $1\le|n|\le ER_{11}$ である。一方、十一の古典超重力を使う長さ条件は $E\ell_{11}\ll1$ である。$R_{11}/\ell_{11}=g_s^{2/3}$ を使えば、$g_s\gg1$ のときだけ $R_{11}^{-1}\ll E\ll \ell_{11}^{-1}$ の窓を作れる。ここでは KK 状態は多数あっても、高エネルギーの補正は小さい。

:::example[両尺度を数値で比べる]
$g_s=1000$ なら $R_{11}=1000\ell_s$、$\ell_{11}=10\ell_s$、従って比は 100 である。$E=5/R_{11}$ では $E\ell_{11}=1/20$ であり、$n=\pm1,\ldots,\pm5$ の質量が閾値以下に入る。
:::

:::example[結合が小さいとき]
$g_s=1/8$ なら $R_{11}=\ell_s/8$、$\ell_{11}=\ell_s/2$ である。$n=1$ の KK 質量は $8/\ell_s$ であり、弦の振動の尺度 $1/\ell_s$ より大きい。質量の一致から直ちに十一の低エネルギーの窓があるわけではない。
:::

### D0 の低エネルギー量子力学

$N$ 枚の D0 を重ねると、軽い場は十次元の $\mathcal N=1$ 超 Yang–Mills 理論の空間九方向を縮約した行列量子力学になる。九つの Hermite 行列 $X^i$ は横座標を $2\pi\alpha'$ で割った量、$A_t$ は時間方向のゲージ接続である。空間微分をゼロにして $D_t X^i=\dot X^i-i[A_t,X^i]$、$F_{ij}=-i[X^i,X^j]$ を代入すると、運動項は $\Tr(D_t X^i)^2$、ポテンシャルは $-\Tr[X^i,X^j]^2$ に比例する。後者は可換ならゼロである。なぜなら Hermite な $X^i$ の交換子は反 Hermite で、$-\Tr[X^i,X^j]^2=\Tr([X^i,X^j]^\dagger[X^i,X^j])$ だからである。全ポテンシャルがゼロのとき全ての $X^i$ は可換であり、同時対角化できる。対角成分は D0 の位置を、固有値の置換は同種の粒子の交換を表す。

対角背景 $X^1={\rm diag}(x_1,\ldots,x_N)$ を選ぶと、線形な交換子は $[X^1,\delta X^j]_{ab}=(x_a-x_b)\delta X^j_{ab}$ である。横変動の質量は $|x_a-x_b|$ で、元のブレイン間の距離 $r_{ab}=2\pi\alpha'|x_a-x_b|$ を用いると $r_{ab}/(2\pi\alpha')$ になる。これは開弦の伸びのエネルギーに等しい。ゲージ偏極とフェルミオンも含めた量子力学のスペクトルで比較すべきものは、重心の $U(1)$ 粒子の運動を除いた相対系の正規化可能な零エネルギー状態である。可換行列の固有値が無限に離れられるので、連続スペクトルも零から始まる。従って有限次元の行列の超対称性の一般論だけから閾値束縛状態の数を決めることはできない。指数の境界寄与を含む計算は :cite[bbs-string] を参照する。

:::example[三単位の電荷の閾値]
三枚の静止 D0 を遠くに離した状態の質量の下限は $3/(g_s\ell_s)$ であり、もし三電荷の BPS 束縛状態があればその質量も同じ値になる。質量公式だけでは、三つの KK 粒子を重ねた連続スペクトルと、一つの KK 粒子の $n=3$ モードを区別できない。相対運動の波動関数が正規化可能かどうかがこの区別に必要である。
:::

### 十一次元の波を D0 に縮約する

十一の計量で進行波が $y$ の正方向に走るとし、
$$
\dd s_{11}^2=-\dd t^2+\dd y^2+(H-1)(\dd t-\dd y)^2+\dd\vb x_9^2
$$
とする。光円錐で $\dd u=\dd t-\dd y$、$\dd v=(\dd t+\dd y)/2$ と置くと $-2\dd u\dd v+(H-1)\dd u^2+\dd\vb x_9^2$ である。非零の接続のうち Ricci に寄与するのは $\Gamma^i_{uu}=-\partial_i H/2$ であり、$R_{uu}=-\Delta H/2$ になる。他の項では $u$ と対になる $v$ 微分がゼロであり、Ricci のトレースも消える。従って源の外で $H=1+Q/r^7$ を取れる。円周の内積を平方完成すると
$$
\dd s_{11}^2=H\bigl[\dd y+(H^{-1}-1)\dd t\bigr]^2-H^{-1}\dd t^2+\dd\vb x_9^2 .
$$
円周の計量成分が $H=e^{4\varphi/3}$ なので $\varphi=(3/4)\log H$ である。十次元の弦フレーム計量にはさらに $e^{2\varphi/3}=H^{1/2}$ を掛ける。よって $C_1=(H^{-1}-1)\dd t$、$\dd s^2_{10,\mathrm{str}}=-H^{-1/2}\dd t^2+H^{1/2}\dd\vb x_9^2$ となり、:eqref[eq-string-dp-sugra] の D0 に一致する。十一の空間方向の波の電荷は、十次元では計量由来の一形式に対する電気電荷となる。

:::example[摂動の比較に使う円周]
$H=16$ の場所で十一計量の $g_{yy}=16$ なので、座標の周期を固定した円の固有半径は漸近値の 4 倍になる。十次元の局所結合は $e^\Phi=g_s H^{3/4}=8g_s$ である。漸近的な結合だけでは、波に近い場所で十一番目の方向を無視できるか判断できない。
:::

## M2 ブレインと M5 ブレイン

M2 と M5 の張力の規格化は $T_{\rm M2}=1/[(2\pi)^2\ell_{11}^3]$、$T_{\rm M5}=1/[(2\pi)^5\ell_{11}^6]$ である。:eqref[eq-string-m-circle] を使うと、円周に巻いた M2 の張力は $2\pi R_{11}T_{\rm M2}=1/(2\pi\alpha')$ となる。巻かない M2 は $1/[(2\pi)^2g_s\ell_s^3]$ を持つ D2 と一致する。M5 を巻くと $2\pi R_{11}T_{\rm M5}=1/[(2\pi)^4g_s\ell_s^5]$ で D4 に当たり、巻かなければ $1/[(2\pi)^5g_s^2\ell_s^6]$ の NS5 である。弦の張力と空間五方向に広がる物体の張力では次元が異なるため、巻くときに円周長を掛け忘れてはならない。

この対応は電場と磁場でも確認できる。M2 は $C_3$ への電気源なので円周に巻くと円周成分の $B_2$ を源とする。M5 は $F_4$ の磁気源であり、巻かないと $B_2$ の磁気的な NS5 に対応する。十一の時空次元の電気・磁気の積は $2\kappa_{11}^2T_{\rm M2}T_{\rm M5}=2\pi$ となり、一単位の Dirac 量子化と一致する。

### 巻き付きと電気・磁気電荷

M2 は $C_3$ に電気的に結合し、M5 は $F_4$ の磁気流束を持つ。従って M2 が円周方向を含むと、その結合は $C_3$ の円周成分 $B_2$ の結合に縮約し、F1 の電荷になる。M5 が円周方向を含まない場合には $B_2$ の磁気源である NS5 に対応する。張力の換算と電荷の縮約を別々に照合すると、どの場に対する電荷を比較しているかが分かる。

:::example[電気と磁気の規格化]
$2\kappa_{11}^2=(2\pi)^8\ell_{11}^9$ を代入すると、$2\kappa_{11}^2 T_{\rm M2}T_{\rm M5}=(2\pi)^{8-2-5}\ell_{11}^{9-3-6}=2\pi$ である。これが最小電気電荷と最小磁気電荷の Dirac の積になっている。
:::

:::example[二回巻きの膜]
M2 の一方向を二回巻くと世界体積の積分は $4\pi R_{11}$ になり、張力は F1 の 2 倍、二形式への電荷も 2 倍である。一次の張力関係はこの総電荷の比較であり、同電荷での束縛状態の縮退度までは決めない。
:::

### 流束の整数から近地平面の半径を決める

M2 の解 :eqref[eq-string-m2-solution] に $N$ 枚分の源を置く。向きを選び $\int_{S^7}*F_4=6\Omega_7 Q_2$ とする。十一の電気源の係数は $2\kappa_{11}^2T_{\rm M2}N=(2\pi)^6\ell_{11}^6N$、$\Omega_7=\pi^4/3$ なので
$$
Q_2=32\pi^2N\ell_{11}^6 .
$$
磁気の場合、電気・磁気の Dirac 条件から $\int_{S^4} F_4=2\pi N/T_{\rm M2}=(2\pi)^3\ell_{11}^3N$ である。:eqref[eq-string-m5-solution] の流束が $3\Omega_4Q_5$ で $\Omega_4=8\pi^2/3$ なので
$$
Q_5=\pi N\ell_{11}^3 .
$$
従って同じ枚数でも、M2 の球半径は $(32\pi^2N)^{1/6}\ell_{11}$、M5 の球半径は $(\pi N)^{1/3}\ell_{11}$ である。ここで球の体積は Euclid の Gaussian 積分を動径と角に分けた $\Omega_j=2\pi^{(j+1)/2}/\Gamma((j+1)/2)$ を使った。局所曲率を Planck 単位で小さくするには、その半径だけでなく AdS 側の半径も比べる。

### 膜の円周を巻く場合と横に置く場合

膜の世界体積の座標の一つを $y$ に等しく取り、残りを $\sigma^0,\sigma^1$ とする。$y$ に依存しない wrapped sector では、誘導計量のブロックの行列式から円周の $e^{4\varphi/3}$ と、外部の二方向の $e^{-4\varphi/3}$ が打ち消し合う。実際、円周の行と列の混合成分を Schur 補で消すと $C_1$ の二次項も消え、行列式は誘導した弦フレームの二次元計量の行列式になる。従って $\int\sqrt{-\det P[\hat g]}$ の $y$ 積分は $2\pi R_{11}$ を掛け、世界面では明示的なディラトン前因子がない。三形式の引き戻しは $B_2\wedge\dd y$ から $2\pi R_{11}\int B_2$ を得る。これが基本弦の Nambu–Goto 項と電気結合である。

円周を巻かない場合、静的に $y$ を固定して $C_1=0$ の背景だけを考えると、世界体積の三方向で体積要素は $e^{-\varphi}$ を持つ。従って非巻き膜の項は D2 のディラトン因子に一致する。動的な場合は $y(\sigma)$ を捨てず、三次元で周期スカラーをゲージ場に双対化する。これは三次元で一形式の微分と二形式の Maxwell 強度が Hodge 双対であることを使う。二次近似で独立な一形式 $v$ と $A_1$ を使い
$$
I[v,A_1]=\tfrac{K}{2}\int v\wedge *v+\tfrac{i}{2\pi}\int A_1\wedge \dd v
$$
と書く。ここでは Euclid の一定背景で、スカラーの周期を $2\pi$、$K>0$ とした。$A_1$ の局所変分で $\dd v=0$ になる。逆に部分積分すると第二項は $i\int v\wedge F_2/(2\pi)$ であり、$v$ の鞍点は $v=-i*F_2/(2\pi K)$ である。代入後は $\int F_2\wedge *F_2/(8\pi^2 K)$ になる。整数周期の和を含めると一方の巻き付きと他方の磁束の量子化が対応する。非線形な世界体積作用では同じ変換を平方根に行う。従って十一番目の位置の自由度は、D2 のゲージ場に残る。

:::example[巻かない膜の自由度を検査する]
十一の膜の横方向は $11-3=8$ 個である。十次元の D2 の横位置は $10-3=7$ 個、三次元 Maxwell 場の物理偏極は $3-2=1$ 個である。和の 8 は十一の記述と一致する。十次元で $y$ を単に定数に固定して D2 のゲージ場も除くと、この一自由度を失う。
:::

### M5 の自己双対強度を円周で分ける

線形化した M5 の世界体積に自己双対三形式 $T_3$ がある。光円錐の小群は $\operatorname{Spin}(4)$ であり、二形式ポテンシャルの横成分 6 個のうち自己双対性で 3 個になる。横位置は $11-6=5$ 個なので、ボソンの物理数は $3+5=8$ である。円周が世界体積方向にあるとき、$T_3=K_3+F_2\wedge e^\perp$ と外部五方向と円周に分ける。積の Lorentz 計量で向きを $\mathrm{vol}_6=\mathrm{vol}_5\wedge e^\perp$ とすれば $*_6(K_3)=(*_5 K_3)\wedge e^\perp$、$*_6(F_2\wedge e^\perp)=-*_5F_2$ である。従って自己双対性は $K_3=-*_5F_2$ と $F_2=*_5K_3$ を与え、$*_5^2=-1$ のため両式は同値である。$\dd T_3=0$ の成分は $\dd F_2=0$ と $\dd *_5F_2=0$ で、D4 の Maxwell 方程式を再現する。五次元のベクトルの物理偏極も 3 個である。巻かずに十次元へ下げる IIA の NS5 には六次元の自己双対型の場が残る。

:::example[巻き付きで新たに見える粒子電荷]
D4 の Wess–Zumino 結合の $C_1$ に掛かる四形式は $\mu_4 (2\pi\alpha')^2 \Tr F\wedge F/2$ である。$\int\Tr F\wedge F/(8\pi^2)=k$ のインスタントンは $\mu_0 k$ の D0 電荷を持つ。係数を代入すると $\mu_4\,16\pi^4\alpha'^2=\alpha'^{-1/2}=\mu_0$ である。十一の言葉では D4 は円周に巻いた M5 であり、その D0 電荷は巻いた方向の運動量である。世界体積の非摂動的な粒子からも円周の存在を検査できる。
:::

## ヘテロティック弦と Type I 弦の双対性

二つの十次元理論に同じ $\mathfrak{so}(32)$ と 16 超電荷がある。ヘテロティック理論では NS–NS の $B_2$ が残り、Type I では R–R の $C_2$ が残る。Einstein フレームで両者を同じ二形式として対応させると、$\Phi_{\mathrm I}=-\Phi_{\mathrm H}$ が候補となる。実際、ヘテロティックの三形式の運動項は $e^{-\Phi_{\mathrm H}}$ を伴い、Type I の R–R 項は $e^{+\Phi_{\mathrm I}}$ を伴う。後者は弦フレームで $e^{-2\Phi_{\mathrm I}}$ を持たず、十次元の体積と逆計量三個から $e^{(10-6)\Phi_{\mathrm I}/4}$ を得るためである。

同じ Einstein フレームでヘテロティック基本弦の張力は $e^{\Phi_{\mathrm H}/2}/(2\pi\alpha'_{\mathrm H})$、Type I の D1 は $e^{-\Phi_{\mathrm I}/2}/(2\pi\alpha'_{\mathrm I})$ である。ここでは二つの弦フレームの尺度を $\alpha'_{\mathrm I}=\alpha'_{\mathrm H}$ とする規格化を選ぶと一致する。別々に漸近の弦フレームの計量を単位行列に戻す場合は座標の尺度も換算する。張力と作用の比較は :term[S 双対性]{en="S-duality" yomi="えすそうついせい"} を支持する検査であり、非摂動的な状態の対応は :cite[polchinski-2] を参照する。

### Einstein フレームでの運動項の照合

共通の Einstein 計量 $g_E$ を使い、十次元の弦フレームを $g_{\mathrm H,s}=e^{\Phi_{\rm H}/2}g_E$、$g_{\mathrm I,s}=e^{\Phi_{\rm I}/2}g_E$ とする。ヘテロティックの NS–NS 三形式の項は $e^{-2\Phi_{\rm H}}$ を持ち、体積の $e^{5\Phi_{\rm H}/2}$ と三つの逆計量の $e^{-3\Phi_{\rm H}/2}$ を掛けると $e^{-\Phi_{\rm H}}$ になる。Type I の R–R 三形式には弦フレームでこの前因子がないので、同じ変換は $e^{+\Phi_{\rm I}}$ を与える。$\Phi_{\rm I}=-\Phi_{\rm H}$ とすれば二つの運動項の依存性が一致する。ゲージの運動項も、ヘテロティックは球面の $e^{-2\Phi_{\rm H}}$、Type I は円板の $e^{-\Phi_{\rm I}}$ から始まり、二つの逆計量を使うと $e^{-\Phi_{\rm H}/2}$ と $e^{+\Phi_{\rm I}/2}$ になる。

:::example[一定ディラトンでの張力照合]
$\Phi_{\rm H}=\log4$ なら、ヘテロティック F1 の Einstein フレームの張力は $2/(2\pi\alpha')$ である。Type I の $\Phi_{\rm I}=-\log4$ では D1 に $e^{-\Phi_{\rm I}}=4$、面積に $e^{\Phi_{\rm I}/2}=1/2$ が掛かるので同じ値になる。
:::

:::example[弦フレームでの長さの換算]
上と同じ定数なら $g_{\mathrm I,s}=g_{\mathrm H,s}/4$ である。同じ座標差の長さは Type I の弦フレームでヘテロティック側の半分である。両方の計量を単位行列にしてから半径を比較する場合、この換算を忘れるとそれぞれの KK 間隔の比較がずれる。
:::

### Type I の D1 の質量ゼロ場

Type I は IIB の世界面の向きを反転する射影を含み、十次元の tadpole の相殺で 32 枚分の D9 の Chan–Paton 成分が必要になる。単一 D1 上の 1–1 開弦に加えて、D1 と D9 を結ぶ 1–9 弦を考える。共通方向は 0,1 であり、残りの八方向が混合境界条件を持つ。相対する境界で Neumann と Dirichlet が入れ替わると、ボソンのモードが半整数に、NS のフェルミオンのモードが整数に替わる。混合方向一つにつき NS 基底エネルギーの変化は $1/8$ である。これは実ボソンの整数と半整数の零点エネルギーが $-1/24$ と $1/48$、実 NS フェルミオンの半整数と整数が $-1/48$ と $1/24$ であり、それぞれ $1/16$ 増えることから分かる。従って八方向のとき $a_{\rm NS}$ を基底エネルギーとして $a_{\rm NS}=-1/2+8/8=+1/2$ で、質量ゼロの NS 状態はない。

R では混合方向のボソンとフェルミオンがともに半整数なので零点エネルギーは相殺する。整数モードの方向は D1 と D9 で共通の 0,1 であり、そのフェルミオン零モードが二次元 Clifford 代数を作る。GSO 射影が二次元の一方のカイラリティを残し、向き反転は 1–9 と 9–1 を同定する。従って各 D9 添字につき一つの実カイラルフェルミオン、計 32 成分が D1 に載る。1–1 の横座標八つと超対称な側の八つのフェルミオンを合わせると、ヘテロティック弦の光円錐の世界面成分と対応する。この比較には Type I の orientifold 射影の符号が入る。 Chan–Paton の構成と単独 D1 の離散ゲージ射影は :cite[polchinski-2] を参照する。

:::example[自由フェルミオンのカレントの次元]
$\lambda^A$、$A=1,\ldots,32$ を左に動く実フェルミオンとし、$\lambda^A(z)\lambda^B(w)\sim\delta^{AB}/(z-w)$ と規格化する。$J^{AB}=i:\lambda^A\lambda^B:$ は $A<B$ について $\binom{32}{2}=496$ 個ある。単縮約は添字の交換による $\mathfrak{so}(32)$ の交換関係を作り、二重縮約は反対称な添字対の単位行列を係数に持つ二位の極を与える。32 個の実フェルミオンの中心電荷は $32/2=16$ であり、ヘテロティックの左内部 CFT が必要とする値と一致する。離散射影の選択は Lie 代数の次元だけで決まらないので、電荷格子も照合する。
:::

## 双対性の網

半径 $R$ の IIA と $\alpha'/R$ の IIB は T 双対である。IIA の結合を大きくすると M 理論の円周が開く。有限の円周にさらに一方向をコンパクト化すると M 理論の二次元トーラスが現れ、その格子基底交換が IIB の $\operatorname{SL}(2,\Z)$ に対応する。長方形トーラスで M2 を二つの基本サイクルにそれぞれ巻くと、張力の比はサイクルの長さの比である。一般の平坦トーラスでサイクル $(p,q)$ の長さは、第一周期を $L$ として $L|p+q\tau|$ である。面積を固定すれば $L\propto(\Im\tau)^{-1/2}$ となり、:eqref[eq-string-pq-tension] の依存性を再現する。

### 電荷ベクトルの原始性

整数の弦電荷 $(p,q)\ne(0,0)$ で $\gcd(p,q)=1$ なら、Bézout の恒等式により $ap-bq=1$ となる整数 $a,b$ がある。$c=q,d=p$ と置けば $ad-bc=1$ である。変換則 $(p',q')=(ap-bq,-cp+dq)$ により $(1,0)$ に写る。例えば $(p,q)=(3,4)$ に対し $(a,b,c,d)=(-1,-1,4,3)$ は $ad-bc=1$ で、電荷を $(1,0)$ に写す。

公約数が $k>1$ なら変換の行列と逆行列が整数であるため、公約数は変換で保存する。従って $(k,0)$ には移せるが $(1,0)$ には移せない。:eqref[eq-string-pq-tension] は $T_{kp,kq}^E=kT_{p,q}^E$ を与える。よって同じ向きと電荷比の複数の弦へ分かれるとき、BPS 張力の比較だけでは結合エネルギーを得られない。これに対し電荷比が異なれば複素平面の $p+q\tau$ の向きも異なる。三角不等式から結合した電荷の BPS 張力は分離した張力の和より小さい。例えば $\tau=i$ では $(1,1)$ は $\sqrt2$、$(1,0)$ と $(0,1)$ の和は 2 である。

### 二つの円周の交換で IIB の結合が反転する

11 次元で直交する二つの円の半径を $R_a,R_b$ とする。最初に $a$ で IIA に縮約すると $\ell_s^2=\ell_{11}^3/R_a$、$g_A=R_a/\ell_s$ である。次に $b$ の T 双対を採用すると、同じ漸近単位で $R_{\rm B}=\ell_s^2/R_b=\ell_{11}^3/(R_aR_b)$、$g_{\rm B}=g_A\ell_s/R_b=R_a/R_b$ である。二円を交換しても $R_{\rm B}$ は不変で、$g_{\rm B}$ は逆数になる。軸子ゼロでのこの結果は、長方形トーラスの複素構造が IIB の軸子・ディラトンに対応することの検査である。

:::example[面積と形を独立に変える]
$R_a=3\ell_{11}$、$R_b=\ell_{11}$ なら $R_{\rm B}=\ell_{11}/3$、$g_{\rm B}=3$ である。二円を交換すると $R_{\rm B}$ は同じで $g_{\rm B}=1/3$ になる。両半径を同じ倍率で半分にすれば結合は 3 のまま、双対円は 4 倍になる。
:::

:::example[二サイクルを巻く膜]
M2 をトーラス全体に巻くと質量は $(2\pi)^2R_aR_b T_{\rm M2}=R_aR_b/\ell_{11}^3=1/R_{\rm B}$ である。よって IIB の最初の KK 運動量と照合できる。トーラスの面積が小さくなるほど、この巻き付き状態は軽くなる。
:::

### ヘテロティックの Wilson 線が九次元の格子を変える

円周の無次元半径 $r=R/\ell_s$、内部の偶自己双対格子のベクトル $P$、無次元の Wilson 線 $A$ を取る。巻き付きのある弦では内部の左運動量を $P'=P+wA$ とする。円周側の左右の無次元運動量を $k_{L,R}=\frac1{\sqrt2}(u/r\pm wr)$ と書き、円周の格子の規約を :eqref[eq-string-narain-momenta] に合わせる。全格子の Lorentz ノルムを $P^2+2nw$ と保つには
$$
u=n-A\cdot P-\frac{w}{2}A^2
$$
とすればよい。実際 $(P+wA)^2+2wu=P^2+2nw$ である。ここでは円周と内部の Cartan 背景だけを変え、内部 CFT の他の場は一定とする。$\lambda$ が内部格子に属するとき、$A\mapsto A+\lambda$ と同時に $P\mapsto P-w\lambda$、$n\mapsto n+\lambda\cdot P-w\lambda^2/2$ と取ると、$P'$ と $u$ が保たれる。整数性と偶性により $n$ の変化は整数であり、$-\lambda$ による逆変換がある。従ってこのシフトは背景を同じ物理に戻す。

:::example[直交群から二つの直交群へ]
$\operatorname{Spin}(32)/\Z_2$ の内部格子を使い、$A=(1/2,\ldots,1/2,0,\ldots,0)$ で最初の八成分だけに $1/2$ を置く。$w=0$ の根は $P=\pm e_i\pm e_j$ であり、$u=0$ を満たすには $A\cdot P\in\Z$ が必要である。二添字が同じ八成分の組にあれば内積は整数、別の組なら半整数である。従って非対角の質量ゼロ状態は $2\cdot4\binom82=224$ 個、内部 Cartan を足すと 240 個であり、$\mathfrak{so}(16)\oplus\mathfrak{so}(16)$ に対応する。半径が十分大きく巻き付きからの追加の根がない領域での数である。
:::

:::example[別の十次元格子から同じ Lie 代数を得る]
各 $E_8$ の八成分に $A=(1,0,\ldots,0)$ を置く。各因子の整数根は全て $A\cdot P$ が整数だが、半整数根では $A\cdot P=\pm1/2$ になる。従って各因子で $112$ 根と八 Cartan が残り、同じ $\mathfrak{so}(16)$ を得る。九次元の質量ゼロ Lie 代数の一致は双対性の検査の一つであり、格子全体を比べるには $w\ne0$ の状態も含める。
:::

### 区間上の十一の時空次元と二つの境界

円周に $y\mapsto-y$ を課すと固定点が二つあり、商は区間になる。十一の向きを反転するこの変換に $C_3\mapsto-C_3$ を組み合わせる。なぜなら $C_3\wedge F_4\wedge F_4$ は三つの場の符号で反転し、向きの反転と合わせて作用が不変になるからである。境界に平行な $C_{\mu\nu\rho}$ は奇、$C_{\mu\nu y}$ は $y$ 添字の反転も含むため偶である。従って零モードには NS–NS の候補 $B_{\mu\nu}$ が残る。超電荷には $\Gamma^y$ の固有値を指定する射影が一つ入り、16 成分が残る。円周縮約の IIA と違って、一方の十次元カイラリティだけが残る。

この :term[Hořava–Witten 構成]{en="Hořava–Witten construction" yomi="ほらゔぁうぃってんこうせい"} では境界ごとに $E_8$ のゲージ多重項が必要になる。必要性を示すのは境界に局在したゲージ・重力アノマリーの計算であり、ボソンの偶奇だけからゲージ群を推定できない。二つの同等な境界でアノマリーの非因子化部分をそれぞれ打ち消し、残りを十一の作用からの流入と合わせる厳密な計算は :cite[bbs-string] を参照する。一方、二つの境界を結ぶ方向に M2 を張れば、残る二方向から十次元の弦が得られ、その張力は膜張力と区間の長さの積である。区間の両端は閉円周と違って膜の境界となるため、膜の端のゲージ変換も境界の自由度と合わせる必要がある。従ってヘテロティックの $E_8\times E_8$ は、先に比較した Type I と $\operatorname{Spin}(32)/\Z_2$ の組とは別の強結合の枝である。

### K3 と四次元トーラスで残る電荷の格子

別の双対性は、六次元の IIA on K3 とヘテロティック on $T^4$ を結ぶ。K3 の二次コホモロジーは、交差形式の符号が $(3,19)$ であることを用いる。理由は四実次元の Ricci 平坦 Kähler 計量で、Kähler 形式と正則二形式の実部・虚部が自己双対な三つの調和形式を張り、残りの調和二形式が反自己双対だからである。外積の積分が $\int\omega\wedge\omega=\pm\int\omega\wedge *\omega$ になるため、六次元の電荷の絶対値にはこの署名が現れる。偶コホモロジーまで入れると、$H^0$ と $H^4$ を交差で結ぶ二成分は一つの正と一つの負を加えるので、符号は $(4,20)$ である。IIA の D0、K3 二サイクルに巻いた D2、K3 全体に巻いた D4 の電荷がこの偶次数に対応する。

ヘテロティックでは四つの運動量と四つの巻き付きが四対の一正一負の方向を作り、Cartan の 16 個の内部電荷が残りの方向を作る。左右のどちらの符号を正に取るかを揃えると同じ $(4,20)$ である。両方でベクトル場は 24 本である。IIA では $C_1$ から一つ、$C_3$ の調和二形式から 22、六次元の外部三形式の双対から一つを得る。ヘテロティックでは計量と $B$ の四本ずつと内部の 16 本から得る。一般点では Abel 群であり、K3 で負のノルム $-2$ のサイクルが縮むと、そのサイクルに巻いた D2 が軽くなる。この現象はヘテロティック格子の追加の根による対称性の増大に対応する。格子の一致と有効作用は双対性の検査であり、完全な量子等価性は :cite[bbs-string] に述べられた双対性の主張である。

:::example[根の最小の増大]
自己交差 $-2$ の球面 $\Sigma$ 一つの面積をゼロに近づけ、$B$ の周期も整数へ近づける。$B=0$ の古典領域では巻いた D2 の質量は $T_{\rm D2}\operatorname{Area}(\Sigma)$ に比例するので、逆向きの巻き付きと合わせて電荷 $\pm[\Sigma]$ が軽くなる。二つの根の電荷と既存の Cartan 一方向は $\mathfrak{su}(2)$ の三成分に合う。面積が弦長以下では幾何学の二微分近似が破れるため、質量の外挿には BPS 電荷の保護を使う。
:::

### 円周の T 双対性を結合も含めて照合する

半径 $R_A$ の円周に沿って IIA を縮約したとき、九次元の Newton 定数は $2\kappa_9^2=2\kappa_{10,A}^2/(2\pi R_A)$ である。T 双対な記述の $R_B=\ell_s^2/R_A$ と、漸近的な非コンパクト計量の単位を一致させる。十次元の Newton 定数に $g_A^2,g_B^2$ が掛かることから、等しい九次元の定数は $g_A^2/R_A=g_B^2/R_B$ を要求し $g_B=g_A\ell_s/R_A$ を得る。このチェックは世界面 Buscher 変換での $\Phi_B=\Phi_A-\log(R_A/\ell_s)$ と一致する。円周のサイズを変えると、同じ結合でも低次元の重力の強さは変わるので、半径だけを反転して結合を固定する比較は一般には誤りである。

RR の電荷にも T 双対性が作用する。円周に巻いた D$p$ から D$(p-1)$ への対応は、巻いた張力 $2\pi R_A T_p$ と双対側の $T_{p-1}(g_B)$ を比較できる。逆に円周に横向きの D$p$ は双対円周に巻く D$(p+1)$ である。この場合は $T_p(g_A)=(2\pi R_B) T_{p+1}(g_B)$ となる。さらに R–R の世界体積結合では、円周の添字があるポテンシャルは双対で添字がなくなり、円周を含まなかったポテンシャルは添字を一つ持つ。これは弦の右移動スピノルの一つの Clifford 行列が左右のカイラリティを変える事実と整合する。

:::example[同じ九次元の D0 電荷の別記述]
$R_A=2\ell_s$、$g_A=1/4$ とすると $R_B=\ell_s/2$、$g_B=1/8$ である。IIA 側の D0 の質量は $4/\ell_s$ である。IIB 側の D1 の張力は $8/(2\pi\ell_s^2)$、巻く円周は $\pi\ell_s$ なので質量は同じ $4/\ell_s$ になる。一方、IIA の運動量の一単位 $1/(2\ell_s)$ は IIB の基本弦の巻き付き一単位 $R_B/\alpha'=1/(2\ell_s)$ と対応する。二つの一致は異なる電荷の比較である。
:::

### M 理論のトーラスから九次元の Einstein 作用を見る

半径 $R_a,R_b$ を十一の漸近平坦計量で測り、トーラス面積を $\mathcal A=(2\pi)^2R_aR_b$ とする。九次元の Einstein 作用の定数は $2\kappa_{9}^2=2\kappa_{11}^2/\mathcal A$ である。得られた IIB の記述では $2\kappa_{9}^2=(2\pi)^6g_B^2\ell_s^8/R_B$ である。$\ell_s^2=\ell_{11}^3/R_a$、$R_B=\ell_{11}^3/(R_aR_b)$、$g_B=R_a/R_b$ を代入すれば
$$
(2\pi)^6\frac{R_a^2}{R_b^2}
\frac{\ell_{11}^{12}}{R_a^4}\frac{R_aR_b}{\ell_{11}^3}
=(2\pi)^6\frac{\ell_{11}^9}{R_aR_b}
$$
となり一致する。この式は全ての長さを漸近的に同じ非コンパクト計量で比較したものである。$G_9$ を固定した Einstein 計量でモジュライを変分する場合は、さらに体積に応じた Weyl 変換が要る。

斜交トーラスでは、面積を固定した内部計量を $G=\mathcal A M_\tau$ と書ける。周期を 1 とし、第 1 周期と第 2 周期の比を $\tau$ とすれば
$$
M_\tau=\frac{1}{\Im\tau}
\begin{pmatrix}1&\Re\tau\\\Re\tau&|\tau|^2\end{pmatrix},
\qquad \det M_\tau=1 .
$$
サイクルのベクトル $m=(p,q)^\mathsf T$ の長さ二乗は $m^\mathsf T G m$ である。計量を格子基底とともに取り替えると、同じサイクルの座標は逆行列で変わり、長さは一定になる。ここで形だけの変化を取り、$K=M_\tau^{-1}\dd M_\tau$ とする。$\tau=x+iy$ を代入して縮約すると $\tfrac14\Tr K^2=(\dd x^2+\dd y^2)/(2y^2)$ となる。例えば $x=0$ に平行移動してから計算すれば、$M_\tau=\operatorname{diag}(1/y,y)$、$K$ の対角成分は $-\dd y/y,\dd y/y$、非対角成分の積は $\dd x^2/y^2$ である。これは IIB の軸子・ディラトンの運動項に使った計量である。長さの不変性に加え、モジュライの計量も同じ変換を許す。

:::example[斜交トーラスで二つの電荷の長さを比較する]
$\tau=1/2+i$ とし、第一周期を長さ $L$ とする。$(0,1)$ と $(-1,1)$ はそれぞれ $L|1/2+i|$ と $L|-1/2+i|$ なのでどちらも $\sqrt5 L/2$ である。一方 $(1,1)$ は $\sqrt{13}L/2$ になる。斜交トーラスでは二つの基本周期の長さだけで任意の巻き付きを求められず、内積を決める実部が必要になる。
:::

### さらに一つの円を加えた電荷の交換

十一の三次元トーラス $T^3$ を長方形で考え、周期半径を $R_i$ とする。八次元の粒子の電荷には KK 運動量 $n_i$ と、$i$ 以外の二方向に巻いた膜の巻き付き $w^i$ がある。八次元の質量を全て同じ十一の非コンパクト計量の単位で測ると、一単位の値は
$$
m_{n_i}=R_i^{-1},\qquad
m_{w^i}=R_jR_k/\ell_{11}^3,\qquad
m_{w^i}/m_{n_i}=R_1R_2R_3/\ell_{11}^3 .
$$
比は $i$ によらない。従って体積モジュラスが、この二組の質量のどちらが小さいかを決める。三方向の整数基底の交換 $\operatorname{SL}(3,\Z)$ は、運動量と巻き付きの向きを同時に変える。実際二サイクルの巻き付きは二つの周期ベクトルの外積であり、体積形式で補方向の添字に変換すると、行列式が 1 の基底変換の下で運動量と同じ型に書ける。

八次元 Einstein 計量に移すと、体積 $\mathcal V/(2\pi)^3=R_1R_2R_3$ の無次元比 $v=\mathcal V/[(2\pi)^3\ell_{11}^3]$ の $1/3$ 乗を計量に掛けるので、質量の係数はさらに $v^{-1/6}$ になる。形を固定して $R_i=\ell_{11}v^{1/3}s_i$、$\prod_i s_i=1$ と書くと、二組は $\ell_{11}^{-1}s_i^{-1}v^{-1/2}$ と $\ell_{11}^{-1}s_i^{-1}v^{1/2}$ になる。体積を反転して運動量と巻き付きを交換すると質量が保たれる。内部 $C_3$ の周期も含めた八次元の双対性では、この反転と周期の整数シフトがもう一つの $\operatorname{SL}(2,\Z)$ を作る。形の $\operatorname{SL}(3,\Z)$ と組み合わせた量子対称性を :term[U 双対性]{en="U-duality" yomi="ゆーそうついせい"} と呼ぶ。この質量の比較はその一断面の検査であり、すべての電荷と作用での成立は :cite[bbs-string] の低次元の双対性を参照する。

:::example[体積の反転を同じ Einstein 単位で見る]
$s_i=1$、$v=16$ なら、各運動量の質量は $1/(4\ell_{11})$、膜の質量は $4/\ell_{11}$ となる。逆体積 $v=1/16$ ではこの値が交換される。十一の漸近時間を両側でそのまま使うと $v^{-1/6}$ の換算を落とすため、八次元の質量は一致しない。
:::

### 円周ヘテロティックの二つの十次元端

九次元の Narain 格子には $P^2+2nw$ の偶自己双対な整数格子があり、Wilson 線と円周半径はその実二次空間で右移動の負の線を指定する。実際 $k_R=(u/r-wr)/\sqrt2$ は元の整数電荷に線形である。$k_L^2+|P'|^2-k_R^2$ が元の二次形式に一致するため、整数格子を保つ線形写像で負の線も移せば、左右のノルムと質量条件が保存される。左移動の直交基底の選択は変わっても、そのノルムは変わらない。純粋に左にある二乗 2 の根、すなわち $k_R=0$ を満たす格子点を数えると、各背景の増大したゲージ代数が分かる。

十次元の二種類の内部格子は互いに非同型だが、双曲平面 $U$ を一つ足すと $D_{16}^{+}\oplus U$ と $(E_8\oplus E_8)\oplus U$ は同型である。ここで $U$ はノルム $2nw$ の階数二の格子である。同型の存在には不定符号の偶自己双対格子の分類を使う。分類の証明はこの章の範囲を越えるため、低次元ヘテロティックへの適用は :cite[polchinski-2] を参照する。この同型で負の線を動かせるので、九次元には両方の十次元端を持つ連続した空間がある。ただし二つの非同型な内部格子は十次元の理論では互いに変わらない。円周の $n,w$ と内部電荷を混ぜる写像を許して初めて、低次元で両者を同じ空間に置ける。

負の線が近づく十次元の端を指定するために、原始な零ノルムベクトル $e$ を取り、$e^\perp/\Z e$ を作る。例えば $e=(P=0,n=1,w=0)$ なら、$e^\perp$ の条件は $w=0$ であり、商には $P$ の格子だけが残る。この $e$ の系列の質量は大きい円で $|n|/R$ となる。従って $e$ が軽い端で残る十次元の電荷格子はこの商で読める。同じ不定符号の格子でも、極限でどの系列を軽くするかで二つの異なる端が可能な理由である。

:::example[Wilson 線で運動量量子数がずれる]
最初の二成分に $A=(1/2,1/2,0,\ldots)$ を取り、根 $P=e_1+e_2$ を選ぶ。$w=0$ で $u=n-1$ だから $n=1$ の状態が十次元根の九次元の質量ゼロの代表になる。一方、$P=e_1+e_3$ なら $u=n-1/2$ であり、同じ $w=0$ では $k_R$ をゼロにできない。半径が大きいとこのずれによる質量は $1/(2R)$ に近づくので、極限で元の十次元の根も戻る。
:::

## 演習問題

::::exercise[結合の反転]{#exr-string-dualities-1 level=basic}
$IIB$ の $C_0=0$、$g_s=4$ に $S$ を作用させた結合を求めよ。

:::solution
$\tau=i/4$ は $4i$ に移る。従って $e^{-\Phi'}=4$、$g_s'=1/4$ である。
:::

::::exercise[D0 と半径]{#exr-string-dualities-2 level=basic}
$g_s=3$ の $R_{11}/\ell_s$ を求めよ。

:::solution
円周運動量一単位 $1/R_{11}$ と D0 質量 $1/(g_s\ell_s)$ を等置し、比は 3 である。
:::
::::

::::exercise[M2 の巻き付き]{#exr-string-dualities-3 level=basic}
M2 の巻き付きから基本弦の張力を導け。

:::solution
$2\pi R_{11}/[(2\pi)^2\ell_{11}^3]=R_{11}/(2\pi\ell_{11}^3)$ である。比 $R_{11}/\ell_{11}^3=\ell_s^{-2}$ を代入して $1/(2\pi\alpha')$ を得る。
:::
::::

::::exercise[自己双対点]{#exr-string-dualities-4 level=basic}
$\tau=i$ の $(p,q)=(1,1)$ の張力と F1 の比を求めよ。

:::solution
$\Im\tau=1$ なので比は $|1+i|/|1|=\sqrt2$ である。
:::
::::

::::exercise[電荷の変換]{#exr-string-dualities-5 level=advanced}
$T:\tau\mapsto\tau+1$ で張力を保つ $(p',q')$ を求めよ。

:::solution
$p'+q'(\tau+1)=p+q\tau$ とすると $\tau$ の係数は $q'=q$、定数部分は $p'+q=p$ である。よって $(p-q,q)$ となる。
:::
::::

::::exercise[重力定数の縮約]{#exr-string-dualities-6 level=advanced}
$\ell_{11}^9$ を $R_{11},g_s,\ell_s$ で表せ。

:::solution
$2\kappa_{11}^2=2\pi R_{11}(2\kappa_{10}^2)$ なので $(2\pi)^8\ell_{11}^9=(2\pi)^8R_{11}g_s^2\ell_s^8$ である。従って $\ell_{11}^9=R_{11}g_s^2\ell_s^8=g_s^3\ell_s^9$ となる。
:::
::::

::::exercise[M5 の磁気電荷]{#exr-string-dualities-7 level=advanced}
$2\kappa_{11}^2T_{\rm M2}T_{\rm M5}$ を求めよ。

:::solution
$(2\pi)^{8-2-5}\ell_{11}^{9-3-6}=2\pi$ となり、長さの単位が消える。
:::
::::

::::exercise[固定面積のトーラス]{#exr-string-dualities-8 level=advanced}
第一周期の長さ $L$ のトーラスで、面積 $A$ を固定して $(p,q)$ サイクルの長さを求めよ。

:::solution
周期ベクトルは複素表示で $L,L\tau$ なので面積は $L^2\Im\tau$ である。サイクルは $L(p+q\tau)$ であり、長さは $\sqrt A|p+q\tau|/\sqrt{\Im\tau}$ となる。
:::
::::

::::exercise[原始電荷を基本弦に移す]{#exr-string-dualities-9 level=advanced}
$(p,q)=(2,3)$ を $(1,0)$ に移す $\operatorname{SL}(2,\Z)$ の変換を一つ求めよ。$\tau=i$ として前後で張力を照合せよ。

:::solution
電荷に作用する符号規約は $(p',q')=(ap-bq,-cp+dq)$ である。$a=2,b=1,c=3,d=2$ とすると $ad-bc=4-3=1$、$(p',q')=(4-3,-6+6)=(1,0)$ である。変換した $\tau'$ の虚部は $1/|3i+2|^2=1/13$ である。従って変換後の無次元張力は $1/\sqrt{1/13}=\sqrt{13}$ であり、変換前の $|2+3i|=\sqrt{13}$ と一致する。
:::
::::

::::exercise[二成分の電荷に対する Dirac の積]{#exr-string-dualities-10 level=advanced}
$(p,q)=(3,1)$、$(m_C,m_B)=(2,-1)$ とする。$\tau\mapsto-1/\tau$ によって電気と磁気がどう変わるかを求め、Dirac の積を検算せよ。

:::solution
$S$ の行列は $\begin{pmatrix}0&-1\\1&0\end{pmatrix}$ なので、電気側は $(p',q')=(q,-p)=(1,-3)$ である。磁気側の列は $M(2,-1)^\mathsf T=(1,2)^\mathsf T$ になる。従って変換前の積は $1\cdot2+3\cdot(-1)=-1$、変換後も $(-3)\cdot1+1\cdot2=-1$ である。両方の成分の順序を揃えずに同じ行列を掛けると、この積を保存する計算にならない。
:::
