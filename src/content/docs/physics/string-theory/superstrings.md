## この章の目標

- 世界面超対称性からボソンとフェルミオンの関係を導く。
- NS と R の真空エネルギーと最初の状態を求める。
- GSO 射影と臨界次元の条件を説明する。
- Type IIA と Type IIB の質量ゼロ状態を分類する。

## 世界面超対称性と RNS 形式

時空座標 $X^\mu$ に世界面スピノル $\psi^\mu$ を組み合わせる。この記述を :term[RNS 形式]{en="Ramond–Neveu–Schwarz formalism" yomi="あーるえぬえすけいしき"} という。自由な正則側では規格化を $\psi^\mu(z)\psi^\nu(w)\sim\eta^{\mu\nu}/(z-w)$ とする。この Green 関数は Euclid 作用の一次演算子 $\bar\partial$ の逆であり、反正則側にも独立な成分がある。共形ゲージでは $\bar\partial\partial X=0$、$\bar\partial\psi=0$ である。

超カレントを $G=i\sqrt{2/\alpha'}:\psi\cdot\partial X:$ とする。$G$ と $X$ の積の単極は $-i\sqrt{\alpha'/2}\,\psi$、$G$ と $\psi$ の単極は $i\sqrt{2/\alpha'}\,\partial X$ である。同じ変換を二度施すと積の定数が 1 となって $\partial X$ と $\partial\psi$ が得られる。従って世界面の超対称性は二度の作用で並進を作る。局所超対称性の拘束として、応力テンソルと超カレントの両方を課す。

### 変換を二回作用させる

規格化を明示するため一つの Lorentz カイラル部分の超座標を $(u,\theta)$ とし、$Q=\partial_\theta+i\theta\partial_u$、$D=\partial_\theta-i\theta\partial_u$ とする。左 Grassmann 微分 $\partial_\theta\theta=1-\theta\partial_\theta$ より $Q^2=i\partial_u$、$D^2=-i\partial_u$、$\{Q,D\}=0$ である。超場を $\mathcal X=X+\theta\psi$ とすれば $Q$ は $X$ と $\psi$ を交換し、二回の作用は $u$ 方向の並進になる。左右を持つ超場にはさらに $\theta_+\theta_- F$ があり、自由作用の $F$ の項は微分を含まない二次形式なので運動方程式で $F=0$ となる。$F$ を残せば超代数の閉包に運動方程式を使わなくてよい。

:::example[単一モードに対する超電荷]
$X(u)=e^{-inu}$ の成分では $Q^2X=nX$ である。$n=2$ のモードで二回作用させれば元の成分の 2 倍になる。一方 $n=0$ では並進は自明であり、零モードを非零モードと同じように反転できるとは限らない。
:::

:::example[カイラルな超電流]
自由場で $\bar\partial\partial X=0$、$\bar\partial\psi=0$ なら $G\propto\psi\cdot\partial X$ の $\bar\partial$ は積の Leibniz 則でゼロとなる。同じ演算子に $\bar\psi$ を使うと一般には $\bar\partial\bar\psi$ が残る。従って左・右の超電流は別々に定義する。
:::

### 自由な作用と Grassmann 変換

世界面の Lorentz 光円錐座標を $u=\tau+\sigma,v=\tau-\sigma$ とする。二成分の実スピノルから右・左へ進む成分 $\psi_+,\psi_-$ を取る。時空座標を $Y=\sqrt{2/\alpha'}X$ と再規格化すると、全体の定数を除いた自由作用の密度を
$$
\mathcal L=\partial_uY\cdot\partial_vY+
 i\psi_+\cdot\partial_v\psi_++i\psi_-\cdot\partial_u\psi_-
$$
と書ける。$Y$ を変分すると $\partial_u\partial_vY=0$ である。$\psi_+$ は Grassmann 奇なので、$\int\psi_+\partial_v\delta\psi_+$ を部分積分した後に $\delta\psi_+$ を前へ移すと、最初の $\int\delta\psi_+\partial_v\psi_+$ と符号が同じになる。従って方程式は $\partial_v\psi_+=0$ であり、$\psi_-$ では $\partial_u\psi_-=0$ である。二次のボソンの作用とは異なり、フェルミオンの方程式は一次である。

定数の奇パラメータ $\epsilon$ を左に置き、$\delta Y=i\epsilon\psi_+$、$\delta\psi_+=-\epsilon\partial_u Y$、$\delta\psi_-=0$ と取る。ボソン項の積分した変分は $2i\int\epsilon\,\partial_uY\cdot\partial_v\psi_+$ であり、フェルミオン項からは $-2i\int\epsilon\,\partial_uY\cdot\partial_v\psi_+$ が出る。実際ボソン項を二つに分け、微分の交換と部分積分を使えば同じ項を二回得る。従って境界のない世界面あるいは適切な境界条件のもとで不変である。二つの変換を順に作用させると $[\delta_{\epsilon_1},\delta_{\epsilon_2}]Y=2i\epsilon_1\epsilon_2\partial_uY$ となり、$u$ 方向の並進を得る。$\psi_+$ でも同じ式が成り立つ。この規格化は Lorentz 作用のものであり、Euclid の正則電流に使う $G$ は OPE の式で別に規格化する。

:::example[二つの進行波の超対称性]
$Y(u,v)=f(u)+g(v)$ かつ $\psi_+=\psi_+(u)$ とする。上の左側の変換は $f$ と $\psi_+$ を混ぜ、$\partial_u g=0$ なので右側の $g$ には作用しない。例えば $f=e^{-2iu}$、$g=e^{-3iv}$ なら、変換の交換子の $\partial_u$ は前者に $-2i$ を掛け、後者をゼロにする。閉弦では反対側にも独立な変換がある。
:::

### 局所対称性を使う理由

微分同相と Weyl 変換をゲージ化すると、計量の変分が世界面の応力テンソルの拘束を課す。世界面の超対称性を局所化すると、パラメータ $\epsilon(\sigma)$ の微分を含む変分に打ち消しが必要である。その係数は超電流であり、世界面のスピン $3/2$ の場を導入して結合させる。従ってその場の変分から超カレントの拘束を得る。共形ゲージのボソンの計量と同様に、平坦な背景でフェルミオンのゲージ場をゼロに置いた後も拘束は残る。局所超重力の全作用とそのゲージ固定の構成には、曲がった世界面でのスピノルと補助場が必要なので :cite[gsw-1] を参照する。この章ではゲージ固定後の自由場の積と超電流から拘束を扱う。

正則場の共形重み を見れば、$T$ は 2、$G$ は $3/2$ である。$\int \epsilon G$ を輪郭積分で変換の生成子にするなら、$\epsilon$ の重みは $1-3/2=-1/2$ である。後でゲージパラメータをゴーストに置き換えると、この同じ重みが $\gamma$ に移る。一方、超電荷の逆側を生成する反ゴースト $\beta$ の重みは、一次の運動作用を不変にするため $3/2$ である。ゴーストの重みは物質スピノルの $1/2$ と同じにはならない。

### 開いた区間で左右のフェルミオンを貼る

左右の物質フェルミオンの変分は、区間の端で $\psi_+\cdot\delta\psi_+-\psi_-\cdot\delta\psi_-$ に比例する。平坦なブレインの反射行列 $S$ を用いて
$$
\psi_-(\tau,0)=\eta_0 S\psi_+(\tau,0),\qquad
\psi_-(\tau,\pi)=\eta_\pi S\psi_+(\tau,\pi),\qquad
\eta_0,\eta_\pi\in\{1,-1\}
$$
とすると、$S^{\mathsf T}\eta S=\eta$ で変分は消える。同じ $S$ はボソンの勾配も貼り合わせるため、境界の左右の超電流はそれぞれの $\eta$ で結ばれる。一つのカイラルフェルミオンを反射で区間の外へ延長すると、二回の反射による一周期 $2\pi$ の符号は $\eta_0\eta_\pi$ である。従って $\eta_0\eta_\pi=-1$ は NS、$+1$ は R である。片方の端の符号だけでセクターは決まらず、二端の相対符号が必要である。左・右の独立な閉弦のスピン構造と、開弦のこの倍化条件を区別する。

:::example[端の符号の一方を変える]
$\eta_0=\eta_\pi=-1$ では積が $+1$ なので、円周へ延長した場は周期的であり零モードを持つ。$\eta_\pi$ だけ $+1$ にすれば積は $-1$ であり、最小の正の振動数は $1/2$ になる。固定端反射の $S$ が両端で同じなら、$S^2=I$ のためこの判定は方向によらない。
:::

## NS セクターと R セクター

円筒上でフェルミオンを反周期とする :term[NS セクター]{en="Neveu–Schwarz sector" yomi="えぬえすせくたー"} は $r\in\Z+1/2$、周期とする :term[R セクター]{en="Ramond sector" yomi="あーるせくたー"} は $r\in\Z$ である。これは $e^{-2\pi i r}=-1$ と $+1$ の解である。モードを留数で取り出すと $\acomm{\psi_r^\mu}{\psi_s^\nu}=\eta^{\mu\nu}\delta_{r+s,0}$ になる。R の零モードを $\Gamma^\mu=\sqrt2\psi_0^\mu$ とすると Clifford 代数であり、真空そのものがスピノルとなる。横 8 次元の複素化した零モードは 4 組の生成消滅演算子にできるため、R 真空は射影前に $2^4=16$ 成分ある。

指数切断後の有限部は $\sum_{n\ge0}(n+x)\leadsto-(x^2-x+1/6)/2$ である。ボソン一方向の零点エネルギーは $-1/24$、NS フェルミオンは $-\tfrac12(\tfrac1{24})=-1/48$、R フェルミオンは $1/24$ である。従って横 8 方向で $a_{\rm NS}=1/2$、$a_{\rm R}=0$ となる。開弦では $\alpha'M^2=N-a$、閉弦では左右の $N-a$ がそれぞれ $\alpha'M^2/4$ になる。

### 超 Virasoro 拘束と Ramond 基底

$G_r=\oint z^{r+1/2}G(z)\dd z/(2\pi i)$ と置く。$G(z)G(w)\sim (2c_{\rm m}/3)/(z-w)^3+2T(w)/(z-w)$ に対し、二つの奇電荷の反交換子は先に $z$ の留数をとればよい。三重極には $z^{r+1/2}$ の二次 Taylor 係数 $(r+1/2)(r-1/2)w^{r-3/2}/2$ が掛かる。従って

$$
\acomm{G_r}{G_s}=2L_{r+s}+\frac{c_{\rm m}}3(r^2-\tfrac14)\delta_{r+s,0}.
\label{eq-string-super-virasoro}
$$

$G$ はウェイト $3/2$ なので、$T$ との二重極と単極の留数から $[L_m,G_r]=(m/2-r)G_{m+r}$ である。例えば NS では $\{G_{1/2},G_{-1/2}\}=2L_0$ となる。これに対し R では $\{G_0,G_0\}=2L_0-c_{\rm m}/12$ となり、$G_0^2$ が円筒の $L_0-c_{\rm m}/24$ を与える。

光円錐ゲージの前に R の物質基底を十次元スピノル $u$ とすると、$G_0$ の零モード部分は $\sqrt{2\alpha'}\,p\cdot\psi_0=\sqrt{\alpha'}\,p\cdot\Gamma$ である。振動のない状態では非零モード項が消えるので、$G_0\ket u=0$ は $p\cdot\Gamma u=0$ である。Clifford 関係から $(p\cdot\Gamma)^2=p^2 I$ となり、非零の解には $p^2=0$ が必要である。$p^+$ だけが非零になる光円錐枠では、$\Gamma^-u=0$ となる。$\{\Gamma^+,\Gamma^-\}=-2$ は核と像を一致させる。実際、$\Gamma^-u=0$ なら $u=-\Gamma^-\Gamma^+u/2$ であり、逆の包含は $(\Gamma^-)^2=0$ による。従って成分は半分になる。この段階では Dirac 拘束によって減ったのであり、カイラリティを選ぶ GSO 射影は次の操作である。

### 真空エネルギーの差をモードから再現する

$x\in(0,1]$ に対して $S_x(\epsilon)=-\partial_\epsilon[e^{-\epsilon x}/(1-e^{-\epsilon})]$ とする。括弧内を $\epsilon^{-1}+(1/2-x)+\epsilon(x^2-x+1/6)/2+O(\epsilon^2)$ と展開すると、$S_x=\epsilon^{-2}-(x^2-x+1/6)/2+O(\epsilon)$ である。整数振動子は $x=1$、半整数振動子は $x=1/2$ で調べる。フェルミオンの Hamiltonian では一モードの基底エネルギーが $-r/2$ なので、ボソンと逆符号が掛かる。R の $r=0$ はエネルギーを加えず、Clifford 表現の縮退度だけを与える。

:::example[横四組だけで切片を比較する]
四つのボソンと四つの Majorana フェルミオンでは、NS の零点エネルギーは $4(-1/24-1/48)=-1/4$ である。R では $4(-1/24+1/24)=0$ である。八組の場合は前者だけが 2 倍になり、$\alpha'M^2=-1/2$ の未射影の NS 真空が得られる。
:::

:::example[四つの複素生成子とカイラリティ]
横八方向の $\psi_0^i$ を二個ずつ組にし、$a_j=(\psi_0^{2j-1}+i\psi_0^{2j})/\sqrt2$ とする。$\{\psi_0^i,\psi_0^j\}=\delta^{ij}$ から $\{a_j,a_k^\dagger\}=\delta_{jk}$ である。各組の占有数は 0 または 1 なので、偶数占有が $1+6+1=8$、奇数占有が $4+4=8$ となる。
:::

### 平面と円筒の境界条件を対応させる

円筒の複素座標を $w=t_{\rm E}+i\sigma$、平面座標を $z=e^w$ とする。重み $1/2$ の場は $\psi_{\rm cyl}(w)=(\dd z/\dd w)^{1/2}\psi_{\rm plane}(z)=z^{1/2}\psi_{\rm plane}(z)$ と変わる。平面で $\psi_{\rm plane}(z)=\sum_r\psi_r z^{-r-1/2}$ と展開すると、円筒では $\sum_r\psi_r e^{-rw}$ である。$w\mapsto w+2\pi i$ で反周期なら $r\in\Z+1/2$、周期なら $r\in\Z$ となる。逆に平面では NS の冪が整数で、R は $\psi$ から見れば原点で分岐を持つ。R 基底の生成を表すスピン場の役割は、この分岐を作ることである。

モードの反交換子は、$z^{r-1/2}w^{s-1/2}$ を $\psi(z)\psi(w)$ に掛け、まず $z=w$ の留数を取ると $w^{r+s-1}$ になるので得られる。従って $\psi_{r>0}$ は消滅、$\psi_{r<0}$ は生成演算子である。エルミート共役は Lorentz の実条件に合わせ $\psi_r^\dagger=\psi_{-r}$ と取る。光円錐ゲージの横成分なら $\langle0|\psi_r^i\psi_{-r}^j|0\rangle=\delta^{ij}$ である。時間成分もそのまますべて物理状態として数えると、$\eta^{00}=-1$ から負規格の状態が現れる。このため共変形式では超 Virasoro と BRST の拘束が必要である。

:::example[円筒上の最低の二種類の位相]
NS の $r=1/2$ は $\sigma$ を一周すると $-1$、R の $r=1$ は $+1$ となる。平面で前者の冪は $z^{-1}$、後者は $z^{-3/2}$ である。平面での $z^{-3/2}$ の分岐と、円筒上の $r=1$ の周期性は、写像の平方根によって両立する。
:::

### 零点エネルギーと質量の整合条件を分ける

横の組を $d_\perp$ 個とすると、各方向の有限なエネルギーを足して $E_{\rm NS}=-d_\perp/16$、$E_{\rm R}=0$ となる。質量式の切片は $a=-E$ と取る。臨界次元を求めるには後のゴーストの計算が必要であり、この式だけで $d_\perp=8$ を仮定しない。臨界の場合に $d_\perp=8$ を入れると $a_{\rm NS}=1/2$ である。非コンパクトな閉弦の質量条件は
$$
\frac{\alpha'M^2}{4}
=N_L-a_L=N_R-a_R
$$
であり、$N_L=N_R$ とは限らない。例えば NS–R の最低物理状態では $N_L=1/2,N_R=0$ と異なるが、左と右で切片を引いた値は同じゼロである。この差の条件は世界面空間方向の並進の拘束から来る。片側だけを励起した状態が質量条件を満たすかどうかは、どちらの切片を使うかまで指定して判定する。

開弦では $\alpha'M^2=N-a$ である。NS 基底を $|0;k\rangle$ として一つのフェルミオン励起 $\epsilon_\mu\psi_{-1/2}^\mu|0;k\rangle$ を取る。$G_{1/2}$ を作用させると、$\alpha_0\cdot\psi_{1/2}$ の項が $\epsilon\cdot k$ に比例する。従って横条件 $\epsilon\cdot k=0$ である。一方 $G_{-1/2}$ を真空へ作用させた零状態は $k\cdot\psi_{-1/2}$ に比例し、$k^2=0$ で規格がゼロである。これを同一視すると $\epsilon_\mu\sim\epsilon_\mu+\lambda k_\mu$ が得られる。このため十次元の共変偏極は 8 横自由度になる。Ramond の零モードの $p\cdot\Gamma$ の拘束とは異なる条件である。

:::example[混合セクターの準位を一つ上げる]
左が NS、右が R の場合、左を $N_L=3/2$ とすれば右は $N_R=1$ で整合する。従って閉弦では $M^2=4/\alpha'$ である。左の同じ $N_L$ だけを開弦に用いると $M^2=1/\alpha'$ なので、開弦の式から閉弦の周波数をそのまま読めない。
:::

### Ramond の零モードとスピンの重み

横八つの Clifford 行列を $\gamma^i=\sqrt2\psi_0^i$ とする。$a_j=(\psi_0^{2j-1}+i\psi_0^{2j})/\sqrt2$ を消滅演算子とし、$N_j=a_j^\dagger a_j$ とすると、$i\gamma^{2j-1}\gamma^{2j}=2N_j-1$ である。四組を掛けると横のカイラリティは $\prod_j(2N_j-1)=(-1)^{\sum_j N_j}$ となる。回転の生成子は $-\frac i2\gamma^{2j-1}\gamma^{2j}$ の規約なら $1/2-N_j$ であり、各重みは $\pm1/2$ である。生成演算子は $N_j$ を一つだけ変えるため、その平面の重みを反転し、全体のカイラリティも反転する。正と負のカイラリティの次元が等しいことは、例えば任意の一つの $\gamma^i$ が可逆で二つを交換することからも従う。

十次元での非零の光的 $p^\mu$ の Dirac 条件では 32 成分の Dirac 表現が 16 に減り、Weyl の射影で 8 に減る。$p^2\ne0$ なら $(p\cdot\Gamma)^2=p^2 I$ で逆行列があるので基底の条件は解を持たない。$p=0$ では方程式が自明になり、この偏極の数え方は非零の運動量の質量ゼロ表現から連続に定義する。零運動量のスピン場から作る時空超電荷の数 16 と、非零の光的運動量の粒子の偏極数 8 をここで区別できる。

## GSO 射影

:term[GSO 射影]{en="Gliozzi–Scherk–Olive projection" yomi="じーえすおーしゃえい"} はフェルミオン数のパリティを用いてセクターごとに状態を選ぶ。NS では真空から数えて奇数個のフェルミオンを残す規約を選ぶ。真空の $\alpha'M^2=-1/2$ は除かれ、一つの $\psi^i_{-1/2}$ で $N=1/2$ となる横ベクトルが残る。R では零モードの積で定まるカイラリティに、非零モードのパリティを掛けて射影する。基底の Clifford 生成演算子を一つ作用させるとカイラリティが反転するため、零モード真空の二つの固有空間は各 8 次元である。

この選択の振幅での意味は世界面のスピン構造の和である。トーラスの時間周期と空間周期を交換する変換がフェルミオン数の挿入と境界条件を交換するため、一セクターだけを独立に残す操作では整合しない。相互局所性とスピン構造の全体符号の導出は :cite[polchinski-2] を参照する。

### 射影後の最初の有質量準位

NS のフェルミオン数が奇数である条件のもと、$N=3/2$ の状態は $\psi_{-3/2}^i$、$\alpha_{-1}^i\psi_{-1/2}^j$、$\psi_{-1/2}^{[i}\psi_{-1/2}^j\psi_{-1/2}^{k]}$ の三種類である。次元は $8+64+56=128$ である。R の $N=1$ では、$\alpha_{-1}^i$ は真空のカイラリティをそのまま選び、$\psi_{-1}^i$ は逆のカイラリティを選ぶ。いずれも $8\times 8$ 個で合計 128 である。両セクターで $\alpha'M^2=1$ なので、時空超対称性は質量を保ってこれらを組にできる。

:::example[真空を除いても励起が残る]
$\psi_{-1/2}^1\psi_{-1/2}^2\ket0$ は $N=1$ であるがフェルミオン二個なので NS の射影で除かれる。一方 $\alpha_{-1}^1\psi_{-1/2}^2\ket0$ は $N=3/2$ でフェルミオン一個なので残る。自由な NS では、各フェルミオンが半整数、各ボソンが整数の準位を加える。従ってフェルミオン数が奇数の条件は $N\in\Z+1/2$ と一致する。
:::

:::example[同じ質量を持つ異なる R 基底]
次元 8 の許容真空 $8_s$ を $N=0$ に選ぶと、$N=1$ の $\alpha_{-1}\ket{8_s}$ と $\psi_{-1}\ket{8_c}$ はどちらも残る。$\psi_{-1}\ket{8_s}$ の方はフェルミオン数が一つ増え、選んだ射影の固有値が逆になる。
:::

### 射影演算子と励起の母関数

NS の振動子真空を偶とし、生成演算子の個数のパリティを $P_{\rm NS}=(-1)^{N_\psi}$ とする。射影 $\Pi_{\rm NS}=(1-P_{\rm NS})/2$ は $\Pi_{\rm NS}^2=\Pi_{\rm NS}$ である。$q=e^{2\pi i\tau}$ を跡の変数とすると、一つの NS フェルミオンの各正モードは占有 0 または 1 であるから、$(1+q^r)$ が掛かる。$P_{\rm NS}$ を挿入した跡では $(1-q^r)$ になる。横ボソンの $(1-q^n)^{-8}$ と切片を合わせると
$$
Z_{\rm NS}^{\rm proj}
=\frac{q^{-1/2}}2\prod_{n\ge1}(1-q^n)^{-8}
\left[\prod_{n\ge1}(1+q^{n-1/2})^8
-\prod_{n\ge1}(1-q^{n-1/2})^8\right].
$$
括弧の差にはフェルミオンの奇数占有だけが残る。最低の項は $16q^{1/2}$ であり、外の $1/2$ と切片を掛けて $8q^0$ になる。次の $q^1$ は $8+64+56=128$ である。この積表示は準位の係数として解釈するか、$|q|<1$ で収束する関数として使う。

R では $P_{\rm R}=\Gamma_\perp(-1)^{N_\psi^{\rm nz}}$ とする。$\Gamma_\perp$ は零モードのカイラリティ、$N_\psi^{\rm nz}$ は非零の励起数である。各非零 Fock 状態について、$\Pi_{\rm R}^{(\pm)}=(1\pm P_{\rm R})/2$ で許容される零モード基底は 8 個である。よって二つのカイラリティのそれぞれで、回転を挿入しない母関数は
$$
Z_{\rm R}^{\rm proj}=8\prod_{n\ge1}\frac{(1+q^n)^8}{(1-q^n)^8}
=8+128q+1152q^2+\cdots .
$$
例えば $q^2$ には一つの $n=2$ のボソンまたはフェルミオンから 16、$n=1$ の二励起から $36+64+28=128$ が出る。零モードの 8 を掛けると $8(16+128)=1152$ である。回転を跡に入れれば零モードの $8_s$ と $8_c$ は異なる重みを持つため、同じ数値の母関数から同一の表現とは結論できない。

:::example[偶と奇の R 励起でのカイラリティ]
$P_{\rm R}=+1$ を残すと、非零フェルミオンが二個の状態は $\Gamma_\perp=+1$ の真空に作用し、一個の状態は $\Gamma_\perp=-1$ の真空に作用する。例えば $\psi_{-1}^i\psi_{-1}^j$、$i\ne j$ は $N=2$ で前者に入り、$\psi_{-2}^i$ は同じ $N=2$ で後者に入る。R では準位の整数性からカイラリティを読めない。
:::

### スピン場との相互局所性で符号を決める

五つの複素フェルミオンを $\psi^I_\pm=e^{\pm iH_I}$ とする。後の節で導く $-\tfrac12$ ピクチャーの時空超電流は $e^{-\phi/2}e^{i\sum_I s_I H_I}$ であり、$s_I=\pm1/2$ である。NS の $-1$ ピクチャーでフェルミオン電荷 $m_I\in\Z$ の頂点と積を作ると、指数の縮約の冪は
$$
-\frac12+\sum_I s_I m_I .
$$
微分場を掛けても冪は整数だけ変わる。従って電流の輪郭を頂点の周りで一周させても分岐を持たないためには $\sum_I m_I$ が奇数でなければならない。$m_I$ は正と負のフェルミオンの出現数の差であるから、$\sum_I m_I$ の偶奇は全フェルミオンの数の偶奇に一致する。この結果が NS の奇数射影を与える。純ボソン励起や NS 真空は、電流と相互局所でない。増えたボソンの振動子の数でこの分岐は変わらない。

R の同じ $-\tfrac12$ ピクチャーの基底 $e^{-\phi/2}S_{\vec t}$ と積を取る。$\vec s$ と $\vec t$ の符号が異なる箇所の数を $k$ とすれば、冪は $-1/4+(5-2k)/4=1-k/2$ である。従って $k$ が偶数、すなわち $\vec s,\vec t$ が同じカイラリティを持つと相互局所になる。R の非零のフェルミオンを一つ追加すると冪の半整数性が反転するため、同じ射影を保つには基底のカイラリティを反転しなければならない。この議論では平坦な十次元かつ一つのカイラル側の超電荷を選んでいる。左右をどのように組にするかの全体の条件には、トーラスのスピン構造と閉弦の準位整合も必要である。

:::example[二つの基底スピン場の分岐]
$\vec s=(+,+,+,+,+)/2$ を取る。$\vec t=(-,-,+,+,+)/2$ なら $k=2$ で冪はゼロ、$\vec t=(-,+,+,+,+)/2$ なら $k=1$ で冪は $1/2$ である。後者をそのまま残すと電流の輪郭を回したときの符号が変わる。従って R の射影を「零モードをすべて残す」としてはならない。
:::

### 同じ跡に使う二つの時間境界条件

有質量も含む射影において、時間側の境界条件は演算子の跡に $(-1)^F$ を挿入するかどうかで変わる。例えば一つのフェルミオンの生成消滅対で $H=r a^\dagger a$ とすると、跡は $1+e^{-2\pi t r}$、符号付きの跡は $1-e^{-2\pi t r}$ である。Grassmann のコヒーレント状態の跡では始端と終端を反周期に同一視するが、$(-1)^F a(-1)^F=-a$ の挿入でその符号が反転する。従って空間円の NS/R と時間円の挿入の有無を合わせて、トーラスの四つのスピン構造になる。R 側の符号付きの跡が回転なしではゼロになるのは、$8_s$ と $8_c$ の差が零モードの跡で消えるためであり、境界条件の選択肢がなくなったという意味ではない。トーラス全体のモジュラー変換は [Type I 弦とヘテロティック弦](/physics/string-theory/heterotic-type-i/) で求める。

## 超弦の臨界次元 D = 10

$T_\psi=-:\psi\cdot\partial\psi:/2$ の自己積で、一方向の四重極の係数は $1/4$ となる。実際、二つの二重縮約の組で、フェルミオンの符号を含む係数は $-1$ と $2$、外の係数は $1/4$ である。従って $c_\psi=1/2$、物質の合計は $3D/2$ である。$G(z)G(w)$ の二重縮約は $D/(z-w)^3$ であり、単縮約は $2(T_X+T_\psi)/(z-w)$ を与える。標準形の三重極 $2c_{\rm m}/3$ とも一致する。

微分同相の $bc$ ゴーストは $-26$ である。反交換する局所超対称性からは可換の $\beta\gamma$ が生じ、ウェイトは $(3/2,-1/2)$ である。可換な一次系の四重極は反交換系に対し符号が反転し、$c_{\beta\gamma}=-1+3(2\lambda-1)^2=11$ となる。従って総中心電荷は $3D/2-15$ であり、Weyl 不変性は $D=10$ を要求する。

### 超電流 OPE とゴーストの重み

$\psi^\mu(z)\psi^\nu(w)\sim\eta^{\mu\nu}/(z-w)$、$G=i\sqrt{2/\alpha'}\,\psi\cdot\partial X$ とする。$GG$ の二重縮約には $(-2/\alpha')(-\alpha'/2)D=D$ が掛かるので三重極は $D/(z-w)^3$ である。$\psi$ だけを縮約した残りは $-2:\partial X\cdot\partial X:/[\alpha'(z-w)]$、$\partial X$ だけを縮約した残りは $:\partial\psi\cdot\psi:/(z-w)$ である。最後の等号では $:\psi\cdot\psi:=0$ を使い $z=w$ の一次展開を取った。従って単極が $2T$、三重極が $2c/3$ となり、$c=3D/2$ を独立に得る。

局所超対称のゴースト $\gamma$ は重み $-1/2$、反ゴースト $\beta$ は作用 $\int\beta\bar\partial\gamma$ が無次元になるように $3/2$ である。$\beta,\gamma$ は可換であり、二重縮約の統計の符号は $bc$ と逆である。従って同じ重みの公式の全体の符号を反転し $c_{\beta\gamma}=2(6(3/2)^2-6(3/2)+1)=11$ となる。

:::example[一成分分の中心項]
$X,\psi$ が一組なら $GG$ の三重極は 1、$c=3/2$ である。従って $G_{3/2}$ と $G_{-3/2}$ の反交換子の定数は $(c/3)((3/2)^2-1/4)=1$ である。$r=1/2$ では同じ定数が消える。
:::

:::example[十次元から一つ減らした世界面]
$D=9$ の平坦な座標とその超パートナーしかないなら $c_{\rm tot}=27/2-26+11=-3/2$ である。半径有限の円周にコンパクト化した第十方向は、一組の世界面場として残るので、これを足せば総中心電荷はゼロである。
:::

### 一次ゴーストの応力テンソルを縮約する

一次系の重みを $(\lambda,1-\lambda)$ とし、可換な $\beta(z)\gamma(w)\sim-1/(z-w)$、$\gamma(z)\beta(w)\sim1/(z-w)$ を用いる。応力テンソルは
$$
T_{\beta\gamma}=-\lambda:\beta\partial\gamma:
-(\lambda-1):\partial\beta\,\gamma:
$$
と取る。例えば $\beta$ と積を作ると、第一項で $\partial\gamma(z)\beta(w)\sim-1/(z-w)^2$ が出て二重極は $\lambda\beta$、展開の単極 $\lambda\partial\beta$ と第二項の $-(\lambda-1)\partial\beta$ の和は $\partial\beta$ である。$\gamma$ にも同じ計算を行うと重み $1-\lambda$ になる。自己 OPE の四重極は、$:\beta\partial\gamma:$ 同士と $:\partial\beta\,\gamma:$ 同士から $\lambda^2+(\lambda-1)^2$、二つの交差から $4\lambda(\lambda-1)$ である。従って $c/2=6\lambda^2-6\lambda+1$ となる。順序を交換する際の縮約に反交換の符号が付く $bc$ 系ではこの符号が逆になる。

$\lambda=3/2$ の可換系では $c=11$、$\lambda=2$ の反交換系では $c=-26$ である。世界面の局所超対称変換のパラメータは奇であり、その Faddeev–Popov 行列式は通常の逆行列式なので可換な場で表す。これがゴーストと物質フェルミオンに反対の統計を用いる理由である。閉弦では左右それぞれについて中心項がゼロでなければならない。例えば片方の不足を反対側の過剰で相殺すると、片側だけの正則座標変換の中心項は残る。

### 物質超 Virasoro と全系の拘束の区別

:eqref[eq-string-super-virasoro] の中心電荷は物質の $c_{\rm m}=15$ であり、物質の超電流の OPE には臨界次元でも三重極がある。総系で消えるのは、ゴーストを含む拘束の中心項である。ボソン Virasoro についても同じく、物質 $L_m$ と全系の $L_m$ を区別する。共変量子化では正のモードの拘束を満たし、負のモードから得た零状態との同値類を取る。それをゴースト込みで記録するのが BRST のコホモロジーである。中心項が消えれば正のモードだけの存在を語るのではなく、全てのモードのゲージ代数を閉じられる。RNS の BRST 電流の全てのゴースト項を導くには、超モジュライとゴーストの零モードをそろえて正則化する必要があるので :cite[polchinski-2] を参照する。ここでは自由な物理頂点の重みと正の物質モードが課す偏極条件を使う。

:::example[正則超電流に残る三重極]
$D=10$ において $G_{\rm m}(z)G_{\rm m}(w)$ の三重極は $10/(z-w)^3$ である。従って例えば $\{G_{3/2}^{\rm m},G_{-3/2}^{\rm m}\}$ の中心項は $(15/3)(9/4-1/4)=10$ になる。一方、ゴーストも合わせた中央電荷はゼロである。このため物質のモード代数に最初から $c_{\rm m}=0$ を代入して拘束を課すことはできない。
:::

### 内部超共形理論を使うときの数え方

十次元の自由な平坦方向が十個あるとき、一組ごとの $c=3/2$ が 15 になる。いくつかの方向を単純な円周にコンパクト化しても局所 OPE は同じであり、零モードのスペクトルだけが変わる。そのため非コンパクトな次元の数が例えば 9 になっても、世界面の物質中心電荷は 15 のままである。より一般に $d$ 個の非コンパクト自由方向と内部超共形理論を組にするなら、内部の必要な中心電荷は $c_{\rm int}=15-3d/2$ である。この式は左右独立な条件であり、内部の実際のスペクトルやモジュラー不変性までは決めない。

:::example[四次元の場合の世界面の条件]
$d=4$ なら非コンパクト部分の $c=6$ なので内部には $c=9$ が要る。平坦な六トーラスなら六組の自由場から $9$ を得る。ここでは中心電荷が一致することだけを検査した。ゲージ対称性や残る時空超対称性を求めるには、内部の頂点演算子やスピン場も必要になる。
:::

### 最初の有質量準位を十次元の回転で整理する

非零の質量を持つ十次元粒子を静止系で見ると、空間回転の little group は $\operatorname{Spin}(9)$ である。光円錐の横八方向だけでは $\operatorname{Spin}(8)$ の表現が見えている。NS の $N=3/2$ の三種類の励起は、八次元ベクトル、二つのベクトルの積、三形式であった。ここで九次元の対称跡なし二階テンソルを横八方向と第九方向に分けると、横対称跡なし $35$、混合 $8$、全体の跡の拘束後に一つ残るスカラーの $1$ である。合計は $44$ となる。九次元の三形式は、添字が全て横の $56$ と第九方向を含む横二形式の $28$ であり、合計が $84$ である。従って NS の $128$ は、これら二つを横回転に制限したときの成分に一致する。質量ゼロのベクトルが横 8 だったことから、有質量なベクトルの積も同じ分解でよいと決めてはならない。

R の最初の有質量の状態は、横ベクトルと $8_s\oplus8_c$ の積で $128$ 個である。九次元では基本スピノルの次元は 16 であり、ベクトルスピノル $9\cdot16$ からガンマトレースの $16$ を引けば $128$ となる。全射性は、ガンマトレースの逆像を第 $i$ 成分 $\gamma_i u/9$ に取って確かめる。この表現を横八方向に制限すると、第九成分は横のガンマトレースにより決まるため、残る八成分は自由である。従って R で直接数えた $8(8+8)$ を得る。違う記述で同じ次元になる理由は、残っている成分の写像をこのように作れるからである。

## Type IIA 超弦と Type IIB 超弦

閉弦では左右の NS と R を独立に選ぶ。NS–NS は $8_v\otimes8_v$ であり、$35+28+1$ が計量、二形式、ディラトンである。NS–R と R–NS は時空フェルミオンであり、ベクトルとスピノルの積をガンマ行列で縮約するとスピン $1/2$、核がスピン $3/2$ の偏極になる。ガンマトレースは全射である。実際 $\sum_i\Gamma^i\Gamma^i=8$ なので各スピノルを $\Gamma^i/8$ で持ち上げられ、核の次元は $64-8=56$ である。

:::definition[Type II の左右カイラリティ]{#def-string-type-ii}
:term[Type IIA 超弦]{en="Type IIA superstring" yomi="たいぷつーえーちょうげん"} は左右の時空超電荷のカイラリティが逆、:term[Type IIB 超弦]{en="Type IIB superstring" yomi="たいぷつーびーちょうげん"} は同じである。
:::

R–R では左右のスピノルをガンマ行列の反対称積で展開する。:cite[polchinski-2] の Clifford 表示を用いると、IIA の独立なポテンシャルは一形式と三形式で偏極は $8+56=64$、IIB は零形式、二形式、自己双対な五形式強度を持つ四形式で $1+28+35=64$ である。ここで四形式の 70 横偏極は自己双対条件で半分になる。横座標一つの T 双対性は右のフェルミオンを反転し、右の零モードスピノルに Clifford 行列一つを作用させる。従ってカイラリティが逆転し、円周上の IIA と IIB を結ぶ。

### R–R の偏極を反対称テンソルに分ける

八次元の横空間で $8_s\otimes 8_c$ はベクトル 8 と三形式 56 に分かれる。理由は、奇数個の横 Gamma 行列の反対称積が $8_s$ と $8_c$ を結び、Hodge 双対で五形式と七形式がそれぞれ三形式と一形式に対応するためである。独立性は Clifford 行列の跡で互いに直交することから確認でき、$8+56=64$ で全成分を尽くす。同じカイラリティなら偶数積であり、零形式 1、二形式 28、半分の四形式 35 に分かれる。四形式にかかる Hodge 射影の符号は選んだカイラリティで決まる。従って IIA では $C_1,C_3$、IIB では $C_0,C_2$ と自己双対な強度を持つ $C_4$ を使う。

:::example[自由度を物質の二種類で比較する]
IIB の NS–NS は $35+28+1=64$ であり、R–R は $1+28+35=64$ である。合計は 128 である。$C_4$ の横成分 $\binom84=70$ を全部数えると自己双対条件を二重に数え、フェルミオンの 128 と一致しない。
:::

:::example[円周双対でカイラリティが反転する]
右の一方向を反転すると、右の Clifford 作用はスピノルへの一つの Gamma 行列の作用で表せる。カイラリティ演算子は各 Gamma 行列と反交換するから、固有値が逆になる。左のスピノルは変わらないので、元が両側同じ IIB なら双対は逆カイラリティの IIA になる。
:::

### 四セクターの偏極を一つずつ構成する

光円錐の非零の質量ゼロ運動量で回転する八方向を取る。NS–NS 偏極 $e_{ij}$ を
$$
e_{ij}
=\left(\frac{e_{ij}+e_{ji}}2-\frac{\delta_{ij}}8 e^k{}_k\right)
+\frac{e_{ij}-e_{ji}}2+\frac{\delta_{ij}}8 e^k{}_k
$$
と分ける。第一項は $8\cdot9/2-1=35$、第二項は $8\cdot7/2=28$、第三項は 1 である。それぞれ重力、二形式、ディラトンの偏極である。対称部を計量とディラトンに分ける際には、時空の場の再定義で混合の規格化が変わる。ここでの分解は横の回転群に関して既約な成分を数えている。

NS–R の $8_v\otimes8_s$ を例に取ると、$\gamma^i$ は $8_s$ を $8_c$ に写す。よってガンマトレースは $8_c$、ガンマ跡なしの核は 56 次元である。$8_v\otimes8_c$ では逆のカイラリティに写る。共変な十次元のベクトルスピノルで重力多重項を扱うとき、粒子の $\Gamma$ 跡なしの成分はグラビティーノであり、跡に対応するスピノルはディラティーノである。左右の R に割り当てた Weyl カイラリティを同じにすれば、二つのグラビティーノも同じ時空カイラリティである。逆ならグラビティーノも互いに逆で、どちらの閉弦でもフェルミオン偏極は $2(56+8)=128$ になる。

:::example[一つのガンマ跡とその補空間]
任意の横スピノル $u\in8_c$ について $\Psi_i=\gamma_i u/8$ と選ぶと、$\Psi_i\in8_s$ で $\sum_i\gamma^i\Psi_i=u$ である。任意の $\widetilde\Psi_i$ からこの形にした自身のトレースを引けば、跡なしの成分が残る。従って分解は次元の足し算だけでなく、偏極を明示して得られる。
:::

### Clifford 基底の完全性と五形式の自己双対条件

八次元の Dirac スピノルは $S=8_s\oplus8_c$、$\dim S=16$ である。$\gamma^{i_1}\cdots\gamma^{i_k}$ を昇順の相異なる添字について取ると、$2^8=256$ 個が $\operatorname{End}(S)$ の基底になる。二つの異なる積の随伴を掛けた結果は、定数を除いて空でない添字集合 $I$ の積である。$|I|$ が奇数で $|I|<8$ なら集合の外の $\gamma^j$、$|I|$ が偶数なら集合の中の $\gamma^j$ で共役すれば符号が反転し、トレースがゼロである。よって異なる積は跡内積で直交し、数が $\dim\operatorname{End}(S)$ と一致する。偶数積はカイラリティを保ち、奇数積は交換する。さらに積に $\gamma^1\cdots\gamma^8$ を掛けると、向きで決まる符号を除いて補集合の積になる。片側のカイラリティに制限するとこの行列は定数なので、独立な積は Hodge 対の片方に減る。

同カイラリティの $8_s\otimes8_s$ では、零次 1、二次 28 と、四次で Hodge 固有値を一つ選んだ 35 が残る。四次の Hodge 星は Euclid の八方向で $(-1)^{4(8-4)}=1$ を二乗に持つ。標準の直交基底四形式と、その補集合を取った四形式とを二つずつ組にすると、和・差の一方ずつが二つの固有値に属する。反対カイラリティの積では一次 8 と三次 56 が残り、五次と七次はそれらの双対である。十次元の Ramond の頂点では Dirac 方程式を左右について課した強度の bispinor が現れる。例えば平面波の $F_5=k\wedge C_4$ では $F_5=*_{10}F_5$ が横 $C_4$ に八次元の一方の Hodge 射影を課す。十次元の Lorentz 計量では五形式について $*^2=(-1)^{5(10-5)+1}=1$ なので、実の自己双対条件が可能である。

:::example[補集合の対を用いて数える]
横基底を $e^1,\ldots,e^8$ とし、向きを昇順に取る。$*e^{1234}=e^{5678}$ なので $e^{1234}+e^{5678}$ と $e^{1234}-e^{5678}$ は互いに逆の Hodge 固有値を持つ。全 70 個の基底は 35 対になり、固有値を一つだけ選ぶと 35 個である。$C_4$ のゲージ条件で縦成分を落とす段階の後に、さらにこの半減を行う。
:::

### 一方向の T 双対性を形式で追う

コンパクトな空間方向を $y$ とし、右の物質フェルミオンの $\psi_R^y$ も $\bar\partial Y_R$ と共に反転する。これで右の超電流 $G_R\propto\psi_R\cdot\bar\partial X_R$ は不変である。右の Ramond スピノルへの反射は Clifford の奇数元を含むのでカイラリティを反転する。例えばピン群の反射は積 $\Gamma^y$ と反射の際の全体符号を合わせて表す。従って IIA と IIB の十次元の記述が円周上で交換される。

線形の R–R 偏極を Clifford 形式で書くと、$\Gamma^y$ の作用は次数を一つ上げる外積と一つ下げる内部積の和になる。これは $\Gamma^y\Gamma^{[i_1}\cdots\Gamma^{i_k]}$ を反交換して、添字 $y$ が含まれない項では完全反対称積になり、含まれる項では $\Gamma^y\Gamma^y=1$ で消えることから従う。例えば IIA の $C_1$ の円周方向成分は九次元のスカラーで、双対側では $C_0$ に対応する。$C_1$ の非コンパクト成分 $C_\mu$ は双対側では $C_{\mu y}$ になる。形式場の係数を質量や電荷まで比較するには、円周体積と規格化の変換も合わせる。

:::example[九次元で同じベクトルを数える]
一対の質量ゼロの Type II の自由な場で $C_1$ を九次元の $C_\mu$ と $C_y$ に分けると、横自由度は $7+1=8$ である。双対側の $C_{\mu y}$ と $C_0$ もそれぞれ $7,1$ を持つ。次数の異なる十次元のポテンシャルを比べても、共通の九次元の偏極は保存される。
:::

## 時空超対称性と Green–Schwarz 形式の概観

時空の超電荷は R のスピン場を用いる。10 個の実フェルミオンを 5 個の複素フェルミオンにし、各対を規格化した自由ボソン $H_j$ で表すとスピン場は $\exp(i\sum_j s_j H_j)$、$s_j=\pm1/2$ となる。指数の縮約からウェイトは $\sum_j s_j^2/2=5/8$ である。超ゴーストをボソン化した $\varphi$ の $e^{-\varphi/2}$ のウェイトは $-q(q+2)/2$ に $q=-1/2$ を入れて $3/8$ である。背後のボソン化と背景電荷の構成は :cite[polchinski-2] を参照する。積のウェイトは 1 なので留数で電荷を作れる。適切なスピン場の積の単極に時空の運動量を表す演算子が現れる。

Green–Schwarz 形式では時空スピノル $\theta$ が世界面の場となる。:term[カッパ対称性]{en="kappa symmetry" yomi="かっぱたいしょうせい"} は局所フェルミオン対称性であり、光円錐ゲージでは物理的な各側の横フェルミオンが 8 成分残る。この拘束の確立には Wess–Zumino 項を含む超空間作用の変分を要するため、詳細は :cite[gsw-1] を参照する。RNS では世界面の超対称性が作用に見え、Green–Schwarz 形式では標的時空での超対称性が作用に見える。

### スピン場で時空超電荷の重みを検査する

十個の実フェルミオンを五つの複素フェルミオンに組にし、$\psi^I_\pm=:e^{\pm iH_I}:$、$H_IH_J\sim-\delta_{IJ}\log(z-w)$ とする。交換符号には異なる $I$ の間のコサイクルを補う。スピン場 $S_{\vec s}=:e^{i\sum_I s_IH_I}:$、$s_I=\pm1/2$ は $\psi_\pm^I$ との OPE に半整数冪を持ち、挿入の周りでフェルミオンの境界条件を変える。重みは $\frac12\sum_I s_I^2=5/8$ である。超ゴーストをボソン化した $\phi$ の応力テンソルを $T_\phi=-\frac12(\partial\phi)^2-\partial^2\phi$ とすれば、縮約から $e^{q\phi}$ の重みは $-q(q+2)/2$ である。$q=-1/2$ の重み $3/8$ を足すと $e^{-\phi/2}S$ の重みは 1 になる。従ってこれを輪郭積分したものが時空超電荷の候補になる。可動頂点との OPE で整数冪が必要なことと、GSO 射影による局所性が結び付く。

:::example[二つの絵の重みを比べる]
$e^{-\phi}$ の重みは $1/2$ なので、質量ゼロの境界頂点 $e^{-\phi}\psi^\mu e^{ikX}$ は $k^2=0$ で重み 1 である。$e^{-2\phi}$ の重みは 0 であり、そのまま同じ $\psi^\mu$ を掛けると重みは $1/2$ になる。ゴーストの指数だけを変えて同じ物理頂点になるわけではなく、ピクチャー変換の演算子が必要である。
:::

:::example[光円錐 Green–Schwarz の切片]
横八方向に周期的なボソンと同じ周期のフェルミオンを置くと、各モードの二つの零点エネルギー $\pm n/2$ が対で相殺する。従って切片は 0 であり、零モードで生成する超多重項は最初から質量ゼロである。RNS で未射影の NS タキオンを明示してから除く構成とは、出発点の変数が異なる。
:::

### 時空超電荷の反交換子をスピン場から求める

$-\tfrac12$ ピクチャーの超電荷の電流を $j_\alpha=e^{-\phi/2}S_\alpha$ とする。同じカイラリティの二つの十次元スピン場の OPE のうち、ベクトルに写る成分は $S_\alpha(z)S_\beta(w)\sim (z-w)^{-3/4}(C\Gamma_\mu)_{\alpha\beta}\psi^\mu(w)$ である。冪は重みの差 $1/2-2(5/8)=-3/4$ であり、ボソン化して五つの $s_I,t_I$ のうち一つだけが同符号なら $\sum_I s_It_I=(1-4)/4=-3/4$ である。指数の和はその一つの $H_I$ で $\pm1$ の電荷を持つので、実ベクトルのフェルミオンを作る。係数をスピノルの基底にまとめたものが $C\Gamma_\mu$ である。

$e^{-\phi/2}$ 同士の縮約は $(z-w)^{-1/4}$ なので、積の留数は $(C\Gamma_\mu)_{\alpha\beta}e^{-\phi}\psi^\mu$ となる。零運動量のこの頂点をピクチャー 0 に上げると $\partial X^\mu$ が出る。実際、ピクチャーを上げる演算子の物質部分は $e^\phi G$ であり、$e^\phi(z)e^{-\phi}(w)$ が $(z-w)^1$、$G(z)\psi^\mu(w)$ が $\partial X^\mu(w)/(z-w)$ を含む。従って両者の有限項が残る。BRST 同値類で輪郭積分すると $\partial X^\mu$ の零モードは時空運動量であるため $\{Q_\alpha,Q_\beta\}\propto(C\Gamma_\mu)_{\alpha\beta}p^\mu$ である。相互作用する背景でのピクチャー変換の零モードと境界は、単純な平坦世界面のこの計算とは別に扱う。

:::example[同カイラリティの五つの電荷]
$\vec s=(+,+,+,+,+)/2$、$\vec t=(+,-,-,-,-)/2$ は負符号がともに偶数個で、同じカイラリティである。指数を足したスピン場の積は $e^{iH_1}$ を作り、縮約は $(z-w)^{-3/4}$ に比例する。超ゴーストを掛けると単極であり、第一複素平面の運動量の組を取り出す。
:::

### 超ゴーストのボソン化と物理頂点

$\phi(z)\phi(w)\sim-\log(z-w)$ のスカラーと、重み $(1,0)$ の反交換系 $(\eta,\xi)$ を用い、$\beta=e^{-\phi}\partial\xi$、$\gamma=\eta e^{\phi}$ と表す。$\partial\xi(z)\eta(w)\sim-1/(z-w)^2$ と $e^{-\phi(z)}e^{\phi(w)}\sim(z-w)$ の積から、$\beta\gamma\sim-1/(z-w)$ を再現する。$\phi$ の改善を含む重みは $h(e^{q\phi})=-q(q+2)/2$ である。$q=-1$ で $h=1/2$ なので $\beta$ の積は $3/2$、$q=1$ で $h=-3/2$ なので $\gamma$ は $-1/2$ である。$\phi$ の改善同士は四重極に 6 を加えるため、$c_\phi=1+12=13$ である。$(\eta,\xi)$ は反交換の重み $(1,0)$ の一次系なら $c=-2$ なので合計 11 が戻る。この表示で $\xi$ の定数モードを独立な物理自由度として足すわけではない。ピクチャーの BRST 同値を定義するにはこの零モードの扱いも要り、:cite[polchinski-2] を参照する。

一側の NS の $-1$ ピクチャーの頂点を
$$
V_{-1}(z)=e^{-\phi}\epsilon_\mu\psi^\mu e^{ik\cdot X_L}
$$
と書く。ここでは $X_L X_L\sim-(\alpha'/2)\log$ の規格化で、閉弦の一側の指数 $k\cdot X_L$ を用いる。開弦の境界を同じ正則場で表すなら、Neumann の境界値が $2X_L$ なので指数の $k$ を $2k_{\rm open}$ と読み替える。重みは $1+\alpha' k^2/4$ だから $k^2=0$ が必要である。$G$ と物質部分の二重極は $\psi$ と $\partial X$ を同時に縮約した $k\cdot\epsilon$ に比例する。その消滅が超 Virasoro の $G_{1/2}$ の横条件である。平坦な背景で $k$ に比例する偏極は零状態に対応する。R 側では $e^{-\phi/2}S_\alpha u^\alpha e^{ik\cdot X_L}$ に対し重み $3/8+5/8+\alpha'k^2/4$ となる。$G$ の $\psi$ がスピン場に与える分岐 $(z-w)^{-1/2}$ と、$\partial X$ が指数に与える単極から $(k\cdot\Gamma)u$ の係数を読む。これが R 基底の Dirac 条件を頂点で再現する。

### ピクチャーを変えて微分結合を見る

BRST の同値類においてピクチャーを一つ上げる演算子の物質部分は $e^\phi G$ である。$V_{-1}$ に対し $e^\phi(z)e^{-\phi}(w)\sim z-w$ なので、$G$ と物質頂点の単極から有限な項を得る。横条件で二重極は消える。$G$ の $\psi$ を縮約すると $\epsilon\cdot\partial X_L$、$\partial X_L$ を縮約すると $-i\alpha'(k\cdot\psi)(\epsilon\cdot\psi)/2$ が残る。従って共通の規格化を除いて
$$
V_0(z)=
\left[\epsilon\cdot\partial X_L
-\frac{i\alpha'}2(k\cdot\psi)(\epsilon\cdot\psi)\right]e^{ik\cdot X_L}
$$
となる。$k=0$ のベクトルではボソンの微分だけになり、円板の境界でのゲージ接続の結合と一致する。$\epsilon=k$ なら二つの同じフェルミオンの積が正規順序でゼロとなり、残りは $\partial e^{ikX_L}$ に比例する。従って輪郭内の積分頂点として、この偏極はゲージ変換の全微分に対応する。

:::example[変わるのはゴーストの係数だけではない]
$\epsilon\cdot k=0$ かつ $k\ne0$ で、$\epsilon$ を $k$ と独立な横偏極に取る。$V_0$ の二項はそれぞれ $\partial X_L$ 一つと $\psi$ 二つを持ち、両方とも重み 1 である。一方 $V_{-1}$ の $e^{-\phi}$ だけを取り除くと、物質の $\psi$ 一つで重み $1/2$ となり、積分頂点に必要な重みを失う。
:::

### Green–Schwarz 変数で見える対称性

超空間で $\theta^A$ を二つの十次元 Majorana–Weyl スピノルとし、$\Pi_a^\mu=\partial_aX^\mu-i\sum_A\bar\theta^A\Gamma^\mu\partial_a\theta^A$ を作る。定数の時空超対称変換 $\delta\theta^A=\epsilon^A$、$\delta X^\mu=i\sum_A\bar\epsilon^A\Gamma^\mu\theta^A$ の下で、$\delta\partial_a X$ と $\delta\bar\theta^A$ の項は消え合う。従って $\Pi_a^\mu$ とそこから作る引き戻し計量は時空超対称である。しかし物理フェルミオンの成分を正しく半減するには、単にこの面積項を使うだけでは足りない。特定係数の Wess–Zumino 項を加えた作用に局所な $\kappa$ 変換がある。この作用が $\kappa$ 変換で不変となることは、十次元の Fierz 恒等式と Wess–Zumino 項の変分を要するので :cite[gsw-1] を参照する。

引き戻しの二つの Gamma 行列を $\gamma_a=\Pi_a^\mu\Gamma_\mu$ と置けば、$\{\gamma_a,\gamma_b\}=2g_{ab}$ である。非退化な Lorentz 世界面で、その向きに沿う Clifford の体積要素 $\Gamma_\Sigma=\epsilon^{ab}\gamma_a\gamma_b/(2\sqrt{-\det g})$ は、局所直交枠では $\gamma_0\gamma_1$ である。二つの Gamma が反交換し $\gamma_0^2=-1,\gamma_1^2=1$ なので $\Gamma_\Sigma^2=1$ となる。$\kappa$ 射影ではこの体積要素に左右のスピノルの添字に作用する符号を組み合わせ、射影 $(1\pm\Gamma_\Sigma)/2$ の半分の方向へ動く。局所直交枠で世界面と直交する空間方向の Gamma 行列を $\Gamma_\perp$ とする。偶 Clifford 元 $\gamma_0\Gamma_\perp$ は十次元の Weyl カイラリティを保ち、$\Gamma_\Sigma$ と反交換する。従って各 Weyl 表現で体積要素の二つの固有空間の次元は等しい。光円錐ゲージで $p^+\ne0$ なら、$\Gamma^+\theta^A=0$ の形で残す 8 成分を選べる。これは質量ゼロ偏極を数えるときの RNS の Dirac 射影と成分数は同じだが、最初から時空スピノルを世界面変数に用いる構成である。

### 光円錐での Green–Schwarz スペクトルの検算

光円錐での各カイラル側は八つの横ボソン $X^i$ と八つの実フェルミオン $S^a$ を持つ。平坦な閉弦の通常の超対称境界条件では $S^a$ は周期的であり、$S_n$ と $\alpha_n$ の正整数周波数が一致する。$\acomm{S_m^a}{S_n^b}=\delta^{ab}\delta_{m+n,0}$ と規格化すれば、各 $n>0$ の零点エネルギーが打ち消し合う。$S_0$ はエネルギーゼロで八次元の Clifford 代数を作る。$S^a$ が横回転の $8_s$ に属する規約では、その表現の 16 基底は $8_v$ と $8_c$ に分かれる。具体的には $\gamma^i_{a\dot b}$ による写像 $S_0^a|i\rangle\propto\gamma^i_{a\dot b}|\dot b\rangle$ と $S_0^a|\dot b\rangle\propto\gamma^i_{a\dot b}|i\rangle$ が二つを交換する。横回転のベクトル、二つのスピノルの三つの八次元表現を結ぶこの Clifford 関係は :cite[gsw-1] の光円錐のスピノル規約に従う。従って各側に 8 ボソンと 8 フェルミオンがある。もう一方のカイラリティの Green–Schwarz 変数なら二つのスピノル表現を交換する。閉弦での左右の組は RNS の射影後の 128 ボソンと 128 フェルミオンを再現する。

:::example[第一励起の状態数を二つの形式で比較する]
Green–Schwarz 形式の一側で、周波数 1 のボソン振動子は八つ、フェルミオン振動子も八つある。零モードの 16 基底に一つ作用させると 256 状態で、元の 8 ボソンおよび 8 フェルミオンに、同じ数の統計を保つ作用と反転する作用を掛けるため各 128 となる。RNS では NS の $N=3/2$ と R の $N=1$ の二組に分かれて各 128 が出た。二つの表示で揃えるのは $N$ そのものではなく、切片を引いた $N-a$ である。
:::

### 超電荷が質量ゼロの多重項の中を移る

適切なピクチャーでの NS のベクトル頂点と R のスピノル頂点の間で、超電荷の輪郭積分の作用を比べる。$-1$ ピクチャーの NS 頂点に $e^{-\phi/2}S$ を近づけると、超ゴーストの縮約に $(z-w)^{-1/2}$、$S$ と $\psi^\mu$ の縮約に $(z-w)^{-1/2}$ が出る。従って留数は $e^{-3\phi/2}$ を持つ R 頂点であり、偏極は $\epsilon_\mu\Gamma^\mu$ で元の超電荷のスピノルを移した形になる。必要ならピクチャー変換を使い、異なるゴーストの表示を同じ質量殻の同値類で比較する。超電荷自身の時空運動量はゼロなので、$e^{ikX}$ は同じ $k$ を保つ。従って振動子の演算子の形は変わっても、$\alpha'M^2$ は変わらない。

反対向きの変換では二つの R のスピン場の積に $\psi^\mu$ の単極を作る成分がある。二つの $-\tfrac12$ ピクチャーを合わせると $-1$ になり、NS のベクトルの頂点と同じ重みになる。光円錐でこの作用を表す行列は、横ベクトルと二つのスピノルを結ぶ $\gamma^i$ である。質量ゼロでの反交換子は $(C\Gamma\cdot k)_{\alpha\beta}$ に比例するので、$k\ne0$ の光的運動量ではその行列の階数を数えて、非自明に働く成分が半分になることを確認できる。見かけ上は 16 の実超電荷があっても、与えた運動量の質量ゼロ多重項の上で生成消滅演算子になる数にはこの制約がある。

:::example[光的運動量の上の一側の重複度]
$k^+>0$ の光的運動量を取ると、規格化した一側の 16 実超電荷のうち 8 成分が非自明な正の Clifford 代数を作る。残りの 8 は反交換子の核にあり、正の内積の表現ではゼロに作用する。8 実 Clifford 生成子を四つの複素対に分けると、既約表現は $2^4=16$ 状態を持つ。フェルミオン数の偶奇は半分ずつである。この数は一側の $8_v$ と許容した R の $8$ に一致する。左右を独立に掛ける臨界の閉弦では全体で $16^2=256$ 状態である。
:::

### 超対称な射影と Type 0 の選択

左右の GSO 射影で時空超電荷を保存する場合には NS–R と R–NS が残り、NS–NS の未射影タキオンは消える。別の射影では世界面の局所超対称性を保ちつつ、混合セクターを除くことができる。例えば Type 0B の指標の組は $|O_8|^2+|V_8|^2+|S_8|^2+|C_8|^2$ であり、ここで $O_8$ は偶数の NS で $V_8$ は奇数の NS、$S_8,C_8$ は R の二つのカイラリティである。各指標のトーラスの変換と位相は [Type I 弦とヘテロティック弦](/physics/string-theory/heterotic-type-i/) で追う。この例の $O_8$ の左右には NS 真空が両側で残るので、切片の条件から $\alpha'M^2/4=-1/2$、すなわち $\alpha'M^2=-2$ である。R–R の二つの組からは二組の場が現れる。混合セクターがないので、時空のフェルミオンと超電荷を持たない。世界面の局所超対称性が消えたためではなく、トーラスの全状態の組合せを変えたためである。

## 演習問題

::::exercise[NS の境界条件]{#exr-string-superstrings-1 level=basic}
$r=3/2$ の円筒モードを一周期動かした位相を求めよ。

:::solution
$e^{-2\pi i(3/2)}=e^{-3\pi i}=-1$ であり、反周期である。
:::
::::

::::exercise[R の零モード]{#exr-string-superstrings-2 level=basic}
四組のフェルミオン生成消滅演算子で、零モード表現の次元を求めよ。

:::solution
各組は非占有と占有の二通りであり、反交換性によって同じ生成演算子を二度使えない。従って $2^4=16$ である。
:::
::::

::::exercise[NS の質量]{#exr-string-superstrings-3 level=basic}
開弦の NS で $N=3/2$ の $\alpha'M^2$ を求めよ。

:::solution
切片は $1/2$ なので $N-a=3/2-1/2=1$ である。
:::
::::

::::exercise[総中心電荷]{#exr-string-superstrings-4 level=basic}
$D=8$ の自由 RNS 座標とゴーストの総中心電荷を求めよ。

:::solution
物質は $3D/2=12$、ゴーストは $-26+11=-15$ であり、和は $-3$ である。
:::
::::

::::exercise[横フェルミオンの切片]{#exr-string-superstrings-5 level=advanced}
ボソンと NS フェルミオン一組の零点エネルギーから開弦の切片を導け。

:::solution
一組の和は $-1/24-1/48=-1/16$ である。八組では $-1/2$ となり、質量式に現れる切片はその反対符号の $1/2$ である。
:::
::::

::::exercise[R–R 偏極]{#exr-string-superstrings-6 level=advanced}
IIB の四形式ポテンシャルの独立偏極数を求めよ。

:::solution
光円錐で横方向は八つなので四形式の成分は $\binom84=70$ である。Hodge 双対で補集合と対になるので自己双対成分は $70/2=35$ である。
:::
::::

::::exercise[ガンマトレース]{#exr-string-superstrings-7 level=advanced}
$8_v\otimes8_s$ のガンマトレースが全射となる例を構成せよ。

:::solution
対象のスピノルを $u$ として、ベクトルスピノルの第 $i$ 成分を $\Gamma^i u/8$ と置く。ガンマトレースは $\sum_i\Gamma^i\Gamma^iu/8=u$ となる。
:::
::::

::::exercise[スピン場の重み]{#exr-string-superstrings-8 level=advanced}
スピン場と $e^{-\varphi/2}$ の重みの和を求めよ。

:::solution
五つのフェルミオン対から各 $1/8$ で $5/8$、超ゴーストから $-(-1/2)(3/2)/2=3/8$ を得る。和は 1 である。
:::
::::

::::exercise[最初の有質量閉弦多重項]{#exr-string-superstrings-9 level=advanced}
平坦な Type II の最初の有質量準位について、閉弦の $\alpha'M^2$ を求め、ボソンとフェルミオンの数を左右の NS/R から数えよ。

:::solution
一側の量は NS で $N-a=3/2-1/2=1$、R で $1-0=1$ であり、左右をどちらのセクターで組にしても準位整合を満たす。閉弦の係数は $\alpha'M^2/4$ なので、$\alpha'M^2=4$ である。一側の NS と R はそれぞれ 128 状態である。左右の一方だけが R のとき時空フェルミオン、両側とも NS または両側とも R のときボソンなので、それぞれ $2\cdot128^2=32768$ である。左右の R のカイラリティの組合せは IIA と IIB で異なるが、この段階の次元は同じである。
:::
::::

::::exercise[カイラリティと相互局所性の検査]{#exr-string-superstrings-10 level=advanced}
十次元のスピン場の電荷を $\vec s=(+,+,+,+,+)/2$ とし、$-\tfrac12$ ピクチャーで $\vec t=(+,-,-,-,+)/2$ の R 基底と近づける。積の冪と、カイラリティを保存する射影に生き残るかを答えよ。さらに $t_5$ を反転して比較せよ。

:::solution
最初は負符号の場所が三つ違うので $\vec s\cdot\vec t=(5-2\cdot3)/4=-1/4$ である。超ゴーストの $-1/4$ を加えると冪は $-1/2$ で、輪郭を一周すれば負符号が出る。従ってこの基底は同じ超電荷と相互局所ではない。$t_5$ を反転すると違う場所は四つになり、冪は $(5-2\cdot4)/4-1/4=-1$ となる。今度は相互局所で、その単極の物質部分は二つの電荷が同符号の第一平面の $\psi$ である。二つの $-\tfrac12$ ピクチャーの和により、超ゴースト部分は $e^{-\phi}$ となる。
:::
::::
