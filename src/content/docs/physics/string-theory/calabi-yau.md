## この章の目標

- 内部の平行スピノルから四次元の超電荷を数える。
- Calabi–Yau 三次元多様体の例を構成する。
- Type II の質量ゼロ多重項を Hodge 数で数える。
- オービフォールド、ミラー対称性、カイラル物質の関係を調べる。

## 4 次元の超対称性と特殊ホロノミー

ワープ、流束、局在した源のない背景 $\R^{1,3}\times X$ を考える。十次元超重力のグラビティーノの変分はこの条件で $\delta\psi_M=\nabla_M\epsilon$ に比例する。従って四次元に残る超電荷は、内部で $\nabla_m\eta=0$ となる平行スピノルから得られる。ホロノミーとは閉曲線に沿う平行移動の群である。平行スピノルはこの群で不変である。逆に一点で不変なスピノルを選び、曲線に沿って移すと二経路の差は閉曲線の作用だから経路に依存せず、平行な断面になる。

六次元の複素スピノルは三つの Clifford 生成演算子を用い $\bigwedge^\bullet\C^3$ と書ける。$SU(3)$ は 0 次と 3 次を固定し、1 次と 2 次には不変ベクトルを持たない。実際、対角部分群 $\diag(e^{i\theta},e^{i\phi},e^{-i(\theta+\phi)})$ は各基底成分を独立に非自明な位相で回す。二つの不変線は偶奇が反対である。十次元の Majorana–Weyl 超電荷一つから四次元の Weyl 超電荷とその共役が得られ、4 実成分が残る。従って$SU(3)$ 構造から持ち上げたスピン構造を選ぶ。ホロノミーがちょうど $SU(3)$ なら Type II は $\mathcal N=2$、ヘテロティック弦は内部ゲージ背景も超対称な場合に $\mathcal N=1$ である。ホロノミーがさらに小さいトーラスでは不変スピノルが増える。

### 不変スピノルを外積代数で数える

六実次元の複素化した Clifford 作用は $\Lambda^\bullet\C^3$ 上で、作る作用 $\omega\mapsto e^i\wedge\omega$ と消す作用 $\omega\mapsto\iota_{e_i}\omega$ を用いて表せる。両者の反交換子は $\delta^i_j$、同種の反交換子はゼロなので、六つの実 Clifford 生成子を組み合わせられる。$SU(3)$ は外積次数を保つ。一次と二次の外積表現は $3$ と $\bar3$ で自明成分を含まない。零次と三次は、作用がそれぞれ恒等と行列式 1 なので不変である。次数の偶奇がカイラリティを与え、各カイラリティに一つの不変線がある。各十次元の超電荷が持つ実 16 成分はこの分解で四次元の実 4 成分に減る。従って Type II の二組は $\mathcal N=2$、ヘテロティックの一組は $\mathcal N=1$ になる。

:::example[対角ホロノミーでの検査]
$U=\diag(e^{ia},e^{ib},e^{-i(a+b)})$ では、例えば $e^1\wedge e^2$ の位相は $e^{i(a+b)}$、$e^1\wedge e^2\wedge e^3$ の位相は 1 である。$a,b$ を独立に変えると一次も二次も不変にならない一方、三次は常に不変である。
:::

:::example[トーラスで超対称性が増える理由]
平坦な $T^6$ の周期的スピン構造では Holonomy が自明であり、外積の全八成分が不変である。Type II では十次元の 32 実成分が保たれて四次元の $\mathcal N=8$ となる。同じ実次元の内部空間でも、正確に $SU(3)$ ホロノミーを持つ場合の $\mathcal N=2$ とは異なる。
:::

### 平行スピノルから計量と微分形式を作る

$\eta$ を内部の正のカイラリティの単位スピノルとし、$\eta_-$ をその電荷共役とする。直交標構で $\eta$ を Clifford の真空に取る。各実二平面で消滅演算子を $b_i=(\gamma_{2i-1}+i\gamma_{2i})/2$ と置くと $b_i\eta=0$ であり、$\{b_i,b_j^\dagger\}=\delta_{ij}$ である。$\gamma_{2i-1}=b_i+b_i^\dagger$、$\gamma_{2i}=-i(b_i-b_i^\dagger)$ なので $i\eta^\dagger\gamma_{2i-1}\gamma_{2i}\eta=-1$ になる。従って $J_{mn}=-i\eta^\dagger\gamma_{mn}\eta$ は三つの二平面の面積形式の和となり、$J(U,V)=g(IU,V)$ で作用素 $I$ を定めると、$I^2=-1$ である。$\eta_-=b_1^\dagger b_2^\dagger b_3^\dagger\eta$ と取れば、$\eta_-^\dagger\gamma_{mnp}\eta$ には各二平面の生成演算子を一つずつ含む積だけが寄与する。従ってその三形式は位相を除いて $\Omega=\prod_i(e^{2i-1}+ie^{2i})$ の外積である。$J\wedge\Omega=0$ は各二平面の因子が重複するためである。同じ標構で $J^3/3!=(i/8)\Omega\wedge\bar\Omega$ となる。

Levi–Civita 接続は Clifford 作用とスピノルの内積を保つ。従って $\nabla\eta=0$ なら、これらから作った $J,\Omega$ も平行である。捩れがゼロなので、外微分は共変微分を反対称化したものであり、$\dd J=\dd\Omega=0$ になる。さらに $J$ を添字を上げて作用素と見たとき、その Nijenhuis テンソルは $\nabla J$ の線形結合になる。実際、各 Lie 括弧を $\nabla_U V-\nabla_V U$ と置けば、$J$ を微分しない項が $J^2=-I$ で相殺する。従って複素構造は可積分で、$J$ は Kähler 形式、$\Omega$ は正則体積形式となる。

Ricci 平坦性はスピノル方程式の可積分条件からも確認できる。$\nabla\eta=0$ なら $[\nabla_i,\nabla_j]\eta=R_{ijab}\gamma^{ab}\eta/4=0$ である。これに $\gamma^j$ を掛け、$\gamma^j\gamma^{ab}=\gamma^{jab}+g^{ja}\gamma^b-g^{jb}\gamma^a$ を用いる。最初の項は Riemann テンソルの第一 Bianchi 恒等式で消え、残りは符号を除いて $R_{ia}\gamma^a\eta$ である。内部は正定値なので $\gamma(v)^2=|v|^2$ であり、非零な $\eta$ に対して $\gamma(v)\eta=0$ なら $v=0$ である。各 $i$ に対して $R_{ia}=0$ が従う。この最後の議論を Lorentz 計量にそのまま移すと、非零の光的な $v$ がありうるため同じ結論は出ない。

:::example[積のホロノミーと四次元超電荷]
$K3\times T^2$ では $SU(2)$ が外積表示の最初の二方向に作用し、最後の一方向には作用しない。$SU(2)$ 不変な外積の基底は $1,e^1\wedge e^2,e^3,e^1\wedge e^2\wedge e^3$ である。偶数次と奇数次に二つずつ不変線がある。周期的スピン構造では十次元の一組あたり四次元に八実成分が残り、Type II では $\mathcal N=4$ になる。全体の標準束は自明だが、ホロノミーをちょうど $SU(3)$ とするこの章の定義の外にある。
:::

### 背景の仮定を運動方程式と照合する

流束と局在源がない Type II のボソン背景で、ディラトンを一定とする。二微分作用から残る局所方程式は十次元の $R_{MN}=0$ である。直積計量の Levi–Civita 接続では混合した接続が消えるので、Minkowski 因子と Ricci 平坦な内部因子がそれぞれ方程式を満たす。グラビティーノでは内部の平行スピノルを数え、ディラティーノの変分では一定ディラトンと流束ゼロから残る項がゼロになる。局所のスピン接続だけでなく、閉経路でのスピンの巻き方も指定する。例えば平坦な円周の反周期スピン構造では局所の一定スピノルが一周後に符号を変え、大域的に平行な非零の断面にならない。

弦の補正を抑えるには、弦フレームの内部の曲率半径が十分大きく、局所結合も十分小さい条件を使う。四次元の零モードを使うときは、外部エネルギーを最初の非零 KK 質量と巻き付き・弦振動の閾値より小さく取る。例えば大きな半径 $R$ のトーラスでは $1/R$ が $1/\sqrt{\alpha'}$ より先に来る。内部を大きくすると曲率補正は抑えられるが、四次元の零モード近似を使えるエネルギーの窓は狭くなりうる。

## Calabi–Yau 多様体の基礎

:::definition[Calabi–Yau 三次元多様体]{#def-string-cy-threefold}
ここではコンパクトで連結な Kähler 複素三次元多様体で、至る所非零な正則三形式 $\Omega$ を持ち、Ricci 平坦計量のホロノミーが $SU(3)$ であるものを :term[Calabi–Yau 多様体]{en="Calabi–Yau manifold" yomi="からびやうたようたい"} と呼ぶ。ホロノミーを部分群まで許す用語法もある。
:::

正則標準束 $K_X=\bigwedge^3(T^{1,0}X)^*$ を考える。実係数で $c_1(X)=0$ なら、任意の Kähler 類に一意な Ricci 平坦 Kähler 計量がある。至る所非零な正則断面がある場合は $K_X$ が自明なので、この仮定が成り立つ。これは :ref[thm-cg-yau]{text="Yau の定理"} の適用である。Ricci 形式は $2\pi c_1(X)$ を代表するため、実係数で $c_1(X)=0$ なら目標の Ricci 形式としてゼロを選べる。$K_X$ の自明性と単に実係数の $c_1=0$ であることは一般に区別する。Kähler 計量と変形の基礎は [Kähler 幾何](/math/complex-geometry/kahler/) と [複素構造の変形](/math/complex-geometry/deformations/) を参照する。

滑らかな次数 5 の超曲面 $X\subset\mathbb{CP}^4$ では、法線束は $\mathcal O(5)|_X$ である。接束と法線束の完全列の行列式から $K_X=(K_{\mathbb{CP}^4}\otimes\mathcal O(5))|_X$ を得る。射影空間の Euler 列から $K_{\mathbb{CP}^4}=\mathcal O(-5)$ なので $K_X$ は自明である。例えば $x_0^5+\cdots+x_4^5=0$ は滑らかである。偏微分がすべてゼロなら五座標すべてがゼロになり、射影空間の点を定めないからである。

### 随伴公式と五次超曲面

$\mathbb{CP}^4$ の滑らかな次数 $d$ の超曲面 $X_d$ を考える。法束は $\mathcal O(d)|_{X_d}$ である。これは定義多項式が $\mathcal O(d)$ の切断であり、その微分が滑らかな零点上で法方向の同型を与えるためである。$0\to TX_d\to T\mathbb{CP}^4|_{X_d}\to\mathcal O(d)|_{X_d}\to0$ の行列式を取ると
$K_{X_d}=(K_{\mathbb{CP}^4}\otimes\mathcal O(d))|_{X_d}$ となる。$\mathbb{CP}^4$ の Euler 完全列から $\det T\mathbb{CP}^4=\mathcal O(5)$ なので $K_{X_d}=\mathcal O(d-5)|_{X_d}$ である。従って滑らかな五次は自明な標準束を持つ。標準束の自明性は正則な体積形式の大域的な存在を保証するが、Ricci 平坦計量を具体式で与えるわけではない。

:::example[滑らかな Fermat 五次]
$P(x)=x_0^5+\cdots+x_4^5$ では勾配の全成分をゼロとするとすべての $x_i$ がゼロになる。これは射影空間の点ではないので $X_5$ は滑らかである。随伴公式で $K_{X_5}=\mathcal O(0)|_{X_5}$ である。
:::

:::example[次数が一つ異なる場合]
$d=4$ なら $K_X=\mathcal O(-1)|_X$ である。超平面類 $H$ に対し $\int_X H^3=4$ なので、$H$ の制限は非零である。従って $c_1(K_X)=-H$ も非零であり、Kähler 計量があるだけでは Ricci 平坦化できない。
:::

### 五次のホロノミーがちょうど $SU(3)$ になる理由

随伴公式と Yau の定理により、滑らかな五次には Ricci 平坦な Kähler 計量と非零な正則三形式がある。正則体積形式のノルムは、Ricci 形式がゼロのとき対数が調和になる。コンパクトで連結ならそのノルムは一定なので、標準束の Chern 接続の接続一形式 $\partial\log\|\Omega\|^2$ はこの枠でゼロである。従って $\Omega$ は平行で、$U(3)$ のホロノミーは $SU(3)$ に入る。一方、部分群に入ることだけでは、冒頭の定義を満たすと結論できない。

ここで弱 Lefschetz の超平面定理を使う。滑らかな十分豊富な因子 $X$ が複素次元 $m$ を持つとき、周囲への包含は次数 $j<m$ のホモトピー群とコホモロジーに同型を誘導する。コホモロジーはここで必要な次数だけ使う。これは十分豊富な因子の補空間に対する Morse 理論を要する結果なので、複素幾何での証明と適用は :cite[huybrechts-cg] を参照する。五次は $\mathcal O(5)$ の滑らかな零点で $m=3$ だから、$\pi_1(X)=\pi_1(\mathbb{CP}^4)=0$、$H^2(X,\R)=\R H$ である。従って $h^{1,1}=1$ であり、$h^{2,0}=0$ でもある。後者は $b_2=h^{1,1}+2h^{2,0}$ で Kähler 類が非零であることから従う。

単連結かつコンパクトな Ricci 平坦 Kähler 三次元多様体が Riemann 積に分かれれば、Kähler の因子の分解には複素一次元の因子が現れる。複素一次元の Ricci 平坦計量は平坦であり、完備かつ単連結な平坦因子は Euclid 空間でコンパクトでない。実既約な de Rham 因子に着目しても、平行な複素構造は非平坦な既約因子を保つ。独立な因子間の写像が平行なら、それぞれのホロノミーが別々に作用するので、非自明な回転を含む因子間では同型を作れないからである。従ってこの例では計量は非平坦で既約である。既約で非局所対称な Ricci 平坦 Kähler 計量の制限ホロノミーは $SU(m)$、または偶数複素次元で $Sp(m/2)$ である。これは Berger の分類から使う帰結であり、分類自体は Riemann 幾何の一般論を要するため :cite[petersen-riemannian] を参照する。既約な局所対称空間で Ricci 平坦な場合は平坦に限る。ここでは複素次元が奇数で単連結だから全ホロノミーは $SU(3)$ である。

:::example[四つの二次式の完全交叉]
$\mathbb{CP}^{7}$ で滑らかに交わる四つの二次式の完全交叉は複素次元三である。法束の行列式は $\mathcal O(8)$、周囲の標準束は $\mathcal O(-8)$ なので随伴公式で $K_X$ が自明になる。一般位置の滑らかな交叉を順に取れば、最後の段階でも弱 Lefschetz の定理が $\pi_1$ と $H^2$ に適用できる。従って五次と同じ論法で $SU(3)$ ホロノミーを持つ。全 Chern 類は $(1+H)^8/(1+2H)^4$ であり、三次まで展開すると $1+4H^2-8H^3$ である。$\int_X H^3=2^4=16$ だから Euler 標数は $-128$、Hodge 数は $(1,65)$ になる。この例でも Ricci 平坦計量の存在は定理で分かるが、その成分の具体式はこの計算から得られない。
:::

### 五次の正則体積形式を留数で書く

$\mathbb C^5$ の斉次座標 $x_i$ から
$$
\varpi=\sum_{i=0}^4(-1)^i x_i\dd x_0\wedge\cdots\wedge\widehat{\dd x_i}\wedge\cdots\wedge\dd x_4
$$
を作る。ハットはその因子を外すことを表す。この四形式は Euler ベクトル場と五形式の縮約なので、さらに Euler ベクトル場で縮約するとゼロである。斉次多項式 $P$ の次数が 5 なら $\varpi/P$ は定数倍 $x\mapsto a x$ で不変であり、射影空間の有理四形式に降りる。$P=0$ の滑らかな点では、局所座標の一つを $P$ に替えられる。$\varpi/P$ を $\dd P/P\wedge\Omega+\text{正則項}$ と書くと留数 $\Omega$ が得られる。$x_0=1$ で $P_{x_4}\ne0$ のパッチでは、$\Omega=-\dd x_1\wedge\dd x_2\wedge\dd x_3/P_{x_4}$ である。$\dd P$ を最初に置くために $\dd x_4$ を三つの因子の前へ移した符号である。パッチを変えても $\dd P=0$ を接空間に制限した恒等式で一致する。滑らかさから少なくとも一つの偏微分が非零なので留数は至る所非零になる。

:::example[留数を保つ対角作用]
Fermat 五次で $x_i\mapsto\zeta_i x_i$、$\zeta_i^5=1$ とすると $P$ は変わらず、$\varpi$ には $\prod_i\zeta_i$ が掛かる。従って積が 1 の対角作用は $\Omega$ を保つ。全ての $\zeta_i$ を共通に選ぶ部分群は射影座標への作用が恒等であり、積も共通位相の五乗なので 1 である。この部分群を割って、異なる射影作用だけを数える。
:::

## Hodge 数と低エネルギースペクトル

:term[Hodge 数]{en="Hodge number" yomi="ほっじすう"} は $h^{p,q}=\dim H^{p,q}_{\bar\partial}(X)$ である。コンパクトな Kähler 多様体では de Rham 調和形式を型で分解でき、複素共役と Hodge 星により $h^{p,q}=h^{q,p}=h^{3-p,3-q}$ である。ホロノミーが $SU(3)$ なら $h^{1,0}=h^{2,0}=0$、$h^{3,0}=1$ である。Ricci 平坦な Kähler 計量では正則形式に Bochner 公式を積分すると $\|\nabla\omega\|^2=0$ になり、平行な形式の数は $SU(3)$ の不変成分で決まる。これらの対称性で $b_2=h^{1,1}$、$b_3=2+2h^{2,1}$、$b_4=h^{1,1}$ となり
$$
\chi(X)=2(h^{1,1}-h^{2,1})
\label{eq-string-cy-euler}
$$
を得る。

Kähler 形式と $B_2$ を調和な $(1,1)$ 形式の基底に展開すると $h^{1,1}$ 個の複素パラメータを得る。複素構造の微小変形は $H^1(X,T^{1,0}X)$ にあり、$\Omega$ との縮約で $H^{2,1}$ に写る。非零な $\Omega$ を使うためこの縮約は各ファイバーで逆を持ち、$\bar\partial$ と可換なのでコホモロジーの同型になる。変形空間の局所的な非障害性は Bogomolov–Tian–Todorov の定理であり、非線形な変形方程式の証明は [複素構造の変形](/math/complex-geometry/deformations/) を参照する。

流束がない Type IIA では $C_3$ を内部調和二形式に沿って展開すると $h^{1,1}$ 個のベクトル、さらに $C_1$ の外部成分から重力多重項のベクトルを得る。複素構造の $2h^{2,1}$ 実成分と $C_3$ の内部三形式からの $2h^{2,1}+2$ 実成分に、ディラトンと外部二形式の双対スカラーを足す。従ってベクトル多重項は $h^{1,1}$ 個、超多重項のうち四実スカラーを持つハイパー多重項は $h^{2,1}+1$ 個である。IIB では五形式強度の自己双対性を課して $C_4$ を内部三形式に沿って展開するとベクトルは電気側だけで $b_3/2=h^{2,1}+1$ 個である。うち一つは重力多重項に入り、ベクトル多重項は $h^{2,1}$ 個、ハイパー多重項は $h^{1,1}+1$ 個となる。

### Chern 類から Euler 標数を求める

上の法束の完全列で全 Chern 類を使うと $c(TX_5)=(1+H)^5/(1+5H)$ である。三次まで展開すれば $c_1=0$、$c_2=(10-25+25)H^2=10H^2$、$c_3=(10-50+125-125)H^3=-40H^3$ になる。超曲面の基本類は周囲の $\mathbb{CP}^4$ で $5H$ の Poincaré 双対なので $\int_{X_5} H^3=5\int_{\mathbb{CP}^4}H^4=5$ である。最高 Chern 類は複素接束の実 Euler 類に等しいため、$\chi=\int_{X_5}c_3=-200$ となる。Lefschetz の超平面定理を用いた $h^{1,1}=1$ と :eqref[eq-string-cy-euler] から $h^{2,1}=101$ となる。

:::example[重力多重項を別に数える]
五次の Type IIA ではベクトル多重項が 1、超多重項のうちハイパー多重項が $101+1=102$ である。四次元の重力多重項自身の重力光子もベクトル場なので、質量ゼロベクトル場は合わせて 2 個になる。
:::

:::example[三形式の実成分数]
$h^{2,1}=101$ のとき $b_3=h^{3,0}+h^{2,1}+h^{1,2}+h^{0,3}=1+101+101+1=204$ である。複素基底で $(2,1)$ と $(1,2)$ は共役なので、実三形式を作るとき片方を捨てるのではなく、共役な係数を組にする。
:::

### 調和形式が質量を持たない理由

内部を境界のないコンパクトな Riemann 多様体 $X$ とし、背景に流束がない二微分作用を用いる。差が閉形式のゲージ変換で結ばれる $p$ 形式のポテンシャルを、内部の固有形式 $\eta_I$ に対し $A=\sum_I a_I(x)\wedge\eta_I(y)$ と展開する。内部 Laplace 演算子は $\Delta_X=\dd_X\dd_X^\dagger+\dd_X^\dagger\dd_X$ であり、内積との関係は $\langle\eta,\Delta_X\eta\rangle=\norm{\dd_X\eta}^2+\norm{\dd_X^\dagger\eta}^2$ である。調和形式は閉かつ共閉なので内部微分が質量項を生じない。一方、ゲージを固定し拘束を解いた非零固有モードでは、固有値 $\lambda_I$ が質量二乗になる。Hodge の定理により零固有値の空間は de Rham コホモロジーと同型であり、Kähler 計量では複素型に分かれる。零モードだけに切断する条件は、外部のエネルギーが内部の最初の非零固有値の平方根より十分小さいことである。

IIB の自己双対五形式の減少を四次元で見る。内部三形式の symplectic 基底を $(\alpha_I,\beta^I)$、$I=0,\ldots,h^{2,1}$ とし、五形式を外部の二形式の強度 $F^I,G_I$ の組で展開する。背景の積計量では十次元 Hodge 双対は四次元と六次元の双対の積になる。Lorentz 四次元の二形式では $*_4^2=-1$、Euclid 六次元の三形式でも $*_6^2=-1$ であり、積は $+1$ である。従って自己双対条件が $G_I$ と $F^I$ を結び、独立なベクトルの数を $b_3/2=h^{2,1}+1$ にする。うち一つは重力多重項の重力光子である。

:::example[内部計量の全体を拡大する]
内部計量を $g_X\mapsto\lambda^2 g_X$ とし $\lambda>0$ を一定とする。Laplace 演算子には逆計量一つの因子が残るため、固有値は $\lambda^{-2}$ 倍、KK 質量は $\lambda^{-1}$ 倍である。零固有値の次元は変わらない。例えば内部の長さを 3 倍にしても Hodge 数は変わらないが、零モードで済むエネルギーの上限は小さくなる。
:::

### Kähler 変形と複素構造変形を計量で見る

内部計量の無限小変形を、固定した複素座標で $\delta g_{i\bar j}$ と $\delta g_{ij},\delta g_{\bar i\bar j}$ に分ける。複素構造を固定した Hermite 変形では $\delta J=i\,\delta g_{i\bar j}\dd z^i\wedge\dd\bar z^{\bar j}$ であり、Kähler 条件から $\dd\delta J=0$ である。Kähler 類の中での変形は $\partial\bar\partial$ 補題により $i\partial\bar\partial f$ と書ける。Ricci 平坦条件を一次化すると、同じ類の中では $\Delta f$ が定数になり、コンパクト性で $f$ は定数になる。従って各非零の調和 $(1,1)$ 類が独立な実変形を与える。反 Hermite 側の変形は、反正則方向が正則方向にずれる量 $\mu^i{}_{\bar j}\dd\bar z^{\bar j}\otimes\partial_i$ で表す。変形後の反正則ベクトル場 $\partial_{\bar j}+\mu^i{}_{\bar j}\partial_i$ の Lie 括弧から、可積分条件の一次は $\partial_{\bar j}\mu^i{}_{\bar k}-\partial_{\bar k}\mu^i{}_{\bar j}=0$ である。座標変換が $\bar\partial$ 完全な変形を加えるので、商が $H^1(T_X)$ になる。

$\Omega$ と縮約すると $\chi_\mu=\iota_\mu\Omega$ は $(2,1)$ 形式である。平行な $\Omega$ により型の写像が点ごとで可逆で、$\bar\partial$ と可換なので、調和代表を用いて複素構造変形を記述できる。ただし三形式の周期は $\Omega$ の全体の非零定数倍にも依存する。その自由度は複素構造の変化として数えない。滑らかな族の $\Omega$ の一次変分は $(3,0)$ 成分と $(2,1)$ 成分だけを持つ。局所的には三つの $\dd z^i$ のうち一つだけを反正則方向へ動かせるからである。従って $\partial_\alpha\Omega=k_\alpha\Omega+\chi_\alpha$ と分け、後者がモジュライの接方向を表す。

### Type IIB のハイパー多重項の中身

IIA と同様に IIB の NS–NS では $J$ と $B_2$ の内部成分から $2h^{1,1}$ 実スカラーを得る。$C_2$ の内部成分は $h^{1,1}$ 個、自己双対な強度を持つ $C_4$ の内部四形式への展開はさらに $h^{1,1}$ 個のスカラーを与える。$C_4$ の外部二形式を内部二形式に沿って展開する記述は、内部四形式のスカラーと自己双対性で対応するので両方を足さない。普遍的な成分は $\Phi,C_0$ と、外部の $B_2,C_2$ をそれぞれ四次元で双対化した二つのスカラーである。従って合計は $4h^{1,1}+4$ で、$h^{1,1}+1$ 個のハイパー多重項の数になる。外部の四形式は四次元で局所的な質量ゼロ偏極を持たない。同様に IIA の外部三形式は四形式強度の定数の選択を持ちうるが、物理スカラーとして数えない。

二形式の双対化は、四次元で独立な三形式 $H$ を取り、閉性を課すスカラー $a$ を導入すれば追える。Euclid で $I=\tfrac K2\int H\wedge *H+i\int a\,\dd H$、$K>0$ とする。第二項は $-i\int\dd a\wedge H=i\int H\wedge\dd a$ と書き換えられる。三形式の星は一形式で、Euclid では一形式と三形式の上の $*^2=-1$ である。$H$ の鞍点は $*H=-i\dd a/K$、すなわち $H=i*\dd a/K$ である。代入すると $I_{\rm dual}=(2K)^{-1}\int\dd a\wedge *\dd a$ になる。閉形式の大域的な周期は、元のゲージ場の磁束と双対スカラーの周期を突き合わせて定める。

:::example[どの形が独立な場か]
$h^{1,1}=2$、$h^{2,1}=4$ の IIB では $C_4$ の三形式展開が 電気・磁気を合わせて 10 成分を与え、独立なベクトルは 5 本である。内部四形式からは 2 実スカラーが残り、その 2 個は外部二形式としても記述できる。ハイパー多重項側の実スカラーは $2(2+1+1)+4=12$、うち 4 個は内部の Hodge 数を変えても残る。
:::

### 交差数と Kähler モジュライの正値性

正則な二サイクル $\Sigma$ に対して $\int_\Sigma J$ は計量で測った面積である。これは各複素接平面上で $J$ が向きに合った面積形式に等しいためである。従って Kähler 形式の座標を $J=t^a\omega_a$ と置くと、曲線の類ごとに $t^a\int_\Sigma\omega_a>0$ が必要である。内部体積は交差数 $\kappa_{abc}=\int_X\omega_a\wedge\omega_b\wedge\omega_c$ を使い $\mathcal V=\kappa_{abc}t^a t^b t^c/6$ である。偏微分すると $\mathcal V_a=\kappa_{abc}t^bt^c/2$、$\mathcal V_{ab}=\kappa_{abc}t^c$ になる。$\omega_a$ が積分基底で $J$ が長さ二乗の次元を持つなら $t^a$ も長さ二乗、$\mathcal V$ は長さ六乗である。内部 $B$ の周期は基本弦の位相から $\int_\Sigma B/(4\pi^2\alpha')$ が整数だけずれる規格化で周期的であり、Kähler パラメータの実部と虚部を作るとき、両方を同じ無次元単位にする。

調和な実 $(1,1)$ 形式 $\alpha$ を $\alpha=\alpha_0+cJ$ と分ける。Kähler 恒等式によって $\Lambda\alpha$ は調和な関数で一定なので、$\Lambda J=3$ を使い $\alpha_0$ を primitive とできる。$*_6J=J^2/2$、$*_6\alpha_0=-J\wedge\alpha_0$ はユニタリ標構で対角の $(1,1)$ 形式に書いて確認できる。例えば $\alpha_0=e^1\wedge e^2-e^3\wedge e^4$ では $J\wedge\alpha_0$ と $*\alpha_0$ の相対符号は負である。従って
$$
\int_X\alpha\wedge *\alpha=-\int_XJ\wedge\alpha^2+
\frac32\,\frac{(\int_X J^2\wedge\alpha)^2}{\int_X J^3}
$$
になる。実際 $\int J^2\alpha_0=0$ であり、$cJ$ に対して左辺は $c^2\int J^3/2$、右辺も $(-1+3/2)c^2\int J^3$ である。この式により Kähler 方向と primitive 方向の符号の違いが分かる。交差形式の符号をそのままスカラーの運動項の符号と読み替えてはいけない。

## オービフォールド

有限群で同一視する背景を :term[オービフォールド]{en="orbifold" yomi="おーびふぉーるど"} と呼ぶ。閉弦は持ち上げた被覆空間上で $X(\sigma+2\pi)=gX(\sigma)$ を満たしても、商の中では閉じている。従って恒等元のセクターを射影するだけでは不十分で、各捻りのセクターを加える。可換群ではトーラスの二周期に $(g,h)$ を割り当て、$S$ は $(h,g^{-1})$、$T$ は $(g,gh)$ に移す。周期の組をすべて足すと、この操作で組の集合が保たれる。

例として $T^4/\Z_2$ の四つの実座標を同時に反転する。各円周で不動点は 0 と半周期の二つであり、合計 16 点ある。非自明な捻りでは定数解はこの 16 点のいずれかなので、各点で局在した twisted 状態が生じる。滑らかな K3 への解消では局所 $\C^2/\Z_2$ の各点を例外的な $\mathbb{CP}^1$ に置き換える。局所解消は $\mathcal O_{\mathbb{CP}^1}(-2)$ の全空間である。非零なベクトルの符号を割り、その二乗を直線束のファイバーに使えば、零切断を除いた部分が $\C^2/\Z_2$ の平滑部と一致する。リンク $S^3/\Z_2$ では実係数の $H^1,H^2$ がゼロなので、Mayer–Vietoris 完全列で各例外曲線の $H^2$ が一つずつ加わる。正則二形式は、局所座標 $(v,w)=(\lambda,\lambda u)$ で $\dd v\wedge\dd w=\tfrac12\dd(\lambda^2)\wedge\dd u$ と書けるため、零切断まで延びる。二つの複素座標から作る四つの未捻り $(1,1)$ 形式は反転で不変なので $h^{1,1}=4+16=20$ になる。固定点のない群作用では同じ数え方で局在状態を加えることはできない。

### 射影と捻りを同じ分配関数に入れる

ゲージ化を妨げるアノマリーがなく、位相の追加をしない有限アーベル群 $G$ について、空間方向を $g$ で捻った Hilbert 空間 $\mathcal H_g$ を取る。時間方向の $h$ の挿入を $Z_{g,h}=\Tr_{\mathcal H_g}(h q^{L_0-c/24}\bar q^{\bar L_0-\bar c/24})$ とする。時間の和 $|G|^{-1}\sum_h h$ は群不変状態への射影である。実際二乗すると、各 $k=hh'$ が $|G|$ 回出て同じ平均に戻る。$S$ は二つの向き付き周期を交換して $(g,h)\mapsto(h,g^{-1})$、$T$ は一方に他方を足して $(g,h)\mapsto(g,gh)$ に対応する。従って離散位相の追加がない場合、全ての組を足せば各変換が項の集合を保つ。未捻りの射影だけでは、旧時間方向の挿入が $S$ で空間方向の捻りに移るため閉じない。

:::example[$\Z_2$ の四項]
$g=-1$ と書くと $(1,g),(g,1)$ は $S$ によって互いに移る。$T$ は $(g,1)$ と $(g,g)$ を交換する。従って $Z_{1,1}+Z_{1,g}$ だけでは変換で不足し、$Z_{g,1}+Z_{g,g}$ も必要になる。
:::

:::example[反転と平行移動の差]
円周で $y\mapsto-y$ なら $2y=0\bmod2\pi R$ で固定点が二つある。$y\mapsto y+\pi R$ では固定点はないが、捻りセクターは $Y(\sigma+2\pi)-Y(\sigma)=\pi R\bmod2\pi R$ を満たし、半整数の巻き付きがある。固定点がないことから、捻りセクター自体が空になるわけではない。
:::

### 非可換群では中心化群で射影する

トーラスの基本群は $\Z^2$ なので、空間と時間の二つの捻りは $gh=hg$ を満たさなければならない。空間のセクター $g$ に $h$ を作用させると $hgh^{-1}$ のセクターへ移るため、同じ Hilbert 空間の跡が取れるのは $h\in C_G(g)$ の場合である。従って位相を追加しないアノマリーのない商では
$$
Z_{\rm orb}=\frac{1}{|G|}\sum_{\substack{g,h\in G\\gh=hg}} Z_{g,h}
=\sum_{[g]}\frac{1}{|C_G(g)|}\sum_{h\in C_G(g)}Z_{g,h}.
$$
第二式は共役類の大きさが $|G|/|C_G(g)|$ であることから従う。内側の平均は中心化群の不変部分への射影である。$S:(g,h)\mapsto(h,g^{-1})$ と $T:(g,h)\mapsto(g,gh)$ は可換条件を保つので、アノマリーのない理論でトーラスの組を閉じる。離散 torsion がある場合は位相を含む変換と射影を同時に検査する必要がある。可換な組を数えるだけで、候補となる任意の作用が無条件に弦背景を定義するわけではない。

:::example[$S_3$ の跡の重み]
$S_3$ の共役類は恒等元、互換、三周期であり、中心化群の位数はそれぞれ $6,2,3$ である。不変射影の係数は順に $1/6,1/2,1/3$ となる。一番目の和には 6 項、二番目には 2 項、三番目には 3 項が入る。一方、共役類にまとめる前には $6+3\cdot2+2\cdot3=18$ の可換な組がある。非可換な二つの異なる互換を同時に周期に置く項はない。
:::

### 孤立固定点の局所幾何と三次元の例

$T^6=E^3$、$E=\mathbb C/(\mathbb Z+\omega\mathbb Z)$、$\omega=e^{2\pi i/3}$ とし、$g$ は三方向を同時に $\omega$ 倍する。行列式は $\omega^3=1$ で、正則三形式を保つ。各因子の固定点は $(1-\omega)z\in\Z+\omega\Z$ を満たし、格子の部分格子 $(1-\omega)\Lambda$ の指数に等しい。基底 $1,\omega$ では $(1-\omega)1=1-\omega$、$(1-\omega)\omega=1+2\omega$ なので行列式は 3 である。したがって 27 個の孤立固定点がある。$g^2$ は同じ固定点を持つ。未捻りの $H^{p,q}$ には $\omega^{p-q}$ の位相が掛かるため、$H^{1,1}$ は全て九次元が残り、$H^{2,1}$ は残らない。

各点の局所商は $\C^3/\Z_3$ である。具体的な解消は $\mathbb{CP}^2$ 上の $\mathcal O(-3)$ の全空間で与えられる。$\mathcal O(-1)$ の零切断の外の点は非零の $v\in\C^3$ に対応し、ファイバーで $v\mapsto\omega v$ を割ると $v^{\otimes3}$ が $\mathcal O(-3)$ の非零のファイバー座標になる。零切断を入れると原点だけを $\mathbb{CP}^2$ に置き換える。全空間の標準束は、射影 $\pi$ を用い $K_{\mathrm{Tot}(L)}=\pi^*(K_{\mathbb{CP}^2}\otimes L^{-1})$ である。接束の縦方向が $\pi^*L$ なので行列式の完全列から得る。$K_{\mathbb{CP}^2}=\mathcal O(-3)$ と $L=\mathcal O(-3)$ で互いに消える。さらに不変な局所三形式は滑らかに延びる。例えば $v=(\lambda,\lambda w_1,\lambda w_2)$ なら $\dd v_0\wedge\dd v_1\wedge\dd v_2=\lambda^2\dd\lambda\wedge\dd w_1\wedge\dd w_2=\tfrac13\dd(\lambda^3)\wedge\dd w_1\wedge\dd w_2$ である。従ってこれは標準束を保つ解消である。

有理係数で境界のリンク $S^5/\Z_3$ のコホモロジーが球のものと同じなので、Mayer–Vietoris 完全列で中間次数の変化を局所ごとに足せる。実際有限の自由被覆 $S^5$ の不変コホモロジーだけが残り、次数 1 から 4 はゼロである。切り取る錐は縮約可能で、入れ直す円板束は零切断 $\mathbb{CP}^2$ に変形収縮する。元の被覆のトーラスから小球を除いても次数 2 と 3 のコホモロジーは変わらず、自由な商では有限被覆の転送写像により不変部分だけが残る。従って $b_2,b_4$ が各点で一つずつ増え、$b_3=2$ は変わらない。解消上の正則二形式を被覆の点を除いた部分へ持ち上げると、Hartogs の拡張で元のトーラスに延びる。不変な $(2,0)$ が元のトーラスにないので $h^{2,0}=0$ である。体積形式の拡張により $h^{3,0}=1$ だから、$b_3=2$ から $h^{2,1}=0$ である。局所の新しい類は例外因子とその中の曲線の類に対応する。この局所模型は、射影的な商を孤立点で吹き上げて得られる。局所環は三次 Veronese の錐の環なので、頂点の吹き上げの例外因子は Veronese 埋め込みを持つ $\mathbb{CP}^2$、法束は $\mathcal O(-3)$ である。従って解消は射影的で Kähler であり、この解消では $(h^{1,1},h^{2,1})=(9+27,0)=(36,0)$ になる。例えば Euler 標数は 72 である。円板束を二つの捻り $g,g^2$ に対応させると、各固定点につき$g$ の三つの回転角の分数部分の和は $3\cdot(1/3)=1$、$g^2$ では $3\cdot(2/3)=2$ である。固定点の零次の類にこの和を両方の Hodge 次数へ足すと、一方が $(1,1)$、他方がその双対の $(2,2)$ に寄与する。両方を $(1,1)$ に数えると重複する。

:::example[トーラスの商の Euler 標数を直接検算する]
滑らかなトーラスの Euler 標数は 0 である。位数 3 の群の作用で恒等元以外の二つは各 27 個の点を固定するため、位相空間としての商の Euler 標数は $(0+27+27)/3=18$ である。これは群に従う三角形分割で各セルの軌道を Burnside の式で数え、次元ごとに交代和を取れば得られる。解消では各特異点を $\chi(\mathbb{CP}^2)=3$ の因子で置き換えるので、$18+27(3-1)=72$ になる。商の位相的な Euler 標数と解消の標数に差があるのは、局在した捻りの状態が新しいコホモロジーに対応するためである。
:::

## ミラー対称性の概観

:term[ミラー対称性]{en="mirror symmetry" yomi="みらーたいしょうせい"} では二次元の $\mathcal N=(2,2)$ 理論の片側の $U(1)$ 電荷の符号を反転する。同じ超共形代数に右の $J\mapsto-J$、$G^\pm\mapsto G^\mp$ を施すと電荷の交換だけが起きる。幾何学を持つ二つの位相の対応ではこの交換が Kähler 変形と複素構造変形を入れ替え、$h^{1,1}(X)=h^{2,1}(Y)$、$h^{2,1}(X)=h^{1,1}(Y)$ を与える。これと Type II の多重項の数から、$X$ の IIA と $Y$ の IIB の質量ゼロスペクトルが対応する。Hodge 数の一致だけで CFT 全体の同値が証明されるわけではない。世界面インスタントンを含む具体的なミラー構成は :cite[bbs-string] を参照する。

### トーラスの双対で電荷反転を計算する

一つの複素方向 $Z=X+iY$ で、右の複素フェルミオンを $\psi_R^Z=(\psi_R^X+i\psi_R^Y)/\sqrt2$ とする。$Y$ の T 双対で $\psi_R^Y$ だけが反転するので、$\psi_R^Z$ と $\psi_R^{\bar Z}$ が交換する。右の $U(1)$ 電流 $J_R=:\psi_R^Z\psi_R^{\bar Z}:$ は反交換で符号を変える。超電流 $G_R^\pm$ でも反対の複素成分が交換する。三つの複素方向で同時に一実方向ずつ双対を取れば、横スピノルのカイラリティが三回反転し Type IIA と IIB が入れ替わる。一般の Calabi–Yau に連続な三つの等長変換があると仮定することはできないので、トーラスでの計算は片側電荷反転を具体的に表す例である。

:::example[五次のミラーの Hodge 数]
$(h^{1,1},h^{2,1})=(1,101)$ の鏡では $(101,1)$ となる。:eqref[eq-string-cy-euler] より $\chi$ は $-200$ から $+200$ に変わる。元の IIA のベクトル多重項 1 は、鏡側 IIB の複素構造変形 1 と一致する。
:::

:::example[三重交差から体積を求める]
五次の Kähler 形式を $J=tH$ とすれば、古典体積は $\int J^3/6=5t^3/6$ である。$t$ を 2 倍にすると体積は 8 倍になる。鏡の複素構造側で同じ情報を表す量は周期積分であり、Hodge 数の対応だけでは三重交差の係数 5 を得られない。
:::

### 五次の周期積分と微分方程式

五次族 $P_\psi=\sum_{i=0}^4 x_i^5-5\psi x_0x_1x_2x_3x_4$ を考える。対角の五乗根の作用のうち積が 1 のものは正則三形式を保ち、射影座標全体の倍率を同一視すると位数 $5^3$ の群になる。この群による商とその解消を使うミラーの構成は、特異点と解消の大域幾何を要するので :cite[bbs-string] を参照する。ここでは商でも不変な周期の一つを求める。

$x_0=1$ とし、$\lvert x_i\rvert=1$ の四トーラス上で $|\psi|>1$ を取る。正則三形式を先の有理四形式の留数で表す。次の四トーラス積分は、規格化した留数の周期を与える。

$$
\Pi_0=\frac1{(2\pi i)^4}\int
\prod_{i=1}^4\frac{\dd x_i}{x_i}
\left[1-\frac{1+x_1^5+x_2^5+x_3^5+x_4^5}{5\psi x_1x_2x_3x_4}\right]^{-1}.
$$

実際、被積分形は $-5\psi\,\dd x_1\wedge\cdots\wedge\dd x_4/P_\psi$ である。$|x_1|=|x_2|=|x_3|=1$ を固定すると、$|x_4|=1$ で線形の項 $-5\psi x_1x_2x_3x_4$ の大きさが残りの五項の和の大きさを超える。Rouché の定理により $|x_4|<1$ にちょうど一つの単純根がある。各単純根は陰関数定理により三トーラス上で滑らかにつながる。$x_4$ の積分を一変数の留数定理で実行すれば、この根が作る三サイクル上の周期になる。対角群はこの三サイクルを保つ。少なくとも $x_0,x_1,x_2,x_3$ が非零なので、点を固定する作用ではその四つの位相が同じになる。積 1 の条件で五つ目も同じになり、射影化した作用は恒等である。従ってこのサイクルは商の平滑部に降りる。被覆の次数の定数倍は $\Omega$ の規格化に吸収できる。

この積分では分母の比の絶対値が高々 $1/|\psi|$ なので等比級数が一様収束する。次数 $m$ の項で各 $x_i$ の冪をゼロにするには、$x_i^5$ の選択回数が $m/5$ でなければならない。従って $m=5n$、$x_0$ に対応する 1 の選択回数も $n$ である。多項係数 $(5n)!/(n!)^5$ を使い $z=(5\psi)^{-5}$ と書けば $\Pi_0(z)=\sum_{n\ge0}(5n)!z^n/(n!)^5$ となる。係数 $a_n$ は
$$
n^4 a_n=5(5n-4)(5n-3)(5n-2)(5n-1)a_{n-1}
$$
を満たすので、$\theta=z\partial_z$ に対して

$$
\left[\theta^4-5z(5\theta+1)(5\theta+2)(5\theta+3)(5\theta+4)\right]\Pi_0=0
\label{eq-string-quintic-picard-fuchs}
$$

である。この形式を :term[Picard–Fuchs 方程式]{en="Picard–Fuchs equation" yomi="ぴかーるふっくすほうていしき"} と呼ぶ。$z=0$ の指標方程式は $\rho^4=0$ なので、一つの正則解のほかに対数を含む解が現れうる。ここで選んだ積分では $\Pi_0(0)=1$ に固定されている。

:::example[最初の係数と収束の端]
$a_1=5!=120$、$a_2=10!/(2!)^5=113400$ である。続く係数比の極限は $5^5$ なので冪級数の収束半径は $5^{-5}$ である。族の特異点の条件も比較できる。勾配がすべてゼロなら $x_i^5=\psi\prod_j x_j$ が各 $i$ で成り立ち、もし一点の座標がゼロなら全座標がゼロになって射影空間の点にならない。全式の積を取ると $\psi^5=1$ であり、これは $z=5^{-5}$ に一致する。
:::

### 対数周期とミラー写像

:eqref[eq-string-quintic-picard-fuchs] の正則解だけでは、複素構造のどの座標が鏡の複素化した面積に当たるかは分からない。$z=0$ の近くで指数 $\rho$ を補助変数とし、$b_0(\rho)=1$、
$$
b_n(\rho)=\frac{5\prod_{j=1}^{4}(5(n-1+\rho)+j)}{(n+\rho)^4}\,b_{n-1}(\rho)
$$
とする。$P(\theta,z)$ を方程式の作用素とすると $P\bigl(\sum_{n\ge0}b_n(\rho)z^{n+\rho}\bigr)=\rho^4 z^\rho$ である。$n\ge1$ の係数は漸化式で消え、右辺は $n=0$ に残る項だけである。適当な小さい点を含む単連結な扇形で対数の枝を固定すれば、$\rho=0$ の近くで級数とその $\rho$ 微分は収束する。漸化式の比が一様に $5^5$ に近づくためである。従って $\rho$ で 0 回から 3 回微分してから $\rho=0$ と置いた四つの解が得られる。最高の対数冪がそれぞれ異なるので独立である。

一階の解を $\Pi_1=\Pi_0\log z+\sum_{n\ge1}b_n'(0)z^n$ と書く。係数は例えば $b_n(\rho)=\Gamma(1+5(n+\rho))\Gamma(1+\rho)^5/[\Gamma(1+n+\rho)^5\Gamma(1+5\rho)]$ を微分して求められる。Gamma 関数の漸化式を使うと、$b_n'(0)/b_n(0)=5(H_{5n}-H_n)$ であり、$H_j=\sum_{m=1}^j1/m$ は調和数である。従って先頭の正則補正は $120\cdot5(H_5-H_1)z=770z$ になる。$t=\Pi_1/(2\pi i\Pi_0)$ は $z$ が一周すると $t\mapsto t+1$ を受ける。鏡の大体積点ではこの変換が積分 $B$ 周期のシフトに対応する。従って $q=e^{2\pi i t}=z+770z^2+\cdots$ は単価であり、$z$ と同じ先頭でも高次で異なる。厳密な周期の整数基底を選ぶには大域的なモノドロミーも必要である。局所式だけから全ての周期の整数規格化は決まらない。

:::example[対数の大きさと曲線の面積]
$z$ を小さな正の数に取ると $t\simeq\log z/(2\pi i)$ の虚部は正で、大きな面積に対応する。例えば $z=e^{-2\pi T}$、$T\gg1$ なら $t=iT+O(e^{-2\pi T})$ である。逆に $z=5^{-5}$ では正則解の収束円の端に到達し、族の特異点のモノドロミーが関与する。大体積の級数をそのまま任意の $z$ へ外挿できない。
:::

### 古典交差数と世界面の面積の補正

$J$ と $B_2$ を積分調和基底で表し、$b^a+i v^a=(4\pi^2\alpha')^{-1}\int_{\Sigma_a}(B_2+iJ)$ と規格化する。Euclid の基本弦が向きの合う正則曲線 $\Sigma$ に巻いたとき、面積は $\int_\Sigma J$ で、位相は $\int_\Sigma B_2/(2\pi\alpha')$ である。従って $\Sigma$ の整数次数を $d_a$ とすれば、その重みは
$$
\exp\bigl[2\pi i\,d_a(b^a+i v^a)\bigr].
$$
$B_2$ の一単位の周期はこの位相を保つ。曲線が多重に覆われれば作用はその回数分になり、重みは対応する冪になる。全体の係数にはその正則写像の変形と障害や、世界面の量子測度が関わる。面積の重みが分かることと、曲線の寄与を正確に数えられることは別である。

ミラーが交換するデータには、一次のスペクトルよりも多い情報がある。大体積の Kähler 側では三つの $(1,1)$ 演算子の古典積が $\kappa_{abc}=\int_X\omega_a\omega_b\omega_c$ になる。量子論では上の巻き付きで指数的に小さい項が加わる。複素構造側では周期の組と、その微分で作る三点の結合から同じ量を計算する。$\partial_\alpha\Omega$ は $(3,0)$ と $(2,1)$ の成分を持つので、$\int\Omega\wedge\partial_\alpha\Omega=0$ である。二階までの微分は一次につき正則型を高々一つ下げるため、同様に $\int\Omega\wedge\partial_\alpha\partial_\beta\Omega=0$ である。一方、三階微分には $(0,3)$ が現れうるので、この積分が Yukawa 結合を記述する。$\Omega$ を $f$ 倍して微分した場合、$f$ の微分を含む低い階の項は上の消失により消え、結合全体は $f^2$ の重みを持つ。従って比較するには $\Pi_0$ などで規格化を合わせる必要がある。五次での曲線次数別の係数を得る大域的な比較は、積分周期とインスタントンの測度を要するので :cite[bbs-string] を参照する。

:::example[古典項と巻き付きの桁]
五次の一つの Kähler パラメータで $v=2$ なら次数 1 の重みの絶対値は $e^{-4\pi}$、次数 2 では $e^{-8\pi}$ である。複素構造側の級数も適切な座標 $q$ ではこの冪で並ぶ。指数に現れる面積は Hodge 数だけから求まらない。$J=tH$ の三重積の係数 5 が、量子補正の項と別に古典の結合を固定する。
:::

## 現象論的模型構築の概観

ヘテロティック弦でゲージ束の接続を内部のスピン接続に埋め込むと、$\tr R\wedge R$ と規格化した $\Tr F\wedge F$ が一致する。従って変形された Bianchi 恒等式で $H=0$ を選べる。この :term[標準埋め込み]{en="standard embedding" yomi="ひょうじゅんうめこみ"} では $E_8$ の一方の $SU(3)$ と可換な $E_6$ が残る。随伴表現の分解は :cite[bbs-string] を参照する。通常の一方のカイラリティ規約で $27$ の多重項数は $h^{2,1}$、共役は $h^{1,1}$ であり、差は $-\chi/2$ である。$27$ と共役の規約を逆にすれば符号だけが変わる。

滑らかな五次超曲面では弱 Lefschetz の定理により $h^{1,1}=1$ である。全 Chern 類は Euler 列と法線列から $(1+H)^5/(1+5H)$ であり、$H^3$ の係数は $10-50+125-125=-40$ となる。$\int_X H^3=5$ なので $\chi=-200$、:eqref[eq-string-cy-euler] から $h^{2,1}=101$ である。従って標準埋め込みの差は 100 である。実際の四次元模型では束の安定性、モジュライの固定、ゲージ群の破れを別々に確認する。この数だけでは Yukawa 結合や物質の質量は決まらない。

### 五次多項式の変形を別の方法で数える

五変数の次数 5 の斉次多項式は、単項式 $x_0^{a_0}\cdots x_4^{a_4}$、$\sum a_i=5$ を係数の基底とする。非負整数解は区切り四つと指数の印五つの並べ方なので $\binom94=126$ 通りある。定義方程式の全体定数は同じ零点集合を与えるため 1 を引き、射影座標の変換 $\operatorname{PGL}(5)$ の次元 24 を引く。滑らかな Fermat 型の点でこの引き算が正しいことは、線形座標変換 $\delta x_i=\sum_j M_{ij}x_j$ の作用を明示すれば分かる。多項式の変分は $5\sum_{ij}M_{ij}x_i^4x_j$ である。$i\ne j$ の二十個の単項式と $i=j$ の五個は互いに異なり、行列のスカラー部分だけが元の多項式の倍になる。従って座標変換が消す変形は射影化の後で 24 個である。残りは $126-1-24=101$ であり、上の Chern 類の計算と一致する。

この一致の背後には法線列 $0\to T_X\to T_{\mathbb{CP}^4}|_X\to\mathcal O_X(5)\to0$ がある。多項式を変形した法線断面は、長完全列の接続準同型で $H^1(T_X)$ の類になる。核は周囲のベクトル場の像であり、法線断面のうち座標変換で消せる部分を表す。この例では制限した Euler 列から $H^1(T_{\mathbb{CP}^4}|_X)=0$ が従う。実際 $H^1(\mathcal O_X(1))=0$ は正の直線束に対する Kodaira 消滅、$H^2(\mathcal O_X)=0$ は $h^{0,2}=0$ である。従って接続準同型は全射であり、すべての一次変形が五次多項式の変形で得られる。場の数を単に多項式の係数で数えるだけでは、周囲の座標の自由度を含めてしまう。

### ゲージ束と世代数の指数

内部の正則ゲージ束を $V$、$c_1(V)=0$ とする。荷電フェルミオンの零モードは Dolbeault コホモロジーで数え、カイラリティの差は指数 $\chi(X,V)=\sum_{p=0}^3(-1)^p h^p(X,V)$ によって決まる。Hirzebruch–Riemann–Roch の定理で $\chi(X,V)=\int_X\operatorname{ch}(V)\operatorname{Td}(TX)$ と書く。$c_1(X)=c_1(V)=0$ なら六形式には $\operatorname{ch}_3(V)=c_3(V)/2$ しか寄与しない。従って $\chi(X,V)=\frac12\int_Xc_3(V)$ である。指数定理の証明は束付き楕円演算子の一般論を要するので、ここでは [Riemann–Roch](/math/complex-geometry/riemann-roch/) の指数の考え方と :cite[bbs-string] の応用を用いる。正味の世代数はカイラリティの規約に応じてこの値またはその負である。

:::example[標準埋め込みを二通りで数える]
$V=TX_5$ なら $\int c_3(V)=-200$ なので指数は $-100$ である。$h^{2,1}=101$、$h^{1,1}=1$ で $27$ と共役の数の差を $101-1$ と定義すれば正味は 100 になり、上の指数と規約の符号だけが違う。
:::

:::example[自由商での指数の変化]
位数 5 の群が自由に作用し、束も商に降りるとする。商の特性類を持ち上げて積分すると被覆の枚数 5 が掛かるので、指数が $-100$ の被覆なら商は $-20$ となる。個々のコホモロジー次元を 5 で割ると結論できるわけではなく、商の各零モードは群の作用を使って射影する。
:::

### ゲージ背景の超対称性と Bianchi 恒等式

十次元ヘテロティックのゲージーノ変分には $F_{mn}\gamma^{mn}\eta$ が現れる。内部のカイラル真空に対し、Clifford 生成演算子二つの係数は $F^{0,2}$ の成分であり、真空成分は $\Lambda_J F$ である。二種類は外積次数が違うので、$\eta$ の変分を消すには $F^{0,2}=0$ と $\Lambda_J F=0$ が必要である。ユニタリ接続では共役の $F^{2,0}$ も消える。従って $F$ は型 $(1,1)$ で原始的である。これは傾きゼロの :term[Hermite–Yang–Mills 方程式]{en="Hermitian Yang–Mills equations" yomi="えるみーとやんみるずほうていしき"} である。$F^{0,2}=0$ は $\bar\partial_A^2=0$ と同じ条件で、ゲージ束に正則構造を与える。$J$ の平方で外積を取ると、原始性は $J^2\wedge F=0$ になる。体積の平均だけがゼロになる条件より強い局所方程式である。

束の傾きは、階数 $r$ の束 $V$ について $\mu_J(V)=\int_X c_1(V)\wedge J^2/r$ とする。傾き安定性では、階数が $0$ と $r$ の間の任意の正則部分層の傾きが $\mu_J(V)$ より小さいことを課す。Hermite–Einstein 接続の存在は傾きポリ安定性と同値であり、傾きゼロなら上の方程式になる。存在定理は解析的な大域評価を要するため、複素幾何での定式化は :cite[huybrechts-cg]、ゲージ束への応用は :cite[bbs-string] を参照する。例えば $V=L\oplus L^{-1}$ なら全体は $c_1(V)=0$ であるが、一方の傾きが正になる Kähler 類ではポリ安定でない。両方の傾きがゼロの壁では、各直線束の曲率は $\Lambda F=0$ にできる。従って「全体の第一 Chern 類がゼロ」という位相条件だけでは超対称性を保証しない。

また源なしでの統合条件は、$\dd H=\alpha'(\tr R\wedge R-\Tr F\wedge F)/4$ を閉四サイクルに積分して得る。適切な群の跡を選び電荷を規格化すると、$[c_2(TX)]=[c_2(V)]$ が必要である。これは $\dd H$ が完全であることによる制約であり、代表する四形式が点ごとに等しいことまでは従わない。標準埋め込みでは、同じ接続を使うので代表も一致し、$H=0$ の選択が可能になる。一般の束でクラスだけを合わせたときは、局所の差を $H$ と幾何の補正が支える場合がある。磁気的な五ブレイン源を置く場合は、この積分条件にその Poincaré 双対が加わる。源のない Ricci 平坦な直積をその場合にも仮定することはできない。

### 標準埋め込みの荷電零モード

$E_8$ の随伴は $SU(3)\times E_6$ に対し
$$
248=(8,1)+(1,78)+(3,27)+(\bar 3,\overline{27})
$$
である。群の表現の構成は :cite[bbs-string] を参照する。次元の照合は $8+78+81+81=248$ である。内部で $3$ の束を $TX$ と取れば、一つの規約で $27$ の四次元のカイラル多重項を $H^1(X,TX)$ が数える。これが $\Omega$ との縮約によって $H^{2,1}(X)$ と同型である。共役の束 $T^*X$ では $H^1(X,T^*X)=H^{1,1}(X)$ なので、$27$ と共役の差は $h^{2,1}-h^{1,1}$ になる。分解の $(8,1)$ には束の変形が含まれる。これは $H^1(X,\operatorname{End}TX)$ などで考え、幾何の二つの Hodge 数だけでは決まらない。第二の $E_8$ にゲージ背景を入れていなければ、その随伴は残る。

一般の安定な $SU(r)$ 束で非零の傾き平行断面がなければ、$H^0(X,V)=0$ である。実際、傾きゼロの Hermite–Einstein 接続の正則断面に Bochner 公式を適用し積分すると共変微分のノルムがゼロになる。一つの平行断面があれば不変部分束を作るので、非自明で既約な束では存在しない。標準束の自明性と Serre 双対から $H^3(X,V)\cong H^0(X,V^*)^*=0$、$h^2(X,V)=h^1(X,V^*)$ となる。従ってこの条件で指数は $-h^1(X,V)+h^1(X,V^*)$ で、荷電物質の正味数を文字通り二つのコホモロジーの差に読める。ただし指数が 3 であっても、たとえば二つの次元が 5 と 8 なら五つの共役対が残る。正味の数と個別の多重項を区別する。

:::example[自由商と Wilson 線でゲージ群を変える]
単連結な内部空間に有限群 $\Gamma$ が自由に作用し、束が同変に降りるとする。商の基本群の表現 $\rho:\Gamma\to E_6$ を選ぶと、内部の平坦な Wilson 線に沿ってゲージ場が $\operatorname{Ad}\rho$ で変換する。従って質量ゼロのゲージ代数は $\rho(\Gamma)$ と可換な成分である。物質は被覆のコホモロジーに $\Gamma$ の作用と $\rho$ を両方掛けて不変にする。位数 2 の作用なら一つの物質表現を偶奇に分け、Wilson 線の符号と同じ固有成分が残る。この射影の仕方から、指標の積分だけでは残る表現の内訳を決められないことが分かる。
:::

## 演習問題

::::exercise[スピノルの基底]{#exr-string-calabi-yau-1 level=basic}
三組の Clifford 生成演算子の外積代数の次元を求めよ。

:::solution
各生成演算子を使うか使わないかで $2^3=8$ 通りである。次数で数えると $1+3+3+1$ である。
:::
::::

::::exercise[Euler 標数]{#exr-string-calabi-yau-2 level=basic}
$(h^{1,1},h^{2,1})=(2,5)$ の $\chi$ を求めよ。

:::solution
偶奇の Betti 数の差は $2(h^{1,1}-h^{2,1})=2(2-5)=-6$ である。
:::
::::

::::exercise[IIA の多重項]{#exr-string-calabi-yau-3 level=basic}
$(h^{1,1},h^{2,1})=(3,7)$ の IIA のベクトル多重項とハイパー多重項を数えよ。

:::solution
ベクトルは $h^{1,1}=3$、ハイパーは普遍的な一つを足して $7+1=8$ である。
:::
::::

::::exercise[捻りの不動点]{#exr-string-calabi-yau-4 level=basic}
二次元トーラスの全反転の不動点を数えよ。

:::solution
各円周で $x=-x$ は周期を法として $2x=0$ である。各二解なので合計 $2^2=4$ である。
:::
::::

::::exercise[超曲面の標準束]{#exr-string-calabi-yau-5 level=advanced}
次数 $d$ の滑らかな $\mathbb{CP}^4$ 内の超曲面の $K_X$ を求めよ。

:::solution
法線束は $\mathcal O(d)|_X$ であり、接束の完全列の行列式をとると $K_X=K_{\mathbb{CP}^4}|_X\otimes\mathcal O(d)|_X=\mathcal O(d-5)|_X$ である。
:::
::::

::::exercise[Chern 類]{#exr-string-calabi-yau-6 level=advanced}
五次超曲面で $c_2$ の係数を求めよ。

:::solution
$(1+H)^5$ の二次係数は 10、一次と分母の逆数の一次の積は $5(-5)=-25$、分母の逆数の二次は 25 である。合わせて $c_2=10H^2$ である。
:::
::::

::::exercise[ミラーの Euler 標数]{#exr-string-calabi-yau-7 level=advanced}
ミラー対の Euler 標数の関係を示せ。

:::solution
二つの Hodge 数が交換されるので $\chi(Y)=2(h^{2,1}(X)-h^{1,1}(X))=-\chi(X)$ である。
:::
::::

::::exercise[IIB ベクトルの数]{#exr-string-calabi-yau-8 level=advanced}
$h^{2,1}=4$ の IIB で、重力多重項に含まれるものも合わせてベクトルを数えよ。

:::solution
三次の Betti 数は $2+2\cdot4=10$ である。自己双対条件により半分の 5 個が独立で、うち一つが重力多重項に入る。
:::
::::

::::exercise[完全交叉の Euler 標数]{#exr-string-calabi-yau-9 level=advanced}
$\mathbb{CP}^5$ における滑らかな二つの三次超曲面の完全交叉 $X$ を考える。随伴公式で $K_X$ を求め、Euler 標数と Hodge 数を計算せよ。超平面定理で $h^{1,1}=1$ を用いてよい。

:::solution
法束は $\mathcal O(3)\oplus\mathcal O(3)$ であり、標準束は $\mathcal O(-6+3+3)|_X$、すなわち自明である。全 Chern 類は $(1+H)^6(1+3H)^{-2}$ である。後ろの因子は三次まで $1-6H+27H^2-108H^3$ であり、前の因子の係数は $1,6,15,20$ である。従って一次の係数は 0、三次は $20-90+162-108=-16$ である。二つの超曲面の基本類の積は $(3H)^2$ なので $\int_XH^3=9$ であり、$\chi=-144$ を得る。$2(1-h^{2,1})=-144$ から $h^{2,1}=73$ になる。
:::
::::
