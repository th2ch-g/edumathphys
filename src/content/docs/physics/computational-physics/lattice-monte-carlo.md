## この章の目標

- 局所エネルギー差から Ising 模型の Metropolis 更新を作る。
- 補助結合を導入して二種類のクラスター更新を証明する。
- 重みの変更とレプリカ交換の受理率を導く。
- 有限格子で臨界点と臨界指数を別々に推定する。

## Ising 模型の Metropolis シミュレーション

### スピンの反転と観測単位

隣接辺を一度ずつ数える格子で $s_i=\pm1$、$E(s)=-J\sum_{\langle i,j\rangle}s_i s_j-H\sum_i s_i$ とする。これが :term[Ising 模型]{en="Ising model" yomi="いじんぐもけい"} のエネルギーであり、$J,H$ はエネルギーの単位をもつ。$s_i$ を反転すると $i$ を含む項だけの符号が変わるので $\Delta E=2s_i(J\sum_{j\sim i}s_j+H)$ となる。点を一様に選べば提案は対称であり、受理には :eqref[eq-comp-mh-accept] を用いる。受理したときは $E\leftarrow E+\Delta E$、$M\leftarrow M-2s_i$ と更新してから $s_i\leftarrow-s_i$ とする。$N$ 回の点提案を 1 sweep と定義すれば格子サイズ間の計算量が比較しやすい。

有限の正温度でランダムな単点提案なら、任意の二配置の差を有限個の反転で埋められる。一般に少なくとも一つの状態で自己遷移があれば周期は 1 である。全反転が常時受理される例では、確率 $1/2$ で提案を省略すれば周期性を避けられる。小格子では全配置を列挙して、時系列の $E,|M|,M^2$ を正準平均と照らし合わせる。

### 応答と揺らぎ

$N=L^d$ とし、$Z=\sum_s e^{-\beta E(s)}$ とする。$\partial_\beta\log Z=-\langle E\rangle$、$\partial_\beta^2\log Z=\langle E^2\rangle-\langle E\rangle^2$ は有限和の微分で得る。粒子あたりの比熱は $k_{\rm B}\beta^2\operatorname{Var}(E)/N$ である。磁場を $H$ としたとき $\partial_H\langle M\rangle/N=\beta\operatorname{Var}(M)/N$ が磁化率となる。$H=0$ の全反転対称な有限体積では $\langle M\rangle=0$ なので、秩序相の磁化の大きさには $\langle|M|\rangle/N$ を併記する。$|M|$ の分散から計算した量は、この微分として定義した磁化率と異なる。

### 小格子の厳密な基準値

四つの辺のある 4 サイト周期鎖で、$K=\beta J$、磁場なしとする。反平行な辺の数 $w$ は、鎖を一周した符号変化が偶数であるため $0,2,4$ のいずれかである。辺の位置が決まれば全体の最初のスピンに自由度が二つあるから、縮退数は順に $2,12,2$ である。エネルギーは $-J(4-2w)$ なので $Z_4=2e^{4K}+12+2e^{-4K}$ となる。$K=0$ で $Z_4=16$ が戻る。ここでの $K$ とエネルギー $E$ の関係から

$$
\langle E\rangle=-4J\frac{e^{4K}-e^{-4K}}{e^{4K}+6+e^{-4K}}
$$

である。無限温度で 0、低温で $-4J$ に近づく。4 サイトを使えば、周期の端の結合を忘れた場合と二重に数えた場合をどちらも検出できる。サンプリングと独立に厳密重みを構成することが重要である。

### 受理率と測定の実装

強磁性で磁場零の正方格子では周囲のスピン和が $-4,-2,0,2,4$ のいずれかであり、正の $\Delta E$ は $4J,8J$ だけである。温度ごとにこの二つの指数を前計算できる。固定順で一掃する方式は局所核の積として分布を保つが、その積が可逆であるとは限らない。逆順の積が随伴になるからである。配置の全サイトを同時に独立受理すると、同じ辺を二つの提案が同時に変え、事前に計算した局所エネルギー差が整合しない。二部格子では一方の色を固定すると他方の色のサイト間に辺がないので、その色内だけは同時更新できる。

### 計算実習：全列挙と連鎖の平均

4 サイトの鎖では観測を全列挙と比較できる。まず厳密な重みを式から作り、別の関数で局所差分による確率更新を行う。エネルギーを毎回計算し直すため、小さな系では局所差分の検算も兼ねる。

~~~python
from itertools import product
from math import exp
from random import Random
from statistics import mean

def energy(spins):
    return -sum(spin * spins[(index + 1) % len(spins)]
                for index, spin in enumerate(spins))

def exact_mean(coupling):
    energies = [energy(state) for state in product((-1, 1), repeat=4)]
    weights = [exp(-coupling * value) for value in energies]
    return sum(value * weight for value, weight in zip(energies, weights)) / sum(weights)

def simulated_mean(coupling, steps):
    rng = Random(761)
    spins = [1, 1, 1, 1]
    observations = []
    for step in range(steps):
        index = rng.randrange(len(spins))
        change = 2 * spins[index] * (spins[index - 1] + spins[(index + 1) % 4])
        if change <= 0 or rng.random() < exp(-coupling * change):
            before = energy(spins)
            spins[index] *= -1
            assert energy(spins) - before == change
        if step >= 1000:
            observations.append(energy(spins))
    return mean(observations)

expected = exact_mean(0.4)
estimate = simulated_mean(0.4, 30000)
print(expected, estimate)
assert abs(estimate - expected) < 0.1
~~~

この試験では $J=1$ を基準にエネルギーを測る。標本の記録を受理された更新だけに変えると、配置に滞在した時間を誤って捨てるため、十分長く実行しても一致しない。温度を低くすると局所更新で整列状態から出る確率が小さくなる。観測時間に対して独立な反転が少ないか調べ、全列挙との差を一点の受理率で説明しない。

### 鎖の移送行列で長さ依存を確認する

一次元の周期鎖では $T_{s,s'}=\exp(Kss')$ と置くと、$\tr T^L=\sum_s\prod_i T_{s_i,s_{i+1}}$ である。行列の二固有値は $2\cosh K,2\sinh K$ なので、$Z_L=(2\cosh K)^L+(2\sinh K)^L$ となる。$L=4$ なら指数を展開して $2e^{4K}+12+2e^{-4K}$ が戻る。有限温度の強磁性 $K>0$ では $\tanh K<1$ であるから、熱力学極限で $\langle E\rangle/L=-J\tanh K$ となる。スピン挿入の行列 $\diag(1,-1)$ は対称・反対称の二固有ベクトルを交換する。したがって距離 $d$ の相関は

$$
\frac{(2\sinh K)^d(2\cosh K)^{L-d}+(2\cosh K)^d(2\sinh K)^{L-d}}
{(2\cosh K)^L+(2\sinh K)^L}.
$$

$L$ が大きいと固定 $d$ で $(\tanh K)^d$ へ収束するので、相関長は格子単位で $-1/\log\tanh K$ である。この一次元模型は有限温度の真の臨界点を持たないが、低温で相関長が箱を超え、有限サイズデータでは見かけ上整列する。有限サイズスケーリングの仮説を用いる前に転移の有無を確認する例になる。

$J=1$、$s=1$、$v=4$ とする。結合を $J$、反転前のスピンを $s$、近傍スピン和を $v$ とする。各隣接項が符号を反転する。したがって、求める量は次の式で与えられる。

$$
2 J s v
$$

ここに上の値を代入して整理すると $8$ を得る。
:::

### 局所分布から直接スピンを引く

エネルギーを $E=-J\sum_{\langle i,j\rangle}s_i s_j-h\sum_i s_i$ とし、$i$ 以外を固定する。$s_i$ に依存するエネルギーは $-s_i H_i$、$H_i=J\sum_{j\sim i}s_j+h$ だけである。従って $\Pr(s_i=+1\mid s_{j\ne i})=1/(1+e^{-2\beta H_i})$ である。ここから直接選ぶ方法を :term[熱浴法]{en="heat-bath algorithm" yomi="ねつよくほう"} という。同一の周辺配置を持つ二状態の流量は、周辺配置の確率と二つの条件付き確率の積であり、順逆で一致する。有限温度で有限格子なら各スピン値を選ぶ確率は正なので、任意の配置へサイトを順に変更して到達できる。サイトを無作為に選ぶ一歩には自己遷移があり、連鎖は非周期的になる。

:::example[反転確率と新しい値の確率]
$\beta H_i=\log2$ で現在値が $-1$ の場合、Metropolis の正への反転はエネルギーを下げるので確率 1 である。熱浴法で正を選ぶ確率は $1/(1+1/4)=4/5$ である。現在値が $+1$ なら Metropolis の負への反転は $1/4$、熱浴法では $1/5$ である。定常の比は前者で $1/(1/4)=4$、後者で $(4/5)/(1/5)=4$ と一致する。一歩の滞在確率や時間相関は同じでない。
:::

### 同時に更新できるサイトを分ける

正方格子を周期境界で用い、各辺の長さが偶数とする。座標和の偶奇で二色に分けると結合は色の異なるサイト間にだけある。片方の色を固定した条件付き分布は他方の各サイトの条件付き分布の積である。従って一色を独立乱数で同時更新した後にもう一色を更新しても不変分布を保つ。全サイトの新しい値を古い配置だけから同時に作ると、隣接サイト間の結合を新しい条件付き分布に反映できない。例えば二サイトをともに低温の熱浴更新で同時に変えると、反平行の $(+,-)$ と $(-,+)$ の間を交互に動きやすい。奇数辺の周期格子では端をつなぐ結合が同色間に現れるので、同じ二色実装を使えない。



### 境界条件が基準値に入る場所

一次元周期鎖で $K=\beta J$、$B=\beta h$ とおく。結合に磁場を半分ずつ割り当てた移送行列は $T_{ss'}=\exp[Kss'+B(s+s')/2]$ である。閉じた鎖の積では各サイトの磁場が両側から一度ずつ足されるため $Z=\tr T^N$ となる。開いた鎖では $\tr$ でつながず、端の磁場半分を補う $v_s=e^{Bs/2}$ を使い $Z=v^\top T^{N-1}v$ とする。同じ $N$ でも結合数と端の重みが異なる。

$B=0$ では $T$ の固有値 $\lambda_\pm=e^K\pm e^{-K}$、固有ベクトル $(1,\pm1)/\sqrt2$ を得る。スピンを挿入する行列 $S=\diag(1,-1)$ はこの二固有ベクトルを交換する。従って周期鎖で

$$
\langle s_i s_{i+r}\rangle
=\frac{\tr(ST^r S T^{N-r})}{\tr T^N}
=\frac{t^r+t^{N-r}}{1+t^N},\qquad t=\tanh K
$$

である。固定 $r$ で $N\to\infty$ では $t^r$ となり、$J>0$ に対する格子単位の相関長は $\xi=-1/\log t$ になる。開鎖の零磁場では端の $v=(1,1)$ が $\lambda_+$ の方向にあるため、同じ挿入から $t^r$ が全有限長で得られる。この違いを小格子の検算に使う。

:::example[四サイトで周期側の補助経路が効く]
$t=1/2$、$N=4$ とする。周期鎖の一結合相関は $(1/2+1/8)/(1+1/16)=10/17$ である。開鎖では $1/2$ である。周期鎖のエネルギーは四結合で $E=-40J/17$、開鎖では三結合で $E=-3J/2$ である。エネルギーをサイト数で割ると両差に結合数の違いも入る。相関の検査にはまず一結合当たりと比較する。
:::

### 零温度と無限温度の極限を別に検査する

零磁場で $J>0$、連結した有限格子なら全結合を満たす基底配置は全正と全負の二つだけである。どちらも同じ重みなので $\beta\to\infty$ では $\langle M\rangle=0$ のまま、$\langle |M|\rangle/N\to1$ となる。局所更新の有限長の軌道が片方に留まれば $\langle M\rangle$ の推定値は $\pm N$ に近くなる。混合が遅いときでも $|M|$ の分布は早く定常らしく見えるため、奇数次モーメントや符号の滞在時間も確認する。一方、$\beta=0$ では各スピンは等確率で独立である。このとき $\langle M^2\rangle=N$、$\langle M^4\rangle=N+6\binom N2=3N^2-2N$ である。四乗の展開で各スピンが偶数回現れる項だけが残る。従って Binder 比 $U=1-\langle M^4\rangle/(3\langle M^2\rangle^2)$ は $2/(3N)$ であり、有限 $N$ では厳密に零でない。単点反転 Metropolis で $\beta=0$ にすると毎回反転するため、上向き数の偶奇が交互になる。定常平均が同じでも分布の収束を検査する場合は自己遷移を加えるか熱浴法を使う。



### 鎖の壁を数えて状態密度を作る

一次元周期の零磁場模型で $s_i\ne s_{i+1}$ の結合を壁と呼ぶ。壁数 $w$ は、全結合の積 $\prod_i s_i s_{i+1}=\prod_i s_i^2=1$ から偶数である。逆に任意の偶数個の結合を壁として選び、$s_0=\pm1$ を決めれば他のスピンは順に復元できる。最後の結合でも初期の符号に戻るため、選択のそれぞれが二配置に対応する。従って

$$
E_w=-JN+2Jw,\qquad g(E_w)=2\binom Nw\quad(w\text{ は偶数})
$$

である。開鎖では端をつなぐ条件がなく、$N-1$ 本から任意の $w$ を選べる。これで周期と開放の状態密度は低温の最初の励起から異なることが分かる。周期鎖で局所反転すると隣接二辺の壁の有無が反転する。隣接壁が零個なら二個生成、一個なら壁の移動、二個なら消滅である。従って低温で一様配置から一壁だけ作る経路はない。

:::example[八サイトの低温の平均を厳密に作る]
$N=8$ では $w=0,2,4,6,8$ に対する縮退度は $(2,56,140,56,2)$ で、和は 256 である。$t=e^{-2K}=1/4$ なら規格化の共通因子 $e^{KN}$ を除いた重みは $(2,56/16,140/256,56/4096,2/65536)$ になる。基底配置の確率は $2/[2+56/16+140/256+56/4096+2/65536]$ でおよそ $0.3300$ である。結合一つが壁になる Boltzmann 因子が $1/4$ でも、壁二つの選び方が 28 通りあるため、基底だけが支配するとは限らない。鎖長と温度を同時に変える際には、単一配置のエネルギー差と縮退度をともに見る。
:::

### 局所更新が磁化を変えるまでの経路

上の鎖で全正から一スピンを反転して二壁を作るには $4J$ のエネルギーが要る。一つの負スピンが作られた後は、負の塊の端を動かせば壁を二つ保ったまま塊の長さが変わる。仮に新しい塊の核生成を止め、負の塊の長さを $j=0,\ldots,N$ と見て、内部で伸縮を等確率とする簡約模型を考える。全負に先に到達する確率 $q_j$ は $q_0=0,q_N=1$、$2q_j=q_{j-1}+q_{j+1}$ である。差 $q_j-q_{j-1}$ が一定だから $q_j=j/N$ となり、長さ 1 の新しい塊が磁化反転を完了する確率は $1/N$ である。実際の鎖では位置選択や端の消滅確率が内部の伸縮と異なる場合があり、この数は簡約した経路モデルの値である。それでも、核生成の待ち時間と、生成した塊が残って全域へ広がる確率を分けて測る動機になる。エネルギーがほぼ定常に見えても磁化が一方の井戸に留まる理由を、時系列のイベント数で検査できる。

## 臨界緩和とクラスター・アルゴリズム（Swendsen–Wang 法と Wolff 法）

### 補助結合の同時分布

強磁性 $J>0$、磁場零で $K=\beta J$ とする。恒等式

$$
e^{K s_i s_j}=e^K[(1-p)+p\,\mathbf 1_{s_i=s_j}],\qquad p=1-e^{-2K}
$$

はスピンの積が $\pm1$ の二場合で確かめられる。各辺に $b_{ij}\in\{0,1\}$ を置き、0 の因子を $1-p$、1 の因子を $p\mathbf 1_{s_i=s_j}$ とする。$b$ を足し上げると元の Ising 分布が戻る。スピンを固定すると結合は独立に生成でき、結合を固定すると連結成分ごとにスピンの符号を独立一様に決めればよい。条件付き分布から交互に引く :term[Swendsen–Wang 法]{en="Swendsen Wang algorithm" yomi="すうぇんせんわんほう"} では、各段が同時分布を保つ。スピンだけの遷移でも $\sum_b \pi(b)\pi(s\mid b)\pi(s'\mid b)$ が両向きで同じなので可逆である。

### 一つの成分だけを反転する

:term[Wolff 法]{en="Wolff algorithm" yomi="うぉるふほう"} では一様な種から同じ向きの辺を確率 $p$ で開き、その成分を反転する。完全な結合配置を裏で引いて種の連結成分だけを調べる操作と同値である。固定結合のもとでは、成分を選ぶ確率はサイズを $N$ で割った値であり、符号には依存しない。反転は同じ確率で逆に戻せるから、条件付き分布を保つ。探索では一度閉じた辺を同じ反転の途中で再抽選しない。局所更新で相関長の大きな領域を反転するには多くの更新が要るため、臨界近くではクラスター更新が有効である。Wolff の 1 回は固定数の点を更新しないので、比較には反転サイズも記録する。

### 交換クラスターの大きさを観測量にする

結合配置 $b$ の連結成分のサイズを $n_1,\ldots,n_q$ とする。成分の符号は条件付きで独立一様であり、$M=\sum_\ell n_\ell\eta_\ell$ から $\mathbb E[M^2\mid b]=\sum_\ell n_\ell^2$ である。Wolff の一様な種が選ぶ成分の大きさの平均は $\sum_\ell(n_\ell/N)n_\ell$ である。結合条件を外せばこの平均は $\langle M^2\rangle/N$ であり、零磁場での磁化率の推定にもなる。同じ結合実現に複数の符号割当を改めて引く必要はない。例えば成分サイズ $(3,1)$ の 4 点系では条件付き二次モーメントは 10、種による平均サイズは $5/2$ である。

### 磁場と反強磁性でのクラスター条件

零磁場の強磁性で導いた条件付き符号の一様性は、$H\ne0$ では壊れる。成分サイズ $n$ の符号 $\eta$ の重みは $e^{\beta Hn\eta}$ なので、二条件付き確率の比は $e^{2\beta Hn}$ になる。Swendsen–Wang の条件付き更新でこの比を入れれば、磁場を含む同時分布を保つ。同じ結合のもとで無条件に符号を反転する Wolff 更新はそのまま可逆ではない。二部格子の零磁場反強磁性なら、一方の色のスピンだけ符号を変えて交差辺ごとの $s_i s_j$ を反転させれば強磁性へ写せる。奇数周回がある格子や周期長が奇数の鎖では全辺をこの写像で変換できない。周回上の各点の符号の積が二度ずつ現れて 1 になるためである。

### 数値例

:::example[同方向スピン間の補助結合確率]
$K=\frac{\log{\left(2 \right)}}{2}$ とする。無次元結合を $K$ とし、反整列の重みとの比を閉結合確率にする。したがって、求める量は次の式で与えられる。

$$
1 - e^{- 2 K}
$$

ここに上の値を代入して整理すると $\frac{1}{2}$ を得る。
:::

:::example[同方向スピン間の補助結合確率]
$K=\frac{\log{\left(4 \right)}}{2}$ とする。無次元結合を $K$ とし、反整列の重みとの比を閉結合確率にする。したがって、求める量は次の式で与えられる。

$$
1 - e^{- 2 K}
$$

ここに上の値を代入して整理すると $\frac{3}{4}$ を得る。
:::

### 結合表現から帯磁率を測る

零磁場の強磁性系では補助結合配置を固定すると、連結成分 $C$ ごとの符号 $s_C$ は独立に $\pm1$ となる。全磁化 $M=\sum_C s_C |C|$ の条件付き二乗平均は $\sum_C |C|^2$ である。異なる成分の交差項の期待値は符号の独立性で零となる。従って有限系の零磁場帯磁率 $\chi=\beta\langle M^2\rangle/N$ は、符号を引き直さずに $\beta\sum_C |C|^2/N$ の標本平均で測れる。この条件付き期待値は分散分解から元の $M^2$ と比べて分散が大きくならない。定常状態の Wolff 更新で種を一様に選ぶと成分 $C$ を選ぶ確率は $|C|/N$ なので、選ばれるクラスターの平均サイズは $\langle\sum_C|C|^2/N\rangle$ になる。これは単一ステップの期待値の等式であり、系列の自己相関が同じになることは意味しない。

:::example[成分を等確率で選んだ場合との違い]
$N=8$ でクラスターの大きさが $(4,3,1)$ のとき、二乗和は $16+9+1=26$ である。全磁化の条件付き平均は零で、二乗平均は 26 である。一様なサイトを種にすると成分サイズの平均は $26/8=13/4$ であり、成分そのものを等確率に選んだときの $8/3$ と異なる。後者を Wolff 法に代入する場合には、種から作る提案の確率が変わるため詳細つり合いを再検証する。
:::

### 計算時間で臨界減速を比較する

自己相関時間の単位が単一サイト反転と単一クラスター反転では異なる。局所更新を $N$ 回行うと一巡であり、Wolff 法では各反転で平均 $\bar c$ サイトを訪ねる。$m$ 回のクラスター反転は訪問数の平均で $m\bar c/N$ 巡に相当する。例えば $N=1024$、$\bar c=128$、磁化二乗の自己相関時間が 12 クラスター更新なら 1.5 巡相当である。隣接結合を調べる負荷、乱数発生、通信の時間まで比べるには実測時間を併記する。系のサイズを大きくして測った $\tau(L)\propto L^z$ の $z$ は更新規則と測定単位に依存し、平衡分布の静的臨界指数とは区別する。



### 一辺の補助結合が作る磁化相関

零磁場の強磁性模型で補助結合配置を $\omega$ とする。条件付きで同じ成分の二点は同じ符号を持ち、異なる成分なら独立で平均零である。従って

$$
\langle s_i s_j\rangle=\Pr(i\leftrightarrow j)
$$

となる。左辺のスピン積を平均する代わりに、結合の連結性を観測する推定量を得る。この関係は一度の補助結合を作ると全二点の連結性が決まるため、相関長や帯磁率を同じ情報から調べられる。一方、磁場がある場合は成分の符号がサイズに依存して偏り、異なる成分の平均積も零とは限らない。外場を追加の固定符号サイトへの結合として表す場合、同じ成分に入るかどうかに加えてそのサイトへの連結性を区別する。

:::example[二サイトの結合表現を全列挙する]
一本だけ結合する二スピンで $t=e^{-2K}$ とする。平行の確率は $1/(1+t)$、これに補助結合を入れる条件付き確率は $1-t$ である。従って結合がある確率は $(1-t)/(1+t)=\tanh K$、二点相関と一致する。$K=\log2$ なら $t=1/4$、連結確率は $3/5$ である。二つのサイトの間を長さ二の経路でつなぎ、両辺の結合が同じ $K$ の開鎖にすると、内部スピンを条件に両端は独立でそれぞれ平均 $s_{\rm mid}\tanh K$ となる。従って両端の相関は $9/25$ である。
:::

### クラスター反転を非対称な提案として解釈する

Wolff 法で境界の未追加辺の確率を確認する。固定して比較する成分 $C$ と種を取り、反転前に成分の内外を結ぶ平行辺を $b_+$、反平行辺を $b_-$ と数える。内部の同符号辺から $C$ を連結にする操作の確率は全反転前後で同じである。境界では平行辺だけが追加の候補になり、追加しない確率が $1-p=e^{-2K}$ である。従って特定の $C$ を作る前後の比は $(1-p)^{b_+-b_-}$ である。反転エネルギー差は $2J(b_+-b_-)$ だから、提案確率自身が Boltzmann の比を持つ。種を同じ一様分布から選ぶと $C$ 内の種を足しても比が変わらない。よって別の受理判定なしで二状態の流量が一致する。内部の結合を足した順序が複数ある実装でも、各辺の Bernoulli 試行を一度ずつと同等な作り方であれば、内部の和は前後で共通である。試行に失敗した辺を異なる経路から再試行すると、この境界確率にならない。

:::example[クラスターだけが境界の高いエネルギーを越える]
三スピンの開鎖で初期状態 $(+,+,-)$、成分として二つの正スピンを反転する。内部の $(1,2)$ 辺が選ばれる確率は $p$、境界 $(2,3)$ は反平行で候補外である。反転後の $(-,-,-)$ から同じ成分を提案するには内部を結ぶのに加え、境界を拒否する確率 $1-p$ が掛かる。元へ戻る向きで $\Delta E=2J$ なので比は $e^{-2K}$ である。$K=\log2$ なら前向きの種込みの確率は $(2/3)(3/4)=1/2$、逆は $1/8$ となる。
:::



### 結合成分の抽出を全列挙で検査する

小さい鎖で Swendsen–Wang の一巡の遷移確率を直接計算できる。同符号の辺が $b$ 本あるスピン配置を固定し、そのうち採用した集合 $A$ の確率を $p^{|A|}(1-p)^{b-|A|}$ とする。$A$ でつながる成分が $c(A)$ 個あるなら、新しい符号割当て一つの確率は $2^{-c(A)}$ である。従って $P(\sigma,\sigma')$ は、新配置も各成分で一定となる $A$ についてこれら二因子の積を足した値である。例えば開鎖三サイトの $(+,+,+)$ から、$(+,-,+)$ へ移るには二辺とも捨てる必要がある。確率は $(1-p)^2/8$ である。逆に $(+,-,+)$ では同符号辺がなく、全配置への遷移確率は $1/8$ となる。$\Delta E=4J$ で正方向の比 $(1-p)^2=e^{-4K}$ と一致する。

全列挙した行列を使えば受理率以外の差も見える。二サイトの一本の結合で $t=e^{-2K}$ とし、観測 $u=s_1s_2$ を考える。単点熱浴では現在の $u$ によらず、新しい $u$ が平行となる確率は $1/(1+t)$ である。従って $u$ の自己相関は一歩で消える。Swendsen–Wang では現在平行なら確率 $1-t$ で一成分となって $u'=1$、残りでは等確率の二符号で平均零なので $\mathbb E[u'|u=1]=1-t$ である。反平行なら結合がなく条件付き平均は零である。中心化した $u$ の固有値は $(1-t)/2$ である。小さな模型ではクラスター更新の方が常に自己相関が短いわけではなく、大きな実系では主な遅いモードと一巡の費用を比較する。

## ヒストグラム法と再重み付け

### 温度間の重み比

逆温度 $\beta_0$ からの標本に対し、目標 $\beta_1$ の重みは $w(E)=e^{-(\beta_1-\beta_0)E}$ である。規格化の比 $Z(\beta_1)/Z(\beta_0)=\langle w\rangle_{\beta_0}$ を用いると $\langle A\rangle_{\beta_1}=\langle Aw\rangle_{\beta_0}/\langle w\rangle_{\beta_0}$ が得られる。エネルギー別の縮退数を $g(E)$ とすると、ヒストグラム確率は $g(E)e^{-\beta E}/Z$ である。したがって単一ヒストグラムから $g$ を比例定数まで推定できる。

独立試行近似でラン $a$ の標本数を $n_a$ とすれば、エネルギーごとの全カウントの期待値は $g(E)\sum_a n_a e^{-\beta_a E}/Z_a$ となる。この式を観測カウントへ合わせ、$Z_a=\sum_Eg(E)e^{-\beta_a E}$ と交互に更新するのが多ヒストグラム推定である。全 $g$ の定数倍は同じ確率を与える。各窓を異なるエネルギー範囲に制限し、それらの範囲が重ならなければ、範囲ごとに独立な規格化が残る。範囲を制限しない正準計算でも、観測された度数の山が離れ、共通域の確率がごく小さいと相対規格化が不安定になる。相関がある系列では独立試行の式を誤差に使わず、各系列をブロックで再標本化して推定全体をやり直す。

### 温度の許容範囲をエネルギー幅で見積もる

$Z(\beta+\delta)/Z(\beta)=\langle e^{-\delta E}\rangle$ を対数展開すると、先頭の曲率は $\operatorname{Var}(E)$ である。したがって $\delta\sqrt{\operatorname{Var}(E)}$ が大きい場合、重みはカウントの少ない尾部へ偏りやすい。これは重なりの目安であり、エネルギー分布が複峰性なら端のピークの有無を直接調べる。再重み付けされた比の誤差は窓ごとに独立と仮定せず、元のエネルギーと磁化モーメントを同時に再標本化し、同じ試行で全目標温度を再計算する。

### 数値例

:::example[エネルギー再重み付けの比]
$b=\log{\left(2 \right)}$、$E=-1$ とする。逆温度差を $b$、エネルギーを $E$ とする。両温度での非規格化確率の比を取る。したがって、求める量は次の式で与えられる。

$$
e^{- E b}
$$

ここに上の値を代入して整理すると $2$ を得る。
:::

:::example[エネルギー再重み付けの比]
$b=\log{\left(2 \right)}$、$E=2$ とする。逆温度差を $b$、エネルギーを $E$ とする。両温度での非規格化確率の比を取る。したがって、求める量は次の式で与えられる。

$$
e^{- E b}
$$

ここに上の値を代入して整理すると $\frac{1}{4}$ を得る。
:::

### 複数のヒストグラムで状態密度を決める

エネルギー箱 $E$ に状態密度 $g_E$ があり、逆温度 $\beta_k$ で $N_k$ 個の独立標本を取ったとする。$P_k(E)=g_E e^{-\beta_k E}/Z_k$、度数を $n_{kE}$ と書く。定数を除いた対数尤度は $\sum_{kE} n_{kE}(\log g_E-\beta_k E)-\sum_kN_k\log Z_k$ である。$\theta_E=\log g_E$ の微分を零にすると

$$
g_E=\frac{\sum_k n_{kE}}{\sum_k N_k e^{-\beta_k E}/Z_k},
\qquad Z_k=\sum_E g_Ee^{-\beta_k E}.
$$

各 $Z_k$ は全 $g_E$ の線形和なので、二式を交互に更新する。$\theta_E$ に定数を足しても確率は変わらないため、一つの $Z_k$ の規格化を固定する。尤度の Hessian の二次形式は任意のベクトル $a_E$ に対し $-\sum_k N_k\operatorname{Var}_{P_k}(a_E)$ であり、凹性が成り立つ。これは各 $\log Z_k$ を方向 $a$ に沿って二回微分した結果である。窓が実質的に分離していれば相対規格化の方向の曲率が小さく、推定が不安定になる。

窓内で許されるエネルギーの集合を $S_k$ に制限するなら、$Z_k$ の和と上の更新の分母をそれぞれ許された項だけに限る。全ビンを頂点とし、同じ窓で正の確率をもつビン同士を辺で結ぶ。Hessian の二次形式が零となる方向は、すべての窓で $a_E$ が一定となる方向である。したがってグラフが連結なら全体の規格化一つだけが残り、分断されていれば連結成分ごとに一つずつ残る。有限温度の正準窓が共通のビンをすべて許すときは、標本度数の零だけで辺を消さない。共通域に測定がほとんどなければ、独立な再計算や中間窓を使って規格化の不確かさを確認する。

:::example[二準位の度数から縮退度比を読む]
$E=0,1$ とし、$\beta_1=0$ で度数 $(20,40)$、$\beta_2=\log2$ で $(30,30)$ を観測した。$g_0=1,g_1=2$ なら $Z_1=3,Z_2=2$ である。$E=0$ の更新は $50/(60/3+60/2)=1$、$E=1$ の更新は $70/(60/3+30/2)=2$ となる。従って同じ状態密度で二つの温度を説明できる。相関する系列ではこの独立標本の尤度から得た曲率だけを誤差とせず、温度ごとの時系列をブロック化して解き直す。
:::



### 再重み付けの微分で不確かさを追う

同じ温度の系列 $(E_i,A_i)$ を $\Delta\beta$ だけ動かし、$w_i=e^{-\Delta\beta E_i}$ とする。$\widehat A=\sum_i w_i A_i/\sum_i w_i$ を $\Delta\beta$ で微分すると

$$
\widehat A'=-\left(\frac{\sum_i w_i E_i A_i}{\sum_iw_i}
-\frac{\sum_iw_i E_i}{\sum_iw_i}\frac{\sum_iw_i A_i}{\sum_iw_i}\right)
$$

となる。符号と単位は、逆温度増分がエネルギーの逆数の単位を持つことから確認できる。平均エネルギーで $A=E$ と置けば必ず非増加であり、横軸を温度に変換すると比熱に相当して非減少の方向になる。複数の $\beta$ の曲線を同じ標本から作ると点ごとの誤差は強く相関するため、交差やピークの位置を推定するときはブロックごとに曲線全体を作り直す。

:::example[一つの高エネルギー箱に誤差が集中する]
$E=0,2$ の二箱で、元の度数が $90,10$、$A$ がそれぞれ 0 と 1 とする。$\Delta\beta=-(\log3)/2$ なら高い箱の重みが三倍で、推定値は $30/(90+30)=1/4$ である。$\widehat A'=-2(1/4)(3/4)=-3/8$ である。もし高い箱の度数が 10 から 11 へ、低い箱が 90 から 89 へ変わると推定値は $33/122$ となる。増分は約 0.0205 で、元の温度での頻度差 0.01 より大きい。ヒストグラムの主な山がよく測れていても、外挿先の誤差は裾の度数に支配されうる。
:::

### 一つの反応座標へまとめると失う情報

Hamiltonian が $E=E_0-hM$ の形なら、逆温度と磁場を同時に変える比は $e^{-(\beta'-\beta)E_0+(\beta'h'-\beta h)M}$ である。無磁場の $E_0$ のヒストグラムだけでは異なる磁場に移せない。同じ $E_0$ の箱に異なる $M$ が入るためである。同時ヒストグラム $H(E_0,M)$、または時系列の $(E_0,M)$ を保持する。例えば零温度の二つの基底状態は同じ $E_0$ だが、磁場を正にしたときの比は $e^{2\beta hN}$ である。箱内平均 $\langle M|E_0\rangle=0$ だけを保存して使うと、指数の非線形性で正しい比を作れない。磁場による再重み付けで $A=M^k$ を求める場合には、同じ箱内で $M^k$ と指数重みの積まで保持する必要がある。

## レプリカ交換法とマルチカノニカル法

### 複数温度の同時分布

独立な温度スロット $a,b$ の同時重みは $e^{-\beta_a E_a-\beta_b E_b}$ である。配置だけ交換した重みを元で割ると

$$
R=\exp[(\beta_a-\beta_b)(E_a-E_b)].
$$

交換候補を対称に選べば $\min(1,R)$ が受理率であり、各スロット内の更新と合成しても同時分布を保つ。高温から低温まで往復した回数を数えると、個々の隣接対の受理率では分からない混合の問題が見える。測定値は配置の識別番号ではなく現在の温度で分類する。

### エネルギーに対する平坦な分布

:term[マルチカノニカル法]{en="multicanonical method" yomi="まるちかのにかるほう"} では配置の重み $W(E)\approx1/g(E)$ を学習して、エネルギー分布 $g(E)W(E)$ を広い範囲にする。$W$ を固定した生産区間での正準重みは $e^{-\beta E}/W(E)$ である。適応中に $W$ が更新された系列には固定分布の詳細つり合いを適用できない。目標温度が必要とする全エネルギー範囲を含むことを確認し、変数がエネルギーと粗い関係しか持たない障壁にも注意する。

### 温度交換と拡張重みの収束を見る

レプリカ交換は、各温度の正準重みを積にした標的を変えない。一方、マルチカノニカル法はエネルギーの周辺分布を変え、測定時に重みを戻す。マルチカノニカル重みの試行 $W$ で得たヒストグラム $H(E)$ が信頼できるビンでは、$W_{\rm new}(E)=W(E)/H(E)$ とすれば、真のヒストグラムで置き換えた理想反復で $g(E)W_{\rm new}(E)$ は定数になる。零カウントではこの式を適用できないので、到達していない範囲を取得する試行を先に行う。学習後には二つ以上のエネルギー境界を往復するかも確かめる。

### 数値例

:::example[レプリカ交換の受理率]
$b=\log{\left(2 \right)}$、$d=-1$ とする。逆温度差を $b$、交換前の同じ順でのエネルギー差を $d$ とし、比を 1 で切る。したがって、求める量は次の式で与えられる。

$$
\min\left(1, e^{b d}\right)
$$

ここに上の値を代入して整理すると $\frac{1}{2}$ を得る。
:::

:::example[レプリカ交換の受理率]
$b=\log{\left(2 \right)}$、$d=1$ とする。逆温度差を $b$、交換前の同じ順でのエネルギー差を $d$ とし、比を 1 で切る。したがって、求める量は次の式で与えられる。

$$
\min\left(1, e^{b d}\right)
$$

ここに上の値を代入して整理すると $1$ を得る。
:::

### レプリカが温度軸を往復するかを見る

交換の受理率だけでは低温と高温を結ぶ全経路を検査できない。温度を固定したスロットへ配置の識別子を置き、交換のたびに識別子も交換する。最低温度から最高温度を経て最低温度へ戻った回数を各識別子について測る。一つの温度境界で交換がほぼ起きないと、他の境界で高受理でも往復は起きない。例えば四温度の隣接交換率が $0.5,0.001,0.5$ なら中央が律速になる。独立な試行で近似しても平均して中央の一回に $1000$ 試行を要し、往復には少なくとも二回通過が必要である。各温度のエネルギーヒストグラムの重なりを調べ、比熱が大きい領域でより細かく温度を置く理由がここにある。

### 状態密度を適応的に見積もる

:term[Wang–Landau 法]{en="Wang–Landau algorithm" yomi="わんらんだうほう"} では推定対数状態密度 $G(E)$ を持ち、対称な構成提案を $\min(1,e^{G(E)-G(E')})$ で受理する。採否の後で滞在した箱の $G$ に正の増分 $\delta$ を足す。同じ箱に滞在するほどその箱から他箱へ出やすくなり、戻りにくくなる。実際に $G=\log g$ を固定すれば箱の確率は $g(E)e^{-G(E)}$ で一定である。適応中には毎歩重みが変わるため、この固定重みの定常分布の証明をその区間へ適用できない。$\delta$ を段階的に下げて探索した後、重みを固定した生産計算で観測量を求める。到達不能なエネルギー箱を平坦化の目標に含めると停止条件を満たせない。



### 平均交換率を Gaussian 近似から設計する

逆温度が $\beta$ と $\beta+\delta$ の二レプリカについて、同じ近傍のエネルギー分散を $s^2$ と近似する。$\partial_\beta\langle E\rangle=-\operatorname{Var}(E)$ だから、低い温度側の平均を $\delta s^2$ だけ下げる。独立な二つのエネルギーの差 $D=E_{\rm hot}-E_{\rm cold}$ は平均 $\delta s^2$、分散 $2s^2$ の正規と近似できる。交換率は $\min(1,e^{-\delta D})$ である。$D\le0$ の項は $\Phi(-\delta s/\sqrt2)$、$D>0$ の項は $e^{-\delta D}$ を正規密度へ掛けて平方完成すれば、平均を $-\delta s^2$ にした正規の正側確率で同じ値となる。従って平均受理率は $2\Phi(-\delta s/\sqrt2)$ である。例えば $\delta s=\sqrt2$ なら $2\Phi(-1)\simeq0.3173$ である。比熱が大きく $s$ が増える区間で温度刻みを縮める目安になる。二相共存のようにエネルギーが二峰なら、平均と分散だけでは交換率も往復時間も十分に予測できない。

### 平坦なエネルギー分布から正準平均へ戻す

固定重み $w(E)>0$ で配置を標本化し、欲しい温度の比 $e^{-\beta E}/w(E)$ を観測ごとに掛ける。例えばエネルギー $E=0,1,2$ に縮退度 $g=(1,4,1)$ があるとする。$w=(1,1/4,1)$ を使うとエネルギー箱は等確率になる。$\beta=\log2$ の正準重みを戻す比は順に $(1,2,1/4)$、従って正準確率は $(4,8,1)/13$、平均エネルギーは $(8+2)/13=10/13$ である。$w$ の二番目を推定誤差で $1/3$ にしても、実際に用いた重みを正しく分母に入れれば上の平均へ戻る。ところが平坦だと仮定して箱を強制的に等頻度に変えてから戻すと、実分布の $g(E)w(E)$ を消してしまい分布が変わる。適応後に実際の重みを固定して再度平衡化する理由である。



### エネルギーで二峰になる転移を有限系で分ける

温度が等重みの二相を与える近傍で、体積を $V=L^d$、エネルギー密度のピークを $e_1,e_2$ とする。各相の内部のエネルギー分散が $O(V)$、相間の平均差が $V(e_2-e_1)$ なら、全分散の分解により混合の分散は $V^2(e_2-e_1)^2/4+O(V)$ である。単位体積の比熱は $k_{\rm B}\beta^2\operatorname{Var}(E)/V$ なので主項は $O(V)$ になる。一方、片方のピークにしか訪れない系列では内部の分散 $O(V)$ だけを見て比熱が $O(1)$ に見える。両相のピークに入った標本数だけでなく、相間を何回往復したかを記録する。マルチカノニカル法では谷の重みを引き上げるが、同じエネルギー箱の内部に別の遅い変数があれば、エネルギーヒストグラムの平坦性だけでは混合を保証できない。

:::example[二ピークの体積成長を定量化する]
$e_2-e_1=1$、相内の分散がどちらも $2V$、$\beta=1$ とする。ピークの重みが半々なら比熱は $C/(Vk_{\rm B})=2+V/4$ である。$V=64$ なら $C/(Vk_{\rm B})=18$、片相のみでは 2 である。標準偏差の比をエネルギー軸で計算するとピーク間隔は $V/\sqrt{2V}=\sqrt{V/2}$ 個の相内標準偏差となる。サイズを増やして二相がよく見えることと、通常の正準法で谷を通れることは別である。
:::

## 有限サイズスケーリングによる臨界指数の決定

### スケーリング窓

換算温度 $t=(T-T_c)/T_c$、熱力学極限の相関長 $\xi\sim|t|^{-\nu}$ を想定する。有限格子で $L/\xi$ が同程度の点を比較するため、変数 $t L^{1/\nu}$ を使う。臨界領域では、例えば $m_L=\langle|M|\rangle/N=L^{-\beta_{\rm m}/\nu}f_m(t L^{1/\nu})$、$\chi_L=L^{\gamma/\nu} f_\chi(t L^{1/\nu})$ を先頭のスケーリング仮説とする。ここで $\beta_{\rm m}$ は秩序変数指数である。熱力学極限の $m\sim(-t)^{\beta_{\rm m}}$ と一致するには、負側で $f_m(x)\sim(-x)^{\beta_{\rm m}}$ である必要があり、このとき $L$ のべきが打ち消し合う。磁化率については、高温側で $f_\chi(x)\sim x^{-\gamma}$ が必要である。低温側の有限零磁場系で全磁化の分散をそのまま使うと、正負二相の混合により $\chi_L$ に $\beta N m^2$ の寄与が残る。単一の純粋相の応答を低温側で比較するには、対称性を破ったうえで熱力学極限を取るか、片相内の揺らぎを別に測る。

Binder 比 $U_L=1-\langle M^4\rangle/(3\langle M^2\rangle^2)$ では磁化のスケール因子が消える。先頭近似では異なる $L$ のグラフが $t=0$ で交差し、勾配の大きさは $L^{1/\nu}$ に比例する。補正を $U_L=U_*+atL^{1/\nu}+bL^{-\omega}$ としたとき、$L$ と $sL$ の差を 0 として $t_{\rm cross}=b(1-s^{-\omega})L^{-\omega-1/\nu}/[a(s^{1/\nu}-1)]$ を得る。交点のずれと傾きの変化を無視した回帰は指数を偏らせる。サイズ下限と温度窓を変え、同じ時系列から再重み付けした温度点どうしの相関も考慮する。

### 勾配を温度差なしで求める

固定 $L$ に対して $m_2=\langle M^2\rangle$、$m_4=\langle M^4\rangle$ と置く。正準平均を逆温度で微分すると $m'_j=-\operatorname{Cov}(M^j,E)$ である。よって

$$
\partial_\beta U_L=
\frac{\operatorname{Cov}(M^4,E)}{3m_2^2}
-\frac{2m_4\,\operatorname{Cov}(M^2,E)}{3m_2^3}.
$$

これを温度微分にするには $\partial_T\beta=-1/(k_{\rm B}T^2)$ を掛ける。交点での傾き比が $L$ と $2L$ の間で 2 なら、補正なしでは $2^{1/\nu}=2$ から $\nu=1$ である。有限サイズによりピーク位置も動くので、異なる量から求めた $T_c$ と $\nu$ を比較する。二次元など比熱が対数で成長する場合、単純に小さい正のべきに当てはめると識別できない。モデルの候補ごとにサイズ窓を変えて残差を調べる。

### 観測量に応じた有限サイズのべき

臨界で相関が $G(r)\sim r^{-(d-2+\eta)}$ と仮定する。空間和を半径積分で見積もると、磁化率のサイズ依存は $\int_1^L r^{d-1}r^{-(d-2+\eta)}\dd r\sim L^{2-\eta}$ となる。ただし $\eta<2$、境界・形状の比を固定し、短距離の寄与を下位項として扱う。この結果と $\chi_L\sim L^{\gamma/\nu}$ を合わせると、両仮定のもとで $\gamma/\nu=2-\eta$ である。$L$ と $2L$ で磁化率の比を取り、その対数を $\log2$ で割って個々のサイズから有効なべきを得る。小さいサイズでは有限の背景項が比に入るので、そのまま漸近指数と解釈しない。$T_c$ の不確かさを温度方向の再重み付けで伝播するときは、交点や指数の計算を同じ再標本化ごとに行う。

### 数値例

:::example[モーメントから求める Binder 比]
$a=2$、$b=4$ とする。磁化の二次と四次モーメントを $a,b$ とする。磁化の尺度を消すため分母に二次モーメントの二乗を置く。したがって、求める量は次の式で与えられる。

$$
1 - \frac{b}{3 a^{2}}
$$

ここに上の値を代入して整理すると $\frac{2}{3}$ を得る。
:::

:::example[モーメントから求める Binder 比]
$a=2$、$b=8$ とする。磁化の二次と四次モーメントを $a,b$ とする。磁化の尺度を消すため分母に二次モーメントの二乗を置く。したがって、求める量は次の式で与えられる。

$$
1 - \frac{b}{3 a^{2}}
$$

ここに上の値を代入して整理すると $\frac{1}{3}$ を得る。
:::

### 交差温度のずれを補正項まで追う

無次元量 $R_L(t)$ を $t=(T-T_c)/T_c$ の近傍で $R_*+a t L^{1/\nu}+b L^{-\omega}$ と近似する。$a\ne0$、$\omega>0$ とし、サイズ $L$ と $sL$、$s>1$ の交差を取ると

$$
t_\times=\frac{b(1-s^{-\omega})}{a(s^{1/\nu}-1)}L^{-\omega-1/\nu}.
\label{eq-comp-binder-crossing-shift}
$$

これは二つの式を引いて $t$ を解いたものである。補正項がなければ交差は $t=0$ で一致するが、有限の格子では交差点を複数対で測り、:eqref[eq-comp-binder-crossing-shift] のべきに沿って外挿する。サイズ比を変えると係数も変わるため、横軸を $L$ だけにして全てを同じ直線へ当てはめない。

:::example[交差と勾配から異なる指数を読む]
$\nu=\omega=a=1$、$b=1/4$、$s=2$ なら $t_\times=1/(8L^2)$ である。$L=8,16$ の交差は $1/512$、$16,32$ の交差は $1/2048$ である。一方、交差点での傾きはこの近似で $L$ に比例するため、傾きの比 $\partial_t R_{2L}/\partial_t R_L=2$ から $1/\nu=1$ を得る。交差のずれの指数はここでは 2 であり、勾配の指数と取り違えると $\nu$ を半分に推定する。
:::




### 二次モーメント相関長を最小波数から測る

並進不変な系で、座標軸の置換と各軸の鏡映に対して対称な相関関数 $G(r)$ を考える。$\sum_r(1+|r|^4)|G(r)|<\infty$、$S(0)>0$ と仮定し、構造因子 $S(k)=\sum_r G(r)e^{ik\cdot r}$ を考える。反転対称性で一次項は消え、軸間の対称性から二次項の係数は各軸同じなので

$$
S(k)=S(0)\bigl[1-\xi_2^2 |k|^2+O(|k|^4)\bigr],\qquad
\xi_2^2=\frac{\sum_r |r|^2G(r)}{2d\sum_r G(r)} .
$$

有限周期格子では $S(0)=N^{-1}\langle|M|^2\rangle$、最小非零波数 $k_{\min}$ で $S(k)=N^{-1}\langle|\sum_x s_xe^{ikx}|^2\rangle$ を測る。離散 Laplacian の波数二乗 $4\sin^2(k_{\min}/2)$ を使った

$$
\xi_{2,L}=\frac{1}{2\sin(\pi/L)}
\sqrt{\frac{S(0)}{S(k_{\min})}-1}
$$

が有限系の定義になる。磁場で平均磁化が非零なら積から切断相関を作り、$k=0$ で $\langle M\rangle^2/N$ を差し引く。$\xi_{2,L}/L$ は無次元なのでサイズ間の交差を臨界温度の推定に使える。有限標本で比が 1 未満に見える場合は、平方根の前に切ってしまうと偏るため、元の $S$ と共分散を調べる。

:::example[一次元の指数相関で二種類の相関長を比べる]
$G(r)=t^{|r|}$、$0<t<1$ の無限鎖で、正負の幾何級数から $S(k)=(1-t^2)/(1-2t\cos k+t^2)$ である。従って $S(0)/S(k)-1=4t\sin^2(k/2)/(1-t)^2$ となり、二次モーメント長は $\sqrt t/(1-t)$ である。$t=1/2$ なら $\xi_2=\sqrt2\simeq1.414$、裾を一指数で読んだ $\xi=-1/\log t\simeq1.443$ とは少し違う。$t\to1$ では両方が $1/(1-t)$ と同じ主項で発散するため、臨界近傍のスケーリングで同じ指数が得られる。
:::

### 感度の異なる観測量で指数を照合する

臨界で磁化密度の分布を $p_L(m)=L^{x}f(m L^x)$ と仮定すると、$m L^x$ で変数変換して $\langle |m|^q\rangle=L^{-qx}\int |z|^qf(z)\dd z$ となる。従って零磁場の帯磁率 $\beta L^d\langle m^2\rangle$ は $L^{d-2x}$、Binder 比はサイズに依らない主項を持つ。仮定の $x=\beta_{\rm mag}/\nu$ と、帯磁率のべき $\gamma/\nu$ を両方測れば $\gamma/\nu=d-2x$ との整合を検査できる。この議論は単一スケールの分布形を仮定するものであり、上部臨界次元や境界による補正が強い場合に無条件で適用しない。例えば $d=2$ で $L$ を二倍にした磁化比が $2^{-1/8}$ なら帯磁率比は $2^{7/4}\simeq3.364$ である。比を一組だけで計算するのでなく、複数のサイズ対の有効指数を出して補正の向きも確認する。




### 磁化の微分を相関から直接求める

$E$ が逆温度に依存しないとき、逆温度に依存しない観測量 $A$ について $\partial_\beta\langle A\rangle=-\operatorname{Cov}(A,E)$ である。Binder 比 $U=1-m_4/(3m_2^2)$ の微分は

$$
\partial_\beta U=\frac{\operatorname{Cov}(M^4,E)}{3m_2^2}
-\frac{2m_4\operatorname{Cov}(M^2,E)}{3m_2^3},
\qquad m_j=\langle M^j\rangle
$$

である。これは温度を微小にずらした二本の独立計算の差を取らずに得られる。ただし四次モーメントと共分散はそれぞれ標本誤差が大きくなりうる。例えば $m_2,m_4$ の誤差が相関すれば、上の二項の誤差も相殺または増幅する。ブロックを一つずつ落とした系列で式全体を再計算すれば、共分散を入れずに各量を別々に誤差伝播するより適切な評価ができる。$\beta_c$ 自体を同じ系列の Binder 交差から推定したなら、ブロックごとに交差も求め直す。

:::example[二磁化を持つ小模型の Binder 曲線]
$M=\pm1$ をエネルギー 0 に、$M=\pm2$ をエネルギー $E>0$ に割り当てる。高い準位の確率を $p=(1+e^{\beta E})^{-1}$ とすれば $m_2=1+3p$、$m_4=1+15p$ である。$\beta E=\log3$ では $p=1/4$、$m_2=7/4$、$m_4=19/4$、$U=1-76/147=71/147$ である。$p'=-Ep(1-p)$ を入れて
$\partial_\beta U=E p(1-p)[15(1+3p)-6(1+15p)]/[3(1+3p)^3]$ を得る。この点では括弧が $-9/4$ なので微分は $-9E/343$ で負となる。Binder 比は一般の有限模型で温度に単調とは限らないので、交差の根を探すときに単調性を仮定しない。
:::



### 交差点と指数の誤差を同じ再標本化で求める

サイズ $L,sL$ の曲線を差し引いた $D(T)=U_L(T)-U_{sL}(T)$ が単純根 $T_\times$ を持つとする。二曲線の統計誤差を $\delta U$ と書くと、一次近似では $\delta T_\times=-(\delta U_L-\delta U_{sL})/D'(T_\times)$ である。これは根の方程式の Taylor 展開で得る。共分散があれば分子の分散には $-2\operatorname{Cov}(\delta U_L,\delta U_{sL})$ が入る。続いて勾配比から $1/\nu$ を求める場合、交差温度と勾配を同じ再標本化で求め直す。交差点の近くで $D'$ が小さい場合には、線形化で誤差を表せる範囲が狭くなる。再標本化の一部で交差自体が得られない場合は、その割合も記録する。

:::example[交差温度の誤差を曲線の勾配から見積もる]
同じ温度で、独立に計算した二サイズの Binder 比の標準誤差が各 $0.002$、差の勾配が $0.4\,\mathrm K^{-1}$ なら、交差温度の標準誤差の一次近似は $\sqrt2(0.002)/0.4\simeq0.0071\,\mathrm K$ となる。交差の有限サイズ補正がこの値と同程度なら、より多くの標本を取ると統計誤差は小さくなるが、外挿に必要なサイズの数は増えない。サイズを追加して交差のずれのべきを測る。
:::

### 二次元 Ising 模型の温度を双対性から照合する

零磁場の正方格子で $e^{K s_i s_j}=\cosh K\, [1+s_i s_j\tanh K]$ と展開する。全スピンの和を取ると、各点で選んだ辺の本数が偶数の項だけが残る。奇数回現れるスピンは $+1,-1$ の和で消えるからである。従って高温の展開は、偶数次数の部分グラフ $\Gamma$ を長さ $|\Gamma|$ の重み $(\tanh K)^{|\Gamma|}$ で足す。双対格子の低温展開では、異符号のスピンを分ける壁が元の格子の辺を通る。壁長一辺ごとにエネルギーが $2J^*$ 増えるため、重みは $e^{-2K^*|\Gamma|}$ である。平面上で外側の双対スピンを固定すれば、壁を横切るごとに符号を反転して内部のスピンを復元できる。偶数次数の壁に対して閉じた経路を一周しても反転回数が偶数なので、復元は一貫する。従って二つの展開の非自明な部分は $e^{-2K^*}=\tanh K$ で対応する。トーラスでは座標を一周する壁の部門があるため、周期境界だけの分配関数をそのまま一対一に同定しない。

この対応の固定点は $e^{-2K}=\tanh K$ を満たす。$x=e^{2K}$ と置くと $1/x=(x-1)/(x+1)$ だから $x^2-2x-1=0$、正の解は $1+\sqrt2$ である。従って $K_{\rm sd}=\tfrac12\log(1+\sqrt2)$、$k_{\rm B}T_{\rm sd}/J=2/\log(1+\sqrt2)\simeq2.269$ となる。双対性の計算だけで転移が一つであることを証明したわけではない。熱力学極限の正方格子零磁場模型でここが唯一の特異点となることの証明は、分配関数の厳密解や無限体積極限の解析に立ち入るため :cite[baxter-exactly] を参照する。有限サイズの Binder 比や相関長比を検証する場合には、有限格子の交差をこの温度と一致するはずの厳密値に固定せず、補正項を含めて外挿する。




正方格子の強磁性 Ising 模型で磁場を零とし、熱力学極限に取ると、臨界指数の基準値は $\beta_{\rm m}=1/8$、$\nu=1$、$\eta=1/4$、$\gamma=7/4$ である。比熱はべき乗ではなく対数で発散する。これらの値の厳密導出には無限格子の分配関数と相関関数の解析が必要なので、:cite[baxter-exactly] と :cite[landau-binder] を参照する。有限格子の検算では、$T_c$ で $L$ を二倍にしたときの磁化の比が $2^{-1/8}$、磁化率の比が $2^{7/4}$、Binder 比の勾配の比が 2 に近づくかを別々に測る。比熱の臨界値を $C_L/(Nk_{\rm B})=A\log L+B+\cdots$ と置けば、サイズ間の差は $A\log2$ に近づく。比そのものは 1 に近づくので、対数成長を調べるには差の方が変化を追いやすい。

:::example[双対固定点で高温辺と低温壁の重みを比べる]
$e^{2K}=1+\sqrt2$ のとき $\tanh K=e^{-2K}=\sqrt2-1$ である。高温側で一 plaquette の四辺を選ぶ重みも、低温側で一サイトを囲む壁を作る重みも $(\sqrt2-1)^4=17-12\sqrt2$ になる。ここで比べたのは展開の個別項であり、有限格子でエネルギーの平均値が両側で一致するという意味ではない。分配関数の前因子には高温の $\cosh K$ や低温の全整列状態の重みが含まれるため、自由エネルギーを微分してエネルギーを求める場合は前因子の微分も残る。
:::

## 演習問題

::::exercise{level=basic}
無磁場の単点反転に伴うエネルギー差。$J=2$、$s=1$、$v=2$ に対する値を求めよ。

:::solution
結合を $J$、反転前のスピンを $s$、近傍スピン和を $v$ とする。各隣接項が符号を反転する。用いる式は次のとおりである。

$$
2 J s v
$$

代入して整理すると $8$ となる。
:::
::::

::::exercise{level=basic}
同方向スピン間の補助結合確率。$K=\frac{\log{\left(5 \right)}}{2}$ に対する値を求めよ。

:::solution
無次元結合を $K$ とし、反整列の重みとの比を閉結合確率にする。用いる式は次のとおりである。

$$
1 - e^{- 2 K}
$$

代入して整理すると $\frac{4}{5}$ となる。
:::
::::

::::exercise{level=basic}
エネルギー再重み付けの比。$b=\log{\left(3 \right)}$、$E=-1$ に対する値を求めよ。

:::solution
逆温度差を $b$、エネルギーを $E$ とする。両温度での非規格化確率の比を取る。用いる式は次のとおりである。

$$
e^{- E b}
$$

代入して整理すると $3$ となる。
:::
::::

::::exercise{level=basic}
レプリカ交換の受理率。$b=\log{\left(2 \right)}$、$d=-3$ に対する値を求めよ。

:::solution
逆温度差を $b$、交換前の同じ順でのエネルギー差を $d$ とし、比を 1 で切る。用いる式は次のとおりである。

$$
\min\left(1, e^{b d}\right)
$$

代入して整理すると $\frac{1}{8}$ となる。
:::
::::

::::exercise{level=basic}
モーメントから求める Binder 比。$a=3$、$b=18$ に対する値を求めよ。

:::solution
磁化の二次と四次モーメントを $a,b$ とする。磁化の尺度を消すため分母に二次モーメントの二乗を置く。用いる式は次のとおりである。

$$
1 - \frac{b}{3 a^{2}}
$$

代入して整理すると $\frac{1}{3}$ となる。
:::
::::

::::exercise{level=advanced}
二スピン一辺、磁場なしで $\langle s_1s_2\rangle$ を求め、補助結合から同じ値を導け。

:::solution
整列する二配置の重みは各 $e^K$、反整列の二配置は各 $e^{-K}$ なので相関は $(e^K-e^{-K})/(e^K+e^{-K})$ である。結合が開いていれば相関は 1、閉じていれば二符号が独立なので 0 である。開く確率は整列の確率 $e^K/(e^K+e^{-K})$ に $1-e^{-2K}$ を掛けた値であり、同じ相関を与える。
:::
::::

::::exercise{level=advanced}
レプリカ交換で、低温スロットに低エネルギー状態があるとき交換比が 1 以下になることを示せ。

:::solution
$a$ を低温とすると $\beta_a>\beta_b$、条件より $E_a\le E_b$ である。差の積 $(\beta_a-\beta_b)(E_a-E_b)$ は 0 以下だから交換比は 1 以下である。反対の配置から元へ戻す交換の比は逆数となるため、常に受理される。
:::
::::

::::exercise{level=advanced}
零磁場で全配置が二つの完全整列状態に集中する極限の Binder 比を求めよ。

:::solution
磁化は $\pm N$ で、偶数次のモーメントは $N^2,N^4$ である。定義式の比は $1/3$ なので、$U_L=2/3$ である。二対称状態の混合比は偶数次には影響しない。
:::
::::

::::exercise{level=advanced}
四サイト周期 Ising 鎖の零磁場で $t=e^{-2\beta J}$ とする。壁数の全列挙から磁化二乗の期待値を求め、$t=1/2$ の値を計算せよ。

:::solution
壁なしは全正と全負で $M^2=16$、壁四個は交互の二配置で $M^2=0$ である。壁二個は $\binom42=6$ 通りの壁の位置と全体の符号二通りである。隣り合う壁の選択は 4 通りで孤立スピンが一つとなり $M^2=4$、向かい合う壁は 2 通りで $M^2=0$ である。従って共通因子を消した分配関数は $2+12t^2+2t^4$、磁化二乗の分子は $32+32t^2$ である。$t=1/2$ では分母 $41/8$、分子 40 だから $\langle M^2\rangle=320/41$ となる。零磁場なので帯磁率一サイト当たりへは $\beta/4$ を掛ける。
:::
