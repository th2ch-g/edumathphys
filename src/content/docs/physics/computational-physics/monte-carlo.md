## この章の目標

- 擬似乱数の周期、系列間の独立性、検定の役割を理解する。
- 積分推定量の平均と分散を求め、標本の割当を設計する。
- 詳細つり合いから Metropolis–Hastings の受理式を導く。
- 相関する標本の平均の誤差をブロックで評価する。

## 擬似乱数の生成と検定

### 状態遷移と検定

:term[擬似乱数]{en="pseudorandom number" yomi="ぎじらんすう"} は初期状態と決定論的な遷移から作る数列である。例として $x_{n+1}=(ax_n+c)\bmod m$ を考える。$m$ 個の状態しかなく、一度状態が再現すればそれ以降も同じ順序になる。$m=8,a=5,c=1$ なら $0,1,6,7,4,5,2,3,0$ と巡回する。全周期では各出力が一様であっても、偶数と奇数が厳密に交替するので隣接値は独立でない。したがって周辺分布の検査と、連続値の組の検査を区別する。

一様性の検査では $K$ 個の等確率区間を作り、実測数 $n_i$ と期待数 $N/K$ から $\chi^2=\sum_i(n_i-N/K)^2/(N/K)$ を求める。独立一様という仮説のもとでカウントの共分散は $N(I/K-\vb1\vb1^\top/K^2)$ である。中心化して平方根で規格化すると、全カウント固定による一方向を除いて単位共分散になる。多変量中心極限定理により、大標本では $\chi^2_{K-1}$ が基準となる。多数の検定をすると偶然の棄却も増えるので、事前に検査数と判定水準を決める。検定を通過しても、すべての物理観測量で乱数の相関が無視できることが保証されたわけではない。独立実行には乱数器のストリーム分割を使い、乱数器の種類、初期化方法と実行ごとの鍵を保存する。

### 逆関数法と一様乱数の端点

連続で厳密に増加する累積分布 $F$ に対して $U\sim\operatorname{Uniform}(0,1)$ とし、$X=F^{-1}(U)$ と取る。単調性から $\Pr(X\le x)=\Pr(U\le F(x))=F(x)$ である。指数分布 $F(x)=1-e^{-\lambda x}$、$x\ge0$ では $X=-\log(1-U)/\lambda$ である。乱数器が閉区間の端点を返す規約なら、$U=1$ で無限大になるため扱いを決める。$U$ が小さいときは $1-U$ の丸めを避け、$\log(1-U)$ 専用の算術を使う。一般の累積分布では $F^{-1}(u)=\inf\{x:F(x)\ge u\}$ と定める。右連続性により $F^{-1}(u)\le x$ と $u\le F(x)$ が同値なので、同じ確率計算で離散分布も得られる。

二つの独立な一様変数から標準正規対を作るには $R=\sqrt{-2\log U_1}$、$\theta=2\pi U_2$、$(X,Y)=(R\cos\theta,R\sin\theta)$ とする。極座標の面積要素が $r\dd r\dd\theta$ であり、$R$ の分布密度は $re^{-r^2/2}$ なので直交座標の同時密度は $(2\pi)^{-1}e^{-(x^2+y^2)/2}$ である。積に分離することから各成分は独立な標準正規と分かる。

### 二進一様乱数から整数を偏りなく生成する

$0,\ldots,M-1$ のいずれかを等確率で返す乱数があるとする。各回で独立に値を引く。$M=qm+r$、$0\le r<m$ のとき、単に $m$ で割った余りを使うと最初の $r$ 個は $q+1$ 回ずつ、残りは $q$ 回ずつ現れる。従って $r>0$ なら一様ではない。$q\ge1$ として $qm$ 以上の元を棄却すると、受理集合の各剰余はちょうど $q$ 回であり、受理した値は一様になる。一回の受理率は $qm/M$、必要な発生回数の期待値は幾何級数から $M/(qm)$ である。

:::example[八状態から六面体を作る]
$M=8,m=6$ のとき、余りだけでは 0 と 1 の確率が $1/4$、2 から 5 が $1/8$ となる。6 と 7 を棄却すれば一回の受理率は $3/4$ で、例えば最終的に 0 となる確率は $(1/8)\sum_{j\ge0}(1/4)^j=1/6$ である。六方向の格子歩行で $0,1$ を同じ軸の正負に割り当てると、偏った方法では平均移動は零に見えてもその軸の分散が他軸の二倍になる。
:::

### 一次元検定と連続する標本の検定

各標本が一様に見えても、隣接標本が独立とは限らない。$X_{n+1}=X_n+1\bmod 8$ を一様な初期状態から始めると、各 $X_n$ は一様であり、周期全体の頻度も等しい。それでも $(X_n,X_{n+1})$ は 64 通り中 8 通りにしか入らない。隣接対の散布図や遷移度数を検査するとこの違いが現れる。重なる対を全て使うと、その度数の誤差を独立な多項分布として扱うことはできない。既知の独立一様乱数を比較対象とする場合は、例えば対を $(X_0,X_1),(X_2,X_3),\ldots$ と非重複に組めば独立性の仮定を満たす。多数の検定を行えば良い生成器でも偶然小さい $p$ 値が出るため、単独の閾値判定よりどの相関が計算対象に伝わるかを調べる。



### 二の冪を法とする合同法の周期を求める

状態 $x_{n+1}=a x_n+c\bmod 2^m$ で、$c$ は奇数、$a\equiv1\bmod4$ とする。整数上の写像を $T(x)=ax+c$ と置く。$T^{2^j}(x)=a^{2^j}x+c\sum_{\ell=0}^{2^j-1}a^\ell$ であり、和を $S_j$ と書くと $S_0=1$、$S_{j+1}=(1+a^{2^j})S_j$ である。$a^{2^j}\equiv1\bmod4$ なので各因子は 2 で割れるが 4 で割れない。従って $S_j$ は $2^j$ で割れるが $2^{j+1}$ で割れない。さらに $T^{2^j}(x)-x=[(a-1)x+c]S_j$ で、括弧は奇数である。従って $2^m$ 回では全ての状態が戻り、$2^j$ 回では $j<m$ なら戻らない。周期は $2^m$ の約数なので、これで周期がちょうど $2^m$ と分かる。ただし各下位 $k$ ビットに同じ議論を適用すると周期は $2^k$ に過ぎない。最下位ビットは毎回反転するので、周期全体で正負が半々でも連続する二値の抽出には使えない。

:::example[四ビットの周期と二歩の写像]
$a=5,c=1,m=4$ で $x_0=0$ から始めると、最初の四状態は $0,1,6,15$ である。二歩の合成は $T^2(x)=25x+6\equiv9x+6\bmod16$、四歩は $T^4(x)\equiv x+12\bmod16$ である。最後の式を四回適用すれば $x+48\equiv x$ となるが、一回、二回ではそれぞれ 12、8 ずれる。二の冪で間引くと一系列の周期は短くなる。例えば四歩ごとの系列では上位二ビットだけが変わり、下位二ビットは同じ値に固定される。
:::

### 並列な部分列を再現可能にする

合同法で $k$ 回後の状態を直接得るには、アフィン変換を組 $(a,c)$ として扱う。組の合成は $(a_2,c_2)\circ(a_1,c_1)=(a_2a_1,a_2c_1+c_2)$ を法で縮約したものである。従って二乗を繰り返して $k$ の二進表現の各ビットに合成を割り当てると $O(\log k)$ 回で移動できる。この方法では $(a-1)$ の法における逆元を要しない。例えば $a=5,m=4$ では $a-1=4$ は逆元を持たないため、幾何和 $(a^k-1)/(a-1)$ の分子を先に法で縮約すると正しい商を求められない。

一系列の長さを $L$ と決め、並列タスク $j$ に状態 $T^{jL}x_0$ からの $L$ 個を割り当てる場合、総消費数が周期を超えなければ状態区間は重複しない。棄却法では一標本当たりの乱数消費数が変わるので、ブロック長は標本数でなく生成器の状態数で数える。棄却が多くブロックを横切りうる場合は、独立ストリームを設計した生成器や、タスク番号と添字を明示してハッシュするカウンタ方式を使う。ストリームが重ならないことは統計的な独立性の証明ではないため、異なる系列間の相関も積分の検査に含める。

### Box–Muller 変換の Jacobian

独立な $U,V$ が $(0,1)$ に一様のとき $R=\sqrt{-2\log U}$、$\Theta=2\pi V$ とする。$r\ge0$ で $\Pr(R>r)=\Pr(U<e^{-r^2/2})=e^{-r^2/2}$ なので $R$ の密度は $r e^{-r^2/2}$ であり、$\Theta$ は独立に一様である。平面の直交座標 $(X,Y)=(R\cos\Theta,R\sin\Theta)$ の面積要素が $r\dd r\dd\theta$ であるため、二変量密度は $(2\pi)^{-1}e^{-(X^2+Y^2)/2}$ となる。これは標準正規の積である。極座標の $R$ は正規でなく、指数乱数の平方根である。$U=0$ を許す実装ではその場合に引き直し、$\log0$ を計算しない。

:::example[二変量の範囲を解析値と比べる]
$R>2$ となる頻度を測ると確率は $e^{-2}\simeq0.1353$ である。独立な 10000 対なら超過数の期待値は約 1353、標準偏差は $\sqrt{10000e^{-2}(1-e^{-2})}\simeq34.2$ である。$X>2$ と $Y>2$ が同時に起きる事象は $R>2$ の一部でしかない。角度の実装を検査するには、例えば第一象限に入る確率を $1/4$ と別に比べ、半径と象限を同時に条件づけても確率が積になるか調べる。
:::

## モンテカルロ積分と分散低減

### 平均と分散

体積 $V$ の領域 $D$ から一様独立に $X_i$ を取り、$I=\int_D f(x)\dd x$ とする。$\widehat I=V\sum_i f(X_i)/N$ は期待値 $I$ をもち、独立性により分散は $V^2\operatorname{Var}(f(X))/N$ である。二乗可積分なら標準誤差は $N^{-1/2}$ に比例する。次元は指数に陽には入らないが、分散や一標本の評価費用は次元とともに増えうる。

### 制御変量と層化

平均 $\mu_g$ が既知の $g$ について、$f-c(g-\mu_g)$ は元と同じ平均をもつ。分散は $\operatorname{Var}f-2c\operatorname{Cov}(f,g)+c^2\operatorname{Var}g$ であり、$\operatorname{Var}g>0$ なら $c=\operatorname{Cov}(f,g)/\operatorname{Var}g$ で最小となる。同じデータから係数を推定すると有限標本では補正項の平均が零とは限らない。独立な試行で係数を調整して固定できる。

層 $j$ の確率を $w_j$、条件付き標準偏差を $\sigma_j$ とし、各層から独立に $n_j$ 個を取る。層平均の重み付き和の分散は $\sum_j w_j^2\sigma_j^2/n_j$ である。Cauchy–Schwarz 不等式から $\bigl(\sum_jw_j\sigma_j\bigr)^2\le(\sum_jn_j)(\sum_jw_j^2\sigma_j^2/n_j)$ であり、連続変数としての最適割当は $n_j\propto w_j\sigma_j$ である。整数への丸め後も正の重みをもつ層に必要な標本を与える。反対称変量では $U,1-U$ のような対を平均し、共分散が負なら同じ評価数で分散を減らす。

### 反対称な対が効く条件

単調増加な $f$ と一様な $U$ に対し、$f(U)$ と $f(1-U)$ は負相関または無相関である。独立な $V$ を使うと $2\operatorname{Cov}(g(U),h(U))=\mathbb E[(g(U)-g(V))(h(U)-h(V))]$ であり、$g=f$ は増加、$h(u)=f(1-u)$ は減少だから積は 0 以下である。例えば $f(u)=u$ なら対の平均は常に $1/2$ となり、分散は 0 である。$f(u)=u^2$ の対平均は $u^2-u+1/2$、平均は $1/3$、分散は $\int_0^1(u^2-u+1/2)^2\dd u-1/9=1/180$ である。二つの独立標本の平均なら分散は $2/45$ なので、この例で同じ評価数に対する分散は八分の一である。

### 計算実習：同じ評価数で分散を比較する

$[0,1]$ の $x^2$ の積分を、一様独立、反対称な対、重点分布 $q(x)=2x$ で計算する。ここでは評価一回あたりの時間が同じとみなし、一試行で二回の評価を行う。各方法の平均と試行単位の分散を比較する。実際の分子模型では、一評価の費用や標本生成の費用も加える必要がある。

~~~python
from math import sqrt
from random import Random
from statistics import mean, variance

def integrate_toy(trials, seed):
    random = Random(seed)
    ordinary, paired, weighted = [], [], []
    for _ in range(trials):
        first, second = random.random(), random.random()
        ordinary.append((first**2 + second**2) / 2)
        u = random.random()
        paired.append((u**2 + (1 - u)**2) / 2)
        x, y = sqrt(random.random()), sqrt(random.random())
        weighted.append((x + y) / 4)
    return [(mean(values), variance(values)) for values in (ordinary, paired, weighted)]

results = integrate_toy(20000, 532)
for (location, spread), exact in zip(results, (2/45, 1/180, 1/144)):
    print(location, spread, exact)
    assert abs(location - 1/3) < 0.01
    assert abs(spread - exact) < 0.1 * exact
~~~

重点密度の累積分布は $x^2$ なので、その逆は平方根である。各重点標本の値は $x/2$ で、独立な二標本の平均の分散は $1/144$ である。反対称な対は同じ一様乱数から作るため、二つの値を独立な試行として分散を計算してはいけない。別の種で実験を繰り返すと、標本分散の揺れと平均の標準誤差の違いも確認できる。

### 分散が存在しない積分

$[0,1]$ 上の $f(x)=x^{-\alpha}$、$0<\alpha<1$ の積分は $1/(1-\alpha)$ である。一様標本の二乗積分は $\int_0^1x^{-2\alpha}\dd x$ なので、$\alpha\ge1/2$ では発散する。積分は有限でも通常の標準誤差や中心極限定理を使えない。変数を $x=u^{1/(1-\alpha)}$ とすると $f(x)\dd x=\dd u/(1-\alpha)$ で、被積分値を一定にできる。この変数変換は特異性を解析的に取り除く例である。一般の問題では特異点付近でどういうべきが出るか先に調べ、分散が有限になる密度か層を選ぶ。有限標本の最大値がまだ小さいことから、尾部が無視できるとは結論できない。

$$

ここに上の値を代入して整理すると $\frac{1}{5}$ を得る。

### 層へ評価回数を配分する

領域を確率 $w_j$ の層へ分け、層内の独立評価の分散を $\sigma_j^2$、評価回数を $n_j$ とする。全平均の推定量 $\sum_j w_j\bar f_j$ の分散は独立性から $\sum_j w_j^2\sigma_j^2/n_j$ である。全評価回数 $\sum_jn_j=N$ の下で Cauchy–Schwarz を使うと

$$
(\sum_j w_j\sigma_j)^2
\le \left(\sum_j\frac{w_j^2\sigma_j^2}{n_j}\right)\left(\sum_j n_j\right).
$$

等号は $n_j\propto w_j\sigma_j$ のときである。この割当を :term[Neyman 配分]{en="Neyman allocation" yomi="ねいまんはいぶん"} と呼ぶ。層ごとの評価コストが $c_j>0$ なら、右の第二因子を $\sum_j c_j n_j$ に取り直し、第一因子の分子に入る係数の積を $w_j\sigma_j\sqrt{c_j}$ として同じ議論を行う。等号条件は $n_j\propto w_j\sigma_j/\sqrt{c_j}$ になる。

:::example[半分ずつの層で評価数を変える]
$w_1=w_2=1/2$、$\sigma_1=1,\sigma_2=3$、$N=40$ とする。等分なら分散は $(1+9)/(4\cdot20)=1/8$ である。Neyman 配分では $(n_1,n_2)=(10,30)$ なので分散は $1/40+9/120=1/10$ となる。ただし実際には $\sigma_j$ 自体が未知の場合が多い。予備標本で配分を選び、独立な本標本の各層平均を使えば、配分で条件づけても各平均の期待値が変わらないため不偏性が保たれる。予備標本が偶然全て同じ値でも、その層を消さないよう最小評価数を与える。
:::



### 複数の制御変量を射影として扱う

$\mu=\mathbb E f$ を求めるため、平均が既知のベクトル $g$ の中心化版 $G=g-\mathbb E g$ を使う。$\Sigma=\mathbb E GG^\top$、$c=\mathbb E[G(f-\mu)]$ と置けば、分散は $\operatorname{Var}(f-b^\top G)=\operatorname{Var}(f)-2b^\top c+b^\top\Sigma b$ である。$\Sigma>0$ なら平方完成から $b_*=\Sigma^{-1}c$ が最小化し、分散の減少は $c^\top\Sigma^{-1}c$ である。残差と $G$ は無相関なので、この選択は平均を引いた $f$ を制御変量の張る部分空間へ最小二乗で射影したものである。$\Sigma$ に零方向があれば対応する線形結合はほとんど確実に零であり、独立な方向だけ残して同じ議論を行う。

:::example[三次の被積分関数を二つの既知モーメントで補正する]
$U$ を $[-1,1]$ の一様とし $f=U^3+U^2$、$g=(U,U^2)$ とする。奇偶性から $\Sigma=\diag(1/3,4/45)$、$c=(1/5,4/45)$ である。最適係数は $b_*=(3/5,1)$ で、残差は $U^3-3U/5+1/3$ になる。この平均は $1/3$ のまま、分散は $1/7-(1/5)^2/(1/3)=4/175$ である。元の分散は $1/7+4/45=73/315$ だから約一桁減る。ただし既知とみなした $g$ の平均を同じ標本から求めて中心化すると、標本平均の補正項が恒等的に零になる。係数の推定には独立な予備標本を使えば、本標本で係数を固定した条件下の不偏性が残る。
:::

### 条件付き平均で乱数の次元を減らす

$f(X,Y)$ を評価する代わりに、$X$ に対する $m(X)=\mathbb E[f(X,Y)|X]$ が計算できれば $m(X)$ の平均を取る。全期待値から平均は同じで、全分散の分解 $\operatorname{Var}(f)=\mathbb E[\operatorname{Var}(f|X)]+\operatorname{Var}(m(X))$ によって分散も増えない。これは :term[Rao–Blackwell 化]{en="Rao–Blackwellization" yomi="らおぶらっくうぇるか"} である。コストの比較では、条件付き積分を正確に計算する費用も含める。

:::example[四分円を指示関数と積分で比較する]
$X,Y$ を独立に $[0,1]$ から引き、$f=\mathbf1_{X^2+Y^2\le1}$ とすると平均は $\pi/4$、分散は $\pi/4-(\pi/4)^2$ である。$m(X)=\sqrt{1-X^2}$ なら二乗平均は $\int_0^1(1-x^2)\dd x=2/3$、分散は $2/3-(\pi/4)^2$ である。差は $\pi/4-2/3>0$ である。両方式とも平均を四倍すれば円周率の推定量になるが、分散も 16 倍にして比較する。
:::

## 重点サンプリング

### 被積分関数を割る密度

$\int f(x)\dd x$ で $f\ne0$ の領域に正の密度 $q$ を選ぶ。$X\sim q$ に対して $f(X)/q(X)$ の平均が積分である。これが :term[重点サンプリング]{en="importance sampling" yomi="じゅうてんさんぷりんぐ"} である。二次モーメントは $\int f^2/q$ なので、$q$ が小さすぎる尾部は分散を増やす。Cauchy–Schwarz により $(\int |f|)^2\le\int f^2/q$、等号には $q\propto|f|$ が必要である。$f$ が非負ならこの理想密度で比は定数になるが、規格化自体に求めたい積分が必要である。

$p=\widetilde p/Z$ の $Z$ が未知で、$q$ が $p$ の支持を覆うなら、$\sum w_i A_i/\sum w_i$、$w_i=\widetilde p(X_i)/q(X_i)$ を使う。分子と分母の大数の法則と $Z>0$ から一致性が従う。有限標本の比は一般に不偏ではない。$N_{\rm eff}=(\sum w_i)^2/\sum w_i^2$ は重みの集中の目安であり、観測量や時系列相関による分散は別に求める。極端な尾部を一度も引いていない場合には、この目安が大きくても安心できない。

### 受理棄却法と重みの違い

規格化前密度 $h$ が既知で、$h(x)\le Mq(x)$ が全域で成り立つとする。$X\sim q$ と一様な $U$ を独立に引き、$U\le h(X)/(Mq(X))$ のとき $X$ を採用する。採用事象と点の同時密度は $h(x)/M$ なので、採用条件付きで $h/\int h$ が得られる。採用率は $\int h/M$ である。採用した点は独立だが、$M$ が過大だと候補を浪費する。一方の重点サンプリングはすべての点を重み付きで使い、この上界は要らない。例えば $h(x)=x$、$q(x)=1$ を $[0,1]$ 上で使うと $M=1$ で受理率は $1/2$、採用点の密度は $2x$ である。

### 比の推定量の先頭分散

規格化重み $w$ を $X\sim q$ から引き、目標を $\mu=\mathbb E_q(wA)/\mathbb E_qw$ とする。推定値の差は厳密に

$$
\widehat\mu-\mu=\frac{\overline{w(A-\mu)}}{\overline w}.
$$

有限な $Z>0$ に分母が収束し、分子の中心化変数が有限分散なら、中心極限定理と Slutsky の定理を適用できる。独立標本に対し $\sqrt N(\widehat\mu-\mu)$ の極限分布は平均零、分散 $\mathbb E_q[w^2(A-\mu)^2]/Z^2$ の正規分布となる。分母が零の標本では推定値を定義できない。$A$ が定数なら重みがいくら偏ってもこの分散は 0 である。$A$ の大きいところと $w$ の大きいところが重なると分散は増える。このため重みだけの $N_{\rm eff}$ は候補密度の比較に使えても、各観測量の標準誤差をその値だけで求めることはできない。

### 数値例

:::example[重点標本の重み付き被積分値]
$f=\frac{1}{2}$、$q=\frac{1}{4}$ とする。その点の被積分値 $f$ を標本密度 $q$ で割る。したがって、求める量は次の式で与えられる。

$$
\frac{f}{q}
$$

ここに上の値を代入して整理すると $2$ を得る。
:::

:::example[重点標本の重み付き被積分値]
$f=\frac{1}{8}$、$q=\frac{1}{2}$ とする。その点の被積分値 $f$ を標本密度 $q$ で割る。したがって、求める量は次の式で与えられる。

$$
\frac{f}{q}
$$

ここに上の値を代入して整理すると $\frac{1}{4}$ を得る。
:::

### 重点分布の混合で大きな重みを抑える

正規化済みの密度 $p$ の期待値を求めたいとする。一つの提案 $q_0$ は典型的な寄与に集中するが、裾で $p/q_0$ が大きいと分散が増える。そのとき $q=(1-\delta)q_0+\delta p$、$0<\delta<1$ を使えば $p/q\le1/\delta$ となる。混合のどちらから点を引いた場合でも分母は全体の $q$ である。実際、$\mathbb E_q[(fp/q)^2]=\int f^2 p(p/q)\le \delta^{-1}\int f^2p$ なので、もとの期待値に有限な二次モーメントがあれば混合による推定量にも有限な分散がある。$p$ 自身から引けない場合でも、$p/q_1$ に上限が分かる別の密度 $q_1$ を加えれば同じ評価ができる。

:::example[小さい確率を二点模型で推定する]
$p(1)=1/100$、$p(0)=99/100$、$f(x)=x$ とする。直接法の一標本分散は $99/10000$ である。$q(1)=1/2$ を使うと $fp/q$ は $1/50$ または 0 を等確率に取るので、平均は $1/100$、分散は $1/10000$ となる。$q(1)$ を 1 にすればこの特定の積分は定数となる。ただし同じ点を使って $1-x$ を測るときは、$x=0$ の支持を失うため推定できない。複数の観測量を測る場合の支持条件はそれぞれの被積分関数について確認する。
:::



### 符号付き積分の理想分布と残る分散

符号付き $f$ の Lebesgue 積分 $I=\int f(x)\dd x$ に対し、$q>0$ が $f\ne0$ の範囲を覆うとする。二次モーメントは $\int f^2/q$ であり、Cauchy–Schwarz から $(\int |f|)^2\le(\int f^2/q)(\int q)$ である。従って $q_*=|f|/\int |f|$ が最小にする。出力は $\sgn(f)\int |f|$ の二値であるため、$f$ が両符号を持てば理想分布でも分散は $(\int |f|)^2-I^2>0$ である。正負の大きな寄与の差が小さい場合、相対分散は $\left(\int|f|/I\right)^2-1$ となって大きい。両符号を別々に正確に積分する、対称性で点ごとに打ち消す、既知の制御変量を引くといった方法は、単に正の密度を探す方法と異なる。

:::example[ほぼ奇関数の積分を対で取る]
$[-1,1]$ 上の $f(x)=x+\epsilon$、$0<\epsilon<1$ なら $I=2\epsilon$、$\int |f|=1+\epsilon^2$ である。例えば $\epsilon=1/10$ の理想重点標本の分散は $(101/100)^2-(1/5)^2=9801/10000$ であり、相対分散は $9801/400$ である。ところが $x$ と $-x$ を同じ標本で評価すれば $f(x)+f(-x)=2\epsilon$ となり分散は零である。計算の支配誤差が符号の相殺にあるなら、相殺を同じ評価内へ移す効果が大きい。
:::

### 多峰の重点重みを対数で計算する

重み $w_j=e^{\ell_j}$ の正規化では、$\max\ell_j=m$ を引いて $\widetilde w_j=e^{\ell_j-m}$ とする。比 $\sum wf/\sum w$ は共通因子が消えて同じになる。規格化定数の対数を求める場合は $\log\sum_j e^{\ell_j}=m+\log\sum_j\widetilde w_j$ であり、$m$ を最後に戻す。重みの偏りを測る量 $N_w=(\sum_jw_j)^2/\sum_jw_j^2$ は、Cauchy–Schwarz で標本数以下で、非負項の展開から 1 以上である。等重みなら実標本数に等しく、一点が支配すれば 1 に近い。これは観測した重みの集中度であり、まだ一度も引けていない重要領域を検出できない。

:::example[一つの重要領域を見落とした場合]
$p$ は二状態を等確率、$q(1)=10^{-4}$ とする。100 回の独立試行で一度も 1 を引かない確率は $(1-10^{-4})^{100}\simeq0.9900$ である。その場合は全重みが同じなので $N_w=100$ だが、$f=\mathbf1_{x=1}$ の重点推定値は 0 で、真値 $1/2$ から離れる。$q$ の設計では一回だけの重み診断に頼らず、事前に両領域へ十分な確率があるかを確かめる。
:::

## Markov 連鎖と詳細つり合い

### 不変分布と可逆性

[Markov 連鎖](/math/probability/markov-chains/) の有限状態の遷移を $P_{ij}$ とする。分布 $\pi$ が $\pi_iP_{ij}=\pi_jP_{ji}$ を満たす条件を :term[詳細つり合い]{en="detailed balance" yomi="しょうさいつりあい"} という。左辺を $i$ について足すと右辺は $\pi_j\sum_iP_{ji}=\pi_j$ となり、不変性が従う。逆は成り立たない。三状態を順に巡回する遷移は一様分布を保存するが、逆方向の確率は 0 である。

不変性だけでは初期分布からの収束は従わない。例えば二状態が常に交替すると $\pi=(1/2,1/2)$ は不変だが各時刻の分布は交替する。有限既約連鎖に自己遷移を加えて周期を 1 にできる。観測量の時系列平均と個々の時刻の分布収束を区別する。連続空間では正の密度を持つ集合に到達できるかを調べる。幾何的に分断された支持の間を提案が移れない場合、受理式が正しくても標本は初期領域に留まる。

### 可逆有限連鎖を対称行列として見る

全成分が正の不変分布 $\pi$ に対し $D=\diag(\pi_i)$ とする。詳細つり合いは $DP=P^\top D$ であるから、$B=D^{1/2}PD^{-1/2}$ は実対称である。従って $P$ の固有値は実である。また各行が凸結合を作るので $\norm{Pv}_\infty\le\norm v_\infty$、固有値の絶対値は 1 以下である。既約なら $Pv=v$ の実ベクトルの最大成分において近傍も同じ値となり、全状態がたどれるため定数である。さらにすべての対角が正なら、$Pv=-v$ の最大絶対値成分を取ったとき、正の自己遷移があるため右辺を反対符号の最大絶対値にできない。よって他の固有値は絶対値 1 未満である。直交固有空間で分解すると $P^n$ は定数空間への射影に収束する。

### 数値例

:::example[二状態連鎖で状態 1 の定常確率]
$u=\frac{1}{2}$、$v=\frac{1}{4}$ とする。状態 0 からの離脱確率 $u$ と状態 1 からの離脱確率 $v$ の流量を等置する。したがって、求める量は次の式で与えられる。

$$
\frac{u}{u + v}
$$

ここに上の値を代入して整理すると $\frac{2}{3}$ を得る。
:::

:::example[二状態連鎖で状態 1 の定常確率]
$u=\frac{1}{4}$、$v=\frac{1}{2}$ とする。状態 0 からの離脱確率 $u$ と状態 1 からの離脱確率 $v$ の流量を等置する。したがって、求める量は次の式で与えられる。

$$
\frac{u}{u + v}
$$

ここに上の値を代入して整理すると $\frac{1}{3}$ を得る。
:::

### 非可逆な定常連鎖を比較する

三状態で $P(i,i)=1/2$、$P(i,i+1\bmod3)=1/2$ とする。列和が全て 1 だから一様分布は定常だが、辺 $i\to i+1$ の逆向き確率が 0 なので詳細つり合いは成立しない。状態の Fourier モード $f_k(j)=e^{2\pi i k j/3}$ に作用させれば $P f_k=\tfrac12(1+e^{2\pi i k/3}) f_k$ である。非定数モードの固有値は $(1\pm i\sqrt3)/4$、絶対値は $1/2$ なので偏差は減衰しながら位相を回す。自己遷移を除いて毎歩必ず次へ動かすと定常分布は同じでも周辺分布は初期点に依存して巡回する。定常性は初期分布を選んだときに分布が変化しない性質であり、任意の初期分布からの収束には別の条件が要る。

### 遷移核の混合と一巡の更新

$P_1,P_2$ が同じ $\pi$ を保つなら、$\pi P_1P_2=(\pi P_1)P_2=\pi$ であり、一巡も $\pi$ を保つ。各核が詳細つり合いを満たしても、積が詳細つり合いを満たすとは限らない。三状態で $P_1$ が 0 と 1 を交換し、$P_2$ が 1 と 2 を交換すると、各交換は一様分布に対して可逆だが、積は三周期の巡回である。一方、固定確率 $\lambda$ の混合 $\lambda P_1+(1-\lambda)P_2$ では、各核のつり合いの等式を足して可逆性が残る。状態を見て混合確率を変える場合はその係数も遷移確率に含めて検証する。



### 有限連鎖の収束を一様な下界から示す

有限集合 $\mathcal X$、行確率行列 $P$ に対し、ある $m$ で $P^m$ の全成分が正とする。一様分布 $\nu$、$\varepsilon=|\mathcal X|\min_{xy}(P^m)_{xy}$ を用いて $P^m(x,\cdot)=\varepsilon\nu+(1-\varepsilon)Q(x,\cdot)$ と分解できる。$\varepsilon=1$ なら一かたまりで一様へ移る。$0<\varepsilon<1$ では $Q$ も行確率行列である。二分布 $\mu,\eta$ の全変動距離を $\|\mu-\eta\|_{\rm TV}=\tfrac12\sum_x|\mu_x-\eta_x|$ と定義する。共通の $\nu$ が消え、確率行列が $\ell^1$ ノルムを増やさないので

$$
\|\mu P^m-\eta P^m\|_{\rm TV}\le (1-\varepsilon)\|\mu-\eta\|_{\rm TV}.
$$

後者の性質は $\sum_y|\sum_x v_x Q_{xy}|\le\sum_x|v_x|\sum_y Q_{xy}=\sum_x|v_x|$ による。不変分布があれば、これで任意の初期分布からの幾何収束と不変分布の一意性が分かる。存在も得られる。列 $\mu(P^m)^k$ は隣接差が幾何的に減る Cauchy 列であり、極限は $P^m$ の不変分布 $\pi$ である。$\pi P$ も $P^m$ の不変分布なので一意性から $\pi P=\pi$ となる。有限の既約連鎖で全状態に正の自己遷移があれば、どの状態間にも長さが有限の正確率の経路があり、自己遷移で余分な歩数を埋めて共通の $m$ を得られる。

:::example[二状態連鎖で上界と真の収束を比較する]
$P=\begin{pmatrix}3/4&1/4\\1/2&1/2\end{pmatrix}$ とする。最小成分は $1/4$ なので $m=1,\varepsilon=1/2$ が使える。定常分布は $(2/3,1/3)$ である。二分布の差は $(a,-a)$ と書け、これに $P$ を掛けると $(a/4,-a/4)$ となる。真の収束倍率は $1/4$ で、最小成分だけを使った上界 $1/2$ より小さい。$\nu$ として各列の最小値に比例する分布を取れば $\varepsilon=1/2+1/4=3/4$ が得られ、この例では鋭くなる。
:::

### 平均零の観測に対する Poisson 方程式

$\pi f=0$ の有限状態観測量を考える。上の幾何収束から各 $x$ で $|P^k f(x)|\le2\|f\|_\infty(1-\varepsilon)^{\lfloor k/m\rfloor}$ である。従って $g=\sum_{k\ge0}P^k f$ は収束し、$(I-P)g=f$ を満たす。定数の自由度を除くため $\pi g=0$ と置く。列 $X_0,\ldots,X_N$ の和は

$$
\sum_{i=0}^{N-1} f(X_i)=g(X_0)-g(X_N)
+\sum_{i=0}^{N-1}[g(X_{i+1})-Pg(X_i)] .
$$

各括弧の条件付き平均は零なので、異なる時刻の括弧は無相関である。定常性の下、一括弧の分散は $\pi g^2-\pi(Pg)^2$ となる。端点の差は有界で、和との交差共分散は Cauchy–Schwarz で $O(\sqrt N)$ だから、元の和の分散を $N$ で割った極限は同じである。実際に $f=g-Pg$ を使うと $\pi g^2-\pi(Pg)^2=2\pi(fg)-\pi f^2$ であり、$g$ の定義を代入すれば自己相関の和と一致する。小状態の遷移行列を作れる場合、長い時系列から多数の遅れを推定せず、方程式を直接解いて分散を照合できる。

:::example[二状態の平均分散を線形方程式で求める]
前の $P$ に対し $f(0)=-1/3,f(1)=2/3$ とする。$Pf=f/4$ なので $g=(4/3)f$ であり、$\pi f^2=(2/3)(1/9)+(1/3)(4/9)=2/9$ である。従って漸近分散は $(8/3-1)(2/9)=10/27$ である。標本を独立と誤認すれば $2/9$ を使い、標準誤差は $\sqrt{5/3}$ 倍だけ過小になる。初期を状態 1 に固定しても $g(X_0)$ の有界な端点項で平均の偏りは抑えられるが、有限の短い系列ではこの差も残る。
:::



空間離散化の格子点を状態とする場合は、到達不能な境界点を不変分布の支持に含めず、支持上で既約性を確認する。境界で提案を棄却する操作は自己遷移を増やす一方、支持内の順逆の遷移比は保つ。

## Metropolis 法

### 提案と受理の積

現在点 $x$ から $q(y\mid x)$ に従って候補 $y$ を引く。目標密度を $p$ とすると

$$
a(x,y)=\min\left(1,\frac{p(y)q(x\mid y)}{p(x)q(y\mid x)}\right)
\label{eq-comp-mh-accept}
$$

で受け入れる。正の流入項が定義される場合、$p(x)q(y\mid x)a(x,y)$ は二方向の提案流量の最小値であり対称である。拒否すれば $x$ に残り、対角の確率も詳細つり合いを満たす。正規化定数は消える。対称な提案なら比は $p(y)/p(x)$ となり、$p\propto e^{-\beta E}$ なら $\min(1,e^{-\beta\Delta E})$ である。逆提案の確率が零なら移動を受理しない。

実装では $U\sim(0,1)$ に対して $\log U<\min(0,\log R)$ を使えば指数のオーバーフローを避けられる。拒否の状態も観測に含める。状態が変化したときだけ記録する列には、元の目標密度に一歩の離脱確率を掛けた密度が不変である。対角を除いた遷移核を離脱確率で割ると、離脱条件付きの核を得る。この核が運ぶ流量では離脱確率が約分され、元の詳細つり合いが残る。同じ状態を提案して受理する離散系で、受理イベントをすべて記録する場合には、離脱確率の代わりに自己提案を含む受理率が掛かる。受理率は目的量ではない。刻みが短すぎる提案は受理されても移動距離が小さいので、自己相関と一有効標本あたりの時間で調整する。

### 非対称な提案で密度比だけを使えない例

状態 0,1 の目標を一様とし、候補を 0 から 1 へ確率 $3/4$、1 から 0 へ確率 $1/4$ で出す。それ以外は現在状態を候補とする。密度比だけなら両方を受理し、実際の不変分布は状態 1 に $3/4$ を与える。一様を保つ受理確率は 0 から 1 で $1/3$、逆で 1 である。従って実際の移動は両方向 $1/4$ となる。これに対し Gibbs 更新は、他の変数を固定して一成分の正確な条件付き分布から引く。現在値と候補を交換した同時密度は条件付き確率の積なので可逆であり、局所受理判定は不要である。

### 勾配を利用する非対称な更新

密度 $p>0$ が滑らかな場合、$y=x+\delta\nabla\log p(x)/2+\sqrt{\delta}\,Z$、$Z$ を標準正規として候補を生成できる。これは標的密度の高い方向へ平均を動かす Langevin 型の提案である。正規分布の対数を :eqref[eq-comp-mh-accept] に代入すると、$g=\nabla\log p$ として対数受理比は

$$
\log p(y)-\log p(x)
-\frac{|x-y-\delta g(y)/2|^2-|y-x-\delta g(x)/2|^2}{2\delta}
$$

となる。後二項が提案の向きの差を補正する。$p$ が標準正規の一変数なら $g(x)=-x$、候補の平均は $(1-\delta/2)x$ である。受理補正なしの反復では $|1-\delta/2|<1$、すなわち $0<\delta<4$ のとき定常分散が $1/(1-\delta/4)$ になり、有限 $\delta$ で 1 からずれる。これは分散漸化式を解けば得る。補正した場合も、移動距離と相関は $\delta$ に依存する。

### 数値例

:::example[対称提案の Metropolis 受理率]
$r=\frac{3}{10}$ とする。候補と現在の目標密度の比 $r$ を 1 で上から切る。したがって、求める量は次の式で与えられる。

$$
\min\left(1, r\right)
$$

ここに上の値を代入して整理すると $\frac{3}{10}$ を得る。
:::

:::example[対称提案の Metropolis 受理率]
$r=2$ とする。候補と現在の目標密度の比 $r$ を 1 で上から切る。したがって、求める量は次の式で与えられる。

$$
\min\left(1, r\right)
$$

ここに上の値を代入して整理すると $1$ を得る。
:::

### 条件付き分布からの更新と過剰緩和

状態を $(x,y)$ に分け、$x$ を固定して $y'$ を $\pi(y'|x)$ から引く。順方向の流量は $\pi(x)\pi(y|x)\pi(y'|x)$ であり、$y,y'$ を交換しても不変なので詳細つり合いを満たす。これは :term[Gibbs サンプリング]{en="Gibbs sampling" yomi="ぎぶすさんぷりんぐ"} の一座標更新であり、提案比を含めた Metropolis 受理率は 1 である。条件付き正規 $N(\mu(x),\sigma^2)$ の場合、$y'=2\mu(x)-y$ という反射も同じ条件付き密度を保つ。反射は可逆で新しい乱数は要らないが、反射だけでは条件付き平均からの距離を変えられない。そこで通常の Gibbs 更新と組み合わせる。

:::example[条件付き更新が作る自己相関]
分散 1、相関 $r$ の二変量正規で、まず $x'|y$、次に $y'|x'$ を引く。平方完成で平均と分散は順に $ry,1-r^2$、$rx',1-r^2$ である。独立な標準正規 $\xi,\eta$ を用いれば $y'=r^2y+\sqrt{1-r^2}(r\xi+\eta)$ なので、一巡後の条件付き平均の係数は $r^2$ である。$r=1/2$ ならラグ $\ell$ の自己相関は $(1/4)^\ell$、$1+2\sum_{\ell\ge1}(1/4)^\ell=5/3$ である。毎歩の受理率は 1 でも、$r$ が 1 に近いと一巡での状態の移動は遅くなる。
:::



### 定常分布の勾配を利用する提案を対数比で組む

正の標的密度を $\pi(x)\propto e^{-V(x)}$ とし、$\ell>0$ について $y=x-\ell\nabla V(x)+\sqrt{2\ell}\,\xi$、$\xi\sim N(0,I)$ と提案する。これは拡散過程の一歩を近似したもので、Langevin 提案付き Metropolis 法では

$$
\log r =-V(y)+V(x)
-\frac{\|x-y+\ell\nabla V(y)\|^2-\|y-x+\ell\nabla V(x)\|^2}{4\ell}
$$

を計算する。二つの分子はそれぞれ逆方向、順方向の Gaussian の中心からの差である。規格化定数は同じ共分散なので消える。$\log u\le\min(0,\log r)$ なら受理し、$e^{\log r}$ のオーバーフローを避ける。

:::example[正規分布に対する刻みの偏りを正す]
$\pi=N(0,1)$ なら提案は $y=(1-\ell)x+\sqrt{2\ell}\,\xi$ である。受理判定を外した反復は $0<\ell<2$ で定常分散 $2\ell/[1-(1-\ell)^2]=1/(1-\ell/2)$ を持ち、例えば $\ell=1$ では 2 になる。比の式の二乗差は $((1-\ell)^2-1)(y^2-x^2)$ なので、正しい $\log r$ は $-\ell(y^2-x^2)/4$ である。$\ell=1,x=0,y=2$ では受理率 $e^{-1}$ となる。勾配が標的の正しい方向を向いても、有限刻みを使った提案を毎回受け入れれば元の分布とは異なる理由である。
:::

### 独立提案がもたらす一様な混合

状態に依存しない提案 $q(y)$ で、規格化済みの標的について $w(x)=\pi(x)/q(x)\le M<\infty$ が支持上で成り立つとする。受理された提案の密度は $q(y)\min(1,w(y)/w(x))$ である。この値は少なくとも $\pi(y)/M$ である。実際、$w(y)/w(x)\ge1$ なら $q(y)\ge\pi(y)/M$、1 未満なら値は $\pi(y)/w(x)\ge\pi(y)/M$ である。従って各一歩を $\pi/M$ と残りに分けられ、前節と同じ差の評価で任意の初期分布と $\pi$ の全変動距離は一歩ごとに高々 $1-1/M$ 倍となる。$w$ に有限上界がない場合も不変性自体は成り立ち得るが、この一様速度は証明できない。

:::example[目標より薄い裾で停滞する]
$\pi=N(0,4)$、$q=N(0,1)$ なら $w(x)=\tfrac12e^{3x^2/8}$ であり、中心に比べ遠方で非常に大きい。$x=4$ から中心 $y=0$ を提案した場合の受理率は $e^{-6}$ である。逆向きでは確率 1 だが、そもそも $q$ が $y=4$ の近くを提案する頻度が小さい。全期間の受理率がよく見えても、裾の訪問頻度とそこからの滞在長を別々に調べる。提案の分散を 4 より大きくすれば $w$ の最大は中心になり、有限の $M$ が取れる。
:::

## 誤差評価と自己相関時間・ブロッキング法

### 相関した平均の厳密分散

定常列 $A_n$ の自己共分散を $\gamma_k=\operatorname{Cov}(A_0,A_k)$ とする。平均の分散の二重和には時間差 $k>0$ の対が両方向を合わせて $2(N-k)$ 個ある。したがって

$$
\operatorname{Var}(\overline A_N)=\frac{1}{N}\left[\gamma_0+2\sum_{k=1}^{N-1}(1-k/N)\gamma_k\right].
$$

$\sum_k|\gamma_k|<\infty$、$\gamma_0>0$ なら、$\rho_k=\gamma_k/\gamma_0$ として $\tau_{\rm int}=1/2+\sum_{k\ge1}\rho_k$ を :term[積分自己相関時間]{en="integrated autocorrelation time" yomi="せきぶんじこそうかんじかん"} と呼ぶ。上式の括弧は優収束により $2\tau_{\rm int}\gamma_0$ に収束する。単位は観測間隔であり、物理時刻に直すにはその間隔を掛ける。

ブロッキングでは連続 $B$ 点を平均して $M$ 個のブロック平均を得る。ブロック分散の標本推定 $s_B^2$ を $M$ で割る。$B$ が相関尺度より短いと隣接ブロックが相関し、長すぎると $M$ が少なく誤差推定が不安定になる。$B$ を倍増させ分散の推定が安定する範囲を探す。小さい標本からの自己相関の長い尾は雑音に埋もれる。定常性を確認できない系列や遷移がごく少ない系列では、独立初期化した複数系列との比較が必要である。

### 平均の分散と有限長補正

$\rho_k=r^k$、$|r|<1$ なら増倍率の極限は $1+2r/(1-r)=(1+r)/(1-r)$ である。有限長は $N=2$ なら $\gamma_0(1+r)/2$、$N=3$ なら $\gamma_0(3+4r+2r^2)/9$ である。例えば $r=1/2,N=3$ では分散が $(11/18)\gamma_0$、独立近似では $\gamma_0/3$ となる。極限係数を先に使うとこの小さい $N$ では過大になる。$r<0$ では近い時刻の反対方向の揺らぎが平均で打ち消し合い、有効標本数が形式上 $N$ を超えることがある。分散推定が減少したからといって、独立な情報が無条件に増えたと解釈しない。

### 分散推定を二つのスケールで行う

観測量 $A$ が複数の速さで緩和すると、自己相関の初期減衰だけを見て積分の打ち切りを決めると遅い尾を見落とす。例えば $\rho_k=0.99(1/2)^k+0.01(0.999)^k$ なら、積分時間の零以外の部分は $0.99+9.99=10.98$ であり、小さい振幅の長い尾が支配する。ブロック長を短めと長めに変えた分散推定、独立初期化した系列間のばらつき、状態間の遷移頻度を記録する。単に $k$ 点ごとに間引くと記憶量を減らせるが、元の全記録を使えるなら観測量によっては情報量を落とす。誤差の報告では一歩の単位、採用したブロック長、測定の総時間を示す。

### 数値例

:::example[幾何的な自己相関での積分自己相関時間]
$r=\frac{1}{2}$ とする。遅れ $k$ の相関が $r^k$、$\abs{r}<1$ とし、零以外の遅れを等比和で足す。したがって、求める量は次の式で与えられる。

$$
\frac{r}{1 - r} + \frac{1}{2}
$$

ここに上の値を代入して整理すると $\frac{3}{2}$ を得る。
:::

:::example[幾何的な自己相関での積分自己相関時間]
$r=\frac{1}{3}$ とする。遅れ $k$ の相関が $r^k$、$\abs{r}<1$ とし、零以外の遅れを等比和で足す。したがって、求める量は次の式で与えられる。

$$
\frac{r}{1 - r} + \frac{1}{2}
$$

ここに上の値を代入して整理すると $1$ を得る。
:::

### 一つの自己相関時間を全観測量に流用しない

定常な可逆連鎖で平均を引いた関数 $f$ を固有関数 $u_j$ で $f=\sum_j a_j u_j$ と展開する。内積を $\sum_x\pi(x)\overline{f(x)}g(x)$ とし、$Pu_j=\lambda_j u_j$、$|\lambda_j|<1$ とする。直交性と $\gamma_f(k)=\langle f,P^k f\rangle_\pi$ から

$$
1+2\sum_{k\ge1}\frac{\gamma_f(k)}{\gamma_f(0)}
=\sum_j\frac{|a_j|^2}{\sum_\ell |a_\ell|^2}\frac{1+\lambda_j}{1-\lambda_j}.
$$

有限状態なので項を入れ替え、各幾何級数を足せる。この倍率は遅い固有関数との重なりに依存する。$f$ に現れない固有関数は分散に寄与しない。二つの独立な二状態連鎖で、非定数の固有値がそれぞれ $1/2$ と $9/10$ なら、前者だけに依存する観測量の倍率は 3、後者だけなら 19 である。エネルギーと磁化の混合が同じ速さとは限らない理由がこの例に現れる。

:::example[負の相関は平均の分散を下げうる]
対称な二状態連鎖で確率 $3/4$ で符号を反転し、確率 $1/4$ で留まるとする。定常で $X=\pm1$ は等確率であり、$\mathbb E[X_{n+1}|X_n]=-X_n/2$ である。ラグ $k$ の相関は $(-1/2)^k$ だから分散の漸近倍率は $(1-1/2)/(1+1/2)=1/3$ となる。単純に相関が初めて負になるところで和を打ち切ると、倍率を 1 と見積もってこの効果を失う。有限長のデータでは負と正が交互に現れること、ブロック長を増やすと平均の分散推定がどう変わるかを併せて確かめる。
:::




### ブロック平均分散の有限長補正を解く

定常系列の相関が $\rho_k=r^k$、$|r|<1$ であるとする。長さ $m$ のブロック平均の分散を $\sigma^2/m$ で割った値は $b_m=1+2\sum_{k=1}^{m-1}(1-k/m)r^k$ である。幾何級数 $\sum_{k=0}^{m-1}r^k=(1-r^m)/(1-r)$ とその微分を用いると

$$
b_m=\frac{1+r}{1-r}-\frac{2r(1-r^m)}{m(1-r)^2}.
\label{eq-comp-block-variance-factor}
$$

$r>0$ では有限長のブロックの値が漸近倍率より小さい。例えば $r=1/2,m=4$ なら $b_4=3-(1-1/16)=33/16$、$m=16$ なら約 2.75 であり、真の 3 へ下から近づく。隣接したブロックの間でも共通境界付近に相関がある。二つのブロックを $X_0,\ldots,X_{m-1}$ と $X_m,\ldots,X_{2m-1}$ とすれば、平均の共分散は

$$
\frac{\sigma^2}{m^2}\sum_{i,j=0}^{m-1} r^{m+j-i}
=\frac{\sigma^2 r(1-r^m)^2}{m^2(1-r)^2}.
$$

指数を $m-i$ と $j$ の二和に分けて得る。有限の計算時間では $m$ を大きくするとブロック数が減り、その分散推定のばらつきが増える。従って複数の $m$ を使って平坦部が得られるかを見て、どの $m$ でも平坦部が見えない場合は系列長が不足している可能性を記す。

:::example[負相関で偶数と奇数のブロック幅を比べる]
$r=-1/2$ のとき $b_1=1$、$b_2=1/2$、$b_3=1/2$、$b_4=7/16$ であり、漸近倍率は $1/3$ である。正相関の場合と異なり、短いブロックで分散を過大評価する。この式には $r^m$ の符号が入るので幅を倍にした系列だけでなく、必要なら近い奇数幅でも比較できる。負相関を切り捨てた有効標本数では、同じ鎖が独立抽出より小さな平均分散を持つことを表せない。
:::



### 計算実習：連鎖の解析値とブロック分散を照合する

二状態の保持確率を調整し、一歩ごとの反転確率 $p$ だけで系列を作る。観測量は符号とし、初期符号は等確率に発生させるので最初の一歩から定常である。$r=1-2p$ とすると、ブロック内の平均の分散は $b_m/m$ である。:eqref[eq-comp-block-variance-factor] を参照値にして、長さ $N$ の一系列から $K$ 個の非重複ブロックを取り、それぞれの平均を $z_j$ とする。比較する統計量は $m\sum_j(z_j-\bar z)^2/(K-1)$ である。有限の $K$ では隣接ブロック間の共分散のため期待値が厳密に $b_m$ とはならない。そこで、次の実習は独立に引いたブロックを使う検査と、一系列から取る検査の両方を行う。

~~~python
from math import sqrt
from random import Random
from statistics import mean, variance


def signs(rng, flip_probability, count, initial=None):
    state = rng.choice((-1, 1)) if initial is None else initial
    for step in range(count):
        if step and rng.random() < flip_probability:
            state = -state
        yield state


def exact_multiplier(width, flip_probability):
    rho = 1 - 2 * flip_probability
    finite = 2 * rho * (1 - rho**width) / (width * (1 - rho)**2)
    return (1 + rho) / (1 - rho) - finite


def stationary_blocks(rng, flip_probability, width, count):
    return [
        mean(signs(rng, flip_probability, width))
        for _ in range(count)
    ]


def contiguous_blocks(rng, flip_probability, width, count):
    path = iter(signs(rng, flip_probability, width * count))
    return [
        sum(next(path) for _ in range(width)) / width
        for _ in range(count)
    ]


def run_experiment(flip_probability, width, block_count=4096, repeat=8):
    cases = (stationary_blocks, contiguous_blocks)
    expected = exact_multiplier(width, flip_probability)
    rng = Random(6043)
    print(f"flip={flip_probability} width={width} exact={expected:.6f}")
    for draw_blocks in cases:
        estimates = []
        for _ in range(repeat):
            blocks = draw_blocks(rng, flip_probability, width, block_count)
            estimates.append(width * variance(blocks))
        standard_error = sqrt(variance(estimates) / repeat)
        print(draw_blocks.__name__, mean(estimates), standard_error)


for flip_probability in (0.05, 0.25, 0.75):
    for width in (4, 16, 64):
        run_experiment(flip_probability, width)
~~~

コードでは各実行内で乱数の状態を共有して進めるが、保持する連鎖の状態は独立ブロックごとに新しく引いている。一系列のブロックに対しては、先頭の初期値を使った後で途中の境界を越える際にも通常の一歩が発生する。境界で符号を初期化し直すと、独立ブロックと同じ実験になってしまう。各反復から一つの分散見積もりを作り、反復間の標本標準偏差を反復数の平方根で割って、その平均の標準誤差を求める。ブロック内部の符号の標準偏差を直接この標準誤差に置き換えることはできない。

$p=1/20$ のとき $r=9/10$、漸近倍率は 19 である。$m=4$ の厳密な倍率は
$1+2[(3/4)(9/10)+(1/2)(9/10)^2+(1/4)(9/10)^3]=7049/2000$ である。$m=16$ でも約 9.83、$m=64$ で約 16.19 にとどまる。従って 4 から 16 に増やしただけで漸近値へ達したと判定すると分散を過小評価する。逆に $p=3/4$ では $r=-1/2$ なので $m=4$ でも $7/16$、$m=64$ では約 0.3403 まで $1/3$ に近づく。独立ブロックの実験は解析曲線と見積もりの単位を確認するものであり、一系列の実験は隣接ブロックの相関を残したまま、同じブロック数で幅を比較する。総標本数を固定する実験は別に行える。例えば $N=4096$ に固定すれば $m=4,16,64$ のブロック数は $1024,256,64$ である。コードの block_count をそれぞれこの値へ変えれば、幅を増やしたときに反復間のばらつきが増える様子を比較できる。

\frac{f}{q}
$$

\frac{u}{u + v}

::::exercise{level=advanced}
二状態 $0,1$ について、離脱確率をそれぞれ $u,v$ とする。不変分布と、指示変数の自己相関を求めよ。ただし $u,v>0$、$u+v<2$ とする。

:::solution
詳細つり合いと和 1 から $\pi_1=u/(u+v)$、$\pi_0=v/(u+v)$ である。$g(i)=i-\pi_1$ とすると $Pg=(1-u-v)g$ を両成分で代入確認できる。よって定常平均で $\mathbb E[g(X_0)g(X_k)]=(1-u-v)^k\mathbb E[g(X_0)^2]$ となり、規格化すれば自己相関が得られる。$\lambda=1-u-v$ は $|\lambda|<1$ だから、$2\tau_{\rm int}=(1+\lambda)/(1-\lambda)$ である。

::::exercise{level=advanced}
$[0,1]$ の積分 $\int_0^1x^2\dd x$ について、一様密度と $q=2x$ の一標本分散を比較せよ。

:::solution
積分は $1/3$ である。一様では二次モーメントが $\int x^4\dd x=1/5$ なので分散は $4/45$ である。$q=2x$ では重み付き値は $x/2$、二次モーメントは $\int_0^1 2x(x/2)^2\dd x=1/8$ なので分散は $1/72$ である。$x=0$ は確率零であり、被積分関数も 0 なので比の値は任意に定めてよい。

::::exercise{level=advanced}
$0$ と $1$ のみを取る定常連鎖で、反転確率が $p$、留まる確率が $1-p$ であり、$0<p<1$ とする。観測 $f(x)=2x-1$ の $N$ 歩平均の分散を求めよ。$p=1/4,3/4$ における漸近倍率を比べよ。

:::solution
定常分布は両状態で $1/2$、従って $f$ の平均は零、分散は 1 である。条件付き平均が $Pf=(1-2p)f$ なので $\rho_k=(1-2p)^k$ である。同じ遅れ $k$ が二重和で $2(N-k)$ 回現れるため分散は $b_N/N$、$b_N=(1+r)/(1-r)-2r(1-r^N)/[N(1-r)^2]$、$r=1-2p$ となる。$p=1/4$ の $r=1/2$ では漸近倍率が 3、$p=3/4$ の $r=-1/2$ では $1/3$ である。反転を増やすことで定常分布は変わらず、観測量の相関の符号が変わる。
:::

::::exercise{level=advanced}
二階層の全体平均を推定する。層の確率を $(1/4,3/4)$、被積分値の標準偏差を $(4,2)$、一回の費用を $(1,4)$ とする。全費用 70 のもとで最小分散を与える正整数の標本数を求めよ。

:::solution
連続緩和した最適配分は $n_j\propto w_j\sigma_j/\sqrt{c_j}$ なので比は $1:3/4=4:3$ である。$(n_1,n_2)=(4k,3k)$ と置くと費用は $16k$ なので $k=35/8$、最適連続点は $(35/2,105/8)$ である。整数解では費用の余りを第 1 層で使えるため $n_1=70-4n_2$ とする。目的関数 $1/(70-4n_2)+(9/4)/n_2$ は正の領域で厳密に凸であり、連続点から離れるほど各側で増えるので $n_2=13,14$ だけを比べればよい。$n_2=13$ では $1/18+9/52=107/468$、14 では $1/14+9/56=13/56$ である。前者が小さいので $(18,13)$ が最適である。
