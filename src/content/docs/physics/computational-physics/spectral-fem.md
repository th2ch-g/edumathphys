## この章の目標

- Fourier 基底による微分と時間発展を求める。
- Chebyshev 点における補間微分と境界条件の処理を理解する。
- KdV 方程式の積を擬スペクトル法で評価し、折り返しを除去する。
- Poisson 問題の弱形式から有限要素行列を作る。

## Fourier スペクトル法

### 射影と微分

周期区間の長さを $L$ とし、$k_n=2\pi n/L$ とする。$u_N=\sum_{|n|\le K}\widehat u_n e^{ik_n x}$ と置き、偏微分方程式の残差を各基底に直交させる。この近似が :term[Galerkin 法]{en="Galerkin method" yomi="がらーきんほう"} である。例えば $u_t=D u_{xx}$ では、積分による直交性から $\dot{\widehat u}_n=-Dk_n^2\widehat u_n$ となり、$\widehat u_n(t)=e^{-Dk_n^2t}\widehat u_n(0)$ と解ける。零モードは保存される。$N$ 点の等間隔格子値から補間の係数を計算する場合、:ref[def-comp-dft] の係数を $N$ で割る。$u$ の波数が格子で区別できる帯域に収まる場合には、連続の射影係数と一致する。一般には高波数の折り返しが加わる。実数の偶数格子で一次微分を扱う際は、正負の区別を失う Nyquist モードに規約が要る。以下では奇数点格子か、Nyquist モードを除いた射影を用いる。

### 係数の減衰と誤差

$r\ge1$ を整数とし、$u^{(r-1)}$ が絶対連続で、関数値と $r-1$ 階までの導関数が周期的に接続するなら、部分積分 $r$ 回で $|\widehat u_n|\le\norm{u^{(r)}}_{L^1}/(L|k_n|^r)$ となる。$r>1$ なら残りの和を積分で抑え、近似関数の一様誤差は $\order{K^{1-r}}$ 以下である。境界で不連続なら境界項が残り、急速な減衰の根拠が失われる。例えば $u=\cos(4\pi x/L)$ は $n=\pm2$ のみを含むので、$K\ge2$ で微分を厳密に再現する。陽的 Euler で拡散を時間積分するなら、最大固有値の大きさ $Dk_K^2$ に対し $\Delta tDk_K^2\le2$ を課す。空間精度を上げても時間安定性は別に必要である。

### 反応項を持つ周期方程式の解

定数 $a>0$ の $-u''+au=f$ を周期で解くと、モードごとに $\widehat u_n=\widehat f_n/(k_n^2+a)$ となる。零モードは $\widehat f_0/a$ である。$a\to0$ で有限な解を保つには $\widehat f_0=0$ が必要である。この極限は平均零の解を選ぶ。$a=0$ の方程式自体には任意の定数を加えられる。例えば $L=2\pi$、$a=1$、$f=1+5\cos 2x$ なら $u=1+\cos2x$ である。離散係数がすべて正しいかを確認するには、境界をまたぐ連続性だけでなく零モードの式と元の微分方程式を代入検査する。

### 数値例

:::example[拡散する Fourier モードの振幅比]
$s=\log{\left(2 \right)}$ とする。$Dk^2t$ を $s$ とし、射影後の一自由度の減衰方程式を解く。したがって、求める量は次の式で与えられる。

$$
e^{- s}
$$

ここに上の値を代入して整理すると $\frac{1}{2}$ を得る。
:::

:::example[拡散する Fourier モードの振幅比]
$s=\log{\left(4 \right)}$ とする。$Dk^2t$ を $s$ とし、射影後の一自由度の減衰方程式を解く。したがって、求める量は次の式で与えられる。

$$
e^{- s}
$$

ここに上の値を代入して整理すると $\frac{1}{4}$ を得る。
:::

### Fourier 空間で剛性を対角にする

周期区間 $[0,L]$ で $-u''=f$ を解く。積分して $\int_0^L f=0$ が必要である。逆に $f$ が平均零の有限 Fourier 和なら、各非零波数で $\widehat u_n=\widehat f_n/k_n^2$、零波数で $\widehat u_0=0$ とすると解が得られる。唯一性は差 $v$ に対して $\int \overline v(-v'')=\int|v'|^2=0$ から $v$ が定数となり、平均零で消えることによる。格子の $f$ から先に平均を引くのは、周期境界で解ける問題へ射影する操作である。総電荷が非零の周期 Poisson 問題では、これは一様背景を加えた別の物理系になる。

:::example[短波長の残差が解に入る割合]
$L=2\pi$、$f(x)=2\cos x+2\cos(8x)$ とすると $u(x)=2\cos x+(1/32)\cos(8x)$ である。二つの荷重の振幅は等しいが、解の短波長側は長波長側の $1/64$ である。一方、導関数では比が $1/8$ になる。解の値だけの収束を見て力や電場の精度まで同じだと判断しない。
:::

### 時間積分側の刻み制限

$u_t=D u_{xx}$ を Fourier 空間で切った場合、最大波数 $k_K$ の陽的 Euler の安定条件は $\Delta t\le2/(Dk_K^2)$ である。空間項が正確に微分されても、この剛性は消えない。線形部分だけを指数 $e^{-D k^2 h}$ で進め、加法的な荷重 $f$ を一歩内で一定と近似すると

$$
\widehat u_k(t_{n+1})=e^{-s}\widehat u_k(t_n)+
h\frac{1-e^{-s}}{s}\widehat f_k(t_n),\qquad s=Dk^2 h
$$

となる。これは積分因子で区間を厳密に積分した式で、$s=0$ では係数を 1 とする。小さな $s$ に対して $1-e^{-s}$ を直接引き算すると桁が落ちるため、差を直接計算する指数関数または級数を使う。



### 打ち切り誤差と微分した後の誤差

$2\pi$ 周期とし、$u\in L^2$ の係数 $\widehat u_k$ に対し $\sum_k (1+k^2)^s|\widehat u_k|^2<\infty$、$s>0$ とする。この和の平方根を Fourier 表示の $H^s$ ノルムとする。$P_K u=\sum_{|k|\le K}\widehat u_k e^{ikx}$ とすると、正規化した二乗ノルムは直交性により

$$
\|u-P_Ku\|_2^2
=\sum_{|k|>K}|\widehat u_k|^2
\le(1+K^2)^{-s}\|u\|_{H^s}^2
$$

である。$0\le m\le s$ の整数階の微分では、同じ和に $|k|^{2m}$ が掛かり、上界は $(1+K^2)^{m-s}\|u\|_{H^s}^2$ になる。ポテンシャルが滑らかに見えても、導関数である力を使う場合の残差は同じ速さで減らない。格子補間と射影の差はさらに異なり、格子上では切り落とすはずの係数が低波数へ折り返す。絶対可和の級数を格子に代入して DFT を取ると、差は各 $|k|\le K$ の係数に $\sum_{j\ne0}\widehat u_{k+jN}$ が加わる形になる。射影の誤差だけを測りたい場合は、先に解析係数を使うか元の積分を十分細かい格子で求める。

:::example[角を持つ関数の収束次数を見積もる]
$u(x)=|x|$ を $[-\pi,\pi]$ から周期化する。偶関数なので $\widehat u_k=\pi^{-1}\int_0^\pi x\cos kx\dd x$ であり、$k\ne0$ では部分積分で $[(-1)^k-1]/(\pi k^2)$ となる。$\widehat u_0=\pi/2$ である。高波数の二乗和は奇数 $k$ の $k^{-4}$ の尾に比例し、積分比較で $O(K^{-3})$ だから値の二乗平均誤差のノルムは $O(K^{-3/2})$ である。一階導関数の二乗和の尾は $k^{-2}$ となるためノルムは $O(K^{-1/2})$ に下がる。$K$ を二倍にしても、導関数では誤差は約 $1/\sqrt2$ にしか減らない。指数収束を前提にした点数選択は、周期境界の角にも注意を要する。
:::

### 係数が滑らかなときの指数減衰

周期関数 $u(z)$ が複素平面の帯 $|\Im z|<a$ で正則で、$0<b<a$ で $|u|\le M_b$ とする。$k>0$ に対し係数の積分を実軸から $\Im z=-b$ へ移す。長方形の二側面は周期性で相殺し、Cauchy の積分定理で上下の積分が一致する。下側では $e^{-ik(x-ib)}=e^{-ikx}e^{-kb}$ だから $|\widehat u_k|\le M_b e^{-kb}$ である。$k<0$ には上側を使って $|\widehat u_k|\le M_b e^{-b|k|}$ を得る。尾は幾何級数として抑えられ、任意の固定次数の微分でも $|k|^m$ は少し小さい指数に吸収できる。従って最も近い複素特異点が実軸に近いと、実軸上が滑らかでも同じ精度に多くのモードを要する。

:::example[幾何係数を持つ周期関数を生成する]
$0<r<1$ に対する $u=(1-r^2)/(1-2r\cos x+r^2)$ は $\sum_{k\in\Z}r^{|k|}e^{ikx}$ である。正と負の幾何級数を足すとこの分母が得られる。$r=1/2$ で $K=4$ のとき、原点で切り落とす値は $2(1/2)^5/(1-1/2)=1/8$ である。平均二乗誤差は $2(1/4)^5/(1-1/4)=1/384$ である。$r$ を $0.9$ にすると同じ $K$ の原点の誤差は $2(0.9)^5/0.1=11.8098$ になる。どちらも解析関数だが、最も近い極の虚部 $\log(1/r)$ が異なるため収束の速さが違う。
:::



### 変数係数の楕円型方程式を射影する

$2\pi$ 周期で $-(a(x)u_x)_x=f(x)$、$a(x)$ は実で $0<a_*\le a(x)\le a^*<\infty$ とし、$f$ の平均を零とする。平均零の試行空間の基底を $e^{ikx}$、$k\ne0$ とすると、部分積分の後の剛性行列は

$$
A_{k\ell}=\frac1{2\pi}\int_0^{2\pi}
\overline{(e^{ikx})'}a(x)(e^{i\ell x})'\dd x
=k\ell\,\widehat a_{k-\ell}.
$$

二次形式は $\int a|u_x|^2/(2\pi)$ だから Hermite 正定値である。対角微分行列 $D=\diag(k^2)$ と比較すると $a_* v^\dagger D v\le v^\dagger A v\le a^* v^\dagger D v$ である。従って $D^{-1/2} A D^{-1/2}$ の任意の規格化ベクトルの Rayleigh 商は $[a_*,a^*]$ に入り、条件数は $a^*/a_*$ 以下である。$D$ を用いる前処理では、格子細分化で生じる $K^2$ の増大を抑えられる。実際の行列作用は、微分を Fourier 空間、係数との積を格子で行い、さらに微分する。格子での二次形式が正であれば選点版でも安定性の検査になるが、Galerkin 行列と一致させたい場合は $\widehat a$ の帯域に応じた零詰めが要る。

:::example[非零係数が隣の波数を混ぜる]
$a(x)=2+\cos x$ とし、$k=1,2$ の部分空間を取る。$\widehat a_0=2,\widehat a_{\pm1}=1/2$ より $A=\begin{pmatrix}2&1\\1&8\end{pmatrix}$ である。$f=(1,0)$ の係数には $u=(8,-1)/15$ を得る。定数係数だけを用いると $u=(1/2,0)$ で第二成分を失う。$D=\diag(1,4)$ で前処理した行列は $\begin{pmatrix}2&1/2\\1/2&2\end{pmatrix}$、固有値は $3/2,5/2$ となり、$a(x)$ の点ごとの上下界 $1,3$ に含まれる。実数場を再現するなら負の波数にも共役の係数を並べる。
:::

## Chebyshev スペクトル法

### 余弦から多項式へ

$T_n(x)=\cos(n\arccos x)$、$-1\le x\le1$ と定義する。余弦の加法公式から $T_{n+1}=2xT_n-T_{n-1}$、初期値 $T_0=1,T_1=x$ を得る。従って $T_n$ は次数 $n$ の多項式である。変数を $x=\cos\theta$ と変えると重み付き内積 $\int_{-1}^1T_nT_m/\sqrt{1-x^2}\dd x$ は $[0,\pi]$ の余弦の内積になる。相異なる次数は直交し、ノルム二乗は $n=0$ で $\pi$、$n>0$ で $\pi/2$ である。

### 補間微分と境界行

Chebyshev–Lobatto 点 $x_j=\cos(j\pi/N)$ で得た値 $u_j$ を補間する。この節点を :term[Chebyshev–Lobatto 点]{en="Chebyshev Lobatto points" yomi="ちぇびしぇふろばっとてん"} と呼ぶ。節点多項式 $\ell(x)=\prod_{j=0}^N(x-x_j)$、$w_j=1/\ell'(x_j)$ とすると $j$ 番目の Lagrange 基底は $\ell(x)w_j/(x-x_j)$ である。$i\ne j$ での微分は $D_{ij}=w_j/[w_i(x_i-x_j)]$ となる。定数関数の微分は 0 なので $D_{ii}=-\sum_{j\ne i}D_{ij}$ とすればよい。第二微分は $D^2$ である。一次微分した補間多項式の次数が下がり、同じ点群での再補間が厳密だからである。$-u''=f$ の境界値を指定するには $-D^2$ の端の行を単位行に置き換える。Neumann 条件なら対応する行を $D$ の行に置き換える。両端の導関数だけを指定する場合は、定数を決める条件と右辺の適合条件が要る。物理区間 $[a,b]$ に移すと一次微分は $2/(b-a)$ 倍、二次微分はその二乗倍である。

### 端の点が密な理由と微分行列の検算

$1-\cos(\pi/N)=\pi^2/(2N^2)+\order{N^{-4}}$ なので、端の最小間隔は $N^{-2}$ のオーダーである。滑らかな関数の補間ではこれにより等間隔高次補間の端の振動を抑える。時間発展では端の細かい尺度も微分作用素に入り、陽解法の刻みを制限する。行列の検査として、入力を $x_j^p$ として $p=0,\dots,N$ なら出力が $p x_j^{p-1}$ になることを確認する。$N=2$ の点 $1,0,-1$ では重みは $(1/2,-1,1/2)$ であり、$D$ の第一行は $(3/2,-2,1/2)$ である。この行を定数列に掛けると 0、一次列に掛けると 1 となる。

### 余弦変換から係数を復元する

Chebyshev–Lobatto 点の値 $u_j$ を角度 $\theta_j=j\pi/N$ における余弦級数の値と見る。両端に半分の重み $\omega_0=\omega_N=1/2$、他に $\omega_j=1$ を置くと

$$
B_{mn}=\sum_{j=0}^N\omega_j\cos(m\theta_j)\cos(n\theta_j)
$$

は対角になる。実際、$j=0,\dots,N$ の重み付き和を鏡映して $2N$ 点の周期和を作れば、余弦積を指数に分けたとき $m\pm n$ が $2N$ の倍数である項だけ残る。従って対角は $m=0,N$ で $N$、それ以外で $N/2$ である。係数 $a_m$ は右辺に $u_j$ を掛けて足した値をこの対角で割って求める。この正規化なら $u_j=1$ で $a_0=1$、$u_j=(-1)^j$ で $a_N=1$ である。端の係数に二倍を掛けるとこの二例で誤りを検出できる。

### 数値例

:::example[第二 Chebyshev 多項式の値]
$x=0$ とする。加法公式で得た多項式に位置 $x$ を入れる。したがって、求める量は次の式で与えられる。

$$
2 x^{2} - 1
$$

ここに上の値を代入して整理すると $-1$ を得る。
:::

:::example[第二 Chebyshev 多項式の値]
$x=1$ とする。加法公式で得た多項式に位置 $x$ を入れる。したがって、求める量は次の式で与えられる。

$$
2 x^{2} - 1
$$

ここに上の値を代入して整理すると $1$ を得る。
:::

### Chebyshev 係数から導関数の係数を求める

$u=\sum_{n=0}^N a_n T_n$、$u'=\sum_{n=0}^{N-1}b_nT_n$ とする。$x=\cos\theta$ から $T_n'(x)=n\sin(n\theta)/\sin\theta$ である。$2\cos(k\theta)\sin\theta=\sin((k+1)\theta)-\sin((k-1)\theta)$ を用いて、$\sin\theta\,u'(\cos\theta)=\sum_{n\ge1}n a_n\sin(n\theta)$ の各係数を比較する。$k\ge2$ では $b_{k-1}-b_{k+1}=2k a_k$、$k=1$ では $2b_0-b_2=2a_1$ となる。$b_N=b_{N+1}=0$ から後退代入すれば $O(N)$ で導関数を得る。$b_0$ だけ規約が異なるのは $\sin(-\theta)=-\sin\theta$ を含む定数項のためである。

:::example[四次多項式の微分を基底で検査する]
$u=3T_4-T_2+T_1$ とすると $b_3=2\cdot4\cdot3=24$、$b_2=0$、$b_1=b_3-4=20$、$b_0=1$ となる。多項式で $T_4=8x^4-8x^2+1$、$T_2=2x^2-1$ を入れると $u'=96x^3-52x+1$ であり、$24T_3+20T_1+1$ に一致する。物理区間 $[a,b]$ へ写すなら、計算した導関数に $2/(b-a)$ が掛かる。
:::



### Chebyshev 求積の重みと積分の種類

$T_n(x)=\cos(n\arccos x)$ とすると、変数 $x=\cos\theta$ により $\int_{-1}^1 f(x)/\sqrt{1-x^2}\dd x=\int_0^\pi f(\cos\theta)\dd\theta$ である。点 $\theta_j=(j+1/2)\pi/N$ の中点を用いた $\pi N^{-1}\sum_j f(\cos\theta_j)$ は、次数 $2N-1$ 以下の多項式で厳密である。これを示すには $T_0,\ldots,T_{2N-1}$ を基底としてよい。$T_0$ は両側が $\pi$ で、他の基底の積分は零である。格子和は $k$ が奇数なら $\theta_j$ と $\pi-\theta_j$ の対が相殺する。偶数 $k=2m$ では共通比 $e^{2\pi i m/N}$ の等比和が零である。ここで $1\le m<N$ なので比は 1 にならない。$k=2N$ では各点の余弦が $-1$ となり、この厳密性の限界も分かる。

重みなし積分 $\int_{-1}^1 f(x)\dd x$ にはこの重みをそのまま使えない。係数 $a_j$ が既にあれば、$\int_{-1}^1 T_j(x)\dd x$ を掛けて足す。奇数は零、偶数では $2/(1-j^2)$ である。実際、$\int_0^\pi\sin\theta\cos j\theta\dd\theta$ を和積公式で積分すればよい。$j=0$ は 2 となる。この規約で Chebyshev 補間を積分する方法では、同じ節点から求積を得ても重み付き積分とは違う値になる。

:::example[二点で重みを間違えたときの値]
$f(x)=x^2=(T_0+T_2)/2$ とする。重み付き求積の二点は $\pm1/\sqrt2$ なので値は $\pi/2$ となり厳密である。重みなしの積分は $(2-2/3)/2=2/3$ である。二点での関数値がともに $1/2$ という事実だけから、単純平均に長さ 2 を掛ければ 1 になり、これも誤りである。使う求積は節点の配置だけでなく、その節点を導入した測度で決まる。
:::

### 内点を高次にしても境界で条件が決まる

$-u''=f$ を $[-1,1]$ の Chebyshev–Lobatto 点で解く。$N=3$ の格子なら $x=1,1/2,-1/2,-1$ の順で、内部二点だけに方程式を当て、端で値を指定する。透過や対称境界のように導関数を指定するときは、端の行に補間多項式の導関数を作用させる。両端が Neumann なら定数が零空間なので、平均を与えるなどの条件と、右辺の整合性が必要になる。離散の整合性は行の線形従属に対応し、連続の積分条件を満たす滑らかな $f$ でも求積と微分の組合せでは小さな不整合が残りうる。

:::example[四点の選点で三次解を正確に戻す]
$f(x)=6x$、$u(-1)=u(1)=0$ とする。試行多項式を $a+b x+c x^2+d x^3$ と置く。端の値を足し引きすると $a=-c,b=-d$ である。内部では $-2c-6d(\pm1/2)=\pm3$ だから $c=0,d=-1$、従って $u=x-x^3$ となる。節点列は $(0,3/8,-3/8,0)$ である。$[0,2]$ へ平行移動しても微分係数は同じだが、$[0,4]$ なら $x=(X-2)/2$ で二階微分に $1/4$ が掛かる。別の物理区間の境界値問題を実装するときはこの因子も検査する。
:::



### 重心補間の微分行列を端点まで作る

相異なる節点 $x_0,\ldots,x_N$ で $w_j=1/\prod_{m\ne j}(x_j-x_m)$ とする。Lagrange 基底 $L_j$ は $w_j\prod_{m\ne j}(x-x_m)$ である。$i\ne j$ なら $L_j'(x_i)$ は因子 $x-x_i$ を一度微分した項だけ残り、

$$
D_{ij}=L_j'(x_i)=\frac{w_j}{w_i(x_i-x_j)},\qquad
D_{ii}=-\sum_{j\ne i}D_{ij}
$$

となる。対角は $\sum_j L_j=1$ の微分から求めた。両辺の定数を $w_j$ に共通に掛けても行列は変わらない。Chebyshev–Lobatto 点 $x_j=\cos(j\pi/N)$ では、この比には $w_j=(-1)^j d_j$、$d_0=d_N=1/2$、内点 $d_j=1$ を使える。実際、節点多項式は定数倍の $(x^2-1)T_N'(x)$ であり、各 $w_j$ はこの多項式の節点での微分の逆に比例する。内点では $T_N'(x_j)=0$ と Chebyshev の微分方程式 $(1-x^2)T_N''-xT_N'+N^2T_N=0$ から微分が $N^2(-1)^j$、両端では $T_N'(\pm1)=(\pm1)^{N-1}N^2$ を使い $2N^2(-1)^j$ となる。微分方程式は $T_N(\cos\theta)=\cos N\theta$ を $\theta$ で二回微分すれば得られる。端を半分にする係数は、この微分の差を取り入れたものである。

:::example[三点行列で定数と二次を正確に微分する]
$x=(1,0,-1)$ なら $w$ は $(1/2,-1,1/2)$ に比例し、行列は

$$
D=\begin{pmatrix}
3/2&-2&1/2\\
1/2&0&-1/2\\
-1/2&2&-3/2
\end{pmatrix}.
$$

定数列を消し、$D(1,0,1)^\top=(2,0,-2)^\top$ となる。$D^2$ を同じ列へ掛けると $(2,2,2)^\top$ である。$x$ の格子の順を昇順に変える場合は値列と行列の行・列をすべて同じ順序に並べ替える。元の導関数の符号を追加で変える必要はない。
:::

### 解析接続と Chebyshev 補間の収束

$\rho>1$ とし、$z=(w+w^{-1})/2$、$|w|=\rho$ で描く楕円の内部と境界の近傍で $u(z)$ が正則、境界上で $|u|\le M$ とする。$v(w)=u((w+w^{-1})/2)$ は $\rho^{-1}<|w|<\rho$ を含む円環で正則で、$v(w)=v(1/w)$ を満たす。Laurent 係数 $c_n$ はこの対称性から $c_{-n}=c_n$ であり、$|w|=\rho$ の積分から $n\ge0$ で $|c_n|\le M\rho^{-n}$ である。単位円に戻すと $u(x)=c_0+2\sum_{n\ge1}c_nT_n(x)$ となる。$|T_n|\le1$ なので、次数 $N$ の打ち切りの一様誤差は $2M\rho^{-N}/(\rho-1)$ 以下である。

Lobatto 補間でも指数的に収束する。節点上で $T_n(x_j)=\cos(nj\pi/N)$ は、$n$ を $2N$ で剰余に直してから $0,\ldots,N$ へ鏡映した次数 $r$ の $T_r(x_j)$ と一致する。このため次数 $N$ を超える係数は補間で $T_n$ から $T_r$ へ移る。級数が絶対一様収束するので節点で項別に同一視でき、補間の一様誤差は $\sum_{n>N}2|c_n|\|T_n-T_r\|_\infty\le4M\rho^{-N}/(\rho-1)$ である。例えば $N=4$ では $T_6$ が $T_2$ に折り返す。補間が節点で一致しても、節点間や導関数では誤差が残る。

### 格子の最小間隔を写像で見積もる

参照区間で $x_0-x_1=1-\cos(\pi/N)=\pi^2/(2N^2)+O(N^{-4})$、中央の間隔は $O(N^{-1})$ である。物理区間の端に境界層があるときは、端の密な点によって多くの点を置ける。一方、時間発展を陽的に進めると最小間隔の近くを伝わる変化にも刻みを合わせる必要がある。特に拡散の選点行列の固有値は微分行列と境界処理に依存するため、内部の平均格子幅だけで刻みを決めない。例えば $N$ を 16 から 32 に増やしたとき端の間隔の比はほぼ $1/4$ である。もし局所差分でその幅の拡散時間を基準にすると比はほぼ $1/16$ になり、単純な Fourier 格子より刻み制限が強まる。実際の選点法では組み立てた行列の最大固有値や、非正規なら短時間の増幅も検査する。

## 擬スペクトル法と非線形項（KdV 方程式）

### KdV 方程式の積を格子で作る

無次元化した周期 KdV 方程式を $u_t+6uu_x+u_{xxx}=0$ とする。$6uu_x=3(u^2)_x$ を使い、

$$
\dot{\widehat u}_n=ik_n^3\widehat u_n-3ik_n\widehat{u^2}_n
$$

を得る。積の係数を直接計算すると全モードの組合せが要る。そこで係数を逆 FFT して格子上で二乗し、FFT で戻す。これが :term[擬スペクトル法]{en="pseudospectral method" yomi="ぎすぺくとるほう"} である。$N$ 点格子の積には添字和が $n\bmod N$ に等しい項がすべて入る。入力と残す出力を $|n|\le K$ に制限すると $|p+q-n|\le3K$ である。従って $N>3K$ なら零でない $N$ の倍数は生じず、低次側の畳み込みを厳密に得る。この不等式が、最高解像波数のおよそ $2/3$ のみを使う規則の根拠である。別の実装は係数をより長い配列に零詰めして同じ条件を満たす。

### 保存量と時間積分の分担

周期境界で $\dv{}{t}\int u\dd x=0$ は全微分の積分から得る。$\dv{}{t}\int u^2/2\dd x=-6\int u^2u_x\dd x-\int uu_{xxx}\dd x=0$ でもある。一項目は $u^3$ の微分、二項目は部分積分後に $u_x^2$ の微分になる。厳密な射影で積を処理する半離散系でも、試験関数 $u_N$ が射影空間内なので同じ証明が使える。時間離散化では保存誤差が残る。線形項を $v_n=e^{-ik_n^3t}\widehat u_n$ に変換すれば、$v_n$ の時間微分から $ik_n^3$ の線形項は消える。非線形項は変換後の時刻で評価する。刻みとモード数を独立に変え、波速、波形、保存量を別々に検査する。

### 折り返しを一つのモードで追う

$N=8$ の周期格子で $u(x)=\cos 3x$ を二乗する。連続では $u^2=(1+\cos 6x)/2$ だが、格子点 $x_j=2\pi j/8$ では $\cos6x_j=\cos2x_j$ である。したがって格子で得た低波数 2 の係数は真の積に存在しない。これを一階微分して KdV の右辺に使うと、真の低モード射影にはない非線形結合を生む。$K=3$ を残すなら $N>9$ の格子で積を評価する。元の係数の対称性や物理単位を保ったまま零詰めし、変換で用いる規格化も新しい点数に合わせる。

### 平坦な場所を伝わる分散の符号

定数解 $u_0$ のまわりで $u=u_0+v$ とすると一次の方程式は $v_t+6u_0v_x+v_{xxx}=0$ である。$v=e^{i(kx-\omega t)}$ を入れると $\omega=6u_0k-k^3$ を得る。例えば $u_0=0,k=2$ なら $\omega=-8$ であり、時間発展は $e^{i8t}$ を掛ける。線形段の位相の符号は、この試験で検出できる。波の振幅を小さくしたときの位相と、非線形性が十分強い波形での保存量を別々に確認する。

### 数値例

:::example[二次積を折り返さず残すために必要な最小点数]
$K=2$ とする。入力と出力の最大添字を整数 $K$ とする。差の最大値 $3K$ より真に多い点を取る。したがって、求める量は次の式で与えられる。

$$
3 K + 1
$$

ここに上の値を代入して整理すると $7$ を得る。
:::

:::example[二次積を折り返さず残すために必要な最小点数]
$K=3$ とする。入力と出力の最大添字を整数 $K$ とする。差の最大値 $3K$ より真に多い点を取る。したがって、求める量は次の式で与えられる。

$$
3 K + 1
$$

ここに上の値を代入して整理すると $10$ を得る。
:::

### 線形分散を積分因子に移す

$u_t+6uu_x+u_{xxx}=0$ で $\widehat u_k=q_k$ とし、積は折り返しを除いて計算する。$6uu_x=3(u^2)_x$ なので $\dot q_k=i k^3 q_k-3ik\widehat{u^2}_k$ である。$v_k(t)=e^{-ik^3t}q_k(t)$ と置くと

$$
\dot v_k=-3ik e^{-ik^3t}\sum_{p+q=k} e^{i(p^3+q^3)t}v_pv_q .
$$

各段時刻で $v$ を $q$ に戻し、格子で積を取り、射影してから位相を掛け直す。振幅を変えない線形項を厳密に進められる一方、非線形相互作用に現れる位相は時間に依存する。そのため大きな刻みで全体が正確になるわけではない。差 $p^3+q^3-k^3=-3pqk$ なので、高波数間の相互作用の振動を時間刻みの収束で調べる。

:::example[二波数の積が伝える成分]
$2\pi$ 周期で $u=A\cos x+B\cos2x$ とする。$u^2$ の波数 3 と 1 の余弦係数はともに $AB$ であり、それぞれ $-3(u^2)_x$ に $9AB\sin3x$ と $3AB\sin x$ を与える。$|k|\le2$ の Galerkin 近似では波数 3 は除く。五点だけで値を掛けると $\cos3x$ が $\cos2x$ へ折り返し、本来なかった低波数の係数を生む。補正の目的は切り捨てるはずの項を、残す帯域に混ぜないことである。
:::



### KdV の孤立波を作り分散の符号を検査する

実数直線の方程式 $u_t+6u u_x+u_{xxx}=0$ で、$u(x,t)=U(\xi)$、$\xi=x-ct$ とし、$U,U',U''$ が無限遠で零になるとする。積分して $U''=cU-3U^2$ を得る。さらに $U'$ を掛けて積分すると $(U')^2=cU^2-2U^3$ である。従って正の峰では $U=c/2$ であり、$c>0$ を要する。$U=(c/2)\operatorname{sech}^2(\sqrt c\,\xi/2)$ と置けば、$\dd \operatorname{sech}^2 z/\dd z=-2\operatorname{sech}^2 z\tanh z$ と $\tanh^2 z=1-\operatorname{sech}^2 z$ によりこの一次式を満たす。峰の近くも滑らかで、二回微分して $U''=cU-3U^2$ を確認できるので元の方程式の解である。この形を有限周期領域で使うときは、周期境界で端の値と微分が十分小さい長さを選ぶ。これは周期での厳密解ではないため、誤差を分割法の刻みだけに帰さない。

:::example[振幅、位置、積分を別々に検査する]
$c=4$ なら $U=2\operatorname{sech}^2(x-4t)$ で、時刻 $t=1/2$ の峰は $x=2$、高さ 2 である。$\int_\R U\dd x=4$ は $\tanh$ の両端の差、$\int_\R U^2\dd x=16/3$ は $z=\tanh(x-4t)$ と置いて $4\int_{-1}^1(1-z^2)\dd z$ から得られる。周期格子の積分が一定でも峰の位置がずれることがあるため、三量を同時に照合する。両端に短い緩衝領域しかない場合、厳密な周期延長の効果で孤立波の位置も変わりうる。
:::

### 非線形項でも零モードと二乗和を検査する

周期解の Fourier–Galerkin 近似で $P_K$ を直交射影とする。$\dot u=-u_{xxx}-3P_K(u^2)_x$ の両辺を積分すれば零モードが一定である。$u$ と内積を取ると、$\langle u,u_{xxx}\rangle=-\langle u_x,u_{xx}\rangle=0$、$\langle u,P_K(u^2)_x\rangle=\langle u,(u^2)_x\rangle=\frac23\int (u^3)_x=0$ となる。最後の等式は $u$ が射影空間にあり、実数値で周期的だからである。従って半離散系では二乗ノルムが一定である。格子上の積が折り返して別の演算子に変わると、中間の射影の等式が使えない。時間積分も二乗和を自動的に保存するとは限らない。陰的中点法で更新差を中点状態と内積すれば上の二つの零が成立し、丸めと非線形解法の誤差まで除いた場合は二乗ノルムを保つ。



### 三次積の折り返しと必要な格子数

波数を整数 $-K,\ldots,K$ に切ると二次積は $-2K,\ldots,2K$ に広がる。DFT の $N$ 点で評価すると、本来の波数 $r$ は $r\bmod N$ に写る。残す波数 $k$ との最大差は $3K$ だから $N>3K$ なら $r-k$ が零でない $N$ の倍数にはならない。二次積を全て表現する $N>4K$ は、残す帯域だけが欲しいときには不要である。一般の $d$ 次積では同じ差の上限 $(d+1)K$ を用いる。例えば三次反応項を含む方程式で二次積用の零詰めを再利用すると、最高波数の三倍が残す帯域に折り返しうる。

:::example[小さい格子で三次の偽の定数項が出る]
$K=2$、$u=\cos2x$ の三乗は $(3\cos2x+\cos6x)/4$ である。$N=6$ では $\cos6x=1$ になるため、格子平均は $1/4$、真の平均は 0 である。$N=8$ では $\cos6x$ が $\cos2x$ になり、波数 2 の係数が本来の $3/4$ でなく 1 になる。$N=9$ では $\cos6x$ は $\cos3x$ へ折り返すが、波数 3 は保持範囲外である。従って残す範囲だけを見ると、初めて正確に $3/4$ が得られる。
:::



折り返しを除いた二次積でも、元の解のスペクトルが切った上端まで大きければ、基底を増やして解像する必要がある。例えば $u=\cos Kx$ では $u^2$ の定数分と $2K$ の成分は同じ振幅である。射影後に定数分しか残らなくても積の計算自体は正確であるが、$2K$ の物理的な高調波を表現できたわけではない。時間発展で高波数側のエネルギーが蓄積したら、時間刻みを下げる試験と、保持する最大波数を上げる試験を別に行う。

## 有限要素法の弱形式と基底関数

### 弱形式と要素の組立て

境界で $u=0$ の $-(a u')'=f$ を考える。$a(x)\ge a_0>0$ とし、同じ境界で 0 となる試験関数 $v$ を掛けて部分積分すると

$$
\int a u'v'\dd x=\int fv\dd x .
$$

この :term[弱形式]{en="weak form" yomi="じゃくけいしき"} では基底の二階微分を必要としない。節点 $x_j$ で値 1、他節点で 0 の連続区分線形な帽子関数 $\phi_j$ をとり、$u_h=\sum_j U_j\phi_j$ とおく。$A_{ij}=\int a\phi'_j\phi'_i$、$b_i=\int f\phi_i$ を作ると $AU=b$ である。一要素 $[x_j,x_{j+1}]$ の幅を $h_e$ とすると、$a$ が一定なら勾配は $(-1,1)/h_e$ で、要素行列は $(a/h_e)\begin{pmatrix}1&-1\\-1&1\end{pmatrix}$ である。一定 $f$ の荷重は二基底の面積が $h_e/2$ なので $(fh_e/2,fh_e/2)$ である。境界の係数を固定し、行列の寄与を右辺から差し引く。

### 弱解が一意になる条件

区間 $[0,L]$ で $a$ が可測かつ $0<a_0\le a(x)\le a_1<\infty$、$f\in L^2$ とする。試行関数と試験関数には、両端が零で弱微分が $L^2$ に属する空間 $H^1_0(0,L)$ を使う。任意の $v$ について $v(x)=\int_0^x v'(s)\dd s$ から $\|v\|_2\le L\|v'\|_2$ を得る。従って $\int a v'w'$ が定めるノルムは $H^1$ ノルムと同値で、この内積で空間は完備である。荷重 $v\mapsto\int fv$ は Cauchy–Schwarz とこの不等式により有界である。Riesz 表現を適用すれば、その荷重を $\int a u'v'$ と表す唯一の $u$ が得られる。同じ議論は任意の有限次元部分空間でも成立し、行列の二次形式は非零ベクトルに対して正である。係数に段差があっても弱形式は定まり、区間ごとに滑らかな解をつなぐ場合には内部境界で $a u'$ の跳びを零にする。

### エネルギー誤差

連続解と離散解の弱形式の差から $a(u-u_h,v_h)=0$、ここで $a(w,v)=\int a w'v'$ とする。従って任意の $w_h$ に対し、$u-w_h=(u-u_h)+(u_h-w_h)$ の二項はこの内積で直交する。ピタゴラスの等式から $u_h$ はエネルギーノルムで最良近似である。一次補間の要素内勾配は $u'$ の要素平均なので、$u''$ が有界ならその差は平均値から最大 $h_e\sup |u''|$ である。これを二乗積分して、エネルギーノルムの収束が少なくとも一次だと分かる。Neumann 境界では部分積分で出た法線流束を右辺に残す。三角形要素では面積座標が線形基底であり、勾配は要素内で一定である。

### 三角形要素を手で組み立てる

頂点 $(0,0),(1,0),(0,1)$ の三角形では基底は $1-x-y,x,y$ である。勾配は $(-1,-1),(1,0),(0,1)$、面積は $1/2$ なので、拡散係数 1 の要素行列は

$$
\frac12\begin{pmatrix}2&-1&-1\\-1&1&0\\-1&0&1\end{pmatrix}.
$$

定数の勾配は零なので行和はすべて零である。一次関数なら各要素で勾配を正しく再現する。定数荷重 $f$ に対する各節点の積分は $f/6$ である。例えば $\int_0^1 \int_0^{1-x} x\dd y\dd x=1/6$ となり、対称性で残りも同じである。形の異なる三角形では、参照三角形からの写像の Jacobian で勾配に逆転置、積分に行列式の絶対値を掛ける。面積だけで置き換えると細長い三角形で誤る。

### 計算実習：製造解で要素の組立てを検査する

区間 $[0,1]$、両端零、$-u''=1$ とする。厳密解は $u(x)=x(1-x)/2$ である。要素幅は一様である必要はないため、異なる幅の四要素を使い、剛性と荷重を要素ごとに足す。

~~~python
from sympy import Matrix, Rational, zeros

nodes = [0, Rational(1, 8), Rational(1, 2), Rational(3, 4), 1]
stiffness = zeros(len(nodes))
load = zeros(len(nodes), 1)
for left, (start, end) in enumerate(zip(nodes, nodes[1:])):
    width = end - start
    local = Matrix([[1, -1], [-1, 1]]) / width
    for a in range(2):
        load[left + a] += width / 2
        for b in range(2):
            stiffness[left + a, left + b] += local[a, b]

interior = stiffness[1:-1, 1:-1]
solution = interior.LUsolve(load[1:-1, :])
expected = Matrix([x * (1 - x) / 2 for x in nodes[1:-1]])
assert solution == expected
assert stiffness * Matrix([1] * len(nodes)) == zeros(len(nodes), 1)
~~~

この問題で節点値が厳密になる理由は、厳密解の一次補間の勾配が各要素で厳密な勾配の平均だからである。係数 $a=1$ と試験要素の勾配が要素内一定なので、厳密解と補間の差の弱形式は各要素で零になる。連続な要素内の誤差は残る。中点では曲率 1 の二次関数と弦の差が $h_e^2/8$ である。例えば最大幅 $3/8$ の要素では中点誤差は $9/512$ になる。係数が要素内で変化する場合や高次元では、この節点一致を一般の期待値にしない。

### 時間発展では質量行列が現れる

熱方程式 $u_t-(a u')'=f$ を同じ帽子関数で射影すると、係数は $M\dot U+AU=b$ を満たす。$M_{ij}=\int\phi_i\phi_j\dd x$ であり、線形要素の局所行列は $h_e\begin{pmatrix}2&1\\1&2\end{pmatrix}/6$ である。これは座標 $s=(x-x_j)/h_e$ に変えて $(1-s)^2,s(1-s),s^2$ をそれぞれ積分すると得られる。零外力で左から $U^\top$ を掛けると $\dv{}{t}(U^\top MU/2)=-U^\top AU\le0$ となる。$M$ を対角へ置き換える場合、どの節点積分に基づくかを決める。境界自由度を消す前の行列を行和で置き換えれば、定数ベクトルへの作用 $M\vb{1}$ は変わらず、要素内の質量の和も保たれる。分散関係など非定数モードの結果は変わりうる。

### 数値例

$h=\frac{1}{2}$、$a=1$ とする。幅を $h$、係数を $a$ とし、基底の勾配二乗を要素積分する。したがって、求める量は次の式で与えられる。

$$
\frac{a}{h}
$$

ここに上の値を代入して整理すると $2$ を得る。
:::

$h=\frac{1}{4}$、$a=2$ とする。幅を $h$、係数を $a$ とし、基底の勾配二乗を要素積分する。したがって、求める量は次の式で与えられる。

ここに上の値を代入して整理すると $8$ を得る。

### 自然境界と固定境界の違いを組立てで見る

$-(a u')'=f$ を区間 $[0,L]$ で扱い、$u(0)=0$、$a(L)u'(L)=g$ とする。試験関数 $v(0)=0$ を掛けて部分積分すると $\int_0^L a u'v'=\int_0^L fv+g v(L)$ を得る。左の固定条件は試行関数の許容集合に入れ、右の指定流束は荷重へ加える。両端を流束で指定すると定数関数 $v=1$ が使え、$\int f$ と正味の流束が釣り合う必要がある。この場合、定数を解に足してもよいので、例えば平均零を条件として選ぶ。

:::example[二要素の境界値を解く]
$L=1,a=1,f=2,g=0$ とし、長さ $1/2$ の二つの線形要素を使う。一要素の剛性は $2\begin{pmatrix}1&-1\\-1&1\end{pmatrix}$、荷重は $2(1/2)(1/2,1/2)^\top=(1/2,1/2)^\top$ である。左端の値を消去すると $\begin{pmatrix}4&-2\\-2&2\end{pmatrix}(u_1,u_2)^\top=(1,1/2)^\top$ となり、$u_1=3/4,u_2=1$ を得る。厳密解は $u=2x-x^2$ で、二節点で一致する。ただし最後の要素の傾きは $(1-3/4)/(1/2)=1/2$ で、端での厳密微分 0 と異なる。自然境界は弱形式で反映される。
:::

### 要素の残差に節点の流束跳びを含める

近似 $u_h$ が区間の各要素で線形の場合、要素内部の二階微分は零である。一方、弱形式 $\int a(u-u_h)'v'$ の右辺を要素ごとに積分し直すと、内部残差 $f+(a u_h')'$ に加え、各共有節点で $[a u_h']v$ が出る。ここで $[a u_h']$ は右側の値から左側の値を引いた差である。点ごとの方程式だけを検査しても、この流束の飛びは見えない。前の二要素の例では二要素の傾きが $3/2,1/2$ なので中央の跳びは $-1$ である。中央の帽子関数に対する荷重 $\int f v=1$ とちょうど相殺し、Galerkin 残差が零になる。別の試験関数すべてについて零になるわけではないため、誤差推定には要素内の分布も調べる。



### 線形要素の補間誤差を区間で導く

区間 $[x_j,x_{j+1}]$ の幅 $h_j$、端点の値を結ぶ線形補間を $I_hu$ とする。$u'$ が絶対連続で $u''\in L^2$ なら、$(I_hu)'$ は $u'$ の要素平均 $\overline{u'}$ である。任意の $x,y$ を取り、$u'(x)-u'(y)=\int_y^x u''(s)\dd s$ と Cauchy–Schwarz により $|u'(x)-u'(y)|^2\le h_j\int_{x_j}^{x_{j+1}}|u''|^2$ となる。$y$ の平均を取り Jensen の不等式を使い、さらに $x$ を積分すると

$$
\|u'-(I_hu)'\|_{L^2(I_j)}\le h_j\|u''\|_{L^2(I_j)}.
$$

誤差 $u-I_hu$ は端で零なので、同じ積分の議論で値の誤差は導関数の $h_j$ 倍以下である。従って $h=\max h_j$ に対し導関数ノルムで $O(h)$、値のノルムで $O(h^2)$ となる。Poisson の Galerkin 解 $u_h$ の導関数誤差は、直交性と最良近似性により補間誤差以下である。$a$ が上下に正で有限ならエネルギーノルムとの定数倍比較で同じ次数になる。

### 双対問題による値のノルムの評価

区間 $[0,1]$ 上の $-u''=f$、両端同次 Dirichlet の線形要素で $e=u-u_h$ とする。$-z''=e$、$z$ も両端零となる解を作るには、$z'(x)=c-\int_0^x e(s)\dd s$ とし、$z(1)=0$ になる $c$ を選べばよい。従って $\|z''\|_2=\|e\|_2$ である。弱形式に $e$ を入れて Galerkin 直交性を使うと

$$
\|e\|_2^2=\int z'e'=\int [z'-(I_hz)']e'
\le h\|e\|_2\|e'\|_2.
$$

$e\ne0$ なら割り、導関数誤差の評価 $\|e'\|_2\le h\|u''\|_2$ とあわせて $\|e\|_2\le h^2\|u''\|_2$ を得る。高次元や入り組んだ領域では双対問題の二階正則性がこのように自明ではないため、次数の主張には領域と係数の仮定が要る。

:::example[線形要素で値と微分の誤差比を厳密に測る]
$u=x(1-x)$、$f=2$ を $[0,1]$ で考える。線形試験関数は要素ごとに導関数が一定で、$\int_{I_j}(u-I_hu)'=0$ だから $u_h=I_hu$ である。幅 $h$ の要素で左端からの座標を $z$ とすると $e=z(h-z)$、$e'=h-2z$ である。積分は $\int_0^h e^2=h^5/30$、$\int_0^h(e')^2=h^3/3$ であり、$1/h$ 要素を足すと $\|e\|_2=h^2/\sqrt{30}$、$\|e'\|_2=h/\sqrt3$ となる。格子を二倍細かくしたとき、値と導関数でそれぞれ 4 倍と 2 倍という別の比を検査できる。
:::



### 一次元の固有モードで質量行列を点検する

一様幅 $h$ の線形要素で $-u''=\lambda u$、両端 Dirichlet とする。組み立て後の剛性と整合質量は $K=h^{-1}\operatorname{tridiag}(-1,2,-1)$、$M=h\operatorname{tridiag}(1,4,1)/6$ である。内部の $v_j=\sin(j\xi)$、$\xi=\ell\pi/N$、$h=L/N$ なら $K v=(2-2\cos\xi)v/h$、$Mv=h(4+2\cos\xi)v/6$ であり、固有値は

$$
\lambda_h=\frac{6(2-2\cos\xi)}{h^2(4+2\cos\xi)}
\label{eq-comp-fem-consistent-dispersion}
$$

となる。$M$ を各要素の行和で対角化してから境界を消すと内部質量は $hI$ となる。これを :term[質量集中]{en="mass lumping" yomi="しつりょうしゅうちゅう"} という。固有値は $(2-2\cos\xi)/h^2$ となり、中心差分と同じである。低波数で $k=\xi/h$ 固定のとき、二式はそれぞれ $k^2(1+\xi^2/12+O(\xi^4))$、$k^2(1-\xi^2/12+O(\xi^4))$ となる。従って同じ要素でも質量行列を変えると分散誤差の符号が逆になる。

:::example[最高側の固有値と陽的刻みの違い]
$\xi=\pi/2$ なら整合質量では $\lambda_h=3/h^2$、集中質量では $2/h^2$ である。空間離散した熱方程式 $\dot u=-M^{-1}Ku$ に陽的 Euler を使う場合、同じモードの刻み上限はそれぞれ $2h^2/3$ と $h^2$ である。一次元波動方程式では固有値の平方根が周波数になるため、刻みの比はそれぞれの平方根から得る。行和を境界行消去の後で取ると端近くの対角が $h$ でなくなるので、どの順で集中を行うかも検査する。
:::

### 要素内の積分誤差を分けて検査する

参照三角形 $(0,0),(1,0),(0,1)$ で線形基底を $N_1=1-\xi-\eta,N_2=\xi,N_3=\eta$ とする。定数係数の剛性は勾配が一定なので面積と一点の評価で厳密に積分できる。質量の $N_i N_j$ は二次だから重心一点では一般に厳密でない。例えば $M_{22}=\int_0^1 \xi^2(1-\xi)\dd\xi=1/12$ だが、重心一点では $(1/2)(1/3)^2=1/18$ になる。さらに重心では三基底が等しいため、すべての行列要素が $1/18$ となって階数 1 である。定数を積分できるというだけで質量行列を置き換えると、時間発展を組み立てるときに零のモードが生まれる。結合した全体系で行列がたまたま正定値になっても、要素のモーメントと分散は異なる。

実際の三角形へのアフィン写像を $x=x_0+B(\xi,\eta)^\top$ とすれば、勾配は $B^{-\top}\nabla_{\xi,\eta}N_i$、面積要素は $|\det B|$ 倍である。例えば頂点が $(0,0),(2,0),(0,1)$ なら $B=\diag(2,1)$、$N_2$ の物理勾配は $(1/2,0)$、面積は 1 だからその剛性対角は $1/4$ である。頂点順序を反転して行列式の符号を変えても面積の符号は正である。積分に $\det B$ を符号つきで使うと剛性の二次形式が負になるため、反転要素の検査と積分の絶対値を分ける。



曲辺の要素では写像の Jacobian が位置に依存する。従って線形の参照基底を使っても、剛性の積分が重心一点で厳密になるとは限らない。

## 流体方程式の数値計算入門

### 非圧縮速度への射影

一定密度 $\rho$ の非圧縮流体では $\partial_t u+(u\cdot\nabla)u=-\nabla p/\rho+\nu\Delta u+f$、$\nabla\cdot u=0$ である。圧力以外から予測速度 $u^\ast$ を作り、$u^{n+1}=u^\ast-(\Delta t/\rho)\nabla p$ とする。発散を取ると $\Delta p=(\rho/\Delta t)\nabla\cdot u^\ast$ を得る。周期箱では右辺の平均が 0 なので零モードを除いて解ける。Fourier 係数で $k\ne0$ に対し $u^{n+1}_k=(I-kk^\top/|k|^2)u^\ast_k$ である。射影行列を二乗すると自身になり、像のベクトルの $k$ 成分は 0 なので、各モードで直交射影と分かる。

壁で法線速度を指定する場合、補正式の法線成分が圧力の境界条件を与える。離散発散と離散勾配を $D,G$ とすれば、圧力行列は同じ組の積 $DG$ と整合させる。そうしないと Poisson 方程式を精密に解いても発散が残りうる。有限要素で速度と圧力を同時に解くと鞍点系になる。任意の速度・圧力空間の組で圧力が安定に決まるわけではない。例えば離散勾配が零になる非定数の圧力モードがあれば、速度の式はその成分を拘束しない。物理量の検査では残差と発散に加え、流量、境界での応力、粘性散逸を測る。

### 粘性流れの基準解

周期二次元で $u=(U\sin(ky)e^{-\nu k^2t},0)$ を置くと、$x$ に依存せず第二速度成分が 0 なので移流項は消える。発散も 0、粘性項は $-\nu k^2u$ であり、一定圧力のもとで方程式を満たす。この解で振幅減衰、圧力の定数モード、射影後の発散を個別に検査できる。運動エネルギーのセル積分は $e^{-2\nu k^2t}$ の割合で減る。駆動のある流れでエネルギー収支を取るときは、速度に外力を掛けて単位時間に供給された仕事を足す。

### 速度と圧力の結合を鞍点行列で見る

時間離散化の一段で速度ブロックを $A>0$、離散発散を $B$ として $Au+B^\top p=f$、$Bu=g$ の形を考える。符号は圧力勾配を $B^\top$ としたものとする。第一式の $u=A^{-1}(f-B^\top p)$ を第二式に代入すると $(BA^{-1}B^\top)p=BA^{-1}f-g$ となる。固有値の正値性は $p^\top BA^{-1}B^\top p=(B^\top p)^\top A^{-1}(B^\top p)$ で調べられ、$B^\top p=0$ の圧力方向だけが零である。速度・圧力の空間を選ぶときは格子を細かくしても圧力の拘束が弱くなりすぎないか検査する。離散発散が数値誤差内で小さくても、圧力の弱い方向の影響を除けているとは限らない。

### 数値例

:::example[第一軸に平行な波数に対する射影後の速度の二乗ノルム]
$v=2$ とする。二次元で波数が第一軸に平行なので、第二速度成分 $v$ だけが残る。したがって、求める量は次の式で与えられる。

$$
v^{2}
$$

ここに上の値を代入して整理すると $4$ を得る。
:::

:::example[第一軸に平行な波数に対する射影後の速度の二乗ノルム]
$v=\frac{1}{2}$ とする。二次元で波数が第一軸に平行なので、第二速度成分 $v$ だけが残る。したがって、求める量は次の式で与えられる。

$$
v^{2}
$$

ここに上の値を代入して整理すると $\frac{1}{4}$ を得る。
:::

### 射影法で圧力の境界条件を定める

仮速度 $u^*$ を作り、$u^{n+1}=u^*-\Delta t\,\nabla p/\rho$ と補正する。非圧縮条件から $\Delta p=(\rho/\Delta t)\nabla\cdot u^*$ を得る。壁法線速度を $g_n$ に指定する場合、補正式の法線成分から $\partial_n p=(\rho/\Delta t)(u^*\cdot n-g_n)$ となる。従って境界で $u^*$ が既に指定値を満たすときだけ圧力補正の法線微分は零である。右辺の体積積分と境界の法線微分の積分の一致には $\int_{\partial\Omega} g_n=0$ が必要であり、閉じた剛体壁ではこれを満たす。圧力の定数は残るので平均を固定する。

:::example[圧力を離散勾配の随伴で結ぶ]
周期格子で、面速度からセルへの離散発散を $D$、セルから面への勾配を $G=-D^\top$ とする。同じ重みの離散内積で $u^*-G\phi$ が発散零になるには $DG\phi=Du^*$ を解く。すると任意の発散零の $v$ について $v^\top G\phi=-(Dv)^\top\phi=0$ であり、補正は直交射影である。従って運動エネルギー差は $\|u^*\|^2-\|u^*-G\phi\|^2=\|G\phi\|^2$ となる。圧力の作用を別の差分で組み、発散と勾配の随伴性が失われる場合、この非増加性は同じ証明では得られない。
:::




### 粘性速度のエネルギー収支を離散化する

一定密度の非圧縮方程式で閉じた周期領域とする。移流 $(u\cdot\nabla)u$ と速度の内積は $\int u\cdot\nabla(|u|^2/2)=0$ であり、発散零と境界項の相殺を用いた。圧力勾配も発散零の速度と直交し、粘性は部分積分で $-\nu\|\nabla u\|_2^2$ を与える。外力 $f$ があれば収支は $\tfrac12\partial_t\|u\|^2=-\nu\|\nabla u\|^2+\langle f,u\rangle$ である。格子の中心差分では連続の積の微分則が厳密に成り立たないため、移流形式と保存形式が一般に一致しない。それでも周期格子の中心差分 $D_j^\top=-D_j$ を使い

$$
C(u)v=\frac12\sum_j \left[u_jD_jv+D_j(u_jv)\right]
$$

とすれば、内積 $\langle v,C(u)v\rangle=0$ が成り立つ。各項で $u_j$ の対角乗算が自己共役であり、$D_j$ の随伴が負で二項が打ち消し合うためである。非圧縮条件を別に保つ射影と組み合わせ、運動エネルギーの人工的な増大を抑えられる。時間離散化でこの等式が残るには、例えば中点状態に対して移流を評価した更新をその中点と内積する。

:::example[Taylor–Green の渦を製造解として使う]
二次元 $2\pi$ 周期で $u=A(t)(\sin x\cos y,-\cos x\sin y)$ とする。発散は零、Laplacian は $-2u$ である。移流を成分ごとに掛けると $A^2(\sin x\cos x,\sin y\cos y)$ であり、無次元密度 1 の圧力 $p=A^2(\cos2x+\cos2y)/4$ の負の勾配と一致する。従って外力なしで $A(t)=A(0)e^{-2\nu t}$ を取れば方程式を満たす。面積平均 $\langle|u|^2\rangle=A^2/2$ なので、$\nu=1/4,t=2$ の運動エネルギーの比は $e^{-2}$ になる。数値計算で速度の発散が小さくても、圧力の符号や粘性の係数を間違えるとこの参照と合わない。
:::




### 速度と圧力を同じ格子に置くときの零モード

周期の偶数点格子で、同じ位置にある圧力を中心差分で微分する。$p_j=(-1)^j$ では $p_{j+1}=p_{j-1}$ だから全点で勾配が零になる。圧力の平均も零なので、定数を差し引くだけではこの零空間を除けない。代わりに圧力をセル、速度を面へ置き、面勾配を $(p_{j+1}-p_j)/h$ とすれば交互モードでは振幅 $2/h$ を持つ。セルへの発散を $(u_{j+1/2}-u_{j-1/2})/h$ とすると、周期和で添字をずらして $G=-D^\top$ である。従って圧力作用素 $DG$ は通常の三点 Laplacian になり、零空間が定数だけに戻る。この配置は各セルへの正味流束も直接求められる。壁を含む場合は、面速度の境界値と圧力方程式の境界寄与を同じ流束で組み立てる。

### 鞍点系の整合性を Schur 補で見る

定常の離散 Stokes 系を $A u+B^\top p=f$、$Bu=0$ とする。$A>0$ なら $u=A^{-1}(f-B^\top p)$ を代入し、$S p=B A^{-1}f$、$S=B A^{-1}B^\top$ を得る。任意の $p$ で $p^\top S p=\|A^{-1/2}B^\top p\|^2$ だから、$B^\top p=0$ の圧力だけが Schur 補の零方向である。平均零空間を選んでも小さな固有値が残ると、圧力は離散残差に敏感になる。厳密に零でないだけで十分ではなく、格子を細分化した列で速度・圧力ノルムに対する下界が一様かを確認する。この下界を一般の要素の組に対して証明するには関数空間の安定性解析が必要なので、ここでは有限行列で残差がどう増幅されるかを直接調べる。

:::example[発散式を満たしても圧力精度を失う]
$A=I_2$、$B=(1,\epsilon)$ なら $S=1+\epsilon^2$ であり、小さな $\epsilon$ は圧力の分母を悪化させない。反対に $B=\diag(1,\epsilon)$ で二つの圧力自由度を持つと $S=\diag(1,\epsilon^2)$、第二方向の残差 $\delta$ は圧力誤差 $\delta/\epsilon^2$ に相当する。$\epsilon=1/100$、$\delta=10^{-6}$ なら圧力誤差は $10^{-2}$、速度へ返る誤差は $10^{-4}$ である。速度の見た目が収束しても圧力の誤差を同じ桁とは判断できない。
:::



### 速度と圧力のノルムをそろえた安定性

$A$ を速度空間の正定値なエネルギー行列、$M_p$ を平均零の圧力空間の正定値な質量行列とする。圧力 $p$ が与える速度方向の最大応答は
$\sup_{v\ne0}|p^\top Bv|/\sqrt{v^\top Av}=\sqrt{p^\top BA^{-1}B^\top p}$ である。$w=A^{1/2}v$ と変えれば Cauchy–Schwarz から上界を得る。$A^{-1/2}B^\top p$ が非零なら $w$ をその方向に取ると上界を達成し、零なら応答は常に零である。従って圧力ノルム $\sqrt{p^\top M_p p}$ で割った値の下限は、$M_p^{-1/2}BA^{-1}B^\top M_p^{-1/2}$ の最小固有値の平方根である。これが離散の :term[下限上限条件]{en="inf sup condition" yomi="かげんじょうげんじょうけん"} に現れる定数である。格子を細かくした列でこの定数が零から一様に離れていれば、正規化した圧力の残差から圧力誤差を一様に制御できる。係数ベクトルの Euclid ノルムのまま格子間で比較すると、基底の規格化による見かけの増減が混ざる。

### 計算実習：周期格子の二種類の圧力作用素

八点の周期格子で、同じ位置の中心差分を二回適用した作用素と、面勾配と発散を組み合わせた作用素を比較する。余弦波 $p_j=\cos(2\pi k j/N)$ に対し前者の固有値は $-\sin^2(2\pi k/N)/h^2$、後者は $-4\sin^2(\pi k/N)/h^2$ である。前者の中心差分を二回行うと $j\pm2$ の点だけがつながるため、偶数点と奇数点の間の圧力差を測れない。後者では $j\pm1$ とつながるためこの問題は生じない。ここでは圧力自体のノルムとの比を測り、零モードに近い場合の振幅を分けて表示する。

~~~python
from math import cos, pi, sin, sqrt


def central_difference(values, spacing):
    size = len(values)
    return [
        (values[(i + 1) % size] - values[i - 1]) / (2 * spacing)
        for i in range(size)
    ]


def face_gradient(values, spacing):
    return [(values[(i + 1) % len(values)] - u) / spacing for i, u in enumerate(values)]


def cell_divergence(values, spacing):
    return [(u - values[i - 1]) / spacing for i, u in enumerate(values)]


def norm(values):
    return sqrt(sum(u * u for u in values))


point_count = 8
spacing = 1 / point_count
for mode in range(point_count // 2 + 1):
    pressure = [cos(2 * pi * mode * i / point_count) for i in range(point_count)]
    collocated = central_difference(central_difference(pressure, spacing), spacing)
    staggered = cell_divergence(face_gradient(pressure, spacing), spacing)
    collocated_ratio = norm(collocated) / norm(pressure)
    staggered_ratio = norm(staggered) / norm(pressure)
    assert abs(collocated_ratio - (sin(2 * pi * mode / point_count) / spacing)**2) < 1e-10
    assert abs(staggered_ratio - (2 * sin(pi * mode / point_count) / spacing)**2) < 1e-10
    print(mode, round(collocated_ratio, 8), round(staggered_ratio, 8))
~~~

$N=8$、$h=1/8$ では $k=2$ の二つの比は 64 と 128、$k=4$ では 0 と 256 である。$k=0$ で両方が零なのは、圧力の定数が速度に作用しないという連続方程式にもある自由度である。$k=4$ に残る零は格子の配置が作った自由度である。圧力方程式を逆にする際、零固有値がこの二つのどちらから来たかを区別する。繰り返しの線形解法で残差が大きいと判断した場合も、収束許容差の前に、右辺がこれらの零空間と直交するかを点検する。
