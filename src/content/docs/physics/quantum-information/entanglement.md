## この章の目標

- 積状態、分離可能状態、もつれ状態を区別する。
- Schmidt 係数を計算し、Bell 相関の古典限界と量子限界を導く。
- 部分転置と文脈依存性の判定を具体的な行列で行う。

## もつれ状態と分離可能状態

局所的な状態を選び、共有した乱数でその選び方をそろえるだけでも相関が生じる。例えば測定結果が常に一致するという事実だけでは、その準備に必要な資源は分からない。

:::definition[分離可能状態]{#def-qi-separable}
$\rho=\sum_jp_j \rho_j^A\otimes\rho_j^B$、$p_j\ge0$、$\sum_jp_j=1$ と書ける状態を :term[分離可能状態]{en="separable state" yomi="ぶんりかのうじょうたい"}という。それ以外を :term[もつれ状態]{en="entangled state" yomi="もつれじょうたい"}という。
:::

各因子をスペクトル分解すれば純粋積状態の凸結合にできる。純粋状態をそのように分解できるなら、直交補上の二次形式が零である。各項が非負なので、各積ベクトルは元の純粋状態と同じ直線上にある。従って純粋状態が分離可能である条件は階数判定 :ref[prop-qi-product-rank] に一致する。

:::example[共有乱数]
$\rho=(\ketbra{00}{00}+\ketbra{11}{11})/2$ は分離可能である。両方の縮約が $I/2$ なので、それらの積は $I_4/4$ であり $\rho$ とは異なる。従って分離可能でも積とは限らない。
:::

:::example[純粋な相関]
$\ket{\Phi^+}$ も同じ局所縮約を持つ。一方、係数行列の階数が 2 なので、純粋積状態でもその凸結合でも表せない。
:::

### 純粋状態の混合で判定が変わる理由

純粋な二体系が分離可能なら積状態である。実際、階数 1 の密度行列の凸分解では各非零成分の支持がその直線に含まれる。核のベクトルに対する二次形式を取ると各成分が非負であり、和が零なので各成分が核を消すからである。縮約の一方が純粋なら、全体の支持はその直線と他方の空間のテンソル積に含まれるので、全体は両縮約の積になる。両縮約とも混合であれば、同じ周辺状態を持つ古典相関と量子的相関が存在する場合がある。

:::example[位相を忘れると積状態の混合になる]
$\ket{\psi_\pm}=\sqrt{3/4}\ket{00}\pm\sqrt{1/4}\ket{11}$ はどちらも係数行列が階数 2 である。ところが半々で混ぜると $\rho=(3/4)\ketbra{00}{00}+(1/4)\ketbra{11}{11}$ となる。$\rho$ の $XX$ 期待値は零だが、$\psi_\pm$ ではそれぞれ $\pm\sqrt3/2$ である。$ZZ$ はいずれも 1 なので、相関の存在だけではもつれを結論できない。
:::

### もつれ証人を相関から作る

Hermite 演算子 $W$ が全分離可能状態に対して $\Tr(W\sigma)\ge0$、ある状態に対して負なら、$W$ を :term[もつれ証人]{en="entanglement witness" yomi="もつれしょうにん"}という。積純粋状態に対する非負だけを確認すれば、線形性で混合にも延長できる。例えば $W=I/2-\ketbra{\Phi^+}{\Phi^+}$ なら、積 $\ket a\ket b$ の Bell 重なりの二乗は $\abs{\sum_j a_jb_j}^2/2\le1/2$ なので非負である。Bell 状態自身では値が $-1/2$ になる。

:::example[三つの測定設定で証人を読む]
$\ketbra{\Phi^+}{\Phi^+}=(II+XX-YY+ZZ)/4$ だから、$W$ の期待値は $(1-\langle XX\rangle+\langle YY\rangle-\langle ZZ\rangle)/4$ である。三つの測定で平均 $(\langle XX\rangle,\langle YY\rangle,\langle ZZ\rangle)=(4/5,-3/5,2/5)$ を得たとすると、値は $-1/5$ になる。有限試行なら各平均に誤差があるので、判定を保証するにはそれぞれの誤差上限の和が $4/5$ 未満であることを確認する。
:::

### 局所変換をかけた状態の判定

分離可能な状態へ Alice と Bob がそれぞれチャネルを掛けると、各分解成分が積状態のまま別の積に移る。さらに一方の測定結果で条件付ける場合、確率が正なら各積成分の重みを更新し、その側の条件付き状態だけを置換する。従って条件付き枝も分離可能である。逆に局所ユニタリで変換した出力が分離可能なら、逆ユニタリも局所なので入力も分離可能である。この性質により、局所基底を都合のよい座標へ変えてから判定できる。測定結果に応じて遠隔側の操作を変える場合にも、各枝の積分解を追えば同じ結論になる。

:::example[一方の局所フィルタで統計を選ぶ]
$\sigma_{AB}=(\ketbra{00}{00}+\ketbra{11}{11})/2$ に対し、Alice が成功演算子 $K=\diag(1,1/2)$ を持つ二結果測定を行う。完備にする失敗演算子は $\diag(0,\sqrt3/2)$ である。成功時の非規格化行列は $\frac12\ketbra{00}{00}+\frac18\ketbra{11}{11}$ で、確率 $5/8$ で起こる。規格化すれば重みは $4/5,1/5$ となる。Bob 側だけを見ると、成功に条件付けた計算基底の分布は $(4/5,1/5)$ に変わる。しかし記録を受け取らず両分枝を平均すると、元の一様周辺に戻る。フィルタの選別で古典相関の強さを変えても、積分解を失うことはない。
:::

:::example[直交でない局所ラベルでも分離可能]
$\sigma_{AB}=(\ketbra{00}{00}+\ketbra{++}{++})/2$ とする。準備は、共通の公平ビットから両者が同じ種類の純粋状態を選ぶ手続きである。両周辺は Bloch ベクトル $(1/2,0,1/2)$ を持つが、全体の $ZZ$ の平均は $\frac12(1^2+0^2)=1/2$ である。周辺の平均同士を掛けると $1/4$ に過ぎない。部分トレースと積の準備の順序を比較すれば、分離可能という条件は、局所状態が互いに独立という条件より広いことが分かる。
:::

### 積状態の凸包と有限測定による分離

有限次元で、純粋積射影の集合は局所単位球面の連続像なのでコンパクトである。跡 1 の Hermite 行列は実次元 $m=(d_A d_B)^2-1$ のアフィン空間にある。純粋積射影の凸結合に $m+2$ 個以上の異なる正重みがあれば、アフィン従属がある。すなわち $\sum_i c_iP_i=0$、$\sum_i c_i=0$ を満たす非零実係数を取れる。正負の係数が両方あり、$t=\min_{c_i>0}p_i/c_i$ で $p_i$ を $p_i-tc_i$ に替えると、全重みは非負のまま少なくとも一つが零になる。この操作を繰り返せば、任意の分離可能状態は高々 $m+1$ 個の純粋積射影の凸結合で表される。個数を固定して零重みを許せば、積射影の組のコンパクト集合と確率単体の連続像であり、従って分離可能状態の集合 $\mathcal S$ 自体も閉じている。

もつれ状態 $\rho$ が与えられたとき、Hilbert–Schmidt ノルムで最も近い $\sigma_*\in\mathcal S$ を取る。このノルムは $\|A\|_2^2=\Tr(A^\dagger A)$ である。$\sigma_*+t(\tau-\sigma_*)$ は $0\le t\le1$ で $\mathcal S$ に入る。距離の二乗を $t=0$ の右から微分すると $\Tr[(\rho-\sigma_*)(\tau-\sigma_*)]\le0$ となる。$A=\sigma_*-\rho$ と置き、$W=A-\Tr(A\sigma_*)I$ とすれば、全 $\tau\in\mathcal S$ に対し $\Tr(W\tau)\ge0$、一方 $\Tr(W\rho)=-\|\rho-\sigma_*\|_2^2<0$ である。従って有限次元の任意のもつれ状態に証人がある。この構成は証人の存在を保証するが、最も近い分離可能状態を効率よく求める方法を与えるものではない。

:::example[証人を Hermite 基底で分解する]
二量子ビットなら $I,X,Y,Z$ の積が実線形基底なので、証人 $W$ は $16$ 項以下の実線形結合に書ける。例えば $W=I/2-\ketbra{\Psi^-}{\Psi^-}$ は $(II+XX+YY+ZZ)/4$ になる。$\Psi^-$ では三つの等軸相関は $-1$ なので値は $-1/2$ である。積 $\ket0\ket1$ では $ZZ=-1$、他の積の平均は零で、値はちょうど 0 になる。同じ $ZZ$ の値でも、別の軸の相関を測れば差が見える。測定を独立に行うなら、証人は試行ごとの積の足し算ではなく、異なる設定の標本平均の線形結合から推定する。
:::

## Schmidt 分解

係数行列の階数は積かどうかを与える。さらに特異値を使うと、局所基底を選び直すことで対応するラベルを一対一にそろえられる。

:::theorem[Schmidt 分解]{#thm-qi-schmidt}
任意の二体系の純粋状態は $\ket\psi=\sum_{j=1}^r s_j\ket{u_j}\ket{v_j}$ と書ける。両側のベクトルは正規直交系であり、:term[Schmidt 係数]{en="Schmidt coefficient" yomi="しゅみっとけいすう"} $s_j>0$ は $\sum_j s_j^2=1$ を満たす。両縮約の正固有値は $s_j^2$ である。
:::

:::proof
係数行列を :ref[thm-linalg-svd] により $C=U\Sigma V^\dagger$ と特異値分解する。$(U\Sigma V^\dagger)_{ab}=\sum_j U_{aj}s_j\overline{V_{bj}}$ より $\ket{u_j}$ は $U$ の列、$\ket{v_j}$ は $V$ の列の複素共役として得られる。ベクトルの規格化が二乗和を定める。部分トレースでは直交性により交差項が消える。従って $s_j$ の組は順序を除いて一意である。
:::

:::example[正規直交でない表示からの計算]
$\ket\psi=(\ket{00}+\ket{01}+\ket{11})/\sqrt3$ では $\rho_A=\frac13\begin{pmatrix}2&1\\1&1\end{pmatrix}$ である。トレース 1、行列式 $1/9$ より Schmidt 係数の二乗は $(3\pm\sqrt5)/6$ である。
:::

二純粋状態の Schmidt 係数が等しければ、それぞれの局所正規直交系を基底に延ばし、対応する基底をユニタリで写すと一方から他方を得る。逆に局所ユニタリは縮約の固有値を変えない。

### Schmidt 係数の求め方と縮退

展開 $\ket\psi=\sum_{ij}C_{ij}\ket{ij}$ から $A$ の縮約は $CC^\dagger$ である。$B$ の縮約は $(C^\dagger C)^\top$ となる。その正固有値は Schmidt 係数の平方であり、零固有値の個数は両側の次元によって変わる。縮退した係数の組の内部で $A$ の正規直交基底を $U$ で混ぜると、$B$ 側を $\overline U$ で混ぜて元の ket を保てる。係数が同じ $\sqrt\lambda$ の組に代入すると、交差項の係数は $\sqrt\lambda\sum_j U_{aj}\overline{U_{bj}}=\sqrt\lambda\delta_{ab}$ になる。

:::example[複素係数をもつ非対称な例]
$\ket\psi=(\ket{00}+i\ket{01}+\ket{11})/\sqrt3$ では $C=[1,i;0,1]/\sqrt3$ であり、$\rho_A=[2,i;-i,1]/3$、$\rho_B=[1,-i;i,2]/3$ である。トレースは 1、行列式は $1/9$ なので正固有値は $(3\pm\sqrt5)/6$ である。例えば $A$ 上で $u_+$ を大きい方の正規化固有ベクトルに取り、$B$ 上で $(\bra{u_+}\otimes I)\ket\psi$ を $\sqrt{(3+\sqrt5)/6}$ で割れば、対応する正規化 Schmidt ベクトルを得る。$\rho_B$ の非対角項の符号は、部分トレースで $C_{i0}\overline{C_{i1}}$ を足す順序に由来する。
:::

:::example[最大もつれの基底を変える]
$\Phi^+$ に対し $Y$ の固有ベクトル $\ket{y_\pm}=(\ket0\pm i\ket1)/\sqrt2$ を使う。$\ket{y_+}\ket{y_-}+\ket{y_-}\ket{y_+}$ を展開すると混合項が消え、$\ket{00}+\ket{11}$ が残る。したがって二人が同じ $Y$ を測ると結果は逆である。同じ $X$ の測定では一致する。この違いは係数の縮退によって Schmidt 基底を変えても、片側の共役を忘れてはいけないことを示す。
:::

### 積状態による最良近似
$\lambda_{\max}$ を Schmidt 係数の平方の最大値とする。任意の単位積 $\ket a\ket b$ に対して $\abs{\braket{a,b}{\psi}}\le\sqrt{\lambda_{\max}}$ である。Schmidt 基底で内積を展開し、各 $\sqrt{\lambda_i}$ を最大値で抑え、Cauchy–Schwarz を適用する。最大係数に対応する基底の積を選べば等号となる。例えば $(3\ket{00}+4\ket{11})/5$ では、積 $\ket{11}$ の重なり $4/5$ が最大である。他方、トレース距離の最小値を純粋な積に限って求めると $\sqrt{1-(4/5)^2}=3/5$ である。

### 局所ユニタリで移る二つの状態を比較する

純粋二体系の局所ユニタリは Schmidt 確率を変えない。$U\otimes V$ を掛けると $A$ の縮約は $U\rho_AU^\dagger$ となり固有値が同じだからである。逆に二つの純粋状態の Schmidt 確率が重複込みで同じなら、各側で対応する Schmidt ベクトルを移す写像を作れる。これを正規直交基底の補空間まで延長すればユニタリになり、状態同士を移せる。この分類では最大もつれ状態は各縮約が一様な場合であり、左右の空間次元が異なるときは小さい側だけが全空間で一様である。大きい側では支持が小さい側の次元に制限される。

:::example[縮約の固有基底が違っても局所的に移せる]
$\psi=(\sqrt3\ket{00}+\ket{11})/2$ と $\phi=(\sqrt3\ket{+1}+i\ket{-0})/2$ を比較する。$A$ では $U=\ketbra{+}{0}+\ketbra{-}{1}$ が $\ket0,\ket1$ を $\ket+,\ket-$ に移す。$B$ では $V=\ketbra10+i\ketbra01$ が $\ket0,\ket1$ を $\ket1,i\ket0$ に移す。両写像は正規直交基底を別の正規直交基底に写すのでユニタリであり、$(U\otimes V)\psi=\phi$ である。計算基底での分布は異なるが、局所基底を対応させると両状態の Schmidt 係数は一致する。
:::

### Schmidt 切断の最良近似

Schmidt 係数を $\sqrt{\lambda_1}\ge\sqrt{\lambda_2}\ge\cdots$ とする。$1\le k\le\min(d_A,d_B)$ とし、必要なら係数列の末尾に零を補う。Schmidt 階数が高々 $k$ でノルム 1 のベクトル $\phi$ を用いて $\psi$ を近似する。$\phi$ の $A$ 側の支持射影 $P$ は階数 $k$ 以下であり、
$$
\abs{\braket{\phi}{\psi}}^2
=\abs{\mel{\phi}{P\otimes I}{\psi}}^2\le \Tr(P\rho_A)
=\sum_i\lambda_i\mel{u_i}{P}{u_i}.
$$
最後の重みは $[0,1]$ にあり、総和は $k$ 以下である。従って重みを大きい固有値から割り当てた上限 $\sum_{i=1}^k\lambda_i$ が得られる。その上位部分への射影を $P$ に選び、$(P\otimes I)\psi$ を正規化した $\phi$ を取れば等号を達成する。上位固有値が境界で縮退する場合は、その固有空間内のどの適切な次元の部分空間を選んでも最適値は同じである。

:::example[三準位のもつれを二準位で近似する]
$\ket\psi=(3\ket{00}+2\ket{11}+\ket{22})/\sqrt{14}$ では $\lambda=(9,4,1)/14$ である。階数 1 の最良の二乗重なりは $9/14$ で、トレース距離は $\sqrt{5/14}$ になる。階数 2 まで許すなら $\ket\phi=(3\ket{00}+2\ket{11})/\sqrt{13}$ を取れば二乗重なりは $13/14$ で、距離は $1/\sqrt{14}$ である。もし二番目の項を落として 0 と 2 だけを残すと二乗重なりは $10/14$ になる。同じ階数でも切断する基底の選択により誤差が異なる。
:::

:::example[縮約を対角化して Schmidt ベクトルを求める]
$\ket\psi=(2\ket{00}+\ket{01}+\ket{11})/\sqrt6$ とすると、$\rho_A=\begin{pmatrix}5&1\\1&1\end{pmatrix}/6$ である。固有値は $(3\pm\sqrt5)/6$ であり、大きい方に対する固有ベクトルは $(1,\sqrt5-2)^\top$ を規格化した $u_+$ である。$u_-$ は直交する規格化ベクトルである。各 $u_i$ の係数を $a_i,b_i$ とすれば、$(\bra{u_i}\otimes I)\ket\psi=(2\bar a_i\ket0+(\bar a_i+\bar b_i)\ket1)/\sqrt6$ である。そのノルムは $\sqrt{\lambda_i}$ だから、割れば $B$ の Schmidt ベクトルになる。二本の $B$ ベクトルの内積の分子は $\mel{u_-}{\rho_A}{u_+}=0$ であり、両側の基底が直交することを確認できる。
:::

### Schmidt 係数を二量子ビットの行列式から読む

係数行列 $C$ が $2\times2$ のとき、正規化は $\Tr(CC^\dagger)=1$ である。$\det(CC^\dagger)=|\det C|^2$ だから、二つの Schmidt 確率は
$$
\lambda_\pm=\frac{1\pm\sqrt{1-4|\det C|^2}}2 .
$$
係数の絶対値だけでは $\det C=C_{00}C_{11}-C_{01}C_{10}$ の打ち消しを決められない。同じ計算基底分布を持つ純粋状態の間でも、四つの振幅の位相が変わるともつれの有無が変わる。

:::example[基底の確率を保ったまま位相を変える]
$\ket{\psi_\varphi}=(\ket{00}+\ket{01}+\ket{10}+e^{i\varphi}\ket{11})/2$ を取る。$\det C=(e^{i\varphi}-1)/4$ なので $4|\det C|^2=\sin^2(\varphi/2)$ である。従って $\lambda_\pm=(1\pm|\cos(\varphi/2)|)/2$ となる。$\varphi=0$ では $\ket+\ket+$ に因数分解でき、$\varphi=\pi$ では両固有値が $1/2$ である。$\varphi=\pi/2$ では $(2\pm\sqrt2)/4$ で、どちらの極限とも異なる。どの場合も計算基底の分布は $(1/4,1/4,1/4,1/4)$ である。

$A$ の縮約の非対角成分は $(1+e^{-i\varphi})/4$ であり、$\varphi=\pi/2$ なら $(1-i)/4$ になる。従って $A$ の $X$ と $Y$ の期待値は $1/2,1/2$、$Z$ は 0 である。式を Bloch 球へ代入しても固有値 $(1\pm1/\sqrt2)/2$ に一致する。このように、入力が純粋であることが既知なら、全体の行列を求めず片側だけを測って Schmidt 確率を推定できる。全体が混合かもしれないなら、同じ縮約を持つ分離可能状態があるので、同じ推論はできない。
:::

## Bell の不等式と CHSH 不等式

二人の測定者の入力を $x,y\in\{0,1\}$、出力を $a,b\in\{-1,1\}$ とする。測定の選択が共有変数 $\lambda$ と独立であり、条件付き分布が $p(a,b|x,y,\lambda)=p(a|x,\lambda)p(b|y,\lambda)$ と分かれる模型を局所隠れ変数模型という。相関 $E_{xy}=\mathbb E[ab|x,y]$ を使い、$S=E_{00}+E_{01}+E_{10}-E_{11}$ を作る。

:::theorem[CHSH 不等式]{#thm-qi-chsh}
局所隠れ変数模型では $\abs S\le2$ である。
:::

:::proof
条件付き平均を $A_x,B_y\in[-1,1]$ とすると、固定した $\lambda$ で $S_\lambda=A_0(B_0+B_1)+A_1(B_0-B_1)$ である。それゆえ $\abs{S_\lambda}\le\abs{B_0+B_1}+\abs{B_0-B_1}=2\max(\abs{B_0},\abs{B_1})\le2$ となる。最後に、設定によらない同一分布で $\lambda$ を平均する。
:::

:::example[分離可能な量子状態の相関]
分離可能な $\sum_j p_j\rho_j\otimes\sigma_j$ に対する積測定は、$j$ を共有変数とする模型を持つ。例えば常に $+1$ を出せば各 $E_{xy}=1$ で $S=2$ となる。逆に違反は分離可能性を否定できる。
:::

### 完全反相関を使う Bell の不等式

三方向 $\boldsymbol a,\boldsymbol b,\boldsymbol c$ の測定を考える。両者が同じ方向を選ぶと出力が必ず反対になると仮定する。局所隠れ変数模型では、必要なら局所の乱数も隠れ変数に含め、各方向の出力を $A_{\boldsymbol n},B_{\boldsymbol n}\in\{\pm1\}$ と取れる。同方向で反対にならない確率は零なので、ほとんどすべての隠れ変数で $B_{\boldsymbol n}=-A_{\boldsymbol n}$ が三方向で同時に成り立つ。この関係から

$$
\begin{aligned}
|E(\boldsymbol a,\boldsymbol b)-E(\boldsymbol a,\boldsymbol c)|
&\le \mathbb E_\lambda|A_{\boldsymbol b}-A_{\boldsymbol c}|\\
&=\mathbb E_\lambda(1-A_{\boldsymbol b}A_{\boldsymbol c})\\
&=1+E(\boldsymbol b,\boldsymbol c)
\end{aligned}
$$

を得る。第二の等号は二つの符号が等しければ両辺が零、異なれば両辺が 2 になることによる。CHSH 不等式では、完全反相関を仮定せず二人に別々の測定方向を二つずつ許す。

:::example[一重項による Bell の不等式の違反]
$\ket{\Psi^-}$ は $XX,YY,ZZ$ の共通固有ベクトルで、各固有値は $-1$ である。また $i\ne j$ について $\sigma_i\otimes\sigma_j$ は $\sigma_i\otimes\sigma_i$ と反可換なので、その期待値は零である。従って相関は $E(\boldsymbol a,\boldsymbol b)=-\boldsymbol a\cdot\boldsymbol b$ となる。平面内で $\boldsymbol a,\boldsymbol b,\boldsymbol c$ の角度を $0,\pi/3,2\pi/3$ と取ると、左辺は $|-1/2-1/2|=1$、右辺は $1-1/2=1/2$ であり、不等式に違反する。
:::

### ゲームの成功率と観測量の対応

各試行で $x,y\in\{0,1\}$ を独立一様に選び、出力 $a,b$ が $a\oplus b=xy$ なら成功とする。符号値 $A=(-1)^a$、$B=(-1)^b$ を使うと、成否の指示変数は $(1+(-1)^{xy}AB)/2$ になる。四つの設定で平均すれば $p_{\mathrm{win}}=1/2+S/8$ である。ここで $S=E_{00}+E_{01}+E_{10}-E_{11}$ とした。古典決定的戦略が四つの条件を同時に満たすと仮定し、両辺をすべて排他的論理和すると、左辺は各出力が二度現れて 0 だが右辺は 1 になる。したがって高々三設定に勝つ。例えば両者が常に 0 を答えれば三設定で勝つので $3/4$ が最適である。共有乱数の使用は決定的戦略の凸結合であり、上限を上げない。

:::example[勝ち過ぎる分布と通信可能性]
条件 $a\oplus b=xy$ を満たす二組の $(a,b)$ に確率 $1/2$ ずつを与えると、各側の出力周辺は常に一様である。従って片側の設定を相手が出力周辺から知ることはできない。しかし $S=4$、成功率は 1 である。次節の量子上限はこれより低いので、周辺が遠隔設定に依存しないことだけでは量子相関の集合を指定できない。
:::

:::example[離散変数の古典相関]
両者が同じ一様ビット $\lambda$ を共有し、Alice が $a=\lambda$、Bob が $b=\lambda$ をどの設定でも返すと、$E_{xy}=1$ が四つ並び $S=2$ になる。その一方で各出力は半々である。実験で局所乱数が良好に見えることだけから、鍵生成に使える秘密乱数があるとは結論できない。共有乱数を第三者も知っていれば鍵は推測できる。
:::

### CHSH の八つの符号型

決定的な局所戦略では四つの積 $A_xB_y$ は積が 1 である。逆に積が 1 の四つの符号 $(c_{00},c_{01},c_{10},c_{11})$ に対して、$A_0=1$、$B_y=c_{0y}$、$A_1=c_{10}c_{00}$ と置ける。最後の成分も全積 1 の条件から一致する。このため相関だけを見た局所集合は、全積が正の八頂点の凸包である。CHSH で選ぶ目標の符号は全積が負なので、どの頂点も高々三箇所で一致する。したがって設定の重みが一様でないゲームでも、局所最大勝率は $1-\min_{x,y}p(x,y)$ である。最小重みの一箇所だけを反転させた符号四組が全積 1 を持ち、その頂点で達成する。

相関四組 $E$ に対して、$\pm u_j$ をこの八頂点とする。$u_1=(1,1,1,1)$、$u_2=(1,1,-1,-1)$、$u_3=(1,-1,1,-1)$、$u_4=(1,-1,-1,1)$ と選ぶと、各 $u_j$ の二乗ノルムは 4 で互いに直交する。従って $E=\sum_j b_j u_j$ で $b_j=u_j\cdot E/4$ であり、局所集合に属する条件は $\sum_j|b_j|\le1$ である。十分性は、重み $|b_j|$ を $\operatorname{sgn}(b_j)u_j$ に割り当て、余った重みは一対の反対頂点に等分すれば分かる。必要性は、頂点では $\sum_j|b_j|=1$ であり、この和が凸関数であることによる。

この条件は、すべての符号 $s_j$ に対する $(\sum_j s_j u_j)\cdot E\le4$ と同値である。$s_j$ の積が正なら、符号列は $\pm u_j$ のいずれかであり、得られる制約は各 $|E_{xy}|\le1$ である。積が負なら、負号が一つの列とその全体反転を考えればよい。例えば $s=(1,1,1,-1)$ では和は $(2,2,2,-2)$ となる。他の負号の位置と反転も合わせると、全積が負の符号型に沿う八つの CHSH 不等式になる。従って相関だけを指定するなら、これらの不等式の成立から局所模型を構成できる。周辺平均も指定する場合は、相関の凸分解がその周辺平均と一致するかを別に調べる。

:::example[設定が偏ると局所限界が変わる]
$(00,01,10,11)$ をそれぞれ $(1/2,1/4,1/8,1/8)$ で選ぶ。常に $a=b=0$ を返す戦略は $11$ だけで負け、勝率 $7/8$ である。各設定で相関の符号付き確率が同じ理想量子戦略では勝率は $(1+1/\sqrt2)/2\simeq0.8536$ である。重みが偏るとこの戦略は $7/8$ に届かず、この勝率だけでは局所上限を越えない。同じ実験データでも、四設定の条件付き相関を別々に推定して無重みの $S$ を計算するなら、重み付き勝率とは異なる統計量を検査している。
:::

### 三者に拡張した全か無かの矛盾

三者が $X$ または $Y$ を測り、$XXX,XYY,YXY,YYX$ の四つの設定に限る。$\ket{\mathrm{GHZ}}=(\ket{000}+\ket{111})/\sqrt2$ と定めると、この状態に対して $XXX$ は固有値 $+1$、残り三つは $-1$ である。$Y\ket0=i\ket1$、$Y\ket1=-i\ket0$ なので、二つの $Y$ は全ビットを交換した後に $-1$ を掛ける。局所決定値なら、四組の積をさらに掛けると各局所値が二度現れて $+1$ になる。一方、量子の四つの目標符号の積は $-1$ である。従って古典で四組全部を満たすことはできない。例えば $X$ の値は全て $+1$、$Y$ は一人だけ $-1$ とすれば三組を満たすので、四組等確率での局所勝率は $3/4$ である。

:::example[白色雑音付きの三者ゲーム]
$\rho_v=v\ketbra{\mathrm{GHZ}}{\mathrm{GHZ}}+(1-v)I/8$ を用いる。各観測量の跡は零なので、期待値は目標符号に $v$ を掛けた値である。従って各設定の勝率は $(1+v)/2$ になり、局所上限の違反条件は $v>1/2$ である。$v=3/5$ なら勝率 $4/5$ である。これに対して一人の結果を全て捨てると、残り二者の状態は $\rho_{AB}=v(\ketbra{00}{00}+\ketbra{11}{11})/2+(1-v)I/4$ なので分離可能である。ここで検出した相関は、第三の記録を捨てた二体系の Bell 試験では残らない。
:::

### 周辺の偏りだけでは Bell 相関を決められない

二値の符号観測 $A,B$ に対し、各設定での接合分布は
$$
p(a,b|x,y)=\tfrac14(1+a m_x+b n_y+ab E_{xy}),\qquad a,b=\pm1
$$
である。これは $1,a,b,ab$ が符号二変数の関数の直交基底であり、各期待値が $(1,m_x,n_y,E_{xy})$ であることから従う。ここで $m_x,n_y$ は各側の周辺平均である。この式がどの $(a,b)$ でも非負であることは $-1+|m_x+n_y|\le E_{xy}\le1-|m_x-n_y|$ と同値になる。実際、$a=b$ の二条件が下界、$a=-b$ の二条件が上界を与える。個々の設定でこの条件を満たすことと、共通の局所隠れ変数から全設定を再現できることは別の条件である。

:::example[同じ偏りと異なる CHSH の値]
全設定で $m_x=n_y=1/5$ とする。各相関の許容範囲は $[-3/5,1]$ である。四つの相関を $(1,1,1,-3/5)$ に取ると全確率は非負であり、遠隔設定に依存しない周辺を持つ。しかし $S=18/5$ なので量子上限 $2\sqrt2$ も越える。$E_{00}=1$ の設定では $p(+,+)=3/5,p(-,-)=2/5$、他は零である。$E_{11}=-3/5$ では $p(+,+)=1/5,p(+,-)=p(-,+)=2/5,p(-,-)=0$ となり、周辺は同じである。各設定の確率を正に保つだけでは、量子実験全体の整合性を判定できない例である。
:::

## Tsirelson 限界

各観測量 $A_x,B_y$ は自己共役で二乗が $I$ とする。一般の二値 POVM は補助系を付けた射影測定へ拡張できるので、この設定で根本的な上限が得られる。両設定のための補助空間を共通に取り、初期補助状態もそろえる。

:::theorem[Tsirelson 限界]{#thm-qi-tsirelson}
二値の局所観測量に対し、量子理論では $\abs S\le2\sqrt2$ である。
:::

:::proof
$\mathcal B=A_0\otimes(B_0+B_1)+A_1\otimes(B_0-B_1)$ とおく。二乗の対角項を足すと $4I$、交差項は積 $(B_0+B_1)(B_0-B_1)=-[B_0,B_1]$ により $-[A_0,A_1]\otimes[B_0,B_1]$ となる。各交換子の作用素ノルムは 2 以下なので $\norm{\mathcal B}^2\le8$ である。期待値の絶対値は作用素ノルムを超えない。
:::

:::example[量子上限の達成]
$\Phi^+$ で $A_0=Z,A_1=X$、$B_0=(Z+X)/\sqrt2,B_1=(Z-X)/\sqrt2$ とする。すると $\mathcal B=\sqrt2(Z\otimes Z+X\otimes X)$ となる。状態は両項の固有値 $+1$ の固有ベクトルなので $S=2\sqrt2$ である。
:::

### 二量子ビットの相関行列と最適値

二量子ビット状態 $\rho$ の実相関行列を $T_{ij}=\Tr(\rho\,\sigma_i\otimes\sigma_j)$ とする。固有値 $\pm1$ の非自明な局所射影測定を Bloch 軸 $\boldsymbol a_x,\boldsymbol b_y$ で指定すると、
$$
S=\boldsymbol a_0^\top T(\boldsymbol b_0+\boldsymbol b_1)+
\boldsymbol a_1^\top T(\boldsymbol b_0-\boldsymbol b_1).
$$
$\boldsymbol b_0+\boldsymbol b_1$ と $\boldsymbol b_0-\boldsymbol b_1$ は直交する。従ってこれらを $2\cos t\,\boldsymbol u$、$2\sin t\,\boldsymbol v$ と書ける。$0\le t\le\pi/2$ とし、零ベクトルの場合の軸は任意に補う。$\boldsymbol a_0,\boldsymbol a_1$ を $T\boldsymbol u,T\boldsymbol v$ の向きに選ぶと、$t$ についての最大値は $2\sqrt{\norm{T\boldsymbol u}^2+\norm{T\boldsymbol v}^2}$ である。$T^\top T$ を対角化し、そこでの $\boldsymbol u,\boldsymbol v$ の成分の平方和を $q_i$ とすれば $0\le q_i\le1$、$\sum_iq_i=2$ である。固有値の大きい二つに $q_i=1$ を与えると上限を取る。その固有軸を選べば達成できるので、最適値は $2\sqrt{\mu_1+\mu_2}$ である。ただし $\mu_1\ge\mu_2\ge\mu_3$ は $T^\top T$ の固有値である。

:::example[純粋もつれはどの程度違反するか]
$\ket\psi=\cos t\ket{00}+\sin t\ket{11}$ では $T=\diag(\sin2t,-\sin2t,1)$ である。対角項は $XX,YY$ が二基底を交換し、$ZZ$ が各基底を固定することから得る。非対角項は支持から出るか、交換位相の虚部が打ち消し合う。したがって最大値は $2\sqrt{1+\sin^22t}$ である。例えば $\cos t=4/5,\sin t=3/5$ なら $\sin2t=24/25$ であり、$S_{\max}=2\sqrt{1201}/25$ になる。Bob の軸を $Z$ と $X$ の平面で $Z\cos u\pm X\sin u$、Alice を $Z,X$ とし、$\tan u=24/25$ とすれば達成する。
:::

:::example[もつれ判定と CHSH 判定の差]
$\rho_v=v\ketbra{\Phi^+}{\Phi^+}+(1-v)I/4$ では $T=v\diag(1,-1,1)$ だから $S_{\max}=2\sqrt2\,v$ になる。$v=1/2$ での値は $\sqrt2$ であり、非自明な射影測定では違反しない。その一方で $\Tr(W\rho_v)=(1-3v)/4=-1/8$ なので、上の証人はこの状態をもつれと判定する。この二つの検査では利用できる測定記録と否定する仮定が異なる。
:::

### 量子相関を実ベクトルの内積で表す

任意の二値射影測定 $A_x,B_y$ と純粋状態 $\psi$ に対し $u_x=(A_x\otimes I)\psi$、$v_y=(I\otimes B_y)\psi$ と置く。各ベクトルの長さは 1 である。相関 $\langle A_x B_y\rangle$ は $\braket{u_x}{v_y}$ に等しく、両演算者が別の系に作用するので実数である。複素空間を実部と虚部に分けて実ベクトル化すると、実内積は複素内積の実部に一致する。従ってこの相関表は実単位ベクトルの内積で表せる。混合状態は参照を追加して純粋化しても同じ相関を持つため同じ結論である。

逆に有限個の実単位ベクトル $u_x,v_y\in\R^m$ に対し、互いに反可換な Hermite 行列 $\Gamma_j$ を用意する。$r=\lceil m/2\rceil$ 量子ビット上で、$j=1,\ldots,r$ に対して
$$
\begin{aligned}
\Gamma_{2j-1}&=Z^{\otimes(j-1)}\otimes X\otimes I^{\otimes(r-j)},\\
\Gamma_{2j}&=Z^{\otimes(j-1)}\otimes Y\otimes I^{\otimes(r-j)}
\end{aligned}
$$
と置き、最初の $m$ 本を使う。同じ $j$ のときは $X,Y$ が反可換である。異なる $j$ では先に $X$ または $Y$ が出る位置だけが反可換なので、全体も反可換である。$\Gamma_j^2=I$ であり、$\Tr(\Gamma_i\Gamma_j)/2^r=\delta_{ij}$ は反可換性と跡の巡回性から従う。$A_x=\sum_j (u_x)_j\Gamma_j$、$B_y=\sum_j (v_y)_j\Gamma_j^\top$ とすれば交差項は反可換性で打ち消され、二乗は $I$ である。$2^r$ 次元の最大もつれを用いると $\langle A\otimes B\rangle=\Tr(A B^\top)/2^r$ なので、指定の実内積を全て実現できる。この構成が再現するのは相関であり、各測定の任意の局所平均も同時に指定する主張ではない。

:::example[三方向の相関表を作る]
$u_1,u_2,u_3$ を三次元の標準基底とし、$v_1=(1,1,1)/\sqrt3$、$v_2=(1,-1,0)/\sqrt2$ とする。量子ビットでは直接 $\Gamma=(X,Y,Z)$ を使える。Bob の測定は $B_1=(X-Y+Z)/\sqrt3$、$B_2=(X+Y)/\sqrt2$ となる。各二乗は $I$ である。$\Phi^+$ で得る相関の第 1 列は $(1,1,1)^\top/\sqrt3$、第 2 列は $(1,-1,0)^\top/\sqrt2$ である。$Y$ の転置を忘れて $B_1$ に正符号を置くと、第 1 列の第 2 成分だけが $-1/\sqrt3$ になる。相関表の転置規約を明示する理由である。
:::

:::example[ベクトルの平行四辺形から CHSH を評価する]
相関のベクトル表現では $S=u_0\cdot(v_0+v_1)+u_1\cdot(v_0-v_1)$ である。従って $|S|$ は二つの和と差の長さの和以下であり、その二乗は Cauchy–Schwarz で $2(\|v_0+v_1\|^2+\|v_0-v_1\|^2)=8$ 以下になる。Bob のベクトル間の内積が $3/5$ なら長さは順に $4/\sqrt5$、$2/\sqrt5$、最大 $S$ は $6/\sqrt5\simeq2.683$ になる。Alice のベクトルをそれぞれ和と差の向きに取れば達成し、二つの長さが等しい場合に全体の $2\sqrt2$ に達する。
:::

### 二値の一般化測定でも同じ上限になる

POVM の二効果を $E_+,E_-$ とする。符号平均を表す $A=E_+-E_-=2E_+-I$ は自己共役縮小作用素である。先の実ベクトル表現で $u_x=(A_x\otimes I)\psi$ とすれば長さは高々 1 になる。同様に $v_y$ も長さが 1 以下であり、二つの和と差の長さの二乗和は $2(\|v_0\|^2+\|v_1\|^2)\le4$ である。従って CHSH の $2\sqrt2$ 上界はそのまま成立する。ベクトルを追加の直交方向で補って単位にしたい場合、$u$ 側の付加軸と $v$ 側の付加軸を直交させれば交差内積を変えずに長さだけを増せる。

二量子ビットで全二値 POVM を許したときの最大値は $\max(2,2\sqrt{\mu_1+\mu_2})$ である。各自己共役縮小作用素は、その固有基底で固有値を平均とする $\pm1$ の符号を選ぶことにより、二乗が $I$ の演算子の凸結合にできる。CHSH 式は各観測量について線形なので、その最大値はそのような演算子だけで達成できる。二次元で二乗が $I$ の自己共役演算子は、跡零の射影観測量または $\pm I$ である。一つでも定数なら同じ側の交換子が零なので、二乗式から絶対値は高々 2 になる。全てを定数 $I$ とすれば 2 を達成する。全てが跡零の場合には相関行列の式を適用する。

:::example[測定器の鋭さを両側で別々に変える]
理想軸の観測 $A_x,B_y$ をそれぞれ $\eta A_x,\mu B_y$ に変える。全二体相関は $\eta\mu$ 倍になる。例えば $\eta=9/10,\mu=4/5$ の場合、理想 Bell 入力と最適軸で $S=36\sqrt2/25>2$ となる。両側とも $4/5$ に落とすと $S=32\sqrt2/25<2$ である。状態に同じもつれがあっても測定が十分に鋭くないと違反が消える。これは基底の誤選択と違い、選んだ軸上の予測値そのものが小さくなる模型である。
:::

## Kochen–Specker の定理と文脈依存性

一つの観測量が複数の可換な組に入る場合、その値をどの組で測るかによらず先に割り当てられるかを考える。:term[非文脈性]{en="noncontextuality" yomi="ひぶんみゃくせい"}の仮定では、可換観測量の積の値は個々の値の積に等しい。

:::proposition[Peres–Mermin の平方による矛盾]{#prop-qi-contextual-square}
次の九つの観測量に文脈によらない $\pm1$ の値を割り当て、各行・各列の積の演算関係をすべて満たすことはできない。

$$
\begin{matrix}
X\otimes I&I\otimes X&X\otimes X\\
I\otimes Y&Y\otimes I&Y\otimes Y\\
X\otimes Y&Y\otimes X&Z\otimes Z
\end{matrix}

$$

:::

:::proof
各行・各列の内部は、反可換な局所因子があれば 2 回の符号反転が打ち消し合うので可換である。Pauli の積から第 3 列だけ積が $-I$、他の五組は $+I$ となる。一方、六組の割当値を掛けると九つの値が各 2 回現れるので $+1$ になる。演算関係からは $-1$ となり矛盾する。
:::

### 三次元での有限配置

:::theorem[Kochen–Specker の定理]{#thm-qi-kochen-specker}
次元 $d\ge3$ の複素 Hilbert 空間で、すべての階数 1 射影に $0,1$ を割り当て、任意の正規直交基底に対応する射影の値の和を 1 とすることはできない。
:::

:::proof
まず $d=3$ で、実ベクトルが張る直線に制限して Peres の配置を使う。$r=\sqrt2$ とし、$(0,0,1),(0,1,1),(0,1,r),(1,1,r)$ の座標を置換し符号を変える。全体の符号の違いは同じ直線なので、最初の非零成分が正のものを採用する。以下の番号で直線を表す。

| 番号 | 代表元 | 番号 | 代表元 | 番号 | 代表元 |
|---|---|---|---|---|---|
| 1 | $(0,0,1)$ | 12 | $(0,r,-1)$ | 23 | $(1,-r,1)$ |
| 2 | $(0,1,0)$ | 13 | $(0,r,1)$ | 24 | $(1,-1,-r)$ |
| 3 | $(1,0,0)$ | 14 | $(1,-r,0)$ | 25 | $(1,-1,r)$ |
| 4 | $(0,1,-1)$ | 15 | $(1,0,-r)$ | 26 | $(1,1,-r)$ |
| 5 | $(0,1,1)$ | 16 | $(1,0,r)$ | 27 | $(1,1,r)$ |
| 6 | $(1,-1,0)$ | 17 | $(1,r,0)$ | 28 | $(1,r,-1)$ |
| 7 | $(1,0,-1)$ | 18 | $(r,-1,0)$ | 29 | $(1,r,1)$ |
| 8 | $(1,0,1)$ | 19 | $(r,0,-1)$ | 30 | $(r,-1,-1)$ |
| 9 | $(1,1,0)$ | 20 | $(r,0,1)$ | 31 | $(r,-1,1)$ |
| 10 | $(0,1,-r)$ | 21 | $(r,1,0)$ | 32 | $(r,1,-1)$ |

直交する対の一方が 1 なら他方は 0 である。対を正規直交基底に補えば、基底の和が 1 だからである。互いに直交する三本のうち二本が 0 なら残りは 1 である。この二規則だけを使う。

座標軸のうち一つは 1 なので、座標置換で 1 番を値 1 としてよい。第 2 座標の反転は 1 番を固定し、直交する 4 番と 5 番を交換するので、4 番を値 0 としてよい。1 番と直交する 2、3、6、9 番は 0 である。表では $v:[u,w]$ を $u,w$ が値 0 の直交三本組から $v=1$ が従うこと、$v:[u]$ を直交対で $u=1$ から $v=0$ が従うこととする。すべての直交関係は表の座標を内積し、$r^2=2$ を使えば確かめられる。

| 15 番の値 | 順に強制される値 |
|---|---|
| 0 | $20:[2,15]$、$24:[20]$、$26:[20]$、$27:[6,26]$、$25:[9,24]$、$12:[27]$、$13:[25]$ |
| 1 | $33:[15]$、$30:[4,33]$、$16:[30]$、$19:[2,16]$、$25:[19]$、$27:[19]$、$26:[6,27]$、$24:[9,25]$、$12:[24]$、$13:[26]$ |

一般の $d$ で割当てがあれば、一つの正規直交基底を選び、値 1 のベクトルと他の二つが張る三次元部分空間を取る。その固定直交補の基底はすべて値 0 である。この補基底を三次元空間内の任意の基底に付け加えると、三本の値の和が 1 であることを要求する。従って三次元での矛盾がそのまま適用できる。
:::

### 文脈ごとの積を用いた実験量

平方の六つの可換な組を $C_1,\dots,C_6$ とし、演算子積の符号を $s_k$ とする。各組で三つを測り、一試行の値の積を $B_k$ とする。決定的な文脈独立割当てでは $\prod_k B_k=1$ であり、$\prod_k s_k=-1$ なので少なくとも一つの $s_k B_k$ が $-1$ になる。従って $\sum_k s_kB_k\le4$、確率的な混合でも期待値の和は 4 以下である。量子の共同射影測定では三演算子が可換で、全結果の積は $s_k$ になるので和は 6 に達する。この判定では、同じ記号に対する測定が各組で同じ観測量を実装するという仮定を確認する必要がある。

:::example[各結果の独立な符号誤り]
組の三結果を読み出した後、それぞれを独立に確率 $e$ で符号反転させると仮定する。各反転因子の平均は $1-2e$ なので、積の平均には $(1-2e)^3$ が掛かり、六組の和は $6(1-2e)^3$ となる。$e=1/20$ なら $6(9/10)^3=2187/500>4$ である。$e=1/10$ なら $6(4/5)^3=384/125<4$ となる。境界は $0\le e\le1/2$ において $e=(1-(2/3)^{1/3})/2$ である。符号誤りが相関する場合は三個の平均の積へ分けられない。
:::

:::example[二次元で矛盾が起こらない配置]
量子ビットの階数 1 射影は単位球面の点に対応し、同じ基底をなす二射影は反対点である。各点 $(x,y,z)$ について、順序 $(z,y,x)$ で最初に現れる非零成分が正なら 1、負なら 0 を割り当てる。例えば $(1,0,0)$ には 1、その反対には 0 である。$(0,1,0)$ でも同じ規則で 1 となる。反対点は符号が反転するためどの基底でも和は 1 である。この構成は連続でなくても基底ごとの条件を満たし、三次元以上の定理と矛盾しない。
:::

### 共同測定の射影を積から構成する

可換な Hermite 二値観測量 $A,B$ は、各組 $(a,b)\in\{\pm1\}^2$ に対して $P_{ab}=(I+aA)(I+bB)/4$ という射影を持つ。因子が可換な射影の積であり、積がゼロでない枝は $A,B$ の共同固有空間である。全 $P_{ab}$ が互いに直交し、その和が $I$ になる。三つ目の観測量が $C=\eta AB$ なら、この測定に第三のラベル $c=\eta ab$ を付けるだけでよい。必要な仮定は同じ組の可換性であり、違う組に属する観測量を同時に測る必要はない。

:::example[平方の第三行を Bell に似た基底で測る]
第三行の $A=X\otimes Y,B=Y\otimes X$ は計算基底状態を補ビット列へ写す。$\ket{00}$ に作用させると両方で $i\ket{11}$、$\ket{11}$ に作用させると両方で $-i\ket{00}$ である。従って偶数部分では $(\ket{00}\pm i\ket{11})/\sqrt2$ が共同の $\pm$ 固有状態である。奇数部分では $A\ket{01}=-i\ket{10}$、$B\ket{01}=i\ket{10}$ であり、符号は逆になる。つまり $C=ZZ$ の値は偶数部分で $+1$、奇数部分で $-1$ で、第三行の積は常に $+1$ となる。入力を $I/4$ としても各共同固有状態が $1/4$ ずつ出る一方で、積の条件は確率 1 で満たされる。
:::

:::example[第三列でだけ積の符号を逆にする]
第三列では $A=XX,B=YY$、$C=ZZ$ であり、$AB=-C$ である。Bell 状態 $\Phi^+,\Phi^-,\Psi^+,\Psi^-$ の $(a,b,c)$ は順に $(+,-,+),(-,+,+),(+,+,-),(-,-,-)$ である。実際、$XX$ は基底列を反転し、$ZZ$ は偶奇を読む。二つの符号を掛けて負号を付ければ $YY$ の値になる。例えば入力 $\ket{00}$ をこの組で測れば、$\Phi^+,\Phi^-$ の二ラベルが各 $1/2$ で出る。$XX$ と $YY$ の局所平均は零だが、その積は必ず $-1$ である。周辺平均の積では、同一試行の積の平均を再構成できない。
:::

### 二値割当てとスペクトル関係

文脈に依存しない値を仮定するとき、自己共役演算子 $A$ に対し実関数 $f$ を適用してできる $f(A)$ の値は $f$ を測定値に掛けたものになる。例えば $A^2=I$ なら値は $\pm1$ であり、射影 $P$ は $P^2=P$ だから値が 0 または 1 に限られる。可換な $A,B$ の積の値は同時固有空間で積になる。これは共同測定を行った一試行におけるスペクトル関係であって、非可換な二観測に対して積の値を要求するわけではない。Peres–Mermin の議論で仮定したのは、それぞれの可換組に入る一つの観測量の値が、組の選択に関わらず同じであることだった。

:::example[同じ射影を二種類の基底に入れる]
三次元で $\ket0$ を含む基底として $(\ket0,\ket1,\ket2)$ と $(\ket0,(\ket1+\ket2)/\sqrt2,(\ket1-\ket2)/\sqrt2)$ を考える。最初の基底で射影 $\ketbra00$ に値 1 を付けるなら、文脈独立な割当てでは二番目の基底でも 1 である。従ってどちらの基底でも補空間の二射影は全て 0 になる。$\ketbra00$ に値 0 を付けた場合は、各直交補基底のどちらか一つに 1 を置く。この二基底だけでは矛盾しない。多くの基底が射影を共有していくと、個別には可能な選択が相互に制約し、有限配置で矛盾が現れる。
:::

## 正値部分転置（PPT）判定条件と Horodecki の定理

:::definition[部分転置]{#def-qi-ppt}
積基底で $(\ketbra ij\otimes\ketbra kl)^{T_B}=\ketbra ij\otimes\ketbra lk$ と線形に定める。$\rho^{T_B}\ge0$ の状態を :term[正値部分転置]{en="positive partial transpose" yomi="せいちぶぶんてんち"}（PPT）状態という。
:::

分離可能なら、各項の第 2 因子を転置するだけである。転置は単一行列の非負固有値を保つので PPT となる。純粋状態では Schmidt 基底を選ぶと $\rho^{T_B}$ の固有値は $s_i^2$ と $\pm s_is_j$（$i<j$）、および残りの零である。実際、$\ket{ii}$ は固有ベクトルであり、$\ket{ij},\ket{ji}$ は $s_is_j$ を係数とする交換行列を作る。

:::example[白色雑音を混ぜた Bell 状態]
$\rho_p=p\ketbra{\Phi^+}{\Phi^+}+(1-p)I_4/4$ を考える。Bell 射影の部分転置は交換演算子の $1/2$ 倍である。対称部分の次元は 3、反対称部分の次元は 1 なので最小固有値は $(1-3p)/4$ となる。従って $p>1/3$ で分離不可能である。例えば $p=1/2$ で、跡零の二値射影観測量に限ると CHSH 最適値は $\sqrt2$ である。一様成分が寄与しないので Tsirelson 上限の $p$ 倍を用いた。定数出力の設定を含める場合は、その観測量が他方の同じ側の観測量と可換であるため、交換子を使う二乗式から上限 2 を得る。いずれにせよこの状態は CHSH に違反しない。
:::

:::theorem[Horodecki の判定]{#thm-qi-horodecki-ppt}
$2\times2$ または $2\times3$ の二体系で、分離可能性と PPT は同値である。一般の有限次元では分離可能性は、すべての正写像 $\Lambda:\operatorname{End}(B)\to\operatorname{End}(A)$ について $(\id\otimes\Lambda)(\rho)\ge0$ であることと同値である。
:::

### 正写像による特徴付け

:::proof[一般次元での正写像判定]
正写像は正演算子を正演算子へ送る線形写像である。分離可能性から必要性は、各積項で第 2 因子が正であり続けることから出る。

逆に分離不可能な $\rho$ を取る。純粋積状態の集合は単位球面の積の連続像なのでコンパクトである。その凸包は有限次元でコンパクトである。実際、凸結合の項が周囲の実空間次元より 2 個以上多ければ、アフィン従属関係に沿って係数を動かし、総和と凸結合を保ったまま一項を消せる。このため必要な項数に一様上限があり、凸包もコンパクト集合の連続像となる。

$\rho$ に最も近い分離可能状態 $\tau$ を Hilbert–Schmidt ノルムで選ぶ。任意の分離可能な $\eta$ について、$\tau$ から $\eta$ へ向かう線分で距離の二乗を微分すると $\Tr[(\tau-\rho)(\eta-\tau)]\ge0$ である。従って $W=\tau-\rho-\Tr[(\tau-\rho)\tau]I$ とすれば $\Tr(W\eta)\ge0$ かつ $\Tr(W\rho)=-\Tr[(\tau-\rho)^2]<0$ である。

$W$ を $A$ の基底で $W=\sum_{ij}\ketbra ij\otimes W_{ij}$ と展開し、$\Gamma(\ketbra ij)=W_{ij}$ と定める。任意の $x\in A,y\in B$ について $\mel y{\Gamma(\ketbra xx)}y=\mel{\bar x\otimes y}{W}{\bar x\otimes y}\ge0$ であり、スペクトル分解により $\Gamma$ は正写像である。トレース内積の随伴 $\Gamma^\dagger$ も正である。実際、正入力に対する出力の任意のベクトルでの二次形式は、正演算子同士の積のトレースである。$\ket\Omega=\sum_i\ket{ii}$ とすると

$$

\mel\Omega{(\id\otimes\Gamma^\dagger)(\rho)}\Omega
=\Tr[W\rho]<0.

$$

従って $\Gamma^\dagger$ が判定の反例となる。
:::

$2\times2$ と $2\times3$ での十分性には、$M_2\to M_2$ および $M_2\to M_3$ の正写像が、完全正写像と完全正写像に転置を合成した写像との和になるという Størmer と Woronowicz の分類を用いる。完全正写像は任意の参照系を付けても正性を保つ。分類の証明は低次元の正写像の構造解析を要するため、文献への案内は :cite[watrous-tqi]{loc="§6.5"} を参照する。この分解はトレース内積の随伴を取っても保たれる。実際、随伴は完全正性を保ち、出力側の転置は両側を転置で共役した完全正写像を使えば入力側へ移せる。従って $M_3\to M_2$ にも $\Lambda=\Lambda_1+\Lambda_2\circ T$ の形が成り立つ。$T$ はここでは入力上の転置である。PPT 状態に対する $(\id\otimes\Lambda_1)(\rho)$ と $(\id\otimes\Lambda_2)(\rho^{T_B})$ はともに正なので、一般の正写像判定を満たす。

:::example[Bell 成分が三分の一の場合の明示分解]
$\rho_{1/3}$ は $X,Y,Z$ の三軸を等確率で選び、$X,Z$ の場合は同じ符号、$Y$ の場合は反対符号の固有状態の積を準備して得られる。各軸で符号を半々に選ぶので一次の Pauli 項は打ち消し合う。積を展開すると、混合は $(I+(X\otimes X-Y\otimes Y+Z\otimes Z)/3)/4$ であり、$\rho_{1/3}$ に等しい。$0\le p\le1/3$ ではさらに一様状態を混ぜれば $\rho_p$ を作れる。従ってこの族の $1/3$ という境界は分類定理を使わずに確認できる。
:::


:::example[三次元どうしの PPT もつれ]
$e_0,e_1,e_2$ を局所基底、$s=e_0+e_1+e_2$ とする。次の五つの積ベクトルを規格化して $v_i$ とする。
$$

e_0\otimes(e_0-e_1),\quad
(e_0-e_1)\otimes e_2,\quad
e_2\otimes(e_1-e_2),\quad
(e_1-e_2)\otimes e_0,\quad
s\otimes s .
$$

最初の四つの異なる二項は、少なくとも片側で因子が直交する。第 5 項と他の各項も、片側に差ベクトルがあるので直交する。従って $P=\sum_i\ketbra{v_i}{v_i}$ は階数 5 の射影である。$\rho=(I_9-P)/4$ は密度演算子であり、第 2 因子がすべて実なので $\rho^{T_B}=\rho\ge0$ である。

一方、五つの局所因子の集合は両側で順序が異なるだけで、$\{e_0,e_0-e_1,e_2,e_1-e_2,s\}$ である。このうち任意の三つは独立である。例えば両方の差ベクトルを含むと、その張る空間の全座標和は零だが、残るどのベクトルも座標和が非零である。一つ以下の差ベクトルを含む残る組は、基底表示の各三列の行列式で確認できる。従って非零ベクトルは片側で高々二つの因子としか直交できない。両因子を合わせても五積すべてと直交する非零積ベクトルは存在しない。

もし $\rho$ が分離可能であれば、その純粋積分解の全成分は $\rho$ の支持に入る。これは核上の二次形式が零で各項が非負だからである。ところが $\rho$ の支持には先の理由で積ベクトルが存在しない。従って $\rho$ は PPT でもつれている。
:::

### 部分転置の基底依存性と負固有値

$B$ の基底をユニタリ $U$ で変える場合、行列表現を $U^\dagger B U$ へ変えてから転置し元の基底へ戻すと、$U U^\top B^\top \bar U U^\dagger$ になる。これは $B^\top$ のユニタリ共役である。テンソル積の行列単位に線形性で適用すれば、$\rho^{T_B}$ の固有値は基底選択に依存しない。純粋状態を Schmidt 基底で $\sum_i \sqrt{\lambda_i}\ket{ii}$ とすると、部分転置後は $\sum_{ij}\sqrt{\lambda_i\lambda_j}\ketbra{ij}{ji}$ である。$\ket{ii}$ の固有値は $\lambda_i$、$i<j$ の対称・反対称結合の固有値はそれぞれ $\pm\sqrt{\lambda_i\lambda_j}$ となる。したがって純粋状態では Schmidt 階数が 2 以上なら必ず負固有値がある。

:::example[三準位の部分転置]
$\ket\psi=(2\ket{00}+2\ket{11}+\ket{22})/3$ に対し、対角の三固有値は $4/9,4/9,1/9$ である。組 $(0,1)$ から $\pm 4/9$、組 $(0,2),(1,2)$ の各々から $\pm2/9$ が加わる。トレースは 1 で変わらないが、負固有値の絶対値の和は $8/9$ になる。比較として三準位の最大もつれでは全 $\lambda_i=1/3$ なので、負固有値三つの和の絶対値は 1 である。
:::

:::example[負固有ベクトルから証人を作る]
$\rho_v$ の部分転置に対し、$\ket{\Psi^-}=(\ket{01}-\ket{10})/\sqrt2$ は固有値 $(1-3v)/4$ を持つ。$W=(\ketbra{\Psi^-}{\Psi^-})^{T_B}$ とおくと $\Tr(W\sigma)=\mel{\Psi^-}{\sigma^{T_B}}{\Psi^-}$ である。転置が基底成分の入れ替えでありトレース内積で自己随伴であるためである。分離可能状態の部分転置は正であるから $W$ は証人になる。$v=3/4$ なら値は $-5/16$ である。この方法では負固有ベクトルが測定すべき観測量を指定する。
:::

### 交換対称な状態の PPT 境界

$d\ge2$ とし、交換演算 $F\ket{ij}=\ket{ji}$ を用いる。対称および反対称射影 $P_\pm=(I\pm F)/2$ の跡は $n_\pm=d(d\pm1)/2$ である。対角の $\ket{ii}$ は対称であり、$i<j$ の二次元に各対称と反対称の一本があることを数えればよい。$\rho_t=tP_+/n_++(1-t)P_-/n_-$ を考える。$F^{T_B}=\ketbra\Omega\Omega$、$\ket\Omega=\sum_i\ket{ii}$ なので、部分転置は $aI+b\ketbra\Omega\Omega$ となる。ここで $a=(t/n_++(1-t)/n_-)/2$、$b=(t/n_+-(1-t)/n_-)/2$ である。$\Omega$ に沿う固有値を整理すると $a+db=(2t-1)/d$、直交補は $a$ である。よって PPT は $t\ge1/2$ と同値である。

この族については、PPT が分離可能性に十分であることも直接示せる。ユニタリ $U$ で同時共役 $U\otimes U$ を平均する。平均後の状態は全 $U\otimes U$ と可換である。この可換性から、行列が $I,F$ の張る二次元に入ることを確かめる。全対角ユニタリとの可換性から、非零の成分 $\mel{ij}{A}{kl}$ では多重集合 $\{i,j\}=\{k,l\}$ が一致する。全置換ユニタリでも不変なら、$i=j$ の対角値は共通の $c$、$i\ne j$ の二次元ブロックは共通の $[a,b;b,a]$ になる。二座標の $U$ が $\ket i$ を $(\ket i+\ket j)/\sqrt2$ に移すと、$\ket{ii}$ での期待値 $c$ は $(c+a+b)/2$ に一致する必要がある。よって $c=a+b$ で、$A=aI+bF$ となる。

積 $\ket u\ket v$ をこの平均に通すと、$F$ 期待値 $\abs{\braket uv}^2$ は変わらない。従って対称部分の重みは $(1+\abs{\braket uv}^2)/2$ になる。重なりの二乗は任意の $[0,1]$ に選べるので、全ての $t\ge1/2$ が得られる。平均は分離可能状態の閉凸集合内に入る。実際、有限和による積準備の混合で任意に近似でき、その極限も閉性から分離可能である。$t<1/2$ なら鋭い証人として $F$ を使える。積状態での期待値が非負で、$\rho_t$ では $2t-1<0$ だからである。

:::example[三次元の交換対称混合]
$d=3,t=1/4$ とする。$n_+=6,n_-=3$ なので $a=(1/24+1/4)/2=7/48$、$b=(1/24-1/4)/2=-5/48$ である。部分転置の固有値は $\Omega$ 方向で $-1/6$、他の八方向で $7/48$ である。証人 $F$ の値は $-1/2$ となり、同じもつれを交換期待値から判定できる。一方 $t=3/4$ なら $F$ 期待値 $1/2$ を持つ積を平均すればよい。例えば $\ket u=\ket0,\ket v=(\ket0+\ket1)/\sqrt2$ がこの重なりを持つ。パラメータの端を変えるだけで、分離可能な実装を使える領域に入る。
:::

### PPT の積と凸混合に対する安定性

PPT 状態の凸結合は、部分転置が線形で正行列の錐が凸なので PPT である。PPT な二状態の積を新しい $A_1 A_2:B_1 B_2$ に分けると、部分転置は各部分転置のテンソル積だから正である。また積 Kraus 演算子 $L_j\otimes M_j$ からなる局所条件付き操作の出力では
$$
\left[\sum_j(L_j\otimes M_j)\rho(L_j\otimes M_j)^\dagger\right]^{T_B}
=\sum_j(L_j\otimes\overline{M_j})\rho^{T_B}(L_j\otimes\overline{M_j})^\dagger.
$$
各項が正なので出力は規格化後も PPT である。古典通信を用いる局所操作は、記録を細分した各葉で局所演算子を順に掛けた積で表せるから、記録を選別した分枝でも同じ結論になる。PPT な入力だけを $n$ 個準備して、このような操作で Bell 対を正確に出すことはできない。近似の場合にも、PPT 状態 $\sigma$ の Bell 重なりは高々 $1/2$ である。実際、$\Tr(\ketbra{\Phi^+}{\Phi^+}\sigma)=\Tr(F\sigma^{T_B})/2\le1/2$ となる。$F$ の最大固有値が 1、$\sigma^{T_B}$ が跡 1 の正行列だからである。従って任意精度で Bell 対へ近付けることもできない。

:::example[三次元の PPT もつれを二次元へ絞る]
前に得た $\rho=(I-P)/4$ に対し、Alice と Bob がそれぞれ $\ket0,\ket1$ の張る部分空間へ局所射影を掛ける。部分転置が正であることは隣接式から保存される。二量子ビットへ規格化した場合は、低次元の Horodecki 判定から分離可能状態になる。射影の成功確率は $P$ の五積の各二次元平面との重なりから計算できる。第 1 項は全部残り、第 2,3 項は $\ket2$ を含む側により消える。第 4 項の $e_1-e_2$ のノルムの二乗の半分が残り、第 5 項は各側 $2/3$ なので積で $4/9$ である。従って成功確率は $(4-1-1/2-4/9)/4=37/72$ である。この成功はもつれの濃縮を意味しない。PPT が保たれ、縮めた次元ではそれが分離可能性まで含意するからである。
:::

### 積ベクトルのない支持から非分解型の証人を作る

五つの実積ベクトルの射影和 $P$ を考える。積の単位ベクトルの集合はコンパクトで、$g(u,v)=\mel{uv}{P}{uv}$ は連続である。その最小値 $\epsilon_*$ は正である。零であれば各非負項 $\abs{\braket{v_i}{uv}}^2$ が全て零になり、既に示した積ベクトルが存在しないことに反するからである。$W=P-\epsilon_*I$ は全積で非負であり、$\rho=(I-P)/4$ で負の期待値 $-\epsilon_*$ を持つ。

もし $W=A+B^{T_B}$ と $A,B\ge0$ で書けると仮定すると、$\Tr(W\rho)=\Tr(A\rho)+\Tr(B\rho^{T_B})\ge0$ である。したがってこの証人はその形に分解できない。正写像による条件が PPT だけより強いのは、正写像または証人にこの種の分解できないものが含まれるからである。一方、$2\times2$ および $2\times3$ で PPT が十分という結果は、この反例の構成を低次元へ同じように移せないことと整合する。

## 演習問題

::::exercise{level=basic}
$\ket{01}$ の Schmidt 階数を求めよ。

:::solution
既に積基底の一項なので $1$ である。
:::

::::exercise{level=basic}
$(\sqrt3\ket{00}+\ket{11})/2$ の縮約の固有値を求めよ。

:::solution
両局所基底が直交するので、部分トレースで交差項は消える。残る確率は $3/4,1/4$ である。
:::
::::

::::exercise{level=basic}
$A_0=A_1=B_0=1,B_1=-1$ の $S$ を求めよ。

:::solution
$S=1-1+1+1=2$ である。
:::
::::

::::exercise{level=basic}
Bell 射影の部分転置の負固有値を求めよ。

:::solution
交換行列の $1/2$ 倍であり、反対称な $(\ket{01}-\ket{10})/\sqrt2$ の固有値は $-1/2$ である。
:::
::::

::::exercise{level=advanced}
局所基底変更 $U\otimes V$ が PPT 性を保つことを示せ。

:::solution
成分を積演算子に展開すると、部分転置後は $(U\otimes\bar V)\rho^{T_B}(U\otimes\bar V)^\dagger$ である。ユニタリ共役なので固有値を保つ。
:::
::::

::::exercise{level=advanced}
各観測量が自己共役で二乗が $I$ であるとする。$A_0,A_1$ が可換なら $\mathcal B$ の作用素ノルムが 2 であることを示せ。

:::solution
:ref[thm-qi-tsirelson] の二乗式で交換子が消えるので $\mathcal B^2=4I$ である。自己共役性からすべての固有値の絶対値は 2 である。
:::
::::

::::exercise{level=advanced}
白色雑音混合例で $p=3/4$ の CHSH 値を求め、違反を確認せよ。

:::solution
例の測定で一様成分のトレースは零なので $S=2\sqrt2\,p=3\sqrt2/2$ である。二乗が $9/2>4$ なので $S>2$ である。
:::
::::

::::exercise{level=advanced}
$\ket{\Phi^+}$ と $\ket{\Phi^-}=(\ket{00}-\ket{11})/\sqrt2$ の等確率混合は分離可能か。

:::solution
二射影を足すと交差項が相殺される。結果は $(\ketbra{00}{00}+\ketbra{11}{11})/2$ であり、明示的な積状態の混合である。
:::
::::

::::exercise{level=advanced}
$\ket{\psi_t}=\sqrt{t}\ket{01}+\sqrt{1-t}\ket{10}$ とし、$0<t<1$ とする。部分転置の負方向を求め、それを用いたもつれ証人の期待値を計算せよ。また同じ対角成分だけを残した状態でその証人の値がどうなるか求めよ。

:::solution
部分転置を取ると、二つの対角成分は $\ket{01},\ket{10}$ に $t,1-t$ を与え、$\ket{00},\ket{11}$ の張る空間には対角が零で非対角が $\sqrt{t(1-t)}$ の行列ができる。従って $\ket{\Phi^-}=(\ket{00}-\ket{11})/\sqrt2$ は負固有値 $-\sqrt{t(1-t)}$ を持つ。$W=(\ketbra{\Phi^-}{\Phi^-})^{T_B}$ なら任意の分離可能状態 $\sigma$ について $\Tr(\sigma W)=\mel{\Phi^-}{\sigma^{T_B}}{\Phi^-}\ge0$ である。入力 $\psi_t$ ではこの値がその負固有値に一致する。一方、対角成分だけを残した混合を部分転置しても変わらず、$\Phi^-$ とその支持が直交するので期待値は 0 になる。
:::
::::

::::exercise{level=advanced}
三者ゲームで目標は $XXX$ が $+1$、$XYY,YXY,YYX$ が $-1$ とする。設定選択の確率が順に $1/2,1/4,1/8,1/8$ なら局所決定的戦略の最大勝率を求めよ。白色雑音付き GHZ の勝率がそれを越える範囲を求めよ。

:::solution
四つの目標符号の積は負だが、局所決定値から得る四積の積は正である。少なくとも一つ失敗するので最大勝率は $1-1/8=7/8$ 以下である。各 $X$ の値を $+1$ にし、第 3 者の $Y$ だけを $-1$ にすると、$XYY,YXY$ が負になり、$YYX$ だけが失敗する。従って $7/8$ を達成する。共有乱数で混ぜてもこの上限は変わらない。GHZ と白色雑音の混合で GHZ の重みを $v$ とすると、各目標の符号付き期待値は $v$ なので、勝率は設定の偏りに依らず $(1+v)/2$ である。従って $v>3/4$ で局所限界を越える。等号ではこの重み付きの勝率だけからは違反を示せない。
:::
::::

## 確認テスト

::::quiz
すべての分離可能状態が満たす条件を選べ。

- [x] 部分転置が正である。
- [ ] 必ず両縮約の積に等しい。

:::explanation
積状態の凸結合は各項の転置後も正である。共有乱数による積状態の混合は一般に積とは異なる。
:::

::::quiz{answer="2" tol="1e-6"}
局所隠れ変数模型での CHSH 値の上限を答えよ。

:::explanation
固定した隠れ変数で $\abs{B_0+B_1}+\abs{B_0-B_1}\le2$ であり、平均でも上限は 2 である。全出力を $+1$ にすれば飽和する。
:::
::::

::::quiz
二体系の純粋状態で積である条件を選べ。

- [x] Schmidt 係数の非零成分が一つである。
- [ ] 二つの縮約の正固有値が重複度も含めて一致する。

:::explanation
前者なら分解は一項である。また積状態なら、係数行列は階数 1 なので Schmidt 係数は一つである。後者は Schmidt 分解により、零固有値の個数が異なりうる空間次元の組でも、全純粋状態に対して成り立つ。
:::
::::

::::quiz{answer="-0.125" tol="1e-6"}
白色雑音混合例で $p=1/2$ の部分転置の最小固有値を答えよ。

:::explanation
反対称部分の固有値は $(1-3p)/4=-1/8$ であり、対称部分の固有値より小さい。
:::
